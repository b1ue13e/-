## 验收方法论(证明作品集制)

1. **定义复述**:每个核心概念闭卷写出定义与符号。
2. **证明重建**:关键定理不看笔记重写证明主线,标出每步使用的工具。
3. **反例先行**:每个定理至少配一个反例 + 一个条件变式(AGENTS.md §5.6)。
4. **闭卷验收**:每阶段结束完成阶段 MOC 的闭卷清单。

## Honor Code

- 官方答案默认 `link-only`:可查阅、可对照,不复制进提交。
- 本地融合作业如实标注来源贡献,不冒充 MIT 官方作业。
- 代码(数值验证)只作辅助,数学证明必须纸笔完成。
