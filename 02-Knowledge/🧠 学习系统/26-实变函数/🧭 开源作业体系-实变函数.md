# 🧭 开源作业体系-实变函数

> 本页是「实变函数」的开源教材与作业的**唯一挂载点**：教材主线、官方作业链、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**Rudin《Real and Complex Analysis》公开讲义 + MIT OCW 18.103 + Royden 公开笔记**。课程定位：**数学证明型课程**，不做机器学习指标冲榜，采用「定义复述、证明重建、反例、条件变式、闭卷验收」模式。

| HW | 主题 | 官方来源 | 所需知识点（双链） | 验收方式 |
|:---|:---|:---:|:---|:---|
| HW01 | $L^2$ 空间完备性与 Weierstrass 反例 | Rudin RCA Ch.1-2 | [[L2空间与完备性]]、[[实变函数 - HW01：L2 空间完备性与 Weierstrass 反例阶梯作业]] | 阶梯作业 4 层全部完成：Weierstrass 函数数值绘图 + Riesz-Fischer 纸笔证明 + 闭卷复述 |

| HW05 | Fourier 级数与 $L^2$ 收敛 | MIT 18.103、Rudin RCA Ch.4 | 三角级数、正交系、$L^2$ 收敛、Plancherel | 证明 $\{e^{inx}\}$ 是 $L^2[-\pi,\pi]$ 完备正交系；给出逐点收敛失败的反例 |
| HW06 | 泛函分析衔接 | Rudin RCA Ch.3-5 | Hahn-Banach / 开映射 / 闭图像三大定理、[[泛函分析 - HW01：三大定理与 Hilbert 空间算子阶梯作业]] | 完成三大定理证明重建 + 一道应用（如 $L^p$ 对偶的铺垫） |

## ✅ 验收方式与评分

本课程为**证明作品集制**，不设自动评测脚本：

1. **证明作品集**：按「定义—定理—反例—习题」四件套组织，每个 HW 提交一份纸笔推导（可含 Lean 4 形式化加分项），存档到 `03-Projects/课程作业/26-实变函数/`。
2. **闭卷概念重建**：每阶段（HW02/HW04/HW06）结束，闭卷完成「复述定义 → 重建证明主线 → 默写反例」三件套，作为阶段验收证据。
3. **口试验收**：每个 HW 完成后闭卷回答 3 问——"这个定理的条件哪些不能省？反例长什么样？证明主线里的关键转念是什么？"
4. **满分 Rubric**（100 分）：定义与反例 20 + 证明正确性 35（关键定理不跳步）+ 分级习题 20 + 定理依赖与反思 15 + 口头验收 10；达 75 分且证明正确性 ≥ 25 分为通过。

## ⚖️ Honor Code

1. 公开讲义、MIT OCW 习题与 Royden 笔记的**官方答案默认 `link-only`**：可查阅、可对照，不复制进作业提交。
2. 作业中的证明与反例构造须**自己完成**；对照官方解答后须在笔记中标注"对照后修订"。
3. 克隆仓库时记录来源 URL、commit 与许可证；自己的证明、代码与报告放入课程项目目录。
4. 反例先行：写定理笔记时强制要求"至少一个反例 + 一个条件变式"，防止把定理背成口号。
