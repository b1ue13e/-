# 状态方程

## 0. 为什么学它

传递函数只看输入-输出，看不见系统内部。**状态空间**用一阶微分方程组描述全部内部状态 $\dot x=Ax+Bu$——能处理多输入多输出、非线性线性化、能控能观分析与最优控制，是现代控制的语言。

## 1. 核心定义

**连续 LTI 状态空间**：

$$\dot x = Ax + Bu,\qquad y = Cx + Du.$$

| 符号 | 含义 | 维数 |
|:---|:---|:---|
| $x$ | 状态向量 | $n\times1$ |
| $u$ | 输入向量 | $m\times1$ |
| $y$ | 输出向量 | $p\times1$ |
| $A$ | 系统矩阵 | $n\times n$ |
| $B$ | 输入矩阵 | $n\times m$ |
| $C$ | 输出矩阵 | $p\times n$ |
| $D$ | 直接传递矩阵 | $p\times m$（常为 0） |

**从 ODE 建立**：把高阶 ODE 化为 n 个一阶方程，选状态变量（如 $x_1=y,x_2=\dot y,\dots$）。

## 2. 最小可手算例子

**题目**：$\ddot y+3\dot y+2y=u$，建立状态空间。

**解**：选 $x_1=y,\ x_2=\dot y$：
$\dot x_1=x_2$；$\dot x_2=-2x_1-3x_2+u$；$y=x_1$。

$$A=\begin{pmatrix}0&1\\-2&-3\end{pmatrix},\ B=\begin{pmatrix}0\\1\end{pmatrix},\ C=\begin{pmatrix}1&0\end{pmatrix},\ D=0.$$

**易错点**：状态变量选取不唯一（不同选取得不同但等价的 $A,B,C,D$）；$D$ 常为 0。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 状态空间表示唯一 | 状态选取非唯一，但输入输出关系等价 |
| $D$ 总是 0 | 直接耦合系统 $D\ne0$ |
| 只有 SISO 能用 | 状态空间天然支持 MIMO |
