# 状态空间与LQR控制

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：现代控制理论的枢纽节点——HW01 的 L1-L2 阶梯（倒立摆稳定、手解 Riccati）直接考察本知识点；HW05 机械臂动力学控制、HW06 闭环都建立在 LQR 之上；同时它是通往 MPC（把 LQR 的目标函数加约束 + 滚动时域）的唯一入口。跳过它，最优控制这条主线全部断掉。

---
## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> PID 控制器（见 [[PID控制器与状态空间法]]）在单输入单输出、线性近似好的系统上很有效，但遇到三类麻烦就抓瞎：① **多变量耦合**——四旋翼的 4 个电机同时影响 6 个自由度，PID 要 6 个回路互相打架；② **没有模型依据的调参**——PID 三个增益全靠试凑，说不出"为什么这个值最优"；③ **性能指标无法形式化**——"又快又稳又省力"是模糊的，没法写成数学上可最小化的目标。
> 因此必须引入**状态空间 + LQR**：先把系统写成 $\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}$（状态空间，天然支持 MIMO 与内部状态），再把"又快又稳又省力"写成二次型目标函数 $J = \int_0^\infty (\mathbf{x}^T Q \mathbf{x} + \mathbf{u}^T R \mathbf{u}) dt$，然后用 Riccati 方程一次性解出**最优**反馈增益 $K$——调参从"试凑 3 个数"升级为"设定 2 个权重矩阵，其余交给数学"。

---
## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是 HW01（LQR + MPC 轨迹跟踪）的理论核心；LQR 的"目标函数 + 代数 Riccati 方程"模式直接推广为 MPC 的"滚动优化"（见 [[🧭 课程作业总索引|课程作业总索引]] HW01 行）；状态空间语言也是 [[卡尔曼滤波KalmanFilter]]（对偶问题）与观测器设计的共同语法。
- **实际应用场景**：倒立摆/双足平衡（HW01）、无人机姿态与轨迹控制、车辆横向控制（PythonRobotics `lqr_steering_control.py`）、机械臂关节空间控制（HW05）、航天器姿轨控——凡"模型可写 + 指标可量化"之处。
- **高频题型/任务**：写状态空间方程；判能控性（rank 条件）；解 ARE 求 $P$ 与 $K$（手算 2 阶）；解释 Q/R 权重的物理含义；Bryson 规则初始化；与 PID 对比选型。

---
## 3. 学它之前需要哪些前置知识？

1. **[[PID控制器与状态空间法]]**：状态空间定义 $\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}$、可控性矩阵 $\mathcal{C} = [B, AB, \dots, A^{n-1}B]$、极点配置——本节在其上叠加"最优性"。
2. **线性代数**：矩阵特征值、正定/半正定矩阵、二次型 $\mathbf{x}^T Q \mathbf{x}$、矩阵求逆——ARE 的解与稳定性判读全靠它们。
3. **移动机器人运动学 / 车辆模型**：LQR 应用的被控对象（如自行车模型线性化），HW01 倒立摆模型也属此类。

---
## 4. 用直觉语言解释它

> «状态空间就是把系统"拍成一张全景照片"：$\mathbf{x}$ 是所有内部状态（位置、速度、角度……），$A$ 是"状态自己怎么演化"，$B$ 是"控制力从哪个口子灌进来"。LQR 则像"请了一位会算账的教练"：你告诉它"状态偏离 1 单位算 Q 分痛，用力 1 单位算 R 分累"（Q/R 权重），它就把"这一辈子（0 到 ∞）总分最低"的控制律一次算出来——不是试出来的，是解方程解出来的。Riccati 方程就是这个"算总账"的结算公式。"»

- **直觉类比/几何图像**：$J$ 是"状态偏离 + 控制代价"的加权累计账单；$P$ 是"未来代价的预估值"（值函数），Riccati 方程让这个预估值自洽。
- **为什么很自然**：把"好控制"翻译成"二次型最小"，二次型有光滑凸性、可解析求导，最优解自然落成线性反馈 $\mathbf{u} = -K\mathbf{x}$——线性系统 + 二次代价 = 线性最优反馈，这是数学给工程的白送礼物。
- **一句话直觉本质**：**用状态空间把系统写清楚，用二次型把"好"定义清楚，再用 Riccati 方程一次性算出全局最优的线性反馈增益——调参从试凑变成设权重。**

---
## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **状态空间模型**：用一阶向量微分方程描述系统：$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}$，输出 $\mathbf{y} = C\mathbf{x} + D\mathbf{u}$（LTI 时 $A,B,C,D$ 为常数矩阵）。
- **能控性**：若可控性矩阵 $\mathcal{C} = [B,\ AB,\ \dots,\ A^{n-1}B]$ 满秩（$\text{rank}\,\mathcal{C} = n$），则系统能控——存在状态反馈把任意初态在有限时间内拉到原点。
- **LQR（线性二次型调节器）**：求反馈律 $\mathbf{u} = -K\mathbf{x}$ 使无穷时域二次型目标 $J$ 最小；最优 $K$ 由代数 Riccati 方程（ARE）给出。

### 2. 核心公式
状态空间与 LQR 目标：
$$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}, \qquad J = \int_0^\infty \big(\mathbf{x}^T Q \mathbf{x} + \mathbf{u}^T R \mathbf{u}\big)\, dt$$

代数 Riccati 方程（ARE）与最优增益：
$$A^T P + P A - P B R^{-1} B^T P + Q = 0, \qquad K = R^{-1} B^T P$$
（$P = P^T \succeq 0$ 为 ARE 的唯一半正定解；闭环 $\dot{\mathbf{x}} = (A - BK)\mathbf{x}$ 渐近稳定。）

Bryson 调参规则（初值）：$Q = \text{diag}\big(1/x_{i,\max}^2\big),\quad R = \text{diag}\big(1/u_{j,\max}^2\big)$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathbf{x}$ | 状态向量 | $\mathbb{R}^n$ | 如 $[p, v, \theta, \dot\theta]^T$ |
| $\mathbf{u}$ | 控制输入 | $\mathbb{R}^m$ | 如力矩、前轮转角 |
| $A, B$ | 系统矩阵 / 输入矩阵 | $\mathbb{R}^{n\times n}$, $\mathbb{R}^{n\times m}$ | 由物理模型线性化得到 |
| $Q$ | 状态代价权重 | 半正定 $n\times n$ | $Q_{ii}$ 越大，$x_i$ 越快被压回 |
| $R$ | 控制代价权重 | 正定 $m\times m$ | $R$ 越大，控制越省力/越保守 |
| $P$ | ARE 解（值函数矩阵） | 对称半正定 | 表征"未来代价" |
| $K$ | 最优反馈增益 | $\mathbb{R}^{m\times n}$ | $\mathbf{u} = -K\mathbf{x}$ |

### 4. 常见变体与适用条件
- **变体**：有限时域 LQR（$J$ 积分到 $T$，Riccati 微分方程）、LQI（加积分项消除稳态误差）、输出加权 LQR、离散时间 LQR（$P = A^T P A - \cdots$ 离散 ARE）、轨迹跟踪 LQR（时变参考，见 HW01）。
- **适用条件**：系统能控（否则无解或部分状态不可达）；模型 $(A,B)$ 足够准确（LQR 是模型依赖设计，模型错则增益错）；代价可写成二次型。
- **限制条件**：线性系统假设（非线性需在工作点线性化，如倒立摆、自行车模型）；无硬约束处理（$\mathbf{u}$ 饱和只能事后限幅；要显式处理约束需升级为 MPC）。

## 6. 推导思路和思想来源

- **最初困难**：多变量系统用传递函数/PID 无法系统化设计；"最优"缺乏数学定义，调参靠经验。
- **直接方法局限**：极点配置能任意放闭环极点，但"极点放哪最优"没有答案；而且极点配置不直接惩罚控制能量。
- **关键"转念"**：**把"控制得好"翻译成二次型目标的最小化**——状态偏离 $x_i^2$、控制用力 $u_j^2$ 都是凸的、可加的，加权求和后"最优"有了精确定义；再用动态规划（Hamilton-Jacobi-Bellman）的思想：假设"从任意状态出发的剩余最优代价"是二次型 $\mathbf{x}^T P \mathbf{x}$，代入最优性条件，二次型系数必须满足 ARE——**一个方程同时给出值函数 $P$ 和最优反馈 $K$**。
- **推导主线与动机**：HJB 方程 $0 = \min_u \big(\mathbf{x}^T Q \mathbf{x} + \mathbf{u}^T R \mathbf{u} + \nabla V \cdot (A\mathbf{x}+B\mathbf{u})\big)$，令 $V = \mathbf{x}^T P \mathbf{x}$；对 $\mathbf{u}$ 求极小得 $\mathbf{u}^* = -R^{-1}B^T P \mathbf{x}$（即 $K = R^{-1}B^T P$）；代回整理即得 ARE。线性系统 + 二次代价 ⇒ 值函数二次 ⇒ 最优反馈线性——自洽闭环。
- **为什么自然得到此结论**：因为二次型是"距离"的自然度量（能量意义），凸性保证全局最优唯一；线性反馈是二次值函数的自然梯度方向——数学结构决定了答案形态，不需要人为假设。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：双积分系统 $A = \begin{bmatrix}0&1\\0&0\end{bmatrix},\ B = \begin{bmatrix}0\\1\end{bmatrix}$（如无摩擦小车，状态 $x_1$ 位置、$x_2$ 速度，输入为力），取 $Q = I_2,\ R = 1$。求 $P$ 与 $K$，并验证闭环稳定。
- **解题思路与关键步骤**：设 $P = \begin{bmatrix}p_{11}&p_{12}\\p_{12}&p_{22}\end{bmatrix}$（对称），代入 ARE $A^T P + PA - PBR^{-1}B^T P + Q = 0$，得三个标量方程：
  $(1,1): -p_{12}^2 + 1 = 0 \Rightarrow p_{12}=1$；$(1,2): p_{11} - p_{12}p_{22} = 0$；$(2,2): 2p_{12} - p_{22}^2 + 1 = 0 \Rightarrow p_{22} = \sqrt{3}$，故 $p_{11} = p_{22} = \sqrt{3}$。
- **最终答案**：$P = \begin{bmatrix}\sqrt3&1\\1&\sqrt3\end{bmatrix}$，$K = R^{-1}B^T P = [1,\ \sqrt3]$，即 $\mathbf{u} = -x_1 - \sqrt3\, x_2$。闭环 $A - BK = \begin{bmatrix}0&1\\-1&-\sqrt3\end{bmatrix}$，特征方程 $\lambda^2 + \sqrt3\,\lambda + 1 = 0$，特征值 $\lambda = (-\sqrt3 \pm i)/2$，实部 $-\sqrt3/2 < 0$ ——渐近稳定 ✓。
- **易错点**：忘记 $P$ 的对称性（少一个未知数会多算）；ARE 中 $PBR^{-1}B^T P$ 的符号是**减号**（来自最优性条件），写成加号会得到发散的"解"。
- **🤔 追问**：若 $Q = \text{diag}(10, 1)$（位置权重放大 10 倍），$K$ 会怎么变？——$p_{12} = \sqrt{10}$，$K = [\sqrt{10},\ \sqrt{1+2\sqrt{10}}] \approx [3.16, 2.86]$：位置增益显著增大，位置收敛更快、但用力更猛——这就是"Q 大 = 更急"的数值证据。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：判断系统 $A = \begin{bmatrix}0&1\\0&0\end{bmatrix},\ B = \begin{bmatrix}1\\0\end{bmatrix}$ 能否用 LQR 设计？若能，说明闭环能压住哪些状态；若不能，为什么？
  解：可控性矩阵 $\mathcal{C} = [B, AB] = \begin{bmatrix}1&0\\0&1\end{bmatrix}$，$\text{rank} = 2 = n$ ——能控，LQR 可行。但注意 $B$ 只直接作用于 $x_1$（位置通道）：输入力直接改变位置、间接改变速度——二阶系统仍然能控（速度由位置积分而来）。**关键推理**：能控性看的是 $(A,B)$ 整体能否"通过输入到达所有状态"，不是看 $B$ 有没有直接连到每个状态；若换 $A = \begin{bmatrix}0&0\\0&1\end{bmatrix},\ B = \begin{bmatrix}0\\1\end{bmatrix}$（两个解耦子系统，第二个不可控），$\text{rank}\,\mathcal{C} = 1 < 2$，LQR 无解——ARE 不存在半正定解。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW01 阶梯 L1-L2 的完整落地：倒立摆线性化得 $(A,B)$，设定 $Q = \text{diag}(q_\theta, q_{\dot\theta}, q_x, q_{\dot x})$、$R = [r]$（Bryson 规则起步：$q_\theta = 1/\theta_{\max}^2$），用 `scipy.linalg.solve_continuous_are` 解 ARE 得 $K$，`np.linalg.eigvals(A - B@K)` 验证实部全负（即 HW01 说明书中的 pytest 断言）。PythonRobotics `lqr_steering_control.py` 则是车辆横向 LQR 的官方对照：把自行车模型误差动力学线性化 + LQR 求横向增益，输出"转向角 vs 时间"曲线——HW01 的自写实现须在同一场景下与之对齐。

## 8. 常见误区和易混概念

### 误区 1：以为"Q/R 随便设，反正都能稳定"
- **错误直觉**：LQR 保证稳定，权重随便填个单位阵就行。
- **为什么错**：$Q,R$ 直接编码控制目标——$Q$ 里把不重要的状态权重设大，系统会把力气浪费在无关状态上；$R$ 过小则控制剧烈（饱和/磨损），$R$ 过大则收敛极慢。单位阵只是"无信息先验"，不是默认最优。
- **正确理解**：用 Bryson 规则按"物理可接受的最大偏离/最大用力"归一化权重起步，再按"收敛速度 vs 控制幅度"的权衡微调——这就是 HW01 要求做 Q/R 敏感性分析的原因。

### 误区 2：把"能控"与"能稳定"混为一谈，或忽略能控性直接解 ARE
- **错误直觉**：只要 ARE 能解出某个 $P$，LQR 就有效。
- **为什么错**：不可控系统 ARE 可能无半正定解（或解出的 $K$ 只稳定可控部分）；数值求解器遇到病态问题会返回垃圾结果。
- **正确理解**：先验 $\text{rank}\,\mathcal{C} = n$，再解 ARE，最后验 $\text{eig}(A-BK)$ 实部——三步缺一不可（HW01 的 pytest 正是按这个顺序断言）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 本概念（LQR） | 模型 + 二次型最优 | 自动给出全局最优线性反馈；需能控线性模型 | 倒立摆、车辆横向、机械臂关节 |
| PID | 无模型误差反馈 | 试凑 3 增益；SISO 为主；无"最优"定义 | 温控、电机调速（见 [[PID控制器与状态空间法]]） |
| 极点配置 | 任意放极点 | 不给"最优"标准，不惩罚控制能量 | 需要指定动态的教学/工程场景 |
| MPC | 约束 + 滚动预测 | LQR + 硬约束 + 有限时域滚动优化（HW01 L3） | 大曲率/强约束轨迹跟踪 |

#### 1. 把 $Q$ 的对角元 $Q_{11}$ 调大（其余不变），闭环行为会怎样变化？
> [!question]- 答案解析
> - **答案**：$x_1$ 被更重地惩罚 → 对应的反馈增益 $K_{1}$ 增大 → $x_1$ 收敛更快（代价是控制输入 $u$ 更大、可能触发饱和/振荡）。
> - **解析**：Q 编码"状态偏离的痛感"，R 编码"用力过度的痛感"；两者比值 $Q/R$ 决定激进 vs 保守。
> - **易错原因**：以为 Q 只影响稳定性——它影响的是"最优权衡点"，稳定性由 ARE 解的存在性保证。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 双积分系统 $A = \begin{bmatrix}0&1\\0&0\end{bmatrix}, B = \begin{bmatrix}0\\1\end{bmatrix}$，$Q = I_2$，$R = 1$。求 $K$。
> [!question]- 答案解析
> - **答案**：$K = [1,\ \sqrt3]$。
> - **解析**：设 $P$ 对称，ARE 得 $p_{12}=1,\ p_{22}=\sqrt3,\ p_{11}=\sqrt3$；$K = R^{-1}B^T P = [p_{12}, p_{22}] = [1, \sqrt3]$。
> - **易错原因**：ARE 中 $PBR^{-1}B^T P$ 是减号；忘记 $B^T P$ 是行向量。

#### 3. 系统能控性矩阵 $\text{rank}\,\mathcal{C} = n$ 是 LQR 可设计的什么条件？若不满足会怎样？
> [!question]- 答案解析
> - **答案**：必要条件（也是充分条件之一）；不满足时 ARE 不存在半正定解，LQR 设计失败——不可控子空间无法被任何反馈改变。
> - **解析**：先验能控性、再解 ARE、最后验闭环特征值，三步是 HW01 自动化测试的固定顺序。
> - **易错原因**：跳过能控性检查直接调 `solve_continuous_are`，得到无意义的数值解。

#### 4. 用 Bryson 规则给倒立摆设初始权重：角度最大可接受 $30^\circ$、控制力矩最大 $2$ N·m。写出 $Q, R$ 初值。
> [!question]- 答案解析
> - **答案**：$q_\theta = 1/(30^\circ)^2 = 1/(\pi/6)^2 \approx 3.65$（rad⁻²），$r = 1/2^2 = 0.25$（N·m⁻²），$Q = \text{diag}(q_\theta, q_{\dot\theta}, \dots)$，$R = [0.25]$。
> - **解析**：Bryson 规则让不同量纲的状态/输入在目标函数里可比；之后按仿真微调（收敛慢 → 放大 Q 或缩小 R）。
> - **易错原因**：角度用度数代入（必须转弧度）；忘记这是初值、仍需敏感性分析微调。

#### 5. 从 HJB 方程出发，推导 LQR 的最优反馈 $u^* = -R^{-1}B^T P x$ 与 ARE。
> [!question]- 答案解析
> - **答案**：HJB：$0 = \min_u\{x^T Q x + u^T R u + \nabla V^T (Ax + Bu)\}$。设值函数 $V = x^T P x$（$\nabla V = 2Px$），对 $u$ 求极小：$2Ru + 2B^T P x = 0 \Rightarrow u^* = -R^{-1}B^T P x$（即 $K = R^{-1}B^T P$）。代回 HJB：$x^T Q x + x^T P B R^{-1} B^T P x + 2x^T P A x = 0$，对任意 $x$ 成立 ⇒ $A^T P + PA - PBR^{-1}B^T P + Q = 0$（ARE）。
> - **解析**：二次值函数假设 + 二次型凸性使"猜测-验证"闭合；这是"线性系统 + 二次代价 ⇒ 线性最优反馈"的完整证明主线。
> - **易错原因**：漏掉 $\nabla V$ 的因子 2 或符号错误；不说明 $P$ 对称半正定与闭环稳定性的联系。
> - **Obsidian 标签建议**：`#自测题/较难`
