# 增益调度

## 0. 为什么学它

车辆/飞机等系统的动态随工作点（车速、高度）大幅变化，单一 LQR 不够。**增益调度**对多个工作点分别设计控制器，运行时按工作点"插值切换"增益——工程上处理变参数系统的实用方案（车辆横向控制的 $v_x$ 调度）。

## 1. 核心方法

1. **选调度变量**（如车速 $v_x$）；
2. 在多个工作点（$v_x=v_1,v_2,\dots$）线性化 + 设计 LQR/极点配置 → 增益 $K(v_i)$；
3. **运行时调度**：按当前 $v_x$ 插值/切换 $K(v_x)$；
4. 保证切换平滑（防抖振）与各点稳定性。

**性质**：每个局部点是稳定的，但**整体稳定性需验证**（调度变量变化率限制；LPV/积分二次约束等严格方法）。

## 2. 最小可手算例子（车辆横向）

**题目**：横向 LQR 增益随车速 $v_x$ 变化，如何调度？

**解**：$A(v_x)$ 含 $v_x$（见 [[车辆误差模型]]），在不同 $v_x$（如 10/20/40 m/s）分别解 ARE 得 $K(v_x)$；运行时由速度表插值 $K$。低速增益大（灵敏），高速增益小（稳定裕度）——与直觉一致 ✓。

**易错点**：调度变量须缓慢变化；插值点间距要合适；稳定性验证不能省。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 局部稳定=全局稳定 | 需整体验证（调度速率约束） |
| 增益硬切换 | 应平滑插值防抖振 |
| 调度变量任意选 | 选主导影响动态的参数（如 $v_x$） |
