# LQR调参

## 0. 为什么学它

LQR 的"旋钮"是权重 $Q,R$——但 $Q,R$ 没有直觉含义。**LQR 调参**给出从物理量级出发的系统化流程（Bryson → 仿真 → 微调），让"调权重"代替"拍极点"。

## 1. 调参流程

1. **Bryson 初值**：$Q_{ii}=1/x_{i,max}^2$，$R_{jj}=1/u_{j,max}^2$（由物理量级归一化）；
2. **仿真验证**：看响应（超调/调节时间/控制量）；
3. **定向调整**：
   - 太慢 → 增大对应 $Q_{ii}$；
   - 控制饱和/输入过大 → 增大 $R$；
   - 某状态偏离大 → 增大该状态 $Q_{ii}$；
4. **保持相对比例**：同乘常数不改变 $K$，只调**比值**。

**经验**：$Q$ 对角通常先设，交叉项少用；$R$ 从保守（大）开始。

## 2. 最小可手算例子（调整决策）

**题目**：LQR 响应超调大且控制量小，如何调 $Q,R$？

**解**：超调大 → 增大状态权重 $Q$（让状态更快归零，等效更强反馈）；控制量小 → 减小 $R$。两者同方向：$\uparrow Q$ 或 $\downarrow R$（本质是同一比值方向）。

**易错点**：只调一个权重不看比值；忘记检查执行器饱和。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| $Q,R$ 绝对大小重要 | 比值决定 $K$ |
| 权重越多越好 | 保持简单，对角 $Q$ 通常够用 |
| 调完不仿真 | 必须闭环仿真验证 |
