# 时延来源

## 0. 为什么学它

纵向控制链路中时延无处不在：传感器处理、通信、执行器响应。**时延来源**盘点各环节延迟，是理解"为什么不能把速度环调太快"与设计补偿的前提。

## 1. 核心时延来源

| 环节 | 时延 | 典型值 |
|:---|:---|:---|
| 传感器（雷达/相机） | 处理/周期延迟 | 50~200 ms |
| 估计/滤波 | 滤波器滞后 | 10~100 ms |
| 通信（V2V/CAN） | 传输/调度 | 10~100 ms |
| 发动机/制动执行 | 建压/节气门 | 100~300 ms |
| 控制周期 | 采样/计算 | 10~50 ms |

**影响**：时延使相位滞后 $-\omega T$（频域），限制闭环带宽（$T$ 大 → 带宽低），严重时不稳定（见 [[时延稳定性]]）。

## 2. 最小可手算例子（概念验证）

**题目**：总时延 $T=0.2$ s，带宽上限约多少？

**解**：经验 $\omega_c\lesssim1/(2T)=2.5$ rad/s（留裕量）；再大相位滞后导致振荡 ✓。

**易错点**：时延在采样环节叠加；不同环节时延需统一到控制周期。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 时延可忽略 | 纵向控制中显著 |
| 只看执行器时延 | 传感器/估计同样贡献 |
| 时延固定 | 随工况/负载变化 |
