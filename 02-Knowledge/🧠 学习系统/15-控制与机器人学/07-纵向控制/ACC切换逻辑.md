# ACC切换逻辑

## 0. 为什么学它

ACC 在**速度模式 ↔ 跟随模式**间切换，切换时机与平滑性决定安全与舒适。**ACC 切换逻辑**用状态机 + 滞回管理切换，避免边界抖动与突加/突减。

## 1. 核心状态机

```
          检测前车且 d < d_switch
  速度模式 ─────────────────────► 跟随模式
      ◄─────────────────────────
   前车消失 或 d > d_release（滞回）
```

**切换条件**：
- → 跟随：前车存在且 $d<d_{switch}$（如 150m）；
- → 速度：前车消失 或 $d>d_{release}$（滞回，$d_{release}>d_{switch}$ 防抖）。

**平滑措施**：切换时目标连续化（速度/间距目标插值）；加速度指令限幅（舒适/安全）。

## 2. 最小可手算例子（概念验证）

**题目**：为什么 $d_{release}>d_{switch}$？

**解**：若无滞回，前车在阈值附近时 ACC 会频繁"跟/巡航"切换（抖振）→ 油门刹车抖动；滞回（如 $d_{switch}=150$，$d_{release}=170$ m）保证稳定 ✓。

**易错点**：无滞回抖振；切换瞬间目标跳变（需平滑）。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 单阈值切换 | 需滞回防抖 |
| 切换目标硬跳 | 需插值平滑 |
| 忽略安全 | 切跟随需制动能力核查 |
