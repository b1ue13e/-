# 发动机模型

## 0. 为什么学它

发动机扭矩不能瞬变：进气、燃烧、飞轮有**动态滞后**。**发动机模型**描述"节气门/油门指令 → 扭矩"的动态（常近似一阶惯性 + 时延），是纵向控制设计中不可忽略的执行器环节。

## 1. 核心模型

**扭矩输出**（简化一阶惯性 + 时延）：

$$T_e(s)=\frac{K_e}{\tau_e s+1}\,e^{-T_d s}\,T_{cmd}(s),$$

- $K_e$：静态增益（油门→扭矩）；
- $\tau_e$：时间常数（0.1~0.3 s）；
- $T_d$：时延（节气门/燃烧，0.1~0.3 s）。

**稳态特性**：扭矩随转速与油门变化（MAP 图）；峰值扭矩在中转速。

**控制意义**：滞后限制了带宽 → 速度环增益不能过大；时延需补偿（见 [[时延来源]]、[[Smith预估器]]）。

## 2. 最小可手算例子（概念验证）

**题目**：$\tau_e=0.2,\ T_d=0.2$ s，速度环带宽应限制多少？

**解**：执行器带宽 $\approx1/\tau_e=5$ rad/s → 速度环带宽取 $\lesssim2$ rad/s（留 2~3 倍裕量），且时延使相位滞后需补偿 ✓。

**易错点**：忽略执行器动态直接设计快速度环 → 振荡。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 发动机扭矩瞬变 | 有惯性+时延动态 |
| 一阶近似永远够 | 大油门/急加速需非线性 MAP |
| 忽略时延 | 时延限制带宽并引起滞后 |
