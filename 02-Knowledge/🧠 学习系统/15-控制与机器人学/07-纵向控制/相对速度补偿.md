# 相对速度补偿

## 0. 为什么学它

只控间距误差还不够：前车速度快时即使间距偏大也应加速跟上（消除速度差）。**相对速度补偿**加入 $e_v=v_f-v$ 项，让 ACC 同时收敛间距与速度——跟车控制的"阻尼项"。

## 1. 核心方法

**ACC 控制律（含相对速度补偿）**：

$$a_{des}=K_d e_d + K_v e_v + a_f^{ff},\qquad e_v=v_f-v,$$

- $K_d e_d$：间距项（拉回时距）；
- $K_v e_v$：相对速度项（消除速度差，提供阻尼）；
- $a_f^{ff}$：前车加速度前馈（可测时）。

**作用**：$K_v$ 项防止"间距到位但速度不匹配"的过冲/振荡——类似 PD 中的 D。

## 2. 最小可手算例子（决策练习）

**题目**：间距恰好等于期望（$e_d=0$）但前车更快（$e_v>0$），ACC 做什么？

**解**：$e_d=0$ 但 $e_v>0$ → $a_{des}=K_v e_v>0$（加速）→ 跟上速度，间距随后增大 → $e_d$ 项再协调 → 收敛到"同速 + 时距" ✓。

**易错点**：$e_v$ 符号（前车快为正）；噪声放大需滤波。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 只控间距 | 需双误差（间距+速度） |
| $K_v$ 可有可无 | 是阻尼，防振荡 |
| 前车加速度直接用 | 需估计/滤波 |
