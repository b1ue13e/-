# 🗺️ 控制与机器人学学习路径

> 本页是「15-控制与机器人学」的唯一学习者主入口：给出**课程目标、最低前置、来源、阶段顺序、每阶段学习目标、知识卡、作业、验收标准与阶段衔接**。导航固定为三级：本路径 → 阶段 MOC → 知识卡/作业。

## 1. 课程目标

掌握从**动态系统建模**到**现代控制与机器人应用**的完整能力链：

- 用微分方程 / 拉普拉斯变换 / 状态空间描述线性与非线性动态系统；
- 用经典控制（时域、频域、PID、根轨迹）与现代控制（能控能观、状态反馈、LQR）设计控制器；
- 建立机械臂（DH、Jacobian、动力学）与车辆（自行车模型、横向/纵向动力学）模型；
- 实现路径规划（A*/RRT）与轨迹跟踪（Pure Pursuit、Stanley、MPC）；
- 用卡尔曼滤波 / EKF / 粒子滤波做状态估计；
- 在仿真环境（PythonRobotics / pydrake）中闭环验证，形成"建模 → 设计 → 仿真 → 验收"工程闭环。

## 2. 最低前置与诊断

- 进入课程前完成 [[00-前置知识/🧭 控制与机器人学-前置知识|前置知识 MOC]] 的诊断（线性代数、ODE 概念、Python/NumPy、概率基础），未达标者按 P1→P4 补学。
- 前置卡复用 09-高等代数、22-概率论与数理统计、01-社交网络挖掘（Python 诊断）的高质量卡，不重复建卡。

## 3. 来源与 Spine（单源充分性判断）

| 角色 | 来源 | 用途 / 边界 |
|:---|:---|:---|
| **主 Spine** | *Modern Robotics*（Lynch & Park，官方免费 preprint + MIT 代码仓库） | 刚体运动、运动学、动力学、规划的严格形式化主线（阶段 2、5、8） |
| **主 Spine（实践）** | [PythonRobotics](https://github.com/AtsushiSakai/PythonRobotics)（MIT） | 定位 / 规划 / 跟踪 / 控制四大模块官方 demo，作业验收基准 |
| **Co-Spine** | *Modern Control Engineering*（Ogata） | 经典控制主线（阶段 1、4）的时域/频域/PID/根轨迹 |
| **Supplement** | MIT 6.832 Underactuated（Drake，开放讲义） | LQR / MPC 理论补充（阶段 5、9） |
| **Supplement** | *Probabilistic Robotics*（Thrun 等） | 状态估计主线（阶段 10）KF/EKF/UKF/PF 理论依据 |

> 单源充分性判断：Modern Robotics 覆盖机械臂主线但缺少经典控制时域/频域与车辆横向/纵向动力学实践，故采用 Modern Robotics + PythonRobotics 双主 Spine，并以 Ogata / Underactuated / Probabilistic Robotics 补理论缺口。每本来源的角色、版本、许可与访问日期记录于 [[📚 教材挂载索引]]。

## 5. 阶段衔接与复习节点

- **阶段进入条件**：完成上一阶段验收（作业达标 + 检查点通过）；首次进入前完成前置诊断。
- **复习节点**：每完成 2 个阶段，回到错题入口 [[控制与机器人学错题漏洞入口]] 复盘薄弱点；阶段 MOC 内设检查点（见各阶段 MOC）。
- **复盘闭环**：作业完成后将失败案例与参数结论写入 04-Review 或对应知识卡主动回忆区。

在统一仿真中串联**定位 → 规划 → 跟踪 → 控制**：默认自动驾驶栈（GPS+里程计 → A* → Pure Pursuit/MPC → 执行器），机械臂方向可选。最低交付：问题定义、可复现输入、朴素基线、核心方法、统一评估、失败案例、限制说明与复现步骤；Rubric 见 [[📚 教材挂载索引]] 开源自学区。
