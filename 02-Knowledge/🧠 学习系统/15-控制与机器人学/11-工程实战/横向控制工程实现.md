# 横向控制工程实现

## 0. 为什么学它

阶段 6 学了 Pure Pursuit / Stanley / LQR 横向控制的理论，本卡解决**落地三问**：预瞄点怎么搜索、转向角公式怎么写进仿真、怎么用"八字绕环/正弦路径"验证并报告误差。它是阶段作业-06（纯跟踪与 Stanley 横向控制）的工程实现总纲。

## 1. 两个核心算法的实现要点

### Pure Pursuit（PP）
1. 在参考路径上找距车辆前视距离 $L_d$ 的**预瞄点**；
2. 计算车辆到预瞄点的转角 $\delta$：

$$
\delta = \arctan\left(\frac{2 L \sin\alpha}{L_d}\right)
$$

其中 $L$ 为轴距，$\alpha$ 为航向与预瞄方向夹角。

### Stanley
1. 计算横向偏差 $e_{fa}$（前轴到路径最近点）；
2. 转向角 = 航向误差项 + 横向偏差项：

$$
\delta = \psi_e + \arctan\left(\frac{k \, e_{fa}}{v}\right)
$$

## 2. 最小可运行例子（PP 核心循环）

```python
import numpy as np

def pure_pursuit_steer(x, y, yaw, cx, cy, Ld=2.0, L=2.5):
    """返回转向角 delta（rad）"""
    # 1. 找预瞄点：路径上距 (x,y) 约 Ld 的点
    d = np.hypot(cx - x, cy - y)
    idx = np.argmin(np.abs(d - Ld))      # 最近于前视距离的路径点
    # 2. 计算预瞄方向角
    alpha = np.arctan2(cy[idx] - y, cx[idx] - x) - yaw
    # 3. 几何转角
    delta = np.arctan2(2.0 * L * np.sin(alpha), Ld)
    return delta
```

**验证**：跑正弦/八字路径，记录横向误差 RMS——`PythonRobotics/pure_pursuit.py` 是完整参考（MIT）。

## 3. 工程验证流程（阶段作业-06 口径）

1. 固定场景：正弦路径或八字绕环，固定车速；
2. 指标：横向误差 RMS/Max、到达时间、稳定性；
3. **参数敏感性**：扫 PP 前视距离 $L_d \in \{1,2,4,8\}$、Stanley $k \in \{0.5, 1, 2\}$，画"参数 → RMS"曲线；
4. 对比 PP vs Stanley 在低速/高速的表现差异并给结论。

## 4. 常见坑

| 坑 | 对策 |
|:---|:---|
| 前视距离太小 → 振荡；太大 → 切弯 | $L_d$ 随速度自适应（$L_d = k v$） |
| 路径点稀疏 → 预瞄点跳变 | 插值路径 / 平滑路径点 |
| Stanley 低速 $\arctan$ 分母小 → 抖动 | 加最小速度保护（$v + \epsilon$） |
| 用同一场景比较才公平 | 固定随机种子、固定路径与车速 |
