# 关节空间控制实现

## 0. 为什么学它

机械臂控制的两种思路：**关节空间**（每个关节独立控制到目标角）与**笛卡尔空间**（末端沿直线/圆弧运动）。关节空间是基础——"每个关节一个 PID"是最简单可靠的起点，配合 PTP（点到点）轨迹规划实现"从 A 点平滑转到 B 点"。本卡解决"关节 PID 怎么调、PTP 轨迹怎么规划、代码怎么组织"。

## 1. 关节 PID 控制

每个关节独立反馈控制：

$$
\tau_j = K_p (q_j^d - q_j) + K_d (\dot{q}_j^d - \dot{q}_j) + K_i \int (q_j^d - q_j)\, dt
$$

- $q_j^d$：目标关节角（来自轨迹规划）；
- 调参原则：先 $K_p$ 后 $K_d$，$K_i$ 用于消稳态误差（见 [[CC调参|CC调参]]）。

## 2. PTP 轨迹规划

关节空间点到点，用三次/五次多项式保证角速度/角加速度连续：

三次多项式 $q(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3$，由边界条件（$q(0)=q_0, q(T)=q_f, \dot q(0)=\dot q(T)=0$）解出系数：

$$
a_2 = \frac{3(q_f - q_0)}{T^2}, \qquad a_3 = -\frac{2(q_f - q_0)}{T^3}
$$

## 3. 最小可手算例子

**题目**：关节从 $q_0=0$ 转到 $q_f=90^\circ$（$\pi/2$ rad），$T=2$ s。求三次多项式系数与 $t=1$ s 时的角位置。

**解**：$q_f - q_0 = \pi/2$：

$$
a_2 = \frac{3\pi/2}{4} = 1.178, \qquad a_3 = -\frac{2\pi/2}{8} = -0.393
$$

$$
q(1) = 0 + 0 + 1.178 \times 1 + (-0.393) \times 1 = 0.785 \text{ rad} = 45^\circ
$$

**解读**：中点恰好 $45^\circ$，轨迹对称平滑——关节 PID 跟踪这条参考轨迹即可实现平滑转动。

## 4. 代码骨架（PyBullet）

```python
import pybullet as p

# 每步：从轨迹取目标角 → PID 算力矩 → 施加力矩
def step(q_d, q, q_dot, Kp, Kd):
    tau = Kp * (q_d - q) - Kd * q_dot   # 简化 PD（不含重力补偿）
    p.setJointMotorControlArray(
        robot, joint_indices, p.TORQUE_CONTROL, forces=[tau]*n_joints)
```

**注意**：简化 PD 会因重力下垂，工程上必须加**重力补偿**（见 [[计算力矩控制|计算力矩控制]]）。

## 5. 常见坑

| 坑 | 对策 |
|:---|:---|
| 不加重力补偿，关节下垂 | 先算 $\tau_g = G(q)$ 前馈补偿 |
| $K_d$ 过大 → 高频抖动 | 减小 $K_d$ 或增加关节滤波 |
| 轨迹阶数低 → 末端冲击 | 用五次多项式（加速度连续） |
| 直接设目标角跳变 | 必须过轨迹规划，不能一步到位 |
