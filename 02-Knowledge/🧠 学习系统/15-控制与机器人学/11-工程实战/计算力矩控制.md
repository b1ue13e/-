# 计算力矩控制

## 0. 为什么学它

关节 PID 对每个关节独立控制，但机械臂是**强耦合非线性系统**：一个关节运动产生的科氏力/离心力/重力会干扰其他关节。独立 PID 在低速小负载下够用，高速/大负载就失控。**计算力矩控制**把动力学模型前馈进控制律，把非线性耦合系统"精确线性化"成一组独立双积分器——机械臂控制的黄金标准，也是理解"模型在控制中的作用"的最佳范例。

## 1. 核心思想

机器人动力学：

$$
M(q)\ddot{q} + C(q,\dot{q})\dot{q} + G(q) = \tau
$$

计算力矩控制律（内环模型 + 外环 PD）：

$$
\tau = M(q)\underbrace{(\ddot{q}^d + K_d \dot{e} + K_p e)}_{a} + C(q,\dot{q})\dot{q} + G(q)
$$

代入动力学得闭环误差方程：

$$
\ddot{e} + K_d \dot{e} + K_p e = 0
$$

**非线性耦合被精确抵消，系统变成独立线性二阶系统**——这就是"计算力矩 = 反馈线性化"。

## 2. 最小可手算例子

**题目**：单连杆 $M(q) = 2$ kg·m²，$G(q) = 9.8\cos q$ N·m。目标 $q^d = \pi/2$，当前 $q = 1.4$ rad，$\dot q = 0$。取 $K_p = 100$，$K_d = 20$，求控制力矩。

**解**：$e = q^d - q = 0.571$，$a = 0 + 20 \times 0 + 100 \times 0.571 = 57.1$：

$$
\tau = 2 \times 57.1 + 9.8\cos(1.4) = 114.2 + 9.8 \times 0.170 = 114.2 + 1.67 = 115.87 \text{ N·m}
$$

**解读**：$9.8\cos q$ 项就是重力补偿（前馈），$114.2$ 是惯性驱动项（反馈）；两者相加——**模型前馈让外环 PD 面对的是"无重力、无耦合"的纯惯性系统**。

## 3. 与关节 PID 的对比

| 方面 | 关节 PID | 计算力矩 |
|:---|:---|:---|
| 模型使用 | 无（纯误差反馈） | 完整动力学 $M, C, G$ |
| 耦合处理 | 忽略（当作扰动） | 精确补偿 |
| 高速/大负载 | 性能下降 | 保持线性响应 |
| 依赖模型精度 | 低 | 高（模型误差 → 补偿失真） |

## 4. 常见坑

| 坑 | 对策 |
|:---|:---|
| 模型参数误差大 | 用辨识（摩擦/惯量标定）或自适应补偿 |
| $M(q)$ 求逆数值不稳 | 加阻尼（$M + \lambda I$）或 QR 分解 |
| 外环增益过大 → 激励未建模动态 | $K_p, K_d$ 按闭环带宽设计，留裕量 |
| 忽略摩擦 | 加摩擦补偿项 $\tau_f = F_c \text{sign}(\dot q) + F_v \dot q$ |
