# 劳斯判据

## 0. 为什么学它

判断系统稳定性需要知道特征方程的根是否都在左半平面。对三阶以上多项式直接求根很麻烦（或只能用数值法），而**劳斯判据**只用系数做一张表，就能回答"右半平面有几个根"——不求解，纯代数，还能指出不稳定的根数。

## 1. 核心思想

线性系统稳定 ⇔ 特征方程 $D(s)=a_n s^n+\cdots+a_0=0$ 的全部根实部为负。

**劳斯判据**：把系数排成劳斯表，若**第一列元素全部同号（都为正）**，则系统稳定；第一列符号变化的次数 = 右半平面根的个数。

## 2. 劳斯表构造算法

以 $D(s)=a_4s^4+a_3s^3+a_2s^2+a_1s+a_0$ 为例：

| $s^4$ | $a_4$ | $a_2$ | $a_0$ |
|:---|:---|:---|:---|
| $s^3$ | $a_3$ | $a_1$ | 0 |
| $s^2$ | $b_1=\dfrac{a_3a_2-a_4a_1}{a_3}$ | $b_2=\dfrac{a_3a_0-a_4\cdot0}{a_3}$ | 0 |
| $s^1$ | $c_1=\dfrac{b_1a_1-a_3b_2}{b_1}$ | 0 | 0 |
| $s^0$ | $d_1=\dfrac{c_1b_2-b_1\cdot0}{c_1}$ | 0 | 0 |

> 一般规则：每行由前两行的**交叉乘积差**生成：$b_1=\dfrac{a_3a_2-a_4a_1}{a_3}$，依此类推。

## 3. 特殊情况处理

| 情况 | 处理 |
|:---|:---|
| 第一列出现 0 | 用无穷小正数 $\epsilon$ 代替 0 继续计算 |
| 整行为 0 | 用上一行构造辅助多项式，对其求导后再填行 |

## 4. 最小可手算例子

**题目**：$D(s)=s^3+s^2+2s+24$，判断稳定性。

**劳斯表**：

| $s^3$ | 1 | 2 |
|:---|:---|:---|
| $s^2$ | 1 | 24 |
| $s^1$ | $\dfrac{1\cdot2-1\cdot24}{1}=-22$ | 0 |
| $s^0$ | 24 | 0 |

第一列符号：$+, +, -, +$ → 变化 2 次 → **2 个右半平面根，系统不稳定**。（特征根确实为 $-3,\ 1\pm j\sqrt7$，验证 ✓）

**易错点**：交叉乘积顺序写反；第一列出现 0 时直接当 0 除以会除零。

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 所有系数为正就判稳定 | 系数为正只是**必要条件**，不是充分条件 |
| 跳过劳斯表直接看根 | 三阶以上手工求根不可行，判据的意义就是避免求根 |
| 忽略整行为 0 的特殊情况 | 整行为 0 表示存在对称于原点的根，需辅助多项式处理 |

## 7. 检索练习（闭卷）

1. 写出劳斯判据的稳定条件；
2. 判断 $D(s)=s^4+2s^3+3s^2+4s+5$ 是否稳定；
3. 求 $D(s)=s^3+Ks^2+2s+1$ 的临界增益 $K$；
4. 说明第一列出现 0 的处理方法。

## 8. 通过标准

- 能构造三阶/四阶劳斯表；
- 能处理第一列为 0 与整行为 0 的特殊情况；
- 能由第一列符号变化数确定右半平面根数；
- 能求参数变化时的临界稳定条件。
