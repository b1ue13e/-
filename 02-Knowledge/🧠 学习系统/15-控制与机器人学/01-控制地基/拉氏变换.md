# 拉氏变换

## 0. 为什么学它

求解 ODE 需要积分和特征方程，遇到非齐次、分段输入（阶跃、斜坡、脉冲）时非常繁琐。拉氏变换把**微分方程变成代数方程**：微分变乘法、积分变除法、卷积变乘积，解完再逆变换回时域。它是经典控制全部方法的语言底座。

## 1. 核心定义

**单边拉普拉斯变换**（$t\ge 0$ 的信号）：

$$F(s) = \mathcal{L}\{f(t)\} = \int_0^\infty f(t)\, e^{-st}\, dt,\qquad s = \sigma + j\omega \in \mathbb{C}.$$

**存在条件**：$f(t)$ 在 $[0,\infty)$ 分段连续，且存在 $M, \alpha$ 使 $\lvert f(t) \rvert \le M e^{\alpha t}$（指数阶）。使积分收敛的 $\sigma$ 范围称为**收敛域（ROC）**。

| 符号 | 含义 | 备注 |
|:---|:---|:---|
| $s$ | 复频率变量 | 实部 $\sigma$ 决定衰减，虚部 $\omega$ 决定振荡 |
| $F(s)$ | 频域函数 | 复数函数 |
| $f(t)$ | 时域信号 | 通常 $t<0$ 时 $f(t)=0$ |

## 2. 常用变换对（务必默写）

| $f(t)$ | $F(s)$ |
|:---|:---|
| $\delta(t)$ 单位脉冲 | $1$ |
| $1(t)$ 单位阶跃 | $\dfrac{1}{s}$ |
| $t$ 斜坡 | $\dfrac{1}{s^2}$ |
| $e^{-at}$ | $\dfrac{1}{s+a}$ |
| $\sin(\omega t)$ | $\dfrac{\omega}{s^2+\omega^2}$ |
| $\cos(\omega t)$ | $\dfrac{s}{s^2+\omega^2}$ |
| $t\,e^{-at}$ | $\dfrac{1}{(s+a)^2}$ |

> 完整表见 [[变换对]]。

## 3. 核心性质（记忆要点）

| 性质 | 公式 | 用途 |
|:---|:---|:---|
| 线性 | $\mathcal{L}\{af+bg\}=aF+bG$ | 叠加 |
| 微分 | $\mathcal{L}\{\dot f\}=sF(s)-f(0^-)$ | **核心：微分变代数** |
| 二阶微分 | $\mathcal{L}\{\ddot f\}=s^2F(s)-sf(0^-)-\dot f(0^-)$ | 二阶系统 |
| 积分 | $\mathcal{L}\{\int_0^t f\,d\tau\}=\dfrac{F(s)}{s}$ | 积分环节 |
| 平移（时移） | $\mathcal{L}\{f(t-a)1(t-a)\}=e^{-as}F(s)$ | 时延 |
| 卷积 | $\mathcal{L}\{f*g\}=F(s)G(s)$ | 系统响应=输入×传递函数 |
| 初值 | $f(0^+)=\lim_{s\to\infty}sF(s)$ | 初值验证 |
| 终值 | $\lim_{t\to\infty}f(t)=\lim_{s\to 0}sF(s)$（需稳定） | 稳态误差 |

## 4. 最小可手算例子

**题目**：求 $\dot{x}+2x=4$（$x(0)=0$）的 $X(s)$ 并逆变换。

**步骤**：
1. 两边取变换：$sX(s)-x(0)+2X(s)=\dfrac{4}{s}$；
2. 代入 $x(0)=0$：$(s+2)X(s)=\dfrac{4}{s}$；
3. 解出 $X(s)=\dfrac{4}{s(s+2)}=\dfrac{2}{s}-\dfrac{2}{s+2}$（部分分式）；
4. 逆变换：$x(t)=2-2e^{-2t}$——与 ODE 卡结果一致 ✓。

**易错点**：
- 忘记初值项 $f(0^-)$；
- 部分分式系数算错（先通分验证）；
- 把 $e^{-at}$ 的变换对写成 $\frac{1}{s-a}$。

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 以为拉氏变换只适用于线性系统 | 定义本身对任意指数阶函数成立；线性系统的优势在于叠加与代数化 |
| 混淆"收敛域"与"极点" | 极点使 $F(s)$ 无穷大，ROC 是使积分收敛的 $\sigma$ 范围 |
| 终值定理无条件套用 | 仅当 $sF(s)$ 极点都在左半平面时成立，否则结果错误 |
