# BIBO稳定

## 0. 为什么学它

"稳定"是控制系统的第一要求——系统不稳定，一切性能指标都没有意义。**BIBO 稳定（有界输入有界输出）**是最直观的稳定性定义：给有界的输入，输出必须也有界。它把稳定性从哲学问题变成可检验的代数条件。

## 1. 核心定义

**BIBO 稳定**：对任意有界输入 $\lvert u(t)\rvert \le M_u < \infty$，输出有界 $\lvert y(t)\rvert \le M_y < \infty$。

**线性时不变系统的 BIBO 稳定判据**：所有极点（特征根）都在左半平面（实部 $<0$），等价于单位脉冲响应 $g(t)$ 绝对可积：

$$\int_0^\infty \lvert g(t)\rvert\, dt < \infty.$$

## 2. 为什么极点实部决定稳定性

脉冲响应由极点模态组成：$\mathcal{L}^{-1}\{\frac{1}{s+p}\}=e^{-pt}$。
- 极点 $p>0$（右半平面）→ $e^{-pt}$ 发散 → 不稳定；
- 极点 $p<0$ → 衰减 → 稳定；
- 极点 $p=0$（原点）或虚轴 → 等幅/常数 → 临界（BIBO 意义下不稳定）。

## 3. 最小可手算例子

**题目**：$G(s)=\dfrac{1}{s-2}$ 与 $G(s)=\dfrac{1}{s+2}$ 哪个 BIBO 稳定？

**解**：$G_1$ 极点 $s=2>0$ → 不稳定（$y(t)=e^{2t}$ 发散）；
$G_2$ 极点 $s=-2<0$ → BIBO 稳定（$y(t)=e^{-2t}$ 衰减）。

**易错点**：只数极点个数不看位置；忽略虚轴上极点（临界不稳定）。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 系统"看着平稳"就稳定 | 必须所有极点左半平面 |
| 零极点对消后判稳定 | 对消可能隐藏不稳定模态（内部不稳定） |
| 临界（虚轴极点）= 稳定 | BIBO 定义下虚轴极点为不稳定 |
