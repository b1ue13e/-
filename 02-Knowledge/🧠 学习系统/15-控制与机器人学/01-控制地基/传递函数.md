# 传递函数

## 0. 为什么学它

同一个物理系统（电机、液位、温度）可以用不同学科语言描述，但它们的输入-输出关系在频域里都能写成**传递函数** $G(s)$。有了它，系统的特性（快慢、振荡、稳定与否）全部可以从 $G(s)$ 的极零点读出，控制器设计也变成对 $G(s)$ 的"整形"。

## 1. 核心定义

对**零初始条件**的 LTI 系统，传递函数定义为输出与输入的拉氏变换之比：

$$G(s) = \frac{Y(s)}{U(s)} = \frac{b_m s^m + b_{m-1}s^{m-1} + \cdots + b_0}{a_n s^n + a_{n-1}s^{n-1} + \cdots + a_0},\qquad n \ge m.$$

**前提条件**：
1. 系统是**线性时不变（LTI）**；
2. 初始条件为零（否则输出含初值项，不能只用比值描述）；
3. $G(s)$ 只反映系统固有特性，与具体输入无关。

## 2. 从 ODE 得到传递函数（最小例子）

**系统**：$M\ddot{y} + c\dot{y} + ky = u(t)$（质量-弹簧-阻尼）。

1. 零初值下取拉氏变换：$(Ms^2 + cs + k)Y(s) = U(s)$；
2. 比值：$G(s)=\dfrac{Y(s)}{U(s)}=\dfrac{1}{Ms^2+cs+k}$。

**验证**：令 $M=1, c=2, k=1$，对单位阶跃输入，$Y(s)=\dfrac{1}{s(s^2+2s+1)}$，时域响应为临界阻尼上升——与直接解 ODE 一致。

## 3. 极点、零点与系统特性

- **极点**：$G(s)$ 分母根。决定响应形态：实部<0 衰减（稳定）、实部>0 发散（不稳定）、虚部决定振荡频率。
- **零点**：$G(s)$ 分子根。影响响应幅值分配，不改变稳定性。
- **增益**：$K = G(0)$（直流增益），决定稳态值。

> 极零点的系统分析见 [[零极点]]。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 把传递函数套用到非线性系统 | 传递函数只对 LTI 成立；非线性需局部线性化 |
| 忘记零初始条件假设 | 非零初值时输出包含初值响应项 |
| 分子分母可约分却直接约 | 零极点对消会丢失不可控/不可观模态（后续能控能观再讲） |
| 认为增益 $K$ 就是 $G(0)$ 与输入无关 | 直流增益只描述稳态比例，动态由极零点决定 |

## 6. 检索练习（闭卷）

1. 写出传递函数定义及其三个前提；
2. 由 $\ddot{y}+5\dot{y}+6y=2u$ 写出 $G(s)$ 与极点；
3. 说明极点实部符号与稳定性的关系；
4. 解释为什么 $G(s)$ 与输入无关。

## 7. 通过标准

- 能从 ODE 经零初值拉氏变换写出 $G(s)$；
- 能由 $G(s)$ 读极点、零点、直流增益；
- 能根据极点位置预判稳定性；
- 能说出传递函数的适用边界（LTI、零初值）。
