# 变换对

## 0. 为什么学它

实际做题不需要每次重算积分——常用信号的拉氏变换被整理成**变换对表**。记住这张表 = 把"时域↔频域"双向翻译的速度翻倍。本卡列出控制中最常用的一批变换对与记忆技巧。

## 1. 核心变换对表

| 时域 $f(t)$ ($t\ge0$) | 频域 $F(s)$ | 记忆技巧 |
|:---|:---|:---|
| $\delta(t)$ | $1$ | 极限最简 |
| $1(t)$ 阶跃 | $\dfrac{1}{s}$ | $\int \delta$ |
| $t$ | $\dfrac{1}{s^2}$ | 阶跃再积分 |
| $t^{n}$ | $\dfrac{n!}{s^{n+1}}$ | 归纳 |
| $e^{-at}$ | $\dfrac{1}{s+a}$ | 平移 $s$ |
| $t e^{-at}$ | $\dfrac{1}{(s+a)^2}$ | 对 $a$ 求导 |
| $\sin\omega t$ | $\dfrac{\omega}{s^2+\omega^2}$ | 分母和 |
| $\cos\omega t$ | $\dfrac{s}{s^2+\omega^2}$ | 分子 $s$ |
| $e^{-at}\sin\omega t$ | $\dfrac{\omega}{(s+a)^2+\omega^2}$ | 阻尼振荡 |
| $e^{-at}\cos\omega t$ | $\dfrac{s+a}{(s+a)^2+\omega^2}$ | 阻尼振荡 |

## 2. 记忆原理

- **指数族**：$e^{-at} \leftrightarrow \frac{1}{s+a}$ 是"母表"；对参数求导可得 $t e^{-at}$ 等。
- **振荡族**：$\sin/\cos \leftrightarrow$ 分母 $s^2+\omega^2$，分子分别是 $\omega$ / $s$。
- **阻尼振荡**：把 $\sin/\cos$ 的 $s$ 换成 $s+a$。
- **阶跃族**：$1/t/t^n$ 是 $\frac{1}{s}$ 的逐次积分。

## 3. 最小例子

**题目**：求 $\mathcal{L}\{3e^{-2t} + 2\sin(4t)\}$。

**解**：由线性 + 变换对：

$$\mathcal{L}\{3e^{-2t}\}=\frac{3}{s+2},\qquad \mathcal{L}\{2\sin4t\}=\frac{8}{s^2+16},$$

所以 $F(s)=\dfrac{3}{s+2}+\dfrac{8}{s^2+16}$。

**易错点**：$\sin\omega t$ 的分子是 $\omega$ 不是 1；$e^{-at}\cos\omega t$ 分子是 $s+a$。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 记混 $\sin$ 与 $\cos$ 的分子 | $\sin\to\omega$，$\cos\to s$ |
| 阻尼项分子写成 $s$ | $e^{-at}\cos\omega t$ 分子是 $s+a$ |
| 忘记 $t^n$ 的阶乘 | $n!$ 不能省 |
