# 根轨迹

## 0. 为什么学它

设计控制器常要回答："增益 $K$ 取多少时闭环性能最好？" **根轨迹**画出闭环极点随 $K$（或其他参数）从 0 到 $\infty$ 变化的轨迹。一眼看清 $K$ 多大开始振荡、多大开始不稳定——是增益整定的可视化工具。

## 1. 核心定义与规则

**根轨迹方程**：$1+KG(s)H(s)=0$，即 $KG(s)H(s)=-1$。

**幅值条件**：$K\lvert G(s)H(s)\rvert = 1$；**相角条件**：$\angle G(s)H(s)=180^\circ + 360^\circ k$。

**绘制规则（摘要）**：
1. 起点：开环极点（$K=0$）；终点：开环零点或无穷远（$K\to\infty$）；
2. 分支数 = 开环极点数；轨迹关于实轴对称；
3. 实轴上的轨迹段：右侧实轴上开环极零点总数为奇数的区间；
4. 渐近线：角度 $\pm 180^\circ(2k+1)/(n-m)$，交点 $\sigma_a=\frac{\sum p - \sum z}{n-m}$；
5. 分离点：$\sum \frac{1}{s+p_i}=\sum \frac{1}{s+z_i}$。

## 2. 增益 $K$ 与稳定性

- $K$ 从 0 增大 → 闭环极点沿轨迹移动；
- 轨迹穿越虚轴的点 → 临界稳定 → 对应临界增益 $K_c$（可用劳斯判据核对）；
- 设计目标：选 $K$ 使主导极点落在期望的 $\zeta,\omega_n$ 区域（扇形）。

## 3. 最小可手算例子

**题目**：$G(s)=\dfrac{K}{s(s+4)}$（单位反馈），画根轨迹草图并求临界增益。

**解**：开环极点 $s=0,-4$，零点无；实轴轨迹段 $(-4,0)$。
渐近线角度 $\pm90^\circ$，交点 $\sigma_a=-2$。
临界：特征方程 $s^2+4s+K=0$，虚轴交点 $s=\pm j2$（$s^2+4=0$），此时 $K=\omega^2=4$。
故 $K_c=4$：$K<4$ 两负实根（过阻尼），$K>4$ 复根（欠阻尼）。

**易错点**：渐近线角度用错；临界增益只数 $K$ 不代入验证。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 根轨迹只有增益一个用途 | 任何参数进入 $1+KG(s)H(s)$ 都能画 |
| 轨迹越靠左越好 | 还要看零点、带宽与噪声 |
| 手工画不准就放弃 | 草图 + 数值验证（Python Control）结合 |

## 6. 检索练习（闭卷）

1. 写出根轨迹方程与幅值/相角条件；
2. 画 $G(s)=\frac{K}{s(s+2)}$ 的根轨迹草图并求 $K_c$；
3. 解释实轴轨迹段规则；
4. 说明如何用根轨迹选择满足超调要求的 $K$。

## 7. 通过标准

- 能画二阶/三阶系统根轨迹草图；
- 能求临界增益与分离点；
- 能根据性能指标在轨迹上选增益；
- 能用劳斯判据交叉验证。
