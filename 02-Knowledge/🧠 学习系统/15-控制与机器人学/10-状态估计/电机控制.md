# 电机控制

## 0. 为什么学它

电机控制是状态估计最广泛的应用之一：**速度/位置测不准或不想装编码器时，用 KF/EKF 从电流电压里"算出"转子状态**——这就是无传感器控制（sensorless control），省掉编码器/霍尔，降低成本、提高可靠性。它是本阶段"估计理论 → 真实执行器"的落地范例，也直接衔接阶段 4 的电机三环控制。

## 1. 需要估计什么

| 状态 | 测量 | 问题 |
|:---|:---|:---|
| 转子位置 $\theta$ | 编码器/霍尔 | 成本高、易坏 |
| 转速 $\omega$ | 位置差分 | 差分放大噪声 |
| 磁链/反电动势 | 无直接测量 | 需模型估计 |

## 2. 无传感器控制（核心应用）

用电机模型 + 电流/电压测量估计 $\theta, \omega$（PMSM 模型）：

$$
L \frac{di}{dt} = v - Ri - K_e \omega \sin\theta
$$

- **EKF 标准应用**：状态 $[\theta, \omega, \psi]$，测量 $[i_d, i_q]$；
- **低速难点**：低速时反电动势弱 → 可观测性下降 → 估计困难（需高频注入）。

## 3. 电机估计的典型方案

| 方案 | 说明 |
|:---|:---|
| 滑模观测器 | 鲁棒，高/中速 |
| 模型参考自适应（MRAS） | 参数在线辨识 |
| EKF / UKF | 噪声最优、通用 |
| 高频注入 | 低速/零速定位 |

## 4. 最小可手算例子

**题目**：PMSM 反电动势模型 $e = K_e \omega \sin\theta$，已知 $K_e = 0.1$ V·s/rad，估计 $\omega = 100$ rad/s，$\theta = \pi/6$。求反电动势 $e$，并说明它如何被用于状态估计。

**解**：

$$
e = 0.1 \times 100 \times \sin(\pi/6) = 0.1 \times 100 \times 0.5 = 5 \text{ V}
$$

**解读**：测量电流/电压后可反解出反电动势，再经 EKF 的测量更新同时修正 $\theta$ 与 $\omega$——这就是"从电气量算机械状态"的原理链。低速时 $e$ 趋零，测量信息消失，估计失效（解释了为何需要高频注入）。

## 5. 工程要点

| 要点 | 说明 |
|:---|:---|
| 高采样率 | 10–100 kHz → 估计器计算要快（见 [[计算复杂度\|计算复杂度]]） |
| 参数变化 | $R, L, K_e$ 随温度/磁饱和变化 → 自适应估计 |
| 故障保护 | 电流过流、失速检测（见 [[故障检测\|故障检测]]） |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "无传感器 = 免维护" | 省掉传感器但依赖模型精度，参数失配会劣化估计 |
| "低速也能随便估" | 低速反电动势弱、可观测性差，需高频注入等专门手段 |
| "只用 EKF 一种方案" | 滑模/MRAS/高频注入各有适用区间，工程上常组合 |
| "估计器越快越好" | 高采样率下数值稳定性与噪声放大需权衡 |
