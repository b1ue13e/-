# 重采样

## 0. 为什么学它

重要性采样迭代后必然遭遇**权重退化**：少数粒子权重趋 1、多数趋 0，粒子集"塌缩"，有效样本数骤减。重采样解决这个问题：**按权重重新抽取粒子——高权重多复制、低权重淘汰，让粒子集重新聚焦**。但它是双刃剑：解决退化的同时牺牲多样性。本卡讲清"为什么需要、怎么做、代价是什么"。

## 1. 为什么需要重采样

重要性采样迭代后权重退化（见 [[控制与机器人学-重要性采样|重要性采样]]）：

- 少数粒子权重趋 1，多数趋 0 → 粒子集塌缩；
- 有效样本数 $N_{eff} = 1/\sum_i w_i^2$ 变小；
- $N_{eff} < N_{th}$（如 $N/2$）→ 触发重采样。

## 2. 重采样方法

| 方法 | 思路 | 方差 |
|:---|:---|:---|
| 多项重采样 | 按权重分布随机抽 | 大 |
| 系统重采样 | 等间隔随机起点均匀抽 | 小（常用） |
| 残差重采样 | 先按整数份复制，再补随机 | 中 |

## 3. 最小可手算例子

**题目**：3 个粒子权重 $w = \{0.7, 0.2, 0.1\}$，系统重采样抽 3 个新粒子。

**解**：累计分布 $[0, 0.7, 0.9, 1.0]$。取随机起点 $u_1 = 0.15$，步长 $1/3$，则抽签位置 $u = \{0.15, 0.483, 0.817\}$：
- $0.15 \in [0, 0.7]$ → 粒子 1；
- $0.483 \in [0, 0.7]$ → 粒子 1；
- $0.817 \in [0.7, 0.9]$ → 粒子 2。

**解读**：新粒子集 = {1, 1, 2}，权重均化为 $1/3$。高权重粒子 1 被复制 2 份、粒子 3 被淘汰——这就是"聚焦"；代价是粒子 3 代表的分布区域永久丢失。

## 4. 代价：多样性损失

- 高权重粒子被大量复制 → 粒子"同质化"；
- 多样性不足 → 分布估计偏差（尤其低噪声场景，粒子挤成几簇）；
- 对策：重采样后加微小抖动（正则化粒子滤波 / Roughening）。

## 5. 工程要点

| 要点 | 说明 |
|:---|:---|
| 触发条件 | $N_{eff}$ 低于阈值才重采样（避免过度） |
| 频率 | 每次重采样损失多样性 → 按需触发 |
| 实现 | 系统重采样简单且方差小，首选 |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "重采样每步都做" | 过度重采样加速多样性损失；只在退化时触发 |
| "重采样免费" | 以多样性为代价；低噪声下粒子同质化更严重 |
| "重采样后权重不变" | 重采样后权重均化为 $1/N$，信息转移到粒子分布 |
| "粒子越多越不需要重采样" | 粒子多只是延迟退化，不能消除 |

## 7. 检索练习（闭卷）

1. 解释权重退化的机制与 $N_{eff}$；
2. 手算 3 粒子系统重采样例子；
3. 比较三种重采样方法的方差；
4. 多样性损失的后果与对策。

## 8. 通过标准

- 能解释退化与重采样的关系；
- 能手算系统重采样；
- 能选择重采样触发条件与方法；
- 能说明多样性损失的代价与缓解。
