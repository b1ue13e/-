# 重采样

> **一句话**:权重退化时,把粒子"按权重重新抽一遍"——高权重的粒子多复制、低权重的淘汰,让粒子集重新聚焦,但会牺牲粒子多样性。

## 为什么需要重采样

重要性采样迭代后权重退化(见[[重要性采样]]):

- 少数粒子权重趋 1,多数趋 0 → 粒子集"塌缩"
- 有效样本数 $N_{eff} = 1/\sum w_i^2$ 变小
- $N_{eff} < N_{th}$(如 $N/2$)→ 触发重采样

## 重采样方法

| 方法 | 思路 |
|:---|:---|
| 多项重采样 | 按权重分布随机抽(方差大) |
| 系统重采样 | 等间隔随机起点均匀抽(方差小,常用) |
| 残差重采样 | 先按整数份复制,再补随机 |

## 代价:多样性损失

- 高权重粒子被大量复制 → 粒子"同质化"
- 多样性不足 → 分布估计偏差(尤其低噪声)
- 对策:重采样后加微小抖动(正则化粒子滤波)

## 工程要点

| 要点 | 说明 |
|:---|:---|
| 触发条件 | $N_{eff}$ 低于阈值才重采样(避免过度) |
| 频率 | 每次重采样损失多样性 → 按需触发 |
| 实现 | 系统重采样简单且方差小,首选 |
