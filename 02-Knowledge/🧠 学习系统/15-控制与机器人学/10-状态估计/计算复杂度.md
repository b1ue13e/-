# 计算复杂度

> **一句话**:EKF 每步要做几次矩阵乘法($P$ 传播、增益求解)——复杂度 $O(n^3)$($n$ 为状态维数),状态多了实时性就吃紧。

## 复杂度分析

每步主要运算:

| 运算 | 复杂度 |
|:---|:---|
| $F_k P_k F_k^\top$ | $O(n^3)$ |
| $H_k P^- H_k^\top + R$ | $O(m n^2)$ |
| 逆 $(H P^- H^\top + R)^{-1}$ | $O(m^3)$ |
| $P^+ = (I - KH)P^-$ | $O(n^3)$ |

- $n$:状态维数;$m$:测量维数
- 总体 $O(n^3)$,随维数**立方增长**

## 降复杂度手段

| 手段 | 效果 |
|:---|:---|
| 稳态增益 | $K$ 常数,省矩阵运算(见[[稳态KF]]) |
| 稀疏结构 | 利用带状/对角(见[[稀疏QP]]思想) |
| 平方根滤波 | 数值稳定 + 省一半运算 |
| 降维分解 | 状态解耦分块滤波 |
| 降低频率 | 低频 EKF + 高频简单模型 |

## 各滤波算法对比

| 算法 | 复杂度 | 适用维数 |
|:---|:---|:---|
| KF/稳态KF | $O(n^3)$(可预计算) | 大 |
| EKF | $O(n^3)$ + 雅可比 | 中 |
| UKF | $O(n^3)$,采样 $2n+1$ 点 | 中 |
| 粒子滤波 | $O(N_p \cdot n)$($N_p$ 粒子) | 小维数 |

## 工程要点

- 车辆位姿 EKF(10-15 维)实时无压力
- SLAM/大规模(上千维)需图优化/稀疏技术
- 嵌入式:预计算稳态增益是首选
