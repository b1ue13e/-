# EKF非线性状态估计

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW04（卡尔曼滤波与状态估计）的核心——官方验收 demo 就是 `ekf_localization.py`，验收指标（EKF 定位 RMSE < 0.5 m）直接由本知识点决定；它同时是 *Probabilistic Robotics* 状态估计主线（KF → EKF → UKF → PF）的承上启下环节，也是 [[卡尔曼滤波KalmanFilter]] 从"玩具线性系统"走向"真实机器人"的唯一桥梁。跳过它，HW04 只能复现 demo 不能理解为什么 EKF 能压住里程计漂移。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> [[卡尔曼滤波KalmanFilter]] 只能处理**线性**系统：状态方程和观测方程都必须是矩阵乘法 $x_k = A x_{k-1} + B u_k$。但真实机器人是**非线性**的——位姿更新里有 $\cos\theta$、$\sin\theta$（见 [[移动机器人运动学与差分驱动]]），GPS 观测距离、激光测距都是非线性函数。以前的做法是"假装它是线性的"：把 $\cos\theta$ 当成常数硬塞进 $A$ 矩阵——结果航向一变，预测误差立刻爆炸，滤波器发散。
> 于是需要回答：**非线性系统怎么沿用卡尔曼滤波"预测-更新"框架？** 答案是 EKF：在每个时刻的当前估计值附近把非线性函数做**一阶泰勒展开（线性化）**，得到时变的雅可比矩阵，再套用标准 KF 公式。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是 HW04 验收基准（`ekf_localization.py`：GPS + 里程计融合，RMSE < 0.5 m，对比纯里程计漂移基线）；是理解 UKF（无迹变换）、粒子滤波（蒙特卡洛）的参照系——后两者都是为了克服 EKF 的线性化误差而生的；EKF-SLAM 是 SLAM 的经典形式。
- **实际应用场景**：自动驾驶车辆 GNSS/IMU/轮速融合定位、手机惯性导航、无人机姿态估计（互补滤波的进阶版）、机械臂末端力/位估计、目标跟踪（雷达 + 视觉）。
- **高频题型/任务**：写出系统方程并求雅可比 $F = \partial f/\partial x$；手算一步 EKF 预测（$P^- = FPF^T + Q$）；比较 KF 与 EKF 的公式差异（$A$ 常数 vs $F$ 时变）；判断强非线性场景该用 EKF 还是 UKF/PF；复现 `ekf_localization.py` 并做 Q/R 敏感性分析。

---

## 3. 学它之前需要哪些前置知识？

1. **[[卡尔曼滤波KalmanFilter]]**：KF 的五条公式、高斯分布表示（均值 + 协方差）、预测/更新两步的直觉——EKF 只是把其中的 $A$、$H$ 换成**时变雅可比**，其余完全不动。
2. **[[移动机器人运动学与差分驱动]]**：系统方程 $f$ 从哪来——unicycle 模型 $\dot{x} = v\cos\theta$ 等就是 EKF 预测步的状态方程（加上过程噪声）。
3. **概率论基础**：高斯分布、协方差传播；多元函数求导（雅可比矩阵）——线性化的数学工具。

---

## 4. 用直觉语言解释它

> «这东西其实就像在地球仪上画直线导航：地球是球面（非线性），但你在当前位置贴一张小纸片，在纸片范围内"地球=平面"，直线近似完全够用；每走一段就换一张新纸片（重新线性化）。EKF 就是"贴着当前估计值不断换纸片"的卡尔曼滤波——函数再弯，在局部小邻域里总能当直线看。"»

- **直觉类比/几何图像**：一阶泰勒展开 = 在曲线 $f(x)$ 上当前点 $(x_0, f(x_0))$ 处画切线，用切线代替曲线；雅可比矩阵 = 切线的斜率（多维版）。
- **为什么很自然**：高斯分布经过**线性**映射后仍是高斯（KF 的数学根基）；非线性映射会把高斯"拧弯"成非高斯，但一阶近似后映射变线性，高斯性质保住——"用一次近似换整套 KF 公式照常使用"是极其划算的交易。
- **一句话直觉本质**：**EKF = 卡尔曼滤波 + "边走边在当前位置画切线"（一阶线性化）：预测/更新的公式结构不变，只是把常数矩阵 $A$、$H$ 换成随状态变化的雅可比 $F$、$H$。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **非线性状态空间模型**：
$$x_k = f(x_{k-1}, u_k) + w_k, \qquad z_k = h(x_k) + v_k$$
其中 $w_k \sim \mathcal{N}(0, Q)$ 过程噪声、$v_k \sim \mathcal{N}(0, R)$ 观测噪声，$f$、$h$ 为非线性函数。
- **扩展卡尔曼滤波（EKF）**：在每个时刻用**一阶泰勒展开**把 $f$、$h$ 在当前估计处线性化，得到时变雅可比矩阵，再套用标准卡尔曼滤波公式的状态估计器。

### 2. 核心公式
线性化（在当前估计处取雅可比）：
$$F_k = \left.\frac{\partial f}{\partial x}\right|_{\hat{x}_{k-1}, u_k}, \qquad H_k = \left.\frac{\partial h}{\partial x}\right|_{\hat{x}_k^-}$$
预测步：
$$\hat{x}_k^- = f(\hat{x}_{k-1}, u_k), \qquad P_k^- = F_k P_{k-1} F_k^T + Q$$
更新步：
$$K_k = P_k^- H_k^T (H_k P_k^- H_k^T + R)^{-1}$$
$$\hat{x}_k = \hat{x}_k^- + K_k \big(z_k - h(\hat{x}_k^-)\big), \qquad P_k = (I - K_k H_k) P_k^-$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $x_k, z_k, u_k$ | 状态 / 观测 / 输入 | $\mathbb{R}^n, \mathbb{R}^m, \mathbb{R}^p$ | 位姿 / GPS 等 / 轮速 |
| $f, h$ | 状态转移 / 观测函数 | 非线性映射 | 来自运动学与传感器模型 |
| $F_k, H_k$ | 雅可比矩阵 | $n\times n$ / $m\times n$ | **时变**，每步重算 |
| $Q, R$ | 过程 / 观测噪声协方差 | 对称半正定 | 调参核心（HW04 敏感性分析） |
| $P_k^-, \hat{x}_k^-$ | 预测协方差 / 预测均值 | — | 先验 |
| $K_k$ | 卡尔曼增益 | $n\times m$ | 权衡预测与观测 |
| $P_k, \hat{x}_k$ | 更新后协方差 / 均值 | — | 后验 |
### 4. 常见变体与适用条件
- **变体**：IEKF（迭代线性化，在更新步内反复重算 $H$ 提高精度）、UKF（无迹变换，用 sigma 点传播高斯，免求雅可比且精度到二阶）、EKF-SLAM（状态 = 位姿 + 路标，联合协方差）、SEIF（稀疏化 EKF，处理大规模地图）。
- **适用条件**：系统"弱非线性"（在估计值附近一阶近似足够好）；噪声可近似为高斯；状态维度不高（EKF-SLAM 超过千维协方差矩阵就吃力）。
- **限制条件**：强非线性（如大角度转弯、近 180° 观测）时一阶近似误差大，可能发散——此时用 UKF 或粒子滤波；$f$、$h$ 必须可微（雅可比存在）。

## 6. 推导思路和思想来源

- **最初困难**：真实系统几乎都是非线性的（三角函数的位姿、非线性传感器），而 KF 的最优性证明依赖"线性 + 高斯"两个条件——直接套公式没有理论支撑，实际也会发散。
- **直接方法局限**：把系统"整体"当作线性（固定 $A$ 矩阵）在状态远离工作点时误差爆炸；全局线性化（如沿参考轨迹线性化）只适用于轨迹跟踪，不适用于"不知道轨迹在哪"的估计问题。
- **关键"转念"**：不需要全局线性——**只需要在当前估计值附近局部线性**。因为估计器本来就"相信"状态在 $\hat{x}$ 附近（协方差 $P$ 表示的不确定区域），在这个小邻域内用切线代替曲线，误差是二阶小量。每步重新线性化（$F_k$、$H_k$ 随时间变），估计器走到哪、切线就画到哪。
- **推导主线与动机**：高斯经线性映射仍为高斯 ⇒ 若把 $f$ 在 $\hat{x}_{k-1}$ 处一阶展开 $f(x) \approx f(\hat{x}) + F(x - \hat{x})$，则 $x_k$ 仍是高斯（均值 $f(\hat{x})$、协方差 $FPF^T + Q$）⇒ KF 的全部推导原样成立，只需把 $A \to F_k$、$H \to H_k$。
- **为什么自然得到此结论**：泰勒展开是"用多项式逼近函数"的第一反应；一阶近似保持高斯闭包性（closure property），二阶以上会破坏高斯假设——所以"一阶泰勒 + KF"是数学结构上最自然、工程上最便宜的组合。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：一维系统，观测函数 $h(x) = x^2$，预测后估计 $\hat{x}^- = 2$，$P^- = 1$，$R = 4$，实测 $z = 5$。求 $H$、$K$、$\hat{x}$、$P$。
- **解题思路与关键步骤**：$H = dh/dx|_{x=2} = 2x = 4$；$K = P^- H (H P^- H + R)^{-1} = 4(16 + 4)^{-1} = 0.2$；$\hat{x} = 2 + 0.2(5 - 4) = 2.2$；$P = (1 - 0.2 \times 4) \times 1 = 0.2$。
- **最终答案**：$H = 4$，$K = 0.2$，$\hat{x} = 2.2$，$P = 0.2$。
- **易错点**：在 $\hat{x}$ 的**后验**而不是预测值处求 $H$（更新步要在 $\hat{x}^-$ 处）；忘记 $h(\hat{x}^-) = 4$ 而不是 $z$；$K$ 的分母是标量时不要漏掉 $H P^- H$ 项。
- **🤔 追问**：如果 $\hat{x}^- = -2$ 呢？——$H = -4$，$K = -0.2$，$\hat{x} = -2 + (-0.2)(5-4) = -2.2$：同样朝向"更接近 $z$ 解释"的方向修正，因为 $x^2$ 在 $x<0$ 一侧斜率是负的——这就是"局部线性化跟随符号"的体现。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：unicycle 模型 $x = (x, y, \theta)^T$，输入 $u = (v, \omega)$，离散状态方程 $x_{k+1} = x_k + v\cos\theta_k\,\Delta t$、$y_{k+1} = y_k + v\sin\theta_k\,\Delta t$、$\theta_{k+1} = \theta_k + \omega\,\Delta t$。求雅可比 $F_k$。
  解：$F_k = \begin{pmatrix} 1 & 0 & -v\sin\theta\,\Delta t \\ 0 & 1 & v\cos\theta\,\Delta t \\ 0 & 0 & 1 \end{pmatrix}$。**关键推理**：$F$ 中非对角项 $(-v\sin\theta\,\Delta t, v\cos\theta\,\Delta t)$ 表示"航向不确定性会泄漏到位置不确定性"——这正是 EKF 能描述"转个弯后位置误差变大"的机制；若写成线性 $A$（$\theta$ 固定），这项永远为零，误差被系统性低估。数值例：$v=1$、$\omega=0.5$、$\Delta t=0.1$、$\theta=0$ 时 $F = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0.1 \\ 0 & 0 & 1 \end{pmatrix}$，若 $P$ 的 $\theta$ 分量方差为 1，则 $y$ 方差被注入 $0.01$——数值上验证了"航向误差 → 横向位置误差"。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：PythonRobotics `Localization/ekf_localization/ekf_localization.py` 演示"GPS（每 10 步一次）+ 里程计"融合定位：预测步用 unicycle 模型（本例子的雅可比），更新步用 GPS 观测 $h(x) = (x, y)$（线性，$H = [I_{2\times2}, 0]$）。HW04 验收流程：先复现官方 demo（保持参数），再自写 EKF，在固定仿真轨迹下对比——EKF 定位 RMSE < 0.5 m，纯里程计漂移随距离线性增长（对照基线）；最后做 Q/R 敏感性分析：$R$ 增大（GPS 更不可信）→ 轨迹更平滑但误差增大；$Q$ 增大（模型更不可信）→ 更信任 GPS、轨迹更抖——"参数 → 误差"曲线即 HW04 报告的核心内容。

## 8. 常见误区和易混概念

### 误区 1：以为"EKF 是精确的非线性最优滤波器"
- **错误直觉**：EKF 就是 KF 的非线性版，一样最优。
- **为什么错**：EKF 只是一阶近似——线性化丢掉了二阶及以上项，估计是**次优**的；强非线性（大转角、大噪声）时误差可观甚至发散，此时 UKF（sigma 点传播，二阶精度）或粒子滤波（任意分布）更合适。
- **正确理解**：EKF 的定位是"便宜、够用、工业默认"；每次遇到发散，先怀疑"线性化误差"，再怀疑参数。
### 误区 2：把雅可比当成"可以预先算好一次"的常数
- **错误直觉**：$F$、$H$ 和 KF 的 $A$、$H$ 一样，建模时算一次就行。
- **为什么错**：$F_k$、$H_k$ 依赖**当前估计值**（在 $\hat{x}_{k-1}$、$\hat{x}_k^-$ 处取值），估计器移动，切线就要重画；用固定雅可比 = 回到"全局线性化"，在状态跑远后误差爆炸。
- **正确理解**：EKF 每步都要重新计算雅可比——这是它与 KF 唯一的结构差异，也是"扩展（Extended）"二字的含义。
### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| KF | 线性高斯系统的最优估计 | 精确最优；$A$、$H$ 常数 | 线性系统、简单模型教学 |
| EKF | 非线性系统的一阶近似估计 | 雅可比线性化；次优但便宜 | GPS+里程计、弱非线性定位（HW04） |
| UKF | 免求导的非线性估计 | sigma 点传播，二阶精度 | 强非线性、难求雅可比 |
| 粒子滤波 | 任意分布的非线性估计 | 采样近似后验，无高斯假设 | 全局定位（kidnapped robot）、多峰后验 |

### 题目与解析

#### 1. EKF 与标准 KF 在公式层面的唯一区别是什么？
> [!question]- 答案解析
> - **答案**：KF 用常数矩阵 $A$、$H$；EKF 用**时变雅可比** $F_k = \partial f/\partial x|_{\hat{x}}$、$H_k = \partial h/\partial x|_{\hat{x}^-}$（每步在当前估计处重算），且预测均值直接用非线性函数 $f(\hat{x}_{k-1}, u_k)$ 而非矩阵乘法。
> - **解析**：其余（增益公式、协方差更新结构）完全一致；EKF 是对 KF 的最小侵入式扩展，这也是它容易上手也容易被误用的原因。
> - **易错原因**：把"预测均值用 $f$ 算"与"协方差用 $F$ 传播"混为一谈——均值走真实非线性函数，协方差走线性化。
> - **对应误区**：误区 2（雅可比当常数）。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 2. 一维系统：$h(x) = \sin x$，$\hat{x}^- = 0$，$P^- = 1$，$R = 1$，$z = 0.3$。求 $H$、$K$、$\hat{x}$、$P$。
> [!question]- 答案解析
> - **答案**：$H = \cos 0 = 1$；$K = 1 \times 1 / (1\times1\times1 + 1) = 0.5$；$\hat{x} = 0 + 0.5(0.3 - \sin 0) = 0.15$；$P = (1 - 0.5\times1)\times1 = 0.5$。
> - **解析**：观测残差 $z - h(\hat{x}^-) = 0.3 - 0 = 0.3$，增益 0.5 把它折半修正；注意 $h(\hat{x}^-)$ 用**非线性函数本身**计算，不是 $H\hat{x}^-$。
> - **易错原因**：用 $H\hat{x}^-$ 算预测观测（线性化只在协方差传播中起作用）；$\sin$ 里用角度制。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 3. 场景：机器人做 180° 急转弯 + 近距离强噪声激光观测，EKF 频繁发散。直接换 UKF 还是先调参？为什么？
> [!question]- 答案解析
> - **答案**：先判断问题根源：180° 转弯让状态跨越 $\theta$ 的周期性跳变（$\pi$ 与 $-\pi$ 等价但数值差 $2\pi$），一阶线性化在跳变点严重失真——这是**结构性问题**，调参只能缓解不能根治，应改用 UKF（sigma 点不依赖导数，且天然处理部分非线性）或对 $\theta$ 做角度归一化（wrapping）后再用 EKF。
> - **解析**：区分"参数问题（调 Q/R 可解）"与"模型问题（换算法才可解）"是状态估计调试的第一判断；角度周期性是 EKF 最经典的失效场景之一。
> - **易错原因**：一律先调参，把结构性问题拖成"怎么调都发散"。
> - **对应误区**：误区 1（EKF 万能）。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 4. unicycle 模型 EKF 中，为什么 $F_k$ 的 $(1,3)$、$(2,3)$ 元素非零？若把 $\theta$ 当成已知常量（固定 $A$），会有什么后果？
> [!question]- 答案解析
> - **答案**：$(1,3) = -v\sin\theta\,\Delta t$、$(2,3) = v\cos\theta\,\Delta t$ 是"$\theta$ 的不确定性向 $x$、$y$ 泄漏"的耦合项——航向估计有方差，位置预测方差就必须随之增大。若固定 $A$（$\theta$ 视为常量），这些耦合项为零，$P^-$ 系统性低估真实不确定性，导致增益 $K$ 偏大、过度信任模型预测、对 GPS 修正反应迟钝，最终误差被低估、滤波器"虚假自信"（overconfident）而发散。
> - **解析**：协方差传播的物理含义就是"不确定性的流动"；EKF 的价值正在于让这种流动沿雅可比结构发生。
> - **易错原因**：只记 $F$ 的公式，不理解非对角项的含义——考变式题时不会判断"哪个元素该是零"。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 5. 为什么说 EKF 的线性化误差会让滤波器"高估自信"（低估协方差）？请给出论证思路。
> [!question]- 答案解析
> - **答案**：一阶展开丢掉了二阶及以上项：真实传播是 $P_{\text{true}} \approx FPF^T + Q + \text{高阶项}$（对凸函数，Jensen 不等式方向使高阶项 $\ge 0$，例如 $E[\cos^2\theta] \ge \cos^2 E[\theta]$）。EKF 只保留 $FPF^T + Q$，故 $P^-_{\text{EKF}} \le P_{\text{true}}$——滤波器以为自己很确定，实际不确定。后果链：$P$ 偏小 → $K$ 偏小（过度信任预测）→ 新观测被轻视 → 误差积累不被修正 → 发散。
> - **解析**：这是"模型误差不进入滤波器统计量"的通病（EKF 没有把线性化误差建模进 $Q$）；工程缓解：人为增大 $Q$（process noise 吸收模型误差）、用 IEKF/UKF、或对角度做 wrapping。这也是 HW04 敏感性分析中"$Q$ 该取多大"没有标准答案的根本原因。
> - **易错原因**：以为调 $R$ 就能解决一切；不理解"低估不确定性 → 增益错误 → 发散"的因果链。
> - **Obsidian 标签建议**：`#自测题/较难`
