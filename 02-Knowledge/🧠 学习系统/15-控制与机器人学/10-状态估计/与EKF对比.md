# 与EKF对比

## 0. 为什么学它

EKF 与 UKF 是"高斯假设下的非线性滤波"的两个主流实现，选哪个直接影响工程效果与开发成本。本卡给出**结构化对比与选型规则**：什么时候 EKF 简单够用、什么时候 UKF 值得换——以及一个重要的现实结论：多数工程场景两者差距 <10%，别为"听起来更先进"盲目换算法。

## 1. 全面对比

| 维度 | EKF | UKF |
|:---|:---|:---|
| 近似方式 | 一阶泰勒线性化 | Sigma 点无迹变换 |
| 精度 | 一阶 | 二阶 |
| 雅可比 | 必须（解析/数值） | 不需要 |
| 实现难度 | 低 | 中 |
| 计算量 | $O(n^3)$ | $O(n^3)$（采样 $2n+1$） |
| 强非线性 | 差 | 好 |
| 非高斯 | 都不适用（需粒子滤波） | 都不适用（需粒子滤波） |

## 2. 选型规则

| 场景 | 选择 |
|:---|:---|
| 弱非线性、模型有雅可比 | EKF（简单） |
| 强非线性、无导数 | UKF |
| 模型复杂难求导 | UKF |
| 高维状态 | EKF（UKF Sigma 点权重为负的风险） |
| 需求成熟稳定 | EKF（工程积累多、文档多） |

## 3. 精度差异的直觉

- EKF：用"切线"近似曲线，大偏差时偏离；
- UKF：用"几个点"描曲线，保留更多非线性信息；
- 强非线性（大角度姿态、近 180° 观测）时 UKF 优势明显。

## 4. 最小可手算例子（精度对比）

**题目**：$x \sim \mathcal{N}(1, 1)$，$f(x)=x^2$。对比 EKF 与 UKF 的预测均值与方差。

**解**：
- EKF：均值 $f(\mu)=1$，方差 $F^2 P + Q = 4+Q$（$F=2$）；
- UKF：均值 2.0，方差 $6.0+Q$（见 [[UKF算法|UKF算法]] 手算）；
- 真值：$\mathbb{E}[x^2]=2$。

**解读**：EKF 均值偏 50%、方差低估 25%；UKF 均值精确、方差更诚实。**非线性越强，差距越大**。

## 5. 工程现状

- 机器人定位：EKF 仍是主流（成熟、够用、好调试）；
- 车辆 IMU+GPS：两者都有，UKF 渐多；
- 实际差距：多数工程场景 <10%，极端场景 UKF 显著更优。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "UKF 精度高就该无脑用" | 高维/非高斯场景 UKF 也有问题；先评估非线性强度 |
| "EKF 已经过时" | EKF 在弱非线性场景精度够、成本低，仍是工业默认 |
| "差距永远显著" | 弱非线性下两者几乎无差，换算法的收益 < 调试成本 |
| "UKF 免调参" | $\alpha, \kappa, \beta$ 需要调，调不好照样发散 |
