# 与EKF对比

> **一句话**:EKF 与 UKF 都是"高斯假设下的非线性滤波",区别在线性化 vs 采样传播——EKF 简单够用,UKF 强非线性下更准,成本相当。

## 全面对比

| 维度 | EKF | UKF |
|:---|:---|:---|
| 近似方式 | 一阶泰勒线性化 | Sigma 点无迹变换 |
| 精度 | 一阶 | 二阶 |
| 雅可比 | 必须(解析/数值) | 不需要 |
| 实现难度 | 低 | 中 |
| 计算量 | $O(n^3)$ | $O(n^3)$(采样 $2n+1$) |
| 强非线性 | 差 | 好 |
| 非高斯 | 都不适用(需 PF) | 都不适用(需 PF) |

## 何时选哪个

| 场景 | 选择 |
|:---|:---|
| 弱非线性、模型有雅可比 | EKF(简单) |
| 强非线性、无导数 | UKF |
| 模型复杂难求导 | UKF |
| 高维状态 | EKF(UKF Sigma 点权重问题) |
| 需求成熟稳定 | EKF(工程积累多) |

## 精度差异的直觉

- EKF:用"切线"近似曲线,大偏差时偏离
- UKF:用"几个点"描曲线,信息保留更多
- 强非线性(如大角度姿态)时 UKF 优势明显

## 工程现状

- 机器人定位:EKF 仍是主流(成熟、够用)
- 车辆 IMU+GPS:两者都有,UKF 渐多
- 实际差距:多数工程场景 <10%,极端场景 UKF 显著更优
