# 问题设定

> **一句话**:卡尔曼滤波解决的问题是——在"模型不准 + 测量有噪"的情况下,如何最优地估计系统状态。设定好模型与噪声,问题就定下来了。

## 问题三要素

$$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u} + \mathbf{w} \quad \text{(过程模型)}$$
$$\mathbf{z} = H\mathbf{x} + \mathbf{v} \quad \text{(测量模型)}$$
$$\mathbf{w} \sim \mathcal{N}(0, Q), \quad \mathbf{v} \sim \mathcal{N}(0, R) \quad \text{(噪声统计)}$$

## 估计目标

求 $\hat{\mathbf{x}}_k$ 使**最小方差意义下最优**:

$$\min_{\hat{\mathbf{x}}} \mathbb{E}[\|\mathbf{x}_k - \hat{\mathbf{x}}_k\|^2]$$

即:最小均方误差估计(MMSE),条件期望 $\hat{\mathbf{x}} = \mathbb{E}[\mathbf{x} | \mathbf{z}_{1:k}]$(高斯下)。

## 前提假设

| 假设 | 违反后果 |
|:---|:---|
| 线性模型 | 需 EKF(见[[EKF非线性状态估计]]) |
| 高斯噪声 | 最优性退化 |
| 噪声统计已知 | 需自适应/标定 |
| 能观(可观) | 估计不可行(见[[能观性定义]]) |

## 建模步骤

1. 选状态变量(位置/速度/偏差)
2. 写过程模型 + 定 $Q$(模型不可信度)
3. 写测量模型 + 定 $R$(传感器噪声)
4. 定初始 $\hat{\mathbf{x}}_0, P_0$
