# 最优性

## 0. 为什么学它

"卡尔曼滤波是最优估计"这句话经常被引用，但**"最优"有严格的前提和精确的含义**。不懂最优性，就无法回答"什么时候 KF 确实最优、什么时候只是次优"，也无法理解为什么非线性系统要换 EKF/UKF、为什么噪声非高斯时粒子滤波登场。本卡把"最优"从口号变成可验证的数学命题。

## 1. 最优性的三层含义

| 层面 | 内容 |
|:---|:---|
| 线性类中最优 | 在所有线性估计器中，后验方差最小（BLUE） |
| 高斯下全局最优 | 高斯噪声下，MMSE 估计 = 条件期望 = KF |
| 递推形式最优 | 每个时刻都用了全部历史测量的最优估计 |

## 2. 数学依据

- 高斯下后验 $p(\mathbf{x}|\mathbf{z}_{1:k})$ 仍是高斯分布；
- 最小均方误差估计 = 条件均值 $\mathbb{E}[\mathbf{x}|\mathbf{z}_{1:k}]$；
- KF 递推恰好计算条件均值与协方差 → 它就是最优估计的实现。

## 3. 最优性失效的情形

| 情形 | 后果 | 对策 |
|:---|:---|:---|
| 非线性系统 | KF 不再最优 | EKF/UKF（见 [[EKF非线性状态估计\|EKF非线性状态估计]]） |
| 非高斯噪声 | MMSE 非条件均值 | 粒子滤波/其他准则 |
| 模型/噪声参数错误 | 实际误差 > 理论下界 | 标定、自适应 |
| 状态不可观 | 无法估计 | 检查能观性（见 [[能观性定义\|能观性定义]]） |

## 4. Cramér–Rao 下界

任何无偏估计的方差存在下界（CRB）：$P \succeq I^{-1}$（$I$ 为 Fisher 信息）。**KF 在"线性 + 高斯"下达到该下界**——这是"最优"的严格表述：不是"看起来不错"，而是统计上不可超越。

## 5. 最小可手算例子（验证最优性）

**题目**：一维系统 $P^-=4, R=1$。KF 增益 $K=0.8$，$P^+ = (1-0.8)\times 4 = 0.8$。验证：若用"固定 0.5 权重"融合（非最优），后验方差是多少？

**解**：非最优线性融合 $\hat{x}^+ = 0.5\hat{x}^- + 0.5 z$（与最优融合 $\hat{x}^+ = 0.2\hat{x}^- + 0.8z$ 的权重不同）。其误差方差：

$$
P^+_{\text{naive}} = 0.5^2 P^- + 0.5^2 R = 0.25\times 4 + 0.25\times 1 = 1.25
$$

而 KF 的 $P^+ = 0.8 < 1.25$。

**解读**：相同的两份信息（$P^-=4, R=1$），KF 按 $P/R$ 比例分配权重（0.8/0.2）比五五开（0.5/0.5）方差小 36%——"最优"体现在权重选择上。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "KF 在所有系统都最优" | 只在线性+高斯+参数正确时最优，否则只是"线性最优"或次优 |
| "达到 CRB = 误差为零" | CRB 是下界不是零；达到下界表示"该信息的极限精度" |
| "最优 = 无偏" | 最优性包含无偏与最小方差两层；有偏估计可能方差更小但不被 KF 采用 |
| "EKF 也是最优" | EKF 是线性化近似，一般达不到 CRB，只有一阶精度 |
