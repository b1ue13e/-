# 目标跟踪

> **一句话**:目标跟踪 = 从带噪测量中持续估计移动目标的位置/速度——"关联 + 滤波 + 航迹管理"三件套,雷达/摄像头感知的核心。

## 跟踪三件套

1. **数据关联**:哪个测量对应哪个目标(见[[数据关联]])
2. **滤波**:用 KF/EKF 平滑估计目标状态
3. **航迹管理**:航迹起始/维持/终结

## 运动模型

| 模型 | 状态 | 适用 |
|:---|:---|:---|
| 恒定速度(CV) | $[x, v_x, y, v_y]$ | 匀速目标 |
| 恒定加速度(CA) | +$[a_x, a_y]$ | 机动目标 |
| 恒定转弯(CT) | + 转弯率 | 转弯目标 |
| 交互多模型(IMM) | 多模型切换 | 复杂机动 |

## 滤波方法选择

| 场景 | 方法 |
|:---|:---|
| 线性 + 高斯 | KF |
| 距离/方位测量(非线性) | EKF/UKF |
| 多模态分布 | 粒子滤波(见[[SIR滤波]]) |
| 密集多目标 | JPDA/MHT + 滤波 |

## 航迹管理

- 起始:连续确认(如 3 次关联成功)
- 维持:关联 + 更新
- 终结:连续丢失(如 5 次未关联)
- 生命周期管理避免"幽灵航迹"

## 性能指标

| 指标 | 含义 |
|:---|:---|
| 位置误差 | RMSE(见[[一致性]]) |
| 航迹纯度 | 目标-航迹正确关联率 |
| 丢失率/虚警率 | 感知质量 |
