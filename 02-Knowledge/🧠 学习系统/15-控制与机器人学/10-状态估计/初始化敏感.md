# 初始化敏感

> **一句话**:EKF 对初值很"挑"——初值偏差大,线性化点就偏,可能不收敛甚至发散;KF 对初值宽容,EKF 必须给好初值。

## 为什么 EKF 敏感

- 线性化在**当前估计**处进行(见[[局部线性化]])
- 初值 $\hat{\mathbf{x}}_0$ 差 → 线性化点远离真值 → 雅可比不准 → 估计更偏 → 恶性循环
- 非线性越强,初值容差越小

## 与 KF 对比

| 方法 | 初值敏感度 | 原因 |
|:---|:---|:---|
| KF(线性) | 低 | 线性化精确,误差指数收敛 |
| EKF | 高 | 线性化点随估计漂移 |
| UKF | 中 | 采样传播稍鲁棒 |
| PF | 低 | 全分布采样 |

## 缓解方法

| 方法 | 说明 |
|:---|:---|
| 好的初值 | 用 GPS/其他传感器粗定位初始化 |
| 大 $P_0$ | 表示"没把握",允许快速修正(见[[协方差矩阵]]) |
| 大 $Q$ 初期 | 加快收敛(收敛后调小) |
| 多初值 | 多个假设并行,选最优 |
| 重启策略 | 检测发散 → 重新初始化 |

## 工程要点

- 初始化在 EKF 部署中要**专门设计**(不是简单置 0)
- 发散检测:新息超限(见[[故障检测]])→ 触发重初始化
- 弱可观状态对初值更敏感(见[[能观性定义]])
