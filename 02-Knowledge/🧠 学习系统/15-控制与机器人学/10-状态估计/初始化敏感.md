# 初始化敏感

## 0. 为什么学它

EKF 对初值很"挑"：**初值偏差大，线性化点就偏，雅可比不准，估计更偏——恶性循环**，可能不收敛甚至发散。同样是滤波器，KF 对初值宽容（线性系统误差指数收敛），EKF 却必须给好初值。本卡解决部署 EKF 时的头号工程问题："初值怎么给、给错了怎么办、怎么设计重启动"。

## 1. 为什么 EKF 敏感

- 线性化在**当前估计**处进行（见 [[局部线性化|局部线性化]]）；
- 初值 $\hat{\mathbf{x}}_0$ 差 → 线性化点远离真值 → 雅可比不准 → 估计更偏 → 循环恶化；
- 非线性越强，初值容差越小。

## 2. 与 KF / UKF / PF 对比

| 方法 | 初值敏感度 | 原因 |
|:---|:---|:---|
| KF（线性） | 低 | 线性化精确，误差指数收敛 |
| EKF | 高 | 线性化点随估计漂移 |
| UKF | 中 | Sigma 点采样传播更鲁棒 |
| 粒子滤波 | 低 | 全分布采样，多初值天然并行 |

## 3. 缓解方法

| 方法 | 说明 |
|:---|:---|
| 好初值 | 用 GPS/其他传感器粗定位初始化 |
| 大 $P_0$ | 表示"没把握"，允许快速修正（见 [[控制与机器人学-协方差矩阵\|协方差矩阵]]） |
| 初期大 $Q$ | 加快收敛，收敛后调小 |
| 多初值 | 多个假设并行，选新息最小的 |
| 重启策略 | 检测发散 → 重新初始化 |

## 4. 最小可手算例子

**题目**：$h(x)=x^2$，$R=4$，真值 $x=3$。比较 $\hat{x}_0=2$ 与 $\hat{x}_0=-2$ 两种初值下，第一步更新后的估计。

**解**：$H = 2\hat{x}_0$，$K = \frac{P^-}{H^2 P^- + R}$（取 $P^-=1$）：

- $\hat{x}_0=2$：$H=4$，$K=\frac{1}{16+4}=0.05$，$\hat{x}^+ = 2 + 0.05(9-4) = 2.25$（向真值 3 收敛）；
- $\hat{x}_0=-2$：$H=-4$，$K=-0.05$，$\hat{x}^+ = -2 - 0.05(9-4) = -2.25$（远离真值）。

**解读**：$x^2$ 的对称性让负初值把估计推向相反方向——若系统进一步更新，$x<0$ 一侧的线性化会持续把估计推向 $-\sqrt{z}$，**收敛到错误的"局部最优"**。这是"初值错 → 收敛到错解"的直观演示。

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "初值设 0 就行" | EKF 必须专门设计初始化（粗定位、多初值） |
| "$P_0$ 小 = 精确起步" | $P_0$ 小 = 拒信测量，初值错时收敛极慢 |
| "发散就是 Q 的问题" | 发散也可能是初值/局部线性化问题，先检查初值 |
| "重启 = 重跑一遍" | 重启要用更鲁棒的初始化策略，否则重蹈覆辙 |
