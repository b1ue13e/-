# 无迹变换

## 0. 为什么学它

EKF 用"切线"近似曲线，切线画错位置就崩。无迹变换（UT）换了一条路：**不线性化函数，而是采样几个代表性点（Sigma 点）穿过非线性函数，再从输出点反推均值与协方差**——精度达二阶（EKF 只有一阶），成本却与 EKF 相当，还不需要算雅可比。它是 UKF 的引擎，也是理解"采样传播优于线性化"的关键。

## 1. 核心思想

对高斯分布取 $2n+1$ 个 Sigma 点（对称采样）：

$$
\mathcal{X}_0 = \bar{\mathbf{x}}, \qquad \mathcal{X}_i = \bar{\mathbf{x}} \pm \sqrt{(n+\lambda) P_i}
$$

让每个点过非线性函数 $\mathcal{Y}_i = f(\mathcal{X}_i)$，再从输出点统计：

$$
\bar{\mathbf{y}} = \sum_i w_i \mathcal{Y}_i, \qquad
P_y = \sum_i w_i (\mathcal{Y}_i - \bar{\mathbf{y}})(\mathcal{Y}_i - \bar{\mathbf{y}})^\top
$$

## 2. 为什么比线性化准

| 方法 | 传播 | 精度 |
|:---|:---|:---|
| EKF 线性化 | 一阶泰勒 | 一阶 |
| 无迹变换 | 点精确传播 | **二阶**（均值）/ 三阶（高斯） |
| 蒙特卡洛 | 大量随机点 | 任意（统计收敛） |

UT 不用算雅可比，对不可导函数也适用——黑盒模型友好。

## 3. 参数选择

- $\lambda = \alpha^2(n + \kappa) - n$：缩放参数；
- $\alpha$（小值，如 $10^{-3}$）：决定 Sigma 点距；
- 权重 $w_i$：均值权重与协方差权重通常分开定义。

## 4. 最小可手算例子

**题目**：一维 $x \sim \mathcal{N}(1, 1)$，$f(x) = x^2$。用 UT（$n=1, \lambda=2$）传播均值与方差，对比 EKF。

**解**：Sigma 点（$\sqrt{(1+2)\cdot 1} = \sqrt{3} \approx 1.732$）：

$$
\mathcal{X} = \{1, \ 1+1.732=2.732, \ 1-1.732=-0.732\}
$$

过 $f(x)=x^2$：$\mathcal{Y} = \{1, \ 7.464, \ 0.536\}$。均值权重 $w_0 = \frac{\lambda}{n+\lambda} = \frac{2}{3}$，$w_{1,2} = \frac{1}{2(n+\lambda)} = \frac{1}{6}$：

$$
\bar{y} = \frac{2}{3}\times 1 + \frac{1}{6}\times 7.464 + \frac{1}{6}\times 0.536 = 0.667 + 1.244 + 0.089 = 2.0
$$

**解读**：$\mathbb{E}[x^2] = \text{Var} + \mu^2 = 2$（精确值）——UT 精确复现；而 EKF 线性化给 $f(\mu) = 1$（错 100%）。UT 的"二阶精度"在这里完美体现。

## 5. 无迹变换 vs 粒子

| 对比 | Sigma 点（UT） | 粒子 |
|:---|:---|:---|
| 采样方式 | 确定性采样 | 随机采样 |
| 样本数量 | 少量（$2n+1$） | 大量（$N_p$） |
| 分布假设 | 高斯 | 任意分布 |
| 用途 | UKF | 粒子滤波（见 [[SIR滤波\|粒子滤波]]） |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "UT 是随机采样" | Sigma 点是**确定性**选取，同一分布每次结果相同 |
| "UT 不需要高斯假设" | UT 仍假设高斯分布，只是传播更准；非高斯要用粒子 |
| "Sigma 点越多越好" | 固定 $2n+1$ 个，参数 $\alpha, \kappa$ 影响点距与权重 |
| "UT 完全没误差" | 三阶以上信息仍丢失；强非线性仍是近似 |
