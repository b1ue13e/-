# 原理陈述

> **一句话**:分离定理说——线性高斯系统里,"最优控制器设计"和"最优状态估计器设计"可以分开做,合起来仍然最优,互不干扰。

## 定理陈述

对线性时不变系统 + 高斯噪声 + 二次代价(LQG):

1. 控制器增益 $K$:只由 $(A, B, Q, R)$ 决定(假设状态已知)
2. 估计器增益 $L$:只由 $(A, C, Q_w, R_v)$ 决定(假设控制已知)
3. **两者独立设计,组合后整体最优**(分离原理)

$$\hat{\mathbf{x}}_{k+1} = A\hat{\mathbf{x}}_k + B\mathbf{u}_k + L(\mathbf{z}_k - C\hat{\mathbf{x}}_k), \quad \mathbf{u}_k = -K\hat{\mathbf{x}}_k$$

## 为什么成立

- 估计误差与状态控制**解耦**:误差动力学 $e_{k+1} = (A-LC)e_k$(不含 $K$)
- 代价可分:状态代价 + 误差代价
- 确定性等价原理:最优控制 = 用最优估计替代真状态

## 成立条件

| 条件 | 违反后果 |
|:---|:---|
| 线性系统 | 非线性需近似(NMPC+EKF 无严格分离) |
| 高斯噪声 | 非高斯最优性退化 |
| 二次代价 | 其他代价分离不保证 |
| 能控 + 能观 | 保证极点配置(见[[闭环极点]]) |

## 工程意义

- 控制器与估计器**分别调试**(设计自由度)
- 加估计器不改变控制器极点(只要估计收敛)
- 分离原理是"状态反馈 + 观测器"架构的理论依据
