# 原理陈述

## 0. 为什么学它

当状态不可直接测量时，控制回路里必须塞一个估计器。直觉上"控制器 + 估计器"应该互相纠缠，但**分离定理**说：线性高斯系统里，两者可以分开设计、合起来仍然最优——这是"状态反馈 + 观测器"架构能成立的数学依据，也是 LQG 控制与工程上"分别调试控制器/估计器"的理论前提。

## 1. 定理陈述

对线性时不变系统 + 高斯噪声 + 二次代价（LQG）：
1. **控制器增益 $K$**：只由 $(A, B, Q, R)$ 决定（假设状态已知）；
2. **估计器增益 $L$**：只由 $(A, C, Q_w, R_v)$ 决定（假设控制已知）；
3. **两者独立设计，组合后整体最优**：

$$
\hat{\mathbf{x}}_{k+1} = A\hat{\mathbf{x}}_k + B\mathbf{u}_k + L(\mathbf{z}_k - C\hat{\mathbf{x}}_k), \qquad \mathbf{u}_k = -K\hat{\mathbf{x}}_k
$$

## 2. 为什么成立

- **误差与状态解耦**：误差动力学 $e_{k+1} = (A - LC)e_k$ 中不含 $K$；
- **代价可分**：总代价 = 状态代价 + 估计误差代价；
- **确定性等价原理**：最优控制 = 用最优估计替代真状态（在 LQG 设定下严格成立）。

## 3. 成立条件

| 条件 | 违反后果 |
|:---|:---|
| 线性系统 | 非线性需近似（NMPC+EKF 无严格分离） |
| 高斯噪声 | 非高斯最优性退化 |
| 二次代价 | 其他代价分离性不保证 |
| 能控 + 能观 | 保证极点可配置（见 [[闭环极点\|闭环极点]]） |

## 4. 最小可手算例子（验证解耦）

**题目**：一阶系统 $A=1, B=1, C=1$。控制器 $u=-kx$ 取 $k=2$，估计器增益 $l=3$。写出闭环误差动力学并验证不含 $k$。

**解**：误差动力学 $e_{k+1} = (A - lC)e = (1-3)e = -2e$——**与 $k$ 无关**。

**解读**：估计误差的收敛速度只由 $l$ 决定（此处 $-2$，快）；而控制性能只由 $k$ 决定。两者互不干扰，这正是"分别设计"合法性的来源。

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "分离原理在任何系统成立" | 只在线性+高斯+二次代价成立；非线性没有严格分离 |
| "估计器收敛前控制器会失控" | 分离定理是稳态最优；暂态需估计器足够快（见 [[闭环极点\|闭环极点]]） |
| "加了估计器控制器不变" | 理想分离下控制器极点不变，但回路鲁棒性会变（见 [[回路传递恢复\|回路传递恢复]]） |
| "LQG 一定有稳定裕度" | LQG 无稳定裕度保证，需要 LTR 等补救 |
