# 采样率差异

> **一句话**:不同传感器频率不同(IMU 100-1000Hz,GPS 1-10Hz,相机 10-30Hz)——估计器要在"快慢不等"的测量流上做异步融合。

## 典型多速率配置

| 传感器 | 频率 | 角色 |
|:---|:---|:---|
| IMU | 100–1000 Hz | 高频预测(运动) |
| 轮速/编码器 | 50–100 Hz | 高频约束 |
| GPS | 1–10 Hz | 低频修正 |
| 相机/LiDAR | 10–30 Hz | 中频观测 |

## 异步融合策略

### 1. 按时间戳处理(推荐)
每个测量到达即更新,时间不齐不强制对齐:

```
收到 z_k (带时间戳 t_k):
    用 t_k 之前的预测结果作为先验
    更新一步
```

### 2. 高低频分层
- 高频传感器驱动预测(每步都跑时间更新)
- 低频传感器触发更新(来了才修正)
- 即"预测高频、修正低频"的异步 KF

### 3. 同步化
- 低频测量插值/外推到高频时刻(引入人为误差)
- 或降采样统一到最低频率(浪费高频信息)

## 工程要点

| 要点 | 说明 |
|:---|:---|
| 时间戳 | 一切异步融合的前提 |
| 预测步频 | 由最高频传感器驱动 |
| 更新步频 | 由各低频测量驱动 |
| 延迟补偿 | 高频预测补偿低频延迟(见[[传感器延迟]]) |
