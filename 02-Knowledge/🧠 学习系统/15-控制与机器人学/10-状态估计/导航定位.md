# 导航定位

## 0. 为什么学它

"车/机器人怎么知道自己在哪？"——GPS 低频且城市峡谷会丢、IMU 高频但积分漂移、轮速打滑失真。**组合导航**用 EKF 把这些"各有毛病"的传感器融合成高精度位姿：高频预测、低频修正、零偏在线标定。它是阶段作业-10（KF/EKF 推导 + 车辆位姿估计仿真）的直接工程落点，也是自动驾驶/机器人导航的地基。

## 1. 传感器互补性

| 传感器 | 优点 | 缺点 |
|:---|:---|:---|
| GPS | 绝对位置、无漂移 | 低频（1-10 Hz）、易遮挡、多径 |
| IMU | 高频（100-1000 Hz）、自主 | 积分漂移随时间累积 |
| 轮速/里程计 | 高频、便宜 | 打滑、胎压/磨损误差 |

**互补原则**：用高频传感器驱动预测（保持连续性），用低频绝对传感器修正（抑制漂移）——正是异步融合（见 [[采样率差异|采样率差异]]）。

## 2. 组合导航架构（EKF 为核心）

- 状态：$[x, y, z, v_x, v_y, v_z, \phi, \theta, \psi, \text{零偏...}]$；
- IMU 驱动**预测步**（高频，见 [[预测步|预测步]]）；
- GPS/视觉驱动**更新步**（低频，见 [[更新步|更新步]]）；
- 零偏（偏差）作为状态估计并补偿（见 [[Allan方差|Allan方差]]）。

## 3. 最小可手算例子

**题目**：车辆 $x$ 方向位置，IMU 测加速度积分得预测 $\hat{x}^- = 100$ m，$P^- = 9$ m²；GPS 测量 $z = 106$ m，$R = 16$ m²。求融合后估计。

**解**：

$$
K = \frac{P^-}{P^- + R} = \frac{9}{25} = 0.36, \qquad
\hat{x}^+ = 100 + 0.36 \times (106 - 100) = 102.16 \text{ m}
$$

**解读**：IMU 预测与 GPS 测量按不确定性加权（$P^-=9$ vs $R=16$）——GPS 更不可信（$R$ 大），只占 36% 权重。这就是"传感器融合"的最小单元。

## 4. 关键工程技巧

| 技巧 | 说明 |
|:---|:---|
| 异步融合 | 预测高频、更新异步（见 [[采样率差异\|采样率差异]]） |
| 延迟补偿 | GPS 有延迟，预测到当前时刻（见 [[传感器延迟\|传感器延迟]]） |
| 零偏估计 | IMU 偏差在线标定 |
| 故障处理 | GPS 丢失 → 纯惯导短时保持（见 [[故障检测\|故障检测]]） |

## 5. 工程指标

- 高速公路：横向精度 < 20 cm（高精地图定位）；
- 城市：GNSS + 视觉 + IMU 融合；
- 隧道：GNSS 丢失 → 惯导 + 轮速维持。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "GPS 够用了" | 城市/隧道 GPS 不可用，必须多传感器冗余 |
| "IMU 积分很准" | 积分漂移随时间累积，必须有绝对参考修正 |
| "融合 = 加权平均" | 是按协方差的自适应加权（KF），不是固定权重 |
| "零偏不用管" | IMU 零偏是最大误差源，必须作为状态在线估计 |
