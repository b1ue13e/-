# 导航定位

> **一句话**:车辆/机器人怎么知道自己在哪?——GPS 低频不准、IMU 高频漂移、轮速有打滑,组合导航用 EKF 把这些"各有毛病"的传感器融合成高精度位姿。

## 传感器互补性

| 传感器 | 优点 | 缺点 |
|:---|:---|:---|
| GPS | 绝对位置、不漂移 | 低频(1-10Hz)、遮挡失效 |
| IMU | 高频(100Hz+)、短时准 | 积分漂移 |
| 轮速/里程计 | 高频、稳定 | 打滑/轮胎差异 |
| 相机/LiDAR | 相对观测丰富 | 光照/环境敏感 |

## 组合导航架构(经典)

$$\text{IMU 高频积分} + \text{GPS/其他低频修正} = \text{EKF 融合}$$

- 状态:$[x, y, z, v_x, v_y, v_z, \phi, \theta, \psi, \text{零偏...}]$
- IMU 驱动**预测步**(高频,见[[预测步]])
- GPS/视觉驱动**更新步**(低频,见[[更新步]])
- 零偏(偏差)作为状态估计并补偿(见[[Allan方差]])

## 关键技巧

| 技巧 | 说明 |
|:---|:---|
| 异步融合 | 预测高频、更新异步(见[[采样率差异]]) |
| 延迟补偿 | GPS 有延迟,预测到当前时刻(见[[传感器延迟]]) |
| 零偏估计 | IMU 偏差在线标定 |
| 故障处理 | GPS 丢失 → 纯惯导短时保持(见[[故障检测]]) |

## 工程指标

- 高速公路:横向精度 < 20cm(高精地图定位)
- 城市:GNSS + 视觉 + IMU 融合
- 隧道:GNSS 丢失 → 惯导 + 轮速维持
