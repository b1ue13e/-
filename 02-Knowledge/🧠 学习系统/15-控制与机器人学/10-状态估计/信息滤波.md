# 信息滤波

> **一句话**:信息滤波是 KF 的"对偶形式"——用信息矩阵(协方差逆)表示不确定性,多传感器融合变成"加信息",分布式融合的天然工具。

## 信息形式

定义信息矩阵与信息状态:

$$\Omega = P^{-1}, \quad \hat{\mathbf{\eta}} = P^{-1} \hat{\mathbf{x}}$$

信息滤波更新/预测在信息域进行。

## 测量更新的关键性质

$$P^+ = P^- + H^\top R^{-1} H \quad \Rightarrow \quad \Omega^+ = \Omega^- + \underbrace{H^\top R^{-1} H}_{\text{测量信息}}$$

**多传感器 = 信息相加**:

$$\Omega^+ = \Omega^- + \Omega_{z_1} + \Omega_{z_2} + \cdots$$

## 为什么重要

| 特性 | 说明 |
|:---|:---|
| 融合即加法 | 每个传感器独立贡献信息量 |
| 分布式 | 各传感器独立计算再汇总(联邦滤波,见[[联邦滤波]]) |
| 初始不确定性 | $\Omega_0 = 0$(无信息)自然表示,无需大 P |
| 数值 | 信息矩阵常比协方差更良态 |

## 与 KF 对比

- KF:协方差域,更新是"除法味"(I-KH)
- IF:信息域,更新是"加法味"
- 预测步 IF 更复杂(需逆),KF 更简单 → 各有所长

## 应用

- 多传感器分布式融合(机器人、无人车)
- SLAM 信息形式(graph SLAM 基础)
- 大规模网络估计
