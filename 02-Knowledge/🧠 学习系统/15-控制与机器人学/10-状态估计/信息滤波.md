# 信息滤波

## 0. 为什么学它

信息滤波（IF）是 KF 的"对偶形式"：用**信息矩阵**（协方差逆）表示不确定性。它最大的优势在测量更新——**多传感器融合变成"加信息"**，每个传感器独立贡献，天然适合分布式融合；SLAM 的图优化（graph SLAM）也建立在信息形式之上。理解 IF，就理解了"KF 的协方差形式不是唯一选择，换个表示能解锁新能力"。

## 1. 信息形式

定义信息矩阵与信息状态：

$$
\Omega = P^{-1}, \qquad \hat{\boldsymbol{\eta}} = P^{-1} \hat{\mathbf{x}}
$$

滤波在信息域进行：状态 = $\Omega^{-1} \hat{\boldsymbol{\eta}}$。

## 2. 测量更新的关键性质

$$
P^+ = P^- + H^\top R^{-1} H \quad \Rightarrow \quad \Omega^+ = \Omega^- + \underbrace{H^\top R^{-1} H}_{\text{测量信息}}
$$

**多传感器 = 信息相加**：

$$
\Omega^+ = \Omega^- + \Omega_{z_1} + \Omega_{z_2} + \cdots
$$

每个传感器独立计算 $H^\top R^{-1} H$（"测量贡献的信息量"），主滤波器只做加法。

## 3. 为什么重要

| 特性 | 说明 |
|:---|:---|
| 融合即加法 | 传感器越多，信息直接相加，无矩阵求逆的更新 |
| 分布式 | 各传感器独立算贡献，汇总到中央（联邦滤波，见 [[联邦滤波\|联邦滤波]]） |
| 初始不确定性 | $\Omega_0 = 0$（无信息）自然表示，无需"大 $P$"技巧 |
| 数值 | 信息矩阵常比协方差更良态（稀疏化容易） |

## 4. 与 KF 对比

| 环节 | KF（协方差域） | IF（信息域） |
|:---|:---|:---|
| 测量更新 | 除法味 $(I-KH)$ | 加法味 $\Omega^+ = \Omega^- + H^\top R^{-1} H$ |
| 预测步 | 简单（$A P A^\top + Q$） | 复杂（需求逆 $P$） |
| 多传感器融合 | 逐次更新 | 一次加总 |
| 典型应用 | 单机实时滤波 | 分布式/图 SLAM |

## 5. 最小可手算例子

**题目**：两个独立传感器测同一位置，$R_1 = 4$，$R_2 = 1$，先验信息 $\Omega^- = 0.5$。求融合后的 $\Omega^+$ 与 $P^+$。

**解**：$H=1$：

$$
\Omega^+ = 0.5 + \frac{1}{4} + \frac{1}{1} = 0.5 + 0.25 + 1 = 1.75, \qquad P^+ = \frac{1}{1.75} \approx 0.571
$$

**解读**：传感器 2（$R=1$）贡献了信息量 1，比传感器 1（$R=4$，贡献 0.25）大 4 倍——信息相加直观体现了"谁准谁说了算"。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "IF 全面优于 KF" | 预测步需要求逆，单机时 IF 反而更贵；两者互补 |
| "信息相加 = 权重相加" | 加的是 $H^\top R^{-1} H$（信息量），不是原始测量值 |
| "IF 不适用于非线性" | 有 IEKF（信息域 EKF），但实现更繁琐 |
| "$\Omega_0 = 0$ 有信息含义" | 表示"一无所知"（协方差无穷大），是自然先验 |
