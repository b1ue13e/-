# 一致性

## 0. 为什么学它

估计器"说的准"和"实际准"是两回事：滤波器输出的协方差 $P$ 可能严重低估真实误差——**EKF 的线性化误差恰恰常让 $P$ 偏小（过于自信）**。一致性检验就是滤波器的"体检"：检查理论协方差与实际误差是否吻合。不查一致性，你可能在用一个"自以为是"的滤波器跑组合导航，而它早就悄悄偏离真值了。**调参前先过一致性检验，再谈精度。**

## 1. 一致性的定义

估计一致 ⇔ 实际均方误差 ≈ 理论协方差：

$$
\mathbb{E}\left[(\mathbf{x} - \hat{\mathbf{x}})(\mathbf{x} - \hat{\mathbf{x}})^\top\right] \approx P
$$

**一致 ≠ 精确**：一致的估计可以误差很大（只要 $P$ 也诚实地说"我不确定"）；不一致才是危险（$P$ 撒谎）。

## 2. 检验指标：NEES

归一化估计误差平方（Normalized Estimation Error Squared）：

$$
\epsilon_k = (\mathbf{x}_k - \hat{\mathbf{x}}_k)^\top P_k^{-1} (\mathbf{x}_k - \hat{\mathbf{x}}_k)
$$

一致性良好时 $\epsilon_k \sim \chi^2_n$（卡方分布，$n$ 为状态维数）。

## 3. 检验方法

1. 多次蒙特卡洛运行，统计平均 NEES：
   $$\bar{\epsilon} = \frac{1}{N} \sum_{i=1}^{N} \epsilon_k^{(i)}$$
2. 查卡方门限区间：$\bar{\epsilon}$ 落在 $\chi^2_n$ 的置信区间内 → 一致；
3. **NEES 偏大**：实际误差 > 理论 → $P$ 过小（乐观，危险）；
4. **NEES 偏小**：实际误差 < 理论 → $P$ 过大（悲观，保守但安全）。

## 4. 不一致的原因

| 原因 | 表现 |
|:---|:---|
| EKF 线性化 | $P$ 偏小（乐观）——最常见 |
| $Q$/$R$ 标定错误 | 系统性偏差 |
| 模型失配 | 误差大但 $P$ 小 |
| 相关噪声 | 独立性假设破坏 |

## 5. 最小可手算例子

**题目**：一维 EKF，$n=1$。10 次蒙特卡洛的 NEES 均值为 $\bar{\epsilon} = 6.5$，$\chi^2_1$ 的 95% 置信区间约为 $[0.98, 14.5]$（10 次均值）。判断一致性。

**解**：$\bar{\epsilon} = 6.5$ 落在 $[0.98, 14.5]$ 内 → 一致性可接受。

**解读**：若 $\bar{\epsilon} = 20$（远超上界），说明实际误差是理论 $P$ 的 $\sqrt{20/1} \approx 4.5$ 倍——滤波器"过度自信"约 4.5 倍，必须增大 $Q$ 或修复线性化。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "NEES 偏大就调小 $R$" | NEES 偏大 = $P$ 过小，应增大 $Q$（让 $P$ 诚实），不是动 $R$ |
| "一致 = 精确" | 一致只说明 $P$ 诚实；精度由 $Q/R$ 与信息量决定 |
| "单次运行看 NEES" | 需多次蒙特卡洛统计，单次是随机量 |
| "只查一次就放心" | 场景/参数变化后要重测（线性化误差随工况变） |

## 7. 检索练习（闭卷）

1. 写出一致性定义式与 NEES 公式；
2. 手算判断 $\bar{\epsilon}=6.5$（$n=1$）的一致性；
3. 解释 NEES 偏大/偏小的物理含义；
4. 为什么 EKF 常"过于自信"？

## 8. 通过标准

- 能写出 NEES 定义并解释其卡方分布性质；
- 能根据蒙特卡洛 NEES 均值判定一致性；
- 能定位不一致的根因（线性化/$Q$/$R$/模型）；
- 能通过调 $Q$ 恢复一致性。
