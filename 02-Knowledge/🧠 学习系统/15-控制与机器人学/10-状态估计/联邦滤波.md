# 联邦滤波

## 0. 为什么学它

多传感器融合的工程架构问题：如果所有传感器都喂给一个中央滤波器，任一传感器故障就会拖垮全局。联邦滤波给出"主从式"分布式架构——**每个子传感器有自己的局部滤波器，主滤波器只做信息汇总**，容错性好、模块化强，是航天/车辆组合导航的经典架构（GPS/INS/磁力计融合的标准方案之一）。

## 1. 架构

```
                ┌─ 子滤波器1(传感器1) ─┐
主滤波器(全局) ─┼─ 子滤波器2(传感器2) ─┼─→ 全局估计
                ├─ 子滤波器3(传感器3) ─┤
                └─ 子滤波器4(动态)    ─┘
```

- 子滤波器：各自用信息滤波估计（见 [[信息滤波|信息滤波]]）；
- 主滤波器：汇总子滤波器信息 + 分配反馈。

## 2. 信息分配原则

- 全局信息按"信息分配系数" $\beta_i$ 分给子滤波器（$\sum_i \beta_i = 1$）；
- $\beta$ 大的子系统更"自信"（分到的信息多）；
- 可无反馈（子滤波器完全独立）→ 容错最强。

## 3. 优点

| 优点 | 说明 |
|:---|:---|
| 容错 | 子滤波器故障不拖垮全局（可隔离） |
| 模块化 | 增删传感器不影响整体结构 |
| 并行 | 子滤波器可分布式计算 |
| 工程成熟 | 航天/车辆导航经典架构 |

## 4. 信息融合公式

全局：

$$
\Omega_g = \sum_i \Omega_i, \qquad \hat{\eta}_g = \sum_i \hat{\eta}_i
$$

正是信息滤波的"加法融合"（见 [[信息滤波|信息滤波]]）。

## 5. 最小可手算例子

**题目**：两个子滤波器分别输出 $\Omega_1 = 0.5$、$\hat{\eta}_1 = 3$；$\Omega_2 = 0.8$、$\hat{\eta}_2 = 4$。求全局估计。

**解**：

$$
\Omega_g = 0.5 + 0.8 = 1.3, \qquad \hat{\eta}_g = 3 + 4 = 7
$$

$$
\hat{x}_g = \frac{\hat{\eta}_g}{\Omega_g} = \frac{7}{1.3} \approx 5.38
$$

**解读**：全局估计 5.38 偏向信息量更大的传感器 2（$\Omega_2 = 0.8$ 贡献 62%），符合"谁准谁说了算"；若子滤波器 1 故障，可直接剔除其贡献重算——容错性的量化体现。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "联邦滤波 = 简单平均" | 是信息量加权（$\Omega$ 加权），不是算术平均 |
| "子滤波器越多越好" | 信息分配系数要合理设计，无意义的重复传感器会过度自信 |
| "无反馈一定更好" | 无反馈容错强但精度低；有反馈精度高但故障传播风险大 |
| "联邦滤波只适合航天" | 任何多传感器融合系统都适用（车辆/机器人） |
