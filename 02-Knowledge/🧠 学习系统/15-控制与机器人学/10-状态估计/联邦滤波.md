# 联邦滤波

> **一句话**:联邦滤波是"主从式"分布式融合架构——每个子传感器有自己的局部滤波器,主滤波器只做信息汇总,容错性好、模块化强。

## 架构

```
                ┌─ 子滤波器1(传感器1) ─┐
主滤波器(全局) ─┼─ 子滤波器2(传感器2) ─┼─→ 全局估计
                ├─ 子滤波器3(传感器3) ─┤
                └─ 子滤波器4(动态)    ─┘
```

- 子滤波器:各自用信息滤波估计(见[[信息滤波]])
- 主滤波器:汇总子滤波器信息 + 分配反馈

## 信息分配原则

- 全局信息按"信息分配系数" $\beta_i$ 分给子滤波器($\sum \beta_i = 1$)
- $\beta$ 大的子系统更"自信"(信息多)
- 可无反馈(子滤波器独立)→ 容错最强

## 优点

| 优点 | 说明 |
|:---|:---|
| 容错 | 子滤波器故障不拖垮全局 |
| 模块化 | 增删传感器不影响结构 |
| 并行 | 子滤波器可分布式计算 |
| 工程成熟 | 航天/车辆导航经典架构 |

## 信息融合公式

全局:

$$\Omega_g = \sum_i \Omega_i, \quad \hat{\eta}_g = \sum_i \hat{\eta}_i$$

正是信息滤波的"加法融合"(见[[信息滤波]])。
