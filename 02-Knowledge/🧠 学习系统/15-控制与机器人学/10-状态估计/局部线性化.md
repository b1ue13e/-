# 局部线性化

## 0. 为什么学它

EKF 的线性化只在"当前估计点附近"成立——这句话是 EKF 全部局限的总根源。**偏差一大、非线性一强，一阶近似就崩**：滤波器"自以为在切线上，实际在悬崖边"。理解局部线性化的成立条件与失效情形，才能正确判断"什么时候 EKF 够用、什么时候必须换 UKF/PF"，也是诊断 EKF 发散的第一把钥匙。

## 1. 线性化的有效范围

$$
\mathbf{x} \approx \hat{\mathbf{x}} \Rightarrow f(\mathbf{x}) \approx f(\hat{\mathbf{x}}) + F(\mathbf{x} - \hat{\mathbf{x}})
$$

仅当两个条件同时成立时近似可靠：
1. $\|\mathbf{x} - \hat{\mathbf{x}}\|$ 小（估计误差小）；
2. $f$ 的二阶导数小（弱非线性）。

## 2. 失效情形

| 情形 | 后果 |
|:---|:---|
| 初始误差大 | 线性化点在错误位置 → 估计不收敛（见 [[初始化敏感\|初始化敏感]]） |
| 强非线性（大角度/大曲率） | 一阶近似丢弃重要高阶项 |
| 分布扭曲严重 | 高斯假设本身失效（多峰） |
| 观测剧烈变化 | 雅可比剧变，切线跟不上 |

## 3. 与 UKF / 粒子滤波对比

| 方法 | 传播方式 | 强非线性表现 |
|:---|:---|:---|
| EKF | 一阶线性化传播 | 差（低估不确定性） |
| UKF | Sigma 点精确传播（见 [[无迹变换\|无迹变换]]） | 好（二阶精度） |
| 粒子滤波 | 蒙特卡洛任意分布（见 [[蒙特卡洛\|蒙特卡洛]]） | 最好（任意分布） |

## 4. 最小可手算例子（演示失效）

**题目**：$f(x) = x^3$，在 $\hat{x} = 2$ 处线性化预测 $f(2.5)$，对比真值。

**解**：$f(\hat{x}) = 8$，$F = 3x^2|_2 = 12$：

$$
f(2.5) \approx 8 + 12 \times 0.5 = 14, \qquad \text{真值} = 2.5^3 = 15.625
$$

**解读**：误差 1.625（10%）。若偏差更大（预测 $f(4)$：线性化给 $8+12\times2=32$，真值 64，误差 100%）——**偏差越大、非线性越强（$x^3$ 的二阶项 $6x$ 在增长），线性化越失真**。

## 5. 工程对策

| 对策 | 说明 |
|:---|:---|
| 好初值 | 热启动 / 多初值（见 [[初始化敏感\|初始化敏感]]） |
| 高更新频率 | 缩短线性化区间（预测步距越小近似越好） |
| 换算法 | 强非线性场景换 UKF/PF |
| 增大 $Q$ | 用过程噪声"吸收"线性化误差（粗糙但有效） |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| "EKF 是精确的非线性滤波" | 只是一阶近似，次优；强非线性下误差大 |
| "调参能根治线性化误差" | 调参只能缓解；结构性问题（角度跳变、多峰）需换算法 |
| "UKF 永远比 EKF 好" | UKF 也要高斯假设；且高维下采样点运算成本上升 |
| "局部 = 全局" | 把局部切线当全局模型 = 回到"全局线性化"，状态跑远必炸 |
