# 串级控制

## 0. 为什么学它

单回路控制器面对内层扰动（如电压波动、负载突变）响应滞后。**串级控制**把内层扰动"包进"内环，先快速镇定内环，再让外环从容调节——显著提升扰动抑制能力，是温度/电机/液位控制的进阶结构。

## 1. 核心结构

```
外环: r → E1 → C1 → 内环给定 → E2 → C2 → 被控对象 → y
                ↑                          │
                └──── 外环测量 y1 ←────────┘
```

- **内环（副环）**：快，抑制副对象扰动；
- **外环（主环）**：慢，调主被控量；
- 主调节器输出 = 副调节器给定。

**优势**：内环扰动在进入主对象前被抑制；内环非线性被"包装"使外环近似线性；带宽分层提高整体响应。

## 2. 最小可手算例子（概念验证）

**题目**：加热炉温度控制，燃料压力波动（内扰），对比单回路与串级。

**解**：单回路：压力扰动 → 影响温度 → 主调节器慢慢纠正（滞后大）；串级：压力扰动被内环（流量/压力环）快速抑制，温度几乎不受影响 ✓。

**易错点**：内外环带宽必须分层（否则耦合振荡）；副环测量需可靠。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 串级只是两个 PID 串联 | 外环输出是内环给定，形成嵌套而非串联 |
| 内外环任意分配 | 内环应包住主要快扰动 |
| 内环越快越好 | 受测量噪声/执行器限制 |
