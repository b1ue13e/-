# 试凑法

## 0. 为什么学它

经验公式给出"起点"，最终参数往往靠**试凑微调**：观察阶跃响应，按规律调整 P/I/D，使超调、调节时间、稳态误差达到指标。理解"哪个现象调哪个参数"，是 PID 工程实践的核心手感。

## 1. 整定口诀与调整表

**口诀**：先比例，再积分，后微分；参数从大到小试（或从小到大）。

| 现象 | 调整 |
|:---|:---|
| 响应慢、误差大 | ↑ $K_p$ |
| 超调大、振荡 | ↓ $K_p$ 或 ↑ $K_d$ |
| 稳态误差不为零 | ↓ $T_i$（加强积分）或 ↑ $K_i$ |
| 积分振荡 | ↑ $T_i$ |
| 噪声大 | ↓ $K_d$ 或加滤波 |
| 收敛慢、摇摆 | ↑ $K_d$（加阻尼） |

**流程**：① 置 $K_i=K_d=0$，调 $K_p$ 至"快但可接受振荡"→ ② 加 $K_i$ 消误差（略减 $K_p$）→ ③ 加 $K_d$ 消超调 → ④ 微调收敛。

## 2. 最小可手算例子（决策练习）

**题目**：阶跃响应显示"超调 30%、稳态误差 5%、有高频毛刺"，如何调整？

**解**：超调大 → ↑$K_d$（或 ↓$K_p$）；稳态误差 → ↑$K_i$；毛刺 → ↓$K_d$ 或对测量滤波。三者需平衡：先压毛刺（↓D 或滤波），再补积分，最后微调 P。

**易错点**：一次只调一个参数；调完做一次完整阶跃测试。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 同时调多个参数 | 一次调一个，否则无法归因 |
| 只看超调不看噪声 | D 增大会放大噪声 |
| 无系统流程乱试 | 按"现象→调整"表逐步收敛 |
