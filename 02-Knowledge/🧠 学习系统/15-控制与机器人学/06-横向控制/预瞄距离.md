# 预瞄距离

## 0. 为什么学它

**预瞄（前视）距离 $l_d$** 是几何横向控制器（PP、部分 Stanley）的灵魂参数：它决定"看多远"——太近振荡、太远切弯。理解 $l_d$ 与车速/曲率的关系，是横向控制调参的第一步。

## 1. 核心规则

**基本规则**：前视距离随车速增大：

$$l_d = k\,v + l_{d0},$$

- $k$：预瞄时间（常取 0.5~3 s）；
- $l_{d0}$：最小前视（低速保底）。

**对性能的影响**：

| $l_d$ | 效果 |
|:---|:---|
| 过小 | 收敛快但振荡、噪声敏感 |
| 过大 | 平滑但切弯（弯道内侧）、收敛慢 |
| 与速度匹配 | 各速度下稳定且跟踪良好 |

**弯道修正**：急弯应缩短前视（否则切弯严重），可用曲率修正 $l_d$。

## 2. 最小可手算例子

**题目**：$k=1,\ l_{d0}=2$，$v=10$ 与 $v=30$ 时的 $l_d$。

**解**：$v=10$：$l_d=12$ m；$v=30$：$l_d=32$ m——高速看更远 ✓。

**易错点**：$k$ 单位（秒）；过弯时固定 $l_d$ 会切弯。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| $l_d$ 固定最优 | 应随速度（和曲率）调整 |
| 越大越稳 | 过大切弯 |
| 忽略弯道 | 急弯需缩短前视 |
