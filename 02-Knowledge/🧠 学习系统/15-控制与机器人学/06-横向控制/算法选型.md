# 算法选型

## 0. 为什么学它

PP / Stanley / LQR / MPC 各有优劣，**选型**决定工程项目的成本与性能。本卡给出按**速度、精度、约束、算力、模型可得性**选择横向控制器的决策框架。

## 1. 选型决策表

| 场景 | 推荐 | 理由 |
|:---|:---|:---|
| 低速 AGV/扫地机 | PP | 简单鲁棒、参数少 |
| 低速高精度（循迹车） | Stanley | 收敛快、精度高 |
| 高速无约束（车道保持） | LQR | 模型法、算力小 |
| 高速有约束（避障/限转角） | MPC | 显式处理约束 |
| 模型未知 | PP/Stanley | 几何法不依赖精确模型 |

**权衡维度**：精度 vs 简单性；约束处理 vs 算力；模型依赖 vs 鲁棒性。

## 2. 最小可手算例子（决策练习）

**题目**：高速（120km/h）车道保持 + 执行器转角限制，选什么？

**解**：高速需动力学（几何法排除）；有转角约束 → MPC（显式约束）；算力够则 MPC，否则 LQR+限幅折中。故选 **MPC 横向**（约束是硬需求）。

**易错点**：只看精度忽略约束/算力；低速场景过度设计。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| MPC 永远最好 | 算力/调参成本高，低速没必要 |
| 几何法只有玩具 | 低速工程场景足够 |
| 选型只看精度 | 需综合约束/算力/模型可得性 |
