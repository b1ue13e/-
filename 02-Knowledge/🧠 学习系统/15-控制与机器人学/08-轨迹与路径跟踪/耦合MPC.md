# 耦合MPC

> **一句话**：把纵向 $s$ 和横向 $d$ 放进同一个优化里同时求——耦合 MPC 显式处理纵横向交互，是激烈工况下的"王炸"。

## 0. 为什么学它

解耦控制在常规工况够用，但急刹+转向、换道+减速同时发生时，纵横向共享轮胎附着（摩擦圆），分开设计会互相打架。耦合 MPC 在一个优化里同时决策 $s$ 与 $d$，是阶段 9 MPC 的工程入口。

## 1. 为什么需要耦合

- 摩擦圆耦合：急刹 + 转向同时需求轮胎附着（见[[Frenet耦合]]）；
- 时间耦合：换道+减速同时发生时，纵横向轨迹共享动力学；
- 紧急避障：必须"边减速边转向"。

## 2. 问题建模

以 $(s, d)$ 为状态，Frenet 系下的车辆模型：

$$\mathbf{x} = [s, \dot s, d, \dot d, \delta, \dot\delta]$$

$$\min_{u} \sum_{k=0}^{N-1} \big( \lVert \mathbf{x}_k - \mathbf{x}_{ref,k} \rVert_Q^2 + \lVert u_k \rVert_R^2 \big) + \lVert \mathbf{x}_N - \mathbf{x}_{ref,N} \rVert_P^2$$

$$\text{s.t. } \mathbf{x}_{k+1} = f(\mathbf{x}_k, u_k), \quad \mathbf{x} \in \mathcal{X}, \; u \in \mathcal{U}$$

## 3. 最小可手算例子（摩擦圆约束进优化）

**题目**：某时刻候选解要求 $a_x = 6,\ a_y = 5$，$\mu g = 7.84$。该解是否满足摩擦圆约束？

**步骤**：
1. $a_x^2 + a_y^2 = 36 + 25 = 61$；
2. $(\mu g)^2 = 61.5$；$61 < 61.5$ → **恰好满足**；
3. 若 $a_y = 6$，则 $36+36=72 > 61.5$ → 违反，优化器必须调整（降低 $a_y$ 或 $a_x$）。

**含义**：耦合 MPC 在求解中自动规避这类不可行组合，解耦方案只能事后限幅。

## 4. 关键设计点

| 要素 | 内容 |
|:---|:---|
| 模型 | 纵向 + 横向动力学联合（摩擦圆） |
| 约束 | 加速度/转向角/转向率/摩擦圆 |
| 代价 | 横纵误差 + 控制量 |
| 求解 | QP（线性化）/NLP（非线性） |

## 5. 与解耦控制对比

| 维度 | 解耦 | 耦合 MPC |
|:---|:---|:---|
| 计算量 | 低（10Hz+ 轻松） | 高（20–50Hz 需优化） |
| 耦合处理 | 事后检查 | 显式建模 |
| 工况 | 常规 | 高速/紧急 |
| 调参 | 直观 | 权重矩阵复杂 |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 耦合 MPC 一定更好 | 计算量大、调参复杂；常规工况解耦足够 |
| 线性化后仍叫耦合 | 线性化 MPC 是近似；强非线性需 NMPC |
| 忽略求解实时性 | 20-50Hz 是硬约束，需热启动/稀疏求解（见阶段 9） |

## 7. 工程现状

- 量产：解耦 + MPC 单通道为主；
- 研究/高端：耦合 MPC（非线性 MPC）；
- 混合：纵向独立 MPC + 横向 MPC 共享约束。

## 8. 检索练习（闭卷）

2. 手算摩擦圆约束判定；
