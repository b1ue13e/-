# 速度分配

> **一句话**：给定路径，沿弧长设计速度曲线 $v(s)$——这就是速度分配，是"路径→轨迹"的关键一步。

## 0. 为什么学它

有了路径，还必须决定"哪里加速、哪里减速、弯道限速多少"。速度分配把几何路径变成带速度约束的可行运动，是时间参数化的工程实现。

## 1. 任务定义

输入：路径 $\mathbf{p}(s)$，弧长 $L$
输出：速度曲线 $v(s)$，$s \in [0, L]$
目标：在约束下最小化时间（或满足任务时间）

## 2. 约束集（速度分配的依据）

$$v(s) \le v_{limit}(s) \quad\text{(限速/曲率限速)}$$
$$|a(s)| = |v v'| \le a_{max}$$
$$|j(s)| \le j_{max}$$
$$v(0) = v_0, \quad v(L) = v_f \quad\text{(边界速度)}$$

## 3. 设计流程

1. **上限曲线**：逐点取 $v_{max}(s) = \min(v_{limit}, \sqrt{a_{lat}/\kappa(s)})$；
2. **反向加速检查**：从终点倒推可减速能力 → 确定减速起点；
3. **正向加速检查**：从起点推可加速能力 → 确定加速终点；
4. **拼接**：加速段+巡航段+减速段，保证 $v(s) \le v_{max}(s)$。

## 4. 最小可手算例子（上限曲线 + 梯形拼接）

**题目**：直道 $L=100$ m，限速 $v_{limit}=20$ m/s，$a_{max}=2$ m/s²，起止静止。求加速段长度与巡航段长度。

**步骤**：
1. 加速段长度 $s_a = \dfrac{v_{max}^2}{2a_{max}} = \dfrac{400}{4} = 100$ m；
2. 减速段对称也是 100 m → **恰好没有巡航段**（$s_a + s_d = L$），到达 $v_{max}$ 立即减速；
3. 若 $L=150$ m，则巡航段 $s_c = 150 - 200 < 0$ → 需降速：$v_{peak} = \sqrt{a_{max} L} = \sqrt{300} \approx 17.3$ m/s（三角剖面）。

**含义**：这就是速度分配的"正反扫描+拼接"的核心逻辑（见[[梯形速度]]的临界情况）。

## 5. 典型速度剖面

| 剖面 | 形态 | 适用 |
|:---|:---|:---|
| 梯形 | 匀加-巡航-匀减 | 简单、快 |
| S 曲线 | jerk 受限平滑 | 舒适 |
| 三角 | 无巡航段 | 短距离 |
| 分段限速 | 随 $v_{limit}(s)$ 变化 | 城市道路 |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 只做正向扫描 | 终点减速能力必须反向扫描，否则到终点停不住 |
| 限速只考虑标志 | 曲率限速 $v\le\sqrt{a_{lat}/\kappa}$ 往往更紧 |
| 速度分配完就交付 | 分配后必须重新做可行性检查（轨迹可能超 jerk） |

## 7. 检索练习（闭卷）

1. 写出速度分配的四条约束；
2. 给定 $L,v_{max},a_{max}$ 手算梯形/三角临界；
3. 说明为什么需要反向（终点→起点）检查。

## 8. 通过标准

- 能列出约束集并执行"上限曲线+双向扫描"流程；
- 能手算梯形剖面临界情况；
- 能解释弯道限速触发的速度分配。
