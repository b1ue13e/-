# 横向边界条件

> **一句话**：横向轨迹的端点状态（位置/速度/加速度各 2 个共 6 个）就是"边界条件"——它们决定了多项式系数，也决定了轨迹是否与车辆当前状态衔接。

## 0. 为什么学它

多项式系数完全由边界条件决定（6 个方程 6 个未知数），所以**边界条件错了，轨迹全错**：起点不匹配实测状态，控制器第一拍就追不上；终点条件不对，换道结束还在漂。边界条件是轨迹生成与重规划衔接的关键。

## 1. 六元组

$$(d_0,\; \dot d_0,\; \ddot d_0) \quad \text{起点}, \qquad (d_f,\; \dot d_f,\; \ddot d_f) \quad \text{终点}$$

## 2. 各边界条件来源

| 条件 | 起点（实测/估计） | 终点（设计） |
|:---|:---|:---|
| $d$ | 当前横向偏移 | 目标车道中心 |
| $\dot d$ | 当前横向速度 | 换道结束时 0 |
| $\ddot d$ | 当前横向加速度 | 换道结束时 0 |

## 3. 最小可手算例子（起点不匹配的后果）

**题目**：实际 $\dot d_0 = 0.5$ m/s，但规划时误写为 $0$。用 $T=4,\ \Delta d=3.5$ 的对称换道系数，求 $t=0^+$ 的横向速度偏差。

**步骤**：
1. 对称解 $\dot d(t) = 3a_3 t^2 + 4a_4 t^3 + 5a_5 t^4$，$\dot d(0) = 0$；
2. 实际车以 0.5 m/s 横向漂移，而轨迹假设 0——轨迹第一段与车状态冲突；
3. 后果：控制器追轨迹产生初始横向误差，换道终点偏差放大（尤其高速）。

**含义**：重规划（换道中断）时，起点必须取旧轨迹当前点的实测/估计状态（$C^2$ 衔接），否则轨迹不可执行。

## 4. 边界条件的工程约束

- **起点必须匹配实测状态**：否则生成轨迹一开始就与车辆状态冲突；
- **连续性**：重规划（换道中断）时，新轨迹的起点 = 旧轨迹的当前点，保证 $C^2$；
- **终点设计**：目标点状态由任务决定（换道/避障/回中）。

## 5. 常见场景的终点条件

| 场景 | $d_f$ | $\dot d_f, \ddot d_f$ |
|:---|:---|:---|
| 车道保持 | 车道中心 | 0, 0 |
| 换道 | 相邻车道中心 | 0, 0 |
| 避障偏移 | 障碍旁某偏移 | 0, 0（平行绕行） |
| 回中 | 原车道中心 | 0, 0 |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 起点状态用设计值 | 起点必须是实测/估计的当前状态 |
| 忽略 $\ddot d$ 边界 | 忽略则加速度在端点跳变（jerk 无限） |
| 纵横向 T 不一致 | 合成轨迹必须共享时间轴，否则无法执行 |

## 7. 检索练习（闭卷）

1. 写出横向边界条件六元组；
2. 说明重规划时起点条件如何确定；
3. 解释为何换道终点要求速度/加速度为 0。

## 8. 通过标准

- 能解释起点匹配与 $C^2$ 连续性；
- 能说出常见场景的终点条件。
