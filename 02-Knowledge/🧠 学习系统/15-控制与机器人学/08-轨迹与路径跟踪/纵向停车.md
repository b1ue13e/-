# 纵向停车

> **一句话**：停车 = 规划一条 $s(t)$ 让车辆在精确位置 $s_{stop}$ 以零速度平稳停下——距离精度与舒适性的平衡。

## 0. 为什么学它

停车是最常见也最容易"难受"的动作：急刹伤乘客、停不准伤流程（泊车/等红灯/排队）。本卡给出从"制动距离几何"到"多项式平滑停车"的完整方法链，是停止线规划与泊车的基础。

## 1. 问题描述

$$\text{给定 } s_{stop}, v_0, a_0 \quad \text{求 } s(t): \quad s(T) = s_{stop}, \; \dot s(T) = 0$$

## 2. 停车轨迹方法

### 2.1 制动距离计算（几何）

恒定减速度 $a_{dec}$ 下的制动距离：

$$d_{brake} = \frac{v_0^2}{2 a_{dec}}$$

**减速起点**：$s_{start} = s_{stop} - d_{brake}$。到点即减速，简单但固定减速度（不舒适）。

### 2.2 梯形/S 曲线停车

设计减速剖面（见[[梯形速度]]/[[S曲线规划]]），jerk 受限，平滑停车。

### 2.3 多项式停车轨迹

给定 $(s_0, \dot s_0, \ddot s_0)$ 与 $(s_{stop}, 0, 0)$，用五次多项式求 $s(t)$：

$$s(t) = a_0 + a_1 t + \cdots + a_5 t^5$$

自动平滑减速到 0。

## 3. 最小可手算例子（制动距离）

**题目**：$v_0 = 20$ m/s，$a_{dec} = 4$ m/s²，停止线 $s_{stop} = 100$ m。求制动距离与减速起点。

**步骤**：
1. $d_{brake} = 20^2/(2\times4) = 400/8 = 50$ m；
2. 减速起点 $s_{start} = 100 - 50 = 50$ m——车到 $s=50$ 时开始匀减速，到 $s=100$ 速度恰好为 0；
3. 若在 $s=80$ 才开始减，$d_{brake}=20$ m < 50 m → 到线时仍有速度 → 冲线。

**含义**：减速起点必须由当前速度反推，这就是"提前减速"的量化依据。

## 4. 停车精度来源

| 误差源 | 处理 |
|:---|:---|
| 模型误差（制动器） | 反馈修正 + 前馈（见[[阻力前馈]]） |
| 坡度 | 坡度前馈补偿（见[[坡度前馈]]） |
| 定位误差 | 高精度定位/停车线检测 |
| 执行器延迟 | 提前补偿（见[[执行器时延]]） |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 固定减速度最省事 | 固定减速度起点/终点 jerk 突变，乘客不适 |
| 停车只算几何 | 坡度、延迟、制动器模型都会造成停不准 |
| 高速停车与低速泊车一样 | 高速靠轨迹规划，低速靠末端微调+抱闸 |
