# 纵向跟车

> **一句话**：跟车 = 在 $s$ 轴上保持安全间距的纵向规划——车距太大被插队、太小危险，本质是间距与速度的动态平衡。

## 0. 为什么学它

ACC/跟车是纵向控制最日常的场景。Frenet 纵向规划的跟车版本把"保持间距"转成"在 $s$ 轴上规划一条不侵入安全区间的轨迹"——从"反应式跟随"升级到"预测式规划"，是本阶段与阶段 7（纵向控制）衔接的桥梁。

## 1. 问题建模

前车纵向位置 $s_{lead}(t)$，本车 $s(t)$。目标：保持期望间距。

期望间距（恒定车头时距，见[[恒定车头时距]]）：

$$d_{des}(v) = d_0 + \tau_h v$$

- $d_0$：最小停车间距
- $\tau_h$：车头时距（通常 1.2–2.0 s）
- $v$：本车速度

## 2. 间距误差

$$e_s(t) = s_{lead}(t) - s(t) - d_{des}(v(t))$$

跟车控制目标：$e_s \to 0$（见[[间距误差]]/[[ACC切换逻辑]]）。

## 3. 最小可手算例子（期望间距）

**题目**：$d_0 = 3$ m，$\tau_h = 1.5$ s，本车 $v = 20$ m/s。前车在 $s_{lead} = 100$ m，本车 $s = 50$ m。求期望间距与间距误差。

**步骤**：
1. $d_{des} = 3 + 1.5\times20 = 33$ m；
2. 实际间距 $= 100 - 50 = 50$ m；
3. $e_s = 50 - 33 = +17$ m——间距偏大，应加速靠近（巡航方向）。

**含义**：间距误差的符号直接驱动加速/减速；$\tau_h v$ 项让高速时保持更大间距（安全）。

## 4. 跟车纵向规划

### 4.1 反应式（经典 ACC）

$$a_{des} = k_p e_s + k_d \dot e_s + a_{lead} \text{（前馈）}$$

### 4.2 预测式（轨迹规划）

在预测时域内采样多条 $s(t)$，约束 $s(t) \le s_{lead}(t) - d_{safe}(t)$，按代价选优（见[[轨迹采样]]）。

## 5. 约束

| 约束 | 内容 |
|:---|:---|
| 安全性 | $s_{gap} \ge d_{safe}$（前车急刹也能停住） |
| 舒适性 | $\lVert a \rVert \le a_{max}, \lVert j \rVert \le j_{max}$ |
| 限速 | $v \le \min(v_{set}, v_{limit})$ |
| 串稳定性 | 车距误差不沿车队放大（见[[串稳定性]]） |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 跟车只看距离不看相对速度 | 相对速度决定间距变化率，$e_s$ 与 $\dot e_s$ 都要反馈 |
| 固定间距 | 恒定车头时距让间距随速度伸缩，更安全 |
| 忽略前车急刹 | 安全约束必须保证本车在最坏情况下能停住 |

## 7. 检索练习（闭卷）

1. 写出期望间距公式并解释参数；
2. 手算：$d_0=3,\ \tau_h=1.5,\ v=20$ 的 $d_{des}$ 与 $e_s$；
3. 对比反应式与预测式跟车。

## 8. 通过标准

- 能建模跟车问题并计算间距误差；
- 能列出跟车约束；
- 能解释车头时距的物理意义。
