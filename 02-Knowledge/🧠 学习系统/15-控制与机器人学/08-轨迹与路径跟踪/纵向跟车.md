# 纵向跟车

> **一句话**:跟车 = 在 $s$ 轴上保持安全间距的纵向规划——车距太大被插队,太小危险,本质是间距与速度的动态平衡。

## 问题建模

前车纵向位置 $s_{lead}(t)$,本车 $s(t)$。目标:保持期望间距。

期望间距(恒定车头时距,见[[恒定车头时距]]):

$$d_{des}(v) = d_0 + \tau_h v$$

- $d_0$:最小停车间距
- $\tau_h$:车头时距(通常 1.2–2.0 s)
- $v$:本车速度

## 间距误差

$$e_s(t) = s_{lead}(t) - s(t) - d_{des}(v(t))$$

跟车控制目标:$e_s \to 0$(见[[间距误差]]/[[ACC切换逻辑]])。

## 跟车纵向规划

### 1. 反应式(经典 ACC)
$$a_{des} = k_p e_s + k_d \dot e_s + a_{lead} \text{(前馈)}$$

### 2. 预测式(轨迹规划)
在预测时域内采样多条 $s(t)$,约束 $s(t) \le s_{lead}(t) - d_{safe}(t)$,按代价选优(见[[轨迹采样]])。

## 约束

| 约束 | 内容 |
|:---|:---|
| 安全性 | $s_{gap} \ge d_{safe}$(前车急刹也能停住) |
| 舒适性 | $\|a\| \le a_{max}, \|j\| \le j_{max}$ |
| 限速 | $v \le \min(v_{set}, v_{limit})$ |
| 串稳定性 | 车距误差不沿车队放大(见[[串稳定性]]) |

## 与前车的交互

- 前车减速 → 本车预测到间距不足 → 提前平滑减速
- 前车驶离 → 间距增大 → 恢复巡航(见[[跟随模式]]/[[速度模式]])
- 决策层切换"跟车/巡航/停车"(见[[ACC切换逻辑]])
