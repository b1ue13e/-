# 路径表示

> **一句话**：路径在计算机里有两种主流形态——参数曲线（紧凑、光滑）与离散点序列（通用、直观）。

## 0. 为什么学它

路径规划器输出的是离散点（A* 的栅格路径、RRT 的采样路径），而控制器需要**光滑、可求曲率**的表示。本卡讲清两种表示与互相转换，是"规划 → 平滑 → 控制"链条的中间环节。

## 1. 两类表示

### 1.1 参数曲线表示

$$x = f(s), \quad y = g(s), \quad s \in [s_0, s_1]$$

- 多项式/样条：三次多项式、五次多项式、Bézier、B 样条；
- 优点：解析光滑、可求导得曲率、存储紧凑；
- 缺点：复杂形状需分段拼接，分段点要满足 $C^2$ 连续。

### 1.2 离散点序列表示

$$\{ \mathbf{p}_0, \mathbf{p}_1, \dots, \mathbf{p}_N \}, \quad \mathbf{p}_k = (x_k, y_k)$$

- 栅格路径、采样路径（A*、RRT 输出）天然是离散点；
- 优点：任意形状、与传感器/地图直接对接；
- 缺点：不光滑，需插值/平滑后才能供控制使用。

## 2. 表示要素

| 要素 | 内容 | 用途 |
|:---|:---|:---|
| 位置 | $(x(s), y(s))$ | 几何形状 |
| 航向 | $\theta(s)$ | 方向信息 |
| 曲率 | $\kappa(s)$ | 可转向性 |
| 弧长 | $s$ | 参数化基准 |

## 3. 最小可手算例子（样条曲率）

**题目**：三次样条段 $y = \frac{1}{6}s^3$，求 $s=2$ 处的曲率（近似，取 $x=s$）。

**步骤**：
1. 一阶导 $y' = \frac{1}{2}s^2 = 2$；二阶导 $y'' = s = 2$；
2. 曲率 $\kappa = \dfrac{y''}{(1+y'^2)^{3/2}} = \dfrac{2}{(1+4)^{3/2}} = \dfrac{2}{5\sqrt{5}} \approx 0.179$。

**含义**：曲率 $\kappa$ 直接决定转向角需求（见[[曲率约束]]）——这是路径表示必须能求出曲率的原因。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 认为三次样条一定通过原离散点 | 三次样条插值通过全部点；B 样条是逼近，不一定通过控制点 |
| 把曲率与曲率变化率混为一谈 | 曲率 $\kappa$ 表示转弯急缓；曲率变化率 $\dot\kappa$ 表示转向是否平滑 |
| 离散路径直接发给控制器 | 离散点之间的插值方式（线性=曲率不连续）会引入抖动 |

## 5. 常见样条选择

- **三次样条**：分段三次多项式，$C^2$ 连续，工程标配；
- **五次多项式**：端点加加速度连续，换道/变道常用；
- **B 样条**：局部修改、凸包性质，全局平滑。

## 6. 检索练习（闭卷）

1. 离散路径为何不能直接控制？如何转换？
2. 三次样条保证什么级别的连续性？B 样条呢？
3. 写出曲率公式，并用手算验证一个简单曲线的 $\kappa$。

## 7. 通过标准

- 能说清两类表示的优缺点与适用场景；
- 能从参数曲线求出曲率；
- 能解释离散→样条的转换流程。
