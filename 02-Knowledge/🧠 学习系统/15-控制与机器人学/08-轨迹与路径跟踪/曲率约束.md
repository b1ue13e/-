# 曲率约束

> **一句话**：方向盘只能转有限角度 → 轨迹曲率有上限 → 转弯时速度必须降低。这是运动学对轨迹的最基本约束。

## 0. 为什么学它

曲率约束贯穿规划全流程：路径平滑要检查它、轨迹可行性要检查它、弯道限速由它决定。它是"几何上画得出、物理上转不过去"这道坎的数学表达。

## 1. 转向角 → 曲率（自行车模型）

$$\kappa_{max} = \frac{\tan\delta_{max}}{L}$$

- $\delta_{max}$：最大转向角（约 30–40°）；
- $L$：轴距；
- 曲率上限 $\kappa_{max}$：车辆"能弯多急"的物理极限。

## 2. 轨迹侧的曲率约束

任何轨迹必须满足：

$$\kappa(s) \le \kappa_{max} = \frac{\tan\delta_{max}}{L}$$

若横向规划生成 $d(s)$ 导致合成曲率超限 → 轨迹不可行（见[[轨迹可行性]]/[[Frenet曲率]]）。

## 3. 曲率 → 限速（侧向动力学）

转弯时侧向加速度：$a_{lat} = v^2 \kappa$

轮胎附着约束 $a_{lat} \le a_{lat,max}$ → **曲率限速**：

$$v_{max}(s) = \sqrt{\frac{a_{lat,max}}{\kappa(s)}}$$

这是弯道速度分配的核心公式（见[[速度限制]]/[[速度分配]]）。

## 4. 最小可手算例子

**题目**：轴距 $L = 2.8$ m，$\delta_{max} = 35°$。求 $\kappa_{max}$，并求该极限下 $a_{lat,max}=4$ 时的限速。

**步骤**：
1. $\kappa_{max} = \tan35°/2.8 = 0.700/2.8 \approx 0.25\ \text{m}^{-1}$（转弯半径 4 m）；
2. $v_{max} = \sqrt{4/0.25} = 4$ m/s（≈14 km/h）；
3. 含义：即使车辆能转 35°，为了不侧滑，这个弯只能 14 km/h 通过。

**易错点**：$\kappa_{max}$ 与限速是两回事——前者运动学极限，后者侧向动力学约束。

## 5. 曲率连续性

- 曲率突变 = 转向角阶跃（方向盘猛打）→ 必须避免；
- 轨迹规划要求曲率连续（$C^2$ 路径）；
- 样条平滑的目的之一就是控制曲率变化率。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 曲率检查只对路径 | 合成轨迹曲率（含横向 $d''$）也要查（见[[Frenet曲率]]） |
| 转向角越大越好 | 大转向角 → 大 $\kappa_{max}$，但侧滑限速仍制约 |
| 曲率约束只限制最大值 | 曲率连续性（变化率）同样关键 |

## 7. 工程要点

| 场景 | 曲率约束作用 |
|:---|:---|
| 路径平滑 | 剔除曲率超限候选 |
| 速度分配 | 弯道限速 |
| 换道规划 | 检查合成曲率 |
| 参考线 | 急弯参考线本身可能超限 |
