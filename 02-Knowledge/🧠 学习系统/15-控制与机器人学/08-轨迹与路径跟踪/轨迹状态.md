# 轨迹状态

> **一句话**：轨迹上每个点都是一个"快照"——位置、航向、速度、加速度、时刻，打包成一个状态向量。

## 0. 为什么学它

控制器在每个控制周期只能消费"一个参考点"。把轨迹离散成**状态向量序列**，是轨迹库采样、可行性检查、控制器查询的共同数据结构。本卡定义笛卡尔与 Frenet 两套状态表示及其互换关系。

## 1. 笛卡尔状态向量

$$\mathbf{q}(t) = \big[ x(t),\; y(t),\; \theta(t),\; v(t),\; a(t) \big]$$

| 分量 | 含义 | 来源 |
|:---|:---|:---|
| $x, y$ | 全局位置 | 几何 |
| $\theta$ | 航向角 | 路径切线角 |
| $v$ | 线速度 | 速度分配 |
| $a$ | 加速度 | 速度曲线导数 |

更高阶可加：转向角 $\delta$、转向率 $\dot\delta$、jerk $j$。

## 2. Frenet 状态向量（规划常用）

$$\mathbf{q}_{F}(t) = \big[ s(t), \dot{s}(t), \ddot{s}(t),\; d(t), \dot{d}(t), \ddot{d}(t) \big]$$

- 纵向 $(s, \dot s, \ddot s)$：沿参考线；
- 横向 $(d, \dot d, \ddot d)$：垂直参考线；
- 好处：纵横向解耦，各用一维多项式描述（见[[Frenet纵向]]/[[Frenet横向]]）。

## 3. 最小可手算例子（笛卡尔 ↔ Frenet 片段）

**题目**：参考线为 $x$ 轴（$s$ 即 $x$，$d$ 即 $y$）。点 $P=(4, 3)$ 以航向 $45°$、速度 $5\sqrt{2}$ 运动。写出该点 Frenet 状态与笛卡尔速度分量。

**步骤**：
1. $s = 4,\ d = 3$（沿参考线弧长与横向偏移）；
2. 纵向速度 $\dot s = v\cos\theta = 5\sqrt2 \cdot \tfrac{\sqrt2}{2} = 5$；横向速度 $\dot d = v\sin\theta = 5$；
3. 笛卡尔速度 $(v_x, v_y) = (5, 5)$——与 $\dot s,\dot d$ 在此特例相等（参考线沿 x 轴时）。

**含义**：Frenet 把"沿路快慢"与"偏离路多少"分开，正是轨迹规划想要的坐标。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| Frenet 的 $s$ 等于 $x$ | 仅在参考线为直线且沿 x 轴时成立；弯曲参考线上 $s$ 是弧长 |
| 忽略航向在转换中的作用 | $\dot s, \dot d$ 与 $v$ 的关系依赖 $\theta$ 与参考线切线角之差 |
| 采样轨迹状态不含时间 | 状态向量序列必须等间隔时间戳，否则控制器无法同步 |

## 5. 状态向量完整性

一条轨迹的完整性 = 是否在每个 $t$ 给出控制器所需全部参考：

| 控制器 | 需要 |
|:---|:---|
| 纵向 PI | $v_{ref}(t), a_{ref}(t)$ |
| Stanley | $\theta_{ref}(s), \kappa(s)$ |
| MPC | 全状态 $[x,y,\theta,v,\delta]$ |

## 6. 检索练习（闭卷）

1. 写出笛卡尔与 Frenet 状态向量并说明各分量含义；
2. 在参考线为 x 轴时，手算一点的位置/速度转换；
3. 说明为什么 MPC 需要全状态参考而纵向 PI 只需要速度/加速度。

## 7. 通过标准

- 能写出两套状态向量并互相转换（直线参考线特例）；
- 能说明不同控制器需要哪些状态分量；
- 理解状态向量离散采样是轨迹库的基础。
