# 横向避障

> **一句话**：横向避障 = 在 $d$ 方向绕开障碍物——要么采样多条横向偏移轨迹选安全的，要么把障碍区间作为约束做优化。

## 0. 为什么学它

自动驾驶最核心的安全场景就是避障。Frenet 系的优势在于：障碍物天然表达为"某个 $s$ 区间内 $d$ 被占用"，避障退化为"生成不穿过占用区间的 $d(t)$ 轨迹"——把三维时空避障降成了两个一维筛选。

## 1. 问题描述

Frenet 系中障碍物投影为 $s$ 轴上的占用区间 + 横向边界：

$$\text{障碍 } i: s \in [s_i^- , s_i^+], \quad d \notin [d_i^- , d_i^+]$$

## 2. 两种主流方法

### 2.1 采样法（工程主流）

采样多条横向轨迹（不同 $(d_f, T)$），剔除与障碍碰撞的，按代价选优（见[[轨迹采样]]）：

```
for (d_f, T) in 采样网格:
    d(t) = 五次多项式(边界, d_f, T)
    if 与障碍相交: 剔除
    计算代价 J(d(t))
选 J 最小者
```

### 2.2 约束优化法

把避障写为约束，直接求解：

$$d(t) \le d_{safe}^-(t) \quad \text{或} \quad d(t) \ge d_{safe}^+(t)$$

（绕行方向由决策层指定：左绕还是右绕）

## 3. 最小可手算例子（采样剔除）

**题目**：障碍占用 $s \in [30, 40]$、$d \in [-1, 1]$。候选轨迹 A：$d_f = 2.5$（右绕），轨迹 B：$d_f = 0.5$。判断可行性。

**步骤**：
1. 轨迹 A 全程 $d(t) \ge 2.5 \cdot$ 形状（从 0 平滑到 2.5），在 $s\in[30,40]$ 段 $d > 1$ → 不进入障碍 $d$ 区间 → **可行**；
2. 轨迹 B 目标 $d_f=0.5$，从 0 变到 0.5 始终在 $[-1,1]$ 内 → 与障碍 $d$ 区间相交 → **剔除**；
3. 结论：采样法"生成→剔除→选优"，安全筛选在代价排序之前。

**易错点**：只检查终点 $d_f$ 不够——全程 $d(s)$ 都可能侵入障碍区间，必须逐点检查。

## 4. 障碍膨胀与安全裕量

- 障碍物按车宽/半宽**膨胀**，保证车身不擦碰；
- 横向安全距离：$\pm(\text{车宽}/2 + \text{裕量})$；
- 动态障碍（他车）还要考虑时间窗口（见[[轨迹采样]]）。

## 5. 决策与轨迹分层

| 层 | 职责 | 输出 |
|:---|:---|:---|
| 决策层 | 选左绕/右绕/跟停 | 绕行方向 |
| 规划层 | 生成候选轨迹 | 多条 $d(t)$ |
| 评估层 | 代价排序 + 安全筛选 | 最优轨迹 |

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 只看终点 $d_f$ 是否避开 | 全程 $d(s)$ 都可能侵入，必须逐点碰撞检测 |
| 障碍不膨胀直接规划 | 车有宽度，必须按车宽+裕量膨胀 |
| 静态障碍与动态障碍同等处理 | 动态障碍需时间窗口（$s$-$t$ 联合考虑），静态只看 $s$ 区间 |

2. 手算一个采样剔除例子；
3. 说明车辆尺寸如何纳入避障。

## 8. 通过标准

- 能说明采样法的完整流程；
- 能解释膨胀与动态障碍的时间维度。
