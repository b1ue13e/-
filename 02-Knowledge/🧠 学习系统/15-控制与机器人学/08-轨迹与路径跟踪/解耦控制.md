# 解耦控制

> **一句话**:方向盘管横向($d_{error}$),油门刹车管纵向($s_{error}$)——两条通道各自闭环,是工程上最主流的轨迹跟踪架构。

## 架构

```
参考轨迹 ─┬→ 横向通道: d_error → Stanley/LQR → 转向角 δ
          └→ 纵向通道: s_error → PI/前馈 → 加速度 a
```

## 横向通道(转向)

| 控制器 | 误差 → 转向 |
|:---|:---|
| Pure Pursuit | 几何预瞄(见[[PP算法]]) |
| Stanley | $d_{error} + \theta_{error}$ 组合(见[[Stanley公式]]) |
| LQR 横向 | 状态反馈(见[[LQR横向状态]]) |

## 纵向通道(油门/刹车)

$$a_{des} = k_p \dot s_{error} + k_i \int \dot s_{error} + a_{ff}$$

- PI 速度控制(见[[PI速度控制]])
- 前馈:参考加速度/阻力/坡度(见[[参考前馈]]/[[阻力前馈]]/[[坡度前馈]])
- 抗饱和(见[[速度控制抗饱和]])

## 解耦的合理性

- 纵横向动力学时间尺度差异大(转向快、加减速慢)
- 轮胎耦合在小侧偏角下弱(见[[线性轮胎]])
- Frenet 坐标天然正交化(见[[Frenet耦合]])

## 局限与补救

| 局限 | 补救 |
|:---|:---|
| 忽略摩擦圆耦合 | 事后检查 + 限幅 |
| 高速强耦合 | 耦合 MPC(见[[耦合MPC]]) |
| 紧急避障 | 纵向先减速再转向 |
