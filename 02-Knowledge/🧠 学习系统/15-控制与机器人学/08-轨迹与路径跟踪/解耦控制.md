# 解耦控制

> **一句话**：方向盘管横向（$d_{error}$），油门刹车管纵向（$s_{error}$）——两条通道各自闭环，是工程上最主流的轨迹跟踪架构。

## 0. 为什么学它

阶段 6（横向）与阶段 7（纵向）分别学的控制器，在这里被组合成完整的轨迹跟踪架构。理解"解耦"的合理性与局限，才能判断何时够用、何时必须上耦合 MPC。

## 1. 架构

```
参考轨迹 ─┬→ 横向通道: d_error → Stanley/LQR → 转向角 δ
          └→ 纵向通道: s_error → PI/前馈 → 加速度 a
```

## 2. 横向通道（转向）

| 控制器 | 误差 → 转向 |
|:---|:---|
| Pure Pursuit | 几何预瞄（见[[PP算法]]） |
| Stanley | $d_{error} + \theta_{error}$ 组合（见[[Stanley公式]]） |
| LQR 横向 | 状态反馈（见[[LQR横向状态]]） |

## 3. 纵向通道（油门/刹车）

$$a_{des} = k_p \dot s_{error} + k_i \int \dot s_{error} + a_{ff}$$

- PI 速度控制（见[[PI速度控制]]）；
- 前馈：参考加速度/阻力/坡度（见[[参考前馈]]/[[阻力前馈]]/[[坡度前馈]]）；
- 抗饱和（见[[速度控制抗饱和]]）。

## 4. 最小可手算例子（通道分工）

**题目**：参考轨迹点 $d_{ref}=0,\ s_{ref}=100$；车辆 $d_{cur}=0.3,\ s_{cur}=95,\ v=18,\ v_{ref}=20$。给出两通道各自输入。

**步骤**：
1. 横向：$d_{error} = -0.3$（右偏 0.3 m）→ 横向控制器算转向角 $\delta$；
2. 纵向：$\dot s_{error} = 20-18 = 2$ m/s → PI 算 $a_{des} > 0$（加速）；
3. 输出：$( \delta, a_{des})$ 分别下发给转向与驱动。

**含义**：两通道互不依赖，各自闭环——这就是解耦架构的日常执行形态。

## 5. 解耦的合理性

- 纵横向动力学时间尺度差异大（转向快、加减速慢）；
- 轮胎耦合在小侧偏角下弱（见[[线性轮胎]]）；
- Frenet 坐标天然正交化（见[[Frenet耦合]]）。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 解耦无耦合错误 | 摩擦圆耦合真实存在，需事后检查+限幅 |
| 横向只看 $d_{error}$ | 航向误差 $\theta_{error}$ 同样重要（Stanley 双项） |
| 解耦适用于一切工况 | 高速/紧急避障需耦合 MPC（见[[耦合MPC]]） |

## 7. 局限与补救

| 局限 | 补救 |
|:---|:---|
| 忽略摩擦圆耦合 | 事后检查 + 限幅 |
| 高速强耦合 | 耦合 MPC（见[[耦合MPC]]） |
| 紧急避障 | 纵向先减速再转向 |

## 8. 检索练习（闭卷）

1. 画出解耦控制架构；
2. 手算一个两通道输入分解；
3. 说明解耦的适用条件与补救。

## 9. 通过标准

- 能画出并解释双通道架构；
- 能选择横向控制器与纵向控制器；
- 能说明解耦局限及补救。
