# d坐标

> **一句话**：$d$ 是到参考线的垂直距离（带符号）——Frenet 系里的"横向位置"，正值在参考线左侧。

## 0. 为什么学它

横向控制（阶段 6）与横向规划（本阶段）的共同语言就是 $d$：车道保持是"让 $d$ 回到 0"，换道是"让 $d$ 平滑地从 0 变到车道宽"。$d$ 是连接"规划"与"控制"的误差量。

## 1. 定义

$$d = \text{sign}(d) \cdot \lVert \mathbf{p} - \mathbf{r}(s) \rVert$$

- $\mathbf{p}$：当前点
- $\mathbf{r}(s)$：投影点
- 符号约定：沿参考线前进方向，**左正右负**（可配置）

## 2. 性质

| 性质 | 说明 |
|:---|:---|
| 有符号距离 | 左正右负（常用约定） |
| 车道内约束 | 车道宽 $W$ → $d \in [-W/2, W/2]$ |
| 由投影给出 | 最近点投影（见[[Frenet转换]]） |

## 3. 横向运动学

- 横向偏移：$\dot{d}$
- 横向加速度：$\ddot{d}$
- 横向 jerk：$\dddot{d}$

## 4. 最小可手算例子（符号与车道边界）

**题目**：参考线为 x 轴，车在点 $(0, -1.5)$。车道宽 $W = 3.5$ m（$d \in [-1.75, 1.75]$）。求 $d$ 并判断是否越界。

**步骤**：
1. 投影点 $(0,0)$；$d = -1.5$（右偏为负，约定成立）；
2. 边界：$|d| = 1.5 < 1.75$ → 未越界；
3. 若 $d = -1.9$，则越界——横向规划必须把 $d$ 限制在 $[-1.75, 1.75]$ 内（见[[横向边界条件]]）。

**含义**：$d$ 的符号与边界约束直接指导"往哪修"和"能修多少"。

## 5. 用途

| 场景 | d 的用法 |
|:---|:---|
| 车道保持 | 控制 $d \to 0$（或车道中心） |
| 换道 | $d$：$0 \to \pm W$（横向多项式，见[[横向多项式]]） |
| 避障 | 障碍物占用 $d$ 区间，避开（见[[横向避障]]） |
| 边界 | 车道边界约束 $d_{min} \le d \le d_{max}$ |

## 6. 直觉

- $d$ 就是"方向盘要不要回正"的依据：车偏左(d>0)就往右修；
- 横向控制误差在 Frenet 系里正是 $d_{error}$（见[[Frenet误差]]）；
- 换道规划本质是设计 $d(s)$ 从当前值平滑过渡到目标车道。

## 7. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 忘记 $d$ 带符号 | 无符号只能知道距离不知道方向，无法驱动控制 |
| 把 $d$ 当转向角 | $d$ 是位置偏差；转向角要经曲率换算（见[[Frenet横向]]） |
| 忽略车道宽约束 | 越界 $d$ 导致压线/出界，规划必须显式约束 |

## 8. 检索练习（闭卷）

1. 写出 $d$ 的定义与符号约定；
2. 手算：参考线为 x 轴，点 $(4,2)$ 的 $d$；
3. 说明车道保持与换道对 $d$ 的不同目标。

## 9. 通过标准

- 能计算带符号横向偏移并判断是否越界；
- 能列出 $d$ 的典型用途；
- 能区分 $d$ 与转向角。
