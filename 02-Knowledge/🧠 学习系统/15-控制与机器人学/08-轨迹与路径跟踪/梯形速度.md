# 梯形速度

> **一句话**:速度按"匀加速→匀速→匀减速"三段走,剖面像梯形,是最简单实用的速度规划。

## 剖面结构

$$v(t) = \begin{cases} a_{max} t & 0 \le t \le t_a \\ v_{max} & t_a \le t \le t_a+t_c \\ v_{max} - a_{max}(t-t_a-t_c) & \text{减速段} \end{cases}$$

三段时间:加速 $t_a = v_{max}/a_{max}$、匀速 $t_c$、减速 $t_d$。

## 位移公式

总位移 = 梯形面积:

$$L = \frac{v_{max}^2}{a_{max}} + v_{max} t_c \quad (\text{起止静止})$$

给定 $L, v_{max}, a_{max}$,解得匀速时间:

$$t_c = \frac{L}{v_{max}} - \frac{v_{max}}{a_{max}}$$

## 临界情况

| 情况 | 条件 | 处理 |
|:---|:---|:---|
| 有匀速段 | $L > v_{max}^2/a_{max}$ | 标准梯形 |
| 无匀速段(三角) | $L = v_{max}^2/a_{max}$ | 刚到 $v_{max}$ 就减速 |
| 距离不足 | $L < v_{max}^2/a_{max}$ | 降速 $v_{max}' = \sqrt{L a_{max}}$ |

## 优缺点

- ✅ 实现简单、计算快、控制直观(三段时间可解析)
- ❌ 加速度阶跃突变(jerk 无穷大)→ 冲击、舒适性差
- 改进:拐角处加圆角 = S 曲线(见[[S曲线规划]])

## 工程实现

```
输入 L, v_max, a_max
t_a = v_max / a_max
if L >= v_max * t_a:   # 有巡航
    t_c = L/v_max - t_a
else:                  # 三角剖面
    v_peak = sqrt(L * a_max)
    重建三段
```
