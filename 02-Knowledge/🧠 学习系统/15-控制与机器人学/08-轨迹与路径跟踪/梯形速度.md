# 梯形速度

> **一句话**：速度按"匀加速→匀速→匀减速"三段走，剖面像梯形，是最简单实用的速度规划。

## 0. 为什么学它

梯形剖面把速度规划压缩成三个解析可算的时间参数（加速/匀速/减速），是电机运动控制与车辆纵向规划的**默认起点**；S 曲线（见[[S曲线规划]]）只是它的"圆角"版本。

## 1. 剖面结构

$$v(t) = \begin{cases} a_{max} t & 0 \le t \le t_a \\ v_{max} & t_a \le t \le t_a+t_c \\ v_{max} - a_{max}(t-t_a-t_c) & \text{减速段} \end{cases}$$

三段时间：加速 $t_a = v_{max}/a_{max}$、匀速 $t_c$、减速 $t_d$。

## 2. 位移公式

总位移 = 梯形面积：

$$L = \frac{v_{max}^2}{a_{max}} + v_{max} t_c \quad (\text{起止静止})$$

给定 $L, v_{max}, a_{max}$，解得匀速时间：

$$t_c = \frac{L}{v_{max}} - \frac{v_{max}}{a_{max}}$$

## 3. 最小可手算例子

**题目**：$L=60$ m，$v_{max}=12$ m/s，$a_{max}=2$ m/s²，起止静止。求 $t_a, t_c, t_d$ 与总时间。

**步骤**：
1. $t_a = v_{max}/a_{max} = 6$ s，$t_d = 6$ s；
2. 加速/减速段位移各 $\tfrac12 a t_a^2 = \tfrac12 \cdot 2 \cdot 36 = 36$ m，合计 72 m > 60 m；
3. $t_c = \dfrac{L}{v_{max}} - \dfrac{v_{max}}{a_{max}} = 5 - 6 = -1 < 0$ → **距离不足**；
4. 降级为三角剖面：$v_{peak} = \sqrt{L a_{max}} = \sqrt{120} \approx 10.95$ m/s，$t_{总} = 2v_{peak}/a_{max} \approx 10.95$ s。

**含义**：$t_c<0$ 是"距离不足"的判据，必须降速（见下方临界情况表）。

## 4. 临界情况

| 情况 | 条件 | 处理 |
|:---|:---|:---|
| 有匀速段 | $L > v_{max}^2/a_{max}$ | 标准梯形 |
| 无匀速段（三角） | $L = v_{max}^2/a_{max}$ | 刚到 $v_{max}$ 就减速 |
| 距离不足 | $L < v_{max}^2/a_{max}$ | 降速 $v_{max}' = \sqrt{L a_{max}}$ |

## 5. 优缺点

- ✅ 实现简单、计算快、控制直观（三段时间可解析）；
- ❌ 加速度阶跃突变（jerk 无穷大）→ 冲击、舒适性差；
- 改进：拐角处加圆角 = S 曲线（见[[S曲线规划]]）。

## 6. 工程实现伪码

```
输入 L, v_max, a_max
t_a = v_max / a_max
if L >= v_max * t_a:   # 有巡航
    t_c = L/v_max - t_a
else:                  # 三角剖面
    v_peak = sqrt(L * a_max)
    重建三段
```

## 7. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 直接令 $t_c = L/v_{max} - t_a$ 得到负数仍用 | 负匀速时间 = 距离不足，必须降速 |
| 忘记起止速度不一定为零 | 边界速度非零时位移公式要加 $\tfrac{v_0+v_f}{2}\cdot$ 项修正 |
| 认为梯形已足够舒适 | 加速度阶跃对乘客/机械有冲击，高速场景要 S 曲线 |

## 8. 检索练习（闭卷）

1. 推导 $t_c = L/v_{max} - v_{max}/a_{max}$；
2. 判断 $L=40, v_{max}=10, a_{max}=2$ 属于哪种剖面并算 $v_{peak}$；
3. 说明梯形剖面的主要缺陷与改进。

## 9. 通过标准

- 能写出三段式剖面与位移公式；
- 能处理距离不足的三角降级；
- 能说出梯形与 S 曲线的关系。
