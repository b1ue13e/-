# Frenet横向

> **一句话**：横向运动就是描述 $d$ 如何变化——车道保持（不动）与换道（平滑过渡）是两个典型模式。

## 0. 为什么学它

横向运动是"把车移到正确车道上"的动作：车道保持让 $d$ 稳定，换道让 $d$ 平滑跨越一个车道宽。横向规划的输出（$d(t)$ 曲线）最终要转成转向指令，是横向控制的参考来源。

## 1. 横向状态

$$[d(t),\; \dot{d}(t),\; \ddot{d}(t)]$$

- $d$：横向偏移
- $\dot{d}$：横向速度
- $\ddot{d}$：横向加速度

## 2. 横向规划模式

### 2.1 车道保持

$$d(t) \equiv d_{ref}(\text{车道中心或当前值}), \quad \dot d = \ddot d = 0$$

### 2.2 换道（横向多项式）

用五阶多项式连接当前横向状态与目标横向状态（见[[横向多项式]]）：

$$d(t) = a_0 + a_1 t + \cdots + a_5 t^5$$

边界：$(d_0, \dot d_0, \ddot d_0) \to (d_f, 0, 0)$，换道宽度 $\Delta d = d_f - d_0$。

### 2.3 避障偏移

临时偏出当前车道再回来（见[[横向避障]]）。

## 3. 最小可手算例子（三次简化换道）

**题目**：换道 $\Delta d = 3.5$ m（一个车道宽），$T = 4$ s，用三次多项式 $d(t) = b_2 t^2 + b_3 t^3$（起止 $\dot d = 0$，$d(0)=0$）。求 $b_2, b_3$ 与中点位移。

**步骤**：
1. $\dot d = 2b_2 t + 3b_3 t^2$；$\dot d(0) = 0$ ✓（无 $b_1$ 项）；
2. $\dot d(T) = 2b_2 T + 3b_3 T^2 = 0$；$d(T) = b_2 T^2 + b_3 T^3 = 3.5$；
3. 解（$T=4$）：$8b_2 + 48b_3 = 0$ 且 $16b_2 + 64b_3 = 3.5$ → $b_2 = \tfrac{21}{32} \approx 0.656$，$b_3 = -\tfrac{7}{64} \approx -0.109$；
4. 中点 $t=2$：$d(2) = 0.656\cdot4 - 0.109\cdot8 \approx 1.75$ m（恰为半车道宽，S 形对称 ✓）。

**含义**：换道轨迹是 S 形——先加速偏离再减速归位，两端切向速度为零。

## 4. 横向代价与约束

- 最小 jerk：$J = \int \dddot{d}^2 dt$（舒适，见[[横向优化]]）
- 车道边界：$d_{min} \le d \le d_{max}$
- 横向加速度：$|\ddot d| \le a_{lat,max}$

## 5. 横向 vs 转向

注意：**横向运动 $d$ 不是直接转向角**。$d$ 通过曲率/航向与转向相关：

$$\kappa \approx \frac{d''}{(1-\kappa_r d)^2} + \kappa_r, \quad \delta = \arctan(L\kappa)$$

横向规划 → 曲率 → 转向角（见[[曲率约束]]）。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 把 $d(t)$ 直接当转向角 | 需经曲率公式换算，还要考虑轴距 $L$ |
| 换道轨迹用直线插值 | 直线在端点有速度突变，必须用多项式平滑过渡 |
| 忽略横向加速度约束 | 换道过快横向 $a$ 超限 → 乘客不适/侧滑 |

## 7. 检索练习（闭卷）

1. 写出横向状态三量与三种规划模式；
2. 手算三次简化换道的系数与中点位移；
3. 说明 $d$ 到转向角 $\delta$ 的换算路径。

## 8. 通过标准

- 能区分车道保持/换道/避障三种横向模式；
- 能手算简化换道多项式；
- 能解释横向规划 → 曲率 → 转向的链路。
