# 轨迹定义

> **一句话**：轨迹 = 路径 + 时间表，回答"什么时刻在哪个位置、以什么速度"。

## 0. 为什么学它

控制器（PID/MPC）需要的是**随时间变化的参考**：$x_{ref}(t), v_{ref}(t)$。只有路径时不知道"该开多快"，无法跟踪。轨迹定义是本阶段从"规划"跨到"执行"的概念桥梁。

## 1. 核心定义

**轨迹**是带时间参数的状态序列：

$$\mathcal{T} = \{ \mathbf{q}(t) \in \mathcal{C} \mid t \in [t_0, t_f] \}$$

- $\mathbf{q}(t)$：时刻 $t$ 的广义状态（位置/航向/速度等）；
- $\mathcal{C}$：构型空间（C-space）；
- $t_0, t_f$：起止时刻。

**与路径的关系**：

$$\text{路径} \;\xrightarrow{\text{速度分配}}\; \text{轨迹}$$

给定路径 $\mathbf{p}(s)$ 与速度曲线 $v(s)$，可得 $s(t)$ → 轨迹 $\mathbf{p}(s(t))$。

## 2. 轨迹的三要素

| 要素 | 内容 | 例子 |
|:---|:---|:---|
| 几何 | 走哪条线 | 换道路径 |
| 运动学 | 多快、加速度多大 | 速度/加速度曲线 |
| 时间 | 何时到哪 | 到达时刻 $t_f$ |

## 3. 最小可手算例子（路径 → 轨迹）

**题目**：路径 $\mathbf{p}(s) = (s, 0)$，$s\in[0,10]$；速度曲线 $v(s) = 2$（匀速）。求轨迹 $\mathbf{p}(t)$ 与到达时间。

**步骤**：
1. 时间参数化：$\dot s(t) = v = 2 \Rightarrow s(t) = 2t$（$s(0)=0$）；
2. 代入：$\mathbf{p}(t) = (2t, 0)$，$t \in [0, 5]$；
3. 到达时间 $t_f = L/v = 10/2 = 5$ s。

**对照**：若 $v = 5$，则 $\mathbf{p}(t)=(5t,0)$、$t_f=2$ s——**同一路径、不同轨迹**。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 轨迹与路径混用 | 轨迹带时间，路径不带；控制器只吃轨迹 |
| 认为轨迹只需位置 | 还要速度/加速度参考（跟踪误差定义需要） |
| 忽略起止状态 | 轨迹起点必须匹配当前实测状态，否则一开始就追不上 |

## 5. 轨迹类型

- **时间最优**：$t_f$ 最小（见[[时间最优]]）；
- **舒适**：jerk 受限（见[[jerk约束]]）；
- **任务约束**：定时到达、停车对齐（见[[停止线规划]]）。

## 6. 检索练习（闭卷）

1. 用集合记号写出轨迹定义，并标注与路径的数学差异；
2. 给定路径与速度曲线，写出由路径构造轨迹的步骤；
3. 说明为什么控制器需要轨迹而非路径。

## 7. 通过标准

- 能区分轨迹与路径并互相转换；
- 能说明轨迹三要素；
- 能举出同一路径对应多条轨迹的例子。
