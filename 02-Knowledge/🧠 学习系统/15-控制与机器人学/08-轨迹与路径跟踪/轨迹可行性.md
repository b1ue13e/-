# 轨迹可行性

> **一句话**：一条轨迹"画得出来"不等于"开得了车"——必须满足机器人的运动学、动力学与执行器约束。

## 0. 为什么学它

轨迹库方法一次生成几十条候选轨迹，绝大多数**不可行**（曲率太急、加速度超限、撞障碍）。可行性检查是候选轨迹的筛选器——跳过它，控制器会超调、侧滑或抖振。

## 1. 可行性层级

| 层级 | 约束 | 检查内容 |
|:---|:---|:---|
| 几何可行 | 无碰撞 | 不与障碍相交 |
| 运动学可行 | 曲率有限 | $\kappa(s) \le \kappa_{max}$（转向角上限） |
| 动力学可行 | 力/加速度受限 | $\lVert a \rVert \le a_{max}$（轮胎附着） |
| 执行器可行 | 电机/制动能力 | 扭矩、转向率受限 |

## 2. 关键可行性条件

### 2.1 曲率-速度耦合
侧向加速度约束给出**速度上界**：

$$v(s) \le \sqrt{\frac{a_{lat,max}}{\kappa(s)}}$$

曲率越大 → 限速越低。这是时间参数化中最常违反的约束。

### 2.2 加速度可行性
$$|a(s)| \le a_{max}, \quad |j(s)| \le j_{max}$$

### 2.3 边界条件匹配
起点状态 $\mathbf{q}(t_0)$ 必须等于当前实测状态——否则控制器一开始就追不上。

## 3. 最小可手算例子（曲率限速）

**题目**：弯道曲率 $\kappa = 0.2\ \text{m}^{-1}$，侧向加速度上限 $a_{lat,max} = 4\ \text{m/s}^2$。求该弯道允许的最大速度。

**步骤**：
1. 代入：$v_{max} = \sqrt{4 / 0.2} = \sqrt{20} \approx 4.47\ \text{m/s}$（≈16 km/h）；
2. 若限速标志 30 km/h（8.3 m/s），取 $\min(8.3, 4.47) = 4.47$——**曲率限速胜出**。

**含义**：不减速进弯，侧向加速度超限 → 侧滑。这就是速度分配中"上限曲线"的由来。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 只看几何（无碰撞）就认为可行 | 运动学/动力学/执行器三层缺一不可 |
| 曲率限速只在弯道中心适用 | 整条轨迹逐点检查，含进弯出弯过渡 |
| 忽略起点状态匹配 | 轨迹起点与当前状态不一致，控制器第一拍就发散 |

## 5. 检查流程

1. 生成候选轨迹（采样/优化）；
2. 逐点检查曲率、速度、加速度、jerk；
3. 碰撞检测（见[[碰撞检测]]）；
4. 全部通过 → 可行；否则剔除/重采样。

## 6. 检索练习（闭卷）

1. 写出可行性四层级并各给一个约束表达式；
2. 已知 $\kappa=0.1,\ a_{lat,max}=3$，求 $v_{max}$；
3. 说明起点状态匹配失败会怎样。

## 7. 通过标准

- 能逐层说出可行性约束；
- 能计算曲率限速并解释其必要性；
- 能说明轨迹库方法为何依赖可行性筛选。
