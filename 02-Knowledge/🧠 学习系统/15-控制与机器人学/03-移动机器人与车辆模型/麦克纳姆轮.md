# 麦克纳姆轮

## 0. 为什么学它

**麦克纳姆轮**（Mecanum wheel）是让机器人"能横移"的工程实现：主轮周围装一圈**斜置 45° 的被动辊子**，把一部分转动分解到横向。它是全向移动平台的实物载体，理解辊子几何才能正确写映射矩阵。

## 1. 核心原理

- 主轮绕水平轴主动旋转；
- 辊子（被动）轴线与主轮轴线成 $\pm45^\circ$，与地面接触时产生**斜向滑动分量**；
- 四个轮（两左两右、辊子镜像布置）的力矢量合成出任意方向的合力 → 全向运动。

**关键点**：辊子是被动的（无驱动），只提供"地面接触方向的转换"。

## 2. 轮布置与运动

| 轮位 | 辊子朝向（示例约定） |
|:---|:---|
| 左前 | 辊子轴线指向前-右 |
| 右前 | 指向前-左 |
| 左后 | 指向后-右 |
| 右后 | 指向后-左 |

四轮同向 → 纵向前进；左右轮速差 → 转向；对角线轮同速反向 → 横向平移。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 麦克纳姆轮=全向轮（omni） | 都是全向轮，但辊子角度不同（麦轮 45°，全向轮 90°） |
| 辊子可独立驱动 | 辊子被动，仅转换接触方向 |
| 任意轮速组合都能走 | 有打滑/悬空限制，需校核接触 |
