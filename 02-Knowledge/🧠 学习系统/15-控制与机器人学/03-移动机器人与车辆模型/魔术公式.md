# 魔术公式

## 0. 为什么学它

线性轮胎模型在大侧偏角下失效，而真实车辆的极限工况（漂移、ESP 标定、赛车仿真）恰恰发生在大侧偏角。**魔术公式（Pacejka 模型）**用一个半经验公式精确拟合 $F_y(\alpha)$ 的全曲线（含饱和与峰值），是整车动力学仿真的行业标准。

## 1. 核心公式

**Pacejka 魔术公式**（侧向力）：

$$F_y = D\sin\big(C\arctan(B\alpha - E(B\alpha-\arctan(B\alpha)))\big).$$

**参数含义**：

| 参数 | 含义 |
|:---|:---|
| $D$ | 峰值因子（力峰值） |
| $C$ | 形状因子（曲线形态） |
| $B$ | 刚度因子（线性区斜率 $=BCD$） |
| $E$ | 曲率因子（峰值位置） |

**特性**：
- 小 $\alpha$：$F_y\approx -BCD\,\alpha$（退化为线性模型，$C_\alpha=BCD$）；
- 大 $\alpha$：$F_y$ 饱和（峰值后下降）；
- 可加垂直载荷/路面条件修正。

## 2. 最小可手算例子（概念验证）

**题目**：解释"线性区斜率 = $BCD$"。

**解**：$\alpha\to0$ 时 $\arctan(B\alpha)\approx B\alpha$，公式括号内 $\approx B\alpha$，$\sin(C\arctan(B\alpha))\approx C B\alpha$，故 $F_y\approx D\cdot C\cdot B\,\alpha=BCD\alpha$——与线性模型 $C_\alpha=BCD$ 一致 ✓。参数 $B,C,D$ 可从侧偏刚度反推。

**易错点**：参数单位（$D$ 是力）；$E$ 为 0 时退化为简化形式；参数须按车型标定。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 魔术公式是物理定律 | 是拟合公式，参数由试验标定 |
| 忽略饱和行为 | 峰值后力下降是极限工况关键 |
| 参数可通用 | 不同轮胎/载荷/路面必须重新标定 |
