# 移动机器人运动学与差分驱动

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：整个移动机器人栈（定位 → 规划 → 跟踪 → 控制）的地基——位姿怎么更新（里程计）、规划器输出什么（路径/轨迹）、EKF 的预测步用什么模型，全部从这里来。HW02 要求自写运动学仿真（官方 `diff_drive.py` 对齐），HW03 跟踪器要"跟随一个会动的模型"，HW04 EKF 定位的预测步就是本笔记的位姿更新方程。跳过它，后面所有 HW 的"误差从哪来"都说不清。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 机器人只有两个电机编码器，能读到左右轮转了多少圈，但没人告诉它"你现在在房间的哪个位置、朝哪个方向"。以前的做法是"看路标猜位置"（全局定位），但室内没有 GPS，路标也不总看得见。于是需要回答两个问题：**① 轮速怎么变成车体的前进速度 $v$ 和转向角速度 $\omega$？② 知道了 $v$、$\omega$，位姿 $(x,y,\theta)$ 怎么随时间更新？** 前者是**运动学模型**（把执行器量映射到车体运动），后者是**位姿积分/里程计**（把车体运动映射到位姿）。这两个映射合起来，就是"机器人怎么知道自己在哪、能去哪"的底层回答。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是 [[路径规划Astar与RRT]] 的输入约束（差分驱动可原地转，规划出的路径才"跟得上"）；是 [[纯跟踪与Stanley控制器]] 要控制的被控对象模型；是 [[EKF非线性状态估计]] 预测步的"系统方程"来源。HW02→HW03→HW04 全部建立在它之上。
- **实际应用场景**：扫地机器人（几乎所有家用机器人都用差速底盘）、仓储 AGV、服务机器人底盘；阿克曼车型（汽车）的自行车模型是同一套思路的变体；机械臂的雅可比是同一思想在高维的推广。
- **高频题型/任务**：已知左右轮速求 $v$、$\omega$；已知 $v$、$\omega$ 与初值做一步/多步位姿更新；对比欧拉积分与精确积分（扇形积分）的误差；unicycle 与 bicycle 模型的选择判断；复现 PythonRobotics `PathTracking/diff_drive/diff_drive.py`。

---

## 3. 学它之前需要哪些前置知识？

1. **[[差分驱动]]**：两个独立驱动轮 + 随动轮（万向轮）的底盘结构，两侧轮速独立可控——这是"$v$ 与 $\omega$ 可任意组合"（含原地旋转）的结构前提。
2. **[[非完整约束]]**：轮子只能滚动不能侧滑 ⇒ 位形空间（3 维：$x,y,\theta$）大于可控自由度（2 个：$v,\omega$）⇒ 位姿不能瞬移，只能沿当前朝向走——这正是"运动学模型 + 积分"而非"直接设坐标"的原因。
3. **[[里程计]]**：把编码器读数折算成轮子走过的弧长（$s = r\,\Delta\phi$），是 $v$ 的测量来源；本笔记的位姿更新就是"里程计 + 航向"的积分过程。

---

## 4. 用直觉语言解释它

> «这东西其实就像两个人抬一根长杆走路：左边的人走得快、右边走得慢，杆子就整体往前挪一点又往左偏一点；两人速度一样，杆子直走；两人速度相反，杆子原地打转。杆子中点就是车体中心，两人的步速就是左右轮速，杆子朝的方向就是车头朝向。"» 位姿更新则像"闭眼走路记路"：每走一小步，就按"当时朝的方向"挪一小段，方向变了就转个身再走——把无穷小的"直走 + 转向"一段段拼起来，就是走过的轨迹。

- **直觉类比/几何图像**：左右轮速之差决定转向——**差速**（差 = differential）驱动因此得名；位姿更新是"小步直走 + 小步转身"的交替积分。
- **为什么很自然**：轮子与地面只有纯滚动接触，每个轮子的速度方向被"钉死"在轮子朝向；把两个轮的约束合成，就得到车体的瞬时旋转中心（ICR）——整辆车每一瞬间都在绕某个点转圆弧，$v$ 与 $\omega$ 不过是对这个圆弧的另一种描述。
- **一句话直觉本质**：**轮速先合成"前进 + 转向"两个自由度，位姿再沿这两个自由度做逐段积分——模型给的是"速度怎么来"，积分给的是"位置怎么变"。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **差分驱动运动学模型**：设左右轮线速度 $v_l, v_r$（$v_i = r\,\omega_{\text{wheel},i}$，$r$ 为轮半径），轮距（左右轮接地点间距）为 $L$，则车体速度分解为
$$v = \frac{v_r + v_l}{2}, \qquad \omega = \frac{v_r - v_l}{L}$$
- **unicycle 模型（单轮车/独轮车模型）**：把车体抽象为"一个可转向的点"，输入为线速度 $v$ 与角速度 $\omega$：
$$\dot{x} = v\cos\theta, \qquad \dot{y} = v\sin\theta, \qquad \dot{\theta} = \omega$$
- **位姿更新（离散时间，步长 $\Delta t$）**——欧拉积分：
$$x_{k+1} = x_k + v_k\cos\theta_k\,\Delta t, \quad y_{k+1} = y_k + v_k\sin\theta_k\,\Delta t, \quad \theta_{k+1} = \theta_k + \omega_k\,\Delta t$$

### 2. 核心公式
差分驱动 → unicycle 的完整映射（含轮子半径）：
$$v = \frac{r(\omega_r + \omega_l)}{2}, \qquad \omega = \frac{r(\omega_r - \omega_l)}{L}$$
精确位姿更新（$\omega \neq 0$ 时按圆弧积分，误差更小）：
$$\begin{pmatrix} x_{k+1} \\ y_{k+1} \\ \theta_{k+1} \end{pmatrix} = \begin{pmatrix} x_k + \frac{v}{\omega}(\sin(\theta_k + \omega\Delta t) - \sin\theta_k) \\ y_k - \frac{v}{\omega}(\cos(\theta_k + \omega\Delta t) - \cos\theta_k) \\ \theta_k + \omega\Delta t \end{pmatrix}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $v_l, v_r$ | 左右轮线速度 | m/s，$v_l \neq v_r$ 时转向 | 由编码器/电机测得 |
| $v$ | 车体前进线速度 | m/s | $= (v_r + v_l)/2$ |
| $\omega$ | 车体转向角速度 | rad/s（注意不是 deg/s） | $= (v_r - v_l)/L$ |
| $L$ | 轮距（左右轮间距） | m | 由底盘几何决定 |
| $r$ | 驱动轮半径 | m | 编码器弧长折算用 |
| $(x, y, \theta)$ | 位姿：位置 + 航向角 | m, m, rad | 相对世界系 |
| $\Delta t$ | 积分步长 | s | 越小欧拉误差越小 |
### 4. 常见变体与适用条件
- **bicycle 模型（自行车模型）**：前轮转向角 $\delta$（阿克曼车的抽象），$v$ 为后轴中点速度，转向半径 $R = L_{\text{wb}}/\tan\delta$，$\omega = v\tan\delta / L_{\text{wb}}$（$L_{\text{wb}}$ 为轴距）——差分驱动是"双轮输入"，bicycle 是"速度 + 转向角输入"，两者都归约为 unicycle 形式。
- **适用条件**：低速、无滑移、刚体、轮子纯滚动（运动学有效）；unicycle 是几乎所有 2D 导航算法的通用抽象。
- **限制条件**：高速时打滑/离心导致运动学失效（需动力学模型）；欧拉积分在 $\Delta t$ 大或 $\omega$ 大时误差显著，应改用圆弧精确积分或更高阶方法；$\omega=0$ 时精确公式分母为零，需退化处理（直线情形）。

## 6. 推导思路和思想来源

- **最初困难**：两个轮子各自有速度，车体作为一个刚体只有一个速度——"两个输入怎么变成一个运动"？
- **直接方法局限**：直接把两个轮速相加除二只得到前进分量，丢掉了"轮速不同导致转弯"的信息。
- **关键"转念"**：刚体平面运动可以分解为"平动 + 转动"，而转动必须相对某个瞬时旋转中心（ICR）描述。**假设左右轮绕同一 ICR 转同一个角速度 $\omega$**，则 $v_l = \omega R_l$、$v_r = \omega R_r$，且 $R_r - R_l = L$。由 $v = \omega R$（$R$ 为车体中心到 ICR 距离，$R = (R_l+R_r)/2$）立刻解出 $v = (v_r+v_l)/2$、$\omega = (v_r - v_l)/L$——"轮距 $L$ 是 $v$ 与 $\omega$ 之间的换算标尺"。
- **推导主线与动机**：位姿更新是"速度定义"的直接积分：$\dot{x} = v\cos\theta$ 就是"把 $v$ 投影到 $x$ 轴"（$\cos\theta$ 来自航向）；欧拉积分是矩形近似，圆弧积分是解析解。两条线（模型 + 积分）拼起来就是完整运动学。
- **为什么自然得到此结论**：因为刚体平面运动定理只有"平动 + 绕瞬时中心转动"这一种分解，所以任何轮式底盘（差速、bicycle、全向）的运动学最终都写成"$v$、$\omega$ 两个量 + 位姿积分"的形式——形式不同只是 $v,\omega$ 与执行器的换算不同。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：轮距 $L = 0.5\,\text{m}$，轮半径 $r = 0.1\,\text{m}$，左轮角速度 $\omega_l = 10\,\text{rad/s}$，右轮 $\omega_r = 14\,\text{rad/s}$。求车体 $v$ 与 $\omega$。
- **解题思路与关键步骤**：先转线速度：$v_l = 0.1\times 10 = 1\,\text{m/s}$，$v_r = 0.1\times 14 = 1.4\,\text{m/s}$；再合成：$v = (1+1.4)/2 = 1.2\,\text{m/s}$；$\omega = (1.4-1)/0.5 = 0.8\,\text{rad/s}$。
- **最终答案**：$v = 1.2\,\text{m/s}$，$\omega = 0.8\,\text{rad/s}$（约 $45.8^\circ/\text{s}$，向左转——右轮快）。
- **易错点**：把轮子角速度 $\omega_l$ 直接当车体 $\omega$ 用；$L$ 用成轮半径；$\omega$ 单位忘换弧度制。
- **🤔 追问**：如果 $\omega_r = -\omega_l$（两轮等速反转）会怎样？——$v=0$、$\omega = 2r\omega_l/L \neq 0$，即**原地旋转**，这是差速底盘独有的机动能力（bicycle 做不到）。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：初值 $(x_0,y_0,\theta_0) = (0,0,0)$，$v = 1\,\text{m/s}$、$\omega = 0.5\,\text{rad/s}$ 保持恒定，$\Delta t = 0.5\,\text{s}$，走两步。比较欧拉积分与精确（圆弧）积分。
  解：欧拉：第一步 $\theta_1 = 0.25$，$x_1 = 0.5\cos 0 = 0.5$，$y_1 = 0.5\sin 0 = 0$；第二步 $\theta_2 = 0.5$，$x_2 = 0.5 + 0.5\cos 0.25 \approx 0.984$，$y_2 = 0 + 0.5\sin 0.25 \approx 0.124$。精确：走的是半径 $R = v/\omega = 2\,\text{m}$ 的圆弧，两步总转角 $0.5\,\text{rad}$，终点 $x = 2\sin 0.5 \approx 0.959$，$y = 2(1-\cos 0.5) \approx 0.245$。**关键推理**：欧拉把每段弧当成"先转后直走"的折线，转角越大、步长越长误差越大——HW 中里程计误差的主要来源之一；$\omega=0$ 时精确公式要退化回直线积分（$x_{k+1}=x_k + v\Delta t$）。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：PythonRobotics `PathTracking/diff_drive/diff_drive.py` 定义了差速驱动的 `State` 类与 `update`（欧拉积分版本），并演示差速底盘跟踪路径。HW02 的验收基准即"自写运动学仿真与官方 demo 对齐"：同一轮速序列输入，逐拍对比 $(x,y,\theta)$，误差须在 $10^{-6}$ 量级（纯数值差异）；再自写**精确圆弧积分**版本做参数敏感性分析（$\Delta t$ 从 0.1 s 缩到 0.01 s，终点误差如何收敛）——这就是仓库"官方复现 → 自写对齐 → 敏感性分析"验收模板的第一个应用点。

## 8. 常见误区和易混概念

### 误区 1：以为"两个轮速加起来除以 2 就是前进速度"
- **错误直觉**：$v = (v_l + v_r)/2$ 已经够了，$\omega$ 是次要的。
- **为什么错**：没有 $\omega$ 就无法描述转弯，位姿更新 $\theta$ 永远不变，轨迹全错；而且 $\omega$ 的公式里分母是轮距 $L$——同样的轮速差，底盘越窄转得越快。
- **正确理解**：$v$ 与 $\omega$ 是**一对**必须同时计算的量，缺一不可；差速驱动"两个输入 → 两个输出"是一一映射。
### 误区 2：把欧拉积分当成"精确"的
- **错误直觉**：$\Delta t$ 小到一定程度欧拉积分就足够精确，可以随便用。
- **为什么错**：欧拉积分是一阶方法，误差 $\mathcal{O}(\Delta t^2)$ 累积；在 $\omega$ 大（急转弯）时"先转后走"与真实圆弧偏差显著，长时间积分（里程计跑 10 分钟）漂移可观。
- **正确理解**：$\omega \approx 0$ 或 $\Delta t$ 极小时欧拉可用；否则用圆弧精确积分（本笔记 5.2 公式）或 RK4；工程上里程计还要考虑轮径标定误差（比积分方法误差大得多）。
### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 差分驱动模型 | 轮速 → 车体 $v,\omega$ | 两轮独立驱动，可原地旋转；$\omega=(v_r-v_l)/L$ | 扫地机、AGV、服务机器人 |
| bicycle 模型 | 车速+转向角 → 车体运动 | 前轮转向，不能原地转；$\omega = v\tan\delta/L_{wb}$ | 汽车、自动驾驶（HW01/HW03） |
| unicycle 模型 | $v,\omega$ → 位姿变化率 | 上述两者的共同抽象，规划/控制的通用接口 | 所有 2D 导航算法的输入形式 |
| 里程计 | 编码器 → 位姿估计 | 积分运动学模型得到，随距离漂移、无全局修正 | 短时局部定位、EKF 预测步 |

| 5 | 开放/证明/建模 | 较难 | 为什么 $\omega$ 公式分母是轮距 $L$（ICR 推导） |

### 题目与解析

#### 1. unicycle 模型 $\dot{x} = v\cos\theta$、$\dot{y} = v\sin\theta$、$\dot{\theta} = \omega$ 中，为什么位置变化率要乘 $\cos\theta$、$\sin\theta$？
> [!question]- 答案解析
> - **答案**：$v$ 是沿车头方向的速度矢量，其方向由航向角 $\theta$ 决定；把它投影到世界坐标系的 $x$、$y$ 轴，水平分量就是 $v\cos\theta$、$v\sin\theta$。$\theta$ 本身的变化率就是转向角速度 $\omega$。
> - **解析**：这是"把体坐标系速度转换到世界坐标系"的旋转投影，与刚体速度变换 $v = R(\theta)\cdot(v_{\text{body}},0)^T$ 等价。
> - **易错原因**：把 $\theta$ 当成位置的一部分直接积分，或把 $\cos\theta$、$\sin\theta$ 写反（$x$ 对应 $\cos$，$y$ 对应 $\sin$）。
> - **对应误区**：误区 1（漏掉 $\omega$ / 投影）。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 2. 轮距 $L = 0.4\,\text{m}$，轮半径 $r = 0.05\,\text{m}$，左轮角速度 $\omega_l = 12\,\text{rad/s}$，右轮 $\omega_r = 4\,\text{rad/s}$。求车体 $v$ 与 $\omega$。
> [!question]- 答案解析
> - **答案**：$v_l = 0.6\,\text{m/s}$，$v_r = 0.2\,\text{m/s}$；$v = 0.4\,\text{m/s}$，$\omega = (0.2 - 0.6)/0.4 = -1\,\text{rad/s}$（负号 = 向右转，因为左轮快）。
> - **解析**：先轮速转线速度（乘 $r$），再合成；符号约定：右轮快 → 左转（$\omega>0$），左轮快 → 右转（$\omega<0$）。
> - **易错原因**：忘记先乘 $r$ 就把轮子角速度直接代入；$\omega$ 符号（转向方向）搞反。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 3. 场景：$v = 1\,\text{m/s}$、$\omega = 2\,\text{rad/s}$、$\Delta t = 1\,\text{s}$。用欧拉积分误差很大，请说明原因并给出改进方案。
> [!question]- 答案解析
> - **答案**：欧拉积分把 1 秒内的运动近似成"先用初值 $\theta$ 直走 1 m，再一次性转 $2\,\text{rad}$"，而真实运动是半径 $R = v/\omega = 0.5\,\text{m}$ 的 2 rad 圆弧（弧长 1 m），两者终点不同——转角越大偏差越大。改进：改用圆弧精确积分（$\omega\neq0$ 时用 $\frac{v}{\omega}(\sin(\theta+\omega\Delta t)-\sin\theta)$ 等解析式），或减小 $\Delta t$ 用 RK4。
> - **解析**：欧拉是一阶方法，局部截断误差 $\mathcal{O}(\Delta t^2)$；本例 $\omega\Delta t = 2\,\text{rad}$ 已经"大步长 + 大转角"，正是欧拉最失效的区间。
> - **易错原因**：以为减小 $\Delta t$ 是唯一办法（可行但成本高）；不知道有解析的圆弧积分公式。
> - **对应误区**：误区 2（欧拉当精确）。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 4. 把差速机器人换成轴距 $L_{wb} = 2\,\text{m}$ 的汽车（bicycle 模型），车速 $v = 10\,\text{m/s}$、前轮转角 $\delta = 10^\circ$，求 $\omega$ 与转弯半径，并说明与差速车的一个本质区别。
> [!question]- 答案解析
> - **答案**：$\omega = v\tan\delta / L_{wb} = 10 \times \tan 10^\circ / 2 \approx 0.88\,\text{rad/s}$；转弯半径 $R = v/\omega = L_{wb}/\tan\delta \approx 11.3\,\text{m}$。本质区别：差速车可原地旋转（$v=0$ 时 $\omega \neq 0$，靠轮速差），汽车只能绕"不小于最小转弯半径"的圆弧运动（$v=0$ 时无法转向）。
> - **解析**：bicycle 的 $\omega$ 由转向角决定而非轮速差，且 $v$ 与 $\delta$ 耦合进半径公式；这解释了为什么阿克曼车规划要用 Hybrid A*（运动学约束更紧）。
> - **易错原因**：$\delta$ 忘转弧度制；把 bicycle 的 $L_{wb}$（轴距）与差速的 $L$（轮距）混为一谈。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 5. 请从瞬时旋转中心（ICR）出发，推导 $\omega = (v_r - v_l)/L$，并说明该公式成立的假设。
> [!question]- 答案解析
> - **答案**：假设两轮纯滚动、无侧滑、车体为刚体，则左右轮绕同一 ICR 以同一角速度 $\omega$ 转动：$v_l = \omega R_l$、$v_r = \omega R_r$，且 $R_r - R_l = L$（轮距）。相减得 $v_r - v_l = \omega(R_r - R_l) = \omega L$，即 $\omega = (v_r - v_l)/L$。同时 $v = (v_r + v_l)/2$ 由 $v = \omega R$、$R = (R_l + R_r)/2$ 得到。
> - **解析**：推导的成立假设是纯滚动（无滑动）、刚体、两轮共 ICR——打滑或底盘变形时公式失效，这正是高速/湿滑地面里程计误差爆炸的机理。
> - **易错原因**：死记公式不理解"$L$ 为什么在分母"——它是两轮到 ICR 距离之差；理解后遇到"轮子打滑该信哪个传感器"的问题自然知道答案（信惯性测量，别信轮速）。
> - **Obsidian 标签建议**：`#自测题/较难`
