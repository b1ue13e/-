# IK多解

## 0. 为什么学它

逆运动学通常**不止一组解**：2R 臂有肘上/肘下两组，6DOF 臂可多达 8 组。控制器必须**从多解中选一个**——选错可能撞障碍、超限位或引起关节大幅跳变。多解管理是 IK 实用化的关键一环。

## 1. 多解的来源

| 来源 | 说明 |
|:---|:---|
| 肘上/肘下（elbow up/down） | $\theta_2$ 取 $\pm$ |
| 肩部翻转 | 冗余自由度或腕翻转 |
| 腕部多解 | 球腕姿态的 Euler 解多义 |
| 冗余机械臂 | 7DOF 臂有连续解集 |

6DOF 球腕臂最坏 8 组解（2³：臂 × 腕 × 翻转组合）。

## 2. 解的选择策略

1. **关节限位过滤**：丢弃超出 $\theta_{min}\le\theta\le\theta_{max}$ 的解；
2. **连续平滑**：优先选离当前关节角最近/变化最小的解（轨迹连续性）；
3. **避障**：在配置空间检查碰撞；
4. **奇异回避**：避开使 Jacobian 病态的邻近解；
5. **能耗/速度**：按任务目标加权重。

## 3. 最小可手算例子

**题目**：2R 臂（$l_1=l_2=1$）目标 $(1,0)$，两组解 $(−60°,+120°)$ 与 $(+60°,−120°)$；当前关节角 $(0°,0°)$，选哪组？

**解**：变化量：
- 解 1：$|−60−0|+|120−0|=180°$；
- 解 2：$|60−0|+|−120−0|=180°$——两组变化量相同（本例对称），实际系统再结合限位（如肘下解可能超限）选择。

**易错点**：只选第一组；忽略关节限位与连续性。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| IK 只有一组解 | 必须枚举全部解 |
| 解越"大"越差 | 用任务指标（限位/平滑/避障）而非大小判断 |
| 忽略奇异邻近解 | 邻奇异解运动学精度差 |
