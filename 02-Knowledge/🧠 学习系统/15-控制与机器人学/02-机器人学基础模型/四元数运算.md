# 四元数运算

## 0. 为什么学它

姿态合成（先转 A 再转 B）、姿态插值（从一个朝向平滑转到另一个）、姿态误差计算（当前朝向离目标差多少）都需要四元数的**代数运算**。掌握乘法、共轭、SLERP，才能在实际系统中用四元数干活。

## 1. 核心运算

**乘法**（Hamilton 积，表示旋转合成：先 $q_1$ 后 $q_2$）：

$$q_2 \otimes q_1 = (w_2 w_1 - \vec v_2\cdot\vec v_1,\; w_2\vec v_1 + w_1\vec v_2 + \vec v_2\times\vec v_1).$$

**共轭**：$q^*=(w,-\vec v)$——逆旋转。

**逆**（单位四元数）：$q^{-1}=q^*$；非单位：$q^{-1}=q^*/\lVert q\rVert^2$。

**范数**：$\lVert q\rVert=\sqrt{w^2+x^2+y^2+z^2}$。

**旋转合成**：向量先 $q_1$ 后 $q_2$ 旋转 = $p''=(q_2q_1)\,p\,(q_2q_1)^{-1}$。

## 2. SLERP 球面线性插值（姿态平滑过渡）

$$q(t)=\frac{\sin((1-t)\Omega)}{\sin\Omega}\,q_0+\frac{\sin(t\Omega)}{\sin\Omega}\,q_1,\qquad t\in[0,1],$$

其中 $\Omega=\arccos(q_0\cdot q_1)$ 为两四元数夹角。SLERP 保证插值路径是"最短弧"且角速度恒定。

**工程注意**：若 $q_0\cdot q_1<0$，先取 $q_1\leftarrow-q_1$ 走短弧。

## 3. 最小可手算例子

**题目**：$q_1=(1,0,0,0)$（单位旋转），$q_2=(0,0,0,1)$（绕 z 轴 180°），求 $q_2 q_1$ 与 $q_1 q_2$。

**解**：标量积 $1\cdot0-\vec0\cdot(0,0,1)=0$；矢量为 $1(0,0,1)+0\cdot\vec0+\vec0\times(0,0,1)=(0,0,1)$。
故 $q_2 q_1=(0,0,0,1)$。
因 $q_1$ 是单位旋转，$q_1 q_2$ 同理 $=(0,0,0,1)$，二者相等（本例特殊，因 $q_1$ 为单位元）。

**易错点**：一般情况下四元数乘法不交换；用 $q_2q_1$ 表示"先 $q_1$ 后 $q_2$"。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 四元数乘法可交换 | 非交换，顺序 = 旋转执行顺序 |
| SLERP 直接用线性插值 | 需按夹角加权（球面插值），否则角速度不均匀 |
| 忘记负四元数等价 | 插值前检查点积符号，避免绕远路 |
