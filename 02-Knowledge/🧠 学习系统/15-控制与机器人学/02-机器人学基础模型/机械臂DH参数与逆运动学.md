# 机械臂DH参数与逆运动学

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW05（机械臂运动学与动力学控制）的入口——验收 demo `arm_navigation_joint_control.py` 内部就是"逆运动学求目标关节角 → 关节控制"，验收指标（2 连杆跟踪误差 < 0.05 rad）直接依赖 IK 的精度与收敛性；同时 DH 参数是 *Modern Robotics* 与所有机械臂教材的通用语言（PUMA560、UR5、KUKA 全用 DH 建模）。跳过它，机械臂方向（HW05/HW06 可选支线）完全无法展开。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 机械臂有 6 个电机，每个电机一转，末端执行器（手爪）的位置和姿态都会变——而且是非线性地变（三角函数耦合）。以前的做法是"试错示教"：人推着机械臂摆到目标位姿，记下每个关节角，回放时原样重放——换个目标点就要重新示教一次，完全无法应对"让手爪沿一条曲线运动"这种连续任务。
> 于是需要两个数学工具：**正运动学**——给定关节角 $\theta_1,\dots,\theta_n$，求末端位姿 $T$（"电机转多少 → 手到哪"）；**逆运动学**——给定目标位姿 $T$，求关节角（"手要到哪 → 电机转多少"）。前者有唯一解、直接相乘；后者多解、非线性、是真正的难点。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：正/逆运动学是机械臂所有后续内容（[[几何Jacobian]] 速度分析、动力学、轨迹规划、力控制）的地基——HW05 的关节轨迹跟踪、HW06 的抓取闭环都从这里出发；DH 参数则是"机械臂 → 数学模型"的标准翻译器。
- **实际应用场景**：工业焊接/喷涂机器人的示教与离线编程、手术机器人末端定位、仓储机械臂抓取（视觉 → IK → 抓取）、自动驾驶中无（机械臂方向选做）；电影特效与游戏里骨骼动画的 IK 是同一数学。
- **高频题型/任务**：给定 DH 参数表写出变换矩阵并求末端位姿；2 连杆机械臂正/逆运动学手算；判断 IK 多解（elbow up/down）与奇异位形；解析 IK 与数值 IK（雅可比迭代）的适用条件对比；复现 PythonRobotics `arm_navigation_joint_control.py`。

---

## 3. 学它之前需要哪些前置知识？

1. **[[齐次变换矩阵]]**：$4\times4$ 矩阵把"旋转 + 平移"合成一次变换——正运动学就是一系列齐次变换矩阵相乘。
2. **[[基本旋转]]**：绕 $x$、$y$、$z$ 轴旋转的 $3\times3$ 矩阵——DH 变换矩阵由 $Rot_x(\alpha)$ 与 $Rot_z(\theta)$ 拼成。
3. **[[旋转矩阵]]**：坐标在不同坐标系间的变换规则——理解"末端位姿 = 各关节坐标系逐级变换"的前提。

---

## 4. 用直觉语言解释它

> «这东西其实就像给机械臂的每根骨头贴标签：DH 参数就是一套"给骨头和关节贴尺寸标签"的统一规则——每根骨头贴"多长、拧多大角度"，每个关节贴"偏了多少、转了多少度"。正运动学就是按标签从肩膀往手指头一级一级算下去（每级乘一个 4×4 矩阵），最后得到手掌的位置朝向；逆运动学就是"倒着解方程"——知道手掌要在哪，反推每根骨头该转多少度。"»

- **直觉类比/几何图像**：正运动学 = 顺着骨链做矩阵乘法（唯一、直接）；逆运动学 = 解"手掌位姿 → 关节角"的方程组（多解、需消元/迭代）。
- **为什么很自然**：机械臂本质是"一串旋转关节 + 刚性连杆"，每个关节坐标系相对上一个只有 4 个自由度（沿 $z$ 平移 $d$、绕 $z$ 转 $\theta$、沿 $x$ 平移 $a$、绕 $x$ 转 $\alpha$）——DH 把这 4 个量定义成标准参数，任何机械臂都能填同一张表，正运动学于是变成"查表 + 连乘"。
- **一句话直觉本质**：**DH 是机械臂的"身份证表格"（4 参数唯一描述每对相邻连杆），正运动学是查表连乘（唯一解），逆运动学是反解方程（多解、靠解析消元或雅可比迭代）。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **DH 参数**：对 $n$ 连杆机械臂，相邻坐标系 $\{i-1\}$ 与 $\{i\}$ 的相对位姿由 4 个参数唯一确定：连杆长度 $a_{i-1}$、连杆扭转 $\alpha_{i-1}$、连杆偏距 $d_i$、关节角 $\theta_i$（标准 DH 约定）。
- **正运动学（forward kinematics）**：由关节角 $\theta$ 求末端位姿：
$$T_n^0 = T_1^0(\theta_1)\, T_2^1(\theta_2) \cdots T_n^{n-1}(\theta_n)$$
- **逆运动学（inverse kinematics, IK）**：由目标位姿 $T_d$ 求关节角 $\theta$：解 $T_n^0(\theta) = T_d$——解析法（闭式消元）或数值法（雅可比迭代）。

### 2. 核心公式
单关节 DH 变换矩阵（标准 DH）：
$$T_i^{i-1} = \begin{pmatrix} \cos\theta_i & -\sin\theta_i\cos\alpha_{i-1} & \sin\theta_i\sin\alpha_{i-1} & a_{i-1}\cos\theta_i \\ \sin\theta_i & \cos\theta_i\cos\alpha_{i-1} & -\cos\theta_i\sin\alpha_{i-1} & a_{i-1}\sin\theta_i \\ 0 & \sin\alpha_{i-1} & \cos\alpha_{i-1} & d_i \\ 0 & 0 & 0 & 1 \end{pmatrix} = Rot_x(\alpha_{i-1}) Trans_x(a_{i-1}) Rot_z(\theta_i) Trans_z(d_i)$$
数值 IK（雅可比迭代，$e$ 为末端误差，$J^\dagger$ 为雅可比伪逆）：
$$\theta \leftarrow \theta + J^\dagger e, \qquad e = \begin{pmatrix} \text{位置误差} \\ \text{姿态误差} \end{pmatrix}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $a_{i-1}$ | 连杆长度（沿 $\hat{x}_{i-1}$ 的平移） | m | 两关节轴公垂线长 |
| $\alpha_{i-1}$ | 连杆扭转（绕 $\hat{x}_{i-1}$ 的旋转） | rad | 两关节轴夹角 |
| $d_i$ | 连杆偏距（沿 $\hat{z}_i$ 的平移） | m | 移动关节的变量 |
| $\theta_i$ | 关节角（绕 $\hat{z}_i$ 的旋转） | rad | 旋转关节的变量 |
| $T_i^{i-1}$ | 坐标系 $\{i-1\} \to \{i\}$ 变换 | $4\times4$ | DH 乘积分解 |
| $J$ | 几何雅可比矩阵 | $6\times n$ | 末端速度 ↔ 关节速度 |
| $T_d$ | 目标末端位姿 | $4\times4$ | IK 的输入 |
### 4. 常见变体与适用条件
- **变体**：标准 DH（Craig 约定，轴在 $\hat{z}_i$）与修正 DH/MDH（轴在 $\hat{z}_{i-1}$）——参数表不同但物理等价，混用必错；解析 IK（PUMA560 型：$\theta_1 = \text{atan2}$ 闭式解）、几何法 IK（平面/球形手腕分解）、数值 IK（雅可比伪逆、阻尼最小二乘 DLS、LM 法）。
- **适用条件**：正运动学恒可用（查表连乘）；解析 IK 要求特殊结构（相邻轴平行/相交，如球形手腕）；数值 IK 通用但需初值、会陷入局部最优。
- **限制条件**：DH 在"相邻轴平行"时参数不连续（微小转动导致 $a$、$\alpha$ 跳变——MDH 缓解）；IK 多解需按关节限位与避障选解；奇异位形（$J$ 秩亏）处数值 IK 发散（需 DLS 正则化）。

## 6. 推导思路和思想来源

- **最初困难**：每个关节坐标系的取法有无限多种（坐标系可以随便摆），"怎么把机械臂变成一张可复用的表"？
- **直接方法局限**：每台机械臂单独建模（直接写各坐标系的齐次变换）——换一台机械臂全部重来，无法标准化、无法比较。
- **关键"转念"**：Denavit 与 Hartenberg 发现：只要把坐标系按**固定规则**摆放（$\hat{z}_i$ 沿关节轴 $i$，$\hat{x}_i$ 沿 $\hat{z}_{i-1}$ 与 $\hat{z}_i$ 的公垂线），那么相邻坐标系的变换**必然**可以分解为"绕 $x$ 转 $\alpha$ → 沿 $x$ 移 $a$ → 绕 $z$ 转 $\theta$ → 沿 $z$ 移 $d$"四个基本动作——于是 4 个参数完全描述相邻关系，且每个参数都有几何意义（长度、扭角、偏距、转角）。
- **推导主线与动机**：正运动学 = 沿链连乘 $T_n^0 = \prod T_i^{i-1}$，唯一且可直接求值；逆运动学 = 反解同一方程——解析法利用"腕部位置只依赖前 3 关节"等结构分解消元，数值法把方程写成 $e(\theta) = 0$ 用牛顿法/梯度下降迭代（$\Delta\theta = J^\dagger e$），两类方法对应"可解结构"与"通用系统"两种工程现实。
- **为什么自然得到此结论**：因为机械臂是**开链机构**，链式结构的数学自然语言就是矩阵连乘；而"4 参数描述相邻刚体"源于"两个旋转轴之间的相对位姿恰有 4 个自由度"的刚体几何事实——这不是发明，是发现。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：平面 2 连杆机械臂（都在 $xy$ 平面），$L_1 = L_2 = 1\,\text{m}$，DH 表：$a_0 = L_1, \alpha_0 = 0, d_1 = 0, \theta_1 = 30°$；$a_1 = L_2, \alpha_1 = 0, d_2 = 0, \theta_2 = 45°$。求末端位置。
- **解题思路与关键步骤**：平面臂的末端位置就是向量叠加：$x = L_1\cos\theta_1 + L_2\cos(\theta_1+\theta_2)$，$y = L_1\sin\theta_1 + L_2\sin(\theta_1+\theta_2)$（第二个连杆角度 = 两角之和，因为关节 2 在关节 1 的坐标系里再转 $\theta_2$）。
- **最终答案**：$x = \cos30° + \cos75° \approx 0.866 + 0.259 = 1.125\,\text{m}$，$y = \sin30° + \sin75° \approx 0.5 + 0.966 = 1.466\,\text{m}$。
- **易错点**：第二连杆角度写成 $\theta_2$ 而不是 $\theta_1 + \theta_2$（忘记角度叠加）；$L_2$ 的方向没跟着第一关节转。
- **🤔 追问**：如果 $\theta_2 = -45°$（肘部反向弯）呢？——$x = 0.866 + \cos(-15°) = 1.832$，$y = 0.5 + \sin(-15°) = 0.241$：同一末端可达域内两个不同解，这正是 IK 多解的几何根源。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：对例子 1 的机械臂，目标末端 $(x_d, y_d) = (1.5, 0.5)$。求 $\theta_1, \theta_2$（解析 IK），并讨论解的个数。
  解：先由余弦定理求 $\theta_2$：$r^2 = x_d^2 + y_d^2 = 2.5$，$\cos\theta_2 = (r^2 - L_1^2 - L_2^2)/(2L_1L_2) = (2.5-2)/2 = 0.25$，$\theta_2 = \pm\arccos 0.25 \approx \pm 75.5°$（**elbow up / elbow down 两解**）。再求 $\theta_1 = \text{atan2}(y_d, x_d) - \text{atan2}(L_2\sin\theta_2, L_1 + L_2\cos\theta_2)$：对 $\theta_2 = +75.5°$：$\theta_1 = \text{atan2}(0.5,1.5) - \text{atan2}(0.968, 1.25) \approx 18.4° - 37.8° = -19.4°$；对 $\theta_2 = -75.5°$：$\theta_1 \approx 18.4° + 37.8° = 56.2°$。**关键推理**：若 $r^2 > (L_1+L_2)^2$（超出可达范围）则无解；若 $r^2 = (L_1+L_2)^2$ 则两解退化为一解（完全伸直）——奇异位形；工程上按关节限位与避障在两个解中选一个（如取 elbow up）。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：PythonRobotics `ArmNavigation/arm_navigation_joint_control/arm_navigation_joint_control.py` 演示"目标末端位姿 → IK（数值/解析）→ 关节角轨迹 → 关节 PD 控制"全流程，`arm_navigation_collision_avoidance.py` 加入避障。HW05 验收流程：复现官方 demo → 自写 2 连杆运动学（DH 建表 + 正运动学 + 解析 IK）→ 同一目标位姿下关节角须与官方一致 → 关节轨迹跟踪误差 < 0.05 rad；再做参数敏感性分析（连杆长度、目标点靠近可达域边界时的 IK 收敛性）——这就是"DH 表 → 正运动学 → IK → 跟踪"的完整机械臂链路。

## 8. 常见误区和易混概念

### 误区 1：把 DH 参数表"背下来"而不是"建出来"
- **错误直觉**：DH 就是四个数字，抄别人的参数表就能用。
- **为什么错**：DH 参数依赖坐标系摆放约定——同一台机械臂用标准 DH 与 MDH 的参数表**不同**；相邻轴平行时标准 DH 的 $a$、$\alpha$ 会突变（参数不连续）；坐标系没按规则摆，四个参数就失去几何意义，算出的位姿全错。
- **正确理解**：每个参数都要能从机械臂图纸上指出来（公垂线在哪、轴夹角是多少）；建表时先定坐标系规则（$\hat{z}_i$ 沿轴 $i$），再读参数。
### 误区 2：以为逆运动学"解出来就是唯一的"
- **错误直觉**：IK 就是一个函数，输入位姿输出关节角。
- **为什么错**：IK 是**多解**的（elbow up/down、手腕翻转、360° 缠绕），且存在无解区（超出可达域）与奇异位形（$J$ 降秩）；数值 IK 的解还依赖初值，可能收敛到"数学正确但物理撞关节限位"的解。
- **正确理解**：IK 的输出是一个**解集**，工程上必须加约束选解（关节限位、避障、最小关节运动）；奇异点附近用阻尼最小二乘（DLS）而不是纯伪逆。
### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 正运动学 | 关节角 → 末端位姿 | 唯一解，矩阵连乘 | 仿真、轨迹验证（HW05 前半） |
| 逆运动学 | 末端位姿 → 关节角 | 多解/无解/奇异，解析或迭代 | 任务空间规划、示教复现（HW05 后半） |
| 解析 IK | 闭式解方程 | 快、可枚举全部解；要求特殊结构 | PUMA560/球形手腕型机械臂 |
| 数值 IK | 雅可比迭代求解 | 通用、需初值、可能局部最优 | 冗余/不规则机械臂 |
| 标准 DH vs MDH | 坐标系约定 | 轴在 $\hat{z}_i$ vs $\hat{z}_{i-1}$，表不同 | 建模时选定并全程一致 |

### 题目与解析

#### 1. 标准 DH 的四个参数 $a_{i-1}$、$\alpha_{i-1}$、$d_i$、$\theta_i$ 分别描述什么几何量？
> [!question]- 答案解析
> - **答案**：$a_{i-1}$ = 沿 $\hat{x}_{i-1}$ 方向、从 $\hat{z}_{i-1}$ 到 $\hat{z}_i$ 的公垂线长度（连杆长度）；$\alpha_{i-1}$ = 绕 $\hat{x}_{i-1}$ 从 $\hat{z}_{i-1}$ 转到 $\hat{z}_i$ 的角度（连杆扭转）；$d_i$ = 沿 $\hat{z}_i$ 从 $\hat{x}_{i-1}$ 到 $\hat{x}_i$ 的距离（连杆偏距）；$\theta_i$ = 绕 $\hat{z}_i$ 从 $\hat{x}_{i-1}$ 转到 $\hat{x}_i$ 的角度（关节角，旋转关节的变量）。
> - **解析**：四个参数正好对应"绕 $x$ 转、沿 $x$ 移、绕 $z$ 转、沿 $z$ 移"四个基本变换；记住"$a,\alpha$ 属于连杆（$x$ 轴系），$d,\theta$ 属于关节（$z$ 轴系）"就不会混。
> - **易错原因**：把 $d$ 与 $a$ 都当成"长度"而忽略方向轴不同；$\alpha$ 与 $\theta$ 的旋转轴（$x$ vs $z$）搞混。
> - **对应误区**：误区 1（背参数表）。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 2. $L_1 = L_2 = 1\,\text{m}$ 的平面 2 连杆臂，$\theta_1 = 0°$、$\theta_2 = 90°$，求末端位置。
> [!question]- 答案解析
> - **答案**：$x = 1\cdot\cos0° + 1\cdot\cos(0°+90°) = 1 + 0 = 1\,\text{m}$；$y = 1\cdot\sin0° + 1\cdot\sin90° = 0 + 1 = 1\,\text{m}$。
> - **解析**：第二连杆在 $90°$ 处竖直向上，末端 $(1, 1)$——直观上"第一连杆水平、第二连杆竖直"。
> - **易错原因**：第二连杆用 $\cos\theta_2$ 而非 $\cos(\theta_1+\theta_2)$（$x = 0$ 的错误答案）；角度制与弧度制混用。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 3. 场景：给一台 6 自由度 PUMA560 型机械臂（球形手腕）做 IK，目标是要在控制周期内实时（1 kHz）求解。选解析法还是数值法？为什么？
> [!question]- 答案解析
> - **答案**：选解析 IK。PUMA560 型结构（前三关节定位、球形手腕定向）存在闭式解，可一次性求出全部解并显式枚举（如 8 组解），计算量小、可稳定在 1 kHz 运行；数值 IK 每次迭代要算雅可比与伪逆，且依赖初值、可能不收敛，不适合硬实时。
> - **解析**：选择依据 = 结构可解性 × 实时性 × 解的完整性；解析法优先，数值法是"结构不配合"时的退路（如 7 自由度冗余臂）。
> - **易错原因**：以为数值法"更通用所以更好"，忽略实时性与多解枚举需求。
> - **对应误区**：误区 2（IK 唯一/万能）。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 4. 2 连杆臂 $L_1 = L_2 = 1\,\text{m}$，目标点 $P = (1.9, 0.4)$。判断可达性并给出解的个数；若目标改为 $(2.1, 0)$ 呢？
> [!question]- 答案解析
> - **答案**：$r = \sqrt{1.9^2 + 0.4^2} \approx 1.942$。可达条件 $|L_1 - L_2| \le r \le L_1 + L_2$：$0 \le 1.942 \le 2$ ✓，且 $\cos\theta_2 = (r^2 - 2)/2 = (3.77-2)/2 = 0.885$，$\theta_2 = \pm 27.7°$ 两解（elbow up/down）→ **2 个解**。目标 $(2.1, 0)$：$r = 2.1 > 2 = L_1+L_2$ → **不可达，无解**。
> - **解析**：$r = L_1+L_2$ 是可达域边界（奇异：臂完全伸直，两解退化为一解）；$r = |L_1-L_2|$ 是内边界（臂完全折叠）。
> - **易错原因**：只判断 $r \le L_1+L_2$ 忘记下界；把"一解（边界）"与"无解（域外）"混淆。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 5. 数值 IK 在奇异位形附近为什么会失效？工程上如何缓解？
> [!question]- 答案解析
> - **答案**：数值 IK 的迭代步 $\Delta\theta = J^\dagger e$，奇异位形处 $J$ 降秩（某些方向的末端运动关节给不出），伪逆 $J^\dagger$ 的元素趋于无穷 → $\Delta\theta$ 爆炸、关节速度超限、迭代发散；即使未完全奇异，条件数大的区域也会放大误差。缓解：① 阻尼最小二乘 DLS：$\Delta\theta = J^T(JJ^T + \lambda^2 I)^{-1}e$，$\lambda$ 吸收奇异方向的无穷增益；② 避开奇异区域规划（把奇异位形作为轨迹约束）；③ 对冗余臂用任务优先级（主任务 + 奇异规避次任务）。
> - **解析**：这是"解的存在性 → 解的稳定性"的进阶问题：奇异不是"没解"而是"解不稳定"；DLS 用可调参数 $\lambda$ 在"精确性"与"稳定性"之间折中，是工业 IK 的标准做法。
> - **易错原因**：只用纯伪逆；不知道 $\lambda$ 是敏感性分析的关键参数（HW05 可做"$\lambda$ vs 跟踪误差"曲线）。
> - **Obsidian 标签建议**：`#自测题/较难`
