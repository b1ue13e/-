# 四元数

## 0. 为什么学它

旋转矩阵 9 个数冗余，欧拉角有万向锁。**四元数**用 4 个数（单位范数）紧凑且**无奇异**地表示旋转，插值平滑（SLERP），是机器人、无人机、VR 姿态估计的实际标准。代价是运算规则稍抽象。

## 1. 核心定义

**四元数**：$q = w + xi + yj + zk = (w, \vec v)$，其中 $i^2=j^2=k^2=ijk=-1$。

**单位四元数**：$q^\top q = w^2+x^2+y^2+z^2 = 1$，表示纯旋转。

**轴角表示**：绕单位轴 $\hat u$ 转 $\theta$ ⟺ $q=\left(\cos\frac\theta2,\ \hat u\sin\frac\theta2\right)$。

**注意**：$q$ 与 $-q$ 表示同一旋转（双覆盖）；$w$ 是旋转角一半的余弦。

| 符号 | 含义 |
|:---|:---|
| $w$ | 标量部分 = $\cos(\theta/2)$ |
| $\vec v=(x,y,z)$ | 矢量部分 = $\hat u\sin(\theta/2)$ |
| $q^*=(w,-\vec v)$ | 共轭（逆旋转） |

## 2. 用四元数旋转向量

对向量 $v=(v_x,v_y,v_z)$，构造纯四元数 $p=(0,v)$，绕 $q$ 旋转：

$$p' = q\, p\, q^{-1},\qquad q^{-1}=q^*\ (\text{单位四元数}).$$

## 3. 最小可手算例子

**题目**：绕 $z$ 轴转 $90^\circ$ 的四元数，并旋转 $v=(1,0,0)$。

**解**：$\hat u=(0,0,1)$，$\theta=90^\circ$：$q=\left(\cos45^\circ,\ (0,0,1)\sin45^\circ\right)=\left(\frac{\sqrt2}{2},\ 0,0,\frac{\sqrt2}{2}\right)$。

用 $p'=qpq^{-1}$ 计算得 $p'=(0,0,1,0)$，即 $v'=(0,1,0)$ ✓（与 $R_z(90^\circ)$ 一致）。

**易错点**：忘记 $q$ 与 $-q$ 等价；旋转向量时用 $qpq^{-1}$ 而非 $qp$。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 把四元数当普通 4D 向量相加 | 四元数用乘法合成旋转，加法无物理意义 |
| 忘记单位化 | 只有单位四元数才表示纯旋转 |
| 忽略双覆盖 | $q$ 和 $-q$ 是同一旋转 |
