# 可操作性

## 0. 为什么学它

不是所有构型"一样好用"：靠近奇异时某些方向几乎不能动。**可操作性度量**用 Jacobian 的特征值量化"各方向运动/施力能力"，指导构型优化（如让机械臂处于灵巧位姿）——是奇异分析的量化升级。

## 1. 核心定义

**速度椭球**：$\lVert\dot q\rVert^2\le1 \Rightarrow \lVert J\dot q\rVert$ 构成椭球，半轴长 = $J$ 的奇异值 $\sigma_i$。

**可操作性度量**（Yoshikawa）：

$$\boxed{w=\sqrt{\det(JJ^\top)}=\sigma_1\sigma_2\cdots\sigma_m}$$

- $w=0$ ⟺ 奇异（某方向能力为零）；
- $w$ 越大 → 各方向能力越均衡。

**力椭球**：由 $\tau=J^\top F$，力椭球半轴与速度椭球成反比（$1/\sigma_i$）——速度好的方向力差，反之亦然（对偶性）。

## 2. 最小可手算例子

**题目**：2R 臂（$l_1=l_2=1$）在 $\theta_2=90^\circ$（L 形）与 $\theta_2=0^\circ$（伸直）的可操作性。

**解**：$J_v$ 的奇异值：
- $\theta_2=90^\circ$：两列 $\begin{pmatrix}-\sin\theta_1\\\cos\theta_1\end{pmatrix}$ 与 $\begin{pmatrix}-\sin(\theta_1+90°)\\\cos(\theta_1+90°)\end{pmatrix}$ 正交 → $\sigma_1=\sigma_2=1$（若 $l=1$）→ $w=1$（最灵巧）；
- $\theta_2=0^\circ$：两列相同 → $\sigma_2=0$ → $w=0$（奇异）。

**易错点**：$w$ 依赖尺度（臂长），跨构型比较才有意义。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| $w$ 越大越好没有代价 | 力椭球与速度椭球反比，需按任务权衡 |
| 只看标量 $w$ | 椭球方向（奇异向量）同样重要 |
| 忽略尺度依赖 | $w$ 有长度量纲，比较需同一尺度 |
