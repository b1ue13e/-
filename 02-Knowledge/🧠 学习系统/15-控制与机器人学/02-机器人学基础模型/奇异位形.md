# 奇异位形

## 0. 为什么学它

在**奇异位形**下，机械臂沿某个方向无法运动（该方向速度不可达），且关节力矩趋于无穷大。理解奇异的位置与后果，才能设计避奇异轨迹、分析工作空间边界——这是机器人使用中必须规避的危险状态。

## 1. 核心定义

**奇异位形**：Jacobian 秩亏的构型：

$$\det(JJ^\top)=0 \iff J\ \text{不满秩（非方阵时）};\qquad n=6:\ \det(J)=0.$$

**后果**：
1. 某方向末端速度不可达（速度椭球退化）；
2. 该方向需关节速度 $\dot q\to\infty$（数值爆炸）；
3. 末端力在该方向 → 关节力矩 $\tau\to\infty$（力奇异）。

**典型奇异**：
- **臂奇异**：机械臂完全伸直或缩回（$p_{end}$ 在可达边界）；
- **腕奇异**：球腕关节 4、6 轴对齐（$\theta_5=0$）；
- 两关节轴共线。

## 2. 最小可手算例子

**题目**：2R 臂（$l_1=l_2=1$）完全伸直时是否奇异？

**解**：$\theta_2=0$ 时 $J_v$ 两列 $\begin{pmatrix}-\sin\theta_1\\\cos\theta_1\end{pmatrix}$ 与 $\begin{pmatrix}-\sin\theta_1\\\cos\theta_1\end{pmatrix}$ **线性相关**（相同）→ $J$ 秩亏 → 奇异。几何意义：末端只能在"沿臂方向"运动，径向速度不可达 ✓。

**易错点**：只在数值上 $\det=0$ 才知道；应先分析几何构型。

## 3. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 奇异只在边界 | 内部也可能（腕奇异、共轴） |
| 奇异是软件 bug | 是机械结构固有的几何现象 |
| 绕过奇异就安全 | 接近奇异处速度/力矩已病态，需裕度 |

4. 为什么接近奇异很危险。
