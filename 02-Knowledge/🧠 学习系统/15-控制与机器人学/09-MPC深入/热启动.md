# 热启动

> **一句话**:相邻周期的问题几乎一样,把上一周期的解当作本轮迭代初值——迭代法从"接近解"的地方出发,收敛快一个数量级。

## 问题背景

滚动优化(见[[滚动优化]])每周期都要求解 QP,但相邻周期:

- 状态变化小(采样间隔短)
- 约束结构相同
- 最优解接近(只平移一步)

## 热启动机制

```
周期 k 求解得 U*_k
周期 k+1 初值: U_0 = shift(U*_k)   # 前移一步,末尾重复
迭代求解 → 快速收敛
```

- 一阶法(OSQP):初值直接进迭代(见[[OSQP]])
- 有效集法:保留上周期有效集(见[[有效集法]])

## 收益

| 指标 | 冷启动 | 热启动 |
|:---|:---|:---|
| 迭代次数 | 数百 | 数十(一个数量级↓) |
| 求解时间 | 数 ms | 亚 ms |
| 实时裕量 | 紧张 | 充裕 |

## 工程要点

| 要点 | 说明 |
|:---|:---|
| 状态突变 | 热启动失效 → 冷启动兜底 |
| 参考跳变 | 预移参考,保持初值接近 |
| 数值退化 | 定期重置防止误差累积 |
