# 热启动

> **一句话**：相邻周期的问题几乎一样，把上一周期的解当作本轮迭代初值——迭代法从"接近解"的地方出发，收敛快一个数量级。

## 0. 为什么学它

实时 MPC 的求解时间预算只有几毫秒，冷启动（从头迭代）常常不够。热启动是"让求解器从上一周期的解附近出发"的免费加速手段，与早期终止配合是嵌入式 MPC 的标配。

## 1. 问题背景

滚动优化（见[[滚动优化]]）每周期都要求解 QP，但相邻周期：

- 状态变化小（采样间隔短）；
- 约束结构相同；
- 最优解接近（只平移一步）。

## 2. 热启动机制

```
周期 k 求解得 U*_k
周期 k+1 初值: U_0 = shift(U*_k)   # 前移一步,末尾重复
迭代求解 → 快速收敛
```

- 一阶法（OSQP）：初值直接进迭代（见[[OSQP]]）；
- 有效集法：保留上周期有效集（见[[有效集法]]）。

## 3. 最小可手算例子（shift 初值）

**题目**：上周期解 $U^*_k = [1.0,\ 0.8,\ 0.5]$（$N=3$）。构造本周期初值。

**步骤**：
1. 前移一步：$[0.8, 0.5, ?]$；
2. 末尾重复/用上周期末值：$[0.8, 0.5, 0.5]$；
3. 该初值距本周真实解很近（若状态变化小）→ 迭代几次即收敛，冷启动要数百次。

**含义**：初值质量决定一阶法收敛步数——这就是"热启动快一个数量级"的机制。

## 4. 收益

| 指标 | 冷启动 | 热启动 |
|:---|:---|:---|
| 迭代次数 | 数百 | 数十（一个数量级↓） |
| 求解时间 | 数 ms | 亚 ms |
| 实时裕量 | 紧张 | 充裕 |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 热启动总能加速 | 状态突变/参考跳变时旧解失真，热启动失效需冷启动兜底 |
| 热启动影响精度 | 只影响收敛速度，收敛后解相同 |
| 只对一阶法有效 | 有效集法同样受益（保留有效集） |

## 6. 工程要点

| 要点 | 说明 |
|:---|:---|
| 状态突变 | 热启动失效 → 冷启动兜底 |
| 参考跳变 | 预移参考，保持初值接近 |
| 数值退化 | 定期重置防止误差累积 |
