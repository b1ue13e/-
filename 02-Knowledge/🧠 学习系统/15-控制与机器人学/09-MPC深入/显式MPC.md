# 显式MPC

> **一句话**：把 MPC 的在线优化"提前算完"——状态空间被划分成多个区域，每区域预存一个线性反馈律，在线只做查表，计算量降到微秒级。

## 0. 为什么学它

当采样频率高到 kHz 级（电力电子）或算力极受限（MCU）时，在线优化算不完。显式 MPC 用"离线算完 + 在线查表"绕过求解器，是实时性极限场景的解法。

## 1. 核心思想

线性 MPC 的优化解是**状态 $\mathbf{x}$ 的分片仿射函数**（由多参数规划性质保证）：

$$\mathbf{u}^*(\mathbf{x}) = F_i \mathbf{x} + G_i, \quad \mathbf{x} \in \mathcal{R}_i$$

- $\{\mathcal{R}_i\}$：状态空间划分的区域（凸多面体）；
- $F_i, G_i$：每区域预计算的反馈增益。

## 2. 离线 vs 在线

| 阶段 | 工作 |
|:---|:---|
| 离线 | 多参数二次规划（mp-QP）求解，划分区域 + 存增益 |
| 在线 | 定位当前 $\mathbf{x}$ 所在区域 → 查表得 $u$ |

## 3. 最小可手算例子（区域查表）

**题目**：一维状态 $x$，两个区域：$\mathcal{R}_1 = \{x \le 1\}$ 增益 $F_1 = -1$；$\mathcal{R}_2 = \{x > 1\}$ 增益 $F_2 = -2$。当前 $x = 1.5$，求 $u^*$。

**步骤**：
1. 定位：$1.5 > 1$ → 区域 $\mathcal{R}_2$；
2. 查表：$u^* = F_2 x = -2\times1.5 = -3$；
3. 在线计算=一次比较 + 一次乘法（微秒级）。

**含义**：在线"求解"退化为查表——这就是显式 MPC 的实时性来源。

## 4. 优缺点

| 优点 | 缺点 |
|:---|:---|
| 在线计算微秒级 | 区域数随 $N$、约束、维度**指数爆炸** |
| 确定性（无迭代） | 只能处理 LTI + 凸约束 |
| 嵌入式友好 | 存储量大（区域表） |
| 可验证性 | 参数变化需重新求解 |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 显式 MPC 通用 | 区域爆炸使高维/大 $N$ 不可行 |
| 在线也有迭代 | 在线只查表，无迭代 |
| 显式优于在线优化 | 存储/预处理成本高，仅极限实时场景值得 |

## 6. 检索练习（闭卷）

2. 手算一个查表例子；
3. 说明区域爆炸原因。
