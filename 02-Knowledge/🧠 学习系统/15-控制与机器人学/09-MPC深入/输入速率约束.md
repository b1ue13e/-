# 输入速率约束

> **一句话**：执行器不只"转到哪"受限，"转多快"也受限——转向率、油门变化率都有上限，写成 $\Delta \mathbf{u}_{min} \le \Delta \mathbf{u} \le \Delta \mathbf{u}_{max}$。

## 0. 为什么学它

只看幅值约束会算出"瞬间打满方向盘"的指令——执行器根本做不到，且横向 jerk 爆表。速率约束限制"变化快慢"，是执行器带宽、舒适性与控制抖动的共同约束。

## 1. 典型约束

$$|\mathbf{u}_{k+1} - \mathbf{u}_k| \le \Delta \mathbf{u}_{max}, \quad \forall k$$

| 执行器 | 速率约束示例 |
|:---|:---|
| 转向电机 | $\dot\delta \le 1.2\ \text{rad/s}$ |
| 油门 | 变化率限制（防突加速） |
| 制动 | 制动力建立速率 |

## 2. 最小可手算例子（转向率）

**题目**：$\dot\delta_{max} = 1.2$ rad/s，采样 $\Delta t = 0.05$ s，当前 $\delta = 0.5$ rad。求一步内转向角变化上限。

**步骤**：
1. 每步最大变化 $\Delta\delta = 1.2\times0.05 = 0.06$ rad；
2. 下一步 $\delta \in [0.44, 0.56]$ rad；
3. 若 MPC 想一步到 $\delta = 0.9$（超出 0.06）→ 违反速率约束 → 需多步到达。

**含义**：速率约束让"急打方向"变成"渐进打方向"，这是横向 jerk 受限的 MPC 表达。

## 3. 为什么重要

- 执行器物理限制：电机有最大转速；
- 舒适性：转向率大 → 横向 jerk 大；
- 稳定性：速率受限影响系统阻尼。

## 4. 增量形式的天然表达

用增量决策变量 $\Delta \mathbf{u}$（见[[增量MPC]]）后，**速率约束变成盒约束**：

$$\Delta \mathbf{u}_{min} \le \Delta \mathbf{u}_k \le \Delta \mathbf{u}_{max}$$

这是增量 MPC 的一大优势：幅值约束复杂化，速率约束简单化。

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 速率约束只对转向 | 油门/制动变化率同样受限 |
| 速率约束可以忽略 | 忽略 → 抖振/执行器跟不上 |
| 速率约束越松越好 | 过松 → 转向过猛，舒适性差 |

## 6. 检索练习（闭卷）

1. 写出速率约束形式；
2. 手算一个转向率例子；
3. 说明增量 MPC 中速率约束为何是盒约束。
