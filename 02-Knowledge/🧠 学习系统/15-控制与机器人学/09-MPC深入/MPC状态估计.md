# MPC状态估计

> **一句话**：MPC 需要完整状态，但传感器测不全——状态估计器（观测器/KF/EKF）在线重建状态，MPC 与估计器"分离原理"式搭配。

## 0. 为什么学它

MPC 的代价与约束都要求完整状态 $\mathbf{x}_k$，而实车只测部分量（如只测位置不测速度）。状态估计是 MPC 落地的前提——本卡把阶段 5 的观测器与阶段 10 的滤波知识接到 MPC 前级。

## 1. 为什么需要

- MPC 代价与约束都基于状态 $\mathbf{x}_k$；
- 真实系统只能测部分状态（如只测位置，不测速度）；
- 扰动模型增广后的 $\hat{\mathbf{d}}$ 也要估计（见[[扰动模型]]）。

## 2. 常用估计器

| 估计器 | 适用 | 说明 |
|:---|:---|:---|
| Luenberger 观测器 | 线性、确定性 | $\hat{\mathbf{x}}^+ = A\hat{\mathbf{x}} + Bu + L(\mathbf{y} - C\hat{\mathbf{x}})$ |
| Kalman 滤波 | 线性 + 高斯噪声 | 最优估计，见[[卡尔曼滤波KalmanFilter]] |
| EKF | 非线性 | 线性化扩展，见[[EKF非线性状态估计]] |
| 无迹 KF / 粒子滤波 | 强非线性 | 计算重 |

## 3. 最小可手算例子（观测器修正）

**题目**：标量系统 $x_{k+1} = 0.9x_k + 0.1u_k$，$y_k = x_k$，观测器增益 $L = 0.5$。$\hat x_k = 2$，$u_k = 1$，实测 $y_{k+1} = 2.9$。求 $\hat x_{k+1}$。

**步骤**：
1. 预测：$\hat x^-_{k+1} = 0.9\times2 + 0.1\times1 = 1.9$；
2. 修正：$\hat x_{k+1} = 1.9 + 0.5(2.9 - 1.9) = 1.9 + 0.5 = 2.4$；
3. 含义：观测器把"预测 1.9"向"实测 2.9"拉近一半（$L=0.5$ 决定信任度）。

**含义**：MPC 用的是 $\hat x$ 而非测量本身——噪声大时 $L$ 调小（信任预测），噪声小时调大。

## 4. 分离结构

```
传感器 y_k → 状态估计器 → x̂_k, d̂_k → MPC 优化 → u_k
```

- 估计器与控制器**分离设计**（类似[[分离原理]]）；
- 估计质量直接影响 MPC 性能：估计噪声 → 控制抖动。

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| MPC 直接用测量当状态 | 测量含噪声且有缺失，必须估计 |
| 估计器随意选 | 线性高斯用 KF，非线性用 EKF/UKF，强非线性用 PF |
| 忽略估计延迟 | 估计滞后 → MPC 用旧状态，需预测补偿 |

## 6. 工程要点

| 要点 | 说明 |
|:---|:---|
| 估计延迟 | 估计滞后 → MPC 用旧状态 → 需预测补偿 |
| 采样同步 | 估计器与 MPC 同频或快于 MPC |
| 故障 | 估计器发散 → 安全降级（切保守控制） |
