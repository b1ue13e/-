# 一阶QP

> **一句话**：一阶 QP 方法只做矩阵-向量乘法与投影——迭代简单、可提前终止、天然适配 MPC 的实时需求，是现代嵌入式求解器的核心。

## 0. 为什么学它

实时 MPC 的求解器（OSQP）几乎都是一阶方法：它们的迭代成本低、可随时停止、可热启动——这三个性质正好对应 MPC 的实时性需求。本卡是理解 OSQP 的算法前提。

## 1. 思想

对 QP 的 KKT 条件做**不动点迭代**，每次迭代只涉及：

1. 梯度计算：$z \leftarrow z - \alpha (Hz + g)$（可预分解）；
2. 约束投影：$z \leftarrow \text{proj}_{[l,u]}(z)$（盒约束）。

## 2. 代表性方法

| 方法 | 原理 | 特点 |
|:---|:---|:---|
| 投影梯度 | 梯度下降 + 投影 | 最简单，收敛慢 |
| FISTA/加速梯度 | Nesterov 加速 | 收敛 $O(1/k^2)$ |
| ADMM | 拆分成子问题交替 | OSQP 基础（见[[OSQP]]） |
| PGD（预条件梯度） | 对角预条件加速 | 收敛更快 |

## 3. 最小可手算例子（投影梯度一步）

**题目**：$\min \tfrac12 (z-3)^2$，约束 $z \le 2$，步长 $\alpha = 0.5$，初值 $z_0 = 0$。

**步骤**：
1. 梯度：$g = (z-3) = -3$；更新 $z = 0 - 0.5(-3) = 1.5$；
2. 投影：$1.5 \le 2$ 无需投影；
3. 再迭代：$g = 1.5-3 = -1.5$，$z = 1.5 + 0.75 = 2.25 > 2$ → 投影到 $2$。

**含义**：迭代就是"朝梯度反方向走 + 投影回可行集"，直到收敛。

## 4. 为什么适合 MPC

| 需求 | 一阶方法优势 |
|:---|:---|
| 实时性 | 迭代成本低（矩阵-向量积） |
| 时限内求解 | 可任意提前终止（见[[早期终止]]） |
| 热启动 | 上次解作初值，快速收敛（见[[热启动]]） |
| 嵌入式 | 内存小、实现简单 |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 一阶方法精度低不可用 | 实时 MPC 只需次优解，精度足够 |
| 一阶方法适合所有问题 | 大规模高精度离线问题仍用内点法 |
| 投影只对盒约束 | 一般线性约束可用 ADMM 交替投影处理 |
