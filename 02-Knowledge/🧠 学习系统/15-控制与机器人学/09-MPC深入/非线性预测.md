# 非线性预测

> **一句话**：当模型、约束或代价非线性时，MPC 变成非线性规划（NLP）——表达力强但求解难，是"把问题说清楚"与"算得动"之间的博弈。

## 0. 为什么学它

车辆动力学、魔术公式轮胎、摩擦圆约束都是非线性的。线性 MPC 在大偏差/紧急工况失效，NMPC 直接处理非线性——本卡讲清 NLP 的形式、求解方法与实时性对策，是阶段 9 车辆 MPC 的理论准备。

## 1. 非线性的来源

| 来源 | 例子 |
|:---|:---|
| 模型 | 车辆动力学、魔术公式轮胎（见[[魔术公式]]） |
| 约束 | 摩擦圆、避障凸分解 |
| 代价 | 非线性惩罚 |
| 目标 | 能量、任务特定 |

## 2. 问题形式（NLP）

$$\min_{x,u} \sum \ell(\mathbf{x}_k, \mathbf{u}_k) \quad \text{s.t.} \quad \mathbf{x}_{k+1} = f(\mathbf{x}_k, \mathbf{u}_k), \; h(\mathbf{x}, u) \le 0$$

## 3. 求解方法

| 方法 | 思想 | 工具 |
|:---|:---|:---|
| SQP | 迭代线性化 → 子 QP | CasADi, ACADO |
| 内点 | 障碍法（见[[内点法]]） | IPOPT |
| 直接打靶/配点 | 离散化 NLP | acados |
| RTI（实时迭代） | 每步单次 SQP 迭代 | acados |

## 4. 最小可手算例子（SQP 思想）

**题目**：约束 $g(u) = u^2 - 4 \le 0$（非线性），当前迭代点 $u = 1$。做一次线性化逼近。

**步骤**：
1. $g(1) = 1 - 4 = -3 < 0$（可行）；
2. 线性化：$g(u) \approx g(1) + g'(1)(u-1) = -3 + 2(u-1)$；
3. 下次迭代用该线性约束代替非线性约束求解——SQP 每步都是"线性化 + 子 QP"。

**含义**：NMPC 求解器把非线性问题逐步线性化迭代，直到收敛（或 RTI 只做一步就执行，靠滚动反馈兜底）。

## 5. 核心挑战

- **初值敏感**：非凸 → 多局部最优 → 热启动（见[[热启动]]）；
- **计算时间**：无法保证实时 → 早期终止 + RTI（见[[早期终止]]）；
- **代码生成**：acados/CasADi 生成高效 C 代码（见[[MPC代码生成]]）。

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| NMPC 一定比线性 MPC 好 | 求解慢、初值敏感；线性 MPC 在平衡点附近足够 |
| 非线性约束必须精确 | 工程常凸化/线性化近似以保实时 |
| 收敛到局部最优就算完 | 多局部最优下需热启动+多起点保证质量 |

## 7. 工程路径

1. 线性 MPC 打底（量产）；
2. 关键场景（紧急/大偏差）启用 NMPC；
3. 用 RTI + 热启动控制算力。

## 8. 检索练习（闭卷）

2. 写出 NLP 形式；
3. 说明初值敏感性与 RTI 对策。

- 能解释实时性对策。
