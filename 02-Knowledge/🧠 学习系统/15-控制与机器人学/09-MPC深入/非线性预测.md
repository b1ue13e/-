# 非线性预测

> **一句话**:当模型、约束或代价非线性时,MPC 变成非线性规划(NLP)——表达力强但求解难,是"把问题说清楚"与"算得动"之间的博弈。

## 非线性的来源

| 来源 | 例子 |
|:---|:---|
| 模型 | 车辆动力学、魔术公式轮胎(见[[魔术公式]]) |
| 约束 | 摩擦圆、避障凸分解 |
| 代价 | 非线性惩罚 |
| 目标 | 能量、任务特定 |

## 问题形式(NLP)

$$\min_{x,u} \sum \ell(\mathbf{x}_k, \mathbf{u}_k) \quad \text{s.t.} \quad \mathbf{x}_{k+1} = f(\mathbf{x}_k, \mathbf{u}_k), \; h(\mathbf{x}, u) \le 0$$

## 求解方法

| 方法 | 思想 | 工具 |
|:---|:---|:---|
| SQP | 迭代线性化 → 子 QP | CasADi, ACADO |
| 内点 | 障碍法(见[[内点法]]) | IPOPT |
| 直接打靶/配点 | 离散化 NLP | acados |
| RTI(实时迭代) | 每步单次 SQP 迭代 | acados |

## 核心挑战

- **初值敏感**:非凸 → 多局部最优 → 热启动(见[[热启动]])
- **计算时间**:无法保证实时 → 早期终止 + RTI(见[[早期终止]])
- **代码生成**:acados/CasADi 生成高效 C 代码(见[[MPC代码生成]])

## 工程路径

1. 线性 MPC 打底(量产)
2. 关键场景(紧急/大偏差)启用 NMPC
3. 用 RTI + 热启动控制算力
