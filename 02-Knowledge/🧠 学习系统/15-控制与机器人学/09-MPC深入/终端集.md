# 终端集

> **一句话**：终端集是给预测末端状态套的"安全笼子"——末端必须落在某个可稳定收敛的区域内，保证下一步优化永远有解。

## 0. 为什么学它

终端代价解决了"尾部成本"，但还没解决"下一时刻还有没有可行解"。终端集通过"控制不变性"保证：只要上一步末端在集合内，下一步必有可行解——这是 MPC 递归可行性与稳定性的第二块拼图。

## 1. 定义

终端集 $\mathcal{X}_f$：满足以下性质的集合：

1. **控制不变性**：对 $\forall \mathbf{x} \in \mathcal{X}_f$，存在局部控制器 $\mathbf{u} = K\mathbf{x}$ 使 $\mathbf{x}^+ = (A+BK)\mathbf{x} \in \mathcal{X}_f$；
2. **约束满足**：$\mathcal{X}_f$ 内状态和控制满足所有约束；
3. **稳定**：局部控制器 $K$ 使系统稳定。

典型形式：椭圆集或多边形集

$$\mathcal{X}_f = \{ \mathbf{x} \mid \mathbf{x}^\top P \mathbf{x} \le \alpha \}$$

## 2. 终端集的作用

| 作用 | 说明 |
|:---|:---|
| 可行性延续 | 上一步末端在 $\mathcal{X}_f$ → 下一步从 $\mathcal{X}_f$ 出发有解 |
| 稳定性论证 | 与终端代价配合完成 Lyapunov 证明（见[[MPC稳定性]]） |
| 约束保证 | 末端以后由局部控制器接管，约束不破 |

## 3. 最小可手算例子（不变性直觉）

**题目**：标量系统 $x_{k+1} = 0.5x_k + u$，局部控制器 $u = -0.3x$（稳定）。判断集合 $\mathcal{X}_f = \{x : |x| \le 1\}$ 是否不变。

**步骤**：
1. 闭环：$x^+ = (0.5 - 0.3)x = 0.2x$；
2. 对 $|x| \le 1$：$|x^+| = 0.2|x| \le 0.2 < 1$ → **仍在集合内**；
3. 且约束 $|u| = 0.3|x| \le 0.3$ 满足 → $\mathcal{X}_f$ 是控制不变集 ✓。

**含义**：一旦状态进入终端集，局部控制器能保证永远留在集合内且收敛——这就是"可行性延续"的机制。

## 4. 工程获得方法

- 从 LQR 增益 $K$ 出发，找满足约束的椭圆集 $\mathcal{X}_f$（计算 $\alpha$）；
- 或直接简化为"末端状态尽量接近原点"的软约束；
- 保守但简单：把 $N_p$ 加长代替终端集。

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 终端集 = 终端代价 | 代价管"尾部成本"，集合管"尾部可行性"，两者配合 |
| 终端集越大越好 | 太大可能不满足约束/不变性，需精细计算 |
| 工程不用终端集 | 严格论证需要；工程常用加长 $N_p$ 近似 |
