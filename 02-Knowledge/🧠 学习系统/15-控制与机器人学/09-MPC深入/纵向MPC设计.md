# 纵向MPC设计

> **一句话**：纵向 MPC 用预测模型优化"加速度序列"——同时满足速度跟踪、安全车距、舒适加速度三目标，是 ACC/定速巡航的高配实现。

## 0. 为什么学它

阶段 7 的 PI 速度控制是反应式；纵向 MPC 能预测前车减速、提前平滑制动（而非到点急刹），并能显式把"最小车距"写进约束——安全与舒适兼顾。

## 1. 设计要素

| 要素 | 内容 |
|:---|:---|
| 状态 | $[s, v, a]$（纵向位置/速度/加速度） |
| 控制量 | 期望加速度 $a_{des}$（或踏板） |
| 模型 | 纵向动力学（见[[纵向方程]]） |
| 约束 | $\lvert a \rvert \le a_{max},\ s_{gap} \ge d_{safe}$ |
| 代价 | 速度误差 + 车距误差 + 加速度（jerk）惩罚 |

## 2. 三目标权衡

$$J = w_v (v - v_{ref})^2 + w_s (s_{gap} - d_{des})^2 + w_a a^2$$

- $w_v$ 大：紧追设定速度；
- $w_s$ 大：保持安全车距（跟车优先）；
- $w_a$ 大：舒适（少加减速）。

## 3. 最小可手算例子（车距约束）

**题目**：前车急刹，预测本车若保持当前加速度会在 3 步后 $s_{gap} = 2$ m < $d_{safe} = 5$ m。MPC 会怎样？

**步骤**：
1. 约束 $s_{gap} \ge 5$ 被违反 → 该控制序列不可行；
2. 优化器必须降低 $a$（减速），使预测车距 $\ge 5$；
3. 若 $a_{min}$ 仍不够 → 松弛/紧急制动。

**含义**：纵向 MPC 把"安全车距"变成硬约束，预测式减速优于反应式急刹。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 纵向 MPC 只跟速度 | 核心是车距+速度双目标，安全优先 |
| 加速度无约束 | 舒适/执行器都限制加速度与 jerk |
| 纵向与横向独立最优 | 摩擦圆耦合（见[[Frenet耦合]]），需联合检查 |

## 5. 检索练习（闭卷）

1. 写出纵向 MPC 设计要素；
2. 手算车距约束判定；
3. 说明三目标权衡。

- 能说明与横向的关系。
