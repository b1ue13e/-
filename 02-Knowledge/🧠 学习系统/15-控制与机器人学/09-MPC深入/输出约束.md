# 输出约束

> **一句话**：关心的是"产品指标"——温度、位置、车距等输出量受限，用 $C\mathbf{x}_k$ 写进约束 $\mathbf{y}_{min} \le C\mathbf{x}_k \le \mathbf{y}_{max}$。

## 0. 为什么学它

控制器最终要保证的是"输出"达标（温度不超限、车距不小、位置不出界），而不是状态本身。输出约束把"可见指标"直接写进优化，是过程控制与车辆控制共同的需求。

## 1. 定义

输出 $\mathbf{y}_k = C\mathbf{x}_k$，约束：

$$\mathbf{y}_{min} \le \mathbf{y}_k \le \mathbf{y}_{max}, \quad \forall k$$

## 2. 与状态约束的关系

- 输出约束是状态约束的特例（$\mathbf{y} = C\mathbf{x}$）；
- 实际约束对象：被控输出（温度、压力、位置、车速）；
- 常与状态约束并存：输出约束管"可见指标"，状态约束管"内部状态"。

## 3. 典型应用

| 场景 | 输出约束 |
|:---|:---|
| 温度控制 | $T_{min} \le T \le T_{max}$ |
| 车距保持 | 最小安全间距 $s_{gap} \ge d_{safe}$ |
| 横向跟踪 | $\lvert d \rvert \le$ 车道边界 |
| 过程控制 | 产品质量指标上下限 |

## 4. 最小可手算例子（预测输出约束）

**题目**：$C = [1, 0]$，预测 $x = [4, 2]^T$，输出约束 $y \le 3$。判断是否可行（$y = x_1$）。

**步骤**：
1. $y = Cx = 4 > 3$ → 违反输出约束；
2. 若无松弛：该预测序列不可行，优化器必须调整 $U$ 使 $x_1 \le 3$；
3. 若带松弛（见[[松弛变量]]）：$y \le 3 + \epsilon$，$\epsilon = 1$ 可付费通过。

**含义**：输出约束直接约束"用户看得见的量"，比状态约束更贴合物理任务。

## 5. 预测中的表达

预测输出 $\mathbf{Y} = C\Phi\mathbf{x}_k + C\Gamma\mathbf{U}$（见[[预测方程]]），约束展开为关于 $\mathbf{U}$ 的线性约束：

$$\mathbf{Y}_{min} \le C\Phi\mathbf{x}_k + C\Gamma\mathbf{U} \le \mathbf{Y}_{max}$$

## 6. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 输出约束=状态约束 | 输出是 $Cx$ 的投影，约束对象不同 |
| 只约束输出就够 | 内部状态（如速度）同样需要约束 |
| 输出约束默认硬 | 安全类硬、性能类软，需取舍 |

## 7. 检索练习（闭卷）

1. 写出输出约束形式；
2. 手算一个预测输出约束判定；
3. 说明软硬取舍。

## 8. 通过标准

- 能写出输出约束；
- 能手算判定；
- 能展开为 $U$ 的约束。
