# 输出约束

> **一句话**:关心的是"产品指标"——温度、位置、车距等输出量受限,用 $C\mathbf{x}_k$ 写进约束 $\mathbf{y}_{min} \le C\mathbf{x}_k \le \mathbf{y}_{max}$。

## 定义

输出 $\mathbf{y}_k = C\mathbf{x}_k$,约束:

$$\mathbf{y}_{min} \le \mathbf{y}_k \le \mathbf{y}_{max}, \quad \forall k$$

## 与状态约束的关系

- 输出约束是状态约束的特例($\mathbf{y} = C\mathbf{x}$)
- 实际约束对象:被控输出(温度、压力、位置、车速)
- 常与状态约束并存:输出约束管"可见指标",状态约束管"内部状态"

## 典型应用

| 场景 | 输出约束 |
|:---|:---|
| 温度控制 | $T_{min} \le T \le T_{max}$ |
| 车距保持 | 最小安全间距 $s_{gap} \ge d_{safe}$ |
| 横向跟踪 | $|d| \le$ 车道边界 |
| 过程控制 | 产品质量指标上下限 |

## 预测中的表达

预测输出 $\mathbf{Y} = C\Phi\mathbf{x}_k + C\Gamma\mathbf{U}$(见[[预测方程]]),约束展开为关于 $\mathbf{U}$ 的线性约束:

$$\mathbf{Y}_{min} \le C\Phi\mathbf{x}_k + C\Gamma\mathbf{U} \le \mathbf{Y}_{max}$$

## 软硬之分

- 安全类输出约束 → 硬约束(见[[状态硬约束]])
- 性能类输出约束 → 软约束 + 松弛(见[[状态软约束]])
