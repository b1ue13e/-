# 有效集法

> **一句话**：猜哪些约束"起作用"（有效集），当成等式约束解一次 KKT，再根据对偶变量增删约束——约束少时极快，MPC 小问题时首选。

## 0. 为什么学它

有效集法是小规模 MPC（车辆横向、约束不多）的经典选择，且天然可热启动——理解它的"猜-解-改"循环，才能理解 qpOASES 这类求解器为何在嵌入式 MPC 中流行。

## 1. 核心思想

- 假设最优解处约束集合（有效集 $\mathcal{W}$）已知；
- 有效约束当等式处理 → 求解等式约束 KKT（线性系统）；
- 检查乘子：负乘子的约束应从有效集删除；违反的不等式加入。

## 2. 迭代流程

```
1. 初始可行解 + 初始有效集 W
2. 解等式约束子问题（固定 W）
3. 若不可行：沿方向走到约束边界，更新 W
4. 若可行但乘子为负：删除该约束，重解
5. 满足 KKT 条件 → 最优
```

## 3. 最小可手算例子（有效集直觉）

**题目**：$\min \tfrac12 z^2$，约束 $z \ge 1$。猜有效集为空，解 $z=0$。

**步骤**：
1. 解无约束：$z = 0$；
2. 检查约束：$0 < 1$ **违反** → 把 $z \ge 1$ 加入有效集；
3. 重解（等式 $z=1$）：$z = 1$，乘子 $\lambda = 1 > 0$ → 最优。

**含义**：有效集法就是"猜约束→解等式子问题→按 KKT 修正集合"的循环，约束个数少时每步只是小线性系统。

## 4. 优缺点

| 优点 | 缺点 |
|:---|:---|
| 约束少时极快（每步小线性系统） | 约束多时迭代次数多 |
| 高精度 | 初始可行点难找（一般/退化） |
| 可热启动（保留上次有效集） | 有效集频繁变化时慢 |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 有效集法约束越多越快 | 约束多时集合猜测次数多，反而不利 |
| 有效集法适合一切 MPC | 大 $N$ 大规模场景用一阶法更合适 |
| 有效集法可随意热启动 | 热启动需保留上次有效集，简单有效 |
