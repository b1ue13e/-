# 有效集法

> **一句话**:猜哪些约束"起作用"(有效集),当成等式约束解一次 KKT,再根据对偶变量增删约束——约束少时极快,MPC 小问题时首选。

## 核心思想

- 假设最优解处约束集合(有效集 $\mathcal{W}$)已知
- 有效约束当等式处理 → 求解等式约束 KKT(线性系统)
- 检查乘子:负乘子的约束应从有效集删除;违反的不等式加入

## 迭代流程

```
1. 初始可行解 + 初始有效集 W
2. 解等式约束子问题(固定 W)
3. 若不可行:沿方向走到约束边界,更新 W
4. 若可行但乘子为负:删除该约束,重解
5. 满足 KKT 条件 → 最优
```

## 优缺点

| 优点 | 缺点 |
|:---|:---|
| 约束少时极快(每步小线性系统) | 约束多时迭代次数多 |
| 高精度 | 初始可行点难找(一般/退化) |
| 可热启动(保留上次有效集) | 有效集频繁变化时慢 |

## 与 MPC 的适配

- 车辆 MPC 约束数中等(输入 + 输出)
- 热启动:上周期有效集接近本周 → 快速收敛(见[[热启动]])
- 实现库:qpOASES(经典有效集求解器)

## 对比

| 方法 | 适用 |
|:---|:---|
| 有效集 | 小/中规模、约束稀疏、可热启动 |
| 内点 | 大规模、高精度、离线 |
| 一阶 | 大规模、实时、可提前终止 |
