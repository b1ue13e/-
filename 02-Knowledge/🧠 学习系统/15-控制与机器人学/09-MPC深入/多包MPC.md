# 多包MPC

> **一句话**:用一组线性模型覆盖工作区间,每模型配一个预计算 MPC 控制器,在线按当前工况选择/插值——"以线性拼非线性"的工程智慧。

## 思想

系统在不同工况(速度、负载、状态)下行为差异大,单一线性模型不准,但非线性 MPC 太贵:

- 把工作区间划分为多个"包"(区域)
- 每包:线性化模型 + 预计算 MPC(增益/矩阵)
- 在线:按当前状态选包或插值

## 结构

```
工况判定(速度/负载)
  ↓
选择包 i: A_i, B_i, Q_i, R_i → 求解 QP
```

## 关键设计

| 要素 | 说明 |
|:---|:---|
| 分区 | 按主导参数(速度)划分 |
| 控制器切换 | 硬切换 / 软插值(权重) |
| 重叠区 | 平滑过渡(防抖) |
| 预计算 | 离线设计各包参数 |

## 与增益调度的关系

- **增益调度**(见[[增益调度]]):调度连续增益
- **多包 MPC**:调度离散控制器集合(每个都是 MPC)
- 本质:用"局部线性 + 切换"逼近非线性

## 优缺点

| 优点 | 缺点 |
|:---|:---|
| 实时(QP 求解) | 包边界切换可能抖动 |
| 覆盖广 | 设计工作量大 |
| 工程成熟 | 区域间一致性需验证 |
