# 松弛变量

> **一句话**:松弛变量是约束的"泄压阀"——约束本来不可行时,松弛变量吸收违反量并计入代价,让优化永远可行。

## 核心思想

把约束放宽:

$$\mathbf{x}_k \le \mathbf{x}_{max} + \epsilon_k$$

$\epsilon_k \ge 0$ 是松弛变量。代价加入惩罚:

$$J = J_{nominal} + \sum_k \rho \|\epsilon_k\|$$

## 为什么需要

1. **扰动**:真实状态被推出约束外,硬约束无解
2. **模型误差**:预测与真实不一致
3. **数值/初始化**:求解过程中暂时不可行

没有松弛 → 求解失败 → MPC 无输出(崩溃)。

## 松弛的类型

| 类型 | 形式 | 特点 |
|:---|:---|:---|
| 标量松弛 | 单一 $\epsilon$ | 简单 |
| 逐约束松弛 | 每约束一个 $\epsilon_i$ | 精细,变量多 |
| 时变松弛 | 每步 $\epsilon_k$ | 灵活性高 |

## 惩罚权重 $\rho$ 的选择

- $\rho$ 大 → 接近硬约束(但可能重新不可行)
- $\rho$ 小 → 约束形同虚设
- 分层松弛:安全约束 $\rho$ 大,舒适约束 $\rho$ 小

## 工程要点

| 要点 | 说明 |
|:---|:---|
| 松弛是"最后手段" | 正常情况松弛应为 0 |
| 监控松弛量 | 松弛持续 > 0 → 诊断约束/模型问题 |
| 与软约束关系 | 软约束 = 约束 + 松弛变量的实现 |
