# 松弛变量

> **一句话**：松弛变量是约束的"泄压阀"——约束本来不可行时，松弛变量吸收违反量并计入代价，让优化永远可行。

## 0. 为什么学它

"MPC 崩溃"（求解失败无输出）在安全系统中不可接受。松弛变量是防止崩溃的标准机制：给约束留一个"可付费的违反通道"，让优化器永远有解。

## 1. 核心思想

把约束放宽：

$$\mathbf{x}_k \le \mathbf{x}_{max} + \epsilon_k$$

$\epsilon_k \ge 0$ 是松弛变量。代价加入惩罚：

$$J = J_{nominal} + \sum_k \rho \lVert \epsilon_k \rVert$$

## 2. 为什么需要

1. **扰动**：真实状态被推出约束外，硬约束无解；
2. **模型误差**：预测与真实不一致；
3. **数值/初始化**：求解过程中暂时不可行。

没有松弛 → 求解失败 → MPC 无输出（崩溃）。

## 3. 最小可手算例子（标量松弛）

**题目**：$x \le 3$，扰动使 $x = 3.4$ 无法避免。求最小 $\epsilon$ 与罚金（$\rho = 20$）。

**步骤**：
1. $\epsilon = 3.4 - 3 = 0.4$；
2. 罚金 $= 20 \times 0.4^2 = 3.2$；
3. 优化器在"付 3.2 违反"与"其他控制代价"之间权衡——若强行不违反则无解，松弛提供出路。

**含义**：松弛让"不可行问题"变成"可行但昂贵"，工程上远优于崩溃。

## 4. 松弛的类型

| 类型 | 形式 | 特点 |
|:---|:---|:---|
| 标量松弛 | 单一 $\epsilon$ | 简单 |
| 逐约束松弛 | 每约束一个 $\epsilon_i$ | 精细，变量多 |
| 时变松弛 | 每步 $\epsilon_k$ | 灵活性高 |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 松弛越大越好 | 松弛应默认 0，仅在必要时启用 |
| $\rho$ 随便给 | $\rho$ 决定违反代价，需按约束重要性分层 |
| 松弛与软约束无关 | 软约束 = 约束 + 松弛变量的实现 |

## 6. 工程要点

| 要点 | 说明 |
|:---|:---|
| 松弛是"最后手段" | 正常情况松弛应为 0 |
| 监控松弛量 | 松弛持续 > 0 → 诊断约束/模型问题 |
| 与软约束关系 | 软约束 = 约束 + 松弛变量的实现 |
