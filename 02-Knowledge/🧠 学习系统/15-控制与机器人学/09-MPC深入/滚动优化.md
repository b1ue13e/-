# 滚动优化

> **一句话**：MPC 的精髓——"算一步，走一步，再算一步"：每个采样周期重新优化，只用第一步控制，然后滚动前进。

## 0. 为什么学它

MPC 与"一次性算出最优解"的开环最优控制的本质区别就在这里：滚动优化带来**反馈**，让每一步都基于最新状态修正，是 MPC 抗扰动的根源。理解它才能回答"MPC 为什么鲁棒"。

## 1. 流程（Receding Horizon）

```
在每个采样时刻 t_k:
1. 测量/估计当前状态 x_k
2. 在 [t_k, t_k+N] 上求解优化问题 → 最优控制序列 U*
3. 只执行第一步 u_k = U*[0]
4. 时刻 t_{k+1}:重复（窗口整体前移）
```

## 2. 为什么只执行第一步

- 预测模型有误差、扰动存在 → 长计划不可信；
- 每步用**最新状态反馈**修正 → 闭环鲁棒性；
- 窗口滑动 → 全局规划隐含在局部优化中。

## 3. 最小可手算例子（反馈修正）

**题目**：$N=3$ 的最优序列 $U^* = [1.0,\ 0.5,\ 0.2]$。$k$ 步后实测状态比预测偏差 0.3。说明执行策略。

**步骤**：
1. 只执行 $u_k = 1.0$（第一步）；
2. $k+1$ 时刻重新测量、重新优化（新序列可能完全不同，如 $[1.2, 0.4, ...]$）；
3. 若执行整个 $U^*$（开环），0.3 的偏差会沿预测链放大——滚动修正把它"每步重置"。

**含义**：滚动优化 = 每步把不确定性"清零重来"，这是鲁棒性的数学来源。

## 4. 与开环最优控制的区别

| 特性 | 开环最优 | 滚动优化（MPC） |
|:---|:---|:---|
| 反馈 | 无（一次性算完） | 每步反馈 |
| 抗扰动 | 差 | 强 |
| 约束 | 可处理 | 可处理 |
| 计算 | 一次 | 每周期一次 |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| MPC 是开环控制 | 滚动优化自带反馈，属于闭环 |
| 执行整条最优序列 | 只执行第一步，其余作废 |
| 滚动与重规划无关 | 滚动本身就是"每步重规划" |

## 6. 滚动优化的代价

- 每采样周期都要重新求解 → 实时性压力（见[[早期终止]]/[[热启动]]）；
- 解可能随时间步"抖动"（非平滑）→ 需增量式处理（见[[增量MPC]]）。

## 7. 检索练习（闭卷）

1. 写出滚动优化四步流程；
2. 手算一个"只执行第一步+重新优化"的例子；
3. 对比开环最优与滚动优化。

## 8. 通过标准

- 能描述滚动优化流程；
- 能解释反馈修正的鲁棒性；
- 能说明实时性与抖动代价。
