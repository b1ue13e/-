# 滚动优化

> **一句话**:MPC 的精髓——"算一步,走一步,再算一步":每个采样周期重新优化,只用第一步控制,然后滚动前进。

## 流程(Receding Horizon)

```
在每个采样时刻 t_k:
1. 测量/估计当前状态 x_k
2. 在 [t_k, t_k+N] 上求解优化问题 → 最优控制序列 U*
3. 只执行第一步 u_k = U*[0]
4. 时刻 t_{k+1}:重复(窗口整体前移)
```

## 为什么只执行第一步

- 预测模型有误差、扰动存在 → 长计划不可信
- 每步用**最新状态反馈**修正 → 闭环鲁棒性
- 窗口滑动 → 全局规划隐含在局部优化中

## 与开环最优控制的区别

| 特性 | 开环最优 | 滚动优化(MPC) |
|:---|:---|:---|
| 反馈 | 无(一次性算完) | 每步反馈 |
| 抗扰动 | 差 | 强 |
| 约束 | 可处理 | 可处理 |
| 计算 | 一次 | 每周期一次 |

## 滚动优化的代价

- 每采样周期都要重新求解 → 实时性压力(见[[早期终止]]/[[热启动]])
- 解可能随时间步"抖动"(非平滑)→ 需增量式处理(见[[增量MPC]])
