# MPC积分

> **一句话**：模型失配/扰动会让 MPC 有稳态误差——把误差的积分（或扰动估计）加进模型，消除稳态偏差，这就是 MPC 的"积分作用"。

## 0. 为什么学它

MPC 靠模型预测，模型一不准就有稳态误差（如定速巡航的实际速度总差 0.5 km/h）。没有积分作用，MPC 和 PID 没有积分一样"消不掉偏差"。本卡给出两种主流消除方案。

## 1. 问题：MPC 为什么有稳态误差

MPC 基于模型优化，若模型与真实系统不一致（参数偏差、未建模扰动），输出将偏离参考且无法消除 → 稳态误差。

## 2. 解决方案

### 2.1 误差积分增广

状态增广积分项 $\mathbf{e}_I$：

$$\mathbf{e}_{I,k+1} = \mathbf{e}_{I,k} + \mathbf{e}_k \cdot \Delta t$$

代价加 $\lVert \mathbf{e}_I \rVert_{Q_I}^2$ → 类 PID 的积分作用，消除稳态误差。

### 2.2 扰动模型（主流）

把常量扰动 $\mathbf{d}$ 增广为状态（见[[扰动模型]]）：

$$\mathbf{x}_{k+1} = A\mathbf{x}_k + B\mathbf{u}_k + B_d \mathbf{d}_k, \quad \mathbf{d}_{k+1} = \mathbf{d}_k$$

用状态估计器（见[[MPC状态估计]]）在线估计 $\mathbf{d}$ → 前馈补偿，稳态无偏。

## 3. 最小可手算例子（积分增广）

**题目**：误差序列 $e = [1, -0.5, 0.3]$，$\Delta t = 0.1$。求积分项 $e_I$ 序列。

**步骤**：
1. $e_{I,1} = 0 + 1\times0.1 = 0.1$；
2. $e_{I,2} = 0.1 + (-0.5)(0.1) = 0.05$；
3. $e_{I,3} = 0.05 + 0.3\times0.1 = 0.08$——积分项保留"历史误差记忆"，驱动 MPC 持续修正直到误差归零。

**含义**：积分项进入代价后，任何持续的非零误差都会累积惩罚，迫使 MPC 输出补偿。

## 4. 对比

| 方法 | 优点 | 缺点 |
|:---|:---|:---|
| 积分增广 | 简单 | 易超调、抗饱和需额外处理 |
| 扰动模型 | 物理意义清晰、可前馈 | 需观测器、增广模型 |

## 5. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 模型准就不需要积分 | 真实系统总有失配，积分/扰动是标配 |
| 两种方法等价 | 积分增广是输出通道积分；扰动模型是物理扰动估计，可前馈 |
| 积分无副作用 | 约束激活时积分饱和，需增量形式/松弛处理 |
