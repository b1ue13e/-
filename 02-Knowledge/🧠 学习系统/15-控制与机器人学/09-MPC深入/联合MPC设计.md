# 联合MPC设计

> **一句话**：把转向与加速度放进同一个优化同时求——联合 MPC 显式处理"边转向边制动"的轮胎耦合（摩擦圆），是换道/避障/极限工况的正解。

## 0. 为什么学它

换道（横向动作）+ 减速（纵向动作）同时发生时，两个独立 MPC 可能抢轮胎附着。联合 MPC 在一个优化里协调 $\delta$ 与 $a$，是激烈工况（见[[耦合MPC]]/[[Frenet耦合]]）的工程实现。

## 1. 设计要素

| 要素 | 内容 |
|:---|:---|
| 状态 | $[s, \dot s, d, \dot d, \delta, \dot\delta]$（Frenet 联合） |
| 控制量 | $[a_{des}, \delta_{des}]$（双通道） |
| 模型 | 纵横向动力学联合 + 摩擦圆 |
| 约束 | 摩擦圆 $a_x^2 + a_y^2 \le (\mu g)^2$、转向/速率、车距 |
| 代价 | 横纵误差 + 控制量（见[[MPC代价函数]]） |

## 2. 联合 vs 分开设计

| 维度 | 横纵分开 | 联合 MPC |
|:---|:---|:---|
| 摩擦圆 | 事后限幅 | 优化内约束 |
| 换道+减速 | 可能抢附着 | 协调分配 |
| 计算 | 两个小 QP | 一个大 QP/NLP |
| 工况 | 常规 | 换道/紧急 |

## 3. 最小可手算例子（附着分配）

**题目**：换道需要 $a_y = 3$，同时要减速 $a_x = 6$。$\mu g = 7.84$。联合 MPC 怎么处理？

**步骤**：
1. $a_x^2 + a_y^2 = 36 + 9 = 45 < 61.5$ ✓ 可行；
2. 若需要 $a_x = 7.5$：$56.25 + 9 = 65.25 > 61.5$ ✗；
3. 优化器自动降低 $a_x$ 或 $a_y$（如 $a_x=7,\ a_y=3$ → 58 < 61.5 ✓）——在约束内最优分配。

**含义**：联合 MPC 把"轮胎抢附着"变成约束内的自动协调，分开设计做不到。

## 4. 常见误区

| 误区 | 正确理解 |
|:---|:---|
| 联合 MPC 总优于分开 | 计算量大、调参复杂，常规工况分开足够 |
| 摩擦圆只在极限 | 换道+急刹等常见组合就会触发 |
| 联合=叠加两个 MPC | 是耦合优化，不是两个独立问题拼装 |

## 5. 检索练习（闭卷）

1. 写出联合设计要素；
2. 手算摩擦圆分配；
3. 对比分开 vs 联合。

## 6. 通过标准

- 能设计联合 MPC；
- 能手算附着分配；
- 能说明工程取舍。
