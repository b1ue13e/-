# 🧭 开源作业体系-控制与机器人学

> 本页是「控制与机器人学」的开源教材与作业体系的**唯一挂载点**：教材主线、官方作业链 HW01-HW06、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**PythonRobotics 官方仓库**（https://github.com/AtsushiSakai/PythonRobotics，MIT License），以《Probabilistic Robotics》《Modern Robotics》与开源讲义为理论主线。

| HW | 主题 | 官方来源（PythonRobotics demo） | 所需知识点（双链） | 验收方式（固定仿真场景 + 轨迹误差指标 + 对比基线） |
|:---|:---|:---|:---|:---|
| HW01 | LQR 与非线性 MPC 轨迹跟踪 | `lqr_steering_control.py`、`model_predictive_speed_and_steering_control.py` | [[状态空间与LQR控制]]、[[PID控制器与状态空间法]] | 按 [[控制与机器人学 - HW01：LQR 与非线性 MPC 轨迹跟踪阶梯作业|HW01 说明书]] 阶梯：L1 倒立摆 PID 稳 10s → L2 手解 Riccati → L3 轨迹误差 < 5cm → L4 导航成功率 ≥ 95%；基线 = 官方 demo 输出 |
| HW02 | 移动机器人运动学与路径规划 A* / RRT | `a_star_search.py`、`rrt.py`、`rrt_star.py` | [[路径规划Astar与RRT]]、[[03-移动机器人与车辆模型/差分驱动\|差分驱动]]、[[03-移动机器人与车辆模型/非完整约束\|非完整约束]] | 固定 50×50 栅格迷宫：A* 路径长度 = Dijkstra 最优长度；RRT* 收敛到最优的 1.05 倍以内；10 组随机种子成功率 100% |
| HW03 | 纯跟踪与 Stanley 横向控制 | `pure_pursuit.py`、`stanley_control.py` | [[纯跟踪与Stanley控制器]]、[[PID控制器与状态空间法]] | 固定八字绕环路径：横向误差 RMS < 0.3 m（PP）/ < 0.15 m（Stanley）；对比 PID 横向控制器基线 |
| HW04 | 卡尔曼滤波与状态估计 | `ekf_localization.py`、`particle_filter_localization.py` | [[卡尔曼滤波KalmanFilter]]、[[03-移动机器人与车辆模型/里程计\|里程计]] | 固定仿真场景（GPS + 里程计）：EKF 定位 RMSE < 0.5 m；对比纯里程计漂移基线；PF（1000 粒子）复现 |
| HW05 | 机械臂运动学与动力学控制 | `arm_navigation_joint_control.py`、`arm_navigation_collision_avoidance.py` | 机械臂运动学（DH / Jacobian）、[[状态空间与LQR控制]] | 固定 2 连杆关节轨迹：跟踪误差 < 0.05 rad；计算力矩 + LQR 双实现对比基线 |
| HW06 | 完整自动驾驶 / 机械臂项目闭环 | 整合 Localization + Planning + Tracking + Control 模块 | 上述全部知识点 + [[卡尔曼滤波KalmanFilter]]、[[纯跟踪与Stanley控制器]] | 固定场景端到端：规划-跟踪闭环完成率 ≥ 95%；交付轨迹误差报告 + 参数敏感性分析（见下方验收方式） |

> 分层验收原则：HW01 是控制核心（LQR + MPC，优先完成）；HW02→HW03 是"规划 → 跟踪"横向链；HW04 是状态估计纵向链；HW05 是机械臂支线；HW06 是全链路 Capstone——默认自动驾驶栈（定位 → 规划 → 跟踪 → 控制），机械臂方向可选。

## ✅ 验收方式与评分

1. **官方 demo 复现**：每个 HW 先跑通 PythonRobotics 对应官方 demo（保持原始参数），输出截图与数据存档到 `03-Projects/`（参照 HW01 starter：`03-Projects/projects-robotics/`）。
2. **自写实现**：作业实现不得直接 import 官方函数；自写代码须在**同一随机种子、同一固定场景**下与官方输出对齐（轨迹、误差指标可比）。
3. **轨迹跟踪误差报告**：每个 HW 交付一份报告：固定场景描述（地图 / 路径 / 速度配置）+ 指标（横向误差 RMS 与 Max、纵向误差、到达时间、成功率）+ 与官方 demo / 基线的误差对比表。
4. **参数敏感性分析**：至少一个关键参数做网格扫描——HW01: Q/R 权重、MPC 预测时域；HW02: 栅格分辨率、采样数；HW03: 前视距离、Stanley 增益 $k$；HW04: 噪声协方差 Q/R——输出"参数 → 误差"曲线并给出结论。
5. **满分 Rubric**：官方复现通过（40 分）+ 自写实现对齐（30 分）+ 误差报告完整（20 分）+ 敏感性分析（10 分）。

## ⚖️ Honor Code

- PythonRobotics 的 demo 代码（MIT License）可阅读、可运行、可对照，但**作业实现必须自己写**；提交时注明"参考了哪些官方文件、改了什么、为什么改"。
- 官方仓库与教材中的公式、伪代码可以引用，但必须在报告中标注出处。
- 已有笔记（[[PID控制器与状态空间法]]、[[卡尔曼滤波KalmanFilter]]、各项目笔记）可双向引用，但不得复制其内容充当作业产出。
- 完成后再对照官方 solution 复盘；复盘结论写入对应知识点笔记的「12. 我的主动回忆区」。
