# 回归建模综合工作流

## 工作流不是模型菜单

一个合格回归案例必须先定义问题和评价协议，再允许模型接触数据。最终报告需要保留失败证据，而不是从多个切分和指标中挑一个最好结果。

## 七步闭环

1. **问题定义**：写清分析单位、目标变量、时间点、估计或预测目标、部署场景。
2. **数据审计**：检查缺失、重复、异常范围、时间顺序、目标泄漏和抽样偏差。
3. **冻结测试集**：测试集不参与预处理拟合、特征选择和模型选择。
4. **建立朴素基线**：连续响应至少比较均值基线和 OLS；分类响应至少比较常数概率和 Logistic。
5. **训练集内诊断与选择**：预处理和超参数选择进入 Pipeline/CV。
6. **最终评价**：方案冻结后只在测试集评价一次，并做误差分层和残差复检。
7. **解释与复现**：区分预测和因果措辞，记录版本、随机种子、命令、失败模型和限制。

## 正确的模型比较骨架

```python
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.model_selection import GridSearchCV
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

candidates = {
    'ols': Pipeline([
        ('scale', StandardScaler()),
        ('model', LinearRegression()),
    ]),
    'ridge': GridSearchCV(
        Pipeline([
            ('scale', StandardScaler()),
            ('model', Ridge()),
        ]),
        {'model__alpha': [0.01, 0.1, 1.0, 10.0, 100.0]},
        scoring='neg_root_mean_squared_error',
        cv=5,
    ),
}

# 只在 X_train, y_train 上拟合和比较。
# 选择规则冻结后，才对 X_test 调用一次 predict 或 score。
```

不能根据两个模型的测试 $R^2$ 选择最终模型；那会把测试集变成验证集。若需要无偏比较多个调参流程，使用嵌套 CV 或额外验证集。

## 推断与预测的双轨报告

- 推断轨：预先指定的模型、系数、置信区间、假设与稳健性分析。
- 预测轨：统一的样本外指标、校准、误差分层和基线比较。

两条轨道可以使用同一数据，但目标和评价证据不同。预测最优模型不自动提供最可信的科学解释。

## 常见错误

- 在全数据上标准化、插补或筛选特征后再 CV。
- 反复查看测试集并调整模型。
- 同时尝试大量指标，只报告最有利的一项。
- 根据 Ridge 略优于 OLS 就断言共线性严重。
- 把测试 $R^2$ 写成解释了总体因果变异。
