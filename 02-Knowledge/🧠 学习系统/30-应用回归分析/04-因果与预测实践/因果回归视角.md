# 因果回归视角

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：因果推断是统计学和机器学习的"圣杯"——几乎所有回归分析的实际应用最终都绕不开"我们得到的系数能解释为因果吗？"这个问题。理解回归的因果解释边界，能避免大量常见的统计误用，是数据分析师和研究人员必备的素养。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 你跑了一个回归，发现 $\hat{\beta} = 0.5$，$p < 0.001$。你很高兴地说："X 每增加 1 个单位，Y 平均增加 0.5 个单位。"但你的老板追问："这是因果效应吗？如果我们把 X 人为提高 1 个单位，Y 真的会增加 0.5 吗？"
>
> 你突然意识到：**回归系数 $\hat{\beta}$ 衡量的是"相关性"（correlation/association），而非"因果性"（causation）**。相关 ≠ 因果——这是统计学中最基本也最容易被忽视的警告。但另一方面，在精心设计的实验或合适的假设下，回归确实可以估计因果效应。
>
> **因果回归视角**要解决的核心问题是：**什么时候回归系数可以解释为因果效应？什么时候不能？如果不能，偏差来自哪里？**

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：这是回归分析从"描述性统计"走向"决策支持"的桥梁。在[[回归分析概述]]中我们学习了回归的技术操作，而这个视角告诉我们如何负责任地解读结果。
- **实际应用场景**：
  - 政策评估：新政策是否真的提高了就业率？
  - 医学研究：该药物是否真的改善了患者预后？
  - 经济学：教育年限是否真的提高了收入（还是能力等混杂因素造成的假象）？
  - A/B 测试分析：随机化实验中的回归调整
- **高频题型/任务**：因果图的 DAG 绘制、混杂变量的识别和调整、敏感性分析、因果效应的估计方法选择。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[回归分析概述]]**：理解回归的基本目标——用 $E(Y|X)$ 描述 Y 和 X 之间的关系。这是讨论"这个关系是否因果"的起点。
2. **[[回归方程的显著性检验]]**：理解 $p$ 值和显著性检验的含义——$p<0.05$ 只说明"数据与零假设不一致"，不代表因果关系成立。
3. **[[简单与多元线性回归]]**：理解"控制其他变量"的含义——多元回归中一个系数的解释是"在其他变量不变的情况下"，这已经很接近因果语言了，但需要附加条件。

---

## 4. 用直觉语言解释它

> «"回归就像一台关联测量仪，而不是因果探测器——它告诉你两个变量之间是否有统计关联，但不说一个是否导致另一个。"»

- **直觉类比/几何图像**：想象一个"冰激凌销量"和"溺水人数"的散点图。两者高度正相关，但显然吃冰激凌不会导致溺水。背后的混杂因素是"天气炎热"——夏天到了，大家既吃冰激凌又去游泳，两者同时增加。回归会给出一个显著的 $\beta$，但这是"伪相关"（spurious correlation）。**因果回归视角的任务就是：教你去问"除了 X 和 Y，还有什么变量同时在影响它们？"**
- **为什么很自然**：因果推断的本质是"反事实推理"——我们想知道如果 X 不同，Y 会怎样。但现实世界中，我们只能观察到"已发生的"而不能观察到"未发生的"。回归只是用"已发生的"数据计算条件期望，天然不等同于反事实。
- **一句话直觉本质**：回归系数是"相关"，要变成"因果"，需要额外的假设——通常是"无混杂"（所有共同原因都被控制了）。

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

**因果效应**（Causal Effect）是指在保持其他条件不变的情况下，改变 $X$ 一个单位对 $Y$ 产生的平均影响。在潜在结果（Potential Outcomes）框架中，处理变量 $X$ 对结果 $Y$ 的平均因果效应（ATE）定义为：

$$\text{ATE} = \mathbb{E}[Y(1) - Y(0)]$$

其中 $Y(1)$ 是处理组的潜在结果，$Y(0)$ 是对照组的潜在结果。对于连续 $X$，ATE 对应 $\frac{\partial \mathbb{E}[Y(x)]}{\partial x}$。

**回归系数 $\beta$ 等于因果效应的条件**（无混杂性，Unconfoundedness）：

$$Y(x) \perp\!\!\!\perp X \mid \mathbf{Z}$$

即：给定一组控制变量 $\mathbf{Z}$，潜在结果 $Y(x)$ 与处理变量 $X$ 独立。

### 2. 核心公式

当无混杂性成立时，回归系数 $\beta$ 等于因果效应：

$$\beta = \frac{\partial \mathbb{E}[Y \mid X, \mathbf{Z}]}{\partial X} = \text{因果效应}$$

当存在未观测混杂 $U$ 时，OLS 估计 $\hat{\beta}$ 的偏差为：

$$\text{Bias}(\hat{\beta}) = \text{Cov}(X, U \mid \mathbf{Z}) \cdot \frac{\text{Var}(U \mid \mathbf{Z})}{\text{Var}(X \mid \mathbf{Z})}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $Y(1), Y(0)$ | 潜在结果 | 与 Y 同量纲 | 只能观测到其中一个 |
| ATE | 平均因果效应 | 与 Y 同量纲 | Average Treatment Effect |
| $X$ | 处理/暴露变量 | 任意 | 因果变量 |
| $\mathbf{Z}$ | 控制变量集 | 向量 | 需要满足"后门准则" |
| $U$ | 未观测混杂 | 任意 | 导致偏差的源头 |
| $\perp\!\!\!\perp$ | 条件独立性 | 布尔值 | 统计独立符号 |

### 4. 常见变体与适用条件

- **适用条件**：
  - 随机实验（RCT）：$X$ 随机分配 → 自动满足无混杂性，回归系数 = 因果效应
  - 观察性研究：需满足无混杂性、正值性（positivity）、一致性（consistency）
- **限制条件**：
  - 存在未观测混杂时，OLS 估计有偏
  - 因果推断需要领域的因果知识（DAG），不能仅靠数据驱动
  - 反向因果（reverse causation）也会导致回归系数 ≠ 因果效应

## 6. 推导思路和思想来源

- **最初困难**：统计学传统上只研究"相关"，但政策制定、医学决策等需要"因果"。
- **直接方法局限**：在观察性数据中，处理组和对照组在协变量分布上通常不平衡，直接比较均值会混淆处理效应和协变量效应。
- **关键"转念"**：回归的"控制其他变量"本质上是"在给定协变量下比较"。如果所有共同原因（confounders）都被控制，那么回归系数就能解释为因果效应。这就是**后门准则**（Backdoor Criterion）的核心思想。
- **推导主线与动机**：
  1. 画出因果 DAG（有向无环图），标记所有变量之间的因果关系
  2. 识别"后门路径"——从 X 到 Y 的非因果路径（有箭头指向 X 的路径）
  3. 通过控制后门路径上的变量来阻断它们
  4. 证明：在 DAG 中，如果控制了所有后门路径上的变量，则 $X$ 和 $Y$ 之间的回归系数等于因果效应

> **重要声明**：上述 do-演算、后门准则、DAG 框架来自 Pearl (2009) *Causality*，属于因果推断的专门内容，**超出了 ISLR 和 Penn State STAT 462 的主线课程范围**。本笔记仅作概念层面的诚实引介，实操细节请参考[[待创建:因果推断入门]]。

- **为什么自然得到此结论**：实际上，多元回归的"在其他变量不变的情况下"已经隐含了条件比较的思想。因果推断只是把这个直觉用 DAG 和潜在结果框架严格化了。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：研究"教育年限 (X) 对收入 (Y)"的影响。假设真实模型为 $Y = 20000 + 3000X + 5000A + \varepsilon$，其中 $A$ 是"能力"（未观测）。如果 $A$ 与 $X$ 相关（$r_{XA} = 0.5$），且 $\text{Var}(X) = 4$，$\text{Var}(A) = 1$，$\text{Cov}(X, A) = 1$。用简单回归 $Y = \alpha + \beta X + \varepsilon$ 估计 $\beta$，偏差是多少？
- **解题思路与关键步骤**：
  1. 真实因果效应 = 3000
  2. 遗漏变量 $A$ 导致的偏差公式：$\text{Bias} = \gamma_A \cdot \delta_{X \sim A}$，其中 $\gamma_A$ 是 $A$ 对 $Y$ 的效应，$\delta_{X \sim A}$ 是 $A$ 对 $X$ 回归的系数
  3. $\gamma_A = 5000$，$\delta_{X \sim A} = \text{Cov}(X, A) / \text{Var}(A) = 1/1 = 1$
  4. $\text{Bias} = 5000 \times 1 = 5000$
  5. 因此 $\hat{\beta}$ 的期望值 = 3000 + 5000 = 8000（高估了教育效应）
- **最终答案**：偏差为 5000，回归高估了教育对收入的影响，因为能力同时影响教育和收入（混杂偏差）。
- **易错点**：混淆"控制变量"和"中介变量"——控制中介变量会阻断因果路径，导致低估因果效应，这是过度控制偏差（overcontrol bias）。
- **🤔 追问**：如果 $A$ 与 $X$ 负相关，偏差会怎样？——偏差方向会反转，可能低估甚至得到负的估计。

### 例子 2：中等例子（条件判断与多步推理）

- **题目与完整解答**：研究"广告投入 (X) 对销售额 (Y)"的影响。除了 X 和 Y，还有三个变量：市场潜力 (M)、竞品广告 (C)、品牌知名度 (B)。已知 M 影响 X 和 Y，C 影响 Y 且与 X 相关，B 受 X 影响且影响 Y。请问：
  (a) 画出 DAG。
  (b) 要估计 X 对 Y 的因果效应，应该控制哪些变量？
  (c) 哪些变量不应该控制？为什么？

  解答：
  (a) DAG: M → X, M → Y, C → Y, X → B → Y, 且 C 和 X 通过 M 相关（M 是共同原因）。
  (b) 后门路径：X ← M → Y（需要阻断），X ← M → C → Y（通过 M 被阻断或通过控制 C 阻断）。控制 M 即可阻断所有后门路径。也可以控制 M 和 C。
  (c) 不应该控制 B：B 是中介变量（X → B → Y），控制 B 会阻断 X 对 Y 的因果路径中的一部分，导致低估总效应。这是过度控制偏差。

### 例子 3：实际应用例子（真实场景/代码）

- **实际价值与转化**：在 A/B 测试中，虽然随机化保证了无混杂性，但回归调整可以提高估计精度（降低方差）。下面是一个模拟示例。

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

# 模拟 A/B 测试数据
np.random.seed(42)
n = 1000
# 处理变量：随机分配（保证无混杂）
treatment = np.random.binomial(1, 0.5, n)
# 协变量（可提高精度）
age = np.random.normal(40, 10, n)
baseline = np.random.normal(100, 15, n)
# 结果变量：真实处理效应 = 5
y = 50 + 5 * treatment + 0.3 * age + 0.5 * baseline + np.random.normal(0, 10, n)

# 方法1：简单比较（t 检验）
X1 = sm.add_constant(treatment)
model1 = sm.OLS(y, X1).fit()
print("--- 简单回归（无控制变量）---")
print(f"处理效应估计: {model1.params[1]:.3f}, SE: {model1.bse[1]:.3f}")
# 输出：处理效应估计 ≈ 5.0

# 方法2：回归调整（控制协变量）
X2 = sm.add_constant(np.column_stack([treatment, age, baseline]))
model2 = sm.OLS(y, X2).fit()
print("--- 回归调整 ---")
print(f"处理效应估计: {model2.params[1]:.3f}, SE: {model2.bse[1]:.3f}")
# 输出：处理效应估计 ≈ 5.0，SE 更小（精度更高）

# 注意：在随机化实验中，两种方法的估计量都是一致的
# 但回归调整通过减少残差方差来提高精度
# 在观察性研究中，如果未控制混杂变量，方法1会有偏
```

## 8. 常见误区和易混概念

### 误区 1：回归系数 = 因果效应

- **错误直觉**："我控制了 10 个变量，$\beta$ 显著，所以 X 导致了 Y。"
- **为什么错**：你永远无法保证控制了所有混杂变量。未观测的混杂（如本例中的"能力"）始终可能存在。显著性检验只检验关联，不检验因果。
- **正确理解**：回归系数是"给定控制变量下 X 和 Y 的条件关联"。要解释为因果，需要额外的因果假设。

### 误区 2：控制越多变量越好

- **错误直觉**："为了估计因果效应，我应该把所有能想到的变量都放进回归。"
- **为什么错**：控制中介变量（mediator）会导致过度控制偏差，控制对撞变量（collider）会导致选择偏差。不是所有变量都应该控制。
- **正确理解**：因果推断中的变量选择需要基于 DAG，而非"越多越好"。需要区分"混杂变量"（必须控制）、"中介变量"（不能控制）、"对撞变量"（不能控制）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 回归关联 | X 和 Y 是否相关 | 描述性，不要求因果假设 | 探索性分析、预测 |
| 因果效应 | X 变化是否导致 Y 变化 | 需要无混杂假设或随机化 | 政策评估、药物效果 |
| 预测 | 用 X 预测 Y 的值 | 关注预测精度，不关心因果 | 机器学习、推荐系统 |

### 题目与解析

#### 1. 以下哪项是"相关 ≠ 因果"的经典例子？
> [!question]- 答案解析
> - **答案**：D. 冰激凌销量与溺水人数正相关
> - **解析**：两者都受"天气炎热"这个混杂变量驱动，不存在直接的因果关系。
> - **易错原因**：大数字的相关性容易让人产生"看起来确实有因果"的错觉。
> - **对应误区**：误区 1

#### 2. 已知真实因果效应为 2，遗漏变量 $U$ 对 $Y$ 的效应为 4，$U$ 与 $X$ 的协方差为 1.5，$\text{Var}(X) = 3$，求 OLS 估计的偏差和期望值。
> [!question]- 答案解析
> - **答案**：偏差 = $4 \times (1.5/3) = 4 \times 0.5 = 2$，期望值 = $2 + 2 = 4$
> - **解析**：代入遗漏变量偏差公式：$\text{Bias} = \gamma_U \cdot \delta_{X\sim U} = \gamma_U \cdot \frac{\text{Cov}(X,U)}{\text{Var}(X)}$
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 在 DAG 中，以下哪种变量应该被控制？
> [!question]- 答案解析
> - **答案**：C. 混杂变量（confounder）：同时影响 X 和 Y 的变量
> - **解析**：A（中介变量）控制后会产生过度控制偏差，B（对撞变量）控制后会产生选择偏差，D（结果变量）是 Y 本身，不能控制。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 随机化实验为什么可以省略因果推断的复杂假设？
> [!question]- 答案解析
> - **答案**：因为随机化保证了处理变量 $X$ 与所有潜在结果 $Y(x)$ 独立，即 $Y(x) \perp\!\!\!\perp X$，自动满足无混杂性。因此简单比较均值就能得到因果效应的一致估计。
> - **解析**：随机化打破了混杂变量对 $X$ 的影响，使得处理组和对照组在协变量分布上（期望意义上）平衡。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 多元回归中的"控制其他变量"在什么条件下可以解释为因果效应？请给出至少两个条件并说明。
> [!question]- 答案解析
> - **答案**：(1) **无混杂性**：控制变量集 Z 包含了所有同时影响 X 和 Y 的变量（后门准则）；(2) **正确设定**：回归函数形式正确（如非线性关系时需包含交互项或多项式）；(3) **无测量误差**：变量测量准确；(4) **无反向因果**：Y 不会反过来影响 X。
> - **解析**：回归系数 ≠ 因果效应是常态，需要额外假设来"升级"。实际应用中，建议做敏感性分析来评估潜在未观测混杂的影响强度。
> - **Obsidian 标签建议**：`#自测题/较难`
