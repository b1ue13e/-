# 🧭 开源作业体系-应用回归分析

> 本页是「应用回归分析」开源名校课程与作业的**唯一挂载点**：教材主线、作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**[An Introduction to Statistical Learning (ISLR)](https://www.statlearning.com/)（官方免费 PDF）** + **[Penn State STAT 462 Applied Regression Analysis](https://online.stat.psu.edu/stat462/)（验收口径）**。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷推导（如正规方程、IRLS 更新式）；② Python 实现（手撕核心 + 与 statsmodels/sklearn 对照）；③ 1 页报告（诊断结论 + 失败案例）。
2. **手撕要求**：HW01 的坐标下降与 IRLS 必须自写迭代，禁止直接调用现成求解器作为主提交。
3. **数据来源**：ISLR 官方数据集（statlearning.com 提供）+ 内置模拟数据；禁止使用无法溯源的数据。
4. **满分 Rubric**：HW01-05 各 20 分，共 100 分（推导 30 + 实现 40 + 报告 30）。
