## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：所有子集回归（best subset selection）是变量选择问题的**理论黄金标准**——它穷举所有可能的变量组合，在保证全局最优的意义上无可替代。虽然 $p$ 大时不可行，但理解它是理解所有其他变量选择方法（逐步回归、Lasso）的参照系。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> [[自变量选择]] 给出了 Cp/AIC/BIC 等准则来**评价**一个模型的好坏，而 [[逐步回归]] 给出了一种**近似搜索**策略。但逐步法是贪心的——它在每一步只做局部最优决策，可能**错过全局最优**。
>
> 所有子集回归（best subset selection / all subsets regression）解决了这个痛点：**枚举所有 $2^p$ 个可能的变量子集，逐一用 Cp/AIC/BIC/调整 $R^2$ 评价，选出全局最优的模型**。代价是：计算量随 $p$ 指数增长。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：所有子集回归是变量选择方法的"理论基准"。后续的逐步回归、Lasso、Ridge 等方法的预测效果和变量选择正确性，本质上都是**对这个"黄金标准"的近似**。在 ISLR Ch.6 中，它被放在"Best Subset Selection"节中作为第一个介绍的方法。
- **实际应用场景**：当候选变量较少（$p \leq 15$）且计算资源充足时，所有子集回归是首选。在生物统计学的小规模变量筛选（如 10 个候选基因的交互效应探索）中有应用。
- **高频题型/任务**：理解 $2^p$ 的计算量含义、对比全子集与逐步法的优劣、用"Cp vs 子集大小"的泡泡图选择模型。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[自变量选择]]**：理解调整 $R^2$、Cp、AIC、BIC 四大准则。所有子集回归的输出就是这些准则在不同子集上的值，你需要根据这些值做决策。
2. **[[多元线性回归模型]]**：理解 $y = X\beta + \varepsilon$，$RSS = (y - X\hat{\beta})'(y - X\hat{\beta})$。每个子集都对应一个 $X$ 矩阵的子列，需要拟合对应的 OLS 模型。
3. **[[最小二乘估计]]**：$\hat{\beta} = (X'X)^{-1}X'y$，每个子集都要重新计算这个估计（虽然可以通过递推算法加速，但概念上仍是 $2^p$ 次 OLS）。

---

## 4. 用直觉语言解释它

> «所有子集回归就像"选最合适的衣服"—— 你把衣柜里所有衣服组合都试一遍，然后选最合身的那一套，而不是"先选裤子再选上衣"地逐步试。»

- **直觉类比**：你要从 10 件衣服中选出出门穿的一套。逐步法：先选裤子（最满意的），再配上衣（在已经选好裤子的基础上配），可能错过"裤子上衣都不突出但搭在一起很棒"的组合。全子集法：把所有可能的搭配都试穿一遍，保证找到全局最优。
- **为什么很自然**：如果你有足够的时间和精力，当然"全都试一遍"是最保险的。全子集回归就是"全都试一遍"的统计版本。
- **一句话直觉本质**：**穷举所有可能的变量组合，用统一准则评分，选出全局最优模型。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

设有 $p$ 个候选自变量（含截距则总参数数为 $p+1$），所有子集回归枚举所有 $2^p$ 个非空子集（通常也包含空模型），对每个子集拟合 OLS 回归，并用预设准则（调整 $R^2$、Cp、AIC、BIC）评分，最终选出在各准则下表现最好的一个或几个模型。

### 2. 核心公式

**子集总数**：
$$
\sum_{k=0}^{p} \binom{p}{k} = 2^p
$$

**各准则**（与 [[自变量选择]] 一致）：

$$
\begin{aligned}
R^2_{adj}(k) &= 1 - \frac{n-1}{n-k-1}(1-R^2_k) \\
C_p(k) &= \frac{RSS_k}{\hat{\sigma}^2} - n + 2(k+1) \\
\text{AIC}(k) &= n\ln\left(\frac{RSS_k}{n}\right) + 2(k+1) \\
\text{BIC}(k) &= n\ln\left(\frac{RSS_k}{n}\right) + (k+1)\ln n
\end{aligned}
$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $p$ | 候选自变量总数 | $\mathbb{N}^+$ | 通常 $p \leq 15$ 才可用全子集 |
| $\binom{p}{k}$ | 从 $p$ 个中选 $k$ 个的组合数 | $\mathbb{N}^+$ | 所有子集数的加和为 $2^p$ |
| $RSS_k$ | 含 $k$ 个变量的残差平方和 | $\mathbb{R}^+$ | 每个子集独立计算 |
| $\hat{\sigma}^2$ | 全模型均方误差 | $\mathbb{R}^+$ | $RSS_p / (n-p-1)$ |

### 4. 常见变体与适用条件

- **适用条件**：$p \leq 15$（$2^{15} = 32768$，现代计算机几分钟可完成）；$p \leq 10$ 时非常推荐。
- **限制条件**：
  - $p > 15$ 时 $2^p$ 过大，即使使用 BFS（分支定界）等加速算法也难在合理时间内完成
  - 当 $p > n$ 时，全模型无法拟合，$\hat{\sigma}^2$ 无法估计，Cp 失效
  - 全子集枚举本身不提供"自动选择"—— 你需要根据准则值和领域知识手动决策

---

## 6. 推导思路和思想来源

- **最初困难**：逐步回归只能找到局部最优，但无法保证选出的模型是全局最优的。
- **直接方法局限**：理论上不存在不枚举所有子集就能保证全局最优的算法（这是 NP-hard 问题，除了 $p$ 很小或使用分支定界）。
- **关键"转念"**：既然 $p$ 不大时枚举是可行的，那就不必"聪明"地搜索，直接"暴力"穷举。配上 Cp/AIC/BIC 这些评分准则，简洁直观。
- **推导主线与动机**：
  1. 生成所有 $2^p$ 个子集（二进制编码：每个变量 0/1 表示是否入选）
  2. 对每个子集拟合 OLS，计算 $RSS_k$
  3. 代入各准则公式
  4. 对每个 $k$ 选出该大小下的最优模型，或直接比较所有模型
  5. 用"泡泡图"（Cp vs 子集大小）或表格展示结果
- **为什么自然得到此结论**：暴力枚举 + 评分准则 = 最直接、最可靠的变量选择方法，适用于 $p$ 较小的场景。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

**题目**：$p=3$ 个候选变量 $x_1, x_2, x_3$，$n=10$。TSS=200，全模型 $RSS = 48$，$\hat{\sigma}^2 = 48/(10-3-1) = 8$。各子集的 $RSS$ 如下：

| 子集 | $k$ | $RSS$ |
|:---|:---:|:---:|
| $\emptyset$（空模型） | 0 | 200 |
| $\{x_1\}$ | 1 | 80 |
| $\{x_2\}$ | 1 | 90 |
| $\{x_3\}$ | 1 | 120 |
| $\{x_1, x_2\}$ | 2 | 55 |
| $\{x_1, x_3\}$ | 2 | 60 |
| $\{x_2, x_3\}$ | 2 | 70 |
| $\{x_1, x_2, x_3\}$ | 3 | 48 |

**解题思路与关键步骤**：

1. 计算每个子集的调整 $R^2$：
   - $\{x_1\}$: $R^2 = 1 - 80/200 = 0.60$，$R^2_{adj} = 1 - \frac{9}{8}(0.40) = 0.55$
   - $\{x_1, x_2\}$: $R^2 = 1 - 55/200 = 0.725$，$R^2_{adj} = 1 - \frac{9}{7}(0.275) = 0.646$
   - $\{x_1, x_2, x_3\}$: $R^2 = 1 - 48/200 = 0.76$，$R^2_{adj} = 1 - \frac{9}{6}(0.24) = 0.64$

2. 计算 Cp：
   - $\{x_1\}$: $C_p = 80/8 - 10 + 2(2) = 10 - 10 + 4 = 4$（$k+1=2$，$C_p=4 > 2$，偏误明显）
   - $\{x_1, x_2\}$: $C_p = 55/8 - 10 + 2(3) = 6.875 - 10 + 6 = 2.875$（$k+1=3$，$C_p=2.875 \approx 3$，好）
   - $\{x_1, x_2, x_3\}$: $C_p = 48/8 - 10 + 2(4) = 6 - 10 + 8 = 4$（$k+1=4$，$C_p=4 = k+1$，但更复杂）

**最终答案**：调整 $R^2$ 最大是 $\{x_1, x_2\}$（0.646），Cp 最小也是 $\{x_1, x_2\}$（2.875），且 $C_p \approx k+1$，说明模型偏误很小。最优模型是 $\{x_1, x_2\}$。

**易错点**：计算 $R^2_{adj}$ 时注意分母是 $n-k-1$（含截距），不是 $n-k$。

**🤔 追问**：如果 $\{x_1, x_3\}$ 的 Cp 也是 2.9，但 $x_2$ 和 $x_3$ 高度相关（$r=0.9$），你会怎么选？答案：优先选 $\{x_1, x_2\}$ 或 $\{x_1, x_3\}$ 中更易解释的，或结合领域知识。Cp 一样时，解释性优先。

### 例子 2：中等例子（条件判断与多步推理）

**题目**：$p=10$，$n=100$，全子集回归得到以下结果。对于 $k=1$ 到 $k=5$，每个大小下的最优模型 Cp 分别为：$k=1: 25.3$，$k=2: 12.1$，$k=3: 4.2$，$k=4: 4.0$，$k=5: 5.8$。如何选择？

**解答**：Cp 在 $k=3$ 时接近 $k+1=4$（$C_p=4.2$），$k=4$ 时也很接近（$C_p=4.0$），但 $k=5$ 时 Cp 反而上升（$C_p=5.8$）。根据"Cp 最小 + 接近 $k+1$"原则，选 $k=3$ 或 $k=4$ 的模型。结合简约性，$k=3$ 更优。

### 例子 3：实际应用例子（Python 代码）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from itertools import combinations

# 模拟数据
np.random.seed(42)
n, p = 50, 10
X = np.random.randn(n, p)
true_beta = np.array([3, -2, 1, 0, 0, 0, 0, 0, 0, 0])
y = X @ true_beta + np.random.normal(0, 1.5, n)

X_full = sm.add_constant(X)

# 全模型用于估计 sigma2
full_model = sm.OLS(y, X_full).fit()
sigma2_hat = full_model.ssr / full_model.df_resid

# 枚举所有子集（p=10 -> 2^10=1024 个，可接受）
results = []
for k in range(0, p + 1):  # 每个子集大小
    for combo in combinations(range(p), k):
        cols = [0] + [c + 1 for c in combo]  # const 在第 0 列
        X_sub = X_full[:, cols]
        model = sm.OLS(y, X_sub).fit()
        k_actual = len(combo)
        rss = model.ssr
        
        # 计算各准则
        adj_r2 = 1 - (rss / (n - k_actual - 1)) / (np.var(y, ddof=1))
        cp = rss / sigma2_hat - n + 2 * (k_actual + 1)
        aic = n * np.log(rss / n) + 2 * (k_actual + 1)
        bic = n * np.log(rss / n) + (k_actual + 1) * np.log(n)
        
        results.append({
            'k': k_actual, 'vars': combo,
            'adj_r2': adj_r2, 'cp': cp, 'aic': aic, 'bic': bic
        })

df = pd.DataFrame(results)

# 对每个 k 选出最优模型
best_per_k = df.loc[df.groupby('k')['cp'].idxmin()]
print("各子集大小下的最优模型（Cp 最小）：")
print(best_per_k[['k', 'vars', 'cp', 'adj_r2', 'aic', 'bic']])

# 全局最优
print(f"\n全局最优 Cp: {df.loc[df['cp'].idxmin(), 'vars']}")
print(f"全局最优 BIC: {df.loc[df['bic'].idxmin(), 'vars']}")
# 预期：真变量 {0, 1, 2} 被一致选出（或接近）

# 可选：使用 Python 的 leaps 类似功能
# 注意：statsmodels 暂无直接的全子集函数，推荐使用 mlxtend 的 ExhaustiveFeatureSelector
# from mlxtend.feature_selection import ExhaustiveFeatureSelector
# efs = ExhaustiveFeatureSelector(LinearRegression(), min_features=1, max_features=5, 
#                                  scoring='r2', cv=5)
```

## 8. 常见误区和易混概念

### 误区 1：全子集回归一定比逐步回归好

- **错误直觉**：穷举必定优于贪心，所以全子集回归永远更好。
- **为什么错**：全子集回归确实保证全局最优，但代价是：① $p$ 大时不可行；② 它仍然只考虑了**线性模型**中的全局最优，若真实关系是非线性的，全子集也不能保证找到真模型；③ 全子集枚举了 $2^p$ 个模型，也面临多重检验风险。
- **正确理解**：当 $p$ 较小（$\leq 15$）且线性假设合理时，全子集回归是最可靠的方法。否则，逐步回归或 Lasso 是更实用的选择。

### 误区 2：全子集回归选出的模型就是"真实模型"

- **错误直觉**：全子集枚举了所有组合，选出的模型一定是产生数据的真实过程。
- **为什么错**：① 变量选择准则（Cp/AIC/BIC）不是"因果发现"工具，它们只是拟合优度与复杂度的权衡；② 真实模型可能不包含在候选变量集合中；③ 多重共线性下，多个模型可能有几乎相同的评分。
- **正确理解**：全子集回归选出的是"在当前候选变量中、在给定准则下最优的预测模型"，不等于因果模型。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **所有子集回归** | 枚举所有变量组合 | 全局最优，但计算量大 | $p \leq 15$ |
| **逐步回归** | 贪心搜索 | 计算效率高，但可能局部最优 | $15 < p \leq 50$ |
| **Lasso 回归** | $L_1$ 正则化 | 连续收缩，可同时选变量和估计系数 | $p$ 很大甚至 $p > n$ |

## 9. 相关知识点与 Obsidian 双链建议

### 上游依赖
- [[自变量选择]]：提供了 Cp/AIC/BIC/调整 $R^2$ 等评分准则，全子集回归需要这些准则来做决策。
- [[多元线性回归模型]]：每个子集都是一个 OLS 回归模型，理解矩阵形式才能理解计算过程。

### 下游延伸
- [[应用回归分析-Lasso回归与坐标下降]]：当 $p$ 很大时，Lasso 通过 $L_1$ 正则化实现"连续的全子集选择"，是高维场景下的替代方案。
- [[逐步回归]]：全子集回归的贪心近似，适用于 $p$ 中等的情况。

### 横向关联
- [[多重共线性]] ↔ [[所有子集回归]]：多重共线性下，多个不同子集可能有非常接近的 Cp/AIC/BIC 值，需谨慎选择。

### 应用场景
- 生物信息学基因筛选：当候选基因数量在 10-15 个时，全子集回归可用于探索最优的基因组合。

### 题目与解析

#### 1. 所有子集回归的核心思想是什么？
> [!question]- 答案解析
> - **答案**：枚举所有可能的变量组合子集，对每个子集拟合 OLS 模型，用 Cp/AIC/BIC 等准则评分，选出全局最优模型。
> - **解析**：核心是"穷举 + 评分"，保证全局最优，但计算量随 $p$ 指数增长。
> - **对应误区**：误区 1。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. $p=5$ 时，所有子集回归需要拟合多少个模型？
> [!question]- 答案解析
> - **答案**：$2^5 = 32$ 个（含空模型）。
> - **解析**：每个变量有"入选/不入选"两种状态，共 $2^p$ 种组合。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 什么情况下所有子集回归不可行？
> [!question]- 答案解析
> - **答案**：$p > 15$ 时，$2^p$ 过大（$2^{20} \approx 10^6$，$2^{30} \approx 10^9$），计算量失控。
> - **解析**：现代计算机 $p=20$ 时勉强可行（约 100 万个子集），$p=30$ 时完全不可行。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 全子集回归相比逐步回归的最大优势和最大劣势是什么？
> [!question]- 答案解析
> - **答案**：优势是保证全局最优；劣势是计算量指数增长，$p$ 大时不可行。
> - **解析**：逐步回归是贪心算法，计算量 $O(p^2)$，但只能找到局部最优。两者是"效率 vs 最优性"的权衡。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 为什么全子集回归选出的模型不一定是"产生数据的真实模型"？
> [!question]- 答案解析
> - **解析**：① 候选变量可能不包含真实变量；② 真实关系可能是非线性的，全子集只考虑线性组合；③ 多重共线性下多个模型评分接近；④ Cp/AIC/BIC 只是统计准则，不是因果标准。具体例子：真实模型是 $y = x_1 + x_2 + \varepsilon$，但若 $x_3$ 与 $x_1$ 高度相关（$r=0.99$），全子集可能选出 $\{x_3, x_2\}$ 且评分几乎一样好。
> - **Obsidian 标签建议**：`#自测题/较难`
