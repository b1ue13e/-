## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：自相关是时间序列数据（如 GDP、股价、气象数据）做回归时最常见的模型违背之一。不理解它，时间序列回归的系数估计和显著性检验全都不可靠。它在计量经济学、金融工程、环境科学中高频出现。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 普通线性回归假设误差项 $\varepsilon_i$ 相互独立。但当你用时间序列数据（如逐月销量、逐年 GDP）做回归时，残差往往表现出"相邻观测值互相依赖"—— 今天卖得好，明天也容易卖得好；去年经济好，今年也容易跟着好。这种"相邻误差彼此相关"的现象就叫**自相关（autocorrelation / serial correlation）**。
>
> 如果无视自相关而直接用 OLS：
> - 系数估计仍然是**无偏的**，但**不再是有效的**（方差被低估）
> - $t$ 检验和 $F$ 检验的显著性被夸大（容易犯第一类错误）
> - $R^2$ 虚高，模型看起来比实际好得多
>
> 所以我们需要：**检测自相关是否存在**，若是，**用恰当的方法修正估计**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：自相关是回归诊断"四大违背"之一（异方差、自相关、多重共线性、异常值）。不学它，后续的时间序列分析、面板数据回归、因果推断都站不稳。
- **实际应用场景**：宏观经济学（GDP 增长建模）、金融学（股票收益率建模）、环境科学（气温序列建模）、工业过程监控。
- **高频题型/任务**：DW 统计量的计算与判断、Cochrane-Orcutt 迭代流程、残差自相关图（ACF 图）的解读。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[最小二乘估计]]**：OLS 的 BLUE 性质（Gauss-Markov 定理）要求误差独立同分布，自相关直接破坏"独立"这条。理解 OLS 的方差公式 $\text{Var}(\hat{\beta}) = \sigma^2 (X'X)^{-1}$ 才能明白为什么自相关会导致方差估计偏小。
2. **[[残差分析]]**：残差 $e_i = y_i - \hat{y}_i$ 是诊断自相关的第一手材料。残差对时间或滞后残差的散点图是直观的自相关检测工具。
3. **[[多元线性回归模型]]**：理解回归模型 $y = X\beta + \varepsilon$ 的矩阵形式，以及 OLS 估计 $\hat{\beta} = (X'X)^{-1}X'y$ 的推导逻辑。

---

## 4. 用直觉语言解释它

> «自相关就像"醉汉走路"—— 他这一步往哪歪，下一步很可能也往同方向歪；误差之间不是独立随机的，而是"拖泥带水"的。」

- **直觉类比**：你每天记录你的体重。如果今天吃多了，明天的体重大概率也偏高，后天可能还偏高 —— 误差（实际体重 vs 你的减肥模型预测值）不是独立震荡的，而是"粘在一起"的。
- **为什么很自然**：时间序列数据天然具有惯性 —— 经济扩张期往往持续多个季度，高温天气往往持续数天。这种"记忆效应"反映在误差项上就是自相关。
- **一句话直觉本质**：**误差项中存在"今天和明天"的相关性**，使得 OLS 的标准误被低估、显著性被高估。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

线性回归模型 $y_t = x_t'\beta + \varepsilon_t$ 中，若误差项满足 $\text{Cov}(\varepsilon_t, \varepsilon_s) \neq 0$ 对某些 $t \neq s$，则称存在**自相关（autocorrelation）**。最常用的是**一阶自回归形式 AR(1)**：

$$
\varepsilon_t = \rho \varepsilon_{t-1} + u_t, \quad u_t \sim \text{i.i.d. } N(0, \sigma_u^2), \quad |\rho| < 1
$$

其中 $\rho$ 是自相关系数，$u_t$ 是白噪声。

### 2. 核心公式：Durbin-Watson 统计量

DW 统计量是最经典的自相关检验：

$$
d = \frac{\sum_{t=2}^{n} (e_t - e_{t-1})^2}{\sum_{t=1}^{n} e_t^2}
$$

其中 $e_t$ 是 OLS 残差。可以证明：

$$
d \approx 2(1 - \hat{\rho}), \quad \hat{\rho} = \frac{\sum_{t=2}^{n} e_t e_{t-1}}{\sum_{t=1}^{n} e_{t-1}^2}
$$

- $d \approx 2$：无自相关（$\hat{\rho} \approx 0$）
- $d < 2$：正自相关（$\hat{\rho} > 0$，更常见）
- $d > 2$：负自相关（$\hat{\rho} < 0$，较少见）

DW 检验的临界值 $d_L$ 和 $d_U$ 查表得到：若 $d < d_L$ 拒绝 $H_0$（无自相关）；若 $d > d_U$ 不拒绝；若 $d_L \leq d \leq d_U$ 则无法判定（灰色区域）。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $y_t$ | 第 $t$ 期因变量 | $\mathbb{R}$ | 时间序列下标 |
| $x_t$ | 第 $t$ 期自变量向量 | $\mathbb{R}^p$ | 可含滞后项 |
| $\varepsilon_t$ | 第 $t$ 期误差项 | $\mathbb{R}$ | 满足 AR(1) 结构 |
| $\rho$ | 一阶自相关系数 | $[-1, 1]$ | $|\rho| < 1$ 保证平稳 |
| $u_t$ | 白噪声误差 | $\mathbb{R}$ | 独立同分布，均值为 0 |
| $e_t$ | OLS 残差 | $\mathbb{R}$ | $\varepsilon_t$ 的估计值 |
| $d$ | DW 统计量 | $[0, 4]$ | $d \approx 2(1-\hat{\rho})$ |

### 4. 常见变体与适用条件

- **适用条件**：时间序列或面板数据回归；误差项怀疑有记忆效应。
- **限制条件**：
  - DW 检验只检测**一阶自相关**，对高阶自相关（如 AR(2)）不敏感
  - DW 检验不能用于含滞后因变量 $y_{t-1}$ 作为自变量的模型（此时 DW 偏向 2，需用 Durbin $h$ 检验）
  - 存在无法判定的灰色区域

## 6. 推导思路和思想来源

- **最初困难**：OLS 下若误差独立，$\text{Var}(\hat{\beta}) = \sigma^2 (X'X)^{-1}$ 是简洁的。但若 $\varepsilon_t$ 之间相关，方差公式变为 $\text{Var}(\hat{\beta}) = \sigma^2 (X'X)^{-1} X' \Omega X (X'X)^{-1}$，其中 $\Omega$ 是误差协方差矩阵，非对角元不为零。
- **直接方法局限**：用 OLS 的方差公式硬算会低估真实方差，导致置信区间过窄、$p$ 值过小。
- **关键"转念"**：既然误差有 AR(1) 结构，那不如先估计 $\rho$，然后用 $\rho$ 对数据做"准差分变换"（quasi-differencing），使得变换后的误差近似独立。
- **推导主线与动机**：
  1. 用 OLS 得到残差 $e_t$
  2. 用残差估计 $\hat{\rho} = \frac{\sum e_t e_{t-1}}{\sum e_{t-1}^2}$
  3. 对变量做变换：$y_t^* = y_t - \hat{\rho} y_{t-1}$，$x_t^* = x_t - \hat{\rho} x_{t-1}$
  4. 对变换后的数据做 OLS —— 这就是 **Cochrane-Orcutt 迭代法**的核心思想
- **为什么自然得到此结论**：如果 $\varepsilon_t = \rho \varepsilon_{t-1} + u_t$，那么 $y_t - \rho y_{t-1} = (x_t - \rho x_{t-1})'\beta + u_t$，$u_t$ 已经是白噪声，OLS 回归恢复 BLUE 性质。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

**题目**：某回归模型有 5 期残差：$e = [2, 3, 5, 4, 6]$，计算 DW 统计量并判断是否可能存在正自相关（$n=5, k=2$ 时 $d_L = 0.61, d_U = 1.40$，$\alpha=0.05$）。

**解题思路与关键步骤**：

1. 计算分子 $\sum_{t=2}^{n} (e_t - e_{t-1})^2$：
   - $(3-2)^2 = 1$，$(5-3)^2 = 4$，$(4-5)^2 = 1$，$(6-4)^2 = 4$
   - 分子和 $= 1 + 4 + 1 + 4 = 10$

2. 计算分母 $\sum_{t=1}^{n} e_t^2$：
   - $2^2 + 3^2 + 5^2 + 4^2 + 6^2 = 4 + 9 + 25 + 16 + 36 = 90$

3. $d = 10 / 90 = 0.111$

**最终答案**：$d = 0.111$，远小于 $d_L = 0.61$，拒绝 $H_0$，存在显著正自相关。

**易错点**：分子求和从 $t=2$ 开始，不要漏掉第一项；分母是全部残差平方和，包括 $t=1$。

**🤔 追问**：如果把残差顺序打乱成 $[2, 6, 3, 5, 4]$，DW 会变大还是变小？答案：变大，因为相邻残差差异更大，分子增大。

### 例子 2：中等例子（条件判断与多步推理）

**题目**：某模型 $n=30, k=3$，DW 统计量 $d = 1.15$，查表得 $d_L = 1.21, d_U = 1.65$（$\alpha=0.05$）。如何判断？

**解答**：$d = 1.15 < d_L = 1.21$，拒绝 $H_0$，存在正自相关。需要采用 Cochrane-Orcutt 或 Prais-Winsten 方法修正。

### 例子 3：实际应用例子（Python 代码）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from scipy import stats

# 模拟带自相关的数据
np.random.seed(42)
n = 100
rho = 0.7
u = np.random.normal(0, 1, n)
eps = np.zeros(n)
eps[0] = u[0]
for t in range(1, n):
    eps[t] = rho * eps[t-1] + u[t]  # AR(1) 误差

x = np.linspace(0, 10, n)
y = 2 + 0.5 * x + eps

# OLS 回归
X = sm.add_constant(x)
model = sm.OLS(y, X).fit()
residuals = model.resid
print(f"OLS 系数: {model.params}")
print(f"OLS 标准误: {model.bse}")

# 手算 DW 统计量
def dw_stat(e):
    n = len(e)
    numerator = np.sum((e[1:] - e[:-1])**2)
    denominator = np.sum(e**2)
    return numerator / denominator

d = dw_stat(residuals)
print(f"DW 统计量: {d:.4f}")
# 输出: DW 统计量 ≈ 0.56 (因随机种子而异，但远小于 2)

# 使用 statsmodels 的 DW 检验
from statsmodels.stats.stattools import durbin_watson
print(f"statsmodels DW: {durbin_watson(residuals):.4f}")

# Cochrane-Orcutt 迭代修正
def cochrane_orcutt(y, X, max_iter=10, tol=1e-6):
    """
    Cochrane-Orcutt 迭代法估计
    """
    n = len(y)
    rho_old = 0
    for iteration in range(max_iter):
        # 1. 当前回归
        beta = np.linalg.lstsq(X, y, rcond=None)[0]
        e = y - X @ beta
        
        # 2. 估计 rho
        rho_new = np.sum(e[1:] * e[:-1]) / np.sum(e[:-1]**2)
        
        # 3. 准差分变换
        y_star = y[1:] - rho_new * y[:-1]
        X_star = X[1:] - rho_new * X[:-1]
        
        # 4. 重新回归
        beta_new = np.linalg.lstsq(X_star, y_star, rcond=None)[0]
        
        if abs(rho_new - rho_old) < tol:
            break
        rho_old = rho_new
    
    return beta_new, rho_new

beta_corrected, rho_est = cochrane_orcutt(y, X)
print(f"Cochrane-Orcutt rho: {rho_est:.4f}")
print(f"Cochrane-Orcutt 系数: {beta_corrected}")
# 预期: rho_est ≈ 0.7, 系数接近 [2, 0.5]
```

## 8. 常见误区和易混概念

### 误区 1：DW 统计量越接近 0 越好

- **错误直觉**：DW 越小说明回归效果越好。
- **为什么错**：DW 检验的是**误差自相关**，不是拟合优度。DW 接近 2 才是理想（无自相关），接近 0 说明正自相关严重。
- **正确理解**：DW $\in [0, 4]$，理想值是 2，不是 0 或 4。

### 误区 2：自相关只影响系数估计

- **错误直觉**：自相关只是让标准误变大，系数估计反正无偏，无所谓。
- **为什么错**：自相关下 OLS 系数虽仍无偏，但**方差被低估**（通常，正自相关导致方差被低估），导致 $t$ 统计量虚高、$p$ 值虚低、置信区间过窄。
- **正确理解**：自相关破坏的是**有效性**和**推断的可靠性**，而非无偏性。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **自相关** | 误差项跨期相关 | 不同时间点的误差依赖 | 时间序列回归 |
| **异方差** | 误差项方差不等 | 不同观测的误差方差不同 | 截面数据回归 |
| **多重共线性** | 自变量间高度相关 | 自变量之间的问题，非误差 | 任何含多个相关预测变量的回归 |

### 题目与解析

#### 1. DW 统计量的取值范围是？
> [!question]- 答案解析
> - **答案**：$[0, 4]$，理想值是 2。
> - **解析**：分子 $\sum (e_t - e_{t-1})^2$ 最小为 0（所有残差相等），最大为 $4\sum e_t^2$（相邻残差反向且幅度相同），故 $d \in [0, 4]$。
> - **易错原因**：误以为 DW 和 $R^2$ 一样越接近 1 越好。
> - **对应误区**：误区 1。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 残差序列 $e = [1, -1, 2, -2, 1]$，计算 DW。
> [!question]- 答案解析
> - **答案**：$d = 38/11 \approx 3.45$，提示负自相关。
> - **解析**：分子 $= (-1-1)^2 + (2+1)^2 + (-2-2)^2 + (1+2)^2 = 4 + 9 + 16 + 9 = 38$，分母 $= 1+1+4+4+1 = 11$，$d = 38/11 \approx 3.45$。$d > 2$ 且接近 4，提示可能存在负自相关。

#### 3. $n=25, k=2, d=1.30, d_L=1.29, d_U=1.45$，结论是？
> [!question]- 答案解析
> - **答案**：落入灰色区域，无法判定是否存在自相关。
> - **解析**：$d=1.30$，$d_L=1.29$，$d_U=1.45$。因为 $d_L=1.29 < d=1.30 < d_U=1.45$，落入"无法判定"的灰色区域。此时应增加样本量或使用其他检验方法（如 Breusch-Godfrey 检验）。

#### 4. Cochrane-Orcutt 迭代的正确步骤顺序是？
> [!question]- 答案解析
> - **答案**：① OLS 回归得到残差 → ② 用残差估计 $\hat{\rho}$ → ③ 准差分变换 → ④ 对变换后数据做 OLS → ⑤ 若 $\hat{\rho}$ 收敛则停止，否则回到 ②。
> - **解析**：这是一个迭代过程，每一步都用新的残差更新 $\hat{\rho}$ 的估计。
> - **对应误区**：认为 Cochrane-Orcutt 只需要一次变换。

#### 5. 证明 $d \approx 2(1 - \hat{\rho})$。
> [!question]- 答案解析
> - **解析**：展开分子 $\sum_{t=2}^n (e_t - e_{t-1})^2 = \sum e_t^2 + \sum e_{t-1}^2 - 2\sum e_t e_{t-1}$。当 $n$ 大时 $\sum e_t^2 \approx \sum e_{t-1}^2 \approx \sum_{t=1}^n e_t^2$，故 $d \approx 2 - 2\hat{\rho} = 2(1-\hat{\rho})$。
> - **Obsidian 标签建议**：`#自测题/较难`
