# 自变量选择

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：现实建模中你往往有几十甚至上百个候选变量，全部放进模型会导致过拟合、解释困难、多重共线性。变量选择是所有回归/机器学习建模的"第一道关卡"，也是 ISLR Ch.6 和 Penn State STAT 462 的核心内容。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 做回归时，你手头有 $p$ 个候选自变量，但：
> - 全部放进去：过拟合，$R^2$ 虚高，预测误差大，模型解释困难
> - 放太少：遗漏重要变量，导致估计有偏（遗漏变量偏误）
> - 放无关变量：降低估计效率，增加标准误
>
> 所以我们需要一套**准则和流程**，在"拟合优度"和"模型简洁性"之间做权衡 —— 这就是**自变量选择（variable selection）**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：变量选择是"模型选择"的子集，它连接着正则化（Lasso、Ridge）、逐步回归、信息准则（AIC/BIC）、交叉验证等现代统计/机器学习方法。
- **实际应用场景**：生物信息学（从数千基因中筛选关键基因）、经济学（从多个宏观经济指标中筛选预测变量）、市场营销（从大量用户特征中筛选购买意愿的关键因素）。
- **高频题型/任务**：比较全子集与逐步法的优劣、用 Cp/AIC/BIC/调整 $R^2$ 选择模型、理解多重检验风险。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[多元线性回归模型]]**：理解 $y = X\beta + \varepsilon$ 的矩阵形式，以及 $R^2$、$F$ 检验、$t$ 检验的意义。变量选择本质是在这个框架下选择最优的列子集。
2. **[[回归方程的显著性检验]]**：$F$ 检验用于比较嵌套模型（nested models），是逐步回归中"向前引入"和"向后删除"的统计依据。理解 $F$ 统计量的计算：$F = \frac{(RSS_r - RSS_f) / (df_r - df_f)}{RSS_f / df_f}$。

---

## 4. 用直觉语言解释它

> «变量选择就像装修时选家具 —— 不是越多越好，而是在"够用"和"不拥挤"之间找平衡。」

- **直觉类比**：你装修一个 50 平米的房子，家具有 100 件备选。全放进去能住人吗？能，但转不开身。你只选最需要的几件，让房子既实用又不拥挤 —— 这就是变量选择：在模型的"解释力"和"简洁性"之间做权衡。
- **为什么很自然**：人类天生喜欢"奥卡姆剃刀"（如无必要勿增实体）。统计学家给这个直觉配上了数学工具（Cp、AIC、BIC），让"简洁性"有了可量化的代价。
- **一句话直觉本质**：**在过拟合（太多变量）和欠拟合（太少变量）之间走钢丝，用信息准则做标尺。**

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

自变量选择（variable selection / feature selection）是指从 $p$ 个候选自变量中选出一个"最优"子集，使得该子集对应的模型在**拟合优度**和**模型复杂度**之间达到最佳权衡。

### 2. 核心公式：四大选择准则

设模型有 $k$ 个自变量（含截距则参数个数为 $k+1$），$n$ 为样本量，$RSS_k$ 为该模型的残差平方和，$\hat{\sigma}^2 = RSS_p / (n-p-1)$ 为全模型的均方误差。

**调整 $R^2$**（最大化）：

$$
R^2_{adj} = 1 - \frac{RSS_k / (n-k-1)}{TSS / (n-1)} = 1 - \frac{n-1}{n-k-1}(1-R^2)
$$

**Mallows' Cp**（最小化，$Cp \approx k+1$ 为理想）：

$$
C_p = \frac{RSS_k}{\hat{\sigma}^2} - n + 2(k+1)
$$

**AIC**（最小化，正比于 $-2\ln L + 2k$）：

$$
\text{AIC} = n \ln\left(\frac{RSS_k}{n}\right) + 2(k+1) \quad (\text{在正态误差下等价形式})
$$

**BIC**（最小化，对复杂度惩罚更严厉）：

$$
\text{BIC} = n \ln\left(\frac{RSS_k}{n}\right) + (k+1)\ln n
$$

> 注意：上述 AIC/BIC 公式在 $\sigma^2$ 已知时略有不同，这里给出的是 OLS 回归中最常用的形式（$n\ln(RSS/n) + k \cdot \text{penalty}$）。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $k$ | 模型中自变量个数（不含截距） | $0 \leq k \leq p$ | |
| $RSS_k$ | 含 $k$ 个自变量的残差平方和 | $\mathbb{R}^+$ | 越小拟合越好 |
| $TSS$ | 总平方和 | $\mathbb{R}^+$ | $\sum(y_i - \bar{y})^2$ |
| $\hat{\sigma}^2$ | 全模型的均方误差 | $\mathbb{R}^+$ | $RSS_p / (n-p-1)$ |
| $C_p$ | Mallows' Cp 统计量 | $\mathbb{R}^+$ | 理想值接近 $k+1$ |
| AIC | Akaike 信息准则 | $\mathbb{R}$ | 越小越好 |
| BIC | 贝叶斯信息准则 | $\mathbb{R}$ | 越小越好，对复杂模型惩罚更重 |

### 4. 常见变体与适用条件

- **适用条件**：线性回归模型的变量选择；广义线性模型下的 AIC/BIC 选择。
- **限制条件**：
  - Cp 需要来自全模型的 $\hat{\sigma}^2$ 估计，全模型本身不能有严重共线性
  - AIC/BIC 在不同软件中的公式常数项可能不同，比较时需用同一软件
  - 准则只给出建议，最终选择需结合领域知识

## 6. 推导思路和思想来源

- **最初困难**：$R^2$ 随变量增加永远不降，无法用它比较不同大小的模型。需要"惩罚"模型复杂度。
- **直接方法局限**：$R^2$ 和 $F$ 检验只适用于嵌套模型比较，无法在非嵌套模型间做选择。
- **关键"转念"**：给拟合优度加上一个"复杂度惩罚项" —— 每多一个变量，就扣一定的分数。Cp 扣 $2(k+1)$，AIC 也扣 $2(k+1)$，BIC 扣 $(k+1)\ln n$（惩罚更重）。
- **推导主线与动机**：
  - **调整 $R^2$**：将 $R^2$ 除以自由度调整，惩罚无用的额外变量。
  - **Cp**：Mallows 证明，若模型无偏，$E[C_p] \approx k+1$；若 $C_p$ 远大于 $k+1$，说明模型有显著偏误。
  - **AIC**：从信息论出发，$-2\ln L + 2k$ 衡量模型与真实分布的 KL 散度。
  - **BIC**：从贝叶斯出发，假定模型先验等概率，BIC 最小的模型后验概率最大。
- **为什么自然得到此结论**：所有这些准则都是在"拟合误差"和"参数数量"之间做权衡 —— 本质是奥卡姆剃刀的数学化。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

**题目**：有 3 个候选模型，$n=50$，$RSS$ 和 $k$ 如下：

| 模型 | $k$ | $RSS$ |
|:---|:---:|:---:|
| A | 1 | 200 |
| B | 2 | 180 |
| C | 3 | 175 |

TSS = 500，全模型 $\hat{\sigma}^2 = 175/(50-3-1) = 3.80$。计算各模型的调整 $R^2$、Cp、AIC、BIC 并选择最优。

**解题思路与关键步骤**：

1. **调整 $R^2$**：
   - A: $R^2 = 1 - 200/500 = 0.60$，$R^2_{adj} = 1 - \frac{49}{48}(0.40) = 0.5917$
   - B: $R^2 = 1 - 180/500 = 0.64$，$R^2_{adj} = 1 - \frac{49}{47}(0.36) = 0.6247$
   - C: $R^2 = 1 - 175/500 = 0.65$，$R^2_{adj} = 1 - \frac{49}{46}(0.35) = 0.6272$ ← **最大**

2. **Cp**：
   - A: $C_p = 200/3.80 - 50 + 2(2) = 52.63 - 50 + 4 = 6.63$（$k+1=2$，远大于 2，偏误大）
   - B: $C_p = 180/3.80 - 50 + 2(3) = 47.37 - 50 + 6 = 3.37$（$k+1=3$，接近 3，好）
   - C: $C_p = 175/3.80 - 50 + 2(4) = 46.05 - 50 + 8 = 4.05$（$k+1=4$，比 B 差）

3. **AIC**（$n\ln(RSS/n) + 2(k+1)$）：
   - A: $50\ln(200/50) + 4 = 50\ln 4 + 4 = 69.31 + 4 = 73.31$
   - B: $50\ln(180/50) + 6 = 50\ln 3.6 + 6 = 64.08 + 6 = 70.08$
   - C: $50\ln(175/50) + 8 = 50\ln 3.5 + 8 = 62.65 + 8 = 70.65$

4. **BIC**（$n\ln(RSS/n) + (k+1)\ln n$）：
   - A: $50\ln 4 + 2\ln 50 = 69.31 + 7.82 = 77.13$
   - B: $50\ln 3.6 + 3\ln 50 = 64.08 + 11.73 = 75.81$
   - C: $50\ln 3.5 + 4\ln 50 = 62.65 + 15.64 = 78.29$

**最终答案**：模型 B（$k=2$）在 Cp、AIC、BIC 上均最优，调整 $R^2$ 与 C 也很接近。综合考虑选 B。

**易错点**：Cp 公式中的 $+2(k+1)$ 容易漏掉截距项；AIC/BIC 的 $k+1$ 也包含截距。

**🤔 追问**：如果 $n=500$ 而不是 50，BIC 会偏向更简单的模型还是更复杂的模型？答案：$\ln n$ 变大，惩罚加重，更偏向简单模型。

### 例子 2：中等例子（条件判断与多步推理）

**题目**：Cp 值为 3.5 的模型有 3 个自变量（$k=3$），$n=30$。这个 $C_p$ 是偏大还是偏小？说明什么？

**解答**：$C_p = 3.5$，$k+1 = 4$，$C_p < k+1$，略小于理想值。说明模型可能略有偏误但尚可接受。若 $C_p$ 远大于 $k+1$（如 $C_p = 12$），说明模型遗漏了重要变量或存在严重偏误。

### 例子 3：实际应用例子（Python 代码）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from itertools import combinations

# 模拟数据：10 个候选变量，只有前 3 个真正相关
np.random.seed(42)
n, p = 100, 10
X = np.random.randn(n, p)
true_beta = np.array([2, -1, 0.5, 0, 0, 0, 0, 0, 0, 0])
y = X @ true_beta + np.random.normal(0, 1, n)

# 计算全模型 sigma2 估计
X_full = sm.add_controls(X)  # 确保有截距
# 手动添加截距
X_full = sm.add_constant(X)
full_model = sm.OLS(y, X_full).fit()
sigma2_hat = full_model.ssr / full_model.df_resid

# 枚举所有子集（p=10 时共 2^10=1024 个，这里演示前 5 个变量）
results = []
for k in range(1, 6):  # 考虑 1 到 5 个变量
    for combo in combinations(range(5), k):  # 只考虑前 5 个变量
        cols = [0] + [c + 1 for c in combo]  # +1 因为 const 在第 0 列
        X_sub = X_full[:, cols]
        model = sm.OLS(y, X_sub).fit()
        k_actual = len(combo)
        n = len(y)
        rss = model.ssr
        
        # 计算准则
        adj_r2 = 1 - (rss / (n - k_actual - 1)) / (np.var(y, ddof=1))
        cp = rss / sigma2_hat - n + 2 * (k_actual + 1)
        aic = n * np.log(rss / n) + 2 * (k_actual + 1)
        bic = n * np.log(rss / n) + (k_actual + 1) * np.log(n)
        
        results.append({
            'vars': combo, 'k': k_actual,
            'adj_r2': adj_r2, 'cp': cp, 'aic': aic, 'bic': bic
        })

df_results = pd.DataFrame(results)
print("各准则最优模型：")
print(f"调整 R² 最优: {df_results.loc[df_results['adj_r2'].idxmax(), 'vars']}")
print(f"Cp 最优:      {df_results.loc[df_results['cp'].idxmin(), 'vars']}")
print(f"AIC 最优:     {df_results.loc[df_results['aic'].idxmin(), 'vars']}")
print(f"BIC 最优:     {df_results.loc[df_results['bic'].idxmin(), 'vars']}")
# 预期：真变量 {0, 1, 2} 被一致选出
```

## 8. 常见误区和易混概念

### 误区 1：$R^2$ 最大的模型就是最好的

- **错误直觉**：$R^2$ 越高说明拟合越好，选 $R^2$ 最大的。
- **为什么错**：$R^2$ 随变量增加永远不降，即使加一个完全无关的随机噪声变量，$R^2$ 也会微增。
- **正确理解**：应使用调整 $R^2$ 或 Cp/AIC/BIC 等惩罚复杂度的准则。

### 误区 2：AIC 和 BIC 选出的模型不一样，说明方法有问题

- **错误直觉**：两个准则不一致说明"哪个都不对"。
- **为什么错**：BIC 对复杂度的惩罚更重（$\ln n$ 惩罚项），所以大样本下 BIC 更偏向简单模型。AIC 更注重预测精度，BIC 更注重真实模型识别。两者目标不同，结果不同是正常的。
- **正确理解**：AIC 最小化预测误差的渐近期望，BIC 最大化真实模型的后验概率。选择哪个取决于你的目标（预测 vs 解释）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **调整 $R^2$** | 惩罚无用变量 | 对每个额外变量扣除固定收益 | 快速比较不同大小的模型 |
| **Cp** | 衡量模型的偏误-方差权衡 | 理想值接近 $k+1$，可判断有无偏误 | 传统线性回归 |
| **AIC** | 最小化 KL 散度 | 惩罚项为 $2k$，注重预测精度 | 预测目标 |
| **BIC** | 最大化后验概率 | 惩罚项为 $k\ln n$，大样本更严厉 | 解释目标（识别真模型） |

### 题目与解析

#### 1. 为什么变量选择不能用 $R^2$？
> [!question]- 答案解析
> - **答案**：$R^2$ 随变量增加永远不降，即使加一个纯噪声变量也会微增。
> - **解析**：$R^2$ 的定义是 $1 - RSS/TSS$，增加变量只会减少或不变 RSS，不会增加 RSS，所以 $R^2$ 单调不减。
> - **对应误区**：误区 1。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. $n=30, k=5, R^2=0.80$，求调整 $R^2$。
> [!question]- 答案解析
> - **答案**：$R^2_{adj} = 1 - \frac{29}{24}(0.20) = 1 - 0.2417 = 0.7583$。
> - **解析**：代入公式 $R^2_{adj} = 1 - \frac{n-1}{n-k-1}(1-R^2)$。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 某模型的 $C_p = 15.2$，$k=3$，说明什么？
> [!question]- 答案解析
> - **答案**：$C_p = 15.2$ 远大于 $k+1 = 4$，说明模型存在严重偏误（遗漏重要变量）。
> - **解析**：Mallows 证明，若模型正确，$E[C_p] = k+1$。$C_p$ 远大于此值意味着模型有偏。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 当 $n=100$ 时，AIC 和 BIC 的惩罚项分别是多少？
> [!question]- 答案解析
> - **答案**：AIC 惩罚 $2(k+1)$，BIC 惩罚 $(k+1)\ln 100 = 4.605(k+1)$。
> - **解析**：BIC 的惩罚约为 AIC 的 2.3 倍，所以 BIC 更倾向于选择更简洁的模型。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 证明调整 $R^2$ 可以写为 $R^2_{adj} = 1 - \frac{n-1}{n-k-1}(1-R^2)$。
> [!question]- 答案解析
> - **解析**：$R^2 = 1 - RSS/TSS$，$R^2_{adj} = 1 - \frac{RSS/(n-k-1)}{TSS/(n-1)} = 1 - \frac{n-1}{n-k-1} \cdot \frac{RSS}{TSS} = 1 - \frac{n-1}{n-k-1}(1-R^2)$。
