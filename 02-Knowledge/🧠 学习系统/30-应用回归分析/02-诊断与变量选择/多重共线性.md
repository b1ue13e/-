# 多重共线性

## 它解决什么问题

多重共线性描述解释变量之间存在精确或近似线性关系。它主要损害分开识别每个系数的能力，不必然损害同一数据分布附近的整体预测。

## 精确定义

- **完全共线性**：存在非零向量 $a$ 使 $Xa=0$。此时 $X$ 不满列秩，OLS 参数不唯一。
- **近似共线性**：$X$ 满列秩，但某些列几乎由其他列线性组合得到。此时 $(X^TX)^{-1}$ 的某些方向很大，系数方差被放大。

在经典同方差模型下，

$$
\operatorname{Var}(\hat\beta\mid X)=\sigma^2(X^TX)^{-1}.
$$

因此共线性本身不自动引入偏差，但会造成标准误增大、符号不稳定、置信区间变宽，并让单个系数解释对微小数据扰动敏感。

## VIF

将第 $j$ 个解释变量对其余解释变量回归，得到 $R_j^2$，则

$$
\operatorname{VIF}_j=\frac{1}{1-R_j^2}.
$$

VIF 是系数方差相对该变量与其他变量正交情形的放大倍数。阈值 5 或 10 只是经验规则，不能替代任务语境、样本量和不确定性判断。

## 最小诊断

```python
import numpy as np
import pandas as pd
from statsmodels.stats.outliers_influence import variance_inflation_factor

rng = np.random.default_rng(42)
x1 = rng.normal(size=300)
x2 = 0.98 * x1 + rng.normal(scale=0.1, size=300)
x3 = rng.normal(size=300)
X = pd.DataFrame({'x1': x1, 'x2': x2, 'x3': x3})

vif = {
    name: variance_inflation_factor(X.to_numpy(), i)
    for i, name in enumerate(X.columns)
}
condition_number = np.linalg.cond(X.to_numpy())
print(vif)
print('condition_number=', condition_number)
```

诊断至少同时看 VIF、条件数、系数稳定性和变量定义。两个变量高度相关可能是重复测量，也可能分别对应必须保留的科学构念。

## 决策顺序

1. 先排查编码错误：虚拟变量陷阱、重复列、单位换算、副本变量。
2. 回到估计目标：需要单个系数解释，还是只需要预测？
3. 对纯粹重复变量进行删除、合并或重新定义。
4. 若保留全部变量，报告联合效应或使用正则化，并明确解释目标如何变化。
5. 用重抽样检查系数和选择结果稳定性。

## 常见错误

- 认为共线性会让 $R^2$ 一定很低；整体拟合反而可能很高。
- 仅因 VIF 超过固定阈值就删除业务关键变量。
- 把中心化当作能消除所有共线性；它主要改善含交互项或多项式项时的非本质共线性。
- 把 Ridge 测试分数略高于 OLS 当作共线性已被证明。

## 闭卷验收

1. 用方差公式解释为什么系数会不稳定。
2. 区分完全共线性和近似共线性。
3. 给出解释任务和预测任务下两种不同处理决策。
4. 生成一组高共线数据，比较不同重抽样中的系数波动。
