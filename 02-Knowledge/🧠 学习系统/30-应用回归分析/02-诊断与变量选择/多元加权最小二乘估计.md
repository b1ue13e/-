# 多元加权最小二乘估计

## 为什么需要 WLS

当条件均值模型合理，但误差方差随样本变化时，OLS 系数仍可能无偏，却不再是线性无偏估计量中方差最小的选择，经典标准误也会失真。WLS 的目标不是让残差图更好看，而是利用可信的方差结构提高效率并恢复合适的推断。

## 模型与目标函数

设

$$
y=X\beta+\varepsilon,\qquad
\operatorname{Var}(\varepsilon\mid X)=\sigma^2\Omega,
$$

其中 $\Omega=\operatorname{diag}(\omega_1,\ldots,\omega_n)$。若 $\omega_i$ 表示第 $i$ 个观测的相对方差，则权重应取

$$
w_i=\frac{1}{\omega_i}.
$$

WLS 最小化

$$
\sum_{i=1}^n w_i(y_i-x_i^T\beta)^2,
$$

解为

$$
\hat\beta_{\mathrm{WLS}}=(X^TWX)^{-1}X^TWy,
\qquad W=\operatorname{diag}(w_1,\ldots,w_n).
$$

它等价于对两边左乘 $W^{1/2}$ 后做 OLS。权重越大，表示该观测的条件方差越小、信息越可靠；权重不是样本重要性的任意分数。

## 可行 WLS

真实方差通常未知，可按以下顺序估计：

1. 拟合 OLS，保存残差与拟合值。
2. 根据领域机制或残差图提出方差模型。
3. 只用训练数据估计方差模型，构造 $\hat w_i=1/\hat\omega_i$。
4. 拟合 WLS，重新检查残差和不确定性。
5. 与 OLS 加异方差稳健标准误比较；若结论依赖脆弱的权重假设，报告敏感性。

## 最小可运行例子

```python
import numpy as np
import statsmodels.api as sm

rng = np.random.default_rng(42)
x1 = rng.uniform(1, 10, 300)
x2 = rng.normal(size=300)
sigma = 0.4 * x1
y = 2.0 + 1.5 * x1 - 0.8 * x2 + rng.normal(scale=sigma)
X = sm.add_constant(np.column_stack([x1, x2]))

ols = sm.OLS(y, X).fit(cov_type='HC3')
wls = sm.WLS(y, X, weights=1 / sigma**2).fit()

assert np.isfinite(ols.params).all()
assert np.isfinite(wls.params).all()
print('OLS-HC3:', ols.params)
print('WLS:', wls.params)
```

这里使用已知模拟方差，只为验证公式。真实任务中不得把使用真实误差方差的结果冒充可实现方法。

## 选择 WLS 还是稳健标准误

| 目标 | 优先方法 | 关键风险 |
| :--- | :--- | :--- |
| 只修正推断，方差结构不可靠 | OLS + HC3 | 小样本仍需谨慎 |
| 方差结构有强机制依据 | WLS | 权重错设会降低效率并扭曲推断 |
| 条件均值也错了 | 重设均值模型 | WLS 不能修复遗漏非线性或遗漏变量 |

## 常见错误

- 直接使用 $1/\lvert e_i\rvert$ 作为权重，导致极端权重并重复利用噪声。
- 用全数据估计权重后再交叉验证，造成折间泄漏。
- 只比较加权后的 $R^2$，不复查原量纲上的预测误差。
- 看到异方差就默认 WLS，而不与稳健标准误做敏感性比较。

## 闭卷验收

1. 从变换后的 OLS 推导 WLS 正规方程。
2. 解释权重为什么与条件方差成反比。
3. 给出一个权重模型错设会使结论更差的例子。
4. 在训练集内估计一次方差模型，并在独立测试集原量纲上评价。
