# 一元线性回归模型

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：一元线性回归是回归分析乃至整个监督学习的"hello world"。它包含了回归建模的全部核心思想（模型结构、参数估计、假设检验、预测），而数学上又足够简单，可以手算直观理解。掌握一元线性回归是理解多元回归、广义线性模型、正则化等一切后续方法的绝对前提。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 你是一名教育研究者，收集了 20 名学生的**学习时长（小时/周）**和**期末考试成绩（分）**的数据。你隐约觉得：学得越久，考得越好，但具体好多少？如果一个学生每周学 15 小时，她能考多少分？以前的做法只能是"大概 80 分左右"——这个"大概"太模糊了。
>
> 更麻烦的是：你发现同样是学习 10 小时的学生，有人考 70 分，有人考 85 分。**你不能用一个固定值预测所有学生**，你需要一个能**量化不确定性**的模型。
>
> **一元线性回归模型要解决的就是**：当只有一个自变量 $X$ 时，如何建立 $Y$ 与 $X$ 之间的线性关系，并基于此进行预测和推断。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：一元线性回归是多元回归、多项式回归、广义线性模型的基础。一元回归中所有的概念（截距、斜率、残差、$R^2$、F 检验、t 检验）都会在更复杂的模型中反复出现。
- **实际应用场景**：
  - **医学**：药物剂量与血压下降的关系
  - **经济学**：通货膨胀率与失业率的关系（菲利普斯曲线）
  - **工程**：温度与材料强度的关系
  - **机器学习**：线性回归是第一个也是最基础的监督学习算法
- **高频题型/任务**：参数估计（OLS 手算）、回归系数的解释、假设检验（t 检验判定 $X$ 是否显著影响 $Y$）、$R^2$ 的解释、预测与预测区间

---

## 3. 学它之前需要哪些前置知识？

1. **[[回归分析概述]]**：回归分析的目标是估计条件期望 $E[Y|X]$，一元线性回归是最简单的实现。
2. **[[待创建:协方差与相关系数]]**：理解 $X$ 和 $Y$ 之间的线性关联强度，回归系数 $\beta_1$ 与相关系数 $r$ 的关系：$\beta_1 = r \cdot \frac{s_Y}{s_X}$。
3. **[[待创建:最小二乘思想]]**：使误差平方和最小的直观想法——这是回归参数估计的核心。

---

## 4. 用直觉语言解释它

> «"这东西其实就像"用一把尺子去量 X 和 Y 之间的"平均步调"——X 每往前走一步，Y 平均走几步。"»

- **直觉类比**：想象你和朋友用同一速度走路，你走 1 米，朋友平均走 $\beta_1$ 米。但有时你们步调不完全一致（误差 $\varepsilon$），可能是他系鞋带、你躲水坑造成的随机扰动。一元线性回归就是找出这个"平均步调比" $\beta_1$，以及"起点差" $\beta_0$。
- **为什么很自然**：我们的直觉就是在散点图上"画一条直线"来代表趋势。一元线性回归就是把这个直觉数学化——用最小二乘法找到"最好"的那条线。
- **一句话直觉本质**：**一元线性回归 = 用一条直线近似 $Y$ 对 $X$ 的条件期望**。

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
一元线性回归模型假设因变量 $Y$ 与自变量 $X$ 之间存在线性关系：
$$Y = \beta_0 + \beta_1 X + \varepsilon$$

其中 $\beta_0$ 是截距，$\beta_1$ 是斜率，$\varepsilon$ 是随机误差项。

### 2. 核心公式
OLS 估计量：
$$\hat{\beta}_1 = \frac{\sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})}{\sum_{i=1}^n (X_i - \bar{X})^2} = \frac{S_{XY}}{S_{XX}}$$
$$\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$$

拟合值（预测值）：
$$\hat{Y}_i = \hat{\beta}_0 + \hat{\beta}_1 X_i$$

残差：
$$e_i = Y_i - \hat{Y}_i$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $Y$ | 因变量（响应变量） | $\mathbb{R}$ | 我们要预测的变量 |
| $X$ | 自变量（解释变量） | $\mathbb{R}$ | 用于预测的单一变量 |
| $\beta_0$ | 截距（intercept） | $\mathbb{R}$ | $X=0$ 时 $Y$ 的期望值 |
| $\beta_1$ | 斜率（slope） | $\mathbb{R}$ | $X$ 每增加 1 单位，$Y$ 的平均变化量 |
| $\varepsilon$ | 随机误差项 | $\mathbb{R}$ | 不可观测的随机扰动，$E[\varepsilon]=0$ |
| $n$ | 样本量 | $\mathbb{N}^+$ | 观测个数 |
| $\hat{Y}_i$ | 第 $i$ 个拟合值 | $\mathbb{R}$ | 模型预测值 |
| $e_i$ | 第 $i$ 个残差 | $\mathbb{R}$ | 观测值与拟合值的差 |

### 4. 常见变体与适用条件
- **适用条件**：
  1. $X$ 和 $Y$ 存在线性关系（散点图初步判断）
  2. 观测独立
  3. 误差同方差（$Var(\varepsilon|X) = \sigma^2$ 常数）
  4. 误差正态分布（推断需要，估计不需要）
- **限制条件**：只能捕捉一个 $X$ 的线性效应；无法处理非线性关系（除非变换变量）

## 6. 推导思路和思想来源

- **最初困难**：给定一堆散点，怎么"客观地"画一条线？不同人画出的线不同。
- **直接方法局限**：连接首尾两点、画"视觉中线"等方法都不具备数学一致性和可重复性。
- **关键"转念"**：定义"好的线"的标准——让所有点到线的**垂直距离平方和最小**。为什么平方？因为：
  - 正负误差不会相互抵消
  - 平方函数可微，方便求导优化
  - 大误差的惩罚更大（符合直觉）
- **推导主线与动机**：
  1. 定义残差平方和 $RSS = \sum_{i=1}^n (Y_i - \beta_0 - \beta_1 X_i)^2$
  2. 对 $\beta_0$ 和 $\beta_1$ 分别求偏导，令为 0
  3. 得到正规方程：
     $$\sum(Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i) = 0$$
     $$\sum X_i(Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i) = 0$$
  4. 解方程组得到 OLS 估计量
- **为什么自然得到此结论**：最小二乘在几何上就是将 $Y$ 向量向 $X$ 张成的空间做正交投影，这是线性代数中最自然的"最佳逼近"方式。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：5 名学生的学习时长（$X$，小时/周）与考试成绩（$Y$，分）如下：
  | $X$ | 2 | 5 | 8 | 10 | 15 |
  |:---:|:---:|:---:|:---:|:---:|:---:|
  | $Y$ | 45 | 60 | 70 | 85 | 95 |
  求一元线性回归方程，并预测学习 12 小时/周的学生的成绩。
- **解题思路与关键步骤**：
  1. 计算均值：$\bar{X} = \frac{2+5+8+10+15}{5} = 8$, $\bar{Y} = \frac{45+60+70+85+95}{5} = 71$
  2. 计算 $S_{XX} = \sum(X_i - \bar{X})^2$:
     $(2-8)^2=36$, $(5-8)^2=9$, $(8-8)^2=0$, $(10-8)^2=4$, $(15-8)^2=49$ → $S_{XX}=98$
  3. 计算 $S_{XY} = \sum(X_i - \bar{X})(Y_i - \bar{Y})$:
     $(-6)(-26)=156$, $(-3)(-11)=33$, $(0)(-1)=0$, $(2)(14)=28$, $(7)(24)=168$ → $S_{XY}=385$
  4. $\hat{\beta}_1 = \frac{385}{98} \approx 3.9286$, $\hat{\beta}_0 = 71 - 3.9286 \times 8 \approx 39.571$
  5. 回归方程：$\hat{Y} = 39.57 + 3.93X$
  6. 预测：$\hat{Y}(12) = 39.57 + 3.93 \times 12 \approx 86.71$ 分
- **最终答案**：$\hat{Y} = 39.57 + 3.93X$，12 小时预测约 86.7 分
- **易错点**：计算 $\bar{X}$ 和 $\bar{Y}$ 时注意精度；$S_{XY}$ 的符号决定斜率方向。
- **🤔 追问**：如果有一个学生每周学 0 小时，预测成绩是 39.57 分——这个解释合理吗？→ 不合理，因为 $X=0$ 不在观测范围内（外推风险）。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：
  某公司研究广告支出（$X$，万元）与月销售额（$Y$，万元）的关系，收集了 10 个月的数据。拟合得 $\hat{Y} = 50 + 3.2X$，$R^2 = 0.64$。请解释系数含义，并判断广告是否有效。
  - **解释**：广告支出为 0 时，基础销售额约 50 万元；广告支出每增加 1 万元，月销售额平均增加 3.2 万元。
  - **判断**：需要做 t 检验判断 $\beta_1$ 是否显著不为 0。$R^2=0.64$ 说明广告支出能解释 64% 的销售额变动，但正式结论需要 p 值。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：
  ```python
  import numpy as np
  from sklearn.linear_model import LinearRegression

  # 数据：学习时长 (小时/周) 与考试成绩 (分)
  X = np.array([2, 5, 8, 10, 15]).reshape(-1, 1)
  Y = np.array([45, 60, 70, 85, 95])

  # 手算 OLS 对照
  X_mean, Y_mean = np.mean(X), np.mean(Y)
  beta_1 = np.sum((X.flatten() - X_mean) * (Y - Y_mean)) / np.sum((X.flatten() - X_mean)**2)
  beta_0 = Y_mean - beta_1 * X_mean
  print(f"手算: beta_0={beta_0:.4f}, beta_1={beta_1:.4f}")
  # 输出: 手算: beta_0=39.5714, beta_1=3.9286

  # sklearn 验证
  model = LinearRegression()
  model.fit(X, Y)
  print(f"sklearn: intercept={model.intercept_:.4f}, coef={model.coef_[0]:.4f}")
  # 输出: sklearn: intercept=39.5714, coef=3.9286

  # 预测学习 12 小时/周
  pred = model.predict(np.array([[12]]))
  print(f"预测成绩 (12h): {pred[0]:.2f} 分")
  # 输出: 预测成绩 (12h): 86.71 分
  ```

## 8. 常见误区和易混概念

### 误区 1：斜率 $\beta_1$ 越大，说明 $X$ 对 $Y$ 的"影响"越大
- **错误直觉**：看到 $\beta_1=100$ 就觉得"这个变量很重要"。
- **为什么错**：$\beta_1$ 的大小取决于 $X$ 和 $Y$ 的量纲。如果 $X$ 的单位是"万元"，$\beta_1=100$；如果换成"元"，$\beta_1$ 就变成 0.01。真正衡量重要性的应该是标准化系数或 t 统计量。
- **正确理解**：$\beta_1$ 的值是有量纲的，不能跨变量比较大小。比较重要性用标准化回归系数或 p 值。

### 误区 2：相关关系就是回归关系
- **错误直觉**：$r=0.8$ 就是 $\beta_1=0.8$。
- **为什么错**：相关系数 $r$ 和回归系数 $\beta_1$ 的关系是 $\beta_1 = r \cdot \frac{s_Y}{s_X}$。$r$ 无量纲（范围 -1 到 1），$\beta_1$ 有量纲。$r$ 衡量的是"线性关联强度"，$\beta_1$ 衡量的是"变化率"。
- **正确理解**：$r$ 和 $\beta_1$ 符号相同，但数值不同且含义不同。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **一元线性回归** | $Y$ 如何随单个 $X$ 线性变化 | 有方向性，给出 $Y$ 的具体预测值 | 单变量预测、因果关系初步探索 |
| **相关分析** | $X$ 和 $Y$ 的线性关联强度 | 对称性，无方向，无预测功能 | 探索性数据分析 |
| **多元线性回归** | $Y$ 如何随多个 $X$ 变化 | 控制其他变量，偏回归系数 | 多变量建模、混淆因素调整 |

### 题目与解析

#### 1. 一元线性回归的基本假设不包括以下哪一项？
> [!question]- 答案解析
> - **答案**：$X$ 和 $Y$ 都服从正态分布。
> - **解析**：一元线性回归不要求 $X$ 或 $Y$ 的边缘分布是正态的，只要求误差 $\varepsilon$ 条件正态（用于推断）或至少 $E[\varepsilon|X]=0$（用于估计）。$X$ 可以是任意分布。
> - **对应误区**：混淆了"误差正态"和"变量正态"。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 已知数据：$\bar{X}=3$, $\bar{Y}=6$, $S_{XX}=10$, $S_{XY}=8$，求 $\hat{\beta}_1$ 和 $\hat{\beta}_0$。
> [!question]- 答案解析
> - **答案**：$\hat{\beta}_1 = 8/10 = 0.8$, $\hat{\beta}_0 = 6 - 0.8 \times 3 = 3.6$
> - **解析**：直接代入 OLS 公式即可。

#### 3. 为什么不能用回归方程 $\hat{Y}=39.57+3.93X$（$X$ 是学习时长 2-15 小时）预测 $X=50$ 小时的情况？
> [!question]- 答案解析
> - **答案**：这是外推问题（extrapolation）。$X=50$ 远远超出训练数据的范围（2-15），我们无法保证 $X$ 和 $Y$ 的关系在 50 小时处仍然是线性的（可能存在边际效应递减）。
> - **解析**：回归模型只在训练数据范围内有效。外推需要额外假设验证。

#### 4. 如果 $X$ 的单位从"小时"改为"分钟"，$\beta_1$ 会如何变化？
> [!question]- 答案解析
> - **答案**：$\beta_1$ 变为原来的 $1/60$。
> - **解析**：$X' = 60X$，则 $\beta_1' = \frac{S_{XY}}{S_{X'X'}} = \frac{S_{XY}}{60^2 S_{XX}} = \frac{\beta_1}{60}$。这印证了"$\beta_1$ 大小不能直接表示重要性"。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 如果一元线性回归的误差项 $\varepsilon$ 不满足 $E[\varepsilon|X]=0$，会有什么后果？
> [!question]- 答案解析
> - **答案**：OLS 估计量 $\hat{\beta}_1$ 和 $\hat{\beta}_0$ 会是有偏的。
> - **解析**：$E[\varepsilon|X]=0$ 是 OLS 无偏性的关键假设。如果 $\varepsilon$ 与 $X$ 相关（如遗漏变量），则 $E[\hat{\beta}_1] \neq \beta_1$。例如，假设真实模型是 $Y = \beta_0 + \beta_1 X + \beta_2 Z + \varepsilon$，但我们在模型中忽略了 $Z$，且 $Z$ 与 $X$ 相关，则 $E[\hat{\beta}_1] \neq \beta_1$。
> - **Obsidian 标签建议**：`#自测题/较难`
