## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：残差分析是回归诊断的核心。没有残差分析，你无法判断回归的基本假设是否成立——"模型显著"的结论可能完全建立在错误的假设上。回归诊断（[[异方差]]、[[异常值与强影响点]]、[[自相关性问题及其处理|自相关]]）都从残差分析开始。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 你拟合了一个回归模型，$R^2 = 0.85$，F 检验显著，看上去一切完美。但你有没有想过：**如果数据中存在一个异常值，或者误差不是同方差的，或者误差之间存在自相关，那你的"显著"结论可能全是错的？**
>
> 以前的方法（[[回归参数的估计]]、显著性检验）都基于一个假设："误差 $\varepsilon_i$ 独立同分布，服从 $N(0, \sigma^2)$。"但这个假设不是自动成立的——**你必须用数据去验证它**。残差分析就是做这件事的。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：残差分析是 [[异方差]]、[[异常值与强影响点]]、[[自相关性问题及其处理]] 的诊断入口。不通过残差分析发现这些问题，后续的"修正方法"（加权最小二乘、Box-Cox 变换等）就无从谈起。
- **实际应用场景**：任何回归分析报告都必须包含残差诊断部分；机器学习的"学习曲线"和"残差图"也是类似思路。
- **高频题型/任务**：画残差图并判断假设是否满足；计算 Cook 距离识别强影响点；计算 Durbin-Watson 统计量判断自相关。

---

## 3. 学它之前需要哪些前置知识？

1. **[[回归参数的估计]]**：知道残差 $e_i = y_i - \hat{y}_i$ 的定义，以及为什么样本残差能有偏地估计误差 $\varepsilon_i$。
2. **[[回归方程的显著性检验]]**：理解基本假设（独立、正态、同方差）的内容。

---

## 4. 用直觉语言解释它

> «"这东西其实就像……体检。模型是人的身体，残差就是体检报告上的异常指标。"»

- **直觉类比**：你感觉自己身体不错（模型 $R^2$ 很高），但体检报告（残差图）可能告诉你肝功能有问题（异方差）、心率不齐（自相关）或者有肿瘤（异常值）。残差分析就是全面体检，而不是只看"体重大小"一个指标。
- **一句话直觉本质**：残差应该"看起来像随机噪音"——如果残差图中能看到任何模式（喇叭形、弯曲形、离群点），说明模型假设被违反了。

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

**残差（Residual）**：
$$ e_i = y_i - \hat{y}_i = y_i - X_i'\hat{\beta} $$

**学生化残差（Studentized Residual）**：
$$ r_i = \frac{e_i}{\hat{\sigma} \sqrt{1 - h_{ii}}} $$
其中 $h_{ii}$ 是帽子矩阵 $H = X(X'X)^{-1}X'$ 的第 i 个对角元（杠杆值）。

**删除残差（Deleted Residual）**：
$$ e_{(i)} = y_i - \hat{y}_{(i)} $$
其中 $\hat{y}_{(i)}$ 是去掉第 i 个观测后拟合的模型对 $y_i$ 的预测值。

### 2. 四类残差图诊断

**图 1：残差 vs 拟合值（$e_i$ vs $\hat{y}_i$）**
- 正常：随机散落在 0 线附近，无趋势、无喇叭形。
- 异方差：呈现喇叭形（左窄右宽或左宽右窄）。
- 非线性：呈现 U 形或倒 U 形弯曲。

**图 2：残差的 Q-Q 图（正态概率图）**
- 正常：点大致沿对角线分布。
- 厚尾：两端偏离对角线（长尾分布）。
- 偏斜：整体呈 S 形弯曲。

**图 3：残差 vs 某个自变量（$e_i$ vs $X_{ij}$）**
- 正常：随机散落。
- 遗漏非线性：呈现弯曲模式 \(\rightarrow\) 考虑添加 $X_j^2$ 项。

**图 4：残差 vs 时间/顺序（时间序列数据）**
- 正常：随机散落。
- 正自相关：相邻残差正相关（同号聚集）。
- 负自相关：相邻残差负相关（交替正负）。

### 3. 杠杆值、Cook 距离、Durbin-Watson 统计量

**杠杆值 $h_{ii}$**：
$$ h_{ii} = X_i'(X'X)^{-1}X_i, \quad 0 \le h_{ii} \le 1, \quad \sum h_{ii} = p+1 $$
经验法则：$h_{ii} > 2(p+1)/n$ 为高杠杆点。

**Cook 距离 $D_i$**：
$$ D_i = \frac{e_i^2}{(p+1)\hat{\sigma}^2} \cdot \frac{h_{ii}}{(1-h_{ii})^2} $$
经验法则：$D_i > 1$ 或 $D_i > 4/n$ 为强影响点。

**Durbin-Watson 统计量 $d$**：
$$ d = \frac{\sum_{i=2}^n (e_i - e_{i-1})^2}{\sum_{i=1}^n e_i^2} \in [0, 4] $$
- $d \approx 2$：无自相关
- $d < 2$ 且显著：正自相关（常见于时间序列）
- $d > 2$ 且显著：负自相关

### 4. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $e_i$ | 普通残差 | $\mathbb{R}$ | 异方差 |
| $r_i$ | 学生化残差 | $\mathbb{R}$ | 近似 $N(0,1)$ |
| $h_{ii}$ | 杠杆值 | $[0, 1]$ | 衡量"异常" |
| $D_i$ | Cook 距离 | $\ge 0$ | 衡量"影响" |
| $d$ | Durbin-Watson | $[0, 4]$ | 检验自相关 |

### 5. 常见变体与适用条件

- **适用条件**：残差分析适用于任何线性回归模型。
- **限制条件**：学生化残差在正态性假设下近似 $t$ 分布；Q-Q 图对样本量较小时不够敏感；Durbin-Watson 检验只适用于一阶自相关。

## 6. 推导思路和思想来源

- **最初困难**：误差 $\varepsilon_i$ 是观测不到的，如何用观测数据验证假设？
- **直接方法局限**：只能用样本残差 $e_i$ 作为 $\varepsilon_i$ 的代理。但 $e_i$ 的方差不是常数（$Var(e_i) = \sigma^2(1-h_{ii})$），且 $e_i$ 之间不独立。
- **关键"转念"**：虽然残差 $e_i$ 不是完美的 $\varepsilon_i$ 估计，但在大样本下，$e_i$ 近似 $\varepsilon_i$。通过学生化（标准化为常数方差）和删除残差（消除相关性），可以更好地逼近 $\varepsilon_i$ 的行为。
- **推导主线与动机**：$e = (I-H)y$，所以 $Var(e) = \sigma^2(I-H)$。学生化残差 $r_i = e_i / (\hat{\sigma} \sqrt{1-h_{ii}})$ 使方差近似为 1。Cook 距离则衡量"如果删除第 i 个观测，所有 $\hat{\beta}$ 的变化有多大"。
- **为什么自然得到此结论**：因为残差是"拟合后剩下的东西"，理论上它应该只是随机噪音。任何系统性的模式都说明"该用模型解释的部分"没有被充分解释。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

已知 $n=5$，$p=1$，$y = [2, 4, 5, 8, 10]$，$x = [1, 2, 3, 4, 5]$，拟合 $\hat{y} = 0.5 + 1.9x$，计算残差并画简单的残差图判断。

- **解题思路**：$\hat{y} = [2.4, 4.3, 6.2, 8.1, 10.0]$，$e = [-0.4, -0.3, -1.2, -0.1, 0.0]$。
- **残差图**：$e_i$ vs $\hat{y}_i$ 大致随机散落，无明显模式。
- **易错点**：样本量太少时，残差图难以判断模式。
- **🤔 追问**：如果残差中有一个值为 -3.5，应该怀疑什么？可能存在异常值。

### 例子 2：中等例子（残差模式识别）

假设你绘制了残差 vs 拟合值图，发现呈明显的喇叭形（左端残差集中，右端发散）。这是什么问题？

- **题目与完整解答**：这是典型的[[异方差]]——误差方差随拟合值增大而增大。后果：标准误被低估，t 检验和 F 检验失效（过于乐观）。解决方案：对 $Y$ 做对数变换，或使用加权最小二乘。
- **另一种模式**：残差图呈 U 形弯曲 → 遗漏了 $X^2$ 项，应添加二次项。

### 例子 3：实际应用例子（matplotlib 残差图代码 + Cook 距离 + Durbin-Watson）

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import OLSInfluence
from statsmodels.stats.stattools import durbin_watson

# 模拟数据：一个正常的模型 + 一个有人为异常的模型
np.random.seed(42)
n = 100
X = np.random.randn(n, 2)
beta = np.array([1.0, 0.5])
y = 2.0 + X @ beta + np.random.randn(n) * 0.8

# 人为加入一个异常值
y[0] = 15  # 极端异常

# 拟合模型
X_df = sm.add_constant(pd.DataFrame(X, columns=['X1', 'X2']))
model = sm.OLS(y, X_df).fit()
y_pred = model.predict(X_df)
residuals = model.resid
influence = OLSInfluence(model)

# === 四类残差图 ===
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# 图1：残差 vs 拟合值
axes[0, 0].scatter(y_pred, residuals, alpha=0.6)
axes[0, 0].axhline(y=0, color='r', linestyle='--', alpha=0.5)
axes[0, 0].set_xlabel('拟合值')
axes[0, 0].set_ylabel('残差')
axes[0, 0].set_title('图1：残差 vs 拟合值\n（检查异方差与非线性）')

# 图2：Q-Q 图
sm.qqplot(residuals, line='s', ax=axes[0, 1])
axes[0, 1].set_title('图2：Q-Q 图\n（检查正态性）')

# 图3：残差 vs 自变量 X1
axes[1, 0].scatter(X[:, 0], residuals, alpha=0.6)
axes[1, 0].axhline(y=0, color='r', linestyle='--', alpha=0.5)
axes[1, 0].set_xlabel('X1')
axes[1, 0].set_ylabel('残差')
axes[1, 0].set_title('图3：残差 vs X1\n（检查遗漏非线性）')

# 图4：残差 vs 顺序
axes[1, 1].scatter(range(n), residuals, alpha=0.6)
axes[1, 1].axhline(y=0, color='r', linestyle='--', alpha=0.5)
axes[1, 1].set_xlabel('观测顺序')
axes[1, 1].set_ylabel('残差')
axes[1, 1].set_title('图4：残差 vs 顺序\n（检查自相关）')

plt.tight_layout()
plt.show()
# 输出注释：图1中可以看到一个明显的离群点（第0个观测）
# Q-Q图两端偏离对角线，说明异常值影响了正态性

# === Cook 距离 ===
cooks_d = influence.cooks_distance[0]
high_influence = np.where(cooks_d > 4/n)[0]
print(f"高影响点（Cook距离 > 4/n = {4/n:.4f}）：{high_influence}")
# 输出：第0个观测的 Cook 距离很大，说明它是强影响点

# 杠杆值
leverage = influence.hat_matrix_diag
high_leverage = np.where(leverage > 2*(X_df.shape[1])/n)[0]
print(f"高杠杆点：{high_leverage}")

# === Durbin-Watson 检验 ===
dw = durbin_watson(residuals)
print(f"Durbin-Watson 统计量: {dw:.4f}")
# 输出：~2.0 说明无自相关（本例中数据是随机生成的，应接近2）
# 解释：d ≈ 2 表示无自相关；d < 1.5 提示正自相关；d > 2.5 提示负自相关
```

## 8. 常见误区和易混概念

### 误区 1：残差小 = 模型好
- **错误直觉**：残差接近 0 说明模型完美拟合。
- **为什么错**：残差小可能只是过拟合——模型把噪音也拟合进去了。残差分析更重要的是看残差的**模式**，而不是大小。
- **正确理解**：好的模型残差应该是"随机噪音"（无模式），而不是"小"。

### 误区 2：杠杆值大的点一定是强影响点
- **错误直觉**：$h_{ii}$ 大 → 一定要删除该点。
- **为什么错**：高杠杆点可能只是 $X$ 值特殊，但如果 $Y$ 值也符合模型趋势，它对 $\hat{\beta}$ 的影响并不大。需要结合 Cook 距离综合判断。
- **正确理解**：高杠杆 + 大残差 = 强影响点（Cook 距离大）；高杠杆 + 小残差 = 对模型无害。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 普通残差 $e_i$ | 原始预测误差 | 方差非常数 | 初步诊断 |
| 学生化残差 $r_i$ | 标准化后的误差 | 方差近似为 1 | 识别异常值 |
| 杠杆值 $h_{ii}$ | 该点在 X 空间中的"特殊性" | 只依赖 X | 识别高杠杆点 |
| Cook 距离 $D_i$ | 该点对 $\hat{\beta}$ 的总体影响 | 综合 X 和 Y | 识别强影响点 |

### 题目与解析

#### 1. 残差 vs 拟合值图呈喇叭形说明什么问题？
> [!question]- 答案解析
> - **答案**：说明存在[[异方差]]——误差方差随拟合值增大而增大。
> - **解析**：这是异方差的典型表现。
> - **易错原因**：误认为是非线性。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 写出学生化残差的公式，并解释为什么需要学生化？
> [!question]- 答案解析
> - **答案**：$r_i = e_i / (\hat{\sigma} \sqrt{1-h_{ii}})$。普通残差方差不相等（$Var(e_i) = \sigma^2(1-h_{ii})$），学生化使其方差近似为 1，便于识别异常值（通常 $|r_i| > 3$ 视为异常）。
> - **解析**：$h_{ii}$ 越大，$e_i$ 的方差越小，所以需要除以 $\sqrt{1-h_{ii}}$ 来矫正。
> - **对应误区**：直接用普通残差识别异常值。

#### 3. 杠杆值大的点一定是强影响点吗？为什么？
> [!question]- 答案解析
> - **答案**：不一定。杠杆值只衡量 $X$ 的"特殊性"，强影响需要 $X$ 特殊且 $Y$ 偏离模型趋势（即大残差）。
> - **解析**：高杠杆 + 小残差 → 对模型影响不大；高杠杆 + 大残差 → 强影响点。
> - **对应误区**：认为杠杆值等同于影响力。

#### 4. Durbin-Watson 统计量 $d=1.2$ 说明什么？
> [!question]- 答案解析
> - **答案**：$d=1.2 < 2$，提示可能存在正自相关（相邻残差正相关，同号聚集）。
> - **解析**：时间序列数据中常见正自相关，$d < d_L$ 时拒绝"无自相关"的零假设。
> - **对应误区**：认为 $d$ 必须严格等于 2 才无自相关。

#### 5. 推导 $Var(e_i) = \sigma^2(1-h_{ii})$。
> [!question]- 答案解析
> - **答案**：$e = (I-H)y = (I-H)(X\beta + \varepsilon) = (I-H)\varepsilon$。所以 $Var(e) = (I-H)Var(\varepsilon)(I-H)' = \sigma^2(I-H)$（因为 $I-H$ 对称幂等）。取第 i 个对角元得 $Var(e_i) = \sigma^2(1-h_{ii})$。
> - **解析**：帽子矩阵 $H = X(X'X)^{-1}X'$ 是幂等矩阵，$I-H$ 也是幂等矩阵。
> - **对应误区**：认为 $Var(e_i) = \sigma^2$（即所有残差同方差）。
