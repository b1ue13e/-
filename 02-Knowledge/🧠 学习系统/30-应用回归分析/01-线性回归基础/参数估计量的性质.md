# 参数估计量的性质

> 所属模块：[[🗺️ 应用回归分析学习路径|应用回归分析]]
> 主教材：[[应用回归分析-第5版|应用回归分析（第5版）]]
> 对应阶段：[[📈 第一阶段：线性回归基础|返回阶段页]]

## 0. 它值不值得深挖？

**绝对值得，且是回归理论中最优雅的结论之一。** 如果不理解 OLS 估计量的性质，[[回归参数的估计]]就只是"算出了一个数值"，而你无法判断这个数值的可信度。Gauss-Markov 定理是回归分析中"凭什么相信 OLS"的根本答案，它为后续的[[回归系数的区间估计|t 检验和置信区间]]、[[回归方程的显著性检验|F 检验]]提供了理论支柱。

---

## 1. 这个知识点解决什么问题？

**场景：** 你刚刚用 [[回归参数的估计]] 中的公式 $\hat{\beta} = (X'X)^{-1}X'y$ 算出了一组回归系数。看着屏幕上的数字，你心里冒出一个问题：

> "算出来的参数靠谱吗？凭什么相信 OLS 的估计结果？如果我用另一种方法（比如 Ridge 回归、Lasso、或者随便猜一组数）会不会更好？"

**你被卡住了：** 你手头只有一个样本，却想推断总体的真实参数。你无法知道 $\hat{\beta}$ 是否接近真实的 $\beta$，也无法判断 $\hat{\beta}$ 的波动有多大。

这个知识点回答三个核心问题：

1. **线性性：** $\hat{\beta}$ 能否表示为 $y$ 的线性组合？
2. **无偏性：** 平均而言，$\hat{\beta}$ 是否等于真实值 $\beta$？
3. **最优性（BLUE）：** 在所有线性无偏估计量中，OLS 是不是方差最小的？—— 这就是著名的 **Gauss-Markov 定理**。

---

## 2. 为什么它重要？它有什么用？

- **Gauss-Markov 定理是 OLS 的"品质保证书"**：它告诉我们，在经典假设下，OLS 是 BLUE（Best Linear Unbiased Estimator）。这是 OLS 成为回归分析默认方法的核心原因。
- **无偏性保证长期准确性**：虽然单个样本的估计有误差，但平均而言不会系统性地偏离真实值。
- **有效性保证最小不确定性**：在所有线性无偏估计量中，OLS 的方差最小，这意味着它的置信区间最窄、推断最精确。
- **一致性保证大样本可靠性**：样本量越大，估计越接近真实值。
- **这些性质是后续推断的基础**：没有它们，[[回归系数的区间估计|t 检验]]和[[回归方程的显著性检验|F 检验]]的统计量就无法推导。

## 4. 直觉解释

> «「这东西其实就像——你手里有一把尺子（OLS 估计量），想量一个物体的真实长度（$\beta$）。你每次测量都有误差，但如果你反复测量很多次，取平均，这把尺子不会系统性地偏长或偏短（无偏性）。而且，在所有同类型的尺子中（线性无偏估计量），这把尺子的测量误差波动最小（有效性）。随着你测量次数越来越多（样本量增大），测量结果越来越接近真实长度（一致性）。」»

更具体地说：
- **无偏性**：$\hat{\beta}$ 不会系统性高估或低估 $\beta$。它可能偶尔偏高或偏低，但多次重复抽样后，平均值就在 $\beta$ 上。
- **有效性（BLUE）**：在所有线性无偏估计量中，OLS 的方差最小。这意味着 OLS 给出的估计是最"紧凑"的——置信区间最短。
- **一致性**：随着样本量 $n \to \infty$，$\hat{\beta}$ 依概率收敛到 $\beta$。即使在小样本下有偏（某些情况下），大样本下也会消失。

## 5. 正式定义、核心公式、符号解释

### 5.1 Gauss-Markov 定理（核心）

**定理陈述：** 在经典线性回归假设下（$E(\varepsilon) = 0$，$\text{Var}(\varepsilon) = \sigma^2 I$，$X$ 非随机且列满秩），OLS 估计量 $\hat{\beta}$ 是 $\beta$ 的 **BLUE（Best Linear Unbiased Estimator）**，即：

1. **线性性（Linear）：** $\hat{\beta} = (X'X)^{-1}X'y$ 是 $y$ 的线性组合
2. **无偏性（Unbiased）：** $E(\hat{\beta}) = \beta$
3. **最优性（Best）：** 对于任意其他线性无偏估计量 $\tilde{\beta}$，有 $\text{Var}(\tilde{\beta}) - \text{Var}(\hat{\beta})$ 是半正定矩阵

### 5.2 三个性质的详细定义

**性质 1：线性性（Linearity）**

$$
\hat{\beta} = (X'X)^{-1}X'y = Cy, \quad \text{其中 } C = (X'X)^{-1}X'
$$

$\hat{\beta}$ 是 $y$ 的线性函数，系数矩阵 $C$ 只依赖于 $X$。

**性质 2：无偏性（Unbiasedness）**

$$
E(\hat{\beta}) = E[(X'X)^{-1}X'y] = (X'X)^{-1}X' E(y) = (X'X)^{-1}X' (X\beta) = \beta
$$

**性质 3：最优性（BLUE）**

$$
\text{Var}(\hat{\beta}) = \sigma^2 (X'X)^{-1}
$$

对于任意其他线性无偏估计量 $\tilde{\beta} = Ay$（其中 $A$ 是某个 $(p+1) \times n$ 矩阵且 $AX = I$），有：

$$
\text{Var}(\tilde{\beta}) - \text{Var}(\hat{\beta}) \text{ 是半正定矩阵}
$$

这意味着 $\hat{\beta}_j$ 的方差不超过 $\tilde{\beta}_j$ 的方差。

### 5.3 一致性（Consistency）

当样本量 $n \to \infty$ 时，$\hat{\beta}$ 依概率收敛到 $\beta$：

$$
\text{plim } \hat{\beta} = \beta
$$

这要求 $\frac{1}{n} X'X \to Q$（一个有限正定矩阵）且 $\frac{1}{n} X'\varepsilon \to 0$。

### 5.4 符号表

| 符号 | 含义 |
|---|---|
| $\hat{\beta}$ | OLS 估计量 |
| $\beta$ | 真实回归系数 |
| $C$ | $C = (X'X)^{-1}X'$，使得 $\hat{\beta} = Cy$ |
| $\tilde{\beta}$ | 任意其他线性无偏估计量 |
| $\text{plim}$ | 依概率收敛（概率极限） |
| $Q$ | $\frac{1}{n}X'X$ 的极限（有限正定矩阵） |
| $\sigma^2$ | 误差方差 |
| $\text{Var}(\hat{\beta})$ | $\hat{\beta}$ 的方差-协方差矩阵，$\sigma^2(X'X)^{-1}$ |

## 6. 推导思路和思想来源

### 6.1 Gauss-Markov 定理的证明思路

**前提：** 任意线性估计量可写为 $\tilde{\beta} = Ay$，其中 $A$ 是 $(p+1) \times n$ 矩阵。

**无偏性约束：** $E(\tilde{\beta}) = E(Ay) = A E(y) = A X \beta = \beta$ 对所有 $\beta$ 成立 $\Rightarrow$ $AX = I$。

**方差比较：** 令 $D = A - C$，则 $DX = (A - C)X = AX - CX = I - I = 0$。

$$
\text{Var}(\tilde{\beta}) = \text{Var}(Ay) = A \cdot \sigma^2 I \cdot A' = \sigma^2 AA'
$$

$$
AA' = (C + D)(C + D)' = CC' + CD' + DC' + DD'
$$

由于 $DX = 0$ 且 $C = (X'X)^{-1}X'$，可以证明 $CD' = 0$，因此：

$$
AA' = CC' + DD'
$$

所以 $\text{Var}(\tilde{\beta}) = \sigma^2 (CC' + DD') = \text{Var}(\hat{\beta}) + \sigma^2 DD'$

由于 $DD'$ 是半正定矩阵，$\text{Var}(\tilde{\beta}) - \text{Var}(\hat{\beta})$ 是半正定矩阵。

### 6.2 思想来源

Gauss 在 1821 年首次提出最小二乘法的优越性，Markov 在 1912 年给出了严格的数学证明。这个定理是**数理统计史上最重要的定理之一**，它将"最小二乘法"从"一个合理的想法"提升为"在最优性准则下的最优选择"。

### 6.3 一致性的直观理解

$$
\hat{\beta} = \beta + (X'X)^{-1}X'\varepsilon
$$

当 $n \to \infty$ 时，$(X'X)^{-1}$ 按 $1/n$ 量级衰减，而 $X'\varepsilon$ 按 $\sqrt{n}$ 量级增长，因此 $(X'X)^{-1}X'\varepsilon \to 0$。

## 7. 例子

### 7.1 基础例子：手算验证无偏性

考虑一个最简单的模型 $y_i = \beta_1 x_i + \varepsilon_i$（无截距），$n=2$。

$$
\hat{\beta}_1 = \frac{\sum x_i y_i}{\sum x_i^2} = \frac{x_1 y_1 + x_2 y_2}{x_1^2 + x_2^2}
$$

代入 $y_i = \beta_1 x_i + \varepsilon_i$：

$$
\hat{\beta}_1 = \frac{x_1(\beta_1 x_1 + \varepsilon_1) + x_2(\beta_1 x_2 + \varepsilon_2)}{x_1^2 + x_2^2}
= \beta_1 + \frac{x_1 \varepsilon_1 + x_2 \varepsilon_2}{x_1^2 + x_2^2}
$$

取期望：

$$
E(\hat{\beta}_1) = \beta_1 + \frac{x_1 E(\varepsilon_1) + x_2 E(\varepsilon_2)}{x_1^2 + x_2^2} = \beta_1
$$

得证无偏。

### 7.2 中等例子：模拟实验验证无偏性和方差最小性

通过 Monte Carlo 模拟来验证 OLS 的无偏性和有效性。

### 7.3 实际应用 / Python 代码

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# ==========================================
# 模拟实验 1：验证 OLS 的无偏性
# ==========================================
np.random.seed(42)

# 真实参数
beta_true = np.array([2.0, 0.5, -1.0])
n = 50
p = 2  # 自变量个数（不含截距）

# 存储 10000 次模拟的估计结果
n_simulations = 10000
beta_estimates = np.zeros((n_simulations, p + 1))

for i in range(n_simulations):
    # 生成 X（固定设计矩阵）
    X = np.c_[np.ones(n), np.random.randn(n, p)]
    # 生成误差
    epsilon = np.random.normal(0, 1.0, n)
    # 生成 y
    y = X @ beta_true + epsilon
    # OLS 估计
    beta_hat = np.linalg.inv(X.T @ X) @ (X.T @ y)
    beta_estimates[i] = beta_hat

# 计算估计量的均值
beta_mean = np.mean(beta_estimates, axis=0)
print("真实 beta:", beta_true)
print("估计均值:", beta_mean)
print("偏差:", beta_mean - beta_true)
# 输出应接近 [0, 0, 0]，验证无偏性

# 计算估计量的方差
beta_var = np.var(beta_estimates, axis=0)
print("估计方差:", beta_var)

# 理论方差（用最后一次模拟的 X 计算）
sigma2 = 1.0
theoretical_var = sigma2 * np.diag(np.linalg.inv(X.T @ X))
print("理论方差:", theoretical_var)
# 模拟方差应接近理论方差

# ==========================================
# 模拟实验 2：验证 OLS 的 BLUE 性质
# ==========================================
# 构造一个"竞争"线性无偏估计量：加权最小二乘的某种特例
# 这里我们简单比较 OLS 和"丢弃一半数据"的估计量

np.random.seed(123)
n = 100
beta_true = np.array([1.0, 2.0])
X = np.c_[np.ones(n), np.random.randn(n)]

ols_var_estimates = []
half_var_estimates = []

for _ in range(5000):
    epsilon = np.random.normal(0, 1.0, n)
    y = X @ beta_true + epsilon
    
    # OLS
    beta_ols = np.linalg.inv(X.T @ X) @ (X.T @ y)
    
    # 竞争估计量：只用前一半数据
    X_half = X[:n//2, :]
    y_half = y[:n//2]
    beta_half = np.linalg.inv(X_half.T @ X_half) @ (X_half.T @ y_half)
    
    ols_var_estimates.append(beta_ols[1])  # 斜率
    half_var_estimates.append(beta_half[1])

ols_var = np.var(ols_var_estimates)
half_var = np.var(half_var_estimates)
print(f"OLS 斜率方差: {ols_var:.6f}")
print(f"半样本估计量斜率方差: {half_var:.6f}")
print(f"方差比: {half_var / ols_var:.2f} 倍")
# OLS 的方差应该显著小于半样本估计量

# ==========================================
# 模拟实验 3：验证一致性（n 增大时方差减小）
# ==========================================
np.random.seed(42)
beta_true = np.array([1.0, 2.0])
sample_sizes = [10, 30, 100, 300, 1000, 3000]
variances = []

for n in sample_sizes:
    beta_est = []
    for _ in range(5000):
        X = np.c_[np.ones(n), np.random.randn(n)]
        epsilon = np.random.normal(0, 1.0, n)
        y = X @ beta_true + epsilon
        beta_hat = np.linalg.inv(X.T @ X) @ (X.T @ y)
        beta_est.append(beta_hat[1])
    variances.append(np.var(beta_est))
    print(f"n={n:5d}, 斜率方差={variances[-1]:.6f}")

# 绘制方差随 n 衰减的曲线
plt.figure(figsize=(8, 5))
plt.plot(sample_sizes, variances, 'o-')
plt.xscale('log')
plt.yscale('log')
plt.xlabel('Sample size (n)')
plt.ylabel('Variance of slope estimate')
plt.title('Consistency of OLS: Variance decays as n increases')
plt.grid(True, alpha=0.3)
plt.show()
# 方差应随 n 增大而趋于 0（约以 1/n 速率衰减）
```

## 8. 常见误区和易混概念

### 概念对比表 1：无偏性 vs 有效性 vs 一致性

| 对比维度 | 无偏性（Unbiasedness） | 有效性（Efficiency） | 一致性（Consistency） |
|---|---|---|---|
| 定义 | $E(\hat{\beta}) = \beta$ | 方差在所有同类估计量中最小 | $\text{plim } \hat{\beta} = \beta$ |
| 关注点 | 平均是否准确 | 波动是否最小 | 大样本是否收敛 |
| 样本量要求 | 任何 $n$ | 任何 $n$ | $n \to \infty$ |
| OLS 是否满足 | 是（经典假设下） | 是（Gauss-Markov） | 是（适当条件下） |
| 直观理解 | 不偏不倚，不系统高估或低估 | 估计值最紧凑、最稳定 | 样本越大越准 |
| 检验方法 | 模拟取均值看是否接近真实值 | 比较不同估计量的方差 | 逐步增大 n 看方差衰减 |

### 概念对比表 2：BLUE vs 其他估计量

| 对比维度 | OLS（BLUE） | Ridge 回归 | 子集选择 | Lasso |
|---|---|---|---|---|
| 线性性 | 是 | 是 | 否 | 否 |
| 无偏性 | 是 | 有偏 | 通常有偏 | 有偏 |
| 方差 | 线性无偏中最小 | 比 OLS 小（通过引入偏差） | 比 OLS 大或小 | 比 OLS 小 |
| MSE | 可能较大（方差主导） | 通常更小（偏差-方差权衡） | 取决于子集 | 通常更小 |
| 适用场景 | 经典假设满足、$n > p$ | 多重共线性、$n \approx p$ | 变量选择 | 高维稀疏（$p \gg n$） |
| 关键特点 | 理论最优基准 | 牺牲无偏性换方差缩减 | 离散选择 | 连续收缩+自动选择 |

### 常见误区

1. **误区：Gauss-Markov 定理不需要误差正态性**
   - 正确。Gauss-Markov 定理只需要 $E(\varepsilon) = 0$ 和 $\text{Var}(\varepsilon) = \sigma^2 I$，不需要正态分布。正态分布是为 t 检验和 F 检验服务的。
2. **误区：BLUE 意味着 OLS 在所有估计量中方差最小**
   - 错误。BLUE 是"在**线性无偏**估计量中"方差最小。如果允许有偏估计（如 Ridge），方差可以更小（偏差-方差权衡）。
3. **误区：$\hat{\beta}$ 的无偏性意味着 $\hat{\beta}$ 一定接近真实值**
   - 错误。无偏性是说"平均而言"等于真实值，但在单个样本中，$\hat{\beta}$ 可能离真实值很远（尤其是样本量小、噪声大的时候）。
4. **误区：一致性意味着 $\hat{\beta}$ 在大样本下等于真实值**
   - 错误。一致性是"依概率收敛"，不是"确定等于"。大样本下 $\hat{\beta}$ 以高概率接近 $\beta$，但仍有微小偏差。

## 11. 自测题

## 12. 我的主动回忆区

> 以下为个人回忆记录，用于主动 recall 训练。

- **Gauss-Markov 定理：** OLS 是 BLUE（Best Linear Unbiased Estimator）
- **三个条件：** 线性性、无偏性、最优性
- **证明关键：** 任意线性无偏估计量满足 $AX = I$，分解 $A = C + D$ 且 $DX = 0$
- **不需要的假设：** 误差正态性（Gauss-Markov 不需要，但 t/F 检验需要）
- **与 MLE 的关系：** 正态误差下 OLS = MLE，此时 OLS 也是 UMVUE（不仅仅是 BLUE）
- **常见混淆：** BLUE 不是"所有估计量中方差最小"而是"线性无偏估计量中方差最小"
- **一致性 vs 无偏性：** 无偏是"均值正确"，一致是"大样本收敛"
