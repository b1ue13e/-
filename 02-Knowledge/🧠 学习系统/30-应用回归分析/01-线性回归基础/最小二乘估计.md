## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：最小二乘估计（Ordinary Least Squares, OLS）是整个回归分析甚至监督学习的核心估计方法。它不只是"一种计算方法"，更是一种贯穿统计学和机器学习的基本思想——使预测误差的平方和最小。不理解 OLS，就无法理解参数估计、模型拟合、残差分析，也无法理解为什么线性回归能成为最广泛使用的统计工具。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 你面前有一张散点图——横轴是学习时长，纵轴是考试成绩。你直觉上知道可以画一条直线来概括趋势，但问题来了：**可以画的直线有无数条，哪一条才是"最好"的？**
>
> 你试了两种方法：
> - 连接第一个点和最后一个点——但只用了 2 个数据，浪费了其他信息
> - 画一条"看起来穿过中间"的线——但不同人画出来的不一样，没有客观标准
>
> 你需要一个**客观的、数学上可计算的、唯一的最优标准**来判断哪条线最好。最小二乘估计就是回答这个问题的。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：OLS 是回归参数估计的基石。不学 OLS，就无法理解：
  - 回归系数的计算方法（[[回归参数的估计]]）
  - 为什么 OLS 估计量是最优的（[[参数估计量的性质]]，Gauss-Markov 定理）
  - 预测和置信区间的构造
- **实际应用场景**：
  - **任何使用线性回归的领域**：OLS 是默认的参数估计方法
  - **机器学习**：线性回归、Ridge 回归（L2 正则化是 OLS 的扩展）、Lasso 回归（L1 正则化）
  - **信号处理**：最小二乘是滤波器设计的基础
  - **数值优化**：OLS 是凸优化最经典的例子，具有闭式解
- **高频题型/任务**：手算 OLS 估计量、推导正规方程、用矩阵形式求解 OLS

## 4. 用直觉语言解释它

> «"这东西其实就像"用一根橡皮筋穿过所有点，橡皮筋的弹力 = 点到线的距离，最小二乘就是找到让橡皮筋总弹力最小的那根线的位置。"»

- **直觉类比**：想象每个数据点都用一根垂直的弹簧连到一条直线上，弹簧的弹力与距离的平方成正比。最小二乘就是找到让所有弹簧总弹力最小的那条线。为什么是平方？因为弹簧的弹力不是线性的——偏离越远，需要拉的力越大，这符合直觉（大误差的代价更大）。
- **为什么很自然**：如果我们把"好"的线定义为"离所有点尽可能近"，那么自然就想到最小化所有点到线的距离之和。但绝对值距离在数学上处理起来不方便（不可导），而平方距离既保持单调性，又可微，还能放大远离点的惩罚。
- **一句话直觉本质**：**最小二乘估计 = 选择一条直线，使所有观测点到该直线的垂直距离平方和最小**。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
最小二乘估计（OLS）是一种通过最小化残差平方和（Residual Sum of Squares, RSS）来估计回归系数的方法。

### 2. 核心公式

**一元线性回归的 OLS：**
$$RSS = \sum_{i=1}^n (Y_i - \beta_0 - \beta_1 X_i)^2$$
$$\hat{\beta}_1 = \frac{\sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})}{\sum_{i=1}^n (X_i - \bar{X})^2} = \frac{S_{XY}}{S_{XX}}$$
$$\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$$

**矩阵形式的 OLS：**
$$RSS(\beta) = (Y - X\beta)'(Y - X\beta)$$
$$\hat{\beta} = (X'X)^{-1}X'Y$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $RSS$ | 残差平方和 | $\mathbb{R}^+$ | 衡量模型拟合误差 |
| $\hat{\beta}_j$ | 第 $j$ 个回归系数的 OLS 估计 | $\mathbb{R}$ | 使 RSS 最小的最优值 |
| $e_i = Y_i - \hat{Y}_i$ | 第 $i$ 个残差 | $\mathbb{R}$ | 观测值与拟合值的差 |
| $S_{XX}$ | $X$ 的离差平方和 | $\mathbb{R}^+$ | $\sum(X_i - \bar{X})^2$ |
| $S_{XY}$ | $X$ 和 $Y$ 的离差叉积和 | $\mathbb{R}$ | $\sum(X_i - \bar{X})(Y_i - \bar{Y})$ |

### 4. 常见变体与适用条件
- **适用条件**：$X'X$ 可逆（无完全多重共线性），$n > p$（样本量大于变量数）
- **限制条件**：对异常值非常敏感（因为平方放大了大误差的影响）；要求误差与自变量不相关（否则有偏）
- **变体**：加权最小二乘（WLS，异方差时使用）、广义最小二乘（GLS，误差相关时使用）

## 6. 推导思路和思想来源

- **最初困难**：如何"客观地"找到一条"最佳"直线？"最佳"的标准是什么？
- **直接方法局限**：视觉画线不客观；只连接两个端点浪费信息；最小化绝对误差（LAD）不可导，计算复杂。
- **关键"转念"**：高斯的洞察——"最小化误差平方和"有以下优点：
  1. 数学上可微，有闭式解
  2. 大误差的惩罚更大（符合直觉：大偏差更不可接受）
  3. 在正态误差假设下，等价于极大似然估计
  4. 几何上对应正交投影，有优美的线性代数解释
- **推导主线与动机**：
  1. **一元情形**：令 $RSS(\beta_0, \beta_1) = \sum (Y_i - \beta_0 - \beta_1 X_i)^2$
  2. 对 $\beta_0$ 求偏导：$\frac{\partial RSS}{\partial \beta_0} = -2\sum (Y_i - \beta_0 - \beta_1 X_i) = 0$
  3. 对 $\beta_1$ 求偏导：$\frac{\partial RSS}{\partial \beta_1} = -2\sum X_i(Y_i - \beta_0 - \beta_1 X_i) = 0$
  4. 解方程组得 $\hat{\beta}_1 = \frac{S_{XY}}{S_{XX}}$，$\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$
  5. **矩阵情形**：$RSS(\beta) = (Y-X\beta)'(Y-X\beta) = Y'Y - 2\beta'X'Y + \beta'X'X\beta$
  6. 对 $\beta$ 求导：$\frac{\partial RSS}{\partial \beta} = -2X'Y + 2X'X\beta = 0$
  7. 得正规方程：$X'X\beta = X'Y$，解出 $\hat{\beta} = (X'X)^{-1}X'Y$
- **为什么自然得到此结论**：这是线性代数中"最佳逼近"问题的标准解——在 $X$ 的列空间中寻找 $Y$ 的投影，投影向量与 $Y$ 的差（残差）垂直于 $X$ 的列空间。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：4 个数据点，求一元线性回归的 OLS 估计。
  | $X$ | 1 | 2 | 3 | 4 |
  |:---:|:---:|:---:|:---:|:---:|
  | $Y$ | 2 | 3 | 5 | 6 |
- **解题思路与关键步骤**：
  1. $\bar{X} = \frac{1+2+3+4}{4} = 2.5$, $\bar{Y} = \frac{2+3+5+6}{4} = 4$
  2. $S_{XX} = (1-2.5)^2 + (2-2.5)^2 + (3-2.5)^2 + (4-2.5)^2 = 2.25 + 0.25 + 0.25 + 2.25 = 5$
  3. $S_{XY} = (1-2.5)(2-4) + (2-2.5)(3-4) + (3-2.5)(5-4) + (4-2.5)(6-4) = (-1.5)(-2) + (-0.5)(-1) + (0.5)(1) + (1.5)(2) = 3 + 0.5 + 0.5 + 3 = 7$
  4. $\hat{\beta}_1 = \frac{7}{5} = 1.4$
  5. $\hat{\beta}_0 = 4 - 1.4 \times 2.5 = 4 - 3.5 = 0.5$
  6. 回归方程：$\hat{Y} = 0.5 + 1.4X$
  7. 拟合值：$\hat{Y}_1 = 0.5 + 1.4 \times 1 = 1.9$, $\hat{Y}_2 = 0.5 + 1.4 \times 2 = 3.3$, $\hat{Y}_3 = 0.5 + 1.4 \times 3 = 4.7$, $\hat{Y}_4 = 0.5 + 1.4 \times 4 = 6.1$
  8. 残差：$e_1 = 2 - 1.9 = 0.1$, $e_2 = 3 - 3.3 = -0.3$, $e_3 = 5 - 4.7 = 0.3$, $e_4 = 6 - 6.1 = -0.1$
  9. $RSS = 0.1^2 + (-0.3)^2 + 0.3^2 + (-0.1)^2 = 0.01 + 0.09 + 0.09 + 0.01 = 0.2$
- **最终答案**：$\hat{Y} = 0.5 + 1.4X$，$RSS = 0.2$
- **易错点**：计算 $S_{XY}$ 时注意符号；残差之和应为 0（$0.1 - 0.3 + 0.3 - 0.1 = 0$）——这是正规方程的性质，可用来验证计算。
- **🤔 追问**：如果用 $X=5$ 做预测，结果是 $\hat{Y}=0.5+1.4\times5=7.5$。这个预测的可靠性如何？→ 需要预测区间，依赖于残差方差 $\hat{\sigma}^2 = RSS/(n-2) = 0.2/2 = 0.1$。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：
  某数据集有 $n=50$，$p=3$，已知 $X'X$ 矩阵，判断是否能用 OLS 求解。
  - 如果 $X'X$ 是 $4\times4$ 矩阵且满秩（秩 = 4），则 $(X'X)^{-1}$ 存在，可以用 OLS 求解。
  - 如果 $X'X$ 的秩 < 4，说明存在完全多重共线性，需要先处理变量（删除冗余变量或使用正则化）。
  - 如果 $n < p+1$（如 $n=3, p=3$），即使 $X'X$ 可逆，估计量也会极不稳定，不建议使用 OLS。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：
  ```python
  import numpy as np
  from sklearn.linear_model import LinearRegression

  # 数据：学习时长 (X) 与考试成绩 (Y)
  X = np.array([1, 2, 3, 4])
  Y = np.array([2, 3, 5, 6])

  # 手算 OLS（公式验证）
  X_mean, Y_mean = np.mean(X), np.mean(Y)
  beta_1 = np.sum((X - X_mean) * (Y - Y_mean)) / np.sum((X - X_mean)**2)
  beta_0 = Y_mean - beta_1 * X_mean
  print(f"手算 OLS: beta_0={beta_0:.4f}, beta_1={beta_1:.4f}")
  # 输出: 手算 OLS: beta_0=0.5000, beta_1=1.4000

  # sklearn 验证
  model = LinearRegression()
  model.fit(X.reshape(-1, 1), Y)
  print(f"sklearn: intercept={model.intercept_:.4f}, coef={model.coef_[0]:.4f}")
  # 输出: sklearn: intercept=0.5000, coef=1.4000

  # 计算 RSS
  Y_pred = model.predict(X.reshape(-1, 1))
  RSS = np.sum((Y - Y_pred)**2)
  print(f"RSS = {RSS:.4f}")
  # 输出: RSS = 0.2000

  # 预测 X=5
  pred = model.predict(np.array([[5]]))
  print(f"预测 (X=5): {pred[0]:.4f}")
  # 输出: 预测 (X=5): 7.5000
  ```

## 8. 常见误区和易混概念

### 误区 1：OLS 假设 $\varepsilon$ 必须服从正态分布
- **错误直觉**：很多人认为 OLS 的推导依赖于正态性假设。
- **为什么错**：OLS 的估计量 $\hat{\beta}=(X'X)^{-1}X'Y$ 的推导不需要任何分布假设，只要求 $E[\varepsilon|X]=0$ 和 $Var(\varepsilon)=\sigma^2I$。正态性只在推断（t 检验、F 检验、置信区间）时才需要。
- **正确理解**：OLS 估计 = 纯代数方法（最小化 RSS）；OLS 推断 = 需要分布假设（通常假设正态或大样本近似）。

### 误区 2：最小二乘 = 最小化误差绝对值
- **错误直觉**：有人以为"最小二乘"就是让所有点到线的距离之和最小（绝对距离）。
- **为什么错**：最小化绝对距离（Least Absolute Deviation, LAD）是另一种估计方法。OLS 最小化的是**平方**距离，不是绝对距离。两者区别：
  - OLS 对异常值更敏感（平方放大影响）
  - LAD 对异常值更稳健
  - OLS 有闭式解，LAD 需要迭代求解
- **正确理解**：最小二乘中的"二"（square）就是指平方，不是绝对值的"二"。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **OLS（最小二乘）** | 最小化残差平方和 | 有闭式解，对异常值敏感 | 数据干净、误差正态时首选 |
| **LAD（最小绝对偏差）** | 最小化残差绝对值之和 | 无闭式解，对异常值稳健 | 数据有离群点、厚尾误差时 |
| **MLE（极大似然估计）** | 最大化观测数据的似然函数 | 需要分布假设，在正态误差下等价于 OLS | 广义线性模型、非正态误差 |

### 题目与解析

#### 1. OLS 最小化的目标函数是什么？
> [!question]- 答案解析
> - **答案**：残差平方和 $RSS = \sum_{i=1}^n (Y_i - \hat{Y}_i)^2 = \sum_{i=1}^n e_i^2$
> - **解析**：OLS 的目标是使拟合值与观测值的差的平方和最小。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 已知 $S_{XX}=20$，$S_{XY}=12$，$\bar{X}=5$，$\bar{Y}=10$，求 $\hat{\beta}_1$ 和 $\hat{\beta}_0$。
> [!question]- 答案解析
> - **答案**：$\hat{\beta}_1 = 12/20 = 0.6$，$\hat{\beta}_0 = 10 - 0.6 \times 5 = 7$
> - **解析**：直接代入 OLS 公式。

#### 3. 什么条件下 $(X'X)^{-1}$ 不存在？
> [!question]- 答案解析
> - **答案**：当 $X$ 的列存在完全线性相关（完全多重共线性）或 $n < p+1$ 时。
> - **解析**：此时 $X$ 不是满秩矩阵，$X'X$ 是奇异矩阵，不可逆。OLS 无唯一解。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 如果数据存在一个异常值（极端大的 $Y$ 值），OLS 和 LAD 谁会受影响更大？为什么？
> [!question]- 答案解析
> - **答案**：OLS 受影响更大。因为 OLS 最小化平方和，大误差被平方放大，异常值会"拉偏"回归线。LAD 最小化绝对值，大误差不被平方，对异常值更稳健。
> - **解析**：这是 OLS 的一个已知弱点——对异常值敏感。实际应用中应在拟合前做异常值检测。

#### 5. 推导一元线性回归的 OLS 正规方程，并证明 $\sum e_i = 0$。
> [!question]- 答案解析
> - **答案**：
>   - 正规方程 1：$\frac{\partial RSS}{\partial \beta_0} = -2\sum(Y_i - \beta_0 - \beta_1 X_i) = 0$ → $\sum e_i = 0$
>   - 正规方程 2：$\frac{\partial RSS}{\partial \beta_1} = -2\sum X_i(Y_i - \beta_0 - \beta_1 X_i) = 0$ → $\sum X_i e_i = 0$
>   - 由正规方程 1 直接可得 $\sum e_i = 0$（残差之和为零）。
> - **解析**：这是 OLS 的优良性质之一——残差之和为零意味着拟合值 $\hat{Y}$ 的均值等于观测值 $Y$ 的均值。
> - **Obsidian 标签建议**：`#自测题/较难`
