## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：偏最小二乘（PLS）是 PCR 的"有监督"升级版，在化学计量学、基因组学、金融预测中广泛应用。它与 PCR 的对比是理解"无监督 vs 有监督降维"的关键。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> [[主成分回归]] 有一个致命的弱点——PCA 在降维时完全不管 $Y$。它只关心 $X$ 的方差大小，但最大的方差方向可能与 $Y$ 毫无关系。想象一个场景：$X$ 中有两个潜在因子，一个解释了 $X$ 中 90% 的方差但与 $Y$ 无关，另一个只解释了 10% 的方差但完美预测 $Y$。PCR 会保留第一个、丢弃第二个——**方向完全错了**。**问题：如何让降维过程"知道" $Y$ 的存在，找到那些既解释 $X$ 又解释 $Y$ 的方向？**

> **为什么必须引入新工具**：我们需要一种方法，在降维时**同时考虑 $X$ 和 $Y$**，找到的"成分"既要能代表 $X$，又要能预测 $Y$。这就是偏最小二乘（PLS）——它在 $X$ 和 $Y$ 之间寻找"最大协方差"的方向。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：PLS 是"有监督降维"的代表方法，与 PCR（无监督降维）形成直接对比。它也是理解 CCA（典型相关分析）和"潜变量模型"的桥梁。
- **实际应用场景**：化学计量学（近红外光谱预测成分含量）、基因组学（基因表达预测疾病状态）、金融（多个经济指标预测市场走势）、过程控制（多变量统计过程控制）。
- **高频题型/任务**：PLS 与 PCR 的对比（无监督 vs 有监督）、PLS 成分个数的选择（交叉验证）、载荷与权重的解释。

---

## 3. 学它之前需要哪些前置知识？

1. **[[主成分回归]]**：理解 PCR 的两阶段框架（PCA + OLS），以及为什么"无监督降维"可能遗漏与 $Y$ 相关的方向。PLS 是对 PCR 的改进。
2. **[[多元线性回归模型]]**：理解 OLS 估计和 $p > n$ 时的问题。
3. **[[多重共线性]]**：理解变量间相关是 PCR 和 PLS 要解决的共同问题。

---

## 4. 用直觉语言解释它

> «"偏最小二乘"就像**找对象既要看颜值又要看性格**——PCR 只看颜值（$X$ 的方差），PLS 则寻找颜值和性格都好的方向（$X$ 和 $Y$ 的协方差）。»

- **直觉类比**：假设你要从一群人中选出"最佳代表"（成分）。PCR 只看谁最突出（方差最大），但 PLS 会问"谁最能代表大家（$X$）同时又最能预测考试成绩（$Y$）？"——它找的是"既典型又有解释力"的人。
- **为什么很自然**：如果目标是预测 $Y$，那么降维时忽略 $Y$ 是愚蠢的。PLS 让 $Y$ 指导降维方向，确保保留的成分对预测有用。
- **一句话直觉本质**：**在降维时同时考虑 $X$ 和 $Y$ 的信息，找到最大化 $X$ 与 $Y$ 协方差的方向。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

偏最小二乘（PLS）是一种有监督降维方法，它寻找 $X$ 的线性组合（称为 PLS 成分）使其与 $Y$ 的协方差最大化，然后用这些成分做线性回归。与 PCR 不同，PLS 在构造成分时利用了 $Y$ 的信息。

### 2. 核心公式

**第一个 PLS 成分的权重向量（最大化协方差）：**
$$\hat{\phi}_1 = \arg\max_{\phi} \left[ \text{Cov}(X\phi, Y) \right]^2, \quad \text{s.t. } \|\phi\| = 1$$

**等价地：**
$$\hat{\phi}_1 = \frac{X^T Y}{\|X^T Y\|}$$

**第一个 PLS 成分：** $Z_1 = X \hat{\phi}_1$

**残差化（deflation）：**
对 $X$ 做回归 $Z_1$，取残差：
$$X^{(1)} = X - \frac{Z_1 Z_1^T}{Z_1^T Z_1} X$$

类似地，对 $Y$ 做回归 $Z_1$，取残差：
$$Y^{(1)} = Y - \frac{Z_1 Z_1^T}{Z_1^T Z_1} Y$$

然后在残差 $X^{(1)}$ 和 $Y^{(1)}$ 上重复上述过程，得到后续 PLS 成分。

**最终模型（用 $M$ 个 PLS 成分）：**
$$\hat{Y}_{PLS}^{(M)} = \bar{Y} + \sum_{m=1}^M \hat{\theta}_m Z_m$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $\phi_m$ | 第 $m$ 个 PLS 权重向量 | $\mathbb{R}^p$ | 最大化 $X$ 与 $Y$ 的协方差 |
| $Z_m$ | 第 $m$ 个 PLS 成分 | $\mathbb{R}^n$ | $Z_m = X^{(m-1)} \phi_m$ |
| $\hat{\theta}_m$ | PLS 回归系数 | $\mathbb{R}$ | 在第 $m$ 个成分上的系数 |
| $M$ | PLS 成分数 | $1 \leq M \leq p$ | 超参数，通过 CV 选择 |

### 4. 常见变体与适用条件

- **适用条件**：预测变量高度相关或 $p > n$；$Y$ 与 $X$ 的方差结构不同时（即 $Y$ 主要由 $X$ 的小方差方向决定）；单变量 $Y$（PLS1）或多变量 $Y$（PLS2）。
- **限制条件**：PLS 虽比 PCR 更"聪明"，但更容易过拟合（因为用了 $Y$ 的信息指导降维），需要严格的交叉验证选择成分数。PLS 系数的可解释性仍然较弱。
- **标准化**：与 PCR 类似，$X$ 和 $Y$ 通常需要标准化。

## 6. 推导思路和思想来源

- **最初困难**：PCR 的 PCA 步骤忽略了 $Y$，可能保留与 $Y$ 无关的成分，丢弃与 $Y$ 相关的成分。
- **直接方法局限**：如果先做 OLS 再降维（如使用逐步回归），会陷入多重共线性问题。
- **关键"转念"**：在构造每个成分时，不仅看 $X$ 的方差，还要看 $X$ 与 $Y$ 的协方差。具体来说，每个 PLS 成分的权重与 $X$ 和 $Y$ 的相关系数成正比——$X$ 中与 $Y$ 相关的变量在成分中权重更大。
- **推导主线与动机**：
  1. 初始化：$X^{(0)} = X$（已中心化），$Y^{(0)} = Y$
  2. 对 $m = 1, 2, \ldots, M$：
     a. 计算权重：$\phi_m = X^{(m-1)T} Y^{(m-1)} / \|X^{(m-1)T} Y^{(m-1)}\|$
     b. 计算成分：$Z_m = X^{(m-1)} \phi_m$
     c. 计算载荷：$p_m = X^{(m-1)T} Z_m / (Z_m^T Z_m)$
     d. 计算系数：$c_m = Y^{(m-1)T} Z_m / (Z_m^T Z_m)$
     e. 残差化：$X^{(m)} = X^{(m-1)} - Z_m p_m^T$，$Y^{(m)} = Y^{(m-1)} - c_m Z_m$
  3. 最终预测：$\hat{Y} = \sum_{m=1}^M c_m Z_m$
- **为什么自然得到此结论**：协方差同时衡量了 $X$ 的方差和 $X$ 与 $Y$ 的相关性。最大化 $\text{Cov}(X\phi, Y)$ 等价于找到与 $Y$ 最相关且方差也大的方向——这是直觉上最合理的折中。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：$X = \begin{bmatrix}1 & 2\\ 2 & 1\\ 3 & 4\\ 4 & 3\end{bmatrix}$（已中心化），$Y = \begin{bmatrix}1\\ 2\\ 3\\ 4\end{bmatrix}$（已中心化）。计算第一个 PLS 成分。
- **解题思路与关键步骤**：
  1. $X^T = \begin{bmatrix}1 & 2 & 3 & 4\\ 2 & 1 & 4 & 3\end{bmatrix}$
  2. $X^T Y = \begin{bmatrix}1\times1 + 2\times2 + 3\times3 + 4\times4\\ 2\times1 + 1\times2 + 4\times3 + 3\times4\end{bmatrix} = \begin{bmatrix}30\\ 28\end{bmatrix}$
  3. $\phi_1 = \frac{X^T Y}{\|X^T Y\|} = \frac{[30, 28]^T}{\sqrt{30^2 + 28^2}} = \frac{[30, 28]^T}{\sqrt{1684}} \approx [0.73, 0.68]^T$
  4. $Z_1 = X \phi_1 = 0.73 \times [1,2,3,4]^T + 0.68 \times [2,1,4,3]^T \approx [2.09, 2.14, 4.91, 4.96]^T$
- **最终答案**：第一个 PLS 成分 $Z_1 \approx [2.09, 2.14, 4.91, 4.96]^T$，权重 $\phi_1 \approx [0.73, 0.68]^T$。
- **易错点**：PLS 权重 $\phi_1$ 不是特征向量，而是 $X^T Y$ 的方向——与 PCR 的载荷向量 $v_1$ 不同。
- **🤔 追问**：如果 $X$ 的两个变量都与 $Y$ 无关，PLS 会怎样？（权重近似随机方向，不如 PCR）

### 例子 2：中等例子（条件判断与多步推理）

- **题目与完整解答**：某化学家使用近红外光谱预测蛋白质含量。$X$ 有 100 个波长，$p=100$，$n=50$。她分别用 PCR 和 PLS 做 5 折交叉验证，结果如下：
  - PCR 最优 $M=5$：CV RMSE = 2.1
  - PLS 最优 $M=3$：CV RMSE = 1.4
- **解释**：PLS 用更少的成分取得了更好的预测效果。说明蛋白质含量主要与 $X$ 中与 $Y$ 协方差大的方向相关，而非与 $X$ 方差最大的方向相关。PLS 的"有监督"特性在这里发挥了优势。

### 例子 3：实际应用例子（Python 代码）

```python
import numpy as np
import pandas as pd
from sklearn.cross_decomposition import PLSRegression
from sklearn.model_selection import cross_val_score, KFold
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LinearRegression
import warnings
warnings.filterwarnings('ignore')

# 模拟数据：Y 与 X 的小方差方向相关
np.random.seed(42)
n, p = 50, 30
# X 中大方差方向（与 Y 无关）
X_large = np.random.randn(n, 3) * 5
# X 中小方差方向（与 Y 相关）
X_small = np.random.randn(n, 2) * 0.5
y = 2 * X_small[:, 0] + 1.5 * X_small[:, 1] + np.random.randn(n) * 0.5
# 合并 X
X = np.hstack([X_large, X_small, np.random.randn(n, p-5) * 0.3])

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# ---- PLS 回归 ----
kf = KFold(5, shuffle=True, random_state=42)

for M in range(1, 8):
    pls = PLSRegression(n_components=M)
    scores = cross_val_score(pls, X_scaled, y, cv=kf, scoring='neg_mean_squared_error')
    print(f"PLS M={M}: CV MSE = {-scores.mean():.4f}")
# 小 M 时 MSE 就很低，因为 PLS 能快速找到与 Y 相关的方向

# 拟合最优模型
M_opt = 2
pls = PLSRegression(n_components=M_opt)
pls.fit(X_scaled, y)
print("PLS R²:", pls.score(X_scaled, y))  # 约 0.65-0.80

# ---- 对比 PCR ----
pca = PCA()
X_pca = pca.fit_transform(X_scaled)
for M in range(1, 8):
    scores = cross_val_score(LinearRegression(), X_pca[:, :M], y,
                             cv=kf, scoring='neg_mean_squared_error')
    print(f"PCR M={M}: CV MSE = {-scores.mean():.4f}")
# PCR 需要更多的成分才能达到 PLS 的预测效果
```

## 8. 常见误区和易混概念

### 误区 1：PLS 总是优于 PCR
- **错误直觉**：因为 PLS 是有监督的，所以它一定比 PCR 好。
- **为什么错**：当 $Y$ 与 $X$ 的方差结构一致时（即 $Y$ 主要由 $X$ 的大方差方向决定），PCR 和 PLS 表现相近。但 PLS 因为使用了 $Y$ 的信息，更容易过拟合。
- **正确理解**：PLS 在 $Y$ 与 $X$ 的小方差方向相关时优于 PCR，但两者的比较应基于交叉验证，不能先验地认为一个更好。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **主成分回归 PCR** | 降维+回归 | 无监督（只看 $X$ 方差） | $X$ 方差结构与 $Y$ 一致 |
| **偏最小二乘 PLS** | 降维+回归 | 有监督（看 $X$ 与 $Y$ 协方差） | $Y$ 与 $X$ 小方差方向相关 |
| **岭回归** | 共线性 | 不降维，收缩系数 | 希望保留所有变量 |
| **典型相关分析 CCA** | 两组变量相关 | 找 $X$ 和 $Y$ 的最大相关方向 | 两组变量间的关联分析 |

### 题目与解析

#### 1. PLS 的第一个成分权重 $\phi_1$ 与 PCR 的第一个载荷 $v_1$ 有何不同？
> [!question]- 答案解析
> - **答案**：$\phi_1$ 是 $X^T Y$ 的方向（最大化 $X$ 与 $Y$ 的协方差），$v_1$ 是 $X^T X$ 的特征向量（最大化 $X$ 的方差）。
> - **解析**：$\phi_1$ 利用了 $Y$ 的信息，$v_1$ 没有。当 $Y$ 与 $X$ 的小方差方向相关时，两者差异显著。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. PLS 中"残差化"（deflation）步骤的目的是什么？
> [!question]- 答案解析
> - **答案**：确保后续成分与已提取的成分正交，避免信息重复，类似 PCA 中的正交性要求。
> - **解析**：从 $X$ 和 $Y$ 中减去当前成分的贡献后，后续成分只能从"剩余"信息中提取，保证了成分之间的正交性。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 什么时候 PLS 的预测性能会显著优于 PCR？
> [!question]- 答案解析
> - **答案**：当 $Y$ 主要由 $X$ 中方差较小但与 $Y$ 高度相关的方向决定时。
> - **解析**：PCR 按方差排序，会丢弃小方差方向。PLS 通过协方差准则，能捕捉到这些方向。这也是 PLS 在光谱分析中广泛应用的原因。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. PLS 的过拟合风险为什么比 PCR 高？
> [!question]- 答案解析
> - **答案**：PLS 在构造每个成分时使用了 $Y$ 的信息，容易在训练数据上"钻空子"——找到与 $Y$ 噪声相关的成分。
> - **解析**：PCR 的 PCA 步骤完全独立于 $Y$，不会过拟合到 $Y$ 的噪声。PLS 的"有监督"特性既是优势也是风险，必须通过交叉验证谨慎选择成分数。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 你有一个 $p=500, n=100$ 的代谢组学数据集，目标是预测疾病风险评分（连续变量）。请设计一个比较 PCR 和 PLS 的建模方案。
> > [!question]- 答案解析
> > - **答案**：(1) 标准化 $X$；(2) 设置 5 折或 10 折交叉验证；(3) 对 $M=1$ 到 $M=20$（或更少），分别拟合 PCR 和 PLS；(4) 记录每个 $M$ 的 CV MSE，选择最优 $M$；(5) 比较两者的最优 CV MSE——如果 PLS 显著优于 PCR，说明 $Y$ 与 $X$ 的小方差方向相关；(6) 在独立测试集上验证最终模型。
> > - **Obsidian 标签建议**：`#自测题/较难`
