# 顺序数据的回归模型

> 所属模块：[[🗺️ 应用回归分析学习路径|应用回归分析]]
> 主教材：[[应用回归分析-第5版|应用回归分析（第5版）]]
> 对应阶段：[[🧩 第三阶段：广义与层次扩展|返回阶段页]]

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：顺序数据（如满意度评分、病情严重程度）在社会科学、医学、市场调研中无处不在。把顺序因变量当作连续变量处理会引入假设错误，当作无序多分类又会丢失序数信息。累积 Logit 模型是处理这类数据的标准工具，也是广义线性模型（GLM）的自然延伸，值得深挖。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 假设你想研究"什么因素影响顾客对服务的满意度评分"（1=非常不满意，2=不满意，3=一般，4=满意，5=非常满意）。这是一个**顺序因变量（ordinal outcome）**——类别之间有明确的高低次序，但类别之间的"距离"不一定相等。
>
> 如果直接用普通线性回归（把 1-5 当成连续数值），等于强迫"从 1 到 2 的差距"等于"从 4 到 5 的差距"，这通常不合理。如果使用无序多分类 Logistic 回归，又会忽略掉"高满意度 vs 低满意度"这个顺序信息，造成统计效率损失。
>
> **顺序数据的回归模型**（Ordinal Regression）就是为了填补这个空白：它利用类别的顺序结构，在建模范式和统计效率之间取得平衡。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：在 GLM 框架中，普通回归处理连续因变量，Logistic 回归处理二分类，多类别 Logistic 回归处理无序多分类，而**累积 Logit 模型**处理顺序多分类。四者共同构成广义线性模型在截面数据上的完整应用版图。
- **实际应用场景**：
  - 市场调研：满意度评分、品牌偏好排序
  - 医学：病情严重程度（轻/中/重）、疗效评价（无效/好转/痊愈）
  - 教育：考试成绩等级（A/B/C/D/F）
  - 社会科学：收入水平分层、教育程度、政治立场偏向
- **高频题型/任务**：模型选择（比例优势假设检验）、系数解释（累积优势比）、预测概率计算。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[Logistic回归模型]]**：Logistic 回归用 logit 链接函数将线性预测值映射到概率，核心是 $\log\frac{p}{1-p} = \mathbf{x}^T\boldsymbol{\beta}$。理解 odds 和 odds ratio 的解读方式是理解累积 Logit 的基础。
2. **[[多类别Logistic回归]]**：当因变量有多个无序类别时，用 softmax 函数同时建模每个类别相对于基准类别的 log-odds。顺序回归正是它的"有序版本"——区别在于顺序回归利用累积概率而非单个类别概率。

---

## 4. 用直觉语言解释它

> «"累积 Logit 模型就像在顺序台阶上逐层画分界线——每一条分界线告诉你'到目前为止 vs 往后'的概率比。"»

- **直觉类比/几何图像**：想象一个连续潜变量 $y^*$（比如"真实满意度"）在数轴上滑动。当它低于某个阈值 $\tau_1$ 时，你看到 $y=1$（非常不满意）；在 $\tau_1$ 和 $\tau_2$ 之间时看到 $y=2$；依此类推。顺序回归模型做的就是：**估计这些阈值的位置，同时估计自变量如何让这个潜变量在数轴上左右移动**。阈值是"边界"，自变量的系数是"推动力"。
- **为什么很自然**：这个"潜变量 + 阈值"的框架非常直观——它承认观测到的有序类别只是背后连续变量的粗糙测量。回到顾客满意度，每个人心里确实有一个"连续满意度分"，只是问卷只给了 5 个选项。
- **一句话直觉本质**：顺序回归 = 在连续潜变量上设置阈值，用累积概率来建模自变量的影响。

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

**累积 Logit 模型**（Cumulative Logit Model），也称比例优势模型（Proportional Odds Model），同时对因变量 $Y$ 的所有 $J$ 个类别的累积概率建模：

$$\log\left(\frac{P(Y \leq j \mid \mathbf{x})}{P(Y > j \mid \mathbf{x})}\right) = \tau_j - \mathbf{x}^T\boldsymbol{\beta}, \quad j = 1, 2, \dots, J-1$$

或者等价地写为：

$$\text{logit}(P(Y \leq j \mid \mathbf{x})) = \tau_j - \mathbf{x}^T\boldsymbol{\beta}$$

其中 $\tau_1 < \tau_2 < \dots < \tau_{J-1}$ 是阈值（截距项）。

### 2. 核心公式

累积概率本身为：

$$P(Y \leq j \mid \mathbf{x}) = \frac{\exp(\tau_j - \mathbf{x}^T\boldsymbol{\beta})}{1 + \exp(\tau_j - \mathbf{x}^T\boldsymbol{\beta})}$$

单个类别的概率为：

$$P(Y = j \mid \mathbf{x}) = P(Y \leq j \mid \mathbf{x}) - P(Y \leq j-1 \mid \mathbf{x})$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $Y$ | 顺序因变量 | $\{1, 2, \dots, J\}$ | 有序类别 |
| $J$ | 类别总数 | 正整数 | $\geq 2$ |
| $\mathbf{x}$ | 自变量向量 | $\mathbb{R}^p$ | 特征 |
| $\boldsymbol{\beta}$ | 回归系数 | $\mathbb{R}^p$ | 所有 $j$ 共享（比例优势假设） |
| $\tau_j$ | 第 $j$ 个阈值 | $\mathbb{R}$，$\tau_1 < \tau_2 < \dots < \tau_{J-1}$ | 截距项 |
| $P(Y \leq j \mid \mathbf{x})$ | 累积概率 | $[0, 1]$ | 比 $j$ 差或等于 $j$ 的概率 |

### 4. 常见变体与适用条件

- **适用条件**：
  - 因变量为有序分类（如 Likert 量表、病情分级）
  - 比例优势假设成立（下面细说）
  - 样本量足够：通常每个类别至少 10-20 个样本，总样本量建议 $> 10p$（$p$ 为自变量数）
- **限制条件**：
  - 比例优势假设不成立时，可改用**非比例优势模型**（partial proportional odds model）或广义有序 Logit 模型
  - 对极端类别概率的预测可能不稳定

## 6. 推导思路和思想来源

- **最初困难**：顺序因变量既不是连续的，也不是无序的——没有现成的回归框架能自然地处理它。
- **直接方法局限**：用 OLS 回归会假设等距（把 1→2 和 4→5 的"跳跃"等同），用无序多分类 Logit 会丢失顺序信息。
- **关键"转念"**：不再直接建模"属于某个类别"的概率，而是建模"属于类别 $j$ 或更低"的**累积概率**。这样既保留了顺序，又用 Logit 函数保证概率在 0-1 之间。
- **推导主线与动机**：
  1. 假设存在连续潜变量 $y^* = \mathbf{x}^T\boldsymbol{\beta} + \varepsilon$，其中 $\varepsilon$ 服从 Logistic 分布
  2. 观测到的 $Y = j$ 当且仅当 $\tau_{j-1} < y^* \leq \tau_j$（$\tau_0 = -\infty, \tau_J = \infty$）
  3. 由 Logistic 分布 CDF 直接得到 $P(Y \leq j \mid \mathbf{x}) = \Lambda(\tau_j - \mathbf{x}^T\boldsymbol{\beta})$
  4. 对累积概率取 logit 即得核心公式
- **为什么自然得到此结论**：Logistic 分布假设使得累积概率有了封闭形式，$\tau_j$ 和 $\boldsymbol{\beta}$ 可同时通过最大似然估计求解。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：假设只有 3 个满意度等级（1=差，2=中，3=好），只用一个自变量 $x$（服务质量评分，标准化）。估计得到 $\tau_1 = -1$，$\tau_2 = 1$，$\beta = 2$。对于 $x = 0$ 的顾客，请计算 $P(Y=1)$、$P(Y=2)$、$P(Y=3)$。
- **解题思路与关键步骤**：
  1. 计算累积概率：
     - $P(Y \leq 1) = \frac{\exp(-1 - 0)}{1 + \exp(-1 - 0)} = \frac{e^{-1}}{1+e^{-1}} \approx 0.269$
     - $P(Y \leq 2) = \frac{\exp(1 - 0)}{1 + \exp(1 - 0)} = \frac{e}{1+e} \approx 0.731$
  2. 计算单个类别概率：
     - $P(Y=1) = P(Y \leq 1) = 0.269$
     - $P(Y=2) = P(Y \leq 2) - P(Y \leq 1) = 0.731 - 0.269 = 0.462$
     - $P(Y=3) = 1 - P(Y \leq 2) = 0.269$
- **最终答案**：$P(Y=1) \approx 0.269$，$P(Y=2) \approx 0.462$，$P(Y=3) \approx 0.269$
- **易错点**：混淆 $\tau_j - \mathbf{x}^T\boldsymbol{\beta}$ 和 $\mathbf{x}^T\boldsymbol{\beta} + \tau_j$ 的符号约定（不同教材写法不同，需注意符号含义）。
- **🤔 追问**：如果 $x$ 从 0 增加到 1，$P(Y=3)$ 会如何变化？——因为 $\beta > 0$，潜变量均值增加，$P(Y=3)$ 增大，$P(Y=1)$ 减小。

### 例子 2：中等例子（条件判断与多步推理）

- **题目与完整解答**：某研究用顺序回归分析教育水平（1=高中及以下，2=本科，3=研究生及以上）与收入的关系，得 $\beta = 0.8$（$p<0.001$）。问：
  (a) 比例优势假设意味着什么？
  (b) 对于收入增加一个单位，$P(Y \leq 1)$ 的 odds 如何变化？
  (c) 如果比例优势假设不成立，你会怎么做？

  解答：
  (a) 比例优势假设意味着收入对"高中及以下 vs 本科及以上"的 log-odds 影响，与对"研究生及以上 vs 以下"的 log-odds 影响相同——即 $\beta$ 对所有累积 logit 都一样。
  (b) 收入增加一个单位，$\text{logit}(P(Y \leq 1))$ 减少 0.8，所以 $P(Y \leq 1)$ 的 odds 乘以 $\exp(-0.8) \approx 0.449$——即"属于低教育水平"的 odds 变为原来的约 45%。
  (c) 改用偏比例优势模型（允许某些变量的系数随 $j$ 变化）或广义有序 Logit 模型。

### 例子 3：实际应用例子（真实场景/代码）

- **实际价值与转化**：在医学研究中，顺序回归可用于药物剂量-疗效分析（疗效等级：无效/部分有效/完全有效），在市场营销中可用于 NPS（净推荐值）评分建模。下面是一个 Python 示例。

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.miscmodels.ordinal_model import OrderedModel

# 生成模拟数据：满意度评分（1-5），Y 与两个特征有关
np.random.seed(42)
n = 500
X = np.random.randn(n, 2)
# 潜变量：y* = 0.5*X1 - 0.3*X2 + epsilon, epsilon ~ Logistic(0,1)
eta = 0.5 * X[:, 0] - 0.3 * X[:, 1]
epsilon = np.random.logistic(0, 1, n)
y_star = eta + epsilon
# 通过阈值将潜变量离散化为 5 个等级
thresholds = [-1.5, -0.5, 0.5, 1.5]
y = np.zeros(n, dtype=int)
for i in range(n):
    if y_star[i] <= thresholds[0]:
        y[i] = 1
    elif y_star[i] <= thresholds[1]:
        y[i] = 2
    elif y_star[i] <= thresholds[2]:
        y[i] = 3
    elif y_star[i] <= thresholds[3]:
        y[i] = 4
    else:
        y[i] = 5

# 拟合累积 Logit 模型
X_df = pd.DataFrame(X, columns=['X1', 'X2'])
model = OrderedModel(y, X_df, distr='logit')
result = model.fit(method='bfgs')
print(result.summary())

# 预测：某样本 (X1=0.5, X2=-0.2) 的类别概率
new_x = pd.DataFrame([[0.5, -0.2]], columns=['X1', 'X2'])
pred_probs = result.predict(new_x)
print("预测概率 (Y=1~5):", pred_probs.values[0])
# 输出示例：预测概率 (Y=1~5): [0.021, 0.123, 0.341, 0.378, 0.137]
# 含义：最可能类别为 4（满意），概率约 38%
```

## 8. 常见误区和易混概念

### 误区 1：把顺序数据当连续变量做 OLS 回归

- **错误直觉**："反正数值是 1,2,3,4,5，直接回归就行。"
- **为什么错**：OLS 假设等距——"从 1 到 2 的差距"和"从 4 到 5 的差距"被强制相等，这在满意度调查中通常不成立（"非常不满意→不满意"的差距可能远小于"满意→非常满意"）。
- **正确理解**：顺序数据只告诉你有高低次序，不告诉你有多少"距离"。应当使用专门为顺序数据设计的模型。

### 误区 2：认为比例优势假设总是成立的

- **错误直觉**：拟合软件默认输出比例优势模型，所以它就是对的。
- **为什么错**：比例优势假设（所有自变量对每个累积 logit 有相同系数）是一个很强的假设，需要检验。常见检验方法有 Brant 检验和似然比检验。
- **正确理解**：拟合后应检验比例优势假设。若假设被拒绝，考虑偏比例优势模型或广义有序 Logit。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 顺序回归（累积 Logit） | 因变量有顺序多分类 | 利用累积概率，保留顺序信息 | 满意度评分、病情分级 |
| 多类别 Logistic 回归 | 因变量为无序多分类 | 基准类别的 log-odds，忽略顺序 | 品牌选择、职业分类 |
| 普通线性回归 | 因变量连续 | 假设等距、正态误差 | 房价、温度预测 |

#### 1. 以下哪种数据最适合用累积 Logit 模型？
> [!question]- 答案解析
> - **答案**：B. 满意度评分（1-5 星）
> - **解析**：A（性别男/女）是二分类用 Logistic 回归，C（温度）是连续用 OLS，D（职业类型）是无序多分类用多类别 Logistic 回归。B 是顺序数据，最适合累积 Logit 模型。
> - **易错原因**：容易把"多分类"和"顺序多分类"混淆。
> - **对应误区**：误区 1
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 给定 $\tau_1 = -2, \tau_2 = 0.5, \boldsymbol{\beta} = 0$，求 $P(Y=1), P(Y=2), P(Y=3)$。
> [!question]- 答案解析
> - **答案**：$P(Y=1) = \frac{e^{-2}}{1+e^{-2}} \approx 0.119$，$P(Y=2) = \frac{e^{0.5}}{1+e^{0.5}} - \frac{e^{-2}}{1+e^{-2}} \approx 0.622 - 0.119 = 0.503$，$P(Y=3) = 1 - 0.622 = 0.378$
> - **解析**：直接代入公式 $P(Y \leq j) = \frac{\exp(\tau_j)}{1+\exp(\tau_j)}$，然后相减。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 比例优势假设被拒绝后，以下哪种做法最合适？
> [!question]- 答案解析
> - **答案**：C. 改用偏比例优势模型
> - **解析**：A（继续用原模型）会得到有偏估计，B（扔掉数据）不合理，D（改用 OLS）会引入等距假设。

#### 4. 某因变量有 4 个有序类别，研究者想分析性别和年龄的影响。模型选择顺序是什么？
> [!question]- 答案解析
> - **答案**：先拟合累积 Logit 模型，检验比例优势假设；若成立则报告该模型，若不成立则尝试偏比例优势模型或广义有序 Logit 模型。
> - **解析**：标准分析流程：EDA → 基准模型 → 假设检验 → 最终模型 → 解释。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 从潜变量模型推导累积 Logit 模型的核心公式。
> [!question]- 答案解析
> - **答案**：设 $y^* = \mathbf{x}^T\boldsymbol{\beta} + \varepsilon$，$\varepsilon \sim \text{Logistic}(0,1)$，且 $Y=j$ 当 $\tau_{j-1} < y^* \leq \tau_j$。则 $P(Y \leq j \mid \mathbf{x}) = P(y^* \leq \tau_j \mid \mathbf{x}) = P(\varepsilon \leq \tau_j - \mathbf{x}^T\boldsymbol{\beta}) = \Lambda(\tau_j - \mathbf{x}^T\boldsymbol{\beta})$，其中 $\Lambda$ 是 Logistic 分布 CDF。取 logit 得 $\text{logit}(P(Y \leq j \mid \mathbf{x})) = \tau_j - \mathbf{x}^T\boldsymbol{\beta}$。
> - **解析**：关键在于理解 Logistic 分布 CDF 与 logit 函数的互逆关系。
> - **Obsidian 标签建议**：`#自测题/较难`
