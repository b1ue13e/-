## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：Logistic 回归是分类问题（二分类）最基础、最广泛的模型，也是医学、金融、营销领域的标准工具。它连接了线性回归与分类、广义线性模型 GLM 和神经网络（sigmoid 激活函数）。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 你是一位银行风控经理，想根据客户的收入和负债比预测"是否会违约"。但"违约"是一个二分类变量（违约/不违约 = 1/0）。如果用线性回归 $Y = \beta_0 + \beta_1 X$，你会遇到三个致命问题：
> 1. **概率越界**：预测值可能小于 0 或大于 1，而概率不能。
> 2. **异方差**：$Y$ 是 0/1，误差项 $\varepsilon = Y - \beta_0 - \beta_1 X$ 不可能是正态分布。
> 3. **线性假设不合理**：收入从 1 万增到 2 万对违约概率的影响，与从 100 万增到 101 万的影响，不应该相同（边际递减效应）。

> **为什么必须引入新工具**：我们需要一个模型，它的输出**天然被限制在 [0,1] 之间**，且能处理**非线性概率关系**。Logistic 回归通过一个巧妙的"链接函数"——logit 变换——解决了这个问题。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：Logistic 回归是[[多类别Logistic回归]]（softmax）和[[待创建:广义线性模型GLM]]的基础。它的 logit 链接函数是"变换思想"（见[[可化为线性回归的曲线回归]]）的综合应用。神经网络中的 sigmoid 激活函数就是 logistic 函数。
- **实际应用场景**：医学（疾病诊断 yes/no）、金融（信用违约）、营销（客户流失）、社会科学（投票意愿）。
- **高频题型/任务**：系数的对数优势比解释、模型比较（似然比检验 vs Wald 检验）、ROC 曲线与 AUC、分类阈值选择。

---

## 3. 学它之前需要哪些前置知识？

1. **[[多元线性回归模型]]**：理解线性预测器 $\eta = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$ 的概念。Logistic 回归的线性部分与此完全相同。
2. **[[含定性变量的回归模型]]**：理解哑变量编码。当 Logistic 回归的预测变量含定性变量时，同样需要哑变量编码。

---

## 4. 用直觉语言解释它

> «"Logistic 回归"就像一把**S 形的弹簧尺**——线性回归的直尺会超出 0-1 的边界，而 Logistic 回归的尺子在两端会自然"压扁"，永远卡在 0 和 1 之间。»

- **直觉类比**：想象一个跷跷板，中间平衡时概率 = 0.5。收入增加，跷跷板倾斜，但永远不可能完全竖起来——概率会无限接近 1 但不会等于 1。这就是 logistic 函数的 S 形曲线。
- **为什么很自然**：概率天然有边界 [0,1]，而线性预测器 $\beta^T X$ 无界。需要一个"桥梁"把无界映射到有界——logit 函数就是这座桥（严格来说，logit 的反函数 logistic 函数把无界映射到有界）。
- **一句话直觉本质**：**用 logit 函数把概率变换到实数轴，在线性预测器上拟合，然后用 logistic 函数把预测值变换回概率。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

Logistic 回归是用于二分类响应变量的广义线性模型。它通过 logit 链接函数将成功概率 $p = P(Y=1|X)$ 与线性预测器 $\eta = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$ 联系起来。

### 2. 核心公式

**Logit 变换（链接函数）：**
$$\text{logit}(p) = \ln\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$$

**Logistic 函数（逆变换）：**
$$p = P(Y=1|X) = \frac{e^{\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p}}{1 + e^{\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p}} = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p)}}$$

**优势比（Odds）：**
$$\text{Odds} = \frac{p}{1-p} = e^{\beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p}$$

**系数解释（对数优势比）：** $\beta_j$ 表示 $X_j$ 每增加一个单位，对数优势比（log-odds）平均变化 $\beta_j$，即优势比乘以 $e^{\beta_j}$。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $p$ | 成功概率 $P(Y=1|X)$ | $[0, 1]$ | 模型输出 |
| $\text{logit}(p)$ | 对数优势比 | $\mathbb{R}$ | 链接函数，无界 |
| $\text{Odds}$ | 优势比 | $\mathbb{R}^+$ | $p/(1-p)$ |
| $\beta_j$ | 回归系数 | $\mathbb{R}$ | 解释为对数优势比的变化 |
| $e^{\beta_j}$ | 优势比（OR） | $\mathbb{R}^+$ | 解释为优势比的倍数变化 |

### 4. 常见变体与适用条件

- **适用条件**：二分类响应变量（$Y \in \{0,1\}$）；观测独立；线性 logit 假设（$\text{logit}(p)$ 与预测变量线性相关）。
- **限制条件**：需要足够样本量（每个预测变量至少 10-15 个事件）；类别不平衡时需谨慎（可调整阈值或使用加权）。
- **估计方法**：最大似然估计（MLE），通过迭代重加权最小二乘（IRLS）求解，无闭式解。

## 6. 推导思路和思想来源

- **最初困难**：线性回归预测概率时，预测值会超出 [0,1] 范围，且违反了正态性和同方差假设。
- **直接方法局限**：线性判别分析（LDA）假设 $X$ 服从多元正态分布，这在很多应用中不成立。
- **关键"转念"**：不直接建模 $p$ 与 $X$ 的关系，而是建模 $p$ 的某个变换函数与 $X$ 的关系。选择 logit 变换 $\ln(p/(1-p))$，因为它将 $[0,1]$ 映射到 $\mathbb{R}$，且当 $p$ 接近 0 或 1 时，变换后的变化率自然不同（S 形）。
- **推导主线与动机**：
  1. 设定 $Y_i \sim \text{Bernoulli}(p_i)$，即 $P(Y_i=1) = p_i$
  2. 链接：$\text{logit}(p_i) = \eta_i = \beta^T X_i$
  3. 似然函数：$L(\beta) = \prod_{i=1}^n p_i^{y_i} (1-p_i)^{1-y_i}$
  4. 对数似然：$\ell(\beta) = \sum_{i=1}^n [y_i \ln(p_i) + (1-y_i)\ln(1-p_i)]$
  5. 代入 $p_i = e^{\beta^T X_i}/(1+e^{\beta^T X_i})$，最大化 $\ell(\beta)$
  6. 用 IRLS（Newton-Raphson）迭代求解：$\beta^{(t+1)} = \beta^{(t)} + (X^T W X)^{-1} X^T (y - p)$，其中 $W$ 是权重矩阵（对角元 = $p_i(1-p_i)$）
- **为什么自然得到此结论**：logistic 函数是 Bernoulli 分布的自然参数（自然链接函数）——在指数族分布框架下，logit 是 Bernoulli 的规范链接函数。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：5 名学生的考试成绩（$X$，分）与录取结果（$Y$，1=录取，0=未录取）。数据：(50,0), (60,0), (70,1), (80,1), (90,1)。假设 $\beta_0 = -5, \beta_1 = 0.08$，计算 $X=65$ 时的录取概率。
- **解题思路与关键步骤**：
  1. 线性预测器：$\eta = -5 + 0.08 \times 65 = 0.2$
  2. 概率：$p = e^{0.2}/(1 + e^{0.2}) = 1.221/2.221 \approx 0.55$
- **最终答案**：$P(\text{录取}|X=65) \approx 0.55$，录取概率略高于 50%。
- **易错点**：$\beta_1 = 0.08$ 表示成绩每增加 1 分，对数优势比增加 0.08，不是概率增加 0.08。
- **🤔 追问**：如果 $\beta_1 = 0.08$，成绩从 65 分提高到 66 分，优势比如何变化？（$e^{0.08} \approx 1.083$，优势比乘以 1.083）

### 例子 2：中等例子（条件判断与多步推理）

- **题目与完整解答**：某 Logistic 回归模型拟合结果如下（响应变量：是否购买，1=购买）：
  - $\text{logit}(\hat{p}) = -2.5 + 0.3 \times \text{收入（万元）} + 1.5 \times \text{性别（男=1）}$
  - 请问：收入每增加 1 万元，购买优势比变化多少？男性的购买概率是女性的多少倍（假设收入相同）？
- **解答**：
  - 收入优势比：$e^{0.3} \approx 1.35$，收入每增 1 万，购买优势比增加 35%
  - 性别优势比：$e^{1.5} \approx 4.48$，男性的购买优势比是女性的 4.48 倍（注意：优势比（odds ratio）不是概率比）

### 例子 3：实际应用例子（Python 代码）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix
import warnings
warnings.filterwarnings('ignore')

# 模拟数据：基于信用评分预测违约
np.random.seed(42)
n = 200
credit_score = np.random.normal(650, 80, n)  # 信用评分
income = np.random.normal(50, 20, n)         # 年收入（万元）

# 真实违约概率（评分越低，收入越低，违约概率越高）
log_odds = -8 + 0.005 * credit_score + 0.04 * income
p_default = 1 / (1 + np.exp(-log_odds))
y = np.random.binomial(1, p_default)

# ---- statsmodels Logit ----
X = sm.add_constant(pd.DataFrame({'credit_score': credit_score, 'income': income}))
model_sm = sm.Logit(y, X).fit(disp=0)
print(model_sm.summary().tables[1])
# 系数：const≈-8, credit_score≈0.005, income≈0.04
# 解释：信用评分每增1分，违约优势比乘以 e^0.005≈1.005

# 打印优势比
print("优势比:")
print(np.exp(model_sm.params))
# const≈0.0003, credit_score≈1.005, income≈1.041

# ---- sklearn LogisticRegression ----
model_sk = LogisticRegression(penalty=None, solver='lbfgs')
model_sk.fit(X[['credit_score', 'income']], y)
y_pred = model_sk.predict(X[['credit_score', 'income']])
print("准确率:", accuracy_score(y, y_pred))  # 约 0.85-0.90
```

## 8. 常见误区和易混概念

### 误区 1：系数 $\beta_j$ 直接解释为概率的变化
- **错误直觉**：$\beta_j = 0.3$，所以 $X_j$ 每增 1，概率增加 0.3。
- **为什么错**：Logistic 回归的系数是对数优势比的变化，不是概率的变化。概率变化依赖于当前 $p$ 值——当 $p$ 接近 0.5 时，$\beta_j$ 对概率的影响最大；当 $p$ 接近 0 或 1 时，影响最小。
- **正确理解**：$\beta_j$ 是对数优势比的变化，优势比乘以 $e^{\beta_j}$。边际效应（概率变化）需要计算 $p(1-p)\beta_j$。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **线性回归** | 预测连续 $Y$ | 最小二乘，闭式解 | 房价预测、销售额预测 |
| **Logistic 回归** | 二分类 $Y$ | MLE，IRLS 迭代，S 形曲线 | 违约预测、疾病诊断 |
| **线性判别分析 LDA** | 二分类/多分类 | 假设 $X$ 正态，协方差相等 | 数据满足正态假设时 |
| **Probit 回归** | 二分类 $Y$ | 用标准正态 CDF 替代 logistic | 经济学（随机效用模型） |

### 题目与解析

#### 1. 为什么线性回归不能直接用于二分类问题？
> [!question]- 答案解析
> - **答案**：三个原因：(1) 预测值会超出 [0,1] 范围；(2) 误差项不服从正态分布（0/1 数据）；(3) 同方差假设不成立（方差 $p(1-p)$ 随 $p$ 变化）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 某 Logistic 回归模型给出 $p = 0.75$，对应的优势比（Odds）是多少？
> [!question]- 答案解析
> - **答案**：$\text{Odds} = 0.75/(1-0.75) = 3$
> - **解析**：优势比 3 表示"成功概率是失败概率的 3 倍"。对数优势比为 $\ln 3 \approx 1.099$。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 当数据完全可分时，Logistic 回归的 MLE 会怎样？
> [!question]- 答案解析
> - **答案**：系数会趋于无穷大（完全分离问题）。
> - **解析**：如果存在一个超平面能完美分开 0 和 1，MLE 无有限解——因为 $\beta$ 越大，似然越接近 1，但永远达不到。需要加入正则化（L2 惩罚）或使用 Firth 的偏置修正。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 模型 $\text{logit}(\hat{p}) = -2 + 0.05 \times \text{年龄}$，年龄从 30 岁增加到 40 岁，优势比怎么变化？
> [!question]- 答案解析
> - **答案**：年龄增加 10 岁，对数优势比增加 $0.05 \times 10 = 0.5$，优势比乘以 $e^{0.5} \approx 1.65$。
> - **解析**：优势比的变化是乘性的，$e^{\beta_j \Delta X}$。年龄每增加 1 岁，优势比乘以 $e^{0.05} \approx 1.051$。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 推导 IRLS 更新公式 $\beta^{(t+1)} = (X^T W X)^{-1} X^T W z$，其中 $z$ 是工作变量，$W$ 是权重矩阵。
> > [!question]- 答案解析
> > - **答案**：对数似然 $\ell(\beta) = \sum[y_i \ln p_i + (1-y_i)\ln(1-p_i)]$，其中 $p_i = e^{\eta_i}/(1+e^{\eta_i})$。一阶导 $\partial \ell/\partial \beta = X^T (y-p)$，二阶导 $\partial^2 \ell/\partial \beta \partial \beta^T = -X^T W X$，其中 $W = \text{diag}(p_i(1-p_i))$。Newton-Raphson 更新：$\beta^{(t+1)} = \beta^{(t)} + (X^T W X)^{-1} X^T (y-p) = (X^T W X)^{-1} X^T W z$，其中 $z = X\beta^{(t)} + W^{-1}(y-p)$ 是工作变量。
> > - **Obsidian 标签建议**：`#自测题/较难`
