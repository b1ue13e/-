## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：现实中的变量关系几乎都是非线性的（如收入与消费的边际递减、药物剂量与疗效的S形曲线）。不理解非线性建模，就无法处理真实数据。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 假设你是一位房地产分析师，想用房屋面积预测价格。当你画散点图时发现——面积每增加 10 平米，低价房价格涨得很快，但豪宅区价格涨幅反而放缓了。这是典型的**边际递减效应**。如果用直线 $y = \beta_0 + \beta_1 x$ 去拟合，要么低估小面积的涨幅，要么高估大面积的涨幅。**线性模型假设"X每增加一个单位，Y的变化量恒定"，这在现实中几乎不成立。**

> **为什么必须引入新工具**：我们需要一个框架，允许回归函数 $f(x) = E(Y|X=x)$ 不是直线，而是**曲线**——它可以弯、可以扭、可以出现拐点。这就是**非线性模型**要解决的问题。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：非线性模型是[[多项式回归]]、[[可化为线性回归的曲线回归]]、广义加性模型（GAM）和深度学习的基础。不理解它，就无法理解为什么需要样条、核方法或神经网络。
- **实际应用场景**：经济学中的边际效用递减、流行病学中的剂量-反应曲线、生物学的生长曲线（logistic growth）、工程中的应力-应变关系。
- **高频题型/任务**：模型诊断时检查残差是否存在非线性模式；选择适当变换（对数、平方、倒数）使模型可解释；比较不同非线性拟合的预测能力。

---

## 3. 学它之前需要哪些前置知识？

1. **[[多元线性回归模型]]**：理解线性模型 $Y = X\beta + \varepsilon$ 的矩阵形式、最小二乘估计和残差分析。非线性模型在其基础上扩展了 $X$ 的变换形式。
2. **[[残差分析]]**：残差 vs 拟合值图是判断是否存在非线性的最重要工具——如果残差呈现"U形"或"喇叭形"，说明线性假设不成立。

---

## 4. 用直觉语言解释它

> «"非线性模型"就像配钥匙——线性模型只允许你**按固定比例**复制钥匙（每加1单位X，Y就加固定值），而非线性模型允许你**调整打磨的力度**——X小的时候磨快一点（斜率大），X大的时候磨慢一点（斜率小）。»

- **直觉类比**：开车时方向盘的角度和转弯半径的关系——不是直线，低速时小角度转弯效果明显，高速时同样角度转弯更平缓。
- **为什么很自然**：边际效应递减、饱和效应、阈值效应都是自然界的基本规律，线性关系才是特例。
- **一句话直觉本质**：**非线性模型就是允许回归线的斜率随着X的变化而变化。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

非线性模型是指回归函数 $f(x) = E(Y|X=x)$ 不是关于参数 $\beta$ 的线性函数的模型。它分为两类：

- **本质线性（intrinsically linear）**：可通过变量变换转化为线性模型，如 $Y = \beta_0 e^{\beta_1 X} \rightarrow \ln Y = \ln\beta_0 + \beta_1 X$。
- **本质非线性（intrinsically nonlinear）**：无法通过简单变换线性化，如 $Y = \beta_0 + \beta_1 e^{\beta_2 X} + \varepsilon$，需要迭代算法估计。

### 2. 核心公式

**多项式回归（最常用的非线性推广）：**
$$Y = \beta_0 + \beta_1 X + \beta_2 X^2 + \cdots + \beta_d X^d + \varepsilon$$

**本质非线性模型的一般形式：**
$$Y = f(X, \beta) + \varepsilon, \quad \text{其中 } f \text{ 关于 } \beta \text{ 非线性}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $Y$ | 响应变量 | $\mathbb{R}$ | 因变量 |
| $X$ | 预测变量 | $\mathbb{R}$ | 自变量 |
| $\beta_j$ | 回归系数 | $\mathbb{R}$ | 可学习参数 |
| $d$ | 多项式次数 | $\mathbb{N}^+$ | 控制弯曲程度 |
| $\varepsilon$ | 随机误差 | $\mathbb{R}$ | 通常假设 $N(0,\sigma^2)$ |

### 4. 常见变体与适用条件

- **多项式回归**：适用条件——关系平滑、无理论形式指导、在数据范围内插值；限制——高次多项式（$d>3$或$d>4$）在边界处振荡严重（Runge现象），外推极不可靠。
- **分段多项式与样条**：在节点之间拟合低次多项式，克服了全局多项式的振荡问题。适用条件——数据量大、关系复杂。
- **广义加性模型（GAM）**：$g(E(Y)) = \beta_0 + f_1(X_1) + f_2(X_2) + \cdots$，每个变量用平滑函数拟合。适用条件——高维非线性问题，可解释性要求高。

---

## 6. 推导思路和思想来源

- **最初困难**：线性模型假设 $E(Y|X) = \beta_0 + \beta_1 X$，但真实关系往往有曲率。残差图会呈现"U形"或"倒U形"模式。
- **直接方法局限**：尝试引入 $X^2$ 项，这实际上仍然是线性模型（关于参数 $\beta$ 线性），只是预测变量变成了 $X$ 和 $X^2$。这种"线性化技巧"可行，但需要知道用什么变换——而真实关系往往未知。
- **关键"转念"**：不必事先知道函数形式，可以用**基函数展开**（basis expansion）——将 $X$ 映射到一组基函数 $\phi_1(X), \phi_2(X), \ldots, \phi_m(X)$，然后拟合线性模型 $Y = \sum \beta_j \phi_j(X) + \varepsilon$。
- **推导主线与动机**：OLS $\rightarrow$ 残差诊断发现非线性 $\rightarrow$ 引入多项式项 $\rightarrow$ 发现高次多项式振荡 $\rightarrow$ 引入分段多项式/样条 $\rightarrow$ 引入正则化（平滑样条）$\rightarrow$ GAM。
- **为什么自然得到此结论**：泰勒展开告诉我们，任何平滑函数都可以用多项式逼近——这是多项式回归的数学基础。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：有 4 个数据点：$(X,Y) = (1,3), (2,6), (3,8), (4,7)$。拟合二次多项式 $Y = \beta_0 + \beta_1 X + \beta_2 X^2 + \varepsilon$ 的 OLS 估计。
- **解题思路与关键步骤**：构造设计矩阵 $X = [\mathbf{1}, X, X^2]$，用矩阵公式 $\hat{\beta} = (X^TX)^{-1}X^Ty$ 求解。
  $$X = \begin{bmatrix}1 & 1 & 1\\ 1 & 2 & 4\\ 1 & 3 & 9\\ 1 & 4 & 16\end{bmatrix}, \quad y = \begin{bmatrix}3\\6\\8\\7\end{bmatrix}$$
  计算 $X^TX$ 和 $(X^TX)^{-1}$，得 $\hat{\beta}_0 = -1, \hat{\beta}_1 = 5.5, \hat{\beta}_2 = -1$。
- **最终答案**：$\hat{Y} = -1 + 5.5X - X^2$，在 $X=2.75$ 处达到最大值。
- **易错点**：$X$ 和 $X^2$ 高度相关会导致多重共线性——中心化可缓解（用 $X - \bar{X}$ 代替 $X$）。
- **🤔 追问**：如果加入 $X^3$ 项，拟合效果一定更好吗？会过拟合吗？

### 例子 2：中等例子（条件判断）

- **题目与完整解答**：判断以下模型是否本质线性：
  (a) $Y = \beta_0 + \beta_1 \ln X + \varepsilon$ → 是（令 $X' = \ln X$）
  (b) $Y = \beta_0 e^{\beta_1 X} + \varepsilon$ → 是（取对数得 $\ln Y = \ln\beta_0 + \beta_1 X$，注意误差项变为相乘）
  (c) $Y = \beta_0 + \beta_1 e^{\beta_2 X} + \varepsilon$ → **否**（参数 $\beta_2$ 在指数内，无法通过变换线性化）

### 例子 3：实际应用例子（Python 代码）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from sklearn.preprocessing import PolynomialFeatures
import warnings
warnings.filterwarnings('ignore')

# 模拟非线性数据：y = 3 + 2*x - 0.5*x^2 + noise
np.random.seed(42)
X = np.linspace(0, 10, 50)
y = 3 + 2*X - 0.5*X**2 + np.random.normal(0, 1.5, 50)

# ---- 线性模型拟合 ----
X_lin = sm.add_constant(X)
model_lin = sm.OLS(y, X_lin).fit()
print("线性模型 R²:", model_lin.rsquared)  # 约 0.67

# ---- 二次多项式拟合 ----
poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly = poly.fit_transform(X.reshape(-1, 1))
X_poly = sm.add_constant(X_poly)
model_quad = sm.OLS(y, X_poly).fit()
print("二次模型 R²:", model_quad.rsquared)  # 约 0.94，显著提升
print("系数:", model_quad.params)  # const≈3.2, x1≈1.9, x2≈-0.5
```

## 8. 常见误区和易混概念

### 误区 1："非线性模型=不可用最小二乘法"
- **错误直觉**：因为模型是"非线性"的，所以不能用 OLS。
- **为什么错**：[[可化为线性回归的曲线回归]] 可以通过变量变换变为线性模型，仍然用 OLS 估计。只有本质非线性模型才需要迭代算法。
- **正确理解**：区分"关于变量非线性"和"关于参数非线性"——前者可通过变换线性化，后者需要专门的非线性最小二乘（NLS）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **线性模型** | 关系是直线 | $Y = \beta_0 + \beta_1 X$，斜率恒定 | 简单基准、近似关系 |
| **多项式回归** | 关系是曲线 | $Y = \sum \beta_j X^j$，全局光滑 | 单变量弯曲关系 |
| **样条回归** | 分段拟合 | 节点间低次多项式，局部控制 | 复杂曲线、大数据 |
| **GAM** | 多变量非线性 | 每个变量单独平滑，加性组合 | 高维可解释建模 |

### 题目与解析

#### 1. 以下哪个模型是本质非线性的？
> [!question]- 答案解析
> - **答案**：(c) $Y = \beta_0 + \beta_1 e^{\beta_2 X} + \varepsilon$
> - **解析**：(a) $Y = \beta_0 + \beta_1 \ln X + \varepsilon$ 可令 $X' = \ln X$ 线性化；(b) $Y = \beta_0 X^{\beta_1} + \varepsilon$ 可两边取对数线性化；(c) 中 $\beta_2$ 在指数内，无法通过有限次变换变为关于参数的线性形式。
> - **易错原因**：混淆"关于变量非线性"与"关于参数非线性"。
> - **对应误区**：误区 1
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 多项式回归中，为什么通常要对 $X$ 做中心化（减去均值）后再构造 $X^2$ 项？
> [!question]- 答案解析
> - **答案**：减少 $X$ 与 $X^2$ 之间的多重共线性。
> - **解析**：原始 $X$ 和 $X^2$ 高度相关（尤其是 $X$ 在正数范围内时），中心化后低次项与高次项近似正交，系数估计更稳定。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 当残差 vs 拟合值图呈现"U形"时，应首先尝试什么方法？
> [!question]- 答案解析
> - **答案**：在模型中引入 $X^2$ 项（二次多项式）。
> - **解析**："U形"残差说明模型低估了两端、高估了中间，二次项可以捕捉这种曲率。如果二次项不够，可尝试更高次或样条。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 高次多项式（$d \geq 5$）拟合的缺点是什么？
> [!question]- 答案解析
> - **答案**：边界振荡（Runge 现象）和过拟合。
> - **解析**：高次多项式在数据范围边界处会剧烈振荡，导致外推完全不可靠；同时过度拟合训练数据中的噪声。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 你有一个数据集，包含 $X$ 和 $Y$，散点图显示 $Y$ 随 $X$ 先快速上升后趋于平缓（饱和效应）。请设计一个建模方案。
> [!question]- 答案解析
> - **答案**：可尝试 (a) 对数变换模型 $Y = \beta_0 + \beta_1 \ln X$；(b) 倒数模型 $Y = \beta_0 + \beta_1 (1/X)$；(c) 二次多项式（若还需下降段）。
> - **解析**：饱和效应通常意味着 $Y$ 对 $X$ 的导数递减。对数模型和倒数模型都能自然产生这种形状。应先可视化比较，再通过 $R^2$ 和残差图选择。
> - **Obsidian 标签建议**：`#自测题/较难`
