# 应用回归分析：广义线性模型框架

## 为什么不直接用 OLS

二元、计数和比例响应的支持集与均值-方差关系不同。GLM 保留线性预测子，但用合适的响应分布和链接函数连接条件均值。

## 三个组成部分

1. **随机部分**：$Y\mid X$ 来自指数族分布。
2. **系统部分**：线性预测子 $\eta=X\beta$。
3. **链接函数**：$g(\mu)=\eta$，其中 $\mu=\mathbb E(Y\mid X)$。

典型组合：

| 响应 | 分布 | 常用链接 | 解释 |
| :--- | :--- | :--- | :--- |
| 连续近似对称 | Gaussian | identity | 均值差 |
| 二元 | Binomial | logit | 对数优势 |
| 计数 | Poisson | log | 对数率；常配 offset |

链接函数必须把均值空间映射到实数线性预测子。选择家族不能只看 API 名称，还要检查支持集、离散程度和观测机制。

## 估计与 IRLS

GLM 通常通过最大似然估计。Newton-Raphson 或 Fisher scoring 可整理为迭代加权最小二乘：

$$
\beta^{(t+1)}
=(X^TW^{(t)}X)^{-1}X^TW^{(t)}z^{(t)}.
$$

$W$ 和工作响应 $z$ 都由当前均值估计决定。它和处理已知异方差的 WLS 形式相似，但权重来源不同，不能混为一谈。

## 诊断

- 看 deviance、Pearson 残差和影响点，而不是照搬 OLS 残差正态性。
- Poisson 模型要检查过度离散；方差明显大于均值时，标准误和模型家族需要调整。
- Logistic 模型要检查完全分离、校准、类别不平衡和阈值依赖。
- 预测评价与推断评价分开报告。

## 最小代码

```python
import numpy as np
import statsmodels.api as sm

rng = np.random.default_rng(42)
x = rng.normal(size=400)
eta = -0.5 + 0.8 * x
p = 1 / (1 + np.exp(-eta))
y = rng.binomial(1, p)
X = sm.add_constant(x)

model = sm.GLM(y, X, family=sm.families.Binomial()).fit()
assert np.isfinite(model.params).all()
print(model.params)
print('deviance=', model.deviance)
```

## 常见错误

- 把链接函数当作响应变量变换后直接做 OLS。
- 把 IRLS 的工作权重解释成样本重要性。
- 在 Logistic 中把系数直接解释为概率变化。
- 用 Poisson 处理过度离散数据却不检查方差结构。
