# 目标跟踪（Object Tracking）

## 0. 先判断它值不值得深挖

- **值得**：目标跟踪是视频理解/自动驾驶/监控的**基础能力**（"同一个物体在连续帧中是哪个"）；SORT/DeepSORT 是工业界最常用的多目标跟踪基线，原理清晰、易于落地。
- **不值得**：如果只做单帧图像任务，跟踪可跳过；若研究前沿可看 Transformer 跟踪（TransT）与联合检测跟踪（ByteTrack）。

## 1. 这个知识点解决什么问题？

**问题**：检测器只回答"这一帧有哪些物体"，不回答"**这一帧的物体对应上一帧的哪个**"。视频任务（跟踪轨迹、计数、行为分析、自动驾驶感知）需要跨帧的身份关联。

**目标跟踪的答案**：为每个物体维护一个**轨迹（tracklet）**，逐帧把新检测与已有轨迹关联，赋予稳定 ID。分两类：
- **单目标跟踪（SOT）**：只跟一个目标（首帧给定框），后续帧定位它（如 Siamese 跟踪器）。
- **多目标跟踪（MOT）**：同时跟多个目标，处理新目标出现、旧目标消失、遮挡与 ID 切换。

## 2. 为什么它重要？它有什么用？

- **视频理解基础**：行为识别、人群计数、轨迹分析都依赖跟踪。
- **自动驾驶**：感知模块输出目标的连续轨迹（速度、意图预测）。
- **监控/安防**：跨摄像头追踪、人流统计。
- **评价指标**：MOTA、IDF1、IDSW（ID 切换数）是 MOT 的度量标准。

## 3. 学它之前需要哪些前置知识？

1. **[[02-Knowledge/🧠 学习系统/05-计算机视觉/03-视觉核心任务/目标检测RCNN与YOLO|目标检测]]**：MOT 的输入通常是检测器输出（框 + 置信度）；检测质量直接影响跟踪。
2. **[[02-Knowledge/🧠 学习系统/05-计算机视觉/03-视觉核心任务/IoU与NMS|IoU]]**：SORT 用 IoU 做帧间关联代价。
3. **卡尔曼滤波（可选但推荐）**：SORT/DeepSORT 用卡尔曼预测目标位置（可在随机过程/控制课程找到）。

## 4. 用直觉语言解释它

想象你在看一段人群视频，给每个人发一个"号码牌"：
- 检测器每帧报"这里有 5 个人（框）"。
- 跟踪器要做的是：**这一帧的 5 个框，分别对应上一帧的哪个号码牌？**
- 方法：上一帧的每个人先"预测"他这帧大概在哪（卡尔曼预测），然后看哪个新框离他的预测最近（IoU 最大）就归他。
- 新出现的框 → 发新号码；消失的框 → 回收号码（可能被遮挡，等几帧再回收）。

## 5. 正式定义、核心公式、符号解释

**SORT（Simple Online and Realtime Tracking）流程**：

1. **检测**：每帧用检测器（当时是 Faster R-CNN）得到框集合 $D_t = \{(x, y, w, h, c)_i\}$。
2. **卡尔曼预测**：每个轨迹 $T_j$ 用恒定速度模型预测本帧状态 $\hat{x}_j = F x_{j-1}$，状态 $x = [x, y, s, r, \dot{x}, \dot{y}, \dot{s}]$（中心、尺度、长宽比、速度）。
3. **关联（匈牙利匹配）**：代价矩阵 $C_{ij} = 1 - \text{IoU}(D_i, \hat{T}_j)$，用匈牙利算法求最小代价匹配。
4. **更新**：匹配上的轨迹用检测更新（卡尔曼更新）；未匹配检测 → 新轨迹；未匹配轨迹 → 若连续 $T_{lost}$ 帧未匹配则删除（防止短暂遮挡误删）。

**DeepSORT 增强**：在 IoU 代价基础上加入**外观特征距离**：
$$
C_{ij} = \lambda \cdot d_{\text{appearance}}(f_i, f_j) + (1-\lambda) \cdot d_{\text{IoU}}
$$
外观特征 $f$ 由小型 ReID 网络（CNN）提取（每帧裁剪目标框 → 128 维嵌入），用余弦距离。这使遮挡/重出现后能**靠外观重关联**（SORT 做不到，导致 IDSW 高）。

**评价指标**：
- **MOTA**（多目标跟踪准确率）：$1 - \frac{\text{FN} + \text{FP} + \text{IDSW}}{\text{GT}}$，越高越好。
- **IDF1**：以身份为中心的 F1（衡量 ID 保持质量）。
- **IDSW**：ID 切换次数（越低越好）。

## 6. 推导思路和思想来源

1. **SORT 的设计哲学**：跟踪不需要复杂模型——检测强 + 关联简单（IoU + 匈牙利）就能在 MOT16 达良好效果。Bewley et al. 强调"检测质量 > 跟踪算法"。
2. **为什么用卡尔曼**：恒速模型 + 高斯噪声假设，用卡尔曼预测目标下一帧位置，减少搜索范围（只需在预测框附近找匹配）。
3. **DeepSORT 的动机**：SORT 只有运动模型（IoU），遮挡恢复时丢失 ID。DeepSORT 加 ReID 外观特征，让"重新出现的同一人"能匹配回原轨迹——代价是需要 ReID 网络（离线训练）。
4. **为什么 IDSW 重要**：下游任务（统计/行为）对 ID 连续性敏感；ID 切换会破坏轨迹完整性。

## 7. 例子：基础 → 中等 → 实际应用

**基础例子（IoU 关联）**：
第 5 帧轨迹 A 预测位置 (10, 10, 20, 20)；第 6 帧检测框 B (11, 11, 21, 21)（IoU≈0.9）、检测框 C (100, 100, 20, 20)（IoU≈0）。
- 匹配代价：A-B = 0.1，A-C = 1.0
- 匈牙利选择 A-B ✅，C 成为新轨迹。

**中等例子（DeepSORT 外观重关联）**：
目标被遮挡 5 帧后重新出现：
- 卡尔曼预测位置偏差大（IoU 匹配失败）
- 但 ReID 特征与历史轨迹的特征余弦距离 < 阈值 → 正确重关联，ID 保持 ✅
- （SORT 在此场景会断轨迹 → 新 ID → IDSW+1）

**实际应用**：
- **自动驾驶**：YOLO 检测 + DeepSORT 跟踪行人/车辆，输出轨迹供轨迹预测。
- **体育分析**：球员跟踪 + ID 保持，统计跑动距离。
- **监控**：人群计数（按轨迹数）、异常行为检测。

## 8. 常见误区和易混概念

| 误区 | 澄清 |
|:---|:---|
| "跟踪 = 检测" | 不同：检测是单帧定位；跟踪是跨帧身份关联（需要时序信息） |
| "SORT 不需要检测器" | 需要：SORT 是"检测 + 关联"框架，检测质量直接决定跟踪上限 |
| "IDSW 无所谓" | 不是：ID 切换破坏轨迹，MOTA/IDF1 都会降，下游任务受影响 |
| "跟踪只处理运动" | DeepSORT/ByteTrack 用外观特征，Transformer 跟踪用注意力；纯运动模型遮挡时失效 |
| 与 [[02-Knowledge/🧠 学习系统/05-计算机视觉/03-视觉核心任务/目标检测RCNN与YOLO|检测]] 混淆 | 检测输出"框+类"，跟踪输出"框+类+ID+轨迹" |
