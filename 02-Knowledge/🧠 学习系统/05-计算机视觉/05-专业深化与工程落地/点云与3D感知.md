# 点云与 3D 感知（Point Cloud & 3D Perception）

## 0. 先判断它值不值得深挖

**B 类专题（3D 视觉主线）**。3D 感知回答"物体/场景的三维几何是什么"：从**双目视差**、**深度传感器（激光雷达/深度相机）**获得点云，用 **PointNet 类网络**理解点云，用 **NeRF/3DGS** 做新视角渲染。本卡合并 MOC 中 立体视觉 / 点云处理 / Gaussian Splatting 三个规划项——它们构成"3D 数据获取 → 3D 表示学习 → 3D 渲染"的完整链条，与 NeRF、相机标定卡互补。

## 1. 这个知识点解决什么问题？

- 图像是 2D 投影，丢失了深度；机器人/自动驾驶/AR 需要三维结构；
- 点云是 3D 的原始表示（$N \times 3$ 坐标 + 特征），但**无序**（点的顺序任意）——CNN 不能直接用于点云；
- 双目立体匹配从两幅图恢复稠密深度（视差图），是无源深度估计的经典手段；
- 3DGS 用可微高斯球实时渲染高质量新视角，替代 NeRF 的慢速体渲染。

## 2. 为什么它重要？它有什么用？

- 自动驾驶（激光雷达点云检测/分割，衔接 BEV 感知）、机器人抓取、AR/VR、测绘；
- 3D 生成/重建（3DGS 是 2023 起新视角合成的事实标准）；
- 理解"无序数据的深度学习"（对称函数）是图神经网络的思想前奏。

## 3. 学它之前需要哪些前置知识？

- 相机几何：[[🎯 相机标定与对极几何 (Epipolar Geometry)|相机标定与对极几何]]（双目对极约束）；
- 神经渲染基础：[[🎯 NeRF 神经辐射场 (Neural Radiance Fields)|NeRF]]（衔接 3DGS）；
- 检测/分割基础（自动驾驶衔接）：[[目标检测RCNN与YOLO]]。

## 4. 用直觉语言解释它

点云就是"一堆空间坐标点"——像夜空里的星星，没有行和列。CNN 要的是规整网格，对点云束手无策；PointNet 的聪明之处在于用**对称函数**（max/mean）把"任意顺序的点"压成同一个特征——就像"取最大值"与点的先后无关。双目立体则像"人的两只眼"：同一物体在左右眼图像上位置不同（视差），视差大 = 离得近，用三角几何换算成深度。3DGS 则是"用几万个半透明彩色小球摆出场景"，渲染时逐个投影叠加，比 NeRF 快几个数量级。

## 5. 正式定义、核心公式、符号解释

### 5.1 立体视觉与视差

对校正后的双目图像，同名点在左右图的水平坐标差为**视差** $d = x_L - x_R$，深度：

$$Z = \frac{f \cdot B}{d}$$

$f$ 焦距、$B$ 基线（两相机距离）。**立体匹配**（如 SGM）在每条极线上搜索最优 $d$（代价聚合 + 平滑约束），输出稠密视差图 → 深度图 → 反投影成点云。

### 5.2 点云的置换不变性（PointNet 核心）

点云 $\{p_1, \dots, p_N\}$ 无序。要求函数 $f$ 对任意置换 $\pi$ 满足 $f(p_1,\dots,p_N) = f(p_{\pi(1)},\dots,p_{\pi(N)})$。PointNet 用**对称函数**实现：

$$f(p_1, \dots, p_N) = \gamma\left(\max_{i=1}^{N} h(p_i)\right)$$

$h$：逐点 MLP（升维）；max：最大池化（对称）；$\gamma$：全局 MLP。结构简单但对齐了置换不变性；并加了 **T-Net**（预测变换矩阵对齐输入/特征）提高鲁棒性。局限：max 只保留"最显著点"，丢失局部结构 → PointNet++ 引入局部邻域分组（类似 CNN 的感受野）。

### 5.3 3D Gaussian Splatting（3DGS）

用 $K$ 个 3D 高斯球表示场景（均值 $\mu_k$、协方差 $\Sigma_k$、颜色、不透明度）：

$$G_k(x) = \exp\left(-\frac12 (x-\mu_k)^\top \Sigma_k^{-1} (x-\mu_k)\right)$$

渲染：3D 高斯投影到 2D → 按深度排序 → alpha 合成（可微，端到端训练）。相比 NeRF（逐光线积分，慢），3DGS 训练快（分钟-小时级）且实时渲染（100+ FPS）。

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——置换不变性验证

```python
import numpy as np

def pointnet_style(x, W1, W2):
    """简化 PointNet：逐点 MLP + max 池化"""
    h = np.maximum(x @ W1, 0)          # 逐点 (N, d1)
    pooled = h.max(axis=0)             # 全局 max（对称）
    return pooled @ W2

rng = np.random.default_rng(0)
pts = rng.random((100, 3)); W1 = rng.random((3, 8)); W2 = rng.random((8, 4))
perm = rng.permutation(100)
f1 = pointnet_style(pts, W1, W2)
f2 = pointnet_style(pts[perm], W1, W2)
print(f"置换前后特征一致: {np.allclose(f1, f2)}")   # True
```

### 例子 2：中等——双目深度公式（NumPy）

```python
import numpy as np

f, B = 500.0, 0.12   # 焦距(px), 基线(m)
d = np.array([10, 20, 50, 100], dtype=float)   # 视差(px)
Z = f * B / d
print(f"视差 {d} px → 深度 {Z} m")   # 视差越大越近
# 注意: Z 与 d 成反比——近处物体视差大、远处视差小(趋于0)
```

### 例子 3：应用——3D 感知流水线

```python

# 1. 获取：双目相机 → 立体匹配(SGM) → 视差图 → 深度图 → 反投影点云

# 3. 渲染：对场景拍多视角照片 → 训练 3DGS（~10 分钟）→ 实时新视角渲染/编辑
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "点云可以直接塞进 CNN" | 点云无序、非网格；需 PointNet 类对称架构或体素化（有量化损失） |
| "立体视觉深度 = 直接测距" | 是三角测量换算，依赖标定精度；无纹理区域匹配失败 |
| "3DGS 与 NeRF 结构相同" | 3DGS 是显式高斯球 + alpha 合成，NeRF 是隐式场 + 体渲染；3DGS 快得多 |
| "视差越大越远" | 视差越大**越近**（$Z = fB/d$） |
| "点云只有坐标没有语义" | 可带法线/颜色/强度，PointNet 类网络输出逐点语义标签 |
