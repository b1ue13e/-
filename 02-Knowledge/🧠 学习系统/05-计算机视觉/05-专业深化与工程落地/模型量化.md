# 模型量化 (Model Quantization)

> 所属模块：[[🗺️ 计算机视觉学习路径|计算机视觉学习路径]]
> 对应阶段：[[🧭 阶段5-专业深化与工程落地|第五阶段]]

---

## 0. 类别：A 类核心概念

量化是模型部署的"第一站"——把 FP32 权重和激活值压缩为 INT8/FP16，实现 2-4× 推理加速和 4× 内存缩减，精度损失通常 <1%。

---

## 1. 直觉：从 32 位到 8 位

FP32 用 32 位存一个数，INT8 只用 8 位。从 32→8 位意味着**存储减少 75%**，且整数运算比浮点快得多。

$$x_{\text{quant}} = \text{round}\left(\frac{x}{\text{scale}}\right) + \text{zero\_point}$$

其中 $\text{scale} = \frac{x_{\max} - x_{\min}}{255}$，$\text{zero\_point}$ 映射浮点 0。

---

## 2. 量化方案对比

| 方案 | 精度 | 加速比 | 内存节省 | 硬件支持 |
|:---|:---|:---:|:---:|:---|
| **FP32** (基线) | 最高 | 1× | — | 所有 GPU |
| **FP16** (半精度) | 几乎无损 | 1.5-2× | 50% | V100+, T4, RTX |
| **INT8** (量化) | <1% 损失 | 2-4× | 75% | T4, 大部分推理卡 |
| **INT4** | 1-3% 损失 | 4-6× | 87.5% | 部分边缘设备 |

---

## 3. 量化类型

### 训练后量化 (PTQ)
不需要重新训练，直接用少量校准数据确定 scale/zero_point。

```python
import torch.quantization as quant

# PyTorch PTQ 示例
model = torchvision.models.resnet50(pretrained=True)
model.eval()
model.qconfig = quant.get_default_qconfig('fbgemm')
quant.prepare(model, inplace=True)
# 校准：跑少量数据确定激活值范围
with torch.no_grad():
    for data in calibration_loader:
        model(data)
quant.convert(model, inplace=True)
# 模型现在是 INT8 了
```

### 量化感知训练 (QAT)
训练时"模拟"量化效果（插入 FakeQuant 节点），让模型适应量化噪声。精度通常优于 PTQ。

| 方法 | 精度 | 需要训练 | 适用场景 |
|:---|:---|:---|:---|
| PTQ | 好 | ❌ | 通用，几分钟完成 |
| QAT | 更好 | ✅ | 精度敏感场景 |

### 3.3 手算量化示例（scale / 量化 / 反量化 / 误差）

设某层权重范围为 $[-1.0, 1.0]$，对称量化（zero_point=0）：

$$\text{scale} = \frac{x_{\max}}{2^7 - 1} = \frac{1.0}{127} \approx 0.00787$$

- 量化：$q = \text{round}(x / \text{scale})$（值域 $[-127, 127]$，不会溢出 int8）
- 反量化：$\hat{x} = q \times \text{scale}$

```python
import numpy as np

x = np.array([0.0, 0.5, 1.0, -1.0, 0.987])
scale = 1.0 / 127.0
q = np.round(x / scale).astype(np.int8)      # [0, 64, 127, -127, 125]
x_hat = q * scale                            # 反量化
err = np.abs(x - x_hat).max()
print(f"量化误差 max|Δx| = {err:.4f}")       # ≈ 0.0039（约半个 scale）
# 结论：8bit 均匀量化在最坏情形引入约 scale/2 的绝对误差；
# 对权重/激活分布集中（多数值接近 0）的网络，相对误差很小 → 精度损失 <1%
```

**精度损失经验数据**（ImageNet 分类，ResNet-50）：

| 量化配置 | Top-1 下降 | 加速 | 说明 |
|:---|:---:|:---:|:---|
| FP16 | ~0% | 1.5-2× | 几乎无损 |
| INT8 PTQ | 0.2-0.8% | 2-4× | 校准集 500-1000 张 |
| INT8 QAT | 0.1-0.4% | 2-4× | 需微调训练 |
| INT4 QAT | 1-3% | 4-6× | 需更强校准/蒸馏辅助 |

> 敏感层：**第一层（输入像素域）与最后分类层**对量化最敏感，常保留 FP16/FP32；检测/分割等任务对量化比分类更敏感（边框回归精度），INT8 前建议验证 mAP 下降。

## 4. TensorRT INT8 部署流程

```python
# TensorRT INT8 量化管线
# 1. PyTorch → ONNX
torch.onnx.export(model, dummy_input, 'model.onnx')

# 2. ONNX → TensorRT (INT8)
import tensorrt as trt
builder = trt.Builder(logger)
builder.int8_mode = True
builder.int8_calibrator = MyCalibrator(calibration_data)
engine = builder.build_engine(network, config)

# 3. 推理 — 预期加速 2-4×，精度损失 <1%
```

---

## 5. 常见误区

- ❌ "量化后精度一定会大幅下降" — PTQ 在 ResNet-50 上通常 <0.5% Top-1 下降
- ❌ "所有层都应该量化" — 第一层和最后一层通常保持高精度（对量化最敏感）
- ❌ "INT8 比 FP16 快 2 倍" — 只有在支持 INT8 的硬件（T4/V100）上才有加速
