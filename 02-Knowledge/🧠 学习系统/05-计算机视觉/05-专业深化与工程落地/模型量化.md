> 所属模块：[[02-Knowledge/🧠 学习系统/05-计算机视觉/🗺️ 计算机视觉学习路径|计算机视觉学习路径]]

## 0. 类别：A 类核心概念

量化是模型部署的"第一站"——把 FP32 权重和激活值压缩为 INT8/FP16，实现 2-4× 推理加速和 4× 内存缩减，精度损失通常 <1%。

---

## 1. 直觉：从 32 位到 8 位

FP32 用 32 位存一个数，INT8 只用 8 位。从 32→8 位意味着**存储减少 75%**，且整数运算比浮点快得多。

$$x_{\text{quant}} = \text{round}\left(\frac{x}{\text{scale}}\right) + \text{zero\_point}$$

其中 $\text{scale} = \frac{x_{\max} - x_{\min}}{255}$，$\text{zero\_point}$ 映射浮点 0。

---

## 2. 量化方案对比

| 方案 | 精度 | 加速比 | 内存节省 | 硬件支持 |
|:---|:---|:---:|:---:|:---|
| **FP32** (基线) | 最高 | 1× | — | 所有 GPU |
| **FP16** (半精度) | 几乎无损 | 1.5-2× | 50% | V100+, T4, RTX |
| **INT8** (量化) | <1% 损失 | 2-4× | 75% | T4, 大部分推理卡 |
| **INT4** | 1-3% 损失 | 4-6× | 87.5% | 部分边缘设备 |

---

## 3. 量化类型

### 训练后量化 (PTQ)
不需要重新训练，直接用少量校准数据确定 scale/zero_point。

```python
import torch.quantization as quant

# PyTorch PTQ 示例
model = torchvision.models.resnet50(pretrained=True)
model.eval()
model.qconfig = quant.get_default_qconfig('fbgemm')
quant.prepare(model, inplace=True)
# 校准：跑少量数据确定激活值范围
with torch.no_grad():
    for data in calibration_loader:
        model(data)
quant.convert(model, inplace=True)
# 模型现在是 INT8 了
```

### 量化感知训练 (QAT)
训练时"模拟"量化效果（插入 FakeQuant 节点），让模型适应量化噪声。精度通常优于 PTQ。

| 方法 | 精度 | 需要训练 | 适用场景 |
|:---|:---|:---|:---|
| PTQ | 好 | ❌ | 通用，几分钟完成 |
| QAT | 更好 | ✅ | 精度敏感场景 |

## 4. TensorRT INT8 部署流程

```python
# TensorRT INT8 量化管线
# 1. PyTorch → ONNX
torch.onnx.export(model, dummy_input, 'model.onnx')

# 2. ONNX → TensorRT (INT8)
import tensorrt as trt
builder = trt.Builder(logger)
builder.int8_mode = True
builder.int8_calibrator = MyCalibrator(calibration_data)
engine = builder.build_engine(network, config)

# 3. 推理 — 预期加速 2-4×，精度损失 <1%
```

---

## 5. 常见误区

- ❌ "量化后精度一定会大幅下降" — PTQ 在 ResNet-50 上通常 <0.5% Top-1 下降
- ❌ "所有层都应该量化" — 第一层和最后一层通常保持高精度（对量化最敏感）
- ❌ "INT8 比 FP16 快 2 倍" — 只有在支持 INT8 的硬件（T4/V100）上才有加速
