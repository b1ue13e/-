# 光流估计与视频理解（Optical Flow & Video Understanding）

## 0. 先判断它值不值得深挖

**B 类专题（视频主线核心）**。图像是"空间快照"，视频是"空间+时间"。光流是视频分析的"底层运动表示"，动作识别、视频分割、目标跟踪、视频插帧都建立其上。本卡合并 MOC 中 光流估计 / 动作识别 / 视频分割 三个规划项——它们是"视频理解"同一主线的三个层次：运动表示 → 行为语义 → 时序分割。

## 1. 这个知识点解决什么问题？

- 静态 CNN 不知道"运动"：把两帧分别分类会漏掉"这个人正在跑"的时序语义；
- 需要显式建模帧间运动：**光流**给出每个像素的位移场；
- 需要从运动/外观中识别行为（动作识别）、把视频按时序分割成语义片段（视频分割）。

## 2. 为什么它重要？它有什么用？

- 动作识别/行为分析（监控、运动分析、医疗康复）；
- 视频插帧、视频稳定、光流引导的视频编辑；
- 自动驾驶的移动目标分割、视频目标跟踪（衔接目标跟踪卡）；
- Two-Stream 与 3D CNN 奠定了视频理解的两大范式，至今仍是基线。

## 4. 用直觉语言解释它

光流就是"给视频里每个像素标一个箭头"：箭头表示这个像素从上一帧移到了哪。传统方法（Lucas-Kanade）假设"像素亮度不变、邻域运动一致"，解小窗口方程；深度方法（FlowNet）直接让网络回归箭头场。有了光流，动作识别就可以"看两张图：一张外观、一张运动"，或干脆用 3D 卷积把时间当成第三个维度一起卷。

## 5. 正式定义、核心公式、符号解释

### 5.1 光流问题设定

相邻帧 $I(x, y, t)$、$I(x, y, t+1)$，光流场 $\mathbf{u}(x,y) = (u, v)$ 满足**亮度恒常假设**：

$$I(x, y, t) = I(x + u, y + v, t+1)$$

一阶泰勒展开 → **光流约束方程**：

$$I_x u + I_y v + I_t = 0$$

一个方程两个未知数——病态，需要正则约束。

### 5.2 Lucas-Kanade：局部一致假设

假设小窗口内 $u, v$ 恒定，用最小二乘求解：

$$\begin{bmatrix} \sum I_x^2 & \sum I_x I_y \\ \sum I_x I_y & \sum I_y^2 \end{bmatrix} \begin{bmatrix} u \\ v \end{bmatrix} = -\begin{bmatrix} \sum I_x I_t \\ \sum I_y I_t \end{bmatrix}$$

（矩阵可逆 ⇔ 窗口内有角点/纹理；平坦区域无法求光流——这是"孔径问题"）

### 5.3 深度光流：FlowNet

用 CNN 直接回归稠密光流：输入两帧拼接（FlowNetS）或两帧分别提特征再关联（FlowNetC），输出 $H\times W\times 2$ 位移场。损失 = 预测与 GT 光流的端到端点距离（EPE）：

$$L = \frac{1}{N}\sum \lVert \hat{\mathbf{u}} - \mathbf{u} \rVert_2$$

### 5.4 动作识别两大范式

| 范式 | 代表 | 思路 |
|:---|:---|:---|
| **Two-Stream** | Simonyan & Zisserman | 空间流（RGB 帧）+ 时间流（堆叠光流），双分支预测后融合 |
| **3D CNN** | C3D、I3D | 把时间当第三维：$3\times3\times3$ 卷积同时看时空；I3D 用 Inception 膨胀 |

I3D 的膨胀（inflation）：把 2D 卷积核复制成 3D（$N_t \times H \times W$），可复用 ImageNet 预训练权重——这是 3D 视频模型能用预训练的关键技巧。

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——LK 光流的孔径问题直觉

```python
# 纯纹理区域（角点）：I_x、I_y 都有变化 → 矩阵满秩 → 光流可解
# 边缘区域：只能确定法向运动（切向模糊）→ 孔径问题
# 平坦区域：I_x ≈ I_y ≈ 0 → 矩阵奇异 → 无法求解
# 结论：光流在平坦区无定义，是"估计"而非"测量"
```

### 例子 2：中等——亮度恒常 + 光流约束（NumPy 验证）

```python
import numpy as np

def brightness_constancy(I1, I2, u, v):
    """亮度恒常残差：理想光流下应为 0"""
    H, W = I1.shape
    ys, xs = np.mgrid[0:H, 0:W]
    x2 = np.clip(xs + u, 0, W - 1).astype(int)
    y2 = np.clip(ys + v, 0, H - 1).astype(int)
    return I2[y2, x2] - I1

rng = np.random.default_rng(0)
I1 = rng.random((16, 16))
I2 = np.roll(np.roll(I1, shift=2, axis=1), shift=1, axis=0)  # 像素整体右移2、下移1
res = brightness_constancy(I1, I2, 2.0, 1.0)
print(f"正确光流残差(roll边界外忽略) ≈ {np.abs(res[2:, 2:]).mean():.4f}")  # 接近 0
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "光流是测出来的" | 光流是估计（约束不足），平坦区无定义 |
| "Two-Stream 的时间流输入是原始帧差" | 是光流（运动向量场），帧差只有一帧的信息且噪声大 |
| "3D CNN 必须从头训练" | I3D 用 2D→3D 膨胀复用预训练权重，训练快很多 |
| "动作识别 = 视频分类" | 是，但长视频需先切片段（temporal segmentation）再分类 |
| "视频分割就是逐帧语义分割" | 还要跨帧一致性（时序平滑/实例跟踪），是视频编辑与跟踪的桥梁 |
