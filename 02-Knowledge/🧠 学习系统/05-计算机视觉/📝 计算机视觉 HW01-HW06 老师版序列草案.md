# 📝 计算机视觉 HW01-HW06 老师版序列草案

> 这份草案不是学生答案，也不是实验报告。  
> 它只解决“老师该怎么布作业”这个问题：
>
> - 学到什么阶段，布哪份 HW；
> - 每份 HW 的教学目的是什么；
> - 最小交付物应该长什么样；
> - 哪些内容是老师该给的，哪些内容要留给学生自己做。

---

## 设计原则

1. **先分类主线，后检测与前沿**  
   先把 `数据 -> 线性模型 -> MLP -> CNN -> 迁移学习` 打稳，再扩到检测、分割和生成。

2. **先从零实现，后工程框架**  
   学生先手写基础模块，再接 PyTorch 训练工作流和工业框架。

3. **先验证正确性，后追求高分**  
   梯度检查、小样本过拟合、统一评测脚本，优先级高于最好准确率。

4. **老师给协议，学生做实验**  
   老师负责 `starter / rubric / data contract / smoke test / report template`，学生负责具体实验与最终结果。

## HW 总表

|:---:|:---|:---|:---|:---|:---|
| HW01 | CIFAR-10 上的 kNN 与 Softmax 基线 | 学完数据处理、距离度量、线性分类后 | NumPy、损失函数、训练/验证/测试切分 | CS231n A1 | baseline 报告、混淆矩阵、失败样本 |
| HW02 | 两层网络与反向传播正确性验证 | 学完反向传播、梯度检查后 | 链式法则、数值梯度、优化基础 | CS231n A1/A2 | 梯度检查、训练日志、小样本过拟合证据 |
| HW03 | 小型 CNN 与训练工程 | 学完卷积、池化、BatchNorm、PyTorch 基础后 | CNN、优化器、数据增强、训练循环 | CS231n A2 + D2L | CNN baseline、公平对照、训练曲线 |
| HW04 | 迁移学习与误差分析 | 学完预训练、特征迁移、校准评估后 | ResNet、预训练、校准、推理成本 | EECS 498 + timm | 冻结/微调对照、误差审计、成本记录 |

| HW06 | 开放课程项目 | 完成前 5 份作业并能稳定复现实验后 | proposal、milestone、实验设计、报告写作 | CS231n Project 风格 | proposal、milestone、final report |

## 每份 HW 为什么排在这里

### HW01：kNN 与 Softmax 基线

- **为什么先布这份**：
  - 学生必须先理解数据、特征、损失和评测；
  - 这份作业是后面所有深度模型的对照基线。
- **老师该给**：
  - CIFAR-10 数据契约；
  - starter；
  - 统一评测脚本；
  - rubric。
- **学生自己做**：
  - 具体超参数；
  - 结果分析；
  - 失败样本解释。
- **正式说明书**：
  - [[18-实战作业说明书/🎓 HW01 - CIFAR-10 kNN 与 Softmax 基线正式作业说明书|进入 HW01 正式作业说明书]]

### HW02：两层网络与反向传播

- **为什么放在 HW01 后面**：
  - 如果学生连梯度与优化都没搞清楚，后面训练 CNN 只是盲调。
- **老师该给**：
  - 数值梯度检查脚本；
  - 小样本过拟合 smoke test；
  - 报告模板。
- **学生自己做**：
  - 网络实现；
  - 损失与梯度调试；
  - 训练过程分析。
- **正式说明书**：
  - [[18-实战作业说明书/🎓 HW02 - 两层网络与反向传播正确性验证正式作业说明书|进入 HW02 正式作业说明书]]

### HW03：CNN 与训练工程

- **为什么是第三份**：
  - 到这里学生才真正第一次“让视觉模型工作起来”；
  - 也是从算法认知过渡到训练工程的关键节点。
- **老师该给**：
  - 统一数据增强边界；
  - 训练日志格式；
  - 最小 CNN starter。
- **学生自己做**：
  - 模型结构改动；
  - 训练调参；
  - 与 HW01/HW02 的公平比较。
- **正式说明书**：
  - [[18-实战作业说明书/🎓 HW03 - 小型 CNN 与训练工程正式作业说明书|进入 HW03 正式作业说明书]]

### HW04：迁移学习与误差分析

- **为什么不是更早**：
  - 学生必须先亲手训练过模型，才能理解“预训练模型到底帮了什么”。
- **老师该给**：
  - 冻结 / 微调任务定义；
  - 成本统计口径；
  - 类别级误差分析模板。
- **学生自己做**：
  - 选择 backbone；
  - 增强策略；
  - 误差归因。
- **正式说明书**：
  - [[18-实战作业说明书/🎓 HW04 - 迁移学习与误差分析正式作业说明书|进入 HW04 正式作业说明书]]

### HW05：检测或分割专题

- **为什么放在第五份**：
  - 检测和分割的协议更复杂；
  - 在分类主线没稳前，不值得过早扩题。
- **老师该给**：
  - 数据格式说明；
  - 最小配置化 starter；
  - smoke test；
  - mAP 或 IoU 评测脚本。
- **学生自己做**：
  - 模型训练；
  - 可视化；
  - 工程调试与专题实验。
- **正式说明书**：
  - [[18-实战作业说明书/🎓 HW05 - Pascal VOC 最小目标检测工程包正式作业说明书|进入 HW05 正式作业说明书]]

### HW06：开放课程项目

- **为什么最后才开**：
  - 只有学生已经具备独立搭建实验协议的能力，project 才有意义。
- **老师该给**：
  - proposal 模板；
  - milestone 节点；
  - final report 模板；
  - grader notes。
- **学生自己做**：
  - 选题；
  - 实验设计；
  - 最终实现与结论。
- **正式说明书**：
  - [[18-实战作业说明书/🎓 HW06 - 开放课程项目正式作业说明书|进入 HW06 正式作业说明书]]

## 第一份最适合先落地成真实作业包的是哪份

我建议优先顺序：

1. `HW01`
2. `HW03`
3. `HW04`

原因：

- `HW01` 最适合做整条课的门面；
- `HW03` 最能代表“视觉课程真正进入模型训练”；
- `HW04` 最能体现老师视角下的误差分析与工程判断。
