# 迁移学习与微调

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：迁移学习是 CS231n Assignment3 与本地 HW04 的主题，也是工业界训练任何视觉模型的默认起点（用 ImageNet/CLIP 预训练权重起步）。它把"训练"从"随机初始化从头学"变成"在好起点上精修"，涉及冻结/解冻、学习率、数据量权衡等一整套工程决策，几乎每次面试都会被问。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 假设我们只有 5000 张"猫狗鸟"图片，想训练一个分类器。如果随机初始化一个 ResNet 从头训练：① 数据太少，深层网络会严重过拟合（训练集 95%，测试集 60%）；② 训练要几百轮、耗 GPU 数天；③ 结果还远不如别人。但 ImageNet 上已经有人花了几十万 GPU 小时、用 128 万张图训好了 ResNet——它学会的"边缘→纹理→部件→物体"的层次特征，绝大多数与具体类别无关，可以直接借用。
> 因此必须引入**迁移学习**：把预训练模型的权重作为起点（或冻结为特征提取器），只在小数据上"微调"（fine-tune）少量部分，用极小代价获得远超从头训练的效果。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW04（迁移学习与误差分析）直接考察本知识点；Assignment3 的 PyTorch 版 ResNet 作业、以及后续检测/分割（[[目标检测与图像分割 (Object Detection & Segmentation)]]）、CLIP（[[🎯 SimCLR 与对比学习 (Contrastive Learning)]]）都建立在"预训练 + 微调"范式上。
- **实际应用场景**：医疗影像（数据稀缺）、工业质检、个性化分类——几乎任何非 ImageNet 规模的视觉任务；开源生态（timm、MMPretrain）就是为微调而生的（见 [[🧭 计算机视觉开源作业源地图]] 中 timm 的定位）。
- **高频题型/任务**：判断"该冻结还是全微调"；选择微调学习率（通常比从头训练小 1-2 个数量级）；解释为什么小数据下先冻结 backbone 再解冻；评估预训练与随机初始化在新数据集上的差距。

## 4. 用直觉语言解释它

> «"迁移学习就像请一位资深厨师来新餐厅：他不用从'认识鸡蛋'学起，只需熟悉新菜单（新数据集）。一开始只让他按老规矩备菜（冻结 backbone，只训练新加的分类头），等新菜品稳定了，再让他微调自己的拿手手法（解冻部分层、小学习率精修）。如果直接让他全部推倒重学（随机初始化），新餐厅食材太少，他反而会学出一身怪毛病（过拟合）。">

- **直觉类比/几何图像**：预训练权重 = 特征空间里的"好地图"，新任务只需在好地图上微调；从头训练 = 在陌生地形重新测绘。几何上，预训练特征把输入映射到"语义对齐"的高维空间，新分类器只需要在这个空间里画一个简单的超平面。
- **为什么很自然**：因为视觉低层特征（边缘、纹理）在不同数据集间几乎通用，只有高层语义需要适配——"共享通用、适配特化"是自然的层次化策略。
- **一句话直觉本质**：**把大数据集上学到的通用表示作为起点：小数据时冻结大部分层只练分类头，数据够时用更小的学习率全量精修，用最少数据与算力获得最强性能。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **迁移学习（Transfer Learning）**：把在源任务（如 ImageNet 分类）上学到的模型参数 $\theta_S$ 作为目标任务（如猫狗分类）的初始化或特征提取器。
- **微调（Fine-tuning）**：在预训练权重基础上，用目标任务数据继续训练（全部或部分参数），通常配以更小的学习率。
- **冻结（Freeze）**：某层参数的梯度置零、不更新，仅作前向特征提取。

### 2. 核心公式
预训练：$\theta_S = \arg\min_\theta \mathcal{L}_S(\theta; \mathcal{D}_S)$（源域，大数据集）
微调：$\theta_T = \arg\min_\theta \mathcal{L}_T(\theta; \mathcal{D}_T),\quad \theta^{(0)} = [\theta_S^{\text{backbone}};\, \theta_{\text{head}}^{(0)}]$

$$\text{更新规则}：\theta \leftarrow \theta - \eta_{\text{ft}} \nabla_\theta \mathcal{L}_T,\qquad \eta_{\text{ft}} \ll \eta_{\text{scratch}}$$
冻结层：$\nabla_{\theta_{\text{frozen}}} \mathcal{L}_T = 0$（等价于不更新该部分参数）

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathcal{D}_S, \mathcal{D}_T$ | 源域、目标域数据集 | 图像-标签对集合 | 源域远大于目标域 |
| $\theta_S, \theta_T$ | 源任务/目标任务参数（含新分类头 $\theta_{\text{head}}$，随机初始化） | 向量 | 微调起点 $\theta_T^{(0)} \approx \theta_S$ |
| $\eta_{\text{ft}}$ | 微调学习率 | 通常 $10^{-4}\sim10^{-3}$ | 比从头训练小 1-2 个数量级 |
| $\text{freeze}$ | 冻结层集合 | 布尔掩码 | 梯度置零 |

### 4. 常见变体与适用条件
- **适用条件**：目标数据集与源域任务相关（视觉任务间几乎总是相关）；数据量小或算力有限时收益最大。
- **限制条件**：目标域与源域差异极大（如从自然图像迁移到医疗内镜图像）时，浅层特征仍需解冻重学；类别数改变时必须替换分类头；预训练任务与目标任务差距过大（如文本→图像）时不适用。

## 6. 推导思路和思想来源

- **最初困难**：小数据上从头训练深度网络必然过拟合，且算力昂贵。
- **直接方法局限**：数据增强、正则化只能缓解，无法凭空创造数据；模型越大越缺数据。
- **关键"转念"**：**特征是可复用的资产，而不是任务专属品**——在 ImageNet 上"顺便"学到的通用视觉表示，可以原样移植到新任务，这就是"表示学习"（representation learning）思想：先学通用表示，再学任务头。
- **推导主线与动机**：① 观察：CNN 浅层学边缘/纹理（与类别无关），深层学语义（与类别相关）；② 因此浅层可以直接借用（冻结），深层与新分类头需要适配（微调）；③ 预训练权重已接近局部最优，大步更新会破坏好特征 → 微调用小学习率；④ 数据量越少，可安全更新的参数越少（冻结越多）——形成"数据量 → 冻结程度"的经验法则。
- **为什么自然得到此结论**：因为"通用 vs 特化"的层次化分界是 CNN 结构的自然结果，策略只是顺应结构。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：用 ImageNet 预训练 ResNet18 微调到 5 类自定义数据集。原分类头输出 1000 类，新任务 5 类，模型总参数 11.2M，backbone 占 11.1M。问：分类头怎么改？冻结 backbone 后可训练参数量是多少？
- **解题思路与关键步骤**：替换最后一层全连接：`fc: 512 → 1000` 改为 `fc: 512 → 5`（仅新头随机初始化）；冻结 backbone = 将其参数的 `requires_grad` 置 False，只训练新头。
- **最终答案**：可训练参数 = 新头参数量 $512 \times 5 + 5 = 2565$（约 0.02% 总参数）；训练 10 轮内即可收敛到不错精度。
- **易错点**：忘记偏置项（+5）；或把 backbone 的 BN 层也冻结导致 running 统计量不更新（应让 BN 保持可更新）。
- **🤔 追问**：如果目标类别数恰好也是 1000，能不能直接沿用原分类头？——可以但不推荐：原头拟合的是 ImageNet 类别，直接使用等于零样本分类；仍应至少微调。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：两个团队在同一数据集（5 万张工业零件图）上做缺陷分类：A 用随机初始化 ResNet50 从头训练，B 用 ImageNet 预训练权重微调（学习率 1e-3）。请比较并解释。
  - 解：B 通常 5-20 轮达到 A 需要 100+ 轮才到的精度，且最终精度更高、更稳。**关键推理**：① 预训练提供了通用特征，A 要从零学这些特征；② 但零件图与自然图像差异大，B 也应解冻后几层让高层特征适配，不能只冻 backbone 训头；③ B 的 BN 层需要热启动：先以训练模式跑若干 batch 更新 running 统计量再正式训练。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW04 的标准流水线：`timm.create_model('resnet50', pretrained=True)` → 替换 `model.fc` → 先冻结 backbone 训头 5 轮 → 解冻全模型用小学习率微调 10 轮 → 对比"从头训练"baseline 并做误差分析（混淆矩阵、错误样本聚类）。这与 CS231n Assignment3 的 `Transfer Learning` notebook 完全同构。
- 代码形态（伪码）：
```python
model = timm.create_model('resnet50', pretrained=True)
model.fc = nn.Linear(2048, 5)                 # 替换分类头
for p in model.parameters(): p.requires_grad = False
for p in model.fc.parameters(): p.requires_grad = True   # 阶段1：只训头
for p in model.parameters(): p.requires_grad = True   # 阶段2：解冻全部，lr=1e-4
```

## 8. 常见误区和易混概念

### 误区 1：以为"微调 = 直接小学习率全量训练"
- **错误直觉**：加载预训练权重后，直接全量小学习率训练就行。
- **为什么错**：小数据下全量微调仍会过拟合，且浅层预训练特征被破坏；分类头是随机初始化的，一开始梯度很大，需要先单独训练头（或给头更大的学习率）。
- **正确理解**：标准做法是分阶段：先冻结 backbone 训头，再解冻以小学习率精修；或使用分层学习率（头大、浅层小）。

### 误区 2：以为预训练权重"万无一失"，直接跳过误差分析
- **错误直觉**：用了预训练模型就一定能超过从头训练。
- **为什么错**：当目标域与源域差异极大、或预训练任务不匹配（如用分类预训练做像素级分割的初始化）时，迁移收益可能为负（负迁移 negative transfer）。
- **正确理解**：HW04 要求同时跑"从头训练 baseline"对照，用数据说话；特征分布差异大时考虑域自适应。

### 概念对比表

| 概念 | 参数起点 | 所需数据/算力 | 典型场景 |
| :--- | :--- | :--- | :--- |
| 从头训练 | 随机初始化 | 数据多、算力足 | 新任务与源域差异极大、无预训练模型 |
| 迁移学习/微调 | 预训练权重 | 小数据即可 | 视觉任务默认起点（本知识点） |
| 特征提取（冻结） | 预训练权重不动 | 极少数据 | 分类头可训练、backbone 冻结 |
| 领域自适应 | 预训练 + 域对齐 | 目标域无标签 | 域偏移大（见 [[迁移学习CV]]） |

### 题目与解析

#### 1. 迁移学习与从头训练的核心区别是什么？何时必须从头训练？
> [!question]- 答案解析
> - **答案**：迁移学习用预训练权重作起点（继承通用特征），从头训练随机初始化；当目标域与源域差异极大、无可用预训练模型、或预训练任务与目标任务无关（负迁移风险高）时，从头训练更合理。
> - **解析**：迁移的收益来自"特征可复用"，前提是两任务共享底层结构。
> - **易错原因**：以为迁移学习总是最优——忽略负迁移。
#### 2. ResNet18 backbone 11.1M 参数，原分类头输出 1000 类（512→1000），改为 5 类后冻结 backbone，可训练参数量是多少？
> [!question]- 答案解析
> - **答案**：$512 \times 5 + 5 = 2565$。
> - **解析**：新头 = 权重矩阵 $512\times5$ + 偏置 5；backbone 全部冻结不参与更新。
#### 3. 训练数据只有 500 张时，应该冻结 backbone 只训头，还是全量微调？为什么？
> [!question]- 答案解析
> - **答案**：冻结 backbone 只训头（必要时只解冻最后 1-2 个 block）。
> - **解析**：数据太少，全量微调会破坏预训练特征并过拟合；冻结相当于用正则化保护通用特征。
#### 4. 微调时学习率为什么要比从头训练小 1-2 个数量级？阶段二（解冻后）与阶段一（只训头）的学习率如何安排？
> [!question]- 答案解析
> - **答案**：预训练权重已接近好的局部最优，大步更新会破坏通用特征；阶段一（头随机初始化）用较大学习率（如 1e-2）快速拟合新头，阶段二解冻后用小学习率（如 1e-4）精修全部参数。
> - **解析**：头是"新学生"需要快学，backbone 是"老专家"只能慢调——分层学习率/分阶段训练正是这一不对称的体现。
#### 5. 为什么 ImageNet 上学到的特征能迁移到"猫狗鸟"小数据集？请用 CNN 的层次结构论证。
> [!question]- 答案解析
> - **答案**：CNN 浅层学的是边缘、颜色、纹理等与类别无关的通用结构（任何图像都有），深层学的是与 ImageNet 类别绑定的语义组合；新任务的低层结构与源任务共享，只有高层需要适配。因此冻结浅层 + 微调深层 + 新分类头即可，且预训练相当于把"低层特征学习"这一最耗数据的部分外包给了大数据集。
> - **解析**：这是"表示学习"的核心理由：通用表示跨任务复用，特化部分按任务定制。
