# 计算机视觉｜微积分与链式法则最小桥接

## 本课程需要什么

只要求你理解**导数 = 变化率**、**偏导 = 对某一个变量的导数**、**链式法则 = 复合函数逐层求导相乘**。这三件事足够看懂反向传播（阶段2）与梯度下降（阶段1）的全部推导。本卡**不要求**会算复杂积分、级数或多元微积分的全部技巧；完整微积分体系请去 [[02-Knowledge/🧠 学习系统/06-常微分方程/00-前置知识/常微分方程-微积分基础|常微分方程-微积分基础]]。

## 最小规则

1. 导数 $f'(x)$ 表示 $x$ 变化一点点时 $f$ 变化得多快；
2. 偏导数 $\frac{\partial f}{\partial w}$ 是"只动 $w$、其他变量冻结"的导数；
3. 链式法则：若 $z = f(y)$、$y = g(x)$，则 $\frac{dz}{dx} = \frac{dz}{dy}\cdot\frac{dy}{dx}$——把"梯度"沿复合路径逐层传下去，这正是反向传播的名字来源。

## 1. 为什么微积分是视觉深度学习的前置

训练神经网络 = 最小化损失 $L$。优化器（SGD/Adam）每步要回答一个问题："参数 $w$ 变大一点点，损失 $L$ 是变大还是变小、变多少？" 答案就是 $\frac{\partial L}{\partial w}$（梯度）。求这个梯度要穿过网络几十层复合函数，只能靠链式法则逐层回传。所以：**没有链式法则，就没有反向传播，也就没有可训练的神经网络。**

## 2. 正式定义与符号

| 概念 | 定义 | 记号 |
|:---|:---|:---|
| 导数 | $f'(x) = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}$ | $f'(x)$、$\frac{df}{dx}$ |
| 偏导数 | 对多元函数只对 $w$ 求导，其余变量视为常数 | $\frac{\partial f}{\partial w}$ |
| 梯度 | 把所有偏导排成向量 | $\nabla_w L = \left(\frac{\partial L}{\partial w_1}, \dots, \frac{\partial L}{\partial w_n}\right)$ |
| 链式法则（多元） | $L = f(y)$、$y = g(w)$ → $\frac{\partial L}{\partial w} = \frac{\partial L}{\partial y}\cdot\frac{\partial y}{\partial w}$ | 逐层相乘 |

常用导数（反向传播必备）：$\frac{d}{dx}x^2 = 2x$；$\frac{d}{dx}e^x = e^x$；$\frac{d}{dx}\ln x = \frac{1}{x}$；$\frac{d}{dx}\sigma(x) = \sigma(x)(1-\sigma(x))$（sigmoid 的性质）。

## 3. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——链式法则手算

$z = \sin(x^2)$。设 $y = x^2$，则 $z = \sin y$：
$\frac{dz}{dx} = \frac{dz}{dy}\cdot\frac{dy}{dx} = \cos(y)\cdot 2x = 2x\cos(x^2)$。

### 例子 2：中等——两层网络的梯度回传（数值对照）

网络 $y = w_2 \cdot \sigma(w_1 x)$，损失 $L = \frac12(y - t)^2$。对 $w_2$：

$\frac{\partial L}{\partial w_2} = \frac{\partial L}{\partial y}\cdot\frac{\partial y}{\partial w_2} = (y-t)\cdot \sigma(w_1 x)$。

对 $w_1$ 要连乘两层（链式法则穿过 sigmoid）：

$\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial y}\cdot\frac{\partial y}{\partial a}\cdot\frac{\partial a}{\partial w_1}$，其中 $a = w_1 x$，$\frac{\partial y}{\partial a} = \sigma(a)(1-\sigma(a))\cdot w_2$，$\frac{\partial a}{\partial w_1} = x$。

```python
import numpy as np

def grad_numerical(x, w1, w2, t, eps=1e-6):
    """数值梯度：用导数定义 f'(x) ≈ (f(x+h)-f(x-h))/(2h) 对照解析梯度"""
    def loss(w1_, w2_):
        y = w2_ * (1 / (1 + np.exp(-w1_ * x)))
        return 0.5 * (y - t) ** 2
    g_w1 = (loss(w1 + eps, w2) - loss(w1 - eps, w2)) / (2 * eps)
    g_w2 = (loss(w1, w2 + eps) - loss(w1, w2 - eps)) / (2 * eps)
    return g_w1, g_w2

x, w1, w2, t = 2.0, 0.5, 1.5, 0.0
# 解析梯度（例子 2 公式）
y = w2 * (1 / (1 + np.exp(-w1 * x)))
a = w1 * x
s = 1 / (1 + np.exp(-a))
g_w1_an = (y - t) * (s * (1 - s) * w2) * x
g_w2_an = (y - t) * s
g_w1_nu, g_w2_nu = grad_numerical(x, w1, w2, t)
print(f"解析: dw1={g_w1_an:.6f} dw2={g_w2_an:.6f}")
print(f"数值: dw1={g_w1_nu:.6f} dw2={g_w2_nu:.6f}")
# 期望输出两组数值接近（相对误差 < 1e-5）
assert abs(g_w1_an - g_w1_nu) < 1e-5
assert abs(g_w2_an - g_w2_nu) < 1e-5
print("链式法则梯度与数值梯度一致 ✔")
```

### 例子 3：应用——Softmax 交叉熵梯度的"省力结论"

损失 $L = -\log \frac{e^{z_y}}{\sum_j e^{z_j}}$。直接用链式法则可以推出惊人简洁的结论：$\frac{\partial L}{\partial z_i} = p_i - \delta_{iy}$（$p_i$ 是 softmax 概率，$\delta_{iy}$ 在正确类别处为 1）。这个结果在 [[02-Knowledge/🧠 学习系统/05-计算机视觉/02-深度学习内核/Softmax与SVM损失函数|Softmax与SVM损失函数]] 中有完整推导；本卡只要求你相信"链式法则能推出它"，不必现在重推。

## 4. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| 链式法则是"乘法"但方向搞反 | 从输出往输入逐层传：$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial y}\cdot\frac{\partial y}{\partial w}$，先算输出端再往输入端 |
| 混淆"导数"与"梯度" | 导数对一元函数；梯度是把多元函数所有偏导排成向量 |
| 忘记冻结其他变量 | 求 $\frac{\partial f(x, y)}{\partial x}$ 时把 $y$ 当常数 |
| 手算 0/0 或无穷 | 极限只在 $h\to0$ 下讨论；数值验证用小的有限 $h$（如 1e-6） |
