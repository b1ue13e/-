# 🧭 阶段0：前置知识（数学与编程速通）

> "如果你已经熟悉线性代数、概率论、微积分和 Python/NumPy，可以跳过本阶段直接进入[[🧭 阶段1-底层基石|第一阶段]]；不确定的话先做「🚪 诊断入口与最低标准」自检。"

## 🚪 谁需要过这一关？

- 数学基础薄弱（矩阵运算手生、导数/链式法则忘了）
- 不熟悉 NumPy 向量化思维
- 需要快速激活"数学肌肉记忆"与编程手感

### 🎯 速通目标

- [ ] 能手算 3×3 矩阵的特征值和特征向量
- [ ] 理解贝叶斯定理：P(A|B) = P(B|A)P(A)/P(B)
- [ ] 能手写梯度下降的三步更新：x_{t+1} = x_t - η∇f(x_t)
- [ ] 能用链式法则推导两层网络的梯度回传
- [ ] 能用 NumPy 完成图像的基本读写和矩阵运算（不用 for 循环）

### 🔗 关卡衔接

> 速通后进入 → [[🧭 阶段1-底层基石|第一阶段：底层基石]]，正式开始计算机视觉学习。

> 🛠️ **卡住时的兜底路径**：从 HW01 起，只要遇到跑不通、报错读不懂、loss 不下降，直接查 [[计算机视觉-训练调试与常见报错|训练调试与常见报错]]（三层定位法 + 报错速查表）。不要靠盲目调超参试错。
