## 🧭 单源充分性判断（§4.2）

**结论**：本课程采用 **单 Spine（D2L）+ 验收源（CS231n）** 模式，不构成多主教材融合，记录单源充分性判断。

| 维度 | 判断 |
|:---|:---|
| 知识主线 | D2L Ch.4-5/7-8/11/13/14/17 完整覆盖线性网络→CNN→注意力→检测分割→GAN，构成连续知识主线 |
| 知识缺口 | D2L 未覆盖的传统视觉（SIFT/滤波/几何）由 CVAA 补充（辅助参考，非 Spine）；3D/部署由阶段5 专题补建 |
| 验收源 | CS231n A1-A3/Final 只作作业与验收口径，不定义知识主线（避免双 Spine 术语冲突） |
| 为什么不用双 Spine | CS231n 讲义与 D2L 高度重叠（同教 CNN/检测），并行会引入重复与术语差异；用 D2L 定义主线、CS231n 验收，职责分离 |
| 补充边界 | CVAA/《Deep Learning》等仅作缺口补充，退出条件：D2L+阶段专题覆盖后不再引入 |

> 按 §4.2：单 Spine 足够时不做多源融合评分；若未来引入第二个并行知识主线（如 CS231n 讲义作为独立 Spine），须执行多源融合自评（≥85）后发布。

> 这一页只做一件事：把计算机视觉需要的书按“传统视觉 -> 深度学习 -> 核心任务 -> 前沿架构 -> 3D 与部署”挂起来，避免你只会堆模型名，不知道每本书到底解决哪一段问题。

> 缺的书统一记在 [[📥 PDF教材待下载清单|PDF教材待下载清单]]，请通过合法来源获取。

## 🪜 建议阅读顺序

1. 先补 `Computer Vision: Algorithms and Applications`，同时用 `Mathematics for Machine Learning` 打好第一阶段的数学和表示底座。
2. 第二步进入 `Deep Learning` + `Hands-on Machine Learning`，把第二阶段的训练、优化和实验框架补齐。
3. 第三步用 `动手学深度学习` 和视觉主教材推进分类、检测、分割等任务。
4. 最后再补 `Multiple View Geometry`，把第五阶段的 3D 视觉与工程落地做深。
