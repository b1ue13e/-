# 视觉-语言多模态模型（ALIGN / BLIP / LLaVA）

## 0. 先判断它值不值得深挖

**B 类专题（前沿主线）**。CLIP 用对比学习把图像与文本对齐到同一空间；本卡回答"CLIP 之后多模态往哪走"：**更大规模噪声数据**（ALIGN）、**理解+生成统一**（BLIP）、**视觉+大语言模型对话**（LLaVA）。这是 2021-2024 视觉-语言模型的三条主线，也是"AI Agent 看世界"的基础组件。合并 MOC 中 ALIGN / BLIP / LLaVA 三个规划项。

## 1. 这个知识点解决什么问题？

- CLIP 对齐了图文，但**只做对比检索**：不能生成文本（caption）、不能做细粒度问答、不能多轮对话；
- 高质量图文对数据稀缺且昂贵——ALIGN 用 18 亿**噪声**图文对证明"数据规模可以弥补数据质量"；
- 需要"一个模型同时做理解与生成"（BLIP）、"视觉输入接入 LLM 对话"（LLaVA）的任务。

## 2. 为什么它重要？它有什么用？

- 图像描述（captioning）、视觉问答（VQA）、图文检索、零样本分类；
- LLaVA 类 VLM 是"多模态 AI Agent/机器人视觉"的基础（看屏幕、看图回答问题）；
- 理解数据规模（ALIGN）与损失设计（BLIP 的 CapFilt）对训练策略有直接指导意义。

## 3. 学它之前需要哪些前置知识？

- 图文对齐基础：[[CLIP]]（对比学习、InfoNCE）；
- 序列建模：[[Transformer与自注意力]]（cross-attention 交叉注意力）。

## 4. 用直觉语言解释它

CLIP 是"图文配对学家"：学会了"这张图配哪句话"。ALIGN 把配对数据从 4 亿张精挑细选扩到 18 亿张"网上随便抓的"，发现噪声数据也能学——**数据量大到一定程度，质量就没那么重要了**。BLIP 更进一步：让模型既会"配对打分"又会"看图写话"，还用模型自己生成的 caption 过滤噪声数据（自举）。LLaVA 则是给 GPT-4V 类能力搭了个开源骨架：把 CLIP 的视觉编码器接上一个大语言模型（LLaMA/Vicuna），用图文指令微调，就能"看着图聊天"。

## 5. 正式定义、核心公式、符号解释

### 5.1 ALIGN：噪声数据 + 双编码器

架构同 CLIP（双塔对比），但训练数据是 18 亿对**弱对齐**图文对（网页 alt-text），损失仍为 InfoNCE 式对比损失。结论：数据规模每提升一个数量级，零样本迁移持续改善，噪声对检索任务影响有限。局限：编码器无法做生成/细粒度推理。

### 5.2 BLIP：统一理解与生成（CapFilt 自举）

三个模块共享视觉编码器：

| 模块 | 角色 | 损失 |
|:---|:---|:---|
| ITC（图文对比） | 对齐表示 | 对比损失（同 CLIP） |
| ITM（图文匹配） | 判断"图-文是否匹配" | 二分类损失 |
| LM（语言建模） | 给定图生成文本 | 自回归生成损失 |

**CapFilt**：用模型给噪声图文对**生成 caption**（Cap），再用 ITM **过滤**不匹配对（Filt）——模型自我净化训练数据，效果超过纯人工标注。

### 5.3 LLaVA：视觉 + 大语言模型

结构：CLIP 视觉编码器 $V$ → 可训练投影层 $W$ → LLM（如 Vicuna/LLaMA）。

$$h_v = W \cdot V(x), \qquad \text{LLM}([h_v; h_q]) \to \text{response}$$

训练两阶段：
1. **特征对齐预训练**：冻结视觉编码器与 LLM，只训投影层（图文配对数据）；
2. **指令微调**：用 GPT-4 生成的图文指令数据微调投影层 + LLM，使其能看图对话（VQA、描述、推理）。

核心贡献：用**语言模型生成训练数据**（由图片+bbox+caption 构造指令），解决了"指令数据标注昂贵"的问题。

### 例子 2：中等——BLIP 的 ITM 判断（伪代码）

```python
import torch
import torch.nn.functional as F

def itm_score(image_emb, text_emb):
    """图文匹配：拼接跨模态特征后二分类"""
    fused = torch.cat([image_emb, text_emb], dim=-1)     # (N, 2d)
    return torch.sigmoid(F.linear(fused, torch.randn(1, 2 * fused.shape[-1])))
# 训练：匹配对 label=1，不匹配对 label=0；推理时用该分数过滤噪声 caption
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "ALIGN 与 CLIP 架构不同" | 架构几乎相同，差异在数据规模与质量策略 |
| "BLIP 就是加了生成头的 CLIP" | BLIP 的 CapFilt 自举（生成→过滤）是数据层面的关键创新 |
| "LLaVA 直接端到端训全部" | 先冻结两端只训投影，再指令微调——训练稳定性依赖分阶段 |
| "VLM 不需要视觉编码器" | 视觉 token 质量决定 VLM 上限，CLIP 编码器是主流底座 |
| "多模态只有理解没有生成" | BLIP 有生成；LLaVA 可对话生成；扩散模型（SD）是生成侧的另一支 |
