# 姿态估计（Pose Estimation：2D/3D）

## 0. 先判断它值不值得深挖

**A 类核心概念（多人场景高频任务）**。姿态估计输出人体/物体的**关键点**（关节位置），是动作识别、人机交互、自动驾驶行人意图、医疗康复、动画驱动的底层能力。本卡合并 MOC 中 OpenPose / HRNet / SimpleBaseline / 单目3D / 多视角 五个规划项——2D 与 3D 姿态是同一任务的两级，且"单目3D/多视角"与阶段5 相机标定共享几何基础，合并成一张总卡避免碎片。

## 1. 这个知识点解决什么问题？

- 检测/分割回答"人在哪、轮廓是什么"；姿态估计回答"人的**骨架**长什么样"（头、肩、肘、腕、髋、膝、踝的位置）；
- 输出形式：每个关键点 $(x, y, \text{confidence})$，或 3D 关键点 $(x, y, z)$；
- 难点：遮挡（关节被身体挡住）、多人交错（谁的手是谁的）、小目标、自遮挡。

## 2. 为什么它重要？它有什么用？

- 动作识别/行为分析、人机交互（手势）、体育分析、康复评估、自动驾驶行人姿态；
- 多人姿态估计是"自顶向下 vs 自底向上"两大学派的分水岭，理解它 = 理解检测与分组的两类设计哲学；
- 3D 姿态把"2D 图像 → 3D 世界"的逆问题具象化，衔接阶段5 多视图几何。

## 4. 用直觉语言解释它

姿态估计就是"给身体关节装钉子"。2D 方法让网络对每个关节输出一张"热力图"——图上最亮的位置就是关节最可能存在的地方。多人怎么办？两条路：**自顶向下**——先检测出每个人（框），再在框里找关节（快但依赖检测质量）；**自底向上**——先找出所有关节，再判断哪些关节属于同一个人（如 OpenPose 的 PAF 向量场把"手腕"和"手肘"配对）。3D 姿态则在 2D 基础上再预测深度，或从多视角三角化。

## 5. 正式定义、核心公式、符号解释

### 5.1 热力图（Heatmap）表示

对第 $k$ 个关键点，GT 热力图是中心在高斯点上的二维分布：

$$H_k(x, y) = \exp\left(-\frac{(x-\mu_{kx})^2 + (y-\mu_{ky})^2}{2\sigma^2}\right)$$

网络输出 $K$ 张热力图，训练用 MSE；推理取每张热力图的最大值位置作为关键点。相比直接回归坐标，热力图保留空间不确定性、天然适合 CNN 的平移不变性。

### 5.2 两大学派

| 学派 | 代表 | 流程 | 优点 | 缺点 |
|:---|:---|:---|:---|:---|
| **自顶向下 Top-Down** | SimpleBaseline、HRNet | 先检测人框 → 每框单人姿态 | 精度高 | 速度随人数下降，依赖检测 |
| **自底向上 Bottom-Up** | OpenPose | 先找全部关键点 → 分组 | 速度与人数无关 | 分组难，精度略低 |

### 5.3 OpenPose 的 PAF（Part Affinity Fields）

分组的关键创新：不仅预测关键点，还预测**每对相邻关节之间的 2D 向量场** $\mathbf{L}_{c}(\mathbf{p})$——向量指向"从哪个关节连到哪个关节"。配对评分 = 沿两点连线的 PAF 向量积分，再用匈牙利匹配求最优二分匹配（贪心松弛）。PAF 让网络同时学到"关节点在哪"和"关节之间如何连接"，解决了密集人群的配对歧义。

### 5.4 SimpleBaseline 与 HRNet

- **SimpleBaseline**：ResNet 提取特征 → 反卷积（deconv）上采样回高分辨率 → 输出热力图。证明"简单反卷积 + 预训练"即可达到 SOTA，是 2018 年的强基线；
- **HRNet**：全程保持**高分辨率特征**，各分辨率并行、反复融合（交换单元），避免"先降后升"的信息损失，是关键点/分割通用的强骨干。

### 5.5 3D 姿态

- **单目 3D**：从单张 2D 图像直接回归/提升到 3D 骨架 $J_{3D} = g(J_{2D})$（2D→3D lifting），病态但可用先验约束；深度信息缺失导致尺度歧义；
- **多视角**：多个相机同时观测，用三角测量恢复 3D 位置（需相机内外参，见阶段5 标定卡）——几何上可靠，是数据集/运动捕捉的标准做法。

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——热力图生成（NumPy）

```python
import numpy as np

def make_heatmap(h, w, cx, cy, sigma=2.0):
    ys, xs = np.mgrid[0:h, 0:w]
    return np.exp(-((xs - cx) ** 2 + (ys - cy) ** 2) / (2 * sigma ** 2))

H = make_heatmap(64, 64, 30.0, 40.0)   # 关节在 (30, 40)
print(f"峰值位置 = ({H.argmax() // 64}, {H.argmax() % 64})")   # 输出 (40, 30)，即 (y=40, x=30)
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "自底向上一定比自顶向下快" | OpenPose 速度与人数无关，但精度通常低于 top-down；HRNet 系 top-down 仍是精度标杆 |
| "热力图峰值就是精确关节" | 峰值受分辨率限制，可用质心/亚像素（soft-argmax）细化 |
| "3D 姿态 = 2D 姿态 + 一个网络" | 单目 3D 有尺度歧义（病态）；多视角需相机标定，几何与学习方法结合 |
| "PAF 只是向量图" | PAF 编码了关键点之间的连接（属于谁的证据），是分组问题的核心 |
| "姿态估计 = 人体检测" | 检测输出框，姿态输出骨架关键点；两者常用但不同 |
