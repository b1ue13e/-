# 长尾分布与类别不平衡（Long-Tail & Class Imbalance）

## 0. 先判断它值不值得深挖

**A 类核心概念**。真实世界数据集几乎都是长尾的：少数"头类"（猫、狗、人）占据大部分样本，大量"尾类"（稀有物种、罕见缺陷）样本极少。如果直接训练，模型会偏向头类、把尾类全部分错。本卡是"真实世界数据"场景（MOC 标注）下分类与检测都绕不开的问题，也是 HW05（PASCAL VOC 检测）里背景类与难例问题的根源。

## 1. 这个知识点解决什么问题？

标准交叉熵损失对所有样本一视同仁。当类别样本数相差 1000 倍时，梯度被头类主导，尾类几乎没有学习信号——模型学到的决策边界完全偏向头类。本卡解决三个问题：

1. 如何**度量**不平衡程度？
2. 有哪些**对策**（数据层 / 损失层 / 训练策略层）？
3. 为什么现代方法（decoupled、两阶段训练）更有效？

## 2. 为什么它重要？它有什么用？

- 工业场景（缺陷检测、医疗影像、自动驾驶稀有场景）几乎全是长尾数据；
- 检测任务中"前景 vs 背景"本身就是极端不平衡（背景框占 99%+），Focal Loss 因此诞生；
- 盲目上采样/欠采样会过拟合或丢失信息；盲目重加权会梯度爆炸——需要理解每类方法的代价。

## 4. 用直觉语言解释它

想象一个班 99 个学生考 90 分、1 个学生考 40 分，平均分 89.5——那 1 个差生被"淹没"了。长尾问题同理：头类样本多，把损失均值拉低；尾类贡献的梯度可以忽略不计。对策就是想办法"给那 1 个学生单独补课"：要么多让他做题（过采样），要么把他的错题权重放大（重加权），要么干脆先学会平均分再单独调他的题（两阶段）。

## 5. 正式定义、核心公式、符号解释

### 5.1 度量

不平衡比（imbalance ratio）$R = N_{\max}/N_{\min}$：最多样本类与最少样本类的数量比。$R > 100$ 视为严重长尾。长尾系数（Gini 系数或 $1/\sum p_i^2$）度量分布集中度。

### 5.2 数据层对策

| 方法 | 做法 | 代价 |
|:---|:---|:---|
| 随机过采样 | 复制尾类样本 | 过拟合（复制品） |
| 随机欠采样 | 丢弃头类样本 | 信息丢失 |
| 类别平衡采样 | 每个 batch 按类别均匀采样 | 训练不稳定，需调参 |
| 数据增强过采样 | 对尾类做更强增广 | 最推荐，缓解过拟合 |

### 5.3 损失层对策：重加权与 Focal Loss

加权交叉熵：给每个样本按类别权重 $w_c$ 加权，

$$L = -\frac{1}{N}\sum_{i=1}^{N} w_{y_i} \log p_{y_i}, \qquad w_c \propto \frac{1}{N_c^\gamma}$$

$\gamma \in [0,1]$ 控制权重强度（$\gamma=0$ 退化为普通 CE）。常用 $\gamma = 1$（反频率）。

**Focal Loss**（检测任务的类别不平衡）：

$$L_{\text{focal}} = -\alpha_t (1-p_t)^\gamma \log p_t$$

其中 $p_t$ 是正确类别的预测概率。$(1-p_t)^\gamma$ 是"调制因子"：容易样本（$p_t$ 接近 1）的损失被大幅压低，困难样本（$p_t$ 小）保持权重——解决"易分负样本淹没梯度"的问题。$\gamma=2, \alpha=0.25$ 是 RetinaNet 的常用默认值。

### 5.4 两阶段/decoupled 训练（现代推荐）

1. **第一阶段**：在原始（长尾）分布上正常训练，学到好的特征表示；
2. **第二阶段**：冻结特征，只微调分类器（用类别平衡采样或 $\tau$ 归一化权重），校准决策边界。

关键发现（BBN/两阶段方法）：特征本身在长尾数据上依然可学，问题主要出在**最后的分类器偏置**——所以只重训分类器即可大幅提升尾类准确率。

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——量化不平衡的影响

```python
import numpy as np

# 模拟 1000 类中头类 10000 样本、尾类 10 样本
counts = np.array([10000] * 10 + [100] * 90 + [10] * 900)
R = counts.max() / counts.min()
print(f"不平衡比 R = {R:.0f}")  # 1000
# 若用普通 CE 训练，尾类 900 类的总样本占比仅 7.6%，其梯度贡献被头类主导
print(f"头类样本占比 = {counts[:10].sum()/counts.sum():.1%}")   # ≈ 84.7%
```

### 例子 2：中等——加权 CE 与 Focal Loss 的 PyTorch 实现

```python
import torch
import torch.nn.functional as F

def focal_loss(logits, targets, alpha=0.25, gamma=2.0):
    ce = F.cross_entropy(logits, targets, reduction="none")
    pt = torch.exp(-ce)                      # 正确类别的预测概率
    w = alpha * (1 - pt) ** gamma            # 调制因子逐样本计算（alpha 为标量）
    return (w * ce).mean()

# 对比：易分样本 (pt=0.99) 调制因子 (1-0.99)^2=0.0001，损失几乎为 0；
# 难分样本 (pt=0.1) 调制因子 0.81，损失保留。→ 梯度聚焦困难样本。
logits = torch.randn(8, 10)
targets = torch.randint(0, 10, (8,))
print(f"focal loss: {focal_loss(logits, targets).item():.4f}")
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "类别不平衡 = 直接上采样就行" | 复制尾类会过拟合；上采样应配合强数据增强 |
| "重加权损失能解决一切" | 极端不平衡下重加权导致梯度爆炸/振荡；两阶段更稳 |
| "Focal Loss 只用于检测" | 任何"易分样本淹没梯度"的场景（分割、分类）都可用 |
| "长尾问题 = 少样本问题" | 少样本（few-shot）是全新类别只有极少样本；长尾是分布整体倾斜，两者对策不同 |
| "指标只看整体准确率" | 长尾数据整体准确率会被头类主导；必须看**每类平均准确率**与 tail 类准确率 |
