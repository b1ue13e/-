# 🎯 第三阶段：视觉核心任务（三大战役）

> "掌握了它们，你就拥有了解决80%工业需求的能力。"


## 🚪 为什么要先过这一关？

> 你已经会训练CNN做分类了。但真实世界的视觉问题几乎从来不只是「这张图是猫还是狗」——自动驾驶需要框出所有行人和车辆（检测），医学影像需要精确勾画肿瘤边界（分割）。
>
> 阶段3把这三大核心任务串成一条线：**分类 → 检测 → 分割**。Faster R-CNN本质上就是CNN+一个小网络（RPN），U-Net就是CNN+跳跃连接——你已经在阶段2攒齐了所有乐高积木，现在要学会把它们拼成城堡。

### 🎯 通关目标

- [ ] 画出Faster R-CNN完整架构图并解释RPN工作原理
- [ ] 手写IoU计算和NMS算法
- [ ] 解释YOLO的网格预测和Anchor Box设计
- [ ] 用预训练ResNet做迁移学习微调
