# 细粒度分类（Fine-Grained Image Classification）

## 0. 学习边界

**B 类专题（高价值）**。细粒度分类是"分类任务的极限形态"：类别之间差异极小（比如 200 种鸟，区分"黄腰白鹭"和"小白鹭"）。它几乎必然叠加长尾问题（稀有鸟类样本少），是真实世界图像识别难度的典型代表。理解它 = 理解"普通分类为什么做不好 + 局部判别特征为什么是答案"。

## 1. 这个知识点解决什么问题？

普通分类（ImageNet 1000 类）区分的是**大类别**：猫 vs 狗、飞机 vs 汽车。细粒度分类要在**同一个大类的子类之间**做区分：鸟的 200 个物种、车的 196 种车型、花的 102 种。子类间差异往往只集中在**局部**（喙的形状、翅膀的斑纹、车灯造型），而全局特征（颜色、轮廓）高度相似——直接微调 CNN 容易过拟合且抓不到判别细节。

## 2. 为什么它重要？它有什么用？

- 生态监测（鸟类/昆虫识别）、电商（商品款型识别）、安防（车型/人脸细粒度）；
- 细粒度分类的方法（局部特征定位 + 注意力）被广泛复用到检测、检索、医疗影像；
- 是"迁移学习 + 注意力机制"在任务侧的经典交汇点，衔接阶段4 的 Transformer。

## 3. 学它之前需要哪些前置知识？

- 微调与特征提取：[[迁移学习与微调]]；
- 注意力：[[Transformer与自注意力]]（或 CNN 注意力 CAM：[[可解释性Saliency与CAM|Saliency与CAM]]）。

## 4. 用直觉语言解释它

区分两种"看起来一样"的鸟，人类靠什么？靠**看局部**：先找到鸟（定位），再盯住喙、翅膀、尾羽这些判别部位比对。细粒度分类就是教会网络"先找到判别性局部、再比较这些局部的细节"。早期方法用手工标注的部件框（strong supervision）告诉网络"看翅膀"，现代方法用注意力让网络自己找到该看哪里（weak supervision）。

## 5. 正式定义、核心公式、符号解释

### 5.1 问题设定

数据集 $D = \{(x_i, y_i)\}$，$y_i \in \{1,\dots,C\}$，$C$ 为同一大类下的子类数（如 CUB-200 的 200 种鸟）。类别间共享大量视觉外观，判别信息集中在局部区域。

### 5.2 方法谱系

| 范式 | 代表方法 | 核心思想 |
|:---|:---|:---|
| 部件定位（强监督） | Part-based R-CNN | 先检测部件框再提取部件特征 |
| 双线性池化 | Bilinear CNN (BCNN) | 用两个特征提取器的外积捕获二阶统计 |
| 注意力定位（弱监督） | RA-CNN、MA-CNN | 注意力定位判别区域 → 放大该区域 → 再分类 |
| Transformer | ViT/TransFG | 自注意力自动发现判别 token |

### 5.3 双线性池化（Bilinear CNN）

两个特征图 $f_A \in \mathbb{R}^{H\times W\times D}$、$f_B$ 逐位置做外积再池化：

$$B = \sum_{i,j} f_A(i,j) f_B(i,j)^\top \in \mathbb{R}^{D\times D}$$

把 $B$ 展平/归一化后作为特征。思想：**二阶统计**能捕捉"部位 A 的特征与部位 B 的特征同时出现的模式"（比如"红色喙"与"黑色头部"共现），比简单拼接一阶特征更有判别力。代价是 $D^2$ 维特征（$D=512$ 时约 26 万维）。

### 5.4 注意力放大（RA-CNN 思路）

1. 全局图分类得到注意力图（如 CAM）；
2. 从注意力图裁剪出判别区域（如注意力最强的 1/3 区域）；
3. 将裁剪区域放大后输入第二个更高分辨率的网络分支；
4. 多尺度损失相加训练。效果：网络"先看整体、再看细节"。

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——为什么直接微调不够

```python
# 思想实验：CUB-200 每类平均仅 30 张训练图
# ResNet-50 微调（只换分类头）→ 准确率 ~65-75%（部分过拟合）
# 加入局部定位（注意力放大）→ ~85%+
# 差距来源：全局特征无法区分"喙部细节"，且样本少容易记住颜色等非判别线索
```

### 例子 2：中等——CAM 定位判别区域（弱监督）

```python
import torch
import torchvision.models as models

def cam_highlight(model, x):
    """用 GAP 层权重定位判别区域（简化实现）"""
    feats = model.features(x)                 # 最后一个卷积特征图 (1, D, H, W)
    weights = model.classifier.weight          # (C, D) 分类器权重
    cls = x.new_zeros(1, 1, *feats.shape[-2:])
    for c in range(feats.shape[1]):            # 对每个通道加权求和
        cls += weights[0, c] * feats[0, c]
    return torch.relu(cls)                     # 高亮区域 = 判别部位
# 应用：热力图最高的区域裁剪放大 → 第二分支高分辨率识别
```

### 例子 3：应用——细粒度识别流水线（鸟类）

```python
# 伪代码：RA-CNN 式流水线
# 1. 数据：CUB-200（5994 训练图 / 5794 测试图，200 类）
# 2. 主干：ImageNet 预训练 ResNet/ViT 微调

# 6. 评估：Top-1 准确率（CUB-200 现代方法 ~90%+）
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "细粒度分类 = 数据多一点的大分类" | 核心难点是局部判别特征与样本量少，方法不同 |
| "强监督部件标注是必须的" | 现代方法弱监督（只靠类别标签 + 注意力）已超过多数强监督方法 |
| "注意力热力图就是分割结果" | CAM 是判别区域（哪些区域决定分类），不是语义分割 |
| "双线性池化仍然主流" | BCNN 计算量大，已被注意力/Transformer 方法取代 |
| "与长尾无关" | 真实细粒度数据几乎都长尾（稀有物种），需叠加长尾对策 |
