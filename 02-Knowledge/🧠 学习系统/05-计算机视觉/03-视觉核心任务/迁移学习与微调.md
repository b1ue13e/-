# 迁移学习与微调

> 所属模块：[[🗺️ 计算机视觉学习路径|计算机视觉学习路径]]
> 对应阶段：[[🧭 阶段3-视觉核心任务|返回阶段页]]

## 0. 学习边界

- **类别**：**A 类（核心方法论，必须深挖）**。
- **判断理由**：当代 CV 中从零训练大模型只发生在顶级实验室。绝大多数工程师面对"小数据 + 大模型"的组合，迁移学习正是打通二者的标准范式。不理解策略取舍、层冻结粒度和分层学习率，就无法在真实业务中有效利用预训练模型。

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：训练高质量 CNN 需要百万级标注和数天 GPU 时间，但实际任务通常只有几百到几千张标注数据——从零训练 ResNet-50（2500 万参数）会严重过拟合。

迁移学习的核心问题：

> **当目标数据太少无法从零训练深度网络时，能否借用大规模预训练模型的"知识"来显著提升小数据表现？**

它解决三个困难：
1. **小数据过拟合**：预训练权重提供强先验，将搜索空间限制在有意义区域。
2. **训练成本爆炸**：从零训练 ImageNet 模型需数百 GPU·天；迁移学习压缩到分钟/小时级。
3. **标注稀缺**：医学影像、遥感、工业检测等领域标注成本极高。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：迁移学习是"预训练-微调"范式的核心。ImageNet 成为 CV 的"ImageNet 时刻"，不是因 1000 类分类本身，而是其预训练权重成为几乎所有下游任务的起点——正如 BERT/GPT 之于 NLP。
- **实际应用**：医学影像（X 光/CT 分类）、遥感（卫星图像分类）、工业缺陷检测、细粒度分类（鸟类/车型识别）。
- **高频题型**：区分特征提取与微调适用场景；设计层冻结策略与学习率配置；根据数据量与域相似度选择迁移策略。

## 3. 学它之前需要哪些前置知识？

1. **卷积神经网络 CNN**：卷积层、池化层、全连接层及特征层级（浅层→边缘/纹理，深层→语义/部件）。
2. **Softmax 分类器**：多分类输出结构和交叉熵损失。
3. **SGD 与学习率**：学习率对收敛速度和稳定性的影响。
4. **过拟合与正则化**：参数多数据少导致过拟合的直觉。

## 4. 用直觉语言解释它

> "迁移学习就像有 10 年驾龄的老司机去学开卡车——方向盘、油门、刹车和路况判断已熟练掌握，只需适应卡车更大的车身和不同换挡方式，无需从科目一重新学起。"

- **直觉类比**：预训练 CNN 前几层学的是"通用视觉词汇"（边缘、颜色斑块、纹理），几乎对所有自然图像共通——如同方向盘操作，换什么车都一样。中间层学"中级部件"（眼睛、轮子形状），有一定迁移性。最后层学"任务特定组合"（猫 vs 狗完整模式），最需替换。
- **为什么自然**：生物视觉也是分层抽象——V1 区简单边缘到 IT 区对象表示，低级特征跨任务共享，与 CNN 层级高度一致。
- **一句话本质**：把别人在大数据上训练好的"视觉理解能力"拿来，只在本任务小数据上做轻度适配。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

源域 $\mathcal{D}_S$（ImageNet，1000 类，120 万张）预训练模型 $f_\theta$，参数 $\theta_{\text{pretrain}}$。目标域 $\mathcal{D}_T$（医学影像，$K$ 类，数百张）。迁移学习以 $\theta_{\text{pretrain}}$ 为初始化点，利用 $\mathcal{D}_T$ 适配。

### 2. 两种主要策略

| 策略 | 做法 | 适用场景 |
| :--- | :--- | :--- |
| **特征提取** (Feature Extraction) | 冻结全部预训练层，仅训练新分类头 | 数据极少（< 1k），与 ImageNet 视觉分布接近 |
| **微调** (Fine-tuning) | 解冻部分/全部预训练层，与分类头一起训练 | 数据中等以上（> 1k），或域偏移较大 |

特征提取——冻结 backbone，只优化分类头：

$$\min_{\theta_{\text{head}}} \mathbb{E}_{(x,y)\sim\mathcal{D}_T}\left[ \mathcal{L}\big( h_{\theta_{\text{head}}}(f_{\theta_{\text{backbone}}}(x)), y \big) \right]$$

微调——在预训练基础上继续梯度更新：

$$\theta^{(t+1)} = \theta^{(t)} - \eta \cdot \nabla_\theta \mathcal{L}_{\mathcal{D}_T}(\theta^{(t)}),\quad \theta^{(0)} = \theta_{\text{pretrain}}$$

### 3. 层冻结策略

CNN 层级特征从通用到专用渐变：

| 策略 | 做法 | 数据量 | 风险 |
| :--- | :--- | :--- | :--- |
| **纯特征提取** | 冻结全部 backbone | < 500 | 欠拟合，无法适应域偏移 |
| **部分微调** | 冻结早期层（conv1–conv3），微调后期层（conv4–conv5） | 500–5000 | 需判断冻结截止点 |
| **全部微调** | 解冻全部层，极小学习率 | > 5000 | 可能灾难性遗忘 |

直觉依据：conv1–conv3 学边缘/角点/纹理等通用低级特征，几乎所有图像共享；conv4–conv5 学任务相关高级语义组合。

### 4. 学习率差异化设置

**分层学习率**（discriminative learning rates）：

$$\eta_\ell = \eta_{\text{base}} \cdot \gamma^{(\text{depth} - \ell)}$$

其中 $\ell$ 是层索引（越深越大），$\gamma \in (0,1)$（典型值 $0.5 \sim 0.9$）。

**经验规则**：分类头（随机初始化）$\eta_{\text{head}} = 1 \times 10^{-3}$；最后几个卷积块 $\eta = 1 \times 10^{-4}$；中间卷积块 $\eta = 5 \times 10^{-5}$；最前卷积块（若解冻）$\eta = 1 \times 10^{-5}$。

**为什么不统一学习率？** 预训练权重已处于优良局部极小值，过大学习率会"撞飞"它导致灾难性遗忘——丢失预训练通用特征，又无足够数据从头学好。

### 5. 符号说明表

| 符号 | 含义 | 典型值 |
| :--- | :--- | :--- |
| $\mathcal{D}_S$ | 源域数据集 | ImageNet: 1.2M 图, 1000 类 |
| $\mathcal{D}_T$ | 目标域数据集 | 几十～几万张 |
| $\theta_{\text{pretrain}}$ | 预训练权重 | `weights="IMAGENET1K_V1"` |
| $\eta_{\text{head}}$ | 分类头学习率 | $10^{-3} \sim 10^{-2}$ |
| $\eta_{\text{backbone}}$ | 骨干网络学习率 | $10^{-5} \sim 10^{-4}$（head 的 1/10） |

## 6. 推导思路和思想来源

- **最初困难**：2012 年 AlexNet 后，人们发现不在 ImageNet 规模数据上大网络无法收敛，而多数实际任务凑不出百万级标注。
- **直接方法局限**：小数据集从零训练 → 严重过拟合。
- **关键"转念"——Yosinski et al. (2014)**：系统实验揭示 CNN 可迁移性规律：① 浅层特征（conv1–conv3）高度通用；② 深层特征体现任务特异性；③ 即使域差异大，预训练初始化也比随机初始化收敛更快、泛化更好；④ 微调优于特征提取（数据非极端少时）。
- **推导主线**：通用视觉特征 → 中级视觉部件 → 任务特定组合，逐层从"共享基底"过渡到"专属顶层"。迁移学习利用此渐变：保留共享基底，替换/微调专属顶层。
- **为什么自然**：与灵长类视觉皮层 V1（方向选择性）→ IT（对象选择性）的层级抽象一致——低级区域跨任务高度共享。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础（策略决策）

- **场景 A**：300 张猫/狗二分类（与 ImageNet 视觉接近）→ **特征提取**。冻结 backbone，只训练 2 输出分类头。
- **场景 B**：8000 张医学 CT 三分类 → **部分/全部微调**。数据足但域偏移大，需解冻后期层适应纹理差异。
- **易错点**：不能仅因"数据量不小"就粗暴全解冻 + 大学习率。

### 例子 2：中等（冻结与学习率匹配）

- **题目**：ResNet-50，2000 张航拍图，10 类土地利用分类。
- **解题**：替换 `fc` 为 `nn.Linear(2048, 10)`；冻结 `layer1`、`layer2`，微调 `layer3`、`layer4`；分类头 $\eta = 1\times10^{-3}$，`layer4` $\eta = 1\times10^{-4}$，`layer3` $\eta = 5\times10^{-5}$；Cosine annealing，30 epoch。
- **判断**：航拍 vs ImageNet 有中等域偏移，不能只做特征提取；2000 张全部微调有风险，部分微调是合理折中。

### 例子 3：实际应用（PyTorch 完整微调代码）

```python
import torch, torch.nn as nn, torch.optim as optim
from torchvision import datasets, transforms, models
from torch.utils.data import DataLoader

# ---- 1. 数据（mean/std 必须与预训练一致！）----
mean, std = [0.485, 0.456, 0.406], [0.229, 0.224, 0.225]
train_tf = transforms.Compose([
    transforms.RandomResizedCrop(224), transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(0.2, 0.2, 0.2), transforms.ToTensor(),
    transforms.Normalize(mean, std)])
val_tf = transforms.Compose([
    transforms.Resize(256), transforms.CenterCrop(224),
    transforms.ToTensor(), transforms.Normalize(mean, std)])
train_ds = datasets.ImageFolder("./data/train", train_tf)
val_ds   = datasets.ImageFolder("./data/val",   val_tf)
train_ld = DataLoader(train_ds, batch_size=32, shuffle=True,  num_workers=4)
val_ld   = DataLoader(val_ds,   batch_size=64, shuffle=False, num_workers=4)
num_cls  = len(train_ds.classes)

# ---- 2. 模型：预训练 backbone + 新分类头 ----
model = models.resnet50(weights="IMAGENET1K_V1")
for p in model.parameters(): p.requires_grad = False
model.fc = nn.Sequential(
    nn.Dropout(0.3), nn.Linear(2048, 256), nn.ReLU(),
    nn.Dropout(0.3), nn.Linear(256, num_cls))

# ---- 3. 分层学习率：解冻 layer4 + layer3 ----
for p in model.layer4.parameters(): p.requires_grad = True
for p in model.layer3.parameters(): p.requires_grad = True
opt = optim.SGD([
    {'params': model.fc.parameters(),      'lr': 1e-3},
    {'params': model.layer4.parameters(),  'lr': 1e-4},
    {'params': model.layer3.parameters(),  'lr': 5e-5},
], momentum=0.9, weight_decay=1e-4)
sched = optim.lr_scheduler.CosineAnnealingLR(opt, T_max=30)

# ---- 4. 训练 ----
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model, crit = model.to(device), nn.CrossEntropyLoss()
for ep in range(30):
    model.train()
    loss_sum, correct = 0.0, 0
    for x, y in train_ld:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()
        L = crit(model(x), y); L.backward(); opt.step()
        loss_sum += L.item() * x.size(0)
        correct  += (model(x).argmax(1) == y).sum().item()
    train_acc = correct / len(train_ds)
    model.eval()
    v_correct = 0
    with torch.no_grad():
        for x, y in val_ld:
            x, y = x.to(device), y.to(device)
            v_correct += (model(x).argmax(1) == y).sum().item()
    val_acc = v_correct / len(val_ds)
    sched.step()
    if (ep+1) % 5 == 0:
        print(f"Ep {ep+1:2d}/30 | Loss {loss_sum/len(train_ds):.4f} | "
              f"Train {train_acc:.4f} | Val {val_acc:.4f}")
```

- **实际价值**：此模板可直接适配任何图像分类任务。**关键**：数据标准化参数必须与预训练一致，否则特征失效。

## 8. 常见误区和易混概念

### 误区 1：ImageNet 预训练对任何图像任务都有用

- **错误直觉**：只要是图像，ImageNet 预训练一定比随机初始化好。
- **为什么错**：目标图像与自然照片差异极大时（CT 灰度切片、雷达点云），浅层特征分布失配，边际收益下降。某些医学任务上域内预训练（如 CheXpert）优于 ImageNet。
- **正确理解**：大多数情况有益，极大域偏移时应对比实验。

### 误区 2：微调一定比特征提取好

- **错误直觉**：更多自由度 = 更好效果。
- **为什么错**：数据极少（< 200 张）时微调立即过拟合——特征提取是唯一合理选择。
- **正确理解**：策略由"数据量 × 域相似度"二维矩阵决定。

### 误区 3：统一学习率即可微调

- **错误直觉**：设好 `.requires_grad`，固定学习率跑就行。
- **为什么错**：统一学习率下预训练层以同样速度偏离优良初始化 → 灾难性遗忘。
- **正确理解**：分层学习率是核心工程实践——预训练层用 $\frac{1}{10} \sim \frac{1}{100}$ 分类头学习率。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型场景 |
| :--- | :--- | :--- | :--- |
| 特征提取 | 只训练分类头 | backbone 完全冻结 | 数据 < 500，视觉分布接近 |
| 部分微调 | 微调部分层 | 早期冻结、后期解冻 | 数据 500–5000，中等域偏移 |
| 全部微调 | 全部层可训练 | 极小学习率保护预训练知识 | 数据 > 5000，域偏移较大 |
| 从零训练 | 随机初始化 | 无预训练先验，需海量数据 | 数据 > 100k 或架构不兼容 |

1. **基础**：什么是迁移学习？它主要解决哪两个实际困难？ #自测题/基础
   > [!question]- 答案解析
   > 将大规模源任务预训练模型知识迁移到小数据目标任务的范式。解决：① 小数据集深度网络从零训练严重过拟合；② 从零训练计算成本极高。

2. **基础**：特征提取和微调的核心区别？ #自测题/基础
   > [!question]- 答案解析
   > 特征提取冻结全部预训练层仅训练分类头；微调解冻部分/全部预训练层在目标数据上继续更新。前者适合数据极少，后者适合数据较充足或有域偏移。

3. **中等**：ResNet-50 在 3000 张域偏移数据集上微调，为什么 layer1 和 fc 需不同学习率？ #自测题/中等
   > [!question]- 答案解析
   > layer1 学通用低级特征（边缘/纹理），预训练权重已优良，大学习率会破坏基本视觉知识；fc 层随机初始化需大学习率快速收敛。分层学习率保护通用知识同时让新任务层快速适应。

4. **中等**：PyTorch 中如何让 ResNet-50 只训练最后 fc 层？写出核心代码。 #自测题/中等
   > [!question]- 答案解析
   > ```python
   > model = models.resnet50(weights="IMAGENET1K_V1")
   > for p in model.parameters(): p.requires_grad = False
   > model.fc = nn.Linear(model.fc.in_features, num_classes)
   > optimizer = optim.Adam(model.fc.parameters(), lr=1e-3)
   > ```

5. **较难**：目标域与 ImageNet 极大域偏移（灰度超声、深度图）时，ImageNet 预训练是否仍有益？从特征层级分析。 #自测题/较难
   > [!question]- 答案解析
   > 可能仍有益但收益递减。浅层 Gabor 式边缘/方向选择性对非自然图像也有一定通用性（超声仍有组织边界、深度图仍有几何边缘），但中层以上纹理统计和部件组合可能完全失配。最佳实践：仍以 ImageNet 预训练为起点（好于随机初始化），解冻更多层并给稍大学习率适应域偏移；若有条件在域内大数据集（如 CheXpert）做二次预训练。

## 🃏 Anki 卡片

- 迁移学习的核心矛盾？::小数据无法从零训练深度网络，需借用大规模预训练模型的视觉知识提升小数据表现。
- 特征提取和微调的区别？::特征提取冻结全部预训练层只训练分类头；微调解冻部分/全部层在目标数据上继续更新。
- CNN 浅层学到什么？为什么高度可迁移？::边缘、角点、纹理等通用低级视觉特征；几乎所有自然图像共享这些基本元素。
- 微调时为何不同层设不同学习率？::预训练层已有优良初始化需小学习率保护；新分类头随机初始化需大学习率快速收敛。统一大学习率导致灾难性遗忘。
- 分层学习率典型三档数值？::分类头 $\eta = 1\times10^{-3}$，最后卷积块 $\eta = 1\times10^{-4}$，中间卷积块 $\eta = 5\times10^{-5}$。
- 数据预处理 mean/std 为何必须与预训练一致？::预训练权重在特定输入分布下学到，改变标准化参数破坏特征语义使预训练权重失效。
- 何时选纯特征提取而非微调？::目标数据极少（< 500 张）且与 ImageNet 视觉分布接近时。微调会立即过拟合。
- PyTorch 加载官方 ImageNet 预训练 ResNet-50 的代码？::`models.resnet50(weights="IMAGENET1K_V1")`
- 灾难性遗忘在微调中的含义？::学习率过大使预训练通用特征被快速覆盖，新任务数据不足以从零学好这些特征。
- 目标域与 ImageNet 极大域偏移时如何调整？::仍用 ImageNet 预训练作起点（好于随机初始化），解冻更多层、适当提高学习率；若有域内大数据集优先做域内预训练。
