# 度量学习与图像检索（Metric Learning & Image Retrieval）

## 0. 学习边界

**A 类核心概念**。图像检索（以图搜图、人脸识别、行人重识别、推荐系统）的核心不是"分类"，而是**学一个距离函数**：让同类图像在特征空间中靠近、异类远离。分类用 Softmax 输出类别概率，检索则直接操作特征向量的距离——这是完全不同的学习范式，也是对比学习（阶段4 SimCLR/CLIP）的直系祖先。

## 1. 这个知识点解决什么问题？

- 分类模型只能回答"这张图属于预定义的哪一类"；检索要回答"哪张图与这张最像"（类别未知或成百上千类）；
- 直接拿分类模型的倒数第二层特征做距离，度量不一定是"语义距离"（同类可能分散、异类可能靠近）；
- 度量学习专门优化特征空间结构，使欧氏/余弦距离与语义相似度一致。

## 2. 为什么它重要？它有什么用？

- **人脸识别/验证**：FaceNet 用 Triplet Loss 学到 128 维嵌入，识别 8 亿人；
- **行人重识别（ReID）**、**以图搜图**、**电商相似商品**、**指纹/声纹验证**；
- 度量学习的思想（构造正/负样本对、拉近推远）是自监督对比学习（SimCLR、MoCo、CLIP）的基础，阶段4 会直接复用本卡概念。

## 3. 学它之前需要哪些前置知识？

- 特征表示与微调：[[迁移学习与微调]]（backbone 提取特征）；
- 对比学习思想：[[自监督学习SimCLR与CLIP]]（正负样本对、InfoNCE）；
- 损失函数基础：[[Softmax与SVM损失函数]]。

## 4. 用直觉语言解释它

想象你要从一万张照片里找到"和我长得像的人"。你需要的不是"这是什么类"，而是一把"相似度尺子"。度量学习就是训练这把尺子：把照片变成向量，训练时三张一组——一张锚图、一张同类图、一张异类图——不断调整网络，让"同类距离 < 异类距离 + 边界"。训练完后，用任意照片都能在向量空间里找到最近的邻居。

## 5. 正式定义、核心公式、符号解释

### 5.1 嵌入（Embedding）

网络 $f_\theta: \mathbb{R}^{H\times W\times 3} \to \mathbb{R}^d$ 把图像映射到 $d$ 维特征向量（常用 $d=128/512$），并做 L2 归一化使 $\lVert f(x)\rVert_2 = 1$（此时欧氏距离与余弦相似度单调等价）。

### 5.2 Contrastive Loss（成对损失）

对样本对 $(x_a, x_b)$，标签 $y \in \{0,1\}$（1=同类）：

$$L = y\, d^2 + (1-y)\max(0, m - d)^2$$

其中 $d = \lVert f(x_a) - f(x_b)\rVert_2$，$m$ 是异类对的边界（margin）。同类对拉近（第一项），异类对推到距离 $m$ 以外（第二项）。

### 5.3 Triplet Loss（三元组损失，FaceNet）

取三元组（anchor $a$，正样本 $p$，负样本 $n$）：

$$L = \max\left(0,\; \lVert f(a)-f(p)\rVert^2 - \lVert f(a)-f(n)\rVert^2 + m\right)$$

- 目标：正对距离至少比负对距离小 $m$；
- 梯度只作用于违反约束的三元组（难例）；
- **训练关键**：选"硬三元组"（负样本很近或正样本很远）才有效，随机采样收敛极慢——这就是**难样本挖掘（hard mining）**。

### 5.4 评估指标

- **Recall@k**：检索返回的前 k 个结果中相关图像的比例（检索标准指标）；
- **mAP**：多查询平均精度（ReID 标准指标）。

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——用特征距离做检索

```python
import numpy as np

# 假设 1000 张图已编码为 128 维归一化特征
feats = np.random.randn(1000, 128)
feats /= np.linalg.norm(feats, axis=1, keepdims=True)
query = feats[42]  # 查询图
scores = feats @ query          # 余弦相似度（归一化后 = 点积）
top5 = np.argsort(-scores)[:5]
print(f"Top-5 检索结果索引: {top5}")   # 第一个应是自己 (42)
```

### 例子 2：中等——PyTorch 实现 Triplet Loss

```python
import torch
import torch.nn.functional as F

def triplet_loss(anchor, positive, negative, margin=0.5):
    """anchor/positive/negative: (N, d) 已归一化"""
    d_pos = F.pairwise_distance(anchor, positive, p=2)     # (N,)
    d_neg = F.pairwise_distance(anchor, negative, p=2)     # (N,)
    loss = torch.clamp(d_pos - d_neg + margin, min=0.0)
    return loss.mean(), (loss > 0).float().mean()   # 损失 + 难例比例

torch.manual_seed(0)
a = F.normalize(torch.randn(4, 128))
p = a + 0.05 * torch.randn(4, 128)      # 同类：接近
n = torch.randn(4, 128); n = F.normalize(n)
loss, frac = triplet_loss(a, p, n)
print(f"triplet loss = {loss.item():.4f}, 激活三元组占比 = {frac.item():.2%}")
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "度量学习 = 分类网络最后一层换损失" | 检索需要嵌入层 + L2 归一化 + 距离度量，评估用 Recall@k 而非 accuracy |
| "Triplet Loss 随便采样就能训" | 随机采样的三元组大多"已满足约束"（损失 0），必须 hard mining |
| "对比学习 = 度量学习" | 度量学习用监督标签；对比学习用数据增广构造正对（自监督），但损失形式同源 |
| "余弦相似度与欧氏距离等价" | 仅当向量 L2 归一化后等价；未归一化时两者排序可能不同 |
| "检索模型要重新训练分类头" | 检索不保留分类头，只保留 backbone 嵌入 |
