# 实例分割与全景分割（Instance & Panoptic Segmentation）

## 0. 先判断它值不值得深挖

**A 类核心概念**。实例分割（每个物体一个 mask + 类别）是目标检测与语义分割的"合体"，全景分割再把"可数物体（things）+ 不可数背景（stuff）"统一成一张图。本卡合并 MOC 中 Mask R-CNN / YOLACT / SOLO / 全景分割定义 / Panoptic FPN 五个规划项——它们是同一主题谱系，拆成五张小卡只会制造碎片。

## 1. 这个知识点解决什么问题？

- 语义分割只回答"每个像素是什么类别"，不区分"两个同类的物体"；
- 目标检测只给矩形框，框里混着背景和其他物体；
- 实例分割要"每个物体实例一个 mask"（自动驾驶需要区分前后两辆车各自的轮廓）；
- 全景分割要"整张图每个像素都被标记，且可数物体按实例区分"（things 按实例、stuff 按类别）。

## 2. 为什么它重要？它有什么用？

- 自动驾驶（实例级车辆/行人轮廓）、医学影像（细胞/器官实例）、工业质检、图像编辑；
- Mask R-CNN 是 Two-Stage 检测的集大成者，理解它 = 理解 Faster R-CNN 的完整升级路径；
- 全景分割是 2019 年起 CV 主流评估任务（MS COCO Panoptic），推动"统一场景理解"。

## 4. 用直觉语言解释它

语义分割是把画面按"材质"涂色（所有天空一个色、所有树一个色）；实例分割还要给每棵树编号（树1、树2……每棵一个轮廓）；全景分割则是"整张图一次涂完"——天空、路面这些"填充物"按类别涂，每一辆车、每个人按编号涂，不留空白。Mask R-CNN 的做法是"在检测框里再画一个精细轮廓"，而 SOLO 的做法是"按像素位置直接分实例"，两者是"先框后掩膜"与"直接掩膜"两条路线。

## 5. 正式定义、核心公式、符号解释

### 5.1 任务定义

- **实例分割**：输出集合 $\{(k_i, c_i, M_i)\}$，$k_i$ 实例编号，$c_i$ 类别，$M_i \subset \mathbb{R}^2$ 是像素掩膜；
- **全景分割**：对每个像素 $p$ 输出 $(\text{label}, \text{instance\_id})$；things 类按实例区分 id，stuff 类共享 id（如所有天空 id 相同）。评估用 PQ（Panoptic Quality）：$PQ = \frac{\sum_{(p,g)} \text{IoU}(p,g)}{|TP| + \frac12|FP| + \frac12|FN|}$。

### 5.2 Mask R-CNN（Two-Stage 实例分割）

在 Faster R-CNN 上新增**并行 Mask 分支**：

1. RPN 提候选框；
2. ROIAlign（解决 RoIPool 的量化误差，保留亚像素对齐）提取固定尺寸特征；
3. 三个并行头：**分类**、**框回归**、**Mask 分割**（每类一个 $K\times m\times m$ 二值掩膜，用 sigmoid + 逐像素 BCE 损失）。

$$L = L_{\text{cls}} + L_{\text{box}} + L_{\text{mask}}$$

关键细节：Mask 分支用**每类一个通道** + sigmoid（而非 softmax），因为类别由分类头决定，掩膜只负责"这个实例长什么样"；训练时只在 GT 类别通道上计算 BCE。

**ROIAlign**：把 ROI 映射到特征图时用双线性插值（不取整），使掩膜精度大幅提升——这是 Mask R-CNN 相对上一代的关键改进。

### 5.3 单阶段实例分割：YOLACT 与 SOLO

| 方法 | 核心思想 | 特点 |
|:---|:---|:---|
| **YOLACT** | 预生成 $k$ 个"原型掩膜"（protonet）+ 每个框预测线性组合系数，$M = \sum \alpha_i P_i$ | 实时（33 FPS），无 ROI 依赖 |
| **SOLO** | 把实例分割变成"按位置分类"：特征图每个格子负责一个实例，预测其类别 + 掩膜 | 完全无框/无 anchor，结构简单 |

### 5.4 Panoptic FPN（全景分割统一框架）

用 FPN 做共享骨干：语义分割头（stuff 类，来自 FPN 高层语义特征） + Mask R-CNN 头（things 类实例 mask），最后**合并**：每个像素优先取 things 的实例 mask（置信度高时），其余归 stuff 类别；重叠区域按置信度/优先级裁决。

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础——三类分割对比

```python
# 同一张街景图的三种输出：
# 语义分割:  {pixel: 'car'}（两辆车都是'car'，无法区分）
# 实例分割:  {car#1: mask_A, car#2: mask_B}（两辆车各自轮廓）
# 全景分割:  {road: stuff, sky: stuff, car#1: instance, car#2: instance}（全图无空洞）
```

### 例子 2：中等——Mask 分支的每类 sigmoid（PyTorch 伪代码）

```python
import torch

def mask_head_loss(mask_logits, gt_masks, gt_classes):
    """mask_logits: (N, K, m, m)，K=类别数；gt_masks: (N, m, m) 二值"""
    N, K = mask_logits.shape[:2]
    loss = 0.0
    for i in range(N):
        c = gt_classes[i]                       # 该实例的类别
        logit = mask_logits[i, c]               # 只取 GT 类别通道
        target = gt_masks[i].float()            # 二值掩膜
        loss = loss + torch.nn.functional.binary_cross_entropy_with_logits(logit, target)
    return loss / N
# 关键：不用 softmax 跨类别竞争，每个类别通道独立 sigmoid
```

### 例子 3：应用——全景分割推理流水线（Panoptic FPN 思路）

```python
# 伪代码：
# 1. FPN 提取多尺度特征
# 2. things 分支：RPN + ROIAlign + (cls, box, mask) → 实例候选
# 3. stuff 分支：语义分割头 → 每像素 stuff 类别
# 4. 合并：按实例置信度排序，逐实例“粘贴” mask（覆盖对应像素），
#    剩余像素填充 stuff 类别 → 无重叠无空洞的全景图
# 5. 评估：PQ（Panoptic Quality）
```

## 7. 常见误区和易混概念

| 误区 | 正确理解 |
|:---|:---|
| "实例分割 = 语义分割 + 检测" | 实现上确实两路结合，但掩膜质量（ROIAlign）、类别与掩膜解耦是关键难点 |
| "Mask 分支用 softmax" | Mask R-CNN 用每类 sigmoid + 只算 GT 类别通道，避免类别间掩膜竞争 |
| "YOLACT 是检测模型" | YOLACT 输出 mask 而非框，属实例分割（虽借用检测框架） |
| "全景分割 = 实例分割 + 语义分割" | 还要处理两路输出的**冲突合并**（重叠/空洞），PQ 评估统一了两者 |
| "SOLO 有 anchor 和框" | SOLO 完全无框无 anchor，直接逐格预测实例 |
