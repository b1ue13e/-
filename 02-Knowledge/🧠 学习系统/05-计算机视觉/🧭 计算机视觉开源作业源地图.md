# 🧭 计算机视觉开源作业源地图

> 这页只回答一个问题：  
> 如果要把 `05-计算机视觉` 做成像机器学习和量化金融那样的“老师版真实作业包”课程，哪些开源资源适合当**课程主线**，哪些更适合当**工程作业源 / baseline 源**。

---

## 一、最适合当“课程主线”的

### 1. Stanford CS231n

- **定位**：唯一主线首选。
- **为什么适合**：
  - 作业推进顺序天然清楚；
  - 从 `kNN / Softmax / 两层网络` 一路推进到 `CNN / PyTorch / Transformer / 自监督 / Diffusion / CLIP`；
  - 非常适合改造成 `HW01-HW06` 或 `HW01-HW08` 的连续作业体系。
- **最适合承接的本地形态**：
  - `HW01` 线性分类与基础训练
  - `HW02` 反向传播与两层网络
  - `HW03` CNN 与训练工程
  - `HW04` 迁移学习与误差分析
  - `HW05` 检测 / 分割专题
  - `HW06` 开放 project

### 2. Michigan EECS 498 / 598

- **定位**：主线补充源。
- **为什么适合**：
  - 比 CS231n 更偏“现代 PyTorch 工作流”；
  - 很适合补 `ResNet / YOLO / Transformer` 这一层的过渡；
  - 可以把“从手搓基础到现代框架”的跨度补得更顺。
- **更适合的用法**：
  - 不替代 CS231n；
  - 作为 `HW03-HW05` 的专题强化源。

---

## 二、最适合当“工程作业源 / baseline 源”的

### 1. MMDetection

- **定位**：检测 / 分割的工程 baseline 源。
- **适合补什么**：
  - 配置化训练；
  - 评测脚本；
  - 推理与可视化；
  - 从“模型想法”过渡到“工程实验协议”。
- **最适合接到本地哪份作业**：
  - `HW05` 检测或分割专题作业。

### 2. Detectron2

- **定位**：成熟视觉框架 baseline 源。
- **适合补什么**：
  - 训练与评测规范；
  - COCO 风格任务的成熟 baseline；
  - “自己实现”和“工业框架结果”之间的对照。
- **最适合接到本地哪份作业**：
  - `HW05` 工程对照；
  - `HW06` 课程项目 baseline。

### 3. Dive into Deep Learning 视觉章节

- **定位**：最小可运行 baseline 源。
- **适合补什么**：
  - CNN / 检测 / 分割最小实现；
  - 快速 smoke run；
  - 帮学生先跑通一条最短路径。
- **限制**：
  - 不够强，不适合当唯一课程主线；
  - 更适合当老师发包时的 starter 参考。

### 4. timm

- **定位**：现代分类 backbone baseline 源。
- **适合补什么**：
  - ResNet / ConvNeXt / ViT 这类 backbone 的快速对照；
  - 迁移学习与预训练模型实验。
- **最适合接到本地哪份作业**：
  - `HW04` 迁移学习；
  - `HW06` 开放 project。

### 5. Albumentations

- **定位**：数据增强协议源。
- **适合补什么**：
  - 数据增强对照；
  - 训练协议标准化；
  - 分类、检测、分割的增强统一口径。
- **最适合接到本地哪份作业**：
  - `HW03-HW05`。

---

## 三、老师版重构时的现实判断

这些开源资源都**很有价值**，但也有同一个问题：

- 它们大多不是可以直接发给学生的正式作业包；
- 普遍缺少统一的：
  - `README`
  - `data card`
  - `rubric`
  - `starter`
  - `smoke test`
  - `baseline log`
  - `report template`

所以它们的角色更准确地说是：

1. `CS231n / EECS 498` 负责给出**课程骨架**；
2. `MMDetection / Detectron2 / D2L / timm` 负责给出**工程实验源与 baseline 参考**；
3. 本地学习系统负责做最后一步：  
   **老师版重构**。

## 四、当前最推荐的组合

如果只选一套最稳的组合，我建议：

### 课程主线

- `CS231n`

### 工程作业源 / baseline 源

- `EECS 498`
- `D2L 视觉章节`
- `MMDetection`
- `Detectron2`

### 角色分工

- `CS231n`：决定作业顺序
- `EECS 498`：补现代作业题型
- `D2L`：补最小 starter
- `MMDetection / Detectron2`：补工程 baseline

## 五、下一步最合理的动作

对于 `05-计算机视觉`，下一步不应该直接去做学生实验，而是继续完成两层老师视角文档：

1. `HW01-HW06 老师版序列草案`
2. `老师视角教学设计与作业节奏`

这样才能真正回答：

- 学到什么时布哪份作业；
- 每份作业为什么排在这里；
- 每份作业最低交付物应该长什么样。
