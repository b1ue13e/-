# 🧠 第二阶段：深度学习内核（模型本质）

> "从感知机到ResNet，拆解深度神经网络的每一颗螺丝。"

---

## 🚪 为什么要先过这一关？

> 阶段1让你理解了「图像是什么」，现在要回答：「神经网络如何从像素里学到猫这个概念？」
>
> 阶段2是整个深度学习的**承重墙**。从kNN（死记硬背）到线性分类器（总结规律），再到亲手推导反向传播——你会发现，当你的两层网络在CIFAR-10上跑出40%准确率时，"梯度下降"四个字才有了重量。
>
> **这一阶段直接对应CS231n Assignment 1和2的全部考点。**

### 🎯 通关目标

- [ ] 手写kNN分类器，理解L1/L2距离的区别
- [ ] 推导Softmax交叉熵损失梯度：∂L/∂sⱼ = pⱼ - 1[y=j]
- [ ] 在纸上完成f=(x+y)×z的计算图反向传播
- [ ] 手写NumPy版conv2d（无for循环）
- [ ] 解释BatchNorm的train/eval模式差异
