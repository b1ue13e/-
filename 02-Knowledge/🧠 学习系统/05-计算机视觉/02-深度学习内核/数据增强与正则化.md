# 数据增强与正则化

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：数据增强与正则化是深度学习训练流水线的"左右护法"——增强从数据端注入不变性、正则化从模型端约束复杂度。CS231n Assignment2 专门考察增强的实现与对比实验；Dropout 与 L2 权重衰减的推导是反向传播作业的标配。面试中"过拟合怎么办"的答案就是"增强 + 正则化"组合拳。二者目标相同（防过拟合），但作用层级和机制截然不同，分开理解才能灵活组合。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 深度网络参数百万级，标注数据仅几千到几万张——模型极易"背诵"训练样本。表现：训练损失一路下降、验证损失不降反升（过拟合）。

**两类工具的协同解决**：
- **数据增强（Data Augmentation）**：在数据端对训练样本施加保持语义的随机变换（翻转、裁剪、色彩抖动、样本混合），凭空扩大有效训练集——**数据层面的隐式正则化**。
- **正则化（Regularization）**：在模型/损失端显式约束复杂度——Dropout 随机丢弃神经元防止共适应，L1/L2 权重衰减惩罚大权重，Early Stopping 在验证误差回升前截停训练——**模型/优化层面的显式正则化**。

> **一句话本质**：增强是"让数据更难被死记"，正则化是"让模型更难看死记"——从数据端和模型端同时夹击过拟合。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW01 到 HW03 的训练脚本中，增强管线（`transforms.Compose`）和正则化配置（`weight_decay`、`dropout`）是标配。Assignment2 的增强对比实验直接验证：有/无增强的验证精度通常差 3-8 个百分点。
- **实际应用场景**：ImageNet 训练标准管线 = `RandomResizedCrop(224)` + `HorizontalFlip` + `ColorJitter`；全连接层 Dropout `p=0.5`；AdamW 的 `weight_decay=1e-4`；Kaggle 比赛保底 Early Stopping。
- **高频题型**：Dropout 训练/测试行为差异；L1 vs L2 的几何本质；Early Stopping 的 patience 如何选取；Mixup/CutMix 的标签混合公式；"手写数字识别能不能水平翻转"。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：
1. **[[卷积神经网络CNN]]**：卷积的平移/翻转敏感性决定"翻转对 CNN 是否安全"；全连接层参数量大，是 Dropout 的主战场。
2. **训练流程**（train/val/test、epoch、梯度下降）：理解训练损失 vs 验证损失的张力，才能判断何时过拟合、何时 Early Stop。
3. **[[反向传播与计算图]]**：L1/L2 权重衰减的本质是在损失上附加惩罚项，需理解其对梯度的影响（$\frac{\partial}{\partial w}(\lambda\|w\|_2^2) = 2\lambda w$）。

---

## 4. 用直觉语言解释它

> «数据增强就像"视力训练班"：同一张猫的照片，让模型看正着拍的、翻转的、裁剪的、调暗的——都是同一只猫，被迫学会"不管猫怎么摆、光怎么打，它都是猫"。正则化则像"考官"：L2 权重衰减是"别把某个特征看得太重"，Dropout 是"每次考试随机收走一半笔记——逼你真正理解而不是照抄"，Early Stopping 是"看你开始胡说了就喊停"。»

- **直觉类比**：
  - 增强 = 在数据分布邻域采样等价样本，"扩充兵源"。
  - L2 正则 = 在损失地形上挖一个"碗"，把最优解往原点拉——圆形约束域，各权重均匀缩小。
  - L1 正则 = 菱形约束域，尖角处产生稀疏解（部分权重精确为零 = 自动特征选择）。
  - Dropout = 训练时对网络做"随机阉割"，每个神经元必须独立有用；测试时全团出战，权重已由倒置 Dropout 缩放好，无需调整。
  - Early Stopping = 训练到验证误差最小点即停，等价于限制有效优化步数——"时间维度"的正则化。
- **一句话直觉本质**：**增强在输入端制造多样性，正则化在模型端限制自由度；二者互补，逼迫模型学到"真正本质"的模式。**

## 5. 正式定义、核心公式、符号解释

### 5.1 数据增强（Data Augmentation）

对训练样本施加保持语义标签的随机变换 $T \sim \mathcal{T}$，生成 $(T(x), y)$。测试时**不做增强**。

| 类别 | 典型方法 | 注入的不变性 |
|:---|:---|:---|
| 几何类 | `RandomHorizontalFlip`, `RandomResizedCrop`, `RandomRotation` | 翻转/平移/旋转 |
| 色彩类 | `ColorJitter`（亮度/对比度/饱和度/色相） | 光照 |
| 遮挡类 | `RandomErasing` / Cutout（随机零值矩形块） | 局部遮挡 |
| 混合类 | Mixup, CutMix | 样本间线性/空间插值 |

**Mixup**（Zhang et al., 2018）——样本对线性插值：
$$\tilde{x} = \lambda x_i + (1-\lambda) x_j,\qquad \tilde{y} = \lambda y_i + (1-\lambda) y_j,\qquad \lambda \sim \text{Beta}(\alpha, \alpha)$$

**CutMix**（Yun et al., 2019）——空间矩形粘贴，标签按面积混合：
$$\tilde{x} = M \odot x_i + (1-M) \odot x_j,\qquad \tilde{y} = \frac{|M|}{HW} y_i + \left(1-\frac{|M|}{HW}\right)y_j$$

### 5.2 Dropout（Srivastava et al., 2014）

训练时每个神经元以概率 $p$ 丢弃，保留者按 $\frac{1}{1-p}$ 缩放（**倒置 Dropout**）：
$$h' = h \odot \frac{m}{1-p},\qquad m_j \sim \text{Bernoulli}(1-p)$$

测试时**不做 Dropout**——训练中 $\frac{1}{1-p}$ 缩放已保证 $\mathbb{E}[h'] = h$，训练/测试期望自动对齐。

> Dropout = 每次训练随机子网络，测试时近似 $2^n$ 子网络集成。除以 $1-p$ 让期望一致，无需测试时缩放。

### 5.3 L1 / L2 权重衰减（Weight Decay）

在损失上加参数范数惩罚：$L_{\text{total}} = L_{\text{data}}(\theta) + \lambda R(W)$

- **L2 正则化**（Ridge）：$R(W) = \frac{1}{2}\|W\|_2^2$
  $$w \leftarrow (1-\eta\lambda)w - \eta\frac{\partial L_{\text{data}}}{\partial w}$$
  每次更新先缩小权重 $1-\eta\lambda$ 倍——故名"权重衰减"。

- **L1 正则化**（Lasso）：$R(W) = \|W\|_1$
  $$w \leftarrow w - \eta\left(\frac{\partial L_{\text{data}}}{\partial w} + \lambda \cdot \text{sign}(w)\right)$$
  产生**稀疏解**——部分权重精确为零。

| 特性 | L2 | L1 |
|:---|:---|:---|
| 约束域 | 圆形（$\|w\|_2 \leq C$） | 菱形（$\|w\|_1 \leq C$） |
| 解 | 权重均匀缩小，非零 | 稀疏解 |
| 贝叶斯 | 高斯先验 MAP | 拉普拉斯先验 MAP |
| DL 使用 | **极其常用**（AdamW 标配） | 较少用 |

> **Adam vs AdamW**：Adam 原始 weight_decay = L2 正则（加到梯度），与自适应学习率耦合。AdamW 解耦——直接在权重上乘法衰减 $w \leftarrow (1-\eta\lambda)w$，效果显著更好。PyTorch 中永远用 `AdamW`。

### 5.4 Early Stopping

监控验证集性能，当验证误差不再下降时停止训练，返回验证误差最小的模型参数。

- **Patience**：允许验证误差连续不改善的 epoch 数（典型 5-20）。
- **本质**：将参数限制在初始值附近邻域内，等价于限制优化步数——"时间维度"的正则化，与 L2 正则有一定等价性（Bishop, 1995）。

### 5.5 符号速查表

| 符号 | 含义 | 备注 |
|:---|:---|:---|
| $T \sim \mathcal{T}$ | 从增强变换池中随机采样 | 只用于训练 |
| $\lambda$（Mixup） | 混合系数，Beta 分布采样 | $\alpha$ 通常 0.2-1.0 |
| $p$（Dropout） | 丢弃概率 | FC 层 $p=0.5$，Conv 层 $p=0.1-0.2$ |
| $\lambda$（权重衰减） | 正则化强度系数 | 常用 $10^{-4} \sim 10^{-2}$ |
| $\eta$ | 学习率 | — |

## 6. 推导思路和思想来源

### 数据增强
- **最初困难**：标注数据昂贵，真实世界变化（光照、视角、遮挡）无法穷举采集。
- **关键转念**：把人类已知的"不变性"编码进训练——翻转不改变语义，就让模型见到翻转样本。LeCun 在 MNIST 中的弹性变形是早期典范。
- **Mixup 的推广**：在样本凸组合上训练，鼓励决策边界线性平滑——不仅是"等价变换"，更在样本间插值。

### Dropout
- **动机**：全连接层神经元容易"共适应"——A 只在 B 也激活时有效，削弱独立泛化能力。
- **关键转念**：每次随机丢弃一半 = 每次训练不同子网络，测试时等价于对 $2^n$ 个子网络做集成平均——倒置 Dropout 的缩放近似了该集成。可视为 Bagging 的极端高效变体（权重共享，每次只训练子集）。

### L1/L2 几何直觉
- L2 约束域圆形：各维度被均匀缩小，不产生零。
- L1 约束域菱形（有尖角）：最优解容易落在坐标轴上 → 稀疏解 → 自动特征选择。
- 贝叶斯视角：L2 = 高斯先验的 MAP，L1 = 拉普拉斯先验的 MAP。

### 共同底层逻辑
都在**不过度损害训练集拟合的前提下，限制模型的"有效自由度"**。增强限制数据多样性、Dropout 限制共适应、权重衰减限制大小、Early Stopping 限制步数——四者互补，从不同维度夹击过拟合。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础（手算 Dropout）

- **题目**：全连接层 Dropout $p=0.5$，训练时原输出 $h = [2.0, -1.0, 0.0, 4.0]$。掩码 $m = [1, 0, 1, 0]$（1=保留，0=丢弃），求倒置 Dropout 输出 $h'$。
- **解**：$h'_j = h_j \cdot \frac{m_j}{1-0.5} = 2h_j \cdot m_j$。$h' = [4.0, 0.0, 0.0, 0.0]$。
- **易错**：忘记 $\frac{1}{1-p}$ 缩放！若只 mask 不缩放，$\mathbb{E}[h'] = 0.5h$，训练/测试分布不一致。

### 例子 2：中等（增强策略设计）

- **题目**：训练一个 X 光片肺炎分类器（5000 张）。设计增强与正则化策略。
- **解**：
  - 增强：水平翻转 ✓（肺左右对称）；小角度旋转 ±10° ✓（拍摄角度偏差）；亮度对比度微调 ✓（设备差异）。**禁止**垂直翻转（解剖上下不对称）、大角度旋转、CutMix（混入不同患者组织可能伪造病理特征）。
  - 正则化：Dropout $p=0.5$ 用于全连接分类头；L2 weight_decay=$10^{-4}$；Early Stopping patience=15。
  - **原则**：医学影像增强受限于"解剖语义不变性"，比自然图像更保守。

### 例子 3：实际应用（PyTorch 代码）

```python
import torch.nn as nn, torchvision.transforms as T
from torch.optim import AdamW

# ===== 增强管线 =====
train_tf = T.Compose([
    T.RandomResizedCrop(224), T.RandomHorizontalFlip(p=0.5),
    T.ColorJitter(0.4,0.4,0.4,0.1), T.ToTensor(),
    T.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225]),
])
test_tf = T.Compose([
    T.Resize(256), T.CenterCrop(224), T.ToTensor(),
    T.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225]),
])

# ===== Mixup =====
def mixup(x, y, alpha=0.2):
    lam = torch.distributions.Beta(alpha,alpha).sample((x.size(0),)).to(x.device)
    idx = torch.randperm(x.size(0), device=x.device)
    return lam.view(-1,1,1,1)*x+(1-lam.view(-1,1,1,1))*x[idx], y, y[idx], lam

# ===== 模型 + Dropout =====
model = nn.Sequential(
    nn.Conv2d(3,64,3,padding=1), nn.BatchNorm2d(64), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(64,128,3,padding=1), nn.BatchNorm2d(128), nn.ReLU(),
    nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Dropout(0.5), nn.Linear(128,10),
)

# ===== AdamW（解耦权重衰减）=====
opt = AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

# ===== 训练循环（含 Early Stopping）=====
best_loss, patience, cnt = float('inf'), 10, 0
for ep in range(100):
    model.train()                    # 启用 Dropout
    for x, y in train_loader:
        x, y = x.cuda(), y.cuda()
        if use_mixup:
            x_m, ya, yb, lam = mixup(x, y)
            loss = lam*nn.CrossEntropyLoss()(model(x_m),ya)+(1-lam)*nn.CrossEntropyLoss()(model(x_m),yb)
        else:
            loss = nn.CrossEntropyLoss()(model(x), y)
        opt.zero_grad(); loss.backward(); opt.step()

    model.eval()                     # 关闭 Dropout
    vloss = sum(nn.CrossEntropyLoss()(model(x.cuda()),y.cuda()).item() for x,y in val_loader)/len(val_loader)
    if vloss < best_loss: best_loss = vloss; cnt = 0; torch.save(model.state_dict(),'best.pth')
    else: cnt += 1
    if cnt >= patience: break

model.load_state_dict(torch.load('best.pth')); model.eval()  # 测试：关闭 Dropout
```

> **关键**：`model.train()` ↔ `model.eval()` 切换 Dropout/BN；增强只在训练 transform；Early Stopping 保存**验证最佳**模型，不是最后一个。

## 8. 常见误区和易混概念

### 误区 1：增强和正则化是一回事
- **为什么错**：增强在数据端制造多样性——若数据全是白天照片，增强无法创造夜间照片。正则化在模型端约束——若模型容量不够（欠拟合），加正则化只会更差。
- **正确理解**：增强是"隐式正则化"（不修改损失），L1/L2/Dropout 是"显式正则化"。过拟合时先加增强（零成本涨点），再配合适的正则化。

### 误区 2：测试时也用 Dropout 或增强
- **为什么错**：Dropout 的随机丢弃只是"训练技巧"——测试时需要全部神经元协同。增强同理，测试应评估真实泛化。
- **正确理解**：`model.eval()` 关闭 Dropout，测试 DataLoader 不做增强——铁律。TTA（测试时增强取平均）是可选后处理，有额外代价。

### 误区 3：Adam 的 weight_decay = L2 正则
- **为什么错**：原始 Adam 将 weight_decay 实现为加到梯度上的 L2 惩罚，与自适应学习率耦合。AdamW 将其解耦——直接在权重上乘法衰减，效果显著更好。
- **正确理解**：PyTorch 中永久使用 `AdamW` 而非 `Adam` 的 `weight_decay`。

### 误区 4：Early Stopping 的 patience 越小越好
- **为什么错**：验证 loss 有随机波动，patience 过小会因噪声提前截停。
- **正确理解**：patience 通常取 5-20 epoch，同时保存验证最佳模型（不是最后一个）。

### 概念对比表

| 概念 | 作用层 | 机制 | 训练/测试差异 | 典型超参 |
|:---|:---|:---|:---|:---|
| 数据增强 | 数据端 | 增广样本，注入不变性 | 训练做/测试不做 | 翻转 p=0.5, 裁剪尺度 |
| Dropout | 模型端 | 随机丢弃神经元，防共适应 | 训练丢弃/测试全激活 | $p=0.2\sim0.5$ |
| L2 权重衰减 | 损失端 | 惩罚大权重，偏好简单解 | 一致 | $\lambda=10^{-4}\sim10^{-2}$ |
| L1 正则化 | 损失端 | 产生稀疏权重 | 一致 | $\lambda=10^{-5}\sim10^{-3}$ |
| Early Stopping | 优化端 | 限制训练步数 | 一致（验证监控） | patience=5~20 |
| Label Smoothing | 标签端 | 软化 one-hot 标签 | 一致 | $\epsilon=0.1$ |

### 题目与解析

#### 1. 「数据增强」和「L2 正则化」都能防过拟合，本质区别是什么？
> [!question]- 答案解析
> - **答案**：增强在**数据端**——通过保持语义的随机变换扩大训练集，注入不变性（隐式正则化），不修改模型或损失函数。L2 在**损失端**——显式惩罚大权重、约束复杂度，优化修改后的目标函数。二者互补：增强让模型"见更多"，正则让模型"学更浅"。
> - **易错原因**：只答"都是防过拟合"，漏掉作用层级的差异。

#### 2. 推导 L2 权重衰减的 SGD 更新公式，说明为何叫"权重衰减"。
> [!question]- 答案解析
> - **答案**：$w_{t+1} = w_t - \eta(\nabla L_{\text{data}} + \lambda w_t) = (1-\eta\lambda)w_t - \eta\nabla L_{\text{data}}$。第一项 $(1-\eta\lambda)w_t$ 将权重缩小到原来的 $1-\eta\lambda$ 倍——每次迭代权重先"衰减"一步，再沿数据梯度方向移动。
> - **解析**：AdamW 将此衰减解耦出来，直接在权重上乘法衰减，不与自适应学习率耦合。

#### 3. 以下哪个任务不应使用水平翻转增强？A. 猫狗分类 B. 手写数字识别 C. 航拍建筑物分割？
> [!question]- 答案解析
> - **答案**：B。手写数字：6 ↔ 9 翻转后语义改变。A 可用（猫狗左右对称）；C 可用（航拍建筑物朝向任意）。
> - **解析**：增强第一原则——**变换必须保持标签不变**。

#### 4. 某全连接层 Dropout $p=0.5$，训练时原输出 $h$ 的 L2 范数为 8.0。同一输入在测试时（关闭 Dropout），输出 L2 范数的期望是多少？
> [!question]- 答案解析
> - **答案**：约 8.0。倒置 Dropout 的 $\frac{1}{1-p}$ 缩放保证了 $\mathbb{E}[h'_{\text{train}}] = \mathbb{E}[h_{\text{test}}] = h$。
> - **易错原因**：混淆"原始 Dropout"（训练不缩放，测试乘 $1-p$）和"倒置 Dropout"（训练缩放，测试不变）——现代框架均默认倒置 Dropout。

#### 5. CIFAR-10 上 ResNet-18 训练 acc=99%、验证 acc=82%。设计一个"增强 + 正则化"组合策略。
> [!question]- 答案解析
> - **答案**（组合策略）：
>   ① 增强：`RandomCrop(32, padding=4)` + `RandomHorizontalFlip` + Cutout(16) + Mixup($\alpha=0.2$)。CIFAR 图小，大尺度裁剪不合适。
>   ② 权重衰减：AdamW `weight_decay=5e-4`。
>   ③ Dropout：仅全连接分类头加 `p=0.3`（ResNet 主靠 BN 正则）。
>   ④ Early Stopping：patience=20，保存最佳验证模型。
>   ⑤ Label Smoothing $\epsilon=0.1$：防止过度自信。
> - **解析**：训练 acc ≫ 验证 acc = 典型过拟合。顺序：先加增强（不改模型），再加 Dropout，最后调 weight_decay。
