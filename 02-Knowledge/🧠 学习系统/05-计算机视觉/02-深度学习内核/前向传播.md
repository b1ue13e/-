# 前向传播 (Forward Propagation)

> 所属模块：[[02-Knowledge/🧠 学习系统/05-计算机视觉/🗺️ 计算机视觉学习路径|计算机视觉学习路径]]

> 建议先看：[[MLP]]、[[激活函数详解]]

---

## 0. 类别：A 类核心概念

前向传播是神经网络的"推理引擎"。理解它 → 理解反向传播（反向传播就是前向传播的逆过程）。

---

## 1. 直觉：数据流过网络

前向传播 = 输入 $\mathbf{x}$ 逐层经过线性变换 + 非线性激活，最终输出预测 $\hat{\mathbf{y}}$。

每层做两件事：
1. **线性变换**：$\mathbf{z}^{(l)} = \mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}$（仿射变换）
2. **非线性激活**：$\mathbf{a}^{(l)} = \sigma(\mathbf{z}^{(l)})$（引入非线性）

---

## 2. 正式定义

对于 $L$ 层网络：

$$\mathbf{a}^{(0)} = \mathbf{x} \quad \text{（输入）}$$
$$\mathbf{z}^{(l)} = \mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)} \quad l = 1, \ldots, L$$
$$\mathbf{a}^{(l)} = \sigma^{(l)}(\mathbf{z}^{(l)}) \quad l = 1, \ldots, L-1$$
$$\hat{\mathbf{y}} = \mathbf{a}^{(L)} \quad \text{（输出）}$$

### 形状追踪

| 层 | 权重形状 | 偏置形状 | 输出形状 |
|:---|:---|:---|:---|
| 输入 | — | — | $N \times d$ |
| 隐藏层 1 | $h_1 \times d$ | $h_1$ | $N \times h_1$ |
| 隐藏层 2 | $h_2 \times h_1$ | $h_2$ | $N \times h_2$ |
| 输出层 | $c \times h_2$ | $c$ | $N \times c$ |

> $N$ = 批量大小，$d$ = 输入维度，$h_i$ = 隐藏层维度，$c$ = 类别数。

---

## 3. 纯 NumPy 实现（理解底层）

```python
import numpy as np

def forward_pass(x, params):
    """
    x: (N, d) 输入
    params: [(W1,b1), (W2,b2), ...] 每层的权重和偏置
    """
    cache = {'a0': x}  # 缓存中间值，反向传播需要
    a = x
    for l, (W, b) in enumerate(params):
        z = a @ W.T + b          # 线性变换 (N, h)
        if l < len(params) - 1:   # 隐藏层：加激活
            a = np.maximum(0, z)   # ReLU
        else:                      # 输出层：不加激活（或Softmax）
            a = z
        cache[f'z{l+1}'] = z
        cache[f'a{l+1}'] = a
    return a, cache

# 示例：2层网络 (d=784, h=128, c=10)
np.random.seed(42)
W1 = np.random.randn(128, 784) * 0.01
b1 = np.zeros(128)
W2 = np.random.randn(10, 128) * 0.01
b2 = np.zeros(10)
params = [(W1, b1), (W2, b2)]

x = np.random.randn(32, 784)  # 批量32张图
output, cache = forward_pass(x, params)
print(f"Input shape: {x.shape}")       # (32, 784)
print(f"Hidden a1 shape: {cache['a1'].shape}")  # (32, 128)
print(f"Output shape: {output.shape}") # (32, 10) — 10个类别的logits
```

## 4. 前向传播中的关键概念

### 4.1 缓存 (Caching)

前向传播必须保存所有中间值 $\mathbf{z}^{(l)}$ 和 $\mathbf{a}^{(l)}$，因为反向传播需要它们计算梯度。

### 4.2 训练 vs 推理

| 阶段 | 缓存 | Dropout | BatchNorm |
|:---|:---|:---|:---|
| **训练** | ✅ 保存全部中间值 | ✅ 随机失活 | 用批次统计 |
| **推理** | ❌ 不缓存（省内存） | ❌ 关闭 | 用全局统计 |

---

## 5. 常见误区

- ❌ "前向传播就是算一次输出" — 训练中前向传播的中间值必须缓存，否则无法反向传播
- ❌ "softmax 是激活函数" — softmax 通常在最后一层，但它不是逐元素的激活函数（依赖整个向量）
- ❌ "输出层需要激活函数" — 分类用 softmax，回归通常不用；二分类用 sigmoid

## 🧪 自测题

1. **(基础)** 一个输入 784 维、隐藏 128 维、输出 10 类的两层 MLP，有多少个参数？
   <details><summary>💡 提示</summary>W1: 128×784=100352, b1: 128, W2: 10×128=1280, b2: 10。总计 101,770 个参数。</details>

2. **(中等)** 为什么训练时前向传播必须缓存中间值，而推理时不需要？
   <details><summary>💡 提示</summary>反向传播需要 $\mathbf{z}^{(l)}$ 和 $\mathbf{a}^{(l-1)}$ 来计算 $\partial L/\partial \mathbf{W}^{(l)}$。推理只做前向，不需要梯度。</details>

3. **(较难)** 如果前向传播中 $\mathbf{a}^{(l)} = \sigma(\mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)})$ 对所有层使用线性激活 $\sigma(z)=z$，最终输出与输入的关系是什么？
   <details><summary>💡 提示</summary>$\hat{\mathbf{y}} = \mathbf{W}^{(L)}\cdots\mathbf{W}^{(1)}\mathbf{x} + \text{常数} = \mathbf{W}_{\text{total}}\mathbf{x} + \mathbf{b}_{\text{total}}$，退化为线性模型。</details>
