# 计算图与自动微分 (Computational Graph & Autograd)

> 所属模块：[[02-Knowledge/🧠 学习系统/05-计算机视觉/🗺️ 计算机视觉学习路径|计算机视觉学习路径]]

## 0. 类别：A 类核心概念

计算图是 PyTorch/TensorFlow 自动求导的底层原理。`loss.backward()` 一行代码背后的整个机制。

---

## 1. 直觉：每个运算是一个节点

计算图 = **有向无环图 (DAG)**：
- **节点** = 数学运算（+、×、ReLU、MatMul...）
- **边** = 数据流动（张量）

前向传播 = 沿图从输入到输出计算值
反向传播 = 沿图从输出到输入传播梯度

---

## 2. 简单示例：$f = (x + y) \times z$

```
    x ──┐
         ├─ (+) ── u ──┐
    y ──┘               ├─ (×) ── f
    z ─────────────────┘
```

### 前向传播
$$\begin{aligned} u &= x + y = 3 + (-2) = 1 \\ f &= u \times z = 1 \times 4 = 4 \end{aligned}$$

### 反向传播（链式法则）
$$\begin{aligned} \frac{\partial f}{\partial f} &= 1 \\ \frac{\partial f}{\partial u} &= \frac{\partial f}{\partial f} \cdot z = 4 \\ \frac{\partial f}{\partial z} &= \frac{\partial f}{\partial f} \cdot u = 1 \\ \frac{\partial f}{\partial x} &= \frac{\partial f}{\partial u} \cdot \frac{\partial u}{\partial x} = 4 \times 1 = 4 \\ \frac{\partial f}{\partial y} &= \frac{\partial f}{\partial u} \cdot \frac{\partial u}{\partial y} = 4 \times 1 = 4 \end{aligned}$$

## 3. PyTorch Autograd 原理

```python
import torch

# 构建计算图
x = torch.tensor(3.0, requires_grad=True)
y = torch.tensor(-2.0, requires_grad=True)
z = torch.tensor(4.0, requires_grad=True)

u = x + y        # 节点：AddBackward
f = u * z        # 节点：MulBackward

f.backward()     # 反向传播！

print(f"df/dx = {x.grad}")  # 4.0
print(f"df/dy = {y.grad}")  # 4.0
print(f"df/dz = {z.grad}")  # 1.0
```

### 关键机制

| 操作 | 说明 |
|:---|:---|
| `requires_grad=True` | 标记需要梯度的张量（叶节点） |
| `f.backward()` | 从 f 开始沿计算图反向传播 |
| `.grad` | 梯度累积在叶节点的 `.grad` 属性 |
| `.grad_fn` | 每个非叶节点记录的梯度函数 |
| `torch.no_grad()` | 禁用计算图构建（推理时用） |
| `.detach()` | 从计算图断开（如 GAN 训练时冻结判别器） |

---

## 4. 反向传播的两种模式

| 模式 | 原理 | 代表框架 |
|:---|:---|:---|
| **静态图** | 先构建完整图，再执行 | TensorFlow 1.x |
| **动态图** | 每次前向传播动态构建图 | **PyTorch**（默认）、TensorFlow 2.x Eager |

**动态图的优势**：支持 Python 原生控制流（if/for/while），调试直观（可用 pdb）。

---

## 5. 常见梯度问题

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| **梯度累积** | 多次 `backward()` 未清零 | 每次更新前 `optimizer.zero_grad()` |
| **in-place 修改** | 修改了需要梯度的张量 | 用 `x = x + 1` 而非 `x += 1` |
| **计算图断开** | `.detach()` 或 `.data` 误用 | 确保梯度路径完整 |
| **非叶节点无 .grad** | PyTorch 默认不保留中间梯度 | 用 `.retain_grad()` |

## 🧪 自测题

1. **(基础)** `x = torch.tensor(2.0, requires_grad=True); y = x ** 2; y.backward(); x.grad` 的值是多少？
   <details><summary>💡 提示</summary>$y = x^2$，$dy/dx = 2x = 4$。x.grad = 4.0。</details>

2. **(中等)** 如果调用 `loss.backward()` 两次而不调用 `optimizer.zero_grad()`，会发生什么？
   <details><summary>💡 提示</summary>梯度会**累加**而不是覆盖。第二次 `.backward()` 的梯度加在第一次的结果上，导致参数更新量错误。</details>

3. **(较难)** 为什么 PyTorch 默认不保留非叶节点的 `.grad`？什么时候需要手动 `.retain_grad()`？
   <details><summary>💡 提示</summary>省内存——训练通常只需要参数梯度。调试梯度流、可视化中间层梯度、或实现自定义梯度惩罚时需要 `.retain_grad()`。</details>
