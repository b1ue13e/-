## 1. 📌 TL;DR

反向传播（Backpropagation）的本质是**链式法则 + 动态规划**：

1. **前向传播**：按拓扑序计算每个节点的输出，缓存计算图
2. **反向传播**：从损失开始，**逆拓扑序**逐节点计算梯度。每个节点将"上游梯度"乘以"本地梯度"后传递给输入
3. **关键性质**：一次前向 + 一次反向 = 所有参数的梯度，时间复杂度 $O(N)$

> 核心口诀：**"本地梯度 × 上游梯度，加法是分发器，乘法是交换器"**。

---

## 2. 🔑 核心概念

### 2.1 为什么需要反向传播？

朴素方法（有限差分）对每个参数计算 $\frac{\partial L}{\partial w_i} \approx \frac{L(w_i+\epsilon) - L(w_i)}{\epsilon}$ 需要 $N+1$ 次前向传播。百万参数 → 完全不可行。

反向传播的关键洞察：**利用链式法则，一次前向 + 一次反向得到所有梯度**。

### 2.2 计算图（Computation Graph）

计算图是表示数学计算的**有向无环图（DAG）**：
- **节点**：运算（+、×、σ）或变量
- **边**：数据依赖关系
- **拓扑序**：前向按拓扑序执行；反向按逆拓扑序执行

```
x=2 ──┐
       ├──→ [+] ──→ q=5 ──┐
y=3 ──┘                   ├──→ [×] ──→ f=20
z=4 ──────────────────────┘
```

> 上图：$f = (x + y) \times z$。$q$ 是中间节点。

### 2.3 链式法则

**标量形式**：若 $y=g(x), z=f(y)$，则 $\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}$

**多变量形式**：$\frac{\partial L}{\partial x_i} = \sum_j \frac{\partial L}{\partial y_j} \cdot \frac{\partial y_j}{\partial x_i}$

或向量形式：$\nabla_{\mathbf{x}} L = \left(\frac{\partial \mathbf{y}}{\partial \mathbf{x}}\right)^\top \nabla_{\mathbf{y}} L$

---

## 3. 📐 数学基础

### 3.1 计算图中的链式法则

设节点按拓扑序排列为 $v_1, \ldots, v_N$（$v_N = L$），对任意节点 $v_i$：

$$\frac{\partial L}{\partial v_i} = \sum_{v_j \in \text{Children}(v_i)} \frac{\partial L}{\partial v_j} \cdot \frac{\partial v_j}{\partial v_i}$$

每个节点只需：
- **上游梯度** $\frac{\partial L}{\partial v_j}$（从子节点传来）
- **本地梯度** $\frac{\partial v_j}{\partial v_i}$（该操作对输入的偏导）

### 3.2 为什么是 $O(N)$？

朴素链式法则展开每条路径 → $O(2^N)$（指数级）。反向传播**缓存中间梯度**（动态规划），每个节点只算一次 → $O(N)$。

```
前向：计算并缓存中间值  → O(N)
反向：利用缓存计算梯度  → O(N)
────────────────────────────────
总计：                  → O(N)
```

---

## 4. 💡 直观理解

把反向传播想象为**生产线的责任追溯**：

1. 原材料 → 工序1 → 工序2 → ... → 产品出现偏差（损失）
2. 从最终偏差开始，逐级追溯：偏差中有多少是工序N造成的？工序N的偏差中有多少是工序N-1造成的？

**加法操作**：$y=a+b$，$y$ 的偏差 $\delta$ → $a$ 和 $b$ 各承担 $\delta$（因为 $\frac{\partial y}{\partial a}=\frac{\partial y}{\partial b}=1$）——**公平分发**。

**乘法操作**：$y=a \times b$，$y$ 的偏差 $\delta$ → $a$ 承担 $b \cdot \delta$，$b$ 承担 $a \cdot \delta$ ——**按对方的值分配**。

---

## 5. 🏗️ 计算图节点类型

### 5.1 核心门的梯度规则

| 操作 | 前向 | 本地梯度 | 直觉 |
|------|------|----------|------|
| $f=a+b$ | $a+b$ | $(1, 1)$ | **分发器**：上游梯度不变地分发 |
| $f=a \times b$ | $a \cdot b$ | $(b, a)$ | **交换器**：上游×另一个输入 |
| $f=\max(a,b)$ | $\max(a,b)$ | $(\mathbb{1}_{a>b},\; \mathbb{1}_{b \ge a})$ | **路由器**：只传给赢的那个输入 |
| $f=\sigma(x)$ | $\frac{1}{1+e^{-x}}$ | $f(1-f)$ | **自给自足**：梯度由输出决定 |
| $f=\exp(x)$ | $e^x$ | $f$ | 指数=自身 |
| $f=\log(x)$ | $\ln x$ | $1/x$ | 对数=倒数 |
| $f=\text{ReLU}(x)$ | $\max(0,x)$ | $\mathbb{1}_{x>0}$ | 正数传、负数断 |

### 5.2 乘法门的代码模式

```python
def mul_forward(a, b):
    return a * b, (a, b)        # 返回值和缓存

def mul_backward(upstream, cache):
    a, b = cache
    return upstream * b, upstream * a   # 本地梯度 × 上游梯度
```

### 5.3 Sigmoid门的特殊性质

$$\frac{d\sigma}{dx} = \sigma(x)(1-\sigma(x))$$

梯度在 $x=0$ 时最大（$0.25$），$|x|$ 增大时趋近于 0（**梯度饱和**）。

## 6. ⚙️ 反向传播机制

### 6.1 核心公式

对每条边 $v_i \to v_j$：

$$\boxed{\text{grad}[v_i] \;\; += \;\; \text{grad}[v_j] \;\; \times \;\; \frac{\partial v_j}{\partial v_i}}$$

- $\text{grad}[v_j]$：上游梯度
- $\frac{\partial v_j}{\partial v_i}$：本地梯度
- `+=`（非 `=`）：因为一个节点可能流向多个子节点，梯度需要**求和**

### 6.2 算法伪代码

```
1. 拓扑排序计算图 → [v_1, ..., v_N], v_N = L
2. 前向传播：按拓扑序执行每个节点，缓存输出
3. grad[L] = 1
4. 逆拓扑序遍历 [v_{N-1}, ..., v_1]：
     对 v_j 的每个输入 v_i：
        grad[v_i] += grad[v_j] × (∂v_j/∂v_i)
5. 返回 grad
```

### 6.3 分支合并

当 $v_i$ 流向多个子节点 $v_{j_1}, v_{j_2}$：

$$\frac{\partial L}{\partial v_i} = \frac{\partial L}{\partial v_{j_1}} \cdot \frac{\partial v_{j_1}}{\partial v_i} + \frac{\partial L}{\partial v_{j_2}} \cdot \frac{\partial v_{j_2}}{\partial v_i}$$

> 这就是为什么 PyTorch 中多次 `.backward()` 会累加梯度 —— 分支合并的 `+=` 语义。

## 7. 📝 手算示例：$f(x, y, z) = (x + y) \times z$

### 7.1 设定与计算图

取 $x=2, y=3, z=4$：

```
x=2 ──┐
       ├──→ [+] ──→ q=5 ──┐
y=3 ──┘                   ├──→ [×] ──→ f=20
z=4 ──────────────────────┘
```

### 7.2 完整反向传播表

| 步骤 | 节点 | 上游梯度 | 本地梯度 | 传递给 | 结果 |
|------|------|----------|----------|--------|------|
| ① | — | — | — | $\frac{\partial f}{\partial f}$ | **1** |
| ② | × → z | 1 | $\frac{\partial f}{\partial z}=q=5$ | $\frac{\partial f}{\partial z}$ | **5** |
| ③ | × → q | 1 | $\frac{\partial f}{\partial q}=z=4$ | $\frac{\partial f}{\partial q}$ | **4** |
| ④ | + → x | 4 | $\frac{\partial q}{\partial x}=1$ | $\frac{\partial f}{\partial x}$ | **4** |
| ⑤ | + → y | 4 | $\frac{\partial q}{\partial y}=1$ | $\frac{\partial f}{\partial y}$ | **4** |

### 7.3 结果汇总

| 变量 | 值 | $\frac{\partial f}{\partial \cdot}$ | 直觉验证 |
|------|-----|-------------------------------------|----------|
| $x$ | 2 | **4** | $x \uparrow 1 \to q \uparrow 1 \to f \uparrow z=4$ ✓ |
| $y$ | 3 | **4** | $y \uparrow 1 \to q \uparrow 1 \to f \uparrow z=4$ ✓ |
| $z$ | 4 | **5** | $z \uparrow 1 \to f \uparrow q=5$ ✓ |
| $q$ | 5 | **4** | 中间变量，$q \uparrow 1 \to f \uparrow z=4$ ✓ |

### 7.4 直接验证

$$\frac{\partial f}{\partial x} = \frac{\partial f}{\partial q} \cdot \frac{\partial q}{\partial x} = z \cdot 1 = 4 \quad \checkmark$$

$$\frac{\partial f}{\partial y} = z \cdot 1 = 4 \quad \checkmark \qquad \frac{\partial f}{\partial z} = q = 5 \quad \checkmark$$

> **关键观察**：每个节点只与直接邻居交互——加法门不需要知道上游有个乘法门。这种**局部性**是反向传播可扩展的关键。

## 8. 💻 代码实现

### 8.1 从零实现计算图反向传播

```python
import numpy as np

class Node:
    def __init__(self, value, name=""):
        self.value = value
        self.grad = 0.0
        self.name = name

def forward_add(a, b, name=""):
    result = Node(a.value + b.value, name)
    result._backward = lambda upstream: (
        setattr(a, 'grad', a.grad + upstream),
        setattr(b, 'grad', b.grad + upstream)
    )
    result._inputs = [a, b]
    return result

def forward_mul(a, b, name=""):
    result = Node(a.value * b.value, name)
    result._backward = lambda upstream: (
        setattr(a, 'grad', a.grad + b.value * upstream),
        setattr(b, 'grad', b.grad + a.value * upstream)
    )
    result._inputs = [a, b]
    return result

def backward(root):
    # 拓扑排序
    topo, visited = [], set()
    def build(node):
        if node not in visited:
            visited.add(node)
            for inp in getattr(node, '_inputs', []):
                build(inp)
            topo.append(node)
    build(root)

    root.grad = 1.0
    for node in reversed(topo):
        if hasattr(node, '_backward'):
            node._backward(node.grad)

# ─── 测试 f(x,y,z) = (x+y)*z ───
x, y, z = Node(2, "x"), Node(3, "y"), Node(4, "z")
q = forward_add(x, y, "q")
f = forward_mul(q, z, "f")
backward(f)

print(f"∂f/∂x={x.grad}, ∂f/∂y={y.grad}, ∂f/∂z={z.grad}")  # 4, 4, 5
assert abs(x.grad-4)<1e-6 and abs(y.grad-4)<1e-6 and abs(z.grad-5)<1e-6
print("✅ 梯度验证通过！")
```

### 8.2 PyTorch autograd 等价实现

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)
z = torch.tensor(4.0, requires_grad=True)

q = x + y          # grad_fn=<AddBackward0>
f = q * z          # grad_fn=<MulBackward0>
f.backward()       # 自动反向传播！

print(f"∂f/∂x={x.grad}, ∂f/∂y={y.grad}, ∂f/∂z={z.grad}")  # 4, 4, 5
assert torch.allclose(x.grad, torch.tensor(4.0))
print("✅ PyTorch autograd 验证通过！")
```

### 8.3 PyTorch autograd 关键API

| API | 作用 |
|-----|------|
| `requires_grad=True` | 标记需要梯度的张量 |
| `.backward()` | 触发反向传播 |
| `.grad` | 查看累积的梯度 |
| `.zero_grad()` | 清零梯度（训练循环必需！） |
| `.detach()` | 从计算图分离（停止梯度传播） |
| `torch.no_grad():` | 上下文管理器，禁用梯度（推理用） |

### 8.4 PyTorch 动态计算图

PyTorch 使用**Define-by-Run**：每次前向传播即时构建图，图取决于实际控制流，`.backward()` 后图自动释放。

```python
x = torch.randn(5, requires_grad=True)
if x.sum() > 0:
    y = x * 2      # 一种图结构
else:
    y = x * 3      # 另一种图结构
y.backward()       # 只对实际执行的路径求梯度
```

> 与 TensorFlow 1.x 的静态图（Define-and-Run）形成对比——动态图更灵活、易调试。

## 9. 🔗 与其他概念的连接

```
损失函数 → 反向传播 → 优化器(SGD/Adam) → 参数更新
              ↕                           ↕
         BatchNorm反向传播          CNN/RNN前向传播
```

| 概念 | 与本卡片的关系 |
|------|---------------|
| **损失函数** | 给出初始上游梯度 $\frac{\partial L}{\partial \text{output}}$ |
| **优化器** | 拿到梯度后更新参数：$w \leftarrow w - \eta \cdot \nabla_w L$ |
| **CNN** | 卷积层的反向传播也是卷积（转置卷积），同一条链式法则 |
| **BatchNorm** | 反向传播需考虑 $\mu,\sigma$ 对输入的依赖 |
| **残差连接** | 跳跃连接提供"梯度高速公路"，缓解梯度消失 |
| **梯度裁剪** | 当梯度过大时裁剪到阈值内 |

## 10. ⚠️ 常见误区

**误区1："反向传播只是链式法则"** → 片面。它是**链式法则 + 动态规划**（缓存中间结果）。纯链式法则展开是 $O(2^N)$，缓存后才是 $O(N)$。

**误区2："梯度只在叶子节点有意义"** → 不完全。中间层梯度用于梯度裁剪、Grad-CAM可视化、对抗攻击等。

**误区3："backward()只能调用一次"** → 可多次，但默认释放图（省显存）。多次调用会累加梯度，需先 `zero_grad()`。

**误区4："梯度的维度必须匹配"** → 梯度可广播。broadcasting 操作的反向传播会自动求和以匹配输入形状。

**误区5："Sigmoid梯度小所以不能用"** → 过于绝对。在二分类输出层、LSTM遗忘门、配合BatchNorm时仍有用。

## 11. 🎯 实践建议

### 梯度检查（Gradient Check）——验证反向传播正确性的金标准

```python
def gradient_check(f, x, eps=1e-6):
    """比较解析梯度 vs 数值梯度（中心差分）"""
    y = f(x); y.backward()
    analytical = x.grad.clone()

    numerical = torch.zeros_like(x)
    for i in range(x.numel()):
        x_flat = x.detach().clone().flatten()
        x_flat[i] += eps
        y_plus = f(x_flat.view_as(x))
        x_flat[i] -= 2 * eps
        y_minus = f(x_flat.view_as(x))
        numerical.flatten()[i] = (y_plus - y_minus) / (2 * eps)

    rel_error = (analytical - numerical).abs().max() / \
                (analytical.abs().max() + numerical.abs().max() + 1e-8)
    assert rel_error < 1e-4, f"FAILED: {rel_error:.2e}"
    print(f"✅ Passed: relative error = {rel_error:.2e}")
```

> 经验：相对误差 $<10^{-4}$（float32），$<10^{-7}$（float64）。

### 训练循环最佳实践

- **每步先 `zero_grad()`**：防止梯度累积
- **推理用 `torch.no_grad()`**：避免构建图，省显存
- **`.detach()` 截断梯度**：GAN训练、RL baseline
- **`retain_graph=True` 慎用**：多次反向传播（如元学习）才用，否则泄漏显存
- **混合精度用 `GradScaler`**：防止 float16 小梯度下溢

3. PyTorch 中 `.grad` 和 `.grad_fn` 的区别？
4. 为什么反向传播是 $O(N)$？关键优化是什么？

### 进阶

5. 节点流向多个子节点时，梯度如何处理？写出公式。
6. 为什么 PyTorch 的 `.backward()` 默认释放计算图？
7. 画出 $f(x) = \sigma(w_2 \cdot \sigma(w_1 x + b_1) + b_2)$ 的计算图，标注每个节点的梯度表达式。

<details>
<summary><b>📝 参考答案</b></summary>

**1.** 加法：$(1,1)$ → 分发器；乘法：$(b,a)$ → 交换器（$a$ 的梯度含 $b$，$b$ 的梯度含 $a$）；max：$(\mathbb{1}_{a>b}, \mathbb{1}_{b \ge a})$ → 路由器。

**2.** $q=ab=6, f=q+c=11$。反向：$\partial f/\partial c=1, \partial f/\partial q=1$。$\partial f/\partial a = 1 \cdot b = 3$，$\partial f/\partial b = 1 \cdot a = 2$，$\partial f/\partial c = 1$。

**3.** `.grad` = 梯度值（张量）；`.grad_fn` = 创建该张量的反向操作对象（叶子节点为 None）。

**4.** 朴素链式展开每条路径 → $O(2^N)$；反向传播缓存中间梯度（动态规划），每节点算一次 → $O(N)$。

**5.** $\frac{\partial L}{\partial v_i} = \sum_{v_j \in \text{children}(v_i)} \frac{\partial L}{\partial v_j} \cdot \frac{\partial v_j}{\partial v_i}$，`+=` 语义。

**6.** 节省显存（中间激活不保留）；大多数场景只需一次反向传播。需要多次时用 `retain_graph=True`。

**7.** $x \to [\times:w_1] \to [+:b_1] \to [\sigma] \to h \to [\times:w_2] \to [+:b_2] \to [\sigma] \to f$，链式法则贯穿始终。

</details>
