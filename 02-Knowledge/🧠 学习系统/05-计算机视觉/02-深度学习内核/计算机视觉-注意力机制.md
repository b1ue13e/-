# 注意力机制：SE-Net 与 CBAM（通道/空间注意力）

> 所属路径：[[🗺️ 计算机视觉学习路径|计算机视觉学习路径]]
> 所属阶段：[[🧭 阶段2-深度学习内核|🧠 第二阶段：深度学习内核（模型本质）]]
> 教材入口：[[02-Knowledge/🧠 学习系统/05-计算机视觉/📚 教材挂载索引|教材挂载索引]]
> 核心源：Hu et al. "Squeeze-and-Excitation Networks" (CVPR 2018)；Woo et al. "CBAM: Convolutional Block Attention Module" (ECCV 2018)

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**——注意力机制是 2017 年后 CNN 架构进化最关键的一支，EfficientNet/ConvNeXt/Transformer 都直接或间接建立在其思想上。
- **判断理由**：SENet 是 ImageNet 2017 冠军，思想极其简单（几行代码的"挤压-激励"）却能稳定涨点；理解它之后，CBAM、ECA、Non-local 等变体一通百通，也是从 CNN 过渡到 ViT 自注意力的认知桥梁。
- **学习边界**：本卡只讲**通道注意力（SE）与通道+空间注意力（CBAM）**；自注意力（Transformer）在 [[Transformer与自注意力]] 单独展开；Non-local/自注意力作为延伸提一句，不深挖。

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：CNN 卷积核在每层对所有通道**一视同仁**地做加权求和。但真实情况是——一张"蓝天"图里，蓝色通道信息量大，红色通道几乎无用；一张"草地"图相反。网络其实**知道**哪些通道重要（看响应值就知道），但标准卷积**没有机制**把这个"通道重要性"反馈给特征。

- **旧方法局限**：池化/卷积只在空间维度操作，跨通道信息只能靠堆层数隐式建模；想让网络"关注重要通道"只能靠调参或加层，效率低。
- **必须引入新工具**：SENet 提出"挤压-激励"（Squeeze-and-Excitation）——先用全局池化把每个通道压成一个标量（挤压），再用两个全连接学出一组 0~1 的权重（激励），最后按通道乘回去。**给每个通道发一个"音量旋钮"。**

## 2. 为什么它重要？它有什么用？

- **连接大图景**：不学它，EfficientNet（阶段2 轻量化）的 MBConv 结构看不懂；ViT 的 self-attention 可以理解为"通道注意力 + 空间注意力的全局版"。它是 CNN → Transformer 的认知桥梁。
- **实际应用场景**：图像分类（SENet 冠军）、目标检测（backbone 替换）、语义分割（编码器增强）、模型压缩（注意力引导剪枝）。工程上"加一个 SE 模块"是涨点最便宜的手段之一。
- **高频任务**：任何"换 backbone 涨点"的比赛中，SE/CBAM 几乎必现；面试高频题"SE 模块参数量怎么算"。

## 3. 学它之前需要哪些前置知识？

1. **[[卷积神经网络CNN]]**：知道卷积输出形状 $B\times C\times H\times W$（B 批量、C 通道、H/W 空间尺寸）——这是 SE 操作的输入输出。
2. **[[批归一化BatchNorm]]**：知道"逐通道归一化"和可学习缩放参数 $\gamma$ 的思路——SE 的通道加权与 BN 的通道缩放是近亲思想。

## 4. 用直觉语言解释它

> «"这东西其实就像……"一个调音台——每个通道（乐器）有一个音量推子，网络根据当前输入自动把重要的通道推高、把无关的通道拉低。"»

- **直觉类比**：SE 模块 = 给特征图加一组"自动音量推子"。挤压（Squeeze）= 把整首歌压成一个平均响度读数；激励（Excitation）= 根据读数决定每个推子推多高；重标定（Reweight）= 把推子作用回原音频。
- **为什么很自然**：卷积已经提取了特征，只是不知道"哪些特征对当前样本重要"。全局平均池化把每通道信息浓缩成一个数（挤压），两个全连接负责"读表 → 决定权重"（激励）——信息论上这就像给每通道算了个"重要性估计"。
- **一句话直觉本质**：**用全局统计量给每个通道打分，再用分数重新加权特征。**

## 5. 正式定义、核心公式、符号解释

### 1. 核心定义

SE 模块对特征图 $\mathbf{U}\in\mathbb{R}^{H\times W\times C}$ 依次做三步：

$$\text{Squeeze: } z_c = \frac{1}{H\times W}\sum_{i=1}^{H}\sum_{j=1}^{W} u_c(i,j) \quad (c=1,\dots,C)$$

$$\text{Excitation: } \mathbf{s} = \sigma\big(\mathbf{W}_2\, \delta(\mathbf{W}_1 \mathbf{z})\big), \quad \mathbf{s}\in\mathbb{R}^{C}$$

$$\text{Reweight: } \tilde{\mathbf{x}}_c = s_c \cdot \mathbf{u}_c$$

其中 $\delta$ 为 ReLU，$\sigma$ 为 sigmoid，$\mathbf{W}_1\in\mathbb{R}^{\frac{C}{r}\times C}$、$\mathbf{W}_2\in\mathbb{R}^{C\times \frac{C}{r}}$，$r$ 为缩减比（默认 16）。

### 2. 符号说明表

| 符号 | 含义 | 取值 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathbf{U}$ | 输入特征图 | $\mathbb{R}^{H\times W\times C}$ | 卷积输出 |
| $z_c$ | 第 $c$ 通道的全局平均池化标量 | $\mathbb{R}$ | 挤压结果 |
| $\mathbf{W}_1$ | 第一个全连接（降维） | $\frac{C}{r}\times C$ | 瓶颈结构 |
| $\mathbf{W}_2$ | 第二个全连接（升维） | $C\times\frac{C}{r}$ | 恢复通道数 |
| $r$ | 缩减比 reduction ratio | 默认 16 | 控制参数量 |
| $s_c$ | 第 $c$ 通道的激励权重 | $(0,1)$ | sigmoid 输出 |
| $\tilde{\mathbf{x}}_c$ | 重标定后的第 $c$ 通道 | $\mathbb{R}^{H\times W}$ | 逐通道缩放 |

### 3. SE 模块参数量

$$\text{Params}_{SE} = 2 \times \frac{C^2}{r}$$

两个全连接：$C \times \frac{C}{r} + \frac{C}{r} \times C = \frac{2C^2}{r}$。对 ResNet-50（$C=2048$, $r=16$）约 2.5M 参数，约占模型总参数 ~2.5%，换来 ~2% 涨点——性价比极高。

### 4. CBAM：SE + 空间注意力

CBAM = 通道注意力（同 SE 思路，但用全局平均池化**和**全局最大池化两个分支）+ 空间注意力（沿通道维做池化，再用 7×7 卷积学空间权重）：

$$\text{CBAM}(\mathbf{F}) = \mathbf{F}' \odot \mathbf{M}_c(\mathbf{F}) \odot \mathbf{M}_s(\mathbf{F}')$$

- $\mathbf{M}_c$：通道注意力（AvgPool+MaxPool 双分支共享 MLP）；
- $\mathbf{M}_s$：空间注意力（沿通道池化后 7×7 卷积 + sigmoid）。

### 5. 变体与适用条件

- **SE**：只看通道，参数少、即插即用，适用于任何 CNN backbone。
- **CBAM**：通道+空间，涨点通常略高但多一层 7×7 卷积，计算开销更大。
- **ECA（2020）**：把 SE 的两个全连接换成 1D 卷积，去掉降维瓶颈，进一步减参。
- **适用条件**：SE 用在"通道数足够大"的深层网络收益明显；浅层小通道网络收益有限。
- **限制条件**：SE 是"实例无关"的静态重标定（权重由当前样本的池化统计决定，但与空间位置无关）；真正的"空间自适应"需要自注意力（见 [[Transformer与自注意力]]）。

## 6. 推导思路和思想来源

- **最初困难**：CNN 无法显式建模"哪些通道重要"，跨通道依赖只能靠堆深度隐式学习。
- **直接方法局限**：加更多卷积层/增大卷积核 → 参数量爆炸且收益递减。
- **关键"转念"**：通道重要性是**全局**性质（要看到整张图才知道哪些通道有用），而卷积是**局部**操作——所以先用全局平均池化把空间信息浓缩（Squeeze），再用极小的 MLP 学通道关系（Excitation）。**把"空间上损失信息"和"通道上获得全局视野"做交换，网络几乎不增加多少计算。**
- **推导主线**：全局池化 → 瓶颈 MLP（降维-升维）→ sigmoid 门控 → 逐通道乘法。ReLU 在瓶颈中间引入非线性，sigmoid 在输出端保证权重在 (0,1)。
- **为什么自然得到此结论**：全局平均池化本来就是分类头前的一步（NIN 提出的思想），SE 只是把它"提前"到中间层并乘回特征——顺手捡来的涨点。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础 — SE 模块手算

- **题目**：输入 $\mathbf{U}\in\mathbb{R}^{2\times 2\times 3}$（H=2, W=2, C=3），设通道 1 为 `[[1,2],[3,4]]`、通道 2 为 `[[1,1],[1,1]]`、通道 3 为 `[[0,0],[0,0]]`。求挤压后的 $z$ 向量。
- **解题思路**：每通道取均值。
  - $z_1 = (1+2+3+4)/4 = 2.5$
  - $z_2 = (1+1+1+1)/4 = 1.0$
  - $z_3 = 0$
- **最终答案**：$\mathbf{z} = [2.5, 1.0, 0]$。直觉：通道 1 信息量大、通道 3 全是零（无用），激励层应给通道 1 高权重、通道 3 近零权重。
- **易错点**：挤压是**每个通道内部**做空间均值，不是跨通道。
- **🤔 追问**：如果换成全局最大池化，$z$ 会变成什么？答：$[4, 1, 0]$——最大池化更敏感于"峰值响应"，这正是 CBAM 双分支并用的动机。

### 例子 2：中等 — 计算 SE 模块参数量

- **题目**：ResNet-50 最后一个 block 输出 $C=2048$，缩减比 $r=16$。求 SE 模块参数量及与 ResNet-50 总参数（约 25.6M）的占比。
- **解答**：$\text{Params} = \frac{2 \times 2048^2}{16} = 524{,}288 \approx 0.52\text{M}$。占比 $\approx 2\%$。
- **结论**：用 ~2% 的额外参数换 ~2% 的 top-1 涨点，是 2017-2018 年性价比最高的架构升级。

### 例子 3：实际应用 — PyTorch 实现 SE 模块（12 行）

```python
import torch
import torch.nn as nn

class SELayer(nn.Module):
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.squeeze = nn.AdaptiveAvgPool2d(1)   # B,C,H,W -> B,C,1,1
        self.excitation = nn.Sequential(
            nn.Linear(channels, channels // reduction),  # 降维
            nn.ReLU(inplace=True),
            nn.Linear(channels // reduction, channels),  # 升维
            nn.Sigmoid(),
        )
    def forward(self, x):
        b, c, _, _ = x.shape
        w = self.squeeze(x).view(b, c)          # 挤压
        w = self.excitation(w).view(b, c, 1, 1) # 激励
        return x * w                            # 重标定（广播乘法）
```

- **验证**：输入 `torch.randn(4, 64, 32, 32)` → 输出形状不变 `(4, 64, 32, 32)`；权重维度 `(4, 64)` 每个通道一个标量。
- **实际价值**：插在任意 block 的残差汇合前，即可给 ResNet/DenseNet/MobileNet 涨点。

## 8. 常见误区和易混概念

### 误区 1："SE 就是加了个注意力，所以和 ViT 的自注意力是一回事"
- **错误直觉**：都叫"注意力"，应该等价。
- **为什么错**：SE 是**通道级、实例相关但空间无关**的静态重标定；自注意力是**空间级**的成对动态交互（每个位置和所有位置算相似度）。
- **正确理解**：SE 可看作自注意力的"极简退化版"——只对通道维度做全局打分，不做空间交互。

### 误区 2："SE 模块会增加大量计算量"
- **错误直觉**：多了两个全连接，肯定很贵。
- **为什么错**：FLOPs 上 SE 几乎免费（全局池化 + 两个小 FC 只在通道维算），主要开销是那 0.5M 参数；推理时逐通道乘法是 $O(C\cdot H\cdot W)$，与卷积本身相比可忽略。
- **正确理解**：SE 的代价在**参数**不在**计算**；这正是它能嵌入移动端网络的资本。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **SE** | 哪些通道重要 | 仅通道维，全局池化+FC | 分类 backbone 即插即用 |
| **CBAM** | 通道+空间哪里重要 | 通道注意 + 空间注意（7×7 卷积） | 检测/分割，略贵 |
| **ECA** | SE 太费参 | 1D 卷积替代两个 FC | 轻量化网络 |
| **自注意力（Transformer）** | 任意两位置关系 | 空间成对动态交互，$O(N^2)$ | ViT、多模态大模型 |
| **BN 的 $\gamma$ 缩放** | 逐通道归一化缩放 | 无全局统计、无门控 | 所有现代网络标配 |

### 题目与解析

#### 1. SE 模块的三步按顺序是？
> [!question]- 答案解析
> - **答案**：Squeeze（全局平均池化）→ Excitation（FC-ReLU-FC-Sigmoid）→ Reweight（逐通道乘回）。
> - **解析**：顺序不能乱——先浓缩全局信息，再学权重，最后应用。
> - **对应误区**：把 Excitation 和 Reweight 混为一谈。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 输入通道 1 为 `[[1,2],[3,4]]`，求 $z_1$。
> [!question]- 答案解析
> - **答案**：$(1+2+3+4)/4 = 2.5$。
> - **解析**：空间均值，与通道内数值分布无关。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. SE 与自注意力的本质区别？
> [!question]- 答案解析
> - **答案**：SE 只做通道级全局静态重标定，不做空间交互；自注意力做空间成对动态交互。
> - **解析**：SE 没有"位置 vs 位置"的相似度计算。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. $C=1024, r=8$ 时 SE 参数量？
> [!question]- 答案解析
> - **答案**：$\frac{2 \times 1024^2}{8} = 262{,}144 \approx 0.26$M。
> - **解析**：$r$ 越大参数越少，但容量下降；$r=16$ 是经验平衡点。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 为什么 SE 涨点但 FLOPs 几乎不变？它有什么局限？
> [!question]- 答案解析
> - **答案**：SE 开销主要在参数（FC 矩阵）而非计算；局限是空间无关——不知道"哪里"重要，只知道"哪个通道"重要，极端场景需要空间注意力或自注意力补充。
> - **解析**：这是从"通道注意力"迈向"空间注意力/自注意力"的关键动机。
> - **Obsidian 标签建议**：`#自测题/较难`
