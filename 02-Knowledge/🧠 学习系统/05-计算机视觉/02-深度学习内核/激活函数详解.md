# 激活函数详解

> **核心叙事**：没有激活函数的深度网络 = 一摞玻璃板叠在一起——堆再多也只是一块厚玻璃。激活函数是网络"弯曲"数据的能力来源，而选择哪种激活函数，本质是在**梯度流畅度、计算开销、稀疏性收益**三者之间做权衡。从 Sigmoid 的优雅致命，到 ReLU 的粗暴统治，再到 GeLU/Swish 的精密回归——激活函数的演化史就是深度学习从寒冬走向春天的历史。

## 1. 📌 TL;DR

激活函数是插入在神经网络相邻层之间的**逐元素非线性变换**：

1. **没有激活函数** → 多层网络退化为单层线性变换：$W_3(W_2(W_1x)) = W'x$
2. **Sigmoid/Tanh**（2012前主流）：梯度在 $|x|>5$ 时趋近于 0 → 深层网络的底层完全无法更新（梯度消失）
3. **ReLU**（2012-2020统治）：$x>0$ 时梯度恒为 1，彻底解决正向梯度消失；$x<0$ 时输出 0 → 可能永久杀死神经元（Dead ReLU）
4. **GeLU/Swish**（2020+ Transformer标配）：平滑的非线性 + 处处非零梯度，在 NLP/CV 前沿模型中全面取代 ReLU

> 核心口诀：**"Sigmoid 饱和→梯度断，ReLU 正半轴→梯度通，死神经元→负半轴，GeLU 平滑→大模型稳"**。

## 2. 🔑 核心概念

### 2.1 为什么线性不够？

设 $f(x) = W_3 \cdot (W_2 \cdot (W_1 x + b_1) + b_2) + b_3$ ——如果没有激活函数夹在中间，整个表达式展开后仍是一个线性变换：

$$f(x) = (W_3 W_2 W_1)x + (W_3 W_2 b_1 + W_3 b_2 + b_3) = W'x + b'$$

堆叠 1000 层 = 只有 1 层。**线性函数的复合仍然是线性函数**。这意味着网络永远只能画直线分类边界，不可能拟合 XOR 这种最基本的非线性问题。

激活函数 $a(\cdot)$ 插入后：
$$h_1 = a(W_1 x), \quad h_2 = a(W_2 h_1), \quad \hat{y} = W_3 h_2$$

`a(线性) = 非线性`，每一层都真正"扭曲"了数据空间。

### 2.2 评判激活函数的五个维度

| 维度 | 评判标准 | 理想状态 |
|------|----------|----------|
| **非线性** | 能否拟合 XOR？ | 必须是非线性 |
| **梯度健康度** | 导数是否远离 0？ | 大部分输入区域导数 ≈ 1 |
| **零中心化** | 输出均值是否为 0？ | 是（避免 zig-zag 优化） |
| **计算开销** | 涉及指数/除法？ | 能分段线性最好 |
| **稀疏性** | 是否自然产生 0 输出？ | 适度稀疏有益泛化 |

## 3. 📐 数学基础

### 3.1 Sigmoid

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

**导数**（极其优美）：
$$\sigma'(x) = \sigma(x)(1 - \sigma(x))$$

**值域**：$(0, 1)$

**梯度饱和分析**：

| $x$ | $\sigma(x)$ | $\sigma'(x)$ | 梯度状态 |
|-----|-------------|--------------|----------|
| $-10$ | $\approx 0.00005$ | $\approx 0.00005$ | 🔴 极度饱和 |
| $-3$ | $0.047$ | $0.045$ | 🟡 严重衰减 |
| $0$ | $0.5$ | **0.25** | 🟢 最大梯度 |
| $3$ | $0.953$ | $0.045$ | 🟡 严重衰减 |
| $10$ | $\approx 0.99995$ | $\approx 0.00005$ | 🔴 极度饱和 |

> **关键事实**：Sigmoid 的最大梯度也只有 **0.25**。经过 $L$ 层反向传播，梯度被乘以 $\le 0.25^L$。$L=10$ 时，底层梯度 $\le 0.25^{10} \approx 9.5 \times 10^{-7}$ —— 基本为 0。

**三个致命缺陷**：
1. **梯度饱和**：$|x|>5$ 时导数 ≈ 0，深层网络底层梯度指数衰减
2. **非零中心化**：输出恒为正 $(0, 1)$ → $\frac{\partial L}{\partial W} = dY \cdot x^T$，所有元素的梯度符号相同 → zig-zag 优化轨迹
3. **指数运算**：$e^{-x}$ 计算成本远高于 ReLU 的 `max(0,x)`

### 3.2 Tanh（双曲正切）

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = 2\sigma(2x) - 1$$

**导数**：
$$\tanh'(x) = 1 - \tanh^2(x)$$

**值域**：$(-1, 1)$

**相比 Sigmoid 的改进**：零中心化 ✅（输出均值 ≈ 0），优化路径不再 zig-zag。

**依然存在的问题**：梯度饱和。$|x|>3$ 时 $\tanh'(x) \approx 0$，梯度消失照旧。

> Tanh 是 Sigmoid 的"缩放居中版"：梯度最大值 1.0（$x=0$），比 Sigmoid 的 0.25 好，但饱和区一样致命。

### 3.3 ReLU（修正线性单元）

$$f(x) = \max(0, x)$$

**导数**：
$$f'(x) = \begin{cases} 1, & x > 0 \\ 0, & x \le 0 \end{cases}$$

注意：$x=0$ 处导数未定义（实践中取 0 或 1 均可，PyTorch 默认取 0）。

**革命性优势**：
1. **正半轴梯度恒为 1**：$1^L = 1$，不管多少层梯度都不会衰减（正向区域）
2. **计算极快**：只需一次 `if x>0` 比较，无指数/除法
3. **稀疏激活**：约 50% 神经元输出 0，类似生物大脑的稀疏编码，天然正则化效果
4. **收敛速度**：实验表明比 Sigmoid/Tanh 快 **6 倍以上**

**致命缺点——Dead ReLU Problem**：

当神经元的输入恒为负（$x \le 0$），导数恒为 0 → 该神经元再也收不到梯度 → 权重永不更新 → 永久死亡。

**死亡成因**：
- **不当的权重初始化**：初始权重使神经元对所有样本输出负数
- **过大的学习率**：一次更新把权重推出有效区域
- **负偏置过大**：$b$ 初始化为较大的负值

### 3.4 ReLU 变体：解决死亡问题

| 变体 | 公式 | 负半轴行为 | 特点 |
|------|------|-----------|------|
| **Leaky ReLU** | $f(x) = \max(\alpha x, x)$ | 小斜率（默认 $\alpha=0.01$） | 固定小梯度，防止彻底死亡 |
| **PReLU** | $f(x) = \max(\alpha x, x)$ | 可学习参数 $\alpha$ | $\alpha$ 通过反向传播学习 |
| **ELU** | $f(x) = \begin{cases} x, & x>0 \\ \alpha(e^x-1), & x \le 0 \end{cases}$ | 指数衰减到 $-\alpha$ | 零中心化，但计算稍贵 |
| **SELU** | 缩放版 ELU | 特殊 $\alpha, \lambda$ | 自归一化性质（特定条件下） |

> **工业实践真相**：Leaky ReLU 理论上修复了 Dead ReLU，但在大规模实验中并未对 ReLU 表现出**压倒性优势**。ReLU 的稀疏性本身是一种有益的正则化。

### 3.5 现代激活函数：GeLU 与 Swish

**GeLU**（Gaussian Error Linear Unit，BERT/GPT 标配）：

$$\text{GeLU}(x) = x \cdot \Phi(x) = x \cdot \frac{1}{2}\left[1 + \text{erf}\left(\frac{x}{\sqrt{2}}\right)\right]$$

近似形式（实践中常用）：
$$\text{GeLU}(x) \approx 0.5x\left(1 + \tanh\left[\sqrt{2/\pi}(x + 0.044715x^3)\right]\right)$$

**Swish**（由 NAS 搜索发现）：

$$\text{Swish}(x) = x \cdot \sigma(\beta x)$$

当 $\beta=1$ 时接近 GeLU 的行为。

**GeLU/Swish 的核心特征**：
- **非单调**：在 $x<0$ 时轻微为负（不像 ReLU 直接归零）
- **处处光滑可导**：有利于高阶优化器
- **自门控**：可以看作 $x \cdot \text{"x 有多正"}$ —— 软化了 ReLU 的硬截断
- **在 Transformer 中表现优异**：注意力机制的梯度流对激活函数的平滑性高度敏感

> **为什么大模型爱 GeLU？** Transformer 的残差连接 + LayerNorm 已经缓解了梯度消失，此时更需要的是**平滑的非线性**而非 ReLU 的稀疏性。GeLU 的"软门控"让每个 token 的信息可以精细调控地流过，而不是被粗暴截断。

## 4. 💡 直观理解

### 水管阀门类比

- **Sigmoid**：老式弹簧阀。水压极小 → 关死（0），水压极大 → 全开（1），但再大的水压也超不过 1。而且阀门两端有"卡顿区"——水压居中时开度变化快，两端时几乎不动（梯度饱和）。
- **Tanh**：Sigmoid 的改进版，阀门居中时水可以反向流动（负输出），但两端卡顿问题照旧。
- **ReLU**：单向止逆阀。水正向流（$x>0$）→ 完全畅通，流多少进多少；水反向（$x<0$）→ 立刻完全关死。简单粗暴但极其有效。
- **Leaky ReLU**：带微小缝隙的止逆阀。反向时不是完全关死，而有 1% 的泄漏——防止阀门因长期不流动而锈死。
- **GeLU**：智能电子阀。根据水压大小**平滑调节**开度——水压大的全开，水压中等的半开，负压微开一点。没有硬截断的"咔嗒"声，全程丝滑。

### 生物学类比

生物神经元有"全或无"的放电阈值：膜电位超过阈值才发放动作电位，否则静默。ReLU 的 `max(0,x)` 完美复刻了这一行为——这正是其名称（Rectified **Linear Unit**）的由来。

### 几何直觉

激活函数 = 对数据空间的"折叠操作"。ReLU 将负半空间"压平"到零平面，把数据流形折叠到第一象限。多个 ReLU 层叠加 = 反复折叠 → 最终能把任意复杂的分类边界"折"出来。

## 5. 🏗️ 激活函数族谱与演进

```
1943  McCulloch-Pitts 阶跃函数 (Step)
  │
1950s Sigmoid / Tanh (生物启发的平滑非线性)
  │   统治神经网络40年
  │
2012  ReLU (AlexNet, Krizhevsky et al.)
  │   "深度学习复兴的标志性工程选择"
  │   比 Sigmoid 快 6×，首次让深层网络可训练
  │
2013  Leaky ReLU / PReLU (何恺明, ResNet)
  │   修复负半轴死亡问题
  │
2015  ELU (Clevert et al.)
  │   负半轴指数衰减，零中心化
  │
2016  Swish (Ramachandran et al., NAS 搜索)
  │   x·σ(x)，非单调，光滑
  │
2018  GeLU (Hendrycks & Gimpel, BERT)
  │   x·Φ(x)，Transformer 的默认激活
  │
2020+ SiLU (Swish β=1), Mish (Misra, "A Self Regularized Non-Monotonic Activation")
       GeLU 统治 NLP，Swish/SiLU 在 ViT 中竞争
```

**选择逻辑的演变**：
- 2012-2018：**"默认 ReLU，不行再换 Leaky/ELU"**
- 2018-2020：**Transformer 架构 → GeLU（NLP），CNN → 继续 ReLU（CV）**
- 2020+：**ViT 兴起 → GeLU/Swish 向 CV 渗透；但 CNN 中 ReLU 依然强劲**

## 6. ⚙️ 梯度流分析

### 6.1 Sigmoid 的梯度消失：定量分析

10 层全连接网络，每层 Sigmoid。假设某个输入 $x$ 通过网络时，各层激活值分布在 $[-3, 3]$：

| 层（从输出往输入数） | 该层局部梯度范围 | 累积梯度（链式） |
|:---------------------|:-----------------|:-----------------|
| L10（靠近输出） | 0.05 ~ 0.25 | 0.05 ~ 0.25 |
| L9 | 0.05 ~ 0.25 | $0.0025 \sim 0.0625$ |
| L8 | 0.05 ~ 0.25 | $1.25\times10^{-4} \sim 0.0156$ |
| L5 | 0.05 ~ 0.25 | $3.125\times10^{-7} \sim 9.77\times10^{-4}$ |
| **L1（靠近输入）** | 0.05 ~ 0.25 | $9.5\times10^{-11} \sim 9.5\times10^{-7}$ |

**结论**：即使取最乐观估计（每层梯度 0.25），10 层后的累积梯度也小于 $10^{-6}$。float32 的有效精度是 $\sim 10^{-7}$，梯度实质上已经为 0。

### 6.2 ReLU 的双面性

**正半轴（$x>0$）**：梯度 = 1 → $1^L = 1$ → 完美！
**负半轴（$x \le 0$）**：梯度 = 0 → 该神经元此轮不更新

**关键统计**（Krizhevsky et al.）：AlexNet 训练中约 **40-50%** 的 ReLU 神经元在任何给定 batch 中输出为 0。这不是 bug，而是**稀疏性特征**——强制网络用少而精的神经元表示信息，起到正则化作用。

### 6.3 Dead ReLU 的动态

```python
# Dead ReLU 发生的典型场景
w = torch.randn(784, 256) * 0.01     # 初始权重过小
b = torch.ones(256) * -5.0           # 负偏置过大
x = torch.randn(128, 784)            # 正态输入（均值0）
h = torch.relu(x @ w + b)            # 前向
# → 大量神经元输出全为 0 → 梯度永远为 0 → 永久死亡
```

**检测 Dead ReLU**：训练过程中，统计每个神经元在所有样本上的输出 > 0 的比例。若某神经元连续多个 epoch 比例为 0 → 已死亡。

## 7. 📝 手算示例

### 7.1 设定

输入向量 $\mathbf{x} = [3.0, \; -2.0, \; 0.5]$，分别经过 Sigmoid 和 ReLU 激活。上游梯度 $\mathbf{d}_{\text{up}} = [2.0, \; -1.5, \; 0.8]$（即 $\frac{\partial L}{\partial y_i}$）。

### 7.2 Sigmoid 前向 + 反向

**前向传播**：

| $i$ | $x_i$ | $y_i = \sigma(x_i)$ | $\sigma'(x_i) = y_i(1-y_i)$ |
|:---:|:-----:|:--------------------:|:---------------------------:|
| 1 | $3.0$ | $\frac{1}{1+e^{-3}} = 0.9526$ | $0.9526 \times 0.0474 = 0.0452$ |
| 2 | $-2.0$ | $\frac{1}{1+e^{2}} = 0.1192$ | $0.1192 \times 0.8808 = 0.1050$ |
| 3 | $0.5$ | $\frac{1}{1+e^{-0.5}} = 0.6225$ | $0.6225 \times 0.3775 = 0.2350$ |

**反向传播**：$\frac{\partial L}{\partial x_i} = \frac{\partial L}{\partial y_i} \cdot \sigma'(x_i)$

| $i$ | 上游 $d_{\text{up},i}$ | 局部梯度 $\sigma'(x_i)$ | $\partial L / \partial x_i$ |
|:---:|:---------------------:|:-------------------------:|:---------------------------:|
| 1 | $2.0$ | $0.0452$ | $2.0 \times 0.0452 = \mathbf{0.0903}$ |
| 2 | $-1.5$ | $0.1050$ | $-1.5 \times 0.1050 = \mathbf{-0.1575}$ |
| 3 | $0.8$ | $0.2350$ | $0.8 \times 0.2350 = \mathbf{0.1880}$ |

> **观察**：$x_1=3.0$ 上游给出了强烈的修正信号（2.0），但穿过 Sigmoid 后几乎被掐灭（只剩 0.09）。$x_2=-2.0$ 同样被大幅衰减。这就是梯度消失的微观机制。

### 7.3 ReLU 前向 + 反向

**前向传播**：

| $i$ | $x_i$ | $y_i = \max(0, x_i)$ | $\text{ReLU}'(x_i)$ |
|:---:|:-----:|:--------------------:|:-------------------:|
| 1 | $3.0$ | $3.0$ | **1** |
| 2 | $-2.0$ | $0$ | **0** |
| 3 | $0.5$ | $0.5$ | **1** |

**反向传播**：

| $i$ | 上游 $d_{\text{up},i}$ | 局部梯度 $\text{ReLU}'(x_i)$ | $\partial L / \partial x_i$ |
|:---:|:---------------------:|:---------------------------:|:---------------------------:|
| 1 | $2.0$ | $1$ | $2.0 \times 1 = \mathbf{2.0}$ |
| 2 | $-1.5$ | $0$ | $-1.5 \times 0 = \mathbf{0}$ |
| 3 | $0.8$ | $1$ | $0.8 \times 1 = \mathbf{0.8}$ |

> **观察**：$x_1=3.0$ 的上游梯度 2.0 **完整回传**。$x_2=-2.0$ 的上游梯度 -1.5 **被完全阻断**——即使上游想调整这个神经元，它的"门"已经关死了。这就是 ReLU 的双面性：正向信号畅通无阻，负向信号彻底丢弃。

### 7.4 对比总结

| 输入 $x$ | Sigmoid 回传梯度 | ReLU 回传梯度 | 关键差异 |
|:--------:|:----------------:|:------------:|:---------|
| $3.0$（正值） | $0.0903$（衰减 95%） | $2.0$（完整） | Sigmoid 饱和区→梯度压扁 |
| $-2.0$（负值） | $-0.1575$（衰减 90%） | $0$（阻断） | ReLU 负半轴→梯度中断 |
| $0.5$（零附近） | $0.1880$（衰减 77%） | $0.8$（完整） | Sigmoid 即使在"最佳区"也衰减 |

> **核心教训**：Sigmoid **在所有区域**都衰减梯度（最多保留 25%），ReLU 在正半轴**完全不衰减**但在负半轴**完全阻断**。这就是为什么深层网络必须用 ReLU 系——至少正半轴的信号能传到底层。

### 8.2 梯度消失/爆炸模拟

```python
def simulate_gradient_flow(depth=20, activation='sigmoid'):
    """模拟 L 层全连接网络随机初始化的梯度传播"""
    torch.manual_seed(42)
    layers = [torch.randn(256, 256) * 0.1 for _ in range(depth)]

    act_fn = {
        'sigmoid': torch.sigmoid,
        'relu': torch.relu,
        'tanh': torch.tanh,
        'gelu': nn.GELU(),
    }[activation]

    x = torch.randn(256)
    grad_magnitudes = []

    for i, W in enumerate(layers):
        z = x @ W
        a = act_fn(z)

        # 模拟反向传播：该层的局部梯度范数
        if activation == 'sigmoid':
            local_grad = a * (1 - a)
        elif activation == 'relu':
            local_grad = (z > 0).float()
        elif activation == 'tanh':
            local_grad = 1 - a**2
        elif activation == 'gelu':
            # GeLU 的近似导数
            local_grad = 0.5 * (1 + torch.erf(z / np.sqrt(2))) + \
                         z * torch.exp(-z**2 / 2) / np.sqrt(2 * np.pi)

        local_grad_norm = local_grad.abs().mean().item()
        grad_magnitudes.append(local_grad_norm)
        x = a

    return grad_magnitudes

# ─── 对比实验 ───
activations = ['sigmoid', 'tanh', 'relu', 'gelu']
plt.figure(figsize=(12, 5))

for act in activations:
    mags = simulate_gradient_flow(depth=20, activation=act)
    plt.plot(range(1, 21), mags, 'o-', linewidth=2, markersize=5, label=act)

plt.axhline(y=1.0, color='gray', linestyle='--', alpha=0.5, label='理想梯度=1')
plt.yscale('log')
plt.xlabel('层深度（从输出→输入）', fontsize=12)
plt.ylabel('局部梯度均值 (log scale)', fontsize=12)
plt.title('20层网络中不同激活函数的梯度传播', fontsize=14, fontweight='bold')
plt.legend(fontsize=11)
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('gradient_flow_comparison.png', dpi=150)
plt.show()
```

**预期输出**：
- **Sigmoid/Tanh**：梯度在第 5-6 层后降到 $10^{-3}$ 以下（log 图上直线下降）
- **ReLU**：梯度在 $0.3\sim0.7$ 之间波动（$x>0$ 时梯度为 1，$x\le0$ 时为 0，均值约 0.5）
- **GeLU**：梯度稳定在 $0.5\sim0.8$，波动小于 ReLU（处处非零梯度）

### 8.3 Dead ReLU 检测

```python
def detect_dead_relu(model, dataloader, threshold=0.001):
    """检测模型中死亡的 ReLU 神经元"""
    model.eval()
    activation_counts = {}
    total_batches = 0

    def hook_fn(name):
        def hook(module, input, output):
            # output shape: [B, C, H, W] 或 [B, D]
            active_ratio = (output > 0).float().mean(dim=0)  # 每个神经元的激活率
            if name not in activation_counts:
                activation_counts[name] = active_ratio.detach()
            else:
                activation_counts[name] += active_ratio.detach()
        return hook

    hooks = []
    for name, module in model.named_modules():
        if isinstance(module, nn.ReLU):
            hooks.append(module.register_forward_hook(hook_fn(name)))

    with torch.no_grad():
        for batch in dataloader:
            model(batch)
            total_batches += 1

    for h in hooks:
        h.remove()

    # 计算平均激活率
    dead_report = {}
    for name, counts in activation_counts.items():
        avg_activation = (counts / total_batches).flatten()
        dead_neurons = (avg_activation < threshold).sum().item()
        total_neurons = avg_neurons.numel()
        if dead_neurons > 0:
            dead_report[name] = (dead_neurons, total_neurons,
                                 dead_neurons / total_neurons)

    return dead_report
```

## 9. 🔗 与其他概念的连接

```
权重初始化 ──→ 激活函数输入分布 ──→ 梯度生死
     │                                    │
     ├── Xavier/He 适配 Sigmoid/Tanh/ReLU  │
     │                                    │
BatchNorm ──→ 强行拉回 0 附近 ──→ 缓解 Sigmoid 饱和
     │                                    │
     └── 配合 ReLU 减少 Dead ReLU ────────┘
                                           │
残差连接 (ResNet) ──→ 梯度高速公路 ──→ ReLU 即使有死亡也不怕
                                           │
Transformer ──→ LayerNorm + 残差 ──→ GeLU 平滑优势放大
```

| 概念 | 与本卡片的关系 |
|------|---------------|
| **权重初始化** | He 初始化专为 ReLU 设计（$\text{Var}(W)=2/n_{\text{in}}$），Xavier 为 Tanh 设计。初始化不当是 Dead ReLU 的头号成因 |
| **BatchNorm** | 将激活输入强行拉到 0 均值 1 方差，缓解 Sigmoid/Tanh 的梯度饱和；对 ReLU 能减少负半轴比例 |
| **残差连接** | $H(x) = F(x) + x$ 提供"梯度高速公路"，即使 $F(x)$ 里的 ReLU 死亡，梯度也能通过 shortcut 回传 |
| **LayerNorm** | Transformer 中配合 GeLU：归一化保持输入在 GeLU 的敏感区内 |
| **梯度裁剪** | ReLU 正半轴梯度不衰减 → 深层仍可能梯度爆炸 → 需要梯度裁剪保底 |
| **Dropout** | 与 ReLU 的稀疏性叠加：神经元可能被 ReLU 置零（数据驱动），也可能被 Dropout 随机丢弃（正则化） |

## 10. ⚠️ 常见误区

**误区1："Sigmoid 导数最大 0.25，所以梯度一定会消失"**
→ 部分正确但不完整。如果配合 BatchNorm 将输入稳定在 $[-2, 2]$，Sigmoid 的梯度其实能用。真正的问题是**深层累积**：每层最多保留 25%，10 层后剩 $10^{-6}$。所以浅层网络 + BatchNorm 用 Sigmoid 完全没问题。

**误区2："Leaky ReLU 修了 Dead ReLU，所以一定比 ReLU 好"**
→ 理论如此，实践不总成立。大量论文实验表明 Leaky ReLU 在大规模任务上并未显著优于 ReLU。ReLU 的稀疏性（负半轴归零）是特征选择的正则化效果。**默认仍用 ReLU，遇到大面积死亡再换 Leaky/PReLU**。

**误区3："激活函数选 GeLU 就对了，它是最新的"**
→ GeLU 在 Transformer 架构中表现出色，但在传统 CNN（如 ResNet-50）中，GeLU vs ReLU 差异很小（甚至 ReLU 略好）。激活函数的选择和**架构强耦合**——不要盲追"新款"。

**误区4："ReLU 在 x=0 处不可导，会导致训练崩溃"**
→ 工程实践中 $x=0$ 的概率测度为零（浮点数精确等于 0 几乎不会发生）。即使偶发，PyTorch 在 $x=0$ 时给梯度 0，梯度下降在此单点上的行为完全不受影响。

**误区5："输出层用 Softmax，不需要考虑激活函数"**
→ Softmax 本身就是一种激活函数（多类归一化），但通常说的"激活函数选择"指隐藏层。二分类输出层用 Sigmoid 是标准做法；多分类用 Softmax；回归任务输出层通常不用激活函数（或 ReLU 用于非负回归）。

### 11.1 激活函数选择决策树

```
开始新项目
│
├─ 是否 Transformer 架构 (BERT/GPT/ViT)？
│   ├─ 是 → GeLU (或 Swish/SiLU)
│   │      理由：Transformer 对平滑梯度敏感；
│   │            GeLU 的软门控匹配注意力机制
│   │
│   └─ 否 ↓
│
├─ 是否 CNN / MLP 隐藏层？
│   ├─ 是 → 默认 ReLU
│   │      理由：简单、快速、久经考验
│   │
│   ├─ 遇到 Dead ReLU（>20% 神经元死亡）？
│   │   ├─ 先调参：减小 lr、换 He 初始化、加 BatchNorm
│   │   └─ 无效 → 换 Leaky ReLU (α=0.01) 或 PReLU
│   │
│   └─ 要挤最后 0.5% 指标？
│       └─ 换 GeLU / Swish（但预期提升在 CNN 中 < 0.3%）
│
├─ 是否 RNN / LSTM？
│   ├─ 隐藏状态 → Tanh（零中心化，$[-1,1]$ 稳定循环）
│   └─ 门控机制 → Sigmoid（$(0,1)$ 天然适合门控）
│
└─ 是否输出层？
    ├─ 二分类 → Sigmoid
    ├─ 多分类 → Softmax（本质是归一化的指数激活）
    └─ 回归（无界）→ 恒等 (Identity)
```

### 11.2 训练技巧速查

| 问题 | 排查方向 |
|------|----------|
| 损失不下降 | 检查最后一层激活 → 回归用了 ReLU 输出？ |
| 底层梯度为 0 | 换 ReLU；加 BatchNorm；检查权重初始化 |
| 大量 Dead ReLU | 减小 lr；He 初始化；加 BN；换 Leaky ReLU |
| 训练不稳定 | 梯度裁剪（clip_grad_norm_）；检查是否漏了激活函数 |
| Transformer 训练慢 | GeLU 计算比 ReLU 重 2-3×；可换 Swish（不含 erf） |

<details>
<summary><b>📝 参考答案</b></summary>

**1.** $W_3(W_2(W_1x)) = (W_3 W_2 W_1)x = W'x$。线性变换的复合仍是线性变换，所以多层无激活 = 单层。不能拟合 XOR 等非线性边界。

**2.** $\sigma'(x) = \sigma(x)(1-\sigma(x))$。当 $\sigma(x)=0.5$（$x=0$）时取最大值 $0.5 \times 0.5 = 0.25$。10 层后梯度 $\le 0.25^{10} \approx 9.5 \times 10^{-7}$，底层参数实质上无法更新。

**3.** $\text{ReLU}(x) = \max(0,x)$；$x>0$ 时导数为 1，$x<0$ 时导数为 0。PyTorch 在 $x=0$ 时返回梯度 0（subgradient 的一种选择）。

**4.** Dead ReLU：神经元对所有输入输出 ≤ 0 → 导数恒为 0 → 永不更新。成因：(a) 不当初始化（如负偏置过大）；(b) 学习率过大→一次更新推出有效区；(c) 无 BatchNorm→输入分布漂移。解决：He 初始化、减小 lr、加 BatchNorm、换 Leaky ReLU/PReLU/ELU。

**5.** Leaky ReLU 的负斜率 $\alpha$ 是手工设定的（默认 0.01）；PReLU 的 $\alpha$ 是可学习的参数，通过反向传播优化。PReLU 理论上更灵活但增加参数量，在小数据集可能过拟合。

**6. Sigmoid**：$x_1=-1.0 \to \sigma=0.2689,\; \sigma'=0.1966,\; dx=0.5 \times 0.1966=0.0983$；$x_2=4.0 \to \sigma=0.9820,\; \sigma'=0.0177,\; dx=-2.0 \times 0.0177=-0.0353$；$x_3=-0.5 \to \sigma=0.3775,\; \sigma'=0.2350,\; dx=3.0 \times 0.2350=0.7051$。**$x_2=4.0$ 衰减最严重**（上游 -2.0 → 只剩 -0.035，衰减 98%）。**ReLU**：$dx=[0, -2.0, 3.0]$（$x_1<0$ 被阻断，$x_2,x_3>0$ 完整回传）。

**7.** Transformer 的自注意力对激活函数的平滑性高度敏感——硬截断（ReLU）会在注意力权重中引入不连续跳变，影响 softmax 注意力的稳定性。GeLU 的软门控让每个 token 的信息可以精细调控，且配合 LayerNorm 和残差连接，GeLU 的非零梯度处处保证了信号的连续流动。此外 GeLU 的非单调性（$x<0$ 时可小幅度为负）为模型提供了更丰富的表达。

**8.** ResNet-50 → **ReLU**（CNN 场景下的最优性价比）；GPT → **GeLU**（Transformer 标配）；二分类输出层 → **Sigmoid**；多分类 → **Softmax**。
