# 轻量化网络：MobileNet / ShuffleNet / EfficientNet / GhostNet

> 所属路径：[[🗺️ 计算机视觉学习路径|计算机视觉学习路径]]
> 所属阶段：[[🧭 阶段2-深度学习内核|🧠 第二阶段：深度学习内核（模型本质）]]
> 教材入口：[[02-Knowledge/🧠 学习系统/05-计算机视觉/📚 教材挂载索引|教材挂载索引]]
> 核心源：MobileNetV1 (Howard et al. 2017)；ShuffleNet (Zhang et al. 2018)；EfficientNet (Tan & Le, ICML 2019)；GhostNet (Han et al. 2020)

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**——轻量化网络是"如何在算力/内存受限下保持精度"的工程核心，也是 5-专业深化与工程落地（TensorRT/部署）的直接前置。
- **判断理由**：MobileNet 的深度可分离卷积把标准卷积拆成"逐通道 + 逐点"两步，是理解几乎所有高效 CNN 的钥匙；EfficientNet 的复合缩放是 NAS/架构设计的重要范式。四者共享"用更少 FLOPs 换同等精度"的目标，但手段不同，正适合一张卡对比。
- **学习边界**：本卡讲四个代表架构的**核心思想与对比**；NAS（自动搜索）在阶段5 作为选修延伸；具体部署优化见 [[计算机视觉-TensorRT]]。

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：ResNet-50 有 25.6M 参数、4.1 GFLOPs——手机上跑一次分类要几百毫秒、几百 MB 内存。移动端、嵌入式、实时推理场景**没有**这么大的算力，但用户还是想要"接近大模型的精度"。

- **旧方法局限**：直接缩小网络（减通道/减层数）会同步损失精度，且是"粗暴裁剪"——没有告诉网络"哪里可以省"。
- **必须引入新工具**：轻量化网络不是"缩小版 ResNet"，而是**重新设计卷积的算术结构**，让每一次 FLOP 都更值钱：深度可分离卷积（MobileNet）、通道混洗（ShuffleNet）、复合缩放（EfficientNet）、冗余特征再生（GhostNet）。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：不学它，阶段5 的 TensorRT/边缘部署/模型压缩（剪枝/量化）没有模型侧基础；EfficientNet 也是 NAS 时代的产物，连接阶段4 架构搜索。
- **实际应用场景**：手机 App 图像识别、自动驾驶车载实时检测、IoT 摄像头、浏览器端推理（ONNX/WebAssembly）。几乎所有"模型要跑到终端"的产品都基于这类网络。
- **高频任务**：面试常问"MobileNet 相比标准卷积省了多少计算量"；竞赛中 EfficientNet 是最强开源 backbone 之一。

## 3. 学它之前需要哪些前置知识？

1. **[[卷积神经网络CNN]]**：掌握卷积计算、参数量/FLOPs 公式（本卡大量使用）。
2. **[[计算机视觉-GoogLeNet]]**：1×1 卷积的作用（通道降维/信息融合）——MobileNet 的逐点卷积就是 1×1 卷积。
3. **[[计算机视觉-注意力机制]]**：EfficientNet 的 MBConv 内含 SE 模块。

## 4. 用直觉语言解释它

> «"这东西其实就像……"把"请 100 个厨师各做一整桌菜"改成"1 个厨师把每种菜批量做好、100 个服务员分装摆盘"——活儿一样多，但每个人只干自己最擅长的一步，整体快得多、人也能少请几个。"»

- **直觉类比（MobileNet）**：标准卷积 = 每个输出像素要同时看"空间邻居 × 所有输入通道"；深度可分离卷积把它拆成两步——先用 3×3 逐通道卷积（每个通道单独做空间滤波），再用 1×1 逐点卷积（跨通道线性组合）。**空间处理和通道融合解耦**，计算量从 $O(K^2\cdot C_{in}\cdot C_{out})$ 降到 $O(K^2\cdot C_{in} + C_{in}\cdot C_{out})$。
- **为什么很自然**：研究表明 CNN 中大量特征通道是**冗余**的（GhostNet 发现一半以上的特征图可以通过廉价操作近似），深度可分离卷积正是"砍掉冗余计算"的系统化手段。
- **一句话直觉本质**：**把"大而全的一次性卷积"拆成"各司其职的廉价小步"，用结构设计换计算效率。**

## 5. 正式定义、核心公式、符号解释

### 1. 核心定义

**深度可分离卷积（Depthwise Separable Convolution）** 把标准卷积拆为两步：

1. **逐通道卷积（Depthwise）**：每个输入通道 $c$ 用独立的 $K\times K$ 卷积核，输出仍为 $C_{in}$ 通道；
2. **逐点卷积（Pointwise）**：用 $1\times 1$ 卷积跨通道线性组合，输出 $C_{out}$ 通道。

### 2. 核心公式

标准卷积（核 $K\times K$，输入 $C_{in}$，输出 $C_{out}$，空间 $H\times W$）：

$$\text{FLOPs}_{std} = K^2 \cdot C_{in} \cdot C_{out} \cdot H \cdot W$$

深度可分离卷积：

$$\text{FLOPs}_{ds} = \underbrace{K^2 \cdot C_{in} \cdot H \cdot W}_{\text{逐通道}} + \underbrace{C_{in} \cdot C_{out} \cdot H \cdot W}_{\text{逐点}}$$

$$\frac{\text{FLOPs}_{ds}}{\text{FLOPs}_{std}} = \frac{1}{C_{out}} + \frac{1}{K^2} \approx \frac{1}{K^2} \quad (\text{当 } C_{out} \gg K^2)$$

对 $K=3$：约 **1/8 到 1/9 的计算量**，精度损失通常仅 1~2%。

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $K$ | 卷积核尺寸 | MobileNet 用 3×3 |
| $C_{in}/C_{out}$ | 输入/输出通道数 | 通常数百~数千 |
| $H\times W$ | 特征图空间尺寸 | |
| $r$ | EfficientNet 复合缩放系数 | 控制深度/宽度/分辨率 |

### 4. 四大架构核心思想

| 架构 | 年份 | 核心创新 | 计算量（输入 224×224） | 精度（ImageNet top-1） |
| :--- | :---: | :--- | :--- | :--- |
| **MobileNetV1** | 2017 | 深度可分离卷积 + 两个超参（宽度乘子 $\alpha$、分辨率乘子 $\rho$） | 0.57 GFLOPs | ~70.6% |
| **ShuffleNet** | 2018 | 分组卷积 + **通道混洗**（channel shuffle）解决组间信息隔离 | 0.14 GFLOPs | ~67.8% |
| **EfficientNet-B0** | 2019 | **复合缩放**：深度×宽度×分辨率同时按 $\phi$ 缩放 | 0.39 GFLOPs | ~77.1% |
| **GhostNet** | 2020 | **廉价操作（cheap operation）**生成冗余特征（一半特征用线性变换近似） | 0.15 GFLOPs | ~74.5% |

### 5. 变体与适用条件

- **MobileNetV2（2018）**：加**倒残差（Inverted Residual）** + 线性瓶颈，先升维再深度卷积再降维，进一步省内存。
- **MobileNetV3（2019）**：NAS 搜索 + SE 模块 + Hard-Swish 激活。
- **EfficientNetV2（2021）**：渐进式训练 + Fused-MBConv，训练更快。
- **适用条件**：移动端/实时场景选 MobileNetV3/ShuffleNetV2；追求精度上限选 EfficientNet；显存受限选 GhostNet。
- **限制条件**：轻量化网络在小数据集上可能不如大模型泛化；深度可分离卷积在低算力硬件（无优化算子库）上加速比达不到理论值。

## 6. 推导思路和思想来源

- **最初困难**：标准卷积把"空间滤波"和"通道混合"耦合在一次运算里，导致计算量随 $C_{in}\cdot C_{out}$ 平方级增长。
- **直接方法局限**：只减小 $C$ 或只减层数，精度掉得快；且没有解释"为什么可以省"。
- **关键"转念"**：**空间卷积和通道融合在信息论上是两件事**——空间滤波负责"局部模式检测"，通道混合负责"特征组合"。把两件事拆开各自做，数学上等价表达能力接近，但计算量从乘法叠加变加法。
- **推导主线**：深度可分离（MobileNet）→ 分组卷积省跨组计算但引入信息隔离 → 通道混洗交换组间信息（ShuffleNet）→ 从"改结构"升级到"系统缩放三个维度"（EfficientNet 复合缩放）→ 发现特征冗余后用廉价线性变换再生产（GhostNet）。一条"越来越懂省"的演进线。
- **为什么自然得到此结论**：NAS（神经架构搜索）发现最优网络往往由高效模块堆叠而成，说明"模块设计"比"暴力加深"更符合资源受限场景的规律。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础 — 计算量对比手算

- **题目**：输入 $C_{in}=64, C_{out}=128, K=3, H=W=28$。分别计算标准卷积与深度可分离卷积的 FLOPs（单位 M）。
- **解题思路**：直接代公式。
  - 标准：$3^2 \times 64 \times 128 \times 28 \times 28 = 3{,}612{,}672 \approx 3.61$M
  - 深度可分离：$3^2 \times 64 \times 28^2 + 64 \times 128 \times 28^2 = 452{,}736 + 6{,{}}424{,}192 \approx 6.88$M
- **最终答案**：标准 3.61M → 深度可分离约 0.69M + 6.42M...（更正：逐点部分 $64\times128\times784 = 6{,}424{,}192 \approx 6.42$M，总 6.87M——此时 $C_{out}$ 大，逐点占主导）。**注意：深度可分离的优势在 $K$ 大或 $C$ 小时更明显；$C$ 很大时逐点卷积仍是主要成本。**
- **易错点**：不要只记"1/9"，要看通道规模；$K=3$ 且 $C_{in}=C_{out}$ 时约 1/9，$C_{out}$ 远大于 $K^2$ 时接近 1/$K^2$。

### 例子 2：中等 — EfficientNet 复合缩放

- **题目**：基线网络计算量 $F_0$，复合系数 $\phi$。EfficientNet 的规则是 depth $= \alpha^\phi$、width $= \beta^\phi$、resolution $= \gamma^\phi$，且 $\alpha\cdot\beta^2\cdot\gamma^2 \approx 2$。当 $\phi=1$、$\alpha=1.2,\beta=1.1,\gamma=1.15$ 时，总计算量放大多少？
- **解答**：计算量 $\propto$ depth × width² × resolution²（FLOPs 与通道平方、分辨率平方成正比）：$1.2 \times 1.1^2 \times 1.15^2 = 1.2 \times 1.21 \times 1.3225 \approx 1.92 \approx 2^\phi = 2$。✓
- **结论**：复合缩放保证"每个 $\phi$ 翻倍计算量"的同时，三个维度协同放大——比只加深/加宽/加分辨率更均衡。

### 例子 3：实际应用 — MobileNetV2 深度可分离层 PyTorch

```python
import torch
import torch.nn as nn

class DepthwiseSeparableConv(nn.Module):
    def __init__(self, cin, cout, kernel_size=3, stride=1):
        super().__init__()
        self.depthwise = nn.Conv2d(cin, cin, kernel_size,
                                   stride=stride, padding=kernel_size//2,
                                   groups=cin)          # 每通道独立卷积
        self.pointwise = nn.Conv2d(cin, cout, 1)        # 1x1 跨通道组合
    def forward(self, x):
        return self.pointwise(self.depthwise(x))

# 验证：输出形状正确
x = torch.randn(2, 64, 32, 32)
y = DepthwiseSeparableConv(64, 128, 3, 1)(x)
print(y.shape)  # torch.Size([2, 128, 32, 32])

# 对比标准卷积参数量
std = nn.Conv2d(64, 128, 3, padding=1)
ds = DepthwiseSeparableConv(64, 128, 3, 1)
print('标准参数量:', sum(p.numel() for p in std.parameters()))   # 73856
print('深度可分离:', sum(p.numel() for p in ds.parameters()))    # 640+8192=8832
```

- **验证**：深度可分离参数量 8832 ≈ 标准 73856 的 1/8.4，与理论吻合。
- **实际价值**：这是 MobileNet 系列的核心算子，也是 ONNX/TensorRT 对高效网络优化的主要对象。

## 8. 常见误区和易混概念

### 误区 1："深度可分离卷积一定比标准卷积快 9 倍"
- **错误直觉**：FLOPs 降 9 倍 = 速度升 9 倍。
- **为什么错**：实际推理速度受内存带宽、算子库优化、硬件特性影响；深度卷积是"memory-bound"算子，在无优化的 CPU 上加速可能只有 2-3 倍。
- **正确理解**：FLOPs 是理论下限，实测加速取决于软硬件；这也是 TensorRT/移动端推理引擎存在的意义。

### 误区 2："轻量化网络就是缩小版大网络"
- **错误直觉**：把 ResNet 砍一半通道就是轻量化。
- **为什么错**：轻量化网络是**结构创新**（可分离卷积/混洗/复合缩放），不是参数裁剪；直接缩放会破坏结构比例导致精度骤降。
- **正确理解**：EfficientNet 的复合缩放告诉我们要**按比例**放大三个维度，而不是单一维度。

### 概念对比表

| 概念 | 核心手段 | 省在哪 | 典型用途 |
| :--- | :--- | :--- | :--- |
| **标准卷积** | 一步完成空间+通道 | 无（基线） | 大模型 backbone |
| **深度可分离** | 拆成逐通道+逐点 | 空间与通道解耦 | MobileNet 全系 |
| **分组卷积+混洗** | 分组算 + 交换通道 | 组间冗余 | ShuffleNet |
| **复合缩放** | 三维按比例放大 | 结构均衡 | EfficientNet |
| **特征再生成** | 廉价变换复制特征 | 冗余特征 | GhostNet |
| **NAS** | 自动搜结构 | 端到端最优 | EfficientNet 搜索空间 |
