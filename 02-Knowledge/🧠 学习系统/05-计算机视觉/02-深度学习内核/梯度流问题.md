# 梯度流问题：消失与爆炸 (Vanishing & Exploding Gradients)

> 所属模块：[[🗺️ 计算机视觉学习路径|计算机视觉学习路径]]
> 对应阶段：[[🧠 第二阶段：深度学习内核|第二阶段]]
> 建议先看：[[反向传播与计算图]]、[[激活函数详解]]

## 0. 类别：A 类核心概念

梯度消失/爆炸是深度学习早期最大的工程障碍。ResNet、BatchNorm、Xavier 初始化等里程碑技术都是为了解决这个问题。

---

## 1. 直觉：梯度的"传话游戏"

反向传播逐层传递梯度信号，就像传话游戏：每传一层信息都会衰减或被放大。

$$\frac{\partial L}{\partial \mathbf{W}^{(1)}} = \frac{\partial L}{\partial \mathbf{a}^{(L)}} \cdot \prod_{l=L}^{2} \left( \frac{\partial \mathbf{a}^{(l)}}{\partial \mathbf{z}^{(l)}} \cdot \frac{\partial \mathbf{z}^{(l)}}{\partial \mathbf{a}^{(l-1)}} \right) \cdot \frac{\partial \mathbf{a}^{(1)}}{\partial \mathbf{W}^{(1)}}$$

连乘项 $\prod$ 是问题根源：每一项 $<1$ → 梯度消失；每一项 $>1$ → 梯度爆炸。

---

## 2. 梯度消失 (Vanishing Gradient)

**症状**：浅层参数几乎不更新（梯度≈0），深层参数正常更新。

**根本原因**：Sigmoid/Tanh 的导数 ≤1（Sigmoid 最大 0.25，Tanh 最大 1.0），深层网络中连乘后指数衰减。

```python
# 直观演示：Sigmoid 梯度衰减
grad = 1.0
for layer in range(10):
    grad *= 0.25  # Sigmoid 最大导数
print(f"After 10 layers: gradient = {grad:.10f}")  # ~9.5e-7, 几乎为零!
```

**典型场景**：20 层 Sigmoid 网络，第一层参数梯度 ≈ 0，网络无法训练。

### 解决方案

| 方法 | 原理 | 代表 |
|:---|:---|:---|
| **ReLU** | 导数=1（正半轴），不衰减 | 现代网络默认激活 |
| **BatchNorm** | 稳定每层输入分布，防止激活饱和 | 几乎所有 CNN |
| **残差连接** | 梯度可通过跳跃连接直通浅层 | ResNet |
| **Xavier/He 初始化** | 控制前向/反向方差，防止信号衰减 | 权重初始化 |

---

## 3. 梯度爆炸 (Exploding Gradient)

**症状**：梯度值极大（如 NaN），参数一步更新飞出合理范围，loss 突然变 NaN。

**根本原因**：权重初始化过大，或循环网络（RNN）中长时间依赖导致梯度指数增长。

### 解决方案

| 方法 | 原理 |
|:---|:---|
| **梯度裁剪** | `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)` |
| **更小的学习率** | 减小每步更新幅度 |
| **权重正则化** | 限制权重范数 |
| **LSTM/GRU** | 门控机制控制梯度流 |

---

## 4. 残差连接如何解决梯度消失？

ResNet 的残差块：$\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$

反向传播时：
$$\frac{\partial L}{\partial \mathbf{x}} = \frac{\partial L}{\partial \mathbf{y}} \cdot \left( \frac{\partial \mathcal{F}}{\partial \mathbf{x}} + \mathbf{1} \right)$$

**关键**：$+1$ 项保证了梯度至少有一条**无损直通路径**到达浅层。即使 $\partial\mathcal{F}/\partial\mathbf{x}$ 很小，梯度也不会消失。

---

## 5. 诊断方法

| 观察 | 判断 |
|:---|:---|
| 浅层梯度范数 ≈ 0 | 梯度消失 |
| loss 突然 NaN | 梯度爆炸 |
| 验证 loss 不变但训练 loss 下降 | 可能梯度消失（浅层没学到） |
| 参数值异常大 | 梯度爆炸 |

```python
# 梯度监控代码
total_norm = 0
for p in model.parameters():
    if p.grad is not None:
        total_norm += p.grad.norm().item() ** 2
total_norm = total_norm ** 0.5
print(f"Gradient norm: {total_norm:.4f}")
# 正常：0.1 ~ 10；危险：>100（爆炸）或 <1e-5（消失）
```

## 🧪 自测题

1. **(基础)** Sigmoid 激活函数为什么容易导致梯度消失？
   <details><summary>💡 提示</summary>Sigmoid 导数 σ'(z) = σ(z)(1-σ(z)) 最大仅 0.25。10 层连乘后梯度降为 0.25^10 ≈ 9.5×10^-7。</details>

2. **(中等)** 残差连接 $\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$ 为什么能缓解梯度消失？反向传播时梯度表达式是什么？
   <details><summary>💡 提示</summary>反向传播时 $\partial L/\partial \mathbf{x} = \partial L/\partial \mathbf{y} \cdot (\partial\mathcal{F}/\partial\mathbf{x} + 1)$。+1 保证梯度至少有一条无损路径。</details>

3. **(较难)** 为什么 LSTM 能缓解 RNN 的梯度消失问题，而普通 RNN 不能？
   <details><summary>💡 提示</summary>LSTM 的细胞状态通过加法更新（$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$），梯度可通过 $C_{t-1}$ 直通早期时间步，不像普通 RNN 每次都要乘以权重矩阵。</details>
