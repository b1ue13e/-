# 感受野 (Receptive Field)

> 所属模块：[[02-Knowledge/🧠 学习系统/05-计算机视觉/🗺️ 计算机视觉学习路径|计算机视觉学习路径]]

> 建议先看：[[卷积神经网络CNN]]

## 0. 类别：A 类核心概念

理解感受野是理解"为什么需要深层网络"和"为什么需要 FPN/空洞卷积"的关键。

---

## 1. 定义

**感受野**：输出特征图上一个像素对应输入图像上的区域大小。

- 浅层神经元："看到"输入的一小片区域（如 3×3 → 5×5）
- 深层神经元："看到"输入的一大片区域（可能覆盖整张图）

> **一句话**：堆叠卷积层 = 指数级扩大感受野。

---

## 2. 计算公式

逐层递推（从第 $k$ 层到第 $k-1$ 层）：

$$r_{k-1} = r_k + (f_k - 1) \cdot \prod_{i=1}^{k-1} s_i$$

其中 $f_k$ 是第 $k$ 层卷积核大小，$s_i$ 是第 $i$ 层步长。

**简化**（所有层 stride=1）：

$$RF_L = RF_{L-1} + (k_L - 1)$$

即每加一层 $3 \times 3$ 卷积，感受野 +2。

| 层数 | 卷积核 | 感受野 |
|:---:|:---|:---:|
| 1 | 3×3 | 3×3 |
| 2 | 3×3 | 5×5 |
| 3 | 3×3 | 7×7 |
| 5 | 3×3 | 11×11 |

---

## 3. 有效感受野 (ERF)

理论感受野是矩形的，但实际**有效感受野**是**高斯分布**形状——中心像素权重最高，边缘几乎为零。这是因为：

1. 卷积核权重在训练中倾向于中心集中（中心像素经过更多路径传播）
2. 多层堆叠后，中心像素参与了所有中间计算，而边缘像素只参与部分计算

### ERF 数值对比实验

```python
import torch
import torch.nn as nn
import numpy as np

def compute_erf(model, input_size=(1, 1, 64, 64)):
    """计算有效感受野：对中心像素求梯度，看哪些输入像素有非零梯度"""
    x = torch.randn(input_size, requires_grad=True)
    y = model(x)
    # 取中心位置输出
    center = y[0, 0, y.shape[2]//2, y.shape[3]//2]
    center.backward()
    grad = x.grad.abs().squeeze().numpy()
    return grad / grad.max()  # 归一化到 [0,1]

# 示例：3 层 3×3 卷积，理论 RF=7×7，但 ERF 中心 ~3×3 区域权重最大
```

**关键发现**（Luo et al. 2016）：
- 理论感受野 $r$ = 矩形区域，但 ERF 呈高斯衰减
- ERF 的有效直径 ≈ $\sqrt{r}$（远小于 $r$）
- **这就是为什么需要更深的网络或更大的卷积核来覆盖大物体**

## 4. 空洞卷积：不增参数扩大感受野

空洞卷积（Dilated/Atrous Convolution）在卷积核元素之间插入"空洞"（零），以指数级扩大感受野而不增加参数量。

$$RF_{dilated} = k + (k-1)(d-1)$$

其中 $d$ = 扩张率（dilation rate）。

| 扩张率 d | 等效核大小 | 参数量 | 感受野增量 |
|:---:|:---|:---|:---|
| 1 | 3×3 | 9 | +2 (标准卷积) |
| 2 | 5×5 | 9 | +4 |
| 3 | 7×7 | 9 | +6 |
| 6 | 13×13 | 9 | +12 |

```python
# PyTorch 空洞卷积示例
conv_dilated = nn.Conv2d(64, 64, kernel_size=3, dilation=2, padding=2)
# dilation=2：3×3 核变成 5×5 的有效感受野，但只有 9 个参数
```

**典型应用**：DeepLab 系列使用 dilation=[1,6,12,18] 的 ASPP 模块同时捕获多尺度上下文。

---

## 5. 为什么这很重要？

| 场景 | 感受野问题 | 解决方案 |
|:---|:---|:---|
| 检测小物体 | 深层特征感受野太大，小物体信息被"稀释" | 使用浅层特征（FPN 高分辨率层） |
| 检测大物体 | 浅层特征感受野太小，看不到完整物体 | 使用深层特征或空洞卷积 |
| **FPN 的动机** | 单一层级无法同时覆盖大小物体 | 融合多层特征 = 同时拥有大小感受野 |
| **空洞卷积** | CNN 下采样丢失空间信息 | 不增加参数的前提下指数级扩大感受野 |
| **语义分割** | 需要同时看到细节和全局上下文 | U-Net 跳跃连接 + 深层的全局感受野 |

---

## 6. 条件变式：步长的影响

当网络中有 stride > 1 的层时，感受野呈**指数增长**：

| 层配置 | 单层 RF 贡献 |
|:---|:---|
| Conv3×3, s=1 | +2 |
| Conv3×3, s=2 | 前一层的每个感受野单元被"放大"2倍 |
| MaxPool2×2, s=2 | 同上，但不引入可学习参数 |

```python
# 复合计算示例：Conv3(s=1) → MaxPool(s=2) → Conv3(s=1)
# 第1层 RF=3
# 第2层(Pool)：RF = 3×2 - 1 = 5 (池化放大)
# 第3层：RF = 5 + 2 = 7
```

**实用经验法则**：在 ImageNet 分类中，ResNet-50 最后一层的理论感受野约 **483×483**（远超 224×224 输入），这意味着深层神经元能"看到"整张图。

---

## 7. 常见失败模式

| 失败模式 | 原因 | 诊断方法 |
|:---|:---|:---|
| 大物体检测漏检 | 所用特征层感受野不足以覆盖完整物体 | 计算 RF，确认 RF > 物体尺寸 |
| 小物体被深层忽略 | 下采样后小物体信息丢失 | 可视化深层特征图，检查小物体区域激活 |
| 空洞卷积产生网格伪影 | dilation 过大导致采样稀疏 | dilation不要超过 feature_map_size / kernel_size |
| 多尺度检测性能差 | 各层感受野分布不合理 | 确保 FPN 各层 RF 覆盖目标的典型尺寸范围 |

## 🧪 自测题

1. **(基础)** 堆叠 3 层 3×3 卷积（stride=1，无池化），理论感受野是多少？
   <details><summary>💡 提示</summary>逐层递推：3→5→7。公式：$RF_L = RF_{L-1} + (k_L - 1)$。</details>

2. **(中等)** 空洞卷积 dilation=2, kernel_size=3 的等效感受野相当于多大的标准卷积？为什么不用标准的大卷积核？
   <details><summary>💡 提示</summary>等效 5×5。标准 5×5 需要 25 个参数，空洞 3×3 只需 9 个参数，且利用了预训练的小卷积核权重。</details>

3. **(较难)** 为什么有效感受野（ERF）呈高斯衰减而非矩形均匀分布？这对网络设计有什么启示？
   <details><summary>💡 提示</summary>每层卷积都相当于一次"信息扩散"，多次扩散后中心像素经过的路径最多，形成高斯分布。启示：理论 RF 可能高估实际有效范围，需要用更深的网络或空洞卷积来确保 ERF 覆盖目标。</details>

4. **(较难)** 如果输入 224×224，经过 ResNet-50（理论 RF≈483），为什么深层神经元还是可能无法有效"看到"全图？
   <details><summary>💡 提示</summary>ERF ≪ 理论 RF。虽然理论 RF 覆盖全图，但 ERF 只有 ~√483 ≈ 22 像素左右的中心区域有实质性梯度，边缘区域贡献接近零。</details>
