# 数据增强与图像预处理

---

## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具，必须会用）**
- **判断理由**：数据增强是 CS231n Assignment1-3 与本地 HW01-HW03 训练流水线的固定环节（Assignment2 的 `data_augmentation` 作业、HW03 的训练工程都直接考察），也是工业界涨点最廉价的手段。它不涉及复杂推导，但"哪些增强能用、哪些不能用、训练/测试怎么配合"是高频面试题。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 深度网络参数成千上万，而我们的数据集往往只有几万甚至几千张图：模型会"背下"训练样本而不是学规律——训练集 99%、测试集 70%（过拟合）。另外，真实世界的图片存在各种变化：翻转、裁剪位置、光照、颜色偏差——我们希望模型对这些变化**不敏感**，但手工收集所有变化形态不现实。因此必须引入两类操作：**数据增强**（在训练时对样本施加保持语义的变换，凭空"造"出更多训练样本，让模型见过更多变化）和**图像预处理**（把像素值归一化到稳定尺度，让优化更稳、让不同来源的图像可比）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW01 的预处理（均值减除）与 HW03 的增强管线（翻转/裁剪/颜色抖动）直接承接本知识点；Assignment2 专门有数据增强作业（对比有无增强的验证集精度差异）。不学它，[[卷积神经网络CNN]]、[[🎯 ResNet (残差网络)]] 训练出的模型都会明显欠拟合。
- **实际应用场景**：任何 CV 训练脚本的第一段代码（PyTorch `transforms` / Albumentations）；AutoAugment/RandAugment 等自动搜索增强策略是 SOTA 模型的标配（见 [[AutoAugment]]）。
- **高频题型/任务**：说出 4-5 种常用增强及其适用性；解释"测试时要不要增强"；计算归一化后的像素值；判断"手写数字识别能否用水平翻转"这类边界问题。

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：
1. **[[图像表示]]**：像素值范围 $[0,255]$、通道布局（HWC/CHW），是理解归一化与增的变换实现前提。
2. **[[卷积神经网络CNN]]**：卷积的平移/翻转敏感性决定了"哪些增强对 CNN 安全"（水平翻转安全、垂直翻转对多数自然图像不安全）。
3. **[[线性分类器与Softmax损失]]**：理解"训练损失 vs 泛化"的张力，才能明白增强是正则化手段。

## 4. 用直觉语言解释它

> «"数据增强就像给模型开'视力训练班'：同一张猫的照片，让它看正着拍的、左右翻转的、裁剪局部的、调暗一点的——都是同一只猫，但模型被迫学会'不管猫怎么摆、光怎么打，它都是猫'，而不是死记照片。图像预处理则是'把所有人的照片统一成标准证件照尺寸和亮度'，让模型不用分心适应不同相机的差异。"»

- **直觉类比/几何图像**：增强 = 在数据分布附近"采样"等价样本，相当于把训练分布"加宽"；归一化 = 把特征分布"对齐"到零均值单位方差，让损失曲面更圆、梯度下降更快。
- **为什么很自然**：人眼对翻转、光照、轻微裁剪天然鲁棒，我们希望模型也鲁棒——增强就是把这些"已知不变性"显式灌输给模型。
- **一句话直觉本质**：**训练时用语义不变的变换扩充样本（正则化、防过拟合），测试时只做与训练一致的归一化；预处理把像素拉到稳定尺度让优化更稳。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **数据增强（Data Augmentation）**：对训练样本施加保持语义标签的随机变换 $T$，生成新训练样本 $(T(x), y)$。测试时通常**不做**增强（只做与训练一致的归一化）。
- **图像预处理（Preprocessing）**：像素值归一化——减均值、除标准差：$\tilde{x} = \frac{x - \mu}{\sigma}$（逐通道），使每个通道均值为 0、方差为 1。

### 2. 核心公式
归一化（逐通道，$\mu_c, \sigma_c$ 由训练集统计）：
$$\tilde{x}_c = \frac{x_c - \mu_c}{\sigma_c},\qquad \mu_c = \frac{1}{N|I|}\sum_{i}\sum_{p} x^{(i)}_{c,p},\quad \sigma_c^2 = \frac{1}{N|I|}\sum_{i}\sum_{p} (x^{(i)}_{c,p} - \mu_c)^2$$
Mixup 混合（一对样本及其标签）：
$$\tilde{x} = \lambda x_i + (1-\lambda) x_j,\qquad \tilde{y} = \lambda y_i + (1-\lambda) y_j,\qquad \lambda \sim \text{Beta}(\alpha, \alpha)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $x, \tilde{x}$ | 原图、变换/归一化后图像 | $[0,255]^3 \to \mathbb{R}^3$（逐像素） | 归一化后可为负 |
| $\mu_c, \sigma_c$ | 通道 $c$ 的均值、标准差 | 由训练集统计 | 测试时复用同一组值 |
| $T(\cdot)$ | 增强变换（翻转/裁剪/抖动…） | 随机函数 | 只用于训练 |
| $\lambda$ | Mixup 混合系数 | $[0,1]$ | 服从 Beta 分布；$N,|I|$ 为样本数、单图像素数 |

### 4. 常见变体与适用条件
- **常用增强**：水平翻转（最安全）、随机裁剪/缩放（`RandomResizedCrop`）、颜色抖动（亮度/对比度/饱和度/色相）、旋转（小角度）、Cutout/RandomErasing（随机遮挡块）、Mixup/CutMix（样本混合）。
- **适用条件**：任务的不变性已知时选择对应增强（分类对翻转/裁剪鲁棒）；测试时保持与训练一致的归一化即可。
- **限制条件**：OCR/文本方向敏感任务不能用翻转与大幅旋转；医学图像（病灶位置敏感）慎用裁剪/翻转；测试时用增强（TTA）会增耗时，只在精度优先时用。

## 6. 推导思路和思想来源

- **最初困难**：数据不足导致过拟合；真实世界变化多样，无法穷举采集。
- **直接方法局限**：多采集数据昂贵；正则化（权重衰减/Dropout）只能限制模型复杂度，无法引入"已知不变性"。
- **关键"转念"**：**把人类已知的"不变性"编码进训练过程**——既然猫倒过来还是猫，就让模型在训练时看到倒过来的猫。这一思想来自经典模式识别的"虚拟样本/弹性畸变"（LeCun 手写数字的弹性变形增强），深度学习时代被系统化为标准训练组件。
- **推导主线与动机**：① 过拟合源于训练分布与真实分布不匹配；② 真实分布的"等价类"（翻转、光照、裁剪）已知；③ 在这些等价类上采样 = 扩大有效训练集 = 隐式正则化；④ 归一化则解决另一问题：像素量纲差异会让损失曲面病态，减均值除标准差把各通道拉到同一尺度，等价于特征标准化（与 [[批量归一化BatchNorm]] 思想同源，但作用于输入层且无学习参数）。
- **为什么自然得到此结论**：因为"让模型对已知变化鲁棒"最直接的实现就是"让它见到这些变化"——不需要数学推导，是统计学习里的经验风险最小化的直接延伸。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：CIFAR-10 训练集 R 通道均值 $\mu_R = 0.4914$、标准差 $\sigma_R = 0.2470$（归一化到 $[0,1]$ 后）。某像素 R 值为 0.8（已除以 255），求归一化后的值。
- **解题思路与关键步骤**：直接代入 $\tilde{x} = (0.8 - 0.4914) / 0.2470$。
- **最终答案**：$\tilde{x} \approx 1.249$。
- **易错点**：忘记先除以 255 再用 ImageNet/CIFAR 的 $\mu,\sigma$（不同数据集的统计量不同，不能混用）；测试时用了与训练不同的统计量会导致精度下降。
- **🤔 追问**：如果训练用 $\mu=0.4914$ 而测试误用 $\mu=0$，会怎样？——输入分布整体偏移，BN 与权重期望的尺度错位，精度明显下降（约 2-5 个点）。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：要训练一个"街道场景车辆检测"模型（图像含水平文字招牌）和一个"手写数字 MNIST"分类器。请分别给出增强策略并说明理由。
  - 解：车辆检测：水平翻转 ✓（车左右对称）、颜色抖动 ✓（光照变化）、随机裁剪 ✓；**禁止**旋转与垂直翻转（会破坏地平线语义与文字方向）。MNIST：可用小角度旋转（$\pm 15°$）、平移、弹性畸变；**禁止**水平翻转（7 会变形成 1 的镜像、6/9 混淆）。
  - **关键推理**：增强的选择 = 任务已知不变性的清单——用得上的是"标签保持"的变换，用不上的是"标签破坏"的变换；这是增强设计的第一原则。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW03 训练工程的标准 `transforms` 管线；Albumentations 提供 GPU 加速的完整增强库（框架页中定位为 HW03-HW05 的增强协议源，见 [[🧭 计算机视觉开源作业源地图]]）；Assignment2 的增强对比实验（有/无增强的验证集曲线）是理解其价值的标准做法。
- 代码形态（伪码）：
```python
# 训练：先增强，后归一化（顺序不能反）
train_tf = Compose([
    RandomResizedCrop(224), HorizontalFlip(p=0.5),
    ColorJitter(brightness=0.4, contrast=0.4, saturation=0.4),
    ToTensor(), Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])
]) # 测试：只归一化（与训练同参数）
test_tf = Compose([Resize(256), CenterCrop(224), ToTensor(),
                   Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])])
```

## 8. 常见误区和易混概念

### 误区 1：以为"增强越多越好，测试时也增强"
- **错误直觉**：增强是免费的，训练测试都用上。
- **为什么错**：① 过度增强会制造"标签破坏"样本（翻转 6 变 9），模型学到错误映射；② 测试时增强（TTA）改变推理分布且增加耗时，测试集应只做与训练一致的归一化（除非刻意用 TTA 提精度）。
- **正确理解**：增强强度是超参数（AutoAugment 就是自动搜它）；训练/测试预处理必须一致（除 TTA 外）。

### 误区 2：把归一化与标准化/白化混为一谈
- **错误直觉**：减均值除标准差就是白化。
- **为什么错**：白化（PCA whitening）还要做特征去相关（旋转坐标系使协方差为对角），计算昂贵且深度网络一般不必要；实践中的"归一化"只是逐通道减均值除标准差。
- **正确理解**：深度学习中"归一化"默认指逐通道 mean/std 标准化；PCA 白化只在传统方法/极小数据时出现。

### 概念对比表

| 概念 | 做什么 | 何时用 | 与增强的关系 |
| :--- | :--- | :--- | :--- |
| 几何增强 | 翻转/裁剪/旋转/缩放 | 训练时 | 注入平移/翻转不变性（见 [[几何增强]]；含颜色抖动见 [[颜色增强]]） |
| 样本混合 | Mixup/CutMix/Cutout | 训练时 | 线性插值/遮挡，强正则化（见 [[Mixup]]、[[CutMix]]） |
| 图像归一化 | 逐通道减均值除标准差 | 训练+测试 | 预处理，非增强；与 [[批量归一化BatchNorm]] 思想同源 |

### 题目与解析

#### 1. 为什么数据增强能缓解过拟合？它的本质是什么？
> [!question]- 答案解析
> - **答案**：增强在保持语义标签的前提下生成等价样本，扩大了有效训练集，迫使模型学到"对已知变化鲁棒"的特征而非死记样本——本质是一种隐式正则化（等价于在数据分布邻域内采样）。
> - **解析**：它同时缩小了训练分布与真实分布的差距；与权重衰减（限制复杂度）互补。
> - **易错原因**：只答"数据变多了"，漏掉"等价样本 + 不变性注入"的机制。
#### 2. 某数据集 G 通道 $\mu_G = 0.456, \sigma_G = 0.224$（归一化到 $[0,1]$ 后），像素值 0.6 归一化后是多少？
> [!question]- 答案解析
> - **答案**：$(0.6 - 0.456) / 0.224 \approx 0.643$。
> - **解析**：直接代入逐通道公式；结果为负也正常（小于均值时）。
#### 3. 下面哪种任务不应使用水平翻转增强：A. 猫狗分类 B. 手写数字识别 C. 街景车辆检测？为什么？
> [!question]- 答案解析
> - **答案**：B 手写数字识别不应使用水平翻转（7 翻转后形似 1、6/9 翻转后语义改变）；A/C 可用（猫狗左右对称、车辆左右对称，且不破坏语义）。
> - **解析**：增强的第一原则是"变换必须保持标签"——翻转是否安全取决于任务已知不变性。
#### 4. 测试时只做归一化不做增强，训练时先增强后归一化——顺序反了会怎样？
> [!question]- 答案解析
> - **答案**：若先归一化再增强（如先 Normalize 再 ColorJitter），抖动的是"归一化后的值"，与训练分布不一致且可能越界（如亮度抖动把值推离均值尺度）；训练/测试预处理必须一致，否则分布错位、精度下降。
> - **解析**：标准顺序是"几何/颜色增强 → ToTensor → Normalize"；测试只保留 ToTensor + Normalize。
#### 5. 给定 $\lambda = 0.7$，样本 A（猫，one-hot $y_A=[1,0]$）与样本 B（狗，$y_B=[0,1]$），写出 Mixup 混合样本与标签，并说明交叉熵损失如何计算。
> [!question]- 答案解析
> - **答案**：$\tilde{x} = 0.7 x_A + 0.3 x_B$，$\tilde{y} = [0.7, 0.3]$；损失为混合标签下的交叉熵：$L = -(0.7 \log p_{\text{cat}} + 0.3 \log p_{\text{dog}})$，其中 $p$ 是模型对 $\tilde{x}$ 的 Softmax 输出。
> - **解析**：Mixup 让模型在样本间线性插值，鼓励决策边界平滑，是强正则化（见 [[Mixup]]）；标签软编码使损失可微地惩罚两个类别。
