# 概率统计-一元与多元线性回归的推断基础

---

## 1. 多元线性回归模型与古典假定

设观测数据为 $(\mathbf{x}_i, y_i)_{i=1}^n$，其中自变量为 $p$ 维列向量。
**矩阵形式**：
$$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$$
其中 $\mathbf{y} \in \mathbb{R}^n$ 为响应向量，$\mathbf{X} \in \mathbb{R}^{n \times (p+1)}$ 为设计矩阵（列满秩 $\text{rank}(\mathbf{X}) = p+1$），$\boldsymbol{\beta} \in \mathbb{R}^{p+1}$ 为未知回归系数，$\boldsymbol{\varepsilon} \in \mathbb{R}^n$ 为误差向量。

### 古典高斯-马尔可夫假定（Gauss-Markov Assumptions）：
1. **线性性**：条件期望关系为线性 $E[\mathbf{y} \mid \mathbf{X}] = \mathbf{X}\boldsymbol{\beta}$；
2. **零均值误差**：$E[\boldsymbol{\varepsilon} \mid \mathbf{X}] = \mathbf{0}$；
3. **同方差与无自相关（球形扰动项）**：$\text{Cov}(\boldsymbol{\varepsilon} \mid \mathbf{X}) = \sigma^2 \mathbf{I}_n$；
4. **正态性假定（推断必需）**：$\boldsymbol{\varepsilon} \sim \mathcal{N}_n(\mathbf{0}, \sigma^2 \mathbf{I}_n)$。

---

## 2. 第一性原理与希尔伯特空间正交投影视角

### 1. 损失函数与投影算子（Hat Matrix）
目标是最小化残差平方和（SSE）：
$$S(\boldsymbol{\beta}) = \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 = (\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^T (\mathbf{y} - \mathbf{X}\boldsymbol{\beta})$$

对向量 $\boldsymbol{\beta}$ 求梯度置零（正规方程 Normal Equations）：
$$\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \mathbf{X}^T\mathbf{y} \implies \hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$$

拟合值向量为 $\hat{\mathbf{y}} = \mathbf{X}\hat{\boldsymbol{\beta}} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} = \mathbf{H}\mathbf{y}$，其中 **$\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T$ 称为帽矩阵（Hat Matrix）**。

> **第一性原理几何直觉**：
> 1. **正交投影（Orthogonal Projection）**：在 $n$ 维欧氏空间 $\mathbb{R}^n$ 中，设计矩阵 $\mathbf{X}$ 的各列张成一个 $p+1$ 维的线性子空间 $\text{Col}(\mathbf{X})$。响应向量 $\mathbf{y}$ 通常不在这个子空间中。OLS 寻找的 $\hat{\mathbf{y}}$，正是 **$\mathbf{y}$ 在子空间 $\text{Col}(\mathbf{X})$ 上的正交投影**！
> 2. **帽矩阵性质**：$\mathbf{H}$ 是对称且幂等的正交投影算子 ($\mathbf{H}^2 = \mathbf{H}, \mathbf{H}^T = \mathbf{H}$)，其迹为 $\text{tr}(\mathbf{H}) = p+1$。
> 3. **残差正交性**：残差向量 $\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}} = (\mathbf{I} - \mathbf{H})\mathbf{y}$ 落在与 $\text{Col}(\mathbf{X})$ 垂直的正交补空间中，故 $\mathbf{X}^T \mathbf{e} = \mathbf{0}$。残差与所有自变量严格正交。

## 3. 高斯-马尔可夫定理（Gauss-Markov Theorem）

### 1. OLS 估计量的统计性质
1. **无偏性**：$E[\hat{\boldsymbol{\beta}}] = \boldsymbol{\beta}$；
2. **协方差矩阵**：$\text{Cov}(\hat{\boldsymbol{\beta}}) = \sigma^2 (\mathbf{X}^T\mathbf{X})^{-1}$。


### 定理陈述
在古典假定下，OLS 估计量 $\hat{\boldsymbol{\beta}}$ 是参数 $\boldsymbol{\beta}$ 的**最佳线性无偏估计（BLUE, Best Linear Unbiased Estimator）**，即在所有线性无偏估计量中，$\hat{\boldsymbol{\beta}}$ 的协方差矩阵最小（对任意估计量 $\tilde{\boldsymbol{\beta}}$，$\text{Cov}(\tilde{\boldsymbol{\beta}}) - \text{Cov}(\hat{\boldsymbol{\beta}})$ 为半正定矩阵）。

### 严格证明
设 $\tilde{\boldsymbol{\beta}} = \mathbf{C}\mathbf{y}$ 为任意线性估计量。令 $\mathbf{C} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T + \mathbf{D}$。
1. 由无偏性要求：$E[\tilde{\boldsymbol{\beta}}] = \mathbf{C}\mathbf{X}\boldsymbol{\beta} = \boldsymbol{\beta} \implies \mathbf{C}\mathbf{X} = \mathbf{I}$。
   代入 $\mathbf{C}$ 得：$[(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T + \mathbf{D}]\mathbf{X} = \mathbf{I} + \mathbf{D}\mathbf{X} = \mathbf{I} \implies \mathbf{D}\mathbf{X} = \mathbf{0}$。
2. 计算协方差矩阵：
   $$\text{Cov}(\tilde{\boldsymbol{\beta}}) = \text{Cov}(\mathbf{C}\mathbf{y}) = \sigma^2 \mathbf{C}\mathbf{C}^T = \sigma^2 [(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T + \mathbf{D}][\mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1} + \mathbf{D}^T]$$
   展开乘积，由于交叉项 $\mathbf{D}\mathbf{X} = \mathbf{0}$ 与 $\mathbf{X}^T\mathbf{D}^T = \mathbf{0}$：
   $$\text{Cov}(\tilde{\boldsymbol{\beta}}) = \sigma^2 (\mathbf{X}^T\mathbf{X})^{-1} + \sigma^2 \mathbf{D}\mathbf{D}^T = \text{Cov}(\hat{\boldsymbol{\beta}}) + \sigma^2 \mathbf{D}\mathbf{D}^T$$
3. 因为对任意实矩阵 $\mathbf{D}$，矩阵 $\mathbf{D}\mathbf{D}^T$ 恒为半正定矩阵（$\mathbf{D}\mathbf{D}^T \succeq 0$）。
   故 $\text{Cov}(\tilde{\boldsymbol{\beta}}) \succeq \text{Cov}(\hat{\boldsymbol{\beta}})$，等号当且仅当 $\mathbf{D} = \mathbf{0}$（即 $\tilde{\boldsymbol{\beta}} = \hat{\boldsymbol{\beta}}$）时成立。 $\blacksquare$

## 4. 假设检验与拟合优度

### 1. 单个回归系数 $t$ 检验
检验单个特征是否显著：$H_0: \beta_j = 0 \quad \text{vs} \quad H_1: \beta_j \ne 0$
$$t_j = \frac{\hat{\beta}_j}{\widehat{\text{SE}}(\hat{\beta}_j)} = \frac{\hat{\beta}_j}{\hat{\sigma}\sqrt{[(\mathbf{X}^T\mathbf{X})^{-1}]_{jj}}} \sim t(n - p - 1)$$

### 2. 决定系数 $R^2$（Coefficient of Determination）
$$R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$
衡量模型自变量对响应变量总方差的解释比例。

## 5. Python 实现多元线性回归推断

```python
import numpy as np
import scipy.stats as stats

np.random.seed(42)
n = 100
# 生成两个自变量
X_raw = np.random.randn(n, 2)
# 真实参数: beta_0=2.0, beta_1=3.5, beta_2=-1.8, sigma=1.0
beta_true = np.array([2.0, 3.5, -1.8])
X = np.column_stack([np.ones(n), X_raw]) # 加上截距列
y = X @ beta_true + np.random.normal(0, 1.0, size=n)

# 1. OLS 解析解求解
XtX_inv = np.linalg.inv(X.T @ X)
beta_hat = XtX_inv @ X.T @ y

# 2. 残差方差与标准误
residuals = y - X @ beta_hat
sse = np.sum(residuals**2)
df_e = n - X.shape[1]
sigma2_hat = sse / df_e
se_beta = np.sqrt(np.diag(sigma2_hat * XtX_inv))

# 3. t 检验统计量与 p 值
t_stats = beta_hat / se_beta
p_vals = 2 * (1 - stats.t.cdf(np.abs(t_stats), df=df_e))

print("估计系数 beta_hat:", np.round(beta_hat, 4))
print("标准误 SE(beta):", np.round(se_beta, 4))
print("t 统计量:", np.round(t_stats, 4))
print("p-values:", p_vals)

assert np.all(p_vals < 0.001), "真实显著特征未通过 t 检验！"
```
