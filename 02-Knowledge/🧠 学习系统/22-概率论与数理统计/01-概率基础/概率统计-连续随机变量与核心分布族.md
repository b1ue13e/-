# 概率统计-连续随机变量与核心分布族

---

## 1. 核心数学定义

随机变量 $X$ 称为**连续型**，若存在非负可积函数 $f(x)$，使得其**累积分布函数（CDF）**满足：
$$F(x) = P(X \le x) = \int_{-\infty}^x f(t) dt \quad (-\infty < x < \infty)$$
其中 $f(x)$ 称为**概率密度函数（PDF）**，满足：
1. $f(x) \ge 0$；
2. 归一化性质：$\int_{-\infty}^\infty f(x) dx = 1$；
3. 在连续点处有 $f(x) = F'(x)$，且 $P(a < X \le b) = F(b) - F(a) = \int_a^b f(x) dx$。

---

## 2. 核心连续分布全景对照表

| 分布名称 | 记号 | 参数与支撑集 | PDF 公式 $f(x)$ | 期望 $E[X]$ | 方差 $\text{Var}(X)$ | 关键特性 / 实际背景 |
| :--- | :---: | :--- | :--- | :---: | :---: | :--- |
| **均匀分布** | $U(a, b)$ | $a < b, x \in [a, b]$ | $\frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 纯随机随机数生成、无先验偏好 |
| **指数分布** | $\text{Exp}(\lambda)$ | $\lambda > 0, x \ge 0$ | $\lambda e^{-\lambda x}$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ | **唯一具有无记忆性的连续分布** |
| **正态分布** | $\mathcal{N}(\mu, \sigma^2)$ | $\mu \in \mathbb{R}, \sigma > 0, x \in \mathbb{R}$ | $\frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$ | $\mu$ | $\sigma^2$ | 钟形对称、CLT极限分布、极大熵 |
| **伽马分布** | $\text{Gamma}(\alpha, \beta)$ | $\alpha>0, \beta>0, x > 0$ | $\frac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}$ | $\frac{\alpha}{\beta}$ | $\frac{\alpha}{\beta^2}$ | $\alpha$ 个独立指数分布和；$\chi^2$ 的母族 |
| **贝塔分布** | $\text{Beta}(a, b)$ | $a>0, b>0, x \in [0, 1]$ | $\frac{1}{B(a, b)} x^{a-1} (1-x)^{b-1}$ | $\frac{a}{a+b}$ | $\frac{ab}{(a+b)^2(a+b+1)}$ | 比例与概率的分布，二项分布共轭先验 |

## 3. 关键定理证明与推导重建

### 1. 指数分布的无记忆性（Memoryless Property）
**定理**：设连续随机变量 $X \sim \text{Exp}(\lambda)$，则对任意 $s, t > 0$，满足：
$$P(X > s + t \mid X > s) = P(X > t)$$

**严格证明**：
指数分布的生存函数为 $P(X > x) = \int_x^\infty \lambda e^{-\lambda u} du = e^{-\lambda x}$。
根据条件概率定义：
$$P(X > s + t \mid X > s) = \frac{P(X > s + t \cap X > s)}{P(X > s)} = \frac{P(X > s + t)}{P(X > s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X > t) \quad \blacksquare$$

### 2. 标准正态分布 $\mathcal{N}(0, 1)$ 的数字特征推导
设 $Z \sim \mathcal{N}(0, 1)$，其密度为 $\phi(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}$。
1. **期望**：
   $$E[Z] = \int_{-\infty}^\infty z \cdot \frac{1}{\sqrt{2\pi}} e^{-z^2/2} dz = 0 \quad (\text{奇函数在对称区间上的积分为 } 0)$$
2. **方差**（分部积分法）：
   $$\text{Var}(Z) = E[Z^2] = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^\infty z \cdot \left(z e^{-z^2/2}\right) dz$$
   令 $u = z, dv = z e^{-z^2/2} dz \implies v = -e^{-z^2/2}$：
   $$E[Z^2] = \frac{1}{\sqrt{2\pi}} \left( \left[-z e^{-z^2/2}\right]_{-\infty}^\infty + \int_{-\infty}^\infty e^{-z^2/2} dz \right) = \frac{1}{\sqrt{2\pi}} \left( 0 + \sqrt{2\pi} \right) = 1 \quad \blacksquare$$

## 5. Python 验证与可视化计算

```python
import numpy as np
import scipy.stats as stats

# 1. 验证标准正态分布 3-Sigma 概率
z_dist = stats.norm(0, 1)
p_1sigma = z_dist.cdf(1) - z_dist.cdf(-1)
p_2sigma = z_dist.cdf(2) - z_dist.cdf(-2)
p_3sigma = z_dist.cdf(3) - z_dist.cdf(-3)

print(f"1-Sigma 覆盖概率: {p_1sigma:.4f} (理论 0.6827)")
print(f"2-Sigma 覆盖概率: {p_2sigma:.4f} (理论 0.9545)")
print(f"3-Sigma 覆盖概率: {p_3sigma:.4f} (理论 0.9973)")

# 2. 验证指数分布无记忆性
lam = 1.5
s, t = 2.0, 3.0
exp_dist = stats.expon(scale=1/lam)
p_cond = (1 - exp_dist.cdf(s + t)) / (1 - exp_dist.cdf(s))
p_direct = 1 - exp_dist.cdf(t)
print(f"P(X > s+t | X > s): {p_cond:.6f}, P(X > t): {p_direct:.6f}")
assert np.isclose(p_cond, p_direct), "无记忆性检验失败！"
```
