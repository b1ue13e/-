# 概率统计-极限定理与渐近收敛

---

## 1. 核心数学收敛模式

设随机变量序列 $X_1, X_2, \dots$ 及随机变量 $X$：
1. **依概率收敛（Convergence in Probability, $\xrightarrow{P}$）**：
   $$\forall \varepsilon > 0, \quad \lim_{n \to \infty} P(|X_n - X| \ge \varepsilon) = 0 \quad (\text{记作 } X_n \xrightarrow{P} X)$$
2. **依分布收敛（Convergence in Distribution, $\xrightarrow{d}$ / 弱收敛）**：
   $$\lim_{n \to \infty} F_{X_n}(x) = F_X(x) \quad (\text{对 } F_X(x) \text{ 的所有连续点 } x, \text{ 记作 } X_n \xrightarrow{d} X)$$
- **收敛强弱关系**：$X_n \xrightarrow{P} X \implies X_n \xrightarrow{d} X$（反之不成立，除非 $X = c$ 为常数）。

---

## 2. 基础不等式与证明重建

### 1. 马尔可夫不等式（Markov's Inequality）
**定理**：设 $Y$ 为非负随机变量（$P(Y \ge 0) = 1$），则对任意常数 $a > 0$：
$$P(Y \ge a) \le \frac{E[Y]}{a}$$

**严格证明**：
$$E[Y] = \int_0^\infty y f(y) dy = \int_0^a y f(y) dy + \int_a^\infty y f(y) dy \ge \int_a^\infty y f(y) dy \ge a \int_a^\infty f(y) dy = a P(Y \ge a)$$
两端除以 $a$ 即得证。 $\blacksquare$

### 2. 切比雪夫不等式（Chebyshev's Inequality）
**定理**：设随机变量 $X$ 具有有限方差 $\sigma^2$，则对任意 $\varepsilon > 0$：
$$P(|X - \mu| \ge \varepsilon) \le \frac{\text{Var}(X)}{\varepsilon^2}$$
- *证明*：令非负变量 $Y = (X - \mu)^2$，$a = \varepsilon^2$，直接代入马尔可夫不等式即得。

---

## 3. 大数定律（Law of Large Numbers, LLN）

### 辛钦弱大数定律（Khinchin's WLLN）
**定理**：设 $X_1, X_2, \dots$ 为独立同分布（i.i.d.）随机变量序列，具有有限数学期望 $E[X_i] = \mu$。定义样本均值 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$，则当 $n \to \infty$ 时：
$$\bar{X}_n \xrightarrow{P} \mu \quad \left(\text{即 } \forall \varepsilon > 0, \lim_{n\to\infty} P(|\bar{X}_n - \mu| \ge \varepsilon) = 0\right)$$

**证明（假定方差 $\sigma^2 < \infty$ 的切比雪夫形式）**：
因 $E[\bar{X}_n] = \mu, \text{Var}(\bar{X}_n) = \frac{\sigma^2}{n}$。
由切比雪夫不等式：
$$P(|\bar{X}_n - \mu| \ge \varepsilon) \le \frac{\text{Var}(\bar{X}_n)}{\varepsilon^2} = \frac{\sigma^2}{n\varepsilon^2} \xrightarrow{n \to \infty} 0 \quad \blacksquare$$

---

## 4. 中心极限定理（Central Limit Theorem, CLT）

### 林德伯格-列维中心极限定理（Lindeberg-Lévy CLT）
**定理**：设 $X_1, X_2, \dots$ 为 i.i.d. 随机变量序列，期望 $E[X_i] = \mu$，方差 $\text{Var}(X_i) = \sigma^2 \in (0, \infty)$。
构造标准化样本均值序列：
$$Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} = \frac{\sum_{i=1}^n X_i - n\mu}{\sqrt{n}\sigma}$$
则当 $n \to \infty$ 时，$Z_n$ 依分布收敛于标准正态分布：
$$Z_n \xrightarrow{d} \mathcal{N}(0, 1)$$
即：$\lim_{n\to\infty} P(Z_n \le z) = \Phi(z) = \int_{-\infty}^z \frac{1}{\sqrt{2\pi}} e^{-u^2/2} du$。

**严格证明（特征函数法）**：
1. 令标准化零均值变量 $Y_i = \frac{X_i - \mu}{\sigma}$，则 $E[Y_i] = 0, \text{Var}(Y_i) = 1$；$Z_n = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i$。
2. $Y_i$ 的特征函数在 $t=0$ 处的二阶泰勒展开为：
   $$\varphi_Y(t) = E[e^{itY}] = 1 + itE[Y] - \frac{t^2}{2}E[Y^2] + o(t^2) = 1 - \frac{t^2}{2} + o(t^2)$$
3. $Z_n$ 的特征函数：
   $$\varphi_{Z_n}(t) = \left[\varphi_Y\left(\frac{t}{\sqrt{n}}\right)\right]^n = \left[1 - \frac{t^2}{2n} + o\left(\frac{t^2}{n}\right)\right]^n$$
4. 取极限：利用极限公式 $\lim_{n\to\infty} (1 + \frac{x}{n})^n = e^x$：
   $$\lim_{n\to\infty} \varphi_{Z_n}(t) = e^{-t^2/2}$$
   此极限正是标准正态分布 $\mathcal{N}(0, 1)$ 的特征函数！根据连续性定理（Lévy's Continuity Theorem），$Z_n \xrightarrow{d} \mathcal{N}(0, 1)$。 $\blacksquare$

## 5. Python 模拟中心极限定理

```python
import numpy as np
import scipy.stats as stats

# 从高度偏态的指数分布 Exp(lambda=1) 抽样，观察样本均值的正态逼近
np.random.seed(42)
lam = 1.0
mu = 1 / lam # 1.0
sigma = 1 / lam # 1.0

n_samples_list = [2, 5, 30, 100]
n_experiments = 50_000

for n in n_samples_list:
    # 模拟 n 个独立指数变量均值
    samples = np.random.exponential(scale=1/lam, size=(n_experiments, n))
    x_bar = samples.mean(axis=1)
    # 标准化
    z_n = (x_bar - mu) / (sigma / np.sqrt(n))
    
    # 检验正态性 (偏度与峰度)
    skew = stats.skew(z_n)
    kurt = stats.kurtosis(z_n) # 超额峰度
    print(f"样本量 n={n:3d} | 偏度: {skew:+.4f} (正态为0) | 超额峰度: {kurt:+.4f} (正态为0)")

# 当 n=100 时偏度非常接近 0
assert abs(skew) < 0.1, "CLT 偏度收敛检验失败！"
```
