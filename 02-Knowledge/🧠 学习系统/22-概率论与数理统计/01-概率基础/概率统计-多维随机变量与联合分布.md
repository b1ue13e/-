# 概率统计-多维随机变量与联合分布

---

## 1. 核心数学定义与公式

### 1. 二维联合累积分布函数（Joint CDF）与联合密度（Joint PDF）

对二维随机向量 $(X, Y)$：
$$F(x, y) = P(X \le x, Y \le y) = \int_{-\infty}^y \int_{-\infty}^x f(u, v) du dv$$
满足：
1. $f(x, y) \ge 0$；
2. 归一化：$\int_{-\infty}^\infty \int_{-\infty}^\infty f(x, y) dx dy = 1$；
3. 偏导关系：$f(x, y) = \frac{\partial^2 F(x, y)}{\partial x \partial y}$。

### 2. 边缘分布（Marginal Distribution）

通过对不关心的变量进行“全空间积分/求和（Marginalization）”得到：
$$f_X(x) = \int_{-\infty}^\infty f(x, y) dy, \qquad f_Y(y) = \int_{-\infty}^\infty f(x, y) dx$$

### 3. 条件分布（Conditional Distribution）

在给定 $Y = y$（$f_Y(y) > 0$）的条件下，$X$ 的**条件概率密度**定义为：
$$f_{X \mid Y}(x \mid y) = \frac{f(x, y)}{f_Y(y)}$$

### 4. 随机变量的独立性（Independence）

$X$ 与 $Y$ 相互独立 $\iff$ 联合分布等于边缘分布的乘积：
$$f(x, y) = f_X(x) f_Y(y) \quad (\forall x, y \in \mathbb{R})$$
（或等价于 $F(x, y) = F_X(x) F_Y(y)$，$f_{X \mid Y}(x \mid y) = f_X(x)$）。

## 2. 核心定理与推导重建

### 1. 独立随机变量之和的分布：卷积公式（Convolution Formula）

**定理**：设连续随机变量 $X$ 与 $Y$ 相互独立，其联合密度为 $f(x, y) = f_X(x) f_Y(y)$。则 $Z = X + Y$ 的概率密度函数为：
$$f_Z(z) = \int_{-\infty}^\infty f_X(x) f_Y(z - x) dx = \int_{-\infty}^\infty f_X(z - y) f_Y(y) dy$$

**严格证明（雅可比换元法）**：
引入辅助变量，作二维可逆线性变换：
$$\begin{cases} Z = X + Y \\ U = X \end{cases} \implies \begin{cases} X = U \\ Y = Z - U \end{cases}$$
计算雅可比行列式：
$$J = \det \begin{pmatrix} \frac{\partial x}{\partial z} & \frac{\partial x}{\partial u} \\ \frac{\partial y}{\partial z} & \frac{\partial y}{\partial u} \end{pmatrix} = \det \begin{pmatrix} 0 & 1 \\ 1 & -1 \end{pmatrix} = 0 - 1 = -1 \implies |J| = 1$$
故 $(Z, U)$ 的联合密度为：
$$f_{Z, U}(z, u) = f_{X, Y}(u, z - u) \cdot |J| = f_X(u) f_Y(z - u)$$
对辅助变量 $u$ 积分即可求出 $Z$ 的边缘密度：
$$f_Z(z) = \int_{-\infty}^\infty f_{Z, U}(z, u) du = \int_{-\infty}^\infty f_X(u) f_Y(z - u) du \quad \blacksquare$$

## 3. 二维正态分布与线性回归雏形

设 $(X, Y)$ 服从二维正态分布 $\mathcal{N}_2(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，其联合密度为：
$$f(x, y) = \frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}} \exp\left(-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_1)^2}{\sigma_1^2} - 2\rho\frac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2}\right]\right)$$

**条件分布定理**：
在 $X = x$ 的条件下，$Y$ 的条件分布仍为一维正态分布：
$$Y \mid (X = x) \sim \mathcal{N}\left(\mu_2 + \rho\frac{\sigma_2}{\sigma_1}(x - \mu_1), \; \sigma_2^2(1 - \rho^2)\right)$$
- **统计学深刻含义**：
  1. 条件期望 $E[Y \mid X = x] = \mu_2 + \beta(x - \mu_1)$ 是关于 $x$ 的**严格线性方程**，这就是**线性回归模型的理论来源**！
  2. 条件方差 $\text{Var}(Y \mid X = x) = \sigma_2^2(1 - \rho^2)$ 是一个与 $x$ 无关的常数，这就是回归分析中的**同方差性（Homoscedasticity）**！

## 4. Python 蒙特卡洛卷积验证

```python
import numpy as np
import scipy.stats as stats

# 验证两独立均匀分布 X, Y ~ U(0, 1) 之和 Z = X + Y 的三角分布 (Triangular)
n_samples = 1_000_000
X = np.random.uniform(0, 1, n_samples)
Y = np.random.uniform(0, 1, n_samples)
Z = X + Y

# 理论三角分布 PDF: f(z) = z if 0<=z<=1 else (2-z) if 1<z<=2
# 在 z = 0.5 与 z = 1.5 处的理论密度均为 0.5
kde = stats.gaussian_kde(Z)
print(f"z=0.5 处的模拟密度: {kde(0.5)[0]:.4f} (理论 0.5000)")
print(f"z=1.0 处的模拟密度: {kde(1.0)[0]:.4f} (理论 1.0000)")
print(f"z=1.5 处的模拟密度: {kde(1.5)[0]:.4f} (理论 0.5000)")
assert abs(kde(1.0)[0] - 1.0) < 0.02, "卷积模拟检验未通过！"
```
