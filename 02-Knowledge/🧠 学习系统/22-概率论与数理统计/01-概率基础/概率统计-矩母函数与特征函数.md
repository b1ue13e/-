# 概率统计-矩母函数与特征函数

---

## 1. 核心数学定义与性质

### 1. 矩母函数（MGF, Moment Generating Function）

设 $X$ 为随机变量，若存在常数 $h > 0$，使得对任意 $t \in (-h, h)$ 期望 $E[e^{tX}]$ 有限，则称：
$$M_X(t) = E[e^{tX}]$$
为 $X$ 的**矩母函数**。

**核心生成性质（为何叫“矩母”？）**：
对 $e^{tX}$ 作泰勒展开：
$$M_X(t) = E\left[\sum_{k=0}^\infty \frac{(tX)^k}{k!}\right] = \sum_{k=0}^\infty \frac{t^k}{k!} E[X^k]$$
对 $t$ 求 $k$ 阶导数并在 $t = 0$ 处求值，可提取 $X$ 的 **$k$ 阶原点矩（$k$-th raw moment）**：
$$E[X^k] = M_X^{(k)}(0) = \left.\frac{d^k M_X(t)}{dt^k}\right|_{t=0}$$
特别地：
- $E[X] = M_X'(0)$；
- $E[X^2] = M_X''(0) \implies \text{Var}(X) = M_X''(0) - [M_X'(0)]^2$。

### 2. 特征函数（Characteristic Function）

当某些厚尾分布（如柯西分布）的 MGF 在 $t \ne 0$ 处发散时，引入虚数单位 $i = \sqrt{-1}$，定义其**特征函数**（傅里叶变换）：
$$\varphi_X(t) = E[e^{itX}] = \int_{-\infty}^\infty e^{itx} f(x) dx$$
- **优势**：因 $|e^{itX}| \le 1$，对**任意**随机变量，特征函数在整个实轴 $\mathbb{R}$ 上恒绝对收敛且一致连续。

---

## 2. 核心代数性质与唯一性定理

1. **线性变换性质**：若 $Y = aX + b$，则：
   $$M_Y(t) = E[e^{t(aX+b)}] = e^{bt} M_X(at)$$
2. **独立和与乘积定理**：若 $X_1, \dots, X_n$ 相互独立，其和 $S_n = \sum_{i=1}^n X_i$，则：
   $$M_{S_n}(t) = E\left[\exp\left(t\sum_{i=1}^n X_i\right)\right] = \prod_{i=1}^n E[e^{tX_i}] = \prod_{i=1}^n M_{X_i}(t)$$
3. **唯一性定理（Uniqueness Theorem）**：
   若两个随机变量 $X$ 和 $Y$ 在包含原点的邻域 $(-h, h)$ 内具有相同的矩母函数（即 $M_X(t) = M_Y(t)$），则 $X$ 与 $Y$ 具有相同的概率分布（$F_X(x) = F_Y(x)$）。

---

## 3. 常见分布族的 MGF 对照表

| 分布名称 | 参数 | MGF $M_X(t)$ 公式 | 有效范围 |
| :--- | :---: | :--- | :---: |
| **伯努利分布** | $p$ | $(1-p) + p e^t$ | $t \in \mathbb{R}$ |
| **二项分布** | $n, p$ | $\big((1-p) + p e^t\big)^n$ | $t \in \mathbb{R}$ |
| **泊松分布** | $\lambda$ | $\exp\left(\lambda(e^t - 1)\right)$ | $t \in \mathbb{R}$ |
| **指数分布** | $\lambda$ | $\frac{\lambda}{\lambda - t}$ | $t < \lambda$ |
| **标准正态分布** | $\mathcal{N}(0, 1)$ | $\exp\left(\frac{t^2}{2}\right)$ | $t \in \mathbb{R}$ |
| **一般正态分布** | $\mathcal{N}(\mu, \sigma^2)$ | $\exp\left(\mu t + \frac{1}{2}\sigma^2 t^2\right)$ | $t \in \mathbb{R}$ |
| **伽马分布** | $\alpha, \beta$ | $\left(1 - \frac{t}{\beta}\right)^{-\alpha}$ | $t < \beta$ |

---

## 4. 经典应用推导：独立正态变量线性组合的再生性

**定理**：设 $X_1 \sim \mathcal{N}(\mu_1, \sigma_1^2), X_2 \sim \mathcal{N}(\mu_2, \sigma_2^2)$ 相互独立，证明 $Y = aX_1 + bX_2 \sim \mathcal{N}(a\mu_1 + b\mu_2, a^2\sigma_1^2 + b^2\sigma_2^2)$。

**严谨证明**：
1. 单个变量的 MGF：$M_{X_j}(t) = \exp\left(\mu_j t + \frac{1}{2}\sigma_j^2 t^2\right)$；
2. 利用独立性和线性性质：
   $$M_Y(t) = M_{X_1}(at) \cdot M_{X_2}(bt) = \exp\left(\mu_1(at) + \frac{1}{2}\sigma_1^2(at)^2\right) \cdot \exp\left(\mu_2(bt) + \frac{1}{2}\sigma_2^2(bt)^2\right)$$
3. 指数项合并：
   $$M_Y(t) = \exp\left((a\mu_1 + b\mu_2)t + \frac{1}{2}(a^2\sigma_1^2 + b^2\sigma_2^2)t^2\right)$$
4. 对照正态分布 MGF 形式，由唯一性定理，$Y$ 必服从参数为 $\mu_Y = a\mu_1 + b\mu_2, \sigma_Y^2 = a^2\sigma_1^2 + b^2\sigma_2^2$ 的正态分布。 $\blacksquare$

## 5. Python 数值验证 MGF 求导

```python
import numpy as np
import scipy.stats as stats

# 验证泊松分布 Poisson(lambda=3.0) 利用 MGF 求期望与方差
lam = 3.0
def mgf_poisson(t):
    return np.exp(lam * (np.exp(t) - 1))

# 数值微分求导 (步长 h)
h = 1e-5
# 一阶导 M'(0) -> E[X]
d1 = (mgf_poisson(h) - mgf_poisson(-h)) / (2 * h)
# 二阶导 M''(0) -> E[X^2]
d2 = (mgf_poisson(h) - 2*mgf_poisson(0) + mgf_poisson(-h)) / (h**2)

calc_mean = d1
calc_var = d2 - (d1**2)

print(f"MGF 数值一阶导 (期望): {calc_mean:.6f} (理论 {lam})")
print(f"MGF 数值二阶导减平方 (方差): {calc_var:.6f} (理论 {lam})")
assert abs(calc_mean - lam) < 1e-4 and abs(calc_var - lam) < 1e-4, "MGF 求导验证失败！"
```
