# 概率统计-概率空间与条件概率

---

## 1. 第一性原理与数学建构动机

### 1. 为什么需要公理化概率空间 $(\Omega, \mathcal{F}, P)$？
在古典概型中，样本空间 $\Omega$ 是有限的，任何子集都是可测事件。然而当引入连续随机变量（如实数区间 $[0, 1]$ 上的随机抽样）时，经典的“每个子集均可赋概率”产生致命矛盾（如 Banach-Tarski 悖论与不可测集）。
因此，现代概率论建立在**测度论**之上：
1. **样本空间 $\Omega$**：试验一切可能结果的集合。
2. **$\sigma$-代数（可测事件族） $\mathcal{F}$**：$\Omega$ 的子集族，满足对补集和可数交/并封闭，排除了非可测集的逻辑悖论。
3. **概率测度 $P: \mathcal{F} \to [0, 1]$**：在 $\mathcal{F}$ 上定义的实函数，满足：
   - **非负性**：对任意 $A \in \mathcal{F}$，$P(A) \ge 0$；
   - **规范性**：$P(\Omega) = 1$；
   - **可数可加性（Countable Additivity）**：对两两互斥序列 $\{A_i\}_{i=1}^\infty \subset \mathcal{F}$：
     $$P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)$$
   > **关键直觉**：*为什么必须是“可数”可加性而非“有限”可加性？* 因为极限定理（如大数定律、中心极限定理）讨论的是事件序列的极限 $n \to \infty$。只有可数可加性才能保证极限与测度运算的可交换性！

## 2. 核心数学定义与公式

### 1. 条件概率的几何本质：空间缩放与重新归一化
设 $B \in \mathcal{F}$ 且 $P(B) > 0$，已知事件 $B$ 发生的条件概率定义为：
$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

> **第一性原理几何视角**：
> 条件概率并非一种“新的概率”，而是**样本空间的缩放与重新归一化（Re-normalization）**：
> 1. 事件 $B$ 的发生将有效样本空间从 $\Omega$ 严密**裁切/约束**至 $B$；
> 2. 原样本空间中在 $B$ 之外的部分（$B^c$）概率彻底衰减为 0；
> 3. 落在 $B$ 内部的交集部分 $A \cap B$，必须整体乘以缩放因子 $\frac{1}{P(B)}$，从而强行满足新空间规范性 $P(B \mid B) = 1$。

### 2. 乘法公式与全概率公式
- **乘法公式**：$P(A \cap B) = P(B) P(A \mid B) = P(A) P(B \mid A)$
- **全概率公式（划分空间分解）**：若 $\{B_1, B_2, \dots, B_n\}$ 为 $\Omega$ 的划分，则：
  $$P(A) = \sum_{i=1}^n P(B_i) P(A \mid B_i)$$

### 3. 贝叶斯公式：从观察证据反推归因
$$P(B_k \mid A) = \frac{P(B_k) P(A \mid B_k)}{\sum_{i=1}^n P(B_i) P(A \mid B_i)}$$
- **先验（Prior）$P(B_k)$**：未观察到证据 $A$ 前的经验信念；
- **似然（Likelihood）$P(A \mid B_k)$**：假定原因 $B_k$ 成立时，生成观察证据 $A$ 的生成概率；
- **后验（Posterior）$P(B_k \mid A)$**：吸收证据 $A$ 后更新的置信分布。


### 4. 事件的独立性

- **两事件独立**：$A$ 与 $B$ 独立 $\iff P(A \cap B) = P(A) P(B)$（等价于 $P(A \mid B) = P(A)$）；
- **三事件相互独立（Mutual Independence）**：必须同时满足两两独立及三重交积：
  $$\begin{cases} P(A \cap B) = P(A)P(B), \quad P(B \cap C) = P(B)P(C), \quad P(A \cap C) = P(A)P(C) \\ P(A \cap B \cap C) = P(A)P(B)P(C) \end{cases}$$

## 3. 直觉与经典案例

### 经典案例：罕见病检测的“基率谬误”（Base Rate Fallacy）
- **背景**：某种罕见病患病率 $P(D) = 0.001$（基率仅 0.1%）。某检测试剂的真阳性率（灵敏度）$P(T^+ \mid D) = 0.99$，假阳性率（特异度补数）$P(T^+ \mid D^c) = 0.01$。
- **问题**：如果一个人体检结果为阳性（$T^+$），他真正患病的概率是多少？
- **贝叶斯计算**：
  $$P(D \mid T^+) = \frac{P(D) P(T^+ \mid D)}{P(D) P(T^+ \mid D) + P(D^c) P(T^+ \mid D^c)} = \frac{0.001 \times 0.99}{0.001 \times 0.99 + 0.999 \times 0.01} = \frac{0.00099}{0.00099 + 0.00999} \approx 0.0902 \ (9.02\%)$$
- **直觉本质**：尽管试剂非常准确（99%），但由于基础患病人群极其稀少，阳性结果中绝大多数（约 91%）是庞大健康人群中的假阳性误报。

## 4. 经典反例

> [!CAUTION]
> **反例：两两独立 $\centernot\implies$ 相互独立（Bernstein 经典反例）**
> 设正四面体的四个面分别涂上：
> 1 号面：红；2 号面：蓝；3 号面：绿；4 号面：红+蓝+绿条纹。
> 投掷该四面体，令事件 $R, B, G$ 分别表示着地的一面含有红、蓝、绿色。
> - 各单事件概率：$P(R) = P(B) = P(G) = \frac{2}{4} = \frac{1}{2}$；
> - 两两交积：只有 4 号面同时有三色，故 $P(R \cap B) = \frac{1}{4} = P(R)P(B)$（同理两两独立）；
> - 三重交积：$P(R \cap B \cap G) = \frac{1}{4} \ne P(R)P(B)P(G) = \frac{1}{8}$。
> - **教训**：两两独立不能推导相互独立！

## 5. Python 蒙特卡洛仿真验证

```python
import numpy as np

# 蒙特卡洛模拟罕见病检测
n_sim = 1_000_000
prior_disease = 0.001
sensitivity = 0.99
false_positive = 0.01

# 1. 生成总体真实状态: 1 为患病, 0 为健康
disease = np.random.rand(n_sim) < prior_disease

# 2. 生成检测结果
test_positive = np.zeros(n_sim, dtype=bool)
# 患病者检测
test_positive[disease] = np.random.rand(disease.sum()) < sensitivity
# 健康者检测 (假阳性)
test_positive[~disease] = np.random.rand((~disease).sum()) < false_positive

# 3. 统计检测阳性者中真实患病的比例
actual_positive = disease[test_positive]
simulated_posterior = actual_positive.mean()
theoretical_posterior = (prior_disease * sensitivity) / (prior_disease * sensitivity + (1 - prior_disease) * false_positive)

print(f"模拟后验概率: {simulated_posterior:.4f}")
print(f"理论后验概率: {theoretical_posterior:.4f}")
assert abs(simulated_posterior - theoretical_posterior) < 0.005, "模拟结果偏离理论值！"
```
