# 概率统计-数字特征：期望、方差与协方差

---

## 1. 核心数学定义与公式

### 1. 数学期望（Expectation）与 LOTUS 法则

- **离散型**：$E[X] = \sum_k x_k P(X = x_k)$（要求绝对收敛 $\sum |x_k| p(x_k) < \infty$）；
- **连续型**：$E[X] = \int_{-\infty}^\infty x f(x) dx$（要求 $\int |x| f(x) dx < \infty$）；
- **无意识统计学家法则（LOTUS, Law of the Unconscious Statistician）**：
  若求 $Y = g(X)$ 的期望，无需先求 $Y$ 的密度函数，可直接对 $g(x)$ 进行加权积分：
  $$E[g(X)] = \int_{-\infty}^\infty g(x) f_X(x) dx \quad \left(\text{离散型 } \sum_k g(x_k) p(x_k)\right)$$

### 2. 方差与标准差（Variance & Standard Deviation）

$$\text{Var}(X) = E\big[(X - E[X])^2\big] = E[X^2] - (E[X])^2, \quad \sigma_X = \sqrt{\text{Var}(X)}$$
**重要代数性质**：
1. $\text{Var}(c) = 0$（常数的方差为 0）；
2. $\text{Var}(aX + b) = a^2 \text{Var}(X)$；
3. **独立线性组合方差可加**：若 $X_1, \dots, X_n$ 相互独立，则 $\text{Var}\left(\sum_{i=1}^n a_i X_i\right) = \sum_{i=1}^n a_i^2 \text{Var}(X_i)$。

### 3. 协方差与 Pearson 相关系数

- **协方差（Covariance）**：
  $$\text{Cov}(X, Y) = E\big[(X - E[X])(Y - E[Y])\big] = E[XY] - E[X]E[Y]$$
- **相关系数（Correlation Coefficient）**：
  $$\rho_{X,Y} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} \quad (-1 \le \rho_{X,Y} \le 1)$$
- **一般和的方差公式**：
  $$\text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y) \pm 2\text{Cov}(X, Y)$$

## 2. 关键定理与全方差分解

### 1. 全期望公式（Law of Iterated Expectations / 塔式法则）

**定理**：对任意随机变量 $X, Y$，若期望有限，则：
$$E\big[E[X \mid Y]\big] = E[X]$$

**证明（连续型情形）**：
根据条件期望定义 $E[X \mid Y = y] = \int_{-\infty}^\infty x f_{X \mid Y}(x \mid y) dx$：
$$E\big[E[X \mid Y]\big] = \int_{-\infty}^\infty \left(\int_{-\infty}^\infty x \frac{f(x, y)}{f_Y(y)} dx\right) f_Y(y) dy = \int_{-\infty}^\infty x \left(\int_{-\infty}^\infty f(x, y) dy\right) dx = \int_{-\infty}^\infty x f_X(x) dx = E[X] \quad \blacksquare$$

### 2. 全方差公式（Law of Total Variance / Eve's Law）

**定理（方差分解）**：
$$\text{Var}(X) = E\big[\text{Var}(X \mid Y)\big] + \text{Var}\big(E[X \mid Y]\big)$$

**口诀**：**“总方差 = 组内方差的期望 + 组间期望的方差”**。

**严谨证明**：
根据方差定义 $\text{Var}(Z) = E[Z^2] - (E[Z])^2$：
1. 计算条件方差的期望：
   $$E[\text{Var}(X \mid Y)] = E\left[E[X^2 \mid Y] - (E[X \mid Y])^2\right] = E\big[E[X^2 \mid Y]\big] - E\left[(E[X \mid Y])^2\right] = E[X^2] - E\left[(E[X \mid Y])^2\right]$$
2. 计算条件期望的方差：
   $$\text{Var}(E[X \mid Y]) = E\left[(E[X \mid Y])^2\right] - \left(E[E[X \mid Y]]\right)^2 = E\left[(E[X \mid Y])^2\right] - (E[X])^2$$
3. 将两式相加，交叉项 $E\left[(E[X \mid Y])^2\right]$ 相互抵消：
   $$E[\text{Var}(X \mid Y)] + \text{Var}(E[X \mid Y]) = E[X^2] - (E[X])^2 = \text{Var}(X) \quad \blacksquare$$

## 3. 经典反例

> [!CAUTION]
> **反例：不相关（$\text{Cov}(X, Y) = 0$）$\centernot\implies$ 相互独立**
> 设 $X \sim U(-1, 1)$，对称分布使得 $E[X] = 0, E[X^3] = 0$。
> 构造非线性确定性关系 $Y = X^2$。
> - 协方差：$\text{Cov}(X, Y) = E[XY] - E[X]E[Y] = E[X^3] - 0 \cdot E[X^2] = 0$；
> - 独立性：已知 $Y = 1$ 时，$X$ 只能取 $\pm 1$，显然不独立（$P(X=0 \mid Y=1) = 0 \ne P(X=0)$）。
> - **结论**：相关系数衡量的是**线性相关程度**，无法捕捉二次/非线性依赖。

## 4. Python 验证全方差公式

```python
import numpy as np

# 验证全方差公式: 随机分组生成混合样本
np.random.seed(42)
n_samples = 1_000_000

# Group Y: 0 或 1 (二项分布)
Y = np.random.binomial(1, 0.4, n_samples)
# X 在 Y=0 下 ~ N(0, 1^2), 在 Y=1 下 ~ N(5, 2^2)
X = np.where(Y == 0, np.random.normal(0, 1, n_samples), np.random.normal(5, 2, n_samples))

# 1. 经验总方差
total_var = np.var(X)

# 2. 条件期望与条件方差
# E[X|Y=0] = 0, E[X|Y=1] = 5
# Var(X|Y=0) = 1, Var(X|Y=1) = 4
p = 0.4
E_var = (1 - p) * 1.0 + p * 4.0 # E[Var(X|Y)] = 0.6*1 + 0.4*4 = 2.2
# E[X|Y] 取值为 0 (概率 0.6) 和 5 (概率 0.4)
E_cond = (1 - p) * 0.0 + p * 5.0 # 2.0
Var_E = (1 - p) * (0 - E_cond)**2 + p * (5 - E_cond)**2 # 0.6*4 + 0.4*9 = 2.4 + 3.6 = 6.0
decomp_var = E_var + Var_E # 2.2 + 6.0 = 8.2

print(f"数据经验总方差 Var(X): {total_var:.4f}")
print(f"全方差分解理论值: {decomp_var:.4f}")
assert abs(total_var - decomp_var) < 0.05, "全方差模拟验证未通过！"
```
