# 概率统计-似然比检验与拟合优度检验

---

## 1. 广义似然比检验（GLRT, Generalized Likelihood Ratio Test）

### 1. 复合假设与全参数空间划分
设总体分布包含未知参数 $\boldsymbol{\theta} \in \Theta$（参数维度为 $k$）。
检验复合假设：
$$H_0: \boldsymbol{\theta} \in \Theta_0 \quad \text{vs} \quad H_1: \boldsymbol{\theta} \in \Theta_1 = \Theta \setminus \Theta_0 \quad (\text{设 } \Theta_0 \text{ 维度为 } k_0 < k)$$

### 2. 似然比统计量 $\Lambda(\mathbf{X})$ 定义
$$\Lambda(\mathbf{X}) = \frac{\sup_{\boldsymbol{\theta} \in \Theta_0} L(\boldsymbol{\theta}; \mathbf{X})}{\sup_{\boldsymbol{\theta} \in \Theta} L(\boldsymbol{\theta}; \mathbf{X})} = \frac{L(\hat{\boldsymbol{\theta}}_0; \mathbf{X})}{L(\hat{\boldsymbol{\theta}}; \mathbf{X})}$$
其中 $\hat{\boldsymbol{\theta}}_0$ 为在原假设限制空间 $\Theta_0$ 下的受约束极大似然估计（Restricted MLE），$\hat{\boldsymbol{\theta}}$ 为全空间 $\Theta$ 下的无约束极大似然估计（Unrestricted MLE）。
- **取值范围**：$0 < \Lambda(\mathbf{X}) \le 1$；
- **决策直觉**：若 $H_0$ 为真，限制极大与无限制极大应该非常接近，$\Lambda \approx 1$；若 $\Lambda$ 显著偏小（趋于 0），说明原假设极大地降低了观测数据的似然度，应**拒绝 $H_0$**。

### 3. 威尔克斯定理（Wilks' Theorem / 似然比渐近分布）
**定理**：在正则条件下，当样本容量 $n \to \infty$ 时，统计量：
$$-2 \ln \Lambda(\mathbf{X}) \xrightarrow{d} \chi^2(r)$$
依分布收敛于自由度为 $r = \dim(\Theta) - \dim(\Theta_0) = k - k_0$ 的卡方分布！
- **拒绝域（大样本准则）**：$-2\ln \Lambda(\mathbf{X}) \ge \chi^2_\alpha(r)$。

## 2. 皮尔逊卡方拟合优度检验（Pearson's $\chi^2$ Goodness-of-fit Test）

### 1. 问题背景
检验总体是否服从某种理论分布 $F_0(x)$：
$$H_0: F(x) = F_0(x) \quad \text{vs} \quad H_1: F(x) \ne F_0(x)$$

### 2. 构造频数表与统计量
将实轴划分为 $k$ 个互不相交的区间 $A_1, \dots, A_k$：
- **观察频数（Observed Frequency）**：$O_i = \sum_{j=1}^n I(X_j \in A_i)$；
- **理论期望频数（Expected Frequency）**：$E_i = n p_i = n P_{H_0}(X \in A_i)$。

**Pearson 卡方统计量**：
$$\chi^2 = \sum_{i=1}^k \frac{(O_i - E_i)^2}{E_i} \xrightarrow{d} \chi^2(k - 1 - m)$$
其中 $m$ 是利用样本数据估计理论分布未知参数的个数（若分布完全已知则 $m=0$）。

---

## 3. 列联表独立性检验（Contingency Table）

设离散分类变量 $A$ 有 $r$ 个水平，$B$ 有 $c$ 个水平，$r \times c$ 列联表的观察频数为 $O_{ij}$。
检验两属性相互独立：$H_0: p_{ij} = p_{i\cdot} p_{\cdot j}$。
- 理论期望频数：$E_{ij} = \frac{R_i C_j}{n}$（$R_i$ 为行和，$C_j$ 为列和）；
- 卡方统计量：
  $$\chi^2 = \sum_{i=1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}} \sim \chi^2\big((r-1)(c-1)\big)$$

---

## 4. Python 验证卡方独立性检验

```python
import numpy as np
import scipy.stats as stats

# 模拟 2x2 列联表 (例如: 两种药物 A/B 与 治愈/未治愈)
# [[A_cured, A_uncured], [B_cured, B_uncured]]
observed_table = np.array([[50, 20],
                           [30, 40]])

chi2_stat, p_val, dof, expected = stats.chi2_contingency(observed_table, correction=False)

print(f"卡方统计量: {chi2_stat:.4f}")
print(f"p-value: {p_val:.4e}")
print(f"自由度 dof: {dof} (理论 (2-1)*(2-1) = 1)")
print("理论期望频数矩阵 E:\n", expected)

# 手算公式验证
manual_chi2 = np.sum((observed_table - expected)**2 / expected)
assert np.isclose(chi2_stat, manual_chi2), "卡方统计量计算不一致！"
```
