# 概率统计-参数区间估计与枢轴量法

---

## 1. 核心数学定义

### 1. 置信区间（Confidence Interval, CI）
设总体分布含未知参数 $\theta \in \Theta$，样本为 $\mathbf{X} = (X_1, \dots, X_n)$。
给定显著性水平 $\alpha \in (0, 1)$（通常取 $0.05$ 或 $0.01$），若存在两个统计量 $\hat{\theta}_L(\mathbf{X})$ 和 $\hat{\theta}_U(\mathbf{X})$，使得对任意 $\theta \in \Theta$ 恒满足：
$$P\big(\hat{\theta}_L(\mathbf{X}) \le \theta \le \hat{\theta}_U(\mathbf{X})\big) = 1 - \alpha$$
则称随机区间 $[\hat{\theta}_L(\mathbf{X}), \hat{\theta}_U(\mathbf{X})]$ 为参数 $\theta$ 的**置信水平为 $1-\alpha$ 的双侧置信区间**。
- **$1-\alpha$** 称为**置信度 / 置信水平（Confidence Level）**；
- $\hat{\theta}_L, \hat{\theta}_U$ 分别称为**置信下限与置信上限**。

---

## 2. 枢轴量法（Pivotal Quantity Method）四步构造法

**枢轴量（Pivot）的定义**：
随机变量 $G(\mathbf{X}, \theta)$ 称为枢轴量，若满足：
1. $G(\mathbf{X}, \theta)$ 是样本 $\mathbf{X}$ 与待估参数 $\theta$ 的函数；
2. **$G(\mathbf{X}, \theta)$ 的概率分布完全已知，不依赖于任何未知参数（包括 $\theta$ 以及其他讨厌参数 nuisance parameters）**。

### 标准四步构造流程：
1. **寻找枢轴量**：基于充分统计量或估计量构造分布已知的 $G(\mathbf{X}, \theta)$；
2. **确定分位数**：对给定的置信水平 $1-\alpha$，在 $G$ 的已知分布中选取分位数 $c_1, c_2$，使得：
   $$P\big(c_1 \le G(\mathbf{X}, \theta) \le c_2\big) = 1 - \alpha$$
3. **不等式反解**：将不等式 $c_1 \le G(\mathbf{X}, \theta) \le c_2$ 转化为以 $\theta$ 为中心的等价形式：
   $$P\big(\hat{\theta}_L(\mathbf{X}) \le \theta \le \hat{\theta}_U(\mathbf{X})\big) = 1 - \alpha$$
4. **代入样本观测值**：得到实际数值置信区间。

## 3. 正态总体经典置信区间推导全景表

设 $X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \mathcal{N}(\mu, \sigma^2)$：

| 待估参数 | 其他参数状态 | 选取的枢轴量 $G(\mathbf{X}, \theta)$ | 枢轴量分布 | $1-\alpha$ 双侧置信区间公式 |
| :--- | :---: | :---: | :---: | :--- |
| **均值 $\mu$** | $\sigma^2$ 已知 | $Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}$ | $\mathcal{N}(0, 1)$ | $\left[\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}}, \; \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right]$ |
| **均值 $\mu$** | $\sigma^2$ 未知 | $T = \frac{\bar{X} - \mu}{S / \sqrt{n}}$ | $t(n-1)$ | $\left[\bar{X} - t_{\alpha/2}(n-1)\frac{S}{\sqrt{n}}, \; \bar{X} + t_{\alpha/2}(n-1)\frac{S}{\sqrt{n}}\right]$ |
| **方差 $\sigma^2$** | $\mu$ 未知 | $\chi^2 = \frac{(n-1)S^2}{\sigma^2}$ | $\chi^2(n-1)$ | $\left[\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \; \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$ |

---

## 4. 频率学派置信区间的本质与认知反例

> [!CAUTION]
> **致命误区：“计算出区间 $[2.1, 4.3]$ 后，参数 $\mu$ 落在此区间的概率是 95%” —— 彻底错误！**
> - **正解**：在经典频率学派看来，真实参数 $\mu$ 是一个**客观固定存在的未知常数**，而不是随机变量。区间 $[2.1, 4.3]$ 计算出来后也是固定的。因此，“常数 $\mu$ 是否落在固定区间 $[2.1, 4.3]$ 内”只有两种可能：**要么在（概率为 1），要么不在（概率为 0）**。
> - **“95% 置信度”的真正含义**：指的是**构造这个区间的随机方法（算法）的长期捕获率**。如果独立重复抽样做 10,000 次实验，生成 10,000 个不同的置信区间，其中大约有 95% 的区间能够成功覆盖住真实的固定参数 $\mu$。

## 5. Python 蒙特卡洛验证置信区间覆盖率

```python
import numpy as np
import scipy.stats as stats

np.random.seed(42)
n_experiments = 10_000
n = 15
true_mu, true_sigma = 10.0, 3.0
alpha = 0.05

# 抽取 10000 组正态样本
samples = np.random.normal(true_mu, true_sigma, size=(n_experiments, n))
x_bars = samples.mean(axis=1)
s_vals = samples.std(axis=1, ddof=1)

# 计算 t 置信区间
t_crit = stats.t.ppf(1 - alpha/2, df=n-1)
margin_errors = t_crit * (s_vals / np.sqrt(n))
ci_lowers = x_bars - margin_errors
ci_uppers = x_bars + margin_errors

# 检验区间是否覆盖真实 mu
covered = (ci_lowers <= true_mu) & (true_mu <= ci_uppers)
coverage_rate = covered.mean()

print(f"95% 置信区间蒙特卡洛经验覆盖率: {coverage_rate:.4f} (理论 0.9500)")
assert abs(coverage_rate - 0.95) < 0.008, "置信区间覆盖率检验失败！"
```
