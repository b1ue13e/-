## 🎯 阶段验收标准与作业

### 闭卷验收标准
- [ ] 准确理解置信区间（$1-\alpha$）的频率学派含义（多次重复抽样区间覆盖真值的长期比例）；
- [ ] 能用枢轴量法推导单正态总体方差未知时均值的 $t$ 置信区间与方差的卡方置信区间；
- [ ] 能写出 Neyman-Pearson 基本引理的似然比拒绝域形式；
- [ ] 能独立推导单/双样本 t 检验统计量、单因素方差齐性 F 检验统计量；
- [ ] 能用 Python 模拟第一类错误（假阳性）与检验功效曲线（Power Curve）。
