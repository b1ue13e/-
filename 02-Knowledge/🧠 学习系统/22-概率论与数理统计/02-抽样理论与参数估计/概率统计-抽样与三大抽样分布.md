# 概率统计-抽样与三大抽样分布

---

## 1. 核心数学定义：三大抽样分布

设所有涉及的变量均相互独立：

### 1. $\chi^2$ 分布（卡方分布）
设 $Z_1, Z_2, \dots, Z_n \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0, 1)$，则其平方和：
$$X = \sum_{i=1}^n Z_i^2 \sim \chi^2(n)$$
服从自由度为 $n$ 的**卡方分布**。
- **性质**：$E[X] = n, \quad \text{Var}(X) = 2n$；
- **可加性**：若 $X_1 \sim \chi^2(n_1), X_2 \sim \chi^2(n_2)$ 相互独立，则 $X_1 + X_2 \sim \chi^2(n_1 + n_2)$。

### 2. $t$ 分布（Student's $t$-Distribution）
设 $Z \sim \mathcal{N}(0, 1)$，$Y \sim \chi^2(n)$，且 $Z$ 与 $Y$ 相互独立，则：
$$T = \frac{Z}{\sqrt{Y / n}} \sim t(n)$$
服从自由度为 $n$ 的 **$t$ 分布**。
- **性质**：对称钟形，厚尾于正态分布；$E[T] = 0 \; (n>1)$，$\text{Var}(T) = \frac{n}{n-2} \; (n>2)$；
- **渐近极限**：当 $n \to \infty$ 时，$t(n) \xrightarrow{d} \mathcal{N}(0, 1)$。

### 3. $F$ 分布（Fisher-Snedecor $F$-Distribution）
设 $U \sim \chi^2(n_1)$，$V \sim \chi^2(n_2)$，且 $U$ 与 $V$ 相互独立，则两者的自由度归一化比值：
$$F = \frac{U / n_1}{V / n_2} \sim F(n_1, n_2)$$
服从第一自由度为 $n_1$、第二自由度为 $n_2$ 的 **$F$ 分布**。
- **倒数性质**：若 $F \sim F(n_1, n_2)$，则 $\frac{1}{F} \sim F(n_2, n_1)$；
- **与 $t$ 分布的关系**：若 $T \sim t(n)$，则 $T^2 \sim F(1, n)$。

---

## 2. 正态总体抽样核心定理

设总体 $X \sim \mathcal{N}(\mu, \sigma^2)$，从该总体中抽取容量为 $n$ 的简单随机样本 $X_1, \dots, X_n$。
定义：
- **样本均值**：$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$
- **样本方差**：$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$

### 定理全景

1. **样本均值的精确分布**：
   $$\bar{X} \sim \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right) \implies \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim \mathcal{N}(0, 1)$$
2. **样本方差的分布与独立性**：
   $$\frac{(n-1)S^2}{\sigma^2} = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} \sim \chi^2(n-1)$$
   且 **$\bar{X}$ 与 $S^2$ 相互独立**！
3. **未知方差时的 $t$ 统计量**：
   $$\frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$$

---

## 3. 正交变换法严谨证明 $\bar{X} \perp S^2$

**严格证明**：
1. 标准化：令 $Z_i = \frac{X_i - \mu}{\sigma} \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0, 1)$。记向量 $\mathbf{Z} = (Z_1, \dots, Z_n)^T \sim \mathcal{N}_n(\mathbf{0}, \mathbf{I})$。
2. 构造正交矩阵 $\mathbf{A}_{n \times n}$（满足 $\mathbf{A}^T \mathbf{A} = \mathbf{I}$），使其第一行为 $(1/\sqrt{n}, \dots, 1/\sqrt{n})$。
3. 作正交变换 $\mathbf{Y} = \mathbf{A}\mathbf{Z} = (Y_1, \dots, Y_n)^T$。
   - 由于正交变换保持多维正态分布的独立性与球对称性，$\mathbf{Y} \sim \mathcal{N}_n(\mathbf{0}, \mathbf{I})$，即 $Y_1, Y_2, \dots, Y_n \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0, 1)$！
4. 第一分量：
   $$Y_1 = \sum_{i=1}^n \frac{1}{\sqrt{n}} Z_i = \sqrt{n} \bar{Z} = \frac{\sqrt{n}(\bar{X} - \mu)}{\sigma}$$
   因此 $\bar{X}$ 完全由 $Y_1$ 唯一决定！
5. 平方和保范性：$\sum_{i=1}^n Z_i^2 = \mathbf{Z}^T \mathbf{Z} = \mathbf{Y}^T \mathbf{Y} = \sum_{i=1}^n Y_i^2$。
   又因为 $\sum_{i=1}^n Z_i^2 = \sum_{i=1}^n (Z_i - \bar{Z})^2 + n\bar{Z}^2 = \frac{(n-1)S^2}{\sigma^2} + Y_1^2$。
   故：
   $$\frac{(n-1)S^2}{\sigma^2} = \sum_{i=2}^n Y_i^2$$
6. **结论**：
   - $\frac{(n-1)S^2}{\sigma^2}$ 是 $n-1$ 个独立标准正态变量 $Y_2^2 + \dots + Y_n^2$ 的平方和，因此严格服从 $\chi^2(n-1)$；
   - $\bar{X}$ 仅依赖 $Y_1$，而 $S^2$ 仅依赖 $(Y_2, \dots, Y_n)$，由 $Y_i$ 的独立性可得 **$\bar{X}$ 与 $S^2$ 严格独立**！ $\blacksquare$

## 4. Python 验证正态抽样定理

```python
import numpy as np
import scipy.stats as stats

np.random.seed(42)
n_sim = 50_000
n = 10
mu, sigma = 5.0, 2.0

# 抽取 50000 组容量为 10 的正态样本
samples = np.random.normal(mu, sigma, size=(n_sim, n))
x_bar = samples.mean(axis=1)
s2 = samples.var(axis=1, ddof=1)

# 1. 检验相关性 (应为 0)
corr, p_val = stats.pearsonr(x_bar, s2)
print(f"X_bar 与 S^2 的样本相关系数: {corr:+.4f} (p-value: {p_val:.4f})")
assert abs(corr) < 0.01, "样本均值与方差应不相关！"

# 2. 检验 (n-1)S^2 / sigma^2 的卡方分布均值 (应为 n-1 = 9)
chi_stat = (n - 1) * s2 / (sigma**2)
print(f"卡方统计量经验均值: {chi_stat.mean():.4f} (理论 9.0000)")
assert abs(chi_stat.mean() - 9.0) < 0.05, "卡方统计量均值偏差过大！"
```
