# 概率统计-充分统计量与因子分解定理

---

## 1. 核心数学定义

设样本 $\mathbf{X} = (X_1, \dots, X_n)$ 的联合分布族为 $\{f(\mathbf{x}; \theta) : \theta \in \Theta\}$。

### 1. 充分统计量（Sufficient Statistic）的条件分布定义

统计量 $T = T(\mathbf{X})$ 称为参数 $\theta$ 的**充分统计量**，若在给定 $T(\mathbf{X}) = t$ 的条件下，样本 $\mathbf{X}$ 的**条件概率分布与未知参数 $\theta$ 无关**：
$$P(\mathbf{X} = \mathbf{x} \mid T(\mathbf{X}) = t) \text{ 不依赖于 } \theta \quad (\forall \theta \in \Theta)$$
- **直觉本质**：一旦你知道了 $T(\mathbf{X})$ 的值，原始样本数据中剩余的所有随机波动，纯粹是已知的背景噪声，不再包含任何关于 $\theta$ 的新信息。

---

## 2. 奈曼-费雪因子分解定理（Neyman-Fisher Factorization Theorem）

### 定理陈述
统计量 $T(\mathbf{X})$ 是参数 $\theta$ 的充分统计量，**当且仅当**样本的联合密度（似然函数）可以分解为两个非负函数的乘积形式：
$$f(\mathbf{x}; \theta) = g(T(\mathbf{x}), \theta) \cdot h(\mathbf{x})$$
其中：
1. $g(T(\mathbf{x}), \theta)$ 仅通过 $T(\mathbf{x})$ 依赖于数据 $\mathbf{x}$，且依赖于参数 $\theta$；
2. $h(\mathbf{x})$ 完全与未知参数 $\theta$ 无关。

---

## 3. 经典案例因子分解示范

### 案例 1：泊松分布 $\text{Poisson}(\lambda)$
设 $X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \text{Poisson}(\lambda)$。
联合似然函数：
$$f(\mathbf{x}; \lambda) = \prod_{i=1}^n \frac{\lambda^{x_i} e^{-\lambda}}{x_i!} = \frac{\lambda^{\sum x_i} e^{-n\lambda}}{\prod x_i!} = \underbrace{\left(\lambda^{\sum_{i=1}^n x_i} e^{-n\lambda}\right)}_{g(T(\mathbf{x}), \lambda)} \cdot \underbrace{\left(\frac{1}{\prod_{i=1}^n x_i!}\right)}_{h(\mathbf{x})}$$
- 令 $T(\mathbf{X}) = \sum_{i=1}^n X_i$，由因子分解定理，$T(\mathbf{X}) = \sum_{i=1}^n X_i$ 是 $\lambda$ 的**充分统计量**。

### 案例 2：双参数正态分布 $\mathcal{N}(\mu, \sigma^2)$
设 $X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \mathcal{N}(\mu, \sigma^2)$，参数 $\theta = (\mu, \sigma^2)$。
联合似然函数：
$$f(\mathbf{x}; \mu, \sigma^2) = \left(\frac{1}{\sqrt{2\pi}\sigma}\right)^n \exp\left(-\frac{1}{2\sigma^2}\sum_{i=1}^n (x_i - \mu)^2\right) = (2\pi\sigma^2)^{-n/2} \exp\left(-\frac{\sum x_i^2 - 2\mu \sum x_i + n\mu^2}{2\sigma^2}\right)$$
分解为：
$$g(T(\mathbf{x}), \theta) = (2\pi\sigma^2)^{-n/2} \exp\left(-\frac{T_2 - 2\mu T_1 + n\mu^2}{2\sigma^2}\right), \qquad h(\mathbf{x}) = 1$$
- 二维统计量 $T(\mathbf{X}) = \left(\sum_{i=1}^n X_i, \; \sum_{i=1}^n X_i^2\right)$ 是 $(\mu, \sigma^2)$ 的**联合充分统计量**（等价于 $(\bar{X}, S^2)$）。

### 案例 3：支撑集依赖参数——均匀分布 $U(0, \theta)$
设 $X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} U(0, \theta)$。
利用示性函数 $I(\cdot)$ 表达联合密度：
$$f(\mathbf{x}; \theta) = \prod_{i=1}^n \left(\frac{1}{\theta} I(0 \le x_i \le \theta)\right) = \frac{1}{\theta^n} I\left(\max_{1\le i\le n} x_i \le \theta\right) \cdot I\left(\min_{1\le i\le n} x_i \ge 0\right)$$
- 令 $T(\mathbf{X}) = X_{(n)} = \max(X_1, \dots, X_n)$，则 $g(T(\mathbf{x}), \theta) = \frac{1}{\theta^n} I(T(\mathbf{x}) \le \theta)$，$h(\mathbf{x}) = I(\min x_i \ge 0)$。
- **结论**：最大次序统计量 $X_{(n)}$ 是 $\theta$ 的充分统计量。

---

## 4. 指数分布族（Exponential Family）

若概率密度可写为标准指数形式：
$$f(x; \boldsymbol{\theta}) = \exp\left(\sum_{j=1}^k \eta_j(\boldsymbol{\theta}) T_j(x) - A(\boldsymbol{\theta}) + B(x)\right)$$
则对容量为 $n$ 的样本，$\left(\sum_{i=1}^n T_1(X_i), \dots, \sum_{i=1}^n T_k(X_i)\right)$ **恒为参数 $\boldsymbol{\theta}$ 的充分统计量**。正态、二项、泊松、Gamma 分布均属指数族。
