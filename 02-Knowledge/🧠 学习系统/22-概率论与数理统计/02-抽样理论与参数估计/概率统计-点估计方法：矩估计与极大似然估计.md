# 概率统计-点估计方法：矩估计与极大似然估计

---

## 1. 矩估计法（Method of Moments, MME）

### 1. 核心原理（大数定律代换）
由辛钦大数定律，样本原点矩 $A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$ 依概率收敛于总体原点矩 $\alpha_k(\theta) = E[X^k]$。
若总体包含 $k$ 个未知参数 $\theta_1, \dots, \theta_k$，令样本矩等于总体理论矩：
$$\begin{cases} \alpha_1(\theta_1, \dots, \theta_k) = \frac{1}{n}\sum_{i=1}^n X_i \\ \alpha_2(\theta_1, \dots, \theta_k) = \frac{1}{n}\sum_{i=1}^n X_i^2 \\ \vdots \\ \alpha_k(\theta_1, \dots, \theta_k) = \frac{1}{n}\sum_{i=1}^n X_i^k \end{cases}$$
反解该方程组所得的解 $\hat{\theta}_{\text{MME}}$ 即为**矩估计量**。

---

## 2. 极大似然估计法（Maximum Likelihood Estimation, MLE）

### 1. 核心思想（高斯-费雪似然原则）
“在已经观察到样本 $\mathbf{x} = (x_1, \dots, x_n)$ 的前提下，什么样的未知参数 $\theta$ 能使这个样本出现的联合概率（似然度）最大？”

### 2. 似然函数与对数似然函数
- **似然函数（Likelihood Function）**：
  $$L(\theta; \mathbf{x}) = \prod_{i=1}^n f(x_i; \theta)$$
- **对数似然函数（Log-Likelihood Function）**（将连乘转化为求和）：
  $$\ell(\theta; \mathbf{x}) = \ln L(\theta; \mathbf{x}) = \sum_{i=1}^n \ln f(x_i; \theta)$$

**MLE 定义**：
$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta \in \Theta} L(\theta; \mathbf{x}) = \arg\max_{\theta \in \Theta} \ell(\theta; \mathbf{x})$$

### 3. 微分法求解似然方程
若 $\ell(\theta)$ 可微且极值在参数空间内部取得，求解一阶导数置零方程（Score Function）：
$$\frac{\partial \ell(\theta)}{\partial \theta} = 0 \quad (\text{多参数为 } \nabla_\theta \ell(\boldsymbol{\theta}) = \mathbf{0})$$
并检查二阶导数（Hessian 矩阵）负定性：$\frac{\partial^2 \ell(\theta)}{\partial \theta^2} < 0$。

### 4. MLE 的不变性原理（Functional Invariance）
若 $\hat{\theta}$ 是 $\theta$ 的 MLE，且 $g(\theta)$ 为单调或一一对应函数，则 $g(\theta)$ 的 MLE **直接为 $g(\hat{\theta})$**。

---

## 3. 经典求解示范

### 案例 1：正态总体 $\mathcal{N}(\mu, \sigma^2)$ 的 MLE 求解
设 $X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \mathcal{N}(\mu, \sigma^2)$，未知参数 $\boldsymbol{\theta} = (\mu, \sigma^2)$。
1. 对数似然函数：
   $$\ell(\mu, \sigma^2) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i - \mu)^2$$
2. 求偏导：
   $$\begin{cases} \frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum_{i=1}^n (x_i - \mu) = 0 \implies \sum x_i - n\mu = 0 \\ \frac{\partial \ell}{\partial (\sigma^2)} = -\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2}\sum_{i=1}^n (x_i - \mu)^2 = 0 \end{cases}$$
3. 联立解得：
   $$\hat{\mu}_{\text{MLE}} = \bar{X} = \frac{1}{n}\sum_{i=1}^n X_i, \qquad \hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$$
   - *注意*：正态方差的 MLE 是除以 $n$（有偏估计），而样本无偏方差 $S^2$ 是除以 $n-1$。

### 案例 2：不可导边界极值——均匀分布 $U(0, \theta)$
似然函数 $L(\theta) = \frac{1}{\theta^n} I(\theta \ge X_{(n)})$。
- 当 $\theta < X_{(n)}$ 时，$L(\theta) = 0$；
- 当 $\theta \ge X_{(n)}$ 时，$L(\theta) = \frac{1}{\theta^n}$ 是关于 $\theta$ 的**单调递减函数**。
- 因此最大值在边界点 $\theta = X_{(n)}$ 处取得：
  $$\hat{\theta}_{\text{MLE}} = X_{(n)} = \max(X_1, \dots, X_n)$$
  （而矩估计解为 $\hat{\theta}_{\text{MME}} = 2\bar{X}$）。

## 4. Python 数值求解双参数 Gamma 分布 MLE

```python
import numpy as np
from scipy.optimize import minimize
from scipy.special import gamma, gammaln

np.random.seed(42)
true_alpha, true_beta = 3.0, 2.0
data = np.random.gamma(shape=true_alpha, scale=1/true_beta, size=500)

# 负对数似然函数
def neg_log_likelihood(params, data):
    alpha, beta = params
    if alpha <= 0 or beta <= 0:
        return 1e10
    n = len(data)
    # log f(x) = alpha*log(beta) - log_gamma(alpha) + (alpha-1)*log(x) - beta*x
    ll = n * (alpha * np.log(beta) - gammaln(alpha)) + (alpha - 1) * np.sum(np.log(data)) - beta * np.sum(data)
    return -ll

# 数值优化求解
res = minimize(neg_log_likelihood, [1.0, 1.0], args=(data,), method='L-BFGS-B', bounds=[(1e-3, None), (1e-3, None)])
hat_alpha, hat_beta = res.x

print(f"真实参数: alpha={true_alpha}, beta={true_beta}")
print(f"数值 MLE 估计值: alpha={hat_alpha:.4f}, beta={hat_beta:.4f}")
assert abs(hat_alpha - true_alpha) < 0.3 and abs(hat_beta - true_beta) < 0.3, "MLE 估计值偏差过大！"
```
