# 概率统计-前置-线性代数与二次型基础

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 当从一维随机变量推广到 $p$ 维随机向量 $\mathbf{X} = (X_1, \dots, X_p)^T$ 时，方差变成了一个 $p \times p$ 的矩阵 $\mathbf{\Sigma}$。我们需要表达变量之间的散布程度、几何旋转（主成分）以及距离度量（马氏距离 Mahalanobis Distance）。如果不借助于矩阵正定性与二次型，就无法写出多元正态分布的概率密度公式：
> $$f(\mathbf{x}) = \frac{1}{(2\pi)^{p/2} |\mathbf{\Sigma}|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu})\right)$$

---

## 2. 核心数学定义与定理

### 1. 对称正定矩阵（Positive Definite Matrix）

设 $\mathbf{A} \in \mathbb{R}^{p \times p}$ 为实对称矩阵（$\mathbf{A} = \mathbf{A}^T$）：
- **半正定（Positive Semi-Definite, PSD）**：对任意非零向量 $\mathbf{x} \in \mathbb{R}^p$，均有二次型 $\mathbf{x}^T \mathbf{A} \mathbf{x} \ge 0$，记作 $\mathbf{A} \succeq 0$。
- **严格正定（Positive Definite, PD）**：对任意非零向量 $\mathbf{x} \ne \mathbf{0}$，均有 $\mathbf{x}^T \mathbf{A} \mathbf{x} > 0$，记作 $\mathbf{A} \succ 0$。

**充要条件（等价判别）**：
1. $\mathbf{A}$ 的所有特征值 $\lambda_i > 0$（半正定为 $\lambda_i \ge 0$）；
2. $\mathbf{A}$ 的所有顺序主子式全大于 0；
3. 存在可逆矩阵 $\mathbf{P}$ 使得 $\mathbf{A} = \mathbf{P}^T \mathbf{P}$（Cholesky 分解）。

### 2. 谱定理（Spectral Decomposition / 对称矩阵对角化）

对任意实对称矩阵 $\mathbf{\Sigma}$，存在正交矩阵 $\mathbf{Q}$（$\mathbf{Q}^T \mathbf{Q} = \mathbf{I}$）使得：
$$\mathbf{\Sigma} = \mathbf{Q} \mathbf{\Lambda} \mathbf{Q}^T = \sum_{i=1}^p \lambda_i \mathbf{q}_i \mathbf{q}_i^T$$
其中 $\mathbf{\Lambda} = \text{diag}(\lambda_1, \dots, \lambda_p)$，$\mathbf{q}_i$ 为对应的标准正交特征向量。

**矩阵平方根**：若 $\mathbf{\Sigma} \succeq 0$，定义 $\mathbf{\Sigma}^{1/2} = \mathbf{Q} \mathbf{\Lambda}^{1/2} \mathbf{Q}^T$。

### 3. 幂等矩阵与正交投影矩阵（Projection Matrix）

若对称矩阵 $\mathbf{P}$ 满足：
$$\mathbf{P}^2 = \mathbf{P}, \quad \mathbf{P}^T = \mathbf{P}$$
则称 $\mathbf{P}$ 为**正交投影矩阵（Orthogonal Projection Matrix）**。
- **性质 1**：$\mathbf{P}$ 的特征值只能为 0 或 1；
- **性质 2**：$\text{rank}(\mathbf{P}) = \text{tr}(\mathbf{P})$（秩等于迹）；
- **统计意义**：在普通最小二乘法中，帽子矩阵（Hat Matrix）$\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T$ 与残差产生矩阵 $\mathbf{M} = \mathbf{I} - \mathbf{H}$ 均为对称幂等矩阵。残差平方和 $SSE = \mathbf{y}^T \mathbf{M} \mathbf{y}$，其自由度即为 $\text{tr}(\mathbf{M}) = n - p$。

## 3. 几何图像与马氏距离

```
一维标准距离: (x - μ)^2 / σ^2
高维欧氏距离: ||x - μ||^2 = (x - μ)^T I (x - μ)  (等高线为同心圆/球)
马氏距离:     (x - μ)^T Σ^(-1) (x - μ)            (等高线为主轴沿特征向量拉伸的超椭球面)
```
- **协方差矩阵 $\mathbf{\Sigma}$ 的几何角色**：$\mathbf{\Sigma}$ 编码了多维数据在各个正交方向上的方差伸缩（特征值 $\lambda_i$）与旋转主轴（特征向量 $\mathbf{q}_i$）。

## 4. Python 验证

```python
import numpy as np

# 1. 构造一个随机数据矩阵并计算样本协方差矩阵
np.random.seed(42)
X = np.random.randn(100, 3)
Sigma = np.cov(X, rowvar=False)

# 2. 特征值分解验证正定性
eigenvals, eigenvecs = np.linalg.eigh(Sigma)
print("Eigenvalues of Covariance Matrix:", eigenvals)
assert np.all(eigenvals > 0), "协方差矩阵特征值必须全部严格为正！"

# 3. 验证投影矩阵幂等性 (Hat Matrix)
H = X @ np.linalg.inv(X.T @ X) @ X.T
print("Is H idempotent? (H @ H == H):", np.allclose(H @ H, H))
print("Rank/Trace of H:", np.trace(H)) # 必须为 3 (变量数)
```
