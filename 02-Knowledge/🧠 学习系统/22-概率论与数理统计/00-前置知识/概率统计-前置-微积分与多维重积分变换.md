# 概率统计-前置-微积分与多维重积分变换

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 当已知二维连续随机向量 $(X, Y)$ 的联合概率密度函数 $f_{X,Y}(x,y)$，我们需要求解其非线性变换 $(U, V) = (g_1(X,Y), g_2(X,Y))$ 的联合概率密度 $f_{U,V}(u,v)$ 时，无法直接像离散型变量一样直接求和。必须借由积分微分微元映射定理，引入多维空间的体积畸变系数——**雅可比行列式（Jacobian Determinant）**。此外，处理连续分布（如卡方分布、指数分布、F分布）的归一化时，必须用到 Gamma 与 Beta 反常积分。

---

## 2. 核心数学定义与公式

### 1. 多维变量换元与雅可比行列式（Jacobian）

设变换 $u = g_1(x, y), v = g_2(x, y)$ 为 $\mathbb{R}^2 \to \mathbb{R}^2$ 的一一对应连续可微映射，其反变换为 $x = h_1(u, v), y = h_2(u, v)$。
定义变换的**雅可比矩阵与雅可比行列式**：
$$J = \frac{\partial(x, y)}{\partial(u, v)} = \det \begin{pmatrix} \frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ \frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} \end{pmatrix} = \frac{\partial x}{\partial u}\frac{\partial y}{\partial v} - \frac{\partial x}{\partial v}\frac{\partial y}{\partial u}$$

微元面积关系为：
$$dx dy = |J| du dv$$

联合概率密度变换公式：
$$f_{U,V}(u,v) = f_{X,Y}\big(h_1(u,v), h_2(u,v)\big) \cdot |J|$$

### 2. Gamma 函数（欧拉第二类积分）

定义为反常积分：
$$\Gamma(\alpha) = \int_0^\infty t^{\alpha-1} e^{-t} dt \quad (\alpha > 0)$$

**核心性质**：
1. **递推关系**：$\Gamma(\alpha+1) = \alpha \Gamma(\alpha)$
   - *推导*：分部积分 $\int_0^\infty t^\alpha e^{-t} dt = \left[-t^\alpha e^{-t}\right]_0^\infty + \alpha \int_0^\infty t^{\alpha-1} e^{-t} dt = \alpha \Gamma(\alpha)$。
2. **正整数阶乘**：当 $n \in \mathbb{N}^+$ 时，$\Gamma(n) = (n-1)!$；$\Gamma(1) = 1$。
3. **半整数特殊值**：$\Gamma(1/2) = \sqrt{\pi}$。
   - *推导*：令 $t = u^2/2$，则 $\Gamma(1/2) = \int_0^\infty t^{-1/2} e^{-t} dt = \sqrt{2} \int_0^\infty e^{-u^2/2} du = \sqrt{2} \cdot \frac{\sqrt{2\pi}}{2} = \sqrt{\pi}$。

### 3. Beta 函数（欧拉第一类积分）

定义为：
$$B(a, b) = \int_0^1 x^{a-1} (1-x)^{b-1} dx \quad (a > 0, b > 0)$$

**与 Gamma 函数的关系**：
$$B(a, b) = \frac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}$$

## 3. 直觉与几何图像

```
[原始空间 (x,y)]                  [变换后空间 (u,v)]
  +-------+                        /       /
  | dxdy  |    --- 映射 g --->    / |J|dudv/
  +-------+                      /       /
(面积微元 dx dy)             (微元拉伸变形为平行四边形，面积 = |J| du dv)
```
- **雅可比行列式 $|J|$ 的本质**：高维微积分中的局部体积缩放因子。概率质量 $\mathbb{P}((X,Y) \in dA) = f_{X,Y}(x,y) dx dy$ 在坐标变换下守恒，因此必须乘以拉伸因子 $|J|$。

## 4. 经典例题与推导

### 例题：两独立标准正态变量平方和的分布推导
设 $X, Y \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0, 1)$，其联合密度为 $f(x,y) = \frac{1}{2\pi} e^{-\frac{x^2+y^2}{2}}$。
令极坐标变换 $X = R\cos\Theta, Y = R\sin\Theta$ ($R > 0, \Theta \in [0, 2\pi)$)。
1. 计算雅可比行列式：
   $$J = \det \begin{pmatrix} \cos\theta & -r\sin\theta \\ \sin\theta & r\cos\theta \end{pmatrix} = r(\cos^2\theta + \sin^2\theta) = r$$
2. 联合密度为：
   $$f_{R, \Theta}(r, \theta) = \frac{1}{2\pi} e^{-r^2/2} \cdot r = \left(r e^{-r^2/2}\right) \cdot \left(\frac{1}{2\pi}\right) \quad (r>0, \theta \in [0, 2\pi))$$
3. $R$ 与 $\Theta$ 相互独立，$\Theta \sim U(0, 2\pi)$，$R$ 服从瑞利分布（Rayleigh）。令 $Z = R^2 = X^2 + Y^2$，则 $Z \sim \text{Exp}(1/2) \equiv \chi^2(2)$（自由度为 2 的卡方分布）。

## 5. 易错点与反例

> [!CAUTION]
> **常见错误 1：忘记对雅可比行列式取绝对值**
> 若变换导致坐标系手性反转（如 $u = -x, v = y$），$\det(J) = -1$。概率密度恒非负，必须乘以 $|J| = |-1| = 1$。
> 
> **常见错误 2：积分限未随变量代换改变**
> 在计算多元变量的边缘分布时，必须严格画出积分区域 $D_{(u,v)}$，切忌直接套用 $(-\infty, \infty)$。

## 6. Python 验证与数值计算

```python
import numpy as np
import scipy.integrate as integrate
from scipy.special import gamma, beta

# 1. 验证 Gamma(1/2) == sqrt(pi)
print(f"Gamma(0.5): {gamma(0.5):.6f}, sqrt(pi): {np.sqrt(np.pi):.6f}")

# 2. 验证 Beta(2, 3) == Gamma(2)*Gamma(3)/Gamma(5) = 1!*2!/4! = 2/24 = 1/12
b_val, _ = integrate.quad(lambda x: x**(2-1) * (1-x)**(3-1), 0, 1)
print(f"Beta integral: {b_val:.6f}, Formula value: {1/12:.6f}")

# 3. 验证二维极坐标变换面积不变性
quad_val, _ = integrate.dblquad(lambda y, x: np.exp(-(x**2 + y**2)/2), -np.inf, np.inf, -np.inf, np.inf)
print(f"2D Gaussian Integral: {quad_val:.6f} (Expected 2*pi = {2*np.pi:.6f})")
```
