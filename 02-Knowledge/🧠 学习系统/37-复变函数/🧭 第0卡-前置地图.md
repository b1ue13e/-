# 🧭 第 0 卡：前置地图

> **学这门课之前，先确认自己有没有这些装备。** 每一项都标了「已有/待建」：
> - 已有 = 知识库中存在对应笔记，点链接即可复习；
> - 待建 = 知识库还没有专门笔记，先补对应数学基础再学本卡（否则会卡）。

## 二、学习顺序（14 卡推荐路径）

```
卡1 复数运算 ─→ 卡2 CR方程 ─→ 卡3 初等函数
                    │              │
                    └──→ 卡4 复积分 ─→ 卡5 Cauchy积分公式 ─→ 卡6 泰勒/洛朗级数
                                                              │
                                                    卡7 奇点与留数 ─→ 卡8 留数算积分
                                                              │
                                    ┌─────────────────────────┘
                            卡9 辐角原理 ─→ 卡13 最大模原理
                                    │
                            卡10 保角映射 ─→ 卡11 调和函数 ─→ 卡12 解析延拓
                                    └────────→ 卡14 域着色画廊（Capstone）
```

## 三、给小白的三条建议

1. **卡 1-3 是地基**：复数运算不熟，后面每张卡都会卡。至少手算 20 道复数题再前进。
2. **卡 4-6 是主线**：Cauchy 积分公式是整门课的"心脏"，证明重建必须独立完成（对照第 10 节闭卷验收）。
3. **卡 7-8 是工具**：留数计算实积分是应用高潮，把 5 道分级习题全部独立做完再进 Capstone。
