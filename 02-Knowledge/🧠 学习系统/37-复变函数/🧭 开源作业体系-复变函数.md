# 🧭 开源作业体系-复变函数

> 本页是「复变函数」开源名校课程与作业的**唯一挂载点**：教材主线、作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**[Complex Analysis: A Visual and Interactive Introduction](https://complex-analysis.com/)（开放教材，许可以官方页面为准）** + **MIT 18.04 Complex Variables with Applications（OCW Spring 2018，验收口径）**。

---

## 📚 教材主线（Spine）

| 角色 | 来源 | 用途 |
|:---|:---|:---|
| 主教材 | [Complex Analysis: A Visual and Interactive Introduction](https://complex-analysis.com/) | 解析函数、围道积分、留数与共形映射；视觉化主线；许可以官方来源为准 |
| 验收源 | [MIT 18.04](https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-spring-2018/) | 习题、项目与验收口径；`link-only` |
| 补充 | [Howell 开放教材 Complex Analysis](https://textbooks.aimath.org/textbooks/approved-textbooks/howell/) | 习题主线补充（AIM 开放教材清单收录） |
| 前置 | 28-数学分析（或多元微积分）+ 09-高等代数 | ε-δ 语言、线积分与 Jacobian |

**Honor Code 说明**：主教材在线阅读并署名，许可条款以官方页面为准，不随意再分发；MIT 18.04 作业只编目不复制答案；域着色画廊等可视化产物放本课程项目目录。

---

## 🎯 作业体系（HW01-HW05）

| HW | 主题 | 官方来源（口径） | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 复数几何与解析函数 | 主教材 + 18.04 | 已有深卡链（第一阶段） | 手算 C-R 方程判别 + 域着色图 |
| HW02 | 围道积分与柯西定理 | 主教材 + 18.04 | 待补卡（柯西积分定理/公式） | 手算围道积分 + 数值参数化验证 |
| HW03 | 留数定理与实积分计算 | 主教材 + 18.04 | 待补卡（洛朗展开、留数） | 留数计算 + 实积分对照（数值积分） |
| HW04 | 共形映射与应用 | 主教材 + 18.04 | 待补卡（分式线性变换、共形性） | 网格映射可视化 |
| HW05 | Capstone：解析性、留数与域着色验证 | 18.04 口径 + 本地 Capstone | 全链 | 完整报告 + 画廊产出 |

> 分层验收原则：HW01-02 建立解析语言与柯西理论；HW03 是计算主线（留数）；HW04-05 用可视化与 Capstone 收口。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷手算（如留数计算、C-R 方程）；② Python 可视化/数值验证（域着色或围道积分数值化）；③ 1 页报告（方法边界 + 失败案例）。
2. **可视化要求**：HW01/HW04 必须产出可复现的域着色/网格映射图（脚本含随机种子与输出路径）。
3. **数据来源**：手构造函数族 + 主教材示例函数。
4. **满分 Rubric**：HW01-05 各 20 分，共 100 分（手算/证明 40 + 可视化实现 30 + 报告 30）。
