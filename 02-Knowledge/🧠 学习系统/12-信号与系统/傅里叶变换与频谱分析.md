# 傅里叶变换与频谱分析 (Fourier Transform and Spectrum Analysis)

## 1. 傅里叶变换与频谱分析的定义与物理直觉

**傅里叶变换与频谱分析 (Fourier Transform and Spectrum Analysis)** 的核心定义是：一种将连续或离散时间信号解构成不同频率正弦/复指数基函数 $\exp(j \omega t)$ 的线性正交投影运算，用于揭示信号在频域中的幅度谱与相位谱分布。由 Joseph Fourier 于 1807 年在热传导研究中提出。

**基本性质与物理直觉**：
1. **正交基投影**：复指数信号族 $e^{j \omega t}$ 是线性时不变 (LTI) 系统的**特征函数 (Eigenfunctions)**；
2. **频域对称性**：实信号的傅里叶变换频谱满足共轭对称性 $X(-\omega) = X^*(\omega)$，幅度谱为偶函数，相位谱为奇函数；
3. **帕塞瓦尔定理 (Parseval's Theorem)**：信号在时域的总能量与其在频域的能量在积分意义下完全守恒：$\int |x(t)|^2 dt = \frac{1}{2\pi} \int |X(\omega)|^2 d\omega$。

## 2. 连续时间傅里叶变换 (CTFT) 形式化推导与卷积定理

**信号假设**：
设连续时间信号 $x(t)$ 满足 Dirichlet 绝对可积条件 $\int_{-\infty}^{\infty} |x(t)| dt < \infty$。

**推导过程（从傅里叶级数 FS 到傅里叶变换 FT）**：
1. 对于周期为 $T_0$ 的周期信号，频域基频 $\omega_0 = \frac{2\pi}{T_0}$。当周期 $T_0 \to \infty$ 时，离散谱线间隔 $\Delta \omega = \omega_0 \to 0$，求和演变为连续积分；
2. **正变换 (Analysis Equation)**：
$$X(\omega) = \mathcal{F}\{x(t)\} = \int_{-\infty}^{\infty} x(t) e^{-j \omega t} dt$$
3. **逆变换 (Synthesis Equation)**：
$$x(t) = \mathcal{F}^{-1}\{X(\omega)\} = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(\omega) e^{j \omega t} d\omega$$
4. **频域卷积定理 (Convolution Theorem) 证明**：时域卷积 $y(t) = x(t) * h(t)$ 的 FT 表达式：
$$Y(\omega) = \int_{-\infty}^{\infty} \left[ \int_{-\infty}^{\infty} x(\tau) h(t-\tau) d\tau \right] e^{-j \omega t} dt$$
交换积分顺序，设 $u = t - \tau$ 得：
$$Y(\omega) = \int_{-\infty}^{\infty} x(\tau) e^{-j \omega \tau} \left[ \int_{-\infty}^{\infty} h(u) e^{-j \omega u} du \right] d\tau = X(\omega) \cdot H(\omega)$$
5. **因此**，时域复杂的微积分/卷积运算在频域退化为简单的标量乘法，大幅简化了 LTI 系统的分析。

## 3. 傅里叶变换 (FT) 与 拉普拉斯变换 (LT) 对比

| 维度 | 连续时间傅里叶变换 (CTFT) | 拉普拉斯变换 (Laplace Transform) |
|:---|:---|:---|
| **算子定义** | $X(\omega) = \int x(t) e^{-j \omega t} dt$ | $X(s) = \int x(t) e^{-s t} dt \quad (s = \sigma + j\omega)$ |
| **收敛域 (ROC)** | 仅限制于虚轴 $s = j\omega$ | **包含收敛带 $\sigma_{\min} < \text{Re}(s) < \sigma_{\max}$** |
| **信号适用范围** | 必须绝对可积 / 满足 Dirichlet 条件 | 适用于呈指数增长的不稳定信号 ($e^{a t}$) |
| **物理含义** | **稳定信号的真实物理频谱** | 系统复频域极点/零点分析与稳定性判定 |

**局限（误区与反例）**：阶跃信号 $u(t)$ 在朴素 FT 意义下不可积，必须借助冲激函数 $\delta(\omega)$ 扩展；在非平稳信号中，傅里叶变换缺失时间局部化信息，须采用短时傅里叶变换 (STFT) 或小波变换。

## 4. Python 手写数值 FT 幅度谱与 Parseval 能量守恒自测断言

```python
import numpy as np

def ctft_numerical(x: np.ndarray, t: np.ndarray, omega: np.ndarray) -> np.ndarray:
    """数值梯形积分仿真连续时间傅里叶变换"""
    dt = t[1] - t[0]
    kernel = np.exp(-1j * np.outer(omega, t))
    return (kernel @ x) * dt

if __name__ == "__main__":
    t = np.linspace(-5, 5, 2000)
    dt = t[1] - t[0]
    x = np.where(np.abs(t) <= 1.0, 1.0, 0.0)
    omega = np.linspace(-20, 20, 400)

    X_num = ctft_numerical(x, t, omega)

    # 1. 验证 \omega = 0 处 X(0) = integral x(t) dt == 2.0
    idx_zero = np.argmin(np.abs(omega))
    assert abs(np.real(X_num[idx_zero]) - 2.0) < 1e-3

    # 2. 验证 Parseval 能量守恒定律
    energy_time = np.sum(x**2) * dt
    d_omega = omega[1] - omega[0]
    energy_freq = (1.0 / (2 * np.pi)) * np.sum(np.abs(X_num)**2) * d_omega
    assert abs(energy_time - energy_freq) < 0.1

    print(f"傅里叶变换与频谱分析 数值积分 X(0) = {np.real(X_num[idx_zero]):.4f}")
    print(f"Parseval 能量守恒: 时域能量 = {energy_time:.4f}, 频域积分能量 = {energy_freq:.4f}")
    print("傅里叶变换与频谱分析 单元测试与自查验证全部成功！")
```
