# 拉普拉斯变换 (Laplace Transform)

## 1. 拉普拉斯变换的定义与收敛域 (ROC)

**拉普拉斯变换 (Laplace Transform)** 的核心定义是：将时域连续信号投影至复频域 $s = \sigma + j\omega$ 的积分变换算子。拉普拉斯变换由 Pierre-Simon Laplace 于 1785 年提出。

**基本性质与收敛域 (Region of Convergence, ROC)**：
1. **收敛域 ROC 判定**：使得拉普拉斯变换积分绝对可积 $\int_{-\infty}^{\infty} |x(t) e^{-\sigma t}| dt < \infty$ 的复数 $s$ 的平面区域；
2. **因果性与稳定性**：
   - **因果系统**：传递函数 $H(s)$ 的 ROC 为最右侧极点右半平面 $\text{Re}(s) > \sigma_{\max}$；
   - **BIBO 稳定系统**：$H(s)$ 的收敛域 ROC **必须包含虚轴 $\text{Re}(s) = 0$**（即傅里叶变换存在）。

## 2. 传递函数 $H(s)$ 与微分方程求解形式化推导

**LTI 系统微分方程假设**：
设系统的输入为 $x(t)$，输出为 $y(t)$，遵循 $n$-阶常系数线性微分方程：
$$\sum_{k=0}^n a_k \frac{d^k y(t)}{dt^k} = \sum_{m=0}^M b_m \frac{d^m x(t)}{dt^m}$$

**推导过程（微分性质与零状态响应）**：
1. 利用单边拉普拉斯变换的微分性质 $\mathcal{L}\left\{ \frac{dx(t)}{dt} \right\} = s X(s) - x(0^-)$；
2. 在零状态条件下（初始状态为 0）：
$$\left( \sum_{k=0}^n a_k s^k \right) Y(s) = \left( \sum_{m=0}^M b_m s^m \right) X(s)$$
3. **传递函数 (Transfer Function) 导出**：
$$H(s) = \frac{Y(s)}{X(s)} = \frac{\sum_{m=0}^M b_m s^m}{\sum_{k=0}^n a_k s^k} = K \frac{\prod_{j=1}^M (s - z_j)}{\prod_{i=1}^n (s - p_i)}$$
其中 $z_j$ 为零点 (Zeros)，$p_i$ 为极点 (Poles)；
4. **部分分式展开与逆变换**：
$$Y(s) = X(s) H(s) = \sum_{i=1}^n \frac{A_i}{s - p_i} \xrightarrow{\mathcal{L}^{-1}} y(t) = \sum_{i=1}^n A_i e^{p_i t} u(t)$$
5. **因此**，系统的冲激响应形态仅由极点 $p_i$ 位置决定——若极点位于左半平面 ($\text{Re}(p_i) < 0$)，衰减指数 $e^{p_i t} \to 0$，系统绝对稳定。

## 3. 拉普拉斯变换 (LT) 与 傅里叶变换 (FT) 及 Z 变换 (ZT) 对比

| 维度 | 拉普拉斯变换 (LT) | 傅里叶变换 (FT) | Z 变换 (ZT) |
|:---|:---|:---|:---|
| **自变量与复平面** | 连续复数 $s = \sigma + j\omega$ | 实频率 $\omega$ ($s$ 的虚轴) | 离散复数 $z = r e^{j\Omega}$ |
| **稳定条件** | 极点全部位于**左半平面 ($\text{Re}(p) < 0$)** | 绝对可积 | 极点全部位于**单位圆内 ($|p| < 1$)** |
| **变换关系** | $H(s)\vert_{s=j\omega} = H(\omega)$ | $H(\omega)$ | $z = e^{s T_s}$ 映射 |
| **主要应用** | 连续电路、控制系统、微分方程 | 频谱分析、滤波 | 数字信号处理 (DSP)、差分方程 |

**局限（误区与反例）**：求逆变换时若忽略收敛域 ROC，相同的表达式 $X(s) = \frac{1}{s+a}$ 可能对应因果信号 $e^{-at} u(t)$ 或反因果信号 $-e^{-at} u(-t)$；不确定 ROC 无法唯一确定时域信号。

## 4. Python 部分分式展开与极点零点稳定性自测断言

```python
import numpy as np
from scipy import signal

def analyze_system_stability(zeros: list, poles: list) -> bool:
    """根据极点位置判定因果 LTI 系统稳定性 (Re(p) < 0)"""
    poles_arr = np.array(poles)
    is_stable = np.all(np.real(poles_arr) < 0)
    return is_stable

if __name__ == "__main__":
    zeros = [-2.0]
    poles = [-1.0, -2.0]

    stable_flag = analyze_system_stability(zeros, poles)
    assert stable_flag == True

    unstable_poles = [0.5, -2.0]
    assert analyze_system_stability(zeros, unstable_poles) == False

    b = [1.0, 2.0]
    a = [1.0, 3.0, 2.0]
    r, p, k = signal.residue(b, a)
    idx_p1 = np.argmin(np.abs(p - (-1.0)))
    assert abs(r[idx_p1] - 1.0) < 1e-5

    print(f"拉普拉斯变换系统极点: {poles}, 稳定性判定: {stable_flag}")
    print(f"部分分式留数 Residue (p=-1): {r[idx_p1]:.4f}")
    print("拉普拉斯变换 单元测试与自查验证全部成功！")
```
