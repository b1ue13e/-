## 一句话定义
> 离散信号是仅定义在整数时刻 n∈ℤ 上的序列 x[n]，通常由连续信号抽样得到。

## 从学习内容上要抓什么
- 自变量 n 取整数；值 x[n] 在量化前仍可连续。
- 能量 $E=\sum_{n}|x[n]|^2$，功率 $P=\lim_{N\to\infty}\frac{1}{2N+1}\sum_{n=-N}^{N}|x[n]|^2$。
- 离散正弦 $\sin(\Omega_0 n)$ 为周期序列 ⇔ $\Omega_0/2\pi$ 为有理数。

## 核心内容
### 1. 基本定义与直觉
离散信号像每秒 44 100 个采样点的数字音频：时间被切成一格一格，每个格子上记录一个数值。它和连续信号的区别在于“时间被点化了”，但每个点上的数值本身未必是整数。

### 2. 公式 / 机制 / 流程
单位采样序列 $\delta[n]=\begin{cases}1,&n=0\\0,&n\ne 0\end{cases}$；能量 $E=\sum_{n=-\infty}^{\infty}|x[n]|^2$；周期条件 $\sin(\Omega_0(n+N))=\sin(\Omega_0 n)$。

### 3. 一个最小例子
例：$x[n]=a^n u[n]$（|a|<1）是能量信号，能量 $E=\sum_{n=0}^{\infty}a^{2n}=1/(1-a^2)$。检查 $\sin(\pi n/4)$ 是否周期：$\Omega_0/2\pi=(1/8)$ 有理 ⇒ 周期 N=8。

### 4. 常见误区
- 以为离散时间信号的值也必须是离散的（量化前仍是实数）。
- 把连续周期判断套到离散上：离散正弦周期要求 $\Omega_0/2\pi$ 有理，否则非周期。

## 可执行示例（Python）

```python
import numpy as np, matplotlib.pyplot as plt
from fractions import Fraction

# 1) 能量信号示例：x[n] = a^n u[n], |a|<1
n = np.arange(0, 21)
a = 0.9
x = a**n                       # 因果指数序列
E = np.sum(x**2)               # 数值能量
print("E =", round(float(E), 4), "  解析 1/(1-a^2) =", round(1/(1-a**2), 4))
plt.stem(n, x); plt.title("x[n]=0.9^n u[n]"); plt.show()

# 2) 离散正弦周期性判定：Omega0/2pi 为有理数则周期
Omega0 = np.pi / 4
frac = Fraction(Omega0/(2*np.pi)).limit_denominator(1000)
print("sin(pi n/4) 是否周期:", frac.denominator != 1, "  N =", 8 if frac.denominator!=1 else None)
```

运行前需 `pip install numpy matplotlib`。输出：$E\approx 5.263$，与解析值 $1/(1-0.9^2)=5.263$ 一致；$\sin(\pi n/4)$ 中 $\Omega_0/2\pi=1/8$ 为有理数 ⇒ 周期 $N=8$。
