# 🧭 开源作业体系-信号与系统

> 本页是「信号与系统」开源名校课程与作业的**唯一挂载点**：教材主线、官方作业链 HW01-HW06、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**Think DSP (Allen Downey)**（https://greenteapress.com/wp/think-dsp/，open textbook）+ **MIT 6.003 Signals and Systems**（https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/，MIT OCW terms）+ **scipy.signal / numpy.fft 实验**。

## 🎯 作业体系（HW01-HW06）

| HW | 主题 | 官方来源（Think DSP / 6.003 章节） | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 信号与 LTI 系统基础 | Think DSP Ch.1-3 + 6.003 Lec 1-3 | 待补卡（连续/离散信号、单位冲激、卷积） | 闭卷手算卷积 + 真实音频信号处理 |
| HW02 | 傅里叶级数 | Think DSP Ch.4-5 + 6.003 Lec 6-9 | 待补卡（FS、复指数表示、Parseval） | 闭卷求方波 FS + 自写 `numpy` 实现 |
| HW03 | 连续傅里叶变换 | Think DSP Ch.6 + 6.003 Lec 10-14 | 待补卡（FT 性质、调制、时频对偶） | 闭卷计算（高斯、矩形脉冲）+ 性质应用 |
| HW04 | 离散傅里叶变换 | Think DSP Ch.7-8 + 6.003 Lec 17-20 | 待补卡（DFT、FFT、频率分辨率） | 自写 FFT + 与 `numpy.fft` 对照 |
| HW05 | 拉普拉斯变换 | 6.003 Lec 15-19 | 待补卡（LT、ROC、零极点、稳定性） | 闭卷 LT 计算 + 零极点稳定性判别 |
| HW06 | Z 变换与数字滤波器 | Think DSP Ch.10-12 + 6.003 Lec 20-25 | 待补卡（ZT、IIR/FIR、Butterworth） | 自写 IIR/FIR 滤波器 + 与 `scipy.signal` 对照 |

> 分层验收原则：HW01-02 是**基础链**（信号 + FS）；HW03-04 是**变换链**（FT → DFT）；HW05-06 是**系统链**（LT → ZT）。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷手算（卷积 / FS / FT / DFT / LT / ZT 公式推导）；② 自写 Python 实现（与 `numpy.fft` / `scipy.signal` 对照）；③ 1 页应用案例（音频/图像/通信）。
2. **音频应用**：HW01-04 至少包含 1 个真实音频信号处理任务。
3. **满分 Rubric**：HW01-06 各 16-17 分，共 100 分（手算 35 + 实现 35 + 应用 30）。
