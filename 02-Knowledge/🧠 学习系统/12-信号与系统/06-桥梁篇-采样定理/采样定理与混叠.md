# 采样定理与混叠 (Nyquist-Shannon Sampling Theorem and Aliasing)

## 1. 采样定理与混叠的定义与核心条件

**采样定理与混叠 (Nyquist-Shannon Sampling Theorem and Aliasing)** 的核心定义是：将连续时间带限信号 $x(t)$ 离散化采样时，采样频率 $f_s$ 与信号最高截止频率 $f_m$ 之间必须满足的临界无损重建约束体系。采样定理与混叠由 Harry Nyquist (1928) 和 Claude Shannon (1949) 提出。

**基本性质与核心条件**：
1. **奈奎斯特采样条件 (Nyquist Criterion)**：采样频率必须满足 $f_s \ge 2 f_m$（或采样周期 $T_s \le \frac{1}{2 f_m}$）；
2. **混叠 (Aliasing) 现象**：若 $f_s < 2 f_m$，频域周期的搬移频谱将发生不可逆重叠，高频成分被错误地假冒（Alias）为低频信号；
3. **理想无损重构**：满足奈奎斯特条件时，可以通过理想低通滤波器 (Sinc 插值) 100% 完美还原原始连续信号。

## 2. 冲激串采样与频谱周期延展形式化推导

**采样数学模型假设**：
设连续信号为 $x(t)$，最高频率为 $\omega_m = 2\pi f_m$。采样冲激串为 $p(t) = \sum_{n=-\infty}^{\infty} \delta(t - n T_s)$。采样后信号 $x_s(t) = x(t) \cdot p(t)$。

**推导过程（频域卷积与频谱搬移）**：
1. 计算冲激串 $p(t)$ 的傅里叶级数系数 $c_k = \frac{1}{T_s}$，其 FT 为：
$$P(\omega) = \frac{2\pi}{T_s} \sum_{k=-\infty}^{\infty} \delta\left(\omega - k \omega_s\right) \quad (\omega_s = \frac{2\pi}{T_s})$$
2. 根据频域卷积定理，采样信号的频谱 $X_s(\omega) = \frac{1}{2\pi} X(\omega) * P(\omega)$：
$$X_s(\omega) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X\left(\omega - k \omega_s\right)$$
3. **防混叠条件推导**：要使第 $k=0$ 主频谱与第 $k=1$ 搬移频谱不重叠，必须要求 $\omega_s - \omega_m \ge \omega_m$：
$$\omega_s \ge 2 \omega_m \iff f_s \ge 2 f_m$$
4. **理想低通滤波 (Sinc 插值) 重建**：通过截止频率为 $\omega_c = \frac{\omega_s}{2}$、增益为 $T_s$ 的理想低通滤波器：
$$x(t) = x_s(t) * \text{sinc}\left(\frac{t}{T_s}\right) = \sum_{n=-\infty}^{\infty} x(n T_s) \text{sinc}\left( \frac{t - n T_s}{T_s} \right)$$
5. **因此**，当 $f_s < 2 f_m$ 时，高频信号在搬移后侵入区间 $[-\frac{f_s}{2}, \frac{f_s}{2}]$，形成不可逆的**频域混叠**。

## 3. 恰采样、过采样与欠采样的全方位对比

| 采样模式 | 采样频率 $f_s$ 与 $f_m$ 关系 | 频域频谱搬移状态 | 时域信号重构结果 | 实际工程应用 |
|:---|:---|:---|:---|:---|
| **恰采样 (Nyquist Rate)** | $f_s = 2 f_m$ | 频谱紧密相切（无缝）| 理论无损（需理想低通滤波器）| 理论临界边界 |
| **过采样 (Oversampling)** | **$f_s \gg 2 f_m$** | 频谱间保留宽广保护带 | **极易滤波重构，降低量化噪声** | 现代 ADC (Sigma-Delta)、CD音频 |
| **欠采样 (Undersampling)**| **$f_s < 2 f_m$** | **频谱严重发生重叠 (混叠)**| **严重失真（高频假冒低频）** | 须加**抗混叠滤波器 (Anti-Aliasing Filter)** |

**局限（误区与反例）**：现实世界中不存在真正的有限带限且有限时域的信号（时频不确定性原理）；因此在 ADC 采样前，必须使用模拟抗混叠低通滤波器强行滤除 $f > \frac{f_s}{2}$ 的高频噪声。

关联知识点推荐：[[傅里叶变换与频谱分析]]、[[拉普拉斯变换]]、快速傅里叶变换(FFT)、二分搜索。

## 4. Python 欠采样混叠现象与 Sinc 插值自测断言

```python
import numpy as np

def simulate_sampling_aliasing(f_signal: float, f_sample: float, duration: float = 1.0) -> float:
    """仿真采样过程，返回采样后在 [-fs/2, fs/2] 区间展现的表观频率"""
    t_discrete = np.arange(0, duration, 1.0 / f_sample)
    x_discrete = np.cos(2 * np.pi * f_signal * t_discrete)

    zero_crossings = np.where(np.diff(np.sign(x_discrete)))[0]
    apparent_freq = len(zero_crossings) / (2.0 * duration)
    return apparent_freq

if __name__ == "__main__":
    f_signal = 70.0
    f_sample = 100.0

    apparent_f = simulate_sampling_aliasing(f_signal, f_sample)
    expected_alias_f = abs(f_signal - f_sample)

    # 1. 欠采样混叠断言
    assert abs(apparent_f - expected_alias_f) < 2.0

    # 2. Nyquist 采样断言
    apparent_correct = simulate_sampling_aliasing(f_signal, f_sample=200.0)
    assert abs(apparent_correct - 70.0) < 2.0

    print(f"采样定理与混叠 验证成功: 70Hz 信号在 100Hz 采样下混叠为 {apparent_f:.1f}Hz (理论 30Hz)")
    print("采样定理与混叠 单元测试与自查验证全部成功！")
```
