## 一句话定义
> 积分限错误：把 ∫_{-∞}^∞ 直接套用而忽略 x(τ)、h(t-τ) 各自的支持区间；正确限是两者重叠的 τ 范围。

## 从学习内容上要抓什么
- 若 x 支持 [a,b]、h 支持 [c,d]，则 h(t-τ) 支持 τ∈[t-d,t-c]。
- 重叠限 = [max(a,t-d), min(b,t-c)]。
- 因果信号常把下限简化为 -∞ 或 0，但上限仍受重叠约束。

## 核心内容
### 1. 基本定义与直觉
积分限像「两把尺子的重叠段」：你只能在两者都非零的地方积分，超出部分乘出来是 0 也白算。

### 2. 公式 / 机制 / 流程
$$\int_{\max(a,\,t-d)}^{\min(b,\,t-c)}x(\tau)h(t-\tau)\,d\tau$$

### 3. 一个最小例子
x=u(t), h=u(t)：重叠限 [0,t]，t<0 时为空 ⇒ y(t)=t·u(t)。

### 4. 常见误区
- 不分情况一律用 (-∞,∞) 导致含 0 的错结果。
- 因果情形漏掉 t<0 时重叠为空（y=0）。
