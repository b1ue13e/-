# 🧭 开源作业体系-属性数据分析

> 本页是「属性数据分析（Categorical Data Analysis）」开源名校课程与作业的**唯一挂载点**：教材主线、官方作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**Penn State STAT 504**（https://online.stat.psu.edu/stat504/，official open course notes）+ **An Introduction to Categorical Data Analysis**（Agresti, 3rd ed., 官方 free PDF per author）+ **R / Python glm** 实验。

---

## 📚 教材主线（Spine）

| 角色 | 来源 | 用途 |
|:---|:---|:---|
| 主教材（讲义） | [Penn State STAT 504](https://online.stat.psu.edu/stat504/) | 列联表、卡方检验、Logistic 回归、Poisson 回归、对数线性模型、对数单位模型；按 HW 主题分段 |
| 教材（书本） | Agresti, *An Introduction to Categorical Data Analysis* (3rd ed.) | 离散响应与列联表权威；每章对应一个 HW |
| 实践/验收源 | R 的 `glm` / `MASS` / `vcd`；Python 的 `statsmodels` | 离散响应回归、对数线性模型、双向/三维列联表 |
| 前置 | 30-应用回归分析 + 16-多元统计 | 线性回归、多元正态、似然推断 |

**Honor Code 说明**：STAT 504 讲义免费可用、可在笔记中引用；作业必须独立完成；R/Python 代码可参考官方文档但禁止直接复制课程解决方案。

## 🎯 作业体系（HW01-HW05）

| HW | 主题 | 官方来源（STAT 504 章节） | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 列联表与概率结构 | STAT 504 Lesson 1-3 | 待补卡（列联表、概率结构、边际/条件独立） | 2×2、2×3、3×3 表的概率与独立性判别 |
| HW02 | 卡方检验与 Fisher 精确检验 | STAT 504 Lesson 4-5 | 待补卡（卡方检验、Fisher 精确） | 多个 2×2 表的卡方 vs Fisher 选型报告 |
| HW03 | 优势比与相对风险 | STAT 504 Lesson 6-7 | 待补卡（OR、RR、95% CI） | 真实医学/社科数据 OR 与 RR 计算 + 解释 |
| HW04 | Logistic 回归（GLM） | STAT 504 Lesson 8-12 | [[属性数据分析 - HW01：Softmax 回归与对数线性模型阶梯作业\|HW01 说明书]] | 二项 Logistic 回归；系数解释为 log-odds；模型拟合优度 |
| HW05 | Poisson 回归与对数线性模型 | STAT 504 Lesson 13-15 | 待补卡（Poisson 回归、对数线性模型） | 计数数据建模；过度离散检验；双向列联表的饱和模型与独立模型对比 |

> 分层验收原则：HW01-03 是**列联表链**（离散推断基本功）；HW04 是**Logistic 主线**（必须完成，与 30-应用回归形成 GLM 闭环）；HW05 是**计数数据收尾**。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷手算（小样本 2×2 表）；② R/Python 复现与扩展；③ 1 页报告（方法选择理由 + 系数解释 + 残差/拟合诊断）。
2. **数据来源**：使用 R 内置数据集（`Arthritis` / `UCBAdmissions` / `HairEyeColor` 等）或公开 UCI 离散数据集。
3. **满分 Rubric**：HW01-03 各 15 分（列联表 45 分）+ HW04 30 分（Logistic 主线）+ HW05 25 分（Poisson / 对数线性），共 100 分。
