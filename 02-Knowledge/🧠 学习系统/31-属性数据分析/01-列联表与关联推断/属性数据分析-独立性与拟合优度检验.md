# 属性数据分析-独立性与拟合优度检验

## 1. 独立性原假设与期望频数

在二维列联表中，$X$ 与 $Y$ **统计独立（Statistical Independence）** 的充要条件是联合概率等于边际概率之积：
$$
H_0: \pi_{ij} = \pi_{i+} \pi_{+j}, \quad \forall i, j
$$

在多项抽样或泊松抽样下，边际概率的 MLE 为 $\hat{\pi}_{i+} = \frac{n_{i+}}{n}$，$\hat{\pi}_{+j} = \frac{n_{+j}}{n}$。
因此，在独立性假设下的**期望频数（Expected Cell Counts）** 为：

$$
\mu_{ij} = n \pi_{ij} \implies \hat{\mu}_{ij} = n \hat{\pi}_{i+} \hat{\pi}_{+j} = \frac{n_{i+} n_{+j}}{n}
$$

---

## 2. 核心检验统计量

### 2.1 Pearson 卡方统计量 ($X^2$)
基于实际观测频数 $n_{ij}$ 与期望频数 $\hat{\mu}_{ij}$ 的相对偏差平方和（本质是 Score 检验）：

$$
X^2 = \sum_{i=1}^I \sum_{j=1}^J \frac{(n_{ij} - \hat{\mu}_{ij})^2}{\hat{\mu}_{ij}} \xrightarrow{d} \chi^2_{(I-1)(J-1)}
$$

自由度推导：无约束参数空间自由度为 $IJ - 1$；在独立假设下，行边际自由度 $I - 1$，列边际自由度 $J - 1$，故：
$$
\text{df} = (IJ - 1) - [(I - 1) + (J - 1)] = (I - 1)(J - 1)
$$

### 2.2 似然比检验统计量 (Deviance, $G^2$)
基于饱和模型（Saturated Model）与独立模型的对数似然差（LRT）：

$$
G^2 = 2 \sum_{i=1}^I \sum_{j=1}^J n_{ij} \ln\left( \frac{n_{ij}}{\hat{\mu}_{ij}} \right) \xrightarrow{d} \chi^2_{(I-1)(J-1)}
$$
注：规定当 $n_{ij} = 0$ 时，$0 \ln(0) \equiv 0$。

### 2.3 $X^2$ 与 $G^2$ 的关系
由 Taylor 展开式 $\ln(1 + x) \approx x - \frac{x^2}{2}$，将 $\frac{n_{ij}}{\hat{\mu}_{ij}} = 1 + \frac{n_{ij} - \hat{\mu}_{ij}}{\hat{\mu}_{ij}}$ 代入 $G^2$ 可得：
$$
G^2 \approx X^2 + O(n^{-1/2})
$$
大样本下两者数值极度接近；当部分单元格较小（$\hat{\mu}_{ij} < 5$）时，两者可能出现分歧，$X^2$ 逼近 $\chi^2$ 的速度通常略快于 $G^2$。

---

## 3. 标准化残差分析（定位关联来源）

当整体卡方检验拒绝 $H_0$ 时，检验本身并未指出具体是哪些单元格产生了显著关联。此时必须计算**标准化 Pearson 残差（Standardized Pearson Residuals）**：

$$
r_{ij} = \frac{n_{ij} - \hat{\mu}_{ij}}{\sqrt{\hat{\mu}_{ij} (1 - p_{i+}) (1 - p_{+j})}} \sim N(0, 1)
$$

其中 $p_{i+} = \frac{n_{i+}}{n}$, $p_{+j} = \frac{n_{+j}}{n}$。
* **判断标准**：当 $|r_{ij}| > 2$ 时，表明该单元格在 $\alpha = 0.05$ 水平上显著偏离独立性；$|r_{ij}| > 3$ 时极为显著。

---

## 4. Fisher 精确检验 (Fisher's Exact Test)

对于 $2 \times 2$ 小样本或稀疏列联表（存在 $\hat{\mu}_{ij} < 5$），大样本卡方分布失效。Fisher 提出了基于固定行、列边际的**超几何分布条件推断**：

$$
P(n_{11} \mid n_{1+}, n_{2+}, n_{+1}, n_{+2}) = \frac{\binom{n_{1+}}{n_{11}} \binom{n_{2+}}{n_{+1} - n_{11}}}{\binom{n}{n_{+1}}}
$$

单侧或双侧 $p$ 值通过将所有不大于实际观测概率的超几何分布概率求和获得，完全不需要任何大样本近似。

## 5. Python 实战代码

```python
import numpy as np
import scipy.stats as stats
import pandas as pd

# 构造 2x2 列联表: 治疗 vs 康复
# [[改善, 无效], [改善, 无效]]
table = np.array([[28, 12],
                  [14, 26]])

# 1. Pearson 卡方与似然比检验
chi2_stat, p_chi2, dof, expected = stats.chi2_contingency(table, correction=False)
g_stat, p_g, _, _ = stats.chi2_contingency(table, lambda_="log-likelihood", correction=False)

# 2. Fisher 精确检验
oddsratio, p_fisher = stats.fisher_exact(table)

# 3. 计算标准化残差
n = np.sum(table)
row_props = np.sum(table, axis=1, keepdims=True) / n
col_props = np.sum(table, axis=0, keepdims=True) / n
std_residuals = (table - expected) / np.sqrt(expected * (1 - row_props) * (1 - col_props))

print(f"Pearson X2: {chi2_stat:.4f} (p={p_chi2:.4e})")
print(f"Deviance G2: {g_stat:.4f} (p={p_g:.4e})")
print(f"Fisher Exact p: {p_fisher:.4e}")
print("标准化残差矩阵:\n", std_residuals)
```
