# 属性数据分析-关联效应量-优势比与相对风险

## 1. 为什么需要关联效应量？

卡方检验（$X^2, G^2$）只能回答变量间“是否存在关联”（检验 $p$ 值），但**无法回答关联的强度（Effect Size）与方向**。样本量极大时，即使微不足道的关联也会产生极小的 $p$ 值。

在 $2 \times 2$ 表中，设两组的成功概率分别为 $\pi_1 = P(Y = 1 \mid X = 1)$ 和 $\pi_2 = P(Y = 1 \mid X = 2)$：

| 指标 | 数学定义 | 取值范围 | 解释含义 |
| :--- | :--- | :---: | :--- |
| **比例差 (Difference of Proportions)** | $d = \pi_1 - \pi_2$ | $[-1, 1]$ | 绝对风险降低/增加量 |
| **相对风险 (Relative Risk, RR)** | $\text{RR} = \frac{\pi_1}{\pi_2}$ | $[0, \infty)$ | 暴露组发病率是非暴露组的多少倍 |
| **优势比 / 比值比 (Odds Ratio, OR)** | $\theta = \frac{\pi_1 / (1 - \pi_1)}{\pi_2 / (1 - \pi_2)}$ | $[0, \infty)$ | 暴露组发生几率是对照组的多少倍 |

---

## 2. 优势比（Odds Ratio）的优良数学性质

### 2.1 交叉乘积比公式 (Cross-Product Ratio)
在 $2 \times 2$ 频数表中：
$$
\hat{\theta} = \frac{(n_{11} / n_{1+}) / (n_{12} / n_{1+})}{(n_{21} / n_{2+}) / (n_{22} / n_{2+})} = \frac{n_{11} n_{22}}{n_{12} n_{21}}
$$

### 2.2 抽样不变性定理（流行病学基石）
* **前瞻性研究（队列研究，按暴露分组抽样，固定行边际）**：估计的是 $\frac{P(D \mid E) / P(\bar{D} \mid E)}{P(D \mid \bar{E}) / P(\bar{D} \mid \bar{E})} = \frac{\pi_{11}\pi_{22}}{\pi_{12}\pi_{21}} = \theta$。
* **回顾性研究（病例对照研究，按患病分组抽样，固定列边际）**：计算暴露的优势比：
  $$
  \theta_{\text{exposure}} = \frac{P(E \mid D) / P(\bar{E} \mid D)}{P(E \mid \bar{D}) / P(\bar{E} \mid \bar{D})} = \frac{(n_{11}/n_{+1}) / (n_{21}/n_{+1})}{(n_{12}/n_{+2}) / (n_{22}/n_{+2})} = \frac{n_{11} n_{22}}{n_{12} n_{21}} = \theta
  $$
> [!IMPORTANT]
> **定理**：疾病与暴露的优势比，在数学上严格等于暴露与疾病的优势比！因此，**病例对照研究无法估计相对风险（RR），但能够无偏估计优势比（OR）**。在罕见病假设下（$\pi \to 0$），$\text{OR} \approx \text{RR}$。

---

## 3. 对数优势比与 Delta 方法置信区间推导

由于 $\hat{\theta} \in [0, \infty)$ 呈强正偏态分布，直接对其构造正态置信区间极不准确。我们对其实施 **Log 变换**：
$$
\ln(\hat{\theta}) = \ln n_{11} - \ln n_{12} - \ln n_{21} + \ln n_{22}
$$

由多项分布渐近理论与 **Delta 方法（Delta Method）**，$\ln(\hat{\theta})$ 的大样本渐近方差为：

$$
\sigma^2(\ln\hat{\theta}) \approx \sum_{i=1}^2 \sum_{j=1}^2 \frac{1}{n_{ij}} = \frac{1}{n_{11}} + \frac{1}{n_{12}} + \frac{1}{n_{21}} + \frac{1}{n_{22}}
$$

因此，$\ln(\theta)$ 的 $95\%$ 大样本 Woolf 置信区间为：
$$
\ln(\hat{\theta}) \pm z_{1-\alpha/2} \cdot \text{SE}(\ln\hat{\theta}) = \ln(\hat{\theta}) \pm 1.96 \sqrt{\frac{1}{n_{11}} + \frac{1}{n_{12}} + \frac{1}{n_{21}} + \frac{1}{n_{22}}}
$$

对其两端取指数指数，即得 **$\theta$ 的 95% 置信区间**：
$$
\left[ \exp\left\{ \ln\hat{\theta} - 1.96 \text{SE}(\ln\hat{\theta}) \right\}, \; \exp\left\{ \ln\hat{\theta} + 1.96 \text{SE}(\ln\hat{\theta}) \right\} \right]
$$

## 4. Python 计算实例

```python
import numpy as np

# 构造 2x2 列联表
# 暴露组: 18 患病, 82 健康 (n1+=100)
# 非暴露组: 6 患病, 94 健康 (n2+=100)
n11, n12 = 18, 82
n21, n22 = 6, 94

# 1. 计算点估计
p1 = n11 / (n11 + n12)
p2 = n21 / (n21 + n22)
rr = p1 / p2
odds1 = p1 / (1 - p1)
odds2 = p2 / (1 - p2)
or_stat = (n11 * n22) / (n12 * n21)

# 2. 计算 ln(OR) 及其标准误
ln_or = np.log(or_stat)
se_ln_or = np.sqrt(1/n11 + 1/n12 + 1/n21 + 1/n22)

# 3. 95% 置信区间
ci_lower = np.exp(ln_or - 1.96 * se_ln_or)
ci_upper = np.exp(ln_or + 1.96 * se_ln_or)

print(f"相对风险 (RR): {rr:.4f}")
print(f"优势比 (OR):   {or_stat:.4f}")
print(f"OR 95% CI:     [{ci_lower:.4f}, {ci_upper:.4f}]")
```
