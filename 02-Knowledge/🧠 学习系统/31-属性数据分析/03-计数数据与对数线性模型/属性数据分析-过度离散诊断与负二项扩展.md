# 属性数据分析-过度离散诊断与负二项扩展

## 1. 泊松等分散假设与过度离散现象

Poisson 分布具有严格的**等分散性（Equidispersion）**：
$$
\mathbb{E}[Y_i] = \text{Var}(Y_i) = \mu_i
$$

在实际真实数据中，由于存在**未观测到的个体异质性（Unobserved Heterogeneity）**、**群体聚集（Clustering）**或**零膨胀（Zero-Inflation）**，常常出现：
$$
\text{Var}(Y_i) > \mathbb{E}[Y_i] \quad \implies \quad \textbf{过度离散 (Overdispersion)}
$$

### 忽略过度离散的严重后果：
1. 均值模型与参数估计值 $\hat{\boldsymbol{\beta}}$ 依然是一致的；
2. **标准误 $\text{SE}(\hat{\boldsymbol{\beta}})$ 会被严重低估（往往被缩小几倍）**；
3. $z$ 统计量虚假偏大，$p$ 值虚假偏小，导致大量的**假阳性显著性结论（Type I Error 膨胀）**。

---

## 2. 过度离散的诊断方法

### 2.1 分散参数（Dispersion Parameter）估计
拟合标准泊松回归后，计算 Pearson 卡方统计量与自由度之比：

$$
\hat{\phi} = \frac{X^2}{n - p} = \frac{1}{n - p} \sum_{i=1}^n \frac{(y_i - \hat{\mu}_i)^2}{\hat{\mu}_i}
$$

* 若 $\hat{\phi} \approx 1$：等分散假设成立；
* 若 $\hat{\phi} > 1.5$ 或 $\gg 1$：存在明显的过度离散。

---

## 3. 解决方案一：准泊松模型 (Quasi-Poisson)

采用 Wedderburn 准似然（Quasi-Likelihood）方法，保留对数链接 $\ln\mu = \mathbf{x}^T \boldsymbol{\beta}$，放宽方差假设：
$$
\text{Var}(Y_i) = \phi \mu_i
$$
* **参数估计**：$\hat{\boldsymbol{\beta}}$ 不变；
* **方差修正**：$\widehat{\text{Var}}(\hat{\boldsymbol{\beta}}) = \hat{\phi} \cdot (X^T W X)^{-1}$，标准误直接乘以 $\sqrt{\hat{\phi}}$ 进行膨胀校正。

---

## 4. 解决方案二：负二项回归 (Negative Binomial Regression)

### 4.1 Gamma 混合泊松分布推导
设在给定未观测随机效应 $\nu_i$ 条件下，$Y_i \mid \nu_i \sim \text{Poisson}(\nu_i \mu_i)$，其中 $\nu_i \sim \text{Gamma}(\alpha^{-1}, \alpha^{-1})$（均值为 1，方差为 $\alpha$）。

对 $\nu_i$ 积分求边际分布，得到**负二项分布（Negative Binomial, $\text{NB2}$）**：

$$
P(Y = y) = \frac{\Gamma(y + \alpha^{-1})}{y! \, \Gamma(\alpha^{-1})} \left( \frac{\alpha^{-1}}{\alpha^{-1} + \mu} \right)^{\alpha^{-1}} \left( \frac{\mu}{\alpha^{-1} + \mu} \right)^y
$$

其均值与方差为：
$$
\mathbb{E}[Y] = \mu, \quad \text{Var}(Y) = \mu + \alpha \mu^2
$$
其中 $\alpha \ge 0$ 称为**分散参数（Dispersion Parameter）**。当 $\alpha \to 0$ 时，负二项分布退化为标准泊松分布。

## 5. Python 建模与模型比较实战

```python
import statsmodels.api as sm
import statsmodels.formula.api as smf
import pandas as pd
import numpy as np

# 模拟过度离散数据 (负二项分布)
np.random.seed(42)
n = 300
x = np.random.normal(size=n)
mu_true = np.exp(1.2 + 0.8 * x)
alpha_true = 0.5  # 分散参数
y = np.random.negative_binomial(n=1/alpha_true, p=1/(1 + alpha_true*mu_true))

df = pd.DataFrame({'x': x, 'y': y})

# 1. 拟合标准 Poisson 回归
model_pois = smf.glm('y ~ x', data=df, family=sm.families.Poisson()).fit()
phi_hat = model_pois.pearson_chi2 / model_pois.df_resid
print(f"Poisson 分散参数估计 phi_hat: {phi_hat:.4f} (严重过度离散!)")
print(f"Poisson x 系数 SE: {model_pois.bse['x']:.4f}")

# 2. 拟合负二项回归 (Negative Binomial)
model_nb = smf.glm('y ~ x', data=df, family=sm.families.NegativeBinomial(alpha=0.5)).fit()
print(f"负二项回归 x 系数 SE: {model_nb.bse['x']:.4f} (真实稳健 SE)")
```

## 🃏 Anki 卡片

### Card 1: 过度离散诊断与散度参数
- **Front**: 如何使用 Pearson 卡方统计量估算计数数据泊松回归的散度参数 $\hat{\phi}$？
- **Back**: 
  - 表达式：$\hat{\phi} = \frac{X^2}{n - p} = \frac{1}{n - p} \sum_{i=1}^n \frac{(y_i - \hat{\mu}_i)^2}{\hat{\mu}_i}$。
  - 诊断规则：若 $\hat{\phi} \approx 1$，等分散假设成立；若 $\hat{\phi} > 1.5$，表明存在显着过度离散，需采用 Quasi-Poisson 或负二项回归。

### Card 2: Quasi-Poisson 与 负二项 (NB2) 方差结构对比
- **Front**: 对比准泊松（Quasi-Poisson）与负二项（NB2）模型在方差结构设定上的差异。
- **Back**: 
  - Quasi-Poisson：线性膨胀方差 $\text{Var}(Y) = \phi \mu$，散度常数 $\phi$ 等比例放大所有单元格方差。
  - 负二项 (NB2)：二次项膨胀方差 $\text{Var}(Y) = \mu + \alpha \mu^2$，散度参数 $\alpha$ 随着均值 $\mu$ 的增大而产生非线性二次膨胀，更适合高均值高离散数据。
