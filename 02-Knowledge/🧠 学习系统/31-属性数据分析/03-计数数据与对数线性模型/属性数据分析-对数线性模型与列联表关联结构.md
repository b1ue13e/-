# 属性数据分析-对数线性模型与列联表关联结构

## 1. 对数线性模型（Log-Linear Models）概念

在列联表中，所有变量地位对称，没有明确区分“响应变量”与“解释变量”。**对数线性模型将所有单元格频数视为泊松响应，通过对数期望频数 $\ln\mu_{ij}$ 的线性展开来建模变量间的复杂关联结构**。

---

## 2. 二维列联表的对数线性模型

对于 $I \times J$ 列联表，单元格期望频数为 $\mu_{ij}$：

### 2.1 独立模型 $(X, Y)$
$$
\ln(\mu_{ij}) = \lambda + \lambda_i^X + \lambda_j^Y
$$
* 参数约束（零和约束 $\sum \lambda_i^X = \sum \lambda_j^Y = 0$ 或基准类别约束 $\lambda_1^X = \lambda_1^Y = 0$）；
* 自由度为 $(I-1)(J-1)$。该模型在数学上等价于假设 $X$ 与 $Y$ 独立。

### 2.2 饱和模型 $(XY)$
$$
\ln(\mu_{ij}) = \lambda + \lambda_i^X + \lambda_j^Y + \lambda_{ij}^{XY}
$$
* 包含所有交互项 $\lambda_{ij}^{XY}$，参数量等于单元格数 $IJ$，拟合值 $\hat{\mu}_{ij} = n_{ij}$，残差偏差 $D = 0$。

---

## 3. 三维列联表中的对数线性模型层次体系

对于 $I \times J \times K$ 三维列联表（变量 $X, Y, Z$）：

| 模型符号 | 模型对数线性公式 $\ln\mu_{ijk}$ | 概率与统计学含义 |
| :--- | :--- | :--- |
| **$(X, Y, Z)$** | $\lambda + \lambda_i^X + \lambda_j^Y + \lambda_k^Z$ | **完全相互独立**：$P(X, Y, Z) = P(X)P(Y)P(Z)$ |
| **$(XY, Z)$** | $\lambda + \lambda_i^X + \lambda_j^Y + \lambda_k^Z + \lambda_{ij}^{XY}$ | **联合独立**：$(X, Y)$ 联合与 $Z$ 独立 |
| **$(XZ, YZ)$** | $\lambda + \lambda_i^X + \lambda_j^Y + \lambda_k^Z + \lambda_{ik}^{XZ} + \lambda_{jk}^{YZ}$ | **条件独立**：给定 $Z$ 条件下，$X$ 与 $Y$ 独立 |
| **$(XY, XZ, YZ)$** | $\lambda + \dots + \lambda_{ij}^{XY} + \lambda_{ik}^{XZ} + \lambda_{jk}^{YZ}$ | **无三阶交互项 (同质性关联)**：$\theta_{XY(k)}$ 在所有 $Z$ 层中恒定 |
| **$(XYZ)$** | 包含三阶交互项 $\lambda_{ijk}^{XYZ}$ | **饱和模型**：完美拟合，允许条件优势比随层变化 |

---

## 4. 对数线性模型与 Logistic 回归的等价性定理

> [!IMPORTANT]
> **等价性定理 (Equivalence Theorem)**：
> 当指定某一变量（如 $Y$）为二分类二项响应变量时，三维列联表的**对数线性模型 $(XY, XZ, YZ)$ 与以 $Y$ 为响应、以 $X$ 和 $Z$ 为主效应的二项 Logistic 回归模型完全数学等价**！
>
> 证明简述：
> $$
> \text{logit}(P(Y=1 \mid X=i, Z=k)) = \ln\left( \frac{\mu_{i1k}}{\mu_{i2k}} \right) = (\lambda_1^Y - \lambda_2^Y) + (\lambda_{i1}^{XY} - \lambda_{i2}^{XY}) + (\lambda_{1k}^{YZ} - \lambda_{2k}^{YZ}) = \beta_0 + \beta_i^X + \beta_k^Z
> $$
> 对数线性模型中的边际项 $\lambda + \lambda_i^X + \lambda_k^Z + \lambda_{ik}^{XZ}$ 在比值中完全被消除！
