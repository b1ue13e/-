# 属性数据分析-极大似然估计与渐近推断三大检验

## 1. 问题动机与直觉

在非高斯广义线性模型中，检验参数 $\boldsymbol{\beta}$ 是否显著（例如 $H_0: \beta_j = 0$）无法依赖正态小样本的精确 $t$ 分布或 $F$ 分布。必须依靠**极大似然估计（MLE）**的大样本渐近理论。

统计学中有三大经典渐近检验：**Wald 检验**、**似然比检验（Likelihood Ratio Test, LRT）** 与 **Score 检验（Rao's Score / Lagrange Multiplier Test）**。理解它们的几何与数学联系，是进行模型比较与显著性判定的核心。

---

## 2. 基础符号与极大似然框架

设独立样本观测对数似然函数为 $\ell(\boldsymbol{\theta}) = \sum_{i=1}^n \ln f(y_i; \boldsymbol{\theta})$。

1. **Score 函数（梯度向量）**：
   $$
   U(\boldsymbol{\theta}) = \nabla \ell(\boldsymbol{\theta}) = \frac{\partial \ell(\boldsymbol{\theta})}{\partial \boldsymbol{\theta}}
   $$
   由定义，在极大似然估计点 $\hat{\boldsymbol{\theta}}$ 处，满足 Score 方程 $U(\hat{\boldsymbol{\theta}}) = \mathbf{0}$。且 $\mathbb{E}[U(\boldsymbol{\theta})] = \mathbf{0}$。

2. **Fisher 信息矩阵（Hessian 负期望）**：
   $$
   \mathcal{I}(\boldsymbol{\theta}) = -\mathbb{E}\left[ \frac{\partial^2 \ell(\boldsymbol{\theta})}{\partial \boldsymbol{\theta} \partial \boldsymbol{\theta}^T} \right] = \text{Var}(U(\boldsymbol{\theta}))
   $$
   在样本量 $n \to \infty$ 时，MLE 具有渐近正态性：
   $$
   \hat{\boldsymbol{\theta}} \xrightarrow{d} N\left(\boldsymbol{\theta}_0, \mathcal{I}(\boldsymbol{\theta}_0)^{-1}\right)
   $$

---

## 3. 渐近三大检验的数学定义与几何直观

考虑检验原假设 $H_0: \boldsymbol{\theta} = \boldsymbol{\theta}_0$（维度为 $r$）：

```
对数似然 l(θ)
    ^
    |             * MLE (θ_hat), 斜率 U(θ_hat) = 0
    |           /   \
    |          /     \      似然比高度差 2[l(θ_hat) - l(θ_0)]
    |         /       \ 
    |        * (θ_0)   \
    |       /  斜率 U(θ_0) != 0
    +------------------------> θ
             | <-----> |
             Wald 距离 (θ_hat - θ_0)
```

### 3.1 Wald 检验 (Wald Test)
* **几何直观**：衡量无约束估计值 $\hat{\boldsymbol{\theta}}$ 距离原假设值 $\boldsymbol{\theta}_0$ 在水平轴上的加权欧氏距离。
* **统计量定义**：
  $$
  W = (\hat{\boldsymbol{\theta}} - \boldsymbol{\theta}_0)^T \mathcal{I}(\hat{\boldsymbol{\theta}}) (\hat{\boldsymbol{\theta}} - \boldsymbol{\theta}_0) \xrightarrow{d} \chi^2_r
  $$
  对于标量参数，常用检验统计量 $z = \frac{\hat{\theta} - \theta_0}{\text{SE}(\hat{\theta})} \sim N(0, 1)$。
* **特点**：只需拟合完整模型（无约束模型），计算便捷；但在参数非常大时，似然曲面可能变平缓，导致 $\text{SE}$ 被夸大，发生著名的 **Hauck-Donner 效应（假阴性）**。

### 3.2 似然比检验 (Likelihood Ratio Test, LRT / Deviance Difference)
* **几何直观**：衡量无约束模型与约束模型在纵轴上的**对数似然函数高度落差**。
* **统计量定义**：
  $$
  G^2 = -2 \ln\left( \frac{L(\boldsymbol{\theta}_0)}{L(\hat{\boldsymbol{\theta}})} \right) = 2 \left[ \ell(\hat{\boldsymbol{\theta}}) - \ell(\boldsymbol{\theta}_0) \right] \xrightarrow{d} \chi^2_r
  $$
* **特点**：对参数变换具有不变性（Invariance under reparameterization），有限样本下收敛速度最快，是模型比较的**黄金准则**。

### 3.3 Score 检验 (Rao's Score / Lagrange Multiplier Test)
* **几何直观**：在原假设点 $\boldsymbol{\theta}_0$ 处评估对数似然曲面的**切线斜率（Score 向量）偏离零的程度**。
* **统计量定义**：
  $$
  S = U(\boldsymbol{\theta}_0)^T \mathcal{I}(\boldsymbol{\theta}_0)^{-1} U(\boldsymbol{\theta}_0) \xrightarrow{d} \chi^2_r
  $$
* **特点**：**只需在原假设 $H_0$ 下拟合简化模型**，无需计算复杂无约束模型的 MLE。在列联表独立性检验中，著名的 Pearson $X^2$ 检验本质上就是 Score 检验！

---

## 4. 三大检验的渐近等价性与有限样本排序

在大样本渐近极限下（$n \to \infty$），三者渐近等价：
$$
W \approx G^2 \approx S \xrightarrow{d} \chi^2_r
$$

但在中小样本与属性数据极端情况下：
$$
\text{稳健性与表现排序：} \quad \text{LRT (似然比)} \ge \text{Score (得分检验)} > \text{Wald (瓦尔德)}
$$

## 5. Python 代码实现与对比

```python
import numpy as np
import scipy.stats as stats

# 二项试验: n 次试验, k 次成功
n = 100
k = 65
pi_0 = 0.50  # H0: pi = 0.5
pi_hat = k / n

# 1. Wald 检验
se_wald = np.sqrt(pi_hat * (1 - pi_hat) / n)
z_wald = (pi_hat - pi_0) / se_wald
w_stat = z_wald ** 2
p_wald = 1 - stats.chi2.cdf(w_stat, df=1)

# 2. 似然比检验 (LRT)
log_lik_hat = k * np.log(pi_hat) + (n - k) * np.log(1 - pi_hat)
log_lik_0 = k * np.log(pi_0) + (n - k) * np.log(1 - pi_0)
lrt_stat = 2 * (log_lik_hat - log_lik_0)
p_lrt = 1 - stats.chi2.cdf(lrt_stat, df=1)

# 3. Score 检验
se_score = np.sqrt(pi_0 * (1 - pi_0) / n)
z_score = (pi_hat - pi_0) / se_score
score_stat = z_score ** 2
p_score = 1 - stats.chi2.cdf(score_stat, df=1)

print(f"Wald 统计量: {w_stat:.4f}, p-val: {p_wald:.4e}")
print(f"LRT 统计量:  {lrt_stat:.4f}, p-val: {p_lrt:.4e}")
print(f"Score 统计量:{score_stat:.4f}, p-val: {p_score:.4e}")
```
