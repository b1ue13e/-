# 🧭 阶段0：前置知识与理论底座

> "进入离散数据建模前，必须建立两根数学支柱：一是离散指数族分布的概率与似然性质，二是广义线性模型（GLM）连接非线性响应与线性预测器的统一几何框架。"

---

## 📌 阶段定位与学习目标

本阶段为全课程提供最低充分的数理统计与矩阵分析准备。学完本阶段后，你应当能够：
1. 写出二项分布、多项分布与 Poisson 分布的概率质量函数，并推导其在自然指数族中的规范形式（Natural Exponential Family Form）。
2. 理解极大似然估计（MLE）的 Score 方程与 Fisher 信息矩阵，熟练区分 Wald 检验、似然比检验（LRT）与 Score 检验的几何意义与计算差异。
3. 掌握广义线性模型（GLM）的三大构成要素（随机成分、系统成分、链接函数），并能独立推导典则链接（Canonical Link）函数。

## 🎯 阶段自测与通过标准

- [ ] 能闭卷写出自然指数族标准式 $f(y; \theta, \phi) = \exp\left\{\frac{y\theta - b(\theta)}{a(\phi)} + c(y, \phi)\right\}$，并推导出 $\mathbb{E}[Y] = b'(\theta)$ 与 $\text{Var}(Y) = b''(\theta)a(\phi)$。
- [ ] 能解释为什么在有限样本下，似然比检验（LRT）的渐近性质通常优于 Wald 检验。
- [ ] 能从指数族形式出发，推导出 Bernoulli 分布的典则链接为 $\text{logit}(\mu) = \ln\left(\frac{\mu}{1-\mu}\right)$。
