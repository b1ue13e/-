# 属性数据分析-离散概率分布与指数族

## 1. 问题动机与直觉

在经典线性回归（OLS）中，我们假设响应变量 $Y \sim N(\mu, \sigma^2)$。然而，属性数据分析面对的是**类别（Categories）**与**计数（Counts）**。例如：
- 患病与否（0/1 二分类，取值受限于 $[0, 1]$ 概率空间）；
- 交通事故发生数（$0, 1, 2, \dots$ 非负整数计数，具有右偏分布且方差随均值增大）。

若直接用 OLS 拟合，会导致：
1. **预测值越界**：线性模型 $\hat{Y} = X\beta$ 可能输出负概率或负计数；
2. **异方差性（Heteroscedasticity）**：离散分布的方差天生依赖于均值（如二项分布方差为 $n\pi(1-\pi)$），违背 OLS 同方差假设。

为了统一处理这些分布，现代统计学引入了**自然指数族（Natural Exponential Family）**。

---

## 2. 自然指数族标准定义

单参数（或含散度参数 $\phi$）的自然指数族分布，其概率质量/密度函数可写为：

$$
f(y; \theta, \phi) = \exp\left\{ \frac{y\theta - b(\theta)}{a(\phi)} + c(y, \phi) \right\}
$$

其中：
- $\theta$：**自然参数（Natural / Canonical Parameter）**；
- $b(\theta)$：**累积量生成函数（Cumulant Function）**；
- $\phi$：**散度参数（Dispersion Parameter）**，对于许多离散分布通常 $a(\phi) = 1$ 或固定为已知常数；
- $c(y, \phi)$：与待估参数 $\theta$ 无关的归一化项。

### 均值与方差的优美性质
对对数似然求一阶与二阶导数，由似然正则性条件（$\mathbb{E}[\frac{\partial \ln f}{\partial \theta}] = 0$ 和 $\mathbb{E}[\frac{\partial^2 \ln f}{\partial \theta^2}] + \text{Var}(\frac{\partial \ln f}{\partial \theta}) = 0$）可直接推导出：

$$
\mathbb{E}[Y] = \mu = b'(\theta)
$$

$$
\text{Var}(Y) = b''(\theta) a(\phi) = V(\mu) a(\phi)
$$

其中 $V(\mu) = b''(\theta(\mu))$ 称为**方差函数（Variance Function）**，明确刻画了方差随均值变化的函数关系。

---

## 3. 核心离散分布的指数族推导

### 3.1 Bernoulli / 二项分布 ($Y \sim \text{Binomial}(n, \pi)$)
设单次试验 $Y \in \{0, 1\}$，$P(Y = y) = \pi^y (1-\pi)^{1-y}$：

$$
f(y; \pi) = \exp\left\{ y \ln\pi + (1-y)\ln(1-\pi) \right\} = \exp\left\{ y \ln\left(\frac{\pi}{1-\pi}\right) + \ln(1-\pi) \right\}
$$

对比指数族标准式：
- 自然参数：$\theta = \ln\left(\frac{\pi}{1-\pi}\right) = \text{logit}(\pi)$ （这就是 **Log-odds** 的天然数学起源！）
- 累积量函数：$\pi = \frac{e^\theta}{1+e^\theta} \implies b(\theta) = -\ln(1-\pi) = \ln(1+e^\theta)$
- 散度参数：$a(\phi) = 1$
- 均值验证：$\mu = b'(\theta) = \frac{e^\theta}{1+e^\theta} = \pi$
- 方差函数：$\text{Var}(Y) = b''(\theta) = \frac{e^\theta}{(1+e^\theta)^2} = \pi(1-\pi) = V(\mu)$

### 3.2 Poisson 分布 ($Y \sim \text{Poisson}(\mu)$)
概率质量函数为 $P(Y = y) = \frac{e^{-\mu} \mu^y}{y!}$：

$$
f(y; \mu) = \exp\left\{ y \ln\mu - \mu - \ln(y!) \right\}
$$

对比指数族标准式：
- 自然参数：$\theta = \ln\mu$ （这就是 **对数链接 Log-link** 的天然起源！）
- 累积量函数：$b(\theta) = \mu = e^\theta$
- 散度参数：$a(\phi) = 1$
- 均值验证：$\mathbb{E}[Y] = b'(\theta) = e^\theta = \mu$
- 方差函数：$\text{Var}(Y) = b''(\theta) = e^\theta = \mu = V(\mu)$ （均值与方差严格相等，即等分散性 Equidispersion）

## 4. Python 计算与性质验证

```python
import numpy as np
import scipy.stats as stats

# 验证二项分布的均值与方差函数
n = 100000
pi = 0.3
samples_binom = np.random.binomial(n=1, p=pi, size=n)

mean_empirical = np.mean(samples_binom)
var_empirical = np.var(samples_binom)
var_theoretical = pi * (1 - pi)

print(f"Bernoulli 均值: {mean_empirical:.4f} (理论: {pi})")
print(f"Bernoulli 方差: {var_empirical:.4f} (理论 V(mu): {var_theoretical:.4f})")
```

## 5. 常见认知误区

1. **误区：认为任何分布都能写成指数族**
   - 澄清：均匀分布 $U(a, b)$ 的支撑集依赖于参数，不是指数族；柯西分布没有有限的一阶矩，也不是自然指数族。
2. **误区：认为计数数据可以直接套用泊松分布**
   - 澄清：现实计数数据常存在“过度离散”（Overdispersion，方差显著大于均值），此时必须引入准泊松（Quasi-Poisson）或负二项分布（Negative Binomial）。
