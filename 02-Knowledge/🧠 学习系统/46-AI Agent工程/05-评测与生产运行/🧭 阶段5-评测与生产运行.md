# 🧭 阶段 5：评测与生产运行

## 为什么现在学

能运行不等于可用。必须以逐样本任务结果、轨迹、危险效果、误拒、成本和恢复证据判断系统，而不是只看最终文本或 HTTP 200。

## 学习目标

- 建立任务、轨迹、安全、成本四层评测。
- 用威胁模型和纵深控制约束真实效果。
- 从 trace 定位失败，并验证暂停、审批、幂等和恢复。

- **回收节点**：次日、3 天后、7 天后闭卷解释 TSR、ToolAcc、ASR、FRR 及其失败归因。
