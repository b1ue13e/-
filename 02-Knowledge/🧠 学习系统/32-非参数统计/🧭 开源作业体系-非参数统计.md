# 🧭 开源作业体系-非参数统计

> 本页是「非参数统计」开源名校课程与作业的**唯一挂载点**：教材主线、官方作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**OpenIntro IMS (2e) Labs**（https://openintro.org/book/ims/online/，CC BY-SA 3.0）+ **Penn State STAT 500**（https://online.stat.psu.edu/stat500/，应用回归方法中非参数章节）+ **R 中的 `coin` / `perm` / `np` 包**。

| 角色 | 来源 | 用途 |

## 🎯 作业体系（HW01-HW05）

| HW | 主题 | 官方来源（IMS 章节） | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 秩与秩统计量 | IMS Ch.14 | 待补卡（秩、秩和、Wilcoxon） | 单样本 Wilcoxon 符号秩；与 t 检验对照（偏态/小样本） |
| HW02 | 符号检验与 Wilcoxon 符号秩 | IMS Ch.14 | 待补卡（符号检验、配对 Wilcoxon） | 配对数据 + 模拟 p 值；ties 校正 |
| HW03 | Wilcoxon 秩和（Mann-Whitney U） | IMS Ch.15 | 待补卡（两独立样本秩和） | 两组独立样本 + 效应量 + 与 t 检验对照 |
| HW04 | 置换检验（Permutation Test） | IMS Ch.15 | 待补卡（置换/随机化分布） | 自实现置换检验；与 `coin` 包对照 |
| HW05 | Bootstrap 与平滑估计 | IMS Ch.16-17 | 待补卡（Bootstrap、平滑、核估计） | Bootstrap CI（百分位/BCa）；LOESS 拟合；与参数化对照 |

> 分层验收原则：HW01-03 是**秩统计链**（单样本 → 配对 → 两独立样本）；HW04 是**置换检验**（不依赖秩分布的现代方法）；HW05 是**Bootstrap + 平滑**收尾（与参数化推断形成对比）。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷手算（单样本符号秩）；② R 实现（自写 + 包函数对照）；③ 1 页报告（何时用非参数 + 偏态/异常值的影响 + 与参数方法对照）。
2. **模拟验证**：HW04 必须自实现置换检验（不用 `coin` 包），并与 `coin` 包结果对照。
3. **数据来源**：IMS 数据集 + R 内置 + 公开 UCI 数据。
4. **满分 Rubric**：HW01-05 各 20 分，共 100 分（手算 30 + 实现 40 + 报告 30）。
