# Lp空间与完备性

---
## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：$L^p$ 空间是"函数作向量"的样板——把函数装进赋范线性空间，泛函分析的全部机器（完备性、稠密性、对偶）从这里开动；[[测度论-Radon-Nikodym定理与条件期望]] 的证明主线之一就建立在 $L^2$ 上（Hilbert 空间方法）；概率论的 $L^p$ 矩、统计的 $L^2$ 误差都直接复用。MT-S03 之后的核心进阶卡。

---
## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 微积分里连续函数空间 $C([0,1])$ 配上 $\|\cdot\|_\infty$ 是完备的，但换成 $L^2$ 范数 $\|f\|_2 = (\int f^2)^{1/2}$ 就**不完备**：$f_n(x) = \min(n, x^{-1/4})$ 的 $L^2$ 极限 $x^{-1/4}$ 在 $x=0$ 无界、不是连续函数——极限"逃出"了空间。完备性（Cauchy 列收敛）是分析学的一切根基：方程解的存在性、级数求和、不动点迭代全靠它。必须把空间**扩大**到 $L^p$，并证明它完备（Riesz-Fischer），同时搞清楚哪些"好函数"（简单函数、阶梯函数、连续函数）在其中稠密——这样"先用好函数证明，再极限过渡"的策略才合法。

---
## 2. 为什么它重要？它有什么用？

- **连接大图景**：$L^p$ 完备性让“函数级数 $\sum f_n$ 收敛”有了严格意义；[[测度论-Radon-Nikodym定理与条件期望]] 采用 Axler 在 $L^2(\nu+\mu)$ 上的 Riesz 表示证明；在本课的 σ-有限口径下，`L^p` 对偶理论是 [[02-Knowledge/🧠 学习系统/27-泛函分析/🗺️ 泛函分析学习路径|泛函分析]] 与变分法的入口。
- **实际应用场景**：信号处理（$L^2$ 能量、Fourier 级数收敛）、概率论（$L^p$ 矩、$L^2$ 鞅）、统计（$L^2$ 风险、投影估计）、PDE（Sobolev 空间是 $L^p$ 的导数版）。
- **高频题型/任务**：验证 $\|f\|_p$ 的三角不等式（Minkowski）；用 Holder 估计积分；证明 $L^p$ 完备（Riesz-Fischer 主线）；构造稠密逼近；判断有限测度空间上 $L^p$ 的包含关系；$p<1$ 非范数反例。

---
## 3. 学它之前需要哪些前置知识？

1. **[[测度论-可测函数与收敛模式]]**：$L^p$ 的元素是可测函数的等价类；$L^p$ 收敛是收敛模式之一。
2. **[[测度论-单调收敛定理与积分收敛]]**：MCT/DCT 是 Riesz-Fischer 证明的两大发动机（级数求和与积分交换）。
3. **[[测度论-Lebesgue测度与可测集]]**：零测集概念用于"模 a.e. 相等"；$\mu(X) < \infty$ 与否决定空间包含方向。

---
## 4. 用直觉语言解释它

> «$L^p$ 空间像"用第 $p$ 范数丈量的函数仓库"：$p=1$ 是总量（面积），$p=2$ 是能量（平方面积开根），$p=\infty$ 是最高楼层（本质最大值）。Holder 不等式像"仓库的装卸预算"：$p$ 与 $q$ 互为"共轭搬运工"，一个管重量一个管体积，合起来恰好搬得动 $L^1$ 的货。»

- **直觉类比/几何图像**：$\|f\|_p$ 是"函数向量"的长度；$L^p$ 完备性说"长度上互相靠近的函数列（Cauchy）一定收敛到仓库里的某个函数"——仓库没有漏洞。
- **为什么很自然**：把"两个函数 a.e. 相等"视为同一元素后，$\|f - g\|_p = 0 \iff f = g$，长度公理齐全；稠密性（简单函数逼近）来自[[测度论-可测函数与收敛模式]]的楼梯构造——先用台阶函数量好，再让台阶无限加密。
- **一句话直觉本质**：**$L^p$ 是按 a.e. 相等取等价类的完备赋范空间；Holder/Minkowski 控制乘积与加法，Riesz-Fischer 保证极限不逃逸。可测简单函数对所有 $p\in[1,\infty]$ 稠密，矩形阶梯函数与 $C_c$ 的稠密性则限于欧氏 Lebesgue 空间的 $p<\infty$ 情形。**

---
## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **$L^p$ 空间**（$1 \le p < \infty$）：$L^p(\mu) = \left\{ f \text{ 可测} : \|f\|_p := \left(\int |f|^p\,d\mu\right)^{1/p} < \infty \right\}/\!\sim$，其中 $f \sim g \iff f = g$ a.e.。
- **$L^\infty$**：$\|f\|_\infty = \inf\{M : |f| \le M \text{ a.e.}\}$（本质有界），$\|f\|_\infty < \infty$ 的元素全体。
- **Holder 不等式**：$1/p + 1/q = 1$（$1 \le p, q \le \infty$），$\|fg\|_1 \le \|f\|_p\|g\|_q$。
- **Minkowski 不等式**（三角不等式）：$\|f + g\|_p \le \|f\|_p + \|g\|_p$。
- **完备性（Riesz-Fischer）**：$L^p$（$1 \le p \le \infty$）是 Banach 空间：$L^p$ 中 Cauchy 列必收敛于 $L^p$ 中某元素。
- **稠密性**：可测简单函数在 $L^p$（$1\le p\le\infty$）中稠密；$C_c(\mathbb{R}^d)$（紧支撑连续函数）和矩形阶梯函数只在 $1\le p<\infty$ 时对 Lebesgue 测度稠密。$L^\infty$ 中失败的是 $C_c$ 等正则函数类的普遍稠密性，不是简单函数稠密性。

### 2. 核心公式
$$\|f\|_p = \left(\int_X |f|^p\,d\mu\right)^{1/p}, \qquad \|f\|_\infty = \operatorname{ess\,sup}|f|$$
$$\text{Holder:}\ \left|\int fg\,d\mu\right| \le \int |fg|\,d\mu \le \|f\|_p\,\|g\|_q,\quad \tfrac1p + \tfrac1q = 1$$
$$\text{Minkowski:}\ \|f+g\|_p \le \|f\|_p + \|g\|_p$$
$$\text{有限测度包含：}\ \mu(X)<\infty,\ p \le q \implies \|f\|_p \le \mu(X)^{\frac1p-\frac1q}\|f\|_q,\quad L^q \subset L^p$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $p, q$ | 共轭指数 | $1 \le p \le \infty$，$1/p+1/q=1$ | $p=2$ 时 $q=2$ |
| $\|f\|_p$ | $p$-范数 | $[0, \infty]$ | $\|f\|_p < \infty$ 才入空间 |
| $\operatorname{ess\,sup}$ | 本质上确界 | — | 忽略零测集后的 sup |
| $L^p/\!\sim$ | 等价类空间 | — | a.e. 相等视为同一元素 |

### 4. 常见变体与适用条件
- **适用条件**：Holder/Minkowski 需要 $p \ge 1$；可测简单函数对所有 $1\le p\le\infty$ 都稠密，$C_c$ 与矩形阶梯函数的稠密性则要求 $p<\infty$ 并使用 $\mathbb{R}^d$ 上的 Lebesgue 测度。
- **限制条件**：$p < 1$ 时 $\|\cdot\|_p$ 不是范数（见例子 3）；$L^p \subset L^q$ 的包含方向依赖 $\mu$ 有限与否。
- **条件变式**：插值不等式 $\|f\|_r \le \|f\|_p^\theta \|f\|_q^{1-\theta}$（$\frac1r = \frac\theta p + \frac{1-\theta}{q}$）：$L^p \cap L^q \subset L^r$ 对任意测度成立。

## 6. 推导思路和思想来源

- **最初困难**：$C([0,1])$ 在 $\|\cdot\|_2$ 下不完备——Cauchy 列的极限（如 $x^{-1/4}$）不是连续函数；"极限逃逸"让 Fourier 级数、变分法的存在性论证全部失效。
- **直接方法局限**：把 $C$ 换成"逐点有界函数"也不行——极限依然可能逃出；问题不在函数"多好"，而在范数允许的极限类。
- **关键"转念"**：**让"模 a.e. 相等"成为同一元素，并用积分定义范数——空间由范数自己"长"出来，而不是先挑好函数类再套范数**。这样 $L^p$ 天然包含自己的一切 $p$-极限（完备性证明的目标），而"好函数"退居二线，只作稠密子集。
- **推导主线与动机**：
  - **Holder 主线**：Young 不等式 $ab \le \frac{a^p}{p} + \frac{b^q}{q}$（由 $\log$ 的凹性：$\log(ab) = \frac1p\log a^p + \frac1q\log b^q \le \log(\frac{a^p}p + \frac{b^q}q)$）→ 归一化 $a = |f|/\|f\|_p$、$b = |g|/\|g\|_q$ 代入并积分，得 $\frac{\|fg\|_1}{\|f\|_p\|g\|_q} \le \frac1p + \frac1q = 1$。等号条件：$|f|^p$ 与 $|g|^q$ 成比例 a.e.。
  - **Minkowski 主线**：$|f+g|^p = |f+g|^{p-1}|f+g| \le |f+g|^{p-1}|f| + |f+g|^{p-1}|g|$；对两项分别用 Holder（$p$ 与 $q$，注意 $(p-1)q = p$），得 $\|f+g\|_p^p \le \|f+g\|_p^{p-1}(\|f\|_p + \|g\|_p)$，除以 $\|f+g\|_p^{p-1}$。**Minkowski 就是"Holder 的推论"。**
  - **Riesz-Fischer 主线（$1\le p<\infty$）**：从 Cauchy 列取快速子列，使 $\|f_{n_{k+1}}-f_{n_k}\|_p\le2^{-k}$。令 $G_N=\sum_{k=1}^N|f_{n_{k+1}}-f_{n_k}|$、$G=\lim_NG_N$。Minkowski 给出 $\|G_N\|_p\le\sum_{k=1}^N2^{-k}$；对 $G_N^p\uparrow G^p$ 用 MCT，得到 $G\in L^p$。因此增量级数 a.e. 绝对收敛并定义极限 $f$。尾和 $H_k=\sum_{j\ge k}|f_{n_{j+1}}-f_{n_j}|$ 满足 $H_k\downarrow0$ a.e. 且 $H_k^p\le G^p\in L^1$，由 DCT 得 $\|f-f_{n_k}\|_p\to0$；原 Cauchy 列因有收敛子列而全列收敛。
  - **$p=\infty$ 的单独论证**：取代表元并删去可数个零测异常集，使快速子列在剩余集合上一致 Cauchy；逐点一致极限本质有界，且本质上确界范数收敛。不能把上面的 $G^p$ 积分论证直接套到 $p=\infty$。
  - **稠密性主线**：当 $p<\infty$ 时，对 $f$ 先截断再按值域量化为简单函数，并用 DCT 得到 $L^p$ 收敛；当 $p=\infty$ 时，对本质有界代表元的值域做有限分箱，可直接把本质上确界误差压到任意 $\varepsilon$。在 $\mathbb{R}^d$ 的 Lebesgue 测度下，$C_c$ 与矩形阶梯函数的 $p<\infty$ 稠密性还要使用 Lebesgue 正则性，不能从“简单函数稠密”无条件推出。
- **为什么自然得到此结论**：完备性是"MCT 管级数求和、DCT 管积分交换"的直接产物；稠密性是"楼梯逼近"的直接产物——**Lp 理论几乎不发明新工具，全是收敛定理与逼近思想的组装**。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：$f(x) = x^{-2/3}$ 于 $(0,1]$。判断 $f \in L^1$? $f \in L^2$?
- **解题思路与关键步骤**：$\int_0^1 x^{-2/3}\,dx = [3x^{1/3}]_0^1 = 3 < \infty$，$f \in L^1$；$\int_0^1 (x^{-2/3})^2\,dx = \int_0^1 x^{-4/3}\,dx = [-3x^{-1/3}]_0^1 = \infty$，$f \notin L^2$。
- **最终答案**：$f \in L^1 \setminus L^2$。与有限测度包含链 $L^2 \subset L^1$ 不矛盾（$f$ 不在 $L^2$ 里，谈不上被包含）；但说明"幂次越高的 $L^p$ 对无界性越挑剔"。
- **易错点**：把"$\int f < \infty$"与"$f$ 有界"混为一谈；$x^{-2/3}$ 无界却 $L^1$ 可积。
- **🤔 追问**：若换成 $g(x) = x^{-1/2}$ 于 $(0,1]$？——同样 $g \in L^1 \setminus L^2$；但 $g \in L^{1.5}$?（$\int x^{-3/4} < \infty$，是的）。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：设 $\mu(X) < \infty$，$f \in L^3$。证明 $f \in L^2$ 并估计 $\|f\|_2$。用 Holder：取 $p = 3/2$，$q = 3$（$1/p + 1/q = 1$），$|f|^2 = |f|^2 \cdot 1$：$\|f\|_2^2 = \int |f|^2 \cdot 1 \le \|\,|f|^2\|_{3/2}\|1\|_3 = \|f\|_3^2 \cdot \mu(X)^{1/3}$。故 $\|f\|_2 \le \mu(X)^{1/6}\|f\|_3$。**关键**：Holder 中的 $g \equiv 1$ 这一招把"函数空间包含"变成"常数函数的范数"，有限测度是 $L^q \subset L^p$（$q \ge p$）的根源。

### 例子 3：实际应用 + 反例——$p < 1$ 时 $\|\cdot\|_p$ 不是范数
- **题目**：$p = 1/2$，$f = \mathbb{1}_{[0,1]}$，$g = \mathbb{1}_{(1,2]}$ 于 $\mathbb{R}$。检验三角不等式。
- **关键步骤**：$\|f\|_{1/2} = (\int \mathbb{1}_{[0,1]})^{2} = 1$（注意 $1/p = 2$，先积分再平方），$\|g\|_{1/2} = 1$；而 $\|f + g\|_{1/2} = (\int \mathbb{1}_{[0,2]})^{2} = 2^2 = 4$。
- **反例结论**：$4 = \|f+g\|_{1/2} > \|f\|_{1/2} + \|g\|_{1/2} = 2$——**三角不等式反向成立，$\|\cdot\|_{1/2}$ 不是范数**。Minkowski 需要 $p \ge 1$（Holder 中 $q = p/(p-1) < 0$ 失效）。补救：$d(f,g) = \int|f-g|^p$ 仍是完备度量，$L^{1/2}$ 是完备度量空间而非赋范空间。**这就是 $L^p$ 定义中 $p \ge 1$ 的硬性来源。**

## 8. 常见误区和易混概念

### 误区 1：以为"$L^p \subset L^q$ 或 $L^q \subset L^p$ 无条件成立"
- **错误直觉**：可积性越强（$p$ 大）包含关系总是某一方向。
- **为什么错**：无限测度下 $f = \mathbb{1}_{[1,\infty)}/x$：$\int f = \infty$（$\log$ 发散）、$\int f^2 = 1 < \infty$，故 $f \in L^2 \setminus L^1$；而 $x^{-2/3}\mathbb{1}_{(0,1]}$ 给出 $L^1 \setminus L^2$（有限测度区）。两个方向都有反例。
- **正确理解**：$\mu(X) < \infty$ 时 $L^q \subset L^p$（$q \ge p$，Holder + $g \equiv 1$）；一般测度只有插值：$L^p \cap L^q \subset L^r$（$p \le r \le q$）。

### 误区 2：把 $\|f\|_\infty$ 当"逐点最大值"
- **错误直觉**：$\|f\|_\infty = \sup_x |f(x)|$。
- **为什么错**：$f = \mathbb{1}_{\mathbb{Q}\cap[0,1]}$：逐点 sup 是 1，但 $\|f\|_\infty = 0$（$f = 0$ a.e.）。
- **正确理解**：本质 sup 忽略零测集；这也再次说明 $L^p$ 的元素是等价类。

### 条件变式（本路径特色）
- **变式 1（$p$ 取极限）**：若 $\mu(X)<\infty$ 且 $f\in L^\infty$，则 $\|f\|_p\to\|f\|_\infty$。可测简单函数仍在 $L^\infty$ 中稠密；通常不稠密的是 $C_c$ 等受拓扑正则性约束的子类。
- **变式 2（完备性的用途）**：$L^p$ 中 $\sum_n \|f_n\|_p < \infty \Rightarrow \sum_n f_n$ 收敛（绝对收敛级数收敛）——完备性的标准推论，证明 DCT 型结论的常用杠杆。
- **变式 3（概率化）**：$L^2$ 是 Hilbert 空间（内积 $\langle f,g\rangle = \int fg$），条件期望 $E[X|\mathcal{G}]$ 恰是 $L^2$ 到闭子空间 $L^2(\mathcal{G})$ 的正交投影——通往 [[测度论-Radon-Nikodym定理与条件期望]] 的 $L^2$ 之路。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| $L^p$ 空间 | 第 $p$ 次幂可积 | 范数空间，$p \ge 1$ | 泛函分析、PDE |
| $L^\infty$ | 本质有界 | 不是 $p \to \infty$ 极限的平凡化 | 一致有界论证 |
| $C_c$ / 阶梯函数 | 好函数类 | 在 $L^p$（$p<\infty$）中稠密非相等 | 逼近、构造性证明 |
| $C([0,1])$ | 连续函数 | 在 $\|\cdot\|_2$ 下不完备 | 微积分（旧家园） |

#### 1. $L^p$ 的元素是什么？为什么 $\|f - g\|_p = 0$ 不推出 $f = g$ 逐点？
> [!question]- 答案解析
> - **答案**：$L^p$ 的元素是可测函数的等价类（$f \sim g \iff f = g$ a.e.）；$\|f-g\|_p = 0$ 只推出 $f = g$ a.e.（如 $f = \mathbb{1}_{\mathbb{Q}\cap[0,1]}$ 与 $g \equiv 0$ 是同一元素）。
> - **解析**：范数公理 $\|x\| = 0 \Rightarrow x = 0$ 在等价类意义下成立；不取等价类则 $\|\cdot\|_p$ 只是半范数。
> - **易错原因**：把"逐点相等"与"a.e. 相等"混为一谈。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 用 Holder 估计 $\int_0^1 |f|\,dx$（$f \in L^2([0,1])$），并写出等号条件。
> [!question]- 答案解析
> - **答案**：$\int_0^1 |f| \le \|f\|_2 \cdot \|1\|_2 = \|f\|_2$（$p = q = 2$，$g \equiv 1$）。等号条件：$|f|$ 与 $1$ 成比例 a.e.，即 $|f|$ 为常数 a.e.。
> - **解析**：Holder 等号条件来自 Young 等号：$a^p = b^q$ 即 $|f|^2 = c$。
> - **易错原因**：忘记验证 $\|1\|_2 = \sqrt{m([0,1])} = 1$。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 判断：$\mathbb{R}$ 上 $f = \mathbb{1}_{[1,\infty)}/x$ 属于哪些 $L^p$？说明包含关系为何失败。
> [!question]- 答案解析
> - **答案**：$\int_1^\infty x^{-2}\,dx = 1 < \infty$ 故 $f \in L^2$；$\int_1^\infty x^{-1}\,dx = \infty$ 故 $f \notin L^1$。无限测度下 $L^2 \not\subset L^1$。
> - **解析**：幂次 $x^{-s}$：$s > 1$ 在 $\infty$ 处可积、$s \le 1$ 不可积；$f$ 的"尾巴"太胖。
> - **易错原因**：默认有限测度下的包含链 $L^q \subset L^p$ 对一切测度成立。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 证明题：证明 Minkowski 不等式 $\|f+g\|_p \le \|f\|_p + \|g\|_p$（$1 < p < \infty$）。
> [!question]- 答案解析
> - **答案**：设 $h = |f+g|^{p-1}$，则 $h \in L^q$（$q = p/(p-1)$）。$\|f+g\|_p^p = \int |f+g|^{p-1}|f+g| \le \int h|f| + \int h|g| \le \|h\|_q\|f\|_p + \|h\|_q\|g\|_p$（Holder 两次）= $\|f+g\|_p^{p-1}(\|f\|_p + \|g\|_p)$。若 $\|f+g\|_p = 0$ 平凡；否则除以 $\|f+g\|_p^{p-1}$。
> - **解析**：$|f+g|^{p-1}$ 是"试函数"：$(p-1)q = p$ 让 Holder 的指数自动对齐——这是 Holder 推 Minkowski 的标准技巧。
> - **易错原因**：试图直接展开 $|f+g|^p$ 逐点用三角不等式（$p > 1$ 时 $|a+b|^p \le |a|^p + |b|^p$ 不成立）。
> - **Obsidian 标签建议**：`#自测题/较难`

#### 5. 反例构造：构造 $f \in L^1(\mathbb{R}) \setminus L^2(\mathbb{R})$ 与 $g \in L^2(\mathbb{R}) \setminus L^1(\mathbb{R})$，并说明这如何反驳"$L^p$ 彼此包含"的错觉。
> [!question]- 答案解析
> - **答案**：$f = x^{-2/3}\mathbb{1}_{(0,1]}$：$\int f = 3$、$\int f^2 = \infty$，故 $f \in L^1 \setminus L^2$；$g = \mathbb{1}_{[1,\infty)}/x$：$\int g = \infty$、$\int g^2 = 1$，故 $g \in L^2 \setminus L^1$。两者同时存在 ⟹ 无限测度下 $L^1$ 与 $L^2$ 互不包含。
> - **解析**：$f$ 在 $0$ 附近太"尖"（$L^2$ 拒绝尖峰），$g$ 在 $\infty$ 处太"胖"（$L^1$ 拒绝长尾）——两个病根不同，方向相反。
> - **易错原因**：只构造一个方向就断言包含关系。
> - **Obsidian 标签建议**：`#自测题/较难`
