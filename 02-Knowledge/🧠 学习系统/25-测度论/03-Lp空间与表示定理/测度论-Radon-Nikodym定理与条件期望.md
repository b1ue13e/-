# Radon-Nikodym与条件期望

---
## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：Radon-Nikodym（RN）定理是 [[测度论-阶段作业-03-Lp与Radon-Nikodym]] 的验收核心；条件期望是 RN 定理的直接推论。证明主线采用 Axler 的 Hilbert 空间方法：Riesz 表示产生 `g`，再经 `h=g/(1-g)`、MCT、σ-有限拼接和符号测度分解得到密度。

---
## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 概率论里“密度函数 $f_X$”人人都用：$P(X \in A) = \int_A f_X\,dx$。但“密度存在吗？何时存在？”需要明确测度类别与 σ-有限条件。本卡版本中，控制测度 $\mu$ σ-有限、$\nu$ 为有限符号/复测度时，$\nu\ll\mu$ 当且仅当存在 $h\in L^1(\mu)$ 使 $\nu(E)=\int_Eh\,d\mu$。若 $\nu$ 在 $\mu$ 的零测集上还有质量，如点质量 $\delta_0$ 对 Lebesgue 测度，则密度不存在。条件期望则是在子 σ 代数上保持所有集合积分的 RN 密度。

---
## 2. 为什么它重要？它有什么用？

- **连接大图景**：RN 定理收束阶段3的“`L^p` → Riesz 表示 → 密度 → 条件期望”主线；当随机变量属于 `L^2` 时，条件期望还可解释为正交投影；Lebesgue 分解把测度拆成绝对连续与奇异两部分。
- **实际应用场景**：概率密度存在性判据、贝叶斯统计（后验密度 = RN 导数）、测度变换（change of measure / Girsanov 定理的测度论根基）、鞅论（条件期望是鞅的定义运算）、强化学习与随机控制（条件期望无处不在）。
- **高频题型/任务**：判断 $\nu \ll \mu$ 是否成立；写出/验证密度 $d\nu/d\mu$；用 RN 证条件期望存在性；证明条件期望性质（塔性质、可测因子提出）；构造"不绝对连续故无密度"的反例；Lebesgue 分解。

3. **本卡内的符号测度接口**：有限符号测度、Jordan 分解与实虚部分解用于从正测度版扩展到符号/复测度版。

## 4. 用直觉语言解释它

> «RN 定理像"测度界的换汇"：$\mu$ 是美元，$\nu$ 是欧元，汇率 $f = d\nu/d\mu$ 在每个"面额"（集合）上把 $\mu$ 换成 $\nu$——但前提是 $\nu$ 从不"凭空印钱"：$\mu$ 认为零的集合（零测集），$\nu$ 也必须认零，否则汇率不存在。条件期望像"用粗粒度信息的最优估计"：只允许看 $\mathcal{G}$ 这块"模糊玻璃"（子 $\sigma$ 代数）来猜 $X$，$E[X|\mathcal{G}]$ 就是看得见的信息下最好的猜测。»

- **直觉类比/几何图像**：密度 $f = d\nu/d\mu$ 是"逐点汇率"：$\nu(E)$ = 在 $E$ 上按汇率 $f$ 兑换 $\mu$ 的总量。当 $X\in L^2$ 时，条件期望：$L^2(\Omega)$ 中 $X$ 向闭子空间 $L^2(\mathcal{G})$ 的**正交投影**——最好的 $\mathcal{G}$-可测近似。
- **为什么很自然**：$\nu\ll\mu$ 精确表示“$\mu$ 看不见的集合，$\nu$ 也不放质量”，即 $\mu(E)=0\Rightarrow\nu(E)=0$；反例 $\delta_0$：单点 $\{0\}$ 对 Lebesgue 测度为零，但对 $\delta_0$ 的质量为 1，因此无法由 Lebesgue 密度表示。
- **一句话直觉本质**：**在 RN 定理的有限性与 σ-有限性条件下，$\nu\ll\mu$ 等价于 $\nu$ 可由 $\mu$ 的密度积分表示；条件期望则是在子 $\sigma$ 代数上保持所有积分测试的 RN 密度。**

---
## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **有限符号测度**：$\nu:\mathcal{M}\to\mathbb{R}$ 可数可加且全变差有限；Jordan 分解为 $\nu=\nu^+-\nu^-$，全变差为 $|\nu|=\nu^++\nu^-$。
- **绝对连续**：$\nu\ll\mu$ 指 $\mu(E)=0\Rightarrow\nu(E)=0$；这是单向的零集条件，不表示 $\mu$ 与 $\nu$ 拥有完全相同的零集。若 $\mu$ σ-有限且 $\nu$ 是有限符号或复测度，则它等价于相应的 $\varepsilon$-$\delta$ 绝对连续性。
- **Radon-Nikodym 定理（本卡版本）**：设 $\mu$ 是 σ-有限正测度，$\nu$ 是有限符号测度且 $\nu\ll\mu$。则存在唯一的 $h\in L^1(\mu)$（模 $\mu$-a.e.）使 $\nu(E)=\int_E h\,d\mu$。若 $\nu$ 是正测度，则 $h\ge0$ a.e.；有限复测度版本同样成立。
- **条件期望**：概率空间 $(\Omega, \mathcal{F}, P)$，$\mathcal{G} \subset \mathcal{F}$ 子 $\sigma$ 代数，$X \in L^1$。$Y = E[X|\mathcal{G}]$ 是满足以下两条件的（唯一 a.s.）随机变量：(i) $Y$ 是 $\mathcal{G}$-可测；(ii) 对一切 $G \in \mathcal{G}$，$\int_G Y\,dP = \int_G X\,dP$。

### 2. 核心公式
$$\nu \ll \mu \iff \left[\mu(E) = 0 \Rightarrow \nu(E) = 0\right]$$
$$\text{RN:}\ \nu \ll \mu \implies \exists!\, h \in L^1(\mu):\ \nu(E) = \int_E h\,d\mu,\ \forall E \in \mathcal{M},\quad h = \frac{d\nu}{d\mu}$$
$$\text{条件期望:}\ Y = E[X|\mathcal{G}] \iff \left[Y \ \mathcal{G}\text{-可测} \ \wedge\ \forall G \in \mathcal{G},\ \int_G Y\,dP = \int_G X\,dP\right]$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\nu \ll \mu$ | $\nu$ 对 $\mu$ 绝对连续 | $\mu(E)=0\Rightarrow\nu(E)=0$ | 密度的存在条件之一 |
| $\nu \perp \mu$ | $\nu$ 与 $\mu$ 互相奇异 | 存在 $A$：$\mu(A)=0=\nu(A^c)$ | 无密度的极端情形 |
| $d\nu/d\mu$ | RN 导数（密度） | $L^1(\mu)$；正测度时非负 | 模 a.e. 唯一 |
| $E[X\mid\mathcal{G}]$ | 条件期望 | 随机变量 | 不是数！$\mathcal{G}$-可测 |
| $\mathcal{G}$ | 子 $\sigma$ 代数 | 信息量 | $\sigma(X)$ = $X$ 生成的信息 |

### 4. 常见变体与适用条件
- **适用条件**：本卡采用“$\mu$ σ-有限、$\nu$ 有限符号/复测度”的版本；条件期望要求 $X\in L^1$。正的 σ-有限 $\nu$ 可通过同时对 $\mu,\nu$ 做有限分块得到扩展版本。
- **限制条件**：控制测度 $\mu$ 非 σ-有限时 RN 可失败（见第 8 节变式 1）；$\nu\not\ll\mu$ 时无密度。
- **条件变式**：Lebesgue 分解 $\nu = \nu_{ac} + \nu_s$（$\nu_{ac} \ll \mu$，$\nu_s \perp \mu$）；RN 导数链式法则 $\frac{d\nu}{d\lambda} = \frac{d\nu}{d\mu}\frac{d\mu}{d\lambda}$（当 $\nu \ll \mu \ll \lambda$ 且各导数存在时）；条件期望的塔性质与 Jensen 不等式。

## 6. 推导思路和思想来源

- **最初困难**：两个测度如何“相除”？若 $\nu$ 在某个 $\mu$-零集上仍有质量，例如 $\delta_0$ 相对于 Lebesgue 测度，则任何密度积分都会漏掉这部分质量。
- **有限正测度情形（Axler 的 Hilbert 空间证明）**：在 $L^2(\nu+\mu)$ 上定义有界线性泛函 $\Phi(f)=\int f\,d\nu$。Riesz 表示给出 $g\in L^2(\nu+\mu)$，使 $\int f\,d\nu=\int fg\,d(\nu+\mu)$。分别用 $\{g\ge1\}$ 与 $\{g<0\}$ 的指示函数测试，可在零测集上修改 $g$ 后假设 $0\le g<1$。令 $h=g/(1-g)$，用截断函数逼近 $\mathbb{1}_E/(1-g)$，再由 MCT 得 $\nu(E)=\int_E h\,d\mu$。
- **σ-有限控制测度的拼接**：取 $X_k\uparrow X$ 且 $\mu(X_k)<\infty$，在每个 $X_k$ 上得到密度 $h_k$。有限情形的 a.e. 唯一性保证 $h_j=h_k$ 于 $X_j$ a.e.（$j<k$），因此可拼成全局可测 $h$；再用 MCT 从 $E\cap X_k$ 推到任意 $E$。
- **符号/复测度情形**：对有限符号测度使用 Jordan 分解，分别表示正负部分；复测度再分别处理实部和虚部。这里不能直接把正测度证明中的“$h\ge0$”原样套到一般符号测度。
- **唯一性**：若 $h_1,h_2\in L^1(\mu)$ 都表示 $\nu$，则对 $E_m=\{h_1\ge h_2+1/m\}$ 有 $\int_{E_m}(h_1-h_2)\,d\mu=0$，从而 $\mu(E_m)=0$。取可数并得到 $\mu\{h_1>h_2\}=0$，交换二者即得 a.e. 相等。
- **条件期望的存在性**：对 $X\in L^1$，在子 σ-代数 $\mathcal{G}$ 上定义有限符号测度 $\nu(G)=\int_GX\,dP$。它满足 $\nu\ll P|_{\mathcal G}$，故符号测度版 RN 给出 $\mathcal G$-可测 $Y\in L^1$，且 $\int_GY\,dP=\int_GX\,dP$；这正是 $E[X\mid\mathcal G]$。若只陈述正测度版 RN，则必须分别对 $X^+$ 与 $X^-$ 应用定理后相减。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：$X = [0,1]$，$m$ 为 Lebesgue 测度，$\nu(E) = \int_E x\,dm$。求 $d\nu/dm$ 并验证。
- **解题思路与关键步骤**：显然 $\nu \ll m$（零测集上积分为 0），RN 导数即被积函数 $f(x) = x$。验证：$\nu([0, 1/2]) = \int_0^{1/2} x\,dx = 1/8$；用密度：$\int_{[0,1/2]} x\,dm = 1/8$ ✓。
- **最终答案**：$d\nu/dm = x$，$\nu([a,b]) = (b^2 - a^2)/2$。
- **易错点**：把"$\nu \ll \mu$ 存在密度"与"密度连续"混为一谈——$f$ 只需可测，$\mathbb{1}_A$ 这类不连续函数同样合法。
- **🤔 追问**：若 $\nu(E) = \int_E \mathbb{1}_{\mathbb{Q}\cap[0,1]}\,dm$？——$\nu \equiv 0$（被积函数 a.e. 为 0），密度 a.e. 为 0。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：$X, Y$ 为离散随机变量，$X \in \{a_1, a_2\}$ 各以概率 $1/2$，$\mathcal{G} = \sigma(X)$。求 $E[Y|\mathcal{G}]$。$\mathcal{G}$-可测函数必形如 $c_1\mathbb{1}_{\{X=a_1\}} + c_2\mathbb{1}_{\{X=a_2\}}$；由公理 (ii) 在 $\{X = a_i\}$ 上：$c_i P(X = a_i) = \int_{\{X=a_i\}} Y\,dP = E[Y \cdot \mathbb{1}_{\{X=a_i\}}]$，故 $c_i = E[Y | X = a_i]$（经典条件期望）。**结论**：$E[Y|\mathcal{G}] = E[Y|X=a_1]\mathbb{1}_{\{X=a_1\}} + E[Y|X=a_2]\mathbb{1}_{\{X=a_2\}}$——离散情形的条件期望是"按 $X$ 的取值逐块取平均"，$\mathcal{G}$-可测性就是"只依赖 $X$ 的信息"。

### 例子 3：实际应用 + 反例——非绝对连续时无密度
- **题目**：$\nu = \delta_0$（Dirac 点质量）于 $(\mathbb{R}, \mathcal{B}, m)$。$\nu \ll m$ 是否成立？密度存在吗？
- **关键步骤**：$m(\{0\}) = 0$ 但 $\nu(\{0\}) = 1$，故 $\nu \not\ll m$。若存在 $f$ 使 $\nu(E) = \int_E f\,dm$，取 $E = \{0\}$：$1 = \nu(\{0\}) = \int_{\{0\}} f\,dm = 0$，矛盾。
- **反例结论**：**点质量对 Lebesgue 测度无密度**——$\delta_0$ 拥有 $m$ 看不到的信息（"$x$ 恰为 0"是 $m$-零测事件）。更强的反例：Cantor 测度 $\mu_C$ 满足 $m(C)=0$、$\mu_C(C)=1$，故 $\mu_C\perp m$；但 $\mu_C(\{x\})=0$ 对每个单点。无密度不能只靠单点原子检测，这正是奇异连续测度。

## 8. 常见误区和易混概念

### 误区 1：以为"$\nu \ll \mu$ 就是 $\nu(E) \le \mu(E)$ 对一切 $E$"
- **错误直觉**：绝对连续 = 点态小。
- **为什么错**：$\nu = 2\mu$ 满足 $\nu \ll \mu$（$\mu$-零集必为 $\nu$-零集）但 $\nu(E) = 2\mu(E) > \mu(E)$。
- **正确理解**：$\nu \ll \mu$ 只约束**零测集**；大小关系由密度 $f = d\nu/d\mu$ 的取值决定（$f$ 可任意大）。

### 误区 2：以为"$E[X|\mathcal{G}]$ 是一个数"
- **错误直觉**：条件期望 = "给定 $X = x$ 时的平均"，是个数值。
- **为什么错**：$\mathcal{G}$ 只给"部分信息"（如只看 $X$ 的符号），$E[X|\mathcal{G}]$ 必须对每个 $\mathcal{G}$-事件取平均——整体是一个 $\mathcal{G}$-可测**随机变量**。
- **正确理解**：离散情形它是"逐块常数"的变量；$E[X]$ 是 $E[X|\{\emptyset,\Omega\}]$ 的特例（平凡 $\sigma$ 代数，信息为 0）。

### 条件变式（本路径特色）
- **变式 1（不能从统一定理中删除 $\sigma$-有限）**：取 $\mu$ 为 $[0,1]$ 上的计数测度（非 $\sigma$-有限）、$\nu=m$。虽然 $\nu\ll\mu$，若存在密度 $f$，对每个单点积分都迫使 $f(x)=0$，从而不能表示非零的 $\nu$。这说明去掉 σ-有限后 RN 结论可能失败；并不表示每一对非 σ-有限测度都没有密度。
- **变式 2（Lebesgue 分解）**：去掉绝对连续：$\nu = \nu_{ac} + \nu_s$ 唯一分解，$\nu_{ac} \ll \mu$、$\nu_s \perp \mu$——$\delta_0 = 0 + \delta_0$，纯奇异部分。
- **变式 3（条件期望版本）**：塔性质 $E[E[X|\mathcal{G}_1]|\mathcal{G}_2] = E[X|\mathcal{G}_2]$（$\mathcal{G}_2 \subset \mathcal{G}_1$）；可测因子提出 $E[ZX|\mathcal{G}] = ZE[X|\mathcal{G}]$（$Z$ $\mathcal{G}$-可测且满足相应可积条件）；条件 Jensen 为 a.s. 不等式。条件 MCT 与条件 DCT 也以 a.s. 相等/收敛陈述，而不是逐点恒等式。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| $\nu \ll \mu$ | $\mu$-零集必为 $\nu$-零集 | 配合 σ-有限性与有限变差得到 RN 密度 | 密度存在性判据 |
| $\nu \perp \mu$ | 支撑互斥 | 无密度（最坏情形） | $\delta_0$、Cantor 测度 |
| 密度 $d\nu/d\mu$ | 逐点汇率 | 模 a.e. 唯一 | 测度变换、贝叶斯 |
| 条件期望 $E[X\mid\mathcal{G}]$ | 信息受限的最优估计 | 是变量不是数 | 鞅、统计推断 |

### 题目与解析

#### 1. 判断：$\nu(E) = \int_E x^2\,dm$（$E \subset [0,1]$）是否绝对连续于 $m$？$\delta_0$ 呢？
> [!question]- 答案解析
> - **答案**：$\nu \ll m$（$m(E) = 0 \Rightarrow \int_E x^2 = 0$），密度 $d\nu/dm = x^2$；$\delta_0 \not\ll m$（$m(\{0\}) = 0$ 但 $\delta_0(\{0\}) = 1$）。
> - **解析**：绝对连续只看零测集；积分定义的测度自动绝对连续。
> - **易错原因**：用"$\nu$ 是否小于 $\mu$"判断绝对连续。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 设 $d\nu/dm = x^2$ 于 $[0,1]$，求 $\nu([0, 1/2])$。
> [!question]- 答案解析
> - **答案**：$\nu([0,1/2]) = \int_0^{1/2} x^2\,dx = [x^3/3]_0^{1/2} = 1/24$。
> - **解析**：密度积分的直接代入；$m$ 限制到 $[0,1]$ 与普通 Riemann 积分一致。
> - **易错原因**：忘记先验证 $\nu \ll m$ 再套 RN（本例显然成立）。

#### 3. 判断：$\mu$ 为 $[0,1]$ 上计数测度（非 $\sigma$-有限），$\nu = m$ 限制。$\nu \ll \mu$ 吗？RN 定理为何不适用？
> [!question]- 答案解析
> - **答案**：$\nu \ll \mu$（$\mu(E) = 0 \Rightarrow E = \emptyset$）；但 $\mu$ 非 $\sigma$-有限，RN 定理结论失败：若 $\nu(E) = \int_E f\,d\mu$，取 $E = \{x\}$ 得 $0 = \nu(\{x\}) = f(x)$ 对一切 $x$，则 $\nu \equiv 0$，矛盾。
> - **解析**：该反例说明 σ-有限性不能从一般 RN 定理中直接删除；计数测度在单点上过细，任何候选密度都被迫逐点为零。
> - **易错原因**：只验证 $\nu \ll \mu$ 就断言密度存在。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 证明题：证明 RN 导数的唯一性：若 $f,g\in L^1(\mu)$ 且 $\int_E f\,d\mu=\int_E g\,d\mu$ 对一切可测 $E$，则 $f=g$ a.e.。
> [!question]- 答案解析
> - **答案**：对每个 $m\ge1$ 令 $E_m=\{f\ge g+1/m\}$。由表示相同和 $f,g\in L^1$，有 $0=\int_{E_m}(f-g)\,d\mu\ge\mu(E_m)/m$，故 $\mu(E_m)=0$。因为 $\{f>g\}=\bigcup_mE_m$，所以 $\mu\{f>g\}=0$；交换 $f,g$ 得结论。
> - **解析**：非负函数在正集合上的积分为 0 ⟹ 集合零测——这是"积分决定函数（a.e.）"的标准杠杆。
> - **易错原因**：忘记先取 $E = \{f > g\}$（可测性由 $f, g$ 可测保证），直接断言逐点相等。
> - **Obsidian 标签建议**：`#自测题/较难`

#### 5. 反例构造：构造 $\nu \not\ll m$（$m$ 为 Lebesgue 测度）并证明 $\nu$ 无密度；再举一个 $\nu(\{x\}) = 0$ 对单点却仍无密度的例子。
> [!question]- 答案解析
> - **答案**：$\nu = \delta_0$：$m(\{0\}) = 0$，$\nu(\{0\}) = 1$，故 $\nu \not\ll m$；若 $\nu(E) = \int_E f\,dm$，取 $E = \{0\}$ 得 $1 = 0$，矛盾。更强反例：Cantor 测度 $\mu_C$：$\mu_C \perp m$（Cantor 集 $C$：$m(C) = 0$ 而 $\mu_C(C) = 1$），故无密度，但 $\mu_C(\{x\}) = 0$ 对每个单点——无密度不能靠"单点质量"检测。
> - **解析**：奇异连续测度"把质量放在零测但稠密的 Cantor 集上"，是 $\delta_0$ 与 Lebesgue 之间的第三形态。
> - **易错原因**：以为"无密度 ⟺ 存在单点正质量"。
> - **Obsidian 标签建议**：`#自测题/较难`
