# 单调收敛定理与积分收敛

---
## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：三大收敛定理（MCT / Fatou / DCT）是 Lebesgue 积分一切“极限与积分交换”操作的法律依据；[[测度论-阶段作业-02-积分与收敛证明档案]] 围绕它们验收。后续 `L^p` 完备性使用 MCT/DCT，Axler 的 RN 证明也在截断极限步骤调用 MCT。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 黎曼积分下"$\lim \int f_n = \int \lim f_n$"几乎从不成立：$f_n = n \cdot \mathbb{1}_{(0,1/n)}$ 逐点趋于 0，但 $\int f_n = 1$ 不趋于 0。而概率论（期望的极限定理）、Fourier 分析（逐项积分）都要求极限与积分可交换。
> 因此必须重新定义积分（Lebesgue 积分：简单函数 → 非负函数 → 一般可测函数），并给出三条**收敛定理**：何时极限与积分可交换（MCT、DCT），交换失败时还剩下什么（Fatou 不等式）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：三大收敛定理是 `L^p` 完备性与乘积积分的直接前提；Axler 的 RN Hilbert 空间证明在把截断测试函数放回积分时使用 MCT；条件期望的存在性则是 RN 定理的推论。
- **实际应用场景**：概率论中"期望与极限交换"（Borel-Cantelli、强大数定律证明）、Fubini 定理（累次积分交换）、遍历平均收敛。
- **高频题型/任务**：验证 DCT 控制条件后交换极限与积分；用 MCT 计算单调函数列的积分；构造 Fatou 严格不等号反例；把积分的可数可加性归结为 MCT。

---
## 3. 学它之前需要哪些前置知识？

1. **[[测度论-Lebesgue测度与可测集]]**：积分定义在测度空间 $(\mathbb{R}^d, \mathcal{L}, m)$ 上；零测集、可测集概念直接复用。
2. **[[测度论-可测函数与简单函数|简单函数与可测函数]]**：简单函数 $\sum_i a_i \mathbb{1}_{E_i}$ 是积分的起点；可测函数四条件判别。

---

## 4. 用直觉语言解释它

> «Lebesgue 积分像"按楼层数钱"：把函数的值域切成水平条，每层"条宽 × 楼层面积（测度）"累加；MCT 说的是"楼层从下往上逐层加高时，总钱数也单调逼近极限"——因为每一层只增不减，先加哪一层都不会出错。»

- **直觉类比/几何图像**：黎曼积分"竖着切"（按定义域切条），Lebesgue 积分"横着切"（按值域切层）；横切让"只在零测集上抖动"的函数差异被忽略。
- **为什么很自然**：非负函数的积分定义为"简单函数积分的上确界"，而 MCT 本质是"上确界换序"：$\sup_n \sup_k (\text{前 } k \text{ 层和}) = \sup_k \sup_n (\text{前 } k \text{ 层和})$——单调性保证换序合法。
- **一句话直觉本质**：**先对简单函数定义积分，再用上确界/正负部把一般函数"夹"出来；MCT 把"极限与积分交换"变成"上确界换序"，Fatou 是它的自动推论，DCT 再加一层"控制"把不等式升级为等式。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **非负简单函数积分**：$s=\sum_{i=1}^k a_i\mathbb{1}_{E_i}$，其中 $a_i\ge0$、$E_i$ 两两不交可测，定义 $\int s\,d\mu=\sum_i a_i\mu(E_i)$。一般符号简单函数再用正负部分定义，并排除 $\infty-\infty$。
- **非负可测函数积分**：$\int f\,dm = \sup\left\{ \int s\,dm : 0 \le s \le f,\ s \text{ 为简单函数} \right\}$。
- **一般可测函数积分**：$f = f^+ - f^-$，$\int f = \int f^+ - \int f^-$（至少一个有限）；$\int |f| < \infty$ 时称 $f$ **可积**（$f \in L^1$）。

### 2. 核心公式（三大收敛定理）
$$\text{MCT: } 0 \le f_1 \le f_2 \le \cdots,\ f_n \uparrow f \ \text{a.e.} \implies \int f_n \uparrow \int f$$
$$\text{Fatou: } f_n \ge 0 \implies \int \liminf_n f_n \le \liminf_n \int f_n$$
$$\text{DCT: } f_n \to f \ \text{a.e.},\ |f_n| \le g,\ g \text{ 可积} \implies \lim_n \int f_n = \int f$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $f^+, f^-$ | 正部 / 负部 | 非负可测 | $f = f^+ - f^-$ |
| $\mathbb{1}_E$ | 指示函数 | $\{0, 1\}$ | 简单函数的基本砖块 |
| $\int$ | Lebesgue 积分 | $[-\infty, +\infty]$ | 对一切非负可测函数有定义 |
| $g$ | DCT 的控制函数 | 非负可积 | 缺它 DCT 失效 |

### 4. 常见变体与适用条件
- **适用条件**：MCT 要求非负单调；DCT 要求 a.e. 收敛 + 可积控制；Fatou 只要求非负。
- **限制条件**：MCT 的非负性不可去掉；DCT 的 $g$ 必须与 $n$ 无关且可积。
- **条件变式**：在有限测度空间（特别是概率空间）上，DCT 可推广为“依测度收敛 + 一致可积”所给出的 Vitali 收敛定理；一般无限测度空间还需要防止质量逃逸到无穷远。Fatou 对任意测度成立。

## 6. 推导思路和思想来源

- **最初困难**：黎曼积分对逐点极限不封闭，"$\lim\int \ne \int\lim$"的失败例子比比皆是。
- **直接方法局限**：想"先定义好积分，再讨论交换极限"行不通——积分与极限天然纠缠。
- **关键"转念"**：**把顺序倒过来：先用上确界（而非极限）定义积分**。非负函数的积分是"所有下方简单函数积分的上确界"，于是"极限与积分交换"变成了"两个上确界交换"——单调性使 $\sup_n \sup_k = \sup_k \sup_n$ 无条件成立，MCT 一步到位。
- **推导主线与动机**：简单函数（线性、单调）→ 非负函数（上确界）→ 一般函数（正负部，可积性由 $\int|f|$ 判定）→ **MCT 证明**：设 $f = \lim_n f_n$（单调升）。对任一简单函数 $0 \le s \le f$ 与 $0 < c < 1$，令 $E_n = \{f_n \ge cs\}$，则 $E_n \uparrow$ 且并满全空间；由测度从下连续与简单函数积分线性性，$\int f_n \ge c \int s\,\mathbb{1}_{E_n} \to c\int s$，令 $c \uparrow 1$ 再对 $s$ 取上确界得 $\liminf_n \int f_n \ge \int f$；反向 $\le$ 由 $f_n \le f$ 平凡成立 → **Fatou 是 MCT 的推论**（令 $g_n = \inf_{k \ge n} f_k$，$g_n \uparrow \liminf f_k$）→ **DCT 由 Fatou 推出**（对 $g \pm f_n$ 分别用 Fatou，两条不等式夹出 $\lim \int f_n = \int f$）。
- **为什么自然得到此结论**：三个定理是一个链条——MCT 给等式，Fatou 是"去掉单调性后剩下的不等式残骸"，DCT 用控制函数 $g$ 把 Fatou 的两个方向都补齐。**背一条 MCT 证明主线，三定理全通。**

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：计算 $f = \mathbb{1}_{\mathbb{Q}\cap[0,1]}$（Dirichlet 函数）的 Lebesgue 积分。
- **解题思路与关键步骤**：$\mathbb{Q}\cap[0,1]$ 可数故零测（见 [[测度论-Lebesgue测度与可测集]] 例子 1）；$f$ 本身是简单函数：$\int f = 1 \cdot m(\mathbb{Q}\cap[0,1]) = 0$。
- **最终答案**：$\int f = 0$；而黎曼意义下 $f$ 不可积——这是"Lebesgue 积分忽略零测集抖动"的第一课。
- **易错点**：误以为 $\mathbb{Q}$ 在 $[0,1]$ 稠密所以"到处都是 1"——测度论里稠密 ≠ 正测度。
- **🤔 追问**：若换成 $f = \mathbb{1}_C$（Cantor 集）？——同样为 0（$m(C) = 0$）。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：求 $\lim_n \int_0^1 \frac{nx}{1+n^2x^2}\,dx$，并说明用哪条定理。
- **解题思路与完整解答**：逐点极限：$x=0$ 时为 0；$x>0$ 时 $\frac{nx}{1+n^2x^2} \le \frac{1}{nx} \to 0$，故逐点收敛到 0。控制：$1 + n^2x^2 \ge 2nx$ 给出 $\frac{nx}{1+n^2x^2} \le \frac{1}{2}$，常数 $\frac12$ 在 $[0,1]$ 上可积。由 DCT：$\lim \int f_n = \int 0 = 0$。
- **易错点**：试图用 MCT——函数列不单调；"先积分再取极限"也可以算，但 DCT 一行给出答案且自动处理 $x=0$。

### 例子 3：实际应用 + 反例——控制函数不存在时 Fatou 仍成立但等式失效
- **题目**：$f_n = n \cdot \mathbb{1}_{(0, 1/n)}$（$n \ge 1$），在 $[0,1]$ 上比较 $\lim \int f_n$ 与 $\int \lim f_n$。
- **关键步骤**：$\int f_n = n \cdot m((0, 1/n)) = n \cdot \frac{1}{n} = 1$；对每个 $x > 0$，取 $n > 1/x$ 即 $f_n(x) = 0$，故逐点 $\lim_n f_n = 0$，$\int \lim f_n = 0$。
- **反例结论**：$\lim \int f_n = 1 \ne 0 = \int \lim f_n$，**极限与积分不可交换**；但 Fatou 仍成立且取严格不等号：$\int \liminf f_n = 0 < \liminf \int f_n = 1$。DCT 不可用：唯一候选控制 $\sup_n f_n$ 处处无有限可积上界（在 $(0,1/n)$ 上高达 $n$）。**这是"控制函数不存在时等式失效、不等式保留"的标本。**

## 8. 常见误区和易混概念

### 误区 1：以为 Fatou 保证等式
- **错误直觉**：Fatou 也是"收敛定理"，$\lim \int f_n = \int \lim f_n$ 应该成立。
- **为什么错**：例子 3 说明严格不等号是常态；Fatou 只保证"积分下极限 ≥ 下极限积分"。
- **正确理解**：Fatou 是 DCT 的前置引理；要等式必须补单调性（MCT）或控制（DCT）。

### 误区 2：DCT 只要"逐点收敛"就行
- **错误直觉**：$f_n \to f$ 逐点，就能交换极限与积分。
- **为什么错**：$f_n = n\mathbb{1}_{(0,1/n)}$ 逐点收敛到 0 但积分不收敛——缺的是"被某个可积函数控制"。
- **正确理解**：DCT 三条件（可测、a.e. 收敛、可积控制）缺一不可；控制函数必须与 $n$ 无关。

### 条件变式（本路径特色）
- **变式 1（MCT 去掉非负性）**：$f_n = -\mathbb{1}_{[n, \infty)}$ 单调升到 0，但 $\int f_n = -\infty$ 而 $\int \lim f_n = 0$——非负性是 MCT 的硬条件。
- **变式 2（DCT 放松）**：在有限测度空间上，把 a.e. 收敛换成依测度收敛、把单一控制函数换成一致可积，可得 Vitali 收敛定理；在无限测度空间上必须再控制质量逃逸。
- **变式 3（Fatou 用于概率）**：Fatou 对概率测度同样成立——条件期望与鞅收敛定理的不等式地基。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| MCT | 单调非负列 | 等式，不需控制 | 构造积分、证明可数可加 |
| Fatou | 非负列 | 仅不等式 | 证明 DCT、下极限估计 |
| DCT | a.e. 收敛 + 控制 | 等式，条件最强 | 交换极限与积分 |
| 黎曼积分 | 竖切、逐段光滑 | 对逐点极限不封闭 | 初等微积分 |

### 题目与解析

#### 1. 黎曼积分与 Lebesgue 积分最本质的区别是什么？
> [!question]- 答案解析
> - **答案**：切法不同：黎曼按定义域"竖切"，Lebesgue 按值域"横切"（层叠法）；因此 Lebesgue 积分对逐点极限封闭（在收敛定理条件下）。
> - **解析**：Dirichlet 函数黎曼不可积、Lebesgue 积分为 0。
> - **易错原因**：误以为区别只是"允许无界函数"。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 计算 $\int \left(2\mathbb{1}_{[0,1]} + 3\mathbb{1}_{(1,2]}\right)\,dm$。
> [!question]- 答案解析
> - **答案**：$2 \cdot m([0,1]) + 3 \cdot m((1,2]) = 2 + 3 = 5$。
> - **解析**：两区间不交，直接用线性性。
> - **易错原因**：担心端点——单点零测，开闭写法不影响结果。

#### 3. 判断：$f_n = \frac{1}{n}\mathbb{1}_{[0,n]}$ 能否用 DCT 求 $\lim_n \int f_n$？
> [!question]- 答案解析
> - **答案**：不能直接套 DCT。对 $x>0$，$\sup_n f_n(x)=1/\lceil x\rceil$（在 $x=0$ 时上确界为 1），其积分按单位区间给出调和级数并发散，因此不存在可积控制。但 $\int f_n=1$ 恒成立，而逐点极限为 0——又一个 Fatou 严格不等式实例。
> - **解析**：看到"收敛"就套 DCT 是典型失误，必须检查控制函数。
> - **易错原因**：不验证控制函数是否存在。

#### 4. 证明题：用 MCT 证明 Fatou 引理。
> [!question]- 答案解析
> - **答案**：令 $g_n = \inf_{k \ge n} f_k$，则 $g_n \uparrow \liminf_k f_k$ 且 $0 \le g_n \le f_n$，故 $\int g_n \le \int f_n$。由 MCT：$\int \liminf f_k = \lim_n \int g_n \le \liminf_n \int f_n$。
> - **解析**：$\liminf$ 本质是"先逐点取下确界再取极限"，天然单调，MCT 一击命中。
> - **易错原因**：忘记构造 $g_n$（直接对 $f_n$ 用 MCT 条件不满足）。
> - **Obsidian 标签建议**：`#自测题/较难`

#### 5. 反例构造：构造 $f_n \ge 0$ 使 Fatou 取严格不等号，并说明 DCT 为何失效。
> [!question]- 答案解析
> - **答案**：$f_n = n\mathbb{1}_{(0,1/n)}$：$\lim \int f_n = 1 > 0 = \int \lim f_n$；DCT 失效因为没有与 $n$ 无关的可积控制函数（$\sup_n f_n$ 在 $(0,1/n)$ 上高达 $n$）。
> - **解析**：质量"逃逸"到 $x \to 0$ 附近；Fatou 仍给出 $0 \le 1$。
> - **易错原因**：想用 $g \equiv 1$ 控制——$f_n$ 取值可达 $n$，不被 1 控制。
> - **Obsidian 标签建议**：`#自测题/较难`
