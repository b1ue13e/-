> [!NOTE] 核心直觉：坐标降维映射
> **类比**：就像把城市中错综复杂的立交桥和地铁网络（高维复杂的拓扑图），映射到手机地图上的经纬度坐标（低维稠密向量）。通过这种映射，网络中连接紧密、拓扑结构相近的节点，它们的“坐标”距离也十分接近。网络嵌入就是给每个节点分配一个向量坐标，把复杂的图问题转化为简单的空间几何问题。

## 1. 为什么需要这个知识点？
- **背景**：在图挖掘任务中，传统的特征工程需要手工设计网络指标（如度、中心性），或者直接使用邻接矩阵表示图拓扑。
- **痛点**：邻接矩阵非常稀疏且维度极高，会导致维度灾难，并难以捕捉网络的高阶连接模式。手工特征则难以全面覆盖复杂的拓扑结构特征。
- **意义**：将节点映射到低维、稠密的连续向量空间中（即嵌入特征），这些向量可以直接无缝接入标准的机器学习模型（如逻辑回归、SVM、XGBoost），极大地提升了链接预测和社区发现的精度与计算效率。

## 2. 核心定义与公式/代码
**图嵌入（Graph Embedding）**：
寻找一个映射函数 $f: V \to \mathbb{R}^d$，将节点 $v \in V$ 映射为 $d$ 维稠密向量（其中 $d \ll |V|$）。

**优化目标（以 DeepWalk 为例）**：
基于 Skip-Gram 模型，最大化在网络中通过随机游走策略 $S$ 得到的上下文节点共现概率：
$$ \max_f \sum_{v \in V} \log P(N_S(v) | f(v)) $$
其中 $N_S(v)$ 表示节点 $v$ 在随机游走中的上下文邻居节点集。

**Python 代码示例（使用 Node2Vec 提取嵌入特征）**：
```python
import networkx as nx
from node2vec import Node2Vec

# 1. 创建图结构
G = nx.fast_gnp_random_graph(n=100, p=0.05)

# 2. 初始化 Node2Vec 模型
# p: Return hyperparameter, q: Inout hyperparameter
node2vec = Node2Vec(G, dimensions=64, walk_length=30, num_walks=200, workers=4, p=1, q=1)

# 3. 拟合模型，生成随机游走并学习向量嵌入
model = node2vec.fit(window=10, min_count=1, batch_words=4)

# 4. 获取特征以供下游预测
node_id = '1'
embedding_vector = model.wv[node_id] 
print(f"Node {node_id} embedding shape: {embedding_vector.shape}")
```

## 3. 具体应用案例
**场景：社交网络的好友推荐（链接预测）**
在社交平台中，系统需要预测用户 A 和用户 B 未来是否会产生关注或好友关系。通过图嵌入算法，我们计算出所有用户的 $d$ 维嵌入特征。
对于待预测的用户对 $(A, B)$，我们将他们的向量 $\mathbf{e}_A$ 和 $\mathbf{e}_B$ 融合成一条边的特征：
- **Hadamard (逐元素乘积)**: $\mathbf{e}_A \odot \mathbf{e}_B$
- **L1/L2 距离权重**: $|\mathbf{e}_A - \mathbf{e}_B|$
得到边的稠密特征后，可以输入给二分类模型（如逻辑回归、随机森林），由分类器来预测 A 和 B 之间存在隐性链接的概率。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **认为嵌入维度越大越好**: 这是一个误区。如果嵌入维度过高，会引入大量噪声并导致计算开销剧增，容易在下游分类任务中严重过拟合。对于一般规模的社交网络，维度 $d$ 选择在 64 到 256 之间通常是最优解。
> - **忽略静态嵌入处理动态图的缺陷**: DeepWalk 和 Node2Vec 是直推式（Transductive）学习。如果社交网络中出现了新注册的用户（新节点），这些模型无法直接生成新节点的特征，必须重新游走和训练整个网络。在动态网络中应考虑归纳式（Inductive）方法（如 GraphSAGE）。
