> [!NOTE] 核心直觉：社交雷达
> **类比**：想象你在一场大型酒会上（社交网络），你想判断两个人是否会成为朋友（链接预测）。你会怎么做？你会看他们是不是认识很多相同的人（共同好友），或者他们各自是不是交际花（节点度数），甚至他们认识的朋友是不是都很有分量（Adamic-Adar）。拓扑特征工程就是把这种“看面相”和“查户口”的直觉，量化成数学指标。

## 1. 为什么需要这个知识点？
- **背景**：在图挖掘任务（如链接预测、推荐系统、节点分类）中，我们通常需要将复杂的图结构转化为机器学习模型可以理解的表格数据或特征向量。
- **痛点**：传统的深度学习模型（如MLP）无法直接处理非欧几里得的图结构。如果不提取拓扑特征，只用节点自身的属性（如年龄、性别），会完全忽略掉网络中的连接信息，导致预测效果极差。
- **意义**：拓扑特征工程通过手工设计一系列数学指标，直接捕获节点之间的局部和全局结构关系。它是图表示学习（如Graph Embedding、GNN）之前最经典、最具解释性的特征提取方法，至今仍在许多工业级风控、推荐场景中作为强基线（Baseline）或补充特征广泛使用。

## 2. 核心定义与公式/代码
在链接预测任务中，给定节点对 $(u, v)$，常用的拓扑特征分为以下几类：

### 1. 基于节点邻居的局部特征 (Local Neighborhood Features)
设 $N(u)$ 为节点 $u$ 的邻居节点集合，$k_u = |N(u)|$ 为节点 $u$ 的度数。

- **Common Neighbors (CN, 共同邻居)**：
  $$CN(u,v) = |N(u) \cap N(v)|$$
  直觉：你们共同好友越多，你们越可能认识。
  
- **Jaccard Coefficient (杰卡德系数)**：
  $$Jaccard(u,v) = \frac{|N(u) \cap N(v)|}{|N(u) \cup N(v)|}$$
  直觉：对共同好友数量进行归一化，惩罚了那些度数极大（交际花）的节点。

- **Adamic-Adar Index (AA指标)**：
  $$AA(u,v) = \sum_{z \in N(u) \cap N(v)} \frac{1}{\log(k_z)}$$
  直觉：共同好友越“社恐”（度数小），这个共同好友对你们两人产生联系的贡献越大；而像“马化腾”这样的共同好友，对建立你们俩私人联系的贡献就没那么大。

- **Preferential Attachment (PA, 优先链接)**：
  $$PA(u,v) = k_u \times k_v$$
  直觉：“富者愈富”。两个度数很高的人，即使没有共同好友，他们产生连接的概率也高于两个边缘人。

### 代码实现 (基于 NetworkX)
```python
import networkx as nx

# 假设 G 是一个无向图，且要预测节点对 (u, v) 的特征
G = nx.karate_club_graph()
preds_jaccard = nx.jaccard_coefficient(G, [(0, 33)])
for u, v, p in preds_jaccard:
    print(f"({u}, {v}) 的 Jaccard 系数: {p}")
    
preds_aa = nx.adamic_adar_index(G, [(0, 33)])
for u, v, p in preds_aa:
    print(f"({u}, {v}) 的 AA 指标: {p}")
```

### 2. 基于路径的全局特征 (Global Path Features)
- **Katz Index**：考虑了所有长度的路径，短路径权重高，长路径权重低。
- **PageRank**：评估节点在全图中的重要性。

## 3. 具体应用案例
**场景**：微信的好友推荐系统（你可能认识的人）。
- **步骤1（候选集召回）**：遍历网络，找出和你距离为2的节点（即朋友的朋友，有共同好友）。
- **步骤2（特征工程）**：计算你与这些候选人的 Common Neighbors、Jaccard 系数和 Adamic-Adar 指标。
- **步骤3（模型打分）**：将这些拓扑特征输入到 XGBoost 或 Logistic Regression 模型中，得出预测概率。
- **结果**：系统发现你和张三有15个共同好友（高CN），且这些好友大多只认识你们俩（高AA），于是高优先级向你推荐张三。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **只用局部特征忽略全局**：共同好友类的特征（CN, Jaccard）只能处理距离为2的节点对。如果两个节点距离为3，它们的CN特征全为0，模型就失效了，此时必须引入 Katz 等全局特征或 GNN。
> - **数据穿越（Data Leakage）**：在提取特征时，如果不小心把测试集中要预测的那条边（链接）算进了度数或共同邻居中，会导致模型过拟合，线上效果暴跌。一定要在残缺图（移除待预测边）上计算拓扑特征！
> - **时间复杂度爆炸**：在大规模图中，计算所有节点对的全局路径特征（如Katz）极其缓慢，工业上常采用局部近似或者随机游走采样来加速。
