# 模块度

模块度（modularity）衡量一个给定社区划分中的**社区内边数量，相比保持节点度数的随机零模型超出了多少**。它评估的是划分，不是单个节点，也不是无需基线的“内部边比例”。

## 1. 无向图定义

设无向图邻接矩阵为 $A$，节点 $i$ 的度为 $k_i$，边数为 $m$，社区标签为 $c_i$。经典 Newman–Girvan 模块度为

$$
Q=\frac{1}{2m}\sum_{i,j}\left(A_{ij}-\frac{k_i k_j}{2m}\right)\delta(c_i,c_j),
$$

其中 $\delta(c_i,c_j)=1$ 表示两节点属于同一社区，否则为 0。$k_i k_j/(2m)$ 是配置模型下 $i,j$ 之间边数的期望项。

也可按社区写成

$$
Q=\sum_c\left(\frac{l_c}{m}-\left(\frac{d_c}{2m}\right)^2\right),
$$

$l_c$ 是社区 $c$ 内部边数，$d_c$ 是该社区节点度数之和。第一项是真实内部边占比，第二项是零模型期望。

## 2. 最小算例

图由两个三角形组成，并用一条桥连接：左侧三角形和右侧三角形各有 3 条内部边，总边数 $m=7$。按两个三角形划分时，每个社区的度数和都是 7，因此

$$
Q=2\left(\frac{3}{7}-\left(\frac{7}{14}\right)^2\right)
=2\left(\frac37-\frac14\right)
=\frac{5}{14}\approx0.357.
$$

若把所有节点放在同一社区，$Q=1-1=0$。因此两社区划分相对该零模型更能体现内部聚集。

```python
import networkx as nx
from networkx.algorithms.community.quality import modularity

G = nx.Graph([(0, 1), (1, 2), (2, 0),
              (3, 4), (4, 5), (5, 3), (2, 3)])
q = modularity(G, [{0, 1, 2}, {3, 4, 5}])
assert abs(q - 5 / 14) < 1e-12
```

## 3. 模块度优化

社区发现算法可搜索使 $Q$ 较大的划分。[[02-Knowledge/🧠 学习系统/01-社交网络挖掘/03-社区发现与链接预测/Louvain算法|Louvain 算法]]通过局部移动节点和聚合社区近似优化模块度。但最大化问题是组合优化，启发式算法可能得到不同局部最优；应固定随机种子并报告稳定性。

## 4. 分辨率参数

常见推广形式引入 $\gamma$：

$$
Q(\gamma)=\frac{1}{2m}\sum_{i,j}\left(A_{ij}-\gamma\frac{k_i k_j}{2m}\right)\delta(c_i,c_j).
$$

增大 $\gamma$ 通常偏向更细划分，减小则偏向更粗划分。比较结果时必须报告 $γ$，不能只报告一个 $Q$ 值。

## 5. 边界与误区

1. **分辨率极限**：标准模块度可能合并规模较小但结构清晰的社区，详见[[02-Knowledge/🧠 学习系统/01-社交网络挖掘/03-社区发现与链接预测/分辨率极限|分辨率极限]]。
2. 高模块度不自动证明社区具有统计显著性；应与合适的随机图或置换基线比较。
3. 不同规模、密度或零模型下的 $Q$ 不宜直接横向比较。
4. 有向图、带权图和二部图需要对应的模块度定义，不能无说明地套用无向无权公式。
5. 社区的业务意义仍需外部标签或稳定性分析验证，参见[[02-Knowledge/🧠 学习系统/01-社交网络挖掘/03-社区发现与链接预测/社区定义|社区定义]]。

## 6. 验证清单

- 手算一个小图并与库函数结果一致。
- 将所有节点放入一个社区，确认经典公式得到 $Q=0$。
- 改变桥边数量，观察两社区划分的 $Q$ 是否下降。
- 用多个随机种子重复启发式算法，检查划分和 $Q$ 的稳定性。
