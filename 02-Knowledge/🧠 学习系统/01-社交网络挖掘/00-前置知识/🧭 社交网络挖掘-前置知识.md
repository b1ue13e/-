# 🧭 社交网络挖掘前置知识

## 为什么先做这一层

本课程同时使用图遍历、随机实验、矩阵传播和二分类评估。前置层不要求先修完整的算法、概率、线性代数或深度学习课程，只补到能够读懂公式、运行最小实验并识别常见错误的深度。

## 最低启动顺序

1. 先完成[[数学与Python前置诊断]]，不要预先阅读答案。
2. Python 模块未通过时学习[[社交网络挖掘-Python图数据处理基础]]。
3. 概率模块未通过时学习[[社交网络挖掘-概率抽样与随机实验基础]]。
4. 线性代数模块未通过时学习[[社交网络挖掘-线性代数与矩阵传播基础]]。
5. 进入阶段 4 前学习[[社交网络挖掘-二分类评估与神经网络训练桥接]]的评估部分；进入阶段 6 前完成其训练部分。
6. 进入阶段 6 前完成[[社交网络挖掘-共现矩阵SVD与负采样基础]]，补齐“游走序列如何变成向量”。
7. 完成对应补学后换数字、换小图复测，不背原题答案。

## 进入主线的最低标准

- 能把一行边表解析为整数节点对，并明确自环、重复边和方向的处理规则。
- 能解释固定随机种子与多随机种子的不同职责，并计算一个 Bernoulli 均值。
- 能完成二维矩阵向量乘法，知道概率向量归一化为何必须保持元素和为 1。
- 能区分训练、验证和测试集合；知道测试数据不能参与特征计算和调参。
- 能运行项目 README 中的 smoke test，并解释输出而不是只看到绿色结果。

## 复盘入口

- 语法或数据结构错误：回到 Python 桥接卡的边表解析与断言。
- 概率波动解释错误：回到概率桥接卡的重复试验与不确定性。
- 矩阵维度或归一化错误：回到线性代数桥接卡的形状检查。
- 指标异常高：回到评估桥接卡的数据切分与泄漏检查。
- 随机游走能生成但没有节点向量：回到共现矩阵、SVD 与负采样桥接卡。
