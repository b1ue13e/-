> [!NOTE] 核心直觉：地图投影 (Map Projection)
> **类比**：图类型与嵌入就像是将三维不规则的高山低谷（复杂的社交拓扑关系、异构节点与动态边）通过“降维投影”转换成二维平整地图上的坐标点（低维连续向量空间 $\mathbb{R}^d$）。在地图上，物理距离近的点在现实中也靠得近；同理，在嵌入空间中，向量余弦相似度高的节点在网络拓扑中也具有相似的结构或语义特征。

## 1. 为什么需要这个知识点？
- **背景**：现实世界中的社交网络、知识图谱与生物网络包含多样的图类型（无向图、有向图、加权图、异构图、二部图、时空动态图等）。为了利用现代机器学习和深度学习工具处理这些高维离散的拓扑数据，必须将其映射为连续的高维向量表示（嵌入 Embedding）。
- **痛点**：高维邻接矩阵（如 $N \times N$）存在极度稀疏、维度随着节点数呈指数级扩展（维度灾难）、无法直接捕获高阶拓扑结构（如多跳邻居关系）以及传统矩阵分解算法计算复杂度昂贵（$O(N^3)$）的问题；同时，离散的图结构无法直接作为经典神经网络（如 MLP、CNN）的标准输入。
- **意义**：图嵌入（Graph Embedding）技术将复杂的离散图结构和节点/边属性信息编码为低维、紧凑、连续的实数向量 $\mathbf{z}_v \in \mathbb{R}^d$ ($d \ll N$)。这不仅极大地降低了存储与计算开销，还使得节点分类、链路预测、社群发现和推荐系统等下游任务可以直接使用标准的向量算法（如 SVM、FAISS、余弦相似度）高效执行。

## 2. 核心定义与公式/代码

### A. 常用图类型及其数学定义
1. **同构图 (Homogeneous Graph)**：仅包含单一类型的节点与边。记为 $G = (V, E)$，其中 $V$ 为节点集，$E \subseteq V \times V$ 为边集。
2. **异构图 (Heterogeneous Graph)**：包含多种类型的节点或边。记为 $G = (V, E, \mathcal{T}_V, \mathcal{T}_E, \phi, \psi)$，其中映射 $\phi: V \to \mathcal{T}_V$ 和 $\psi: E \to \mathcal{T}_E$ 满足 $|\mathcal{T}_V| + |\mathcal{T}_E| > 2$。
3. **二部图 (Bipartite Graph)**：节点集可分割为两个互不相交的子集 $V_1, V_2$，使得每条边均跨越这两个子集：$E \subseteq V_1 \times V_2$。
4. **动态/时序图 (Dynamic/Temporal Graph)**：拓扑结构随时间演进，记为带有时间戳的事件集合 $\mathcal{E} = \{(u, v, t, w)\}$ 或时序图序列 $G_1, G_2, \dots, G_T$。

### B. 图嵌入的核心定义与拓扑保持目标
图嵌入的目标是寻找一个映射函数 $f: V \to \mathbb{R}^d$，将每一个节点 $v \in V$ 映射至低维连续向量空间，使得拓扑空间的相似度矩阵 $\mathbf{S} \in \mathbb{R}^{N \times N}$ 在嵌入向量空间中得到良好还原：

$$ \mathbf{S}_{u, v} \approx \text{Sim}(\mathbf{z}_u, \mathbf{z}_v) = \mathbf{z}_u^\top \mathbf{z}_v \quad \text{or} \quad \frac{\mathbf{z}_u^\top \mathbf{z}_v}{\|\mathbf{z}_u\|_2 \|\mathbf{z}_v\|_2} $$

对于不同粒度的表达需求，分为三类嵌入：
- **节点级嵌入 (Node-level Embedding)**：每个节点表示为 $\mathbf{z}_v \in \mathbb{R}^d$。
- **边级嵌入 (Edge-level Embedding)**：连接 $(u, v)$ 的向量表示为 $\mathbf{z}_{(u,v)} = g(\mathbf{z}_u, \mathbf{z}_v)$（常用 Hadamard 积 $\mathbf{z}_u \odot \mathbf{z}_v$ 或拼接 $[ \mathbf{z}_u \| \mathbf{z}_v ]$）。
- **全图级嵌入 (Graph-level Embedding)**：整个图 $G$ 表示为 $\mathbf{z}_G = \text{Readout}(\{\mathbf{z}_v \mid v \in V\})$（如 Mean/Sum Pooling 或 DiffPool）。

### C. 核心 Python 实现：异构图定义与嵌入 Pooling (PyTorch Geometric & NetworkX)

```python
import torch
import torch.nn as nn
import networkx as nx
from torch_geometric.data import Data, HeteroData
from torch_geometric.nn import global_mean_pool

# 1. 构建异构社交网络图 (User-Item 交互)
hetero_graph = HeteroData()
hetero_graph['user'].x = torch.randn(100, 16)  # 100个用户，属性特征维度16
hetero_graph['item'].x = torch.randn(50, 32)   # 50个商品，属性特征维度32

# 添加 User -> Buy -> Item 的异构边关系 (2 x 300 边的张量)
hetero_graph['user', 'buys', 'item'].edge_index = torch.randint(0, 50, (2, 300))
print("异构图元数据:", hetero_graph.metadata())

# 2. 经典节点嵌入查表层 (Lookup Table / Embeddings Layer)
num_nodes = 1000
embedding_dim = 64
node_embedder = nn.Embedding(num_embeddings=num_nodes, embedding_dim=embedding_dim)
node_ids = torch.tensor([0, 5, 42])  # 节点索引
selected_embeddings = node_embedder(node_ids)
print(f"提取的节点嵌入 Shape: {selected_embeddings.shape}")  # [3, 64]

# 3. 节点嵌入至全图嵌入的 Readout (Global Pooling) 操作
batch_node_embeddings = torch.randn(34, 64)  # 包含 34 个节点的向量
graph_assignment = torch.zeros(34, dtype=torch.long)  # 假定属于同图 Batch=0
graph_embedding = global_mean_pool(batch_node_embeddings, graph_assignment)
print(f"全图级嵌入向量 Shape: {graph_embedding.shape}")  # [1, 64]
```

## 3. 具体应用案例
**场景**：大规模电商系统的协同过滤与实时推荐（如淘宝/Amazon 的异构交互网络）。

- **拓扑建立**：将用户和商品建模为二部异构图 $G = (V_{user}, V_{item}, E_{buy})$。节点属性包括用户兴趣标签与商品文本嵌入；边权代表历史购买/点击频率。
- **嵌入学习**：
  1. 使用异构图嵌入模型（如 Metapath2vec 或 RGCN）按元路径 `User -> Item -> User` 进行游走采像。
  2. 端到端优化 Loss 函数，使频繁产生交互的 $(u, i)$ 在向量空间中的点积 $\mathbf{z}_u^\top \mathbf{z}_i$ 最大化。
- **实时推理服务**：
  在商品推荐阶段，直接利用线下的商品向量库库建立 FAISS 索引；在线上请求到来时，实时提取用户嵌入 $\mathbf{z}_u$，在低维向量空间中运行近邻检索（ANN），毫秒级召回 Top-K 相关商品。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **混淆拓扑距离与空间几何欧式距离**：图嵌入中的距离用于衡量网络连通性或结构角色（如一阶/二阶邻接，或 Role2Vec 的结构等价性），而非现实中的欧氏物理坐标。使用 t-SNE 降维至 2D 观察时，几何距离远近可能会出现非线性失真。
> - **将有向图或异构图强行降级为无向同构图处理**：忽略边方向与节点类型会导致严重信息丢失。例如在社交网络中，$u \to v$ 表示关注，但不代表 $v \to u$；若简化为无向图，会误破坏拓扑的信息流向。
> - **动态图训练中的未来信息泄露 (Look-ahead Leakage)**：在时序动态图中，若直接在全局拓扑上计算嵌入，会导致 $t_0$ 时刻的模型无意中利用了 $t > t_0$ 的未来连通边信息。时序图嵌入必须按时间切片（Time-slice）或使用连续时间事件编码（如 TGAT/TGN）。
