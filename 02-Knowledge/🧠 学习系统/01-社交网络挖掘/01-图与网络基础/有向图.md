> [!NOTE] 核心直觉：单向通道与不平等的社会关系
> **类比**：如果无向图是微信里的“互加好友”（双向奔赴），那么有向图就是微博/Twitter里的“单向关注”（单相思）。你可以关注一个大V，但大V不一定关注你。这里的边具有**方向性**，表示关系是不对称的。

## 1. 为什么需要这个知识点？
- **背景**：现实世界中的大量关系并非对称的。例如食物链（A吃B）、资金流向（A转账给B）、网页链接（网页A指向网页B）。
- **痛点**：如果只用无向图来建模这些系统，会丢失“信息流向”或“权力不对称”的关键特征，无法区分谁是信息的发送者，谁是接收者。
- **意义**：有向图（Directed Graph / Digraph）为描述和挖掘不对称关系提供了基础数学工具，是理解网络影响力（如PageRank）、信息传播路径和因果关系的核心抽象。

## 2. 核心定义与公式/代码

**数学定义**：
一个有向图可以表示为 $G = (V, E)$：
- $V$ 是节点（Vertices/Nodes）的集合。
- $E$ 是有向边（Directed Edges/Arcs）的集合，其中每一条边是节点的**有序对** $e = (u, v)$，表示从节点 $u$ 指向节点 $v$。
- **出度 (Out-degree)** $d_{out}(v)$：以节点 $v$ 为起点的边数。
- **入度 (In-degree)** $d_{in}(v)$：以节点 $v$ 为终点的边数。

**邻接矩阵 (Adjacency Matrix)**：
对于有向图，其邻接矩阵 $A$ 通常是**不对称**的。
$$A_{ij} = \begin{cases} 1, & \text{如果存在边 } (i, j) \\ 0, & \text{否则} \end{cases}$$

**NetworkX 代码示例**：
```python
import networkx as nx

# 创建一个有向图
DG = nx.DiGraph()

# 添加有向边 (A -> B, A -> C, B -> C)
DG.add_edges_from([('A', 'B'), ('A', 'C'), ('B', 'C')])

# 获取节点的入度和出度
print("A的出度:", DG.out_degree('A')) # 输出: 2
print("C的入度:", DG.in_degree('C'))   # 输出: 2
```

## 3. 具体应用案例
**场景：网页排名 (PageRank) 与搜索引擎**
- 在互联网中，网页是节点，网页中的超链接是有向边。
- 如果一个网页有很多其他网页指向它（入度高），说明这个网页可能很重要。
- 谷歌的创始人正是利用了有向图的这一特性，提出了 PageRank 算法：一个网页的重要性不仅取决于指向它的网页数量（入度），还取决于指向它的网页本身的重要性。这彻底改变了搜索引擎的信息检索效率。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **混淆边 (u,v) 的方向**: 在数学和代码表示中，`(u, v)` 通常严格代表从 `u` 指向 `v`。在邻接矩阵中，这通常对应于矩阵的第 `u` 行第 `v` 列，但有时不同文献的行列表征习惯相反，需要仔细核对定义。
> - **忽视弱连通与强连通的区别**: 在无向图中，连通就是连通。但在有向图中，分为**强连通**（任意两点互相可达）和**弱连通**（忽略边的方向后图是连通的）。不能将两者混淆。
> - **默认入度等于出度**: 只有在特定类型的图（如欧拉有向图）或对全图求和时，总入度才等于总出度。对单个节点而言，入度完全可以为 0 出度很大，反之亦然。
