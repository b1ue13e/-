# 图与网络基础

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**。
- **判断理由**：课程所有统计量、生成模型和传播过程都依赖同一对象 $G=(V,E)$。如果方向、自环、重边或节点属性的口径不清，后续结果即使代码能运行也没有可解释性。

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：好友、关注、合作与交易的数据格式各不相同。图模型把“对象”和“对象之间的关系”统一成节点与边，使路径、群体、排序和传播能够在同一数学语言下计算。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：邻接矩阵连接线性代数；邻接表连接图算法；边表连接真实数据处理。
- **实际应用场景**：微博关注图、论文合作图、支付交易图、网页超链接图。
- **高频题型/任务**：从关系描述构图；区分有向/无向和简单/多重图；核对节点边数；选择合适存储结构。

## 3. 学它之前需要哪些前置知识？

1. **集合与有序对**：无向边是二元无序集合，方向边是有序对。
2. **Python 容器**：列表适合边表，集合适合邻居去重，字典适合邻接表。

## 4. 用直觉语言解释它

> “图就是一张只保留‘谁和谁有关’的关系地图。”

- **直觉类比**：地铁站是节点，轨道是边；若只能单向通行，就是有向边。
- **为什么自然**：很多任务关心的不是对象本身，而是对象在关系结构中的位置。
- **一句话直觉本质**：图把实体属性与关系结构分离，使局部连接能够组合成全局模式。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

图记为 $G=(V,E)$。$V$ 是节点集合；无向简单图中 $E\subseteq\{\{u,v\}:u,v\in V,u\ne v\}$，有向图中 $E\subseteq V\times V$。

### 2. 核心公式

邻接矩阵 $A\in\{0,1\}^{n\times n}$：

$$A_{ij}=\begin{cases}1,&(i,j)\in E\\0,&\text{otherwise}\end{cases}$$

无向简单图满足 $A=A^\top$，且握手定理为：

$$\sum_{v\in V}d(v)=2|E|.$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $V,E$ | 节点集、边集 | 有限集合 | 边的语义必须写清 |
| $n,m$ | 节点数、边数 | 非负整数 | $n=|V|,m=|E|$ |
| $A$ | 邻接矩阵 | $n\times n$ | 加权图用实数权重 |
| $N(v)$ | 节点 $v$ 的邻居集 | $V$ 的子集 | 有向图需区分入/出邻居 |

### 4. 常见变体与适用条件

- 无向图表达对称关系；有向图表达关注、引用或支付。
- 加权图表达频次、距离或强度；多重图允许同一对节点存在多条边。
- 简单图不允许自环和重边；清洗真实数据时不能默认输入已满足简单图约束。

## 6. 推导思路和思想来源

- **最初困难**：关系数据不能逐行孤立分析，因为一条边的意义取决于周围结构。
- **直接方法局限**：只用表格统计会丢掉多跳路径、共同邻居和群体结构。
- **关键“转念”**：把关系本身设为一等对象，用邻接运算组合局部关系。
- **推导主线**：边表定义 $E$；邻接表实现 $N(v)$；邻接矩阵使路径计数转化为矩阵幂，其中 $(A^k)_{ij}$ 是长度 $k$ 的游走数。
- **为什么自然**：矩阵乘法的求和恰好枚举中间节点，因此可以拼接相邻边。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：无向图边集为 $\{\{1,2\},\{1,3\},\{2,3\},\{3,4\}\}$，求度序列并验证握手定理。
- **解题思路与关键步骤**：逐边给两个端点各加 1。
- **最终答案**：度序列为 $(2,2,3,1)$，度和 $8=2\times4$。
- **易错点**：无向边只计一次，但对度和贡献两次。
- **🤔 追问**：若加入自环 $(4,4)$，不同图库对度的计数约定是什么？NetworkX 在无向图中令自环对度贡献 2。

### 例子 2：中等例子（条件判断与多步推理）

邻接矩阵
$A=\begin{bmatrix}0&1&1\\1&0&1\\1&1&0\end{bmatrix}$ 对称且对角为零，因此是三节点无向简单完全图；$A^2$ 的对角元素均为 2，表示每个节点有两条长度 2 的闭合游走。

### 例子 3：实际应用例子（真实场景/代码）

```python
import networkx as nx

edges = [("Alice", "Bob"), ("Alice", "Carol"), ("Bob", "Carol")]
graph = nx.Graph()
graph.add_edges_from(edges)

print(graph.number_of_nodes(), graph.number_of_edges())
print(dict(graph.degree()))
assert sum(dict(graph.degree()).values()) == 2 * graph.number_of_edges()
# 输出：3 3
# 输出：{'Alice': 2, 'Bob': 2, 'Carol': 2}
```

- **实际价值与转化**：先用不变量断言核对数据，再计算复杂指标，能尽早发现重复边或方向错误。

## 8. 常见误区和易混概念

### 误区 1：节点编号决定网络结构

- **错误直觉**：编号相近的节点更接近。
- **为什么错**：编号通常只是标识符，距离由路径定义。
- **正确理解**：除非模型显式引入空间位置，否则编号没有几何意义。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 边表 | 存在哪些边 | 紧凑、易导入，查邻居较慢 | 文件交换 |
| 邻接表 | 每个节点连向谁 | 稀疏图遍历高效 | BFS、邻居统计 |
| 邻接矩阵 | 任意节点对是否相连 | $O(n^2)$ 空间，便于线性代数 | 谱方法、小图推导 |

## 11. 自测题：5 道

1. **基础**：为什么无向图的邻接矩阵对称？ #自测题/基础
   > [!question]- 答案解析
   > 因为 $\{i,j\}=\{j,i\}$，所以 $A_{ij}=A_{ji}$。
2. **基础**：度序列 $(3,3,2,2)$ 对应多少条无向边？ #自测题/基础
   > [!question]- 答案解析
   > 度和为 10，因此 $m=5$。
3. **中等**：稀疏百万节点图为何优先邻接表？ #自测题/中等
   > [!question]- 答案解析
   > 空间约为 $O(n+m)$，而邻接矩阵需要 $O(n^2)$。
4. **中等**：有向边表转无向图会丢失什么？ #自测题/中等
   > [!question]- 答案解析
   > 丢失方向、互惠与入/出度信息，且双向边可能被合并。
5. **较难**：证明 $(A^2)_{ij}$ 等于 $i,j$ 的共同邻居数（无向简单图）。 #自测题/较难
   > [!question]- 答案解析
   > $(A^2)_{ij}=\sum_k A_{ik}A_{kj}$，每个同时邻接 $i,j$ 的 $k$ 贡献 1。
