# 数学与 Python 前置诊断

## 0. 先判断它值不值得深挖
- **类别**：**A 类入口卡**。
- **判断理由**：它不是额外门槛，而是避免在图算法表面看懂、实际卡在 Python、概率或特征值上的分流器。

## 1. 这个知识点解决什么问题？
> **麻烦**：PageRank 卡住可能不是网络概念不会，而是矩阵乘法不熟；幂律估计失败可能是对数/概率不会；代码报错可能是集合与字典没掌握。必须先定位真实瓶颈。

## 2. 为什么它重要？它有什么用？
- 让补课精确到最小前置，不要求先学完整线代/概率课程。
- 建立“先预测信心、再答题、最后校准”的元认知习惯。
- 决定阶段 1、2、4、5、6 的准入与补救路径。

## 3. 学它之前需要哪些前置知识？
无。允许不会；禁止看答案后把“看懂”记成“掌握”。

## 4. 用直觉语言解释它
> “像开车前检查油、电、轮胎：不是为了考试，而是判断车为什么走不了。”
- **一句话本质**：诊断的价值是定位错误来源，不是制造一个漂亮分数。

### 1. 评分规则

### 3. 校准误差
答题前给每模块信心 $c\in\{1,2,3,4,5\}$，答题后记录正确率 $a$。粗略校准差：
$$\operatorname{gap}=|20c-a|.$$
差值大于 20 个百分点时，下一轮必须先写理由再看答案，防止熟悉感冒充掌握。

- **检索优于重读**：先独立输出才能暴露知识缺口。

## 7. 例子：基础 → 中等 → 实际应用

### Python 诊断（P1–P5）
1. P1：`set([1,1,2])` 的长度？
2. P2：字典 `degree={"a":2}` 如何安全读取不存在的 `"b"` 并返回 0？
3. P3：列表推导式生成 0–4 中偶数的平方。
4. **P4 关键**：给定 `adj={0:{1,2},1:{0},2:{0}}`，不用 NetworkX 计算每个节点度。
5. P5：解释随机实验为什么要固定 seed，但不能只跑一个 seed。

> [!question]- Python 核对
> P1：2。P2：`degree.get("b", 0)`。P3：`[x*x for x in range(5) if x%2==0]`。P4：`{node: len(neighbors) for node, neighbors in adj.items()}`。P5：seed 保证复现；多 seed 衡量随机波动。

### 概率统计诊断（R1–R5）
1. R1：$X\sim\operatorname{Bernoulli}(p)$ 的 $E[X]$？
2. R2：为什么 $E[X+Y]=E[X]+E[Y]$ 不要求独立？
3. R3：若 100 次独立试验成功 23 次，成功率点估计是多少？
4. **R4 关键**：沿随机选中的边到达节点时，为何更容易看到高度节点？
5. R5：为什么 log-log 图近似直线不能单独证明幂律？

> [!question]- 概率核对
> R1：$p$。R2：期望的线性来自求和/积分线性。R3：0.23。R4：到达概率与节点度成正比，发生 size bias。R5：有限区间、分箱、截断和其他重尾分布都能产生近似直线。

### 线性代数诊断（L1–L5）
1. L1：$A=\begin{bmatrix}0&1\\1&0\end{bmatrix}$ 的两个特征值？
2. L2：为何对称矩阵适合用 `eigh`？
3. L3：概率向量的元素和应是多少？
4. **L4 关键**：计算 $A(2,1)^T$。
5. L5：Rayleigh 商 $x^TAx/x^Tx$ 在单位向量上极值对应什么？

> [!question]- 线代核对
> L1：$1,-1$。L2：实特征值且有正交特征向量基，`eigh` 利用对称结构。L3：1。L4：$(1,2)^T$。L5：对称矩阵的最大/最小特征值及相应方向。

### 实际应用：可运行自检
```python
import numpy as np

adjacency = {0: {1, 2}, 1: {0}, 2: {0}}
degrees = {node: len(neighbors) for node, neighbors in adjacency.items()}
matrix = np.array([[0.0, 1.0], [1.0, 0.0]])
vector = np.array([2.0, 1.0])
values = np.linalg.eigvalsh(matrix)
print(degrees)
print(matrix @ vector)
print(values)
# {0: 2, 1: 1, 2: 1}; [1. 2.]; [-1. 1.]
```

## 8. 常见误区和易混概念
- **误区 1：看完答案觉得简单，就记为会。** 必须 24 小时后无提示复测。
- **误区 2：总分掩盖关键题。** 关键题失败会直接阻断图遍历、概率模型或谱算法。
- **误区 3：一次代码运行成功就是实验可靠。** 语法正确、口径正确、统计稳定是三层不同验收。
