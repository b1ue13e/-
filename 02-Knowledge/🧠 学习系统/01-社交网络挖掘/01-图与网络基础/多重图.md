> [!NOTE] 核心直觉：多维度的人际关系
> **类比**：想象你和你的好朋友：你们既是高中同学（关系1），又是同公司的同事（关系2），周末还一起打游戏组成固定队伍（关系3）。在普通的图中，你们之间只能连一条“朋友”的线；但在**多重图**中，你们之间可以连三条不同颜色、代表不同性质的线。多重图允许两点之间存在多条边！

## 1. 为什么需要这个知识点？
- **背景**：现实世界中的实体之间往往存在多种不同类型的关系或多次交互行为，而不仅是单一的二元关系。
- **痛点**：传统的简单图（Simple Graph）限制了任意两个节点之间最多只能有一条边，无法表达“多重交互”或“多维关系”（例如：交通网络中两城市间的多种交通工具路线，或者社交网络中的多重身份连接）。
- **意义**：多重图（Multigraph）为复杂系统提供了更真实、高分辨率的数学模型，是理解多层网络（Multiplex Networks）和异构图的基础。

## 2. 核心定义与公式/代码
**数学定义**：
多重图 $G = (V, E, f)$ 由以下组成：
- $V$ 是节点集合。
- $E$ 是边集合。
- $f: E \to \{\{u, v\} \mid u, v \in V\}$ 是一个映射，将每条边映射到一对节点。如果对于 $e_1, e_2 \in E$ 有 $f(e_1) = f(e_2)$，则这两条边称为**平行边（Parallel edges）**或多重边。

**NetworkX 代码示例**：
```python
import networkx as nx

# 创建一个多重图
MG = nx.MultiGraph()

# 添加节点
MG.add_nodes_from(["Alice", "Bob"])

# 节点间添加多条不同类型的边
MG.add_edge("Alice", "Bob", key="colleague", weight=1)
MG.add_edge("Alice", "Bob", key="classmate", weight=5)
MG.add_edge("Alice", "Bob", key="gaming_buddy", weight=3)

print("Alice和Bob之间的边数:", MG.number_of_edges("Alice", "Bob"))
# 输出: 3
```

## 3. 具体应用案例
**场景**：城市公共交通网络分析
在构建两个城市A和城市B的交通网络时，A和B之间可能同时存在高铁、飞机和高速公路大巴。
- 节点：城市A，城市B。
- 边1：高铁连接（属性：时长 2h，成本 150）。
- 边2：飞机航班（属性：时长 1h，成本 500）。
- 边3：高速公路（属性：时长 4h，成本 80）。
使用多重图可以完美保留这些平行路径，在计算“最快路径”或“最便宜路径”时具有不同选择，而不会像简单图那样只能被迫聚合或丢弃信息。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **混淆多重图与加权简单图**: 认为用简单图的“边权重（Weight）”累加就可以完全替代多重边。错误！权重只能表示强度，如果多重边有各自不同的属性（如不同交通工具的耗时、成本），累加权重会丢失维度信息。
> - **算法兼容性问题**: 许多经典的图算法（如基础的最短路径、聚类系数计算）默认输入是简单图。直接将多重图扔给这些算法可能会报错或得出错误结果，通常需要先转换为简单图或使用专门的多重图算法。
