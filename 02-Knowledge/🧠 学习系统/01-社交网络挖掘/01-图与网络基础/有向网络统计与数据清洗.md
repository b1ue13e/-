# 有向网络统计与数据清洗

## 0. 先判断它值不值得深挖

- **类别**：**A 类（作业与工程共同核心）**。
- **判断理由**：CS224W HW0 的第一关就是统一有向边、自环、互惠和边去重口径。错误口径会传染到 PageRank、HITS 和度分布。

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：同一条边表里可能同时存在 `(a,b)`、`(b,a)`、重复行和 `(a,a)`。如果不先声明计数规则，“边数”和“度”会得到多套相互矛盾的答案。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：入度支撑 authority/PageRank，出度支撑 hub/传播能力，互惠性刻画社交互动。
- **实际应用场景**：关注、投票、引用、转账和消息网络。
- **高频任务**：统计自环节点、非自环有向边、唯一无向边、互惠节点对、零入/出度节点。

## 3. 学它之前需要哪些前置知识？

1. **[[图与网络基础]]**：有序对、简单图和多重图。
2. **集合去重**：用集合区分“输入行数”和“唯一边数”。

## 4. 用直觉语言解释它

> “关注关系像箭头：我关注你，不代表你关注我；两支反向箭头才是互惠。”

- **直觉类比**：投票网络中 $(a,b)$ 表示 $a$ 给 $b$ 投票。
- **为什么自然**：关系的发起方和接收方承担不同角色。
- **一句话直觉本质**：先保存方向，再按任务有意识地投影成无向图，而不是导入时无意丢失方向。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

节点 $v$ 的出邻居 $N^+(v)=\{u:(v,u)\in E\}$，入邻居 $N^-(v)=\{u:(u,v)\in E\}$；出度 $d^+(v)=|N^+(v)|$，入度 $d^-(v)=|N^-(v)|$。

### 2. 核心公式

非自环唯一有向边数：$m_d=|\{(u,v)\in E:u\ne v\}|$。

唯一无向节点对：$m_u=|\{\{u,v\}:(u,v)\in E,u\ne v\}|$。

互惠节点对数：$m_r=|\{\{u,v\}:(u,v),(v,u)\in E,u<v\}|$。

互惠率常见口径之一为 $r=2m_r/m_d$；报告时必须写出口径。

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $d^+,d^-$ | 出度、入度 | 自环会同时贡献 1 |
| $m_d$ | 非自环有向边数 | 双向关系计 2 |
| $m_u$ | 唯一无向节点对数 | 双向关系计 1 |
| $m_r$ | 互惠节点对数 | 必须两方向都存在 |

### 4. 常见变体与适用条件

- `DiGraph` 合并重复边；`MultiDiGraph` 保留多次交互。
- 二值投影适合“是否发生过”；加权聚合适合“发生次数/金额”。
- 零入度/出度节点只有在节点全集单独提供时才能可靠识别；只读边表会遗漏孤立节点。

## 6. 推导思路和思想来源

- **最初困难**：原始文件的行数不等于数学图的边数。
- **直接方法局限**：直接 `len(lines)` 会重复计数、包含注释与自环。
- **关键“转念”**：把数据处理拆成“解析—标准化—去重—按口径聚合—不变量检查”。
- **推导主线**：保留 `directed_edges`；用 `frozenset({u,v})` 得到无向节点对；检查反向有向边得到互惠对。
- **为什么自然**：不同统计量是同一有向边集合的不同投影。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：$E=\{(1,2),(2,1),(1,3),(1,1)\}$。
- **最终答案**：节点数 3；自环节点 1 个；非自环有向边 3 条；唯一无向边 2 条；互惠节点对 1 对；零出度节点为 3；零入度节点为 0。
- **易错点**：互惠的是节点对 $\{1,2\}$，不是两条互惠边。
- **🤔 追问**：删除自环后，节点 1 的入度和出度各减少 1。

### 例子 2：中等例子（条件判断与多步推理）

若输入重复两次 `(1,2)`，在简单有向图中仍只有一条边；在交互次数网络中应聚合为权重 2。选择取决于研究问题，而不是文件格式。

### 例子 3：实际应用例子（真实场景/代码）

```python
import networkx as nx

raw_edges = [(1, 2), (2, 1), (1, 3), (1, 1), (1, 2)]
nodes = {1, 2, 3}
edges = set(raw_edges)
graph = nx.DiGraph()
graph.add_nodes_from(nodes)
graph.add_edges_from(edges)

non_self = {(u, v) for u, v in edges if u != v}
undirected_pairs = {frozenset((u, v)) for u, v in non_self}
reciprocal_pairs = {
    frozenset((u, v)) for u, v in non_self if (v, u) in non_self
}

print(len(non_self), len(undirected_pairs), len(reciprocal_pairs))
print([n for n in graph if graph.out_degree(n) == 0])
# 输出：3 2 1
# 输出：[3]
```

## 8. 常见误区和易混概念

### 误区 1：把双向关系当作重复数据

- **错误直觉**：`(a,b)` 与 `(b,a)` 是同一条边。
- **为什么错**：在有向关系中它们表达两个独立行为。
- **正确理解**：只有在明确无向投影时才合并。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 场景 |
| :--- | :--- | :--- | :--- |
| 重复边 | 同方向同端点重复出现 | 简单图合并，多重图保留 | 多次转账 |
| 互惠边 | 两个方向均出现 | 是结构信号，不是脏数据 | 互相关注 |
| 自环 | 端点相同 | 可能合法，也可能是异常 | 自引用、内部转账 |

## 11. 自测题：5 道

1. `(a,b)` 和 `(b,a)` 何时可合并？ #自测题/基础
   > [!question]- 答案解析
   > 仅当研究问题明确采用无向投影；原始有向层必须保留。
2. 一个自环对有向节点的入度和出度各贡献多少？ #自测题/基础
   > [!question]- 答案解析
   > 各贡献 1。
3. 为什么互惠对数不能直接等于双向边数？ #自测题/中等
   > [!question]- 答案解析
   > 一对互惠节点对应两条有向边，但互惠对只计一次。
4. 如何识别零入度但存在于节点表的节点？ #自测题/中等
   > [!question]- 答案解析
   > 先载入完整节点集，再载入边；检查 `in_degree==0`。
5. 设计两个不变量检查有向边导入是否正确。 #自测题/较难
   > [!question]- 答案解析
   > 例如 $\sum_v d^+(v)=\sum_v d^-(v)=|E|$；互惠对数不超过唯一无向节点对数。
