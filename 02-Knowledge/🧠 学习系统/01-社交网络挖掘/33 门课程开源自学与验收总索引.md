# 33 门课程开源自学与验收总索引

> 本页回答“每门课跟什么主线、用什么证据验收、现在是否启动”。当前 33 门课程均已按 `attachment-v2-2026-07-28` 资源策略逐门对齐。完整建制不等于同时开课：当前唯一 Active Sprint 仍是量化金融，其余课程保持 `planned`。

## 使用规则

1. 每门课只保留一个决定顺序的 **Spine**。
2. 每个阶段最多挂一个 **Lab**，不把资源列表变成待办列表。
3. 每门课只有一个 **Capstone**，并按课程角色验收。
4. 未逐项核验许可证的外部资源一律 `link-only`。
5. 官方课程题目和 Starter Code 遵守 Honor Code，不保存或分发他人答案。
6. 只有当前 Sprint 的课程可以进入每日任务；其余页面只是已经设计好的待启动课程。

## 激活课程前的闸门

- [ ] 当前 Sprint 已结项或明确移交；
- [ ] 选定课程仍只有一个 Spine；
- [ ] 第一阶段 Lab 的数据、软件与计算预算可用；
- [ ] 外部资源许可证或 `link-only` 边界已经确认；
- [ ] Capstone 的验收证据可测量，但没有脱离数据口径的万能分数；
- [ ] 新 Sprint 页面是全库唯一 `sprint: current && source_of_truth: true`。
