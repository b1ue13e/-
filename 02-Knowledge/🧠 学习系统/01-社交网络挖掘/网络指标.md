# 网络指标

> [!NOTE] 核心直觉：衡量城市交通的“体检报告”
> **类比**：想象你在管理一个城市的交通系统。**度（Degree）**就像是一个十字路口连接了几条路；**平均路径长度（Average Path Length）**是从城东到城西平均需要经过几个路口（交通效率）；**聚类系数（Clustering Coefficient）**则代表了某个街区内部的道路网是否错综复杂、四通八达（抱团程度）；**密度（Density）**则反映了整个城市是空旷还是拥挤。这些指标就是用来给这整个网络“体检”的量化标准。

## 1. 为什么需要这个知识点？
- **背景**：在现实生活中，无论是人际关系网、互联网网页链接，还是生物学中的蛋白质相互作用网，都可以抽象为图（Graph）。面对成千上万节点的庞大网络，我们无法单纯用肉眼去观察其结构。
- **痛点**：仅仅知道“这是一个网络”毫无用处。我们需要回答：这个网络的信息传播速度快吗？网络中有没有明显的小圈子（社群）？网络是稀疏的还是密集的？
- **意义**：网络统计指标（Network Metrics）为我们提供了一套标准化的数学工具，用宏观和微观的统计量来刻画网络的拓扑结构特征，是进行后续社群发现、影响力最大化等高级图挖掘任务的基石。

## 2. 核心定义与公式/代码
### 主要网络指标定义

**1. 度 (Degree)**
- 节点 $i$ 的度 $k_i$ 是指与该节点直接相连的边数。对于有向图，分为入度 (In-degree) 和出度 (Out-degree)。
- 网络的平均度：$\langle k \rangle = \frac{1}{N} \sum_{i=1}^N k_i = \frac{2M}{N}$ （$N$为节点数，$M$为边数）。

**2. 网络密度 (Density)**
- 实际存在的边数与所有可能存在的边数之比。
- 无向图密度公式：$D = \frac{M}{\frac{N(N-1)}{2}} = \frac{2M}{N(N-1)}$

**3. 平均路径长度 (Average Path Length)**
- 网络中任意两个节点之间最短路径长度的平均值。衡量网络的全局信息传输效率。
- 公式：$L = \frac{1}{N(N-1)} \sum_{i \neq j} d_{ij}$，其中 $d_{ij}$ 是节点 $i$ 到 $j$ 的最短路径距离。

**4. 聚类系数 (Clustering Coefficient)**
- 衡量节点聚集形成团（Clique）的倾向。即“你朋友的朋友，也是你的朋友”的概率。
- 节点 $i$ 的局部聚类系数 $C_i$：节点 $i$ 的邻居之间实际存在的边数 $e_i$ 与最大可能边数之比。
  $C_i = \frac{2e_i}{k_i(k_i - 1)}$
- 网络的全局聚类系数：所有节点聚类系数的平均值 $C = \frac{1}{N} \sum C_i$。

### Python (NetworkX) 代码实现示例
```python
import networkx as nx

# 生成一个随机图 (Erdős-Rényi model)
G = nx.erdos_renyi_graph(n=100, p=0.1)

# 1. 计算平均度
degrees = dict(G.degree())
avg_degree = sum(degrees.values()) / len(G)

# 2. 计算网络密度
density = nx.density(G)

# 3. 计算平均最短路径长度 (如果图是连通的)
if nx.is_connected(G):
    avg_path_length = nx.average_shortest_path_length(G)

# 4. 计算全局平均聚类系数
avg_clustering = nx.average_clustering(G)

print(f"Average Degree: {avg_degree:.2f}")
print(f"Density: {density:.4f}")
print(f"Average Path Length: {avg_path_length:.2f}")
print(f"Clustering Coefficient: {avg_clustering:.4f}")
```

## 3. 具体应用案例
**场景**：识别“小世界网络”特征（六度分隔理论）
在社交网络（如微信好友网络或电影演员合作网络）中，往往会发现两个显著特征：
1. **高聚类系数**：人们倾向于形成紧密的小圈子，你的朋友彼此之间大多也认识。
2. **短平均路径长度**：尽管世界很大，但任意两个人通过少量的中间人就能建立联系（通常约为6步）。
通过计算上述两个指标，研究人员可以判断一个网络是否属于“小世界网络”。这对于理解病毒营销的传播速度、传染病的扩散模型具有极其重要的指导意义。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **误把局部指标当全局特征**: 一个节点的聚类系数很高，不代表整个网络都是紧密相连的。少数的“星型中心点”可能会拉低平均值。
> - **忽略连通性计算平均路径长度**: 如果图不是连通的（存在孤岛），那么某些节点之间的最短路径是无穷大（$\infty$）。直接计算整个图的平均路径长度会报错，通常应针对最大的连通子图（Giant Component）进行计算。
> - **有向图与无向图的混淆**: 计算度、路径和聚类系数时，有向图（如Twitter关注）和无向图（如Facebook双向好友）的物理意义和计算公式存在差异，使用库函数时必须指定正确的图类型。

## 5. 跨学科链接与双链
- **上游知识**：图论基础、邻接矩阵、概率统计
- **下游知识**：节点中心性算法（PageRank, Betweenness）、社群检测（Louvain算法）、小世界网络模型（Watts-Strogatz）、无标度网络模型（Barabási-Albert）
- **跨领域关联**：流行病学（传染病传播速度模型）、城市规划（交通路网抗毁性评估）、神经科学（大脑功能连接网络拓扑分析）。
