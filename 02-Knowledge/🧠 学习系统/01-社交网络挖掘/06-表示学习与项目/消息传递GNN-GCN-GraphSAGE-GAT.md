# 消息传递 GNN：GCN、GraphSAGE 与 GAT

## 0. 先判断它值不值得深挖
- **类别**：A 类（现代全面主干）。
## 1. 这个知识点解决什么问题？
> 让每个节点聚合邻居特征，学习适合节点分类、链接预测或图分类的表示，并共享参数到未见节点。
## 2. 为什么它重要？它有什么用？
社交分类、推荐、欺诈检测；统一 GCN/SAGE/GAT；解释过平滑与采样。
## 3. 学它之前需要哪些前置知识？
1. [[图表示学习-DeepWalk与Node2Vec]]。
2. 矩阵乘法、反向传播。
## 4. 用直觉语言解释它
> 节点反复听取邻居消息；层数决定能看到几跳，聚合规则决定谁的话更重要。
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
$m_v^{(k)}=AGG\{h_u^{(k-1)}:u\in N(v)\}$，$h_v^{(k)}=UPDATE(h_v^{(k-1)},m_v^{(k)})$。
### 2. 核心公式
GCN：$H^{k+1}=\sigma(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}H^kW^k)$；SAGE 拼接自身与聚合邻居；GAT 学习归一化注意力 $\alpha_{vu}$。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $H^k$ | 第 k 层表示 | 0 层为输入特征 |
| $\tilde A=A+I$ | 加自环邻接 | 保留自身消息 |
### 4. 常见变体与适用条件
聚合必须对邻居排列不变；SAGE 可采样邻居；层数过深会过平滑/过压缩。
## 6. 推导思路和思想来源
局部参数共享满足图大小可变；归一化邻接防止高度节点数值爆炸；SAGE 的函数编码器带来归纳能力；GAT 让邻居权重数据驱动。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
节点自身特征 2、两个邻居特征 1 和 3，mean 聚合为 2；若更新取自身与邻居均值平均，结果仍 2。
### 例子 2
两层消息传递看到两跳；若训练/测试边未先切分，测试关系会进入计算图造成泄漏。
### 例子 3（代码）
```python
import numpy as np
A = np.array([[0.,1.],[1.,0.]])
X = np.array([[1.],[3.]])
At = A + np.eye(2); D = np.diag(At.sum(axis=1) ** -0.5)
H = D @ At @ D @ X
print(H.ravel())
# 输出：[2. 2.]
```
## 8. 常见误区和易混概念
- **误区**：层越深越好。纠正：表示可能趋同且远程消息被压缩。
| 模型 | 聚合 | 归纳性 | 特点 |
| :--- | :--- | :--- | :--- |
| GCN | 归一化加权和 | 可用于新图若有特征 | 简洁 |
| GraphSAGE | mean/pool/LSTM + concat | 强 | 邻居采样 |
| GAT | 注意力加权 | 强 | 权重可解释但昂贵 |
