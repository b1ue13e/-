## 原笔记：可复现网络挖掘实验

### 0. 先判断它值不值得深挖
- **类别**：A 类；所有作业的横向验收卡。
### 1. 这个知识点解决什么问题？
> 让别人从同一输入复现结果，并判断提升来自算法而非数据泄漏、随机运气或评价口径变化。
### 2. 为什么它重要？它有什么用？
作业验收、研究复现、模型上线；防止图任务中最常见的切分与拓扑泄漏。
### 3. 学它之前需要哪些前置知识？
1. 任务定义与指标。
2. Python 环境、随机种子和文件哈希。
### 4. 用直觉语言解释它
> “实验不是一张最好看的图，而是一条从原始数据到结论可重放的证据链。”
### 5. 正式定义、核心公式、符号解释
#### 1. 最核心定义
实验单元包括：版本化输入、固定切分、baseline、候选方法、统一指标、重复运行、误差分析和限制。
#### 2. 核心公式
重复结果报告均值与样本标准差 $s=\sqrt{\sum_i(x_i-\bar x)^2/(n-1)}$；随机比较应给置信区间或检验而非单次最好值。
#### 3. 符号说明表
| 字段 | 含义 | 例子 |
| :--- | :--- | :--- |
| seed | 随机状态 | 42 |
| split | 训练/验证/测试规则 | 时间切分 |
| baseline | 最低可信参照 | 随机、度、PA |
#### 4. 常见变体与适用条件
描述性作业核对不变量；预测作业冻结切分；随机传播统一随机预算；大图实验记录采样器与硬件。
### 6. 推导思路和思想来源
先冻结问题与输入，再运行 baseline，最后只改变一个因素。图数据的边既是样本又是计算结构，所以测试边不能进入训练图特征或 GNN 消息传递。
### 7. 例子：基础 → 中等 → 实际应用
#### 例子 1（手算）
三次 AUC 为 0.70、0.74、0.72，均值 0.72；报告单次 0.74 会夸大典型表现。
#### 例子 2
链接预测在完整图算 Node2Vec 再删测试边属于泄漏；正确顺序是先删边，再游走训练。
#### 例子 3（完整产物契约代码）
```python
import csv
import hashlib
import json
import platform
import tempfile
from pathlib import Path

def file_sha256(path):
    return hashlib.sha256(path.read_bytes()).hexdigest()

config = {"seed": 42, "split": "time", "metric": "pr_auc"}
with tempfile.TemporaryDirectory() as temp_dir:
    run_dir = Path(temp_dir) / "run-001"
    run_dir.mkdir()
    data_path = run_dir / "input.edgelist"
    data_path.write_text("0 1\n1 2\n", encoding="utf-8")
    (run_dir / "config.json").write_text(
        json.dumps(config, indent=2) + "\n", encoding="utf-8")
    with (run_dir / "metrics.csv").open("w", newline="", encoding="utf-8") as handle:
        writer = csv.DictWriter(handle, fieldnames=["seed", "pr_auc", "status"])
        writer.writeheader()
        writer.writerow({"seed": 42, "pr_auc": 0.72, "status": "smoke-test"})
    manifest = {
        "input_sha256": file_sha256(data_path),
        "python": platform.python_version(),
        "config": config,
        "artifacts": ["config.json", "metrics.csv"],
    }
    (run_dir / "manifest.json").write_text(
        json.dumps(manifest, indent=2) + "\n", encoding="utf-8")
    assert all((run_dir / name).exists()
               for name in ["config.json", "metrics.csv", "manifest.json"])
    print(sorted(path.name for path in run_dir.iterdir()))
# 输出输入、配置、指标和 manifest 产物；真实实验还应保存图与日志。
```

## 原笔记：NetworkX-SNAP环境与数据工作流

### 0. 先判断它值不值得深挖
- **类别**：**A 类工具入口**。
- **判断理由**：CS224W 2017 作业使用 SNAP API；当前知识库示例主要使用可安装、可测试的 NetworkX。必须理解概念等价和 API 差异，不能机械替换函数名。

### 1. 这个知识点解决什么问题？
> **麻烦**：环境没隔离、数据方向读错、节点 ID 被转成字符串、自环/重边被库自动处理，都可能让“代码能跑”却得到错误答案。

### 2. 为什么它重要？它有什么用？
- 建立可复现 Python 环境和版本记录。
- 用一个最小数据集贯通读取、清洗、统计、绘图、保存结果。
- 把 SNAP 作业要求翻译到 NetworkX 时保留图类型和算法口径。

### 3. 学它之前需要哪些前置知识？
1. Python 变量、循环、函数、字典和集合。
2. 不具备时先完成[[../01-图与网络基础/数学与Python前置诊断#Python 诊断（P1–P5）]]。

### 4. 用直觉语言解释它
> “库是不同品牌的工具箱；锤子名字可以不同，但施工图中的对象、单位和验收标准不能变。”
- **一句话本质**：先固定环境与图语义，再选择 API。

### 6. 推导思路和思想来源
- 虚拟环境隔离依赖，`pip freeze` 固定可复现状态。
- 图类决定自环/重边/方向如何存储；算法选择必须晚于语义确认。
- 小图手算是库调用的 oracle：先在 4–6 个节点验证，再上真实数据。
- 不变量用于发现静默错误，比“输出看起来合理”可靠。
- URL 存活与题面公开不等于数据永久可得；哈希、下载日期和不可用状态都是复现证据。

#### 例子 3：可运行端到端最小工作流
```python
from pathlib import Path
import tempfile
import networkx as nx

edge_text = "0 1\n1 2\n2 0\n2 3\n"
with tempfile.TemporaryDirectory() as temp_dir:
    edge_path = Path(temp_dir) / "toy.edgelist"
    edge_path.write_text(edge_text, encoding="utf-8")
    graph = nx.read_edgelist(edge_path, nodetype=int, create_using=nx.Graph)

    degrees = dict(graph.degree())
    assert graph.number_of_nodes() == 4
    assert graph.number_of_edges() == 4
    assert sum(degrees.values()) == 2 * graph.number_of_edges()
    assert degrees == {0: 2, 1: 2, 2: 3, 3: 1}
    print(nx.__version__, degrees)
# 输出当前 NetworkX 版本与 {0: 2, 1: 2, 2: 3, 3: 1}。
```

### 8. 常见误区和易混概念
- **误区 1：`Graph` 能保存平行边。** 它会合并；需要 `MultiGraph` 才保留。
- **误区 2：SNAP 与 NetworkX 同名概念必有相同归一化。** PageRank、介数、分量返回值和归一化需逐项查文档并用小图比对。
- **误区 3：直接在真实数据上调试。** 大图无法人工判断；先用可手算 toy graph。
- **误区 4：安装命令成功等于环境可用。** 必须 import、运行算法并记录版本。
- **误区 5：用相似公开数据替代遗失作业数据。** 可以验证 loader 和算法，但不能据此声称复现了官方结果。

| 层级 | 验收问题 | 证据 |
| :--- | :--- | :--- |
| 环境 | 能否 import？ | 版本输出 |
| 数据 | 图语义是否正确？ | $n,m$ 与不变量 |
| 算法 | 口径是否一致？ | toy graph 手算对照 |
| 实验 | 结果能否复现？ | seed、配置、输出文件 |
