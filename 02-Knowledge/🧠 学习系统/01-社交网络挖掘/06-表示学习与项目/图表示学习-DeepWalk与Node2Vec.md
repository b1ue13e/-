# 图表示学习：DeepWalk 与 Node2Vec

## 0. 先判断它值不值得深挖
- **类别**：A 类（现代扩展）。
## 1. 这个知识点解决什么问题？
> 把离散节点映射为低维向量，使结构相近节点可被分类器、聚类器和链接预测器使用。
## 2. 为什么它重要？它有什么用？
传统特征到 GNN 的桥梁；强链接预测 baseline；适合无节点特征图。
## 3. 学它之前需要哪些前置知识？
1. [[../04-排序与链接预测/PageRank-HITS-PPR与Spam-Farm]]。
2. Skip-gram、负采样和向量内积。
## 4. 用直觉语言解释它
> 把随机游走当句子、节点当单词；经常在相同上下文出现的节点向量接近。
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
DeepWalk 用均匀随机游走；Node2Vec 根据上一步 $t$、当前 $v$ 对候选 $x$ 加权：$\alpha_{pq}(t,x)=1/p$（返回）、1（相邻）、$1/q$（外扩）。
### 2. 核心公式
Skip-gram 最大化 $\sum_{u}\sum_{v\in context(u)}\log P(v\mid z_u)$，常用负采样近似 softmax。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $z_u$ | 节点嵌入 | $\mathbb R^d$ |
| $p,q$ | 返回/进出参数 | 控制 BFS/DFS 倾向 |
### 4. 常见变体与适用条件
$q>1$ 更局部（BFS-like），$q<1$ 更外扩（DFS-like）；纯 lookup 嵌入通常不能直接推断训练未见节点。
## 6. 推导思路和思想来源
游走把图邻域转换为序列共现；窗口定义结构相似。Node2Vec 的二阶转移在同质社区与结构角色之间调节偏好。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
若候选分别是返回点、与上一步相邻、距离 2，$p=2,q=0.5$，未归一权重为 $(0.5,1,2)$，概率为 $(1/7,2/7,4/7)$。
### 例子 2
两个不相连星图的中心结构角色相同，但 DeepWalk 主要保持局部邻近，不一定把两中心嵌近。
### 例子 3（代码）
```python
weights = [1/2, 1, 1/0.5]
probs = [w / sum(weights) for w in weights]
print([round(p, 3) for p in probs])
# 输出：[0.143, 0.286, 0.571]
```
## 8. 常见误区和易混概念
- **误区**：嵌入相似必然表示属性相似。纠正：目标只优化特定游走上下文。
| 方法 | 编码器 | 归纳能力 | 结构偏好 |
| :--- | :--- | :--- | :--- |
| DeepWalk | 节点 lookup | 弱 | 均匀邻近 |
| Node2Vec | 节点 lookup | 弱 | $p/q$ 可调 |
| GraphSAGE | 特征聚合 | 强 | 学习邻域函数 |
