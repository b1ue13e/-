> [!NOTE] 核心直觉：派系分明的“社交宴会”
> **类比**：想象一场社交宴会，客人们被分成了不同的圈子（比如：极客圈、体育圈、文艺圈）。**随机块模型（SBM）**的核心假设是：两个人是否会互相交谈（形成连边），**完全取决于他们所属的圈子（Block）**。同属“极客圈”的人可能大概率互相聊天，而“极客圈”和“体育圈”的人之间聊天的概率可能很低。SBM 就是这样一个生成图的概率模型，通过事先定义好每个群体的连接概率来生成网络结构。

## 1. 为什么需要这个知识点？
- **背景**：在真实世界网络中，节点往往表现出聚集特性（社区结构）。我们需要一种能够**生成并且刻画**这种社团结构的数学模型，以便进行理论分析和统计推断。
- **痛点**：经典的 Erdős-Rényi (ER) 随机图模型假设所有节点间连接概率完全一样，无法表现出真实网络中的社区、核心-边缘结构等异质性。启发式算法（如 Louvain, Girvan-Newman）虽然能发现社区，但缺乏严谨的统计理论基础。
- **意义**：SBM 将网络划分为不同的“块”，不仅是发现网络社区结构的**统计推断基石**，还能模拟出“同配性”（Assortativity，如物以类聚）、“异配性”（Disassortativity，如买家与卖家之间的双分图结构）以及“核心-边缘”结构等丰富形态，是复杂网络领域最基础的生成模型之一。

## 2. 核心定义与公式/代码
随机块模型 $SBM(n, k, \pi, P)$ 是一个生成概率图的模型，定义如下：

- **参数说明**：
  - $n$: 网络中的节点总数。
  - $k$: 网络中的社区（Block）数量。
  - $\pi$: 一个长度为 $k$ 的向量，表示每个社区的先验概率分布。例如 $\pi_r$ 表示一个节点被分配到社区 $r$ 的概率，$\sum_{r=1}^k \pi_r = 1$。
  - $P$: 一个 $k \times k$ 的对称概率矩阵。元素 $P_{rs}$ 表示社区 $r$ 的节点和社区 $s$ 的节点之间产生连边的概率。

- **生成过程（Generative Process）**：
  1. **分配社区**：对网络中的每个节点 $i \in \{1, 2, \dots, n\}$，独立地从多项式分布 $\pi$ 中抽取其所属社区标签 $z_i \in \{1, 2, \dots, k\}$。
  2. **生成连边**：对每一对节点 $(i, j)$，它们之间产生连边 $A_{ij} = 1$ 的概率服从伯努利分布，概率取决于它们所属的社区：
     $$ P(A_{ij} = 1 | z_i, z_j) = P_{z_i, z_j} $$
     （在无向图中，$P_{z_i, z_j} = P_{z_j, z_i}$）。

**推断任务**：在真实场景中，我们只看到图的邻接矩阵 $A$，任务是**逆向推断**出每个节点的隐藏标签 $z_i$（社区发现）。通常通过最大似然估计（MLE）或贝叶斯推断（如 EM 算法、MCMC）来解决。

```python
import networkx as nx
import matplotlib.pyplot as plt

# 定义 SBM 参数
sizes = [75, 75] # 两个社区，各75个节点
# 连接概率矩阵 P
# 同社区连接概率为 0.1，跨社区连接概率为 0.01
probs = [[0.1, 0.01], 
         [0.01, 0.1]]

# 生成随机块模型图
G = nx.stochastic_block_model(sizes, probs, seed=42)

# 绘制网络图
color_map = ['lightblue' if i < 75 else 'lightgreen' for i in range(150)]
nx.draw(G, node_color=color_map, node_size=50, with_labels=False)
plt.show()
```

## 3. 具体应用案例
**场景：科学家合作网络中的派系推断与链接预测**
在一所大学中，物理系和计算机系的学者们经常合作。
- **推断（社区发现）**：给定一张科学家合作关系图（谁和谁发过文章），我们不知道每个科学家的系别。利用 SBM 进行拟合，模型能自动将连接稠密的群体归为一类（如推断出 Block 1 是物理系，Block 2 是计算机系）。
- **生成结构（异配性）**：假设学校有一个“交叉学科项目”，要求物理系和计算机系的老师必须配对。此时模型可以设置 $P_{11}$ 和 $P_{22}$ 极低，而 $P_{12}$ 很高。SBM 完美兼容这种二分图（Bipartite）或异配网络。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **度分布过于均匀 (Degree Defect)**: 标准 SBM 假设同一社区内的节点是完全对称的（期望度数相同）。但在现实中，同一个社区里既有“大佬”（度很大）也有“边缘人”（度很小）。这会导致标准 SBM 把度数很高的人全部分成一个“大佬社区”，而不是按真实社团划分。**解法**：使用**度修正随机块模型 (Degree-Corrected SBM, DCSBM)**。
> - **SBM 一定是同配的吗？**: 很多人误以为 SBM 只能用于“同配社区”（内部边密集，外部边稀疏，即对角线概率大）。事实上，只要你调整矩阵 $P$，SBM 同样可以描述核心-边缘结构（Core-Periphery）或分层结构。
> - **硬分配限制**: 标准 SBM 中每个节点只能属于**唯一**的一个社区。现实中一个人可能跨越多个圈子，这就需要引入重叠社区发现模型，如 MMSB（Mixed Membership SBM）。
