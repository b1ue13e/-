# PageRank、HITS、PPR 与 Spam Farm

> **阅读顺序**：PageRank 与 HITS 建立全局链接分析，PPR 引入个性化重启，Spam Farm 研究对该机制的操纵与约束。公式可共用，因此不再拆成两张卡。

## 原笔记：PageRank-HITS与PPR

### 0. 先判断它值不值得深挖
- **类别**：A 类；HW0 与 HW4 直接考查。
### 1. 这个知识点解决什么问题？
> 入度只数票，不考虑投票者质量；随机游走与 hub-authority 递归地传播声望，并用 teleport 解决陷阱和悬挂节点。
### 2. 为什么它重要？它有什么用？
- 网页排序、推荐、局部社区搜索、专家发现。
- PPR 对 teleport 向量线性，是 HW4 组合题核心。
### 3. 学它之前需要哪些前置知识？
1. [[../01-图与网络基础/有向网络统计与数据清洗]]。
2. 随机矩阵、特征向量、幂迭代。
### 4. 用直觉语言解释它
> PageRank 是会偶尔传送的随机浏览者；HITS 把好目录（hub）与好内容（authority）相互定义。
### 5. 正式定义、核心公式、符号解释
#### 1. 最核心定义
列随机转移矩阵 $M$ 下：
$$r=\beta Mr+(1-\beta)s.$$
$s=\mathbf1/n$ 是全局 PageRank；任意偏好分布 $s$ 是 PPR。
#### 2. 核心公式
HITS：$a=A^Th,\ h=Aa$，故 authority 是 $A^TA$ 主特征向量，hub 是 $AA^T$ 主特征向量。
#### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $\beta$ | 继续沿边概率 | 常取 0.85 |
| $s$ | teleport 分布 | 和为 1 |
| $r$ | 稳态排名 | 和为 1 |
#### 4. 常见变体与适用条件
悬挂列应替换为 $s$ 或统一分布；矩阵行/列约定必须一致。topic-sensitive PageRank 预计算多个 $s$ 的解。
### 6. 推导思路和思想来源
无 teleport 时链可能不可约或周期；加入 $(1-\beta)s$ 保证从任意状态重启。线性方程 $(I-\beta M)r=(1-\beta)s$ 表明 $r$ 对 $s$ 线性，支持 HW4 的加权组合。
### 7. 例子：基础 → 中等 → 实际应用
#### 例子 1（手算）
两节点互相指向、$s=(1,0)$、$\beta=0.5$：解 $r_1=0.5r_2+0.5,r_2=0.5r_1$，得 $(2/3,1/3)$。
#### 例子 2
星型引用图中中心可能是 authority，指向多个高 authority 的索引页是 hub；两角色不必同一节点。
#### 例子 3（代码）
```python
import networkx as nx
g = nx.DiGraph([(0, 1), (1, 0), (2, 1)])
ppr = nx.pagerank(g, alpha=0.85, personalization={0: 1, 1: 0, 2: 0})
hubs, authorities = nx.hits(g, max_iter=1000, normalized=True)
print(round(sum(ppr.values()), 12), max(authorities, key=authorities.get))
# 输出概率和 1；authority 最高节点为 1。
```

- **误区**：PageRank 就是入度。纠正：分数由来源分数按出度分摊并含 teleport。
| 方法 | 递归关系 | 个性化 | 典型角色 |
| :--- | :--- | :--- | :--- |
| PageRank | 单一稳态 | 均匀 $s$ | 全局声望 |

## 原笔记：PageRank-Spam-Farm与抗操纵

### 0. 先判断它值不值得深挖
- **类别**：**A 类**；补齐 HW4-Q1.3–Q1.5。
- **判断理由**：会算 PPR 线性组合不足以覆盖 HW4-Q1；后半题要求把链接结构翻译成联立 PageRank 流量方程，并比较联盟结构。

### 1. 这个知识点解决什么问题？
> **麻烦**：PageRank 把高分沿出边传递，攻击者可以创建“助推页”把 teleport 得到的基础质量集中到目标页。怎样用守恒方程量化增益，并判断联盟是否真的提高总收益？

### 2. 为什么它重要？它有什么用？
- 理解链接排序的博弈面与鲁棒性，而非只会调用 `pagerank`。
- 训练“看图列流量方程—消元—比较基线”的通用能力。
- 对应 HW4-Q1.3–Q1.5；本卡讲方法与同构例，不保存官方作业最终答案。

### 3. 学它之前需要哪些前置知识？
1. **[[PageRank-HITS-PPR与Spam-Farm]]**：$r=\beta Mr+(1-\beta)s$。
2. 二元/多元线性方程、出度分摊与外部流入。

#### 先备诊断
- [ ] 一个分数为 $r$、出度为 $d$ 的页面，沿每条出边贡献多少？
- [ ] 能否把两个互链页面写成二元一次方程并消元？
- **答案**：$\beta r/d$；不能完成第二项时先做第 7.1 节的两节点例。

### 4. 用直觉语言解释它
> “Teleport 给每页发基础津贴，助推页把津贴汇给目标；目标再把流量回灌，形成循环放大器。联盟会不会更好，取决于新增流入是否抵消分流损失。”
- **一句话本质**：Spam Farm 是带外部注入的线性反馈系统。

### 5. 正式定义、核心公式、符号解释

#### 1. 通用流量方程模板
对受控节点集合 $C$：
$$
r_C=\beta M_{CC}r_C+u,
$$
$u$ 汇总 teleport 与集合外入链贡献。因此
$$
r_C=(I-\beta M_{CC})^{-1}u.
$$
不要先套记忆公式；先从每个节点的入边逐项列方程。

#### 2. 单目标—$k$ 助推页的同构模型
设目标页为 $0$，每个助推页只指向目标；目标均匀指回 $k$ 个助推页。令每页均匀 teleport 质量 $\tau=(1-\beta)/N$，外部链接经阻尼后的总输入为 $\lambda$。由对称性所有助推页同分 $b$：
$$
p_0=\tau+\lambda+\beta kb,\qquad
b=\tau+\beta\frac{p_0}{k}.
$$
消去 $b$：
$$
(1-\beta^2)p_0=\tau(1+\beta k)+\lambda.
$$
这个推导展示方法；完成官方题时必须按官方图的出度与 $\lambda$ 定义重新核对每一项。

#### 3. 两个目标结盟的矩阵法
无论联盟结构多复杂，先把助推页按对称组消元，最终可写成：
$$
\begin{bmatrix}p\\q\end{bmatrix}
=C\begin{bmatrix}p\\q\end{bmatrix}+b,
\qquad
\begin{bmatrix}p\\q\end{bmatrix}=(I-C)^{-1}b.
$$
比较时必须计算三类量：各自增量 $p-p^{(0)}$、$q-q^{(0)}$，以及联盟总增量 $(p+q)-(p^{(0)}+q^{(0)})$。个人获益与总获益不是同一命题。

#### 4. 出度分流规则
若目标新增一条联盟出边，它给原有每条出边的份额可能从 $p/d$ 变为 $p/(d+1)$。任何“多一条入边一定更好”的直觉都必须同时核算出度分母变化。

#### 5. 符号表
| 符号 | 含义 | 是否含阻尼 |
| :--- | :--- | :--- |
| $\tau$ | 单页 teleport 注入 | 已含 $1-\beta$ |
| $\lambda$ | 外部页面流入目标的总贡献 | 本卡约定已含 $\beta$ |
| $b$ | 单个助推页 PageRank | 概率质量 |
| $C$ | 受控目标间反馈矩阵 | 已含转移份额与 $\beta$ |

### 6. 推导思路和思想来源
1. **节点守恒**：每个页面分数 = teleport + 所有入邻居的阻尼分摊。
2. **利用对称**：结构相同的助推页同分，$k$ 个未知量压成一个 $b$。
3. **先消内部页**：把 $b$ 表成目标分数，再代回目标方程。
4. **联盟矩阵化**：剩余目标变量构成小线性系统。
5. **与独立基线比较**：保持 $N,\beta,k,m$ 口径一致，分别比较个人与总量。

### 7. 例子：已解 → 渐隐 → 实际应用

#### 例子 1：已解手算
取 $N=10,k=2,\beta=1/2,\lambda=0$，$\tau=0.05$。由上式
$$p_0=\frac{0.05(1+1)}{1-0.25}=\frac{2}{15},\qquad b=0.05+\frac{p_0}{4}=\frac1{12}.$$
检查目标方程：$0.05+0.5\times2\times(1/12)=2/15$。

#### 例子 2：渐隐例
若目标不再指回助推页而只指向外部，补全：
1. 助推页方程 $b=\_\_\_\_$；
2. 目标方程 $p_0=\tau+\lambda+\_\_\_\_$；
3. 与反馈环结构相比，少了哪一项二次反馈？

> [!question]- 核对
> $b=\tau$；$p_0=\tau+\lambda+\beta k\tau$；少了 $\beta^2p_0$。

#### 例子 3：可运行线性系统
```python
import numpy as np

beta = 0.5
n_pages = 10
k = 2
tau = (1.0 - beta) / n_pages
# 未知量依次为 target, booster；方程 p=τ+βkb, b=τ+βp/k
feedback = np.array([[0.0, beta * k], [beta / k, 0.0]])
injection = np.array([tau, tau])
target, booster = np.linalg.solve(np.eye(2) - feedback, injection)
print(round(target, 6), round(booster, 6))
assert np.allclose([target, booster], feedback @ [target, booster] + injection)
# 输出：0.133333 0.083333
```

### 8. 常见误区和易混概念
- **误区 1：漏 teleport。** 每个受控页仍有基础注入。
- **误区 2：把 $\lambda$ 重复乘 $\beta$。** 先声明它是原始入邻居和还是已经阻尼后的贡献。
- **误区 3：联盟多一条边必然增益。** 新边同时改变目标的出度分摊。
- **误区 4：只比较个人增益。** 联盟可发生一方受益、另一方损失，或总量不增。

| 概念 | 目标 | 关键变量 | 防御思路 |
| :--- | :--- | :--- | :--- |
| PPR | 个性化相关性 | teleport 分布 | 可信种子 |
| Spam Farm | 操纵全局排名 | 反馈环与助推页 | TrustRank/链接折损 |
| Link farm 检测 | 识别异常子图 | 稠密互链、同步增长 | 结构+内容联合 |
