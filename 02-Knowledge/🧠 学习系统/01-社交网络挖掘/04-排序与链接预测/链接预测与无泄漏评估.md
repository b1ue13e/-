# 链接预测与无泄漏评估

## 0. 学习边界
- **类别**：A 类（课程全面主干与 Capstone 必做）。
## 1. 这个知识点解决什么问题？
> 根据训练时可见的图预测未来/隐藏边，同时保证测试边没有通过特征计算、负采样或调参泄漏进训练。
## 2. 为什么它重要？它有什么用？
好友推荐、合作预测、知识图谱补全和欺诈关系发现；也是最容易“高分但无效”的图任务。
## 3. 学它之前需要哪些前置知识？
1. [[三元闭包弱关系与同质性]]。
2. 二分类、ROC-AUC/PR-AUC。
## 4. 用直觉语言解释它
> “只允许看过去的朋友圈猜未来，不许先看到答案边再计算共同邻居。”
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
对当前非边 $(u,v)$ 计算分数：$CN=|N(u)\cap N(v)|$，$J=CN/|N(u)\cup N(v)|$，$AA=\sum_{w\in N(u)\cap N(v)}1/\log d(w)$，$PA=d(u)d(v)$。
### 2. 核心公式
用训练图 $G_{train}$ 计算所有特征；测试正边 $E_{test}$ 与训练边不交，负边不在完整观察图中。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $E^+,E^-$ | 正/负样本 | 负样本是未观测，不必然真实负 |
| AUC | 排序正边高于负边概率 | 类不平衡时补 PR-AUC |
### 4. 常见变体与适用条件
时间数据优先时间切分；静态图边切分需保持训练图基本连通；有向图需定义候选方向。
## 6. 推导思路和思想来源
闭包产生邻域相似度；高度 hub 造成 PA 基线。正确评估先冻结切分，再只在训练图提特征；阈值和超参数仅用验证集。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
$N(u)=\{a,b,c\},N(v)=\{b,c,d\}$：$CN=2,J=0.5$；若 $d(b)=2,d(c)=4$，$AA=1/\ln2+1/\ln4$。
### 例子 2
随机删除桥边可能使训练图断裂并改变所有距离特征；时间切分更贴近部署，但需处理新节点冷启动。
### 例子 3（代码）
```python
import networkx as nx
g = nx.Graph([(0, 2), (0, 3), (1, 2), (1, 3), (1, 4)])
print(list(nx.jaccard_coefficient(g, [(0, 1)]))[0][2])
print(list(nx.adamic_adar_index(g, [(0, 1)]))[0][2])
# Jaccard = 2/3；AA 按共同邻居度数加权。
```
## 8. 常见误区和易混概念
- **误区**：在完整图上计算特征再切分。纠正：测试边已经改变邻域与距离。
| 指标 | 偏好 | 优点 | 限制 |
| :--- | :--- | :--- | :--- |
| CN | 共同邻居多 | 简单 | 偏高度 |
| Jaccard | 重叠比例 | 度归一化 | 小集合不稳 |
| AA | 稀有共同邻居 | 降权 hub | log 度敏感 |
| PA | 高度端点 | 强基线 | 不看局部闭包 |

## 11. 自测题：5 道
1. Jaccard 分母是什么？ #自测题/基础
   > [!question]- 邻居并集大小。
2. AA 为何降权高度共同邻居？ #自测题/基础
   > [!question]- 权重为 $1/\log d(w)$。
3. 什么是结构特征泄漏？ #自测题/中等
   > [!question]- 测试边参与了训练特征或嵌入计算。
4. 类极不平衡为何看 PR-AUC？ #自测题/中等
   > [!question]- ROC-AUC 可能掩盖大量假阳性，PR 更关注正类质量。
5. 设计无未来信息的负采样。 #自测题/较难
   > [!question]- 在预测时点前未连且在观察窗口末仍未连的候选中抽样，并说明未观测不等于真实负的限制。
