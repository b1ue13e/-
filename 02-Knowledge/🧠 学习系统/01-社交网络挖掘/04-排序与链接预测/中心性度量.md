# 中心性度量

## 0. 先判断它值不值得深挖
- **类别**：A 类。不同“重要”定义对应不同任务，不能只给一个排行榜。
## 1. 这个知识点解决什么问题？
> 在网络中找直接连接多、到全网近、控制最短路或连接重要节点的不同角色。
## 2. 为什么它重要？它有什么用？
- hub 发现、桥梁识别、设施选址、传播种子基线。
- HW4 直接考近似介数；HW3 用高度种子与随机种子比较。
## 3. 学它之前需要哪些前置知识？
1. [[../01-图与网络基础/路径连通与Bow-tie结构]]。
2. 归一化和最短路计数。
## 4. 用直觉语言解释它
> 度看“认识多少人”，接近看“到大家多快”，介数看“多少最短路经过我”，特征向量看“我认识的人是否也重要”。
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
$$C_D(v)=\frac{d(v)}{n-1},\quad C_C(v)=\frac{n-1}{\sum_{u\ne v}d(v,u)},$$
$$C_B(v)=\sum_{s\ne v\ne t}\frac{\sigma_{st}(v)}{\sigma_{st}},\quad Ax=\lambda x.$$
### 2. 核心公式
非连通图优先 harmonic closeness：$C_H(v)=\sum_{u\ne v}1/d(v,u)$，不可达项为 0。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $\sigma_{st}$ | $s,t$ 最短路数 | 介数分母 |
| $x$ | 特征向量分数 | 非负连通图用主特征向量 |
### 4. 常见变体与适用条件
有向图区分入/出度；接近需声明可达口径；介数是否计端点与归一化需声明。
## 6. 推导思路和思想来源
中心性不是单一真值：局部受欢迎、全局效率、桥接控制、递归声望分别形成四类目标。选指标必须先写任务语义。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
四节点星图中心度中心性 1，叶子 $1/3$；中心到其余距离和 3，接近为 1；中心承载所有叶子对最短路，介数最高。
### 例子 2
两个团之间的单桥端点度不一定最高，但介数很高，说明“朋友多”和“跨圈控制”不同。
### 例子 3（代码）
```python
import networkx as nx
g = nx.star_graph(3)
print(nx.degree_centrality(g))
print(nx.closeness_centrality(g))
print(nx.betweenness_centrality(g, normalized=False))
# 中心节点 0 在三种指标上均最高。
```
## 8. 常见误区和易混概念
- **误区**：高度节点必是最佳传播种子。传播模型、社区与冗余会改变结果。
| 指标 | 信息范围 | 擅长角色 | 弱点 |
| :--- | :--- | :--- | :--- |
| 度 | 一跳 | 本地 hub | 忽略全局 |
| 接近 | 全局距离 | 快速触达 | 非连通敏感 |
| 介数 | 全局最短路 | 桥梁 | 计算昂贵 |
| 特征向量 | 递归邻居 | 声望 | 可能集中在单一组件 |

## 11. 自测题：5 道
1. 度中心性只看几跳？ #自测题/基础
   > [!question]- 一跳。
2. 星图中心接近为何高？ #自测题/基础
   > [!question]- 到所有叶子均为一步。
3. 非连通图为何用 harmonic closeness？ #自测题/中等
   > [!question]- 不可达距离的倒数自然记 0，避免无限距离破坏平均。
4. 介数为何需 $\sigma_{st}$？ #自测题/中等
   > [!question]- 多条最短路时应按经过 $v$ 的比例分摊。
5. 构造度低但介数高的节点。 #自测题/较难
   > [!question]- 两个团之间唯一桥的端点只需少量边却承载大量跨团最短路。
