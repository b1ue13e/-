# SIR 网络流行病模型

## 0. 学习边界
- **类别**：A 类；HW3 最大编程实验之一。
## 1. 这个知识点解决什么问题？
> 在固定网络上，感染、恢复、初始种子和社区结构如何共同决定爆发概率与最终感染比例？
## 2. 为什么它重要？它有什么用？
疾病、恶意软件、一次性信息传播；连接网络结构与统计显著性。
## 3. 学它之前需要哪些前置知识？
1. [[随机网络模型-ER-WS-BA-配置模型]]。
2. 伯努利试验、蒙特卡洛与卡方检验。
## 4. 用直觉语言解释它
> S 是可感染者，I 是正在传播者，R 是退出传播且不再感染者。
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
每轮每条 I-S 边以概率 $\beta$ 感染，I 节点以概率 $\delta$ 恢复到 R。
### 2. 核心公式
有 $m$ 个感染邻居时，本轮至少一次感染概率 $1-(1-\beta)^m$。模拟结束时累计感染比例 $|R|/|V|$（若无 I）。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $\beta$ | 单边感染概率 | 每轮 |
| $\delta$ | 恢复概率 | 感染期约 $1/\delta$ 轮 |
### 4. 常见变体与适用条件
SIS 恢复后回 S；SEIR 加潜伏态 E。更新必须基于轮初状态，避免新感染者同轮继续感染。
## 6. 推导思路和思想来源
网络替代均匀混合假设；度异质提高 hub 种子效应，社区内密集传播但跨社区桥限制全局规模。单次模拟随机性大，需重复实验和置信/显著性报告。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
$\beta=0.2$、3 个感染邻居，感染概率 $1-0.8^3=0.488$。
### 例子 2
PA 网络随机种子常落在叶子导致快速熄灭；命中 hub 后爆发更强，因此分布可能双峰。
### 例子 3（代码）
```python
import random
import networkx as nx

def sir_once(g, seed, beta=0.2, delta=0.5, rng=None):
    rng = rng or random.Random(0)
    susceptible, infected, recovered = set(g) - {seed}, {seed}, set()
    while infected:
        new_i = {u for u in susceptible
                 if any(rng.random() < beta for v in g[u] if v in infected)}
        new_r = {u for u in infected if rng.random() < delta}
        susceptible -= new_i; infected = (infected | new_i) - new_r; recovered |= new_r
    return len(recovered) / g.number_of_nodes()

print(0 <= sir_once(nx.path_graph(8), 0) <= 1)
# 输出：True
```
## 8. 常见误区和易混概念
- **误区**：新感染者同轮继续传播。纠正：题目伪代码通常采用同步快照。
| 模型 | 恢复后 | 记忆 | 典型应用 |
| :--- | :--- | :--- | :--- |
| SI | 保持 I | 无恢复 | 累积采用 |
| SIS | 回 S | 无免疫 | 可重复感染 |
| SIR | 进 R | 永久免疫/退出 | 一次疫情 |
| 阈值 | 通常保持活跃 | 累积暴露 | 行为采用 |
