# 影响力最大化与贪心算法

## 0. 先判断它值不值得深挖
- **类别**：A 类；HW3-Q4 要求构造贪心反例和理解上界。
## 1. 这个知识点解决什么问题？
> 给定预算 $k$，选哪些种子使期望传播范围最大？精确枚举不可行，何时贪心有保证？
## 2. 为什么它重要？它有什么用？
营销、疫苗/阻断、信息投放；把传播模型提升为优化问题。
## 3. 学它之前需要哪些前置知识？
1. [[阈值模型与网络级联]]。
2. 边际增益、单调性与集合包含。
## 4. 用直觉语言解释它
> 每次选择“在已有种子之外还能多覆盖最多人”的节点；覆盖重叠越大，后来的边际收益越小。
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
$$\max_{S\subseteq V,|S|\le k}\sigma(S),\qquad \Delta(u\mid S)=\sigma(S\cup\{u\})-\sigma(S).$$
次模性：若 $A\subseteq B$，则 $\Delta(u\mid A)\ge\Delta(u\mid B)$。
### 2. 核心公式
单调次模且 $\sigma(\varnothing)=0$ 时，贪心达到 $(1-1/e)$ 近似；随机传播下 $\sigma$ 用蒙特卡洛估计。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $S,k$ | 种子集/预算 | 离散约束 |
| $\sigma(S)$ | 期望影响范围 | 含种子与否需声明 |
| $\Delta$ | 边际增益 | 贪心选择依据 |
### 4. 常见变体与适用条件
IC/LT 下经典期望影响单调次模；任意竞争传播、非单调行为不自动满足。CELF 只缓存边际增益，不改变解。
## 6. 推导思路和思想来源
贪心可能非最优，因为早期选择覆盖大但与后续候选高度重叠。次模性保证每步至少吃掉当前最优剩余差距的 $1/k$，递推得到 $1-1/e$。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
覆盖集 $X_a=\{1,2,3,4\},X_b=\{1,2,5\},X_c=\{3,4,6\}$，预算 2。贪心先选 $a$，再增益仅 1，总 5；最优 $b+c$ 覆盖 6。
### 例子 2
高度中心性会重复覆盖同一社区；边际增益会倾向补充未覆盖社区。
### 例子 3（代码）
```python
cover = {"a": {1,2,3,4}, "b": {1,2,5}, "c": {3,4,6}}
selected, reached = [], set()
for _ in range(2):
    node = max((u for u in cover if u not in selected),
               key=lambda u: len(cover[u] - reached))
    selected.append(node); reached |= cover[node]
print(selected, len(reached))
# 输出以并列打破顺序为准；若先 a，最终覆盖 5，展示非最优。
```
## 8. 常见误区和易混概念
- **误区**：贪心总最优。纠正：只有近似保证；HW3 明确要求反例。
| 方法 | 选择依据 | 成本 | 特点 |
| :--- | :--- | :--- | :--- |
| 度启发式 | 局部度 | 低 | 忽略重叠 |
| 贪心 IM | 模拟边际增益 | 高 | 有次模保证 |
| CELF | 延迟重算边际增益 | 较低 | 与贪心同解 |
| RIS | 反向可达集合覆盖 | 可扩展 | 概率保证依实现而定 |

2. 次模性表达什么？ #自测题/基础
   > [!question]- 集合越大，新元素的边际收益不增。

   > [!question]- 单调次模条件下为 $1-1/e$。

   > [!question]- 边际增益是随机估计，噪声可能颠倒候选排序；需共同随机数/置信区间或足够样本。
