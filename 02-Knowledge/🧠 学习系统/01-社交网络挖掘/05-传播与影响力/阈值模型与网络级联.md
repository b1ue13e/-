# 阈值模型与网络级联

## 0. 学习边界
- **类别**：A 类；HW2/HW3 直接主线。
## 1. 这个知识点解决什么问题？
> 个体要看到多少人或多大邻居比例采用行为才跟随？小种子何时停住、何时引发宏观级联？
## 2. 为什么它重要？它有什么用？
创新采用、投票、抗议、产品扩散；训练同步/异步更新与固定点推理。
## 3. 学它之前需要哪些前置知识？
1. 累计直方图与归纳。
2. [[图与网络基础]]。
## 4. 用直觉语言解释它
> 每个人都有“跟随门槛”；当前活跃规模跨过更多人的门槛，就会自我强化。
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
HW3 全局阈值模型：个体 $i$ 至少看到 $t_i$ 个**其他人**已参与时加入，参与不可逆。阈值 0 的人初始参与。若阈值直方图为 $N_\ell$，定义累计人数
$$C(k)=\sum_{\ell=0}^{k}N_\ell,\qquad C(n)=n.$$
### 2. 核心公式
从 $a_0=N_0$ 出发，精确迭代为 $a_{r+1}=C(a_r)$；最终规模是
$$R=\min\{k\in\{0,\ldots,n\}:C(k)=k\}.$$
阈值为 $\ell$ 的组能激活，当且仅当对所有 $k=1,\ldots,\ell$ 都有 $C(k-1)\ge k$。完整证明任务见[[社交网络挖掘-课后作业-04-幂律传播与影响力#1. 群体心理与阈值（10 分，Yokila）|课后作业 04 题 1]]。网络 LT 则是另一模型：$\sum_{u\in N(v)\cap A_t}w_{uv}\ge\theta_v$。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $t_i,\theta_i$ | 绝对/比例阈值 | 不可混用 |
| $A_t,a_t$ | 活跃集合/规模 | 通常单调不可逆 |
### 4. 常见变体与适用条件
同步更新用上一轮快照；异步更新立刻影响后续节点，结果可能依赖顺序。
## 6. 推导思路和思想来源
累计直方图给出“在当前规模下愿意激活的人数”；全局模型的逐层不等式、首个失败阈值和最小固定点等价，证明任务见[[社交网络挖掘-课后作业-04-幂律传播与影响力#1. 群体心理与阈值（10 分，Yokila）|课后作业 04 题 1]]。网络版本把全局人数替换为加权邻居暴露，不能沿用同一累计直方图公式。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
阈值 $[0,1,1,3]$：初始门槛 0 的 1 人激活，随后两个门槛 1 激活，规模到 3，再激活门槛 3，最终 4。
### 例子 2
在环上同步多数规则可能停在局部块；异步按 ID 更新可在同一轮继续传播，必须复现题目顺序。
### 例子 3（代码）
```python
thresholds = [0, 1, 1, 3]
active = 0
while True:
    updated = sum(t <= active for t in thresholds)
    if updated == active:
        break
    active = updated
print(active)
# 输出：4
```
## 8. 常见误区和易混概念
- **误区**：阈值模型等于 IC。阈值是累积暴露决定，IC 是边独立尝试。
| 模型 | 随机性 | 激活依据 | 可恢复 |
| :--- | :--- | :--- | :--- |
| 全局阈值 | 阈值可异质 | 总活跃人数 | 通常否 |
| LT | 阈值/权重 | 邻居权重和 | 通常否 |
| IC | 边尝试随机 | 单次感染尝试 | 否 |
| SIR | 感染/恢复随机 | 感染邻居 | 是，进入 R |
