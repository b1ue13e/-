# 阈值模型与网络级联

## 0. 先判断它值不值得深挖
- **类别**：A 类；HW2/HW3 直接主线。
## 1. 这个知识点解决什么问题？
> 个体要看到多少人或多大邻居比例采用行为才跟随？小种子何时停住、何时引发宏观级联？
## 2. 为什么它重要？它有什么用？
创新采用、投票、抗议、产品扩散；训练同步/异步更新与固定点推理。
## 3. 学它之前需要哪些前置知识？
1. 累计直方图与归纳。
2. [[../01-图与网络基础/图与网络基础]]。
## 4. 用直觉语言解释它
> 每个人都有“跟随门槛”；当前活跃规模跨过更多人的门槛，就会自我强化。
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
全局阈值模型：个体 $i$ 在活跃人数 $a_t\ge t_i$ 时激活。若阈值直方图为 $N_\ell$，累计 $F(a)=\sum_{\ell=0}^{a}N_\ell$。
### 2. 核心公式
迭代 $a_{t+1}=F(a_t)$（按题目“其他人/含自身”口径可能偏移 1）；最终规模是从初始值出发到达的最小稳定固定点。网络 LT：$\sum_{u\in N(v)\cap A_t}w_{uv}\ge\theta_v$。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $t_i,\theta_i$ | 绝对/比例阈值 | 不可混用 |
| $A_t,a_t$ | 活跃集合/规模 | 通常单调不可逆 |
### 4. 常见变体与适用条件
同步更新用上一轮快照；异步更新立刻影响后续节点，结果可能依赖顺序。
## 6. 推导思路和思想来源
累计直方图给出“在当前规模下愿意激活的人数”；反复应用直到人数不再增加。网络版本把全局人数替换为加权邻居暴露。
## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
阈值 $[0,1,1,3]$：初始门槛 0 的 1 人激活，随后两个门槛 1 激活，规模到 3，再激活门槛 3，最终 4。
### 例子 2
在环上同步多数规则可能停在局部块；异步按 ID 更新可在同一轮继续传播，必须复现题目顺序。
### 例子 3（代码）
```python
thresholds = [0, 1, 1, 3]
active = 0
while True:
    updated = sum(t <= active for t in thresholds)
    if updated == active:
        break
    active = updated
print(active)
# 输出：4
```
## 8. 常见误区和易混概念
- **误区**：阈值模型等于 IC。阈值是累积暴露决定，IC 是边独立尝试。
| 模型 | 随机性 | 激活依据 | 可恢复 |
| :--- | :--- | :--- | :--- |
| 全局阈值 | 阈值可异质 | 总活跃人数 | 通常否 |
| LT | 阈值/权重 | 邻居权重和 | 通常否 |
| IC | 边尝试随机 | 单次感染尝试 | 否 |
| SIR | 感染/恢复随机 | 感染邻居 | 是，进入 R |
