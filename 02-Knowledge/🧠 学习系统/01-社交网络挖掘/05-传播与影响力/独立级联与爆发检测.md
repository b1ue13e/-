# 独立级联与爆发检测

## 0. 学习边界

- **类别**：A 类传播与干预核心。
- **判断理由**：阈值模型描述“邻居比例够不够”，SIR 描述感染与恢复；独立级联（IC）描述每条关系的一次随机传播机会，并自然连接影响力最大化和传感器放置。

## 1. 这个知识点解决什么问题？

> 在有向概率网络上，怎样模拟一次性随机传播？当不能阻止爆发时，怎样用有限传感器尽早发现并覆盖尽可能多的传播场景？

## 2. 为什么它重要？它有什么用？

- 建立信息扩散、病毒营销和告警传播的最小随机模型。
- 解释[[影响力最大化与贪心算法]]中单调性/子模性保证来自哪里。
- 把“选最有影响力节点”与“选最早检测节点”区分开：目标函数和最优位置可能不同。

## 3. 学它之前需要哪些前置知识？

1. [[阈值模型与网络级联]]：对照确定性/阈值式更新。
2. [[SIR网络流行病模型]]：对照重复时间步、感染与恢复状态。
3. [[影响力最大化与贪心算法]]：理解集合边际增益与预算约束。

## 4. 用直觉语言解释它

> 每个刚收到消息的人只给每位邻居打一次电话，接通概率由边决定；爆发检测则是在网络中放少量报警器，希望任何常见传播路径都尽早碰到一个报警器。

## 5. 正式定义、核心公式、符号解释

### 1. Independent Cascade

给定有向图 $G=(V,E)$、边传播概率 $p_{uv}$ 和初始激活集合 $S$：

1. $t=0$ 时仅 $S$ 激活。
2. 节点 $u$ 在时刻 $t$ 首次激活后，对每个尚未激活的出邻居 $v$ 尝试一次，成功概率为 $p_{uv}$。
3. 成功的 $v$ 在 $t+1$ 激活；无论成功与否，$u$ 不再对 $v$ 重试。
4. 没有新节点激活时停止。

### 2. 活边图等价

预先独立采样每条边是否“活”：

$$
L_{uv}\sim\operatorname{Bernoulli}(p_{uv}).
$$

最终激活集合等于从 $S$ 在活边子图中可达的节点集合。该视角把随机过程转成随机可达性，便于证明传播范围的单调性和子模性。

### 3. 爆发场景与检测

对场景 $i$，设传播到节点 $v$ 的时间为 $T_i(v)$，传感器集合为 $A$。检测时间

$$
T_i(A)=\min_{v\in A}T_i(v),
$$

若场景未触及任何传感器则为 $\infty$。目标可组合：

- **检测概率**：$P(T_i(A)<\infty)$；
- **检测时延**：越小越好；
- **检测前受影响规模**：越小越好；
- **传感器成本**：$\sum_{v\in A}c_v\le B$。

必须先固定效用/损失，再选择算法；“最高度节点”不是通用答案。

### 4. 场景覆盖式效用

若每个场景对节点 $v$ 有非负收益 $b_{iv}$，集合效用写成

$$
F(A)=\sum_i w_i\max_{v\in A}b_{iv}.
$$

它是单调子模的：新增传感器对较大集合的边际收益不超过对较小集合的收益，因此单位成本贪心可作为可解释基线；具体保证取决于预算与算法条件。

## 6. 推导思路和证据链

1. 用固定随机数/活边样本让不同种子集合共享传播场景，降低比较噪声。
2. 在小图枚举所有活边子图，验证 IC 实现的最终可达分布。
3. 为每个场景预计算到达时间或传播序列。
4. 明确检测目标：时延、覆盖、受影响人数或组合效用。
5. 对每个候选传感器计算边际收益，按预算选择，并与随机、度、介数基线同场景比较。
6. 多种子/多场景报告均值、分位数和失败场景，不只报平均值。

## 7. 例子：手算 → 目标差异 → 可运行代码

### 例子 1：三节点链

$a\to b\to c$，两条边概率均为 $1/2$，种子为 $a$：

- $P(b\text{ 激活})=1/2$；
- $P(c\text{ 激活})=(1/2)(1/2)=1/4$；
- 期望激活数为 $1+1/2+1/4=1.75$。

### 例子 2：影响力与检测不同

源点附近的传感器可更早检测，却未必是能触达最多节点的种子；一个高度 hub 若位于传播下游，影响力可能高但检测时延较大。

### 例子 3：可运行 IC 与检测时间

```python
from collections import deque
import random
import networkx as nx

def independent_cascade(graph, seeds, probability, seed=0):
    rng = random.Random(seed)
    active = set(seeds)
    queue = deque((node, 0) for node in seeds)
    activation_time = {node: 0 for node in seeds}
    while queue:
        source, time = queue.popleft()
        for target in graph.successors(source):
            if target in active:
                continue
            if rng.random() < probability[(source, target)]:
                active.add(target)
                activation_time[target] = time + 1
                queue.append((target, time + 1))
    return active, activation_time

graph = nx.DiGraph([("a", "b"), ("b", "c")])
probability = {("a", "b"): 0.5, ("b", "c"): 0.5}
active, times = independent_cascade(graph, {"a"}, probability, seed=3)
detection = min((times[node] for node in {"b", "c"} if node in times), default=float("inf"))
assert detection in {1, float("inf")}
print(active, times, detection)
```

- **依赖**：`networkx>=3.2`。
- **输入**：有向图、边概率、种子、随机种子与传感器集合。
- **输出**：最终激活集合、激活时间与检测时间；正式实验需重复场景和置信区间。

## 8. 常见误区和概念对比

- **每轮重复尝试同一边**：IC 中新激活节点对目标只有一次机会。
- **把 $p_{uv}$ 当节点概率**：传播概率属于有向边，反向边可不同或不存在。
- **检测失败记为 0 时延**：应单独报告未检测比例或定义惩罚。
- **用不同随机场景比较方法**：会把 Monte Carlo 噪声误当算法差异。

| 模型/任务 | 状态与随机性 | 核心目标 |
| :--- | :--- | :--- |
| 线性阈值 | 邻居权重累计超过阈值 | 复杂社会强化 |
| 独立级联 | 每条边一次独立尝试 | 简单随机扩散 |
| SIR | 感染与恢复随时间演化 | 疾病过程与峰值/规模 |
| 影响力最大化 | 选择传播种子 | 最大化期望覆盖 |
| 爆发检测 | 选择传感器 | 早发现、少损失、低成本 |

## 11. 自测题：5 道

1. IC 中失败的边下一轮能否重试？ #自测题/基础
   > [!question]- 不能；源节点首次激活后对该目标只有一次机会。
2. 活边图中最终激活节点是什么？ #自测题/基础
   > [!question]- 从种子集合沿活的有向边可达的全部节点。
3. 传感器未被传播触及时延是多少？ #自测题/中等
   > [!question]- 通常记为无穷或按预声明惩罚处理，并单报未检测比例，不能记 0。
4. 为什么方法比较要共享传播场景？ #自测题/中等
   > [!question]- 降低 Monte Carlo 方差，避免随机样本差异冒充算法增益。
5. 场景最大收益和为何具有递减收益？ #自测题/较难
   > [!question]- 集合已有更多传感器时，新增节点能改善的场景最大值只会减少或不变。
