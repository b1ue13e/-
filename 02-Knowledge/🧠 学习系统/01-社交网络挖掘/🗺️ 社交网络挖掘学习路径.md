# 🗺️ 社交网络挖掘学习路径

> **学习者任务**：从真实网络的数据契约出发，依次掌握结构统计、生成机制、社会结构、排序预测、传播干预与表示学习，最终完成一份可复现、无数据泄漏、结论边界清楚的网络挖掘项目。

## 课程目标

完成本路线后，你应能：

1. 把现实关系建模为有向、无向、加权或符号图，并解释清洗口径。
2. 计算并解释度、余度、聚类、距离、中心性、社区与连通结构。
3. 区分 ER、WS、BA、配置模型与 Kronecker 模型的机制、假设和失效边界。
4. 正确实现 PageRank、链接预测、传播模型与影响力优化的最小基线。
5. 在固定切分、版本、随机种子和 Rubric 下比较传统特征、节点嵌入与 GNN。

## 最低前置与启动门

- **数学**：集合与关系、矩阵乘法、特征值直觉、基础概率与对数。
- **编程**：能阅读 Python 函数，使用列表/集合/字典，安装并调用 `numpy`、`networkx`。
- **启动诊断**：先完成[[数学与Python前置诊断]]；未通过的题只回补对应前置，不通读无关教材。
- **来源与环境**：需要核对教材、课程版本、许可证或数据时进入[[📚 教材挂载索引]]。

## 建议节奏与阶段衔接

每次学习采用“10 分钟闭卷回忆 → 30–50 分钟新内容 → 20–30 分钟手算/代码”。每个阶段按以下循环推进：

1. 先读阶段 MOC 中的“为什么现在学”和知识顺序。
2. 每张主题卡完成手算例、代码例与检索练习，不以阅读完成代替掌握。
3. 做对应课后作业；错题按题号回流到主题卡。
4. 完成阶段作业并满足阶段 Rubric 后，才进入下一阶段。
5. 代码结果必须来自真实运行记录；无正式数据证据时保持 `planned/ongoing`。

## 课程完成标准

- [ ] 六个阶段 MOC 与全部主题卡按顺序完成。
- [ ] 每张可验收主题卡至少链接一份可执行作业或检索产物。
- [ ] 五份课后作业保留稳定题号、来源边界、知识反链、提交物与验收口径。
- [ ] 六份阶段作业均留下自己的推导、代码、图表或失败记录。
- [ ] 大作业可从 `README`/manifest 复现，baseline 与改进方法使用同一切分。
- [ ] 不保存官方/第三方答案，不把未运行代码、失效数据或搜索摘要写成已验证结果。

## 失败时如何回流

- **数据计数或方向错误** → 阶段 1 的有向统计与连通卡。
- **模型曲线能画但不会解释** → 阶段 2 的生成机制与统计口径。
- **社区结论不稳定** → 阶段 3 的目标函数、随机性与分辨率限制。
- **链接预测指标异常高** → 阶段 4 的无泄漏切分与负采样。
- **传播结果方差大** → 阶段 5 的随机种子、终止规则与条件均值。
- **GNN 只赢单次结果** → 阶段 6 的传统基线、消融与多种子报告。
