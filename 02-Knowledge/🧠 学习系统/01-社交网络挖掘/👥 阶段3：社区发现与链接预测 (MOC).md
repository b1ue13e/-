# 👥 阶段3：社区发现与链接预测 (MOC)

> [!NOTE] 阶段导读
> “圈子”和“牵线搭桥”是社交网络永恒的主题。本阶段我们将解决网络挖掘的两大核心任务：**社区发现 (Community Detection)**（宏观上把网络切分为不同的社交圈子或兴趣群组）与 **链接预测 (Link Prediction)**（微观上推断两个素不相识的人未来是否会建立联系）。这两者本质上都在揭示网络潜在的“结构一致性”。

## 📍 核心概念导航 (Core Concepts)

### 1. 社区发现基础理论
没有定义就无法计算，如何用数学严格定义“小圈子”？
- [[社区定义]]：内部紧密、外部稀疏的模块化结构。
- [[模块度]] (Modularity, $Q$)：衡量社区划分质量的最核心目标函数。
- [[分辨率极限]]：模块度自身在极大网络中会“无视”微小社区的严重缺陷。

### 2. 经典社区发现算法 (Community Detection)
各显神通的聚类切分策略。
- **分裂法**：[[GN算法]]（Girvan-Newman，不断切断中介连边）。
- **凝聚法/启发式优化**：[[Louvain算法]]（自底向上贪心折叠，工业界标配）。
- **信息论/随机游走**：[[Infomap]]（用哈夫曼编码压缩随机游走轨迹）、[[Walktrap]]。
- **传播动力学**：[[LPA算法]]（标签传播算法，靠邻居投票快速收敛）。
- **重叠社区**：[[BigClam重叠社区发现]]（一个人可以同时属于工作圈和生活圈）。

### 3. 链接预测：基于拓扑启发式指标 (Heuristics)
“你可能认识的人”背后的经典规则。
- **局部指标 (Local)**：[[共同邻居]] (CN)、[[Jaccard系数]]、[[Adamic-Adar]] (AA指数)、[[优先连接]] (PA)。
- **全局与路径指标 (Global/Path)**：[[Katz指标]]（统计所有高阶路径并衰减）、[[随机游走链接预测]]（Rooted PageRank 与 SimRank）。

### 4. 链接预测：机器学习与深度学习框架
将启发式规则升级为特征工程与神经网络。
- [[链接预测ML框架]]：将边预测转化为二分类任务的通用 Pipeline。
- [[拓扑特征工程]]与[[嵌入特征]]：如何为节点对提取用于 XGBoost / RF 的特征向量。
- [[GNN链接预测]]：使用 GCN/GraphSAGE 结合 Negative Sampling 进行端到端边预测。

### 5. 高级网络结构模型与演化机制
更复杂的网络生成原理与宏观现象。
- **网络生成模型**：[[随机块模型SBM]] (Stochastic Block Model，图聚类的生成式基准)、[[指数随机图模型ERGM]] (用指数族分布拟合网络结构)。
- **市场匹配与群体博弈**：[[二部图匹配与匹配市场]]（广告竞价拍卖与相亲市场的底层图论逻辑）、[[结构平衡理论]]（“敌人的敌人是朋友”在符号网络上的数学证明）。
- **图模式挖掘**：[[频繁子图挖掘gSpan]]（在大量小图中寻找高频化学分子或Motif）、[[谱聚类-社交网络应用]]（基于拉普拉斯矩阵降维的图切割）。

## 🛠️ 工程与工具实战 (Tools)

- **Python生态**：
  - [[NetworkX社区]]：网络基础库自带的贪心模块度、连通分量工具。
  - [[igraph社区]]：C底层高性能实现，可快速跑通几十万节点的 Louvain、Infomap。
  - [[CDlib]]：专门用于社区发现与评估的最全大一统开源库 (Community Discovery Library)。
