> [!NOTE] 核心直觉：派系分流与信息传递
> **类比**：想象一个班级里因两位核心班长产生矛盾而撕裂成两个小圈子。我们只明确知道两位班长各自的政治阵营（极少量已知标签），但通过观察同学们日常打游戏、一起吃饭的频繁互动网络（图拓扑结构），沿着社交边传递“影响力与亲疏度”（图卷积/消息传递），就能精准预测班里其他每一位同学最终会站队哪一方。

## 1. 为什么需要这个知识点？
- **背景**：韦恩·扎卡里（Wayne W. Zachary）在 1970-1973 年间观察记录了某大学空手道俱乐部的 34 名成员及其 78 条社交互动边。最终俱乐部因管理者（President, 节点 33）与教练（Mr. Hi, 节点 0）的冲突分裂为两大派系。该经典数据集（Zachary's Karate Club）成为了图机器学习（Graph Machine Learning）与社交网络挖掘中节点分类（Node Classification）与社区发现（Community Detection）的“Hello World”基准标杆。
- **痛点**：传统机器学习模型假设样本独立同分布（i.i.d.），忽视了节点之间的结构关联（Graph Topology）；而单纯依靠图拓扑距离（如最短路径）又无法灵活融合节点属性特征与极少量监督标签，导致半监督学习场景下的泛化能力较差。
- **意义**：空手道俱乐部节点分类任务示范了从“纯拓扑分析（如拉普拉斯谱聚类 Fiedler 向量）”过度到“现代图神经网络半监督节点分类（GCN/PyTorch）”的全过程。通过极少量的已知标签（例如仅提供 2 个领袖节点的标签），利用图结构中的信息传播（Message Passing）实现全局节点的精准预测，为现实中风控反欺诈、推荐系统用户画像归类、生物网络蛋白质功能预测提供了基石范式。

## 2. 核心定义与公式/代码

### (1) 图结构与拉普拉斯谱分解 (Spectral Formulation)
设社交网络为无向图 $G = (V, E)$，其中 $|V| = 34$ 个节点，$|E| = 78$ 条边。
- **邻接矩阵** $A \in \{0, 1\}^{34 \times 34}$，度矩阵 $D_{ii} = \sum_{j} A_{ij}$。
- **未规范化拉普拉斯矩阵** $L = D - A$。
- **对称规范化拉普拉斯矩阵** $L_{\text{sym}} = D^{-1/2} L D^{-1/2} = I - D^{-1/2} A D^{-1/2}$。
- **Fiedler 向量划分**：计算 $L_{\text{sym}}$ 的特征值 $0 = \lambda_1 \le \lambda_2 \le \dots \le \lambda_N$，第二最小特征值 $\lambda_2$ 对应的特征向量 $\mathbf{v}_2$ 称为 **Fiedler 向量**。节点 $i$ 的派系归属可根据 $v_{2, i} > 0$ 或 $v_{2, i} < 0$ 进行符号符号划分。

### (2) 图卷积网络 (GCN) 半监督分类公式
在极少数标定节点 $\mathcal{V}_L$（如仅已知节点 0 属于派系 0，节点 33 属于派系 1）的情况下，GCN 通过自环邻接矩阵与重参数化技巧传播特征：
$$\tilde{A} = A + I_N, \quad \tilde{D}_{ii} = \sum_{j} \tilde{A}_{ij}$$
$$\hat{A} = \tilde{D}^{-1/2} \tilde{A} \tilde{D}^{-1/2}$$
两层 GCN 的前向传播过程：
$$Z = f(X, A) = \text{Softmax}\left( \hat{A} \cdot \text{ReLU}(\hat{A} X W^{(0)}) W^{(1)} \right)$$
其中 $X \in \mathbb{R}^{34 \times F}$ 为节点初始特征（若无节点属性，通常初始化为单位矩阵 $X = I_{34}$ 或 One-hot 编码），$W^{(0)} \in \mathbb{R}^{F \times H}$，$W^{(1)} \in \mathbb{R}^{H \times 2}$。

半监督交叉熵损失函数（仅对训练集节点 $\mathcal{V}_L$ 计算 Loss）：
$$\mathcal{L} = - \sum_{l \in \mathcal{V}_L} \sum_{c=0}^{1} Y_{l, c} \ln Z_{l, c}$$

### (3) Python 完整实战代码 (NetworkX + PyTorch 节点分类)

```python
import networkx as nx
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
import torch.nn.functional as F

# 1. 加载空手道俱乐部网络与真实派系标签
G = nx.karate_club_graph()
num_nodes = G.number_of_nodes()

# 获取真实标签：Mr. Hi 派系 -> 0, Officer 派系 -> 1
labels = np.array([0 if G.nodes[i]['club'] == 'Mr. Hi' else 1 for i in range(num_nodes)])
y = torch.tensor(labels, dtype=torch.long)

# 2. 构建规范化邻接矩阵 \hat{A} = \tilde{D}^{-1/2} \tilde{A} \tilde{D}^{-1/2}
A = nx.to_numpy_array(G)
A_tilde = A + np.eye(num_nodes)
D_tilde = np.diag(np.sum(A_tilde, axis=1))
D_tilde_inv_sqrt = np.power(D_tilde, -0.5)
D_tilde_inv_sqrt[np.isinf(D_tilde_inv_sqrt)] = 0.0
hat_A = torch.tensor(D_tilde_inv_sqrt @ A_tilde @ D_tilde_inv_sqrt, dtype=torch.float32)

# 特征矩阵 X 初始化为单位矩阵 I (无独立属性时使用拓扑 One-hot)
X = torch.eye(num_nodes, dtype=torch.float32)

# 3. 定义简易 GCN 模型
class KarateGCN(nn.Module):
    def __init__(self, in_feats, hidden_dim, num_classes):
        super(KarateGCN, self).__init__()
        self.fc1 = nn.Linear(in_feats, hidden_dim, bias=False)
        self.fc2 = nn.Linear(hidden_dim, num_classes, bias=False)
        
    def forward(self, x, hat_A):
        # 第一层卷积: \hat{A} X W^{(0)}
        h = torch.mm(hat_A, x)
        h = F.relu(self.fc1(h))
        # 第二层卷积: \hat{A} H W^{(1)}
        h = torch.mm(hat_A, h)
        out = self.fc2(h)
        return out

# 4. 设置极端半监督场景：仅提供节点 0 (Mr. Hi) 和节点 33 (Officer) 的标签！
train_mask = torch.zeros(num_nodes, dtype=torch.bool)
train_mask[0] = True   # 教练
train_mask[33] = True  # 管理员

# 5. 模型训练与评估
model = KarateGCN(in_feats=num_nodes, hidden_dim=4, num_classes=2)
optimizer = optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

for epoch in range(1, 201):
    model.train()
    optimizer.zero_grad()
    logits = model(X, hat_A)
    loss = F.cross_entropy(logits[train_mask], y[train_mask])
    loss.backward()
    optimizer.step()

# 推断全图节点归属
model.eval()
with torch.no_grad():
    logits = model(X, hat_A)
    preds = logits.argmax(dim=1)
    acc = (preds == y).float().mean()
    print(f"Epoch 200 | 仅用 2 个训练样本的节点分类准确率: {acc.item() * 100:.2f}%")
```

## 3. 具体应用案例
**场景**：金融反欺诈社交黑灰产团伙挖掘（黑产聚类与节点分类）
- **业务问题**：在某大型支付平台上，团伙作案的诈骗账号经常相互转账或共享设备。安全团队手头只有少量经过司法核实的“已知黑产主谋账号”（标签极少），需要快速找出隐藏在庞大交易网络中的潜在黑产节点（全图节点分类）。
- **解决方案**：
  1. 将用户拟合为节点，交易/社交互为边，构建动态异构社交图。
  2. 以已知被封禁的几个主谋账号（相当于空手道网络中的 Node 0 与 Node 33）作为已知训练集。
  3. 利用 GCN 沿交易边进行消息传递与特征聚合（Message Passing），得到全局节点的风险概率预测向量。
- **效果**：相比传统按单账号规则判断，空手道节点分类范式利用图拓扑关系，在召回率上提升了 40% 以上，准确捕获“游走于边缘的帮凶账号”。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **[误区 1：忽略自环（Self-loop）导致节点自身特征丢失]**：在构建邻接矩阵 $A$ 时，若直接使用原始邻接矩阵而不加上单位矩阵 $I$（即用 $A$ 代替 $\tilde{A}$），会导致图卷积在消息聚合时只累加邻近节点的特征，而完全丢失了节点自身的初始特征，造成特征过度平滑或归零。
> - **[误区 2：在图神经网络中直接划分常规 Train/Test Mask 导致图断裂]**：节点分类是直推式学习（Transductive Learning），训练时模型依然需要全图的邻接矩阵 $A$ 进行消息传递，划分训练/测试集只是限制 Loss 计算的节点 Mask，切勿将测试节点从图拓扑结构中直接删除（否则破坏了连通性）。
