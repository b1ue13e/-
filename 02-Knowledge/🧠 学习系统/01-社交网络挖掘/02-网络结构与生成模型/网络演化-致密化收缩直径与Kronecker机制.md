# 网络演化：致密化、收缩直径与 Kronecker 机制

## 0. 学习边界

- **类别**：A 类核心概念。
- **判断理由**：静态度分布只能描述一个时间点；真实平台、引文网和通信网会增长，模型还必须解释“节点和边怎样一起变化”。

## 1. 这个知识点解决什么问题？

> 给定一系列网络快照 $G_1,G_2,\ldots,G_T$，怎样判断网络是否越来越稠密、典型距离是否变化，以及一个生成机制是否同时复现这些时间规律？

## 2. 为什么它重要？它有什么用？

- 防止用单张快照的拟合替代演化机制证据。
- 为容量规划、传播时延、推荐候选规模和动态图基线提供结构先验。
- 连接[[随机网络模型-ER-WS-BA-配置模型]]与[[Kronecker图与网络演化]]：前者多为静态基线，后者可产生递归增长结构。

## 3. 学它之前需要哪些前置知识？

1. [[图与网络基础]]：节点、边、方向和快照语义。
2. [[度分布余度与幂律估计]]：对数回归只是描述工具，不自动证明机制。
3. [[聚类系数与网络距离]]：有效直径必须在可达节点对和固定分位数下解释。

## 4. 用直觉语言解释它

> 网络像一座增长中的城市：人口增加时，道路增加得更快，平均每人拥有的连接上升；新增捷径还可能让典型出行距离变短。

- **一句话本质**：比较时间快照中的规模、密度和距离，而不是只比较最终图。

## 5. 正式定义、核心公式、符号解释

### 1. 时间快照与一致口径

令 $N_t=|V_t|$、$E_t=|E_t|$。不同时间点必须使用相同的节点身份、边方向、自环/重边处理与观测窗口；否则“演化”可能只是数据管线改变。

### 2. 致密化定律

经验关系常写成

$$
E_t \approx cN_t^a.
$$

- $a=1$：边与节点近似线性增长，平均度大致稳定。
- $a>1$：边增长更快，平均度随时间上升，称为致密化。
- $a$ 由 $\log E_t=\log c+a\log N_t$ 的斜率估计，但必须报告时间点数量、残差和结构断点。

无向图平均度为

$$
\bar d_t=\frac{2E_t}{N_t}\approx2cN_t^{a-1}.
$$

### 3. 有效直径

对可达有序或无序节点对的最短路长度分布 $F_t(\ell)$，固定分位数 $q$ 的有效直径为

$$
D_{q,t}=\inf\{\ell:F_t(\ell)\ge q\}.
$$

“收缩直径”通常指固定 $q$ 下的有效直径随时间下降，不等于最大直径必然下降。必须固定 $q$、方向处理和不可达节点策略。

### 4. 微观演化与宏观规律

局部机制可以包括：优先连接、三元闭包、属性相似、群体加入和复制。宏观致密化/距离变化不能唯一反推出某个微观机制；需比较多个候选模型的多项统计。

## 6. 推导思路和证据链

1. 从带时间戳的边流构造累积或滑窗快照。
2. 对每个快照记录 $N_t,E_t$ 与可达率。
3. 在 log-log 坐标估计 $a$，并检查时间残差、断点和早期小样本影响。
4. 在同一抽样协议下估计 $D_{q,t}$ 与不确定性。
5. 用候选模型生成同规模序列，同时比较边数、度、聚类、有效直径和社区结构。
6. 只有多项演化统计均接近时，才说模型“部分解释”数据；不把单一曲线拟合写成因果结论。

## 7. 例子：手算 → 判断 → 可运行代码

### 例子 1：手算致密化指数

两个快照为 $(N_1,E_1)=(10,20)$、$(N_2,E_2)=(100,800)$：

$$
a=\frac{\log(800/20)}{\log(100/10)}=\log_{10}40\approx1.602.
$$

这两点显示超线性增长，但只有两个时间点，不能检查残差或结构断点。

### 例子 2：边界判断

若平台在 $t=3$ 改为记录点赞边，$E_t$ 突增，不能直接解释为用户关系致密化；应先恢复一致关系定义或把制度变化作为断点。

### 例子 3：可运行最小验证

```python
import numpy as np

nodes = np.array([20, 40, 80, 160], dtype=float)
true_exponent = 1.4
edges = 0.8 * nodes ** true_exponent
estimated, log_c = np.polyfit(np.log(nodes), np.log(edges), 1)
assert abs(estimated - true_exponent) < 1e-12

average_degree = 2 * edges / nodes
assert np.all(np.diff(average_degree) > 0)
print(round(estimated, 3), np.round(average_degree, 3))
# 输出：1.4；平均度随 N 增长。
```

- **依赖**：`numpy>=1.26`。
- **输入**：同口径快照的节点/边计数。
- **输出**：估计指数、残差、平均度序列；真实任务还需有效直径与置信区间。

## 8. 常见误区和概念对比

- **把 $a>1$ 当作普适定律**：它是需在具体数据、时间范围和口径下检验的经验关系。
- **最大直径与有效直径混用**：最大直径对单个离群节点敏感。
- **累积图与滑窗图混用**：累积图只增边，滑窗图允许边消失，问题不同。
- **单指标验证生成模型**：匹配度分布不代表匹配距离、聚类或演化。

| 概念 | 核心问题 | 关键区别 |
| :--- | :--- | :--- |
| 优先连接 | 新边偏向谁 | 微观选择机制 |
| 致密化 | 边数怎样随节点数增长 | 宏观时间规律 |
| 收缩有效直径 | 典型可达距离怎样变化 | 距离分布的固定分位数 |
| Kronecker 机制 | 递归生成能复现哪些统计 | 候选生成模型，不是规律本身 |

## 11. 自测题：5 道

1. $a=1$ 时平均度怎样变化？ #自测题/基础
   > [!question]- 在同一无向图口径下近似保持常数。
2. 为什么有效直径要固定分位数？ #自测题/基础
   > [!question]- 否则不同时间比较的不是同一距离统计，且最大值易受离群点影响。
3. $a>1$ 能证明优先连接吗？ #自测题/中等
   > [!question]- 不能；多种微观机制都可能产生超线性边增长。
4. 平台新增一种边类型后应怎样处理？ #自测题/中等
   > [!question]- 统一历史口径或显式建模为结构断点，不直接并入同一回归。
5. 怎样强验证一个演化模型？ #自测题/较难
   > [!question]- 在同规模时间序列上同时比较边增长、度、聚类、可达率、有效直径和群体结构，并报告不确定性。
