# 度分布、余度与幂律估计

## 0. 先判断它值不值得深挖
- **类别**：**A 类**。HW0、HW1、HW2、HW3 反复使用。
- **判断理由**：度分布描述“连接如何分配”，余度描述“沿随机边看到什么”，幂律估计决定能否合理声称网络存在 hub。

## 1. 这个知识点解决什么问题？
> **麻烦**：平均度相同的两个网络，可能一个人人相近，另一个由少数 hub 占据大部分边。必须研究完整分布，并区分随机选节点与沿边选节点。

## 2. 为什么它重要？它有什么用？
- **大图景**：连接生成模型、流行病阈值、鲁棒性和优先连接。
- **应用**：识别 hub、比较真实网络与零模型、估计传播风险。
- **高频任务**：log-log 图、余度期望、CCDF、逆变换采样、LS 与 MLE。

## 3. 学它之前需要哪些前置知识？
1. **[[../01-图与网络基础/图与网络基础]]**：节点度与握手定理。
2. **概率分布**：PMF/PDF、期望、条件抽样和对数似然。

## 4. 用直觉语言解释它
> “随机问一个人朋友数”和“随机挑一段友谊再看端点朋友数”不是同一抽样；后者更容易撞上社交达人。
- **一句话本质**：沿边采样对高度节点按度加权，产生友谊悖论。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
$p_k=P(D=k)=n_k/n$；平均度 $\langle k\rangle=\sum_k kp_k$。余度 $K=D-1$ 的分布为：
$$q_k=P(K=k\mid\text{沿随机边到达})=\frac{(k+1)p_{k+1}}{\langle k\rangle}.$$

### 2. 核心公式
连续幂律（$x\ge x_{min}$）：$p(x)=(\alpha-1)x_{min}^{\alpha-1}x^{-\alpha}$；
$$P(X\ge x)=\left(\frac{x}{x_{min}}\right)^{1-\alpha},\qquad
\hat\alpha=1+\frac{n}{\sum_i\ln(x_i/x_{min})}.$$

### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $p_k,q_k$ | 度/余度分布 | $q_k$ 按度加权 |
| $\alpha$ | 幂律指数 | 连续模型常要求 $>1$ |
| $x_{min}$ | 幂律尾部起点 | 不能任意固定为最小观测值 |

### 4. 常见变体与适用条件
- 离散度数应使用离散幂律似然；上式 MLE 是连续近似。
- log-log 近似直线只是诊断，不是幂律证据；需与对数正态等候选比较。

## 6. 推导思路和思想来源
- **关键转念**：度为 $k+1$ 的节点有 $k+1$ 个被边抽中的机会，所以概率与 $(k+1)p_{k+1}$ 成正比。
- **CCDF**：对 PDF 从 $x$ 积分到无穷得 $(x/x_{min})^{1-\alpha}$。
- **MLE**：对 $\ell=n\ln(\alpha-1)+n(\alpha-1)\ln x_{min}-\alpha\sum\ln x_i$ 求导并令零。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
度分布 $p_1=1/2,p_3=1/2$，则 $\langle k\rangle=2$；$q_0=1/4,q_2=3/4$。沿边更常遇到度 3 节点。

### 例子 2：中等例子
若连续样本 $x=(1,2,4,8)$、$x_{min}=1$，则 $\hat\alpha=1+4/\ln64\approx1.962$。这只是连续近似，不能直接用于整数度的正式检验。

### 例子 3：实际应用例子（可运行代码）
```python
import math
from collections import Counter

degrees = [1, 1, 3, 3]
counts = Counter(degrees)
n = len(degrees)
p = {k: count / n for k, count in counts.items()}
mean_degree = sum(k * prob for k, prob in p.items())
q = {k - 1: k * prob / mean_degree for k, prob in p.items()}
alpha = 1 + n / sum(math.log(x / 1) for x in [1.1, 2, 4, 8])
print(p, q, round(alpha, 3))
# 输出：{1: 0.5, 3: 0.5} {0: 0.25, 2: 0.75} 2.054
```

## 8. 常见误区和易混概念
### 误区 1：log-log 直线证明幂律
- **为什么错**：有限样本、分箱和其他重尾分布也可近似成直线。
- **正确理解**：估计 $x_{min},\alpha$，检查拟合优度，并与替代分布比较。

| 概念 | 抽样对象 | 典型偏差 | 用途 |
| :--- | :--- | :--- | :--- |
| $p_k$ | 随机节点 | 无度加权 | 描述总体 |
| $q_k$ | 随机边端点 | 偏向 hub | 分支过程、传播 |
| PDF | 点/区间概率 | 尾部噪声大 | 似然 |
| CCDF | 超过阈值概率 | 更稳定 | 尾部分布图 |

   > [!question]- 因为到达节点时已经用掉一条入射边，剩余可继续走的边为 $D-1$。
2. $p_2=1$ 时 $q_k$ 是什么？ #自测题/基础
   > [!question]- $q_1=1$。
3. log-log 直线为什么不充分？ #自测题/中等
   > [!question]- 分箱、有限区间及其他重尾分布都能产生近似直线。
4. 推导连续幂律逆变换采样。 #自测题/中等
   > [!question]- 若 $u\sim U(0,1)$，可取 $x=x_{min}(1-u)^{-1/(\alpha-1)}$。

   > [!question]- 它近似一次沿边扩展后可继续产生的分支数；大于 1 时分支过程可能持续。
