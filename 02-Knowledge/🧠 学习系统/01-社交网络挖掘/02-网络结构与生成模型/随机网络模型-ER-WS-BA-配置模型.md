# 随机网络模型：ER、WS、BA 与配置模型

## 0. 先判断它值不值得深挖
- **类别**：**A 类**。
- **判断理由**：生成模型不是“造假数据”，而是把结构机制变成可反驳的基线；HW1-HW3 要求反复比较它们。

## 1. 这个知识点解决什么问题？
> **麻烦**：观察到高聚类、重尾或易传播时，必须问“仅由规模/密度/度序列能否解释？”不同零模型控制不同因素。

## 2. 为什么它重要？它有什么用？
- ER 控制规模与边密度；WS 加入局部格和捷径；BA 表达增长与优先连接；配置模型固定度序列。
- 用于显著性检验、算法压力测试、机制辨析。
- 高频任务：从零生成、比较度分布/聚类/距离、保度随机化。

## 3. 学它之前需要哪些前置知识？
1. [[度分布余度与幂律估计]]。
2. [[聚类系数与网络距离]]。

## 4. 用直觉语言解释它
> “ER 掷边硬币；WS 给熟人圈加远程捷径；BA 新人追随名人；配置模型按每人的握手配额随机配对。”
- **一句话本质**：每个模型保留一种机制并随机化其他结构。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
- $G(n,p)$：每个无向节点对独立以概率 $p$ 连边。
- WS：从规则环格出发，以概率 $\beta$ 重连边。
- BA：每步加入节点并以 $\Pi(i)=k_i/\sum_jk_j$ 连接已有节点。
- 配置模型：为节点 $i$ 创建 $d_i$ 个 stub 并随机配对。

### 2. 核心公式
ER：$E[m]=p\binom n2$，$E[D]=(n-1)p$，$C\approx p$。
配置模型近似连边期望：$E[A_{ij}]\approx d_id_j/(2m)$。
BA 在线性优先连接下产生渐近 $P(k)\propto k^{-3}$。

### 3. 符号说明表
| 参数 | 模型 | 控制内容 |
| :--- | :--- | :--- |
| $p$ | ER | 密度 |
| $k,\beta$ | WS | 局部度与捷径比例 |
| $m$ | BA | 新节点每步边数 |
| $\{d_i\}$ | 配置 | 精确度序列（多重图口径） |

### 4. 常见变体与适用条件
- $G(n,m)$ 固定边数；$G(n,p)$ 固定期望边数。
- stub matching 允许自环/重边；若强行简化会改变度序列。
- NetworkX `watts_strogatz_graph` 与 HW1“环格加 4000 条随机非边”不是同一生成过程。

## 6. 推导思路和思想来源
- ER 用独立性建立无结构基线。
- WS 的少量捷径显著缩短路径，同时大部分局部三角形仍保留。
- BA 的“增长 + 按度抽样”形成富者愈富。
- 配置模型通过固定 stub 数严格控制度，适合检验高阶结构是否超出度序列。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
$G(5,0.5)$ 有 $E[m]=0.5\binom52=5$，期望度 2，期望聚类约 0.5。

### 例子 2：中等例子
度序列 $(2,2,1,1)$ 有 6 个 stub；一次配对可能产生简单路径，也可能产生自环/重边。拒绝非法配对会改变“均匀抽样”过程，必须说明算法。

### 例子 3：实际应用例子（可运行代码）
```python
import networkx as nx

n = 200
er = nx.gnp_random_graph(n, 0.04, seed=7)
ws = nx.watts_strogatz_graph(n, 8, 0.05, seed=7)
ba = nx.barabasi_albert_graph(n, 4, seed=7)
for name, graph in [("ER", er), ("WS", ws), ("BA", ba)]:
    largest = graph.subgraph(max(nx.connected_components(graph), key=len))
    print(name, round(nx.average_clustering(graph), 3),
          round(nx.average_shortest_path_length(largest), 3),
          max(dict(graph.degree()).values()))
# 输出随固定 NetworkX 版本确定；比较聚类、路径和最大度，而非追求固定数值。
```

## 8. 常见误区和易混概念
### 误区 1：度分布相同意味着结构相同
- **为什么错**：配置模型保度后会破坏三角形、社区和同质性。

| 模型 | 保留/机制 | 能解释 | 主要缺陷 |
| :--- | :--- | :--- | :--- |
| ER | $n,p$ | 随机基线 | 低聚类、窄度分布 |
| WS | 局部格+捷径 | 高聚类短路径 | 度尾不重 |
| BA | 增长+优先连接 | hub/幂律 | 聚类与真实机制有限 |
| 配置 | 度序列 | 度控制零模型 | 自环重边、高阶结构随机 |
