# 聚类系数与网络距离

## 0. 学习边界
- **类别**：**A 类**；是“小世界”的两条证据轴。
- **判断理由**：度数只说明连接数量；聚类说明邻居是否互连，距离说明全网是否可快速到达。

## 1. 这个知识点解决什么问题？
> **麻烦**：两个同度序列网络可以一个由紧密圈子组成，另一个近似随机。需要局部闭包与全局路径两类指标。

## 2. 为什么它重要？它有什么用？
- 聚类刻画朋友的朋友是否相识；距离刻画信息跨网络的步数。
- 用于比较真实网络与 ER/配置模型、解释社区对传播的阻滞。
- HW1 要求自写平均聚类；HW2 用保度重连观察聚类消失。

## 3. 学它之前需要哪些前置知识？
1. **[[路径连通与Bow-tie结构]]**：BFS 与最短路。
2. **集合组合**：$\binom{k}{2}$ 个潜在邻居对。

## 4. 用直觉语言解释它
> “聚类问朋友圈有多抱团；距离问跨圈找到陌生人要几跳。”
- **一句话本质**：高聚类是局部冗余，短距离是全局效率。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
无向简单图中，若 $k_v\ge2$ 且邻居间有 $e_v$ 条边：
$$C_v=\frac{e_v}{\binom{k_v}{2}}=\frac{2e_v}{k_v(k_v-1)}.$$
平均局部聚类 $\bar C=\frac1n\sum_v C_v$；传递性 $C_T=3\times\#\triangle/\#\text{connected triples}$。

### 2. 核心公式
平均路径长度常在最大连通分量内计算：
$$L=\frac{1}{|P|}\sum_{(u,v)\in P}d(u,v),$$
直径 $D=\max_{(u,v)\in P}d(u,v)$。

### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $C_v$ | 局部聚类 | $k_v<2$ 时通常定义 0 |
| $\bar C,C_T$ | 平均局部/传递性 | 权重口径不同 |
| $L,D$ | 平均距离/直径 | 需声明连通范围 |

### 4. 常见变体与适用条件
- 有向、加权聚类有多种定义，不能混用。
- 非连通图的无限距离不能直接平均；可用最大 WCC 或 harmonic efficiency。

## 6. 推导思路和思想来源
- 邻居间最多有 $\binom{k_v}{2}$ 条边，因此用实际边数除以可能边数。
- 传递性按 connected triple 加权，高度节点影响更大；平均局部聚类让每个节点等权。
- 保度双边交换固定度数但逐渐破坏三角形，揭示“度序列不能解释全部聚类”。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
节点 $v$ 有 3 个邻居，其中邻居间有 2 条边，则 $C_v=2/3$；若三邻居全互连，则 $C_v=1$。

### 例子 2：中等例子
星图中心度很高但 $C=0$；叶子度 1 也按约定为 0。星图平均距离接近 2，说明短距离不保证高聚类。

### 例子 3：实际应用例子（可运行代码）
```python
import networkx as nx

graph = nx.Graph([(0, 1), (0, 2), (0, 3), (1, 2), (2, 3)])
neighbors = list(graph.neighbors(0))
neighbor_edges = graph.subgraph(neighbors).number_of_edges()
k = len(neighbors)
manual = 2 * neighbor_edges / (k * (k - 1))
print(manual, nx.clustering(graph, 0))
print(nx.average_shortest_path_length(graph))
# 输出：0.666666... 0.666666...
# 输出：1.166666...
```

## 8. 常见误区和易混概念
### 误区 1：平均局部聚类等于传递性
- **为什么错**：前者节点等权，后者 connected triple 等权。

| 概念 | 衡量尺度 | 关键区别 | 场景 |
| :--- | :--- | :--- | :--- |
| 聚类系数 | 局部闭包 | 三角形密度 | 社交圈 |
| 社区 | 中观分组 | 组内相对更密 | 群体发现 |
| 平均距离 | 全局效率 | 所有可达对平均 | 小世界 |
| 直径 | 最坏距离 | 对异常路径敏感 | 网络边界 |
