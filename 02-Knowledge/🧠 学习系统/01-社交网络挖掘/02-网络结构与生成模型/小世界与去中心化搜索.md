# 小世界与去中心化搜索

## 0. 先判断它值不值得深挖
- **类别**：**A 类**。
- **判断理由**：HW1 不只问路径短，还要求证明仅凭局部层次信息能否找到短路；这是“存在短路”与“可导航”的关键区别。

## 1. 这个知识点解决什么问题？
> **麻烦**：全知最短路算法知道整张图，但现实个体只知道邻居和目标的大致属性。短路径存在并不保证局部算法找得到。

## 2. 为什么它重要？它有什么用？
- 连接六度分隔、P2P 路由、组织内找人和弱关系桥接。
- 高频任务：层次距离、归一化常数、概率界、成功率与路径长度仿真。
- 揭示结构与算法共同决定可导航性。

## 3. 学它之前需要哪些前置知识？
1. [[../01-图与网络基础/路径连通与Bow-tie结构]]。
2. [[随机网络模型-ER-WS-BA-配置模型]]。

## 4. 用直觉语言解释它
> “知道朋友在哪个院系，就把消息交给组织树上更接近目标的朋友。”
- **一句话本质**：远程边的概率必须与潜在几何匹配，局部贪心才有方向感。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
HW1 层次模型把网络节点设为完全 $b$ 叉树的叶子，$h(v,w)$ 为最低公共祖先子树高度，连边概率：
$$p_v(w)=\frac{b^{-\alpha h(v,w)}}{Z_v},\quad Z_v=\sum_{w\ne v}b^{-\alpha h(v,w)}.$$

### 2. 核心公式
与 $v$ 的层次距离恰为 $d$ 的叶子数为 $b^d-b^{d-1}$。当 $\alpha=1$：
$$Z_v=\sum_{d=1}^{\log_bN}(b^d-b^{d-1})b^{-d}le\log_bN.$$
局部贪心每步选择使 $h(u,t)$ 最小的邻居。

### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $h(v,w)$ | 层次距离 | 越小越接近 |
| $\alpha$ | 距离衰减指数 | 太小/太大都可能不可导航 |
| $Z_v$ | 归一化常数 | 保证概率和为 1 |

### 4. 常见变体与适用条件
- Kleinberg 格模型用几何距离的幂律；HW1 用层次树距离。
- 可导航性依赖模型、边数与局部信息定义，不能从平均路径长度直接推出。

## 6. 推导思路和思想来源
- **关键转念**：搜索无需一步命中目标，只需高概率进入更接近目标的下一层。
- 距离 $d$ 的候选数指数增长，而单个候选连边概率指数衰减；$\alpha=1$ 时各尺度获得近似均衡概率质量。
- 若每层能以足够概率下降，最多下降树高 $O(\log_bN)$ 次。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
二叉树高度 3、固定叶子 $v$：距离 1、2、3 的其他叶子数分别为 $1,2,4$，符合 $2^d-2^{d-1}$。

### 例子 2：中等例子
$\alpha$ 很大时边几乎全在本地，难以跨大尺度；$\alpha$ 很小时边近似随机，虽有远边但缺乏朝目标的尺度信息。匹配维度时成功率最高。

### 例子 3：实际应用例子（可运行代码）
```python
def hierarchical_distance(left, right):
    """叶子用等长二进制串表示；返回最低公共前缀之后的高度。"""
    common = 0
    for a, b in zip(left, right):
        if a != b:
            break
        common += 1
    return len(left) - common

target = "111"
neighbors = ["001", "101", "110"]
best = min(neighbors, key=lambda node: hierarchical_distance(node, target))
print(best, hierarchical_distance(best, target))
# 输出：110 1
```

## 8. 常见误区和易混概念
### 误区 1：平均最短路短就一定容易搜索
- **为什么错**：最短路需要全局拓扑；局部代理信息可能与捷径结构无关。

| 概念 | 已知信息 | 目标 | 典型算法 |
| :--- | :--- | :--- | :--- |
| 最短路 | 全图 | 最少边数 | BFS/Dijkstra |
| 去中心化搜索 | 当前邻居+目标属性 | 局部找到目标 | 贪心转发 |
| 扩散 | 通常无特定目标 | 扩大覆盖 | 广播/随机传播 |

## 11. 自测题：5 道
1. 去中心化搜索能看到全图吗？ #自测题/基础
   > [!question]- 不能，只使用当前邻居及与目标相关的局部属性。
2. 完全 $b$ 叉树高度是多少？ #自测题/基础
   > [!question]- 有 $N$ 个叶子时为 $\log_bN$。
3. 为什么条件平均成功路径可能误导？ #自测题/中等
   > [!question]- 它排除了失败样本；低成功率模型也可能在少数成功时路径很短。
4. $\alpha$ 太大为何失败？ #自测题/中等
   > [!question]- 边过于局部，缺少跨尺度捷径。
5. 证明每次层次距离严格下降时步数为 $O(\log_bN)$。 #自测题/较难
   > [!question]- 初始距离至多树高 $\log_bN$，每步至少下降 1，故最多该数量级步数。
