> [!NOTE] 核心直觉：社交网络推断与“侦探破案”
> **类比**：在扎卡里空手道俱乐部（Zachary's Karate Club）中，隐藏的社交边就像未被公开记录的人际关联。如果两个人拥有共同的好友网络、类似的互动频率，或者在图嵌入映射的几何高维空间中距离极其接近，即使他们当前尚未被观察到直接联系，他们之间产生连接（或隐藏潜在关系）的概率依然极高。链接预测就是利用网络的已知拓扑结构与表征向量，定量评估任意节点对之间“结成边”的可能性。

## 1. 为什么需要这个知识点？
- **背景**：扎卡里空手道俱乐部（Zachary's Karate Club）是图数据挖掘与社交网络分析中最著名的基准数据集之一（34 个节点，78 条边）。真实图网络（如社交网、蛋白质相互作用网、电商相关推荐网）总是面临结构信息不全或动态演化的挑战。
- **痛点**：在现实场景中，全图直接标注代价极高；传统的经验规则往往忽视高阶拓扑结构或特征嵌入表达，难以精准识别潜在/未观察到的关联边；在链路预测建模中极其容易出现数据泄露（如将测试边保留在全图拓扑特征计算中）。
- **意义**：以空手道俱乐部为综合实战载体，贯通从“经典启发式拓扑相似度指标（CN, Jaccard, Adamic-Adar, PA）”到“图嵌入表征（Node2Vec / DeepWalk）+ 机器学习分类器（Logistic Regression / LightGBM）”的全流程建模与评估（AUC-ROC / Average Precision），是社交网络挖掘从理论走向工程落地不可或缺的实践关卡。

## 2. 核心定义与公式/代码

### (1) 链接预测问题形式化
设无向无权图 $G = (V, E)$，其中 $V$ 是节点集合，$E$ 是观察到的边集合。
定义全图可能存在的全边集（完全图边集）为 $U = \{ (u, v) \mid u, v \in V, u \neq v \}$。
缺失边与未连接边集为 $U \setminus E$。
链接预测的目标是对任意未知节点对 $(u, v) \in U \setminus E$，计算一个相似度得分或连接概率 $S(u, v)$，使得真实存在的潜在边得分高于不存在的随机节点对。

### (2) 经典启发式拓扑指标公式
设 $\Gamma(u)$ 表示节点 $u$ 的邻居节点集合，$k_u = |\Gamma(u)|$ 表示节点 $u$ 的度数：
- **Common Neighbors (CN)**:
  $$S_{\text{CN}}(u, v) = |\Gamma(u) \cap \Gamma(v)|$$
- **Jaccard Coefficient (JC)**:
  $$S_{\text{JC}}(u, v) = \frac{|\Gamma(u) \cap \Gamma(v)|}{|\Gamma(u) \cup \Gamma(v)|}$$
- **Adamic-Adar Index (AA)**:
  $$S_{\text{AA}}(u, v) = \sum_{z \in \Gamma(u) \cap \Gamma(v)} \frac{1}{\log |\Gamma(z)|}$$
- **Preferential Attachment (PA)**:
  $$S_{\text{PA}}(u, v) = k_u \times k_v$$

### (3) 图嵌入表示学习与分类建模
利用 Node2Vec 映射函数 $f: V \to \mathbb{R}^d$，得到节点表达向量 $\mathbf{z}_u, \mathbf{z}_v \in \mathbb{R}^d$。
节点对 $(u, v)$ 的边嵌入特征构建算子：
- **Hadamard 积**: $\mathbf{x}_{(u,v)} = \mathbf{z}_u \odot \mathbf{z}_v$
- **L1 距离**: $\mathbf{x}_{(u,v)} = |\mathbf{z}_u - \mathbf{z}_v|$

最后以边特征 $\mathbf{x}_{(u,v)}$ 为输入，训练逻辑回归二分类器：
$$\hat{y}_{(u,v)} = \sigma(\mathbf{w}^T \mathbf{x}_{(u,v)} + b)$$

### (4) NetworkX + Scikit-Learn 实战代码
```python
import networkx as nx
import numpy as np
from sklearn.metrics import roc_auc_score, average_precision_score
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

# 1. 加载空手道俱乐部网络
G = nx.karate_club_graph()
print(f"原图节点数: {G.number_of_nodes()}, 边数: {G.number_of_edges()}")

# 2. 正负样本构建与划分 (防止数据泄露)
edges = list(G.edges())
non_edges = list(nx.non_edges(G))

np.random.seed(42)
# 划分 80% 训练边, 20% 测试边
train_edges, test_pos_edges = train_test_split(edges, test_size=0.2, random_state=42)

# 抽取等量负样本用于测试
test_neg_indices = np.random.choice(len(non_edges), len(test_pos_edges), replace=False)
test_neg_edges = [non_edges[i] for i in test_neg_indices]

# 构建只包含训练边的训练图 train_G (极其关键：防止拓扑信息泄露)
train_G = nx.Graph()
train_G.add_nodes_from(G.nodes())
train_G.add_edges_from(train_edges)

# 3. 评估启发式拓扑指标 (AA / Jaccard / CN)
def evaluate_heuristic(train_graph, pos_edges, neg_edges, predict_fn):
    test_pairs = pos_edges + neg_edges
    preds = list(predict_fn(train_graph, test_pairs))
    y_true = [1] * len(pos_edges) + [0] * len(neg_edges)
    y_scores = [score for u, v, score in preds]
    return roc_auc_score(y_true, y_scores)

auc_aa = evaluate_heuristic(train_G, test_pos_edges, test_neg_edges, nx.adamic_adar_index)
auc_jc = evaluate_heuristic(train_G, test_pos_edges, test_neg_edges, nx.jaccard_coefficient)
auc_pa = evaluate_heuristic(train_G, test_pos_edges, test_neg_edges, nx.preferential_attachment)

print(f"[启发式拓扑指标] Adamic-Adar AUC: {auc_aa:.4f}")
print(f"[启发式拓扑指标] Jaccard Coefficient AUC: {auc_jc:.4f}")
print(f"[启发式拓扑指标] Preferential Attachment AUC: {auc_pa:.4f}")
```

## 3. 具体应用案例
**场景**：扎卡里空手道俱乐部成员分流预测与社交潜在纽带挖掘。
- **数据输入**：空手道俱乐部网络，其中社员管理者（Mr. Hi）与教练（Officer）派系斗争期间，观察到部分社员之间的直接联系，同时部分社员联系被掩蔽。
- **建模过程**：
  1. 计算测试边在去除掩蔽后的 `train_G` 中的拓扑指标得分。
  2. 提取 Node2Vec 节点向量，通过 Hadamard 积融合成边二分类特征。
  3. 联合预测两名社员之间未来建立联系或隐藏社交纽带的概率。
- **效果与价值**：可以在不需要全面私密调查的情况下，精准预测潜藏的社员信任纽带，提升社交平台“可能认识的人”好友推荐准确率，也可延伸至学术文献合作者推荐与金融反欺诈洗钱团伙链条识别。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **数据泄露 (Data Leakage / Target Contamination)**：在计算训练集与测试集节点的共同邻居或全局拓扑特征时，直接传入了原始图 `G` 而不是移除了测试集的 `train_G`。这相当于模型“提前看到了答案”，导致 AUC 虚高（如输出 AUC=0.99，但部署到真实场景严重失效）。
> - **负采样分布失真与正负样本不平衡**：完全随机抽取非边可能包含大量远距离、零共邻的平庸节点对，使任务过于简单。而在真实大规模网络中，未知边数量呈 $O(|V|^2)$，直接进行全未连接边计算会导致严重的假阳性比率偏高。需要采用 Hard Negative Sampling（困难负采样）提高模型鲁棒性。
