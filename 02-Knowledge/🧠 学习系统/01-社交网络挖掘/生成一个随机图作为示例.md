> [!NOTE] 核心直觉：财富分配的二八定律
> **类比**：想象一个城市里的财富分布，少数几个人（如马斯克、比尔·盖茨）拥有绝大部分财富，而绝大多数人只拥有很少的财富。在网络中，财富就对应着“连接数”（度）。度分布描述的就是全局视角的“贫富差距”——“有多少节点拥有多少个连接”的宏观图景。

## 1. 为什么需要这个知识点？
- **背景**：只看单个节点的“度”无法了解整个网络的宏观结构。我们需要一种统计工具来刻画网络的全局连通性特征。
- **痛点**：在面对动辄数百万节点的巨大复杂网络时，我们无法逐一分析每个节点。我们需要一种降维的方法，用一个概率分布来快速捕捉网络的拓扑本质。
- **意义**：度分布是区分不同网络模型（如随机网络 vs. 无标度网络）的核心指标。它直接决定了网络对随机攻击和蓄意攻击的鲁棒性，也是理解信息传播速度和流行病爆发阈值的关键。

## 2. 核心定义与公式/代码
**数学定义**
度分布 $P(k)$ 表示在网络中随机选取一个节点，其度数为 $k$ 的概率。也可以理解为度数为 $k$ 的节点数 $N_k$ 占总节点数 $N$ 的比例：
$$ P(k) = \frac{N_k}{N} $$

**累计度分布 (Cumulative Degree Distribution)**
在经验数据中，尾部（度数很大的节点）通常非常稀疏且噪音很大。为了平滑分布并减少数据噪声，通常使用累积度分布（即度数大于等于 $k$ 的概率）：
$$ P_{\geq}(k) = \sum_{k'=k}^{\infty} P(k') $$

**NetworkX 代码示例**
```python
import networkx as nx
import matplotlib.pyplot as plt
from collections import Counter

# 生成一个随机图作为示例
G = nx.erdos_renyi_graph(1000, 0.05)

# 获取所有节点的度
degrees = [d for n, d in G.degree()]
degree_counts = Counter(degrees)

# 计算概率 P(k)
total_nodes = len(G)
pk = {k: v / total_nodes for k, v in degree_counts.items()}

# 绘制度分布直方图
plt.bar(pk.keys(), pk.values())
plt.xlabel('Degree k')
plt.ylabel('P(k)')
plt.title('Degree Distribution')
plt.show()
```

## 3. 具体应用案例
**场景：识别社交媒体上的水军与买粉行为**
在真实的社交媒体网络（如 Twitter/微博）中，度分布通常服从幂律分布（Power-law distribution）。极少数的大V（Hub节点）拥有数千万粉丝，而绝大多数普通用户只有不到百个粉丝。
如果通过爬虫获取某个圈层的关注网络，发现其度分布突然表现出类似泊松分布（大家的粉丝数高度集中在平均值附近），或者在某个特定的高频度数上出现异常峰值，这通常意味着存在大规模的机器水军或自动化脚本买粉行为，因为这种分布违背了自然形成的社交网络演化规律（优先连接原则）。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **混淆均值与典型值**: 认为“平均度”可以代表网络中大多数节点的情况。在具有幂律度分布的无标度网络中，由于极端的长尾效应，绝大多数节点的度远低于平均度，平均值完全失去了代表性（就像你和马云的平均资产并不能代表普通人的资产水平）。
> - **坐标轴选择错误**: 在普通线性坐标系下绘制真实网络的度分布图，会导致大部分数据挤在一起变成一个直角。正确的做法是使用双对数坐标轴（Log-Log Plot），在双对数坐标下，幂律分布会呈现为一条直线，直线的斜率即为幂指数 $\gamma$。
