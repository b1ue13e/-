> [!NOTE] 核心直觉：圈子决定影响力
> **类比**：一个人的影响力不仅取决于他认识多少人（数量），更取决于他认识的人有多重要（质量）。认识100个普通人让你“人缘好”，但认识1个总统让你“有权势”。你的重要性是由连接到你的节点的重要性所定义的。

## 1. 为什么需要这个知识点？
- **背景**：度中心性（Degree Centrality）仅仅统计了节点的直接邻居数量。
- **痛点**：在现实网络中，所有连接的权重并非等价。连接到一个高度核心的节点，远比连接到许多边缘节点更有价值。单纯基于连接数评估节点影响力不够准确。
- **意义**：特征向量中心性（Eigenvector Centrality）通过递归的方式定义节点重要性，完美契合了“重要节点的邻居也是重要的”这一现实规律，并为PageRank等高级算法奠定了数学基础。

## 2. 核心定义与公式/代码
**数学定义**：
一个节点的特征向量中心性与其所有邻居的中心性之和成正比。
设网络有 $N$ 个节点，邻接矩阵为 $A$。节点 $v_i$ 的中心性为 $x_i$：
$$x_i = \frac{1}{\lambda} \sum_{j=1}^{N} A_{ij} x_j$$
写成矩阵形式为：
$$Ax = \lambda x$$
其中 $x$ 是特征向量，$\lambda$ 是特征值。根据 Perron-Frobenius 定理，为了保证所有的中心性分数都为正数，我们选择对应于最大特征值 $\lambda_{max}$ 的特征向量。

**Python (NetworkX) 实现**：
```python
import networkx as nx

# 生成一个示例图（空手道俱乐部网络）
G = nx.karate_club_graph()

# 计算特征向量中心性
eigenvector_centrality = nx.eigenvector_centrality(G)

# 打印前5个节点的中心性分数
for node in list(G.nodes())[:5]:
    print(f"节点 {node}: {eigenvector_centrality[node]:.4f}")
```

## 3. 具体应用案例
**场景**：关键意见领袖（KOL）挖掘与论文影响力评估
- **学术引用网络**：一篇论文的价值不仅取决于被引用的总次数，更取决于它是否被其他高影响力的“神作”所引用。被普通论文引用10次，不如被Nature核心论文引用1次。
- **社交媒体大V识别**：在Twitter或微博上，寻找真正的大V。一个拥有1万个僵尸粉的用户，其影响力远不及一个只有10个粉丝但这10个人都是行业顶尖大佬的用户。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **有向图的适用性崩溃**: 标准的特征向量中心性在有向图中容易失效。如果一个节点只有出度没有入度，它的中心性会变成0，并且会导致中心性分数无法正常传递。在有向图中应使用其变体（如PageRank或Katz中心性）。
> - **非连通图的零值问题**: 如果图不是强连通的，信息传递会被阻断，可能导致某些连通分量的节点中心性全为0。实际计算时，通常需要图是全连通的，或者对每个连通子图分别计算。
