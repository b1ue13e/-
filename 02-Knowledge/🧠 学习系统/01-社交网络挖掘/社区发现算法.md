# 社区发现算法 (Community Detection Algorithm)

## 1. 社区发现算法的定义与模块度 (Modularity) 评估

**社区发现算法 (Community Detection Algorithm)** 的核心定义是：在网络图 $G=(V, E)$ 中识别出“内部连接紧密、社区间连接稀疏”的密集的节点子集（社区/社群）的图聚类算法。由 Newman, Girvan 和 Blondel 等人确立理论框架。

**基本性质与模块度 $Q$ (Modularity)**：
模块度 $Q$ 是衡量网络社区划分质量的核心定量指标。其物理含义是：社区内部实际边数与随机期望边数之间的差值比例。$Q \in [-0.5, 1.0)$，通常当 $Q > 0.3$ 时表明网络存在显著的社区结构。

---

## 2. 模块度 $Q$ 形式化推导与 Louvain 算法递推过程

**网络假设与模块度推导**：
设无向图节点数为 $N$，总边数为 $m = \frac{1}{2} \sum_{ij} A_{ij}$。节点 $i$ 的度数为 $k_i$。在随机配置模型 (Configuration Model) 下，节点 $i, j$ 间存在随机边的概率为 $\frac{k_i k_j}{2m}$。

**模块度 $Q$ 形式化表达式**：
设节点 $i$ 所属社区为 $c_i$，当 $c_i = c_j$ 时克罗内克符号 $\delta(c_i, c_j) = 1$，否则为 0：

$$Q = \frac{1}{2m} \sum_{i,j} \left[ A_{ij} - \frac{k_i k_j}{2m} 
ight] \delta(c_i, c_j)$$

**Louvain 算法两阶段递推推导**：
1. **阶段 1 (局部模块度最大化)**：将每个节点视为独立社区。对节点 $i$，遍历其邻居节点 $j$，计算将其移入社区 $C$ 后的模块度增量 $\Delta Q$：
$$\Delta Q = \left[ \frac{\Sigma_{\text{in}} + k_{i,\text{in}}}{2m} - \left( \frac{\Sigma_{\text{tot}} + k_i}{2m} 
ight)^2 
ight] - \left[ \frac{\Sigma_{\text{in}}}{2m} - \left( \frac{\Sigma_{\text{tot}}}{2m} 
ight)^2 - \left( \frac{k_i}{2m} 
ight)^2 
ight]$$
2. **阶段 2 (社区折叠/粗化)**：将同一社区的所有节点折叠为一个超节点 (Super-node)，社区内部边转化为自环，形成粗化网络；
3. **循环迭代**：重复阶段 1 与阶段 2，直到全网模块度 $Q$ 不再增长。

## 3. 常见社区发现算法全方位对比

| 社区发现算法 | 核心机制 | 时间复杂度 | 适用图规模 | 优点 / 缺点 |
|:---|:---|:---|:---|:---|
| **Louvain 算法** | **贪心贪婪模块度最大化 + 层次折叠** | **$O(N \log N)$** | **超大规模 ($10^8$ 节点)** | 速度极快；存在分辨率极限 (Resolution Limit) |
| **Girvan-Newman (GN)** | 边介数 (Edge Betweenness) 拆重 | $O(m^2 n)$ | 小规模 ($< 10^3$ 节点) | 概念直观；计算极其缓慢 |
| **LPA 标签传播算法** | 异步节点邻居多数表决 | $O(m)$ | 超大规模 | 无需先验参数；可能产生平凡解 (全为一个社区) |
| **Infomap 算法** | 信息论压缩 (随机游走 Huffman) | $O(m)$ | 中大规模 | 基于信息流，对方向敏感 |

**局限（误区与反例）**：模块度最大化存在**分辨率极限 (Resolution Limit)**——在极大规模网络中，小规模的真实紧密社区可能被错误地合并入大社区中；对此可以采用带尺度参数的 Leidan 算法改善。

## 4. Python 手写模块度 $Q$ 计算与 Louvain 单步增量自测断言

```python
import numpy as np

def compute_modularity(adj: np.ndarray, communities: list) -> float:
    """
    计算图划分的模块度 Q
    adj: N x N 邻接矩阵
    communities: list of node indices [0, 0, 1, 1]
    """
    m = np.sum(adj) / 2.0
    if m == 0: return 0.0
    degrees = np.sum(adj, axis=1)
    N = len(adj)
    Q = 0.0

    for i in range(N):
        for j in range(N):
            if communities[i] == communities[j]:
                Q += adj[i, j] - (degrees[i] * degrees[j]) / (2.0 * m)

    return float(Q / (2.0 * m))

if __name__ == "__main__":
    # 模拟两个明显分离的 3 节点团结构 (共 6 节点)
    adj = np.zeros((6, 6))
    # 团 A: 0, 1, 2
    adj[0,1]=adj[1,0]=adj[1,2]=adj[2,1]=adj[0,2]=adj[2,0]=1
    # 团 B: 3, 4, 5
    adj[3,4]=adj[4,3]=adj[4,5]=adj[5,4]=adj[3,5]=adj[5,3]=1
    # 团间单边桥梁: 2 - 3
    adj[2,3]=adj[3,2]=1

    # 正确划分: [0,0,0, 1,1,1]
    comm_good = [0, 0, 0, 1, 1, 1]
    q_good = compute_modularity(adj, comm_good)

    # 错误划分: 全部同属一个社区 [0,0,0, 0,0,0]
    comm_bad = [0, 0, 0, 0, 0, 0]
    q_bad = compute_modularity(adj, comm_bad)

    # 自测验证 1: 正确划分的模块度应显著大于 0.3
    assert q_good > 0.3, f"好的社区划分模块度应很高: {q_good}"

    # 自测验证 2: 好的划分模块度必须高于坏的划分
    assert q_good > q_bad, "正确社区划分模块度必须大于单一社区划分"

    print(f"社区发现算法 模块度 Q (完美划分) = {q_good:.4f}, (全单一社区) = {q_bad:.4f}")
    print("社区发现算法 单元测试与自查验证全部成功！")
```
