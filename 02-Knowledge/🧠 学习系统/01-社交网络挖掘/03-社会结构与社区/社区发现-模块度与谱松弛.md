## 原笔记：社区发现与模块度

### 0. 先判断它值不值得深挖
- **类别**：**A 类（课程全面主干）**。
- **判断理由**：社区是传播、链接预测和异常团伙分析的中观结构；模块度把“组内边多”改写成相对度保持零模型的超额边。

### 1. 这个知识点解决什么问题？
> 没有标签时，怎样划分内部连接相对密、跨组连接相对稀的节点群，并判断划分是否超出度序列随机基线？

### 2. 为什么它重要？它有什么用？
- 营销分群、团伙识别、生物模块和传播阻隔。
- 为谱聚类和 Louvain 提供共同评价语言。
- 解释社区结构为何影响 SIR 最终规模。

### 3. 学它之前需要哪些前置知识？
1. [[../02-网络结构与生成模型/随机网络模型-ER-WS-BA-配置模型]]。
2. [[../02-网络结构与生成模型/聚类系数与网络距离]]。

### 4. 用直觉语言解释它
> “好的社区不是组内边绝对多，而是比相同度数随机乱连时预期的更多。”
- **一句话本质**：模块度等于观察到的组内边比例减去配置模型期望。

### 5. 正式定义、核心公式、符号解释
#### 1. 最核心定义
对划分 $c_i$：
$$Q=\frac1{2m}\sum_{ij}\left(A_{ij}-\frac{k_ik_j}{2m}\right)\mathbf1[c_i=c_j].$$
#### 2. 核心公式
社区级等价式：$Q=\sum_c[e_c/m-(d_c/2m)^2]$，$e_c$ 为社区内部边数，$d_c$ 为社区节点度数和。
#### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $A_{ij}$ | 真实邻接 | 无向无权基本式 |
| $k_ik_j/2m$ | 配置模型期望 | 度保持基线 |
| $Q$ | 划分质量 | 不同图之间不宜直接比较 |
#### 4. 常见变体与适用条件
- 有向/加权图需对应空模型；重叠社区不适用硬划分基本式。
- 模块度有分辨率极限，小社区可能被合并。

### 6. 推导思路和思想来源
- 仅数内部边会偏爱高度节点组；减去配置模型期望控制度序列。
- Louvain 先局部移动节点以增加 $Q$，再聚合社区为超节点，多层迭代。
- 优化 NP-hard，Louvain 是启发式且受初始化/节点顺序影响。

### 7. 例子：基础 → 中等 → 实际应用
#### 例子 1（手算）
两个互不相连三角形，$m=6$。每社区 $e_c=3,d_c=6$，故 $Q=2[3/6-(6/12)^2]=0.5$。
#### 例子 2
把所有节点放同一社区总有 $Q=0$；这不是“没有边”，而是观察组内边与零模型期望完全相抵。
#### 例子 3（可运行代码）
```python
import networkx as nx
from networkx.algorithms.community import modularity

graph = nx.disjoint_union(nx.complete_graph(3), nx.complete_graph(3))
partition = [{0, 1, 2}, {3, 4, 5}]
print(modularity(graph, partition))
# 输出：0.5
```

### 8. 常见误区和易混概念
- **误区**：$Q$ 越高就是真实群体。**纠正**：它是特定空模型和分辨率下的结构划分，需稳定性与外部证据。
| 概念 | 目标 | 是否需 $k$ | 主要限制 |

## 原笔记：谱松弛-Normalized-Cut与模块度

### 0. 先判断它值不值得深挖
- **类别**：**A 类**；HW4-Q4 要求完整证明链与实现。
- **判断理由**：普通 Fiedler 向量只是入口；官方题目分别要求归一化割最小化、模块度最大化、二者关系及真实网络聚类。

### 1. 这个知识点解决什么问题？
> **麻烦**：只最小化跨割边数会偏爱切出孤立小集合，直接搜索所有二分又是组合难题。怎样同时惩罚失衡，并把离散二分变成可计算的特征向量问题？

### 2. 为什么它重要？它有什么用？
- **连接大图景**：图拉普拉斯、配置模型空模型、Rayleigh 商、社区评价和 GCN 共享同一线性代数骨架。
- **实际应用**：政治博客二分、图像分割、用户群体发现。
- **高频任务**：证明二次型、做 relax-and-round、实现两种谱算法、用 purity 评价。

### 4. 用直觉语言解释它
> “先允许节点站在连续数轴上，让强连接节点靠近；求出最省拉伸的非平凡方向后，再按符号切回两组。”
- **一句话本质**：谱松弛用连续特征向量近似离散分组，Normalized Cut 控制体积平衡，模块度控制相对空模型的超额组内连接。

### 5. 正式定义、核心公式、符号解释

#### 1. Cut、volume 与 Normalized Cut
$$
\operatorname{cut}(S,\bar S)=\sum_{i\in S,j\in\bar S}A_{ij},\qquad
\operatorname{vol}(S)=\sum_{i\in S}d_i,
$$
$$
\operatorname{NCut}(S,\bar S)=\operatorname{cut}(S,\bar S)
\left(\frac1{\operatorname{vol}(S)}+\frac1{\operatorname{vol}(\bar S)}\right).
$$

#### 2. 与二次型严格对应
令 $a=\operatorname{vol}(S)$、$b=\operatorname{vol}(\bar S)$，定义
$$
x_i=\begin{cases}
\sqrt{b/a},&i\in S,\\
-\sqrt{a/b},&i\in\bar S.
\end{cases}
$$
则：
$$x^TD\mathbf1=0,\qquad x^TDx=a+b=2m.$$
只有跨割边产生非零差；跨割差的平方为
$$\left(\sqrt{b/a}+\sqrt{a/b}\right)^2=\frac{(a+b)^2}{ab}.$$
采用 $x^TLx=\sum_{(i,j)\in E}(x_i-x_j)^2$ 的无向边口径：
$$
x^TLx=\operatorname{cut}(S,\bar S)\frac{(a+b)^2}{ab}
=2m\cdot\operatorname{NCut}(S,\bar S).
$$
因此离散目标等价于在特定两值向量上最小化 $x^TLx/x^TDx$。

#### 3. Normalized Cut 的 relax-and-round
去掉“两值向量”约束，保留 $x^TD\mathbf1=0$。令 $z=D^{1/2}x$：
$$
\frac{x^TLx}{x^TDx}=\frac{z^T(D^{-1/2}LD^{-1/2})z}{z^Tz},\qquad
z^TD^{1/2}\mathbf1=0.
$$
$\mathcal L=D^{-1/2}LD^{-1/2}$ 的最小特征向量正比于 $D^{1/2}\mathbf1$；正交约束排除它，所以最优 $z$ 是第二小特征向量 $v_2$，$x=D^{-1/2}v_2$。用 $x_i$ 的符号或扫描阈值 round。

#### 4. 模块度矩阵与二次型
配置模型空模型给出期望 $d_id_j/(2m)$。令
$$
B=A-\frac{dd^T}{2m},\qquad B\mathbf1=0.
$$
二分标签 $y_i\in\{-1,+1\}$，且 $\mathbb I[y_i=y_j]=(1+y_iy_j)/2$。于是
$$
Q(y)=\frac1{2m}\sum_{ij}B_{ij}\mathbb I[y_i=y_j]
=\frac1{4m}y^TBy,
$$
因为 $\sum_{ij}B_{ij}=0$。放松 $y\in\{\pm1\}^n$ 为 $y^Ty=n$ 后，Rayleigh–Ritz 定理说明最大化解为 $B$ 的最大代数特征值对应向量。

#### 5. 模块度与 cut/volume 的关系
设 $a=\operatorname{vol}(S)$、$b=2m-a$。组内有向计数为 $2m-2\operatorname{cut}(S,\bar S)$，空模型组内期望和为 $(a^2+b^2)/(2m)$。代入得
$$
Q=1-\frac{\operatorname{cut}}{m}-\frac{a^2+b^2}{4m^2}
=\frac{ab}{2m^2}-\frac{\operatorname{cut}}{m}
=\frac1{2m}\left(-2\operatorname{cut}+\frac{ab}{m}\right).
$$
这说明模块度同时奖励体积乘积（平衡）并惩罚跨割边。

#### 6. 符号表
| 符号 | 含义 | 注意 |
| :--- | :--- | :--- |
| $L=D-A$ | 组合拉普拉斯 | 半正定 |
| $\mathcal L$ | 对称归一化拉普拉斯 | 孤立点需单独处理 |
| $B$ | 模块度矩阵 | 行和为 0，可有负特征值 |
| $x,y$ | 连续/离散分配向量 | rounding 规则要报告 |

### 6. 推导思路和思想来源
1. 用特殊两值向量把“是否跨割”编码成边上坐标差。
2. 离散向量约束导致组合困难；删除它得到 Rayleigh 商。
3. 正交约束去掉恒定平凡解，第二小特征向量承载最平滑的非平凡二分。
4. 模块度先从观测边减去配置模型期望，再用 $\pm1$ 标签把“同组”写成二次型。
5. 最大特征向量是连续放松最优方向；rounding 只给近似离散解，需用原始目标比较阈值。

#### 例子 3：两种谱二分的可运行实现
```python
import networkx as nx
import numpy as np

graph = nx.karate_club_graph()
nodes = list(graph)
adjacency = nx.to_numpy_array(graph, nodelist=nodes)
degree = adjacency.sum(axis=1)
laplacian = np.diag(degree) - adjacency
inv_sqrt = np.diag(1.0 / np.sqrt(degree))
normalized = inv_sqrt @ laplacian @ inv_sqrt
values, vectors = np.linalg.eigh(normalized)
ncut_coordinate = inv_sqrt @ vectors[:, 1]
ncut_labels = ncut_coordinate >= 0

m = graph.number_of_edges()
modularity = adjacency - np.outer(degree, degree) / (2.0 * m)
mod_values, mod_vectors = np.linalg.eigh(modularity)
mod_labels = mod_vectors[:, -1] >= 0
print(int(ncut_labels.sum()), int(mod_labels.sum()))
print(round(values[1], 6), round(mod_values[-1], 6))
# 输出两种二分的组规模及相应谱值；特征向量整体符号翻转不改变二分。
```

### 8. 常见误区和易混概念
- **误区 1：直接用 $L$ 的 Fiedler 向量就等于 Normalized Cut。** NCut 的松弛对应 $\mathcal L$ 与 $D^{-1/2}$ 变换。
- **误区 2：最大“绝对值”特征向量。** 模块度松弛取最大代数特征值，不是绝对值最大。
- **误区 3：把 relax 解当作离散最优证明。** 特征向量只解连续问题，rounding 后必须计算离散目标。

| 方法 | 矩阵 | 谱方向 | 平衡依据 |
| :--- | :--- | :--- | :--- |
| Ratio/unnormalized cut | $L$ | 第二小 | 节点数 |
| Normalized Cut | $\mathcal L$ | 第二小 | 体积/度 |
| 模块度谱法 | $B$ | 最大代数 | 配置模型超额连接 |
| 边介数删边 | 最短路 DAG | 非特征向量 | 跨群路径负载 |
