# 谱聚类与近似介数

## 0. 先判断它值不值得深挖
- **类别**：**A 类**；HW4 两道核心题。
- **判断理由**：谱方法把最小割转成特征向量近似；采样介数把全源最短路降为少量源点估计。

## 1. 这个知识点解决什么问题？
> 精确组合划分和全节点介数都很昂贵。怎样利用线性代数松弛与抽样，在大图上得到可解释近似？

## 2. 为什么它重要？它有什么用？
- 图拉普拉斯连接切割、扩散和 GCN。
- 介数识别跨群桥梁；近似算法提供计算/方差权衡。
- HW4 要求推导与实现，而不是只调库。

## 3. 学它之前需要哪些前置知识？
1. [[../01-图与网络基础/路径连通与Bow-tie结构]]。
2. 特征值、Rayleigh quotient 与 BFS 最短路 DAG。

## 4. 用直觉语言解释它
> “把相连节点用弹簧绑在一起，最平滑但不恒定的振动方向，就是最自然的二分坐标。”
- **一句话本质**：Fiedler 向量是离散切割的连续松弛；采样介数是全源依赖的无偏/近似估计。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
$L=D-A$，且 $x^TLx=\sum_{(i,j)\in E}(x_i-x_j)^2$。连通图第二小特征值 $\lambda_2>0$，对应向量为 Fiedler 向量。
### 2. 核心公式
节点介数：$C_B(v)=\sum_{s\ne v\ne t}\sigma_{st}(v)/\sigma_{st}$。采样源点集合 $S$ 时按 $n/|S|$ 缩放单源依赖和。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $L,D,A$ | 拉普拉斯、度、邻接 | 可用归一化变体 |
| $\lambda_2$ | 代数连通度 | 0 的重数等于分量数 |
| $\sigma_{st}(v)$ | 经过 $v$ 的最短路数 | 排除端点口径 |
### 4. 常见变体与适用条件
- $L_{sym}=I-D^{-1/2}AD^{-1/2}$ 适合度差异大的图。
- 近似介数必须报告源点抽样方案、随机种子与误差。

## 6. 推导思路和思想来源
- 离散二分向量使 $x^TLx$ 与跨割边数相关；去掉离散约束并要求 $x\perp\mathbf1$ 后，Rayleigh 最小化解为第二特征向量。
- Brandes 先 BFS 得到距离、路径数与前驱，再逆序累积依赖；抽样只对部分源点执行。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
三节点路径的 $L=\begin{bmatrix}1&-1&0\\-1&2&-1\\0&-1&1\end{bmatrix}$，Fiedler 向量可取 $(1,0,-1)$，按符号切分两端。
### 例子 2
四节点路径中间节点位于更多端点对最短路上，介数高于端点；只采样端点源会比只采样中间源更有代表性，说明抽样设计影响方差。
### 例子 3（可运行代码）
```python
import networkx as nx
import numpy as np

graph = nx.path_graph(4)
laplacian = nx.laplacian_matrix(graph).toarray().astype(float)
values, vectors = np.linalg.eigh(laplacian)
fiedler = vectors[:, 1]
print(np.round(values, 6))
print([int(x >= 0) for x in fiedler])
print(nx.betweenness_centrality(graph, normalized=False))
# 特征向量整体符号可反转；划分不变。
```

## 8. 常见误区和易混概念
- **误区**：特征向量符号反转表示结果不同。**纠正**：$x$ 与 $-x$ 是同一方向。
| 概念 | 优化对象 | 输出 | 限制 |
| :--- | :--- | :--- | :--- |
| 谱二分 | 拉普拉斯平滑性 | 连续坐标/二分 | 需阈值或 k-means |
| 模块度 | 超额组内边 | 硬划分 | 分辨率极限 |
| 精确介数 | 全源最短路 | 节点分数 | 计算昂贵 |
| 近似介数 | 抽样源点 | 估计分数 | 抽样方差 |
