# 三元闭包、弱关系与同质性

## 0. 先判断它值不值得深挖
- **类别**：**A 类**。它把静态三角形转换成关系形成与信息跨圈传播的机制解释。
- **判断理由**：共同邻居、社区、链接预测和社会资本都依赖这些概念，但三者不能互相替代。

## 1. 这个知识点解决什么问题？
> 为什么朋友的朋友容易成为朋友？为什么弱联系反而带来新信息？属性相似是选择造成，还是交往后的影响造成？

## 2. 为什么它重要？它有什么用？
- 解释高聚类、结构洞、跨社区桥接和好友推荐。
- 帮助区分结构相关与因果机制。
- 支撑链接预测特征和扩散路径解释。

## 3. 学它之前需要哪些前置知识？
1. [[../02-网络结构与生成模型/聚类系数与网络距离]]。
2. 时间顺序与混杂变量的基本概念。

## 4. 用直觉语言解释它
> “熟人圈靠闭包变密，新消息常从圈外弱联系进入；相似的人既可能主动结交，也可能交往后变相似。”
- **一句话本质**：闭包制造局部冗余，桥接关系提供非冗余信息。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
- 三元闭包：若 $u-w$ 与 $w-v$ 存在，则未来 $u-v$ 出现概率上升。
- 局部桥：删除边 $(u,v)$ 后，两端距离显著增加；严格桥删除后分量数增加。
- 同质性：相似属性节点之间的连边比例高于合适零模型。

### 2. 核心公式
共同邻居 $CN(u,v)=|N(u)\cap N(v)|$；Jaccard $J=|N(u)\cap N(v)|/|N(u)\cup N(v)|$。属性同配可用 assortativity $r$ 衡量，但 $r>0$ 不是因果结论。

### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $CN,J$ | 闭包型结构特征 | 只用训练图计算 |
| $r$ | 同配系数 | 相对随机混合 |
| bridge | 桥接边 | 信息可能非冗余 |

### 4. 常见变体与适用条件
- 强/弱关系需要由频率、亲密度等外部属性定义，不能仅凭边存在推断。
- 选择与社会影响需要纵向数据或识别策略区分。

## 6. 推导思路和思想来源
- 闭包使共同朋友降低结交成本。
- 强关系往往嵌入大量共同邻居；跨群体桥通常较弱，却连接不同信息源。
- 观察相似连边时，选择、影响、共同环境三者都会产生相同静态相关，需要时间或准实验辨别。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
$N(u)=\{a,b,c\}$、$N(v)=\{b,c,d\}$，则 $CN=2,J=2/4=0.5$。
### 例子 2
两个各自高聚类的社群只由一条弱边连接；删除该边会切断跨群信息，但对两端局部度影响仅 1。
### 例子 3（可运行代码）
```python
import networkx as nx
graph = nx.Graph([("u", "a"), ("u", "b"), ("u", "c"),
                  ("v", "b"), ("v", "c"), ("v", "d")])
common = set(nx.common_neighbors(graph, "u", "v"))
union = set(graph["u"]) | set(graph["v"])
print(common, len(common) / len(union))
# 输出：{'b', 'c'} 0.5（集合显示顺序可能不同）
```

## 8. 常见误区和易混概念
- **误区**：同质性证明社会影响。**纠正**：也可能是选择或共同环境。
| 概念 | 机制/现象 | 时间性 | 典型证据 |
| :--- | :--- | :--- | :--- |
| 三元闭包 | 共同邻居促成新边 | 动态 | 新边概率随共同邻居增加 |
| 同质性 | 相似者更常相连 | 静态也可见 | 属性混合矩阵/同配 |
| 社会影响 | 相连后属性趋同 | 动态因果 | 纵向或准实验 |
| 弱关系桥 | 跨圈非冗余连接 | 结构角色 | 低重叠、跨社区 |

## 11. 自测题：5 道
1. 三元闭包是什么？ #自测题/基础
   > [!question]- 两个节点共享邻居时，它们未来形成边的概率上升。

   > [!question]- 删除该边会增加连通分量数。

   > [!question]- 强关系常嵌入共同社交圈，双方共享更多邻居。
4. 如何区分选择与社会影响？ #自测题/中等
