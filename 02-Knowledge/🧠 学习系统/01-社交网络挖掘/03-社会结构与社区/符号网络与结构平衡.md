# 符号网络与结构平衡

## 0. 先判断它值不值得深挖
- **类别**：**A 类**；HW2 理论、反例和模拟主线。
- **判断理由**：正负关系不能用普通无向图的“边越多越好”解释，三元组符号提供独立结构约束。

## 1. 这个知识点解决什么问题？
> 朋友与敌人同时存在时，哪些三人关系稳定？局部修复是否一定让全网更平衡？

## 2. 为什么它重要？它有什么用？
- 应用于信任/不信任、支持/反对、国际联盟网络。
- 训练构造反例和随机零模型比较能力。
- 支撑符号链接预测与极化分析。

## 3. 学它之前需要哪些前置知识？
1. [[../01-图与网络基础/图与网络基础]]。
2. 独立伯努利概率与三角形计数。

## 4. 用直觉语言解释它
> “朋友的朋友是朋友，敌人的敌人是朋友；一个三角形里负边为偶数时更稳定。”
- **一句话本质**：平衡三元组的边符号乘积为正。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
完整符号图每条边 $s_{ij}\in\{+1,-1\}$。三元组平衡当 $s_{ij}s_{jk}s_{ik}=+1$，即负边数为 0 或 2。
### 2. 核心公式
若边独立为正的概率为 $p$，四类三元组 $t_k$（$k$ 条正边）概率为：
$$P(t_k)=\binom3k p^k(1-p)^{3-k}.$$
平衡概率 $P(t_3)+P(t_1)=p^3+3p(1-p)^2$。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $s_{ij}$ | 边符号 | 正/负 |
| $t_k$ | 含 $k$ 条正边的三元组 | $k=1,3$ 平衡 |
| $p$ | 随机正边概率 | 零模型参数 |
### 4. 常见变体与适用条件
- 强结构平衡：完整图可分为最多两个内部正、跨组负的阵营。
- 弱平衡允许多阵营；不完整图需说明仅对闭合三元组还是全局 cycle 判断。

## 6. 推导思路和思想来源
- 三条符号乘积为正等价于负号出现偶数次。
- 独立符号零模型先控制总体正边比例，再比较真实三元组是否过度平衡。
- 随机挑不平衡三元组翻边可能修好该三元组，却破坏共享该边的其他三元组，因此总平衡数不必单调。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
$p=0.8$ 时全正三元组概率 $0.512$，一正两负概率 $3(0.8)(0.2)^2=0.096$，总平衡概率 $0.608$。
### 例子 2
两个共享一条边的三角形中，翻转共享边可能让目标三角形平衡、另一个从平衡变不平衡，构成“局部修复不保证全局单调”的反例骨架。
### 例子 3（可运行代码）
```python
from itertools import combinations

sign = {(0, 1): 1, (0, 2): -1, (1, 2): -1,
        (0, 3): 1, (1, 3): 1, (2, 3): -1}

def edge_sign(a, b):
    return sign[tuple(sorted((a, b)))]

def balanced(triad):
    a, b, c = triad
    return edge_sign(a, b) * edge_sign(a, c) * edge_sign(b, c) == 1

print([(t, balanced(t)) for t in combinations(range(4), 3)])
# 输出给出每个三元组的平衡真假，可据此核对模拟。
```

## 8. 常见误区和易混概念
- **误区**：一个三元组被修复后全网更平衡。**纠正**：共享边会影响多个三元组。
| 概念 | 边类型 | 稳定标准 | 用途 |
| :--- | :--- | :--- | :--- |
| 普通聚类 | 无符号 | 三角形是否闭合 | 圈层密度 |
| 结构平衡 | 正负符号 | 符号乘积为正 | 阵营/冲突 |
| 弱平衡 | 正负符号 | 放宽全局阵营数 | 多阵营网络 |
