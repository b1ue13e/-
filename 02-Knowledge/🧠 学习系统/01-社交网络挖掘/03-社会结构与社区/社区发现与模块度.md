# 社区发现与模块度

## 0. 先判断它值不值得深挖
- **类别**：**A 类（课程全面主干）**。
- **判断理由**：社区是传播、链接预测和异常团伙分析的中观结构；模块度把“组内边多”改写成相对度保持零模型的超额边。

## 1. 这个知识点解决什么问题？
> 没有标签时，怎样划分内部连接相对密、跨组连接相对稀的节点群，并判断划分是否超出度序列随机基线？

## 2. 为什么它重要？它有什么用？
- 营销分群、团伙识别、生物模块和传播阻隔。
- 为谱聚类和 Louvain 提供共同评价语言。
- 解释社区结构为何影响 SIR 最终规模。

## 3. 学它之前需要哪些前置知识？
1. [[../02-网络结构与生成模型/随机网络模型-ER-WS-BA-配置模型]]。
2. [[../02-网络结构与生成模型/聚类系数与网络距离]]。

## 4. 用直觉语言解释它
> “好的社区不是组内边绝对多，而是比相同度数随机乱连时预期的更多。”
- **一句话本质**：模块度等于观察到的组内边比例减去配置模型期望。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
对划分 $c_i$：
$$Q=\frac1{2m}\sum_{ij}\left(A_{ij}-\frac{k_ik_j}{2m}\right)\mathbf1[c_i=c_j].$$
### 2. 核心公式
社区级等价式：$Q=\sum_c[e_c/m-(d_c/2m)^2]$，$e_c$ 为社区内部边数，$d_c$ 为社区节点度数和。
### 3. 符号说明表
| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $A_{ij}$ | 真实邻接 | 无向无权基本式 |
| $k_ik_j/2m$ | 配置模型期望 | 度保持基线 |
| $Q$ | 划分质量 | 不同图之间不宜直接比较 |
### 4. 常见变体与适用条件
- 有向/加权图需对应空模型；重叠社区不适用硬划分基本式。
- 模块度有分辨率极限，小社区可能被合并。

## 6. 推导思路和思想来源
- 仅数内部边会偏爱高度节点组；减去配置模型期望控制度序列。
- Louvain 先局部移动节点以增加 $Q$，再聚合社区为超节点，多层迭代。
- 优化 NP-hard，Louvain 是启发式且受初始化/节点顺序影响。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1（手算）
两个互不相连三角形，$m=6$。每社区 $e_c=3,d_c=6$，故 $Q=2[3/6-(6/12)^2]=0.5$。
### 例子 2
把所有节点放同一社区总有 $Q=0$；这不是“没有边”，而是观察组内边与零模型期望完全相抵。
### 例子 3（可运行代码）
```python
import networkx as nx
from networkx.algorithms.community import modularity

graph = nx.disjoint_union(nx.complete_graph(3), nx.complete_graph(3))
partition = [{0, 1, 2}, {3, 4, 5}]
print(modularity(graph, partition))
# 输出：0.5
```

## 8. 常见误区和易混概念
- **误区**：$Q$ 越高就是真实群体。**纠正**：它是特定空模型和分辨率下的结构划分，需稳定性与外部证据。
| 概念 | 目标 | 是否需 $k$ | 主要限制 |
| :--- | :--- | :--- | :--- |
| Louvain | 近似最大化模块度 | 否 | 分辨率、随机性 |
| 谱聚类 | 拉普拉斯嵌入后切分 | 通常是 | 特征计算、$k$ 选择 |
| 连通分量 | 无跨分量路径 | 否 | 过于严格 |
| 聚类系数 | 局部三角闭包 | 否 | 不是群组划分 |

## 11. 自测题：5 道
1. 模块度比较什么？ #自测题/基础

2. 所有节点一个社区时 $Q$ 是多少？ #自测题/基础
   > [!question]- 0。
3. Louvain 为什么要聚合社区？ #自测题/中等
   > [!question]- 把局部结构压缩后在更粗尺度继续提高模块度。
4. 模块度分辨率极限是什么？ #自测题/中等
   > [!question]- 全局目标可能把真实小社区合并，因为拆出它们带来的增益不足。
