> [!NOTE] 核心直觉：城市的建筑物与居民
> **类比**：如果把整个社交网络想象成一座繁忙的城市，那么**节点（Node/Vertex）**就是这座城市里的每一栋建筑、每一个具体的居民。节点是网络中最基础的实体单元，承载着信息、属性和状态。没有节点，就没有关系，也就没有网络。

## 1. 为什么需要这个知识点？
- **背景**：在复杂系统和社交网络中，我们需要一种数学抽象来表示系统中的独立个体（如人、网页、蛋白质分子）。
- **痛点**：如果不将现实世界中的实体抽象为标准的“节点”，我们就无法系统地分析个体在群体中的重要性、角色以及它们所携带的特征。
- **意义**：节点不仅是构成网络拓扑图的基石，也是挂载数据（属性）的锚点。定义好节点，是开展图挖掘（如图神经网络、社区发现）的绝对起点。

## 2. 核心定义与公式/代码
- **数学定义**：在图论中，图 $G$ 定义为二元组 $G = (V, E)$，其中 $V$ 是**节点集（Vertex Set）**，$V = \{v_1, v_2, ..., v_n\}$，每个 $v_i$ 代表图中的一个节点。图的节点总数常表示为 $N = |V|$。
- **节点属性（Node Attributes）**：每个节点可以附带特征向量 $x_i \in \mathbb{R}^d$，表示节点的属性（如用户的年龄、收入）。

**NetworkX 代码示例**：
```python
import networkx as nx

# 实例化一个图
G = nx.Graph()

# 添加节点并赋予属性
G.add_node(1, name="Alice", age=25)
G.add_node(2, name="Bob", age=30)

# 批量添加节点
G.add_nodes_from([3, 4, 5])

# 访问节点及其属性
print(G.nodes(data=True)) 
# 输出: [(1, {'name': 'Alice', 'age': 25}), (2, {'name': 'Bob', 'age': 30}), (3, {}), (4, {}), (5, {})]
```

## 3. 具体应用案例
**场景**：Twitter 用户影响力分析
- 在 Twitter 网络中，每个**账号（User）**就是一个节点。
- 节点不仅有一个唯一的 ID（如 `@elonmusk`），还有丰富的属性（粉丝数、账号注册时间、认证状态）。
- 算法（如 PageRank 或节点中心性分析）会将这些节点视为分析单元，找出在信息传播网络中最具影响力的“超级节点”。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **混淆节点与边**：在特定转化图（如线图 Line Graph）中，原图的边会变成新图的节点。务必明确当前分析上下文中的基本实体到底是什么。
> - **忽略孤立节点 (Isolated Nodes)**：在构建网络时，有时会忘记加入没有连边的节点，导致网络特征（如平均度数）计算产生偏差。
> - **属性爆炸**：给节点附加过多冗余特征，导致图神经网络（GNN）训练时遭遇维度灾难。节点特征应尽量精简且具代表性。
