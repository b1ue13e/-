# 🧭 开源作业体系-数值分析

> 本页是「数值分析」的开源名校教材与作业的**唯一挂载点**：教材主线、官方作业链、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**MIT 18.335J Introduction to Numerical Methods**（https://ocw.mit.edu/courses/18-335j-introduction-to-numerical-methods-spring-2019/ ，GitHub: https://github.com/mitmath/18335）。

## ✅ 验收方式与评分

1. **实现验收**：每个 HW 的算法自行实现（numpy 只允许用 `linalg` 做对照，不许直接调用目标算法），最小测试用例通过。
2. **数值实验验收**：每个 HW 必须包含——误差/残差随问题规模或条件数的变化曲线、至少一个病态算例（如 Hilbert 矩阵、近奇异矩阵）、与**高精度参考**（`np.linalg` / `mpmath` 50 位 / Julia `BigFloat`）的对照表。
3. **稳定性报告**：每个 HW 交付 0.5-1 页报告，回答"结果误差从哪来：问题本身病态（条件数大）还是算法不稳定（后向误差大）？"——**这是本体系的核心验收点，不是只看答案**。
4. **Capstone（HW06）**：完整项目报告，Rubric 沿用 [[📚 教材挂载索引]] 的 100 分制（数据与复现 20 / 方法正确性 25 / 基线与公平比较 20 / 评估与误差 20 / 报告与边界 15），75 分及格。
5. **口试验收**：每个 HW 完成后闭卷回答 3 问——"这个算法在算一个什么问题？它的前向/后向误差边界是什么？什么条件下它会失效？"
