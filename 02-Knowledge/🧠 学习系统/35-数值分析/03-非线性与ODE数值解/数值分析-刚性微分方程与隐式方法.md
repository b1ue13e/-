# 数值分析-刚性微分方程与隐式方法

> “当动力系统中存在跨越数个数量级的快衰减与慢演化多重时间尺度时，该微分方程系统被称为刚性问题（Stiff System）。显式积分器为了数值稳定性被迫采用被最快时间尺度支配的微小步长，导致计算耗时爆炸；只有绝对稳定的隐式积分器才能跨越快时间尺度，稳定跟踪物理主线。”

---

## 1. 刚性问题的物理与数学本质

考虑线性常系数 ODE 系统：
$$y' = A y, \quad y(0) = y_0$$
设矩阵 $A$ 的特征值为 $\lambda_1, \lambda_2, \dots, \lambda_n$，且所有特征值均满足 $\operatorname{Re}(\lambda_i) < 0$。

### 1.1 刚性比（Stiffness Ratio）
$$\text{Stiffness Ratio} = \frac{\max_i |\operatorname{Re}(\lambda_i)|}{\min_i |\operatorname{Re}(\lambda_i)|} \gg 1$$
- **快时间尺度**：由大特征值 $\lambda_{\max}$ 决定，瞬态解分量以 $e^{\lambda_{\max} t}$ 极速衰减至 0；
- **慢时间尺度**：由小特征值 $\lambda_{\min}$ 决定，平缓主导系统长时演化。

---

## 2. 线性稳定性理论与稳定性区域

采用标量线性测试模型：$y' = \lambda y$（其中 $\operatorname{Re}(\lambda) < 0$）。
设数值单步格式递推为 $y_{n+1} = R(z) y_n$，其中无量纲复参数 $z = \lambda h \in \mathbb{C}$，$R(z)$ 称为**稳定性函数（Stability Function）**。

### 2.1 绝对稳定性区域定义
$$\mathcal{D} = \{z \in \mathbb{C} : |R(z)| \le 1\}$$

### 2.2 典型积分器稳定性函数对照

| 算法格式 | 显式 / 隐式 | 稳定性函数 $R(z)$ | 稳定性区域几何特征 |
| :--- | :---: | :---: | :--- |
| **前向 Euler** | 显式 | $1 + z$ | 以 $-1$ 为圆心的单位圆，步长受限 $h \le \frac{2}{\|\lambda\|}$ |
| **四阶 Runge-Kutta (RK4)** | 显式 | $1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}$ | 沿负实轴伸展至 $[-2.78, 0]$ 的有界封闭区域 |
| **后向 Euler (Implicit Euler)** | 隐式 | $\frac{1}{1 - z}$ | 复平面上以 $1$ 为圆心的单位圆**外部**（包含整个 $\mathbb{C}^-$） |
| **梯形公式 (Crank-Nicolson)** | 隐式 | $\frac{1 + z/2}{1 - z/2}$ | 严格等于整个复平面左半平面 $\mathbb{C}^-$（边界为虚轴） |
| **2阶 Radau IIA** | 隐式 RK | $\frac{1 + z/3}{1 - 2z/3 + z^2/6}$ | 严格 A-稳定与 L-稳定 |

---

## 3. A-稳定性、L-稳定性与 Dahlquist 屏障

### 3.1 A-稳定性（A-Stability）
若积分方法的绝对稳定性区域包含整个复平面左半平面，即：
$$\mathbb{C}^- = \{z \in \mathbb{C} : \operatorname{Re}(z) \le 0\} \subseteq \mathcal{D}$$
则称该方法是 **A-稳定的**。无论步长 $h$ 多大，计算数值解恒有 $|y_{n+1}| \le |y_n|$，绝不产生数值发散爆炸。

### 3.2 L-稳定性（L-Stability）
在 A-稳定的基础上，若当 $z \to -\infty$ 时满足：
$$\lim_{\operatorname{Re}(z) \to -\infty} |R(z)| = 0$$
则称该方法是 **L-稳定的**。
- **差异**：梯形公式是 A-稳定但非 L-稳定（$z \to -\infty$ 时 $R(z) \to -1$，会在极度刚性截断处产生高频不衰减的非物理震荡）；
- 后向 Euler 与 Radau IIA 是典型的 L-稳定方法，能瞬间强力阻尼掉瞬态快分量。

### 3.3 Dahlquist 屏障定理（Dahlquist Barriers）
1. **第一屏障**：没有显式线性多步法（LMM）可以是 A-稳定的；
2. **第二屏障**：A-稳定的线性多步法其代数精度阶数最高不能超过 **2 阶**（梯形公式是最高阶的 A-稳定线性多步法）。

## 4. Python 实测：刚性系统显式崩溃 vs 隐式鲁棒

```python
import numpy as np

def solve_stiff_system():
    # 测试刚性方程: y' = -1000 y + 1000 cos(t), y(0) = 0
    # 精确解在极短时间内快衰减，随后稳定跟随 sin(t)
    lambda_val = -1000.0
    t_span = (0.0, 1.0)
    
    # 选取较大步长 h = 0.01 (此时 |lambda * h| = 10 >> 2，前向 Euler 理论必爆炸)
    h = 0.01
    n_steps = int((t_span[1] - t_span[0]) / h)
    t = np.linspace(t_span[0], t_span[1], n_steps + 1)
    
    # 1. 前向 Euler (显式)
    y_explicit = np.zeros(n_steps + 1)
    for i in range(n_steps):
        y_explicit[i+1] = y_explicit[i] + h * (lambda_val * y_explicit[i] + 1000.0 * np.cos(t[i]))
        if abs(y_explicit[i+1]) > 1e10:
            y_explicit[i+1:] = np.nan
            print(f"前向 Euler 在第 {i} 步彻底数值溢出崩溃！")
            break
            
    # 2. 后向 Euler (隐式)
    y_implicit = np.zeros(n_steps + 1)
    for i in range(n_steps):
        # y_{n+1} = y_n + h*(lambda*y_{n+1} + 1000*cos(t_{n+1}))
        # (1 - h*lambda) * y_{n+1} = y_n + 1000*h*cos(t_{n+1})
        y_implicit[i+1] = (y_implicit[i] + 1000.0 * h * np.cos(t[i+1])) / (1.0 - h * lambda_val)
        
    print(f"后向 Euler 终端解: {y_implicit[-1]:.6f}, 理论值: {np.sin(1.0):.6f}")
    assert abs(y_implicit[-1] - np.sin(1.0)) < 0.05
    return True

if __name__ == "__main__":
    solve_stiff_system()
```
