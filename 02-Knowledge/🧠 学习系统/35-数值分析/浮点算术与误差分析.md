# 浮点算术与误差分析

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：数值分析的一切结论都建立在"计算机里的数不是实数"上；LU、QR、特征值、迭代法的稳定性分析全部从这里出发，也是 [[🧭 开源作业体系-数值分析]] HW01 验收口径（误差/残差/条件数实验）的理论底座。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 纸上 $0.1$ 精确无误，但计算机里 `0.1 + 0.2 != 0.3`；按实数公式算出错答案时，不知该怪题目（病态）还是算法（不稳定）。
> 因此必须引入：**IEEE 754 浮点算术**（怎么存数、每步误差多大）+ **误差分析框架**（误差 = 条件数 × 算法稳定性）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：后续算法（[[LU分解与数值稳定性]]、[[QR分解与最小二乘]]、幂法/QR 迭代、CG/GMRES）的稳定性分析都引用本卡的浮点模型 $\operatorname{fl}(a\circ b)=(a\circ b)(1+\delta)$，不学它后面每个"为什么这样设计算法"都答不上来。
- **实际应用场景**：数值实验"结果与理论不符"的归因；深度学习梯度下溢/上溢（log-sum-exp）；混合精度（FP16/FP32/BFloat16）选型。
- **高频题型/任务**：给定 $\epsilon_{\text{mach}}$ 估计误差上界；识别灾难性抵消；判断算法是否后向稳定；数值稳定改写（如 $\sqrt{1+x}-1=\frac{x}{\sqrt{1+x}+1}$）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[误差与数值线代-浮点与误差-IEEE 浮点]]**：float/double 的符号-指数-尾数结构，理解"精度是相对的不是绝对的"。
2. **[[误差与数值线代-条件与稳定-condition number]]**：条件数度量"问题本身"对扰动的放大，是区分病态与不稳定的前提。
3. **[[误差与数值线代-条件与稳定-backward stability]]**：后向误差概念，本卡把它与浮点模型衔接。

---

## 4. 用直觉语言解释它

> «"浮点数就像一把只有有限刻度的尺子"：任何实数落进计算机都被"咔哒"吸到最近的刻度上，最大相对偏差就是 $\epsilon_{\text{mach}}$。误差分析则是"记账"——把每步舍入记成"输入被轻微污染"，再看答案误差是被问题放大（病态）还是算法添乱（不稳定）。»（参考：Trefethen & Bau, Lecture 1-3）

- **直觉类比**：$\epsilon_{\text{mach}}\approx2.2\times10^{-16}$（double）≈"尺子只有 16 位有效数字"；条件数 $\kappa$ 是放大镜倍数，$\kappa=10^{12}$ 意味着输入小误差被放大成灾难。
- **为什么很自然**：存储空间有限（64 bit），任何格式都要牺牲精度换范围；而相对误差是唯一与量纲无关的度量，故所有定义围绕它展开。
- **一句话直觉本质**：**"计算机算术 = 精确实数算术 + 每步 $1+\delta$ 相对扰动；误差 = 问题条件数 × 算法后向误差。"**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **IEEE 754 double**：$x=\pm(1.f)_2\times2^{e}$，$e\in[-1022,1023]$，尾数 52 bit（总精度 53 bit，含隐式前导 1）。
- **机器精度**：$\epsilon_{\text{mach}}=2^{-52}\approx2.22\times10^{-16}$，即满足 $\operatorname{fl}(1+\epsilon)>1$ 的最小 $\epsilon$。

### 2. 核心公式
- 单次舍入：$\left|\frac{\operatorname{fl}(x)-x}{x}\right|\le\epsilon_{\text{mach}}$
- 求和误差（朴素顺序）：$\left|\frac{\hat{s}-s}{s}\right|\lesssim n\,\epsilon_{\text{mach}}\cdot\kappa_{\text{sum}}$，其中 $\kappa_{\text{sum}}=\frac{\sum|x_i|}{|\sum x_i|}$
- 误差总公式：$\frac{\|\text{forward error}\|}{\|x\|}\lesssim\kappa(x)\cdot\epsilon_{\text{mach}}$（良态+稳定算法时）

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\operatorname{fl}(\cdot)$ | 浮点舍入结果 | — | 最近偶数舍入 |
| $\epsilon_{\text{mach}}$ | 机器精度 | double: $2^{-52}$ | 相对误差单位 |
| $\delta$ | 单次运算相对扰动 | $\le\epsilon_{\text{mach}}$ | 浮点模型"噪声" |
| $\kappa(x)$ | 问题条件数 | $\ge1$ | 病态问题 $\kappa\gg1$ |

### 4. 常见变体与适用条件
- **变体**：float（$u\approx6\times10^{-8}$）、double、FP16/BFloat16（深度学习常用）、任意精度（mpmath/BigFloat，作高精度参考）。
- **适用条件**：无溢出/下溢时成立；$\sqrt{\cdot}$ 等同样满足（IEEE 正确舍入）。**限制**：$\delta$ 模型不覆盖灾难性抵消（那是条件数问题）；BLAS 的 FMA 单次误差可减半。

---

## 6. 推导思路和思想来源

- **最初困难**：直接跟踪每步舍入的"前向误差"极其繁琐，且误差互相抵消/放大，给不出干净界。
- **关键"转念"**（Wilkinson 后向误差分析）：**把误差"推回去"**——不追问"答案偏多少"，而问"答案精确求解了哪个被轻微扰动的问题"：若 $\hat{x}$ 精确满足 $(A+\Delta A)\hat{x}=b+\Delta b$ 且 $\|\Delta A\|/\|A\|=O(\epsilon_{\text{mach}})$，则算法后向稳定。
- **推导主线**：浮点模型 $\operatorname{fl}(a\circ b)=(a\circ b)(1+\delta)$ → 中间量全是"被污染版本" → 累积等价于"输入被污染" → 后向误差 → 用条件数翻译成前向误差：$\text{forward}\le\kappa\times\text{backward}$（"条件数×后向误差"把责任一分为二，对应"题目难 vs 算法差"）。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：double 下计算 $1+10^{-17}$，结果是多少？
- **解答**：$10^{-17}<\epsilon_{\text{mach}}/2\approx1.1\times10^{-16}$（小于"最小可分辨增量"），舍入得 `1.0`；相对误差 $10^{-17}$ 看似小，对 $10^{-17}$ 本身却是 100%。
- **易错点**：绝对误差小 ≠ 相对误差小。
- **🤔 追问**：`1e16+1` 呢？——`1e16` 的 ULP 是 2，舍入回 `1e16`；`1e16+3` 得 `1.0000000000000002e16`。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：求 $x^2+10^8x+1=0$ 的较小根。直接套公式 $x=\frac{-b-\sqrt{b^2-4ac}}{2a}$ 得 $x\approx-10^8$——灾难性抵消（两个大数相减只剩噪声）。改写：两根之积 $x_1x_2=c/a=1$，故小根 $x_2=1/x_1\approx-10^{-8}$。**关键推理**：大根直算（无抵消），小根由韦达定理导出，两根都精确。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：任何数值实验的第一步都是"用代码验证 $\epsilon_{\text{mach}}$ 与抵消现象"，即 HW01 的验收入口：
```python
import numpy as np
eps = 1.0
while 1.0 + eps > 1.0:
    eps /= 2.0
print("eps_mach =", eps * 2)          # ≈ 2.22e-16

x = 1e-8
rel = abs(np.sin(x) - x) / x          # 灾难性抵消：两个近似相等的数相减
import mpmath as mp
mp.mp.dps = 50
print("真实 sin(x)-x =", mp.sin(x) - x)   # ≈ -1.666...e-25
```
- **🤔 追问**：改用 `math.sin` 会变好吗？——不会，抵消发生在"相减"这一步，与实现精度无关；正确做法是改写公式 $\sin x-x\approx-x^3/6$。

## 8. 常见误区和易混概念

### 误区 1：以为"$\epsilon_{\text{mach}}$ 是最小的正浮点数"
- **错误直觉**：机器精度就是能表示的最小正数。
- **为什么错**：最小正数（约 $5\times10^{-324}$）由指数范围决定，$\epsilon_{\text{mach}}$ 由尾数位数决定（**相对分辨率**）；正确理解：它是"1 旁边最近浮点数的间距"，即相对误差单位。

### 误区 2：把"结果不对"一律归咎于舍入误差
- **错误直觉**：答案偏差大 = 精度不够，升精度就行。
- **为什么错**：偏差可能来自**病态**（条件数大，升精度救不了）或**算法不稳定**（如不选主元的消元）；误差 = 条件数 × 后向误差。正确理解：病态 → 换表述/正则化；不稳定 → 换算法（主元、Householder）；都不是 → 才升精度。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 前向误差 | 答案偏了多少 | 直接度量输出 | 报告最终精度 |
| 后向误差 | 输入被污染多少 | 度量算法本身 | 判断算法稳定性（[[误差与数值线代-条件与稳定-backward stability]]） |
| 条件数 | 问题放大多少 | 与算法无关 | 判断问题是否病态（[[误差与数值线代-条件与稳定-condition number]]） |
| 灾难性抵消 | 相减丢精度 | 是条件数问题 | 改写公式规避（[[误差与数值线代-浮点与误差-消去误差]]） |

### 题目与解析

#### 1. 为什么说 $\epsilon_{\text{mach}}$ 衡量的是"相对"精度而不是"绝对"精度？
> [!question]- 答案解析
> - **答案**：$\epsilon_{\text{mach}}$ 是 $1$ 与下一个可表示浮点数的间距（double $2^{-52}$），任何浮点数的相对误差都被它界定：$|\operatorname{fl}(x)-x|/|x|\le\epsilon_{\text{mach}}$，与量级无关。
> - **解析**：浮点间距随指数缩放（越大越稀疏），绝对误差无统一上界、相对误差才有——故相对误差成为标准度量。
> - **易错原因**：混淆"最小正数"（指数下界决定）与"机器精度"（尾数位数决定）。
> - **对应误区**：误区 1。 `#自测题/基础`

#### 2. 设 $a=1.0,\ b=2.0\times10^{-16}$，double 下 $\operatorname{fl}(a+b)$ 是多少？$b=2.0\times10^{-15}$ 呢？
> [!question]- 答案解析
> - **答案**：前者 `1.0`（$b<u$ 被吸收）；后者 `1.0000000000000002`（$b>u$，最近偶数舍入）。
> - **解析**：$u=\epsilon_{\text{mach}}/2=1.11\times10^{-16}$；$2e-15>u$ 可表示但相对误差 $\approx2e-15$ 仍是 $\epsilon_{\text{mach}}$ 量级。易错：把舍入门槛记成 $\epsilon_{\text{mach}}$ 而非 $u$。

#### 3. 算法 A 后向误差 $10^{-16}$、B 为 $10^{-8}$，问题 $\kappa=10^{12}$。哪个结果更可信？为什么？
> [!question]- 答案解析
> - **答案**：A。前向误差 $\lesssim\kappa\times$后向误差：A 约 $10^{-4}$，B 约 $10^{4}$——B 可能完全无意义。
> - **解析**：误差 = 条件数 × 后向误差；两算法都被放大，但 A 的放大起点低 8 个量级。易错：只看"答案差多少"不做归因分解。

#### 4. 计算 $f(x)=\sqrt{x+1}-1$ 在 $x\approx0$ 处发生灾难性抵消，请给出数值稳定改写并说明原理。
> [!question]- 答案解析
> - **答案**：$f(x)=\dfrac{x}{\sqrt{x+1}+1}$。
> - **解析**：分子有理化后不再有两个近似相等的大数相减，$x$ 的信息以乘法保留，相对误差不再被 $\kappa_{\text{sum}}$ 放大（$x\ge-1$ 时分母非零）。易错：只背结论不讲原理。

#### 5. 证明：朴素顺序求 $s=\sum x_i$（同号）满足 $\left|\frac{\hat{s}-s}{s}\right|\lesssim n\,\epsilon_{\text{mach}}$；若 $x_i$ 异号，上界如何变化？
> [!question]- 答案解析
> - **答案**：设第 $i$ 步部分和为 $s_i$，浮点模型给每步引入 $(1+\delta_i)$，故 $\hat{s}=s\prod(1+\delta_i)$；同号时 $|s_i|\le|s|$，误差因子累加得 $n\epsilon_{\text{mach}}+O(\epsilon^2)$。
> - **解析**：异号时部分和可远大于最终和，上界需乘 $\kappa_{\text{sum}}=\sum|x_i|/|\sum x_i|$（可任意大）——同号求和才安全，也是 Kahan 求和（误差 $O(\epsilon)$）的动机。易错：漏掉 $\kappa_{\text{sum}}$ 因子。
