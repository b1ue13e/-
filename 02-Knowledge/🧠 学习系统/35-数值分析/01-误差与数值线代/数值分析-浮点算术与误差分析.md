# 数值分析-浮点算术与误差分析

> "计算机算术 = 精确实数算术 + 每步 $1+\delta$ 相对扰动。前向误差是答案与真值的偏离，而后向误差是使得计算结果成为另一个邻近问题精确解的扰动量。"

---

## 1. 问题动机与核心价值

纸面上 $0.1$ 精确无误，但计算机中 $0.1$ 转化为二进制是无限循环小数，产生固有舍入误差。
在多步复合计算中，如果不加控制，舍入误差会迅速被条件数放大，甚至在相近大数相减时发生**灾难性相消（Catastrophic Cancellation）**。

---

## 2. 严密数学模型与公式

### 标准浮点运算模型（Standard Model of Floating Point Arithmetic）
对于基础算术操作 $\circ \in \{+, -, \times, /\}$，IEEE 754 标准保证：
$$\operatorname{fl}(x \circ y) = (x \circ y)(1 + \delta), \quad |\delta| \le \epsilon_{\text{mach}}$$

### 求和的误差积累推导
计算 $s_n = \sum_{i=1}^n x_i$，按朴素递归求和：
$$\hat{s}_n = x_1(1+\theta_n) + x_2(1+\theta_n) + x_3(1+\theta_{n-1}) + \dots + x_n(1+\theta_2)$$
其中 $|\theta_k| \le \gamma_k = \frac{k \epsilon_{\text{mach}}}{1 - k \epsilon_{\text{mach}}}$。
绝对误差界为：
$$|\hat{s}_n - s_n| \le \gamma_n \sum_{i=1}^n |x_i|$$
相对误差界为：
$$\frac{|\hat{s}_n - s_n|}{|s_n|} \le \gamma_n \frac{\sum_{i=1}^n |x_i|}{|\sum_{i=1}^n x_i|} = \gamma_n \kappa_{\text{sum}}$$

其中 $\kappa_{\text{sum}} = \frac{\sum |x_i|}{|\sum x_i|}$ 为求和问题的条件数。当正负项相加且总和接近 0 时，$\kappa_{\text{sum}} \gg 1$，发生灾难性抵消。

## 3. 经典算例与 Python 稳定改写

```python
import numpy as np

# 经典灾难性相消：f(x) = sqrt(1+x) - 1 当 x 极小时
x = 1e-15

# 不稳定形式
y_bad = np.sqrt(1.0 + x) - 1.0

# 代数有理化稳定形式: x / (sqrt(1+x) + 1)
y_good = x / (np.sqrt(1.0 + x) + 1.0)

print(f"Unstable: {y_bad:.18e}")
print(f"Stable  : {y_good:.18e}")
print(f"Expected: 5.000000000000000000e-16")
```

## 4. 易错陷阱与数值误区

- **误区**：以为使用 double 精度（16 位有效数字）就可以高枕无忧。在病态求和或微分中，一次相消就可以瞬间丢掉全部 16 位有效数字！
