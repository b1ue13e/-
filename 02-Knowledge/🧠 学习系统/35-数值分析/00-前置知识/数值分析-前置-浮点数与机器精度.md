# 数值分析-前置-浮点数与机器精度

> "实数轴是连续且无界的，但计算机内存是离散且有限的。任何数值算法都必须在 IEEE 754 浮点网格上运行。"

---

## 1. 问题动机与核心价值

在数学纸面上，运算满足结合律 $(a+b)+c = a+(b+c)$，但在计算机中，由于每次运算都会产生舍入误差（Roundoff Error），结合律不再严格成立。
了解浮点数的二进制表示、机器精度（Machine Epsilon, $\epsilon_{\text{mach}}$）以及下溢（Underflow）与上溢（Overflow），是理解所有数值稳定性的物理基础。

---

## 2. 严密数学定义与 IEEE 754 结构

### IEEE 754 双精度浮点格式（Binary64 / Double）
一个实数在计算机中被表示为 64 位二进制位：
$$x = (-1)^s \times (1.f)_2 \times 2^{e - 1023}$$

| 组成部分 | 占用位数 | 含义与取值范围 |
| :--- | :--- | :--- |
| **符号位 $s$** | 1 bit | 0 表示正数，1 表示负数 |
| **阶码 $e$** | 11 bit | 偏置指数，取值 $[1, 2046]$（0 和 2047 用于特殊值） |
| **尾数 $f$** | 52 bit | 包含隐式前导 1，有效数字共 53 位二进制位 |

### 机器精度（Machine Epsilon）
机器精度定义为使得 $1.0 + \epsilon > 1.0$ 的最小正浮点数 $\epsilon$：
$$\epsilon_{\text{mach}} = 2^{-52} \approx 2.220446 \times 10^{-16}$$

对于任何实数 $x$，其最近偶数舍入值 $\operatorname{fl}(x)$ 满足基本浮点模型：
$$\operatorname{fl}(x) = x(1 + \delta), \quad |\delta| \le \frac{1}{2}\epsilon_{\text{mach}} = u$$
其中 $u = 2^{-53} \approx 1.11 \times 10^{-16}$ 称为单位舍入误差（Unit Roundoff）。

## 3. Python 验证代码

```python
import numpy as np

# 验证机器精度
eps = np.finfo(np.float64).eps
print(f"Numpy Float64 eps: {eps}")
assert 1.0 + eps > 1.0
assert 1.0 + eps / 2.0 == 1.0

# 灾难性抵消演示
x = 1.0 + 1e-15
y = 1.0
diff = x - y
print(f"Direct sub: {diff}, Expected: 1e-15, Relative Error: {abs(diff - 1e-15)/1e-15:.2e}")
```

---

## 4. 易错陷阱

- **误区 1**：把 $\epsilon_{\text{mach}}$ 当作计算机能表示的最小正数。最小正正规数是 $2^{-1022} \approx 2.23 \times 10^{-308}$，而 $\epsilon_{\text{mach}}$ 是“相对分辨率”。
- **误区 2**：浮点数在数轴上是均匀分布的。实际上，浮点数是按 $2^e$ 分段分布的，越靠近 0 越密集，越远离 0 越稀疏。
