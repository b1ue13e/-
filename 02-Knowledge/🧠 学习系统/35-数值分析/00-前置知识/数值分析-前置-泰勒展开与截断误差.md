# 数值分析-前置-泰勒展开与截断误差

> “数值分析中所有连续逼近（差分、插值、求积、ODE/PDE 离散）的解析理论底座，都是带 Lagrange / Cauchy 余项的多元 Taylor 展开定理。理解截断误差与舍入误差在步长 $h$ 缩小过程中的消长竞争，是构建可靠算法的第一课。”

---

## 1. 问题动机与核心价值

连续微积分中的导数定义 $f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}$ 在离散物理计算机上无法直接执行无穷小极限。
必须用有限离散步长 $h > 0$ 的代数商式来近似导数。Taylor 展开定理不仅给出了近似算子的构造方法，更精确给出了**截断误差（Truncation Error）的渐近阶 $O(h^p)$ 与先验误差界**。

---

## 2. 严密数学推导：导数差分算子与截断误差

设 $f \in C^4[x-h, x+h]$，在 $x$ 处进行 Taylor 展开：
$$f(x+h) = f(x) + h f'(x) + \frac{h^2}{2!} f''(x) + \frac{h^3}{3!} f'''(x) + \frac{h^4}{4!} f^{(4)}(\xi_1)$$
$$f(x-h) = f(x) - h f'(x) + \frac{h^2}{2!} f''(x) - \frac{h^3}{3!} f'''(x) + \frac{h^4}{4!} f^{(4)}(\xi_2)$$

### 2.1 前向单侧差分（Forward Difference）
$$D_+ f(x) = \frac{f(x+h) - f(x)}{h} = f'(x) + \frac{h}{2} f''(\xi_1) = f'(x) + O(h)$$
- **截断误差**：$E_{\text{trunc}}(h) = \frac{h}{2} f''(\xi_1)$，为**一阶代数精度 $O(h)$**。

### 2.2 中心差分（Central Difference）
将两式相减可消去所有偶数阶微商项：
$$f(x+h) - f(x-h) = 2h f'(x) + \frac{2h^3}{6} f'''(x) + O(h^5)$$
$$D_0 f(x) = \frac{f(x+h) - f(x-h)}{2h} = f'(x) + \frac{h^2}{6} f'''(\eta) = f'(x) + O(h^2)$$
- **截断误差**：$E_{\text{trunc}}(h) = \frac{h^2}{6} f'''(\eta)$，由对称性直接跃升为**二阶代数精度 $O(h^2)$**。

### 2.3 二阶导数中心差分（Laplacian 模板基石）
将两式相加可消去所有奇数阶微商项：
$$f(x+h) + f(x-h) = 2f(x) + h^2 f''(x) + \frac{h^4}{12} f^{(4)}(\zeta)$$
$$D^2 f(x) = \frac{f(x+h) - 2f(x) + f(x-h)}{h^2} = f''(x) + \frac{h^2}{12} f^{(4)}(\zeta) = f''(x) + O(h^2)$$
- 该格式是后续偏微分方程有限差分（Poisson 方程五点模板）的核心数学来源。

### 2.4 理查森外推法（Richardson Extrapolation）
利用已知误差渐近展开 $D_0(h) = f'(x) + c_2 h^2 + c_4 h^4 + \dots$，取步长 $h$ 与 $h/2$：
$$D_0(h/2) = f'(x) + c_2 \frac{h^2}{4} + c_4 \frac{h^4}{16} + \dots$$
消除 $h^2$ 项得到四阶高精导数逼近：
$$D_{\text{richardson}} = \frac{4 D_0(h/2) - D_0(h)}{3} = f'(x) + O(h^4)$$

## 3. 物理冲突：截断误差与舍入误差的“U型竞争”

在 IEEE 754 浮点机上，函数值计算带有机器舍入误差 $\tilde{f}(x) = f(x) + \epsilon(x)$（其中 $|\epsilon| \le \epsilon_{\text{mach}}$）。
实际计算的中心差商总误差为：
$$E_{\text{total}}(h) = \left| \frac{\tilde{f}(x+h) - \tilde{f}(x-h)}{2h} - f'(x) \right| \le \underbrace{\frac{h^2}{6} M_3}_{\text{截断误差 } O(h^2)} + \underbrace{\frac{\epsilon_{\text{mach}}}{h}}_{\text{舍入误差放大 } O(h^{-1})}$$
- 当 $h$ 较大时，截断误差占主导；
- 当 $h \to 0$ 时，舍入误差由于分母 $h$ 被剧烈放大；
- 最优平衡步长：对 $h$ 求导可得 $h^* = \left( \frac{3 \epsilon_{\text{mach}}}{M_3} \right)^{1/3} \approx \epsilon_{\text{mach}}^{1/3} \approx 10^{-5} \sim 10^{-6}$。

```python
import numpy as np

def demo_truncation_vs_roundoff():
    x = 1.0
    exact = np.cos(x)
    f = np.sin
    
    h_vals = np.logspace(-16, 0, 50)
    err_forward = []
    err_central = []
    
    for h in h_vals:
        df_fwd = (f(x + h) - f(x)) / h
        df_cen = (f(x + h) - f(x - h)) / (2 * h)
        err_forward.append(abs(df_fwd - exact))
        err_central.append(abs(df_cen - exact))
        
    min_idx = np.argmin(err_central)
    best_h = h_vals[min_idx]
    print(f"中心差分最优实测步长 h*: {best_h:.2e}, 最小总误差: {err_central[min_idx]:.2e}")
    return h_vals, err_central

if __name__ == "__main__":
    demo_truncation_vs_roundoff()
```
