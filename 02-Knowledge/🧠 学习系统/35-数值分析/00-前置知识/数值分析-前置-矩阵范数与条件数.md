# 数值分析-前置-矩阵范数与条件数

> "条件数度量的是数学问题本身的内在敏感性，它是任何算法无法通过巧妙设计而消除的物理误差放大倍数。"

---

## 1. 问题动机与核心价值

求解线性方程组 $Ax=b$ 时，如果输入 $b$ 受到微小扰动 $\delta b$，解的扰动 $\delta x$ 会有多大？
通过引入向量范数与诱导矩阵范数，我们可以严格导出条件数 $\kappa(A)$，它是连接后向误差与前向误差的决定性桥梁。

---

## 2. 严密数学定义

### 向量范数与诱导矩阵范数
对于矩阵 $A \in \mathbb{R}^{m \times n}$，由向量范数 $\|\cdot\|_p$ 诱导的矩阵范数为：
$$\|A\|_p = \sup_{x \ne 0} \frac{\|Ax\|_p}{\|x\|_p}$$

常用矩阵范数计算公式：
- **1-范数（最大列和）**：$\|A\|_1 = \max_{1 \le j \le n} \sum_{i=1}^m |a_{ij}|$
- **$\infty$-范数（最大行和）**：$\|A\|_\infty = \max_{1 \le i \le m} \sum_{j=1}^n |a_{ij}|$
- **2-范数（谱范数）**：$\|A\|_2 = \sigma_{\max}(A) = \sqrt{\lambda_{\max}(A^T A)}$

### 矩阵条件数（Condition Number）
对于非奇异方阵 $A$，其相对于逆运算的条件数定义为：
$$\kappa(A) = \|A\| \|A^{-1}\|$$
特别地，在 2-范数下：
$$\kappa_2(A) = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)} \ge 1$$

### 扰动定理核心不等式
设 $Ax = b$ 且 $A(x+\delta x) = b+\delta b$，则：
$$\frac{\|\delta x\|}{\|x\|} \le \kappa(A) \frac{\|\delta b\|}{\|b\|}$$

## 3. 几何直觉与 Python 演示

```python
import numpy as np

# Hilbert 矩阵是经典病态矩阵
def hilbert(n):
    return 1.0 / (np.arange(1, n+1) + np.arange(0, n)[:, np.newaxis])

H = hilbert(10)
cond_H = np.linalg.cond(H)
print(f"10阶 Hilbert 矩阵条件数: {cond_H:.2e}")
```

## 4. 易错陷阱

- **误区**：矩阵行列式小 $\det(A) \approx 0$ 就代表矩阵病态。
  - 反例：$A = 0.1 I_{100}$，$\det(A) = 10^{-100} \approx 0$，但 $\kappa_2(A) = 1$，属于极其良态的问题！
