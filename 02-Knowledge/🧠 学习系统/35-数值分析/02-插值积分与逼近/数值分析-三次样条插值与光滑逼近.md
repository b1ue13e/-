# 数值分析-三次样条插值与光滑逼近

> "避免全局高次插值振荡的工程黄金解法是分段低次多项式。三次样条在保证分段三次的同时，通过全局连续性约束获得了 $C^2$ 的二阶连续导数光滑度。"

---

## 1. 严密数学定义与方程推导

设给定节点 $a = x_0 < x_1 < \dots < x_n = b$，步长 $h_i = x_{i+1} - x_i$。
函数 $S(x)$ 称为三次样条插值函数，满足：
1. **插值条件**：$S(x_i) = y_i, \quad i = 0, 1, \dots, n$；
2. **分段多项式**：在每个子区间 $[x_i, x_{i+1}]$ 上，$S(x)$ 是三次多项式 $S_i(x)$；
3. **$C^2$ 光滑性**：在所有内部节点 $x_i$ 处，函数值、一阶导数与二阶导数均连续：
   $$S_i(x_i) = S_{i-1}(x_i), \quad S_i'(x_i) = S_{i-1}'(x_i), \quad S_i''(x_i) = S_{i-1}''(x_i)$$

### 二阶导数连续性（三对角方程组）
令 $M_i = S''(x_i)$ 为节点处的弯矩（二阶导数值）。根据线性插值与二阶积分，内部节点 $x_i$ 满足严密的**三对角方程组**：
$$\mu_i M_{i-1} + 2 M_i + \lambda_i M_{i+1} = d_i, \quad i = 1, 2, \dots, n-1$$
其中：
$$\lambda_i = \frac{h_i}{h_{i-1} + h_i}, \quad \mu_i = \frac{h_{i-1}}{h_{i-1} + h_i}, \quad d_i = \frac{6}{h_{i-1} + h_i} \left( \frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}} \right)$$

由于 $\lambda_i + \mu_i = 1$，该三对角矩阵**严格对角占优**，使用 Thomas 算法可以在 $O(n)$ 线性时间内无求逆后向稳定求解！

### 边界条件分类
- **自然样条（Natural Spline）**：$M_0 = M_n = 0$（自由端点）；
- **钳位样条（Clamped Spline）**：$S'(a) = y_0', S'(b) = y_n'$；
- **周期样条（Periodic Spline）**：$S(a)=S(b), S'(a)=S'(b), S''(a)=S''(b)$。
