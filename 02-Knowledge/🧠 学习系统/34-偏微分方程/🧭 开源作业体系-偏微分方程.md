# 🧭 开源作业体系-偏微分方程

> 本页是「偏微分方程」开源名校课程与作业的**唯一挂载点**：教材主线、作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**[MIT 18.152 PDE Notes](https://ocw.mit.edu/courses/18-152-introduction-to-partial-differential-equations-fall-2005/)（MIT OCW terms，讲义+作业）** + **MIT 18.152 Assignments（验收口径，link-only）**。

---

## 📚 教材主线（Spine）

| 角色 | 来源 | 用途 |
|:---|:---|:---|
| 主教材 | [MIT 18.152 PDE Notes](https://ocw.mit.edu/courses/18-152-introduction-to-partial-differential-equations-fall-2005/) | 一阶 PDE、椭圆/抛物/双曲分类与证明主线；`MIT OCW terms` |
| 验收源 | [MIT 18.152 Assignments](https://ocw.mit.edu/courses/18-152-introduction-to-partial-differential-equations-fall-2005/pages/assignments/) | 习题与验收口径；默认 `link-only` |
| 前置 | 06-常微分方程 + 26-实变函数（或 28-数学分析） | ODE 求解工具与分析语言（一致收敛、逐项微分） |

**Honor Code 说明**：MIT OCW 讲义可在线免费阅读并署名；作业必须独立完成，不复制官方解答；笔记 `sources` 需定位到讲义章节或作业编号。

## 🎯 作业体系（HW01-HW05）

| HW | 主题 | 官方来源（口径） | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 一阶 PDE 与特征线法 | 18.152 讲义 + Assignments | 待补卡（特征线、柯西问题） | 手解 + 特征线作图 |
| HW02 | 波动方程与达朗贝尔解 | 18.152 | 待补卡（双曲方程、初值问题） | 行波解推导 + 依赖区间分析 |
| HW03 | 热方程与分离变量/Fourier 级数 | 18.152 | 待补卡（抛物方程、Fourier 展开、极值原理） | 手算级数解 + 数值验证 |
| HW04 | 拉普拉斯方程与调和函数 | 18.152 | 待补卡（椭圆方程、Green 函数、最大值原理） | 圆域/矩形域边值问题手解 |
| HW05 | 能量方法与唯一性 | 18.152 | 待补卡（能量积分、适定性三要素） | 能量法证明唯一性 + 反例讨论 |

> 分层验收原则：HW01-02 走特征线与双曲线；HW03-04 是 Fourier/边值主线；HW05 用能量法收口，完成三类方程的"分类 → 解法 → 适定性"闭环。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷手算/证明（证明型课程核心）；② 数值验证（有限差分或谱方法小例，Python）；③ 1 页报告（方法适用边界 + 失败案例）。
2. **证明要求**：HW05 的能量法证明必须完整逐步写出，禁止跳步。
3. **数据来源**：手构造边值数据 + 公开 PDE 算例库（如 SciPy/NumPy 有限差分，许可 MIT/Apache）。
4. **满分 Rubric**：HW01-05 各 20 分，共 100 分（证明/手算 40 + 数值实现 30 + 报告 30）。
