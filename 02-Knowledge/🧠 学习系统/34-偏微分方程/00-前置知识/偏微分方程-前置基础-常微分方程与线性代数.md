# 常微分方程与线性代数

> 所属阶段 MOC：[[00-前置知识/🧭 偏微分方程-前置知识|🧭 偏微分方程-前置知识]]  
> 学习定位：为偏微分方程分离变量法提供二阶常微分方程边值求解技术与 $L^2$ 内积空间正交展开理论支撑。

---

## 1. 核心问题与物理直觉

偏微分方程（如弦振动波动方程、棒导热热方程）在空间有界区域上的求解，核心思想是通过“**分离变量法**”将一个包含多变量的偏微分方程拆解为若干个仅含单变量的常微分方程。
在这个过程中，空间方向的常微分方程通常伴随齐次边界条件，构成**两点边值问题（特征值问题）**。线性代数中矩阵的特征值与特征向量理论，在无穷维函数空间上自然推广为微分算子的特征值与特征函数系。

---

## 2. 正式数学表述与定理公式

### 2.1 典型二阶线性 ODE 两点边值问题
考虑区间 $[0, L]$ 上的常系数齐次常微分方程：
$$X''(x) + \lambda X(x) = 0, \quad x \in (0, L)$$
根据不同物理边界条件，特征值 $\lambda$ 与特征函数 $X(x)$ 的解结构如下：

#### (1) 两端固定（Dirichlet 边界）：$X(0) = 0, X(L) = 0$
- 通解分类讨论：
  - 若 $\lambda < 0$，令 $\lambda = -\mu^2 (\mu > 0)$，$X(x) = c_1 \cosh(\mu x) + c_2 \sinh(\mu x)$。代入边界条件得 $c_1 = 0, c_2 \sinh(\mu L) = 0 \implies c_2 = 0$（仅零解）。
  - 若 $\lambda = 0$，$X(x) = c_1 x + c_2 \implies c_1 = c_2 = 0$（仅零解）。
  - 若 $\lambda > 0$，令 $\lambda = \mu^2 (\mu > 0)$，$X(x) = c_1 \cos(\mu x) + c_2 \sin(\mu x)$。
    $X(0) = 0 \implies c_1 = 0$；$X(L) = c_2 \sin(\mu L) = 0$。为存在非零解，必有 $\mu L = n\pi \, (n \in \mathbb{N}^+)$。
- **特征值与特征函数**：
  $$\lambda_n = \left(\frac{n\pi}{L}\right)^2, \quad X_n(x) = \sin\left(\frac{n\pi x}{L}\right), \quad n = 1, 2, 3, \dots$$

#### (2) 两端绝热/自由（Neumann 边界）：$X'(0) = 0, X'(L) = 0$
- 类似分类讨论可得：
  $$\lambda_0 = 0, \quad X_0(x) = 1; \quad \lambda_n = \left(\frac{n\pi}{L}\right)^2, \quad X_n(x) = \cos\left(\frac{n\pi x}{L}\right), \quad n = 1, 2, 3, \dots$$

### 2.2 $L^2(0, L)$ 希尔伯特空间内积与正交性
在实函数空间 $L^2(0, L)$ 中定义标准内积与诱导范数：
$$\langle f, g \rangle = \int_0^L f(x) g(x) \, dx, \quad \|f\|_{L^2} = \sqrt{\langle f, f \rangle} = \left(\int_0^L |f(x)|^2 \, dx\right)^{1/2}$$

**特征函数系正交性**：
$$\int_0^L \sin\left(\frac{m\pi x}{L}\right) \sin\left(\frac{n\pi x}{L}\right) \, dx = \begin{cases} 0, & m \neq n \\ \frac{L}{2}, & m = n \end{cases}$$

### 2.3 广义傅里叶级数展开定理 (Fourier Series)
对任意 $f \in L^2(0, L)$，在 $L^2$ 均方意义下可唯一展开为正交基的无穷级数：
$$f(x) = \sum_{n=1}^\infty c_n \sin\left(\frac{n\pi x}{L}\right), \quad c_n = \frac{\langle f, X_n \rangle}{\|X_n\|^2} = \frac{2}{L}\int_0^L f(x)\sin\left(\frac{n\pi x}{L}\right) \, dx$$

## 3. 典型例题与推导演练

### 【例题】计算方波函数的正弦 Fourier 展开系数
设 $L = \pi$，函数 $f(x) = 1, x \in (0, \pi)$。求其正弦基展开系数 $c_n$。

**计算步骤**：
1. 套用投影公式：
   $$c_n = \frac{2}{\pi}\int_0^\pi 1 \cdot \sin(nx) \, dx = \frac{2}{\pi}\left[ -\frac{\cos(nx)}{n} \right]_0^\pi = \frac{2}{n\pi}\left( 1 - (-1)^n \right)$$
2. 分奇偶项讨论：
   $$c_n = \begin{cases} \frac{4}{n\pi}, & n \text{ 为奇数} \\ 0, & n \text{ 为偶数} \end{cases}$$
3. 得到级数展开式：
   $$f(x) = \frac{4}{\pi}\left( \sin(x) + \frac{\sin(3x)}{3} + \frac{\sin(5x)}{5} + \dots \right)$$

## 4. 常见误区与反例

- **误区 1：漏掉 $\lambda = 0$ 对应常数特征函数的可能性**。在 Neumann 边界（导数全为 0）时，$\lambda = 0$ 对应非零解 $X_0(x) = \text{常数}$，代表系统平均温度或质心平衡态，若遗漏会导致初始条件无法拟合直流分量。
- **误区 2：逐点收敛与 $L^2$ 均方收敛的混淆**。带有跳跃间断点的函数进行傅里叶级数展开时，级数在间断点附近会出现高达 $9\%$ 峰值的 **Gibbs 现象**，但它在 $L^2$ 范数下仍严格收敛。
