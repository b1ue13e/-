## 3. 🧪 自动化测试 Harness (SymPy Validation)

```python
import sympy as sp

def test_implicit_function_derivative():
    x, y = sp.symbols('x y')
    # F(x, y) = x^2 + y^2 - 1 = 0 => dy/dx = -F_x / F_y = -x / y
    F = x**2 + y**2 - 1
    dy_dx = -sp.diff(F, x) / sp.diff(F, y)
    
    assert sp.simplify(dy_dx - (-x / y)) == 0, "隐函数一阶导数公式必须符合 -F_x / F_y"
```

## 🃏 Anki 卡片

- Q: 函数项级数 $\sum f_n(x)$ 在区间 $I$ 上一致收敛 (Uniform Convergence) 的定义是什么？它与逐点收敛有何区别？
- A: 一致收敛要求对任意 $\varepsilon > 0$，存在统一的 $N(\varepsilon)$（与 $x$ 无关），使得当 $n > N$ 时，对**所有** $x \in I$ 均有 $|S_n(x) - S(x)| < \varepsilon$。逐点收敛的 $N(\varepsilon, x)$ 可以依赖于特定点 $x$。
