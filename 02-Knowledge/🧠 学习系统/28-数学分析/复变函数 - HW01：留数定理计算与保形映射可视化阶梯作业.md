## 3. 🧪 自动化测试 Harness (SymPy Residue Validation)

```python
import sympy as sp

def test_residue_computation():
    z = sp.Symbol('z')
    # f(z) = cos(z) / (z**2 + 1), 极点在 z = I 与 z = -I
    f = sp.cos(z) / (z**2 + 1)
    
    res_I = sp.residue(f, z, sp.I)
    expected = sp.cos(sp.I) / (2 * sp.I) # cos(i) = cosh(1)
    
    assert sp.simplify(res_I - expected) == 0, "SymPy 留数计算必须符合极点公式"
```

## 🃏 Anki 卡片

- Q: 简述留数定理 (Residue Theorem) 计算闭曲线积分 $\oint_C f(z) dz$ 的核心结论与条件。
- A: 若函数 $f(z)$ 在简单闭曲线 $C$ 及其内部除有限个孤立奇点 $z_1, z_2, \dots, z_n$ 外处处解析，则沿 $C$ 正向的回路积分为 $2\pi i$ 乘以曲线内部所有奇点处留数的总和：$\oint_C f(z) dz = 2\pi i \sum_{k=1}^n \text{Res}(f, z_k)$。
