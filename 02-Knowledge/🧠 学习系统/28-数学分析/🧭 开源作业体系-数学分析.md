# 🧭 开源作业体系-数学分析

> 本页是「数学分析」的开源教材与作业的**唯一挂载点**：教材主线、官方作业链（HW01-HW06）、知识点覆盖矩阵、验收方式全部在此对齐。数学类课程不走机器学习"指标冲榜"模式，统一采用 **定义复述 → 证明重建 → 反例 → 条件变式 → 闭卷验收** 的闭环。

## ✅ 验收方式（数学类闭环模式）

1. **每章核心证明 + 反例卡 + 分级习题**：每个 HW 至少完成 1 个核心定理的"证明重建"（合上教材，从定义出发写出证明主线与关键转念）、1 张反例卡（默写条件缺失时结论如何失效）、基础/变式/综合分级习题各若干。
2. **阶段末『从定义重建定理链』闭卷验收**：合上所有笔记，按依赖顺序从定义出发重建整条定理链（例：一致收敛定义 → 连续性保持 → M-判别 → 极限/积分/微分交换定理），用依赖表逐条核对，卡住处即回补。
3. **100 分 Rubric**（沿用 [[📚 教材挂载索引]]）：定义/正例/反例 20 分、证明正确性 35 分、分级习题 20 分、定理依赖与反思 15 分、口头验收 10 分；总分 ≥75 且证明 ≥25 通过。
4. **工具**：纸笔证明为主；SymPy 做符号/数值验证（见 [[数学分析 - HW01：隐函数定理与一致收敛证明阶梯作业]]）；Lean 4 可选作 L4 形式化拓展。

## 🎓 Honor Code

- MIT OCW 与 Rudin 的 Problem Sets 必须**先独立闭卷完成**，再对照公开解答（如 baby-rudin-solutions）复盘；禁止先看解答再"默写"。
- 讲义与公开笔记可引用并记录来源（URL / 章节 / 作业编号），但**答案默认 `link-only`**，不复制他人证明冒充自证。
- 反例卡鼓励自己构造；借用经典反例（如 $x^n$、Dirichlet 函数）时须能闭卷复述其失效机制。
