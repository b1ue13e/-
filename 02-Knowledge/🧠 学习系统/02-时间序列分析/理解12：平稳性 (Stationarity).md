# 理解12：平稳性 (Stationarity)

## 1. 优先级判断
- **优先级**：A 类核心概念
- **理由**：平稳性是所有经典时间序列分析（如 ARMA 模型）的绝对前提。如果不理解平稳性，就无法进行任何有意义的预测和建模。它是时间序列统计基础层的“地基”。

## 2. 这个知识点解决什么问题？
> **我们遇到了什么麻烦？**

在分析时间序列时，数据是沿着时间轴展开的单次实现（我们只有一个历史）。如果数据的生成规律（平均水平、波动大小）随着时间不断变化，那么“过去”就无法作为预测“未来”的依据，因为游戏规则一直在变。我们需要一种数学上的“稳定性”，使得利用历史数据估计出的统计特征（如均值、方差）能够推广到未来，从而使得预测成为可能。

## 3. 为什么它重要？它有什么用？
- **大图景位置**：它是整个经典时间序列分析（Box-Jenkins 方法）的基石。所有的预测模型（AR、MA、ARMA）都假设输入序列是平稳的。
- **量化金融应用**：在量化交易中，资产价格（如股票价格）通常是不平稳的（随机游走），无法直接预测。我们必须通过差分或计算收益率，将其转化为平稳序列，才能使用统计模型进行套利或风险评估（例如配对交易中的协整关系，本质也是寻找平稳的价差序列）。

## 4. 学它之前需要哪些前置知识？
### 最小必要背景 (200 字以内)
1. **随机变量与概率分布**：理解时间序列 $X_t$ 在每个时间点都是一个随机变量。
2. **期望（Mean）与方差（Variance）**：知道 $E[X]$ 表示中心位置，$Var(X)$ 表示波动幅度。
3. **协方差（Covariance）**：理解两个随机变量如何协同变化，$Cov(X, Y) = E[(X-E[X])(Y-E[Y])]$。

## 5. 用直觉语言解释它
«“这东西其实就像……”»

这就像你在观察一片海面的波浪。如果正处于涨潮期，海平面在不断上升（均值变化）；或者风暴正在聚集，浪头越来越高（方差变化），那么你昨天的观察经验对今天就没用了。**平稳性**，就像是找到了一片没有潮汐、风力恒定的人工湖，虽然水面仍然有波纹（随机波动），但它的平均水位始终不变，波浪的起伏幅度也始终一致，且两个时刻的波浪关联度只取决于它们相隔的时间，而不取决于你具体在哪个时间点观察。

**一句话本质**：平稳性是指时间序列的统计规律不随时间的推移而改变。

## 6. 正式定义、核心公式、符号解释

在实际应用中，我们主要使用的是**弱平稳（Weak Stationarity）**（又称协方差平稳）。

### 核心定义（弱平稳的三大条件）
一个时间序列 $\{X_t\}$ 是弱平稳的，必须同时满足以下三个条件对所有时间 $t$ 成立：
1. **恒定均值**：$E[X_t] = \mu$ （常数）
2. **恒定方差**：$Var(X_t) = \sigma^2$ （常数且有限，独立于 $t$）
3. **自协方差只与时间间隔有关**：$Cov(X_t, X_{t-k}) = \gamma_k$ （只取决于时间间隔 $k$，与具体的起点 $t$ 无关）

### 符号解释表
| 符号 | 含义 | 备注 |
|---|---|---|
| $X_t$ | 时刻 $t$ 的随机变量 | 时间序列在 $t$ 时刻的观测值 |
| $\mu$ | 均值 (Mean) | 平稳序列的常数期望 |
| $\sigma^2$ | 方差 (Variance) | 平稳序列的常数波动率 |
| $k$ | 滞后期 (Lag) | 两个观测值之间的时间间隔 |
| $\gamma_k$ | 滞后 $k$ 阶自协方差 | 衡量序列过去与现在的线性相关性 |

## 7. 推导思路和思想来源
### 动机与“转念”
- **动机**：我们要计算随机过程的统计特征，但对于每个时间点 $t$，我们只有一个样本 $x_t$。用一个样本无法计算期望和方差。
- **转念（Ergodicity 遍历性）**：如果序列是平稳的，我们可以用“时间平均”来代替“空间平均（总体平均）”。只要均值和协方差不随时间改变，我们就可以把不同时刻的历史数据当成来自同一个分布的多次采样。这样，有限的历史数据就被激活了，可以用来估计未来的统计参数。

## 8. 例子：基础 → 中等 → 实际应用

### 例子 1：基础（手工计算）
- **题目**：判断时间序列 $X_t = 3 + \epsilon_t$ 是否弱平稳，其中 $\epsilon_t \sim \mathcal{N}(0, 1)$ 是独立的白噪声。
- **解题思路**：
  1. 均值：$E[X_t] = E[3 + \epsilon_t] = 3 + 0 = 3$（常数）。
  2. 方差：$Var(X_t) = Var(3 + \epsilon_t) = Var(\epsilon_t) = 1$（常数）。
  3. 协方差（对于 $k \neq 0$）：$Cov(X_t, X_{t-k}) = Cov(\epsilon_t, \epsilon_{t-k}) = 0$（只依赖 $k$，这里恒为0）。
- **结论**：满足弱平稳三大条件，该序列是平稳的。

### 例子 2：中等（识别非平稳性）
- **题目**：带有线性趋势的序列 $Y_t = 2t + \epsilon_t$ （其中 $\epsilon_t$ 是白噪声），它是平稳的吗？如何使其平稳？
- **解答**：
  - 计算均值：$E[Y_t] = 2t + E[\epsilon_t] = 2t$。均值依赖于时间 $t$，不断增长，因此**不平稳**。
  - 转换方法：进行一阶差分。$\Delta Y_t = Y_t - Y_{t-1} = (2t + \epsilon_t) - (2(t-1) + \epsilon_{t-1}) = 2 + \epsilon_t - \epsilon_{t-1}$。此时新序列的均值为 2，变成了平稳序列。

### 例子 3：实际应用（量化金融场景）
- **实际场景**：苹果公司（AAPL）的日收盘价 $P_t$ 是一个典型的非平稳序列（通常被视为随机游走 $P_t = P_{t-1} + \epsilon_t$），价格整体趋势可能向上，方差也随时间变大。
- **应用**：量化研究员不会直接对 $P_t$ 建模，而是计算**对数收益率** $r_t = \ln(P_t) - \ln(P_{t-1})$。对数收益率序列通常在 0 附近波动，方差在一定时期内相对稳定，满足弱平稳性假设，从而可以输入到 ARMA-GARCH 模型中预测未来的波动率。

## 9. 常见误区和易混概念
1. **误区 1：平稳意味着数据不能有波动**
   - *纠正*：平稳不代表没有波动，而是波动的“幅度（方差）”和“规律（协方差）”保持不变。白噪声剧烈震荡，但它是最完美的平稳序列。
2. **误区 2：严格平稳与弱平稳混淆**
   - *纠正*：严格平稳要求整个联合概率分布不随时间平移改变，条件极其苛刻。弱平稳只要求前二阶矩（均值、方差、协方差）不变，是实际工程中使用的标准。
3. **误区 3：忽视方差的时变性**
   - *纠正*：很多序列虽然均值围绕0波动（比如金融收益率），但在金融危机时波动率剧增（方差改变），这种“异方差性”破坏了弱平稳条件，需要 GARCH 模型处理。

## 12. 自测题：5 道

> [!question]- 1. 概念辨析 (基础)
> **题目**：以下哪一项会破坏时间序列的弱平稳性？
> A. 序列中存在随机波动
> B. 序列的值在 0 附近来回穿插
> C. 序列带有明显的周期性季节趋势
> D. 序列的均值恒定为 100
>
> **答案解析**：**C**。周期性季节趋势意味着在一年中的不同月份，序列的均值是不同的（比如冰淇淋销量夏天高冬天低），均值随时间变化，破坏了弱平稳性。A、B、D都是平稳序列可能具备的特征。

> [!question]- 2. 公式运用 (基础)
> **题目**：对于随机游走模型 $X_t = X_{t-1} + \epsilon_t$（其中 $X_0=0$，$\epsilon_t$ 为标准白噪声），计算其方差 $Var(X_t)$，并判断是否平稳。
>
> **答案解析**：展开可得 $X_t = \epsilon_1 + \epsilon_2 + \dots + \epsilon_t$。因为白噪声彼此独立，方差相加：$Var(X_t) = t \cdot Var(\epsilon) = t$。方差依赖于时间 $t$ 并随时间趋于无穷大，因此**不平稳**。

> [!question]- 3. 条件判断 (中等)
> **题目**：如果一个时间序列的均值为常数，方差为常数，那么它一定弱平稳吗？
>
> **答案解析**：不一定。弱平稳还需要第三个条件：自协方差 $Cov(X_t, X_{t-k})$ 仅与时间间隔 $k$ 有关。如果协方差除了依赖滞后 $k$，还依赖于具体时间 $t$，则依然不平稳。

> [!question]- 4. 变式/综合 (中等)
> **题目**：为什么量化金融中常常使用对数收益率而不是简单差分？（与平稳性有何关联）
>
> **答案解析**：股票价格通常呈现指数型增长，价格越高时波动的绝对幅度越大（即方差随价格上升而扩大）。直接差分 $\Delta P_t$ 的方差仍然不平稳。取对数 $\ln(P_t)$ 可以压缩随物价水平膨胀的方差，对数差分 $\ln(P_t) - \ln(P_{t-1})$ 能够得到一个均值和方差更为稳定的近似平稳序列。

> [!question]- 5. 开放/证明 (较难)
> **题目**：证明 MA(1) 过程 $X_t = \epsilon_t + \theta \epsilon_{t-1}$ （$\epsilon_t$ 是白噪声，方差为 $\sigma^2$）是弱平稳的。
>
> **答案解析**：
> 1. 均值：$E[X_t] = E[\epsilon_t] + \theta E[\epsilon_{t-1}] = 0$，恒定。
> 2. 方差：$Var(X_t) = Var(\epsilon_t + \theta \epsilon_{t-1}) = \sigma^2 + \theta^2 \sigma^2 = (1+\theta^2)\sigma^2$，恒定。
> 3. 自协方差：$k=1$ 时，$Cov(X_t, X_{t-1}) = E[(\epsilon_t + \theta \epsilon_{t-1})(\epsilon_{t-1} + \theta \epsilon_{t-2})] = \theta \sigma^2$。$k \ge 2$ 时，$Cov(X_t, X_{t-k}) = 0$。协方差只与滞后期 $k$ 有关。
> 三个条件均满足，因此 MA(1) 过程是弱平稳的。
