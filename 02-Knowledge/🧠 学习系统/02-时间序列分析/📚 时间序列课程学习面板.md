# 📚 时间序列课程学习面板

> 本页只负责回答三个问题：**现在学哪课、怎样算学会、卡住后去哪里。**课程内容从[[🧑‍🏫 时间序列教师版学习入口]]进入，参考卡只在主课讲解不足时打开。

## ⚡ 30 秒开始学习

```dataviewjs
const lessonPath = "02-Knowledge/🧠 学习系统/02-时间序列分析/01-课程";
const homeworkPath = "03-Projects/金融与时序/02-时间序列分析";

const lessons = dv.pages(`"${lessonPath}"`)
  .where(p => p.type === "study" && p.course === "时间序列分析" && p.lesson)
  .array()
  .sort((a, b) => Number(a.lesson) - Number(b.lesson));

const homeworks = dv.pages(`"${homeworkPath}"`)
  .where(p => p.type === "project" && p.course === "时间序列分析" && p.lesson)
  .array();

const next = lessons.find(p => Number(p.mastery ?? 0) < 2 || p.status !== "completed");

if (!next) {
  dv.paragraph("🎓 L01–L09 已全部达到过关标准。下一步完成综合项目并做一次闭卷复讲。");
} else {
  const hw = homeworks.find(p => Number(p.lesson) === Number(next.lesson));
  const row = [next.file.link, hw?.file.link ?? "未找到", `${next.mastery ?? 0}/3`, "完成课前诊断 → 主例题 → 当堂练习"];
  dv.table(["现在开始", "对应作业", "当前掌握", "本次目标"], Array.of(row));
}
```

> [!warning] 若上表显示的并非你正在学习的课
> 不要改查询代码。把已经真正过关的课程设置为 `status: completed` 且 `mastery: 2` 或 `3`；没有过关的课程保持 `learning/planned`。

## 🧭 45–90 分钟单次学习流程

### 开始前 5 分钟

1. 只打开面板给出的下一课。
2. 不看答案完成“课前诊断”。
3. 写一句：`我预计最容易错在：______`。

### 学习阶段 25–45 分钟

1. 先算具体数字，再读一般公式。
2. 运行代码前写下预期图形或输出。
3. 每读完一节，关闭正文，用自己的话讲 30 秒。
4. 只有主课解释不够时才打开参考卡，不沿链接无限跳转。

### 输出阶段 15–30 分钟

1. 闭卷完成当堂练习。
2. 至少完成对应 HW 的 A、B 两级；完整学习日继续完成后续部分。
3. 对照折叠答案，用“概念错、计算错、条件漏、实现错”标记错误类型。
4. 按下面的掌握量表更新课程 frontmatter。

## 🎚️ 掌握度不是心情分

| mastery | 可观察证据 | 下一步 |
|---:|---|---|
| 0 | 尚未学习，或只能认出名词 | 从主课课前诊断开始 |
| 1 | 跟着例子能做，关闭笔记后不能独立完成 | 重算主例题，再做一道变式 |
| 2 | 能闭卷解释、计算并完成核心作业 | 可以进入下一课 |
| 3 | 能讲给别人、处理变式，并解释方法边界 | 进入综合项目或制作少量 Anki 卡 |

一课只有同时满足以下条件才设置 `status: completed`：

- [ ] `mastery >= 2`
- [ ] 能闭卷回答主课“必答问题”
- [ ] 主课过关清单全部完成
- [ ] 对应作业核心部分已完成并核对
- [ ] 未解决错误已经进入 Review，而不是被遗忘

## 🧯 错题如何回流

错误不是在作业末尾写一个正确答案，而是执行以下闭环：

1. 回到出错主课，将 `flow` 改为 `review`，增加：

```yaml
weak: true
weak_since: YYYY-MM-DD
```

2. 使用[[🧯 错题漏洞笔记模板]]记录：错误答案、错误原因、最小修复和一道变式。
3. 24 小时后闭卷重做；仍错则缩小到前置知识，不继续堆新题。
4. 能独立讲解并通过变式后，主课恢复 `flow: knowledge`，删除或关闭 `weak`。
5. 所有待修项目会进入[[04-🔁 Review]]的薄弱点队列。

## 🗓️ 建议节奏

不要连续阅读九课。默认采用“新课—练习—回忆”的节奏：

| 学习日 | 主任务 | 次日开始前 |
|---|---|---|
| 第 1 天 | L01 + HW01 | 闭卷解释平稳与差分 |
| 第 2 天 | L02 + HW02 | 手画白噪声/AR/MA 的相关图预期 |
| 第 3 天 | L03 + HW03 | 手算 AR(1) 两步预测 |
| 第 4 天 | L04 + HW04 | 对比有限冲击与持续记忆 |
| 第 5 天 | L05 + HW05 | 从水平到差分再还原预测 |
| 第 6 天 | L06 + HW06 | 手算季节差分与交叉滞后 |
| 第 7 天 | 只复习 L01–L06 | 不开新课，修复所有 mastery 1 |
| 第 8 天 | L07 + HW07 | 冻结候选并解释 AICc |
| 第 9 天 | L08 + HW08 | 读懂残差图和 Ljung–Box |
| 第 10 天 | L09 + HW09 | 完成滚动评估协议 |
| 第 11–14 天 | 综合项目 | 写报告、复现、闭卷答辩 |

时间不足时缩小当天作业范围，不删除闭卷回忆和错误回流。
