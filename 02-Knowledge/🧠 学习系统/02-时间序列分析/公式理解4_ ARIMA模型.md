# 公式理解4: ARIMA模型

## 1. 优先级判断与理由
- **优先级**：A 级核心模型
- **理由**：ARIMA 是时间序列分析中“03-经典模型层”的绝对霸主与基石。它不仅是金融计量经济学的标配，更是后续学习高级模型（如 SARIMA、GARCH 甚至深度学习时序模型）的必需参照物。不吃透它，时间序列的特征工程无从谈起。

## 2. 知识点解决什么问题？
> **我们遇到了什么麻烦？**

在现实生活中，大多数时间序列数据（如股票价格、宏观经济指标）都是**非平稳**的——它们有明显的趋势或周期，均值和方差随时间四处飘移。传统的纯自回归 (AR) 或纯移动平均 (MA) 模型一遇到这种数据就会彻底失效，预测结果离谱。我们急需一个“一体化”的框架，能先通过数学手段把数据“拉平”成平稳序列，再同时捕捉数据本身的惯性和随机冲击的余波。

## 3. 为什么它重要？它有什么用？
- **大图景位置**：它是整个经典时间序列预测理论的集大成者，连接了数据预处理（差分）与核心建模（AR、MA）。
- **实际应用**：在量化金融中，常用于基准收益率预测、高频交易的微观结构建模以及宏观经济因子的超前预测。
- **不可替代性**：在数据量较小、需要极强白盒可解释性的场景（如央行政策制定、风控报告），ARIMA 的说服力远超黑盒深度学习模型。

## 4. 学它之前需要哪些前置知识？
### 最小必要背景 (200 字以内)
1. **平稳性 (Stationarity)**：序列的均值、方差不随时间改变，且协方差只与时间间隔有关。
2. **白噪声 (White Noise)**：均值为 0、方差恒定且完全不相关的随机序列。
3. **差分 (Differencing)**：当前时刻的值减去上一时刻的值，用于消除趋势。

## 5. 用直觉语言解释它
«“这东西其实就像……”»

这就像你在逆水行舟时掌舵。
- **I (差分)**：水流本身有一个向东的稳定推力（趋势），我们首先要计算并抵消掉这个整体的位移，让我们只专注于局部的波动。
- **AR (自回归)**：船体本身的巨大惯性。你昨天往左打了一把方向，今天船还会由于惯性继续往左偏。
- **MA (移动平均)**：一阵突如其来的随机阵风（误差冲击）。风吹过之后，水面的余波还会在这几分钟内对船产生摇晃。

**直觉本质**：ARIMA 模型就是用“差分”抹平宏观趋势，用“惯性”拟合过去自身的影响，用“余波”修正历史误差的综合预测器。

## 6. 正式定义、核心公式、符号解释

### 核心公式
ARIMA(p, d, q) 模型的公式，其中 $y_t$ 是经过 $d$ 阶差分后的平稳序列（通常记作 $y'_t$ 或 $\Delta^d y_t$）：

$$
y'_t = c + \phi_1 y'_{t-1} + \phi_2 y'_{t-2} + \dots + \phi_p y'_{t-p} + \theta_1 \epsilon_{t-1} + \theta_2 \epsilon_{t-2} + \dots + \theta_q \epsilon_{t-q} + \epsilon_t
$$

或者用滞后算子 (Lag Operator) $L$ 表示为更紧凑的形式：
$$
\left( 1 - \sum_{i=1}^p \phi_i L^i \right) (1-L)^d y_t = c + \left( 1 + \sum_{j=1}^q \theta_j L^j \right) \epsilon_t
$$

### 符号解释表
| 符号 | 含义 | 备注 |
|---|---|---|
| $p$ | 自回归 (AR) 阶数 | 依赖过去多少个时刻的值 |
| $d$ | 差分 (I) 阶数 | 使得序列平稳所需的最少差分次数 |
| $q$ | 移动平均 (MA) 阶数 | 依赖过去多少个时刻的预测误差 |
| $y'_t$ | $d$ 阶差分后的当前值 | 若 $d=1$，则 $y'_t = y_t - y_{t-1}$ |
| $c$ | 常数项/漂移项 | 序列的长期基线水平 |
| $\phi_i$ | AR 参数 | 衡量过去第 $i$ 步对当前步的影响权重 |
| $\theta_j$ | MA 参数 | 衡量过去第 $j$ 步误差对当前步的影响权重 |
| $\epsilon_t$ | 白噪声误差项 | 当前时刻不可预测的随机冲击 |

## 7. 推导思路和思想来源
### 动机与“转念”
时间序列分析的初衷是找到 $y_t = f(t)$。但时间往往不是原因，过去发生的事情才是原因。
- **演化步骤 1**：发现 $y_t$ 与它自己过去的滞后项高度相关，于是提出 AR(p)。
- **演化步骤 2**：发现真实世界不仅有历史数值惯性，还会受到随机突发事件（冲击）的余波影响，于是加入 MA(q) 拟合误差的滞后。组合成了 ARMA(p, q)。
- **终极转念**：ARMA 只能处理平稳数据。面对非平稳的真实数据怎么办？我们不需要找更复杂的非线性方程，只需要对原序列进行 $d$ 次差分，直到它平稳为止，再套用 ARMA。这就诞生了 ARIMA(p, d, q)。

## 8. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手工计算 (ARIMA(1,0,0) 即 AR(1))
- **情景**：设某城市的日均温度距平值服从 AR(1) 模型，$y_t = 0.5 y_{t-1} + \epsilon_t$。已知昨天 $y_0 = 4$ 度，今天的冲击 $\epsilon_1 = 1$，明天的预期冲击为 0。
- **计算**：
  - 今天 ($t=1$)：$y_1 = 0.5 \times 4 + 1 = 3$ 度。
  - 明天 ($t=2$)：预期 $y_2 = 0.5 \times y_1 + 0 = 0.5 \times 3 = 1.5$ 度。
- **结论**：序列具有均值回归特性，逐渐衰减趋向于 0。

### 例子 2：中等案例 (ARIMA 的定阶过程)
- **情景**：对某季度销量数据进行建模。
- **步骤**：
  1. 发现数据有上升趋势，做一阶差分（$d=1$）。
  2. 对差分后的数据画 ACF 和 PACF 图。
  3. 发现 PACF 在滞后 2 阶后截尾（暗示 $p=2$），ACF 拖尾。
  4. 最终确定使用 ARIMA(2,1,0) 模型进行参数估计。

### 例子 3：量化金融实际应用 (配对交易中的均值回归)
- **场景**：量化基金在寻找统计套利机会。
- **操作**：找两支高度相关的股票（如可口可乐和百事可乐），计算它们价格的比值或价差序列。发现价差序列非平稳，但建立 ARIMA 模型时发现它的残差是白噪声。当实盘中最新价差严重偏离 ARIMA 预测的一个标准差时，策略判断发生了“非理性偏离”，自动做多被低估的一方，做空被高估的一方，赚取均值回归的利润。

## 9. 常见误区和易混概念
1. **差分过滥（过度差分）**：
   - *误区*：以为 $d$ 越大越平稳，不管三七二十一先差分 3 次。
   - *纠正*：差分会丢失长期的内存信息，且引入人造噪声。一般 $d$ 极少超过 2。
2. **混淆 ACF 和 PACF 的截尾特性**：
   - *误区*：看图定阶时，把 AR 和 MA 的图谱记反。
   - *纠正*：口诀：“AR 看 PACF 截尾，MA 看 ACF 截尾”。
3. **强行在强季节性数据上只用 ARIMA**：
   - *误区*：对月度零售额（每年 11 月飙升）直接用 ARIMA(p,d,q)。
   - *纠正*：标准 ARIMA 无法处理季节性周期，必须升级使用包含季节参数的 SARIMA 模型。

## 12. 自测题：5 道

> [!question]- 1. 基础题：ARIMA 中的 "I" 代表什么？它的作用是？
> **答案解析**：I 代表 Integrated（差分整合）。作用是将非平稳的时间序列通过差分操作转化为平稳序列，以便后续的 ARMA 建模。

> [!question]- 2. 基础题：如果一个时间序列的 ACF 呈指数衰减（拖尾），PACF 在阶数 p 之后骤降为 0（截尾），它适合什么模型？
> **答案解析**：适合 AR(p) 模型。PACF 截尾是自回归模型 (AR) 的显著特征。

> [!question]- 3. 中等题：模型 ARIMA(0, 1, 1) 的预测公式可以展开为什么形式？
> **答案解析**：设原始序列为 $y_t$，差分后为 $y'_t = y_t - y_{t-1}$。该模型是差分后的 MA(1)，即 $y_t - y_{t-1} = c + \epsilon_t + \theta_1 \epsilon_{t-1}$。移项得预测公式：$y_t = y_{t-1} + c + \epsilon_t + \theta_1 \epsilon_{t-1}$。相当于随机游走加上误差项的移动平均。

> [!question]- 4. 综合题：用程序进行 ARIMA 建模时，如果得到的残差序列存在显著的自相关性，说明了什么？
> **答案解析**：说明模型没有充分提取数据中的信息，残差不是白噪声，仍有规律可循。通常需要重新定阶，可能需要增加 $p$ 或 $q$ 的值，或者考虑其他外部变量。

> [!question]- 5. 挑战题：为什么在量化交易中，极少直接对股票绝对价格使用 ARIMA 预测？
> **答案解析**：1) 股票价格通常是一阶单整的，一阶差分后（即收益率）接近白噪声，此时 ARIMA 退化，难以产生有用的超前预测；2) 金融收益率序列具有典型的“波动率聚集”现象（方差不齐），这违背了 ARIMA 残差方差恒定的假设，因此常结合 GARCH 模型处理。
