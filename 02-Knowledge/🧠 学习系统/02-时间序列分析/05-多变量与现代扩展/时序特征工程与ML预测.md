# 时序特征工程与 ML 预测

---

## 0. 学习边界

- **类别**：**B 类（常用工具）**
- **判断理由**：Capstone 第四模型（ML）；把树模型/神经网络接到时序上的关键在"特征不泄漏"。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：XGBoost/LightGBM 不懂"时间"，需要把时序信息变成**表格特征**（滞后、滚动统计、日历、外生），并保证特征在预测时可用。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：ML 预测是经典模型的补充（非线性、多外生）；泄漏控制决定成败。
- **实际应用场景**：需求预测竞赛（M5）、风控时序。
- **高频题型/任务**：滞后/滚动特征设计；时间感知切分；特征在 $t-h$ 前可用。

---

## 3. 学它之前需要哪些前置知识？

1. **[[滚动回测与预测区间]]**：评估协议。
2. **[[动态回归与ARIMAX]]**：外生思想。

---

## 4. 用直觉语言解释它

> «"给'不懂时间'的模型戴上'时间眼镜'：把过去 7 天、上周同期、节假日等'翻译'成普通表格列。"»

- **直觉类比/几何图像**：特征 = 时间信息翻译官。
- **为什么很自然**：监督学习只需 $(X,y)$，特征工程就是构造 $X$。
- **一句话直觉本质**：**时序 ML = 把时序翻译成特征 + 时间感知的验证。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

特征族：1) 滞后 $\{y_{t-1},\ldots,y_{t-L}\}$；2) 滚动统计（均值/标准差/最小/最大，窗口 $w$）；3) 日历（周几/月/节假日/距节假日天数）；4) 外生（价格、天气）；5) 目标编码（同期历史均值）。

### 2. 核心公式

滚动均值：$\text{mean}_w(t)=\frac{1}{w}\sum_{s=1}^{w}y_{t-s}$；目标：$\hat y_{t+h}$ 用 $X_t$（只含 $t$ 及以前信息）预测。

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $L,w$ | 滞后数/窗口 | 超参 |
| $h$ | 预测步长 | 目标对齐 |
| $X_t$ | 特征向量 | 必须 $t-h$ 前可得 |

### 4. 常见变体与适用条件

- **适用条件**：样本量大、外生丰富、非线性关系时优于经典模型。
- **限制条件**：小样本/短序列不如 ETS/ARIMA；无法天然给出区间（需分位数回归/集成）。

---

## 6. 推导思路和思想来源

- **最初困难**：监督模型无法直接消费序列。
- **直接方法局限**：ARIMA 线性假设限制表达力。
- **关键"转念"**：把"预测"重构为"监督回归"：在预测原点 $t$，用信息集 $\mathcal F_t$ 中可得的特征 $X_t$ 预测 $y_{t+h}$，滑动构造训练样本对 $(X_t,y_{t+h})$。
- **推导主线与动机**：特征必须属于预测原点的信息集 $\mathcal F_t$，不能使用 $t$ 之后才产生或发布的数据；验证必须采用时间切分与滚动回测。
- **为什么自然得到此结论**：监督学习框架 + 时序约束 = 平移问题。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：在预测原点 $t$ 预测周销量 $y_{t+7}$，特征 $y_t$、$y_{t-1}$ 和 $y_{t-7}$ 是否合法？
- **解题思路**：先写清预测发生的时间。若 $y_t$ 在预测时已经完整观测，三者都属于 $\mathcal F_t$，均可使用；若业务要求在 $t$ 期结束前预测，则 $y_t$ 尚未完整形成，只能使用当时确实已发布的数据。
- **最终答案**：合法性由预测原点的信息可得性决定，而不是机械要求“特征与目标之间至少间隔 $h$”。训练样本必须按同一业务时钟重建信息集。
- **易错点**：把目标时点 $t+7$ 当成预测原点，或忽略报表发布延迟、修订与当期数据是否已经闭合。
- **🤔 追问**：滚动均值窗口 $w=7$ 的"同期去年"特征呢？（季节捕捉）

### 例子 2：中等例子（条件判断与多步推理）

- **题目**：为什么"先全样本标准化再切分"是泄漏？
- **完整解答**：均值/方差用了未来数据；必须只在训练段拟合 scaler，验证/测试段用训练参数转换——这是特征级泄漏的典型坑。

### 例子 3：实际应用例子（真实场景/代码）

- **实际价值与转化**：`sktime`/`tsfresh` 生成特征 + LightGBM；生产协议：时间感知切分 + 滚动回测 + 与 ETS/ARIMA 基线对比（赢过基线才有价值）。

---

## 8. 常见误区和易混概念

### 误区 1："特征越多模型越准"
- **错误直觉**：堆特征。
- **为什么错**：滞后多=共线性；滚动窗口多=冗余；且特征需在部署时逐期更新（工程成本）。
- **正确理解**：特征选择 + 特征重要性诊断。

### 概念对比表

| 概念 | 输入 | 适用 |
| :--- | :--- | :--- |
| 经典 ARIMA | 序列本身 | 线性自相关 |
| ML 预测 | 特征表 | 非线性+外生 |
| 深度学习 | 序列窗口 | 大样本模式 |

### 题目与解析

#### 1. 哪类特征能捕捉季节性？
> [!question]- 答案解析
> - **答案**：周期滞后（$y_{t-m}$）+ 日历特征 + 同期历史均值。
> - **解析**：周期信息。
> - **易错原因**：只加短滞后。

#### 2. 滚动标准差的作用？
> [!question]- 答案解析
> - **答案**：捕捉波动率（条件方差代理）。
> - **解析**：二阶矩特征。
> - **易错原因**：以为只去噪。

#### 3. 预测 $y_{t+1}$ 时把 $y_{t+1}$ 的真实值当特征？
> [!question]- 答案解析
> - **答案**：严重泄漏。
> - **解析**：部署时不存在。
> - **易错原因**：训练时不自查。

#### 4. 在预测原点 $t$ 直接预测 $y_{t+28}$，最晚可以使用哪个目标滞后？
> [!question]- 答案解析
> - **答案**：若 $y_t$ 在预测时已经完整观测，最晚可以使用 $y_t$；也可以使用 $y_{t-1},y_{t-2},\ldots$。不需要机械留出 28 期空隙。
> - **解析**：目标是 $y_{t+28}$，但预测原点仍是 $t$。合法性取决于特征是否属于当时的信息集 $\mathcal F_t$。只有在业务时钟规定 $y_t$ 尚未闭合时，才需要退回到最后一个实际可得的滞后。
> - **易错原因**：把 horizon 28 误当成“所有特征必须滞后至少 28 期”，混淆目标时点、预测原点与数据发布时间。

#### 5. ML 预测的验收标准？
> [!question]- 答案解析
> - **答案**：滚动回测赢过 ETS/ARIMA 基线 + 残差白噪声 + 区间覆盖率达标。
> - **解析**：无基线对比无意义。
> - **易错原因**：只报训练精度。

## 🃏 Anki 卡片

- 时序 ML 的三大类特征？::滞后特征（过去值 $y_{t-k}$）、滚动统计（移动平均/标准差/极值）、时间特征（小时/星期/节假日/距上次事件）
- 为什么"时间不是特征"？::把时间戳本身当连续特征会让模型外推从未见过的未来时刻；应转为周期编码（sin/cos）或类别特征
- 递归多步 vs 直接多步预测？::递归：用预测值回填当特征（误差累积）；直接：为每个步长单独训练模型（无累积但模型多、数据利用不充分）
- 特征工程中最容易犯的前视偏差？::滚动统计/滞后特征用到预测时刻之后的信息（如用 t+1 的均值预测 t），或标准化时用了全样本统计量；必须只用训练窗口内数据
