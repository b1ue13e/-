# 时间序列分析｜矩阵运算与线性模型最小桥接

## 本课程需要什么

只要求读懂矩阵维度、矩阵乘向量、转置以及“多变量线性组合”。完整线性代数证明留给高等代数课程。

## 核心规则

若 $A\in\mathbb R^{m\times n}$、$x\in\mathbb R^n$，则 $Ax\in\mathbb R^m$，第 $i$ 个元素为

$$
(Ax)_i=\sum_{j=1}^n A_{ij}x_j.
$$

线性模型写成

$$
y=X\beta+\varepsilon,
$$

其中 $X$ 的每一行是一条观测，每一列是一个特征；$\beta$ 是系数向量。VAR 模型只是让响应和系数都变成向量/矩阵，并加入滞后。

## 手算例子

$$
A=\begin{bmatrix}1&2\\3&4\end{bmatrix},
\quad
x=\begin{bmatrix}5\\6\end{bmatrix}
\quad\Rightarrow\quad
Ax=\begin{bmatrix}17\\39\end{bmatrix}.
$$

第一行与向量做点积：$1\times5+2\times6=17$；第二行同理得到 39。

## 最小可运行例子

```python
import numpy as np

design = np.array([[1.0, 2.0], [3.0, 4.0]])
coefficients = np.array([5.0, 6.0])
prediction = design @ coefficients

assert design.shape == (2, 2)
assert prediction.shape == (2,)
assert np.allclose(prediction, [17.0, 39.0])
print(prediction)
```

## 常见错误

1. 只看元素个数，不检查内维是否匹配。
2. 把逐元素乘法 `*` 与矩阵乘法 `@` 混淆。
3. 看到可逆公式就机械求逆；数值实现通常应解线性方程而非显式求逆。
4. 把回归系数直接解释为因果效应，忽略数据生成机制和识别条件。
