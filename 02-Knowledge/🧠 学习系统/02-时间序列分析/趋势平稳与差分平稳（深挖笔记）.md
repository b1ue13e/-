> 主卡：[[趋势平稳与差分平稳]]｜本卡为深挖细节版，主线索引请走主卡。

> **真正的核心区别是：**
>
> **趋势平稳 TS：冲击是暂时的，序列会围绕一条确定性趋势线回归。**
> **差分平稳 DS：冲击是永久的，序列本身没有固定的长期趋势线，必须差分后才平稳。**
>
> 这两个概念经常被混，因为它们看起来都"有趋势"，但背后的随机过程完全不同。

---

## 0. 先判断它值不值得深挖

**A 类：核心概念，必须深挖！**

**理由：**
趋势平稳（TS）和差分平稳（DS）的区分是时间序列分析中最重要也最容易混淆的概念之一。混淆两者会导致完全错误的处理策略——对 TS 做差分会破坏趋势信息，对 DS 去趋势则无法消除非平稳性。Nelson 和 Plosser（1982）的著名论文正是围绕这个区分展开的，它改变了宏观经济学对时间序列建模的思维方式。

---

## 1. 这个知识点解决什么问题？

**我们遇到了什么麻烦？**

你拿到一个向上趋势的序列（如 GDP、股价），想让它变平稳以便建模。但有两种完全不同的"病因"：
- **病因 A**：序列只是"围绕着一条固定趋势线上下波动"——去掉趋势就平稳了
- **病因 B**：序列"没有固定趋势线，每次冲击都永久改变路径"——必须差分才平稳

**以前的方法在哪里卡住？**

初学者最常见的错误：
- 看到非平稳就条件反射做差分 → 可能把 TS 序列过度差分
- 看到趋势就回归去趋势 → 对 DS 序列完全无效

**为什么必须区分 TS 和 DS？**

因为两种类型的"处理方式"和"经济含义"完全不同：
- TS：冲击是暂时的，长期会回到趋势
- DS：冲击是永久的，长期路径被改写

## 4. 用直觉语言解释它

**生活类比：两种不同类型的"长期目标"**

想象你在减肥：

- **趋势平稳（TS）**：你设定了一个目标体重 70kg（确定性趋势）。某天吃多了（冲击），体重暂时偏离，但你过几天会通过控制饮食和运动回到 70kg 附近。**冲击是暂时的，你有回归力量。**

- **差分平稳（DS）**：你没有固定目标，减肥策略是"今天比昨天少吃一点"。某天吃多了（冲击），你的体重基准被永久抬高了一点，之后的所有体重都是在这个新基准上继续变化。**冲击是永久的，没有回归力量。**

**关键区别**：
- TS：偏离后**会回来**（围绕固定趋势线）
- DS：偏离后**不回来**（路径被永久改写）

**为什么这个想法很自然？**

人生中很多事情都有这两种模式：
- TS 模式：考试成绩围绕你的真实水平波动
- DS 模式：知识存量只增不减（当然现实中会遗忘，但近似）

**一句话总结它的直觉本质：**
> **TS = 有固定跑道，偏离后会回归；DS = 没有跑道，每一步都在重新定义起点。**

## 5. 正式定义、核心公式、符号解释

### 5.1 趋势平稳 (Trend Stationary, TS)

$$y_t = \alpha + \beta t + u_t$$

其中 $u_t$ 是平稳过程（如 $u_t = \rho u_{t-1} + \varepsilon_t$，$|\rho| < 1$）。

**关键特征**：
- 趋势项 $\alpha + \beta t$ 是**确定性的**
- 去掉趋势后：$y_t - \alpha - \beta t = u_t \sim I(0)$
- 冲击影响：$\rho^k \varepsilon_t \to 0$（$k \to \infty$）

### 5.2 差分平稳 (Difference Stationary, DS)

最典型的是随机游走：
$$y_t = y_{t-1} + \varepsilon_t$$

或带漂移：
$$y_t = \mu + y_{t-1} + \varepsilon_t$$

展开：
$$y_t = y_0 + \mu t + \sum_{i=1}^{t}\varepsilon_i$$

**关键特征**：
- 包含**随机趋势** $\sum_{i=1}^t \varepsilon_i$
- 一阶差分后平稳：$\Delta y_t = \mu + \varepsilon_t \sim I(0)$
- 冲击影响：永久保留

### 5.3 $I(0)$ 和 $I(1)$

| 记号 | 含义 |
|------|------|
| $I(0)$ | 本身平稳 |
| $I(1)$ | 一阶差分后平稳 |
| $I(2)$ | 二阶差分后平稳 |

- TS：去趋势后 $I(0)$
- DS：差分后 $I(0)$，本身 $I(1)$

### 5.4 符号说明表

| 符号 | 含义 | 备注 |
|------|------|------|
| $\alpha + \beta t$ | 确定性趋势 | TS 的特征 |
| $\sum \varepsilon_i$ | 随机趋势 | DS 的特征 |
| $u_t$ | 平稳扰动 | TS 中围绕趋势的波动 |
| $\mu$ | 漂移项 | DS 中的确定性增长成分 |
| $I(d)$ | $d$ 阶单整 | 差分 $d$ 次后平稳 |

## 6. 推导思路和思想来源

**我们一开始想解决什么困难？**

很多序列"看起来有趋势"，但趋势的来源完全不同。需要区分"确定性趋势"和"随机趋势"。

**直接方法为什么不够？**

肉眼无法区分：
- $y_t = 10 + 0.5t + u_t$（TS）
- $y_t = 0.5 + y_{t-1} + \varepsilon_t$（DS）

两者画出来时序图都可能向上走。

**关键的"转念"是什么？**

> **看冲击的长期影响：会消失（TS）还是永久保留（DS）？**

**推导主线**

TS：$y_t = \alpha + \beta t + u_t$，$u_t = \rho u_{t-1} + \varepsilon_t$
- 冲击 $\varepsilon_t$ 对未来的影响：$\rho^k \varepsilon_t$
- 因为 $|\rho| < 1$，$\rho^k \to 0$，冲击逐渐消失

DS：$y_t = y_{t-1} + \varepsilon_t$
- 冲击 $\varepsilon_t$ 对未来的影响：永久保留在 $y_{t+1}, y_{t+2}, \dots$ 中
- $y_{t+k} = y_t + \varepsilon_{t+1} + \dots + \varepsilon_{t+k} + \varepsilon_t$（已累积）

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础对比

**题目**：判断以下序列是 TS 还是 DS，并说明处理方式。
(a) $y_t = 5 + 2t + \varepsilon_t$
(b) $y_t = y_{t-1} + 2 + \varepsilon_t$

**解题思路**：看趋势来源和冲击影响。

**关键步骤**：

(a) $y_t = 5 + 2t + \varepsilon_t$
- 趋势项 $5 + 2t$ 是确定性的
- $\varepsilon_t$ 是白噪声，冲击只影响当期
- **TS**。处理方式：**去趋势**（回归后取残差）

(b) $y_t = y_{t-1} + 2 + \varepsilon_t$
- 展开：$y_t = y_0 + 2t + \sum_{i=1}^t \varepsilon_i$
- 包含随机趋势 $\sum \varepsilon_i$
- **DS**。处理方式：**差分**（$\Delta y_t = 2 + \varepsilon_t$，平稳）

**容易错的地方**：两者都有 $+2t$ 的确定性成分，但 (b) 还有随机趋势。

---

### 例子 2：中等综合题（错误处理的后果）

**题目**：设 $y_t = 10 + 0.5t + u_t$，$u_t = 0.6u_{t-1} + \varepsilon_t$（TS 序列）。
(a) 若错误地做一阶差分，得到什么？
(b) 说明为什么这是错误的。

**解答过程**：

(a) $\Delta y_t = y_t - y_{t-1} = [10 + 0.5t + u_t] - [10 + 0.5(t-1) + u_{t-1}]$
$$= 0.5 + u_t - u_{t-1} = 0.5 + \Delta u_t$$

$u_t = 0.6u_{t-1} + \varepsilon_t$，所以 $\Delta u_t = u_t - u_{t-1} = -0.4u_{t-1} + \varepsilon_t$

$\Delta y_t = 0.5 - 0.4u_{t-1} + \varepsilon_t$

(b) 虽然 $\Delta y_t$ 可能也是平稳的，但：
- 破坏了清晰的确定性趋势结构
- 引入了不必要的 MA 成分（$\Delta u_t$）
- 长期趋势斜率信息被削弱
- 模型解释性变差

**结论**：TS 序列应去趋势，不应差分。

---

### 例子 3：实际应用（GDP 的 TS vs DS 之争）

**背景**：宏观经济学中一个长期争论——GDP 是 TS 还是 DS？

- **TS 观点（传统）**：GDP 围绕长期趋势（由技术、资本积累决定）波动，经济周期是暂时偏离。冲击（如货币政策）长期无效。
- **DS 观点（Nelson-Plosser, 1982）**：GDP 是 DS，技术冲击有永久影响。经济衰退的产出损失可能是永久性的。

**实际价值**：
- 如果 GDP 是 TS：凯恩斯主义的逆周期政策有效
- 如果 GDP 是 DS：真实经济周期理论（RBC）更有说服力，政策长期效果有限

**实证结果**：大多数宏观序列（GDP、消费、投资）的 ADF 检验不拒绝单位根，支持 DS 观点。但争论仍在继续。

## 8. 常见误区和易混概念

### 误区 1："看到趋势就差分"

**错误直觉**：所有有趋势的序列都应该差分。

**为什么错**：TS 序列差分会破坏趋势信息并引入 MA 结构。

**正确理解**：
- 先判断是 TS 还是 DS
- TS → 去趋势
- DS → 差分

---

### 误区 2："去趋势对所有序列都有效"

**错误直觉**：回归个趋势线就完事了。

**为什么错**：DS 序列的偏离不是短期波动，而是随机趋势的累积。去趋势后残差仍不平稳。

**正确理解**：对 DS 序列做去趋势回归是伪回归的温床。

---

### 误区 3：混淆 $I(1)$ 和 TS

**错误直觉**：TS 也是 $I(1)$。

**为什么错**：TS 序列去趋势后是 $I(0)$，不是 $I(1)$。只有 DS 序列才是 $I(1)$。

**正确理解**：
- TS：去趋势 $\to I(0)$
- DS：差分 $\to I(0)$，本身 $I(1)$

---

### 易混概念对比表

| 对比点 | 趋势平稳 TS | 差分平稳 DS |
|--------|------------|------------|
| 英文 | Trend Stationary | Difference Stationary |
| 趋势来源 | 确定性趋势 | 随机趋势 |
| 典型形式 | $y_t = \alpha + \beta t + u_t$ | $y_t = y_{t-1} + \mu + \varepsilon_t$ |
| 处理方式 | 去趋势 | 差分 |
| 冲击影响 | 暂时影响 | 永久影响 |
| 长期路径 | 回到固定趋势线 | 路径被冲击永久改写 |
| 是否有单位根 | 通常没有 | 通常有 |
| 单整阶数 | 去趋势后 $I(0)$ | 本身 $I(1)$ |

### 题 1：概念辨析

**题目**：趋势平稳和差分平稳最根本的区别是：
A. 一个有序列，一个没有
B. 趋势是确定性的还是随机的
C. 一个需要差分，一个不需要
D. 一个用于经济，一个用于金融

> [!question]- 答案解析
> **答案：B**
> **解析**：TS 的趋势是确定性的（$\alpha + \beta t$），DS 的趋势是随机的（$\sum \varepsilon_i$）。这是最本质的区别。A 错因为两者都有序列；C 是处理方式的区别，不是本质；D 无意义。
> **最可能做错的原因**：把处理方式（差分 vs 去趋势）当作本质区别。
> **对应误区**：误区 3
> **标签**：#时间序列分析 #趋势平稳 #差分平稳 #概念辨析

### 题 2：公式运用

**题目**：$y_t = 3 + 0.8t + u_t$，$u_t = 0.4u_{t-1} + \varepsilon_t$。这是 TS 还是 DS？

> [!question]- 答案解析
> **答案：TS**
> **解析**：存在确定性趋势 $3 + 0.8t$，扰动项 $u_t$ 是平稳 AR(1)（$|0.4| < 1$）。去趋势后 $u_t$ 平稳。没有随机趋势累积项。
> **最可能做错的原因**：看到有 $t$ 就以为是 DS，或因为 $u_t$ 是自回归的就以为是单位根。
> **对应误区**：误区 3
> **标签**：#时间序列分析 #趋势平稳 #模型识别

### 题 3：条件判断

**题目**：某序列经 ADF 检验（带趋势项）拒绝单位根。最合适的下一步是：
A. 直接做一阶差分
B. 对序列去趋势，再检验残差
C. 建立 ARIMA 模型
D. 判定为白噪声

> [!question]- 答案解析
> **答案：B**
> **解析**：带趋势项的 ADF 拒绝单位根，说明序列更像 TS。应去趋势后检验残差是否平稳。A 错误（TS 不应差分）；C 可能可行但不是下一步；D 与 ADF 结果无关。
> **最可能做错的原因**：看到 ADF 拒绝就以为可以直接建模，忘记 TS 需要先去趋势。
> **对应误区**：误区 1
> **标签**：#时间序列分析 #趋势平稳 #ADF #处理策略

### 题 4：变式/综合

**题目**：对 TS 序列 $y_t = 10 + 0.5t + u_t$ 错误地做一阶差分，得到 $\Delta y_t = 0.5 + \Delta u_t$。以下说法正确的是：
A. 差分后一定不平稳
B. 差分后破坏了原来的 AR 结构
C. $\Delta u_t$ 是白噪声
D. 去趋势比差分更好

> [!question]- 答案解析
> **答案：D**
> **解析**：A 错，差分后可能仍平稳；B 表述不清；C 错，$\Delta u_t$ 一般不是白噪声（如 $u_t$ 是 AR(1)，则 $\Delta u_t$ 有 MA 结构）；D 正确，TS 序列应去趋势而非差分。
> **最可能做错的原因**：误以为差分后的序列一定有问题，或混淆了 $\Delta u_t$ 的性质。
> **对应误区**：误区 1

### 题 5：开放/证明

**题目**：设 $y_t = \alpha + \beta t + u_t$，其中 $u_t = \rho u_{t-1} + \varepsilon_t$，$|\rho| < 1$，$\varepsilon_t \sim WN(0, \sigma^2)$。证明：一个冲击 $\varepsilon_t$ 对未来的影响为 $\rho^k \varepsilon_t$（$k$ 期后），并说明为什么当 $k \to \infty$ 时影响消失。

> [!question]- 答案解析
> **答案**：
> 由 $u_t = \rho u_{t-1} + \varepsilon_t$，递推得：
> $$u_{t+k} = \rho^k u_t + \rho^{k-1}\varepsilon_{t+1} + \dots + \rho\varepsilon_{t+k-1} + \varepsilon_{t+k}$$
> 其中 $u_t$ 包含了 $\varepsilon_t$：$u_t = \rho u_{t-1} + \varepsilon_t$，所以 $\varepsilon_t$ 对 $u_{t+k}$ 的影响路径为：
> $$\varepsilon_t \to u_t \to \rho u_t \to \rho^2 u_t \to \dots \to \rho^k u_t$$
> 即影响为 $\rho^k \varepsilon_t$。
> 因为 $|\rho| < 1$，$\rho^k \to 0$（$k \to \infty$），所以冲击影响逐渐消失。
> **最可能做错的原因**：没有清晰写出递推关系，或忘记说明 $|\rho| < 1$ 是收敛的关键条件。
> **对应误区**：无特定误区
> **标签**：#时间序列分析 #趋势平稳 #证明 #冲击传导
