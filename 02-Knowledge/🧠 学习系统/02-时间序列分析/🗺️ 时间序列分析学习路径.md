# 🗺️ 时间序列分析学习路径

> **学习者任务**：从可信时间索引与预测信息边界出发，依次完成结构探索、平稳化、经典模型、识别诊断、滚动样本外评估与多变量/现代扩展，最终提交一份可复现且允许复杂模型失败的预测报告。

## 课程目标

完成本路线后，你应能：

1. 定义预测对象、频率、季节周期、预测原点与 horizon，识别时间泄漏。
2. 用图形、分解、差分、ACF/PACF 与单位根检验描述序列结构和边界。
3. 推导并拟合 AR、MA、ARMA、ARIMA、SARIMA 与 ETS，解释参数和冲击传播。
4. 用收敛、根、残差、Ljung–Box、基线和滚动预测共同筛选模型。
5. 在多变量、状态空间或现代模型中保持相同的数据契约与评估口径。

## 最低前置与启动门

- **数学**：均值、方差、协方差、相关系数、条件期望、矩阵乘法与基础假设检验。
- **编程**：能运行 Python 脚本，使用 `numpy`、`pandas`、`matplotlib` 和 `statsmodels`。
- **启动诊断**：先进入[[00-前置知识/🧭 阶段0-前置知识]]；只回补未通过的统计或 Python 前置。
- **来源与版本**：课程来源、许可、版本和排除范围只在[[📚 教材挂载索引]]维护。

## Spine 与使用边界

- **Spine**：[Penn State STAT 510](https://online.stat.psu.edu/stat510/) 负责应用时间序列主干：ARIMA、识别估计、预测、平滑分解、动态关系、VAR、ARCH 与频域入口。
- **Co-Spine**：[Forecasting: Principles and Practice (3e)](https://otexts.com/fpp3/) 负责小白友好的预测工作流、ETS、ARIMA、动态回归与时间序列交叉验证。
- **Theory Supplement**：[MIT OCW 14.384](https://ocw.mit.edu/courses/14-384-time-series-analysis-fall-2013/) 只补充研究生理论和公开样例题，不冒充完整官方作业链。
- **Tool**：[statsmodels](https://github.com/statsmodels/statsmodels) 用于可复现实验和 API 交叉核对，不替代理论定义或手算验收。

详细章节覆盖、冲突裁决、许可和镜像策略见[[📚 教材挂载索引]]。

## 建议节奏与阶段衔接

每次学习采用“10 分钟闭卷回忆 → 30–50 分钟新内容 → 20–40 分钟手算/代码”。每个阶段：

1. 先读阶段 MOC 的动机和有序知识卡清单。
2. 每张卡完成至少一个手算或可运行例子；先写预期，再运行代码。
3. 作业依赖由作业 frontmatter 的 `requires` 维护，知识卡中的作业入口由 Dataview 反向派生。
4. 完成阶段作业并达到 80/100 且硬验收通过后，再进入下一阶段。
5. 未实际运行的代码、未冻结的数据和未完成的作答保持 `planned/ongoing`，不得写成实验结论。

## 失败时如何回流

- **日期重复、缺期或特征泄漏** → 阶段 0–1 的时间索引和数据契约。
- **差分次数靠 p 值追结果** → 阶段 2 的平稳性、单位根和过度差分反例。
- **ACF/PACF 靠口诀选阶** → 阶段 2–3 的冲击传播和候选台账。
- **模型收敛但预测无增益** → 阶段 4 的基线、滚动原点和逐 horizon 指标。
- **复杂模型只赢单次切分** → 阶段 5 的多种子、消融、数据规模与算力预算。
