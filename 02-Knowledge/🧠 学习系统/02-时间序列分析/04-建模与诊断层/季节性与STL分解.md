# 季节性与 STL 分解

---

## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具）**
- **判断理由**：经典分解的工业级替代；允许季节时变、抗异常值，是生产环境默认分解工具。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：经典分解假设季节每年不变、对异常值敏感。真实序列的季节形态会漂移（消费习惯变化）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：STL = 经典分解的稳健升级；其"内循环/外循环"思想也是 ETS 季节状态更新的对照。
- **实际应用场景**：零售、能源的日常分解；异常检测（残差阈值）。
- **高频题型/任务**：解释 LOESS 平滑与季节平滑窗；参数（seasonal, trend, robust）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[移动平均与经典分解]]**。
2. LOESS 局部回归直觉。

---

## 4. 用直觉语言解释它

> «"STL 用'局部回归'代替'简单平均'：季节可以慢慢变，异常值不会把整条曲线带偏。"»

- **直觉类比/几何图像**：会呼吸的分解——季节形状随时间微调。
- **为什么很自然**：稳健性 + 时变性是真实数据的两个刚需。
- **一句话直觉本质**：**STL = 基于 LOESS 的迭代分解，季节时变且稳健。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

STL（Seasonal-Trend decomposition using LOESS）：交替应用内循环（估计季节、趋势）与外循环（计算稳健权重），迭代直至收敛。$y_t=T_t+S_t+R_t$（仅加法）。

### 2. 核心公式

无单一公式；核心是 LOESS 平滑 $\hat y = \text{loess}(y,x)$ 与周期子序列平滑（按周期位置分组做 LOESS）。

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| period | 一个完整季节包含的观测数 | 例如月度年周期为 12、季度年周期为 4 |
| seasonal | 季节子序列 LOESS 平滑器长度 | 必须为奇数，通常不小于 7；不是 period |
| trend | 趋势 LOESS 平滑器长度 | 必须为奇数；省略时由 period 与 seasonal 推导默认值 |
| robust | 外循环开关 | 抗异常值 |

### 4. 常见变体与适用条件

- **适用条件**：加法模型；正值且振幅随水平增长的数据可先取对数。周期 $m>1$，并且样本应覆盖足够多的完整周期。
- **限制条件**：`period` 由数据频率和业务机制确定；`seasonal`、`trend` 是平滑强度参数。不能用“趋势窗必须大于季节窗”替代官方约束或验证，应在合理候选上检查分解稳定性与下游任务表现。

---

## 6. 推导思路和思想来源

- **最初困难**：经典分解季节固定 + 不耐异常值。
- **直接方法局限**：移动平均受离群点拖拽。
- **关键"转念"**：Cleveland et al. (1990) 用 LOESS（局部加权回归）替代 MA，并用"外循环"给异常值降权——两个循环交替逼近。
- **推导主线与动机**：周期子序列平滑把"季节"变成"按相位分别平滑"的问题，允许季节形态沿时间缓变。
- **为什么自然得到此结论**：局部方法天然可时变，加权天然稳健。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：季度数据按“一年一个季节周期”分解。`period` 应取多少？若采用 statsmodels 默认季节平滑强度，`seasonal` 取多少？
- **解题思路**：一个周期含 4 个季度，因此 `period=4`；`seasonal` 描述跨年份同一季度子序列的 LOESS 平滑长度，不是 4，statsmodels 默认取 7。
- **最终答案**：`period=4, seasonal=7`。可把 `seasonal` 改为其他不小于 7 的奇数做敏感性比较，但不能仅凭周期长度机械设定。
- **易错点**：把 `period` 与 `seasonal` 当成同一个参数，或声称 `seasonal` 必须大于周期长度。
- **🤔 追问**：robust=True 什么时候开？（有异常值/节假日效应）

### 例子 2：中等例子（条件判断与多步推理）

- **题目**：为什么乘法数据要先 log？
- **完整解答**：STL 是加法分解；乘法 $y=T\cdot S\cdot R$ 取对数变 $\log y=\log T+\log S+\log R$，分解后指数还原。

### 例子 3：实际应用例子（真实场景/代码）

```python
import numpy as np
from statsmodels.tsa.seasonal import STL

rng = np.random.default_rng(42)
t = np.arange(40)  # 10 年季度数据
y = 20 + 0.2 * t + 3 * np.sin(2 * np.pi * t / 4) + rng.normal(0, 0.5, len(t))

fit = STL(y, period=4, seasonal=7, robust=True).fit()
assert len(fit.trend) == len(y)
print(np.round([fit.seasonal.std(), fit.resid.std()], 3))
# 输出两个有限数：季节成分与残差的标准差；具体值由固定随机种子复现
```

- **实际价值与转化**：显式写出 `period=4` 可以避免 ndarray 没有频率信息时的歧义。`robust=True` 会对部分离群点使用稳健权重，但异常阈值仍需结合残差分布、误报成本和验证集校准，不能把“3 倍 MAD”当成普遍定律。

## 8. 常见误区和易混概念

### 误区 1："STL 只能加法所以不如经典分解"
- **错误直觉**：乘法场景不能用。
- **为什么错**：log 变换解决乘法。
- **正确理解**：log + STL = 乘法分解。

### 概念对比表

| 概念 | 季节 | 稳健性 | 场景 |
| :--- | :--- | :--- | :--- |
| 经典分解 | 固定 | 弱 | 快速 |
| STL | 时变 | 强 | 生产 |
| X-13 | 含日历效应 | 强 | 官方统计 |

### 题目与解析

#### 1. STL 相对经典分解的两个优势？
> [!question]- 答案解析
> - **答案**：季节时变 + 稳健（抗异常值）。
> - **解析**：LOESS + 外循环。
> - **易错原因**：只说一个。

#### 2. 乘法数据怎么用 STL？
> [!question]- 答案解析
> - **答案**：先 log 再分解，最后指数还原。
> - **解析**：加法模型。
> - **易错原因**：直接分解。

#### 3. seasonal 窗必须满足？
> [!question]- 答案解析
> - **答案**：在 statsmodels 中必须为奇数，通常应不小于 7；它不等于周期长度。
> - **解析**：`period` 指周期长度，`seasonal` 指季节子序列平滑器长度。参数增大通常会让季节成分随时间变化得更慢，但应通过敏感性分析验证。
> - **易错原因**：把 `period=12` 误写成 `seasonal=12`，或臆造“必须大于 period”的规则。

#### 4. robust=True 的作用？
> [!question]- 答案解析
> - **答案**：外循环给异常值低权重，防止拖拽。
> - **解析**：加权回归。
> - **易错原因**：以为改模型。

#### 5. 用 STL 做异常检测的流程？
> [!question]- 答案解析
> - **答案**：STL 分解 → 残差标准化（MAD）→ 超阈值判异常。
> - **解析**：残差是"去结构后的信号"。
> - **易错原因**：用原始值阈值。
