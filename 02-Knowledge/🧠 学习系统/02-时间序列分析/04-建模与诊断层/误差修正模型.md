# 误差修正模型（ECM）

## 0. 核心价值

ECM 同时回答两个时间尺度的问题：

- **短期**：本期 $x$ 的变化如何影响 $y$ 的变化？
- **长期**：上一期偏离均衡后，本期以多快速度拉回？

若变量协整，只做水平回归会有动态残差，只做差分又丢失长期均衡。ECM 将二者放进同一方程。

## 1. 直觉

设长期关系为 $y_t\approx\beta_0+\beta_1x_t$。上一期误差

$$e_{t-1}=y_{t-1}-\beta_0-\beta_1x_{t-1}$$

像被拉长的绳子。若 $e_{t-1}>0$ 表示 $y$ 高于长期均衡，那么本期 $\Delta y_t$ 应倾向下降。这个“朝反方向调整”的力度由调整系数 $\alpha$ 控制。

## 2. 正式模型

最简单的单方程 ECM：

$$
\Delta y_t
=c+\alpha(y_{t-1}-\beta_0-\beta_1x_{t-1})
+\gamma\Delta x_t+\varepsilon_t.
$$

| 符号 | 含义 | 常见解释 |
|---|---|---|
| $\beta_1$ | 长期协整系数 | $x$ 长期增加 1 单位时，均衡 $y$ 改变多少 |
| $e_{t-1}$ | 上一期均衡偏离 | 长期关系的“误差” |
| $\alpha$ | 调整速度 | 常见稳定情形为负；偏高后向下修正 |
| $\gamma$ | 同期短期效应 | $x$ 的本期变化对 $y$ 变化的影响 |
| $c$ | 短期漂移/截距 | 需结合长期方程设定解释 |

复杂模型可以加入 $\Delta y_{t-i}$、$\Delta x_{t-j}$、季节项和干预变量。多变量系统若存在多个协整向量，应使用 VECM，而不是分别拼接多个单方程 ECM。

## 3. 从 ARDL 到 ECM 的代数重写

从

$$y_t=a+\rho y_{t-1}+\delta x_t+\lambda x_{t-1}+\varepsilon_t$$

两边减 $y_{t-1}$，并用 $x_t=x_{t-1}+\Delta x_t$：

$$
\Delta y_t=a+(\rho-1)y_{t-1}+(\delta+\lambda)x_{t-1}+\delta\Delta x_t+\varepsilon_t.
$$

令 $\alpha=\rho-1$，$\beta_1=-(\delta+\lambda)/\alpha$，即可写成

$$
\Delta y_t=a+\alpha(y_{t-1}-\beta_1x_{t-1})+\delta\Delta x_t+\varepsilon_t.
$$

ECM 不是凭空添加一个残差，而是动态水平模型的等价重参数化；协整让括号内组合为平稳量。

## 4. 可手算例子

长期关系为 $y=2x$，模型为

$$\Delta y_t=-0.4(y_{t-1}-2x_{t-1})+0.5\Delta x_t.$$

若上一期 $x=10,y=23$，则均衡偏离为 $23-20=3$；本期 $x$ 增加 2：

$$\Delta y_t=-0.4(3)+0.5(2)=-0.2.$$

短期 $x$ 上升推高 $y$ 1 单位，但此前 $y$ 偏高带来 -1.2 的修正，净变化 -0.2。

## 5. 可运行代码

运行前预测：长期斜率接近 2，调整系数应为负；若上一期 $y$ 高于均衡，本期 $\Delta y$ 倾向下降。

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

rng = np.random.default_rng(20)
n = 600
dx = rng.normal(size=n)
x = np.cumsum(dx)
e = np.zeros(n)
y = np.zeros(n)
y[0] = 2 * x[0]

for t in range(1, n):
    diseq = y[t - 1] - 2 * x[t - 1]
    dy = -0.35 * diseq + 0.6 * dx[t] + rng.normal(scale=0.5)
    y[t] = y[t - 1] + dy

long_run = sm.OLS(y, sm.add_constant(x)).fit()
ect = y - long_run.predict(sm.add_constant(x))

frame = pd.DataFrame({
    "dy": np.diff(y),
    "dx": np.diff(x),
    "ect_lag": ect[:-1],
})
ecm = sm.OLS(frame["dy"], sm.add_constant(frame[["ect_lag", "dx"]])).fit()

print("long-run beta:", long_run.params.round(3))
print("ECM [const, alpha, gamma]:", ecm.params.round(3).to_dict())
# 预期：长期 beta 接近 2，alpha 为负，gamma 为正
```

## 6. 建模流程

1. 先确认变量含义、时间对齐、公布延迟与可能结构突变。
2. 审计整合阶数；经典 ECM 不应把任意 $I(0)$/$I(1)$ 变量混合后直接套用。
3. 根据理论设定长期方程和确定性项，检验协整。
4. 冻结长期残差后构造 $e_{t-1}$，只使用滞后一阶避免同期信息混淆。
5. 建立简约短期动态，检查残差、稳定性和调整系数符号。
6. 用滚动窗口检验长期系数和调整速度是否漂移。
7. 若目标是预测，仍需与差分 VAR、ARIMAX 和朴素基线做样本外比较。

## 7. 常见误区

| 误区 | 问题 | 正确理解 |
|---|---|---|
| $\alpha$ 越大调整越快 | 符号与离散动态稳定性被忽略 | 结合误差定义；常见稳定单方程中 $\alpha<0$ |
| 协整显著即可直接 ECM | 长期设定可能不稳或有突变 | 检查系数、残差与结构稳定 |
| 误差修正项用当期残差 | 可能引入同期内生性/不可用信息 | 通常使用 $e_{t-1}$ |
| ECM 自动证明因果方向 | 调整只是动态关系 | 因果需识别假设与外生信息 |
| 样本内调整显著即可预测 | 显著不等于基线增益 | 做滚动样本外评估 |

### Card 1
Q: ECM 中误差修正项为什么通常滞后一期？
A: 它表示预测原点已经观察到的上一期均衡偏离，并避免把当期未完成或同期决定的信息直接放入右侧。

### Card 2
Q: ECM 的调整系数 alpha 如何解释？
A: 在给定误差定义下，它描述上一期偏离有多少通过本期变化被修正；常见稳定设定中为负。
