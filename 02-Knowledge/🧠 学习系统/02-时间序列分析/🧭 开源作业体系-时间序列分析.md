# 🧭 开源作业体系-时间序列分析

> 本页是「时间序列分析」开源名校课程与作业的**唯一挂载点**：教材主线、官方作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**Forecasting: Principles and Practice (3e)**（https://otexts.com/fpp3/，official-free online）+ **Penn State STAT 510**（https://online.stat.psu.edu/stat510/，应用回归视角）+ **statsmodels / pmdarima 实验**。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷手算（ACF 衰减、AR(1) 自协方差）；② Python 实现（含 statsmodels 复现）；③ 1 页报告（数据背景 + 模型选型理由 + 残差诊断 + 预测误差）。
2. **数据来源**：FPP3 提供的 R 数据集（移植到 Python）+ 公开 UCI/联邦储备经济数据 + 03-Projects 现有数据集。
3. **满分 Rubric**：HW01-05 各 20 分，共 100 分（手算 25 + 实现 45 + 报告 30）。
