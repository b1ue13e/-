# L00｜环境、时间索引与信息边界

> **预计用时**：60–90 分钟　**当前掌握**：0 / 1 / 2 / 3

## 0. 这节课解决什么问题

时间序列代码最常见的失败并不是公式写错，而是时间轴不可信：日期重复、顺序颠倒、频率说不清、缺失期被静默跳过，或者训练时使用了预测发生后才知道的数据。

本课只完成一个最小闭环：**建立可运行环境，把一张带日期的表变成经过检查的时间序列，并明确每个预测原点能使用什么信息。**

## 1. 学习目标

学完后，不看笔记能够：

- 检查 Python 与核心依赖是否可用；
- 将日期列转换为排序、唯一的 `DatetimeIndex`；
- 区分观测间隔、声明频率和季节周期；
- 发现缺期、重复期、异常类型和不合理填补；
- 写出预测原点 $t$ 的信息集 $\mathcal F_t$；
- 按时间切分训练集和测试集，不随机打乱。

## 2. 开课前的最小先修

只需要会三件事：

## 4. 第一个可复现数据集

下面的数据故意包含乱序、重复月份和一个缺失值。先预测每一步检查会发现什么，再运行：

```python
from io import StringIO
import pandas as pd

raw = StringIO("""date,value
2025-01-01,10
2025-03-01,14
2025-02-01,12
2025-03-01,15
2025-05-01,
""")

df = pd.read_csv(raw, parse_dates=["date"])
print("原始行数:", len(df))
print("重复日期数:", int(df["date"].duplicated().sum()))
print("缺失值数:", int(df["value"].isna().sum()))

# 重复记录必须先查业务原因；教学例暂以同月均值聚合
series = (
    df.groupby("date", as_index=True)["value"]
      .mean()
      .sort_index()
      .asfreq("MS")
)

print(series)
print("声明频率:", series.index.freqstr)
print("补齐时间轴后的缺期数:", int(series.isna().sum()))
```

**预期现象**：3 月重复值被聚合为 14.5；4 月作为缺失月份被显式补出；5 月原本也是缺失值。因此最终有两个缺失期，而不是只看到 CSV 中的一个空单元格。

## 5. 频率、季节周期与窗口不是一回事

| 名称 | 回答的问题 | 月度例子 |
|---|---|---|
| 采样频率 | 多久记录一次 | 每月一次，`MS` |
| 季节周期 $m$ | 模式隔多少期重复 | 年度季节性常取 $m=12$ |
| 滞后 $k$ | 比较相隔多少期的观测 | $k=1$ 是相邻月 |
| 预测步长 $h$ | 要预测多远 | $h=3$ 是未来三个月 |
| 滚动窗口 $w$ | 每次使用多少历史 | 最近 36 个月 |

月度数据不自动等于 $m=12$。只有业务机制、时间图或重复结构支持年度季节性时，12 才是合理候选周期。

## 6. 缺失值不能机械填补

先区分缺失机制：停业导致的真实零值、传感器断线、报表延迟和“不适用”不是同一种缺失。

```python
import pandas as pd

# 与上一节整理后的规则月度序列相同；本代码块可独立运行
series = pd.Series(
    [10.0, 12.0, 14.5, float("nan"), float("nan")],
    index=pd.date_range("2025-01-01", periods=5, freq="MS"),
)
linear = series.interpolate(method="time")
forward = series.ffill()
comparison = pd.DataFrame({"original": series, "linear": linear, "ffill": forward})
print(comparison)
```

- 插值会利用缺失点两侧的信息，若在全样本上先插值再切分，可能把未来泄漏到训练期；
- 前向填充只使用过去值，但会制造平段并改变自相关；
- 真实项目应在每个训练窗口内部拟合或执行填补规则，并保留缺失指示变量与原始数据。

## 7. 预测原点与信息集

在时点 $t$ 预测 $y_{t+h}$ 时，可用信息写作 $\mathcal F_t$。特征合法性的判断标准是：**部署时在预测原点是否已经知道它**。

例如在 6 月 30 日预测 7 月销量：

- 6 月完整销量若已结算，可用；若 7 月 1 日才出报表，则不可用；
- 5 月销量通常可用；
- 7 月促销计划若已冻结，可用；
- 7 月实际天气不可用，只能使用当时可得的天气预报；
- 事后修订的宏观数据必须使用当时发布版本，而不是最终修订值。

## 8. 第一次时间切分

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(0)
index = pd.date_range("2020-01-01", periods=60, freq="MS")
y = pd.Series(100 + 0.4 * np.arange(60) + rng.normal(0, 2, 60), index=index)

split = 48
train, test = y.iloc[:split], y.iloc[split:]

assert train.index.is_monotonic_increasing
assert train.index.max() < test.index.min()
assert len(train) + len(test) == len(y)
print(train.index.min(), train.index.max(), len(train))
print(test.index.min(), test.index.max(), len(test))
```

禁止用 `train_test_split(..., shuffle=True)` 随机打乱普通时间序列。最终测试段在模型、变换和指标冻结前保持封存。

## 9. 当堂练习

1. 某月度表缺少 4 月这一行，5 月值为空。这是几个缺失期？
2. 在周一早上预测本周总销量，哪些“本周特征”可能尚不可用？
3. 为什么先对全样本标准化或插值，再切训练/测试，会产生泄漏？
4. 写出你的一个真实数据集的频率、候选季节周期、关键 horizon 和公布延迟。

> [!answer]- 当堂练习答案
> 1. 两个：时间轴缺少的 4 月，以及已经存在但数值为空的 5 月。  
> 2. 尚未发生的本周实际销量、实际天气和事后汇总指标；计划值或预测值能否使用取决于周一是否已发布。  
> 3. 变换参数或插值结果吸收了测试期信息，使训练过程间接看到未来。  
> 4. 必须写具体业务时钟；只写“月度数据”不算完成。
