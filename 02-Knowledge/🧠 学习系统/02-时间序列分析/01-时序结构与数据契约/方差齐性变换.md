# 方差稳定化与 Box-Cox 变换

## 0. 它解决什么问题

当序列水平越高，波动幅度也越大时，等方差误差和固定宽度区间会失真。方差稳定化把“绝对误差随规模放大”转成更接近“相对误差稳定”的尺度。

它不是为了让图更漂亮，也不等于消除趋势或单位根。

## 1. 直觉与正式公式

销量从 10 波动 2 与从 1000 波动 200，绝对幅度不同，但相对幅度都是 20%。对数把乘法变化转为加法：

$$\log(ab)=\log a+\log b.$$

经典正值 Box–Cox 族为

$$
w_t=\begin{cases}
\log y_t,&\lambda=0,\\
(y_t^\lambda-1)/\lambda,&\lambda\ne0.
\end{cases}
$$

$\lambda=1$ 基本保留原形状，$\lambda=0$ 为自然对数，$\lambda=1/2$ 近似平方根变换。标准 Box–Cox 要求正值；存在零/负值时不能随意加一个常数后假装解释不变，应考虑 Yeo–Johnson、领域合理的平移或直接建模异方差。

## 2. 手算例子

从 100 增至 110 的对数变化：

$$\log(110)-\log(100)=\log(1.1)\approx0.0953.$$

从 200 增至 220 得到同样的 $\log(1.1)$。对数尺度表达相同的相对变化，而原尺度变化分别是 10 与 20。

## 3. 选择流程

1. 画时间图与“局部水平—局部波动”关系。
2. 先做领域调整：交易日、人口、通胀、曝光量等已知规模效应。
3. 在训练段选择固定变换和 $\lambda$；验证/测试不得重新看未来后调参。
4. 在变换尺度拟合并诊断残差。
5. 逆变换到原尺度评估；非线性逆变换通常需要偏差修正或模拟。
6. 同时与不变换模型比较滚动误差和区间覆盖。

## 4. 可运行代码

```python
import numpy as np
from scipy.stats import boxcox, boxcox_normmax

rng = np.random.default_rng(31)
t = np.arange(240)
level = np.exp(2 + 0.006 * t)
y = level * np.exp(rng.normal(0, 0.18, len(t)))

train = y[:180]
test = y[180:]
lam = boxcox_normmax(train, method="mle")
train_bc = boxcox(train, lmbda=lam)
test_bc = boxcox(test, lmbda=lam)  # 只沿用训练段 lambda

print("lambda:", round(lam, 3))
print("raw half std:", round(train[:90].std(), 2), round(train[90:].std(), 2))
print("Box-Cox half std:", round(train_bc[:90].std(), 2), round(train_bc[90:].std(), 2))
print("test transformed length:", len(test_bc))
```

这段代码只演示变换参数边界，不声称 Box–Cox 后已经平稳。下一步仍要检查趋势、季节和残差。

## 5. 逆变换与偏差

若在对数尺度预测的是条件均值 $E[\log Y]$，直接指数化得到的是几何中心，通常不等于 $E[Y]$。正态对数误差近似下：

$$E[Y]\approx\exp(\hat\mu+\tfrac12\hat\sigma^2).$$

真实任务可用模拟、残差 bootstrap 或模型提供的原尺度分布进行偏差修正。不能只逆变换点预测而忽略区间的不对称性。

## 6. 常见误区

- 方差变换会自动消除趋势：错，均值结构仍需建模。
- 全样本选择 $\lambda$：泄漏未来尺度信息。
- 有零值就统一加 1：加多少会改变低值区解释，必须有领域理由。
- 对数预测直接 `exp` 就是原尺度均值：忽略 Jensen 偏差。
- 变换模型 AICc 与原尺度模型机械比较：响应尺度不同，似然口径不同。

> [!answer]- 自测答案
> 1. 极限形式为自然对数。  
> 2. 它把乘法/比例变化转成加法变化。  
> 3. 否则变换参数吸收验证/测试分布。  
> 4. 非线性下 $E[e^X]\ne e^{E[X]}$。  
> 5. 领域调整、Yeo–Johnson、计数模型或显式异方差模型，并说明解释边界。
