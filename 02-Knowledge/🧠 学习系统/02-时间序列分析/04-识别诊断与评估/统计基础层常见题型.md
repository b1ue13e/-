# 统计基础层常见题型

> [!NOTE] 题型特征
> 本层级的核心考点全在数学计算和定义辨析上。主要考察如何计算方差和自协方差，以及如何根据方程判断平稳性与可逆性。

## 题型 1：由定义计算自协方差
**题目描述**：设 $X_t = \epsilon_t + c\epsilon_{t-1}$，其中 $\epsilon_t \sim WN(0, \sigma^2)$ 是白噪声。求该序列的自协方差函数 $\gamma_0$ 和 $\gamma_1$。
**解题思路**：
直接套用自协方差定义：$\gamma_k = E[X_t X_{t-k}]$（因为序列显然均值为0）。
1. $k=0$ 时：
   $$ \gamma_0 = E[(\epsilon_t + c\epsilon_{t-1})^2] = E[\epsilon_t^2] + c^2 E[\epsilon_{t-1}^2] + 2c E[\epsilon_t \epsilon_{t-1}] $$
   由于白噪声独立，$E[\epsilon_t \epsilon_{t-1}]=0$。所以 $\gamma_0 = \sigma^2 + c^2 \sigma^2 = (1+c^2)\sigma^2$。
2. $k=1$ 时：
   $$ \gamma_1 = E[(\epsilon_t + c\epsilon_{t-1})(\epsilon_{t-1} + c\epsilon_{t-2})] $$
   展开后只有交叉项 $\epsilon_{t-1} \cdot \epsilon_{t-1}$ 的期望不为 0：
   $$ \gamma_1 = c E[\epsilon_{t-1}^2] = c \sigma^2 $$

## 题型 2：判断 AR(p) 的平稳性 (特征方程求根)
**题目描述**：判断时间序列模型 $X_t = 0.5 X_{t-1} + 0.5 X_{t-2} + \epsilon_t$ 是否平稳？
**解题思路**：
1. **写出特征方程**：把 $X_{t-k}$ 替换成延迟算子 $L^k$，得到 $(1 - 0.5L - 0.5L^2) X_t = \epsilon_t$。所以特征方程为 $1 - 0.5L - 0.5L^2 = 0$。
2. **求解特征根**：
   同乘 2 得到 $2 - L - L^2 = 0 \implies -(L-1)(L+2) = 0$。
   解得特征根 $L_1 = 1$, $L_2 = -2$。
3. **判别平稳性**：AR(p) 模型平稳的充要条件是**所有特征根的绝对值（模）严格大于 1**（即都在单位圆外）。
   现在有一个根 $L_1 = 1$ 正好落在了单位圆上（这就是所谓的“单位根”）。因此，该模型**不平稳**！

## 题型 3：Wold 分解的理论理解题
**题目描述**：简述 Wold 分解定理，并解释为什么它使得 ARMA 建模成为可能？
**解题思路**：
- **定理**：任何零均值的协方差平稳序列都可以分解为一个纯非确定性部分（MA(∞)）和一个确定性部分的和。
- **联系**：既然任何平稳序列其随机波动部分都可以表示为无穷项的 MA 模型，而无穷多项的参数无法估计；数学上我们证明了有理分式多项式 $\Theta(L)/\Phi(L)$ 可以极好地逼近这种无穷阶多项式。这就是为什么我们用含有限个参数的 ARMA 模型去近似现实，它有着坚实的数学物理根基。

## 检索练习与通过标准

闭卷推导 MA(1) 的方差、lag-1 协方差和可逆性条件，再判断一个 AR(2) 的根是否满足平稳要求。通过标准：符号、白噪声条件和根的判定方向无误，能指出初始条件的作用。
