# 时间序列分析｜大作业：漂移监控扩展

> [!info] 课程关系
> 先完成[[时间序列分析-大作业-滚动预测与完整建模报告]]，本页只增加漂移监控与上线决策，不替代经典基线、残差和区间审计。

## 学习目标

使用一个公开的日频数据集，完成从清洗、基线预测、滚动验证到分布漂移监控的完整链路。重点是验证预测是否在样本外成立，而不是追求单次最优分数。

## 任务边界与数据约束

- 输入：日期、目标值和可用的外生变量；禁止使用未来窗口统计量。
- 切分：按时间顺序划分 train / validation / test，禁止随机打乱。
- 基线：naive-last、季节性 naive、ARIMA；可选 XGBoost/LSTM 只能作为对照。
- 指标：MAE、RMSE、MASE，并报告预测区间覆盖率（若提供区间）。

## 任务清单

- [ ] 完成 HW09 的预测任务契约，冻结 horizon、主要指标与最终测试段。
- [ ] 写出数据字典并处理缺失日期、重复时间戳和异常值。
- [ ] 实现 expanding-window 与 rolling-window 两种回测。
- [ ] 比较 naive、ARIMA 与一个机器学习模型，记录每个窗口的指标。
- [ ] 用 PSI 或滚动 KS 检验监控特征分布漂移，并设置告警阈值。
- [ ] 做残差白噪声检验，解释失败窗口，不只汇报均值。
- [ ] 将最大误差窗口回链到 HW09，并说明这些失败在预测时是否可识别。

## 提交产物

提交 `README.md`、`manifest.yml`、数据字典、时间切分图、逐窗口预测与指标 CSV、漂移统计/告警表、残差诊断图、环境与运行命令，以及一份说明重训/降级/暂停决策的报告。不得提交许可证不允许再分发的数据快照。

## 验收标准

- [ ] 固定随机种子后可重复生成同一张结果表。
- [ ] 报告包含时间切分图、窗口级指标、残差诊断和漂移告警示例。
- [ ] 明确模型失效条件与下一步动作（重训、降级到基线或暂停预测）。

通过线为 85/100，且不得出现未来信息泄漏、随机打乱、无朴素基线、测试集调参或无法复现等硬失败。

## 引导与自检

先冻结预测原点和告警阈值，再运行窗口实验；逐项检查每个窗口的训练结束时间早于预测时间，漂移告警能回链到具体特征与窗口，并保留模型输给基线的结果。
