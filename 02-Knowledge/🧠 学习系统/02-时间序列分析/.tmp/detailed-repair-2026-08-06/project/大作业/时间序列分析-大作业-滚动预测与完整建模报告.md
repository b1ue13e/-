# 时间序列分析｜大作业：滚动预测与完整建模报告

## 学习目标

把一个真实序列转化为可复核的预测决策，完成从数据契约、候选模型、残差诊断到滚动样本外评估的完整闭环。

## 用户结果

在一个真实公开序列上，提交可从空目录复核的预测报告：明确数据与决策、比较朴素基线/ETS/ARIMA，使用无泄漏滚动评估，报告点预测和区间，保留复杂模型失败的证据。

## 数据与任务边界

- 数据至少覆盖 120 个规则时点；若有季节性，至少 5 个完整周期。
- 记录官方/原始来源 URL、下载日期、条款、字段、频率、修订与公布延迟。
- 模型选择使用滚动验证；最终测试段在全部协议冻结后只打开一次。
- 必选：last-value naïve；存在稳定季节时加 seasonal naïve；候选至少含 ETS 和 ARIMA。
- ML/DL、多变量或状态空间仅作为可选扩展，必须使用同一窗口/指标并说明计算预算。

## 里程碑

1. **任务与 manifest**：冻结预测对象、决策、频率、horizon、信息边界、主指标、区间和失败成本。
2. **数据契约**：审计排序、重复、缺期、异常、真实零和公布延迟；所有变换在训练窗口内拟合。
3. **结构与候选**：图形、分解、方差变换、差分、ACF/PACF；保留有限候选与预注册理由。
4. **估计与诊断**：收敛、警告、参数区间、根、残差/平方残差、Ljung–Box、结构变化。
5. **滚动评估**：按 horizon 报告 MAE/RMSE/MASE；区间报告覆盖率和宽度；比较 expanding/rolling 协议。
6. **最终测试与失败审计**：协议冻结后只评估一次；保留最大误差窗口、负结果和与验证期不一致之处。
7. **报告与复现**：从 README 到全部表图只有一条可执行路径，结果由逐预测文件可复算。

## 100 分 Rubric

| 维度 | 分值 | 通过证据 |
| :--- | ---: | :--- |
| 数据、信息边界与复现 | 20 | 来源/版本/公布时钟、manifest、命令与逐预测文件可复核 |
| 方法与推导正确性 | 25 | 变换/差分/估计/根/实现口径一致，警告保留 |
| 基线与公平比较 | 20 | 同一窗口、真实值与指标比较 naïve/seasonal naïve/ETS/ARIMA |
| 诊断、不确定性与失败 | 20 | 残差、区间覆盖/宽度、失败窗口、协议敏感性和负结果 |
| 解释与适用边界 | 15 | 结论服务决策但不夸大，不把预测关联当因果 |

通过线 85/100，且无以下硬失败：未来信息泄漏、测试调参、来源/环境不可追踪、无朴素基线、残差或区间未审计、删除失败窗口、结果无法由 README 复现。

## 引导与自检

- 先写预期和协议，再运行；每次看测试前问“这是否改变了模型选择”。
- 模型可以输给基线；负结果是结论，不是需要隐藏的异常。
- 每张图回答一个问题，所有汇总数值均能回到逐预测记录。
- 提交前从空目录按 README 重跑；未实际重跑时保持 `status: planned/ongoing`。

完成后可选进入阶段 5 的动态回归、多变量或现代模型对照，但扩展不能替代本大作业的经典基线与无泄漏协议。
