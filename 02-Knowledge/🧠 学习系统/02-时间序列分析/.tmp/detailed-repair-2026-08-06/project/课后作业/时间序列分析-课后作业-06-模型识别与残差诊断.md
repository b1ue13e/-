# 时间序列分析｜课后作业 06：模型识别与残差诊断

## 🎯 学习目标

1. **信息准则（AIC / AICc / BIC）推导与计算**：掌握小样本修正信息准则 AICc 的计算公式与应用条件，理解对数似然 $\ell$、参数个数 $k$ 与有效样本量 $T$ 对模型选择的协同约束。
2. **候选模型预注册与估计台账**：建立看样本 ACF/PACF 前预注册候选模型的规范，记录优化器收敛状态、根模（Root Modulus）边界与参数标准误。
3. **Ljung–Box 白噪声检验统计量**：独立手算 Ljung–Box 联合检验统计量 $Q^*$，掌握自由度调整（$\text{df} = h - p - q$）与白噪声拒绝后的故障定位。
4. **残差四联图诊断与模型迭代**：绘制残差时序图、ACF 图、Q–Q 图/直方图及平方残差 ACF 图（ARCH 效应检测），实施最小必要模型修复。

---

## 🚧 任务背景与环境

在平稳与非平稳 ARIMA 模型建立过程中，盲目网格搜索容易导致过拟合与“P-hacking”。本实验沿用阶段 3 冻结的训练数据集，测试段数据保持严格封存。

**边界与假设**：
- **有效样本量一致性**：进行 AICc 比较时，所有候选模型必须建立在完全相同的有效样本集 $T$ 上（即差分阶数 $d, D$ 不一致的模型不能直接机械比较 AICc）。
- **软硬件边界**：Python 3.11+，`statsmodels`, `scipy`, `matplotlib`；普通 CPU 预计运行时间 $< 10$ 分钟。

## 📝 详细题目与手算步骤

### 1. AICc 手算与模型比较 (15分)
已知样本量 $T=80$，三组候选模型 A, B, C 的对数似然 $\ell$ 与参数个数 $k$ 分别为：
- 模型 A: $\ell = -100.0, k = 3$
- 模型 B: $\ell = -98.0, k = 6$
- 模型 C: $\ell = -101.0, k = 2$

根据 AICc 修正公式：
$$\text{AIC} = 2k - 2\ell, \quad \text{AICc} = \text{AIC} + \frac{2k(k+1)}{T - k - 1}$$
手算三组模型的 AIC 与 AICc，比较其数值大小并解释为何在小样本下 AICc 比 AIC 更能惩罚过拟合。

### 2. 候选模型与参数估计台账 (20分)
在查看样本 ACF/PACF 图表前，在 `data/candidate_registry.csv` 中预注册 3–5 个候选 ARIMA 结构。运行估计后填入以下台账字段：
- `model_str` (如 ARIMA(1,1,1))
- `log_likelihood`, `aicc`
- `convergence_status` (CONVERGED / WARNING)
- `ar_roots_min_modulus` (验证平稳性，模长必须 $> 1.0$)
- `ma_roots_min_modulus` (验证可逆性，模长必须 $> 1.0$)

### 3. 边界敏感性分析 (15分)
在保留原始最佳模型的同时，改变以下两项中的任意一项，观察模型参数与 AICc 的波动：
- 更改训练集的起始起点（如删除前 5 个观察值）。
- 更改优化器算法（如从 `lbfgs` 切换为 `nm` 或 `powell`）。

### 4. Ljung–Box 检验手算与预注册 (20分)
已知样本量 $T=100$，前两个滞后阶的自相关系数分别为 $\hat{\rho}_1 = 0.10, \hat{\rho}_2 = 0.05$。
利用 Ljung–Box 统计量公式：
$$Q^* = T(T+2) \sum_{k=1}^m \frac{\hat{\rho}_k^2}{T-k}$$
手算 $m=2$ 时的 $Q^*$ 值。对于 $\text{ARIMA}(1,0,1)$ 模型，说明为什么自由度为 $\text{df} = m - p - q = 2 - 1 - 1 = 0$，此时应如何调整滞后阶数 $m$。

### 5. 残差四联图诊断与故障修复 (20分)
绘制并导出残差四联图 `output/residual_diagnostics.png`：
1. **残差时序图**：检查均值是否为 0，是否存在方差集聚（Volatility Clustering）。
2. **残差 ACF 图**：检查自相关落入 $\pm 1.96/\sqrt{T}$ 虚线框内。
3. **Q–Q 图与直方图**：检查正态性假设。
4. **平方残差 ACF 图**：检查是否存在未被捕获的 ARCH 异方差效应。

选取一个未能通过诊断的失败模型，执行一次最小必要修复（如增加 MA 阶数或引入 GARCH），对比修复前后的诊断图。

### 6. 评审结论与样本外评估决策 (10分)
撰写 300 字评审结论：说明哪些模型允许进入阶段 4 样本外交叉验证，哪些模型因不平稳/未收敛/残差自相关而被淘汰。
