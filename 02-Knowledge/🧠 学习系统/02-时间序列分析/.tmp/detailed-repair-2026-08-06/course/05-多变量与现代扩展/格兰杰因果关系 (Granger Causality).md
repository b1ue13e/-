# 格兰杰因果关系 (Granger Causality)

> [!NOTE] 核心直觉：公鸡打鸣与太阳升起
> **类比**：公鸡打鸣（事件 X）发生后，太阳总是升起（事件 Y）。我们知道公鸡并不是太阳升起的物理“原因”。但是，在时间序列分析中，如果“知道公鸡打鸣”能帮助我们**更好地预测**“太阳何时升起”，那么我们就说 X 对 Y 具有“格兰杰因果关系”。格兰杰因果本质上是**预测能力的前后顺序**，而不是哲学意义上的“因果律”。

## 1. 为什么需要这个知识点？
- **背景**：在多变量时间序列分析中（如宏观经济指标、股票量价数据），我们常常想知道一个变量的变化是否“导致”了另一个变量的变化。
- **痛点**：传统的皮尔逊相关系数只能告诉你两个变量同步变化（相关不等于因果）。我们需要一种基于时间先后的统计方法，来检验变量间是否存在领先/滞后的预测关系。
- **应用场景**：量化投资中，测试“交易量”是否是“价格变动”的格兰杰原因；宏观经济中，测试“货币供应量”是否是“通货膨胀”的格兰杰原因。

## 2. 核心定义与公式
格兰杰因果关系的严格统计学定义是：如果加入时间序列 $X$ 的历史信息，能够显著降低时间序列 $Y$ 的预测误差，则称 $X$ 是 $Y$ 的格兰杰原因（Granger Cause）。

**数学公式表达 (基于 VAR 框架)**：
假设有两个平稳时间序列 $X_t$ 和 $Y_t$。我们对 $Y_t$ 建立两个自回归模型：

1. **受限模型 (Restricted Model)**：只用 $Y$ 自己的历史数据预测 $Y_t$。
   $$ Y_t = \alpha_0 + \sum_{i=1}^{p} \alpha_i Y_{t-i} + e_{1t} $$
   残差平方和为 $RSS_R$。

2. **无限制模型 (Unrestricted Model)**：用 $Y$ 的历史数据加上 $X$ 的历史数据共同预测 $Y_t$。
   $$ Y_t = \beta_0 + \sum_{i=1}^{p} \beta_i Y_{t-i} + \sum_{j=1}^{q} \gamma_j X_{t-j} + e_{2t} $$
   残差平方和为 $RSS_U$。

**假设检验 (F-Test)**：
- 原假设 $H_0$: $\gamma_1 = \gamma_2 = \dots = \gamma_q = 0$ ($X$ 不是 $Y$ 的格兰杰原因)。
- 计算 F 统计量：
  $$ F = \frac{(RSS_R - RSS_U) / q}{RSS_U / (n - p - q - 1)} $$
- 如果 F 统计量显著（p-value < 0.05），拒绝原假设，认为 $X$ Granger causes $Y$。

## 3. 具体应用案例
**场景**：检验“隔夜美股指数回报率”是否能格兰杰引起“A股开盘涨跌幅”。
1. 收集过去 1 年的标普 500 指数日收益率（$X$）和上证指数日收益率（$Y$）。
2. 先对 $X$ 和 $Y$ 进行平稳性检验（ADF 检验），若不平稳则需差分。
3. 确定最佳滞后阶数 $p$（通常通过 AIC/BIC 信息准则）。
4. 运行 Granger Causality Test，得出 p-value。若 p-value < 0.05，则说明美股隔夜收益率对A股开盘具有统计学意义上的预测价值。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **伪回归陷阱**：前提条件是序列必须是**平稳的**（Stationary）。如果对两个不平稳且没有协整关系的序列做格兰杰检验，极容易得出荒谬的结论（伪回归）。
> - **真正的因果谬误**：格兰杰因果检验检验的是“预测的领先滞后关系”，而不是物理/逻辑上的因果关系。例如夏天“冰淇淋销量增加”会格兰杰导致“溺水人数增加”，因为它们有共同的潜在变量（气温升高）。
> - **滞后阶数敏感性**：结果高度依赖滞后阶数 $p$ 的选择。不同的 $p$ 可能得出截然相反的结论，因此必须用严格的 AIC/BIC 准则定阶。
