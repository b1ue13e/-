# 🧭 阶段5｜多变量与现代扩展

## 为什么现在学

只有经典基线和滚动协议已经冻结，增加外生变量、多个序列、隐藏状态或高容量模型才有可比较的价值。

## 有序学习清单

1. [[动态回归与ARIMAX]]：冻结外生变量在预测原点的可得性。
2. [[向量自回归VAR]] → [[格兰杰因果关系 (Granger Causality)]]。
3. [[虚假回归]] → [[协整]] → [[误差修正模型]]。
4. [[状态空间模型与Kalman滤波]]。
5. [[时序特征工程与ML预测]] → [[XGBoost时序预测]]。
6. [[RNN时序建模]] → [[LSTM与GRU在时序中的应用]] → [[Transformer 时序预测]] → [[N-BEATS与N-HiTS]]。

## 学完能做什么

- 区分预测关联、格兰杰可预测性和因果效应。
- 检查协整关系、误差修正项和状态空间递推的适用条件。
- 在相同数据、窗口、horizon 和指标下比较经典模型与 ML/DL，并做消融。
