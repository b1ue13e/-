# 🧭 阶段3｜经典预测模型

## 为什么现在学

阶段 2 已把序列转成可建模对象；现在用冲击传播、滞后算子和状态更新解释模型，而不是把软件订单当标签。

## 有序学习清单

1. [[L03-AR模型与均值回归]] → [[AR模型]] → [[AR模型平稳性与等比数列求和]]。
2. [[L04-MA模型与有限冲击]] → [[MA模型]] → [[ARMA模型]]。
3. [[差分运算]] → [[L05-ARMA与ARIMA建模闭环]] → [[ARIMA建模流程-识别-估计-诊断]]。
4. [[L06-SARIMA与季节预测]] → [[SARIMA模型]]。

6. [[参数估计]]、[[Yule-Walker 方程 (Yule-Walker Equations)]]、[[Yule-Walker 方程估计推导]]。

[[Wold 分解定理 (Wold's Decomposition Theorem)]]与[[投影定理与时间序列最优线性预测]]是理论专题，完成主线后再读。

## 学完能做什么

- 推导 AR(1) 均值、冲击响应和多步预测；推导 MA(1) 方差与 ACF。
- 写出 ARIMA/SARIMA 滞后算子形式，并把差分预测还原到原尺度。
- 在固定差分和趋势口径下建立简约候选，检查收敛和根。
