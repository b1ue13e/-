# 🧭 阶段0｜前置知识

## 为什么现在学

时序模型的第一类错误通常不是选阶，而是日期、频率、缺失、公布延迟或切分错误。先建立可信数据对象，后续公式才有意义。

## 有序学习清单

1. [[时间序列分析-Python与表格数据最小桥接]]：运行脚本、读取表格、排序和缺失检查。
2. [[时间序列分析-描述统计与相关性最小桥接]]：均值、方差、协方差、相关与条件均值。
3. [[时间序列分析-矩阵运算与线性模型最小桥接]]：矩阵维度、乘法与线性模型记号。
4. [[L00-环境与时间索引]]：把前置能力用于环境、预测原点、规则索引与信息边界。

## 学完能做什么

- 运行最小 Python 脚本，读取并验证一张带日期的表。
- 手算均值、样本方差和相关系数，解释相关不等于因果。
- 检查矩阵乘法维度，读懂线性模型的向量记号。
- 发现乱序、重复日期、缺行和空值，并说明信息可得性。
