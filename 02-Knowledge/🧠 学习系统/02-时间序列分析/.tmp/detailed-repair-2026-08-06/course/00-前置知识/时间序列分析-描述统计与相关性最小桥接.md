# 时间序列分析｜描述统计与相关性最小桥接

## 本课程需要什么

你需要能计算和解释均值、方差、协方差、相关系数与条件期望的最小含义。完整概率论、估计理论和渐近理论不在本卡展开。

## 定义与符号

对样本 $x_1,\ldots,x_n$：

$$
\bar x=\frac1n\sum_{t=1}^n x_t,
\qquad
s_x^2=\frac1{n-1}\sum_{t=1}^n(x_t-\bar x)^2.
$$

对成对样本 $(x_t,y_t)$：

$$
s_{xy}=\frac1{n-1}\sum_{t=1}^n(x_t-\bar x)(y_t-\bar y),
\qquad
r_{xy}=\frac{s_{xy}}{s_xs_y}.
$$

- 方差衡量围绕均值的平方离散程度，非负且带平方量纲。
- 协方差的符号表示共同变化方向，大小受量纲影响。
- 相关系数无量纲并位于 $[-1,1]$，但相关不代表因果。
- $E(Y\mid\mathcal F_t)$ 表示在时点 $t$ 已知信息下对 $Y$ 的条件均值，是点预测的重要目标。

## 手算例子

令 $x=(1,2,3)$、$y=(2,4,6)$。两者均围绕各自均值同向变化，因此样本相关系数为 1。若把 $y$ 改为 $(200,400,600)$，协方差随量纲放大，但相关仍为 1。

## 最小可运行例子

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0])
y = np.array([2.0, 4.0, 6.0])

sample_variance = np.var(x, ddof=1)
sample_covariance = np.cov(x, y, ddof=1)[0, 1]
sample_correlation = np.corrcoef(x, y)[0, 1]

assert np.isclose(sample_variance, 1.0)
assert np.isclose(sample_correlation, 1.0)
print(sample_variance, sample_covariance, sample_correlation)
```

## 常见错误

1. 混用总体分母 $n$ 与样本分母 $n-1$，却不声明口径。
2. 看到高相关就宣称存在机制因果。
3. 把无条件均值与给定历史信息后的条件均值混为一谈。
4. 忽略异常值、趋势或共同季节性会制造高相关。

## 与本课程的连接

- 自协方差是把同一序列的不同时点组成一对变量。
- 弱平稳要求均值、方差和只依赖滞后的自协方差保持稳定。
- ACF 是自协方差的标准化；滚动误差指标仍依赖均值和尺度概念。
