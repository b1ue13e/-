# 差分运算

> [!tip] 这张卡怎么学（45 分钟）
> 1. 手算 `10, 12, 15, 19, 24` 的一阶和二阶差分。
> 2. 把每个公式重新代回这组数字，不要直接背算子。
> 3. 运行代码，比较差分前后的时序图与 ACF。
>
> **过关问题**：差分为什么能消除随机趋势？过度差分为什么常产生一阶负相关？

差分通过比较相隔固定时间的观测来消除水平变化，使均值结构更接近平稳。一阶差分为

$$
\Delta y_t=y_t-y_{t-1}=(1-B)y_t,
$$

它把随机游走 (y_t=y_{t-1}+\varepsilon_t) 转化为白噪声 (\Delta y_t=\varepsilon_t)。二阶差分是“变化的变化”：

$$
\Delta^2y_t=y_t-2y_{t-1}+y_{t-2}=(1-B)^2y_t.
$$

实践中很少需要超过二阶；高阶差分通常意味着模型设定或结构理解有问题。

## 1. 季节差分

周期为 (m) 的季节差分定义为

$$
\Delta_m y_t=y_t-y_{t-m}=(1-B^m)y_t.
$$

若同时需要普通和季节差分，

$$
(1-B)(1-B^m)y_t
=y_t-y_{t-1}-y_{t-m}+y_{t-m-1}.
$$

两种算子可交换，但强季节数据通常先检查季节差分，因为它可能已足以平稳，无需再做普通差分。

```python
import pandas as pd

d1 = y.diff(1)
ds = y.diff(12)
d1s = y.diff(12).diff(1)
result = pd.concat({"level": y, "d1": d1,
                    "d12": ds, "d12_d1": d1s}, axis=1)
```

## 2. 如何决定差分次数

1. 画原序列并识别趋势、季节、方差变化和结构突变。
2. 用 ACF 的慢衰减、[[单位根检验]]与领域解释判断随机趋势，而不是只看一个 p 值。
3. 每做一次差分就重新画时序图和 ACF，选择使均值稳定的最少次数。
4. 对季节数据分别判断 (D) 与 (d)，不要把长期趋势和季节重复混为一谈。
5. 在[[ARIMA模型]]中用滚动预测比较相邻差分设定。

## 3. 差分后的解释与还原

差分模型预测的是变化量，回到原尺度需累加最后观测。多步预测区间也必须传播累积创新的不确定性，不能只把差分点预测简单相加后沿用原区间。对数后差分近似增长率：(\Delta\log y_t\approx(y_t-y_{t-1})/y_{t-1})，但反变换到水平时需要考虑偏差修正。

## 4. 过度差分与边界

过度差分会增加噪声方差，并常在一阶 ACF 产生明显负相关；模型可能用 MA 项去补偿人为制造的结构。确定性趋势适合回归去趋势，随机趋势才需要差分。结构突变、季节长度变化和多重季节性也不能靠不断差分解决。每次差分还损失前端观测，短序列尤其要克制。

## 5. 开放教材定位

FPP3 §9.1 给出普通与季节差分的建模语境，§9.2 用滞后算子统一推导。验收标准是能展开组合差分、解释差分后变量含义，并识别过度差分的 ACF 迹象。
