# 时间序列参数估计

> [!tip] 这张卡怎么学（60 分钟）
> 1. 先固定一个 AR(1)，理解“结构已知、参数未知”。
> 2. 比较 OLS、条件平方和与最大似然各自使用了什么信息。
> 3. 用两个候选的 log-likelihood 和参数数目手算一次 AIC。
>
> **过关问题**：为什么最大似然更高的模型不一定应该被选择？

模型阶数确定后，参数估计要从相关观测中恢复 AR、MA、常数和创新方差。对 ARIMA 模型，现代软件通常使用最大似然估计（MLE）：选择参数 (\vartheta) 使观测序列的联合似然最大，等价于最小化负对数似然。

若给定参数后能递推得到一步创新 (\varepsilon_t(\vartheta))，高斯条件下目标大致包含

$$
-2\ell(\vartheta)
=T\log(2\pi)+T\log(\sigma^2)
+\frac{1}{\sigma^2}\sum_t\varepsilon_t(\vartheta)^2,
$$

但初始状态、差分、精确似然与条件似然的处理会影响有限样本结果。因此不同软件或优化器给出略有差异并不必然是错误，必须同时记录实现、初始化和收敛信息。

## 1. AR 与 MA 的估计差异

平稳 AR 模型在适当条件下可用 OLS，把滞后观测当预测变量；Yule–Walker 则用样本自协方差解线性方程。MA/ARMA 的创新不可直接观测，目标对参数非线性，通常需要数值优化。条件平方和可提供快速初值，精确 MLE 则通过状态空间/Kalman 递推更完整地处理初始状态。

## 2. 估计不是选阶

MLE 在给定阶数内找最佳参数；阶数比较需要惩罚复杂度。对固定差分阶数，

$$
\mathrm{AIC}=-2\ell+2k,
\qquad
\mathrm{BIC}=-2\ell+k\log T,
$$

小样本优先查看 AICc。差分阶数改变了参与似然的数据，因此不同 (d,D) 的 AIC/AICc 通常不可直接横比；先依据平稳性和可解释性确定差分，再比较 (p,q,P,Q)。

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA

rng = np.random.default_rng(66)
noise = rng.normal(size=340)
y = np.zeros(340)
for t in range(2, len(y)):
    y[t] = 0.5 * y[t - 1] - 0.15 * y[t - 2] + noise[t] + 0.3 * noise[t - 1]
train = pd.Series(y[40:])

fit = ARIMA(train, order=(2, 0, 1), trend="c",
            enforce_stationarity=True,
            enforce_invertibility=True).fit()
print(fit.aicc, fit.mle_retvals.get("converged"))
print(fit.params, fit.bse)
```

## 3. 估计后的必要检查

1. 优化器是否收敛，是否出现边界解、奇异 Hessian 或巨大标准误。
2. AR 根是否满足平稳性、MA 根是否满足可逆性；接近单位圆意味着估计与长期预测敏感。
3. 参数符号和量级是否与 ACF/PACF 及业务机制一致。
4. 创新残差是否均值近零、无自相关；区间预测还要检查方差稳定与覆盖率。
5. 轻微改变样本窗口或初值后，参数与预测是否稳定。

## 4. 不确定性与误区

参数点估计不是事实常数。标准误依赖模型正确设定和渐近近似；残差异方差、厚尾或结构突变会使常规区间失真。系数显著也不保证样本外预测提升，多个强相关滞后可能单个不显著却联合有用。不要删除所有“不显著”项后反复重估而不重新验证，这会忽略选择带来的不确定性。

## 5. 知识连接与数值验收

具体结构分别见[[AR模型]]、[[MA模型]]与[[ARMA模型]]；本卡只处理“结构给定后怎样估计并判断是否可信”。信息准则口径见[[L07-模型识别与参数估计]]，残差验收连接[[纯随机性检验]]。

例如两个同差分阶数模型的对数似然分别为 -100、-98，参数数分别为 3、6，则 AIC 分别为 206 与 208：复杂模型虽提高拟合似然，却没有抵消新增参数惩罚。验收表应列出估计值、标准误、置信区间、根模、收敛状态、AICc 与滚动预测误差，避免只粘贴一列系数。
