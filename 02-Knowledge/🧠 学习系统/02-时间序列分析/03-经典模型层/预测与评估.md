# 时间序列预测与评估

> [!tip] 这张卡怎么学（60 分钟）
> 1. 画出一个训练窗口和未来测试窗口，明确每个预测时点能看到什么。
> 2. 手算两组预测的 MAE 与 RMSE，观察指标如何偏重大误差。
> 3. 做 rolling-origin，并按 1、3、6、12 步分别汇总结果。
>
> **过关问题**：为什么训练残差不能替代样本外误差？为什么必须保留 naïve 基线？

时间序列评估必须模拟真实预测时刻：任何时点的模型只能看到该时点之前的信息。随机打乱交叉验证会把未来泄漏到过去，低估真实误差。训练残差也不等于预测误差：残差来自已参与拟合的数据且通常是一步创新；测试误差来自未见未来，可以是多步预测。

$$
e_{T+h}=y_{T+h}-\hat y_{T+h|T}.
$$

## 1. 划分与滚动起点

单次留出应保证测试集至少覆盖目标最大预测步长，季节任务最好覆盖完整季节周期。更稳健的方法是 rolling forecasting origin：逐步向前移动预测起点，每次只用过去拟合，对固定 (h) 预测未来，再按步长分别聚合误差。

```python
import numpy as np
from sklearn.model_selection import TimeSeriesSplit

rng = np.random.default_rng(68)
y = 50 + 0.03 * np.arange(120) + rng.normal(size=120)
cv = TimeSeriesSplit(n_splits=5, test_size=12)
scores = []
for train_idx, test_idx in cv.split(y):
    train, test = y[train_idx], y[test_idx]
    # 预处理、选阶和估计都必须在本轮 train 内完成
    naive = np.repeat(train[-1], len(test))
    scores.append(np.mean(np.abs(test - naive)))
print("fold MAE:", np.round(scores, 3), "mean:", round(float(np.mean(scores)), 3))
```

扩展窗口不断累积历史，适合参数较稳定的过程；滑动窗口只保留最近样本，适合可能漂移的过程。窗口类型、初始训练长度、步长和预测 horizon 必须与上线场景一致。

## 2. 点预测指标

$$
\mathrm{MAE}=\operatorname{mean}|e_t|,
\qquad
\mathrm{RMSE}=\sqrt{\operatorname{mean}(e_t^2)}.
$$

MAE 与原变量同尺度、对极端误差相对稳健；RMSE 更强调大误差。MAPE 在真实值为零或接近零时失效，也要求尺度有有意义的零点。跨序列比较可使用 MASE：用训练集 naïve 或 seasonal naïve 的平均绝对误差缩放；MASE 小于 1 表示优于相应朴素基线。

## 3. 区间与分布预测

只比较点误差会忽略不确定性。对 80%/95% 预测区间至少报告：

- **覆盖率**：真实值落入区间的比例，应接近名义水平；
- **平均宽度**：在覆盖合理时越窄越有信息；
- **按 horizon 分层**：远期区间通常更宽，不能把所有步长混成一个数字。

若模型给出完整预测分布，应使用 proper scoring rule（如 log score、CRPS 或区间分数），避免通过无限加宽区间换取覆盖率。

## 4. 必须存在的基线

非季节序列至少比较均值、naïve 和 drift；季节序列必须比较 seasonal naïve。复杂 ARIMA/SARIMA 若不能稳定胜过基线，就没有证据证明复杂度有价值。比较应在相同预测起点、相同 horizon、相同缺失处理和相同变换还原方式下进行。

## 5. 评估陷阱

- 在全序列上标准化、差分阶数选择或异常值修复后再切分。
- 反复查看最终测试集并继续调参，使测试集退化为验证集。
- 只报所有步长平均值，掩盖关键 horizon 上的失败。
- 对数尺度训练后直接指数反变换，忽略均值预测的变换偏差。
- 只检查残差白噪声；残差合格是必要诊断，不是样本外优胜证明。

## 6. 知识连接与数值验收

这套协议适用于[[ARIMA模型]]、[[SARIMA模型]]以及机器学习预测器；变化的是拟合器，不变的是信息边界。例如真实值为 `[100, 110]`，模型 A 预测 `[90, 120]`，MAE 与 RMSE 都是 10；模型 B 预测 `[100, 130]`，MAE 仍是 10，但 RMSE 约为 14.14，说明 RMSE 对单个大误差惩罚更重。指标必须与[[模型评估指标]]和业务损失一致。

残差阶段连接[[纯随机性检验]]，候选管理连接[[模型识别]]：前者回答“是否遗漏线性结构”，后者回答“哪组候选更合适”，二者都不能替代样本外预测。验收表至少包含模型、预测起点、horizon、MAE、RMSE、MASE、区间覆盖率和运行版本。

## 7. 开放教材定位

FPP3 §5.8 建立测试集、预测误差与尺度化指标，§5.10 给出滚动预测起点。验收标准是可复现的时间切分表、逐 horizon 指标、朴素基线和区间覆盖，而非单个训练 RMSE。
