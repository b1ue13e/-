# L09｜滚动预测与模型评估

> **预计用时**：90 分钟　**当前掌握**：0 / 1 / 2 / 3

## 0. 这节课解决什么问题

一个模型可以训练拟合很好、残差也没有明显自相关，却在真实未来输给“直接使用最后一个值”。前八课回答了模型是否合理；本课回答更严格的问题：

> **站在过去的每个预测时点，只使用当时可见的信息，这个模型能否稳定胜过简单基线？**

本课完成整个时间序列课程闭环：从公式与诊断走向可复现的预测决策。

## 1. 学习目标

学完后，不看笔记能够：

- 区分训练残差、验证误差和最终测试误差；
- 设计 expanding-window 或 rolling-window 评估；
- 按预测步长分别计算 MAE、RMSE 与 MASE；
- 选择与任务匹配的 naïve/seasonal naïve 基线；
- 同时评估预测区间覆盖率和宽度；
- 识别预处理、调参和反复查看测试集造成的数据泄漏。

## 2. 课前诊断

> [!question] 先判断
> 时间序列不能随机打乱，所以只要按时间做一次 80/20 切分，评估结果就足够可靠。对吗？

> [!answer]- 诊断答案
> 不一定。一次切分可能刚好落在异常、旺季或制度变化附近，结论对预测起点很敏感。滚动预测使用多个历史起点，更接近模型反复上线使用的过程；最终仍可保留一个完全未参与选择的测试段。

## 3. 为什么训练残差不是预测误差

训练残差通常来自已参与参数估计的数据，而且多为一步预测误差；真实任务可能要求未来 1、3、6 或 12 步预测。

样本外预测误差定义为：

$$
e_{T+h}=y_{T+h}-\hat y_{T+h|T},
$$

其中 $\hat y_{T+h|T}$ 只能使用时点 $T$ 及之前的信息。若预处理、异常修复或选阶看到了 $T$ 之后的数据，误差就不再是诚实的样本外误差。

## 4. 滚动预测起点如何工作

假设最大预测步长为 3：

```text
起点 1： [训练训练训练训练] | 预测 h=1,2,3
起点 2： [训练训练训练训练训练] | 预测 h=1,2,3
起点 3： [训练训练训练训练训练训练] | 预测 h=1,2,3
```

每移动一次起点，都必须只用新的过去重新完成需要学习的数据步骤。

- **扩展窗口**：训练集不断增长，适合机制较稳定且旧数据仍有价值的过程；
- **滑动窗口**：只保留最近固定长度，适合存在漂移、旧机制可能失效的过程。

窗口类型不是超参数装饰，而是对“历史多久仍有用”的业务假设。

## 5. 必须按 horizon 分开评估

一步预测和十二步预测是不同任务。把所有误差混成一个均值，可能掩盖模型只在短期有效或在远期崩溃。

最低报告形式：

| 模型 | h=1 MAE | h=3 MAE | h=6 MAE | h=12 MAE |
|---|---:|---:|---:|---:|
| naïve |  |  |  |  |
| seasonal naïve |  |  |  |  |
| ARIMA/SARIMA |  |  |  |  |

若业务只关心未来 3 期，就应提前把 h=3 指标设为主要决策指标，而不是事后挑模型表现最好的 horizon。

## 6. 手算 MAE 与 RMSE

真实值为 `[100, 110]`：

- 模型 A 预测 `[90, 120]`，误差绝对值为 `[10, 10]`；
- 模型 B 预测 `[100, 130]`，误差绝对值为 `[0, 20]`。

两者 MAE 都是 10，但：

$$
\mathrm{RMSE}_A=10,
\qquad
\mathrm{RMSE}_B=\sqrt{(0^2+20^2)/2}\approx14.14.
$$

- MAE 与原变量同尺度，对单个极端误差较稳健；
- RMSE 更重罚大误差；
- 应根据实际损失选择主要指标，而不是选择让模型最好看的指标。

## 7. MASE：把误差放到基线尺度上

跨不同尺度的序列比较时，可使用 MASE：

$$
\mathrm{MASE}=
\frac{\operatorname{mean}|e_t|}
{\frac{1}{T-m}\sum_{t=m+1}^{T}|y_t-y_{t-m}|}.
$$

非季节序列常取 $m=1$；季节任务使用季节周期 $m$。分母只能用训练数据计算，避免未来泄漏。

- MASE $<1$：平均绝对误差优于相应训练期朴素尺度；
- MASE $>1$：没有优于该基准；
- 若训练序列几乎不变化，分母可能为零或很小，此时 MASE 不稳定。

## 8. 基线是最低证据门槛

至少根据任务比较：

- **mean**：稳定水平序列；
- **naïve**：随机游走型或短期持久序列；
- **drift**：带稳定长期变化的非季节序列；
- **seasonal naïve**：有稳定季节重复的序列。

复杂模型若只比一个不合适的弱基线好，不能证明有价值。所有模型必须使用相同预测起点、horizon、缺失处理和逆变换口径。

## 9. 可运行的滚动评估骨架

下面只依赖 NumPy，先用两个朴素预测器学会评估协议；之后把 `forecast_fn` 换成 ARIMA/SARIMA 拟合器。

```python
import numpy as np

def naive_forecast(train, horizon):
    return np.repeat(train[-1], horizon)

def seasonal_naive_forecast(train, horizon, season=4):
    last_season = np.asarray(train[-season:])
    return np.resize(last_season, horizon)

def rolling_errors(y, initial, horizon, forecast_fn):
    y = np.asarray(y, dtype=float)
    rows = []
    for origin in range(initial, len(y) - horizon + 1):
        train = y[:origin]
        pred = np.asarray(forecast_fn(train, horizon))
        actual = y[origin:origin + horizon]
        for h, (a, p) in enumerate(zip(actual, pred), start=1):
            rows.append((origin, h, a - p))
    return rows

y = [10, 14, 18, 22, 12, 16, 21, 25, 13, 18, 23, 27]
rows = rolling_errors(
    y, initial=8, horizon=3,
    forecast_fn=lambda train, h: seasonal_naive_forecast(train, h, season=4),
)

for h in (1, 2, 3):
    errors = np.array([e for _, step, e in rows if step == h])
    mae = np.mean(np.abs(errors))
    rmse = np.sqrt(np.mean(errors ** 2))
    print(h, round(mae, 3), round(rmse, 3))
```

这个骨架使用扩展窗口。若每个起点都要重新选择变换、阶数或标准化参数，这些操作必须写在循环内部，并且只能读取该起点的 `train`。

## 10. 区间预测：覆盖率与宽度缺一不可

对名义 80% 或 95% 预测区间至少报告：

$$
\text{coverage}=\operatorname{mean}(L_t\le y_t\le U_t),
$$

$$
\text{width}=\operatorname{mean}(U_t-L_t).
$$

只追求覆盖率会鼓励无限加宽区间；只追求窄区间又会频繁漏掉真实值。应按 horizon 同时报告覆盖和宽度，或使用会同时惩罚漏覆盖与过宽的 proper scoring rule。

样本很少时，覆盖率只能取少数离散值。例如 10 次预测中的 9 次覆盖是 90%，不能据此断言真实覆盖已经精确校准。

## 11. 最常见的数据泄漏

- 在全序列上决定对数变换、差分阶数或异常值阈值后再切分；
- 用未来数据计算标准化均值和方差；
- 查看最终测试集后继续改阶数、指标或特征；
- 滚动评估时只更新预测，不重新拟合需要更新的模型；
- 预测对数尺度后直接指数还原，却不说明目标是中位数还是均值；
- 使用修订后的历史数据预测当时尚未公布的“最终值”。

## 12. 决策不是“谁平均分最低”

最终选择还要回答：

1. 关键 horizon 是否稳定优于基线？
2. 优势是否跨多个预测起点，而非由一个异常窗口贡献？
3. 区间是否合理校准？
4. 模型是否经常失败、难以收敛或对窗口敏感？
5. 微小精度提升是否值得额外维护和解释成本？

没有模型胜过基线也是有效结论。它告诉你当前数据和特征不足以支持更复杂的方法。

## 13. 当堂练习

1. 模型 A 与 B 的 MAE 相同但 RMSE 不同，说明 RMSE 对什么更敏感？
2. 为什么季节序列的 MASE 分母应使用 $y_t-y_{t-m}$ 而不是固定使用一阶差？
3. 滚动评估中在全数据上先做标准化，泄漏发生在哪里？
4. 95% 区间覆盖率为 99%，是否一定优于覆盖率 94% 的模型？

> [!answer]- 当堂练习答案
> 1. 对少数较大的误差更敏感。  
> 2. 因为需要用与任务匹配的 seasonal naïve 误差缩放，避免把正常季节跳动错误地当成基线困难。  
> 3. 标准化参数包含未来观测信息，使每个历史起点间接看到了未来。  
> 4. 不一定。99% 可能来自过宽区间；应同时比较宽度或 proper score，并考虑样本量不确定性。
