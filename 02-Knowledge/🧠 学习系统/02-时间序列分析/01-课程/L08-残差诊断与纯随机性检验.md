# L08｜残差诊断与纯随机性检验

> **预计用时**：75 分钟　**当前掌握**：0 / 1 / 2 / 3

## 0. 这节课解决什么问题

模型拟合结束后，不能立刻预测。你要先问：**模型声称已经解释的部分，是否真的从残差中消失了？**

残差诊断像老师批改解题过程：答案看似漂亮，但草稿里若还存在规律性错误，说明方法没有学会问题的结构。

本课不把“大 p 值”当合格章，而是训练你定位模型遗漏了什么、检验没有检查什么，以及何时应回到模型识别阶段。

## 1. 学习目标

学完后，不看笔记能够：

- 区分创新、训练残差和样本外预测误差；
- 用时间图、残差 ACF 和 Ljung–Box 完成线性相关诊断；
- 手算一个低阶 Ljung–Box 统计量；
- 为 ARIMA/SARIMA 残差正确说明自由度修正；
- 解释大 p 值不能证明独立、正态或模型正确；
- 根据残差模式提出下一步，而不是盲目加阶。

## 2. 课前诊断

> [!question] 先判断
> Ljung–Box 检验得到 $p=0.72$，所以残差已经证明为独立同分布的正态白噪声，模型可以上线。对吗？

> [!answer]- 诊断答案
> 不对。它只表示在指定滞后、样本量和检验功效下，没有足够证据拒绝“这些自相关同时为零”。它不证明独立、正态、方差稳定、没有结构变化，也不证明样本外预测优于基线。

## 3. 先分清三种误差

| 名称 | 何时得到 | 用途 |
|---|---|---|
| 创新 $\varepsilon_t$ | 理论数据生成过程中 | 表示时点 $t$ 的新信息 |
| 训练残差 $e_t$ | 模型在训练样本上的一步预测后 | 检查拟合后是否遗留结构 |
| 测试预测误差 | 真实未来出现后 | 衡量未见数据上的预测价值 |

训练残差通常是创新的估计，但并不等于真实创新；它还受参数估计、初始化和模型错设影响。训练残差合格也不能替代下一课的测试误差。

## 4. 合格创新残差应满足什么

最低要求是：

1. 均值接近零，没有持续高估或低估；
2. 没有剩余自相关，即线性可预测信息基本提取完；
3. 若需要概率预测，方差和分布假设还应足以支持区间计算。

前两项是均值预测的核心诊断。正态性不是获得无偏点预测的必要条件，但重尾、偏态和异方差会影响预测区间与风险判断。

## 5. 三步诊断：先看图，再做联合检验

### 第一步：残差时间图

寻找：

- 均值偏离零；
- 波动逐渐扩大或成簇；
- 异常点；
- 周期重复；
- 某一时点前后行为改变。

### 第二步：残差 ACF

ACF 帮助定位遗漏结构在哪些滞后。白噪声下，单个样本自相关常用

$$
\pm\frac{1.96}{\sqrt T}
$$

作为粗略参考带。但同时查看很多柱时，偶尔越界并不意外，不能看到一根柱便机械加一个参数。

### 第三步：Ljung–Box 联合检验

它回答“前 $h$ 阶自相关是否联合为零”：

$$
Q^*=T(T+2)\sum_{k=1}^{h}\frac{r_k^2}{T-k}.
$$

小 p 值提示至少存在某些剩余相关；具体遗漏发生在哪里，仍要回到时间图与 ACF 定位。

## 6. 手算一次 Ljung–Box

设 $T=100$，只检查前两阶，$r_1=0.10$、$r_2=0.05$：

$$
Q^*=100\times102\left(\frac{0.10^2}{99}+\frac{0.05^2}{98}\right)
\approx1.29.
$$

若这是原始白噪声候选，可用近似 $\chi^2_2$ 参考；$1.29$ 并不算异常大。真正报告时应给出 $h$、自由度、统计量和 p 值，而不是只写“通过”。

## 7. 为什么拟合残差要扣自由度

参数是用同一批数据估出来的，模型已经主动吸收了一部分样本相关。对 ARMA$(p,q)$ 残差，常用近似自由度：

$$
h-p-q.
$$

对乘法季节模型，通常还应计入季节 AR/MA 参数，使用 $h-(p+q+P+Q)$；差分阶数 $d,D$ 一般不作为已估 AR/MA 参数扣除。具体软件实现可能不同，报告时必须写明 `model_df`。

要求 $h$ 明显大于被扣除的模型自由度，否则检验几乎没有可用自由度。季节序列的 $h$ 还应覆盖至少一个季节周期，但不能相对样本量无限增大。

## 8. 读懂不同滞后的信息

| 残差现象 | 可能遗漏 | 下一步 |
|---|---|---|
| lag 1 附近连续相关 | 低阶 AR/MA 或过度差分 | 回看差分与低阶候选 |
| $m,2m$ 季节峰 | 季节 AR/MA 或季节差分 | 检查周期与季节结构 |
| 均值长期偏正/偏负 | 截距、漂移或系统偏差 | 检查趋势项与变换还原 |
| 波动成簇 | 条件异方差 | 看平方残差 ACF/ARCH 检验 |
| 个别巨大尖峰 | 异常、干预或数据问题 | 核实事件，不先盲目加阶 |
| 某时点后整体改变 | 结构突变 | 分段、干预或更新窗口 |

这张表提供调查方向，不是从症状到模型的自动处方。

## 9. 最小代码实验

运行前预测：若模型遗漏季节项，残差 ACF 在季节滞后附近可能突出，覆盖该周期的 Ljung–Box 更容易拒绝原假设。

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.graphics.tsaplots import plot_acf
from statsmodels.stats.diagnostic import acorr_ljungbox
import matplotlib.pyplot as plt

# 构造 AR(1) 样本并拟合正确的 ARIMA(1,0,0)，使代码可独立运行
rng = np.random.default_rng(8)
noise = rng.normal(size=260)
y = np.zeros(260)
for t in range(1, len(y)):
    y[t] = 0.65 * y[t - 1] + noise[t]
series = pd.Series(y[20:])
p, q, P, Q = 1, 0, 0, 0
fit = ARIMA(series, order=(p, 0, q)).fit()

# 使用训练样本的一步创新残差；必要时去掉初始化阶段
residuals = fit.resid.dropna()

fig, axes = plt.subplots(2, 1, figsize=(9, 6))
axes[0].plot(residuals)
axes[0].axhline(0, color="black", linewidth=1)
axes[0].set_title("Residuals over time")
plot_acf(residuals, lags=24, ax=axes[1])
plt.tight_layout()

table = acorr_ljungbox(
    residuals,
    lags=[12, 24],
    model_df=p + q + P + Q,
    return_df=True,
)
print(table)
# 输出：lag 12 和 24 的 lb_stat/lb_pvalue；正确设定下通常不拒绝白噪声
```

不要事后尝试许多 $h$，只汇报最有利的 p 值。应根据预测任务、季节周期和样本量预先规定主要滞后，并可补充少量敏感性结果。

## 10. 线性白噪声之外还要检查什么

原残差无自相关，不代表没有非线性依赖。最常见反例是波动聚集：

- 原残差 ACF 可能接近零；
- 平方残差或绝对残差 ACF 却显著；
- 均值模型可能尚可，但正态等方差预测区间会失真。

若目标涉及风险、尾部或区间预测，应检查平方残差、分位数图、覆盖率和异常事件。不要为了让直方图更像正态而忽略时间结构。

## 11. 常见错误

- 对原序列做 Ljung–Box，却声称检验的是模型残差。
- 只看一个 p 值，不报告 $h$ 和自由度修正。
- 把不拒绝原假设写成“证明白噪声”。
- 选择 p 值最大的模型；p 值不是模型评分。
- 发现残差相关便无条件增加阶数，不检查差分、异常或季节周期。
- 残差合格后跳过样本外评估。

## 12. 当堂练习

1. $T=100,r_1=0.10,r_2=0.05$ 时，为什么不能分别看两根 ACF 柱代替联合检验？
2. ARIMA$(2,1,1)(1,1,0)_{12}$ 在 $h=24$ 时，常用残差检验自由度是多少？
3. 残差 ACF 无明显峰，但平方残差 ACF 有连续相关，这提示什么？
4. $p=0.40$ 与 $p=0.80$ 的两个候选，能否仅据此选择后者？

> [!answer]- 当堂练习答案
> 1. 单柱检查不能直接回答多个自相关是否联合为零，而且同时查看多根柱有多重比较问题。  
> 2. 扣除 $p+q+P+Q=2+1+1+0=4$，近似自由度为 $24-4=20$；报告时还要说明软件口径。  
> 3. 可能存在条件异方差或波动聚集，需要检查 ARCH/GARCH 类结构和区间可靠性。  
> 4. 不能。两者都只是未发现指定范围的相关，应再比较简洁性、稳定性和样本外预测。
