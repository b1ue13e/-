# 纯随机性检验

> [!tip] 这张卡怎么学（45 分钟）
> 1. 先写出原假设：前 \(h\) 阶自相关同时为零。
> 2. 比较“看单根 ACF 柱”和“Ljung–Box 联合检验”的问题差异。
> 3. 对同一残差用两个滞后长度检验，并解释结论为何可能不同。
>
> **过关问题**：大 p 值没有证明哪些事情？为什么 ARMA 残差要扣自由度？

纯随机性检验判断一段序列在给定滞后范围内是否还保留线性可预测结构。时间序列建模中，它通常用于检验**创新残差是否近似白噪声**：若残差仍显著自相关，说明模型没有提取完可利用的信息。通过检验只表示“没有发现指定形式的相关”，不证明独立、正态，更不证明模型唯一正确。

## 1. Ljung–Box 联合检验

对样本量 (T)、样本自相关 (r_k) 和最大滞后 (h)，Ljung–Box 统计量为

$$
Q^*=T(T+2)\sum_{k=1}^{h}\frac{r_k^2}{T-k}.
$$

原假设是前 (h) 阶总体自相关同时为零。大样本下，原始序列检验常近似使用 (\chi_h^2)；若检验的是拟合 ARMA/ARIMA 模型残差，应扣除已估计的 AR、MA 参数自由度，常写成 (h-p-q)。小 p 值表示至少某些滞后仍有相关；大 p 值只是“现有样本不足以拒绝白噪声”。

```python
from statsmodels.stats.diagnostic import acorr_ljungbox

# residuals 应来自训练样本的一步预测创新，而非原序列
table = acorr_ljungbox(residuals, lags=[10, 20],
                       model_df=p + q, return_df=True)
print(table.to_string(columns=["lb_stat", "lb_pvalue"]))
```

## 2. 为什么不能只看一根 ACF 柱

在白噪声下，单个样本 ACF 常以 (\pm1.96/\sqrt T) 作近似参考带。一次查看很多滞后，即使每个滞后都无相关，也可能偶然有约 5% 的柱越界。Ljung–Box 将多个滞后的证据合并，适合回答“整体上是否仍有相关”；[[自相关函数ACF]]图则帮助定位遗漏结构发生在哪些滞后。两者应联合使用，而不是互相替代。

## 3. 检验协议

1. 先画残差时间图，检查均值偏离、方差变化、异常点和结构突变。
2. 预先规定 (h)：季节数据至少覆盖一个到两个季节周期，但 (h) 不应相对样本量过大。
3. 画残差 ACF，再报告 Ljung–Box 的 (h)、自由度修正、统计量和 p 值。
4. 若多组模型都通过检验，使用滚动样本外误差、区间覆盖率和简洁性选择，而非挑 p 值最大者。
5. 若拒绝原假设，根据异常滞后回到[[模型识别]]，考虑遗漏的 AR、MA、季节项或外生变量。

## 4. 边界与反例

- 独立白噪声一定不相关，但“不相关”不保证独立；非线性依赖可能不被 ACF 和 Ljung–Box 捕捉。
- 条件异方差序列的原值可能零自相关，而平方残差显著相关；应额外检查平方残差或 ARCH 检验。
- 原序列通过白噪声检验意味着线性预测空间有限，不代表不存在结构变化、尾部风险或外部变量信号。
- 大样本会检出很弱、业务上无意义的相关；小样本又可能检验功效不足。统计显著性必须结合效应大小和预测收益。

## 5. 开放教材定位
