# 白噪声

白噪声序列表示时间上没有可利用的线性相关结构。它是时间序列模型创新项和残差诊断的核心基线；模型残差若仍有显著自相关，说明模型没有提取完可预测结构。

## 1. 弱白噪声定义

序列 $\{\varepsilon_t\}$ 是弱白噪声，若

$$
E(\varepsilon_t)=0,
\qquad
\operatorname{Var}(\varepsilon_t)=\sigma^2<\infty,
$$

且对所有 $h\ne0$：

$$
\operatorname{Cov}(\varepsilon_t,\varepsilon_{t-h})=0.
$$

因此其理论自相关函数为 $\rho(0)=1$、$\rho(h)=0$（$h\ne0$）。弱白噪声只要求不相关，不保证独立，也不保证高斯分布。

- **独立同分布白噪声**比弱白噪声条件更强。
- **高斯白噪声**若协方差为零，则因联合高斯性可推出独立。

## 2. 样本 ACF 不是精确为零

有限样本的自相关会随机偏离零。对白噪声样本，单个样本自相关常用近似界限

$$
\pm\frac{1.96}{\sqrt{T}}
$$

作粗略判断，但同时查看许多滞后会产生多重比较问题，不能因一根柱越界就机械否定白噪声。

## 3. Ljung–Box 联合检验

Ljung–Box 统计量联合检查前 $m$ 个自相关：

$$
Q=T(T+2)\sum_{h=1}^{m}\frac{\hat\rho_h^2}{T-h}.
$$

原假设是所选滞后范围内自相关均为零。较小的 p 值提示拒绝白噪声假设，但不说明具体应增加哪一阶模型，也不检查异方差等非线性依赖。

## 4. 最小模拟与验证

```python
import numpy as np
from statsmodels.stats.diagnostic import acorr_ljungbox

rng = np.random.default_rng(12)
eps = rng.normal(size=1000)
result = acorr_ljungbox(eps, lags=[10], return_df=True)

assert abs(eps.mean()) < 0.1
assert result.shape == (1, 2)
```

p 值是随机变量，不能把“本次大于 0.05”写成白噪声已被证明。应同时看时序图、[[02-Knowledge/🧠 学习系统/02-时间序列分析/02-统计基础层/自相关函数ACF|ACF]]、方差稳定性和领域背景。

## 5. 模型残差中的作用

对[[02-Knowledge/🧠 学习系统/02-时间序列分析/03-经典模型层/ARMA模型|ARMA]]或[[02-Knowledge/🧠 学习系统/02-时间序列分析/03-经典模型层/ARIMA模型|ARIMA]]，理想残差应近似白噪声。如果残差存在：

- 均值非零：可能遗漏截距或系统偏差；
- 自相关：可能遗漏 AR/MA 或季节结构；
- 波动聚集：可能需要 ARCH/GARCH 类条件方差模型；
- 重尾和异常点：基于正态误差的预测区间可能失真。

## 6. 常见误区

1. 白噪声不等于所有观测值都很小；其幅度由方差决定。
2. 不相关不等于独立，除非有额外分布条件。
3. 白噪声不等于正态分布；可以存在非高斯白噪声。
4. 单个 Ljung–Box p 值不能证明模型正确，只表示当前检验未发现特定线性相关。
