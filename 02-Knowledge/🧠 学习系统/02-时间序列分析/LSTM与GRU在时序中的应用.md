# LSTM与GRU在时序中的应用

> [!NOTE] 核心直觉：带着记事本的快递员
> **类比**：传统的时间序列模型（如 AR）就像一个只有几秒钟记忆的金鱼，只能记住最近的 $p$ 步。普通的 RNN 稍微好点，但容易患上“记忆衰退症”（梯度消失）。
> 
> **LSTM (长短期记忆网络)** 就像是一个拿着高级记事本的快递员。记事本里有三扇门：
> - **遗忘门**：看到新消息后，决定用橡皮擦掉记事本里哪些过期的旧消息。
> - **输入门**：决定把刚收到的哪些新消息写进记事本。
> - **输出门**：决定今天送货时，该根据记事本里的哪部分内容来规划路线。
> 
> **GRU (门控循环单元)** 则是这个快递员的“精简版”，把遗忘门和输入门合并成了一个“更新门”，效率更高，记事效果几乎一样好。

## 1. 为什么需要这个知识点？
- **背景**：在经典模型（ARIMA、VAR）中，我们假设数据生成机制是**线性的**，并且我们只能处理相对短期的滞后效应。
- **痛点**：对于海量、高频、充满复杂非线性规律（比如具有极长周期的金融高频数据、带有复杂文本情绪特征的多模态时序），传统的线性模型或者特征工程完全无能为力。
- **意义**：LSTM 和 GRU 是深度学习统治时间序列序列建模的初代王者，能够自动从海量数据中提取任意长距离的非线性依赖关系。

## 2. 核心机制对比与应用
在时序预测中，时间步 $t$ 的输入通常是一个向量 $x_t$（比如当天的多维特征：量、价、宏观指标），输出则是对未来 $y_{t+1}$ 的预测。

### LSTM 的细胞状态 (Cell State)
LSTM 之所以能在超长的时间跨度上不遗忘，是因为它有一个贯穿整个时间链条的“传送带”——**细胞状态 $c_t$**。
- **状态更新公式**：$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$
  - 过去的记忆 $c_{t-1}$ 只经过了简单的按位乘法 $f_t$（遗忘门）和加法，这就保证了梯度在反向传播时可以**无损地在时间长河中穿梭**，彻底解决了普通 RNN 的梯度消失问题！

### GRU 的精简之道
GRU 认为 LSTM 的细胞状态 $c_t$ 和隐藏状态 $h_t$ 有点多余，于是把它们合并了。
- 它只使用一个状态 $h_t$ 来传递记忆。
- 用 **更新门 (Update Gate, $z_t$)** 同时兼任了 LSTM 中“遗忘旧记忆”和“写入新记忆”的工作：
  $h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$
- **实战经验**：在大多数时序任务（股票预测、需求预测）中，GRU 的预测精度与 LSTM 不相上下，但因为参数减少了 $1/4$，训练速度更快，抗过拟合能力更强，往往是调参的首选首发。

## 3. 具体应用案例
**场景**：预测未来一小时的比特币价格趋势（涨/跌）。
1. **数据切分 (Sliding Window)**：使用过去 60 分钟的 1 分钟级别 K 线数据（包含开盘、最高、最低、收盘、成交量 5 个特征）。于是每一个样本的形状为 `(60, 5)`（Time Steps = 60, Features = 5）。
2. **构建模型**：
   - 输入层传入 `(60, 5)`。
   - 经过一层 GRU 网络（Hidden Size = 64），GRU 会在内部循环 60 次，将这 60 分钟的序列压缩成一个最终的隐藏状态向量，形状为 `(64,)`。
   - 经过一层全连接层（Dense），输出 `(1,)`，通过 Sigmoid 函数映射到 0~1 的涨跌概率。
3. **训练**：使用二元交叉熵损失，用 Adam 优化器训练。模型自动学会了“当遇到连续三根大阴线且放量时，后续反弹概率大”这种复杂的非线性规律，而无需人工定义。

## 4. 常见误区与陷阱 (Pitfalls)
> [!WARNING] 踩坑预警
> - **不加掩码的未来数据穿越**：在构建序列样本时，极容易把 $t+1$ 时刻的特征偷偷放进了 $t$ 时刻的输入里，导致模型在训练集上神准，实盘直接爆仓。
> - **序列未缩放 (Unscaled Data)**：LSTM/GRU 内部大量使用 Sigmoid 和 Tanh 激活函数。如果你的价格数据是 50000 这样的绝对数值，激活函数会瞬间饱和进入“死区”（输出全变成1，梯度为0）。必须做严格的 Z-score 标准化或 Min-Max 归一化。
> - **非平稳性依然致命**：虽然深度学习自诩能拟合一切，但如果用 LSTM 直接去拟合绝对价格（典型的非平稳随机游走序列），模型往往只会学会“用昨天的价格作为今天的预测值”（即 $y_{t+1} \approx x_t$），预测曲线看起来完美贴合，实际上只是整体滞后了一步，毫无实战价值。应该预测差分收益率！
