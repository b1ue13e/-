# 📚 时间序列课程学习面板

> **这是唯一行动入口。**本页只负责回答三个问题：**现在学哪课、怎样算学会、卡住后去哪里。**L00–L09 详纲已合并在本页下方，参考卡只在主课讲解不足时打开。

> 课后习题入口：[[开源课程习题/📚 FPP3课后习题总表|FPP3 开源课程课后习题]]。每完成一课，至少从对应章节选择 1 道手算题和 1 道复现题，作答证据回填到章节练习册。

## 🧭 唯一必修主线

`L00 环境与时间索引` → `L01 平稳性与差分` → `L02 ACF/PACF` → `L03–L04 AR/MA` → `L05–L06 ARIMA/SARIMA` → `L07–L08 识别与诊断` → `L09 滚动评估` → `HW09 综合项目`

> 每次只推进一个 L 课次。A–F 阶段、深挖卡和专题支线都是参考资料，不是今天的任务队列。

## 📚 必修主线详纲

## 开课前：最终要会什么

给你一条时间序列，你应该能够：

1. 判断是否需要变换或差分；
2. 用 ACF/PACF 提出少量候选模型；
3. 估计 ARIMA/SARIMA，并检查残差；
4. 用滚动预测和朴素基线判断模型是否真的有用。

最终作品不是一堆公式，而是一份从数据检查到样本外预测的完整建模报告。

## 第零阶段：把数据和环境变得可信

### 第 0 课：环境、时间索引与信息边界（60–90 分钟）

- 主课：[[L00-环境与时间索引]]
- 必答：一个特征是否泄漏，应该相对哪个时间点判断？
- 动手：运行环境自检，把乱序、重复、缺期数据整理成规则时间索引。
- 过关：能说明频率、季节周期、滞后、预测步长和窗口的区别。

## 第一阶段：平稳化

### 第 1 课：平稳性与差分（60 分钟）

- 主课：[[L01-平稳性与差分]]
- 作业：[[HW01-平稳性与差分阶梯作业]]
- 参考卡：[[平稳性]]、[[差分运算]]、[[单位根检验]]
- 必答：为什么价格水平常不平稳，而收益率可能平稳？
- 动手：画随机游走及其差分，并完成 HW01。
- 过关：能区分确定趋势、随机趋势和季节性，并解释何时不应差分。

### 第 2 课：ACF、PACF 与白噪声（70 分钟）

- 主课：[[L02-ACF-PACF与白噪声]]
- 作业：[[HW02-ACF-PACF与白噪声阶梯作业]]
- 参考卡：[[自相关函数ACF]]、[[PACF（深挖笔记）]]、[[白噪声]]
- 必答：ACF 为零为什么不等于独立？
- 动手：比较白噪声、AR(1)、MA(1) 的 ACF。
- 过关：不背口诀，能从冲击传播解释拖尾和截尾。

## 第二阶段：经典模型

### 第 3 课：AR（75 分钟）

- 主课：[[L03-AR模型与均值回归]]
- 作业：[[HW03-AR模型与均值回归阶梯作业]]
- 参考卡：[[AR模型]]
- 必答：为什么 \(|\phi|<1\) 时冲击会消失？
- 动手：分别模拟 \(\phi=0.7\)、\(-0.7\)、1 的 AR(1)。
- 过关：能写出均值、方差、ACF 和两步预测。

### 第 4 课：MA（70 分钟）

- 主课：[[L04-MA模型与有限冲击]]
- 作业：[[HW04-MA模型与有限冲击阶梯作业]]
- 参考卡：[[MA模型]]
- 必答：MA 模型为什么不是滑动平均平滑？
- 动手：追踪一次创新在 MA(2) 中影响几期。
- 过关：能解释有限冲击响应和可逆性。

### 第 5 课：ARMA 与 ARIMA（90 分钟）

- 主课：[[L05-ARMA与ARIMA建模闭环]]
- 作业：[[HW05-ARMA与ARIMA建模闭环阶梯作业]]
- 参考卡：[[ARMA模型]]、[[ARIMA模型]]、[[模型识别]]、[[参数估计]]
- 必答：ARIMA 中的 `I` 做了什么？
- 动手：给同一序列拟合多个候选，比较残差、滚动预测和 naïve 基线。
- 过关：能从差分序列写回原序列模型，并完成候选提名、筛选、验收。

### 第 6 课：SARIMA（90 分钟）

- 主课：[[L06-SARIMA与季节预测]]
- 作业：[[HW06-SARIMA与季节预测阶梯作业]]
- 参考卡：[[SARIMA模型]]、[[差分运算]]、[[季节性与STL分解]]
- 必答：\((P,D,Q)_m\) 与 \((p,d,q)\) 分别处理什么？
- 动手：手算季节差分，并对月度或季度序列比较 seasonal naïve 与 SARIMA。
- 过关：能展开乘法季节模型、解释交叉滞后，并拒绝没有样本外增益的复杂模型。

## 第三阶段：完成建模闭环

### 第 7 课：模型识别与参数估计（100 分钟）

- 主课：[[L07-模型识别与参数估计]]
- 作业：[[HW07-模型识别与参数估计阶梯作业]]
- 参考卡：[[模型识别]]、[[参数估计]]、[[L07-模型识别与参数估计]]
- 必答：为什么 ACF/PACF 只能提出候选？
- 动手：先冻结候选，再建立包含 AICc、标准误、根、收敛状态和淘汰理由的台账。
- 过关：能区分识别、估计、选择和验收，并写出每个候选被保留或淘汰的证据。

### 第 8 课：残差诊断（75 分钟）

- 主课：[[L08-残差诊断与纯随机性检验]]
- 作业：[[HW08-残差诊断与纯随机性检验阶梯作业]]
- 参考卡：[[纯随机性检验]]、[[白噪声]]、[[自相关函数ACF]]
- 必答：Ljung–Box 大 p 值证明了什么，又没有证明什么？
- 动手：同时检查残差时间图、ACF、Ljung–Box 和平方残差。
- 过关：会做自由度修正，能根据失败模式定位遗漏，并且不把“大 p 值”当作正确证明。

### 第 9 课：滚动预测与模型评估（90 分钟）

- 主课：[[L09-滚动预测与模型评估]]
- 综合作业：[[HW09-滚动预测与完整建模报告]]
- 参考卡：[[预测与评估]]、[[模型评估指标]]、[[纯随机性检验]]
- 必答：为什么训练残差不能代表真实预测误差？
- 动手：做 rolling-origin 评估，逐 horizon 比较基线、候选模型和预测区间。
- 过关：能够识别泄漏，同时报告点误差、区间覆盖率、宽度和基线增益。

## 最终验收项目

最终交付使用：[[HW09-滚动预测与完整建模报告]]。

任选一条至少包含 5 个季节周期的序列，交付：

1. 原序列、差分序列、ACF/PACF；
2. 至少三个候选及选择理由；
3. 参数、根、残差诊断；
4. rolling-origin 评估；
5. 与 naïve/seasonal naïve 的对比；
6. 不超过 200 字的结论：模型能做什么、不能做什么。

## 🧭 45–90 分钟单次学习流程

### 开始前 5 分钟

1. 只打开面板给出的下一课。
2. 不看答案完成“课前诊断”。
3. 写一句：`我预计最容易错在：______`。

### 学习阶段 25–45 分钟

1. 先算具体数字，再读一般公式。
2. 运行代码前写下预期图形或输出。
3. 每读完一节，关闭正文，用自己的话讲 30 秒。
4. 只有主课解释不够时才打开参考卡，不沿链接无限跳转。

### 输出阶段 15–30 分钟

1. 闭卷完成当堂练习。
2. 至少完成对应 HW 的 A、B 两级；完整学习日继续完成后续部分。
3. 对照折叠答案，用“概念错、计算错、条件漏、实现错”标记错误类型。
4. 按下面的掌握量表更新课程 frontmatter。

## 🎚️ 掌握度不是心情分

| mastery | 可观察证据 | 下一步 |
|---:|---|---|
| 0 | 尚未学习，或只能认出名词 | 从主课课前诊断开始 |
| 1 | 跟着例子能做，关闭笔记后不能独立完成 | 重算主例题，再做一道变式 |
| 2 | 能闭卷解释、计算并完成核心作业 | 可以进入下一课 |
| 3 | 能讲给别人、处理变式，并解释方法边界 | 进入综合项目或制作少量 Anki 卡 |

一课只有同时满足以下条件才设置 `status: completed`：

- [ ] `mastery >= 2`
- [ ] 能闭卷回答主课“必答问题”
- [ ] 主课过关清单全部完成
- [ ] 对应作业核心部分已完成并核对
- [ ] 未解决错误已经进入 Review，而不是被遗忘

## 🧯 错题如何回流

错误不是在作业末尾写一个正确答案，而是执行以下闭环：

1. 回到出错主课，将 `flow` 改为 `review`，增加：

```yaml
weak: true
weak_since: YYYY-MM-DD
```

2. 使用[[🧯 错题漏洞笔记模板]]记录：错误答案、错误原因、最小修复和一道变式。
3. 24 小时后闭卷重做；仍错则缩小到前置知识，不继续堆新题。
4. 能独立讲解并通过变式后，主课恢复 `flow: knowledge`，删除或关闭 `weak`。
5. 所有待修项目会进入[[04-🔁 Review]]的薄弱点队列。

## 🗓️ 建议节奏

不要连续阅读九课。默认采用“新课—练习—回忆”的节奏：

| 学习日 | 主任务 | 次日开始前 |
|---|---|---|
| 第 0 天 | L00 + 环境自检 | 重新解释信息边界与时间切分 |
| 第 1 天 | L01 + HW01 | 闭卷解释平稳与差分；重做 L00 的泄漏判断 |
| 第 2 天 | L02 + HW02 + 累计测验 Q1 | 混合辨析白噪声、随机游走和 AR(1) |
| 第 3 天 | L03 + HW03 | 手算 AR(1) 两步预测；复习差分 |
| 第 4 天 | L04 + HW04 + 累计测验 Q2 | 混合辨析 AR 与 MA 的冲击传播 |
| 第 5 天 | L05 + HW05 | 从水平到差分再还原；复查信息边界 |
| 第 6 天 | 旧课修复日 | 随机抽取 L01–L05 题目，修复所有 mastery 1 |
| 第 7 天 | L06 + HW06 + 累计测验 Q3 | 混合普通与季节模型，不只做同类题 |
| 第 8 天 | L07 + HW07 | 冻结候选并解释 AICc；重算 AR/MA 根 |
| 第 9 天 | L08 + HW08 + 累计测验 Q4 | 综合识别、估计与诊断失败模式 |
| 第 10 天 | L09 + HW09 | 完成滚动评估协议 |
| 第 11–14 天 | 综合项目 | 写报告、复现、闭卷答辩；48 小时后重做 Q4 |

时间不足时缩小当天作业范围，不删除闭卷回忆和错误回流。
