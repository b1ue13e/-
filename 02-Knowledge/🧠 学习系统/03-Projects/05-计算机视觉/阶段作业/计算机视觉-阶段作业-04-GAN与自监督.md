# 计算机视觉-HW05：GAN 与自监督表征学习

## 1. 作业身份与来源

- 编号：HW05（stage），CS231n A3 后半段本地化（GAN / Self-Supervised）。
- 许可：公开课程作业本地化，不复制官方解答。

## 2. 学习目标

完成本作业后，应能：训练一个 GAN（生成器+判别器极小极大对抗）并诊断模式崩溃；用 SimCLR 式对比学习在无标签数据上预训练编码器，再把表征迁移到线性分类头验证「表征质量」。

## 3. 任务背景与边界

- 数据集：CIFAR-10（或本地同构子集）。
- 任务 A：GAN 生成逼真样本，定性+定量（如 Inception Score 近似 / FID 近似）评价。
- 任务 B：SimCLR 式对比预训练（同图不同增强为正对），线性评估分类准确率。
- 假设：可用 PyTorch；对比学习用标准 ResNet 小编码器。
- 禁止：用标签做对比学习的正/负对（那不再是自监督）。

## 4. 环境与依赖

- `torch`、`torchvision`、`numpy`、`matplotlib`。
- 运行：`python -m hw05_gan` 与 `python -m hw05_simclr` 或对应 pytest。
- 资源：GPU 推荐；调试用 `num_train=2000`。

## 5. 稳定题号

1. **Q1 GAN**：实现 DCGAN 风格生成器/判别器，交替优化；每 epoch 存生成样本网格。
2. **Q2 GAN 诊断**：识别模式崩溃（生成多样性低）、损失不收敛，记录并尝试至少一种缓解（如标签平滑、TTUR）。
3. **Q3 对比学习**：实现带投影头的编码器，NT-Xent 类损失，温度 `τ` 可调。
4. **Q4 线性评估**：冻结编码器训线性头，报无标签预训练 vs 随机初始化基线的线性分类准确率差。

## 6. 提交产物

- `hw05_gan.py`、`hw05_simclr.py`、`models.py`、`losses.py`。
- `report.md`：GAN 样本演化网格、模式崩溃分析、对比学习温度扫描、线性评估结果表。
- 命令与种子。

## 8. 引导自检（不泄露答案）

- **检查点 C1**：先用极小网络在玩具分布（如 2D 高斯混合）上调通 GAN，再上图像。
- **渐进提示 H1**：对比学习负对数量极大，batch 内负对要排除自身增广（掩码对角线）。
- **调试 D1**：GAN 判别器过强导致生成器梯度消失，先降判别器学习率或加历史重建。
- **调试 D2**：对比学习准确率接近随机，先查「增强是否过强到连同类都认不出」。

## 9. 常见失败

- 生成器与判别器容量/学习率失衡，训练崩成一方碾压。
- 对比学习把同图两个增广当不同样本却未正确屏蔽，损失恒为 0 或 NaN。
- 忘记对图像做归一化到模型期望分布，生成样本全灰。
