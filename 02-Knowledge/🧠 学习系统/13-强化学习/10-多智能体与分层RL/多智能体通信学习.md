# 多智能体通信学习 (Learning to Communicate)

> 所属模块：[[🗺️ 强化学习学习路径|强化学习学习路径]]
> 对应阶段：[[🧭 阶段10-多智能体与分层RL|返回阶段页]]

## 动机
CTDE 训练期用全局、执行期去中心，但若任务**本质需要实时协调**（如"你左我右包抄"），仅靠局部观测无法达成。此时让 Agent 之间**学一种通信协议**就关键了：它们自己决定发什么消息、怎么用，而不是人工规定。

## 正式定义 / 公式
两类主流：
- **CommNet**：各 Agent 把隐状态广播/平均成"群体上下文"，再结合自身观测决策；通信在隐空间、端到端可微、连续消息。
- **DIAL（Differentiable Inter-Agent Learning）**：训练期消息走可微通道（梯度能穿过通信），执行期把连续消息**量化成离散符号**（如 0/1 比特），使协议在部署时廉价、鲁棒；用 REINFORCE/actor-critic 联合训通信与策略。

## 最小手算例子
"找开关开灯"任务：一个 Agent 看到开关位置，另一个在灯处。CommNet 让看到开关的 Agent 把"开关在左"编码进消息广播，灯处 Agent 据此移动；DIAL 在训练中学会用离散比特表示"左/右/已开"，部署时只需传 1~2 比特，省带宽且抗噪。

## 对比与常见错误
- 与纯 CTDE（无通信）：通信解决"必须实时协调"的任务；CTDE 适合"训练期全局够用"的任务。
- 与手写协议：学习到的协议更适配任务，但可能不可解释。
- **常见错误**：通信带宽无限→过拟合到噪声、且部署贵；DIAL 训练期不量化、执行期突然量化导致分布漂移（应训练期也模拟量化梯度）。
