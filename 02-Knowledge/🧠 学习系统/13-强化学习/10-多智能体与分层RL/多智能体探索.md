# 多智能体探索 (Multi-Agent Exploration)

> 所属模块：[[🗺️ 强化学习学习路径|强化学习学习路径]]
> 对应阶段：[[🧭 阶段10-多智能体与分层RL|返回阶段页]]

## 动机
单智能体探索已经难，多智能体更麻烦：**环境对每个 Agent 都不平稳（别人在变）**，且"大家都乱逛"和"协同去不同地方"效果天差地别。好的多智能体探索既要**个体有新信息**，又要**彼此不重复、覆盖全局**。这是把阶段9 的探索思想搬进多智能体场景。

## 正式定义 / 公式
两类思路：
- **协同计数/信息增益**：把"联合状态的新奇度"或"对联合动力学后验的信息增益"当团队内在奖励（如 MAVEN 用隐变量协调各 Agent 的探索方向）。
- **去相关探索（MADE）**：显式让各 Agent 的探索策略**互不相同**（最大化彼此策略距离 / 互信息最小化），避免全队挤在同一状态。形式化如 max 各 Agent 策略互信息差异 + 个体信息增益。

## 最小手算例子
多无人机测绘未知地图：若都用同一探索策略，全飞到同一角落；MADE 让每架无人机走不同方向（策略去相关），MAVEN 用共享隐变量协调"这次整体往北探"。团队覆盖效率远高于"各自乱走"。

## 对比与常见错误
- 与单智能体 RND/ICM：多了"Agent 间协调/去相关"维度，否则团队探索冗余。
- 与 IQL：IQL 各 Agent 独立探索，易撞车/重复，缺乏协同覆盖。
- **常见错误**：只优化个体新奇度→全队挤向同一"最有趣"区；协调变量太弱→探索方向不统一。
