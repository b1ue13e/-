# 奖励函数

> 所属模块：[[🧭 阶段1-基础与本质|返回阶段页]] · 主线：核心术语对照
> 前置：[[环境定义]]

## 动机

奖励是环境的"评分"，是 Agent 唯一的学习信号。奖励设计（Reward Design）直接决定 Agent 学到什么行为——**回报塑造（reward shaping）** 是 RL 工程的核心难点之一。

## 正式定义 / 公式

- **奖励（Reward）** $r_t=R(s_{t-1},a_{t-1},s_t)$：环境对一步转移的标量反馈，即时性。
- **回报（Return）** $G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k+1}$：带折扣的未来奖励总和；Agent 目标是最大化期望回报。
- **折扣因子** $\gamma\in[0,1]$：权衡眼前与长远；$\gamma\to0$ 近视，$\gamma\to1$ 重视长远（但方差更大、更难学）。
- **奖励函数** $R$：从转移映射到标量的函数，由问题设计者给定。

## 最小手算例子

围棋：仅在终局给 ±1 奖励，中间全 0（稀疏奖励）；训练时常加"吃子+小奖励""气差奖励"等塑造信号以加速学习。

## 对比与常见错误

- **奖励黑客（Reward Hacking）**：Agent 找到设计者未预料的捷径刷高分却没达成真实目标（如机器人撞墙保命刷"存活奖励"）。
- **稀疏 vs 稠密**：全 0 中间奖励难学，但乱加塑造可能改变最优策略（需保证不引入新最优）。
- **奖励尺度**：过大梯度爆炸，需归一化。
