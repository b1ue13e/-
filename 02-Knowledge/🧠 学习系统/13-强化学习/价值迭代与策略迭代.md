# 价值迭代与策略迭代

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：贝尔曼方程给出的是"解应满足的自洽条件"，而价值迭代/策略迭代是**第一批真正能算出解的算法**——HW01（CS188 Project 3 的 valueIterationAgent）直接考察；同时"评估—改进"二分法是一切策略优化算法（[[PolicyGradient策略梯度]]、[[PPO近端策略优化]]）的原型，异步迭代思想还出现在 [[DQN深度Q网络]] 的目标网络同步里。Sutton & Barto Ch.4 与 Spinning Up 入门部分均以此为核心。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 上一节写出的贝尔曼方程只是"未知数 $V(s)$ 之间的自洽关系"，并没有给出怎么把它算出来——直接解线性方程组需要 $|\mathcal{S}|$ 个未知数，状态一多（Pacman 的格子）就不可行；而且我们最终要的是**策略**，不是价值表本身。以前的方法（枚举所有策略再逐一评估）随策略数指数爆炸。
> 因此必须引入**动态规划（DP）**：把"求最优策略"拆成反复的两个动作——**策略评估**（给定策略，算它的价值）与**策略改进**（根据价值，换更好的动作），两者交替直到收敛；价值迭代则是把两步合并成一步的加速版。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：不学它，就无法理解 [[Q-Learning算法]] 的更新式为什么长那样（它就是"无模型版价值迭代"：用采样代替期望、用单样本代替全量扫描）；也无法理解 DQN 里"固定目标网络、周期同步"在模仿"异步迭代中的冻结目标"。
- **实际应用场景**：已知模型的小规模问题（GridWorld、棋盘类游戏、迷宫规划）直接求精确最优解；模型已知的子问题（MPC 短时域规划）在线求解；也是验证 RL 实现正确性的"黄金标准"（先跑 DP 得真值，再对比学习算法结果）。
- **高频题型/任务**：手算若干轮策略评估/价值迭代；证明策略改进定理；解释收敛性（收缩映射）；对比 DP 与 TD 的适用条件（CS188 Project 3 与 HW01 的核心考点）。

## 4. 用直觉语言解释它

> «"价值迭代就像全班同学互相抄答案的估值游戏：每个格子举着估值牌，一轮里大家同时按公式'新估值 = 眼前奖励 + 折扣 × 邻居估值里最好的那个'重写牌子；因为折扣 $\gamma<1$，'抄来的错误'每轮都打折扣、越来越小，整张地图的估值会一轮轮稳定下来。策略迭代则是'先按老战术把每个人的身价估准（评估），再让每个人都改投身价最高的方向（改进），然后重新估、再改……直到没人想改'——价值迭代把'估准'和'改方向'合并成一步，所以更快。"»

- **直觉类比/几何图像**：价值迭代是"热力图扩散"：终点的热度（奖励）随迭代按 $\gamma$ 衰减地向四周传播；策略迭代是"计划-执行"循环：先算清当前计划的账，再修正计划。
- **为什么很自然**：因为贝尔曼方程本身就是"每格估值与邻居估值的关系式"，把关系式当成"更新规则"反复套用，正是解自洽方程组的通用做法（Jacobi/Gauss-Seidel 迭代）。
- **一句话直觉本质**：**把"解方程"变成"反复套用方程当更新规则"，用折扣因子保证更新误差逐轮衰减，最终得到唯一的最优价值与最优策略。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **策略评估（Policy Evaluation）**：给定 $\pi$，迭代 $V_{k+1}(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R + \gamma V_k(s')]$ 直至收敛，得到 $V^\pi$。
- **策略改进（Policy Improvement）**：$\pi'(s) = \arg\max_a \sum_{s'} P(s'|s,a)[R(s,a,s') + \gamma V^\pi(s')]$——贪心换成当前最优动作。
- **策略迭代（Policy Iteration）**：评估 → 改进 → 再评估……直到 $\pi$ 不变；有限 MDP 下保证有限步终止于最优策略。
- **价值迭代（Value Iteration）**：$V_{k+1}(s) = \max_a \sum_{s'} P(s'|s,a)[R + \gamma V_k(s')]$——单次扫描同时完成"评估+改进"。

### 2. 核心公式
策略评估（同步更新）：
$$V_{k+1}(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\big[ R(s,a,s') + \gamma V_k(s') \big], \quad \forall s$$

价值迭代（同步更新）：
$$V_{k+1}(s) = \max_{a} \sum_{s'} P(s' \mid s, a)\big[ R(s,a,s') + \gamma V_k(s') \big], \quad \forall s$$

收敛性（贝尔曼算子 $T$ 是 $\gamma$-收缩）：
$$\| TV - TU \|_\infty \le \gamma\, \| V - U \|_\infty, \qquad \lim_{k\to\infty} V_k = V^* \text{（唯一不动点）}$$

策略改进定理：若 $\pi'$ 由 $\pi$ 贪心改进而来，则 $V^{\pi'}(s) \ge V^\pi(s),\ \forall s$。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $V_k$ | 第 $k$ 轮迭代的价值向量 | $\mathbb{R}^{\|\mathcal{S}\|}$ | 同步更新用 $V_k$ 算 $V_{k+1}$ |
| $T$ | 贝尔曼算子 | 函数到函数 | 最优方程的不动点算子 |
| $\pi, \pi'$ | 旧策略、改进后策略 | 状态→动作映射 | 有限 MDP 策略数有限 |
| $\gamma$ | 折扣因子 | $[0,1)$ | 决定收缩率与收敛速度 |

### 4. 常见变体与适用条件
- **同步 vs 异步**：异步（in-place）用最新值更新、收敛更快但路径依赖；Gauss-Seidel 式异步是工程默认；**提前停止**：价值变化足够小时即可停（策略可能早已稳定），或只做有限步评估（modified policy iteration）。
- **适用条件**：必须已知 $P$ 与 $R$、状态空间有限；模型未知时改用采样类方法（[[Q-Learning算法]]、[[DQN深度Q网络]]）。

## 6. 推导思路和思想来源

- **最初困难**：贝尔曼方程是"无限多个未知数的自洽方程组"，直接解不可行（$O(|\mathcal{S}|^3)$ 且无法利用结构）；枚举策略指数爆炸。
- **关键"转念"**：把方程 $V = TV$ 看成**不动点方程**，用迭代 $V_{k+1} = TV_k$ 逼近——因为 $T$ 是 $\gamma$-收缩（每轮把误差缩小 $\gamma$ 倍），巴拿赫不动点定理直接给出存在性、唯一性与几何收敛速度 $\|V_k - V^*\|_\infty \le \gamma^k \|V_0 - V^*\|_\infty$。
- **推导主线与动机**：策略评估：期望方程 → 迭代规则 → 收缩 → 收敛到 $V^\pi$；策略改进：逐状态替换动作，用期望方程展开比较得策略改进定理 → 策略数有限 → 有限步收敛；价值迭代：把 $\max$ 塞进迭代规则（$\max$ 保持收缩性）→ 收敛到 $V^*$。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：3 状态链（同 [[MDP与贝尔曼方程]] 例 1）：$s_1 \to s_2 \to s_3$（终止，奖励 +10），$\gamma=0.9$。用策略评估迭代 3 轮（$V_0 = 0$）。
- **解题思路与关键步骤**：$V_{k+1}(s_2) = 0 + 0.9 V_k(s_3)$，$V_{k+1}(s_1) = 0 + 0.9 V_k(s_2)$，$V(s_3)=0$。轮 1：$(0, 9, 0)$；轮 2：$(8.1, 9, 0)$；轮 3：$(7.29, 9, 0)$。**最终答案**：$V_3 = (7.29, 9, 0)$，向真值 $(8.1, 9, 0)$ 以每轮 $\times 0.9$ 的速度逼近。
- **易错点**：把终止状态 $s_3$ 也参与更新（终止状态价值恒 0）。
- **🤔 追问**：若改为异步（in-place）且按 $s_1 \to s_2$ 顺序？——$V(s_2)$ 先更新为 9，$V(s_1)$ 用最新值算得 $0.9 \times 9 = 8.1$，**一轮就收敛**：异步比同步快得多。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：4 格直线 $A \to B \to C \to D$（终点奖励 +1，$\gamma=0.9$），每格可前进或后退（后退奖励 0），价值迭代两轮（$V_0=0$）。轮 1：$V_1(C)=0.9$、$V_1(B)=0.81$、$V_1(A)=0.729$；轮 2：$V_2(C)=0.9$，$V_2(B)=\max(0.81,\ 0.9\times V_1(A)=0.656)=0.81$。**关键推理**：$\max$ 隐式完成动作选择，最优动作两轮内稳定，价值收敛到真值 $V^*=(0.729, 0.81, 0.9)$。
- **易错点**：把"价值收敛"与"策略收敛"混为一谈——策略可能远早于价值稳定（本例无差异，含噪声环境才明显）。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：CS188 Project 3 的 `valueIterationAgent` 用价值迭代处理 Pacman/GridWorld（含噪声转移），autograder 直接检验收敛后的价值与策略；本地可对照 [[项目-GridWorld最优]]、[[项目-价值可视化]]（热力图看价值扩散）、[[项目-MDP求解器]]。
```python
V = zeros(n_states)
for _ in range(max_iter):
    V_new = [max(sum(P[s][a][s'] * (R[s][a][s'] + gamma * V[s'])
                 for s' in states) for a in actions) for s in states]
    if max(abs(V_new[s] - V[s]) for s in states) < theta: break
    V = V_new
```

## 8. 常见误区和易混概念

### 误区 1：以为价值迭代必须"收敛到价值"才算完
- **错误直觉与为什么错**：策略往往在价值还差很远时就已经最优（价值小误差不影响 $\arg\max$）；工程上常用"价值变化 < $\theta$"提前停止。
- **正确理解**：目标是最优策略；价值只是中间量，可按误差界 $\frac{2\gamma\epsilon}{1-\gamma}$ 控制停止时机。

### 误区 2：把"策略迭代"与"价值迭代"当成同一种算法
- **错误直觉与为什么错**：策略迭代每轮"评估到收敛 + 显式改进策略"，价值迭代每轮只做一次 $\max$ 扫描、不显式维护策略——前者轮数少但每轮贵，后者反之；**正确理解**：策略迭代是"评估/改进二分法"（策略空间搜索），价值迭代是"不动点迭代"（价值空间逼近），收敛到同一最优解。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 策略评估 | 给定 $\pi$ 求 $V^\pi$ | 对 $\pi$ 求期望，无 $\max$ | 评价一个已知策略 |
| 策略迭代 | 求最优策略 | 评估+改进交替，策略显式 | 小规模精确求解 |
| 价值迭代 | 求最优价值 | 单次 $\max$ 扫描，无显式策略 | GridWorld/Pacman 官方作业 |
| DP vs TD | 模型已知 vs 未知 | 全量期望 vs 单样本采样 | 规划 vs 学习（[[Q-Learning算法]]） |

### 题目与解析

#### 1. 策略评估与价值迭代的更新式有什么本质区别？
> [!question]- 答案解析
> - **答案**：策略评估对策略 $\pi$ 求期望（无 $\max$），收敛到 $V^\pi$；价值迭代对动作取 $\max$，收敛到 $V^*$。
> - **解析**：$\max$ 的有无决定了"评价固定策略"还是"同时寻找最优动作"；价值迭代可看作"每轮都做一次贪心改进的评估"。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 两状态 MDP：状态 1 动作 a 以概率 1 到状态 2 得奖励 5，动作 b 停留状态 1 得奖励 1；状态 2 终止。$\gamma=0.9$，$V_0=(0,0)$。求一轮价值迭代后的 $V_1$。
> [!question]- 答案解析
> - **答案**：$V_1(2) = 0$；$V_1(1) = \max(5 + 0.9\times 0,\ 1 + 0.9\times 0) = 5$，即 $V_1 = (5, 0)$。
> - **解析**：$\max$ 比较两个动作：a 得 5、b 得 1，选 a；终止状态不参与更新；易错点是奖励乘 $\gamma$ 或忘记 $\max$。

#### 3. 什么时候不能用策略迭代/价值迭代求解？给出两个场景。
> [!question]- 答案解析
> - **答案**：① 模型未知（不知道 $P(s'|s,a)$ 与 $R$）——DP 需要全量期望，改用 [[Q-Learning算法]]/[[DQN深度Q网络]] 采样求解；② 状态空间巨大或连续——表格无法存储 $V$，需函数近似。
> - **解析**：DP 前提是"已知 MDP 五元组 + 状态可枚举"；这也是 CS188 里"模型已知用 valueIteration、模型未知用 qlearning"的分工。

#### 4. 价值迭代中，为什么"策略提前稳定"可以提前停止？异步（in-place）更新为什么通常更快？
> [!question]- 答案解析
> - **答案**：最终决策只依赖 $\arg\max_a$ 的比较关系；价值小误差不翻转比较结果时策略已最优，可用"价值变化 < $\theta$"停止。异步更新让先更新的格子立即把最新信息传给邻居，一轮内传播完成（见例子 1 追问），收敛更快。
> - **解析**：提前停止是工程常用（CS188 的 `theta` 参数）；异步是 Gauss-Seidel 思想，结果依赖更新顺序，但仍收敛到同一不动点（算子仍收缩）。

#### 5. 简述"贝尔曼算子 $T$ 是 $\gamma$-收缩"的证明思路，并说明它为什么保证价值迭代收敛。
> [!question]- 答案解析
> - **答案**：对任意 $U, V$ 与状态 $s$：$|(TU)(s) - (TV)(s)| \le \max_a \sum_{s'} P(s'|s,a) \cdot \gamma |U(s') - V(s')| \le \gamma \|U - V\|_\infty$（三角不等式 + 概率和为 1），取 $\max_s$ 得 $\|TU - TV\|_\infty \le \gamma\|U-V\|_\infty$。由巴拿赫不动点定理：收缩映射有唯一不动点，$V_k$ 以 $\gamma^k$ 速率几何收敛；该不动点满足 $V^* = TV^*$，即贝尔曼最优方程。
> - **解析**：DP 理论的核心证明，$\gamma<1$ 是全部收敛保证的来源；同样论证可迁移到 Q-Learning 的收敛性直觉。
