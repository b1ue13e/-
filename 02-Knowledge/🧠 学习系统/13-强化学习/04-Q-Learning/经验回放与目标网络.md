# 经验回放与目标网络

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：它们是 DQN 从"理论上能学"到"实践中能收敛"的**两大命门**（Mnih et al., 2015 Nature 明确列出的核心技巧）；HW03 要求 DQN 最小实现并提交学习曲线，没有经验回放与目标网络，CartPole 上的 DQN 几乎必然发散。[[DQN深度Q网络]] 的算法骨架也由这两块组成。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 把 [[Q-Learning算法]] 的更新式原样搬到神经网络上（在线 TD 更新：采一步、算一步、更新一步），训练**发散了**。原因有两个，都在"监督学习假设"上翻了车：
> 1. **样本相关性**：在线更新相邻样本 $(s_t,a_t,r_t,s_{t+1})$ 与 $(s_{t+1},a_{t+1},r_{t+1},s_{t+2})$ 高度相关，SGD 的 i.i.d. 假设被打破，梯度震荡甚至爆炸；
> 2. **非平稳目标**：TD 目标 $y = r + \gamma\max_{a'} Q(s',a';\theta)$ 里的 $Q$ 就是**正在被更新的同一个网络**——"学生同时当老师"，目标随参数移动，优化目标本身在漂移，loss 无定义地乱跑。
> 因此需要两件套：**经验回放**（把数据存进缓冲区、均匀采样，破坏时间相关性）与**目标网络**（用一份冻结参数的"老师" $\theta^-$ 计算目标，隔段时间才同步，稳定靶心）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：DQN 三件套（CNN + 经验回放 + 目标网络）开启了深度 RL 时代；后续 DDPG/TD3/SAC 全部沿用这两件套；[[SAC软Actor-Critic]] 的软更新直接继承自目标网络思想。
- **实际应用场景**：一切 off-policy 深度 RL（DQN/Double DQN/PER/DDPG/TD3/SAC）的数据管线；Atari、机器人、推荐系统的价值学习。
- **高频题型/任务**：HW03 的 DQN 最小实现（必须手写 replay buffer 与 target net）；解释"为什么 DQN 训练会发散"；手算目标值 $y$（含 done 处理）；软/硬更新的适用条件判断题。

---

## 3. 学它之前需要哪些前置知识？

1. **[[Q-Learning算法]]**：TD 更新 $Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma\max_{a'}Q(s',a') - Q(s,a)]$——经验回放与目标网络就是这条更新式的"深度化改造"。
2. **[[DQN深度Q网络]]**：用神经网络 $Q_\theta$ 近似 $Q^*$、损失取 TD 误差平方——本笔记是 DQN 笔记中"两大 trick"的展开。
3. **监督学习**：SGD 的 i.i.d. 假设与固定目标（标签不随模型变）——理解"为什么 RL 在线更新违背假设"的参照系。

---

## 4. 用直觉语言解释它

> «"经验回放像学生的错题本+睡眠记忆回放：白天经历的事（状态-动作-奖励）先记下来，晚上随机抽几道题复习——抽题顺序打乱了时间关联，反复复习也提高了数据利用率。目标网络像'答案固定的老师'：学生做题时答案册是上周印好的（参数冻结），每周才重印一次（同步），学生不会追着老师临时改的答案跑。"»

- **直觉类比/几何图像**：相关性破坏 = 把"按时间顺序背书"改成"洗牌复习"；非平稳目标 = 把"移动靶"换成"每隔 C 步挪一次的慢靶"。
- **为什么很自然**：SGD 需要近似独立的样本、监督学习需要固定标签；经验回放与目标网络恰好把 RL 更新**重新包装成监督学习的样子**——这就是 DQN 能稳定训练的本质原因。**一句话直觉本质**：**"打乱样本破相关性、冻结目标稳靶心——把 RL 在线更新伪装成监督学习。"**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **经验回放（Replay Buffer）**：容量 $N$ 的环形缓冲区 $\mathcal{D}=\{(s,a,r,s',\text{done})\}$，新样本覆盖最旧样本；训练时从 $\mathcal{D}$ **均匀随机采样** minibatch。
- **目标网络（Target Network）**：参数 $\theta^-$ 的副本网络，仅用于计算 TD 目标，不参与梯度更新。
- **DQN 损失（两件套合体）**：$L(\theta) = \mathbb{E}_{(s,a,r,s')\sim\mathcal{D}}\Big[\big(y - Q_\theta(s,a)\big)^2\Big]$，其中 $y = r + \gamma\,(1-\text{done})\,\max_{a'} Q_{\theta^-}(s',a')$。

### 2. 核心公式
硬更新（每 $C$ 步整份拷贝）：
$$\theta^- \leftarrow \theta \quad (\text{every } C \text{ steps})$$

软更新（每步按比例混合，Polyak 平均）：
$$\theta^- \leftarrow \tau\,\theta + (1-\tau)\,\theta^- \qquad (\tau \approx 0.005)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathcal{D}$ | 经验缓冲区 | 容量 $N$（如 $10^5$-$10^6$） | 环形队列 |
| $\theta$ | 在线网络（学生） | $\mathbb{R}^p$ | 每步更新 |
| $\theta^-$ | 目标网络（老师） | $\mathbb{R}^p$ | 冻结/慢更新 |
| $y$ | TD 目标 | 实数 | 用 $\theta^-$ 计算、$\theta$ 拟合 |
| done | 终止标志 | $\{0,1\}$ | done=1 时无未来项 |
| $C$ | 硬更新周期 | 正整数（如 1000） | Nature DQN 的配置 |
| $\tau$ | 软更新系数 | $(0,1)$，常用 0.005 | Polyak 平均 |

### 4. 常见变体与适用条件
- **变体**：优先经验回放（PER，按 $|\delta|$ 加权采样，配重要性采样权重）；Double DQN（用 $\theta$ 选动作、$\theta^-$ 估值，与目标网络正交可叠加）；软更新（DDPG/TD3/SAC 标配）。**适用条件**：off-policy 算法（策略不依赖 $\mathcal{D}$ 内容更新）；**限制条件**：on-policy 算法（如 [[PPO近端策略优化]]、REINFORCE）**不能用**回放（旧策略数据带来分布偏移）；缓冲区过旧样本与当前策略偏差大时需清理或限制容量。

## 6. 推导思路和思想来源

- **最初困难与直接方法局限**：2013 年 DeepMind 首次用深度网络玩 Atari，若不处理相关性与非平稳性训练发散；直接沿用表格 Q-learning 的在线更新是死路——在线 SGD 假设样本 i.i.d.（RL 轨迹强相关），而 TD 目标含自身参数（loss 的"真值"每步在变，等于没有固定监督信号）。
- **关键"转念"**：**把 RL 更新重构成监督学习**——经验回放把时间序列打散成"近似独立"的数据集（均匀采样使任意两个样本相关性期望为 0）；目标网络把 TD 目标冻结在 $\theta^-$ 上，使 $y$ 在一段时间内**成为固定的监督标签**，loss 有了稳定最小值可优化。
- **推导主线与动机**：Q-learning 更新式等价于"对 TD 误差平方做一步 SGD"（损失 $L=(y-Q_\theta)^2$，梯度 $\propto (y-Q_\theta)\nabla Q_\theta$）→ 把 $y$ 里的 $\theta$ 换成 $\theta^-$（stop-gradient，目标不参与反传）→ 采样从 $\mathcal{D}$ 均匀抽取而非按轨迹顺序 → 收敛性得以保证（在近似 i.i.d. + 准静态目标的条件下，DQN 退化为稳定的回归问题）。
- **为什么自然得到此结论**：人类学习本就有"回放巩固"（海马体重放）与"先学后考"（固定答案）两个机制；工程上它们恰好对应统计学（打破相关性）与优化（稳定目标）两个病根。
- **代价**：目标网络引入**滞后偏差**（$\theta^-$ 是旧参数）；回放引入**off-policy 偏差**（缓冲区内含旧策略数据）；两者都是"用一点点偏差换巨大稳定性"的工程权衡。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：缓冲区内一条样本：$s$ 下选 $a$ 得 $r=2$，$s'$ 处 $\max_{a'}Q_{\theta^-}(s',a')=3$，$\gamma=0.9$，done=0。求 TD 目标 $y$；若 done=1 呢？
- **解题思路与关键步骤**：done=0：$y = 2 + 0.9\times 3 = 4.7$（未来价值参与）；done=1：$y = 2$（终止后无未来，**不能 bootstrap**）。**最终答案**：$y=4.7$ 或 $y=2$。**易错点**：done=1 时漏乘 $(1-\text{done})$ 会凭空引入 $\gamma\max Q$ 项，把终止状态当可延续状态，价值被系统性高估。
- **🤔 追问**：若目标不用 $\theta^-$ 而用 $\theta$ 自身？——目标随每步更新移动，loss 最小点永远追不上（非平稳目标），这是没有目标网络时发散的直接原因。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：何时用硬更新、何时用软更新？——硬更新（Nature DQN：$C=1000$）简单、周期明确，但同步瞬间目标跳变可能引起 loss 抖动；软更新（$\tau=0.005$，DDPG/SAC 标配）目标每步微移、平滑稳定，但需要调 $\tau$ 且目标永远"慢半拍"。**关键推理**：连续控制/确定性策略类算法（DDPG、TD3、SAC）几乎都用软更新，因为 actor-critic 双网络对目标突变更敏感；离散动作 DQN 用硬更新足够。**易错点**：$\tau$ 太大（如 0.1）≈ 没有目标网络；太小（如 $10^{-5}$）目标长期不动、学习变慢。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW03 的 DQN 最小实现（CartPole-v1）三件套齐活：replay buffer 用 `collections.deque(maxlen=N)`；目标网络 `target_net.load_state_dict(net.state_dict())` 每 C 步同步；对应 [[强化学习-阶段作业-HW02-DQN与PPO连续动作控制]]。
```python
batch = random.sample(buffer, batch_size)          # 均匀采样打破相关性
s, a, r, s2, done = zip(*batch)
with torch.no_grad():                              # 目标网络：stop-gradient
    y = r + gamma * (1 - done) * target_net(s2).max(1).values
q = net(s).gather(1, a)                            # 在线网络取所选动作的 Q
loss = F.mse_loss(q, y); loss.backward(); opt.step()
if step % C == 0:                                  # 硬更新：冻结的目标定期同步
    target_net.load_state_dict(net.state_dict())
```
- **实际价值**：`with torch.no_grad()` 与 `target_net` 就是"目标不参与反传"的代码形态；若删掉这两行，CartPole 上 DQN 在数百步内即发散——HW03 报告里可附这个消融对比。

## 8. 常见误区和易混概念

### 误区 1：缓冲区越大越好
- **错误直觉与为什么错**：数据越多越像大数据训练；但缓冲区过大时大部分样本来自**很久以前的旧策略**，与当前策略的分布偏移（off-policy 偏差）增大、梯度信号失真，过小则相关性破坏不彻底。
- **正确理解**：容量是权衡旋钮（常用 $10^5$-$10^6$）；训练后期可配合"只保留近期样本"或 PER 动态调节。

### 误区 2：目标网络更新越频繁越好
- **错误直觉**：目标越"新"越准。
- **为什么错**：$C$ 太小（或 $\tau$ 太大）时 $\theta^- \approx \theta$，非平稳目标问题复发，等于没装目标网络；完全不动则目标过时、学习慢。
- **正确理解**：更新周期是"稳定性 vs 新鲜度"的权衡；硬更新 $C$ 常用 1000-10000，软更新 $\tau$ 常用 0.001-0.01。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 经验回放 | 样本相关性 | 打散时间序列、复用数据 | DQN/DDPG/SAC 数据管线 |
| 目标网络 | 目标非平稳 | 冻结 $\theta^-$ 算目标、周期同步 | DQN/DDPG/SAC 训练稳定 |
| 在线 TD 更新 | 二者都不处理 | 采一步更一步，简单但发散 | 表格 Q-learning |

### 题目与解析

#### 1. DQN 在线训练发散的两个病根是什么？两件套各自对治哪个？
> [!question]- 答案解析
> - **答案**：① 样本时间相关性（破坏 SGD 的 i.i.d. 假设）→ 经验回放均匀采样打散；② 非平稳目标（TD 目标含自身参数，靶心随更新漂移）→ 目标网络冻结 $\theta^-$、周期同步。**解析**：两件套一一对治：回放治"数据关"，目标网络治"目标关"；缺任一，DQN 在 CartPole/Atari 上都难以收敛。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 一条样本：$r=1$，$s'$ 处 $\max_{a'}Q_{\theta^-}(s',a')=5$，$\gamma=0.99$。求 done=0 与 done=1 时的 $y$。
> [!question]- 答案解析
> - **答案**：done=0：$y=1+0.99\times5=5.95$；done=1：$y=1$。
> - **解析**：$(1-\text{done})$ 因子保证终止状态不 bootstrap；漏乘会把终止状态价值高估约 $\gamma\max Q$，长期累积使 Q 值虚高（正是 Double DQN 要修的偏差的另一来源）。

#### 3. 你在写 DDPG 的 critic 更新，应该选硬更新还是软更新？参数怎么取？
> [!question]- 答案解析
> - **答案**：软更新（Polyak），$\tau$ 取 0.001-0.01（如 0.005）；DDPG/TD3/SAC 均如此。
> - **解析**：连续控制 actor-critic 对目标突变敏感，硬更新的周期性跳变会破坏训练平稳性；软更新让目标平滑漂移。离散动作 DQN 用硬更新（$C=1000$）则足够且更简单。

#### 4. 为什么 [[PPO近端策略优化]] 不能用经验回放？这与 DQN 有何本质差异？
> [!question]- 答案解析
> - **答案**：PPO 是 on-policy：梯度估计要求数据由**当前策略** $\pi_\theta$ 采样，旧策略（旧缓冲区）数据会引入分布偏移，使重要性权重爆炸或梯度估计失真；DQN 是 off-policy：Q-learning 更新只要求"行为策略覆盖最优动作"，与数据来源策略解耦，故可复用回放。**解析**："能否回放"是 on-policy 与 off-policy 家族的分水岭，也是 PPO 样本效率低于 DQN 系的原因之一（PPO 每轮数据用完即弃）。

#### 5. （推导题）写出 DQN 损失 $L(\theta)=\mathbb{E}[(y - Q_\theta(s,a))^2]$ 对 $\theta$ 的梯度，并说明为什么目标网络必须 stop-gradient（$\theta^-$ 不参与反传）。
> [!question]- 答案解析
> - **答案**：$\nabla_\theta L = -2\,\mathbb{E}\big[(y - Q_\theta(s,a))\,\nabla_\theta Q_\theta(s,a)\big]$，其中 $y = r + \gamma(1-\text{done})\max_{a'}Q_{\theta^-}(s',a')$ 视为常数（$y$ 对 $\theta$ 的依赖被 $\theta^-$ 切断）。若 $y$ 用 $\theta$ 计算，梯度会多出一项 $\propto (y-Q_\theta)\gamma\nabla_\theta\max_{a'}Q_\theta(s',a')$，使"目标"与"预测"同向移动——损失的最小点自身漂移，训练在追逐移动靶中发散；冻结 $\theta^-$ 后 $y$ 是准静态标签，$L$ 退化为普通回归损失，SGD 收敛性得以恢复。**解析**：这是"非平稳目标"问题的精确数学形态；代码形态即 `with torch.no_grad()` + `target_net`，HW03 实现中这两行是收敛的底线。
