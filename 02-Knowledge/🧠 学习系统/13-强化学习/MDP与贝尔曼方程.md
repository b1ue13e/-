# MDP与贝尔曼方程

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：MDP 是强化学习的**形式化地基**——没有它，"试错学习"就没有统一的数学语言；贝尔曼方程则是后面所有算法（[[价值迭代与策略迭代]]、[[Q-Learning算法]]、[[DQN深度Q网络]]、[[PPO近端策略优化]]）共用的"心脏"。HW01（CS188 Project 3）与 Sutton & Barto Ch.3 直接考察本节，跳过它等于跳过整门课。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 我们想让智能体在未知环境里通过试错学会做决策（走迷宫、玩游戏、控制机器人）。但"学决策"太模糊：状态怎么描述？动作的后果有随机性怎么算账？延迟奖励（先苦后甜）怎么比较？以前的方法是给每个场景写死 if-then 规则，环境一复杂规则就爆炸，且无法处理概率性后果。
> 因此必须引入两样东西：**MDP**（把决策问题规范成"状态—动作—转移概率—奖励—折扣"五元组）和**贝尔曼方程**（把"长期总回报"递归地拆成"当前奖励 + 未来价值"，让价值可以被计算、被迭代、被学习）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：不学它，HW01 的 valueIterationAgent 无从下手，HW02 的 Q 表更新式只是符号游戏；DQN/PPO 的价值网络与优势估计全部建立在贝尔曼递归之上。
- **实际应用场景**：机器人路径规划、游戏 AI（Pacman/Atari）、推荐系统、自动驾驶决策——RL 落地项目的第一步几乎都是"把问题建模成 MDP"。
- **高频题型/任务**：给定五元组手算价值函数；判断是否满足马尔可夫性质；写出/展开贝尔曼方程；解释 $\gamma$ 的作用（CS188 Project 3 的 analysis 部分即此类题）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[布朗运动与鞅-鞅语言-条件期望|条件期望]]**：$\mathbb{E}[X \mid Y]$ 的含义——转移概率 $P(s' \mid s,a)$ 与期望回报都建立在此之上。
2. **[[马尔可夫性质|马尔可夫链]]**：状态转移矩阵——MDP 是"带动作和奖励的马尔可夫链"。

---

## 4. 用直觉语言解释它

> «"MDP 是一本带概率的棋盘游戏规则书：你站在某个局面（状态）上选择一步棋（动作），规则书告诉你每种走法各有几成概率到达哪些新局面并当场记分（奖励）。贝尔曼方程说的是一句极有用的话：'你现在这一步的价值 = 这步的得分 + 折扣 × 之后所有步的价值'——把'算总账'拆成'算眼前 + 算未来'，未来部分又可以用同样的话递归下去。"»

- **直觉类比/几何图像**：价值函数是"站在每个格子上的正确估值牌"；贝尔曼方程是"相邻格子估值的自洽关系"，像解方程组一样把整张地图的估值一次算清。
- **为什么很自然**：因为"眼前奖励 + 未来价值的折扣和"就是总回报的定义本身，递归拆解只是把定义换了个写法。
- **一句话直觉本质**：**用五元组把决策问题规格化，再用"当前 + 折扣未来"的递归关系把长期价值变成可计算、可迭代的量。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **MDP**：五元组 $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$，$P(s' \mid s, a)$ 为转移概率，$R(s, a, s')$ 为奖励函数，$\gamma \in [0, 1)$ 为折扣因子。
- **马尔可夫性质**：$P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots) = P(s_{t+1} \mid s_t, a_t)$——未来只依赖当前状态-动作对。
- **策略** $\pi(a \mid s)$：状态到动作（概率）的映射，RL 的学习目标。
- **状态价值** $V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]$；**动作价值** $Q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]$。

### 2. 核心公式
折扣回报：$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$

贝尔曼期望方程：
$$V^\pi(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\big[ R(s,a,s') + \gamma V^\pi(s') \big]$$
$$Q^\pi(s, a) = \sum_{s'} P(s' \mid s, a)\big[ R(s,a,s') + \gamma \sum_{a'} \pi(a' \mid s') Q^\pi(s', a') \big]$$

贝尔曼最优方程：
$$V^*(s) = \max_a \sum_{s'} P(s' \mid s, a)\big[ R(s,a,s') + \gamma V^*(s') \big]$$
$$Q^*(s, a) = \sum_{s'} P(s' \mid s, a)\big[ R(s,a,s') + \gamma \max_{a'} Q^*(s', a') \big]$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathcal{S}, \mathcal{A}$ | 状态集、动作集 | 离散或连续 | 表格法要求有限离散 |
| $P(s' \mid s, a)$ | 转移概率 | $[0,1]$，$\sum_{s'} P=1$ | 环境的"物理规则" |
| $R(s,a,s')$ | 奖励 | 实数 | 可能稀疏 |
| $\gamma$ | 折扣因子 | $[0, 1)$（收敛要求） | 越大越"远视" |
| $V^\pi, Q^\pi$ | 状态/动作价值 | 实数 | 有界（$\gamma<1$ 时） |
| $\pi(a \mid s)$ | 策略 | 概率分布 | 学习目标 |

### 4. 常见变体与适用条件
- **变体**：episodic vs continuing；折扣 vs 平均回报；部分可观测 POMDP；带吸收态（terminal 价值为 0）；**适用条件**：状态能完全描述问题（马尔可夫性质近似成立）。
- **限制条件**：状态巨大时表格不可行 → 函数近似（[[DQN深度Q网络]]）；转移概率未知时无法直接求期望 → 采样（[[Q-Learning算法]]）。

## 6. 推导思路和思想来源

- **最初困难**：多步随机决策的总回报无法直接枚举（轨迹指数爆炸）；直接方法局限在于按"历史"组织信息无法压缩状态。
- **关键"转念"**：利用马尔可夫性质 + 回报的递归结构，把 $G_t$ 写成 $R_{t+1} + \gamma G_{t+1}$——**"总账 = 眼前 + 折扣 × 未来的总账"**，价值函数之间出现自洽方程。
- **推导主线与动机**：定义 $V^\pi = \mathbb{E}_\pi[G_t \mid s_t=s]$ → 代入 $G_t = R_{t+1} + \gamma G_{t+1}$ → 把未来部分写成 $V^\pi(s')$ → 期望方程；对 $\pi$ 取"每步选最优动作"的算子（$\max$）→ 最优方程。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：3 状态链 $s_1 \to s_2 \to s_3$（终点，奖励 $+10$），转移概率 1，$\gamma = 0.9$，中间步奖励 0。求 $V^\pi(s_1), V^\pi(s_2)$。
- **解题思路与关键步骤**：从终点倒推。$V(s_3)=0$（终止）；$V(s_2) = 0 + 0.9 \times 10 = 9$；$V(s_1) = 0 + 0.9 \times 9 = 8.1$。与直接展开 $G = 0.9^2 \times 10$ 一致。**最终答案**：$V(s_1) = 8.1,\ V(s_2) = 9$。
- **易错点**：忘记终点状态价值为 0（否则把 10 再折扣一次）。
- **🤔 追问**：如果 $\gamma = 1$ 呢？——$V(s_1)=V(s_2)=10$，但无限步时回报可能发散，这正是 $\gamma<1$ 保证有界的原因。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：2×2 GridWorld：左上起点，右下终点（奖励 +1 并终止），其余奖励 0，$\gamma=0.9$，动作各以概率 1 执行。从终点倒推：$V^*(终点)=0$；与终点相邻格 $V^* = 0.9 \times 1 = 0.9$；起点 $V^* = 0.9 \times 0.9 = 0.81$。**关键推理**：若动作带噪声（80% 按意图、20% 随机），$V^*$ 下降且最优策略会"远离悬崖"——正是 CS188 GridWorld 的 analysis 题。
- **易错点**：在含噪声环境中仍假设动作 100% 按意图执行。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：CS188 Project 3 的 `valueIterationAgents.py` 反复应用 $V(s) \leftarrow \max_a \sum_{s'} P(s'|s,a)[R + \gamma V(s')]$ 直到收敛；Pacman 状态抽象为"位置 + 食物分布"。本地实验见 [[项目-GridWorldMDP]]、[[项目-贝尔曼求解]]、[[项目-价值可视化]]。
```python
V = zeros(n_states)
for _ in range(k):
    V_new = [max(sum(P[s][a][s'] * (R + gamma * V[s'])
                 for s' in range(n_states)) for a in range(n_actions))
             for s in range(n_states)]
    V = V_new
```

## 8. 常见误区和易混概念

### 误区 1：以为 $\gamma=0$ 只是"小折扣"
- **错误直觉与为什么错**：$\gamma=0$ 时 $V^\pi(s)=\mathbb{E}[R_{t+1}]$，智能体完全短视，任何延迟奖励都不参与决策——这是本质性的行为改变。
- **正确理解**：$\gamma$ 同时是"远视程度"和"收敛保证"：$\gamma \to 1$ 时 $V$ 可能发散（非折扣问题需用平均回报）。

### 误区 2：把 $V$ 和 $Q$ 混为一谈
- **错误直觉与为什么错**：$V(s)$ 在状态 $s$ 上按 $\pi$ 对动作求期望，$Q(s,a)$ 固定动作 $a$；关系 $V^\pi(s)=\sum_a \pi(a|s) Q^\pi(s,a)$。决策（$\arg\max$）必须发生在 $Q$ 上。
- **正确理解**：$Q$ 比 $V$ 多"指定动作"这一维信息，策略改进与动作选择用 $Q$。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| MDP | 决策问题如何规格化 | 含动作与奖励的马尔可夫链 | RL 问题建模 |
| 马尔可夫链 | 状态如何演化 | 无动作、无奖励、无控制 | 概率演化建模 |
| 期望 vs 最优方程 | 评价策略 vs 求最优 | 对 $\pi$ 求期望 vs 对 $a$ 取 $\max$ | 策略评估 vs 策略优化 |

### 题目与解析

#### 1. 什么是马尔可夫性质？为什么它对 MDP 如此重要？
> [!question]- 答案解析
> - **答案**：$P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots) = P(s_{t+1} \mid s_t, a_t)$——未来只由当前状态-动作决定。
> - **解析**：它让价值函数只依赖当前状态而非整段历史，贝尔曼递归才成立；若不满足，任何以 $V(s)$ 为记忆单元的方法都会失真。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 一条轨迹奖励为 $R = (5, 0, 10)$（三步后终止），$\gamma = 0.5$，求 $G_1$。
> [!question]- 答案解析
> - **答案**：$G_1 = 5 + 0.5 \times 0 + 0.25 \times 10 = 7.5$。
> - **解析**：按定义逐项乘 $\gamma^k$：$R_1 + \gamma R_2 + \gamma^2 R_3$；注意第一步奖励不乘 $\gamma$，终止后无奖励。

#### 3. 同一 MDP，$\gamma=0.99$ 与 $\gamma=0.1$ 相比，最优策略可能有何不同？
> [!question]- 答案解析
> - **答案**：$\gamma=0.99$ 时策略"远视"：愿意牺牲眼前小奖励换远期大奖励（如 Pacman 绕路吃豆）；$\gamma=0.1$ 时策略"短视"：只在乎立即奖励。
> - **解析**：$\gamma$ 决定未来奖励权重；最优路径依赖延迟回报时，$\gamma$ 太小会选出次优策略。

#### 4. 已知 $Q^\pi(s, a)$ 与策略 $\pi$，如何计算 $V^\pi(s)$？已知 $V^\pi$ 能反推出 $Q^\pi$ 吗？
> [!question]- 答案解析
> - **答案**：$V^\pi(s) = \sum_a \pi(a \mid s) Q^\pi(s, a)$；不能——反推 $Q^\pi$ 需要转移概率与奖励：$Q^\pi(s,a)=\sum_{s'}P(s'|s,a)[R+\gamma V^\pi(s')]$。
> - **解析**：$V$ 是 $Q$ 按策略的加权平均（丢失动作维信息），从 $V$ 到 $Q$ 必须借助环境模型。

#### 5. 简述贝尔曼最优方程的推导思路，并说明为什么 $\max$ 与对 $s'$ 的求和不能交换。
> [!question]- 答案解析
> - **答案**：$V^*(s)=\max_\pi V^\pi(s)$；用最优性原理把"对 $\pi$ 求期望"替换为"对 $a$ 取 $\max$"，未来部分递归地仍是 $V^*$。$\max_a \sum_{s'} P[\cdot]$ 是"先看转移分布再决策"，而 $\sum_{s'} P \max_a[\cdot]$ 隐含"事后诸葛亮"（不同 $s'$ 配不同动作），违背因果——决策时不知道 $s'$。
> - **解析**：RL 理论的核心证明题，也解释了 $Q^*$ 更新式中 $\max_{a'}$ 的位置必须谨慎；易错点是混同"期望的最大"与"最大的期望"（Jensen 方向）。
