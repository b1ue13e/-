# 信息论基础（熵 / KL / 交叉熵）

> 所属模块：[[🧭 强化学习-前置知识|前置知识]]

## 动机
策略输出是概率分布，价值网络要拟合目标；衡量"两个分布差多少"用 KL 散度，分类/策略学习常用的损失是交叉熵。SAC 的最大熵目标直接把策略熵写进奖励。

## 定义与公式
- 香农熵 H(p) = −Σᵢ pᵢ log pᵢ（比特用 log₂；自然单位用 ln）。熵越大越不确定。
- 交叉熵 H(p,q) = −Σᵢ pᵢ log qᵢ。
- KL 散度 KL(p‖q) = Σᵢ pᵢ log(pᵢ/qᵢ) = H(p,q) − H(p) ≥ 0。

## 最小手算例子
二点分布 p=[0.5,0.5]：H = −(0.5·ln0.5 + 0.5·ln0.5) = ln2 ≈ 0.693（自然单位）。若 p=[1,0]：H = 0（完全确定）。
交叉熵：p=[1,0], q=[0.8,0.2] → H(p,q) = −(1·ln0.8 + 0) = 0.223。

## 对比与常见错误
- KL 不对称：KL(p‖q) ≠ KL(q‖p)。
- 常见错误：把交叉熵当对称距离；忽略 log(0) 用 log(q+ε) 防数值爆炸；在 RL 中误用 KL 方向（PPO 约束的是 KL(π_new‖π_old)）。

## 闭卷自测

2. 写出 KL(p‖q) 与交叉熵的关系。
3. 为什么 KL 不对称？
