# 概率论基础（RL 视角速查）

> 所属模块：[[🧭 强化学习-前置知识|前置知识]]
> 本课程用到的概率工具集中在三处：值函数是回报的期望；贝尔曼方程依赖条件期望；UCB / 汤普森采样依赖浓度不等式。下面只列 RL 真正用到的部分。

## 1. 为什么 RL 需要概率

强化学习中"环境"用随机过程建模：同一状态执行同一动作，下一状态和奖励可能不同。所有"价值"都是对随机回报取期望得到的数字，因此期望、方差、条件概率是一切算法的地基。

## 2. 核心定义与符号

- **随机变量** $X$：映射样本点到实数的函数；取值集合即状态/奖励空间。
- **期望** $\mathbb{E}[X]=\sum_x x\,P(x)$（离散）或 $\int x\,p(x)\,dx$（连续）。RL 中值函数 $v_\pi(s)=\mathbb{E}_\pi[G_t\mid S_t=s]$ 就是条件期望。
- **方差** $\mathrm{Var}(X)=\mathbb{E}[(X-\mathbb{E}[X])^2]$，衡量不确定性；探索时方差大的臂更"值得试"。
- **条件期望** $\mathbb{E}[X\mid Y]$：已知 $Y$ 时 $X$ 的平均；贝尔曼方程 $v(s)=\mathbb{E}[R+\gamma v(S')\mid S=s]$ 即此。
- **大数定律**：样本均值 $\bar X_n\to\mathbb{E}[X]$。这解释了为何"多试几次"能估计真实动作价值 $q_*(a)$。
- **贝叶斯更新**：先验 $\to$ 观测 $\to$ 后验。汤普森采样正是从后验抽样动作。

## 3. 最小手算例子

掷一枚公平骰子，$X\in\{1,\dots,6\}$。
- $\mathbb{E}[X]=(1+2+3+4+5+6)/6=3.5$。
- 若奖励 $R=X-3$，则 $\mathbb{E}[R]=0.5$，方差 $\mathrm{Var}(R)=\mathrm{Var}(X)=35/12\approx2.92$。
这就是单臂老虎机"真实值"估计的原型。

## 4. 常见错误与辨析

- **混淆条件与联合**：$\mathbb{E}[R_{t+1}\mid S_t=s,A_t=a]$ 与 $\mathbb{E}[R_{t+1}]$ 不同，前者是给定状态下的条件值。
- **把期望当必然**：期望高不代表每次都高；方差大的臂短期可能很差，这正是探索的理由。
- **忽略随机种子**：复现实验必须固定随机种子，否则同代码不同结果。
