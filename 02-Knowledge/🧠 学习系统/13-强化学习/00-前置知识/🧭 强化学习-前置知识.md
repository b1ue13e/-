## 二、学习顺序（14 卡推荐路径）

```
卡1 多臂老虎机（探索-利用）──→ 卡2 MDP与贝尔曼方程 ──→ 卡3 动态规划
                                          │                  │
                                          │                  ├──→ 卡4 蒙特卡洛
                                          │                  └──→ 卡5 TD/Q-Learning ─→ 卡6 DQN
                                          │
卡9 搜索（BFS/DFS/A*）──→ 卡10 博弈（Minimax）
                                          │
卡7 策略梯度 ──→ 卡8 Actor-Critic/PPO ──→ 卡11 离线RL/模仿学习
        │                  │
        │                  └──→ 卡13 评估协议 ──→ 卡14 分层/多智能体
卡12 奖励设计（与卡2 并行）
```

## 三、给小白的三条建议

1. **卡 1 建立"试错"直觉**：探索-利用权衡是整个 RL 的哲学起点，别跳过直接学算法。
2. **卡 2 的贝尔曼方程是公理**：`现在值 = 立即奖励 + 折扣 × 未来值`——所有算法（DP/MC/TD/DQN）都是这个等式的不同求解器。卡 2 的证明重建必须独立完成。
3. **算法卡（6、8）务必跑代码**：DQN 和 PPO 光看公式学不会，至少跑通一个 `stable_baselines3` 或手写最小实现。
