# 回归损失函数（MSE / Huber）

> 所属模块：[[🧭 强化学习-前置知识|前置知识]]

## 动机
Q 网络、价值网络输出连续标量，训练目标是让预测 ŷ 逼近目标 y。最常用均方误差 MSE；但 MSE 对离群点敏感，Huber 在误差大时退化为线性，更鲁棒。

## 定义与公式
- MSE：L = (y − ŷ)²（批量为均值）。
- Huber：|δ|≤δ₀ 时 ½δ²；否则 δ₀(|δ|−½δ₀)。δ = y − ŷ。

## 最小手算例子
y=3, ŷ=2 → δ=1 → MSE = 1² = 1。若 ŷ=0 → MSE = 9（离群误差被平方放大）。
Huber 取 δ₀=1：δ=1 时 L=½·1=0.5；δ=3 时 L=1·(3−0.5)=2.5，比 MSE=9 温和得多。

## 对比与常见错误
- MSE 梯度 ∝ δ，离群点主导训练；Huber 大误差时梯度封顶。
- 常见错误：对分类用 MSE 而非交叉熵；忽略奖励尺度导致 MSE 量级失衡。
