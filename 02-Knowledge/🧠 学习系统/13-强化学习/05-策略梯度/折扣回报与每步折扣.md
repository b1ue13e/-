# 折扣回报与每步折扣

> **⏱ 预计耗时**：20–30 分钟
> **🎯 行为目标**：完成本卡后，
> - 写出折扣回报 G_t 公式；
> - 解释 γ 对目标与梯度的影响；
> - 说明"每步折扣"修正与"重复折扣"陷阱。

## 0. 学习边界
- **类别**：**B 类（重要实现细节）**——折扣因子 γ 与"每步折扣"是策略梯度目标与梯度的标准形式，影响梯度尺度与稳定性。

---

## 1. 折扣回报（折扣-回报）
G_t = Σ_{k≥0} γ^k r_{t+k+1}；无折扣（γ=1）：G_t = Σ r。带折扣时远期奖励衰减。
**手算**：奖励序列 [0, +1, 0]，γ=0.9：G_0 = 0 + 0.9·1 + 0.81·0 = 0.9。

## 2. 折扣因子 γ（折扣-Gamma）
目标 J(θ)=E[ Σ_t γ^t r_{t+1} ]；梯度里每个 G_t 也是折扣回报。γ 小→重短期；γ 大→重长期；γ→1 近似平均奖励。
**手算**：γ=0.9 第 3 步奖励权重 0.81；γ=0.99 权重 0.97——长期信号保留更多。
- 常见错误：忽略 γ 对梯度幅值的影响——长幕累积 γ^t 会缩放梯度，需配合优势/归一。

## 3. 每步折扣修正（折扣-修正）
直接对每步乘 γ^t 会引入"时间越晚梯度越小"的偏差。常用"每决策步折扣"：目标改为 E[ Σ_t γ^t r_{t+1} ]，梯度为 Σ_t γ^t ∇log π(a_t|s_t)·R_t，其中 R_t 为从该步起的折扣回报或优势。
**手算**：t=0 权重 1，t=2 权重 γ^2=0.81；早期动作影响更大，符合"当下决策当下负责"。
- 常见错误：在已折扣的 G_t 上再乘 γ^t——重复折扣；应只在梯度系数用一次 γ^t。
