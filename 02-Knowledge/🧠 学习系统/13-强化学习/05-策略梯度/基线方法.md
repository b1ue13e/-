# 基线方法

> **⏱ 预计耗时**：25–35 分钟
> **🎯 行为目标**：完成本卡后，
> - 说出常数 / 状态价值 / 自适应三类基线；
> - 证明任意只依赖 s 的基线不改梯度期望；
> - 比较三类基线的方差与代价。

## 0. 学习边界
- **类别**：**A 类（核心概念，必须深挖）**——基线是在不引入偏差前提下降低 REINFORCE / 策略梯度方差的关键技巧，是 Actor-Critic 与优势方法的桥梁。

---

## 1. 动机
策略梯度用整幕回报 G_t 方差大。减去一个与动作无关的基线 b(s_t) 可降方差且保持无偏：E[∇log π·b]=0，故 E[(G_t−b)∇log π]=E[G_t∇log π]。

## 2. 常数基线（基线-常数）
b = 所有轨迹回报的移动平均（或指数滑动平均）。更新 θ ← θ + α∇logπ·(G_t−b)。因 b 与动作独立，仍无偏。
**手算**：平均回报 b=0.3；某步 G_t=1 ⇒ 权重 0.7；另一 G_t=0 ⇒ 权重 −0.3，正负抵消平均噪声。
- 常见错误：让 b 依赖当前动作——破坏无偏性。

## 3. 状态价值基线（基线-状态价值）
用状态价值 V(s) 作基线：b(s)=V_φ(s)，由价值网络近似；更新用 A_t≈G_t−V_φ(s_t)，同时用 TD 误差训练 V_φ。这就是 Actor-Critic 的 critic。
**手算**：状态平均得分 0.4；V_φ(s)=0.4 比全局常数 0.3 更贴合该状态，降方差更好。
- 与常数基线：状态相关，方差更低，但需额外训练 critic（引入偏差）。

## 4. 自适应基线（基线-自适应）
基线不必固定；可用神经网络 critic 随策略改进而更新。critic V_φ 用梯度下降最小化 (V_φ(s_t)−target)^2（target 可为 G_t 或 r+γV(s′)）。
量化：常用指数滑动平均 b ← 0.9·b + 0.1·r_t（β=0.9），让基线平滑跟踪近期回报水平。
- 与固定基线：固定基线不随策略变，后期可能不再贴合；自适应基线持续有效。

## 5. 闭卷自测
1. 常数基线是什么？为何保持无偏？
2. 状态价值基线比常数好在哪？代价是什么？
3. 什么是自适应基线？相对固定基线的好处？
