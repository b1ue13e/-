# 策略梯度演进

> **⏱ 预计耗时**：30–40 分钟
> **🎯 行为目标**：完成本卡后，
> - 说清从随机策略、连续动作到自然梯度、端到端的演进链；
> - 用数值例子解释自然梯度校正；
> - 复述 REINFORCE → 基线/优势 → NPG/TRPO → PPO/Actor-Critic 的脉络。

## 0. 学习边界
- **类别**：**B 类（脉络性）**——从 REINFORCE 到端到端深度策略梯度的演进，是理解现代算法的地图。

---

## 1. 随机策略（演进-随机策略）
策略梯度天然优化随机策略：π_θ(a|s) 对 θ 连续可微（softmax/高斯），梯度可求，且以正概率尝试动作自带探索；确定性 argmax 不可微、探索需外加噪声。
**手算**：高斯策略采样 a=μ+σε，σ>0 持续探索；梯度经 ε 回传调 μ、σ。

## 2. 连续动作（演进-连续动作）
值方法（Q-learning）难处理连续动作；策略梯度用高斯策略天然支持。π_θ(a|s)=𝒩(μ_θ(s),σ_θ(s))，无需对连续 a 求 max。
**手算**：μ=0.3, σ=0.1，采到 a≈0.27；对比 Q-learning 要在连续域解 max_a Q(s,a)（无解析解）。

## 3. 连续优化 / 自然梯度（演进-连续优化）
普通梯度在参数空间步长难定；自然梯度 Δθ ∝ F(θ)^{−1} ∇_θ J，F 为 Fisher 信息矩阵，把更新限制在"策略分布变化"意义上固定步长。
**手算（自然梯度校正）**：F=[[2,0],[0,0.5]], g=[1,1] ⇒ 自然梯度 F^{-1}g=[0.5,2]；曲率大的方向步长压到 0.5、曲率小的放大到 2。

## 4. 端到端深度策略梯度（演进-端到端）
把可微策略 + 神经网络 + 优势/critic + 信任域组合，得现代深度策略梯度（A2C/PPO）：状态（甚至图像）直接进 NN 策略，输出动作分布，用优势估计做策略梯度。
演进链：REINFORCE → 基线/优势 → 自然梯度(NPG/TRPO) → 信任域近似(PPO)/Actor-Critic。
量化：Atari 输入 210×160×3≈10 万像素，策略网络直接输出 18 个离散动作，从原始像素到动作一步学到。
- 常见错误：以为"端到端=无 baseline"——深度 PG 更需要 baseline/critic 才稳。

## 5. 闭卷自测
