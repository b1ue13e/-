# 复合误差与模型偏差 (Compounding Error & Model Bias)

> 所属模块：[[🗺️ 强化学习学习路径|强化学习学习路径]]
> 对应阶段：[[🧭 阶段8-模型基与规划|返回阶段页]]

## 动机
模型基 RL 最大的隐忧：单步模型误差 ε 会在多步"想象 rollout"里**指数级**放大。规划得越远，落在模型分布外（OOD）的区域越多，预测越不可信。理解这条误差下界，才能回答"到底该规划多少步"。

## 正式定义 / 公式
设单步状态预测误差有界 ‖ŝ_{t+1} − s_{t+1}‖ ≤ ε。在 H 步开环 rollout 中（每步用模型预测值当下一步输入），误差上界约为

  ‖ŝ_t − s_t‖ ≤ ε·(1 + γ_model + γ_model² + … + γ_model^{H−1}) ≤ ε·H

更紧的结论（Asadi 等）：在确定性动力学下 H 步后误差下界为 Ω(ε·H)，即**线性但随 horizon 增长**；若误差是方差型且在 OOD 区膨胀，则呈指数级。模型偏差（bias）指模型系统性偏离真实动力学，导致"在错误模型里最优"≠"在真实环境里最优"。

## 最小手算例子
单步误差 ε=0.1，H=1 时预测终点误差≈0.1；H=10 时若每步误差相加可达≈1.0，状态已偏离真实轨迹一格以上，后续动作全建立在错位置上。这就是为什么 MBPO 把模型 rollout 截断到很短（H≈1~5）。

## 对比与常见错误
- 与无模型：无模型不碰模型误差，但样本效率低；模型基用误差换样本。
- **常见错误**：在训练早期、模型还很烂时做长 horizon 规划 → 误差爆炸、策略学到"骗模型"的行为。
- 缓解手段：短 horizon（MBPO）、集成模型取不确定性、用真实数据约束（PETS 的 CEM + 不确定性裁剪）。

## 闭卷自测
1. 单步误差 ε 在 H 步开环 rollout 中如何增长？开环与闭环规划有何区别？
2. 为什么"在模型里表现好"不等于"在真实环境里表现好"？
