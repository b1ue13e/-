# PPO 工程实践与调参 (PPO Engineering & Hyperparameters)

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：PPO 理论（clip 目标、GAE）只占一半，另一半是工程实践与超参。HW 的"PPO 实现 / PPO 调参"项目直接考查这些经验值；不懂它们，PPO 要么训不动、要么方差爆炸。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 有了 PPO-Clip 公式和 GAE 优势，仍然训不出好策略：学习率太大崩、优势尺度不稳、价值网络爆炸、单步大梯度掀翻更新。

**工程实践与调参的答案**：用一组经验超参与稳定化 trick（价值裁剪、归一化、梯度裁剪、并行采样、早停、LR 衰减）把训练变稳。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：直接服务 [[PPO近端策略优化]] 的落地，配合 [[GAE广义优势估计]] 的优势估计；优化器细节见 [[梯度下降与优化器]]。
- **实际应用场景**：CleanRL / Stable-Baselines3 的 PPO 实现、MuJoCo 连续控制、Atari、LLM RLHF。
- **高频题型/任务**：给出一组超参解释其作用；诊断训练抖动的原因。

## 4. 用直觉语言解释它

> «"PPO 像一台需要调校的发动机：clip 是限速器，价值裁剪是油压阀，归一化是稳压器，梯度裁剪是保险丝，并行环境是多缸同时点火，LR 衰减是收油门前慢下来。"»

- **一句话直觉本质**：**理论给出目标，工程 trick 决定目标能否被稳定优化。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 总损失（PPO 标准组合）
$$L_{\text{total}} = \mathbb{E}\big[L^{\text{CLIP}}\big] + c_1\,(V_\phi - V_{\text{target}})^2 - c_2\,H(\pi(\cdot|s))$$
策略项 + 价值项（权重 $c_1$）+ 熵奖励（权重 $c_2$）。

### 2. 关键超参数经验值

| 参数 | 典型值 | 作用 | 过大 / 过小后果 |
| :--- | :--- | :--- | :--- |
| $\gamma$ | 0.99 | 回报折扣 | 过大回报可能发散 |
| $\lambda$ | 0.90–0.98 | GAE 偏差-方差系数 | 过近 1 引入高方差 MC 尾巴 |
| $\epsilon$ | 0.1–0.2（连续 0.2，Atari 0.1） | clip 半宽 | 过大形同无约束，过小学习慢 |
| $c_1$ | 0.5 | 价值损失权重 | 过大价值盖过策略 |
| $c_2$ | 0–0.01 | 熵奖励系数 | 过大长期随机，过小探索不足 |
| $K$ | 3–10 | 每批数据复用 epoch | 过大偏离 on-policy |
| batch | 2048–4096 步（如 128×16） | 每次收集步数 | 过小优势噪声大 |
| minibatch | 64–512 | SGD 切片 | 过小噪声大，过大欠随机 |
| LR | 1e-4–3e-4（连续），2.5e-4（Atari） | 优化步长 | 照搬监督学习 LR 易崩 |

### 3. 工程稳定化 trick（公式）

- **价值裁剪 V-clip**：$V_{\text{loss}} = \max\big((V-R)^2,\;(\mathrm{clip}(V,V_{\text{old}}-\epsilon_V,V_{\text{old}}+\epsilon_V)-R)^2\big)$，防止单步大误差主导。
- **优势归一化**：$A \leftarrow (A-\mathrm{mean}(A))/\mathrm{std}(A)$，每 batch 内稳定梯度尺度。
- **全局梯度裁剪**：$\|g\|>c$ 时 $g\leftarrow g\cdot c/\|g\|$（$c\approx0.5$）。
- **向量化环境**：一次在 $N$ 个并行副本 step，得 $[N,\dots]$ 批量，GPU 利用率高。
- **LR 衰减**：总步数内线性降到 0（或余弦退火）。
- **早停**：监控独立评估回报，连续若干轮无提升则停或回退最佳检查点。

### 4. 符号说明表

| 符号 | 含义 |
| :--- | :--- |
| $c_1, c_2$ | 价值 / 熵损失权重 |
| $K$ | 数据复用 epoch 数 |
| $\epsilon_V$ | 价值裁剪半宽 |
| $c$ | 梯度裁剪阈值 |

### 5. 常见变体与适用条件
- 连续控制：默认 $\epsilon=0.2$、$\lambda\approx0.95$–$0.99$、LR $3\times10^{-4}$。
- Atari / 图像：更小 $\epsilon$（0.1–0.2）、更大 batch。
- RLHF：额外 KL 惩罚（见 [[RLHF-PPO阶段]]），LR 更小。

---

## 6. 推导思路和思想来源

- **最初困难**：纯 clip 仍可能因价值爆炸、优势尺度飘、离群梯度而训崩。
- **关键"转念"**：把"稳定性"拆成多个独立 knob（价值、优势、梯度、学习率、并行度），各自对症。
- **工程共识**：这些经验值来自大规模复现（PPO 原文 + Spinning Up + CleanRL），是"先训稳 critic，再调 $\lambda$"等经验的形式化。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（手算）
$R=2.0,\;V_{\text{old}}=1.0,\;\epsilon_V=0.2$ → $V$ 被约束在 $[0.8,1.2]$ 附近，防价值爆炸拖垮 GAE。
$\|g\|=3.0,\;c=0.5$ → $g$ 缩到原长 $1/6$。

### 例子 2：中等例子（参数关系）
$128$ 并行环境 × $16$ 步 = $2048$ 步一批；切成 $8$ 个 $256$ 的 minibatch，重复更新 $K=4$ 轮。$K$ 过大→策略偏离采集时过远、训练不稳。

### 例子 3：实际应用例子（训练循环）
```python
for iteration:
    traj = collect_trajectories(π_old)          # 向量化环境并行采样
    compute_gae(traj, γ, λ)                       # 优势估计
    for epoch in range(K):                        # 数据复用 K 轮
        for mb in minibatches(traj):
            r = π(a|s) / π_old(a|s)
            policy_loss = -min(r*A, clip(r,1-ε,1+ε)*A).mean()
            value_loss  = (V(s)-R).pow(2).mean()
            loss = policy_loss + c1*value_loss - c2*entropy
            loss.backward(); clip_grad(g, c); optimizer.step()  # 梯度裁剪
    π_old ← π
```

## 8. 常见误区和易混概念

### 误区 1：ε 与探索 ε-greedy 混淆
- **错误直觉**：PPO 的 $\epsilon$ 是探索率。
- **为什么错**：PPO 的 $\epsilon$ 是 clip 半宽（约束概率比率），与 $\epsilon$-greedy 无关。

### 误区 2：只裁剪策略不裁剪价值
- **错误直觉**：价值网络自己会收敛。
- **为什么错**：价值爆炸会让 GAE 优势失真，必须 V-clip 保护。

### 误区 3：用训练回报早停
- **错误直觉**：训练曲线不涨就停。
- **为什么错**：应看独立评估回报，训练回报噪声大、会过拟合到奖励漏洞。

### 概念对比表

| 维度 | 调什么 | 典型手段 |
| :--- | :--- | :--- |
| 步长 | LR / 衰减 | 线性衰减到 0 |
| 梯度 | 裁剪 | 全局梯度裁剪 |
| 优势 | 尺度 | 优势归一化 |
| 价值 | 范围 | 价值裁剪 V-clip |
| 吞吐 | 并行 | 向量化环境 |
| 终止 | 时机 | 早停 |

#### 1. PPO 的 $\epsilon$ 与探索的 $\epsilon$-greedy 有何不同？如何选 $\epsilon$？
> [!question]- 答案解析
> - **答案**：PPO 的 $\epsilon$ 是 clip 半宽，约束概率比率在 $[1-\epsilon,1+\epsilon]$；$\epsilon$-greedy 是探索率。连续控制常 0.2，Atari 0.1–0.2。

#### 2. 为何要对价值网络做裁剪？它如何保护 GAE？
> [!question]- 答案解析
> - **答案**：价值网络若预测离谱，GAE 优势 $A_t$ 失真；V-clip 把 $V$ 约束在旧值邻域，防止单步大误差主导梯度。
