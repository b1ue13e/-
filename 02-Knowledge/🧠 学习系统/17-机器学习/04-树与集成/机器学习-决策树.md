# 决策树



决策树用一系列“特征 (j) 是否小于阈值 (s)”把特征空间递归切成互不重叠的区域，并在每个叶节点输出常数。回归树叶内通常预测训练响应均值；分类树输出多数类或类别比例。它能自然表达非线性、阈值效应与变量交互，但单棵深树方差很高。



## 1. 递归划分



对节点样本集合 (R)，候选切分产生 (R_L(j,s)) 与 (R_R(j,s))。回归树选择使叶内平方误差最小的切分：



$$

\min_{j,s}\left[

\sum_{i:x_i\in R_L}(y_i-\bar y_L)^2+

\sum_{i:x_i\in R_R}(y_i-\bar y_R)^2

\right].

$$



分类树常用 Gini 不纯度



$$G(R)=1-\sum_{k=1}^{K}\hat p_{Rk}^2,$$



或交叉熵 (-\sum_k\hat p_{Rk}\log\hat p_{Rk})。选择使加权子节点不纯度下降最大的切分。算法是贪心的：每一步只优化当前切分，通常不保证全局最优树。



## 2. 停止与剪枝



树若长到每个叶几乎纯净，会把噪声当规律。可用 `max_depth`、`min_samples_leaf` 等预剪枝，也可先长大树，再用代价复杂度剪枝：



$$

C_\alpha(T)=\sum_{m=1}^{|T|}\sum_{i:x_i\in R_m}(y_i-\hat y_{R_m})^2+\alpha|T|.

$$



(\alpha) 越大，越偏好叶数更少的子树。应在训练折内选择 (\alpha)，最终测试集只评估一次。



```python

from sklearn.tree import DecisionTreeClassifier

from sklearn.model_selection import GridSearchCV



search = GridSearchCV(

    DecisionTreeClassifier(random_state=42),

    {"max_depth": [2, 4, 8, None],

     "min_samples_leaf": [1, 5, 20],

     "ccp_alpha": [0.0, 0.001, 0.01]},

    scoring="balanced_accuracy", cv=5

)

search.fit(X_train, y_train)

```



## 3. 验收与误区



- 报告交叉验证选择的深度、叶节点最小样本数、叶数及样本外指标；类别不平衡时不要只看准确率。

- 树对单调缩放不敏感，通常不需要标准化，但缺失值和类别编码仍需明确处理。

- “可画出来”不等于可解释：深树路径多且对小扰动不稳定；分裂重要性也不是因果效应。

- 同一特征有多个相近切点时，样本微小变化可能产生完全不同的树。

- 若单树偏差可接受但方差大，可用[[机器学习-随机森林]]；若需要逐轮纠错，可考虑[[机器学习-XGBoost]]。



## 4. 开放教材定位



以 ISLR Chapter 8 为主线，依次掌握递归二元划分、分类不纯度与成本复杂度剪枝。验收不是背算法名，而是能说明每个停止参数改变的是偏差还是方差，并用交叉验证选择树复杂度。



例如只有“年龄”和“收入”两个特征时，根节点可先用收入阈值切分，随后每个分支再选择年龄阈值。最终边界由与坐标轴平行的矩形组成。这解释了树为何能表达交互：同一个年龄阈值在不同收入分支下可以产生不同结论；也解释了限制——斜边界可能需要许多阶梯状小区域才能逼近。最小验收应比较深度为 1、受限深度和不受限深度三棵树：训练分数通常单调提高，验证分数却可能先升后降。还应输出叶节点样本数和混淆矩阵，确认高分不是极小叶记忆噪声或多数类占优造成。
