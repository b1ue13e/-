# 神经网络



前馈神经网络把仿射变换与非线性激活逐层复合。以一层隐藏层的多层感知机（MLP）为例：



$$

H=\sigma(XW_1+b_1),\qquad

\hat Y=HW_2+b_2.

$$



若去掉非线性 (\sigma)，多层仿射变换仍可合并成单个仿射变换，深度不会增加表达能力。ReLU (\max(0,x)) 计算简单并缓解饱和梯度；sigmoid 常用于二分类输出概率，但隐藏层大量使用时可能饱和。



## 1. 训练链路



1. **前向传播**：由输入逐层计算预测和损失。

2. **反向传播**：在计算图上应用链式法则，得到每个参数的梯度。

3. **优化器更新**：SGD、Adam 等根据梯度改变参数。



[[机器学习-反向传播算法]]负责高效求梯度，不负责决定更新规则；优化器才执行参数更新。分类任务常把 logits 直接交给交叉熵函数，避免手动 softmax 后再取对数引入数值不稳定。



```python

import torch

from torch import nn



net = nn.Sequential(

    nn.Linear(2, 8), nn.ReLU(),

    nn.Linear(8, 2)

)

loss_fn = nn.CrossEntropyLoss()

opt = torch.optim.Adam(net.parameters(), lr=1e-2)



for _ in range(500):

    opt.zero_grad()

    loss = loss_fn(net(X), y)

    loss.backward()

    opt.step()

```



用 XOR 数据验收：线性分类器无法一次线性分割四点，而含非线性隐藏层的 MLP 可以拟合。实验应固定随机种子并记录训练/验证曲线；一次成功不能证明训练稳定。



## 2. 形状与参数



若输入维数为 (d)、隐藏宽度为 (h)、输出维数为 (q)，则 (W_1\in\mathbb R^{d\times h})、(b_1\in\mathbb R^h)、(W_2\in\mathbb R^{h\times q})。参数量为 (dh+h+hq+q)。先写清张量形状能提前发现大量广播和矩阵乘法错误。



## 3. 训练验收



- 先尝试在很小批样本上过拟合到近零训练损失，验证模型、损失和梯度链路能工作。

- 检查梯度是否为有限值、学习率是否导致发散、标签编码是否匹配损失函数。

- 与线性模型基线使用同一划分和[[机器学习-模型评估指标]]比较；复杂模型必须证明样本外收益。

- 用验证集选择宽度、深度、正则、早停轮数；测试集不能参与调参。



## 4. 边界与误区



神经网络是高容量函数族，不会自动获得因果性、鲁棒性或概率校准。小型表格数据上，树模型常是更强且更便宜的基线。训练损失下降也不代表泛化改善，应持续监测[[机器学习-过拟合与欠拟合]]。更深网络还会带来初始化、梯度消失/爆炸、归一化与计算成本问题；架构应由数据结构决定，而不是默认“越深越好”。

```python

import torch

import torch.nn as nn

import torch.optim as optim



# ---------------------------------------------------------------

# 1. 模拟非线性螺旋/双环二分类数据 (Non-linear Synthetic Data)

# ---------------------------------------------------------------

torch.manual_seed(42)

N = 400

# 内部同心圆 (Class 0) 与 外部同心圆 (Class 1)

r_in = torch.randn(N // 2) * 0.2 + 0.5

theta_in = torch.rand(N // 2) * 2 * 3.14159

X0 = torch.stack([r_in * torch.cos(theta_in), r_in * torch.sin(theta_in)], dim=1)



r_out = torch.randn(N // 2) * 0.2 + 1.8

theta_out = torch.rand(N // 2) * 2 * 3.14159

X1 = torch.stack([r_out * torch.cos(theta_out), r_out * torch.sin(theta_out)], dim=1)



X = torch.cat([X0, X1], dim=0) # [400, 2]

y = torch.cat([torch.zeros(N // 2, dtype=torch.long), torch.ones(N // 2, dtype=torch.long)], dim=0) # [400]



# ---------------------------------------------------------------

# 2. 多层感知机定义 (Multi-Layer Perceptron in PyTorch)

# 包含 2 个隐藏层，使用 ReLU 激活与 Dropout

# ---------------------------------------------------------------

class MLPClassifier(nn.Module):

    def __init__(self, input_dim, hidden_dim, num_classes):

        super().__init__()

        self.network = nn.Sequential(

            nn.Linear(input_dim, hidden_dim),   # W1: [2, 16]

            nn.ReLU(),

            nn.Dropout(p=0.1),                  # 随机置零防止过拟合

            nn.Linear(hidden_dim, hidden_dim),  # W2: [16, 16]

            nn.ReLU(),

            nn.Linear(hidden_dim, num_classes)  # W3: [16, 2]

        )



    def forward(self, x):

        return self.network(x)                  # [batch, 2]



model = MLPClassifier(input_dim=2, hidden_dim=16, num_classes=2)

criterion = nn.CrossEntropyLoss()

optimizer = optim.Adam(model.parameters(), lr=0.01) # 使用 Adam 优化器



# ---------------------------------------------------------------

# 3. 训练循环

# ---------------------------------------------------------------

for epoch in range(200):

    model.train()

    optimizer.zero_grad()

    logits = model(X)                # [400, 2]

    loss = criterion(logits, y)

    loss.backward()

    optimizer.step()



# 测试计算分类准确率

model.eval()

with torch.no_grad():

    test_logits = model(X)

    preds = torch.argmax(test_logits, dim=1) # [400]

    acc = (preds == y).float().mean()



print("=== PyTorch 多层神经网络 (MLP) 训练完成 ===")

print(f"最终 Loss: {loss.item():.4f}")

print(f"同心圆非线性数据集分类准确率: {acc.item() * 100:.2f}%")

```
