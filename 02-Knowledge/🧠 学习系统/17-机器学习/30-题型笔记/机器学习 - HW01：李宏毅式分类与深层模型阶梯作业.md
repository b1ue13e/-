## 2. 🎯 阶梯式 Baseline / 难度设计 (4-Tier Difficulty)

| 梯度级别 | 目标 ACC / Metric | 关键实现细节与要求 |
| :--- | :--- | :--- |
| 🟢 **L1 - Simple Baseline** | ACC ≥ 62.0% | 调用 `scikit-learn.linear_model.LogisticRegression` 跑通数据加载、标准化与验证基线。 |
| 🟡 **L2 - Medium Baseline** | ACC ≥ 71.5% | 引入特征工程（规范化 + 多项式交叉特征），使用 `XGBoost` 或手写 `LogisticRegression` (带 L2 正则)。 |
| 🔴 **L3 - Strong Baseline** | ACC ≥ 80.0% | **手写 PyTorch 3 层 DNN**：加入 `BatchNormalization`, `Dropout(0.2)`, `CosineAnnealingLR` 调度器。 |
| 👑 **L4 - Boss Baseline** | ACC ≥ 86.5% | 使用 5-Fold Cross Validation K-Fold 集成 (DNN + XGBoost + LightGBM)，在测试集冲榜。 |

## 🃏 Anki 卡片

- Q: 在深层神经网络训练中，为何 Batch Normalization 应放在 Linear 层之后、ReLU 激活函数之前？
- A: Batch Normalization 对线性输出的每个 Feature 进行均值为 0、方差为 1 的标准化，防止数据落入激活函数的饱和区，加速收敛并缓解梯度消失。
