# 🎯 感知机 (Perceptron)

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：感知机（Perceptron）由 Frank Rosenblatt 于 1957 年提出，是**人工神经网络（ANN）的鼻祖与最简神经元模型**。搞懂感知机的几何意义、判别函数、收敛定理以及著名的“XOR 异或危机”，是理解为何需要多层网络（MLP）与非线性激活函数的历史起源与理论基石。

---

## 1. 这个知识点解决什么问题？

> **We Encountered a Problem (我们遇到了什么麻烦)**：
> 1950年代，计算机刚刚问世，人们渴望制造出像人类大脑神经元一样能够根据外界输入进行“二分类决策”（例如：判断眼前的图像是猫还是狗、信号是真还是假）的机器。
> 以前的规则系统需要人类硬编码判断标准，无法自动学习。我们迫切需要一种模型，能**自动从标注数据中学习出分隔超平面（Decision Boundary）**，一旦出现分类错误，就能自动微调自己的参数权重。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：感知机是单层二分类器，多层感知机（MLP）就是由多个感知机堆叠组成的深层神经网络。如果不理解单层感知机无法解决非线性可分问题（XOR 问题），就无法真正体会多层隐藏层与非线性激活函数对深度学习的决定性价值。
- **实际应用场景**：SVM（支持向量机）与 Logistic 回归均可看作感知机在损失函数与概率化表达上的直接演进与推广。
- **高频考点/任务**：感知机学习算法 (PLA) 原始形式与对偶形式手推、感知机收敛定理 (Novikoff 定理) 证明、XOR 无法被单层感知机解决的代数证明。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景：

1. **[[17-机器学习/01-基础概念/向量内积|向量内积与超平面]]**：超平面方程 $\mathbf{w}^T \mathbf{x} + b = 0$ 中，$\mathbf{w}$ 是超平面的法向量（决定方向），$b$ 是截距（决定到原点的偏置距离）。点 $\mathbf{x}_i$ 到超平面的带符号距离正比于 $\mathbf{w}^T \mathbf{x}_i + b$。

---

## 4. 用直觉语言解释它

> «“这东西其实就像……”»

- **直觉类比**：感知机就像一个**非常严格且会自我修正的门卫**：
  - 来了一个访客（输入特征向量 $\mathbf{x}$），门卫根据各项特征赋予权重加权打分（$\mathbf{w}^T \mathbf{x} + b$）；
  - 如果总分超过 threshold（大于 0），就判放行（+1）；低于 threshold 判拒绝（-1）；
  - 一旦判错了（把坏人放进去了，或者把好人拦住了），门卫会立刻根据该访客的特征调整自己的打分偏好：放错坏人就把坏人的特征权重减掉一些；拦截好人就把好人的特征权重加上一些，直到不再犯错。
- **为什么很自然**：错误驱动（Error-driven）机制！只有犯错时才更新，没犯错就不动。
- **一句话直觉本质**：用一条直线（或超平面）切开空间，通过“看错就往正确方向微调法向量”来收敛超平面。

---

## 5. 正式定义、核心公式、符号解释

### 1. 核心定义
感知机是一个输入为特征向量 $\mathbf{x} \in \mathbb{R}^d$，输出为类别 $y \in \{-1, +1\}$ 的线性二分类模型：
$$f(\mathbf{x}) = \text{sign}(\mathbf{w}^T \mathbf{x} + b)$$

### 2. 判别函数与损失函数
符号函数定义为：
$$\text{sign}(a) = \begin{cases} +1, & a \ge 0 \\ -1, & a < 0 \end{cases}$$

感知机的损失函数定义为**误分类点到超平面的总几何距离之和**（忽略常数分母）：
$$L(\mathbf{w}, b) = -\sum_{i \in M} y_i (\mathbf{w}^T \mathbf{x}_i + b)$$
其中 $M$ 为当前所有误分类样本点的集合（当误分类时，$y_i(\mathbf{w}^T \mathbf{x}_i + b) < 0$，因此加负号使 Loss 为正数）。

### 3. 参数更新规则 (Perceptron Learning Algorithm, PLA)
对任一误分类点 $(\mathbf{x}_i, y_i) \in M$，按梯度下降更新：
$$\mathbf{w} \leftarrow \mathbf{w} + \eta y_i \mathbf{x}_i$$
$$b \leftarrow b + \eta y_i$$
其中 $\eta \in (0, 1]$ 为学习率。

### 4. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathbf{x}_i$ | 第 $i$ 个样本的特征向量 | $\mathbb{R}^d$ | 输入特征 |
| $y_i$ | 第 $i$ 个样本的真实标签 | $\{-1, +1\}$ | 二分类标签 |
| $\mathbf{w}$ | 权重向量 (Weight) | $\mathbb{R}^d$ | 超平面的法向量 |
| $b$ | 偏置 (Bias) | $\mathbb{R}$ | 超平面的偏置项 |
| $\eta$ | 学习率 (Learning Rate) | $(0, 1]$ | 参数更新步长 |
| $M$ | 误分类点集合 | $\{i \mid y_i(\mathbf{w}^T \mathbf{x}_i + b) \le 0\}$ | 错误样本 |

## 6. 推导思路和思想来源

- **最初困难**：如何定义一个可导的损失函数？如果直接统计误分类点的个数，这是一个阶跃离散函数，导数处处为 0，无法使用梯度下降。
- **关键转念**：转而计算**误分类点到决策边界的距离**！
- **推导主线**：
  1. 空间中任意一点 $\mathbf{x}_i$ 到超平面的距离为 $r_i = \frac{|\mathbf{w}^T \mathbf{x}_i + b|}{\|\mathbf{w}\|}$。
  2. 对于误分类数据 $(\mathbf{x}_i, y_i)$，因为 $y_i$ 与 $(\mathbf{w}^T \mathbf{x}_i + b)$ 异号，所以 $-y_i(\mathbf{w}^T \mathbf{x}_i + b) > 0$，故分子等于 $-y_i(\mathbf{w}^T \mathbf{x}_i + b)$。
  3. 不考虑分母 $\|\mathbf{w}\|$，得到连续可导的损失函数 $L(\mathbf{w}, b) = -\sum_{i \in M} y_i (\mathbf{w}^T \mathbf{x}_i + b)$。
  4. 对 $\mathbf{w}, b$ 求偏导：$\nabla_{\mathbf{w}} L = -\sum_{i \in M} y_i \mathbf{x}_i$，$\nabla_{b} L = -\sum_{i \in M} y_i$。
  5. 采用随机梯度下降（SGD），每次遇到一个误分类点即沿负梯度更新，即得到著名的 PLA 更新公式！

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（二维数据手算 PLA）
- **题目**：已知正例点 $x_1 = (3, 3)^T, y_1 = +1$；$x_2 = (4, 3)^T, y_2 = +1$；负例点 $x_3 = (1, 1)^T, y_3 = -1$。初始 $\mathbf{w}_0 = (0, 0)^T, b_0 = 0, \eta = 1$。求感知机决策超平面。
- **解答过程**：
  1. $i=1$: $y_1(\mathbf{w}_0^T x_1 + b_0) = 1 \times 0 = 0 \le 0$ (误分类！)。更新参数：
     $\mathbf{w}_1 = \mathbf{w}_0 + y_1 x_1 = (3, 3)^T, b_1 = 0 + 1 = 1$。
  2. 此时判别超平面为 $3x^{(1)} + 3x^{(2)} + 1 = 0$。
  3. 测试 $x_1$: $1 \times (3\times 3 + 3\times 3 + 1) = 19 > 0$ (对)；测试 $x_2$: $1 \times (3\times 4 + 3\times 3 + 1) = 22 > 0$ (对)；
  4. 测试 $x_3$: $-1 \times (3\times 1 + 3\times 1 + 1) = -7 \le 0$ (误分类！)。更新参数：
     $\mathbf{w}_2 = \mathbf{w}_1 + y_3 x_3 = (3,3)^T - (1,1)^T = (2,2)^T, b_2 = 1 - 1 = 0$。
  5. 此时超平面 $2x^{(1)} + 2x^{(2)} = 0 \implies x^{(1)} + x^{(2)} = 0$。继续迭代直至所有点无误分类，收敛于 $x^{(1)} + x^{(2)} - 3 = 0$。
- **🤔 追问**：如果初始参数变了，最终得到的超平面是一样的吗？
  - *答*：不一样！感知机的解依赖于初始值和误分类点选择的顺序，解不唯一。

### 例子 2：中等例子（XOR 异或问题的不可分证明）
证明单层感知机无法表达 XOR 异或逻辑（即输入 $(0,0)\to 0, (1,1)\to 0, (1,0)\to 1, (0,1)\to 1$）。
- **证明**：假设存在 $\mathbf{w} = (w_1, w_2)^T$ 和 $b$ 使得感知机满足：
  1. $(0,0) \implies b < 0$
  2. $(1,1) \implies w_1 + w_2 + b < 0$
  3. $(1,0) \implies w_1 + b \ge 0$
  4. $(0,1) \implies w_2 + b \ge 0$
  将 (3) 和 (4) 式相加得到 $w_1 + w_2 + 2b \ge 0$。
  结合 (1) 式 $b < 0 \implies w_1 + w_2 + b > w_1 + w_2 + 2b \ge 0$，得到 $w_1 + w_2 + b > 0$，与 (2) 式矛盾！
  故单层感知机无法解决异或问题。必须叠加隐藏层（MLP）扭曲空间！

### 例子 3：实际应用（NumPy 纯手写 PLA 分类器）

```python
import numpy as np

class Perceptron:
    def __init__(self, lr=0.1, max_epochs=1000):
        self.lr = lr
        self.max_epochs = max_epochs
        self.w = None
        self.b = 0.0

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.w = np.zeros(n_features)
        
        for _ in range(self.max_epochs):
            errors = 0
            for xi, yi in zip(X, y):
                # 如果误分类 y_i * (w^T x_i + b) <= 0
                if yi * (np.dot(xi, self.w) + self.b) <= 0:
                    self.w += self.lr * yi * xi
                    self.b += self.lr * yi
                    errors += 1
            if errors == 0:
                print("PLA 训练提前收敛！")
                break
```

## 8. 常见误区和易混概念

### 误区 1：感知机在非线性可分数据集上也能停止迭代
- **错误直觉**：“PLA 跑足够多的 Epoch 就会自动终止。”
- **为什么错**：Novikoff 证明了感知机仅在**数据集线性可分**时能在有限步内收敛。若数据集非线性可分，PLA 会在误分类点之间发生无限震荡，永不停止。
- **正确理解**：非线性可分数据集需改用口袋算法 (Pocket Algorithm) 或 Logistic 回归。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **感知机 (PLA)** | 寻找任意线性划分超平面 | 损失函数为误分类点距离，解不唯一，只能做二分类 | 神经网络最简神经元 |
| **Logistic 回归** | 估计输出为正类的概率 | 损失函数为对数似然（Cross-Entropy），平滑可导，输出概率 $[0,1]$ | 概率二分类 |
| **SVM (支持向量机)** | 寻找最大间隔 (Max Margin) 超平面 | 引入间隔与核函数，解唯一且泛化性能最强 | 高维几何硬分类 |

### 题目与解析

#### 1. 单层感知机不能解决以下哪个问题？
- A. AND 逻辑门
- B. OR 逻辑门
- C. NOT 逻辑门
- D. XOR 异或逻辑门

> [!question]- 答案解析
> - **答案**：D
> - **解析**：AND/OR/NOT 均线性可分，可通过单条直线划分；而 XOR 逻辑的四个点在二维平面上非线性可分，单层感知机无法解决。
> - **对应误区**：误区 1。

#### 2. 在 PLA 算法中，已知当前权重 $\mathbf{w} = (1, 1)^T$, $b=0$, 学习率 $\eta=0.5$。出现误分类样本 $\mathbf{x} = (2, -1)^T, y = -1$。更新后的 $\mathbf{w}'$ 和 $b'$ 为多少？
> [!question]- 答案解析
> - **答案**：$\mathbf{w}' = (0, 1.5)^T, b' = -0.5$。
> - **解析**：
>   检查误分类：$y(\mathbf{w}^T \mathbf{x} + b) = -1 \times (1\times 2 + 1\times (-1) + 0) = -1 \le 0$（确实误分类）。
>   更新权重：$\mathbf{w}' = \mathbf{w} + \eta y \mathbf{x} = (1,1)^T + 0.5 \times (-1) \times (2,-1)^T = (1,1)^T - (1, -0.5)^T = (0, 1.5)^T$。
>   更新偏置：$b' = b + \eta y = 0 + 0.5 \times (-1) = -0.5$。

#### 3. 关于感知机的收敛性，下列说法正确的是？
- A. 无论数据集是否线性可分，PLA 一定在有限步内收敛
- B. 只要数据集线性可分，PLA 的收敛解是唯一的
- C. 线性可分数据集下，PLA 必定在有限步内收敛，但解依赖于初始值和样本顺序
- D. 学习率 $\eta$ 的大小会影响 PLA 是否能找到收敛解

> [!question]- 答案解析
> - **答案**：C
> - **解析**：根据 Novikoff 收敛定理，线性可分下 PLA 必然在有限步内收敛；由于满足条件的超平面有无数条，解取决于初始值与遍历样本的顺序；学习率 $\eta$ 只影响更新步幅，不改变收敛性。

#### 4. 为什么在单层感知机中加入一个包含 Sigmoid/ReLU 激活函数的隐藏层就能解决 XOR 问题？
> [!question]- 答案解析
> - **答案**：非线性激活函数对原始输入空间进行了非线性空间变换（Warping）。
> - **解析**：隐藏层将原二维非线性可分的 4 个点映射到新的特征空间 $\mathbf{h} = (h_1, h_2)^T$，在该新空间中，原本扭曲分布的点变得线性可分，从而可以被输出层感知机用一条直线割开。

#### 5. 【证明/开放】简述感知机对偶形式 (Dual Form) 的基本思想与优势。
> [!question]- 答案解析
> - **答案**：将参数表示为样本向量的线性组合 $\mathbf{w} = \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i$。
> - **解析**：在对偶形式中，我们不再直接更新 $\mathbf{w}$，而是统计每个样本被误分类并更新的次数 $\alpha_i$。算法的核心计算退化为计算样本间的内积 $\mathbf{x}_i^T \mathbf{x}_j$。这允许我们预先计算 Gram 矩阵，并为后续引入**核函数 (Kernel Trick)** 处理非线性分类奠定了理论框架。
