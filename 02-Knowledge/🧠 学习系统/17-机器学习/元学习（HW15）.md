# 元学习（HW15）

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 常规模型学一个任务需要大量标注数据，但**新任务往往只有极少样本**：给模型看 5 张"外星动物"照片要学会认出它（5-shot），看 1 张就要会（1-shot）。从头训练不可能，直接微调预训练模型也不够——因为"如何快速适应新任务"这件事本身没学过。因此必须引入新范式：**在大量"相似结构的任务"上训练，让模型学会"如何快速学会新任务"**——元学习（Meta Learning / Learning to Learn）。目标不是学一个模型，而是学一个"能快速适应新任务的学习过程"。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW15 官方任务（Omniglot/miniImageNet few-shot）直接基于本笔记；与 [[领域自适应（HW11）]]、[[BERT自监督表征]] 构成"迁移"家族三个层次；MAML 的"初始化学习"也是现代大模型 prompt tuning 的理论先声。
- **实际应用场景**：个性化推荐冷启动、医疗罕见病识别（样本极少）、机器人快速模仿新技能、大模型 in-context learning（上下文即"任务"，参数即"元知识"）。
- **高频题型/任务**：解释 N-way K-shot 与 episode 采样；写 MAML 双层优化；对比 MAML 与 ProtoNet；对比元学习与迁移学习/领域自适应；设计 few-shot 评估协议。

3. **[[反向传播算法BP]]**：外循环需要跨内循环的梯度传播（计算图展开）。

## 4. 用直觉语言解释它

> «"元学习"就像培养一位"速记员教练"：普通学习是教速记员记一份稿件；元学习是训练教练——让他看过几百种"不同风格稿件 + 新手快速上手的过程"，总结出"如何让新手用最短时间适应任意新稿件"的**方法**。到了真正的新稿件（新任务）前，教练只需给新手一个极好的"起手姿势"（初始化），几步练习就上手。»

- **直觉类比/几何图像**：普通训练在参数空间找一个点；元学习找一个**位置**——这个位置对"任务分布中的任何任务"，几步梯度下降就能到达其最优解（MAML 找"对许多任务都易微调"的初始化）。ProtoNet 是另一条路：学一个**度量空间**——同类样本聚成类原型，新样本离哪个原型近就归哪类。人类学新概念靠"经验迁移"：见过的任务越多，"如何学习"的经验越丰富，把"学习算法"本身参数化就能用梯度下降训练它。
- **一句话直觉本质**：**元学习 = 在"任务分布"上训练"学习算法本身"：MAML 学"易微调的初始化"（优化路线），ProtoNet 学"好的度量空间"（判别路线）；few-shot 是最典型应用。**

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
**N-way K-shot**：每个 episode（任务）从类别集抽 $N$ 类，每类 $K$ 个样本构成 support set，再抽 query set。元训练：在大量 episode 上优化"元参数"；元测试：在新类别上（只用 support）快速适应并评估 query 准确率。

### 2. 核心公式
MAML 双层优化：
$$\min_\theta\ \mathbb{E}_{\tau\sim p(\mathcal{T})}\Big[\mathcal{L}_{\tau}\big(\theta-\alpha\nabla_\theta\mathcal{L}_{\tau}(\theta)\big)\Big]$$
内循环：$\theta'_\tau=\theta-\alpha\nabla_\theta\mathcal{L}_\tau(\theta)$；外循环：$\theta\leftarrow\theta-\beta\nabla_\theta\sum_\tau\mathcal{L}_\tau(\theta'_\tau)$。
ProtoNet：类原型 $c_n=\frac{1}{K}\sum_{x\in S_n}\phi(x)$，预测：
$$p(y=n\mid x)=\frac{\exp\big(-d(\phi(x),c_n)\big)}{\sum_{n'}\exp\big(-d(\phi(x),c_{n'})\big)}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\tau$ | 一个任务（episode） | 采样自 $p(\mathcal{T})$ | N-way K-shot |
| $\theta$ | 元参数（初始/度量） | $\mathbb{R}^p$ | 外层优化的对象 |
| $\alpha,\beta$ | 内/外循环学习率 | $>0$ | 内循环常 1-5 步 |
| $S_n$ | 第 $n$ 类 support 集 | $|S_n|=K$ | 原型 = 类均值 |
| $\phi(x)$ | 嵌入（度量）函数 | $\mathbb{R}^d$ | ProtoNet 学它 |
| $d(\cdot,\cdot)$ | 距离（欧氏） | $\ge 0$ | 负距离做 logits |

### 4. 常见变体与适用条件
- **变体**：MAML 家族（Reptile 一阶、iMAML）、度量家族（ProtoNet、Matching Networks、RelationNet）、优化器学习（LSTM Meta-Learner）、与 [[BERT自监督表征|预训练]] 结合的 few-shot 微调。
- **限制条件**：MAML 二阶导贵（一阶近似损失性能）；任务分布与元测试差异大时失效；way 越大越难；对"任务内样本数"敏感。

---

## 6. 推导思路和思想来源

- **最初困难**：few-shot 下经验风险最小化失效（样本远少于参数）；直接微调预训练模型也不稳（方向被噪声主导）。共享特征（预训练骨干 + 线性层）在"任务间类别完全不同"时不够；单任务学习没有"如何适应"的先验。
- **关键"转念"**：**把"任务"当成样本**——普通训练采样"数据点"，元训练采样"任务"。在任务分布上优化"适应过程"本身：MAML 优化"初始点"（从这个点出发任何任务几步梯度下降都能学好）；ProtoNet 优化"度量"（新任务上无需训练，直接最近邻分类）。
- **推导主线与动机**：① MAML：内循环模拟"新任务上微调"（1-5 步），外循环让"微调后的损失"最小——对 $\theta$ 求二阶梯度（计算图展开）；② Reptile 用"微调前后参数差"做一阶近似，大幅降开销；③ ProtoNet：放弃梯度适应，学"度量使同类聚集"（欧氏距离 + softmax 训练嵌入）；④ 本质都是"跨任务学习归纳偏置"：MAML 学优化偏置，ProtoNet 学表示偏置。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：基学习器为线性模型 $f_\theta(x)=\theta x$，任务 $\tau$ 的损失 $\mathcal{L}_\tau(\theta)=(\theta-2)^2$。初始 $\theta=0$，内循环 $\alpha=0.5$，一步。求 $\theta'$ 与外循环梯度（对 $\theta$）。
- **解题思路与关键步骤**：$\nabla_\theta\mathcal{L}_\tau(0)=2(0-2)=-4$；$\theta'=0-0.5\times(-4)=2$。外循环损失 $(2-2)^2=0$，$\frac{\partial\mathcal{L}_\tau(\theta')}{\partial\theta}=\frac{\partial\mathcal{L}_\tau}{\partial\theta'}\cdot\frac{\partial\theta'}{\partial\theta}=0\times(1-2\alpha)=0$。
- **最终答案**：$\theta'=2$，外循环梯度 $=0$（已达最优）。关键：外循环梯度经链式法则穿过内循环（含 $-2\alpha$ 项）——这是"二阶导"的来源；非凸时 $\theta$ 被推向"对多任务都几步可达"的位置。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：miniImageNet 5-way 1-shot 上，MAML 训练极慢（显存爆掉），ProtoNet 收敛快但精度低 5%。分析原因并给出改进路线。
- **解题思路与完整解答**：① MAML 慢：内循环展开计算图，显存与二阶导开销随（步数 × 任务 batch）线性增长——改用 Reptile（一阶）、减少内循环步数、降低任务 batch。② ProtoNet 精度低：欧氏距离在原始嵌入空间不够判别——增强骨干（更深/预训练）、用余弦距离 + 可学习缩放、加任务内数据增强。**关键推理**：优化派与度量派的权衡是"适应能力 vs 计算开销"：MAML 每任务微调（强适应、贵），ProtoNet 不微调（快、依赖表示质量）；HW15 报告需对比两条路线说明取舍。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW15 官方任务（Omniglot/miniImageNet few-shot）pipeline：episode 采样器（每轮抽 N 类 K+Q 样本）→ 选 MAML 或 ProtoNet → 元训练 → 元测试（新类别）报告平均准确率 ±95% 置信区间。代码骨架：
```python
def maml_inner_step(model, support_x, support_y, alpha=0.01):
    loss = F.cross_entropy(model(support_x), support_y)
    grads = torch.autograd.grad(loss, model.parameters(), create_graph=True)
    return {n: p - alpha * g for (n, p), g in zip(model.named_parameters(), grads)}

def proto_net_loss(model, support_x, support_y, query_x, query_y, n_way, k_shot):
    emb = model(torch.cat([support_x, query_x]))
    proto = emb[:n_way * k_shot].view(n_way, k_shot, -1).mean(dim=1)  # 类原型
    return F.cross_entropy(-torch.cdist(emb[n_way * k_shot:], proto), query_y)  # 欧氏距离
```

## 8. 常见误区和易混概念

### 误区 1：元学习 = 迁移学习/预训练微调
- **错误直觉**：都是"先在别处学，再用到新任务"。
- **为什么错**：预训练优化"任务内损失"（学通用特征）；元学习优化"任务分布上的适应后损失"（学**如何适应**）。MAML 的 $\theta$ 是"几步梯度下降后表现好"的初始化，不是"直接表现好"的参数。
- **正确理解**：预训练是元学习的特例（内循环 0 步 / 单任务）；元学习显式建模"适应过程"，任务差异大的 few-shot 下更优。

### 误区 2：few-shot 里模型"没训练过"，所以是零样本学习
- **错误直觉**：support set 只有几张图，模型没有"学习"。
- **为什么错**：模型在**元训练阶段**已在几百个任务上练过"如何学习"；support 用于"适应"（MAML 几步梯度下降或 ProtoNet 原型计算），这本身就是学习。
- **正确理解**：few-shot 的"学"有两层：元训练学元知识，support 上做任务级适应；"零样本"（zero-shot）才是完全无适应。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 元学习 | 学会快速适应新任务 | 优化"学习过程"（初始化/度量） | few-shot（HW15） |
| 迁移学习 | 借已有知识到新任务 | 单次迁移、无"任务分布"概念 | 预训练-微调 |
| [[领域自适应（HW11）]] | 源域→目标域分布偏移 | 同任务跨域、目标域无标签 | 跨域分类 |

### 题目与解析

#### 1. "5-way 1-shot"的准确含义？评估时为什么用新类别？
> [!question]- 答案解析
> - **答案**：每个 episode 抽 5 类、每类 1 个 support 样本（共 5 个）用于适应，再从同类抽 query 评估。元测试必须用**元训练未出现过的类别**，才能测"适应能力"而非"记忆类别"。
> - **解析**：类别不重叠是 few-shot 泛化的关键：模型见过"如何学新类别"，但没见过这些类别本身。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 任务损失 $\mathcal{L}_\tau(\theta)=(\theta-2)^2$、初始 $\theta=0$、$\alpha=0.5$，求一步内循环后的 $\theta'$ 与外循环梯度。
> [!question]- 答案解析
> - **答案**：$\theta'=0-0.5\times(-4)=2$；外循环损失 $(2-2)^2=0$，梯度 $0$（已最优）。
> - **解析**：外循环梯度 $\frac{\partial\mathcal{L}(\theta')}{\partial\theta}=\frac{\partial\mathcal{L}}{\partial\theta'}\cdot(1-2\alpha)$——链式法则穿过内循环，$(1-2\alpha)$ 即二阶信息。

#### 3. 什么情况下 ProtoNet 优于 MAML，反之亦然？
> [!question]- 答案解析
> - **答案**：计算受限、任务多、1-shot → ProtoNet（无内循环，快且稳）；任务差异大、需强适应 → MAML（显式适应，但贵）。
> - **解析**：度量派赌"表示足够好"，优化派赌"适应足够快"；实际常取折中：预训练骨干 + 度量头，或用 Reptile 降 MAML 开销。

#### 4. 预训练-微调与元学习的本质区别？为什么 few-shot 下元学习常更优？
> [!question]- 答案解析
> - **答案**：预训练优化"任务内损失"得到通用表示；元学习优化"任务分布上的适应后损失"，显式训练"适应过程"。few-shot 下样本太少，微调方向被噪声主导，而元学习让初始点"对微调友好"。
> - **解析**：预训练可看作"内循环 0 步"的元学习特例；"预训练 + 元学习"叠加是 few-shot 的最强配置。

#### 5. 论证：为什么 MAML 外循环需要二阶梯度？什么情况下一阶近似（Reptile）够用？
> [!question]- 答案解析
> - **答案**：$\theta'=\theta-\alpha\nabla_\theta\mathcal{L}_\tau(\theta)$ 是 $\theta$ 的函数，外循环目标 $\mathcal{L}_\tau(\theta')$ 对 $\theta$ 求导必须穿过内循环（链式法则产生 $\nabla_\theta^2\mathcal{L}$，即二阶梯度）；忽略它会退化成"普通训练后微调"。Reptile 用"$\theta'$ 与 $\theta$ 的差"作一阶更新方向：差方向平均了多个任务的适应方向，任务分布平滑时近似有效，且省显存。
> - **解析**：二阶项在 $\mathcal{L}_\tau$ 非凸、内循环步数多时贡献显著；一阶近似在"任务分布相似、内循环短"时损失可接受——这是 HW15"MAML vs Reptile"实验的核心结论。
