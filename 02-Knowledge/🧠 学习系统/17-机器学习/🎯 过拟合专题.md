# 🎯 过拟合专题

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：过拟合（Overfitting）是机器学习与深度学习优化中最常发生的“头号天敌”。单独成卡作为专题卡，集中梳理过拟合的底层物理机制、识别方法与工业界六大常用减过拟合技术。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 训练模型时，训练集损失降低到 0.0001，但一上线实际使用错误率高达 35%。模型将训练样本中的随机噪点、特定拍摄角度甚至背景水印误当成了核心识别特征。

以往的方法卡在：
- 盲目增加模型深度或训练 Epoch，导致“模型越学越死”；
- 缺乏系统化的工程减过拟合手段库。

过拟合专题**给出了从数据、架构、损失函数到训练过程的全方位治理框架**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：
  - **后续影响**：支撑了 [[正则化]]（L1/L2）、Early Stopping、Dropout、数据增强与集成学习的理论基础。
  - **课程位置**：属于“模型泛化与优化诊断”的的核心专题。
- **实战与科研价值**：
  - **工业调优**：遇到拟合问题时的标准操作手册。
  - **最常出现题型**：过拟合诊断、抑制过拟合手段多选题、学习曲线拐点识别题。

---

## 3. 学它之前需要哪些前置知识？

### 最小必要背景：
1. **过拟合与欠拟合**：训练误差小而测试误差大的物理现象。
2. **偏差与方差**：高方差状态（High Variance）。

---

## 4. 用直觉语言解释它

> «“这东西其实就像学生死记硬背模拟题……”»

- **过拟合表现**：学生把 100 道模拟题的答案、甚至题目右下角的页码和印刷污渍都背了下来（训练 Loss=0）。期末考试换了一套新卷子，他就完全不会推理了。
- **对策**：
  1. **减少题目难度/模型容量**：不要用高阶多项式，用低阶模型；
  2. **扣分惩罚 (正则化)**：答题纸写得太复杂就扣分；
  3. **增加新练习题 (数据增强/加数据)**：做 10,000 道题，背答案就没用了；
  4. **提前交卷 (Early Stopping)**：看到模拟考成绩最好时立马停止训练。

---

## 5. 治理过拟合的六大工程武器

### 1. 数据层面
- **增加数据量 (More Data)**：最根本解法。
- **数据增强 (Data Augmentation)**：旋转、裁剪、加噪、Mixup。

### 2. 模型结构层面
- **降低复杂度 (Reduce Capacity)**：减少参数量、减少树深度。
- **Dropout (随机丢弃)**：深度学习中随机屏蔽神经元，破坏特征共适应。
- **剪枝 (Pruning)**：决策树中的预剪枝与后剪枝。

### 3. 损失函数层面
- **正则化 (Regularization)**：加入 L1/L2 范数惩罚项 $\lambda \|w\|$。

### 4. 训练过程层面
- **早停法 (Early Stopping)**：监控 Validation Loss，拐点处停止。

---

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：诊断与治理
**题目**：在训练一个 ResNet-18 图像分类模型时，第 5 个 Epoch 时 Train Acc=80%, Val Acc=79%；第 50 个 Epoch 时 Train Acc=99.9%, Val Acc=71%。请问发生什么了？该怎么办？

**解答**：
- **诊断**：从第 5 到 50 Epoch，模型从恰当拟合走向了严重过拟合。
- **处方**：采用 Early Stopping（在第 5-10 Epoch 停止）；增加 Data Augmentation；开启 Weight Decay (L2 正则化)。

---

## 7. 常见误区和易混概念

### 误区 1：只要增加了数据，就一定能完全解决过拟合
- **错误直觉**：“数据无限多，过拟合就自动消失了。”
- **为什么错**：如果新增的数据全是同质化的重复数据，或者数据本身带有极高的标签噪声，增加数据无法消除过拟合。

   A. 相当于训练了大量子网络的集成（Ensemble），并解耦了神经元间的共适应关系

> **作业任务说明**：本作业为《过拟合》对应的高级 PyTorch 实战任务。请基于零依赖的 PyTorch Tensor/Module 代码，完成数据预处理、模型架构搭建、梯度训练循环与 4 级 Baseline 冲榜。

### 1. 4 级 Baseline 设级与冲榜拆解 (4-Tier Baseline System)

| Baseline 级别 | 评估指标 (Metric Target) | 突破核心技术 & 优化建议 |
| :--- | :--- | :--- |
| 🟢 **Simple Baseline** | 跑通代码无报错 | 搭建基础 PyTorch 模型框架，完成前向传播与 Loss 计算 |
| 🔵 **Medium Baseline** | 评估 Metric 提升 $20\%$ | **特征与损失优化**：引入数据标准化 (StandardScaler)、标签平滑或权值衰减 |
| 🟣 **Strong Baseline** | 评估 Metric 提升 $40\%$ | **架构与调度优化**：使用 `AdamW` + `CosineAnnealingLR` 余弦退火学习率调度器 |
| 🔴 **Boss Baseline** | **绝顶 SOTA 达标线** | **理论极值突破**：手写无偏估计/SVD 伪逆矩阵/K-Fold 模型集成 (Ensemble) 突破极限 |

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 过拟合 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 过拟合 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (过拟合) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```

### 3. 作业思考题与避坑指南 (Q&A & Gotchas)

1. ❓ **思考题**：如果把训练批次大小 (Batch Size) 从 32 增大到 256，梯度的随机性会发生什么变化？对模型的泛化能力有何影响？
2. ⚠️ **避坑指南 1 (梯度累积)**：每次调用 `optimizer.step()` 前务必调用 `optimizer.zero_grad()`，避免梯度无限累加。
3. ⚠️ **避坑指南 2 (模式切换)**：由于模型中包含 `nn.BatchNorm1d` 与 `nn.Dropout`，测试评估前必须显式调用 `model.eval()`。
