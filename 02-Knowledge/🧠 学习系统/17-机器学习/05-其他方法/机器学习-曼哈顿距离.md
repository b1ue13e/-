# 曼哈顿距离 (Manhattan / L1 Distance)



## 为什么学



距离度量是聚类、[[机器学习-K-means]]、kNN、[[机器学习-度量学习]] 的底层算子。除常用的欧氏（L2）距离外，**曼哈顿距离（L1）对异常值更鲁棒，且在稀疏/高维场景下更自然**（如文本词频、one-hot 特征里大量坐标为 0）。



## 定义与公式



对 `n` 维向量 `x, y`：



`d₁(x,y) = Σ_{i=1}^{n} |x_i − y_i|`



即各坐标绝对差之和，类比「城市街区只能沿格线走」的路程；对应 L1 范数 `||x−y||₁`。



## 最小例子



二维点 `x=(1,2)`、`y=(4,6)`：

`d₁ = |1−4| + |2−6| = 3 + 4 = 7`。

（对比欧氏：`√(3²+4²) = 5`。）



## 与欧氏距离的区别



- L1 对大偏差「线性惩罚」，离群点影响更小；L2 对大偏差「平方惩罚」，更易被离群点拉动。

- L1 诱导的等值线是菱形，L2 是圆；在稀疏特征上 L1 距离/正则更倾向产生零分量。



## 常见错误



- 特征量纲不一致时直接算 L1/L2 → 应先标准化/归一化，否则量纲大的维度主导距离。

- 把 L1 距离与 L1 正则（如 Lasso）混为一谈——前者是**样本间距离**，后者是**参数稀疏惩罚**，但都源于 L1 范数。

## 可执行示例（Python）



```python

import numpy as np



x, y = np.array([1, 2]), np.array([4, 6])

l1 = np.sum(np.abs(x - y))      # 曼哈顿距离 = |1-4| + |2-6| = 7

l2 = np.linalg.norm(x - y)      # 欧氏距离 = 5

print(f"L1={l1}, L2={l2:.2f}")   # 验证卡片最小例子

```

> 运行环境：Python 3.11+、numpy。把 L1 与 L2 并列计算，直观看到离群点对 L2 拉动更大。
