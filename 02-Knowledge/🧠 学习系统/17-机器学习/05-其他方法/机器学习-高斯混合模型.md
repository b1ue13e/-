# 高斯混合模型 (Gaussian Mixture Model, GMM)



## 为什么学



[[机器学习-K-means]] 给每个样本**硬分配**到一个簇，且只用质心（均值）描述簇，无法表达簇的形状、大小，也难以处理重叠簇。**GMM 用多个高斯分布的加权叠加建模数据**，给每个样本**软分配**（属于各簇的概率），并可用协方差刻画椭圆簇与重叠区域，是生成式聚类代表。



## 定义与公式



- 概率模型：`p(x) = Σ_{k=1}^{K} π_k · N(x | μ_k, Σ_k)`，其中 `Σ_k π_k = 1`，`π_k ≥ 0`。

- `N(x|μ_k,Σ_k)` 是第 `k` 个高斯分量；`π_k` 是混合权重。

- **责任（responsibility）**：样本 `x` 属于第 `k` 簇的后验概率

  `γ_{ik} = π_k · N(x_i|μ_k,Σ_k) / Σ_{j} π_j · N(x_i|μ_j,Σ_j)`。



## 学习：EM 算法



- **E 步**：用当前参数算每个样本对各分量的责任 `γ_{ik}`。

- **M 步**：用责任更新参数

  - `N_k = Σ_i γ_{ik}`（有效样本数）

  - `π_k = N_k / N`

  - `μ_k = (1/N_k) Σ_i γ_{ik} x_i`

  - `Σ_k = (1/N_k) Σ_i γ_{ik} (x_i−μ_k)(x_i−μ_k)ᵀ`

- 交替迭代至对数似然收敛。



## 最小例子



两个重叠的高斯团：K-means 会画一条硬分界线；GMM 给出每个点属于左/右团的连续概率，边界附近样本的概率接近 0.5，更符合「重叠」事实。



## 常见错误



- 把 GMM 当判别模型——它是**生成模型**，可算出 `p(x)` 与密度。

- 协方差矩阵用满秩却样本不足 → 过拟合/奇异；常用对角或 tied 协方差约束。

- 成分数 `K` 随意定 → 用 BIC/AIC 或交叉验证选择。

## 可执行示例（Python）



```python

import numpy as np

from sklearn.mixture import GaussianMixture



rng = np.random.default_rng(0)

A = rng.normal([-2, 0], 0.3, (50, 2))

B = rng.normal([2, 1], 0.3, (50, 2))

X = np.vstack([A, B])



gmm = GaussianMixture(n_components=2, covariance_type="full", random_state=0).fit(X)

print("混合权重:", gmm.weights_.round(3))

print("重叠区样本软分配(前2):\n", gmm.predict_proba(X).round(2)[:2])

```

> 运行环境：Python 3.11+、numpy、scikit-learn；`random_state=0` 保证可复现。对比 `predict_proba` 与 K-means 的硬标签，体会软分配。
