# 异常检测



## 1. 为什么学



异常检测（Anomaly Detection，也称离群点检测 Outlier Detection）的目标是找出与绝大多数样本“显著不同”的数据点。它和分类的关键区别在于：**正常样本极多、异常样本极少且事先不知道长什么样**，所以通常不能用普通监督学习。



典型场景：

- 信用卡欺诈、入侵检测、工业设备异常振动；

- 数据中心指标突刺、传感器漂移；

- 数据清洗时剔除录入错误。



> 直觉：我们先用“正常”的数据建一个模型，凡是模型解释不了的点就标记为异常。



## 2. 形式化定义



给定样本集 $X=\{x_1,\dots,x_n\}$，异常检测输出每个点的异常分数 $s(x)$，再按阈值 $\tau$ 判定：



$$

\text{异常}(x)=

\begin{cases}

1, & s(x)>\tau \\

0, & \text{否则}

\end{cases}

$$



不同方法的本质区别只在于：**用什么定义“正常”，以及异常分数 $s(x)$ 怎么算**。



## 3. 主要方法族



### 3.1 参数/统计方法（Gaussian 模型）

假设正常数据服从多元高斯分布 $\mathcal N(\mu,\Sigma)$，异常分数取负对数密度（越小概率越异常）：



$$

p(x)=\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}\exp\!\Big(-\tfrac12 (x-\mu)^\top\Sigma^{-1}(x-\mu)\Big)

$$



### 3.2 距离/密度方法（Mahalanobis + LOF）

马氏距离同时考虑均值和协方差，比欧氏距离更合理：



$$

D_M(x)=\sqrt{(x-\mu)^\top\Sigma^{-1}(x-\mu)}

$$



局部离群因子（LOF）比较一个点与其邻居的局部可达密度：LOF 显著大于 1 表示它比邻居“更稀疏”，更可能是异常。



$$

\text{LOF}_k(p)=\frac{1}{|N_k(p)|}\sum_{o\in N_k(p)}\frac{\text{lrd}_k(o)}{\text{lrd}_k(p)}

$$



### 3.3 隔离森林（Isolation Forest）

异常点“少且不同”，用随机超平面切分数据时会更快被单独隔离到很浅的叶子。异常分数 = 路径长度越短越异常。对高维、大规模数据很实用。



### 3.4 自编码器重构（深度学习）

训练自编码器最小化重构误差 $\|x-\hat x\|^2$；异常点重构误差大。适合图像、时序等复杂分布。



## 4. 关键公式小结



| 方法 | 异常分数方向 | 优点 | 缺点 |

| :--- | :--- | :--- | :--- |

| 高斯密度 | 概率越低越异常 | 可解释、快 | 假定高斯，对相关性建模弱 |

| 马氏距离 | 距离越大越异常 | 考虑协方差 | 需估计 $\Sigma$，维度高时不稳定 |

| LOF | LOF≫1 越异常 | 捕捉局部密度 | 需选 $k$，计算贵 |

| 隔离森林 | 路径越短越异常 | 大规模友好 | 随机性，需多次平均 |

| 自编码器 | 重构误差越大越异常 | 复杂分布 | 需数据、易过拟合正常样本 |



## 5. 最小可运行例子（sklearn）



```python

from sklearn.datasets import make_blobs

from sklearn.covariance import EllipticEnvelope

from sklearn.ensemble import IsolationForest



X, _ = make_blobs(n_samples=300, centers=1, cluster_std=1.0, random_state=0)

# 注入 10 个明显离群点

import numpy as np

rng = np.random.RandomState(42)

X = np.vstack([X, rng.uniform(low=-12, high=12, size=(10, 2))])



# 方法 A：稳健高斯（Elliptic Envelope）

ee = EllipticEnvelope(contamination=0.03, random_state=0).fit(X)

pred_ee = ee.predict(X)          # 1=正常, -1=异常



# 方法 B：隔离森林

iso = IsolationForest(contamination=0.03, random_state=0).fit(X)

pred_iso = iso.predict(X)



print("EE 异常数:", int((pred_ee == -1).sum()))

print("ISO 异常数:", int((pred_iso == -1).sum()))

```



运行应得到接近 10 个异常点（取决于随机种子与 `contamination`）。



## 6. 常见误区



1. **把异常当噪声直接删**：异常可能是欺诈/故障信号，先诊断再决定。

2. **用有标签的监督分类代替**：异常常“未见过的新型”，监督模型会漏掉新形态。

3. **contamination 拍脑袋**：阈值/比例应结合业务可承受成本设定，并做人工抽检。

4. **忽略特征尺度**：距离/密度方法必须先标准化，否则大尺度特征主导。

5. **训练集混入异常**：无监督方法默认训练数据是“正常”的，混入异常会污染模型。



## 7. 验收与边界



- 能通过最小例子解释每种方法的异常分数方向；

- 能根据数据规模/维度/是否有标签选择方法；

- 知道 LOF 的 $k$、隔离森林的 `contamination` 如何影响结果；

- 边界：本卡只覆盖单变量/表格型异常；时序与图结构异常需专用方法（不直接展开）。
