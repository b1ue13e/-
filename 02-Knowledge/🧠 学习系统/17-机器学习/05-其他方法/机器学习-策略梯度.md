# 策略梯度（Policy Gradient）



## 1. 为什么学



在强化学习中，有两大家族：

- **价值方法**（Q-learning / DQN）：先学动作价值 $Q(s,a)$，再由此“推导”出策略（取 $\arg\max_a Q$）。

- **策略梯度方法**：直接把策略 $\pi_\theta(a\mid s)$ 参数化，并用梯度上升最大化期望回报。



策略梯度的必要性：

1. 当动作空间**连续**（如机器人扭矩）或**随机策略**更优时，价值方法取 $\arg\max$ 不方便或无定义；

2. 可以直接优化最终关心的内容——期望回报 $J(\theta)$，而不必先精确估计价值；

3. 天然适合随机策略，能表达探索与随机最优解。



> 直觉：与其“先估价值再选动作”，不如直接“朝回报更高的动作方向扭参数”。



## 2. 策略参数化与目标函数



策略是一个参数化概率分布 $\pi_\theta(a\mid s)$（如用神经网络输出 softmax 得到离散动作概率，或输出高斯均值得到连续动作）。



目标为期望累积回报：



$$

J(\theta)=\mathbb E_{\tau\sim\pi_\theta}\Big[\sum_{t=0}^{T}\gamma^t r_t\Big]

=\mathbb E_{s_0\sim\rho_0,\ a_t\sim\pi_\theta(\cdot\mid s_t)}\big[R(\tau)\big]

$$



其中 $\tau=(s_0,a_0,s_1,\dots)$ 为一条轨迹，$\gamma$ 为折扣因子。



## 3. 策略梯度定理（核心公式）



策略梯度定理给出 $J(\theta)$ 对 $\theta$ 的梯度，无需知道状态转移动力学：



$$

\nabla_\theta J(\theta)=\mathbb E_{\tau\sim\pi_\theta}\Big[\sum_{t=0}^{T}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\;Q^{\pi_\theta}(s_t,a_t)\Big]

$$



即：对每条轨迹，在每一步用“动作的对数概率梯度”乘以“该动作的价值 $Q$”作加权，再求期望。$\nabla_\theta\log\pi_\theta$ 把梯度“指向”那些被选中动作，权重 $Q$ 决定“该往哪推、推多强”。



### REINFORCE（蒙特卡洛策略梯度）

用整条轨迹的实际回报 $G_t=\sum_{k=t}^{T}\gamma^{k-t}r_k$ 作为 $Q^{\pi}(s_t,a_t)$ 的无偏估计：



$$

\nabla_\theta J(\theta)\approx\frac1N\sum_{i=1}^N\sum_{t=0}^{T}\nabla_\theta\log\pi_\theta(a_t^{(i)}\mid s_t^{(i)})\;G_t^{(i)}

$$



## 4. 减方差：基线（Baseline）



REINFORCE 方差很大。引入与动作无关的基线 $b(s_t)$（常用价值函数 $V^\pi(s_t)$ 或滑动平均回报），因为



$$

\mathbb E_{a\sim\pi_\theta}\big[\nabla_\theta\log\pi_\theta(a\mid s_t)\,b(s_t)\big]=b(s_t)\nabla_\theta\sum_a\pi_\theta(a\mid s_t)=0

$$



所以减去基线不改变期望、只减方差。用 $A^\pi(s_t,a_t)=Q^\pi(s_t,a_t)-V^\pi(s_t)$（优势函数）替代 $Q$ 是同一思想：



$$

\nabla_\theta J(\theta)=\mathbb E\Big[\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\;A^\pi(s_t,a_t)\Big]

$$



## 5. 最小可运行例子（CartPole，PyTorch）



```python

import gym, torch, torch.nn as nn

from torch.distributed import reduce



env = gym.make("CartPole-v1")

net = nn.Sequential(nn.Linear(4, 32), nn.Tanh(), nn.Linear(32, 2))

opt = torch.optim.Adam(net.parameters(), lr=1e-2)

gamma = 0.99



for ep in range(500):

    s, _ = env.reset(); logps, rews = [], []

    done = False

    while not done:

        prob = torch.softmax(net(torch.as_tensor(s, dtype=torch.float32)), -1)

        a = torch.multinomial(prob, 1).item()

        logps.append(torch.log(prob[a]))

        s, r, terminated, truncated, _ = env.step(a)

        rews.append(r); done = terminated or truncated

    # 计算折扣回报 G_t

    G, returns = 0, []

    for r in reversed(rews):

        G = r + gamma * G; returns.insert(0, G)

    returns = torch.tensor(returns); returns = (returns - returns.mean()) / (returns.std() + 1e-8)

    loss = -torch.stack([lp * Gt for lp, Gt in zip(logps, returns)]).sum()

    opt.zero_grad(); loss.backward(); opt.step()

```



要点：损失是“负对数概率 × 优势（这里用标准化回报当基线）”，梯度上升等价于最小化该损失。



## 6. 与价值方法的对比



| 维度 | 策略梯度 | 价值方法（Q/DQN） |

| :--- | :--- | :--- |

| 输出 | 策略 $\pi_\theta$ | 价值 $Q$ |

| 连续/随机动作 | 自然支持 | 需改造 |

| 方差 / 偏差 | 高方差，需 baseline | 有近似偏差 |

| 样本效率 | 较低 | 较高 |

| 收敛 | 理论保证弱（只到局部最优） | 同左，但更稳定 |



> 实际中主流做法是二者结合：Actor-Critic（策略网络 + 价值网络当 baseline / 估计优势）。



## 7. 常见误区



1. **REINFORCE 直接减回报**：必须用“对数概率 × 回报”，不是最小化负回报本身。

2. **忘记 baseline 减方差**：训练会极不稳定、几乎不收敛。

3. **把 $\nabla_\theta\log\pi$ 写成 $\nabla_\theta\pi$**：策略梯度定理里是 **score function** $\nabla\log\pi$，不是梯度本身。

4. **连续动作直接用 softmax**：连续动作应输出高斯参数，再用重参数化采样。

5. **回合太长导致信用分配难**：长轨迹需用优势函数 / TD 残差替代整条回报。



## 8. 验收与边界



- 能独立写出策略梯度定理并解释每一项；

- 能说明 baseline 为何无偏且减方差；

- 能跑通上面的 CartPole 最小例子并解释 loss 含义；

- 边界：本卡只覆盖基础 REINFORCE + baseline；Actor-Critic、PPO、TRPO 属于进阶，不在本卡展开。



## 9. 练习



1. 在最小例子中去掉回报标准化，观察训练曲线是否更抖。

2. 把基线从“标准化回报”换成“指数滑动平均回报”，对比稳定性。

3. 推导 $\mathbb E_{a\sim\pi}[\nabla_\theta\log\pi_\theta(a\mid s)\,b(s)]=0$（一步即可）。
