# 主成分分析



主成分分析（PCA）寻找一个低维线性子空间，使中心化数据投影后的方差最大，等价地使平方重构误差最小。设数据矩阵 (X\in\mathbb R^{n\times p})，先对每列减去训练集均值，得到 (X_c)。第一主方向求解



$$

v_1=\arg\max_{\|v\|_2=1}v^\top S v,qquad

S=\frac{1}{n-1}X_c^\top X_c.

$$



解是协方差矩阵最大特征值对应的特征向量。后续方向在与前面方向正交的约束下依次最大化方差。投影得分为 (Z=X_cV_k)，近似重构为



$$

\hat X=ZV_k^\top+\mathbf1\mu^\top.

$$



同一结果可由 SVD 得到：若 (X_c=U\Sigma V^\top)，右奇异向量就是主方向，解释方差与 (\sigma_j^2/(n-1)) 成正比。SVD 通常比显式形成协方差矩阵更稳定。



## 1. 维数如何选择



第 (j) 个主成分的解释方差比为



$$

\text{EVR}_j=\frac{\lambda_j}{\sum_{r=1}^{p}\lambda_r}.

$$



累计解释方差（如 90% 或 95%）只是压缩规则，不是预测效果保证。若 PCA 服务于监督学习，应把 `StandardScaler` 和 PCA 放入交叉验证管道，用验证误差选择 (k)；不能先在全数据上拟合 PCA，否则验证集信息已泄漏。



```python

from sklearn.pipeline import make_pipeline

from sklearn.preprocessing import StandardScaler

from sklearn.decomposition import PCA

from sklearn.linear_model import LogisticRegression



pipe = make_pipeline(

    StandardScaler(), PCA(n_components=0.95),

    LogisticRegression(max_iter=2000)

)

pipe.fit(X_train, y_train)

```



## 2. 中心化、标准化与解释



中心化是标准 PCA 的必要步骤。是否除以标准差取决于量纲：若变量单位不同或方差差异主要来自尺度，应标准化；若绝对方差本身有物理意义，强制标准化可能扭曲目标。主方向符号可整体翻转而不改变子空间，所以载荷正负号本身没有唯一性。



## 3. 验收与边界



1. 记录训练集均值、尺度、所选 (k)、累计解释方差和重构误差。

2. 用留出集或交叉验证比较“原特征模型”和“PCA 后模型”，验证降维是否真正有益。

3. PCA 是无监督线性方法：最大方差方向未必最能区分类别，也无法保留弯曲流形。

4. 对异常值敏感；极端点可主导协方差与主方向。

5. 载荷描述相关结构，不提供因果解释；把主成分命名为潜在机制需要额外证据。



## 4. 开放教材定位



主线精读 MML Chapter 10 的最大方差与最小重构误差两种视角，再用 ISLR Chapter 12 的标准化、载荷图和实践案例验收。掌握标准是能从 SVD 写出投影/重构，并能解释为何 PCA 必须放在交叉验证内部。



“最大方差”和“最小重构误差”等价的关键是正交投影：总平方能量可分解为投影保留的能量与正交残差能量。固定维数时，保留最大特征值对应方向就同时保留最多方差、丢失最少平方能量。这个结论依赖欧氏距离与线性子空间；如果任务真正关心类别边界、稀有事件或非欧几里得结构，方差最大未必是正确目标。验收时应同时报告重构误差和下游任务指标，避免只凭碎石图主观选维数。
