# 🧭 开源作业体系-机器学习

> 本页是「机器学习」开源名校课程与作业的**唯一挂载点**：教材主线、官方作业链 HW01-HW15、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**李宏毅《Machine Learning》2021 Spring 官方课程**（https://speech.ee.ntu.edu.tw/~hylee/ml/2021-spring.php），配套 Colab starter 与作业代码镜像：https://github.com/ga642381/ML2021-Spring；经典 ML 入门补充轨道：**Microsoft ML for Beginners**（https://github.com/microsoft/ML-For-Beginners）。

## ✅ 验收方式与评分

1. **每个 HW（统一验收）**：① 可复现的训练脚本（固定 seed、数据路径、超参数配置，`03-Projects/projects-ml/hwXX_*/`）；② 测试集指标（官方测试数据上的最终分数/指标）；③ **1 页报告**（`reports/report_template.md` 填充）：loss 曲线、误差分析（bad cases）、与 baseline 的对照（提升幅度 + 原因）。
2. **口试验收**（每个 HW 完成后）：闭卷回答 3 个问题——"这个模型为什么选这个结构？误差主要来自哪里？你比 baseline 强在哪一步？"
3. **Capstone（结课）**：官方 Final 任务——**表格数据完整流水线**：数据清洗 → 特征工程 → 模型选择与调参 → 集成 → 结果报告（含消融与误差分析），对应 `03-Projects/projects-ml/capstone/`。
4. **满分 Rubric**：15 个 HW 全部提交且脚本可复现（60 分）+ 每个 HW 报告质量（loss 曲线/误差分析/baseline 对照齐全，20 分）+ Capstone 表格数据流水线（20 分）。
