# 自注意力机制Self-Attention

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：Self-Attention 是 Transformer（HW05）、BERT（HW07）以及全部现代大模型的**唯一地基**；HW04 的整个作业就是搭一个 attention encoder。跳过它，HW04-HW07 全部无法进行，后续看任何 NLP 论文都会卡在 Q/K/V 上。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 我们想让模型处理**变长的序列输入**（一段语音、一句话、一串帧），并且希望每个位置都能利用**整个序列的信息**。以前的方法：RNN 按顺序逐个处理，长距离信息会衰减（梯度消失），而且**无法并行**；CNN 用局部窗口，每个位置只能看到感受野内的邻居，要看远必须叠很多层。
> 因此必须引入一种机制：**让序列中任意两个位置直接交互、同时并行计算**——这就是自注意力（Self-Attention，也叫 intra-attention）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：Self-Attention → Transformer（HW05）→ BERT（HW07）；也是 CNN 作业（HW03）之后理解"全局 vs 局部建模"的关键对比点。
- **实际应用场景**：机器翻译、文本分类、语音识别（HW04 的说话人分类）、图像（ViT）、推荐系统——所有"输入是集合/序列"的任务。
- **高频题型/任务**：写出注意力公式并解释缩放因子；Q/K/V 三者的角色辨析；多头注意力的维度切分；与 RNN/CNN 的复杂度对比（$O(n^2d)$ vs $O(nd^2)$）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[🎯 多层神经网络 (MLP)]]**：线性层 $W$、激活函数、softmax 输出分布——Q/K/V 三个投影就是三个线性层。
2. **[[反向传播算法BP]]**：注意力里的矩阵乘与 softmax 都要反向传播梯度，理解链式法则即可。
3. **[[🎯 线性代数基础]]**：矩阵乘法、转置、内积的几何含义（内积 = 相似度）是点积注意力的数学底座。

---

## 4. 用直觉语言解释它

> «"自注意力"就像一场全班的"传纸条"会议：每个同学（序列中的一个 token）手里拿着一张**问题纸条**（Query）和一张**自我介绍名片**（Key），还带了一份**自己的小礼物**（Value）。会议规则是：每个人把自己的问题纸条递给全班，谁的名片和我的问题最匹配（点积大），谁的礼物我就多拿一点。最后每个人手里都捧着一份"全班按匹配度加权混合"的礼物——这就是他新的表示。"»

- **直觉类比/几何图像**：把每个 token 想成一个"提问者 + 应答者"合体。Query 是"我想找什么"，Key 是"我是什么"，Value 是"我提供什么"；注意力权重就是"找对了没有"的软开关。
- **为什么很自然**：内积 $\mathbf{q}\cdot\mathbf{k}$ 度量两个向量的相似度（方向越一致值越大），softmax 把相似度变成"对所有人加起来等于 1 的权重"，加权求和就是"按相关度混合信息"——全部是线性代数的自然组合。
- **一句话直觉本质**：**每个位置用自己的 Query 去匹配所有位置的 Key，得到权重，再按权重混合所有位置的 Value——一次计算让全局信息直接流动，且天然可并行。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **注意力（Attention）**：给定 Query 矩阵 $Q$、Key 矩阵 $K$、Value 矩阵 $V$，输出所有位置的加权混合：
$$ \text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V $$
- **自注意力（Self-Attention）**：$Q,K,V$ 由**同一个输入序列** $X$ 经三个可学习线性投影得到：$Q=XW^Q,\ K=XW^K,\ V=XW^V$。

### 2. 核心公式
多头注意力（Multi-Head Attention）：
$$\text{head}_i = \text{Attention}(XW_i^Q,\ XW_i^K,\ XW_i^V),\qquad \text{MultiHead}(X) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W^O$$
缩放因子 $\sqrt{d_k}$ 的来源：当 $q,k \in \mathbb{R}^{d_k}$ 各分量独立同分布且方差为 1 时，点积 $q\cdot k$ 的方差为 $d_k$，除以 $\sqrt{d_k}$ 把方差拉回 1，避免 softmax 输入过大导致梯度消失。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $X$ | 输入序列表示 | $\mathbb{R}^{n \times d}$ | $n$ 个 token，每个 $d$ 维 |
| $Q, K, V$ | Query / Key / Value 矩阵 | $\mathbb{R}^{n \times d_k}$（$V$ 为 $n \times d_v$） | 由 $X$ 线性投影得到 |
| $d_k$ | Key 的维度 | 正整数 | 缩放因子 $\sqrt{d_k}$ 的分母 |
| $h$ | head 数 | 通常 8 | 每个 head 的 $d_k = d/h$ |
| $n$ | 序列长度 | 正整数 | 注意力矩阵 $n \times n$ |

### 4. 常见变体与适用条件
- **变体**：self-attention（Q=K=V 同源）、cross-attention（Q 来自一个序列，K/V 来自另一个，如翻译的 encoder-decoder）、masked self-attention（只允许看左侧，用于自回归生成）。
- **适用条件**：输入是集合/序列；需要全局依赖；有足够显存（$O(n^2)$ 注意力矩阵）。
- **限制条件**：序列很长时 $n^2$ 显存爆炸（需稀疏/线性注意力变体）；本身不含位置信息，必须加**位置编码**。

---

## 6. 推导思路和思想来源

- **最初困难**：RNN 串行计算慢、长程依赖弱；CNN 局部感受野无法直接建模全局。
- **直接方法局限**：把整句拼成一个向量（pooling）会丢失词间关系；叠多层 CNN 才能"看远"，但路径长、信息易稀释。
- **关键"转念"**：**放弃"顺序/局部"的先验，让所有位置两两直接比较**——用内积当相似度、softmax 当权重、加权和当输出。这一步把"路径长度"压到 1（任意两位置一步直达）。
- **推导主线与动机**：① 内积相似度 $\to$ 权重；② softmax 归一化使权重和为 1（凸组合，数值稳定）；③ 除以 $\sqrt{d_k}$ 修正方差；④ 用 $h$ 组投影并行捕捉 $h$ 个"关系子空间"（多头）；⑤ 补位置编码恢复顺序信息（$PE_{(pos,2i)}=\sin(pos/10000^{2i/d})$）。
- **为什么自然得到此结论**：相似度加权求和（kernel smoothing）是统计学里最自然的估计方式；把"相似度"换成"可学习的双线性内积"就得到了注意力——这是从"最近邻/核方法"到"可学习版本"的一步之遥。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：两个 token，$d=2$。设 $Q=\begin{pmatrix}1&0\\0&1\end{pmatrix},\ K=I,\ V=\begin{pmatrix}1&2\\3&4\end{pmatrix}$（无缩放、无投影，直接算）。求注意力输出。
- **解题思路与关键步骤**：$QK^{\top}=I$；逐行 softmax：$\text{softmax}([1,0])=[e/(e+1),\ 1/(e+1)]\approx[0.731,0.269]$，第二行同理 $[0.269,0.731]$。输出 $= A V$：第 1 行 $=0.731\cdot(1,2)+0.269\cdot(3,4)=(1.538,2.538)$。
- **最终答案**：$\text{Output} \approx \begin{pmatrix}1.538&2.538\\2.462&3.462\end{pmatrix}$。注意每一行都是两行 $V$ 的加权平均——token 1 的输出"掺进"了 token 2 的 26.9% 信息。
- **易错点**：忘记 softmax 是**逐行**归一化（对每个 query 单独归一化，不是整个矩阵）。
- **🤔 追问**：如果 $d_k=64$ 而不缩放，会发生什么？——点积方差变成 64，softmax 输入落在 $\pm 8$ 附近，梯度几乎为 0（饱和区），训练不动。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：HW04 中 batch 里序列长度不等，需要 padding 到相同长度。请问 padding 位置为什么必须被 mask？mask 加在哪里？
- **解题思路与完整解答**：padding 的 0 向量是"假 token"，若不 mask，它们会参与 softmax 权重分配（白白分走注意力），且与真实 token 的点积可能干扰梯度。做法：把 padding 位置在 $QK^{\top}$ 中对应位置设为 $-\infty$（或加一个大的负数 mask），softmax 后权重为 0，V 的加权和不受污染。**关键推理**：mask 必须加在 softmax **之前**（加在 $QK^{\top}$ 上），加在 softmax 之后等于没加。
- **易错点**：把 mask 加在 $V$ 上（错误）；忘记 mask 只作用于 padding 列（对每个 query 行，padding 的 key 列要屏蔽）。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW04 官方任务是说话人分类——把一段语音切帧后输入 attention encoder，模型自己学会"这一帧和哪几帧最相关"（如元音段与元音段互相关），pooling 后分类。这正是 attention 相比简单平均 pooling 的价值：**自适应地挑重要帧**。
- 代码形态（PyTorch，缩放点积注意力核心）：
```python
def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)  # (B, h, n, n)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn = torch.softmax(scores, dim=-1)
    return attn @ V, attn
```

## 8. 常见误区和易混概念

### 误区 1：把注意力权重直接当"可解释性"
- **错误直觉**：attention 权重大的地方就是模型"真正关注"的地方，可以直接当解释。
- **为什么错**：权重是模型内部计算的中间量，不保证与人类语义对齐；不同层/不同 head 的权重语义完全不同，甚至有论文指出权重与梯度归因（如 LIME/SHAP）相关性很弱。
- **正确理解**：attention 权重只能作为**线索**（尤其 head 聚合后），正式解释请用 XAI 方法（HW09）。

### 误区 2：以为 Q/K/V 必须来自同一个输入
- **错误直觉**：self-attention 是唯一形态，Q 必须等于 K 的投影源。
- **为什么错**：Q 和 K/V 可以来自不同序列（cross-attention，翻译的 decoder 查 encoder 的输出）；"self" 只是指"Q/K/V 同源于一个序列"这一特例。
- **正确理解**：统一公式 $\text{softmax}(QK^{\top}/\sqrt{d_k})V$ 对任意来源的 Q/K/V 都成立。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| Self-Attention | 全局关系 + 并行 | 任意两位置一步直达，$O(n^2d)$ 显存 | Transformer 编码器、BERT |
| RNN | 顺序依赖建模 | 串行、长程衰减、$O(nd^2)$ 计算 | 短序列、流式处理 |
| CNN | 局部特征提取 | 感受野受限、平移等变、可并行 | 图像、局部 n-gram 模式 |
| 位置编码 | 恢复顺序信息 | 注意力本身置换不变，必须补位置 | 所有 transformer 类模型 |

### 题目与解析

#### 1. 在 self-attention 中，Query、Key、Value 分别扮演什么角色？
> [!question]- 答案解析
> - **答案**：Query 是"当前 token 想找什么"（提问者），Key 是"每个 token 是什么"（名片），Value 是"每个 token 提供什么内容"（礼物）；权重 = Query 与所有 Key 的相似度，输出 = 按权重混合所有 Value。
> - **解析**：三者都由同一输入经三个不同线性层投影得到，因此可以学习到不同的语义角色。
> - **易错原因**：把 Key 和 Value 混为一谈；Key 决定"被谁关注"，Value 决定"贡献什么内容"。
> - **对应误区**：误区 2（QKV 同源特例）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 写出缩放点积注意力公式，并解释为什么要除以 $\sqrt{d_k}$。
> [!question]- 答案解析
> - **答案**：$\text{Attention}(Q,K,V)=\text{softmax}(QK^{\top}/\sqrt{d_k})V$。当 $q,k$ 各分量方差为 1 时点积方差为 $d_k$，除以 $\sqrt{d_k}$ 将方差归一为 1，避免 softmax 进入饱和区导致梯度消失。
> - **解析**：若 $d_k$ 很大而不缩放，注意力权重会退化成 one-hot，训练初期梯度极小。
> - **易错原因**：写成除以 $d_k$（应开根号）；或忘记缩放只影响 softmax 前的分数。

#### 3. 什么场景下必须使用 masked attention？mask 应该加在哪里？
> [!question]- 答案解析
> - **答案**：自回归生成（decoder 预测第 $i$ 个 token 时不能看 $i$ 之后的内容）以及 batch 内 padding 时。mask 加在 $QK^{\top}$ 上（softmax 之前），被屏蔽位置置 $-\infty$。
> - **解析**：softmax 之后再乘 mask 无效，因为权重已归一化；padding mask 屏蔽"假 token 被关注"，causal mask 屏蔽"未来 token"。
> - **易错原因**：mask 位置加错（加在 V 上）；忘记 mask 值用 $-\infty$ 而非 0。
> - **对应误区**：HW04 常见坑"忘记处理 padding mask"。

#### 4. 输入 $X\in\mathbb{R}^{n\times d}$，多头注意力 $h=8$。请说明各投影矩阵的维度与每个 head 的输出维度。
> [!question]- 答案解析
> - **答案**：$W_i^Q,W_i^K\in\mathbb{R}^{d\times d_k}$，$W_i^V\in\mathbb{R}^{d\times d_v}$，其中 $d_k=d_v=d/h$；每个 head 输出 $\mathbb{R}^{n\times d_k}$，拼接后 $\mathbb{R}^{n\times d}$，再乘 $W^O\in\mathbb{R}^{d\times d}$ 得到最终 $\mathbb{R}^{n\times d}$。
> - **解析**：多头不增加参数量级（总参数仍约 $3d^2+d^2$），只是把 $d$ 维空间切成 $h$ 个子空间并行学习不同关系。
> - **易错原因**：以为每个 head 都是全维度注意力（那样参数量×h）。

#### 5. 为什么说注意力是"置换不变的"？这对序列建模意味着什么？如何补救？
> [!question]- 答案解析
> - **答案**：注意力公式只依赖两两点积与加权和，打乱 token 顺序后输出只是跟着换位（$\text{Attn}(\pi X)=\pi\,\text{Attn}(X)$），模型本身感知不到顺序。补救：在输入上加位置编码（如正弦/可学习位置嵌入），使表示携带顺序信息。
> - **解析**：这是"集合建模"的优势（不依赖顺序先验），但也是序列任务的缺陷——位置编码因此是 transformer 的必要组件。
> - **易错原因**：认为 attention 天然有序；位置编码是"加上去的"而非"内置的"。
