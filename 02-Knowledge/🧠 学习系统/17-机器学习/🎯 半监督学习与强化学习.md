# 🎯 半监督学习与强化学习

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：半监督学习（SSL）解决“高昂标注成本下利用海量无标签数据”的工业痛点；强化学习（RL）则是解决试错决策、自主智能（如 AlphaGo、具身智能机器人、ChatGPT 的 RLHF 泛化对齐）的唯一范式。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 麻烦 1：医疗 CT 数据有 100 万张，但受限于专家精力只有 1,000 张打好了标签。只用 1,000 张训模型容易过拟合，扔掉剩下的 99.9 万张无标签数据又太浪费！
> 麻烦 2：训练无人驾驶汽车或机器人打乒乓球时，没有任何静态数据集能告诉你“在 0.01 秒时手腕该精确倾斜 12.3 度”这种标准答案。

以往的方法卡在：
- 传统监督学习无法利用未标注数据；
- 传统静态数据集无法建模“连续动作-环境反馈-长期奖励”的动态试错交互过程。

半监督学习与强化学习分别提供了**“小标签+大无标数据协同学习”**与**“环境交互试错与累积奖励最大化”**的解法。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：
  - **半监督学习**：伪标签（[[伪标签|Pseudo-Labeling]]）、一致性正则（Consistency Regularization）、Self-Training。
  - **强化学习**：马尔可夫决策过程（MDP）、[[Q-Learning]]、Policy Gradient、PPO/DPO（大模型人类偏好对齐）。
- **实战与科研价值**：
  - **半监督**：极大降低数据标注成本（医学影像、工业瑕疵检测）。
  - **强化学习**：机器人控制、Game AI、大语言模型 RLHF。

## 4. 用直觉语言解释它

> «“半监督像老师点拨；强化学习像训练宠物狗……”»

- **半监督学习**：老师只精讲了 5 道例题（有标签数据），剩下 95 道题让你自学（无标签数据）。你根据 5 道例题的规律去推导 95 道题，再用自己的解答来反哺巩固知识（伪标签/自训练）。
- **强化学习**：训练狗握手。你无法给狗的大脑直接写代码。你只需给指令：如果狗伸出了爪子，你给它一块肉（正奖励 +1）；如果狗咬你，你训斥它（负奖励 -1）。经过反复试错，狗学会了“握手就能吃到肉”的最佳策略（Policy）。

## 5. 正式定义、核心公式、符号解释

### 1. 半监督学习 (SSL) 形式化
数据集 $D = D_L \cup D_U$，其中带标签集 $D_L = \{(\mathbf{x}_i, y_i)\}_{i=1}^L$，无标签集 $D_U = \{\mathbf{x}_j\}_{j=L+1}^{L+U}$（通常 $U \gg L$）。目标是同时利用 $D_L$ 的监督信息和 $D_U$ 的边际分布 $P(X)$ 提高泛化性能。

### 2. 强化学习 (RL) 形式化：马尔可夫决策过程 (MDP)
强化学习由五元组 $(S, A, P, R, \gamma)$ 严格定义：
- **状态空间 $S$**：环境当前的客观状况 $s_t \in S$。
- **动作空间 $A$**：智能体可执行的操作 $a_t \in A$。
- **状态转移概率 $P$**：$P(s_{t+1} \mid s_t, a_t)$。
- **奖励函数 $R$**：$R(s_t, a_t)$ 执行动作后获得的即时反馈。
- **折扣因子 $\gamma$**：$\gamma \in [0, 1)$，对未来奖励的衰减系数。

#### 累积折扣回报：
$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

目标是寻找最佳策略 $\pi^*(a \mid s)$，使得期望累积回报最大化 $\max_{\pi} \mathbb{E}_\pi [G_t]$。

### 例子 1：实际应用（大模型 RLHF 对齐）
**场景**：ChatGPT 的训练阶段。
1. **预训练 (无监督)**：海量文本自监督预测下一个词；

## 7. 常见误区和易混概念

### 对比表格：四大范式终极对比
| 范式 | 训练数据 | 核心反馈信号 | 典型应用 |
| :--- | :--- | :--- | :--- |
| **监督学习** | 特征 + 标签 $(X, Y)$ | 即时精确的错误标号 | 垃圾邮件、图像分类 |
| **无监督学习** | 仅特征 $X$ | 无外部反馈（自关联结构） | 用户聚类、PCA 降维 |
| **半监督学习** | 少标号 + 多无标号 | 混合反馈 + 分布平滑假设 | 医疗少样本诊断 |
| **强化学习** | 状态-动作轨迹 | 延迟、稀疏的标量奖励 $R$ | 围棋 AI、自动驾驶控制 |

3. **[公式理解] 在 MDP 中，折扣因子 $\gamma \in [0, 1)$ 设置为 0 时代表：**
   A. 智能体只关注眼前极短期的即时奖励，完全不顾未来  
   B. 智能体拥有无限远见的未来视野

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 半监督与强化学习 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 半监督与强化学习 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (半监督与强化学习) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```

### 3. 作业思考题与避坑指南 (Q&A & Gotchas)

1. ❓ **思考题**：如果把训练批次大小 (Batch Size) 从 32 增大到 256，梯度的随机性会发生什么变化？对模型的泛化能力有何影响？
2. ⚠️ **避坑指南 1 (梯度累积)**：每次调用 `optimizer.step()` 前务必调用 `optimizer.zero_grad()`，避免梯度无限累加。
3. ⚠️ **避坑指南 2 (模式切换)**：由于模型中包含 `nn.BatchNorm1d` 与 `nn.Dropout`，测试评估前必须显式调用 `model.eval()`。
