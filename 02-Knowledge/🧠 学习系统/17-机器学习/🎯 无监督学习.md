# 🎯 无监督学习

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：真实世界中 99% 的数据都是未标记的（Unlabeled Data）。无监督学习（Unsupervised Learning）无需人工标注即可从无标签数据中发现隐藏的内在结构、模式、聚类分布与低维流形，是数据挖掘、特征表示学习与生成式 AI（Generative AI）的核心基石。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 假设你手头有 10,000,000 条电商用户的浏览与消费日志，或者数 TB 的未标记基因序列。人工对每条数据打标签成本极高甚至根本不可能完成；同时你也不知道数据中具体有哪些类别或隐藏规律。

以往的方法卡在：
- 缺乏人工标准答案（Label $Y$）作为误差指导；
- 无法直接使用监督学习的损失函数（如 MSE, Cross-Entropy）进行优化。

无监督学习**通过数据自身的几何距离、统计分布、重构误差或对比约束**，自动挖掘数据内部的底层结构。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：
  - **后续影响**：包含了聚类算法（[[K-means]]、层次聚类）、降维算法（[[PCA]]、t-SNE）、密度估计（GMM）以及大模型无监督预训练（Self-Supervised Learning）。
  - **课程位置**：属于“机器学习四大范式”中第二大范式。
- **实战与科研价值**：
  - **客户分群/画像**：根据消费行为自动将用户划分为高价值/潜在/流失人群。
  - **数据压缩与可视化**：将成百上千维特征降至 2D/3D 进行可视化展示。
  - **异常检测**：偏离常规数据分布簇的孤立点识别（信用卡欺诈、网络入侵）。
  - **最常出现题型**：聚类算法性能评估指标（轮廓系数 Silhouette）、PCA 降维推导题、监督与无监督对比题。

---

## 3. 学它之前需要哪些前置知识？

### 最小必要背景：
1. **距离度量**：欧氏距离（Euclidean Distance）、余弦相似度（Cosine Similarity）。
2. **矩阵分解与特征值**：协方差矩阵、特征值分解（EVD）与奇异值分解（SVD）。

---

## 4. 用直觉语言解释它

> «“这东西其实就像整理未分类的图书堆……”»

- **场景**：有人给了你 1,000 本没有书名和分类标签的旧书。
- **任务**：你不需要知道每本书的具体书名，只需按语言（中文/英文）、厚度、封面颜色或关键词出现频率，把相似的书堆在一起（聚类），或者提炼出每本书最核心的 3 个主题词（降维）。

**直觉本质一句话**：**没有标准答案，让算法自己去发现数据中的“物以类聚，人以群分”。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
给定无标签数据集 $D = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_N\}$，其中 $\mathbf{x}_i \in \mathbb{R}^d$。无监督学习的目标是学习数据内在的概率分布 $P(X)$、模式结构或低维流形表示 $\mathbf{z}_i = g(\mathbf{x}_i) \in \mathbb{R}^k$ ($k \ll d$)。

### 2. 三大核心任务
- **聚类 (Clustering)**：将数据划分为 $K$ 个簇 $\mathcal{C}_1, \dots, \mathcal{C}_K$，使簇内距离极小，簇间距离极大。
- **降维 (Dimensionality Reduction)**：寻找低维表示空间，最大化保留原数据的方差或几何拓扑。
- **密度估计 (Density Estimation)**：估计数据生成分布 $P(X)$（如高斯混合模型 GMM）。

---

## 6. 推导思路和思想来源

### 没有 Label 怎么定义损失？
1. **距离/相似度最小化**：例如 K-Means 最小化簇内平方误差和（WCSS）：$\sum_{k=1}^K \sum_{\mathbf{x} \in \mathcal{C}_k} \|\mathbf{x} - \boldsymbol{\mu}_k\|^2$。
2. **信息保留最大化**：例如 PCA 最小化重构误差，或最大化投影后数据的方差 $\text{Var}(\mathbf{w}^T \mathbf{X})$。
3. **似然最大化**：例如 GMM 极大化对数似然 $\sum_i \log \sum_k \pi_k \mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（K-Means 聚类）
**题目**：平面上 4 个点 $(1, 1), (1, 2), (5, 5), (5, 6)$。设定 $K=2$。
- **直觉与结果**：前两个点离得很近（距离 $\le 1$），后两个点离得很近，两组之间距离为 $\sqrt{4^2+4^2} \approx 5.65$。算法会自动将前两个点归为簇 1，后两个点归为簇 2。

---

### 例子 2：实际应用例子（基因组学与降维）
**场景**：生物学家测量了 1,000 个患者的 20,000 个基因表达量（$X \in \mathbb{R}^{1000 \times 20000}$）。20,000 维无法直接绘图查看。
- **无监督降维**：使用 t-SNE 或 UMAP 算法将 20,000 维降至 2 维 $(z_1, z_2)$。
- **发现**：在 2D 散点图上，患者自动聚集成了 3 个清晰的斑块，进而发现了先前未知的 3 种癌细胞亚型。

---

## 8. 常见误区和易混概念

### 误区 1：无监督学习的性能比监督学习差
- **错误直觉**：“没有标准答案，算法肯定学不准。”
- **为什么错**：两者解决的问题类型完全不同。在特征提取、数据预训练（如 GPT/BERT 的自监督预训练）中，无监督学习能利用海量免费数据学习到比单纯监督学习更泛化的通用特征。

> **作业任务说明**：本作业为《无监督学习》对应的高级 PyTorch 实战任务。请基于零依赖的 PyTorch Tensor/Module 代码，完成数据预处理、模型架构搭建、梯度训练循环与 4 级 Baseline 冲榜。

### 1. 4 级 Baseline 设级与冲榜拆解 (4-Tier Baseline System)

| Baseline 级别 | 评估指标 (Metric Target) | 突破核心技术 & 优化建议 |
| :--- | :--- | :--- |
| 🟢 **Simple Baseline** | 跑通代码无报错 | 搭建基础 PyTorch 模型框架，完成前向传播与 Loss 计算 |
| 🔵 **Medium Baseline** | 评估 Metric 提升 $20\%$ | **特征与损失优化**：引入数据标准化 (StandardScaler)、标签平滑或权值衰减 |
| 🟣 **Strong Baseline** | 评估 Metric 提升 $40\%$ | **架构与调度优化**：使用 `AdamW` + `CosineAnnealingLR` 余弦退火学习率调度器 |
| 🔴 **Boss Baseline** | **绝顶 SOTA 达标线** | **理论极值突破**：手写无偏估计/SVD 伪逆矩阵/K-Fold 模型集成 (Ensemble) 突破极限 |

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 无监督学习 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 无监督学习 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (无监督学习) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```

### 3. 作业思考题与避坑指南 (Q&A & Gotchas)

1. ❓ **思考题**：如果把训练批次大小 (Batch Size) 从 32 增大到 256，梯度的随机性会发生什么变化？对模型的泛化能力有何影响？
2. ⚠️ **避坑指南 1 (梯度累积)**：每次调用 `optimizer.step()` 前务必调用 `optimizer.zero_grad()`，避免梯度无限累加。
3. ⚠️ **避坑指南 2 (模式切换)**：由于模型中包含 `nn.BatchNorm1d` 与 `nn.Dropout`，测试评估前必须显式调用 `model.eval()`。
