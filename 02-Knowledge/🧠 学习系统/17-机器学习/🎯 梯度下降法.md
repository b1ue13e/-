# 🎯 梯度下降法

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：梯度下降法（Gradient Descent）是现代机器学习与深度学习中**求解模型参数的核心优化引擎**。从线性回归、Logistic 回归到千亿参数的大语言模型（LLM），几乎所有无解析解模型的求解均依赖梯度下降及其变体（SGD, Adam）。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 定义好了模型 $f(x; \mathbf{w})$ 和损失函数 $J(\mathbf{w})$ 之后，我们希望找到一组最佳参数 $\mathbf{w}^*$ 使损失最小。然而对于复杂的非线性函数或高维参数，直接令导数等于零求解方程 $
abla J(\mathbf{w}) = 0$ 极其困难甚至根本无法求出解析解（Analytical Solution）！

以往的方法卡在：
- 复杂非凸或高维函数无法通过代数运算直接解出最小值；
- 随机盲目搜索参数效率极低，面对上百万维参数如同大海捞针。

梯度下降法**提供了一种基于局部导数方向迭代下山的通用优化框架**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：
  - **后续影响**：理解批量梯度下降（BGD）、随机梯度下降（SGD）、小批量梯度下降（Mini-batch GD）以及动量法（Momentum）、Adam 优化器的基础。
  - **课程位置**：属于“模型三要素之算法 (Algorithm/Optimizer)”的基石。
- **实战与科研价值**：
  - **超参调优**：学习率（Learning Rate $\alpha$）的选择直接决定了模型收敛速度与稳定性。
  - **最常出现题型**：梯度计算与单步更新手算题、学习率过大/过小现象辨析题、SGD 与 BGD 优缺点对比题。

---

## 3. 学它之前需要哪些前置知识？

### 最小必要背景：
1. **多元函数偏导数与梯度**：函数 $J(\mathbf{w})$ 在点 $\mathbf{w}$ 处的梯度 $
abla J(\mathbf{w})$ 是一个向量，指向函数增长最快的方向。
2. **泰勒展开（一阶）**：$J(\mathbf{w} + \Delta\mathbf{w}) \approx J(\mathbf{w}) + 
abla J(\mathbf{w})^T \Delta\mathbf{w}$。

---

## 4. 用直觉语言解释它

> «“这东西其实就像盲人深夜下山……”»

- **场景**：你被困在一个迷雾笼罩、伸手不见五指的山顶（高损失位置），目标是走到山谷最低处（最小损失点）。
- **策略**：
  1. 用脚感受四周地面的倾斜程度（计算梯度 $
abla J$）；
  2. 找到陡峭程度最大的下坡方向（梯度的反方向 $-
abla J$）；
  3. 迈出固定长度的一步（乘以学习率 $\alpha$）；
  4. 重复以上步骤，直到脚下地面变平（梯度接近 0）。

**直觉本质一句话**：**沿着函数下降最快的方向一步一步小步迭代，最终到达局部极小值点。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 核心更新公式
设目标函数为 $J(\mathbf{w})$，参数在第 $t$ 次迭代的值为 $\mathbf{w}^{(t)}$，梯度下降的参数更新规则为：

$$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \alpha 
abla J(\mathbf{w}^{(t)})$$

### 2. 梯度与一阶泰勒推导逻辑
要使 $J(\mathbf{w}^{(t+1)}) < J(\mathbf{w}^{(t)})$，根据一阶泰勒展开：
$$J(\mathbf{w}^{(t)} + \Delta\mathbf{w}) \approx J(\mathbf{w}^{(t)}) + 
abla J(\mathbf{w}^{(t)})^T \Delta\mathbf{w}$$
若取步长 $\Delta\mathbf{w} = -\alpha 
abla J(\mathbf{w}^{(t)})$ （其中 $\alpha > 0$），则：
$$
abla J(\mathbf{w}^{(t)})^T \Delta\mathbf{w} = -\alpha \|
abla J(\mathbf{w}^{(t)})\|^2 \le 0$$
确保了每次迭代损失函数严格单调递减。

### 3. 符号解释表
| 符号 | 含义 | 取值范围/量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathbf{w}$ | 模型可训练参数矢量 | $\mathbb{R}^d$ | 优化的自变量 |
| $J(\mathbf{w})$ | 目标损失函数 | $\mathbb{R}_{\ge 0}$ | 优化的因变量 |
| $
abla J(\mathbf{w})$ | 损失函数对参数的梯度向量 | $\mathbb{R}^d$ | 指向增长最快的方向 |
| $\alpha$ | 学习率 (Learning Rate / 步长) | $\alpha > 0$（通常 1e-4 ~ 0.1）| 控制每步下山距离 |

---

## 6. 推导思路和思想来源

### 为什么梯度负方向是下降最快的方向？
设步长向量为 $\Delta\mathbf{w}$，且模长有限 $\|\Delta\mathbf{w}\| = \epsilon$。根据内积性质：
$$
abla J(\mathbf{w})^T \Delta\mathbf{w} = \|
abla J(\mathbf{w})\| \cdot \|\Delta\mathbf{w}\| \cdot \cos\theta$$
当 $\theta = \pi$（即 $\Delta\mathbf{w}$ 与梯度方向相反）时，$\cos\theta = -1$，内积取得最小值且负得最多！因此，**梯度的负方向 $-
abla J(\mathbf{w})$ 是函数值下降最快的方向**。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（一维二次函数手工迭代）
**题目**：目标函数 $J(w) = w^2 - 4w + 5$。初始值 $w^{(0)} = 0$，学习率 $\alpha = 0.1$。请手工计算第 1 次和第 2 次迭代后的 $w$ 值及损失。

**解答过程**：
1. **求导**：$J'(w) = 2w - 4$。
2. **第 1 次迭代**：
   - 梯度 $J'(0) = -4$；
   - 更新 $w^{(1)} = 0 - 0.1 \times (-4) = 0.4$；
   - 损失 $J(0.4) = 0.4^2 - 4(0.4) + 5 = 3.56$（从 5 降至 3.56）。
3. **第 2 次迭代**：
   - 梯度 $J'(0.4) = 2(0.4) - 4 = -3.2$；
   - 更新 $w^{(2)} = 0.4 - 0.1 \times (-3.2) = 0.72$；
   - 损失 $J(0.72) = 2.6416$。
- **理论极小值**：$w^* = 2, J(w^*)=1$。

---

### 例子 2：中等例子（学习率的影响）
**题目**：针对上述函数 $J(w) = w^2 - 4w + 5$，如果设置学习率 $\alpha = 1.1$，从 $w^{(0)}=0$ 开始迭代，会发生什么？

**解答**：
- 梯度 $J'(0) = -4$；
- $w^{(1)} = 0 - 1.1 \times (-4) = 4.4$；
- $J'(4.4) = 2(4.4) - 4 = 4.8$；
- $w^{(2)} = 4.4 - 1.1 \times (4.8) = -0.88$。
- **结论**：$w$ 在极小值 $w=2$ 左右两边剧烈来回发散振荡（$0 \to 4.4 \to -0.88 \to \dots$），损失爆表。说明**学习率过大会导致不收敛/发散**。

---

### 例子 3：实际应用例子（三类梯度下降对比）
**场景**：在 100 万条样本的线性回归模型中选择优化算法：
1. **批量梯度下降 (BGD)**：每次更新计算全量 100 万条样本的梯度。**缺点**：太慢，单次迭代内存爆表。
2. **随机梯度下降 (SGD)**：每次只随机挑 1 条样本计算梯度更新。**优点**：极快；**缺点**：梯度噪声极大，路线弯弯曲曲。
3. **小批量梯度下降 (Mini-batch GD)**：每次取 256 条样本组成 Batch 计算梯度。**结果**：兼顾了计算效率与收敛平滑度，成为深度学习工业界标准。

---

## 8. 常见误区和易混概念

### 误区 1：梯度下降一定能找到全局最小值（Global Minimum）
- **错误直觉**：“只要一直下降，就一定能走到最低的谷底。”
- **为什么错**：对于非凸函数（Non-convex Function，如深度神经网络），梯度下降很容易陷入**局部极小值（Local Minima）**或**鞍点（Saddle Points）**（梯度为 0 但不是最小值）。

1. **[公式计算] 已知损失函数 $J(w) = 3w^2$，初始 $w=2$，学习率 $\alpha=0.1$，单步更新后的 $w$ 为：**
   A. 0.8  B. 1.2  C. 1.8  D. -0.4
> [!question]- 答案解析
> **答案**：A  
> **解析**：$J'(w) = 6w$；当 $w=2$ 时，梯度为 12。更新 $w = 2 - 0.1 \times 12 = 0.8$。

2. **[现象分析] 在训练模型时发现 Loss 发生剧烈震荡且持续增大，最可能的原因是：**
   A. 学习率设置过小  B. 学习率设置过大  C. 训练样本太多  D. 迭代次数不够
> [!question]- 答案解析
> **答案**：B  
> **解析**：学习率过大会导致更新步子太大跨过极小值点，引发发散与 Loss 震荡上升。  
> **标签**：`#自测/基础 #学习率`

3. **[算法辨析] 关于随机梯度下降（SGD），下列说法正确的是：**
   A. SGD 每次使用全部样本计算梯度  
   B. SGD 的单次迭代计算开销远低于 BGD，且随机噪声有助于跳出浅局部极小值  
   C. SGD 的损失下降曲线比 BGD 更平滑

> **答案**：B

> **标签**：`#自测/中等 #SGD`

4. **[条件判断] 在高维非凸优化中，使得梯度 $
abla J(\mathbf{w}) = \mathbf{0}$ 但既不是极大值也不是极小值的点被称为：**
   A. 全局最小值  B. 鞍点 (Saddle Point)  C. 离群点  D. 拐点
> [!question]- 答案解析
> **答案**：B  
> **解析**：鞍点在一个方向上是极小值，在另一个方向上是极大值，梯度为 0。  
> **标签**：`#自测/中等 #鞍点`

5. **[理论证明] 为什么对于 Lipschitz 连续梯度的函数，学习率满足 $\alpha < \frac{2}{L}$ 时能保证梯度下降单调收敛？**
> [!question]- 答案解析
> **答案**：根据 descent lemma，$J(\mathbf{w}^{(t+1)}) \le J(\mathbf{w}^{(t)}) - \alpha(1 - \frac{\alpha L}{2})\|
abla J(\mathbf{w}^{(t)})\|^2$。只要 $1 - \frac{\alpha L}{2} > 0$（即 $\alpha < \frac{2}{L}$），后项就恒负，保证损失值单调递减。  
> **标签**：`#自测/较难 #收敛性证明`

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 梯度下降法 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 梯度下降法 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (梯度下降法) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```

### 3. 作业思考题与避坑指南 (Q&A & Gotchas)

1. ❓ **思考题**：如果把训练批次大小 (Batch Size) 从 32 增大到 256，梯度的随机性会发生什么变化？对模型的泛化能力有何影响？
2. ⚠️ **避坑指南 1 (梯度累积)**：每次调用 `optimizer.step()` 前务必调用 `optimizer.zero_grad()`，避免梯度无限累加。
3. ⚠️ **避坑指南 2 (模式切换)**：由于模型中包含 `nn.BatchNorm1d` 与 `nn.Dropout`，测试评估前必须显式调用 `model.eval()`。
