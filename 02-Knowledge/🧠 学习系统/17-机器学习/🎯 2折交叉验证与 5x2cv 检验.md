# 🎯 2折交叉验证与 5x2cv 检验

---

## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具，重点掌握例题和应用）**
- **判断理由**：2折交叉验证（2-Fold CV）是 K-Fold 交叉验证的特例（$K=2$）。虽然单次 2 折评估由于训练集只有 50% 可能会悲观估计参数，但扩展形式 **5 次 2 折交叉验证成对 t 检验（5x2cv Paired t-Test）** 是学术界解决“传统 10 折交叉验证各折重叠导致假阳性率（Type-I Error）偏高”问题的标准工具。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 在使用传统的 10 折交叉验证做成对 t 检验时，各折的训练集有 90% 的重叠数据，导致求出的 10 个误差差值高度相关、估计出的差值标准差偏小，$t$ 统计量虚高，经常误把无差异的算法判定为有显著差异（第一类错误/假阳性高）。

5x2cv 假设检验**通过 5 次独立的 2 折交叉验证，并在统计量中显式校正相关性**，保证了严格的 5% 假阳性率控制。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：
  - **后续影响**：应用于学术论文中高可靠性的算法对比；作为 [[比较检验]] 的标准算法之一。
- **实战与科研价值**：
  - **统计学可靠性**：相比于普通的 10 折 t 检验，5x2cv 被 Dietterich (1998) 证明具有最佳的 Type-I 错误控制能力。

---

## 3. 学它之前需要哪些前置知识？

### 最小必要背景：
1. **K 折交叉验证**：数据集平均切分为 $K$ 份。
2. **假设检验与 t 检验**：构建统计量并计算自由度。

---

## 4. 用直觉语言解释它

> «“这东西其实就像两组选手交换场地背靠背 PK 五轮……”»

- **单次 2 折**：把数据集五五对半切成 A 和 B。第一轮 A 训练 B 测试，第二轮 B 训练 A 测试。
- **5 次重复 (5x2cv)**：重复进行 5 次独立的对半切分与角色互换（共 10 次训练测试）。
- **优势**：由于每次训练集只有一半，两半之间完全不重叠，大大降低了样本重叠带来的相关性。

---

## 5. 正式定义与 5x2cv 统计量公式

### 5x2cv 成对 t 检验统计量
设第 $i$ 次（$i=1\dots 5$）2 折交叉验证中，第 1 折的差值为 $p_i^{(1)}$，第 2 折的差值为 $p_i^{(2)}$。
第 $i$ 次变化的样本方差为 $s_i^2 = (p_i^{(1)} - \bar{p}_i)^2 + (p_i^{(2)} - \bar{p}_i)^2$（自由度为 1）。

构建 5x2cv $t$ 统计量：

$$t = \frac{p_1^{(1)}}{\sqrt{\frac{1}{5} \sum_{i=1}^5 s_i^2}} \sim t(5)$$

**自由度为 5**。当 $|t| > t_{0.025, 5} = 2.571$ 时，拒绝原假设，宣称两算法差异显著。

---

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：计算 5x2cv 统计量
**题目**：假设第 1 次 2 折的第一折差值 $p_1^{(1)} = 0.04$，5 次 2 折的方差和 $\sum_{i=1}^5 s_i^2 = 0.0005$。判断两算法是否有显著差异（自由度 5 的临界值为 2.571）。

**解答**：
$$t = \frac{0.04}{\sqrt{\frac{1}{5} \times 0.0005}} = \frac{0.04}{\sqrt{0.0001}} = \frac{0.04}{0.01} = 4.0$$
由于 $|t| = 4.0 > 2.571$，拒绝原假设，认为差异显著。

## 7. 常见误区和易混概念

### 普通 10 折 t 检验 vs 5x2cv t 检验
| 维度 | 普通 10 折 t 检验 | 5x2cv t 检验 |
| :--- | :--- | :--- |
| **自由度** | 9 | 5 |
| **训练集重叠度** | 90%（相关性极高） | 50%（相关性显著降低） |
| **假阳性率 (Type-I Error)** | 较高（容易误报显著差异） | 严格控制在 5% |

### 1. 4 级 Baseline 设级与冲榜拆解 (4-Tier Baseline System)

| :--- | :--- | :--- |
| 🟢 **Simple Baseline** | 跑通代码无报错 | 搭建基础 PyTorch 模型框架，完成前向传播与 Loss 计算 |
| 🔵 **Medium Baseline** | 评估 Metric 提升 $20\%$ | **特征与损失优化**：引入数据标准化 (StandardScaler)、标签平滑或权值衰减 |
| 🟣 **Strong Baseline** | 评估 Metric 提升 $40\%$ | **架构与调度优化**：使用 `AdamW` + `CosineAnnealingLR` 余弦退火学习率调度器 |

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 2折交叉验证 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 2折交叉验证 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (2折交叉验证) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```

### 3. 作业思考题与避坑指南 (Q&A & Gotchas)

1. ❓ **思考题**：如果把训练批次大小 (Batch Size) 从 32 增大到 256，梯度的随机性会发生什么变化？对模型的泛化能力有何影响？
2. ⚠️ **避坑指南 1 (梯度累积)**：每次调用 `optimizer.step()` 前务必调用 `optimizer.zero_grad()`，避免梯度无限累加。
3. ⚠️ **避坑指南 2 (模式切换)**：由于模型中包含 `nn.BatchNorm1d` 与 `nn.Dropout`，测试评估前必须显式调用 `model.eval()`。
