# 算法稳定性

稳定性理论：从**算法本身的稳定性**角度推导泛化界，而非假设空间复杂度。

---

## 核心定义：均匀稳定性

算法 $A$ 是 $\beta$-均匀稳定的，若对任意训练集 $S$ 和其任意单点替换 $S^i$：

$$\sup_z |L(A_S, z) - L(A_{S^i}, z)| \leq \beta$$

替换一个样本，损失改变不超过 $\beta$——算法"对单点不敏感"。

---

## 稳定性→泛化

均匀稳定性 $\beta$ 的算法，泛化差距以高概率有界：

$$R(A_S) - R_{emp}(A_S) \leq 2\beta + O\left(\sqrt{\frac{\ln(1/\delta)}{m}}
ight)$$

$\beta$ 小（稳定）→ 泛化好。

---

## 正则化提升稳定性

带L2正则化的损失最小化（如SVM、岭回归）的均匀稳定性：

$$\beta = \frac{L^2}{\lambda m}$$

$\lambda$ 越大（正则化越强）→ $\beta$ 越小 → 越稳定 → 泛化越好。

这给出了L2正则化为什么有效的理论解释。

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 稳定性 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 稳定性 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (稳定性) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```
