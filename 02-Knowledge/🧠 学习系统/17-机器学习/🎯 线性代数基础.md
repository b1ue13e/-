# 🎯 线性代数基础

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：线性代数是机器学习表示数据与向量计算的“物理结构语言”。数据集以矩阵存储，模型参数以向量表达，主成分分析（PCA）依赖特征值分解，推荐系统与降维依赖 SVD 奇异值分解。不掌握线性代数无法理解高维几何与矩阵求导。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 假设你需要处理 100,000 个用户、每个用户包含 500 个维度的特征。如果你用标量循环 `for i in range(...)` 写代码，运算速度极其缓慢且数学公式表达繁琐至极。

线性代数**用向量、矩阵与张量统一了高维数据表示**，并通过矩阵乘法实现了高性能并行向量化运算（Vectorization）。

## 4. 用直觉语言解释它

> «“这东西其实就像空间的线性拉伸与旋转……”»

- **向量 $\mathbf{x}$**：高维空间中的一个点或带方向的箭头。
- **矩阵 $\mathbf{A}$**：对空间进行线性变换的“操作机器”。矩阵乘法 $\mathbf{A}\mathbf{x}$ 就是把向量 $\mathbf{x}$ 旋转、拉伸、缩放到新的位置。
- **特征向量 $\mathbf{v}$ 与特征值 $\lambda$ ($\mathbf{A}\mathbf{v} = \lambda \mathbf{v}$)**：在空间被矩阵 $\mathbf{A}$ 剧烈拉伸旋转时，只有极其特殊的方向 $\mathbf{v}$ **方向保持不变，只被纯粹拉伸了 $\lambda$ 倍**。这个方向代表了变换的主轴方向。

---

## 5. 正式定义、核心公式、符号解释

### 1. 特征值 decomposition (EVD)
对 $n \times n$ 对称矩阵 $\mathbf{A}$：

$$\mathbf{A} = \mathbf{Q} \mathbf{\Lambda} \mathbf{Q}^T = \sum_{i=1}^n \lambda_i \mathbf{q}_i \mathbf{q}_i^T$$

其中 $\mathbf{Q}$ 为正交矩阵（特征向量），$\mathbf{\Lambda} = \text{diag}(\lambda_1, \dots, \lambda_n)$ 为特征值。

### 2. 奇异值分解 (SVD)
对任意 $m \times n$ 矩阵 $\mathbf{A}$：

$$\mathbf{A} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$$

- $\mathbf{U} \in \mathbb{R}^{m \times m}$：左奇异向量（$\mathbf{A}\mathbf{A}^T$ 的特征向量）；
- $\mathbf{\Sigma} \in \mathbb{R}^{m \times n}$：奇异值对角阵 $\sigma_i = \sqrt{\lambda_i}$；
- $\mathbf{V} \in \mathbb{R}^{n \times n}$：右奇异向量（$\mathbf{A}^T\mathbf{A}$ 的特征向量）。

### 3. 常用矩阵求导公式
- $\frac{\partial (\mathbf{a}^T \mathbf{x})}{\partial \mathbf{x}} = \mathbf{a}$
- $\frac{\partial (\mathbf{x}^T \mathbf{A} \mathbf{x})}{\partial \mathbf{x}} = (\mathbf{A} + \mathbf{A}^T)\mathbf{x}$ （若 $\mathbf{A}$ 对称，则为 $2\mathbf{A}\mathbf{x}$）

---

## 6. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（矩阵求导推导 OLS）
**题目**：最小二乘损失函数为 $J(\mathbf{w}) = \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2 = (\mathbf{y} - \mathbf{X}\mathbf{w})^T(\mathbf{y} - \mathbf{X}\mathbf{w})$。试推导对 $\mathbf{w}$ 的梯度并求封闭解。

**解答**：
1. 展开：$J(\mathbf{w}) = \mathbf{y}^T\mathbf{y} - 2\mathbf{w}^T\mathbf{X}^T\mathbf{y} + \mathbf{w}^T\mathbf{X}^T\mathbf{X}\mathbf{w}$。
2. 求导：$\frac{\partial J}{\partial \mathbf{w}} = -2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\mathbf{w}$。
3. 令梯度为 0：$\mathbf{X}^T\mathbf{X}\mathbf{w} = \mathbf{X}^T\mathbf{y} \implies \mathbf{w}^* = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$。

## 7. 常见误区和易混概念

### EVD vs SVD
| 维度 | 特征值分解 (EVD) | 奇异值分解 (SVD) |
| :--- | :--- | :--- |
| **应用矩阵类型** | 只能用于**方阵**（最好是对称方阵） | 可用于**任意形状**的 $m \times n$ 矩阵 |
| **几何意义** | 同一个空间内的缩放变换 | 从 $n$ 维空间到 $m$ 维空间的旋转+缩放+旋转 |
| **机器学习应用** | 协方差矩阵对角化 (PCA) | 图像压缩、推荐系统 (LSA / Matrix Factorization) |

## 10. 自测题：5 道

| 题号 | 类型 | 难度 | 考查点 |
| :--- | :--- | :--- | :--- |
| 1 | 几何理解 | 基础 | 特征向量几何含义 |
| 2 | 公式求导 | 基础 | 向量微分公式 |
| 3 | 矩阵性质 | 中等 | 正交矩阵性质 |
| 4 | SVD 应用 | 中等 | SVD 与低秩近似 |
| 5 | 迹与范数 | 较难 | 矩阵迹 (Trace) 与 Frobenius 范数 |

1. **[几何理解] 矩阵 $\mathbf{A}$ 作用于其特征向量 $\mathbf{v}$ 上时，其几何效果等价于：**
   A. 将向量 $\mathbf{v}$ 旋转 90 度  
   B. 保持 $\mathbf{v}$ 的方向不变（或反向），仅沿该方向进行 $\lambda$ 倍的缩放  
   C. 将向量归一化为 0  
   D. 投影到正交空间
> [!question]- 答案解析
> **答案**：B  
> **解析**：根据 $\mathbf{A}\mathbf{v}=\lambda\mathbf{v}$，变换仅改变模长 $\lambda$ 倍，方向保持不变。  
> **标签**：`#自测/基础 #特征向量`

2. **[公式求导] 若 $\mathbf{A}$ 为对称矩阵，则向量标量函数 $f(\mathbf{x}) = \mathbf{x}^T \mathbf{A} \mathbf{x}$ 对 $\mathbf{x}$ 的梯度为：**
   A. $\mathbf{A}\mathbf{x}$  B. $2\mathbf{A}\mathbf{x}$  C. $\mathbf{A}^T\mathbf{x}$  D. $\mathbf{x}$
> [!question]- 答案解析
> **答案**：B  
> **解析**：对称矩阵下 $\frac{\partial (\mathbf{x}^T\mathbf{A}\mathbf{x})}{\partial \mathbf{x}} = 2\mathbf{A}\mathbf{x}$。  
> **标签**：`#自测/基础 #矩阵求导`

3. **[矩阵性质] 正交矩阵 $\mathbf{Q}$ 满足 $\mathbf{Q}^T \mathbf{Q} = \mathbf{I}$，其对向量 $\mathbf{x}$ 进行变换 $\mathbf{y} = \mathbf{Q}\mathbf{x}$ 时，不变的物理量是：**
   A. 向量的方差  B. 向量的模长（L2 范数 $\|\mathbf{y}\|_2 = \|\mathbf{x}\|_2$）  C. 矩阵的秩  D. 均值
> [!question]- 答案解析
> **答案**：B  
> **解析**：正交变换保内积且保模长，保范数不变（只作旋转/镜像）。  
> **标签**：`#自测/中等 #正交矩阵`

4. **[SVD 应用] 在图像压缩中，使用 SVD 截断前 $k$ 项奇异值（$k \ll \min(m,n)$）能够实现高压缩比，其理论依据是 Eckart-Young 定理，该定理证明了截断 SVD 是原矩阵的：**
   A. 最佳低秩近似 (Best Low-Rank Approximation)  
   B. 绝对无损压缩  
   C. 正交基扩展  
   D. 稀疏投影
> [!question]- 答案解析
> **答案**：A  
> **解析**：截断 SVD 在 Frobenius 范数下是原矩阵的最优 $k$ 秩逼近。  
> **标签**：`#自测/中等 #SVD低秩近似`

5. **[迹与范数] 证明：对于任意矩阵 $\mathbf{A} \in \mathbb{R}^{m \times n}$，其 Frobenius 范数的平方等于其特征值/奇异值平方和，即 $\|\mathbf{A}\|_F^2 = \text{Tr}(\mathbf{A}^T \mathbf{A}) = \sum \sigma_i^2$。**
> [!question]- 答案解析
> **答案**：将 SVD $\mathbf{A}=\mathbf{U}\mathbf{\Sigma}\mathbf{V}^T$ 代入：$\text{Tr}(\mathbf{A}^T\mathbf{A}) = \text{Tr}(\mathbf{V}\mathbf{\Sigma}^T\mathbf{U}^T\mathbf{U}\mathbf{\Sigma}\mathbf{V}^T) = \text{Tr}(\mathbf{V}\mathbf{\Sigma}^2\mathbf{V}^T)$。根据迹的循环置换性质 $\text{Tr}(\mathbf{B}\mathbf{C}) = \text{Tr}(\mathbf{C}\mathbf{B})$，得到 $\text{Tr}(\mathbf{\Sigma}^2 \mathbf{V}^T \mathbf{V}) = \text{Tr}(\mathbf{\Sigma}^2) = \sum \sigma_i^2 = \|\mathbf{A}\|_F^2$。  
> **标签**：`#自测/较难 #矩阵迹证明`

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 线性代数基础 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 线性代数基础 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (线性代数基础) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```
