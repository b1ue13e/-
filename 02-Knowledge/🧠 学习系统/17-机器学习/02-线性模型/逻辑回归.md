# 逻辑回归

逻辑回归是二分类的判别式概率模型。它直接建模 $P(Y=1\mid x)$，虽然名称含“回归”，但主要用于分类。

## 1. 模型

令线性得分 $z=\beta_0+x^\top\beta$，通过 sigmoid 映射为概率：

$$
p(x)=P(Y=1\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}.
$$

取对数几率可得

$$
\log\frac{p(x)}{1-p(x)}=\beta_0+x^\top\beta.
$$

因此 $\beta_j$ 表示 $x_j$ 增加一单位时 log-odds 的变化；$e^{\beta_j}$ 是其他变量不变时 odds 的倍数变化。它不是概率直接增加 $\beta_j$。

## 2. 极大似然与交叉熵

对 $y_i\in\{0,1\}$，伯努利似然为

$$
\prod_i p_i^{y_i}(1-p_i)^{1-y_i}.
$$

最小化负对数似然得到二元交叉熵：

$$
\mathcal L(\beta)=-\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].
$$

该目标是凸的，但一般没有 OLS 那样的闭式解，通常用 Newton、L-BFGS、SAG/SAGA 等迭代方法。实际实现常加入 L2 或 L1 正则化。

## 3. 决策边界与阈值

若阈值为 0.5，则 $p(x)\ge0.5$ 等价于 $\beta_0+x^\top\beta\ge0$，所以输入空间中的决策边界是超平面。改变阈值不会重新训练概率模型，却会改变 Precision、Recall 和错误成本。

## 4. 最小验证

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

X = np.array([[-2.0], [-1.0], [1.0], [2.0]])
y = np.array([0, 0, 1, 1])
model = LogisticRegression(C=1000).fit(X, y)
prob = model.predict_proba([[-1.5], [1.5]])[:, 1]

assert prob[0] < 0.5 < prob[1]
assert model.predict([[-1.5], [1.5]]).tolist() == [0, 1]
```

验证不能止于训练集分类正确；还应在独立数据上检查 log loss、ROC/PR 曲线、阈值指标和概率校准。

## 5. 与相邻模型的区别

- [[02-Knowledge/🧠 学习系统/17-机器学习/02-线性模型/线性回归|线性回归]]预测连续值并最小化平方误差；逻辑回归预测概率并最小化对数损失。
- [[02-Knowledge/🧠 学习系统/17-机器学习/02-线性模型/线性判别分析|线性判别分析]]先对类条件分布 $P(x\mid y)$ 建模，再由贝叶斯公式分类；逻辑回归直接建模 $P(y\mid x)$。
- 多分类可用 multinomial/softmax 回归；详见[[02-Knowledge/🧠 学习系统/17-机器学习/02-线性模型/多分类学习|多分类学习]]。

## 6. 边界与误区

1. 原始特征下的 log-odds 需要近似线性；可通过变换、样条或交互项扩展。
2. 完全分离时无正则的极大似然系数可能发散。
3. 类别不平衡时不能只看 Accuracy，也不能默认阈值为 0.5。
4. 正则化和特征缩放会影响系数；解释系数前必须说明预处理与惩罚项。
5. 概率输出不必然校准，尤其在重采样或类权重改变训练分布之后。
