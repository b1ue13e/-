# 线性回归

线性回归用特征的线性组合预测连续目标。这里的“线性”是对参数线性；加入 $x^2$ 等固定基函数后，模型仍可对参数保持线性。

## 1. 模型与目标函数

对样本 $(x_i,y_i)$，模型为

$$
\hat y_i=\beta_0+x_i^\top\beta.
$$

普通最小二乘（OLS）选择参数使残差平方和最小：

$$
\min_{\beta_0,\beta}\sum_{i=1}^n(y_i-\beta_0-x_i^\top\beta)^2.
$$

把截距并入设计矩阵 $X$ 后，目标是 $\|y-X\beta\|_2^2$。一阶条件给出正规方程

$$
X^\top X\hat\beta=X^\top y.
$$

若 $X$ 满列秩，则 $\hat\beta=(X^\top X)^{-1}X^\top y$。数值实现通常使用 QR、SVD 或专用最小二乘求解器，而不是显式计算逆矩阵。

## 2. 几何解释

$X\hat\beta$ 是 $y$ 在 $X$ 列空间上的正交投影，因此残差 $e=y-X\hat\beta$ 满足

$$
X^\top e=0.
$$

这解释了正规方程，也说明无法由特征列空间表达的部分会留在残差中。详见[[02-Knowledge/🧠 学习系统/17-机器学习/02-线性模型/线性回归的几何解释|线性回归的几何解释]]。

## 3. 最小例子

取三点 $(0,1),(1,3),(2,5)$。它们恰好满足 $y=1+2x$，所以 OLS 得 $\hat\beta_0=1,\hat\beta_1=2$，残差平方和为 0。

```python
import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[0.0], [1.0], [2.0]])
y = np.array([1.0, 3.0, 5.0])
model = LinearRegression().fit(X, y)

assert np.isclose(model.intercept_, 1.0)
assert np.isclose(model.coef_[0], 2.0)
future_x = np.array([3.0]).reshape(1, -1)
assert np.allclose(model.predict(future_x), [7.0])
```

## 4. 统计解释需要额外假设

用于预测时，最小二乘只要求明确损失和验证协议；若要解释标准误、置信区间与显著性，还需讨论条件均值线性、误差独立或相关结构、同方差性等假设。异常值和高杠杆点可能显著改变系数。

系数 $\beta_j$ 表示“其他特征保持不变时，$x_j$ 增加一单位的条件均值变化”。它不是自动的因果效应；遗漏变量、反向因果和选择偏差都可能破坏因果解释。

## 5. 诊断与评估

1. 在训练集拟合，在独立验证/测试集报告 MAE、RMSE 和 $R^2$。
2. 画残差—拟合值图，检查非线性与异方差。
3. 检查影响点和特征共线性。
4. 与预测均值等简单基线比较。
5. 若过拟合或共线性严重，考虑 Ridge、[[02-Knowledge/🧠 学习系统/17-机器学习/03-正则优化/L1正则化Lasso|Lasso]]或降维。

## 6. 常见误区

- $R^2$ 高不代表测试误差低，更不代表因果关系成立。
- 训练误差只会随特征增加而不增，不能据此证明新特征有用。
- 对分类标签直接做线性回归会产生区间外预测；二分类通常使用[[02-Knowledge/🧠 学习系统/17-机器学习/02-线性模型/逻辑回归|逻辑回归]]。
- 外推依赖线性关系在观测区间之外仍成立，风险通常高于插值。
