## 0. 先判断它值不值得深挖


* **分类结果**：**A 类（核心概念，必须深挖）**
* **判断理由**：L1 正则化（Lasso）与 L2 正则化（Ridge / 权重衰减）是整个机器学习和深度学习中防止模型过拟合（Overfitting）、控制模型复杂度最核心的数学工具。它们深刻体现了**结构风险最小化（SRM）**、**几何凸约束交点**以及**贝叶斯最大后验估计 (MAP) 中的先验分布（Laplace 先验 vs Gaussian 先验）** 的本质区别。掌握 L1 产生稀疏解与 L2 产生平滑衰减的几何与统计推导，是深入理解高维建模与模型刷优的必修课。

---

## 1. 这个知识点解决什么问题？


**我们遇到了什么麻烦？**

假设你正在训练一个复杂模型（如包含 1,000 个特征的回归模型）。
* **以前的方法在哪里卡住？**
  * **过拟合与权重暴涨**：如果训练数据中存在噪声或特征数量极大，为了死记硬背每一个样本点，模型会倾向于将参数权重 $w$ 调整得**极其巨大**（如 $w_1 = 1,000,000, w_2 = -999,999$）。巨大的权重使得模型对输入的微小扰动极度敏感，导致在测试集上的泛化误差彻底崩溃（严重过拟合）。
  * **特征冗余无从选择**：在 1,000 个特征中，可能只有 10 个特征是真正有用的。人工手动挑选特征费时费力。

* **为什么必须引入这个新工具？**
  * 我们需要一种在损失函数中**显式惩罚权重过大**、强迫参数保持简单平滑或自动剔除无用特征的机制。这就是 **L1 与 L2 正则化**。

---

## 2. 为什么它重要？它有什么用？


* **大图景连接**：
  * **课程位置**：它是从经验风险最小化（ERM）跨越到结构风险最小化（SRM）的核心载体，连接了最优化理论与贝叶斯推断。
  * **后续知识**：不理解 L1 的非光滑棱角切点，就无法理解压缩感知（Compressed Sensing）与稀疏学习；不理解 L2 的权重衰减，就无法理解 AdamW 相较于 Adam 的核心改进。
* **实际应用**：
  * **高维自动特征选择 (Lasso)**：文本挖掘、基因序列分析中从数万特征中自动筛选出极少数关键特征（将无用特征权重直接压缩为严格的 0）。
  * **深度学习防止过拟合 (Weight Decay)**：ResNet、Transformer 等神经网络训练的标准权重衰减。
  * **弹性网 (ElasticNet)**：结合 L1 与 L2 解决高维强相关特征组的选择问题。

## 3. 学它之前需要哪些前置知识？


最小必要背景清单：

1. **范数 (Norm $\|w\|_1, \|w\|_2$)**：
   > 200 字补齐：向量 $w \in \mathbb{R}^d$ 的 $L_1$ 范数为各元素绝对值之和 $\|w\|_1 = \sum_{i=1}^d |w_i|$；$L_2$ 范数的平方为各元素平方和 $\|w\|_2^2 = \sum_{i=1}^d w_i^2$。

2. **拉格朗日乘子与受限优化**：
   > 200 字补齐：带约束的优化问题 $\min_{w} J_0(w) \text{ s.t. } \|w\| \le C$，在 KKT 条件下等价于无约束优化问题 $\min_{w} \left[ J_0(w) + \lambda \|w\| \right]$（其中超参数 $\lambda \ge 0$ 控制惩罚强度）。

---

## 4. 用直觉语言解释它


«“这东西其实就像给模型参数颁发**‘权重膨胀罚单’**。如果你把权重 $w$ 搞得很大，损失函数除了算预测误差，还要额外收一大笔‘身材肥胖税’（惩罚项）。L1 罚单非常狠，只要发现某特征用途不大，立刻判死刑降为 0（**极简断舍离 / 稀疏化**）；L2 罚单则比较平缓，希望所有参数大家都变小变均匀，谁也别当出头鸟（**集体瘦身 / 平滑化**）。”»

* **L1 正则化 (Lasso) 在干什么？** 在损失函数后加上 $\lambda \sum |w_i|$。几何约束域是“菱形/正八面体”（带有尖锐棱角），容易将参数压缩到坐标轴上（形成**稀疏解**）。
* **L2 正则化 (Ridge) 在干什么？** 在损失函数后加上 $\frac{\lambda}{2} \sum w_i^2$。几何约束域是“光滑超球体”，将参数均匀缩小但不为 0（形成**平滑小权重**）。
* **一句话直觉本质**：**L1 正则化通过绝对值棱角切点实现自动特征选择（稀疏解）；L2 正则化通过平方球域平滑缩减所有权重（平滑解与权重衰减）。**

## 5. 正式定义、核心公式、符号解释


### 1. 核心定义
* **经验损失函数 $J_0(w)$**：原始训练损失（如 MSE 或交叉熵）。
* **L1 正则化 (Lasso Regression)**：
  $$J_{\text{L1}}(w) = J_0(w) + \lambda \|w\|_1 = J_0(w) + \lambda \sum_{i=1}^d |w_i|$$
* **L2 正则化 (Ridge Regression / 岭回归)**：
  $$J_{\text{L2}}(w) = J_0(w) + \frac{\lambda}{2} \|w\|_2^2 = J_0(w) + \frac{\lambda}{2} \sum_{i=1}^d w_i^2$$

### 2. 核心公式与梯度更新比较

#### (1) 梯度更新对比 (Gradient Update)
对参数 $w_i$ 求偏导更新（设学习率为 $\eta$）：

* **L2 正则化 (Weight Decay 权重衰减)**：
  $$\frac{\partial J_{\text{L2}}}{\partial w_i} = \frac{\partial J_0}{\partial w_i} + \lambda w_i \implies w_i^{(t+1)} = (1 - \eta \lambda) w_i^{(t)} - \eta \frac{\partial J_0}{\partial w_i}$$
  *(每次更新前先把旧权重按因子 $(1 - \eta \lambda) < 1$ 比例衰减，故称权重衰减)*。

* **L1 正则化 (软阈值算子 Soft-Thresholding)**：
  $$\frac{\partial J_{\text{L1}}}{\partial w_i} = \frac{\partial J_0}{\partial w_i} + \lambda \cdot \text{sign}(w_i) \implies w_i^{(t+1)} = w_i^{(t)} - \eta \frac{\partial J_0}{\partial w_i} - \eta \lambda \cdot \text{sign}(w_i)$$
  *(每次以恒定步长 $\eta \lambda$ 将 $w_i$ 向 0 强行拉拢，一旦跨越 0 点即被直接截断裁剪为 0)*。

#### (2) 贝叶斯最大后验估计 (MAP) 视角恒等式
在 MAP 框架下 $\max_w P(w \mid D) \propto P(D \mid w) P(w)$：

* **L1 正则化 $\iff$ 假设参数服从拉普拉斯先验 (Laplacian Prior)**：
  $$P(w_i) = \frac{1}{2b} \exp\left( -\frac{|w_i|}{b} \right) \implies -\ln P(w) = \frac{1}{b} \sum |w_i| + \text{const}$$

* **L2 正则化 $\iff$ 假设参数服从零均值高斯先验 (Gaussian Prior)**：
  $$P(w_i) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{w_i^2}{2\sigma^2} \right) \implies -\ln P(w) = \frac{1}{2\sigma^2} \sum w_i^2 + \text{const}$$

### 3. 符号说明

| 符号 | 含义 | 取值范围/量纲 | 备注 |
|:---|:---|:---|:---|
| $\lambda$ | 正则化超参数（惩罚系数）| $[0, +\infty)$ | $\lambda$ 越大，模型越简单，越不易过拟合 |
| $J_0(w)$ | 原始经验损失 | $[0, +\infty)$ | 拟合训练数据的损失 |
| $\text{sign}(w_i)$ | 符号函数 | $\{-1, 0, 1\}$ | L1 梯度的方向向 0 靠拢 |
| $C$ | 等价受限优化问题的边界半径 | $(0, +\infty)$ | $\|w\|_1 \le C$ 或 $\|w\|_2^2 \le C$ |

## 6. 推导思路和思想来源


### 1. 为什么 L1 产生稀疏解而 L2 不会？（几何切点推导主线）
* **受限优化问题转换**：
  根据拉格朗日对偶性，最小化 $J_0(w) + \lambda R(w)$ 完全等价于：
  $$\min_w J_0(w) \quad \text{s.t.} \quad R(w) \le C$$
* **几何画图分析（二维平面 $(w_1, w_2)$）**：
  1. **原始损失 $J_0(w)$ 的等高线**：以不加正则的最优解 $\hat{w}^{\text{unconstrained}}$ 为中心的同心椭圆。越靠近中心，损失越小。
  2. **L2 正则约束域 $\|w\|_2^2 \le C$**：在二维平面上是一个**光滑的圆形**（$w_1^2 + w_2^2 \le C$）。
  3. **L1 正则约束域 $\|w\|_1 \le C$**：在二维平面上是一个**带有 4 个尖锐棱角（顶点）的菱形**（$|w_1| + |w_2| \le C$）。
* **切点概率分析**：
  损失函数 $J_0(w)$ 的椭圆等高线从中心向外膨胀，首次触碰到正则约束域边界的点就是最优解 $w^*$。
  * 对于 L2 的光滑圆形，椭圆等高线与圆相切的点**极大概率发生在圆周的非坐标轴上**，即 $w_1 \ne 0, w_2 \ne 0$。
  * 对于 L1 的菱形，由于菱形的 4 个顶点刚好位于坐标轴上（如 $(C, 0), (0, C)$），椭圆等高线在膨胀时**极大概率首先触碰到菱形的尖锐顶点**！一旦切点在坐标轴上，对应的某个参数就严格等于 0（即 $w_2 = 0$）！
  **结论**：L1 的几何“棱角顶点”决定了其解具有极高的稀疏性（Sparse Solution）。

## 7. 例子：基础 → 中等 → 实际应用


### 例子 1：基础例子（一维线性回归下 L1 与 L2 闭式解手算）

**题目**：
假设单参数一维经验损失为 $J_0(w) = \frac{1}{2} (w - w_0)^2$（其中不加正则的最优解 $w_0 = 3.0$）。
设置正则化系数 $\lambda = 1.0$。
1. 求 L2 正则化下的最优解 $w_{\text{L2}}^*$。
2. 求 L1 正则化下的最优解 $w_{\text{L1}}^*$。

**解题思路与步骤**：
1. **L2 正则化求解**：
   $$J_{\text{L2}}(w) = \frac{1}{2}(w - 3.0)^2 + \frac{1.0}{2} w^2$$
   求导令其为 0：
   $$\frac{d J_{\text{L2}}}{dw} = (w - 3.0) + 1.0 \cdot w = 2w - 3.0 = 0 \implies w_{\text{L2}}^* = \frac{3.0}{1 + 1.0} = 1.5$$
   *(L2 将原始解 3.0 等比例缩小到了 1.5)*。

2. **L1 正则化求解**：
   $$J_{\text{L1}}(w) = \frac{1}{2}(w - 3.0)^2 + 1.0 \cdot |w|$$
   由于 $w_0 > 0$，设 $w > 0$，求导令其为 0：
   $$\frac{d J_{\text{L1}}}{dw} = (w - 3.0) + 1.0 = w - 2.0 = 0 \implies w_{\text{L1}}^* = 3.0 - 1.0 = 2.0$$

**最终答案**：$w_{\text{L2}}^* = 1.5$；$w_{\text{L1}}^* = 2.0$。

**追问**：若原始未正则解 $w_0 = 0.5$（小参数），且 $\lambda = 1.0$，L1 与 L2 的解分别是多少？
*(答案：L2 解 $w_{\text{L2}}^* = \frac{0.5}{2} = 0.25$；L1 软阈值解直接截断裁剪为 $w_{\text{L1}}^* = \max(0, 0.5 - 1.0) = 0$！演示了 L1 的零截断特性)*。

---

### 例子 2：中等例子（Lasso 软阈值算子 Soft-Thresholding）

**题目**：
在一维正则化问题中，对于通用目标 $\min_w \frac{1}{2}(w - w_0)^2 + \lambda |w|$，推导其闭式解软阈值算子 $S_\lambda(w_0)$ 的分段表达式。

**完整解答过程**：
1. 当 $w_0 > \lambda$ 时，$w^* = w_0 - \lambda > 0$；
2. 当 $w_0 < -\lambda$ 时，$w^* = w_0 + \lambda < 0$；
3. 当 $|w_0| \le \lambda$ 时，软阈值直接将参数裁剪截断为 0：$w^* = 0$。
统一写作**软阈值算子 (Soft-Thresholding Operator)**：

$$S_\lambda(w_0) = \text{sign}(w_0) \cdot \max(0, |w_0| - \lambda)$$

---

### 例子 3：实际应用例子（大模型微调与特征筛选）

1. **高维稀疏特征选择 (Lasso)**：在基因组学（50,000 个基因特征）中预测患病概率。使用 Lasso（L1）模型训练后，49,900 个基因的权重被直接压为 0，只保留 100 个非零权重基因，医生可以直接拿着这 100 个基因做靶向药研发。
2. **深度学习 Weight Decay (L2)**：在 Transformer / ResNet 训练中，使用 $L_2$ 权重衰减（如 `weight_decay = 0.01`）。每次更新时强迫权重向量的模长维持在极小范围内，极大地增强了神经网络对图像噪声或文本噪音的抗干扰泛化能力。

## 8. 常见误区和易混概念


### 误区 1：L1 和 L2 正则化可以互相完全替代

* **错误直觉**：反正都是防止过拟合的，用 L1 和用 L2 效果完全一样。
* **为什么错**：后方的解结构完全不同！L1 的目标是**稀疏化（剔除特征）**，但遇到高度相关的特征组时，L1 会随机选一个而抛弃其余；L2 的目标是**平滑化（保留所有特征但减小幅度）**，能均匀地把权重分配给所有相关特征。
* **正确理解**：如果需要做**特征选择**或希望得到可解释的稀疏模型，选 **L1 (Lasso)**；如果特征全都有用、只希望**防止过拟合**，选 **L2 (Ridge)**；若兼而有之，选两者结合的 **ElasticNet**。

### 误区 2：在 Adam 优化器中，设置 `weight_decay` 就完全等价于直接在 Loss 后加上 $L_2$ 正则项

* **错误直觉**：`Loss + L2` 和 Adam 的 `weight_decay` 是完全一回事。
* **为什么错**（Loshchilov & Hutter, 2017 - AdamW 论文）：
  若直接在 Loss 里加 $\frac{\lambda}{2} w^2$，梯度变为 $g_t = \nabla J_0 + \lambda w$。二阶矩 $v_t$ 会将含有 $\lambda w$ 的梯度进行按元素缩放：$\frac{g_t}{\sqrt{v_t}}$。这导致**大权重的衰减步长被分母二阶矩强行缩小**，破坏了真正的权重衰减！
* **正确理解**：在 Adam 中，必须使用 **AdamW（解耦权重衰减）**，将 $w \leftarrow (1-\eta \lambda) w$ 独立放在梯度更新步骤之外执行。

### 概念对比表格

| 维度 | L1 正则化 (Lasso) | L2 正则化 (Ridge) | ElasticNet (弹性网) |
|:---|:---|:---|:---|
| **惩罚项** | $\lambda \sum |w_i|$ | $\frac{\lambda}{2} \sum w_i^2$ | $r \lambda \|w\|_1 + \frac{1-r}{2} \lambda \|w\|_2^2$ |
| **解的特性** | **稀疏解 (Sparse)**（许多权重严格为 0）| **平滑解 (Smooth)**（权重微小但不为 0）| **组稀疏 (Group Sparse)** |
| **几何约束域** | 带有尖锐棱角的菱形/正八面体 | 光滑的超球体 | 介于菱形与超球体之间 |
| **贝叶斯先验** | **拉普拉斯先验 (Laplace Prior)** | **零均值高斯先验 (Gaussian Prior)** | 混合先验 |
| **求解方法** | 坐标下降法 (Coordinate Descent) / 软阈值 | 最小二乘法闭式解 $(X^T X + \lambda I)^{-1} X^T Y$ | 软阈值迭代 |

### 题目 1 (概念辨析)
**题目**：在训练包含 1,000 个特征的模型时，如果你希望模型在训练完成后能够自动输出“哪些特征是无用的，可以直接在预测阶段剔除”，你应该选择 L1 正则化还是 L2 正则化？为什么？

> [!question]- 答案解析
> **答案**：
> 应该选择 **L1 正则化 (Lasso)**。
> 因为 L1 正则化的几何约束域具有尖锐的棱角顶点，会强行将无用特征的权重 $w_i$ 彻底裁剪压缩为**严格的零 ($w_i = 0$)**（产生稀疏解）。在预测阶段，权重为 0 的特征可以被直接剔除。而 L2 正则化只会将权重压缩到很小的非零实数（如 $0.0001$），无法自动剔除特征。
> **Obsidian 标签建议**：`#自测题/概念辨析` `#稀疏特征选择`

### 题目 2 (公式运用)
**题目**：已知某参数未加正则时的最优解为 $w_0 = -2.5$。若设置 L1 软阈值惩罚系数 $\lambda = 1.0$，请计算 L1 正则化后的最优解 $w_{\text{L1}}^*$。

> [!question]- 答案解析
> **答案**：
> 使用软阈值算子公式 $S_\lambda(w_0) = \text{sign}(w_0) \cdot \max(0, |w_0| - \lambda)$：
> 1. $\text{sign}(-2.5) = -1$；
> 2. $|-2.5| - 1.0 = 2.5 - 1.0 = 1.5 > 0$；
> 3. $w_{\text{L1}}^* = -1 \times 1.5 = -1.5$。
> **最可能做错的原因**：计算符号时弄反，将 $-2.5$ 误算为 $-3.5$。

### 题目 3 (条件判断)
**题目**：在数据集存在两个高度强相关的线性特征 $X_1 \approx X_2$ 时，L1 正则化 (Lasso) 与 L2 正则化 (Ridge) 分别会如何分配这两个特征的权重 $w_1, w_2$？

> [!question]- 答案解析
> **答案**：
> 1. **L1 正则化 (Lasso)**：会在两个强相关特征中**随机挑选其中一个**赋予全部权重（如 $w_1 = C, w_2 = 0$），而将另一个直接裁剪为 0。其选择具有极大的随机不稳定性。
> 2. **L2 正则化 (Ridge)**：倾向于**平分权重**（如 $w_1 \approx C/2, w_2 \approx C/2$），使两个参数均等缩小，保持模型的平滑性。

### 题目 4 (变式/综合)
**题目**：在未加正则的普通最小二乘法 (OLS) 中，当样本量 $N < d$（特征数大于样本数）时，矩阵 $X^T X$ 是不可逆的奇异矩阵（无法求逆）。试证明：加入 L2 正则化后的岭回归解 $(X^T X + \lambda I)^{-1} X^T Y$ 在 $\lambda > 0$ 时必定永远可逆！

> [!question]- 答案解析
> **证明**：
> 1. 数据矩阵 $X \in \mathbb{R}^{N \times d}$，其转置乘积 $X^T X \in \mathbb{R}^{d \times d}$ 是对称半正定矩阵。
> 2. 对称半正定矩阵 $X^T X$ 的所有特征值满足 $\mu_i \ge 0$ ($i=1, \dots, d$)。
> 3. 加入 $\lambda I$ 矩阵后，$A = X^T X + \lambda I$ 的特征值变为 $\lambda_i(A) = \mu_i + \lambda$。
> 4. 因为 $\mu_i \ge 0$ 且 $\lambda > 0$，所以对所有特征值均满足 $\lambda_i(A) \ge \lambda > 0$。
> 5. 矩阵 $A$ 的所有特征值均严格大于 0，故 $A$ 是**严格的正定矩阵**。
> 6. 正定矩阵的行列式 $\det(A) = \prod \lambda_i(A) > 0 \ne 0$。
> 证毕。矩阵 $X^T X + \lambda I$ 永远满秩且可逆！这从线性代数角度解释了岭回归为何能解决多重共线性奇异矩阵问题。
> **Obsidian 标签建议**：`#自测题/线性代数` `#岭回归满秩证明`

### 题目 5 (开放/证明/建模)
**题目**：从贝叶斯最大后验估计 (MAP) 视角，详细推导在参数服从零均值独立高斯先验 $w_i \sim \mathcal{N}(0, \sigma^2)$ 时，极大化后验概率等价于带有 L2 正则化的最小二乘损失。

> [!question]- 答案解析
> **证明**：
> 1. 根据贝叶斯定理，后验概率为：
>    $$P(w \mid D) = \frac{P(D \mid w) P(w)}{P(D)} \propto P(D \mid w) P(w)$$
> 2. 取负对数极大化后验 (MAP)：
>    $$\arg\max_w P(w \mid D) = \arg\min_w \left[ -\ln P(D \mid w) - \ln P(w) \right]$$
> 3. 第一项为似然：假设观察噪声为高斯分布 $\mathcal{N}(0, \sigma_n^2)$，其负对数似然为：
>    $$-\ln P(D \mid w) = \frac{1}{2\sigma_n^2} \sum_{i=1}^N (y_i - w^T x_i)^2 + \text{const}$$
> 4. 第二项为先验：假设参数 $w_i \sim \mathcal{N}(0, \sigma_p^2)$ 独立服从零均值高斯先验，其负对数先验为：
>    $$-\ln P(w) = -\ln \prod_{j=1}^d \frac{1}{\sqrt{2\pi}\sigma_p} \exp\left( -\frac{w_j^2}{2\sigma_p^2} \right) = \frac{1}{2\sigma_p^2} \sum_{j=1}^d w_j^2 + \text{const}$$
> 5. 代回 MAP 目标并同乘以 $2\sigma_n^2$：
>    $$\min_w \left[ \sum_{i=1}^N (y_i - w^T x_i)^2 + \frac{\sigma_n^2}{\sigma_p^2} \sum_{j=1}^d w_j^2 \right]$$
> 6. 令惩罚系数 $\lambda = \frac{2\sigma_n^2}{\sigma_p^2}$，上式精准写为：
>    $$\min_w \left[ J_0(w) + \frac{\lambda}{2} \sum_{j=1}^d w_j^2 \right]$$
> 证毕。L2 正则化等价于对参数赋予零均值高斯分布的贝叶斯先验！
> **Obsidian 标签建议**：`#自测题/贝叶斯MAP` `#高斯先验证明`
