# 数据集划分与交叉验证

数据集划分的目标不是形式上切成几份，而是模拟模型面对未来未见样本的过程。训练集拟合参数，验证过程选择模型和超参数，测试集只在流程冻结后提供一次最终评估。

## 1. 三种角色

- **训练集**：估计权重、均值、标准差、词表及其他可学习参数。
- **验证集/交叉验证折**：选择特征、模型、超参数和阈值。
- **测试集**：在全部选择完成后估计最终泛化性能。

如果根据测试结果返回调参，测试集已经参与模型选择，不再是独立测试集。

## 2. K 折交叉验证

把训练数据分成 $K$ 个互斥子集。每轮用 $K-1$ 折训练、剩余一折验证，得到分数 $s_1,\ldots,s_K$：

$$
\bar s=\frac1K\sum_{k=1}^Ks_k.
$$

应同时报告折间波动，而不是只给均值。交叉验证估计的是特定数据生成机制、划分器和训练管线下的性能；各折共享大量训练数据，因此不能把折分数简单当成完全独立样本。

## 3. 划分器必须匹配数据结构

- 分类且类别不均衡：使用分层划分保持各折类别比例。
- 同一患者、用户或设备有多条记录：按组划分，禁止同组跨训练与验证。
- 时间序列：按时间向前验证，不能随机打乱未来到训练集。
- 空间或站点数据：考虑按区域留出，避免邻近样本造成乐观估计。
- 小样本调参与性能估计同时进行：考虑嵌套交叉验证，外层评估、内层调参。

## 4. 预处理必须放入每个训练折

标准化、缺失值填补、特征选择、降维、目标编码和过采样都可能学习数据统计量，必须只在当前训练折拟合，再应用到验证折。使用 Pipeline 可降低泄露风险。

```python
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_validate
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True)
pipe = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000))
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=8)
scores = cross_validate(pipe, X, y, cv=cv, scoring=["roc_auc", "accuracy"])

assert len(scores["test_roc_auc"]) == 5
assert len(scores["test_accuracy"]) == 5
```

## 5. 可复现评估协议

1. 在查看测试标签表现前写清样本单位、切分键和时间边界。
2. 保存随机种子和各样本所属 split，而不仅保存比例。
3. 所有候选模型使用相同外层划分，确保公平比较。
4. 使用[[模型评估指标]]中预先指定的主指标。
5. 流程冻结后在测试集评估一次，并报告不确定性及子群结果。

## 6. 常见误区

- 先对全数据标准化再交叉验证。
- 同一主体的重复记录被随机分到不同集合。
- 时间序列随机 K 折导致未来信息泄露。
- 反复查看测试成绩并挑最好的一次。
- 把交叉验证均值微小差异当成确定优势；应结合[[过拟合与欠拟合]]和统计不确定性判断。
