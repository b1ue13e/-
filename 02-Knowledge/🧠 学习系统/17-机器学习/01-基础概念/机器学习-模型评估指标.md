# 模型评估指标

评估指标把模型输出映射为可比较的数值，但**不存在脱离任务代价的万能指标**。正确流程是先明确预测对象、错误成本和数据分布，再选择指标；测试集只用于最终一次无偏评估，不能反复用于调参。

**模型评估指标的定义**：在固定数据划分、预测输出形式和聚合规则后，量化预测质量或业务损失的函数。模型评估指标只回答被明确定义的问题；分类阈值、类别权重、时间窗口或样本聚合方式一旦改变，指标含义也会改变。

## 1. 分类指标从混淆矩阵开始

二分类中令 TP、FP、TN、FN 分别表示真正、假正、真负、假负：

$$
\text{Accuracy}=\frac{TP+TN}{TP+FP+TN+FN},
$$

$$
\text{Precision}=\frac{TP}{TP+FP},\qquad
\text{Recall}=\frac{TP}{TP+FN},
$$

$$
F_1=\frac{2PR}{P+R}.
$$

- **Accuracy**：类别相对均衡、两类错误成本近似时易解释；极端不平衡时可能误导。
- **Precision**：预测为正的样本有多少是真的；误报代价高时重点关注。
- **Recall**：真实正类有多少被找出；漏报代价高时重点关注。
- **F1**：Precision 与 Recall 的调和平均，但忽略 TN，也不表达概率质量。

ROC-AUC 衡量随机正样本得分高于随机负样本的排序能力；PR-AUC 更聚焦正类检索，在正类稀少时通常更有解释力。二者都是跨阈值指标，不能替代上线阈值下的 Precision、Recall 和业务成本。

## 2. 概率预测需要概率指标

如果模型输出概率，应评估概率而不只评估硬分类：

$$
\text{LogLoss}=-\frac1n\sum_i\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right],
$$

$$
\text{Brier}=\frac1n\sum_i(p_i-y_i)^2.
$$

Log loss 会强烈惩罚自信但错误的预测。Brier score 同时受区分能力和校准影响。还应配合可靠性图检查“预测概率为 0.8 的样本是否约有 80% 为正类”。

## 3. 回归指标

令误差 $e_i=y_i-\hat y_i$：

$$
\text{MAE}=\frac1n\sum_i|e_i|,
\qquad
\text{RMSE}=\sqrt{\frac1n\sum_i e_i^2}.
$$

MAE 与目标同量纲，对极端误差相对稳健；RMSE 对大误差更敏感。$R^2=1-\frac{\sum e_i^2}{\sum(y_i-\bar y)^2}$ 表示相对均值基线的平方误差改善，测试集上可以为负。MAPE 在真实值为零或接近零时不稳定，不能默认使用。

## 4. 最小验证：同一准确率，不同风险

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

y_true = [1, 1, 1, 1, 0, 0, 0, 0]
y_pred = [1, 0, 0, 0, 0, 0, 0, 1]

assert accuracy_score(y_true, y_pred) == 0.5
assert precision_score(y_true, y_pred) == 0.5
assert recall_score(y_true, y_pred) == 0.25
assert round(f1_score(y_true, y_pred), 3) == 0.333
```

准确率 0.5 并未说明正类只召回四分之一。若正类代表严重疾病或欺诈，该模型可能不可接受。

## 5. 评估协议

1. 先确定样本单位、预测时点和业务损失。
2. 使用[[机器学习-数据集划分与交叉验证|数据集划分与交叉验证]]隔离训练、验证和测试信息。
3. 预先指定一个主指标和若干护栏指标，避免看到结果后挑指标。
4. 报告点估计之外的折间波动或置信区间。
5. 与简单基线比较，并在重要子群上检查性能。
6. 多模型比较应结合[[机器学习-比较检验|比较检验]]，不能只比较第三位小数。

## 6. 常见误区

- 在训练数据上报告最终性能。
- 用测试集反复挑模型，导致测试集变成验证集。
- 类别不平衡时只报告 Accuracy。
- 将 AUC 高解释为概率已校准或实际收益一定高。
- 交叉验证前对全数据做标准化、特征选择或缺失值填补，造成数据泄露。
- 把单一模型评估指标当作模型整体质量；上线决策还需要延迟、稳定性、公平性和成本约束。
