# 过拟合与欠拟合



训练误差衡量模型对已见样本的拟合；泛化误差是模型在同一目标分布的新样本上的期望损失。我们只能用独立验证/测试样本估计后者。若训练损失很低而验证损失明显更高，称为过拟合；若训练和验证损失都高，称为欠拟合。



| 状态 | 训练误差 | 验证误差 | 首要诊断 |

|---|---:|---:|---|

| 欠拟合 | 高 | 高且接近 | 表达能力、特征、优化是否不足 |

| 过拟合 | 低 | 明显更高 | 容量、数据量、泄漏、调参次数 |

| 可接受拟合 | 低 | 低且差距受控 | 是否跨切分、跨时间仍稳定 |



“误差低/高”必须相对可用基线、任务噪声与业务代价判断，不能只看训练集曲线。



## 1. 学习曲线比单点分数更有信息



绘制训练轮数或样本量横轴下的训练/验证损失：



- 两条曲线都高且继续加数据改善很少：先提高模型能力、改特征或修复优化。

- 训练低、验证高且差距大：增加有效数据、加强正则化、降低容量或早停。

- 验证突然异常地好：优先排查重复样本、未来信息、目标泄漏和预处理泄漏。



随着样本量增加，过拟合模型的验证误差常下降、泛化间隙缩小；因此“加数据”主要缓解方差问题，不一定能修复错误假设造成的高偏差。



## 2. 标准诊断流程



1. 先固定任务指标与无信息/简单模型基线。

2. 按数据生成过程划分：时间序列按时间，用户级数据按用户，重复实体不得跨折。

3. 所有预处理、特征选择、PCA 与缺失值填补都只在训练折拟合。

4. 在验证集选择容量和正则强度；锁定方案后，测试集只使用一次。

5. 报告均值、波动和不同切分表现，不用单次幸运划分下结论。



```python

from sklearn.model_selection import learning_curve



sizes, train_s, valid_s = learning_curve(

    estimator, X, y, cv=5, scoring="neg_log_loss",

    train_sizes=[.1, .25, .5, .75, 1.0]

)

```



## 3. 常用修复手段



欠拟合可尝试更合适的特征、非线性结构、训练更充分或减弱正则；过拟合可使用[[机器学习-L1正则化Lasso]]、数据增强、早停、dropout、剪枝、减少参数或更严格的验证。方法必须针对根因：如果问题是分布漂移或标签错，简单加正则并不能解决。



## 4. 易混淆边界



- **过拟合不等于训练误差为零**，关键是泛化间隙及样本外损失。

- **测试集反复查看会变成验证集**；即使参数未显式更新，人也会根据结果选择方案。

- **高方差与过拟合相关但不完全等价**；应通过重采样稳定性检查，而非只套偏差—方差口号。

- 深度网络常可拟合随机标签，参数个数等传统容量指标不能单独解释其泛化；数据、优化与归纳偏置都重要。
