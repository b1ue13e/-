# 🎯 监督学习

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：监督学习（Supervised Learning）是当前工业界落地最成熟、应用最广泛的机器学习范式（占商业落地 80% 以上）。掌握监督学习的形式化定义、两大核心任务（分类与回归）以及训练推理流程，是深入所有经典算法的前置关键。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 假设你需要根据房子的面积、房间数预测售价（连续值），或者根据病人的检查指标判断患病与否（离散标签）。你手头积累了大量历史成交记录或临床诊断病例（包含特征 $X$ 与正确答案 $Y$），如何利用这些带标准答案的数据让计算机学会预测未来？

以往的方法卡在：
- 无标签数据无法进行有针对性的误差修正与监督校正。

监督学习**通过在带标签数据上建立“输入到输出”的映射关系**，解决了有明确预测目标任务的自动化决策难题。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：
  - **后续影响**：绝大部分经典算法（线性回归、Logistic 回归、SVM、决策树、随机森林、GBDT、ResNet 等）均属于监督学习范畴。
  - **课程位置**：属于“机器学习四大范式”中最核心的第一大范式。
- **实战与科研价值**：
  - **分类任务**：垃圾邮件识别、图像分类、风控违约预测、医学诊断。
  - **回归任务**：房价预测、股票价格预测、销量预测、气温预测。
  - **最常出现题型**：分类与回归辨析题、监督学习流程图填空题、损失函数选择题。

## 4. 用直觉语言解释它

> «“这东西其实就像学生做有标准答案的练习题……”»

- **训练阶段**：老师发给你 100 道练习题，每道题后面都附带了标准答案。你先自己做，做完对照标准答案算分数（计算 Loss），如果做错了就总结原因并纠正思考方式（更新参数 $\mathbf{w}$）。
- **测试阶段**：期末考试发下一张只有新题目没有答案的试卷，你根据之前训练好的思维模式独立作答（预测 $\hat{y}$）。

**直觉本质一句话**：**基于“输入-标准答案”对进行有监督纠错的学习。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
给定训练数据集 $D = \{(\mathbf{x}_1, y_1), (\mathbf{x}_2, y_2), \dots, (\mathbf{x}_N, y_N)\}$，其中 $\mathbf{x}_i \in \mathcal{X}$ 为特征向量，$y_i \in \mathcal{Y}$ 为已知标签。监督学习的目标是学习一个映射函数 $f: \mathcal{X} \to \mathcal{Y}$ 或条件概率分布 $P(Y \mid X)$，使得对于未知的输入 $\mathbf{x}_{\text{new}}$，能够准确预测出 $y_{\text{new}} \approx f(\mathbf{x}_{\text{new}})$。

### 2. 两大核心任务分类
- **回归 (Regression)**：目标空间 $\mathcal{Y} = \mathbb{R}$ 为连续实数空间（如预测温度、房价）。
- **分类 (Classification)**：目标空间 $\mathcal{Y} = \{c_1, c_2, \dots, c_K\}$ 为离散类别集合（如判断阴性/阳性、识别 0-9 手写数字）。

---

## 6. 推导思路和思想来源

### 学习流程通用框架：
1. **选择模型结构**：确定假设空间 $\mathcal{H} = \{f(\mathbf{x}; \mathbf{w})\}$。
2. **定义损失函数**：
   - 回归常用**均方误差 (MSE)**：$L(y, \hat{y}) = (y - \hat{y})^2$。
   - 分类常用**交叉熵损失 (Cross-Entropy Loss)**：$L(y, \hat{y}) = -y \log \hat{y} - (1-y) \log(1-\hat{y})$。
3. **求解优化**：利用梯度下降等算法求 $\arg\min_{\mathbf{w}} \sum_{i=1}^N L(y_i, f(\mathbf{x}_i; \mathbf{w}))$。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（分类与回归区分）
**题目**：判断以下预测任务属于分类还是回归：
1. 根据二手车年限和里程预测转卖价格（实数）。 -> **回归**
2. 根据医疗 CT 图像判断肿瘤是良性还是恶性（二选一）。 -> **分类**
3. 预测明日的降雨量（毫米）。 -> **回归**

---

### 例子 2：实际应用例子（电商点击率预测 CTR）
**场景**：在淘宝/京东推荐系统中，用户刷新页面时模型需要在 5ms 内预测用户是否会点击某个商品（$y \in \{0, 1\}$）。
- **特征 $X$**：用户历史偏好、商品属性、当前时间与上下文。
- **算法模型**：使用 Logistic Regression 或 Deep & Cross Network (DCN) 进行监督学习训练。

---

## 8. 常见误区和易混概念

### 误区 1：监督学习不需要数据预处理
- **错误直觉**：“既然有标准答案，模型自己就能学好。”
- **为什么错**：标签噪声（错标/漏标）会严重干扰监督学习效果；必须清洗数据与离群点。

### 1. 4 级 Baseline 设级与冲榜拆解 (4-Tier Baseline System)

| :--- | :--- | :--- |
| 🟢 **Simple Baseline** | 跑通代码无报错 | 搭建基础 PyTorch 模型框架，完成前向传播与 Loss 计算 |
| 🔵 **Medium Baseline** | 评估 Metric 提升 $20\%$ | **特征与损失优化**：引入数据标准化 (StandardScaler)、标签平滑或权值衰减 |

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 监督学习 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 监督学习 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (监督学习) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```

### 3. 作业思考题与避坑指南 (Q&A & Gotchas)

1. ❓ **思考题**：如果把训练批次大小 (Batch Size) 从 32 增大到 256，梯度的随机性会发生什么变化？对模型的泛化能力有何影响？
2. ⚠️ **避坑指南 1 (梯度累积)**：每次调用 `optimizer.step()` 前务必调用 `optimizer.zero_grad()`，避免梯度无限累加。
3. ⚠️ **避坑指南 2 (模式切换)**：由于模型中包含 `nn.BatchNorm1d` 与 `nn.Dropout`，测试评估前必须显式调用 `model.eval()`。
