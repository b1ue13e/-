# 对抗攻击与防御（HW10）

---

- **判断理由**：HW10 整份作业就是"攻击一个已训练模型再防御它"，FGSM/PGD、白盒/黑盒、对抗训练是作业的四个支柱；它把 HW09 的"梯度"工具反向使用，是理解模型脆弱性的关键环节（与 [[生成对抗网络GAN]] 的"对抗"思想汇合）。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 深度模型测试集准确率很高，但**加一点点肉眼不可见的噪声，预测就完全翻转**（熊猫 → 长臂猿，置信度 99%）。模型决策边界对"非自然扰动"极其脆弱——路牌加个贴纸就识别错、人脸识别被对抗眼镜欺骗。因此必须研究两件事：**如何系统构造微小扰动（攻击）**与**如何让模型免疫（防御）**——这就是对抗攻击与防御（Adversarial Attack & Defense）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW10 官方任务（攻击官方模型 + 提交防御模型）全部基于白盒/黑盒攻击；与 HW09 共享梯度工具、与 HW06 GAN 共享"对抗博弈"思想；是"模型鲁棒性"主题的入口（HW11 的分布偏移是自然的、这里是恶意的）。
- **实际应用场景**：人脸/语音助手的对抗欺骗、内容审核绕过、自动驾驶感知攻击、模型红队测试、联邦学习投毒防御。
- **高频题型/任务**：手写 FGSM 公式并解释符号；对比 FGSM 与 PGD；区分白盒/黑盒/有目标/无目标；对抗训练为什么有效；用 $\epsilon$ 与攻击成功率评估鲁棒性。

## 4. 用直觉语言解释它

> «"对抗攻击"就像给试卷改答案：考官（模型）把答案写在答题卡（输入像素）上，攻击者拿到答题卡，用橡皮擦（梯度）精准擦掉几个关键笔划——人眼看还是同一张卡，机器判卷却从"对"变"错"。而"对抗训练"就是让考官提前见惯各种"被擦改的卷子"。»

- **直觉类比/几何图像**：决策边界把输入空间分成两类区域；对抗样本就是"跨过边界一点点"的输入——距原样本欧氏距离极小，却落在边界另一侧。攻击 = 沿梯度方向（垂直边界的捷径）推输入；防御 = 把边界"撑胖"。高维空间中决策边界极度弯曲，存在大量"人眼无感、模型敏感"的方向，梯度恰好指出这些方向。
- **一句话直觉本质**：**攻击 = 沿输入梯度方向加约束内的小扰动，让模型跨过决策边界；防御 = 用对抗样本训练/平滑边界，让"跨边界"需要更大扰动。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
给定模型 $f$、输入 $x$、标签 $y$，**对抗样本** $\tilde{x}=x+\delta$ 满足：$\|\delta\|_p\le\epsilon$（人眼不可见）且 $f(\tilde{x})\ne y$（无目标）或 $f(\tilde{x})=y_{target}$（有目标）。按信息分**白盒**（知道模型与梯度）与**黑盒**（只知道输入输出）。

### 2. 核心公式
FGSM（单步）：
$$\tilde{x}=x+\epsilon\cdot\text{sign}\big(\nabla_x \mathcal{L}(f(x),y)\big)$$
PGD（迭代 + 投影）：
$$x^{t+1}=\Pi_{B_\epsilon(x)}\Big(x^t+\alpha\cdot\text{sign}\big(\nabla_x \mathcal{L}(f(x^t),y)\big)\Big)$$
对抗训练（防御）目标：
$$\min_\theta\ \mathbb{E}_{(x,y)\sim\mathcal{D}}\Big[\max_{\|\delta\|_p\le\epsilon}\mathcal{L}\big(f_\theta(x+\delta),y\big)\Big]$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\delta$ | 对抗扰动 | $\|\delta\|_p\le\epsilon$ | 常取 $p=\infty$（逐像素限幅） |
| $\epsilon$ | 扰动预算 | 如图像 8/255 | 越大越强也越明显 |
| $\alpha$ | 迭代步长 | 如 2/255 | PGD 每步大小 |
| $\Pi_{B_\epsilon(x)}$ | 投影回 $\epsilon$-球 | — | 保证扰动不超预算 |
| $\mathcal{L}$ | 损失（交叉熵） | $\mathbb{R}_{\ge0}$ | 攻击最大化它 |

### 4. 常见变体与适用条件
- **变体**：有目标攻击、C&W（直接优化 $\|\delta\|$）、DeepFool、边界攻击；黑盒常用**迁移攻击**（替代模型生成）与**查询攻击**（有限差分）。
- **限制条件**：攻击强度与不可见性矛盾；对抗训练牺牲少量干净精度；PGD 训练计算量大。

## 6. 推导思路和思想来源

- **最初困难**：Szegedy et al. (2014) 发现极小扰动能让模型完全改判，且**跨模型迁移**——不是过拟合噪声，而是结构性脆弱。随机扰动基本无效——必须"沿着模型最敏感的方向"走。
- **关键"转念"**：**把攻击当成"输入空间的梯度上升"**：损失对输入求梯度，沿梯度方向推输入使损失增大；FGSM 用 sign 只取方向（$\ell_\infty$ 约束下逐坐标最优），一步即可；PGD 重复 $T$ 步并每步投影回 $\epsilon$-球，逼近"最坏扰动"。
- **推导主线与动机**：① 一阶线性化 $\mathcal{L}(x+\delta)\approx\mathcal{L}(x)+\nabla_x\mathcal{L}\cdot\delta$，在 $\|\delta\|_\infty\le\epsilon$ 下最优扰动是 $\epsilon\,\text{sign}(\nabla_x\mathcal{L})$；② 线性化不准 → 多步投影（PGD）；③ 防御侧把"最坏扰动"当训练数据——min-max 稳健优化（内层攻击、外层训练）。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：线性分类器 $f(x)=\text{sign}(2x_1-3x_2)$，输入 $x=(1,1)$（真实类别 $-1$）。用 FGSM（$\epsilon=0.5$）求让模型"更确信"的扰动方向。
- **解题思路与关键步骤**：损失取 $-(2x_1-3x_2)y$；$\nabla_x\mathcal{L}\propto(-2,3)$；$\text{sign}=(-1,1)$；$\tilde{x}=(1,1)+0.5(-1,1)=(0.5,1.5)$。分数从 $-1$ 变 $2(0.5)-3(1.5)=-3.5$，向负类更确信。
- **最终答案**：$\tilde{x}=(0.5,1.5)$，方向是"减小 $x_1$、增大 $x_2$"。若目标是翻转类别，沿相反方向（$+1,-1$）推即可。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：黑盒场景下无法访问目标模型梯度，如何攻击？给出两条路线并比较。
- **解题思路与完整解答**：① **迁移攻击**：训练替代模型，在其上跑 PGD 生成对抗样本直接喂目标模型——利用对抗样本的跨模型迁移性；② **查询攻击**：反复查询输出，用有限差分估计梯度，或用边界攻击沿决策边界游走缩小扰动。**比较**：迁移攻击快但成功率依赖替代模型相似度；查询攻击不依赖替代模型但查询次数多、易被检测。**关键推理**：黑盒攻击的本质是把"梯度不可得"转化为"近似梯度可得"（代理模型或数值差分）。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW10 官方任务两阶段：白盒攻击官方模型（目标：多数样本错分），再训练防御模型（目标：攻击成功率显著下降）。代码骨架：
```python
def fgsm_attack(model, x, y, eps):
    x = x.clone().requires_grad_(True)
    loss = F.cross_entropy(model(x), y)
    model.zero_grad(); loss.backward()
    return (x + eps * x.grad.sign()).clamp(0, 1).detach()

def pgd_attack(model, x, y, eps, alpha, iters):
    x_adv = x.clone().detach()
    for _ in range(iters):
        x_adv.requires_grad_(True)
        loss = F.cross_entropy(model(x_adv), y); model.zero_grad(); loss.backward()
        x_adv = (x_adv + alpha * x_adv.grad.sign()).detach()
        x_adv = torch.min(torch.max(x_adv, x - eps), x + eps).clamp(0, 1)  # 投影回 eps-球
    return x_adv
```

## 8. 常见误区和易混概念

### 误区 1：对抗样本 = 噪声样本，去噪就能防住
- **错误直觉**：对抗扰动是随机噪声，加模糊/降噪即可消除。
- **为什么错**：对抗扰动是**定向**、结构化的（沿梯度方向），与随机噪声统计特性完全不同；去噪可能反而破坏分类信息，且白盒攻击者可绕过预处理。
- **正确理解**：必须"以攻为守"：对抗训练或输入梯度正则化，而非单纯去噪。

### 误区 2：白盒攻击比黑盒攻击"更强"，所以黑盒不用防
- **错误直觉**：攻击者拿不到模型权重，成功率一定很低。
- **为什么错**：迁移攻击让黑盒成功率常接近白盒；查询攻击理论上可在多项式次查询内逼近最优；工业模型常被复刻，白盒边界模糊。
- **正确理解**：黑盒是更现实的威胁模型，评估需同时测白盒（上界）与黑盒（实际风险）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 对抗攻击 | 构造最小扰动改变预测 | 白盒用梯度、黑盒用迁移/查询 | 鲁棒性评测（HW10） |
| 对抗训练 | 让模型对扰动免疫 | min-max 训练、牺牲少量干净精度 | 基础防御 |
| [[可解释性XAI（HW09）]] | 解释模型依据 | 同用梯度但目标是"理解" | 模型审计 |

### 题目与解析

#### 1. 白盒攻击与黑盒攻击的本质区别？黑盒有哪些实现路线？
> [!question]- 答案解析
> - **答案**：白盒知道模型与梯度，直接梯度上升；黑盒只知道输入输出，用迁移攻击（替代模型）或查询攻击（有限差分/边界法）。
> - **解析**：评估时白盒给"最坏上界"，黑盒给"实际风险"；黑盒成功率常接近白盒。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 对 $f(x)=\text{sign}(2x_1-3x_2)$、$x=(1,1)$，用 FGSM（$\epsilon=0.5$）求扰动方向与对抗样本。
> [!question]- 答案解析
> - **答案**：$\nabla_x\mathcal{L}\propto(-2,3)$，$\text{sign}=(-1,1)$，$\tilde{x}=(1,1)+0.5(-1,1)=(0.5,1.5)$。
> - **解析**：核心是理解 sign 取方向、$\epsilon$ 定幅度；翻转方向则取相反符号。

#### 3. 什么时候用 PGD 而不是 FGSM？
> [!question]- 答案解析
> - **答案**：评估最坏情况、对抗训练内层用 PGD；快速粗测用 FGSM。FGSM 是线性近似一步到位，常低估最坏扰动；PGD 迭代逼近真实最坏情况。
> - **解析**：PGD 是"更强的 FGSM"（$T=1$ 的特例）；FGSM 攻不破 ≠ 模型鲁棒。

#### 4. 对抗训练提升鲁棒性的原理与代价？
> [!question]- 答案解析
> - **答案**：把内层 max 生成的对抗样本纳入外层 min 训练，模型被迫在"扰动球内处处正确"，边界被"撑开"；代价：干净精度下降（robustness-accuracy tradeoff）、训练开销大、防御质量依赖攻击强度。
> - **解析**：min-max 稳健优化视角；HW10 官方防御提交标准做法即 PGD 对抗训练 + 数据增强。

#### 5. 论证：$\ell_\infty$ 约束下最大化一阶近似损失的最优扰动是 $\delta=\epsilon\,\text{sign}(\nabla_x\mathcal{L})$。
> [!question]- 答案解析
> - **答案**：一阶展开 $\mathcal{L}(x+\delta)\approx\mathcal{L}(x)+\nabla_x\mathcal{L}\cdot\delta$；在 $\ell_\infty$ 球内最大化内积，逐坐标：梯度为正取 $+\epsilon$、为负取 $-\epsilon$，即符号方向。
> - **解析**：这是 $\ell_\infty$ 球与 $\ell_1$ 范数的对偶关系；$\ell_2$ 约束的最优方向则是归一化梯度。
> - **易错原因**：把 $\ell_2$ 的最优方向套到 $\ell_\infty$ 上。
