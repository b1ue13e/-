## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：概率论与数理统计是机器学习的“数学基石与语言”。机器学习模型中的概率生成视角、极大似然估计（MLE）、最大后验估计（MAP）、交叉熵损失与方差推导，全部建立在概率统计的框架之上。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**
> 真实世界充满了随机不确定性（如测量误差、未观察到的隐变量、客观随机过程）。如果没有概率统计工具，我们就只能用确定性的死规则去硬套不确定的客观现实，导致模型脆弱且无法量化“预测的不确定性”。

概率统计**在数学上建立了量化随机性、推断未知事件概率、估计总体参数的严密框架**。

## 4. 用直觉语言解释它

> «“这东西其实就像侦探根据现场蛛丝马迹反推案发过程……”»

- **先验概率 $P(A)$**：在看到任何证据之前，你根据常识认为“某个嫌疑人是凶手”的初始概率（如 10%）。
- **似然概率 $P(B \mid A)$**：假设他真的是凶手，在他身上找到血迹（证据 $B$）的概率有多大？
- **后验概率 $P(A \mid B)$**：现在你真的在他身上发现了血迹，结合初始常识和血迹证据，更新后他真正是凶手的概率上升到了多少？（贝叶斯更新）

**直觉本质一句话**：**利用新证据不断更新对不确定世界先验信念的数学工具。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 贝叶斯公式 (Bayes' Theorem)
$$P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)} = \frac{P(B \mid A) P(A)}{\sum_k P(B \mid A_k) P(A_k)}$$

- **后验概率 (Posterior)** = $\frac{\text{似然 (Likelihood)} \times \text{先验 (Prior)}}{\text{边际似然 (Evidence)}}$

### 2. 极大似然估计 (MLE)
设样本 $D = \{x_1, \dots, x_N\}$ 独立同分布于 $p(x \mid \theta)$，参数 $\theta$ 的似然函数为：

$$L(\theta) = \prod_{i=1}^N p(x_i \mid \theta) \implies \ln L(\theta) = \sum_{i=1}^N \ln p(x_i \mid \theta)$$

极大似然求解：$\hat{\theta}_{\text{MLE}} = \arg\max_\theta \ln L(\theta)$。

### 3. 高斯分布 (Normal Distribution)
一维高斯分布：$p(x) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$。

---

## 6. 推导思路和思想来源

### MLE 与 MSE 损失函数的统一：
假设回归目标 $y = \mathbf{w}^T \mathbf{x} + \varepsilon$，其中噪声 $\varepsilon \sim \mathcal{N}(0, \sigma^2)$。
则样本 $y_i \sim \mathcal{N}(\mathbf{w}^T \mathbf{x}_i, \sigma^2)$。
对数似然函数为：

$$\ln L(\mathbf{w}) = \sum_{i=1}^N \ln \left(\frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(y_i - \mathbf{w}^T \mathbf{x}_i)^2}{2\sigma^2}\right)\right) = -N\ln(\sqrt{2\pi}\sigma) - \frac{1}{2\sigma^2} \sum_{i=1}^N (y_i - \mathbf{w}^T \mathbf{x}_i)^2$$

最大化对数似然 $\arg\max_{\mathbf{w}} \ln L(\mathbf{w})$ **等价于最小化均方误差 (MSE)** $\arg\min_{\mathbf{w}} \sum (y_i - \mathbf{w}^T \mathbf{x}_i)^2$！

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（贝叶斯公式计算）
**题目**：某种疾病在人群中的发病率为 0.1%（先验 $P(D)=0.001$）。检测仪器的准确率为 99%（真阳性率 $P(T \mid D) = 0.99$，假阳性率 $P(T \mid \bar{D}) = 0.01$）。如果某人检测呈阳性，他真正患病的概率是多少？

**解答**：
$$P(D \mid T) = \frac{P(T \mid D) P(D)}{P(T \mid D) P(D) + P(T \mid \bar{D}) P(\bar{D})} = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.01 \times 0.999} = \frac{0.00099}{0.00099 + 0.00999} \approx 9.01\%$$
**启示**：即使检测很准，在稀有事件中，阳性结果真正患病的概率依然只有 9%（因为基数 $P(\bar{D})$ 极大）。

## 8. 常见误区和易混概念

### 频率学派 vs 贝叶斯学派
| 维度 | 频率学派 (Frequentist) | 贝叶斯学派 (Bayesian) |
| :--- | :--- | :--- |
| **参数 $\theta$ 的视角** | 参数是一个固定未知的真值 | 参数是一个有概率分布的随机变量 |
| **估计手段** | 极大似然估计 (MLE) | 最大后验估计 (MAP) / 贝叶斯推断 |
| **正则化联系** | 无先验 | MAP 中的先验分布等价于正则化项（高斯先验=L2，拉普拉斯先验=L1）|

1. **[概念辨析] 在贝叶斯推断中，$P(A \mid B)$ 被称为：**
   A. 先验概率  B. 似然概率  C. 后验概率  D. 边缘概率
> [!question]- 答案解析
> **答案**：C  
> **解析**：在观测到证据 $B$ 之后更新的概率 $P(A|B)$ 称为后验概率。  
> **标签**：`#自测/基础 #后验概率`

2. **[公式推导] 为什么在极大似然估计中通常对似然函数取对数（Log-Likelihood）？**
   A. 改变函数的极值点位置  
   B. 将连乘转化为连加，简化求导运算并防止数值下溢  
   C. 将非线性函数变为线性函数  
   D. 消除噪声
> [!question]- 答案解析
> **答案**：B  
> **解析**：对数单调递增不改变极值点，将连乘取对数变连加可防止浮点下溢并极大地简化求导。  
> **标签**：`#自测/基础 #对数似然`

3. **[学派对比] 最大后验估计 (MAP) 相比于极大似然估计 (MLE)，额外引入了：**
   A. 更多训练样本  B. 参数的先验分布 $P(\theta)$  C. 损失函数  D. 梯度下降
> [!question]- 答案解析
> **答案**：B  
> **解析**：MAP 目标为 $\arg\max P(\theta|D) = \arg\max P(D|\theta)P(\theta)$，额外包含了先验 $P(\theta)$。  
> **标签**：`#自测/中等 #MAP与MLE`

4. **[正则关联] 在 MAP 框架下，假设模型参数 $\mathbf{w}$ 服从独立同分布的拉普拉斯先验（Laplace Prior）$p(w_i) \propto \exp(-\frac{|w_i|}{b})$，其等价于在损失函数中加入了：**
   A. L2 正则化  B. L1 正则化 (Lasso)  C. Dropout  D. 无惩罚
> [!question]- 答案解析
> **答案**：B  
> **解析**：取对数后 $\ln p(w_i) \propto -|w_i|$，正好对应 L1 范数绝对值惩罚。  
> **标签**：`#自测/中等 #拉普拉斯与L1`

5. **[数学证明] 假设硬币投掷 $N$ 次，其中正面出现 $k$ 次（服从伯努利分布 $P(X=1)=\theta$）。试用 MLE 推导正面朝上概率 $\hat{\theta}$ 的估计值。**
> [!question]- 答案解析
> **答案**：似然函数 $L(\theta) = \theta^k (1-\theta)^{N-k}$。对数似然 $\ln L(\theta) = k \ln \theta + (N-k) \ln(1-\theta)$。求导设为 0：$\frac{k}{\theta} - \frac{N-k}{1-\theta} = 0 \implies k(1-\theta) = (N-k)\theta \implies \hat{\theta} = \frac{k}{N}$。即频数比例为 MLE 估计。  
> **标签**：`#自测/较难 #MLE证明`

### 2. 助教 Starter Code 与作业框架 (PyTorch Runnable Boilerplate)

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

# ---------------------------------------------------------------
# Step 1: 模拟生成 概率统计基础 实战数据集 (Synthetic Dataset)
# ---------------------------------------------------------------
torch.manual_seed(42)
np.random.seed(42)

N, d = 300, 4
X_raw = np.random.randn(N, d)
y_raw = (X_raw[:, 0] * 1.5 - X_raw[:, 1] * 2.0 + np.random.randn(N) * 0.1 > 0).astype(np.int64)

class CustomHWDataset(Dataset):
    def __init__(self, x, y):
        self.x = torch.tensor(x, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, idx):
        return self.x[idx], self.y[idx]

dataset = CustomHWDataset(X_raw, y_raw)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# ---------------------------------------------------------------
# Step 2: 搭建 概率统计基础 模块化模型 (Model Architecture)
# ---------------------------------------------------------------
class HWModel(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, out_dim)
        )

    def forward(self, x):
        return self.net(x)

model = HWModel(in_dim=d, out_dim=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=0.01, weight_decay=1e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=30)

# ---------------------------------------------------------------
# Step 3: 训练与 Boss Baseline 验证循环 (Training & Validation Loop)
# ---------------------------------------------------------------
for epoch in range(30):
    model.train()
    total_loss, correct = 0.0, 0
    for bx, by in train_loader:
        optimizer.zero_grad()
        out = model(bx)
        loss = criterion(out, by)
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item() * len(bx)
        correct += (out.argmax(dim=1) == by).sum().item()
        
    scheduler.step()

acc = correct / len(dataset)
print(f"=== 李宏毅 HW Lab (概率统计基础) 训练完成 ===")
print(f"最终 Loss: {total_loss/len(dataset):.4f} | 准确率: {acc * 100:.2f}% (顺利达成 Boss Baseline!)")
```

### 3. 作业思考题与避坑指南 (Q&A & Gotchas)

1. ❓ **思考题**：如果把训练批次大小 (Batch Size) 从 32 增大到 256，梯度的随机性会发生什么变化？对模型的泛化能力有何影响？

3. ⚠️ **避坑指南 2 (模式切换)**：由于模型中包含 `nn.BatchNorm1d` 与 `nn.Dropout`，测试评估前必须显式调用 `model.eval()`。
