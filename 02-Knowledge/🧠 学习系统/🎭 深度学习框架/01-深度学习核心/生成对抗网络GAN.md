# 生成对抗网络GAN

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：GAN 是 HW06 的唯一核心，也是"生成模型"这一大类的代表；它的 min-max 博弈视角与训练不稳定问题贯穿 HW06 全部实验（mode collapse、判别器过强）。同时为理解对抗样本（HW10）提供"对抗"思想的前置。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 之前学的模型都是"判别式"的：给一个输入，输出标签或数值。但我们想要**生成**——给定随机噪声，产出逼真的新样本（人脸、动漫头像）。直接学数据分布 $P_{data}(x)$ 很难：真实分布高维、复杂、没有解析形式；用最大似然拟合（如高斯混合）表达力不够。
> 因此必须引入一种新思路：**不显式写出分布，而是让两个网络互相博弈，在对抗中逼出真实分布**——这就是生成对抗网络（GAN, Goodfellow et al. 2014）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW06 官方任务（人脸生成）直接基于 GAN；GAN 的"训练不稳定"分析是 HW06 报告的重头戏；它与 [[自编码器Autoencoder]]（HW08）构成"生成模型两条路线"（隐变量重建 vs 对抗博弈）。
- **实际应用场景**：图像生成与超分辨率、风格迁移（CycleGAN）、语音转换、数据增强、异常检测（用判别器当打分器）。
- **高频题型/任务**：写出 min-max 目标函数并解释 $\log D(x)$ 与 $\log(1-D(G(z)))$ 的语义；解释 mode collapse；说明为什么判别器太强生成器学不动；DCGAN/WGAN 的关键改进点。

---

## 3. 学它之前需要哪些前置知识？

1. **[[🎯 多层神经网络 (MLP)]]**：生成器与判别器都是 MLP/CNN 的堆叠，前向与反向传播是基础。
2. **[[🎯 深度学习优化器 (Adam, RMSprop, Momentum)]]**：GAN 训练对优化器敏感（Adam 标配），判别器更新步数/学习率是稳定训练的核心旋钮。
3. **[[ 无监督学习]]**：生成建模属于无监督学习（只用 $x$，不用标签）；与聚类/降维共享"从数据本身找结构"的视角。
4. **[[交叉熵损失函数]]**：判别器的二分类目标就是交叉熵。

---

## 4. 用直觉语言解释它

> «"生成器"是个造假钞的团伙，"判别器"是验钞机。团伙每次造一批假钞，验钞机尽力分辨真假；验钞机越练越厉害，团伙就不得不把假钞造得越来越逼真——直到验钞机完全分不出来（输出恒为 1/2）。此时团伙造的就是"以假乱真"的钞（真实分布）。»

- **直觉类比/几何图像**：一个"猫和老鼠"的军备竞赛：$G$ 想把噪声 $z$ 映射到数据流形上，$D$ 想画出"真假边界"；$G$ 的梯度来自 $D$ 的判断误差，所以 $D$ 越强，$G$ 得到的"改进信号"越准确。
- **为什么很自然**：最大似然估计"从分布到样本"难，但"判别真假"是分类问题——分类器是最成熟的技术。把"生成"翻译成"骗过一个分类器"，就把难题化成了两个易题（分类 + 优化）。
- **一句话直觉本质**：**生成器最小化、判别器最大化同一个目标：$G$ 让 $D$ 分不清真假，$D$ 努力分清——纳什均衡处 $P_G = P_{data}$。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **生成器 $G$**：把噪声 $z \sim p_z(z)$（如标准正态）映射到数据空间：$G(z;\theta_G)$。
- **判别器 $D$**：输出输入 $x$ 来自真实数据的概率：$D(x;\theta_D)\in[0,1]$。
- **目标（min-max 博弈）**：
$$\min_G \max_D V(D,G) = \mathbb{E}_{x\sim P_{data}}[\log D(x)] + \mathbb{E}_{z\sim p_z}[\log(1 - D(G(z)))]$$

### 2. 核心公式
固定 $G$ 时最优判别器：$D^*(x) = \dfrac{P_{data}(x)}{P_{data}(x) + P_G(x)}$；代入后目标等价于最小化 JS 散度：
$$V(D^*,G) = -\log 4 + 2\cdot\text{JSD}(P_{data}\,\Vert\,P_G)$$
训练中交替更新：$\theta_D \leftarrow \theta_D + \nabla_{\theta_D} V(D,G)$（上升），$\theta_G \leftarrow \theta_G - \nabla_{\theta_G} V(D,G)$（下降）；实践中生成器常用"非饱和"损失 $-\mathbb{E}_z[\log D(G(z))]$ 缓解早期梯度消失。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $z$ | 噪声向量（隐变量） | $\mathbb{R}^{d_z}$，$z\sim\mathcal{N}(0,I)$ | 生成器的唯一输入 |
| $x$ | 真实样本 / 生成样本 | $\mathbb{R}^{d}$ | 图像展平或张量 |
| $G(z)$ | 生成样本 | 与 $x$ 同空间 | 造假钞 |
| $D(\cdot)$ | 判别概率 | $[0,1]$ | 越大越像真 |
| $P_{data}, P_G$ | 真实 / 生成分布 | 概率测度 | 目标：$P_G \to P_{data}$ |

### 4. 常见变体与适用条件
- **变体**：DCGAN（全卷积 + BatchNorm 稳定结构）、WGAN（用 Wasserstein 距离 + 权重裁剪/梯度惩罚，解决 JS 散度不连续问题）、条件 GAN cGAN（$G$ 和 $D$ 都输入类别 $y$）、CycleGAN（无配对风格迁移）。
- **适用条件**：需要从隐变量生成新样本；数据分布复杂无解析式；对"多样性"有要求。
- **限制条件**：训练不稳定（纳什均衡难到达）；mode collapse（只生成少数模式）；评价困难（loss 不能直接反映质量，需 FID/IS 等指标）。

---

## 6. 推导思路和思想来源

- **最初困难**：显式密度模型（如 MLE + 高斯）表达力不足，隐式密度模型（如 VAE 的 ELBO）有近似误差，且都难以生成高分辨率图像。
- **直接方法局限**：用自编码器（AE）生成时，从隐空间采样并不保证落在"像数据"的区域（AE 只为重建优化，不为采样优化）。
- **关键"转念"**：**不写密度，只写"真假判别"**——把生成质量交给一个可学习的判别器打分，而不是用固定的损失（如 MSE）。"对抗"让误差信号自适应地聚焦在 $G$ 最弱的地方。
- **推导主线与动机**：① 写出二分类交叉熵目标 $V(D,G)$；② 对 $D$ 求最大值得到最优判别器 $D^*(x)=\frac{P_{data}}{P_{data}+P_G}$（对每个 $x$ 求导=0）；③ 代入后目标化为 JS 散度，最小值当且仅当 $P_G=P_{data}$，此时 $D\equiv 1/2$；④ 交替梯度下降-上升逼近该均衡。
- **为什么自然得到此结论**：分类器的 Bayes 最优解就是密度比 $\frac{P_{data}}{P_{data}+P_G}$，而"判别真假"恰好能隐式估计密度比——生成问题被"翻译"成密度比估计问题，这是统计里最成熟的操作。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：设真实分布 $P_{data}$ 只在 $x=0$ 有质量（$P_{data}(0)=1$），生成分布 $P_G$ 只在 $x=1$ 有质量（$P_G(1)=1$）。求最优判别器在这两个点的取值，以及此时的 $V(D^*,G)$。
- **解题思路与关键步骤**：由 $D^*(x)=\frac{P_{data}(x)}{P_{data}(x)+P_G(x)}$：$D^*(0)=\frac{1}{1+0}=1$，$D^*(1)=\frac{0}{0+1}=0$。$V(D^*,G)=\mathbb{E}_{x\sim P_{data}}[\log D^*(x)]+\mathbb{E}_{z}[\log(1-D^*(G(z)))]=\log 1+\log(1-0)=0$。
- **最终答案**：$D^*(0)=1,\ D^*(1)=0,\ V(D^*,G)=0$。此时 $G$ 与 $P_{data}$ 完全不重合，但判别器完全分得开——这正是"JS 散度不连续"问题的雏形：$P_{data}$ 与 $P_G$ 支撑集不重叠时，JS 散度恒为 $\log 2$，梯度为 0，$G$ 学不动（WGAN 的动机）。
- **易错点**：把 $D^*(x)$ 记成"密度本身"；它是**密度比**，不是概率质量。
- **🤔 追问**：如果改用 Wasserstein 距离，这个例子会怎样？——$W(P_{data},P_G)=|0-1|=1$，梯度非零，这正是 WGAN 比原始 GAN 稳的数学原因。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：训练中观察到生成样本只有 2-3 张"同一张脸"的变体（mode collapse）。请给出判断依据与两个可操作的修复方向。
- **解题思路与完整解答**：判断依据：① 固定随机种子采样，样本多样性明显不足；② $D$ 的 loss 稳定但 $G$ 的 loss 持续下降（$G$ 找到"骗过 $D$ 的捷径"）；③ 生成样本间相似度（如 L2 距离）异常小。修复方向：① 用 WGAN-GP（梯度惩罚）替换原始目标，缓解"判别器过强导致梯度消失"；② 训练技巧：判别器更新步数减少、label smoothing、mini-batch discrimination；③ 特征匹配：让 $G$ 匹配 $D$ 中间层特征的均值。**关键推理**：collapse 的本质是 $G$ 找到了一个"局部最优的骗术"——多样性没有对应的梯度信号，必须靠目标函数或正则化主动奖励多样性。
- **易错点**：只看 loss 曲线判断好坏（loss 下降不代表质量上升）；把 collapse 当代码 bug 反复调学习率而不改目标。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW06 官方任务是用 DCGAN 生成动漫人脸：固定噪声种子每 epoch 存样本网格图，用 FID 与肉眼双重判断；E1 跑通最小 DCGAN → E2 加 label smoothing/谱归一化 → E3 换 WGAN-GP/EMA 对比稳定性 → E4 定稿。这正是工业界"生成质量评估靠样本 + FID、训练稳定靠技巧组合"的缩影。
- 代码形态（PyTorch 训练循环骨架）：
```python
for epoch in range(epochs):
    for real, _ in dataloader:
        # 判别器：真样本 log D(x) 升，假样本 log(1-D(G(z))) 升
        d_loss = -(torch.log(d(real) + 1e-8) + torch.log(1 - d(g(z)) + 1e-8)).mean()
        d_opt.zero_grad(); d_loss.backward(); d_opt.step()
        # 生成器（非饱和损失）：最大化 log D(G(z))
        g_loss = -torch.log(d(g(z)) + 1e-8).mean()
        g_opt.zero_grad(); g_loss.backward(); g_opt.step()
```

## 8. 常见误区和易混概念

### 误区 1：用 loss 大小判断 GAN 训练好坏
- **错误直觉**：$G$ 的 loss 越小说明生成越好，loss 曲线下降就是成功。
- **为什么错**：GAN 是博弈，双方 loss 此消彼长；$G$ loss 很小可能只是找到了骗过当前 $D$ 的捷径（collapse），而 $D$ 也在变强，数值不可跨实验比较。
- **正确理解**：以**固定噪声种子的样本网格 + FID/IS 指标**为准；loss 只用来诊断失衡（如 $D$ loss 恒为 0 说明 $D$ 过强）。

### 误区 2：判别器越强越好
- **错误直觉**：把 $D$ 训练到完美分类，$G$ 自然会被逼着进步。
- **为什么错**：$D$ 过强时 $\log(1-D(G(z)))$ 的梯度在 $D(G(z))\approx0$ 处几乎为 0（饱和），$G$ 学不到任何信号；且 $P_{data}$ 与 $P_G$ 支撑集不重叠时梯度恒为 0。
- **正确理解**：$D$ 要比 $G$ "略强一点点"（如每轮 $D$ 更新 1-2 步），保持"可学习的梯度信号"；这也是 WGAN 用 Wasserstein 距离的动机。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| GAN | 隐式分布 + 对抗 | 无显式密度、min-max 博弈、训练不稳 | 图像生成、风格迁移 |
| [[自编码器Autoencoder]] | 重建 + 隐变量 | 显式 MSE 损失、隐空间可解释 | 降维、异常检测（HW08） |
| VAE | 隐变量 + 变分推断 | 显式 ELBO、样本偏模糊 | 生成 + 表示学习 |
| 判别模型 | $P(y\mid x)$ | 不做生成 | 分类、回归 |

### 题目与解析

#### 1. 解释 GAN 目标 $\min_G\max_D V(D,G)$ 中每一项的含义。
> [!question]- 答案解析
> - **答案**：$\mathbb{E}_{x\sim P_{data}}[\log D(x)]$ 鼓励 $D$ 给真样本高分；$\mathbb{E}_{z}[\log(1-D(G(z)))]$ 鼓励 $D$ 给假样本低分（max 方向），同时鼓励 $G$ 让假样本被认成真（min 方向）。$G$ 最小化、$D$ 最大化同一目标。
> - **解析**：max 是对 $D$ 求，min 是对 $G$ 求——同一个 $V$ 的两面；博弈均衡处 $P_G=P_{data}$、$D\equiv 1/2$。
> - **易错原因**：以为 $G$ 和 $D$ 各自有独立损失；它们共享一个目标函数。
> - **对应误区**：误区 1（loss 语义）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 推导固定 $G$ 时最优判别器 $D^*(x)$。
> [!question]- 答案解析
> - **答案**：对每个 $x$ 求导置零：$\frac{\partial}{\partial D(x)}\big[P_{data}(x)\log D(x)+P_G(x)\log(1-D(x))\big]=0$，解得 $D^*(x)=\frac{P_{data}(x)}{P_{data}(x)+P_G(x)}$。
> - **解析**：$D^*$ 是"密度比"的单调函数；当 $P_G=P_{data}$ 时 $D^*=1/2$（完全分不清）。
> - **易错原因**：忘记把期望展开成对 $x$ 的积分/求和再逐点求导。

#### 3. 训练中生成样本多样性骤降（mode collapse），如何判断并修复？
> [!question]- 答案解析
> - **答案**：判断：固定种子采样看网格图、$D$ loss 稳定而 $G$ loss 持续降、样本间距离异常小。修复：WGAN-GP / 梯度惩罚、label smoothing、降低 $D$ 更新频率、mini-batch discrimination、特征匹配。
> - **解析**：collapse 是 $G$ 找到"骗过 $D$ 的捷径"，多样性没有梯度信号；必须从目标函数或正则化层面奖励多样性。
> - **易错原因**：当成代码 bug 反复调学习率；只看 loss 不看样本。
> - **对应误区**：误区 1。

#### 4. DCGAN 相比原始全连接 GAN 做了哪些关键改进？
> [!question]- 答案解析
> - **答案**：① 判别器用带步长卷积替代池化；② 生成器用转置卷积上采样；③ 除输出层外全部用 BatchNorm；④ 生成器输出层用 Tanh、判别器用 LeakyReLU；⑤ Adam 优化器（lr=2e-4）。
> - **解析**：这些改动共同解决"训练不稳定"：BatchNorm 稳定分布、LeakyReLU 避免判别器梯度消失、卷积保留空间结构。
> - **易错原因**：只记住"卷积"而忽略 BatchNorm 与激活选择。

#### 5. 论证：为什么 $P_{data}$ 与 $P_G$ 支撑集不重叠时原始 GAN 的生成器梯度为 0？
> [!question]- 答案解析
> - **答案**：支撑集不重叠时 $D^*(x)$ 在真实点恒为 1、生成点恒为 0，代入 $\log(1-D^*(G(z)))=\log 1=0$，梯度为 0；且此时 JSD 恒为 $\log 2$（不随 $G$ 参数变化），无法提供下降方向。WGAN 用 Wasserstein 距离（处处有梯度）替代 JSD 解决此问题。
> - **解析**：这是原始 GAN 训练不稳定的核心数学原因，也是 WGAN 论文的出发点；HW06 报告中可引用此论证解释为什么 WGAN-GP 更稳。
> - **易错原因**：只背"不稳定"结论，讲不出支撑集论证。
