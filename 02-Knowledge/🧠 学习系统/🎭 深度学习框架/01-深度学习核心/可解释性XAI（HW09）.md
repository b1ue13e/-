# 可解释性XAI（HW09）

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW09 整份作业就是"解释一个已训练模型"，不掌握归因方法（Saliency/Grad-CAM）与"解释不可靠"的边界，报告只能停留在"画了几张热力图"。它还是 HW10 的认知前置：解释与攻击共享"梯度"工具。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 深度模型准确率很高，但**它为什么做出这个判断？** 医生不敢信说不出理由的模型；工程师无法定位"模型在靠背景作弊"；监管要求解释权。看权重、看中间特征都回答不了"对这张具体图片，模型看的是哪里"。因此必须引入**事后解释（post-hoc explanation）**：对已训练模型，回答"哪些输入特征/区域驱动了预测"——这就是可解释 AI（XAI）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW09 官方任务（解释分类模型）直接要求 Saliency/Grad-CAM；它与 HW10 共享"梯度敏感性"视角；是模型审计（找偏见/伪特征）与模型调试（发现学歪）的标准工具箱。
- **实际应用场景**：医疗影像辅助诊断（指出病灶）、自动驾驶（模型在看路面还是路牌）、风控拒贷解释、大模型幻觉归因、监管合规。
- **高频题型/任务**：写 Saliency map 公式；说明 Grad-CAM 为什么用梯度 × 激活；对比 LIME 与 SHAP；指出"注意力即解释"的局限；设计实验评估解释方法。

---

## 3. 学它之前需要哪些前置知识？

1. **[[反向传播算法BP]]**：Saliency 是"输入对输出的梯度"，Grad-CAM 是"特征图对类别的梯度"。
2. **[[🎯 多层神经网络 (MLP)]]**（含卷积版）：特征图是 Grad-CAM 的操作对象。
3. **[[ 模型评估指标]]**：评估"解释"也需要指标（faithfulness、删除/保留实验），不能只看图好不好看。

---

## 4. 用直觉语言解释它

> «"可解释性"就像给模型做"体检 X 光"：Saliency 是"哪里动一下，结论就变"——问"你这一票最怕哪个证据被改"；Grad-CAM 是"你最后一眼重点扫了哪些区域"——荧光笔标出模型最后凝视的位置；LIME/SHAP 是"换个角度问"：把输入打碎成小块，逐块问"少了这块你还这么判吗"。»

- **直觉类比/几何图像**：梯度 = 损失面在输入点的"切面斜率"，斜率大的像素即"敏感像素"；Grad-CAM 把最后卷积层特征图按类别梯度加权求和；LIME 在输入邻域拟合线性代理模型，权重即局部重要性。模型连续可微，"小扰动 → 输出变化率"是最便宜的敏感性度量，"局部线性化"（LIME/SHAP）则把黑盒变成局部白盒。
- **一句话直觉本质**：**解释 = 回答"模型做决定时依据了什么"；梯度类给"敏感性"，代理模型给"局部线性权重"，都是对黑盒的近似，不是内部真相。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
给定模型 $f$、输入 $x$ 与预测类别 $c$，**特征归因（attribution）**给每个输入维度一个"贡献分数"，解释 $f_c(x)$ 为何高。三类方法：**梯度类**（Saliency、Grad-CAM、Integrated Gradients）、**代理模型类**（LIME、SHAP）、**扰动类**（遮挡、RISE）。

### 2. 核心公式
Saliency map（输入梯度）：
$$S(x)=\left|\frac{\partial f_c(x)}{\partial x}\right|$$
Grad-CAM（最后一层卷积特征图 $A^k$ 加权求和）：
$$\alpha_k^c=\frac{1}{Z}\sum_i\sum_j\frac{\partial f_c}{\partial A^k_{ij}},\qquad L^c_{\text{Grad-CAM}}=\text{ReLU}\!\left(\sum_k \alpha_k^c A^k\right)$$
LIME（局部代理模型）：$\xi(x)=\arg\min_{g\in G}\ \mathcal{L}(f,g,\pi_x)+\Omega(g)$。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $f_c(x)$ | 模型对类别 $c$ 的分数 | $\mathbb{R}$ | 常取 logit |
| $S(x)$ | 敏感度（归因）图 | 与 $x$ 同形状 | 逐像素绝对值 |
| $A^k$ | 第 $k$ 张卷积特征图 | $\mathbb{R}^{H\times W}$ | 最后一层 conv |
| $\alpha_k^c$ | 类别 $c$ 对特征图 $k$ 的权重 | $\mathbb{R}$ | 梯度全局平均池化 |
| $\pi_x, g, \Omega$ | 邻域权重 / 代理模型 / 复杂度惩罚 | — | LIME 组件 |

### 4. 常见变体与适用条件
- **变体**：Integrated Gradients（沿路径积分，满足公理）、SHAP（Shapley 值）、RISE（随机遮挡）、LRP（逐层相关度反传）。
- **限制条件**：梯度类对噪声/饱和敏感（梯度消失时 Saliency 全黑）；SHAP 计算贵；所有方法都是**近似**，不是因果解释。

---

## 6. 推导思路和思想来源

- **最初困难**：模型内部是数百万参数，权重不可读；中间特征是高维向量，人眼无法解读。可视化权重只反映"神经元喜欢什么模式"，回答不了"这张图为什么被判为猫"。
- **关键"转念"**：**不读内部，改问"敏感性"**——反向传播算"输出对输入"的梯度，一阶泰勒展开 $f_c(x+\delta)\approx f_c(x)+\nabla_x f_c\cdot\delta$ 直接给出每像素边际贡献；Grad-CAM 把梯度"翻译"回空间位置，得到人眼可读热力图。
- **推导主线与动机**：① 一阶敏感性（Saliency）太局部、易受噪声干扰；② 沿路径积分（IG）消除饱和与基准依赖；③ 局部代理模型（LIME）把"局部梯度"换成"局部线性权重"，更稳；④ SHAP 从博弈论给出唯一满足公理的分配。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：线性模型 $f(x)=3x_1-2x_2+1$，输入 $x=(2,1)$。求 Saliency 归因，并讨论它与权重的关系。
- **解题思路与关键步骤**：$\frac{\partial f}{\partial x_1}=3,\ \frac{\partial f}{\partial x_2}=-2$；Saliency 为 $(3,2)$。对线性模型梯度恒等于权重、与输入无关——Saliency 是"权重的推广"：非线性模型的梯度随输入变化，捕捉**局部**重要性。
- **最终答案**：归因 $(3,2)$。但若 $x=(0,100)$，梯度仍是 $(3,2)$，实际贡献 $3\cdot0=0$ 与 $-2\cdot100=-200$ 差异巨大——梯度 ≠ 贡献，真正的一阶贡献是 $\nabla f\odot x$。
- **🤔 追问**：若输出饱和（sigmoid 两端），Saliency 会怎样？——梯度趋近 0，归因图全黑，模型"最确信"却无法解释。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：猫狗分类器在"草地背景+猫"上 98%，在"室内背景+猫"上掉到 70%，用解释方法定位问题。
- **解题思路与完整解答**：① Grad-CAM 看一批样本：热力图集中在草地而非猫身——模型在靠背景作弊（spurious correlation）。② LIME/SHAP 交叉验证：遮挡猫身预测不变、遮挡草地预测翻转。③ 修复：多样化背景数据 / 背景增强 / 解释监督重训。**关键推理**：解释的价值在"发现分布外失败的根因"，对应 HW09"用解释结果反向改模型"的目标。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW09 官方任务即"解释已训练模型并对照多方法"：E1 Saliency baseline → E2 加 Grad-CAM/IG 对照 → E3 稳定性测试 → E4 挑成功/失败样本写分析。代码骨架：
```python
def saliency_map(model, x, target):
    x = x.clone().requires_grad_(True)
    out = model(x)[0, target]; out.backward()
    return x.grad.abs().max(dim=1)[0]   # RGB 取通道最大

def grad_cam(model, x, target, conv_out, grad):
    alpha = grad.mean(dim=(2, 3), keepdim=True)               # 全局平均池化
    cam = (alpha * conv_out).sum(dim=1, keepdim=True).relu()  # 加权求和 + ReLU
    return F.interpolate(cam, size=x.shape[-2:], mode="bilinear", align_corners=False)
```

## 8. 常见误区和易混概念

### 误区 1：热力图"看起来合理"就等于解释正确
- **错误直觉**：模型在热力图上聚焦了猫脸，所以它"真的在看猫"。
- **为什么错**：解释方法本身可能不可靠（对扰动敏感、随机种子不同结果不同）；没有 ground truth 时"合理"只是主观判断。
- **正确理解**：解释需要**评估**：faithfulness（删除高归因区域预测是否改变）、稳定性（加噪后解释是否一致）、多方法一致性。

### 误区 2：注意力权重 = 模型解释
- **错误直觉**：attention 权重矩阵可以直接当解释用。
- **为什么错**：attention 是"软加权混合"而非"选择"；Jain & Wallace (2019) 证明 attention 与归因相关性弱，甚至可构造出任意 attention 图。
- **正确理解**：attention 是"解释候选"，必须用归因方法交叉验证。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| Saliency/Grad-CAM | 输入/特征对输出的敏感性 | 需可微模型、局部梯度 | CNN 图像解释（HW09） |
| LIME/SHAP | 局部代理 / 博弈分配 | 黑盒可用、SHAP 有公理 | 表格/任意黑盒 |
| [[对抗攻击与防御（HW10）]] | 找最小扰动改变预测 | 同用梯度但方向相反 | 鲁棒性测试 |

### 题目与解析

#### 1. Saliency map 与模型权重是一回事吗？
> [!question]- 答案解析
> - **答案**：不是。线性模型两者相等；非线性模型下梯度是"特定输入点的一阶敏感性"，随输入变化，而权重是全局参数。
> - **解析**：Saliency 对输入求导（$\partial f_c/\partial x$），权重对参数求导（$\partial f/\partial\theta$）——求导对象不同。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 对 $f(x)=3x_1-2x_2+1$ 与 $x=(2,1)$，计算 Saliency 归因，并指出局限。
> [!question]- 答案解析
> - **答案**：$S=(|3|,|-2|)=(3,2)$。局限：梯度是"边际敏感性"而非"实际贡献"——$x_1=2$ 的实际贡献是 $6$，$x_2=1$ 是 $-2$。
> - **解析**：真正的一阶贡献近似是 $\nabla f\odot x$（Hadamard 积）；Saliency 取绝对值丢掉了方向与尺度。

#### 3. 表格信贷模型（XGBoost）和 CNN 图像模型，分别该用哪种解释方法？
> [!question]- 答案解析
> - **答案**：表格 → SHAP/LIME（黑盒可用、SHAP 有公理保证）；CNN 图像 → Grad-CAM/Saliency（需要空间热力图且模型可微）。
> - **解析**：方法选择取决于"模型是否可微 + 输入是否结构化空间"。

#### 4. 如何量化评估一个解释方法"靠不靠谱"？
> [!question]- 答案解析
> - **答案**：① faithfulness：删除高归因区域后预测分数应显著下降；② 稳定性：加噪/重参数化后解释应一致；③ 多方法一致性：Grad-CAM 与 LIME 的高归因区域应重叠。
> - **解析**：对应 HW09 说明书 E3"稳定性测试"与"记录不可靠解释"的要求。

#### 5. 论证：模型输出饱和时为什么 Saliency 会失效？给出两个对策。
> [!question]- 答案解析
> - **答案**：softmax/sigmoid 饱和区导数趋近 0，$\partial f_c/\partial x\approx0$，归因图全黑——模型"最确信"时反而"最不可解释"。对策：① 对 logit 而非概率求梯度；② 用 Integrated Gradients 沿路径积分，聚合整条路径的敏感性。
> - **解析**：IG 的动机之一就是单点梯度在饱和区的失效。
