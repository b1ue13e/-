# 终身学习（HW13）

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW13 官方任务（连续学多个任务并测"遗忘曲线"）直接围绕灾难性遗忘与 EWC/回放/蒸馏展开；它是"模型为什么会越训越笨"的入口，与 HW14 共享"存储受限"视角，也与 [[ L1正则化Lasso]] 的正则思想一脉相承。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 现实模型要**连续学习多个任务**：先学会手写数字，再学交通标志，未来还要学鸟类。但用新任务数据继续训练时，模型**学会新任务的同时把旧任务忘光**——旧任务准确率断崖式下跌，甚至跌回随机。这就是灾难性遗忘（catastrophic forgetting）。每次学新任务都重训全部旧数据不可行（存储/隐私/算力），因此必须引入一种方法：**在只有新任务数据（或极少旧数据）的情况下持续学习且不显著遗忘旧任务**——这就是终身学习（Life-Long Learning / Continual Learning）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW13 官方任务（连续任务学习 + 遗忘评估）直接要求实现 EWC/回放等；它是"持续学习"主题入口，与 HW14 共享"存储/参数受限"约束，与 [[🎯 过拟合专题]] 的"正则化"思想直接对话。
- **实际应用场景**：手机端模型随用户数据持续更新（隐私约束下不能存旧数据）、推荐系统持续演化、机器人增量学技能、大模型持续预训练（LoRA 续训的核心痛点）。
- **高频题型/任务**：解释灾难性遗忘成因（参数共享 + 梯度冲突）；写 EWC 损失并解释 Fisher 含义；对比正则/回放/蒸馏的代价；画并解释遗忘曲线；设计评估协议（任务顺序、ACC/BWT）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[🎯 多层神经网络 (MLP)]]**：遗忘发生在共享参数上，理解"参数共享"是前提。
2. **[[ L1正则化Lasso]]**：EWC 本质是"带权重的 L2 正则"——Fisher 权重即惩罚强度。
3. **[[反向传播算法BP]]**：梯度冲突（新梯度覆盖旧方向）是遗忘的机制解释。

---

## 4. 用直觉语言解释它

> «"终身学习"就像一位不断学新乐器的乐手：学了吉他再学钢琴，结果**吉他也忘光了**——手指"肌肉记忆"（参数）被新练习覆盖。三条出路：① 学钢琴时**重点保护**练吉他最敏感的动作（EWC：重要参数少动）；② 偶尔**复习**几首老曲子（回放：存一点旧数据）；③ 新练习**以旧曲子的感觉为参照**（蒸馏：旧模型当老师）。»

- **直觉类比/几何图像**：损失面里旧任务的"低损失盆地"被新梯度推离——EWC 在旧盆地周围"筑墙"（Fisher 加权惩罚）；回放是在新任务里掺旧样本，把旧盆地"重新夯实"；蒸馏让新模型输出模仿旧模型，保持旧"行为"。遗忘 = 新梯度覆盖旧梯度，所以要么限制覆盖（正则）、重放旧信息（回放）、把旧行为编码进目标（蒸馏）——从"参数/数据/行为"三个层面防守。
- **一句话直觉本质**：**灾难性遗忘 = 新任务梯度覆盖旧任务参数；终身学习 = 用参数重要性加权（EWC）、数据回放或输出蒸馏，让"学新"不"忘旧"。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
终身学习：模型顺序学习任务 $T_1,\dots,T_T$，训练 $T_t$ 时只能访问任务 $t$ 的数据（至多少量旧样本），目标是学完后在**所有旧任务上保持性能**。核心指标：平均准确率（ACC）与平均遗忘（BWT, Backward Transfer）。

### 2. 核心公式
EWC（Elastic Weight Consolidation）：
$$\mathcal{L}(\theta)=\mathcal{L}_t(\theta)+\frac{\lambda}{2}\sum_i F_i\,(\theta_i-\theta^*_{i})^2,\qquad F_i=\mathbb{E}_{x\sim D_{old}}\Big[\big(\nabla_{\theta_i}\log p(y|x,\theta^*)\big)^2\Big]$$
知识蒸馏（KD）损失（旧模型 $f^{old}$ 当老师，$T$ 为温度）：
$$\mathcal{L}=\mathcal{L}_t(\theta)+\lambda\,T^2\,\mathrm{KL}\!\left(\mathrm{softmax}(z^{old}/T)\,\big\Vert\,\mathrm{softmax}(z/T)\right)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\theta^*$ | 旧任务学完后的参数 | $\mathbb{R}^p$ | 被"锚定" |
| $F_i$ | 参数 $i$ 对旧任务的重要性 | $\ge 0$ | Fisher 对角近似 |
| $\lambda$ | 惩罚强度 | $>0$ | 越大越保守 |
| $T$ | 蒸馏温度 | $>1$ 常用 | 放大软标签 |
| ACC / BWT | 平均准确率 / 平均遗忘 | $[0,1]$ | 评估协议核心 |

### 4. 常见变体与适用条件
- **变体**：正则类（EWC、SI、LwF）、回放类（经验回放 ER、A-GEM）、结构类（Progressive Networks、参数隔离）、参数高效（每任务 LoRA）。
- **限制条件**：EWC 的"对角重要性"近似在任务差异大时失效；回放需存储预算；纯蒸馏在类别集变化（class-incremental）时效果差；遗忘只能缓解不能消除。

---

## 6. 推导思路和思想来源

- **最初困难**：参数全共享，新任务 SGD 会无差别覆盖旧任务学到的参数配置。全存旧数据重训最稳但违反存储前提；固定旧层学不了新任务；均匀 L2 正则对"不重要"参数过度约束，新任务学不动。
- **关键"转念"**：**参数不是平等的**——旧任务对某些参数"极度依赖"（Fisher 大），对另一些"无所谓"（Fisher 小）。EWC 用 Fisher 对角做**逐参数弹性**：重要参数钉死，不重要放手，实现"既不忘旧、又学得动新"。
- **推导主线与动机**：① 贝叶斯视角：旧任务后验 $p(\theta|D_{old})$ 用 Laplace 近似为高斯（均值 $\theta^*$、精度 Fisher）；② 新任务 MAP ⇒ 损失 = 新任务 NLL + $\frac{\lambda}{2}\sum F_i(\theta_i-\theta_i^*)^2$；③ 蒸馏（LwF）走"行为"路线：输出逼近旧模型；④ 回放走"数据"路线：存代表性旧样本直接参与训练。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：两参数模型，任务 A 后 $\theta^*=(1,0)$，Fisher $F=(2,0.1)$；任务 B 损失 $\mathcal{L}_B=(\theta_1-3)^2+(\theta_2-4)^2$，$\lambda=1$。求 EWC 最优解。
- **解题思路与关键步骤**：$\mathcal{L}_{EWC}=(\theta_1-3)^2+(\theta_2-4)^2+\frac{1}{2}[2(\theta_1-1)^2+0.1\theta_2^2]$。对 $\theta_1$：$2(\theta_1-3)+2(\theta_1-1)=0\Rightarrow\theta_1=2$；对 $\theta_2$：$2(\theta_2-4)+0.1\theta_2=0\Rightarrow\theta_2\approx3.81$。
- **最终答案**：$\theta\approx(2,3.81)$。对比无正则解 $(3,4)$：Fisher 大的 $\theta_1$ 被拉回 2（贴近旧值 1），Fisher 小的 $\theta_2$ 几乎自由——"重要的钉住、不重要的放手"。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：任务序列 [数字 → 服装]，EWC 训练后旧任务准确率仍从 95% 掉到 60%。定位原因并给出修复方向。
- **解题思路与完整解答**：① 检查 Fisher 是否在**旧任务最优参数**处计算、旧样本是否足够（Fisher 方差大是常见失败原因）；② 检查 $\lambda$：太小惩罚不足，太大新任务学不动（连锁遗忘）；③ 若两任务类别集不同（10+10 类），分类头维度变化破坏逐参数对齐——需任务专属头或改蒸馏/回放；④ 换方法：存 5% 旧数据做经验回放，通常立竿见影。**关键推理**：EWC 的假设（共享骨干 + 对角重要性）在"任务差异大/类别集变化"时失效，回放是更稳的兜底。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW13 官方任务（顺序学多个分类任务）pipeline：统一骨干 + 每任务分类头，记录"任务 × 任务"准确率矩阵，画遗忘曲线。代码骨架：
```python
def ewc_loss(model, fisher, theta_star, lam):
    reg = sum(fisher[n] * (p - theta_star[n]) ** 2
              for n, p in model.named_parameters() if n in fisher).sum()
    return lam / 2 * reg   # 训练：loss = ce_loss + ewc_loss(...)
# 评估：学完 T 个任务后测"任务×任务"准确率矩阵，BWT = mean(下三角) - mean(对角线)
```

## 8. 常见误区和易混概念

### 误区 1：把"全部旧数据重新训练"当终身学习
- **错误直觉**：允许重训，遗忘就消失了。
- **为什么错**：终身学习的约束是**存储/隐私/算力**：旧数据不可得（用户删除、隐私法规、流式场景）时无法重训。
- **正确理解**：回放类方法就是在"存储预算内"近似重训；方法比较要在同一存储预算下进行。

### 误区 2：EWC 的 $\lambda$ 越大越好
- **错误直觉**：遗忘要压到 0，惩罚拉满。
- **为什么错**：$\lambda$ 过大 → 新任务学不动 → 新任务准确率低，共享层没学到新特征，旧任务也间接受损；这是"旧不降、新要学"的双目标。
- **正确理解**：用 ACC 与 BWT 联合评估；$\lambda$ 目标是帕累托前沿，不是单点最小遗忘。

### 题目与解析

#### 1. 为什么神经网络会灾难性遗忘？
> [!question]- 答案解析
> - **答案**：参数全共享 + 顺序 SGD：新任务梯度更新覆盖旧任务优化的参数配置，旧任务"低损失盆地"被推出，误差回升。Fisher 视角：新梯度与旧任务重要方向冲突的分量被改写。
> - **解析**：这不是过拟合（旧任务测试误差上升），而是优化目标切换；经典实验 MNIST 先 0-4 再 5-9，旧任务准确率可跌回随机。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 给定 $\theta^*=(1,0)$、$F=(2,0.1)$、$\mathcal{L}_B=(\theta_1-3)^2+(\theta_2-4)^2$、$\lambda=1$，求 EWC 最优解。
> [!question]- 答案解析
> - **答案**：$\theta_1=2,\ \theta_2\approx3.81$。
> - **解析**：$2(\theta_1-3)+2(\theta_1-1)=0\Rightarrow\theta_1=2$；$2(\theta_2-4)+0.1\theta_2=0\Rightarrow\theta_2\approx3.81$。Fisher 大的 $\theta_1$ 被拉向旧值，Fisher 小的 $\theta_2$ 基本自由。

#### 3. 三台设备分别面临：①存储几乎为零；②能存 10% 旧样本；③旧任务类别集与新的完全不同。各自首选哪类方法？
> [!question]- 答案解析
> - **答案**：① 正则/蒸馏类（EWC、LwF，零存储）；② 经验回放（ER，性价比最高）；③ 任务专属头/参数隔离（类别集变化时共享输出头会冲突）。
> - **解析**：方法选择 = 存储预算 × 任务结构；回放最强但吃存储，正则省存储但受对角假设限制，蒸馏在 class-incremental 下最弱。

#### 4. 学完 3 个任务后，任务 1、2 的准确率分别从 0.95、0.90 掉到 0.60、0.75。计算 BWT 并解释。
> [!question]- 答案解析
> - **答案**：BWT = 平均"学完后 vs 刚学完时"的变化：$(0.60-0.95)+(0.75-0.90)$ 再平均 $\approx-0.25$，即平均每个旧任务掉了 25 个百分点，遗忘严重。
> - **解析**：BWT<0 表示遗忘；终身学习评估必须同时报 ACC 与 BWT，只看最终 ACC 会掩盖遗忘。

#### 5. 从贝叶斯视角推导 EWC 损失，并指出其两个近似假设。
> [!question]- 答案解析
> - **答案**：旧任务后验 $p(\theta|D_{old})\propto p(D_{old}|\theta)p(\theta)$，Laplace 近似为 $\mathcal{N}(\theta^*,F^{-1})$；新任务 MAP 即 $\max_\theta\log p(\theta|D_{old})+\log p(D_{new}|\theta)$，得损失 $\mathcal{L}_{new}(\theta)+\frac{\lambda}{2}\sum_i F_i(\theta_i-\theta_i^*)^2$。近似假设：① 高斯（Laplace）后验且 Fisher 取**对角**（忽略参数相关性）；② $\theta^*$ 与 Fisher 一次估计，任务序列变长误差累积。
> - **解析**：对角假设在参数强相关时失效（可用块对角 Fisher 缓解），这是 EWC 在任务差异大时效果差的数学根源。
