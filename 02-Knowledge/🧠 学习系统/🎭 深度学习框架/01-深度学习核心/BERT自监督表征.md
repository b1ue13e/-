# BERT自监督表征

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：BERT 是 HW07 的唯一核心（预训练模型微调），也是"预训练-微调"范式（现代 NLP 与全部大模型）的样板。不掌握 MLM/NSP 与微调流程，HW07 的 tokenizer、截断策略、冻结层实验全都无法解释。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 以前做 NLP 任务（分类、问答、命名实体识别）都是"任务一个模型"：从头训练，每个任务都要海量标注数据，且每个模型只学到任务特定的表面模式，无法共享语言知识。
> 因此必须引入一种新范式：**先用海量无标注文本"自监督"地学出通用的语言表示（预训练），再在少量标注数据上做任务适配（微调）**——这就是 BERT（Devlin et al., 2018）开创的"预训练 + 微调"路线。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：BERT 建立在 [[自注意力机制Self-Attention]]（HW04）与 Transformer 编码器（HW05）之上；HW07 整个作业就是"微调 BERT 做问答"。它与 GPT 的对比（双向 vs 单向）是理解"编码器 vs 解码器"路线的分水岭。
- **实际应用场景**：文本分类、问答（HW07）、命名实体识别、句子相似度、检索排序——几乎所有 NLP 下游任务；其"预训练-微调"思想已扩展到图像（MAE）与多模态。
- **高频题型/任务**：解释 MLM 与 NSP 任务设计及为什么有效；微调与特征提取两种用法的区别；BERT vs GPT 的结构与任务差异；tokenizer/截断/冻结层的工程问题（HW07 常见坑）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[自注意力机制Self-Attention]]**：BERT 的每一层都是多头 self-attention + FFN，Q/K/V 机制是理解 BERT 前向的基础。
2. **[[🎯 多层神经网络 (MLP)]]**：BERT 顶部的分类头就是线性层；微调 = 继续反向传播。
3. **[[交叉熵损失函数]]**：MLM 是"预测被 mask 的词"的多分类（词表大小类别数），NSP 是二分类，都用交叉熵。

---

## 4. 用直觉语言解释它

> «"预训练"就像让一个学生先读一百万本书（无监督，不考试），把"词怎么搭配、句子怎么组织"的语感学到骨子里；"微调"就像拿到具体考题（分类/问答）后，只做几套真题就上考场。BERT 的"读书方式"很特别：老师把书上的词**用墨点涂掉**（Mask），让学生猜被涂掉的是什么——猜得准，说明真的读懂了上下文。»

- **直觉类比/几何图像**：MLM 是"完形填空"（Cloze）：随机遮住 15% 的 token，用双向上下文预测；NSP 是"判断两句话是否连贯"。这两件事都不需要人工标注，所以能无限"读书"。
- **为什么很自然**：语言的核心能力是"根据上下文预测"，而完形填空天然逼迫模型同时利用左右两侧信息（双向），这正是 BERT 与"只能从左往右读"的 GPT 的根本差异。
- **一句话直觉本质**：**在海量无标注文本上用"完形填空 + 句子连贯性"两个自监督任务预训练一个双向 Transformer 编码器，得到通用语言表示；下游任务只需在顶部加一个分类头微调。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **BERT（Bidirectional Encoder Representations from Transformers）**：多层双向 Transformer 编码器，在预训练阶段优化两个自监督目标：
  - **MLM（Masked Language Model）**：随机 mask 15% 的 token，用双向上下文预测被 mask 的词：
$$\mathcal{L}_{\text{MLM}} = -\sum_{i \in \mathcal{M}} \log P(w_i \mid X_{\setminus \mathcal{M}}), \qquad P(w_i\mid\cdot) = \text{softmax}(h_i W_{\text{vocab}}^{\top})$$
  - **NSP（Next Sentence Prediction）**：判断第二句是否是第一句的下一句（二分类，正/负样本 1:1）。
$$\mathcal{L}_{\text{NSP}} = -\big[y\log P(\text{IsNext}) + (1-y)\log P(\text{NotNext})\big]$$

### 2. 核心公式
预训练总损失：$\mathcal{L} = \mathcal{L}_{\text{MLM}} + \mathcal{L}_{\text{NSP}}$。输入表示 = token embedding + segment embedding + position embedding：
$$h_0 = E_{\text{token}} + E_{\text{seg}} + E_{\text{pos}}, \qquad h_l = \text{TransformerBlock}(h_{l-1}), \quad l=1,\dots,L$$
微调：在 $h_L$ 的 `[CLS]` 位置接分类头 $P(y) = \text{softmax}(h_L^{\text{CLS}} W_c)$，用交叉熵在标注数据上继续训练全部参数（或冻结部分层）。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $X$ | 输入 token 序列 | $\mathbb{R}^{n}$（词表索引） | 含 `[CLS]`/`[SEP]` 特殊符 |
| $\mathcal{M}$ | 被 mask 的 token 位置集合 | 约 15% 位置 | 80% 换 `[MASK]`、10% 随机词、10% 不变 |
| $h_l$ | 第 $l$ 层表示 | $\mathbb{R}^{n\times d}$ | $L=12$（base），$d=768$ |
| $W_{\text{vocab}}$ | 词表投影矩阵 | $\mathbb{R}^{d\times |V|}$ | 与输入 embedding 共享权重 |
| $y$ | NSP 标签 | $\{0,1\}$ | IsNext / NotNext |

### 4. 常见变体与适用条件
- **变体**：RoBERTa（去掉 NSP、动态 mask、更大数据）、ALBERT（参数共享）、DistilBERT（蒸馏压缩，HW14 相关）、多语言 mBERT、中文 BERT（chinese-bert-wwm）。
- **适用条件**：有预训练权重可用（HuggingFace `transformers`）；下游任务能表达为"序列 → 标签/区间"。
- **限制条件**：输入长度受限于 512 token（截断策略影响 HW07 效果）；训练/推理显存大；领域差异大时需继续预训练（domain adaptation）。

## 6. 推导思路和思想来源

- **最初困难**：标注数据稀缺，每任务从头训练成本高且泛化差；传统词嵌入（word2vec）是"静态"的——一个词只有一个向量，无法处理一词多义（"bank" 河岸/银行）。
- **直接方法局限**：ELMo/GPT 等早期模型只做"单向"语言模型（只能看左侧），丢失了右侧上下文；而很多任务（完形、消歧）需要双向信息。
- **关键"转念"**：**把"语言模型"改造成"完形填空"**——遮住词再预测，既保留"预测"的自监督信号，又让模型同时看到左右两侧（双向）。这就是 MLM；再加 NSP 逼迫模型建模句子间关系。
- **推导主线与动机**：① 词嵌入静态 → 用 Transformer 编码器得到"上下文相关"的动态表示；② 单向 LM → mask 后双向预测（MLM）；③ 单句建模 → NSP 学习句间关系；④ 预训练 → 微调：顶部换分类头，全参数继续训练（end-to-end）。
- **为什么自然得到此结论**：完形填空是人类学习语言的本能任务；"先广泛阅读再专项训练"也是人类学习的自然顺序——BERT 把这两点工程化了。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：句子 "I [MASK] to school yesterday."，词表仅 {go, went, eat}。模型预测三个词的 logits 为 $[0.1, 2.0, 0.5]$。求 MLM 的交叉熵损失（假设真实词为 went）。
- **解题思路与关键步骤**：softmax：$e^{0.1}+e^{2.0}+e^{0.5}=1.105+7.389+1.649=10.143$；$P(\text{went})=7.389/10.143\approx0.728$。交叉熵 $=-\log 0.728\approx0.317$。
- **最终答案**：$\mathcal{L}_{\text{MLM}} \approx 0.317$。若模型预测均匀（各 1/3），损失为 $-\log(1/3)\approx1.099$——损失从 1.099 降到 0.317 说明模型利用上下文（yesterday → went）学到了信息。
- **易错点**：损失只对被 mask 的位置计算，不是对所有位置；类别数是**词表大小**而非标签数。
- **🤔 追问**：如果句子换成 "I [MASK] to school tomorrow."，正确的词应是什么？——tomorrow 提示未来时态，正确答案更可能是 "go"，这正是 MLM 学到的"时态线索"。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：HW07 中一段文本长度 1200 token，BERT 最大长度 512。请设计处理策略并说明 trade-off。
- **解题思路与完整解答**：策略 A：直接截断前 512（简单但丢信息）；策略 B：截断后 512（答案常在尾部时有效）；策略 C：滑窗分段（切 3 段分别过模型再聚合，显存×3）；策略 D：按答案/证据位置动态截取（QA 任务常用）。**关键推理**：选择依据是"信息密度分布"——先做长度分布统计（HW07 要求），若关键信息均匀分布则滑窗，若集中则定向截断；报告中必须对比不同 `max_length` 的验证指标（截断策略分析是 HW07 评分点之一）。
- **易错点**：`max_length` 设置与 tokenizer 的 `truncation=True` 语义不一致；截断后标签对齐错误；OOM 后只降 batch 不分析长度。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW07 官方任务是阅读理解（QA）：输入 question + context，输出答案 span。用 `transformers` 加载 `bert-base-uncased`，顶部加 span 起止分类头，微调 2-3 epoch；对比"冻结底层 vs 全量微调"、"分层学习率"验证预训练收益——这正是工业界"大模型底座 + 任务头"的标准流程。
- 代码形态（PyTorch + HuggingFace）：
```python
from transformers import BertForQuestionAnswering, BertTokenizerFast
tok = BertTokenizerFast.from_pretrained('bert-base-uncased')
model = BertForQuestionAnswering.from_pretrained('bert-base-uncased')
enc = tok(question, context, truncation=True, max_length=512, return_tensors='pt')
start_logits, end_logits = model(**enc)  # 答案 span = argmax(start)..argmax(end)
```

## 8. 常见误区和易混概念

### 误区 1：BERT 的预训练权重可以直接用于任何任务而不微调
- **错误直觉**：BERT 已经"什么都会"，直接拿 `[CLS]` 向量当特征即可。
- **为什么错**：预训练学的是语言知识，任务头（分类边界）没学过；不微调时表示与任务分布错位，效果显著下降（尤其领域差异大时）。
- **正确理解**：两种用法：① 特征提取（冻结 BERT，只训分类头，快但弱）；② 微调（全参/分层学习率继续训练，强但贵）。HW07 要求对比二者并解释差距。

### 误区 2：BERT 与 GPT 没有本质区别，都是"预训练语言模型"
- **错误直觉**：都是 transformer + 海量文本，换个名字而已。
- **为什么错**：BERT 是**双向编码器**（MLM，看左右），适合"理解"类任务（分类、抽取、QA）；GPT 是**单向解码器**（自回归 LM，只看左侧），适合"生成"类任务（续写、对话）。结构决定任务分工。
- **正确理解**：编码器-解码器是两种归纳偏置：BERT 用"完形填空"逼出双向表示，GPT 用"下一个词预测"逼出生成能力。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| BERT | 理解型表征 | 双向编码器 + MLM/NSP | 分类、QA、NER（HW07） |
| GPT | 生成型建模 | 单向解码器 + 自回归 LM | 文本生成、对话 |
| 词嵌入 word2vec | 静态词向量 | 一词一向量、无上下文 | 传统特征、快速原型 |
| ELMo | 上下文表征 | 双向 LSTM，浅层融合 | 预训练早期方案 |

### 题目与解析

#### 1. BERT 预训练的两个任务分别解决什么问题？
> [!question]- 答案解析
> - **答案**：MLM（完形填空）解决"双向上下文建模"——同时利用左右两侧信息预测被 mask 的词；NSP（句子连贯性）解决"句子间关系建模"，让表示携带篇章级信息。
> - **解析**：二者都不需要人工标注，是"自监督信号"的来源；总损失为两者之和。
> - **易错原因**：只记得 MLM 忘了 NSP，或说不清 NSP 解决什么。
> - **对应误区**：误区 2。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 手算：词表 {a, b, c}，被 mask 位置 logits 为 [1.0, 2.0, 0.5]，真实词为 b，求 MLM 交叉熵损失。
> [!question]- 答案解析
> - **答案**：$e^1+e^2+e^{0.5}=2.718+7.389+1.649=11.756$；$P(b)=7.389/11.756\approx0.628$；$\mathcal{L}=-\log 0.628\approx0.465$。
> - **解析**：损失只对 mask 位置计算；若模型给真实词的概率越高，损失越接近 0。
> - **易错原因**：忘记 softmax 归一化直接取 logits；或对全部 token 位置求和。

#### 3. 什么情况下"冻结 BERT 只训分类头"比"全量微调"更合理？
> [!question]- 答案解析
> - **答案**：① 标注数据极少（微调易过拟合）；② 计算资源受限（显存/时间）；③ 下游任务与预训练领域非常接近，底层语言知识已足够；④ 需要快速原型验证。
> - **解析**：全量微调收益大但风险高（灾难性遗忘、过拟合）；分层学习率是折中方案（底层小 lr、顶层大 lr）。
> - **易错原因**：默认全量微调永远更好，忽略数据量与算力约束。
> - **对应误区**：误区 1。

#### 4. 从结构与任务两方面对比 BERT 与 GPT。
> [!question]- 答案解析
> - **答案**：结构上 BERT 用 Transformer **编码器**（双向注意力，无因果 mask），GPT 用**解码器**（带因果 mask 的单向注意力）；任务上 BERT 用 MLM/NSP 预训练（理解型），GPT 用自回归"预测下一个词"（生成型）。
> - **解析**：双向带来上下文优势但无法直接生成；单向可自回归生成但左侧信息受限。BERT 适合分类/QA/抽取，GPT 适合续写/对话。
> - **易错原因**：混淆编码器/解码器的注意力 mask 差异。
> - **对应误区**：误区 2。

#### 5. 为什么 MLM 的 mask 策略是"80% 换 [MASK]、10% 随机替换、10% 保持不变"？
> [!question]- 答案解析
> - **答案**：微调阶段输入**没有** [MASK] token，若预训练只见过 [MASK] 会出现"预训练-微调不一致"（exposure bias）。10% 随机替换迫使模型不能只依赖"见到 [MASK] 就猜"的捷径，必须真正理解上下文；10% 保持不变让模型学会"即使词没被遮住也要编码它"。
> - **解析**：这是 BERT 论文的消融结论：全换 [MASK] 时微调效果下降；随机替换比例过高则任务过难。
> - **易错原因**：以为 mask 比例纯粹是超参数拍脑袋；讲不出"分布一致性"动机。
