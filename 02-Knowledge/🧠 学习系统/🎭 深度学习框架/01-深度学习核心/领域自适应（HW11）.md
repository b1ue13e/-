# 领域自适应（HW11）

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW11 官方任务（跨域分类：真实照片 vs 手绘简笔画）直接要求"源域标签 + 目标域无标签"训练；特征对齐（MMD/对抗）与自训练是作业核心招式；同时是"迁移学习"主题的入口，与 [[BERT自监督表征]] 的 pretrain-finetune 形成对照。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 训练数据（源域：真实照片）与部署数据（目标域：手绘简笔画）**分布不同**——同一类别，照片与简笔画的像素分布差异巨大。直接把源域模型拿到目标域，准确率断崖式下跌（domain shift）。重新标注目标域太贵，但**无标签的目标域数据是免费的**。因此必须引入一种方法：**用源域有标签数据 + 目标域无标签数据，学一个在目标域也好用的模型**——这就是无监督领域自适应（UDA）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW11 官方任务（Office-Home/简笔画跨域分类）就是标准 UDA；与 [[BERT自监督表征]] 同属"迁移"家族：BERT 是任务间迁移，UDA 是域间迁移；与 HW10 的对抗思想再次相遇（这次对抗"域判别器"）。
- **实际应用场景**：合成→真实数据（自动驾驶 sim2real）、跨语言情感分析、跨摄像头行人重识别、医疗影像跨设备迁移、冷启动推荐。
- **高频题型/任务**：解释 domain shift 成因（covariate/label/concept shift）；写 MMD 公式；说明 DANN 梯度反转层；比较特征对齐与自训练；设计 UDA 实验与评估协议。

---

## 3. 学它之前需要哪些前置知识？

1. **[[ 无监督学习]]**：目标域数据无标签，对齐目标本质是无监督目标。
2. **[[🎯 多层神经网络 (MLP)]]**：特征提取器 + 分类器是 UDA 标准骨架。
3. **[[BERT自监督表征]]**：预训练-微调是"任务迁移"，与"域迁移"对照理解，其表示常作为 UDA 初始化。

---

## 4. 用直觉语言解释它

> «"领域自适应"就像请一位教"普通话班"的老师去教"四川话班"：两个班教材（特征分布）不同，但知识结构（类别边界）相同。老师不能照搬教案，但可以让两个班学生**做同一套动作**——让模型提取出"不分口音都能用"的特征（域不变特征），再用普通话班的标签教会分类。»

- **直觉类比/几何图像**：把两域数据映射到同一特征空间；若两域**特征分布重叠**，源域的分类边界在目标域同样好用。UDA 核心就是"把两个分布拉到一起"：MMD 直接度量并最小化分布距离；对抗方法训练"分不清域"的判别器逼特征混淆。分类器只依赖特征，若"特征-标签"关系两域一致（共享假设），只需让"特征的边际分布"一致，标签条件分布就自动迁移。
- **一句话直觉本质**：**UDA = 源域标签定边界 + 目标域无标签做"分布对齐"，让边界在目标域依然成立；对齐工具是分布距离（MMD）或域对抗（DANN）。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
UDA：源域 $D_s=\{(x_i^s,y_i^s)\}_{i=1}^{n_s}$（有标签）、目标域 $D_t=\{x_j^t\}_{j=1}^{n_t}$（无标签），共享类别集合；目标是学特征映射 $\phi$ 与分类器 $f$，使目标域误差最小。

### 2. 核心公式
MMD（最大均值差异，核 $k$ 的经验估计）：
$$\widehat{\text{MMD}}^2=\left\|\frac{1}{n_s}\sum_{i}\phi(x_i^s)-\frac{1}{n_t}\sum_{j}\phi(x_j^t)\right\|^2_{\mathcal{H}_k}$$
域对抗（DANN）：特征提取器 $G$ 骗过域判别器 $D$：
$$\min_{G,C}\max_{D}\ \frac{1}{n_s}\sum_i \mathcal{L}_C(C(G(x_i^s)),y_i^s)-\lambda\Big[\frac{1}{n_s}\sum_i\log D(G(x_i^s))+\frac{1}{n_t}\sum_j\log(1-D(G(x_j^t)))\Big]$$
自训练（pseudo-label）：用当前模型给目标域打伪标签，按置信度筛选加入训练。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\phi(\cdot)$ | 特征映射（提取器） | $\mathbb{R}^d\to\mathbb{R}^m$ | 可学习 |
| $D_s,D_t$ | 源域 / 目标域 | 有标签 / 无标签 | 共享类别集 |
| $\text{MMD}$ | 两分布均值在 RKHS 的距离 | $\ge 0$ | =0 当且仅当分布相同 |
| $D$ | 域判别器 | 输出域概率 | 对抗对齐的"裁判" |
| $\lambda$ | 对齐强度 | $>0$ | 常用 $\frac{2}{1+e^{-10p}}-1$ 调度 |

### 4. 常见变体与适用条件
- **变体**：MMD 家族（DAN/JAN 多层对齐）、对抗家族（DANN、ADDA、CDAN）、自训练家族（pseudo-label + 置信度筛选）、统计家族（CORAL 对齐二阶矩）。
- **限制条件**：类别比例偏移时需条件对齐；对抗训练不稳定（同 GAN）；两域太不相关时强行对齐反而变差（负迁移）。

---

## 6. 推导思路和思想来源

- **最初困难**：目标域没有标签，监督学习无从谈起；直接迁移，domain shift 让误差暴涨。"输入级"适配（颜色迁移、直方图匹配）只处理浅层差异；"输出级"微调需要目标域标签，不可得。
- **关键"转念"**：**在特征空间做分布匹配**——不求"输入长得一样"，只求"特征分布一样"：MMD 用核技巧度量"均值嵌入的距离"；DANN 把对抗思想引入域判别：让特征提取器骗过"这是哪个域"的判别器（梯度反转层 GRL），特征被迫"域无关"。
- **推导主线与动机**：① Ben-David 上界：目标域误差 ≤ 源域误差 + 域差异 + 理想联合误差——对齐分布直接收紧上界；② MMD 无参数、可端到端训练；③ 对抗对齐把"分布距离"换成"判别器误差"，对高维数据更有效；④ 自训练从"输出"层面利用目标域自身预测结构。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：源域特征 $\{1,3\}$、目标域特征 $\{2,4\}$（一维），线性核 $k(x,y)=xy$ 下计算经验 MMD²。
- **解题思路与关键步骤**：$\widehat{\text{MMD}}^2=\left(\frac{1+3}{2}-\frac{2+4}{2}\right)^2=(2-3)^2=1$。
- **最终答案**：MMD² = 1。线性核只对齐一阶矩（均值差平方）；RBF 核可捕获方差等更高阶差异——选核 = 选对齐到几阶统计量。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：DANN 训练中域判别器 loss 降不下去（≈ log2），可能原因与处理？
- **解题思路与完整解答**：① loss ≈ log2 有两种解读：对齐成功（特征已域不变）或判别器太弱；区分方法：看目标域准确率是否同步上升，上升则成功，不动则欠拟合。② 欠拟合则加大判别器容量、提高其更新频率、调大 $\lambda$ 或用 CDAN（条件对抗）。③ 另一种原因：GRL 的 $\lambda$ 调度太快，特征没学好就强推对齐，产生"特征塌缩"——降低 $\lambda$ 或改渐进调度。**关键推理**：对抗训练里"判别器输"未必是坏事，必须用任务指标（目标域准确率）做最终裁判——与 HW06 GAN 的判断逻辑一致。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW11 官方任务（Office-Home/简笔画域）pipeline：ResNet 特征提取器 + 域对抗头 + 分类头，源/目标 batch 交替喂入。代码骨架：
```python
class GradientReversal(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, lam): ctx.lam = lam; return x.clone()
    @staticmethod
    def backward(ctx, grad): return -ctx.lam * grad, None

def train_step(src_x, src_y, tgt_x):
    feats_s, feats_t = g(src_x), g(tgt_x)
    cls_loss = F.cross_entropy(c(feats_s), src_y); d_s = d(GRL.apply(feats_s, lam)); d_t = d(GRL.apply(feats_t, lam))
    adv_loss = F.binary_cross_entropy(d_s, ones) + F.binary_cross_entropy(d_t, zeros)
    return cls_loss + lam * adv_loss
```

## 8. 常见误区和易混概念

### 误区 1：UDA 就是"半监督学习"
- **错误直觉**：都是"少量标签 + 大量无标签"。
- **为什么错**：半监督假设无标签与有标签**同分布**；UDA 假设无标签来自**不同分布**（目标域），其作用是"看清域差异"而非"补充同分布样本"。
- **正确理解**：半监督利用流形结构，UDA 利用分布差异本身；方法有交集（自训练）但问题设定不同。

### 误区 2：对齐得越彻底越好
- **错误直觉**：MMD/对抗 loss 压到 0 就成功了。
- **为什么错**：**过度对齐**会破坏类别判别信息（特征塌缩）：分布完全重合但类别结构被抹平，目标域反而更差。
- **正确理解**：对齐的是"与任务相关的差异"，需保留类别可分性——用条件对齐、类别级 MMD、目标域熵最小化。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 领域自适应 UDA | 源域标签 + 目标域无标签 | 域间分布对齐 | 跨域分类（HW11） |
| 迁移学习（广义） | 任意源→目标任务迁移 | 含 pretrain-finetune、few-shot | BERT（HW07）、元学习 |
| [[对抗攻击与防御（HW10）]] | 扰动改变预测 | 对抗的是"扰动"非"域" | 鲁棒性 |

### 题目与解析

#### 1. 无监督领域自适应与半监督学习的核心区别？
> [!question]- 答案解析
> - **答案**：半监督中无标签数据与有标签数据同分布，靠流形假设补标签；UDA 中无标签数据来自不同分布（目标域），靠"对齐两域分布"让源域边界迁移。
> - **解析**：设定不同 → 目标不同：半监督最小化同分布泛化误差，UDA 最小化跨域误差。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 源域特征 $\{1,3\}$、目标域特征 $\{2,4\}$，线性核下 MMD² 是多少？
> [!question]- 答案解析
> - **答案**：$\left(\frac{1+3}{2}-\frac{2+4}{2}\right)^2=(2-3)^2=1$。
> - **解析**：线性核 MMD 即均值差平方（一阶矩）；RBF 核可对齐更高阶矩；训练 $\phi$ 使该量最小化。

#### 3. 什么情况下用 MMD 对齐优于域对抗，反之亦然？
> [!question]- 答案解析
> - **答案**：数据量小、维度适中、求稳定 → MMD（无对抗不稳定，闭式估计）；高维图像、分布差异复杂 → 域对抗（判别器自适应聚焦难分区域）。
> - **解析**：MMD 是无参度量但受核选择影响；对抗是学习式度量、表达力强但训练不稳；实践中两路都跑，用目标域验证集选最优。

#### 4. 训练中域判别器 loss 逼近 log2 但目标域准确率不升反降，发生了什么？
> [!question]- 答案解析
> - **答案**：特征塌缩/过度对齐：对齐 loss 强行拉近两域特征，同时抹掉类别可分信息，分类器"两域都分不清类"；loss 低是"假成功"。
> - **解析**：判别器分不清域 ≠ 任务可分；需引入熵最小化、条件对齐或降低 $\lambda$，用目标域准确率做早停依据。
> - **对应误区**：误区 2。

#### 5. 论证：为什么"最小化域差异"能降低目标域误差？
> [!question]- 答案解析
> - **答案**：Ben-David 上界：$E_t(h)\le E_s(h)+\frac{1}{2}d_{\mathcal{H}\Delta\mathcal{H}}(D_s,D_t)+\lambda^*$，其中第二项是两域的"假设类可分距离"（域差异），第三项是理想联合误差。前两项分别由源域监督与分布对齐控制，第三项要求两域"特征-标签"关系一致。
> - **解析**：UDA 方法都在最小化第二项（MMD/对抗是它的可优化代理）；过度对齐危险在于 $\lambda^*$ 可能因类别结构被破坏而变大。
