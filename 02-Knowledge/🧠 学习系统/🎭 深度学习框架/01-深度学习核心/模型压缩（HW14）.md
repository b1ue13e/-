# 模型压缩（HW14）

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW14 官方任务（剪枝/蒸馏后测"压缩率 vs 精度"曲线）直接围绕四大压缩手段展开；它是"把模型塞进手机/边缘设备"的入口，与 [[自编码器Autoencoder]] 的"低维表示"同源（低秩 ≈ 线性自编码器），与 HW13 共享蒸馏工具。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 大模型（BERT-Large 3.4 亿参数、ResNet-152 6000 万参数）在服务器上跑得很好，但**手机、嵌入式设备、浏览器**的内存与算力装不下、跑不动：文件几百 MB、推理几十亿次浮点运算。直接训练小模型又达不到大模型精度（大模型有"知识冗余"）。因此必须引入一套技术：**尽量不损失精度地把模型变小、变快**——模型压缩（Model Compression），四大支柱：剪枝、量化、知识蒸馏、低秩分解。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW14 官方任务（分类模型剪枝/蒸馏，报告压缩率-精度曲线）直接基于本笔记；与 [[终身学习（HW13）]] 共享蒸馏（一个防遗忘、一个压缩）；与 [[自编码器Autoencoder]] 的"低维重构"同源。
- **实际应用场景**：手机端模型下载与推理、边缘 AI 芯片部署、大模型量化推理（GPTQ/AWQ 把 70B 压到 4-bit）、蒸馏小模型（DistilBERT 体积减半精度保留 97%）。
- **高频题型/任务**：解释结构化/非结构化剪枝及硬件影响；写量化公式（对称/非对称、INT8）；说明蒸馏的"温度"作用；计算压缩率；解释"精度-压缩率"权衡曲线。

## 4. 用直觉语言解释它

> «"模型压缩"就像给大词典做精简版：① 剪枝 = 删掉从没人查的生僻词（不重要的权重置零）；② 量化 = 把精细排版改成粗体大字（32 位浮点 → 8 位整数，信息略损但小 4 倍）；③ 蒸馏 = 老教授（大模型）亲自给新教师（小模型）划重点、讲答题套路（软标签）；④ 低秩分解 = 把"完整词条"拆成"词根 + 前后缀组合表"（大矩阵 ≈ 两个小矩阵乘积）。»

- **直觉类比/几何图像**：剪枝在"参数空间"删冗余（很多权重接近 0）；量化在"数值空间"降精度（相邻浮点值对预测几乎等价）；蒸馏在"输出空间"传知识（软标签比硬标签信息量大）；低秩在"矩阵空间"降秩（奇异值谱快速衰减，尾部可舍弃）。深度模型严重过参数化——有效自由度远小于参数量，冗余是压缩的"富矿"，四法分别从"结构、数值、行为、代数"四个维度挖冗余。
- **一句话直觉本质**：**压缩 = 在不改变"输入→输出映射"太多的前提下减少参数/比特/计算：剪枝删结构、量化降精度、蒸馏换小模型、低秩分解降秩。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
给定模型 $f_\theta$ 与目标压缩比 $r$，模型压缩寻找 $\tilde{f}$ 使 $\text{size}(\tilde{f})\le r\cdot\text{size}(f)$ 且精度损失最小。压缩率：$\text{CR}=\frac{\text{原始参数量}}{\text{压缩后参数量}}$（或体积比）。

### 2. 核心公式
量化（对称 INT8，$s$ 为缩放因子）：
$$x_q=\text{round}\!\left(\frac{x}{s}\right),\qquad s=\frac{\max|x|}{2^{b-1}-1}$$
剪枝：$\tilde{W}_{ij}=W_{ij}\cdot\mathbb{1}\{|W_{ij}|>\tau\}$（幅度阈值），或按 $L_1$ 剪通道。
知识蒸馏（学生 $f^S$ 学教师 $f^T$，温度 $T$）：
$$\mathcal{L}=\alpha\,\mathcal{L}_{CE}(f^S(x),y)+(1-\alpha)\,T^2\,\mathrm{KL}\!\left(\mathrm{softmax}(z^T/T)\,\Vert\,\mathrm{softmax}(z^S/T)\right)$$
低秩分解：$W\approx UV$，$W\in\mathbb{R}^{m\times n}$，$U\in\mathbb{R}^{m\times k}$，$V\in\mathbb{R}^{k\times n}$，$k\ll\min(m,n)$。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $W$ | 权重矩阵 | $\mathbb{R}^{m\times n}$ | 被压缩对象 |
| $\tau$ | 剪枝阈值 | $>0$ | 幅度阈值 |
| $s$ | 量化缩放因子 | $>0$ | 由数值范围决定 |
| $b$ | 量化比特数 | 8/4/2 | INT8 常见 |
| $T$ | 蒸馏温度 | $>1$ | 放大软标签 |
| $k$ | 分解秩 | $<\min(m,n)$ | 越低压缩越多 |

### 4. 常见变体与适用条件
- **变体**：非结构化剪枝（压缩率高但硬件不友好）、结构化剪枝（通道/层，硬件友好）；量化 PTQ/QAT；蒸馏离线/在线/特征蒸馏；低秩 SVD/CP/LoRA。
- **限制条件**：非结构化剪枝在 GPU 上难加速；低比特（≤4bit）量化精度损失显著；蒸馏需教师-学生容量差距适中；低秩对"奇异值谱平坦"的层效果差。

---

## 6. 推导思路和思想来源

- **最初困难**：模型规模与设备资源矛盾；直接训小模型达不到大模型精度。随机删权重毁模型；统一降精度误差累积；单独训小模型缺少"大模型的暗知识"（软标签里的类间相似性）。
- **关键"转念"**：**冗余是有结构的**——① 幅度剪枝：大量权重接近 0，删后微调即可恢复（彩票假说：存在稀疏子网络匹配原精度）；② 量化：相邻量化级别内的扰动对输出影响小，用缩放因子把动态范围映射到整数域；③ 蒸馏：软标签（"猫"0.7"狗"0.2"虎"0.1）比 one-hot 携带更多知识（类间相似性）；④ 低秩：SVD 截断小奇异值，Eckart-Young 定理保证重构最优。
- **推导主线与动机**：每种方法都是"最小化压缩后重构/行为误差"：剪枝最小化参数扰动、量化最小化数值误差、蒸馏最小化输出分布 KL、低秩最小化 Frobenius 重构误差——统一视角是"在约束下逼近原映射"。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：$W=\begin{bmatrix}3.2&-0.1&0.05\\0.2&-2.8&0.01\end{bmatrix}$。① 阈值 $\tau=0.1$ 剪枝后稀疏度？② 对称 INT8 量化求 $s$ 与 3.2 的量化值。
- **解题思路与关键步骤**：① $|{-0.1}|=0.1\le\tau$ 删，$|0.05|,|0.01|<0.1$ 删 ⇒ 删 3/6 = 50%。② $\max|W|=3.2$，$s=3.2/127\approx0.0252$，$3.2/s=127$（饱和）；$-2.8/s\approx-111.1\to-111$。
- **最终答案**：稀疏度 50%；$s\approx0.0252$，$3.2\to127$，$-2.8\to-111$；反量化误差 $|{-2.8}-(-111\times0.0252)|\approx0.003$，相对误差约 0.1%。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：ResNet 通道剪枝，压缩率 2× 时精度 76%→74%（可接受），但推理速度只提升 20%。分析原因并修复。
- **解题思路与完整解答**：① 原因：通道剪枝若每层独立阈值，会留下"宽窄不一"的层，内存带宽瓶颈与算子碎片化抵消 FLOPs 节省；且全局稀疏不一定落在计算热点层。② 修复：按"层敏感度"分配剪枝率、剪后**微调**恢复精度（剪枝-微调循环）、结构化整层剪枝 + 重排减少碎片。**关键推理**：压缩的最终指标是**实际延迟/能耗**而非参数量；FLOPs 下降 ≠ 速度提升，HW14 报告必须报"压缩率 vs 精度"与"压缩率 vs 延迟"两条曲线。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW14 官方任务 pipeline：先训大模型 → 剪枝 → 微调 → 蒸馏（大模型当教师）→ 逐步提高压缩率，记录精度曲线找"拐点"。代码骨架：
```python
def prune_by_magnitude(model, sparsity):
    for name, p in model.named_parameters():
        if p.dim() >= 2:
            thresh = torch.quantile(p.abs().flatten(), sparsity)
            p.data *= (p.abs() > thresh).float()   # 训练时保持 mask：p.grad *= mask

def distill_loss(student_logits, teacher_logits, y, T=4.0, alpha=0.7):
    soft = F.kl_div(F.log_softmax(student_logits / T, dim=-1),
                    F.softmax(teacher_logits.detach() / T, dim=-1), reduction="batchmean")
    return alpha * T**2 * soft + (1 - alpha) * F.cross_entropy(student_logits, y)
```

## 8. 常见误区和易混概念

### 误区 1：压缩率越高越好，只要精度不掉太多
- **错误直觉**：往死里压，反正有微调。
- **为什么错**：压缩收益**边际递减**：超过某点后精度断崖（信息论下界）；高压缩率下微调收益有限，还可能引入不可预测的失败模式（如量化后某类别系统性错误）。
- **正确理解**：画"压缩率-精度"曲线找**拐点**（HW14 报告核心），在目标约束（体积/延迟/能耗）内选点。

### 误区 2：蒸馏 = 用教师标签做硬标签训练
- **错误直觉**：把教师预测当"更准的标签"训练学生。
- **为什么错**：蒸馏的精髓是**软标签**（带温度的概率分布）：类间相似性才是额外知识；用硬标签只是"标签平滑化"，丢掉了暗知识。
- **正确理解**：温度 $T$ 放大软分布（越大越平、暗知识越多但噪声越多）；训练用 $T$、推理学生用 $T=1$，故损失乘 $T^2$ 平衡梯度尺度。

### 题目与解析

#### 1. 剪枝、量化、蒸馏、低秩分解各自从哪个"维度"压缩模型？
> [!question]- 答案解析
> - **答案**：剪枝删"结构"（权重/通道/层）；量化降"数值精度"（比特数）；蒸馏换"更小的模型"（行为匹配）；低秩降"矩阵秩"（代数结构）。
> - **解析**：四个维度可正交组合（蒸馏出小模型 → 剪枝 → 量化），HW14 实践常叠加。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 对 $\max|W|=3.2$ 的权重做对称 INT8 量化，求 $s$ 并量化 $-2.8$。
> [!question]- 答案解析
> - **答案**：$s=3.2/127\approx0.0252$，$-2.8/s\approx-111.1$，round 后 $-111$；反量化 $-111\times0.0252\approx-2.797$。
> - **解析**：对称量化动态范围 $[-127,127]$；舍入误差 $\le s/2$。

#### 3. 目标设备是 GPU（支持稠密矩阵乘）和 FPGA（支持稀疏加速），分别该选哪种剪枝？
> [!question]- 答案解析
> - **答案**：GPU → 结构化剪枝（通道/层，保持稠密张量）；FPGA/专用芯片 → 非结构化剪枝（细粒度稀疏可被稀疏加速器利用）。
> - **解析**：非结构化剪枝在通用硬件上无法加速；选型取决于**硬件稀疏支持**，而非压缩率本身。

#### 4. 蒸馏损失里为什么有 $T^2$ 因子？温度 $T$ 的作用？
> [!question]- 答案解析
> - **答案**：学生以 $T$ 训练、以 $T=1$ 推理；$\frac{\partial \mathrm{KL}}{\partial z}$ 量级约 $1/T^2$，乘 $T^2$ 使梯度尺度与 $T$ 无关；$T$ 放大软标签（越大分布越平，暗知识越多但噪声也越多）。
> - **解析**：没有 $T^2$ 时大 $T$ 会让 KL 项梯度消失，学生学不到软知识。

#### 5. 论证：对 $W$ 做秩 $k$ 低秩近似时，SVD 截断在 Frobenius 范数下最优。
> [!question]- 答案解析
> - **答案**：Eckart-Young 定理：$\min_{\mathrm{rank}(X)\le k}\|W-X\|_F=\sqrt{\sum_{i=k+1}^{\min(m,n)}\sigma_i^2}$，最优解 $X^*=U_k\Sigma_k V_k^\top$。奇异值谱快速衰减时（深度学习权重常见），截断损失可忽略。
> - **解析**：这给出低秩分解的最优性保证与误差公式；判断"该层能否低秩化"看奇异值谱衰减速度。
