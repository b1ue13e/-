# 🧭 下一批样板课开源作业源扩展路线图

> 这页回答的不是“还有哪些资源”，而是更具体的问题：
>
> - 下一批最值得继续做成“老师版真实作业包”的课程是哪几门；
> - 每门课该用谁做 **课程主线**；
> - 每门课该用谁做 **工程作业源 / baseline 源**；
> - 重构时老师该给什么，学生又该自己完成什么。

---

## 🎯 当前建议：先做 4 门最稳的样板课

| 优先级 | 课程 | 为什么优先 | 目标形态 |
|:---:|:---|:---|:---|
| 1 | 计算机视觉 | 连续作业骨架最清楚，公开资料成熟，最像“可直接老师版重构”的第二门样板课 | `HW01-HW06` 连续作业 |
| 2 | NLP 全栈 | 课程主线清晰，实验链路成熟，最适合做“传统方法 → Transformer → 项目评测” | `HW01-HW06` 连续作业 |
| 3 | 计算机组成原理 | 项目序列天然强、测试文化最强，极适合真实作业包思路 | `HW01-HW08/HW12` 分层项目作业 |
| 4 | 强化学习 | 适合做“小环境 + 多随机种子 + baseline 公平对照”的老师版实验课 | `HW01-HW06` 项目型作业 |

## 1. 计算机视觉

### 课程主线源

1. `Stanford CS231n`
   最像连续作业体系。kNN / Softmax / 两层网络 / CNN / PyTorch / Transformer-CLIP-Diffusion 的推进顺序非常适合改造成 `HW01-HW06`。

2. `Michigan EECS 498 / 598`
   适合当 CS231n 的补充作业源，尤其适合把“从手搓到现代框架”的过渡做得更平滑。

### 工程作业源 / baseline 源

1. `MMDetection`
   很适合做检测、实例分割、训练配置、推理与评测这一层的工程 baseline。

2. `Detectron2`
   很适合做“成熟框架 baseline 对照”，帮助学生理解“自己实现”和“工业级训练框架”之间的差异。

3. `D2L 视觉章节`
   适合做最小可运行 baseline，不适合当唯一课程主线。

### 老师版重构建议

- `HW01`：kNN 与线性分类器公平对照
- `HW02`：两层网络与反向传播
- `HW03`：CNN from scratch 与 PyTorch CNN
- `HW04`：迁移学习与误差分析
- `HW05`：检测或分割最小工程包
- `HW06`：开放题 project，要求 proposal / milestone / report

### 老师该给什么

- 固定数据版本与最小数据子集
- 分类 / 检测统一评测脚本
- baseline 记录位
- 误差分析模板
- 课程项目的 proposal / milestone / final report 模板

### 学生自己做什么

- 具体实验设计
- 数据增强、训练细节与对照实验
- 最终模型与结论

## 2. NLP 全栈

### 课程主线源

1. `Stanford CS224N`
   最适合做 NLP 主线。它的顺序天然适合老师版重构：词向量 → 依存分析 / 序列建模 → 注意力 / NMT → Transformer / 预训练。

2. `Hugging Face Course`
   更适合作为 Lab，不适合替代 CS224N 的课程骨架。

### 工程作业源 / baseline 源

1. `transformers/examples`
   很适合当微调、训练脚本和评测脚本的 baseline 源。

2. `sentence-transformers`
   很适合做语义检索、文本匹配和向量检索这一类专题实验。

3. `Hugging Face Course`
   适合作为 tokenizer、dataset、trainer、evaluation 的工程补丁。

### 老师版重构建议

- `HW01`：Word2Vec / GloVe 与词相似度评测
- `HW02`：文本分类，majority / TF-IDF / 线性模型 / 小型神经网络公平对照
- `HW03`：序列标注或依存分析
- `HW04`：Seq2Seq / Attention / NMT 最小闭环
- `HW05`：Transformer / MinBERT 最小实现
- `HW06`：检索、问答或文档分类的专题 project

### 老师该给什么

- 数据清洗约束
- 训练 / 验证 / 测试切分协议
- majority / TF-IDF / BM25 的 baseline 位
- 错误分类模板
- report 与 rubric

### 学生自己做什么

- 模型选择与调参
- 数据特征工程
- 最终实验和误差解释

## 3. 计算机组成原理

### 课程主线源

1. `Nand2Tetris`
   这是最标准、最强、最适合“真实作业包”思路的一门。它不是几份松散作业，而是天然的项目链：门电路 → ALU / Memory → CPU → 汇编器 → VM → 编译器。

### 工程作业源 / baseline 源

1. `Nand2Tetris 官方 tools / projects`
   这是最核心的测试、starter 与运行工具来源。

2. `n2t-ide`
   适合作为更现代的工具链参考，帮助后续做本地化运行与 grading。

### 老师版重构建议

- `HW01`：Boolean Logic
- `HW02`：Boolean Arithmetic
- `HW03`：Sequential Logic / Memory
- `HW04`：Machine Language
- `HW05`：Computer Architecture
- `HW06`：Assembler
- `HW07`：VM I
- `HW08`：VM II
- 进阶再接 Compiler / OS

### 老师该给什么

- 分层测试说明
- 每一层最小通过标准
- 常见故障定位指引
- 提交文件结构
- grader notes

### 学生自己做什么

- HDL / Assembler / VM Translator 具体实现
- 调试
- 边界测试补充

## 4. 强化学习

### 课程主线源

1. `OpenAI Spinning Up`
   很适合做老师版开源自学主线：理论、算法、最小实现和实验输出都比较清楚。

2. `Berkeley CS188 Projects`
   更适合做离散环境题型源与问题设计参考，不一定要直接当唯一工程主线。

### 工程作业源 / baseline 源

1. `Stable-Baselines3`
   最适合做成熟 baseline，对照学生自己实现的 PPO / DQN。

2. `CleanRL`
   最适合做“短实现、可读实现、单文件实现”的 baseline 参考。

3. `Gymnasium`
   适合作为环境接口与最小实验协议层。

### 老师版重构建议

- `HW01`：Bandit / MDP / 动态规划
- `HW02`：Q-Learning 与表格法
- `HW03`：DQN 最小实现
- `HW04`：Policy Gradient
- `HW05`：Actor-Critic / PPO
- `HW06`：多随机种子 + 样本效率 + baseline 公平对照 project

### 老师该给什么

- 固定环境版本
- 固定随机种子协议
- 统一日志与评测脚本
- baseline 对照口径
- 学习曲线 / 方差 / 样本效率报告模板

### 学生自己做什么

- 算法实现
- 超参数调整
- 最终比较实验

## 🧱 统一重构原则

不管扩哪门课，都继续沿用你现在已经在机器学习和量化金融里跑出来的标准：

1. 先找一个 **唯一课程主线**，不要把资源列表当课程。
2. 再选 1-3 个 **工程作业源 / baseline 源**，只负责补实验链路，不负责决定顺序。
3. 老师只给：
   - README
   - 布置时机
   - 前置知识
   - 教学目标
   - 数据 / 环境契约
   - starter
   - smoke test
   - rubric
   - FAQ
   - submission checklist
   - milestones
   - grader notes
4. 学生自己做：
   - 具体实验
   - 调参
   - 误差分析
   - 最终实现与结论

## 🚦推荐推进顺序

如果下一步要真正开始做“下一门样板课”，建议顺序是：

1. `05-计算机视觉`
2. `08-NLP全栈`
3. `11-计算机组成原理`
4. `13-强化学习`

原因很简单：

- 视觉和 NLP 最像“李宏毅 ML / 量化金融”这种连续 HW 体系；
- 组成原理最适合做“项目型作业包”；
- 强化学习更适合在前面三门样板课稳定后，再把实验协议做严。
