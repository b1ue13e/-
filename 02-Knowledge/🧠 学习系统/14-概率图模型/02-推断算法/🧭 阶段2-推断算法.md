## 🎯 模块 1：精确推断

> **为什么现在学**：先掌握"可精确计算"的方法，理解树宽如何决定可行性；它是理解近似推断的基准。
> **学完能做什么**：手算小图边缘/条件概率；对树/小树宽模型做精确推断。

| 主题 | 核心内容 | 状态 | 笔记 |
|:---|:---|:---:|:---|
| **变量消去** | 因子运算、消去顺序、树宽 | ✅ | [[概率图模型-变量消去]] |
| **和积算法与消息传递** | 树上 BP、收集-分发、最大积 | ✅ | [[概率图模型-和积算法与消息传递]] |
| **联结树算法** | 三角化、运行相交性、全局一致 | ✅ | [[概率图模型-联结树算法]] |

### 🎯 模块 1 检查点
- [ ] 能手算简单图的变量消去过程
- [ ] 理解信念传播在树上的正确性
- [ ] 能构建给定图的联结树并算树宽
- [ ] 掌握最大积算法求 MAP（Viterbi 框架）

## 🔄 模块 2：采样推断（MCMC）

> **为什么现在学**：精确推断在大树宽下失效；采样用随机样本近似分布，适用任何规模。
> **学完能做什么**：实现 Gibbs/MH 采样器，做收敛诊断（$\hat R$/ESS），选择适合问题的 MCMC 变体。

| 主题 | 核心内容 | 状态 | 笔记 |
|:---|:---|:---:|:---|
| **基本采样方法** | 直接采样、拒绝采样、似然加权 | ✅ | [[概率图模型-基本采样方法]] |
| **Gibbs与MH采样** | MCMC 核心、详细平衡、Gibbs=MH 特例 | ✅ | [[概率图模型-Gibbs与MH采样]] |
| **MCMC收敛与诊断** | burn-in、自相关、ESS、Gelman-Rubin | ✅ | [[概率图模型-MCMC收敛与诊断]] |
| **高级MCMC** | HMC、NUTS、Swendsen-Wang | ✅ | [[概率图模型-高级MCMC]] |

### 🎯 模块 2 检查点
- [ ] 能实现 Gibbs 采样器（如 Ising 模型）
- [ ] 能诊断 MCMC 链的收敛性（$\hat R < 1.05$）
- [ ] 理解混合时间对采样效率的影响
- [ ] 会用 PyMC/NumPyro 进行概率编程

## 📐 模块 3：变分推断

> **为什么现在学**：采样慢；变分把推断变优化，适合大规模/可微分场景。
> **学完能做什么**：推导 ELBO，实现 CAVI，理解 SVI/BBVI 与变分族扩展。

| 主题 | 核心内容 | 状态 | 笔记 |
|:---|:---|:---:|:---|
| **KL散度** | 定义、非负性、两种方向、与 ELBO 关系 | ✅ | [[概率图模型-KL散度]] |
| **变分推断与 ELBO** | ELBO 双推导、平均场、重参数化 | ✅ | [[概率图模型-变分推断与ELBO]] |
| **变分推断算法** | CAVI、SVI（自然梯度）、BBVI | ✅ | [[概率图模型-变分推断算法]] |
| **结构化变分与正规流** | 平均场局限、结构化族、flow 变换 | ✅ | [[概率图模型-结构化变分与正规流]] |

### 🎯 模块 3 检查点
- [ ] 能推导简单模型的 ELBO
- [ ] 实现坐标上升变分推断（CAVI）
- [ ] 理解平均场假设的优缺点
- [ ] 会比较 VI 和 MCMC 的适用场景
