# 概率图模型-结构化变分与正规流

> 平均场变分族（完全分解）计算简单但**忽略变量间相关性**，导致后验方差被低估。本卡介绍两条提升变分族表达力的路线：**结构化变分**（保留部分依赖结构，如树/链）与**正规流**（用可逆变换把简单分布"推"成灵活分布）。两者都是"变分族设计"的主题。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：平均场假设 $q(\mathbf{z}) = \prod_i q_i(z_i)$ 假设变量完全独立——但真实后验里变量往往强相关。后果：①低估方差（过自信）；②错过相关结构导致 ELBO 上界差。我们需要**更灵活但依然可优化**的变分族。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：变分族的表达能力决定 VI 近似质量；结构化 VI 用于时间序列（链结构）、空间模型（图结构）；正规流是现代深度生成模型（VAE 的 flow 变体、基于流的生成模型）的核心。
- **实际应用场景**：状态空间模型的结构化变分、图像生成（RealNVP/Glow）、密度估计。
- **高频考点**：平均场的局限、结构化变分的条件、正规流的可逆性与 Jacobian、ELBO 中的对数 det。

## 4. 定义与核心公式

### 4.1 平均场及其局限（回顾）

**平均场变分族**：$q(\mathbf{z}) = \prod_i q_i(z_i)$。

**局限**：$q$ 中变量独立 ⇒ 协方差为 0。若后验中 $z_i, z_j$ 强相关，平均场 $q$ 只能"取一个折中"，低估方差、可能丢失模式。

### 4.2 结构化变分族（Structured VI）

**定义**：$q$ 保留**部分依赖结构**，如链式 $q(\mathbf{z}) = \prod_t q(z_t \mid z_{t-1})$（状态空间模型）或树上 $q$（用树上消息参数化）。

**优化**：$q$ 的 ELBO 优化可以用**消息传递**（在 $q$ 的结构上运行 BP 更新因子），把"CAVI 的坐标更新"替换为"结构化因子的 BP 更新"。复杂度由 $q$ 的树宽决定（比完整后验低，但比平均场高）。

**优点**：保留关键相关性，方差估计更准；**代价**：优化更复杂、计算更贵。

### 4.3 正规流（Normalizing Flows）

**定义**：用**可逆、可微**变换 $f = f_K \circ \cdots \circ f_1$ 把基础分布 $q_0(\mathbf{u})$ 映射为 $q_K(\mathbf{z})$：

$$\mathbf{z} = f(\mathbf{u}), \qquad q_K(\mathbf{z}) = q_0(\mathbf{u}) \left|\det \frac{\partial f^{-1}}{\partial \mathbf{z}}\right| = q_0(f^{-1}(\mathbf{z})) \left|\det \frac{\partial f}{\partial \mathbf{u}}\right|^{-1}$$

**ELBO 中的对数 det**：
$$\log q_K(\mathbf{z}) = \log q_0(\mathbf{u}) - \sum_{k=1}^{K} \log\left|\det \frac{\partial f_k}{\partial \mathbf{u}_{k-1}}\right|$$

**计算关键**：选择**三角/耦合**结构的变换使 Jacobian 行列式 $O(d)$ 可算（如耦合层：一半变量线性变换、另一半加平移缩放，det 为对角乘积）。

**常见流**：RealNVP（耦合层）、Planar Flow（$\mathbf{z} = \mathbf{u} + \mathbf{w} h(\mathbf{b}^\top\mathbf{u} + c)$）、Spline Flow。

---

## 5. 关键推导

**推导：平均场低估方差（直觉 + 示例）**。

二元高斯后验相关 $\rho = 0.9$，方差 1。平均场 $q(z_1)q(z_2)$：最优 $q_i$ 是条件后验的平均化，$q(z_1)$ 方差 $= 1 - \rho^2 = 0.19 < 1$——**方差被低估**。且 ELBO 中丢失了相关性信息（KL 惩罚缺失的协方差结构）。∎

**推导：正规流对数密度公式**。

变量替换定理：$q_K(\mathbf{z}) = q_0(f^{-1}(\mathbf{z}))|\det J_{f^{-1}}|$；$J_{f^{-1}} = (J_f)^{-1}$，$\det$ 取倒数。取对数即得 $\log q_K = \log q_0 - \log|\det J_f|$。复合变换时 Jacobian 相乘，对数相加。∎

**推导：耦合层 det 为什么便宜**。

耦合层：$\mathbf{u}_{1:d}$ 原样，$\mathbf{u}_{d+1:D} = \mathbf{u}_{d+1:D} \cdot \exp(s(\mathbf{u}_{1:d})) + t(\mathbf{u}_{1:d})$。Jacobian 是**下三角**（后半依赖前半），det = 对角乘积 $= \prod \exp(s_i)$，$O(d)$ 计算。∎

---

## 6. 最小可手算例子

**例（Planar Flow 一维手算）**：$f(u) = u + 2\tanh(u)$，$q_0 = \mathcal{N}(0,1)$。
- $\frac{df}{du} = 1 + 2\text{sech}^2(u)$；
- $\log q_K(f(u)) = \log q_0(u) - \log|1 + 2\text{sech}^2(u)|$；
- 基础高斯经 tanh 挤压后变成**双峰/变形**分布——单层流即可偏离高斯形状。

**例（结构化 VI 直觉）**：HMM 后验（状态序列相关）。平均场：$q(s_t)$ 各时刻独立——丢失相邻状态相关；结构化：$q(\mathbf{s}) = q(s_1)\prod q(s_t\mid s_{t-1})$——保留马尔可夫链结构，优化用前向-后向算法。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| 流越多越好 | **不精确**。更深的流表达力更强但训练更难（梯度消失/爆炸），且需更多数据 |
| 平均场总能抓到多峰 | **错**。平均场是单峰（或其分解），多峰后验下只能锁一个峰（见 KL 卡） |
| 结构化 VI = 平均场加边 | **近似**。结构化族保留依赖，但优化方法（BP/前向后向）与平均场（坐标上升）本质不同 |
| 正规流的变换必须全局可逆 | **对**。每个 $f_k$ 必须可逆；耦合/三角结构保证 |
| 流适合所有变分问题 | **不精确**。流的 ELBO 有额外 $\log\det$ 项，训练方差更高；简单后验平均场足够 |

4. 举例：HMM 后验用结构化变分（链）与平均场的差异。

### #自测题/较难
5. 推导：二元高斯后验（$\rho=0.9$）下平均场最优 $q$ 的方差为什么是 $1-\rho^2$。

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. 完全分解 $q = \prod q_i$；忽略相关性、低估方差。
2. $q_K(\mathbf{z}) = q_0(\mathbf{u})|\det J_f|^{-1}$，$\log q_K = \log q_0 - \log|\det J_f|$。
3. 耦合层 Jacobian 下三角，det = 对角乘积 $\prod \exp(s_i)$，$O(d)$。
4. 平均场：$q(s_t)$ 独立，丢失时序依赖；结构化：$q(\mathbf{s}) = q(s_1)\prod q(s_t\mid s_{t-1})$，用前向-后向更新，保留相邻相关。
5. 固定 $q(z_2)$，最优 $q(z_1) \propto \exp(\mathbb{E}_{q(z_2)}[\log p(z_1,z_2)])$；对高斯后验，这等于条件分布 $p(z_1\mid z_2)$ 在 $z_2$ 均值处的形式，方差 $= 1 - \rho^2$（条件方差），小于边缘方差 1。
</details>
