# 概率图模型-基本采样方法

> 本卡介绍**最简单的三类采样推断**：直接采样（无证据时按联合分布抽样）、拒绝采样（有证据时筛掉不合样本）、似然加权（用权重修复拒绝采样的浪费）。它们是理解 MCMC（阶段 2 下一张）的起点，也是蒙特卡洛推断的第一课。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：精确推断（VE/联结树）在树宽大时指数级爆炸，无法计算 $P(\mathbf{Q} \mid \mathbf{e})$。**采样推断**用随机样本近似分布：从模型采样大量样本，用样本频率估计概率。基本采样方法简单直观，但（拒绝采样）在高维或证据稀有时效率极低——这为 MCMC 和变分推断埋下动机。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：直接采样是"从联合分布抽样"的黄金标准（如果可行）；拒绝采样揭示"证据稀有"的致命问题；似然加权在两者之间折中。三者共有的缺点（高维低效）是 MCMC（Gibbs/MH）的改进动机。
- **实际应用场景**：贝叶斯网络无证据模拟、蒙特卡洛估计期望、作为复杂算法（如粒子滤波）的组件。
- **高频考点**：采样-估计流程、拒绝采样接受率、似然权重计算、估计的方差来源。

---

## 3. 学它之前需要哪些前置知识？

1. **[[概率图模型-因子分解]]**：BN 的链式分解 $P(\mathbf{X}) = \prod P(X_i \mid \text{Pa}(X_i))$。
2. **[[概率图模型-联合分布与链式法则]]**：边际化与条件概率。
3. 概率基础：大数定律（样本频率收敛到概率）、期望。

---

## 4. 定义与核心公式

### 4.1 直接采样（Forward / Ancestral Sampling）

**算法**（对 BN）：
1. 按**拓扑序**处理每个节点 $X_i$；
2. 从 $P(X_i \mid \text{Pa}(X_i) = \text{已采样父值})$ 采样一个值；
3. 重复得完整样本 $\mathbf{x}^{(1)}, \dots, \mathbf{x}^{(N)}$。

**性质**：样本 $\mathbf{x}^{(t)} \sim P(\mathbf{X})$（服从真实联合分布）。任意边缘可用样本频率估计：$\hat{P}(X_i = a) \approx \frac{1}{N}\sum_t \mathbb{1}[x_i^{(t)} = a]$。

**限制**：**无法处理证据**——若想估计 $P(\mathbf{Q} \mid \mathbf{e})$，直接采样产生的样本里恰好匹配 $\mathbf{e}$ 的极少（证据概率低时几乎为 0）。

### 4.2 拒绝采样（Rejection Sampling）

**算法**：
1. 从 $P(\mathbf{X})$ 直接采样（无条件）得 $\mathbf{x}^{(t)}$；
2. 若 $\mathbf{x}^{(t)}$ 与证据 $\mathbf{e}$ 一致则**接受**，否则**拒绝**；
3. 用接受样本估计 $P(\mathbf{Q} \mid \mathbf{e}) \approx \frac{\text{接受样本中 } Q \text{ 取值频率}}{\text{接受样本数}}$。

**接受率** = $P(\mathbf{e})$。证据越稀有（$P(\mathbf{e})$ 越小），接受率越低，浪费越严重。高维时 $P(\mathbf{e})$ 指数级小，拒绝采样**不可用**。

### 4.3 似然加权（Likelihood Weighting）

**算法**：
1. 按拓扑序采样**非证据**变量；
2. 对**证据变量**不采样，直接把其取值代入，并累乘条件概率得**权重** $w^{(t)} = \prod_{e_j \in \mathbf{e}} P(e_j \mid \text{Pa}(e_j))$；
3. 用**加权样本**估计：
$$\hat{P}(\mathbf{Q} = \mathbf{q} \mid \mathbf{e}) \approx \frac{\sum_t w^{(t)} \mathbb{1}[\mathbf{q}^{(t)} = \mathbf{q}]}{\sum_t w^{(t)}}$$

**优点**：每个样本都被使用（无拒绝浪费），证据值被"硬编码"进权重。
**局限**：证据节点**越多**，权重越偏斜（方差大）；证据在**父节点**时效果好，在**后代**时权重集中于少数样本（本质仍未摆脱高维低效）。

---

## 5. 关键推导

**推导：似然加权估计量的无偏性**。

设非证据变量 $\mathbf{Z}$，采样分布 $q(\mathbf{z}) = \prod_{z_i \notin \mathbf{e}} P(z_i \mid \text{pa}_i)$，权重 $w = \prod_{e_j \in \mathbf{e}} P(e_j \mid \text{pa}_j)$。
则 $q(\mathbf{z}) w = \prod_i P(z_i \mid \text{pa}_i)$（含证据项）= $P(\mathbf{z}, \mathbf{e})$（链式分解）。
因此 $\mathbb{E}_q[\mathbb{1}(\mathbf{q})\, w] = \sum_{\mathbf{z}} q(\mathbf{z}) w \mathbb{1}(\mathbf{q}) = \sum_{\mathbf{z}} P(\mathbf{z},\mathbf{e})\mathbb{1}(\mathbf{q}) = P(\mathbf{q}, \mathbf{e})$。
同理 $\mathbb{E}_q[w] = P(\mathbf{e})$，两者之比 $\to P(\mathbf{q} \mid \mathbf{e})$（大数定律）。∎

**推导：拒绝采样估计也是正确的**。
接受事件 = $\mathbf{x} = \mathbf{e}$（概率 $P(\mathbf{e})$）；接受条件下 $\mathbf{Q}$ 的分布即 $P(\mathbf{Q} \mid \mathbf{e})$（条件概率定义）。∎

---

## 6. 最小可手算例子

**例**：BN $A \to B$，$A$ 二值 $P(A{=}1)=0.5$，$P(B{=}1\mid A{=}1)=0.9$，$P(B{=}1\mid A{=}0)=0.1$。证据 $B{=}1$，求 $P(A{=}1\mid B{=}1)$。

**精确**：$P(A{=}1,B{=}1) = 0.5\times0.9 = 0.45$；$P(B{=}1) = 0.45 + 0.05 = 0.5$；$P(A{=}1\mid B{=}1) = 0.9$。

**直接采样**：采样 $(A,B)$ 对，$B{=}1$ 的样本占比 ~50%，从中 $A{=}1$ 占比 ~90% → 估计 $\approx 0.9$。

**拒绝采样**：采样 1000 对，约 500 对 $B{=}1$ 被接受（接受率 0.5）；接受样本中 $A{=}1$ 约 450 → $0.9$。

**似然加权**：对 $A$ 采样（$B$ 是证据），$A{=}1$ 样本权重 $w = P(B{=}1\mid A{=}1) = 0.9$，$A{=}0$ 样本权重 $0.1$。若 500 个 $A{=}1$、500 个 $A{=}0$：$\hat P(A{=}1) = \frac{500\times0.9}{500\times0.9+500\times0.1} = \frac{450}{500} = 0.9$ ✓。**注意**：本例证据是后代，似然加权权重无偏但方差偏高；若证据是父节点（如 $A{=}1$），权重恒为 1 效果最好。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| 直接采样可以处理证据 | **错**。直接采样只产出无证据样本；匹配证据的样本极少，无法条件估计 |
| 拒绝采样在高维下依然实用 | **错**。接受率 $=P(\mathbf{e})$ 随维数指数级下降，几乎全部被拒绝 |
| 似然加权完全解决证据问题 | **部分错**。它消除了"拒绝浪费"，但权重方差随证据数量/位置恶化，估计仍可能不稳定 |
| 采样数越多越准，无代价 | **错**。方差以 $1/\sqrt{N}$ 收敛，需要 $4\times$ 样本才能标准差减半；高维仍不足 |
| 权重 = 样本概率 | **错**。权重是**证据变量的条件概率乘积**，不是样本的联合概率 |

### #自测题/较难
5. 证明似然加权估计量的期望正确性（写出 $q(\mathbf{z})w = P(\mathbf{z},\mathbf{e})$ 的推导）。

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. 按拓扑序从 $P(X_i\mid pa_i)$ 采样；因链式分解 $=\prod P(X_i\mid pa_i)$，样本服从联合分布。
2. $P(\mathbf{e})$（证据的边缘概率）。
3. $P(A{=}0\mid B{=}1) = \frac{0.05}{0.5} = 0.1$（对称于上例）。
4. $P(\mathbf{e})$ 是多个低概率事件的乘积，随证据数量指数级衰减；接受样本数 $\approx N\cdot P(\mathbf{e}) \to 0$。
5. 见 §5 推导：$q(\mathbf{z}) = \prod_{z\notin e}P(z\mid pa)$，$w=\prod_{e}P(e\mid pa)$，乘积 = 全链式分解 = $P(\mathbf{z},\mathbf{e})$。
