# 概率图模型-变分推断算法

> 本卡讲解变分推断的**三大算法实现**：坐标上升（CAVI）、随机变分推断（SVI）、黑盒变分推断（BBVI）。它们解决同一个问题——在平均场/可分解变分族下最大化 ELBO——但更新方式与适用场景不同。基础理论见 [[概率图模型-变分推断与ELBO]]。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：有了 ELBO 目标（最大化 $\mathcal{L}(q) = \mathbb{E}_q[\log p(\mathbf{x},\mathbf{z})] - \mathbb{E}_q[\log q(\mathbf{z})]$），怎么**实际优化**它？平均场假设下 ELBO 关于每个因子 $q_i$ 有闭式最优，但全局耦合、且大数据下全量迭代昂贵。CAVI/SVI/BBVI 给出三条优化路线。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：CAVI 是 LDA 主题模型的经典求解（原论文的变分 EM）；SVI 让 VI 扩展到千万级文档；BBVI 用自动微分把 VI 变成"黑盒"，催生 Pyro/NumPyro 的自动变分。
- **实际应用场景**：LDA、混合模型、贝叶斯神经网络、VAE 训练（BBVI 的重参数化是其特例）。
- **高频考点**：CAVI 坐标更新推导、SVI 的自然梯度、BBVI 的梯度估计（评分函数/重参数化）。

## 4. 定义与核心公式

### 4.1 平均场变分族（回顾）

**假设**：$q(\mathbf{z}) = \prod_i q_i(z_i)$（完全分解）。ELBO 分解为：
$$\mathcal{L}(q) = \sum_i \mathbb{E}_{q_i}[\mathbb{E}_{q_{-i}}[\log p(\mathbf{z}_i \mid \mathbf{z}_{-i}, \mathbf{x})]] - \sum_i \mathbb{E}_{q_i}[\log q_i(z_i)] + \text{const}$$

### 4.2 CAVI（坐标上升变分推断）

**更新规则（关键公式）**：
$$q_i^*(z_i) \propto \exp\left( \mathbb{E}_{q_{-i}}[\log p(z_i \mid \mathbf{z}_{-i}, \mathbf{x})] \right)$$

即：第 $i$ 个因子的最优分布正比于"其余因子期望下的条件对数概率"的指数。

**算法**：
1. 初始化所有 $q_i$；
2. 循环：对每个 $i$，按上式更新 $q_i$（用最新 $q_{-i}$）；
3. 直到 ELBO 收敛（单调不降）。

**收敛性**：ELBO 关于每个 $q_i$ 是凸的，坐标上升保证**单调收敛到局部最优**（平均场目标一般非凸，不保证全局）。

### 4.3 SVI（随机变分推断）

**问题**：CAVI 每轮要扫全部数据（LDA 的文档数），大数据不可行。

**思路**：用**随机优化** + **自然梯度**：
- 每次采样一个小批量数据，估计 ELBO 梯度的噪声版本；
- **自然梯度**（对指数族）：$\hat\nabla_\lambda \mathcal{L} = \lambda - \hat\lambda_{\text{全局}}$（把期望替换为小批量估计的"目标自然参数"）；
- 更新：$\lambda \leftarrow (1-\rho_t)\lambda + \rho_t \hat\lambda_{\text{全局}}$，步长 $\rho_t$ 满足 Robbins-Monro（$\sum\rho_t = \infty$，$\sum\rho_t^2 < \infty$）。

**优点**：可扩展海量数据；**收敛**：随机近似下几乎必然收敛到局部最优。

### 4.4 BBVI（黑盒变分推断）

**问题**：CAVI/SVI 需要**模型特定的**期望推导；每换一个模型要重推。

**思路**：把 ELBO 梯度写成可自动估计的形式（$\nabla_\lambda \mathcal{L} = \mathbb{E}_q[\nabla_\lambda \log q_\lambda(\mathbf{z}) \cdot (\log p(\mathbf{x},\mathbf{z}) - \log q_\lambda(\mathbf{z}))]$，**评分函数估计**），用蒙特卡洛 + 自动微分计算，无需手工推导：

$$\nabla_\lambda \mathcal{L} \approx \frac{1}{S}\sum_{s=1}^{S} \nabla_\lambda \log q_\lambda(\mathbf{z}^{(s)}) \left( \log\frac{p(\mathbf{x},\mathbf{z}^{(s)})}{q_\lambda(\mathbf{z}^{(s)})} \right)$$

**改进（重参数化）**：若 $q_\lambda$ 可写成 $\mathbf{z} = g_\lambda(\epsilon)$（如高斯 $\mathbf{z} = \mu + \sigma\epsilon$），则 $\nabla_\lambda \mathcal{L} = \mathbb{E}_\epsilon[\nabla_\lambda \log p(\mathbf{x}, g_\lambda(\epsilon)) - \nabla_\lambda \log q_\lambda(g_\lambda(\epsilon))]$——方差远小于评分函数（VAE 的标准做法）。

**优点**：模型无关（黑盒），Pyro/NumPyro `AutoNormal` 即此实现。

---

## 5. 关键推导

**推导：CAVI 更新公式的来源（对 ELBO 关于 $q_i$ 求变分）**。

固定 $q_{-i}$，ELBO 中与 $q_i$ 相关的部分：$\mathbb{E}_{q_i}[\mathbb{E}_{q_{-i}}[\log p(z_i\mid\mathbf{z}_{-i},\mathbf{x})]] - \mathbb{E}_{q_i}[\log q_i(z_i)] = -\text{KL}(q_i \parallel q_i^*)$（$q_i^*$ 如公式）。KL 非负，取 $q_i = q_i^*$ 时为零 → 最大化。∎

**推导：SVI 用自然梯度的原因**。

欧氏梯度在参数重参数化下不稳定；自然梯度 = $F^{-1}\nabla_\theta$（$F$ 为 Fisher 信息矩阵）。对指数族，Fisher 矩阵 = $\nabla^2_\lambda A(\lambda)$，且自然梯度更新退化为 $\lambda \leftarrow \lambda + \rho(\lambda_{\text{opt}} - \lambda)$——不需要显式矩阵求逆，这就是 SVI 高效且与参数化无关的原因。∎

**推导：BBVI 评分函数估计的无偏性**。

$\nabla_\lambda \mathbb{E}_q[f] = \int f \nabla_\lambda q_\lambda dz = \int f\, q_\lambda \nabla_\lambda \log q_\lambda\, dz = \mathbb{E}_q[f \nabla_\lambda \log q_\lambda]$（用 $\nabla q = q\nabla\log q$ 与交换积分微分条件）。∎

---

## 6. 最小可手算例子

**例（CAVI 手算，伯努利-高斯混合简化）**：单隐变量 $z \in \{0,1\}$，$p(z)$ 均匀，$p(x\mid z{=}1) = \mathcal{N}(1,1)$，$p(x\mid z{=}0)=\mathcal{N}(-1,1)$，观测 $x = 0.5$。求 $q(z)$。

$\log q(z{=}1) \propto \log p(z{=}1) + \log p(x{=}0.5\mid z{=}1) = \log0.5 + \log\mathcal{N}(0.5;1,1) = -0.693 - 0.625 = -1.318$；
$\log q(z{=}0) \propto -0.693 + \log\mathcal{N}(0.5;-1,1) = -0.693 - 1.125 = -1.818$；
归一化：$q(z{=}1) = \frac{e^{-1.318}}{e^{-1.318}+e^{-1.818}} = \frac{0.268}{0.268+0.162} \approx 0.62$。一轮 CAVI 即得（本例无耦合）。

**例（SVI 直觉）**：LDA 中每次取一批文档，估计主题-词分布的自然参数 $\hat\beta$，再 $\beta \leftarrow (1-\rho)\beta + \rho\hat\beta$。

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| CAVI 保证全局最优 | **错**。平均场目标非凸，坐标上升只保证局部最优（ELBO 单调不降） |
| SVI 比 CAVI 更准 | **不精确**。SVI 用噪声梯度，收敛到相同局部最优的**分布**；为速度牺牲确定性 |
| BBVI 无需任何推导 | **部分对**。评分函数/重参数化本身要选对；重参数化通常方差远小于评分函数 |
| 平均场假设总够用 | **错**。完全分解忽略后验相关性，会低估方差（见 [[概率图模型-结构化变分与正规流]] 的扩展） |
| ELBO 单调即可停 | **近似对**。要同时检查 $\hat R$（对随机优化）或收敛准则；噪声梯度下 ELBO 本身也在波动 |

### #自测题/较难
5. 对比评分函数与重参数化梯度估计的方差差异，解释 VAE 为何用重参数化。

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. $q_i^*(z_i) \propto \exp(\mathbb{E}_{q_{-i}}[\log p(z_i\mid z_{-i},x)])$。
2. 大数据下全量扫描昂贵；SVI 用小批量 + 自然梯度，扩展到海量数据。
3. ELBO 关于 $q_i$ 的可变部分 = $-\text{KL}(q_i \parallel q_i^*) + \text{const}$；KL ≥ 0 且取 $q_i = q_i^*$ 时最小。
4. 用恒等式 $\nabla q = q\nabla\log q$ 把 $\nabla\mathbb{E}_q[f]$ 变为 $\mathbb{E}_q[f\nabla\log q]$（见 §5 推导）。
5. 评分函数方差随 $f$ 波动大（与 $f$ 值尺度相关）；重参数化把噪声从分布搬到 $\epsilon$，梯度穿过确定性变换，方差显著更低（VAE 稳定训练依赖此）。
</details>
