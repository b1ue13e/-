# 概率图模型-标准化流与概率编程

> 本卡收口两件事：**标准化流（Normalizing Flow）**——用可逆变换构建灵活分布（基于流的生成模型的基础）；**概率编程**（PyMC/NumPyro/Pyro/Stan/TFP）——把"写模型、自动推断"工程化。两者共同代表 PGM 的现代工具生态。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：①平均场/高斯变分族太简单，需要更灵活的后验近似 → **流**用可逆变换把简单分布"推"成任意形状；②手写每个模型的推断算法太麻烦 → **概率编程**让你只声明模型，自动选择 NUTS/SVI 推断。本卡把阶段 2 的理论与阶段 6 的工具衔接。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：流是 VAE/变分推断的表达力升级（[[概率图模型-结构化变分与正规流]] 的深入）；概率编程是 PGM 推断的"生产级"封装（NUTS 默认）。
- **实际应用场景**：密度估计、flexible 变分推断、贝叶斯建模（PyMC 生态）。
- **高频考点**：流密度公式、耦合层 det、概率编程的声明式建模与自动推断。

## 4. 定义与核心公式

### 4.1 标准化流（回顾 + 深入）

**定义**：$\mathbf{z} = f(\mathbf{u})$（$f$ 可逆可微），$q_K(\mathbf{z}) = q_0(\mathbf{u})|\det J_f|^{-1}$。

**耦合层（RealNVP）**：
$$\mathbf{u}_{1:d} = \mathbf{u}_{1:d}, \quad \mathbf{z}_{d+1:D} = \mathbf{u}_{d+1:D} \odot \exp(s(\mathbf{u}_{1:d})) + t(\mathbf{u}_{1:d})$$
Jacobian 下三角 → $\det = \prod \exp(s_i)$，$O(D)$ 可算。

**表达力**：多层耦合 + 可逆置换交替，可逼近任意可逆映射。

### 4.2 概率编程（Probabilistic Programming）

**范式**：声明模型（随机变量 + 依赖），引擎自动做推断。

| 工具 | 推断引擎 | 特点 |
|:---|:---|:---|
| **PyMC** | NUTS（默认）、SVI | 生态成熟，后端 Aesara |
| **NumPyro** | NUTS、SVI（重参数化） | JAX 后端，快、可微分 |
| **Pyro** | SVI、NUTS | 深度概率编程（VAE 友好） |
| **Stan** | HMC/NUTS（行业标准） | 强模型语言，诊断完备 |
| **TFP**（TensorFlow Probability） | HMC、VI | TF 生态 |

**声明式建模示例（PyMC）**：
```python
with pm.Model():
    mu = pm.Normal("mu", 0, 1)          # 先验
    sigma = pm.HalfNormal("sigma", 1)
    obs = pm.Normal("obs", mu, sigma, observed=data)  # 似然
    trace = pm.sample()                  # NUTS 自动推断
```
自动完成：后验采样（NUTS）、$\hat R$ 诊断、后验摘要。

## 5. 关键推导

**推导：流密度公式（变量替换）**。
$q_K(\mathbf{z}) = q_0(f^{-1}(\mathbf{z})) \cdot |\det J_{f^{-1}}(\mathbf{z})|$；$J_{f^{-1}} = J_f^{-1}$，$\det$ 取倒数 → $q_K = q_0|\det J_f|^{-1}$。复合时 Jacobian 相乘、对数相加。∎

**推导：耦合层 det 便宜**。
耦合层把后半变量写成前半的函数 → Jacobian 是**块下三角**（后半对前半有导数，前半对后半为 0），det = 对角块乘积 $= \prod_{i} \exp(s_i)$。∎

**推导：NUTS 为什么是"免调参" HMC**。
NUTS 用双平均自适应步长 $\epsilon$（目标接受率 ~0.8）+ 轨迹"不转弯"停止规则自适应轨迹长度——消除 HMC 的两个手动超参数（见 [[概率图模型-高级MCMC]]）。∎

---

## 6. 最小可手算例子

**例（耦合层手算）**：$\mathbf{u} = (u_1, u_2)$，$s(u_1) = u_1$，$t(u_1) = 0$，$d=1$。
$z_1 = u_1$，$z_2 = u_2 e^{u_1}$。
- $J = \begin{pmatrix}1 & 0\\ u_2 e^{u_1} & e^{u_1}\end{pmatrix}$，$\det = e^{u_1}$；
- $q(z) = q_0(u)e^{-u_1}$——单层耦合即可实现尺度依赖的扭曲。

**例（PyMC 自动推断）**：8 学校问题（经典分层模型），`pm.sample()` 输出 4 链 × 2000 样本、$\hat R < 1.01$——几分钟内完成"建模-采样-诊断"。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| 概率编程 = 自动解决一切 | **不精确**。仍需正确建模（先验/似然选择）、检查收敛、诊断 $\hat R$ |
| 流的 det 计算总是便宜 | **错**。只有三角/耦合结构才 $O(D)$；一般可逆网络 det 昂贵 |
| 流的层数越多越好 | **不精确**。深流训练难、可能数值不稳定 |
| NumPyro 与 PyMC 等价 | **近似**。后端不同（JAX vs Aesara），性能/生态有差异 |
| 概率编程只能采样 | **错**。也支持变分（SVI/ADVI） |
