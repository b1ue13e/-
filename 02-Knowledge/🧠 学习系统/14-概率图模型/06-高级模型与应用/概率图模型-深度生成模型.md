# 概率图模型-深度生成模型

> 本卡对比两类**深度生成模型**：**GAN**（对抗训练，隐式分布）与**扩散模型**（逐步加噪/去噪，显式变分目标）。它们与 VAE 并列为现代生成模型三大范式；扩散模型（DDPM）当前在图像生成质量上占优。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：VAE 生成样本模糊（高斯似然 + 平均场近似）；需要**更清晰的生成**。GAN 用"生成器 vs 判别器"对抗训练，隐式匹配数据分布；扩散模型把生成分解为"从噪声逐步去噪"，用变分目标显式训练。两者都在回答：如何让模型生成**逼真、多样**的新样本？

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：VAE/GAN/Flow/Diffusion 是生成模型四范式；扩散模型统治图像/音频生成（Stable Diffusion），GAN 用于风格迁移/超分。
- **实际应用场景**：文生图、图像修复、语音合成、数据增强。
- **高频考点**：GAN 的 min-max 目标、模式坍缩；扩散的前向/反向过程、训练目标（噪声预测）。

## 4. 定义与核心公式

### 4.1 GAN（生成对抗网络）

**结构**：生成器 $G_\theta$（噪声 $z \to$ 图像）+ 判别器 $D_\phi$（区分真/假）。

**min-max 目标**：
$$\min_G \max_D V(D, G) = \mathbb{E}_{\mathbf{x}\sim p_{\text{data}}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z}\sim p_z}[\log(1 - D(G(\mathbf{z})))]$$

**训练**：交替更新 $D$（最大化判别能力）与 $G$（最小化 $D$ 的判别能力）。**理论**：最优 $G$ 使 $p_G = p_{\text{data}}$（此时 $D \equiv 1/2$，$V = -\log 4$）。

**问题**：训练不稳定（对抗）、**模式坍缩**（$G$ 只生成少数模式）。

### 4.2 扩散模型（DDPM）

**前向过程（加噪）**：逐步加高斯噪声 $T$ 步：
$$q(\mathbf{x}_t \mid \mathbf{x}_{t-1}) = \mathcal{N}(\mathbf{x}_t; \sqrt{1-\beta_t}\mathbf{x}_{t-1}, \beta_t I)$$
（$\beta_t$ 为噪声调度；$T$ 大时 $\mathbf{x}_T \approx \mathcal{N}(0,I)$。）

**反向过程（去噪，生成）**：学习 $p_\theta(\mathbf{x}_{t-1}\mid\mathbf{x}_t) = \mathcal{N}(\mathbf{x}_{t-1}; \mu_\theta(\mathbf{x}_t, t), \Sigma_\theta(\mathbf{x}_t,t))$，从 $\mathbf{x}_T \sim \mathcal{N}(0,I)$ 逐步去噪到 $\mathbf{x}_0$。

**训练目标（简化版，噪声预测）**：
$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{t, \mathbf{x}_0, \epsilon}\left[\lVert \epsilon - \epsilon_\theta(\mathbf{x}_t, t)\rVert^2\right]$$
即：预测被加的噪声 $\epsilon$（等价于预测 $\mathbf{x}_0$）。目标来自变分下界的重参数化。

**性质**：训练稳定（无对抗）、模式覆盖好（对比 GAN）；采样慢（$T$ 步迭代，可用 DDIM 加速）。

---

## 5. 关键推导

**推导：GAN 最优判别器**。

对固定 $G$，$V(D,G) = \int p_{\text{data}}\log D + p_G\log(1-D) dx$。逐点对 $D$ 求导置零：$\frac{p_{\text{data}}}{D} - \frac{p_G}{1-D} = 0 \Rightarrow D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_G(x)}$。代入得 $V(D^*,G) = -\log 4 + 2\text{JSD}(p_{\text{data}}\parallel p_G)$——生成器最小化 JSD。∎

**推导：扩散训练目标来自 ELBO**。

$\log p_\theta(\mathbf{x}_0) \ge \mathbb{E}_q[\log p_\theta(\mathbf{x}_{0:T}) - \log q(\mathbf{x}_{1:T}\mid\mathbf{x}_0)]$（变分下界）。重参数化每步为"预测噪声"，各项化简为 $\lVert\epsilon - \epsilon_\theta\rVert^2$（忽略权重常数）。∎

**推导：前向过程单步可跳跃采样**。
由加噪定义，$q(\mathbf{x}_t\mid\mathbf{x}_0) = \mathcal{N}(\mathbf{x}_t; \sqrt{\bar\alpha_t}\mathbf{x}_0, (1-\bar\alpha_t)I)$（$\bar\alpha_t = \prod_{s\le t}(1-\beta_s)$）——训练时无需逐步加噪，直接跳一步。∎

---

## 6. 最小可手算例子

**例（GAN 目标手算）**：$p_{\text{data}}(0) = 0.7$，$p_G(0) = 0.3$（一点）。
$D^*(0) = \frac{0.7}{0.7+0.3} = 0.7$；$V = 0.7\log0.7 + 0.3\log0.3 = -0.250 + (-0.361) = -0.611$；$-\log4 = -1.386$，JSD > 0（分布不等）。$G$ 被推动向 $p_{\text{data}}$ 靠近。

**例（扩散噪声预测）**：$\mathbf{x}_0 = 1.0$，$t=1$ 步 $\beta = 0.2$（$\bar\alpha = 0.8$），加噪 $\mathbf{x}_1 = \sqrt{0.8}\times1.0 + \sqrt{0.2}\times\epsilon$；若实际 $\epsilon = 0.5$，模型预测 $\hat\epsilon$；损失 $\lVert 0.5 - \hat\epsilon\rVert^2$ 驱动模型学"去噪"。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| GAN 一定比 VAE 好 | **不精确**。GAN 清晰但模式坍缩/训练不稳；VAE 稳定但模糊 |
| 扩散模型采样很快 | **错**。$T$ 步迭代慢（需 DDIM/蒸馏加速） |
| 扩散是 GAN 的一种 | **错**。扩散是显式变分目标（无对抗），GAN 是隐式对抗 |
| 扩散模型不需要变分 | **错**。训练目标正是 ELBO 的重参数化 |
| 生成模型只有一种范式 | **错**。VAE/GAN/Flow/Diffusion 四范式，各有取舍 |

4. 写出扩散的简化训练损失并解释"预测噪声"。

### #自测题/较难
5. 对比 VAE/GAN/扩散的生成质量、训练稳定性与采样速度。

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. $\min_G\max_D \mathbb{E}_{data}[\log D] + \mathbb{E}_z[\log(1-D(G(z)))]$。
2. 前向：逐步加噪到纯噪声；反向：学去噪从噪声生成。
3. 见 §5 推导（逐点求导得 $D^* = \frac{p_{data}}{p_{data}+p_G}$）。
4. $\mathcal{L} = \mathbb{E}[\lVert\epsilon - \epsilon_\theta(x_t,t)\rVert^2]$；重参数化后预测噪声 = 预测 $x_0$ 的方向。
5. VAE：稳、模糊、快；GAN：清晰、不稳/坍缩、快；扩散：质量最高、最稳、慢。
