# 概率图模型-主题模型

> **主题模型**从文档集合中发现潜在主题：LSA（矩阵分解）、pLSA（概率版）、**LDA（贝叶斯版）**。LDA 是"文档-主题-词"的三层生成模型，用 Dirichlet 先验 + 变分 EM 求解，是文本分析的经典 PGM 应用。本卡覆盖从 LSA 到 LDA 的演进、生成过程、推断与扩展（DTM/HDP/SLDA/LDA2vec）。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：海量文档没有标注，如何自动发现"主题"（如体育/财经/科技）并给每篇文档分配主题比例、每个主题分配词分布？直观做法是词频统计，但词义多变（一词多义、同义）。主题模型假设**每篇文档 = 主题的混合，每个主题 = 词的分布**，用概率生成模型从数据反推这些隐藏结构。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：LDA 是变分 EM（[[概率图模型-变分EM]]）与指数族（[[概率图模型-指数族]]）的经典结合；它是无监督表征学习的文本版（对比 VAE 的图像版）。
- **实际应用场景**：文档聚类/检索、推荐系统（内容特征）、科研文献主题分析。
- **高频考点**：LDA 生成过程、变分推断更新、LSA/pLSA/LDA 演进、困惑度评价。

## 4. 定义与核心公式

### 4.1 演进：LSA → pLSA → LDA

| 模型 | 思想 | 缺陷 |
|:---|:---|:---|
| **LSA** | SVD 分解词-文档矩阵（$X = U\Sigma V^\top$），取低维"潜在语义" | 非概率、负值无解释 |
| **pLSA** | 概率化：$P(w\mid d) = \sum_k P(w\mid z_k)P(z_k\mid d)$ | 过拟合（文档参数随文档数增长）、无先验 |
| **LDA** | pLSA + Dirichlet 先验（贝叶斯化） | 推断需近似（变分/MCMC） |

### 4.2 LDA 生成过程

**参数**：$K$ 个主题；每主题-词分布 $\beta_k \sim \text{Dirichlet}(\eta)$；每文档-主题分布 $\theta_d \sim \text{Dirichlet}(\alpha)$。

**生成（对文档 $d$ 的 $N_d$ 个词）**：
1. 采样 $\theta_d \sim \text{Dirichlet}(\alpha)$（文档主题比例）；
2. 对每个词 $n$：
   - 采样主题 $z_{dn} \sim \text{Multinomial}(\theta_d)$；
   - 采样词 $w_{dn} \sim \text{Multinomial}(\beta_{z_{dn}})$。

**联合分布**：
$$P(\mathbf{w},\mathbf{z},\theta,\beta \mid \alpha,\eta) = \prod_d P(\theta_d\mid\alpha)\prod_n P(z_{dn}\mid\theta_d)P(w_{dn}\mid z_{dn},\beta) \cdot \prod_k P(\beta_k\mid\eta)$$

### 4.3 推断（变分 EM）

后验 $P(\theta,\mathbf{z},\beta\mid\mathbf{w})$ 不可解（词-主题耦合）→ 平均场近似 $q(\theta,\mathbf{z},\beta) = \prod_d q(\theta_d)\prod_{dn}q(z_{dn})\prod_k q(\beta_k)$。

**变分 E 步**（CAVI 更新）：
- $\phi_{dnk} \propto \exp(\mathbb{E}_q[\log\beta_{k,w_{dn}}] + \mathbb{E}_q[\log\theta_{dk}])$（词-主题责任）；
- $\gamma_{dk} = \alpha_k + \sum_n \phi_{dnk}$（文档-主题参数）；
- （$\beta$ 类似，全局。）

**M 步**：更新 $\beta_{kv} \propto \sum_{d,n}\phi_{dnk}\mathbb{1}[w_{dn}=v]$（软计数）。

**等价求解**：Gibbs 采样（另一路线）对 $z_{dn}$ 条件采样。

### 4.4 扩展

| 模型 | 扩展 |
|:---|:---|
| **SLDA** | 主题带监督标签（文档标签） |
| **DTM** | 主题随时间演化（动态主题模型） |
| **HDP** | 主题数自动确定（层次 Dirichlet 过程） |
| **LDA2vec** | 主题 + 词嵌入结合（深度扩展） |

## 5. 关键推导

**推导：LDA 是 pLDA 的贝叶斯化（先验作用）**。

pLDA 对每文档学 $\theta_d$（参数随文档数增长 → 过拟合）；LDA 给 $\theta_d \sim \text{Dirichlet}(\alpha)$ 先验——参数被"收缩"向 $\alpha$ 比例，文档多时仍稳健，且新文档可直接推断（无需重新学习）。∎

**推导：变分 E 步的 $\phi$ 更新（CAVI）**。

$\log q(z_{dn}=k) \propto \mathbb{E}_{q}[\log\theta_{dk}] + \mathbb{E}_{q}[\log\beta_{k,w_{dn}}]$（来自生成过程对数似然中与 $z_{dn}$ 相关的两项）；$\mathbb{E}[\log\theta]$ 用 Dirichlet 期望（digamma 函数）计算。归一化得 $\phi_{dnk}$。∎

**推导：困惑度（perplexity）评价**。
$\text{Perp}(\mathcal{D}) = \exp\left(-\frac{\sum_d\log P(\mathbf{w}_d)}{\sum_d N_d}\right)$——越低越好；用留出数据的近似对数似然（变分下界）。∎

## 6. 最小可手算例子

**例（生成）**：$K=2$，主题 1（体育）$\beta_1$ 高概率给"球/队"，主题 2（科技）给"芯片/数据"。文档 $\theta_d = (0.7, 0.3)$ → 约 70% 词来自主题 1。

**例（推断手算直觉）**：词"球"的 $\phi_{dnk} \propto \exp(\mathbb{E}\log\theta_{dk} + \mathbb{E}\log\beta_{k,\text{球}})$：若文档主题偏向体育（$\theta_1$ 大）且主题 1 给"球"高概率 → $\phi_{dn1} \gg \phi_{dn2}$，该词归主题 1。

**例（LSA 对比）**：词-文档矩阵 SVD 后取 $K=2$ 维；LDA 与 pLSA 输出可解释的主题-词分布，LSA 给出的是数值因子。

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| LDA 需要文档标注 | **错**。LDA 是无监督（只给词序列） |
| 主题数 $K$ 自动确定 | **错**。LDA 固定 $K$（需用户指定/模型选择）；HDP 才自动 |
| LDA 的推断是精确的 | **错**。变分/Gibbs 都是近似（后验不可解） |
| pLDA 与 LDA 等价 | **错**。LDA 有 Dirichlet 先验（贝叶斯），pLDA 是最大似然 |
| 困惑度越低模型一定越好 | **不精确**。困惑度只测语言建模质量；下游任务（聚类/可解释性）更关键 |

4. 为什么 Dirichlet 先验能缓解 pLDA 过拟合？

### #自测题/较难
5. 对比变分 EM 与 Gibbs 采样求解 LDA 的差异与各自适用场景。

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. 采样 $\theta_d$ → 每词采样主题 $z_{dn}$ → 采样词 $w_{dn}$；$\beta_k$ 全局先验采样。
2. LSA 矩阵分解（非概率）；pLSA 概率但无先验；LDA 贝叶斯化（Dirichlet）。
3. 词-主题责任 $\phi \propto$ 文档主题倾向 × 主题词倾向（CAVI 双项）。
4. $\theta_d$ 被先验收缩，参数不过度拟合单文档；新文档可直接推断。
5. 变分 EM：快、可扩展、确定性（但平均场近似有偏）；Gibbs：无偏渐进、易实现、但慢且需收敛诊断。大规模语料常用变分/SVI；小数据或需精确时用 Gibbs。
</details>
