# 概率图模型-变分自编码器

> **变分自编码器（VAE）** 把变分推断与深度神经网络结合：编码器（神经网络）近似后验，解码器（神经网络）参数化似然，用**重参数化技巧**让 ELBO 可通过梯度下降端到端优化。它是"深度贝叶斯生成模型"的基石（VQ-VAE、CVAE、扩散模型的祖先）。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：想在隐变量模型 $p_\theta(\mathbf{x}, \mathbf{z})$ 上做最大似然，但后验 $p(\mathbf{z}\mid\mathbf{x})$ 不可解、$\log p_\theta(\mathbf{x})$ 的积分不可算。传统 VI 需手推每个模型的更新。VAE 用**神经网络参数化**变分族 $q_\phi(\mathbf{z}\mid\mathbf{x})$ 与生成模型 $p_\theta(\mathbf{x}\mid\mathbf{z})$，用**重参数化**把 ELBO 的梯度变成可采样估计——一个通用、可扩展的深度生成框架。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：VAE = 摊销变分推断（编码器共享参数）+ 深度生成；它与 [[概率图模型-变分推断算法]]（BBVI）一脉相承，是扩散模型、表征学习（β-VAE 解耦）的基础。
- **实际应用场景**：图像生成、异常检测、表征学习、半监督分类。
- **高频考点**：ELBO 分解、重参数化技巧、KL 项闭式（高斯）、编码器/解码器结构、变体。

## 4. 定义与核心公式

### 4.1 模型结构

- **生成模型（解码器）**：$p_\theta(\mathbf{x}\mid\mathbf{z})$（如高斯/伯努利），先验 $p(\mathbf{z})$（标准高斯）；
- **推断模型（编码器）**：$q_\phi(\mathbf{z}\mid\mathbf{x}) \approx p(\mathbf{z}\mid\mathbf{x})$（高斯，$\phi$ 输出均值/方差）。

### 4.2 ELBO（VAE 目标）

$$\log p_\theta(\mathbf{x}) \ge \mathcal{L}(\theta, \phi; \mathbf{x}) = \mathbb{E}_{q_\phi(\mathbf{z}\mid\mathbf{x})}[\log p_\theta(\mathbf{x}\mid\mathbf{z})] - \text{KL}(q_\phi(\mathbf{z}\mid\mathbf{x}) \parallel p(\mathbf{z}))$$

- **重构项**：$\mathbb{E}_q[\log p_\theta(\mathbf{x}\mid\mathbf{z})]$——编码-解码重建质量；
- **KL 正则项**：约束编码后验靠近先验（高斯先验下闭式）：
$$\text{KL}(\mathcal{N}(\mu_\phi, \sigma_\phi^2) \parallel \mathcal{N}(0, I)) = \frac{1}{2}\sum_j \left(\mu_j^2 + \sigma_j^2 - 1 - \log\sigma_j^2\right)$$

### 4.3 重参数化技巧（Reparameterization Trick）

**问题**：$\mathbb{E}_{q_\phi}[\cdot]$ 对 $\phi$ 求梯度不可直接蒙特卡洛（采样不可微）。

**技巧**：把采样写成确定性变换 + 外部噪声：
$$\mathbf{z} = \mu_\phi(\mathbf{x}) + \sigma_\phi(\mathbf{x}) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$
则 $\nabla_\phi \mathcal{L} = \mathbb{E}_\epsilon[\nabla_\phi(\cdots)]$ 可通过反向传播估计——**低方差**（对比评分函数估计）。

### 4.4 训练

交替/联合 SGD 最大化 ELBO（重构项 + KL 项）；解码器与编码器同时学习。

### 4.5 变体

| 变体 | 改进 | 目的 |
|:---|:---|:---|
| **β-VAE** | KL 项乘 $\beta > 1$ | 解耦表征（disentanglement） |
| **CVAE** | 条件变量 $\mathbf{c}$ | 条件生成（指定属性） |
| **HVAE** | 多层隐变量 $\mathbf{z}_1,\dots,\mathbf{z}_L$ | 分层表征 |
| **VQ-VAE** | 离散隐变量（向量量化） | 离散表征（文本/音频） |

## 5. 关键推导

**推导：ELBO 分解（VAE 形式）**。

$\log p_\theta(\mathbf{x}) = \mathbb{E}_{q_\phi}[\log p_\theta(\mathbf{x},\mathbf{z}) - \log q_\phi(\mathbf{z}\mid\mathbf{x})] + \text{KL}(q_\phi \parallel p(\mathbf{z}\mid\mathbf{x}))$
$= \mathbb{E}_{q_\phi}[\log p_\theta(\mathbf{x}\mid\mathbf{z})] - \text{KL}(q_\phi(\mathbf{z}\mid\mathbf{x}) \parallel p(\mathbf{z})) + \text{KL}(q_\phi \parallel p(\mathbf{z}\mid\mathbf{x}))$
第三项 ≥ 0 → 前两项是下界。∎

**推导：重参数化梯度（低方差）**。

设 $\mathbf{z} = g_\phi(\epsilon)$。$\nabla_\phi\mathbb{E}_{q_\phi}[f] = \nabla_\phi\mathbb{E}_\epsilon[f(g_\phi(\epsilon))] = \mathbb{E}_\epsilon[\nabla_\phi f(g_\phi(\epsilon))]$——梯度穿过确定性映射，无采样噪声干扰参数方向（对比评分函数：$\nabla_\phi\log q_\phi$ 项方差大）。∎

**推导：高斯 KL 闭式**。
$\text{KL}(\mathcal{N}(\mu,\sigma^2)\parallel\mathcal{N}(0,1)) = \frac{1}{2}(\mu^2 + \sigma^2 - 1 - \log\sigma^2)$（展开 log 密度比，用 $\mathbb{E}[z^2] = \mu^2+\sigma^2$）。∎

---

## 6. 最小可手算例子

**例（KL 项手算）**：编码器输出 $\mu = (1.0, 0.0)$，$\sigma^2 = (0.5, 1.0)$（2 维潜变量）。
$$\text{KL} = \frac12[(1^2 + 0.5 - 1 - \log 0.5) + (0 + 1 - 1 - \log 1)] = \frac12[(1 + 0.5 - 1 + 0.693) + 0] = \frac12[1.193] = 0.597$$

**例（重参数化）**：$\mu = 1.0$，$\sigma = 0.5$，采样 $\epsilon = 0.8$ → $\mathbf{z} = 1.0 + 0.5\times0.8 = 1.4$（确定性可微）。

**例（重构项）**：解码器输出高斯均值 $\hat x = 0.9$，固定方差，观测 $x = 1.0$ → $\log p_\theta(x\mid z) = -\frac{(1.0-0.9)^2}{2\sigma^2} + \text{const}$——重构误差驱动梯度。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| VAE 直接最大化 $\log p_\theta(\mathbf{x})$ | **错**。最大化 ELBO（下界），不是真实似然 |
| 编码器给出精确后验 | **错**。$q_\phi$ 是近似（摊销 + 平均场式高斯），有近似误差 |
| 重参数化可有可无 | **错**。它是 VAE 可训练的关键（低方差梯度）；无它需评分函数（高方差） |
| 重构项 = MSE | **部分对**。高斯似然下重构项 = 加权 MSE；伯努利下是交叉熵 |
| VAE 样本质量必然差于 GAN | **不精确**。VAE 训练稳定、覆盖模式，但样本模糊；GAN 清晰但模式坍缩——各有取舍 |

## 8. 检索练习（闭卷自检）

### #自测题/基础
1. 写出 VAE 的 ELBO（两项）。
2. 重参数化技巧解决什么问题？

### #自测题/中等
3. 手算 $\mu=(0.5,1.0)$，$\sigma^2=(2.0,1.0)$ 的高斯 KL。
4. 说明 β-VAE 的 $\beta$ 如何影响表征。

### #自测题/较难
5. 对比 VAE（重参数化）与 BBVI（评分函数）的梯度估计方差，解释 VAE 训练更稳的原因。

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. $\mathcal{L} = \mathbb{E}_q[\log p_\theta(x\mid z)] - \text{KL}(q_\phi(z\mid x)\parallel p(z))$。
2. 采样不可微 → 用 $\mathbf{z} = \mu + \sigma\epsilon$ 使梯度穿过确定性映射。
3. $\frac12[(0.25+2-1-\log2) + (1+1-1-0)] = \frac12[1.557+1] = 1.279$。
4. $\beta$ 大 → KL 正则强 → 潜变量各维更独立（解耦）；$\beta$ 小 → 重构优先。
5. 重参数化把噪声放外部，梯度只含"目标函数对参数"项，方差由数据决定；评分函数含 $\nabla\log q$ 项，其方差随函数值尺度放大——VAE 梯度更稳。
</details>
