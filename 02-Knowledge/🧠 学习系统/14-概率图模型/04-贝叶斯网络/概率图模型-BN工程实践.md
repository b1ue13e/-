# 概率图模型-BN工程实践

> 本卡把 BN 从"理论模型"带到"工程落地"：**建模流程**（结构设计/参数获取/验证）、**工具链**（pgmpy 等）、**验证方法**（数据拟合/交叉验证）与**敏感性分析**（结论对参数扰动的稳健性）。这是课程 Capstone 与真实项目（医疗 BN、诊断网络）的操作指南。

## 4. 核心内容

### 4.1 建模流程（四步）

1. **结构建模**：
   - 专家设计（因果语义、可解释）或数据学习（BIC/BDeu、PC）；
   - 常见做法：专家结构 + 数据校验；
2. **参数估计**：专家 CPT 或数据 MLE/贝叶斯平滑；
3. **模型验证**：留出数据上比较 $P(\mathbf{x})$、预测校准、交叉验证；
4. **敏感性分析**：扰动 CPT，观察后验/决策变化。

### 4.2 工具链（pgmpy 为主）

| 工具 | 用途 |
|:---|:---|
| pgmpy | BN/MRF 建模、精确/近似推断、结构/参数学习（课程验收源） |
| bnlearn (R) | 结构学习（白名单/黑名单约束） |
| pyAgrum | 敏感性分析、可视化 |

**pgmpy 典型流程**：`BayesianModel(edges)` → `CPD` 填充 → `VariableElimination/JunctionTree` 推断 → `ParameterEstimator/HillClimbSearch` 学习。

### 4.3 模型验证

- **拟合度**：训练/测试对数似然；
- **校准**：预测概率 vs 实际频率（可靠性图）；
- **任务指标**：分类准确率/AUC（若用于预测）；
- **结构稳定性**：bootstrap 重采样下的边频率（结构学习可信度）。

### 4.4 敏感性分析（Sensitivity Analysis）

**定义**：研究**参数扰动**对**查询结果**（后验 $P(Q \mid e)$、决策）的影响。

**方法**：
- 单参数扰动：修改一个 CPT 条目，观察 $P(Q\mid e)$ 变化；
- 多参数（全局）敏感性：在参数空间采样扰动，统计结论翻转的比例；
- 目标：识别"对哪些参数敏感"→ 对敏感参数提高估计精度，对不敏感参数可简化。

**意义**：模型结论的**稳健性证据**；指导数据收集优先级。

---

## 5. 关键推导

**推导：后验对参数的一阶敏感性（直觉）**。

$P(q \mid e, \theta) = \frac{\sum_{z} P(q, z, e \mid \theta)}{P(e \mid \theta)}$。对数-线性参数化下，$\frac{\partial \log P(q\mid e)}{\partial \theta_c}$ 与"查询中包含该参数的因子"相关——敏感性可解析或数值计算。工程上常用数值扰动（简单可靠）。∎

**推导：为什么验证必须用留出数据**。
训练数据上模型必然过拟合（MLE 最大化训练似然）；留出数据评估反映泛化。CPT 参数多、小数据更易过拟合 → 验证与平滑（贝叶斯估计）必须配套。∎

---

## 6. 最小可手算例子

**例（敏感性分析）**：诊断 BN，$P(D{=}1) = 0.02$（患病率），$P(T{=}1\mid D{=}1) = 0.9$（灵敏度）。查询 $P(D{=}1\mid T{=}1)$。

- 基线（误报 5%）：$P(D\mid T) = \frac{0.9\times0.02}{0.9\times0.02 + 0.05\times0.98} = \frac{0.018}{0.067} \approx 0.269$；
- 扰动灵敏度 0.95：$\frac{0.95\times0.02}{0.95\times0.02+0.05\times0.98} = \frac{0.019}{0.068} \approx 0.279$；
- 扰动误报 0.10：$\frac{0.018}{0.018+0.098} \approx 0.155$；
- **结论**：结论对误报率**更敏感**（0.27→0.16 大变化），应优先精确估计误报率。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| 专家结构不用验证 | **错**。专家结构也需数据校验（结构可能有误） |
| 训练集上表现好 = 模型好 | **错**。必须留出/交叉验证；否则过拟合 |
| 敏感性分析可有可无 | **错**。参数不确定时不做敏感性 = 结论无稳健性证据 |
| 参数越多越好 | **不精确**。多参数需更多数据支撑；平滑/简化常更稳健 |
| 工具（pgmpy）自动保证正确 | **不精确**。工具只执行算法；结构/参数/验证责任在建模者 |

### #自测题/较难

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. 结构建模 → 参数估计 → 验证 → 敏感性分析。
2. 结论（后验/决策）对参数扰动的稳健性。
3. $P(D\mid T) = \frac{0.018}{0.018+0.147} = 0.109$——比基线 0.269 大幅下降，误报率是关键参数。
4. 训练数据上 MLE 必然过拟合；留出数据反映泛化能力。
5. 对每个参数在合理区间扰动，计算后验变化量；变化最大者即最敏感参数，优先精修（更多数据/专家校准）。
