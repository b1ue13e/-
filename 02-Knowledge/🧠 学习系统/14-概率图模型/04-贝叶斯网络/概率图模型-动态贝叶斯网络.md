# 概率图模型-动态贝叶斯网络

> **动态贝叶斯网络（DBN）** 把 BN 扩展到时序：用"时间片"表示每时刻的变量，用转移/观测模型连接相邻时刻。HMM 是 DBN 的特例（单隐状态链）；DBN 允许更丰富的状态结构（多变量、分层）。本卡覆盖 DBN 定义、展开、推断，以及语音/动作/故障应用。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：静态 BN 无法表达"随时间演化的系统"（机器人状态、语音、设备故障）。若把每一时刻的变量都画进一张 BN，图随时间无限增长。DBN 用**两个时间片模板 + 一阶马尔可夫假设**紧凑表达无限长的时序过程，并支持在线滤波与平滑。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：DBN 是 HMM 的推广（状态可以是多变量的 BN），也是卡尔曼滤波（线性-高斯 DBN）的框架；它统一了时序概率模型的表示。
- **实际应用场景**：机器人定位（SLAM）、语音识别（分层状态）、设备故障诊断（随时间演化的健康状态）。
- **高频考点**：时间片/转移/观测模型、DBN 展开、前向滤波、DBN vs HMM 关系。

## 4. 定义与核心公式

### 4.1 DBN 的组成

**时间片（time slice）**：时刻 $t$ 的变量集合 $\mathbf{X}^{(t)} = (X_1^{(t)}, \dots, X_n^{(t)})$。

**转移模型（transition model）**：$P(\mathbf{X}^{(t+1)} \mid \mathbf{X}^{(t)})$——相邻时间片间的依赖（一阶马尔可夫）。

**观测模型（observation model）**：$P(\mathbf{O}^{(t)} \mid \mathbf{X}^{(t)})$——隐状态生成观测。

**先验/初始分布**：$P(\mathbf{X}^{(0)})$。

### 4.2 联合分布与展开（Unrolling）

**定义**：DBN 的联合分布（一阶）：
$$P(\mathbf{X}^{(0:T)}, \mathbf{O}^{(0:T)}) = P(\mathbf{X}^{(0)}) \prod_{t=0}^{T} P(\mathbf{O}^{(t)} \mid \mathbf{X}^{(t)}) \prod_{t=1}^{T} P(\mathbf{X}^{(t)} \mid \mathbf{X}^{(t-1)})$$

**展开（unrolling）**：把 $T+1$ 个时间片按转移/观测模型连接成一张大 BN——用静态 BN 推断算法处理。**同质性假设**：转移/观测模型各时刻相同（模板复用）→ 参数不随 $t$ 变。

### 4.3 推断任务

| 任务 | 定义 | 算法 |
|:---|:---|:---|
| **滤波（filtering）** | $P(\mathbf{X}^{(t)} \mid \mathbf{o}^{(0:t)})$ | 前向递推（BP 前向消息） |
| **预测（prediction）** | $P(\mathbf{X}^{(t+k)} \mid \mathbf{o}^{(0:t)})$ | 转移模型递推 |
| **平滑（smoothing）** | $P(\mathbf{X}^{(t)} \mid \mathbf{o}^{(0:T)})$，$t<T$ | 前向+后向（链上 BP） |
| **最可能序列（MAP）** | $\arg\max_{\mathbf{x}^{(0:T)}} P(\mathbf{x}^{(0:T)} \mid \mathbf{o}^{(0:T)})$ | Viterbi（最大积） |

### 4.4 DBN vs HMM

**HMM 是 DBN 特例**：HMM = DBN 且 $\mathbf{X}^{(t)}$ 是单变量（$S_t$）、状态转移 $P(S_{t+1}\mid S_t)$、观测 $P(O_t\mid S_t)$。**DBN 推广**：状态是多变量的 BN（可含内部依赖、分层状态）、观测可多模态。

**对比**：HMM 状态离散单维；DBN 状态可为连续/多维/结构化。推断算法（前向后向/Viterbi）在 DBN 上同样适用（经展开）。

### 4.5 应用

- **语音 DBN**：音素/词级分层状态；
- **动作 DBN**：机器人动作序列的状态估计；
- **故障 DBN**：设备健康状态随时间演化，滤波实时诊断。

## 5. 关键推导

**推导：滤波递推（前向）**。

$P(\mathbf{x}^{(t)}\mid \mathbf{o}^{(0:t)}) \propto P(\mathbf{o}^{(t)}\mid \mathbf{x}^{(t)}) \sum_{\mathbf{x}^{(t-1)}} P(\mathbf{x}^{(t)}\mid \mathbf{x}^{(t-1)}) P(\mathbf{x}^{(t-1)}\mid \mathbf{o}^{(0:t-1)})$——即"预测（转移）+ 更新（观测）"，与 HMM 前向算法同构。∎

**推导：HMM 是 DBN 特例（参数映射）**。
HMM：$\pi = P(S_0)$、转移 $A = P(S_{t+1}\mid S_t)$、观测 $B = P(O_t\mid S_t)$——代入 DBN 联合分布即 HMM 联合。∎

**推导：平滑 = 前向 × 后向**。
$P(\mathbf{x}^{(t)}\mid \mathbf{o}^{(0:T)}) \propto \underbrace{P(\mathbf{x}^{(t)}\mid \mathbf{o}^{(0:t)})}_{\text{前向}} \cdot \underbrace{P(\mathbf{o}^{(t+1:T)}\mid \mathbf{x}^{(t)})}_{\text{后向}}$——链上 BP 的两方向消息乘积（与 HMM 前向后向一致）。∎

---

## 6. 最小可手算例子

**例（二时刻滤波）**：状态 $X_t \in \{0,1\}$，$P(X_0{=}1) = 0.5$；转移 $P(X_{t+1}{=}1\mid X_t{=}1) = 0.8$，$P(X_{t+1}{=}1\mid X_t{=}0) = 0.3$；观测 $P(O{=}1\mid X{=}1) = 0.9$，$P(O{=}1\mid X{=}0) = 0.2$。观测 $O_0 = 1, O_1 = 1$。

**滤波 $t=0$**：$P(X_0{=}1\mid O_0{=}1) \propto 0.9\times0.5 = 0.45$；$P(X_0{=}0\mid O_0{=}1) \propto 0.2\times0.5 = 0.10$；归一化 $= 0.45/0.55 = 0.818$。

**滤波 $t=1$**：
- 预测：$P(X_1{=}1\mid O_0{=}1) = 0.818\times0.8 + 0.182\times0.3 = 0.654 + 0.055 = 0.709$；
- 更新：$P(X_1{=}1\mid O_{0:1}{=}1,1) \propto 0.9 \times 0.709 = 0.638$；$P(X_1{=}0) \propto 0.2 \times 0.291 = 0.058$；
- 归一化：$0.638/0.696 \approx 0.917$——观测支持状态 1。

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| DBN = HMM | **错**。HMM 是 DBN 单状态变量特例；DBN 状态可多维/结构化 |
| DBN 只能离散状态 | **错**。线性-高斯 DBN = 卡尔曼滤波（连续状态） |
| 展开后必须用专门算法 | **错**。展开后是普通 BN，可用 VE/联结树；滤波/平滑是链上 BP 的高效特例 |
| 转移模型必须同质（各时刻相同） | **不必须**。同质是简化假设；异质 DBN 允许时变参数 |
| DBN 不能处理长序列 | **不精确**。展开随 $T$ 增长，但滤波/平滑递推是 $O(T)$，适合长序列 |
