# 概率图模型-条件随机场

> **条件随机场（CRF）** 是序列标注的**判别式**无向模型：直接建模 $P(\mathbf{y} \mid \mathbf{x})$（而非 HMM 的联合 $P(\mathbf{x},\mathbf{y})$）。线性链 CRF 用**特征函数** + 权重线性组合定义势函数，突破 HMM 的观测独立假设，是 NER/POS 的标准模型。本卡覆盖定义、推断（前向/后向/Viterbi）、学习（梯度上升）与 HMM 对比。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：HMM 假设观测条件独立（$o_t$ 只依赖 $q_t$），无法利用重叠、长距离特征（如"词尾 -ing""上一个词"）。CRF 直接对**条件分布** $P(\mathbf{y} \mid \mathbf{x})$ 建模，把任意重叠特征塞进势函数，训练时学权重——拟合能力更强，且无需对 $\mathbf{x}$ 建模（省掉生成 $x$ 的浪费）。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：CRF 是"判别式 PGM"代表（对比 HMM 生成式）；它与最大熵/逻辑回归一脉相承，与深度序列模型（BiLSTM-CRF）直接衔接。
- **实际应用场景**：命名实体识别（NER）、词性标注（POS）、分块、图像分割（全连接 CRF）。
- **高频考点**：特征函数与势函数、归一化 $Z$、推断（Viterbi/前向后向）、学习（梯度 + 模型期望）、与 HMM 差异。

## 4. 定义与核心公式

### 4.1 线性链 CRF 定义

**定义**：给定输入序列 $\mathbf{x} = (x_1,\dots,x_T)$，输出标签 $\mathbf{y} = (y_1,\dots,y_T)$：

$$P(\mathbf{y} \mid \mathbf{x}) = \frac{1}{Z(\mathbf{x})} \exp\left( \sum_{t=1}^{T}\sum_{k} \lambda_k f_k(y_t, y_{t-1}, \mathbf{x}, t) \right)$$

其中：
- $f_k$：**特征函数**（通常二值，如"$y_t$=NNP 且 $x_t$ 大写开头"）；
- $\lambda_k$：特征权重（待学习）；
- $Z(\mathbf{x}) = \sum_{\mathbf{y}'}\exp(\sum_{t,k}\lambda_k f_k(y_t', y_{t-1}', \mathbf{x}, t))$：配分函数（对标签序列求和）。

**势函数视角**：节点势 $\exp(\sum_k \lambda_k f_k^{node})$ 与边势 $\exp(\sum_k\lambda_k f_k^{edge})$——与 MRF 同构，但**条件于 $\mathbf{x}$**（$\mathbf{x}$ 是常数，不作为变量建模）。

### 4.2 推断

- **评估/边缘**：前向-后向算法（与 HMM 相同框架，把 $b_j(o_t)$ 换成节点势）；
- **解码（MAP）**：Viterbi（与 HMM 相同，势替换发射概率）；
- 复杂度 $O(T \cdot N^2)$（$N$ 标签数）。

### 4.3 学习（最大条件似然）

**目标**：最大化 $\ell(\lambda) = \sum_{(\mathbf{x},\mathbf{y})} \log P(\mathbf{y}\mid\mathbf{x},\lambda)$。

**梯度**（与 MRF 学习同构）：
$$\nabla_{\lambda_k} \ell = \underbrace{\sum_{\text{data}} f_k(\mathbf{y},\mathbf{x})}_{\text{数据特征计数}} - \underbrace{\sum_{\text{data}} \mathbb{E}_{P(\mathbf{y}'\mid\mathbf{x})}[f_k(\mathbf{y}',\mathbf{x})]}_{\text{模型期望}}$$

**模型期望**：用前向-后向算边缘分布再求特征期望——**无闭式**，需迭代（梯度上升/L-BFGS）。**目标凸**：CRF 的对数似然是 $\lambda$ 的凹函数（$\log Z$ 凸）→ 全局最优（对比 EM 的局部最优）。

### 4.4 CRF vs HMM

| 维度 | HMM | CRF |
|:---|:---|:---|
| 建模 | 生成式 $P(\mathbf{x},\mathbf{y})$ | 判别式 $P(\mathbf{y}\mid\mathbf{x})$ |
| 观测假设 | 条件独立（强） | 无（特征任意重叠） |
| 特征 | 固定（发射/转移） | 任意设计特征 |
| 学习 | Baum-Welch（EM，局部最优） | 梯度上升（凸，全局最优） |
| 数据需求 | 联合建模浪费（$\mathbf{x}$ 需建模） | 只需标注数据 |
| 应用 | 语音、基因 | NER、POS、分块 |

---

## 5. 关键推导

**推导：CRF 梯度 = 数据期望 − 模型期望**。

$\nabla_{\lambda_k}\ell = \sum_{(\mathbf{x},\mathbf{y})}\left[f_k - \frac{1}{Z}\nabla_{\lambda_k}Z\right]$，而 $\frac{\nabla_{\lambda_k}Z}{Z} = \mathbb{E}_{P(\cdot\mid\mathbf{x})}[f_k]$（对 $Z = \sum\exp(\sum\lambda f)$ 求导并归一化）。∎

**推导：似然凹性（全局最优）**。
$\ell(\lambda) = \sum_k\lambda_k F_k(\text{data}) - \sum_{(\mathbf{x},\mathbf{y})}\log Z(\mathbf{x})$。第一项线性；$\log Z$ 是指数族累积函数（凸），负号使其凹 → $\ell$ 凹 → 梯度上升收敛到全局最大。∎

**推导：CRF 推断与 HMM 同构**。
把 HMM 的发射概率 $b_j(o_t)$ 替换为节点势 $\exp(\sum_k\lambda_k f_k(j, \mathbf{x}, t))$、转移 $a_{ij}$ 替换为边势——前向/后向/Viterbi 递推公式结构不变（求和/取最大）。∎

---

## 6. 最小可手算例子

**例（特征与势）**：POS 标注，标签 $\{N, V\}$。特征：$f_1 = \mathbb{1}[y_t = N \wedge x_t \text{ 以 -tion 结尾}]$，$f_2 = \mathbb{1}[y_t = V]$，$f_3 = \mathbb{1}[y_{t-1}=N, y_t=V]$（转移特征）。权重 $\lambda_1 = 2.0, \lambda_2 = 0.5, \lambda_3 = 1.0$。

给定 $\mathbf{x} = (\text{action, play})$：
- $y = (N, V)$：$\exp(2.0 + 0.5 + 1.0) = e^{3.5} = 33.1$；
- $y = (N, N)$：$\exp(2.0 + 0 + 0) = e^2 = 7.4$；
- 归一化（$Z$ = 所有标签对的和）后 $P(N,V) = 33.1/(33.1+7.4+\dots)$——"action→N" 被 $f_1$ 强烈支持。

**学习梯度**（示意）：若数据中 $f_1$ 在标注序列出现 3 次、模型期望 1.5 次，则 $\nabla\lambda_1 = 3 - 1.5 = 1.5$，梯度上升增加 $\lambda_1$ 使模型更倾向 $f_1$ 模式。

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| CRF 是生成模型 | **错**。CRF 是判别式（条件建模） |
| CRF 观测也要求条件独立 | **错**。特征可任意重叠，这正是相对 HMM 的核心优势 |
| CRF 学习可能陷入局部最优 | **错**。条件似然是凹函数，梯度上升全局最优 |
| CRF 的 $Z$ 很好算 | **错**。$Z$ 对标签序列指数求和，需前向-后向动态规划 |
| CRF = HMM + 更多特征 | **不精确**。范式不同（判别 vs 生成）；CRF 不建模 $\mathbf{x}$ 分布 |

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. $P(\mathbf{y}\mid\mathbf{x}) = \frac{1}{Z(\mathbf{x})}\exp(\sum_t\sum_k\lambda_k f_k(y_t,y_{t-1},\mathbf{x},t))$。
2. CRF 条件建模 $P(\mathbf{y}\mid\mathbf{x})$；HMM 联合建模 $P(\mathbf{x},\mathbf{y})$。
3. 数据特征计数 − 模型期望；模型期望需前向-后向计算。
4. 势函数替换发射/转移概率后，链式 DP 结构相同（和/最大）。
5. CRF 的 $\log P(\mathbf{y}\mid\mathbf{x})$ 是线性项 − 凸 $\log Z$ → 凹；HMM 的 $\log P(\mathbf{x}\mid\lambda)$ 对参数非凹（EM 只局部最优）。
