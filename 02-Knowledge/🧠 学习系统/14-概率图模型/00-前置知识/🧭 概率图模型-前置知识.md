## 二、补学顺序（必须先过前置诊断）

```
概率基础（复用）→ 贝叶斯规则与条件独立（新建）→ 图论基础（新建）→ 优化初步（新建）
        ↓
进入阶段 1：基础与表示（BN / MRF / 因子分解）
```

**最低通过标准（未达标不进入阶段 1）**：
1. 能写出链式法则 $P(X_1,\dots,X_n) = \prod_i P(X_i \mid X_1,\dots,X_{i-1})$ 并手算 3 变量例子；
2. 能用贝叶斯定理推导后验，识别条件独立与边缘独立的区别；
3. 能画出 DAG / 无向图并识别路径、环、团（clique）；
4. 能解释梯度下降更新公式并手算一步。
