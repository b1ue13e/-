# 概率图模型-优化初步

> 概率图模型的**学习**（参数估计、MLE、EM）与**近似推断**（变分推断）最终都归结为优化问题：最大化似然、最大化 ELBO、最小化损失。本卡给出读懂这些优化的最小工具集，是阶段 2（变分推断）与阶段 3（学习算法）的数学前置。只讲支撑课程的最小内容，完整优化见 [[07-最优化方法]]。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：给定数据 $\mathcal{D}$，我们想找参数 $\theta$ 使模型最"好"——通常定义为最大化对数似然 $\ell(\theta) = \log P(\mathcal{D} \mid \theta)$。但 $\ell(\theta)$ 往往没有闭式解（尤其是含隐变量的模型，如 GMM、HMM）。我们需要**迭代算法**一步步逼近最优参数，并且要理解：什么条件下迭代会收敛、什么时候会遇到局部最优。

变分推断更进一步：要把"推断"变成优化——最大化 ELBO。所以优化不是 PGM 的附属品，而是**推断与学习的公共引擎**。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：MLE（阶段 3）、EM 算法（阶段 3）、变分推断（阶段 2）、结构学习的打分函数（阶段 3）全是优化。
- **实际应用场景**：神经网络训练（梯度下降）、正则化参数选择（拉格朗日）、EM 求解 GMM/HMM、变分自编码器训练。
- **高频考点**：梯度下降更新推导、拉格朗日乘子法、凸函数判定、约束优化。

---

## 3. 学它之前需要哪些前置知识？

1. **微积分**：偏导数、梯度、链式法则——求导是优化的基础动作。
2. **概率图模型-贝叶斯规则与条件独立**：理解似然 $P(\mathcal{D} \mid \theta)$ 与对数似然为什么常被最大化（乘积变求和）。

---

## 4. 定义与核心公式

### 4.1 无约束优化与梯度下降

**问题**：$\min_{\theta} f(\theta)$，$f: \mathbb{R}^d \to \mathbb{R}$。

**梯度下降（Gradient Descent）**：从初始点 $\theta^{(0)}$ 出发，沿负梯度方向迭代：

$$\theta^{(t+1)} = \theta^{(t)} - \eta_t \nabla f(\theta^{(t)})$$

其中 $\eta_t > 0$ 是**学习率（步长）**。

**为什么是负梯度**：梯度 $\nabla f$ 指向 $f$ 增长最快的方向，所以 $-\nabla f$ 指向下降最快的方向（一阶泰勒展开 $f(\theta + \epsilon d) \approx f(\theta) + \epsilon \langle \nabla f, d \rangle$，取 $d = -\nabla f/|\nabla f|$ 使下降最大）。

**收敛条件（直观）**：$f$ 凸且可微、步长合适时，$\theta^{(t)} \to$ 全局最优；$f$ 非凸时收敛到**局部最优**（取决于初值与路径）。

**随机梯度下降（SGD）**：用数据子集（mini-batch）的梯度近似全量梯度，$d$ 大时显著加速。

### 4.2 凸函数

**定义（凸集）**：集合 $C$ 中任意两点连线上的点都在 $C$ 中：$\forall x, y \in C, \lambda \in [0,1]: \lambda x + (1-\lambda) y \in C$。

**定义（凸函数）**：$f$ 定义在凸集上，且

$$f(\lambda x + (1-\lambda) y) \le \lambda f(x) + (1-\lambda) f(y), \quad \forall \lambda \in [0,1]$$

**一阶判定**（可微时）：$f(y) \ge f(x) + \langle \nabla f(x), y - x \rangle$（切线始终在函数下方）。
**二阶判定**（二阶可微时）：$\nabla^2 f(x) \succeq 0$（Hessian 半正定）。

**凸优化的重要性**：凸问题的**局部最优 = 全局最优**，这是"优化结果可靠"的理论保证。

### 4.3 约束优化与拉格朗日乘子

**问题**：$\min_{\theta} f(\theta)$ 受约束 $g_i(\theta) \le 0$（不等式）、$h_j(\theta) = 0$（等式）。

**拉格朗日函数（Lagrangian）**（等式约束情形）：

$$\mathcal{L}(\theta, \lambda) = f(\theta) + \sum_j \lambda_j h_j(\theta)$$

**KKT 条件**（等式 + 不等式约束的一阶必要条件，正规性假设下）：存在乘子 $\lambda \ge 0, \mu$ 使得
$$\nabla_\theta \mathcal{L} = 0, \quad g_i(\theta) \le 0, \quad \lambda_i g_i(\theta) = 0 \ (\text{互补松弛})$$

**用途**：带约束的 MLE（如概率归一化约束 $\sum_x P(x) = 1$）可用拉格朗日法导出闭式解；正则化（L2）等价于带范数约束的优化。

### 4.4 期望最大化视角（预告）

EM 算法（阶段 3）是一种**坐标式/迭代式优化**：交替"E 步（在固定参数下计算隐变量后验期望）"与"M 步（最大化完整数据对数似然期望）"。它保证单调不降地提高对数似然——这是"迭代优化"在 PGM 中的标志性应用。

---

## 5. 关键推导

**推导 1：梯度下降更新来自一阶泰勒近似**。
$f(\theta + \Delta) \approx f(\theta) + \nabla f(\theta)^\top \Delta$。若想让 $f$ 下降且 $\Delta$ 有界（$\lVert \Delta \rVert \le \epsilon$），最优下降方向由柯西-施瓦茨不等式给出：$\Delta^* = -\epsilon \frac{\nabla f}{\lVert \nabla f \rVert}$，即负梯度方向。∎

**推导 2：凸 ⇒ 局部最优即全局最优**。
设 $\theta^*$ 是局部最优。对任意 $\theta$，由凸性：$f(\theta) \ge f(\theta^*) + \langle \nabla f(\theta^*), \theta - \theta^* \rangle$。若 $\theta^*$ 是内点局部最优则 $\nabla f(\theta^*)=0$，故 $f(\theta) \ge f(\theta^*)$，即全局最优。∎

**推导 3：带归一化约束的 MLE 用拉格朗日求解**。
最大化 $\sum_x n_x \log p_x$ 受 $\sum_x p_x = 1$。Lagrangian：$\mathcal{L} = \sum_x n_x \log p_x + \lambda(\sum_x p_x - 1)$。对 $p_x$ 求导置零：$\frac{n_x}{p_x} + \lambda = 0 \Rightarrow p_x \propto n_x$；由 $\sum_x p_x = 1$ 得 $p_x = n_x / \sum_x n_x$——频率即 MLE。∎

---

## 6. 最小可手算例子

**例 1：梯度下降手算**。最小化 $f(x) = x^2$（凸）。$\nabla f = 2x$，取 $x^{(0)} = 2$，$\eta = 0.1$：
- $x^{(1)} = 2 - 0.1 \times 4 = 1.6$
- $x^{(2)} = 1.6 - 0.1 \times 3.2 = 1.28$
- 继续迭代，$x \to 0$，$f \to 0$。收敛到全局最小。

**例 2：拉格朗日解归一化 MLE**。数据：$n = (3, 5, 2)$（三类别计数，共 10）。最大化多项式对数似然受 $\sum p_i = 1$，由推导 3：$p = (0.3, 0.5, 0.2)$。

**例 3：凸性判定**。$f(x) = x^2$：$f'' = 2 > 0$，严格凸。$g(x) = -\log x$（$x>0$）：$g'' = 1/x^2 > 0$，凸——这就是负对数似然的凸性来源之一。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| 梯度下降保证全局最优 | **错**。只有凸函数才保证；非凸问题（如深度模型、EM 一般情形）只能保证局部最优 |
| 学习率越大收敛越快 | **错**。过大导致发散/震荡；过小收敛慢。需调参或自适应（Adam 等） |
| 拉格朗日乘子必须为正 | **错**。等式约束的乘子可正可负；不等式约束的乘子才要求 $\lambda \ge 0$ |
| 约束优化=无约束优化加惩罚 | **不精确**。惩罚法只是近似；拉格朗日/KKT 才是精确的一阶条件 |
| SGD 不如批量梯度下降"准确" | **错**。SGD 是随机近似，收敛性质不同但大规模下实用；噪声反而有正则化作用 |

### #自测题/基础
1. 写出梯度下降更新公式，解释 $\eta$ 的作用。
2. 判断 $f(x) = x^4 - 2x^2$ 是否为凸函数（说明理由）。

### #自测题/中等
3. 用梯度下降手算 $f(x) = x^2$ 从 $x=3$ 出发、$\eta=0.2$ 的前两步。
4. 用拉格朗日乘子法求解：最大化 $\sum_i n_i \log p_i$ 受 $\sum_i p_i = 1$。

### #自测题/较难
5. 解释为什么 EM 算法能保证对数似然单调不降（提示：利用 ELBO 下界与 Jensen 不等式）。这与梯度下降的收敛保证有何区别？

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. $\theta^{(t+1)} = \theta^{(t)} - \eta \nabla f(\theta^{(t)})$；$\eta$ 控制步长。
2. 非凸。$f''(x) = 12x^2 - 4$，在 $x=0$ 处为 $-4 < 0$，Hessian 非半正定。
3. $x^{(1)} = 3 - 0.2\times 6 = 1.8$；$x^{(2)} = 1.8 - 0.2\times 3.6 = 1.08$。
4. $p_i = n_i / \sum n_i$（见推导 3）。
5. EM 每次迭代构造并最大化 ELBO 下界，$Q$ 函数保证 $\ell(\theta^{(t+1)}) \ge \ell(\theta^{(t)})$（Jensen 不等式给出下界，M 步最大化该下界）；梯度下降只保证沿方向下降、不保证每一步都提高目标。两者都是迭代算法，但 EM 的单调性来自下界构造而非局部梯度。
</details>
