# 概率图模型-贝叶斯规则与条件独立

> 本卡是概率图模型的**第一块基石**：贝叶斯网络（BN）的全部定义、d-分隔、推断与学习都建立在「条件独立」与「贝叶斯规则」之上。这里只讲支撑课程的最小内容，完整概率论见 [[22-概率论与数理统计]]。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：面对 $n$ 个随机变量，联合分布 $P(X_1, X_2, \dots, X_n)$ 一般需要指数级参数（$n$ 个二值变量需要 $2^n - 1$ 个参数）。我们**无法**枚举、存储或推断如此巨大的分布。唯一出路是：利用变量之间的**条件独立**把联合分布拆成小块的乘积——这正是概率图模型的全部动机。

**贝叶斯规则**解决另一个问题：已知"原因→结果"方向的概率（似然 $P(\text{观测} \mid \text{假设})$），如何反推"结果→原因"方向（后验 $P(\text{假设} \mid \text{观测})$）——这是推断（inference）的核心动作。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：没有条件独立，就没有因子分解，就没有 BN/MRF 的紧凑表示；没有贝叶斯规则，就没有后验推断，EM、变分推断、MCMC 全部无从谈起。
- **实际应用场景**：疾病-症状诊断（已知患病率与检验灵敏度，求检验阳性时的患病概率）、垃圾邮件过滤、语音识别中的状态后验。
- **高频考点**：手算贝叶斯规则、识别条件独立、用链式法则分解联合分布。

---

## 3. 学它之前需要哪些前置知识？

1. **概率基础**：事件、概率公理、条件概率定义 $P(A \mid B) = P(A \cap B)/P(B)$、乘法法则、全概率公式。最小补充见 [[17-机器学习/00-前置知识/机器学习-概率统计基础|机器学习-概率统计基础]]。
2. **集合与图直觉**：能看懂"给定集合 $Z$ 下"这种条件表达；知道集合运算（并、交、补）。图论细节由下一张前置卡承接。

---

## 4. 定义与核心公式

### 4.1 条件概率与乘法法则

**定义（条件概率）**：对事件 $A, B$，$P(B) > 0$ 时

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

**乘法法则（链式法则的二元形式）**：由上式立即得到

$$P(A \cap B) = P(A \mid B) P(B) = P(B \mid A) P(A)$$

**链式法则（$n$ 元）**：对任意顺序 $X_1, \dots, X_n$，

$$P(X_1, X_2, \dots, X_n) = P(X_1) \prod_{i=2}^{n} P(X_i \mid X_1, \dots, X_{i-1})$$

> 链式法则**恒真**，不需要任何独立性假设——它只是乘法法则的反复应用。

### 4.2 贝叶斯规则（Bayes' Rule）

由乘法法则两边除以 $P(B)$：

$$P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)}$$

其中分母用**全概率公式**展开（设 $\{A_i\}$ 是样本空间的一个划分）：

$$P(B) = \sum_i P(B \mid A_i) P(A_i)$$

于是对 $n$ 个互斥且穷尽的假设 $A_1, \dots, A_n$：

$$P(A_j \mid B) = \frac{P(B \mid A_j) P(A_j)}{\sum_i P(B \mid A_i) P(A_i)}$$

**术语**：$P(A)$ 先验（prior），$P(B \mid A)$ 似然（likelihood），$P(A \mid B)$ 后验（posterior），$P(B)$ 证据/归一化常数（evidence/normalizing constant）。

### 4.3 条件独立（Conditional Independence）

**定义**：随机变量 $X$ 与 $Y$ 在给定 $Z$ 时条件独立，记 $X \perp\!\!\!\perp Y \mid Z$，当且仅当对所有取值满足

$$P(X, Y \mid Z) = P(X \mid Z)\, P(Y \mid Z)$$

**等价形式**（三者任选其一，均等价）：

| 形式 | 表达式 | 直觉 |
|:---|:---|:---|
| 联合条件概率分解 | $P(X,Y \mid Z) = P(X \mid Z)P(Y \mid Z)$ | 知道 $Z$ 后，$X,Y$ 联合分布可分解 |
| 条件概率形式 | $P(X \mid Y, Z) = P(X \mid Z)$ | 知道 $Z$ 后，$Y$ 不再提供关于 $X$ 的信息 |
| 对称形式 | $P(Y \mid X, Z) = P(Y \mid Z)$ | 同上，对称 |

**无条件独立是特殊情况**：$Z$ 为空集时退化为 $P(X,Y) = P(X)P(Y)$。

---

## 5. 关键性质（推导）

**性质 1：条件独立 ⇒ 联合分布分解**。若 $X \perp\!\!\!\perp Y \mid Z$，则

$$P(X, Y, Z) = P(X \mid Z) P(Y \mid Z) P(Z)$$

**推导**：$P(X,Y,Z) = P(X,Y \mid Z)P(Z) = P(X \mid Z)P(Y \mid Z)P(Z)$。∎

**性质 2：链式法则 + 条件独立 = 紧凑表示**。设 $X_1 \perp\!\!\!\perp X_3 \mid X_2$，则

$$P(X_1, X_2, X_3) = P(X_1 \mid X_2) P(X_2) P(X_3 \mid X_2)$$

参数从 $2^3 - 1 = 7$ 个降到 $2 + 1 + 2 = 5$ 个（每个二值变量）。这是 BN 参数压缩的雏形。

**性质 3（对称性与分解性）**：条件独立是**对称**的（$X \perp\!\!\!\perp Y \mid Z \iff Y \perp\!\!\!\perp X \mid Z$），但**不一定传递**：$X \perp\!\!\!\perp Y \mid Z$ 且 $Y \perp\!\!\!\perp W \mid Z$ 推不出 $X \perp\!\!\!\perp W \mid Z$（可构造反例，见下）。

---

## 6. 最小可手算例子

**例：医学诊断**。设 $D$ = 患病（$P(D=1) = 0.01$），$T$ = 检测阳性。灵敏度 $P(T=1 \mid D=1) = 0.95$，误报率 $P(T=1 \mid D=0) = 0.05$。问：检测阳性时实际患病的概率？

由贝叶斯规则：

$$P(D=1 \mid T=1) = \frac{P(T=1 \mid D=1)P(D=1)}{P(T=1 \mid D=1)P(D=1) + P(T=1 \mid D=0)P(D=0)}$$

$$= \frac{0.95 \times 0.01}{0.95 \times 0.01 + 0.05 \times 0.99} = \frac{0.0095}{0.0095 + 0.0495} = \frac{0.0095}{0.059} \approx 0.161$$

**结论**：即使检测阳性，患病概率也只有约 16%——因为患病率极低。这个"违反直觉"的结果正说明**先验不可忽略**，也解释了为什么 PGM 推断必须同时考虑先验与似然。

**例：条件独立手算**。设 $X, Y$ 独立同分布 $\text{Bernoulli}(0.5)$，$Z = X \oplus Y$（异或）。验证：$X \perp\!\!\!\perp Y$（无条件独立成立，因为构造独立）；但 $X \not\perp\!\!\!\perp Y \mid Z$（给定 $Z$ 后不独立）：若已知 $Z=0$，则 $X=Y$，$X$ 与 $Y$ 完全相关。这个例子说明：**观测共同"孩子"会破坏独立性**——这是 V 型结构（汇连）的本质，也是阶段 1 中 d-分隔的关键。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| 条件独立 ⇒ 无条件独立 | **错**。异或例中 $X \perp\!\!\!\perp Y \mid Z$ 可以成立但 $X$ 与 $Y$ 不独立（如 $X,Y$ 独立、$Z=X\oplus Y$ 时给定 $Z$ 反而**不**独立；反之构造 $X \perp\!\!\!\perp Y$ 但给定公共父节点后条件独立也成立）。**两个方向都不能想当然**，必须逐项验证 |
| 无条件独立 ⇒ 条件独立 | **错**。$X, Y$ 独立但给定共同原因 $Z$ 后（如 $Z$ 是 $X,Y$ 的公共父节点）它们**条件依赖**：知道 $Z$ 后，$X$ 的信息改变 $Y$ 的分布 |
| 条件独立可传递 | **错**。$X \perp\!\!\!\perp Y \mid Z$ 与 $Y \perp\!\!\!\perp W \mid Z$ 不推 $X \perp\!\!\!\perp W \mid Z$（构造四变量反例可验证） |
| 贝叶斯规则只适用于"因果"场景 | **错**。$P(A \mid B)$ 中 $A,B$ 的因果关系方向任意，贝叶斯规则只是概率恒等式 |
| 忽略归一化常数 | **错**。$P(B)$ 保证后验求和为 1；在 BN 推断中 $P(B)$ 常需对隐变量求和（这正是"推断难"的来源） |

## 8. 检索练习（闭卷自检）

### #自测题/基础
1. 写出贝叶斯规则，并说明每一项的术语名称。
2. 用链式法则展开 $P(A, B, C, D)$（任意顺序）。

### #自测题/中等
3. 已知 $P(D)=0.02$，$P(T\mid D)=0.9$，$P(T\mid \bar D)=0.1$，求 $P(D\mid T)$。
4. 证明：$X \perp\!\!\!\perp Y \mid Z$ 等价于 $P(X \mid Y, Z) = P(X \mid Z)$。

### #自测题/较难
5. 构造随机变量使 $X \perp\!\!\!\perp Y$，但 $X \not\perp\!\!\!\perp Y \mid Z$；再构造使 $X \not\perp\!\!\!\perp Y$ 但 $X \perp\!\!\!\perp Y \mid Z$。解释两者分别对应哪种图结构（分叉/汇连）。

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. $P(A\mid B) = \dfrac{P(B\mid A)P(A)}{P(B)}$；先验/似然/后验/证据。
2. $P(A)P(B\mid A)P(C\mid A,B)P(D\mid A,B,C)$。
3. $P(D\mid T) = \dfrac{0.9 \times 0.02}{0.9\times 0.02 + 0.1\times 0.98} = \dfrac{0.018}{0.116} \approx 0.155$。
4. $P(X\mid Y,Z) = \dfrac{P(X,Y,Z)}{P(Y,Z)} = \dfrac{P(X\mid Z)P(Y\mid Z)P(Z)}{P(Y\mid Z)P(Z)} = P(X\mid Z)$。
5. 例一：$X,Y$ 独立、$Z=X\oplus Y$（汇连，观测孩子激活依赖）；例二：$Z$ 为 $X,Y$ 公共父节点（分叉，给定父亲后子女独立）。
</details>
