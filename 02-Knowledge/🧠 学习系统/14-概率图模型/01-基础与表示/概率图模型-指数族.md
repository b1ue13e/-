# 概率图模型-指数族分布

> 指数族（Exponential Family）把伯努利、高斯、多项、泊松等常见分布统一成一种形式。它有两个 PGM 中的关键作用：**变分推断**（阶段 2）假设变分分布来自指数族以简化 ELBO 优化；**共轭先验**（阶段 3）让贝叶斯参数学习有闭式更新。理解指数族 = 理解"为什么这么多模型能统一处理"。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：每个分布各有各的公式和参数化（伯努利用 $p$，高斯用 $\mu, \sigma$），每次推导都要重新来。我们希望找到一种**统一形式**，让"取对数、求期望、算 KL、做 MAP"等操作对一大类分布**通用**。指数族就是这套统一框架。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：MFVI 的"平均场 + 指数族"假设让坐标上升有闭式解；EM 的 E 步计算后验期望在指数族下有简化；共轭先验让贝叶斯更新保持闭式。
- **实际应用场景**：LDA 主题模型（多项+Dirichlet）、GMM（高斯）、贝叶斯网络的 CPT（多项）。
- **高频考点**：写出分布的指数族形式、识别自然参数/充分统计量/对数配分函数、共轭关系。

## 4. 定义与核心公式

### 4.1 指数族的一般形式

**定义**：分布族 $\{p_\theta\}$ 是指数族，若

$$p(x \mid \theta) = h(x) \exp\!\Big( \langle \eta(\theta), T(x) \rangle - A(\theta) \Big)$$

其中：
- $T(x)$：**充分统计量**（sufficient statistic）；
- $\eta(\theta)$：**自然参数**（natural parameter）；
- $A(\theta)$：**对数配分函数**（log-partition function），保证归一化：
$$A(\theta) = \log \int h(x) \exp(\langle \eta(\theta), T(x)\rangle) dx$$

**规范形式**：把 $\eta$ 直接作为参数写为

$$p(x \mid \eta) = h(x) \exp\big( \eta^\top T(x) - A(\eta) \big)$$

### 4.2 常见分布示例

| 分布 | $h(x)$ | $T(x)$ | $\eta$ | $A(\eta)$ |
|:---|:---|:---|:---|:---|
| Bernoulli | $1$ | $x$ | $\log\frac{p}{1-p}$ | $\log(1+e^\eta)$ |
| Gaussian（固定 $\sigma^2$） | $\frac{1}{\sqrt{2\pi}\sigma}e^{-x^2/2\sigma^2}$ | $x$ | $\mu/\sigma^2$ | $\frac{\eta^2\sigma^2}{2}$ |
| Multinomial | $1$ | one-hot $\mathbf{x}$ | $\log p$（去冗余） | $\log \sum e^{\eta_i}$ |

### 4.3 关键性质

**性质 1（期望即导数）**：$\mathbb{E}[T(x)] = \nabla_\eta A(\eta)$，$\mathrm{Cov}[T(x)] = \nabla^2_\eta A(\eta)$。
**性质 2（充分性）**：$T(x)$ 携带关于 $\theta$ 的全部信息；给定 $T(x)$ 后 $x$ 与 $\theta$ 条件独立。
**性质 3（共轭）**：指数族的似然 $\times$ 同族先验 $\Rightarrow$ 后验仍在同一族（自然参数相加）：

$$p(\theta \mid \mathbf{x}) \propto p(\theta) \prod p(x_i \mid \theta) = h'\exp\big(\eta^\top \sum T(x_i) - nA(\eta) + \eta_0^\top T(\theta)\big)$$

**性质 4（KL 与变分）**：对指数族变分分布 $q$，ELBO 中的 $-\mathbb{E}_q[\log q]$ 有闭式（熵 $= \eta^\top \nabla A(\eta) - A(\eta)$），这正是 MFVI 可优化的关键。

---

## 5. 关键推导

**推导：伯努利的指数族形式**。

$p(x\mid p) = p^x(1-p)^{1-x} = \exp\big(x\log p + (1-x)\log(1-p)\big)$
$= \exp\big( x \log\frac{p}{1-p} + \log(1-p) \big)$
对照 $h(x)=1$，$T(x)=x$，$\eta = \log\frac{p}{1-p}$，$A = -\log(1-p) = \log(1+e^\eta)$。∎

**推导：$\mathbb{E}[T] = \nabla A$**（一维示意）。

$\int p_\eta(x) dx = 1 \Rightarrow \nabla_\eta \int h e^{\eta T - A} dx = 0$
$\Rightarrow \int h e^{\eta T - A}(T - \nabla A) dx = 0 \Rightarrow \mathbb{E}[T] - \nabla A = 0$。∎

**推导：高斯（固定方差）指数族**。

$\log p = -\frac{(x-\mu)^2}{2\sigma^2} - \log(\sqrt{2\pi}\sigma) = \frac{\mu}{\sigma^2}x - \frac{x^2}{2\sigma^2} - \frac{\mu^2}{2\sigma^2} - \log(\sqrt{2\pi}\sigma)$
取 $T(x)=x$，$\eta = \mu/\sigma^2$，$h(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-x^2/2\sigma^2}$，$A(\eta) = \eta^2\sigma^2/2$。∎

---

## 6. 最小可手算例子

**例 1（共轭更新）**：伯努利似然 + Beta 先验（Beta 是指数族的广义成员）。
先验 $\text{Beta}(\alpha_0, \beta_0)$，观测 $N$ 次成功 $s$ 次。后验 $\text{Beta}(\alpha_0 + s, \beta_0 + N - s)$——参数直接相加，闭式。

**例 2（期望即导数）**：Bernoulli，$A(\eta) = \log(1+e^\eta)$。
$\frac{dA}{d\eta} = \frac{e^\eta}{1+e^\eta} = p = \mathbb{E}[X]$ ✓（与 $p = \text{sigmoid}(\eta)$ 一致）。

**例 3（MFVI 熵）**：$q$ 为 Bernoulli，$\eta_q$ 自然参数。
$H(q) = \eta_q \frac{e^{\eta_q}}{1+e^{\eta_q}} - \log(1+e^{\eta_q})$，代入即可得闭式——变分推断里每个坐标的更新都用这个。

---

## 7. 反例与常见误区

| 误区 | 反例/纠正 |
|:---|:---|
| 指数族 = 指数分布 | **错**。指数分布只是成员之一；伯努利、高斯、泊松、多项都是 |
| 充分统计量总是一维 | **错**。$T(x)$ 可以是向量（如高斯 $\{x, x^2\}$） |
| 对数配分函数可以随便写 | **错**。$A$ 由归一化唯一确定，且必须是凸函数（保证归一性） |
| 共轭先验对所有分布存在 | **错**。只有指数族对指数族有自然共轭；非指数族通常没有简单共轭 |
| 指数族假设限制模型能力 | **不精确**。指数族足够广（覆盖常见分布），但确实不包括所有分布（如均匀分布非指数族的一般形式） |

## 8. 检索练习（闭卷自检）

### #自测题/基础
1. 写出指数族的一般形式，标注每个符号的含义。
2. 将 Bernoulli 写成指数族形式，求出 $\eta$ 与 $A(\eta)$。

### #自测题/中等
3. 推导 $\mathbb{E}[T(x)] = \nabla_\eta A(\eta)$ 的主要步骤。
4. 高斯（固定 $\sigma^2$）的充分统计量是什么？为什么？

### #自测题/较难
5. 解释：为什么"变分分布取指数族"能让 MFVI 的坐标更新有闭式解？（提示：结合熵的闭式与 ELBO 分解）

<details>
<summary>答案（先闭卷作答再展开）</summary>

1. $p(x\mid\eta) = h(x)\exp(\eta^\top T(x) - A(\eta))$；$T$ 充分统计量、$\eta$ 自然参数、$A$ 对数配分函数、$h$ 基测度。
2. $h=1$，$T(x)=x$，$\eta=\log\frac{p}{1-p}$，$A=\log(1+e^\eta)$。
3. 对 $\int p_\eta dx = 1$ 两边关于 $\eta$ 求导，交换积分与求导，得 $\mathbb{E}[T]-\nabla A = 0$。
4. $T(x)=x$（固定 $\sigma^2$ 时 $x^2$ 项并入 $h$）；样本均值是充分统计量。
5. ELBO $= \mathbb{E}_q[\log p(x,z)] - \mathbb{E}_q[\log q]$；第二项（$q$ 的熵）对指数族有闭式 $\eta_q^\top \nabla A(\eta_q) - A(\eta_q)$，第一项在指数族联合分布下是 $T$ 的线性函数，故对 $\eta_q$ 求导得闭式更新——这就是 CAVI/MFVI 的解析步骤。
</details>
