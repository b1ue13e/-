# 概率图模型-贝叶斯网络 (Bayesian Network)

## 1. 贝叶斯网络的定义与有向无环图 (DAG) 因子化

**贝叶斯网络 (Bayesian Network)** 的核心定义是：一种基于**有向无环图 (Directed Acyclic Graph, DAG)** 结构表达随机变量集合间因果/依赖关系及其联合概率分布的概率图模型。由 Judea Pearl 于 1985 年提出，并因此荣获 2011 年图灵奖。

**基本性质与链式因子分解定理**：
设贝叶斯网络节点集合为 $X = \{X_1, X_2, \dots, X_n\}$，$\text{Pa}(X_i)$ 表示节点 $X_i$ 的父节点集合。贝叶斯网络通过局部条件概率分布 (CPD) 将联合概率分布唯一**链式因子分解**为：

$$P(X_1, X_2, \dots, X_n) = \prod_{i=1}^n P(X_i \mid \text{Pa}(X_i))$$

这一性质极大地简化了高维联合分布的存储与推理，将参量数目从指数级 $O(2^n)$ 降至仅与父节点最大度数相关的 $O(n 2^k)$。

## 2. d-分隔 (d-Separation) 条件独立性三态形式化推导

为了在贝叶斯网络中判断给定观测子集 $\mathbf{Z}$ 下，两个节点子集 $\mathbf{X}$ 与 $\mathbf{Y}$ 是否条件独立（$\mathbf{X} \perp \mathbf{Y} \mid \mathbf{Z}$），Pearl 推导出了 **d-分隔 (d-Separation)** 准则的三种基本拓扑结构：

**三种基本拓扑推导**：
1. **顺连结构 (Tail-to-Head: $X \to Z \to Y$)**：
   $$P(X,Y,Z) = P(X) P(Z|X) P(Y|Z) \Rightarrow P(X,Y \mid Z) = \frac{P(X,Y,Z)}{P(Z)} = P(X|Z) P(Y|Z)$$
   **结论**：若 $Z$ 未被观测，通路连通；若 $Z$ **已被观测，通路阻断 (独立)**。
2. **分叉结构 (Tail-to-Tail: $X \leftarrow Z \to Y$)**：
   同理可推导 $P(X,Y \mid Z) = P(X|Z) P(Y|Z)$。
   **结论**：若 $Z$ **已被观测，通路阻断 (独立)**。
3. **汇合结构 / V-型结构 (Head-to-Head: $X \to Z \leftarrow Y$)**：
   $$P(X,Y,Z) = P(X) P(Y) P(Z|X,Y)$$
   **结论**：若 $Z$（及 $Z$ 的所有子孙节点）**未被观测，通路天然阻断 (独立)**；反之，一旦 $Z$ 或其子孙**已被观测，通路激活 (不独立)**（Explain-Away 解释消除现象）。

## 3. 贝叶斯网络 (有向) 与 马尔可夫随机场 (无向) 对比

| 维度 | 贝叶斯网络 (Bayesian Network) | 马尔可夫随机场 (MRF) |
|:---|:---|:---|
| **图结构** | **有向无环图 (DAG)** | 无向图 (Undirected Graph) |
| **因子化形式** | **条件概率乘积** $\prod P(X_i \mid \text{Pa}_i)$ | 团势函数乘积 $\frac{1}{Z}\prod \psi_C$ |
| **归一化开销** | **$Z=1$ 天然归一** (无需计算配分函数) | 需要计算全图配分函数 $Z$ |
| **条件独立判定** | **d-分隔 (d-Separation)** 规则 | 全局图分割 (Graph Cut) |
| **因果关系表达** | **适合建模因果关系 (Causality)** | 适合建模无向对称相互作用 |

**局限（误区与反例）**：贝叶斯网络绝对禁止包含环路（有向环）；此外，并非所有无向图表达的条件独立性都能用贝叶斯网络无损表达（反之亦然），两者表达能力互有交叉。

## 4. Python 贝叶斯网络 (V-Structure) 条件独立性自测断言

```python
import numpy as np

def simulate_v_structure(n_samples: int = 100000) -> tuple:
    """
    仿真 V-型结构: X -> Z <- Y (硬币X, 警报器Z, 盗贼Y)
    X ~ Bernoulli(0.5), Y ~ Bernoulli(0.5)
    Z = X OR Y
    """
    np.random.seed(42)
    x = (np.random.rand(n_samples) < 0.5).astype(int)
    y = (np.random.rand(n_samples) < 0.5).astype(int)
    z = (x | y).astype(int)
    return x, y, z

if __name__ == "__main__":
    x, y, z = simulate_v_structure()

    # 1. 在 Z 未被观测时，X 与 Y 边缘独立 P(X, Y) == P(X)P(Y)
    p_x1 = np.mean(x == 1)
    p_y1 = np.mean(y == 1)
    p_x1_y1 = np.mean((x == 1) & (y == 1))
    assert abs(p_x1_y1 - (p_x1 * p_y1)) < 1e-3, "未观测 Z 时 X 与 Y 必须边缘独立"

    # 2. 当 Z 已被观测 (例如 Z=1 警报响了)，X 与 Y 不再独立 (Explain-Away 现象)
    z1_mask = (z == 1)
    p_x1_given_z1 = np.mean(x[z1_mask] == 1)
    p_x1_given_z1_y1 = np.mean(x[z1_mask & (y == 1)] == 1)

    # 如果知道 Y=1 (已知有盗贼)，X=1 (硬币误触发) 的概率显著下降
    assert p_x1_given_z1_y1 < p_x1_given_z1, "观测 Z 后知道 Y=1 应降低 X=1 概率 (Explain-Away)"

    print(f"V-型结构未观测 Z 时: P(X=1,Y=1)={p_x1_y1:.4f} approx P(X)*P(Y)={p_x1*p_y1:.4f}")
    print(f"观测 Z=1 后: P(X=1|Z=1)={p_x1_given_z1:.4f}, P(X=1|Z=1,Y=1)={p_x1_given_z1_y1:.4f}")
    print("贝叶斯网络 (V-Structure d-Separation) 单元测试与自查验证全部成功！")
```
