# 🗺️ 随机过程学习路径

> **学习者任务**：从“如何描述一族随时间变化的随机变量”出发，依次掌握平稳过程、Markov/Poisson/排队过程、Brownian/鞅与 Itô/SDE，最终提交一份理论、模拟和失败边界都可复核的随机系统分析。

## 课程目标

完成本路线后，你应能：

1. 用样本路径、有限维分布、均值与协方差描述随机过程，并区分严格平稳和宽平稳。
2. 分析离散与连续时间 Markov 链的转移、状态分类、平稳分布和生成元。
3. 从 Poisson 到达、指数等待和更新结构建立排队模型，并判断稳态是否存在。
4. 解释 Brownian 运动的独立增量、反射原理与二次变差，使用鞅和停时处理条件期望。
5. 构造 Itô 积分，使用 Itô 公式、生成元和 SDE 模型，并审计 Euler-Maruyama 模拟误差。
6. 在模拟中固定随机种子、比较理论量与经验量、保留不稳定或不收敛结果。

## 最低前置与启动门

- **概率**：联合分布、条件概率、期望、方差、独立性和大数定律。
- **分析**：理解可测性、几乎处处、积分与极限交换的条件；进阶阶段需要 $L^2$ 语言。
- **线性代数**：矩阵乘法、特征值/特征向量和线性方程组。
- **编程**：能运行 Python 脚本、阅读断言和保存 JSON/CSV 结果。
- **启动诊断**：先进入[[🧭 随机过程-前置知识]]。三张桥接卡的闭卷任务和作业 00 未通过时，只回补缺口，不进入阶段 1。
- **来源事实源**：版本、许可证、覆盖和排除范围只在[[📚 教材挂载索引]]维护。
- **作业事实源**：课后、阶段和 capstone 只在[[🧭 课程作业总索引]]及其 frontmatter 维护；阶段 MOC 只负责顺序和出口。

## 课程边界

本路线覆盖一学期“离散过程 + 连续随机分析”的核心闭环，不展开大偏差、一般状态空间 Markov 过程、随机偏微分方程、Girsanov 定理和高阶数值格式。这些主题只有在大作业确有需要时再进入后续课程。

## 有序阶段

1. [[🧭 随机过程-前置知识]]：补齐条件期望/滤过、$L^2$/收敛和非负矩阵三条最短支架。
2. [[🧭 阶段1-过程描述与平稳性]]：建立过程对象、有限维分布、平稳性和 Gaussian/随机游走例子。
3. [[🧭 阶段2-马尔可夫泊松与排队]]：从转移核到 Poisson、CTMC 和 M/M/1 排队。
4. [[🧭 阶段3-布朗运动与鞅]]：用二次变差、鞅与停时进入连续随机分析。
5. [[🧭 阶段4-Ito微积分与随机微分方程]]：构造随机积分、使用 Itô 公式并完成 SDE 数值实验。

## 阶段产出与通过门

| 阶段 | 可观察产出 | 进入下一阶段的门槛 |
| :--- | :--- | :--- |
| 前置 | 三份闭卷诊断和一个可运行环境自检 | 关键定义正确，矩阵与条件期望手算无硬错误 |
| 1 | 一组过程描述、平稳性判别和样本路径对照 | 课后作业与阶段作业均 ≥80，能给出反例 |
| 2 | Markov/Poisson/CTMC/排队的理论量与模拟量对照 | 确认转移、稳态与负载条件，不把有限样本当证明 |
| 3 | Brownian 路径与停时问题的证明—模拟双证据 | 可选停止条件写全，二次变差与普通变差不混淆 |
| 4 | SDE 解析检查、数值误差实验和跨阶段报告 | 阶段作业 ≥80；大作业 ≥85 且无硬失败 |

## 复习与回收节奏

- 每张卡学完后先闭卷完成“检索练习”，再查看正文纠错。
- 每个阶段结束后做一次 30 分钟混合回顾：定义复述、最小手算、反例和一段代码检查。
- 阶段 2 结束回看阶段 1 的平稳性；阶段 4 结束回看阶段 3 的鞅与二次变差。
- 错误按“概念、条件、计算、模拟协议”分类，真实薄弱点进入 `04-Review/`，不在课程目录复制第二套错题导航。

课程只有在以下条件同时成立时才算完成：

- 五个阶段的知识卡、课后作业和阶段作业均完成；阶段 3/4 的 Brownian、鞅、Itô 和 SDE 卡必须出现非空的作业派生入口；
- 大作业达到 85/100，且来源、稳定性、随机种子、失败案例和复现命令无硬失败；
- 能在不看笔记时解释“有限维分布 → Markov/Poisson → Brownian/鞅 → Itô/SDE”的依赖链；
- 当前 C 级维护复评通过不等于正式发布；正式发布仍需 A/B 级独立验收。
