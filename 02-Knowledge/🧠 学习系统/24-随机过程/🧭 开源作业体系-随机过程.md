# 🧭 开源作业体系-随机过程

> 本页是「随机过程」开源名校课程与作业的**唯一挂载点**：教材主线、作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**[QuantEcon Python Lectures](https://python.quantecon.org/)（Markov 链、动态规划、Monte Carlo）** + **MIT 6.011 Signals, Systems and Inference（OCW Spring 2018，验收口径）**。

## 🎯 作业体系（HW01-HW05）

| HW | 主题 | 官方来源（口径） | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 有限 Markov 链：转移矩阵与样本轨道 | QuantEcon Markov Chains 讲座 | 待补卡（转移矩阵、轨道模拟） | 模拟轨道 + 经验频率对照转移概率 |
| HW02 | 平稳分布与遍历性 | QuantEcon | 待补卡（平稳分布、不可约、非周期、遍历定理） | 幂迭代求平稳分布 + 收敛诊断 |
| HW03 | 泊松过程与排队 | 6.011 推断口径 + QuantEcon | 待补卡（泊松过程、指数分布无记忆性、M/M/1） | 事件计数模拟 + Little 律验证 |
| HW04 | 布朗运动与 Monte Carlo | QuantEcon Monte Carlo 讲座 | 待补卡（布朗运动性质、随机模拟方差） | 布朗路径模拟 + 方差缩减对照 |
| HW05 | 动态规划初步（接量化金融） | QuantEcon Dynamic Programming | 待补卡（Bellman 方程、值迭代） | 值迭代求解最小例 + 收敛曲线 |

> 分层验收原则：HW01-02 是 Markov 链主线（模拟 → 稳态）；HW03 切换到计数过程；HW04-05 打通连续噪声与动态规划，为 03-量化金融 的 SDE/动态最优化铺路。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷推导（如平稳分布方程组、无记忆性证明）；② Python 模拟（固定随机种子，含 assert）；③ 1 页报告（模拟 vs 理论 + 失败案例）。
2. **模拟验证要求**：HW02 必须同时给出幂迭代收敛曲线与轨道频率对照；HW04 布朗路径需验证增量独立性与二次变差 ≈ T。
3. **数据来源**：自模拟数据 + QuantEcon 案例数据。
4. **满分 Rubric**：HW01-05 各 20 分，共 100 分（推导 30 + 实现 40 + 报告 30）。
