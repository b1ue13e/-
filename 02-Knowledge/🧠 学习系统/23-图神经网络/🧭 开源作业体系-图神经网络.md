# 🧭 开源作业体系-图神经网络

> 本页是「图神经网络」开源名校课程与作业的**唯一挂载点**：教材主线、官方作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**Stanford CS224W (Machine Learning with Graphs)**（http://web.stanford.edu/class/cs224w/）+ **Graph Representation Learning**（https://www.cs.mcgill.ca/~wlh/grl_book/，author PDF；official-free）+ **PyG (PyTorch Geometric)** 实验框架（https://github.com/pyg-team/pytorch_geometric，MIT）。

## 📚 教材主线（Spine）

| 角色 | 来源 | 用途 |
|:---|:---|:---|
| 主教材 | [Graph Representation Learning (Hamilton)](https://www.cs.mcgill.ca/~wlh/grl_book/) | 图嵌入传统方法 → GNN 消息传递 → 实际应用；每章对应一个 HW 主题 |
| 官方课程 | [Stanford CS224W](http://web.stanford.edu/class/cs224w/)（含 colab 作业） | 节点/边/图级别任务的官方作业链 HW01-HW05 |
| 实验工具 | [PyTorch Geometric (PyG)](https://github.com/pyg-team/pytorch_geometric) | 图数据加载、消息传递层、模型训练；与 OGB 数据集对接 |
| 数据集 | [Open Graph Benchmark (OGB)](https://ogb.stanford.edu/) | 标准化节点/边/图分类基准；HW 验收口径 |
| 互补 | 01-社交网络挖掘 [[Networks, Crowds, and Markets]] | 图论与网络科学基础，与 GNN 形成"基础 → 深度"双线 |

**Honor Code 说明**：CS224W 官方 Colab 作业可参考（注明来源），但**实现必须自己完成**；PyG 官方教程可学习 API，但禁止直接调库当作自写实现提交；OGB 数据集按官方划分（train/val/test）使用，禁止跨划分合并训练。

## 🎯 作业体系（HW01-HW05）

| HW | 主题 | 官方来源 | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | Node2Vec / DeepWalk 节点嵌入 | CS224W Colab 1 + GRL Ch.3 | 待补卡（随机游走、Node2Vec、负采样） | OGB-Arxiv 节点分类；与 Spectral Embedding 对照 |
| HW02 | GCN 图卷积网络 | CS224W Colab 2 + GRL Ch.5 | 待补卡（GCN、谱图卷积） | Cora/Citeseer 节点分类；与 Node2Vec 对照 |
| HW03 | GraphSAGE 与消息传递 | CS224W Colab 3 + GRL Ch.5 | 待补卡（消息传递、邻居采样、归纳式学习） | OGB-Arxiv + OGB-Products 归纳式测试 |
| HW04 | GAT 注意力图网络 | CS224W Colab 4 | 待补卡（图注意力、多头注意力） | 同上数据集 + 注意力权重可视化 |
| HW05 | 图分类与读出 (Readout) | CS224W Colab 5 + GRL Ch.6 | 待补卡（图分类、Sum/Mean/Max Readout） | OGB-MolHIV/MolPCBA 图分类；与 FP/GNN 基线对照 |

> 分层验收原则：HW01 是**传统嵌入基线**（不依赖 GNN，必须先完成）；HW02-04 是**消息传递家族**（GCN → GraphSAGE → GAT，每步一卡一实验）；HW05 是**图级任务收尾**（含 OGB 官方排行榜口径）。

## ✅ 验收方式与评分

1. **每个 HW 统一三件套**：① PyG 实现（自己写消息传递类，不得直接调 `GCNConv` 预定义层）；② OGB 官方划分训练；③ 1 页报告（loss 曲线 + 与 baseline 对照 + 失败案例）。
2. **OGB 官方提交**：每个 HW 报告 OGB 排行榜得分（train/val/test），禁止过拟合 test。
3. **可视化证据**：HW01 节点嵌入 t-SNE 图、HW04 注意力热图、HW05 图分类 confusion matrix。
4. **满分 Rubric**：HW01-05 各 20 分，共 100 分（实现 50 + 报告 30 + OGB 排名 20）。
