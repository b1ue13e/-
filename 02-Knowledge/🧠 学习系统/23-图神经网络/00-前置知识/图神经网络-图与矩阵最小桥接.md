# 图神经网络-图与矩阵最小桥接

## 1. 这张卡解决什么问题

GNN 不是把“图”当作一张图片，而是把节点、边和节点特征写成可运算对象。若不能从一组边恢复 `A`、`D` 和 `L`，后面的 GCN 归一化传播就只能死记公式。

## 2. 正式对象与符号

设无向简单图为 `G=(V,E)`，节点数为 `n`。

- 邻接矩阵 `A∈R^{n×n}`：`A_ij=1` 表示 `(i,j)∈E`，无边为 0；有权图把 1 换成边权。
- 度矩阵 `D=diag(d_1,…,d_n)`，其中 `d_i=Σ_j A_ij`。
- 未归一化拉普拉斯 `L=D-A`。
- 加自环邻接 `\tilde A=A+I`，加自环度矩阵 `\tilde D_ii=Σ_j\tilde A_ij`。
- 对称归一化传播算子 `S=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}`。

无向图的 `A`、`D`、`L` 对称；有向图需要先说明消息方向，不能直接套用无向公式。

## 3. 为什么拉普拉斯值得记住

对任意节点信号 `x∈R^n`：

$$x^T Lx=\frac12\sum_{i,j}A_{ij}(x_i-x_j)^2=\sum_{(i,j)∈E}(x_i-x_j)^2$$

它把“相邻节点信号应该平滑”写成了一个能量。能量小，说明相邻节点值接近；这正是图滤波和消息传递的谱直觉。这里的结论依赖 `A` 对称且无向边被计数两次，换成有向图不能直接照搬。

## 4. 最小手算例

对路径 `0—1—2`：

```text
A = [[0,1,0],
     [1,0,1],
     [0,1,0]]
D = diag(1,2,1)
L = [[ 1,-1, 0],
     [-1, 2,-1],
     [ 0,-1, 1]]
```

若 `x=[0,1,3]^T`，则边差异平方和为 `(0-1)^2+(1-3)^2=5`，直接计算 `x^T Lx` 也应为 5。这个等式是后续检查矩阵实现的 oracle，不是“看起来差不多”的直觉。

## 5. 最小可运行检查

```python
import numpy as np

A = np.array([[0., 1., 0.], [1., 0., 1.], [0., 1., 0.]])
x = np.array([0., 1., 3.])
D = np.diag(A.sum(axis=1))
L = D - A
energy = float(x @ L @ x)
edge_energy = float((x[0] - x[1]) ** 2 + (x[1] - x[2]) ** 2)
assert np.isclose(energy, edge_energy)
print(energy)
```

输出应为 `5.0`。如果不是，先检查边是否重复计数、`D` 是否由同一份 `A` 生成，以及节点编号是否错位。

## 6. 概念边界与常见错法

- `A` 记录连接，`D` 记录每个节点的总权重，`L` 不是“另一个邻接矩阵”。
- `D^{-1}A` 是随机游走归一化，`D^{-1/2}AD^{-1/2}` 是对称归一化；二者都不是无条件可互换。
- 加自环会把自身特征纳入传播，度数也必须同步加一。
- 拉普拉斯的零特征值个数与连通分量有关，但“特征向量就是节点类别”是错误的。

## 7. 检索练习与通过标准

1. 对星形图写出 `D`、`L` 和一行 `D^{-1}A`；解释中心节点为何被平均更多邻居。
2. 说明加自环后路径中间节点的归一化权重如何变化。
3. 闭卷写出 `x^TLx` 的边差异形式，并指出需要的图假设。

通过标准：三题全对；代码断言通过；能解释为什么 GCN 使用对称归一化而不是直接把 `A` 乘上特征。
