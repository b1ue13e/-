# 图神经网络-图学习评估与无泄漏划分

## 1. 这张卡解决什么问题

图上的样本不是独立同分布的行。节点之间的边本身就是信息，因此“随机切行”不一定等于公平测试。本卡先固定协议，再谈模型分数。

## 2. 两种学习协议

- **Transductive**：训练时可看到整张图的结构和无标签节点特征，但只能使用训练标签更新参数；测试节点已经在同一张图中。
- **Inductive**：测试节点或整张测试图在训练时不可见；消息传递图、特征和标签边界必须写清楚。

同一个节点分类模型在两种协议下不能直接横比。报告必须写出：可见节点、可见边、标签可见范围、训练/验证/测试掩码。

## 3. 最小切分契约

节点分类：`train_mask`、`val_mask`、`test_mask` 两两不交并覆盖声明的节点集合；训练阶段只对 `train_mask` 计算 loss。

链路预测：先冻结正边的 train/val/test 划分，再从不存在的边中采负例；测试边不能留在训练消息传递图中，除非明确声明这是 transductive 结构可见协议，并解释任务定义。

时间图：按时间排序切分，任何特征工程只能使用预测时刻之前的信息。不能看到未来边后再构造当前节点特征。

## 4. 指标选择

- Accuracy 适合类别大致平衡的节点分类，不适合稀有正例。
- ROC-AUC 衡量正负排序的整体能力；极度不平衡时仍需报告 PR-AUC/AP。
- AP 是按预测排序累积精确率的平均，链路预测通常比 accuracy 更有解释力。
- 任何指标都必须报告 split、随机种子、正负样本构造和置信区间/多种子波动；只报最佳种子不算证据。

## 5. 最小泄漏审计伪代码

```python
def assert_disjoint(train, valid, test):
    assert not (set(train) & set(valid))
    assert not (set(train) & set(test))
    assert not (set(valid) & set(test))

def assert_test_edges_hidden(train_edges, test_edges):
    assert set(train_edges).isdisjoint(test_edges)
```

这两个断言只检查集合关系，不能证明所有特征都无泄漏；报告仍需说明邻居聚合图和时间窗口。

## 6. 反例与常见误区

1. 在全图上先做随机游走，再按节点随机切分：测试节点的结构信息已经进入 embedding，不能称为严格 inductive。
2. 用 test AP 选择 `hidden_dim`：即使模型没有直接读取 test label，也把测试集用于模型选择。
3. 负例从 train/val/test 正边混合采样：评价口径不可复现，且可能把未来正边当负例。

## 7. 检索练习与通过标准

- 给出一个节点分类和一个链路预测任务，分别写出可见的结构、特征、标签边界。
- 解释为什么“全图结构可见但测试标签不可见”仍可能是合法 transductive 设置。
- 对一份 split manifest 做三组不交断言，并指出它还缺少哪条特征时间审计。

通过标准：能审阅作业中的 split，不把高分自动解释成泛化；能在报告中明确协议而不是只写 `train/val/test` 三个词。
