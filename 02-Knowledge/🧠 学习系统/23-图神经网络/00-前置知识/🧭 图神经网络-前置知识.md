# 🧭 图神经网络-前置知识

> 这里不是“建议会一点”的愿望清单，而是进入 GNN 主线前必须能做出的最小动作集合。先完成诊断，再进入阶段 1。

## 为什么现在学

GNN 的公式同时使用图的邻接结构、矩阵归一化、张量运算和训练/评估协议。缺任一层，学习者都会把“消息传递”“参数更新”和“测试指标”混成一句口号。三张桥接卡只补本课程需要的最小深度，不复制上游课程。

## 有序前置卡

1. [[图神经网络-图与矩阵最小桥接]]：能从边列表写出邻接矩阵、度矩阵、拉普拉斯和归一化传播算子。
2. [[图神经网络-PyTorch张量与分类训练最小桥接]]：能读写张量形状，计算交叉熵并完成一次参数更新。
3. [[图神经网络-图学习评估与无泄漏划分]]：能区分 transductive/inductive，冻结 split，解释 accuracy、ROC-AUC 和 AP 的适用范围。

## 进入主线诊断

闭卷完成以下 6 项，至少 5 项正确；第 3 项必须通过，否则先回到对应桥接卡：

- [ ] 给出 3 个节点路径图的 `A`、`D` 和 `L=D-A`。
- [ ] 说明 `x^T L x` 为什么等于边差异平方和。
- [ ] 对 `logits.shape == (4, 3)` 和 `target.shape == (4,)` 写出交叉熵输入输出含义。
- [ ] 说清训练集、验证集、测试集各自允许做什么。
- [ ] 解释为什么在测试边仍存在于消息传递图中时，链路预测可能泄漏。
- [ ] 给出一个节点分类任务的最小提交产物：代码、固定 split、指标和失败案例。

## 最低通过标准

- 能手算路径图的归一化邻接矩阵的一行；
- 能运行两张桥接卡中的最小代码并解释输出形状；
- 能用自己的话区分“图结构可见”和“标签可见”；
- 未通过诊断前不进入 `[[🧭 阶段1-图表示与任务]]`。
