# 图神经网络-图自监督目标与增强

## 1. 问题动机

图标签经常少、贵或延迟。自监督方法从图自身构造训练信号，但“没有人工标签”不等于目标天然合理：增强可能破坏任务语义，负样本可能有假负例，下游指标仍必须独立评估。

## 2. 两类目标

### 对比目标

同一节点/图的两个视图作为正对，不同样本作为负对。InfoNCE 形式：

$$\mathcal L_i=-\log\frac{\exp(sim(z_i,z_i^+)/τ)}{\sum_j\exp(sim(z_i,z_j)/τ)}$$

视图可由边/节点丢弃、特征掩码或子图采样得到；每种增强都隐含“被删除信息不应决定任务”的假设。

### 掩码/重建目标

随机遮住节点特征、边或属性，让模型重建被遮住内容。它更像自编码器，评价的是重建目标，不自动保证下游分类更好。

DGI 通过局部节点表示与全局摘要的正负互信息式判别；GraphCL 对两种图增强后的图表示做对比。使用这些名字时要写清楚正负样本和 corruption 规则，不能只写“做自监督”。

## 3. 最小 InfoNCE 检查

```python
import torch

z1 = torch.tensor([[1., 0.], [0., 1.]])
z2 = torch.tensor([[1., 0.], [0., 1.]])
similarity = z1 @ z2.T
temperature = 0.5
labels = torch.arange(2)
loss = torch.nn.functional.cross_entropy(similarity / temperature, labels)
assert loss.item() >= 0.0
print(float(loss))
```

这段代码只验证 logits/label 对齐；真实实验必须对增强、batch 规模、温度、负样本范围和下游冻结协议做记录。

## 4. 增强的任务边界

- 节点分类可能允许删边，但药物键预测不能随意删关键化学键；
- 社交网络的节点特征掩码可能合理，时间图不能把未来特征掩成训练可见；
- 对比学习的负样本若来自同一语义类别，可能是假负例；
- 预训练表示必须和从头训练的 GNN 在相同 split、相同下游头和相同 seed 范围比较。

## 5. 常见错误

1. 用测试集参与增强策略选择。
2. 只报告预训练 loss 下降，不报告冻结/微调后的下游任务。
3. 把随机增强数量增加带来的 batch 变化当作模型改进。
4. 将 DGI、GraphCL、掩码节点重建写成一张无差别“自监督卡”。

## 6. 检索练习与通过标准

- 为节点分类、图分类分别设计一个不会明显破坏标签语义的增强和一个危险增强。
- 写出一个假负例场景，并说明如何改用 supervised contrastive 或 hard-negative 审计。
- 比较从头训练、冻结 encoder、全量微调三种下游协议。

通过标准：能写出 InfoNCE 的正负分母；能说明增强假设；下游报告包含至少一个无自监督基线和失败案例。
