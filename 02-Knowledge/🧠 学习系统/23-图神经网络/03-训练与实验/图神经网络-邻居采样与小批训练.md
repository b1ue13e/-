# 图神经网络-邻居采样与小批训练

## 1. 问题动机

全图 GCN 在中小图上简单，但大图的每个节点都展开多跳邻居会产生内存和计算瓶颈。小批训练把目标节点分批，再按每层 fanout 构造计算子图；代价是采样偏差、重复节点和边界协议更复杂。

## 2. 采样合同

对 `K` 层模型，目标 batch `B_0` 逐层采样 `B_1,…,B_K`。必须记录：

- `fanout=[s_1,…,s_K]` 和是否有放回；
- 采样概率/权重、随机种子、邻居去重策略；
- input nodes、output nodes、message-passing nodes 的索引关系；
- 训练/验证/测试是否使用同样的结构可见范围。

若只想评估目标节点，却把测试目标的标签或隐藏边用于采样概率，需要在协议中明确，否则就是泄漏。

## 3. 复杂度直觉

最坏节点数按 fanout 连乘增长；实际去重和图重叠会降低数量，但不能把一次观测当作稳定复杂度。报告应同时保存：目标节点数、采样后节点数、采样边数、峰值内存和每 batch 时间。

## 4. 采样与分区的区别

- Neighbor sampling：围绕目标节点随机展开，适合归纳/小批；
- Cluster-GCN：先把图分区，再在子图/簇上训练，减少跨簇边；
- GraphSAINT：按节点/边/随机游走采样子图，再做归一化；
- 稀疏张量：表示和计算格式，不等于采样算法。

名称相近但事实源不同，不能把“用了 sparse tensor”当作“完成了大规模训练”。

## 5. 最小可复现 sampler

```python
import random

neighbors = {0: [1, 2], 1: [0, 2], 2: [0, 1, 3], 3: [2]}
rng = random.Random(42)
targets = [0, 2]
fanout = 2
sampled = {v: rng.sample(neighbors[v], min(fanout, len(neighbors[v]))) for v in targets}
assert set(sampled) == set(targets)
print(sampled)
```

作业中把这个 dict 换成张量索引并测试 parent-child 映射；不能依赖 Python dict 顺序来定义模型语义。

## 6. 常见错误

1. 验证/测试阶段仍随机采样却不固定 seed，导致每次指标不可比。
2. 采样后只保留目标节点特征，丢掉中间层的邻居节点。
3. 在每 batch 独立标准化特征，改变了训练/验证分布。
4. 用采样后的一个 batch 报告“全图性能”，没有覆盖目标节点或报告采样方差。

## 7. 检索练习与通过标准

- 给 `B=8,K=3,fanout=[10,5,5]` 估算最坏读取数，并说明去重为何不能预先假定。
- 设计一个验证阶段固定采样的 manifest 字段。
- 比较 neighbor sampling 和 cluster sampling 各自适合的图结构。

通过标准：能画出一批目标节点的计算子图；能从日志读出 fanout、节点/边数和时间；测试结果至少重复 3 个 seed。
