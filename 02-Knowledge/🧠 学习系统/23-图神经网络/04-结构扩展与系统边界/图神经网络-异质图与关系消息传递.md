# 图神经网络-异质图与关系消息传递

## 1. 问题动机

在用户—商品—订单或论文—作者—机构图中，不同节点/边类型代表不同语义。把所有关系压成同一个邻接矩阵会让“购买”和“浏览”拥有相同传播含义，模型可能学到错误捷径。

## 2. 关系化消息

令 `r∈R` 表示关系类型，一个 R-GCN 风格更新为：

$$h_v^{(l+1)}=σ\left(\sum_{r∈R}\sum_{u∈N_r(v)}\frac{1}{c_{v,r}}W_r^{(l)}h_u^{(l)}+W_0^{(l)}h_v^{(l)}\right)$$

`W_r` 区分关系语义，`c_{v,r}` 控制归一化；关系数量大时参数共享/基分解可降低成本。节点类型也可能需要类型专属输入投影或共享空间映射。

## 3. 时间与标签边界

异质图的关系往往带时间。若用未来交易关系构造当前用户表示，离线分数会失真。每种关系都要写时间窗口、方向、是否可见和预测目标，不能只写一个全局 split。

## 4. 最小关系聚合检查

```python
import torch

h = torch.tensor([[1., 0.], [0., 1.], [1., 1.]])
relation_edges = {"buys": [(0, 1)], "views": [(0, 2)]}
W = {"buys": torch.eye(2), "views": 2 * torch.eye(2)}
messages = []
for relation, edges in relation_edges.items():
    for source, target in edges:
        messages.append((target, h[source] @ W[relation]))
assert len(messages) == 2
print(messages)
```

这段只验证关系不被混合；正式层还需按目标节点/关系归一化、处理反向边和稀疏 batch。

## 5. 与同质 GNN 的边界

- 同质 GNN：所有邻居共享同一消息函数，适合关系语义近似一致的图；
- R-GCN/HGT：关系/类型进入参数或 attention，表达更强但参数和稀疏模式更复杂；
- 知识图谱 embedding：常以三元组解码关系，未必使用局部消息传递；不要把二者当成同一个模型。

## 6. 常见错误

1. 把节点类型整数直接拼到连续特征，没有说明 embedding/投影。
2. 关系反向边重复计入却不记录，导致消息强度翻倍。
3. 关系数量多时为每种关系学习完整矩阵，忽略参数规模和低频关系过拟合。
4. 在异质关系中用单一 accuracy 掩盖少数关系类型完全失效。

## 7. 检索练习与通过标准

- 为用户—商品二部图写出两种关系消息方向，并说明预测时可见边。
- 估算关系数 `R=100`、隐藏维度 `d=64` 的完整矩阵参数量，提出共享方案。
- 设计按关系分组的错误分析表。

通过标准：能写出 relation-specific 更新；能说明时间/类型边界；代码能显示不同关系使用不同参数；报告按关系类型呈现指标。
