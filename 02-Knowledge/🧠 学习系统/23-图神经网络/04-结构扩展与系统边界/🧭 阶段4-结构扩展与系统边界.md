# 🧭 阶段4-结构扩展与系统边界

## 为什么现在学

核心 GNN 已经能在固定协议下完成实验。最后阶段不再堆“前沿名词”，而是观察结构复杂度如何改变消息函数、位置编码、复杂度和评估边界。每个扩展都必须回答：它解决哪个主线缺口，新增了什么假设，什么时候不该用。

## 学习顺序

1. [[图神经网络-异质图与关系消息传递]]：把节点/边类型显式纳入消息函数。
2. [[图神经网络-图Transformer与结构编码]]：比较稀疏局部 attention 与全局/结构编码的取舍。
3. [[图神经网络-大规模训练与线上评估边界]]：把采样、服务、延迟、漂移和错误分析串起来。

## 阶段产出

- 为一个异质图写出 relation-specific message contract。
- 对一个小图比较局部 GAT 与结构编码 attention 的复杂度和失效模式。
- 完成一个带固定预算的规模/延迟实验，明确不能外推到生产的部分。
- 使用 capstone reference 的失败节点和复杂模型无增益结果完成一次 kill/pivot 说明；reference 产物位于 `03-Projects/23-图神经网络/artifacts/capstone-reference/`。
- 先运行 S04 worked example 区分理论复杂度估算与实测延迟，再独立完成假设、资源与 kill 条件审计。
