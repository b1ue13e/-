# 图神经网络-随机游走与浅层节点嵌入

## 1. 问题动机

节点没有天然的欧氏坐标。随机游走把“哪些节点在局部上下文中共同出现”变成样本，再用 Skip-gram 学一个向量，使相近上下文的节点向量更容易互相预测。它是理解 GNN 表示学习目标的基线，不是 GCN 的替代品。

## 2. 随机游走

无权无向图上的一步转移矩阵为 `P=D^{-1}A`。从节点 `u` 出发，长度为 `T` 的游走是 `v_0=u,v_1,…,v_T`，每一步按 `P[v_t,v_{t+1}]` 抽样。列/行方向必须在实现中固定；本课程代码统一使用“行是当前节点、列是下一节点”的 `P_row`，避免与教材列向量约定混淆。

DeepWalk 在每个节点上采样多条均匀随机游走，再把窗口内节点当作上下文对。Node2Vec 在上一步节点和当前节点共同决定下一跳概率，通过 `p` 控制回退、`q` 控制 BFS/DFS 偏好；参数不是“越大越好”，必须在报告中说明结构假设。

## 3. Skip-gram 目标

给中心节点 `u` 和上下文节点 `v`，基本目标最大化：

$$\log P(v\mid u)=\log\frac{\exp(z_u^T z'_v)}{\sum_{w∈V}\exp(z_u^T z'_w)}$$

全量 softmax 成本高，负采样用若干噪声节点 `n` 近似：

$$\log σ(z_u^Tz'_v)+\sum_{n∈N^-}\log σ(-z_u^Tz'_n)$$

训练后可用 `z_u` 做节点分类、链路打分或可视化，但下游 split 必须独立于 embedding 训练协议。

## 4. 最小可运行游走统计

```python
import random
from collections import Counter

neighbors = {0: [1], 1: [0, 2], 2: [1, 3], 3: [2]}
rng = random.Random(7)
walk = [0]
for _ in range(6):
    current = walk[-1]
    walk.append(rng.choice(neighbors[current]))
counts = Counter(zip(walk, walk[1:]))
assert len(walk) == 7
assert sum(counts.values()) == 6
print(walk, dict(counts))
```

这段代码只验证游走协议和计数，不声称已经训练出高质量 embedding。真实作业还需固定每节点游走数、窗口、负采样分布、seed 和输出 manifest。

## 5. 与 GNN 的连接

- 随机游走 embedding：通常是节点 ID lookup，新增节点没有天然参数；
- 消息传递 GNN：共享局部聚合函数，可利用节点特征并在满足条件时归纳到新节点；
- 二者都把邻域关系转成表示，但一个主要通过上下文共现学习，一个通过可学习传播算子学习。

不要把“随机游走能看到多跳”误解为“它已经完成了可泛化的消息传递”。

## 6. 常见错误与边界

1. 把 `p/q` 当作无向图的边权；Node2Vec 的偏置依赖上一步节点，是二阶转移。
2. 在全图上训练 embedding 后再随机切分节点分类；这可能把测试结构信息带入表示，必须声明协议。
3. 只画 t-SNE 就宣布 embedding 有用；需要固定下游分类器、split、指标和随机种子。
4. 把共现矩阵的 SVD 结果称作“Node2Vec 训练结果”；它可以是结构基线，但算法与训练目标不同。

## 7. 检索练习与通过标准

- 对路径 `0—1—2` 写出 `P_row`，计算从 0 出发两步到 2 的概率。
- 说明窗口大小从 1 增到 3 会引入什么上下文，为什么可能损失局部结构。
- 用一句话比较 DeepWalk、Node2Vec 和 GNN 的参数共享/归纳能力。

通过标准：能写出转移矩阵和负采样目标；运行游走统计代码；报告中不把可视化当作独立效果证据。
