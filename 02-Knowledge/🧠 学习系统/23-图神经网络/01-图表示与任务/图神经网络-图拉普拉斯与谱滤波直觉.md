# 图神经网络-图拉普拉斯与谱滤波直觉

## 1. 从欧氏卷积转念到图滤波

在规则网格上，傅里叶变换把信号分解成频率，卷积在频域变成逐频率缩放。图没有统一坐标轴，但对称拉普拉斯 `L=UΛU^T` 提供一组由图结构决定的特征方向 `U`，可把节点信号 `x` 写成图傅里叶系数 `U^Tx`。

## 2. 正式定义

给定对称 `L` 的特征分解：

$$L=UΛU^T,\qquad \hat x=U^Tx$$

谱滤波器 `g_θ` 作用为：

$$g_θ\star x=U g_θ(Λ) U^T x$$

其中 `g_θ(Λ)` 对特征值逐项缩放。低特征值方向通常对应图上较平滑的信号；这是解释“邻居平均”而非证明所有任务都低频的直觉。

## 3. 为什么不能直接做完整特征分解

对 `n` 个节点，显式特征分解和稠密乘法成本高，且参数会依赖具体图的特征基，难以迁移到新图。Chebyshev 多项式近似用 `K` 阶 `L` 的多项式替代：

$$g_θ(L)x≈\sum_{k=0}^{K}θ_k T_k(\tilde L)x$$

只需反复稀疏矩阵乘向量；把 `K` 限制为 1 并做一阶近似，得到 GCN 的局部传播形式。这里“GCN 是谱近似的一个受限形式”，不等于所有消息传递都必须在谱域定义。

## 4. 最小数值检查

```python
import numpy as np

A = np.array([[0., 1., 0.], [1., 0., 1.], [0., 1., 0.]])
L = np.diag(A.sum(axis=1)) - A
eigenvalues, U = np.linalg.eigh(L)
x = np.array([0., 1., 3.])
reconstructed = U @ (U.T @ x)
assert np.allclose(reconstructed, x)
assert np.all(eigenvalues >= -1e-10)
print(np.round(eigenvalues, 6))
```

输出的第一个特征值应接近 `0`；若出现明显负值，先检查 `L` 是否对称、度矩阵是否由同一个 `A` 生成。

## 5. 相近概念边界

- 图信号：节点上的数值 `x`；不是特征向量 `U` 本身。
- 图频率：由拉普拉斯特征值标识的结构方向；不能直接等同于时间频率。
- 图滤波：对 `x` 的线性/非线性变换；不必然是可学习神经网络。
- 消息传递：在局部邻域做聚合更新；可用谱近似解释一部分模型，但其统一定义在时域更直接。

## 6. 常见错误

1. 看到“高频”就说是噪声；任务标签可能恰好依赖高频/异配结构。
2. 把 `U` 的符号翻转当作模型效果变化；特征向量的符号存在等价性。
3. 用全图特征分解后随机切分新图，宣称模型已归纳；谱基本身依赖完整图。
4. 忽略 `L`、`A`、归一化邻接的不同，直接把谱公式写成 GCN 公式。

## 7. 检索练习与通过标准

- 对路径图解释零特征值与连通分量的关系。
- 写出一阶多项式滤波为何只需要自身和一跳邻居信息。
- 说明谱方法迁移到新图时的一个实际障碍。

通过标准：能手算 `L` 的一个二次型；能解释特征分解到局部传播的近似链；不把谱直觉写成无条件结论。
