# 图神经网络-消息传递统一框架

## 1. 问题动机

GCN、GraphSAGE 和 GAT 都在重复同一件事：每个节点接收邻居消息，以对邻居顺序不敏感的方式聚合，再更新自身表示。统一框架让我们能比较“变了哪一项”，也能检查实现是否把边方向、形状或自环弄错。

## 2. 一层消息传递

第 `k` 层对边 `(u,v)`：

$$m_{u\to v}^{(k)}=M^{(k)}\left(h_u^{(k-1)},h_v^{(k-1)},e_{uv}\right)$$

$$m_v^{(k)}=\bigoplus_{u∈N(v)}m_{u\to v}^{(k)},\qquad h_v^{(k)}=U^{(k)}\left(h_v^{(k-1)},m_v^{(k)}\right)$$

`⊕` 常取 sum/mean/max，必须对邻居排列不变。共享的 `M,U` 让参数数量不随节点数增长；堆叠 `K` 层后，节点最多接收 `K` 跳范围的信息。

图级输出还需：

$$h_G=R\left(\{h_v^{(K)}:v∈V\}\right)$$

其中 `R` 对节点排列不变。

## 3. 等变与不变

若只重新编号节点，节点级输出应该用同样方式重新排列，称为 permutation equivariant；图级输出不应变化，称为 invariant。对邻居使用字符串拼接或固定索引位置通常会破坏这个性质，除非先定义了有意义的顺序。

## 4. 最小一层实现

```python
import torch

A = torch.tensor([[0., 1., 0.], [1., 0., 1.], [0., 1., 0.]])
X = torch.tensor([[1., 0.], [0., 1.], [1., 1.]])
degree = A.sum(dim=1, keepdim=True).clamp_min(1.0)
neighbor_mean = (A @ X) / degree
combined = torch.cat([X, neighbor_mean], dim=1)
layer = torch.nn.Linear(4, 3, bias=False)
H = torch.relu(layer(combined))
assert H.shape == (3, 3)
print(H.shape)
```

这段代码包含可学习参数，但没有 loss 和优化步骤，只是“一层可训练模块的前向”。在作业中必须再接任务头、损失、训练掩码和优化器，才能称为训练。

## 5. 三个模型落在框架的哪里

| 模型 | message/权重 | aggregate | update |
|:---|:---|:---|:---|
| GCN | 由度数归一化的邻居特征 | 加权和 | 线性变换 + 非线性 |
| GraphSAGE | 采样邻居特征 | mean/pool 等 | 与自身拼接后变换 |
| GAT | 学习的注意力系数乘邻居值 | 加权和 | 多头拼接/平均 + 非线性 |

这张表只比较主干，不代表每篇论文所有变体。

## 6. 常见错误与反例

- 把 `N(v)` 当作有序列表，使用依赖输入顺序的聚合器却不说明排序规则。
- 堆 `K` 层后声称能无损捕获任意 `K` 跳信息；聚合会压缩多重集，信息可能丢失。
- 对有向图同时沿入边和出边传播却不区分边类型。
- 把 readout 放到节点分类中，导致所有节点共享同一个图向量。

## 7. 检索练习与通过标准

1. 给 mean aggregator 写出 `M,⊕,U` 的一种合法定义。
2. 证明 sum 对邻居顺序不变；给出一个依赖顺序的反例聚合器。
3. 对三层 MPNN 说明 receptive field 上界和信息压缩的区别。

通过标准：能从统一公式拆出至少两个具体模型；能检查输入/输出形状；能准确说出 equivariant 与 invariant 的对象。
