# 图神经网络-图级读出与任务头

## 1. 问题动机

消息传递输出节点表示 `H`，但任务可能要求节点、边或整图预测。任务头决定如何从 `H` 得到 logits；错误的 readout 会把模型训练成另一个任务。

## 2. 三种任务头

### 节点头

对每个节点独立变换：`Z_node=H W_o+b`，形状为 `n×C`。

### 边头

组合端点表示：内积 `s(u,v)=h_u^Th_v`、双线性 `h_u^T R h_v` 或 MLP `[h_u||h_v||e_uv]`。无向边解码器应满足对称性，除非任务有方向。

### 图头

先做排列不变读出：

$$h_G=READOUT(\{h_v:v∈V\})$$

再用 `h_G` 分类/回归。sum 保留节点数尺度，mean 更接近分布平均，max 只保留各维最大激活；三者偏置不同，不存在无条件最佳。

## 3. 最小批图读出

```python
import torch

H = torch.tensor([[1., 0.], [0., 1.], [2., 1.], [1., 2.]])
graph_id = torch.tensor([0, 0, 1, 1])
pooled = torch.zeros(2, 2)
pooled.index_add_(0, graph_id, H)
counts = torch.bincount(graph_id).float().unsqueeze(1)
mean_pooled = pooled / counts
assert mean_pooled.shape == (2, 2)
print(mean_pooled)
```

这段演示 sum/mean；真实 mini-batch 需要保证 `graph_id` 与节点顺序一致，并测试空图/单节点图边界。

## 4. readout 与表达能力

mean 无法区分“同样分布但节点数量不同”的多重集；max 会丢掉计数；sum 在适当的可学习变换下能保留更多多重集信息，但数值尺度随图大小变化。若目标依赖子结构计数，sum 往往比 mean 更自然；若目标应与图大小无关，需要额外归一化和基线验证。

## 5. 常见错误

- 对图分类直接取“第一个节点”作为图表示，却没有合法的特殊 token 定义。
- 链路预测先在全图上消息传递，再把测试边保留在传播图里。
- 无向边使用非对称 concat 解码器但只训练一个方向，导致交换端点时分数变化。
- 不记录图大小分布，模型只学会“大图/小图”捷径。

## 6. 检索练习与通过标准

1. 对两张节点数不同但节点特征均值相同的图，比较 sum/mean/max 输出。
2. 为无向链路预测设计一个对称解码器并说明限制。
3. 给出一个必须图级 readout、一个不应图级 readout 的任务。

通过标准：能从任务粒度选择任务头；能写出批图 pooling 形状；能说明 readout 的信息丢失与图大小偏置。
