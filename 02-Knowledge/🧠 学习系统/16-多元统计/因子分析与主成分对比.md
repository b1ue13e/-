# 因子分析与主成分对比 (Factor Analysis vs PCA)

## 1. 因子分析与主成分对比的定义与潜在结构

**因子分析与主成分对比 (Factor Analysis vs PCA)** 的核心定义是：比较两种在多元统计中用于降维与变量压缩的经典方法——因子分析 (Factor Analysis, FA) 旨在**寻找隐藏在显变量背后的潜在公共因子 (Latent Factors)** 并解释变量间的相关性；而主成分分析 (PCA) 旨在**寻找可观测变量的最大方差正交线性组合**。由 Spearman (1904) 和 Thurston (1947) 建立因子分析体系。

**基本性质与建模范式**：
1. **主成分分析 (PCA)**：数据驱动的**线性坐标变换**，把 $p$ 个显变量组合成 $k$ 个互相正交的主成分（无潜在变量假设）；
2. **因子分析 (FA)**：基于结构的**生成式概率模型**，假设观测变量由少数 $m$ 个不可观测的公共因子与特定的特殊因子共同生成；
3. **因子旋转 (Factor Rotation)**：因子分析允许通过最大方差法 (Varimax) 旋转载荷矩阵，以获得具备高度可解释性的“简单结构 (Simple Structure)”。

---

## 2. 因子模型协方差分解形式化推导

**因子分析模型假设**：
设观测向量为 $\mathbf{X} = [X_1, \dots, X_p]^T$，均值为 $\boldsymbol{\mu}$。公共因子向量为 $\mathbf{F} = [F_1, \dots, F_m]^T$ ($m < p$)，特殊因子为 $\boldsymbol{\epsilon} = [\epsilon_1, \dots, \epsilon_p]^T$。

$$\mathbf{X} - \boldsymbol{\mu} = L \mathbf{F} + \boldsymbol{\epsilon}$$

其中 $L \in \mathbb{R}^{p \times m}$ 为**因子载荷矩阵 (Factor Loading Matrix)**。

**统计假设条件**：
1. $\mathbb{E}[\mathbf{F}] = \mathbf{0}, \quad \text{Cov}(\mathbf{F}) = I_m$（公共因子标准正交）；
2. $\mathbb{E}[\boldsymbol{\epsilon}] = \mathbf{0}, \quad \text{Cov}(\boldsymbol{\epsilon}) = \Psi = \text{diag}(\psi_1, \dots, \psi_p)$（特殊因子相互独立）；
3. $\text{Cov}(\mathbf{F}, \boldsymbol{\epsilon}) = \mathbf{0}$。

**推导过程（总体协方差矩阵分解）**：
1. 计算 $\mathbf{X}$ 的协方差矩阵 $\Sigma = \text{Cov}(\mathbf{X} - \boldsymbol{\mu})$：
$$\Sigma = \mathbb{E}[(\mathbf{X}-\boldsymbol{\mu})(\mathbf{X}-\boldsymbol{\mu})^T] = \mathbb{E}[(L \mathbf{F} + \boldsymbol{\epsilon})(L \mathbf{F} + \boldsymbol{\epsilon})^T]$$
2. 展开矩阵乘积：
$$\Sigma = \mathbb{E}[L \mathbf{F} \mathbf{F}^T L^T] + \mathbb{E}[L \mathbf{F} \boldsymbol{\epsilon}^T] + \mathbb{E}[\boldsymbol{\epsilon} \mathbf{F}^T L^T] + \mathbb{E}[\boldsymbol{\epsilon} \boldsymbol{\epsilon}^T]$$
3. 代入假设条件 $\mathbb{E}[\mathbf{F}\mathbf{F}^T]=I_m$ 与 $\mathbb{E}[\boldsymbol{\epsilon}\boldsymbol{\epsilon}^T]=\Psi$：
$$\Sigma = L L^T + \Psi$$
4. **方差分解意义**：
   - 变量 $X_i$ 的方差 $\sigma_{ii} = h_i^2 + \psi_i$；
   - $h_i^2 = \sum_{j=1}^m l_{ij}^2$ 称为**公共方差 (Communality)**；
   - $\psi_i$ 称为**特殊方差 (Uniqueness)**；
5. **因此**，因子分析仅对变量间共享的公共方差 $L L^T$ 进行建模，而忽略独立的特殊方差 $\Psi$，这是与把全方差一起降维的 PCA 的根本数学区别。

## 3. 因子分析 (FA) 与 主成分分析 (PCA) 全方位对比

| 维度 | 主成分分析 (PCA) | 因子分析 (Factor Analysis, FA) |
|:---|:---|:---|
| **数学模型范式** | 线性组合映射：$Y = W^T X$ | **生成式潜在模型**：$X = L F + \epsilon$ |
| **方差分解** | 解释**总方差 (Total Variance)** | 仅解释**公共方差 (Shared Variance)** |
| **对角元素填充** | 协方差矩阵对角线充填 **$1.0$ (全方差)** | 协方差矩阵对角线充填 **公共方差 $h_i^2$** |
| **主轴旋转 (Rotation)**| 绝对禁止旋转（旋转破坏主成分最大方差性）| **鼓励因子旋转**（如 Varimax 正交旋转可提升解释性）|
| **因子/主成分可估计性** | 主成分 $Y_i$ 可精确唯一计算 | 潜在因子 $F_j$ 存在“因子不确定性”无法精确求解 |

**局限（误区与反例）**：不能混淆 PCA 与 FA 的用途——当目标是无损数据压缩或去除多重共线性时首选 PCA；当目标是探索心理学测验或问卷背后隐藏的潜在特质（如智商、性格维度）时必须使用 FA。

关联知识点推荐：[[多元正态分布]]、[[主成分分析PCA]]、[[奇异值分解SVD]]、[[二分搜索]]。

## 4. Python 手写因子分析协方差分解 $\Sigma = LL^T + \Psi$ 自测断言

```python
import numpy as np

def factor_analysis_covariance_decomposition(L: np.ndarray, Psi_diag: np.ndarray) -> np.ndarray:
    """根据载荷矩阵 L 和特殊方差 Psi_diag 合成理论协方差矩阵 Sigma = L L^T + Psi"""
    Psi = np.diag(Psi_diag)
    return L @ L.T + Psi

if __name__ == "__main__":
    # 设 3 个变量，1 个公共因子 (p=3, m=1)
    L = np.array([[0.9], [0.8], [0.1]]) # 载荷矩阵
    Psi_diag = np.array([0.19, 0.36, 0.99]) # 特殊方差 (使得 h^2 + psi = 1.0)

    Sigma_model = factor_analysis_covariance_decomposition(L, Psi_diag)

    # 1. 验证变量 1 的公共方差 h1^2 = 0.9^2 = 0.81
    h1_sq = L[0, 0]**2
    assert abs(h1_sq - 0.81) < 1e-5

    # 2. 验证对角线元素等于 1.0 (总方差为 1)
    diag_elements = np.diag(Sigma_model)
    assert np.allclose(diag_elements, [1.0, 1.0, 1.0]), f"对角线总方差不等于 1: {diag_elements}"

    # 3. 验证协方差 Off-diagonal 元素仅由 L L^T 决定
    cov_12 = Sigma_model[0, 1]
    assert abs(cov_12 - (0.9 * 0.8)) < 1e-5, f"变量 1 和 2 的协方差错误: {cov_12}"

    print(f"因子模型理论协方差矩阵合成成功! \n{Sigma_model.round(4)}")
    print("因子分析与主成分对比 单元测试与自查验证全部成功！")
```
