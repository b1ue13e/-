# 多元统计-多元正态分布与性质

## 1. 为什么多元正态分布是多元统计的支柱？

在实际多变量数据中，虽然单个变量可能近似正态，但变量之间往往存在错综复杂的线性相关性。多元正态分布 $N_p(\boldsymbol{\mu}, \mathbf{\Sigma})$ 具备以下几乎不可替代的绝佳数学性质：
1. **边缘分布全正态**：其任意子集变量的边缘分布仍是严格的多元正态分布；
2. **线性组合仍正态**：变量的任意非零线性组合 $\mathbf{a}^T \mathbf{X}$ 仍服从一元正态分布；
3. **不相关即独立**：对多元正态变量而言，协方差为零（$\operatorname{Cov}(X_i, X_j) = 0$）等价于相互独立；
4. **条件分布完全线性**：条件期望是已知变量的精确线性函数，条件协方差是常数阵；
5. **极大熵特性**：在给定一阶矩（均值）和二阶矩（协方差）的前提下，多元正态分布是微分熵最大的连续概率分布。

## 2. 严格数学定义与密度函数

### 2.1 概率密度函数 (PDF) 与特征函数

设 $\mathbf{X} = (X_1, \dots, X_p)^T \in \mathbb{R}^p$ 为连续随机向量。若协方差矩阵 $\mathbf{\Sigma} \succ 0$ 正定，均值向量 $\boldsymbol{\mu} \in \mathbb{R}^p$，则多元正态概率密度函数为：
$$f(\mathbf{x}) = \frac{1}{(2\pi)^{p/2} |\mathbf{\Sigma}|^{1/2}} \exp\left( -\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu}) \right)$$
其特征函数（无论 $\mathbf{\Sigma}$ 是否严格正定均成立）：
$$\phi_{\mathbf{X}}(\mathbf{t}) = \mathbb{E}[\exp(i \mathbf{t}^T \mathbf{X})] = \exp\left( i \mathbf{t}^T \boldsymbol{\mu} - \frac{1}{2} \mathbf{t}^T \mathbf{\Sigma} \mathbf{t} \right)$$

### 2.2 仿射变换不变性定理

设 $\mathbf{X} \sim N_p(\boldsymbol{\mu}, \mathbf{\Sigma})$，$\mathbf{C} \in \mathbb{R}^{q \times p}$ 为常数矩阵（$\operatorname{rank}(\mathbf{C}) = q \le p$），$\mathbf{d} \in \mathbb{R}^q$ 为常数向量。则线性组合：
$$\mathbf{Y} = \mathbf{C}\mathbf{X} + \mathbf{d} \sim N_q(\mathbf{C}\boldsymbol{\mu} + \mathbf{d}, \mathbf{C}\mathbf{\Sigma}\mathbf{C}^T)$$

## 3. 分块矩阵、边缘分布与条件分布定理

将随机向量与参数划分为两部分：
$$\mathbf{X} = \begin{pmatrix} \mathbf{X}_1 \\ \mathbf{X}_2 \end{pmatrix}, \quad \boldsymbol{\mu} = \begin{pmatrix} \boldsymbol{\mu}_1 \\ \boldsymbol{\mu}_2 \end{pmatrix}, \quad \mathbf{\Sigma} = \begin{pmatrix} \mathbf{\Sigma}_{11} & \mathbf{\Sigma}_{12} \\ \mathbf{\Sigma}_{21} & \mathbf{\Sigma}_{22} \end{pmatrix}$$
其中 $\mathbf{X}_1 \in \mathbb{R}^{q}, \mathbf{X}_2 \in \mathbb{R}^{p-q}$。

### 3.1 边缘分布
$$\mathbf{X}_1 \sim N_q(\boldsymbol{\mu}_1, \mathbf{\Sigma}_{11}), \quad \mathbf{X}_2 \sim N_{p-q}(\boldsymbol{\mu}_2, \mathbf{\Sigma}_{22})$$

### 3.2 条件分布与 Schur 补
给定 $\mathbf{X}_2 = \mathbf{x}_2$ 的条件下，$\mathbf{X}_1$ 的条件分布仍是多元正态分布：
$$\mathbf{X}_1 \mid (\mathbf{X}_2 = \mathbf{x}_2) \sim N_q(\boldsymbol{\mu}_{1|2}, \mathbf{\Sigma}_{11|2})$$
- **条件期望（线性回归面）**：
  $$\boldsymbol{\mu}_{1|2} = \mathbb{E}[\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2] = \boldsymbol{\mu}_1 + \mathbf{\Sigma}_{12} \mathbf{\Sigma}_{22}^{-1} (\mathbf{x}_2 - \boldsymbol{\mu}_2)$$
- **条件协方差（Schur 补，与观测值 $\mathbf{x}_2$ 完全无关）**：
  $$\mathbf{\Sigma}_{11|2} = \operatorname{Cov}(\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2) = \mathbf{\Sigma}_{11} - \mathbf{\Sigma}_{12} \mathbf{\Sigma}_{22}^{-1} \mathbf{\Sigma}_{21}$$

## 4. 多元正态性诊断与 Mardia 检验

一元正态性（如 Shapiro-Wilk 检验）不能保证多元联合正态性！多元正态性诊断通常采用两种互补方法：

1. **Chi-Square Q-Q 图**：根据马氏距离平方 $D_i^2 = (\mathbf{x}_i - \bar{\mathbf{x}})^T \mathbf{S}^{-1} (\mathbf{x}_i - \bar{\mathbf{x}}) \overset{\text{approx}}{\sim} \chi^2(p)$，绘制样本分位数与理论分位数散点图，散点紧密落在 $y=x$ 直线上表明联合正态；
2. **Mardia 偏度与峰度检验**：
   - 偏度统计量：$b_{1,p} = \frac{1}{n^2}\sum_{i,j} [(\mathbf{x}_i - \bar{\mathbf{x}})^T \mathbf{S}^{-1} (\mathbf{x}_j - \bar{\mathbf{x}})]^3$，大样本下 $\frac{n}{6} b_{1,p} \sim \chi^2(\frac{p(p+1)(p+2)}{6})$；
   - 峰度统计量：$b_{2,p} = \frac{1}{n}\sum_{i} [(\mathbf{x}_i - \bar{\mathbf{x}})^T \mathbf{S}^{-1} (\mathbf{x}_i - \bar{\mathbf{x}})]^2$，大样本下 $\frac{b_{2,p} - p(p+2)}{\sqrt{8p(p+2)/n}} \sim N(0, 1)$。

## 5. Python 实战代码：真实瑞士钞票数据正态性诊断

```python
import sys, os
import numpy as np
import pandas as pd

# 引入真实数据加载器与 MVA 工具库
sys.path.insert(0, r"f:\-\03-Projects\16-多元统计\scripts")
from load_data import load_swiss_banknotes
from mva_toolkit import mardia_test, chi_square_qq_plot_data

# 1. 加载真钞 6 维测量数据
df_bank = load_swiss_banknotes()
genuine_features = df_bank[df_bank['Is_Counterfeit'] == 0][['Length', 'Left', 'Right', 'Bottom', 'Top', 'Diagonal']].values

# 2. Mardia 偏度与峰度联合检验
mardia_res = mardia_test(genuine_features)
print("=== 瑞士真钞数据多元正态性 Mardia 检验 ===")
print(f"Mardia 偏度卡方统计量: {mardia_res['skewness_stat']:.3f} (df={mardia_res['df_skew']}, p-value={mardia_res['skewness_p_value']:.4f})")
print(f"Mardia 峰度标准正态统计量: {mardia_res['kurtosis_stat']:.3f} (p-value={mardia_res['kurtosis_p_value']:.4f})")

# 3. 卡方 Q-Q 图数据计算
qq_res = chi_square_qq_plot_data(genuine_features)
correlation_qq = np.corrcoef(qq_res['ordered_d2'], qq_res['theoretical_quantiles'])[0, 1]
print(f"Q-Q 图马氏距离与理论卡方分位数相关系数: {correlation_qq:.4f}")
assert correlation_qq > 0.95
print("✅ 多元正态性诊断实战通过！")
```

## 6. 易错反例与调试陷阱

> [!CAUTION]
> - **一元正态不保证多元正态**：构造经典反例 $X \sim N(0, 1)$，令符号随机变量 $W \in \{-1, 1\}$ 独立等概率取值，设 $Y = W X$。则 $X, Y$ 分别服从标准一元正态分布，但联合分布 $(X, Y)$ 不是二元正态分布（其概率密度集中在两条对角线上）。
> - **高维奇异性陷阱**：若变量间存在完全多重共线性（如各分量之和恒为常数），则 $|\mathbf{\Sigma}| = 0$，不存在标准概率密度函数，称为**退化多元正态分布**。此时必须先做正交投影或主成分降维。
