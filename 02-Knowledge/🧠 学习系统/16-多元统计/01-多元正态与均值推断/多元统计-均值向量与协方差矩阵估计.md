# 多元统计-均值向量与协方差矩阵估计

## 1. 为什么多元点估计需要样本几何视角？

设数据矩阵 $\mathbf{X} \in \mathbb{R}^{n \times p}$ 包含 $n$ 个 $p$ 维样本行向量 $\mathbf{x}_1^T, \dots, \mathbf{x}_n^T$。
多元点估计存在两种互为对偶的几何视角：
1. **变量空间视角（$\mathbb{R}^p$ 中的 $n$ 个点）**：样本均值 $\bar{\mathbf{x}}$ 是样本点云的重心质心，样本协方差 $\mathbf{S}$ 决定了点云椭球的离散程度与倾斜主轴；
2. **样本空间视角（$\mathbb{R}^n$ 中的 $p$ 个向量）**：去中心化后的每个特征向量 $\tilde{\mathbf{x}}_j = \mathbf{x}_j - \bar{x}_j \mathbf{1}_n$ 是 $\mathbb{R}^n$ 超平面上的向量，两两内积 $\tilde{\mathbf{x}}_j^T \tilde{\mathbf{x}}_k$ 精确等于样本协方差 $(n-1) S_{jk}$，夹角余弦精确等于样本相关系数 $r_{jk} = \cos \theta_{jk}$。

## 2. 估计量构造与第一性原理性质

### 2.1 样本均值向量 $\bar{\mathbf{X}}$

$$\bar{\mathbf{X}} = \frac{1}{n}\sum_{i=1}^n \mathbf{X}_i = \frac{1}{n}\mathbf{X}^T \mathbf{1}_n$$
- **期望与方差**：$\mathbb{E}[\bar{\mathbf{X}}] = \boldsymbol{\mu}$（严格无偏），$\operatorname{Cov}(\bar{\mathbf{X}}) = \frac{1}{n}\mathbf{\Sigma}$。

### 2.2 样本协方差矩阵 $\mathbf{S}$ 与 Wishart 分布

定义离差阵 $\mathbf{A}$ 与无偏样本协方差矩阵 $\mathbf{S}$：
$$\mathbf{A} = \sum_{i=1}^n (\mathbf{X}_i - \bar{\mathbf{X}})(\mathbf{X}_i - \bar{\mathbf{X}})^T = \mathbf{X}^T \mathbf{H}_n \mathbf{X}$$
其中中心化投影矩阵 $\mathbf{H}_n = \mathbf{I}_n - \frac{1}{n}\mathbf{1}_n\mathbf{1}_n^T$（满足对称幂等 $\mathbf{H}_n^2 = \mathbf{H}_n, \operatorname{tr}(\mathbf{H}_n) = n-1$）。
$$\mathbf{S} = \frac{1}{n-1}\mathbf{A}$$

> [!IMPORTANT]
> **定理 (Wishart 母体分布)**：
> 若 $\mathbf{X}_1, \dots, \mathbf{X}_n \overset{iid}{\sim} N_p(\boldsymbol{\mu}, \mathbf{\Sigma})$，则：
> 1. $\bar{\mathbf{X}}$ 与 $\mathbf{S}$ 相互统计独立；
> 2. $\mathbf{A} = (n-1)\mathbf{S} \sim W_p(n-1, \mathbf{\Sigma})$ 服从自由度为 $n-1$ 的 Wishart 分布；
> 3. $\mathbb{E}[\mathbf{S}] = \mathbf{\Sigma}$（无偏），而 MLE 估计量 $\hat{\mathbf{\Sigma}} = \frac{1}{n}\mathbf{A} = \frac{n-1}{n}\mathbf{S}$。

## 3. Python 代码：样本几何与 Wishart 模拟验证

```python
import numpy as np
from scipy import stats

np.random.seed(42)
n, p = 100, 3
true_mu = np.array([1.0, 2.0, 3.0])
true_cov = np.array([
    [2.0, 0.8, 0.4],
    [0.8, 1.5, 0.6],
    [0.4, 0.6, 3.0]
])

# 抽样模拟
X = np.random.multivariate_normal(true_mu, true_cov, size=n)

x_bar = np.mean(X, axis=0)
S = np.cov(X, rowvar=False, ddof=1)
S_mle = np.cov(X, rowvar=False, ddof=0)

print("真实均值:", true_mu, "样本均值估计:", np.round(x_bar, 3))
print("真实协方差:\n", true_cov)
print("无偏样本协方差 S (ddof=1):\n", np.round(S, 3))
print("MLE 样本协方差 (ddof=0):\n", np.round(S_mle, 3))
```
