# 多元统计-协方差结构检验

## 1. 为什么在均值推断前必须检验协方差结构？

在多元统计推断中，许多核心方法都建立在关于总体协方差矩阵的严格前提假设之上：
1. **两样本 Hotelling $T^2$ 与 MANOVA**：假设各组总体协方差矩阵严格相等（**协方差齐性** $\mathbf{\Sigma}_1 = \dots = \mathbf{\Sigma}_g$）。若协方差非齐，两样本 $T^2$ 与 Wilks' $\Lambda$ 的检验水准会出现严重偏差；
2. **主成分分析与因子分析**：假定变量之间存在显著相关性。若相关矩阵退化为单位阵（$\mathbf{R} = \mathbf{I}$），则降维分析完全无意义。

因此，**协方差结构检验是多元推断与降维建模不可或缺的诊断前哨**。

## 2. Box's M 多组协方差齐性检验

### 2.1 假设设定与统计量构造

设共有 $g$ 个独立多元正态总体，样本量分别为 $n_1, \dots, n_g$，总样本量 $N = \sum_{k=1}^g n_k$。
检验假设：
$$H_0: \mathbf{\Sigma}_1 = \mathbf{\Sigma}_2 = \dots = \mathbf{\Sigma}_g \quad \text{vs} \quad H_1: \text{至少存在两个组的协方差矩阵不相等}$$

合并样本协方差矩阵：
$$\mathbf{S}_{pooled} = \frac{1}{N - g} \sum_{k=1}^g (n_k - 1) \mathbf{S}_k$$
基于似然比构造 **Box's $M$ 统计量**：
$$M = (N - g) \ln |\mathbf{S}_{pooled}| - \sum_{k=1}^g (n_k - 1) \ln |\mathbf{S}_k|$$

### 2.2 Bartlett 修正与卡方近似

Box (1949) 导出了著名的尺度修正系数 $c_1$：
$$c_1 = \left( \sum_{k=1}^g \frac{1}{n_k - 1} - \frac{1}{N - g} \right) \frac{2p^2 + 3p - 1}{6(p + 1)(g - 1)}$$
修正后的统计量渐近服从卡方分布：
$$C = M (1 - c_1) \overset{\text{approx}}{\sim} \chi^2\left( \frac{(g - 1) p (p + 1)}{2} \right)$$

## 3. Bartlett 球形检验 (Test of Sphericity)

检验变量间是否完全不相关（相关系数矩阵是否为单位阵）：
$$H_0: \mathbf{R} = \mathbf{I}_p \quad \text{vs} \quad H_1: \mathbf{R} \neq \mathbf{I}_p$$
Bartlett 统计量：
$$\chi^2 = - \left( n - 1 - \frac{2p + 5}{6} \right) \ln |\mathbf{R}| \sim \chi^2\left( \frac{p(p - 1)}{2} \right)$$
若拒绝 $H_0$（$p < 0.05$），表明变量间存在共享结构，适合进行 PCA 和因子分析。

## 4. Python 实战代码：真伪钞票协方差齐性诊断

```python
import sys
import numpy as np
import pandas as pd

sys.path.insert(0, r"f:\-\03-Projects\16-多元统计\scripts")
from load_data import load_swiss_banknotes
from mva_toolkit import box_m_test, bartlett_sphericity_test

# 1. 加载真钞与伪钞数据
df_bank = load_swiss_banknotes()
cols = ['Length', 'Left', 'Right', 'Bottom', 'Top', 'Diagonal']
X_gen = df_bank[df_bank['Is_Counterfeit'] == 0][cols].values
X_fake = df_bank[df_bank['Is_Counterfeit'] == 1][cols].values

# 2. 运行 Box's M 检验
res_box = box_m_test([X_gen, X_fake])

print("=== 瑞士真伪钞票协方差矩阵齐性 Box's M 检验 ===")
print(f"Box's M 统计量: {res_box['M_stat']:.2f}")
print(f"修正卡方统计量: {res_box['chi2_stat']:.2f} (df={res_box['df']})")
print(f"检验 p-value: {res_box['p_value']:.2e}")

# 3. 运行 Bartlett 球形检验
res_bart = bartlett_sphericity_test(X_gen)
print(f"\n真钞指标 Bartlett 球形检验卡方值: {res_bart['statistic']:.2f}, p-value: {res_bart['p_value']:.2e}")
```

## 5. 易错反例与调试陷阱

> [!WARNING]
> - **Box's M 检验对非正态性极度敏感**：Box's M 检验如果被拒绝，往往不仅是因为协方差不相等，更可能是因为数据存在厚尾或轻微偏斜！因此在大样本下拒绝原假设时，应配合 Pillai 迹检验使用，而不要盲目废弃线性判别分析。
