# 多元统计-多重比较与检验校正

## 1. 为什么多元均值拒绝 $H_0$ 后必须做多重比较校正？

当 Hotelling $T^2$ 或 MANOVA 检验拒绝原假设（证明多个总体在 $p$ 维高维空间中的均值向量存在显著差异）后，研究者面临更具体的问题：**究竟是哪些具体变量、哪些组别之间产生了显著差异？**
如果直接对 $p$ 个指标分别运行 $p$ 次独立 $t$ 检验：
- **族假阳性率 (Family-Wise Error Rate, FWER)** 会急剧膨胀：$\operatorname{FWER} \le 1 - (1-\alpha)^p \approx p\alpha$；
- 忽略了多维方向上的**同时置信区间 (Simultaneous Confidence Intervals)** 旋转投影关系。

---

## 2. 经典多元同时置信区间与校正方法

### 2.1 Bonferroni 联合置信区间

利用 Boole 不等式，对 $p$ 个单变量假设同时进行显著性水准分割：$\alpha_{each} = \frac{\alpha}{p}$。
每个变量 $\mu_j$ 的 $(1-\alpha)$ 同步置信区间为：
$$\bar{X}_j \pm t_{\alpha / (2p), \, n-1} \sqrt{\frac{S_{jj}}{n}}$$
- **优点**：计算极其简单，不依赖具体的相关结构；
- **缺点**：当 $p$ 非常大或变量高度相关时过于保守（假阴性率增加）。

### 2.2 Simultaneous Hotelling $T^2$ 联合置信区间

利用 Hotelling $T^2$ 统计量的极值特性，对任意非零线性组合 $\mathbf{a}^T \boldsymbol{\mu}$（包含坐标轴及斜对角方向）：
$$P\left( \text{对所有 } \mathbf{a} \neq \mathbf{0}, \ \mathbf{a}^T \bar{\mathbf{X}} - \sqrt{\frac{p(n-1)}{n(n-p)} F_{\alpha, p, n-p} \mathbf{a}^T \mathbf{S} \mathbf{a}} \le \mathbf{a}^T \boldsymbol{\mu} \le \mathbf{a}^T \bar{\mathbf{X}} + \sqrt{\frac{p(n-1)}{n(n-p)} F_{\alpha, p, n-p} \mathbf{a}^T \mathbf{S} \mathbf{a}} \right) = 1 - \alpha$$
> [!TIP]
> **几何含义**：Hotelling 同时置信区间建立了高维置信超椭球在各个投影方向上的精确切线外包络，保证所有可能的线性组合在指定显著性下同时成立！

## 3. Python 代码：瑞士钞票指标 Bonferroni vs Hotelling 同时置信区间

```python
import sys
import numpy as np
import pandas as pd
from scipy import stats

sys.path.insert(0, r"f:\-\03-Projects\16-多元统计\scripts")
from load_data import load_swiss_banknotes

df_bank = load_swiss_banknotes()
cols = ['Length', 'Left', 'Right', 'Bottom', 'Top', 'Diagonal']
X_gen = df_bank[df_bank['Is_Counterfeit'] == 0][cols].values

n, p = X_gen.shape
x_bar = np.mean(X_gen, axis=0)
S = np.cov(X_gen, rowvar=False, ddof=1)
alpha = 0.05

# 1. Bonferroni 临界值
t_bonf = stats.t.ppf(1 - alpha / (2 * p), df=n - 1)
bonf_margin = t_bonf * np.sqrt(np.diag(S) / n)

# 2. Hotelling 临界值
F_crit = stats.f.ppf(1 - alpha, dfn=p, dfd=n - p)
hotell_margin = np.sqrt(((p * (n - 1)) / (n - p)) * F_crit) * np.sqrt(np.diag(S) / n)

ci_df = pd.DataFrame({
    'Mean': np.round(x_bar, 3),
    'Bonf_Lower': np.round(x_bar - bonf_margin, 3),
    'Bonf_Upper': np.round(x_bar + bonf_margin, 3),
    'Hotell_Lower': np.round(x_bar - hotell_margin, 3),
    'Hotell_Upper': np.round(x_bar + hotell_margin, 3)
}, index=cols)

print("=== 瑞士真钞 6 维测量指标 95% 同时置信区间对比 ===")
print(ci_df)
```
