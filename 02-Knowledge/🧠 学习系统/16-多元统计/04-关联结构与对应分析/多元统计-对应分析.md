# 多元统计-对应分析

## 1. 为什么离散列联表需要对应分析 (CA)？

主成分分析 (PCA) 适用于连续定量变量，卡方独立性检验适用于离散定性变量列联表。
但卡方检验只能给出“两属性是否相关”的 0/1 判定，无法揭示**具体哪些行类别与哪些列类别相互吸引（强相关）或相互排斥**。
**对应分析 (Correspondence Analysis, CA / Dual Scaling)** 将列联表各行各列转化为低维空间中的点，在一个联合二维“感知图 (Perceptual Map)”上同时展示行与列的对应关联结构。

## 2. 统计与数学推导：加权 SVD 分解

### 2.1 列联表与轮廓矩阵 (Profiles)

设有 $I \times J$ 频数交叉表 $\mathbf{N} = (n_{ij})$，总频数 $n = \sum_{i,j} n_{ij}$。
- **对应矩阵**：$\mathbf{P} = \frac{1}{n} \mathbf{N} = (p_{ij})$；
- **行质量与列质量向量**：$r_i = \sum_j p_{ij}, \ \mathbf{r} = (r_1,\dots,r_I)^T$；$c_j = \sum_i p_{ij}, \ \mathbf{c} = (c_1,\dots,c_J)^T$；
- **对角质量矩阵**：$\mathbf{D}_r = \operatorname{diag}(\mathbf{r}), \, \mathbf{D}_c = \operatorname{diag}(\mathbf{c})$。

### 2.2 总惯量 (Total Inertia) 与卡方统计量

总惯量衡量各轮廓点偏离平均轮廓的离散程度，与皮尔逊卡方统计量严格等价：
$$\text{Inertia} = \sum_{i=1}^I \sum_{j=1}^J \frac{(p_{ij} - r_i c_j)^2}{r_i c_j} = \frac{\chi^2}{n}$$

### 2.3 加权 SVD 分解求解主坐标

对标准化残差矩阵 $\mathbf{Z} = \mathbf{D}_r^{-1/2} (\mathbf{P} - \mathbf{r} \mathbf{c}^T) \mathbf{D}_c^{-1/2}$ 进行 SVD 分解：
$$\mathbf{Z} = \mathbf{U} \boldsymbol{\Gamma} \mathbf{V}^T$$
- **行主坐标**：$\mathbf{F} = \mathbf{D}_r^{-1/2} \mathbf{U} \boldsymbol{\Gamma}$
- **列主坐标**：$\mathbf{G} = \mathbf{D}_c^{-1/2} \mathbf{V} \boldsymbol{\Gamma}$
将 $\mathbf{F}$ 和 $\mathbf{G}$ 绘制在同一直角坐标系中，距离越近表明行/列属性越匹配。

## 3. Python 实战代码：品牌与年龄段列联表对应分析

```python
import sys
import numpy as np

sys.path.insert(0, r"f:\-\03-Projects\16-多元统计\scripts")
from mva_toolkit import correspondence_analysis_fit

# 品牌与消费者年龄段交叉频数表 (3 品牌 x 3 年龄段)
N = np.array([
    [60, 20, 10], # 品牌 A (偏年轻)
    [30, 50, 40], # 品牌 B (偏中年)
    [10, 30, 80]  # 品牌 C (偏老年)
])

# 运行对应分析
res_ca = correspondence_analysis_fit(N, n_components=2)

print("=== 品牌与年龄段列联表对应分析 ===")
print(f"列联表总惯量 Inertia: {res_ca['total_inertia']:.4f}")
print("第一主轴解释卡方百分比:", np.round(res_ca['explained_inertia_ratio'][0] * 100, 2), "%")
print("行主坐标 F (品牌):\n", np.round(res_ca['row_principal_coordinates'], 3))
print("列主坐标 G (年龄段):\n", np.round(res_ca['col_principal_coordinates'], 3))

assert res_ca['total_inertia'] > 0
print("✅ 对应分析加权 SVD 与主坐标计算通过！")
```
