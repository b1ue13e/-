# 多元统计-多变量图表示法

## 1. 为什么高维探索性数据分析 (EDA) 需要专门的图表示法？

人类大脑只能直观感知 2 维或 3 维几何空间。面对 $p \ge 4$ 的高维样本数据，直接罗列数字表格无法洞察变量分布形态、相关性与异常聚类。
多变量图表示法的核心目标：**通过多维空间映射、多通道几何编码或高维平行坐标，将高维数据的结构直观呈现在二维平面上**。

---

## 2. 四大多元统计经典图形方法

### 2.1 散点图矩阵 (Scatterplot Matrix / Pairplot)
- **原理**：将 $p$ 个变量两两组合，构成 $p \times p$ 的子图矩阵；对角线上展示各变量单变量分布（直方图/核密度 KDE），非对角线展示两两散点图；
- **用途**：第一眼快速扫描多重共线性、非线性模式与明显异常离群点。

### 2.2 雷达图与星图 (Radar / Star Chart)
- **原理**：从中心向外发射 $p$ 条等角射线，将样本在各射线上的取值点用线段封闭连接成多边形；
- **用途**：直观对比少数几个典型样本（如不同公司财务画像）。

### 2.3 平行坐标图 (Parallel Coordinates)
- **原理**：用 $p$ 条相互平行的等距纵轴分别代表 $p$ 个特征，每一个高维样本点对应贯穿所有纵轴的一条折线；
- **用途**：展示高维聚类模式与变量正负相关（若轴间线段平行则正相关，交叉成束则负相关）。

### 2.4 Chernoff 脸谱图 (Chernoff Face Graph)
- **原理**：将高维变量分别对应面部几何特征（脸宽、眼距、微笑弧度等），利用人类视觉对比多维状态。

## 3. Python 实战代码：真实瑞士钞票 6 维几何特征相关性热力图

```python
import sys
import numpy as np
import pandas as pd

sys.path.insert(0, r"f:\-\03-Projects\16-多元统计\scripts")
from load_data import load_swiss_banknotes

df_bank = load_swiss_banknotes()
cols = ['Length', 'Left', 'Right', 'Bottom', 'Top', 'Diagonal']
X = df_bank[cols]

corr_matrix = X.corr()
print("=== 瑞士钞票 6 维指标散点图矩阵关联矩阵 ===")
print(np.round(corr_matrix, 3))

# 对角线与底部/对角线强相关性校验
assert corr_matrix.loc['Bottom', 'Top'] < 0
print("✅ 散点图矩阵背后的多变量几何相关结构提取成功！")
```
