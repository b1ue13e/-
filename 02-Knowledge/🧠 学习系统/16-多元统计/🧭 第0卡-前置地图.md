# 🧭 第 0 卡：前置地图

> **学这门课之前，先确认自己有没有这些装备。** 每一项都标了「已有/待建」：
> - 已有 = 知识库中存在对应笔记，点链接即可复习；
> - 待建 = 知识库还没有专门笔记，先补对应数学基础再学本卡（否则会卡）。

## 一、必会背景（按依赖顺序）

| 背景 | 状态 | 本课哪里用到 |
|:---|:---:|:---|
| 线性代数：矩阵/逆/行列式/特征值 | ⚠️ 待建（`矩阵代数基础`，可去 [[09-高等代数]] 补） | 全部课程（Σ 运算、特征分解） |
| 一元正态分布与抽样分布 | ⚠️ 待建（`一元正态分布`，可去 [[22-概率论与数理统计]] 补） | 多元正态定义 |
| 多元微积分：偏导/二次型 | ⚠️ 待建（`矩阵代数基础` 内含） | 密度推导、配平方 |
| 假设检验：t/F/χ² 分布 | ⚠️ 待建（`统计推断基础`，可去 [[33-贝叶斯统计]] 补） | T²、MANOVA、协方差检验 |

## 二、学习顺序（14 卡推荐路径）

```
卡1 多元正态 ─→ 卡2 均值/协方差估计 ─→ 卡3 Hotelling T² ─→ 卡4 MANOVA
     │                  │                  │
     │                  │                  └──→ 卡11 多重比较
     │                  └──→ 卡13 稳健协方差
     │
     ├──→ 卡5 PCA ─→ 卡6 因子分析 ─→ 卡12 协方差结构检验
     │       └──→ 卡14 维度灾难
     │
     └──→ 卡7 LDA/QDA ─→ 卡8 聚类
     │
     └──→ 卡9 CCA ─→ 卡10 多元回归矩阵形式
```

## 三、给小白的三条建议

1. **卡 1 必须真正理解**：多元正态的密度二次型、马氏距离、条件分布公式是后面所有推导的原料。先把 `矩阵代数基础` 补完。
2. **检验类卡（3、4、11、12）用证明模板**：它们的价值在"为什么这个统计量服从这个分布"，别只记公式。
3. **方法类卡（5-10）动手算**：PCA 至少手算一次 2×2 特征分解，LDA 至少手算一维判别边界——纸上算过才算会。
