# 多元正态分布 (Multivariate Normal Distribution)

## 1. 多元正态分布的定义与几何二次型结构

**多元正态分布 (Multivariate Normal Distribution)** 的核心定义是：一维正态分布向 $p$-维向量空间的自然推广，表示线性组合 $a_1 X_1 + \dots + a_p X_p$ 对任意实系数向量 $\mathbf{a}$ 均服从一维正态分布的多元连续连续概率分布。由 Carl Friedrich Gauss 与 Francis Galton 等人奠基。

**基本性质与几何概率等高线**：
1. **参量表征**：由均值向量 $\boldsymbol{\mu} \in \mathbb{R}^p$ 和对称正定协方差矩阵 $\Sigma \in \mathbb{R}^{p \times p}$ 唯一参数化，记为 $\mathbf{X} \sim \mathcal{N}_p(\boldsymbol{\mu}, \Sigma)$；
2. **马氏距离 (Mahalanobis Distance)**：二次型 $(\mathbf{x} - \boldsymbol{\mu})^T \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu}) = c^2$ 在 $p$ 维空间中定义了概率密度的超椭球等高线；
3. **线性变换封闭性**：若 $\mathbf{X} \sim \mathcal{N}_p(\boldsymbol{\mu}, \Sigma)$，$A \in \mathbb{R}^{q \times p}$，则 $A \mathbf{X} + \mathbf{b} \sim \mathcal{N}_q(A \boldsymbol{\mu} + \mathbf{b}, A \Sigma A^T)$。

## 2. 概率密度函数与条件正态分布形式化推导

**密度函数表达式**：
设协方差矩阵 $\Sigma$ 严格正定（满秩），则 $p$-维多元正态分布的联合概率密度函数 (PDF) 形式为：

$$f(\mathbf{x}) = \frac{1}{(2\pi)^{p/2} |\Sigma|^{1/2}} \exp\left( -\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^T \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu}) 
ight)$$

**条件正态分布 (Conditional Distribution) 形式化推导**：
将向量与协方差分块：$\mathbf{X} = [\mathbf{X}_1^T, \mathbf{X}_2^T]^T$，$\boldsymbol{\mu} = [\boldsymbol{\mu}_1^T, \boldsymbol{\mu}_2^T]^T$，$\Sigma = \begin{bmatrix} \Sigma_{11} & \Sigma_{12} \ \Sigma_{21} & \Sigma_{22} \end{bmatrix}$。

1. 给定 $\mathbf{X}_2 = \mathbf{x}_2$，条件分布 $\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2$ 依然服从多元正态分布：
$$\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2 \sim \mathcal{N}\left( \boldsymbol{\mu}_{1|2}, \Sigma_{1|2} 
ight)$$
2. **条件均值推导**：
$$\boldsymbol{\mu}_{1|2} = \boldsymbol{\mu}_1 + \Sigma_{12} \Sigma_{22}^{-1} (\mathbf{x}_2 - \boldsymbol{\mu}_2)$$
3. **条件协方差 (Schur 补) 推导**：
$$\Sigma_{1|2} = \Sigma_{11} - \Sigma_{12} \Sigma_{22}^{-1} \Sigma_{21}$$
4. **因此**，条件均值是 $\mathbf{x}_2$ 的**严格线性函数**，且条件协方差在给定 $\mathbf{x}_2$ 后完全恒定（同方差性），这一推导奠定了线性回归与高斯过程的理论根基。

## 3. 多元正态分布与一维正态及多元 t 分布对比

| 维度 | 一维正态分布 $\mathcal{N}(\mu, \sigma^2)$ | 多元正态分布 $\mathcal{N}_p(\boldsymbol{\mu}, \Sigma)$ | 多元 t 分布 $t_
u(\boldsymbol{\mu}, \Sigma)$ |
|:---|:---|:---|:---|
| **变量空间** | 1 维标量 $x \in \mathbb{R}$ | **$p$ 维向量 $\mathbf{x} \in \mathbb{R}^p$** | $p$ 维向量 $\mathbf{x} \in \mathbb{R}^p$ |
| **分散程度表征**| 标量方差 $\sigma^2$ | **$p \times p$ 协方差矩阵 $\Sigma$** | 尺度矩阵 $\Sigma$ + 自由度 $
u$ |
| **不相关与独立** | 不相关不一定独立 | **零协方差 ($\Sigma_{ij}=0$) 充要等价于独立** | 零相关不表示独立 |
| **尾部厚度** | 指数快速衰减 | **高维指数快速衰减** | 胖尾 (Heavy-tailed) |

**局限（误区与反例）**：每个边际分布服从一维正态分布并不意味着联合分布服从多元正态分布（必须要求任意线性组合均服从正态）；此外多元正态分布无法有效建模金融领域的肥尾 (Fat-tailed) 极值风险。

## 4. Python 手写多元正态密度计算与条件分布自测断言

```python
import numpy as np

def mvn_pdf(x: np.ndarray, mean: np.ndarray, cov: np.ndarray) -> float:
    """计算 p-维多元正态分布概率密度 PDF"""
    p = len(mean)
    det_cov = np.linalg.det(cov)
    inv_cov = np.linalg.inv(cov)
    diff = x - mean
    exponent = -0.5 * (diff.T @ inv_cov @ diff)
    norm_const = 1.0 / ((2.0 * np.pi)**(p / 2.0) * np.sqrt(det_cov))
    return float(norm_const * np.exp(exponent))

if __name__ == "__main__":
    mean = np.array([1.0, 2.0])
    cov = np.array([[2.0, 0.5], [0.5, 1.0]])

    # 1. 计算均值点处的概率密度
    pdf_center = mvn_pdf(mean, mean, cov)
    assert pdf_center > 0.0, "均值点密度必须大于 0"

    # 2. 条件正态分布 Schur 补推导自测
    mu1, mu2 = mean[0], mean[1]
    s11, s12, s22 = cov[0,0], cov[0,1], cov[1,1]

    x2_val = 3.0  # 给定 x2 = 3.0
    cond_mu1 = mu1 + (s12 / s22) * (x2_val - mu2)  # 1.0 + 0.5/1.0 * (3-2) = 1.5
    cond_cov1 = s11 - (s12**2 / s22)               # 2.0 - 0.25/1.0 = 1.75

    assert abs(cond_mu1 - 1.5) < 1e-5, f"条件均值推导错误: {cond_mu1}"
    assert abs(cond_cov1 - 1.75) < 1e-5, f"条件方差 Schur 补推导错误: {cond_cov1}"

    print(f"多元正态分布 均值点 PDF = {pdf_center:.4f}")
    print(f"条件正态分布 (x1|x2=3.0): 均值 = {cond_mu1:.2f}, 条件方差 = {cond_cov1:.4f}")
    print("多元正态分布 单元测试与自查验证全部成功！")
```
