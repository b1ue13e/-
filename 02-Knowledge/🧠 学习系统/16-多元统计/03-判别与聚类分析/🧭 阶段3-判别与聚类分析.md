# 🧭 阶段 3 - 判别与聚类分析

> **阶段定位**：本阶段掌握有监督模式识别与无监督群体分割方法。
> 
> 重点解决：如何通过 **Fisher LDA Rayleigh 商优化**、**QDA 异方差贝叶斯决策面**、**K-Means / Ward 层次聚类** 与 **GMM-EM 概率软聚类**，实现多维空间中复杂几何边界的判别与分割。
