# 多元统计-前置-矩阵微积分与二次型

## 1. 为什么多元统计必须熟练掌握矩阵微积分？

在一元统计学中，求似然函数的极值点只需要对标量参数 $\mu, \sigma^2$ 求一阶导数令为零。
但在多元统计中，待估计的参数是**均值向量 $\boldsymbol{\mu} \in \mathbb{R}^p$** 与 **协方差矩阵 $\mathbf{\Sigma} \in \mathbb{R}^{p \times p}$**。
似然函数中包含大量的**矩阵二次型 $(\mathbf{x}-\boldsymbol{\mu})^T \mathbf{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})$**、**矩阵迹 $\operatorname{tr}(\mathbf{A}\mathbf{B})$** 与 **对数行列式 $\ln|\mathbf{\Sigma}|$**。

如果不掌握严格的矩阵求导法则，多元正态分布的 MLE 估计、Fisher LDA 投影向量求解、PCA 拉格朗日优化都会沦为机械死记硬背。

## 2. 向量微积分核心法则与严格推导

### 2.1 线性形式求导法则

设 $\mathbf{a}, \mathbf{x} \in \mathbb{R}^p$，标量函数 $f(\mathbf{x}) = \mathbf{a}^T \mathbf{x} = \mathbf{x}^T \mathbf{a} = \sum_{i=1}^p a_i x_i$。
按分量求偏导：
$$\frac{\partial f}{\partial x_k} = a_k \implies \nabla_{\mathbf{x}} (\mathbf{a}^T \mathbf{x}) = \mathbf{a}$$

### 2.2 二次型求导法则

设 $\mathbf{A} \in \mathbb{R}^{p \times p}$，标量二次型 $g(\mathbf{x}) = \mathbf{x}^T \mathbf{A} \mathbf{x} = \sum_{i=1}^p \sum_{j=1}^p A_{ij} x_i x_j$。
对第 $k$ 个分量 $x_k$ 求偏导：
$$\frac{\partial g}{\partial x_k} = \sum_{j=1}^p A_{kj} x_j + \sum_{i=1}^p A_{ik} x_i = (\mathbf{A}\mathbf{x})_k + (\mathbf{A}^T\mathbf{x})_k$$
因此，一般矩阵二次型的梯度为：
$$\nabla_{\mathbf{x}} (\mathbf{x}^T \mathbf{A} \mathbf{x}) = (\mathbf{A} + \mathbf{A}^T)\mathbf{x}$$
> [!IMPORTANT]
> **当 $\mathbf{A}$ 为对称矩阵（$\mathbf{A} = \mathbf{A}^T$）时**：
> $$\nabla_{\mathbf{x}} (\mathbf{x}^T \mathbf{A} \mathbf{x}) = 2\mathbf{A}\mathbf{x}$$

## 3. 矩阵微积分核心定理与行列式求导

在协方差极大似然估计与多元方差分析中，精度矩阵 $\mathbf{\Omega} = \mathbf{\Sigma}^{-1}$ 扮演核心角色。

### 3.1 矩阵迹求导定理与分量级推导

设 $\mathbf{X} \in \mathbb{R}^{p \times p}$，常数矩阵 $\mathbf{A} \in \mathbb{R}^{p \times p}$。考虑标量函数 $f(\mathbf{X}) = \operatorname{tr}(\mathbf{A}\mathbf{X}) = \sum_{i=1}^p \sum_{j=1}^p A_{ij} X_{ji}$。
对矩阵 $\mathbf{X}$ 的第 $(k, l)$ 个元素 $X_{kl}$ 求偏导：
$$\frac{\partial \operatorname{tr}(\mathbf{A}\mathbf{X})}{\partial X_{kl}} = \frac{\partial}{\partial X_{kl}} \left( \sum_{i=1}^p \sum_{j=1}^p A_{ij} X_{ji} \right) = A_{lk} = (\mathbf{A}^T)_{kl}$$
由此证明矩阵导数：
$$\nabla_{\mathbf{X}} \operatorname{tr}(\mathbf{A}\mathbf{X}) = \mathbf{A}^T$$

**微分法（Differential Form）推导框架**：
定义全微分关系 $df(\mathbf{X}) = \operatorname{tr}\left( (\nabla_{\mathbf{X}} f)^T d\mathbf{X} \right)$。
当 $f(\mathbf{X}) = \operatorname{tr}(\mathbf{A}\mathbf{X}\mathbf{B})$ 时：
$$df = \operatorname{tr}(\mathbf{A} d\mathbf{X} \mathbf{B}) = \operatorname{tr}(\mathbf{B} \mathbf{A} d\mathbf{X}) \implies (\nabla_{\mathbf{X}} f)^T = \mathbf{B} \mathbf{A} \implies \nabla_{\mathbf{X}} \operatorname{tr}(\mathbf{A}\mathbf{X}\mathbf{B}) = \mathbf{A}^T \mathbf{B}^T$$

### 3.2 对数行列式求导定理 (Log-Determinant Derivative)

根据 Jacobi 行列式微分公式，对可逆矩阵 $\mathbf{X} \succ 0$：
$$d|\mathbf{X}| = |\mathbf{X}| \operatorname{tr}(\mathbf{X}^{-1} d\mathbf{X})$$
因此，对数行列式微分：
$$d(\ln |\mathbf{X}|) = \frac{1}{|\mathbf{X}|} d|\mathbf{X}| = \operatorname{tr}(\mathbf{X}^{-1} d\mathbf{X})$$
对比全微分标准式 $df = \operatorname{tr}((\nabla_{\mathbf{X}} f)^T d\mathbf{X})$，得：
$$\nabla_{\mathbf{X}} \ln |\mathbf{X}| = \mathbf{X}^{-T}$$
当 $\mathbf{X}$ 为对称正定矩阵时：
$$\nabla_{\mathbf{X}} \ln |\mathbf{X}| = \mathbf{X}^{-1}$$

### 3.3 各向同性白化矩阵 $\mathbf{\Sigma}^{-1/2}$ 的第一性原理构造

已知协方差矩阵 $\mathbf{\Sigma} \succ 0$ 对称正定，由**谱定理（Spectral Theorem）**可正交对角化：
$$\mathbf{\Sigma} = \mathbf{Q} \mathbf{\Lambda} \mathbf{Q}^T, \quad \mathbf{Q} \mathbf{Q}^T = \mathbf{I}, \ \mathbf{\Lambda} = \operatorname{diag}(\lambda_1, \dots, \lambda_p) \ (\lambda_i > 0)$$
定义其**对称平方根逆矩阵（Whitening Matrix）**：
$$\mathbf{\Sigma}^{-1/2} = \mathbf{Q} \mathbf{\Lambda}^{-1/2} \mathbf{Q}^T, \quad \mathbf{\Lambda}^{-1/2} = \operatorname{diag}(1/\sqrt{\lambda_1}, \dots, 1/\sqrt{\lambda_p})$$
**白化性质（Whitening Property）**：
设随机向量 $\mathbf{X}$ 满足 $\operatorname{Cov}(\mathbf{X}) = \mathbf{\Sigma}$。构造变换向量 $\mathbf{Z} = \mathbf{\Sigma}^{-1/2} (\mathbf{X} - \boldsymbol{\mu})$，则：
$$\operatorname{Cov}(\mathbf{Z}) = \mathbf{\Sigma}^{-1/2} \operatorname{Cov}(\mathbf{X}) (\mathbf{\Sigma}^{-1/2})^T = \mathbf{\Sigma}^{-1/2} \mathbf{\Sigma} \mathbf{\Sigma}^{-1/2} = \mathbf{I}_p$$
这表明白化变换将任意各向异性的协方差椭球打回各向同性的标准单位球，使得欧氏距离与马氏距离在此空间中完全等价！

## 4. 实战推导：多元正态协方差矩阵的 MLE 闭式求解

设样本 $\mathbf{x}_1, \dots, \mathbf{x}_n \overset{iid}{\sim} N_p(\boldsymbol{\mu}, \mathbf{\Sigma})$，对数似然函数为：
$$\ell(\boldsymbol{\mu}, \mathbf{\Sigma}) = -\frac{np}{2}\ln(2\pi) - \frac{n}{2}\ln|\mathbf{\Sigma}| - \frac{1}{2}\sum_{i=1}^n (\mathbf{x}_i - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x}_i - \boldsymbol{\mu})$$
利用迹的恒等式，二次型之和可写为：
$$\sum_{i=1}^n (\mathbf{x}_i - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x}_i - \boldsymbol{\mu}) = \operatorname{tr}\left( \mathbf{\Sigma}^{-1} \sum_{i=1}^n (\mathbf{x}_i - \boldsymbol{\mu})(\mathbf{x}_i - \boldsymbol{\mu})^T \right) = \operatorname{tr}(\mathbf{\Sigma}^{-1} \mathbf{A})$$
令精度矩阵 $\mathbf{\Omega} = \mathbf{\Sigma}^{-1}$，似然函数关于 $\mathbf{\Omega}$ 为：
$$\ell(\mathbf{\Omega}) = \text{const} + \frac{n}{2}\ln|\mathbf{\Omega}| - \frac{1}{2}\operatorname{tr}(\mathbf{\Omega}\mathbf{A})$$
对 $\mathbf{\Omega}$ 求导并令为零：
$$\nabla_{\mathbf{\Omega}} \ell(\mathbf{\Omega}) = \frac{n}{2} \mathbf{\Omega}^{-1} - \frac{1}{2}\mathbf{A} = \mathbf{0} \implies \mathbf{\Omega}^{-1} = \hat{\mathbf{\Sigma}} = \frac{1}{n}\mathbf{A} = \frac{1}{n}\sum_{i=1}^n (\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^T$$
这从第一性原理严格证明了多元样本协方差的 MLE 闭式解！

## 5. Python 符号求导与数值验证

```python
import numpy as np

# 数值梯度与解析梯度对比
np.random.seed(42)
p = 3
A = np.random.randn(p, p)
A = A @ A.T  # 对称正定
x = np.random.randn(p)

# 1. 解析梯度: 2 * A @ x
grad_analytic = 2 * A @ x

# 2. 有限差分数值梯度
eps = 1e-6
grad_numeric = np.zeros(p)
for i in range(p):
    x_plus = x.copy()
    x_minus = x.copy()
    x_plus[i] += eps
    x_minus[i] -= eps
    f_plus = x_plus.T @ A @ x_plus
    f_minus = x_minus.T @ A @ x_minus
    grad_numeric[i] = (f_plus - f_minus) / (2 * eps)

print("解析梯度:", np.round(grad_analytic, 5))
print("数值梯度:", np.round(grad_numeric, 5))
assert np.allclose(grad_analytic, grad_numeric, atol=1e-5)
print("✅ 矩阵二次型微积分数值验证通过！")
```
