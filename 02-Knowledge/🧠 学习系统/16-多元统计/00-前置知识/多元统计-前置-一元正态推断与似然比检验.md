# 多元统计-前置-一元正态推断与似然比检验

## 1. 为什么多元检验方法是一元推断的自然推广？

多元统计中的核心推断工具（Hotelling $T^2$、MANOVA、协方差齐性 Box's M）并非凭空捏造，而是经典一元数理统计理论在高维矩阵参数空间中的严格推广：
- **单样本 $t$ 检验** $\longrightarrow$ **单样本 Hotelling $T^2$ 检验**；
- **两独立样本等方差 $t$ 检验** $\longrightarrow$ **两样本 Hotelling $T^2$ 检验**；
- **单因素方差分析 (ANOVA $F$ 检验)** $\longrightarrow$ **多元方差分析 (MANOVA Wilks' $\Lambda$)**；
- **方差齐性 Bartlett 检验** $\longrightarrow$ **协方差齐性 Box's M 检验**。

理解一元推断中**似然比检验 (Likelihood Ratio Test, LRT)** 的构造逻辑与自由度损耗，是掌握多元推断第一性原理的前提。

## 2. 经典一元正态均值推断回顾

### 2.1 单样本 Student's t 检验

设 $X_1, \dots, X_n \overset{iid}{\sim} N(\mu, \sigma^2)$，检验 $H_0: \mu = \mu_0$ vs $H_1: \mu \neq \mu_0$。
样本均值 $\bar{X} \sim N(\mu_0, \sigma^2/n)$，样本方差 $S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$，且 $(n-1)S^2/\sigma^2 \sim \chi^2(n-1)$。
根据 Student's $t$ 分布定义：
$$t = \frac{\bar{X} - \mu_0}{S / \sqrt{n}} = \frac{\sqrt{n}(\bar{X} - \mu_0)}{\sqrt{S^2}} \sim t(n-1)$$
> [!NOTE]
> 平方形式：$t^2 = \frac{n(\bar{X} - \mu_0)^2}{S^2} \sim F(1, n-1)$。这正是一元形式的 Hotelling $T^2$！

### 2.2 两样本合并方差 t 检验

设两独立样本 $X_{11}, \dots, X_{1n_1} \overset{iid}{\sim} N(\mu_1, \sigma^2)$ 与 $X_{21}, \dots, X_{2n_2} \overset{iid}{\sim} N(\mu_2, \sigma^2)$。
合并样本方差：
$$S_{pooled}^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}$$
统计量：
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{S_{pooled}^2 \left(\frac{1}{n_1} + \frac{1}{n_2}\right)}} \sim t(n_1 + n_2 - 2)$$

## 3. 似然比检验 (LRT) 与 Wilks 大样本渐近定理

### 3.1 广义似然比统计量构造

设总体分布族概率密度为 $f(x; \boldsymbol{\theta}), \boldsymbol{\theta} \in \Theta$。检验假设：
$$H_0: \boldsymbol{\theta} \in \Theta_0 \quad \text{vs} \quad H_1: \boldsymbol{\theta} \in \Theta \setminus \Theta_0$$
定义**广义似然比 (Likelihood Ratio)**：
$$\Lambda = \frac{\sup_{\boldsymbol{\theta} \in \Theta_0} L(\boldsymbol{\theta})}{\sup_{\boldsymbol{\theta} \in \Theta} L(\boldsymbol{\theta})}, \quad 0 \le \Lambda \le 1$$
$\Lambda$ 越小，说明在约束参数空间 $\Theta_0$ 下的似然度显著低于全局无约束最大似然，支持拒绝原假设 $H_0$。

### 3.2 Wilks 渐近卡方定理 (Wilks' Theorem)

当样本量 $n \to \infty$ 时，在正则性条件及 $H_0$ 为真的前提下：
$$-2 \ln \Lambda \overset{d}{\longrightarrow} \chi^2(df)$$
其中自由度 $df = \dim(\Theta) - \dim(\Theta_0)$ 为原假设所施加的约束参数个数。
这是协方差结构检验（Box's M、Bartlett 球形检验）与因子分析模型拟合度卡方检验的通用渐近理论基础。

## 4. Python 代码：LRT 统计量与 F 分布精确对齐

```python
import numpy as np
from scipy import stats

np.random.seed(42)
n = 30
mu_0 = 5.0
X = np.random.normal(loc=5.5, scale=1.2, size=n)

# 1. 经典 t 检验
t_stat, p_val_t = stats.ttest_1samp(X, mu_0)

# 2. 极大似然比统计量 LRT
x_bar = np.mean(X)
# 无约束 MLE 方差: s_mle^2 = sum(x - x_bar)^2 / n
var_unconstrained = np.var(X, ddof=0)
# H0 约束下的 MLE 方差: s_0^2 = sum(x - mu_0)^2 / n
var_constrained = np.mean((X - mu_0) ** 2)

# Lambda = (var_unconstrained / var_constrained)^(n/2)
lambda_stat = (var_unconstrained / var_constrained) ** (n / 2.0)
lrt_chi2 = -2.0 * np.log(lambda_stat)
p_val_lrt = 1.0 - stats.chi2.cdf(lrt_chi2, df=1)

print(f"Student t 统计量: {t_stat:.4f}, p-value: {p_val_t:.4f}")
print(f"Wilks LRT 卡方值: {lrt_chi2:.4f}, 渐近 p-value: {p_val_lrt:.4f}")
print(f"t^2 精确等于 (n-1) * (var_constrained / var_unconstrained - 1): {(n-1)*(var_constrained/var_unconstrained - 1):.4f} == t^2: {t_stat**2:.4f}")
```

## 5. 检索自测练习

1. 证明在一元正态单样本均值检验中，LRT 统计量 $\Lambda$ 与 Student's $t$ 统计量之间满足单调双射关系 $\Lambda = \left(1 + \frac{t^2}{n-1}\right)^{-n/2}$。
2. 解释为什么小样本情况下直接使用 Wilks 渐近卡方分布会导致检验水平膨胀（偏激进），而需要通过 Bartlett 修正因子进行修正。
