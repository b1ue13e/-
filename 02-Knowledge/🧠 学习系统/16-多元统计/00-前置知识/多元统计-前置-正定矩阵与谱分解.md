# 多元统计-前置-正定矩阵与谱分解

## 1. 为什么谱分解是多元降维与几何度量的核心钥匙？

在多维欧氏空间中，欧几里得距离 $d(\mathbf{x}, \mathbf{y}) = \sqrt{(\mathbf{x}-\mathbf{y})^T(\mathbf{x}-\mathbf{y})}$ 假设空间在各个方向上的伸缩比例相同（各向同性），且各坐标轴之间完全正交不相关。
但在真实世界数据中：
1. **各维度量纲不同**（如身高与体重、利率与GDP）；
2. **维度之间存在强烈的线性相关性**（如通胀与利率）。

协方差矩阵 $\mathbf{\Sigma}$ 就是数据空间的**度量张量**。通过**对称谱分解**，我们可以把倾斜、拉伸的数据椭球**正交旋转到主轴方向**，并通过**白化变换**将其还原为标准各向同性的正球体！

---

## 2. 实对称矩阵谱定理与几何解释

### 2.1 谱分解定理 (Spectral Theorem)

设 $\mathbf{\Sigma} \in \mathbb{R}^{p \times p}$ 为实对称矩阵（$\mathbf{\Sigma} = \mathbf{\Sigma}^T$）。则存在正交矩阵 $\mathbf{P} = [\mathbf{e}_1, \dots, \mathbf{e}_p]$（满足 $\mathbf{P}^T \mathbf{P} = \mathbf{I}_p$）和实特征值对角矩阵 $\mathbf{\Lambda} = \operatorname{diag}(\lambda_1, \dots, \lambda_p)$，使得：
$$\mathbf{\Sigma} = \mathbf{P} \mathbf{\Lambda} \mathbf{P}^T = \sum_{j=1}^p \lambda_j \mathbf{e}_j \mathbf{e}_j^T$$
其中：
- $\mathbf{e}_j$ 为相互正交的单位特征向量，决定了**数据散布的主轴几何方向**；
- $\lambda_j \ge 0$ 为对应的特征值，决定了**数据在第 $j$ 主轴方向上的方差大小**。

### 2.2 正定性与二次型超椭球面

当 $\mathbf{\Sigma} \succ 0$ 严格正定（所有 $\lambda_j > 0$）时，二次型等高线方程：
$$(\mathbf{x} - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu}) = c^2$$
在 $\mathbb{R}^p$ 中定义了一个**以 $\boldsymbol{\mu}$ 为中心、主轴方向为 $\mathbf{e}_j$、半轴长度为 $c\sqrt{\lambda_j}$ 的超椭球**。

## 3. 空间白化变换 (Whitening / Sphering)

如何消除多变量之间的相关性并将方差统一为 1？
定义对称平方根逆矩阵：
$$\mathbf{\Sigma}^{-1/2} = \mathbf{P} \mathbf{\Lambda}^{-1/2} \mathbf{P}^T = \sum_{j=1}^p \frac{1}{\sqrt{\lambda_j}} \mathbf{e}_j \mathbf{e}_j^T$$
设随机向量 $\mathbf{X} \sim N_p(\boldsymbol{\mu}, \mathbf{\Sigma})$，定义**白化变换 (ZCA Whitening)**：
$$\mathbf{Z} = \mathbf{\Sigma}^{-1/2} (\mathbf{X} - \boldsymbol{\mu})$$
易验证：
$$\mathbb{E}[\mathbf{Z}] = \mathbf{0}, \quad \operatorname{Cov}(\mathbf{Z}) = \mathbf{\Sigma}^{-1/2} \mathbf{\Sigma} \mathbf{\Sigma}^{-1/2} = \mathbf{I}_p$$
> [!TIP]
> **第一性原理洞察**：马氏距离的本质，就是**将数据经过白化变换投影到标准正交空间后的欧氏距离**：
> $$D_M^2(\mathbf{X}, \boldsymbol{\mu}) = (\mathbf{X} - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{X} - \boldsymbol{\mu}) = \|\mathbf{\Sigma}^{-1/2}(\mathbf{X} - \boldsymbol{\mu})\|_2^2 = \|\mathbf{Z}\|_2^2$$

## 4. 广义特征值问题 (Generalized Eigenvalue Problem)

在判别分析 (LDA)、典型相关分析 (CCA) 与多元方差分析 (MANOVA) 中，核心优化目标往往是两个二次型之比（**Rayleigh 商**）：
$$\max_{\mathbf{w} \neq \mathbf{0}} \frac{\mathbf{w}^T \mathbf{A} \mathbf{w}}{\mathbf{w}^T \mathbf{B} \mathbf{w}} \quad (\mathbf{B} \succ 0)$$
求导令梯度为零：
$$2\mathbf{A}\mathbf{w} \cdot (\mathbf{w}^T\mathbf{B}\mathbf{w}) - 2\mathbf{B}\mathbf{w} \cdot (\mathbf{w}^T\mathbf{A}\mathbf{w}) = \mathbf{0} \implies \mathbf{A}\mathbf{w} = \lambda \mathbf{B}\mathbf{w}$$
其中 $\lambda = \frac{\mathbf{w}^T \mathbf{A} \mathbf{w}}{\mathbf{w}^T \mathbf{B} \mathbf{w}}$。
**求解方法**：两边左乘 $\mathbf{B}^{-1}$ 转换为标准特征值问题：
$$\mathbf{B}^{-1}\mathbf{A}\mathbf{w} = \lambda \mathbf{w}$$
或通过对称化变换 $\tilde{\mathbf{w}} = \mathbf{B}^{1/2}\mathbf{w}$，求解对称阵 $\mathbf{B}^{-1/2}\mathbf{A}\mathbf{B}^{-1/2}\tilde{\mathbf{w}} = \lambda \tilde{\mathbf{w}}$。

## 5. Python 实战代码：白化变换与椭球几何

```python
import numpy as np
import matplotlib.pyplot as plt

# 构造具有强相关性的 2D 协方差数据
np.random.seed(42)
cov = np.array([[3.0, 1.8], [1.8, 2.0]])
mu = np.array([1.0, 2.0])
X = np.random.multivariate_normal(mu, cov, size=300)

# 1. 谱分解与白化矩阵计算
eigvals, eigvecs = np.linalg.eigh(cov)
inv_sqrt_cov = eigvecs @ np.diag(1.0 / np.sqrt(eigvals)) @ eigvecs.T

# 2. 白化变换
X_centered = X - mu
Z_whitened = X_centered @ inv_sqrt_cov.T

# 验证白化后的样本协方差是否逼近单位矩阵 I
cov_z = np.cov(Z_whitened, rowvar=False)
print("白化前原始协方差矩阵:\n", np.round(cov, 3))
print("白化后样本协方差矩阵:\n", np.round(cov_z, 3))
assert np.allclose(cov_z, np.eye(2), atol=0.15)
print("✅ 谱分解与空间白化变换验证通过！")
```
