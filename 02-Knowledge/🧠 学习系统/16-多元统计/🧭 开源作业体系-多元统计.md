# 🧭 开源作业体系-多元统计

> 本页是「多元统计」开源名校课程与作业的**唯一挂载点**：教材主线、官方作业链 HW01-HW05、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**Penn State STAT 505**（https://online.stat.psu.edu/stat505/，CC BY-NC 4.0）+ **An Introduction to Applied Multivariate Analysis with R**（open textbook）+ **R / Python sklearn** 实验。

## 📚 教材主线（Spine）

| 角色 | 来源 | 用途 |
|:---|:---|:---|
| 主教材 | [Penn State STAT 505](https://online.stat.psu.edu/stat505/) | 多元正态、均值向量推断、协方差、PCA、因子分析、判别、聚类、典型相关 |
| 工具 | R: `MASS`、`factoextra`、`psych`；Python: `sklearn` / `scipy` | 完整多元分析工作流 |
| 教材补充 | Johnson & Wichern *Applied Multivariate Statistical Analysis* | 深度理论 |
| 前置 | 30-应用回归分析 + 22-概率论 | 多元正态、似然推断 |

**Honor Code 说明**：STAT 505 讲义 CC BY-NC 4.0 可在笔记中引用并署名；作业独立完成；R / Python 实现可参考文档但禁止直接复制教科书代码。

## 🎯 作业体系（HW01-HW05）

| HW | 主题 | 官方来源（STAT 505 章节） | 所需知识点 | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 多元正态与均值向量 | STAT 505 Lesson 1-4 | 待补卡（多元正态、均值向量、协方差矩阵） | 闭卷手算 + 真实数据描述统计 |
| HW02 | 推断（Hotelling T²、似然比） | STAT 505 Lesson 5-7 | 待补卡（Hotelling T²、Wilks Lambda） | 闭卷手算两均值对比 + 与 `scipy.stats` 对照 |
| HW03 | 主成分分析（PCA） | STAT 505 Lesson 8-10 | [[主成分分析PCA]] | PCA 推导 + 碎石图 + 解释方差比 |
| HW04 | 判别分析（LDA / QDA） | STAT 505 Lesson 11-13 | 待补卡（LDA、QDA、Bayes 判别） | 自写 LDA + 与 `sklearn` 对照 |
| HW05 | 聚类与因子分析 | STAT 505 Lesson 14-16 | 待补卡（k-means、层次聚类、因子分析） | 聚类 + 因子分析双报告 + 解释性评估 |

> 分层验收原则：HW01-02 是**分布与推断链**；HW03-04 是**降维与判别链**；HW05 是**聚类与潜变量收尾**。

## ✅ 验收方式与评分

1. **每个 HW 三件套**：① 闭卷手算（小样本多元正态）；② R/Python 实现；③ 1 页报告（数据背景 + 假设检验 + 解释）。
2. **数据来源**：R 内置（`iris` / `mtcars` / `USArrests`）+ UCI 多元数据集。
3. **满分 Rubric**：HW01-05 各 20 分，共 100 分（手算 25 + 实现 45 + 报告 30）。
