# 多元统计-高维数据的维度灾难

## 1. 为什么高维统计不能直接复用经典多元统计公式？

当数据维度 $p$ 接近或显著大于样本量 $n$（即大 $p$ 小 $n$ 场景，$p \ge n$），经典多元统计面临崩溃：
1. **样本协方差矩阵奇异**：$\operatorname{rank}(\mathbf{S}) \le \min(n-1, p) < p$，导致 $\mathbf{S}^{-1}$ 无法直接求逆（马氏距离、Hotelling $T^2$、LDA 算法失效）；
2. **特征值谱偏离（Marchenko-Pastur 畸变）**：主成分分析的最大特征值被严重高估，最小特征值被严重低估；
3. **几何距离集中效应 (Distance Concentration)**：在超高维欧氏空间中，任意两点间的相对距离差趋于零，使得基于欧氏距离的聚类与近邻算法失效。

---

## 2. 核心现象与几何理论

### 2.1 高维超球体积归零与壳集中现象

设 $p$ 维单位超球 $V_p(R) = \frac{\pi^{p/2}}{\Gamma(p/2 + 1)} R^p$。当 $p \to \infty$ 时：
$$\lim_{p \to \infty} V_p(1) = 0$$
高维空间的绝大部分体积都集中在靠近超球外壳（Thin Shell）的极薄区域内，且随机样本点几乎相互正交。

### 2.2 样本协方差矩阵的 Ledoit-Wolf 压缩估计

为了解决高维下 $\mathbf{S}$ 奇异与病态求逆问题，Ledoit & Wolf (2004) 提出最佳线性压缩估计器：
$$\mathbf{\Sigma}^* = (1 - \alpha) \mathbf{S} + \alpha \mu \mathbf{I}_p$$
其中 target $\mu = \frac{\operatorname{tr}(\mathbf{S})}{p}$。
- **解析求解最优压缩强度 $\alpha \in [0, 1]$**：最小化均方误差 $\mathbb{E}[\|\mathbf{\Sigma}^* - \mathbf{\Sigma}\|_F^2]$；
- **优点**：所得矩阵 $\mathbf{\Sigma}^*$ 恒保证**严格正定且可逆**，良置求逆矩阵，且在均方误差意义下显著优于原始样本协方差 $\mathbf{S}$。

## 3. Python 实战代码：高维 $p > n$ 协方差 Ledoit-Wolf 正则化

```python
import sys
import numpy as np

sys.path.insert(0, r"f:\-\03-Projects\16-多元统计\scripts")
from mva_toolkit import ledoit_wolf_shrinkage

# 模拟高维小样本数据: n=20, p=50 (p > n)
np.random.seed(42)
n, p = 20, 50
X_high = np.random.randn(n, p)

# 1. 原始样本协方差矩阵
S = np.cov(X_high, rowvar=False, ddof=1)
rank_S = np.linalg.matrix_rank(S)
print(f"原始样本协方差矩阵秩: {rank_S} (维度 p={p}) -> 必须奇异不可逆！")

# 2. 运行 Ledoit-Wolf 压缩估计
lw_res = ledoit_wolf_shrinkage(X_high)
S_shrunk = lw_res['shrunk_cov']
alpha = lw_res['shrinkage_intensity']

eigvals_shrunk = np.linalg.eigvalsh(S_shrunk)
min_eig = np.min(eigvals_shrunk)

print(f"最优 Ledoit-Wolf 压缩强度 alpha: {alpha:.4f}")
print(f"压缩后协方差矩阵最小特征值: {min_eig:.4f} -> 严格正定可逆！")

assert rank_S <= n
assert min_eig > 0
print("✅ 高维协方差 Ledoit-Wolf 压缩估计验证成功！")
```
