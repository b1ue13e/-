# 多元统计-因子分析

## 1. 为什么有了 PCA 还需要因子分析 (FA)？

虽然 PCA 与因子分析都是多元降维方法，但两者的**统计哲学本质完全不同**：
- **PCA（描述性数据压缩）**：纯数据驱动的正交线性组合，目标是**最大化解释原始变量的总方差**，不假设潜变量概率生成模型；
- **因子分析（潜变量生成概率模型）**：假设可观测变量 $\mathbf{X}$ 是由少数几个**不可观测的潜公共因子 (Common Factors)** 加上**特殊误差 (Specific Factors)** 线性生成的，目标是**解释原始变量之间的协方差/相关性结构**。

---

## 2. 正交因子模型与协方差分解定理

### 2.1 数学生成模型

设观测随机向量 $\mathbf{X} = (X_1, \dots, X_p)^T$，均值 $\boldsymbol{\mu}$。正交因子模型为：
$$\mathbf{X} - \boldsymbol{\mu} = \mathbf{L} \mathbf{F} + \boldsymbol{\epsilon}$$
其中：
- $\mathbf{F} = (F_1, \dots, F_m)^T$ 为 $m$ 个正交公共因子 ($m \ll p$)，满足 $\mathbb{E}[\mathbf{F}] = \mathbf{0}, \operatorname{Cov}(\mathbf{F}) = \mathbf{I}_m$；
- $\mathbf{L} = (\ell_{ij})_{p \times m}$ 为**因子载荷矩阵 (Factor Loading Matrix)**；
- $\boldsymbol{\epsilon} = (\epsilon_1, \dots, \epsilon_p)^T$ 为特殊因子/误差，满足 $\mathbb{E}[\boldsymbol{\epsilon}] = \mathbf{0}, \operatorname{Cov}(\boldsymbol{\epsilon}) = \mathbf{\Psi} = \operatorname{diag}(\psi_1, \dots, \psi_p)$；
- 假定公共因子与特殊因子相互独立：$\operatorname{Cov}(\mathbf{F}, \boldsymbol{\epsilon}) = \mathbf{0}$。

### 2.2 协方差分解基本定理

由模型假设直接推导观测变量的协方差矩阵结构：
$$\mathbf{\Sigma} = \operatorname{Cov}(\mathbf{X}) = \operatorname{Cov}(\mathbf{L}\mathbf{F} + \boldsymbol{\epsilon}) = \mathbf{L} \operatorname{Cov}(\mathbf{F}) \mathbf{L}^T + \operatorname{Cov}(\boldsymbol{\epsilon}) = \mathbf{L}\mathbf{L}^T + \mathbf{\Psi}$$
对第 $i$ 个变量的方差进行分解：
$$\operatorname{Var}(X_i) = \sigma_{ii} = \sum_{j=1}^m \ell_{ij}^2 + \psi_i = h_i^2 + \psi_i$$
- **共同度 (Communality) $h_i^2 = \sum_{j=1}^m \ell_{ij}^2$**：变量 $X_i$ 能被 $m$ 个公共因子共同解释的方差比例；
- **特殊方差 (Uniqueness) $\psi_i$**：变量 $X_i$ 独有的特定方差与测量误差。

## 3. Kaiser Varimax 正交旋转准则

由于因子模型存在**旋转不确定性**（若 $\mathbf{T}$ 为正交阵，则 $\mathbf{L}^* = \mathbf{L}\mathbf{T}$ 与 $\mathbf{F}^* = \mathbf{T}^T\mathbf{F}$ 满足同样的协方差结构 $\mathbf{L}^*\mathbf{L}^{*T} = \mathbf{L}\mathbf{L}^T$），原始载荷矩阵往往难以给出清晰的业务解释。

**Varimax (最大方差正交旋转)** 目标：调整因子载荷，使每一个公共因子上的载荷平方的方差极大化，从而促使载荷矩阵逼近**简单结构 (Simple Structure)**——即每个变量只在某一个公共因子上有极高载荷（接近 $\pm 1$），而在其他因子上载荷接近 0。

目标优化函数：
$$V = \sum_{j=1}^m \left[ \frac{1}{p}\sum_{i=1}^p \left(\frac{\ell_{ij}^*}{h_i}\right)^4 - \left( \frac{1}{p}\sum_{i=1}^p \left(\frac{\ell_{ij}^*}{h_i}\right)^2 \right)^2 \right] \to \max$$

## 4. Python 实战代码：宏观经济指标 Varimax 因子旋转

```python
import sys
import numpy as np
import pandas as pd

sys.path.insert(0, r"f:\-\03-Projects\16-多元统计\scripts")
from load_data import load_macro_financial_panel
from mva_toolkit import factor_analysis_fit, kmo_test

# 1. 加载 10 个宏观经济变量
df_macro = load_macro_financial_panel()
macro_cols = ['GDP_Growth', 'CPI', 'PPI', 'M2_Growth', 'TSF_Increment', 'Base_Rate', 'PMI', 'Trade_Balance', 'Unemployment_Rate', 'Industrial_Output']
X = df_macro[macro_cols].values

# 2. 运行 EFA (主因子提取 + Varimax 正交旋转)
fa_res = factor_analysis_fit(X, n_factors=3, rotate=True)

df_loadings = pd.DataFrame(
    np.round(fa_res['loadings'], 2),
    index=macro_cols,
    columns=['Factor1_经济增长', 'Factor2_通胀名义', 'Factor3_货币流动性']
)

print("=== 宏观经济 10 维指标 Varimax 旋转后因子载荷矩阵 ===")
print(df_loadings)
print("\n各变量共同度 h_i^2:", np.round(fa_res['communalities'], 3))

assert np.all(fa_res['communalities'] > 0.3)
print("✅ 探索性因子分析与 Varimax 简单结构旋转成功！")
```
