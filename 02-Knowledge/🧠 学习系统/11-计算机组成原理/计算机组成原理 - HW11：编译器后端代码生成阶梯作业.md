# 计算机组成原理 - HW11：编译器后端代码生成阶梯作业

> 🎯 **作业目标**：手写符号表（类级 + 子程序级）与 VM 代码生成器，把 Jack 程序编译为 `.vm` 文件；最终编译官方 Pong 并在 CPU Emulator 配合 OS 全链路跑通。

---

## 1. ⚙️ 环境与 Starter Code 准备
- **Starter Code 路径**：`nand2tetris/projects/11/`（官方测试程序：`Seven`、`ConvertToBin`、`Square`、`Average`、`Pong`；前四个有官方预期 `.vm` 文件，`Pong` 无预期、以运行为准）
- **开源标杆仓库**：[nand2tetris/nand2tetris](https://github.com/nand2tetris/nand2tetris)（Software Suite：JackCompiler、VM Emulator、CPU Emulator、TextComparer）
- **实现语言自由**：Java / Python / C++ 均可，输出标准 VM 代码（与 HW07/08 的 VM Translator 格式完全一致）
- **符号表设计**：class 级（`static` / `field` → static/this 段）+ subroutine 级（`argument` / `var` → argument/local 段），进入子程序建表、退出销毁
- **验收链路**：`.jack` → 你的编译器 → `.vm` → 与官方预期 `.vm` 比对；`Pong` 则用 CPU Emulator 加载编译产物 + 官方 OS 运行
- **Honor Code**：官方 JackCompiler 可运行对照，编译器实现须自己完成

## 2. 🎯 阶梯式 Baseline / 难度设计 (4-Tier Difficulty)

| 梯度级别 | 验收标准 | 关键实现细节与要求 |
| :--- | :--- | :--- |
| 🟢 **L1 - Simple Baseline** | 表达式与常量 | 整数/字符串常量、算术表达式（`+ - * / & | ~` 及一元运算）生成正确 VM 代码；`Seven` 编译产物与官方 `.vm` 逐字节一致并通过 VM Emulator。 |
| 🟡 **L2 - Medium Baseline** | 变量与符号表 | 变量声明、`let` / `return` 语句、四种内存段（argument / local / static / this）的映射与压栈/弹栈；`ConvertToBin`、`Square` 通过比对与运行。 |
| 🔴 **L3 - Strong Baseline** | 控制流与函数调用 | `if` / `while` 唯一标签生成、`function` / `call` / `return` 调用约定、method 的 this 绑定、constructor 的 Memory.alloc；`Average` 通过。 |
| 👑 **L4 - Boss Baseline** | 编译 Pong 全链路 | 完整 Pong（含数组、字符串、OS 调用）由你的编译器编译，与官方 OS 一起在 CPU Emulator 上完整运行（可玩、计分、胜负判定）。 |

## 3. 🧪 自动化测试 Harness (Validation)

官方 `.tst` 列表（VM Emulator 加载编译产物运行）：
- `projects/11/Seven/Seven.tst`、`projects/11/ConvertToBin/ConvertToBin.tst`
- `projects/11/Square/Square.tst`、`projects/11/Average/Average.tst`
- `projects/11/Pong/Pong.tst`（CPU Emulator，配合 OS）

Python 编译 + 比对示例：

```python
import subprocess
import pathlib

def compile_and_compare(jack_dir: str) -> bool:
    """编译 .jack 目录并与官方预期 .vm 比对"""
    subprocess.run(["MyJackCompiler", jack_dir], check=True)
    ok = True
    for vm in sorted(pathlib.Path(jack_dir).glob("*.vm")):
        expected = vm.with_name(vm.stem + "cmp.vm")   # 官方预期文件
        if expected.exists() and vm.read_text() != expected.read_text():
            print(f"MISMATCH: {vm.name}")
            ok = False
    return ok

assert compile_and_compare("projects/11/Seven")
assert compile_and_compare("projects/11/Square")
assert compile_and_compare("projects/11/Average")
```

shell 运行 Pong 全链路：

```bash
sh nand2tetris/tools/JackCompiler.sh projects/11/Pong && \
sh nand2tetris/tools/CPUEmulator.sh projects/11/Pong/Pong.tst
```

## 🃏 Anki 卡片

- Q: 编译 method 时如何绑定 this？
- A: 子程序符号表中把第 0 个参数绑定为 `this`（argument 段 slot 0）；调用端 `call` 前先 `push` 对象引用，再依次压入显式参数。
- Q: constructor 如何分配对象内存？
- A: 编译 `constructor` 时先为字段计数，生成 `Memory.alloc(fieldCount)` 调用，并把返回值存入 `pointer 0`（即 this），随后才初始化各字段。
- Q: Jack 字符串常量被编译成什么 VM 代码？
- A: 生成一段调用序列：`String.new(长度)` 创建实例，再逐个 `String.appendChar(字符)` 追加内容，最终在栈顶留下字符串对象引用。
- Q: 为什么 if/while 生成的标签必须唯一？
- A: 嵌套与多次出现的 if/while 若共用标签会导致跳转目标歧义；用计数器生成 `IF_TRUE1`、`IF_FALSE1`、`WHILE_EXP1` 等自增唯一标签。
