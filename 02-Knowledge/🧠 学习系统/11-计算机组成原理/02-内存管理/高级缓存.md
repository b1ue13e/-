# 高级缓存 (Non-blocking Cache, Victim Cache & Beyond)

## 1. 为什么学：缓存优化的最后一公里

`缓存性能.md` 讲了 4C 缺失模型与基础优化。这张卡覆盖**现代 CPU 缓存的高级技术**：非阻塞缓存（隐藏缺失惩罚）、Victim Cache（减少冲突缺失）、缓存压缩（容量扩展）。这些技术是理解"为什么 Intel/Apple 缓存设计各不相同"的关键。

## 2. 非阻塞缓存（Non-blocking Cache）

### 2.1 问题

阻塞缓存（Blocking Cache）在缺失时**暂停整个流水线**等待数据——缺失惩罚直接暴露给性能。

### 2.2 机制

- **Hit Under Miss**：缺失进行时，后续命中仍可被服务；
- **Miss Under Miss / 多缺失跟踪（MSHR）**：同时跟踪多个在途缺失（如 4-8 个 MSHR 条目），重叠多个缺失的延迟；
- **代价**：需要 MSHR 表、标签比较逻辑复杂化。

## 3. Victim Cache（牺牲缓存）

- **动机**：直接映射/低相联缓存的冲突缺失严重（如数组步长 = 缓存大小时）；
- **机制**：在缓存与下一层之间放一个小全相联缓存（通常 4-16 项），被主缓存驱逐的块先放入 victim cache；
- **命中路径**：主缓存缺失 → 查 victim cache → 命中则交换回来（把 victim 块放回主缓存）；
- 经典结果（Jouppi 1990）：4 项 victim cache 消除 20-40% 冲突缺失。

## 4. 缓存压缩（Cache Compression）

- 把相邻数据压缩存储，等效扩大缓存容量；
- 常见方案：**零值压缩（Zero-Content）**——全零块的指针表示；**频繁模式压缩**（Frequent Pattern Compression）；
- 挑战：压缩/解压延迟、与一致性协议的交互。

## 5. 其他高级技术

| 技术 | 思路 | 应用 |
|:---|:---|:---|
| **预取（Prefetch）** | 提前取数据隐藏延迟 | 见 [[存储层次详解]] |
| **分区缓存（Partitioning）** | 多核按需分配缓存 | 云/虚拟化 QoS |
| **动态缓存大小** | 按负载调整激活路数 | 低功耗场景 |
| **Sectored Cache** | 大块内分扇区，只取需要的子块 | 减少带宽浪费 |

## 6. 常见误区（反例）

- **误区 1**："非阻塞缓存免费"——MSHR 条目、标签逻辑增加面积与功耗，收益有限时（低缺失率）不划算；
- **误区 2**："Victim Cache 能替代高相联度"——victim cache 只救冲突缺失，容量/强制缺失无效；
- **误区 3**："缓存压缩必然赢"——压缩率取决于数据特征，随机数据压缩率低且开销大。
