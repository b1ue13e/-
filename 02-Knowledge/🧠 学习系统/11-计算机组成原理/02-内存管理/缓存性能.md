# 缓存性能 (AMAT, Hit Rate, Miss Penalty & Optimization)

## 1. 为什么学：缓存好不好，用数字说话

`缓存设计.md` 讲了缓存的三大决策（映射/写/替换）。这张卡把**性能量化**补上：如何用 AMAT 评估缓存、缺失的四种来源（4C）、以及减少缺失/缺失代价的优化手段。这是 CSAPP Cache Lab 和阶段作业 HW02 的直接理论基础。

## 2. 核心指标与公式

### 2.1 命中率与缺失率

$$\text{命中率 } h = \frac{\text{命中次数}}{\text{总访问次数}}, \quad \text{缺失率 } m = 1 - h$$

### 2.2 平均访问时间 AMAT

$$\text{AMAT} = t_{hit} + m \times t_{miss}$$

- $t_{hit}$：命中时间（通常 1-4 周期）；$t_{miss}$：缺失惩罚（L1 缺失需访问 L2/L3/内存，可达百周期）。

### 2.3 缺失惩罚的分层

```
L1 miss → L2 (10周期) → L3 (40周期) → 内存 (100+周期)
```

- 现代 CPU 采用**多级缓存 + 非阻塞（Non-blocking）** 隐藏缺失惩罚（衔接 [[高级缓存]]）。

## 3. 缺失的四种来源（4C Model, Hill & Smith）

| 缺失类型 | 原因 | 对策 |
|:---|:---|:---|
| **强制缺失（Compulsory）** | 首次访问，块从未进缓存 | 预取（Prefetch）、更大的块 |
| **容量缺失（Capacity）** | 工作集 > 缓存容量 | 增大缓存 |
| **冲突缺失（Conflict）** | 多地址映射同组（相联度不足） | 提高相联度 |
| **一致性缺失（Coherency）** | 多核写失效（伪共享） | 一致性协议优化（衔接 [[高级缓存]]） |

## 4. 优化手段

| 手段 | 目标 | 机制 |
|:---|:---|:---|
| **增大块大小** | 减少强制/容量缺失 | 利用空间局部性（但块过大增缺失惩罚） |
| **提高相联度** | 减少冲突缺失 | 2-8 路组相联 |
| **预取（Prefetch）** | 隐藏缺失延迟 | 硬件/软件提前取块 |
| **Victim Cache** | 减少冲突缺失 | 缓存被驱逐的块 |
| **非阻塞缓存** | 隐藏缺失惩罚 | 命中继续服务（Hit Under Miss） |
| **写合并（Write Buffer）** | 减少写缺失 | 合并写回 |

## 5. 常见误区（反例）

- **误区 1**："命中率 99% 就够了"——若缺失惩罚 100 周期、命中 1 周期，1% 缺失使 AMAT 翻倍：$1 + 0.01 \times 100 = 2$ 周期，性能损失近半；
- **误区 2**："块越大越好"——块翻倍减半强制缺失但增缺失惩罚；块超过工作集特征反而性能下降；
- **误区 3**："只优化命中率"——有时容忍部分缺失、用非阻塞/预取隐藏惩罚更有效（延迟 vs 吞吐的取舍）。
