# 虚拟内存机制 (Virtual Memory)

## 1. 虚拟内存的定义与三大核心功能

**虚拟内存机制 (Virtual Memory)** 的核心定义是：由操作系统与硬件 MMU（内存管理单元）协同构建的内存管理抽象。它为每个进程提供一个连续、私有且统一的逻辑地址空间（如 x86-64 下的 256TB 虚拟地址空间），并将该虚拟空间透明隐蔽地映射至物理内存 (DRAM) 或辅存 (磁盘/SSD)。

**基本性质与三大核心功能**：
1. **缓存管理**：将物理 DRAM 视为主存与辅存之间的高速缓存（按需调页 Demand Paging）；
2. **内存管理**：为各进程提供一致的线性地址空间，简化链接、加载与共享库分配；
3. **保护机制**：通过页表项 (PTE) 标志位（R/W, U/S, XD）实现进程间隔离与内核态保护。

## 2. TLB 硬件加速与四级页表翻译推导

x86-64 使用 **48 位虚拟地址** 与 **TLB (Translation Lookaside Buffer)** 快表加速：

```
虚拟地址 (48位):
[47:39] PML4 (9位)  [38:30] PDPT (9位)  [29:21] PD (9位)  [20:12] PT (9位)  [11:0] Offset (12位)
```

**前提条件与地址翻译推导**：
1. **假设**：CPU 试图访问虚拟地址 $VA$；
2. **TLB 查找（$O(1)$ 硬件并行查找）**：用虚拟页号 VPN 匹配 TLB 中的 Tag。若 TLB 命中 (TLB Hit)，仅需 1 个周期即可直接组合得到物理地址 $PA = \text{PPN} \mid \text{VPO}$；
3. **TLB 缺失 (TLB Miss)**：由 MMU 硬件页表遍历器 (Page Table Walker) 依次查询 PML4 $\to$ PDPT $\to$ PD $\to$ PT 取得 PTE；
4. **因此**，TLB 命中的平均内存访问时间 $\text{AMAT} = h \cdot t_{\text{TLB}} + (1-h) \cdot (4 \cdot t_{\text{mem}} + t_{\text{TLB}})$，当命中率 $h > 99\%$ 时，四级页表带来的多倍内存访问开销被完全消除。

## 3. 虚拟内存与物理直接寻址的区别与对比

| 维度 | 物理直接寻址 (Physical Addressing) | 虚拟内存寻址 (Virtual Memory) |
|:---|:---|:---|
| **地址空间** | 全局唯一受限于物理 DRAM 大小 | 每个进程独立且可远大于物理 DRAM |
| **内存隔离** | 无隔离，一个进程崩溃全盘皆崩 | 独立页表强制隔离，无法非法跨进程访问 |
| **碎片管理** | 严重外部碎片 | 彻底消除外部碎片（按 4KB 页框分配）|
| **硬件需求** | 无需 MMU | 必须支持 MMU 与 TLB 硬件 |
| **典型应用** | 单片机 (Cortex-M)、早期 DOS | 现代通用 OS (Linux, Windows, macOS) |

**局限（反例/误区）**：虚拟内存机制引入了**颠簸 (Thrashing)** 风险——当所有进程的活跃工作集 (Working Set) 之和超过物理 DRAM 总量时，系统将频繁触发 Page Fault (#PF)，导致 CPU 时间全部耗费在磁盘 I/O 上，系统吞吐降为 0。

关联知识点推荐：[[分页机制]]、[[中断机制]]、[[内存调试]]、缓存一致性。

## 4. Python TLB 命中率与 AMAT 延迟仿真自测断言

```python
import numpy as np

def simulate_tlb_amat(hit_rate: float, t_tlb: float = 1.0,
                      t_mem: float = 100.0, page_table_levels: int = 4) -> float:
    """
    计算虚拟内存 AMAT (Average Memory Access Time)
    推导: AMAT = t_tlb + (1 - hit_rate) * (page_table_levels * t_mem) + t_mem
    """
    assert 0 <= hit_rate <= 1.0
    walk_penalty = page_table_levels * t_mem
    return t_tlb + (1.0 - hit_rate) * walk_penalty + t_mem

if __name__ == "__main__":
    # 自测验证 1: 高 TLB 命中率 (99%) AMAT 接近物理访存
    amat_99 = simulate_tlb_amat(0.99)
    # 理论 AMAT = 1 + 0.01*(400) + 100 = 105.0 ns
    assert abs(amat_99 - 105.0) < 1e-6

    # 自测验证 2: 完全 TLB 缺失 (0%) AMAT 飙升
    amat_0 = simulate_tlb_amat(0.0)
    # 理论 AMAT = 1 + 1.0*(400) + 100 = 501.0 ns
    assert abs(amat_0 - 501.0) < 1e-6
    assert amat_0 / amat_99 > 4.5, "TLB 缺失代价应高于 4.5 倍"

    # 自测验证 3: 异常边界 - Page Fault (#PF) 磁盘访问开销
    t_disk = 10_000_000.0  # 10ms
    amat_page_fault = 1.0 + 400.0 + t_disk
    assert amat_page_fault / amat_99 > 90000.0, "Page Fault 颠簸代价为数量级增长"

    print(f"虚拟内存 AMAT 仿真完成！")
    print(f"  TLB 99% 命中 AMAT = {amat_99:.1f} ns")
    print(f"  TLB 0% 缺失 AMAT  = {amat_0:.1f} ns (慢 {amat_0/amat_99:.2f}x)")
    print("虚拟内存机制单元测试与自查验证全部成功！")
```
