# 计算机组成原理 - HW10：编译器前端词法与语法分析阶梯作业

> 🎯 **作业目标**：手写 JackTokenizer（词法分析器）与 CompilationEngine（递归下降语法分析器），把 Jack 源码解析为 XML 语法树，并与官方 JackAnalyzer 输出逐字节比对一致。

---

## 1. ⚙️ 环境与 Starter Code 准备
- **Starter Code 路径**：`nand2tetris/projects/10/`（官方三个测试程序：`ArrayTest`、`ExpressionLessSquare`、`Square`，每个目录含若干 `.jack` 与官方预期 `.xml`）
- **开源标杆仓库**：[nand2tetris/nand2tetris](https://github.com/nand2tetris/nand2tetris)（Software Suite：JackAnalyzer、TextComparer）
- **实现语言自由**：Java / Python / C++ 均可，只要接口对齐官方 JackAnalyzer 的两种输出模式
- **两种输出模式**：默认输出**语法树 XML**（含嵌套标签）；`-t` 模式只输出 **token 流 XML**（五类 token 平铺）
- **验收工具**：TextComparer 逐字节比较你的 `.xml` 与官方预期 `.xml`，输出 "Comparison ended successfully" 才算通过
- **Honor Code**：官方 `JackAnalyzer` 可运行对照，但分析器实现须自己完成

## 3. 🧪 自动化测试 Harness (Validation)

官方测试：每目录一个 `.tst` 脚本（调用 JackAnalyzer + TextComparer）+ 官方预期 XML（如 `MainT.xml`、`SquareGameT.xml`）。Python 批量比对示例：

```python
import subprocess
import pathlib

def compare_with_official(prog_dir: str) -> bool:
    """运行自己的分析器，逐一与官方预期 XML 比对"""
    subprocess.run(["MyJackAnalyzer", prog_dir], check=True)
    ok = True
    for xml in sorted(pathlib.Path(prog_dir).glob("*.xml")):
        expected = xml.with_name(xml.stem + "T.xml")   # 官方预期文件
        if expected.exists() and xml.read_text() != expected.read_text():
            print(f"MISMATCH: {xml.name}")
            ok = False
    return ok

assert compare_with_official("projects/10/ArrayTest")
assert compare_with_official("projects/10/ExpressionLessSquare")
assert compare_with_official("projects/10/Square")
```

shell 单目录验证示例：

```bash
sh nand2tetris/tools/TextComparer.sh \
  projects/10/Square/MainT.xml projects/10/Square/Main.xml
```

## 🃏 Anki 卡片

- Q: 递归下降解析中如何保证运算符优先级？
- A: 按优先级分层递归：`expression` → `term` → `factor`，高优先级运算符（`*` `/`）在更深一层的 `term` 中先解析，低优先级（`+` `-`）在 `expression` 层后解析，天然形成优先级。
- Q: XML 语法树中 `term` 有哪几种形式？
- A: 整数常量 / 字符串常量 / 关键字常量（true、false、null、this）/ 变量名、数组访问 `varName[expression]`、子程序调用、括号表达式 `(expression)`、一元运算（`-`、`~`）。
- Q: JackTokenizer 需要跳过哪些内容？
- A: 空白字符、行注释 `//`、块注释 `/* ... */`、文档注释 `/** ... */`——注释不产生任何 token。
- Q: 编译 `if` 语句时如何判断是否存在 `else` 分支？
- A: 解析完 `if` 语句体（花括号块）后，`peek` 下一个 token 是否为关键字 `else`；是则继续解析 `else` 分支，否则直接返回。
