# 缓存一致性协议 MESI (Cache Coherence)

## 1. 缓存一致性的定义与 MESI 协议

**缓存一致性 (Cache Coherence)** 的核心定义是：在共享内存多处理器 (SMP) 系统中，确保所有 CPU 核心对同一内存位置的读写操作保持全局一致语义的硬件机制。

**MESI 协议（Illinois 协议）** 是一种基于**总线嗅探 (Bus Snooping)** 的监听型一致性协议，将每个 Cache Line 设置为以下四个状态之一：

1. **M (Modified, 已修改)**：该缓存行已被修改，与主存不一致，独占当前 Cache；
2. **E (Exclusive, 独占)**：该缓存行与主存一致，且仅驻留在当前 Cache；
3. **S (Shared, 共享)**：该缓存行与主存一致，可能驻留在多个 Cache 中；
4. **I (Invalid, 无效)**：该缓存行不含有效数据。

---

## 2. MESI 状态转移逻辑推导

**前提条件与推导**：
- 假设初始状态为 **I (Invalid)**；
- **Local Read**：若总线上无其他核心拥有该行，状态转为 **E**；若其他核心拥有该行，状态转为 **S**；
- **Local Write**：必须先获取独占权。若当前状态为 **S**，须向总线广播 `Invalidate` 消息将其他核心该行置为 **I**，自身状态转为 **M**；
- **Remote Write (嗅探到其他核心写入)**：若自身状态为 **S** 或 **E**，收到广播后立即将自身状态转为 **I**；
- **因此**，MESI 协议保证了“单写者/多读者 (Single-Writer / Multiple-Readers)”不变性，彻底阻止了脏读与数据覆盖。

---

## 3. 监听型 (Snooping) 与目录型 (Directory-Based) 协议对比

| 维度 | 监听型协议 (Snooping / MESI) | 目录型协议 (Directory-Based) |
|:---|:---|:---|
| **通信机制** | 广播 (Broadcast) 到所有核心 | 单播/组播 (Point-to-Point) 给记录的核心 |
| **硬件结构** | 共享总线 / 环形总线 (Ring) | 中央/分布式目录 (Directory) |
| **扩展性极限** | 仅支持小型多核 ($\le 8-16$ 核) | 可扩展至巨型多核 ($> 64-1024$ 核) |
| **广播开销** | 随着核心数增加呈现 $O(N^2)$ 爆炸 | 仅与关注该行的核心数相关 $O(k)$ |
| **典型应用** | Intel Core 桌面/笔记本 CPU | Intel Xeon Scalable, AMD EPYC 服务器 |

**局限（反例/误区）**：MESI 协议本身要求强顺序，但会导致 CPU 在等待 Invalidate ACK 时产生停顿。现代 CPU 引入了 **Store Buffer (写缓冲区)** 与 **Invalidate Queue (失效队列)**，打破了严格 MESI，从而导致了内存重排序，必须显式使用**内存屏障 (Memory Barrier)**。

关联知识点推荐：[[伪共享]]、[[无锁编程]]、[[流水线技术]]、[[Amdahl定律]]。

## 4. Python MESI 状态机转移仿真与自测断言

```python
from enum import Enum

class MESIState(Enum):
    MODIFIED = "M"
    EXCLUSIVE = "E"
    SHARED = "S"
    INVALID = "I"

class CoreCache:
    def __init__(self, core_id: int):
        self.core_id = core_id
        self.state = MESIState.INVALID

def simulate_mesi_access(caches: list, core_idx: int, action: str) -> None:
    """
    模拟 MESI 状态转移
    action: 'read' 或 'write'
    """
    target = caches[core_idx]
    other_states = [c.state for i, c in enumerate(caches) if i != core_idx]

    if action == 'read':
        if target.state == MESIState.INVALID:
            if any(s in (MESIState.SHARED, MESIState.EXCLUSIVE, MESIState.MODIFIED) for s in other_states):
                target.state = MESIState.SHARED
            else:
                target.state = MESIState.EXCLUSIVE
    elif action == 'write':
        # 写入必须使所有其他核心失效 (I)
        for i, c in enumerate(caches):
            if i != core_idx:
                c.state = MESIState.INVALID
        target.state = MESIState.MODIFIED

if __name__ == "__main__":
    caches = [CoreCache(i) for i in range(4)]

    # 自测验证 1: Core 0 读 -> Exclusive
    simulate_mesi_access(caches, 0, 'read')
    assert caches[0].state == MESIState.EXCLUSIVE

    # 自测验证 2: Core 1 读 -> 均变为 Shared
    simulate_mesi_access(caches, 1, 'read')
    assert caches[0].state == MESIState.EXCLUSIVE  # 保持
    assert caches[1].state == MESIState.SHARED

    # 自测验证 3: Core 2 写 -> Core 2 为 Modified, 其它全部为 Invalid
    simulate_mesi_access(caches, 2, 'write')
    assert caches[2].state == MESIState.MODIFIED
    assert caches[0].state == MESIState.INVALID
    assert caches[1].state == MESIState.INVALID

    print("MESI 协议四核状态机转移模拟验证成功！")
    print("缓存一致性 MESI 协议单元测试与自查验证全部成功！")
```
