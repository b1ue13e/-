# 🧭 开源作业体系-计算机组成原理

> 本页是「计算机组成原理」的开源名校教材与作业的**唯一挂载点**：教材主线、官方作业链、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**Nand2Tetris 官方 Projects 1-12**（https://www.nand2tetris.org / GitHub: https://github.com/nand2tetris/nand2tetris）。

---

## 📚 教材主线（Spine）

| 角色 | 来源 | 用途 |
|:---|:---|:---|
| 主线教材 | *The Elements of Computing Systems*（Nand2Tetris 同名书，第 2 版） | 门电路 → ALU → 内存 → CPU → 汇编器 → VM → 编译器 → OS 的完整上升链 |
| 官方作业 | Nand2Tetris 官方 `projects/01-12`（HDL + 测试脚本 + 工具链） | 每章一个可自动评测的项目，即本体系 HW01-HW12 |
| 配套工具 | Nand2Tetris 官方 Software Suite（Hardware Simulator / CPU Emulator / VM Emulator / Assembler） | 本地运行与自动验收 |
| 补充参考 | `nand2tetris-ide`、CSAPP 第 1-4 章（数据表示与汇编视角） | 现代工具链与真实 ISA 对照 |

**Honor Code 说明**：官方 projects 的 starter 与测试脚本可复用，`*.hdl / *.asm / VM Translator` 实现须自己完成；完成后再对照官方 solutions 复盘。

## 🎯 作业体系（Nand2Tetris Projects 1-12）

| HW | 主题 | 官方 Project | 所需知识点（双链） | 验收方式 |
|:---|:---|:---:|:---|:---|
| HW01 | Boolean Logic | Project 01 | [[🧠 布尔逻辑门与HDL]]、[[💻 主线：系统与硬件 (Systems, Computing & Systems Control Track)|数据表示主线]] | 全部 15 个门的 HDL 通过 Hardware Simulator 测试 |
| HW02 | Boolean Arithmetic | Project 02 | [[🧠 ALU算术逻辑单元]]、补码与溢出 | HalfAdder/FullAdder/ALU 通过测试；能解释溢出行为 |
| HW03 | Sequential Logic / Memory | Project 03 | [[🧠 时序逻辑与寄存器]]、时钟与触发器 | DFF/寄存器/PC/内存 通过测试 |
| HW04 | Machine Language | Project 04 | [[🧠 CPU与取指执行循环]]、Hack 汇编 | Fill/Mult 在 CPU Emulator 跑通 |
| HW05 | Computer Architecture | Project 05 | [[🧠 CPU与取指执行循环]]、[[🧠 时序逻辑与寄存器]] | 整机 CPU 通过 `Computer` 测试 |
| HW06 | Assembler | Project 06 | 汇编器设计、符号表 | 自写汇编器能汇编官方程序并通过 CPU Emulator 验证 |
| HW07 | VM I（栈运算） | Project 07 | VM 栈模型、算术/比较/跳转翻译 | VM Translator 通过官方 VM 测试 |
| HW08 | VM II（函数调用） | Project 08 | 调用约定、帧与返回地址 | 含函数调用的程序通过测试 |
| HW09 | High-Level Language | Project 09 | Jack 语言与编译目标 | 完成一个 Jack 程序（如 Pong 或自选） |
| HW10 | Compiler I（词法/语法） | Project 10 | 词法分析与语法树 | 分析器输出 XML 通过官方比较 |
| HW11 | Compiler II（代码生成） | Project 11 | 符号表与代码生成 | Jack 编译器能编译 Pong 并通过 VM Emulator |
| HW12 | Operating System | Project 12 | 内存管理、Math/String/Output 库 | OS 库函数通过测试套件 |

> 分层验收原则：HW01-05 是硬件链（必须顺序完成）；HW06-08 是工具链（汇编器→VM→编译器三段式）；HW09-12 是应用链（可选进阶，完成 Pong 全链路为满分 Capstone）。

## ✅ 验收方式与评分

1. **自动验收**：每个 Project 用官方测试脚本（`.tst`）跑通为准，截图或输出存档到 `03-Projects/11-计算机组成原理/`。
2. **口试验收**（每个 HW 完成后）：闭卷回答 3 个问题——"这一层向上提供什么接口？向下使用什么接口？测试脚本在验证什么？"
3. **Capstone（结课）**：从 NAND 到 Pong 全链路跑通 + 一篇 1-2 页技术报告（每层设计决策 + 一个调试故事）。
4. **满分 Rubric**：全部 12 个 Project 官方测试通过（60 分）+ 口试 3 问全对（20 分）+ Capstone 报告（20 分）。
