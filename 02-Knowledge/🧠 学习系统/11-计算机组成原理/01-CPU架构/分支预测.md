# 分支预测技术 (Branch Prediction)

## 1. 分支预测的定义与核心动机

**分支预测技术 (Branch Prediction)** 的核心定义是：在现代超标量流水线 CPU 中，在控制分支指令（如 `jge`, `jne`, `beq`）实际计算出跳转条件与目标地址之前，通过硬件预测器推测分支是否跳转 (Taken / Not Taken) 并提前从目标地址取指执行的微架构技术。

**基本性质与动机**：对于深流水线（如 Intel Core 架构 14~19 级流水线），分支指令在 EX 阶段才能确定实际跳转结果。若每次等待分支确定，流水线将面临 15~20 个时钟周期的**气泡冲刷 (Pipeline Flush)** 惩罚。因此分支预测将控制冒险的开销大幅降低至理想情况下的 0 惩罚。

---

## 2. 2-Bit 饱和计数器与二阶自适应预测推导

**2-Bit 饱和计数器 (2-Bit Saturated Counter)** 状态机包含四个状态：
- `00`：强不跳转 (Strongly Not Taken)
- `01`：弱不跳转 (Weakly Not Taken)
- `10`：弱跳转 (Weakly Taken)
- `11`：强跳转 (Strongly Taken)

**状态转移与逻辑推导**：
1. **前提条件（假设）**：每次分支实际发生 Taken 时，计数器 $+1$（最大到 `11` 截断）；未发生 Not Taken 时，计数器 $-1$（最小到 `00` 截断）；
2. **滞后性 (Hysteresis) 优势**：相比 1-Bit 预测器（单次反例即改变预测方向），2-Bit 计数器要求连续出现两次预测错误才会改变主预测方向；
3. **因此**，在双重循环嵌套的内层循环退出时（出现一次 Not Taken 反例），2-Bit 计数器仅从 `11` 降为 `10`（仍预测 Taken），在下一次进入内层循环时依然能准确预测 Taken，预测准确率从 1-Bit 的 ~50% 提升至 >90%。

---

## 3. 分支预测三类硬件机制的区别与对比

| 预测器类型 | 预测原理 | 硬件结构 | 准确率 | 适用场景 |
|:---|:---|:---|:---|:---|
| **静态分支预测** | 总是预测 Taken (如BTFN) | 无额外状态 | ~60% | 嵌入式简单 CPU |
| **动态 2-Bit 局部预测** | 基于单条指令历史 (BHT) | 2-Bit 饱和计数器表 | ~85-90% | 早期 x86 处理器 |
| **双层全局自适应 (Two-Level)** | 结合全局分支历史 (GHR) | GHR + PHT (Two-Level) | ~95% | Pentium Pro, MIPS |
| **TAGE 预测器** | 关联多重历史长度 (Tagged) | 多个不同历史长度标记表 | **>98%** | 现代 AMD Zen / Intel Core |

**局限（反例/误区）**：对于完全随机的条件判断（如对无序数组求 `if (arr[i] > 128)`），任何分支预测器的准确率都会衰减至 50% 抛硬币水平，从而引发严重性能崩溃。

## 4. Python 2-Bit 饱和计数器预测器仿真与无序数组反例自测

```python
import numpy as np
from typing import List

class TwoBitBranchPredictor:
    """
    2-Bit 饱和计数器分支预测器仿真
    状态: 0=SNT, 1=WNT, 2=WT, 3=ST
    预测规则: state >= 2 预测 Taken (True)
    """
    def __init__(self, size: int = 256):
        self.bht = [2] * size  # 初始状态 10 (Weakly Taken)
        self.mask = size - 1

    def predict(self, pc: int) -> bool:
        idx = pc & self.mask
        return self.bht[idx] >= 2

    def update(self, pc: int, actual_taken: bool) -> None:
        idx = pc & self.mask
        state = self.bht[idx]
        if actual_taken:
            self.bht[idx] = min(3, state + 1)
        else:
            self.bht[idx] = max(0, state - 1)

def evaluate_outcomes(outcomes: List[bool], pc: int = 0x4000) -> float:
    """评估预测准确率"""
    predictor = TwoBitBranchPredictor()
    correct = 0
    for actual in outcomes:
        pred = predictor.predict(pc)
        if pred == actual:
            correct += 1
        predictor.update(pc, actual)
    return correct / len(outcomes)

if __name__ == "__main__":
    # 自测验证 1: 循环分支 pattern (9 次 Taken, 1 次 Not Taken, 重复 10 次)
    loop_pattern = ([True] * 9 + [False]) * 10
    acc_loop = evaluate_outcomes(loop_pattern)
    # 2-Bit 应获得 > 85% 准确率
    assert acc_loop >= 0.85, f"循环预测准确率低于预期: {acc_loop:.2%}"

    # 自测验证 2: 反例测试 - 随机数据分支 (无序数组)
    np.random.seed(42)
    random_pattern = list(np.random.rand(1000) > 0.5)
    acc_random = evaluate_outcomes(random_pattern)
    # 随机数据准确率在 50% 附近 (45% ~ 55%)
    assert 0.40 <= acc_random <= 0.60, f"随机分支预测异常: {acc_random:.2%}"

    print(f"分支预测仿真完成！")
    print(f"  规律循环分支准确率: {acc_loop:.2%} (符合 > 85% 预期)")
    print(f"  无序随机分支准确率: {acc_random:.2%} (降至 ~50% 崩溃边缘)")
    print("分支预测技术单元测试与自查验证全部成功！")
```
