# 中断机制 (Hardware Interrupts & ISR)

## 1. 中断概念与四类异常分类

在 x86-64 处理器体系结构中，**中断机制 (Hardware Interrupts & ISR)** 是一种由硬件或软件信号触发的控制流突变。它导致 CPU 暂停当前程序的执行，转而执行专门的 **中断服务程序 (ISR, Interrupt Service Routine)**。中断机制是操作系统内核实现 I/O 调度、进程切换与系统调用的根本硬件基础。

CSAPP（Bryant & O'Hallaron, 2015）将处理器的所有控制流突变（异常）分为四类：

| 异常类型 | 中文术语 | 触发方式 | 返回行为 | 典型实例 |
|:---|:---|:---|:---|:---|
| **Interrupt** | 异步中断 | 外部 I/O 硬件信号 | 返回下一条指令 | 时钟中断 (IRQ 0)、网卡 DMA 中断 |
| **Trap** | 陷阱 | 故意同步触发 | 返回下一条指令 | `syscall` / `int 0x80` 系统调用 |
| **Fault** | 故障 | 潜在可恢复同步错误 | 重试当前指令 | 缺页异常 (#PF Page Fault) |
| **Abort** | 终止 | 不可恢复严重硬件故障 | 不返回 (终止进程) | 双重故障 (#DF Double Fault) |

## 2. IDT 中断描述符表与硬件中断处理推导

在 x86-64 体系结构中，CPU 通过查询 **IDT (Interrupt Descriptor Table，中断描述符表)** 定位 ISR：

1. **收到向量号 (Vector)**：范围 0~255（前 32 个为体系结构保留异常）；
2. **IDTR 定位基地址**：`IDTR` 寄存器存放 IDT 在虚拟内存中的物理/虚拟基地址与限长；
3. **硬件压栈保存上下文**：CPU 硬件自动按顺序压入 `SS`, `RSP`, `RFLAGS`, `CS`, `RIP` 及错误码 (Error Code) 到内核栈；
4. **执行与恢复**：执行 ISR 完毕后，调用 `iretq` 指令原子性恢复 `RIP`, `CS`, `RFLAGS`。

---

## 3. 中断机制与轮询 (Polling) 的区别与对比

| 维度 | 中断驱动 (Interrupt-Driven) | 轮询 (Polling) |
|:---|:---|:---|
| **CPU 占用** | 仅在事件到达时响应，高效率 | 持续循环查询，死等占用 100% CPU |
| **响应延迟** | 存在 ISR 切换与上下文保存开销 | 极低（在空闲轮询循环中直接处理）|
| **适用场景** | 低频/突发 I/O（如键盘、网卡包）| 高频/超高吞吐 I/O（如千兆网卡 DPDK）|

**局限（反例/误区）**：在极高频 I/O 场景下（如每秒接收 1000 万个数据包），中断驱动会导致 **中断风暴 (Interrupt Storm)**，使 CPU 100% 消耗在 ISR 压栈开销上，此时必须切换为轮询机制 (NAPI / DPDK)。

关联知识点推荐：DMA机制、[[虚拟内存]]、[[分页机制]]、[[流水线技术]]。

## 4. C 语言/Python 中断上下文帧结构与 ISR 仿真自测

```python
from dataclasses import dataclass

@dataclass
class InterruptFrame:
    rip: int
    cs: int
    rflags: int
    rsp: int
    ss: int

def simulate_isr_execution(frame: InterruptFrame, vector: int) -> bool:
    """
    仿真 x86-64 中断处理与 iretq 恢复
    假设: IDT 表包含 256 个向量
    """
    assert 0 <= vector <= 255, "中断向量号越界"
    initial_rip = frame.rip
    # 模拟 ISR 执行
    if vector == 1:
        # IRQ 1: 键盘中断
        pass
    elif vector == 14:
        # #PF: 缺页异常
        pass
    # 模拟 iretq 恢复: 检查 RIP 恢复一致
    return frame.rip == initial_rip

if __name__ == "__main__":
    frame = InterruptFrame(rip=0x40008C, cs=0x33, rflags=0x246, rsp=0x7FFE8A00, ss=0x2B)

    # 自测验证 1: ISR 处理与 iretq 恢复
    assert simulate_isr_execution(frame, vector=1)
    assert simulate_isr_execution(frame, vector=14)

    # 自测验证 2: 向量号越界拦截反例
    try:
        simulate_isr_execution(frame, vector=300)
        assert False, "应拦截非法向量号"
    except AssertionError as err:
        print(f"反例非法向量拦截成功: {err}")

    print("中断机制与 ISR 硬件上下文恢复仿真验证成功！")
    print("中断机制单元测试与自查验证全部成功！")
```
