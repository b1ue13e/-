# 缓存伪共享 (False Sharing)

## 1. 伪共享的概念与 MESI 协议背景

**缓存伪共享 (False Sharing)** 的核心定义是：多核 CPU 中不同核心上的多线程并发修改逻辑上独立、但在物理内存中位于**同一个缓存行 (Cache Line，通常为 64 字节)** 上的不同变量时，导致缓存一致性协议（如 MESI 协议）频繁触发无效化与总线刷新的性能瓶颈现象。

**基本性质**：虽然程序逻辑上没有任何线程数据竞争（各线程访问独立的变量），但在微架构层面，CPU 以 Cache Line 为单位管理缓存一致性，因此产生了“虚假”的数据共享与无效化开销。

---

## 2. MESI 协议下的伪共享形式化产生过程

**假设（前提条件）**：
- 核心 Core 1 频繁写入变量 $X$，核心 Core 2 频繁写入变量 $Y$；
- $X$ 与 $Y$ 在内存中相邻，共同占用同一个 64 字节 Cache Line。

**推导过程（MESI 状态震荡）**：
1. Core 1 写入 $X$：发送 `Invalidate` 总线广播，将该 Cache Line 标记为 **Modified (M)**，使得 Core 2 中的 Cache Line 变为 **Invalid (I)**；
2. Core 2 写入 $Y$：发现缓存行已失效 (I)，触发 Cache Miss，强行要求 Core 1 将 Cache Line 写回内存/L3 缓存，并将自身 Cache Line 标记为 **Modified (M)**，同时使 Core 1 中的 Cache Line 变为 **Invalid (I)**；
3. **因此**，两个核心陷入交替写回与无效化的“缓存乒乓 (Cache Ping-Pong)”恶性循环，使内存访问延迟从 L1 缓存的 ~1ns 飙升至总线仲裁的 ~100ns。

---

## 3. 解决伪共享的方案对比与字节对齐

| 解决方案 | 实现机制 | 优势 | 额外开销 | 适用语言 |
|:---|:---|:---|:---|:---|
| **显式字节填充 (Padding)** | 插入无用变量填满 64 字节 | 通用，无特化要求 | 浪费空间 (内存膨胀) | C/C++/Java |
| **编译器对齐指令** | `alignas(64)` 或 `__attribute__((aligned(64)))` | 简洁，结构清晰 | 依赖编译器扩展 | C++11 / C |
| **Java 注解填充** | `@Contended` (JVM 选项 `-XX:-RestrictContended`) | 虚拟机自动管理 | 仅限特定 JVM | Java 8+ |

**局限（反例/误区）**：过度的缓存行对齐填充会导致数据结构体积大幅膨胀，从而降低 L1/L2 Cache 的空间局部性与装载密度。

关联知识点推荐：[[缓存一致性]]、[[无锁编程]]、[[Amdahl定律]]、[[Roofline模型]]。

## 4. C++11 / Python 伪共享效果仿真与结构体对齐自测

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <chrono>
#include <cassert>

// 存在伪共享风险的结构体
struct UnpaddedData {
    uint64_t a; // 8 字节
    uint64_t b; // 8 字节 (位于同一 64 字节 Cache Line)
};

// 消除伪共享的字节对齐结构体 (alignas 64 字节)
struct alignas(64) PaddedData {
    uint64_t a;
};

void run_test() {
    UnpaddedData unpadded{0, 0};
    constexpr int iterations = 10000000;

    // 线程 1 增加 a，线程 2 增加 b
    std::thread t1([&]() {
        for (int i = 0; i < iterations; ++i) unpadded.a++;
    });
    std::thread t2([&]() {
        for (int i = 0; i < iterations; ++i) unpadded.b++;
    });

    t1.join();
    t2.join();

    assert(unpadded.a == iterations);
    assert(unpadded.b == iterations);
    std::cout << "伪共享并发累加测试通过: a=" << unpadded.a << ", b=" << unpadded.b << std::endl;
}

int main() {
    run_test();
    return 0;
}
```

```python
import numpy as np

def simulate_false_sharing(cache_line_size: int = 64) -> dict:
    """
    伪共享偏移量计算模拟
    假设: 变量占用 8 字节, Cache Line 为 64 字节
    """
    var_size = 8
    vars_per_line = cache_line_size // var_size
    return {
        'vars_per_line': vars_per_line,
        'padding_bytes_needed': cache_line_size - var_size
    }

if __name__ == "__main__":
    res = simulate_false_sharing(64)
    assert res['vars_per_line'] == 8
    assert res['padding_bytes_needed'] == 56
    print(f"64字节 Cache Line 伪共享仿真: 每行容纳 {res['vars_per_line']} 个 uint64 变量")
    print(f"独立对齐所需填充字节: {res['padding_bytes_needed']} 字节")
    print("伪共享单元测试与自查验证全部成功！")
```
