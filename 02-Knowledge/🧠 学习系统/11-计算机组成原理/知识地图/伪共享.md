## 📌 核心要点速览

- **定义**：多核上逻辑独立但落在同一 64 字节缓存行的变量被不同核心并发修改，引发 MESI 无效化震荡（缓存乒乓）。
- **本质**：程序层面无数据竞争，微架构层面却以缓存行为粒度做一致性管理——"虚假共享"。
- **代价**：L1 命中 ~1ns 退化为总线仲裁 ~100ns，吞吐量级下降。
- **解法对比**：显式 Padding / `alignas(64)` / Java `@Contended`；过度填充会膨胀结构、损失空间局部性。
