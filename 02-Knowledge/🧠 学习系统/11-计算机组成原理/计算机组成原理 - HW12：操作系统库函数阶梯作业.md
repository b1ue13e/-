Python 冒烟检查（OS 源码必须可被编译器编译且产物非空）：

```python
import subprocess
import pathlib

def compile_os(os_dir: str) -> bool:
    """六个库 + 测试程序全部编译成功、产物非空"""
    r = subprocess.run(["JackCompiler", os_dir], capture_output=True, text=True)
    vms = list(pathlib.Path(os_dir).rglob("*.vm"))
    return r.returncode == 0 and len(vms) >= 6
```

## 🃏 Anki 卡片

- Q: `Memory.alloc` 如何实现？
- A: 维护空闲链表（每个空闲块头部存下一块地址），采用首次适配（或最佳适配）在堆中分配；`Memory.dealloc` 把释放块插回链表头；`heap` 指针标记堆起点。
- Q: `Math.divide` 如何既加速又防溢出？
- A: 用移位近似：反复把除数左移逼近被除数（商的每一位由移位累加得到），代替逐次减法；最后统一处理符号与余数（`x = q*y + r`），必要时修正商。
- Q: `Output` 如何把字符画到屏幕？
- A: 内置 8×11 字符点阵表，把每个字符的位图按光标行列换算成屏幕映射区（`16384` 起）的地址，逐字写入；行满则换行，到底则整屏上卷。
- Q: `Sys.wait(duration)` 如何实现毫秒级延时？
- A: 用空循环计数消耗 CPU 周期：外层循环按 duration 计数，内层固定次数的空转近似 1ms，从而粗略实现延时（不依赖硬件定时器）。
- Q: Jack OS 的 `Sys.init` 在启动时做什么？
- A: 初始化内存堆（`Memory.init`）与屏幕（`Output.init`），然后调用用户程序的 `Main.main`；程序结束后调用 `Sys.halt` 进入死循环停机。
