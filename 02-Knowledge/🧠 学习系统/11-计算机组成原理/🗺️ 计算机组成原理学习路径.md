## 🎯 课程边界（2026-08-08 重构确认）

- **本课程范围**：计算机组成原理 —— 数字逻辑与数据表示 → 指令集与 CPU 微架构 → 存储层次与缓存/虚拟内存 → 性能分析与优化。
- **已移出内容**：进程/线程、调度算法、进程通信、并发同步、死锁、内存模型等**操作系统主题**（原阶段3-4）已于 2026-08-08 移出本课程，素材归档于 `.recovery-hold/2026-08-08/已移出-OS阶段与重复导航/`，未来独立"操作系统"课程时恢复。本课程聚焦硬件与系统结构本身。
- **作业体系**：Nand2Tetris（逻辑门→CPU→汇编器→VM）与 CSAPP（Data/Bomb/Cache Lab）为两大来源；见 [[🧭 课程作业总索引]]。

```dataviewjs
dv.table(
    ["笔记", "阶段", "更新日期", "状态"],
    dv.pages('"02-Knowledge/🧠 学习系统/11-计算机组成原理"')
        .where(p => !p.file.path.includes("🗺️") && !p.file.path.includes("教材挂载") && !p.file.path.includes("作业"))
        .sort(p => p.file.mtime, 'desc')
        .limit(5)
        .map(p => {
            let category = "-";

            return [p.file.link, category, p.file.mtime.toFormat("MM-dd"), p.status || "ongoing"];
```
