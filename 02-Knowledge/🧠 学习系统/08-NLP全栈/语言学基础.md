# 语言学基础
---
## 0. 先判断它值不值得深挖
- **类别**：**B 类（常用工具）**
- **判断理由**：语言学是 NLP 的"母学科"：NLP 任务的划分（分词/词性/句法/语义）就是语言层级的映射。不学语言学，[[句法分析]]、[[序列标注]] 的术语（依存、词性、格）会一直隔层纱；但只需掌握"层级观 + 关键概念"，无需研究理论细节。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 学 NLP 时遇到一堆"语言学术语"：音素、语素、词性、依存、语义角色、语用——它们之间什么关系？为什么 NLP 任务要按"词性标注→句法分析→语义理解"分层？
> 语言学基础的回答：**语言是分层的符号系统**——音系（声音单元）→ 形态（词的结构）→ 句法（词如何组句）→ 语义（句子什么意思）→ 语用（话在语境中什么意思）。每一层有独立规律与单位；NLP 的任务体系几乎一一对应这些层级：分词/词性=形态句法层，依存/成分=句法层，NER/关系=语义层，对话/指代=语用层。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：语言层级是 NLP 课程地图的"坐标系"：[[序列标注]]（词性/分词）、[[句法分析]]（依存树）、[[信息抽取]]（语义角色）、[[对话系统]]（语用与指代）；理解层级才能理解"为什么任务这样划分、特征为什么有效"。
- **实际应用场景**：词性标注与依存解析的术语基础、中文分词的语言学依据（语素/词）、语义角色标注（谓词论元）、指代消解（语用）。
- **高频题型/任务**：面试"词性和依存是什么""形态学对 NLP 有什么用（词形还原/词干提取）""语言层级与 NLP 任务的对应"。

## 4. 用直觉语言解释它
> «"语言像'俄罗斯套娃'：最外层是'话怎么说才得体'（语用：'你能把盐递给我吗'字面是问能力，实际是请求）；往里是'句子什么意思'（语义：'他打碎了花瓶'——谁对谁做了什么）；再往里是'词怎么排成句'（句法：主谓宾、修饰关系）；再往里是'词怎么长出来'（形态：'un-happy-ness' 拆成前缀-词根-后缀）；最核心是'声音怎么区分意义'（音系：b/p 一音之差，'爸/怕'不同）。NLP 的每个任务，都在某一层'套娃'上做工程：分词在形态层，词性/依存从句法层，NER/关系在语义层，对话在语用层。"»
- **直觉类比/几何图像**：层级 = 洋葱/套娃：从物理（音）到心理（义）到社会（用）。
- **为什么很自然**：语言是"有限符号 → 无限句子 → 无限意义"的生成系统，层级是压缩信息的最优组织方式。
- **一句话直觉本质**：**"语言五层级（音系→形态→句法→语义→语用）是 NLP 任务地图的坐标系：每个 NLP 任务都落在某一层级，术语（词性/依存/论元/指代）就是各层级的工程化单位。"**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**五层级**：音系（phonology，最小意义区分单位：音素）、形态（morphology，最小意义单位：语素 morpheme）、句法（syntax，词组合规则：短语结构/依存）、语义（semantics，意义：论元结构/语义角色）、语用（pragmatics，语境意义：指代/言语行为）。
**词性（POS）**：词的语法类别（名/动/形/介…），形态与句法的接口。
**依存关系**：词与词的中心-修饰关系（nsubj 主谓、obj 动宾）。
### 2. 核心公式
**语言生成系统**（Chomsky 视角）：
$$\text{有限词汇} \xrightarrow{\text{句法规则}} \text{无限句子} \xrightarrow{\text{语义解释}} \text{意义} \xrightarrow{\text{语境}} \text{意图}$$
**词性序列 → 句法树 → 语义角色的层级流水线**：
$$\text{tokens} \xrightarrow{\text{POS}} \text{tags} \xrightarrow{\text{parsing}} \text{tree} \xrightarrow{\text{SRL}} \text{roles}$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| 音素 | 最小音位单位 | 每语言 20-60 个 | /p/ vs /b/ |
| 语素 | 最小意义单位 | 词根/词缀 | un-happy-ness |
| POS | 词性标签 | 如 n/v/adj | 序列标注输出 |
| nsubj/obj | 依存关系 | 关系集合 | 句法分析输出 |
| 论元 | 谓词参与者 | 施事/受事/工具 | 语义角色 |
### 4. 常见变体与适用条件
- **语言学流派**：结构主义（分布分析）、生成语法（Chomsky 规则系统）、功能语法（交际功能）、认知语言学（概念化）。
- **NLP 应用**：形态层（词形还原 lemmatization、词干 stem、分词）、句法层（依存/成分）、语义层（NER/SRL/WSD）、语用层（指代消解、对话行为）。
- **适用条件**：低资源语言需语言学先验（形态丰富的语言分词与词形处理尤其重要）。
- **限制条件**：语言学的"规则完备性"理想在真实语料（口语、错误、代码混合）前失效——NLP 以数据驱动为主，语言学提供特征与任务边界。

## 6. 推导思路和思想来源
- **最初困难**：语言现象无穷无尽，规则系统（1950-1980 专家系统）永远写不完。
- **直接方法局限**：纯规则 NLP 覆盖窄；纯统计又丢失结构知识（语言学家积累的层级规律）。
- **关键"转念"**：① Saussure/结构主义：语言是"符号系统"，意义来自系统内差异（分布假说的源头）；② Chomsky：语言是"生成系统"，句法是核心（引出句法分析任务）；③ 计算语言学：把层级规律工程化——树库（Penn Treebank）、依存标注（UD）、语义角色标注（PropBank），让统计/神经模型在结构化标注上学习。
- **推导主线与动机**：语言层级 → 标注规范（树库/语料库）→ 统计模型 → 神经模型：语言学提供"任务与标注的坐标系"，数据驱动填充参数。
- **为什么自然得到此结论**：NLP 任务不是凭空发明的，而是语言层级各层的"可计算化"——这就是为什么课程按"词法→句法→语义→语用"组织。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：对句子"小猫在桌上睡觉"标注词性并指出层级。
- **解题思路与关键步骤**：小/形（或前缀）、猫/名、在/介、桌/名、上/方位词、睡觉/动。层级：形态（"小猫"合成词）→ 句法（主谓结构：小猫|在桌上|睡觉）→ 语义（施事=小猫，动作=睡觉，处所=桌上）。
- **最终答案**：词性序列 [形, 名, 介, 名, 方位, 动]；句子是"主-状-谓"结构。
- **易错点**：把"在桌上"整体当状语（句法层）却混入语义层"处所"（角色）——层级混淆是新手常见错误。
- **🤔 追问**：若换成英语 "The cat slept on the table"？—— 词性对应 the/DET, cat/N, slept/V, on/P, table/N；层级结构一致，说明层级是跨语言的。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：为什么"形态学"对中文 NLP 不如对英文重要，但对土耳其语极其重要？—— 中文缺乏形态变化（词形不因语法功能改变，靠语序与虚词）；英语有屈折（run/runs/ran）；土耳其语是黏着语（一个词根可挂 10+ 后缀表达格/数/时态）——不处理形态，词表爆炸且稀疏。所以分词与词形还原的优先级随语言形态丰富度上升。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：词形还原与词性标注是语言学知识的最直接落地：
```python
import spacy

nlp = spacy.load("en_core_web_sm")
doc = nlp("The cats were running quickly.")
for tok in doc:
    print(tok.text, tok.lemma_, tok.pos_, tok.dep_, tok.head.text)
# cats cat NOUN nsubj running / running run VERB ROOT running / quickly quickly ADV advmod running
```

## 8. 常见误区和易混概念
### 误区 1：以为"语言学 = 语法规则 = 过时"
- **错误直觉**：深度学习不需要语言学。
- **为什么错**：语言学提供了：任务定义（树库/标注规范）、特征（词性/依存曾是 SOTA 特征）、评估（语言学家设计的基准）；现代模型在语言学标注（UD 树库）上评测。只是"显式规则"被"隐式学习"取代。
- **正确理解**：语言学是"坐标系"，深度模型是"绘图员"——坐标系仍然决定画什么。
### 误区 2：以为"语义 = 词典释义，语用 = 修辞"
- **错误直觉**：层级划分模糊。
- **为什么错**：语义是"脱离语境的字面意义结构"（论元、指称）；语用是"语境中的意义"（"你能把盐递给我吗"是请求不是提问）。同一句话在不同语境有不同语用功能。
- **正确理解**：语义 vs 语用 = "句义" vs "言外之意"。
### 概念对比表
| 层级 | 单位 | NLP 任务 | 典型输出 |
| :--- | :--- | :--- | :--- |
| 音系（本概念） | 音素 | 语音识别、注音 | 音素序列 |
| 形态 | 语素/词 | 分词、词形还原 | 词序列 |
| 句法 | 短语/依存 | 词性、句法分析 | 依存树 |
| 语义 | 论元/关系 | NER、SRL、WSD | 角色标注 |
| 语用 | 言语行为 | 对话、指代消解 | 意图/指代链 |

## 11. 自测题：5 道
| 题号 | 类型 | 难度 | 考查点 |
| :--- | :--- | :--- | :--- |
| 1 | 概念辨析 | 基础 | 五层级的单位与任务映射 |
| 2 | 公式运用 | 基础 | 词性标注与层级判断 |
| 3 | 条件判断 | 中等 | 形态学与语言类型 |
| 4 | 变式/综合 | 中等 | 语义 vs 语用 |
| 5 | 开放/证明/建模 | 较难 | 设计低资源语言的形态处理方案 |
### 题目与解析
#### 1. 语言五层级及各自的最小单位是什么？对应哪些 NLP 任务？
> [!question]- 答案解析
> - **答案**：音系（音素）→ 语音识别；形态（语素/词）→ 分词、词形还原；句法（短语/依存）→ 词性、句法分析；语义（论元/关系）→ NER、语义角色标注；语用（言语行为）→ 对话、指代消解。
> - **解析**：任务分层 = 语言分层；上层依赖下层输出（流水线）。`#自测题/基础`
#### 2. 句子"小明昨天去了北京"，给出词性与结构层级。
> [!question]- 答案解析
> - **答案**：小/名 明/名（或专名）昨/时间词 天/时间词 去/动 了/助词 北/名 京/名。句法：主（小明）|状（昨天）|谓（去了）|宾（北京）；语义：施事=小明、动作=去、时间=昨天、终点=北京。
> - **解析**：同一句可从词性（形态句法）、依存（句法）、角色（语义）三层分别描述。`#自测题/基础`
#### 3. 什么语言需要重点做"词形还原"，为什么中文相对不需要？
> [!question]- 答案解析
> - **答案**：形态丰富的语言（英语的 run/runs/ran、土耳其语黏着后缀）需要：词形变化导致词表膨胀、统计稀疏。中文缺乏屈折变化（语法靠语序/虚词），词形≈原形，重点在分词而非还原。
> - **解析**：语言类型学（孤立语/屈折语/黏着语）直接决定 NLP 预处理管线。`#自测题/中等`
#### 4. 区分语义与语用：给出一个"字面义与言外之意不同"的例子并分析。
> [!question]- 答案解析
> - **答案**：例句"这里好冷啊"（冬天教室）。语义：陈述温度低；语用：可能是请求关窗/开暖气（间接言语行为）。判断依据是语境与意图，超出字面组合义。
> - **解析**：语用层处理"说话人意图"，对话系统（[[对话系统]]）的核心难题。`#自测题/中等`
#### 5. 为一种无分词标注的低资源语言设计基础 NLP 管线（利用语言学先验）。
> [!question]- 答案解析
> - **答案**：① 语言类型学调查（黏着/屈折？）决定预处理重点；② 无监督分词（基于字符互信息/频率的 BPE 类方法）建立词表；③ 借助跨语言对齐（翻译词典/多语言词向量）迁移词性与形态标注；④ 用少量标注数据训练 CRF/神经 tagger；⑤ 形态丰富的语言加规则词形还原（后缀表）缩小词表。
> - **解析**：语言学先验（词缀表、词序类型）在低资源场景是宝贵监督信号——这正是"语言学 + 数据驱动"结合的典型。`#自测题/较难`
