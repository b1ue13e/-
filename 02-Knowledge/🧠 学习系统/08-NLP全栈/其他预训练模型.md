# 其他预训练模型
---
## 0. 先判断它值不值得深挖
- **类别**：**B 类（常用工具）**
- **判断理由**：BERT 之后一年内涌现 XLNet/ELECTRA/T5/BART 四大代表，分别从"预训练目标"和"架构"两个维度改进 BERT。面试高频"ELECTRA 的 replaced token detection 是什么""T5 和 BART 的区别""XLNet 为什么用排列语言模型"；掌握它们等于掌握预训练设计的完整光谱。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> BERT 的 MLM 有两个短板：① 预训练和微调不一致（[MASK] 只在预训练出现）；② 只做"理解"（Encoder），无法生成；③ 每个 token 的预测只用 15% 的掩码，学习效率低。
> 其他预训练模型的回答：**各攻一个短板**——XLNet 用排列语言模型（PLM）解决 [MASK] 不一致；ELECTRA 用"替换词检测"（判别任务，样本效率翻倍）；T5 把一切任务统一成"文本到文本"（text-to-text）；BART 用去噪自编码（破坏+重建）兼顾理解与生成，是 [[Seq2Seq与注意力机制]] 的预训练版。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：这四个模型构成"BERT 之后"的改进谱系：理解派（XLNet/ELECTRA）与生成派（T5/BART）；它们与 [[GPT系列]] 一起铺满 Encoder/Decoder 的所有组合，是 [[HuggingFace生态系统]] 里 `AutoModel` 家族的骨干。
- **实际应用场景**：ELECTRA 用于小数据高效率微调（工业常见）；T5/BART 用于摘要、翻译、生成式问答（[[文本生成]] 任务）。
- **高频题型/任务**：面试"PLM 怎么实现双向且无 [MASK]""ELECTRA 的生成器-判别器""T5 的 text-to-text 统一范式""BART 的噪声类型"。
---
## 3. 学它之前需要哪些前置知识？
1. **[[BERT及其变体]]**：MLM/NSP 与 Encoder-only 架构是对照基准。
2. **[[Transformer架构]]**：Encoder/Decoder 两种栈的差异。
3. **[[Seq2Seq与注意力机制]]**：理解 T5/BART 的 Encoder-Decoder 结构。
---
## 4. 用直觉语言解释它
> «"BERT 之后各家都在'改良完形填空训练法'：XLNet 说'不涂掉词了，把句子顺序打乱着猜'（排列语言模型，练完还能双向看上下文）；ELECTRA 说'与其填空，不如当侦探——把句子里的词偷偷换成假的，你找出来哪个是假的'（每个词都参与训练，效率翻倍）；T5 说'别分任务了，什么任务都写成'输入→输出'的翻译题'（text-to-text）；BART 说'我把句子打乱、删词、翻转，你负责还原'（去噪自编码，既能理解又能生成）。"»
- **直觉类比/几何图像**：四种训练目标 = 四种"语文练习题"：乱序重排（XLNet）、找茬（ELECTRA）、翻译题（T5）、还原被破坏的句子（BART）。
- **为什么很自然**：预训练目标设计的核心矛盾 = "自监督信号越强越好" vs "与下游任务越一致越好"；每个模型都是这个天平上的一个砝码位置。
- **一句话直觉本质**：**"改进预训练 = 改目标（XLNet 排列、ELECTRA 判别、T5 统一、BART 去噪）或改架构（Encoder/Decoder 取向）；四者分别优化了双向性、样本效率、任务统一性与生成能力。"**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**XLNet**：排列语言模型——对序列随机排列 $\mathcal{Z}_T$，在每种排列下做自回归，期望形式获得双向上下文且无 [MASK]。
**ELECTRA**：replaced token detection——生成器（小 MLM）把部分 token 换成假词，判别器判断每个 token 真假，全体 token 参与损失。
**T5**：text-to-text——所有任务（分类/翻译/摘要/问答）统一为"前缀 + 输入 → 输出"的 seq2seq。
**BART**：去噪自编码——输入被多种噪声破坏（打乱/删词/掩码），Decoder 重建原句，Encoder-Decoder 结构。
### 2. 核心公式
**XLNet 目标**（$x$ 为排列 $\mathbf{z}$ 下的序列）：
$$\max_\theta \mathbb{E}_{\mathbf{z}\sim\mathcal{Z}_T}\left[\sum_{t=1}^{T}\log p_\theta(x_{z_t} \mid x_{z_{<t}})\right]$$
**ELECTRA 判别损失**：
$$\mathcal{L} = -\sum_{i: \text{replaced}} \log D(x_i^{\text{fake}} = \text{fake}) - \sum_{i: \text{original}} \log D(x_i = \text{real})$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathcal{Z}_T$ | 长度 $T$ 的全部排列 | $T!$ 个 | 训练时采样 |
| $x_{z_t}$ | 排列第 $t$ 位 token | 词表 | 自回归顺序 |
| $D(\cdot)$ | 判别器 | 二分类 | 真假判定 |
| $G(\cdot)$ | 生成器（小 MLM） | 分布 | 只用于造负例 |
| noise | BART 噪声类型 | 打乱/删词/掩码 | 训练时随机加 |
### 4. 常见变体与适用条件
- **XLNet**：需 Two-Stream 注意力（内容流+查询流），训练贵；适合理解类（分类/问答），生成弱。
- **ELECTRA**：判别器小（生成器 1/4 大小），样本效率高，适合中小数据微调；理解类任务。
- **T5**：encoder-decoder 全任务统一；变体 T5-small/base/large/11B；适合生成与转换任务（摘要/翻译）。
- **BART**：去噪重建，生成（摘要/对话）强且理解不弱；变体 mBART 多语言。
- **限制条件**：XLNet 排列训练开销大；ELECTRA 无生成能力；T5 的"前缀式"任务格式需要模板设计；BART 对长文噪声敏感度需调。
---
## 6. 推导思路和思想来源
- **最初困难**：MLM 的 [MASK] 导致预训练-微调不一致（pretrain-finetune discrepancy），且 85% token 不参与损失。
- **直接方法局限**：BERT 变体（RoBERTa 去 NSP、动态掩码）只做修补，没解决不一致与效率。
- **关键"转念"**：① XLNet：把"双向"从"掩码"换成"排列"——排列下自回归等价于期望意义下的双向（Yang et al. 2019）；② ELECTRA：把"生成式完形"换成"判别式找茬"——所有位置都有监督信号（Clark et al. 2020）；③ T5：把所有 NLP 任务统一为"文本到文本"，预训练=span 破坏重建（Raffel et al. 2020）；④ BART：破坏-重建的 seq2seq 去噪，Decoder 顺带获得生成能力（Lewis et al. 2020）。
- **推导主线与动机**：目标函数设计 = 样本效率 × 任务一致性 × 架构能力的三维搜索；四个模型各占一个角。
- **为什么自然得到此结论**：预训练目标越"难"，学到的表示越通用；但必须与下游一致（生成任务需要生成式预训练）——T5/BART 用"重建"统一了两者。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：句子 "A B C"（3 个 token），写出一种排列下 XLNet 的自回归目标。
- **解题思路与关键步骤**：取排列 $\mathbf{z}=(2,3,1)$，即顺序 B→C→A：目标 = $\log p(B) + \log p(C|B) + \log p(A|B,C)$。注意"看 A"时能看到 B 和 C（双向性来源）。
- **最终答案**：$\log p_\theta(x_2)+\log p_\theta(x_3|x_2)+\log p_\theta(x_1|x_2,x_3)$。
- **易错点**：漏掉排列期望（目标是所有排列的期望，不只是一种）；误以为 PLM 等价于"从左到右+从右到左"拼接。
- **🤔 追问**：为什么必须 Two-Stream 注意力？—— 否则位置 $z_t$ 的预测会看到自己的内容（泄漏），需要内容流（编码）与查询流（预测）分离。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：T5 如何用 text-to-text 处理情感分类？—— 输入前缀 "sentiment: 这部电影太棒了"，输出 "positive"。分类任务被改写为受限生成（词表限定标签）；所有任务共享同一套 encoder-decoder 与损失（交叉熵），这就是"统一范式"。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HuggingFace 一行切换模型做摘要：
```python
from transformers import pipeline

summarizer = pipeline("summarization", model="facebook/bart-large-cnn")
print(summarizer("...长文本...", max_length=60, min_length=20)[0]["summary_text"])

# T5 风格：输入前缀即任务指令
t5 = pipeline("text2text-generation", model="t5-small")
print(t5("translate English to Chinese: Hello world")[0]["generated_text"])
```

## 8. 常见误区和易混概念
### 误区 1：以为"XLNet 就是'从左到右 + 从右到左'两个方向拼起来"
- **错误直觉**：双向 = 两个单向模型。
- **为什么错**：两个单向拼接仍是"半双向"（每半只看到一个方向），且无法建模交叉依赖；PLM 是在**每个排列**下的完整自回归，期望覆盖所有方向依赖。
- **正确理解**：排列 = 随机化"看的方向"，期望意义下每个 token 能看到任意上下文组合。
### 误区 2：以为"T5 和 BART 都是 encoder-decoder，没区别"
- **错误直觉**：结构一样就一样。
- **为什么错**：预训练目标不同：T5 是 span 破坏重建（均匀 span 掩码，纯文本）；BART 是多种噪声破坏 + 全文重建（含打乱顺序）。T5 强调任务统一与缩放规律；BART 更擅长生成风格任务。
- **正确理解**：同架构、不同"练习题"，能力侧重不同。
### 概念对比表
| 模型 | 架构 | 预训练目标 | 擅长任务 |
| :--- | :--- | :--- | :--- |
| BERT（基准） | Encoder | MLM+NSP | 理解类 |
| XLNet | Encoder | 排列 LM | 理解类（问答） |
| ELECTRA | Encoder | 替换词检测 | 小数据理解 |
| T5 | Enc-Dec | span 破坏重建 | 转换/生成 |
| BART | Enc-Dec | 多噪声去噪重建 | 摘要/对话生成 |

### 题目与解析
#### 1. XLNet、ELECTRA、T5、BART 的预训练目标分别是什么？
> [!question]- 答案解析
> - **答案**：XLNet：排列语言模型（排列下自回归）；ELECTRA：替换词检测（判别真假）；T5：span 破坏重建（text-to-text）；BART：多噪声去噪重建。
> - **解析**：理解派（XLNet/ELECTRA）优化双向与效率；生成派（T5/BART）兼顾理解与生成。`#自测题/基础`
#### 2. 序列 "x1 x2 x3" 在排列 (1,3,2) 下的 XLNet 目标是什么？
> [!question]- 答案解析
> - **答案**：$\log p(x_1) + \log p(x_3|x_1) + \log p(x_2|x_1,x_3)$。
> - **解析**：按排列顺序自回归；预测 $x_2$ 时能看到 $x_1$ 和 $x_3$（双向性的体现）。`#自测题/基础`
#### 3. 摘要任务选 T5 还是 ELECTRA？为什么？
> [!question]- 答案解析
> - **答案**：选 T5（或 BART）。摘要需要生成能力，必须 Encoder-Decoder + 生成式预训练；ELECTRA 是 Encoder-only 判别模型，无生成能力。
> - **解析**：选型铁律：生成任务要生成式预训练架构（T5/BART/GPT）。`#自测题/中等`
#### 4. ELECTRA 为什么样本效率比 BERT 高？
> [!question]- 答案解析
> - **答案**：MLM 只让 15% 被掩 token 参与损失；ELECTRA 的判别器对**每个位置**判真假（全体 token 参与），监督信号密度 6.7 倍以上；且判别任务比生成任务更简单，小模型也能学得好。
> - **解析**：同样的计算预算下，ELECTRA 在 GLUE 上小模型超越 BERT/RoBERTa。`#自测题/中等`
#### 5. 如果让你设计一个面向"长文档问答"的预训练目标，会怎么设计？与 T5 相比改进什么？
> [!question]- 答案解析
> - **答案**：示例方案：① 长文档 span 破坏 + 指代一致性（掩码代词要求重建先行词）；② 段落重排（打乱段落序，重建原序，训练篇章结构）；③ 加入"问题-答案对"自监督（从文档自动构造 QA 对再训练）；架构沿用 encoder-decoder，但注意长文本注意力稀疏化。
> - **解析**：预训练目标应与下游结构对齐：问答需要"定位+生成"，指代与篇章目标直接服务定位能力；T5 的均匀 span 掩码没有显式篇章结构信号。`#自测题/较难`
