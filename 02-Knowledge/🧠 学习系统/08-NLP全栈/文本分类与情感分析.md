# 文本分类与情感分析

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：文本分类是 HW02 的全部内容（TF-IDF/线性模型/神经网络三路对照）与 HW05 的验收任务（SST-2 情感分类）；它也是 NLP 应用面最广的任务（垃圾过滤、意图识别、舆情）。从传统特征到 BERT 微调的完整路线，是"NLP 方法演进"的最佳切片。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 大量任务本质是"给文本贴标签"：这条评论是好评还是差评？这封邮件是垃圾吗？这句话是用户想订票还是退票？直接规则（关键词匹配"好/差"）覆盖不了语言的多变性——"这部电影不差"里有"差"字却是好评。
> 需要**监督学习**：收集标注数据（文本 → 标签），训练模型从文本自动预测标签。核心难题是"文本怎么变成模型能算的特征"——这就是特征工程（BoW/TF-IDF）→ 表示学习（词向量）→ 预训练（BERT）三级演进的舞台。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW02 用三种方法（TF-IDF+逻辑回归、MLP、微调）做同一任务对照，直接检验第一至四阶段的全部知识；HW05 的 SST-2 是 BERT 微调的验收场。它是"从词向量到 Transformer"每一层技术的最佳应用题。
- **实际应用场景**：电商评论情感分析、垃圾邮件过滤、新闻分类、意图识别（对话系统）、内容审核、舆情监控。
- **高频题型/任务**：HW02 的对照实验与报告；面试问"TF-IDF vs 词向量 vs BERT 的特征差异""类别不平衡怎么办""为什么情感分析里否定词是难点"。

## 4. 用直觉语言解释它

> «"文本分类像'给信件分拣'：第一步（BoW/TF-IDF）是数信封上出现的关键词——'爱'出现 3 次、'恨'出现 0 次，多半是情书；第二步（词向量）是看'用词风格'——情书和商业信函的用词风格（向量空间位置）不同；第三步（BERT）是'通读全文再判断'——不仅看用词，还看句法结构、上下文、反讽（'这部电影不差'其实在夸）。方法越高级，越能抓住'言外之意'，但代价是数据与算力需求越大。"»

- **直觉类比/几何图像**：三种方法 = 三级厨师：TF-IDF 是"数食材种类"（统计）、词向量平均是"尝味道"（分布式语义）、BERT 是"品鉴整桌菜"（上下文建模）。
- **为什么很自然**：分类的本质是"找判别性特征"——从显式词频特征到隐式语义特征再到上下文特征，是表示能力逐级增强的自然演进。
- **一句话直觉本质**：**用监督学习把"文本 → 标签"映射建模：特征从词频统计（TF-IDF）升级为静态语义（词向量）再到上下文语义（BERT 微调），每级提升以数据与算力为代价。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
**文本分类**：给定文本 $x$，预测标签 $y \in \{1,\dots,C\}$。情感分析是二分类/多分类特例（正/负/中性）。三种主流路线：① 线性模型 + TF-IDF 特征；② MLP/CNN/RNN + 词向量；③ 预训练模型微调（BERT）。

### 2. 核心公式
**TF-IDF 特征**（词 $t$ 在文档 $d$ 中）：
$$\text{TF-IDF}(t,d) = \text{TF}(t,d) \times \text{IDF}(t),\qquad \text{IDF}(t) = \log\frac{N}{1+\text{df}(t)}$$

**逻辑回归分类器**（HW02 baseline）：
$$P(y=c \mid x) = \text{softmax}(W x_{\text{tfidf}} + b)$$

**词向量平均 + MLP**：
$$h = \frac{1}{n}\sum_{i=1}^{n} v_{w_i},\qquad P(y\mid x) = \text{softmax}(W_2\, \text{ReLU}(W_1 h + b_1) + b_2)$$

**BERT 微调**（[CLS] 表示 + 分类头）：
$$P(y \mid x) = \text{softmax}(W_c\, h_{[\text{CLS}]} + b_c),\qquad \mathcal{L} = -\sum \log P(y^* \mid x)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $x$ | 输入文本 | 变长字符串 | 预处理后 token 化 |
| $y$ | 标签 | $\{1,\dots,C\}$ | SST-2 是二分类 |
| $\text{TF}(t,d)$ | 词频 | 非负整数 | 可归一化 |
| $\text{df}(t)$ | 含词 $t$ 的文档数 | $[1,N]$ | IDF 的分母 |
| $N$ | 文档总数 | 整数 | |
| $v_{w_i}$ | 词 $w_i$ 的向量 | $\mathbb{R}^{d}$ | GloVe/BERT 嵌入 |
| $h_{[\text{CLS}]}$ | BERT 的 CLS 表示 | $\mathbb{R}^{768}$ | 微调任务头输入 |

### 4. 常见变体与适用条件
- **TF-IDF + 线性模型**：数据少、可解释性要求高、需要快速上线时；缺点是无法利用词序与语义。
- **词向量 + 池化**：中小数据、语义相似度有用时；平均池化丢词序，可换 BiLSTM/TextCNN。
- **BERT 微调**：数据量 ≥ 数千、效果优先时；成本高、推理慢，可蒸馏（DistilBERT）压缩。
- **类别不平衡处理**：重采样、类权重（`class_weight`）、F1 优化目标（见 [[数据集与评测指标]]）。
- **限制条件**：领域迁移（训练语料是影评、应用是商品评论）需要领域适配；长文本需截断/分块策略。

## 6. 推导思路和思想来源

- **最初困难**：规则/关键词方法无法泛化（"不差"反例）；文本无天然数值特征。
- **直接方法局限**：BoW 稀疏且丢语义（"好"与"棒"是不同维度）；TF-IDF 缓解了高频词干扰但仍是词袋。
- **关键"转念"**：① 特征工程路线：把"词频"重加权为"区分度"（IDF），配合线性分类器——解释性最好；② 表示学习路线：用词向量把"语义相似"映射到"向量相近"，平均/池化后 MLP 分类；③ 预训练路线：BERT 让"表示"随上下文变化（"不差"被正确理解），微调只学任务头。
- **推导主线与动机**：词频 → TF-IDF（重加权）→ 逻辑回归；词向量 → 池化 → MLP；BERT → [CLS] → 任务头——三级路线的"表示能力"单调上升，"数据需求"也单调上升。
- **为什么自然得到此结论**：分类性能的上限由**表示**决定：TF-IDF 表示词面、词向量表示词义、BERT 表示上下文义；路线演进 = 表示粒度从"字面"到"语境"。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：3 篇文档：d1="love this movie"、d2="hate this movie"、d3="love this book"。计算 "movie" 与 "love" 的 IDF（$N=3$）。
- **解题思路与关键步骤**：df(movie) = 2（d1、d2），df(love) = 2（d1、d3）。IDF(movie) = $\log(3/(1+2)) = \log 1 = 0$；IDF(love) = $\log(3/3) = 0$。再加一篇 d4="movie movie movie"：df(movie)=3 → IDF(movie) = $\log(4/4)=0$。
- **最终答案**：两者 IDF 均为 0——因为它们在多数文档出现，"区分度"为零；IDF 惩罚的是"到处出现"的词。
- **易错点**：忘记 $1+\text{df}$ 平滑（df=N 时 log 0 未定义）；IDF 只在**文档级**统计，与词频无关。
- **🤔 追问**：如果语料里只有 d4 提到 "amazing"？—— df=1，IDF=$\log(4/2)=\log2\approx0.69$，"amazing" 的区分度最高。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：SST-2 情感分类中，"This movie is not bad" 对 TF-IDF+LR 与 BERT 分别是什么挑战？
- **解题思路与完整解答**：TF-IDF+LR 是词袋：特征含 "not"、"bad"，线性模型会学"bad → 负向"的权重；"not bad" 的组合信号需要"not"改变 "bad" 的极性——词袋模型只能学"not 出现则偏正"这种粗略补偿，泛化差（"not good" 就失效）。BERT：双向注意力看到 "not" 修饰 "bad"，[CLS] 表示编码了"否定+程度"的组合语义，天然处理。因此 HW02 对照实验里，BERT 在含否定句的测试子集上优势最大。
- **易错点**：认为"加 bigram 特征（not_bad）"能完全解决——只能覆盖训练见过的组合，无法泛化到 "not terrible" 等新组合。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW02 三路对照 + HW05 SST-2 微调的完整流程。代码形态（TF-IDF + LR，HW02 baseline）：
```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import f1_score, accuracy_score
from datasets import load_dataset

ds = load_dataset("glue", "sst2")
vec = TfidfVectorizer(max_features=20000, ngram_range=(1, 2))
Xtr = vec.fit_transform(ds["train"]["sentence"])
Xva = vec.transform(ds["validation"]["sentence"])
clf = LogisticRegression(max_iter=1000)
clf.fit(Xtr, ds["train"]["label"])
pred = clf.predict(Xva)
print("Acc:", accuracy_score(ds["validation"]["label"], pred),   # 期望 ~0.82-0.85
      "F1:", f1_score(ds["validation"]["label"], pred))
# 对照：MLP(词向量平均) 与 BERT 微调 见 HW02 报告
```

## 8. 常见误区和易混概念

### 误区 1：以为"TF-IDF 特征包含词序信息"
- **错误直觉**：TF-IDF 已经很好地表示了文本。
- **为什么错**：TF-IDF 是词袋：维度是独立词（除非显式加 n-gram 特征），"猫追狗"与"狗追猫"特征完全相同。
- **正确理解**：TF-IDF 编码"词的重要性"，不编码结构；需要词序用 n-gram 特征（维度爆炸）或神经网络。

### 误区 2：以为"微调 BERT 一定吊打一切，不用做特征工程"
- **错误直觉**：直接上 BERT，传统方法没必要学。
- **为什么错**：BERT 需要足够数据与算力；小数据（几百条）时 TF-IDF+LR 常与 BERT 相当甚至更好（预训练分布与领域差异大时）；且传统方法可解释、可部署轻量。
- **正确理解**：HW02 的意义就是"对照"——用数据说话，别用信仰选模型。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| TF-IDF+LR（本概念） | 词面区分度 | 稀疏、可解释、无词序 | HW02 baseline、小数据 |
| 词向量+MLP | 静态语义 | 稠密、语义相似、无上下文 | 中小数据 |
| 微调 BERT | 上下文语义 | 双向、强、贵 | SST-2（HW05）、大数据 |
| 规则/词典 | 关键词匹配 | 零训练、覆盖差 | 快速原型 |

### 题目与解析

#### 1. TF-IDF、词向量平均、BERT [CLS] 三种表示各编码了什么信息？
> [!question]- 答案解析
> - **答案**：TF-IDF 编码"词的文档级区分度"（词面统计）；词向量平均编码"词的静态语义"（分布式表示，无词序）；BERT [CLS] 编码"整句的上下文语义"（双向注意力融合全部 token，含词序与句法）。
> - **解析**：表示能力递增：字面 → 词义 → 语境；对应 HW02 三路对照的性能阶梯。
> - **易错原因**：以为词向量平均包含词序（它不包含，平均丢顺序）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. $N=10$，词 "the" 在 9 篇文档出现，"great" 在 1 篇出现，求两者 IDF。
> [!question]- 答案解析
> - **答案**：IDF(the) = $\log(10/(1+9)) = \log 1 = 0$；IDF(great) = $\log(10/(1+1)) = \log 5 \approx 1.609$。
> - **解析**：IDF 衡量"罕见度"：the 无区分度，great 区分度高（1.609 的权重放大其贡献）。
> - **易错原因**：忘记 $1+$ 平滑；把 df 与 TF 混淆。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 只有 300 条标注数据做情感分类，选哪种方法？理由？
> [!question]- 答案解析
> - **答案**：TF-IDF + 逻辑回归（或 SVM）优先；可同时试词向量平均 + MLP 作对照。不建议直接微调 BERT-base（110M 参数在 300 条数据上易过拟合，且与预训练领域差异可能大）。
> - **解析**：小数据下复杂模型过拟合、收益递减；传统方法可解释、稳定、快。若必须用 BERT：冻结主干只微调顶层 + 强正则（dropout、早停）或 LoRA。
> - **易错原因**：无脑上 BERT——小数据时效果常不如 LR 且调试成本高。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 为什么 "not bad" 是词袋方法的难点？bigram 特征能解决吗？
> [!question]- 答案解析
> - **答案**：词袋把 "not" 与 "bad" 当独立维度，线性模型学到 "bad→负" 的权重，组合语义（否定翻转极性）无法表达。bigram 特征（"not_bad"）只能覆盖训练见过的组合，对 "not terrible"/"not awful" 等未见组合不泛化，且特征爆炸。
> - **解析**：BERT 通过注意力让 "not" 直接修饰 "bad"，组合语义被编码进表示——这是上下文表示的本质优势。
> - **易错原因**：以为 bigram 根治否定问题。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 电商评论 98% 好评、2% 差评，要召回差评（用于售后），设计完整方案。
> [!question]- 答案解析
> - **答案**：① 指标：不优化 Acc（98% 无意义），优化差评类的召回率@固定误报率（或 F1、PR-AUC）；② 数据：对差评过采样/合成（SMOTE 或回译增强）、对好评欠采样，或训练时用 `class_weight` 提高差评权重；③ 模型：TF-IDF+LR 与 BERT 双路线对比（数据量决定）；④ 阈值：把差评判定阈值从 0.5 下调（如 0.3）以提升召回，用验证集画 PR 曲线选点；⑤ 上线：保留"待人工复核"桶（召回优先、误报由人工兜底）。
> - **解析**：核心是"代价不对称"：漏掉差评（售后危机）比误报好评（多看一眼）代价高——指标、采样、阈值、人工兜底四层协同。
> - **易错原因**：只做重采样不改指标/阈值；或只调阈值不重采样（两者需联合验证）。
> - **Obsidian 标签建议**：`#自测题/较难`
