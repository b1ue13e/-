# 序列标注
---
## 0. 先判断它值不值得深挖
- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：序列标注是 NLP 最通用的任务框架——词性标注、NER、分块、槽位填充全是它；HMM/CRF 是 [[统计机器学习]] 与 [[NLP数学基础]] 的集成，BiLSTM-CRF 是 [[信息抽取]] 的标配。面试必考"BIO 标注""CRF 与 HMM 的区别""BiLSTM-CRF 为什么强"。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 很多任务本质是"给每个词贴标签"（词性/实体/分块），但标签间强烈相关：独立 softmax 无视"B-PER 后不能接 I-LOC"这类约束，输出非法序列。
> 序列标注的回答：**把"逐词打标签"建模为结构化预测**——HMM（生成式）/CRF（判别式）显式建模标签转移；BiLSTM 编码上下文 + CRF 约束输出（BiLSTM-CRF 标准）；预训练时代 BERT + 头。

- **实际应用场景**：NER、词性标注、中文分词（B/M/E/S）、槽位填充；面试"BIO/BIOES""CRF 特征函数""BiLSTM-CRF 损失"；作业 HW 手写 parser。

## 4. 用直觉语言解释它
> «"序列标注像'给流水线上的每个零件贴工序标签'：BIO 是三种贴纸——B（一个部件段的开头）、I（段中间）、O（不属于任何段）。HMM 像'按图纸猜工序'：它假设'下一步工序只由当前工序决定'（转移）且'零件形状只由当前工序决定'（发射），简单但常猜错。CRF 是'有经验的老师傅'：他不只看单一依赖，而是把整条线的所有局部线索（这个词是名词、上一个是动词、下一个是介词）综合打分，最后选一条'全局最合理的标签串'。BiLSTM-CRF = '老师傅 + 智能眼'：BiLSTM 先看完整上下文把每个词变成有语境的向量（发射分数），CRF 再保证标签串合法。"»
- **直觉类比/几何图像**：CRF = 带转移边的序列图模型，解码 = 在图上找最长路径（Viterbi）。
- **为什么很自然**：语言标签有强序列依赖，建模"相邻标签的兼容性"是最小必要假设。
- **一句话直觉本质**：**"序列标注 = 给词序列预测合法标签序列：HMM 生成式（转移+发射），CRF 判别式（特征+转移），BiLSTM-CRF 用深度上下文喂发射分数 + CRF 全局约束。"**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**序列标注**：输入 $x_1,\dots,x_n$，预测标签 $y_1,\dots,y_n$（如 BIO 集合），要求整条序列联合一致。
**HMM**：生成式模型，$P(x,y) = \prod_t P(y_t|y_{t-1}) P(x_t|y_t)$（一阶马尔可夫 + 观测独立）。
**CRF**：判别式线性链模型，$P(y|x) \propto \exp\big(\sum_t [\phi(y_t,x,t) + \psi(y_{t-1},y_t)]\big)$。
**BiLSTM-CRF**：BiLSTM 输出发射分数 $E$，CRF 加转移分数 $T$。
### 2. 核心公式
**CRF 条件概率**：
$$P(y|x) = \frac{\exp\left(\sum_{t=1}^{n} E_{t,y_t} + \sum_{t=1}^{n-1} T_{y_t,y_{t+1}}\right)}{\sum_{y'}\exp\left(\sum_{t} E_{t,y'_t} + \sum_{t} T_{y'_t,y'_{t+1}}\right)}$$
**训练损失（负对数似然）**：
$$\mathcal{L} = -\log P(y^*|x)$$
**Viterbi 解码**：$y^* = \arg\max_y \sum_t E_{t,y_t} + \sum_t T_{y_t,y_{t+1}}$（动态规划 $O(n|Y|^2)$）。
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $x_t$ | 第 $t$ 个词 | 词/子词 | 输入 |
| $y_t$ | 第 $t$ 个标签 | BIO 集合 | 输出 |
| $E_{t,y}$ | 发射分数 | $\mathbb{R}$ | BiLSTM 输出 |
| $T_{a,b}$ | 转移分数 | $\mathbb{R}$ | CRF 参数 |
| $\phi,\psi$ | 特征/转移函数 | $\mathbb{R}$ | 可学习 |
| $|Y|$ | 标签数 | 如 5（BIOES） | 复杂度因子 |
### 4. 常见变体与适用条件
- **HMM**：无监督/小数据、解释性强；观测独立假设强、判别能力弱。
- **BiLSTM-CRF**：端到端、免特征工程，2015-2019 NER 标准。
- **BERT+CRF/Linear**：预训练时代，token 级表示 + 轻量头；数据足时线性头即可。
- **限制条件**：解码复杂度 $O(n|Y|^2)$；长程标签依赖（>2 阶）建模难；嵌套实体需特殊方案。

## 6. 推导思路和思想来源
- **最初困难**：逐词独立分类产生非法标签序列、丢失标签依赖；HMM 加了转移却假设"观测独立"（$P(x_t|y_t)$ 切断词间联系）。
- **关键"转念"**：① 判别式优于生成式：直接建模 $P(y|x)$ 而非 $P(x,y)$，特征可以任意重叠（Lafferty et al. 2001 提出 CRF，解决 MEMM 的标注偏置）；② 全局归一化：分母对整条序列求和（区别于逐位置 softmax），配合 Viterbi 得全局最优；③ 深度化：BiLSTM 自动学特征替代手工特征（Huang et al. 2015；Ma & Hovy 2016）。
- **推导主线与动机**：独立分类 → HMM（转移）→ MEMM/CRF（判别+全局归一）→ BiLSTM-CRF（表示+约束）→ BERT（预训练表示）；每步修正上一步的统计假设。
- **为什么自然得到此结论**：标签序列是"路径"而非"点集"，自然用图模型 + 路径解码；深度模型负责表示、图模型负责结构。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：词序列 [我, 在, 北京, 工作]，标注 PER/LOC/O。写出 BIO 标签。
- **解题思路与关键步骤**：我=O；在=O；北京=B-LOC（单实体词也是 B）；工作=O。
- **最终答案**：[O, O, B-LOC, O]。
- **易错点**："北京"若写成 B-LOC I-LOC 也常见（两字拆两 token）；但"我在北/京工作"（子词）必须 B-LOC I-LOC。
- **🤔 追问**：BIOES 方案怎么写？—— 北京=B-LOC E-LOC？不，"北京"整体是单个实体：B-LOC E-LOC（两字）或 S-LOC（一字）；"我"=O，"在"=O，"工作"=O。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：CRF 与逐词 softmax 的损失有何本质不同？—— softmax 对每个位置独立归一化：$\mathcal{L}=-\sum_t\log P(y_t|x)$；CRF 对整条序列归一化（分母遍历所有标签串，用前向算法算）。因此 CRF 能惩罚非法序列（如 B-PER→I-LOC 组合），softmax 不能——训练时 CRF 显式压低转移分数 $T_{\text{B-PER,I-LOC}}$。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HuggingFace + torchcrf 的 BiLSTM-CRF 骨架：
```python
import torch, torch.nn as nn
from torchcrf import CRF

class BiLSTM_CRF(nn.Module):
    def __init__(self, vocab, emb_dim=100, hidden=128, n_tags=5):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb_dim)
        self.lstm = nn.LSTM(emb_dim, hidden, bidirectional=True, batch_first=True)
        self.fc = nn.Linear(hidden * 2, n_tags)
        self.crf = CRF(n_tags, batch_first=True)
    def forward(self, x, mask):
        e = self.emb(x)
        h, _ = self.lstm(e)
        emissions = self.fc(h)
        return self.crf.decode(emissions, mask)   # Viterbi 解码
    def loss(self, x, y, mask):
        emissions = self.fc(self.lstm(self.emb(x))[0])
        return -self.crf(emissions, y, mask)      # 负对数似然
```

## 8. 常见误区和易混概念
### 误区 1：以为"HMM 和 CRF 差不多，都是序列概率模型"
- **错误直觉**：都有转移和发射。
- **为什么错**：HMM 是生成式（建模 $P(x,y)$，要求观测独立）；CRF 是判别式（建模 $P(y|x)$，特征可任意重叠，无独立假设）。CRF 精度普遍更高，代价是需标注数据。
- **正确理解**：生成 vs 判别是统计建模的根本分歧，不止序列模型。
### 误区 2：以为"BiLSTM-CRF 的 CRF 层可有可无"
- **错误直觉**：BiLSTM 已经很强，softmax 够了。
- **为什么错**：BiLSTM 的发射分数是逐位置独立的；CRF 提供标签转移约束（B 后必须 I 同类型或 O），并全局归一化训练。去掉 CRF 在 NER 上通常掉 1-3 个点，且输出非法序列。
- **正确理解**：表示（BiLSTM/BERT）+ 结构（CRF）互补，缺一不可。
### 概念对比表
| 概念 | 建模方式 | 关键假设 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| HMM | 生成式 | 观测独立+一阶转移 | 无监督分词 |
| CRF（本概念） | 判别式 | 全局归一化 | 特征工程 NER |
| BiLSTM-CRF | 深度+判别 | 表示自动学 | 标准 NER |
| BERT+头 | 预训练+微调 | 表示预训练 | 现代 SOTA |

### 题目与解析
#### 1. BIO 与 BIOES 标注方案的区别？为什么 BIOES 更优？
> [!question]- 答案解析
> - **答案**：BIO 只有 B（开始）/I（内部）/O（外部）；BIOES 增加 E（结尾）/S（单字实体）。BIOES 显式编码实体边界信息，解码更准；代价是标签数从 3 变 5。
> - **解析**：实体长度信息帮助 Viterbi 排除非法路径（如 B 后必须接 I/E）。`#自测题/基础`
#### 2. 序列 [我, 爱, 北京]，标签 [O, O, B-LOC]，发射分数 $E$：O=(0.6,0.4), O=(0.7,0.3), B-LOC=(0.8,0.2)（各位置两标签分数），转移 $T_{O,O}=1, T_{O,B}=0.5$。求路径分数（忽略其他项）。
> [!question]- 答案解析
> - **答案**：$E_{1,O}+E_{2,O}+E_{3,B} + T_{O,O}+T_{O,B} = 0.6+0.7+0.8+1+0.5=3.6$。
> - **解析**：路径分数 = 发射和 + 转移和；解码就是找使该分数最大的路径。`#自测题/基础`
#### 3. 什么场景用 HMM 而不是 CRF？
> [!question]- 答案解析
> - **答案**：无标注数据（HMM 可无监督/半监督，如 jieba 用 HMM 识别新词）、需要生成式解释、数据极小且特征工程不可行时。有标注数据、追求精度时 CRF 全面占优。
> - **解析**：生成式可用 EM 无监督训练；判别式必须有标签。`#自测题/中等`
#### 4. 论证"BiLSTM-CRF 中 CRF 层不可省略"。
> [!question]- 答案解析
> - **答案**：① 结构约束：B-PER 后 I-LOC 等非法转移被转移矩阵压制，逐词 softmax 无法表达；② 全局归一化：训练时整条路径归一，模型学会"整串合法"而非"每点正确"；③ 实验：CoNLL-2003 NER 上去掉 CRF 通常掉 1-3 个点（尤其长实体）。
> - **解析**：表示层提供发射分数，结构层保证标签合法性——两者正交。`#自测题/中等`
#### 5. 分析 Viterbi 解码的复杂度，并说明与暴力枚举的差距。
> [!question]- 答案解析
> - **答案**：暴力枚举 $|Y|^n$ 条路径；Viterbi 利用最优子结构：每步只需保留到每个标签的最优路径（$|Y|$ 条候选），转移 $O(|Y|^2)$，总 $O(n|Y|^2)$。$n=100, |Y|=5$ 时：暴力 $5^{100}$ 不可行，Viterbi $100\times25=2500$ 步。
> - **解析**：这是动态规划在序列解码上的标准应用，与 HMM 解码同构。`#自测题/较难`
