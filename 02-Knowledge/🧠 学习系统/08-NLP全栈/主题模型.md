# 主题模型
---
## 0. 先判断它值不值得深挖
- **类别**：**B 类（常用工具）**
- **判断理由**：LDA 是"无监督发现文档主题"的经典方法，面试与信息检索课程必提；其"生成过程 + 变分/Gibbs"思想是理解 [[02-Knowledge/🧠 学习系统/14-概率图模型/🗺️ 概率图模型学习路径|概率图模型]] 的绝佳入口。深度学习时代它不是主线，但 [[词向量与Word2Vec]] 的共现思想与它同源，值得掌握到"能讲清生成故事"。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 一万篇新闻文档，没人标注主题，怎么自动知道它们讲什么？TF-IDF 只能给词排序，看不出"文档-主题-词"的层次结构。
> 主题模型的回答：假设**每篇文档是若干主题的混合，每个主题是词表上的分布**——LSA 用矩阵分解找潜在语义；pLSA/LDA 用概率生成模型：先选主题（掷文档-主题骰子），再从主题-词骰子生成每个词。训练后得到"文档→主题分布"与"主题→词分布"，主题就是可解释的词聚类。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：LDA 是 [[NLP数学基础]]（贝叶斯、Dirichlet）与 [[统计机器学习]]（生成模型）的集大成应用；其"潜在变量"思想延伸到神经主题模型与 [[词向量与Word2Vec]] 的潜在语义。
- **实际应用场景**：新闻聚类与热点发现、学术文献主题图谱、推荐系统的兴趣画像、语料探索（数据科学 EDA）。
- **高频题型/任务**：面试"LDA 的生成过程""LDA 和 pLSA 的区别""困惑度评估主题数""Gibbs 采样直觉"。

## 4. 用直觉语言解释它
> «"LDA 像一个'文档装盘师'：每篇文档是一桌菜，主题是'菜系'（川菜/粤菜/甜品），词是'菜品'。生成一篇文档 = 先决定这桌菜里各菜系占多少比例（文档-主题分布），再按比例从各菜系菜单里一道道点菜（主题-词分布）。反过来说，给一桌菜猜它是什么菜系、各占多少——这就是推断。Gibbs 采样像'一个词一个词地重猜'：先随机给每个词分配菜系，然后轮流根据其他词的分配重新掷骰子，多轮后分配稳定下来，主题就出来了。"»
- **直觉类比/几何图像**：LDA 是三层贝叶斯：语料级（主题-词 Dirichlet）→ 文档级（文档-主题 Dirichlet）→ 词级（多项式采样）。
- **为什么很自然**：人类读文档就是在做"这篇主要在讲什么"的贝叶斯推断；把直觉形式化为骰子生成故事，是生成模型的自然表达。
- **一句话直觉本质**：**"文档 = 主题混合，主题 = 词分布"的双重骰子生成过程；推断 = 从词观测反推主题分配（变分推断或 Gibbs 采样）。**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**LDA（Latent Dirichlet Allocation, Blei 2003）**：$K$ 个主题，每个主题 $\phi_k$ 是词表上的分布，每篇文档有主题比例 $\theta_d$（Dirichlet 先验），生成第 $n$ 个词：先采主题 $z_{dn}\sim\text{Mult}(\theta_d)$，再采词 $w_{dn}\sim\text{Mult}(\phi_{z_{dn}})$。
### 2. 核心公式
**生成过程**：
$$\theta_d \sim \text{Dir}(\alpha), \qquad \phi_k \sim \text{Dir}(\beta), \qquad z_{dn} \sim \text{Mult}(\theta_d), \qquad w_{dn} \sim \text{Mult}(\phi_{z_{dn}})$$
**文档似然**：
$$P(w_d | \alpha, \beta) = \int \prod_{n=1}^{N_d} \left(\sum_{k=1}^{K} \theta_{dk}\,\phi_{k w_{dn}}\right) P(\theta_d|\alpha)\,P(\phi|\beta)\,d\theta_d\,d\phi$$
**Gibbs 采样更新（单个词的主题条件分布）**：
$$P(z_i=k | z_{-i}, w) \propto \frac{n_{k,w_i}^{(-i)}+\beta}{n_k^{(-i)}+V\beta}\cdot\frac{n_{d,k}^{(-i)}+\alpha}{n_d^{(-i)}+K\alpha}$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $K$ | 主题数 | 超参数 | 需调（困惑度选） |
| $\theta_d$ | 文档-主题分布 | 单纯形 $\Delta^{K-1}$ | 每文档一份 |
| $\phi_k$ | 主题-词分布 | 单纯形 $\Delta^{V-1}$ | 每主题一份 |
| $\alpha,\beta$ | Dirichlet 超参 | $>0$ | 控制稀疏性 |
| $z_{dn}$ | 词的主题指派 | $\{1,\dots,K\}$ | 潜在变量 |
| $V$ | 词表大小 | 整数 | 去停用词后 |
### 4. 常见变体与适用条件
- **LSA**：SVD 分解词-文档矩阵，非概率、无先验，速度快但结果无概率解释。
- **pLSA**：概率化 LSA，有主题-词/文档-主题分布但**无先验**（参数随文档数增长、易过拟合）。
- **LDA**：pLSA 加 Dirichlet 先验的贝叶斯版本，泛化最好，是事实标准。
- **限制条件**：$K$ 需人工指定；词袋假设忽略词序；主题可解释性需人工判断（无自动"好主题"标准）。
---
## 6. 推导思路和思想来源
- **最初困难**：文档聚类需要语义级相似度，BOW 向量维数爆炸且稀疏；不知道"主题"这个隐藏变量怎么建模。
- **直接方法局限**：LSA 的 SVD 给出连续潜在空间但无概率解释、无法处理新文档的增量推断。
- **关键"转念"**：把主题当作**潜在随机变量**，构造生成故事（先验→隐藏→观测），用贝叶斯后验 $P(z,\theta,\phi|w)$ 推断。后验不可解析 → ① 变分推断（用可分解分布逼近，Blei 原始论文）；② **Gibbs 采样**（对每个词轮流采样其主题，利用共轭结构闭式更新，Griffiths & Steyvers 2004，实现更简单）。
- **推导主线与动机**：LSA（矩阵）→ pLSA（概率+EM）→ LDA（贝叶斯+先验）→ 推断（变分/Gibbs）——每一步补上前一步的缺陷。
- **为什么自然得到此结论**：Dirichlet 与多项式的共轭性使 Gibbs 更新闭式可算；"轮流重采样"正是马尔可夫链蒙特卡洛的标准玩法。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：$K=2$，主题 1 词分布偏爱 {猫,鱼}，主题 2 偏爱 {编程,数据}。文档只有 2 个词：猫、编程。给出 Gibbs 采样一步的直觉计算。
- **解题思路与关键步骤**：先随机指派 $z_1=\text{T1}, z_2=\text{T2}$。重采样 $z_1$：$P(z_1=\text{T1})\propto\frac{n_{\text{T1,猫}}+1}{n_{\text{T1}}+V}\cdot\frac{n_{d,\text{T1}}+\alpha}{n_d+K\alpha}$，其中分子分母来自其他词当前指派。直观上"猫"在 T1 下似然高，$z_1$ 倾向留在 T1。
- **最终答案**：多轮采样后，文档主题分布收敛到 $\theta_d\approx(\text{T1 高, T2 低})$ 附近（"猫"主导）。
- **易错点**：计数要排除当前词（$(-i)$ 记号）；忘记加先验平滑 $\beta$ 会导致零概率。
- **🤔 追问**：若文档只有"编程编程编程"？—— 全部分配到 T2，主题比例 $\theta_d\to(0,1)$。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：为什么 LDA 优于 pLSA？—— pLSA 的 $\theta_d$ 是**点估计参数**（无先验），文档越多参数越多，且新文档无法直接推断；LDA 给 $\theta_d,\phi_k$ 加 Dirichlet 先验，参数化固定、可对新文档做后验推断、天然正则化防过拟合。代价是后验无解析解，需近似推断。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：`gensim` 的 LDA 一行训练 + 困惑度选 $K$：
```python
from gensim.corpora import Dictionary
from gensim.models import LdaModel

texts = [["股票","上涨","市场"], ["算法","数据","模型"], ...]   # 已分词
dct = Dictionary(texts)
corpus = [dct.doc2bow(t) for t in texts]
model = LdaModel(corpus, num_topics=5, id2word=dct, passes=10, alpha="auto")
print(model.print_topics(num_words=5))          # 主题→词分布
print(model[corpus[0]])                          # 文档→主题分布
```

## 8. 常见误区和易混概念
### 误区 1：以为"LDA 的主题就是聚类中心，越少越好"
- **错误直觉**：$K$ 越小越简洁。
- **为什么错**：$K$ 太小把不同话题混在一起（"猫"和"狗"并到一个"动物"主题），太大则主题碎片化；$K$ 是模型容量超参数。
- **正确理解**：用困惑度（held-out）与主题可解释性共同选 $K$；还可对比不同 $K$ 的稳定性。
### 误区 2：以为"LDA 输出即语义向量，可直接当词向量用"
- **错误直觉**：主题分布就是文档表示，够用了。
- **为什么错**：LDA 是词袋、忽略词序与上下文，主题数通常 20-200（粒度粗）；神经词向量（[[词向量与Word2Vec]]）维度更高、语义更细。
- **正确理解**：LDA 适合"可解释的粗粒度主题画像"，稠密向量适合"细粒度语义计算"。
### 概念对比表
| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| LDA（本概念） | 主题发现 | 生成模型+先验 | 文档聚类、画像 |
| LSA | 潜在语义 | 矩阵分解、无概率 | 快速降维检索 |
| pLSA | 主题发现 | 概率无先验 | 历史方法 |
| 词向量 | 词义表示 | 分布式、上下文 | 深度学习输入 |
| 聚类（K-means） | 文档分组 | 距离度量、无生成故事 | 硬聚类 |

## 11. 自测题：5 道
| 题号 | 类型 | 难度 | 考查点 |
| :--- | :--- | :--- | :--- |
| 1 | 概念辨析 | 基础 | LSA/pLSA/LDA 三者的区别 |
| 2 | 公式运用 | 基础 | 生成过程的书写 |
| 3 | 条件判断 | 中等 | 主题数 K 的选择 |
| 4 | 变式/综合 | 中等 | Gibbs vs 变分推断 |
| 5 | 开放/证明/建模 | 较难 | 推导 Gibbs 更新公式的来历 |
### 题目与解析
#### 1. LSA、pLSA、LDA 三者的核心区别是什么？
> [!question]- 答案解析
> - **答案**：LSA = SVD 矩阵分解（无概率）；pLSA = 概率生成但无先验（点估计）；LDA = pLSA + Dirichlet 先验（全贝叶斯）。
> - **解析**：演进方向是"概率化 → 贝叶斯化"，每步修前一步缺陷（无解释、过拟合、无新文档推断）。`#自测题/基础`
#### 2. 写出 LDA 生成一篇文档 $d$ 的完整过程（含每个符号）。
> [!question]- 答案解析
> - **答案**：① 采 $\theta_d\sim\text{Dir}(\alpha)$；② 对第 $n$ 个词：采 $z_{dn}\sim\text{Mult}(\theta_d)$，再采 $w_{dn}\sim\text{Mult}(\phi_{z_{dn}})$（$\phi_k\sim\text{Dir}(\beta)$ 全局共享）。
> - **解析**：两层骰子：文档层决定主题比例，主题层决定词；$\alpha$ 小则文档主题稀疏。`#自测题/基础`
#### 3. 选择主题数 $K$ 时，困惑度越低越好吗？
> [!question]- 答案解析
> - **答案**：不一定。训练集困惑度随 $K$ 单调下降（过拟合）；held-out 困惑度呈 U 形，选谷底附近；但困惑度最小不代表主题可解释，需结合人工检查主题词。
> - **解析**：$K$ 是容量超参数，与正则化同理——在验证集上选，并看主题质量。`#自测题/中等`
#### 4. Gibbs 采样与变分推断各自的优缺点？
> [!question]- 答案解析
> - **答案**：Gibbs：实现简单、渐近精确（MCMC 收敛到真实后验），但收敛慢、需诊断；变分：确定性、可并行、有下界监控收敛，但只给近似分布（有偏）。
> - **解析**：小数据/教学用 Gibbs；大规模生产用变分（如 gensim 的 online variational LDA）。`#自测题/中等`
#### 5. 解释 Gibbs 更新公式 $P(z_i=k|\cdot)\propto\frac{n_{k,w_i}^{(-i)}+\beta}{n_k^{(-i)}+V\beta}\cdot\frac{n_{d,k}^{(-i)}+\alpha}{n_d^{(-i)}+K\alpha}$ 的两项分别是什么。
> [!question]- 答案解析
> - **答案**：第一项 $\frac{n_{k,w_i}^{(-i)}+\beta}{n_k^{(-i)}+V\beta}$ = "词-主题"项：主题 $k$ 生成词 $w_i$ 的似然（共现计数+先验平滑）；第二项 $\frac{n_{d,k}^{(-i)}+\alpha}{n_d^{(-i)}+K\alpha}$ = "文档-主题"项：文档 $d$ 倾向主题 $k$ 的先验强度。两项乘积正比于后验；$(-i)$ 表示排除当前词。
> - **解析**：这是"主题一致性"与"文档主题倾向"的平衡——词想跟同类词走，文档想把词拉向自己的主流主题。`#自测题/较难`
