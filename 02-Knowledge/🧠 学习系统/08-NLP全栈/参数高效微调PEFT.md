# 参数高效微调PEFT
---
## 0. 先判断它值不值得深挖
- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：全量微调 7B 模型需要 7×16GB 显存，普通设备根本跑不动；PEFT 是个人开发者微调大模型的唯一现实路径。[[🧭 开源作业体系-NLP全栈|开源作业体系]] 的微调类作业（HW05 进阶、项目层）都要求 PEFT；面试必问"LoRA 的原理与秩的选择"。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 微调大模型要更新全部参数：7B 模型仅梯度就占 28GB 显存（FP16），加上优化器状态（Adam 再 ×2-3），消费级显卡直接爆显存；而且每个下游任务存一份完整权重，部署成本爆炸。
> PEFT 的回答：**冻结预训练权重，只训练少量新增参数**——Adapter 在层间插小模块；LoRA 给权重矩阵加低秩旁路（$W + BA$）；Prefix/Prompt-Tuning 只调输入侧的连续向量。训练参数量从 100% 降到 0.1%-1%，显存与存储同步下降，效果接近全量微调。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：PEFT 是 [[BERT及其变体]]/[[GPT系列]] 到 [[指令微调与对齐]]（SFT）的工程桥梁；QLoRA = 量化 + LoRA 把 65B 模型微调压进单卡；与 [[LLM推理优化]] 一起构成"低成本用大模型"的两翼。
- **实际应用场景**：本地微调 Llama/Qwen 做领域助手、多任务同时部署（一个底座 + N 个 LoRA 插拔）、少样本领域适配。
- **高频题型/任务**：面试"LoRA 为什么有效（内在低秩）""秩 r 怎么选""Adapter 和 LoRA 参数量对比""PEFT 与全量微调效果差距"；作业：LoRA 微调 BERT 分类。

## 4. 用直觉语言解释它
> «"PEFT 像'给一本精装书加便利贴'：原书（预训练权重）一个字不动，只在关键页贴便利贴（小参数模块）。LoRA 的便利贴最有意思：它不直接改原文，而是在原文旁边放一块'缩小版抄写板'——先压缩成很窄的一行（降维 A），再展开回原宽度（升维 B），$W$ 变成 $W + BA$。因为研究发现权重更新矩阵天然是'低秩'的（有效自由度很小），用窄抄写板就能近似全量更新。推理时把 $BA$ 合并回 $W$，零额外延迟。"»
- **直觉类比/几何图像**：低秩 = 信息集中在少数方向（主成分思想）；$r$ 是抄写板宽度（4-64），$r$ 越大越接近全量微调。
- **为什么很自然**：预训练权重已经很好，微调只是"微调"——大模型的适配是低维流形上的移动（Li et al. 2018 的内在维度实验）。
- **一句话直觉本质**：**"冻结底座，只学增量：Adapter 插层内小网络，LoRA 学低秩旁路 $BA$，Prefix 学输入侧连续向量——把微调参数量降到 0.1%-1% 而效果基本不掉。"**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**LoRA（Hu et al. 2021）**：冻结 $W_0 \in \mathbb{R}^{d\times d}$，引入低秩分解 $BA$（$B\in\mathbb{R}^{d\times r}$，$A\in\mathbb{R}^{r\times d}$，$r\ll d$），前向变为 $h = W_0 x + BAx$。
**Adapter（Houlsby 2019）**：层内插入"降维-激活-升维"瓶颈模块，只训练瓶颈参数。
**Prefix-Tuning（Li & Liang 2021）/ P-Tuning**：在输入序列前拼接可学习的连续向量（前缀/软提示），只训练这些向量。
### 2. 核心公式
**LoRA 前向**：
$$h = W_0 x + \frac{\alpha}{r} B A x, \qquad A \sim \mathcal{N}(0,\sigma^2),\ B = 0 \ (\text{初始化})$$
**训练参数量对比**（全量 vs LoRA，作用于 $W_Q,W_K,W_V,W_O$）：
$$\text{可训练参数} = 4 \times (d \cdot r + r \cdot d) = 8dr \ll d^2$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $W_0$ | 冻结的预训练权重 | $\mathbb{R}^{d\times d}$ | 不更新 |
| $r$ | 低秩秩 | 4–64 | 超参数 |
| $A,B$ | LoRA 分解矩阵 | $\mathbb{R}^{r\times d}, \mathbb{R}^{d\times r}$ | 仅它们可训练 |
| $\alpha$ | 缩放系数 | 常数 | 与 r 联合调 |
| $d$ | 隐藏维度 | 768–8192 | 模型宽度 |
### 4. 常见变体与适用条件
- **LoRA**：作用在注意力投影（默认 $Q,V$，可全上）；推理可合并零延迟；$r$ 小则欠拟合、大则接近全量。
- **QLoRA**：4-bit 量化权重 + LoRA，单卡微调 65B；额外加"分页优化器"防 OOM。
- **Adapter**：层内串行/并行瓶颈；可模块复用（一次训练多处插拔），但推理有额外层延迟。
- **Prefix/P-Tuning**：参数最少（几千-几十万），适合提示敏感任务；容量小，强任务（生成）效果弱于 LoRA。
- **限制条件**：极低资源下 PEFT 仍可能欠拟合；不同任务最优 $r$ 不同；PEFT 不能替代全量微调的天花板（数据足够时）。
---
## 6. 推导思路和思想来源
- **最初困难**：全量微调大模型的显存/存储/通信三重成本随参数量线性暴涨。
- **直接方法局限**：只微调顶层（迁移差）、冻结底座（效果差）、蒸馏（需要训练数据与教师）。
- **关键"转念"**：① 权重更新 $\Delta W$ 是**低秩**的：Aghajanyan 2020 证明预训练模型微调的内在维度很小，$r$ 取 1-64 即可近似；② 把 $\Delta W$ 显式参数化为 $BA$（LoRA）——既约束了假设空间（正则化）又大幅降参；③ 不碰权重、只调"输入侧"也是合法微调（Prefix/Prompt）——因为 Transformer 对前缀向量敏感。
- **推导主线与动机**：全量（$d^2$）→ 低秩分解（$2dr$）→ 层内瓶颈（Adapter）→ 输入侧（Prefix）；沿"哪里需要更新、更新多少维度"的轴线收缩。
- **为什么自然得到此结论**：预训练已给好表示，适配只需要"局部低维修正"——低秩假设是统计上最自然的先验。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：$d=768$，$r=8$，对 $W_Q,W_K,W_V,W_O$ 四个矩阵做 LoRA。可训练参数量是多少？占比多少（模型 110M）？
- **解题思路与关键步骤**：每个矩阵 $2dr = 2\times768\times8 = 12288$；四个共 49152。
- **最终答案**：49152 参数，占 110M 的 0.045%。
- **易错点**：忘记乘 2（A 和 B 各一份）或乘 4（四个投影矩阵）。
- **🤔 追问**：$r$ 翻倍到 16？—— 参数量翻倍到 98304，仍只有 0.09%；效果通常略升。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：为什么 LoRA 推理时零额外延迟？—— 推理时先算 $W' = W_0 + \frac{\alpha}{r}BA$ 合并成单一矩阵，前向只用 $W'x$；而 Adapter 是层内串行模块，每层多两次矩阵乘，延迟增加。这也是 LoRA 成为工业默认的原因之一。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：`peft` 库 + `transformers`，LoRA 微调 BERT 分类：
```python
from transformers import AutoModelForSequenceClassification, Trainer
from peft import LoraConfig, get_peft_model

model = AutoModelForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=2)
lora = LoraConfig(r=8, lora_alpha=16, target_modules=["query", "value"], lora_dropout=0.1)
model = get_peft_model(model, lora)
print(model.print_trainable_parameters())   # trainable: 294,912 / 109,485,058 (0.27%)
trainer = Trainer(model=model, args=training_args, train_dataset=ds["train"],
                  eval_dataset=ds["validation"])
trainer.train()
```

## 8. 常见误区和易混概念
### 误区 1：以为"LoRA 的秩 $r$ 越大一定越好"
- **错误直觉**：$r=512$ 接近全量，肯定更好。
- **为什么错**：$r$ 大到一定程度收益饱和甚至下降（低秩是正则，约束有益）；且 $r$ 大时 $\alpha/r$ 缩放需重调，显存上升。
- **正确理解**：$r\in[4,64]$ 是经验甜区；用验证集调，而非一味加大。
### 误区 2：以为"PEFT 效果永远等于全量微调"
- **错误直觉**：论文说 LoRA 不输全量。
- **为什么错**：那是"通常/多数任务"；在数据充足、任务与预训练分布差异大时，全量仍占优；PEFT 是"近似 + 正则"的折中。
- **正确理解**：PEFT 是成本约束下的最优解，不是无条件等价。
### 概念对比表
| 概念 | 更新什么 | 参数量级 | 典型场景 |
| :--- | :--- | :--- | :--- |
| LoRA（本概念） | 低秩旁路 BA | 0.01%-1% | 通用微调默认 |
| Adapter | 层内瓶颈模块 | 0.5%-5% | 模块复用 |
| Prefix/P-Tuning | 输入侧连续向量 | <0.1% | 轻量适配 |
| 全量微调 | 全部权重 | 100% | 数据足、预算足 |
| 蒸馏 | 学生模型权重 | 100%（小模型） | 部署替代 |

### 题目与解析
#### 1. LoRA、Adapter、Prefix-Tuning 各自更新哪些参数？
> [!question]- 答案解析
> - **答案**：LoRA：权重矩阵的低秩旁路 $BA$（冻结 $W_0$）；Adapter：层内瓶颈小模块；Prefix/P-Tuning：输入侧连续向量（软提示）。
> - **解析**：三者分别是"权重侧/结构侧/输入侧"的参数化，都冻结底座。`#自测题/基础`
#### 2. $d=1024$，$r=16$，LoRA 作用于 $Q,K,V,O$ 四个矩阵，可训练参数多少？
> [!question]- 答案解析
> - **答案**：每个矩阵 $2\times1024\times16=32768$，四个共 131072。
> - **解析**：$8dr=8\times1024\times16=131072$；对比全量 $4d^2=4.2\text{M}$，降低约 32 倍。`#自测题/基础`
#### 3. 什么场景必须全量微调而不是 PEFT？
> [!question]- 答案解析
> - **答案**：任务与预训练分布差异极大（新语言/新模态）、数据非常充足、需要模型完全改变行为模式（强对齐）时，PEFT 容量可能不够；此时全量（或加高秩 LoRA）更稳。
> - **解析**：PEFT 本质是低维假设 + 正则；假设不成立时失效。成本允许时可用全量做对照。`#自测题/中等`
#### 4. QLoRA 由哪些组件组成？各自解决什么问题？
> [!question]- 答案解析
> - **答案**：① 4-bit 量化底座权重（NF4 格式）→ 显存降 4 倍；② LoRA 低秩旁路 → 可训练参数极小；③ 分页优化器（paged optimizer）→ 显存峰值溢出时自动换页到 CPU；④ 反量化计算 → 保持精度。
> - **解析**：三者叠加使 65B 微调进入单卡（48GB）；论文报告 4-bit 相对 16-bit 精度损失 <1%。`#自测题/中等`
#### 5. 论证"微调更新是低秩的"这一假设，并说明 LoRA 如何利用它。
> [!question]- 答案解析
> - **答案**：Aghajanyan et al. 2020 实验：把微调限制在随机投影的低维子空间（仅 200-1000 维）仍能达到接近全量效果——说明任务适配所需的有效自由度很小，即 $\Delta W$ 的低秩近似误差可忽略。LoRA 据此把 $\Delta W$ 参数化为 $BA$（秩 $r$），把优化从 $d^2$ 维空间约束到 $2dr$ 维；低秩既是容量约束（正则）也是计算红利（梯度只回传 $A,B$）。
> - **解析**：这是"先有现象（内在低维）→ 后有参数化（低秩分解）"的科研链路；$r$ 即假设的自由度。`#自测题/较难`
