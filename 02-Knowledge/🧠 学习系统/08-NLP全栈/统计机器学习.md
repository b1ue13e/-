# 统计机器学习
---
## 0. 先判断它值不值得深挖
- **类别**：**B 类（常用工具）**
- **判断理由**：深度学习之前，NLP 靠统计方法打天下：朴素贝叶斯（情感分类基线）、逻辑回归（特征线性分类）、HMM/CRF（序列标注）、LDA（主题）。理解它们才能理解"深度方法到底改进在哪"；面试常考"生成式 vs 判别式""朴素贝叶斯的独立假设""CRF vs 逻辑回归"。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 早期 NLP 面对的是"小数据 + 高维稀疏特征"：10 万维词特征、几万条样本。深度模型（需要海量数据与算力）跑不动；规则系统覆盖不了语言的变化。
> 统计机器学习的回答：**用数学上成熟、数据效率高的模型处理稀疏高维特征**——朴素贝叶斯用"条件独立假设"把联合概率拆成可估的乘积（生成式，零训练成本）；逻辑回归/最大熵直接建模 $P(y|x)$ 并用梯度/迭代加权拟合（判别式，特征任意组合）；CRF 把逻辑回归推广到序列（带转移约束的结构化预测）；LDA 做无监督主题发现。它们定义了 NLP 的特征工程时代。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：统计方法是 [[NLP数学基础]] 的第一次大规模应用，也是 [[文本分类与情感分析]]（HW02 baseline）、[[序列标注]]、[[主题模型]] 的骨架；深度模型是"统计目标 + 神经函数近似"——逻辑回归的 softmax 就是神经网络的最后一层。
- **实际应用场景**：垃圾邮件/情感分类基线、特征可解释的信用/风控 NLP、小数据场景、序列标注的传统管线。
- **高频题型/任务**：面试"朴素贝叶斯为什么'朴素'""生成式与判别式的区别""逻辑回归与 SVM 对比""CRF 是序列版逻辑回归吗"。
---
## 3. 学它之前需要哪些前置知识？
1. **[[NLP数学基础]]**：条件概率、贝叶斯定理、最大似然。
2. **[[文本表示方法]]**：BOW/TF-IDF 是统计模型的输入特征。
3. **概率论基础**：分布与期望。

## 4. 用直觉语言解释它
> «"统计方法像'经验丰富的老师傅'：朴素贝叶斯是'记性极好但一根筋的会计'——它假设所有特征互不干扰（条件独立：'看到'苹果'和'好吃'的概率直接相乘），算得快但假设太强；逻辑回归是'会加权投票的委员'——每个词投一票（权重可正可负），加总后过 sigmoid 决定正负（'苹果'+1.5 分，'难吃'-2 分，总分>0 判正面）；CRF 是'逻辑回归 + 流程约束'——不只单点投票，还检查标签转合不合法（'B-PER 后不能接 I-LOC'）。深度方法则是'老师傅的学徒'：同样学这些规律，但不用人告诉它看什么特征，自己从数据里学。"»
- **直觉类比/几何图像**：逻辑回归 = 高维空间里找一条"分界线"（线性决策面）；朴素贝叶斯 = 用"独立乘积"近似联合概率。
- **为什么很自然**：小数据下"简单假设 + 强正则"优于"复杂模型 + 过拟合"——统计方法正是这种归纳偏置。
- **一句话直觉本质**：**"统计 NLP = 用成熟概率/优化工具处理稀疏高维文本特征：NB 用独立假设换效率，LR 用特征加权换判别力，CRF 加序列约束，LDA 做无监督；深度模型是它们的'可微分升级版'。"**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**朴素贝叶斯（NB）**：$P(y|x) \propto P(y)\prod_i P(x_i|y)$（条件独立假设）。
**逻辑回归（LR）**：$P(y=1|x) = \sigma(w^\top x + b)$，交叉熵损失，梯度下降/牛顿法求解。
**CRF**：序列版 LR，$P(y|x)\propto\exp(\sum_t w^\top f(y_t,y_{t-1},x,t))$。
### 2. 核心公式
**NB 分类决策**：
$$\hat{y} = \arg\max_y P(y)\prod_{i=1}^{d}P(x_i|y)$$
**LR 预测与损失**：
$$P(y|x) = \sigma(w^\top x), \qquad \mathcal{L} = -\sum_{(x,y)}\big[y\log\sigma(w^\top x) + (1-y)\log(1-\sigma(w^\top x))\big] + \lambda\|w\|^2$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $x_i$ | 第 $i$ 个特征 | 0/1 或实数 | BOW/TF-IDF |
| $w$ | 权重向量 | $\mathbb{R}^d$ | 特征贡献 |
| $\sigma$ | sigmoid 函数 | $(0,1)$ | 概率化 |
| $\lambda$ | L2 正则系数 | $\geq0$ | 防过拟合 |
| $f(\cdot)$ | CRF 特征函数 | $\mathbb{R}$ | 手工设计 |
| $d$ | 特征维度 | 1 万-10 万 | 稀疏 |
### 4. 常见变体与适用条件
- **NB 变体**：多项式 NB（词频）、伯努利 NB（出现与否）、补集 NB（不平衡数据）。
- **LR 变体**：最大熵（多分类）、带 L1/L2 正则（特征选择）。
- **线性 SVM**：hinge 损失 + 最大间隔，小样本分类强。
- **HMM/CRF**：序列任务（见 [[序列标注]]）。
- **适用条件**：小数据、高维稀疏、需可解释、训练预算小。
- **限制条件**：特征线性组合无法捕捉非线性交互（"not good" 需人工构造交叉特征）；NB 的独立假设在语言上明显失真。
---
## 6. 推导思路和思想来源
- **最初困难**：规则系统覆盖窄；小数据下复杂模型过拟合；特征维度 10 万远超样本数。
- **直接方法局限**：决策树/近邻在稀疏高维文本上效果差；深度模型当时缺数据与算力。
- **关键"转念"**：① 贝叶斯框架：把分类变成"后验概率最大化"（NB 用独立假设让参数估计可行——每个 $P(x_i|y)$ 单独计数即可）；② 判别式革命：不建模"词怎么生成"，直接建模"给定词怎么分类"（LR/最大熵，特征可任意重叠、可加权）；③ 序列化：把 LR 的"点分类"推广为"路径分类"（CRF 全局归一化）。
- **推导主线与动机**：生成式（NB：$P(x,y)$ 可分解）→ 判别式（LR：$P(y|x)$ 直接优化）→ 结构化（CRF：路径级判别）；深度化（神经网络 = 特征自动学习 + 相同目标函数）。
- **为什么自然得到此结论**：统计学习 = "数据有限 → 强假设/强正则"的工程科学；每个模型都是"假设强度-表达能力"权衡上的一个点。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：二分类（正/负），词表 {好, 差}，训练集：正类 2 篇（"好"1 次、"差"0 次），负类 2 篇（"好"0 次、"差"1 次）。平滑 $\alpha=1$。新文档含"好"，NB 判哪类？
- **解题思路与关键步骤**：$P(\text{正})=P(\text{负})=0.5$；$P(\text{好}|\text{正})=\frac{1+1}{2+2}=0.5$，$P(\text{好}|\text{负})=\frac{0+1}{2+2}=0.25$。后验：正 $=0.5\times0.5=0.25$，负 $=0.5\times0.25=0.125$。
- **最终答案**：判为正类（0.25 > 0.125）。
- **易错点**：忘记拉普拉斯平滑（$P=0$ 会吞掉整个乘积）；忘记先验 $P(y)$。
- **🤔 追问**：若负类里"好"出现 0 次且不平滑？—— 后验直接为 0，这就是平滑的必要性。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：为什么逻辑回归需要特征交叉（"not+good"）而神经网络不需要？—— LR 是线性模型：$w^\top x$ 只能表达特征独立贡献，"not" 和 "good" 各投各的票，无法表达"not 反转 good"的非线性交互；人工构造交叉特征（$\phi(x)=\text{not}\land\text{good}$）才能表达。神经网络通过隐藏层自动学习这种交互（这就是"深度方法的主要改进"）。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：sklearn 三行训练统计基线，用于对照深度学习：
```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

X = TfidfVectorizer().fit_transform(train_texts)
nb = MultinomialNB().fit(X, train_labels)          # 朴素贝叶斯
lr = LogisticRegression(max_iter=1000).fit(X, train_labels)  # 逻辑回归
print(accuracy_score(test_labels, lr.predict(TfidfVectorizer().fit(train_texts).transform(test_texts))))
```

## 8. 常见误区和易混概念
### 误区 1：以为"朴素贝叶斯因为假设太强所以没用"
- **错误直觉**：条件独立在语言上不成立，模型必差。
- **为什么错**：分类任务只需要"后验排序正确"而非"概率精确"——独立假设下的近似常保留足够的相对排序；且 NB 方差小、对高维稀疏数据稳健，在文本分类上仍是不错的基线。
- **正确理解**：NB 是"有偏但低方差"的模型，小数据下常常赢过复杂模型。
### 误区 2：以为"深度学习出现后统计方法毫无价值"
- **错误直觉**：谁还用手工特征。
- **为什么错**：统计方法的"特征工程 + 线性模型"在数据极少、要求可解释、预算有限的场景仍是首选；且神经网络的输出层/损失函数就是 LR/softmax——统计方法是深度学习的特例。
- **正确理解**：统计 vs 深度是"假设强度-数据规模"的连续谱，不是替代关系。
### 概念对比表
| 模型 | 类型 | 假设 | 优势 | 典型场景 |
| :--- | :--- | :--- | :--- | :--- |
| 朴素贝叶斯（本概念） | 生成式 | 条件独立 | 快、小数据 | 文本分类基线 |
| 逻辑回归 | 判别式 | 线性可分 | 可解释、稳健 | 通用分类 |
| SVM | 判别式 | 最大间隔 | 小样本强 | 高维分类 |
| CRF | 判别式+结构 | 序列约束 | 全局最优 | NER/POS |
| 神经网络 | 判别式 | 无（可逼近） | 非线性+自动特征 | 大数据任务 |

## 11. 自测题：5 道
| 题号 | 类型 | 难度 | 考查点 |
| :--- | :--- | :--- | :--- |
| 1 | 概念辨析 | 基础 | 生成式 vs 判别式 |

### 题目与解析
#### 1. 生成式模型与判别式模型的本质区别？
> [!question]- 答案解析
> - **答案**：生成式建模联合分布 $P(x,y)$（NB、HMM），可生成样本、可无监督；判别式直接建模 $P(y|x)$（LR、CRF、神经网络），只关心分类边界，通常精度更高。
> - **解析**：判别式"只做必要的事"（不建模无关的词分布），数据利用效率更高。`#自测题/基础`
#### 2. 正类 3 篇、"好"出现 2 次；负类 2 篇、"好"出现 0 次；词表 10，$\alpha=1$。含"好"的新文档判哪类？
> [!question]- 答案解析
> - **答案**：$P(\text{正})=0.6$，$P(\text{好}|\text{正})=\frac{2+1}{3+10}=\frac{3}{13}\approx0.231$；$P(\text{负})=0.4$，$P(\text{好}|\text{负})=\frac{0+1}{2+10}=\frac{1}{12}\approx0.083$。正后验 $=0.6\times0.231=0.139>0.4\times0.083=0.033$，判正类。
> - **解析**：平滑分母是"类别词数+词表大小"（多项式 NB）；不平滑则负类后验为 0。`#自测题/基础`
#### 3. 什么场景选统计方法而不是深度模型？
> [!question]- 答案解析
> - **答案**：样本极少（<1 万）、特征高维稀疏、需要可解释权重、训练/推理预算极低、已有高质量特征工程时；深度模型需要大数据与算力，小数据下过拟合。
> - **解析**：选择标准是"数据-模型复杂度匹配"，不是"越先进越好"。`#自测题/中等`
#### 4. 为什么"not good"会难倒线性模型？如何解决？
> [!question]- 答案解析
> - **答案**：线性模型打分 $w^\top x$ 是特征独立贡献之和："not" 与 "good" 各自贡献，无法表达"not 反转 good"的交互（"not good" 应偏负面但"good"权重为正）。解决：① 人工交叉特征（bigram "not_good"）；② 核方法；③ 神经网络隐藏层自动学习交互。
> - **解析**：这是"特征工程时代 vs 表征学习时代"的分水岭问题。`#自测题/中等`
#### 5. 论证"CRF 是序列版逻辑回归"。
> [!question]- 答案解析
> - **答案**：LR：$P(y|x)=\sigma(w^\top f(x))$，线性特征打分后 sigmoid 概率化（单点）；CRF：$P(y|x)=\frac{\exp(\sum_t w^\top f(y_t,y_{t-1},x,t))}{Z(x)}$，同样是"线性特征打分 + 指数概率化"，但特征含标签转移项、归一化在整条路径上（全局）。当序列长度 1 且无转移特征时 CRF 退化为 LR（多分类 softmax 版）。
> - **解析**："结构 = 序列约束"是 CRF 相对 LR 的唯一本质扩展，参数学习同为凸优化。`#自测题/较难`
