# 文本表示方法
---
## 0. 先判断它值不值得深挖
- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：文本表示是 NLP 的"入场券"——所有模型都在消费某种文本向量。从 one-hot/BOW/TF-IDF 到词向量再到上下文表征的演进，串起了 [[词向量与Word2Vec]]、[[BERT及其变体]] 两大主线；面试必考"TF-IDF 公式""静态向量与上下文向量的区别""为什么词向量比 one-hot 好"。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 模型只能吃数字，文本是离散符号："苹果" 和 "香蕉" 在计算机里只是两个不相关的 ID。直接 one-hot：维度=词表大小（10 万维）、向量正交（词间相似度恒为 0）、稀疏。
> 文本表示的回答：**把文本变成有语义结构的向量**——one-hot/BOW 计数（离散、稀疏）；TF-IDF 加权（突出重要词）；词向量/稠密向量（分布假说：相似语境→相近向量，维度 50-300 稠密）；上下文表征（BERT：同一个词在不同句子里有不同向量）。表示质量直接决定下游任务上限。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：文本表示是 [[文本分类与情感分析]]、[[检索增强生成RAG]]、[[信息抽取]] 的公共底座；[[词向量与Word2Vec]]/[[GloVe与稠密向量]] 是"静态表示"的实现，[[BERT及其变体]] 是"上下文表示"的实现。
- **实际应用场景**：检索排序（TF-IDF/稠密向量）、聚类、分类特征、Embedding 数据库（向量检索）。
- **高频题型/任务**：面试"TF-IDF 的 IDF 为什么取对数""one-hot 的余弦相似度为什么恒 0""静态 vs 上下文向量""OOV 问题怎么解决"。

## 4. 用直觉语言解释它
> «"文本表示像'给词拍照'：one-hot 是'一人一个编号'（编号之间毫无关系，10 万人只有 10 万个序号）；BOW 是'统计谁出现过'（只数人头，丢顺序）；TF-IDF 是'统计谁既常见又有特色'（'的'满篇都是但没特色，'量子'少见却很有区分度——TF 看频率，IDF 看稀有度）；词向量是'给每个人画性格坐标'（善良的人聚在一起，词也按语义聚类）；上下文表征是'同一个人在不同场合穿不同衣服'（'苹果'在公司语境是科技公司，在水果摊是水果）。"»
- **直觉类比/几何图像**：表示空间 = 地图：one-hot 是 10 万个互相垂直的坐标轴；词向量是低维稠密地图，语义相近的词聚成团。
- **为什么很自然**：语言的意义在用法中（分布假说），表示必须编码"用法"而非"编号"。
- **一句话直觉本质**：**"文本表示演进 = 从'离散编号'（one-hot/BOW）到'加权统计'（TF-IDF）到'稠密语义'（词向量）再到'上下文动态'（BERT）：信息密度与语义质量逐级提升。"**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**one-hot**：词 $w_i$ 的向量 $\mathbf{v}_i \in \{0,1\}^{|V|}$，第 $i$ 维为 1，其余 0。
**BOW**：文档向量 = 词频计数 $\mathbf{d} = (\text{count}(w_1),\dots,\text{count}(w_{|V|}))$。
**TF-IDF**：$\text{tfidf}(w,d) = \text{tf}(w,d) \times \text{idf}(w)$。
**词向量**：稠密低维向量 $\mathbf{v}_w \in \mathbb{R}^d$（$d\approx100-300$），相似词向量近。
**上下文表征**：$\mathbf{h}_w = f(w, \text{context})$，同词不同语境不同向量。
### 2. 核心公式
$$\text{idf}(w) = \log\frac{N}{1+\text{df}(w)}, \qquad \text{tfidf}(w,d) = \frac{\text{count}(w,d)}{\sum_{w'}\text{count}(w',d)} \cdot \log\frac{N}{1+\text{df}(w)}$$
$$\cos(\mathbf{v}_a, \mathbf{v}_b) = \frac{\mathbf{v}_a \cdot \mathbf{v}_b}{\|\mathbf{v}_a\|\|\mathbf{v}_b\|}$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $|V|$ | 词表大小 | 1 万-10 万 | one-hot 维度 |
| $\text{df}(w)$ | 含词 $w$ 的文档数 | $[1,N]$ | IDF 输入 |
| $N$ | 文档总数 | 整数 | 语料规模 |
| $\mathbf{v}_w$ | 词向量 | $\mathbb{R}^d$ | $d$=50-300 |
| $\mathbf{h}_w$ | 上下文向量 | $\mathbb{R}^d$ | BERT 等输出 |
### 4. 常见变体与适用条件
- **BOW/TF-IDF**：可解释、零训练、稀疏；适合传统分类/检索基线、特征可解释场景。
- **静态词向量**（Word2Vec/GloVe）：稠密、语义相似度；一词一义，多义词被"平均"。
- **上下文表征**（BERT/ELMo）：一词多义、任务自适应；需预训练模型与算力。
- **子词级表示**：BPE 等解决 OOV（见 [[子词分词(Subword Tokenization)]]）。
- **限制条件**：BOW 丢词序；TF-IDF 无语义泛化（"汽车"与"轿车"正交）；静态向量多义词问题；上下文向量维度与成本高。
---
## 6. 推导思路和思想来源
- **最初困难**：符号离散无法直接计算相似度；词表维度爆炸（one-hot 10 万维稀疏）。
- **直接方法局限**：BOW 加权（TF-IDF）只是"更聪明的统计"，词与词依然无关；SVD/LSA 降维（[[主题模型]]）开始有语义但不可增量。
- **关键"转念"**：Harris 分布假说（1954）：**"相似语境出相似词"** → 用"词的上下文分布"表示词：① 统计派：共现矩阵 + 降维（LSA/GloVe）；② 预测派：用词预测邻居（Word2Vec 的 CBOW/Skip-gram）；③ 深度派：预训练语言模型让表示随上下文变化（ELMo → BERT）。
- **推导主线与动机**：编号（one-hot）→ 计数（BOW）→ 加权（TF-IDF）→ 分布式（词向量）→ 上下文（BERT）：每步补上"语义、泛化、歧义"的短板。
- **为什么自然得到此结论**：语言的意义 = 用法；用法 = 上下文分布；表示学习的本质就是"压缩上下文分布"。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：语料 100 篇文档，"深度学习"出现在 4 篇中，其中第 1 篇出现 3 次、共 100 词。求 TF-IDF。
- **解题思路与关键步骤**：$\text{tf}=3/100=0.03$；$\text{idf}=\log\frac{100}{1+4}=\log20\approx3.0$。
- **最终答案**：$\text{tfidf}\approx0.09$。
- **易错点**：忘记 +1 平滑（df=4 时 $\log(100/5)$ 与 $\log(100/4)$ 不同）；TF 用原始频次还是归一化频次（实现相关）。
- **🤔 追问**：若"深度学习"出现在 100 篇中的 100 篇？—— $\text{idf}=\log\frac{100}{101}\approx-0.01$（负值说明无区分度，常被截为 0）。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：为什么 one-hot 向量的余弦相似度恒为 0？—— one-hot 向量只有一个 1，两个不同词的内积为 0（正交），模长均为 1，所以余弦恒 0——模型完全无法判断"猫"和"狗"比"猫"和"汽车"更接近。这就是"语义鸿沟"问题的数学根源。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：三种表示的切换即下游任务的分水岭：
```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sentence_transformers import SentenceTransformer

docs = ["深度学习改变生活", "自然语言处理很酷", "深度学习与NLP"]
# 稀疏表示
tfidf = TfidfVectorizer().fit_transform(docs)
# 稠密语义表示（上下文表征）
model = SentenceTransformer("BAAI/bge-small-zh-v1.5")
vecs = model.encode(docs)
sim = (vecs @ vecs.T)                      # 余弦相似度矩阵
print(sim.round(2))                        # 第 0 与第 2 篇最相似
```

## 8. 常见误区和易混概念
### 误区 1：以为"TF-IDF 越高词越重要"
- **错误直觉**：IDF 大就是好词。
- **为什么错**：IDF 惩罚高频词，但任务中高频词可能恰恰重要（领域术语在领域语料中高频）；且 IDF 假设"文档间独立"，对主题聚集语料失真。
- **正确理解**：TF-IDF 是"通用显著性"近似，任务特定场景需调权或学习权重。
### 误区 2：以为"词向量就是上下文表征"
- **错误直觉**：都是稠密向量，一个东西。
- **为什么错**：静态词向量一词一向量（多义词被平均）；上下文表征一词多向量（按语境动态生成），信息量大得多，是 BERT 系模型的输出。
- **正确理解**：词向量是"词的静态画像"，上下文表征是"词在句子中的实时画像"。
### 概念对比表
| 表示 | 维度 | 语义 | 词序 | 多义词 | 典型场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| one-hot | 10 万 | 无 | 无 | ✗ | 词表索引 |
| BOW/TF-IDF | 10 万 | 弱 | 无 | ✗ | 传统分类/检索 |
| 词向量（本概念） | 100-300 | 强 | 无 | ✗ | 相似度、特征 |
| 上下文表征 | 768+ | 强 | ✓ | ✓ | 预训练微调 |

### 题目与解析
#### 1. one-hot、BOW、TF-IDF、词向量、上下文表征各解决上一级的什么问题？
> [!question]- 答案解析
> - **答案**：BOW 解决 one-hot 的文档级聚合（计数）；TF-IDF 解决 BOW 的高频词偏置（加权）；词向量解决稀疏与无语义（稠密分布式）；上下文表征解决一词多义（动态向量）。
> - **解析**：演进是"信息量"与"语义质量"的双重提升，代价是复杂度。`#自测题/基础`
#### 2. 语料 50 篇，"NLP"出现于 9 篇，文档 A 中 "NLP" 出现 6 次共 200 词。求 TF-IDF（自然对数）。
> [!question]- 答案解析
> - **答案**：$\text{tf}=6/200=0.03$；$\text{idf}=\log\frac{50}{1+9}=\log5\approx1.609$；$\text{tfidf}\approx0.0483$。
> - **解析**：IDF 的 +1 平滑防止 df=N 时除零/负值。`#自测题/基础`
#### 3. 什么场景用 TF-IDF，什么场景必须用上下文表征？
> [!question]- 答案解析
> - **答案**：TF-IDF：可解释特征、小数据传统模型、关键词提取、快速检索基线；上下文表征：语义相似度、问答、需要一词多义与句法语义的任务、数据充足的微调。
> - **解析**：成本-效果权衡：TF-IDF 免费但语义弱；上下文表征强但需预训练模型。`#自测题/中等`
#### 4. 论证"one-hot 向量无法表达任何词间相似度"。
> [!question]- 答案解析
> - **答案**：任意两个不同词的 one-hot 向量 $\mathbf{v}_i,\mathbf{v}_j$ 内积 $\mathbf{v}_i\cdot\mathbf{v}_j=0$（非零维不重合），模长都为 1，故余弦相似度恒 0——所有词对等不相似；模型无法利用"猫与狗相近"这类先验，只能靠数据硬学。
> - **解析**：这是"语义鸿沟"的数学化表述，也是分布式表示的直接动机。`#自测题/中等`
#### 5. 设计"苹果"（公司/水果）多义词的表示方案。
> [!question]- 答案解析
> - **答案**：① 上下文表征：BERT 对"苹果发布新机"与"苹果很甜"给出不同向量（动态）；② 静态方案：一词多向量（sense embedding，如多原型聚类）或"上下文词向量"（ELMo 式拼接）；③ 子词消歧：加领域限定词（"苹果公司"）。
> - **解析**：上下文表征天然解决多义词，这也是 BERT 系碾压静态向量的核心原因之一。`#自测题/较难`
