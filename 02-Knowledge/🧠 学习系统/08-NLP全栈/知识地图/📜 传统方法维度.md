# 📜 传统方法维度

> "无深度学习时代的地基"——统计与规则方法，理解现代 NLP 的必由之路。

## 🧭 维度定位

- **核心思想**：用统计建模（贝叶斯、HMM、CRF、LDA）与人工特征（TF-IDF、n-gram）处理语言，可解释、低算力。
- **主线脉络**：[[文本预处理]] → [[文本表示方法]] → [[统计机器学习]] → [[序列标注]] / [[主题模型]] / [[句法分析]]。
- **对应阶段**：第二阶段《传统NLP方法》，向上承接 [[🔢 数学基础维度]]，向下过渡到 [[词向量与Word2Vec]] 开启 [[🧠 深度学习维度]]。

## 📋 主题笔记清单

- [[文本预处理]]：分词、归一化、停用词、词干提取的流水线。
- [[文本表示方法]]：One-hot、BoW、TF-IDF、n-gram 与共现矩阵。
- [[词向量与Word2Vec]]：从稀疏离散到稠密连续的转折点（承上启下）。
- [[统计机器学习]]：朴素贝叶斯、SVM、最大熵、CRF 等传统分类器。
- [[序列标注]]：HMM、MEMM、CRF、BiLSTM-CRF 与 BIO 标注体系。
- [[主题模型]]：LSA、pLSA、LDA 的文档-主题-词生成框架。
- [[句法分析]]：CFG、PCFG、依存句法分析与评测。
- [[文本分类与情感分析]]：传统特征 + 分类器在文本任务上的应用。
