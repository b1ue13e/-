# 🚀 LLM前沿维度

> "大模型时代的新范式"——规模定律、对齐、提示与 Agent，当前 NLP 的最前沿。

## 🧭 维度定位

- **核心思想**：预训练大模型 + 对齐（让模型听话）+ 提示/工具（让模型干活）三层新范式。
- **主线脉络**：[[指令微调与对齐]] → [[提示工程]] → [[LLM推理优化]] / [[Agent与工具使用]]。
- **对应阶段**：第五阶段《大语言模型与前沿技术》，建立在 [[⚡ Transformer维度]] 的 GPT 路线之上。

## 📋 主题笔记清单

- [[指令微调与对齐]]：Instruction Tuning、SFT、RLHF、DPO 与 Constitutional AI。
- [[提示工程]]：Zero/Few-shot、CoT、ToT、Self-Consistency 等提示策略。
- [[参数高效微调PEFT]]：LoRA、Adapter、Prompt/Prefix Tuning 的低成本适配。
- [[多模态NLP]]：从 CLIP 到 LLaVA/MiniGPT-4 的视觉-语言模型。
- [[LLM推理优化]]：KV Cache、量化（GPTQ/AWQ）、投机解码与 vLLM 部署。
- [[Agent与工具使用]]：ReAct、Function Calling、AutoGen/LangGraph 多 Agent 协作。
- [[GPT系列]]：从 GPT-1 到 GPT-3 的能力跃迁与涌现背景。
