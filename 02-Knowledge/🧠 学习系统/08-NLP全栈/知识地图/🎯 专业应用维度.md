# 🎯 专业应用维度

> "让模型干活"——把通用能力落到具体任务与产品场景的维度。

## 🧭 维度定位

- **核心思想**：任务定义（输入/输出 schema）→ 模型选择 → 评测迭代；同一底座模型服务不同任务。
- **主线脉络**：[[信息抽取]] / [[问答系统]] → [[检索增强生成RAG]] / [[对话系统]] → [[多模态NLP]]。
- **对应阶段**：第六阶段《专业方向深入》，复用 [[⚡ Transformer维度]] 与 [[🚀 LLM前沿维度]] 的底座能力。

## 📋 主题笔记清单

- [[问答系统]]：抽取式/生成式问答、知识型与检索型问答。
- [[对话系统]]：任务型 NLU/NLG、开放域生成与检索混合对话。
- [[信息抽取]]：NER、关系抽取、事件抽取与 UIE 统一框架。
- [[检索增强生成RAG]]：检索 + 生成，缓解幻觉与时效性问题。
- [[文本分类与情感分析]]：分类任务全家桶与情感极性分析。
- [[文本生成]]：摘要、机器翻译、条件生成与解码控制。
- [[多模态NLP]]：图文联合理解（CLIP/LLaVA）与跨模态生成。
