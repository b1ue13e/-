# 循环神经网络RNN

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：RNN 是 CS224N HW03（依存分析）与 HW04（NMT）的骨架模型；"梯度消失/爆炸"与 BPTT 是所有序列模型面试的必问题；LSTM/GRU 的门控思想直接延续到 Transformer 的残差设计中。不深挖 RNN，HW03/04 无法完成，也无法理解 Transformer 为什么取代它。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 前面的模型（词向量平均、BoW、MLP）都把句子当成"词的集合"，**丢掉顺序**——"猫追狗"和"狗追猫"特征完全相同。但 NLP 任务（词性标注、翻译、情感分析中的否定转移）强烈依赖词序。
> 我们需要一个能**按顺序读取输入、并记住已读内容**的模型。前馈网络没有记忆，无法处理变长序列；把窗口滑过句子（n-gram）只能看到局部。因此引入循环神经网络：在每一步把"当前输入"与"上一步的隐藏状态"一起处理，形成沿时间展开的链式结构——这就是"循环"的含义。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：RNN 是深度学习时代第一个主流序列模型：HW03 的依存分析 parser（CS224N 官方 Assignment 3 为 MLP-based arc-standard，本体系扩展版可用 BiLSTM 编码）与 HW04 用 LSTM 编码器-解码器做机器翻译；它引出的"隐藏状态 + 门控"概念是理解 [[Seq2Seq与注意力机制]] 与 [[Transformer架构]] 的必要阶梯。
- **实际应用场景**：机器翻译、语音识别、时间序列预测、文本生成（GPT 之前的 LSTM 语言模型）、命名实体识别。
- **高频题型/任务**：手推 BPTT 梯度；解释梯度消失/爆炸及三种缓解手段（门控、梯度裁剪、正交初始化）；比较 RNN/LSTM/GRU/BiLSTM；HW03 的 parser 代码中 LSTM 是标配组件（官方 MLP parser 中亦常用 LSTM 特征）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[词向量与Word2Vec]]**：RNN 每一步输入是词向量 $x_t$，输出是隐藏状态 $h_t$。
2. **反向传播与链式法则**：BPTT 就是沿时间展开的反向传播；需要熟练矩阵微分与"梯度是误差信号乘以路径上所有雅可比矩阵"的直觉。
3. **Softmax 与交叉熵**：每个时间步的输出层用 softmax 产生词表上的分布（语言模型/序列标注）。

---

## 4. 用直觉语言解释它

> «"RNN 就像一个边读边记的读者：每读一个词，就把这个词的意思和脑子里已有的印象（隐藏状态）融合，形成新的印象；这个新印象既包含当前词，又携带前面所有词的浓缩记忆。读者读完整个句子后，脑子里的最终印象就是对整句话的理解。缺点也像人：读太长的句子会忘掉开头——这就是梯度消失。"»

- **直觉类比/几何图像**：隐藏状态 $h_t$ 是一个"滚动摘要"，$h_t = f(h_{t-1}, x_t)$ 相当于"新摘要 = 融合(旧摘要, 新词)"。沿时间展开后，RNN 就是一个非常深的"共享权重"的前馈网络，深度 = 序列长度。
- **为什么很自然**：语言是顺序产生的，人类理解也是逐词累积的；"共享参数"让模型可以用同一套规则处理任意长度序列（参数数量不随序列长度增长）。
- **一句话直觉本质**：**用共享权重的循环单元把变长序列压缩为固定维度的隐藏状态序列，实现"顺序读取 + 记忆累积"。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
**RNN（Elman 网络）**：给定输入序列 $x_1,\dots,x_T$，通过共享参数 $W_h, W_x, b$ 递推计算隐藏状态 $h_t$，最后用 $h_T$（或 $h_1,\dots,h_T$）做预测：
$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$

**双向 RNN（BiRNN）**：正向 $h_t^{\rightarrow}$ 与反向 $h_t^{\leftarrow}$ 拼接，$h_t = [h_t^{\rightarrow}; h_t^{\leftarrow}]$，让每个位置同时看到左右上下文（HW03 扩展版的标准做法，官方 Assignment 3 的 MLP parser 也以 BiLSTM 特征为输入）。

### 2. 核心公式
**逐时间步输出**（如词性标注）：
$$\hat{y}_t = \text{softmax}(W_s h_t + b_s)$$

**BPTT 梯度**（对 $W_h$，沿时间反向累积）：
$$\frac{\partial J}{\partial W_h} = \sum_{t=1}^{T} \frac{\partial J_t}{\partial h_t} \frac{\partial h_t}{\partial h_{t-1}} \cdots \frac{\partial h_2}{\partial h_1} \frac{\partial h_1}{\partial W_h} = \sum_{t=1}^{T} \delta_t \prod_{k=2}^{t} \text{diag}(\tanh'(h_{k-1})) W_h$$

**梯度消失/爆炸判据**：若 $W_h$ 的最大奇异值 $\sigma_{\max} < 1$，$\prod W_h \to 0$（消失）；若 $\sigma_{\max} > 1$，$\prod W_h$ 指数爆炸。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $x_t$ | 第 $t$ 步输入词向量 | $\mathbb{R}^{d_x}$ | 如 GloVe 300d |
| $h_t$ | 第 $t$ 步隐藏状态 | $\mathbb{R}^{d_h}$ | "滚动摘要" |
| $h_0$ | 初始隐藏状态 | $\mathbb{R}^{d_h}$ | 通常为 0 向量 |
| $W_h$ | 隐藏到隐藏权重 | $\mathbb{R}^{d_h\times d_h}$ | 共享、跨步复用 |
| $W_x$ | 输入到隐藏权重 | $\mathbb{R}^{d_h\times d_x}$ | 共享 |
| $T$ | 序列长度 | 整数 | 展开深度 = $T$ |
| $\delta_t$ | 第 $t$ 步输出误差信号 | $\mathbb{R}^{d_h}$ | BPTT 起点 |

### 4. 常见变体与适用条件
- **LSTM**：加入输入门/遗忘门/输出门与细胞状态，让梯度有一条"高速公路"（细胞状态上的加法），缓解梯度消失（见 [[03-深度学习NLP基础/细胞状态|细胞状态]]、[[03-深度学习NLP基础/遗忘门|遗忘门]]）。
- **GRU**：LSTM 的简化（两个门：更新门、重置门），参数更少、训练更快，效果接近（见 [[03-深度学习NLP基础/GRU结构|GRU结构]]、[[03-深度学习NLP基础/GRU vs LSTM|GRU vs LSTM]]）。
- **BiLSTM**：双向拼接，序列标注/依存分析标配。
- **深层 RNN**：堆叠多层（每层一个 RNN），见 [[03-深度学习NLP基础/深层RNN|深层RNN]]。
- **适用条件**：序列不太长（< 数百步）且无并行需求；**限制**：无法并行（顺序依赖）、长距离依赖弱——这两点正是 Transformer 的突破口。

## 6. 推导思路和思想来源

- **最初困难**：前馈网络无法处理变长顺序输入；固定窗口丢失长距离信息。
- **直接方法局限**：n-gram 窗口越大参数越多且仍有边界；把整句拼成定长向量（词袋）丢顺序。
- **关键"转念"**：把"记忆"建模为**显式的状态变量**，用"状态更新方程"代替"输入-输出映射"：$h_t = f(h_{t-1}, x_t)$。参数共享使模型与序列长度解耦。
- **推导主线与动机**：① 定义状态递推；② 展开成 $T$ 层深网；③ 反向传播沿时间链累积（BPTT）；④ 发现连乘 $\prod \text{diag}(\tanh')W_h$ 要么坍缩要么爆炸——由此引出门控（LSTM/GRU）与梯度裁剪。
- **为什么自然得到此结论**：梯度消失的本质是"非线性压缩 + 权重连乘"：$\tanh' \le 1$ 且 $W_h$ 反复相乘。LSTM 的细胞状态用**加法**（$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$）替代连乘，梯度沿 $f_t$ 直通，是"把乘法链改成加法链"的巧妙一转。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：$d_h = d_x = 1$（标量）。设 $W_h = 0.9$，$W_x = 0.5$，$b = 0$，$h_0 = 0$，输入 $x_1 = 1$，$x_2 = 1$（用 $\tanh$）。计算 $h_1, h_2$。
- **解题思路与关键步骤**：$h_1 = \tanh(0.9\cdot 0 + 0.5\cdot 1) = \tanh(0.5) \approx 0.4621$；$h_2 = \tanh(0.9\cdot 0.4621 + 0.5\cdot 1) = \tanh(0.4159 + 0.5) = \tanh(0.9159) \approx 0.7234$。
- **最终答案**：$h_1 \approx 0.462$，$h_2 \approx 0.723$。
- **易错点**：忘记先算 $W_h h_{t-1}$ 再加 $W_x x_t$；$\tanh$ 取值在 $(-1,1)$，不可能超过 1——若算出 $>1$ 说明公式用错。
- **🤔 追问**：若 $W_h = 1.1$（$>1$），重复 100 步，$h_t$ 会怎样？—— $\tanh$ 本身有界，但梯度 $\prod W_h$ 会爆炸；隐藏状态饱和在 ±1 附近（梯度消失的另一面）。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：解释为什么"梯度消失"不等于"隐藏状态没记住"，并判断一个 $T=50$ 的 RNN 语言模型在哪类词上最易出错。
- **解题思路与完整解答**：隐藏状态 $h_t$ 仍受早期输入影响（前向传播正常），但**梯度**无法传回早期时间步，导致模型"无法学习"早期输入的贡献——即"能记住但不更新"。对 $T=50$ 的句子，模型能学好局部 n-gram 模式，但对"句首否定词 not 影响句尾情感"这类长距离依赖学不动。缓解：LSTM/GRU、梯度裁剪（防爆炸）、残差/直连、注意力（彻底绕开 RNN）。
- **易错点**：把"梯度消失"误说成"信息丢失"——两者相关但不同：前向信息仍流动，反向学习信号断了。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW03 的依存 parser（官方为 MLP-based arc-standard，本体系扩展版用 BiLSTM 编码整句后做转移决策）与 HW04 的 NMT 用 LSTM 编码器把源句压成最后一个隐藏状态（瓶颈），再用注意力缓解。代码形态（PyTorch）：
```python
import torch, torch.nn as nn

class SimpleRNN(nn.Module):
    def __init__(self, vocab, d_emb=100, d_hid=128, n_layers=2, bidirectional=True):
        super().__init__()
        self.emb = nn.Embedding(vocab, d_emb)
        self.rnn = nn.LSTM(d_emb, d_hid, n_layers, bidirectional=bidirectional,
                           batch_first=True)   # 实战用 LSTM 而非裸 RNN
        self.dropout = nn.Dropout(0.3)

    def forward(self, tokens):
        x = self.emb(tokens)                       # (B, T, d_emb)
        out, (h, c) = self.rnn(x)                  # out: (B, T, 2*d_hid)
        return self.dropout(out)                   # 每位置表示，供分类/标注头使用

    def clip(self, max_norm=5.0):
        torch.nn.utils.clip_grad_norm_(self.parameters(), max_norm)  # 防梯度爆炸
```

## 8. 常见误区和易混概念

### 误区 1：以为"RNN 的梯度消失只发生在长序列"
- **错误直觉**：序列短就不会有梯度问题。
- **为什么错**：梯度消失取决于 $\sigma_{\max}(W_h)$ 与非线性，短序列只是连乘项少；即使 $T=20$，若 $\sigma_{\max}=0.5$，$0.5^{20}\approx 10^{-6}$，早期梯度已消失。
- **正确理解**：消失/爆炸是"权重谱 + 深度"共同决定；门控与裁剪是通用手段。

### 误区 2：以为"LSTM 完全解决梯度消失"
- **错误直觉**：LSTM 有门控就万事大吉。
- **为什么错**：LSTM 的细胞状态直连缓解了"细胞状态路径"的消失，但遗忘门 $f_t<1$ 时仍会衰减，且**输入/输出路径仍有连乘**；长距离依赖（如 1000 步）依然困难——这是 Transformer/注意力登场的原因。
- **正确理解**：LSTM 把"可学习的衰减率"交给网络，显著改善但非根治。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 裸 RNN（本概念） | 顺序记忆 | 单一 $\tanh$ 单元、梯度易消失 | 教学、HW03 理解 |
| LSTM | 长程记忆 | 细胞状态 + 三门控 | NMT、标注（见 [[03-深度学习NLP基础/GRU vs LSTM|GRU vs LSTM]]） |
| GRU | 简化门控 | 两门、参数少 | 中小数据集 |
| Transformer | 全局并行 | 无循环、注意力直连 | 现代 LLM 全部（见 [[Transformer架构]]） |

### 题目与解析

#### 1. 为什么说"RNN 展开后是一个共享权重的深网"？
> [!question]- 答案解析
> - **答案**：把 $h_t = f(h_{t-1}, x_t)$ 沿时间展开，得到 $T$ 层链式结构，每层都是同一组参数 $W_h, W_x, b$，层数 = 序列长度 $T$。
> - **解析**：参数共享是 RNN 的核心设计：模型复杂度与序列长度解耦，可处理任意长度输入。代价是梯度沿 $T$ 层连乘（BPTT）。
> - **易错原因**：以为每步参数不同，或以为展开深度固定。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. $W_h=0.5$，$W_x=1$，$b=0$，$h_0=0$，$x_1=x_2=1$，求 $h_2$。
> [!question]- 答案解析
> - **答案**：$h_1 = \tanh(0.5\cdot 0 + 1) = \tanh(1) \approx 0.7616$；$h_2 = \tanh(0.5\times 0.7616 + 1) = \tanh(1.3808) \approx 0.8817$。
> - **解析**：注意顺序：先 $W_h h_{t-1}$ 再 $+W_x x_t$；$\tanh(1)\approx0.7616$，$\tanh(1.3808)\approx0.8817$。
> - **易错原因**：把 $x_t$ 乘到 $W_h$ 上，或 $\tanh$ 查值错误。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 如何判断一个 RNN 会发生梯度消失还是爆炸？分别怎么处理？
> [!question]- 答案解析
> - **答案**：看 $W_h$ 的最大奇异值 $\sigma_{\max}$：$\sigma_{\max}<1$ 倾向于消失，$\sigma_{\max}>1$ 倾向于爆炸（同时受 $\tanh'$ 影响）。爆炸用梯度裁剪（clip grad norm）；消失用门控（LSTM/GRU）、更好的初始化（正交）、残差连接或注意力。
> - **解析**：BPTT 的连乘 $\prod \text{diag}(\tanh') W_h$ 中，谱范数决定长期行为。梯度裁剪只解决爆炸（数值问题），门控才解决消失（学习问题）。
> - **易错原因**：用梯度裁剪治消失——治标不治本。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 列举三种缓解梯度消失的手段并说明原理。
> [!question]- 答案解析
> - **答案**：① LSTM/GRU 门控：细胞状态用加法递推，提供梯度直通路径；② 正交初始化/合理初始化：让 $W_h$ 谱范数接近 1，减缓连乘衰减；③ 残差连接/跳连：把梯度路径缩短；此外可用注意力完全绕开循环链。
> - **解析**：核心思路都是"打断/缩短梯度连乘链"。LSTM 的 $c_t = f_t\odot c_{t-1} + i_t\odot\tilde{c}_t$ 中，若遗忘门 $f_t\approx1$，梯度可无损流过。
> - **易错原因**：把 dropout 当缓解手段——dropout 是正则化，不解决消失。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 推导 BPTT 中 $J$ 对 $h_1$ 的梯度表达式，说明连乘结构，并解释 LSTM 如何缓解。
> [!question]- 答案解析
> - **答案**：$\frac{\partial J}{\partial h_1} = \sum_{t=1}^{T} \frac{\partial J_t}{\partial h_t}\prod_{k=2}^{t}\frac{\partial h_k}{\partial h_{k-1}}$，其中 $\frac{\partial h_k}{\partial h_{k-1}} = \text{diag}(1-\tanh^2(h_{k-1})) W_h$。连乘项范数 $\le (\sigma_{\max}(W_h))^{t-1}$（因 $\tanh'\le1$），故 $t$ 大时指数衰减或爆炸。
> - **解析**：LSTM 中细胞状态 $c_t = f_t\odot c_{t-1} + i_t\odot\tilde{c}_t$，对 $c_{t-1}$ 的偏导是 $\text{diag}(f_t)$（无 $W_h$ 连乘、无 $\tanh'$ 压缩），只要 $f_t$ 接近 1 梯度就能直通——把"乘法连乘"换成"可调衰减加法"。
> - **易错原因**：写 BPTT 时漏掉 $\tanh'$ 因子，或误以为 LSTM 中门是常数。
> - **Obsidian 标签建议**：`#自测题/较难`
