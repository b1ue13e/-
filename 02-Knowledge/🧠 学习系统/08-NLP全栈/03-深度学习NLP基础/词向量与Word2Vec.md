# 词向量与Word2Vec

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：词向量是 CS224N HW01 的全部内容，也是 NLP 从"符号离散"走向"稠密连续"的分水岭。后续 RNN、Transformer、BERT 的输入层全部是词向量；不懂 Word2Vec 的损失函数与梯度推导，HW01 无法通过，HW02-05 的输入表征也无从谈起。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 传统 NLP 用 one-hot 表示词：每个词是一个 $|V|$ 维向量，只有一个位置为 1。这带来三个致命问题：①维度灾难——词汇表 $|V|$ 通常有数万到数十万，向量稀疏且巨大；②语义空白——"猫"与"狗"的 one-hot 内积为 0，机器完全看不出它们都是动物；③无法类比——"king - man + woman ≈ queen" 这种代数运算在 one-hot 空间毫无意义。
> 因此必须引入**分布式表示（distributed representation）**：把每个词映射到低维稠密向量（如 100-300 维），让语义相近的词在向量空间中距离相近。Word2Vec（Mikolov et al., 2013）就是用神经网络从无标注语料中自动学习这种向量的方法。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：词向量是所有深度 NLP 模型的"输入层"。HW01 手写其梯度；HW02 用词向量平均做分类特征；HW03-05 的 RNN/Transformer 都吃词向量。它还直接引出 GloVe（全局统计视角）与后来的上下文词向量（BERT）。
- **实际应用场景**：搜索引擎查询扩展、推荐系统物品嵌入（word2vec 思路迁移到 item2vec）、机器翻译的词对齐初始化、医学/法律领域的专业词嵌入训练。
- **高频题型/任务**：HW01 要求推导并实现 sigmoid、softmax、负采样损失对中心词/上下文词向量的梯度；面试常问"CBOW 与 Skip-gram 区别""负采样为什么有效""为什么用两个矩阵（中心词 + 上下文词）"。

---

## 3. 学它之前需要哪些前置知识？

1. **[[01-基础准备/交叉熵|交叉熵]]与 Softmax**：softmax 把得分变成概率分布，交叉熵是分类损失。Word2Vec 的目标就是"最大化正确上下文词的概率"，等价于最小化交叉熵。
2. **梯度下降与链式法则**：HW01 的核心是手推 $\partial J / \partial v_c$、$\partial J / \partial u_w$ 并对每个参数做数值梯度校验（gradient check）。
3. **[[文本预处理]]**：分词、大小写归一化、低频词裁剪（min-count）决定词表 $V$ 的大小。

## 4. 用直觉语言解释它

> «"词向量学习"就像让一个孩子从大量句子里猜词：给他一个词的上下文（周围的词），让他猜中间是什么词（CBOW）；或者给他一个词，让他猜周围会出现什么词（Skip-gram）。猜错了就微调"这个词长什么样"和"那些词长什么样"的两本词典，猜得越准，两本词典里的向量就越能反映真实的共现规律——最后"长得像"的向量就是语义相近的词。"»

- **直觉类比/几何图像**：每个词是 $d$ 维空间里的一个点；训练过程把"常一起出现的词"的点拉近，把"从不一起出现的词"的点推远。最终空间中"方向"也承载语义：$\vec{king} - \vec{man} + \vec{woman} \approx \vec{queen}$。
- **为什么很自然**：语言学的分布假说（distributional hypothesis）说"You shall know a word by the company it keeps"（Firth, 1957）——词的语义由它出现的上下文决定。Word2Vec 只是把这句话变成了一个可微分的优化目标。
- **一句话直觉本质**：**用"预测上下文"这个伪装成语言模型的任务，逼出每个词的低维稠密向量，让共现规律沉淀为几何结构。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
**Word2Vec**：给定语料中每个词 $w$，学习两个稠密向量：中心词向量 $v_w \in \mathbb{R}^d$ 与上下文词向量 $u_w \in \mathbb{R}^d$。目标是最大化整个语料中"上下文词出现在中心词周围"的对数似然。训练完成后通常取 $v_w$（或 $v_w + u_w$）作为词的最终表示。

### 2. 核心公式
**Skip-gram 目标**（给定中心词 $c$，预测窗口内上下文词 $o$）：
$$J(\theta) = -\frac{1}{T}\sum_{t=1}^{T}\sum_{-m \le j \le m,\, j\ne 0} \log P(w_{t+j} \mid w_t)$$

其中条件概率用 softmax：
$$P(o \mid c) = \frac{\exp(u_o^\top v_c)}{\sum_{w \in V} \exp(u_w^\top v_c)}$$

**负采样损失**（用 $K$ 个负样本近似分母）：
$$J_{\text{neg}}(o, c) = -\log\sigma(u_o^\top v_c) - \sum_{k=1}^{K} \log\sigma(-u_{\tilde{w}_k}^\top v_c)$$

其中 $\sigma(x) = 1/(1+e^{-x})$，负样本按噪声分布 $P(w) \propto U(w)^{3/4}$ 采样（$U(w)$ 为词频）。

**CBOW 目标**（用上下文词向量平均预测中心词）：
$$P(w_t \mid w_{t-m\ldots t+m}) = \frac{\exp(v_{w_t}^\top \hat{v})}{\sum_{w\in V}\exp(v_w^\top \hat{v})},\qquad \hat{v} = \frac{1}{2m}\sum_{-m\le j\le m,\,j\ne 0} v_{w_{t+j}}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $v_c$ | 中心词 $c$ 的向量 | $\mathbb{R}^d$（$d$≈100-300） | 训练后作为词表示 |
| $u_w$ | 词 $w$ 作上下文时的向量 | $\mathbb{R}^d$ | 与 $v$ 分开训练 |
| $m$ | 上下文窗口半宽 | 整数，通常 5-10 | 窗口越大语义越"主题化" |
| $T$ | 语料总词数 | — | 损失按词数平均 |
| $K$ | 负样本数 | 5-20（小语料） | 越大越接近 softmax |
| $\sigma$ | sigmoid 函数 | $(0,1)$ | 二分类概率 |

### 4. 常见变体与适用条件
- **Skip-gram vs CBOW**：Skip-gram 对每个词对单独建模，对低频词更友好，训练慢；CBOW 把整个窗口平均成一点，训练快但低频词质量差。小语料用 Skip-gram，大语料用 CBOW。
- **层次 softmax（Hierarchical Softmax）**：用 Huffman 树把 softmax 分母从 $O(|V|)$ 降到 $O(\log |V|)$，适合词表极大的情况（见 [[03-深度学习NLP基础/层次Softmax|层次Softmax]]）。
- **限制条件**：Word2Vec 是**静态**词向量——同一个词在所有语境下只有一个向量，无法处理一词多义（如 "bank" 银行/河岸）；这个问题由 BERT 等上下文表示解决。

## 6. 推导思路和思想来源

- **最初困难**：one-hot 向量无法表达语义相似度，且维度过高；早期 LSA/SVD 虽能降维但不可扩展到大语料。
- **直接方法局限**：对整个共现矩阵做 SVD 需要 $O(|V|^2)$ 内存，$|V|=10^5$ 时就是 $10^{10}$ 个元素，不可行。
- **关键"转念"**：不显式构造共现矩阵，而是**把"预测共现"变成分类任务**——用中心词预测上下文词，把共现统计隐式地编码进神经网络参数。这就是"预测式"（predictive）对"计数式"（count-based）的范式切换。
- **推导主线与动机**：① 定义对数似然目标；② 用 softmax 建模 $P(o|c)$；③ 对 $v_c$ 和 $u_o$ 求梯度（$\partial J/\partial v_c = \sum_w (P(w|c) - \mathbb{1}[w=o]) u_w$，即"预测概率 - 真实指示"的残差加权）；④ 因分母求和太贵，用负采样近似；⑤ 用 SGD 更新。
- **为什么自然得到此结论**：softmax 梯度的"残差形式"（预测概率减真实标签）是所有分类模型的统一形态；负采样则是"把 10 万类的 softmax 换成 20 个二分类"的工程直觉，数学上等价于优化一个二分类目标。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：词表 $V = \{$I, love, NLP$\}$，$d=2$。设 $v_{\text{NLP}} = (1, 0)$，$u_{\text{love}} = (0, 1)$，$u_{\text{I}} = (1, 1)$。计算 Skip-gram 中 $P(\text{love} \mid \text{NLP})$。
- **解题思路与关键步骤**：先算得分 $u_o^\top v_c$：$u_{\text{love}}^\top v_{\text{NLP}} = 0\cdot1 + 1\cdot0 = 0$；$u_{\text{I}}^\top v_{\text{NLP}} = 1$。再算 softmax：分母 $e^0 + e^1 = 1 + e$。
- **最终答案**：$P(\text{love} \mid \text{NLP}) = \frac{e^0}{e^0 + e^1} = \frac{1}{1+e} \approx 0.269$。
- **易错点**：忘记 softmax 要对**全部词表**归一化，只对两个候选归一化会得到 $\frac{1}{2}$ 的错误答案。
- **🤔 追问**：如果引入负采样，$K=1$ 且负样本是 "I"，$\sigma$ 值怎么算？—— $\sigma(u_{\text{love}}^\top v_{\text{NLP}}) = \sigma(0) = 0.5$，$\sigma(-u_{\text{I}}^\top v_{\text{NLP}}) = \sigma(-1) \approx 0.269$，损失 $= -\log 0.5 - \log 0.269 \approx 2.01$。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：推导 softmax 损失 $J = -\log P(o|c)$ 对 $v_c$ 的梯度，并解释为什么等于"残差"。
- **解题思路与完整解答**：$J = -u_o^\top v_c + \log\sum_w e^{u_w^\top v_c}$。对 $v_c$ 求导：第一项得 $-u_o$；第二项是 $\log$-sum-exp 的导数，$\frac{\partial}{\partial v_c}\log\sum_w e^{u_w^\top v_c} = \sum_w \frac{e^{u_w^\top v_c}}{\sum_{w'}e^{u_{w'}^\top v_c}} u_w = \sum_w P(w|c) u_w$。合并得 $\frac{\partial J}{\partial v_c} = \sum_w \big(P(w|c) - \mathbb{1}[w=o]\big) u_w$——即"模型认为的概率"减去"真实标签"的残差，把所有上下文向量按残差加权求和。这正是 HW01 手推的核心结果。
- **易错点**：把 $\log$-sum-exp 的导数误写成 $1/\sum_w e^{u_w^\top v_c}$，漏掉每项乘 $u_w$。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW01 要求用 NumPy 实现 naive 版（完整 softmax）与负采样版 Skip-gram，并用梯度检查（$\frac{J(\theta+\epsilon)-J(\theta-\epsilon)}{2\epsilon} \approx \frac{\partial J}{\partial\theta}$，$\epsilon=1e^{-4}$）验证手推梯度。之后做词类比评测：$v_{queen} \approx v_{king} - v_{man} + v_{woman}$ 的余弦相似度最高者是否命中。
- 核心代码形态：
```python
def softmax(x):
    e = np.exp(x - np.max(x))          # 数值稳定
    return e / np.sum(e)

def naive_softmax_loss_and_gradient(center_vec, outside_vecs, outside_idx):
    probs = softmax(outside_vecs @ center_vec)      # (V,)
    # 损失：负对数似然
    loss = -np.log(probs[outside_idx])
    # 梯度：残差 (probs - onehot) 加权求和
    delta = probs.copy(); delta[outside_idx] -= 1.0
    grad_center = outside_vecs.T @ delta
    grad_outside = np.outer(delta, center_vec)
    return loss, grad_center, grad_outside
```

## 8. 常见误区和易混概念

### 误区 1：以为"词向量直接来自共现矩阵"
- **错误直觉**：Word2Vec 就是共现矩阵（PPMI）做 SVD 的另一种叫法。
- **为什么错**：Word2Vec 是预测式方法，通过神经网络梯度下降学习；共现矩阵 SVD 是计数式方法。两者目标不同（局部窗口预测 vs 全局统计重建），但得到的向量性质相似（GloVe 试图融合两者）。
- **正确理解**：区分"预测式"（Word2Vec）与"计数式"（LSA/SVD、GloVe 混合式）。

### 误区 2：以为"训练好的 $u$ 和 $v$ 是两个不同模型，取哪个都行"
- **错误直觉**：$v$ 和 $u$ 是两套独立的词向量，随便取一套用。
- **为什么错**：$v$（中心词向量）是在"预测别人"的角色中学到的，$u$（上下文向量）是在"被预测"角色中学到的；单独取 $u$ 通常效果略差，惯例取 $v$，也有工作取 $v+u$。
- **正确理解**：两者是同一目标的两种角色参数，最终表示选 $v$（或加和）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| Word2Vec（本概念） | 预测式词嵌入 | 用上下文预测任务学向量 | HW01、下游任务输入层 |
| GloVe | 混合式词嵌入 | 直接拟合共现矩阵的对数 | 静态词向量基准 |
| one-hot | 符号表示 | 无语义、稀疏 | 词袋模型输入 |
| BERT 词表示 | 上下文相关表示 | 同一词多义、随语境变化 | 预训练微调 |

### 题目与解析

#### 1. CBOW 与 Skip-gram 的核心区别是什么？
> [!question]- 答案解析
> - **答案**：CBOW 用上下文词向量的平均预测中心词；Skip-gram 用中心词分别预测每个上下文词。
> - **解析**：CBOW 每窗口只更新一次（平均向量），训练快但对低频词不利；Skip-gram 每对词单独建模，低频词质量更好。小语料/罕见词优先 Skip-gram。
> - **易错原因**：把方向记反——CBOW 是"上下文 → 中心词"。
> - **对应误区**：无，属基础概念辨析。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 词表 {A, B}，$v_A=(1,0)$，$u_A=(0,1)$，$u_B=(1,1)$，求 $P(A|A)$。
> [!question]- 答案解析
> - **答案**：$P(A|A) = \frac{e^{u_A^\top v_A}}{e^{u_A^\top v_A}+e^{u_B^\top v_A}} = \frac{e^0}{e^0+e^1} = \frac{1}{1+e}\approx 0.269$。
> - **解析**：$u_A^\top v_A = 0$，$u_B^\top v_A = 1$；softmax 必须对全词表归一化。
> - **易错原因**：只对分子分母取两个候选词而不是全词表，或算错点积。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 什么时候必须用负采样或层次 softmax 而不是完整 softmax？
> [!question]- 答案解析
> - **答案**：当词表 $|V|$ 很大（$>10^5$）且训练语料大时；完整 softmax 每步要算 $O(|V|)$ 次指数与求和，代价不可接受。
> - **解析**：负采样把 $O(|V|)$ 降到 $O(K)$（$K$≈5-20）；层次 softmax 用 Huffman 树降到 $O(\log|V|)$。小词表（如 toy 语料）直接用完整 softmax 更准。
> - **易错原因**：以为负采样改变了解释——它只是近似分母，不改变"预测共现"的本质。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 推导 $\frac{\partial}{\partial v_c}\big(-\log P(o|c)\big)$ 并化简。
> [!question]- 答案解析
> - **答案**：$\frac{\partial J}{\partial v_c} = \sum_{w\in V}\big(P(w|c) - \mathbb{1}[w=o]\big)\, u_w$。
> - **解析**：$J = -u_o^\top v_c + \log\sum_w e^{u_w^\top v_c}$；对第一项求导得 $-u_o$，对 log-sum-exp 求导得 $\sum_w P(w|c)u_w$；合并即"预测概率 − 真实指示"的残差加权和。HW01 的代码与数值梯度校验都依赖此式。
> - **易错原因**：把 $\log\sum_w e^{u_w^\top v_c}$ 的导数误写成标量，忘记每项乘 $u_w$。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 负采样分布 $P(w)\propto U(w)^{3/4}$ 有什么作用？为什么不是 $U(w)$ 本身？
> [!question]- 答案解析
> - **答案**：$3/4$ 次幂"压缩"词频差异：高频词（如 the/of）被降权，中低频词被升权，使负样本分布更均匀、更有区分度。
> - **解析**：直接用词频 $U(w)$ 采样会让极高频功能词霸占负样本，学到"它们与一切词都负相关"的无意义信号；$3/4$ 幂是经验上对"频率-信息量"折中（Mikolov et al., 2013 实验确定）。
> - **易错原因**：把负采样分布与训练语料分布混为一谈。
> - **Obsidian 标签建议**：`#自测题/较难`
