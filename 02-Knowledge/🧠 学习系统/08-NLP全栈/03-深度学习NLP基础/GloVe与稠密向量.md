# GloVe与稠密向量

---

## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具）**
- **判断理由**：GloVe 是 CS224N 讲义重点讲解的静态词向量方法（HW01 的概念对照），是"计数式"路线的集大成者，面试高频。但日常建模中已被 BERT 类上下文向量取代，故归 B 类：学懂思想、会对比、能复现，不必深挖到每个实现细节。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> Word2Vec 是"预测式"方法——它只利用局部窗口内的共现信息，窗口外的全局统计（如"这两个词在全语料中一共共现了多少次"）被丢弃。而纯计数式方法（LSA/PPMI + SVD）虽然利用了全局统计，却有两个缺陷：①对高频词过度加权（"the"与一切词共现，主导分解结果）；②SVD 分解的是高维稀疏矩阵，计算昂贵且分解结果难以解释。
> 因此需要一种方法，**既利用全局共现统计，又像 Word2Vec 一样高效可扩展**。GloVe（Global Vectors，Pennington et al., 2014）正是这样：它把"共现次数的对数"直接作为回归目标，用加权最小二乘拟合。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：GloVe 填上"计数式 vs 预测式"对照表的最后一格，是理解词向量发展史的关键一环；其"共现矩阵 + 加权损失"的思想后来被很多模型借鉴（如 BERT 的共现目标仍是核心）。
- **实际应用场景**：静态词向量基准（semeval 词相似度任务上 GloVe 长期优于 Word2Vec）；初始化 RNN/CNN 嵌入层；语义搜索的向量底座（与 [[检索增强生成RAG]] 的向量库配合）。
- **高频题型/任务**：HW01 报告题"比较 Word2Vec 与 GloVe 的异同"；面试问"GloVe 的损失函数为什么带权重函数 $f(X_{ij})$""GloVe 向量为什么能直接做加减类比"。

---

## 3. 学它之前需要哪些前置知识？

1. **[[词向量与Word2Vec]]**：理解分布式表示的目标与 softmax/负采样训练方式，才能对比 GloVe 的差异。
2. **共现矩阵**：$X$ 中 $X_{ij}$ 表示词 $j$ 出现在词 $i$ 上下文窗口内的次数；这是 GloVe 的唯一输入。
3. **加权最小二乘**：给每个样本不同的权重，GloVe 用 $f(X_{ij})$ 控制高频/低频词的贡献。

---

## 4. 用直觉语言解释它

> «"GloVe 就像给每对词记账：先统计全语料里每对词一起出现的次数（共现矩阵），然后让两个词的向量点积去'复刻'这个次数的对数——账记得越准，向量越好。但高频词（the）的账太多了，会淹没其他词，所以给每笔账一个递减的权重，让中等频率的词（语义更具体）拥有最大话语权。"»

- **直觉类比/几何图像**：把 $v_i^\top v_j$ 想成"词 $i$ 和词 $j$ 的相似度得分"，目标就是让这个得分等于 $\log X_{ij}$（共现对数）。词向量空间里方向承载语义，所以向量差能表达类比关系。
- **为什么很自然**：共现对数 $\log X_{ij}$ 是信息论里点互信息（PMI）的近亲；让向量点积拟合它，等于把"统计相关性"嵌入几何内积——这是矩阵分解（SVD）思想在词嵌入上的直接应用。
- **一句话直觉本质**：**把"全语料共现统计"作为监督信号，用加权最小二乘让词向量点积逼近共现对数，从而融合计数式与预测式的优点。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
**GloVe**：设 $X$ 为共现矩阵，$X_{ij}$ 为词 $j$ 出现在词 $i$ 上下文中的次数。学习中心词向量 $w_i$ 与上下文向量 $\tilde{w}_j$，使得 $w_i^\top \tilde{w}_j + b_i + \tilde{b}_j \approx \log X_{ij}$，其中 $b_i, \tilde{b}_j$ 为偏置。

### 2. 核心公式
**加权最小二乘损失**：
$$J = \sum_{i,j=1}^{|V|} f(X_{ij}) \left( w_i^\top \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij} \right)^2$$

**权重函数**（截断递增，避免高频词主导）：
$$f(x) = \begin{cases} (x/x_{\max})^{\alpha} & x < x_{\max} \\ 1 & x \ge x_{\max} \end{cases}$$
常用 $\alpha = 3/4$，$x_{\max} = 100$。

**类比性质的来源**：$w_i^\top \tilde{w}_j \approx \log X_{ij} - b_i - \tilde{b}_j$，而 $\log X_{ik} - \log X_{jk}$ 是"词 $i$ 与词 $k$ 的共现相对词 $j$ 与词 $k$ 的比值"，比值编码了语义关系（如 "ice" 与 "steam" 例子），因此向量差 $\vec{king}-\vec{man}\approx\vec{queen}-\vec{woman}$ 成立。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $X_{ij}$ | 词 $j$ 在词 $i$ 窗口内共现次数 | 非负整数 | 全语料统计一次 |
| $w_i$ | 词 $i$ 的中心向量 | $\mathbb{R}^d$ | 训练后作为表示 |
| $\tilde{w}_j$ | 词 $j$ 的上下文向量 | $\mathbb{R}^d$ | 与 $w$ 对称 |
| $b_i, \tilde{b}_j$ | 词偏置 | $\mathbb{R}$ | 吸收词频影响 |
| $f(x)$ | 权重函数 | $[0,1]$ | 抑制高频词 |
| $\alpha, x_{\max}$ | 超参数 | $3/4$，$100$ | 论文默认值 |

### 4. 常见变体与适用条件
- **适用条件**：需要高质量静态词向量的场景；语料较大（$10^9$ 词级）时效果好；需要可解释的"计数+几何"直觉。
- **限制条件**：仍是静态向量（一词一义）；训练需要构造 $O(|V|^2)$ 的共现矩阵（实际用稀疏存储，只存 $X_{ij}>0$ 的项）；对超参数（窗口大小、$\alpha$）较敏感。

---

## 6. 推导思路和思想来源

- **最初困难**：Word2Vec 只看到局部窗口；纯计数法（LSA）对高频词敏感且计算重。
- **直接方法局限**：把 SVD 直接用在共现矩阵上，低频噪声被放大、高频词主导、分解代价高；把 Word2Vec 的窗口无限放大又回到共现矩阵。
- **关键"转念"**：Pennington 等人从**比值（ratio）**出发：$P_{ik}/P_{jk}$（词 $i$ 与 $k$ 共现概率比词 $j$ 与 $k$ 共现概率）能干净地编码语义关系——比值远大于 1 说明 $i$ 与 $k$ 更相关。而比值可以用向量空间中的差来表示：$w_i - w_j$ 与 $\tilde{w}_k$ 的点积。由"点积 = 比值"反推，得到 $w_i^\top \tilde{w}_k \approx \log P_{ik} = \log X_{ik} - \log X_i$，把 $\log X_i$ 吸收进偏置，即得损失函数。
- **推导主线与动机**：共现概率比 → 向量差与第三词的点积 → 对数线性模型 → 加权最小二乘损失。
- **为什么自然得到此结论**：因为"语义关系 = 共现模式的差异"，而向量空间的差运算天然适合表达这种差异；对数把乘法（比值）变成加法（差），正好匹配点积的线性结构。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：小语料，词表 {ice, steam, water}。已知 $X_{\text{ice,water}}=5$，$X_{\text{steam,water}}=1$，$X_{\text{ice,ice}}=2$，$X_{\text{steam,steam}}=2$。估算 $\log X_{\text{ice,water}} - \log X_{\text{steam,water}}$。
- **解题思路与关键步骤**：直接代入：$\log 5 - \log 1 = \ln 5 \approx 1.609$。
- **最终答案**：$\approx 1.609$。含义：ice 与 water 的共现显著多于 steam 与 water，向量空间中 $\vec{ice}-\vec{steam}$ 应与 $\vec{water}$ 方向有较大正点积。
- **易错点**：用错底数（自然对数 vs 常用对数）不影响相对大小，但实现里必须统一；忘记 GloVe 拟合的是 $\log X_{ij}$ 而非 $X_{ij}$。
- **🤔 追问**：如果 $X_{\text{ice,water}}=X_{\text{steam,water}}=5$，比值等于 1，说明什么？—— 说明 water 与两者共现相当，不携带区分 ice/steam 的信息，$\vec{ice}-\vec{steam}$ 与 $\vec{water}$ 点积应接近 0。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：为什么权重函数 $f(x)$ 在 $x$ 很小时要小、很大时封顶为 1？分别解释低频和高频。
- **解题思路与完整解答**：① 低频共现（$X_{ij}$ 很小）：统计噪声大，权重小可抑制噪声——$f(x)\to 0$ 当 $x\to 0$；② 高频共现（如 the 与一切词）：权重封顶 1，避免重复出现的高频对主导损失——若不加封顶，$f$ 线性增长会让少数高频对贡献绝大部分梯度；③ 中间频率（5-100）权重最大，因为它们是"有信息量且统计可靠"的词对。因此 $f$ 是"先升后平"的截断曲线。
- **易错点**：以为 $f$ 是单调递增无上界；忘记 $x_{\max}$ 的截断作用。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：GloVe 官方发布的 300d 词向量（glove.6B.zip、glove.840B.300d.zip）是 NLP 实验的标准静态底座；与 Word2Vec 不同，GloVe 无需训练即可下载使用，可作为 HW02 分类器嵌入层初始化或语义搜索的固定编码器。
- 代码形态（PyTorch 简化版，训练循环省略）：
```python
import torch, torch.nn as nn

class GloVe(nn.Module):
    def __init__(self, vocab_size, d=100, x_max=100, alpha=0.75):
        super().__init__()
        self.w = nn.Embedding(vocab_size, d)          # 中心词向量
        self.tw = nn.Embedding(vocab_size, d)         # 上下文向量
        self.b = nn.Parameter(torch.zeros(vocab_size))
        self.tb = nn.Parameter(torch.zeros(vocab_size))
        self.x_max, self.alpha = x_max, alpha

    def weight(self, x):                              # f(X_ij)
        return torch.where(x < self.x_max,
                           (x / self.x_max) ** self.alpha,
                           torch.ones_like(x))

    def forward(self, i, j, Xij):
        pred = (self.w(i) * self.tw(j)).sum(-1) + self.b[i] + self.tb[j]
        loss = self.weight(Xij) * (pred - Xij.log()) ** 2
        return loss.mean()
```

## 8. 常见误区和易混概念

### 误区 1：以为"GloVe 就是 SVD 共现矩阵分解"
- **错误直觉**：GloVe 和 LSA 一样，对共现矩阵做奇异值分解。
- **为什么错**：GloVe 不分解矩阵，而是用梯度下降拟合 $\log X_{ij}$（回归目标），且带权重函数；SVD 是无权重的最小二乘重建，且对高频词敏感。
- **正确理解**：GloVe 是"计数式思想 + 预测式训练"的混合体：目标来自全局统计，优化用 SGD。

### 误区 2：以为"GloVe 的 $w_i$ 和 $\tilde{w}_j$ 必须取 $w_i$，$\tilde{w}_j$ 没用"
- **错误直觉**：$\tilde{w}_j$ 只是训练陪衬。
- **为什么错**：GloVe 论文发现 $w_i + \tilde{w}_i$ 或 $w_i$ 单独用差别不大，但 $\tilde{w}_j$ 本身也是有效表示（对称目标）；更关键的是**必须加偏置 $b_i+\tilde{b}_j$**，否则高频词无法拟合。
- **正确理解**：$w$ 与 $\tilde{w}$ 对称等价，偏置不可省略。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| GloVe（本概念） | 全局共现回归 | 加权最小二乘拟合 $\log X_{ij}$ | 静态词向量基准 |
| Word2Vec | 局部窗口预测 | softmax/负采样分类目标 | HW01 手写、快速训练 |
| LSA/SVD | 矩阵分解降维 | 无权重、无偏置、高频敏感 | 主题分析、文档向量 |
| BERT 词表示 | 上下文相关 | 一词多义、随语境变化 | 微调下游任务 |

### 题目与解析

#### 1. GloVe 与 Word2Vec 的监督信号（学习目标）分别是什么？
> [!question]- 答案解析
> - **答案**：GloVe 的监督信号是全局共现对数 $\log X_{ij}$（回归目标）；Word2Vec 的监督信号是局部窗口内的"上下文词是否共现"（分类目标）。
> - **解析**：GloVe 属于"计数式+预测式"混合：统计来自全语料，训练用 SGD；Word2Vec 只利用窗口内共现。
> - **易错原因**：把两者都简单归为"共现矩阵分解"。
> - **对应误区**：误区 1。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 设 $x_{\max}=100$，$\alpha=3/4$，计算 $f(0)$、$f(16)$、$f(1000)$。
> [!question]- 答案解析
> - **答案**：$f(0)=0$，$f(16)=(16/100)^{3/4}\approx 0.253$，$f(1000)=1$。
> - **解析**：$16^{3/4} = (2^4)^{3/4} = 2^3 = 8$，$100^{3/4} = (10^2)^{3/4} = 10^{1.5} \approx 31.62$，故 $f(16)=8/31.62\approx 0.253$。$x\ge100$ 时封顶为 1。
> - **易错原因**：忘记 $f$ 在 $x_{\max}$ 处截断；指数运算出错。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 什么场景下优先选 GloVe 而不是 Word2Vec？
> [!question]- 答案解析
> - **答案**：需要现成高质量静态向量（直接下载 300d 官方权重）、词相似度评测、或想利用全局统计信息时；小语料快速训练、需要手写梯度练习（HW01）时选 Word2Vec。
> - **解析**：GloVe 在词相似度/类比基准上整体略优且训练可并行化；但它是静态向量，需要上下文表示时应转向 BERT 类模型。
> - **易错原因**：以为 GloVe 能解决一词多义——不能，它仍是静态的。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 损失函数中的偏置 $b_i + \tilde{b}_j$ 起什么作用？去掉会怎样？
> [!question]- 答案解析
> - **答案**：吸收词频的边际效应：高频词的 $\log X_{ij}$ 整体偏大，若不设偏置，模型只能靠增大向量模长拟合，导致向量方向被词频污染；偏置把"该词本身多常见"从向量中剥离。
> - **解析**：$\log X_{ij} = \log P(i,j) + \log X_{总}$ 中，$\log X_{总}$ 与词对无关，偏置对恰好吸收这类全局常数。实验显示去偏置后质量明显下降。
> - **易错原因**：把偏置当成正则化项（它不是），或以为偏置只影响数值稳定性。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 解释为什么 GloVe 向量能支持 "king − man + woman ≈ queen" 类类比运算。
> [!question]- 答案解析
> - **答案**：GloVe 的目标使 $w_i^\top \tilde{w}_k \approx \log X_{ik} - b_i - \tilde{b}_k$。类比成立的关键是共现概率比：$\frac{P(\text{king}|k)}{P(\text{man}|k)} \approx \frac{P(\text{queen}|k)}{P(\text{woman}|k)}$ 对很多 $k$ 成立（"男性王室"与"女性王室"的分布差异一致），而该比值等于 $w_{\text{king}}^\top \tilde{w}_k - w_{\text{man}}^\top \tilde{w}_k$（忽略偏置后），即 $(w_{\text{king}} - w_{\text{man}})^\top \tilde{w}_k$；对足够多的 $k$ 成立意味着 $w_{\text{king}} - w_{\text{man}} \approx w_{\text{queen}} - w_{\text{woman}}$，移项即得类比式。
> - **解析**：核心是"语义关系以共现比值的几何形式存在"，向量差捕捉的是关系的"方向"，与具体词对无关。
> - **易错原因**：只背结论，讲不出"比值 → 差向量"这一环。
> - **Obsidian 标签建议**：`#自测题/较难`
