# CNN在NLP中的应用
---
## 0. 先判断它值不值得深挖
- **类别**：**B 类（常用工具）**
- **判断理由**：TextCNN（Kim, 2014）是深度学习文本分类的经典基线，HW02 的 baseline 就是它；实现简单、训练快、可解释（滤波器可视化为 n-gram 模式）。虽被 Transformer 取代主流，但面试、竞赛 baseline、低延迟工程仍高频出现，值得掌握到"能手写"。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 文本分类需要捕捉短语级特征："not good" 比 "good" 重要得多。词袋（BOW）丢词序；n-gram 计数特征组合爆炸且稀疏。
> CNN 的回答：**词嵌入矩阵 + 一维卷积 + 最大池化**。卷积核在词序列上滑动，覆盖连续 $k$ 个词（= 可学习的 n-gram 检测器）；max-pooling 自动选出最强位置——位置无关、可并行、参数少。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：CNN 是 [[词向量与Word2Vec]] 之后、[[Transformer架构]] 之前的重要架构；理解"局部窗口 + 池化"才能理解为何 CNN 快而局部、注意力为何要全局。
- **实际应用场景**：短文本分类（情感/意图/垃圾邮件）、句子匹配、字符级 CNN（OOV 鲁棒）；工业低延迟分类服务。
- **高频题型/任务**：HW02 文本分类 baseline；面试"为什么 max-pooling 不用 mean""卷积核大小怎么选""CNN vs RNN vs Transformer 复杂度"。
---
## 3. 学它之前需要哪些前置知识？
1. **[[词向量与Word2Vec]]**：输入是词嵌入矩阵（可静态可微调）。
2. **[[文本预处理]]**：分词、padding、vocab 构建决定输入形态。
3. **卷积与池化基础**：2D 卷积直觉迁移到 1D 序列。
---
## 4. 用直觉语言解释它
> «"TextCNN 像一个'滑动窗口扫描仪'：宽 $k$ 的窗口沿句子滑动，每到一个位置就'读'窗口里的 $k$ 个词并打分（卷积），最后把每个模式在全句各位置的最强分挑出来（max-pooling）。多个宽度（2/3/4）的窗口同时扫，就分别捕捉 bigram/trigram/4-gram 特征——自动学会'哪些短语对分类最有用'。"»
- **直觉类比/几何图像**：1D 卷积 = 在词向量序列上做"模板匹配"；每个滤波器是可学习的"短语模板"，max-pooling 回答"模板在句中最强出现在哪"。
- **为什么很自然**：分类的判别证据通常是局部短语（"太差了""性价比高"），卷积的局部性正好匹配这个归纳偏置。
- **一句话直觉本质**：**用"局部窗口卷积 + 全局最大池化"把变长句子压成定长特征向量，特征 = 各种长度的可学习 n-gram 激活强度。**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**TextCNN**：输入 $X \in \mathbb{R}^{n \times d}$，对每个滤波器 $w \in \mathbb{R}^{k \times d}$ 做一维卷积得特征图 $c \in \mathbb{R}^{n-k+1}$，max-pooling 得标量，拼接所有滤波器输出后接全连接 + softmax。
### 2. 核心公式
$$c_i = f\left(w \cdot X_{i:i+k-1} + b\right),\ i=1,\dots,n-k+1; \qquad \hat{c} = \max\{c_1,\dots,c_{n-k+1}\}$$
$$y = \text{softmax}\left(W_c\,[\hat{c}^{(1)};\dots;\hat{c}^{(m)}] + b_c\right)$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $n$ | 句子长度 | 整数 | 常 padding 定长 |
| $d$ | 嵌入维度 | 50–300 | Word2Vec/GloVe |
| $k$ | 卷积窗口 | 2–5 | 对应 n-gram 长度 |
| $m$ | 滤波器个数 | 100–256 | 每窗口一组 |
| $c_i$ | 第 $i$ 窗口得分 | $\mathbb{R}$ | 激活后值 |
| $\hat{c}$ | 池化标量 | $\mathbb{R}$ | 位置无关特征 |
### 4. 常见变体与适用条件
- **多尺寸滤波器**：$k\in\{2,3,4\}$ 各若干，捕捉多种 n-gram。
- **静态 vs 非静态嵌入**：冻结省显存；微调提精度但易过拟合。
- **适用条件**：短文本（<200 词）、判别依赖局部短语、低延迟推理。
- **限制条件**：窗口固定，长距离依赖捕捉不到；本质局部。
---
## 6. 推导思路和思想来源
- **最初困难**：BOW/n-gram 维度爆炸、稀疏、无语义泛化；RNN 能建模序列但串行慢。
- **直接方法局限**：加深 RNN 只是缓解；n-gram 统计特征无法泛化到未见短语。
- **关键"转念"**：视觉 CNN（局部感受野 + 权值共享 + 池化）搬到文本：词嵌入行 = 像素，窗口 = 感受野，max-pooling = "位置不变性"（"not good" 在句首还是句尾不影响情感）。
- **推导主线与动机**：嵌入矩阵 → 一维卷积（可学习 n-gram）→ 多滤波器（多模板）→ max-pooling（变长压定长、保留最强）→ softmax 分类。
- **为什么自然得到此结论**：分类证据的"局部性 + 位置无关性"与卷积"局部 + 平移不变"的归纳偏置严丝合缝。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：句子 "I love it"（$n=3$），$d=1$：I=0, love=1, it=2。滤波器 $w=(1,1)$，$b=0$，恒等激活。求特征图与池化输出。
- **解题思路与关键步骤**：$k=2$，$n-k+1=2$ 个位置：$c_1 = 1\cdot0+1\cdot1=1$；$c_2 = 1\cdot1+1\cdot2=3$。
- **最终答案**：特征图 $(1,3)$，max-pooling 输出 $3$。
- **易错点**：漏掉最后一个窗口位置；padding 改变窗口数。
- **🤔 追问**：若滤波器换 $w=(-1,1)$？—— $c_1=1$，$c_2=1$，池化输出 1：负权重滤波器捕捉"上升"模式（如 "not good" 中 not→good 的转变）。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：为什么 max-pooling 比 mean-pooling 更适合 TextCNN？—— max 只保留最强激活，对"模式是否存在"敏感且位置无关；mean 会把无关位置噪声平均进来稀释信号。若任务需要频次信息（主题词密度），可改用 k-max pooling。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW02 baseline 的 PyTorch 实现，100 行内完成：
```python
import torch, torch.nn as nn

class TextCNN(nn.Module):
    def __init__(self, vocab, emb_dim=100, num_filters=100, filter_sizes=[2,3,4], num_classes=2):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb_dim, padding_idx=0)
        self.convs = nn.ModuleList([nn.Conv1d(emb_dim, num_filters, k) for k in filter_sizes])
        self.fc = nn.Linear(num_filters * len(filter_sizes), num_classes)

    def forward(self, x):                       # x: (B, n)
        e = self.emb(x).transpose(1, 2)         # (B, d, n)
        pooled = [torch.max(torch.relu(conv(e)), dim=2).values for conv in self.convs]
        return self.fc(torch.cat(pooled, dim=1))
```

## 8. 常见误区和易混概念
### 误区 1：以为"卷积窗口越大越好"
- **错误直觉**：$k=10$ 特征更丰富。
- **为什么错**：窗口越大参数越多越易过拟合，多数判别短语在 2–4 词。
- **正确理解**：多尺寸小窗口组合优于单一大窗口；长依赖交给 RNN/Transformer。
### 误区 2：以为"CNN 能建模任意长距离依赖"
- **错误直觉**：堆多层感受野就全局了。
- **为什么错**：感受野随层数**线性**增长，覆盖 1000 词需上百层；池化还在压缩信息。
- **正确理解**：CNN 是局部特征提取器，全局建模是注意力的主场。
### 概念对比表
| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| TextCNN（本概念） | 局部短语特征 | 并行、局部、参数少 | 短文本分类 |
| RNN/LSTM | 顺序建模 | 串行、长距离记忆 | 序列标注、生成 |
| Transformer | 全局交互 | 并行、全局、$O(n^2)$ | 预训练、长文 |
| 词袋/n-gram | 统计特征 | 无序、稀疏、无语义 | 传统基线 |

### 题目与解析
#### 1. TextCNN 的三个核心组件及各自职责是什么？
> [!question]- 答案解析
> - **答案**：词嵌入层（离散词→连续向量）；多尺寸一维卷积（局部 n-gram 特征）；max-pooling（定长、最强信号）+ 全连接分类头。
> - **解析**：卷积核宽度 $k$ 直接对应 n-gram 长度；多尺寸即多粒度。`#自测题/基础`
#### 2. 句子 "A B C D"（$n=4$），$d=1$：A=1,B=2,C=3,D=4，滤波器 $w=(1,0,1)$，$b=0$，ReLU，求特征图与池化输出。
> [!question]- 答案解析
> - **答案**：$n-k+1=2$：$c_1=1\cdot1+0\cdot2+1\cdot3=4$；$c_2=1\cdot2+0\cdot3+1\cdot4=6$。特征图 $(4,6)$，池化输出 $6$。
> - **解析**：窗口 3 覆盖 A,B,C 与 B,C,D；滤波器是"首尾词加权"模板。`#自测题/基础`
#### 3. 什么任务适合 TextCNN，什么任务不适合？
> [!question]- 答案解析
> - **答案**：适合：短文本、判别依赖局部短语（情感/意图/垃圾邮件）；不适合：长距离依赖（指代消解）、序列输出（NER 需 CRF、翻译）。
> - **解析**：卷积感受野固定；且词序敏感任务（语义角色）CNN 结构上对顺序不敏感。`#自测题/中等`
#### 4. 对比 CNN / RNN / Transformer 的并行性与长距离建模能力。
> [!question]- 答案解析
> - **答案**：并行：CNN ✓、Transformer ✓、RNN ✗；长距离：CNN ✗、RNN △（LSTM 缓解仍衰减）、Transformer ✓；复杂度：CNN $O(nkd)$、RNN $O(nd^2)$、Transformer $O(n^2d)$。
> - **解析**：三者是"局部并行 / 顺序记忆 / 全局并行"的权衡，现代方案常混合。`#自测题/中等`
#### 5. 为"否定情感反转"（"not bad" 实际偏正面）设计特征方案。
> [!question]- 答案解析
> - **答案**：① 2-gram 专用滤波器（not, X）学反转映射；② 嵌入后加"否定标记"通道（not 后词嵌入取反或加维度）；③ attention 让 "not" 的表示传播到被修饰词。
> - **解析**：TextCNN 的 2-gram 滤波器可学到 "not+褒义词" 的高激活，但窗口外传播弱，方案二/三更鲁棒。`#自测题/较难`
