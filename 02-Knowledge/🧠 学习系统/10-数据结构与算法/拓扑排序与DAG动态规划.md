# 拓扑排序与DAG动态规划

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：拓扑排序是[[图遍历BFS与DFS]] 的第一个重要应用（6.006 Lec 10 末尾），而"在 DAG 上按拓扑序做 DP"是把图论与[[动态规划入门]] 打通的关键桥梁（Lec 15-18）：许多在一般图上 NP 难的问题（最长路径）在 DAG 上变成多项式时间。HW03 官方 PS5 直接要求实现拓扑排序，HW05 动态规划以此为思想前站。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：现实中的"先后依赖"无处不在——课程先修、编译依赖、工程任务的先后顺序。给它们排一个**线性顺序**（每个任务只依赖排在自己前面的任务）就是拓扑排序。更妙的是：很多优化问题（项目最短工期、DAG 最长路径、带依赖的最优决策）都建立在这种"只向前看"的结构上——一旦有了拓扑序，就能从前往后做**动态规划**，每个子问题只需看前面已算好的结果。没有拓扑序，这些 DP 就不知道"谁先谁后"。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：拓扑排序是 DFS 完成时间性质的直接应用，是"图遍历 → 图算法"的第一站；DAG 上 DP 则是 HW03（图）→ HW05（动态规划）的**衔接枢纽**：[[图遍历BFS与DFS]] 给遍历工具，[[动态规划入门]] 给递推思想，本笔记把两者焊在一起。关键路径法是工程管理（CPM/PERT）的行业标准。
- **实际应用场景**：课程编排与编译系统（`make`/`pip` 依赖解析）、项目管理（关键路径、松弛时间）、DAG 最长路径（奖金链、任务链）、有向无环图上的调度。**高频题型/任务**：手算拓扑序（DFS 法 vs Kahn 法）、用拓扑排序检测环、DAG 最长/最短路径 DP、关键路径、把问题建模成 DAG 再 DP。

## 3. 学它之前需要哪些前置知识？

1. **[[图遍历BFS与DFS]]**：DFS 的时间戳（发现/完成时间）、前向/后向/横叉边分类、图的邻接表存储——拓扑排序的 DFS 法直接基于"完成时间"性质。
2. **[[动态规划入门]]**：子问题划分、最优子结构、无后效性——DAG 上 DP 是"无后效性"的天然舞台（按拓扑序处理时，所有入边来源都已算完）。**[[知识地图/复杂度分析|复杂度分析]]**：理解 $O(V+E)$ 与"为何 DAG 上最长路径是多项式而一般图上是 NP 难"的对比。

## 4. 用直觉语言解释它

> «"拓扑排序就像给一个剧组排出场顺序：导演规定'谁必须先化妆谁才能上台'（依赖边）。DFS 法像'从台前角色往下追问：你依赖谁？'——一路问到最底层的化妆师，先把化妆师排好，再一层层往上'汇报'；入度法（Kahn）像'舞台监督先放行所有不需要等别人的人上台，每上一人就把'被他解放的人'的等待数减一，归零的人立刻可以上台'。如果最后还有人说'我还在等人'，那一定是有人互相等——循环依赖，戏排不出来。"»

- **直觉类比/几何图像**：排队/出栈（DFS 完成序逆序）+ 入度归零入场（Kahn）；环 = 死锁。
- **为什么很自然**：DAG 无环 ⟹ 至少有一个入度为 0 的点（否则沿入边反推必成环），删掉它仍是 DAG——归纳地排下去必然排完；DFS 里"依赖者先完成被依赖者"（先完成者先出）的反序自然形成拓扑序。**一句话直觉本质**：**拓扑序 = DAG 上"每条边都从左指向右"的线性排列；有了它，任何"只依赖前面"的递推（最长路径、关键路径、DP）都能从前往后一次算完。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **拓扑排序**：对 DAG $G=(V,E)$，求一个排列 $v_1,\dots,v_n$ 使每条边 $u\to v$ 满足 $u$ 排在 $v$ 之前。
- **存在性定理**：$G$ 有拓扑序 ⟺ $G$ 是有向无环图（DAG）。
- **DFS 法**：对 $G$ 跑 DFS，按**完成时间降序**输出顶点（等价于"递归返回时压栈、最后出栈"）。
- **Kahn 法**：重复"取入度为 0 的点输出并删除，将其后继入度减 1"；若队列空而有点未输出 ⟹ 有环。
- **DAG 上 DP（最长路径）**：按拓扑序计算 $dp[v]=\max_{(u,v)\in E}\big(dp[u]+w(u,v)\big)$，$dp[s]=0$。

### 2. 核心公式
$$T_{\text{拓扑排序}}=O(V+E)\qquad(\text{DFS 法与 Kahn 法均为})$$
$$dp[v]=\max_{(u,v)\in E}\big(dp[u]+w(u,v)\big)\qquad(\text{DAG 最长路径 DP})$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $V, E$ | 顶点数、边数 | $V,E\ge 1$ | 复杂度 $O(V+E)$ |
| $d[v], f[v]$ | DFS 发现/完成时间 | $1..2V$ | 完成时间降序 = 拓扑序 |
| $\text{in}(v)$ | 入度 | $0..V-1$ | Kahn 法的排队依据 |
| $dp[v]$ | 到 $v$ 的最长路径长度 | $\mathbb{R}$ | 按拓扑序递推 |
| $w(u,v)$ | 边权 | $\mathbb{R}$ | 可负！DAG 上 DP 不怕负权 |

### 4. 常见变体与适用条件
- **变体**：DFS 完成序法、Kahn 入度法、字典序最小拓扑序（Kahn 用优先队列取最小标号）、DAG 最短/最长路径（$O(V+E)$，替代 Bellman-Ford 的 $O(VE)$）。**适用条件**：图必须无环（有环先报错）、需要"线性顺序"或"按序递推"；**限制**：一般图（有环）上最长路径是 NP 难，拓扑 DP 不适用。

## 6. 推导思路和思想来源

- **最初困难**：给依赖关系排线性序，直觉是"反复找没有未满足依赖的任务"，但怎么高效实现？以及怎么证明 DFS 顺手就能做？**直接方法局限**：朴素每轮扫描找入度 0 是 $O(V^2)$；"DFS 完后发现顺序恰好反了"需要解释。
- **关键"转念"**：**DFS 完成时间就是天然的"被依赖者先完成"信号**——边 $u\to v$ 存在时，$v$ 必然先于 $u$ 完成（$v$ 是 $u$ 的后代或被 $u$ 访问时已结束，而 DAG 排除后向边），所以完成时间**降序**满足"$u$ 在 $v$ 前"。Kahn 则是把"找入度 0"用队列 + 度数维护做到均摊 $O(1)$。
- **推导主线与动机**：先证"无环 ⟹ 存在入度 0 点"（反证沿入边无限回溯）→ Kahn 归纳删点；DFS 法：后向边 ⟺ 环，无环时完成时间降序即拓扑序 → 两个 $O(V+E)$ 算法。DP 动机：拓扑序使"处理 $v$ 时所有 $(u,v)$ 的 $u$ 都已处理"，递推无后顾之忧——**无后效性被拓扑序强制保证**。
- **为什么自然得到此结论**："依赖关系"天然是偏序；偏序的线性延拓就是拓扑序；而"按线性延拓从前往后累加"正是 DP 最优子结构的最顺执行顺序。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：课程依赖：$C_1\to C_3$、$C_1\to C_4$、$C_2\to C_4$、$C_3\to C_5$、$C_4\to C_5$（$A\to B$ 表示先修 $A$）。给出一个拓扑序。
- **解题思路与关键步骤**：**Kahn 法**：入度 $C_1=0,C_2=0$，队列出 $C_1$：$C_3,C_4$ 入度减 1；出 $C_2$：$C_4$ 入度 0；出 $C_4$：$C_5$ 入度 1；出 $C_3$：$C_5$ 入度 0；出 $C_5$。顺序 $C_1,C_2,C_4,C_3,C_5$。
- **最终答案**：$C_1\to C_2\to C_4\to C_3\to C_5$（不唯一：$C_2$ 也可先于 $C_1$ 的后续，只要每条边从左到右）。校验：$C_1$ 在 $C_3,C_4$ 前 ✓，$C_3,C_4$ 在 $C_5$ 前 ✓。
- **易错点**：拓扑序**不唯一**——多个入度 0 时先后随意；Kahn 每次"删点"要同步更新后继入度，忘了更新会漏排。

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：用 DFS 完成时间法重做例子 1 的图：从 $C_1$ 开始 DFS，$C_1\to C_3\to C_5$ 完成（$C_5$ 先完成、$C_3$ 次之、$C_1$ 最后），回溯 $C_1\to C_4$ 完成，再 $C_2$ 完成。完成时间降序：$C_1,C_4,C_3,C_5,C_2$（取决于访问顺序，另一合法序 $C_1,C_3,C_5,C_4,C_2$）。**环检测判据**：DFS 中出现后向边（发现"灰色"节点）⟹ 有环；Kahn 结束时未排点数 > 0 ⟹ 有环。两者等价。**易错点**：DFS 法必须遍历所有连通分量（外层 for 每个未访问顶点），且是"降序"不是"升序"。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：**关键路径法**：活动图（AOE）中，$dp[v]$ = 到事件 $v$ 的最早发生时间，$dp[v]=\max(dp[u]+w(u,v))$；汇点 $dp[t]$ = 项目最短工期；使 $dp$ 取到最大值的边构成**关键路径**（其上活动一天都不能拖）。代码（DAG 最长路径）：
```python
from collections import deque
def topo_kahn(adj, indeg):
    q = deque([v for v in adj if indeg[v] == 0])
    order = []
    while q:
        u = q.popleft(); order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return order if len(order) == len(adj) else None  # None = 有环

def dag_longest(adj, w, s):
    order = topo_kahn(adj, indeg)      # indeg 由调用方传入并维护
    dp = {v: float('-inf') for v in adj}; dp[s] = 0
    for u in order:                      # 按拓扑序：无后效性
        if dp[u] == float('-inf'): continue
        for v in adj[u]:
            dp[v] = max(dp[v], dp[u] + w[(u, v)])
    return dp
```
复杂度 $O(V+E)$；**注意边权可为负也不影响正确性**——这正是 DAG 上 DP 强于 Dijkstra 之处（[[Dijkstra最短路径]] 要求非负、[[Bellman-Ford与负环检测]] 要 $O(VE)$）。

## 8. 常见误区和易混概念

### 误区 1：以为"拓扑排序结果唯一"
- **错误直觉**：算法给定输入，输出应该固定。
- **为什么错**：入度 0 的点往往不止一个，取谁的顺序自由；DFS 的邻接访问顺序也影响结果。**正确理解**：拓扑序一般**不唯一**；若题目要求唯一结果，通常图本身是"全序"（任意两点间有路径）。

### 误区 2：以为"最长路径在任何图上都能用拓扑 DP"
- **错误直觉**：最长路径和最短路径一样，都是 $O(V+E)$。
- **为什么错**：一般图（含环）上最长路径是 **NP 难**（哈密顿路径是其特例）；拓扑 DP 依赖"无后效性"，有环时递推会互相依赖。**正确理解**：DAG 上最长/最短路径都是 $O(V+E)$；一般图只能近似或指数算法。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| DFS/BFS（[[图遍历BFS与DFS]]） | 遍历/可达性 | 无顺序要求 | 连通性、环检测 |
| 拓扑排序 | DAG 线性延拓 | 完成序逆序或入度归零 | 依赖解析、编译 |
| DAG 最长路径 DP | 有向无环图最优路径 | 拓扑序递推 $O(V+E)$ | 关键路径、任务链 |
| Dijkstra（[[Dijkstra最短路径]]） | 一般图非负权最短路 | 贪心+堆 | 地图导航 |

### 题目与解析

#### 1. 什么样的图才有拓扑排序？为什么？
> [!question]- 答案解析
> - **答案**：有向无环图（DAG）。若图有环，环上每个点都依赖"前面的点"，无法线性排列；反之 DAG 至少有一个入度 0 点（反证：否则沿入边回溯无限，必遇重复顶点成环），删掉后仍是 DAG，归纳可得拓扑序。
> - **解析**：存在性定理的两方向都要会证。易错：把"有拓扑序"与"连通"混淆——不连通的多分量 DAG 也有拓扑序。标签：`#自测题/基础`

#### 2. 用 Kahn 法求图 $A\to C, A\to D, B\to D, C\to E, D\to E$ 的一个拓扑序。
> [!question]- 答案解析
> - **答案**：入度 0：$A,B$。出 $A$：$C,D$ 入度减 1；出 $B$：$D$ 入度 0；出 $D$：$E$ 入度 1；出 $C$：$E$ 入度 0；出 $E$。顺序 $A,B,D,C,E$（或 $A,B,C,D,E$ 等，不唯一）。
> - **解析**：关键动作是"出队时更新所有后继入度"。易错：忘记把 $E$ 的入度按两条入边各减一次（$E$ 入度初始 2，需两次减 1 才归零）。

#### 3. 如何用拓扑排序判断一个有向图是否有环？给出两种判据。
> [!question]- 答案解析
> - **答案**：① DFS 法：遍历中出现后向边（访问到灰色节点）⟹ 有环；② Kahn 法：队列空时若已输出顶点数 < $V$ ⟹ 有环（剩下的点入度全不为 0，互相等待）。
> - **解析**：后向边 ⟺ 环是 DFS 边分类的核心定理。易错：Kahn 法要记录"输出计数"而不是只看队列是否空过；DFS 法要从所有未访问顶点各起一次。

#### 4. 边权可负的 DAG 上求最长路径：$dp$ 递推式怎么写？为什么边权为负也正确？
> [!question]- 答案解析
> - **答案**：$dp[v]=\max_{(u,v)\in E}(dp[u]+w(u,v))$，初始 $dp[s]=0$，其余 $-\infty$；按拓扑序计算。边权为负也正确，因为正确性只依赖"处理 $v$ 时所有入边来源 $u$ 已处理完"（无后效性），不依赖权值符号——这与 Dijkstra 要求非负（贪心依据）完全不同。
> - **解析**：这是"拓扑 DP vs Dijkstra vs Bellman-Ford"三算法选型的核心考点。易错：初始化为 0 会把不可达点也算成 0；用 $-\infty$ 并跳过。

#### 5. 证明：DFS 完成后按完成时间降序输出顶点，得到的是拓扑序。
> [!question]- 答案解析
> - **答案**：任取边 $u\to v$。DFS 中分三种情况：① $v$ 在 $u$ 发现前已发现并完成，则 $f[v]<f[u]$；② $v$ 在 $u$ 发现后被 $u$ 直接/间接访问，$v$ 是 $u$ 的后代，$f[v]<f[u]$；③ $v$ 在 $u$ 发现时是灰色（祖先），即 $u\to v$ 是后向边——但 DAG 无环，后向边不存在（后向边必成环）。故 $f[u]>f[v]$ 恒成立，降序输出满足"$u$ 在 $v$ 前"。**解析**：关键是"后向边 ⟺ 环"把情况 ③ 排除。易错：忘记分情况讨论，或没说明 DAG 排除了后向边。
