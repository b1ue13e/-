## 💡 问题动机与直观解析

贪心算法（Greedy Algorithm）在每一步决策时，都做出在**当前看来最好的选择**（局部最优选择），希望通过一系列局部最优选择导致全局最优解。

贪心算法的优势在于运行效率极高（通常为 $\mathcal{O}(n)$ 或 $\mathcal{O}(n \log n)$），但难点在于**“看似贪心很对，实则错误百出”**。使用贪心前必须进行数学证明！

---

## 📐 算法原理与两大证明范式

使用贪心算法的前提是问题必须具备两大性质：
1. **贪心选择性质 (Greedy Choice Property)**：可以通过局部最优选择来构造全局最优解。
2. **最优子结构 (Optimal Substructure)**：问题的最优解包含其子问题的最优解。

### 两大数学证明范式

#### 1. 替换法 / 贪心选择替换证明 (Exchange Argument)
- 假设存在一个全局最优解 $O$。
- 如果 $O$ 没有做出贪心选择，我们可以构造一个新的解 $O'$，将 $O$ 中的非贪心选择替换为贪心选择。
- 证明 $O'$ 的质量不亚于 $O$（即质量 $\ge O$），从而证明贪心选择绝不劣于任何其他选择。

#### 2. 归纳法 (Mathematical Induction)
- 证明第一步贪心选择是正确的。
- 假设前 $k$ 步贪心选择正确，证明第 $k+1$ 步贪心选择依然保持全局最优性。

## 💻 经典代码实现 (区间调度问题 Interval Scheduling)

给定 $n$ 个区间，求互不重叠的最大区间子集数量。贪心策略：**每次选择最早结束的区间 (Earliest Finish Time)**。

```python
def max_overlapping_intervals(intervals: list[list[int]]) -> int:
    if not intervals:
        return 0
    # 按区间结束时间 end 升序排序
    intervals.sort(key=lambda x: x[1])
    
    count = 1
    end_time = intervals[0][1]
    
    for i in range(1, len(intervals)):
        if intervals[i][0] >= end_time:
            count += 1
            end_time = intervals[i][1]
            
    return count
```

## 🃏 Anki 卡片

- Q: 证明贪心算法正确性的 Exchange Argument（替换法）的核心思路是什么？
- A: 假设存在非贪心的全局最优解 $O$，证明将 $O$ 中首个非贪心决策替换为贪心决策后，得到的解 $O'$ 性能 $\ge O$，从而证明贪心策略可行。
