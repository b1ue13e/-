## 💡 问题动机与直观解析

回溯算法（Backtracking）是一种系统化搜索**状态空间树 (State Space Tree)** 所有解的通用算法（相当于试错法）。它特别适用于解决**NP完全/组合爆破问题**（如子集、排列、组合、N皇后、数独解算）。

如果不加约束地遍历搜索树，指数级 $\mathcal{O}(2^n)$ 或阶乘级 $\mathcal{O}(n!)$ 的开销将使问题无法求解。回溯的关键在于**剪枝 (Pruning)**：在搜索过程中一旦判定“当前分支不可能产生合法解或最优解”，立刻放弃该分支向回撤退。

---

## 📐 回溯三要素与剪枝范式

### 1. 回溯框架三要素

- **路径 (Path)**：已经做出的选择。
- **选择列表 (Choices)**：当前位置可以做出的合法选择。
- **结束条件 (Termination Condition)**：到达决策树叶子节点，找到一个合法解。

### 2. 剪枝两大技巧

1. **可行性剪枝 (Feasibility Pruning)**：判定当前选择是否违反约束（如 N 皇后同行/同列/斜线冲突）。
2. **最优性剪枝 / 限界 (Bound Pruning)**：若当前累计代价已超过已知全局最优解，提前终止分支。

## 💻 经典代码实现 (N 皇后问题)

```python
def solve_n_queens(n: int) -> list[list[str]]:
    res = []
    cols = set()
    diag1 = set() # 主对角线 r - c
    diag2 = set() # 副对角线 r + c
    board = [["."] * n for _ in range(n)]

    def backtrack(r: int):
        if r == n:
            res.append(["".join(row) for row in board])
            return

        for c in range(n):
            if c in cols or (r - c) in diag1 or (r + c) in diag2:
                continue # 可行性剪枝
                
            # 做选择
            board[r][c] = "Q"
            cols.add(c)
            diag1.add(r - c)
            diag2.add(r + c)

            backtrack(r + 1)

            # 撤销选择 (Backtrack)
            board[r][c] = "."
            cols.remove(c)
            diag1.remove(r - c)
            diag2.remove(r + c)

    backtrack(0)
    return res
```
