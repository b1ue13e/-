## 💡 问题动机与直观解析

动态规划（Dynamic Programming, DP）是解决多阶段决策最优化问题的终极思想。

与分治不同，动态规划解决的是**重叠子问题 (Overlapping Subproblems)** 极其丰富的场景。如果直接递归，大量子问题会被重复计算指数次 $\mathcal{O}(2^n)$。DP 通过“记忆化搜索 (Memoization)”或“自底向上填表 (Tabulation)”，将每个子问题的解保存下来，避免重复计算，将复杂度降至多项式级别（如 $\mathcal{O}(n \cdot W)$）。

---

## 📐 算法原理与背包模型

解决 DP 问题的核心四步法：
1. **定义 DP 状态**：明确 $dp[i][j]$ 的具体物理/数学含义。
2. **推导状态转移方程 (State Transition)**：找到 $dp[i]$ 与子状态 $dp[i-1]$ 的推导依赖关系。
3. **确定 Base Case 与初始化**。
4. **确定遍历顺序与空间压缩技巧**。

### 0-1 背包 vs 完全背包状态方程

给定 $n$ 件物品，背包容量为 $W$。第 $i$ 件物品重量为 $w_i$，价值为 $v_i$：

#### 1. 0-1 背包（每件物品最多选 1 次）
$$dp[i][j] = \max(dp[i-1][j], \; dp[i-1][j - w_i] + v_i)$$
- **一维空间压缩**：逆序遍历容量 $j$ 从 $W$ 降至 $w_i$：
  $$dp[j] = \max(dp[j], \; dp[j - w_i] + v_i)$$

#### 2. 完全背包（每件物品可无限次选择）
$$dp[i][j] = \max(dp[i-1][j], \; dp[i][j - w_i] + v_i)$$
- **一维空间压缩**：正序遍历容量 $j$ 从 $w_i$ 升至 $W$。

---

## 💻 经典代码实现 (0-1 背包一维空间优化)

```python
def knapsack_01(weights: list[int], values: list[int], W: int) -> int:
    dp = [0] * (W + 1)
    
    for w, v in zip(weights, values):
        # 倒序遍历容量，防止同一物品被重复放入！
        for j in range(W, w - 1, -1):
            dp[j] = max(dp[j], dp[j - w] + v)
            
    return dp[W]
```

## 📝 检索练习与自测题

1. **思考题**：在 0-1 背包空间压缩为一维数组时，为什么遍历容量 $j$ **必须倒序**？如果正序遍历会发生什么？（正序会导致当前物品被重复选择，退化为完全背包）。

## 🃏 Anki 卡片

- Q: 0-1 背包与完全背包在一维空间压缩时的遍历方向有什么本质区别？
- A: 0-1 背包容量维度必须**逆序遍历**（防重复使用当前物品）；完全背包容量维度必须**正序遍历**（允许使用当前物品更新后的新状态）。
