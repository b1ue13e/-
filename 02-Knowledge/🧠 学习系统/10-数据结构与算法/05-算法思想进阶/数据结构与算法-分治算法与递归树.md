## 💡 问题动机与直观解析

分治算法（Divide and Conquer）的核心思想是“分而治之”：
1. **分 (Divide)**：将原问题划分为若干规模较小、相互独立且与原问题形式相同的子问题。
2. **治 (Conquer)**：递归求解各个子问题。若子问题规模足够小（到达 Base Case），则直接求解。
3. **合 (Combine)**：将子问题的解合并为原问题的解。

经典应用包括：归并排序、快速排序、Strassen 矩阵乘法、平面最近点对问题。

---

## 📐 算法原理与递归树分析

递归树（Recursion Tree）是可视化分治递推式 $T(n) = a T(n/b) + f(n)$ 资源消耗的强大分析工具：

1. **根节点**：原问题开销 $f(n)$。
2. **第 1 层**：产生 $a$ 个子节点，每个子节点开销为 $f(n/b)$，第 1 层总开销为 $a \cdot f(n/b)$。
3. **第 $i$ 层**：产生 $a^i$ 个节点，总开销为 $a^i \cdot f(n/b^i)$。
4. **树高**：$h = \log_b n$。
5. **叶子节点数**：$a^{\log_b n} = n^{\log_b a}$。

## 💻 经典代码实现 (平面最近点对 $\mathcal{O}(n \log n)$)

```python
import math

def closest_pair(points: list[tuple[float, float]]) -> float:
    px = sorted(points, key=lambda p: p[0])
    py = sorted(points, key=lambda p: p[1])
    return _closest_pair_rec(px, py)

def _closest_pair_rec(px, py):
    n = len(px)
    if n <= 3:
        return _brute_force(px)
        
    mid = n // 2
    mid_point = px[mid]
    
    Qx = px[:mid]
    Rx = px[mid:]
    
    mid_x = mid_point[0]
    Qy = [p for p in py if p[0] <= mid_x]
    Ry = [p for p in py if p[0] > mid_x]
    
    d1 = _closest_pair_rec(Qx, Qy)
    d2 = _closest_pair_rec(Rx, Ry)
    d = min(d1, d2)
    
    # 跨边界探测带 (Strip)
    strip = [p for p in py if abs(p[0] - mid_point[0]) < d]
    
    # 检查 strip 中的点，每个点最多只需与后续 7 个点比较！
    for i in range(len(strip)):
        for j in range(i + 1, min(i + 8, len(strip))):
            dist = math.hypot(strip[i][0] - strip[j][0], strip[i][1] - strip[j][1])
            d = min(d, dist)
            
    return d

def _brute_force(pts):
    d = float('inf')
    for i in range(len(pts)):
        for j in range(i + 1, len(pts)):
            d = min(d, math.hypot(pts[i][0] - pts[j][0], pts[i][1] - pts[j][1]))
    return d
```
