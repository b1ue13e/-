## 💡 问题动机与直观解析

优先队列 (Priority Queue) 是一种能以 $\mathcal{O}(1)$ 获取最高优先级元素（最小值或最大值），并以 $\mathcal{O}(\log n)$ 插入新元素和弹出堆顶的数据结构。

优先队列最经典的底层实现是**二叉堆 (Binary Heap)**。二叉堆是一棵**完全二叉树 (Complete Binary Tree)**，因此可以完美用连续数组（如 `vector` / `list`）隐式存储，完全摆脱指针内存开销，天然具备极高的 Cache 局部性。

---

## 📐 隐式数组索引映射与堆化证明

### 1. 数组隐式存储寻址

对于 0-indexed 数组，位于索引 $i$ 处节点的逻辑拓扑关系为：
- **父节点**：$\text{parent}(i) = \lfloor (i - 1) / 2 \rfloor$
- **左子节点**：$\text{left}(i) = 2i + 1$
- **右子节点**：$\text{right}(i) = 2i + 2$

### 2. 堆属性 (Heap Property)
- **大顶堆 (Max Heap)**：对任意非根节点 $i$，满足 $A[\text{parent}(i)] \ge A[i]$。
- **小顶堆 (Min Heap)**：对任意非根节点 $i$，满足 $A[\text{parent}(i)] \le A[i]$。

### 3. 自底向上建堆 (Build-Heap) $\mathcal{O}(n)$ 复杂度严格证明

对任意包含 $n$ 个元素的无序数组，从最后一个非叶子节点 $\lfloor n/2 \rfloor - 1$ 开始向前依次调用 `sift_down` 下沉调整。
高度为 $h$ 的节点最多有 $\lceil n / 2^{h+1} \rceil$ 个。总下沉移位步数为：
$$T(n) = \sum_{h=0}^{\lfloor \log_2 n \rfloor} \left\lceil \frac{n}{2^{h+1}} \right\rceil \mathcal{O}(h) \le \frac{n}{2} \sum_{h=0}^{\infty} \frac{h}{2^h} = \frac{n}{2} \cdot 2 = \mathcal{O}(n) \quad \blacksquare$$

## 💻 经典代码实现 (大顶堆与 Heapify)

```python
class MaxHeap:
    def __init__(self, arr: list[int] = None):
        self.heap = arr if arr else []
        if self.heap:
            self._build_heap()

    def _sift_down(self, i: int, n: int):
        largest = i
        left = 2 * i + 1
        right = 2 * i + 2

        if left < n and self.heap[left] > self.heap[largest]:
            largest = left
        if right < n and self.heap[right] > self.heap[largest]:
            largest = right

        if largest != i:
            self.heap[i], self.heap[largest] = self.heap[largest], self.heap[i]
            self._sift_down(largest, n)

    def _build_heap(self):
        n = len(self.heap)
        for i in range(n // 2 - 1, -1, -1):
            self._sift_down(i, n)

    def push(self, val: int):
        self.heap.append(val)
        self._sift_up(len(self.heap) - 1)

    def pop(self) -> int:
        if not self.heap:
            raise IndexError("pop from empty heap")
        root = self.heap[0]
        self.heap[0] = self.heap[-1]
        self.heap.pop()
        if self.heap:
            self._sift_down(0, len(self.heap))
        return root

    def _sift_up(self, i: int):
        parent = (i - 1) // 2
        if i > 0 and self.heap[i] > self.heap[parent]:
            self.heap[i], self.heap[parent] = self.heap[parent], self.heap[i]
            self._sift_up(parent)
```

## 📝 检索练习与自测题

1. **思考题**：在求解 Top-K 频繁元素（如查找最大的 $K$ 个数）时，应该使用**大顶堆**还是**小顶堆**？维护堆的大小为多少？时间复杂度是多少？（答案：使用大小为 $K$ 的小顶堆，开销为 $\mathcal{O}(n \log K)$）。

- Q: 从无序数组自底向上构建二叉堆 (Build Heap) 的时间复杂度是多少？如何证明？
- A: $\mathcal{O}(n)$。通过级数求和 $\sum_{h=0}^{\log n} \frac{h}{2^h} = 2$，证明总结点下沉移动次数与节点总数线性成正比。
