## 💡 问题动机与直观解析

并查集（Disjoint Set Union, DSU）是一种专门用来高效维护**不相交集合连通关系**的数据结构。它主要支持以下两大核心操作：
1. **合并 (Union)**：将两个元素所在的集合合并为一个集合。
2. **查找 (Find)**：查询某个元素所在集合的代表元（根节点），从而判断两个元素是否属于同一集合。

应用场景包括：Kruskal 最小生成树算法、无向图环路检测、社交网络动态连通块统计。

---

## 📐 两大核心优化机制

### 1. 路径压缩 (Path Compression)

在执行 `find(x)` 查找代表元的过程中，顺便将沿途递归访问到的所有节点直接挂载到根节点下方。
下一次再查询这些节点时，只需 $\mathcal{O}(1)$ 步即可到达根节点。

### 2. 按秩合并 (Union by Rank / Size)

在执行 `union(x, y)` 时，将深度较小（或节点数较少）的树合并到深度较大（或节点数较多）的树下方，避免树结构退化成长链。

### 3. 均摊复杂度定理

**定理**：同时使用“路径压缩”与“按秩合并”优化的并查集，对 $n$ 个元素执行 $m$ 次 `Find`/`Union` 操作的均摊单步时间复杂度为：
$$\mathcal{O}(\alpha(n))$$
其中 $\alpha(n)$ 为**阿克曼函数的反函数 (Inverse Ackermann Function)**。对于全宇宙已知的输入规模 $n \le 10^{80}$，$\alpha(n) \le 4$。因此单步开销可以被视为**常数时间 $\mathcal{O}(1)$**。

## 💻 经典代码实现

```python
class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [1] * n
        self.count = n # 动态连通块数量

    def find(self, x: int) -> int:
        # 路径压缩递归实现
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> bool:
        rootX = self.find(x)
        rootY = self.find(y)
        if rootX == rootY:
            return False # 已在同一集合，合并无效
        
        # 按秩合并
        if self.rank[rootX] < self.rank[rootY]:
            rootX, rootY = rootY, rootX
        self.parent[rootY] = rootX
        if self.rank[rootX] == self.rank[rootY]:
            self.rank[rootX] += 1
            
        self.count -= 1
        return True

    def is_connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)
```
