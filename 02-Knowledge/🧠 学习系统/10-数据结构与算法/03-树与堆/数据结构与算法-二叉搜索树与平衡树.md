## 💡 问题动机与直观解析

二叉搜索树（BST, Binary Search Tree）结合了连续有序数组二分查找的对数开销与链表动态插入/删除的灵活性。

BST 的核心性质为：对任意节点 $X$，其左子树所有节点键值均小于等于 $X.key$，右子树所有节点键值均大于等于 $X.key$。

然而，普通 BST 在按有序数据依次插入时，会退化为一根**单链表**，查找与插入开销从期望的 $\mathcal{O}(\log n)$ 恶化为最坏的 $\mathcal{O}(n)$。为了保证树的高度的平衡性，诞生了**自平衡二叉搜索树 (Self-Balancing BSTs)**，如 AVL 树和红黑树 (Red-Black Tree)。

---

## 📐 算法原理与树的旋转

### 1. AVL 树与平衡因子 (Balance Factor)

定义节点 $X$ 的平衡因子为左子树高度与右子树高度之差：
$$\text{BF}(X) = \text{Height}(X.left) - \text{Height}(X.right)$$
AVL 树要求对任意节点，恒满足 $|\text{BF}(X)| \le 1$。

当插入或删除打破平衡（$|\text{BF}| = 2$）时，通过**树的旋转 (Tree Rotations)** 在 $\mathcal{O}(1)$ 时间恢复平衡：
- **LL 型**：单右旋 (Right Rotation)
- **RR 型**：单左旋 (Left Rotation)
- **LR 型**：先左旋后右旋 (Left-Right Double Rotation)
- **RL 型**：先右旋后左旋 (Right-Left Double Rotation)

---

### 2. 红黑树 (Red-Black Tree) 五大黑盒约束

红黑树牺牲了一部分严格的高度平衡（允许最高子树是最短子树的 2 倍），换取更少的旋转重构次数：
1. 每个节点或是**红色的**，或是**黑色的**。
2. 根节点是**黑色的**。
3. 所有叶子节点 (NIL 哨兵) 是**黑色的**。
4. **不许有连续的红节点**（红节点的父节点和子节点必须为黑）。
5. 对每个节点，从该节点到其所有后代叶节点简单路径上的**黑色节点数量相同**（Black-Height 相同）。

## 💻 AVL 树单右旋 C++ 实现

```cpp
struct TreeNode {
    int key;
    int height;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int k) : key(k), height(1), left(nullptr), right(nullptr) {}
};

int getHeight(TreeNode* node) {
    return node ? node->height : 0;
}

void updateHeight(TreeNode* node) {
    if (node) {
        node->height = 1 + std::max(getHeight(node->left), getHeight(node->right));
    }
}

// 单右旋 (LL 型不平衡修正)
TreeNode* rotateRight(TreeNode* y) {
    TreeNode* x = y->left;
    TreeNode* T2 = x->right;

    x->right = y;
    y->left = T2;

    updateHeight(y);
    updateHeight(x);

    return x; // 新的根节点
}
```

## 📝 检索练习与自测题

1. **思考题**：在删除 BST 节点 $X$（且 $X$ 同时具备左右两个子节点）时，如何选择其**中序前驱 (Predecessor)** 或**中序后继 (Successor)** 节点替换 $X$？
2. **概念辨析**：为什么在 C++ `std::map` / `std::set` 与 Java `TreeMap` 中，底层普遍选用红黑树而非 AVL 树？（红黑树插入删除引发的旋转次数少，综合性能更优）。

## 🃏 Anki 卡片

- Q: AVL 树通过什么机制保证树的高度平衡在 $\mathcal{O}(\log n)$？
- A: 要求每个节点的平衡因子 $|\text{BF}| = |\text{Height}(left) - \text{Height}(right)| \le 1$，并在失衡时通过 LL/RR/LR/RL 四种旋转纠正。
