# 红黑树 (Red-Black Tree)

## 1. 红黑树定义与五条不变性

**红黑树 (Red-Black Tree)** 的核心定义是：一种满足以下**五条红黑性质 (Red-Black Properties)** 的自平衡二叉搜索树 (BST)，由 Guibas 和 Sedgewick 于 1978 年提出，是 C++ STL `std::map`、Java `TreeMap` 和 Linux 内核 `rb_tree` 的底层实现：

1. **颜色性质**：每个结点着色为**红色 (Red)** 或**黑色 (Black)**；
2. **根性质**：根结点为**黑色**；
3. **叶性质**：所有 NIL 叶结点（哨兵）为**黑色**；
4. **红色性质**：红色结点的两个子结点均为**黑色**（不存在两个相邻红结点）；
5. **黑高性质**：从任意结点到其后代 NIL 叶结点的所有路径上，**黑色结点数目相等**（定义为该结点的**黑高 `bh`**）。

**基本性质（由五条不变性推导）**：含 $n$ 个内部结点的红黑树，其高度 $h \leq 2 \log_2(n+1)$，因此所有基本操作（查找、插入、删除）均保证 $O(\log n)$ 最坏情形时间复杂度。

---

## 2. 黑高定理与高度界限推导

**定理**：含 $n$ 个内部结点的红黑树，黑高 $\text{bh}(root) \geq h/2$，从而 $h \leq 2\log_2(n+1)$。

**前提条件（假设）**：
- 假设红黑树根结点的黑高为 $k$。
- 假设以任意结点 $x$ 为根的子树，内部结点数至少为 $2^{\text{bh}(x)} - 1$。

**推导过程**：
1. 对子树高度进行归纳证明：当 $h=0$ 时（NIL 结点），内部结点数 $0 \ge 2^0 - 1 = 0$；
2. 由红色性质，从根到叶子的路径上黑色结点至少占一半，因此根的黑高 $k \ge h/2$；
3. 根结点的内部结点数 $n \ge 2^k - 1 \ge 2^{h/2} - 1$；
4. 两边取对数得到 $n + 1 \ge 2^{h/2} \Rightarrow \log_2(n+1) \ge h/2$；
5. **因此**，红黑树高度 $h \leq 2\log_2(n+1)$。

## 3. 红黑树与 AVL 树的区别与对比

| 维度 | 红黑树 (Red-Black Tree) | AVL 树 |
|:---|:---|:---|
| **平衡条件** | 黑高相等（宽松平衡）| 左右子树高度差 $\leq 1$（严格平衡）|
| **最坏高度** | $2\log_2(n+1)$ | $1.44 \log_2(n)$ |
| **插入旋转次数** | 至多 2 次旋转 | 至多 2 次旋转 |
| **删除旋转次数** | **至多 3 次旋转** | $O(\log n)$ 次旋转 |
| **查找性能对比** | 稍慢（因为树稍微偏高）| 稍快（因为树保持最矮）|
| **写多读少场景** | **显著更优**（旋转重构成本低）| 较差（删除触发级联旋转）|
| **实际工程应用** | Linux 进程调度 CFS、STL `map` | 数据库只读索引 |

**边界条件（误区）**：红黑树并非最矮的平衡 BST，其真正优势在于**插入/删除的旋转次数有常数上界 $O(1)$**，而非查找速度最优。

## 4. Python 红黑树核心性质自测与验证

```python
from enum import Enum
from typing import Optional

class Color(Enum):
    RED = 0
    BLACK = 1

class RBNode:
    def __init__(self, key: int, color: Color = Color.RED):
        self.key = key
        self.color = color
        self.left: Optional['RBNode'] = None
        self.right: Optional['RBNode'] = None

NIL = RBNode(key=-1, color=Color.BLACK)

def black_height(node: RBNode) -> int:
    """计算结点的黑高 bh(node)"""
    if node is NIL or node is None:
        return 0
    lh = black_height(node.left)
    rh = black_height(node.right)
    assert lh == rh, f"违反黑高一致性: lh={lh}, rh={rh}"
    return lh + (1 if node.color == Color.BLACK else 0)

def verify_rb_properties(node: RBNode, parent_color: Color = Color.BLACK) -> bool:
    """验证红黑树不变性（红色性质）"""
    if node is NIL or node is None:
        return True
    if node.color == Color.RED:
        assert parent_color == Color.BLACK, f"违反红色性质: key={node.key}"
    return (verify_rb_properties(node.left, node.color) and
            verify_rb_properties(node.right, node.color))

if __name__ == "__main__":
    # 构建合法红黑树: 10(B) -> 5(R), 15(R)
    root = RBNode(10, Color.BLACK)
    n5   = RBNode(5,  Color.RED)
    n15  = RBNode(15, Color.RED)
    root.left = n5; root.right = n15
    n5.left = NIL; n5.right = NIL
    n15.left = NIL; n15.right = NIL

    # 自测验证 1: 根属性
    assert root.color == Color.BLACK, "根必须为黑色"

    # 自测验证 2: 黑高属性
    bh = black_height(root)
    assert bh == 1, f"根黑高应为 1，实测 {bh}"

    # 自测验证 3: 红色属性
    assert verify_rb_properties(root), "红色性质测试失败"

    # 自测验证 4: 故意破坏红色性质测试反例
    n5.right = RBNode(7, Color.RED) # 红红相连
    try:
        verify_rb_properties(root)
        assert False, "应捕获红红相邻冲突"
    except AssertionError as err:
        print(f"反例拦截成功: {err}")

    print(f"红黑树合法性验证成功: 根 key={root.key}, 黑高={bh}")
    print("红黑树单元测试与自查验证全部完成！")
```
