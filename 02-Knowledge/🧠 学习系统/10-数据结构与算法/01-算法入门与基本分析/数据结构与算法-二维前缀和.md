## 1. 🎯 核心原理与容斥原理推导

**二维前缀和（2D Matrix Prefix Sum）** 将一维前缀和思想扩展到二维平面网格。通过预计算从左上角 `(0, 0)` 到任意位置 `(r, c)` 的矩形区域元素之和，在 $O(1)$ 时间内回答任意子矩阵的累加和查询。

### 递推构建与容斥原理（Inclusion-Exclusion Principle）
定义 1-based 二维前缀和矩阵 $P[R+1][C+1]$，其中 $P[i][j]$ 表示原矩阵中左上角为 $(0,0)$、右下角为 $(i-1, j-1)$ 的矩形区域所有元素的总和。

#### 1. 预处理构建公式 (Precomputation Formula)
计算 $P[i][j]$ 时，根据几何区域重叠（容斥原理）：
$$P[i][j] = P[i-1][j] + P[i][j-1] - P[i-1][j-1] + A[i-1][j-1]$$

```
+-------------------+-----+=+
|                   |     | |
|     P[i-1][j-1]   |  B  | |  P[i-1][j] = Top Rect (A + B)
|                   |     | |  P[i][j-1] = Left Rect (A + C)
+-------------------+-----+ |
|         C         |A[i-1][j-1]|
+-------------------+-------+
区域重叠分析：(A + B) + (A + C) - A + Element = A + B + C + Element
```

#### 2. 子矩阵查询公式 (Submatrix Query Formula)
对于原矩阵中左上角为 $(r_1, c_1)$、右下角为 $(r_2, c_2)$ 的闭区间矩形，其元素之和为：
$$\text{Sum}((r_1, c_1), (r_2, c_2)) = P[r_2+1][c_2+1] - P[r_1][c_2+1] - P[r_2+1][c_1] + P[r_1][c_1]$$

```
+----------------------+----------------------+
|     (0,0)            | (0, c2+1)            |
|       +--------------+--------------+       |
|       |              |              |       |
|       |      D       |      B       |       |
|       |              |              |       |
| (r1,0)+--------------+--------------+(r1, c2+1)
|       |              |              |       |
|       |      C       |  Target Sum  |       |
|       |              |              |       |
|       +--------------+--------------+       |
|   (r2+1, 0)      (r2+1, c1)     (r2+1, c2+1)|
+---------------------------------------------+
 Target Sum = Total - Top - Left + Overlap(D)
```

## 2. 💻 规范 C++20 实现

以下提供封装良好、兼顾高性能与边界安全校验的 `NumMatrix` C++20 类：

```cpp
#include <vector>
#include <cstddef>
#include <cstdint>
#include <stdexcept>

namespace Algorithm::PrefixSum2D {

class NumMatrix {
private:
    std::vector<std::vector<int64_t>> P; // 使用 int64_t 防止溢出

public:
    explicit NumMatrix(const std::vector<std::vector<int>>& matrix) {
        if (matrix.empty() || matrix[0].empty()) return;

        const size_t rows = matrix.size();
        const size_t cols = matrix[0].size();

        P.assign(rows + 1, std::vector<int64_t>(cols + 1, 0));

        for (size_t r = 0; r < rows; ++r) {
            for (size_t c = 0; c < cols; ++c) {
                P[r + 1][c + 1] = P[r][c + 1] + P[r + 1][c] - P[r][c] + matrix[r][c];
            }
        }
    }

    // 查询左上角 (row1, col1) 到右下角 (row2, col2) 的矩形区域和 (0-based)
    [[nodiscard]] int64_t sumRegion(size_t r1, size_t c1, size_t r2, size_t c2) const {
        if (P.empty()) return 0;
        if (r1 > r2 || c1 > c2 || r2 + 1 >= P.size() || c2 + 1 >= P[0].size()) {
            throw std::out_of_range("NumMatrix::sumRegion Index out of bounds");
        }

        return P[r2 + 1][c2 + 1] - P[r1][c2 + 1] - P[r2 + 1][c1] + P[r1][c1];
    }
};

} // namespace Algorithm::PrefixSum2D
```

## 3. 🔍 状态跟踪与图解分析

考虑输入矩阵 $A$:
$$A = \begin{pmatrix} 3 & 0 & 1 \\ 5 & 6 & 3 \\ 1 & 2 & 0 \end{pmatrix}$$

#### 预处理前缀和矩阵 $P$ 构建计算过程（$4 \times 4$ 矩阵）：
- $P[0][j] = 0, P[i][0] = 0$
- $P[1][1] = 0 + 0 - 0 + A[0][0] = 3$
- $P[1][2] = P[0][2] + P[1][1] - P[0][1] + A[0][1] = 0 + 3 - 0 + 0 = 3$
- $P[1][3] = P[0][3] + P[1][2] - P[0][2] + A[0][2] = 0 + 3 - 0 + 1 = 4$
- $P[2][1] = P[1][1] + P[2][0] - P[1][0] + A[1][0] = 3 + 0 - 0 + 5 = 8$
- $P[2][2] = P[1][2] + P[2][1] - P[1][1] + A[1][1] = 3 + 8 - 3 + 6 = 14$
- $P[2][3] = P[1][3] + P[2][2] - P[1][2] + A[1][2] = 4 + 14 - 3 + 3 = 18$
- $P[3][1] = P[2][1] + P[3][0] - P[2][0] + A[2][0] = 8 + 0 - 0 + 1 = 9$
- $P[3][2] = P[2][2] + P[3][1] - P[2][1] + A[2][1] = 14 + 9 - 8 + 2 = 17$
- $P[3][3] = P[2][3] + P[3][2] - P[2][2] + A[2][2] = 18 + 17 - 14 + 0 = 21$

得到 $P$ 矩阵为：
$$P = \begin{pmatrix} 
0 & 0 & 0 & 0 \\ 
0 & 3 & 3 & 4 \\ 
0 & 8 & 14 & 18 \\ 
0 & 9 & 17 & 21 
\end{pmatrix}$$

#### 子矩阵查询校验：
查询左上角 $(1, 1)$ 至右下角 $(2, 2)$ 的子矩阵（元素包含 $6, 3, 2, 0$，理论和为 $6+3+2+0 = 11$）：
$$\text{Sum}((1,1), (2,2)) = P[3][3] - P[1][3] - P[3][1] + P[1][1] = 21 - 4 - 9 + 3 = 11 \quad (\text{完全正确})$$

## 4. 📈 复杂度分析与严格证明

### 算法复杂度
- **时间复杂度**：
  - **预处理**：$O(R \times C)$。需遍历 $R \times C$ 网格，单元格计算耗时 $O(1)$。
  - **查询**：$O(1)$。仅执行 3 次加减法。
- **空间复杂度**：
  - **辅助空间**：$O(R \times C)$。用于构建 $(R+1) \times (C+1)$ 的前缀和矩阵。

## 5. ⚠️ 常见坑点与边界条件

1. **减去重叠区与补加重叠区的加减号倒错**
   - 极易混淆预处理与查询中的加减逻辑：
     - 构建：$+ P[r-1][c] + P[r][c-1] \mathbf{- P[r-1][c-1]} + A[r-1][c-1]$（重叠区被加了两次，故**减去**一次）。
     - 查询：$- P[r_1][c_2+1] - P[r_2+1][c_1] \mathbf{+ P[r_1][c_1]}$（重叠区被减了两次，故**补加**一次）。
2. **行列坐标混淆 ($r$ 与 $c$)**
   - 二维网格中 $r$ 代表行（Row，对应 $y$ 轴），$c$ 代表列（Column，对应 $x$ 轴）。传入 `(row1, col1, row2, col2)` 时误写成 `(x1, y1, x2, y2)` 会导致严重越界或答案错乱。

## 6. 🧠 💡 Flashcards (Guided Recall)

Q: 请描述二维前缀和构建公式中为什么需要减去 $P[r-1][c-1]$，而在查询公式中为什么需要加上 $P[r_1][c_1]$？
A: 构建时，$P[r-1][c]$ 和 $P[r][c-1]$ 都包含了左上角 $P[r-1][c-1]$ 区域，重复加了一次，故需减去一次；查询时，$P[r_1][c_2+1]$ 和 $P[r_2+1][c_1]$ 都减去了左上角 $P[r_1][c_1]$ 区域，重复减了一次，故需补加一次。

Q: 二维前缀和的时间与空间复杂度分别是多少？
A: 预处理时间复杂度 $O(R \times C)$，空间复杂度 $O(R \times C)$；单次子矩阵区域和查询时间复杂度为 $O(1)$。
