## 1. 🎯 归并排序分治机制

归并排序（Merge Sort）是典型的**分治法（Divide-and-Conquer）**应用。算法将一个大问题递归地拆解为若干子问题，求解子问题后再将其结果强力合并：
1. **分解 (Divide)**：计算中点 `mid = left + (right - left) / 2`，将当前序列划分为左右两个长度大致相同的子序列 `[left, mid]` 与 `[mid+1, right]`。
2. **解决 (Conquer)**：递归地对左、右两个子序列分别调用归并排序，直到子序列长度为 1 或 0（天然有序）。
3. **合并 (Combine)**：使用双指针顺序扫描有序的左右子序列，按从小到大的顺序将元素复制填充到辅助缓冲区（Auxiliary Array）中，最后拷贝回原数组。

## 2. 🔍 归并树与步骤跟踪 (Step-by-Step Merge Trace)

以输入数组 `[38, 27, 43, 3, 9, 82, 10]`（长度 $n=7$）为例，跟踪其递归拆解与双路合并全过程：

```
                    [38, 27, 43, 3, 9, 82, 10]
                   /                          \
        [38, 27, 43, 3]                    [9, 82, 10]
        /             \                    /         \
   [38, 27]         [43, 3]             [9, 82]      [10]
    /    \           /    \              /   \        |
 [38]   [27]       [43]   [3]          [9]   [82]    [10]
```

### 底层向上合并过程（Merge Phase Trace）：
1. **合并 `[38]` 与 `[27]`**：比较 `38 > 27` $\to$ 合并结果为 `[27, 38]`。
2. **合并 `[43]` 与 `[3]`**：比较 `43 > 3` $\to$ 合并结果为 `[3, 43]`。
3. **合并 `[27, 38]` 与 `[3, 43]`**：
   - 指针 `i` 指向 27，`j` 指向 3：`3 < 27` $\to$ 取 3；
   - `i` 指向 27，`j` 指向 43：`27 < 43` $\to$ 取 27；
   - `i` 指向 38，`j` 指向 43：`38 < 43` $\to$ 取 38；
   - 残余右侧 43 $\to$ 取 43。
   - 合并结果为：`[3, 27, 38, 43]`。
4. **合并 `[9]` 与 `[82]`** $\to$ `[9, 82]`。
5. **合并 `[9, 82]` 与 `[10]`**：比较取 9，再比较 `10 < 82` 取 10，最后取 82 $\to$ 合并结果为 `[9, 10, 82]`。
6. **最终大合并：`[3, 27, 38, 43]` 与 `[9, 10, 82]`**：
   - 比较依次提取：`3` (左), `9` (右), `10` (右), `27` (左), `38` (左), `43` (左), `82` (右)。
   - **最终有序输出**：`[3, 9, 10, 27, 38, 43, 82]`。

## 3. 📐 递归求解与主定理证明 (Master Theorem Proof)

### 3.1 递推关系式建立
设规模为 $n$ 的数组排序时间为 $T(n)$：
- 分解时间：计算中点为 $O(1)$；
- 解决时间：递归求解 2 个规模为 $n/2$ 的子问题，耗时 $2T(n/2)$；
- 合并时间：双指针合并 $n$ 个元素需线性比较与复制，耗时 $\Theta(n)$。

建立递推方程：
$$T(n) = 2T\left(\frac{n}{2}\right) + \Theta(n), \quad T(1) = \Theta(1)$$

### 3.2 应用主定理（Master Theorem）证明
主定理通用递推形式为 $T(n) = a T(n/b) + f(n)$，此处参数为：
$$a = 2, \quad b = 2, \quad f(n) = \Theta(n)$$

计算关键界：
$$n^{\log_b a} = n^{\log_2 2} = n^1 = n$$

因为 $f(n) = \Theta(n) = \Theta(n^{\log_b a})$，符合主定理的**情况 2 (Case 2)**：
$$T(n) = \Theta(n^{\log_b a} \log n) = \Theta(n \log n)$$

**结论**：归并排序在最好、最坏以及平均情况下的时间复杂度严格为 **$\Theta(n \log n)$**。

### 3.3 空间复杂度 $O(n)$ 与稳定性证明
* **空间复杂度**：
  1. 递归调用栈的深度为 $\log_2 n$，栈空间占用 $O(\log n)$；
  2. 合并操作需要申请长度为 $n$ 的辅助缓冲区用于暂存合并元素，空间开销 $O(n)$；
  3. 主导项为辅助数组，因此总额外空间复杂度为 **$O(n)$**。
* **稳定性保证**：
  在双指针合并时，比较条件设置为 `if (left_arr[i] <= right_arr[j])`。当遇到相等键值时，**优先将左半部分的元素拷入辅助数组**。这就严格保证了原来排在左侧的同值元素依然排在左侧，因此**归并排序是严格稳定排序**。

## 4. 💻 C++20 高性能实现代码（单缓冲区复用优化）

在工业级工程实现中，频繁在递归内部申请/释放临时 `vector` 会带来巨大的动态内存分配开销。标准做法是在顶层分配一个全局辅助缓冲区并以引用形式向下传递：

```cpp
#include <iostream>
#include <vector>
#include <cassert>

template <typename T>
void merge(std::vector<T>& arr, std::vector<T>& temp, size_t left, size_t mid, size_t right) {
    size_t i = left;      // 左子序列起始
    size_t j = mid + 1;   // 右子序列起始
    size_t k = left;      // 临时缓冲区写入起始

    // 双指针比较合并，相等时优先取左侧元素保证稳定性 (<=)
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }

    // 处理剩余元素
    while (i <= mid) {
        temp[k++] = arr[i++];
    }
    while (j <= right) {
        temp[k++] = arr[j++];
    }

    // 将合并后的数据拷回原数组
    for (size_t p = left; p <= right; ++p) {
        arr[p] = temp[p];
    }
}

template <typename T>
void merge_sort_internal(std::vector<T>& arr, std::vector<T>& temp, size_t left, size_t right) {
    if (left >= right) return;

    // 避免 (left + right) / 2 可能导致的整型溢出
    size_t mid = left + (right - left) / 2;

    merge_sort_internal(arr, temp, left, mid);
    merge_sort_internal(arr, temp, mid + 1, right);
    merge(arr, temp, left, mid, right);
}

template <typename T>
void merge_sort(std::vector<T>& arr) {
    if (arr.size() <= 1) return;
    std::vector<T> temp(arr.size());
    merge_sort_internal(arr, temp, 0, arr.size() - 1);
}

int main() {
    std::vector<int> data = {38, 27, 43, 3, 9, 82, 10};
    merge_sort(data);

    std::vector<int> expected = {3, 9, 10, 27, 38, 43, 82};
    assert(data == expected);

    std::cout << "[归并排序测试] 排序成功: ";
    for (int v : data) std::cout << v << " ";
    std::cout << "\n";
    return 0;
}
```

## 5. ⚠️ 常见工程陷阱与边界坑点

1. **递归内部频繁分配临时 vector 产生严重性能惩罚**  
   若在 `merge` 函数内部每次调用 `std::vector<T> temp(right - left + 1)`，会导致大量的 `malloc`/`free` 系统调用，使得执行速度比堆排序慢数倍。必须采用顶层分配、传参复用的单缓冲区策略。

2. **中点计算溢出（Integer Overflow）**  
   若使用 `mid = (left + right) / 2`，在处理超大数组（索引接近 `INT_MAX`）时，`left + right` 会发生算术溢出变为负数。正确写法是 `mid = left + (right - left) / 2`。

3. **双指针合并时使用 `<` 取代 `<=` 破坏稳定性**  
   若写成 `if (arr[i] < arr[j]) temp[k++] = arr[i++]`，在遇到 `arr[i] == arr[j]` 时程序会跳过左边优先取右边的 `arr[j]`，导致原本靠左的元素排到了右侧，从而丧失稳定性。

## 6. 🃏 闭卷自测考点 (Anki Card)

- Q: **请写出归并排序的递推方程，并用主定理求解其渐近时间复杂度。**
- A: 递推方程为 $T(n) = 2T(n/2) + \Theta(n)$。参数 $a=2, b=2$，计算 $n^{\log_2 2} = n$。因为 $f(n) = \Theta(n)$ 满足主定理 Case 2，故 $T(n) = \Theta(n \log_2 n)$。

- Q: **工业级 C++ 实现归并排序时，如何优化临时合并数组的内存分配开销？**
- A: 不在每次 `merge` 递归中重复分配局部 `vector`；而是在最顶层入口处一次性分配一个与原数组等长的大缓冲区 `temp`，通过引用将其作为参数透传给子递归函数复用。

- Q: **归并排序如何保证排序的稳定性？代码中的关键判断是什么？**
- A: 关键在双指针合并阶段的判断必须是 `if (arr[i] <= arr[j])`。当左右指针元素值相同时，该条件确保优先提取并拷贝左子序列的元素，使得相等元素的相对前后次序得以完整保留。

## 🚨 常见误区与边界条件

1. **临时数组频繁创建开销**：在递归内部每次都重新 `malloc` 或 `new` 临时数组会导致巨大的内存分配与 GC 开销。**优化**：在顶层分配一个全局/全局辅助数组，递归过程中复用。
2. **双指针合并越界**：左右子数组合并时，当某一侧指针越界后，必须把另一侧剩余所有元素一次性拷贝至辅助数组。
