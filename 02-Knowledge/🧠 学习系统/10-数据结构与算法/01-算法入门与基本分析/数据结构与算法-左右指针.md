## 1. 🎯 核心原理与算法动机

**左右指针（Boundary / Partition Pointers）** 是指在数组划分子区间、执行快速排序划分（Partitioning）或处理三路分流（Dutch National Flag）时，用于界定不同属性区域边界的指针机制。

### 核心动机与循环不变式 (Loop Invariant)
在快速排序（Quicksort）或荷兰国旗问题中，算法需要在原数组空间内（$O(1)$ 辅助空间）将数据划分为满足特定属性的若干子区间。左右指针的核心思想是**维护明确的循环不变式（Loop Invariants）**：

1. **Hoare 划分范式（Hoare Partitioning）**：
   - 指针 `i` 从左边界向右扫描，寻找首个高于或等于 pivot 的元素；
   - 指针 `j` 从右边界向左扫描，寻找首个低于或等于 pivot 的元素；
   - **循环不变式**：在每轮交换前，$\forall k \in [\text{low}..i-1], A[k] \le \text{pivot}$ 且 $\forall k \in [j+1..\text{high}], A[k] \ge \text{pivot}$。当 $i \ge j$ 时划分完成。
2. **三路划分范式（Dutch National Flag Partitioning）**：
   - 维护三个指针：`left`（界定 $< pivot$ 的右边界）、`curr`（当前探索指针）、`right`（界定 $> pivot$ 的左边界）。

```
三路划分状态结构:
[ 0 .. left-1 ]   [ left .. curr-1 ]   [ curr .. right ]   [ right+1 .. N-1 ]
   小于 pivot        等于 pivot           未扫描探索区          大于 pivot
```

## 2. 💻 规范 C++20 实现

以下给出 **Hoare 快速排序划分** 与 **荷兰国旗三路划分（Dutch National Flag Algorithm）** 的标准 C++20 实现。

```cpp
#include <vector>
#include <utility>
#include <cstddef>
#include <stdexcept>

namespace Algorithm::PartitionPointers {

// 1. Hoare 划分算法 (Hoare Partition Scheme)
// 返回划分切分点下标 j，保证 A[low..j] <= pivot 且 A[j+1..high] >= pivot
[[nodiscard]] int hoarePartition(std::vector<int>& arr, int low, int high) noexcept {
    const int pivot = arr[low + (high - low) / 2]; // 选取中间值为 pivot
    int i = low - 1;
    int j = high + 1;

    while (true) {
        // 从左向右寻找第一个 >= pivot 的元素
        do {
            ++i;
        } while (arr[i] < pivot);

        // 从右向左寻找第一个 <= pivot 的元素
        do {
            --j;
        } while (arr[j] > pivot);

        if (i >= j) {
            return j; // 返回分割点
        }

        std::swap(arr[i], arr[j]);
    }
}

// 2. 荷兰国旗三路划分 (Sort Colors / 3-Way Partitioning)
// 将数组中的 0 (红), 1 (白), 2 (蓝) 原地排序
void sortColors(std::vector<int>& nums) noexcept {
    if (nums.size() < 2) return;

    int left = 0;                        // [0..left-1] 均为 0
    int curr = 0;                        // [left..curr-1] 均为 1
    int right = static_cast<int>(nums.size()) - 1; // [right+1..end] 均为 2

    while (curr <= right) {
        if (nums[curr] == 0) {
            std::swap(nums[left], nums[curr]);
            ++left;
            ++curr;
        } else if (nums[curr] == 2) {
            std::swap(nums[curr], nums[right]);
            --right; // 注意：curr 不增加，因为交换过来的 nums[right] 尚未检查
        } else {
            ++curr;  // 元素为 1，直接推进
        }
    }
}

} // namespace Algorithm::PartitionPointers
```

## 3. 🔍 状态跟踪与图解分析

对数组 `arr = [4, 7, 2, 8, 1, 5, 3]`，范围 `low = 0, high = 6` 执行 `hoarePartition` 追踪：

- `pivot = arr[0 + (6-0)/2] = arr[3] = 8`
- 初始化 `i = -1`, `j = 7`

| 步骤 | `i` 推进过程 | `j` 推进过程 | 触发条件 | 执行操作 | 数组状态 |
|---|---|---|---|---|---|
| **初始** | `i=-1` | `j=7` | - | 选取 `pivot = 8` | `[4, 7, 2, 8, 1, 5, 3]` |
| **1** | `do ++i` 停于 `i=3` (`arr[3]=8`) | `do --j` 停于 `j=6` (`arr[6]=3`) | `i (3) < j (6)` | `swap(arr[3], arr[6])` | `[4, 7, 2, 3, 1, 5, 8]` |
| **2** | `do ++i` 停于 `i=6` (`arr[6]=8`) | `do --j` 停于 `j=5` (`arr[5]=5`) | `i (6) >= j (5)` | **碰撞终止**！返回 `j = 5` | `[4, 7, 2, 3, 1, 5, 8]` |

**划分结果分析**：
- 左半区 `arr[0..5] = [4, 7, 2, 3, 1, 5]`（均 $\le 8$）
- 右半区 `arr[6..6] = [8]`（均 $\ge 8$）
- 切分成功，划分为两个不相交子问题。

## 4. 📈 复杂度分析与严格证明

### 算法复杂度
- **时间复杂度**：
  - 单次 Partition 扫描：$\Theta(N)$。`i` 和 `j` 指针从两侧向中间推进，每个元素最多被检查 1~2 次。
  - 基于 Partition 的 QuickSort：平均时间复杂度为 $O(N \log N)$；极端退化场景（如已排序且固定选端点为 pivot）为 $O(N^2)$。
- **空间复杂度**：
  - 原地划分过程：$O(1)$ 辅助空间。

### 循环不变式数学证明 (Hoare Partition)
在 `hoarePartition` 的任意一次外层循环开始前：
1. **不变式 1**：$\forall k < i, A[k] \le \text{pivot}$
2. **不变式 2**：$\forall k > j, A[k] \ge \text{pivot}$
- **初始化**：$i = low - 1, j = high + 1$，区间为空，不变式显然成立。
- **保持**：`i` 停止时 $A[i] \ge pivot$；`j` 停止时 $A[j] \le pivot$。交换 $A[i]$ 与 $A[j]$ 后，新 $A[i] \le pivot$ 且新 $A[j] \ge pivot$，不变式在 `++i` 与 `--j` 后依然成立。
- **终止**：当 $i \ge j$ 时终止，数组被分割为 $A[low..j] \le pivot$ 和 $A[j+1..high] \ge pivot$。

## 5. ⚠️ 常见坑点与边界条件

1. **三路划分中 `curr` 指针自增错误**
   - 在 `sortColors` 中，当 `nums[curr] == 2` 时，执行 `swap(nums[curr], nums[right])` 并 `--right` 后，**决不能对 `curr` 执行 `++curr`**！因为从 `right` 位置交换过来的元素尚未经过校验，可能也是 0 或 2，必须在下一轮循环中再次检查 `nums[curr]`。
2. **Hoare 划分死循环与数组越界**
   - 如果将 `do { ++i; } while(arr[i] < pivot);` 写成 `while(arr[i] <= pivot) ++i;`，当数组元素全部相等时（如 `[2, 2, 2, 2]`），`i` 和 `j` 会直接越界溢出数组边界。必须使用 `<` 和 `>` 比较，并在相等时停下进行交换。

## 6. 🧠 💡 Flashcards (Guided Recall)

Q: 在荷兰国旗三路划分算法中，为什么与 `right` 指针交换后 `curr` 指针不能递增，而与 `left` 指针交换后 `curr` 指针需要递增？
A: 与 `left` 交换换过来的是已经过 `curr` 扫描确认的元素（只能是 1），因此可安全 `++curr`；而与 `right` 交换换过来的是未知的未扫描元素，可能为 0、1 或 2，必须保持 `curr` 不变在下一轮重新检查。

Q: Lomuto 划分与 Hoare 划分的主要区别是什么？
A: Lomuto 划分使用单向快慢指针（移动次数更多，对重复元素敏感）；Hoare 划分使用双向左右指针相向移动，交换次数显著减少，性能比 Lomuto 高约 3 倍且更能有效应对重复元素。
