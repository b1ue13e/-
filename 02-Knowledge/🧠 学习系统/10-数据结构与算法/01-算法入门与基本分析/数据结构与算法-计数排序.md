## 1. 🎯 计数排序核心原理与偏移映射

计数排序（Counting Sort）是一种突破 $\Omega(n \log n)$ 决策树下界的**非比较线性时间排序算法**。其核心机制是将元素的“数值”直接转化为连续数组的“物理下标”：
1. **范围求解与偏移映射 (Range & Offset)**：找到数组最小值 `min_val` 与最大值 `max_val`，计算取值开区范围 $k = \text{max\_val} - \text{min\_val} + 1$。通过映射公式 `idx = val - min_val` 将任意整数（包括负整数）无缝映射至离散索引区 `[0, k-1]`。
2. **频次统计 (Frequency Count)**：开辟大小为 $k$ 的计数数组 `count`，遍历原数组记录每个数值出现的频次。
3. **前缀和计算 (Prefix Sum)**：对 `count` 数组计算前缀和：
   $$\text{pref}[i] = \sum_{m=0}^{i} \text{count}[m]$$
   前缀和数值 $\text{pref}[i]$ 的精确物理含义为：**在排序后的最终数组中，小于或等于数值 $(i + \text{min\_val})$ 的元素总个数**。
4. **逆向反向填装 (Backward Placement)**：从右向左逆向遍历原数组，利用前缀和将元素精准推入输出数组的目标索引位置 `pref[val - min_val] - 1`，并将前缀和减 1。**逆向遍历是确保稳定性的核心物理保障**。

## 2. 🔍 步骤跟踪 (Step-by-Step Trace)

以输入数组 `[4, 2, 2, 8, 3, 3, 1]`（长度 $n=7$）为例：

```
初始输入: [4, 2, 2, 8, 3, 3, 1]
min_val = 1, max_val = 8, 范围 k = 8 - 1 + 1 = 8
```

### 1. 频次统计 (Frequency Array)
根据 `val - 1` 建立长度为 8 的 `count` 数组：
- 数值 `1` (offset 0): 1 个
- 数值 `2` (offset 1): 2 个 (`2_a`, `2_b`)
- 数值 `3` (offset 2): 2 个 (`3_a`, `3_b`)
- 数值 `4` (offset 3): 1 个
- 数值 `5, 6, 7` (offset 4, 5, 6): 0 个
- 数值 `8` (offset 7): 1 个
$$\text{count} = [1, 2, 2, 1, 0, 0, 0, 1]$$

### 2. 前缀和累加 (Prefix-Sum Array)
计算前缀和：
$$\text{pref} = [1, 3, 5, 6, 6, 6, 6, 7]$$

### 3. 逆向填装过程 (Backward Placement Trace)
创建长度 $n=7$ 的输出数组 `output`：
- **`idx = 6` (元素 `1`)**：offset 0 $\to \text{pref}[0] = 1$。目标位置 $1 - 1 = 0 \implies \text{output}[0] = 1$。更新 $\text{pref}[0] = 0$。
- **`idx = 5` (元素 `3_b`)**：offset 2 $\to \text{pref}[2] = 5$。目标位置 $5 - 1 = 4 \implies \text{output}[4] = 3_b$。更新 $\text{pref}[2] = 4$。
- **`idx = 4` (元素 `3_a`)**：offset 2 $\to \text{pref}[2] = 4$。目标位置 $4 - 1 = 3 \implies \text{output}[3] = 3_a$。更新 $\text{pref}[2] = 3$。
- **`idx = 3` (元素 `8`)**：offset 7 $\to \text{pref}[7] = 7$。目标位置 $7 - 1 = 6 \implies \text{output}[6] = 8$。更新 $\text{pref}[7] = 6$。
- **`idx = 2` (元素 `2_b`)**：offset 1 $\to \text{pref}[1] = 3$。目标位置 $3 - 1 = 2 \implies \text{output}[2] = 2_b$。更新 $\text{pref}[1] = 2$。
- **`idx = 1` (元素 `2_a`)**：offset 1 $\to \text{pref}[1] = 2$。目标位置 $2 - 1 = 1 \implies \text{output}[1] = 2_a$。更新 $\text{pref}[1] = 1$。
- **`idx = 0` (元素 `4`)**：offset 3 $\to \text{pref}[3] = 6$。目标位置 $6 - 1 = 5 \implies \text{output}[5] = 4$。更新 $\text{pref}[3] = 5$。

**最终有序输出**：`[1, 2_a, 2_b, 3_a, 3_b, 4, 8]`。
注：`2_a` 排在 `2_b` 前面，`3_a` 排在 `3_b` 前面，完全保持原始输入次序！

## 3. 📐 复杂度分析与稳定性严格证明

### 3.1 时间与空间复杂度
- **时间复杂度**：
  1. 寻找极值 $\text{min\_val}, \text{max\_val}$ 耗时 $\Theta(n)$；
  2. 遍历原数组构建频次数组耗时 $\Theta(n)$；
  3. 累加计算前缀和耗时 $\Theta(k)$；
  4. 逆向扫描拷贝回输出数组耗时 $\Theta(n)$。
  **总时间复杂度为 $\mathbf{\Theta(n + k)}$**。在 $k = O(n)$ 时，表现为严格的线性时间 $O(n)$。

- **空间复杂度**：
  开辟前缀和数组 $O(k)$ 与临时输出数组 $O(n)$，额外空间复杂度为 **$\mathbf{O(n + k)}$**。

### 3.2 稳定性物理证明
- 前缀和 $\text{pref}[\text{offset}]$ 指示的是该数值在输出数组中可被放置的**最大右侧边界索引**。
- 从原数组的**末尾**（`n-1`）开始向左扫描时，遇到的第一个同值元素先被填入最大的右侧下标；随后遇到靠前的同值元素时，`pref` 已自减 1，被填入更靠左的位置。
- 这种“后进靠右、先进靠左”的物理机制保证了原始输入中靠前的元素在输出中依然靠前。**计数排序是严格稳定的**。

## 4. 💻 C++20 完整实现代码（支持负数与稳定输出）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cassert>

void counting_sort(std::vector<int>& arr) {
    if (arr.size() <= 1) return;

    // 1. 寻找最小值与最大值
    int min_val = *std::min_element(arr.begin(), arr.end());
    int max_val = *std::max_element(arr.begin(), arr.end());
    size_t k = static_cast<size_t>(max_val - min_val + 1);

    // 2. 构建频次统计数组
    std::vector<size_t> count(k, 0);
    for (int x : arr) {
        count[static_cast<size_t>(x - min_val)]++;
    }

    // 3. 计算前缀和 (Prefix Sum)
    for (size_t i = 1; i < k; ++i) {
        count[i] += count[i - 1];
    }

    // 4. 逆向扫描填充输出数组（确保稳定性）
    std::vector<int> output(arr.size());
    for (ssize_t i = static_cast<ssize_t>(arr.size()) - 1; i >= 0; --i) {
        int val = arr[static_cast<size_t>(i)];
        size_t offset = static_cast<size_t>(val - min_val);
        output[count[offset] - 1] = val;
        count[offset]--; // 消费一次名额
    }

    arr = std::move(output);
}

int main() {
    std::vector<int> data = {4, -2, 2, 8, -2, 3, 1};
    counting_sort(data);

    std::vector<int> expected = {-2, -2, 1, 2, 3, 4, 8};
    assert(data == expected);

    std::cout << "[计数排序测试] 排序成功: ";
    for (int v : data) std::cout << v << " ";
    std::cout << "\n";
    return 0;
}
```

## 5. ⚠️ 常见工程陷阱与应用局限

1. **数值极值跨度极大（$k \gg n$）引发内存爆表**  
   若数组仅包含两个元素 `[1, 1000000000]`，此时 $n=2$，但 $k=10^9$。计数排序会尝试申请数 GB 的内存空间并扫描 $10^9$ 次，时间与空间效率急剧退化为 $O(10^9)$，彻底失效。

2. **正向遍历填充导致稳定性丧失**  
   若将逆向遍历（`i = n-1 down to 0`）误写为正向遍历（`i = 0 to n-1`），前缀和的扣减机制会导致较早遇到的元素被填在右侧，彻底反转相同元素的物理次序。

3. **忽略偏移量映射导致负数越界崩溃**  
   若没有计算 `min_val` 并使用 `x - min_val`，直接用 `arr[i]` 作为数组下标，遇到负数时会直接触发非法负索引访问（Out-of-Bounds Segment Fault）。

## 6. 🃏 闭卷自测考点 (Anki Card)

- Q: **为什么计数排序的时间复杂度能够突破 $\Omega(n \log n)$ 的限制？**
- A: 因为计数排序是非比较排序，它不依赖“两两比较元素”建立二叉决策树，而是利用元素的数值特征作为数组物理下标直接定位，避开了决策树下界约束，实现了 $O(n + k)$ 的线性开销。

- Q: **前缀和数组在计数排序中的物理意义是什么？**
- A: 前缀和数组 `pref[i]` 表示在最终排好序的数组中，小于等于数值 `(i + min_val)` 的元素累计个数。它直接指示了当前数值在输出数组中允许填入的**最大右侧索引位置**（即 `pref[i] - 1`）。

- Q: **计数排序在逆向填充输出数组时，如何保证算法的稳定性？**
- A: 从末尾 `n-1` 向左扫描时，遇到的后进元素先获得最大的索引 `pref[offset] - 1`；当扫描到靠前的同值元素时，前缀和已被扣减 1，从而被放入更靠左的位置。这种机制严格保留了相同的相对次序。

## 🚨 常见误区与边界条件

1. **非整数或负数限制**：计数排序无法直接处理浮点数或负数。若有负数，需通过减去 `min_val` 进行偏移映射。
2. **正向累加数组保证稳定性**：构造前缀和数组 `count[i] += count[i-1]` 后，从后向前遍历原数组填入结果数组，方能保证排序的稳定性。
