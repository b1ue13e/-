# 数据结构与算法-前缀和与差分数组

## 💡 问题动机与直观解析

前缀和 (Prefix Sum) 与差分 (Difference Array) 是处理静态与动态区间查询问题的一对对偶工具（相当于离散数学中的微积分关系）：
- **前缀和**：预处理开销 $\mathcal{O}(n)$，将静态任意子区间和查询从 $\mathcal{O}(n)$ 降低至 $\mathcal{O}(1)$。
- **差分数组**：将连续子区间的批量更新（如对 $[L, R]$ 区间内所有数值加上 $v$）从 $\mathcal{O}(n)$ 降低至 $\mathcal{O}(1)$。

---

## 📐 离散对偶数学模型

### 1. 一维前缀和与区间和公式

定义前缀和数组 $P$，其中 $P[0] = 0$，对 $i \ge 1$：
$$P[i] = \sum_{k=0}^{i-1} A[k] = P[i-1] + A[i-1]$$
则任意闭区间 $[L, R]$ (0-indexed) 的元素之和可表示为：
$$\sum_{k=L}^{R} A[k] = P[R+1] - P[L]$$

---

### 2. 二维前缀和 (2D Prefix Sum)

对 $m \times n$ 矩阵，定义 $P[i][j]$ 为左上角 $(0,0)$ 至右下角 $(i-1, j-1)$ 的子矩阵和：

* **构建公式**：
  $$P[i][j] = A[i-1][j-1] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]$$
* **区域查询公式**（求左上角 $(r_1, c_1)$ 到右下角 $(r_2, c_2)$ 的子矩阵和）：
  $$\text{RegionSum} = P[r_2+1][c_2+1] - P[r_1][c_2+1] - P[r_2+1][c_1] + P[r_1][c_1]$$

---

### 3. 差分数组 (Difference Array)

定义差分数组 $D[i] = A[i] - A[i-1]$（规定 $A[-1]=0$）。

要对区间 $[L, R]$ 所有元素加上 $v$：
$$D[L] \gets D[L] + v, \quad D[R+1] \gets D[R+1] - v$$
修改完成后，对 $D$ 数组求前缀和即可精准还原修改后的数组 $A$。

---

## 💻 代码实现 (一维与二维前缀和)

```python
class NumMatrix:
    def __init__(self, matrix: list[list[int]]):
        if not matrix or not matrix[0]:
            return
        m, n = len(matrix), len(matrix[0])
        self.P = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                self.P[i][j] = (matrix[i-1][j-1] 
                                + self.P[i-1][j] 
                                + self.P[i][j-1] 
                                - self.P[i-1][j-1])

    def sumRegion(self, r1: int, c1: int, r2: int, c2: int) -> int:
        return (self.P[r2+1][c2+1] 
                - self.P[r1][c2+1] 
                - self.P[r2+1][c1] 
                + self.P[r1][c1])
```

- Q: 一维差分数组对区间 $[L, R]$ 加 $v$ 的修改操作是什么？
- A: $D[L] += v$ 并且 $D[R+1] -= v$，修改耗时 $\mathcal{O}(1)$。
