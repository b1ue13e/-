## 1. 🎯 核心原理与算法动机

**对撞指针（Inward Two Pointers）** 是一种在单维连续数据结构（如数组或字符串）中，从序列的两头分别设置起始指针，并在条件驱动下相向移动（`left++` 与 `right--`），直到两指针相遇或交叉的算法范式。

### 核心动机与单调性剪枝
在暴力枚举中，搜索双变量区间或组合点对通常需要 $O(N^2)$ 的时间复杂度。对撞指针之所以能将时间降低至 $O(N)$，本质上是因为利用了数据的**单调性（Monotonicity）**或**几何边界约束（Geometric Bounding Constraint）**，在每一步迭代中排除掉不可能包含最优解的整个决策子集（即隐式剪枝）：

1. **有序数组的两数之和**：若当前 $A[left] + A[right] > target$，由单调增特性，任意 $k > left$ 的 $A[k] + A[right]$ 也必定 $> target$。因此，`right` 处的元素不可能再与任何左侧元素构成解，安全执行 `right--`。
2. **盛最多水的容器**：容积 $V(l, r) = (r - l) \times \min(h[l], h[r])$。若 $h[l] < h[r]$，如果保持 $l$ 不变而缩小 $r$，新长度缩小且新高度不可能超过 $h[l]$，故容积必然减少。因此 $l$ 的使命结束，安全执行 `left++`。

```
初始状态:  [left] ------------->                <------------- [right]
相向移动:  left ++  (当和偏小或左侧为短板)       right -- (当和偏大或右侧为短板)
终止条件:  left >= right (两指针撞击，决策域归零)
```

## 2. 💻 规范 C++20 实现

以下给出基于 C++20 标准的三个典型对撞指针范式实现：**有序数组两数之和**、**盛最多水的容器**、以及**验证回文字符串**。

```cpp
#include <vector>
#include <string_view>
#include <algorithm>
#include <cctype>
#include <cstdint>
#include <optional>

namespace Algorithm::TwoPointers {

// 范式一：有序数组两数之和 (Two Sum II - Sorted Array)
// 返回两元素的下标（1-based），若无解返回 std::nullopt
[[nodiscard]] std::optional<std::pair<size_t, size_t>> twoSumSorted(
    const std::vector<int>& numbers, int target) noexcept 
{
    if (numbers.size() < 2) return std::nullopt;

    size_t left = 0;
    size_t right = numbers.size() - 1;

    while (left < right) {
        // 使用 int64_t 预防加法溢出 (Integer Overflow)
        const int64_t sum = static_cast<int64_t>(numbers[left]) + numbers[right];
        if (sum == target) {
            return std::make_pair(left + 1, right + 1); // 1-based 下标
        } else if (sum < target) {
            ++left;  // 增大左值以提升总和
        } else {
            --right; // 减小右值以降低总和
        }
    }
    return std::nullopt;
}

// 范式二：盛最多水的容器 (Container With Most Water)
// 利用几何单调性排除不可能更优的板
[[nodiscard]] int maxArea(const std::vector<int>& height) noexcept {
    if (height.size() < 2) return 0;

    size_t left = 0;
    size_t right = height.size() - 1;
    int max_val = 0;

    while (left < right) {
        const int width = static_cast<int>(right - left);
        const int min_h = std::min(height[left], height[right]);
        max_val = std::max(max_val, width * min_h);

        // 总是移动较短的一侧板，以寻找潜在的高板
        if (height[left] < height[right]) {
            ++left;
        } else {
            --right;
        }
    }
    return max_val;
}

// 范式三：验证回文字符串 (Valid Palindrome)
// 对撞过滤非字母数字字符
[[nodiscard]] bool isPalindrome(std::string_view s) noexcept {
    if (s.empty()) return true;

    size_t left = 0;
    size_t right = s.length() - 1;

    while (left < right) {
        while (left < right && !std::isalnum(static_cast<unsigned char>(s[left]))) {
            ++left;
        }
        while (left < right && !std::isalnum(static_cast<unsigned char>(s[right]))) {
            --right;
        }
        if (left < right) {
            if (std::tolower(static_cast<unsigned char>(s[left])) != 
                std::tolower(static_cast<unsigned char>(s[right]))) {
                return false;
            }
            ++left;
            --right;
        }
    }
    return true;
}

} // namespace Algorithm::TwoPointers
```

|---|---|---|---|---|---|---|---|
| **1** | 0 (`1`) | 8 (`7`) | 8 | $\min(1, 7) = 1$ | $8 \times 1 = 8$ | **8** | `h[0] < h[8]` $\implies$ `left++` |
| **2** | 1 (`8`) | 8 (`7`) | 7 | $\min(8, 7) = 7$ | $7 \times 7 = 49$ | **49** | `h[8] < h[1]` $\implies$ `right--` |
| **3** | 1 (`8`) | 7 (`37`) | 6 | $\min(8, 37) = 8$ | $6 \times 8 = 48$ | 49 | `h[1] < h[7]` $\implies$ `left++` |
| **4** | 2 (`6`) | 7 (`37`) | 5 | $\min(6, 37) = 6$ | $5 \times 6 = 30$ | 49 | `h[2] < h[7]` $\implies$ `left++` |
| **5** | 3 (`2`) | 7 (`37`) | 4 | $\min(2, 37) = 2$ | $4 \times 2 = 8$ | 49 | `h[3] < h[7]` $\implies$ `left++` |
| **6** | 4 (`5`) | 7 (`37`) | 3 | $\min(5, 37) = 5$ | $3 \times 5 = 15$ | 49 | `h[4] < h[7]` $\implies$ `left++` |
| **7** | 5 (`4`) | 7 (`37`) | 2 | $\min(4, 37) = 4$ | $2 \times 4 = 8$ | 49 | `h[5] < h[7]` $\implies$ `left++` |
| **8** | 6 (`8`) | 7 (`37`) | 1 | $\min(8, 37) = 8$ | $1 \times 8 = 8$ | 49 | `h[6] < h[7]` $\implies$ `left++` |

## 4. 📈 复杂度分析与严格证明

### 时间复杂度
- **定理**：对撞指针在长度为 $N$ 的线性结构上运行时间为 $\Theta(N)$。
- **证明**：初始化时 `right - left = N - 1`。在 `while (left < right)` 循环的每一次迭代中，要么 `left` 递增 1，要么 `right` 递减 1（或两者同时变动）。即循环体每执行一次，区间长度 `right - left` 至少精确减少 1。因为区间长度从 $N-1$ 减少至 $0$，循环体执行的最大次数为 $N-1$。每次循环内仅进行 $O(1)$ 的比较与算术运算，故总复杂度为 $O(N)$。

### 空间复杂度
- **辅助空间**：$O(1)$。仅维护 `left` 与 `right` 两个迭代索引或指针变量，不需要额外的动态内存分配。

## 5. ⚠️ 常见坑点与边界条件

1. **整数加法溢出 (Integer Overflow)**
   - 在计算两数之和（如 `numbers[left] + numbers[right]`）时，若数组元素值接近 `INT_MAX`，直接相加会导致未定义行为（Undefined Behavior）。必须使用 `static_cast<int64_t>` 提升类型后再计算。
2. **指针越界与死循环**
   - 在过滤非字母数字字符（如 `isPalindrome`）时，内嵌的 `while` 循环（如 `while (!isalnum(s[left])) ++left;`）**必须严格包含 `left < right` 约束**。否则当字符串全部由标点符号组成时，`left` 将一路溢出数组边界导致段错误（Segmentation Fault）。
3. **循环终止条件的选择 (`left < right` vs `left <= right`)**
   - 对于需要选出两个**不同位置**元素的场景（如容器面积、两数之和），使用 `left < right`；对于需要检测或包含中心单元素的场景（如奇数长度回文检测），使用 `left <= right`。混用会导致漏诊中心元素或使用同一个元素计算两次。

## 6. 🧠 💡 Flashcards (Guided Recall)

Q: 对撞指针的核心剪枝逻辑是什么？它依赖于数据的什么性质？
A: 对撞指针通过判断两端状态，在 $O(1)$ 时间内剔除掉不可能包含最优解的整个一侧子集。它高度依赖数据的单调性（如排序）或几何边界约束（如短板效应）。

Q: 在“盛最多水的容器”中，为什么每次移动短板是正确的？移动高板会怎样？
A: 容积由 `宽度 * 短板高度` 决定。若移动高板，宽度减小，而新高度绝不会超过原短板高度，容积必然减小或不变，绝不可能产生更大容积。因此只有移动短板才可能遇到更高的板从而提升容积。

Q: 为什么对撞指针能将 $O(N^2)$ 的双重循环降低到 $O(N)$？
A: 因为指针相向移动使得总决策空间从 $N \times N$ 的二维矩阵压缩为沿对角线的线性遍历，每次指针移动都永久剔除了 $N$ 种可能组合中的一行或一列。
