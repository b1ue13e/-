## 💡 问题动机与直观解析

二分查找（Binary Search）是“减治法”（Decrease and Conquer）最经典的落地。在单调有序序列中查找目标值时，通过每次将搜寻区间减半，可将线性查找 $\mathcal{O}(n)$ 的复杂度降至对数级 $\mathcal{O}(\log n)$。

但“二分查找写对了 $90\%$ 容易，处理防死循环与死边界写对最后 $10\%$ 极难”。二分查找的精髓在于**二分单调性 (Monotonicity)** 以及**区间端点的闭合契约（闭区间 vs 左闭右开区间）**。

---

## 📐 正式定义与区间契约

### 1. 整数二分两大核心模板

#### 模板一：闭区间 $[left, right]$ 查找第一个 $\ge target$ 的位置 (Lower Bound)

* **区间定义**：`left = 0, right = n - 1`，循环条件 `while left <= right:`
* **中点计算**：`mid = left + (right - left) // 2` （防范 `left + right` 整型溢出）

```python
def lower_bound(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1
    ans = len(nums)
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] >= target:
            ans = mid
            right = mid - 1  # 缩小右边界，继续探索更左侧
        else:
            left = mid + 1   # 缩小左边界
    return ans
```

---

### 2. 浮点二分 (Floating-Point Binary Search)

浮点数二分不需要考虑整数的 `+1` / `-1` 离散偏移，通常采用固定的**迭代次数**（如 100 次，精度达 $2^{-100}$）或**精度阈值 $\epsilon$**（如 $10^{-7}$）：

```python
def cube_root(x: float, eps: float = 1e-7) -> float:
    left, right = min(-1.0, x), max(1.0, x)
    while right - left > eps:
        mid = left + (right - left) / 2.0
        if mid ** 3 >= x:
            right = mid
        else:
            left = mid
    return left
```

---

### 3. 二分答案 (Binary Search on Answer)

当问题满足“单调判定函数 $P(x)$”——即若 $x$ 可行，则对所有 $x' > x$ 也可行（或不可行）——即可将搜索目标从索引转化为**解空间范围**。此时判定函数复杂度为 $\mathcal{O}(f(n))$，整体时间复杂度为 $\mathcal{O}(f(n) \log(\text{Range}))$。

## 🃏 Anki 卡片

- Q: 整数二分查找防死循环的关键是什么？
- A: 区间更新逻辑（`mid + 1` 或 `mid - 1`）必须与中点向下/向上取整规则及循环条件（`left <= right` 或 `left < right`）完全严格配套。

- Q: 什么是二分答案 (Binary Search on Answer)？
- A: 当可行性问题具有单调判定性质 $P(x)$ 时，将求解问题转化为在可能的答案取值范围内进行二分查找。
