## 💡 问题动机与直观解析

双指针（Two Pointers）与滑动窗口（Sliding Window）是优化连续子数组/子字符串检索算法的黄金利器。

暴力的双重循环遍历子区间开销为 $\mathcal{O}(n^2)$。当目标问题满足**单调性 (Monotonicity)**（例如：若子区间 $[left, right]$ 不满足条件，则对更长的 $[left, right+k]$ 也必然不满足）时，我们可以维护左右两个指针向单向滑动。因为每个指针最多移动 $n$ 次，整体时间复杂度降至 $\mathcal{O}(n)$。

---

## 📐 算法基本形态分类

1. **对撞双指针 (Two-Way Collision Pointers)**：
   * `left` 从头部出发，`right` 从尾部出发，向中间靠拢（如有序数组两数之和 `Two Sum II`、盛最多水的容器）。
2. **快慢双指针 (Fast-Slow Pointers / Tortoise and Hare)**：
   * `fast` 步长大于 `slow`，用于链表成环检测 (Floyd Cycle Detection) 或原地数组去重。
3. **滑动窗口 (Sliding Window)**：
   * 维护一个动态区间 $[left, right]$，右指针扩大窗口引入元素，左指针收缩窗口排除失效元素。

---

## 💻 经典代码实现（最长无重复字符子串）

```python
def length_of_longest_substring(s: str) -> int:
    char_map = {}
    left = 0
    max_len = 0
    
    for right, char in enumerate(s):
        # 发现重复字符，且重复字符在当前窗口内部
        if char in char_map and char_map[char] >= left:
            left = char_map[char] + 1
        
        char_map[char] = right
        max_len = max(max_len, right - left + 1)
        
    return max_len
```

## 🃏 Anki 卡片

- Q: 滑动窗口算法能够将复杂度从 $\mathcal{O}(n^2)$ 降至 $\mathcal{O}(n)$ 的前提条件是什么？
- A: 问题的窗口性质必须满足单调性：即随着右界扩张，状态单调递增/递减；随着左界收缩，状态单调恢复。
