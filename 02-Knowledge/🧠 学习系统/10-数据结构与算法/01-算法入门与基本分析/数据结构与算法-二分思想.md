## 1. 🎯 核心原理与算法动机

**二分思想（Binary Search Paradigm）** 是分治法（Divide and Conquer）中最经典且极致的应用。其核心哲学是：**通过每次检查解空间中间元素，将搜索规模减半，从而把指数/线性级的暴力搜索压缩至对数级开销**。

```
原始搜索区间 [0, 9]:
[ 2 | 5 | 8 | 12 | 16 | 23 | 38 | 56 | 72 | 91 ]   Target = 23
                   ↑ Mid = (0+9)/2 = 4 (Value: 16)
               16 < 23 -> 排除左半区间 [0, 4]!

新搜索区间 [5, 9]:
[ 23 | 38 | 56 | 72 | 91 ]
        ↑ Mid = (5+9)/2 = 7 (Value: 56)
    56 > 23 -> 排除右半区间 [7, 9]!

新搜索区间 [5, 6]:
[ 23 | 38 ]
   ↑ Mid = (5+6)/2 = 5 (Value: 23) -> 命中!
```

### 1.1 两个本质前提：单调性与随机访问
1. **单调性（Monotonicity）**：二分查找的底层逻辑不局限于“有序数组”，而是要求搜索域具备某种**二分单调判定性质 $P(x)$**。即存在分界点 $x^*$，使得对所有 $x < x^*$，判定条件 $P(x)$ 均为 `False`；对所有 $x \ge x^*$，$P(x)$ 均为 `True`。
2. **随机访问能力（Random Access）**：数据结构必须支持 $O(1)$ 时间获取指定中间节点（如数组或 Array-like 连续内存）。单链表虽然可保持有序，但寻找 `mid` 需 $O(N)$ 遍历，无法享受二分对数级加速。

### 1.2 循环不变性（Loop Invariant）
要确保二分算法百分百正确，必须维护**循环不变性**：
在算法任意一次循环开始前，只要目标解 $target$ 存在于原数组中，它就**必然严格包含在当前搜索区间 $[left, right]$ 内部**。
- **初始化**：初始区间 $[0, N-1]$ 覆盖所有可能性，不变性成立。
- **保持**：取 $mid = left + (right - left) / 2$。若 $arr[mid] < target$，由于数组单调递增，$[left, mid]$ 必然全小于 $target$，故解只可能在 $[mid+1, right]$，更新 $left = mid + 1$ 保持不变性；反之亦然。
- **终止**：当 $left > right$ 时区间为空，表明目标解不存在。

### 1.3 二分决策树（Binary Decision Tree）
对于长度为 $N$ 的有序数组，二分查找的所有可能比较路径可以映射为一棵**高度为 $h = \lceil \log_2(N+1) \rceil$ 的二叉判定树**。
树中每个内部节点代表一次与 `mid` 的比较，树的叶节点代表查找成功或失败。这表明：无论问题规模 $N$ 多大，二分查找的最坏比较次数绝不会超过二叉决策树的高度 $\lceil \log_2(N+1) \rceil$。

## 2. 📐 渐近分析与主定理证明

### 2.1 时间复杂度证明（使用主定理 Master Theorem）
二分查找每次将规模为 $n$ 的问题规约为一个规模为 $n/2$ 的子问题，且比较操作需 $O(1)$ 常数时间。递推关系式为：

$$T(n) = T\left(\frac{n}{2}\right) + \Theta(1)$$

对比主定理标准形式 $T(n) = a T(n/b) + f(n)$，其中 $a = 1, b = 2, f(n) = \Theta(1)$。
计算临界指数 $n^{\log_b a} = n^{\log_2 1} = n^0 = 1$。
由于 $f(n) = \Theta(n^{\log_b a}) = \Theta(1)$，符合主定理 **Case 2**：

$$T(n) = \Theta(n^{\log_b a} \lg n) = \Theta(1 \cdot \log n) = \Theta(\log n)$$

- **最坏时间复杂度**：$O(\log N)$
- **最好时间复杂度**：$O(1)$（第一次 `mid` 即命中）
- **平均时间复杂度**：$O(\log N)$

### 2.2 空间复杂度分析
- **迭代实现**：仅需 $left, right, mid$ 三个指针/下标变量，空间复杂度为 $O(1)$。
- **递归实现**：递归调用栈深度等于二叉决策树高度 $\lceil \log_2(N+1) \rceil$，空间复杂度为 $O(\log N)$。

## 3. 💻 C++ 20 完整工程实现与测试

以下代码实现了带详细决策轨迹打印、支持泛型的二分查找算法，并包含严格的正确性断言：

```cpp
#include <iostream>
#include <vector>
#include <cassert>
#include <concepts>
#include <iomanip>

using namespace std;

// 使用 C++20 Concept 约束泛型类型支持比较操作
template <typename T>
requires std::three_way_comparable<T>
class BinarySearcher {
public:
    // 基础二分查找：寻找精确等于 target 的索引，未找到返回 -1
    static int search(const vector<T>& arr, const T& target) {
        if (arr.empty()) return -1;

        int left = 0;
        int right = static_cast<int>(arr.size()) - 1;
        int step = 1;

        cout << "\n[Binary Search Trace] Target: " << target << endl;
        cout << "Step | Left | Right | Mid | Value | Action" << endl;
        cout << "-----------------------------------------------" << endl;

        while (left <= right) {
            // 防止整数溢出的 mid 计算
            int mid = left + (right - left) / 2;
            cout << setw(4) << step++ << " | "
                 << setw(4) << left << " | "
                 << setw(5) << right << " | "
                 << setw(3) << mid << " | "
                 << setw(5) << arr[mid] << " | ";

            if (arr[mid] == target) {
                cout << "Match Found!" << endl;
                return mid;
            } else if (arr[mid] < target) {
                cout << "Target > Mid -> Search Right [" << mid + 1 << ", " << right << "]" << endl;
                left = mid + 1; // 缩小解空间至右半区
            } else {
                cout << "Target < Mid -> Search Left [" << left << ", " << mid - 1 << "]" << endl;
                right = mid - 1; // 缩小解空间至左半区
            }
        }

        cout << "Search space exhausted. Not Found." << endl;
        return -1;
    }
};

int main() {
    // 升序有序数组
    vector<int> data = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91};
    
    // 1. 查找存在的元素
    int idx1 = BinarySearcher<int>::search(data, 23);
    assert(idx1 == 5);
    cout << "[Assert Pass] Target 23 found at index " << idx1 << endl;

    // 2. 查找不存在的元素
    int idx2 = BinarySearcher<int>::search(data, 40);
    assert(idx2 == -1);
    cout << "[Assert Pass] Target 40 correctly returned -1." << endl;

    // 3. 边界元素查找 (最小值与最大值)
    assert(BinarySearcher<int>::search(data, 2) == 0);
    assert(BinarySearcher<int>::search(data, 91) == static_cast<int>(data.size()) - 1);

    return 0;
}
```

## 4. 📊 状态转换与推导步骤 Trace

### 算例追踪：数组 `[2, 5, 8, 12, 16, 23, 38, 56, 72, 91]` ($N=10$)，查找 Target = `23`

| 步骤 (Step) | 左边界 `left` | 右边界 `right` | `mid` 计算公式 | `arr[mid]` 值 | 条件比较与决策行为 | 维持循环不变性 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Init | 0 | 9 | - | - | 搜素区间 $[0, 9]$ 包含全集 | $23 \in arr[0..9]$ |
| Pass 1 | 0 | 9 | $0 + (9-0)/2 = 4$ | `arr[4] = 16` | $16 < 23 \implies left = 4 + 1 = 5$ | $23 \in arr[5..9]$ |
| Pass 2 | 5 | 9 | $5 + (9-5)/2 = 7$ | `arr[7] = 56` | $56 > 23 \implies right = 7 - 1 = 6$ | $23 \in arr[5..6]$ |
| Pass 3 | 5 | 6 | $5 + (6-5)/2 = 5$ | `arr[5] = 23` | $23 == 23 \implies$ **Hit! Index 5** | 返回 5 |

## 5. ⚠️ 经典陷阱与边界防御

1. **对无序数据滥用二分（Violating Monotonicity Prerequisite）**：
   - *陷阱*：对未排序的数组直接调用二分查找，由于抛弃半区的前提（$arr[mid] < target$ 则左侧均小于 $target$）不成立，算法会随机丢弃包含正确解的区域，导致查找失效。
   - *防御*：必须确保数据已排序（单调），或判定函数 $P(x)$ 具备二段单调性。

2. **忽略循环不变性导致死循环（Infinite Loop Bug）**：
   - *陷阱*：在分支更新时误写为 `left = mid` 或 `right = mid` 且配合 `while (left <= right)`，当区间缩小到仅剩 2 个元素（如 $left=4, right=5, mid=4$）且触发 `left = mid` 时，`left` 的值未发生变化，导致算法陷入死循环。
   - *防御*：在 `[left, right]` 闭区间模板中，匹配失败后必须强行跳过 `mid` 节点（即 `left = mid + 1` 和 `right = mid - 1`）。

3. **二叉决策树高度计算错误**：
   - *陷阱*：误认为 $N=10^6$ 时二分需要上万次比较。
   - *分析*：因为 $\log_2(10^6) \approx 19.93$，最大仅需 20 次比较。

## 6. 🃏 闭卷自测与 Anki 卡片

### 闭卷自测考点
- **问答**：二分查找的递推公式是什么？如何使用主定理推导出其 $O(\log N)$ 时间复杂度？
- **标准解答**：递推公式为 $T(n) = T(n/2) + \Theta(1)$。在主定理 $T(n) = a T(n/b) + f(n)$ 中，$a=1, b=2, f(n)=\Theta(1)$。因为 $n^{\log_b a} = n^{\log_2 1} = n^0 = 1$，满足 $f(n) = \Theta(n^{\log_b a})$（Case 2），故 $T(n) = \Theta(n^{\log_b a} \log n) = \Theta(\log n)$。

## 🚨 常见误区与边界条件

1. **死循环问题**：在中点计算 `mid = (left + right) // 2` 时，若分支写为 `left = mid` 而非 `left = mid + 1`，且区间长度为2（例如 `left=0, right=1`），会导致 `mid=0`，区间死循环不收敛。**解法**：使用 `left = mid + 1`，或者上取整 `mid = (left + right + 1) // 2`。
2. **整数溢出**：在 C++/Java 等有界语言中 `(left + right)` 可能发生 32 位 signed int 溢出。**解法**：改用 `mid = left + (right - left) // 2`。
3. **单调性假设失效**：二分查找的前提是序列或搜索空间具有严格或非严格单调性（或满足可二分决策性）。若数组未排序直接二分会导致错误结果。

## 🃏 Anki 卡片

- Q: 二分查找能运用的本质前提是什么？
- A: 数据必须具备**二段单调性**（判定函数 $P(x)$ 划分为 False/True 两半），且底层存储支持 $O(1)$ 随机访问。
---
- Q: 请用“循环不变性（Loop Invariant）”解释为什么二分查找过程中更新区间时 `left = mid + 1`？
- A: 当 `arr[mid] < target` 时，由于数组单调递增，`[left, mid]` 的所有元素均严格小于 `target`，目标不可能在此区间。为了将解空间维持在可能存在解的范围内，必须排除 `mid`，将左边界更新为 `mid + 1`。
---
- Q: 包含 $N$ 个元素的有序数组，二分查找最坏情况下的比较次数上限是多少？
- A: 上限为该数组二叉决策树的高度，即 $\lceil \log_2(N+1) \rceil$ 次。
