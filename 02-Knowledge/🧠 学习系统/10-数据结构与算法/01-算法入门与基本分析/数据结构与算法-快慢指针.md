## 1. 🎯 核心原理与算法动机

**快慢指针（Fast and Slow Pointers）**，又称龟兔赛跑算法（Tortoise and Hare Algorithm），是指两个指针在同向移动过程中以**不同步长或不同速度**（如慢指针步长为 1，快指针步长为 2，或快指针作为探路者、慢指针作为有效边界写入者）遍历数据结构的技巧。

### 核心应用场景与数学机理
1. **链表环路检测与入口寻找（Floyd's Cycle-Finding Algorithm）**：
   - 快指针步长为 2，慢指针步长为 1。如果链表中存在环，快慢指针必然在环内相遇。
   - 相遇后，将一个指针重置回链表头，两指针均以步长 1 同步前进，再次相遇点即为**环的起始入口节点**。
2. **寻找链表中点（Middle of Linked List）**：
   - 当快指针到达链表末尾（`nullptr` 或最后一个节点）时，慢指针正好停留在链表的中点位置（偶数节点时停在下中点或上中点，视初始化而定）。
3. **有序数组原地去重（In-place Array De-duplication）**：
   - 快指针 `fast` 作为探索指针，扫描每一个元素；慢指针 `slow` 作为维护无重序列的写入指针。

```
链表环检测数学示意图:
[Head] ----- L ----- [Cycle Entrance] ----- A ----- [Meet Point]
                            |                           |
                            +----------- C - A ---------+
```

## 2. 💻 规范 C++20 实现

以下包含链表节点定义及三个核心算法实现：环检测与入口定位、寻找链表中点、有序数组原地去重。

```cpp
#include <vector>
#include <cstddef>
#include <algorithm>

namespace Algorithm::FastSlowPointers {

// 单链表节点定义
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int x) : val(x), next(nullptr) {}
};

// 1. 弗洛伊德环路检测与入口寻找 (Linked List Cycle II)
[[nodiscard]] ListNode* detectCycle(ListNode* head) noexcept {
    if (!head || !head->next) return nullptr;

    ListNode* slow = head;
    ListNode* fast = head;

    // 阶段一：检测是否存在环
    bool has_cycle = false;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            has_cycle = true;
            break;
        }
    }

    if (!has_cycle) return nullptr;

    // 阶段二：寻找环入口节点
    ListNode* ptr1 = head;
    ListNode* ptr2 = slow;
    while (ptr1 != ptr2) {
        ptr1 = ptr1->next;
        ptr2 = ptr2->next;
    }

    return ptr1; // 返回环入口节点
}

// 2. 寻找链表中点 (Find Middle of Linked List)
// 对于偶数长度 [1, 2, 3, 4]，返回第二个中点 3
[[nodiscard]] ListNode* findMiddle(ListNode* head) noexcept {
    if (!head) return nullptr;

    ListNode* slow = head;
    ListNode* fast = head;

    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

// 3. 有序数组原地去重 (Remove Duplicates from Sorted Array)
// 返回去重后的新长度，同时修改前 k 个元素
[[nodiscard]] size_t removeDuplicates(std::vector<int>& nums) noexcept {
    if (nums.empty()) return 0;

    size_t slow = 0; // slow 之前 (含 slow) 的元素为无重复序列
    for (size_t fast = 1; fast < nums.size(); ++fast) {
        if (nums[fast] != nums[slow]) {
            ++slow;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}

} // namespace Algorithm::FastSlowPointers
```

## 3. 🔍 状态跟踪与图解分析

### 弗洛伊德环路检测数学证明与追踪
设头节点到环入口的距离为 $L$，环入口到相遇点的顺时针距离为 $A$，环的总周长为 $C$。

1. 当慢指针 `slow` 首次到达环入口时，走了 $L$ 步；此时快指针 `fast` 已经进入环内，走了 $2L$ 步。
2. 慢指针在环内继续走 $A$ 步与快指针相遇。此时 `slow` 共走了 $L + A$ 步。
3. `fast` 走的总步数为 $2(L + A)$。因为 `fast` 在环内比 `slow` 多绕了 $k$ 圈（$k \ge 1$）：
   $$2(L + A) = L + A + k \cdot C \implies L + A = k \cdot C \implies L = k \cdot C - A = (k-1)C + (C - A)$$
4. **结论**：头节点到环入口的距离 $L$，恰好等于相遇点沿着环继续走到入口的距离 $(C - A)$ 加上 $(k-1)$ 整圈周长！因此，一个指针从 `head` 出发，另一个从相遇点出发，二者以步长 1 同步前进，必将在**环入口节点**处首次碰撞。

#### 追踪示例：
链表结构：`1 -> 2 -> 3 -> 4 -> 5`，其中 `5->next = 3`（入口为节点 3）。$L=2$ (1->2->3), $C=3$ (3->4->5->3)。

| 步数 | `slow` 节点 (值) | `fast` 节点 (值) | 状态 / 说明 |
|---|---|---|---|
| 0 | 1 | 1 | 初始化，在 head 处 |
| 1 | 2 | 3 | `slow` 走1步，`fast` 走2步 |
| 2 | 3 | 5 | `slow` 到达环入口 (已走 $L=2$ 步) |
| 3 | 4 | 4 | **相遇点**！(`slow` 位于 4，在环内走了 $A=1$ 步) |
| **阶段二** | **`ptr1` (从 head 出发)** | **`ptr2` (从相遇点 4 出发)** | **寻找入口** |
| 0 | 1 | 4 | 重置 `ptr1=head`, `ptr2=slow` |
| 1 | 2 | 5 | 同步步长 1 前进 |
| 2 | **3** | **3** | **在节点 3 碰撞**！成功定位环入口节点 |

## 4. 📈 复杂度分析与严格证明

### 环路检测 (Floyd's Algorithm)
- **时间复杂度**：$O(N)$。
  - 阶段一：慢指针进入环前走 $L$ 步。进入环后，快慢指针在环内的相对速度为 $2 - 1 = 1$ 步/次。快慢指针之间的最大距离不超过 $C$，因此在环内最多移动 $C$ 步即相遇。总步数 $\le L + C = N$，复杂度为 $O(N)$。
  - 阶段二：同步指针相遇需移动 $L$ 步。故整体复杂度为 $O(N)$。
- **空间复杂度**：$O(1)$。仅需常数个指针节点变量，无需哈希表集合 $O(N)$ 的空间开销。

## 5. ⚠️ 常见坑点与边界条件

1. **链表空指针解引用 (Null Pointer Dereference)**
   - 在 `while (fast && fast->next)` 约束中，必须**同时校验 `fast` 与 `fast->next`**。只校验 `fast->next` 在空链表或单节点无环链表上会导致段错误。
2. **偶数节点链表中点位置定义不一致**
   - 若链表长度为 4（`1->2->3->4`）：
     - `fast = head; while(fast && fast->next) { slow=slow->next; fast=fast->next->next; }` 结束时 `slow` 指向 `3`（第二个中点）。
     - 若逻辑需要第一个中点 `2`，控制条件需改为 `while (fast->next && fast->next->next)`。
3. **数组去重未覆盖全相同元素**
   - 在有序数组去重中，若未初始化 `slow = 0` 或 `fast` 从 1 开始，可能会导致首个元素被覆盖或数组越界。

## 6. 🧠 💡 Flashcards (Guided Recall)

Q: 为什么 Floyd 环路检测算法中快指针步长为 2、慢指针步长为 1 能保证在环内必然相遇？
A: 因为在环内，快指针相对于慢指针的相对移动速度是每次 1 个节点 ($2 - 1 = 1$)。相对距离在模周长意义下每步递减 1，因此不可能“跳过”慢指针，必然在有限步内追上。

Q: 请写出 Floyd 环检测寻找环入口节点的数学等式推导。
A: 设 $L$ 为入口距离，$A$ 为入口到相遇点距离，$C$ 为周长。慢指针走 $L+A$，快指针走 $2(L+A) = L + A + kC$。解得 $L = kC - A = (k-1)C + (C - A)$，故 head 到入口距离等于相遇点沿环走回入口的距离。

Q: 如何用快慢指针找链表的中点？对于偶数长度链表，如何控制返回上中点还是下中点？
A: `slow` 走1步，`fast` 走2步。当 `while(fast && fast->next)` 结束时返回 `slow`（下中点）；若改为 `while(fast->next && fast->next->next)` 则返回 `slow`（上中点）。
