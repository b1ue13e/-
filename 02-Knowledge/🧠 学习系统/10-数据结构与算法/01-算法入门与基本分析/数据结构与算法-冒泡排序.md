# 冒泡排序 (Bubble Sort & Early-Exit Optimization)

## 1. 🎯 冒泡排序核心机制

冒泡排序（Bubble Sort）是一种简单直观的基于比较的相邻交换排序算法。其核心物理逻辑如下：
1. **遍历与相邻比较**：从数组起始位置开始，顺次比较相邻两个元素 `arr[j]` 与 `arr[j+1]`。若 `arr[j] > arr[j+1]`，则交换两者位置。
2. **气泡上浮**：经过一轮（Pass）完整的相邻比较与交换后，当前未排序区间的最大元素会被像气泡一样一步步“压入”并固定在未排序区间的末尾位置。
3. **标志位优化（Early Exit）**：引入布尔标志位 `swapped`。若某一轮遍历中没有发生任何一次交换，说明整个数组已经处于完全单调递增状态，算法可立即提前终止（Early Exit），从而在最好情况下达到 $O(n)$ 时间复杂度。

## 2. 🔍 步骤跟踪 (Step-by-Step Trace)

以输入数组 `[5, 2, 8, 3, 1]`（长度 $n=5$）为例，跟踪带有 `swapped` 标志位优化的冒泡排序全过程：

```
初始状态: [5, 2, 8, 3, 1]
```

### 轮次 1 (`pass i = 0`): 未排序区间 `[0, 4]`, `swapped = false`
- `j = 0`: 比较 `5` 与 `2` (5 > 2) $\rightarrow$ **交换** $\rightarrow$ 数组为 `[2, 5, 8, 3, 1]`, `swapped = true`
- `j = 1`: 比较 `5` 与 `8` (5 < 8) $\rightarrow$ 不交换 $\rightarrow$ 数组为 `[2, 5, 8, 3, 1]`
- `j = 2`: 比较 `8` 与 `3` (8 > 3) $\rightarrow$ **交换** $\rightarrow$ 数组为 `[2, 5, 3, 8, 1]`, `swapped = true`
- `j = 3`: 比较 `8` 与 `1` (8 > 1) $\rightarrow$ **交换** $\rightarrow$ 数组为 `[2, 5, 3, 1, 8]`, `swapped = true`
- **轮次 1 结束**：元素 `8` 沉底固定，已排序区域包含 `[8]`。

### 轮次 2 (`pass i = 1`): 未排序区间 `[0, 3]`, `swapped = false`
- `j = 0`: 比较 `2` 与 `5` (2 < 5) $\rightarrow$ 不交换 $\rightarrow$ 数组为 `[2, 5, 3, 1, 8]`
- `j = 1`: 比较 `5` 与 `3` (5 > 3) $\rightarrow$ **交换** $\rightarrow$ 数组为 `[2, 3, 5, 1, 8]`, `swapped = true`
- `j = 2`: 比较 `5` 与 `1` (5 > 1) $\rightarrow$ **交换** $\rightarrow$ 数组为 `[2, 3, 1, 5, 8]`, `swapped = true`
- **轮次 2 结束**：元素 `5` 沉底固定，已排序区域包含 `[5, 8]`。

### 轮次 3 (`pass i = 2`): 未排序区间 `[0, 2]`, `swapped = false`
- `j = 0`: 比较 `2` 与 `3` (2 < 3) $\rightarrow$ 不交换 $\rightarrow$ 数组为 `[2, 3, 1, 5, 8]`
- `j = 1`: 比较 `3` 与 `1` (3 > 1) $\rightarrow$ **交换** $\rightarrow$ 数组为 `[2, 1, 3, 5, 8]`, `swapped = true`
- **轮次 3 结束**：元素 `3` 沉底固定，已排序区域包含 `[3, 5, 8]`。

### 轮次 4 (`pass i = 3`): 未排序区间 `[0, 1]`, `swapped = false`
- `j = 0`: 比较 `2` 与 `1` (2 > 1) $\rightarrow$ **交换** $\rightarrow$ 数组为 `[1, 2, 3, 5, 8]`, `swapped = true`
- **轮次 4 结束**：元素 `2` 固定，最终仅剩元素 `1` 天然有序。

### 轮次 5 (`pass i = 4`): `i < n-1` 循环结束
**最终输出**：`[1, 2, 3, 5, 8]`，总计进行了 4 轮遍历，发生了 7 次相邻交换。

## 3. 📐 复杂度与稳定性证明

### 3.1 时间复杂度分析与数学证明
1. **最坏情况（逆序数组）**：
   - 比较总次数：
     $$T_{\text{cmp}}(n) = \sum_{i=0}^{n-2} (n - 1 - i) = (n-1) + (n-2) + \dots + 1 = \frac{n(n-1)}{2}$$
   - 交换总次数：每次比较均触发交换，同为 $\frac{n(n-1)}{2}$。
   - 时间复杂度为 $O(n^2)$。

2. **最好情况（完全有序数组，带 `swapped` 优化）**：
   - 第一轮遍历中，`j` 从 `0` 扫到 `n-2`，进行 $n-1$ 次比较。
   - 期间未发生任何交换，`swapped` 保持为 `false`。
   - 触发 `if (!swapped) break;` 立即退出外层循环。
   - 最好时间复杂度为 $O(n)$。

3. **平均时间复杂度**：
   - 随机序列的平均逆序对数量为 $\frac{n(n-1)}{4}$，每次相邻交换恰好消除一个逆序对。因此平均比较与交换开销均为 $\Theta(n^2)$。

### 3.2 空间复杂度分析
- 冒泡排序仅使用了固定数量的迭代变量 `i`, `j` 与标记变量 `swapped`，未开辟动态内存空间。
- 额外空间复杂度为 $O(1)$（原位排序 In-place）。

### 3.3 稳定性推导
- 冒泡排序的交换条件为**严格大于**：`if (arr[j] > arr[j+1]) std::swap(...)`。
- 当出现 `arr[j] == arr[j+1]` 时，算法不会触发交换。因此，键值相等的元素在前向移动过程中相对位置永远不会改变。
- **结论**：冒泡排序属于**稳定排序**算法。

## 4. 💻 C++20 完整实现代码

```cpp
#include <iostream>
#include <vector>
#include <utility>
#include <cassert>

// 带标志位优化的冒泡排序
template <typename T>
void bubble_sort(std::vector<T>& arr) {
    const size_t n = arr.size();
    if (n <= 1) return;

    for (size_t i = 0; i < n - 1; ++i) {
        bool swapped = false;
        // 每一轮将当前未排序区间的最大值沉底到 index (n - 1 - i)
        for (size_t j = 0; j < n - 1 - i; ++j) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        // 若本轮遍历未发生任何交换，说明数组已有序，提前终止
        if (!swapped) {
            break;
        }
    }
}

int main() {
    std::vector<int> data = {5, 2, 8, 3, 1};
    bubble_sort(data);

    std::vector<int> expected = {1, 2, 3, 5, 8};
    assert(data == expected);

    std::cout << "[冒泡排序测试] 排序成功: ";
    for (int v : data) std::cout << v << " ";
    std::cout << "\n";
    return 0;
}
```

## 5. ⚠️ 常见工程陷阱与边界坑点

1. **内层循环边界越界（Off-by-one Error）**  
   若内层循环条件写为 `j < n - i`，在访问 `arr[j+1]` 时会导致最末轮 `j = n-1` 产生 `arr[n]` 的数组越界访问（Undefined Behavior）。必须严格限制为 `j < n - 1 - i`。

2. **错误更改比较逻辑导致稳定性丧失**  
   若将比较条件误改写为 `if (arr[j] >= arr[j + 1])`，相等元素之间也会触发强制交换，从而彻底破坏排序的稳定性。

3. **忽略 `swapped` 标志位导致冗余计算**  
   未使用 `swapped` 标志位的冒泡排序即使面对完全有序的输入，依然会硬性执行 $\frac{n(n-1)}{2}$ 次比较，使得最好情况下的时间复杂度退化为 $O(n^2)$。

## 6. 🃏 闭卷自测考点 (Anki Card)

- Q: **冒泡排序中 `swapped` 标志位的作用是什么？它如何改变算法的时间复杂度？**
- A: `swapped` 标志位记录当前一轮内循环是否发生了相邻元素交换。若未发生交换，说明序列已完全有序，外层循环立即终止。它将输入完全有序（或近乎有序）时的最好时间复杂度从 $O(n^2)$ 降低至 $O(n)$。

- Q: **为什么冒泡排序的内层循环边界是 `j < n - 1 - i`？**
- A: 因为经过前 `i` 轮冒泡后，末尾的 `i` 个元素已经被固定处于全局有序状态；且相邻比较访问的是 `arr[j]` 和 `arr[j+1]`，取 `j = n - 2 - i` 时 `j+1 = n - 1 - i` 恰好指向未排序区间的最后一个元素，既不破坏正确性又杜绝了越界。

- Q: **证明冒泡排序是稳定排序的关键条件是什么？**
- A: 关键在于相邻元素的交换触发条件必须是**严格大于**（`arr[j] > arr[j+1]`）。当遇到相同值的元素时不会触发交换，因而相等的元素绝不会改变相对先后顺序。

## 🚨 常见误区与边界条件

1. **未设置提前终止标志位**：基础冒泡排序不管数组是否有序均执行 $O(n^2)$ 比较。**优化**：引入 `swapped` 布尔标志，若某一轮无任何交换发生，说明数组已然有序，可立即退出。
2. **边界索引越界**：内层循环比较 `nums[j]` 与 `nums[j+1]` 时，界限应为 `len - 1 - i`，防止 `j+1` 越界。
