## 1. 🎯 核心原理与常用技巧总结

字符串问题在数据结构与算法竞赛及面试中占有极高的比例。掌握针对字符串结构的独特算法技巧，能够大幅降低代码复杂度并避免不必要的动态内存分配。

### 1. 字符频率映射表 (Fixed-size Array Hashing)
在处理只包含小写英文字母（`'a'`~`'z'`）或 ASCII 字符的字符串时，无需使用重型的 `std::unordered_map`。使用固定大小的数组 `int count[26]` 或 `int count[256]`，通过 `ch - 'a'` 进行数组下标映射：
- 查找/修改时间为绝对 $O(1)$。
- 零哈希碰撞开销，极佳的 CPU L1 缓存局部性（Cache Locality）。

### 2. 字符串哈希 (Polynomial Rolling Hash)
将字符串映射为一个整数哈希值，从而把字符串比较的复杂度从 $O(K)$ 降低至 $O(1)$。
- **前缀哈希计算公式**：选择基数 $B$（如 131 或 13331）与大质数模数 $M$（如 $10^9 + 7$ 或利用 `uint64_t` 自然溢出 $2^{64}$）：
  $$H[i] = (H[i-1] \times B + S[i-1]) \pmod M$$
- **子串哈希查询公式**（区间 $[L, R]$，0-based）：
  $$\text{Hash}(L, R) = \left( H[R+1] - H[L] \times B^{R-L+1} \right) \pmod M$$

### 3. 中心扩散法求最长回文子串 (Expand Around Center)
回文串具有高度的对称性。中心扩散法的核心思想是遍历所有可能的**回文中心点**（共 $2N - 1$ 个，包括 $N$ 个单字符奇数中心和 $N-1$ 个双字符偶数中心），从中心向两侧扩散扩张。

```
中心扩散示意图:
奇数长度回文 (中心为单个字符):   ... [left] <-- (center) --> [right] ...
偶数长度回文 (中心为字符间隙):   ... [left] <-- (c1 , c2) --> [right] ...
```

## 2. 💻 规范 C++20 实现

以下给出**异位词判断**、**字符串滚动哈希**、以及**中心扩散法最长回文子串**的标准 C++20 实现：

```cpp
#include <vector>
#include <string>
#include <string_view>
#include <array>
#include <algorithm>
#include <cstdint>

namespace Algorithm::StringTechniques {

// 1. 字符频率映射表应用：有效的字母异位词 (Valid Anagram)
[[nodiscard]] bool isAnagram(std::string_view s, std::string_view t) noexcept {
    if (s.length() != t.length()) return false;

    std::array<int, 26> freq{};
    freq.fill(0);

    for (size_t i = 0; i < s.length(); ++i) {
        freq[static_cast<size_t>(s[i] - 'a')]++;
        freq[static_cast<size_t>(t[i] - 'a')]--;
    }

    return std::all_of(freq.begin(), freq.end(), [](int count) { return count == 0; });
}

// 2. 多项式滚动哈希封装类 (Polynomial Rolling Hash Class)
class StringHash {
private:
    static constexpr uint64_t B = 131; // 基数 Base
    std::vector<uint64_t> H;
    std::vector<uint64_t> P;           // 预计算 B 的幂次

public:
    explicit StringHash(std::string_view s) {
        const size_t n = s.length();
        H.resize(n + 1, 0);
        P.resize(n + 1, 1);

        for (size_t i = 0; i < n; ++i) {
            P[i + 1] = P[i] * B; // 利用 uint64_t 2^64 自然溢出代替取模
            H[i + 1] = H[i] * B + static_cast<uint64_t>(s[i]);
        }
    }

    // O(1) 查询子串 s[L..R] 的哈希值 (0-based)
    [[nodiscard]] uint64_t getSubstrHash(size_t L, size_t R) const noexcept {
        return H[R + 1] - H[L] * P[R - L + 1];
    }
};

// 3. 中心扩散法寻找最长回文子串 (Longest Palindromic Substring)
class PalindromeFinder {
private:
    // 辅助扩张函数
    static std::pair<int, int> expandAroundCenter(std::string_view s, int left, int right) noexcept {
        while (left >= 0 && right < static_cast<int>(s.length()) && s[static_cast<size_t>(left)] == s[static_cast<size_t>(right)]) {
            --left;
            ++right;
        }
        // 退出时 left 和 right 多扩了一步，实际回文区间为 [left + 1, right - 1]
        return {left + 1, right - 1};
    }

public:
    [[nodiscard]] static std::string_view longestPalindrome(std::string_view s) noexcept {
        if (s.empty()) return {};

        int start = 0;
        int max_len = 0;

        for (int i = 0; i < static_cast<int>(s.length()); ++i) {
            // 奇数长度中心: (i, i)
            auto [l1, r1] = expandAroundCenter(s, i, i);
            if (r1 - l1 + 1 > max_len) {
                max_len = r1 - l1 + 1;
                start = l1;
            }

            // 偶数长度中心: (i, i + 1)
            auto [l2, r2] = expandAroundCenter(s, i, i + 1);
            if (r2 - l2 + 1 > max_len) {
                max_len = r2 - l2 + 1;
                start = l2;
            }
        }

        return s.substr(static_cast<size_t>(start), static_cast<size_t>(max_len));
    }
};

} // namespace Algorithm::StringTechniques
```

## 3. 🔍 状态跟踪与图解分析

输入 `s = "babad"`，中心扩散法全过程扫描追踪：

| 步骤 | 选定中心 (`left`, `right`) | 中心类型 | 向外扩散步演轨迹 | 找到的合规回文 | 区间与长度 | `max_len` 更新 |
|---|---|---|---|---|---|---|
| 1 | `(0, 0)` (指向 `'b'`) | 奇数 | `'b'` $\implies$ `left=-1` 止 | `"b"` | `[0, 0]`, len=1 | 1 (子串 `"b"`) |
| 2 | `(0, 1)` (`'b'`, `'a'`) | 偶数 | `'b' != 'a'` 立即止 | 无 | len=0 | 1 |
| **3** | `(1, 1)` (指向 `'a'`) | 奇数 | `s[1]=='a'` $\implies$ `s[0]=='b' == s[2]=='b'` $\implies$ `s[-1]` 越界止 | **`"bab"`** | **`[0, 2]`, len=3** | **3 (子串 `"bab"`)** |
| 4 | `(1, 2)` (`'a'`, `'b'`) | 偶数 | `'a' != 'b'` 立即止 | 无 | len=0 | 3 |
| **5** | `(2, 2)` (指向 `'b'`) | 奇数 | `s[2]=='b'` $\implies$ `s[1]=='a' == s[3]=='a'` $\implies$ `s[0]=='b' != s[4]=='d'` 止 | **`"aba"`** | **`[1, 3]`, len=3** | 3 (保留 `"bab"`) |
| 6 | `(2, 3)` (`'b'`, `'a'`) | 偶数 | `'b' != 'a'` 立即止 | 无 | len=0 | 3 |
| 7 | `(3, 3)` (指向 `'a'`) | 奇数 | `s[3]=='a'` $\implies$ `s[2]=='b' != s[4]=='d'` 止 | `"a"` | `[3, 3]`, len=1 | 3 |
| 8 | `(3, 4)` (`'a'`, `'d'`) | 偶数 | `'a' != 'd'` 立即止 | 无 | len=0 | 3 |
| 9 | `(4, 4)` (指向 `'d'`) | 奇数 | `s[4]=='d'` $\implies$ `right=5` 越界止 | `"d"` | `[4, 4]`, len=1 | 3 |

**输出**：最长回文子串为 `"bab"`（或 `"aba"`），长度为 3。

## 4. 📈 复杂度分析

### 1. 字符频率数组
- **时间复杂度**：$O(N)$（单次扫描）。
- **空间复杂度**：$O(1)$（仅固定使用 26 个 `int` 的数组）。

### 2. 字符串滚动哈希 (String Hash)
- **预处理**：$O(N)$ 时间与空间。
- **区间哈希查询**：$O(1)$ 时间复杂度。

### 3. 中心扩散法 (Expand Around Center)
- **时间复杂度**：$O(N^2)$。共有 $2N - 1$ 个中心，每个中心最坏扩散 $O(N)$ 次（例如字符串全为 `'a'`）。
- **空间复杂度**：$O(1)$ 辅助空间（远优于动态规划法的 $O(N^2)$ 矩阵空间）。

## 5. ⚠️ 常见坑点与边界条件

1. **字符串哈希碰撞 (Hash Collision)**
   - 使用单哈希（如仅靠 `uint64_t` 自然溢出）在极大数据集下（如 $N \ge 10^5$）容易遭受人为构造的哈希杀手数据（如 Anti-Hash Test Case）撞哈希。在严苛题目中推荐使用**双哈希（Double Hash）**（取两个不同大质数如 $10^9+7$ 与 $10^9+9$ 取模）。
2. **中心扩散法漏掉偶数长度回文**
   - 编写中心扩散法时，初学者经常只枚举 `(i, i)`（奇数长度），从而完全漏掉像 `"baab"` 这样的偶数回文。必须对 `(i, i)` 和 `(i, i+1)` 两种中心同时进行扩张。

## 6. 🧠 💡 Flashcards (Guided Recall)

Q: 字符串滚动哈希如何做到在 $O(1)$ 时间内获取任意子串 $[L, R]$ 的哈希值？
A: 预处理前缀哈希 $H[i]$ 与基数幂次 $P[i]$。子串哈希公式为 $\text{Hash}(L, R) = H[R+1] - H[L] \times P[R-L+1]$，通过将左前缀乘以对应的幂次在相同高位对齐后相减得出。

Q: 中心扩散法求最长回文子串的中心点共有多少个？为什么？
A: 共有 $2N - 1$ 个中心点。包含 $N$ 个以字符为中心的奇数回文中心，以及 $N-1$ 个以相邻字符间隙为中心的偶数回文中心。
