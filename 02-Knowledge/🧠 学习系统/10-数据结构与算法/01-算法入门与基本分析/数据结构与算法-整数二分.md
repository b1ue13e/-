## 1. 🎯 核心原理与两大模板剖析

**整数二分（Integer Binary Search）** 的本质是寻找**单调序列中满足某一判定条件的边界点**（如第一个 $\ge target$ 的位置，或最后一个 $\le target$ 的位置）。

在整数域上，由于数据存在最小离散单位 1，区间边界的开闭选择（闭区间 vs 半开区间）直接决定了循环终止条件与指针更新逻辑。

```
寻找目标元素 4 的 lower_bound 与 upper_bound:
数据:  [ 1 | 2 | 4 | 4 | 4 | 6 | 7 ]
索引:    0   1   2   3   4   5   6
                 ↑           ↑
        lower_bound(4)    upper_bound(4)
         (第一个 >=4)      (第一个 >4)
                 └───────────┘
                  区间长度 = upper_bound - lower_bound = 5 - 2 = 3
```

### 1.1 闭区间模板 `[left, right]`
- **区间定义**：搜索域为双闭区间 $[left, right]$。
- **初始赋值**：`left = 0, right = N - 1`。
- **循环条件**：`while (left <= right)`（当 `left == right` 时区间内仍有一个有效元素未检验）。
- **更新规则**：
  - 若排除左半边：`left = mid + 1`
  - 若排除右半边：`right = mid - 1`
- **循环终止**：退出循环时 `left = right + 1`，此时 `left` 指向第一个满足条件的元素位置。

### 1.2 左闭右开区间模板 `[left, right)`
- **区间定义**：搜索域为左闭右开区间 $[left, right)$，`right` 为开边界。
- **初始赋值**：`left = 0, right = N`。
- **循环条件**：`while (left < right)`（当 `left == right` 时区间为空 `[x, x)`，终止循环）。
- **更新规则**：
  - 若排除左半边：`left = mid + 1`
  - 若排除右半边：`right = mid`（因为 `right` 是开边界，不包含 `mid` 本身）。
- **循环终止**：退出循环时 `left == right`。

### 1.3 防溢出中点计算公式
传统写法 `mid = (left + right) / 2` 在 `left + right` 超出整型上限（例如 $2 \times 10^9 + 2 \times 10^9 = 4 \times 10^9 > \text{INT\_MAX}$）时会触发 **Integer Overflow** 变成负数，引发严重 Segfault。

在 C++ 中应使用无溢出算术写法或位运算写法：

$$\text{mid} = \text{left} + \frac{\text{right} - \text{left}}{2} \quad \text{或} \quad \text{mid} = \text{left} + ((\text{right} - \text{left}) \gg 1)$$

## 2. 📐 渐近分析与数学推导

对于长度为 $N$ 的数组：
- **解空间变化**：每一次迭代后，新解空间的长度 $L_{k+1} = \lfloor L_k / 2 \rfloor$。
- **最大迭代次数**：求解 $N / 2^k \le 1 \implies 2^k \ge N \implies k = \lceil \log_2 N \rceil$。
- **复杂度**：
  - 时间复杂度：$O(\log N)$（最坏、平均），$O(1)$（最好）。
  - 空间复杂度：迭代实现为 $O(1)$。

## 3. 💻 C++ 20 完整工程实现与测试

以下完整代码实现了自定义的 `lower_bound`（寻找首个 $\ge x$ 的索引）与 `upper_bound`（寻找首个 $> x$ 的索引），并验证重复元素频次统计：

```cpp
#include <iostream>
#include <vector>
#include <cassert>

using namespace std;

// 1. 闭区间模板实现 lower_bound: 寻找首个 arr[i] >= target 的索引
int custom_lower_bound(const vector<int>& arr, int target) {
    int left = 0;
    int right = static_cast<int>(arr.size()) - 1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] >= target) {
            right = mid - 1; // 尝试寻找更靠左的满足条件的索引
        } else {
            left = mid + 1;  // arr[mid] < target，必定在右半边
        }
    }
    return left; // 循环结束时 left 指向首个 >= target 的位置
}

// 2. 左闭右开模板实现 upper_bound: 寻找首个 arr[i] > target 的索引
int custom_upper_bound(const vector<int>& arr, int target) {
    int left = 0;
    int right = static_cast<int>(arr.size()); // 开边界
    
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] > target) {
            right = mid;     // 保留开边界为 mid
        } else {
            left = mid + 1;  // arr[mid] <= target，排除左半区包含 mid
        }
    }
    return left; // 循环结束时 left == right 指向首个 > target 的位置
}

// 3. 统计元素 target 在有序数组中出现的频次
int count_occurrences(const vector<int>& arr, int target) {
    int lb = custom_lower_bound(arr, target);
    // 边界安全校验：若 lb 超界或值不等于 target，说明不存在
    if (lb >= static_cast<int>(arr.size()) || arr[lb] != target) {
        return 0;
    }
    int ub = custom_upper_bound(arr, target);
    return ub - lb;
}

int main() {
    vector<int> nums = {1, 2, 4, 4, 4, 6, 7};

    // 测试 lower_bound (找首个 >= 4) -> 应返回索引 2
    int lb = custom_lower_bound(nums, 4);
    assert(lb == 2);
    cout << "[Lower Bound Test] Target 4 first appears at index: " << lb << endl;

    // 测试 upper_bound (找首个 > 4) -> 应返回索引 5 (值为 6)
    int ub = custom_upper_bound(nums, 4);
    assert(ub == 5);
    cout << "[Upper Bound Test] First element > 4 is at index: " << ub << " (Value: " << nums[ub] << ")" << endl;

    // 测试频次统计 -> 4 出现了 3 次
    int freq = count_occurrences(nums, 4);
    assert(freq == 3);
    cout << "[Frequency Test] Target 4 count: " << freq << endl;

    // 测试不存在元素的 lower_bound
    int lb_missing = custom_lower_bound(nums, 5);
    assert(lb_missing == 5); // 5 不存在，首个 >= 5 的元素是 6，索引 5

    return 0;
}
```

## 4. 📊 状态转换与推导步骤 Trace

### 算例：数组 `[1, 2, 4, 4, 4, 6, 7]` ($N=7$), 查找 Target = `4` 的 `lower_bound`

| 步骤 | `left` | `right` | `mid` | `arr[mid]` | `arr[mid] >= 4` | 动作 (Action) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Init | 0 | 6 | - | - | - | 闭区间 $[0, 6]$ |
| Step 1 | 0 | 6 | $0 + (6-0)/2 = 3$ | `arr[3] = 4` | True (4 >= 4) | `right = mid - 1 = 2` |
| Step 2 | 0 | 2 | $0 + (2-0)/2 = 1$ | `arr[1] = 2` | False (2 < 4) | `left = mid + 1 = 2` |
| Step 3 | 2 | 2 | $2 + (2-2)/2 = 2$ | `arr[2] = 4` | True (4 >= 4) | `right = mid - 1 = 1` |
| End | 2 | 1 | - | - | - | `left > right` (2 > 1), 退出循环，返回 `left = 2` |

## 5. ⚠️ 经典陷阱与边界防御

1. **混淆开闭区间导致的越界与死循环（Range Mismatch Bug）**：
   - *陷阱*：初始设 `right = arr.size() - 1`（闭区间），却写了 `while (left < right)`。当搜索目标为数组最大值且位于末尾时，循环会在 `left == right` 处提前终止，丢弃末位校验。
   - *防御*：严格配对规则：
     - 双闭区间：`right = n - 1` $\iff$ `while (left <= right)` $\iff$ `right = mid - 1`。
     - 左闭右开：`right = n` $\iff$ `while (left < right)` $\iff$ `right = mid`。

2. **直接解引用 `lower_bound` 结果造成段错误**：
   - *陷阱*：若 `target` 大于数组内所有元素，`lower_bound` 会返回 `N`（超界索引）。若直接访问 `arr[lb]` 会触发越界崩溃。
   - *防御*：解引用前必须校验 `if (lb < arr.size() && arr[lb] == target)`。

3. **`mid` 加法整数溢出（Overflow Hazard）**：
   - *陷阱*：在二分答案问题中，`left` 和 `right` 取值范围可能为 $10^9$ 或更大，`left + right` 溢出 `int` 范围。
   - *防御*：一律采用 `left + (right - left) / 2`。

## 🚨 常见误区与边界条件

1. **查找左边界 vs 右边界的 mid 向上取整**：
   - 查找答案在右半段（更新为 `left = mid`）：`mid` 必须设为 `(left + right + 1) // 2`，否则当 `left + 1 == right` 时会陷入死循环。
   - 查找答案在左半段（更新为 `right = mid`）：`mid` 设为 `(left + right) // 2`。

## 🃏 Anki 卡片

- Q: 整数二分中，防止 `left + right` 整数溢出的标准写法是什么？
- A: 写为 `mid = left + (right - left) / 2`，或者位运算写法 `mid = left + ((right - left) >> 1)`。
---
- Q: `std::lower_bound` 与 `std::upper_bound` 的核心判定条件有何本质区别？
- A: `lower_bound` 寻找的是**第一个满足 `arr[i] >= target`** 的位置；`upper_bound` 寻找的是**第一个满足 `arr[i] > target`** 的位置。
---
- Q: 双闭区间 `[left, right]` 模板中，为什么 `while` 循环判定条件必须是 `left <= right`？
- A: 因为当 `left == right` 时，区间内仍然包含一个元素 `arr[left]` 未被检查。若写成 `left < right`，该元素会被遗漏。
