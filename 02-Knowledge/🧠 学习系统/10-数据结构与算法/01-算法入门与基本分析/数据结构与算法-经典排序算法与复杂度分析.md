## 💡 问题动机与直观解析

排序（Sorting）是计算机科学中最基础的计算范式。排序不仅仅是“将乱序序列排列整齐”，它还是解决搜索、去重、凸包计算、最近点对等复杂问题的预处理基石。

根据算法性质，排序算法可分为两大流派：
1. **基于比较的排序 (Comparison-based Sorting)**：通过两两比较元素大小确定相对顺序（如冒泡、插入、快排、归并、堆排）。
2. **非比较/线性时间排序 (Non-comparison Sorting)**：利用元素值的整数/离散特征进行键值映射（如计数排序、基数排序、桶排序）。

## 📐 正式定义与核心定理

### 1. 经典排序算法对比矩阵

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 (Stability) | 核心算法思想 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **冒泡排序** | $\mathcal{O}(n^2)$ | $\mathcal{O}(n^2)$ | $\mathcal{O}(1)$ | 稳定 | 相邻交换，每轮将最大值浮至末尾 |
| **插入排序** | $\mathcal{O}(n^2)$ | $\mathcal{O}(n^2)$ | $\mathcal{O}(1)$ | 稳定 | 维护已排序前缀，小规模数据性能优异 |
| **快速排序** | $\mathcal{O}(n \log n)$ | $\mathcal{O}(n^2)$ | $\mathcal{O}(\log n)$ | 不稳定 | 随机 Pivot 划分 (Lomuto/Hoare) |
| **归并排序** | $\mathcal{O}(n \log n)$ | $\mathcal{O}(n \log n)$ | $\mathcal{O}(n)$ | 稳定 | 分治合并，二路归并，缓存友好 |
| **堆排序** | $\mathcal{O}(n \log n)$ | $\mathcal{O}(n \log n)$ | $\mathcal{O}(1)$ | 不稳定 | 大顶堆/小顶堆，Heapify 下沉调整 |
| **计数排序** | $\mathcal{O}(n + k)$ | $\mathcal{O}(n + k)$ | $\mathcal{O}(k)$ | 稳定 | 频次统计前缀和映射 |

### 2. 比较排序下界定理 (Lower Bound Theorem)

**定理**：任何在最坏情况下通过比较来确定 $n$ 个不同元素顺序的排序算法，其比较次数必然满足：
$$\Omega(n \log n)$$

**证明概述**：
包含 $n$ 个元素的序列共有 $n!$ 种可能的全排列。每一次两两比较形成二叉决策树（Decision Tree）的一个分支。决策树的叶子节点至少要有 $n!$ 个才能涵盖所有可能的排序结果。
高度为 $h$ 的二叉树叶子节点最多为 $2^h$。
由 $2^h \ge n!$，取对数得：
$$h \ge \log_2(n!) = \sum_{i=1}^n \log_2 i \ge \sum_{i=n/2}^n \log_2(n/2) = \frac{n}{2} \log_2\frac{n}{2} = \Omega(n \log n) \quad \blacksquare$$

## 💻 快速排序经典代码实现 (Lomuto Partition)

```python
import random

def quicksort(arr: list[int], low: int, high: int):
    if low < high:
        # 随机选择 Pivot 防范最坏 O(n^2) 情况
        pivot_idx = random.randint(low, high)
        arr[high], arr[pivot_idx] = arr[pivot_idx], arr[high]
        
        p = partition(arr, low, high)
        quicksort(arr, low, p - 1)
        quicksort(arr, p + 1, high)

def partition(arr: list[int], low: int, high: int) -> int:
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

## 🃏 Anki 卡片

- Q: 比较排序算法的最坏时间复杂度下界是多少？如何证明？
- A: $\Omega(n \log n)$。使用决策树模型，包含 $n!$ 种全排列的决策树树高 $h \ge \log_2(n!) = \Omega(n \log n)$。

- Q: 快速排序最坏时间复杂度为 $\mathcal{O}(n^2)$ 的原因是什么？如何避免？
- A: 当数组原本有序/逆序且每次固定选端点为 Pivot 时，划分为 $0$ 和 $n-1$ 个元素。通过**随机选择 Pivot** 或**三数取中法**可将期望复杂度保持在 $\mathcal{O}(n \log n)$。
