## 1. 🎯 快速排序核心机制与划分原理

快速排序（Quicksort）是由 C. A. R. Hoare 发明的经典分治算法。其核心物理逻辑是通过**枢轴（Pivot）划分**将原问题不断缩小：
1. **枢轴选择 (Pivot Selection)**：在当前数组区间中挑选一个元素作为基准（Pivot）。
2. **分区操作 (Partitioning)**：重新排列数组，使得所有小于等于 Pivot 的元素都被移到 Pivot 的左侧，所有大于等于 Pivot 的元素都被移到 Pivot 的右侧。分区完成后，Pivot 处于其最终全局有序的正确物理位置。
3. **递归求解 (Recurse)**：递归地对 Pivot 左侧与右侧的两个子区间分别重复上述过程。

在工程实现中，最经典的分区方案分为 **Lomuto 划分** 与 **Hoare 划分**，结合**三数取中法（Median-of-Three）**可彻底规避最坏情况退化。

## 2. 🔍 步骤跟踪 (Lomuto Partition Trace)

以输入数组 `[10, 7, 8, 9, 1, 5]`（长度 $n=6$）为例，采用三数取中确定 Pivot，演示 Lomuto 划分全过程：

```
初始状态: [10, 7, 8, 9, 1, 5], low = 0, high = 5
```

### 1. 三数取中 Pivot 选择 (Median-of-Three)
- 取 `low=0` (`10`), `mid=2` (`8`), `high=5` (`5`)。
- 中位数为 `8`。将 `8` 与末尾 `arr[high]` (`5`) 交换，数组变为 `[10, 7, 5, 9, 1, 8]`，此时 Pivot 位于末尾 `pivot = 8`。

### 2. Lomuto Partition 过程 (`low = 0, high = 5, pivot = 8`)
设置慢指针 $i = low - 1 = -1$，快指针 $j$ 从 $low$ 扫到 $high - 1$：
- $j = 0$ (`10`): $10 > 8 \implies$ 不移动。
- $j = 1$ (`7`): $7 \le 8 \implies i++ (i=0)$，交换 $arr[0]$ (`10`) 与 $arr[1]$ (`7`) $\implies$ `[7, 10, 5, 9, 1, 8]`。
- $j = 2$ (`5`): $5 \le 8 \implies i++ (i=1)$，交换 $arr[1]$ (`10`) 与 $arr[2]$ (`5`) $\implies$ `[7, 5, 10, 9, 1, 8]`。
- $j = 3$ (`9`): $9 > 8 \implies$ 不移动。
- $j = 4$ (`1`): $1 \le 8 \implies i++ (i=2)$，交换 $arr[2]$ (`10`) 与 $arr[4]$ (`1`) $\implies$ `[7, 5, 1, 9, 10, 8]`。
- **循环结束**：将 $arr[i+1]$ (`arr[3] = 9`) 与末尾 Pivot (`arr[5] = 8`) 交换 $\implies$ `[7, 5, 1, 8, 10, 9]`。

**分区输出**：Pivot `8` 正确落在下标 3 位置；左子数组 `[7, 5, 1]` 均 $\le 8$，右子数组 `[10, 9]` 均 $\ge 8$。

## 3. 📐 复杂度与退化避险证明

### 3.1 复杂度分析
1. **平均时间复杂度 $O(n \log n)$**：
   若每次划分 Pivot 都能将区间近似平分，递推式为 $T(n) = 2T(n/2) + \Theta(n)$，由主定理解得 $T(n) = \Theta(n \log n)$。

2. **最坏时间复杂度 $O(n^2)$**：
   当输入序列已经单调有序（或完全逆序），且固定选取最左端/最右端作为 Pivot 时，每次划分只能排除 1 个元素（产生 $0$ 和 $n-1$ 两个极度倾斜的子区间）。递推式变为：
   $$T(n) = T(n-1) + \Theta(n) \implies T(n) = \sum_{k=1}^n k = \frac{n(n+1)}{2} = \Theta(n^2)$$

3. **递归栈空间复杂度 $O(\log n)$ 保证**：
   在最坏倾斜划分下，递归深度可能退化为 $O(n)$，导致系统栈溢出（Stack Overflow）。
   **优化方案**：在递归时**优先递归处理较短的子区间**，对较长的子区间采用**尾递归消除（Tail Call Optimization）**，可以将最坏栈空间严格压制在 **$O(\log n)$**。

4. **不稳定性证明**：
   在分区过程中，快慢指针跨越 Pivot 进行大跨度交换（如将左侧大于 Pivot 的元素与右侧小于 Pivot 的元素互换），会破坏相同键值元素的相对位置。因此**快速排序是不稳定排序**。

## 4. 💻 C++20 完整实现代码（三数取中 + 尾递归优化）

```cpp
#include <iostream>
#include <vector>
#include <utility>
#include <cassert>

// 三数取中法选取枢轴
template <typename T>
size_t median_of_three(std::vector<T>& arr, size_t low, size_t high) {
    size_t mid = low + (high - low) / 2;
    if (arr[mid] < arr[low]) std::swap(arr[low], arr[mid]);
    if (arr[high] < arr[low]) std::swap(arr[low], arr[high]);
    if (arr[high] < arr[mid]) std::swap(arr[mid], arr[high]);
    // 此时 arr[mid] 为中位数，将其换至末尾 high 作为 pivot
    std::swap(arr[mid], arr[high]);
    return high;
}

// Lomuto 分区方案
template <typename T>
size_t lomuto_partition(std::vector<T>& arr, size_t low, size_t high) {
    median_of_three(arr, low, high);
    T pivot = arr[high];
    ssize_t i = static_cast<ssize_t>(low) - 1;

    for (size_t j = low; j < high; ++j) {
        if (arr[j] <= pivot) {
            i++;
            std::swap(arr[static_cast<size_t>(i)], arr[j]);
        }
    }
    std::swap(arr[static_cast<size_t>(i) + 1], arr[high]);
    return static_cast<size_t>(i + 1);
}

// 快速排序 (带短区间优先与尾递归优化)
template <typename T>
void quicksort_internal(std::vector<T>& arr, ssize_t low, ssize_t high) {
    while (low < high) {
        size_t p = lomuto_partition(arr, static_cast<size_t>(low), static_cast<size_t>(high));
        ssize_t pivot_idx = static_cast<ssize_t>(p);

        // 优先递归较小区间，将较大区间的处理留在 while 循环中（尾递归消除）
        if (pivot_idx - low < high - pivot_idx) {
            quicksort_internal(arr, low, pivot_idx - 1);
            low = pivot_idx + 1;
        } else {
            quicksort_internal(arr, pivot_idx + 1, high);
            high = pivot_idx - 1;
        }
    }
}

template <typename T>
void quicksort(std::vector<T>& arr) {
    if (arr.size() <= 1) return;
    quicksort_internal(arr, 0, static_cast<ssize_t>(arr.size()) - 1);
}

int main() {
    std::vector<int> data = {10, 7, 8, 9, 1, 5};
    quicksort(data);

    std::vector<int> expected = {1, 5, 7, 8, 9, 10};
    assert(data == expected);

    std::cout << "[快速排序测试] 排序成功: ";
    for (int v : data) std::cout << v << " ";
    std::cout << "\n";
    return 0;
}
```

## 5. ⚠️ 常见工程陷阱与边界坑点

1. **固定枢轴选取引发 $O(n^2)$ 性能灾难**  
   若固定总是选择首个元素（`arr[low]`）作为 Pivot，在面对完全有序或逆序的大数据集时，时间复杂度将急剧退化为 $O(n^2)$，引发严重的 CPU 瓶颈。必须采用三数取中法或随机化 Pivot。

2. **全等元素数组（All Equal Elements）下的死循环与死退化**  
   在数组所有元素全部相等（如 `[5, 5, 5, 5, 5]`）时，如果 Hoare 分区中没有在 `arr[i] == pivot` 时停止指针，指针会一直走到底，导致划分极度倾斜退化为 $O(n^2)$。三路划分（Three-way Partition / Dutch National Flag Algorithm）是解决全等元素的综合方案。

3. **递归未做尾递归优化引发 Stack Overflow**  
   若双侧子区间盲目递归调用，当遇到最坏退化场景时，递归栈帧深度可达 $n$，瞬间耗尽系统栈内存。

## 6. 🃏 闭卷自测考点 (Anki Card)

- Q: **为什么快速排序在最坏情况下时间复杂度会退化为 $O(n^2)$？如何通过枢轴选取策略规避？**
- A: 当数组有序或逆序且固定选择端点作为 Pivot 时，每次划分只能减少 1 个元素，产生 $n$ 层单侧倾斜递归树，比较次数为 $\frac{n(n-1)}{2}$，退化为 $O(n^2)$。通过“三数取中法”（Median-of-Three）或随机选择 Pivot，可确保概率上实现近乎均匀的二分，维持 $O(n \log n)$。

- Q: **如何保证快速排序的额外空间复杂度严格限制在 $O(\log n)$？**
- A: 在递归调用时，显式比较左右两个子区间的长度，优先对较短的子区间进行递归调用，对较长的子区间采用 `while` 循环改写（尾递归消除），从而保证调用栈的最大深度不会超过 $\log_2 n$。

- Q: **简述 Hoare 划分与 Lomuto 划分的核心差异。**
- A: Lomuto 划分使用单向快慢双指针（`j` 扫描，`i` 维护小于 Pivot 界限），代码简洁但元素交换次数较多；Hoare 划分采用双向对头指针向中间扫描，交换次数更少、效率更高，但边界逻辑极其敏感，稍微不慎极易引发死循环。

## 🚨 常见误头与边界条件

1. **退化为 $O(n^2)$**：顺序或逆序数组下，若总是选择首/尾元素作为 Pivot，递归树深度退化为 $n$。**解法**：采用随机化选择 Pivot 或三数取中法 (Median-of-Three)。
2. **重复元素死循环 / 倾斜**：当数组包含大量重复元素时，若分割逻辑未将与 Pivot 相等的元素均匀分配到两侧（例如使用单向扫描），会导致切分极度不平衡。**解法**：双指针相向扫描 (Hoare 分割) 或三路快排 (3-way Partition)。
