## 1. 🎯 核心原理与算法机制

数组的固定连续物理结构赋予了它极致的查找性能，但也限制了其在修改长度时的灵活度。在数组中进行**插入（Insertion）** 与 **删除（Deletion）** 操作时，为了维持连续内存无缝缝合的约束，必须对后续所有元素进行**整体平移（Element Shifting）**。

```
插入操作 (Insert value at index k):
原数组:  [ 10 | 20 | 30 | 40 | 50 | __ ]
索引:      0    1    2    3    4    5
Step 1: 倒序平移 (k 以后的元素向右挪一位)
         [ 10 | 20 | 30 | 30 | 40 | 50 ]
Step 2: 覆写目标位置 (arr[k] = val)
         [ 10 | 20 | 99 | 30 | 40 | 50 ]  (Size: 5 -> 6)

删除操作 (Delete index k):
原数组:  [ 10 | 20 | 99 | 30 | 40 | 50 ]
Step 1: 正序平移 (k+1 以后的元素向左挪一位)
         [ 10 | 99 | 30 | 40 | 50 | __ ]  (Size: 6 -> 5)
```

### 1.1 元素平移规则
1. **插入（Insert at $k$）**：
   - 必须**从后向前（Reverse Iteration）** 遍历：即从最后一个元素 $N-1$ 开始，依次执行 `arr[i+1] = arr[i]`，直到索引 $k$ 挪出空位。若正序复制，会造成后序元素被提前覆写毁坏。
2. **删除（Delete at $k$）**：
   - 必须**从前向后（Forward Iteration）** 遍历：从 $k+1$ 开始，依次执行 `arr[i-1] = arr[i]`，覆盖掉 $k$ 位置上的废弃值，直到最后一个元素。

### 1.2 边界校验策略
对数组操作的防御性编程（Defensive Programming）需强约束：
- 插入边界校验：$0 \le \text{index} \le N$ 且 $N < \text{Capacity}$。
- 删除边界校验：$0 \le \text{index} < N$ 且 $N > 0$。
- 随机访问安全：对比 `arr[i]`（无边界检查）与 `arr.at(i)`（带有 `std::out_of_range` 异常防护）。

## 2. 📐 渐近分析与数学推导

假设数组当前包含 $N$ 个元素。

### 2.1 插入操作复杂度推导
假设插入到位置 $k \in [0, N]$ 的概率均匀分布 $P(k) = \frac{1}{N+1}$。
在位置 $k$ 插入需要平移的元素个数为 $N - k$ 次。
期望平移次数为：

$$\mathbb{E}[\text{Shifts}] = \sum_{k=0}^N P(k) \cdot (N - k) = \frac{1}{N+1} \sum_{k=0}^N (N - k) = \frac{1}{N+1} \cdot \frac{N(N+1)}{2} = \frac{N}{2}$$

- **最好时间复杂度**：$O(1)$（在尾部 $k=N$ 插入，平移 0 次）。
- **最坏时间复杂度**：$O(N)$（在头部 $k=0$ 插入，平移 $N$ 次）。
- **平均时间复杂度**：$O(N)$（平均平移 $N/2$ 次）。

### 2.2 删除操作复杂度推导
假设删除位置 $k \in [0, N-1]$ 的概率均匀分布 $P(k) = \frac{1}{N}$。
删除位置 $k$ 需要左移覆盖的元素个数为 $N - 1 - k$ 次。
期望平移次数为：

$$\mathbb{E}[\text{Shifts}] = \frac{1}{N} \sum_{k=0}^{N-1} (N - 1 - k) = \frac{N-1}{2}$$

- **最好/最坏/平均时间复杂度**：最好 $O(1)$（删除尾部），最坏 $O(N)$（删除头部），平均 $O(N)$。

## 3. 💻 C++ 20 完整工程实现与测试

以下代码实现了一个带完整边界校验、支持泛型、安全增删改查的 `CustomArray` 类：

```cpp
#include <iostream>
#include <stdexcept>
#include <cassert>
#include <algorithm>

template <typename T, size_t Capacity>
class CustomArray {
private:
    T data[Capacity];
    size_t sz = 0;

public:
    CustomArray() = default;

    // 获取当前元素个数
    [[nodiscard]] size_t size() const noexcept { return sz; }
    [[nodiscard]] size_t capacity() const noexcept { return Capacity; }

    // 在指定索引 pos 插入 value
    void insert(size_t pos, const T& value) {
        if (sz >= Capacity) {
            throw std::overflow_error("[CustomArray] Error: Capacity limit reached!");
        }
        if (pos > sz) { // 注意：pos == sz 属于在末尾追加，合法
            throw std::out_of_range("[CustomArray] Error: Insert position out of bounds!");
        }

        // 倒序平移，防止覆写数据
        for (size_t i = sz; i > pos; --i) {
            data[i] = std::move(data[i - 1]);
        }
        data[pos] = value;
        ++sz;
    }

    // 删除指定索引 pos 的元素
    T remove(size_t pos) {
        if (sz == 0) {
            throw std::underflow_error("[CustomArray] Error: Array is empty!");
        }
        if (pos >= sz) {
            throw std::out_of_range("[CustomArray] Error: Remove position out of bounds!");
        }

        T removed_val = std::move(data[pos]);
        // 正序平移，覆盖旧值
        for (size_t i = pos; i + 1 < sz; ++i) {
            data[i] = std::move(data[i + 1]);
        }
        --sz;
        return removed_val;
    }

    // 按值查找第一个出现的索引，无则返回 -1
    long long find(const T& value) const noexcept {
        for (size_t i = 0; i < sz; ++i) {
            if (data[i] == value) return static_cast<long long>(i);
        }
        return -1;
    }

    // 安全随机访问 (带边界防护)
    T& at(size_t index) {
        if (index >= sz) {
            throw std::out_of_range("[CustomArray] Error: Access index out of range!");
        }
        return data[index];
    }

    const T& at(size_t index) const {
        if (index >= sz) {
            throw std::out_of_range("[CustomArray] Error: Access index out of range!");
        }
        return data[index];
    }
};

int main() {
    CustomArray<int, 10> arr;

    // 1. 测试尾部插入与任意位置插入
    arr.insert(0, 10); // [10]
    arr.insert(1, 20); // [10, 20]
    arr.insert(2, 30); // [10, 20, 30]
    arr.insert(3, 40); // [10, 20, 30, 40]
    arr.insert(4, 50); // [10, 20, 30, 40, 50]

    assert(arr.size() == 5);

    // 2. 测试在索引 2 插入 99
    arr.insert(2, 99); // 应为 [10, 20, 99, 30, 40, 50]
    assert(arr.at(2) == 99);
    assert(arr.at(3) == 30);
    assert(arr.size() == 6);
    std::cout << "[Test Pass] Successfully inserted 99 at index 2." << std::endl;

    // 3. 测试删除索引 1 处元素 (删除 20)
    int removed = arr.remove(1);
    assert(removed == 20);
    assert(arr.at(1) == 99); // 原索引 2 的 99 前移到索引 1
    assert(arr.size() == 5);
    std::cout << "[Test Pass] Successfully removed element 20 from index 1." << std::endl;

    // 4. 测试边界防护异常捕获
    try {
        arr.at(100);
    } catch (const std::out_of_range& e) {
        std::cout << "[Boundary Protection Triggered] " << e.what() << std::endl;
    }

    return 0;
}
```

## 4. 📊 状态转换与推导步骤 Trace

### 示例: 初始数组 `[10, 20, 30, 40, 50]`（Size = 5），在 `pos = 2` 插入 `99`

| 步骤 | 循环变量 `i` | 执行指令 | 数组内存状态 (Array Buffer State) |
| :--- | :--- | :--- | :--- |
| 0 (Initial) | - | - | `[10, 20, 30, 40, 50,  _ ]` (size=5) |
| 1 | `i = 5` | `data[5] = data[4]` | `[10, 20, 30, 40, 50, 50]` |
| 2 | `i = 4` | `data[4] = data[3]` | `[10, 20, 30, 40, 40, 50]` |
| 3 | `i = 3` | `data[3] = data[2]` | `[10, 20, 30, 30, 40, 50]` |
| Loop End | `i == 2` | 循环终止 | 空出索引 2 位置 |
| Final Write | - | `data[2] = 99` | `[10, 20, 99, 30, 40, 50]` (size=6) |

## 5. ⚠️ 经典陷阱与边界防御

1. **正序平移导致数据覆写（Insertion Order Inversion Bug）**：
   - *陷阱*：插入时若误从 `i = pos` 开始正序赋值：`data[i+1] = data[i]`，则 `data[pos]` 的值会被连续覆盖到整个后续数组中，导致原数组数据丢失。
   - *防御*：严格谨记“插入倒序移，删除正序移”。

2. **无符号整型 `size_t` 减法下溢（Unsigned Underflow）**：
   - *陷阱*：在编写倒序平移循环时，使用 `for (size_t i = sz - 1; i >= pos; --i)`。当 `pos == 0` 时，在 `i = 0` 阶段执行 `--i` 后，`i` 不会变为 `-1`，而是直接溢出回无符号数最大值 `SIZE_MAX`，从而触发死循环及段错误（Segmentation Fault）。
   - *防御*：采用 `for (size_t i = sz; i > pos; --i)` 的控制条件，循环体内使用 `data[i] = data[i-1]`。

3. **插入与删除边界条件混淆（Off-by-One Boundary Errors）**：
   - *陷阱*：误将插入的上限设为 `pos < sz`，导致无法在数组最末尾（`pos == sz`）追加元素；或将删除的上限设为 `pos <= sz`，引发 `sz` 索引处越界读写。
   - *防御*：插入允许 `pos == sz`；删除必须 `pos < sz`。

## 6. 🃏 闭卷自测与 Anki 卡片

### 闭卷自测考点
- **问答**：如果在一个无序数组中，我们不在乎元素的原始顺序，如何将插入和删除操作的时间复杂度均降低至 $O(1)$？
- **标准解答**：
  - **$O(1)$ 插入**：直接追加到数组末尾 `arr[sz++] = val`。
  - **$O(1)$ 删除**：将要删除的索引 `pos` 处元素与当前最后一个元素 `arr[sz-1]` 进行交换或覆盖（`arr[pos] = arr[sz-1]`），然后执行 `sz--`，完全免去整块元素的平移过程。

## 🚨 常见误区与边界条件

1. **插入/删除时间复杂度**：数组尾部插入/删除为 $O(1)$，但头部或中间插入/删除需搬运后续所有元素，复杂度为 $O(n)$。
2. **动态扩容开销**：动态数组（如 Python `list`、C++ `std::vector`）扩容时需申请新空间并拷贝原数组，扩容因子通常取 1.5 或 2.0，均摊复杂度为 $O(1)$，但单次扩容点有显著延迟。

## 🃏 Anki 卡片

- Q: 数组在指定索引 $k$ 插入元素时，为什么平移循环必须“倒序遍历”？
- A: 倒序平移能先将靠后的元素挪移至新位置，防止后方数据被前面的元素提前覆写毁坏。
---
- Q: 为什么在 C++ 中使用无符号数 `size_t` 编写倒序循环 `for (size_t i = sz - 1; i >= 0; --i)` 是严重错误？
- A: `size_t` 为无符号数，`0 - 1` 会下溢环绕变成 `SIZE_MAX`，导致 `i >= 0` 永远成立从而引发死循环与越界访问崩溃。
---
- Q: 推导大小为 $N$ 的数组在随机位置插入元素的平均平移次数与时间复杂度。
- A: 平均平移次数为 $\frac{1}{N+1}\sum_{k=0}^N (N-k) = \frac{N}{2}$ 次，对应平均时间复杂度为 $O(N)$。
