## 💡 问题动机与直观解析

带权图（Weighted Graph）的最短路径问题是导航定位、网络路由协议 (OSPF/BGP) 及物流规划的核心数学模型。

所有最短路径算法的共同底层支撑机制是**松弛操作 (Relaxation)**：
对于边 $(u, v, w)$，如果经由 $u$ 到达 $v$ 的路径比当前记录的 $dist[v]$ 更短，则更新：
$$\text{if } dist[u] + w < dist[v]: dist[v] = dist[u] + w$$

---

## 📐 三大最短路径算法对比矩阵

| 算法 | 问题类型 | 边权限制 | 算法策略/思想 | 时间复杂度 |
| :--- | :--- | :--- | :--- | :--- |
| **Dijkstra** | 单源最短路 | 边权**必须全为非负数** ($w \ge 0$) | 贪心 + 小顶堆优先队列 | $\mathcal{O}((|V| + |E|) \log |V|)$ |
| **Bellman-Ford / SPFA** | 单源最短路 | 允许负权边，可检测负权环 | 动态规划 / 队列优化松弛 | $\mathcal{O}(|V| \cdot |E|)$ (SPFA 期望 $\mathcal{O}(k |E|)$) |
| **Floyd-Warshall** | 全源最短路 | 允许负权边，不能有负环 | 动态规划三重循环 (中继点 $k$) | $\mathcal{O}(|V|^3)$ |

## 💻 堆优化 Dijkstra 算法 C++ / Python 实现

```python
import heapq

def dijkstra(graph: dict[int, list[tuple[int, int]]], start: int, n: int) -> list[int]:
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)] # (distance, node)
    
    while pq:
        d, u = heapq.heappop(pq)
        
        # 懒惰删除：若弹出距离大于当前最优记录，忽略
        if d > dist[u]:
            continue
            
        for v, weight in graph.get(u, []):
            if dist[u] + weight < dist[v]:
                dist[v] = dist[u] + weight
                heapq.heappush(pq, (dist[v], v))
                
    return dist
```

## 📝 检索练习与自测题

1. **思考题**：为什么当图中存在负权边时，Dijkstra 算法会失效？（因为 Dijkstra 的贪心策略假设“一旦某个节点从优先队列弹出，其最短路径已被确定”，而负权边打破了这一单调递增的前提）。
2. **算法推导**：Floyd-Warshall 算法的 DP 状态转移方程 $d[k][i][j]$ 中，中继点 $k$ 的循环为什么必须放在最外层？

## 🃏 Anki 卡片

- Q: 为什么 Dijkstra 算法要求图中所有边的权值非负？
- A: 贪心选择的前提是路径长度随着边数单调非递减。若存在负权边，已弹出的节点距离可能被后序更长路径加上负权而破坏。
