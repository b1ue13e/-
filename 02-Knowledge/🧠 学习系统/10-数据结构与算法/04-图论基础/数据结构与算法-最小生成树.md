## 💡 问题动机与直观解析

对连通无向带权图 $G = (V, E)$，**生成树 (Spanning Tree)** 是包含了 $G$ 中所有 $|V|$ 个顶点且仅有 $|V|-1$ 条边构成的无环树状子图。

**最小生成树 (Minimum Spanning Tree, MST)** 是指所有生成树中**边权之后最小**的生成树。它在电路板布线、光纤管道铺设、城市道路网规划中是降本增效的核心数学模型。

---

## 📐 算法原理与切分定理 (Cut Property)

所有 MST 贪心算法的基础是**切分定理**：

**定理**：将图顶点集 $V$ 切割划分为两个不相交的非空子集 $S$ 与 $V \setminus S$。若边 $e = (u, v)$ 是所有跨越该切分（即 $u \in S, v \in V \setminus S$）的边中权值**严格最小的边**（轻边 / Light Edge），则边 $e$ 必然属于图 $G$ 的某棵最小生成树。

### 两大算法流派

1. **Kruskal 算法（加边法）**：
   - 将所有边按权值升序排序。
   - 配合**并查集 (DSU)** 依次挑选最小边，若边的两端节点不在同一连通分量，则加入 MST。
   - 时间复杂度：$\mathcal{O}(|E| \log |E|)$，适合稀疏图。
2. **Prim 算法（加点法）**：
   - 从任意源点出发，维护当前生成树节点集 $S$。
   - 配合**优先队列**每次挑选离集合 $S$ 最近的未访问节点加入。
   - 时间复杂度：堆优化后为 $\mathcal{O}(|E| \log |V|)$，适合稠密图。

## 💻 Kruskal 算法 Python 代码实现

```python
def kruskal(n: int, edges: list[tuple[int, int, int]]) -> int:
    # edges 形式为 (u, v, weight)
    edges.sort(key=lambda x: x[2]) # 按权值升序排序
    
    parent = list(range(n))
    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]

    mst_weight = 0
    edges_count = 0

    for u, v, w in edges:
        root_u, root_v = find(u), find(v)
        if root_u != root_v:
            parent[root_u] = root_v
            mst_weight += w
            edges_count += 1
            if edges_count == n - 1:
                break
                
    return mst_weight if edges_count == n - 1 else -1
```

## 🃏 Anki 卡片

- Q: Kruskal 算法与 Prim 算法的核心区别是什么？各适合什么场景？
- A: Kruskal 按边权排序用并查集避环，适合稀疏图 $\mathcal{O}(E \log E)$；Prim 从节点集向外扩张，结合堆优化适合稠密图 $\mathcal{O}(E \log V)$。
