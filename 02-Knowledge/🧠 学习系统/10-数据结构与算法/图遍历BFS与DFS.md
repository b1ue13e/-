# 图遍历BFS与DFS

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：图遍历是从"数据结构"跨入"图算法"的分水岭（6.006 Lec 9/10）：BFS 是[[Dijkstra最短路径]]的直接前身，DFS 是拓扑排序、连通分量与后续 DP 的基础；HW03 官方 PS5 全部围绕它。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：图（[[知识地图/图结构|图结构]]）给我们的是一堆节点和边，但"从 A 能到哪些节点？到 B 最短几步？按什么顺序处理？"没有现成答案——需要一种**系统性探索方法**，保证每个节点恰好访问一次、不重不漏，并留下探索信息（层级、时间戳）。因此必须引入两种遍历范式：**BFS（广度优先）**像水波逐层扩散、先近后远；**DFS（深度优先）**像走迷宫一条路走到黑再回头。它们回答不同问题，但共享骨架：**标记已访问 + 按策略展开邻居**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：BFS 是"无权图最短路径"解法，也是 Dijkstra 把"步数"换成"权重"的推广；DFS 的时间戳与后序是拓扑排序、SCC、DAG 上动态规划（[[动态规划入门]]）的顺序来源。HW03 PS5 直接考查。
- **实际应用场景**：社交网络"几度人脉"、迷宫最短路（BYOW）、网页爬虫、编译依赖拓扑排序。高频题型：手算访问序与时间戳、连通性/二分性判断、拓扑排序、找环。

---

## 3. 学它之前需要哪些前置知识？

1. **[[知识地图/栈与队列|栈与队列]]**：BFS 用队列（FIFO=按层）、DFS 用栈（LIFO=深入）；顺序语义决定遍历行为。
2. **[[知识地图/递归|递归]]**：DFS 递归实现（隐式调用栈）是标准写法；**[[知识地图/图结构|图结构]]**：邻接表/矩阵；加 **[[知识地图/复杂度分析|复杂度分析]]** 推导 $O(V+E)$。

---

## 4. 用直觉语言解释它

> «"BFS 就像往池塘扔石子：水波一圈圈外推，先到的是近的——所以第一次碰到目标时路径一定最短。DFS 就像迷宫探险：选一条路走到底，走不通就原路退回岔路口换一条——所以它能摸清整片区域的完整结构，还能记录每步的进入/离开时刻。"»

- **直觉类比/几何图像**：BFS=水波纹（层级同心圆）；DFS=迷宫回溯（一路到底 + 回溯）。
- **为什么很自然**："先访问的邻居先被扩展"（队列）自然产生层级；"后进先出"（栈/递归）自然产生深度——都是"用容器控制探索节奏"的直接结果。
- **一句话直觉本质**：**BFS 用队列按"距离"分层探索，首次到达即最短；DFS 用栈/递归深度优先推进，用进入/离开时间戳完整记录图的结构。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **BFS**：从源点 $s$ 按"与 $s$ 的距离"逐层访问，用队列维护"已发现未访问"节点；BFS 树中 $s\to v$ 的路径长度即最短距离 $\delta(s,v)$。
- **DFS**：尽可能深地前进、无路可走时回溯，用递归（或显式栈）实现，记录每个节点的**发现时间 $d[v]$** 与**完成时间 $f[v]$**。
- **括号定理**：DFS 中任意两节点 $u,v$ 的区间 $[d[u],f[u]]$ 与 $[d[v],f[v]]$ 要么互不相交，要么一个完全包含另一个。

### 2. 核心公式
$$T_{\text{BFS}} = O(V+E),\qquad T_{\text{DFS}} = O(V+E)$$
BFS 层性质：$v$ 在 BFS 树第 $k$ 层 $\Leftrightarrow$ $\delta(s,v)=k$，且距离 $k$ 的节点都在距离 $k+1$ 的节点之前被访问。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $V, E$ | 节点数、边数 | 非负整数 | 复杂度以两者计 |
| $s$ | 源点 | $\in V$ | 遍历起点 |
| $\delta(s,v)$ | 无权图最短距离 | 非负整数 | BFS 输出 |
| $d[v], f[v]$ | DFS 发现/完成时间 | $1..2V$ | 时间戳 |

### 4. 常见变体与适用条件
- **变体**：多源 BFS、双向 BFS、迭代加深（IDDFS）、DFS 边分类（树边/前向/后向/横叉边）。
- **适用条件**：BFS 适用无权（或等权）最短路与层级问题；DFS 适用结构分析（环、拓扑序、连通分量）。限制条件：BFS 在带权图上不保证最短（需 [[Dijkstra最短路径]]）；DFS 求最短路径无保证。

---

## 6. 推导思路和思想来源

- **最初困难**：图无天然线性顺序，随便走会漏节点、在环上死循环；朴素"递归访问邻居"在环上无限循环，需要"标记已访问"终止。
- **关键"转念"**：**把"访问过"变成状态（白/灰/黑），把探索顺序交给容器**——队列给层级、栈给深度；BFS 的"首次到达即最短"来自队列 FIFO 的距离单调性。
- **推导主线与动机**：标记解决环 → 队列逐层扩散得 BFS（$d[v]=d[u]+1$ 当首次发现）→ 归纳证明 $d[v]=\delta(s,v)$ → 栈/递归深入得 DFS → 记录 $d/f$ → 括号定理刻画子树 → 完成时间降序 = 拓扑排序（DAG 上）。
- **为什么自然得到此结论**："先发现先处理"（队列）与"后进先出"（栈）是最基本的调度纪律，遍历只是把纪律执行到底。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：有向图 $s\to a, s\to b, a\to c, b\to c, c\to d$。从 $s$ 跑 BFS 写队列变化与距离；再跑 DFS 写 $d/f$（按字母序访问邻居）。
- **解题思路与关键步骤**：BFS：出 $s$ 入 $a,b$；出 $a$ 入 $c$；出 $b$（$c$ 已访问跳过）；出 $c$ 入 $d$。距离 $s:0, a:1, b:1, c:2, d:3$；BFS 树 $s\to\{a,b\}, a\to c, c\to d$。DFS：$d[s]=1,f[s]=10$；链 $s\to a\to c\to d$ 上 $a=(2,7), c=(3,6), d=(4,5)$；回 $s$ 后访问 $b$：$b=(8,9)$。
- **易错点**：时间戳"进一次出一次"共 $2V$ 个；$b\to c$ 是横叉边（$c$ 已完成、非 $b$ 后代）；若 $c$ 未完成则是后向边（环）。
- **🤔 追问**：$f$ 降序是什么？——拓扑排序：$s,b,a,c,d$（$b\to c$ 强制 $b$ 在 $c$ 前，$a$ 与 $b$ 可互换），正是 DAG 上 DP 的计算顺序。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：判断无向图是否二分图（可二染色），BFS 还是 DFS？
- **解题思路与完整解答**：两者皆可，BFS 更直观：源点染 0，逐层交替染色，发现同色边即非二分图。核心：二分图 $\Leftrightarrow$ 无奇环；奇环必在某层内产生同色冲突。复杂度 $O(V+E)$。
- **易错点**：图可能不连通——每个连通分量都要单独起染；单源会漏判。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：BYOW 迷宫最短路、社交网络人脉、编译器依赖拓扑排序都是 BFS/DFS 落地。代码形态：
```python
from collections import deque

def bfs_dist(adj, s):                        # 无权图最短路
    dist = {s: 0}; q = deque([s])
    while q:
        u = q.popleft()
        for v in adj.get(u, []):
            if v not in dist: dist[v] = dist[u] + 1; q.append(v)
    return dist

def topological_sort(adj, V):                # Kahn：入度表 + 队列
    indeg = {v: 0 for v in range(V)}
    for u in adj:
        for v in adj[u]: indeg[v] += 1
    q = deque([v for v in range(V) if indeg[v] == 0])
    order = []
    while q:
        u = q.popleft(); order.append(u)
        for v in adj.get(u, []):
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return order if len(order) == V else None  # None = 有环
```

## 8. 常见误区和易混概念

### 误区 1：以为"DFS 也能求最短路径"
- **错误直觉**：DFS 遍历了所有节点，第一次碰到目标就是最短。
- **为什么错**：DFS 深入优先，首次碰到目标可能走了弯路；没有 BFS 的"层级单调"性质。正确理解：无权最短路径默认 BFS；DFS 的用武之地是结构分析（拓扑序、环、SCC）。

### 误区 2：把"visited 标记"与"路径记录"混为一谈
- **错误直觉**：标记了 visited 就能输出路径。
- **为什么错**：visited 只保证不重复访问；输出路径需要额外记录前驱（parent 数组），且只有 BFS 的 parent 链是最短路径。
- **正确理解**：遍历 = 访问序；路径 = 前驱链；两者是不同信息（6.006 PS5 考过"只给 visited 不给 parent 如何改造"）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| BFS | 无权最短路/层级 | 队列、首次发现即最短 | 迷宫最短路、社交层级 |
| DFS | 结构分析 | 栈/递归、时间戳 | 拓扑排序、环检测、SCC |
| [[并查集]] | 动态连通性 | 只答"是否连通"，无路径 | Kruskal、动态加边 |
| [[Dijkstra最短路径]] | 带权最短路 | 优先队列、贪心 | 地图导航 |

### 题目与解析

#### 1. 为什么 BFS 第一次发现 $v$ 时记录的 $d[v]$ 一定是最短距离？
> [!question]- 答案解析
> - **答案**：队列 FIFO 保证队列中节点距离单调不减；若存在更短路径，其节点会在更早层被访问并逐层传播，使 $v$ 更早被发现，矛盾。解析：先证 $d[v]\ge\delta(s,v)$（每条边至多 +1），再证 $d[v]\le\delta(s,v)$（沿最短路径逐层传播）。易错：讲不出"距离单调"这个关键。标签：`#自测题/基础`

#### 2. 对例子 1 的图写出 BFS 的 $d$ 数组与 DFS 的 $f$ 时间戳，并验证 $c,d$ 满足括号定理。
> [!question]- 答案解析
> - **答案**：$d: s=0,a=1,b=1,c=2,d=3$；$[d[c],f[c]]=[3,6]$、$[d[d],f[d]]=[4,5]$，$[4,5]\subset[3,6]$ 且 $d$ 是 $c$ 的子孙——包含关系成立。解析：$d$ 是 $c$ 的后代 $\Leftrightarrow$ 区间被完全包含，即括号定理。易错：发现/完成顺序写反。

#### 3. 何时用邻接表、何时用邻接矩阵？
> [!question]- 答案解析
> - **答案**：稀疏图（$E\ll V^2$）用邻接表（空间 $O(V+E)$、遍历 $O(V+E)$）；稠密图或需 $O(1)$ 判"$u,v$ 是否有边"时用矩阵（空间 $O(V^2)$）。解析：判边频率决定选型——频繁判边的算法（如 Floyd）才值得矩阵；6.006 默认邻接表。易错：忽略判边操作频率。

#### 4. DFS 逆后序与 Kahn 算法实现拓扑排序有何区别？
> [!question]- 答案解析
> - **答案**：DFS 逆后序：按完成时间降序输出（正确性来自 $u\to v$ 有边则 $f[v]<f[u]$）；Kahn：反复删除入度为 0 的节点。均 $O(V+E)$；Kahn 能直接检测环（输出不足 $V$ 个即有环）且无递归栈溢出；DFS 版更简洁。易错：把 DFS 前序当拓扑序；忘记 DAG 前提。

#### 5. 证明括号定理：任意两节点 $u,v$ 的区间 $[d[u],f[u]]$、$[d[v],f[v]]$ 要么不相交，要么一个完全包含另一个。
> [!question]- 答案解析
> - **答案**：设 $d[u]<d[v]$。① 若 $d[v]<f[u]$：$v$ 在 $u$ 未完成时被发现，必在 $u$ 的 DFS 子树内，故 $f[v]<f[u]$，区间包含；② 若 $d[v]>f[u]$：两区间不相交。$d[v]<d[u]$ 对称。解析：核心引理"DFS 子树 = 发现与完成之间的节点集"（CLRS 22.7）；它也是边分类、白色路径定理的公共基础。易错：不先建立子树引理就硬证。
