# 堆与堆排序 (Heap and Heapsort)

## 1. 堆的定义与核心性质

**堆与堆排序 (Heap and Heapsort)** 中，堆的核心定义是：一种满足**堆性质 (Heap Property)** 的完全二叉树，通常用数组紧凑表示（无需存储指针）：

- **最大堆 (Max-Heap)**：对树中任意结点 $i$，有 $A[i] \geq A[\text{left}(i)]$ 且 $A[i] \geq A[\text{right}(i)]$；
- **最小堆 (Min-Heap)**：$A[i] \leq A[\text{left}(i)]$ 且 $A[i] \leq A[\text{right}(i)]$。

**数组索引映射（1-based）**：父 $=\lfloor i/2 \rfloor$，左孩子 $= 2i$，右孩子 $= 2i+1$。

**基本性质**：含 $n$ 个元素的完全二叉树高度 $h = \lfloor \log_2 n \rfloor$，因此 `MAX-HEAPIFY` 的时间复杂度为 $O(\log n)$。

---

## 2. BUILD-MAX-HEAP 复杂度形式化推导

**定理**：BUILD-MAX-HEAP 时间复杂度为 $O(n)$（非 $O(n \log n)$）。

**假设**：对 $n$ 个元素自底向上从 $\lfloor n/2 \rfloor$ 到 1 调用 `MAX-HEAPIFY`，高度为 $h$ 处的子树最多 $\lceil n/2^{h+1} \rceil$ 个。

**推导**：
$$T = \sum_{h=0}^{\lfloor \log n \rfloor} \left\lceil \frac{n}{2^{h+1}} \right\rceil O(h) = O\!\left(n \sum_{h=0}^{\infty} \frac{h}{2^h}\right) = O(n \cdot 2) = O(n)$$

**堆排序流程（因此总复杂度 $O(n \log n)$）**：
1. `BUILD-MAX-HEAP(A)`：$O(n)$ 建堆
2. 循环 $n-1$ 次：堆顶换末尾，堆大小减 1，再 `MAX-HEAPIFY`：$O(\log n)$

---

## 3. 堆与其他优先队列的区别与对比

| 结构 | 插入 | 取最大值 | 建堆 | 实际应用 |
|:---|:---|:---|:---|:---|
| **二叉堆** | $O(\log n)$ | $O(\log n)$ | $O(n)$ | Python `heapq`、`PriorityQueue` |
| **斐波那契堆** | $O(1)$ 摊还 | $O(\log n)$ | $O(n)$ | Dijkstra 理论最优 |
| **有序数组** | $O(n)$ | $O(1)$ | $O(n \log n)$ | 小规模固定集合 |
| **红黑树** | $O(\log n)$ | $O(\log n)$ | $O(n \log n)$ | 需要遍历排序 |

## 4. Python 最大堆完整实现与堆排序验证

```python
from typing import List
import random

def max_heapify(arr: List[int], n: int, i: int) -> None:
    """
    维护最大堆性质 (0-based)
    假设: arr[2i+1] 和 arr[2i+2] 的子树已满足堆性质
    推导: 比较 arr[i], arr[left], arr[right]，下沉较小元素
    因此时间复杂度 O(log n)
    """
    largest = i
    left  = 2 * i + 1
    right = 2 * i + 2
    if left  < n and arr[left]  > arr[largest]: largest = left
    if right < n and arr[right] > arr[largest]: largest = right
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        max_heapify(arr, n, largest)

def build_max_heap(arr: List[int]) -> None:
    """O(n) 自底向上建堆"""
    n = len(arr)
    for i in range(n // 2 - 1, -1, -1):
        max_heapify(arr, n, i)

def heapsort(arr: List[int]) -> List[int]:
    """堆排序: O(n log n) 时间, O(1) 额外空间"""
    a = arr.copy()
    build_max_heap(a)
    for i in range(len(a) - 1, 0, -1):
        a[0], a[i] = a[i], a[0]
        max_heapify(a, i, 0)
    return a

if __name__ == "__main__":
    arr = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3]
    sorted_arr = heapsort(arr)
    assert sorted_arr == sorted(arr)

    assert heapsort([]) == []
    assert heapsort([42]) == [42]
    assert heapsort([2, 1]) == [1, 2]

    test = [5, 3, 8, 1, 9, 2, 7]
    build_max_heap(test)
    assert test[0] == 9

    random.seed(42)
    big = [random.randint(0, 10000) for _ in range(1000)]
    assert heapsort(big) == sorted(big)

    print(f"堆排序验证: {arr} -> {sorted_arr}")
    print("堆与堆排序全部单元测试成功！")
```
