# 数据结构与算法-字符串匹配算法

## 💡 问题动机与直观解析

在长度为 $n$ 的文本串 $S$ 中查找长度为 $m$ 的模式串 $P$ 是否存在及首次出现位置：
- 暴力算法 (Naive String Matcher) 当遇到失配时，文本指针需回退，最坏复杂度为 $\mathcal{O}(n \cdot m)$。
- **KMP 算法 (Knuth-Morris-Pratt)**：利用模式串 $P$ 自身的**最长相同前后缀 (Longest Proper Prefix/Suffix)** 信息，失配时文本指针**绝不回退**，仅移动模式串指针，复杂度优化至 $\mathcal{O}(n + m)$。
- **Rabin-Karp 算法**：利用**滚动哈希 (Rolling Hash)** 思想，以 $\mathcal{O}(1)$ 计算子串哈希值，实现快速过滤。

---

## 📐 算法原理与 KMP `next` 数组

### KMP 前缀函数 (Prefix Function)

定义 `next[i]` 为模式串子串 $P[0 \dots i]$ 中，既是真前缀也是真后缀的最长相同字符串长度。

当文本 $S[j]$ 与模式 $P[i]$ 发生失配时：
- 无需回退 $j$。
- 将模式指针滑动调整为 $i \gets next[i - 1]$，继续匹配。

---

## 💻 经典代码实现 (KMP 算法 Python)

```python
def kmp_search(text: str, pattern: str) -> list[int]:
    n, m = len(text), len(pattern)
    if m == 0:
        return []

    # 1. 构建 next 前缀数组
    next_arr = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = next_arr[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        next_arr[i] = j

    # 2. 匹配过程 (文本指针 i 绝不回退)
    matches = []
    j = 0
    for i in range(n):
        while j > 0 and text[i] != pattern[j]:
            j = next_arr[j - 1]
        if text[i] == pattern[j]:
            j += 1
        if j == m:
            matches.append(i - m + 1)
            j = next_arr[j - 1]
            
    return matches
```

## 🃏 Anki 卡片

- Q: KMP 算法为什么能做到文本指针不回退？
- A: 因为预先计算了模式串的 `next` 数组（最长相同前后缀），失配时利用模式串自身的对称性直接跳过已知匹配部分。
