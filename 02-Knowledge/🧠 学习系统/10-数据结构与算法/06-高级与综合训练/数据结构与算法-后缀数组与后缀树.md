# 数据结构与算法-后缀数组与后缀树

> **摘要**：后缀数组（Suffix Array, SA）与后缀树（Suffix Tree）是处理复杂字符串模式匹配、最长公共前缀（LCP）、最长重复子串等高级字符串问题的核心数据结构。后缀数组利用基数排序与倍增法，在 $O(N \log N)$ 时间内完成所有后缀的字典序排序。

---

## 1. 💡 问题动机与核心直觉

### 1.1 后缀的几何定义
对于长度为 $N$ 的字符串 $S$，其从位置 $i$ ($0 \le i < N$) 开始的子串称为 $S$ 的第 $i$ 个后缀 $\text{Suffix}(i) = S[i \dots N-1]$。

### 1.2 为什么需要后缀数组？
如果将字符串 $S$ 的所有 $N$ 个后缀排序：
- **匹配任意子串**：字符串 $S$ 的任意子串都是某个后缀的前缀。通过在排序好的后缀数组上进行**二分查找**，可以在 $O(M \log N)$ 时间内检索任意长度为 $M$ 的模式串。
- **最长公共前缀 (LCP)**：借助 Height 数组，可以在 $O(1)$ 时间内求出任意两个后缀的最长公共前缀。

---

## 2. 📐 正式定义与倍增构造法

### 2.1 核心数组定义
1. **`sa[i]`**：保存字典序排在第 $i$ 位的后缀的起始位置 index。
2. **`rk[i]`**：保存起始位置为 $i$ 的后缀的字典序排名（`sa` 的逆数组）。
3. **`height[i]`**：保存 $\text{Suffix}(\text{sa}[i])$ 与 $\text{Suffix}(\text{sa}[i-1])$ 的最长公共前缀（LCP）长度。

### 2.2 倍增构造算法 (Doubling Algorithm)
通过阶段性长度 $k = 1, 2, 4, 8, \dots$ 递增构造：
1. 长度为 $k$ 的后缀由**两个长度为 $k/2$ 的子串组合**而成（前半段与后半段排名）。
2. 使用双关键字**基数排序（Radix Sort）**，每次排序时间复杂度为 $O(N)$。
3. 总构造时间复杂度：$O(N \log N)$。

## 3. 💻 Python 核心实现

```python
def build_suffix_array(s: str):
    n = len(s)
    sa = list(range(n))
    rk = [ord(c) for c in s]
    tmp = [0] * n
    
    k = 1
    while k < n:
        # 按双关键字 (rk[i], rk[i+k]) 排序
        sa.sort(key=lambda i: (rk[i], rk[i + k] if i + k < n else -1))
        
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, curr = sa[i-1], sa[i]
            prev_key = (rk[prev], rk[prev + k] if prev + k < n else -1)
            curr_key = (rk[curr], rk[curr + k] if curr + k < n else -1)
            tmp[curr] = tmp[prev] + (1 if prev_key < curr_key else 0)
            
        rk = tmp[:]
        if rk[sa[-1]] == n - 1:
            break
        k *= 2

    return sa, rk

def build_height(s: str, sa: list, rk: list):
    n = len(s)
    height = [0] * n
    k = 0
    
    for i in range(n):
        if rk[i] == 0:
            k = 0
            continue
        if k > 0:
            k -= 1
        j = sa[rk[i] - 1]
        while i + k < n and j + k < n and s[i + k] == s[j + k]:
            k += 1
        height[rk[i]] = k
        
    return height
```

## 4. ⚠️ 常见误区与应用点

1. **直接比较时间爆炸**：若不用倍增或基数排序，直接调用原生 `sort` 比较字符串后缀，单次比较耗时 $O(N)$，总时间退化为 $O(N^2 \log N)$。
2. **Height 数组性质**：Height 数组满足 $h[i] \ge h[i-1] - 1$，利用此性质（Kasai 算法）可在 $O(N)$ 时间内构建 Height 数组。
