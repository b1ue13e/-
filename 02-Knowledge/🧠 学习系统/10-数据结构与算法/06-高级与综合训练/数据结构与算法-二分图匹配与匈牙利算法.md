# 数据结构与算法-二分图匹配与匈牙利算法

> **摘要**：二分图（Bipartite Graph）是指顶点集可分割为两个互不相交的集合 $L$ 与 $R$，使得每条边都连接 $L$ 与 $R$ 中各一个顶点的图。二分图最大匹配是指求出包含边数最多的无公共顶点边集。匈牙利算法（Hungarian Algorithm）通过不断寻找**增广路（Augmenting Path）**求解最大匹配，时间复杂度为 $O(V \cdot E)$。

---

## 1. 💡 问题动机与核心概念

### 1.1 二分图判定与匹配定义
- **二分图判定**：无向图 $G$ 是二分图的充要条件是**图无奇数环**（可使用染色法 BFS/DFS 在 $O(V+E)$ 内验证）。
- **匹配（Matching）**：边集 $M \subseteq E$，且 $M$ 中任意两条边均不共享顶点。
- **增广路（Augmenting Path）**：一条始于未匹配点、止于另一个未匹配点的路径，且路径上的边交替属于非匹配边与匹配边。

### 1.2 匈牙利算法的核心思想（Berge 定理）
> **Berge 定理**：匹配 $M$ 是最大匹配的充要条件是：**图 $G$ 中不存在关于 $M$ 的增广路**。

匈牙利算法每次从左侧集合的一个未匹配顶点出发，DFS 寻找增广路。若找到增广路，则将路径上所有边的状态取反（匹配变非匹配，非匹配变匹配），匹配数即 $+1$。

## 2. 💻 Python 核心实现

```python
class BipartiteMatching:
    def __init__(self, num_left: int, num_right: int):
        self.num_left = num_left
        self.num_right = num_right
        self.adj = [[] for _ in range(num_left)]
        self.match_right = [-1] * num_right  # 右侧节点匹配到的左侧节点

    def add_edge(self, u: int, v: int):
        self.adj[u].append(v)

    def dfs(self, u: int, visited: list) -> bool:
        for v in self.adj[u]:
            if visited[v]:
                continue
            visited[v] = True

            # 若 v 未匹配，或 v 的原配左侧节点能找到其他增广路
            if self.match_right[v] == -1 or self.dfs(self.match_right[v], visited):
                self.match_right[v] = u
                return True
        return False

    def max_matching(self) -> int:
        result = 0
        for u in range(self.num_left):
            visited = [False] * self.num_right
            if self.dfs(u, visited):
                result += 1
        return result
```

## 3. ⚠️ 经典等价转化（König 定理）

在二分图中：
1. **最大匹配数 = 最小点覆盖数**（选最少的点覆盖所有边）。
2. **最大独立集 = 顶点总数 - 最大匹配数**（选最多的点使得任意两点无边直接相连）。

## 🚨 常见误区与边界条件

1. **`vis` 数组每次 DFS 前清空**：匈牙利算法为左侧每个顶点尝试寻找增广路时，**必须在每轮 DFS 前清空右侧顶点的 `vis` 访问标记**，否则无法正确进行“让位”。
2. **二分图判定前提**：匈牙利算法假设图为二分图。若图包含奇数环（非二分图），直接运行匈牙利算法会得到错误匹配数，需先用染色法验证。
