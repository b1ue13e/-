# 数据结构与算法-图的高级连通性

## 💡 问题动机与直观解析

在图的网络拓扑分析中，我们需要找出最具脆弱性的**关键节点（割点/关节点 Cut Vertex）**和**关键链路（割边/桥 Cut Edge）**：
- **割点**：删去该节点及相关边后，图的连通块数量增加。
- **割边**：删去该边后，图的连通块数量增加。
- **强连通分量 (SCC, Strongly Connected Components)**：在有向图中，极大节点子集使得其中任意两点均互相可达。

**Tarjan 算法**以优雅的单次 DFS 遍历，配合时间戳与追溯值，在 $\mathcal{O}(|V| + |E|)$ 时间内线性求解上述所有图连通性特征！

---

## 📐 算法原理与时间戳/追溯值

DFS 过程中为每个节点 $u$ 维护两个核心数值：
1. **`dfn[u]` (DFS Number)**：节点 $u$ 被首次访问到的**时间戳**。
2. **`low[u]` (Lowest Reachable DFN)**：从 $u$ 出发，经由 DFS 树边与至多一条反向边（Back Edge）能追溯到的**最小时间戳**。

### 割点判定条件

对于非根节点 $u$，若存在子节点 $v$ 满足：
$$\text{low}[v] \ge \text{dfn}[u]$$
表明子节点 $v$ 无法在不经过 $u$ 的前提下翻回到 $u$ 祖先节点，因此 $u$ 必然是**割点**！

## 💻 经典代码实现 (Tarjan 求解有向图 SCC)

```python
def tarjan_scc(n: int, graph: list[list[int]]) -> list[list[int]]:
    dfn = [0] * n
    low = [0] * n
    in_stack = [False] * n
    stack = []
    timer = 0
    sccs = []

    def dfs(u: int):
        nonlocal timer
        timer += 1
        dfn[u] = low[u] = timer
        stack.append(u)
        in_stack[u] = True

        for v in graph[u]:
            if not dfn[v]:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif in_stack[v]:
                low[u] = min(low[u], dfn[v])

        # 若 low[u] == dfn[u]，说明 u 是当前 SCC 的首个被访问根节点
        if low[u] == dfn[u]:
            scc = []
            while True:
                node = stack.pop()
                in_stack[node] = False
                scc.append(node)
                if node == u:
                    break
            sccs.append(scc)

    for i in range(n):
        if not dfn[i]:
            dfs(i)

    return sccs
```

- Q: Tarjan 算法中 `dfn[u]` 与 `low[u]` 的定义分别是什么？
- A: `dfn[u]` 是节点 $u$ 被首次访问的时间戳；`low[u]` 是从 $u$ 出发通过树边和至多一条反向边能追溯到的最小时间戳。
