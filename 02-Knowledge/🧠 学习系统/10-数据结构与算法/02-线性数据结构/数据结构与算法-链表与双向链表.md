## 💡 问题动机与直观解析

链表（Linked List）是一种物理存储单元上非连续、非顺序的线性结构。元素的逻辑顺序通过节点中的指针链接实现。

与连续数组相比：
- **优点**：插入与删除已知节点位置只需 $\mathcal{O}(1)$ 修改指针，无需移动大量元素，且天然动态扩展无需连续预分配空间。
- **缺点**：失去随机索引访问能力，第 $k$ 个元素查找开销为 $\mathcal{O}(k)$，且由于节点分散在堆内存上，Cache Locality 较差。

在链表实现中，**哑节点 (Dummy Head / Sentinel Node)** 是避免空指针异常、简化头部/尾部边界条件的核心编程范式。

---

## 📐 算法模型与核心技巧

### 1. 哑节点 (Dummy Head) 技巧

若无哑节点，在单链表头部插入或删除节点时，需要对 `head` 指针进行特殊判断：
`if head is None: ...`。

通过引入不存储实际数据的虚拟节点 `dummy = ListNode(0); dummy.next = head`，可以将所有节点（包括原来的首节点）的处理逻辑统一化，大幅减少分支错误。

### 2. 快慢指针 (Floyd Cycle Finding) 找中点与环

维护 `slow`（每次走 1 步）和 `fast`（每次走 2 步）：
- **找中点**：当 `fast` 走到链表末尾时，`slow` 正好位于链表的中点。
- **检测环**：若 `fast` 与 `slow` 重合，证明链表存在环；重合后将 `slow` 放回 `head`，两者同时以步长 1 前进，再次相遇点即为**入环起点**。

## 💻 经典代码实现 (反转链表与双向链表)

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 迭代法反转单链表 (O(n) 时间, O(1) 空间)
def reverse_list(head: ListNode) -> ListNode:
    prev = None
    curr = head
    while curr:
        nxt = curr.next  # 暂存下一节点
        curr.next = prev # 反转指针
        prev = curr      # 前移 prev
        curr = nxt       # 前移 curr
    return prev
```

## 🃏 Anki 卡片

- Q: 链表编程中使用哑节点 (Dummy Node) 的核心作用是什么？
- A: 统一头节点与其他节点的插入/删除逻辑，避免针对 `head == None` 进行特殊的特判分支。

- Q: 如何证明 Floyd 快慢指针寻找链表入环起点的正确性？
- A: 设头节点到入环点距离为 $a$，入环点到相遇点距离为 $b$，环长为 $L$。相遇时 $2(a+b) = a + b + kL \implies a = kL - b = (k-1)L + (L-b)$。故从头节点与相遇点同时以步长 1 出发，必在入环点相遇。
