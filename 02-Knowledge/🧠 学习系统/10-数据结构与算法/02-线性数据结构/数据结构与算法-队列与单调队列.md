## 💡 问题动机与直观解析

队列（Queue）是一种遵循**先进先出 (FIFO - First In First Out)** 原则的受限线性表。队列是广度优先搜索 (BFS) 与任务调度系统的核心载体。

在滑动窗口最值问题（如求解长为 $k$ 的滑动窗口内最大值）中，使用普通队列或优先队列 (Heap) 维护最值的开销为 $\mathcal{O}(n \log k)$。通过构建**单调队列 (Monotonic Queue)**（基于双端队列 `Deque` 实现），在队尾剔除不可能成为最值的“较小/较大且较老”的元素，能将滑动窗口最值检索的时间复杂度降低至**严格 $\mathcal{O}(n)$**。

---

## 📐 算法原理与单调队列维护

### 单调递减队列维护规则（求窗口最大值）

维护一个存储元素索引的双端队列 `deque`：
1. **入队扩展 (Push)**：当新元素 $x$ 入队时，从队尾弹出所有 $\le x$ 的索引（因为它们既比 $x$ 小，又比 $x$ 旧，绝不可能成为当前或后续窗口的最大值）。
2. **出队收缩 (Pop)**：如果队头索引已经超出了当前窗口左边界 `i - k`，将其从队头弹出。
3. **获取最值 (Get Max)**：队头元素索引对应的数值即为当前窗口的**最大值**，耗时 $\mathcal{O}(1)$。

---

## 💻 经典代码实现 (滑动窗口最大值 LeetCode 239)

```python
from collections import deque

def max_sliding_window(nums: list[int], k: int) -> list[int]:
    q = deque() # 存储索引，维持 nums[q[i]] 单调递减
    res = []
    
    for i, num in enumerate(nums):
        # 1. 剔除队尾被淘汰的较小元素
        while q and nums[q[-1]] <= num:
            q.pop()
        q.append(i)
        
        # 2. 剔除超出窗口左边界的过期队头
        if q[0] <= i - k:
            q.popleft()
            
        # 3. 记录窗口最大值
        if i >= k - 1:
            res.append(nums[q[0]])
            
    return res
```

## 🃏 Anki 卡片

- Q: 单调队列 (Monotonic Queue) 维护滑动窗口最大值的核心逻辑是什么？
- A: 队尾入队前弹出所有小于新元素的尾部索引；队头超出窗口范围时弹出头索引；队头元素恒为当前窗口最大值。
