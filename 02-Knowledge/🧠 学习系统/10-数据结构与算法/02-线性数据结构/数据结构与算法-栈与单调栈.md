## 💡 问题动机与直观解析

栈（Stack）是一种遵循**后进先出 (LIFO - Last In First Out)** 原则的受限线性表。栈在函数递归调用、括号语法匹配、表达式求值（中缀转后缀 AST）中起着基础支撑作用。

**单调栈 (Monotonic Stack)** 则是栈结构的进阶应用：通过在压栈时剔除破坏单调性的元素，保持栈内元素单调递增或递减。单调栈能以 $\mathcal{O}(n)$ 的时间复杂度解决**“寻找每个元素左侧/右侧第一个比它大/小的元素 (Next Greater Element)”**这一经典问题（暴力算法需 $\mathcal{O}(n^2)$）。

---

## 📐 算法原理与维护契约

### 1. 单调递减栈维护原理

若要求解“每个元素右侧第一个更大元素”：
- 维护一个从栈底到栈顶**单调递减**的栈。
- 遍历数组元素 $x$ 时：
  - 若 $x > \text{stack.top()}$，说明 $x$ 就是 $\text{stack.top()}$ 右侧遇到的第一个更大元素！
  - 弹出 $\text{stack.top()}$ 并记录答案，重复此过程直至栈为空或 $x \le \text{stack.top()}$。
  - 最后将 $x$ 压入栈中。

因为每个元素最多进栈一次、出栈一次，总耗时在均摊意义下严格为 $\mathcal{O}(n)$。

---

## 💻 经典代码实现 (Next Greater Element & 接雨水/柱状图最大矩形)

```python
def next_greater_element(nums: list[int]) -> list[int]:
    n = len(nums)
    res = [-1] * n
    stack = [] # 存储索引
    
    for i in range(n):
        while stack and nums[i] > nums[stack[-1]]:
            idx = stack.pop()
            res[idx] = nums[i]
        stack.append(i)
        
    return res
```
