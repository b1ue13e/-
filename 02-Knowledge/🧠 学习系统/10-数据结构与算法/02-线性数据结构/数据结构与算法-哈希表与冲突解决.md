## 💡 问题动机与直观解析

哈希表（Hash Table / Dictionary / Map）是现代软件工程中使用频率最高的数据结构。它通过**哈希函数 (Hash Function)** 将任意类型的键 (Key) 映射为固定范围的槽位索引 (Bucket Index)，实现平均开销为 **$\mathcal{O}(1)$ 的插入、查找和删除**。

然而，根据鸽巢原理 (Pigeonhole Principle)，当键的空间远大于槽位数量时，不同 Key 映射到同一槽位的**哈希冲突 (Hash Collision)** 是无法避免的。

---

## 📐 算法原理与冲突解决流派

### 1. 两大冲突解决流派对比

| 特性 | 分离链接法 (Separate Chaining / 拉链法) | 开放寻址法 (Open Addressing) |
| :--- | :--- | :--- |
| **冲突处理逻辑** | 槽位存储链表/红黑树，冲突项直接挂在链表末尾 | 不使用额外指针，冲突时按探针序列搜寻下一个空槽位 |
| **探针/寻址策略** | 链表遍历 | 线性探测 ($i + k$) / 二次探测 ($i + k^2$) / 双重哈希 |
| **负载因子 $\alpha = n/m$** | 可大于 $1.0$（Java `HashMap` 在 $\alpha \ge 0.75$ 时扩容） | 必须严格 $< 1.0$（通常在 $\alpha \ge 0.5 \sim 0.7$ 时扩容） |
| **缓存友好度** | 较低（链表节点分散） | 极高（探测连续内存块） |

---

### 2. 全域哈希 (Universal Hashing)

为防止恶意输入构造特定的 Key 导致哈希表退化为 $\mathcal{O}(n)$ 链表，全域哈希从一组哈希函数族 $\mathcal{H}$ 中随机选择一个函数 $h$。对任意两个不同的 Key $x \neq y$，满足：
$$\Pr_{h \in \mathcal{H}}[h(x) = h(y)] \le \frac{1}{m}$$

## 💻 经典拉链法哈希表 Python 实现

```python
class HashTable:
    def __init__(self, capacity: int = 16):
        self.capacity = capacity
        self.size = 0
        self.buckets = [[] for _ in range(capacity)]

    def _hash(self, key) -> int:
        return hash(key) % self.capacity

    def put(self, key, value):
        idx = self._hash(key)
        for i, (k, v) in enumerate(self.buckets[idx]):
            if k == key:
                self.buckets[idx][i] = (key, value)
                return
        self.buckets[idx].append((key, value))
        self.size += 1
        # 负载因子超过 0.75 时触发扩容
        if self.size / self.capacity >= 0.75:
            self._resize(self.capacity * 2)

    def get(self, key):
        idx = self._hash(key)
        for k, v in self.buckets[idx]:
            if k == key:
                return v
        raise KeyError(key)

    def _resize(self, new_capacity: int):
        old_buckets = self.buckets
        self.capacity = new_capacity
        self.buckets = [[] for _ in range(new_capacity)]
        self.size = 0
        for bucket in old_buckets:
            for k, v in bucket:
                self.put(k, v)
```

## 🃏 Anki 卡片

- Q: 解决哈希冲突的拉链法与开放寻址法的核心区别是什么？
- A: 拉链法每个槽位挂载动态链表/树；开放寻址法所有元素都保存在连续数组内，发生冲突时按探测序列寻找空槽位。
