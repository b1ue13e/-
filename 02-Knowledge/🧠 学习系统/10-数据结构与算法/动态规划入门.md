# 动态规划入门

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：动态规划是算法设计五大范式（分治/贪心/DP/回溯/分支限界）中最重要的一种（6.006 Lec 15-18 四讲连讲），HW05 官方 PS7 全部围绕它；背包、LCS、编辑距离是面试与竞赛的绝对主力题型。学不会 DP，算法能力直接断层。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：有一大类问题（背包、最长公共子序列、编辑距离、矩阵链乘）的朴素解法是枚举所有可能性，而枚举量随输入规模**指数爆炸**：$n$ 个物品的背包有 $2^n$ 种选择，$n=50$ 就超过宇宙原子数。但仔细看会发现：这些问题的**子问题大量重复**——同一个"小状态"被反复计算成千上万次。因此必须引入动态规划：**只把每个子问题算一次、存起来复用**，用"状态 + 转移"把指数级枚举压成多项式级计算。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：6.006 用四讲（Lec 15-18：SRBOT、Fib、DAG、LCS、LIS、Coins、Rods、Subsetsum）系统讲 DP，它是图算法、字符串算法、伪多项式算法的公共底座；与贪心（[[Dijkstra最短路径]]）、分治（[[最近点对问题-分治进阶]]）是"算法思想三兄弟"。HW05 PS7 直接考查。
- **实际应用场景**：基因序列比对（编辑距离）、文本 diff、资源分配（背包）、语音识别（维特比）。高频题型：识别最优子结构、写状态转移方程、记忆化 vs 表格、手算 DP 表、与贪心/分治选型辨析。

---

## 3. 学它之前需要哪些前置知识？

1. **[[知识地图/递归|递归]]**：DP 的自顶向下（记忆化）就是"带缓存的递归"；递归树是理解"重叠子问题"的直观工具。
2. **[[知识地图/复杂度分析|复杂度分析]]**：需要区分指数/多项式/伪多项式复杂度，才能看懂"为什么 DP 把 $2^n$ 变成 $O(nW)$"。
3. **[[图遍历BFS与DFS]]**：拓扑排序给出 DAG 上 DP 的计算顺序（6.006 把 DP 统一看作 DAG 最短路）。

---

## 4. 用直觉语言解释它

> «"动态规划就像记账本上填表：你要算'到第 $i$ 个格子为止的最优值'，它只依赖'到第 $i-1$（或 $i-2$）个格子为止的答案'——所以从第一格开始一格一格往后填，每格只算一次，后面的格子直接查账本，绝不算第二遍。这就是'记住已算过的答案，避免重复劳动'。"»

- **直觉类比/几何图像**：填表（每个格子 = 一个子问题的答案）；递归树剪枝（记忆化 = 砍掉重复子树）。
- **为什么很自然**："大问题的最优解由小问题的最优解组成"（最优子结构），且"小问题被无数大问题共用"（重叠子问题）——既然共用，就只算一次。一句话直觉本质：**把问题写成"状态 + 转移"，每个子问题只算一次并存储——用空间换时间，把指数级枚举压成多项式级。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **最优子结构（Optimal Substructure）**：问题的最优解包含其子问题的最优解（可用"剪切-粘贴"论证）。
- **重叠子问题（Overlapping Subproblems）**：递归求解时同一子问题被反复求解（与分治的关键区别）。
- **状态转移方程（Recurrence）**：把"大状态"表示成"小状态"的函数——DP 的心脏。

### 2. 核心公式（三个经典递推）
斐波那契：$f(i) = f(i-1) + f(i-2)$，$f(0)=0, f(1)=1$。
0/1 背包（容量 $W$、物品 $i$ 重 $w_i$ 值 $v_i$）：
$$dp[i][c] = \max\big(dp[i-1][c],\ dp[i-1][c-w_i] + v_i\big)$$
LCS（$X[1..m], Y[1..n]$）：
$$dp[i][j] = \begin{cases} dp[i-1][j-1]+1 & X_i = Y_j \\ \max(dp[i-1][j], dp[i][j-1]) & X_i \ne Y_j \end{cases}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $dp[i][c]$ | 前 $i$ 个物品、容量 $c$ 的最优值 | 非负整数 | 状态 |
| $w_i, v_i$ | 物品重量、价值 | 正整数 | 输入 |
| $W$ | 背包容量 | 正整数 | 伪多项式来源 |
| $X_i, Y_j$ | 序列字符 | 任意字符 | LCS 状态 |
| $O(nW)$ | 背包 DP 复杂度 | — | 伪多项式 |

### 4. 常见变体与适用条件
- **变体**：记忆化（自顶向下）vs 表格（自底向上）、滚动数组（空间优化）、状态压缩 DP、区间 DP、数位 DP。
- **适用条件**：最优子结构 + 重叠子问题；子问题规模可枚举。限制条件：状态数太大（如 $W$ 巨大）时伪多项式失效；无最优子结构时（如"最长简单路径"）DP 不适用。

## 6. 推导思路和思想来源

- **最初困难**：枚举方案指数爆炸；贪心对部分问题给出错误答案（如 0/1 背包取"单位价值最高"不一定最优）。直接方法局限：递归求解 Fib 是 $O(2^n)$，因为同一个 $f(k)$ 被算 $F(n-k)$ 次——重复劳动是罪魁。
- **关键"转念"**：**既然子问题重复，就把"递归"换成"查表"**——自顶向下加缓存（记忆化），或自底向上按依赖顺序填表。6.006 的 SRBOT 框架把 DP 设计标准化：**S**ubproblems（子问题定义）→ **R**elation（转移方程）→ **B**ase case（边界）→ **O**riginal problem（原问题如何由子问题组装）→ **T**ime（复杂度核算）。
- **推导主线与动机**：暴力递归 → 画递归树发现重叠 → 记忆化剪枝 → 观察依赖顺序改表格 → 每个状态只算一次 → 复杂度 = 状态数 × 每状态转移代价。
- **为什么自然得到此结论**：数学归纳法告诉我们"想证明 $P(n)$ 只需 $P(n-1)$"——DP 就是把这个证明过程变成算法：子问题 = 归纳假设，转移 = 归纳步。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：用 DP 手算 $f(6)$（Fib，$f(0)=0,f(1)=1$），列出表格与计算次数。
- **解题思路与关键步骤**：表格：$f(2)=1, f(3)=2, f(4)=3, f(5)=5, f(6)=8$，共 5 次加法；朴素递归算 $f(6)$ 要 25 次调用（$f(1)$ 被算 8 次）。最终答案：$f(6)=8$——表格 $O(n)$ vs 递归 $O(2^n)$。
- **易错点**：边界写错（$f(0),f(1)$）；自底向上时忘记从最小子问题开始。
- **🤔 追问**：若还要输出"最优方案"（不只是最优值），怎么办？——额外维护一个"决策表"（每个状态记录选择了哪个转移分支），最后回溯；背包/LCS 输出方案都靠这个技巧。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：0/1 背包，容量 $W=5$，物品 $(w,v)$：$(2,3),(3,4),(4,5),(1,2)$。求最优值并说明为何贪心"单位价值最高"会错。
- **解题思路与完整解答**：单位价值：$3/2=1.5, 4/3\approx1.33, 5/4=1.25, 2/1=2$——贪心先拿 $(1,2)$ 再拿 $(2,3)$ 共值 5、剩容量 2 拿不下 $(3,4)$；而最优是 $(2,3)+(3,4)=7$ 或 $(1,2)+(4,5)=7$。DP 填表：$dp[4][5]=7$。
- **易错点**：贪心在"可分割背包"（分数背包）是对的、0/1 背包是错的——是否可分割是选型分界线。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：编辑距离是基因比对与文本 diff 的核心；LCS 是版本控制与 diff 工具的基础。代码形态（记忆化 + 表格双版本）：
```python
from functools import lru_cache

def fib_memo(n):                       # 自顶向下：记忆化
    @lru_cache(maxsize=None)
    def f(i): return i if i < 2 else f(i-1) + f(i-2)
    return f(n)

def lcs_table(X, Y):                   # 自底向上：表格
    m, n = len(X), len(Y)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if X[i-1] == Y[j-1]: dp[i][j] = dp[i-1][j-1] + 1
            else: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]                    # O(mn)，空间可滚动到 O(n)
```

## 8. 常见误区和易混概念

### 误区 1：以为"贪心失败的问题就上 DP"
- **错误直觉**：DP 是万能药，任何优化问题都能 DP。
- **为什么错**：DP 需要最优子结构；如"最长简单路径"（含环）无最优子结构，只能指数级搜索。且状态空间过大时 DP 也不可行。
- **正确理解**：先验证两个性质（最优子结构 + 重叠子问题），再决定 DP；否则考虑搜索/近似。

### 误区 2：以为"记忆化 = 动态规划的全部"
- **错误直觉**：只要用了缓存递归就是 DP。
- **为什么错**：记忆化只是实现手段；DP 的灵魂是**状态定义与转移方程**——写不出正确的递推，缓存再多也算不对。正确理解：先设计 SRBOT（子问题/转移/边界/原问题/复杂度），实现方式是最后一步；记忆化只算用到的状态、表格无递归栈开销。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 动态规划 | 重叠子问题+最优子结构 | 子问题共享、存表复用 | 背包、LCS、编辑距离 |
| 分治（[[最近点对问题-分治进阶]]） | 子问题独立 | 子问题不重叠、只合并 | 归并排序、FFT |
| 贪心（[[Dijkstra最短路径]]） | 局部最优=全局最优 | 不回溯、无表 | 分数背包、Dijkstra |
| 回溯 | 枚举+剪枝 | 指数级最坏 | 数独、N 皇后 |

### 题目与解析

#### 1. 一个问题能用动态规划求解的两个必要条件是什么？
> [!question]- 答案解析
> - **答案**：① 最优子结构：最优解包含子问题的最优解（剪切-粘贴可证）；② 重叠子问题：递归时同一子问题被反复求解。解析：只有①是分治也有（但子问题独立不重叠）；无①则"最长简单路径"式问题无法 DP。易错：把"有递归结构"当成充分条件。标签：`#自测题/基础`

#### 2. 手算 $X=\text{ABCBDAB}, Y=\text{BDCABA}$ 的 LCS 长度与一个最长公共子序列。
> [!question]- 答案解析
> - **答案**：长度 4（如 `BCBA` 或 `BDAB`）。按递推填 $7\times6$ 表，$dp[7][6]=4$。解析：遇相等字符取左上+1，不等取上/左较大——逐格填表；回溯决策表可输出具体 LCS。易错：认为"相等时必须取左上"而忽略上/左可能同样长（长度不变，仍最优）。

#### 3. 0/1 背包为什么不能用"单位价值贪心"？什么变体可以？
> [!question]- 答案解析
> - **答案**：0/1 背包中物品不可分割，贪心可能留下"装不下的缝隙"而错失全局最优（反例见例子 2）；**分数背包**（物品可分割）贪心单位价值最高即最优。解析：可分割性改变问题结构——可分割时局部最优可拼接，0/1 时拼接被"整数容量"破坏。易错：把两个背包问题混为一谈。

#### 4. 记忆化与表格两种实现各有什么优缺点？LCS 如何做空间优化？
> [!question]- 答案解析
> - **答案**：记忆化只计算用到的子问题、代码直观，但有递归栈开销；表格无栈开销、顺序可控。LCS 只需保留上一行即可滚动数组，空间 $O(mn)\to O(n)$（时间不变）。解析：滚动数组要求"当前行只依赖上一行"——LCS 满足；背包若滚动数组需逆序枚举容量（否则覆盖未用值）。易错：忽视依赖方向。

#### 5. 用剪切-粘贴法证明 0/1 背包问题具有最优子结构。
> [!question]- 答案解析
> - **答案**：设 $OPT(i,c)$ 为前 $i$ 个物品容量 $c$ 的最优值，最优解 $S$。若 $S$ 不含物品 $i$：则 $S$ 是前 $i-1$ 个物品容量 $c$ 的最优解（否则替换得更好）。若 $S$ 含物品 $i$：则 $S\setminus\{i\}$ 是前 $i-1$ 个物品容量 $c-w_i$ 的最优解（否则用更优解替换得含 $i$ 的更好解，矛盾）。故 $dp[i][c]=\max(dp[i-1][c], dp[i-1][c-w_i]+v_i)$ 正确。解析：剪切-粘贴（cut-and-paste）：假设子解非最优 → 粘贴更优子解 → 更优原解 → 矛盾，是 6.006/CLRS 标准模板。易错：只验证递推式而不做矛盾论证。
