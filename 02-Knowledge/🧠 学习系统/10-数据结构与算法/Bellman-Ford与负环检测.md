# Bellman-Ford与负环检测

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：[[Dijkstra最短路径]] 对负权失效，而现实（外汇套利、带折扣的定价）处处有负权；Bellman-Ford 是"任意权 + 负环检测"的唯一经典答案，也是"最短路径 = 动态规划"这一思想的第一次完整亮相（6.006 Lec 11-12，直接衔接 HW05 动态规划），HW04 官方 PS6 要求与 Dijkstra 对拍验收。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：Dijkstra 要求边权非负，一旦出现负权边，它的"先确定最近点"就会出错（被后来的更短路径推翻）。更糟的是：如果图里有**负环**（总权重为负的环），最短路径根本不存在——可以绕着负环转无限圈把代价压到 $-\infty$。我们需要一个算法：① 支持任意权重的边；② 能检测并指出负环；③ 最好还能顺便给出"为什么是 $V-1$ 轮"的清晰解释。Bellman-Ford 用最朴素的工具——**把每条边松弛 $V-1$ 轮**——同时解决这三件事。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：Bellman-Ford 是单源最短路径（SSSP）家族的另一半，与 [[Dijkstra最短路径]] 互补：Dijkstra 快（$O((V+E)\log V)$）但要求非负权；Bellman-Ford 慢（$O(VE)$）但通吃。它的"按轮次迭代"结构是**动态规划**的教科书案例（[[动态规划入门]] 的最短路版），HW04 官方 PS6 直接考查、HW05 动态规划以此为思想先声。
- **实际应用场景**：**外汇套利检测**（汇率 → 取对数 → 找负环，经典金融应用）、带负折扣的定价系统、路由协议 RIP（按跳数传播距离向量）。**高频题型/任务**：手算迭代轮次、负环检测、与 Dijkstra 选型对比、正确性证明、判断何时必须用 BF。

---

## 3. 学它之前需要哪些前置知识？

1. **[[Dijkstra最短路径]]**：理解"松弛"操作（$d[u]+w(u,v)<d[v]$ 则更新）与 SSSP 问题本身——BF 复用同一松弛，只是顺序与轮数不同。
2. **[[图遍历BFS与DFS]]**：图存储（邻接表）、"最短路径最多 $V-1$ 条边"的直觉（路径无环）。
3. **[[动态规划入门]]**：理解"子问题按规模分层、逐层递推"——BF 的 $V-1$ 轮就是 DP 的滚动数组版本。

---

## 4. 用直觉语言解释它

> «"Bellman-Ford 就像一场谣言接力：源点先告诉所有直接邻居'我的距离是 0'，每个听到的人立刻把'我听到的距离 + 到你的路费'转告自己的邻居——谁的数字变小了谁就再喊一轮。一条最短路径最多经过 $V-1$ 条边，所以谣言最多传 $V-1$ 轮就能传到所有人。如果传完 $V-1$ 轮还有人能'变得更小'，那一定是有个负环在无限'制造更短距离'——谣言永远传不完，这就是负环的铁证。"»

- **直觉类比/几何图像**：谣言接力/消息广播；$k$ 轮 = "最多走 $k$ 条边的信息"；负环 = 永远收不完的好消息。
- **为什么很自然**：任何简单路径最多 $V-1$ 条边（无环路径），所以"按边数分层"递推 $V-1$ 层必然覆盖所有最短路径；负环使"层数"失效——每多转一圈都能更短。**一句话直觉本质**：每轮对全部边做一次松弛，第 $k$ 轮后所有"边数 ≤ k"的最短路径都已找到；$V-1$ 轮后若还能松弛，则存在负环。

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **Bellman-Ford 算法**：初始化 $d[s]=0$，其余 $d[v]=+\infty$；重复 $V-1$ 轮"对每条边 $(u,v)$ 松弛"；最后再做一轮：若仍有边可松弛，报告"存在负环"。
- **负环**：总权重为负的环 $C$（$\sum_{e\in C}w(e)<0$）。存在负环时 $\delta(s,v)$ 对可达节点无定义（可为 $-\infty$）。
- **松弛**（与 Dijkstra 相同）：若 $d[u]+w(u,v)<d[v]$，则 $d[v]\leftarrow d[u]+w(u,v)$，前驱 $\pi[v]\leftarrow u$。

### 2. 核心公式
$$T_{\text{Bellman-Ford}}=O(VE),\qquad S=O(V)$$
正确性（无负环时，$V-1$ 轮后）：
$$d[v]=\delta(s,v)\quad \forall v\in V$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $V, E$ | 顶点数、边数 | $V,E\ge 1$ | 复杂度 $O(VE)$ |
| $d[v]$ | 当前已知最短距离上界 | $[-\infty,+\infty]$ | 每轮单调不增 |
| $\delta(s,v)$ | 真实最短距离 | 无负环时有限 | 负环可达时为 $-\infty$ |
| $w(u,v)$ | 边权 | $\in\mathbb{R}$ | 允许负数 |
| $k$ | 迭代轮数 | $1..V$ | 第 $V$ 轮用于检测负环 |

### 4. 常见变体与适用条件
- **变体**：SPFA（队列优化，平均快、最坏仍 $O(VE)$）、DAG 上的 BF（按拓扑序一轮即可，$O(V+E)$，见 [[拓扑排序与DAG动态规划]]）、差分约束系统（不等式组 → 最短路）。**适用条件**：任意边权、需要负环检测、图不大（$O(VE)$ 可承受）；**限制**：稠密大图上太慢，负环上无法给出最短距离本身。

## 6. 推导思路和思想来源

- **最初困难**：Dijkstra 的贪心（先确定最近点）在负权下不成立；朴素枚举所有路径指数爆炸。**直接方法局限**：按"从源点出发的路径长度"排序也不行——路径长度未知，鸡生蛋问题。
- **关键"转念"**：**换一个可计算的排序维度——边数**。任何最短路径若无环至多 $V-1$ 条边；于是定义"最多用 $k$ 条边能到达 $v$ 的最短距离" $d_k[v]$，它有干净的递推。
- **推导主线与动机**：$d_0[s]=0$，$d_k[v]=\min\big(d_{k-1}[v],\ \min_{(u,v)\in E}\{d_{k-1}[u]+w(u,v)\}\big)$ → 这就是动态规划（子问题 = 边数上界）→ 每轮对全部边松弛恰好实现一层递推 → $k=V-1$ 时 $d=\delta$ → 若 $d_V\ne d_{V-1}$，说明存在"边数可无限增加而代价更小"的路径，即负环。
- **为什么自然得到此结论**：按边数分层是唯一不需要预知路径长度的递推维度；负环检测则是"递推不收敛"的直接判据——DP 的边界条件（$V-1$ 轮）就是最短路径的边界条件。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：$s\to a$（4）、$s\to b$（2）、$b\to a$（1）、$a\to b$（-3）、$a\to t$（3）、$b\to t$（5）。跑 BF，$V=4$，做 3 轮。
- **解题思路与关键步骤**：$d[s]=0$。第 1 轮：$d[a]=4,d[b]=2$。第 2 轮：$b\to a$：$2+1=3<4$ → $d[a]=3$；$a\to b$：$4+(-3)=1<2$ → $d[b]=1$；$a\to t$：$4+3=7$；$b\to t$：$2+5=7$。第 3 轮：$b\to a$：$1+1=2<3$ → $d[a]=2$；$a\to b$：$3+(-3)=0<1$ → $d[b]=0$；$a\to t$：$3+3=6<7$ → $d[t]=6$；$b\to t$：$1+5=6$。第 4 轮（检测轮）：$a\to b$：$2+(-3)=-1<0$ → **还能松弛！存在负环 $a\rightleftharpoons b$（权 $-3+1=-2<0$）**。
- **最终答案**：检测到负环，$d[t]$ 无意义。若把 $a\to b$ 的权改为 $2$（环权 $+3>0$），第 3 轮后 $d[t]=6$，第 4 轮无更新，答案 $d[t]=6$（路径 $s\to b\to a\to t$：$2+1+3=6$）。
- **易错点**：**边数 $V-1$ 不是轮数上限而是必须做满的轮数**（少做一轮可能漏掉"最后一条边"的最短路）；负环检测必须做第 $V$ 轮，且只看"是否还能松弛"而非"$d$ 是否为负"。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：判断"第 $V$ 轮还能松弛 ⟺ 存在从 $s$ 可达的负环"两个方向分别怎么理解，并构造一个"有负环但不在 $s$ 可达区内"的图说明第 $V$ 轮不会误报。
- **解题思路与完整解答**：⇒ 方向：若第 $V$ 轮边 $(u,v)$ 还能松弛，则 $d_V[u]+w<d_V[v]$；$d_V[u]$ 对应的路径加这条边形成一条 $V$ 条边、且比 $d_{V-1}$ 更短的路径，必有重复顶点 → 含环且环权为负（否则去掉环更短）。⇐ 方向：负环上每转一圈都能把 $d$ 压低，所以第 $V$ 轮必然还能松弛。误报问题：图 $s\to a$（1），另有孤立负环 $x\to y$（-5）、$y\to x$（-5）。BF 从 $s$ 出发，$x,y$ 的 $d$ 恒为 $+\infty$，松弛条件 $+\infty+(-5)<+\infty$ 不成立（$+\infty$ 参与比较不触发），第 $V$ 轮无更新——**负环必须从 $s$ 可达才被检测到**，这符合"最短路径无定义"的语义。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：**外汇套利**——把货币当顶点，汇率 $r(i,j)$ 当边权，套利条件是 $\prod r>1$；取对数 $\log r$，套利 ⟺ 存在负环（$\sum\log r<0$）。BF 检测到负环即可打印套利路径。代码：
```python
def bellman_ford(edges, n, s):
    """edges: [(u, v, w)]，返回 (dist, has_neg_cycle)"""
    INF = float('inf')
    dist = [INF] * n
    dist[s] = 0
    for _ in range(n - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:            # 提前终止：无更新即已收敛
            break
    for u, v, w in edges:          # 第 V 轮：负环检测
        if dist[u] != INF and dist[u] + w < dist[v]:
            return dist, True
    return dist, False
```
复杂度 $O(VE)$；提前终止是实用优化，不改变最坏界。注意 `dist[u] != INF` 的判空——用 $+\infty$ 松弛毫无意义（见例子 2）。

## 8. 常见误区和易混概念

### 误区 1：以为"BF 能处理负环并给出最短距离"
- **错误直觉**：算法跑完，$d$ 值就是答案，负环只是让某些 $d$ 很小。
- **为什么错**：负环上最短距离是 $-\infty$（无定义），任何有限 $d$ 都是错的。**正确理解**：BF 对负环只能**检测并报告**，不能给出距离；检测标志是"第 $V$ 轮仍能松弛"。

### 误区 2：以为"少做几轮也没关系，反正提前终止了"
- **错误直觉**：某轮没更新就说明收敛了，可以放心停。
- **为什么错**：提前终止本身是对的（无负环时），但**前提是已经做了足够多轮**。**正确理解**："某轮完全无更新 ⟹ 递推达不动点 ⟹ 已收敛"，所以提前终止安全且推荐；但负环检测轮必须完整执行。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| Dijkstra（[[Dijkstra最短路径]]） | 非负权 SSSP | 贪心 + 优先队列，$O((V+E)\log V)$ | 地图导航、路由 |
| Bellman-Ford | 任意权 SSSP + 负环 | DP 式 $V-1$ 轮松弛，$O(VE)$ | 外汇套利、负权图 |
| Floyd-Warshall | 全源 APAP | DP $O(V^3)$ | 稠密小图 |
| SPFA | 任意权 SSSP | 队列优化 BF，最坏 $O(VE)$ | 竞赛常用、负权稀疏图 |

### 题目与解析

#### 1. 为什么 Bellman-Ford 需要恰好 $V-1$ 轮松弛？
> [!question]- 答案解析
> - **答案**：任何无环路径至多包含 $V-1$ 条边；第 $k$ 轮后所有"边数 ≤ k"的最短路径已被找到，故 $V-1$ 轮覆盖所有可能的最短路径。若做第 $V$ 轮仍能松弛，则存在负环。
> - **解析**：若路径含环，去掉环不增加代价（无负环时），所以最短路径必无环。易错：把"轮数"理解成"边数上限"以外的神秘数字。标签：`#自测题/基础`

#### 2. 给定 $d[b]=2$，边 $b\to a$ 权 1、$a\to t$ 权 3，当前 $d[a]=4,d[t]=+\infty$。依次松弛这两条边后 $d$ 如何变化？
> [!question]- 答案解析
> - **答案**：松弛 $b\to a$：$2+1=3<4$ → $d[a]=3$；松弛 $a\to t$：$3+3=6<+\infty$ → $d[t]=6$。
> - **解析**：**同一轮内先更新的 $d[a]$ 可以被本轮后续边使用**——这正是 BF"一轮 = 路径长度 +1"的机制（松弛顺序不同结果仍正确，只是中间值不同）。易错：误以为一轮内只能用上一轮的 $d$ 值（那是严格两阶段版本，效果等价但实现更繁琐）。

#### 3. 如何用 BF 判断"存在从源点 $s$ 可达的负环"？孤立负环会被误报吗？
> [!question]- 答案解析
> - **答案**：做完 $V-1$ 轮后再做第 $V$ 轮，若任何边还能松弛则存在 $s$ 可达负环。孤立负环不会被误报：其 $d$ 恒为 $+\infty$，$+\infty+(-5)<+\infty$ 不成立。
> - **解析**：负环检测的语义是"最短路径无定义"，只对 $s$ 可达部分有意义。易错：写松弛条件时漏掉 `dist[u] != INF` 判空，导致 `inf + (-5) < inf` 误报。

#### 4. 把汇率矩阵建模为图，说明套利与负环的对应关系。
> [!question]- 答案解析
> - **答案**：货币为顶点，$i\to j$ 边权 $\log r_{ij}$。套利 $\prod r>1$ ⟺ $\sum\log r>0$ ⟺ 对 $\log$ 取反后的边权 $\sum(-\log r)<0$ ⟺ 负环。用 BF 检测即可，负环路径即套利序列。
> - **解析**：对数把乘积化为求和，是"乘法变加法"的经典技巧。易错：忘记取对数直接跑 BF（边权为汇率时找的是"最重环"，不是套利）。

#### 5. 证明：无负环时 $V-1$ 轮后 $d[v]=\delta(s,v)$；有负环时第 $V$ 轮必能松弛。
> [!question]- 答案解析
> - **答案**：对轮数归纳证明"第 $k$ 轮后，所有至多 $k$ 条边的最短路径对应的 $d$ 已被找到"：最短路径 $P=s\to v_1\to\cdots\to v_k$ 的每条前缀也是最短的（最优子结构），第 $k$ 轮松弛 $(v_{k-1},v_k)$ 即得。$k=V-1$ 时因无负环所有最短路至多 $V-1$ 条边，故 $d=\delta$。有负环时：环上每转一圈 $d$ 严格下降，第 $V$ 轮必然还能松弛（否则递推已收敛，与"转圈能更短"矛盾）。
> - **解析**：前半是 DP 最优子结构，后半是"收敛 ⟺ 无负环"的直观严格化。易错：证明"第 $k$ 轮"时假设路径恰 $k$ 条边而忽略"至多"（取等号版本需要额外处理）。
