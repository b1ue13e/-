# 二分搜索

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：$O(\log n)$ 是算法课第一个"碾压直觉"的复杂度；二分是分治思想最简案例，其"循环不变式"分析方法是所有边界类题（lower_bound、二分答案）的通用武器，面试高频。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：在 10 亿个有序号码中找目标，线性扫描最坏 $O(n)$。二分搜索利用"有序"信息，每次把候选区间砍半，$O(\log n)$ 次比较即可定位。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：二分是"减治"（每次只进一边）的典范，与分治对比学习（[[分治算法]]）；"单调性 → 可二分"是二分答案题的核心。
- **实际应用场景**：数据库索引定位、调试代码（git bisect）、机器学习阈值搜索、竞赛"最小化最大值"。
- **高频题型/任务**：查找目标、lower_bound/upper_bound、旋转数组、峰值查找、浮点二分、二分答案。

---

## 3. 学它之前需要哪些前置知识？

1. **[[复杂度分析]]**：理解 $O(\log n)$（每轮砍半，$\log_2 n$ 轮）。
2. **[[数组与链表]]**：二分要求 $O(1)$ 随机访问——数组可以，链表不行。
3. **[[递归]]**：二分可递归描述，理解"子问题规模减半"。

---

## 4. 用直觉语言解释它

> «"二分搜索就像猜数字游戏：心里想一个 1-100 的数，每次猜中间值，说'大了/小了'——每猜一次范围缩小一半，最多 7 次必中（$2^7=128>100$）。"»

- **直觉类比/几何图像**：对折纸条；每次把"答案所在区间"对半切，丢掉不含答案的一半。
- **为什么很自然**：有序让"大小关系"提供方向信息，比较一次排除一半——这正是信息论下界 $\lceil\log_2 n\rceil$ 次比较的必然。
- **一句话直觉本质**：**维护"答案必在其中"的区间，每次用中点比较把区间砍半，直到区间缩到目标——正确性靠循环不变式保证。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- 给定**有序**数组 $A[0..n-1]$ 与目标 $x$，求 $A[i]=x$ 的下标（或首个 $\ge x$ 的位置）。
- **循环不变式**：每次迭代前，答案必在区间 $[lo,hi)$ 内；比较 $A[mid]$ 与 $x$ 后区间收缩，不变式保持，结束时 $lo=hi$ 即答案。
- **二分答案**：判定函数 $f(v)$（"容量 $v$ 是否可行"）单调时，可对 $v$ 二分，把最优化转判定。

### 2. 核心公式
左闭右开写法（配合 lower_bound）：
$$lo=0,\ hi=n;\qquad mid=lo+(hi-lo)//2;\qquad A[mid]<x\Rightarrow lo=mid+1,\ \text{否则 }hi=mid$$
$$T(n)=T(n/2)+O(1)=\Theta(\log n),\quad 空间\ O(1)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $lo,hi$ | 候选区间下界/上界 | $[0,n]$ | 左闭右开 |
| $mid$ | 中点 | $[lo,hi)$ | 防溢出写法 |
| $x$ | 目标值 | 与 $A$ 同型 | |
| $f(v)$ | 判定函数 | 布尔 | 须单调 |

### 4. 常见变体与适用条件
- **变体**：普通查找、lower_bound、upper_bound、浮点二分（定次数/精度）、三分（单峰）。
- **适用条件**：有序 + 随机访问 + 可比较；二分答案要求判定函数单调。限制：无序、链表、不可比较时不可用。

---

## 6. 推导思路和思想来源

- **最初困难**：路径数量指数爆炸（此处为查找次数），线性扫描浪费"有序"信息。
- **直接方法局限**：[[双指针]] 从两头扫只解决特定问题（两数之和），不能任意查找。
- **关键"转念"**：**不按位置逐个找，而按"大小关系"做排除**——每次比较中点，用有序性断定目标在左半/右半，另一半直接丢弃。
- **推导主线与动机**：区间 $[lo,hi)$ 含答案 → 取 $mid$ → 比较后收缩 → 区间长度每轮减半 → $\log_2 n$ 轮后长为 1 → 终止。正确性 = 不变式 + 区间单调收缩 + 终止条件。
- **为什么自然得到此结论**：信息论下界就是 $\log_2 n$ 次比较，二分恰好达到，是"必然的最优解"而非巧合。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：在 $[1,3,5,7,9,11]$ 中查找 $7$，再求 $8$ 的 lower_bound。
- **解题思路与关键步骤**：$lo=0,hi=6$；$mid=3$（值 7）命中 → 返回 3。找 $8$：$mid=3$（7<8）→ $lo=4$；$mid=5$（11≥8）→ $hi=5$；$mid=4$（9≥8）→ $hi=4$；$lo=hi=4$。
- **最终答案**：$7$ 在下标 3；$8$ 的 lower_bound 为 4。
- **易错点**：$hi$ 初始为 $n$ 而非 $n-1$；更新用 $hi=mid$ 而非 $mid-1$；重复元素时 lower_bound 返回"第一个 $\ge x$"。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：力扣 33 旋转排序数组 $[4,5,6,7,0,1,2]$ 查找 $0$，要求 $O(\log n)$。
- **解题思路与完整解答**：每次取 $mid$ 后先判断哪半有序：$A[lo]\le A[mid]$ 则左半有序，若目标在 $[A[lo],A[mid]]$ 内则 $hi=mid$，否则 $lo=mid+1$；左半无序则右半必有序，对称处理。本题：$mid=3$（7），左半 $[4,7]$ 有序但 $0\notin$ → $lo=4$；$mid=5$（1），$A[4]=0\le1$ 且 $0\in[0,1]$ → $hi=5$；$mid=4$（0）命中。
- **易错点**：含重复元素（如 $[1,0,1,1,1]$）会破坏"判断哪半有序"，退化为线性收缩。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：力扣 875 吃香蕉——最小速度 $k$ 使 $\sum\lceil p_i/k\rceil\le h$，判定函数单调，二分 $k$：
```python
def minEatingSpeed(piles, h):
    def ok(k): return sum((p + k - 1) // k for p in piles) <= h
    lo, hi = 1, max(piles)
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid): hi = mid
        else: lo = mid + 1
    return lo
```
"最小化最大值"类题标准模板：**二分答案 + 贪心判定**。

## 8. 常见误区和易混概念

### 误区 1：边界条件全靠"背模板"
- **错误直觉**：`while lo <= hi`、`lo=mid+1`、`hi=mid-1` 三件套背下来就行。
- **为什么错**：换左闭右开或找左边界写法立即死循环或漏答案。
- **正确理解**：每次更新必须维持不变式"答案仍在区间内"且区间严格收缩（`lo=mid` 在 $hi-lo=1$ 时死循环）。

### 误区 2：以为二分要求"严格有序"
- **错误直觉**：数组必须严格递增。
- **为什么错**：lower_bound 在非降（含重复）数组上依然正确。
- **正确理解**：真正前提是**单调性**——比较结果能一致地排除一半。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 线性查找 | 任意序列找目标 | $O(n)$、无需有序 | 无序小数组 |
| 二分搜索 | 有序序列找目标 | $O(\log n)$、需随机访问 | 有序数组、数据库索引 |
| 哈希查找（[[哈希表HashTable]]） | 找目标 | 均摊 $O(1)$、无序 | 精确匹配、去重 |
| 二分答案 | 最优化求极值 | 判定函数单调即可 | 最小化最大值类 |

### 题目与解析

#### 1. 二分搜索需要哪些前提？链表上为什么不能二分？
> [!question]- 答案解析
> - **答案**：① 有序（单调）；② $O(1)$ 随机访问；③ 可比较。链表取中点 $O(n)$，"砍半"收益被抵消，总复杂度反而更差。
> - **解析**：随机访问让"取 mid"是常数时间。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 手算：在 $[2,4,6,8,10,12]$ 中用左闭右开二分查找 $10$，写出每轮 $lo,mid,hi$ 与比较次数。
> [!question]- 答案解析
> - **答案**：$lo=0,hi=6$；① $mid=3$（8<10）→ $lo=4$；② $mid=5$（12≥10）→ $hi=5$；③ $mid=4$（10≥10）→ $hi=4$；返回 4，共 3 次（$2^3=8>6$，符合 $\lceil\log_2 6\rceil=3$）。
> - **解析**：lower_bound 语义下 $hi=mid$ 而非 $mid-1$，命中后还会向左收缩。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 3. 判断：`while lo < hi: mid=(lo+hi)//2; if A[mid]<x: lo=mid; else: hi=mid` 会怎样？
> [!question]- 答案解析
> - **答案**：当 $hi-lo=1$ 且 $A[lo]<x$ 时 $mid=lo$、$lo$ 不变 → **死循环**。
> - **解析**：`lo=mid` 必须保证区间收缩；正确写法 `lo=mid+1`（$A[mid]<x$ 时 $mid$ 不可能是答案）。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 4. 力扣 875：$piles=[3,6,7,11],h=8$，二分答案求最小速度 $k$。
> [!question]- 答案解析
> - **答案**：$k\in[1,11]$。$mid=6$：$1+1+2+2=6\le8$ → $hi=6$；$mid=3$：$1+2+3+4=10>8$ → $lo=4$；$mid=5$：$1+2+2+3=8$ → $hi=5$；$mid=4$：$1+2+2+3=8$ → $hi=4$。答案 $k=4$。
> - **解析**：判定函数关于 $k$ 单调不增，可行域是后缀区间，二分其左端点。
> - **Obsidian 标签建议**：`#自测题/中等`

#### 5. 证明：左闭右开二分搜索必然终止且返回正确位置。
> [!question]- 答案解析
> - **答案**：不变式"答案恒在 $[lo,hi)$ 内"。① 初始 $[0,n)$ 成立；② $A[mid]<x$ 则答案在 $[mid+1,hi)$，否则在 $[lo,mid)$——不变式保持；③ 每轮 $hi-lo$ 至少减半，有限步后 $hi-lo=1$；④ 退出时 $lo=hi$ 即唯一候选。复杂度 $O(\log n)$。
> - **解析**："不变式 + 度量递减 + 终止"三段式证明是面试证明万能模板。
> - **Obsidian 标签建议**：`#自测题/较难`
