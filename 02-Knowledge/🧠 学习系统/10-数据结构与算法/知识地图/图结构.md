# 图结构

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：图是"关系"的通用模型（社交网络、地图、依赖关系），图算法是课程后半程的重心：[[图遍历BFS与DFS]]、[[Dijkstra最短路径]]、[[拓扑排序与DAG动态规划]]、[[并查集]] 全部建立在"图的表示与性质"之上。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：树只能表达"一对多"的层级关系，但现实是"多对多"：谁和谁是好友、哪两个城市有航线、哪个任务依赖哪个任务。图用"顶点 + 边"统一表达任意二元关系，本节解决两个问题：**怎么把图存进计算机**（表示法）、**图有哪些基本性质**（度、连通性、路径、环），这是所有图算法的地基。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：图的表示决定算法复杂度（邻接矩阵 $O(V^2)$ vs 邻接表 $O(V+E)$）；性质（DAG、连通分量）直接通向 [[拓扑排序与DAG动态规划]]、[[并查集]] 与最短路径。
- **实际应用场景**：社交推荐（好友图）、地图导航（路网）、依赖构建（Makefile/包管理器 DAG）、网络路由（[[Dijkstra最短路径]]）。
- **高频题型/任务**：图的存储选型、度/连通性判断、环检测、二分图判定（BFS 染色）、DAG 判定、图遍历（[[图遍历BFS与DFS]]）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[数组与链表]]**：邻接表 = 顶点数组 + 边链表/动态数组。
2. **[[栈与队列]]**：DFS 用栈（递归）、BFS 用队列。
3. **[[递归]]**：DFS 的递归实现与访问顺序。

---

## 4. 用直觉语言解释它

> «"图就是'关系地图'：点是地图上的地点，线是连通它们的道路（边可以带方向、带长度）。存图有两种方式：邻接矩阵像一张'两地之间有没有路'的查询表（查得飞快但费纸），邻接表像每个地点挂一块牌子'从这里出发能去哪'（省纸但查起来要翻牌子）。"»

- **直觉类比/几何图像**：地图/社交网络；矩阵 = 全表，邻接表 = 出度清单。
- **为什么很自然**：关系数据要么"全量查询"（矩阵）要么"按点展开"（邻接表），两种存法对应两种访问模式。
- **一句话直觉本质**：**图 = 顶点集 + 边集（可有向/带权）；邻接矩阵以 $O(V^2)$ 空间换 $O(1)$ 边查询，邻接表以 $O(V+E)$ 空间换 $O(deg)$ 邻居枚举——稀疏图用表、稠密图用矩阵。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **图**：$G=(V,E)$，$V$ 顶点集、$E$ 边集；**无向图**（边无方向）、**有向图**（边有方向）、**带权图**（边有权重 $w:E\to\mathbb{R}$）。
- **邻接矩阵**：$A[u][v]=1$（或权值）表示边 $(u,v)$ 存在；空间 $O(V^2)$。
- **邻接表**：每个顶点一个列表存其邻居；空间 $O(V+E)$。
- **基本性质**：度（无向）/$入度·出度$（有向）、路径与简单路径、连通/强连通、环、**DAG**（有向无环图）、二分图。

### 2. 核心公式
存储对比：
$$\text{矩阵：空间 }O(V^2),\ \text{边查询 }O(1);\qquad \text{邻接表：空间 }O(V+E),\ \text{邻居枚举 }O(deg(u))$$
度数恒等式：$$\sum_{v\in V} deg(v)=2|E|\quad(\text{无向});\qquad \sum_{v} indeg(v)=\sum_v outdeg(v)=|E|\quad(\text{有向})$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $V, E$ | 顶点集、边集 | $\|V\|=n,\ \|E\|=m$ | |
| $deg(v)$ | 顶点 $v$ 的度 | $[0,n-1]$ | 无向 |
| $A[u][v]$ | 邻接矩阵元素 | 0/1 或权值 | |
| $w(u,v)$ | 边权 | 实数 | 带权图 |

### 4. 常见变体与适用条件
- **变体**：无向/有向/带权/多重图/自环；特殊图：树（连通无环）、DAG、二分图、完全图。
- **适用条件**：关系建模通用；稀疏图（$m\ll n^2$）用邻接表，稠密图（$m\approx n^2$）用邻接矩阵（或 Floyd 类算法）。限制：邻接矩阵无法表示 $n>10^4$ 的稀疏图（空间爆炸）。

---

## 6. 推导思路和思想来源

- **最初困难**：多对多关系如何存储与遍历？
- **直接方法局限**：树结构表达不了任意关系；朴素"边列表"（存所有边对）无法快速回答"$u$ 的邻居是谁"。
- **关键"转念"**：**按访问模式设计存储**——要"查任意两点间是否有边"就开 $n\times n$ 表（矩阵）；要"遍历邻居"就把每个顶点的邻居收拢成列表（邻接表）。两种模式对应两类算法（矩阵适合全对全查询如 Floyd，表适合遍历如 BFS/DFS/Dijkstra）。
- **推导主线与动机**：定义图与性质 → 两种表示与复杂度 → 遍历（DFS/BFS）作为"读图"的基本操作 → 性质判定（环、连通、二分）复用遍历 → 高级算法（最短路径、拓扑）建立其上。
- **为什么自然得到此结论**：图的算法几乎都以"遍历邻居"为原语，邻接表让遍历代价 $O(V+E)$ 达到下界——所以它是竞赛与工业的默认选择。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：图 $G$：$V=\{a,b,c,d\}$，无向边 $(a,b),(b,c),(c,d),(a,d),(b,d)$。写出邻接矩阵与邻接表，求各顶点度。
- **解题思路与关键步骤**：矩阵 $5\times5$（对角线 0）：$a$ 行 $[0,1,0,1]$ 等；邻接表：$a:[b,d],\ b:[a,c,d],\ c:[b,d],\ d:[a,c,b]$。度：$deg(a)=2,deg(b)=3,deg(c)=2,deg(d)=3$。
- **最终答案**：如上；度数之和 $=10=2|E|$（$|E|=5$）验证恒等式。
- **易错点**：无向图邻接表每条边存两次；矩阵对角元为 0（无自环）。
- **🤔 追问**：该图连通吗？——是（任意两点有路径）；有环吗？——有（如 $a\to b\to d\to a$）。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：判定有向图是否为 DAG（有向无环图），并说明与拓扑排序的关系。
- **解题思路与完整解答**：DFS 三色标记（白=未访问、灰=在栈中、黑=完成）：若 DFS 遇到"灰"邻居则存在后向边 → 有环。或 Kahn 算法：反复删除入度为 0 的顶点，若最终删除数 $<|V|$ 则有环。DAG ⇔ 存在拓扑序 ⇔ 无环。例：$a\to b,\ a\to c,\ b\to c$ 是 DAG（拓扑序 $a,b,c$）；加边 $c\to a$ 后成环，无拓扑序。
- **易错点**：把"访问过"（黑）误判为环——只有"灰色（递归栈中）"才构成后向边；Kahn 算法要正确维护入度。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：邻接表的构建与 BFS（图算法标准骨架）：
```python
from collections import deque
adj = [[] for _ in range(n)]               # 邻接表
for u, v in edges: adj[u].append(v); adj[v].append(u)   # 无向
dist = [-1]*n; dist[0] = 0; q = deque([0])
while q:
    u = q.popleft()
    for v in adj[u]:
        if dist[v] == -1: dist[v] = dist[u]+1; q.append(v)
```
真实场景：社交网络"六度分隔"（无权 BFS 最短路）、包管理器依赖解析（DAG 拓扑排序，见 [[拓扑排序与DAG动态规划]]）、路网最短路径（[[Dijkstra最短路径]]）。

## 8. 常见误区和易混概念

### 误区 1：邻接矩阵"空间省"或邻接表"查询快"
- **错误直觉**：矩阵更全能，表更省事，随便选。
- **为什么错**：矩阵 $O(n^2)$ 空间在稀疏图（$n=10^5,m=10^5$）直接内存爆炸；表查询"两点间是否有边"需 $O(deg)$。
- **正确理解**：稀疏（$m\ll n^2$）→ 邻接表；稠密或需要 $O(1)$ 边查询 → 矩阵；混合需求可"表 + 哈希集合"。

### 误区 2：把"树"与"图"的遍历混为一谈
- **错误直觉**：图遍历不需要记录"已访问"。
- **为什么错**：图有环，不标记 visited 会死循环；树天然无环（每个节点一个父），无需标记。
- **正确理解**：图遍历必须 visited（或三色标记），且要考虑"起点不可达"的连通分量。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 树（[[二叉树]]） | 层级关系 | 无环连通、$n-1$ 条边 | 目录、表达式 |
| 图 | 任意二元关系 | 可环、可多分量 | 社交、路网 |
| DAG | 依赖关系 | 有向无环、可拓扑排序 | 任务调度 |
| 并查集（[[并查集]]） | 连通性动态维护 | 只答"是否连通"不答路径 | Kruskal |

### 题目与解析

#### 1. 有向图与无向图、带权图的区别？各自适用场景？
> [!question]- 答案解析
> - **答案**：无向边无方向（好友）；有向边有方向（关注/依赖）；带权边有代价（距离/延迟）。场景：好友网络（无向）、任务依赖（有向）、路网（有向带权）。
> - **解析**：建模第一步是确定"关系是否有方向、是否有代价"。
> - **易错原因**：把"依赖关系"建模成无向图（依赖有方向）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 无向图有 10 个顶点、度数和为 42，边数是多少？可能吗？
> [!question]- 答案解析
> - **答案**：$|E|=42/2=21$。可能：$K_{10}$ 有 45 条边，21 条边可行（任意 21 条边）。
> - **解析**：$\sum deg=2|E|$（握手引理），边数必须是"度数和的一半"。
> - **易错原因**：忘记除以 2（每条边贡献两个度）。

#### 3. $n=10^5$ 顶点、$m=10^5$ 边的稀疏图，选哪种存储？为什么？
> [!question]- 答案解析
> - **答案**：邻接表（空间 $O(V+E)=2\times10^5$）。邻接矩阵需 $10^{10}$ 个元素（约 40GB），直接不可行。
> - **解析**：稀疏图矩阵空间 $O(n^2)$ 爆炸；邻接表空间与边数成正比。
> - **易错原因**：不考虑 $n$ 的量级就选矩阵。

#### 4. 用 Kahn 算法判断 `a→b, a→c, b→c, c→b` 是否有环。
> [!question]- 答案解析
> - **答案**：有环。入度：$a=0,b=2,c=2$？精确：$indeg(a)=0, indeg(b)=2$（来自 a,c）, $indeg(c)=2$（来自 a,b）。删除 $a$ 后 $indeg(b)=1, indeg(c)=1$，无人度为 0 → 删除数 $1<3$ → 有环（$b,c$ 互指）。
> - **解析**：环 ⇔ 无法删光所有顶点；Kahn 的删除顺序即拓扑序。
> - **易错原因**：入度计算漏边（$c\to b$ 影响 $indeg(b)$）。

#### 5. 证明：无向图可二分染色（二分图）⇔ 无奇环，并给出判定算法。
> [!question]- 答案解析
> - **答案**：⇒ 二分图中每条边跨两色，任何环必须偶数次跨色，故无奇环。⇐ 反证：任取一个连通分量 BFS 染色（起点色 0，邻居异色）；若出现"同色相邻"则存在奇环（沿 BFS 树两路径合并长度和为奇数）。算法：BFS/DFS 染色，遇到冲突边即非二分图，$O(V+E)$。例：三角形（3-环）染色冲突 → 非二分；$C_4$ 可染成 0,1,0,1 → 二分。
> - **解析**："奇环 ⇔ 非二分"是图论的经典充要条件，BFS 染色是最短证明路径。
> - **易错原因**：只做"局部两色"检查而忘记跨层约束（与 [[二叉树]] 的 BST 判定误区同构）。
