# 状态压缩

---

## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具，值得深挖）**
- **判断理由**：当 DP 状态需要描述"哪些元素已被使用"时，位掩码是把集合装进一个整数的标准手段；TSP、Hamilton 路径、子集枚举是竞赛高频题（[[🏆 竞赛应用维度]]），面试中作为进阶 DP 题出现。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：旅行商问题（TSP）需要记录"当前在城市 $i$，且已访问过城市集合 $S$"——状态里含一个集合，朴素做法用布尔数组表示 $S$，导致状态维度爆炸、无法直接做 DP。状态压缩的转念：**集合 $S\subseteq\{0,\dots,n-1\}$ 可以用 $n$ 位二进制数表示**，$2^n$ 个集合对应 $2^n$ 个整数，状态 $(i,S)$ 直接变成二维 DP 表 $dp[i][mask]$。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：位掩码是 [[动态规划]] 的"状态编码"进阶（状态数从指数级集合压缩为整数）；也是 [[回溯算法]] 的剪枝加速器（`used` 用位运算判断）。
- **实际应用场景**：TSP 及变体（物流配送）、Hamilton 路径、图着色、子集划分、位运算技巧题（[[🏆 竞赛应用维度]]）。
- **高频题型/任务**：TSP 最短环、Hamilton 路径计数、子集枚举求和、"每个人都必须做一件事"类分配问题。

---

## 3. 学它之前需要哪些前置知识？

1. **[[动态规划]]**：状态设计与转移方程是 DP 基本功（状态压缩只是把状态编码成位掩码）。
2. **[[回溯算法]]**：理解"集合状态"的朴素枚举方式，才能体会压缩的收益。
3. **[[图结构]]**：TSP 需要邻接矩阵（$O(n^2)$ 距离表）。

---

## 4. 用直觉语言解释它

> «"状态压缩就像用一排开关表示'谁已经去过'：4 个城市就 4 个开关，`1011` 表示去过城市 0、1、3。DP 表格里每个格子是'当前站在城市 i，开关状态是 mask'时的最短路径——从 $n$ 个集合变量变成 1 个整数，表格才能画得下。"»

- **直觉类比/几何图像**：一排灯泡开关（亮=已访问）、二进制计数器。
- **为什么很自然**：计算机里集合本质就是位图；$2^n$ 个状态恰好是整数 $0..2^n-1$，天然可索引、可做 DP 表下标。
- **一句话直觉本质**：**用 $n$ 位二进制数 $mask$ 编码"已使用元素的集合"，把含集合的复杂状态变成普通整数，从而可以写 DP：$dp[mask][i]$ = 已访问 $mask$、当前在 $i$ 的最优值。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **位掩码（bitmask）**：整数 $mask$ 的第 $k$ 位（$mask>>k \& 1$）表示元素 $k$ 是否在集合中。
- **常用位运算**：加入元素 `mask | (1<<k)`；删除元素 `mask & ~(1<<k)`；判断存在 `mask>>k & 1`；子集枚举 `for sub = mask; sub; sub = (sub-1) & mask`；集合大小 `bin(mask).count('1')`。
- **状态压缩 DP**：$dp[mask][i]$ = 已访问集合为 $mask$ 且最后位于 $i$ 的最优值；转移：从 $i$ 走到未访问的 $j$。

### 2. 核心公式
TSP（从 0 出发，访问全部城市回到 0）：
$$dp[mask][i]=\min_{j\in mask,\ j\ne i}\big(dp[mask\setminus\{i\}][j]+w(j,i)\big)$$
答案：$$\min_{i}\ dp[(1<<n)-1][i]+w(i,0);\qquad T(n)=O(n^2 2^n),\quad S(n)=O(n2^n)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $mask$ | 已访问集合的位掩码 | $[0, 2^n)$ | 第 $k$ 位=城市 $k$ |
| $dp[mask][i]$ | 访问 $mask$ 且最后在 $i$ 的最短路 | $\ge0$ | 主状态 |
| $w(i,j)$ | 城市间代价 | $\ge0$ | 邻接矩阵 |
| $n$ | 城市数 | $\le 20$ 左右 | $2^n$ 可承受 |

### 4. 常见变体与适用条件
- **变体**：Hamilton 路径/回路计数、子集划分（平分数组）、蒙德里安的梦想（铺砖）、旅行商回程、带位掩码的记忆化搜索（[[回溯算法]] + memo）。
- **适用条件**：$n\le20$（$2^n\le10^6$）；状态含"集合"。限制：$n$ 再大需启发式/分支限界；位运算注意整数溢出（Python 无此问题，C++ 用 `int64`）。

---

## 6. 推导思路和思想来源

- **最初困难**：TSP 状态含"访问过的城市集合"，直接枚举 $n!$ 条路径不可行；把"集合"作为状态又没法索引。
- **直接方法局限**：贪心（最近邻）不保证最优；[[回溯算法]] 全枚举 $O(n!)$。
- **关键"转念"**：**观察到 DP 最优子结构：到城市 $i$ 的最短 Hamilton 路径 = 到某前驱 $j$ 的最短路径 + 边 $(j,i)$**；而"到 $i$ 的最短路径"只依赖"访问了哪些城市"而不依赖"访问顺序的细节"——集合用位掩码编码后，$(mask, i)$ 就是可索引的 DP 状态。
- **推导主线与动机**：定义 $dp[mask][i]$ → 转移枚举最后一步的前驱 $j$ → 按 $mask$ 从小到大填表（子集先于超集）→ 答案闭合回路。
- **为什么自然得到此结论**：$2^n$ 个掩码恰好铺满状态空间，每个状态只算一次，把 $O(n!)$ 压到 $O(n^2 2^n)$——"以空间（指数但可承受）换时间（避免重复枚举）"。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：4 城市距离矩阵 $w$：$w(0,1)=2, w(0,2)=9, w(0,3)=10, w(1,2)=6, w(1,3)=4, w(2,3)=8$（对称）。求从 0 出发回到 0 的最短 TSP 环。
- **解题思路与关键步骤**：$dp[\{0\}][0]=0$。扩展：$dp[\{0,1\}][1]=2$；$dp[\{0,2\}][2]=9$；$dp[\{0,3\}][3]=10$。再扩展：$dp[\{0,1,2\}][2]=\min(dp[\{0,1\}][1]+6,\ dp[\{0,2\}][2]+9)=8$；$dp[\{0,1,2\}][1]=\min(dp[\{0,2\}][2]+6,\ dp[\{0,1\}][1]+9)=15$；... 逐步到 $mask=1111$：$dp[1111][1]=\min(dp[1110][2]+6, dp[1110][3]+4)$。
- **最终答案**：$0\to1\to3\to2\to0$：$2+4+8+9=23$（最优；直接 $0\to1\to2\to3\to0$ 是 $2+6+8+10=26$）。手算要点：逐层扩展掩码，只保留"最后位置"维度。
- **易错点**：忘记闭合回路的最后一步 $+w(i,0)$；初始化只给 $dp[1][0]=0$。
- **🤔 追问**：若要求"恰好访问一次且不要求回起点"（Hamilton 路径）？——答案取 $\min_i dp[(1<<n)-1][i]$，去掉闭合项即可。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：子集枚举求和：求 $nums=[1,2,3]$ 所有子集和，用位掩码实现。
- **解题思路与完整解答**：`for mask in range(1<<3)`：对 `mask=5`（101）求和 = `nums[0]+nums[2]=4`。8 个掩码对应 8 个子集：`0,1,2,3,3,4,5,6`。进一步：枚举 $mask$ 的所有子集用 `sub=(sub-1)&mask`，如 `mask=6`（110）的子集：`6,4,2,0`——这是"枚举子集的子集"的竞赛套路（$O(3^n)$ 总复杂度）。
- **易错点**：`sub-1 & mask` 运算优先级（写成 `(sub-1) & mask`）；漏掉空集 0。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：TSP 的位掩码实现（$n\le16$ 内可行）：
```python
def tsp(n, w):
    dp = [[float('inf')]*n for _ in range(1<<n)]
    dp[1][0] = 0
    for mask in range(1, 1<<n):
        for i in range(n):
            if not (mask >> i) & 1: continue
            for j in range(n):
                if (mask >> j) & 1 or w[i][j] == INF: continue
                dp[mask | (1<<j)][j] = min(dp[mask | (1<<j)][j], dp[mask][i] + w[i][j])
    return min(dp[(1<<n)-1][i] + w[i][0] for i in range(1, n))
```
真实场景：物流配送路径规划、PCB 钻孔顺序优化；配合剪枝（分支限界）可处理 $n\le30$ 的近似规模。

## 8. 常见误区和易混概念

### 误区 1：位运算优先级写错
- **错误直觉**：`mask | 1 << k` 等价于 `(mask|1) << k`。
- **为什么错**：`<<` 优先级高于 `|`，`mask | 1 << k` 实际是 `mask | (1<<k)`——多数场景恰好想要后者，但判断 `mask>>k & 1` 必须写括号。
- **正确理解**：涉及位运算与比较/算术混用一律加括号，读代码也按"移位优先"理解。

### 误区 2：以为状态压缩 DP 是"位运算技巧"，忽略 DP 本身
- **错误直觉**：会 `mask | (1<<k)` 就会状态压缩 DP。
- **为什么错**：核心难点仍是**状态设计与转移顺序**（$mask$ 必须按子集序从小到大），位运算只是编码。
- **正确理解**：先设计"状态 = (集合, 最后位置)"，再套位运算；转移顺序错了（如按 $i$ 外循环）会用到未计算的子状态。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 状态压缩 | 集合状态编码 | 位掩码整数化 | TSP、子集 DP |
| 普通 DP（[[动态规划]]） | 标量/序列状态 | 状态是数字或索引 | 背包、LIS |
| 回溯（[[回溯算法]]） | 枚举所有解 | 无记忆化 | 全排列、N 皇后 |
| 位运算 | 底层操作 | 快但易错优先级 | 掩码、子集枚举 |

### 题目与解析

#### 1. 用位掩码表示集合 {1,3,4}（元素编号从 0 开始）并写出"加入元素 2"的运算。
> [!question]- 答案解析
> - **答案**：`mask = (1<<1)|(1<<3)|(1<<4) = 2+8+16 = 26`（二进制 11010）；加入元素 2：`mask | (1<<2) = 26|4 = 30`（11110）。
> - **解析**：第 $k$ 位为 1 ⇔ 元素 $k$ 在集合中；或运算置位。
> - **易错原因**：位编号从 0 开始还是 1 开始搞混（与题目约定一致）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 枚举 `mask=10`（1010）的所有非空子集。
> [!question]- 答案解析
> - **答案**：`sub=10 → 8 → 2 → 0`（用 `sub=(sub-1)&mask`），即 {1,3}、{3}、{1}、∅（元素 1、3）。
> - **解析**：`(sub-1)&mask` 的技巧保证只清除掩码中为 1 的位，且遍历全部子集。
> - **易错原因**：直接用 `sub-1` 会得到掩码外的位。

#### 3. TSP 状态为什么是"集合 + 最后位置"二维？去掉"最后位置"行不行？
> [!question]- 答案解析
> - **答案**：转移需要知道"当前在哪"才能加边权 $w(i,j)$；若只有集合，不知道从哪个城市出发扩展，转移不闭合。可以去掉"最后位置"的变体是"集合权值和"类问题（与顺序无关）。
> - **解析**：状态必须携带转移所需的全部信息——这是 DP 状态设计第一原则。
> - **易错原因**：状态缺信息导致转移方程写不出来或写错。

#### 4. 求无向图中从 0 出发覆盖全部 $n$ 个顶点的 Hamilton 路径数量（$n\le15$）。
> [!question]- 答案解析
> - **答案**：$dp[mask][i]$ = 访问 $mask$ 且终点为 $i$ 的路径数；$dp[1][0]=1$；转移 $dp[mask|(1<<j)][j]+=dp[mask][i]$（若边 $(i,j)$ 存在且 $j\notin mask$）；答案 $\sum_i dp[(1<<n)-1][i]$。$T=O(n^2 2^n)$，$n=15$ 时约 $7\times10^6$ 状态，可行。
> - **解析**：计数 DP 与最优化 DP 同构——把 `min` 换成累加。
> - **易错原因**：忘记初始化 $dp[1][0]=1$；把无向图当有向图重复计数。

#### 5. 论证 TSP 的 $O(n^2 2^n)$ 复杂度与正确性，并说明 $n$ 的可行上限。
> [!question]- 答案解析
> - **答案**：状态数 $n\cdot2^n$，每个状态枚举 $n$ 个前驱，总 $O(n^2 2^n)$，空间 $O(n2^n)$。正确性：最优子结构——到 $(mask,i)$ 的最优路径，其"去掉最后一步"的前缀必是到 $(mask\setminus\{i\}, j)$ 的最优路径（否则替换前缀可得到更优），归纳成立。$n=20$ 时 $2^{20}\approx10^6$、$n\cdot2^n\approx2\times10^7$ 可行；$n=25$ 时 $8\times10^8$ 状态已吃紧，需分支限界/启发式（竞赛中 $n\le16$ 常见）。
> - **解析**：$O(n^2 2^n)$ 仍是指数，但把 $O(n!)$ 降了指数级——这是"多项式空间换指数时间"的典型交易。
> - **易错原因**：忽略空间 $O(n2^n)$ 在大 $n$ 时同样爆炸。
