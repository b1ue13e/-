# 🧠 算法思想维度

> 算法思想是"怎么想问题"的思维模式：贪心赌局部最优、分治拆子问题、回溯穷举加剪枝、动态规划记状态、状态压缩把指数级状态装进位掩码。这是算法能力的核心体现。

## 维度主题清单

| 主题 | 笔记 | 一句话说明 |
|:---|:---|:---|
| 分治算法 | [[分治算法]] | 分解→解决→合并三步 + 主定理定复杂度 |
| 贪心算法 | [[贪心算法]] | 贪心选择性质 + 交换论证，局部最优推出全局最优 |
| 回溯算法 | [[回溯算法]] | 决策树深度搜索 + 剪枝，组合/排列/子集通吃 |
| 动态规划 | [[动态规划]] | 最优子结构 + 重叠子问题，用状态表换掉重复计算 |
| 状态压缩 | [[状态压缩]] | 位掩码表示集合状态，DP 状态数骤减（如 TSP） |

## 推荐学习顺序

1. **[[分治算法]]** 与 **[[贪心算法]]** 先行：思路最直白、证明最规范；
2. **[[回溯算法]]**：穷举思想的正式化，为 DP 做铺垫；
3. **[[动态规划]]**：五兄弟中的重头戏，需吃透状态设计；
4. **[[状态压缩]]** 最后：动态规划的高阶变体，需要位运算基础。

## 维度交叉

- 分治 + 递归树 → 主定理（[[复杂度分析]] 延伸）；
- 贪心 vs DP → 判断"局部最优是否安全"（[[动态规划]] 有对比表）；
- 回溯 + 记忆化 → 过渡到 DP；回溯 + 位运算 → [[状态压缩]]。
