# 动态规划

> 📌 **完整入门笔记见根目录**：[[动态规划入门]]。本篇是知识地图视角的精简版，聚焦"DP 是什么、何时用、怎么设计状态"的地图级概览。

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：DP 是算法思想维度的"重头戏"（[[🧠 算法思想维度]]）：背包、LIS、区间 DP、树形 DP 全是它；面试与竞赛的高频难点，与贪心/回溯的辨析是常考点。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：最优化与计数问题（背包、最长子序列、爬楼梯）用 [[回溯算法]] 枚举会指数爆炸；很多子问题被反复计算（斐波那契）。DP 的转念：**把"重复计算的子问题"只算一次并保存**，用表格（或记忆化）把指数级搜索变成多项式级填表。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：与贪心、分治并列三大范式；[[状态压缩]] 是它的进阶编码；[[拓扑排序与DAG动态规划]]、[[Bellman-Ford与负环检测]] 是它在图上的应用。
- **实际应用场景**：资源分配（背包）、基因序列比对（LCS）、路径规划（网格 DP）、文本断词。
- **高频题型/任务**：0-1 背包、LIS/LCS、爬楼梯/斐波那契、区间 DP（石子合并）、树形 DP、数位 DP、[[状态压缩]] DP（TSP）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[递归]]**：自顶向下 DP = 递归 + 记忆化。
2. **[[回溯算法]]**：理解"枚举"为何慢，DP 为何快（重叠子问题）。
3. **[[复杂度分析]]**：状态数 × 转移代价 = 复杂度公式。

---

## 4. 用直觉语言解释它

> «"DP 就像记账本：爬楼梯到第 $n$ 级的方法数，不用每次从零枚举——把算过的 $f(k)$ 记在本子上，要用时直接翻（记忆化）；或者干脆从 $f(1)$ 开始一路填表填到 $f(n)$（自底向上）。'状态'是账本的一行，'转移方程'是这一行怎么由上一行算出来。"»

- **直觉类比/几何图像**：记账本/填表格；"记住答案，别再算第二遍"。
- **为什么很自然**：子问题重复出现 → 存起来；子问题有依赖序 → 按序填表。
- **一句话直觉本质**：**DP = 最优子结构（全局最优由子问题最优拼出）+ 重叠子问题（子问题重复出现）+ 状态转移方程（子问题间的关系）；实现用记忆化（自顶向下）或填表（自底向上）。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **最优子结构**：问题的最优解包含子问题的最优解（与贪心共用此性质，但 DP 不要求贪心选择性质）。
- **重叠子问题**：递归展开时同一子问题被多次求解（区别于分治的独立子问题）。
- **状态**：描述"已决策到哪、剩余信息是什么"的最小元组；**转移方程**：状态之间的递推关系；**边界条件**：最小状态的初值。
- **实现**：自顶向下（递归 + memo 表）或自底向上（按依赖序填表，可滚动数组优化空间）。

### 2. 核心公式
0-1 背包（容量 $W$，物品 $i$ 重量 $w_i$、价值 $v_i$）：
$$dp[i][c]=\max(dp[i-1][c],\ dp[i-1][c-w_i]+v_i)\quad(c\ge w_i)$$
LIS（最长递增子序列）：$$dp[i]=1+\max_{j<i,\ A[j]<A[i]} dp[j]$$
复杂度范式：$$T(n)=O(\text{状态数}\times\text{每状态转移代价})$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $dp[i][c]$ | 前 $i$ 个物品、容量 $c$ 的最大价值 | $\ge0$ | 0-1 背包 |
| $w_i, v_i$ | 物品重量、价值 | $>0$ | |
| $W$ | 背包容量 | $\ge0$ | 状态维度 |
| $dp[i]$ | 以 $A[i]$ 结尾的 LIS 长度 | $\ge1$ | LIS |

### 4. 常见变体与适用条件
- **变体**：线性 DP、背包（0-1/完全/多重）、区间 DP、树形 DP、数位 DP、[[状态压缩]] DP、概率 DP。
- **适用条件**：最优子结构 + 重叠子问题。限制：状态空间爆炸时（$n$ 大、$W$ 大）需优化（滚动数组、斜率优化、单调队列优化）或换思路；无重叠子问题时优先分治/贪心。

---

## 6. 推导思路和思想来源

- **最初困难**：枚举所有方案指数爆炸；递归+回溯重复计算。
- **直接方法局限**：[[回溯算法]] 无记忆化时 $O(2^n)$；分治要求子问题独立（背包不满足）。
- **关键"转念"**：**"重复计算"是可以消除的**——把子问题的解存起来；更进一步，子问题之间存在固定的依赖序，可以按序填表而完全不递归。
- **推导主线与动机**：递归展开发现重叠 → 记忆化（自顶向下）→ 分析依赖序转填表（自底向上）→ 优化空间（滚动数组）→ 推广到区间/树形/位掩码状态。
- **为什么自然得到此结论**：DP 本质是"DAG 上的最长/最短路"：状态是节点、转移是边，无环（依赖序）保证填表一次正确——与 [[拓扑排序与DAG动态规划]] 完全同构。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：爬楼梯：一次 1 或 2 级，到第 4 级几种走法？
- **解题思路与关键步骤**：$f(n)=f(n-1)+f(n-2)$，$f(1)=1,f(2)=2$。填表：$f(3)=f(2)+f(1)=3$，$f(4)=f(3)+f(2)=5$。
- **最终答案**：5 种（1+1+1+1、1+1+2、1+2+1、2+1+1、2+2）。
- **易错点**：$f(0)$ 定义（设 $f(0)=1$ 时 $f(2)=2$ 自洽）；忘记边界。
- **🤔 追问**：若一次可走 1/2/3 级？——$f(n)=f(n-1)+f(n-2)+f(n-3)$，$f(4)=7$。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：0-1 背包：容量 5，物品 (w,v) = (2,3)、(3,4)、(4,5)，求最大价值。
- **解题思路与完整解答**：$dp[0][*]=0$。物品 1：$dp[1][2..5]=3$。物品 2：$dp[2][3]=4,\ dp[2][5]=\max(dp[1][5],dp[1][2]+4)=7$。物品 3：$dp[3][4]=5,\ dp[3][5]=\max(7, dp[2][1]+5)=7$。答案 7（物品 1+2）。注意容量 5 时"物品 1+2"（2+3=5 装得下）价值 7 最优。
- **易错点**：状态"前 $i$ 个物品"而非"恰好用 $i$ 个"；空间优化（一维倒序）时容量必须从大到小遍历。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：LIS 的 $O(n\log n)$ 优化版（贪心 + 二分）是 DP 优化的代表作；记忆化模板：
```python
from functools import lru_cache
@lru_cache(None)
def dp(i):                      # 自顶向下：状态 i
    if i == 0: return base      # 边界
    return max(transition(j) for j in predecessors(i))
```
真实场景：编辑距离（文本 diff）、背包（预算分配）、路径计数（游戏寻路）——DP 是"多项式时间解决指数搜索"的通用范式。

## 8. 常见误区和易混概念

### 误区 1：把"贪心"当 DP 的廉价替代
- **错误直觉**：背包按价值密度装就是最优。
- **为什么错**：无贪心选择性质（见 [[贪心算法]] 反例）；DP 显式枚举所有"前 $i$ 个 + 容量 $c$"状态才保证最优。
- **正确理解**：先验证贪心选择性质，证不出来用 DP。

### 误区 2：状态设计缺信息或冗余
- **错误直觉**：LIS 状态只用"前 $i$ 个元素的最长长度"。
- **为什么错**：转移需要知道"最后一个元素的值"才能判断能否接上——状态必须携带转移所需全部信息。
- **正确理解**：状态设计口诀——"已决策部分 + 影响未来决策的信息"；缺信息则转移写不出来（这是 DP 第一大难点）。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 动态规划 | 重叠子问题最优 | 记忆化/填表 | 背包、LIS、编辑距离 |
| 贪心（[[贪心算法]]） | 局部最优串全局 | 不回溯、需证明 | 区间调度、Huffman |
| 分治（[[分治算法]]） | 独立子问题 | 无重叠、递归+合并 | 归并、最近点对 |
| 回溯（[[回溯算法]]） | 枚举所有解 | 无记忆化 | N 皇后、全排列 |

### 题目与解析

#### 1. DP 的两大适用条件是什么？分治为什么不需要第二个？
> [!question]- 答案解析
> - **答案**：最优子结构 + 重叠子问题。分治子问题相互独立（无重叠），每个子问题只算一次，无需保存；DP 的子问题重复出现，不保存则指数爆炸。
> - **解析**：重叠与否是"分治 vs DP"的分水岭。
> - **易错原因**：只记"最优子结构"，漏掉重叠子问题。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 爬楼梯（1/2 级）到第 6 级有几种走法？列出递推过程。
> [!question]- 答案解析
> - **答案**：$f(1)=1,f(2)=2,f(3)=3,f(4)=5,f(5)=8,f(6)=13$。
> - **解析**：$f(n)=f(n-1)+f(n-2)$ 即斐波那契位移。
> - **易错原因**：$f(2)$ 误算为 1（忘了"一次跨 2 级"的走法）。

#### 3. 为什么 LIS 的状态是"以 $A[i]$ 结尾的最长长度"而不是"前 $i$ 个的最长长度"？
> [!question]- 答案解析
> - **答案**：转移"把 $A[j]$ 接到 $A[i]$ 后面"需要知道当前子序列最后一个元素的值（$A[i]$）才能判断 $A[j]>A[i]$；"前 $i$ 个的最长"不知道结尾是谁，无法判定能否接续。
> - **解析**：状态必须包含"影响未来决策的信息"——DP 状态设计第一原则。
> - **易错原因**：状态信息不足导致转移方程无法写出。

#### 4. 0-1 背包：容量 7，物品 (2,3)、(3,4)、(4,5)、(5,6)，最大价值？
> [!question]- 答案解析
> - **答案**：10（物品 3+4：4+5=9 超容量？精确：物品 2+4 重量 3+5=8 超；物品 1+2+3 重量 2+3+4=9 超；物品 1+4 重 7 价值 3+6=9；物品 1+3 重 6 价值 8；物品 2+3 重 7 价值 9；物品 1+2 重 5 价值 7；物品 3+4 重 9 超。最佳：物品 1+4=9 或 物品 2+3=9？再查：物品 2+4 重 8 超；物品 4+? 单 6。最大为 9（物品 1+4 或 2+3 均 9）。验证 dp：$dp[2][5]=7$，$dp[3][7]=9$（物品2+3），$dp[4][7]=\max(9, dp[3][2]+6=3+6=9)=9$。答案 9。
> - **解析**：$dp[i][c]=\max(dp[i-1][c], dp[i-1][c-w_i]+v_i)$；注意"物品 1+4"价值 3+6=9 重量 7。
> - **易错原因**：漏考虑"组合"，或超容量误算。

#### 5. 说明 LIS 的 $O(n^2)$ 解法为何慢，并简述 $O(n\log n)$ 优化的核心思想。
> [!question]- 答案解析
> - **答案**：$O(n^2)$：$dp[i]=1+\max_{j<i,A[j]<A[i]}dp[j]$，每状态扫全部前驱。优化：维护数组 $tails[k]$ = "长度为 $k$ 的递增子序列的最小结尾"（单调递增），对每个 $A[i]$ 二分查找第一个 $\ge A[i]$ 的位置替换之；$tails$ 的单调性由构造保证，总复杂度 $O(n\log n)$。
> - **解析**：优化本质是"用更少信息（最小结尾）代表一类等价状态"——贪心 + 二分的结合，是 DP 优化的经典示范。
> - **易错原因**：以为 $tails$ 就是 LIS 本身（它只是"最小结尾"记录）。
