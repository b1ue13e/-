# 📦 数据结构维度

> 数据结构是程序设计的基石：数组与链表定内存布局，栈与队列定访问顺序，树与图定层级关系，哈希表与堆定"快查"与"快取最值"。选对结构，算法就赢了一半。

## 维度主题清单

| 主题 | 笔记 | 一句话说明 |
|:---|:---|:---|
| 数组与链表 | [[数组与链表]] | 内存布局与操作复杂度对比，缓存局部性决定实际速度 |
| 栈与队列 | [[栈与队列]] | LIFO/FIFO 基础 + 单调栈与单调队列两大进阶武器 |
| 二叉树 | [[二叉树]] | 遍历/性质/与 BST 的关系，树形结构的入门枢纽 |
| 图结构 | [[图结构]] | 邻接矩阵/邻接表表示法，度、连通性、DAG 等性质 |
| 堆 | [[堆]] | 完全二叉树 + 堆序性，$O(\log n)$ 取最值 |
| 哈希表 | [[哈希表]] | 哈希函数 + 冲突解决，平均 $O(1)$ 查找 |
| 并查集 | [[并查集]] | 路径压缩 + 按秩合并，摊还近常数连通性维护 |

> 📌 堆/哈希表/并查集主题的完整知识卡在课程根目录：[[堆与堆排序]]、[[哈希表HashTable]]、[[并查集]]（本页对应链接为知识地图入口）。

## 推荐学习顺序

1. **[[数组与链表]] → [[栈与队列]]**：线性结构打底；
2. **[[二叉树]] → [[堆]]**：树形结构入门，理解"完全二叉树"的数组存储；
3. **[[哈希表]] → [[图结构]] → [[并查集]]**：从单元素快速查找走向关系结构。

## 根目录延伸笔记

- [[红黑树]]、[[AVL树与平衡树]]：平衡二叉搜索树（哈希表的"有序替代品"）；
- [[图遍历BFS与DFS]]：图的遍历与连通性应用；
- [[快速傅里叶变换FFT]]：数组上的高级运算加速。

## 维度交叉

- 栈/队列 + 单调性 → 单调栈/单调队列（见 [[栈与队列]]）；
- 图结构 + 堆 → Dijkstra（[[Dijkstra最短路径]]）；图结构 + 并查集 → Kruskal；
- 二叉树 + 状态 → 线段树/树状数组（竞赛维度延伸）。
