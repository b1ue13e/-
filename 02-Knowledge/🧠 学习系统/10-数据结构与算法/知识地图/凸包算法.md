# 凸包算法

---

## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具，值得深挖）**
- **判断理由**：凸包是计算几何的入门必修（竞赛考点，[[🏆 竞赛应用维度]]）：Graham 扫描与 Andrew 单调链是 $O(n\log n)$ 的标准算法；叉积的方向判断是所有几何题（点线关系、多边形面积、线段相交）的基础。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：给一堆钉子（点集），用一根橡皮筋把它们全部圈住，橡皮筋绷紧后形成的多边形就是凸包。朴素做法检查所有"点对"（$O(n^3)$）或所有"三点"（$O(n^4)$）不可行；需要 $O(n\log n)$ 的算法：**按极角（或按坐标）排序后，用单调栈维护"始终左转"的边界**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：凸包是计算几何的基石：旋转卡壳（最远点对）、最小包围圆、点集直径都建立在凸包上；与 [[分治算法]]（最近点对）同属几何分治/排序类。
- **实际应用场景**：图像轮廓提取、碰撞检测的包围盒、地理围栏（GPS 区域）、城市规划中的最小包围区域。
- **高频题型/任务**：求凸包顶点（Graham/Andrew 手写）、判断点在多边形内外、凸包周长/面积、最远点对。

---

## 3. 学它之前需要哪些前置知识？

1. **[[复杂度分析]]**：排序 $O(n\log n)$ + 扫描 $O(n)$ 的分析。
2. **[[分治算法]]**：凸包也可用分治求（左右子集合并），理解两种思路的对比。
3. **[[数组与链表]]**：栈结构（Graham 用栈维护候选顶点）。

---

## 4. 用直觉语言解释它

> «"凸包就像给点集'套橡皮筋'：橡皮筋绷紧后只贴着最外层的点。Graham 扫描的思路是：先找最左下角的点做原点，其余点按'从原点看过去的角度'（极角）排队；然后沿着队列走，手里拿个'只许左转'的规矩——一旦发现要右转，说明中间那个点是凹进去的，弹掉它（出栈）。走完全程，栈里剩下的就是凸包。"»

- **直觉类比/几何图像**：橡皮筋套钉子、海港凸出的码头（凹进去的码头会被跳过）。
- **为什么很自然**：凸包的边界上"所有相邻三点的转向一致（都左转）"，这个局部性质让"扫描 + 弹出"成为可能。
- **一句话直觉本质**：**凸包 = 包围全部点的最小凸多边形；Graham/Andrew 把问题化为"按序扫描 + 用叉积判左转、弹掉凹点"的单调栈问题。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **凸包**：点集 $P$ 的凸包 $CH(P)$ 是包含 $P$ 的最小凸集（等价地：所有凸组合的集合；边界是 $P$ 中点的凸多边形）。
- **叉积**：向量 $\vec a=(x_1,y_1),\ \vec b=(x_2,y_2)$，叉积 $cross = x_1y_2 - y_1x_2$；$cross>0$ 表示 $\vec b$ 在 $\vec a$ 逆时针方向（左转），$<0$ 右转，$=0$ 共线。
- **Graham 扫描**：找最低点（同高取最左）$p_0$ → 其余点按极角排序 → 单调栈维护凸包：新点使栈顶"右转或共线"时弹栈顶。
- **Andrew 单调链**：按 $x$（同 $x$ 按 $y$）排序，先扫下凸壳再扫上凸壳，避免浮点极角排序。

### 2. 核心公式
叉积（判断 $p,q,r$ 三点的转向，$p\to q\to r$）：
$$cross(p,q,r)=(q.x-p.x)(r.y-p.y)-(q.y-p.y)(r.x-p.x)$$
复杂度：$$T(n)=O(n\log n)\quad(\text{排序})+O(n)\quad(\text{扫描}),\quad S(n)=O(n)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $p_i=(x_i,y_i)$ | 点坐标 | 实数 | |
| $cross$ | 叉积 | 实数 | 符号=转向 |
| $p_0$ | 极角排序原点 | $P$ 中最低最左点 | Graham |
| $n$ | 点数 | $\ge3$ | |

### 4. 常见变体与适用条件
- **变体**：Graham（极角排序）、Andrew（坐标排序，无浮点比较）、分治凸包、增量法（动态加点）、旋转卡壳（在凸包上求直径）。
- **适用条件**：静态点集、$n$ 可排序。限制：极角排序需处理共线点（保留端点、去中间点）；浮点误差用 $\varepsilon$ 容差比较。

---

## 6. 推导思路和思想来源

- **最初困难**：判断"哪些点是边界点"似乎需要全局信息（每个点都可能被任何其他点"挡住"）。
- **直接方法局限**：枚举所有三点判断"其余点是否全在一侧"是 $O(n^4)$。
- **关键"转念"**：**边界点有局部刻画：凸包边界上相邻三点总是同向转弯（左转）**。于是先排序给点一个顺序（极角或坐标），再贪心构建：新点若使栈顶右转，栈顶必在凸包内部，可安全弹出——"右转即内部"是核心不变量。
- **推导主线与动机**：排序保证扫描顺序与"橡皮筋"缠绕方向一致 → 栈维护当前凸包边界 → 叉积判定转向 → 弹栈直到恢复左转 → 栈内即凸包（归纳：每一步后栈中都是"已扫描点"的凸包）。
- **为什么自然得到此结论**：凸包边界是"单调转角"的闭合折线，扫描法把"构造凸包"化简为"维护一串左转"——与单调栈维护单调性（[[栈与队列]]）同构。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：点集 $A(0,0), B(1,1), C(2,0), D(1,-1)$，求凸包（Andrew 下凸壳）。
- **解题思路与关键步骤**：按 $x$ 排序：$A(0,0), D(1,-1), B(1,1), C(2,0)$。下凸壳扫描：压 $A$；压 $D$；$B$：$cross(A,D,B)=(1)(1)-(-1)(1)=2>0$ 左转 → 压 $B$；$C$：$cross(D,B,C)=(0)(0)-(2)(1)=-2<0$ 右转 → 弹 $B$；$cross(A,D,C)=(1)(0)-(-1)(2)=2>0$ 左转 → 压 $C$。下凸壳 $A,D,C$。上凸壳反向扫描得 $C,B,A$（去重端点）。凸包：$A\to D\to C\to B\to A$（四边形）。
- **最终答案**：4 个点全在凸包上（正方形顶点）。
- **易错点**：排序时同 $x$ 的点（D 与 B）顺序影响叉积符号；共线点处理（本题无共线）。
- **🤔 追问**：若加一个点 $E(1,0)$（正方形中心）？——$E$ 必在凸包内部：扫描中任何一次"压入 $E$"后都会被后续点以右转弹出，最终不在栈中。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：判断点 $Q$ 是否在凸多边形内部（$O(\log n)$ 或 $O(n)$）。
- **解题思路与完整解答**：$O(n)$ 法：沿凸包边 $p_i\to p_{i+1}$ 检查 $Q$ 是否始终在同一侧（叉积符号一致）。$O(\log n)$ 法（竞赛常用）：以 $p_0$ 为原点把多边形三角剖分（扇形），对 $Q$ 的极角二分定位到三角形 $p_0p_ip_{i+1}$，再判断 $Q$ 与边 $p_ip_{i+1}$ 的位置。本题 $Q=(1,0.5)$、凸包正方形：四条边检查叉积均同号（内部），$Q=(2,0.5)$ 则对边 $B\to C$ 检查时叉积符号翻转（外部）。
- **易错点**：凸多边形顶点顺序必须一致（顺时针/逆时针统一），否则叉积符号比较失效。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：Andrew 单调链实现（整数运算，无浮点误差）：
```python
def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def convex_hull(points):
    pts = sorted(points)                 # 按 (x, y) 排序
    if len(pts) <= 1: return pts
    lower = []
    for p in pts:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()                  # 右转或共线 → 弹出
        lower.append(p)
    upper = []
    for p in reversed(pts):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]       # 去重首尾
```
真实场景：游戏碰撞检测先用凸包包围盒粗筛；GIS 用地边界简化（保留凸包顶点）。

## 8. 常见误区和易混概念

### 误区 1：叉积符号与"左右"搞反
- **错误直觉**：$cross>0$ 是右转。
- **为什么错**：$cross(p,q,r)>0$ 表示 $q\to r$ 相对 $p\to q$ **逆时针**（左转）——坐标系 y 向上时。
- **正确理解**：屏幕坐标 y 向下会翻转直觉；统一约定"逆时针为正"，代码里用"$\le0$ 弹出"还是"$\ge0$ 弹出"取决于想要上/下凸壳。

### 误区 2：共线点处理不当
- **错误直觉**：共线点留着也无妨。
- **为什么错**：共线会触发"$\le0$ 弹出"把端点也弹掉（Andrew 用 $\le0$ 保留端点需去重），或使 Graham 的极角排序产生歧义。
- **正确理解**：明确需求——"只要顶点"用严格 $<0$；"含边界点"用 $\le0$ 并去重端点。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 凸包 | 最小包围凸多边形 | 排序 + 单调栈 | 轮廓、包围盒 |
| 最近点对（[[最近点对问题-分治进阶]]） | 最小距离点对 | 分治 $O(n\log n)$ | 聚类 |
| 多边形面积 | 面积计算 | 叉积求和 $/2$ | 几何题工具 |
| 旋转卡壳 | 凸包上最远点对 | 双指针绕凸包 | 直径问题 |

### 题目与解析

#### 1. 判断三点 $O(0,0), A(1,0), B(0,1)$ 的转向，用叉积说明。
> [!question]- 答案解析
> - **答案**：$cross(O,A,B)=(1)(1)-(0)(0)=1>0$，$B$ 在 $A$ 的逆时针方向（左转）。
> - **解析**：$cross(p,q,r)=(q_x-p_x)(r_y-p_y)-(q_y-p_y)(r_x-p_x)$；正值 = 逆时针。
> - **易错原因**：坐标轴方向（y 向上）约定不统一。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 点集 $(0,0),(2,2),(1,1),(2,0)$ 的凸包顶点有哪些？
> [!question]- 答案解析
> - **答案**：$(0,0),(2,0),(2,2)$ 三个顶点（$(1,1)$ 在斜边上，共线被剔除）。
> - **解析**：凸包是三角形；共线点（$(1,1)$ 在 $(0,0)-(2,2)$ 上）不是"严格顶点"。
> - **易错原因**：把共线点算进顶点（取决于"含边界"约定，Andrew 用 $\le0$ 弹出即剔除）。

#### 3. Graham 扫描与 Andrew 单调链各自适合什么场景？
> [!question]- 答案解析
> - **答案**：Graham 需极角排序（涉及浮点 `atan2` 或有理数比较），代码稍繁；Andrew 只按 $(x,y)$ 排序（整数比较），无浮点误差、实现更稳，竞赛首选。Graham 的优势是"从原点看全局"的语义直观，适合讲解与动态插入场景。
> - **解析**：二者都是 $O(n\log n)$；工程与竞赛实践中 Andrew 更常用。
> - **易错原因**：误以为 Graham 复杂度更低（极角排序同样是 $O(n\log n)$）。

#### 4. 判断点 $Q(1.5,1.5)$ 是否在三角形 $(0,0),(3,0),(0,3)$ 内部。
> [!question]- 答案解析
> - **答案**：在内部。三条边 $(0,0)\to(3,0)$：$cross=1.5\times0-0\times1.5=0$？精确：$cross((0,0),(3,0),Q)=(3)(1.5)-(0)(1.5)=4.5>0$；$(3,0)\to(0,3)$：$cross=(-3)(1.5)-...$ 计算得 $>0$；$(0,3)\to(0,0)$：$>0$。三边叉积同号（均逆时针），点在内部。
> - **解析**：凸多边形内部判定 = 所有边叉积同号。
> - **易错原因**：顶点顺序不一致导致符号比较失效。

#### 5. 论证 Andrew 单调链的正确性（为什么弹出的点一定不在凸包上）。
> [!question]- 答案解析
> - **答案**：下凸壳扫描维护不变量："栈中点是已扫描点集的下凸壳，且按 $x$ 单调"。新点 $p$ 使栈顶 $t$ 满足 $cross(prev,t,p)\le0$（右转或共线）时：$t$ 位于三角形/退化带 $prev$-$t$-$p$ 内或边上，而该区域的所有点都被 $prev,p$ 的连线"覆盖"——$t$ 必在最终凸包内部，可安全弹出。反复弹出后恢复左转，压入 $p$，不变量保持。扫描完所有点，栈即完整下凸壳；上凸壳对称。归纳于扫描步数即得正确性；每点至多进出栈一次 ⇒ $O(n)$ 扫描。
> - **解析**："右转点必在凸包内部"是关键引理，证明靠叉积的几何意义（$t$ 在 $prev,p$ 连线内侧）。
> - **易错原因**：说不清"为什么弹出是安全的"（这正是正确性核心）。
