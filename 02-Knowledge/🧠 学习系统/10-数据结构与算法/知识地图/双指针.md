# 双指针

> 🔗 **重定向页**：双指针的完整笔记在课程根目录 → [[../双指针|双指针]]（知识卡片，含三种模式、单调性推导与 Python 自测代码）。

## 要点速览

- **核心思想**：用两个指针（索引）协同遍历线性结构，把 $O(n^2)$ 的嵌套循环降到 $O(n)$。
- **三种模式**：
  - **对顶指针（左右指针）**：一前一后相向移动，用于有序数组求和、回文判断；
  - **快慢指针**：不同速度同向移动，用于链表环检测、找中点、原地去重；
  - **滑动窗口（同向双指针）**：左右指针维护动态窗口，用于最长子串、最小覆盖子串。
- **关键前提**：对顶指针依赖数组有序/单调性；无序时改用哈希表（[[哈希表HashTable]]）。
- **高频考点**：两数之和 II、盛最多水的容器、无重复字符的最长子串、链表环检测（Floyd 判圈）。
