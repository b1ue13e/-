# 并查集 (Disjoint-Set / Union-Find)

## 1. 并查集定义与核心 API

**并查集 (Disjoint-Set / Union-Find)** 的核心定义是：一种维护由若干互不相交的集合构成的动态树形数据结构，主要用于解决图论中的动态连通性问题，并支持以下两种核心 API 操作：

1. **`Find(x)`**：查找元素 $x$ 所在集合的代表元素（根节点），用于判断两个元素是否属于同一个集合；
2. **`Union(x, y)`**：将元素 $x$ 所在集合与元素 $y$ 所在集合合并为一个集合。

**基本性质**：若同时采用**路径压缩 (Path Compression)** 与**按秩合并 (Union by Rank / Size)** 两种优化策略，并查集 $m$ 次操作的摊还时间复杂度为 $O(m \cdot \alpha(n))$，其中 $\alpha(n)$ 为**反阿克曼函数 (Inverse Ackermann Function)**，对现实中任意 $n < 10^{80}$ 均有 $\alpha(n) \le 4$，完全等价于常数时间 $O(1)$。

---

## 2. 路径压缩与按秩合并复杂度形式化推导

**定理（Tarjan, 1975）**：双重优化下的并查集单次操作摊还复杂度为 $O(\alpha(n))$。

**前提条件与优化逻辑推导**：
1. **假设**：每个节点初始自成一个独立集合，`parent[x] = x` 且 `rank[x] = 0`；
2. **路径压缩 (Path Compression)**：在 `Find(x)` 递归查找根节点时，将路径上所有节点的父指针直接指向根节点 `parent[x] = find(parent[x])`，这使后续 `Find` 操作路径长度直接坍塌为 1；
3. **按秩合并 (Union by Rank)**：在 `Union(x, y)` 时，将高度较小（或结点数较少）的树合并到高度较大的树根下，阻止树退化为线性链表；
4. **因此**，单纯按秩合并保证树高 $h \le \log_2 n$；结合路径压缩后，树的高度急剧坍塌，由势能分析法可严格证明其摊还代价为 $O(\alpha(n))$。

## 3. 并查集与搜索/图论算法的区别与对比

| 维度 | 并查集 (Union-Find) | 广度优先搜索 (BFS) / DFS |
|:---|:---|:---|
| **核心优势** | **动态连通性 (Dynamic Connectivity)** | 静态图路径搜索 / 最短路径 |
| **合并/查询代价** | $O(\alpha(n)) \approx O(1)$ | $O(V + E)$ 重新遍历全图 |
| **空间开销** | $O(V)$ 仅需 `parent` 数组 | $O(V + E)$ 需存储全图邻接表 |
| **典型应用场景** | Kruskal 最小生成树、Grid 连通块计数 | Dijkstra 最短路、拓扑排序 |

**局限（反例/误区）**：标准并查集只支持集合的合并与连通性查询，**不支持集合拆分 (Split/Delete)** 操作；若需支持撤销与拆分，须使用复杂的可持久化并查集或撤销栈 (Undo Stack)。

关联知识点推荐：[[红黑树]]、[[堆与堆排序]]、[[双指针]]、[[二分搜索]]。

## 4. Python 完整并查集实现与连通性自测断言

```python
class UnionFind:
    """
    并查集 (路径压缩 + 按秩合并)
    假设: 元素编号为 0 到 n-1
    推导: Find 递归压缩路径, Union 小树贴大树, 摊还复杂度 O(alpha(n))
    """
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.count = n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> bool:
        rootX = self.find(x)
        rootY = self.find(y)
        if rootX == rootY:
            return False

        if self.rank[rootX] < self.rank[rootY]:
            rootX, rootY = rootY, rootX
        self.parent[rootY] = rootX
        if self.rank[rootX] == self.rank[rootY]:
            self.rank[rootX] += 1
        self.count -= 1
        return True

    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)

if __name__ == "__main__":
    uf = UnionFind(10)
    assert uf.count == 10

    # 自测验证 1: 动态连通测试
    uf.union(0, 1)
    uf.union(1, 2)
    assert uf.connected(0, 2), "0 与 2 应传递连通"
    assert uf.count == 8

    # 自测验证 2: 独立集合测试
    assert not uf.connected(0, 5)

    # 自测验证 3: 重复合并反例
    assert not uf.union(0, 2)

    # 自测验证 4: 路径压缩后 parent 直连 root
    root0 = uf.find(0)
    assert uf.parent[2] == root0

    print("并查集单元测试与自查验证全部成功！")
```
