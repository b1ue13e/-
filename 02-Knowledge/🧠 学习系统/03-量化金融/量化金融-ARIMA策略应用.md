# 量化金融-ARIMA策略应用

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
ARIMA 模型（及其参数 $(p, d, q)$）是经典统计时间序列建模（Box-Jenkins 方法论）的大成者。它巧妙地结合了**自回归 (AR)**、**差分 (I)** 与 **移动平均 (MA)**，将原本非平稳的金融宏观与资产价格序列转化平稳序列并进行均值预测。在量化交易中，ARIMA 是均值回归策略、宏观因子预测、期货基差预测以及气象/电力高频量化预测的工业级标配。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你正在试图预测明天的国债期货价格或国债收益率。
你拿到的原始价格序列 $P_t$ 是单边漂移非平稳的（具有趋势，未通过单位根检验）。如果直接用经典线性回归 $P_t = \beta t + \epsilon_t$，会出现严重误导的“伪回归”。
但如果你简单地把数据做一阶差分 $\Delta P_t = P_t - P_{t-1}$，变成了平稳的每日变化量，你又面临新麻烦：**如何同时捕捉“昨日变动量对今日的直接记忆（AR 部分）”以及“过去未预期冲击的持续影响（MA 部分）”？**

**以前的方法在哪里卡住：**
1. **纯 AR 模型**：无法有效表达随机冲击（如突发利好/利空）衰减的滞后记忆；
2. **纯 MA 模型**：无法表达长时间跨度的历史趋势自身相关；
3. **未差分的非平稳模型**：违反计量经济学平稳性假设，模型预测方差爆炸。

**为什么必须引入 ARIMA 模型：**
引入**差分算子 $d$** 将非平稳序列化为平稳序列，再叠加 $p$ 阶自回归与 $q$ 阶移动平均，用极其精简的表达式 $(p, d, q)$ 完美拟合复杂动态过程。

**它到底解决了哪类问题：**
解决了**含有趋势/单位根的非平稳时间序列的平稳化处理、自回归记忆与随机冲击联合建模及未来均值点预测**问题。

---

## 2. 为什么它重要？它有什么用？

- **体系与大图景**：线性时间序列分析的顶点，承接 ACF/PACF 与单位根检验，衍生出 GARCH（条件异方差模型）与 VAR（向量自回归）。
- **量化与实战应用**：
  1. **资产基差与配对均值预测**：对期货-现货基差（Basis）构建 ARIMA 模型，预测基差向均值回归的收敛路径。
  2. **宏观量化指标预测**：对 CPI、PMI、货币供应量 M2 等宏观月度指标进行短期拟合与外推预测。
  3. **自动化模型定阶 (Auto-ARIMA)**：量化系统中利用 AIC / BIC 准则自动挑选最优 $(p, d, q)$ 组合。

## 4. 用直觉语言解释它

### 生活类比：驾驶一艘有惯性和海浪冲击的轮船

想象你在海上驾驶一艘轮船：
- **$d$（差分/积分 Integrated）**：海面有风浪和航线漂移，你不上看绝对坐标（非平稳），只看**每秒钟的速度变化**（一阶差分）。
- **$p$（自回归 AR）**：轮船巨大的惯性。你前 1 分钟、前 2 分钟的方向（$X_{t-1}, X_{t-2}$），决定了你现在的航向。
- **$q$（移动平均 MA）**：海浪冲击的记忆。刚才浪打在船舷上的随机冲击（$\epsilon_{t-1}$），其余波还在推着船走。

**ARIMA 的直觉本质**：
先把不稳定、有趋势的数据求差分变成稳定的变化量，然后把变化量拆成“惯性（AR）+ 浪花余波（MA）”两部分共同预测下一刻的方向。

«“ARIMA(p,d,q) 就是先差分去除趋势，再用‘惯性(p)’和‘冲击余波(q)’来预测平稳变化量。”»

---

## 5. 正式定义、核心公式、符号解释

### 核心定义
**ARIMA(p, d, q) 模型**：指一个时间序列在经过 $d$ 阶差分后，所得到的平稳序列满足阶数为 $p$ 的自回归与阶数为 $q$ 的移动平均混合模型。

### 核心公式

#### 1. 经典代数标准形式
设 $Y_t = (1-L)^d X_t = \Delta^d X_t$ 为 $d$ 阶差分后的平稳序列：
$$Y_t = c + \sum_{i=1}^p \phi_i Y_{t-i} + \epsilon_t + \sum_{j=1}^q \theta_j \epsilon_{t-j}$$

其中 $\epsilon_t \sim i.i.d. N(0, \sigma^2)$ 为白噪声序列。

#### 2. 滞后算子多项式紧凑形式
$$\Phi_p(L) (1 - L)^d X_t = c + \Theta_q(L) \epsilon_t$$

其中：
- $\Phi_p(L) = 1 - \phi_1 L - \phi_2 L^2 - \dots - \phi_p L^p$ (AR 多项式)
- $\Theta_q(L) = 1 + \theta_1 L + \theta_2 L^2 + \dots + \theta_q L^q$ (MA 多项式)

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $p$ | 自回归阶数 (AR order) | 非负整数 | 滞后项 $X_{t-i}$ 的个数 |
| $d$ | 差分阶数 (Integrated order) | 非负整数 | 使原序列平稳需要的差分次数（通常为 0, 1, 2） |
| $q$ | 移动平均阶数 (MA order) | 非负整数 | 滞后随机冲击 $\epsilon_{t-j}$ 的个数 |
| $\phi_i$ | 第 $i$ 个自回归系数 | 标量 $[-1, 1]$ | 满足平稳性根条件（在单位圆外） |
| $\theta_j$ | 第 $j$ 个移动平均系数 | 标量 | 满足可逆性条件 |
| $c$ | 常数项/漂移项 (Drift) | 标量 | 决定差分后的均值水平 |

## 6. 推导思路和思想来源

### 建模与参数选择（Box-Jenkins 三步法）

1. **第一步：平稳化与 $d$ 的确定**
   绘制原序列 $X_t$ 图形并进行 ADF 单位根检验。若不平稳，做一阶差分 $\Delta X_t$。若仍不平稳则继续差分，直至平稳，记录差分次数为 $d$。
2. **第二步：模型定阶（确定 $p, q$）**
   - **手动直观法**：观察差分后序列 $Y_t$ 的 ACF 与 PACF 截尾位置。
   - **信息准则自动化法（最小化 AIC / BIC）**：
     $$AIC = 2k - 2\ln(\hat{L})$$
     $$BIC = k \ln(n) - 2\ln(\hat{L})$$
     其中 $k = p + q + 1$ 为参数个数，$n$ 为样本量。选择使 $BIC$ 最小的 $(p, q)$ 组合。
3. **第三步：残差诊断（Residual Diagnostics）**
   模型拟合后，必须对残差 $\hat{\epsilon}_t$ 进行 Ljung-Box $Q$ 检验，确保残差为纯粹的白噪声。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（ARIMA(1, 1, 1) 的一步外推预测）

**题目**：
已知某大宗商品价格序列经过 1 阶差分后的 ARIMA(1,1,1) 模型方程为：
$$(1 - 0.4L)(1 - L) X_t = 0.5 + (1 + 0.3L) \epsilon_t$$
已知 $t$ 时刻价格 $X_t = 100$，上一期价格 $X_{t-1} = 98$（即 $\Delta X_t = 2.0$）。
当前残差 $\epsilon_t = 0.5$，且预测未来冲击 $E[\epsilon_{t+1}] = 0$。
求对 $t+1$ 时刻价格的预测值 $\hat{X}_{t+1}$。

**解答过程**：
1. 展开差分序列 $Y_t = \Delta X_t = X_t - X_{t-1}$ 的方程：
   $$Y_t - 0.4 Y_{t-1} = 0.5 + \epsilon_t + 0.3 \epsilon_{t-1}$$
   $$Y_t = 0.5 + 0.4 Y_{t-1} + \epsilon_t + 0.3 \epsilon_{t-1}$$
2. 计算对 $t+1$ 期变化量 $Y_{t+1} = \Delta X_{t+1}$ 的预测：
   $$\hat{Y}_{t+1} = 0.5 + 0.4 Y_t + \underbrace{E[\epsilon_{t+1}]}_{=0} + 0.3 \epsilon_t$$
   代入 $Y_t = 2.0$ 和 $\epsilon_t = 0.5$：
   $$\hat{Y}_{t+1} = 0.5 + 0.4 \times 2.0 + 0.3 \times 0.5 = 0.5 + 0.8 + 0.15 = 1.45$$
3. 还原到价格预测 $\hat{X}_{t+1}$：
   $$\hat{X}_{t+1} = X_t + \hat{Y}_{t+1} = 100 + 1.45 = 101.45 \text{ 元}$$

---

### 例子 2：中等例题（过拟合与 AIC/BIC 选型）

**题目**：
量化团队拟合某利差序列，拟合了两个候选模型：
- **模型 A：ARIMA(1,0,1)**，对数似然值 $\ln L = -150$，参数个数 $k=3$（含常数项）。
- **模型 B：ARIMA(4,0,3)**，对数似然值 $\ln L = -142$，参数个数 $k=9$。

假设样本量 $n = 500$。计算两者的 BIC 值，并依据 BIC 选出更优模型。（$\ln(500) \approx 6.214$）

**解答过程**：
1. $BIC$ 计算公式：$BIC = k \ln(n) - 2 \ln L$
2. **模型 A**：
   $$BIC_A = 3 \times 6.214 - 2 \times (-150) = 18.642 + 300 = 318.642$$
3. **模型 B**：
   $$BIC_B = 9 \times 6.214 - 2 \times (-142) = 55.926 + 284 = 339.926$$
4. **结论**：虽然模型 B 复杂度高导致似然值稍微提升，但 $BIC_A (318.642) < BIC_B (339.926)$。模型 A 惩罚过拟合更有效，因此选择结构更精简的 **模型 A**。

### 例子 3：实际应用（Python pmdarima 自动拟合与交易信号外推）

```python
import numpy as np
import pandas as pd
import pmdarima as pm

# 模拟 300 天的某种大宗商品基差序列
np.random.seed(42)
basis = np.cumsum(np.random.normal(0, 1, 300)) + 50.0

# 自动拟合最优 ARIMA(p, d, q)
model = pm.auto_arima(basis, seasonal=False, stepwise=True,
                      suppress_warnings=True, error_action="ignore")

print(f"自动选择的最佳 ARIMA 阶数: {model.order}")

# 外推预测未来 3 天的基差
forecasts, conf_int = model.predict(n_periods=3, return_conf_int=True)
print(f"未来 3 天基差预测: {forecasts}")
```

## 8. 常见误区与易混概念

### 误区 1：ARIMA 模型可以用来预测未来几年的股票长远价格

错误直觉：“我已经拟合了完美的 ARIMA(2,1,2) 模型，所以可以用它预测未来 1 年的股票价格。”  
为什么错：ARIMA 属于**均值回归型中短期模型**。由于误差项的累积，多步外推预测（Multi-step Ahead Forecast）的方差会快速收敛到序列的全局方差，长期预测值会趋于常数线，失去所有预测价值。  
正确理解：ARIMA 主要适用于**1~5 个步长内的超短期外推预测**。

### 概念对比：ARIMA vs GARCH

| 维度 | ARIMA 模型 | GARCH 模型 |
| :--- | :--- | :--- |
| **建模对象** | 序列的**均值** $E[X_{t+1} \mid \mathcal{F}_t]$ | 序列的**波动率/方差** $Var(X_{t+1} \mid \mathcal{F}_t)$ |
| **假设** | 假设残差方差恒定 $\sigma^2$ | 假设残差方差时变（波动率聚集） |
| **组合应用** | 常作为第一步拟合均值，残差送入 GARCH 拟合波动率 (ARIMA-GARCH) |

### 第 1 题：概念辨析（基础）
**题目**：如果一个时间序列本身已经是平稳的（即 $d=0$），且只有自回归成分（$p=2$），那么这个 ARIMA(p,d,q) 模型等价于什么模型？

> [!question]- 答案解析
> **答案**：等价于标准的 $AR(2)$（二阶自回归）模型，即 $ARIMA(2, 0, 0) \equiv AR(2)$。  
> **Obsidian 标签**：`#自测题/ARIMA定义`

---

### 第 2 题：公式运用（基础）
**题目**：已知平稳 $ARIMA(1,0,0)$ 模型为 $X_t = 2.0 + 0.6 X_{t-1} + \epsilon_t$。若当前 $X_t = 10$，求对下一期 $\hat{X}_{t+1}$ 的预测值。

> [!question]- 答案解析
> **答案**：
> $\hat{X}_{t+1} = E[2.0 + 0.6 X_t + \epsilon_{t+1}] = 2.0 + 0.6 \times 10 + 0 = 2.0 + 6.0 = 8.0$。  
> **Obsidian 标签**：`#自测题/ARIMA预测`

---

### 第 3 题：条件判断（中等）
**题目**：判断：“在拟合完 ARIMA 模型后，对残差序列做 Ljung-Box $Q$ 检验，若 $p$-value $< 0.05$，说明模型拟合非常成功，可以投入实盘。”

> [!question]- 答案解析
> **答案**：错误。Ljung-Box 检验的原假设 $H_0$ 是“残差为白噪声”。若 $p$-value $< 0.05$，说明拒绝原假设，即**残差中依然存在未被模型提取的自相关信息**，模型拟合不足，需要增加 $p$ 或 $q$ 阶数。  
> **Obsidian 标签**：`#自测题/残差诊断`

### 第 4 题：变式/综合（中等）
**题目**：对某股票对数收益率序列拟合，得到了 ARIMA(0,0,1) 模型。写出该模型价格预测的含义。

> [!question]- 答案解析
> **答案**：ARIMA(0,0,1) 即 $MA(1)$ 模型：$r_t = c + \epsilon_t + \theta_1 \epsilon_{t-1}$。这说明收益率本身无长期自回归记忆，但上一期的随机冲击 $\epsilon_{t-1}$ 会对本期收益率产生一个暂态的线性修正，超出 1 期后影响消失。  
> **Obsidian 标签**：`#自测题/MA模型`

### 第 5 题：开放/建模（较难）
**题目**：在量化交易系统中，为什么不能对全历史数据一次性拟合一个固定参数的 ARIMA 模型，而是需要使用滚动窗口（Rolling Window）重复拟合？

> [!question]- 答案解析
> **解析**：
> 1. **结构性变化（Structural Break）**：金融市场的微观结构、宏观利率环境和市场参与者结构随时间剧烈变化，固定参数模型会出现“参数失效”。
> 2. **样本外拟合（Out-of-sample Adaptation）**：滚动窗口（如固定使用过去 250 天数据）能使 ARIMA 模型的系数 $\phi_i, \theta_j$ 实时更新，动态自适应近期的均值回归速率与冲击持续度。  
> **Obsidian 标签**：`#自测题/RollingARIMA`

## 可定位依据与失效复核

本卡的复核对象是 **ARIMA 差分自回归移动平均模型 (Autoregressive Integrated Moving Average)**，而不是只复述一个公式。对 **ARIMA 差分自回归移动平均模型 (Autoregressive Integrated Moving Average)** 的独立验证重点是：用滚动起点预测并检查残差白噪声、参数稳定和差分后的可逆性，禁止随机切分。

### 失效边界与验收协议

- **成立条件**：先写清数据时点、估计窗口、交易摩擦和分布/市场结构假设，再运行模型。
- **反例压力测试**：用滚动起点预测并检查残差白噪声、参数稳定和差分后的可逆性，禁止随机切分。
- **最小实验**：固定随机种子或冻结原始数据快照，同时保存基线、破坏条件后的对照组、关键中间量与失败日志。
- **通过标准**：结论必须在样本外仍保持方向一致；若成本、延迟、参数扰动或结构突变使结论反转，就把该情形登记为适用边界而不是删除失败结果。
