# 量化金融每周学习执行卡

> [!important] 怎么使用
> 本页只解释“这一周具体怎么做”，不决定你在哪一周。不确定当前位置时返回 [[🗺️ 量化金融学习路径]]；当前指针以 [[01-Active Sprint/🚀 Active Sprint|Active Sprint]] 为准。每周只按“先测 → 学习 → 仿做 → 独立做 → 迁移 → 延迟重测”推进。

## 固定节奏与停止条件

| 时点 | 动作 | 保留证据 |
| :--- | :--- | :--- |
| 开始前 | 做 3-5 分钟先测，记录每题作答前信心 | 初答、信心、卡点 |
| 当天 | 学最小知识集，完成示例题和仿做题 | 推导或代码输出 |
| 24 小时后 | 不看笔记重做一题独立题 | 第二次答案 |
| 72 小时后 | 混入前两周旧题，完成交错重测 | 错因分类 |
| 7 天后 | 做迁移题或口头答辩 | 第三次答案、作答后信心 |

**停止条件**：如果核心定义无法闭卷复述、代码无法从空环境运行，或独立题正确率低于 80%，停止解锁新周。把笔记设为 `flow: review`、记录“错因 → 补救页 → 重测日期”，完成补救后再测。任何**高置信错误**都必须优先复测。

## Week 0：诊断、环境与最小数学语言

### 本周目标
知道自己缺什么；能运行一个最小 Python 程序；能解释百分比、均值、方差和矩阵乘法在课程中的角色。

### 学习顺序
1. 完成 [[00-课程说明与先修诊断#2. 20 分钟先修诊断|20 分钟诊断]]，每题记录信心。
2. 未达标时只学习 [[00-零基础补救-数学统计与Python]] 的对应分区。
3. 打开 [[00-量化金融符号与术语速查]]，先认符号，不要求背完整定义。

### 当周练习
- 完成补救卡中的环境自检、收益率手算和数组均值代码。
- 在 [[03-Projects/开源课程课后习题/PS01-线性代数与概率基础|PS01]] 做题 1-2，只做示例题和仿做题。

### 通过闸门
- [ ] 四个诊断维度均至少 3/4。
- [ ] 能从终端运行 Python，并解释实际输出。
- [ ] 能写出简单收益率、均值和方差的含义；不要求先会随机微积分。

## Week 1：收益率与 OHLCV 数据契约

### 本周目标
区分价格、简单收益率和对数收益率；知道复权错误如何制造虚假收益。

### 学习顺序
1. [[01-夯实基础/收益率与对数收益率]]。
2. [[01-夯实基础/OHLCV字段清洗与复权]]。
3. 先手算，再运行笔记中的 Python 断言。

### 当周练习
- 做 [[03-Projects/开源课程课后习题/PS01-线性代数与概率基础|PS01]] 题 3-4。
- 运行 [[03-Projects/Capstone-AAPL/README|AAPL Phase 1]]，只检查输入数据与收益率产物。

### 通过闸门
- [ ] 能解释 `pct_change()` 首项为何缺失。
- [ ] 能构造一个未复权拆股的失败案例。
- [ ] 24 小时后闭卷重做收益率手算题。

## Week 2：时间协议与面板操作

### 本周目标
把观察时间、信息发布时间、决策时间和成交时间分开；避免跨资产 `shift` 污染。

### 学习顺序
1. [[01-夯实基础/时间索引与频率（量化）]]。
2. [[01-夯实基础/Pandas分组聚合与透视表]]。
3. 画出一条从信息产生到收益记账的时间线。

### 当周练习
- 修改一份双资产小数据，使“错误 shift”必定失败，再按资产分组修复。
- 做 [[03-Projects/开源课程课后习题/PS02-回归与CAPM|PS02]] 题 1，复习矩阵投影直觉。

### 通过闸门
- [ ] 能说清 $t$ 日收盘信号何时最早可成交。
- [ ] 测试能捕获跨资产污染和未来数据变更。
- [ ] 72 小时后把 Week 1 的复权题混入重测。

## Week 3：滚动特征与样本泄漏

### 本周目标
建立“每个特征都必须有可得时点”的习惯，并用不变性测试抓住未来函数。

### 学习顺序
1. [[01-夯实基础/滚动窗口与波动率特征]]。
2. [[02-量化核心技能/样本泄漏]]。
3. 完成 [[01-夯实基础/量化金融-Level0-累计交错测验]]。

### 当周练习
- 做 [[03-Projects/开源课程课后习题/PS03-时间序列与波动率|PS03]] 题 1-2。
- 删除测试集尾部数据，验证更早时点的训练特征逐位不变。

### 通过闸门
- [ ] Level 0 首测至少 80%。
- [ ] 48 小时后闭卷重测至少 80%。
- [ ] 能展示一个先失败、后修复的泄漏测试。

## Week 4：组合、回归与 CAPM

### 本周目标
从协方差理解分散化；从 OLS 理解 Alpha、Beta 与估计不确定性。

### 学习顺序
[[02-量化核心技能/相关系数、协方差与资产组合分散化 (Covariance, Correlation & Diversification)]] → [[02-量化核心技能/CAPM 资本资产定价模型]] → [[02-量化核心技能/[支线任务] HW01-CAPM与Alpha检验]]。

### 当周练习
- 完成 [[03-Projects/开源课程课后习题/PS02-回归与CAPM|PS02]] 全部题。
- 运行 [[03-Projects/HW01-CAPM/README|HW01 CAPM 包]]，比较模型与均值基线的测试 MSE。

### 通过闸门
- [ ] 闭卷写出 $\hat\beta=(X^TX)^{-1}X^Ty$ 的对象和维度。
- [ ] 不把“大 p 值”解释为证明 Alpha 等于零。
- [ ] 能说明训练、验证和测试各自用途。

## Week 5：平稳性、时间序列与 GARCH

### 本周目标

### 学习顺序
[[02-量化核心技能/单位根检验与 ADF 检验 (Unit Root & Augmented Dickey-Fuller Test)]] → [[02-量化核心技能/量化金融-波动率-GARCH家族模型]]。

### 当周练习
- 完成 [[03-Projects/开源课程课后习题/PS03-时间序列与波动率|PS03]] 题 3-6。
- 运行 [[03-Projects/Phase2-GARCH/README|Phase 2 GARCH]]，检查训练期均值和样本外 QLIKE。

### 通过闸门
- [ ] 能手推 AR(1) 无条件均值与平稳条件。

- [ ] 未来数据扰动测试通过。

## Week 6：VaR、ES 与风险回测

### 本周目标
理解 VaR 是分位数损失阈值，不是最大损失；能回测覆盖率。

### 学习顺序
[[02-量化核心技能/参数法VaR（方差-协方差法）]] → [[02-量化核心技能/极值理论 EVT 与 POT 超过门槛模型 (Extreme Value Theory & POT Model)]]。

### 当周练习
- 在 [[03-Projects/开源课程课后习题/PS03-时间序列与波动率|PS03]] 完成迁移题。
- 运行 [[03-Projects/HW06-DynamicVaR/README|动态 VaR 包]]，比较参数法与历史法违约次数。

### 通过闸门
- [ ] 能解释置信水平、持有期和收益频率。
- [ ] 能计算并解释 Kupiec 检验，但不把未拒绝当作模型正确证明。
- [ ] 写出厚尾情况下正态 VaR 的失效方向。

## Week 7：Black-Scholes 与动态对冲

### 本周目标
从无套利与 Delta 对冲得到 PDE；区分模型价格、市场报价和对冲误差。

### 学习顺序
[[04-深入精通/量化金融-随机过程-伊藤引理与随机微分方程]] → [[02-量化核心技能/Black-Scholes 期权定价模型 (Black-Scholes Option Pricing Model)]] → [[02-量化核心技能/期权希腊字母 (Option Greeks_ Delta, Gamma, Theta, Vega, Rho)]]。

### 当周练习
- 完成 [[03-Projects/开源课程课后习题/PS05-随机微积分与SDE|PS05]] 题 1-5。
- 运行 [[03-Projects/HW05-BSM/README|HW05 BSM 包]]，比较闭式、蒙特卡洛和离散对冲。

### 通过闸门
- [ ] 闭卷重建 PDE 的每一步，不写“显然”。
- [ ] 能解释配对样本标准误为何按 pair mean 计算。
- [ ] 写出至少两个 BSM 假设破坏后的影响。

### 学习顺序

### 当周练习

## Week 9：Capstone 整合、复盘与答辩

### 本周目标
把数据协议、基线、风险、模型和限制整理成一个可复现研究结论。

### 学习顺序
1. 回看 Week 1-8 的失败测试和错因，不重新抄笔记。
2. 完成 [[03-Projects/Capstone-统一标的贯穿实战项目]]。
3. 随机抽取两份开源练习做 7 天迁移重测。

### 当周练习
- 完成 [[03-Projects/开源课程课后习题/PS05-随机微积分与SDE|PS05]] 题 6。

### 通过闸门
- [ ] 从 README 可在干净环境复现。
- [ ] 报告包含失败结果、交易成本、样本外评估与限制。
- [ ] 总评至少 75/100，方法正确性至少 18/25。
