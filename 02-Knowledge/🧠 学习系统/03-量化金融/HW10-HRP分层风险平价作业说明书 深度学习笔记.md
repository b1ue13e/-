# HW10-HRP分层风险平价作业说明书 深度学习笔记

## 0. 先判断它值不值得深挖
- **类别**：A 类核心实战作业。
- **理由**：HRP（Hierarchical Risk Parity）是当前工业界解决资产配置鲁棒性问题的主流机器学习方法。本作业贯穿了“数学推导 $\rightarrow$ 算法设计 $\rightarrow$ 代码实现与排错 $\rightarrow$ 样本外回测评估”的全流程，是量化求职面试的高频考点，必须达到闭卷手撕代码的熟练度。

---

## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦？**

在量化投资中，传统的马科维茨均值方差模型（MVO）非常脆弱。它被称为“误差放大器”——只要输入的预期收益率或协方差矩阵有微小的估计误差（比如少量的噪声），或者资产之间存在高度共线性（相关性极高），协方差矩阵在求逆 ($\Sigma^{-1}$) 时数值就会剧烈震荡，导致最终计算出的投资权重荒谬且极端。
而传统的风险平价（Risk Parity / ERC）虽然不需要求逆，但它将所有资产视为同等地位，忽略了金融市场天然存在的**层次结构**（例如：银行股之间相关性高，而它们与黄金相关性低）。我们需要一种既不依赖矩阵求逆，又能顺应市场层级结构的资产配置算法。

---

## 2. 为什么它重要？它有什么用？
- **大图景位置**：它是现代量化金融中“资产配置”与“机器学习”结合的标杆，桥接了传统金融工程与现代无监督学习。
- **实际应用**：在桥水基金等顶级机构的大类资产配置、FOF 组合管理中被广泛使用，特别适合用于抵御市场黑天鹅和结构性突变，构建具有高鲁棒性的底仓策略。
- **本作业核心目标**：要求你从零构建 Python 版 HRP 优化器，重点考察对 `scipy` 聚类库的调用、矩阵递归分治切片能力，以及样本外（Out-of-Sample）回测的工程规范。

## 3. 学它之前需要哪些前置知识？
### 最小必要背景 (200 字以内)
1. **协方差与相关系数**：理解协方差矩阵 $\Sigma$ 衡量风险，相关系数矩阵 $\rho$ 衡量线性相关程度。
2. **逆方差加权 (IVP)**：懂最简单的风险平价——资产权重与其方差成反比：$w_i \propto 1/\sigma_i^2$。
3. **层次聚类 (Hierarchical Clustering)**：知道基于距离矩阵，将最相似的元素自底向上合并成树状图（Dendrogram）的基础概念。

---

## 4. 用直觉语言解释它
«“这东西其实就像……”»

这就像是给一个庞大的多代家族分配祖传基金。如果按照每个人的人头平分，或者按当前赚钱能力来分配（传统优化），一旦某个人隐瞒了真实财务状况（数据噪声），整个分配方案都会大乱。
HRP 的做法是：**先查家谱！**
首先根据血缘远近，把大家分成几个大支系（层次聚类）；然后在各大支系之间，根据这个支系的整体稳定性（风险/方差）去分摊资金；分摊给某个支系的资金，再在这个支系的子家庭之间继续按稳定性分摊，直到分到每个人头上（递归二分）。这样，即使某个远房亲戚的数据错得离谱，他也只会在自己的小分支里受影响，绝不会波及其他大支系的资金分配。

**直觉本质**：用“树形拓扑结构”隔离风险传染，用“分治法”替代“全局矩阵求逆”。

---

## 5. 正式定义、核心公式、符号解释

### 算法三大核心步骤与公式
1. **树形聚类 (Tree Clustering)**：将相关系数转化为满足度量空间特性的距离矩阵：
   $$ D_{i,j} = \sqrt{\frac{1}{2}(1 - \rho_{i,j})} $$
2. **准对角化 (Quasi-Diagonalization)**：根据聚类树重排协方差矩阵，使得高相关资产在对角线上相邻。
3. **递归二分 (Recursive Bisection)**：
   对任意一个聚簇 $c$，其基于逆方差加权 (IVP) 的权重 $w_c$ 为 $w_{c,i} = \frac{1/\sigma_i^2}{\sum_{j \in c} 1/\sigma_j^2}$。
   该聚簇的整体方差为：$V_c = w_c^T \Sigma_c w_c$。
   将当前聚簇对半分为 $c_1$ 和 $c_2$，按风险平价分配资金比例：
   $$ \alpha_1 = 1 - \frac{V_1}{V_1 + V_2}, \quad \alpha_2 = 1 - \alpha_1 $$

### 符号解释表
| 符号 | 含义 | 取值范围/量纲 | 备注 |
|---|---|---|---|
| $\rho_{i,j}$ | 资产 $i$ 与 $j$ 的相关系数 | $[-1, 1]$ | 直接用会导致不满足三角不等式 |
| $D_{i,j}$ | 聚类用距离矩阵 | $[0, 1]$ | $0$表示完全正相关，$1$表示完全负相关 |
| $V_c$ | 聚簇的集群方差 | $[0, +\infty)$ | 衡量一个资产簇的整体风险水平 |
| $\alpha$ | 分裂资金分配因子 | $[0, 1]$ | 控制流向左右子树的资金比例 |

## 6. 推导思路和思想来源
### 动机与“转念”
传统优化的死穴在于协方差矩阵 $\Sigma$ 极易出现**病态（ill-conditioned）**。当存在两只高度相关的资产时，$\Sigma$ 接近奇异矩阵，$\Sigma^{-1}$ 会出现极端的正负权重。
Marcos Lopez de Prado 的关键“转念”是：**既然全连接图（矩阵）算不清楚，那就把它降维成一棵树（拓扑图）！**
树状结构中没有任何循环和闭环，不存在共线性的概念。通过正交的树分支，自上而下进行分配，从根本上绕开了求逆运算。不仅具有严格的数学收敛性，更能优雅地吸收数据噪声。

## 7. 例子：基础 → 中等 → 实际应用 (作业重点)

### 例子 1：基础例子 (手算逻辑验证)
- **场景**：三个资产 A, B, C。其中 A 和 B 极度相似（$\rho_{A,B}=0.9$），C 是独立避险资产。它们的波动率都是 $10\%$。
- **MVO 的做法**：由于 AB 共线性，优化器可能会给出 A:+100%, B:-90%, C: 10% 的荒谬极端权重来试图对冲。
- **HRP 的做法**：
  1. 聚类：A 和 B 距离极近，组成簇 1 $(A, B)$，C 独自作为簇 2 $(C)$。
  2. 簇间分配：由于波动率相同，簇1整体方差与簇2相近，资金在 (AB) 和 (C) 之间按约 $50\%:50\%$ 分配。
  3. 簇内分配：(AB) 拿到的 50% 资金，在 A 和 B 内部因为风险相同，各分 25%。
- **结果**：权重为 A: 25%, B: 25%, C: 50%。非常符合常理！

### 例子 2：中等例子 (作业核心代码架构)
- **题目**：如何使用 Python 与 scipy 实现准对角化和重排？
- **代码实现指引**：
```python
import scipy.cluster.hierarchy as sch
import scipy.spatial.distance as ssd

# 1. 距离矩阵转换
dist = np.sqrt(0.5 * (1 - corr))
# 2. 将方阵转为 scipy 需要的压缩距离向量
condensed_dist = ssd.squareform(dist)
# 3. 层次聚类 (注意 link 算法的选择)
link = sch.linkage(condensed_dist, method='ward')
# 4. 获取叶子节点重排索引 (准对角化核心)
sort_ix = sch.leaves_list(link)
# 5. 根据索引重排协方差矩阵
corr_sorted = corr.iloc[sort_ix, sort_ix]
```

### 例子 3：实际应用 (作业回测与测试标准)
- **测试场景**：在包含 20 支股票、5 支国债、5 支商品的真实数据回测中，验证 HRP 的抗噪性。
- **测试标准**：对原始历史价格注入信噪比为 1:5 的随机高斯噪声。你会发现在有噪声的蒙特卡洛模拟下，MVO 策略的样本外夏普比率断崖式下跌，且换手率（Turnover）飙升；而 HRP 的夏普比率衰减不到 10%，换手率依然稳定。这就证明了实验成功。

## 8. 常见误区和实验踩坑点

- **坑点 1：距离矩阵计算错误 (ValueError)**
  - **错误做法**：直接把 `corr` 丢给 `sch.linkage()`，或者距离公式少开了个根号。
  - **正确做法**：必须使用 $D = \sqrt{0.5 \times (1 - \rho)}$，保证其满足度量空间的三角不等式。
- **坑点 2：Linkage Method 导致树生长不平衡**
  - **错误直觉**：随便用一个聚类连接法（如 `single`）。这在金融资产中极易产生“链式效应”（一长串资产依次连着，树形极不平衡）。
  - **正确策略**：作业中推荐使用 `ward` 离差平方和法或 `average` 平均距离法，生成的聚类树更均匀。
- **坑点 3：递归切片时的索引迷失**
  - **工程难点**：在“递归二分”时，传递给子函数的资产列表是重排后的索引集合。如果不注意在每层递归中维护局部索引到全局索引的映射，权重会赋值错位。**务必使用带有资产名称的 Pandas Series 来传递权重！**

### 聚类连接方法对比
| Linkage Method | 核心逻辑 | 在 HRP 中的表现 | 推荐指数 |
|---|---|---|---|
| Single | 取两个簇中最近元素的距离 | 易产生长尾链式效应，聚集性差 | ⭐ |
| Complete | 取两个簇中最远元素的距离 | 容易切断本该相连的资产 | ⭐⭐ |
| Ward | 最小化簇内方差增加量 | 产生的子树大小均衡，非常适合资金分配 | ⭐⭐⭐⭐⭐ |

## 11. 自测题：5 道

> [!question]- 1. 概念理解 (基础)
> **题目**：HRP 为什么被称为“无需计算协方差矩阵逆”的优化方法？
> 
> **答案解析**：因为 HRP 抛弃了全局联合优化，而是利用层次聚类建立树形结构，在树的每个分叉节点上，仅计算两个子簇的局部方差，并通过简单的比例分配（无需矩阵求逆）来实现风险平价。

> [!question]- 2. 公式运用 (基础)
> **题目**：已知两资产相关系数 $\rho = -0.28$，求其在 HRP 聚类时使用的距离 $D$。
> 
> **答案解析**：$D = \sqrt{0.5 \times (1 - (-0.28))} = \sqrt{0.5 \times 1.28} = \sqrt{0.64} = 0.8$。

> [!question]- 3. 实验排障 (中等)
> **题目**：在运行 `scipy.cluster.hierarchy.linkage` 时，程序报错 `ValueError: condensed distance matrix must contain only finite values`，最可能的原因是什么？
> 
> **答案解析**：最可能是输入的距离矩阵格式不对。`linkage` 要求输入一维的压缩距离矩阵，需要先调用 `scipy.spatial.distance.squareform()` 将方形矩阵进行转换。

> [!question]- 4. 深度对比 (中等)
> **题目**：如果所有资产的相关系数完全一致（例如全是 0.5），HRP 的配置结果和单纯的逆方差加权（IVP）有区别吗？
> 
> **答案解析**：没有区别。如果相关系数全部相同，聚类树会失去意义（所有距离相同），最终资金分配的比例将完全回退到由各自资产的方差决定的逆方差加权（IVP）。

> [!question]- 5. 代码架构 (较难)
> **题目**：在递归二分的逻辑中，如何确定从哪里将当前聚簇的列表切分为 $c_1$ 和 $c_2$ 两部分？
> 
> **答案解析**：由于经过了“准对角化”重排，最相似的资产在列表中已经靠在一起。切分时无需复杂计算，直接从当前列表的正中间（`len(c)//2`）进行二等分即可，由于资产已经被重排序，二等分天然就切割开了最粗粒度的两个子聚簇。
