# 协整关系与 Engle-Granger 两步法 (Cointegration & Engle-Granger Method)

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
协整（Cointegration，由 2003 年诺贝尔经济学奖得主 Robert Engle 和 Clive Granger 提出）是跨期资产定价与统计套利的“定海神针”。两个资产的价格单独看可能都是非平稳的随机游走 $I(1)$，但它们的某个线性组合却表现出常数均值和有限方差的平稳性 $I(0)$。协整是避开“伪回归（Spurious Regression）陷阱”、构建配对交易（Pairs Trading）与误差修正模型（ECM）的唯一数学检验标准。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你想在市场中寻找两只可以进行套利的股票（如贵州茅台与五粮液）。
如果你直接计算它们的日收益率相关系数，可能高达 $0.92$。
但当你根据相关系数建立回归模型 $P_A = \beta P_B + \alpha$ 时，你发现价差残差 $e_t$ 居然是非平稳的！
这意味着：虽然两只股票平时走势方向相同，但某些时候价差拉开后就**再也不回拢**，导致做多低估、做空高估的统计套利策略发生毁灭性爆仓。

**以前的方法在哪里卡住：**
1. **传统回归（OLS）**：非平稳时间序列直接线性回归会产生显著的 **伪回归 (Spurious Regression)**（$R^2$ 极高、$t$ 统计量虚高，但实际没有任何经济关系）。
2. **单纯差分法**：如果将序列全做一阶差分，虽然变成了平稳序列，但抹杀了价格之间**长期的水平均衡信息（Long-run Equilibrium）**。

**为什么必须引入协整：**
协整允许我们直接在**非平稳的价格原序列**上建立长期均衡关系，并通过 ADF 残差检验验证价差是否具备真正的均值回归特性。

**它到底解决了哪类问题：**
解决了**非平稳价格序列之间长期均衡关系的验证、伪回归识别以及统计套利策略的可行性判定**问题。

---

## 2. 为什么它重要？它有什么用？

- **体系与大图景**：非平稳时间序列计量经济学最伟大的里程碑，承上（单位根检验）启下（误差修正模型 ECM、Johansen 检验、配对交易）。
- **量化与实操应用**：
  1. **统计套利与配对交易**：通过 Engle-Granger 两步法筛选 $I(0)$ 协整对，计算 Z-Score 生成开平仓信号。
  2. **期现套利与基差回归**：验证现货价格与期货价格之间的 $I(0)$ 协整关系。
  3. **宏观多变量均衡建模**：验证消费与收入、货币供应量 M2 与 GDP 之间的长期协整。

## 4. 用直觉语言解释它

### 生活类比：醉汉与狗的牵狗绳

- **相关性 (Correlation)**：两个醉汉从酒吧出来，碰巧都朝东方走。这叫“高相关”，但过一会儿一个可能掉进河里，另一个爬上山，两者越走越远。
- **协整性 (Cointegration)**：一个醉汉牵着一条狗。醉汉随机游走（非平稳 $I(1)$），狗也乱跑（非平稳 $I(1)$）。但他们中间有一根长度有限的橡皮牵狗绳！醉汉和狗之间的距离（线性组合残差 $e_t$）永远受到橡皮绳的约束，不可能无限拉大（残差平稳 $I(0)$）。

«“协整就是两个各自乱走的随机游走序列，中间有一根收紧的橡皮绳把它们绑定在长期均衡附近。”»

## 5. 正式定义、核心公式、符号解释

### 核心定义
**协整（Cointegration）**：如果两个或多个时间序列 $X_t, Y_t$ 均为 $d$ 阶单整序列（即 $X_t, Y_t \sim I(d)$），且存在一个非零向量 $\boldsymbol{\beta} = (1, -\beta_1)^T$，使得它们的线性组合 $Z_t = Y_t - \beta_1 X_t$ 是一个较低阶单整序列（如 $Z_t \sim I(d-b)$，其中 $b > 0$），则称 $X_t$ 和 $Y_t$ 具有协整关系。

### 核心公式与 Engle-Granger 两步法

#### 1. 第一步：长期均衡 OLS 回归
对两个 $I(1)$ 序列 $Y_t$ 与 $X_t$ 进行普通最小二乘回归：
$$Y_t = \alpha + \beta X_t + e_t$$
获得对冲比例估计值 $\hat{\beta}$ 并提取残差序列：
$$\hat{e}_t = Y_t - \hat{\alpha} - \hat{\beta} X_t$$

#### 2. 第二步：残差平稳性 ADF 检验
对估计的残差序列 $\hat{e}_t$ 进行无常数项无趋势项的 ADF 检验：
$$\Delta \hat{e}_t = \gamma \hat{e}_{t-1} + \sum_{i=1}^p \psi_i \Delta \hat{e}_{t-i} + u_t$$
**临界值判定**：注意！此处 ADF 检验的临界值不能使用标准 ADF 表，而**必须使用 Engle-Granger 专属临界值表 (MacKinnon Critical Values)**（因为残差是估计出来的，自由度受损，临界值要求更严格/更负）。

若拒绝 $H_0$（即 $\hat{e}_t \sim I(0)$ 平稳），则证明 $X_t$ 与 $Y_t$ 具有协整关系！

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $X_t, Y_t$ | 原始资产价格或对数价格序列 | 货币单位/对数 | 要求均为同阶单整 $I(1)$ |
| $\hat{\beta}$ | 协整向量斜率 / 对冲比例 (Hedge Ratio) | 无量纲 | 配对交易中 1 单位 Y 需匹配 $\beta$ 单位 X |
| $\hat{e}_t$ | 长期均衡残差 (Equilibrium Error) | 货币单位 | **必须通过 ADF 检验证明为 $I(0)$ 平稳** |
| $I(1)$ | 一阶单整序列 | 差分后平稳 | 含有单位根的非平稳序列 |
| $I(0)$ | 零阶单整序列 | 原始即平稳 | 常数均值和有限方差 |

---

## 6. 推导思路和思想来源

### 为什么不能用普通的 ADF 临界值检验协整残差？
1. **OLS 拟合机制**：在第一步 $Y_t = \alpha + \beta X_t + e_t$ 中，OLS 算法的数学目标本来就是**极小化残差平方和 $\sum e_t^2$**。
2. **后果**：即使 $X_t$ 和 $Y_t$ 没有任何真实的协整关系，OLS 也会“尽最大努力”把残差压得看起来很小、很平稳。
3. **转念（MacKinnon 修正临界值）**：因此，对估计残差 $\hat{e}_t$ 做单位根检验时，更容易虚假地拒绝原假设（犯第一类错误）。必须使用比普通 ADF 更严格的 **MacKinnon 协整临界值**（例如 5% 临界值从 $-2.86$ 变更为 $-3.34$）。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（Engle-Granger 残差平稳性判定）

**题目**：
对股票 A ($Y_t$) 与股票 B ($X_t$) 过去 200 天的价格做 OLS 回归，得到：
$$Y_t = 3.0 + 1.5 X_t + \hat{e}_t$$
对残差 $\hat{e}_t$ 进行回归得到：$\Delta \hat{e}_t = -0.25 \hat{e}_{t-1} + u_t$，计算出的 ADF $t$-统计量为 $-3.85$。
查 MacKinnon 临界值表得知 $5\%$ 显著性水平下的临界值为 $-3.34$。
判断股票 A 与股票 B 是否具有协整关系？

**解答过程**：
1. 原假设 $H_0$：残差 $\hat{e}_t$ 存在单位根（非协整）。
2. 备择假设 $H_1$：残差 $\hat{e}_t$ 平稳（存在协整）。
3. 比较统计量：$t_{stat} = -3.85 < t_{critical} = -3.34$。
4. **结论**：在 5% 显著性水平下拒绝原假设 $H_0$。残差 $\hat{e}_t \sim I(0)$ 平稳，证明股票 A 与股票 B 存在显著的协整关系，对冲比例 $\beta = 1.5$。

---

### 例子 2：中等例题（伪回归识别）

**题目**：
某研究员对某国“理发服务价格 $Y_t$”与“生猪出栏价格 $X_t$”做线性回归，得到 $R^2 = 0.95$，$t_{\beta} = 15.2$（看似极度显著）。
但残差的 DW (Durbin-Watson) 统计量仅为 $0.12$，且残差 ADF 检验 $p$-value $= 0.45$。
试分析该回归模型是否存在问题？

**解答过程**：
1. 残差 ADF 检验 $p = 0.45 > 0.05$，无法拒绝残差存在单位根的原假设，残差是非平稳的 $I(1)$。
2. 当 $R^2 > DW$ 且残差非平稳时，典型地触发了**伪回归 (Spurious Regression)** 陷阱。
3. 结论：高 $R^2$ 和高 $t$ 值仅仅是因为两序列各自带有时间趋势，两者没有任何真实的协整经济关系。

---

### 例子 3：实际应用（Python 自动化 EG 协整检验与对冲比例求解）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.tsa.stattools import coint

# 模拟两只协整股票 P_A 与 P_B
np.random.seed(42)
P_B = np.cumsum(np.random.normal(0, 1, 500)) + 100
P_A = 2.0 * P_B + 10.0 + np.random.normal(0, 1, 500) # 强协整 beta=2.0

# 使用 statsmodels 的 coint 简便函数（内置 Engle-Granger 两步法）
score, pvalue, crit_value = coint(P_A, P_B)

print(f"Engle-Granger 协整检验 t-统计量: {score:.4f}")
print(f"p-value: {pvalue:.4f}")
if pvalue < 0.05:
    print("拒绝非协整假设：资产 A 与资产 B 具备显著协整关系！")
```

## 8. 常见误区与易混概念

### 误区 1：只要两个资产收益率相关系数大于 0.8，就一定存在协整关系

错误直觉：“收益率相关系数很高，说明它们肯定绑定在一起，有协整关系。”  
为什么错：相关系数很高只代表短期的“同向变动”，但如果两者的残差存在随机游走漂移，价格差会随时间无限拉大（无协整）。  
正确理解：**高相关性不等于协整性！必须对价格原序列做残差 ADF 检验。**

### 概念对比：相关性 (Correlation) vs 协整性 (Cointegration)

| 维度 | 相关性 (Correlation) | 协整性 (Cointegration) |
| :--- | :--- | :--- |
| **计算对象** | 收益率序列 $\Delta P_t$ | 价格原序列 $P_t$ |
| **稳定期限** | 短期易变（结构易变） | **长期持久（长期均衡）** |
| **数学判定** | 皮尔逊相关系数 $r$ | 组合残差 $\hat{e}_t \sim I(0)$ 平稳 |
| **应用防坑** | 容易陷入“伪回归”陷阱 | **防伪回归的标准武器** |

### 第 1 题：概念辨析（基础）
**题目**：如果两个时间序列 $X_t$ 和 $Y_t$ 存在协整关系，那么它们的线性组合 $Z_t = Y_t - \beta X_t$ 必须满足什么统计性质？

> [!question]- 答案解析
> **答案**：必须是平稳序列（即零阶单整 $I(0)$），具有常数均值、有限方差以及均值回归特性。  
> **Obsidian 标签**：`#自测题/协整定义`

---

### 第 2 题：公式运用（基础）
**题目**：经 OLS 回归得到 $P_A = 10.0 + 2.5 P_B + \hat{e}_t$。若此时 $P_A = 105$ 元，$P_B = 36$ 元。求当期的协整残差 $\hat{e}_t$。

> [!question]- 答案解析
> **答案**：
> $\hat{e}_t = P_A - (10.0 + 2.5 P_B) = 105 - (10.0 + 2.5 \times 36) = 105 - (10.0 + 90.0) = 105 - 100 = +5.0 \text{ 元}$。  
> **Obsidian 标签**：`#自测题/协整残差`

---

### 第 3 题：条件判断（中等）
**题目**：判断：“假设序列 $X_t$ 是一阶单整 $I(1)$，而序列 $Y_t$ 是平稳序列 $I(0)$，两者可以建立 Engle-Granger 协整关系。”

> [!question]- 答案解析
> **答案**：错误。协整的前提是两个序列必须是**同阶单整**（均为 $I(1)$）。一个 $I(1)$ 序列和一个 $I(0)$ 序列的线性组合必然保留 $I(1)$ 的非平稳性，不可能构成协整。  
> **Obsidian 标签**：`#自测题/同阶单整`

### 第 4 题：变式/综合（中等）
**题目**：在 EG 两步法中，若对残差 $\hat{e}_t$ 检验得到的 ADF $t$-统计量为 $-2.50$，而 MacKinnon 5% 临界值为 $-3.34$，10% 临界值为 $-3.04$。结论是什么？

> [!question]- 答案解析
> **答案**：$t_{stat} = -2.50 > -3.04 > -3.34$（未能达到拒绝域）。因此无法拒绝非协整的原假设 $H_0$，说明两序列不存在协整关系，不能进行配对套利。  
> **Obsidian 标签**：`#自测题/EG检验判定`

---

### 第 5 题：开放/建模（较难）
**题目**：为什么当变量个数 $N \ge 3$（如三只股票）时，Engle-Granger 两步法不再适用，而必须使用 Johansen 协整检验？

> [!question]- 答案解析
> **解析**：
> 1. **多协整向量问题**：当 $N \ge 3$ 时，变量之间可能存在多个（最多 $N-1$ 个）独立的协整向量。
> 2. **EG 法局限**：EG 两步法基于单方程 OLS 回归，只能估计出**一个**协整向量，且取决于哪个变量放在等式左边（因变量选择的不对称性）。
> 3. **Johansen 优势**：基于向量自回归 (VAR) 架构，通过求解矩阵特征值，能够一次性找出系统中所有的独立协整向量。  
> **Obsidian 标签**：`#自测题/Johansen与EG对比`

## 完整算例：同行业股票的 Engle-Granger 两步法

我们用中国消费品行业的两大巨头——青岛啤酒（代号 Y）**和**华润啤酒（代号 X）来做一回实战推演。它们属于同一个行业，面对同样的原材料（大麦）和同样的消费市场，理论上应该有一条“隐形的绳子”牵着它们。

**“量化不相信眼泪，只相信残差的平稳性。”** 接下来，我们彻底拆解图片中这惊心动魄的“两步法”。

## 初始状态：准备数据与直觉

假设我们收集了它们过去 1000 个交易日的收盘价。我们先看一眼原始数据：

- **青岛啤酒 ($Y$)** 现在的价格在 70 元附近徘徊；
    
- **华润啤酒 ($X$)** 现在的价格在 50 元附近徘徊。
    

如果我们直接对它们的价格做单位根检验（ADF Test），会发现它们都无法拒绝原假设，也就是说它们**本身都是不平稳的 $I(1)$ 序列**，都在像醉汉一样随机游走。

## 第一阶段：OLS 最小二乘法回归（拆解每一步）

这就是图片里的**第一步**。我们要用数学方法，把这两种资产强行“配对”，看看它们之间最完美的对冲比例是多少。

### 1. 建立回归方程

我们在 Python 里调用 `statsmodels` 库的 OLS 模块，把青岛啤酒的价格作为因变量（左手边），华润啤酒的价格作为自变量（右手边），输入这 1000 天的数据，跑出下面这个方程：

$$Y_t = \alpha + \beta X_t + \epsilon_t$$

### 2. 计算机在底层做了什么？

计算机通过**最小化残差平方和（$\sum \epsilon_t^2$）**，在千百种可能性中，帮我们找到了最合适的两个参数：

- **$\beta$（对冲比例 / 协整系数）**：假设算出来是 **$1.2$**。这代表什么？代表在统计学看来，华润啤酒每涨 1 元，青岛啤酒倾向于涨 1.2 元。
    
- **$\alpha$（截距）**：假设算出来是 **$10$**。这代表由于品牌溢价或其他固定因素，青岛啤酒天然比 1.2 倍的华润啤酒贵 10 元。
    

### 3. 提取残差序列（计算 Spread）

现在，我们有了黄金组合。我们把方程变形，提取出每一天的残差 $\hat{\epsilon}_t$（在交易中我们也叫它价差 **Spread**）：

$$\hat{\epsilon}_t = Y_t - 10 - 1.2 X_t$$

我们来看具体的两天：

- **第 100 天**：青岛啤酒 $Y = 74$ 元，华润啤酒 $X = 50$ 元。
    
    $$\hat{\epsilon}_{100} = 74 - 10 - 1.2 \times 50 = 74 - 10 - 60 = 4$$
    
    这说明今天青岛啤酒相对于华润啤酒**明显贵了**，残差为正。
    
- **第 200 天**：青岛啤酒 $Y = 66$ 元，华润啤酒 $X = 50$ 元。
    
    $$\hat{\epsilon}_{200} = 66 - 10 - 1.2 \times 50 = 66 - 10 - 60 = -4$$
    
    这说明今天青岛啤酒相对于华润啤酒**明显便宜了**，残差为负。
    

## 第二阶段：残差的单位根检验（为什么这是生死线？）

这是**第二步**。算出残差不牛逼，证明残差能“回家”（均值回归）才牛逼。

如果青岛啤酒和华润啤酒真的有协整关系，那么这个残差 $\hat{\epsilon}_t$ 虽然一会儿是 $4$，一会儿是 $-4$，但它**绝对不能一去不复返**。它必须像弹簧一样，始终围绕着均值 $0$ 震荡。

### 1. 对残差运行 ADF 检验的底层数学

我们对算出来的残差序列 $\hat{\epsilon}_t$ 建立一个自回归方程（最简单的 DF 形式）：

$$\Delta \hat{\epsilon}_t = \gamma \hat{\epsilon}_{t-1} + \nu_t$$

其中 $\Delta \hat{\epsilon}_t = \hat{\epsilon}_t - \hat{\epsilon}_{t-1}$ 是残差的变化量。

- **核心考点**：我们测试的原假设 $H_0$ 是 $\gamma = 0$（存在单位根，意味着残差是随机游走，两只股票根本没有绳子牵着，是伪回归）。
    
- 我们希望**拒绝原假设**，也就是说我们希望证明 $\gamma < 0$。如果 $\gamma$ 是个显著的负数（比如 $-0.1$），这意味着如果昨天的价差很大（$\hat{\epsilon}_{t-1}$ 为正），今天的价差就会倾向于减小（$\Delta \hat{\epsilon}_t$ 为负）。这就是**均值回归的数学铁证**！
    

### 2. 隐藏的魔鬼细节：为什么不能用普通的 ADF 临界值？

这是初学者 99% 会漏掉的顶级知识点。

在普通的 ADF 检验中，我们直接查 Dickey-Fuller 表。但是！这里的残差 $\hat{\epsilon}_t$ **不是原始观测数据，而是通过第一步 OLS 强行“捏合”出来的**。

> 💡 **硬核真相**：最小二乘法（OLS）天生就有一种奴性，它会极尽谄媚之能事，通过调整 $\beta$ 和 $\alpha$，让残差序列看起来“尽可能平稳”。
> 
> 哪怕这两只股票根本没有协整关系，OLS 算出来的残差也会比真实情况更显得平稳。

因此，如果我们使用普通的 ADF 临界值（比如 $-2.86$），我们就会高估它们的协整性。我们必须使用更严格的 **Engle-Granger 专用临界值表（也称 MacKinnon 临界值表）**。

- 普通 ADF 的 5% 显著性临界值可能是 $-2.86$。
    
- 而 Engle-Granger 考虑了变量个数后，5% 的临界值会被推高到 **$-3.34$**（要求更负、更严格）。
    

### 3. 最终裁判

假设软件计算出我们残差的 ADF 统计量（$t$-statistic）为 **$-3.85$**。

我们拿 $-3.85$ 去和临界值 $-3.34$ 对比。因为 $-3.85 < -3.34$（它落在了极端的拒绝域），我们成功**拒绝存在单位根的原假设**！

**恭喜你，协整关系正式成立！你找到了量化交易的圣杯。**

## 第三阶段：从检验到捞钱（策略落地）

通过上述两步，你拿到了两样东西：

1. **对冲比例**：$1 : 1.2$（买入 1 手青岛啤酒，需要同时做空 1.2 手华润啤酒）。
    
2. **一个完美的平稳时间序列**：$\hat{\epsilon}_t$。
    

由于 $\hat{\epsilon}_t$ 是平稳的，它的均值是 $0$，标准差（假设）是 $\sigma = 2$。

|**当残差 Z-Score 状态**|**市场含义**|**你的量化开仓指令**|**获利原理**|
|---|---|---|---|
|**$Z > +2$** (残差 $> 4$)|青岛啤酒被严重高估，华润被低估|**卖出**青岛啤酒 ($Y$)，**买入** 1.2倍华润啤酒 ($X$)|等待价差缩回 0，平仓双向获利|
|**$Z < -2$** (残差 $< -4$)|青岛啤酒被严重低估，华润被高估|**买入**青岛啤酒 ($Y$)，**卖出** 1.2倍华润啤酒 ($X$)|等待价差涨回 0，平仓双向获利|
[[表格理解]]
这就是 Engle-Granger 两步法从数据到统计、再到策略的完整闭环。
