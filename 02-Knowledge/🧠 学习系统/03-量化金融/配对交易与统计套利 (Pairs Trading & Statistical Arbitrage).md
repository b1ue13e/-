# 配对交易与统计套利 (Pairs Trading & Statistical Arbitrage)

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
配对交易（Pairs Trading）由摩根士丹利量化团队（Nunzio Tartaglia 等人）于 20 世纪 80 年代发明，是统计套利（StatArb）与市场中性（Market Neutral）策略的鼻祖。它将严密的统计学工具（协整检验、卡尔曼滤波、Z-Score 信号）转化为具备真实 Alpha 的交易策略。在量化对冲基金中，配对交易不仅是面试必考点，也是搭建多资产统计套利系统的底层原型。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你看好贵州茅台，但此时大盘宏观经济面临加息，整个 A 股大盘都在暴跌。即使茅台基本面优异，也难以抵挡全市场大盘下跌的泥石流。
单边做多（Long-only）必须承受巨大的市场系统性风险（Beta 风险）。

**以前的方法在哪里卡住：**
1. **单边猜涨跌**：依靠择时预测全市场方向胜率低、波动大。
2. **单纯相关性配对**：寻找两只走势相关的股票（如可口可乐与百事可乐），但简单相关性经常出现“伪相关”。两只股票可能各自单边大涨，但价差持续发散不回头，导致配对套利巨额亏损。

**为什么必须引入基于协整的配对交易：**
通过严格的**协整（Cointegration）检验**，找到线性组合 $y_t - \beta x_t = z_t$ 具备平稳均值回归特性的资产对；并在对冲组合中消除市场 Beta，实现无视大盘涨跌的**市场中性绝对收益**。

**它到底解决了哪类问题：**
解决了**消除市场单边系统性风险（Beta 对冲），在两只经济同质资产偏离历史均衡价差时进行均值回归获利**的问题。

- **体系与大图景**：量化策略开发（第三阶段）核心框架，连接计量经济学（协整/ECM）与对冲交易实战（仓位/止损/风控）。
- **量化与实战应用**：

## 4. 用直觉语言解释它

### 生活类比：主人与宠物狗遛弯（协整模型）

想象一个人（股票 A）遛一条狗（股票 B），狗身上系着一条有弹性的橡皮筋（协整关系）。
主人和狗在公园里漫无目的地随机游走（价格各自是非平稳的 $I(1)$），但因为橡皮筋的存在，狗跑得太远就会被拽回来，主人落后了也会加快脚步。
你（配对交易员）并不需要预测主人和狗最终会走到公园的哪个角落（无需预测大盘涨跌），你只需要在**狗跑离主人太远（橡皮筋拉得很紧，Z-Score 超出界限）时，买入落后的那一方、卖空跑得太远的那一方**。

**配对交易的直觉本质**：
不赌任何一只股票的单边方向，只赌两只相关资产被拉开的橡皮筋最终会弹回原处。

«“配对交易就是买入暂时落后的资产，卖空暂时跑太快的同类资产，等待橡皮筋弹回历史均值。”»

## 5. 正式定义、核心公式、符号解释

### 核心定义
**配对交易（Pairs Trading）**：一种基于均值回归原理的市场中性统计套利策略。通过选择具有长期协整关系的两种资产，在其价差偏离长期均衡区间时，卖出相对高估的资产、买入相对低估的资产，并在价差回归均衡时平仓获利。

### 核心公式

#### 1. 协整回归方程 (Hedge Ratio $\beta$ 估计)
$$P_{A, t} = \alpha + \beta P_{B, t} + \epsilon_t$$

#### 2. 价差 (Spread) 与 Z-Score 计算
$$\text{Spread}_t = P_{A, t} - \beta P_{B, t}$$
$$Z_t = \frac{\text{Spread}_t - \mu_w(S)}{\sigma_w(S)}$$
其中 $\mu_w, \sigma_w$ 为滚动窗口 $W$ 内价差的均值与标准差。

#### 3. 交易信号生成规则
- **开仓做多价差 (Long Spread)**：当 $Z_t < -Z_{entry}$ 时，买入 1 单位 A，卖空 $\beta$ 单位 B。
- **开仓做空价差 (Short Spread)**：当 $Z_t > +Z_{entry}$ 时，卖空 1 单位 A，买入 $\beta$ 单位 B。
- **平仓回归 (Exit)**：当 $|Z_t| \le Z_{exit}$ （如 $Z \approx 0$）时平仓。
- **止损保护 (Stop Loss)**：当 $|Z_t| \ge Z_{stop}$ （如 $|Z| > 3.5$）时强制止损（防协整关系破裂）。

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $P_A, P_B$ | 资产 A 与资产 B 的价格（或对数价格） | 货币单位 | 必须满足协整关系 |
| $\beta$ | 对冲比率 (Hedge Ratio) | 无量纲/比例 | 通常用 OLS 或卡尔曼滤波动态估计 |
| $\text{Spread}_t$ | $t$ 时刻的价差残差 | 货币单位 | 要求满足平稳性 $I(0)$ |
| $Z_t$ | 滚动的标准化 Z-Score 信号 | 标准差倍数 | 触发开平仓信号 |
| $Z_{entry}$ | 开仓触发阈值 | 标准差倍数 | 常用 $1.5 \sim 2.0$ |
| $Z_{stop}$ | 止损触发阈值 | 标准差倍数 | 常用 $3.0 \sim 3.5$ |

## 6. 推导思路和思想来源

### 为什么单纯相关性 (Correlation) 靠不住？
1. **假相关陷阱**：两只非平稳时间序列（如随机游走 $I(1)$）即使完全无关，其相关系数也可能高达 0.9（伪回归）。如果在高相关但非协整的资产上做配对，价差可能一去不复返（橡皮筋拉断）。
2. **转念（协整检验 Cointegration）**：只有残差 $\text{Spread}_t \sim I(0)$，才保证残差在统计上具备**常数均值和有限方差**，保证价差一定会以有限的半衰期回归均值。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（Z-Score 计算与开仓决策）

**题目**：
根据历史数据回归得到：股票 A 与股票 B 的对冲比例 $\beta = 1.2$。
近 30 天价差 $\text{Spread} = P_A - 1.2 P_B$ 的滚动均值 $\mu_w = 2.0$ 元，标准差 $\sigma_w = 0.5$ 元。
今天收盘时：$P_A = 100$ 元，$P_B = 80$ 元。设定开仓阈值 $Z_{entry} = 2.0$。
计算今天的 Z-Score，并给出交易操作指令。

**解答过程**：
1. 计算今天的价差 $\text{Spread}_{today}$：
   $$\text{Spread} = 100 - 1.2 \times 80 = 100 - 96 = 4.0 \text{ 元}$$
2. 计算标准化 Z-Score：
   $$Z = \frac{4.0 - 2.0}{0.5} = \frac{2.0}{0.5} = +4.0$$
3. 决策判断：
   $Z = +4.0 > Z_{entry} = 2.0$，价差严重向上偏离！
   同时 $Z = 4.0 > Z_{stop} = 3.5$，触发了止损/异常偏离区。
   **指令**：若为常态偏离（未设 $Z_{stop}$ 超限）则做空价差（卖空 A、买入 $1.2$ 份 B）；若触发风控止损门槛则拒绝开仓，预防破裂。

---

### 例子 2：中等例题（对冲组合资金分配与市场中性构建）

**题目**：
你有 100 万元资金进行配对交易。股价 $P_A = 50$ 元，$P_B = 20$ 元，对冲比例 $\beta = 2.0$（即 1 股 A 匹配 2 股 B）。
当信号触发买入 A、卖空 B 时，应如何分配买入和卖空的资金金额以保持对冲平衡？

**解答过程**：
1. 每一份策略单元包含：做多 1 股 A（花费 50 元），同时做空 2 股 B（融券收入 $2 \times 20 = 40$ 元）。
2. 每单元对应资产名义总敞口 $= 50 + 40 = 90$ 元。
3. 100 万元做多保证金可建立的单元份数：$\approx \frac{1,000,000}{90} \approx 11,111$ 份。
4. 具体头寸：
   - 买入股票 A：$11,111 \times 50 = 55.55$ 万元。
   - 卖空股票 B：$11,111 \times 40 = 44.44$ 万元。
   - 实现无市场单边 Exposure 的对冲建仓。

---

### 例子 3：实际应用（Python 完整配对交易策略回测框架）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

# 模拟两只协整股票价格 P_A 与 P_B
np.random.seed(42)
N = 200
P_B = 50 + np.cumsum(np.random.normal(0, 1, N))
noise = np.random.normal(0, 0.5, N)
P_A = 1.5 * P_B + 5.0 + noise # 强协整关系 beta=1.5

# 1. 滚动回归求解动态 beta 与 Z-score
spread = P_A - 1.5 * P_B - 5.0
z_score = (spread - np.mean(spread)) / np.std(spread)

# 2. 生成信号: Z < -1.5 逢低做多价差，Z > 1.5 逢高做空价差
positions = np.zeros(N)
positions[z_score < -1.5] = 1   # 买A卖B
positions[z_score > 1.5] = -1   # 卖A买B
positions[np.abs(z_score) < 0.2] = 0 # 平仓

print("策略开仓天数:", np.count_nonzero(positions))
```

## 8. 常见误区与易混概念

### 误区 1：高相关系数（Correlation 近于 1）的资产一定可以做配对交易

错误直觉：“A 和 B 的收益率相关系数 0.95，绝对能做配对套利。”  
为什么错：高相关只代表方向同步，但两者的价格差可能呈现趋势性漂移（如 $y_t = x_t + 0.1 t$），导致价差无限发散。  
正确理解：必须通过 ADF 检验验证残差的**平稳性 (Cointegration)**，确保价差具备真正的均值回归特性。

### 概念对比：相关性 vs 协整性

| 维度 | 相关性 (Correlation) | 协整性 (Cointegration) |
| :--- | :--- | :--- |
| **关注对象** | 收益率（变化量）的短期同步程度 | 价格（绝对水平）的长期均衡约束 |
| **数学要求** | 线性相关系数 $r$ | 线性组合残差平稳 $I(0)$ |
| **失效风险** | 容易遇到“伪相关”导致价差发散爆仓 | 仅在公司基本面发生结构性断裂时失效 |

### 第 1 题：概念辨析（基础）
**题目**：在配对交易策略中，当整个大盘股票市场暴跌 $20\%$ 时，一个完善对冲的配对交易组合理论上会发生什么？

> [!question]- 答案解析
> **答案**：理论上受大盘暴跌影响极小（市场中性），因为组合同时持有了等 Beta 量的空头与多头，大盘下跌造成的空头盈利会完全抵消多头亏损，收益取决于两只股票相对价差的回归。  
> **Obsidian 标签**：`#自测题/配对交易`

### 第 2 题：公式运用（基础）
**题目**：已知价差历史均值 5.0，标准差 1.0。若当前价格 $P_A = 20, P_B = 10, \beta = 1.2$。求当前的 Z-Score。

> [!question]- 答案解析
> **答案**：
> $\text{Spread} = 20 - 1.2 \times 10 = 20 - 12 = 8.0$。
> $Z = \frac{8.0 - 5.0}{1.0} = 3.0$。  
> **Obsidian 标签**：`#自测题/ZScore计算`

### 第 3 题：条件判断（中等）
**题目**：判断：“若配对交易中的某只股票因违约突然停牌破产，Z-Score 会急剧飙升，此时策略应该继续加仓以摊薄成本等待回归。”

> [!question]- 答案解析
> **答案**：错误。公司破产代表基本面发生结构性断裂（Structural Break），协整关系彻底解体，价差永远不会回归。此时加仓会导致毁灭性亏损，必须严格触发止损离场。  
> **Obsidian 标签**：`#自测题/配对风控`

### 第 4 题：变式/综合（中等）
**题目**：某配对交易每次单边交易滑点与手续费成本合计为 $0.15\%$。如果价差回归预计能带来 $0.50\%$ 的毛收益，但股票借券利息为年化 $8.0\%$，持仓平仓花了 30 天。求该笔交易的净收益率。

> [!question]- 答案解析
> **答案**：
> 1. 双边交易摩擦成本（开仓+平仓，多头+空头）$\approx 0.15\% \times 4 = 0.60\%$。（若按单边费率双向算）
> 2. 借券持仓成本 $= 8.0\% \times \frac{30}{365} \approx 0.657\%$。
> 3. 净收益 $= 0.50\% - \text{摩擦成本} - \text{借券成本} < 0$，该笔交易实际亏损！说明交易频率与持仓成本必须精算。

### 第 5 题：开放/建模（较难）
**题目**：为什么传统的 OLS 静态估计 $\beta$ 在长期配对交易中效果较差？卡尔曼滤波（Kalman Filter）是如何改善这一问题的？

> [!question]- 答案解析
> **解析**：
> 1. **OLS 局限**：静态 OLS 假设对冲比例 $\beta$ 永恒不变，但现实中企业的业务比重、财务杠杆随时在变，静态 $\beta$ 会导致模型失效。
> 2. **Kalman Filter 改进**：将 $\beta_t$ 设为隐状态变量（State Variable），建立状态空间模型（State-Space Model），利用每期最新的价格观测值 $P_t$ 进行贝叶斯在线更新（Update），实现对冲比例 $\beta_t$ 的实时动态追踪。  
> **Obsidian 标签**：`#自测题/卡尔曼滤波`
