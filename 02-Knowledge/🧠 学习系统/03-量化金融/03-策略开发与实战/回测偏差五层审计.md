# 回测偏差五层审计

## 五层清单

| 层 | 核心问题 | 代表风险 |
|:---|:---|:---|
| 数据 | 字段何时可得、是否修订 | 复权、发布日期、缺失值 |
| 股票池 | 是否使用历史时点成分 | 生存者偏差、退市遗漏 |
| 特征 | 是否含未来或全样本统计 | `shift(-1)`、全样本标准化 |
| 标签 | 窗口是否跨切分 | 标签重叠、边界泄漏 |
| 执行 | 信号后能否真实成交 | 同收盘成交、停牌、成本 |

每项只能标记 `pass / fail / unknown / blocked`，并给出证据路径。没有数据不等于通过。

## K24 最小作业与闸门

对 E0/E1/E2 填写五层清单。通过要求：每一项有证据；unknown 不冒充 pass；失败项说明影响和修复；执行层同时检查成本与可成交性。

## 🃏 Anki 卡片

- K24｜回测五层审计是哪五层？ :: 数据、股票池、特征、标签、执行。
- K24｜为什么 `unknown` 不能当作 `pass`？ :: 缺少证据只说明无法判断，不证明不存在偏差。

## K24 来源、边界与独立复核

### 定义、假设、机制与边界

回测偏差五层审计把风险分为数据、股票池、特征、标签和执行。机制是对每层列出可见时间、选择规则、失败测试与证据位置；任何 unknown 都不能自动转为 pass。假设某层无泄漏并不能推出其他层安全。反例是特征完全滞后，却使用今天仍存续的股票重建十年前股票池。验证应故意破坏一层并确认审计测试失败，同时保留失败日志。

### 可定位来源

1. scikit-learn Common pitfalls, Section Data leakage: https://scikit-learn.org/stable/common_pitfalls.html
2. Microsoft Qlib Recorder, Section experiment artifacts and portfolio analysis: https://qlib.readthedocs.io/en/stable/component/recorder.html
3. López de Prado, Advances in Financial Machine Learning, Wiley, 2018, ISBN 9781119482086, Chapters 7 and 11.

### 可复现示例与验证

```python
layers = {"data":"pass", "universe":"unknown", "feature":"pass", "label":"pass", "execution":"fail"}
assert set(layers) == {"data","universe","feature","label","execution"}
formal_pass = all(v == "pass" for v in layers.values())
assert not formal_pass
```

该最小实验只验证 K24 的定义、符号或时间边界，不等价于策略有效。正式结论还必须保存输入版本、期望输出、实际结果和失败案例。
