# 换手率调和收益

> K10 的目标不是发明一个新指标，而是把目标权重变化、真实交易额和成本扣除接成可复核的 E0 基线。

设上期持仓经价格漂移后的权重为 $\tilde w_{t-1}$，本期目标权重为 $w_t$。常见单边换手定义为：

$$TO_t=\frac{1}{2}\sum_i|w_{t,i}-\tilde w_{t-1,i}|$$

若成本率按单边换手匹配，可写近似成本 $C_t=c\,TO_t$；实际项目需按买卖两侧费率分别计算。净收益仍是：

$$R_t^{net}=R_t^{gross}-C_t$$

## Worked example

两资产从漂移后的 `55%/45%` 调回 `50%/50%`。绝对权重变化和为 10%，单边换手为 5%。若买卖均按 20 bps 计且使用单边换手口径，成本为 $5\%\times20\text{ bps}=1\text{ bp}$。若采用双边成交额定义，公式必须相应调整，不能混用。

## K10 最小作业

建立 E0 等权组合，输出逐期目标权重、漂移权重、买入额、卖出额、换手、gross、cost、net；再运行低/中/高三档成本敏感性。

## K10 来源、边界与独立复核

### 定义、假设、机制与边界

换手率调和收益的定义不是新绩效指标，而是把权重变化、交易成本和净收益放在同一会计恒等式中。双边换手常写为权重绝对变化之和的一半，但具体口径必须声明是否包含现金、申赎和漂移。机制上更高换手通常提高成本，却不保证收益单调下降，因为成交时点也会变化。反例是只报告换手后 Sharpe 而不保留 gross 与 net。验证应对等权持有、全量换仓和部分调仓三个场景手算。

### 可定位来源

1. Microsoft Qlib Recorder, Section portfolio analysis with and without cost: https://qlib.readthedocs.io/en/stable/component/recorder.html
2. Qlib Strategy, Section TopkDropoutStrategy and turnover controls: https://qlib.readthedocs.io/en/stable/component/strategy.html
3. Perold, The Implementation Shortfall, DOI 10.3905/jpm.1988.409150, Section transaction accounting: https://doi.org/10.3905/jpm.1988.409150

### 可复现示例与验证

```python
old = [0.5, 0.5, 0.0]
new = [0.0, 0.5, 0.5]
turnover = 0.5 * sum(abs(a-b) for a, b in zip(old, new))
assert turnover == 0.5
assert 0 <= turnover <= 1
```

这段最小实验不是收益证明；它只验证 K10 的局部定义与边界。正式作业仍需保存输入、期望输出、实际结果和失败案例。
