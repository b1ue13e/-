# 因子构造

一个可审计因子必须在运行前冻结五项：**经济含义、原始字段、变换与窗口、方向、可得时间**。例如 20 日动量可写成 $f_{i,t}=P_{i,t}/P_{i,t-20}-1$，预期方向为正；若使用 t 日收盘价，信号只能在收盘后形成并于预设的后续时点执行。

## 最小因子定义卡

| 字段 | 必填内容 |
|:---|:---|
| 名称与假设 | 为什么它可能预测未来收益 |
| 输入 | 字段、单位、复权、发布日期 |
| 公式 | 变换、窗口、缺失处理 |
| 方向 | 高值应对应高/低未来收益 |
| 可交易时间 | 特征完成与最早执行时间 |
| 失效边界 | 容量、行业暴露、制度变化等 |

## K11 最小作业与闸门

只选 1–3 个简单因子，逐项填写定义卡；未看测试结果前冻结方向。通过要求：公式能在 10 行小样本手算，字段可得时间明确，缺失值不静默替换，测试期结果不能用于修改定义。

## K11 来源、边界与独立复核

### 定义、假设、机制与边界

因子构造的定义是把经济假设转成在每个资产与时点都可重复计算的数值映射。机制必须冻结字段、变换、窗口、方向和可得时间；任何看完测试结果再改方向的动作都属于研究者自由度。成立条件包括原始字段 point-in-time、横截面股票池可追溯。反例是把未来二十日收益误作“动量因子”。独立验证应在十行样本上手算一个资产，并测试窗口未满、价格缺失和分母为零的边界。

### 可定位来源

1. Microsoft Qlib Data Layer, Section Expression Engine and formulaic alphas: https://qlib.readthedocs.io/en/stable/component/data.html
2. Qlib Alpha158 data handler configuration, Section Feature expressions: https://qlib.readthedocs.io/en/stable/component/data.html#data-handler
3. López de Prado, Advances in Financial Machine Learning, Wiley, 2018, ISBN 9781119482086, Chapter 4.

### 可复现示例与验证

```python
prices = [100, 101, 103]
momentum_2 = prices[-1] / prices[0] - 1
assert abs(momentum_2 - 0.03) < 1e-12
available_at = 2
assert available_at == len(prices) - 1
```

这段最小实验不是收益证明；它只验证 K11 的局部定义与边界。正式作业仍需保存输入、期望输出、实际结果和失败案例。
