# 因子标准化

> **K12 目标**：不靠阅读完成度，而是通过定义、边界、反例和可运行断言证明掌握。

## 0. 先测再学

闭卷写出 因子标准化 的输入、输出、成立条件和一个失败案例。若无法写清，先完成本页示例，不并行开启下一个 K 点。

## 1. 定义、机制、假设与边界

因子标准化的定义是在指定信息集合内改变尺度，而不改变研究对象。横截面 z-score 应只使用当日可见资产；训练型变换则只能在训练区间拟合。机制通常包含去极值、缺失处理、行业或规模中性化与标准化，顺序改变会产生不同结果。假设均值方差稳定并不总成立。反例是先用全样本均值标准化再切测试集。验证应检查每期均值、标准差、极端值和只含一个有效样本的截面。

## 2. Worked example

```python
import numpy as np
x = np.array([1.0, 2.0, 3.0])
z = (x - x.mean()) / x.std(ddof=0)
assert abs(z.mean()) < 1e-12
assert abs(z.std(ddof=0) - 1) < 1e-12
```

运行后必须保存输入、期望输出和实际输出。代码可执行只证明局部定义一致，不证明策略在样本外有效。

## 截面协议：标准化只在同一可比集合内进行

**因子标准化**通常在单个交易日横截面完成：先按当日可见股票池处理极值，再用当日中心和尺度转成可比较分数。机制上，z-score 假设均值与标准差有代表性；偏态或厚尾因子可改用中位数/MAD 或秩变换，但不同方法会改变极端信息。复现实验应对常数列、单个极端值、小样本行业和全缺失组设置明确输出并断言无穷值不会进入模型。

反例是用全历史均值标准化，或在行业中性化后忘记重新检查市值暴露。**因子标准化**的验收要求是逐日保存处理前后分位数、缺失率和行业/市值相关性，并在训练期冻结方法；若换一种稳健尺度就导致因子收益符号反转，应登记为不稳定而非择优报告。

### 定义—推导—对比复核

**因子标准化** 的定义必须能落到数据列和时点，而不能只停留在术语。从当日可比集合定义中心与尺度，再对比 z-score、MAD 和秩变换对尾部信息的保留程度。因此，对 **因子标准化** 的误区检查要同时保留正例、破坏条件后的反例和样本外结果；只要三者不能形成同一因果链，就暂不判定掌握。
