# 分层回测

> **K15 目标**：不靠阅读完成度，而是通过定义、边界、反例和可运行断言证明掌握。

## 0. 先测再学

## 1. 定义、机制、假设与边界

分层回测的定义是在每个截面按预先冻结的因子排序，把资产分入若干组合并追踪后续收益。机制要固定股票池、分位数边界、权重、调仓和成本，才能把 Top-Bottom 差异解释为排序证据。假设每层有足够资产且可交易；重复值、缺失和小截面会使 qcut 失效。反例是看完结果后改成最有利的分组数。验证应同时报告各层样本数、单调性、换手和净收益。

## 2. Worked example

```python
scores = [1, 2, 3, 4, 5]
future = [-0.02, -0.01, 0.00, 0.01, 0.03]
assert len(scores) == len(future)
top_bottom = future[-1] - future[0]
assert abs(top_bottom - 0.05) < 1e-12
```

运行后必须保存输入、期望输出和实际输出。代码可执行只证明局部定义一致，不证明策略在样本外有效。

## 单调性协议：分层只验证排序，不自动证明可交易收益

**分层回测**先在每个调仓日用当时可见的横截面分位点分组，再把下一持有期收益归入对应组。若全样本先计算固定阈值，未来分布已经泄漏。机制上，理想因子应表现为组间收益大体单调，而不只是最高组偶然胜出；因此需要同时报告各组净值、Top-minus-Bottom、Rank IC、组内样本数和换手。

反例包括小市值股票集中在极端组、停牌股无法成交、以及分位点重复导致某组为空。**分层回测**的最小实验应打乱因子生成零基线，再按市值和行业中性化重跑；只有成本后多期单调性仍稳定、极端组不由少数证券驱动时才通过。

### 定义—推导—对比复核

**分层回测** 的定义必须能落到数据列和时点，而不能只停留在术语。从当期横截面排序推导组别，再对比分层单调性与单个多空组合收益，避免把一个极端组的偶然收益当稳定排序能力。因此，对 **分层回测** 的误区检查要同时保留正例、破坏条件后的反例和样本外结果；只要三者不能形成同一因果链，就暂不判定掌握。
