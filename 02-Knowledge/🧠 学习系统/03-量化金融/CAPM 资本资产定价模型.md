# CAPM 资本资产定价模型

所属模块： 量化金融 / 夯实基础
关联课程： 投资学、公司理财、金融计量学
重要程度： A
前置知识： [[相关系数、协方差与资产组合分散化 (Covariance, Correlation & Diversification)|马科维茨均值-方差模型]]、[[🧠 无风险资产与资本市场线 (Risk-free Asset & Capital Market Line)|无风险资产与资本市场线]]
后续延伸： [[APT套利定价理论]]、[[Fama-French三因子模型]]
当前状态： 学习中

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**

CAPM（Capital Asset Pricing Model，资本资产定价模型）是现代金融学的灵魂和立足之基。如果不彻底搞懂 CAPM，现代公司理财中的加权平均资本成本（WACC）、投资组合管理中的业绩评价（Alpha/Beta）、资产定价中的因子模型（APT、Fama-French）以及量化对冲交易的底层逻辑将全面塌陷。它是金融学从“经验定性”走向“严格数学定量”的里程碑，在期末考试、CPA/CFA 认证、量化面试中均属于必考核心。

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你手里有 100 万现金，现在有两个项目找你投资：

1. **老牌贵州茅台**：业务稳定，但大家觉得收益可能一般。
    
2. **初创 AI 芯片公司**：波动剧烈，可能暴赚也可能赔光。
    

作为投资人，你心里一定有这个困惑：**“对于承担的风险，我到底该索要多少的回报率才合理？”**

在 CAPM 出现之前，金融界处于“乱打鬼”状态。大家知道“风险越高，收益越高”，但**无法量化**：

- 波动大 2 倍，收益率就该提升 2 倍吗？
    
- 如果某种风险可以通过“多买几家公司的股票（分散投资）”直接抹平，市场凭什么要为此付给你更高的收益率？
    

**以前的方法在哪里卡住：**

马科维茨（Markowitz）提出了投资组合理论，告诉大家怎么通过分散投资降低风险（用方差 $\sigma^2$ 表示风险）。但马科维茨没有解答：**在市场达到平衡时，单只股票或单个资产的“合理价格”和“期望收益率”到底由什么决定？**

**为什么必须引入 CAPM：**

我们需要一个工具，把资产的总风险拆开，精准剔除掉“可以通过分散化消除的风险”，只针对“无法被分散的风险”进行定价。

**它到底解决了哪类问题：**

给**任何风险资产**（股票、债券、项目）的风险进行**标准化定价**，确定其合理的**最低要求回报率（期望收益率）**。

## 2. 为什么它重要？它有什么用？

```
  【前置知识】                【核心模型】                【下游应用】
马科维茨均值-方差模型 ──┐                             ┌──> WACC 计算与企业估值
                      ├──> CAPM 资本资产定价模型 ────┼──> 基金业绩评价 (Alpha / Beta)
无风险资产与 SML     ──┘                             └──> 多因子模型 (Fama-French)
```

- **课程大图景：** 它是投资学/公司理财的承上启下者。向上承接马科维茨资产组合理论与资本市场线（CML），向下衍生出证券市场线（SML）、WACC 计算、业绩评价（Sharpe ratio, Jensen's Alpha）及多因子模型。
    
- **实际应用领域：**
    
    - **公司理财/投行：** 计算公司的股权资本成本（$r_e$），用于 DCF 折现模型估算公司价值。
        
    - **基金管理：** 评价基金经理是靠选股能力赚钱（赚 Alpha），还是仅仅靠大盘上涨赚钱（赚 Beta）。
        
    - **量化投资：** 构造 Market Neutral（市场中性）策略，剥离 Beta 风险，套取纯粹的 Alpha。
        

## 3. 学它之前需要哪些前置知识？

### 最小必要背景 1：系统性风险与非系统性风险

- **非系统性风险（Unsystematic Risk）：** 个别公司特有的风险（如 CEO 离职、厂房着火）。这种风险可以通过同时买入 30 支不同行业的股票**完全对冲掉（分散化）**。
    
- **系统性风险（Systematic Risk）：** 全局性风险（如加息、战争、宏观经济衰退）。所有公司都会受影响，**买再多股票也无法消除**。
    

> **核心定理：** 资本市场是高效且“精明”的，它**只对投资者承担的“系统性风险”给予风险补偿**。想靠承担非系统性风险赚钱？市场认为那是你徒劳的裸奔，不予补偿！

### 最小必要背景 2：协方差与 Beta 的直觉

协方差 $\text{Cov}(R_i, R_m)$ 测量资产 $i$ 与市场整体 $m$ 的“同频共振程度”。若协方差为正，大盘涨它也涨；若为负，大盘涨它反跌。

## 4. 用直觉语言解释它

资产的期望收益率，本质上是由“躺赚保底”**加上**“硬核风险打工费”构成的。

> «“CAPM 就像在市场里做生意买保险：无风险利率（如国债）是你的保底收入。如果你想多赚钱去买股票，市场只看你的股票和整个大盘（市场组合）的绑定程度。如果大盘跌 10%，你的股票跟着跌 15%，说明你这股票太敏感、太危险了，那你必须给投资者更高的收益率作为补偿！”»

### 可视化结构示意图

```
总期望收益率 E(R_i)
┌─────────────────────────────────────────┐
│  风险溢价 (打工费)                       │ ──> β_i × [E(R_m) - R_f]
│  (由资产与大盘的联动程度 β_i 决定)       │
├─────────────────────────────────────────┤
│  无风险收益率 (保底收入)                 │ ──> R_f (如国债收益率)
└─────────────────────────────────────────┘
```

- **直觉本质：** **资产的价格不取决于它自己有多抖（总方差），而取决于它跟整个市场一起抖的程度（Beta）。**
    

## 5. 正式定义、核心公式、符号解释

### 1. 核心定义

资本资产定价模型（CAPM）表明：在市场均衡状态下，任何风险资产的期望收益率与其对市场组合的系统性风险（以 $\beta$ 表示）成正比例线性关系。

### 2. 核心公式（证券市场线 SML）

$$E(R_i) = R_f + \beta_i \Big(E(R_m) - R_f\Big)$$

其中，$\beta_i$（贝塔系数）的计算公式为：

$$\beta_i = \frac{\text{Cov}(R_i, R_m)}{\text{Var}(R_m)}$$

### 3. 常见变体

若考虑实际收益率与期望收益率的偏差，可写成回归方程形式：

$$R_{i,t} - R_{f,t} = \alpha_i + \beta_i \Big(R_{m,t} - R_{f,t}\Big) + \epsilon_{t}$$

- 当 $\alpha_i > 0$ 时，说明该资产被**低估**（超额收益）；
    
- 当 $\alpha_i < 0$ 时，说明该资产被**高估**。
    

### 4. 符号解释

|**符号**|**含义**|**取值范围/量纲**|**备注**|
|---|---|---|---|
|$E(R_i)$|资产 $i$ 的期望收益率|通常为 $[0, 1]$ 或百分比|我们想要算出的“合理定价”|
|$R_f$|无风险收益率|无风险，通常为 $[1\%, 5\%]$|通常用长期国债收益率替代|
|$E(R_m)$|市场组合的期望收益率|视市场情况，如 $[8\%, 12\%]$|代表整个大盘的平均收益率|
|$E(R_m) - R_f$|市场风险溢价 (ERP)|通常为 $[4\%, 8\%]$|投资整个大盘相比无风险资产的额外补偿|
|$\beta_i$|资产 $i$ 的系统性风险系数|$(-\infty, +\infty)$，常见 $[0.5, 2.0]$|$\beta=1$ 风险同大盘；$\beta>1$ 激进；$\beta<1$ 防御|
|$\text{Cov}(R_i, R_m)$|资产 $i$ 与市场组合的协方差|不受限|量度同频共振方向和幅度|
|$\text{Var}(R_m)$|市场组合的方差|$> 0$|市场整体波动的平方|

### 5. 适用条件与限制 (CAPM 的基本假设)

1. **投资者无差异：** 所有投资者都是马克维茨意义上的均值-方差优化者，具有同质期望（Homogeneous Expectations）。
    
2. **无摩擦市场：** 无交易成本、无税收、可以任意拆分资产、可以按 $R_f$ 自由借贷。
    
3. **单一投资期：** 所有投资者只规划相同的一期（例如 1 年）。
    
4. **现实局限（Roll 批判）：** 理论上的“市场组合 $m$”必须包含全球所有风险资产（股票、房地产、艺术品、人力资本等），现实中根本无法构建，因此实证中用的 S&P 500 或沪深 300 只是代理变量。
    

## 6. 推导思路和思想来源

### 困难与转念

- **困难：** 马科维茨投资组合理论推导出，所有人都会选择**无风险资产**与**有效前沿切点组合**构成的“资本市场线（CML）”。但 CML 只适用于**完全分散化的有效组合**，不能给单只股票（非完全分散化）定价。
    
- **关键转念：** 把一只具体的股票 $i$（占比为 $w$）强行掺入市场组合 $m$（占比为 $1-w$），组成一个新的混合组合 $p$。
    

### 推导主线图解

```
【构建混合组合 p】 ──> 【求 p 的收益率与方差】 ──> 【求 w=0 时的边际变化率 (斜率)】 ──> 【在切点处，该斜率必须等于 CML 斜率】 ──> 【整理得到 CAPM】
```

### 极简数学推导动机

1. 混合组合的期望收益与方差：
    
    $$E(R_p) = w E(R_i) + (1-w) E(R_m)$$
    
    $$\sigma_p = \sqrt{w^2 \sigma_i^2 + (1-w)^2 \sigma_m^2 + 2w(1-w)\text{Cov}(R_i, R_m)}$$
    
2. 在均衡状态下，当 $w=0$ 时，混合组合 $p$ 实际上就是市场组合 $m$ 本身。此时，投资者在“收益-风险”切面上的边际增加率（即曲线在 $w=0$ 处的斜率 $\frac{d E(R_p)}{d \sigma_p}$），必须恰好等于市场组合切线的斜率（夏普比率）：
    
    $$\left. \frac{d E(R_p) / dw}{d \sigma_p / dw} \right\vert{}_{w=0} = \frac{E(R_m) - R_f}{\sigma_m}$$
    
3. 对 $w$ 求导并在 $w=0$ 处求值：
    
    - $\left. \frac{d E(R_p)}{dw} \right\vert{}_{w=0} = E(R_i) - E(R_m)$
        
    - $\left. \frac{d \sigma_p}{dw} \right\vert{}_{w=0} = \frac{\text{Cov}(R_i, R_m) - \sigma_m^2}{\sigma_m}$
        
4. 代入均衡条件：
    
    $$\frac{E(R_i) - E(R_m)}{\frac{\text{Cov}(R_i, R_m) - \sigma_m^2}{\sigma_m}} = \frac{E(R_m) - R_f}{\sigma_m}$$
    
5. 交叉相乘、同类项合并移项，两边整理后，即可导出：
    
    $$E(R_i) = R_f + \frac{\text{Cov}(R_i, R_m)}{\sigma_m^2} \Big(E(R_m) - R_f\Big)$$
    
    令 $\beta_i = \frac{\text{Cov}(R_i, R_m)}{\sigma_m^2}$，即得 CAPM 公式！
    

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（套公式与直觉验证）

**题目：**

假设无风险利率 $R_f = 3\%$，市场组合期望收益率 $E(R_m) = 8\%$。

现有股票 A，其 $\beta_A = 1.5$；股票 B，其 $\beta_B = 0.5$。

1. 计算股票 A 和 B 的期望收益率。
    
2. 如果股票 A 的实际市场预期收益率为 $11\%$，这只股票被高估了还是低估了？你该买入还是卖出？
    

**解题思路：**

直接代入 CAPM 公式计算均衡期望收益率，然后将实际收益率与理论收益率进行对比。

**关键步骤：**

1. 市场风险溢价 $E(R_m) - R_f = 8\% - 3\% = 5\%$
    
2. $E(R_A) = 3\% + 1.5 \times (8\% - 3\%) = 3\% + 7.5\% = 10.5\%$
    
3. $E(R_B) = 3\% + 0.5 \times (8\% - 3\%) = 3\% + 2.5\% = 5.5\%$
    
4. 对于股票 A：CAPM 理论要求的合理收益率是 $10.5\%$，而市场实际给到了 $11\%$。说明这只股票给的收益超出了它应有的风险补偿（$\alpha = 11\% - 10.5\% = +0.5\%$）。
    

**最终答案：**

- $E(R_A) = 10.5\%$，$E(R_B) = 5.5\%$。
    
- 股票 A 被**低估**（价格便宜了，导致实际收益率偏高），应该**买入**。
    

**容易错的地方：**

把“收益率偏高”误认为是“价格偏高”。收益率高意味着你用更便宜的价格买到了资产！

> **追问：** 如果无风险利率 $R_f$ 从 $3\%$ 升到 $5\%$，市场组合收益率不变，股票 A 的期望收益率会怎么变？
> 
> _解析：_ $E(R_A) = 5\% + 1.5 \times (8\% - 5\%) = 5\% + 4.5\% = 9.5\%$。收益率下降，因为市场风险溢价被挤压了。

### 例子 2：中等例子（结合协方差与方差求 Beta）

**题目：**

已知市场组合的标准差 $\sigma_m = 20\%$。资产 X 的标准差 $\sigma_X = 30\%$，资产 X 与市场组合的相关系数 $\rho_{X,m} = 0.6$。无风险利率为 $4\%$，市场期望收益率为 $10\%$。

求资产 X 的 $\beta$ 值以及期望收益率。

**解答过程：**

1. **求协方差：**
    
    $$\text{Cov}(R_X, R_m) = \rho_{X,m} \cdot \sigma_X \cdot \sigma_m = 0.6 \times 0.30 \times 0.20 = 0.036$$
    
2. **求市场方差：**
    
    $$\text{Var}(R_m) = \sigma_m^2 = (0.20)^2 = 0.04$$
    
3. **计算 Beta：**
    
    $$\beta_X = \frac{\text{Cov}(R_X, R_m)}{\text{Var}(R_m)} = \frac{0.036}{0.04} = 0.9$$
    
    _(快捷算法：$\beta_X = \rho_{X,m} \cdot \frac{\sigma_X}{\sigma_m} = 0.6 \times \frac{0.30}{0.20} = 0.9$)_
    
4. **计算期望收益率：**
    
    $$E(R_X) = 4\% + 0.9 \times (10\% - 4\%) = 4\% + 5.4\% = 9.4\%$$
    

### 例子 3：实际应用例子（公司理财中 WACC 的计算）

**现实场景：**

某新能源车企准备投资一条新的电池生产线，需要计算该项目的贴现率（WACC）。

- 公司债务资本占比 $40\%$，税前债务成本 $6\%$，所得税率 $25\%$。
    
- 公司股权资本占比 $60\%$。
    
- 市场上无风险收益率（10年期国债）为 $2.5\%$，沪深300指数预期收益率为 $7.5\%$。
    
- 通过回归分析测得该车企股票的 $\beta = 1.4$。
    

**转化过程：**

1. **利用 CAPM 计算股权资本成本 $r_e$：**
    
    $$r_e = R_f + \beta \Big(E(R_m) - R_f\Big) = 2.5\% + 1.4 \times (7.5\% - 2.5\%) = 2.5\% + 7.0\% = 9.5\%$$
    
2. **计算税后债务成本 $r_d$：**
    
    $$r_d = 6\% \times (1 - 25\%) = 4.5\%$$
    
3. **计算加权平均资本成本 WACC：**
    
    $$\text{WACC} = w_e \cdot r_e + w_d \cdot r_d = 60\% \times 9.5\% + 40\% \times 4.5\% = 5.7\% + 1.8\% = 7.5\%$$
    
    **实际价值：** 该新能源车企在评估新电池项目时，项目的内部收益率（IRR）必须**大于 $7.5\%$**，项目才值得投资，否则就会毁灭股东价值。

## 8. 常见误区和易混概念

### 误区 1：股票的总风险（标准差 $\sigma$）越大，CAPM 算出来的期望收益率就越高

- **错误直觉：** “高风险高收益，这只股票波动率 80%，收益率肯定比波动率 20% 的股票高得多！”
    
- **为什么错：** CAPM 认为总风险 $\sigma$ 包含非系统性风险。如果这 80% 的波动是因为公司内部乱七八糟的事情导致的，投资者可以通过分散投资抹平，市场不会为此给一分钱多余的收益。
    
- **正确理解：** 决定收益率的只有**系统性风险 $\beta$**，而不是总标准差 $\sigma$。
    

### 误区 2：$\beta$ 不可能为负数

- **错误直觉：** 资产收益率怎么可能和市场反着走？$\beta$ 最低也就是 0（像国债）。
    
- **为什么错：** 理论上存在与大盘逆向波动的资产（例如黄金或避险看跌衍生品）。
    
- **正确理解：** 当 $\beta < 0$ 时，该资产在市场大跌时反而上涨。根据 CAPM，它的期望收益率会**低于无风险利率**（甚至为负），因为投资者买它相当于买“保险”，愿意为了避险而放弃收益。
    

### 误区 3：混淆资本市场线（CML）与证券市场线（SML）

|**维度**|**资本市场线 (CML)**|**证券市场线 (SML)**|
|---|---|---|
|**横坐标（风险测度）**|**总风险 $\sigma$**（标准差）|**系统性风险 $\beta$**|
|**纵坐标**|期望收益率 $E(R)$|期望收益率 $E(R)$|
|**适用对象**|**仅适用于完全分散化的“有效组合”**|**适用于任何资产**（单只股票、无效组合、有效组合）|
|**截距与斜率**|截距 $R_f$，斜率是夏普比率|截距 $R_f$，斜率是市场风险溢价 $E(R_m)-R_f$|

### 第 1 题（概念辨析）

关于 CAPM 模型中的风险与收益，下列说法正确的是：

A. 资产的期望收益率由其总风险（标准差）决定

B. 如果一个资产的非系统性风险很大，投资者可以要求更高的预期收益率

C. 一个与市场组合协方差为 0 的风险资产，其 CAPM 要求的期望收益率应等于无风险收益率 $R_f$

D. $\beta$ 系数不可能为负数

> [!question]- 答案解析
> 
> **正确答案：C**
> 
> - **解析：** 根据 CAPM， $E(R_i) = R_f + \beta_i(E(R_m)-R_f)$。如果资产与市场组合协方差为 0，则 $\beta_i = 0$，代入公式得 $E(R_i) = R_f$。虽然它有自身波动，但由于可以被完全分散掉，市场只给无风险回报。
>     
> - **最可能做错的原因：** 误以为风险资产收益率必须大于 $R_f$。
>     
> - **对应误区：** 误区 1、误区 2。
>     
> - **Obsidian 标签：** `#自测题/概念辨析`
>     

### 第 2 题（公式运用）

已知无风险利率为 $3\%$，市场组合预期收益率为 $9\%$。某股票的 $\beta = 1.2$，上一年度该股票实际收益率为 $11\%$。根据 CAPM：

1. 该股票的理论期望收益率是多少？
    
2. 该股票的詹森 Alpha（$\alpha$）是多少？这代表该股票被高估还是低估？
    

> [!question]- 答案解析
> 
> **正确答案：**
> 
> 1. $E(R) = 3\% + 1.2 \times (9\% - 3\%) = 3\% + 7.2\% = 10.2\%$
>     
> 2. $\alpha = R_{\text{实际}} - E(R)_{\text{理论}} = 11\% - 10.2\% = +0.8\%$
>     
>     $\alpha > 0$ 说明该股票给出了超越风险补偿的额外收益，价格处于**低估**状态。
>     
> 
> - **最可能做错的原因：** 计算 $\alpha$ 时减反了顺序，或者误将高收益判断为“价格高（高估）”。
>     
> - **Obsidian 标签：** `#自测题/计算题`
>     

### 第 3 题（条件判断）

投资者张三构建了一个组合，该组合由 50% 的股票 A 和 50% 的股票 B 组成。已知该组合位于资本市场线（CML）上。请判断以下结论是否必然成立，并说明理由：

“股票 A 和股票 B 也必然位于资本市场线（CML）上。”

> [!question]- 答案解析
> 
> **正确答案：不成立。**
> 
> - **解析：** 资本市场线（CML）**仅适用于完全分散化的有效组合**（即市场组合与无风险资产的切点组合）。股票 A 和股票 B 作为单只股票，包含非系统性风险，必定位于 CML 线的**下方**。只有当它们组合在一起，且非系统性风险被完全相互抵消，且恰好构成了切点组合时，该组合才能落在 CML 上。但是，单只股票只保证落在证券市场线（SML）上。
>     
> - **最可能做错的原因：** 混淆了 CML 和 SML 的适用对象。
>     
> - **对应误区：** 误区 3。
>     
> - **Obsidian 标签：** `#自测题/条件判断`
>     

### 第 4 题（变式/综合）

假设你的投资组合总资金为 100 万元，资金配置如下：

- 20 万元购买无风险国债 ($R_f = 4\%$)
    
- 50 万元购买股票 X ($\beta_X = 1.5$)
    
- 30 万元购买股票 Y ($\beta_Y = 0.8$)
    

已知市场风险溢价 $E(R_m) - R_f = 6\%$。求：

1. 整个投资组合的 $\beta_p$ 是多少？
    
2. 该投资组合的期望收益率 $E(R_p)$ 是多少？
    

> [!question]- 答案解析
> 
> **正确答案：**
> 
> 1. **计算各资产权重：**
>     
>     $w_{f} = 0.2$, $w_X = 0.5$, $w_Y = 0.3$
>     
>     无风险资产的 $\beta_f = 0$。
>     
>     组合 $\beta_p = w_f \cdot \beta_f + w_X \cdot \beta_X + w_Y \cdot \beta_Y = 0.2 \times 0 + 0.5 \times 1.5 + 0.3 \times 0.8 = 0 + 0.75 + 0.24 = 0.99$
>     
> 2. **计算组合期望收益率：**
>     
>     _方法一（利用组合 $\beta$）：_
>     
>     $E(R_p) = R_f + \beta_p (E(R_m) - R_f) = 4\% + 0.99 \times 6\% = 4\% + 5.94\% = 9.94\%$
>     
>     _方法二（加权平均各资产期望收益率）：_
>     
>     $E(R_X) = 4\% + 1.5 \times 6\% = 13\%$
>     
>     $E(R_Y) = 4\% + 0.8 \times 6\% = 8.8\%$
>     
>     $E(R_p) = 0.2 \times 4\% + 0.5 \times 13\% + 0.3 \times 8.8\% = 0.8\% + 6.5\% + 2.64\% = 9.94\%$
>     
> 
> - **最可能做错的原因：** 忘记无风险资产的 $\beta=0$，或者误将权重算错。
>     
> - **Obsidian 标签：** `#自测题/综合应用`
>     

### 第 5 题（开放/证明）

请从理论上证明：由 $n$ 个资产构成的投资组合，其 Beta 系数等于各单资产 Beta 系数的加权平均值，即：

$$\beta_p = \sum_{i=1}^{n} w_i \beta_i$$

> [!question]- 答案解析
> 
> **证明过程：**
> 
> 1. 根据投资组合收益率公式：$R_p = \sum_{i=1}^{n} w_i R_i$
>     
> 2. 根据组合 Beta 的定义式：
>     
>     $$\beta_p = \frac{\text{Cov}(R_p, R_m)}{\text{Var}(R_m)}$$
>     
> 3. 将 $R_p = \sum_{i=1}^{n} w_i R_i$ 代入协方差展开：
>     
>     $$\text{Cov}(R_p, R_m) = \text{Cov}\left(\sum_{i=1}^{n} w_i R_i, R_m\right)$$
>     
> 4. 利用协方差的线性性质（Linearity of Covariance）：
>     
>     $$\text{Cov}\left(\sum_{i=1}^{n} w_i R_i, R_m\right) = \sum_{i=1}^{n} w_i \text{Cov}(R_i, R_m)$$
>     
> 5. 代回 $\beta_p$ 公式：
>     
>     $$\beta_p = \frac{\sum_{i=1}^{n} w_i \text{Cov}(R_i, R_m)}{\text{Var}(R_m)} = \sum_{i=1}^{n} w_i \left( \frac{\text{Cov}(R_i, R_m)}{\text{Var}(R_m)} \right)$$
>     
> 6. 因为 $\beta_i = \frac{\text{Cov}(R_i, R_m)}{\text{Var}(R_m)}$，故：
>     
>     $$\beta_p = \sum_{i=1}^{n} w_i \beta_i$$
>     
>     **证毕。**
>     
> 
> - **最可能做错的原因：** 不熟悉协方差运算法则的线性叠加性质。
>     
> - **Obsidian 标签：** `#自测题/公式推导`
>
