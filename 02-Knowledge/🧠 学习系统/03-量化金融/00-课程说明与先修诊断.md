## 1. 目标用户与完成结果

本课程面向会使用电脑、但不一定学过金融建模的学习者。真正零基础者先完成下方诊断，再按分流结果补底；不要直接跳入随机微积分或高频交易。

完成必修主线后，学习者应能独立提交以下可检查证据：

1. 定义并验证一份 OHLCV 数据契约，解释复权、交易日历和公告日边界。
2. 写出无前视的策略信号、持仓和收益时间协议，并用失败测试捕获泄漏。
3. 手算并用 Python 复核收益率、波动率、最大回撤、CAPM Beta 和 Alpha。
4. 估计并解释一个波动率模型，区分样本内拟合与样本外预测。
5. 从 Delta 对冲推导 Black–Scholes PDE，并复核欧式期权基准价格。
6. 完成 [[Capstone-统一标的贯穿实战项目]]，提交代码、测试、产物清单和一页研究结论。

## 2. 20 分钟先修诊断

### 作答规则

- 合上其他笔记，限时 20 分钟；每题 1 分，共 16 分。
- 每题作答前记录信心 `0-100%`。答错且信心不低于 80% 时，标记为“高置信误区”，必须进入补救路线。
- 代码题只有实际运行并得到预期输出才得分。

### A. Python 与数据操作（4 分）

1. `Series.pct_change()` 的第一个结果为什么通常是缺失值？
2. 多资产面板做 `shift(1)` 前为什么通常要先按资产分组？
3. 下面代码应输出什么？实际运行验证。

```python
import pandas as pd

prices = pd.Series([100.0, 105.0, 102.9])
returns = prices.pct_change()
assert round(returns.iloc[1], 4) == 0.05
assert round(returns.iloc[2], 4) == -0.02
print(returns.round(4).tolist())
# 输出：[nan, 0.05, -0.02]
```

4. 数据按时间升序排列与按字符串字典序排列，什么时候会给出不同结果？

### B. 数学与统计（4 分）

1. 价格从 100 变为 105，简单收益率是多少？
2. 为什么多期对数收益率可以相加，而多期简单收益率通常不能直接相加？
3. 两项资产的协方差为负，对组合分散化意味着什么？
4. 方差与标准差的量纲有什么区别？报告波动率时通常使用哪一个？

### C. 金融数据与时间协议（4 分）

1. OHLCV 五个字段分别是什么？Volume 为 0 一定是缺失数据吗？
2. 拆股前后直接使用未经一致口径处理的价格计算收益，会制造什么错误？
3. 使用 $t$ 日收盘价生成信号，最早通常在哪个时点假设成交才不偷看？
4. 财报期末日与公告日哪个决定回测中“可获得信息”的时点？

### D. 研究与验证（4 分）

1. 训练集、验证集和测试集各自负责什么？
2. 为什么只报告毛收益、不加入手续费和换手成本不构成可交易证据？
3. 最大回撤衡量什么？它与期末收益率回答的是同一个问题吗？
4. 回测盈利能否证明未来实盘盈利？至少写出两个不能的原因。

> [!success]- 诊断答案与判分锚点
> **A1**：首期没有上一期价格；**A2**：否则会把上一资产末行移到下一资产首行；**A3**：`[nan, 0.05, -0.02]`；**A4**：非 ISO 日期字符串、月份未补零或混合时区时可能不同。  
> **B1**：5%；**B2**：价格比的对数把连乘变为加法；**B3**：在权重合适时可降低组合方差；**B4**：方差是收益率量纲的平方，标准差与收益率同量纲，通常报告标准差。  
> **C1**：开、高、低、收、成交量；Volume 为 0 可能代表真实停牌或无成交，不能直接填充；**C2**：虚假跳跃和虚假损益；**C3**：在预先声明执行规则后使用 $t+1$ 或更晚的可成交价格；**C4**：公告日。  
> **D1**：训练拟合参数、验证选择方案、测试只做最终无偏评估；**D2**：摩擦可能吞噬收益且容量有限；**D3**：峰值到后续谷值的最大损失，不同于终值收益；**D4**：过拟合、前视/幸存者偏差、制度漂移、成本和容量等任写两个。
