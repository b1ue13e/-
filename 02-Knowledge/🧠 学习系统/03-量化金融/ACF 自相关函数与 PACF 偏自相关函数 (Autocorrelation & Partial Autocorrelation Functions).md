# ACF 自相关函数与 PACF 偏自相关函数 (Autocorrelation & Partial Autocorrelation Functions)

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
ACF（自相关函数）与 PACF（偏自相关函数）是平稳时间序列建模的“两把手术刀”。不理解 ACF 与 PACF 的截尾（Cut-off）与拖尾（Tails off）性质，就无法对 ARMA / ARIMA 模型进行定阶（$p, q$ 选择），也无法对高频收益率序列或因子残差进行白噪声（White Noise）诊断。它是金融计量学与时序量化选股的绝对基石。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你正在分析比特币的 5 分钟 K 线收益率序列，想预测下一个 5 分钟的涨跌。
你怀疑“前天的剧烈波动”影响到了“今天”，但你无法确定：**“今天和前天相关，是因为前天直接影响了今天？还是因为前天影响了昨天，而昨天又影响了今天？”**

**以前的方法在哪里卡住：**
普通的皮尔逊相关系数（Pearson Correlation）只能计算两个独立变量之间的相关性。如果直接算 $r(X_t, X_{t-2})$，这种“自相关”混杂了中间中间阶数 $X_{t-1}$ 的间接传导效应，无法识别出真正的纯粹直接因果。

**为什么必须引入 ACF 与 PACF：**
- **ACF**：测量历史所有的“间接 + 直接”总余音；
- **PACF**：通过控制中间所有 $X_{t-1}, X_{t-2}, \dots, X_{t-k+1}$ 的线性影响，剥离出 $X_t$ 与 $X_{t-k}$ 之间**纯粹的直接相关性**。

**它到底解决了哪类问题：**
解决了**金融时间序列记忆长度测量、间接传导与直接效应解耦、以及 ARMA 模型自回归阶数 $p$ 与移动平均阶数 $q$ 的识别定阶**问题。

---

## 2. 为什么它重要？它有什么用？

- **体系与大图景**：时间序列建模（Box-Jenkins 方法论）的第一步诊断工具，承上（收益率风格化事实）启下（ARIMA/GARCH/Var 预测）。
- **量化与实操应用**：
  1. **均值回归策略定阶**：通过 PACF 截尾阶数判断价格偏离历史均值后的**半衰期与最佳回归阶数 $p$**。
  2. **模型残差白噪声检验**：在量化因子回归后，检查残差的 ACF 图形，若 ACF 在所有 Lag $>0$ 显著为 0，说明残差已无未提取的信息（达到 White Noise）。
  3. **高频做市与订单流预测**：检测订单流不平衡（OFI）的自相关持久度。

## 3. 学它之前需要哪些前置知识？

1. **[[收益率序列的风格化事实]]**：理解收益率序列通常无显著一阶自相关（弱有效市场），但收益率平方/绝对值存在强自相关（波动率聚集）。
2. **[[02-Knowledge/🧠 学习系统/03-量化金融/02-量化核心技能/单位根检验]]**：ACF 与 PACF 的计算前提是时间序列满足**平稳性（Stationarity）**。
3. **最小必要背景（自协方差）**：
   $$\gamma_k = Cov(X_t, X_{t-k}) = E[(X_t - \mu)(X_{t-k} - \mu)]$$

## 4. 用直觉语言解释它

### 生活类比：小明打水漂的波纹与声音传导

1. **ACF（自相关函数）就像打水漂的声音**：
   你在湖边丢下一块石头（$X_t$），第 1 秒产生大波纹，第 2 秒水波推着第 1 秒的余波继续扩散，第 3 秒还在响。你在第 3 秒听到的声音（ACF 滞后 3），包含了“第 1 秒直接余波”加上“第 2 秒推过来”的所有声音累积。
2. **PACF（偏自相关函数）就像隔音屏障实验**：
   如果我们用两块隔音板把第 1 秒和第 2 秒的传播路线挡住，只测量第 0 秒那一击**直接穿越空气到达第 3 秒**的声音有多大。这就是 PACF！

«“ACF 测的是历史留下的所有余波总和；PACF 测的是剔除中间中间过程后，历史对现在的纯粹直接冲击。”»

---

## 5. 正式定义、核心公式、符号解释

### 核心定义
- **ACF（自相关系数 $\rho_k$）**：滞后 $k$ 阶的自协方差与方差的比值。
- **PACF（偏自相关系数 $\phi_{kk}$）**：在控制了中间变量 $X_{t-1}, \dots, X_{t-k+1}$ 的线性影响后，$X_t$ 与 $X_{t-k}$ 的条件相关系数。

### 核心公式

#### 1. ACF 公式
$$\rho_k = \frac{\gamma_k}{\gamma_0} = \frac{E[(X_t - \mu)(X_{t-k} - \mu)]}{E[(X_t - \mu)^2]}$$

#### 2. PACF 公式（通过回归系数定义）
在如下多元线性回归方程中，$X_t$ 对其前 $k$ 个滞后项回归：
$$X_t = \phi_{k1} X_{t-1} + \phi_{k2} X_{t-2} + \dots + \phi_{kk} X_{t-k} + \epsilon_t$$
末端斜率系数 $\phi_{kk}$ 即为滞后 $k$ 阶的 **PACF 值**。

#### 3. Yule-Walker 方程（ACF 与 PACF 的联系）
$$\rho_j = \sum_{i=1}^k \phi_{ki} \rho_{j-i}, \quad j = 1, 2, \dots, k$$

### 符号解释表

| 符号 | 含义 | 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\rho_k$ | 滞后 $k$ 阶的 ACF 值 | $[-1, 1]$ 无量纲 | 总线性相关性 |
| $\phi_{kk}$ | 滞后 $k$ 阶的 PACF 值 | $[-1, 1]$ 无量纲 | 条件直接相关性 |
| $\gamma_k$ | 滞后 $k$ 阶自协方差 | 变量方差单位 | $Cov(X_t, X_{t-k})$ |
| $k$ | 滞后阶数 (Lag) | 正整数 | 时间跨度 |

---

## 6. 推导思路和思想来源

### ARMA 模型定阶识别法则 (Box-Jenkins 法则)
为何自回归模型 $AR(p)$ 的 PACF 会截尾，而移动平均模型 $MA(q)$ 的 ACF 会截尾？

1. **对于 $AR(p)$ 模型**：$X_t = \phi_1 X_{t-1} + \dots + \phi_p X_{t-p} + \epsilon_t$
   超出 $p$ 阶后（即 $k > p$），在控制了 $X_{t-1}, \dots, X_{t-p}$ 的情况下，$X_t$ 与 $X_{t-k}$ 再无任何**直接关系**（全部被中间 $p$ 个变量解释），因此 **PACF 在 $p$ 阶后陡峭截尾（Cut-off）**。但 ACF 由于递推迭代会呈现指数或三角函数式**拖尾（Tails off）**。

2. **对于 $MA(q)$ 模型**：$X_t = \epsilon_t + \theta_1 \epsilon_{t-1} + \dots + \theta_q \epsilon_{t-q}$
   冲击 $\epsilon$ 只持续 $q$ 期，超越 $q$ 期后 $X_t$ 与 $X_{t-k}$ 完全共享零个冲击，因此 **ACF 在 $q$ 阶后陡峭截尾**，而 **PACF 呈现拖尾**。

### 定阶规则总结表

| 模型类型 | ACF 图像特征 | PACF 图像特征 |
| :--- | :--- | :--- |
| **$AR(p)$ 模型** | 拖尾 (Tails off) | **在 $p$ 阶后截尾 (Cut-off)** |
| **$MA(q)$ 模型** | **在 $q$ 阶后截尾 (Cut-off)** | 拖尾 (Tails off) |
| **$ARMA(p, q)$ 模型** | 拖尾 | 拖尾 |

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（一阶自回归 $AR(1)$ 的 ACF 推导）

**题目**：
设平稳序列 $X_t = 0.6 X_{t-1} + \epsilon_t$，其中 $\epsilon_t \sim i.i.d.(0, \sigma^2)$。
求该序列的 1 阶、2 阶、3 阶自相关系数 $\rho_1, \rho_2, \rho_3$。

**解答过程**：
1. 两边同乘以 $X_{t-k}$ 并求期望：
   $$E[X_t X_{t-k}] = 0.6 E[X_{t-1} X_{t-k}] + E[\epsilon_t X_{t-k}]$$
2. 化为自协方差递推式：$\gamma_k = 0.6 \gamma_{k-1}$ （当 $k \ge 1$）。
3. 除以 $\gamma_0$ 得到自相关系数递推式：$\rho_k = 0.6 \rho_{k-1}$。
4. 由于 $\rho_0 = 1$：
   - $\rho_1 = 0.6 \times 1 = 0.6$
   - $\rho_2 = 0.6^2 = 0.36$
   - $\rho_3 = 0.6^3 = 0.216$
5. 结论：ACF 呈指数衰减拖尾，极值递减。

---

### 例子 2：中等例题（根据图形判断模型类型与阶数）

**题目**：
量化分析师对某股票对冲配对的价差序列 $S_t$ 进行统计，绘制出如下置信区间（$95\%$ 显著性界限为 $\pm 0.1$）：
- **ACF 值**：Lag 1 = 0.7, Lag 2 = 0.49, Lag 3 = 0.34, Lag 4 = 0.24 (缓缓衰减，均超出界限)
- **PACF 值**：Lag 1 = 0.7 (显著超出界限), Lag 2 = 0.02 (落入界限内), Lag 3 = -0.03 (落入界限内)

请判断该价差序列最适合用什么模型拟合？模型参数阶数是多少？

**解答过程**：
1. 观察 ACF：呈指数衰减（拖尾特征）。
2. 观察 PACF：在 Lag 1 显著超出 0.1，从 Lag 2 开始立刻落入 0 附近置信区间（1 阶后截尾特征）。
3. 根据 Box-Jenkins 定阶法则：PACF 1 阶截尾、ACF 拖尾对应 **$AR(1)$ 模型**。
4. 参数推断：$AR(1)$ 斜率系数 $\phi_1 \approx 0.7$。

---

### 例子 3：实际应用（Python 绘制 ACF/PACF 与配对交易半衰期计算）

```python
import numpy as np
import statsmodels.api as sm
import statsmodels.tsa.stattools as ts

# 假设生成配对交易的均值回归价差序列 Spread
np.random.seed(42)
spread = np.zeros(500)
for t in range(1, 500):
    spread[t] = 0.8 * spread[t-1] + np.random.normal(0, 1)

# 计算 ACF 与 PACF
acf_vals = ts.acf(spread, nlags=10)
pacf_vals = ts.pacf(spread, nlags=10)

# 根据 AR(1) 参数计算半衰期 Half-life
phi_1 = pacf_vals[1]
half_life = -np.log(2) / np.log(phi_1)

print(f"Lag 1 PACF (phi_1): {phi_1:.3f}")
print(f"均值回归半衰期 Half-life: {half_life:.2f} 天")
```

## 8. 常见误区与易混概念

### 误区 1：ACF 值为 0 意味着两个时间点完全独立

错误直觉：“$\rho_k = 0$，说明 $X_t$ 和 $X_{t-k}$ 没有任何关系。”  
为什么错：ACF 只衡量**线性相关性**。如果存在非线性关系（如 $X_t = X_{t-1}^2$），ACF 值可能为 0，但两者高度相关（这正是 GARCH 效应的根源）。  
正确理解：ACF 为 0 仅代表无线性相关性，必须进一步检查平方收益率的 ACF 诊断非线性特征。

### 概念对比：ACF vs PACF

| 维度 | ACF (自相关函数) | PACF (偏自相关函数) |
| :--- | :--- | :--- |
| **物理含义** | 包含所有间接传导的总相关性 | 控制中间项后的纯粹直接相关性 |
| **截尾适用模型** | $MA(q)$ 模型（$q$ 阶后截尾） | $AR(p)$ 模型（$p$ 阶后截尾） |
| **计算复杂度** | 低（直接计算样本协方差） | 较高（需求解多元线性回归/Yule-Walker 方程） |

### 第 2 题：公式运用（基础）
**题目**：已知平稳 $AR(1)$ 过程 $X_t = -0.5 X_{t-1} + \epsilon_t$。求其 Lag 1, Lag 2, Lag 3 的 ACF 值 $\rho_1, \rho_2, \rho_3$。

### 第 5 题：开放/建模（较难）
**题目**：简述对于 $AR(2)$ 模型 $X_t = \phi_1 X_{t-1} + \phi_2 X_{t-2} + \epsilon_t$，如何利用 Yule-Walker 方程组求解 $\rho_1$ 与 $\rho_2$？

> [!question]- 答案解析
