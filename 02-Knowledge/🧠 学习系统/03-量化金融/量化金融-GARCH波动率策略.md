# 量化金融-GARCH波动率策略

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
GARCH 模型（由 Tim Bollerslev 于 1986 年在 Engle 的 ARCH 模型基础上提出）是整个金融波动率建模与风险管理的基石。金融资产收益率普遍存在“大波动后跟随大波动、小波动后跟随小波动”的**波动率聚集（Volatility Clustering）**现象。GARCH(1,1) 是工业界描述时变条件方差（Time-Varying Conditional Variance）最经典、最稳健的标准工具，在 VaR 计算、期权动态对冲、波动率交易策略与风险平价（Risk Parity）中均被广泛使用。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你正在管理一个 10 亿规模的量化对冲基金，需要计算明天的 Value at Risk (VaR，最大可能亏损)。
如果使用传统的历史方差（如滚动 60 天标准差）：
- 当今天市场突发暴跌（如 2008 年雷曼兄弟倒闭或 2020 年熔断），旧模型依然用过去 60 天平缓的平均方差，严重低估了明天的风险（风险失真）。
- 当市场从海啸恢复平静后，旧模型却因为包含了 60 天前的历史暴跌，继续维持极高的估算方差（幽灵效应 Ghost Effect）。

**以前的方法在哪里卡住：**
1. **假设常数方差（Homoskedasticity）**：与真实的金融市场脱节；
2. **ARCH(q) 模型**：为了捕捉长期波动率记忆，需要拟合极高阶数 $q$ 的参数（如 $q=10$），导致参数估计极其不稳定、容易崩溃。

**为什么必须引入 GARCH 模型：**
在方程中同时引入**过去残差平方项 $\epsilon_{t-1}^2$（市场新冲击）** 和 **过去条件方差项 $\sigma_{t-1}^2$（历史波动率记忆）**。仅用 3 个参数的 GARCH(1,1)，就能达到 ARCH(20) 的强大效果！

**它到底解决了哪类问题：**
解决了**金融收益率条件异方差性（时变波动率）的精简自回归建模与前瞻性动态风险预测**问题。

---

## 2. 为什么它重要？它有什么用？

- **体系与大图景**：金融计量学（第二阶段）波动率建模最高峰，承接 ARCH 效应与波动率聚集，衍生出 EGARCH（非对称杠杆效应）与 GARCH-GARCH (多维动态相关 DCC-GARCH)。
- **量化与实操应用**：
  1. **动态 VaR 计算 (GARCH-VaR)**：将预测的条件标准差 $\sigma_{t+1}$ 代入高斯/t分布分位数，动态计算逐日风险敞口。
  2. **波动率择时与动态杠杆**：在 GARCH 预测明日波动率上升时，量化算法自动降低策略资金杠杆，实现控制下行回撤。
  3. **期权定价与波动率交易**：在几何布朗运动的常数波动率假设失效时，用 GARCH 模拟资产路径进行蒙特卡洛期权定价。

## 3. 学它之前需要哪些前置知识？

1. **[[波动率聚集]]**：理解收益率序列绝对值或平方呈现强自相关性。
2. **[[ARCH效应]]**：理解残差平方对历史残差平方的回归模型（Engle 1982）。
3. **最小必要背景（条件方差 vs 无条件方差）**：
   > - **条件方差 $\sigma_t^2 = Var(r_t \mid \mathcal{F}_{t-1})$**：已知截至 $t-1$ 期所有历史信息时，对 $t$ 期方差的预判（随着每天新消息发布而动态更新）。
   > - **无条件方差 $\overline{\sigma}^2 = Var(r_t)$**：全样本长期固定不变的边际方差。

## 4. 用直觉语言解释它

### 生活类比：天气预报里的“今日气温不确定性”

假设你在预测明天的气温波动（方差）：
- **旧方法（常数方差）**：不管今天是晴天还是台风，一律预测明天气温上下浮动 5 度。
- **ARCH 方法**：如果今天下了暴雨（产生了新冲击 $\epsilon_{t-1}^2$），预测明天气温浮动加大到 10 度。
- **GARCH(1,1) 方法**：明天的气温浮动，既看今天有没有突发暴雨（$\epsilon_{t-1}^2$），也看**这整个星期是不是本身就处于极端气候季（$\sigma_{t-1}^2$）**！如果上周气温就一直剧烈跳动，即使今天平静了一天，明天的预估波动依然很大。

**GARCH 的直觉本质**：
把明天的方差，写成“长期基础方差 + 昨天市场新冲击 + 过去波动惯性”的加权平均。

«“GARCH(1,1) 就是用‘昨天的突发消息’和‘昨天的历史波动惯性’共同预测明天的市场风险。”»

## 5. 正式定义、核心公式、符号解释

### 核心定义
**GARCH(p, q) 模型**：假定资产收益率序列的残差 $\epsilon_t = \sigma_t z_t$（其中 $z_t \sim i.i.d. N(0, 1)$），其条件方差 $\sigma_t^2$ 服从关于过去 $q$ 阶残差平方和 $p$ 阶历史条件方差的自回归过程。

### 核心公式

#### 1. GARCH(1, 1) 经典条件方差方程
$$\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2$$

其中约束条件：$\omega > 0, \; \alpha \ge 0, \; \beta \ge 0, \; \alpha + \beta < 1$。

#### 2. 无条件方差 (Unconditional Variance / 长期均值回归方差)
$$\overline{\sigma}^2 = E[\sigma_t^2] = \frac{\omega}{1 - \alpha - \beta}$$

#### 3. 另一种等价表达（长期均值回归重构）
$$\sigma_t^2 = (1 - \alpha - \beta) \overline{\sigma}^2 + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2$$

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 约束与物理意义 |
| :--- | :--- | :--- | :--- |
| $\sigma_t^2$ | $t$ 期的条件方差 (Conditional Variance) | 收益率平方 | 当前最新的估计风险 |
| $\omega$ | 基础常数项 | 收益率平方 | $\omega = (1 - \alpha - \beta) \overline{\sigma}^2 > 0$ |
| $\epsilon_{t-1}^2$ | $t-1$ 期的残差平方（ARCH 项） | 收益率平方 | 代表**昨日市场的新冲击/新信息 (New Information)** |
| $\sigma_{t-1}^2$ | $t-1$ 期的条件方差（GARCH 项） | 收益率平方 | 代表**过去波动率的持久度/记忆 (Persistence)** |
| $\alpha$ | ARCH 项系数 | 标量 $[0, 1)$ | 反映市场对新消息反应的敏感度 |
| $\beta$ | GARCH 项系数 | 标量 $[0, 1)$ | 反映波动率记忆衰减的慢程度 |
| $\alpha + \beta$ | **波动率持久度系数 (Persistence)** | 标量 $[0, 1)$ | 越接近 1，说明冲击衰减越慢，聚集效应越强 |

---

## 6. 推导思路和思想来源

### 为何 GARCH(1,1) 比高阶 ARCH(q) 更强大？
1. **ARCH(q) 的局限**：$\sigma_t^2 = \omega + \sum_{i=1}^q \alpha_i \epsilon_{t-i}^2$。如果波动率记忆长达一个月，需要估计 20 个参数 $\alpha_1, \dots, \alpha_{20}$，极易出现估计值负数或过拟合。
2. **转念（无穷级数求和与 ARMA 思想）**：
   类比时间序列中 $AR(1)$ 可以表达成无限阶 $MA(\infty)$，Bollerslev 引入了 $\sigma_{t-1}^2$ 递推项。
   递归展开：$\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta (\omega + \alpha \epsilon_{t-2}^2 + \beta \sigma_{t-2}^2) = \dots$
   这相当于用极其精简的 3 个参数（$\omega, \alpha, \beta$），实现了对历史无限多期残差平方 $\epsilon_{t-k}^2$ 按照指数衰减赋予权重的效果！

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（GARCH(1,1) 明日波动率预测）

**题目**：
已知某股票指数收益率的 GARCH(1,1) 模型估计参数如下：
$$\omega = 0.000002, \quad \alpha = 0.08, \quad \beta = 0.90$$
假设今天（$t$ 期）收盘后，计算得到今天的条件标准差 $\sigma_t = 1.5\%$（即 $\sigma_t^2 = 0.000225$），且今天的实际残差 $\epsilon_t = +3.0\%$（即 $\epsilon_t^2 = 0.0009$）。
1. 计算明日（$t+1$ 期）预测的条件方差 $\sigma_{t+1}^2$ 与条件标准差 $\sigma_{t+1}$。
2. 计算该指数的长期无条件年化波动率（假设一年 252 天）。

**解答过程**：
1. 计算明日条件方差 $\sigma_{t+1}^2$：
   $$\sigma_{t+1}^2 = \omega + \alpha \epsilon_t^2 + \beta \sigma_t^2$$
   $$\sigma_{t+1}^2 = 0.000002 + 0.08 \times (0.0009) + 0.90 \times (0.000225)$$
   $$\sigma_{t+1}^2 = 0.000002 + 0.000072 + 0.0002025 = 0.0002765$$
2. 开方求明日条件标准差 $\sigma_{t+1}$：
   $$\sigma_{t+1} = \sqrt{0.0002765} \approx 0.016628 \quad (1.66\%)$$
   （因为今天出现了 3% 的较大冲击，预测明日波动率从 1.5% 升至 1.66%）。
3. 计算长期无条件日方差 $\overline{\sigma}^2$：
   $$\overline{\sigma}^2 = \frac{\omega}{1 - \alpha - \beta} = \frac{0.000002}{1 - 0.08 - 0.90} = \frac{0.000002}{0.02} = 0.0001$$
   长期无条件日标准差 $= \sqrt{0.0001} = 1.0\%$。
   长期年化波动率 $= 1.0\% \times \sqrt{252} \approx 15.87\%$。

---

### 例子 2：中等例题（波动率持久度与半衰期 calculation）

**题目**：
在上一题中，持久度系数 $\alpha + \beta = 0.08 + 0.90 = 0.98$。
当发生一次突发重大冲击后，此冲击对条件方差的偏离衰减到一半所需要的天数（半衰期 Half-life）是多少天？（已知 $\ln(0.5) \approx -0.693, \ln(0.98) \approx -0.0202$）

**解答过程**：
1. 方差偏离的衰减公式：$(\alpha + \beta)^k = 0.5$
2. 两边取对数：$k \cdot \ln(\alpha + \beta) = \ln(0.5)$
3. 计算天数 $k$：
   $$k = \frac{\ln(0.5)}{\ln(\alpha + \beta)} = \frac{-0.693}{-0.0202} \approx 34.3 \text{ 天}$$
4. **结论**：由于 $\alpha+\beta=0.98$ 极接近 1，此冲击的影响在市场上需要经历约 34 个交易日才能衰减一半（展现出强烈的波动率持久记忆）。

### 例子 3：实际应用（Python arch 库估计 GARCH(1,1) 与动态 95% VaR 计算）

```python
import numpy as np
import pandas as pd
from arch import arch_model

# 模拟 1000 天的对数收益率
np.random.seed(42)
returns = np.random.normal(0.0002, 0.012, 1000)

# 拟合 GARCH(1,1) 模型
am = arch_model(returns, vol='Garch', p=1, q=1, mean='Zero')
res = am.fit(disp='off')

# 预测未来 1 天的条件方差
forecasts = res.forecast(horizon=1)
pred_var = forecasts.variance.iloc[-1, 0]
pred_vol = np.sqrt(pred_var)

# 计算 95% 置信度下的 1 日 GARCH-VaR (假设正态分布 z=1.645)
var_95 = 1.645 * pred_vol
print(f"预测明日条件波动率: {pred_vol*100:.2f}%")
print(f"明日 95% 置信度 1 日 VaR: {var_95*100:.2f}%")
```

## 8. 常见误区与易混概念

### 误区 1：若 $\alpha + \beta \ge 1$，GARCH 模型依然平稳

错误直觉：“估计出来的系数加起来大于 1，说明模型对记忆更敏感，更有效。”  
为什么错：当 $\alpha + \beta \ge 1$ 时，分母 $1 - \alpha - \beta \le 0$，长期无条件方差变得不存在或为负数（变成非平稳的 IGARCH 过程），方差会随时间爆炸。  
正确理解：**对于平稳 GARCH(1,1)，必须严格满足 $\alpha + \beta < 1$。**

### 概念对比：ARCH(q) vs GARCH(p,q) vs EGARCH

| 维度 | ARCH(q) 模型 | GARCH(1,1) 模型 | EGARCH (指数 GARCH) |
| :--- | :--- | :--- | :--- |
| **自回归项** | 仅包含过去 $q$ 阶残差平方 | 包含过去 1 阶残差平方和 1 阶条件方差 | 对 $\ln(\sigma_t^2)$ 建模 |
| **参数效率** | 极低（需较多参数） | 极高（3个参数拟合全貌） | 高 |
| **利好/利空非对称性** | 无法刻画（平方抹平正负符号） | 无法刻画（平方抹平正负符号） | **可刻画（捕捉坏消息比好消息引发更大波动）** |

**题目**：在 GARCH(1,1) 方程 $\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2$ 中，$\epsilon_{t-1}^2$ 代表什么？

> [!question]- 答案解析
> **答案**：代表前一期的残差平方，即上一期市场发生的非预期新冲击/新信息（New Information Impact）。

### 第 2 题：公式运用（基础）
**题目**：已知 $\omega = 0.00001, \alpha = 0.1, \beta = 0.8$。若无条件方差等于 $\frac{\omega}{1 - \alpha - \beta}$，求该序列的无条件日标准差。

> [!question]- 答案解析
> **答案**：
> 1. $\overline{\sigma}^2 = \frac{0.00001}{1 - 0.1 - 0.8} = \frac{0.00001}{0.1} = 0.0001$。
> 2. 无条件日标准差 $\overline{\sigma} = \sqrt{0.0001} = 0.01 = 1.0\%$。

### 第 3 题：条件判断（中等）
**题目**：判断：“若对某股票估计得到的 GARCH(1,1) 参数中 $\alpha = 0.15, \beta = 0.90$，说明该资产的价格序列是平稳的。”

> [!question]- 答案解析
> **答案**：错误。因为 $\alpha + \beta = 0.15 + 0.90 = 1.05 \ge 1.0$，违反了平稳 GARCH 过程的 $\alpha + \beta < 1$ 条件。此时无条件方差发散为负数或无穷，说明模型非平稳（即存在方差爆炸/集成异方差特点）。  
> **Obsidian 标签**：`#自测题/GARCH平稳性`

### 第 4 题：变式/综合（中等）
**题目**：已知明日预估的 GARCH 日条件标准差为 $2.0\%$，持仓金额 1000 万元。在正态分布假设下（99% 置信度 $Z_{0.99} = 2.33$），求明日该组合的 1 日 99% VaR 风险暴露。

> [!question]- 答案解析
> **答案**：
> 1. $VaR_{pct} = 2.33 \times 2.0\% = 4.66\%$。
> 2. $VaR_{amount} = 1000 \text{ 万元} \times 4.66\% = 46.6 \text{ 万元}$。  
> **Obsidian 标签**：`#自测题/GARCH-VaR`

### 第 5 题：开放/建模（较难）
**题目**：为什么标准的 GARCH(1,1) 模型无法刻画股票市场中的“杠杆效应 (Leverage Effect)”，而必须使用 EGARCH 或 GJR-GARCH？

> [!question]- 答案解析
> **解析**：
> 1. **标准 GARCH 的局限**：在 $\sigma_t^2 = \omega + \alpha \epsilon_{t-1}^2 + \beta \sigma_{t-1}^2$ 中，残差是平方形式 $\epsilon_{t-1}^2$。无论上一期是大幅大涨（$\epsilon_{t-1} = +5\%$）还是暴跌（$\epsilon_{t-1} = -5\%$），平方后均得到相同的 $0.0025$，对明日条件方差的贡献完全对称。
> 2. **真实金融反应（杠杆效应）**：在股票市场中，负面消息（股价下跌）会导致公司资产负债率（财务杠杆）上升，从而引发比等量正面消息更大的市场恐慌与未来波动。
> 3. **EGARCH 改进**：在条件方差方程中加入对残差正负符号的非对称响应项（$\gamma \frac{\epsilon_{t-1}}{\sigma_{t-1}}$），当 $\epsilon_{t-1} < 0$ 时产生额外的波动率提升。  
> **Obsidian 标签**：`#自测题/EGARCH杠杆效应`

## 可定位依据与失效复核

本卡的复核对象是 **GARCH 广义自回归条件异方差模型 (Generalized Autoregressive Conditional Heteroskedasticity)**，而不是只复述一个公式。对 **GARCH 广义自回归条件异方差模型 (Generalized Autoregressive Conditional Heteroskedasticity)** 的独立验证重点是：对标准化残差再次做 Ljung–Box 与 ARCH-LM，并比较正态和厚尾创新分布。

### 权威来源与定位

1. Bollerslev (1986), *Generalized Autoregressive Conditional Heteroskedasticity*, DOI: 10.1016/0304-4076(86)90063-1。用于复核“对标准化残差再次做 Ljung–Box 与 ARCH-LM，并比较正态和厚尾创新分布”。
2. Nelson (1991), *Conditional Heteroskedasticity in Asset Returns: A New Approach*, DOI: 10.2307/2938260。用于复核“对标准化残差再次做 Ljung–Box 与 ARCH-LM，并比较正态和厚尾创新分布”。
3. Kevin Sheppard 的 `arch` 官方波动率建模文档：https://arch.readthedocs.io/en/latest/univariate/univariate_volatility_modeling.html；参见 Chapter 1 示例。用于复核“对标准化残差再次做 Ljung–Box 与 ARCH-LM，并比较正态和厚尾创新分布”。

### 失效边界与验收协议

- **成立条件**：先写清数据时点、估计窗口、交易摩擦和分布/市场结构假设，再运行模型。
- **反例压力测试**：对标准化残差再次做 Ljung–Box 与 ARCH-LM，并比较正态和厚尾创新分布。
- **最小实验**：固定随机种子或冻结原始数据快照，同时保存基线、破坏条件后的对照组、关键中间量与失败日志。
- **通过标准**：结论必须在样本外仍保持方向一致；若成本、延迟、参数扰动或结构突变使结论反转，就把该情形登记为适用边界而不是删除失败结果。
