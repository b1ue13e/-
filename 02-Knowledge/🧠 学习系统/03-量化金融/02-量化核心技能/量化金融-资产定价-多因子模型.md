# 多因子模型：从暴露到截面回归

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类核心概念，必须深挖**
- **判断理由**：多因子模型是现代量化投资的绝对基石。它连接了资产定价理论（如APT）与实际选股策略，是所有多因子量化框架（如Barra风险模型）的核心底座。若不理解背后的数学推导与截面回归逻辑，就无法排查因子回测中的共线性与特质风险问题，属于必须闭卷彻底掌握的硬核知识。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 在 CAPM（单因子模型）中，我们假设资产的超额收益仅由市场风险溢价（Beta）决定。但在实际投资中我们常常发现，小盘股、价值股、动量股能产生持续的、无法被单一市场Beta解释的超额收益（Alpha）。如果我们仅依赖市场因子，一是无法准确预测股票的预期收益率，二是无法精准刻画组合在各种特定风格下的风险暴露，导致量化策略在特定市场风格切换时遭遇“腰斩”级别的无法解释的回撤。我们需要一个能将收益与风险拆解到多个维度的数学框架。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是整个“03-量化金融”投资体系的骨架。向下兼容 CAPM，向上支撑 Fama-French 多因子模型与现代工业级的 Barra 风险模型。
- **实际应用场景**：广泛用于股票预期收益预测（Alpha模型构建）、投资组合风险控制与约束（Risk模型）、以及投资经理的绩效归因（Performance Attribution）。
- **高频题型/任务**：截面回归计算因子收益率、因子组合的中性化处理、因子共线性的正交化。

## 4. 用直觉语言解释它

> «“这东西其实就像预测一道菜的卡路里。”»

- **直觉类比/几何图像**：CAPM模型就像是只看“菜的重量”（市场大盘），这显然不准确；而多因子模型则是把菜拆解为碳水化合物、脂肪、蛋白质（不同维度因子）的含量（因子暴露度/载荷），并乘以每种营养素的单位热量（因子收益率）。
- **为什么很自然**：任何复杂的资产都可以拆解为其内在的各项基础风险特征的总和。
- **一句话直觉本质**：用多个维度的风险暴露（我承担了多少该因子的风险）乘以对应的风险溢价（市场给该风险多少补偿），通过线性组合来解释和预测资产的总收益率。

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
多因子模型假设资产 $i$ 的收益率可以由 $K$ 个系统性因子的线性组合及特质风险解释。

### 2. 核心公式
截面回归的单资产表达：
$$R_i = \alpha_i + \sum_{k=1}^K \beta_{i,k} f_k + \epsilon_i$$

矩阵表达（全市场截面）：
$$\mathbf{R} = \mathbf{B} \mathbf{f} + \mathbf{\epsilon}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $R_i$ / $\mathbf{R}$ | 超额收益率 | 实数 | 标的在某周期的实际涨幅 |
| $\alpha_i$ | 特质Alpha | 实数 | 无法被已知因子解释的超额收益 |
| $\beta_{i,k}$ / $\mathbf{B}$ | 因子暴露度 (Exposure) | 实数 | 资产 $i$ 在因子 $k$ 上的敏感度或标准化属性 / $N \times K$ 矩阵 |
| $f_k$ / $\mathbf{f}$ | 因子收益率 (Factor Return) | 实数 | 承担单位该因子风险所获得的收益 / $K \times 1$ 向量 |
| $\epsilon_i$ / $\mathbf{\epsilon}$ | 特质风险 (Idiosyncratic) | 实数 | 满足 $E(\epsilon_i)=0, Cov(\epsilon_i, f_k)=0$ |

### 4. 常见变体与适用条件
- **适用条件**：因子暴露度矩阵 $\mathbf{B}$ 满秩，没有严重的共线性。
- **限制条件**：因子之间可能存在相关性，工程上常需要通过施密特正交化或对称正交化处理。

---

## 6. 推导思路和思想来源

- **最初困难**：单因子无法解释截面收益差异，比如小市值股票长期跑赢大市值。
- **直接方法局限**：单纯增加解释变量如果缺乏经济学支撑，会导致严重的过拟合。
- **关键“转念”**：套利定价理论 (APT) 的无套利假设。
- **推导主线与动机**：
  1. 假设资产收益由 $K$ 个系统因素驱动：$R_i = E(R_i) + \sum_{k=1}^K \beta_{i,k} F_k + \epsilon_i$。
  2. 构建资金权重向量 $\mathbf{w}$ 使得 $\sum w_i = 0$ (零成本), $\sum w_i \beta_{i,k} = 0$ (零系统风险), $\sum w_i \epsilon_i \approx 0$ (充分分散)。
  3. 根据无套利均衡，此组合预期收益必为0：$\sum w_i E(R_i) = 0$。
  4. 依据线性代数定理：若向量 $\mathbf{w}$ 垂直于向量 $\mathbf{1}$ 和 $\mathbf{\beta}_k$，且 $\mathbf{w}$ 也垂直于 $E(\mathbf{R})$，那么 $E(\mathbf{R})$ 必能由 $\mathbf{1}$ 和 $\mathbf{\beta}_k$ 线性表出，推导出 $E(R_i) = \lambda_0 + \sum \beta_{i,k} \lambda_k$。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（手工推算）
- **题目**：无风险利率为 2%。某股票在规模因子暴露为 1.2，溢价为 3%；价值因子暴露为 -0.5，溢价为 4%。求预期收益。
- **解题思路与关键步骤**：
  预期超额收益 = $1.2 \times 3\% + (-0.5) \times 4\% = 3.6\% - 2.0\% = 1.6\%$。
- **最终答案**：预期总收益 = $2\% + 1.6\% = 3.6\%$。

### 例子 2：中等例子（截面回归求解因子收益）
- **题目与完整解答**：已知全市场 3000 只股票在月末的市值、动量暴露度矩阵 $\mathbf{B}_{3000 \times 2}$，并在下月末观测到了实际收益率 $\mathbf{R}_{3000 \times 1}$。如何计算这两个因子的实际收益率 $\mathbf{f}$？
- **解答**：利用最小二乘法 (OLS) 求解矩阵方程 $\mathbf{R} = \mathbf{B} \mathbf{f} + \mathbf{\epsilon}$。
  $\hat{\mathbf{f}} = (\mathbf{B}^T \mathbf{B})^{-1} \mathbf{B}^T \mathbf{R}$，求得的向量 $\hat{\mathbf{f}}$ 即为截面因子收益率。

### 例子 3：实际应用例子（量化组合中性化）
- **实际价值与转化**：
  在 Barra 风险模型中，如果挖掘到一个新的 Alpha 因子，但发现它在“小市值”上有很大的负暴露，导致组合在熊市中遭遇剧烈回撤。
  操作：在组合优化器中，加入约束 $\mathbf{B}_{port, 市值} = \mathbf{w}^T \mathbf{\beta}_{市值} = 0$。这样构建出的投资组合剥离了市值因子的波动，获取的才是纯粹的正交 Alpha。

## 8. 常见误区和易混概念

### 误区 1：混淆因子暴露度（Beta）和因子收益率（Factor Return）
- **错误直觉**：认为暴露度高，下个月收益一定高。
- **为什么错**：暴露度（如市盈率倒数）在月初是已知的，是股票的属性。因子收益率是月末才观测到的市场奖惩。如果当月该因子溢价为负，高暴露度反而会导致大亏。
- **正确理解**：预测收益 = 暴露度 (已知) $\times$ 因子收益率的期望预估。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| **OLS 回归** | 特质残差方差一致 | 直接最小化残差平方和 | 理论推导或粗略计算 |
| **WLS 回归 (加权)**| 特质残差异方差 | 使用市值的平方根或残差方差倒数作为权重进行惩罚 | 工业界（如 Barra 模型）计算因子收益率的标准做法，更高效(BLUE) |

### 题目与解析

#### 1. 多因子模型中的 $\beta_{i,k}$ 代表什么？它和 CAPM 里的 Beta 是一回事吗？
> [!question]- 答案解析
> - **答案**：代表资产 $i$ 对第 $k$ 个因子的风险暴露度（Factor Loading）。
> - **解析**：它是广义的，CAPM 里的 Beta 仅仅是针对“市场组合”这单一因子的特例暴露度。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 已知股票 A 在市值因子暴露为 1.5，溢价为 -2%；在价值因子暴露为 0.8，溢价为 5%。无风险利率为 2%，求预期收益率。
> [!question]- 答案解析
> - **答案**：3%。
> - **解析**：超额收益 = $1.5 \times (-2\%) + 0.8 \times 5\% = 1\%$。预期总收益 = $2\% + 1\% = 3\%$。

#### 3. 在估计截面因子收益率时，为什么要经常使用加权最小二乘法 (WLS) 而不是 OLS？
> [!question]- 答案解析
> - **答案**：因为股票的特质风险具有异方差性。
> - **解析**：市值大的股票波动率通常较小，用市值的平方根等作为权重进行 WLS 回归，可以给予大盘股更高的信赖度，得到更高效的估计。

#### 4. 什么是因子组合中性化（Neutralization）？
> [!question]- 答案解析
> - **答案**：将组合在特定风险因子（如行业、市值）上的总暴露度限制为 0 或与基准一致。
> - **解析**：目的是消除不希望承担的系统性风格风险，只赚取纯粹的正交选股收益。

#### 5. 简述如何利用零成本组合，从 APT 推导得到多因子的预期收益线性表达式。
> [!question]- 答案解析
> - **答案**：构造 $\sum w_i=0$ 且 $\sum w_i\beta_{ik}=0$ 的分散组合，根据无套利假定其预期收益必为0，由线性代数正交性定理得出结论。

## 可定位依据与失效复核

本卡的复核对象是 **多因子模型：从暴露到截面回归**，而不是只复述一个公式。对 **多因子模型：从暴露到截面回归** 的独立验证重点是：逐日检查暴露矩阵条件数、行业中性和因子收益标准误，避免共线性伪造显著性。

2. Kenneth French Data Library（因子定义与可复现数据）。

### 失效边界与验收协议

- **成立条件**：先写清数据时点、估计窗口、交易摩擦和分布/市场结构假设，再运行模型。
- **反例压力测试**：逐日检查暴露矩阵条件数、行业中性和因子收益标准误，避免共线性伪造显著性。
- **最小实验**：固定随机种子或冻结原始数据快照，同时保存基线、破坏条件后的对照组、关键中间量与失败日志。
- **通过标准**：结论必须在样本外仍保持方向一致；若成本、延迟、参数扰动或结构突变使结论反转，就把该情形登记为适用边界而不是删除失败结果。

### 最小可运行反例/性质测试

```python
import numpy as np

X = np.array([[1.0, -1.0], [0.5, 0.2], [-0.4, 1.1], [1.2, 0.7]])
true_factor_return = np.array([0.03, -0.01])
y = X @ true_factor_return
estimated = np.linalg.lstsq(X, y, rcond=None)[0]
assert np.allclose(estimated, true_factor_return)
print(estimated)
```
