# 回测框架与无泄漏实验

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：量化研究的"手术室消毒规程"——回测不可信，则一切因子/模型结论作废；Qlib（HW17）的核心价值就是无泄漏实验框架。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：策略在历史上"看起来赚钱"很容易——只要不小心用了未来数据（幸存者偏差、前视偏差、点在前沿）、没扣成本、或参数是在全样本上调出来的。需要一套**防作弊的验收规程**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：无泄漏实验是"因子研究→策略→实盘"之间的质检关卡，Qlib 的 data handler/backtester 设计正是为此。
- **实际应用场景**：任何策略上线前的必经流程；因子报告的可信度。
- **高频题型/任务**：列举泄漏源（幸存者偏差/前视偏差/点在前面/过拟合）；解释"训练-验证-测试"时间切分；成本敏感性分析。

**量化回测的极简四步骨架**
真正的量化系统其实就是四个闭环步骤（如 `quant-for-beginners` 项目所示）：
1. **获取数据 (Data)**：股票价格、成交量、财务数据。这是燃料，没有数据就没有量化。
2. **分析数据 (Analysis)**：找规律。发现波动、趋势。
3. **设计策略 (Strategy)**：把规律变成规则。比如 `5日均线 > 20日均线` 就买入。
4. **回测验证 (Backtesting)**：用历史数据模拟撮合，测算真实的收益和回撤。**一个策略看起来有效，不代表真的有效，必须被历史验证，且不能偷看未来。**

## 4. 用直觉语言解释它

> «"回测是'体检'，无泄漏是'不能提前看答案'：体检单上的每一项都必须只用当时已知的信息填写。"»

- **直觉类比/几何图像**：禁止"点在前沿"（peeking ahead）= 考试时不能翻到后面的答案页。
- **为什么很自然**：实盘只能看到"当时"的数据，回测必须模拟同样的信息约束。
- **一句话直觉本质**：**无泄漏回测 = 每个决策点只用当时可得信息 + 全成本 + 样本外验证。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

**前视偏差（look-ahead）**：使用了 $t$ 时刻尚不可得的 $t+1$ 后信息。**幸存者偏差**：样本只含当前存续标的（退市股被剔除）。**点在前沿（peeking）**：用全样本调参后再"回测"。

### 2. 核心公式

策略收益（含成本）：$R_p=\sum_t w_t^\top R_{t+1}-\text{cost}_t$，其中 $w_t$ 必须由 $\le t$ 的信息决定；信息系数 IC = $\text{corr}(\text{signal}_t, R_{t+1})$（signal 用 $t$ 时刻因子值）。

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $w_t$ | $t$ 日收盘决定权重 | 用 $t$ 及以前数据 |
| $R_{t+1}$ | 次日收益 | 标签 |
| IC | 因子与未来收益相关 | 分层检验 |
| cost | 佣金+冲击+滑点 | 必须计入 |

### 4. 常见变体与适用条件

- **适用条件**：日频调仓用"收盘信号→次日开盘/收盘成交"；因子研究用分层回测（IC、多空收益）。
- **限制条件**：回测过拟合（多次尝试后最优参数）；市场状态变化（回测期不代表未来）——需要样本外/滚动验证。

---

## 6. 推导思路和思想来源

- **最初困难**：策略评估本质是"反事实"——无法重来。
- **直接方法局限**：朴素净值曲线易被各种偏差污染。
- **关键"转念"**：把回测视为**科学实验**：明确信息集（$\mathcal{F}_t$）、时间对齐、成本模型、样本外协议——Qlib 把"数据处理器（防泄漏特征）→模型→回测器→分析"固化进框架。
- **推导主线与动机**：IC/分层收益验证因子单调性 → 组合优化 → 成本敏感回测 → 风险归因；每一步都有明确的时间对齐约束。
- **为什么自然得到此结论**：金融数据的时序性决定"信息集约束"是唯一正确的实验设计。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：用"当日收盘后的因子值"在"当日开盘"成交，是什么偏差？
- **解题思路**：因子在开盘后才知道（收盘数据），开盘价成交用了未来信息。
- **最终答案**：前视偏差（look-ahead）——应次日开盘/收盘成交。
- **易错点**：时间戳对齐（"当日"边界）。
- **🤔 追问**：用"月末调整后的市值"算市值因子？（下月用，合法；当月用=前视）

### 例子 2：中等例子（条件判断与多步推理）

- **题目**：为什么"在全历史上选最优参数"不可信？
- **完整解答**：这是点在前沿——参数被未来数据优化，回测净值虚高；正确做法：训练段调参 → 验证段选模型 → 测试段只跑一次（或滚动 walk-forward）。

### 例子 3：实际应用例子（真实场景/代码）

- **实际价值与转化**：Qlib：`DataHandler` 保证特征只用历史、`Backtest` 带成本模型、`RiskAnalysis` 输出 IR/最大回撤；生产协议：walk-forward + 成本敏感 + 每因子独立 IC 报告。

## 8. 常见误区和易混概念

### 误区 1："回测年化 50% 就是好策略"
- **错误直觉**：高收益即有效。
- **为什么错**：未扣成本、样本内过拟合、幸存者偏差都可制造虚高收益。
- **正确理解**：看样本外、扣成本后、多市场期的稳健性。

### 概念对比表

| 偏差 | 本质 | 防法 |
| :--- | :--- | :--- |
| 前视偏差 | 用未来信息 | 时间对齐 |
| 幸存者偏差 | 样本截断 | 含退市股 |
| 点在前沿 | 全样本调参 | 三段切分 |
| 过拟合 | 参数过多 | 样本外验证 |

### 题目与解析

#### 1. 幸存者偏差是什么？
> [!question]- 答案解析
> - **答案**：样本只含存活标的，退市股被剔除，收益虚高。
> - **解析**：样本截断。
> - **易错原因**：与前视混淆。

#### 2. IC 度量什么？
> [!question]- 答案解析
> - **答案**：因子值与未来收益的截面相关。
> - **解析**：预测力。
> - **易错原因**：用同期收益。

#### 3. "收盘信号当日成交"属于？
> [!question]- 答案解析
> - **答案**：前视偏差。
> - **解析**：收盘后信号无法当日成交。
> - **易错原因**：以为无问题。

#### 4. 参数选择为什么不能在测试段做？
> [!question]- 答案解析
> - **答案**：测试段应只评估一次，否则点在前沿。
> - **解析**：三段切分。
> - **易错原因**：反复试参。

#### 5. 成本模型包含哪些？
> [!question]- 答案解析
> - **答案**：佣金、买卖价差、冲击成本（按成交量比例）。
> - **解析**：高频策略成本敏感。
> - **易错原因**：只扣佣金。
