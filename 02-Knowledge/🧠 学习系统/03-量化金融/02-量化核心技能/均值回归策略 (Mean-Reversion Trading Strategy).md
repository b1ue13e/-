# 均值回归策略 (Mean-Reversion Trading Strategy)

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
均值回归（Mean Reversion）是量化金融两大核心交易哲学（均值回归 vs 趋势跟踪）之一。物理学家与统计学家发现，绝大多数资产的价格偏离（如 Bollinger Bands 布林带偏离、价差偏离、网格交易）都遵循 Ornstein-Uhlenbeck (OU) 随机过程。在量化对冲基金中，无论是高频做市、配对套利、网格交易还是跨品种基差套利，底层数学全都是均值回归框架。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你观察到某只股票在过去 3 个月里一直在 90 元到 110 元之间宽幅震荡。
今天这只股票因为盘中某个突发小噪声，价格暴跌到了 85 元（严重偏离历史均值 100 元）。
如果你顺势做空（趋势跟踪），你极易惨遭见底反弹的反杀；如果你主观伸手去接跌停板，又担心它会一路跌破 50 元崩溃。

**以前的方法在哪里卡住：**
1. **主观凭感觉抄底**：无法定量测量“85 元到底偏离了多少个标准差？它弹回 100 元需要多少天（半衰期）？”
2. **忽视均值破裂风险**：当股票基本面发生永久性断裂（如财务造假爆雷）时，均值回归策略会持续加仓越买越亏，引发“接下坠飞刀”的毁灭性爆仓。

**为什么必须引入均值回归策略框架：**
通过 OU 过程估计回归半衰期（Half-life），并用标准化 Z-Score 信号控制开仓、平仓与硬止损边界。

**它到底解决了哪类问题：**
解决了**震荡或协整市场中价格偏离度的定量评估、开平仓信号触发以及防止均值不回归导致爆仓**的问题。

## 4. 用直觉语言解释它

### 生活类比：弹簧与橡皮筋

想象你手里拉着一根弹簧：
- 当你用力把弹簧向外拉伸（价格过度暴涨），弹簧内部产生的形变拉力（均值回归力）就越大；当你松手时，弹簧会猛烈弹回原状。
- 当你把弹簧向内压缩（价格过度暴跌），弹簧会反弹恢复。

**均值回归策略的直觉本质**：
在弹簧拉得极紧（Z-Score 超出正负 2 倍标准差）时入场，反向建立头寸，静静等待弹簧弹回常态（均值）时平仓出场。

«“均值回归策略就是寻找被拉紧的弹簧，在弹簧偏离最厉害时做反向交易，等待价格弹回均值。”»

## 5. 正式定义、核心公式、符号解释

### 核心定义
**均值回归策略（Mean-Reversion Strategy）**：一种假设资产价格或价差在偏离其长期均值后，最终会重新向该均值靠拢的量化交易策略。

### 核心公式

#### 1. Ornstein-Uhlenbeck (OU) 离散 $AR(1)$ 表达式
$$X_t - X_{t-1} = \alpha + \beta X_{t-1} + \epsilon_t$$
对应连续 OU 过程：$\theta = -\ln(1 + \beta) \approx -\beta$（要求 $\beta < 0$）。
长期均值：$\mu = -\frac{\alpha}{\beta}$。

#### 2. 均值回归半衰期 (Half-Life $t_{half}$)
指价格偏离均值后，衰减回复到偏离量一半所需要的交易时间：
$$t_{half} = -\frac{\ln(2)}{\lambda} = -\frac{\ln(2)}{\ln(1 + \beta)} \approx -\frac{\ln(2)}{\beta}$$

#### 3. Z-Score 信号与交易规则
$$Z_t = \frac{X_t - \mu_w}{\sigma_w}$$
- **买入信号**：$Z_t < -Z_{entry}$
- **卖出信号**：$Z_t > +Z_{entry}$
- **平仓信号**：$|Z_t| \le Z_{exit}$
- **止损信号**：$|Z_t| \ge Z_{stop}$

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $X_t$ | 资产价格/价差/指标 | 货币/标量 | 要求具备平稳性 |
| $\theta$ 或 $\lambda$ | 均值回归速率系数 | 1/时间 | $\theta > 0$ 回归速度越快 |
| $\mu$ | 长期均衡均值 | 货币单位 | $\mu = -\alpha / \beta$ |
| $t_{half}$ | 半衰期 | 天数/分钟 | 决定策略最佳持仓周期 |
| $Z_{entry}$ | 开仓触发阈值 | 标准差倍数 | 常用 $1.5 \sim 2.0$ |
| $Z_{stop}$ | 硬止损阈值 | 标准差倍数 | 常用 $3.0 \sim 4.0$（防基本面破裂） |

## 6. 推导思路和思想来源

### 为何半衰期 $t_{half}$ 是均值回归策略的生命线？
1. **资金成本与持仓周期匹配**：如果估计出的半衰期 $t_{half} = 300$ 天，而你的对冲基金融资利息很高，持有 300 天的利息成本会彻底吃掉均值回归的利润。
2. **转念（挑选最佳半衰期）**：
   - 最适合均值回归交易的资产，其半衰期应该在 **1 天至 30 天之间**。
   - 若 $t_{half} < 1$ 天：适合做高频做市与网格交易。
   - 若 $t_{half} > 60$ 天：说明均值回归太慢，资金占用成本极高，不宜单独交易。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（半衰期与长期均值计算）

**题目**：
对某 ETF 的价格偏离序列做回归：$\Delta X_t = 0.10 - 0.05 X_{t-1} + \epsilon_t$。
求该序列的长期均值 $\mu$ 与均值回归半衰期 $t_{half}$（已知 $\ln(2) \approx 0.693$）。

**解答过程**：
1. 提取参数：$\alpha = 0.10, \beta = -0.05$。
2. 计算长期均值 $\mu$：
   $$\mu = -\frac{\alpha}{\beta} = -\frac{0.10}{-0.05} = 2.0 \text{ 元}$$
3. 计算半衰期 $t_{half}$：
   $$t_{half} = -\frac{\ln(2)}{\beta} = -\frac{0.693}{-0.05} = \frac{0.693}{0.05} = 13.86 \text{ 天}$$
4. **结论**：偏离量平均需要约 13.9 个交易日恢复到一半，策略预期持仓周期约 14 天。

---

### 例子 2：中等例题（布林带 Bollinger Bands 均值回归信号）

**题目**：
某股票 20 日移动平均价格 $SMA_{20} = 100$ 元，20 日标准差 $\sigma_{20} = 5$ 元。
设定布林带上轨为 $SMA + 2\sigma$，下轨为 $SMA - 2\sigma$。
今天的收盘价为 88 元。
判断价格是否触发买入信号？

**解答过程**：
1. 计算下轨价格：
   $$Band_{lower} = 100 - 2 \times 5 = 90 \text{ 元}$$
2. 计算今日 Z-Score：
   $$Z_{today} = \frac{88 - 100}{5} = \frac{-12}{5} = -2.4$$
3. 判断：
   收盘价 88 元 $< 90$ 元（下轨），且 $Z = -2.4 < -2.0$。价格严重超卖偏离。
4. **结论**：触发均值回归多头买入信号！

---

### 例子 3：实际应用（Python 编写布林带 + Z-Score 均值回归回测策略）

```python
import numpy as np
import pandas as pd

# 模拟 200 天均值回归价格序列
np.random.seed(42)
prices = pd.Series(100 + np.cumsum(np.random.normal(0, 1, 200)))

# 计算 20 日滚动均值与标准差
window = 20
rolling_mean = prices.rolling(window).mean()
rolling_std = prices.rolling(window).std()

# 计算 Z-Score
z_score = (prices - rolling_mean) / rolling_std

# 生成交易信号
signals = pd.Series(0, index=prices.index)
signals[z_score < -2.0] = 1   # 超卖做多
signals[z_score > 2.0] = -1   # 超买做空
signals[z_score.abs() < 0.5] = 0 # 均值回归平仓

print("策略多头开仓次数:", (signals == 1).sum())
```

## 8. 常见误区与易混概念

### 误区 1：均值回归策略可以不设止损，反正是会回归的

错误直觉：“价格跌得越多，偏离均值越大，我应该无限加仓，反正迟早弹回来。”  
为什么错：当公司发生破产退市、重大诉讼或财务造假时，价格不是“偏离”均值，而是**长期均值本身崩塌下降**。不设止损的均值回归策略被称为“下坠的飞刀”，是量化破产的最主要原因。  
正确理解：**必须设置硬止损（如 $|Z| > 3.5$）或最大持有天数止损！**

### 概念对比：均值回归 vs 趋势跟踪

| 维度 | 均值回归策略 (Mean-Reversion) | 趋势跟踪策略 (Trend-Following) |
| :--- | :--- | :--- |
| **交易哲学** | 逆势操作（买低卖高 / 逢低抄底） | 顺势操作（追涨杀跌 / 突破买入） |
| **适用市场** | 震荡市、箱体整理、低波动市场 | 强趋势单边牛市/熊市 |
| **胜率与赔率** | **高胜率（70%+），低赔率（小盈小亏）** | **低胜率（30%~40%），高赔率（大盈小亏）** |
| **主要危险** | 遇到强单边趋势被碾压爆仓 | 在震荡市中被反复左右打脸 (Whipsaw) |

### 第 1 题：概念辨析（基础）
**题目**：在市场处于无趋势的宽幅震荡行情时，均值回归策略与趋势跟踪策略哪个表现更好？

### 第 2 题：公式运用（基础）
**题目**：对某资产偏离度回归得到 $\Delta X_t = -0.10 X_{t-1} + \epsilon_t$。求其均值回归半衰期 $t_{half}$ 天数（取 $\ln(2) \approx 0.693$）。

> [!question]- 答案解析
> **答案**：
> $t_{half} \approx -\frac{0.693}{\beta} = -\frac{0.693}{-0.10} = 6.93 \text{ 天}$。

### 第 3 题：条件判断（中等）
**题目**：判断：“若某股票因为行业重大利好连续封住 5 个涨停板，此时其 Z-Score 达到 +4.5，均值回归策略应该重仓做空该股票。”

> [!question]- 答案解析
> **答案**：错误。连续涨停代表强单边趋势发散，基本面发生重大改观，均值本身已被抬升。此时做空不仅违反了 $|Z| \ge 3.5$ 的硬止损风控规则，还会遭受巨大的单边爆仓风险。  
> **Obsidian 标签**：`#自测题/均值回归风控`

### 第 4 题：变式/综合（中等）
**题目**：某交易员设计策略：当价格低于布林带下轨（$Z < -2.0$）且 14 日 RSI $< 30$（双重超卖）时才建仓做多。分析这种组合过滤的优缺点。

> [!question]- 答案解析
> **答案**：

### 第 5 题：开放/建模（较难）
**题目**：在估计 OU 过程参数时，静态 OLS 估计的均值 $\mu$ 是固定不变的。如何利用卡尔曼滤波（Kalman Filter）实现长期均值 $\mu_t$ 的动态追踪？

> [!question]- 答案解析
> **解析**：
> 1. **构建状态空间模型**：将长期均值设为不可观测的状态变量 $\mu_t = \mu_{t-1} + w_t$（允许长期均值平滑漂移）。
> 2. **观测方程**：$X_t = \mu_t + e_t$。
> 3. **Kalman 更新**：每期收到最新价格 $X_t$ 后，通过卡尔曼增益（Kalman Gain）动态更新 $\mu_t$ 的估计值。这样策略交易的仅是“偏离动态均值的短期波动”，而不会在均值发生趋势性转移时错误做多/做空。

- **成立条件**：先写清数据时点、估计窗口、交易摩擦和分布/市场结构假设，再运行模型。
