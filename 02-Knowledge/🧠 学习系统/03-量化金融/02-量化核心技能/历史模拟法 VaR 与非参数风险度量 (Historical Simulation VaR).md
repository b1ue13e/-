# 历史模拟VaR

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
历史模拟法 VaR（Historical Simulation Value at Risk，以 Philippe Jorion 经典风控体系为代表）是全球银行巴塞尔协议（Basel Accords）与对冲基金风险管理中最常用的非参数风控模型。相较于假定正态分布的参数法 VaR（Parametric VaR），历史模拟法完全不依赖任何收益率正态分布假设，能够天然保留现实市场收益率序列中残酷的**尖峰厚尾 (Fat Tails)** 与**偏态 (Skewness)** 特征。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你使用参数法（正态分布假设）计算某对冲基金的 99% 日 VaR（风险价值）。
正态分布告诉你在 99% 置信度下最大日亏损是 2.33 个标准差（如 500 万元）。
但是在 2008 年金融危机爆发现场，市场出现了 6 个标准差（6-Sigma）甚至 10 个标准差的巨额暴跌事件！
在正态分布中，10-Sigma 事件发生的概率是 $10^{-23}$（相当于自宇宙大爆炸以来都不可能发生一次）。**你的参数法 VaR 模型被市场暴击打得粉碎。**

**以前的方法在哪里卡住：**
强行假设收益率服从正态分布，忽视了真实金融市场“尖峰厚尾”与“黑天鹅效应”。

**为什么必须引入历史模拟法 VaR：**
让历史数据自己说话（Let data speak for itself）！直接使用过去 $N$ 天（如 500 天）真实发生的历史收益率序列，重新应用到当期资产组合上，直接提取分位数（Quantile）。

**它到底解决了哪类问题：**
解决了**无需假设概率分布函数前提下，精准度量包含肥尾与非线性衍生品组合的下行风险**问题。

---

## 2. 为什么它重要？它有什么用？

- **体系与大图景**：风控与量化风险管理（第二阶段）三大 VaR 求解方法（参数法、历史模拟法、蒙特卡洛法）的核心支柱之一。
- **量化与实战应用**：
  1. **巴塞尔协议监管资本计提 (Basel Capital Adequacy)**：商业银行计算 10 日 99% 历史模拟 VaR 乘以 3 倍乘数确定最低风控准备金。
  2. **非线性衍生品风控 (Non-linear Risk)**：在不依赖 Greeks 线性近似的前提下，计算包含复杂期权组合的真实损益分布。

## 4. 用直觉语言解释它

### 生活类比：翻看历史天气防台风

- **参数法（正态分布）** 就像：拿圆规画一条完美抛物线，预测明天降雨量。即便历史上有过特大暴雨，它也因为抛物线尾部太薄而忽略了。
- **历史模拟法** 就像：直接把过去 500 天气象局记录的每日实际降雨量抄在一张纸上，按降雨量从大到小排个序。
  看倒数第 5 绝的大暴雨那天下了多少水，直接用这个真实发生过的降雨量作为预防台风的沙袋高度！

**历史模拟法的直觉本质**：
不搞花里胡哨的数学公式假设，用过去真金白银发生过的真实历史惨剧，作为防范未来亏损的参照物。

«“历史模拟法就是不用任何正态假设，把历史发生的真实损益从差到好排个序，直接抓出对应概率位置的那个历史亏损。”»

## 5. 正式定义、核心公式、符号解释

### 核心定义
**历史模拟法 VaR (Historical Simulation VaR)**：指假设未来的资产收益率分布与过去 $N$ 个交易日观察到的历史收益率分布完全一致，将当期资产组合的权重直接映射到历史收益率序列上，生成伪历史组合损益序列，并取指定置信水平 $(1-\alpha)$ 对应的分位数作为 VaR 的非参数估算方法。

### 核心公式

#### 1. 伪历史组合损益序列构建
设当期组合对各资产的持仓金额为 $w_1, w_2, \dots, w_K$。
对于历史第 $t$ 天（$t = 1, 2, \dots, N$）：
$$r_{p, t} = \sum_{k=1}^K w_k r_{k, t}$$
计算组合伪历史价值变化：
$$\Delta V_t = V_{current} \times r_{p, t}$$

#### 2. 分位数排序与 VaR 提取
将 $N$ 个历史损益 $\Delta V_t$ 按升序排列：$\Delta V_{(1)} \le \Delta V_{(2)} \le \dots \le \Delta V_{(N)}$。
在置信水平 $c = 1 - \alpha$ 下（如 $c = 95\%, \alpha = 5\%$）：
$$\mathbf{\text{VaR}_{1-\alpha} = - \Delta V_{(\lfloor N \cdot \alpha \rfloor)}}$$

#### 3. 衰减加权历史模拟法 (Age-Weighted / BRW Method)
为了赋予近期数据更高的权重，赋予历史第 $t$ 天权重 $w_t = \frac{\lambda^{N-t} (1-\lambda)}{1 - \lambda^N}$（其中 $\lambda \approx 0.98$），按累积概率分配求分位数。

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 备注与经验取值 |
| :--- | :--- | :--- | :--- |
| $N$ | 历史回看窗口天数 | 天数 | 常用 $N=250$ (1年) 或 $N=500$ (2年) |
| $\alpha$ | 显著性水平 (Significance Level) | 百分比 | $\alpha = 5\%$ (95% 置信度) 或 $\alpha = 1\%$ (99% 置信度) |
| $\Delta V_{(k)}$ | 排序后第 $k$ 小的伪历史损益 | 货币单位 | 为负数时代表亏损 |
| $\lambda$ | 衰减因子 (Decay Factor) | 标量 $< 1$ | 衰减加权历史模拟法专用 |

## 6. 推导思路和思想来源

### 为什么历史模拟法能够天然捕捉“尖峰厚尾”与“非对称偏态”？
1. **摒弃函数假设**：历史模拟法不需要拟合任何如 $N(\mu, \sigma^2)$ 或 $t$ 分布函数。
2. **全保真实分布**：历史收益率数据本身就包含了市场曾经发生过的肥尾（Fat Tails）、负偏态（Negative Skewness）、波动率聚集（Volatility Clustering）以及资产间的非线性相关性（Copula 违约相关）。
3. **结果**：分位数由历史真实极值决定，彻底消除了模型设定错误（Model Risk）。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（500 天历史模拟 VaR 提取）

**题目**：
某量化基金持仓市值 1 亿元。
利用过去 $N = 500$ 个交易日的历史收益率应用到当期组合，将生成的 500 个每日模拟损益按从小到大（亏损最大到盈利最大）排序。
最小的 5 个损益分别为：
- 第 1 小：$-800$ 万元
- 第 2 小：$-650$ 万元
- 第 3 小：$-550$ 万元
- 第 4 小：$-480$ 万元
- 第 5 小：$-420$ 万元

求该基金在 $99\%$ 置信度下的 1 日历史模拟 VaR。

**解答过程**：
1. 计算显著性水平 $\alpha = 1 - 99\% = 1\% = 0.01$。
2. 确定对应分位数位置：
   $$k = N \times \alpha = 500 \times 0.01 = 5$$
3. 提取第 5 小的损益：$\Delta V_{(5)} = -420$ 万元。
4. **结论**：在 99% 置信度下，该基金 1 日历史模拟 $\text{VaR}_{99\%} = 420 \text{ 万元}$（即明日亏损超过 420 万元的概率不超过 1%）。

---

### 例子 2：中等例题（传统历史模拟法的“鬼影效应 Ghost Effect”）

**题目**：
假设 1 年前（250 天前）发生了暴跌黑天鹅（单日亏损 1000 万），这一数据一直保留在 250 天的历史窗口内，拉高了 VaR。
今天（第 251 天），这笔黑天鹅数据从 250 天回看窗口中被踢出。
分析明天计算出的 VaR 会发生什么突变？

**解答过程**：
1. **鬼影效应 (Ghost Effect)**：在今天市场非常平静的情况下，仅仅因为 1 年前的黑天鹅数据掉出了 250 天时间窗口，算出的 VaR 会在今天无故**突然暴跌**！
2. **缺陷**：传统历史模拟法对窗口长度 $N$ 极其敏感，数据剔除会造成 VaR 阶梯状伪跳跃。
3. **解决方案**：引入衰减加权历史模拟法 (BRW) 或结合 GARCH 模型过滤波动率。

---

### 例子 3：实际应用（Python 抽取股票组合历史模拟 VaR 与 Expected Shortfall CVaR）

```python
import numpy as np
import pandas as pd

## 模拟 3 只股票过去 500 天收益率 (带有肥尾)
np.random.seed(42)
returns = pd.DataFrame(np.random.standard_t(df=4, size=(500, 3)) * 0.015, columns=['A', 'B', 'C'])
weights = np.array([0.4, 0.3, 0.3])
portfolio_value = 10000000 # 1000 万组合

## 计算伪历史组合日收益率
port_returns = returns.dot(weights)
port_pnl = portfolio_value * port_returns

## 计算 95% 与 99% 历史模拟 VaR
var_95 = -np.percentile(port_pnl, 5)
var_99 = -np.percentile(port_pnl, 1)

## 计算条件 VaR (Expected Shortfall / CVaR)
cvar_95 = -port_pnl[port_pnl <= -var_95].mean()

print(f"1000万组合 95% 历史模拟 VaR: {var_95:.2f} 元")
print(f"1000万组合 99% 历史模拟 VaR: {var_99:.2f} 元")
print(f"1000万组合 95% 条件 VaR (CVaR): {cvar_95:.2f} 元")
```

## 8. 常见误区与易混概念

### 误区 1：历史模拟法 VaR 能够完美预测未来从未发生过的黑天鹅事件

错误直觉：“我已经用了历史模拟法，没有正态假设了，所以风控万无一失。”  
为什么错：历史模拟法的前提是“历史会重演”。如果过去 500 天内市场从未发生过 2008 年级别的流动性危机，历史模拟法完全无法预测该危机（所谓的“历史盲区”）。  
正确理解：**历史模拟法只能反映历史出现过的极端场景，无法防范历史未曾出现的全新黑天鹅！必须补充压力测试 (Stress Testing)。**

### 概念对比：参数法 VaR vs 历史模拟法 VaR vs 蒙特卡洛 VaR

| 维度 | 参数法 VaR (Parametric) | 历史模拟法 VaR (Historical) | 蒙特卡洛 VaR (Monte Carlo) |
| :--- | :--- | :--- | :--- |
| **分布假设** | 严格假定正态/T 分布 | **无参数假设 (Non-parametric)** | 指定随机过程（如 GBM/Jump） |
| **计算速度** | 极快（直接乘 $z_{\alpha} \sigma$） | 中等（仅需排序） | 慢（数万次随机模拟） |
| **肥尾与非线性** | 无法处理肥尾与复杂期权 | **天然支持肥尾与复杂期权** | 最完美支持非线性与复杂衍生品 |
| **主要坑点** | 正态假设失真 | 受限于历史窗口与鬼影效应 | 模型设定错误与计算瓶颈 |

### 第 1 题：概念辨析（基础）
**题目**：在计算历史模拟法 VaR 时，我们需要估计参数如均值 $\mu$ 和方差 $\sigma^2$ 吗？

> [!question]- 答案解析
> **答案**：不需要。历史模拟法是非参数估计方法（Non-parametric），直接利用历史数据提取经验分位数，不需要拟合均值和方差参数。  
> **Obsidian 标签**：`#自测题/非参数VaR`

---

### 第 2 题：公式运用（基础）
**题目**：在包含 $N = 1000$ 天的历史数据中，计算 99% 置信度下的历史模拟 VaR，应该取升序排列后第几个最小的损益值？

> [!question]- 答案解析
> **答案**：
> 显著性水平 $\alpha = 1 - 99\% = 1\% = 0.01$。
> 排序位置 $k = 1000 \times 0.01 = 10$。即取第 10 小的历史损益值。  
> **Obsidian 标签**：`#自测题/VaR分位数`

### 第 3 题：条件判断（中等）
**题目**：判断：“因为历史模拟法完全基于真实历史数据，所以巴塞尔协议只允许商业银行使用历史模拟法，禁止使用参数法。”

> [!question]- 答案解析
> **答案**：错误。巴塞尔协议允许银行自行选择内部模型法（包含参数法、历史模拟法与蒙特卡洛法），但要求模型必须通过严密的后验检验（Backtesting）并施加 3~4 倍的监管加倍因子。  
> **Obsidian 标签**：`#自测题/巴塞尔协议VaR`

### 第 4 题：变式/综合（中等）
**题目**：为什么巴塞尔协议 III 逐渐推荐使用条件 VaR（Expected Shortfall, ES / CVaR）替代传统 VaR？

> [!question]- 答案解析
> **答案**：
> 1. **VaR 不满足一致性风险度量 (Coherent Risk Measure)**：VaR 不具备次可加性 (Sub-additivity)，可能出现两个资产组合后的 VaR 大于单体 VaR 之和。
> 2. **忽视尾部绝壁风险**：VaR 只告诉你 99% 门槛处的最大亏损，完全不关心超越 99% 之后那 1% 极小概率下到底会亏损 1 亿还是 100 亿。而 ES / CVaR 计算的是超越门槛后尾部亏损的**期望均值**，包含了尾部极端损失。  
> **Obsidian 标签**：`#自测题/CVaR优势`

### 第 5 题：开放/建模（较难）
**题目**：Barone-Adesi, Giannopoulos and Vosper (1999) 提出的“过滤历史模拟法 (Filtered Historical Simulation, FHS)”是如何结合 GARCH 模型与历史模拟法优点的？

> [!question]- 答案解析
> **解析**：
> 1. **提取标准化残差**：先用 GARCH(1,1) 模型拟合历史收益率，提取出剔除波动率聚集后的标准化残差 $\hat{e}_t = \frac{r_t}{\sigma_t}$（此时 $\hat{e}_t$ 近似独立同分布）。
> 2. **当期波动率重缩放**：利用当期预测的波动率 $\sigma_{today}$ 对历史残差重新缩放：$r_t^* = \hat{e}_t \cdot \sigma_{today}$。
> 3. **效果**：既保留了历史残差的非正态肥尾特征，又让计算出的 VaR 具备了当前最新的波动率动态感知能力，彻底解决了传统历史模拟法的时延滞后与鬼影效应。  
> **Obsidian 标签**：`#自测题/过滤历史模拟法`
