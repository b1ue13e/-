# Fama-French 三因子模型

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：CAPM 实证失败后的标准补救；因子投资（SMB/HML）的起源；量化多因子体系的模板。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：CAPM 说"β 一个因子就够"，但实证发现：**小市值股票长期跑赢、低市净率（价值股）长期跑赢**——这两个异象用 β 解释不了，Alpha 显著不为零。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：三因子是"多因子模型"的起点（后续五因子、动量因子都按同样范式构建）；SMB/HML 的构造方法（排序分组）是因子构建的行业标准。
- **实际应用场景**：业绩归因（超额收益是 Alpha 还是风格暴露）、多因子选股、风险模型（Barra）。
- **高频题型/任务**：解释 SMB/HML 的构造（2×3 分组）；三因子回归与 Alpha 解读；与 CAPM 的嵌套关系。

---

## 3. 学它之前需要哪些前置知识？

1. **[[CAPM 资本资产定价模型|CAPM资本资产定价模型]]**：单因子定价与 Alpha。
2. **[[收益率定义与对数收益]]**：超额收益。

---

## 4. 用直觉语言解释它

> «"CAPM 只问'跟大盘一起颠多少'，三因子再加两个问题：'你是不是小盘股？' '你是不是便宜的价值股？'——这两个身份本身就有风险溢价。"»

- **直觉类比/几何图像**：β 是"音量"，SMB 是"体型"，HML 是"性价比"——三个特征共同决定期望收益。
- **为什么很自然**：小公司经营风险高、价值股财务困境风险高，投资者要求补偿——系统性风险的来源不止市场一个。
- **一句话直觉本质**：**三因子 = 市场 + 规模(SMB) + 价值(HML)，把 CAPM 的 Alpha 分解为两个风格暴露 + 真正残余的 Alpha。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

$$E[R_i]-R_f = \beta_i^{M}(E[R_M]-R_f) + \beta_i^{SMB}\cdot E[SMB] + \beta_i^{HML}\cdot E[HML]$$

实证回归：$R_{i,t}-R_{f,t}=\alpha_i+\beta_i^{M}\text{MKT}_t+\beta_i^{SMB}\text{SMB}_t+\beta_i^{HML}\text{HML}_t+\varepsilon_{i,t}$。

### 2. 核心公式（因子构造）

SMB（Small Minus Big）：每月按市值中位数分大小两组，SMB = 小盘组合收益 − 大盘组合收益（市值加权）。HML（High Minus Low）：按市净率（B/M）分三组（30/40/30），HML = 高 B/M 组合收益 − 低 B/M 组合收益。两者交叉形成 2×3 六组，SMB/HML 分别取两组的均值。

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| MKT | 市场超额收益 | $R_M-R_f$ |
| SMB | 规模因子 | 小−大 |
| HML | 价值因子 | 高 B/M − 低 B/M |
| $\beta^{SMB}$ | 规模暴露 | 小盘股 > 0 |
| $\alpha_i$ | 三因子定价误差 | 显著 ≠ 0 说明漏因子 |

### 4. 常见变体与适用条件

- **适用条件**：美股日/月频实证；因子值用公开数据（Kenneth French 数据库）可复现。
- **限制条件**：SMB/HML 是"经验因子"缺乏严格理论（Fama-French 五因子后 HML 部分被 RMW/CMA 吸收）；中国市场适用性需重估（壳价值、涨跌停影响）。

---

## 6. 推导思路和思想来源

- **最初困难**：CAPM 的 $\alpha$ 系统性非零（小盘、价值异象）。
- **直接方法局限**：把异象当"市场无效"无法建模。
- **关键"转念"**：Fama & French (1993) 主张这些异象是**系统性风险因子**的暴露，而非错误定价——按规模/价值排序分组构造多空组合，把异象"因子化"。
- **推导主线与动机**：2×3 交叉分组保证 SMB/HML 相互正交化（控制对方后的纯风格暴露）；因子收益率 = 多空组合月收益。
- **为什么自然得到此结论**："能被因子解释的 Alpha 不是 Alpha"——归因先于结论。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

- **题目**：小盘价值股的三因子暴露大致什么符号？
- **解题思路**：小盘 → SMB 暴露正；价值（高 B/M）→ HML 暴露正；市场 β 接近 1。
- **最终答案**：$\beta^{SMB}>0,\ \beta^{HML}>0,\ \beta^M\approx1$。
- **易错点**：HML 方向（高 B/M 是"价值"侧，暴露为正表示"像价值股"）。
- **🤔 追问**：大盘成长股的暴露？（SMB 负、HML 负）

### 例子 2：中等例子（条件判断与多步推理）

- **题目**：某基金三因子回归 $\alpha=0.5\%$（月，t=2.8），怎么解读？
- **完整解答**：三因子无法解释的显著正超额——可能是技能（选股）、或遗漏因子（动量/流动性）。结论需结合持仓与更长样本；若换五因子后 α 消失，则原 α 只是风格暴露。

### 例子 3：实际应用例子（真实场景/代码）

- **实际价值与转化**：从 Kenneth French 网站下载因子序列，`statsmodels` OLS 三因子回归（Newey-West 标准误）；生产：月度归因报告，跟踪 α 的 t 统计量与风格漂移（$\beta^{SMB}$ 是否随市场变化）。

## 8. 常见误区和易混概念

### 误区 1："三因子 Alpha 显著 = 基金经理有真本事"
- **错误直觉**：α>0 就是技能。
- **为什么错**：可能只是暴露了未包含的因子（动量、质量、流动性）；样本期短时 α 噪声大。
- **正确理解**：α 是"给定因子模型下的残余"，换模型结论可能反转。

### 概念对比表

| 概念 | 因子 | 说明 |
| :--- | :--- | :--- |
| CAPM | MKT | 单因子基线 |
| 三因子 | MKT+SMB+HML | 规模+价值 |
| 五因子 | +RMW+CMA | 盈利+投资 |
| 动量因子 | MOM | UMD 独立因子 |

### 题目与解析

#### 1. SMB 的构造？
> [!question]- 答案解析
> - **答案**：按市值分大小两组，小盘组收益减大盘组收益。
> - **解析**：多空组合。
> - **易错原因**：方向记反（大盘减小盘）。

#### 2. HML 用哪个指标分组？
> [!question]- 答案解析
> - **答案**：账面市值比 B/M（或市净率倒数）。
> - **解析**：价值代理。
> - **易错原因**：用市盈率（含盈利噪声）。

#### 3. 大盘成长股的 HML 暴露？
> [!question]- 答案解析
> - **答案**：负（低 B/M 侧）。
> - **解析**：成长股=低 B/M。
> - **易错原因**：以为价值暴露恒正。

#### 4. 三因子 α 显著为正的可能解释？
> [!question]- 答案解析
> - **答案**：技能、遗漏因子、样本噪声。
> - **解析**：模型内残余。
> - **易错原因**：直接断定技能。

#### 5. 中国市场用三因子的注意事项？
> [!question]- 答案解析
> - **答案**：壳价值/ST 效应扭曲市值与价值因子；需重估分组阈值、加流动性因子、剔除新股。
> - **解析**：制度差异。
> - **易错原因**：直接套用美国参数。
