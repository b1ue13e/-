# 单位根检验与 ADF 检验 (Unit Root & Augmented Dickey-Fuller Test)

---

## 0. 先判断它值不值得深挖

**分类：A 类（核心概念，必须深挖）**

**理由：**
单位根检验（Unit Root Test，最常用为 ADF 检验与 PP 检验）是时间序列分析中判断序列是否平稳（Stationary）的“终极诊断探针”。在金融计量学中，未经单位根检验直接对非平稳价格原序列做 OLS 回归会导致毁灭性的伪回归（Spurious Regression）；而对不含单位根的平稳序列强行求差分则会导致过度差分与信息丢失。掌握单位根检验是构建 ARIMA、GARCH、协整与配对交易的首要门槛。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你正在研究股票价格序列 $P_t$。
你观察到 $P_t$ 在过去一年里不断上涨，如果你直接对 $P_t$ 进行自回归 $P_t = \rho P_{t-1} + \epsilon_t$，估计出的斜率系数 $\rho \approx 1.0$。

**以前的方法在哪里卡住：**
如果 $\rho = 1.0$，序列包含一个**单位根（Unit Root）**，变为随机游走（Random Walk $P_t = P_{t-1} + \epsilon_t$）。
- **冲击永久留存**：今天的突发利空冲击 $\epsilon_t$ 会永久残留在未来的价格中，价格方差随时间 $t$ 无限增大 ($Var(P_t) = t \sigma^2$)！
- **经典 $t$ 检验失效**：传统的 $t$ 统计量在单位根假设下不再服从标准正态分布，普通假设检验完全失真。

**为什么必须引入单位根检验：**
通过严格的统计检验（Dickey-Fuller 非标准分布）判断参数 $\rho$ 是否等于 1（$\gamma = \rho - 1 = 0$），决定序列是否需要进行一阶或多阶差分平稳化。

**它到底解决了哪类问题：**
解决了**分辨时间序列是具有常数均值方差的平稳过程、还是记忆永不衰减的非平稳随机游走**的问题。

---

## 2. 为什么它重要？它有什么用？

- **体系与大图景**：时间序列平稳性检验的第一关，连接基础统计特征与高级计量模型（ARIMA / 协整 / VAR）。
- **量化与实操应用**：
  1. **避免伪回归陷阱**：在因子选股或多变量回归前，先通过 ADF 检验排除含单位根的非平稳因子。
  2. **价差平稳性验证**：在配对交易中，对价差残差进行 ADF 检验，验证其是否具备均值回归特性（$\rho < 1$）。
  3. **确定单整阶数 $I(d)$**：递进检验原序列 $X_t$、一阶差分 $\Delta X_t$，确定其单整阶数 $d$。

   > - 若 $|\rho| > 1$：序列方差指数爆炸。

## 4. 用直觉语言解释它

### 生活类比：拴橡皮筋的狗 vs 醉汉的随机游走

- **平稳序列（$|\rho| < 1$）**：就像一只拴着橡皮筋的狗。无论狗跑出多远，橡皮筋的拉力（均值回归力）都会把狗拉回主人身边。
- **含有单位根的非平稳序列（$\rho = 1$）**：就像一个喝醉酒的汉子。他每一步都在前一步停下的地方继续向随机方向迈出。他昨天的失足（历史冲击）永远留在了后方，他离酒吧越走越远，再也不会主动回到起点（方差无限扩大）。

**单位根检验的直觉本质**：
拿一把尺子去量那根橡皮筋是否存在（检验 $\rho$ 是否小于 1）。如果有橡皮筋，就是平稳的；如果橡皮筋断了（$\rho = 1$），就是单位根非平稳。

«“单位根检验就是检测数据有没有‘均值回归的拉力’，还是像醉汉一样越走越远。”»

## 5. 正式定义、核心公式、符号解释

### 核心定义
**单位根检验（Unit Root Test）**：检验一阶自回归 $AR(1)$ 模型的特征根是否等于 1（即是否存在单位根）的假设检验方法。若存在单位根，序列为非平稳序列；若不存在，序列为平稳序列。

### 核心公式与 ADF 检验方程

#### 1. 原始 DF 检验方程 (Dickey-Fuller 1979)
对 $X_t = \rho X_{t-1} + \epsilon_t$ 两边减去 $X_{t-1}$，令 $\gamma = \rho - 1$：
$$\Delta X_t = \gamma X_{t-1} + \epsilon_t$$
- 原假设 $H_0: \gamma = 0$ ($\rho = 1$，存在单位根/非平稳)
- 备择假设 $H_1: \gamma < 0$ ($\rho < 1$，平稳)

#### 2. 增广 Dickey-Fuller (ADF) 检验方程 (处理高阶自相关)
为了消除残差 $\epsilon_t$ 中的高阶自相关，加入了滞后差分项 $\Delta X_{t-i}$：
$$\Delta X_t = \alpha + \beta t + \gamma X_{t-1} + \sum_{i=1}^p \psi_i \Delta X_{t-i} + \epsilon_t$$

其中包含三种可能模型结构：
1. **无常数项无趋势项**：$\alpha = 0, \beta = 0$
2. **仅含常数项（漂移项）**：$\beta = 0$
3. **含常数项和时间趋势项**：$\alpha \neq 0, \beta \neq 0$

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\Delta X_t$ | $t$ 期的一阶差分 $X_t - X_{t-1}$ | 变化量 | 检演方程的左侧因变量 |
| $X_{t-1}$ | 滞后一期的水平值 | 原始量纲 | **核心项！其斜率 $\gamma$ 是 ADF 检验的对象** |
| $\gamma$ | $\rho - 1$ 差分系数 | 标量 | $H_0: \gamma = 0$（存在单位根） |
| $\alpha$ | 截距项/漂移项 (Drift) | 标量 | 决定是否有单边趋势漂移 |
| $\beta t$ | 线性时间趋势项 (Trend) | 标量 | 决定是否有确定性趋势 |
| $\Delta X_{t-i}$ | 滞后差分项 | 变化量 | 用于消除高阶自相关 |

## 6. 推导思路和思想来源

> [!tip] 🚧 认知脚手架：为什么经典中心极限定理在此失效？
> 在经典统计学中，我们习惯了用 $t$ 分布去检验回归系数。因为只要样本量够大，中心极限定理就会保证估计量服从正态分布。
> **但是！** 单位根的原假设是“该序列是一个随机游走”。还记得前面的“醉汉”吗？随机游走的方差是随时间发散的（$Var = t\sigma^2$），它根本没有稳定的均值和方差！
> 当底层数据的方差爆炸时，经典的中心极限定理彻底崩塌。因此，我们在下面即将看到的极限分布，不再是我们熟悉的钟形曲线，而是一个高度向左偏斜的“怪物”（维纳过程积分的泛函分布）。不要被下面的随机微积分公式吓倒，你只需要记住其物理意义：**它要求证据极其确凿，临界值比普通 $t$ 检验要严苛得多（向左偏移极大）！**

### 为什么 ADF 检验不能使用标准 $t$ 分布临界值？
1. **零假设下的非正态性**：在 $H_0: \gamma = 0$（即序列是随机游走 $X_t = \sum \epsilon_i$）的前提下，估计量 $\hat{\gamma}$ 的分母包含维纳过程的平方积分：
<details>
<summary>🧠 点击展开：硬核的维纳过程积分分布（不看完全没关系）</summary>

   $$\hat{\gamma} \xrightarrow{d} \frac{\frac{1}{2} [W(1)^2 - 1]}{\int_0^1 W(r)^2 dr}$$
这不再是一个钟形的标准正态分布，而是一个极其向左偏斜的怪物分布。
</details>

2. **转念（Dickey-Fuller 模拟临界值）**：此极限分布严重**左偏**，并非标准正态 $N(0,1)$ 或学生 $t$ 分布！因此 Dickey 和 Fuller 运用 Monte Carlo 模拟得出了专门的 **DF/ADF 临界值表**（通常 5% 显著性水平下的临界值为 $-2.86 \sim -3.45$ 左右，远比正态分布的 $-1.645$ 更加严格/偏负）。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（ADF $t$-统计量计算与决策）

**题目**：
对某股票对数价格 $P_t$ 进行 1 阶 ADF 回归，得到方程：
$$\Delta P_t = 0.05 - 0.02 P_{t-1} + 0.15 \Delta P_{t-1}$$
其中 $P_{t-1}$ 项的回归斜率标准误为 $SE(\hat{\gamma}) = 0.01$。
查 ADF 临界值表（含常数项模型，样本量 $N=250$）：5% 临界值为 $-2.88$。
计算 ADF $t$-统计量，并判断 $P_t$ 是否平稳。

**解答过程**：
1. 提取 $\hat{\gamma} = -0.02$。
2. 计算 ADF $t$-统计量：
   $$t_{ADF} = \frac{\hat{\gamma}}{SE(\hat{\gamma})} = \frac{-0.02}{0.01} = -2.00$$
3. 比较统计量与临界值：
   $t_{ADF} = -2.00 > t_{critical} = -2.88$ （注意：ADF 检验为单侧左尾检验，统计量越负代表越倾向于拒绝 $H_0$）。
4. **结论**：在 5% 显著性水平下**无法拒绝原假设 $H_0$**。序列 $P_t$ 存在单位根，是非平稳序列！

---

### 例子 2：中等例题（确定单整阶数 $I(d)$）

**题目**：
量化分析师对某大宗商品价格序列 $S_t$ 进行单位根检验流程：
- 步骤 1：对 $S_t$ 做 ADF 检验，$p$-value $= 0.72$。
- 步骤 2：对一阶差分序列 $\Delta S_t$ 做 ADF 检验，$p$-value $= 0.001$。

判断 $S_t$ 的单整阶数 $d$ 是多少？能否直接对 $S_t$ 建立 ARMA 模型？

**解答过程**：
1. 步骤 1 中 $p = 0.72 > 0.05$，无法拒绝 $H_0$，说明原序列 $S_t$ 非平稳，存在单位根。
2. 步骤 2 中 $p = 0.001 < 0.05$，强力拒绝 $H_0$，说明一阶差分 $\Delta S_t$ 已经平稳。
3. **结论**：序列 $S_t$ 为**一阶单整序列 $I(1)$**。不能直接对 $S_t$ 建立 ARMA 模型，而必须建立 ARIMA(p, 1, q) 模型。

---

### 例子 3：实际应用（Python adfuller 接口自动化检验）

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import adfuller

# 生成一个真正的平稳均值回归序列
np.random.seed(42)
stationary_series = np.zeros(500)
for t in range(1, 500):
    stationary_series[t] = 0.7 * stationary_series[t-1] + np.random.normal(0, 1)

# 执行 ADF 单位根检验
result = adfuller(stationary_series, autolag='AIC')

print(f"ADF 统计量: {result[0]:.4f}")
print(f"p-value: {result[1]:.4e}")
print(f"5% 临界值: {result[4]['5%']:.4f}")

if result[1] < 0.05:
    print("结论: 拒绝原假设 H0，序列平稳 (No Unit Root)！")
```

## 8. 常见误区与易混概念

### 误区 1：ADF 检验的原假设 $H_0$ 是“序列平稳”

错误直觉：“$p$-value 小于 0.05，说明接受了原假设，所以平稳。”  
为什么错：ADF 检验的原假设 $H_0$ 极其特殊，是 **“存在单位根（非平稳）”**。  
正确理解：**只有 $p$-value 小于 0.05 拒绝 $H_0$ 时，才说明序列平稳！** （与 KPSS 检验相反）。

### 概念对比：ADF 检验 vs KPSS 检验

| 维度 | ADF 检验 (Augmented Dickey-Fuller) | KPSS 检验 (Kwiatkowski et al.) |
| :--- | :--- | :--- |
| **原假设 $H_0$** | **存在单位根（非平稳）** | **序列平稳 (Stationary)** |
| **拒绝 $H_0$ 含义** | 证明序列平稳 | 证明存在单位根（非平稳） |
| **组合应用** | 工业界常组合使用两者进行“双重确认” |

### 第 3 题：条件判断（中等）
**题目**：判断：“若序列 $X_t = 0.05 t + \epsilon_t$（其中 $\epsilon_t$ 为白噪声），则该序列含有单位根，需要通过求差分来平稳化。”

> [!question]- 答案解析
> **答案**：错误。该序列为**确定性趋势平稳序列 (Trend-Stationary Process)**。它不含有单位根（随机游走成分），只需通过减去线性时间趋势 $0.05t$ 即可平稳化，强行差分会导致过度差分。在 ADF 检验中应选择“含时间趋势项”的模型。  
> **Obsidian 标签**：`#自测题/确定性趋势`

---

### 第 4 题：变式/综合（中等）
**题目**：对某汇率序列做 ADF 检验，原序列 $p = 0.85$，一阶差分后 $p = 0.02$。若将一阶差分序列再次求一阶差分（二阶差分），二阶差分序列的 ADF 检验结果会怎样？

> [!question]- 答案解析
> **答案**：二阶差分序列仍会显著拒绝单位根假设（$p < 0.05$ 显平稳），但这属于**过度差分 (Over-differencing)**，会向序列中人工引入一个 MA(1) 负相关自相关毒瘤，破坏数据原始信息。  
> **Obsidian 标签**：`#自测题/过度差分`

---

### 第 5 题：开放/建模（较难）
**题目**：在 2008 年金融危机发生时，为什么传统的 ADF 检验很容易将一个“趋势发生了结构性突变（Structural Break）但实际平稳”的序列误判为“含有单位根”？Zivot-Andrews 检验是如何修正的？

> [!question]- 答案解析
> **解析**：
> 1. **传统 ADF 局限**：传统 ADF 假设截距 $\alpha$ 和趋势系数 $\beta$ 永恒不变。当金融危机导致序列均值突然发生永久跃迁（跳阶）时，传统 ADF 会将这种均值跳变误认为是随机游走的无界漂移，从而极其错误地接受单位根假假设（统计功效拉垮）。
> 2. **Zivot-Andrews 修正**：允许在数据驱动下内生寻找结构断裂点 $T_{break}$，并在 ADF 方程中加入断裂哑变量（Dummy Variables），在允许结构突变的前提下重新检验单位根。  
> **Obsidian 标签**：`#自测题/ZivotAndrews`

## 可定位依据与失效复核

本卡的复核对象是 **单位根检验与 ADF 检验 (Unit Root & Augmented Dickey-Fuller Test)**，而不是只复述一个公式。对 **单位根检验与 ADF 检验 (Unit Root & Augmented Dickey-Fuller Test)** 的独立验证重点是：同时记录检验回归中的常数、趋势和滞后阶数，并用结构突变反例检验结论稳健性。

### 权威来源与定位

1. Dickey 与 Fuller (1979), *Distribution of the Estimators for Autoregressive Time Series with a Unit Root*, DOI: 10.1080/01621459.1979.10482531。用于复核“同时记录检验回归中的常数、趋势和滞后阶数，并用结构突变反例检验结论稳健性”。
2. statsmodels `adfuller` 官方 API：https://www.statsmodels.org/stable/generated/statsmodels.tsa.stattools.adfuller.html。用于复核“同时记录检验回归中的常数、趋势和滞后阶数，并用结构突变反例检验结论稳健性”。
3. James D. Hamilton, *Time Series Analysis*, Princeton University Press, ISBN 9780691042893, Chapter 17（趋势、单位根与伪回归边界）。用于复核“同时记录检验回归中的常数、趋势和滞后阶数，并用结构突变反例检验结论稳健性”。

### 失效边界与验收协议

- **成立条件**：先写清数据时点、估计窗口、交易摩擦和分布/市场结构假设，再运行模型。
- **反例压力测试**：同时记录检验回归中的常数、趋势和滞后阶数，并用结构突变反例检验结论稳健性。
- **最小实验**：固定随机种子或冻结原始数据快照，同时保存基线、破坏条件后的对照组、关键中间量与失败日志。
- **通过标准**：结论必须在样本外仍保持方向一致；若成本、延迟、参数扰动或结构突变使结论反转，就把该情形登记为适用边界而不是删除失败结果。
