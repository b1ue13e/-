## 1. 定义、机制、假设与边界

滚动窗口与波动率特征的定义包含窗口边界、最小样本数、标准差自由度与年化频率。其机制是在每个资产内部对过去观测做局部统计，并不自动保证可交易性。假设信号在收盘后生成且次日执行时，可以使用当日收盘信息；若当日开盘执行则必须退回到此前可见数据。反例是无条件 shift 一天或完全不写交易时点。验证要同时检查前导空值、手算样本标准差以及两个时点协议。

## 2. Worked example

```python
import numpy as np
r = np.array([0.01, -0.01, 0.01])
sigma = r.std(ddof=1)
assert abs(sigma - 0.011547005383792516) < 1e-12
assert np.isnan(np.array([np.nan, np.nan])[0])
```

运行后必须保存输入、期望输出和实际输出。代码可执行只证明局部定义一致，不证明策略在样本外有效。

## 决策规则：窗口右端必须早于预测对象的可得时点

**滚动窗口与波动率特征**的核心机制是将时点 $t$ 的特征限定为 $[t-L, t]$ 内已知观测；如果标签从 $t+1$ 开始，任何中心窗口或负向 `shift` 都会越界。窗口长度控制估计方差与响应速度：短窗能追踪 regime 变化但噪声大，长窗稳定却会稀释跳变。复现实验应同时计算 `rolling(L).std()` 与手工切片标准差，并在窗口刚满、缺失值和停牌段做逐行断言。

反例是先用全样本均值填缺失再滚动，或把当日收盘后才能得到的波动率用于当日收盘成交。**滚动窗口与波动率特征**的验收要求是明确 `closed`、`min_periods`、年化因子和 `ddof`，再用截断未来数据后的重算结果确认历史特征完全不变。

### 定义—推导—对比复核

**滚动窗口与波动率特征** 的定义必须能落到数据列和时点，而不能只停留在术语。从信息集 $\mathcal F_t$ 推导窗口右端约束，并对比扩展窗口与固定窗口在估计方差和制度漂移下的取舍。因此，对 **滚动窗口与波动率特征** 的误区检查要同时保留正例、破坏条件后的反例和样本外结果；只要三者不能形成同一因果链，就暂不判定掌握。
