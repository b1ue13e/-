# 最大回撤

给定净值 $V_t$，历史峰值 $H_t=\max_{s\le t}V_s$，回撤为：

$$D_t=\frac{V_t}{H_t}-1\le0$$

最大回撤通常报告其绝对损失幅度：$MDD=-\min_tD_t$。

## Worked example

净值 `100, 110, 108, 95, 97, 120`：到 95 时历史峰值仍为 110，回撤为 $95/110-1=-13.64\%$；这比“最差单日收益”描述的是不同问题。

## K08 最小作业

手算一段 8 期净值的历史峰值、逐期回撤和最大回撤，再实现函数与手算对照。额外记录峰值日、谷值日和恢复日。

## 常见错误

- 把最差单日收益当最大回撤。
- 直接对收益率序列求最小值，而不先构造净值路径。
- 用未来峰值计算当前回撤。

## K08 来源、边界与独立复核

### 定义、假设、机制与边界

最大回撤的定义是净值相对历史峰值的最大相对跌幅，而不是最差单日收益。计算机制先取 running maximum，再计算当前净值除以峰值减一；因此路径顺序会改变最大回撤，即使期末收益相同。边界包括净值必须使用一致成本口径、缺失期不能默认零收益。反例是将全期最高点与更早最低点相减，那条“回撤”在时间上无法发生。独立验证应保存峰值日期、谷底日期和恢复日期。

### 可定位来源

1. Bacon, Practical Portfolio Performance Measurement and Attribution, Wiley, 2008, ISBN 9780470059289, Chapter 4.
2. Microsoft Qlib Recorder, Section risk_analysis output: https://qlib.readthedocs.io/en/stable/component/recorder.html
3. NumPy maximum.accumulate API, Section cumulative maximum: https://numpy.org/doc/stable/reference/generated/numpy.maximum.accumulate.html

### 可复现示例与验证

```python
import numpy as np
nav = np.array([1.0, 1.1, 1.05, 0.88, 0.95])
peak = np.maximum.accumulate(nav)
drawdown = nav / peak - 1
assert abs(drawdown.min() - (0.88 / 1.1 - 1)) < 1e-12
assert drawdown[0] == 0
```

这段最小实验不是收益证明；它只验证 K08 的局部定义与边界。正式作业仍需保存输入、期望输出、实际结果和失败案例。
