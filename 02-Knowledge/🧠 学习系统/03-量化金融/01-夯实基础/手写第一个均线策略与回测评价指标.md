---

## 1. 策略思想：均线交叉 (Moving Average Crossover)

> **我们遇到了什么麻烦**：股票价格每天上下跳动（噪音太大），怎么判断它是在涨还是在跌？

**直觉解法**：把过去 N 天的价格加起来算个平均数，画成一条线。
- **短期均线 (SMA_Short)**：比如过去 10 天的平均价。它反应敏捷，贴着现在的价格走。
- **长期均线 (SMA_Long)**：比如过去 60 天的平均价。它反应迟钝，代表长期的总体趋势。

**交易规则（极其简单）**：
- 📈 **买入（做多）**：当短期均线 **向上穿过** 长期均线时（这叫“金叉”），说明近期涨势凶猛，买入！
- 📉 **卖出（平仓）**：当短期均线 **向下穿过** 长期均线时（这叫“死叉”），说明近期跌势已成，卖出！

---

## 2. 伪代码实现 (Pandas 20行搞定)

假设你已经有了一个 DataFrame 叫 `df`，里面有一列每天的收盘价 `close`。

```python
import pandas as pd
import numpy as np

## 1. 计算均线
df['SMA_10'] = df['close'].rolling(window=10).mean() # 短期均线
df['SMA_60'] = df['close'].rolling(window=60).mean() # 长期均线

## 2. 生成交易信号 (1表示持有，0表示空仓)
## 当 SMA_10 > SMA_60 时，产生买入信号
df['signal'] = np.where(df['SMA_10'] > df['SMA_60'], 1, 0)

## ⚠️ 极其关键的一步：信号我们要明天才能执行！
## 因为你是在今天收盘时才算出均线的，你只能以明天的价格买入。必须 shift(1)！
df['position'] = df['signal'].shift(1)

## 3. 计算收益
## 每天的股票涨跌幅
df['daily_return'] = df['close'].pct_change()
## 你的策略收益 = 你是否持有股票(position) * 当天的股票涨跌幅
df['strategy_return'] = df['position'] * df['daily_return']

## 4. 算总账 (净值)
df['equity_curve'] = (1 + df['strategy_return']).cumprod()
```

> **恭喜！你刚刚写出了人生中第一个量化策略系统！**

## 3. 回测评价指标（怎么判断赚没赚钱？）

策略跑完了，怎么向别人吹牛（或者认错）？量化界有几个通用指标：

1. **累积收益率 (Cumulative Return)**：
   最直观的指标。从 1 块钱变成了 1.5 块钱，累积收益就是 50%。
   
2. **最大回撤 (Maximum Drawdown)**：
   **最体现心脏承受能力的指标**。指的是在整个历史中，你的账户从最高点跌到最低点，最多跌了多少？
   如果一个策略能赚 100%，但中间的最大回撤是 -80%，普通人绝对会在黎明前被吓得割肉离场。

3. **夏普比率 (Sharpe Ratio)**：
   **量化界的圣杯**。它衡量的是**“性价比”**。
   公式：`(策略收益率 - 无风险利率) / 策略波动率`
   简单说：你每承受一分风险，能换来几分超额收益？夏普比率 > 1 算及格，> 2 是优秀，> 3 通常是印钞机（或者代码写错了有 Bug）。

---

## 4. 常见误区和易混概念

### 误区：为什么均线策略在实盘总是亏钱？
- **错误直觉**：金叉买，死叉卖，历史图表上看着每次都抓住了大趋势，怎么一实盘就亏？
- **为什么错 (Whipsaw Effect)**：均线策略**只有在单边大牛市或大熊市**才赚钱。一旦遇到“震荡市”（价格在一个区间内来回波动），均线就会频繁地死叉、金叉。你会反复在“高点买入，低点割肉”，被市场来回打耳光（这叫“拉锯效应”），光手续费就能把你亏光。
- **结论**：世界上没有完美的万能指标。量化的进阶，就是去研究如何判断环境，如何组合指标。
