# 量化数据排雷指南：复权、生存者偏差与未来函数

## 0. 先判断它值不值得深挖
- **类别**：**A+ 类（救命稻草）**
- **判断理由**：在量化机构，80% 的时间在洗数据，20% 的时间在写模型。如果你不懂得排雷，学再多高深数学，一上实盘也是瞬间破产。

## 1. 为什么你的回测收益率高得离谱？
如果你从某个免费 API 下载了数据，写个均线策略，发现夏普比率高达 5.0，十年翻了 100 倍。
**先别辞职，你大概率踩雷了。**

### 雷区 1：生存者偏差 (Survivorship Bias)
- **直觉**：你下载了“当前 A 股所有股票”的历史数据进行回测。
- **真相**：那些在历史中因为造假、破产而**退市**的股票，不在你当前下载的列表里。你完美避开了所有必死的雷！
- **解法**：必须使用包含退市股票的全市场 point-in-time（历史某个时点的真实切片）数据。

### 雷区 2：未复权导致的暴跌暴涨 (Split/Dividend Adjustments)
- **直觉**：价格是连续的。
- **真相**：某天股票 1 股拆 2 股（除权），股价瞬间从 100 变成 50。你的策略会判定为“暴跌 50%”，从而产生严重误判。
- **解法**：

  - **前复权**：以现在的价格为基准，向后调整历史价格。适合跑量化回测。
  - **后复权**：以历史价格为基准，向前调整。适合算长期的绝对真实收益。

### 💻 实战代码：用 yfinance 演示“未复权”与“复权”的巨大差异

> **不要纸上谈兵，看下面这段处理苹果 (AAPL) 拆股的代码！** 苹果历史上发生过多次拆股（比如 2020年 1拆4，2014年 1拆7）。如果我们不复权，回测曲线会直接断崖式暴跌！

```python
import yfinance as yf
import pandas as pd
import matplotlib.pyplot as plt

# 1. 下载 AAPL 数据（包含拆股前的历史）
# [Capstone 主线任务] 我们始终以 AAPL 为研究对象
aapl = yf.download('AAPL', start='2019-01-01', end='2021-01-01')

# 2. 'Close' 是未复权的真实收盘价
# 3. 'Adj Close' 是前复权收盘价（消除了拆股和分红导致的断层跳空）

fig, ax = plt.subplots(figsize=(10, 5))
aapl['Close'].plot(ax=ax, label='Raw Close (未复权，踩雷！)', color='red', linestyle='--')
aapl['Adj Close'].plot(ax=ax, label='Adj Close (前复权，正确！)', color='green', linewidth=2)

ax.set_title("AAPL 2020年 1拆4 拆股事件：复权前后的毁灭性差异")
ax.legend()
plt.show()
`

### 雷区 3：财务数据的未来函数 (Look-ahead Bias in Fundamentals)
- **直觉**：2023年一季度的财报（3月31日截止），在 3月31日 就能用。
- **真相**：公司可能在 4月28日 才发布一季报。如果你在 4月1日 的回测中就用了一季度的净利润数据去选股，你就是穿越到了未来。
- **解法**：严格区分 `report_date` (财报截止期) 和 `publish_date` (财报实际发布日)。回测时只能在 `publish_date` 之后才能使用该数据。
