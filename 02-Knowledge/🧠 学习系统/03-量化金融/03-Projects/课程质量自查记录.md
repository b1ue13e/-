# 量化金融课程质量自查记录

## 评分规则

总分 100，五个维度各 20 分：引导性教学、认知科学、课程详细度、小白适配性、知识点详细度。通过必须同时满足：

1. 总分不低于 85；
2. 每个维度不低于 15；
3. `audit_quant_course_quality.py` 的代码、链接、项目测试和结构门禁通过。

评分器：`99-System/tools/score_quant_course.py`。评分项使用课程文件、核心卡、练习题数、来源登记、实验包和测试数量等可复核证据，不使用“看起来不错”作为得分依据。

## 每轮发现与修复

### 轮次 0 → 1

- **发现**：10 周只有总表，没有逐周学习动作；新手诊断失败后缺少可直接执行的补底；开源作业只有目录，没有实际题目。
- **修复**：新增 [[00-每周学习执行卡|每周执行卡]]、[[00-零基础补救-数学统计与Python|零基础补救]]、[[00-量化金融符号与术语速查|符号术语速查]]。
- **练习实物**：将 MIT OCW 18.S096 的 9 份 Problem Set 映射为 [[开源课程课后习题/README|5 份本地练习册]]，共 30 道改编题。
- **仍未通过原因**：来源 ID 的大小写重复导致机器计数误判；核心卡使用“机制/边界/先测”等同义标题，旧评分器只识别固定模板词；作业索引没有使用“唯一事实源”明确措辞。

### 轮次 1 → 2

- **修复评分误判**：评分器改为识别语义等价标题，不要求所有笔记机械复制同一模板；来源 ID 统一小写去重。
- **修复真实缺口**：正式入口接入 Week 0-9、零基础补救、术语表和开源练习；作业索引明确课程状态的唯一事实源。
- **认知闭环**：所有练习包含示例题 → 仿做题 → 独立题 → 迁移题、两级提示、答案锚点、前后信心、错因和 24h/72h/7d 重测。
