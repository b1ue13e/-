# 量化金融阶段 0：先修诊断与研究协议

## 为什么现在学

先确认 Python、数学统计、金融数据和研究验证四类前置。诊断、环境和数据边界没有证据时，不进入定价或机器学习。

## 核心学习顺序

1. [[量化金融-先修诊断与分流]]：闭卷诊断并记录信心与错因。
2. [[量化金融-零基础补救-数学统计与Python]]：只补诊断失败项。
3. [[量化金融-本地环境配置与依赖]]：运行最小环境和数据示例。
4. [[量化金融-符号与术语速查]]：统一收益、可得时间、成本和风险符号。
5. [[量化金融-主观交易与量化交易]]：区分可证伪研究结论与主观判断。

## 学完能做什么

- 运行并记录最小 Python 环境、输入、输出和依赖版本。
- 解释信息可得时间、执行时间、样本内/外和 smoke 的区别。
- 依据诊断结果选择补救路径，而不是把未掌握的前置隐藏在作业中。

## 阶段验收与作业

- 四个诊断维度均不低于 3/4。
