# 量化金融符号与术语速查

> 首次遇到术语时先看“它回答什么问题”，再回到主题卡学习定义和推导。本页是减轻工作记忆负担的速查表，不替代正式笔记。

## 核心符号

| 符号 | 一句话含义 | 取值/量纲 | 常见误读 |
| :--- | :--- | :--- | :--- |
| $P_t$ | $t$ 时点价格 | 货币单位 | 与收益率混为一谈 |
| $R_t$ | 简单收益率 | 无量纲 | 多期直接相加 |
| $r_t$ | 对数收益率 | 无量纲 | 极端收益下当作简单收益 |
| $R_f$ | 无风险利率 | 必须声明频率 | 年化值直接减日收益 |
| $\mu$ | 均值或漂移参数 | 随模型频率 | 当作下一期保证收益 |
| $\sigma$ | 标准差或波动率 | 与收益同量纲 | 与方差混用 |
| $\sigma^2$ | 方差 | 收益率平方 | 直接按百分比解释 |
| $\Sigma$ | 协方差矩阵 | 方差量纲 | 忽略非正定问题 |
| $w$ | 组合权重向量 | 常有 $\mathbf1^Tw=1$ | 默认允许或禁止做空 |
| $\alpha$ | 回归截距/定价误差 | 与收益同频 | 自动解释为投资技能 |
| $\beta$ | 市场或因子暴露 | 无量纲 | 高 Beta 等于高 Alpha |
| $\epsilon_t$ | 模型未解释部分 | 与因变量同量纲 | 默认是独立正态白噪声 |
| $X$ | 设计矩阵或状态变量 | 依上下文 | 忽略行列维度 |
| $y$ | 回归目标 | 依任务 | 与预测值 $\hat y$ 混淆 |
| $\hat\theta$ | 参数估计值 | 依参数 | 与真实参数 $\theta$ 等同 |
| $S_t$ | 标的资产价格 | 货币单位 | 与执行价 $K$ 混淆 |
| $K$ | 期权执行价 | 货币单位 | 与时间索引混淆 |
| $T$ | 到期时点或样本长度 | 时间 | 与剩余期限 $T-t$ 混淆 |
| $W_t$ | 布朗运动 | 标准差为 $\sqrt t$ | 把路径当可微函数 |
| $dW_t$ | 布朗增量 | 方差为 $dt$ | 当普通微分处理 |
| $\Delta$ | 期权对标的价格的一阶敏感度 | 每单位标的 | 等同实际对冲盈亏 |
| $\Gamma$ | Delta 对标的价格的变化率 | 每价格单位 | 忽略离散调仓风险 |

## 数据与研究术语

| 术语 | 它回答什么问题 | 最小检查 |
| :--- | :--- | :--- |
| OHLCV | 一根行情柱记录了什么 | 字段、时区、频率、复权 |
| 复权 | 公司行动后价格如何保持可比 | 原始价与总回报口径 |
| 可得时点 | 当时真的知道这条信息吗 | 发布日而非报告期末日 |
| 前视偏差 | 是否偷看未来 | 扰动未来后历史特征不变 |
| 幸存者偏差 | 样本是否只保留活下来的资产 | 使用点时成分股/退市股 |
| 训练集 | 用什么数据估计参数 | 不触碰未来数据 |
| 验证集 | 用什么数据选择方案 | 只用于调参和选择 |
| 测试集 | 用什么数据做最终评估 | 最后只开封一次 |
| 基线 | 复杂方法至少要超过什么 | 均值、持有或简单规则 |
| 换手率 | 仓位变化有多频繁 | 明确单边/双边口径 |
| 交易成本 | 毛收益会被削减多少 | 手续费、滑点、冲击 |
| 最大回撤 | 历史峰值后最坏跌幅是多少 | 使用累计净值而非单期收益 |
| VaR | 给定尾部概率的损失阈值 | 置信度、期限、损失正负号 |
| ES | 超过 VaR 后平均有多坏 | 尾部样本和模型稳定性 |
| 平稳性 | 分布特征是否随时间保持 | 区分严格与弱平稳 |
| GARCH | 条件波动率如何随冲击更新 | 参数约束、训练期估计 |
| QLIKE | 波动率预测如何比较 | 实现中的方差单位与正值 |
| PCA | 哪些正交方向解释最多方差 | 标准化与协方差/相关矩阵 |
| 因子暴露 | 收益对共同驱动有多敏感 | 暴露、溢价与残差分开 |
| 样本外 | 结论是否在未参与建模的数据成立 | 冻结切分和一次性测试 |

## 阅读公式的四步法

1. 圈出等号左侧：这是待解释量、目标还是状态？
2. 给每个符号写维度和频率。
3. 写出公式成立的条件。
4. 用一个极端或边界输入检查方向是否合理。
