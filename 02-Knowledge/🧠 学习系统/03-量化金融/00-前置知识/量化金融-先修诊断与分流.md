# 量化金融先修诊断与分流

## 为什么先诊断

本课程不要求既有金融背景，但后续任务会同时使用 Python、数学统计、金融数据和研究验证。先诊断可避免把工具错误、时间口径错误或高置信误区带入模型。

## 作答协议

- 合上其他笔记，限时 20 分钟；每题 1 分，共 16 分。
- 每题先记录信心 0–100%；答错且信心不低于 80% 时标记“高置信误区”。
- 代码题只有实际运行并得到预期输出才得分。

## A. Python 与数据操作（4 分）

1. Series.pct_change() 的第一个结果为什么通常是缺失值？
2. 多资产面板做 shift(1) 前为什么通常要先按资产分组？
3. 运行下面代码，解释两个断言分别验证什么。

```python
import pandas as pd

prices = pd.Series([100.0, 105.0, 102.9])
returns = prices.pct_change()
assert round(returns.iloc[1], 4) == 0.05
assert round(returns.iloc[2], 4) == -0.02
print(returns.round(4).tolist())
```

4. 日期按字符串排序与按时间戳排序，什么时候会产生不同结果？

## 判分锚点

- **A**：首期无上一期价格；分组防止资产间污染；代码输出为 [nan, 0.05, -0.02]；非 ISO 日期、混合时区等会破坏字符串排序。
- **B**：5%；对数把连乘变为加法；负协方差可在合适权重下降低组合方差；标准差与收益同量纲。
- **C**：开高低收量；零成交可能是真实状态；口径混用制造虚假跳跃；信号应在预先声明的下一可成交时点执行；公告日决定信息可得。
- **D**：训练拟合、验证选择、测试最终评估；摩擦可能吞噬收益；回撤衡量峰谷损失；过拟合、泄漏、制度漂移、成本和容量均可使结果失效。
