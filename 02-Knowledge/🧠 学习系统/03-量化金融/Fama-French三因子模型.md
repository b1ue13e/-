# Fama-French 三因子模型

> **一句话直觉**：单靠大盘 Beta 无法解释股票收益率的异象；小市值公司（SMB）和高账面市值比的价值型公司（HML）长期存在持续的超额风险收益补偿。

---

## 0. 先判断它值不值得深挖？

* **分类**：**A 类（核心概念，必须深挖）**
* **判断理由**：
  1. **历史地位**：诺贝尔经济学奖得主尤金·法玛（Eugene Fama）与肯尼斯·弗伦奇（Kenneth French）于 1993 年提出的三因子模型，是实证资产定价历史上最成功的经典里程碑。
  2. **行业标准**：它是现代学术界检验股票超额收益（Alpha）的标准基准，也是金融工业界 Smart Beta ETF、风格因子配置与量化多因子选股策略的直接源头。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦？**

CAPM 模型预测：在调整了市场 Beta 后，任何股票或组合的残差收益率应该完全是无规律的随机噪声（Alpha 应为 0）。
但在 20 世纪 80-90 年代，实证经济学家们在美股市场发现了严重的 **CAPM 定价异常 (CAPM Anomalies)**：

1. **小公司效应 (Size Anomaly)**：小市值公司的平均收益率长期显著高于大市值公司，即使调整了更高的 Beta 后依然存在无法解释的超额收益。
2. **价值效应 (Value Anomaly)**：高账面市值比（B/M，相当于低市盈率/低市净率）的“价值股”，收益率长期显著跑赢低 B/M 的“高估/成长股”。

**Fama-French 模型解决的问题**：
通过显式构造 **小减大因子 (SMB)** 和 **高减低因子 (HML)**，与大盘市场溢价因子结合，将模型对股票组合收益率异质性的解释力（$R^2$）从 CAPM 的 70% 大幅提升至 90% 以上。

---

## 2. 为什么它重要？它有什么用？

* **知识图谱位置**：连接理论资产定价（CAPM/APT）与工业界量化选股（Barra/Smart Beta）的最重要实证模型。
* **实际应用场景**：
  * **业绩归因 (Performance Attribution)**：评估公募/私募基金经理的收益到底是来自于“选股择时”，还是仅仅因为“长期偏好买小盘股”或“偏好买低估值价值股”。
  * **Smart Beta ETF 投资**：发行针对 SMB（小盘）或 HML（价值）因子的指数基金。

---

## 3. 学它之前需要哪些前置知识？

1. **[[CAPM 资本资产定价模型]]**：了解市场风险溢价 $R_m - R_f$ 与 贝塔系数 $\beta$。
2. **[[APT套利定价理论]]**：理解多元线性回归中多个共同风险因子的并行定价方程。
3. **账面市值比 (Book-to-Market Ratio, B/M)**：公司账面净资产除以公司股票总市值（市净率 PB 的倒数）。

## 4. 用直觉语言解释它

### 生活类比：不同身型的运动员跑马拉松

如果把股票看作跑马拉松的选手：
* CAPM 认为：跑步速度只取决于“天气的风速（大盘 $R_m$）”和“选手对风速的敏感度（$\beta$）”。
* 但实际比赛中大家发现：
  1. **身材瘦小的选手（小市值 SMB）**：虽然风大时跑得吃力，但在复杂路况下步频极快，整体平均成绩竟然显著更好！
  2. **身体抗造的实干选手（高价值 HML）**：虽然没有花哨包装，但体力耐力极强，长期看往往跑赢那些吹得天花乱坠的明星选手（成长股）。

**Fama-French 的直觉本质**：
除了大盘风向之外，**“公司体量大小（SMB）”** 和 **“资产估值实虚（HML）”** 是决定股票收益率的另外两个天然基因因子。

---

## 5. 正式定义、核心公式与符号解释

### 核心公式（Fama-French 三因子回归方程）
$$R_{it} - R_{ft} = \alpha_i + \beta_{i1} (R_{mt} - R_{ft}) + \beta_{i2} \text{SMB}_t + \beta_{i3} \text{HML}_t + \epsilon_{it}$$

### 符号含义表

| 符号 | 名称 | 含义 / 构造方法 | 备注 |
| :--- | :--- | :--- | :--- |
| $R_{it} - R_{ft}$ | 资产超额收益率 | 股票 $i$ 的收益率减去无风险利率 | 被解释变量 |
| $R_{mt} - R_{ft}$ | 市场风险溢价因子 | 全市场组合收益率减去无风险利率 | CAPM 经典市场因子 |
| $\text{SMB}_t$ | **规模因子 (Small Minus Big)** | 买入小市值组合、卖空大市值组合的净收益 | $E(\text{SMB}) > 0$ 长期成立 |
| $\text{HML}_t$ | **价值因子 (High Minus Low)** | 买入高 B/M (价值股) 组合、卖空低 B/M (成长股) 组合的净收益 | $E(\text{HML}) > 0$ 长期成立 |
| $\beta_{i1}, \beta_{i2}, \beta_{i3}$ | 因子敏感度 (因子 Beta) | 股票 $i$ 在市场、规模、价值三个因子上的多元回归斜率 | 暴露度度量 |
| $\alpha_i$ | **三因子 Alpha (Jensen's Alpha)** | 剥离了市场、规模、价值三大因子后的纯粹超额收益 | 真正能力体现 |

---

## 6. 推导思路与思想来源

### 为什么 SMB 和 HML 能够作为风险因子？

Fama 和 French 坚持理性资产定价范式（Efficient Market Hypothesis），解释为什么这两个因子存在长期风险溢价：

1. **SMB 的风险本质**：小公司资金链薄弱、抗宏观风险能力差、面临破产和融资约束风险更高。投资者买入小公司，必须获得补偿这种“财务脆弱性风险”的风险溢价。
2. **HML 的风险本质**：高 B/M 的公司通常是处于困境中的边缘企业（Distressed Firms），其资产变现能力差。投资者持有此类“陷入困境风险”的企业，要求更高的预期回报。

## 7. 渐进例题与实战应用

### 例子 1：基础手算例题（超额收益分析）

**题目**：
已知某月份的市场参数如下：
* 市场超额收益 $R_m - R_f = 1.0\%$
* 规模因子 $\text{SMB} = 0.6\%$
* 价值因子 $\text{HML} = 0.4\%$
* 无风险利率 $R_f = 0.2\%$

基金 A 的因子暴露为 $\beta_{m} = 1.1, \beta_{SMB} = 0.8, \beta_{HML} = -0.3$。
求基金 A 的理论预期收益率。

**解答**：
$$E(R_A) - R_f = 1.1 \times 1.0\% + 0.8 \times 0.6\% + (-0.3) \times 0.4\% = 1.1\% + 0.48\% - 0.12\% = 1.46\%$$
$$E(R_A) = 1.46\% + 0.2\% = 1.66\%$$

---

### 例子 2：实际应用（Python 三因子多重回归与基金业绩归因）

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

# 1. 模拟 60 个月的基金收益率与 Fama-French 三因子数据
np.random.seed(42)
months = 60

mkt_rf = np.random.normal(0.008, 0.04, months)
smb = np.random.normal(0.003, 0.02, months)
hml = np.random.normal(0.004, 0.025, months)

# 假设某小盘价值型基金真实 Alpha = 0.1% (月度), 各因子暴露如下
fund_excess = 0.001 + 0.9 * mkt_rf + 0.7 * smb + 0.5 * hml + np.random.normal(0, 0.01, months)

# 2. 构建多元线性回归
X = pd.DataFrame({'Mkt-RF': mkt_rf, 'SMB': smb, 'HML': hml})
X = sm.add_constant(X)
y = fund_excess

model = sm.OLS(y, X).fit()

print(model.summary())
```

## 8. 常见误区与易混概念

### 误区 1：三因子模型中的 Alpha ($\alpha$) 与 CAPM 中的 Alpha 是一样的

* **错误直觉**：“都是叫 Alpha，数值肯定差不多。”
* **为什么错**：CAPM 的 Alpha 包含了“小盘效应”和“价值效应”带来的收益。如果一个基金经理只是盲目买入小盘价值股，在 CAPM 回归中可能会得到很高的 Alpha；但在 Fama-French 三因子回归中，这部分收益会被 $\beta_{SMB}$ 和 $\beta_{HML}$ 解释掉，其真实的 $\alpha$ 会大幅缩水归零！
* **正确理解**：**三因子 Alpha 剥离了常见的风格暴露，更能体现经理真正的选股能力**。

### 第 1 题：概念辨析（基础）
**题目**：成长型股票（Growth Stock）的 $\beta_{HML}$ 符号通常是正还是负？

> [!question]- 答案解析
> **答案**：负数 ($\beta_{HML} < 0$)。  
> **解析**：成长股具有低 B/M 占比，而 HML 因子是“买高 B/M、卖低 B/M”。因此成长股与 HML 因子呈负相关。  
> **Obsidian 标签**：`#自测题/FamaFrench` `#HML因子`

### 第 2 题：公式运用（基础）
**题目**：若某股票在 SMB 上的 Beta 为 1.2，说明该股票属于大盘股还是小盘股？

> [!question]- 答案解析
> **答案**：小盘股。正的 $\beta_{SMB}$ 表明其收益变动方向与小盘股组合一致。  
> **Obsidian 标签**：`#自测题/SMB因子`

### 第 3 题：条件判断（中等）
**题目**：判断：“Fama-French 三因子模型完全否定了 CAPM 模型。”

> [!question]- 答案解析
> **答案**：错误。三因子模型包含了 CAPM 市场因子，是对 CAPM 的继承与扩展，而非彻底否定。  
> **Obsidian 标签**：`#自测题/CAPM与FF`

### 第 4 题：变式综合（中等）
**题目**：若某基金的 CAPM Alpha 为 +3%，但在三因子回归中 $\beta_{SMB}=1.5, \beta_{HML}=0.8$，三因子 Alpha 为 0%。说明该基金经理的真实能力如何？

> [!question]- 答案解析
> **答案**：该基金经理没有真正的选股能力。其 CAPM 下的超额收益完全来自于长期暴露于小盘风格与价值风格（风格 Beta 带来的收益），而非阿尔法选股技能。  
> **Obsidian 标签**：`#自测题/业绩归因`

---

### 第 5 题：开放与证明题（较难）
**题目**：简述为什么 Fama-French 后续又提出了五因子模型？增加了哪两个因子？

> [!question]- 答案解析
> **解析**：因为三因子模型无法解释盈利能力异象（高盈利股票跑赢低盈利）和投资异象（低投资增长率公司跑赢高投资增长率公司）。因此五因子模型增加了：盈利能力因子 RMW (Robust Minus Weak) 和投资风格因子 CMA (Conservative Minus Aggressive)。  
> **Obsidian 标签**：`#自测题/五因子模型`
