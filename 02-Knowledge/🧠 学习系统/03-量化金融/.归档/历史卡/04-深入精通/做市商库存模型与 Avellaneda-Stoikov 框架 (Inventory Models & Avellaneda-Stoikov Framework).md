# 做市商库存模型与 Avellaneda-Stoikov 框架 (Inventory Models & Avellaneda-Stoikov Framework)

---

## 0. 学习边界

**学习定位：核心主题。**

**理由：**
做市商库存模型（Inventory Model，以 Ho-Stoll 1981 及 Avellaneda-Stoikov 2008 模型为代表）是高频做市（Market Making）与自动化流动性提供（ALP）的数学灵魂。做市商提供买卖双向流动性，但最致命的危险是**单边库存积压 (Inventory Risk)**。如果市场单边下跌，而做市商手里砸下了大量买入的多头库存，做市商将面临毁灭性亏损。库存模型通过随机最优控制（Stochastic Optimal Control）推导出动态调整报价中枢与挂单价差的解析解。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦：**

假设你是一个高频做市商，在盘口挂买一（10.00元）和卖一（10.02元）。
最近半小时内，市场上的卖单源源不断砸过来，你的买一不断被成交。
不知不觉中，你账户里积压了 50,000 股的多头股票（库存 $q = +50,000$）。如果此时市场大盘暴跌 5%，你的做市利润会被瞬间抹平，甚至直接破产。

**以前的方法在哪里卡住：**
1. **对称挂单**：继续傻傻地在 10.00 和 10.02 对称挂单，导致多头库存越来越大。
2. **人工凭感觉调整**：不知道“多拿了 50,000 股后，我的买卖报价到底应该向下倾斜（Skew）多少钱，才能既快速消化多头库存，又不错过交易收益？”

**为什么必须引入 Avellaneda-Stoikov 库存模型：**
利用随机最优控制解出**reservation price（参考保留价格 $r(s, q, t)$）**。根据当前持仓 $q$ 与风险厌恶系数 $\gamma$，自动将买卖报价向有利于出清库存的方向平移倾斜！

**它到底解决了哪类问题：**
解决了**高频做市商在随机订单流冲击下，如何通过动态调整挂单价格（Quote Skew）与价差（Spread）来控制库存风险并实现效用最大化**的问题。

---

## 2. 为什么它重要？它有什么用？

- **体系与大图景**：市场微观结构（第四阶段）最经典的理论模型之一，连接做市策略、微观风险控制与随机控制数学。
- **量化与实操应用**：
  1. **自动化做市商算法 (Avellaneda-Stoikov Market Maker)**：加密货币（Binance/DEX）与期货高频做市的主流算法原型。
  2. **动态库存风控 (Inventory Skew Control)**：当库存多头过高时，下调买单价（不愿再买）并下调卖单价（吸引买方买走自己的库存），实现“平滑去库存”。

## 4. 用直觉语言解释它

### 生活类比：水果贩子的“动态清仓打折”

假设你是一个水果贩子：
- 早上你进货了 1000 斤香蕉（零库存）。你挂牌：收购价 2 元/斤，卖出价 4 元/斤。
- 到中午时，来卖香蕉的人特别多，你手里积压了 800 斤香蕉（多头库存过高，怕放烂了）。
- **你的反应**：
  1. 收购价降到 1.5 元/斤（**降低买价**， discourage 别人继续卖给你）。
  2. 卖出价降到 3.0 元/斤（**降低卖价**， encourage 顾客赶紧买走你的香蕉）。

**库存模型的直觉本质**：
当手里东西拿多了，就降价吸引买家帮自己出清；当手里东西空了，就加价吸引卖家卖给自己。通过报价的整体偏移（Skew），把库存强行维持在安全线附近。

«“库存模型就是做市商根据自己手里货多货少，自动把买卖挂牌价整体向上或向下倾斜，用来吸引市场帮你平仓。”»

## 5. 正式定义、核心公式、符号解释

### 核心定义
**Avellaneda-Stoikov 框架**：指在连续时间下，假定资产价格服从算术布朗运动、订单到达服从强度为 $\lambda(\delta)$ 的泊松过程，做市商通过极大化负指数效用函数，推导出包含库存惩罚项的保留价格与最优买卖挂单距离的理论模型。

### 核心公式

#### 1. 考虑库存后的参考保留价格 (Reservation Price $r$)
$$r(s, q, t) = s - q \gamma \sigma^2 (T - t)$$

其中：
- $s$：当前市场中间价 (Mid Price)
- $q$：做市商当前的库存持仓量（多头为正 $q>0$，空头为负 $q<0$）
- $\gamma$：做市商的绝对风险厌恶系数 (Risk Aversion)
- $\sigma$：标的资产波动率
- $T - t$：剩余做市时间

#### 2. 最优买卖挂单距离 ($\delta^a, \delta^b$)
$$r(s, q, t) - r^b = \delta^b, \quad r^a - r(s, q, t) = \delta^a$$
$$\delta^a + \delta^b = \gamma \sigma^2 (T - t) + \frac{2}{\gamma} \ln\left(1 + \frac{\gamma}{\kappa}\right)$$

做市商报出的买价 $r^b$ 与卖价 $r^a$ 为：
$$r^b(s, q, t) = r(s, q, t) - \frac{1}{\gamma} \ln\left(1 + \frac{\gamma}{\kappa}\right)$$
$$r^a(s, q, t) = r(s, q, t) + \frac{1}{\gamma} \ln\left(1 + \frac{\gamma}{\kappa}\right)$$

### 符号解释表

| 符号 | 含义 | 维度/量纲 | 备注与物理意义 |
| :--- | :--- | :--- | :--- |
| $s$ | 即期市场中中间价 | 货币单位 | 挂单的基准锚点 |
| $q$ | 做市商当前净库存 | 股数/合约数 | **核心状态变量！决定倾斜方向** |
| $\gamma$ | 风险厌恶系数 | 标量 $>0$ | $\gamma$ 越大，对库存积累越敏感，报价偏转越剧烈 |
| $\sigma$ | 资产波动率 | 标量 | 波动率越高，库存风险越大 |
| $\kappa$ | 订单流随挂单距离衰减的弹性参数 | 标量 | 挂单离买卖一越远，被成交概率下降越快 |
| $r(s,q,t)$ | 参考保留价格 | 货币单位 | $q>0$ 时 $r < s$（中枢下移）；$q<0$ 时 $r > s$（中枢上移） |

## 6. 推导思路和思想来源

### 为什么保留价格 $r(s, q, t)$ 中会带有 $- q \gamma \sigma^2 (T - t)$？
1. **持有库存的均值-方差惩罚**：
   做市商持有 $q$ 单位资产，直到时间 $T$。其末期资产价值的方差为 $Var(q S_T) \approx q^2 \sigma^2 (T - t)$。
   在负指数效用函数 $\text{Utility} = -\exp(-\gamma W)$ 下，对方差的边际惩罚为 $\frac{\partial}{\partial q} \left(\frac{1}{2} \gamma q^2 \sigma^2 (T - t)\right) = q \gamma \sigma^2 (T - t)$。
2. **转念（报价中枢下移）**：
   如果 $q > 0$（多头积压），做市商多持有 1 单位资产就会增加额外的风险惩罚。因此做市商对资产的真实心理估值（Reservation Price）**降到了 $s - q \gamma \sigma^2 (T - t)$**！
3. **结果**：做市商围绕 $r$ 而非 $s$ 挂单，使得买价 $r^b$ 和卖价 $r^a$ 整体向下滑动（Skew Down）。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础手算例题（保留价格倾斜计算）

**题目**：
某高频做市商在做市时，当前市场中间价 $s = 100.00$ 元。
已知参数：风险厌恶系数 $\gamma = 0.1$，资产日波动率 $\sigma = 1.0$ 元，剩余做市时间 $T - t = 1$ 天。
1. 当做市商无库存（$q = 0$）时，求保留价格 $r$。
2. 当做市商多头积压 50 手（$q = +50$）时，求保留价格 $r$。
3. 当做市商空头积压 50 手（$q = -50$）时，求保留价格 $r$。

**解答过程**：
1. **$q = 0$ 时**：
   $$r = 100.00 - 0 \times 0.1 \times 1.0^2 \times 1 = 100.00 \text{ 元}$$ （中性无倾斜）
2. **$q = +50$ 时**：
   $$r = 100.00 - (50) \times (0.1) \times (1.0)^2 \times 1 = 100.00 - 5.0 = 95.00 \text{ 元}$$
   （中枢大幅下移 5 元！强力向下倾斜去多头库存）
3. **$q = -50$ 时**：
   $$r = 100.00 - (-50) \times (0.1) \times (1.0)^2 \times 1 = 100.00 + 5.0 = 105.00 \text{ 元}$$
   （中枢大幅上移 5 元！强力向上倾斜去空头库存）

---

### 例子 2：中等例题（确定做市买卖挂单价格）

**题目**：
继承上题，当 $q = +10$ 手，$s = 100.00$ 元，$\gamma = 0.01, \sigma = 1.0, T-t = 1$。
假设计算得到的半价差项 $\frac{1}{\gamma} \ln(1 + \frac{\gamma}{\kappa}) = 0.05$ 元。
求做市商应当报出的买一价 $r^b$ 与卖一价 $r^a$。

**解答过程**：
1. 计算保留价格 $r$：
   $$r = 100.00 - 10 \times 0.01 \times 1^2 \times 1 = 100.00 - 0.10 = 99.90 \text{ 元}$$
2. 计算买一价 $r^b$：
   $$r^b = r - 0.05 = 99.90 - 0.05 = 99.85 \text{ 元}$$
3. 计算卖一价 $r^a$：
   $$r^a = r + 0.05 = 99.90 + 0.05 = 99.95 \text{ 元}$$
4. **结论**：相较于对称挂单（99.95 / 100.05），做市商将挂单整体下移到了（99.85 / 99.95）。卖一价 99.95 低于市场中间价 100.00，极易被买方吃掉，从而快速平掉多头库存！

### 例子 3：实际应用（Python 编写 Avellaneda-Stoikov 仿真做市商）

```python
import numpy as np

def avellaneda_stoikov_quotes(s, q, gamma, sigma, T_minus_t, k):
    # 1. 计算 Reserve Price
    r = s - q * gamma * (sigma ** 2) * T_minus_t
    
    # 2. 计算 Spread 偏移量
    spread_half = (1 / gamma) * np.log(1 + gamma / k)
    
    bid_price = r - spread_half
    ask_price = r + spread_half
    return r, bid_price, ask_price

## 模拟：现价 100，持有多头 5 手，风险厌恶 0.1，波动率 0.2
r, bid, ask = avellaneda_stoikov_quotes(s=100.0, q=5, gamma=0.1, sigma=0.2, T_minus_t=0.5, k=1.5)
print(f"保留价格: {r:.3f}, 买一挂单: {bid:.3f}, 卖一挂单: {ask:.3f}")
```

## 8. 常见误区与易混概念

### 误区 1：做市商无论何时都应该在 Mid-price 两侧保持对称挂单

错误直觉：“买一卖一副加相同距离，赚两边对称的价差才是做市商。”  
为什么错：如果对称挂单，当遭遇单边订单流冲击时，做市商的单边库存会无限累积，直到发生重大亏损或死于爆仓。  
正确理解：**成熟的做市商必定是非对称挂单（Skew Quotes）的！报价中枢随库存动态偏转。**

### 概念对比：库存模型 (Inventory Model) vs 信息交易模型 (Information Model)

| 维度 | 库存模型 (如 Avellaneda-Stoikov) | 信息交易模型 (如 Glosten-Milgrom) |
| :--- | :--- | :--- |
| **关注的核心风险** | 资产价格波动与做市商**持仓库存风险** | 知情交易者带来的**逆向选择风险** |
| **报价偏转原因** | 自身库存 $q$ 偏离零点 | 收到买单/卖单后对真实价值的贝叶斯更新 |
| **做市目标** | 极小化库存方差与极大化终期效用 | 剔除逆向选择后实现零期望亏损 |

**题目**：判断：“在 Avellaneda-Stoikov 模型中，当标的资产波动率 $\sigma$ 大幅上升时，做市商给出的买卖总价差（Total Spread $\delta^a + \delta^b$）会随之拉宽。”

> [!question]- 答案解析
> **答案**：正确。公式中 $\delta^a + \delta^b = \gamma \sigma^2 (T-t) + \dots$，总价差与方差 $\sigma^2$ 成正比。波动率越大，做市商承担的每单位时间库存风险越高，必须拉宽价差以索取更高的风险补偿。

### 第 4 题：变式/综合（中等）
**题目**：在实盘高频做市中，除了使用 AS 模型动态调整报价外，为什么通常还要设置硬性“最大库存限制（Max Inventory Limit $Q_{max}$）”？

> [!question]- 答案解析
> **答案**：
> 因为在极端的单边趋势行情中，仅仅靠价格 Skew 可能无法阻止单边成交，导致库存达到数学模型的极限；设置硬性 $Q_{max}$ 可以在 $|q| \ge Q_{max}$ 时强制停止同向挂单，或者触发 IOC 损单平仓，防止做市商彻底穿仓爆仓。  
> **Obsidian 标签**：`#自测题/库存风控`

### 第 5 题：开放/建模（较难）
**题目**：在连续时间随机控制中，Avellaneda-Stoikov 模型的 HJB 方程为 $\partial_t V + \frac{1}{2} \sigma^2 q^2 \partial_{ss} V + \max_{\delta^a} \lambda(\delta^a) [V(x+s+\delta^a, q-1, s, t) - V] + \max_{\delta^b} \lambda(\delta^b) [V(x-s+\delta^b, q+1, s, t) - V] = 0$。简述利用 Ansfatz 拟设 $V(x,q,s,t) = -\exp(-\gamma x) \exp(-\gamma R(s,q,t))$ 简化该偏微分方程的思路。

> [!question]- 答案解析
> **解析**：
> 1. **分离变量**：利用卡罗什-库恩-塔克及负指数效用的可分离性，将现金 $x$ 从效用函数中提取出来。
> 2. **价值函数化简**：将原三维 PDE（$x, q, s, t$）简化为只关于库存状态 $q$ 和残余时间 $t$ 的常微分方程（ODE）组。
> 3. **无风险套利解**：在 $T-t$ 较短或无穷时域前提下，导出了保留价格 $r(s,q,t) = s - q \gamma \sigma^2 (T-t)$ 的线性闭式近似解。  
> **Obsidian 标签**：`#自测题/HJB求解`
