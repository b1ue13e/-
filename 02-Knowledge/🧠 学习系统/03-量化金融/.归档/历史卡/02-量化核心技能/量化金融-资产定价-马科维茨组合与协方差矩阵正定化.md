# 马科维茨组合与协方差矩阵正定化

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：现代投资组合理论（MPT）的起点。虽然经典马科维茨模型在实盘中常因“误差放大”而失效，但所有的改进模型（如 Black-Litterman、风险平价）以及工业界 Barra 组合优化器，底层的数学形式都是在此基础上发展的。尤其是协方差矩阵非正定导致的无解问题，是量化工程实战中最常见的 Bug 之一。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 手头有 100 只股票，我们预估了每只股票明天的预期收益率。直觉上，我们应该把所有的钱买预期收益率最高的那只（全仓一次性下单）。但是万一预估错了，我们会破产。为了分散风险，我们需要同时买多只股票。那么问题来了：**到底应该给每只股票分配多少权重，才能在满足目标收益的同时，让整个组合的波动（风险）最小？**

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是 CAPM 定价模型的直接推导前置条件。
- **实际应用场景**：公募基金构建指数增强组合（在跟踪误差约束下最大化 Alpha）、对冲基金求解最优多空权重。
- **高频题型/任务**：给定收益向量和协方差矩阵，手算出两个资产的最优权重；在代码中使用 `scipy.optimize` 求解约束最优化问题；处理协方差矩阵非正定的报错。

---

## 3. 学它之前需要哪些前置知识？

1. **[[相关系数、协方差与资产组合分散化 (Covariance, Correlation & Diversification)]]**：必须理解两个资产的协方差如何降低总组合的方差。
2. **二次规划 (Quadratic Programming)**：理解目标函数带有平方项，约束条件为线性的优化问题。

---

## 4. 用直觉语言解释它

> «“这东西其实就像在一个自助餐盘子里搭配营养。”»

- **直觉类比**：股票的预期收益是碳水，波动率是脂肪，相关性是食物之间是否会发生反应。你的目标是保证碳水达到特定值（目标收益）的前提下，摄入最少的脂肪（最小化方差）。
- **为什么很自然**：人们总是厌恶风险的，在同样的预期回报下，天然偏好最平稳的那条路径。
- **一句话直觉本质**：马科维茨模型就是一个带有约束条件的**二次规划求解器**。

---

## 5. 正式定义、核心公式、符号解释

### 1. 核心最优化问题
**目标：最小化组合方差**
$$ \min_{\mathbf{w}} \frac{1}{2} \mathbf{w}^T \Sigma \mathbf{w} $$

**约束条件**：
1. 达到目标预期收益：$ \mathbf{w}^T \mathbf{\mu} = \mu_{target} $
2. 资金满仓（权重和为1）：$ \mathbf{w}^T \mathbf{1} = 1 $
3. （可选）禁止卖空约束：$ w_i \ge 0 $

### 2. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathbf{w}$ | 资产权重向量 | $N \times 1$ 实数向量 | 若允许卖空可为负 |
| $\Sigma$ | 协方差矩阵 | $N \times N$ 半正定矩阵 | 刻画资产间相关性 |
| $\mathbf{\mu}$ | 预期收益率向量 | $N \times 1$ 实数向量 | 必须与协方差周期一致 |

### 3. 协方差矩阵正定化 (Positive Definite Fix)
- **适用条件**：求解上述二次规划问题时，要求 $\Sigma$ 必须是**正定 (Positive Definite)** 或**半正定**的（即对于任意非零向量 $\mathbf{x}$，有 $\mathbf{x}^T \Sigma \mathbf{x} > 0$），否则优化器会报错或陷入局部最优/无穷大。
- **为什么会非正定？**：当样本期数 $T$ 小于资产数量 $N$ 时，协方差矩阵必然不可逆（存在多重共线性）；或者在计算过程中存在缺失值。
- **修正方法**：将 $\Sigma$ 进行特征值分解，将小于等于 0 的特征值强行设为一个极小的正数（如 $1e-8$），然后重新构建矩阵（即 Higham 最近相关矩阵算法）。

---

## 6. 推导思路和思想来源

- **思想来源**：Harry Markowitz 1952 年的论文《Portfolio Selection》。
- **关键“转念”**：不要孤立地看单一资产的风险，而是要把“协方差”作为风险的核心。即：如果两个高风险资产是高度负相关的，把它们组合在一起，整体风险可能会变得极低。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（解析解公式）
对于没有禁止卖空约束的马科维茨模型，可以通过拉格朗日乘子法求得解析解：
构造拉格朗日函数：
$L(\mathbf{w}, \lambda_1, \lambda_2) = \frac{1}{2} \mathbf{w}^T \Sigma \mathbf{w} - \lambda_1 (\mathbf{w}^T \mathbf{\mu} - \mu_{target}) - \lambda_2 (\mathbf{w}^T \mathbf{1} - 1)$
对 $\mathbf{w}$ 求导令为0，得到 $\Sigma \mathbf{w} = \lambda_1 \mathbf{\mu} + \lambda_2 \mathbf{1}$，从而得出最优权重 $\mathbf{w} = \Sigma^{-1} (\lambda_1 \mathbf{\mu} + \lambda_2 \mathbf{1})$。

### 例子 2：实际应用例子（Python 实战求解与正定化）
```python
import numpy as np
from scipy.optimize import minimize

def make_positive_definite(cov_matrix, min_eigval=1e-8):
    # 特征值分解
    eigvals, eigvecs = np.linalg.eigh(cov_matrix)
    # 将负特征值截断
    eigvals = np.maximum(eigvals, min_eigval)
    # 重构矩阵
    return eigvecs @ np.diag(eigvals) @ eigvecs.T

def optimize_portfolio(mu, cov, target_return):
    cov = make_positive_definite(cov)
    n = len(mu)
    
    def objective(w):
        return 0.5 * np.dot(w.T, np.dot(cov, w))
        
    constraints = [
        {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},          # 权重和为1
        {'type': 'eq', 'fun': lambda w: np.dot(w.T, mu) - target_return} # 目标收益
    ]
    bounds = tuple((0, 1) for _ in range(n)) # 禁止卖空
    
    res = minimize(objective, np.ones(n)/n, bounds=bounds, constraints=constraints)
    return res.x
```

## 8. 常见误区和易混概念

### 误区 1：“马科维茨模型在实战中完美无缺”
- **错误直觉**：既然它是最优解，实盘就直接用它给 1000 只股票算权重。
- **为什么错（误差放大器效应）**：优化器就像一个“误差放大器”。输入参数 $\mathbf{\mu}$ 极其难以预测，只要有一点估计误差，优化器就会把极端的权重分配给“预估收益略高、协方差略低”的资产，导致最终权重高度集中在少数几只股票上（Corner Solutions）。
- **正确理解**：实战中必须对协方差进行收缩（Shrinkage），对收益引入贝叶斯先验（Black-Litterman），并加入大量的行业和个股权重上限约束。
