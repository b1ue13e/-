# Johansen 检验：协整秩、迹统计量与最大特征值统计量

广义特征值和对数似然比检验的数学公式初看像是一堆无意义的符号，但如果把它拆解开，你会发现这两个统计量其实是**两个不同风格的“侦探”**——一个喜欢大包大揽的“全局扫荡官”，另一个是步步为营的“精准狙击手”。

它们的核心任务只有一个：**帮你在多只股票中，数出到底存在几条真正的“绳子”（协整向量）。**

为了彻底拆解这两个公式，我们需要由浅入深，先剥开它们共同的“数学心脏”，再看它们的兵分两路。

## 核心密码：解构 $-\ln(1 - \hat{\lambda}_i)$ 的数学心脏

在看具体公式前，我们必须先看懂两个公式里都高频出现的灵魂项：$-T \ln(1 - \hat{\lambda}_i)$。

前面讲过，Johansen 检验算出来了一组从大到小排列的特征值：$1 > \hat{\lambda}_1 > \hat{\lambda}_2 > \dots > \hat{\lambda}_n \ge 0$。每一个 $\hat{\lambda}_i$ 都代表一条潜在“绳子”的均值回归强度。

### 1. 为什么套了一个 $\ln(1 - \hat{\lambda})$？

我们可以用极端值来做一次直觉推演：

- **情况 A：假设某条绳子超级强，$\hat{\lambda}_i \to 1$（几乎完美平稳回归）**
    
    那么 $1 - \hat{\lambda}_i \to 0$。我们知道 $\ln(0)$ 会趋向于 $-\infty$。
    
    加上外面的负号，$-\ln(1 - \hat{\lambda}_i) \to \boldsymbol{+\infty}$。
    
    **数学含义**：特征值越强，这个变换算出来的“得分”就**高得爆炸**。
    
- **情况 B：假设某个组合纯粹是随机游走噪声，$\hat{\lambda}_i \to 0$**
    
    那么 $1 - \hat{\lambda}_i \to 1$。而 $\ln(1) = 0$。
    
    加上负号，$-\ln(1 - \hat{\lambda}_i) \to \mathbf{0}$。
    
    **数学含义**：如果是个废物噪声，这个变换算出来的“得分”就**接近于 0**。
    

### 2. 为什么前面还要乘以样本量 $T$？

$T$ 代表你用来测试的数据有多少天（时间步长）。在统计学里，数据量越大，证据越确凿。同样的偏离幅度，在 1000 天的数据里出现和在 10 天的数据里出现，其统计显著性是完全不同的。乘以 $T$ 是为了把这个“得分”放大为具有统计学意义的**似然比卡方统计量**。

> 💡 **一句话总结它的底层逻辑**：
> 
> 这个数学结构是一个 **“放大镜兼计分器”**。它把接近 1 的“强协整信号”放大成极大的正数，把接近 0 的“垃圾噪声”直接抹平为 0。

## 1. 迹统计量（Trace Statistic）：全局扫荡官

现在我们看第一个公式：

$$J_{\text{trace}}(r) = -T \sum_{i=r+1}^n \ln(1 - \hat{\lambda}_i)$$

### 1. 拆解求和符号 $\sum_{i=r+1}^n$

注意看它的下限是 $i = r+1$，上限是 $n$。这意味着，**它是把从第 $r+1$ 个开始、直到最后一个的所有特征值的“得分”全部加起来。**

### 2. 它的原假设（$H_0$）逻辑

- **原假设 $H_0$**：协整向量的个数**小于或等于** $r$ 个。
    
- **潜台词**：假设市场里最多只有 $r$ 条绳子，那么剩下的（从第 $r+1$ 到第 $n$ 个）线性能量组合**应该全都只是垃圾噪声**。
    
- **判决过程**：如果原假设是真的，那么剩下的 $\hat{\lambda}_{r+1} \dots \hat{\lambda}_n$ 应该全都接近于 0。通过刚才的放大镜一算，它们的得分加起来也应该非常小。
    
- **拒绝原假设**：如果算出来的 $J_{\text{trace}}(r)$ **大于临界值**，说明剩下的这些特征值里“脏东西”太多了，它们加起来的能量不可忽视（有大特征值造反）。因此，我们拒绝原假设，认为绳子数量**绝对不止 $r$ 条**！
    

### 3. 实战中的“盲盒关卡”闯关流

我们在 Python 里跑 Trace 检验时，它是一个**从左到右的闯关游戏**：

```
[第1关: 测试 r=0] ──(大干临界值,拒绝)──> [第2关: 测试 r=1] ──(大干临界值,拒绝)──> [第3关: 测试 r=2] ──(小于临界值,认输) ──> 终点: 判定存在2条绳子
```

1. **第一关（$r=0$）**：假设市场一条绳子都没有（$r \le 0$）。公式把所有特征值的得分全加起来。如果值很大，拒绝！说明至少有一条绳子。闯入下一关。
    
2. **第二关（$r=1$）**：假设市场最多只有 1 条绳子（$r \le 1$）。公式把扣除老大后的剩余特征值全加起来。如果值还是很大，拒绝！说明至少有两条绳子。闯入下一关。
    
3. **第三关（$r=2$）**：假设市场最多有 2 条绳子（$r \le 2$）。公式把扣除老大、老二后的剩余特征值加起来。这一次，算出来的 $J_{\text{trace}}$ 终于**小于**临界值了。侦探说：“行了，剩下的确实都是噪声了。”
    
4. **最终结论**：游戏结束，确定有 **2 条**合法的协整绳子。
    

## 2. 最大特征值统计量（Maximum Eigenvalue Statistic）：精准狙击手

接下来看第二张图：

$$J_{\max}(r, r+1) = -T \ln(1 - \hat{\lambda}_{r+1})$$

### 1. 它与 Trace 的最大区别

注意看，这个公式里**没有求和符号 $\sum$**！它不看后面那一整串垃圾噪声的累加和，它一双鹰眼**死死盯着下一个特定的特征值：$\hat{\lambda}_{r+1}$**。

### 2. 它的原假设（$H_0$）逻辑

- **原假设 $H_0$**：协整向量的个数**恰好等于** $r$ 个。
    
- **备择假设 $H_1$**：协整向量的个数**恰好等于** $r+1$ 个。
    
- **判决过程**：既然已经确认了前 $r$ 条绳子，现在我们就来看紧接着的这第 $r+1$ 个组合。如果它是噪声，它的特征值 $\hat{\lambda}_{r+1}$ 就会很小，算出来的 $J_{\max}$ 就会很小，我们承认它等于 $r$；如果这单单一个组合的得分 $J_{\max}$ **飙得比临界值还高**，说明这第 $r+1$ 个组合也是条正儿八经的绳子，我们判定绳子数等于 $r+1$。
    

## 总结：双剑合璧

在实际量化研究中，这两个统计量各自承担了不同的风控视角：

|**侦探角色**|**统计量名称**|**特点**|**交易员大白话**|
|---|---|---|---|
|**全局扫荡官**|**迹统计量 $J_{\text{trace}}$**|整体打包，看剩下的特征值里是否有**残留的总能量**。|“别废话，放眼望去，后面那一锅粥里还有没有真货？”|
|**精准狙击手**|**最大特征值统计量 $J_{\max}$**|一对一决斗，只测试**下一个特征值是否足够强壮**。|“老几位先站好，就说这第 $r+1$ 兄弟，你到底算不算条好汉？”|

### 避坑指南：如果两个侦探打架了怎么办？

在有些诡异的行业组合数据里，你会发现 Python 输出的结果中，Trace 统计量告诉你存在 2 条协整关系，而 Max Eigenvalue 统计量却傲娇地告诉你只存在 1 条。

这时候，成熟的量化团队通常会采取**保守策略**：以较小的那个 $r$（即只有1条绳子）作为最终实盘的对冲依据，或者优先信任 **Trace 统计量**（因为它对高维整体波动的稳健性在多数计量经济学仿真中表现更好）。

到现在为止，你已经不仅掌握了协整的哲学、双资产的EG两步法，连多资产高维的 Johansen 检验最核心的两大公式的数理逻辑也被你彻底吃透了。

## 可定位依据与失效复核

本卡的复核对象是 **Johansen 检验：协整秩、迹统计量与最大特征值统计量**，而不是只复述一个公式。对 **Johansen 检验：协整秩、迹统计量与最大特征值统计量** 的独立验证重点是：分别报告迹统计量与最大特征值统计量，并把协整秩选择对滞后阶数和确定性项的敏感度列成表。

### 权威来源与定位

1. Engle 与 Granger (1987), *Co-Integration and Error Correction*, DOI: 10.2307/1913236。用于复核“分别报告迹统计量与最大特征值统计量，并把协整秩选择对滞后阶数和确定性项的敏感度列成表”。
2. Johansen (1988), *Statistical Analysis of Cointegration Vectors*, DOI: 10.1016/0304-4076(88)90041-3。用于复核“分别报告迹统计量与最大特征值统计量，并把协整秩选择对滞后阶数和确定性项的敏感度列成表”。
3. statsmodels VECM/Johansen 官方文档：https://www.statsmodels.org/stable/vector_ar.html；配套定位为 Hamilton, ISBN 9780691042893, Chapter 19。用于复核“分别报告迹统计量与最大特征值统计量，并把协整秩选择对滞后阶数和确定性项的敏感度列成表”。

### 失效边界与验收协议

- **成立条件**：先写清数据时点、估计窗口、交易摩擦和分布/市场结构假设，再运行模型。
- **反例压力测试**：分别报告迹统计量与最大特征值统计量，并把协整秩选择对滞后阶数和确定性项的敏感度列成表。
- **最小实验**：固定随机种子或冻结原始数据快照，同时保存基线、破坏条件后的对照组、关键中间量与失败日志。
- **通过标准**：结论必须在样本外仍保持方向一致；若成本、延迟、参数扰动或结构突变使结论反转，就把该情形登记为适用边界而不是删除失败结果。

### 最小可运行反例/性质测试

```python
import numpy as np
from statsmodels.tsa.vector_ar.vecm import coint_johansen

rng = np.random.default_rng(7)
x = np.cumsum(rng.normal(size=800))
y = 1.6 * x + rng.normal(scale=0.4, size=800)
result = coint_johansen(np.column_stack([y, x]), det_order=0, k_ar_diff=1)
assert result.lr1[0] > result.cvt[0, 1]  # 5% 下至少拒绝 r=0
print(result.lr1, result.cvt[:, 1])
```
