# 🧭 量化金融开源作业源地图

> 目标不是“搜集量化仓库”，而是筛出能被改造成 **李宏毅式真实作业包** 的上游来源。
>
> 评价优先级：**连续作业骨架 > 可复现研究流程 > baseline 可运行性 > 数据可获得性 > 文档清晰度**。

---

## 🎯 本地图怎么用

把开源来源分成三层：

1. **课程主线源**：适合直接抽象成 HW01-HW08 / HW01-HW12 连续作业。
2. **工程 baseline 源**：适合给某份作业提供 starter、baseline、模块结构和报告模板。
3. **参考扩展源**：适合做 Boss 题、专题实验或阅读材料，不直接当正式作业骨架。

## 🧪 对“真实作业包”标准的适配判断

| 判断问题 | CS7646 | AI for Trading | Qlib | AlphaEngine | quant-equity-factor-research-system |
|:---|:---:|:---:|:---:|:---:|:---:|
| 有连续作业骨架 | ✅ | ⚠️ | ❌ | ❌ | ❌ |
| 有真实研究工作流 | ⚠️ | ⚠️ | ✅ | ✅ | ✅ |
| 有 starter 可抽取 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 有测试/审计意识 | ⚠️ | ⚠️ | ✅ | ⚠️ | ✅ |
| 易改造成 README + baseline + report + rubric | ✅ | ✅ | ✅ | ✅ | ✅ |
| 可直接当正式作业包 | ❌ | ❌ | ❌ | ❌ | ❌ |

> 结论：这些仓库大多只能当 **上游资产**，不能直接视作“正式作业包”。  
> 真正进入学习系统前，仍然要补 `README / starter / data card / tests / baseline / report / rubric / smoke test`。

## 🧭 建议的吸收策略

### 路线 A：先做连续课程骨架

- 用 `CS7646` 负责“从投资组合到策略学习”的主线顺序。
- 用 `AI for Trading` 补“专题项目感”和更现代的金融 ML 主题。
- 用你本地已有的 HW01-HW12 说明书继续当正式出口。

### 路线 B：先做工程化样板课

- 用 `Qlib + AlphaEngine + quant-equity-factor-research-system` 做一门偏研究工程的“量化金融实验课”。
- 适合你现在已经在走的 `HW17-Qlib因子研究与成本敏感回测` 路线。

### 我的推荐

先走 **A+B 组合**：

1. `CS7646` 负责 **HW01-HW08 连续骨架**；
2. `AI for Trading` 负责 **HW09-HW12 专题增强**；
3. `Qlib` 负责 **HW17 Capstone**；
4. `AlphaEngine / quant-equity-factor-research-system` 负责 **高级 baseline 和 evidence 模板**。

## 🚦当前结论

- **可以找到**适合量化金融自学设计的开源来源。
- **最像李宏毅机器学习作业骨架** 的是 `CS7646`。

- **最适合做高级 baseline** 的是 `AlphaEngine` 和 `quant-equity-factor-research-system`。
- 下一步不该继续泛搜，而应该进入 **作业序列重构**。
