## 版本与镜像策略

- QuantEcon 与 MIT OCW 使用官方网页链接；不保存整站镜像。
- ML4T 只引用公开课程目标、软件要求和 Honor Code；不分发课程私有数据、模板或评分器。
- Qlib 代码实验必须记录 pyqlib 版本或 Git commit；行情数据必须另记来源、日期、校验值和再分发条款。
- 课程代码、测试和本地任务放在 03-Projects/金融与时序/03-量化金融/；大型行情与缓存不进入知识卡目录。
- 无法从官方页面核验的具体题面、许可证或版本保持 [待验证]，且不得作为正式市场证据。

## 多源融合裁决

### 术语统一

- return 统一译为“收益率”，simple return 与 log return 分开。
- availability time 统一译为“信息可得时间”，不与财报期末日混用。
- backtest 统一指包含信号、持仓、成交、成本和评价的研究链路；单一净值曲线不称为完整回测。
- smoke 只表示工程入口可运行，不代表真实数据或策略有效。

### 去重与冲突

- QuantEcon 负责讲授与计算主线，MIT OCW 负责数学练习，不按两套目录机械拼接。
- ML4T 与 Qlib 都涉及回测；前者只提供公开工程目标，后者提供可开源复现的基础设施。
- Qlib 的 MIT 许可证只覆盖代码；社区/第三方行情的许可单独判断。
- 同名或重复卡以课程阶段 MOC 中列出的卡为准；明确标记 triage_decision: merged 的隔离页不进入正式路线。
