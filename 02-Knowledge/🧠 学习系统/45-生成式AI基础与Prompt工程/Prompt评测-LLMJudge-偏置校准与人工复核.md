# Prompt 评测：LLM-as-a-Judge 的偏置、校准与人工复核

## 0. 先判断它值不值得深挖

- **类别**：**B 类（全面扩展）**。
- **判断理由**：开放式输出难以自动打分，模型评审可扩展但会受位置、长度、风格和自偏好影响，必须经过人工校准。

## 1. 这个知识点解决什么问题？

> 两段回答都没有标准答案，人工逐条评分太贵；直接让另一个模型选优虽然方便，却可能偏爱更长答案或第一个候选。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：Judge 是 Prompt 优化、回归测试和 Agent 评测的常见组件。
- **实际场景**：摘要、写作、帮助性、风格和多维 Rubric。
- **高频任务**：成对比较、绝对评分、位置交换、人工一致率。

## 4. 用直觉语言解释它

> “请 AI 当裁判可以降低成本，但裁判也要考试：先拿人工金标准校准，再持续抽查。”

- Rubric 要把“好”拆成事实、覆盖、简洁、安全等维度。
- 候选顺序互换能检测位置偏置。
- 人工复核集中在低置信、分歧和高风险样本。
- 一句话本质：Judge 是待评测的测量工具，不是真值本身。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

Judge $J(x,y,r)$ 根据输入 $x$、候选输出 $y$ 和评分规则 $r$ 生成分数或偏好。

### 2. 核心公式

与人工标签的一致率：

$$Agreement=\frac{1}{N}\sum_i\mathbf{1}[J_i=H_i].$$

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $J_i$ | Judge 判定 | 可能有偏置 |
| $H_i$ | 人工金标准 | 也需标注规范 |
| $r$ | Rubric | 应逐项可判定 |

### 4. 常见变体与适用条件

- 成对偏好适合比较两个版本；绝对评分适合监控阈值。
- 有确定真值时优先程序指标，不要滥用 Judge。
- 高风险决策不由单一 Judge 自动放行。

## 6. 推导思路和思想来源

- **困难**：开放输出没有唯一参考答案。
- **关键转念**：用 Rubric 将主观质量拆成多个可判断维度。
- **主线**：人工标注小集 → Judge Prompt → 位置互换 → 一致率/偏置分析 → 阈值与人工路由。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

Judge 与人工在 20 条中一致 16 条，一致率 80%。交换 A/B 顺序后有 4 条翻转，位置翻转率 20%，不能只报告一致率。

### 例子 2：中等例子

摘要 Judge 偏爱长文。Rubric 应分别评分“关键事实覆盖”和“冗余”，并加入同内容不同长度的对照样本。

### 例子 3：实际应用例子（可运行 Python）

```python
# 输入：Judge 与人工二元标签；输出：一致率。
judge = [1, 1, 0, 1, 0]
human = [1, 0, 0, 1, 0]
agreement = sum(a == b for a, b in zip(judge, human)) / len(human)
print(round(agreement, 3))
# 预期：0.8。
```

## 8. 常见误区和易混概念

### 误区 1：Judge 模型更强就不需要校准
- **为什么错**：能力强不消除位置、长度、自偏好和领域偏差。

### 误区 2：一个总分足够
- **为什么错**：总分掩盖事实错误、安全失败和风格取舍。

### 概念对比表

| 方法 | 优点 | 局限 | 优先场景 |
| :--- | :--- | :--- | :--- |
| 程序指标 | 客观可复现 | 覆盖有限 | JSON、分类、单测 |
| 人工评审 | 质量高 | 贵、慢 | 金标准与高风险 |
| LLM Judge | 可扩展 | 有系统偏置 | 开放输出初筛 |

## 11. 自测题：5 道

1. Judge 是真值吗？
   > [!question]- 答案解析 `#自测题/基础`
   > 不是；它是需要校准的测量工具。
2. 什么是位置偏置？
   > [!question]- 答案解析 `#自测题/基础`
   > 候选内容不变但交换呈现位置后，评审偏好系统性变化。
3. 有单元测试时还应先用 Judge 吗？
   > [!question]- 答案解析 `#自测题/中等`
   > 不应；确定性真值优先用程序验证。
4. 为什么要多维 Rubric？
   > [!question]- 答案解析 `#自测题/中等`
   > 事实性、覆盖、简洁、安全可能相互独立，总分会掩盖关键失败。
5. 如何用 100 条预算建立可靠 Judge？
   > [!question]- 答案解析 `#自测题/较难`
   > 分层抽样人工双标，校准 Judge，做顺序/长度对照，将分歧和高风险样本转人工并持续抽查。
