# 阶段 1：模型心智模型

## 为什么现在学

Prompt 不是脱离模型的措辞技巧。先理解条件概率、上下文计算、训练目标和解码，才能判断失败来自任务规格、模型能力、证据不足还是采样配置。本阶段只建立足够解释行为的模型心智；从零实现另放在可选阶段 2，不阻塞 Prompt 主线。

## 学完能做什么

- 画出 Token → Transformer → logits → 概率 → 解码的完整生成循环。
- 区分参数知识、上下文知识、外部检索和训练侧适配。
- 比较自回归、VAE、GAN、扩散与多模态条件生成的适用边界。
- 为一次生成实验固定模型、上下文、解码和评测边界。

## 学习顺序

1. [[生成式AI-基础-概率生成Token与能力边界]]：先建立“概率不等于真值”的底线。
2. [[Transformer与大语言模型-架构-Transformer工作原理]]：理解上下文怎样通过注意力被计算。
3. [[Transformer与大语言模型-训练-GPT与自回归语言模型]]：连接因果 Mask、下一 Token 目标与上下文学习。
4. [[生成控制-解码-温度Top-k与Top-p]]：区分模型分布和推理时选择策略。
5. [[模型适配-对齐-SFT-RLHF与DPO]]：判断何时 Prompt 已到边界，需要训练侧改变行为分布。
6. [[生成式AI-模型家族-VAE-GAN与扩散模型]]：建立文本之外的生成模型比较坐标。
7. [[生成式AI-多模态-条件生成与基础模型]]：把条件生成扩展到图像、音频与跨模态证据。

前 5 张构成 Prompt 主线的必修顺序；后 2 张用于“生成式 AI 基础”的广度，不要求实现训练。

## 复习与回顾

- 完成第 4 张卡后，闭卷画一次生成循环并标出可控变量与不可控变量。
- 完成第 7 张卡后，交错比较“文本自回归 / 扩散 / 多模态条件生成”三个案例。
- 若把“高概率”误当成“真实”或把“对齐”误当成“知识更新”，返回第 1、5 张卡，而不是重新通读全部阶段。
