# 模型适配与对齐：SFT、RLHF 与 DPO
---
## 0. 学习边界
- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：基座模型只会续写，不天然遵循人类意图；SFT、RLHF 与 DPO 解释了聊天模型如何获得指令跟随与偏好行为，也帮助判断何时 Prompt 已到边界、需要训练侧适配。
---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 预训练 GPT 只会"接话"：问它"1+1="它可能接"1+1=2 是数学问题…"而不是直接答"2"；让它写诗它写说明文；有害内容也照单全收。预训练目标是"预测下一个词"，不是"满足用户意图"。
> 对齐的回答：**用人类偏好把模型"驯化"成助手**——① **SFT**：用"指令-回答"数据监督微调（学会格式与服从）；② **RLHF**：训练奖励模型打分，用 PPO 强化学习最大化奖励（学会"人类觉得好"）；③ **DPO**：跳过奖励模型，直接用偏好对做隐式奖励优化（更简单更稳）。对齐让模型有用（helpful）、诚实（honest）、无害（harmless）。
---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：对齐把 [[Transformer与大语言模型-训练-GPT与自回归语言模型|预训练语言模型]] 变成更可用的指令模型；工具调用、对话行为和多模态指令跟随都依赖训练侧行为塑形，但仍需运行时验证。
- **实际应用场景**：ChatGPT/Claude 类产品训练流水线、企业私有助手对齐、安全过滤（拒绝有害请求）。
- **高频题型/任务**：面试"RLHF 三步流程""PPO 的 KL 惩罚为什么必要""DPO 的隐式奖励""对齐税是什么、怎么缓解"。

## 4. 用直觉语言解释它
> «"对齐像'驯服一匹野马'：预训练模型是野马（只会按本能奔跑=续写）。SFT 是'套缰绳'：给它看大量'问题-标准答案'，教会它基本服从。RLHF 是'胡萝卜加大棒'：先请人类给回答打分（训练一个'评委'奖励模型），再用强化学习让模型朝着'评委喜欢'的方向微调——但为了防止它钻空子（只说漂亮话、胡编），还要拽住缰绳（KL 惩罚，不许离原模型太远）。DPO 更聪明：'既然评委喜欢 A 甚于 B，那直接让模型提高 A 的概率、降低 B 的概率就行'——连评委都不用训练了。"»
- **直觉类比/几何图像**：RLHF = 奖励模型（评委）+ PPO（选手）+ KL（缰绳）；DPO = 把"评委偏好"直接写成损失函数。
- **为什么很自然**：人类反馈是最真实的监督信号；把"偏好"转化为可优化目标（奖励/隐式奖励）是 RL 的标准思路。
- **一句话直觉本质**：**"对齐 = 让模型输出符合人类偏好：SFT 教格式，RLHF 用奖励模型+PPO 学偏好（带 KL 约束），DPO 用偏好对直接优化——本质都是调整输出分布，使其偏向人类更喜欢的回答。"**
---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**SFT**：在"指令-回答"数据上监督微调，$\mathcal{L}=-\log\pi_\theta(y|x)$。
**RLHF（InstructGPT 2022）**：① 训练奖励模型 $r_\phi(x,y)$（人类排序数据）；② PPO 最大化 $\mathbb{E}[r_\phi] - \beta D_{KL}(\pi_\theta\|\pi_{\text{ref}})$。
**DPO（Rafailov 2023）**：用偏好对 $(y_w, y_l)$ 直接优化策略，隐式奖励 $r(x,y)=\beta\log\frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)}$。
### 2. 核心公式
**RLHF 目标**：
$$\max_{\pi_\theta}\ \mathbb{E}_{x\sim\mathcal{D}, y\sim\pi_\theta}\big[r_\phi(x,y)\big] - \beta\, \mathbb{E}_{x}\big[D_{KL}(\pi_\theta(\cdot|x)\,\|\,\pi_{\text{ref}}(\cdot|x))\big]$$
**DPO 损失**：
$$\mathcal{L}_{\text{DPO}} = -\mathbb{E}_{(x,y_w,y_l)}\left[\log\sigma\left(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]$$
### 3. 符号说明表
| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\pi_\theta$ | 策略（被对齐模型） | 分布 | 更新对象 |
| $\pi_{\text{ref}}$ | 参考模型（SFT 后） | 分布 | 冻结 |
| $r_\phi$ | 奖励模型 | $\mathbb{R}$ | 人类偏好代理 |
| $y_w, y_l$ | 偏好对（优/劣） | 文本 | DPO 数据 |
| $\beta$ | KL/温度系数 | $>0$ | 约束强度 |
| $x$ | 指令 | 文本 | 输入 |
### 4. 常见变体与适用条件
- **SFT**：数据质量决定上限；成本低、稳定；但只学"表面风格"，学不会深层偏好。
- **RLHF（PPO）**：效果最强、可在线采样；工程复杂（4 个模型：actor/critic/reward/ref）、不稳定。
- **DPO**：无需奖励模型与 RL 循环，简单稳定；对偏好数据质量敏感，超参 $\beta$ 需调。
- **其他**：RLAIF（AI 反馈代替人工）、KTO、ORPO（合并 SFT 与偏好）。
- **限制条件**：对齐税（安全对齐损伤通用能力）；奖励黑客（模型钻奖励空子）；偏好数据偏差放大。
---
## 6. 推导思路和思想来源
- **最初困难**：语言模型目标（下一词预测）与人类目标（有用/诚实/无害）不一致；文本生成不可微，无法直接对"回答质量"反向传播。
- **直接方法局限**：SFT 只能模仿标注风格；规则过滤治标不治本。
- **关键"转念"**：① 把"质量"变成**可优化的标量**：训练奖励模型 $r_\phi$ 打分（Bradley-Terry 偏好模型：$P(y_w \succ y_l)=\sigma(r(y_w)-r(y_l))$）；② 用**强化学习**优化不可微目标（PPO 策略梯度）；③ 加 **KL 约束**防止模型漂移（奖励黑客与退化）；④ DPO 的洞察：RLHF 的闭式最优策略 $\pi^*(y|x)\propto\pi_{\text{ref}}(y|x)e^{r(x,y)/\beta}$ 可反解出 $r$，于是偏好损失可以直接写成策略比率的函数——**奖励模型被消掉**。
- **推导主线与动机**：偏好（Bradley-Terry）→ 奖励模型 → PPO 优化 → 反解出隐式奖励（DPO）；每步把"人类判断"翻译成数学目标。
- **为什么自然得到此结论**：偏好只提供"相对比较"，而策略比率 $\pi_\theta/\pi_{\text{ref}}$ 正是"相对概率"——两者天然配对。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：DPO 中 $\beta=1$，$\pi_\theta(y_w|x)=0.4$，$\pi_{\text{ref}}(y_w|x)=0.2$，$\pi_\theta(y_l|x)=0.1$，$\pi_{\text{ref}}(y_l|x)=0.3$。计算该样本的 DPO 损失。
- **解题思路与关键步骤**：比率 $w$：$\log\frac{0.4}{0.2}-\log\frac{0.1}{0.3}=\log2-\log\frac13=\log6\approx1.79$；$\sigma(1.79)=\frac{1}{1+e^{-1.79}}\approx0.857$。
- **最终答案**：$\mathcal{L}=-\log0.857\approx0.155$。
- **易错点**：$\sigma$ 输入是"对数比率差"不是概率差；$\beta$ 影响梯度尺度。
- **🤔 追问**：若 $\pi_\theta(y_w)=0.1,\pi_\theta(y_l)=0.4$（模型更喜欢劣答）？—— $\log\frac{0.1}{0.2}-\log\frac{0.4}{0.3}=\log0.375\approx-0.98$，$\sigma(-0.98)\approx0.27$，损失 $0.27$ 变大——梯度把模型推向正确偏好。
### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：为什么 RLHF 必须加 KL 惩罚？—— 无约束时模型会"奖励黑客"：只说评委爱听的空话（如无限重复"好的好的"），或偏离人类语言分布产生退化输出；KL 惩罚 $\beta D_{KL}(\pi_\theta\|\pi_{\text{ref}})$ 把模型钉在参考模型附近，只允许"朝偏好方向小幅移动"——这是"对齐"与"保持能力"的平衡器，也是对齐税的直接来源。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：下面用标准库逐样本计算 DPO 损失，先验证公式、边界与数据 schema；真正训练需另建带 GPU/依赖锁的工程环境：
```python
import math

def dpo_loss(model_chosen: float, reference_chosen: float,
             model_rejected: float, reference_rejected: float,
             beta: float = 0.1) -> float:
    probabilities = (model_chosen, reference_chosen, model_rejected, reference_rejected)
    if any(value <= 0.0 for value in probabilities) or beta <= 0.0:
        raise ValueError("概率与 beta 必须为正")
    margin = math.log(model_chosen / reference_chosen) - math.log(
        model_rejected / reference_rejected
    )
    return math.log1p(math.exp(-beta * margin))

loss = dpo_loss(0.4, 0.2, 0.1, 0.3, beta=1.0)
print(round(loss, 3))
assert round(loss, 3) == 0.154
```

## 8. 常见误区和易混概念
### 误区 1：以为"SFT 之后模型就已经对齐了"
- **错误直觉**：教了标准答案就会了。
- **为什么错**：SFT 只学"指令-回答"的格式与分布，无法学会"哪些回答更符合人类深层偏好"（SFT 数据里没有偏好排序）；对分布外指令依然会犯错。
- **正确理解**：SFT 是对齐第一步（教服从），偏好学习（RLHF/DPO）才是对齐核心（教好坏）。
### 误区 2：以为"DPO 和 RLHF 效果完全一样"
- **错误直觉**：DPO 论文说等价。
- **为什么错**：DPO 在"静态偏好数据 + Bradley-Terry 假设"下与 RLHF 目标等价；但 RLHF 可在线采样探索、奖励模型可迭代更新，实际中 RLHF 上限更高（也更贵更不稳）。
- **正确理解**：DPO 是"便宜且通常足够好"的替代；追求极致用 RLHF。
### 概念对比表
| 概念 | 训练信号 | 优化方式 | 典型场景 |
| :--- | :--- | :--- | :--- |
| SFT（本概念） | 标准答案 | 监督学习 | 格式与服从 |
| RLHF | 奖励模型分数 | PPO 强化学习 | 高质量对齐 |
| DPO | 偏好对 | 隐式奖励+交叉熵 | 轻量对齐 |
| 提示工程 | 无训练 | 输入侧调整 | 零成本对齐 |

| 题号 | 类型 | 难度 | 考查点 |
| :--- | :--- | :--- | :--- |
| 1 | 概念辨析 | 基础 | SFT/RLHF/DPO 三步定位 |

### 题目与解析
#### 1. SFT、RLHF、DPO 各自的训练信号是什么？
> [!question]- 答案解析
> - **答案**：SFT：标准答案（监督）；RLHF：奖励模型分数（人类排序训练）；DPO：偏好对 $(y_w,y_l)$（直接）。
> - **解析**：信号从"模仿"到"比较"再到"直接偏好"，逐步逼近人类真实判断。`#自测题/基础`
#### 2. $\beta=1$，$\pi_\theta(y_w)=0.3,\pi_{\text{ref}}(y_w)=0.1,\pi_\theta(y_l)=0.2,\pi_{\text{ref}}(y_l)=0.4$，求 DPO 损失。
> [!question]- 答案解析
> - **答案**：$\log\frac{0.3}{0.1}-\log\frac{0.2}{0.4}=\log3+\log2=\log6\approx1.79$；$\mathcal{L}=-\log\sigma(1.79)\approx0.155$。
> - **解析**：模型相对参考模型更喜欢优答（比率 3 > 0.5），损失小；若反过来则损失大。`#自测题/基础`
#### 3. 去掉 KL 惩罚直接最大化奖励会怎样？
> [!question]- 答案解析
> - **答案**：奖励黑客：模型发现高分捷径（重复套话、谄媚、胡编）并过度优化；输出退化、偏离自然语言；分布漂移导致评测崩坏。
> - **解析**：KL 惩罚是"对齐与保持能力"的平衡项；$\beta$ 越大越保守。`#自测题/中等`
#### 4. 什么是"对齐税"？有哪些缓解手段？
> [!question]- 答案解析
> - **答案**：对齐训练（尤其安全对齐）会损伤模型通用能力（推理、创造力、诚实度）——安全拒绝也可能拒绝合法请求。缓解：① 控制 KL 系数与数据配比；② 用弱到强对齐分层；③ 推理时安全开关（只在实际需要时启用安全约束）；④ 能力与安全分阶段训练。
> - **解析**：对齐税本质是"约束分布偏离原分布"的代价，属于 KL 约束的直接后果。`#自测题/中等`
#### 5. 推导：为什么 DPO 不需要显式奖励模型？
> [!question]- 答案解析
> - **答案**：RLHF 的带 KL 约束最优策略有闭式解 $\pi^*(y|x)=\frac{1}{Z(x)}\pi_{\text{ref}}(y|x)\exp(r(x,y)/\beta)$，反解出 $r(x,y)=\beta\log\frac{\pi^*(y|x)}{\pi_{\text{ref}}(y|x)}+\beta\log Z(x)$。代入 Bradley-Terry 偏好概率 $P(y_w\succ y_l)=\sigma(r(y_w)-r(y_l))$，归一化常数 $Z(x)$ 恰好消掉，得到只含策略比率的损失——奖励模型被"反解消除"，直接优化 $\pi_\theta$。
> - **解析**：这是"最优策略闭式解"+"偏好模型代入"两步消元；DPO 因此只需策略与参考模型两个网络。`#自测题/较难`

- 何时应先做 Prompt 或 RAG 而不是微调？::要求仍不明确、知识需要频繁更新或外部可检索时，先改规格或接入检索更便宜且可追溯。
