# 生成式 AI 可靠性：幻觉、校准与事实核验

## 0. 学习边界

- **类别**：**A 类（作业必需）**。
- **判断理由**：流畅错误是生成模型的结构性风险。可靠系统的目标不是声称“零幻觉”，而是降低错误、识别不确定、提供证据并控制损失。

## 1. 这个知识点解决什么问题？

> 模型给出不存在的论文、把材料外知识混入回答、引用了真实网页却不能支撑结论。仅要求“准确回答”无法发现这些失败。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：事实性依赖 RAG、校准、评测与人工接管。
- **实际场景**：研究综述、法规、医疗、财务和企业知识问答。
- **高频任务**：引用核验、证据覆盖率、拒答阈值、冲突检测。

## 3. 学它之前需要哪些前置知识？

1. [[生成式AI-基础-概率生成Token与能力边界]]：概率自然不等于事实。
2. [[Prompt评测-实验-指标数据集与误差分析]]：可靠性必须用样本和指标衡量。

## 4. 用直觉语言解释它

> “可信回答像审计报告：每个关键结论要么有凭证，要么标明推断，要么明确未知。”

- **内在幻觉**：与给定材料冲突。
- **外在幻觉**：材料没支持却新增事实。
- **校准**：置信表达应与真实正确率相匹配。
- 一句话本质：把“回答”拆成声明、证据和不确定性三部分分别检查。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

将回答拆成原子声明 $c_1,\ldots,c_n$。证据支持率：

$$Support=\frac{\sum_i \mathbf{1}[c_i\text{ 被证据直接支持}]}{n}.$$

### 2. 核心公式

分箱校准误差 ECE：

$$ECE=\sum_b\frac{|B_b|}{N}|acc(B_b)-conf(B_b)|.$$

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $c_i$ | 原子事实声明 | 一句话可能含多个声明 |
| $B_b$ | 置信度分箱 | 如 0.8-0.9 |
| $acc$ | 实际正确率 | 需人工或权威真值 |

### 4. 常见变体与适用条件

- 无来源问题可用内部一致性作弱信号，不能当真值。
- 有来源问题应检查“引用存在、引用相关、引用蕴含结论”。
- 高风险场景采用保守阈值和人工复核。

## 6. 推导思路和思想来源

- **直接方法局限**：整段打“正确/错误”无法定位是哪条声明失败。
- **关键转念**：原子化声明，再逐条对证据。
- **主线**：抽取声明 → 查找证据 → 判断支持/冲突/未知 → 聚合指标 → 设置拒答阈值 → 复盘失败。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

回答含 5 个声明，其中 3 个有直接证据、1 个与证据冲突、1 个未提及，支持率为 $3/5=60\%$；不能因为引用了同一篇文档就算 100%。

### 例子 2：中等例子

“公司 2025 年收入增长 20%，因此市场份额上升。”材料只支持收入增长，不支持市场份额。应拆成两个声明，第二个标记未知或推断。

### 例子 3：实际应用例子（可运行 Python）

```python
# 输入：声明到判定的映射；输出：支持率和需复核声明。
claims = {
    "收入增长20%": "supported",
    "市场份额上升": "unknown",
    "报告发布于五月": "contradicted",
}
supported = sum(value == "supported" for value in claims.values())
score = supported / len(claims)
review = [claim for claim, value in claims.items() if value != "supported"]
print({"support_rate": round(score, 3), "review": review})
# 预期：支持率 0.333，后两条进入复核。
```

## 8. 常见误区和易混概念

### 误区 1：有引用就可靠
- **为什么错**：引用可能不存在、相关但不蕴含、或只支持句子的一部分。

### 误区 2：模型说“我很确定”就是置信度
- **为什么错**：自然语言自信可能未校准，必须在固定数据集上验证。

### 概念对比表

| 概念 | 问题 | 检查方式 | 处置 |
| :--- | :--- | :--- | :--- |
| 冲突 | 与证据相反 | 蕴含/人工核验 | 更正 |
| 未支持 | 证据未提及 | 来源覆盖 | 删除或标推断 |
| 过时 | 曾正确但已变化 | 时间戳与更新源 | 重新检索 |

## 11. 自测题：5 道

1. “引用存在”是否等于“结论被支持”？
   > [!question]- 答案解析 `#自测题/基础`
   > 不等于；还需检查相关性和是否蕴含具体声明。
2. 4 条声明有 3 条支持，支持率多少？
   > [!question]- 答案解析 `#自测题/基础`
   > $75\%$。
3. 为什么要原子化声明？
   > [!question]- 答案解析 `#自测题/中等`
   > 同一句可含多个事实，整句判定会掩盖部分支持和部分错误。
4. 自一致性高就一定真实吗？
   > [!question]- 答案解析 `#自测题/中等`
   > 不一定；模型可能稳定复现同一偏差或训练语料错误。
5. 为法规问答设计保守拒答策略。
   > [!question]- 答案解析 `#自测题/较难`
   > 要求权威且当前的条款证据；关键声明无直接支持、来源过期或来源冲突时拒答并转人工。
