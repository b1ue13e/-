# 图表示学习：不变聚合、消息传递与手性边界

## 0. 学习边界

- **类别**：A 类（MIT HW2 Q15–Q18 主卡）。
- **判断理由**：图输入没有固定邻居顺序；聚合必须不变，同时普通消息传递存在不可区分结构与手性限制。

## 1. 这个知识点解决什么问题？

> 怎样让模型处理任意大小、任意编号的图？为什么两个分子局部连接相同但三维手性不同，普通 GNN 仍可能给出同一表示？

## 2. 为什么它重要？它有什么用？

- 集合/邻域聚合建立置换不变性。
- 消息传递将局部结构逐层传播到节点表示。
- 读出函数把节点集合变成图级预测。
- 表达边界决定何时必须加入边、距离、角度或三维等变特征。

## 3. 学它之前需要哪些前置知识？

1. 图的节点、边、邻接与邻居集合。
2. [[神经网络表达-ReLU分段线性逻辑门与泛化]]：表示能力不等于可训练/泛化。

## 4. 用直觉语言解释它

> “每个节点先听邻居发消息，再把一袋消息用不看顺序的方式汇总；多轮后汇总全图。但如果两张图每轮收到的消息袋都一样，模型就无法区分。”

一句话本质：**不变聚合解决编号问题，也同时限定了模型能看到的结构。**

## 5. 正式定义、核心公式、符号解释

通用 Deep Sets 形式：
$$f(\{x_i\})=\rho\left(\sum_i\phi(x_i)\right),$$
求和可替换为满足置换不变的 mean/max，但表达和计数能力不同。

消息传递第 $l$ 层：
$$m_v^{(l)}=\operatorname{AGG}\{M_l(h_v^{(l)},h_u^{(l)},e_{uv}):u\in\mathcal N(v)\},$$
$$h_v^{(l+1)}=U_l(h_v^{(l)},m_v^{(l)}).$$

图级读出：
$$h_G=\operatorname{READOUT}\{h_v^{(L)}:v\in V\},\quad \hat y=g(h_G).$$

| 聚合 | 不变 | 保留计数 | 主要风险 |
| :--- | :---: | :---: | :--- |
| sum | 是 | 较好 | 规模变化导致幅值变 |
| mean | 是 | 否 | 重复相同元素可能不变 |
| max | 是 | 否 | 丢失频数与非最大信息 |

手性：镜像分子可能具有相同的原子/键邻接，却不能通过旋转重合。只看 2D 拓扑和标量距离的模型可能无法区分，需要有向体积、角度/扭转角或 $E(3)$ 等变结构。

## 6. 推导思路和思想来源

1. 节点重新编号不应改变图级答案，因此邻域与读出必须置换不变。
2. 每层只传播一跳，$L$ 层节点最多聚合 $L$ 跳信息。
3. 若聚合非单射，不同邻居多重集会碰撞；mean/max 特别容易丢计数。
4. 标准 MPNN 区分能力与 1-WL 类似，存在规则图等反例。
5. 分子性质若依赖三维手性，仅靠二维连接无法恢复被输入丢掉的信息。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

邻居特征 `{1,1,3}`：sum=5、mean=5/3、max=3。集合 `{1,3}` 的 max 也为 3，说明 max 无法区分二者。

### 例子 2：中等例子

所有节点初始特征相同的两个 2-regular 图，若每轮每个节点都收到两个相同消息，普通聚合可能保持相同颜色/表示，即使全局连通结构不同。

### 例子 3：可运行 Python

```python
# 输入：邻接表与标量节点特征；输出：一轮 sum 消息传递。
def message_passing(adjacency: dict[int, list[int]], features: dict[int, float]):
    updated = {}
    for node, neighbors in adjacency.items():
        message = sum(features[neighbor] for neighbor in neighbors)
        updated[node] = features[node] + message
    return updated

graph = {0: [1, 2], 1: [0], 2: [0]}
features = {0: 1.0, 1: 2.0, 2: 3.0}
result = message_passing(graph, features)
print(result)
assert result == {0: 6.0, 1: 3.0, 2: 4.0}

renamed_graph = {2: [0, 1], 0: [2], 1: [2]}
renamed_features = {2: 1.0, 0: 2.0, 1: 3.0}
assert message_passing(renamed_graph, renamed_features)[2] == result[0]
```

## 8. 常见误区和易混概念

- “输入顺序固定”不能替代置换不变设计，换编号就会失效。
- 多加层不一定解决表达限制，还可能 oversmoothing。
- 距离对镜像保持不变，所以只有 pairwise distance 不一定能识别手性。
- 高验证分数不证明模型学到化学因果，可能利用 scaffold/数据泄漏。

| 概念 | 变换 | 期望性质 | 示例 |
| :--- | :--- | :--- | :--- |
| 置换不变 | 节点编号变化 | 图输出不变 | 分子性质 |
| 置换等变 | 节点编号变化 | 节点输出同样重排 | 节点分类 |
| 旋转不变 | 3D 坐标旋转 | 标量性质不变 | 能量 |
| 旋转等变 | 3D 坐标旋转 | 向量输出同步旋转 | 力 |

## 🃏 Anki 卡片

Q: 为什么 GNN 聚合器必须置换不变？
A: 节点编号和邻居枚举顺序不是图的语义，改变编号不应改变图级答案。

Q: 普通 2D MPNN 为什么可能无法识别手性？
A: 对映异构体可有相同邻接和距离，而手性需要反射敏感的三维方向信息。
