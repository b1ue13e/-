## 2. 为什么它重要？它有什么用？

- **表达能力**：偏置、激活与深度决定决策边界能否平移、弯折和组合。
- **训练机制**：链式法则把总损失分解为局部导数乘积。
- **优化边界**：参数对称性和层间乘积使神经网络目标通常非凸，训练只能寻找好解而非保证全局最优。

## 3. 学它之前需要哪些前置知识？

1. [[课程前置-概率向量与Softmax最小补丁]]：向量、点积与 softmax。
2. 一元导数：知道 $(f\circ g)'(x)=f'(g(x))g'(x)$；本卡把它推广到计算图。

## 4. 用直觉语言解释它

> “神经元像可移动、可翻折的纸片；网络把纸片层层拼成边界。反向传播像沿装配单倒查每个零件对最终误差的责任。”

- 无偏置直线必须经过原点；有偏置后才能平移。
- ReLU 在 0 处折弯，组合后形成分段线性函数。
- 梯度是局部最陡上升方向，负梯度给局部下降方向，不承诺全局最优。

## 5. 正式定义、核心公式、符号解释

凸函数满足：对任意 $x,y$ 与 $\lambda\in[0,1]$，

$$f(\lambda x+(1-\lambda)y)\le\lambda f(x)+(1-\lambda)f(y).$$

线性分类边界为 $w^Tx+b=0$；当 $b=0$ 时必过原点。对计算图 $x\to y=Wx\to u=\operatorname{ReLU}(y)\to L$：

$$\frac{\partial L}{\partial x}=W^T\frac{\partial L}{\partial y},\qquad
\frac{\partial L}{\partial y}=\frac{\partial L}{\partial u}\odot\mathbf{1}[y>0].$$

| 符号 | 含义 | 范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $w,b$ | 超平面法向量与偏置 | 向量、标量 | $b$ 控制平移 |
| $W$ | 线性层权重 | 矩阵 | 反传使用 $W^T$ |
| $\odot$ | 逐元素乘法 | 同形向量 | 不是点积 |
| $\eta$ | 学习率 | 正数 | $\theta\leftarrow\theta-\eta\nabla L$ |

## 6. 推导思路和思想来源

1. **几何**：单个线性单元只能按超平面分区；偏置决定超平面是否必须经过原点。
2. **表达**：ReLU 把线性函数截成两段，多神经元、多层组合出更多分段区域。
3. **训练**：每个节点只需知道上游梯度和自身局部导数，按链式法则相乘。
4. **非凸**：两层参数以乘积/激活组合进入损失，交换隐藏单元等参数对称会产生多个等价解与鞍点。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

$y=2x$，$u=\operatorname{ReLU}(y)$，$L=(u-3)^2/2$。当 $x=1$ 时，$y=2,u=2$，$\partial L/\partial u=-1$，ReLU 导数为 1，所以 $\partial L/\partial x=(-1)\times1\times2=-2$。

### 例子 2：中等例子

无偏置分类器 `sign(wᵀx)` 不能把一条不经过原点的目标直线作为边界：所有满足 $w^Tx=0$ 的点都构成经过原点的超平面。增加 $b$ 后，$w^Tx+b=0$ 可平移。

### 例子 3：实际应用例子（可运行 Python）

```python
# 输入：标量 x、w、b、目标；输出：前向损失与手写梯度，并做有限差分检查。
def loss_and_grad(x: float, w: float, b: float, target: float):
    pre_activation = w * x + b
    activation = max(0.0, pre_activation)
    loss = 0.5 * (activation - target) ** 2
    relu_grad = 1.0 if pre_activation > 0.0 else 0.0
    upstream = activation - target
    return loss, upstream * relu_grad * x, upstream * relu_grad

x, w, b, target = 2.0, 1.5, 0.5, 4.0
loss, grad_w, grad_b = loss_and_grad(x, w, b, target)
epsilon = 1e-6
plus = loss_and_grad(x, w + epsilon, b, target)[0]
minus = loss_and_grad(x, w - epsilon, b, target)[0]
numerical_grad = (plus - minus) / (2 * epsilon)
print(loss, grad_w, grad_b, numerical_grad)
assert abs(grad_w - numerical_grad) < 1e-5
```

## 8. 常见误区和易混概念

- **误区**：ReLU 是凸函数，所以整个网络对参数也是凸的。输入上的凸性不等于多层参数联合目标的凸性。
- **误区**：梯度下降一定找到全局最优。非凸目标通常只有局部下降保证。
- **误区**：无偏置网络只是少一个参数。它还失去平移边界的能力。

| 概念 | 核心问题 | 关键区别 | 场景 |
| :--- | :--- | :--- | :--- |
| 凸函数 | 弦是否在图像上方 | 性质针对指定自变量 | 判断目标结构 |
| 线性边界 | 如何划分空间 | 无偏置必过原点 | 表达能力 |
| 反向传播 | 如何高效算梯度 | 链式法则的动态规划 | 参数训练 |
| 梯度下降 | 如何更新参数 | 局部一阶优化 | 训练循环 |

## 🃏 Anki 卡片

Q: 为什么无偏置线性分类边界必过原点？
A: 边界是 w^T x=0，x=0 恒满足；偏置 b 才允许超平面平移。

Q: 反向传播的本质是什么？
A: 在计算图上复用链式法则，从损失向输入逐节点传播上游梯度乘局部导数。
