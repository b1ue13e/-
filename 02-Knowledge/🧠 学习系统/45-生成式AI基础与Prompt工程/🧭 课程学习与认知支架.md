# 🧭 课程学习与认知支架

## 1. 学习负荷与节奏

- **建议周期**：小白 14 周、每周 7–9 小时；已掌握 Python、概率、线性代数、PyTorch 与基础机器学习者可压缩为 10 周。MIT/CS336 全量实现另计训练时间，不强塞进 Prompt 入门工期。
- **每周结构**：概念卡 90 分钟 → 手算/代码 90 分钟 → 官方作业导航 2–3 小时 → 错误复盘 60 分钟。
- `status: completed` 表示**笔记内容已填充**，个人掌握度看 `mastery: not_started | learning | passed`，不要把二者混为一谈。

## 2. 渐隐支架

每个主题连续做三层任务，避免只读不练：

1. **Worked Example**：照着主题卡手算并运行标准库代码；Prompt/RAG 阶段运行 `03-Projects/45-生成式AI基础与Prompt工程/starter/` 的 rule adapter，逐条解释结果。
2. **Completion Problem**：保留 `ModelAdapter`、固定数据、parser 与测试，新建自己的 adapter；失败时只按 README 的“schema→raw→parser→Prompt”顺序看一条提示。
3. **Independent Transfer**：换成非情感任务，自建 50 条冻结数据与行为量规；保留同一报告 schema，不能复制 starter 样本凑数。

若第三层失败，先按“概念→公式→实现→数据→指标”定位，不重复读整张卡。

## 4. 认知科学落地

- **提取练习**：先闭卷回答每卡第 10 节，再看正文。
- **间隔复习**：1/3/7/14 天回看失败题，不重复复习已通过题。
- **交错练习**：在同一小数据集比较 zero-shot、few-shot、分解和 RAG，而不是连续做同类模板。
- **生成效应**：先预测实验结果，再运行；预测错误比“看懂答案”更能形成边界感。
- **双重编码**：为 Transformer、RAG 和安全边界各画一张数据流图，并用文字复述。

## 5. 高阶题统一评分量规

| 维度 | 0 分 | 1 分 | 2 分 |
| :--- | :--- | :--- | :--- |
| 定义与假设 | 缺失或混乱 | 部分明确 | 变量、边界、假设完整 |
| 方法与理由 | 只给结论 | 方法可行但理由弱 | 能比较替代方案与取舍 |
| 证据 | 无证据 | 少量例子 | 固定数据、指标、逐样本证据 |
| 失败分析 | 把失败归因“模型不行” | 有分类无定位 | 能定位层级并给回归测试 |
| 可复现性 | 无配置 | 部分记录 | 数据/Prompt/模型/种子/代码齐全 |

总分低于 7/10 不算通过；9–10 分才算可迁移掌握。
