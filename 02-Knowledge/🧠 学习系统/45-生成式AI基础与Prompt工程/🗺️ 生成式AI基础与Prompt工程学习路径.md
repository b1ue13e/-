# 生成式 AI 基础与 Prompt 工程学习路径

> 目标：解释生成模型的行为边界，把模糊需求写成可验收规格，用受控实验比较 Prompt，并为证据、幻觉、注入和不确定性设计防线。

## 课程目标与最低前置

- **必须能做**：Token/上下文/解码解释；任务规格与 JSON Gate；固定数据集评测；Few-shot 与分解对照；RAG 引用/拒答；事实核验；提示注入分层防护。
- **最低前置**：能运行 Python，理解列表/字典/异常处理、概率与对数，能写 JSON 校验和断言。先完成 [[00-前置知识/🧭 生成式AI基础与Prompt工程-前置知识]] 与课程作业 00；诊断未通过，不进入主线。
- **选修前置**：若做阶段 2，实现前必须通过其 MOC 中的 PyTorch、BPE、优化和数学 Gate；阶段 2 不阻塞 Prompt 主线。

## 官方主教材与来源边界

来源、版本、许可和排除范围只维护在 [[📚 教材挂载索引]]，本页不复制来源账本。

## 学习节奏与支架

- 小白建议 12–14 周、每周 7–9 小时；已有 Python、概率和机器学习基础者可压缩到 8–10 周。阶段 2 的完整实现时间另计。
- 每个主题依次完成 **示范复现 → 保留接口的补全题 → 更换数据的独立迁移**。离线规则夹具只证明协议可运行，不是 LLM 能力证据。
- 高阶交付按定义与假设、方法与理由、证据、失败分析、可复现性各 0–2 分评分；低于 7/10 不通过，9–10 分才算可迁移掌握。
- 复习采用 1/3/7/14 天提取练习；先闭卷答每卡的复现任务，再只修复失败点，不重复通读已通过内容。

## 阶段顺序与衔接

1. [[01-模型心智模型/🧭 阶段1-模型心智模型]]
   - **目标**：建立 Token → Transformer → logits → 解码的生成循环，区分参数知识、上下文、检索和训练适配。
   - **知识卡**：由阶段 MOC 维护有序清单。
   - **作业**：阶段 1 作业由 `stage_id: "01"` 自动派生；完成后才能解释 Prompt 的能力边界。
   - **验收**：闭卷画生成循环，并让阶段作业 Gate 通过。
2. [[02-模型实现选修/🧭 阶段2-模型实现选修]]
   - **目标**：按需完成 CS336 A1 最小实现链或 MIT 分支，保留 shape、梯度、资源和恢复证据。
   - **知识卡**：由阶段 MOC 维护；跳过不会阻塞阶段 3。
   - **作业**：只在需要从零实现时选择阶段 2 作业。
   - **验收**：结构测试、训练恢复和资源核算齐全，不能用微型结果冒充官方规模。
3. [[03-Prompt规格与方法/🧭 阶段3-Prompt规格与方法]]
   - **目标**：任务规格 → 评测协议 → Prompt 方法 → 示例选择 → 可验证分解。
   - **知识卡**：由阶段 MOC 维护有序清单。
   - **作业**：至少完成一份基线和一份受控改写，保留逐样本输出、指标、方差和错误分类。
   - **验收**：只改一个变量；没有原始输出、数据隔离或回退结论不通过。
4. [[04-增强评测与可靠性/🧭 阶段4-增强评测与可靠性]]
   - **目标**：RAG 证据链 → 幻觉与事实核验 → Judge 校准 → 提示注入与分层防护。
   - **知识卡**：由阶段 MOC 维护有序清单。
   - **作业**：完成至少一个 RAG/可靠性实验和一组注入回归；结课项目汇总全链路。
   - **验收**：区分检索、生成、评审与授权失败，报告拒答/人工接管策略。

## 课程作业与结课标准

- 作业入口唯一维护在 `03-Projects/45-生成式AI基础与Prompt工程/🧭 课程作业总索引.md`；本页只说明阶段衔接，不复制作业列表。
- 结课项目必须迁移到新数据和新用户问题，提交配置、Prompt 版本、模型/adapter、逐样本结果、失败复盘和安全边界。
- **结课通过**：能对同一任务比较 direct/few-shot/分解/RAG；至少 30 条冻结评测样本；能解释何时继续 Prompt、何时 RAG、何时训练适配、何时交给 Agent。
