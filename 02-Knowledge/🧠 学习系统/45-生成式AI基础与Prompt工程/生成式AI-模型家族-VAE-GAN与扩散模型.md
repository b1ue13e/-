# 生成式 AI 模型家族：VAE、GAN 与扩散模型

## 0. 学习边界

- **类别**：**A 类（全面知识主卡）**。
- **判断理由**：只学 LLM 会把生成式 AI 误等同于文本生成。本卡建立三类视觉生成模型与自回归模型的统一坐标。

## 1. 这个知识点解决什么问题？

> 如何从训练数据中学习一个可采样的分布，生成未出现过但“像数据”的图像、音频或连续信号？不同方法为什么在清晰度、覆盖度、训练稳定性和采样速度上取舍不同？

## 2. 为什么它重要？它有什么用？

- **连接大图景**：VAE 学潜变量，GAN 学生成器与判别器博弈，扩散模型学习逐步去噪。
- **实际应用**：图像生成、编辑、超分辨率、数据增强和跨模态生成。
- **高频任务**：辨析 mode collapse、重建质量、ELBO、噪声调度和 classifier-free guidance。

## 3. 学它之前需要哪些前置知识？

1. **概率分布与期望**：理解采样、似然和 KL 散度。
2. **神经网络训练**：损失函数、反向传播和训练/验证切分。

## 4. 用直觉语言解释它

- **VAE**：把样本压进平滑地图，再从地图位置解码。
- **GAN**：造假者与鉴别者对练，逼生成器产出逼真样本。
- **扩散**：先学会从不同噪声等级一步步擦掉噪声，再从纯噪声反向生成。
- **一句话本质**：三者都学习数据分布，但优化目标和采样路径不同。

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义

- VAE 最大化 ELBO：重建项减去近似后验与先验的 KL。
- GAN 求解生成器 $G$ 与判别器 $D$ 的极小极大博弈。
- 扩散模型学习噪声预测器 $\epsilon_\theta(x_t,t)$，反向恢复 $x_0$。

### 2. 核心公式

$$\mathcal{L}_{VAE}=\mathbb{E}_{q(z|x)}[\log p(x|z)]-D_{KL}(q(z|x)\Vert p(z))$$

$$\min_G\max_D\;\mathbb{E}_{x\sim p_{data}}\log D(x)+\mathbb{E}_{z}\log(1-D(G(z)))$$

$$\mathcal{L}_{diff}=\mathbb{E}_{x,\epsilon,t}\|\epsilon-\epsilon_\theta(x_t,t)\|_2^2$$

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $z$ | 潜变量/随机噪声 | 通常来自简单先验 |
| $G,D$ | 生成器、判别器 | GAN 对抗双方 |
| $x_t$ | 第 $t$ 个噪声等级的样本 | 扩散状态 |

### 4. 常见变体与适用条件

- 条件 VAE/GAN/扩散把类别、文本或图像作为条件。
- GAN 采样快但训练可能不稳；扩散训练稳、质量高但多步采样慢。
- VAE 潜空间规则、重建方便，但输出可能更平滑。

## 6. 推导思路和思想来源

- **最初困难**：高维数据分布难直接归一化和采样。
- **关键转念**：引入潜变量、对抗判别或可逆的加噪/去噪路径。
- **主线**：定义生成过程 → 选择可训练代理目标 → 从简单分布采样 → 映射回数据空间 → 用质量和覆盖度共同评测。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

一维前向扩散 $x_t=\sqrt{0.8}x_0+\sqrt{0.2}\epsilon$。若 $x_0=1,\epsilon=0$，则 $x_t\approx0.894$；若 $\epsilon=1$，则 $x_t\approx1.341$。

### 例子 2：中等例子

GAN 只生成一种高质量人脸属于 mode collapse：清晰度高但覆盖度差。只展示最好样本会掩盖失败，应查看分布、多样性和最近邻。

### 例子 3：实际应用例子（可运行 Python）

```python
# 输入：干净标量、噪声和 alpha；输出：一个前向扩散样本。
import math

x0, noise, alpha = 1.0, 0.5, 0.8
xt = math.sqrt(alpha) * x0 + math.sqrt(1 - alpha) * noise
print(round(xt, 4))
# 预期：约 1.118，表示信号与噪声的线性组合。
```

## 8. 常见误区和易混概念

### 误区 1：样本越逼真，模型越好
- **为什么错**：还需覆盖数据多样性并避免记忆训练样本。

### 误区 2：扩散等于给图片加模糊
- **为什么错**：标准扩散按噪声调度加入随机噪声，并学习概率反向过程。

### 概念对比表

| 模型 | 学习方式 | 优势 | 主要风险 |
| :--- | :--- | :--- | :--- |
| VAE | 变分下界 | 潜空间规则 | 结果偏平滑 |
| GAN | 对抗博弈 | 采样快、锐利 | 训练不稳、模式坍塌 |
| 扩散 | 多步去噪 | 质量与覆盖好 | 采样慢 |
| 自回归 | 顺序条件概率 | 似然清晰、适合离散序列 | 串行生成 |

## 11. 自测题：5 道

1. VAE 的 KL 项在约束什么？
   > [!question]- 答案解析 `#自测题/基础`
   > 让编码后的近似后验接近可采样先验，形成连续、可用的潜空间。
2. GAN 的两个网络分别做什么？
   > [!question]- 答案解析 `#自测题/基础`
   > 生成器造样本，判别器区分真实与生成样本。
3. 扩散模型为何能从噪声生成数据？
   > [!question]- 答案解析 `#自测题/中等`
   > 它学习每个噪声等级的反向去噪方向，迭代近似数据分布。
4. mode collapse 为什么不是“图片不清晰”？
   > [!question]- 答案解析 `#自测题/中等`
   > 它是生成分布缺少多样性，即使单张样本很清晰也可能发生。
5. 如何评测生成模型避免只看精选样本？
   > [!question]- 答案解析 `#自测题/较难`
   > 同时检查质量、覆盖、多样性、最近邻、条件一致性和人工盲评，并公开随机样本。
