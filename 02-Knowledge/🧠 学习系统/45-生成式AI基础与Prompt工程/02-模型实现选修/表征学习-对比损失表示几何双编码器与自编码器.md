# 表征学习：对比损失、表示几何、双编码器与自编码器

## 0. 学习边界

- **类别**：A 类（MIT HW4 Q1–Q8 主卡）。
- **判断理由**：HW4 需要正样本构造、球面几何、温度、InfoNCE/双编码器和实现分析；解码温度或多模态概览不能替代。

## 1. 这个知识点解决什么问题？

> 没有人工类别时，怎样用同一实例的不同增强教模型“哪些应相近、哪些应分开”？表示重建输入后，为什么仍可能没有语义结构？

## 2. 为什么它重要？它有什么用？

- 对比学习把增强不变性写成可训练监督信号。
- 单位球归一化让点积等于余弦相似度，并连接距离几何。
- 双编码器是现代图文对齐和稠密检索的基础。
- Autoencoder 重建目标与语义判别目标不同，必须分别评测。

## 3. 学它之前需要哪些前置知识？

1. [[课程前置-概率向量与Softmax最小补丁]]：softmax、交叉熵、点积。
2. [[深度学习工程-PyTorch张量自动微分与训练循环]]：batch、增强和训练循环。

## 4. 用直觉语言解释它

> “同一张图的两种合法增强是正对，batch 里其他图是负对；模型在单位球上拉近正对、推远负对。自编码器则只要求能还原，不保证邻居有相同语义。”

一句话本质：**训练目标定义了表示空间中什么关系值得保留。**

## 5. 正式定义、核心公式、符号解释

归一化表示 $z_i=h_i/\|h_i\|_2$。单位向量满足
$$\|z_i-z_j\|_2^2=2-2z_i^Tz_j,$$
所以最大化余弦相似度等价于最小化平方距离。

单向 InfoNCE：
$$\ell_i=-\log\frac{\exp(z_i^Tz_i^+/\tau)}{\sum_{j\in\mathcal B}\exp(z_i^Tz_j/\tau)}.$$

双向双编码器损失常为 image→text 与 text→image 两个交叉熵的平均。温度 $\tau$ 缩放**相似度 logits**；它与文本解码温度作用对象不同。

Autoencoder：
$$z=f_\phi(x),\quad\hat x=g_\theta(z),\quad
\mathcal L_{rec}=\|x-\hat x\|^2.$$

| 组件 | 作用 | 失败边界 |
| :--- | :--- | :--- |
| augmentation | 定义应保持的语义不变性 | 过强增强改变标签 |
| normalization | 固定半径，比较角度 | 丢失模长信息 |
| temperature | 控制 softmax 尖锐度/梯度 | 过小导致过尖与数值问题 |
| negatives | 提供相对分离信号 | false negatives |

## 6. 推导思路和思想来源

1. 同一实例经两次语义保持增强得到正样本；其他实例作 batch negatives。
2. 对相似度矩阵逐行做分类：正确列是对应正样本，即交叉熵。
3. 归一化防止仅靠放大向量模长降低 loss。
4. 双编码器分别编码两种模态/对象，点积矩阵可批量检索和训练。
5. Autoencoder 可把每个训练样本编码为任意“暗号”后重建，因此低重建误差不推出类内紧、类间分离或下游泛化。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）

单位向量点积为 0.8，则平方距离为 $2-1.6=0.4$。若 $\tau=0.1$，相似度 logit 为 8；若 $\tau=1$，为 0.8，前者 softmax 更尖。

### 例子 2：中等例子

图像 crop 删除了决定类别的唯一物体，却仍当正样本，会强迫模型把不同语义拉近。增强策略是任务假设，不是无害的数据扩充。

### 例子 3：可运行 Python

```python
# 输入：两个 anchor 对两个 candidate 的单位向量；输出：InfoNCE 平均损失。
import math

def dot(left, right):
    return sum(a * b for a, b in zip(left, right))

def cross_entropy(logits, target):
    maximum = max(logits)
    return maximum + math.log(sum(math.exp(value - maximum) for value in logits)) - logits[target]

anchors = [[1.0, 0.0], [0.0, 1.0]]
candidates = [[0.9, 0.1], [0.1, 0.9]]
temperature = 0.2
losses = []
for index, anchor in enumerate(anchors):
    logits = [dot(anchor, candidate) / temperature for candidate in candidates]
    losses.append(cross_entropy(logits, index))
loss = sum(losses) / len(losses)
print(round(loss, 6))
assert loss < 0.05
```

## 8. 常见误区和易混概念

- 对比温度不是生成采样温度；前者缩放训练相似度 logits。
- batch 中所有其他样本不一定是真负样本，可能存在同类 false negative。
- 最近邻图“看起来合理”只是定性证据，还需冻结标签评测和泄漏检查。
- 重建清晰不代表潜空间语义线性可分。

| 概念 | 正信号 | 主要目标 | 典型应用 |
| :--- | :--- | :--- | :--- |
| 分类交叉熵 | 人工类别 | 类别决策边界 | 监督分类 |
| InfoNCE | 配对/增强 | 相对表示几何 | 自监督、CLIP |
| Triplet loss | anchor/pos/neg | margin 排序 | 度量学习 |
| Autoencoder | 输入自身 | 重建信息 | 压缩、生成前置 |

## 🃏 Anki 卡片

Q: InfoNCE 的温度作用在哪里？
A: 它除在表示相似度 logits 上，控制训练 softmax 尖锐度，不是文本生成采样温度。

Q: 为什么低重建误差不保证语义表示？
A: 重建只要求保留可解码信息，潜空间可用任意暗号排列，不要求类内紧或类间分离。
