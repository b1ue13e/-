# 阶段 2：模型实现选修

## 为什么这是选修

本课程的核心目标是能设计、评测和防护生成式 AI 工作流，而不是复刻一门完整深度学习系统课。Stanford CS336 明确要求较强 Python、PyTorch、系统优化和机器学习基础；MIT 6.7960 的多份作业也覆盖远超 Prompt 入门的数学与架构。因此本阶段只服务“我要从零实现或完整理解官方作业”的学习者，跳过它不影响进入阶段 3。

## 学完能做什么

- 在 CPU 小规模环境实现并测试 Tokenizer、Transformer block、损失与训练恢复。
- 用 shape、参数量、FLOP、梯度和 checkpoint 证据定位实现失败。
- 按需要完成 MIT 6.7960 的表达、几何、图、表征或生成数学分支。
- 明确区分“本地微型正确性证据”和“官方规模复现结果”。

## 默认实现顺序：CS336 A1 最小链

1. [[神经网络表达-ReLU分段线性逻辑门与泛化]]：激活、表达、训练与泛化边界。
2. [[深度学习工程-PyTorch张量自动微分与训练循环]]：shape、梯度、状态和最小训练闭环。
3. [[Tokenizer工程-Unicode字节与BPE训练]]：建立可逆数据接口。
4. [[Transformer工程-RMSNorm-SwiGLU-RoPE与资源核算]]：实现现代 decoder block 并先核算资源。
5. [[训练优化-交叉熵AdamW调度梯度裁剪与检查点]]：完成损失、优化、调度与恢复。

## MIT 6.7960 按需分支

按实际要做的官方作业选择，不要求为了“学全”全部串行完成：

1. HW2 数学与架构：[[深度学习数学-对偶范数谱范数PowerIteration与最速下降]] → [[深度学习工程-宽度缩放WeightDecay卷积与受控比较]] → [[图表示学习-不变聚合消息传递与手性边界]]。
2. HW4 表征：[[表征学习-对比损失表示几何双编码器与自编码器]]。
3. HW5 生成数学：[[生成模型数学-高斯KL重参数化与扩散后验]]。

## 复习与回顾

- 每完成一个实现模块，先跑最小边界测试，再拼接下一模块。
- 第一次完整训练后，从 checkpoint 恢复并比较连续三步参数；不能恢复等价则阶段不通过。
- 任何 GPU 或官方规模实验都必须记录删减、硬件和未复现部分，不用微型 CPU 结果冒充。
