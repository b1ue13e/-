# 🎯 第四阶段：融会贯通

> 本阶段不再增加一轮百科式知识清单，而是把逻辑、图论、组合、数论、自动机和复杂度组织成可验证的综合产出。

## 🎯 阶段目标

完成本阶段后，应能：

1. 从一个问题中识别逻辑、图、组合或数论结构。
2. 给出正确性说明，并分析时间与空间复杂度。
3. 将形式化定义转成可运行的最小实现。
4. 对失败案例、适用条件和不可解边界作出解释。

## ✅ 统一验收标准

- [ ] **定义正确**：关键对象、输入、输出和假设明确。
- [ ] **推理完整**：能说明算法或系统为什么正确，而不只展示运行结果。
- [ ] **复杂度可解释**：给出时间、空间或问题难度分析。
- [ ] **测试可复现**：包含正常、边界和失败案例，结果可重复运行。
- [ ] **边界诚实**：明确当前方案不适用或无法保证的情况。
- [ ] **闭卷复盘**：不看资料重画“逻辑 → 表示 → 算法 → 验证 → 边界”的依赖链。
