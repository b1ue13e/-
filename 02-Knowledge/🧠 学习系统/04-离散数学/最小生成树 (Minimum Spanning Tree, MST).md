# 最小生成树 (Minimum Spanning Tree, MST)

## 0. 先判断它值不值得深挖

- **分类结果**: **A 类（核心概念，必须深挖）**
- **分类理由**: 最小生成树（Minimum Spanning Tree, MST）是加权无向连通图中连通所有顶点且总边权和达到最小的树形子图。它是离散数学与图论中证明**贪心策略 (Greedy Strategy)** 能取得全局绝对最优解的最经典范例（割性质与回路性质）。在计算机网络布局（光纤铺设、局域网拓扑构建）、电路板布线、图像分割（基于 MST 的层次聚类）及 TSP 问题近似求解中，它是底层的核心基石。

---

## 1. 这个知识点解决什么问题？

**我们遇到了什么麻烦？**

假设你负责规划一个地区的通信网络，需要在 $n$ 个城市之间铺设光纤电缆。已知任意两城市间铺设电缆的经济成本（边权 $w(e)$）。
- 如果在城市间铺设了多余的闭合环路，会白白浪费巨额施工成本；
- 如果铺设的电缆太少，又无法保证所有城市都能互相通信；
- 如果随意盲目连接，虽然连通了全网，但花费的总建设资金可能远高于最优解。

为了在**确保 $n$ 个节点全连通（无环且连通，即构造生成树）**的前提下，使**总建造成本 $\sum_{e \in T} w(e)$ 达到数学上的绝对最小值**，图论提出了**最小生成树**及其求解算法。

## 2. 为什么它重要？它有什么用？

- **课程大图景位置**: 图论模块的核心纽带，连接图的连通性、树的结构性质与算法设计（贪心算法、割性质证明）。
- **后续知识支撑**:
  - [[并查集]]: Kruskal 算法高效判定环路的数据结构；
  - [[Prim]] & [[Kruskal]]: 两大经典 MST 贪心求解算法；
  - **旅行商问题 (TSP) 2-近似算法**: 基于 MST 构造欧拉回路求解 NP-Hard 的 TSP 问题。
- **实战与跨学科应用**:
  - **计算机网络 (STP 协议)**: 交换机生成树协议（Spanning Tree Protocol）自动阻塞冗余链路，防止广播风暴与环路；
  - **超大规模集成电路 (VLSI)**: 芯片引线长度最小化与时钟树合成；
  - **数据挖掘与图像处理**: 基于 MST 割断最长边的图像分割算法（Felzenszwalb 算法）。

## 3. 学它之前需要哪些前置知识？

- **加权无向图 $G = (V, E, w)$**: 节点集 $V$，边集 $E$，边权映射 $w: E \to \mathbb{R}$。
- **生成树 (Spanning Tree)**: 包含 $G$ 的全体 $|V|$ 个顶点的连通无环子图，恰好含有 $|V|-1$ 条边。
  - *最小必要背景速补*: 树具有“无环且连通”的最简结构。在生成树中任意添加一条不在树中的边，必产生唯一简单回路；而删去该回路上的任意一条边，图形依然保持连通树形态。

## 4. 用直觉语言解释它

«“最小生成树其实就像**用最省电线的方式，把整栋大楼里所有房间的插座全部串联通电**。”»

假设楼里有 $n$ 个插座节点：
1. **不能有封闭死循环**：你绝不会把电线绕成一个闭合环圈，因为那会白白浪费电线（树结构不能有环）；
2. **必须全连通**：你必须保证每个房间都能通电（必须包含所有顶点）；
3. **性价比最高**：在不破坏上述两点的原则下，你每次都优先挑成本最低的电线去连接尚未通电的房间（贪心选择）。
- **直觉本质**: 消除冗余回路，用最小总代价维持全局全连通。

## 5. 正式定义、核心公式、符号解释

### 最核心定义

设 $G = (V, E, w)$ 为带权连通无向图。$G$ 的一个生成树 $T = (V, E_T)$（其中 $E_T \subseteq E$ 且 $|E_T| = |V|-1$），如果满足其所有边权之和在 $G$ 的所有生成树中达到最小：
$$ w(T) = \sum_{e \in E_T} w(e) = \min_{T' \in \mathcal{S}(G)} \left( \sum_{e \in E_{T'}} w(e) \right) $$
其中 $\mathcal{S}(G)$ 表示 $G$ 的所有生成树集合，则称 $T$ 为 $G$ 的**最小生成树 (MST)**。

### 贪心奠基两大核心定理

#### 定理一：割性质 (Cut Property - 贪心选择基础)
设 $G=(V, E, w)$ 为连通带权无向图。设 $S \subset V$ 为 $V$ 的任意非空真子集，定义切割为 $(S, V \setminus S)$。
若边 $e = (u, v)$ 是**跨越该切割的最小权值边**（即 $u \in S, v \in V \setminus S$，且对所有跨越该切割的边 $e'$ 均有 $w(e) \le w(e')$），则**必定存在包含边 $e$ 的最小生成树**。
*(注：若全图所有边权互不相同，则边 $e$ 必然存在于唯一的最小生成树中。)*

#### 定理二：回路性质 (Cycle Property)
设 $C$ 为图 $G$ 中的任意简单回路。若边 $e$ 是回路 $C$ 中**权值严格最大的边**，则边 $e$ 必定不属于 $G$ 的任何最小生成树。

### 两大经典求解算法比较

| 算法 | 贪心策略 | 核心数据结构 | 时间复杂度 | 适用图类型 |
|:---|:---|:---|:---|:---|
| **Kruskal 算法** | 选全局最小边（加边法） | [[并查集]] (Disjoint Set) | $\mathcal{O}(\|E\| \log \|E\|)$ | 稀疏图 ($E \ll V^2$) |
| **Prim 算法** | 选切分集最小边（加点法） | 优先队列 / 斐波那契堆 | $\mathcal{O}(\|E\| + \|V\| \log \|V\|)$ | 稠密图 ($E \approx V^2$) |

### 符号解释表

| 符号 | 含义 | 取值范围/量纲 | 备注 |
|:---:|:---|:---|:---|
| $G=(V,E,w)$ | 带权无向连通图 | 图结构 | $w(e)$ 为边 $e$ 的权值 |
| $T=(V, E_T)$ | 最小生成树 | 子图 | 包含 $|V|$ 个顶点，$|V|-1$ 条边 |
| $w(T)$ | MST 的总权值 | 实数 / 标量 | $w(T) = \sum_{e \in E_T} w(e)$ |
| $(S, V \setminus S)$ | 图的顶点分割 (Cut) | 顶点集的划分 | 割性质的基准线 |

## 6. 推导思路和思想来源

- **困难与动机**: 根据 Cayley 定理，完全图 $K_n$ 有 $n^{n-2}$ 棵不同的生成树。面对巨大的解空间，不可能穷举所有生成树比较权值。
- **关键转念**: 能否通过“局部最优选择”推导出“全局最优”？**割性质**给出了肯定的证明。
- **割性质的反证法推导主线**:
  1. 假设跨越割 $(S, V \setminus S)$ 的最小权边为 $e = (u, v)$；
  2. 假设有一棵不包含边 $e$ 的最小生成树 $T$；
  3. 将边 $e$ 加入 $T$ 中，因为 $T$ 连通，加入 $e$ 后必定形成一个唯一的简单回路 $C$；
  4. 回路 $C$ 从 $S$ 出发又回到 $S$，因此回路上必然存在**另一条跨越割 $(S, V \setminus S)$ 的边 $e' = (x, y)$**；
  5. 构造一个新生成树 $T' = (T \cup \{e\}) \setminus \{e'\}$（删去 $e'$，树恢复无环且连通）；
  6. 计算新树权值：$w(T') = w(T) + w(e) - w(e')$。
     由于 $e$ 是跨越割的最小权边，必有 $w(e) \le w(e')$，因此 $w(T') \le w(T)$；
  7. 因为 $T$ 原本就是 MST，故必有 $w(T') = w(T)$。说明新树 $T'$ 也是一棵最小生成树，且 $T'$ 包含了边 $e$。得证！

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（4 节点带权图手算演练）
- **题目**: 给定无向加权图 $G$，节点为 $\{A, B, C, D\}$，边权如下：
  - $(A, B) = 1, (B, C) = 2, (A, C) = 4, (B, D) = 3, (C, D) = 5$。
  用 Kruskal 算法求最小生成树及其总权值。

- **手算步骤**:
  1. **按权值升序排列所有边**:
     1. $(A, B), w=1$
     2. $(B, C), w=2$
     3. $(B, D), w=3$
     4. $(A, C), w=4$
     5. $(C, D), w=5$
  2. **贪心依次选边（并查集判环）**:
     - 选 $(A, B), w=1$：不构成环，加入 $E_T = \{(A,B)\}$；
     - 选 $(B, C), w=2$：不构成环，加入 $E_T = \{(A,B), (B,C)\}$；
     - 选 $(B, D), w=3$：不构成环，加入 $E_T = \{(A,B), (B,C), (B,D)\}$；
     - 此时边数已经达到 $|V|-1 = 4-1 = 3$ 条，算法终止。
  3. **检查后续边**:
     - 若考察 $(A, C), w=4$，因为 $A, B, C$ 已在同一连通块中，加入会形成回路 $(A-B-C-A)$，舍弃（符合回路性质）。
- **最终答案**:
  MST 边集为 $\{(A,B), (B,C), (B,D)\}$，最小总权值 $w(T) = 1 + 2 + 3 = 6$。

---

### 例子 2：中等例子（Kruskal 算法的 Python 实现）
- **代码实现**（结合路径压缩并查集）：

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    def find(self, i):
        if self.parent[i] == i:
            return i
        self.parent[i] = self.find(self.parent[i]) # 路径压缩
        return self.parent[i]
    def union(self, i, j):
        root_i = self.find(i)
        root_j = self.find(j)
        if root_i != root_j:
            self.parent[root_i] = root_j
            return True
        return False

def kruskal(n, edges):
    # edges 为列表 [(u, v, weight), ...]
    edges.sort(key=lambda x: x[2]) # 按权值升序
    uf = UnionFind(n)
    mst_weight = 0
    mst_edges = []
    
    for u, v, w in edges:
        if uf.union(u, v):
            mst_weight += w
            mst_edges.append((u, v, w))
            if len(mst_edges) == n - 1:
                break
    return mst_weight, mst_edges
```

### 例子 3：实际应用例子
- **真实场景**: **图像分割 (Graph-Based Image Segmentation)**
  在计算机视觉中，将一张图像的每个像素看作图的节点，邻近像素之间的颜色/纹理差异作为边权 $w(e)$。
  - **基于 MST 的分割算法**:
    1. 构建全图的最小生成树；
    2. 如果两条区域内部的边权最大值远小于跨区域边的权值，则将该边切断；
    3. 逐渐切断 MST 中权值高于区域异质性阈值的边，整张图片便自然分割为若干个代表不同物体背景的连通块！

## 8. 常见误区和易混概念

### 常见误区

#### 误区 1：认为图的最小生成树是唯一的
- **错误直觉**: “一个图算出来的 MST 必定只有一种形态。”
- **为什么错**: **只有当全图所有边权严格互不相同时，MST 才保证唯一**！如果图中存在多条权值相同的边，可能存在多棵形态不同但总权值完全相等的 MST。
- **正确理解**: MST 的总边权和 $w(T)$ 是绝对唯一的，但生成树的拓扑形态可能不唯一。

#### 误区 2：混淆最小生成树 (MST) 与单源最短路径树 (SPT)
- **错误直觉**: “从起点 $S$ 到各个节点的 Dijkstra 最短路径树就是最小生成树。”
- **为什么错**:
  - **最小生成树 (MST)**：追求**全图所有边权的总和最小**（全局最小）；
  - **单源最短路径树 (SPT)**：追求**指定起点 $S$ 到每个节点各自的路径距离最小**。
- **反例**: 考虑三角形图 $(A,B)=1, (B,C)=1, (A,C)=1.5$。起点为 $A$：
  - MST 为 $\{(A,B), (B,C)\}$，总权值 2；但 $A \to C$ 的树上距离为 $1+1=2$；
  - SPT 为 $\{(A,B), (A,C)\}$，总权值 2.5；但 $A \to C$ 距离为 1.5。两者完全不同！

### 易混概念对比

| 概念 | 优化目标 | 针对关系 | 算法代表 | 结果形态 |
|:---|:---|:---|:---|:---|
| **最小生成树 (MST)** | $\min \sum_{e \in T} w(e)$ (全局总和) | 无向带权图 | Kruskal / Prim | 无向树 (1 棵或多棵) |
| **最短路径树 (SPT)** | $\min d(S, v), \forall v$ (单点距离) | 有向/无向带权图 | Dijkstra | 以 $S$ 为根的有向树 |
| **拓扑排序** | 节点线性序列满足 $u \to v$ | 有向无环图 (DAG) | Kahn / DFS | 节点的线性列表 |

### 题目 1
对于一个连通带权无向图 $G$，下列说法正确的是：
A. $G$ 的最小生成树必定是唯一的
B. 若 $G$ 中所有边的权值互不相同，则 $G$ 的最小生成树必定唯一
C. $G$ 中权值最小的边一定只有一条
D. Prim 算法和 Kruskal 算法求出的生成树形态必定完全相同

> [!question]- 答案解析
> **答案**: B
> **解析**: 当图中所有边权互不相同时，在每一个割上的最小跨越边是绝对唯一的，由割性质可知其最小生成树唯一。若存在等权边，则可能存在多棵不同形态的 MST（A、D 错误）。C 选项图中可能存在多条权值并列最小的边。
> **最可能错因**: 混淆了边权相同与不同对唯一性的影响。
> **Obsidian 标签**: `#自测题 #基础 #最小生成树 #唯一性`

### 题目 2
在一个包含 5 个顶点的连通图 $G$ 中，已知通过 Kruskal 算法选出的前 3 条边的权值分别为 2, 3, 5。若第 4 条被选中的边的权值为 7，则该图的最小生成树总权值为：
A. 10
B. 17
C. 无法确定
D. 20

> [!question]- 答案解析
> **答案**: B
> **解析**: 含有 5 个顶点的树恰好包含 $5 - 1 = 4$ 条边。4 条被选中的边权值之和为 $2 + 3 + 5 + 7 = 17$。
> **最可能错因**: 忘记 $n$ 个顶点的树恰有 $n-1$ 条边。

### 题目 3
判断命题正误：若将连通带权图 $G$ 中的所有边的权值都乘以一个正常数 $k$ ($k > 0$)，则原图 $G$ 的最小生成树形态不会发生改变。

> [!question]- 答案解析
> **答案**: 正确
> **解析**: 对所有边权乘以同一个正数 $k$，不会改变任意两条边权值的大小比较关系（即若 $w(e_1) < w(e_2)$，则 $k \cdot w(e_1) < k \cdot w(e_2)$）。因此在割性质与 Kruskal 排序中，边的相对顺序完全保持一致，选出的边集 $E_T$ 保持不变，最小生成树的形态不变（总权值变为 $k \cdot w(T)$）。
> **Obsidian 标签**: `#自测题 #中等 #权值缩放`

### 题目 4
已知连通带权图 $G$ 的一棵最小生成树为 $T$。现将 $G$ 中一条**不属于 $T$ 的边 $e_0 = (u, v)$** 的权值 $w(e_0)$ **减小**到一个非常小的值。问：如何快速重新更新得到新的最小生成树？

> [!question]- 答案解析
> **答案**: 见下述更新算法
> **解析**:
> 1. 将边 $e_0$ 加入原本的树 $T$ 中，此时 $T \cup \{e_0\}$ 中必形成唯一的简单回路 $C$。
> 2. 在回路 $C$ 中找到权值最大的边 $e_{max}$。
> 3. 若 $w(e_0) < w(e_{max})$，则将 $e_{max}$ 从树中删去，新的最小生成树为 $T' = (T \cup \{e_0\}) \setminus \{e_{max}\}$。
> 4. 若 $w(e_0) \ge w(e_{max})$，说明 $e_0$ 依然不够小，最小生成树保持 $T$ 不变。
>    时间复杂度仅为 $\mathcal{O}(|V|)$（寻找树上回路），远优于重新运行全局 MST 算法。
> **Obsidian 标签**: `#自测题 #综合 #动态生成树`

### 题目 5
利用割性质证明：若连通带权图 $G=(V, E, w)$ 中所有边的权值互不相同（即对任意 $e_1 \ne e_2 \implies w(e_1) \ne w(e_2)$），则 $G$ 的最小生成树是唯一的。

> [!question]- 答案解析
> **答案**: 见下述证明
> **解析**:
> 假设图 $G$ 存在两棵不同的最小生成树 $T_1$ 和 $T_2$ ($T_1 \ne T_2$)。
> 1. 令边集对称差 $E_{diff} = (E_{T_1} \setminus E_{T_2}) \cup (E_{T_2} \setminus E_{T_1})$。因为 $T_1 \ne T_2$，$E_{diff}$ 非空。
> 2. 由于所有边权互不相同，$E_{diff}$ 中必存在一条**权值绝对最小的边**，记作 $e_{min} = (u, v)$。不妨设 $e_{min} \in E_{T_1}$ 且 $e_{min} \notin E_{T_2}$。
> 3. 将边 $e_{min}$ 加入 $T_2$ 中，形成包含 $e_{min}$ 的唯一简单回路 $C$。
> 4. 因为 $T_1$ 是一棵树，它不能包含整个回路 $C$。故回路 $C$ 上必存在至少一条边 $e' \notin E_{T_1}$。因此 $e' \in E_{T_2} \setminus E_{T_1} \subseteq E_{diff}$。
> 5. 由于 $e_{min}$ 是 $E_{diff}$ 中权值严格最小的边，且 $e' \in E_{diff}$ 并与 $e_{min}$ 不相等，必有：
>    $$ w(e_{min}) < w(e') $$
> 6. 用 $e_{min}$ 替换 $T_2$ 中的 $e'$，得到新生成树 $T_2' = (T_2 \cup \{e_{min}\}) \setminus \{e'\}$。
>    其总权值为：$w(T_2') = w(T_2) + w(e_{min}) - w(e') < w(T_2)$。
> 7. 这说明存在一棵比 $T_2$ 权值更小的生成树 $T_2'$，与 $T_2$ 是最小生成树矛盾！
>    因此，当所有边权互不相同时，最小生成树必然唯一。得证！
> **Obsidian 标签**: `#自测题 #证明 #较难 #割性质 #唯一性证明`
