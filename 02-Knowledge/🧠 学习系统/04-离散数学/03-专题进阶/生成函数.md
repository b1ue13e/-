# 生成函数

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类**
- **判断理由**：生成函数是离散数学中最强大的"形式化工具"——它将序列编码为幂级数的系数，把组合恒等式和递推关系转化为代数方程。DMOI 4e §6.1 专门一章。

---

## 1. 这个知识点解决什么问题？

> 递推关系和组合恒等式往往难以直接处理。生成函数将序列 $(a_n)$ 编码为 $A(x)=\sum a_n x^n$，使得序列的**卷积**对应函数的**乘法**，递推关系变为函数方程。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：生成函数 $\to$ 解析组合学 $\to$ 复分析中的鞍点法。
- **应用**：解递推、证明组合恒等式、分析算法复杂度、整数分拆理论。

---

## 3. 学它之前需要哪些前置知识？

1. **[[排列组合与二项式定理]]**：$\binom{n}{k}$ 的组合意义。
2. **[[递推关系与特征根法]]**：生成函数是解递推的另一种方法。

---

## 4. 定义复述

**普通生成函数（OGF）**：$A(x) = \sum_{n=0}^{\infty} a_n x^n$

**指数生成函数（EGF）**：$\hat{A}(x) = \sum_{n=0}^{\infty} a_n \frac{x^n}{n!}$

**基本操作**：
- 加法：$(A+B)(x) = A(x) + B(x)$
- 乘法（卷积）：$(AB)(x) = \sum_n (\sum_{k=0}^n a_k b_{n-k}) x^n$
- 差分：$A(x) - xA(x) = a_0 + \sum_{n=1}^{\infty} (a_n - a_{n-1})x^n$

**常见生成函数**：
- $(1+x)^n = \sum_{k=0}^n \binom{n}{k} x^k$（二项式系数）
- $\frac{1}{1-x} = 1+x+x^2+\cdots$（全1序列）
- $\frac{1}{(1-x)^2} = \sum_{n=0}^{\infty} (n+1)x^n$

### 符号说明

| 符号 | 含义 |
| :--- | :--- |
| $[x^n]A(x)$ | $A(x)$ 中 $x^n$ 的系数 $a_n$ |
| OGF | 普通生成函数 |
| EGF | 指数生成函数 |

---

## 5. 直觉与图像

- **直觉类比**：生成函数像 DNA——序列的每个信息（$a_n$）被编码在 $x^n$ 的位置上。OGF 中 $x^n$ 是"位置标记"而不是变量值——我们只关心系数，不关心 $x$ 的值。
- **一句话直觉本质**：生成函数 = "序列的形式幂级数编码"——乘法对应卷积。

---

## 6. 定理陈述与证明重建

### Fibonacci 数列的生成函数推导

$F_0=0, F_1=1, F_n=F_{n-1}+F_{n-2}$。设 $G(x)=\sum_{n=0}^{\infty} F_n x^n$。

$G(x) - xG(x) - x^2G(x) = F_0 + (F_1-F_0)x + \sum_{n=2}^{\infty}(F_n-F_{n-1}-F_{n-2})x^n = 0 + x + 0 = x$

故 $G(x)(1-x-x^2) = x$，$G(x) = \frac{x}{1-x-x^2}$。

通过部分分式分解，恢复出 Binet 公式。**关键"转念"**：递推关系在生成函数空间变成了代数方程——$F_n-F_{n-1}-F_{n-2}=0$ 每一项乘上 $x^n$ 求和后变成了 $G(x)-xG(x)-x^2G(x)$。

---

## 7. 经典反例库

### 反例：混淆 OGF 和 EGF

- 序列 $(1,1,1,\ldots)$ 的 OGF 是 $\frac{1}{1-x}$，EGF 是 $e^x$。两者完全不同，不能混用。
