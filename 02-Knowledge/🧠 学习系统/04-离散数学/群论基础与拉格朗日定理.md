# 群论基础与拉格朗日定理 (Group Theory and Lagrange's Theorem)

## 1. 群的定义与四条公理

**群 (Group)** 的核心定义是：一个集合 $G$ 配备二元运算 $\cdot$，满足以下**四条群公理**，则称 $(G, \cdot)$ 为群：

1. **封闭性 (Closure)**：$\forall a, b \in G \Rightarrow a \cdot b \in G$
2. **结合律 (Associativity)**：$\forall a,b,c \in G \Rightarrow (a \cdot b) \cdot c = a \cdot (b \cdot c)$
3. **单位元 (Identity)**：$\exists e \in G$ 使 $\forall a \in G, e \cdot a = a \cdot e = a$
4. **逆元 (Inverse)**：$\forall a \in G, \exists a^{-1} \in G$ 使 $a \cdot a^{-1} = a^{-1} \cdot a = e$

**基本性质**：单位元唯一；每个元素的逆元唯一；消去律成立（$ab = ac \Rightarrow b = c$）。

若额外满足**交换律** $a \cdot b = b \cdot a$，则称 $(G, \cdot)$ 为**阿贝尔群 (Abelian Group)**。

## 2. 拉格朗日定理（形式化推导）

**定理（Lagrange, 1771）**：设 $G$ 是有限群，$H$ 是 $G$ 的子群，则 $|H|$ 整除 $|G|$，即：

$$|G| = [G : H] \cdot |H|$$

其中 $[G : H]$ 称为 $H$ 在 $G$ 中的**指标 (Index)**。

**推导（陪集分拆）**：

**假设**：$H \leq G$（$H$ 是 $G$ 的子群），$|G| = n$，$|H| = m$。

对任意 $g \in G$，定义**左陪集** $gH = \{g \cdot h \mid h \in H\}$。

**关键引理**：任意两个左陪集 $aH$ 和 $bH$ 要么相等，要么不相交。

**证明**：若 $aH \cap bH 
eq \emptyset$，则 $\exists h_1, h_2 \in H$ 使 $ah_1 = bh_2$，从而 $a = bh_2h_1^{-1} \in bH$，**因此** $aH = bH$。

**推导**：$G$ 被所有左陪集无交划分，每个陪集恰有 $|H| = m$ 个元素，**因此** $|G| = [G:H] \cdot m$，即 $m \mid n$。

**推论**：$G$ 中任意元素 $g$ 的阶 $\text{ord}(g)$ 整除 $|G|$；特别地，素数阶群必为循环群。

**局限（反例）**：拉格朗日定理的逆命题不成立——整除 $|G|$ 的正整数 $k$ 不一定存在 $k$ 阶子群（$A_4$ 无 6 阶子群）。

## 3. 群论与密码学的关联：区别与对比

| 代数结构 | 公理 | 典型例子 | 密码学应用 |
|:---|:---|:---|:---|
| **群 (Group)** | 封闭、结合、单位元、逆元 | $(\mathbb{Z}_n, +)$ | DH 密钥交换、ECC |
| **环 (Ring)** | 群 + 乘法分配律 | $(\mathbb{Z}_n, +, \times)$ | RSA、多项式密码 |
| **域 (Field)** | 环 + 乘法逆元 | $GF(2^8)$ | AES S-Box、有限域算术 |

## 4. Python 群公理验证器与拉格朗日定理检验

```python
from itertools import product
from math import gcd
from typing import Set, Tuple, List

def verify_group_axioms(elements: List, op) -> dict:
    """
    验证 (elements, op) 是否满足四条群公理
    假设: elements 有限，op 为二元运算函数
    推导: 依次检验封闭、结合、单位元、逆元
    """
    results = {'closure': True, 'associativity': True,
               'identity': None, 'inverse': True}

    # 封闭性
    for a, b in product(elements, repeat=2):
        if op(a, b) not in elements:
            results['closure'] = False; break

    # 单位元
    for e in elements:
        if all(op(e, a) == a and op(a, e) == a for a in elements):
            results['identity'] = e; break

    # 逆元
    e = results['identity']
    if e is not None:
        for a in elements:
            if not any(op(a, b) == e and op(b, a) == e for b in elements):
                results['inverse'] = False; break

    # 结合律（随机抽样 - 完整验证成本 O(n^3)）
    for a, b, c in list(product(elements, repeat=3))[:50]:
        if op(op(a, b), c) != op(a, op(b, c)):
            results['associativity'] = False; break

    return results

def lagrange_check(group_order: int, subgroup_order: int) -> bool:
    """验证拉格朗日定理: |H| 整除 |G|"""
    return group_order % subgroup_order == 0

if __name__ == "__main__":
    # 测试 1: (Z_6, + mod 6) 是阿贝尔群，阶为 6
    Z6 = list(range(6))
    op_add6 = lambda a, b: (a + b) % 6
    axioms = verify_group_axioms(Z6, op_add6)
    assert axioms['closure'], "封闭性失败"
    assert axioms['identity'] == 0, f"单位元应为 0，得到 {axioms['identity']}"
    assert axioms['inverse'], "逆元不存在"
    assert axioms['associativity'], "结合律失败"
    print(f"Z_6 群公理验证: {axioms}")

    # 测试 2: 拉格朗日定理 - Z_6 的子群阶必须整除 6
    for h_order in [1, 2, 3, 6]:
        assert lagrange_check(6, h_order), f"{h_order} 不整除 6"
    # 反例: 4 不整除 6，所以 Z_6 没有 4 阶子群
    assert not lagrange_check(6, 4), "4 应不整除 6"

    print("拉格朗日定理验证: Z_6 的合法子群阶为 {1, 2, 3, 6}")
    print("群论基础单元测试完全成功！")
```
