# 序列与增长率

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类**
- **判断理由**：序列是离散数学的"连续函数"——差分对应导数，求和对应积分。增长率分析是算法复杂度分析的基础。MIT 6.042J PS8 考查。

---

## 1. 这个知识点解决什么问题？

> 数列如何用简洁的闭式表达？等差数列求和、等比数列增长、多项式的离散差分——这些是分析算法复杂度（$O(n), O(n^2), O(2^n)$）和求解递推关系的数学基础。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：序列 → 递推关系 → 生成函数 → 算法复杂度分析（大O记号体系）。
- **实际应用场景**：算法运行时间分析、分期付款计算、种群增长模型、数据结构的摊销分析。
- **高频题型**：求等差/等比数列通项与和；判断渐近增长阶；用差分法求多项式序列的和。

---

## 3. 学它之前需要哪些前置知识？

1. **[[数学归纳法]]**：验证求和公式的正确性。
2. **[[排列组合与二项式定理]]**：$\binom{n}{k}$ 在多项式序列中的出现。

## 4. 定义复述

**序列**：函数 $a: \mathbb{N} \to \mathbb{R}$，记作 $(a_n)$。

**等差数列**：$a_n = a_0 + nd$，递推 $a_n = a_{n-1} + d$。前 $n$ 项和：$S_n = \frac{n(a_1+a_n)}{2}$。

**等比数列**：$a_n = a_0 r^n$，递推 $a_n = r a_{n-1}$。前 $n$ 项和（$r \ne 1$）：$S_n = a_0\frac{1-r^{n+1}}{1-r}$。

**多项式序列**：$a_n$ 是 $n$ 的多项式。差分 $\Delta a_n = a_{n+1}-a_n$ 降次。

**增长率记号**：
- $a_n = O(b_n)$：存在 $C$ 使 $a_n \le C b_n$（上界）
- $a_n = \Theta(b_n)$：上下界一致（紧确界）
- $a_n = \Omega(b_n)$：下界

### 常见和式
- $\sum_{k=1}^n k = n(n+1)/2$
- $\sum_{k=1}^n k^2 = n(n+1)(2n+1)/6$
- $\sum_{k=0}^n r^k = (r^{n+1}-1)/(r-1)$

---

## 5. 直觉

- **直觉类比**：差分 $\Delta a_n$ 是离散的"速度"（一阶导数），二阶差分是"加速度"。等比序列增长等于"翻倍"，多项式序列增长等于"幂次"。
- **一句话直觉本质**：序列 = 离散世界的变化规律——差分是离散导数，求和是离散积分。

---

## 6. 定理：$\sum_{k=1}^n k = n(n+1)/2$ 的组合证明

将 $1$ 到 $n$ 写两遍（正序+倒序）：$(1+n)+(2+(n-1))+\cdots+(n+1) = n(n+1)$。每对被算了两次，故和 $= n(n+1)/2$。

**关键"转念"**：对称配对——从 Gauß 小学时的故事：$1+100=101, 2+99=101, \ldots, 50+51=101$，共 50 对。

---

## 7. 经典反例库

### 反例 1：混淆增长率顺序

- **问题**：$n^2 = O(2^n)$ 是正确的，但 $2^n = O(n^2)$ 是错误的。
- **反例构造**：$\lim_{n\to\infty} 2^n / n^2 = \infty$，故 $2^n$ 增长远快于 $n^2$。大O记号中多项式永远小于指数。
- **教训**：增长率有严格的层次：$\log n < n < n\log n < n^2 < 2^n < n!$

### 反例 2：等差求和公式的误用

- **问题**：求 $2+5+8+\cdots+98$ 的和。
- **常见错误**：$a_1=2, a_n=98$，项数 $n = (98-2)/3+1 = 33$，和 $= 33(2+98)/2 = 1650$。
- **正确**：此数列公差 $d=3$。验证：$a_{33} = 2+32\cdot 3 = 98$ ✓。和 $= 33\cdot 100/2 = 1650$ ✓。
- **教训**：必须正确计算项数——$(末项-首项)/公差+1$。
