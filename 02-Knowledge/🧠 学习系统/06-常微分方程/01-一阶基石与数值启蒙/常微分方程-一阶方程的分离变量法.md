# 一阶方程的分离变量法

---

## 0. 学习边界

- **类别**：**A 类（核心计算技能，必须掌握）**
- **判断理由**：这是你面对常微分方程的第一把也是最锋利的斧头。绝大多数物理和工程基础课（如传热学、人口模型）推导出的方程，都可以被这把斧头劈开。不会分离变量，这门课直接寸步难行。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 面对一阶方程 $\frac{dy}{dt} = f(t, y)$，我们最直白的冲动就是直接两边对 $t$ 积分：$y(t) = \int f(t, y) dt$。
> 但是！等号右边的积分里藏着未知的函数 $y(t)$，你根本没法积出来。我们需要一种方法，把混在一起的 $y$ 和 $t$ 强行拆散。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是所有解析解法的起点。后续的高阶降阶法、偏微分方程中的分离变量法（分离时间与空间），都继承了这种“分而治之”的核心思想。
- **高频场景**：人口指数增长（Malthus模型）、放射性衰变、牛顿冷却定律，全都是标准的分离变量方程。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景：
1. **[[常微分方程-微积分基础#基本积分表\|基本积分表]]**：必须熟练默写 $\int \frac{1}{y} dy = \ln|y| + C$，以及多项式积分。
2. **[[常微分方程-微积分基础#链式法则与微元\|链式法则与微元]]**：理解 $dy$ 和 $dt$ 可以像代数分数一样被“搬运”（这是莱布尼茨符号最大的工程优势）。

---

## 4. 用直觉语言解释它

> «“分离变量，就是让方程的两边各回各家、各找各妈。把所有带 $y$ 的项赶到等号左边，和 $dy$ 待在一起；把所有带 $t$ 的项赶到等号右边，和 $dt$ 待在一起。然后两边各自关起门来做积分。”»

- **为什么很自然**：既然混在一起没法积，那就利用乘除法把它们彻底隔离，这样左边就是纯 $y$ 的积分，右边就是纯 $t$ 的积分，互不干涉。

---

## 5. 正式定义与核心步骤

### 1. 适用条件 (可分离形式)
只有当一阶方程能被写成两个单变量函数相乘（或相除）的形式时，才适用：
$$\frac{dy}{dt} = g(t) \cdot h(y)$$
或者写成 $M(t) dt + N(y) dy = 0$。

> ⚠️ **预警**：如果是 $\frac{dy}{dt} = t + y$，它们是被加号连起来的，**绝不可能**通过乘除法分离！这属于一阶线性方程，需要用“积分因子法”。

### 2. 标准求解四步曲

- **第 1 步：代数分离**。利用乘除法，将 $h(y)$ 移到左边，$dt$ 移到右边。
  $$\frac{1}{h(y)} dy = g(t) dt$$
- **第 2 步：丢失解检查 (奇异解，极其重要)**。
  你在第 1 步除以了 $h(y)$。数学上除以 0 是非法的，这意味着上述分离只在 $h(y) \neq 0$ 的状态下有效。
  如果存在常数 $c$ 使得 $h(c) = 0$，那么常值函数 $y(t) \equiv c$ 必然是原方程的解（代入原方程验证：左边导数为0，右边 $g(t) \cdot 0 = 0$）。
  这类解被称为**奇异解 (Singular Solution)**，它们通常会被通解的积分过程排除在外（比如对应于 $C \to -\infty$）。必须在除法发生的这一刻就单独记录下来，最后再看看能否被放宽限制后的通解吸收！
- **第 3 步：两边各自积分**。
  $$\int \frac{1}{h(y)} dy = \int g(t) dt + C$$
  （注意：常数 $C$ 只需在等号右边写一个即可，不用两边都写，因为常数相减还是常数）。
- **第 4 步：严格处理绝对值与初值**。
  当你遇到 $\int \frac{1}{y} dy$ 时，结果是 $\ln|y|$，**绝对值符号绝对不能省略**！
  - 带着绝对值写出式子：$\ln|y| = G(t) + C$
  - 脱绝对值：$|y| = e^{G(t)+C} = e^C e^{G(t)}$
  - 引入正负号参数：$y = \pm e^C e^{G(t)}$。由于 $e^C > 0$，我们可以定义一个新非零常数 $A = \pm e^C$（此时 $A \neq 0$）。
  - **吸收奇异解**：回头看第 2 步，如果 $y=0$ 是丢失的奇异解，我们可以放宽 $A$ 的限制，允许 $A=0$，从而将通解无缝延拓为 $y = A e^{G(t)}$，其中 $A$ 可以是任何实数。

---

## 6. 例子：基础 → 中等 → 易错

### 例子 1：基础例子 (人口爆炸模型)
- **题目**：$\frac{dy}{dt} = k y$ （增长率正比于当前人口）
- **解题步骤（感受严谨的代数脚手架）**：
  1. **分离**：$\frac{1}{y} dy = k dt$ （仅当 $y \neq 0$ 时合法）
  2. **丢失解**：除以了 $y$，因此立刻记录 $y(t) \equiv 0$ 是一个奇异解（没人就永远没人，逻辑自洽）。
  3. **积分**：$\int \frac{1}{y} dy = \int k dt \implies \ln|y| = kt + C$ （绝不漏掉绝对值）
  4. **化简**：两边取指数，得 $|y| = e^{kt+C} = e^C e^{kt}$。
  5. **脱绝对值**：去掉绝对值，引入正负号：$y = \pm e^C e^{kt}$。令非零常数 $A = \pm e^C$，则在 $y \neq 0$ 的前提下通解为 $y = A e^{kt}$ ($A \neq 0$)。
  6. **吸收**：注意到 $A=0$ 时刚好能完美复现第 2 步捡起来的奇异解 $y=0$。所以合并后，万能通解就是 $y = A e^{kt}$，其中 $A \in \mathbb{R}$。

### 例子 2：易错例子 (丢失平衡解)
- **题目**：$\frac{dy}{dt} = y^2, \quad y(0) = 1$
- **解题步骤**：
  1. 分离：$y^{-2} dy = dt$
  2. 丢失解：$y=0$ 是丢失解。
  3. 积分：$-y^{-1} = t + C \implies y = \frac{-1}{t+C}$
  4. 代入初值：$y(0) = \frac{-1}{C} = 1 \implies C = -1$。
  5. 最终解：$y(t) = \frac{1}{1-t}$。
- **🤔 追问 (爆炸时间)**：当 $t \to 1$ 时，解趋于无穷大。这说明虽然存在唯一性定理保证了局部有解，但解在有限时间 $t=1$ 处发生了“爆炸”（Finite-time blow-up）。

---

## 7. 常见误区和易混概念

### 误区 1：乱用莱布尼茨符号
- **错误直觉**：认为 $\frac{dy}{dt}$ 真的就是一个分数，随便怎么倒腾都行。
- **正确理解**：$\frac{dy}{dt} = f(t,y)$ 分离变量写成 $g(y)dy = h(t)dt$ 的底层数学逻辑是**积分的换元法**：$\int g(y) \frac{dy}{dt} dt = \int h(t) dt$，左边根据换元法等价于 $\int g(y) dy$。虽然表现得像搬运代数分数，但脑子里必须清楚这是链式法则的逆运算。

### 误区 2：忘记加任意常数 $C$
- 许多人积分完忘记加 $C$，或者到了最后一步化简完了才生硬地在最后加一个 $+C$。
- **正确做法**：**完成积分符号的那一瞬间**，必须立刻在方程右侧写上 $+C$。早加和晚加，结果天壤之别！

### 题目与解析

#### 1. [基础计算] Diffy Qs 1.3 Exercise
> [!question]- 答案与解析（复盘阶段查看）
> - **题目**：求解微分方程 $\frac{dy}{dt} = t^2 y$。
> - **答案/证明**：$y = C e^{\frac{t^3}{3}}$
> - **解析**：分离变量得到 $\frac{dy}{y} = t^2 dt$，积分得到 $\ln\|y\| = \frac{t^3}{3} + C$，化简得指数形式。注意 $y=0$ 也是解。

#### 2. [IVP求解] MIT 18.03SC Problem Set 1
> [!question]- 答案与解析（复盘阶段查看）
> - **题目**：求解初值问题 $\frac{dy}{dt} = \frac{t}{y}$，且 $y(0) = -2$。
> - **答案/证明**：$y = -\sqrt{t^2 + 4}$
> - **解析**：分离变量 $y dy = t dt$，积分得 $\frac{y^2}{2} = \frac{t^2}{2} + C \implies y^2 = t^2 + 2C$。代入初值 $(-2)^2 = 0 + 2C \implies 2C = 4$。因此 $y^2 = t^2 + 4$。因为 $y(0) = -2 < 0$，取负号分支。
