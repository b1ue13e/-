# 常数变易法原理

---

## 1. 这是什么？

求解一阶非齐次方程 $y' + p(x)y = f(x)$，除了积分因子法外，还有一种极其强大的通用方法——**常数变易法 (Variation of Parameters)**。这套方法不仅能解一阶方程，更是求解高阶非齐次线性方程的万能钥匙。

## 2. 核心步骤与直觉

**直觉**："齐次解包含了系统的本质结构，非齐次项只是在这个结构上施加了动态的改变"。
如果齐次解是 $y = C y_1(x)$，当受到外界强制力 $f(x)$ 干扰时，解的形状依然由 $y_1$ 决定，只是常数 $C$ 被强制力“逼迫”成了一个随时间变化的函数 $C(x)$。

**步骤（以一阶线性方程为例）**：
1. **先解齐次方程** $y' + p(x)y = 0$。分离变量得到 $y_h = C e^{-P(x)}$。
2. **常数变易**：设非齐次方程的解为 $y = C(x) e^{-P(x)}$。
3. **代入原方程**：
   $y' = C'(x) e^{-P(x)} - p(x)C(x)e^{-P(x)}$
   代入 $y' + py = f(x)$：
   $[C' e^{-P} - p C e^{-P}] + p [C e^{-P}] = f(x)$
   极其神奇的是，包含 $C(x)$（不带导数）的项**必然会完美抵消**！
   剩下：$C'(x) e^{-P(x)} = f(x)$。
4. **积分求 $C(x)$**：$C'(x) = f(x)e^{P(x)} \implies C(x) = \int f(x)e^{P(x)} dx + C_0$。
5. **代回**得到最终通解。
