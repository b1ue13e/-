# 常数变易法原理

---

## 1. 这是什么？

求解一阶非齐次方程 $y' + p(x)y = f(x)$，除了积分因子法外，还有一种极其强大的通用方法——**常数变易法 (Variation of Parameters)**。这套方法不仅能解一阶方程，更是求解高阶非齐次线性方程的万能钥匙。

## 2. 核心步骤与直觉

**直觉**："齐次解包含了系统的本质结构，非齐次项只是在这个结构上施加了动态的改变"。
如果齐次解是 $y = C y_1(x)$，当受到外界强制力 $f(x)$ 干扰时，解的形状依然由 $y_1$ 决定，只是常数 $C$ 被强制力“逼迫”成了一个随时间变化的函数 $C(x)$。

**步骤（以一阶线性方程为例）**：
1. **先解齐次方程** $y' + p(x)y = 0$。分离变量得到 $y_h = C e^{-P(x)}$。
2. **常数变易**：设非齐次方程的解为 $y = C(x) e^{-P(x)}$。
3. **代入原方程**：
   $y' = C'(x) e^{-P(x)} - p(x)C(x)e^{-P(x)}$
   代入 $y' + py = f(x)$：
   $[C' e^{-P} - p C e^{-P}] + p [C e^{-P}] = f(x)$
   极其神奇的是，包含 $C(x)$（不带导数）的项**必然会完美抵消**！
   剩下：$C'(x) e^{-P(x)} = f(x)$。
4. **积分求 $C(x)$**：$C'(x) = f(x)e^{P(x)} \implies C(x) = \int f(x)e^{P(x)} dx + C_0$。
5. **代回**得到最终通解。

## 3. 最小例子（可手算）

**例**：$y' + \frac{2}{x}y = x^3$（$x>0$）。

1. 齐次：$y' + \frac{2}{x}y = 0 \Rightarrow y_h = Cx^{-2}$。
2. 变易：$y = C(x)x^{-2}$，$y' = C'(x)x^{-2} - 2C(x)x^{-3}$。
3. 代入：$C'x^{-2} - 2Cx^{-3} + \frac{2}{x}Cx^{-2} = C'x^{-2} = x^3 \Rightarrow C' = x^5$。
4. 积分：$C(x) = \frac{x^6}{6} + C_0$。
5. 通解：$y = \left(\frac{x^6}{6} + C_0\right)x^{-2} = \frac{x^4}{6} + \frac{C_0}{x^2}$。

检验：代入原方程成立，且与积分因子法结果一致（交叉验证）。

## 4. 反例：为什么必须"从齐次解出发"

**反例**：若设 $y = C(x) \cdot \text{(任意函数)}$ 而不是齐次解 $y_1$，则代入后 $C(x)$ 的项**不会抵消**，剩不下关于 $C'$ 的干净方程——方法失效。这解释了常数变易法的适用前提：**必须先求得齐次解 $y_1$**。若齐次方程解不出来（变系数且非特殊型），常数变易法无法使用。

## 5. 条件变式

| 变式 | 改变什么 | 结果是否改变 | 结论 |
| :--- | :--- | :---: | :--- |
| 一阶线性 → 高阶线性 | 把常数 $C$ 换成函数 $C_1(x), \dots, C_n(x)$ | 方法推广 | 成立（Wronskian 非零约束） |
| 齐次解是复根形式 | $y_1$ 含 $\cos/\sin$ | 步骤相同 | 成立 |
| 用非齐次特解当"齐次解" | 出发点错误 | 抵消失败 | 不成立 |
| 系数 $p(x)$ 有奇点 | 积分区间含奇点 | 解表达式需分段 | 局部成立 |

## 6. 常见误区

1. **忘记"变易"发生在齐次解上**：直接从 $y = C(x)$ 出发得不到抵消效果。
2. **二阶情形的 Wronskian 条件**：高阶常数变易要求 $y_1, \dots, y_n$ 线性无关（Wronskian 非零），否则法方程组退化。
3. **与待定系数法混用**：常数变易法对任意连续 $f(x)$ 均适用（代价是积分），待定系数法只对特定 $f$（多项式/指数/三角）适用——两者是互补关系而非替代。
