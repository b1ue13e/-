# 相平面与轨线分析

> 所属模块：[[🗺️ 常微分方程学习路径|常微分方程学习路径]] · 返回阶段：[[02-Knowledge/🧠 学习系统/06-常微分方程/02-中级/📗 第二阶段：中级|第二阶段：中级]] / [[02-Knowledge/🧠 学习系统/06-常微分方程/03-进阶/📙 第三阶段：进阶|第三阶段：进阶]]

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心方法，必须深挖）**。相平面是把"解函数"升级为"几何轨迹"的根本视角切换，是后续所有定性理论（稳定性、极限环、混沌）的共同语言。
- **判断理由**：大部分一阶/线性系统可以写解析解，但一旦方程给不出通解，唯一还能回答"长期行为是什么"的办法就是相平面分析。它不追求闭式公式，只画轨迹、看形状。
- **验收模式说明**：本卡不设置指标/冲榜类任务；验收只看「定义复述、证明重建、反例、条件变式、闭卷验收」五项是否通过。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：面对一个方程组
> $$x' = f(x,y),\qquad y' = g(x,y)$$
> 比如摆的方程 $\theta'' + \frac{g}{L}\sin\theta = 0$ 化成的一阶系统，我们**写不出通解**，甚至写不出任何闭式解。此时"求解"这条路彻底卡死——我们怎么知道解会不会爆炸？会不会绕圈？会不会被某个点吸走？
>
> **相平面的回答**：把解 $(x(t), y(t))$ 看成平面 $\mathbb{R}^2$ 上一条随参数 $t$ 运动的曲线（**轨线**），把整个方程看成一个"速度场"（**方向场**）。不再问"解是什么函数"，改问"轨迹长什么样"。形状对了，长期行为就有了。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：不学它，后续的 [[非线性方程定性理论]]（平衡点分类、极限环、分岔）、[[稳定性理论基础]]（Lyapunov 稳定性）以及 [[03-进阶/📙 第三阶段：进阶|进阶阶段]] 全部读不懂。它是整座定性理论大厦的地基。
- **实际应用场景**：一切"状态演化"问题的定性分析——摆、电路（[[04-精通与专题/电路建模|电路建模]]）、[[04-精通与专题/种群建模|种群建模]]（Lotka–Volterra）、[[项目-Lorenz|Lorenz 系统]] 等，第一件事都是画相图。
- **高频考点**：2×2 线性系统奇点分类（结点/鞍点/焦点/中心 × 稳定/不稳定）、由特征值手判奇点类型、方向场作图、轨线不相交的判断。

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[线性方程组与矩阵方法]]**：2×2 矩阵的特征值、特征向量、$e^{At}$。因为线性系统的相图完全由特征值决定，本卡第 6 节的分类定理就建立在特征分解之上。
2. **[[解的存在唯一性定理]]**：Picard–Lindelöf（本库细卡 [[Picard迭代]] / [[Picard结论]]；主教材 Diffy Qs §1.2.2、§3.1.5）。相曲线不相交定理、流的良好定义，全部依赖"初值唯一决定解"这一条。
3. **[[特征值定义]]** 与 [[02-中级/基解矩阵|基解矩阵]]：给出线性系统解的显式结构，才能解释"为什么形状如此"。

## 4. 定义复述

### 1. 精确定义

**自治系统**：$\mathbf{x}' = f(\mathbf{x})$，其中 $f: D \subseteq \mathbb{R}^2 \to \mathbb{R}^2$（二维情形），$D$ 为开集，$f$ 为 $C^1$ 函数（至少局部 Lipschitz）。

- **方向场（vector field）**：在平面每一点 $\mathbf{p}$ 上放置向量 $f(\mathbf{p})$，得到的就是方向场。解的切线方向处处与 $f$ 平行。
- **轨线 / 相轨线（trajectory / orbit）**：初值问题 $\mathbf{x}'=f(\mathbf{x}),\ \mathbf{x}(0)=\mathbf{x}_0$ 的解 $\varphi(t;\mathbf{x}_0)$ 在平面中扫出的点集
  $$O(\mathbf{x}_0) = \{\varphi(t;\mathbf{x}_0) : t \in I\},$$
  其中 $I$ 是解的最大存在区间。
- **相平面（phase plane）**：把 $(x,y)$ 当作状态的平面 $\mathbb{R}^2$。强调：平面上的点不是几何位置，而是**系统的状态**；运动是状态随时间的变化。
- **相图（phase portrait）**：方向场加上若干代表性轨线，形成的完整图像。
- **奇点 / 临界点 / 平衡点（critical point / equilibrium）**：$f(\mathbf{x}_0)=0$ 的点。在奇点上方向场为零向量，$\varphi(t;\mathbf{x}_0) \equiv \mathbf{x}_0$ 是常数解。
- **周期轨（periodic orbit）**：若存在 $T>0$ 使 $\varphi(T;\mathbf{x}_0)=\mathbf{x}_0$（且 $\varphi(t;\mathbf{x}_0)\neq \mathbf{x}_0,\ 0<t<T$），则轨线闭合成环。

### 2. 等价形式

| 形式 | 表述 | 适用场景 |
| :--- | :--- | :--- |
| 参数曲线 | $t \mapsto (x(t),y(t))$，$t$ 为参数 | 解轨线 |
| 一阶 ODE 的斜率方程 | $\dfrac{dy}{dx} = \dfrac{g(x,y)}{f(x,y)}$（$f\neq 0$ 处） | 直接画轨线形状 |
| 相流 | $\varphi_t(\mathbf{x}_0)=\varphi(t;\mathbf{x}_0)$，一族保时映射 | 与 [[动力系统与遍历理论]] 衔接 |

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $f=(f,g)$ | 速度场（右端函数） | $D\to\mathbb{R}^2$ | 自治：不含 $t$ |
| $\varphi(t;\mathbf{x}_0)$ | 过 $\mathbf{x}_0$ 的解流 | $t\in I$ | 也叫流/解映射 |
| $O(\mathbf{x}_0)$ | 轨线（点集） | 平面中的曲线 | 不含方向信息 |
| $\lambda_1,\lambda_2$ | 线性化矩阵的特征值 | $\mathbb{C}$ | 决定奇点类型 |
| $\tau,\Delta$ | 矩阵的迹与行列式 | $\mathbb{R}$ | $\lambda^2-\tau\lambda+\Delta=0$ |

## 5. 直觉与图像

- **直觉类比/几何图像**：相平面是"**不看公式看轨迹的地图**"。想象一条河，方向场就是每一点的水流方向与流速；丢一片叶子（初值），叶子沿水流走的路线就是轨线。奇点是"水面静止"的漩涡眼（稳定）或"喷泉口"（不稳定）。你不用知道水流方程，只看叶子怎么漂，就能说出它最后被冲去哪。
- **为什么很自然**：微分方程给的是"每一瞬间的倾向"（$\mathbf{x}'$），而轨迹是这些瞬间倾向的累积。问"瞬间倾向怎么走"，比问"最终表达式是什么"更本质——后者往往根本不存在。
- **一句话直觉本质**：**方向场 = 处处写好的"下一步方向"说明书；轨线 = 照着说明书走出来的路线；奇点 = 说明书说"原地不动"的地方。**

> ⚠️ 直觉只是导航，不是证明。任何直觉表述都要能回到第 4 节的精确定义。

## 6. 定理陈述与证明重建

### 定理 A：2×2 线性系统奇点完整分类定理

**前提**：$\mathbf{x}' = A\mathbf{x}$，$A$ 为 $2\times 2$ 实矩阵且 $\det A \neq 0$（奇点是孤立的）。记特征值为 $\lambda_1,\lambda_2 \in \mathbb{C}$（按重数计），对应（广义）特征向量为 $\mathbf{v}_1,\mathbf{v}_2$。
**结论**：由 $\lambda_1,\lambda_2$ 完全决定奇点 $\mathbf{0}$ 的类型与稳定性，如下表（主教材 Diffy Qs §3.5，Table 3.1）：

| 特征值 | 奇点名称 | 稳定性 | 轨线形状 |
| :--- | :--- | :--- | :--- |
| 实根，同为负 | 稳定结点（sink / stable node） | 渐近稳定 | 所有轨线沿某方向切入原点 |
| 实根，同为正 | 不稳定结点（source / unstable node） | 不稳定 | 所有轨线沿某方向切出原点 |
| 实根，异号 | 鞍点（saddle） | 不稳定 | 双曲型曲线；仅两条特殊轨线进出 |
| 共轭复根，实部为负 | 稳定焦点（spiral sink） | 渐近稳定 | 旋转收缩的螺线 |
| 共轭复根，实部为正 | 不稳定焦点（spiral source） | 不稳定 | 旋转扩张的螺线 |
| 共轭复根，实部为零 | 中心（center） | 稳定但非渐近 | 一族椭圆闭轨 |

**出处**：Notes on Diffy Qs §3.5（`sec_twodimaut`），Table 3.1；重复特征值情形在 §3.7；等价表述的"迹—行列式平面"见 MIT 18.03SC Unit IV（§-级引用 [待验证]）。

### 2. 证明主线（骨架）：每个情形的解结构

关键事实：对 $\det A\neq 0$ 的 $2\times2$ 矩阵，总能用（广义）特征向量解耦求解，通解结构决定几何。

- **第 1 步（解耦）**：若 $\lambda_1\neq\lambda_2$ 为实特征值，$\mathbf{v}_1,\mathbf{v}_2$ 为特征向量，则
  $$\mathbf{x}(t) = c_1 e^{\lambda_1 t}\mathbf{v}_1 + c_2 e^{\lambda_2 t}\mathbf{v}_2.$$
  两个指数项各自沿一条固定直线（特征方向）伸缩，轨线是这两个"纯指数运动"的叠加。这是全分类的发动机。
  - *同号情形*：设 $\lambda_2<\lambda_1<0$。当 $t\to+\infty$，两项都趋于 $\mathbf{0}$，但 $e^{\lambda_2 t}$ 衰减**更快**，故 $e^{\lambda_1 t}$ 项占优，轨线沿慢特征方向（$\mathbf{v}_1$）切入原点 → **结点**。稳定/不稳定仅由实部符号翻转（$t\to-\infty$ 即得 source）。这就是"为什么形状是全部轨线切着一条线进入"。
  - *异号情形*：设 $\lambda_1>0>\lambda_2$。沿 $\mathbf{v}_2$ 的方向（$c_1=0$）轨线直线进入原点——**稳定流形** $E^s=\operatorname{span}(\mathbf{v}_2)$；沿 $\mathbf{v}_1$（$c_2=0$）直线逃逸——**不稳定流形** $E^u=\operatorname{span}(\mathbf{v}_1)$。一般轨线（$c_1c_2\neq0$）在 $t\to\pm\infty$ 时分别趋近这两条直线，画出来是双曲型曲线 → **鞍点**。
- **第 2 步（重根）**：$\lambda$ 为重实根（§3.7）。
  - 若 $A=\lambda I$（可对角化），$\mathbf{x}(t)=e^{\lambda t}\mathbf{x}_0$，所有轨线是经过原点的直线 → **奇结点（proper node / star）**。
  - 若 $A$ 是 Jordan 块（不可对角化），$\mathbf{x}(t)=e^{\lambda t}\big(c_1\mathbf{v} + c_2(t\mathbf{v}+\mathbf{w})\big)$，含 $te^{\lambda t}$ 项 → **退化结点（degenerate node）**：多数轨线沿一个方向切向原点。
- **第 3 步（复根）**：$\lambda=\alpha\pm i\beta,\ \beta\neq 0$。取特征向量 $\mathbf{v}=\mathbf{a}+i\mathbf{b}$，则
  $$\mathbf{x}(t) = e^{\alpha t}\Big[\cos(\beta t)\,\mathbf{a} - \sin(\beta t)\,\mathbf{b},\ \dots\Big],$$
  即解是"以角速度 $\beta$ 旋转、半径以 $e^{\alpha t}$ 伸缩"的运动 → $\alpha>0$ 螺旋源、$\alpha<0$ 螺旋汇、$\alpha=0$ 椭圆闭轨（中心）。这就是"为什么复根必旋转"：复指数 $e^{(\alpha+i\beta)t}=e^{\alpha t}e^{i\beta t}$ 自带一个圆。
- **关键"转念"**：把矩阵方程**解耦成特征方向上的标量指数方程**——相图不是凭空猜的，而是"两条指数曲线在平面上的张成"。谁慢谁占优、谁正谁负，几何就长什么样。

**定理 A 的等价工具：迹—行列式（$\tau$-$\Delta$）平面。**
特征多项式 $\lambda^2-\tau\lambda+\Delta=0$，判别式 $D=\tau^2-4\Delta$：

| 判别 | 条件 | 类型 |
| :--- | :--- | :--- |
| $D>0$ | $\Delta<0$ | 鞍点 |
| $D>0$ | $\tau<0,\ \Delta>0$ | 稳定结点 |
| $D>0$ | $\tau>0,\ \Delta>0$ | 不稳定结点 |
| $D=0$ | — | 结点/退化结点分界 |
| $D<0$ | $\tau<0$ | 稳定焦点 |
| $D<0$ | $\tau>0$ | 不稳定焦点 |
| $D<0$ | $\tau=0$ | 中心 |

主教材 Diffy Qs 用特征值分类（§3.5 Table 3.1）而非 $\tau$-$\Delta$ 平面；后者是 MIT 18.03 系统的等价表述，二者结论一致。$\tau$-$\Delta$ 平面便于口算：**$\Delta<0\Rightarrow$ 鞍点，$\Delta>0$ 且 $\tau^2\ge4\Delta$ 看 $\tau$ 符号定结点，$\tau^2<4\Delta$ 看 $\tau$ 定焦点，$\tau=0$ 且 $\Delta>0$ 为中心。**

### 定理 B：相曲线不相交定理（由唯一性推出，完整证明）

**前提**：$\mathbf{x}'=f(\mathbf{x})$，$f$ 在 $D$ 上 $C^1$（或局部 Lipschitz），从而初值问题解唯一（Picard–Lindelöf，Diffy Qs §1.2.2 / §3.1.5）。
**结论**：任意两条不同的轨线 $O(\mathbf{x}_0)$ 与 $O(\mathbf{y}_0)$ 不相交；等价地，若两条轨线共有一个点，则它们重合。

**证明**（完整）：
设 $\mathbf{p}\in O(\mathbf{x}_0)\cap O(\mathbf{y}_0)$，即存在 $t_1,t_2$ 使 $\varphi(t_1;\mathbf{x}_0)=\varphi(t_2;\mathbf{y}_0)=\mathbf{p}$。定义两条"重新定时的解"：
$$\psi_1(s):=\varphi(t_1+s;\mathbf{x}_0),\qquad \psi_2(s):=\varphi(t_2+s;\mathbf{y}_0).$$
两者都在同一区间 $I$ 上定义（各自为平移后的最大存在区间），且
$$\psi_1(0)=\mathbf{p}=\psi_2(0),\qquad \psi_1' = f\circ\psi_1,\ \psi_2' = f\circ\psi_2.$$
即 $\psi_1,\psi_2$ 都是初值问题 $\mathbf{z}'=f(\mathbf{z}),\ \mathbf{z}(0)=\mathbf{p}$ 的解。由解的唯一性，$\psi_1\equiv\psi_2$。因此作为点集
$$O(\mathbf{x}_0)=\{\psi_1(s)\}=\{\psi_2(s)\}=O(\mathbf{y}_0).$$
故两条"不同"的轨线不可能有公共点。∎

**推论**：非周期轨线不能自交（若自交则它是周期轨）；不同初值给出的解曲线在相平面中互不相碰，只能渐近靠近（如进入同一焦点）。

### 4. 证明技巧迁移

- **解耦 + 谁慢谁占优**（慢特征方向决定切入方向）→ 可迁移到一般线性系统、[[02-中级/基解矩阵|基解矩阵]]、矩阵指数的估计。

- **迹—行列式判别式 $D=\tau^2-4\Delta$** → 可迁移到[[03-进阶/非线性方程定性理论|非线性]]平衡点判别（同一判别式在 Jacobian 上重演）。

## 7. 经典反例库

> 数学的边界由反例划定。每个反例回答一个问题：「这个条件能省吗？」

### 反例 1：Lipschitz 条件不能省——"相曲线相交"的伪例子

- **问题**：去掉唯一性（$f$ 仅连续、不 Lipschitz），"轨线不相交"还成立吗？
- **反例构造**：一维（可视为平面退化情形，$y'=0$ 即嵌入平面）
  $$x' = 3x^{2/3}.$$
  常数解 $x\equiv 0$ 是一条轨线（平衡点）；同时 $x(t)=(t+C)^3$ 也是解（代入即验：$3(t+C)^2 = 3\big((t+C)^3\big)^{2/3}=3(t+C)^2$）。取 $C=0$，解 $x(t)=t^3$ 在 $t=0$ 与平衡解 $x\equiv0$ 相交于原点 $(0,0)$——两条**不同**的轨线在相平面（直线）上共点。
- **结论崩塌点**：$f(x)=3x^{2/3}$ 在 $x=0$ 处导数无界（$f'(x)=2x^{-1/3}\to\infty$），不满足 Lipschitz，Picard–Lindelöf 的唯一性失效，定理 B 证明中"$\psi_1\equiv\psi_2$"这一步不再成立。**教训：唯一性不是装饰品，是"轨线不相交"的承重墙。**

### 反例 2：中心的"稳定性"是脆弱的（非通用结构）

- **问题**：线性系统的中心（特征值纯虚）在加任意小扰动后还保持吗？
- **反例构造**：$A=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$（特征值 $\pm i$，中心）。给 $(1,1)$ 位置加小量 $\varepsilon$：$A_\varepsilon=\begin{pmatrix}\varepsilon&-1\\1&\varepsilon\end{pmatrix}$。则 $\tau=2\varepsilon,\ \Delta=1$，特征值 $\lambda=\varepsilon\pm i$。任何 $\varepsilon\neq0$ 都把中心变成**焦点**（$\varepsilon<0$ 稳定，$\varepsilon>0$ 不稳定）。
- **教训**：$\tau=0$ 落在 $\tau$-$\Delta$ 平面的**零测度边界**上，是小扰动就会离开的非通用情形。这就是为什么在 [[非线性方程定性理论]] 中"线性化是中心"时结论必须打问号——中心稳定性由**非线性项**决定，而非线性项可以把它推向任一方向。

## 8. 条件变式

> 把条件改一改，结论还成立吗？这是数学学习最有效的自检方式。

| 变式 | 条件改动 | 结论变化 | 成立/不成立 | 依据（证明或反例） |
| :--- | :--- | :--- | :---: | :--- |
| 同号实根→异号实根 | $\lambda_1\lambda_2<0$ | 结点→鞍点 | 成立 | 定理 A 情形 2，$E^s/E^u$ 出现 |
| 中心加实扰动 | $\tau:0\to\varepsilon$ | 中心→焦点 | 不成立 | 反例 2 |
| $f$ 仅连续非 Lipschitz | 去掉唯一性 | 轨线可相交 | 不成立 | 反例 1：$x'=3x^{2/3}$ |
| 二维→三维 | $\mathbb{R}^2\to\mathbb{R}^3$ | 相"平面"不存在，需相空间；分类定理失效 | 不成立 | 高维有"太多空间"，见 [[非线性方程定性理论]] P–B 定理的二维性 |

### 题目与解析

#### 1. 判断题
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：判断下列命题真假并说明理由：相平面上的点 $(x,y)$ 表示系统的两个状态变量当前取值；轨线是解的图像。
> - **答案/证明**：真。相平面的点就是状态；轨线是解映射的点集，不画 $t$ 轴、只画状态平面。
> - **解析**：要点是"平面上的坐标是状态不是位置"，这是相平面与"解的 $xy$-图"的本质区别。
> - **易错原因**：把相平面当成 $(t,x)$ 的时空图。
> - **对应反例/变式**：见第 4 节符号说明表。

#### 2. $\det A=0$ 的边界情形
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：分类 $\mathbf{x}'=\begin{pmatrix}1&0\\0&0\end{pmatrix}\mathbf{x}$ 的奇点。
> - **答案/证明**：特征值 $1,0$。$y'=0\Rightarrow y\equiv y_0$；$x'=x\Rightarrow x(t)=x_0 e^t$。整个 $x$-轴由平衡点组成（$f(x,0)=0$），其余轨线是沿 $x$ 方向远离平衡线运动的水平直线。
> - **解析**：$\det A=0$ 时奇点不孤立，Table 3.1 前提不满足。此类情形的处理见 Diffy Qs §3.5 习题 3.5.5 / 3.5.103。
> - **易错原因**：硬套 Table 3.1，忽略"奇点孤立"前提。
> - **对应反例/变式**：条件变式表的 $\det A=0$ 行。

#### 3. 重根情形
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：比较 $\mathbf{x}'=\begin{pmatrix}-1&0\\0&-1\end{pmatrix}\mathbf{x}$ 与 $\mathbf{x}'=\begin{pmatrix}-1&1\\0&-1\end{pmatrix}\mathbf{x}$ 的相图差异。
> - **答案/证明**：前者 $A=-I$，$\mathbf{x}(t)=e^{-t}\mathbf{x}_0$，轨线为过原点的直线（奇结点/星形结点）。后者为 Jordan 块，$\mathbf{x}(t)=e^{-t}\big(c_1\mathbf{v}+c_2(t\mathbf{v}+\mathbf{w})\big)$ 含 $te^{-t}$ 项，轨线沿一个方向切入原点（退化结点）。
> - **解析**：可对角化与否决定重根下是否出现旋转混合项 $te^{\lambda t}\mathbf{w}$。细节见 Diffy Qs §3.7。
> - **易错原因**：只记"重根→结点"，忽略奇/退化之分。
> - **对应反例/变式**：习题 3 对应定理 A 第 2 步。

#### 4. 手算综合例题（本卡主例题）
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：给定 $\mathbf{x}'=\begin{pmatrix}1&2\\4&3\end{pmatrix}\mathbf{x}$，手算特征值，判定奇点类型与稳定性，画相图草图。
> - **答案/证明**：$\tau=1+3=4,\ \Delta=1\cdot3-2\cdot4=-5<0$ ⇒ **鞍点**（不依赖 $\tau$ 符号）。验算：特征值 $\lambda_{1,2}=(4\pm\sqrt{16+20})/2=(4\pm6)/2$，即 $\lambda=5$ 与 $\lambda=-1$，异号实根。$\lambda=5$ 对应特征向量：解 $(A-5I)\mathbf{v}=0$ 得 $\mathbf{v}_1=(1,2)$（不稳定流形方向）；$\lambda=-1$ 对应 $(A+I)\mathbf{w}=0$ 得 $\mathbf{w}_1=(1,-1)$（稳定流形方向）。
> - **相图草图**：方向场呈双曲形；两条直线轨线——沿 $(1,-1)$ 进入原点、沿 $(1,2)$ 离开原点；其余轨线先沿 $(1,2)$ 方向走、再折向 $(1,-1)$ 方向切向原点。
> - **解析**：用 $\tau$-$\Delta$ 平面：$\Delta<0$ 一票判定鞍点，免去开根。相图与方向场见下方 Python 程序。
> - **易错原因**：忘记 $\Delta<0$ 时与 $\tau$ 无关恒为鞍点。
> - **对应反例/变式**：见 §5 直觉与 §6 定理 A 情形 2。

#### 5. 扰动下相图拓扑
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：讨论 $\mathbf{x}'=A_\varepsilon\mathbf{x},\ A_\varepsilon=\begin{pmatrix}\varepsilon&1\\-1&\varepsilon\end{pmatrix}$ 的相图随 $\varepsilon$ 的变化。
> - **答案/证明**：特征值 $\varepsilon\pm i$。$\varepsilon<0$：稳定焦点；$\varepsilon=0$：中心；$\varepsilon>0$：不稳定焦点。临界 $\varepsilon=0$ 处相图拓扑突变（闭轨族→螺线族）。
> - **解析**：这是反例 2 的延伸，展示"非通用结构（中心）只在零测度参数点上出现"。此类"参数变化导致相图定性变化"正是 [[非线性方程定性理论]] 中分岔的线性版本。
> - **易错原因**：以为中心可以"稳稳地"存在于线性系统族中。
> - **对应反例/变式**：反例 2。

## 附：可运行 Python——方向场与轨线（鞍点）

```python
import matplotlib
matplotlib.use('Agg')          # 无显示器环境用 Agg；交互环境可删此行
import numpy as np
import matplotlib.pyplot as plt

# 手算例题：x' = x + 2y,  y' = 4x + 3y
# A = [[1,2],[4,3]],  tau=4, Delta=-5 < 0  ->  鞍点，特征值 5 与 -1
def f(state):
    x, y = state
    return np.array([x + 2*y, 4*x + 3*y])

# --- 方向场（streamplot）---
Y, X = np.mgrid[-3:3:15j, -3:3:15j]
U, V = f([X, Y])
M = np.hypot(U, V)             # 归一化速度，避免箭头长短差异过大
M[M == 0] = 1
plt.streamplot(X, Y, U/M, V/M, density=1.2, color='C0', arrowstyle='->')

# --- 四条 RK4 轨线（从不同初值出发）---
for s0 in [(0.5,0.1), (0.1,0.5), (-0.5,0.1), (-0.1,0.5)]:
    T = np.linspace(0, 2.0, 300)
    sol = np.zeros((len(T), 2)); sol[0] = s0
    for i in range(1, len(T)):
        dt = T[1] - T[0]
        k1 = f(sol[i-1]); k2 = f(sol[i-1] + dt/2*k1)
        k3 = f(sol[i-1] + dt/2*k2); k4 = f(sol[i-1] + dt*k3)
        sol[i] = sol[i-1] + dt/6*(k1 + 2*k2 + 2*k3 + k4)
    plt.plot(sol[:,0], sol[:,1], 'k-', lw=1)

plt.title("Saddle: x'=x+2y, y'=4x+3y  (eigenvalues 5, -1)")
plt.xlabel('x'); plt.ylabel('y')
plt.axis('equal'); plt.grid(alpha=0.3)
# 预期输出：双曲形方向场；黑色轨线先沿不稳定方向 (1,2) 离开、
#          再折向稳定方向 (1,-1) 切向原点。屏幕出现一个鞍点相图。
plt.savefig('phase_saddle.png', dpi=150)
```
