# 非线性系统的局部线性化（雅可比矩阵）

---

## 1. 这个知识点解决什么问题？

前面的相图分类全是针对**线性系统** $\mathbf{x}' = A\mathbf{x}$。
但自然界绝大多数系统是**非线性**的，例如摆的方程、Lotka-Volterra 捕食者-猎物模型。
面对复杂的非线性场 $f(x,y)$，我们要如何判断它的平衡点是稳定还是不稳定？

## 2. 核心思想：微积分的本质是局部线性化

在单变量微积分中，曲线在某一点的切线可以近似代替这条曲线。
在多变量动力系统中，我们也可以用平衡点处的**雅可比矩阵（Jacobian Matrix）**来近似局部的非线性向量场。

对于系统：
$x' = f(x,y)$
$y' = g(x,y)$

在平衡点 $(x_0, y_0)$ 处，雅可比矩阵为：
$$ J = \begin{pmatrix} \frac{\partial f}{\partial x} & \frac{\partial f}{\partial y} \\ \frac{\partial g}{\partial x} & \frac{\partial g}{\partial y} \end{pmatrix}_{(x_0, y_0)} $$

我们计算出这个 $J$ 矩阵后，就直接把它当成上一节的矩阵 $A$，去算它的 Trace 和 Det，从而判断平衡点类型！

## 3. 定义复述

**定义（雅可比矩阵）**：设 $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^n$ 在点 $\mathbf{x}_0$ 附近可微，其雅可比矩阵 $J(\mathbf{x}_0)$ 是 $\mathbf{f}$ 在 $\mathbf{x}_0$ 的一阶导数的矩阵表示，$(J)_{ij} = \frac{\partial f_i}{\partial x_j}(\mathbf{x}_0)$。

**定理（Hartman-Grobman）**：设 $\mathbf{x}_0$ 是非线性系统 $\mathbf{x}' = \mathbf{f}(\mathbf{x})$ 的平衡点（$\mathbf{f}(\mathbf{x}_0) = \mathbf{0}$），$J = D\mathbf{f}(\mathbf{x}_0)$。若 $J$ 的所有特征值实部均非零（即 $\mathbf{x}_0$ 是**双曲平衡点**），则非线性系统在 $\mathbf{x}_0$ 附近的局部相图与线性化系统 $\mathbf{u}' = J\mathbf{u}$ 在原点附近的相图**拓扑等价**——平衡点类型（结点/焦点/鞍点）与稳定性完全一致。

**推论（中心情形的失效）**：若 $J$ 存在纯虚特征值（实部为零，如中心），Hartman-Grobman 定理不适用，线性化结论**不可信**——必须回到非线性分析（如 Lyapunov 函数、中心流形）。

## 4. 最小例子（可手算）

**例**：摆的小幅运动系统
$$ \theta'' + \frac{g}{L}\sin\theta = 0 \quad \Longleftrightarrow \quad \begin{cases} x' = y \\ y' = -\frac{g}{L}\sin x \end{cases} $$

1. 平衡点：$(\sin x = 0, y = 0) \Rightarrow (x, y) = (k\pi, 0)$。取 $(0,0)$（最低点）与 $(\pi, 0)$（倒立点）。
2. 雅可比矩阵：
$$ J = \begin{pmatrix} 0 & 1 \\ -\frac{g}{L}\cos x & 0 \end{pmatrix} $$
3. 在 $(0,0)$：$J = \begin{pmatrix} 0 & 1 \\ -\frac{g}{L} & 0 \end{pmatrix}$，特征值 $\lambda = \pm i\sqrt{g/L}$（纯虚）→ **中心**。但这是非线性系统，Hartman-Grobman 不适用；实际摆有阻尼时中心变为稳定焦点，无阻尼时是"弱中心"（轨道闭合但易碎）。
4. 在 $(\pi, 0)$：$J = \begin{pmatrix} 0 & 1 \\ \frac{g}{L} & 0 \end{pmatrix}$，特征值 $\lambda = \pm\sqrt{g/L}$（一正一负实根）→ **鞍点**，双曲，结论可靠：倒立摆不稳定。

## 5. 反例：为什么中心不能信

**反例**：$x' = y + \epsilon x^3, \quad y' = -x$。线性化 $J = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$，特征值 $\pm i$，判为**中心**。但真实系统：
- $\epsilon < 0$：$r' = \epsilon r^3\cos^4\theta + \cdots < 0$（平均），轨线向内螺旋 → **稳定焦点**；
- $\epsilon > 0$：轨线向外螺旋 → **不稳定焦点**；
- 只有 $\epsilon = 0$ 才是真中心。

教训：**纯虚特征值处，线性化与非线性行为可以完全不同**。这正是 Hartman-Grobman 要求"双曲"（无零实部）的原因。

## 6. 条件变式

| 变式 | 改变什么 | 结果是否改变 | 结论 |
| :--- | :--- | :---: | :--- |
| 双曲结点（两负实根） | 无 | 稳定结点不变 | 可靠 |
| 双曲鞍点（一正一负） | 无 | 鞍点不变 | 可靠 |
| 中心（纯虚根） | 加高阶非线性项 | 中心→焦点 | **不可信** |
| 特征值实部为零但非纯虚（临界情形） | 无 | 需中心流形/更高阶分析 | 不可信 |
| 高维（$n \ge 3$） | 维度 | 双曲情形仍拓扑等价 | 可靠（定理通用） |

## 7. 常见误区

1. **把"线性化判为稳定"当成"全局稳定"**：Hartman-Grobman 只保证平衡点**小邻域内**拓扑等价，远离平衡点的大范围行为完全可能不同（如存在极限环时）。
2. **在非平衡点处求雅可比**：线性化必须取在 $\mathbf{f}(\mathbf{x}_0) = \mathbf{0}$ 的平衡点上；其他点没有"平衡点分类"可言。
3. **忽视特征值实部为零的情形**：考试与工程中最常见的错误是把中心、鞍-结等临界情形直接套线性结论。
