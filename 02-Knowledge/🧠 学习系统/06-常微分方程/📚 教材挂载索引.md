## 单源充分性判断（Spine 覆盖核验）

> 按 AGENTS §5.2.8：本课程采用**单 Spine 结构**（MIT 18.03 为官方主线 + Diffy Qs 为主教材 + Python 为实验工具，非平行 Co-Spine），不强行进行多源融合评分。以下为单源充分性核验：

| 核验项 | 结论 | 说明 |
| :--- | :---: | :--- |
| MIT 18.03 是否覆盖课程核心目标（一阶/高阶/线性系统/频域/非线性/PDE 桥梁） | ✅ 覆盖 | 18.03 含全部 6 大知识块；07 阶段前沿专题（Neural ODE/SDE）由本地扩展 |
| Diffy Qs 是否补充主教材缺口 | ✅ 补充 | 提供可开放获取的完整教材正文、例题与习题编号（§1.1–§7） |
| 是否引入无必要 Co-Spine | ✅ 否 | 未引入平行课程；Python 仅作实验/验证工具，不承担教学主线 |
| 术语与符号是否统一 | ✅ 统一 | 以 18.03 术语为基准，Diffy Qs 章节号标注于卡片 sources |
| 作业是否对齐已教授知识 | ✅ 对齐 | 作业 `requires` 全部指向课程内知识卡（2026-08-08 校验通过） |

**结论**：单 Spine 结构足以覆盖课程目标，无需引入 Co-Spine；Python 工具的角色、边界（复现/对照，不替代理论）已在正文说明。

### 阶段 / 层级

| 阶段/层级 | 阶段目标 | 实践任务 | 验收要求 |
|:---:|:---|:---|:---|
| 阶段 1 | 一阶方程解析与初级数值 | 完成一阶ODE求解与Euler/RK2代码实现 | 校验求根与局部截断误差 |

### Capstone

**项目任务**：构建包含非刚性与刚性 ODE 的通用科学计算工具包，比较 Euler、RK4、隐式梯形法的收敛阶与稳定性；在 Neural ODE 或 Lorenz 混沌吸引子上完成建模验证。

最低交付：问题定义、可复现输入、朴素基线、核心方法、统一评估、失败案例、限制说明和复现步骤。证明型课程将“代码基线”替换为“定义—定理—证明—反例”链条。
