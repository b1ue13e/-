# 二维线性系统平衡点分类

---

## 1. 这是什么？

对于线性系统 $\mathbf{x}' = A\mathbf{x}$，原点永远是一个平衡点（因为 $A\mathbf{0} = \mathbf{0}$）。
利用上一节提到的**特征值**和**特征向量**，我们可以完美预测在这个平衡点附近，轨线到底长什么样。

## 2. 完整分类定理（特征值法）

根据矩阵 $A$ 的两个特征值 $\lambda_1, \lambda_2$ 的情况，奇点分为以下几类（主教材 Diffy Qs §3.5）：

| 特征值 | 奇点名称 | 稳定性 | 轨线形状直觉 |
| :--- | :--- | :--- | :--- |
| 实根，同为负 | 稳定结点 (sink) | 渐近稳定 | 所有轨线沿特征向量方向被吸入原点 |
| 实根，同为正 | 不稳定结点 (source) | 不稳定 | 所有轨线沿特征向量方向向外喷射 |
| 实根，一正一负 | 鞍点 (saddle) | 不稳定 | 两条特殊轨线（稳定/不稳定流形）直进直出，其余成双曲形绕开 |
| 共轭复根，实部为负 | 稳定焦点 (spiral sink) | 渐近稳定 | 像漩涡一样旋转着被吸入原点 |
| 共轭复根，实部为正 | 不稳定焦点 (spiral source) | 不稳定 | 像漩涡一样旋转着向外甩出 |
| 共轭复根，实部为零 | 中心 (center) | 稳定但非渐近 | 永无止境的椭圆闭轨（纯振荡） |

## 3. 证明主线直觉：解耦与“谁慢谁占优”

对于特征值 $\lambda_1 < \lambda_2 < 0$（稳定结点）：
通解是 $\mathbf{x}(t) = c_1 e^{\lambda_1 t}\mathbf{v}_1 + c_2 e^{\lambda_2 t}\mathbf{v}_2$。
当 $t \to +\infty$ 时，由于 $\lambda_1$ 负得更多，它衰减得**极快**。$\lambda_2$ 衰减得**慢**。
因此，时间越往后，慢项 $e^{\lambda_2 t}$ 越占据主导地位！这就解释了为什么所有轨线在进入原点时，都**相切于慢特征向量**的方向。

## 4. 最小例子（可手算）

**例**：$\mathbf{x}' = \begin{pmatrix}-1&0\\0&-3\end{pmatrix}\mathbf{x}$。

特征值 $\lambda_1 = -1$（慢）、$\lambda_2 = -3$（快），均为负 → **稳定结点**。通解 $\mathbf{x}(t) = c_1 e^{-t}\begin{pmatrix}1\\0\end{pmatrix} + c_2 e^{-3t}\begin{pmatrix}0\\1\end{pmatrix}$。当 $t\to\infty$，慢项 $e^{-t}$ 主导，轨线从远处沿 $\mathbf{v}_1 = (1,0)^\top$ 方向进入原点（慢特征向量方向）。

## 5. 反例：退化与临界情形

**反例 1（实部为零的中心）**：$\mathbf{x}' = \begin{pmatrix}0&-1\\1&0\end{pmatrix}$，特征值 $\pm i$ → 中心（稳定但非渐近）。轨线是闭合椭圆，永远不进入原点——"稳定"但不"吸引"。

**反例 2（重根退化）**：$\mathbf{x}' = \begin{pmatrix}-1&1\\0&-1\end{pmatrix}$，特征值 $-1$（重根）但只有一个特征向量 → 退化结点（非对角化），轨线沿单方向进入。此时迹-行列式判别法会判为结点，但轨线几何与标准结点不同，需注意。

**教训**：分类表覆盖的是"一般位置"（双曲 + 可对角化）；中心与退化结点是临界情形，稳定性需另行论证（Lyapunov/中心流形）。

## 6. 条件变式

| 变式 | 特征值 | 类型与稳定性 | 结论 |
| :--- | :--- | :---: | :--- |
| 同为负实根 | $\lambda_1,\lambda_2<0$ | 稳定结点 | 渐近稳定 |
| 同为正实根 | $\lambda_1,\lambda_2>0$ | 不稳定结点 | 不稳定 |
| 异号实根 | $\lambda_1\lambda_2<0$ | 鞍点 | 不稳定 |
| 共轭复根实部<0 | $\mathrm{Re}<0$ | 稳定焦点 | 渐近稳定 |
| 共轭复根实部>0 | $\mathrm{Re}>0$ | 不稳定焦点 | 不稳定 |
| 纯虚根 | $\mathrm{Re}=0$ | 中心 | 稳定非渐近（临界） |

## 7. 常见误区

1. **把中心当"稳定"就放心**：中心只在小扰动下保持闭合轨道，任何非线性扰动都可能把它变成焦点——它是临界情形，不是鲁棒稳定。
2. **忽略轨线方向**：稳定结点是"进入"，不稳定是"喷出"，鞍点是"一进一出"，方向判断靠特征值符号而非直觉。
3. **非对角化重根**：重根不一定对应标准结点，轨线几何可能退化，需用 Jordan 形。
