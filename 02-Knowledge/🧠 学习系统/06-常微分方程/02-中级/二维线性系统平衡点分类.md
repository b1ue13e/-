# 二维线性系统平衡点分类

---

## 1. 这是什么？

对于线性系统 $\mathbf{x}' = A\mathbf{x}$，原点永远是一个平衡点（因为 $A\mathbf{0} = \mathbf{0}$）。
利用上一节提到的**特征值**和**特征向量**，我们可以完美预测在这个平衡点附近，轨线到底长什么样。

## 2. 完整分类定理（特征值法）

根据矩阵 $A$ 的两个特征值 $\lambda_1, \lambda_2$ 的情况，奇点分为以下几类（主教材 Diffy Qs §3.5）：

| 特征值 | 奇点名称 | 稳定性 | 轨线形状直觉 |
| :--- | :--- | :--- | :--- |
| 实根，同为负 | 稳定结点 (sink) | 渐近稳定 | 所有轨线沿特征向量方向被吸入原点 |
| 实根，同为正 | 不稳定结点 (source) | 不稳定 | 所有轨线沿特征向量方向向外喷射 |
| 实根，一正一负 | 鞍点 (saddle) | 不稳定 | 两条特殊轨线（稳定/不稳定流形）直进直出，其余成双曲形绕开 |
| 共轭复根，实部为负 | 稳定焦点 (spiral sink) | 渐近稳定 | 像漩涡一样旋转着被吸入原点 |
| 共轭复根，实部为正 | 不稳定焦点 (spiral source) | 不稳定 | 像漩涡一样旋转着向外甩出 |
| 共轭复根，实部为零 | 中心 (center) | 稳定但非渐近 | 永无止境的椭圆闭轨（纯振荡） |

## 3. 证明主线直觉：解耦与“谁慢谁占优”

对于特征值 $\lambda_1 < \lambda_2 < 0$（稳定结点）：
通解是 $\mathbf{x}(t) = c_1 e^{\lambda_1 t}\mathbf{v}_1 + c_2 e^{\lambda_2 t}\mathbf{v}_2$。
当 $t \to +\infty$ 时，由于 $\lambda_1$ 负得更多，它衰减得**极快**。$\lambda_2$ 衰减得**慢**。
因此，时间越往后，慢项 $e^{\lambda_2 t}$ 越占据主导地位！这就解释了为什么所有轨线在进入原点时，都**相切于慢特征向量**的方向。
