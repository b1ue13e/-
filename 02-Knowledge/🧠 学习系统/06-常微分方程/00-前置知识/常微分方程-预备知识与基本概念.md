## 0. 为什么常微分方程是现代科学的语言？

现实世界中，我们几乎无法直接测量一个动态系统的全部状态显式公式 $y(t)$，但物理定律却极易给出**状态的变化率关系**：
- **牛顿第二定律**：力决定加速度（二阶导数），$m \frac{d^2 x}{dt^2} = F(t, x, \dot{x})$。
- **人口繁殖与放射性衰变**：变化速度正比于当前存量，$\frac{dN}{dt} = k N$。
- **电路与信号演化**：电容电流正比于电压变化率 $i = C \frac{du}{dt}$，电感电压正比于电流变化率 $u = L \frac{di}{dt}$。

常微分方程（ODE）就是从**局部变化规则（导数）**反推**系统全局演化轨迹（解）**的数学工具。

## 2. 核心分类维度（极速自测）

在正式进入阶段 1 之前，请确保能在一秒钟内识别以下概念：

### 2.1 阶数 (Order)
方程中出现的**最高阶导数**的阶数。
- $y' + 3y = e^t$：一阶（描述速度、衰减、单回路 RC 电路）。
- $y'' + 4y' + 13y = 0$：二阶（描述力学振荡、RLC 振荡电路）。

### 2.2 线性 (Linear) vs 非线性 (Non-linear)
- **线性 ODE**：未知函数 $y$ 及其所有导数 $y', y'' \dots$ 均以一次方出现，且无交叉相乘，不嵌套在非线性函数内。
  - 标准形式：$a_n(t)y^{(n)} + \dots + a_1(t)y' + a_0(t)y = g(t)$。
  - 核心性质：**满足叠加原理**，齐次解集构成向量空间。
- **非线性 ODE**：如 $y' = y^2$、$\theta'' + \frac{g}{L}\sin\theta = 0$（单摆大角度振荡）。通常无法获得初等解析解，依赖相平面定性分析与数值算法。

### 2.3 初值问题 (IVP) vs 边值问题 (BVP)
- **初值问题 (IVP)**：所有约束条件集中在**同一个时间起点** $t_0$（如 $y(0)=1, y'(0)=0$）。
- **边值问题 (BVP)**：约束条件分布在**空间区间的不同端点**（如弦振动两端固定 $y(0)=0, y(L)=0$），引出特征值与 Sturm-Liouville 谱理论。
