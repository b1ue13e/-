# 一阶线性方程

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心定理，必须深挖）**
- **判断理由**：一阶线性方程是**唯一一类保证"通解公式 + 整体存在唯一"同时成立**的一阶方程。它背后藏着两套互相印证的核心思想——积分因子法（§1.4 主线）与常数变易法——而这两套思想分别又指向 §1.8 恰当方程（积分因子 = 把不恰当变恰当）和高阶线性方程（常数变易的推广）。不掌握通解公式的完整证明，后续所有"线性"理论（二阶、方程组、Laplace 变换）都缺地基。
- **验收模式说明**：本卡不设置指标/冲榜类任务；验收只看「定义复述、证明重建、反例、条件变式、闭卷验收」五项是否通过。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 面对 $y' + p(x)y = f(x)$，分离变量法帮不上忙——右边 $f(x) - p(x)y$ 是"差"不是"积"，没法拆成 $g(x)h(y)$。直接积分也不行。
> 但这类方程又无处不在：RC 电路、盐水混合、落体阻力、利息增长……它比一般的一阶方程**多一个"线性"结构**，而这个结构足以换来一个**万能的通解公式**。

一阶线性方程回答的问题：**对一切连续系数 $p(x)$、$f(x)$，怎样给 $y' + p(x)y = f(x)$ 写出一劳永逸的通解，并且证明解在系数连续的整个区间上存在且唯一？**

关键工具是**积分因子（integrating factor）**：乘一个 $\mu(x)$ 上去，让左端变成一个函数 $\mu(x)y$ 的导数——"乘法法则的逆用"。这个"乘个因子把方程变成全导数"的想法，正是下一张卡（恰当方程与积分因子）里"把不恰当方程变成恰当方程"的特例。

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：一阶线性方程是可分离方程（§1.3）之后最重要的可解类。
  - 它的积分因子 $\mu = e^{\int p\,dx}$ 与 §1.8 恰当方程的积分因子理论**是同一个机制**（详见本卡 §9 与 [[02-Knowledge/🧠 学习系统/06-常微分方程/恰当方程与积分因子|恰当方程与积分因子]]）；
  - 常数变易法是**一切线性理论**的种子：二阶线性方程、线性方程组的变易法公式都是它的推广；
  - 它首次给出"**整体**存在唯一"（系数连续 ⇒ 解在系数定义区间上处处存在），为后面的 Picard 理论提供可对比的"线性好消息"。
- **实际应用场景**：RC/RL 电路充放电、盐水池混合（Diffy Qs §1.4 例题即 brine tank）、空气阻力下的自由落体 $v' + \frac{k}{m}v = g$、连续复利、药物代谢。
- **高频考点**：识别线性 + 齐次/非齐次；积分因子计算；**初始值下的定积分版公式**（Diffy Qs 公式 (1.4)）；常数变易法与积分因子法互验；线性 vs 非线性的存在性对比。

## 4. 定义复述

### 1. 精确定义

**一阶线性方程**：能写成
$$
y' + p(x)\,y = f(x)
$$
的方程（$p, f$ 为给定函数）。其中对 $y$ 及其导数的依赖是**线性的**（$y'$ 与 $y$ 的系数 1 与 $p(x)$ 都不依赖 $y$）。量词：$\exists\, p, f$（单变量函数）使上式在定义域内成立。

- 若 $f \equiv 0$：称为**齐次**（homogeneous）方程 $y' + p(x)y = 0$。
- 若 $f \not\equiv 0$：称为**非齐次**（nonhomogeneous）方程。
- 等价写法：$y' = a(x)\,y + b(x)$（取 $a = -p$，$b = f$）。

**积分因子**：一个非零函数 $\mu(x)$，使得 $\mu(x)\big(y' + p(x)y\big)$ 恰好是某个函数对 $x$ 的全导数。对一阶线性方程取 $\mu(x) = e^{\int p(x)\,dx}$ 即满足 $\mu' = \mu p$，从而 $\mu(y' + py) = (\mu y)'$。

**注意边界情形**：$p$、$f$ 的连续区间决定了 $\mu$ 的良定义区间；$p$ 有奇点（如 $1/x$）时公式只在光滑区间内使用（见 §7 反例 1）。

### 2. 等价形式

| 形式 | 表述 | 适用场景 |
| :--- | :--- | :--- |
| 原始定义 | $y' + p(x)y = f(x)$ | 判别线性、套公式 |
| 商形式 | $y' = a(x)y + b(x)$ | 与可分离、Bernoulli 对比 |
| 全导数形式 | $(\mu y)' = \mu(x) f(x)$，$\mu = e^{\int p\,dx}$ | 直接积分得到通解；几何直觉最清晰 |
| 微分形式 | $(p y - f)\,dx + dy = 0$（即 $M = py - f$，$N = 1$） | 与恰当方程 $M dx + N dy = 0$ 统一（§1.8） |

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $p(x)$ | $y'$ 的系数（除以首项系数后） | 在开区间 $I$ 上连续 | 决定 $\mu = e^{\int p\,dx}$ |
| $f(x)$ | 非齐次项（强迫项/源项） | 在 $I$ 上连续 | $f \equiv 0$ 为齐次 |
| $P(x)$ | $p$ 的一个原函数，$P' = p$ | 常数 $+$ 任意 | 改变 $P$ 只改变积分因子一个常数倍 |
| $\mu(x)$ | 积分因子 $e^{P(x)}$ | 恒正（$> 0$） | 满足 $\mu' = \mu p$ |
| $C$ | 任意积分常数 | $\mathbb{R}$ | 由初值确定 |

## 5. 直觉与图像

- **直觉类比/几何图像**：把 $y' + p y = f$ 想成一个"被污染的方程"——左边 $y' + p y$ 不是一个函数的导数，我们没法直接积分。积分因子 $\mu(x)$ 像**乘上一个校准系数**，把左端"补成全导数"：$(\mu y)' = \mu y' + \mu' y = \mu y' + \mu p y = \mu(y' + p y)$。于是方程变成"某函数的导数 = 已知函数"：$(\mu y)' = \mu f$，两边积分就完事。
- **为什么很自然**：$\mu' = \mu p$ 恰好是"增长率正比于自身"的方程，解就是指数 $e^{\int p}$——**乘指数因子来吸收 $p y$ 项**，让乘积法则把 $y'$ 和 $y$ 项合并成一个项。几何上，齐次方程 $y' + py = 0$ 的所有解 $y = Ce^{-P}$ 是"基线"，非齐次解是基线被 $f$ 推动后的叠加。
- **一句话直觉本质**：**乘 $\mu = e^{\int p}$，把 $y' + py$ 反向包装成 $(\mu y)'$**——用乘法法则的逆运算把不能积分的左端变成一个能积分的导数。

> ⚠️ 直觉只是导航，不是证明。$(\mu y)' = \mu(y' + py)$ 要求 $\mu' = \mu p$，而 $\mu = e^{\int p}$ 是满足它的最小自然构造；"为什么乘 $\mu$ 而非别的"必须回到 §6 的证明。

## 6. 定理陈述与证明重建

### 1. 定理陈述

**定理 2.1（一阶线性方程通解公式）**

**前提**：$p, f$ 在区间 $I$ 上连续，$P$ 是 $p$ 在 $I$ 上的一个原函数。

**结论**：$y' + p(x)\,y = f(x)$ 的全部解为
$$
y(x) = e^{-P(x)}\left(\int e^{P(x)} f(x)\,dx + C\right), \qquad C \in \mathbb{R}.
$$
（等价地，用定积分版：$y(x) = e^{-\int_{x_0}^x p(s)ds}\,y_0 + \displaystyle\int_{x_0}^{x} e^{-\int_t^x p(s)\,ds} f(t)\,dt$。）

**出处**：Notes on Diffy Qs §1.4 *Linear equations and the integrating factor*（书中方程 (1.3)，公式 (1.4)）；MIT 18.03SC Fall 2011，Unit I，Session 5（First Order Linear ODEs，对应 PS1）。

**定理 2.2（一阶线性方程整体存在唯一）**

**前提**：$p, f$ 在开区间 $I$ 上连续，$x_0 \in I$。

**结论**：初值问题 $y' + p y = f$，$y(x_0) = y_0$ 在**整个 $I$** 上存在唯一解。

**出处**：同定理 2.1（书中 §1.4 存在唯一性讨论）；与 MIT 18.03SC Session 12 的 Linear vs Nonlinear 对比。

### 2. 证明主线（骨架）

**定理 2.1 的证明（两条路线，都要能重建）**

**路线 A：积分因子法。**
- **第 1 步**：令 $\mu(x) = e^{P(x)}$（$P' = p$）。由链式法则 $\mu' = \mu p$。
- **第 2 步**：方程两边乘 $\mu$：
  $$
  \mu y' + \mu p y = \mu f.
  $$
  左端用乘积法则反向识别：$\mu y' + \mu' y = (\mu y)'$，而 $\mu' = \mu p$，故 $\mu y' + \mu p y = (\mu y)'$。所以
  $$
  (\mu y)' = \mu f.
  $$
- **第 3 步**：两边对 $x$ 积分：$\mu y = \int \mu f\,dx + C$，除以 $\mu > 0$：
  $$
  y = \frac{1}{\mu}\left(\int \mu f\,dx + C\right) = e^{-P}\left(\int e^{P}f\,dx + C\right). \qquad \blacksquare
  $$

**路线 B：常数变易法。**
- **第 1 步**：先解齐次方程 $y' + p y = 0$。分离变量：$\frac{dy}{y} = -p\,dx$ ⇒ $y_h = C e^{-P(x)}$。
- **第 2 步**（常数变易——"转念"）：把常数 $C$ 换成函数 $C(x)$：设 $y = C(x)\,e^{-P(x)}$，代入原方程。计算
  $$
  y' = C' e^{-P} + C(-p)e^{-P} = C' e^{-P} - p\,y,
  $$
  于是 $y' + p y = C' e^{-P}$。方程要求 $y' + p y = f$，故
  $$
  C'(x) e^{-P(x)} = f(x) \;\Longrightarrow\; C'(x) = f(x)\,e^{P(x)}.
  $$
- **第 3 步**：积分得 $C(x) = \int f e^P\,dx + C_0$，代回 $y = C e^{-P}$ 得同一公式。$\blacksquare$

**关键"转念"（两条路线是同一个想法）**：路线 A 靠"找对 $\mu$ 使 $(\mu y)'$ 出现"，路线 B 靠"让 $C$ 变起来吸收非齐次项 $f$"。二者殊途同归，因为 $e^{-P}$ 恰好是齐次方程的解、$e^{P}$ 恰好是积分因子——它们互为倒数，这不是巧合：**齐次解的结构决定了积分因子的形状**。

**定理 2.2 的证明（整体存在唯一）**
- **存在性**：由定理 2.1 的定积分版直接定义
  $$
  y(x) = e^{-\int_{x_0}^x p\,ds} y_0 + \int_{x_0}^x e^{-\int_t^x p\,ds} f(t)\,dt.
  $$
  右边每一项在 $I$ 上连续可微（$p, f$ 连续，$\mu$ 恒正光滑），用微积分基本定理逐项求导即可验证 $y' + p y = f$ 且 $y(x_0) = y_0$。
- **唯一性**：设 $y_1, y_2$ 是任意两个解，$w = y_1 - y_2$。则 $w' + p w = 0$，$w(x_0) = 0$。乘以 $\mu$：$(\mu w)' = 0$，故 $\mu w \equiv$ 常数；在 $x_0$ 处 $\mu(x_0) w(x_0) = \mu(x_0)\cdot 0 = 0$，故 $\mu w \equiv 0$，因 $\mu > 0$ 得 $w \equiv 0$。$\blacksquare$
- **与非线性对比的"转念"**：非线性方程（如 $y' = y^2$）的解可以有限时间爆破，唯一性也只是局部的；而线性方程只要系数连续，公式就把解**钉在整个区间上**。唯一性的证明只需一句"$(\mu w)' = 0$ 且 $w(x_0) = 0$"，干净得惊人。

### 4. 证明技巧迁移

- **"补全导数"技巧（积分因子/降阶）**：找到一个乘子让表达式变成 $(某量)'$，这个技巧出现在高阶线性方程的降阶法、Wronskian、$\frac{d}{dx}(\mu y)$ 的一切场合。
- **常数变易法**：解齐次方程 → 把常数"变易"为函数 → 代入原方程解出 $C'(x)$。这是求解非齐次问题的**通用范式**，推广到二阶线性方程（2 个变易常数）、线性方程组（变易向量）。
- **线性算子 + 叠加**：非齐次通解 = 特解 + 齐次通解，这一结构来自"求导与乘 $\mu$ 是线性映射"，在高阶、方程组里反复使用。

## 7. 经典反例库

> 数学的边界由反例划定。每个反例回答一个问题：「这个条件能省吗？」

### 反例 1：系数 $p$ 的奇点破坏整体存在（"$p$ 在 $I$ 连续"不能省）

- **问题**：$p$ 不连续（在区间内有奇点），定理 2.2 的"解在整个 $I$ 上存在"还成立吗？
- **反例构造**：$y' + \dfrac{1}{x}\,y = 0$ 在包含 $0$ 的区间 $(-1, 1)$ 上。
  - $p(x) = \frac{1}{x}$ 在 $x = 0$ 处不连续。
  - 通解 $y = \frac{C}{x}$ 只在 $x > 0$ 或 $x < 0$ 上有定义；$\lim_{x\to 0} \frac{C}{x}$ 不存在（无界、无极限），解**无法连续延拓到 $0$**。任何形如 $C/x$ 的函数都过不去 $0$。
- **结论崩塌点**：公式 $y = Ce^{-\int p\,dx}$ 中 $\int \frac{dx}{x} = \ln|x|$ 在 $0$ 处奇异，$\mu = e^{\int p dx}$ 在 $0$ 处发散（$\to 0$ 或 $\to \infty$），整个构造在奇点失效。**教训**："系数在区间上连续"不是修饰性前提，它直接决定解的定义域；方程的解"活在" $p$ 的光滑区间里。

### 反例 2：非线性"伪线性"方程套公式必错（"线性"二字是本质前提）

- **问题**：把非线性的 $y' = y^2$ 当成"$y' + p y = f$"（取 $p = 0$，$f = y^2$？）套公式，会怎样？
- **反例构造**：$y' = y^2$ 无法写成 $y' + p(x)y = f(x)$（因为 $y^2$ 依赖 $y$，而 $p, f$ 不许依赖 $y$）。强行套线性公式必然错：$y' = y^2$ 的真实解是 $y = -\frac{1}{x+C}$（**有限时间爆破**），而线性方程的通解公式绝无爆破——结构完全不同。
- **结论崩塌点**：线性公式的推导第 2 步要求 $\mu f$ 只含 $x$；若 $f = y^2$ 依赖 $y$，$\int \mu f\,dx$ 无法只对 $x$ 积分。**教训**：判别"线性"要核对系数 $p(x), f(x)$ **不含 $y$**；$y^2$、$e^y$、$\sin y$ 出现一个就不是一阶线性方程。
- **延伸**：$\sqrt{y'}$、$\dfrac{1}{y'}$ 这类也不线性。MIT 18.03SC Session 12（Linear vs Nonlinear）专门对比此点。

### 反例 3：$f$ 分段连续——解连续但导数间断（"解"的含义需要小心）

- **问题**：$f$ 只是分段连续（有跳跃），公式还适用吗？
- **反例构造**：$y' = H(x)$（$H$ 为 Heaviside：$x<0$ 取 0，$x\ge 0$ 取 1），$y(0) = 0$。
  - 分段积分得 $y = xH(x)$（即 $x<0$ 时 $y=0$，$x\ge 0$ 时 $y = x$）。
  - $y$ 连续，但 $y'$ 在 $x=0$ 处从 0 跳到 1，不存在。
- **结论崩塌点**：公式 $\int \mu f$ 在 $f$ 的跳跃点仍可定义（Riemann 积分），但"$y'$ 处处存在"不再成立——解是连续的、几乎处处可导的，导数在跳跃点缺席。**教训**：$p, f$ 连续是"处处可导解"的充分条件，可弱化为分段连续，但要接受"解"含义的软化。

## 8. 条件变式

> 把条件改一改，结论还成立吗？这是数学学习最有效的自检方式。

| 变式 | 条件改动 | 结论变化 | 成立/不成立 | 依据（证明或反例） |
| :--- | :--- | :--- | :---: | :--- |
| 弱化 1 | $p, f$ 仅分段连续 | 解分段存在、可拼接，在跳跃点处仅 $C^0$ | 成立（弱意义） | 反例 3：$y' = H(x)$ |
| 弱化 2 | $p$ 在区间内有奇点（如 $1/x$） | 解无法延拓跨过奇点，整体存在失败 | 不成立 | 反例 1：$y' + \frac{y}{x} = 0$ |
| 加强 1 | $p, f$ 光滑（$C^\infty$） | 解同样光滑；正则性随系数提升 | 成立 | 公式中 $\mu, \int\mu f$ 继承正则性 |
| 换条件 1 | $f \equiv 0$（齐次） | 通解 $y = Ce^{-P}$，解集是 1 维线性空间；叠加原理可用 | 成立 | 直接代入验证 |
| 换条件 2 | Bernoulli 方程 $y' + p y = b\,y^n$（$n \neq 0, 1$） | 非线性，线性公式失效 | 成立（代换后） | 代换 $v = y^{1-n}$ 化为线性（§1.5） |
| 换条件 3 | $p, f$ 为复值函数 | 公式形式不变，$e^P$ 为复指数 | 成立 | 复指数运算验证 |
| 换空间 | 向量形式 $\mathbf y' + P(x)\mathbf y = \mathbf f$（$P$ 为矩阵） | 一维公式推广为基解矩阵/矩阵指数 | 成立（中级卡） | 线性方程组理论 |

### 例题（先看解答，掌握流程）

#### 例 1（基础，完整解答）：解 $y' + 2xy = 2x$，$y(0) = 0$。

> [!question]- 答案与解析
> - **第 1 步 识别**：$p = 2x$，$f = 2x$，线性非齐次。
> - **第 2 步 积分因子**：$P = \int 2x\,dx = x^2$，$\mu = e^{x^2}$。
> - **第 3 步 乘 $\mu$**：$(\mu y)' = \mu f$，即 $(e^{x^2} y)' = 2x\,e^{x^2}$（右端恰是 $e^{x^2}$ 的导数）。
> - **第 4 步 积分**：$e^{x^2} y = e^{x^2} + C$ ⇒ $y = 1 + C\,e^{-x^2}$。
> - **第 5 步 初值**：$0 = 1 + C$ ⇒ $C = -1$ ⇒ $\boxed{y = 1 - e^{-x^2}}$。
> - **验证**：$y' = 2x\,e^{-x^2}$；$y' + 2xy = 2x e^{-x^2} + 2x(1 - e^{-x^2}) = 2x$ ✓。

#### 例 2（中等，完整解答）：解 $y' + \dfrac{1}{x}\,y = x^2$，$x > 0$，$y(1) = 1$。

> [!question]- 答案与解析
> - **第 1 步**：$p = \dfrac{1}{x}$，$f = x^2$。
> - **第 2 步**：$\mu = e^{\int \frac{dx}{x}} = e^{\ln x} = x$（注意：在 $x > 0$ 上 $\int \frac{dx}{x} = \ln x$，$\mu = x$——不是指数而是多项式！）。
> - **第 3 步**：$(xy)' = x \cdot x^2 = x^3$。
> - **第 4 步**：$xy = \dfrac{x^4}{4} + C$ ⇒ $y = \dfrac{x^3}{4} + \dfrac{C}{x}$。
> - **第 5 步 初值**：$1 = \dfrac{1}{4} + C$ ⇒ $C = \dfrac{3}{4}$ ⇒ $\boxed{y = \dfrac{x^4 + 3}{4x}}$。
> - **验证**：$y' = \dfrac{3x^2}{4} - \dfrac{3}{4x^2}$；$y' + \dfrac{y}{x} = \dfrac{3x^2}{4} - \dfrac{3}{4x^2} + \dfrac{x^2}{4} + \dfrac{3}{4x^2} = x^2$ ✓。
> - **注意**：区间含 $x = 0$ 时 $p$ 不连续，公式失效——见 §7 反例 1。

### 题目与解析

#### 1. 判断下列方程是否一阶线性，若是说明齐次/非齐次：$y' = xy + 3$；$y' = y^2 + x$；$y' + e^x y = \sin x$；$y' = xy^2$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案**：$y' = xy + 3$ 线性非齐次（$p = -x$，$f = 3$）；$y' + e^x y = \sin x$ 线性非齐次（$p = e^x$，$f = \sin x$）；$y' = y^2 + x$ 与 $y' = xy^2$ 非线性（含 $y^2$）。
> - **解析**：判据是 $y$ 与 $y'$ 的次数是否都一次且系数不含 $y$。
> - **易错原因**：把 $xy$ 误判为非线性（系数含 $x$ 没关系，$p(x)$ 可以是 $x$ 的函数）。
> - **对应反例/变式**：§7 反例 2。

#### 2. 解 $y' + 3y = 0$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：齐次。$\mu = e^{3x}$，$(e^{3x}y)' = 0$ ⇒ $y = Ce^{-3x}$。或分离变量直接得。
> - **解析**：齐次方程是最快入口，验算 $(Ce^{-3x})' + 3Ce^{-3x} = 0$ ✓。
> - **易错原因**：指数符号写反。
> - **对应反例/变式**：§8 换条件 1。

#### 3. 解 $y' + (\tan x)y = \cos x$（$-\frac{\pi}{2} < x < \frac{\pi}{2}$）。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$p = \tan x$，$f = \cos x$。$\mu = e^{\int \tan x\,dx} = e^{-\ln|\cos x|} = \dfrac{1}{\cos x}$（在 $-\frac{\pi}{2} < x < \frac{\pi}{2}$ 上 $\cos x > 0$）。乘 $\mu$ 后 $(\mu y)' = \mu f$，而 $\mu f = \dfrac{1}{\cos x}\cdot\cos x = 1$。故 $(y\sec x)' = 1$，积分得 $y\sec x = x + C$，即 $y = (x + C)\cos x$。
> - **解析**：验证：$y' = \cos x - (x+C)\sin x$；$y' + \tan x\cdot y = \cos x - (x+C)\sin x + \sin x(x+C) = \cos x$ ✓。
> - **易错原因**：$\int \tan x\,dx = -\ln|\cos x|$ 的符号；把 $\mu f$ 和 $\mu y$ 混淆。
> - **对应反例/变式**：非指数积分因子（本例 $\mu = \sec x$）。

#### 4. 解初值问题 $y' + y = e^{-x}$，$y(0) = 0$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$p = 1$，$\mu = e^x$。$(e^x y)' = e^x \cdot e^{-x} = 1$，积分得 $e^x y = x + C$，$y = (x + C)e^{-x}$。初值 $0 = (0 + C)\cdot 1$ ⇒ $C = 0$ ⇒ $y = x e^{-x}$。
> - **解析**：$x e^{-x}$ 在 $x \to \infty$ 时趋于 0（指数衰减压制线性增长），是"共振修正"的雏形。
> - **易错原因**：忘了 $\mu f = 1$ 而不是 $e^{-x}$；初值代入时 $e^{-x}$ 在 0 处为 1。
> - **对应反例/变式**：定理 2.1 定积分版公式可重写此例。

#### 5. （盐水池混合）池中有 100 升含盐 2 kg 的水，以 5 L/min 注入浓度 0.1 kg/L 的盐水，同时以 5 L/min 排出（充分搅拌），求池中盐量 $Q(t)$ 与长期极限。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$Q' = \text{流入} - \text{流出} = 5\times 0.1 - 5 \times \dfrac{Q}{100} = 0.5 - \dfrac{Q}{20}$，即 $Q' + \frac{1}{20}Q = \frac{1}{2}$，$Q(0) = 2$。积分因子 $\mu = e^{t/20}$：$(e^{t/20}Q)' = \frac12 e^{t/20}$ ⇒ $e^{t/20}Q = 10e^{t/20} + C$ ⇒ $Q = 10 + Ce^{-t/20}$。$Q(0) = 2$ ⇒ $C = -8$ ⇒ $Q(t) = 10 - 8e^{-t/20}$。极限 $\lim_{t\to\infty} Q = 10$ kg（与注入浓度 $0.1$ kg/L $\times$ 100 L = 10 kg 一致）。
> - **解析**：这是 §1.4 书中 brine tank 例题的同类题（已核实该节有此类型例题）。平衡解 $Q = 10$ 是齐次解 $Ce^{-t/20} \to 0$ 后的"稳态"。
> - **易错原因**：流出速率中 $Q/100$ 的单位（kg/L）；初始条件 $Q(0) = 2$（不是浓度）。
> - **对应反例/变式**：§8 弱化/加强表；线性结构保证 $t \to \infty$ 收敛。

#### 6. 用常数变易法重解第 4 题，并说明两条路线结果一致。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：齐次解 $y_h = Ce^{-x}$。变易：$y = C(x)e^{-x}$，$y' = C' e^{-x} - y$，代入 $y' + y = C' e^{-x} = e^{-x}$ ⇒ $C' = 1$ ⇒ $C = x + C_0$ ⇒ $y = (x + C_0)e^{-x}$。与第 4 题一致。
> - **解析**：两路线结论相同的根源是 $e^{-P}$（齐次解）与 $e^{P}$（积分因子）互为倒数（§6 关键"转念"）。
> - **易错原因**：$y'$ 中漏掉 $-y$ 项（链式法则）。
> - **对应反例/变式**：定理 2.1 的路线 A/B。
