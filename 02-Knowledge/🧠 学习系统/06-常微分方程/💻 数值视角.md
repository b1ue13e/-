# 常微分方程数值视角 (Numerical Perspective of ODE)

## 1. 数值视角的定义与核心动机

**常微分方程数值视角 (Numerical Perspective of ODE)** 的核心定义是：通过有限步的离散化计算（如差分逼近、积分插值），在计算机上近似求解无法得到闭合解析表达式的复杂 ODE。

**基本性质与动机**：解析视角要求 ODE 具有特殊结构（如线性、可分离变量等），然而绝大多数实际工程与物理问题（如 N 体引力系统、化学反应动力学、神经元电位 Hodgkin-Huxley 模型）均不存在显式闭合解。因此数值视角提供了普遍适用的定量近似求解框架。

---

## 2. RK4 算法形式化推导与局部/全局误差

**四阶 Runge-Kutta 方法 (RK4)** 的局部截断误差 (LTE) 为 $O(h^5)$，全局误差为 $O(h^4)$。

**假设（前提条件）**：$f(t, y)$ 充分光滑（至少 5 阶连续可微），步长 $h$ 足够小。

**推导过程**（对 $t$ 处的 Taylor 展开与加权平均）：
$$k_1 = h \cdot f(t_n,\ y_n)$$
$$k_2 = h \cdot f\!\left(t_n + \frac{h}{2},\ y_n + \frac{k_1}{2}
ight)$$
$$k_3 = h \cdot f\!\left(t_n + \frac{h}{2},\ y_n + \frac{k_2}{2}
ight)$$
$$k_4 = h \cdot f\!\left(t_n + h,\ y_n + k_3
ight)$$
$$y_{n+1} = y_n + \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

**因此**：RK4 用 4 次函数评估换取 $O(h^4)$ 的全局精度，比 Euler 法 ($O(h)$) 精度高出 4 个阶次，构成工程仿真中性价比最高的显式方法。

---

## 3. 数值方法对比（刚性方程与稳定性局限）

| 数值方法 | 局部截断误差 | 全局误差 | 函数评估/步 | 适用场景 |
|:---|:---|:---|:---|:---|
| **Euler** (显式) | $O(h^2)$ | $O(h)$ | 1 | 教学演示 |
| **改进 Euler** (RK2) | $O(h^3)$ | $O(h^2)$ | 2 | 初步近似 |
| **RK4** | $O(h^5)$ | $O(h^4)$ | 4 | **一般非刚性 ODE** |
| **隐式 Euler** | $O(h^2)$ | $O(h)$ | 1 (解方程) | **刚性 (Stiff) ODE** |

**刚性 ODE 的定义与局限（反例）**：若 Jacobian $J = \partial f/\partial y$ 的特征值实部差距极大（如 $\text{Re}(\lambda_1)/\text{Re}(\lambda_2) \gg 10^6$），则显式 RK4 步长受绝对稳定性区域制约而急剧减小，导致计算崩溃，因此必须改用 A-稳定的隐式 Runge-Kutta 或 BDF 方法。

## 4. Python RK4 完整实现、全局误差阶次 $O(h^4)$ 自测断言

```python
import numpy as np
from typing import Callable, Tuple

def rk4_solve(f: Callable, y0: float, t_span: Tuple[float, float],
              h: float) -> Tuple[np.ndarray, np.ndarray]:
    """
    RK4 求解标量 IVP: y'=f(t,y), y(t0)=y0
    假设: f 5 阶可微，h 足够小
    推导: k1~k4 加权平均，LTE = O(h^5)，全局误差 = O(h^4)
    """
    t0, t_end = t_span
    t_vals = [t0]
    y_vals = [y0]
    t, y = t0, y0

    while t < t_end - 1e-12:
        h_cur = min(h, t_end - t)
        k1 = h_cur * f(t,           y)
        k2 = h_cur * f(t + h_cur/2, y + k1/2)
        k3 = h_cur * f(t + h_cur/2, y + k2/2)
        k4 = h_cur * f(t + h_cur,   y + k3)
        y  = y + (k1 + 2*k2 + 2*k3 + k4) / 6
        t  = t + h_cur
        t_vals.append(t)
        y_vals.append(y)

    return np.array(t_vals), np.array(y_vals)

if __name__ == "__main__":
    # 测试 1: y' = -2y, y(0)=1 -> 解析解 y(t) = e^{-2t}
    f = lambda t, y: -2 * y
    t_h1, y_h1 = rk4_solve(f, y0=1.0, t_span=(0, 2), h=0.1)
    y_exact = np.exp(-2 * t_h1)
    err_h1 = np.max(np.abs(y_h1 - y_exact))

    # 自测验证 1: RK4 全局误差阶次 O(h^4)
    assert err_h1 < 1e-4, f"RK4 全局误差过大: {err_h1}"
    assert abs(y_h1[-1] - np.exp(-4)) < 1e-5

    # 自测验证 2: 步长减半误差缩小 2^4 = 16 倍验证
    t_h2, y_h2 = rk4_solve(f, y0=1.0, t_span=(0, 2), h=0.05)
    err_h2 = np.max(np.abs(y_h2 - np.exp(-2 * t_h2)))
    ratio = err_h1 / err_h2
    assert 14.0 <= ratio <= 18.0, f"收敛阶次应趋向 16, 得 ratio={ratio:.2f}"

    # 自测验证 3: 反例验证 (刚性系统 y' = -1000 y 显式步长过大导致发散)
    f_stiff = lambda t, y: -1000 * y
    _, y_stiff = rk4_solve(f_stiff, y0=1.0, t_span=(0, 0.1), h=0.01) # h=0.01 > 2.78/1000
    assert np.max(np.abs(y_stiff)) > 1e5, "显式 RK4 在刚性方程大步长下应发散"

    print(f"RK4 精度验证成功！h=0.1 误差={err_h1:.2e}, h=0.05 误差={err_h2:.2e}")
    print(f"收敛阶比值 ratio = {ratio:.2f}x (符合理论 16x)")
    print("常微分方程数值视角单元测试与自查验证全部完成！")
```
