# 常微分方程应用视角 (Applied Perspective of ODE)

## 1. 应用视角的定义与核心方法

**常微分方程应用视角 (Applied Perspective of ODE)** 的核心定义是：把现实系统（物理、生物、金融、机器学习）的**状态演化规律**翻译成 ODE，再借助解析解或数值解反推系统的可观测行为（频率、衰减率、稳态、爆发阈值、收敛速率等）。

**建模三步法（变量 → 定律 → 方程）**：
1. **选变量 (Variables)**：找出刻画系统状态的最少一组量 $\mathbf{x}(t)$；
2. **写定律 (Laws)**：写下支配这些量变化的原理（Newton 定律、Kirchhoff 定律、质量作用、密度制约、均值回归、连续残差假设等）；
3. **列方程 (Equations)**：把"定律"翻译成"变化率 = 驱动项"，得到初值问题 $\dfrac{d\mathbf{x}}{dt} = \mathbf{f}(t,\mathbf{x}),\ \mathbf{x}(t_0)=\mathbf{x}_0$。

**基本性质**：同一个数学结构（一阶线性、二阶常系数、二维非线性系统）可以跨学科复现——物理的弹簧与电路、生物的种群与疫情、金融的利率、机器学习的连续深度，都由同一族 ODE 支配。这正是"建模模式 (Modeling Pattern)"视角的价值。

## 2. 四大领域建模模式的形式化推导

### 2.1 物理·弹簧-质量-阻尼系统（机械振动）
- **变量**：位移 $x(t)$（相对平衡位置）；
- **定律**：Newton 第二定律 $m\ddot{x}=\sum F$；弹簧恢复力 $-kx$（Hooke 定律）、阻尼力 $-c\dot{x}$、外加驱动力 $F(t)$；
- **方程**：
$$m\ddot{x} + c\dot{x} + kx = F(t)$$

**推导**：无阻尼无外力时 $m\ddot{x}+kx=0$，设 $x=e^{rt}$ 得特征方程 $mr^2+k=0$，$r=\pm i\omega_0$，$\omega_0=\sqrt{k/m}$，故 $x(t)=A\cos(\omega_0 t+\phi)$。欠阻尼 $c^2<4mk$ 时 $x(t)=A e^{-\frac{c}{2m}t}\cos(\omega_d t+\phi)$，其中 $\omega_d=\sqrt{\frac{k}{m}-\frac{c^2}{4m^2}}$——振幅按指数衰减，对应 [[常系数线性方程]] 的特征根方法。

### 2.2 物理·RLC 串联电路（电学类比）
- **变量**：电荷 $q(t)$，电流 $i(t)=\dot{q}$；
- **定律**：Kirchhoff 电压定律（回路电压和为零）+ 元件本构关系：电阻 $v_R=Ri$、电感 $v_L=L\frac{di}{dt}$、电容 $v_C=\frac{q}{C}$；
- **方程**：
$$L\ddot{q} + R\dot{q} + \frac{1}{C}\,q = E(t)$$

**推导**：与 2.1 完全同构：$L\leftrightarrow m$、$R\leftrightarrow c$、$1/C\leftrightarrow k$、$E(t)\leftrightarrow F(t)$；固有频率 $\omega_0=1/\sqrt{LC}$，衰减由 $R/(2L)$ 决定。同一 ODE、两个物理系统，是"建模模式复用"最经典的例证。（说明：该电路方程在 Diffy Qs 中以二阶常系数线性 ODE 的习题形式出现，小节定位未经逐字核实，见参考文献标注。）

### 2.3 生物·Logistic 种群增长（Verhulst）
- **变量**：种群规模 $N(t)$；
- **定律**：人均增长率随密度线性下降（Verhulst 假设）；当 $N\to K$（环境容量）时增长停止；
- **方程**：
$$\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right)$$

**推导**：分离变量方程 $\frac{dN}{N(1-N/K)}=r\,dt$，部分分式积分得
$$N(t) = \frac{K}{1 + \frac{K-N_0}{N_0}\,e^{-rt}}$$
平衡点 $N^*=0$ 处 $f'(0)=r>0$（不稳定）、$N^*=K$ 处 $f'(K)=-r<0$（稳定）——一维情形下的 [[稳定性理论基础]]。

### 2.4 生物·SIR 流行病模型（Kermack-McKendrick）
- **变量**：易感者 $S(t)$、感染者 $I(t)$、康复者 $R(t)$，$N=S+I+R$ 恒定；
- **定律**：均匀混合下的**质量作用定律**——新感染率与 $S\cdot I$ 成正比；感染者以速率 $\gamma$ 康复并获得免疫；
- **方程**：
$$\frac{dS}{dt} = -\frac{\beta SI}{N}, \qquad \frac{dI}{dt} = \frac{\beta SI}{N} - \gamma I, \qquad \frac{dR}{dt} = \gamma I$$

**推导**：基本再生数 $R_0=\beta/\gamma$ 是**爆发阈值**：$dI/dt$ 在 $S=N/R_0$ 处变号，$R_0>1$ 且 $S_0\approx N$ 时 $I$ 先升后降（爆发），$R_0<1$ 时疫情自灭。由 $\frac{dS}{dR}=-\frac{S}{N/R_0}=-\frac{R_0}{N}S$ 积分得 $S=S_0 e^{-R_0 R/N}$，最终易感者 $S_\infty$ 满足超越方程 $S_\infty = S_0 e^{-R_0(1-S_\infty/N)}$。守恒量 $S+I+R=N$ 是数值模拟必须保持的**不变式**（见 §4 断言）。

### 2.5 金融·利率模型的 ODE 骨架（均值回归）
- **变量**：短期利率 $r(t)$；
- **定律**：利率趋向长期均值 $b$ 的**均值回归 (Mean Reversion)**——偏离越大回拽越强；完整 Vasicek 模型在确定性回拽上叠加噪声（SDE）：
$$dr = a(b-r)\,dt + \sigma\,dW_t$$
- **方程（ODE 骨架，$\sigma=0$）**：
$$\frac{dr}{dt} = a(b-r) \quad\Longrightarrow\quad r(t) = b + (r_0-b)\,e^{-at}$$

**推导**：一阶线性方程，解给出随机模型的**条件期望漂移** $\mathbb{E}[r_t]=b+(r_0-b)e^{-at}$——SDE 的"骨架"就是 ODE。回拽速率 $a$ 决定均值回归半衰期 $t_{1/2}=\ln 2/a$。

### 2.6 机器学习·Neural ODE 与连续归一化流
- **变量**：隐藏状态 $h(\tau)$ 随**连续深度** $\tau$ 演化；
- **定律**：残差块 $h_{n+1}=h_n+f_\theta(h_n)$ 取 $\Delta\tau\to 0$ 极限（连续残差网络）；归一化流由连续可逆变换 + Liouville 方程约束密度演化；
- **方程**：
$$\frac{dh}{d\tau} = f_\theta\big(h(\tau), \tau\big), \qquad h(0)=\mathbf{x}$$
$$\frac{d\log p\big(h(\tau)\big)}{d\tau} = -\operatorname{tr}\!\left(\frac{\partial f_\theta}{\partial h}\right)$$

**推导**：前向传播 = 黑盒 ODE 求解器（如 RK45/DOP853）；反向传播用**伴随方法 (Adjoint Method)**：伴随状态 $\lambda(\tau)=\partial L/\partial h(\tau)$ 满足 $\frac{d\lambda}{d\tau}=-\lambda^\top \frac{\partial f_\theta}{\partial h}$，梯度内存开销 $O(1)$、与深度无关。FFJORD 用 Hutchinson 随机迹估计，把对数密度中 $O(d^3)$ 的 Jacobian 行列式计算降为 $O(d)$ 的迹估计。详见 [[神经微分方程]]。

## 3. 四大领域建模模式对比

| 领域 | 典型变量 | 支配定律 | ODE | 方程类型 | 解的定性行为 |
|:---|:---|:---|:---|:---|:---|
| 物理-机械 | 位移 $x$ | Newton 第二定律 | $m\ddot{x}+c\dot{x}+kx=F(t)$ | 二阶常系数线性 | 欠阻尼指数衰减振荡 |
| 物理-电路 | 电荷 $q$ | Kirchhoff 电压定律 | $L\ddot{q}+R\dot{q}+q/C=E(t)$ | 二阶常系数线性 | 与机械系统同构 |
| 生物-种群 | 种群 $N$ | Verhulst 密度制约 | $\dot N = rN(1-N/K)$ | 一阶非线性自洽 | 逻辑斯蒂饱和于 $K$ |
| 生物-流行病 | $S,I,R$ | 质量作用定律 | SIR 方程组 | 二维非线性系统 | $R_0>1$ 爆发后收敛 |
| 金融-利率 | 利率 $r$ | 均值回归假设 | $\dot r = a(b-r)$ | 一阶线性 | 指数回拽到 $b$ |
| 机器学习 | 隐藏态 $h$ | 连续残差 / Liouville | $\dot h = f_\theta(h,\tau)$ | 高维非线性 | 数据驱动的动力学 |

**共性规律**：① 二阶振荡系统由"恢复力 + 阻尼 + 外力"三件套支配（物理双胞胎）；② 一阶自洽方程平衡点稳定性由 $f'(N^*)$ 符号判定；③ 守恒量（$N=S+I+R$）为数值验证提供硬断言；④ 高维非线性系统统一用 [[相平面与轨线分析]] 与 [[稳定性理论基础]] 定性分析。

关联知识点推荐：[[🔢 解析视角]]、[[📐 几何视角]]、[[相平面与轨线分析]]、[[ARIMA模型与差分平稳性]]。

## 4. Python 自测：SIR 流行病模拟（solve_ivp + 守恒量断言）

```python
import numpy as np
from scipy.integrate import solve_ivp

def sir(t, y, beta, gamma):
    """SIR 模型右端: y = (S, I, R)"""
    S, I, R = y
    N = S + I + R
    dS = -beta * S * I / N
    dI =  beta * S * I / N - gamma * I
    dR =  gamma * I
    return [dS, dI, dR]

if __name__ == "__main__":
    N, I0, R0, S0 = 1000.0, 1.0, 0.0, 999.0
    beta, gamma = 0.3, 0.1        # R0 = beta/gamma = 3 > 1 → 疫情爆发
    sol = solve_ivp(sir, (0.0, 120.0), [S0, I0, R0],
                    args=(beta, gamma), method='RK45',
                    rtol=1e-9, atol=1e-11, dense_output=True)

    S, I, R = sol.y
    N_check = S + I + R

    # 自测 1: 守恒量不变式断言——S + I + R ≡ N
    assert np.allclose(N_check, N, rtol=1e-5), "S+I+R 应恒等于 N"
    assert np.all(S >= -1e-6) and np.all(I >= -1e-6) and np.all(R >= -1e-6)

    # 自测 2: R0 = 3 > 1 → 先爆发再消退, 且绝大多数人最终被感染
    assert I[0] < np.max(I), "R0>1 时 I 应先上升"
    assert S[-1] < S0 * 0.1, "R0=3 疫情后易感者应锐减"

    # 自测 3: 峰值处 dI/dt = 0 ⟹ S = N/R0 (与理论吻合)
    i_peak = int(np.argmax(I))
    assert abs(S[i_peak] - N / (beta / gamma)) < 5.0

    print(f"SIR: R0={beta/gamma:.1f}, 峰值 I_max={np.max(I):.1f}, "
          f"最终 S={S[-1]:.1f}, 最终 R={R[-1]:.1f}")
    print(f"守恒量检查: max|S+I+R-N| = {np.max(np.abs(N_check - N)):.2e}")
    print("常微分方程应用视角单元测试与自查验证全部成功！")
```

（在 numpy 2.4 + scipy 1.17 下实测通过：$R_0=3$ 时 $I_{\max}=300.8$、最终 $S=59.6$、$R=939.6$，守恒偏差 $3.4\times10^{-13}$。）
