# 常微分方程数值视角 (Numerical Perspective of ODE)

## 1. 数值视角的定义与核心目标

**常微分方程数值视角 (Numerical Perspective of ODE)** 的核心定义是：把连续的初值问题 (IVP) $y' = f(t,y),\ y(t_0)=y_0$ 通过**离散化 (Discretization)** 转化为有限步代数迭代，在计算机上近似求解，从而绕过"绝大多数 ODE 不存在显式闭合解"的根本障碍。

**离散化思想**：在时间轴 $t_0 < t_1 < \cdots < t_N$ 上引入步长 $h = t_{n+1}-t_n$，用差商逼近导数：
$$y'(t_n) \approx \frac{y_{n+1}-y_n}{h} \quad\Longrightarrow\quad y_{n+1} = y_n + h\,\Phi(t_n, y_n, h)$$
其中 $\Phi$ 称为**增量函数 (Increment Function)**。任何数值方法都可看成对 $\Phi$ 的一种选择：Euler 法取 $\Phi=f(t_n,y_n)$，RK4 取 $f$ 在 4 个采样点的加权平均，多步法则让 $\Phi$ 依赖前 $k$ 步的历史值。

**基本性质**：离散化的代价是把"精确求解"换成"误差可控的逼近"，因此 **收敛性 (Convergence)、稳定性 (Stability)、精度 (Accuracy)** 构成数值视角的三大核心问题，也是 [[数值解法基础]] 与 [[刚性方程与多步法]] 两张主题卡的共同主线。

## 2. 方法谱系：Euler / Runge-Kutta / 线性多步法

### 2.1 Euler 法（一阶显式单步）与推导

对 $y(t_n+h)$ 做一阶 Taylor 展开，并代入 $y'=f(t,y)$：
$$y(t_{n+1}) = y(t_n) + h\,f(t_n, y(t_n)) + \underbrace{\tfrac{h^2}{2}\,y''(\xi)}_{\text{局部截断误差 LTE}=O(h^2)}$$
舍去 $O(h^2)$ 项即得 Euler 迭代 $y_{n+1} = y_n + h f(t_n, y_n)$。每步 LTE 为 $O(h^2)$，走 $N\sim 1/h$ 步累计后**全局误差为 $O(h)$**，故 Euler 是一阶方法。对模型方程 $y'=\lambda y$，放大因子为 $1+h\lambda$，绝对稳定区域 $|1+h\lambda|<1$（$\lambda<0$ 时要求 $h<2/|\lambda|$）。

### 2.2 RK4（四阶 Runge-Kutta）

RK4 用区间内 4 个点斜率的加权平均逼近平均斜率，逐步与 $y(t_n+h)$ 的 4 阶 Taylor 展开匹配（该思想由 C. Runge 与 W. Kutta 于 1900 年前后建立）：
$$k_1 = h\,f(t_n,\ y_n)$$
$$k_2 = h\,f\!\left(t_n + \tfrac{h}{2},\ y_n + \tfrac{k_1}{2}\right)$$
$$k_3 = h\,f\!\left(t_n + \tfrac{h}{2},\ y_n + \tfrac{k_2}{2}\right)$$
$$k_4 = h\,f\!\left(t_n + h,\ y_n + k_3\right)$$
$$y_{n+1} = y_n + \tfrac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

**因此**：RK4 以每步 4 次函数评估换取 LTE $O(h^5)$、全局误差 $O(h^4)$，比 Euler 高 4 个阶次，是工程仿真中性价比最高的显式方法。

### 2.3 线性多步法（Adams-Bashforth / BDF）

多步法不限于当前点，而是复用前 $k$ 步信息：显式 **Adams-Bashforth** 对 $f$ 的历史值做多项式外插积分；隐式 **BDF (Backward Differentiation Formula)** 对 $y$ 的历史值做多项式差分求导，增量函数隐式含有 $y_{n+1}$，每步需解（非）线性方程。隐式方法（隐式 Euler、BDF、Radau IIA）绝对稳定区域无界（A-稳定），是刚性问题的标配，工程实现即 SciPy `solve_ivp` 的 `BDF`/`LSODA` 方法。

## 3. 收敛性、稳定性与精度三要素（对比表）

| 要素 | 数学刻画 | 破坏后果 | 保障手段 |
|:---|:---|:---|:---|
| **精度 (Accuracy)** | 全局误差阶：Euler $O(h)$、RK4 $O(h^4)$ | 解偏离真实轨迹 | 对分步长验证收敛阶（§4 自测 2） |
| **稳定性 (Stability)** | 绝对稳定区域覆盖特征谱：显式有限、隐式无界 | 舍入/截断误差指数放大、数值爆炸 | 步长落入稳定区域，或改用隐式方法 |
| **收敛性 (Convergence)** | 相容性 + 稳定性 $\Rightarrow$ $E(h)\to 0$ | 即使 $h\to0$ 也不逼近真解 | 同时检验相容（LTE$\to$0）与稳定 |

**刚性问题的数值刻画**：若 Jacobian $J=\partial f/\partial y$ 的特征值实部差距极大（比值常达 $\ge 10^3$），显式方法的稳定区域迫使步长 $h$ 由最快分量决定、小到失去意义，而慢分量根本不需要这么小的步长。以 $y'=-1000y$ 为例：Euler 要求 $h<0.002$，RK4 要求 $h<0.00278$，一旦 $h$ 超出即数值爆炸（见 §4 自测 4）。**隐式方法**（隐式 Euler、BDF、Radau、LSODA 自动切换）不受此约束，这是 [[刚性方程与多步法]] 主题卡的核心内容。

| 方法 | 类型 | LTE | 全局误差 | 函数评估/步 | 稳定区域 | 适用场景 |
|:---|:---|:---|:---|:---|:---|:---|
| Euler | 显式单步 | $O(h^2)$ | $O(h)$ | 1 | 有限 | 教学演示 |
| 改进 Euler (RK2) | 显式单步 | $O(h^3)$ | $O(h^2)$ | 2 | 有限 | 初步近似 |
| RK4 | 显式单步 | $O(h^5)$ | $O(h^4)$ | 4 | 有限 | 一般非刚性 ODE |
| Adams-Bashforth 4 | 显式多步 | $O(h^5)$ | $O(h^4)$ | 1/步 | 有限 | 非刚性、$f$ 昂贵 |
| 隐式 Euler / BDF | 隐式多步 | $O(h^2)$/高阶 | $O(h)$~高阶 | 解方程 | **A-稳定（无界）** | 刚性 (Stiff) ODE |

关联知识点推荐：[[数值解法基础]]、[[刚性方程与多步法]]、[[神经微分方程]]、[[ARIMA模型与差分平稳性]]。

## 4. Python 自测：Euler vs RK4 vs solve_ivp 误差对比

```python
import numpy as np
from scipy.integrate import solve_ivp

def euler_solve(f, y0, t_span, h):
    """一阶显式 Euler: y_{n+1} = y_n + h f(t_n, y_n)"""
    t0, t_end = t_span
    ts, ys = [t0], [y0]
    t, y = t0, y0
    while t < t_end - 1e-12:
        h_cur = min(h, t_end - t)
        y = y + h_cur * f(t, y)
        t += h_cur
        ts.append(t); ys.append(y)
    return np.array(ts), np.array(ys)

def rk4_solve(f, y0, t_span, h):
    """四阶 Runge-Kutta: LTE = O(h^5), 全局误差 = O(h^4)"""
    t0, t_end = t_span
    ts, ys = [t0], [y0]
    t, y = t0, y0
    while t < t_end - 1e-12:
        h_cur = min(h, t_end - t)
        k1 = h_cur * f(t, y)
        k2 = h_cur * f(t + h_cur/2, y + k1/2)
        k3 = h_cur * f(t + h_cur/2, y + k2/2)
        k4 = h_cur * f(t + h_cur, y + k3)
        y += (k1 + 2*k2 + 2*k3 + k4) / 6
        t += h_cur
        ts.append(t); ys.append(y)
    return np.array(ts), np.array(ys)

def max_err(ts, ys, exact):
    return np.max(np.abs(ys - exact(ts)))

if __name__ == "__main__":
    # 测试 IVP: y' = -y, y(0) = 1, t in [0,5], 解析解 y = e^{-t}
    f = lambda t, y: -y
    exact = lambda t: np.exp(-t)
    T = (0.0, 5.0)

    # 自测 1: 同一步长 h=0.05 下误差量级对比
    err_e = max_err(*euler_solve(f, 1.0, T, h=0.05), exact)
    err_r = max_err(*rk4_solve(f, 1.0, T, h=0.05), exact)
    assert err_e < 5e-2, f"Euler 误差过大: {err_e}"
    assert err_r < 1e-3, f"RK4 误差过大: {err_r}"
    assert err_r < err_e / 10, "RK4 应显著优于 Euler"

    # 自测 2: 收敛阶验证——h 减半, Euler 误差减半, RK4 误差减为 1/16
    ratio_e = err_e / max_err(*euler_solve(f, 1.0, T, h=0.025), exact)
    ratio_r = err_r / max_err(*rk4_solve(f, 1.0, T, h=0.025), exact)
    assert 1.6 <= ratio_e <= 2.4, f"Euler 应一阶收敛, 得 {ratio_e:.2f}"
    assert 12 <= ratio_r <= 20, f"RK4 应四阶收敛, 得 {ratio_r:.2f}"

    # 自测 3: 自适应库求解器 solve_ivp 高精度参考
    sol = solve_ivp(f, T, [1.0], rtol=1e-10, atol=1e-12)
    err_ivp = np.max(np.abs(sol.y[0] - exact(sol.t)))
    assert err_ivp < 1e-8, f"solve_ivp 误差过大: {err_ivp}"
    assert abs(sol.y[0, -1] - np.exp(-5)) < 1e-8

    # 自测 4: 刚性问题 y' = -1000y——显式大步长爆炸, 隐式 BDF 正常
    f_stiff = lambda t, y: -1000 * y
    _, y_s = euler_solve(f_stiff, 1.0, (0, 0.1), h=0.01)
    assert np.max(np.abs(y_s)) > 1e5, "显式 Euler 在刚性问题大步长下应发散"
    _, y_s2 = rk4_solve(f_stiff, 1.0, (0, 0.1), h=0.01)
    assert np.max(np.abs(y_s2)) > 1e5, "显式 RK4 在刚性问题大步长下应发散"
    sol_bdf = solve_ivp(f_stiff, (0, 0.1), [1.0], method='BDF',
                        rtol=1e-8, atol=1e-10)
    err_bdf = np.max(np.abs(sol_bdf.y[0] - np.exp(-1000 * sol_bdf.t)))
    assert err_bdf < 1e-3, f"隐式 BDF 应能处理刚性问题: {err_bdf}"

    print(f"Euler 误差 = {err_e:.2e} | RK4 误差 = {err_r:.2e} | solve_ivp 误差 = {err_ivp:.2e}")
    print(f"收敛阶: Euler x{ratio_e:.2f}, RK4 x{ratio_r:.2f} (理论 2 / 16)")
    print("常微分方程数值视角单元测试与自查验证全部成功！")
```

（在 numpy 2.4 + scipy 1.17 下实测通过：Euler 误差 $9.4\times10^{-3}$、RK4 误差 $2.0\times10^{-8}$、solve_ivp 误差 $7.9\times10^{-12}$；收敛阶实测 2.02 / 16.3；刚性问题显式发散与隐式 BDF 成功均验证。）
