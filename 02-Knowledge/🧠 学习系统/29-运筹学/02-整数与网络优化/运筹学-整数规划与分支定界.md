# 整数规划与分支定界

> 所属阶段：[[🧭 阶段2-整数与网络优化|🕸️ 第2阶段：整数与网络优化]]

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**；现实中"建不建厂、派不派车、选不选项目"全是 0-1 决策，连续 LP 无法表达——整数规划（MIP）是运筹学应用面最广的模型类，分支定界（B&B）是所有 MIP 求解器的骨架；[[🧭 课程作业总索引]] 的[[运筹学-课后作业-03-整数规划建模与B&B手撕|课后作业 03]]直接用它，[[运筹学-约束规划与CP-SAT]] 也以"另一套搜索范式"的身份与它对比。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> [[运筹学-线性规划与单纯形法]] 解决连续决策，但现实大量决策是**离散的**：仓库建或不建（0/1）、车派给哪条路线（指派）、旅行商按什么顺序访问城市（排列）。直接取整 LP 解：可能不可行，即使可行也常远非最优（例子 1 会看到 34 vs 39 的差距）。因此引入：**整数规划**（LP + 整数约束）与**分支定界**（"放松整数约束求上下界 + 剪枝"的通用搜索框架）。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：整数规划是 **NP-hard** 问题类（背包、TSP 都是特例），B&B 是理解"NP-hard 问题为何工程上仍可解"的钥匙；也是 [[运筹学-约束规划与CP-SAT]] 与启发式方法（[[运筹学-元启发式方法\|模拟退火]]）的对比基准。
- **实际应用场景**：供应链选址、机组排班、投资组合（整数手数）、芯片布线、TSP/VRP；OR-Tools 的 SCIP、CP-SAT MIP 模式与 CPLEX/Gurobi 全部基于 B&B + 割平面。**高频题型/任务**：建模（背包/指派/选址/集合覆盖，见 [[运筹学-整数规划建模\|背包]]）、判断 LP 松弛界、手写/程序 B&B 树、TSP 的整数规划建模。

2. **图论基础**（TSP/网络）：顶点、回路、匹配——见 [[运筹学-匹配与指派问题\|二分图]]。

## 4. 用直觉语言解释它

> «"分支定界就像在图书馆找一本特定书：先把书架放松成'上界目录'（任何书最多值这么多分），再一层层按类别分支（左半/右半）；每到一个分支先查目录：如果这一半的高级比手里最好的书还低，就整个书架剪掉不翻。分支越细，高级越准，剪得越快。"»

- **直觉类比/几何图像**：整数可行点是"漂浮在多面体里的散点"，LP 松弛多面体是外壳（界）；B&B 用超平面（$x_j \le k$ / $x_j \ge k+1$）不断切外壳，让它贴着散点收紧。"先求松的界、再用界淘汰整片区域"是搜索的通用省钱策略（同源于二分查找、Alpha-Beta 剪枝）。
- **一句话直觉本质**：**用 LP 松弛给出界，用分支排除非整数解，用界剪掉不可能更优的子树——精确、可证明最优，但最坏情况指数时间。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
**混合整数线性规划（MILP）**：
$$\min\ \mathbf{c}^T\mathbf{x} + \mathbf{d}^T\mathbf{y} \quad \text{s.t.}\quad A\mathbf{x} + B\mathbf{y} \le \mathbf{b},\quad \mathbf{x} \ge \mathbf{0},\quad \mathbf{y} \in \{0,1\}^p$$

**LP 松弛**：删去整数约束的 LP。对最小化，松弛最优值 $z_{LP}$ 是 $z^*$ 的**下界**（最大化则上界）；**界越紧，B&B 剪枝越狠**。**分支定界（B&B）框架**：① **定界**：解子问题的 LP 松弛得界；② **剪枝**：界不优于 incumbent（当前最好整数可行解）或 LP 解本身整数可行，则剪掉子树；③ **分支**：取分数变量 $y_j = f$，生成 $y_j \le \lfloor f \rfloor$ 与 $y_j \ge \lceil f \rceil$ 两个子问题；④ 递归至无可分支节点。

**TSP 的整数规划建模（DFJ）**：$x_{ij} \in \{0,1\}$ 表示走边 $(i,j)$：
$$\min \sum_{i,j} c_{ij} x_{ij} \quad \text{s.t.}\quad \sum_j x_{ij} = 1\ \forall i,\quad \sum_i x_{ij} = 1\ \forall j,\quad \sum_{i \in S,\, j \notin S} x_{ij} \ge 1\ \forall\ \varnothing \ne S \subsetneq V$$
最后一行是**子回路消除约束**（割形式）：任何真子集必须至少一条边出去，杜绝"小圈圈"。

### 2. 核心公式
**相对最优性差距（MIP gap）**——求解器报告的验收指标：
$$\text{gap} = \frac{|z_{incumbent} - z_{bound}|}{|z_{incumbent}|} \times 100\%$$
gap = 0 即证明最优；工程上常设 gap limit（如 1%）提前终止。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathbf{x}, \mathbf{y}$ | 连续 / 0-1 变量 | $\mathbb{R}^n_{\ge0}$ / $\{0,1\}^p$ | 0-1 表达离散选择 |
| $z_{LP}$ | 松弛最优值 | $\mathbb{R}$ | 界的来源 |
| incumbent | 当前最好整数可行解 | — | 下界（最小化） |
| gap | 相对最优性差距 | $[0,100)\%$ | 求解器验收指标 |
| $x_{ij}$ | TSP 是否走边 $(i,j)$ | $\{0,1\}$ | 排列的 0-1 表达 |

### 4. 常见变体与适用条件
- **变体**：分支**割平面**（Branch-and-Cut，加 Gomory 割收紧松弛）、分支**定价**（列生成，大规模）、启发式取 incumbent。**适用条件**：除整数性外目标约束线性、界紧或规模适中；**限制**：最坏指数（NP-hard），对称性拖慢搜索（需对称破缺）。

## 6. 推导思路和思想来源

- **最初困难**：0-1/整数变量使可行域离散化，没有梯度与极点可言；穷举 $2^p$ 组合爆炸；取整 LP 解既不保可行也不保最优，单靠割平面收敛慢。
- **关键"转念"**：**不直接求解离散问题，而是反复求解它的"连续外壳"（LP 松弛）**——外壳的解给出界，用界成片排除区域；外壳解恰好整数时即得可证明的最优。Land & Doig (1960) 固化为树搜索框架。
- **推导主线与动机**：松弛界 → 分支排除分数解 → 界与 incumbent 比较剪枝 → 树穷尽即最优。割平面同理：松弛解不在整数凸包上，就加一条切掉它的平面收紧界。**为什么自然**："松弛-界-剪枝"把指数搜索变成自适应搜索，而实际问题界通常紧，故工程上极其成功。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：$\max\ z = 5x_1 + 8x_2$，s.t. $x_1+x_2 \le 6$，$5x_1+9x_2 \le 45$，$x_1,x_2 \ge 0$ 整数。
- **解题思路与关键步骤**：① 根节点 LP 松弛：交点 $(2.25, 3.75)$，$z_{LP}=41.25$，上界 41；② 取整 $(2,3)$ 可行但 $z=34$——取整失效！③ 分支 $x_1 \le 2$：LP 界 41.11 → 再分支 $x_2\le3$ 得可行 $(3,3)$，$z=39$；$x_2\ge4$ 与 $x_1\le2$ 矛盾剪枝；④ 分支 $x_1 \ge 3$：LP 界 41.67 → 分支 $x_2\le3$ 得 $(3,3)$ 更新 incumbent 39；$x_2\ge4$ 不可行剪枝。
- **最终答案**：$(x_1^*, x_2^*) = (3, 3)$，$z^* = 39$；两个分支均收敛，树穷尽即最优性证明。
- **易错点**：把根 $z_{LP}=41.25$ 当答案；忘记取整不可行/次优。**🤔 追问**：第二约束改为 $5x_1+9x_2 \le 44$？——$(3,3)$ 仍可行，最优仍 39，树更小。

**B&B 树图示**（例子 1 的分支过程；方框=节点，标 LP 界/剪枝理由）：

```mermaid
flowchart TD
    R[根节点<br/>LP 松弛 41.25<br/>取整(2,3) 得可行 z=34] --> A[x1 ≤ 2<br/>LP 界 41.11]
    R --> B[x1 ≥ 3<br/>LP 界 41.67]
    A --> A1[x2 ≤ 3<br/>整数解 (3,3) z=39<br/>更新 incumbent=39]
    A --> A2[x2 ≥ 4<br/>与 x1≤2 矛盾 → 剪枝]
    B --> B1[x2 ≤ 3<br/>整数解 (3,3) z=39<br/>不优于 incumbent → 剪枝]
    B --> B2[x2 ≥ 4<br/>不可行 → 剪枝]
```

### 例子 2：中等例子（条件判断与多步推理）
- **题目与完整解答**：背包容量 $W=10$：A(6,8) B(5,7) C(4,6) D(3,4)（重量,价值）。按密度排序 C>B>A=D；根 LP 松弛装 C、B 后剩 1 装 $1/6$ A：价值 $6+7+8/6=14.33$，**上界 14**；可行解 A+C 价值 14 = 上界 → **根节点即证最优，无需分支**。要点：紧的界让搜索一步收敛——这正是 课后作业 03 验收"报告 MIP gap"的意义；一般形式见 [[运筹学-整数规划建模\|背包]]。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：TSP 的 DFJ 模型是[[运筹学-大作业-01-VRP车辆路径问题|大作业 01]]的建模基础；指数多个子回路约束在求解器中用 **lazy callback** 动态添加。OR-Tools 的 MIP 求解器默认 SCIP：
```python
from ortools.linear_solver import pywraplp
solver = pywraplp.Solver.CreateSolver("SCIP")
n = 4
x = {}
for i in range(n):
    for j in range(n):
        if i != j:
            x[i, j] = solver.IntVar(0, 1, f"x_{i}_{j}")
for i in range(n):                      # 每城恰好一进一出
    solver.Add(sum(x[i, j] for j in range(n) if i != j) == 1)
    solver.Add(sum(x[j, i] for j in range(n) if i != j) == 1)
solver.Add(x[0, 1] + x[1, 0] <= 1)      # 子回路消除（示意，正式用 callback）
solver.Minimize(sum(c[i][j] * x[i, j] for i in range(n) for j in range(n) if i != j))
solver.Solve(); print(solver.Objective().Value())  # 与手撕 B&B 对照，gap=0
```

## 8. 常见误区和易混概念

### 误区 1：以为"LP 解取整就是整数规划的解"
- **错误直觉**：取整损失一点精度，问题不大；但取整可能不可行（$(2,4)$ 违反 $5x_1+9x_2\le45$），也可能严重次优（34 vs 39，差 13%）。
- **正确理解**：整数规划的困难恰恰在于"取整走不通"，必须用 B&B/割平面等专门方法。

### 误区 2：以为"B&B 一定能很快求出最优"
- **错误直觉**：框架正确 = 实际快；但 B&B 最坏要枚举指数个节点（NP-hard 本质），快慢取决于**界紧不紧**与分支/选点策略。
- **正确理解**：B&B 是"可证明最优的通用框架"，快慢由问题结构决定；课后作业 03 的求解时间曲线正是观察这一点。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| LP 松弛 | 给出界的连续外壳 | 无整数约束，多项式可解 | B&B 的定界子程序 |
| 分支定界 | 用界剪枝的树搜索 | 精确、最坏指数 | 所有 MIP 求解器骨架 |
| 割平面 | 收紧松弛外壳 | 加有效不等式，常与 B&B 组合 | Branch-and-Cut、整数凸包研究 |
| 分支定价 | 海量变量处理 | 列生成动态加变量 | 机组排班、大规模 TSP |

### 题目与解析

#### 1. 为什么"把 LP 松弛最优解四舍五入取整"不能作为整数规划的通用解法？
> [!question]- 答案解析
> - **答案**：取整解可能不可行，即使可行也可能严重次优；例：松弛解 $(2.25,3.75)$ 取整得 $(2,4)$ 违反 $5x_1+9x_2\le45$，$(2,3)$ 可行但 $z=34$，最优是 $(3,3)$ 的 39。
> - **解析**：整数可行域是离散点集，与连续外壳之间没有"取整保可行"的映射；这也是整数规划 NP-hard 而 LP 多项式可解的本质差异。
> - **易错原因**：把"数值上接近"误当成"结构上等价"。
> - **对应误区**：误区 1。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 最小化问题中，节点 P 的 LP 松弛值 $z_{LP}(P) = 12.7$，incumbent $z = 13$。该节点能否剪枝？
> [!question]- 答案解析
> - **答案**：能。$z_{LP}(P)=12.7$ 意味着该子树任何解目标 $\ge 12.7$，整数解目标 $\ge 13$，不可能优于 incumbent 13，故剪枝——这是"整数下取整"带来的额外剪枝（剪枝条件 $z_{LP}(P) \ge z_{incumbent}$）。

#### 3. 什么样的实例会让 B&B 接近最坏情况（指数级）？
> [!question]- 答案解析
> - **答案**：LP 松弛界很松（整数凸包与松弛多面体差距大）且分数变量多的实例，如随机大系数背包、无结构 0-1 矩阵问题；此时几乎每个节点都要展开，剪枝失效。对策：加有效不等式、改进分支策略（强分支）、启发式先拿好 incumbent——界松时 30 个 0-1 变量也能跑不动。

#### 4. TSP 模型中为什么需要子回路消除约束？去掉它会怎样？
> [!question]- 答案解析
> - **答案**：仅有一进一出约束时，解可能是多个不相交小回路（如 1→2→1 与 3→4→3），不是一条 Hamiltonian 回路；割形式 $\sum_{i\in S, j\notin S} x_{ij}\ge 1$ 强制任何真子集必须有边通向外，消除子回路。DFJ 有指数多个约束，实践中用 lazy callback 按需添加；MTZ 用 $O(n^2)$ 辅助变量但松弛更松——这是大作业 01 手撕 TSP 的关键点。

#### 5. 解释"割平面"收紧界的直觉，并说明为什么它与 B&B 互补。
> [!question]- 答案解析
> - **答案**：整数可行点的凸包是松弛多面体的"内核"；割平面是一条把松弛最优解（分数点）与整数凸包分开的线性不等式——加上它，新松弛解离整数凸包更近，界更紧。B&B 靠分支收紧，割平面靠不等式收紧，两者结合（Branch-and-Cut）是现代求解器标配。Gomory 割可由单纯形表自动生成；"界紧度是第一性能指标"是理解一切 MIP 加速技术的钥匙。
