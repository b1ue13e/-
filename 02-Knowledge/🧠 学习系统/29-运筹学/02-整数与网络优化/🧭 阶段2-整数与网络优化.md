# 🕸️ 第二阶段：整数与网络优化

## 为什么现在学？

现实决策大量是**离散的**：仓库建不建（0/1）、车派给哪条路线（指派）、访问城市按什么顺序（排列）。连续 LP 无法表达这些决策；把 LP 的"整数约束"加入就得到**整数规划（MIP）**，用**分支定界（B&B）**与**割平面**求解。另一条线是**网络结构**：运输、分配、流问题天然是图上的优化，有比通用 MIP 更快的专用算法。本阶段还引入与 MIP 互补的**约束规划（CP-SAT）**范式，以及最重要的应用——**车辆路径问题（VRP）**。

## 学习目标

学完本阶段，你能：

1. 把背包、选址、集合覆盖、指派翻译成 0-1 整数规划模型，并理解"松弛—界—剪枝"的 B&B 框架。
2. 手撕一次小型 B&B（用 LP 松弛给界、分支剪枝），并理解割平面如何收紧松弛。
3. 建立最大流、最小费用流模型，用增广路径思想求解，理解流守恒与残量网络。
4. 解二分图匹配与指派问题（增广路径、匈牙利方法），理解稳定匹配（Gale-Shapley）。
5. 用 CP-SAT 建模排班/组合约束问题，对比 CP 与 MIP 的适用边界。
6. 建模 TSP/VRP/CVRP/VRPTW，用 OR-Tools Routing 求解并做小规模精确对照。
