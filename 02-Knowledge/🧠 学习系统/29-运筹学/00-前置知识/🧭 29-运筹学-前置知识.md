# 🧭 29-运筹学-前置知识

## 1. 为什么需要前置知识？

运筹学把现实决策问题翻译成**模型**再用**算法**求解，两头都需要工具：

- **线性代数**：单纯形表的每一步都是高斯消元；"基可行解"就是线性代数里的"基"；对偶、灵敏度分析都建立在矩阵运算上。
- **概率与期望**：第三阶段的 MDP、库存、排队，第四阶段的随机规划、仿真，全部以随机变量、期望、条件期望为语言。
- **凸集与凸函数**：LP 可行域是凸多面体、"最优解在极点"的几何依据。
- **Python 与 OR-Tools**：本课程作业统一用 Python + Google OR-Tools 建模求解，需要最小环境与建模基础。

如果你在推导中卡在基础运算，将无法把精力集中在"建模与算法结构"上。因此先通过本层诊断，再进入第一阶段。

## 2. 最低通过标准与进入条件

进入 [[🧭 阶段1-线性规划基础|第一阶段]] 前，请确保能独立完成以下诊断：

- **线性代数**：能手算一个 3×3 增广矩阵的高斯消元并判断解的情况；能解释"基、秩、线性无关"；理解 $A\mathbf{x}=\mathbf{b}$ 中 $\mathbf{x}$ 的含义。
- **概率**：能写出离散随机变量的期望 $E[X]=\sum_x x\,P(X=x)$ 与方差定义；理解条件概率与全概率公式；知道期望的线性性 $E[aX+bY]=aE[X]+bE[Y]$。
- **凸性**：能判断一个集合是否凸；理解"凸多面体的极点是基可行解"的几何直觉。
- **编程**：能运行 Python 脚本、安装 pip 包、用 OR-Tools 求解一个最小 LP 示例并读取解。

> 诊断不通过的模块，按下方"补学顺序"回到原课程补学，不跳过。

## 4. 补学顺序

1. 线性代数薄弱 → 09-高等代数 `01-基础入门/`（矩阵运算 → 高斯消元 → 基与维数 → 秩），完成即可满足诊断。
2. 概率薄弱 → 22-概率论与数理统计 `01-概率基础/`（概率空间与事件 → 随机变量与分布 → 数字特征）。
3. 凸性未接触 → 07-最优化方法 `02-凸分析与最优性条件/最优化方法-凸集与凸函数`。
4. Python/OR-Tools 未装 → 完成 [[运筹学-前置-OR-Tools环境与建模]] 的环境步骤。
