# 运筹学-前置-概率与期望

> 所属阶段：[[🧭 29-运筹学-前置知识|前置知识]]

## 这个知识点解决什么问题？

运筹学后半程全是"不确定条件下的决策"。**我们遇到的麻烦**：库存备多少货（需求随机）、排队等多久（到达随机）、随机规划怎么比较方案（期望成本）——不掌握期望与条件期望，这些模型无法读懂。本卡讲运筹学需要的最小概率集：随机变量、期望、条件期望、常用分布。

## 核心定义与公式

### 1. 随机变量与分布

- **随机变量** $X$ 是样本空间到实数的函数；离散型用概率质量函数 $P(X=x)$ 描述，连续型用密度 $f(x)$。
- **常用分布**：Bernoulli（一次成功/失败）、Binomial（$n$ 次独立试验成功次数，$E[X]=np$）、Poisson（单位时间事件数，$E[X]=\lambda$）、Normal（$\mathcal{N}(\mu,\sigma^2)$）、Exponential（排队论服务/到达间隔，$E[X]=1/\lambda$）。

### 2. 期望

$$E[X]=\sum_x x\,P(X=x)\quad(\text{离散}),\qquad E[X]=\int x f(x)\,dx\quad(\text{连续})$$

**期望的线性性**（运筹学最常用）：$E[aX+bY]=aE[X]+bE[Y]$，**不要求 $X,Y$ 独立**。

### 3. 条件期望

- 条件概率 $P(A\mid B)=P(A\cap B)/P(B)$；全概率公式 $P(B)=\sum_i P(B\mid A_i)P(A_i)$。
- **条件期望** $E[X\mid Y=y]$：给定 $Y=y$ 时 $X$ 的平均值。
- **塔性质（全期望公式）**：$E[X]=E[E[X\mid Y]]$——这是 MDP 贝尔曼方程与随机规划两阶段模型的数学根基。

### 4. 符号说明

| 符号 | 含义 | 备注 |
|:---|:---|:---|
| $X,Y$ | 随机变量 | 需求、到达时间等 |
| $E[X]$ | 期望 | 平均意义 |
| $E[X\mid Y]$ | 条件期望 | 给定 $Y$ 后的平均 |
| $P(A\mid B)$ | 条件概率 | 已知 $B$ 时 $A$ 的概率 |

## 一个最小例子

库存问题：每天需求 $D$ 服从 $P(D=0)=0.3,\ P(D=1)=0.5,\ P(D=2)=0.2$。若备货 1 件，当日期望缺货量：
$$E[(D-1)^+]=(0)\cdot0.3+(0)\cdot0.5+(1)\cdot0.2=0.2.$$

这正是 [[运筹学-库存管理]] 中"服务水平/期望成本"建模的最小雏形——**随机问题转化为期望目标**。

## 塔性质数值验证（numpy 模拟）

手算验证 $E[X]=E[E[X\mid Y]]$ 用"先掷硬币、再按结果选 Bernoulli"的例子：$Y=1$（概率 0.5）时 $X\sim\text{Bernoulli}(0.8)$，$Y=0$ 时 $X\sim\text{Bernoulli}(0.2)$。理论 $E[X]=0.5\times0.8+0.5\times0.2=0.5$：

```python
import numpy as np
rng = np.random.default_rng(42)          # 固定种子，结果可复现
N = 2_000_000
coin = rng.binomial(1, 0.5, N)          # Y：正/反各 0.5
p = np.where(coin == 1, 0.8, 0.2)       # 按 Y 选成功概率
X = rng.binomial(1, p)                  # 观测 X
print("模拟 E[X] =", X.mean())          # ≈ 0.499
E_X_given_Y = [X[coin == 0].mean(), X[coin == 1].mean()]
print("E[X|Y=0]=", E_X_given_Y[0], " E[X|Y=1]=", E_X_given_Y[1])
print("E[E[X|Y]] =", E_X_given_Y @ np.array([0.5, 0.5]))   # ≈ 0.5 ✓
```

输出：三个值都 ≈ 0.5（模拟误差 < 0.001）——**塔性质被数值证实**。这是 MDP 贝尔曼方程 $V(s)=\sum_{s'}P(s'\mid s)V(s')$ 的思想来源：先按转移概率"分层"求条件期望，再对外层随机变量取期望。

## 常用分布对比（运筹学选型）

| 分布 | 用途 | 参数 | $E[X]$ | 典型场景 |
|:---|:---|:---|:---|:---|
| Bernoulli | 单次成败 | $p$ | $p$ | 是否缺货、0-1 决策 |
| Binomial | $n$ 次独立试验成功数 | $n,p$ | $np$ | 抽查不合格数 |
| Poisson | 单位时间事件数 | $\lambda$ | $\lambda$ | 顾客到达数、故障次数 |
| Exponential | 到达/服务间隔 | $\lambda$ | $1/\lambda$ | 排队论 M/M/1 的服务时间 |
| Normal | 连续对称误差 | $\mu,\sigma^2$ | $\mu$ | 需求近似、测量误差 |

**选型提醒**：到达数用 Poisson、到达间隔用 Exponential，是排队论的标准配对；不要所有随机量都套 Normal（见误区 3）。

## 常见误区

- **误区 1**：期望线性性需要独立性。不对——线性性无条件成立；方差才需要独立性假设。
- **误区 2**：$E[X\mid Y]$ 当作普通数。它是 $Y$ 的函数（随机变量），所以 $E[E[X\mid Y]]=E[X]$ 才有意义。
- **误区 3**：分布一律用 Normal。排队论中到达间隔用 Exponential、到达数用 Poisson 才是标准建模，用错分布会导致错误结论。
- **误区 4**：用模拟结果当精确值。numpy 模拟只是验证/估计，误差 ~ $1/\sqrt{N}$；理论计算才给出精确答案（见 [[运筹学-仿真与MonteCarlo]]）。

## 与本课程的连接

- [[运筹学-Markov决策过程]] 的贝尔曼方程 $V(s)=R(s)+\gamma\sum_{s'}P(s'\mid s,a)V(s')$ 就是全期望公式的展开。
- [[运筹学-随机规划]] 的期望目标 $\min_x E_\omega[f(x,\omega)]$ 直接使用期望。
- [[运筹学-排队论]] 的 Little 定律 $L=\lambda W$ 建立在稳态期望之上。
