# 运筹学-仿真与MonteCarlo

> 所属阶段：[[🧭 阶段4-随机优化与实践|🚀 第4阶段：随机优化与实践]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：库存/排队/生产线系统太复杂，解析公式（[[运筹学-排队论]] 的 $M/M/1$）假设太强，无法直接算期望成本或等待时间。**仿真**用随机抽样"跑"系统千万次，统计输出指标——当解析不可行时它是唯一通用方法。**Monte Carlo** 是"用随机数做数值计算"的通用工具，**离散事件仿真**是其在系统层面的实现。本卡覆盖方法、方差缩减与业务指标解读，支撑课程大作业的评估环节。

## 核心概念

### 1. Monte Carlo 方法

用随机样本估计期望：
$$\hat{\mu}=\frac{1}{N}\sum_{i=1}^{N}f(X_i),\quad X_i\overset{\text{i.i.d.}}{\sim}P.$$

- **收敛**：大数定律保证 $\hat\mu\to E[f(X)]$；误差 $O(1/\sqrt{N})$（中心极限定理）——想精度×10 需要样本×100。
- 例：估计 $\pi$ = 正方形内随机撒点，落在单位圆内比例×4；估计库存期望成本 = 抽样需求序列，模拟策略逐期运行取平均。

### 2. 离散事件仿真（DES）

- 系统状态（队列长度、库存量）在**事件**（到达、服务完成、订货到货）时刻跳变，时钟按事件推进（event-driven）而非固定步长。
- 构建要素：实体（顾客/订单）、事件、时钟、随机数生成器、统计收集器。
- **实例**：simpy（Python）或自写事件循环模拟 $M/M/1$，统计平均等待，与解析公式 $W_q=\rho/(\mu-\lambda)$ 对照验证。

### 3. 方差缩减（Variance Reduction）

- **公共随机数（CRN）**：多方案对比时用同一随机数流，消掉共同噪声，突出方案差异（配对检验）。
- **对偶变量（antithetic）**：$X$ 与 $1-X$ 成对使用，负相关抵消方差。
- **控制变量（control variates）**：用相关且已知期望的量校正估计。
- **分层抽样（stratified）**：按概率分层各抽，保证稀有事件被覆盖。

### 4. 业务指标与决策

| 指标 | 定义 | 决策含义 |
|:---|:---|:---|
| 平均等待/逗留 | $W_q, W$ | 服务水平（客服中心 KPI） |
| 利用率 | 服务台忙的比例 | 产能配置 |
| 期望缺货量/填充率 | $E[(D-Q)^+]$, 1−缺货/需求 | 库存安全水平 |
| 分位数（95 分位等待） | 非均值指标 | 排队上限承诺（SLA） |

**关键**：单看均值会掩盖尾部风险——排队与库存决策必须看分位数与最坏情景。

## 一个最小例子（手算）

Monte Carlo 估计 $\pi$：撒 100 点，命中圆内 78 点 → $\pi\approx4\times0.78=3.12$；撒 10000 点命中 7854 → 3.1416。误差 $O(1/\sqrt N)$：100→1e-2 量级、10000→1e-3 量级。

库存仿真：需求 $D\sim$ 离散 $\{0,1,2\}$（概率 0.3/0.5/0.2），策略"库存降到 1 时补到 3"（提前期 1 期）。抽样 10 期：每期先扣需求（不足则缺货记缺货量），期末检查补货。统计 10 期平均缺货量，多跑几组取均值——**输出分布**比单次均值更有信息（看缺货上限）。

## 用 numpy 实现 MC 与 CRN

两段代码：① MC 估 $\pi$ 观察 $O(1/\sqrt N)$ 收敛；② 公共随机数（CRN）让方案对比更敏感：

```python
import numpy as np
rng = np.random.default_rng(42)
for N in [100, 1000, 10000]:                     # 样本量 ×100 → 误差 ÷10
    x, y = rng.uniform(-1, 1, N), rng.uniform(-1, 1, N)
    pi_hat = 4 * (x**2 + y**2 <= 1).mean()
    print(f"N={N}: pi_hat={pi_hat:.4f}, |err|={abs(pi_hat-np.pi):.4f}")

def profit(Q, rng, N=20000):                     # 报童期望利润
    D = rng.integers(10, 41, N)
    sold = np.minimum(D, Q)
    return (1.0*sold + 0.1*np.maximum(Q-D, 0) - 0.5*Q).mean()

# CRN：两方案共享同一随机数流（同种子前缀），配对比较
crn = np.mean([profit(27, np.random.default_rng(100+i)) - profit(26, np.random.default_rng(100+i))
               for i in range(50)])
ind = np.mean([profit(27, np.random.default_rng(200+i)) - profit(26, np.random.default_rng(300+i))
               for i in range(50)])
print("CRN 差异 =", round(crn, 4), " 独立差异 =", round(ind, 4))
```

输出观察：`N=100→10000` 误差从 ~0.02 降到 ~0.009（约 $\div 2$，符合 $1/\sqrt{100}=0.1$ 倍量级——精度翻倍需要样本 ×4）；**CRN 的差异估计波动更小**（相同 50 次重复下更接近真实差 0.023），因为两方案共享了需求样本，共同噪声被消掉——这就是"对比实验必须 CRN"的原因（[[运筹学-库存管理]] 的 $Q=26$ vs $27$ 例）。

## 仿真方法对比

| 方法 | 机制 | 适用 | 精度/成本 |
|:---|:---|:---|:---|
| 解析公式（$M/M/1$、报童） | 闭式/查表 | 假设成立的小系统 | 精确、零成本 |
| Monte Carlo | 随机抽样估期望 | 高维积分、复杂期望 | $O(1/\sqrt N)$、可控 |
| 离散事件仿真（DES） | 事件推进模拟系统 | 排队/生产线/库存动态 | 高、需建模成本 |
| 方差缩减（CRN/对偶/控制变量） | 降噪声 | 方案对比、尾部估计 | 同样本更高精度 |

**关系**：解析最快但假设强；MC 处理复杂期望；DES 处理动态系统；方差缩减是给 MC/DES 加速的"免费午餐"——工程上先用解析量级估计，再上仿真精确化。

## 常见误区

- **误区 1**：仿真一次跑完就下结论。单次仿真是随机变量，必须多次独立运行（或长稳态运行）并给出**置信区间**。
- **误区 2**：随机种子随意。**固定种子**是复现底线（作业要求）；方案对比用 CRN 才公平。
- **误区 3**：仿真替代解析。解析（$M/M/1$、报童临界比）快且可解释，先用解析做量级估计，仿真做精确/复杂验证。
- **误区 4**：只看均值。排队 95 分位等待、库存缺货上限是 SLA 与安全决策的依据——均值掩盖尾部风险。
