# 运筹学-元启发式方法

> 所属阶段：[[🧭 阶段4-随机优化与实践|🚀 第4阶段：随机优化与实践]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：VRP、Job-Shop、大规模 MIP 在真实规模下精确求解不可行（NP-hard，时间不够）。但工程上要"足够好"的解。**元启发式**放弃最优性证明，用"邻域搜索 + 逃逸局部最优"的通用策略，在可接受时间内给出高质量近似解。OR-Tools Routing 的 `GUIDED_LOCAL_SEARCH`、排班求解器都在内部使用它们。本卡覆盖三个核心：**邻域搜索**、**模拟退火**、**禁忌搜索**。

## 核心概念

### 1. 邻域搜索（Local Search）

- **解空间 + 邻域**：解的"邻居" = 一次小改动得到的解（swap 两个位置、insert/remove、2-opt 翻转）。
- **爬山法**：从初始解出发，反复移向邻居中最优者，直到局部最优。
- **问题**：局部最优 ≠ 全局最优；爬山一旦进坑就出不来。

### 2. 模拟退火（Simulated Annealing）

借鉴金属退火：以概率接受**更差的解**，概率随"温度"下降而减小。

- 当前解 $x$，邻居 $x'$，$\Delta=E(x')-E(x)$（最小化）：
$$P(\text{接受})= \begin{cases}1 & \Delta<0\\ e^{-\Delta/T} & \Delta\ge0\end{cases}$$
- 温度 $T$ 从高到低（退火计划）；**高温=大胆探索，低温=精细收敛**。
- 关键参数：初始温度、降温速率、每温度迭代数、停止准则。

### 3. 禁忌搜索（Tabu Search）

- 维护**禁忌表**：最近移动过的操作暂时禁止（防止立刻回到刚离开的解，即防"振荡"）。
- 每步选邻域中**非禁忌**的最优邻居（即使比当前差也接受——允许爬山式"下山"）。
- **禁忌长度**是核心参数：太短防不住振荡，太长限制探索；**特赦准则**（aspiration）允许禁忌解若足够好。

### 4. 通用对比

| 方法 | 逃逸机制 | 记忆 | 典型适用 |
|:---|:---|:---|:---|
| 爬山 | 无 | 无 | 基线、局部微调 |
| 模拟退火 | 随机接受差解（温度控制） | 无 | TSP/VRP、调度 |
| 禁忌搜索 | 禁忌表强制换方向 | 短期记忆 | 排班、VRP、图染色 |

## 一个最小例子（手算）

单变量：$f(x)=x^2$ 定义在整数 $x\in[-5,5]$，从 $x_0=3$ 出发，邻域 $\{\pm1\}$。

- 爬山：$x=3\to2\to1\to0$（每一步 $f$ 都降），停在全局最优 0——成功。
- 换 $f(x)=\lvert x\rvert-3\cos(\pi x/2)$（多坑）：爬山从 3 会卡在局部最优；**模拟退火**：温度高时接受 $f$ 上升的移动，跳出坑；温度降后收敛到全局最优。温度计划 $T=5\to0.5$，接受概率 $e^{-\Delta/T}$ 随 $T$ 降而趋 0。

## 用代码对比三种方法（实测逃逸能力）

多坑函数 $f(x)=\lvert x\rvert-3\cos(\pi x/2)$，整数 $x\in[-5,5]$，全局最优 $x=0,\ f=-3$（局部坑在 $\pm1,\pm4$，$f=1$）。从 $x_0=4$ 出发：

```python
import numpy as np, math
rng = np.random.default_rng(7)
def f(x): return abs(x) - 3*math.cos(math.pi*x/2)

def hill(x0=4):                                  # 爬山：只接受更优邻居
    x = x0
    while True:
        best = min((x-1, x+1), key=f)
        if f(best) < f(x): x = best
        else: return x, f(x)

def sa(x0=4, T0=10.0, alpha=0.95, iters=200):    # 模拟退火：概率接受差解
    x, T, best = x0, T0, (x0, f(x0))
    for _ in range(iters):
        nxt = x + rng.choice([-1, 1])
        d = f(nxt) - f(x)
        if d < 0 or rng.random() < math.exp(-d/T):
            x = nxt
        if f(x) < best[1]: best = (x, f(x))
        T *= alpha
    return best

def tabu(x0=4, length=3, iters=200):             # 禁忌搜索：禁最近访问解
    x, tl, best = x0, [], (x0, f(x0))
    for _ in range(iters):
        cands = [(nx, f(nx)) for nx in (x-1, x+1) if nx not in tl]
        if not cands: break
        x, _ = min(cands, key=lambda t: t[1])
        tl.append(x)
        if len(tl) > length: tl.pop(0)
        if f(x) < best[1]: best = (x, f(x))
    return best

print("爬山:", hill(4))      # (4, 1.0) 卡局部最优
print("退火:", sa(4))        # (0, -3.0) 找到全局最优
print("禁忌:", tabu(4))      # (4, 1.0) 也卡住
```

输出：爬山 `(4, 1.0)`、模拟退火 `(0, -3.0)`、禁忌搜索 `(4, 1.0)`。**关键解读**：
- **爬山**：$4$ 的邻居 $3,5$ 都更差（$f=3,5$），无路可走——卡死在局部最优；
- **模拟退火**：温度高时接受 $f$ 上升的移动（如 $4\to3$），一路"爬山越岭"最终到全局最优 $0$——**随机接受差解 = 逃逸机制**；
- **禁忌搜索**：本例也卡住（$4\to3\to4$ 振荡被禁忌表压住后无更好方向）——**诚实说明**：元启发式没有免费午餐，一维 $\pm1$ 邻域对禁忌搜索不利，它的优势体现在高维 swap/2-opt 邻域（如 TSP）。这本身是重要教训：**不是所有元启发式都适合所有问题**。

## 三种方法对比

| 方法 | 逃逸机制 | 记忆 | 参数 | 适用 |
|:---|:---|:---|:---|:---|
| 爬山 | 无（贪心） | 无 | — | 基线、精细局部微调 |
| 模拟退火 | 随机接受差解（温度控制） | 无 | $T_0,\alpha$、迭代数 | TSP/VRP、连续优化 |
| 禁忌搜索 | 禁忌表强制换方向 | 短期记忆 | 禁忌长度、特赦准则 | 排班、VRP、图染色 |

**关系**：爬山是基线（无逃逸）；SA 用"概率"逃逸（无记忆）；禁忌用"记忆"逃逸（确定性强制）——三者复杂度与适用性递增，工程上常组合使用（如先 SA 粗搜再爬山精修）。

## 常见误区

- **误区 1**：退火温度降太快。冷却过快 = 提前变爬山，卡局部最优；退火计划要足够慢（几何降温 $T_{k+1}=\alpha T_k,\ \alpha\approx0.9$）。
- **误区 2**：禁忌搜索每次必选最优邻居。允许接受差邻居是**故意**的（逃生机制）；只选最优邻居会退化成爬山。
- **误区 3**：元启发式给"最优解"。给的是近似解（无最优性证明）；报告时必须注明 gap 或与精确解对照，见 [[运筹学-VRP与路径优化]]。
- **误区 4**：以为某一种元启发式万能。上面代码已证：一维例中禁忌搜索也会卡住——选型要匹配问题邻域结构，不能套模板。
