# 运筹学-鲁棒优化

> 所属阶段：[[🧭 阶段4-随机优化与实践|🚀 第4阶段：随机优化与实践]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：随机规划需要知道概率分布，但很多场景分布未知或难以估计（需求预测误差、参数漂移）。**鲁棒优化**换个思路：不知道分布没关系，只要给出参数的**不确定性集**（参数可能落进的集合），就优化**最坏情形**——决策在集合内任何实现下都可行且目标有保证。代价是**保守**（最优值劣于"平均最优"），核心权衡：集合大小 ↔ 保守程度。

## 核心概念

### 1. 不确定性集（Uncertainty Sets）

约束参数 $\tilde{a}$ 落在集合 $\mathcal{U}$ 内：
$$\min\ \mathbf{c}^T\mathbf{x}\quad \text{s.t.}\quad \tilde{a}^T\mathbf{x}\le b\ \ \forall \tilde{a}\in\mathcal{U}.$$

常用集合：
| 集合 | 定义 | 特征 |
|:---|:---|:---|
| **盒集（box）** | $\lvert\tilde{a}_j-\hat{a}_j\rvert\le\epsilon_j$ | 最保守，逐系数独立最坏 |
| **椭球集（ellipsoid）** | $(\tilde{a}-\hat{a})^T\Sigma^{-1}(\tilde{a}-\hat{a})\le\Omega^2$ | 相关结构，得 SOCP |
| **预算集（budget）** | 至多 $\Gamma$ 个系数同时取最坏 | Bertsimas-Sim：灵活、可调保守度 |

### 2. 鲁棒对等（Robust Counterpart）

- **盒集**的鲁棒对等仍为 **LP**：把每个系数替换为其最坏值 $a_j+\epsilon_j$（最大化问题取上界）。
- **椭球集**对等为 **SOCP**（二阶锥规划）：利用对偶/柯西不等式改写，可被内点法高效求解。
- **预算集**对等仍为 LP：引入辅助变量表达"最多 $\Gamma$ 个偏离"，每个约束独立处理。

### 3. 预算集鲁棒对等的显式形式（Bertsimas-Sim）

这是本卡最容易"只闻其名、不见其形"的部分，给出完整推导。原始约束（标称系数 $a_j$、偏差上界 $d_j$、预算 $\Gamma$）：

$$\sum_j a_j x_j + \underbrace{\max_{\substack{S\subseteq J\\ |S|\le\Gamma}} \sum_{j\in S} d_j x_j}_{\text{最多 }\Gamma\text{ 个系数同时取最坏}} \le b$$

关键是内层 $\max$ 的**线性化**。它等价于：选至多 $\Gamma$ 个"偏离惩罚" $d_jx_j$ 最大化。引入变量 $z$（对应"取到第 $\Gamma$ 个偏离的边际量"）和 $p_j$（每个系数的独立防护），可证：

$$\max_{\substack{S:|S|\le\Gamma}}\sum_{j\in S}d_jx_j = \min\Big\{\Gamma z + \sum_j p_j : z+p_j \ge d_jx_j,\ z\ge0,\ p_j\ge0\ \forall j\Big\}$$

（对偶论证：左边是"选 $\Gamma$ 个最大 $d_jx_j$"，其对偶正是右边 LP——固定 $x$ 时两边值相等。）把 $\min$ 吸收进"$\le b$"约束（鲁棒约束要求对最坏情形成立，等价于存在一组 $z,p_j$ 使不等式成立），得到**预算集鲁棒对等 LP**：

$$\sum_j a_j x_j + \Gamma z + \sum_j p_j \le b,\qquad z+p_j \ge d_jx_j\ \forall j,\qquad z\ge0,\ p_j\ge0.$$

**解读**：$p_j$ 是"系数 $j$ 单独偏离 $\epsilon_j$ 时的防护费"，$z$ 是"第 $\Gamma$ 个偏离的共享边际费"——$\Gamma z+\sum_j p_j$ 精确等于"最多 $\Gamma$ 个偏离"的最坏附加消耗。这是把组合选择（选哪 $\Gamma$ 个）翻译成连续 LP 的关键一步，**保持 LP 结构**（无整数变量）。

### 4. 保守性权衡

- 集合越大 → 越保守 → 最坏目标越差，但对真实世界的防护越强。
- **对偶视角**：鲁棒约束的对偶变量即"最坏情形下的影子价格"，与 [[运筹学-对偶理论与影子价格]] 的灵敏度分析呼应——灵敏度分析给"局部变化"的区间，鲁棒优化给"全局集合"的保证。

## 一个最小例子（手算）

单约束投资：$\max\ x$ s.t. $\tilde{a}x\le 10$，其中 $\tilde{a}\in[2,4]$（盒集，标称 3）。

- **标称解**：$x=10/3\approx3.33$——但 $\tilde{a}=4$ 时不可行！
- **鲁棒解（盒集）**：最坏 $\tilde{a}=4$，$x=10/4=2.5$。保证集合内任何实现可行。
- **预算集**：若知道实际最多一个系数偏离（本例单系数，同盒集）；多系数时预算 $\Gamma$ 小于系数总数则比盒集松，目标更优、仍保可行。

## 用代码验证"标称不可行、鲁棒可行"

```python
from ortools.linear_solver import pywraplp

# 标称模型：a = 3
s = pywraplp.Solver.CreateSolver("GLOP")
x = s.NumVar(0, s.infinity(), "x"); s.Add(3*x <= 10); s.Maximize(x); s.Solve()
print("标称解 x =", x.solution_value())          # 3.333
print("标称解在 a=4 时:", 4*x.solution_value(), ">10 → 不可行")

# 盒集鲁棒模型：取最坏系数 a = 4
s2 = pywraplp.Solver.CreateSolver("GLOP")
x2 = s2.NumVar(0, s2.infinity(), "x"); s2.Add(4*x2 <= 10); s2.Maximize(x2); s2.Solve()
print("盒集鲁棒解 x =", x2.solution_value())      # 2.5
```

输出：标称解 $x=3.33$ 在 $\tilde{a}=4$ 时 $4\times3.33=13.3>10$ **不可行**；盒集鲁棒解 $x=2.5$ 在 $\tilde{a}\in[2,4]$ 内任何实现下都满足 $4\times2.5=10\le10$。**这就是鲁棒优化的核心 trade-off**：放弃 $0.83$ 的目标值（$3.33\to2.5$），换取"集合内任何参数实现都可行"的保证。盒集的鲁棒对等 = 把每个系数替换为其最坏值，保持 LP 结构——一行 `4*x2 <= 10` 就是整个"对等"。

## 用代码验证预算集对等（标称 > 预算集 > 盒集）

预算集的核心价值是"用 $\Gamma$ 连续调节保守度"，代码验证对等 LP 的正确性。例子：$\max\ x_1+x_2$，约束 $(2+\tilde d_1)x_1+(2+\tilde d_2)x_2\le5$，$\tilde d_j\in[0,1]$，$\Gamma=1$（至多一个系数同时取最坏）：

```python
from ortools.linear_solver import pywraplp

def solve(name, kind):
    s = pywraplp.Solver.CreateSolver("GLOP")
    x1 = s.NumVar(0, s.infinity(), "x1"); x2 = s.NumVar(0, s.infinity(), "x2")
    if kind == "nom":                      # 标称：忽略波动
        s.Add(2*x1 + 2*x2 <= 5)
    elif kind == "budget":                 # 预算集 Γ=1：鲁棒对等 LP
        z  = s.NumVar(0, s.infinity(), "z")
        p1 = s.NumVar(0, s.infinity(), "p1"); p2 = s.NumVar(0, s.infinity(), "p2")
        s.Add(2*x1 + 2*x2 + 1*z + p1 + p2 <= 5)   # Σa_j x_j + Γz + Σp_j <= b
        s.Add(z + p1 >= x1)                       # z + p_j >= d_j x_j
        s.Add(z + p2 >= x2)
    elif kind == "box":                    # 盒集：两个系数都取最坏
        s.Add(3*x1 + 3*x2 <= 5)
    s.Maximize(x1 + x2); s.Solve()
    print(f"{name}: x1={x1.solution_value():.2f} x2={x2.solution_value():.2f} obj={s.Objective().Value():.3f}")

solve("标称（忽略波动）", "nom")     # obj = 2.500
solve("预算集（Γ=1）", "budget")      # obj = 2.000
solve("盒集（两系数都最坏）", "box")  # obj = 1.667
```

输出：标称 `2.500` > 预算集 `2.000` > 盒集 `1.667`——**保守度阶梯清晰可见**。预算集解为 $(1,1)$：检查最坏情形，$\tilde d_1=1$ 时 $3\times1+2\times1=5\le5$ ✓，$\tilde d_2=1$ 时 $2\times1+3\times1=5\le5$ ✓——**任何一个系数单独取最坏都可行**；但两个同时偏离 $3+3=6>5$（预算集 $\Gamma=1$ 不承诺防护此情形，这正是与盒集的保守度差异）。若要防护双偏离，把 $\Gamma$ 提到 2 即退化为盒集。

## 不确定性建模对比

| 集合 | 定义 | 对等模型 | 保守度 | 适用 |
|:---|:---|:---|:---|:---|
| 盒集 | $\lvert\tilde a_j-\hat a_j\rvert\le\epsilon_j$ | LP（最坏系数） | 最高 | 系数独立、最坏防护 |
| 椭球集 | 二次型 $\le\Omega^2$ | SOCP | 中 | 参数相关、正态近似 |
| 预算集 | 至多 $\Gamma$ 个系数同时偏离 | LP（$z+p_j$ 辅助变量） | 可调（$\Gamma$） | 实践中常用、灵活 |
| 随机规划（[[运筹学-随机规划]]） | 概率分布 | LP/MIP（情景树） | — | 分布已知时 |

**关系**：盒集最保守但最简；椭球集用相关性换精度（付出 SOCP 代价）；预算集用参数 $\Gamma$ 连续调节保守度——三者是"集合形状 → 模型类别 → 保守程度"的连续谱。

## 常见误区

- **误区 1**：鲁棒优化 = 随机规划的特例。两者哲学不同：随机规划用分布求期望最优；鲁棒优化用集合求最坏保证。分布未知时选鲁棒。
- **误区 2**：集合越大越好。无限大集合导致可行域空或目标无穷差；集合要由"业务实际波动范围"定义。
- **误区 3**：椭球集对等还是 LP。椭球集引入二次项，对等为 SOCP；只有盒集与预算集保持 LP 结构。
- **误区 4**：把鲁棒解当"平均最优"。鲁棒解是**最坏保证**，通常劣于平均最优（本例 2.5<3.33）——为防护付费是设计意图，不是缺陷。
