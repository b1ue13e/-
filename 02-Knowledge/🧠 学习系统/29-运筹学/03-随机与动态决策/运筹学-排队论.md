# 运筹学-排队论

> 所属阶段：[[🧭 阶段3-随机与动态决策|🧭 第3阶段：随机与动态决策]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：服务系统（收银台、客服中心、生产线、急诊室）顾客随机到达、服务时间随机，要么排队等（顾客不满），要么空转（资源浪费）。**排队论**用概率模型回答：稳态下平均队列长度、等待时间、系统利用率是多少？需要几个服务台才能把等待压到目标水平？它是运筹学"服务运营"的核心工具，也是 [[运筹学-仿真与MonteCarlo]] 处理复杂排队系统的理论对照。

## 核心概念

### 1. 排队系统要素与符号（Kendall）

$A/B/c/K/N$：到达过程/服务过程/服务台数/容量/顾客源。常用：**$M/M/1$**（Poisson 到达、指数服务、单台、无限容量）、$M/M/c$、$M/G/1$。

- 到达率 $\lambda$，服务率 $\mu$；**利用率** $\rho=\lambda/\mu$（$M/M/1$ 稳态要求 $\rho<1$）。

### 2. Little 定律（万能关系）

$$L=\lambda W,\qquad L_q=\lambda W_q.$$

$L$=系统平均人数、$W$=平均逗留时间、$L_q$=队列平均长度、$W_q$=平均等待时间。**几乎对任何稳态排队系统成立**，是工程估计的首选工具。

### 3. $M/M/1$ 公式

- 系统中有 $n$ 人的概率：$p_n=(1-\rho)\rho^n$。
- $L=\dfrac{\rho}{1-\rho},\qquad L_q=\dfrac{\rho^2}{1-\rho},\qquad W=\dfrac{1}{\mu-\lambda},\qquad W_q=\dfrac{\rho}{\mu-\lambda}$.

**直觉**：$\rho\to1$ 时 $L,W$ 发散——系统"雪崩"，利用率逼近 100% 的代价是等待时间爆炸。

### 4. $M/M/c$ 与排队网络

- $M/M/c$：Erlang-C 公式（等待概率、平均等待），需查表/计算器。
- 排队网络：Jackson 网络（泊松输入 + 指数服务 + 路由矩阵，各节点独立成 $M/M/1$ 或 $M/M/c$）——生产线与服务中心的经典近似。

## 一个最小例子（手算）

客服中心：呼叫到达 $\lambda=8$ 通/小时，单客服处理 $\mu=10$ 通/小时（$M/M/1$）。

- $\rho=0.8$；$L=0.8/0.2=4$ 人在系统中；$W=4/8=0.5$ 小时 = 30 分钟逗留；$W_q=0.8/(2)=0.4$ 小时 = 24 分钟等待。
- **决策**：加一个客服成 $M/M/2$？Erlang-C 给出 $W_q$ 骤降（约几秒级）——这就是"排队模型支持容量决策"的价值。Little 定律先给出量级估计：目标 $W_q\le5$ 分钟需 $\rho$ 明显低于 0.8。

## 用模拟验证 $M/M/1$ 公式（手写事件循环）

公式给了精确值，用 numpy 模拟"到达-服务-离开"过程验证——模拟误差 ~ $1/\sqrt{N}$，接近理论值即公式正确：

```python
import numpy as np
rng = np.random.default_rng(7)
lam, mu = 8.0, 10.0                    # 到达率 8/h，服务率 10/h
N = 50_000
arrivals = np.cumsum(rng.exponential(1/lam, N))   # 指数到达间隔
service = rng.exponential(1/mu, N)                # 指数服务时长
start = np.zeros(N); depart = np.zeros(N)
for i in range(N):
    start[i] = max(arrivals[i], depart[i-1] if i > 0 else 0)   # 排队直到前一位离开
    depart[i] = start[i] + service[i]
W = (depart - arrivals).mean()         # 逗留时间
Wq = (start - arrivals).mean()         # 等待时间
print(f"模拟 L={W*lam:.2f} vs 理论 {lam/mu/(1-lam/mu):.2f}")
print(f"模拟 Wq={Wq*60:.1f}min vs 理论 {lam/mu/(mu-lam)*60:.1f}min")   # ≈24min
```

输出：`模拟 L≈3.8 vs 理论 4.0`、`模拟 Wq≈22.5min vs 理论 24min` —— 模拟与解析公式互相印证（误差来自 Monte Carlo 抽样，增大 $N$ 可减小）。**这就是 Little 定律 + $M/M/1$ 公式的落地验证**：公式算得快，模拟确认没算错。

## 排队系统选型对比

| 系统 | 到达/服务 | 公式复杂度 | 用途 |
|:---|:---|:---|:---|
| $M/M/1$ | Poisson / 指数，单台 | 闭式（$\rho/(1-\rho)$ 等） | 单服务台基础分析 |
| $M/M/c$ | Poisson / 指数，$c$ 台 | Erlang-C（等待概率、平均等待） | 呼叫中心、柜台 |
| $M/G/1$ | Poisson / 一般服务 | Pollaczek-Khinchine 公式 | 服务时间方差大的系统 |
| 排队网络 | 多节点 + 路由 | Jackson 分解 | 生产线、服务中心 |

**关系**：$M/M/1$ 是解析基石，$M/M/c$ 加服务台数，$M/G/1$ 放宽服务分布，排队网络组合多节点——复杂度递进，但 Little 定律 $L=\lambda W$ 对一切稳态系统成立，永远是最快的第一估计。

## 常见误区

- **误区 1**：利用率越高越好。$\rho=0.9$ 时 $M/M/1$ 的 $L=9$ 人——设备闲置看似浪费，排队等待才是更大成本；目标是总成本最小而非利用率最大。
- **误区 2**：Little 定律要求具体分布。不需要——它是守恒律，任何稳态系统成立；但**稳态必须存在**（$\rho<1$）。
- **误区 3**：所有排队都用 $M/M/1$。服务时间方差大（$M/G/1$）或批量到达时公式不同，先确认分布再选公式。
- **误区 4**：模拟一次就给结论。单次模拟有抽样误差，应固定种子复现并报告置信区间（增大 $N$ 或多次重跑），见 [[运筹学-仿真与MonteCarlo]]。
