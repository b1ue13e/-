# 运筹学-库存管理

> 所属阶段：[[🧭 阶段3-随机与动态决策|🧭 第3阶段：随机与动态决策]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：备货太少丢销售（缺货损失），备货太多压资金（持有成本）。需求还有波动。**库存管理**回答两个问题：**订多少**（单期：报童模型；连续补货：EOQ）与**什么时候订**（$(s,S)$ 策略、服务水平）。库存是运筹学最成熟的随机决策应用之一，也是 [[运筹学-Markov决策过程]] 与 [[运筹学-仿真与MonteCarlo]] 的直接练习场。

## 核心模型

### 1. EOQ（确定性需求，经济订货量）

需求率 $D$，每次订货固定成本 $K$，单位持有成本 $h$：
$$Q^*=\sqrt{\frac{2KD}{h}},\qquad\text{年总成本}=\sqrt{2KDh}.$$

**直觉**：订得越多，订货频次成本越低但持有成本越高，平方根公式平衡两者。

### 2. 报童模型（单期随机需求）

需求 $D\sim F$，单位售价 $p$、进价 $c$、残值 $s$。**临界比（critical fractile）**：
$$Q^*=F^{-1}\Big(\frac{p-c}{p-s}\Big).$$

**直觉**：多订一单位，卖出的边际收益 $(p-c)$ vs 卖不掉的边际损失 $(c-s)$——订货量取到"卖出概率 = 临界比"的分位数。

### 3. $(s,S)$ 策略（定期检查）

- 当库存 $x<s$ 时订到 $S$（补足量 $S-x$）；$x\ge s$ 不订。
- $s$（再订货点）由提前期需求 + 安全库存决定：$s=\mu_L+z_\alpha\sigma_L$（$z_\alpha$ 对应服务水平）。
- $(s,S)$ 是 MDP 视角下最优库存策略的结构（状态=库存，动作=订到多少）。

### 4. 服务水平

- **周期服务水平**：不缺货的概率 $P(D\le s)=\alpha$。
- **填充率（fill rate）**：需求被立即满足的比例 $=1-E[\text{缺货量}]/E[D]$。
- 服务水平越高安全库存越大（边际递减），需用成本权衡而非无限加高。

## 一个最小例子（手算）

**报童**：报纸进价 $c=0.5$、售价 $p=1.0$、残值 $s=0.1$，需求 $D\sim$ 均匀 $\{10,11,\ldots,40\}$（等概率 31 个值）。

- 临界比：$(1.0-0.5)/(1.0-0.1)=0.556$。
- $Q^*$ = 需求分布 55.6% 分位数 ≈ $10+0.556\times30\approx 26.7$ → 订 27 份。
- 检查：订 27 时，需求 ≤27 概率 $18/31=0.58>0.556$，需求 >27 概率 $13/31=0.42$。多订一份的期望边际收益 $0.5\times0.42-0.4\times0.58=-0.02<0$ ✓ 不应再订。

## 用 numpy 穷举验证 $Q^*$

手算给出临界比公式，用穷举确认它就是最优解：

```python
import numpy as np
p, c, s = 1.0, 0.5, 0.1
crit = (p - c) / (p - s)
print("临界比 =", round(crit, 3))          # 0.556

D = np.arange(10, 41)                       # 需求 31 个等概率值
best_Q, best_profit = None, -np.inf
for Q in range(10, 41):
    sold = np.minimum(D, Q)                 # 卖出的（≤ 订量）
    profit = p*sold + s*np.maximum(Q-D, 0) - c*Q   # 收入+残值-进价
    if profit.mean() > best_profit:
        best_profit, best_Q = profit.mean(), Q
print("穷举 Q* =", best_Q, "期望利润 =", round(best_profit, 3))   # 27  9.058
print("分位数 ≈", 10 + crit*30)             # 26.67 → 取 27 ✓
```

输出：临界比 $0.556$、穷举最优 $Q^*=27$、期望利润 $9.058$——与手算完全一致。**验证边际逻辑**：订 28 份期望利润 $9.035 < 9.058$，因为多订一份的期望边际收益 $(p-c)P(D>27)-(c-s)P(D\le27)=0.5\times0.42-0.4\times0.58<0$。**临界比公式 = 穷举最优，公式与枚举互相印证。**

## 库存模型选型对比

| 模型 | 需求 | 决策 | 最优解 | 适用 |
|:---|:---|:---|:---|:---|
| EOQ | 确定性恒定 | 订多少 | $Q^*=\sqrt{2KD/h}$ | 稳定消耗品补货 |
| 报童 | 单期随机 | 订多少 | 临界比分位数 $F^{-1}((p-c)/(p-s))$ | 报纸、生鲜、单季商品 |
| $(s,S)$ | 随机 + 提前期 | 何时订 + 订到多少 | 动态规划/MDP 求解 | 持续补货、定期检查 |
| 服务水平模型 | 随机 | 安全库存 | $s=\mu_L+z_\alpha\sigma_L$ | 服务承诺、缺货惩罚 |

**关系**：EOQ 是确定基准；报童是"单期随机"；$(s,S)$ 是"多期随机"（MDP 视角）；服务水平给出安全库存——四者按"不确定性程度"递进，套错模型会系统性多订或少订（见误区 1）。

## 常见误区

- **误区 1**：EOQ 用于随机需求。EOQ 假设需求确定；随机需求用报童/$(s,S)$，套错模型会系统性多订或少订。
- **误区 2**：服务水平=100%。缺货概率为 0 需要无穷安全库存；应比较"安全库存增量成本 vs 缺货损失"定服务水平。
- **误区 3**：忽略提前期。再订货点 $s$ 必须按"提前期需求"而非"当期需求"计算，否则经常断货。
- **误区 4**：报童模型把残值当 0 或忽略。$s$ 参与临界比分母，忽略残值会低估最优订货量（本例 $s=0.1$ 时 $Q^*=27$，若 $s=0$ 临界比变 $0.5$、$Q^*=25$）。
