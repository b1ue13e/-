# 运筹学-动态规划

> 所属阶段：[[🧭 阶段3-随机与动态决策|🧭 第3阶段：随机与动态决策]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：多阶段决策（分几年投资、分阶段生产、多站运输）最优解不能"每阶段各自贪心"——今天的决策影响明天的状态。**动态规划（DP）**把多阶段问题拆成递推：每阶段只回答"在当前状态下怎么选最优"，靠**最优性原理**保证局部最优拼出全局最优。它是马尔可夫决策过程（[[运筹学-Markov决策过程]]）、库存控制、项目调度的共同数学内核。

## DP 四要素与最优性原理

### 1. 四要素

| 要素 | 含义 | 示例（资源分配） |
|:---|:---|:---|
| **阶段** | 决策时刻 | 把 $K$ 单位资源分给 $n$ 个项目 |
| **状态** $s_k$ | 阶段起点携带的信息 | 剩余可分配资源 |
| **决策** $d_k$ | 本阶段选择 | 项目 $k$ 分到 $x$ 单位 |
| **递推** | $f_k(s)=\max_d\{r_k(d)+f_{k+1}(s-d)\}$ | 本期收益 + 后续最优 |

### 2. 最优性原理（Bellman）

> 无论过去状态与决策如何，剩余决策必须构成"从当前状态出发的最优策略"。

这不是显然的——它要求问题有**无后效性**（马尔可夫性）：未来只依赖当前状态，不依赖历史路径。无后效性不满足时 DP 不适用。

### 3. 价值函数与贝尔曼方程

设 $V_k(s)$ 为从阶段 $k$、状态 $s$ 出发的最优总收益，则：
$$V_k(s)=\max_{d\in D(s)}\ \bigl[r_k(s,d)+V_{k+1}(T(s,d))\bigr],\qquad V_{n+1}(\cdot)=0.$$

边界（最后阶段）向回递推，或用"向后归纳"（倒推）。**先决策后观察 vs 先观察后决策**决定 $V$ 中是期望还是 max。

## 一个最小例子（手算）

**最短路径（4 层）**：从 A 到 D，路径 A→{B1,B2}→{C1,C2,C3}→D，边权：
A→B1=3, A→B2=4；B1→C1=2, B1→C2=4, B2→C1=5, B2→C2=2, B2→C3=3；C1→D=2, C2→D=3, C3→D=4。

- 末层：$V(C1)=2,\ V(C2)=3,\ V(C3)=4$。
- 中层：$V(B1)=\min(B1\to C1+V(C1),\ B1\to C2+V(C2))=\min(2+2,\ 4+3)=4$；$V(B2)=\min(5+2,\ 2+3,\ 3+4)=5$。
- 顶层：$V(A)=\min(A\to B1+V(B1),\ A\to B2+V(B2))=\min(3+4,\ 4+5)=7$ → 最优路径 A→B1→C1→D（3+2+2=7）。

本例规模小（共 5 条路径），DP 与枚举差别不大；规模增大时 DP 计算量正比于"状态数×每状态动作数"（$O(nm)$），枚举则随路径数指数增长。**DP 用"状态"去重**是省时的关键——每个中间节点只算一次价值函数，而不是把经过它的每条路径都走一遍。

## 用代码实现倒推递推

把上面手算翻译成"状态 → 价值函数"的递推，验证每一步：

```python
V_C = {"C1": 2, "C2": 3, "C3": 4}               # 末层
B_edges = {"B1": {"C1": 2, "C2": 4},
           "B2": {"C1": 5, "C2": 2, "C3": 3}}
V_B = {b: min(w + V_C[c] for c, w in es.items()) for b, es in B_edges.items()}
print(V_B)                                       # {'B1': 4, 'B2': 5}
V_A = min(3 + V_B["B1"], 4 + V_B["B2"])
print(V_A)                                       # 7
```

输出：`{'B1': 4, 'B2': 5}`、`7` —— 与手算一致。核心模式 `min(w + V[下一状态])` 就是贝尔曼方程 $V_k(s)=\min_d\{c(s,d)+V_{k+1}(T(s,d))\}$ 的直接翻译：**每一层只算一次价值函数，靠"状态"去重避免指数枚举**。这也是 [[运筹学-Markov决策过程]] 中 $V(s)=\min_a\{c(s,a)+\sum P V(s')\}$ 的确定性特例。

## DP vs 贪心 vs 分治对比

| 方法 | 决策依据 | 需要子问题最优 | 典型失败场景 | 举例 |
|:---|:---|:---|:---|:---|
| 贪心 | 每步局部最优 | 否 | 局部最优 ≠ 全局最优 | 背包取密度最大可能次优 |
| 动态规划 | 本步 + 后续最优 | 是（最优性原理） | 无后效性不满足 | 最短路径、资源分配 |
| 分治 | 独立子问题合并 | 部分 | 子问题重叠（重复计算） | 归并排序（无重叠） |

**关系**：贪心"快但可能错"、DP"对且状态去重"、分治"独立拆分"；子问题**重叠**时用 DP（记忆化），不重叠时用分治。

## 常见误区

- **误区 1**：把"贪心"当 DP。贪心每步取局部最优；DP 比较"本步收益+后续最优"，两者结果不同（资源分配反例：局部最优组合不是全局最优）。
- **误区 2**：状态定义含过多信息。状态越多计算越重（维度灾难）；要选"影响未来决策的最小信息集"。
- **误区 3**：递推方向搞反。从末阶段倒推（或从初阶段顺推+记忆化），顺序错了价值函数无法定义。
- **误区 4**：无后效性检查缺失。若未来决策依赖"历史路径"（如累计折旧），状态必须把该历史纳入，否则最优性原理失效。
