# 运筹学-调度与项目排程

> 所属阶段：[[🧭 阶段3-随机与动态决策|🧭 第3阶段：随机与动态决策]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：机器/人手有限，多个任务抢资源——先做哪个、怎么排，直接决定完工时间与成本。**调度**回答"任务—机器—时间"的三维排布问题；**项目排程**（CPM/PERT）回答"一个项目里哪些活动并行、哪些串行、瓶颈在哪"。它们是排班系统、生产计划、项目管理的共同内核，也是 [[运筹学-约束规划与CP-SAT]] 排班建模与课程大作业（Job-Shop 排程）的直接前置。

## 核心概念

### 1. 调度问题分类（三要素 $\alpha|\beta|\gamma$）

- $\alpha$：机器环境（单机 1、平行机 P、流水车间 F、作业车间 J）。
- $\beta$：加工特征（抢占、就绪时间、顺序依赖）。
- $\gamma$：目标（$\sum C_j$ 完工和、$C_{\max}$ 最大完工时间、$\sum w_j T_j$ 加权延误）。

示例：$1||\sum C_j$ = 单机、最小化完工时间之和 → **SPT 规则**（最短加工时间优先）最优；$1||L_{\max}$ → EDD 规则（最早截止期优先）；$J3|2|C_{\max}$ = 3 作业 2 机器作业车间、最小化 makespan（NP-hard，小规模 CP-SAT）。

### 2. 经典规则速查

| 问题 | 最优规则 | 直觉 |
|:---|:---|:---|
| $1\|\|\sum C_j$ | SPT | 短活先做减少在制积压 |
| $1\|\|\sum w_j C_j$ | WSPT（$\frac{w_j}{p_j}$ 降序） | 权重/时长比优先 |
| $1\|\|L_{\max}$ | EDD | 截止期早的先做 |

### 3. CPM/PERT（关键路径法/计划评审技术）

- **网络**：节点=里程碑，弧=活动（时长 $t_{ij}$）；**关键路径** = 从起点到终点最长路径（决定项目最短工期）。
- 每个活动算 **ES/EF/LS/LF**（最早/最晚开始/完成）；**总时差** $=LS-ES$；总时差为 0 的活动在关键路径上。
- **PERT**：活动时长不确定时用三时估计 $(a,m,b)$，期望 $\approx(a+4m+b)/6$，方差 $\approx((b-a)/6)^2$，用于工期概率估计。

### 4. 滚动优化（Rolling Horizon）

大规模动态调度不一次解到底：按时间窗切段，只优化当前窗（含未来预测），窗口滚动推进。**直觉**：实时环境下信息逐步揭示，一次求解既贵又基于过时信息；滚动 = "预测 + 短视最优 + 重计划"。

## 一个最小例子（手算）

**CPM**：项目活动 A(3天)、B(2,依赖A)、C(4,依赖A)、D(2,依赖B和C)、E(3,依赖D)。

- 前向：ES(A)=0,EF(A)=3；ES(B)=3,EF(B)=5；ES(C)=3,EF(C)=7；ES(D)=max(5,7)=7,EF(D)=9；ES(E)=9,EF(E)=12。
- **项目工期 12 天**。后向：LF(E)=12；LF(D)=9；LF(B)=7,LF(C)=7；LF(A)=min(5-2,7-4)=3。
- 总时差：A 为 0、C 为 0、D 为 0、E 为 0 → **关键路径 A→C→D→E（3+4+2+3=12）**；B 时差 $7-5=2$ 天（可推迟 2 天不拖工期）。

## 用代码实现前向/后向递推

把"前向算 ES/EF、后向算 LS/LF、时差为 0 即关键"的过程写成可运行代码，验证手算：

```python
deps = {"A": [], "B": ["A"], "C": ["A"], "D": ["B", "C"], "E": ["D"]}
dur = {"A": 3, "B": 2, "C": 4, "D": 2, "E": 3}
order = ["A", "B", "C", "D", "E"]                # 拓扑序
ES = {k: 0 for k in order}; EF = {}
for k in order:                                   # 前向
    ES[k] = max((EF[d] for d in deps[k]), default=0)
    EF[k] = ES[k] + dur[k]
proj = EF["E"]
LF = {k: proj for k in order}; LS = {}
for k in reversed(order):                         # 后向
    succ = [s for s in order if k in deps[s]]
    LF[k] = min((LS[s] for s in succ), default=proj)
    LS[k] = LF[k] - dur[k]
slack = {k: LS[k] - ES[k] for k in order}
print("工期 =", proj)                              # 12
print("总时差 =", slack)                           # B 为 2，其余 0
print("关键路径 =", [k for k in order if slack[k] == 0])   # A C D E
```

输出：`工期 = 12`、`总时差 = {'A':0,'B':2,'C':0,'D':0,'E':0}`、关键路径 `A C D E`——与手算完全一致。**时差为 0 的活动组成关键路径**；B 有时差 2 天意味着推迟 B 不超过 2 天不拖项目工期——这就是"关键路径决定工期、非关键活动有松弛"的量化证据。

## 调度规则与模型对比

| 方法 | 回答的问题 | 最优性 | 适用规模 |
|:---|:---|:---|:---|
| SPT/WSPT/EDD 规则 | 单机排序 $1||\gamma$ | SPT 对 $\sum C_j$、WSPT 对 $\sum w_j C_j$、EDD 对 $L_{\max}$ 最优 | 单机、快速 |
| CPM/PERT | 项目最短工期与关键活动 | 精确（确定性）；PERT 概率估计 | 项目网络 |
| 整数规划/CP-SAT（[[运筹学-整数规划建模]]） | 通用调度 $J||C_{\max}$ | 精确但 NP-hard | 小-中规模 |
| 滚动优化 | 动态大规模调度 | 近似（窗口假设） | 实时大规模 |

**关系**：规则法快但只适用特定目标；CPM 专攻项目网络；CP-SAT 精确但规模受限；滚动优化牺牲最优换实时性——按问题规模与目标选型。

## 常见误区

- **误区 1**：工期最长的单个活动 = 关键路径。关键路径是**路径总长**最长，而非单个活动最长。
- **误区 2**：SPT 对所有目标最优。SPT 只对 $\sum C_j$（无权重）最优；有权重用 WSPT，有截止期用 EDD。
- **误区 3**：滚动优化 = 全局最优。它是有界的近似（窗口边界假设）；窗口太短会只见树木，太长计算爆炸。
- **误区 4**：CPM 里"时差 = 0"的活动只有一个。关键路径可能有多条，所有时差为 0 的活动都在关键路径上（本例 B 有时差、其余 0）。
