- **类别**：核心概念（LP 全景与算法地图）

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 现实里到处是"资源有限下做最优决策"：工厂用有限的原料、工时、机器排产，怎么利润最大？拍脑袋或穷举在变量一多时就彻底失效，且无法证明"已经最优"。因此引入：**线性规划**（统一数学模型）与**单纯形法**（在约束围成的几何体上系统搜索最优解，Dantzig 1947，至今是工业界主力）。

## 2. 为什么它重要？它有什么用？

- **连接大图景**：不学它，[[运筹学-整数规划与分支定界]]、[[运筹学-约束规划与CP-SAT]]、[[运筹学-网络流模型]]、随机规划都无法落地；它是全部 LP 类作业的前置。
- **实际应用场景**：排产调度、运输配送、投资组合；OR-Tools 的 GLOP 与所有商用求解器（CPLEX/Gurobi）的核心算法。**高频题型/任务**：建模、图解/单纯形表迭代、写对偶验证强对偶、灵敏度分析。

## 4. 用直觉语言解释它

> «"线性规划就像在一座多面体形状的斜平面上找最低点：最低点一定出现在某个棱角（顶点），绝不在面中间。单纯形法就是沿着棱从当前顶点滑到相邻更低的顶点，滑不动了就到底了。"»

- **直觉类比/几何图像**：可行域是约束平面切出的凸多面体，目标函数是倾斜平面；最优解在顶点，或整条棱/整个面平齐（无穷多最优解）。线性函数在凸多面体内部没有极值点——若内部点最优，沿任一方向移动目标值不变，可一直走到边界再推到顶点。
- **一句话直觉本质**：**最优解必在极点；单纯形法 = 沿棱在顶点间爬山的搜索；对偶 = 从价格视角逼近同一个最优值。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
**线性规划（LP）标准形**：
$$\min\ \mathbf{c}^T\mathbf{x} \quad \text{s.t.}\quad A\mathbf{x} = \mathbf{b},\quad \mathbf{x} \ge \mathbf{0}$$
任何 LP（不等式、最大化、自由变量）都可用松弛变量、取负、变量替换化为标准形。**极点**是不能表示为两个不同可行点凸组合的可行点；当 $A$ 满秩时，极点恰对应"选 $m$ 个基变量、其余取 0"的**基可行解（BFS）**。

### 2. 算法地图（细节见细分卡）
- **单纯形法**：沿棱在顶点间迭代搜索，每步是一次高斯消元——算法细节（标准形处理、检验数 $\bar{c}_j$、比值检验 $\theta$、初始基、退化与 Bland 规则、tableau 实现）全部在 [[运筹学-单纯形法]]。
- **对偶**：$\max\ \mathbf{b}^T\mathbf{y}\ \text{s.t.}\ A^T\mathbf{y} \le \mathbf{c}$；**强对偶** $p^* = d^*$；**互补松弛** $\bar{c}_j x_j = 0$——见 [[运筹学-对偶理论与影子价格]]。
- **灵敏度分析**：目标系数、右端项变化时最优基何时保持稳定——见 [[运筹学-灵敏度分析]]。

### 3. 符号说明表

| 符号 | 含义 | 取值范围 | 备注 |
| :--- | :--- | :--- | :--- |
| $\mathbf{x}$ | 决策变量 | $\mathbb{R}^n_{\ge 0}$ | 生产量等 |
| $A, \mathbf{b}, \mathbf{c}$ | 约束矩阵/右端项/目标系数 | $\mathbb{R}^{m\times n}$ | 标准形输入 |
| $p^*$ | 原问题最优值 | $\mathbb{R}$ | 对偶目标同一值 |

### 4. 常见变体与适用条件
- **变体**：两阶段法/大 M 法（找初始 BFS）；对偶单纯形法；修订单纯形法——详见 [[运筹学-单纯形法]]。**适用条件**：目标与约束全线性、变量连续；**限制**：最坏指数级（Klee-Minty），需数值容差；整数约束见 [[运筹学-整数规划与分支定界]]。

## 6. 推导思路和思想来源

- **最初困难**：二战后勤中大量"有限资源最优分配"：枚举不可行、微积分方法对不等式约束不直接；沿梯度走会撞边界，穷举全部极点（$\binom{n}{m}$ 个）爆炸。
- **关键"转念"**：**最优解必在极点**（线性函数在凸多面体上的极值），且相邻极点只差一个基变量——把连续优化变成"在极点图上沿棱走"的离散搜索，每步进基/出基就是一次高斯消元。
- **推导主线与动机**：多面体 → 极点 ⇔ BFS → 沿使目标下降的棱（$\bar{c}_j<0$）走到相邻 BFS → 走不动（$\bar{c}_j\ge0$）时由凸性证全局最优。对偶来自"给约束乘价格 $\mathbf{y}$ 相加得 $p^*$ 下界，再最大化这个下界"。
- **为什么自然得到此结论**：因为"价格/影子"与"实物/顶点"是同一枚硬币的两面，强对偶说明两者严丝合缝。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算，图解法）
- **题目**：$\max\ z = 3x_1 + 2x_2$，s.t. $x_1+x_2 \le 4,\ x_1 \le 2,\ x_2 \le 3,\ x \ge 0$。图解法求最优。
- **解题思路与关键步骤**：可行域五个顶点 $(0,0),(2,0),(2,2),(1,3),(0,3)$；等值线斜率 $-3/2$，向右上平移，最后接触的顶点即最优。
- **最终答案**：$(x_1^*,x_2^*) = (2,2)$，$z^* = 10$。
- **易错点**：平移方向弄反；若目标改成 $2x_1+2x_2$，整条棱 $(1,3)$–$(2,2)$ 都是最优（无穷多最优解）。
- **🤔 追问**：把 $x_2 \le 3$ 改成 $x_2 \le 4$，最优值变吗？——不变：该约束在最优处松弛，影子价格为 0（见 [[运筹学-对偶理论与影子价格\|影子价格]]）。

### 例子 2：对偶与强对偶（中等）
写例子 1 的对偶并验证强对偶：$\min\ 4y_1+2y_2+3y_3$ s.t. $y_1+y_2 \ge 3,\ y_1+y_3 \ge 2,\ y\ge 0$。取 $y=(2,1,0)$：可行且目标值 $4\cdot2+2\cdot1+3\cdot0=10=p^*$，由弱对偶它已最优。$y_1=2$ 即影子价格：$b_1$ 每 +1，最优值 +2。完整推导与互补松弛见 [[运筹学-对偶理论与影子价格]]。

### 例子 3：实际应用例子（OR-Tools GLOP）
- **实际价值与转化**：GLOP 内部就是修订/对偶单纯形法；用它建模并与手算解对照，验证模型正确。
- 代码形态（OR-Tools Python）：
```python
from ortools.linear_solver import pywraplp
solver = pywraplp.Solver.CreateSolver("GLOP")
x1 = solver.NumVar(0, solver.infinity(), "x1")
x2 = solver.NumVar(0, solver.infinity(), "x2")
solver.Add(x1 + x2 <= 4); solver.Add(x1 <= 2); solver.Add(x2 <= 3)
solver.Maximize(3 * x1 + 2 * x2)
solver.Solve()
print(solver.Objective().Value(), x1.solution_value(), x2.solution_value())
# 10.0 2.0 2.0
```

## 8. 常见误区和易混概念

### 误区 1：以为"LP 解取整就是答案"
- **错误直觉**：产量要整数，把 LP 解四舍五入即可；但整数约束让问题变成 NP-hard 的 [[运筹学-整数规划与分支定界]]，取整可能不可行或远非最优。
- **正确理解**：LP 解是 MIP 求解器用来剪枝的界，不是答案本身。

### 误区 2：以为"LP 与整数规划是同一回事"
- **错误直觉**：都是"在约束下优化"，只是加了个整数限制；实际上整数约束把多项式可解的 LP 变成 NP-hard，算法框架完全不同（单纯形 vs B&B/割平面）。
- **正确理解**：LP 是连续问题的黄金标准；整数规划依赖 LP 松弛提供界，但求解范式不同。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 线性规划（LP） | 连续决策最优规划 | 多项式可解，极点最优 | 资源分配、排产、运输 |
| 整数规划（MIP） | 离散决策 | NP-hard，LP 松弛给界 | 选址、背包、排班 |
| 网络流 | 图上流动优化 | LP 特例，专用算法更快 | 运输、分配、最大流 |
| 对偶问题 | 价格视角求同一最优值 | 变量是约束影子价格 | 灵敏度分析、最优性证书、B&B 的界 |

## 11. 自测题：4 道（概念全景层；算法层自测见细分卡）

| 题号 | 类型 | 难度 | 考查点 |
| :--- | :--- | :--- | :--- |
| 1 | 概念辨析 | 基础 | 为什么最优解在极点 |
| 2 | 公式运用 | 基础 | 标准形化法与极点 ⇔ BFS |
| 3 | 变式/综合 | 中等 | 写对偶并验证强对偶 |
| 4 | 开放/证明/建模 | 较难 | LP vs MIP 复杂度与算法选择 |

### 题目与解析

#### 1. 为什么 LP 的最优解一定可以在可行域的极点取得？
> [!question]- 答案解析
> - **答案**：目标线性、可行域为凸多面体；若最优解在非极点，它可写成两个不同可行点的凸组合，由线性性两点目标值相等，沿连线移到边界再推到顶点目标值不增，故存在极点最优解。
> - **解析**：这是单纯形法"只在极点搜索"的依据；若目标与某条棱平行，整条棱都是最优（无穷多解）。
> - **易错原因**：把"存在极点最优解"误记成"所有最优解都是极点"。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 把 $\max\ 3x_1+2x_2$ s.t. $x_1+x_2 \le 4,\ x_1 \le 2,\ x_2 \le 3$ 化为标准形，并指出极点 $(2,2)$ 对应的基。
> [!question]- 答案解析
> - **答案**：加松弛 $x_3,x_4,x_5$ 得 $x_1+x_2+x_3=4,\ x_1+x_4=2,\ x_2+x_5=3$；$(2,2)$ 处 $x_3=0$，基变量 $\{x_1,x_2,x_5\}$。
> - **解析**：$m=3$ 个线性无关列构成基；$(2,2)$ 满足前两个约束取等，是"选 $m$ 个基变量、其余取 0"的 BFS。

#### 3. 写出 $\min\ 3x_1+4x_2$ s.t. $x_1+x_2\ge 2,\ x_1+2x_2\ge 3,\ x\ge 0$ 的对偶并验证强对偶。
> [!question]- 答案解析
> - **答案**：对偶 $\max\ 2y_1+3y_2$ s.t. $y_1+y_2 \le 3,\ y_1+2y_2 \le 4,\ y\ge 0$；原最优 $(1,1)$，$p^*=7$；对偶最优 $(2,1)$，$d^*=7=p^*$ ✓。
> - **解析**：互补松弛自动满足（$x>0$ ⇒ 对偶约束取等）。注意 $\ge$ 约束 → $y\ge0$，$=$ 约束 → $y$ 自由。

#### 4. "LP 实践很快，为什么还要警惕最坏情况？整数规划为什么更难？" 请从算法复杂度角度回答。
> [!question]- 答案解析
> - **答案**：LP 有内点法的多项式保证，单纯形法实践极快但最坏指数（Klee-Minty）；MIP 加入整数约束后成为 NP-hard，只能依赖 B&B/割平面在中等规模上求最优。
> - **解析**：这正是"LP 松弛给界 → 分支定界剪枝"在工程上不可替代的原因——界越紧，剪枝越多。
