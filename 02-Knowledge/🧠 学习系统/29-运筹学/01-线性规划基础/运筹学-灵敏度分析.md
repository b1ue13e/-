# 运筹学-灵敏度分析

> 所属阶段：[[🧭 阶段1-线性规划基础|📊 第1阶段：线性规划基础]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：模型参数（价格、资源量、需求）总在变，重新求解成本高且不直观。经理问："原料价格涨 10% 方案还最优吗？资源多给 5 吨值多少？"**灵敏度分析**回答：参数在什么区间内变化**最优基不变**（解结构稳定），超出区间后如何变化。它是把静态最优解变成"决策稳健性"认识的第一站，也是 [[运筹学-鲁棒优化]] 的动机来源。

## 三类典型变化

### 1. 目标系数变化 $c_j \to c_j + \delta$

- 最优基不变条件（对非基变量 $j$）：
$$\bar{c}_j' = \bar{c}_j - \delta \ge 0 \ \Rightarrow\ \delta \le \bar{c}_j$$
  即非基变量系数最多增加 $\bar{c}_j$（检验数）不改变最优解。
- 对基变量 $x_k$：变化会波及所有检验数 $\bar{c}_j' = \bar{c}_j - \delta\,(B^{-1}A_k)$ 中的对应分量，需逐个检查非负。区间由"所有 $\bar{c}_j'\ge0$"共同界定。

### 2. 右端项变化 $\mathbf{b}\to\mathbf{b}+\Delta\mathbf{b}$

- 最优基不变条件：$\mathbf{x}_B' = B^{-1}(\mathbf{b}+\Delta\mathbf{b}) \ge 0$。
- 单个 $b_i$ 的保持区间：$\Delta b_i$ 使得每个基变量分量 $x_k' \ge0$ 的交集。
- 区间内最优值变化率 = 影子价格 $y_i^*$（见 [[运筹学-对偶理论与影子价格]]）；超出区间需重新求解或对偶单纯形。

### 3. 新增约束 / 新增变量

- 新约束：检查当前最优解是否满足；不满足则加入并用对偶单纯形恢复最优。
- 新变量：检验数 $\bar{c}_j' = c_j - \mathbf{c}_B^T B^{-1}A_j \ge 0$ 则保持最优，否则进基。

## 100% 规则（多参数同时变化）

多系数同时变化时，精确区间失效。实用规则：对每个变化计算"实际变化 / 允许变化"比值，**若比值之和 ≤ 100% 则最优基不变**（充分条件，非必要条件）。

## 一个最小例子（手算）

原问题（沿用对偶卡）：$\max\ 3x_1+2x_2$ s.t. $x_1+x_2\le4,\ x_1\le2,\ x_2\le3,\ x\ge0$，最优 $(2,2)$，$z=10$，基变量 $\{x_1,x_2\}$，影子价格 $y=(2,1,0)$。

1. **$c_1$ 区间**（基变量）：$c_1$ 从 3 变到 $3+\delta$。最优表给出 $z=(3+\delta)(2-x_4)+2(2-x_3+x_4)=10+2\delta-2x_3-(1+\delta)x_4$，非基变量 $x_3,x_4$ 的检验数需满足 $-2\le0$、$-(1+\delta)\le0$ → $\delta\ge-1$，即 **$c_1\in[2,\infty)$** 时最优基不变（$c_1<2$ 时最优解沿 $x_1+x_2=4$ 滑向 $(0,3)$；$c_1\ge2$ 时梯度偏向 $x_1$，顶点 $(2,2)$ 保持最优；$c_1=2$ 时整条边 $(1,3)$–$(2,2)$ 均为最优）。
2. **$b_3$ 区间**（右端项）：$x_2\le3$ 是松弛约束（$y_3=0$），$b_3$ 变化不影响最优基，直到 $b_3$ 小到约束变紧——$x_2^*=2$，故 $b_3\ge2$ 时基不变。
3. **$b_1$ 区间**：$b_1=4$，影子价格 $y_1=2$；$b_1$ 每 +1 最优值 +2。基解 $x_1=2,\ x_2=b_1-2$，需 $x_2\ge0\Rightarrow b_1\ge2$ 且 $x_2\le3\Rightarrow b_1\le5$，故 **$b_1\in[2,5]$** 时最优基不变；超出区间（$b_1>5$）约束 $x_2\le3$ 变紧，需要重新求解。

## 用 scipy 数值验证区间（参数扫描）

pywraplp 未暴露灵敏度 API，用 `scipy.optimize.linprog` 对 $c_1$、$b_1$ 扫描，观察最优解何时换基：

```python
import numpy as np
from scipy.optimize import linprog

def solve(c1=3.0, b1=4.0):
    c = np.array([-c1, -2.0])                    # max → min 取负
    A = np.array([[1., 1.], [1., 0.], [0., 1.]])
    b = np.array([b1, 2., 3.])
    r = linprog(c, A_ub=A, b_ub=b, bounds=[(0, None)] * 2, method="highs")
    return r.x, -r.fun

for c1 in [1.9, 2.0, 3.0, 5.0]:                 # c1 扫描
    x, z = solve(c1=c1); print(f"c1={c1}: x=({x[0]:.2f},{x[1]:.2f}) z={z:.2f}")
for b1 in [1.9, 2.0, 4.0, 5.0, 5.1]:            # b1 扫描
    x, z = solve(b1=b1); print(f"b1={b1}: x=({x[0]:.2f},{x[1]:.2f}) z={z:.2f}")
```

输出观察：
- `c1=1.9` 时解跳到 $(1,3)$（换基）→ 印证区间 $c_1\in[2,\infty)$；
- `c1=3.0/5.0` 解保持 $(2,2)$ → 区间内基不变；
- `b1=1.9` 解变 $(1.9,0)$、`b1=5.1` 解变 $(2,3)$（换基）→ 印证区间 $b_1\in[2,5]$。

**结论**：区间端点正是换基的临界点，与检验数/基解不等式推导完全吻合——手算给出区间，代码负责复核。

## 灵敏度分析相关概念对比

| 概念 | 回答的问题 | 方法 | 与灵敏度的关系 |
|:---|:---|:---|:---|
| 灵敏度分析 | 参数小变，最优解/基变不变 | 检验数/基解区间 | 本卡主题 |
| 100% 规则 | 多参数同时变是否保基 | 比值和 ≤ 100% | 灵敏度的多参数推广 |
| 鲁棒优化（[[运筹学-鲁棒优化]]） | 参数在**整个不确定集**内最坏情形的稳健解 | 对等模型、保守性权衡 | 灵敏度把"参数变化"升级为"对抗最坏" |
| 参数规划 | 参数连续变化时最优值的函数 | 扫参、解析式 | 灵敏度的全域延伸 |

**关系**：灵敏度回答"哪个区间内答案不变"；100% 规则处理多个参数联动；鲁棒优化干脆不假设区间，直接求最坏情形最优——三者是"不确定性"问题由浅入深的三个层次。

## 常见误区

- **误区 1**：灵敏度区间 = 最优值不变区间。**错**——区间保证的是**最优基不变**，最优值通常随参数连续变化。
- **误区 2**：多个参数同时超区间就必然换基。100% 规则只是充分条件，可能仍保持最优。
- **误区 3**：忽略"基变量与非基变量系数"的处理差异。目标系数变化要区分 $x_j$ 是基变量还是非基变量，公式不同。
- **误区 4**：把影子价格外推到区间外。$y_i^*$ 只在最优基不变区间内等于边际值，区间外需重新求解（见对偶卡误区 2）。

## 最小自测

- [#自测题/基础] 解释为什么 $y_i^*$ 就是 $b_i$ 变化时最优值的变化率。
- [#自测题/基础] 对非基变量 $j$，写出系数变化不换基的检验数条件。
- [#自测题/中等] 用 100% 规则判断：$b_1$ 变化 30%、$c_2$ 变化 40%（各自允许 40%、60%）是否保证最优基不变。
- [#自测题/中等] 用上面的 scipy 代码扫描 $c_2$，找到它的保持区间并与手算对比。
- [#自测题/较难] 解释：为什么 $c_1=2$ 时最优解不唯一（整条边最优）？用互补松弛条件分析这是否影响对偶唯一性。
