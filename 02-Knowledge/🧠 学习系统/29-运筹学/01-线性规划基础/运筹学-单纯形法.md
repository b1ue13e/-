# 运筹学-单纯形法

> 所属阶段：[[🧭 阶段1-线性规划基础|📊 第1阶段：线性规划基础]]

## 这个知识点解决什么问题？

**我们遇到的麻烦**：已知最优解在极点，但极点有 $\binom{n}{m}$ 个（指数级），穷举不可行。单纯形法给出"从一个极点沿棱走到相邻更好极点"的**系统迭代规则**——每次迭代只是一次高斯消元（[[运筹学-前置-线性代数最小集]]），实践极快，是 GLOP、CPLEX、Gurobi 的 LP 内核。本卡展开算法细节：标准形、初始基、检验数与比值检验、退化。

## 标准形与基可行解

### 1. 标准形与松弛变量

$$\min\ \mathbf{c}^T\mathbf{x}\quad \text{s.t.}\quad A\mathbf{x}=\mathbf{b},\ \mathbf{x}\ge\mathbf{0},\ A\in\mathbb{R}^{m\times n},\ m<n$$

把不等式加松弛变量变等式；最大化取负转最小化。

### 2. 基可行解（BFS）

选 $m$ 个线性无关列构成**基矩阵** $B$（对应基变量 $\mathbf{x}_B$），其余为非基变量 $x_N=0$。解 $B\mathbf{x}_B=\mathbf{b}$ 得 $\mathbf{x}_B=B^{-1}\mathbf{b}$；若 $B^{-1}\mathbf{b}\ge0$ 则得到一个 BFS。**极点 ⇔ BFS**（几何与代数的同一对象）。

## 迭代规则（最小化）

### 1. 检验数

对每个非基变量 $j$：
$$\bar{c}_j = c_j - \mathbf{c}_B^T B^{-1}A_j$$

$\bar{c}_j<0$ 表示 $x_j$ 每增加 1 单位目标下降 $\lvert\bar{c}_j\rvert$ → **进基**（选最负的，Dantzig 规则；或 Bland 最小下标规则防循环）。

### 2. 比值检验（确定出基变量）

$$\theta = \min_{i:\ (B^{-1}A_j)_i>0}\ \frac{(B^{-1}\mathbf{b})_i}{(B^{-1}A_j)_i}$$

$\theta$ 是沿 $x_j$ 方向的最大可行步长；达到 $\theta$ 的那行对应的基变量出基。

### 3. 最优性条件

所有 $\bar{c}_j\ge0$ 时当前 BFS 最优（凸性保证全局）。

### 4. 迭代流程总览

```mermaid
flowchart TD
    A[化为标准形，找初始 BFS<br/>两阶段法 / 大M法] --> B{存在检验数 c̄_j < 0 ?}
    B -- 否 --> F[当前 BFS 最优]
    B -- 是 --> C[选进基变量 j<br/>Dantzig: 最负检验数]
    C --> D[比值检验求 θ<br/>θ = min (B⁻¹b)_i / (B⁻¹A_j)_i]
    D --> E[出基变量 k，高斯消元<br/>更新基 B 与单纯形表]
    E --> B
    F --> G[退化时用 Bland 规则防循环]
```

## 两个必须解决的问题

### 1. 初始基：两阶段法 / 大 M 法

标准形通常没有现成单位矩阵。**两阶段法**：加入工变量 $x^a$ 构造辅助问题 $\min\sum x^a$，第一阶段把 $\sum x^a$ 最小化到 0（原问题可行）得到初始 BFS；**大 M 法**：目标加 $M\sum x^a$（$M$ 充分大）一次性处理。两法等价，两阶段法数值更稳。

### 2. 退化与循环

**退化**：某基变量取 0（多个约束在极点重合）。退化时目标值可能连续多轮不降，若进基/出基选择不当会**循环**（无限迭代）。**Bland 规则**（按最小下标选择进基/出基）保证有限终止。

## 一个最小例子（手算）

$\min\ -3x_1-2x_2$ s.t. $x_1+x_2\le4,\ x_1\le2,\ x_2\le3,\ x\ge0$（等价于 $\max\ 3x_1+2x_2$，最优 $(2,2)$，$z=10$）。

1. **加松弛**：$x_1+x_2+x_3=4,\ x_1+x_4=2,\ x_2+x_5=3$，初始基 $\{x_3,x_4,x_5\}$，$\mathbf{x}_B=(4,2,3)^T$。
2. **迭代 1**：$\bar{c}_1=-3$（最负）→ $x_1$ 进基；比值检验：$4/1=4,\ 2/1=2,\ 3/0=\infty$ → $\theta=2$，$x_4$ 出基。消元后 $\mathbf{x}_B=(2,2,3)$，$x_1=2$。
3. **迭代 2**：$\bar{c}_2=-2$ → $x_2$ 进基；比值：$2/1=2,\ 3/1=3$ → $\theta=2$，$x_3$ 出基。消元后 $x_2=2$，$\mathbf{x}_B=(2,2,1)$。
4. **检查**：全部 $\bar{c}\ge0$ → 最优 $(x_1,x_2)=(2,2)$，$z=10$。GLOP 验证一致。

## 常见误区

- **误区 1**：比值检验对 $(B^{-1}A_j)_i=0$ 或 $<0$ 的分量也做比值。**错误**——只有正值分量限制步长，否则会出界。
- **误区 2**：$\bar{c}_j\ge0$ 就停，忽略退化下"最优"的判断。退化时 $\bar{c}$ 可能为 0 但还有更优解？不会——$\bar{c}_j\ge0$ 是最优性充分条件（最小化）。
- **误区 3**：认为单纯形法是多项式算法。最坏指数（Klee-Minty），实践极快；多项式保证来自内点法。
