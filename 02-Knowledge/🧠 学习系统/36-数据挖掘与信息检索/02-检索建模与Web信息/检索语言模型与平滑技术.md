## 💡 动机与直觉

在经典向量空间模型（Vector Space Model）和 BM25 之后，信息检索从概率论视角引入了**语言模型（Language Models for IR）**。

- **核心假设（Query Likelihood Model）**：为每个文档 $D$ 估计一个词频分布概率模型 $M_D$。当用户输入查询 $Q = (q_1, q_2, \dots, q_k)$ 时，计算该文档模型生成查询 $Q$ 的先验概率 $P(Q | M_D)$。文档按 $P(Q | M_D)$ 由大到小排序。
- **零概率陷阱（Zero-Probability Problem）**：若查询词 $q_i$ 未在文档 $D$ 中出现，则 $P(q_i | M_D) = 0$，导致整个乘积 $P(Q | M_D) = \prod P(q_i | M_D) = 0$。
- **平滑（Smoothing）的作用**：将背景语料库（Collection $C$）的概率分布引入文档语言模型中，既消除了零概率零得分问题，又自然实现了类似 IDF 的逆文档频率惩罚效果！

## 📐 数学推导与估计

假设查询词独立（Unigram Language Model）：
$$P(Q | M_D) = \prod_{i=1}^{|Q|} P(q_i | M_D)$$

取对数可得对数似然排序得分：
$$\text{Score}(Q, D) = \sum_{i=1}^{|Q|} \log P(q_i | M_D)$$

### 1. Jelinek-Mercer (JM) 线性插值平滑
将文档极大似然估计 $P_{\text{ml}}(t | D) = \frac{\text{tf}(t, D)}{|D|}$ 与全集背景模型 $P(t | C) = \frac{\text{cf}(t)}{|C|}$ 进行线性混合（$\lambda \in (0, 1)$）：

$$P_{\text{JM}}(t | M_D) = (1 - \lambda) \frac{\text{tf}(t, D)}{|D|} + \lambda P(t | C)$$

- **适用场景**：适合短查询（Short Queries），通常取 $\lambda \approx 0.1 \sim 0.7$。

### 2. Dirichlet 先验平滑 (Dirichlet Smoothing)
将文档模型看作多项分布，使用 Dirichlet 分布作为共轭先验（伪计数参数为 $\mu$）：

$$P_{\text{Dir}}(t | M_D) = \frac{\text{tf}(t, D) + \mu P(t | C)}{|D| + \mu}$$

改写为线性插值形式：
$$P_{\text{Dir}}(t | M_D) = \frac{|D|}{|D| + \mu} P_{\text{ml}}(t | D) + \left(1 - \frac{|D|}{|D| + \mu}\right) P(t | C)$$

- **物理含义**：参数 $\mu$ 代表伪文档长度。当文档极短（$|D| \ll \mu$）时，主要依靠背景词频平滑；当文档极长（$|D| \gg \mu$）时，主要依靠文档自身的词频估计。
- **适用场景**：适合长查询与长文档，通常取 $\mu \approx 2000$。

## 💻 最小 Python 实现

```python
import math
from collections import Counter
from typing import List, Dict

class LanguageModelIR:
    def __init__(self, corpus: Dict[str, str]):
        self.docs = corpus
        self.doc_tokens = {doc_id: text.lower().split() for doc_id, text in corpus.items()}
        self.doc_lens = {doc_id: len(tokens) for doc_id, tokens in self.doc_tokens.items()}

        # 背景语料库统计
        self.collection_counter = Counter()
        self.total_collection_tokens = 0
        for tokens in self.doc_tokens.values():
            self.collection_counter.update(tokens)
            self.total_collection_tokens += len(tokens)

    def p_collection(self, term: str) -> float:
        cf = self.collection_counter[term]
        return cf / self.total_collection_tokens if self.total_collection_tokens > 0 else 1e-9

    def score_dirichlet(self, query: List[str], doc_id: str, mu: float = 2000.0) -> float:
        tokens = self.doc_tokens[doc_id]
        tf_map = Counter(tokens)
        doc_len = self.doc_lens[doc_id]

        score = 0.0
        for q in query:
            q = q.lower()
            p_c = self.p_collection(q)
            tf = tf_map[q]
            p_t_d = (tf + mu * p_c) / (doc_len + mu)
            score += math.log(p_t_d)
        return score

# 测试样例
if __name__ == "__main__":
    corpus = {
        "d1": "information retrieval and data mining algorithms",
        "d2": "data mining patterns and association rules",
        "d3": "search engine indexing and language models"
    }
    lm = LanguageModelIR(corpus)
    query = ["data", "mining"]
    scores = {doc_id: lm.score_dirichlet(query, doc_id, mu=10.0) for doc_id in corpus}
    sorted_docs = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    print("Dirichlet 平滑排序结果:", sorted_docs)
```

## ⚠️ 常见误区与避坑指南

1. **误区：平滑只是为了避免除零或乘零**
   - 避坑：平滑不仅解决了未登录词问题，更赋予了背景高频词（如 "the", "is"）较小的权重、罕见词较大的权重，在数学上等价于实现了 IDF 权重的自动调节。

## 🃏 Anki 卡片

**Q: Dirichlet 平滑估计公式是什么？伪计数参数 $\mu$ 的作用是什么？**
**A**:
- **公式**：$P_{\text{Dir}}(t | M_D) = \frac{\text{tf}(t, D) + \mu P(t | C)}{|D| + \mu}$。
- **$\mu$ 作用**：作为先验伪文档长度。调节文档自身词频与背景词频的融合比例。长文档受 $\mu$ 影响小，短文档受 $\mu$ 影响大。
