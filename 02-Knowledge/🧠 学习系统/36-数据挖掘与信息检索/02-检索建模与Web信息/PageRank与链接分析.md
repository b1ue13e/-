# Web检索与PageRank

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：[[🧭 开源作业体系-数据挖掘与信息检索]] 的 HW06 拓展项（IIR 第 21 章）；PageRank 是"链接即投票"思想的鼻祖，理解它才能读懂现代 Web 排序（与 BM25 混合、LTR 特征）与图算法；也是面试"Google 三驾马车"必问题。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：Web 语料和普通文档库有本质区别：**规模巨大**（几十亿页）、**质量参差**（垃圾站、内容农场）、**查询歧义严重**（"apple"）。纯内容打分（[[BM25与TF-IDF|BM25]]）只数"词出现几次"——垃圾站堆砌关键词就能刷排名；而且 BM25 是**查询相关**的，无法回答"这篇文档本身权威吗"。以前的方法卡在：**内容信号回答不了"权威性"**。因此引入**超链接分析**：把网页间的链接当作"投票"——被高质量页面链接的页面更可信。**PageRank** 把链接投票建模成**随机游走**的平稳分布，用**幂迭代**高效求解；**HITS** 则区分**枢纽（hub）**与**权威（authority）**两类页面；最终与 BM25 混合得到 Web 排序分。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW06 的拓展模块；PageRank 是"图上传播"思想的起点（连接知识图谱、社交网络）；Web 排序 = 查询相关（BM25）× 全局权威（PageRank）的经典分解。
- **实际应用场景**：搜索引擎排序（Google 原始核心）、反垃圾（TrustRank）、推荐（Personalized PageRank）、网络科学中心性度量。**高频题型/任务**：手算一步幂迭代；解释 $d$ 与蛛网陷阱；对比 PageRank 与 HITS；设计 BM25×PageRank 混合并评估。

---

## 3. 学它之前需要哪些前置知识？

1. **马尔可夫链与随机游走**：转移矩阵、平稳分布、收敛条件——PageRank 就是"随机冲浪者"的马尔可夫链。
2. **线性代数（矩阵与特征向量）**：$r = Mr$ 的 Perron-Frobenius 理论背景；幂迭代是主特征向量的数值解法。
3. **[[BM25与TF-IDF]]**：内容打分是混合排序的另一半；Web 排序的评估沿用 nDCG/MRR。

---

## 4. 用直觉语言解释它

> «"PageRank 像'学术引用声望'：一篇论文被越多好论文引用，它越权威；而被权威论文引用的论文，它的'票'更值钱——这是递归的声望。实现上想象一个'随机冲浪者'：从任意网页出发，80% 的时间点链接跳走，20% 的时间无聊了随便输入网址跳到任意页；他长期停留在每页的时间比例就是 PageRank。HITS 则把页面分成两类：'目录页'（hub，指向很多好页面）和'内容页'（authority，被很多目录页指向）。"»
- **直觉类比/几何图像**：PageRank = 图上的"热扩散"：重要性沿出链流向下游，阻尼因子 $d$ 是"热度流失/随机注入"；幂迭代 = 反复让热度沿边流动直到稳定。
- **为什么很自然**：链接是用户手工"投票"，比内容更抗刷（刷链接比堆关键词难）；"被重要者引用的更重要的递归"正是声望系统的自然定义。
- **一句话直觉本质**：**把网页图当马尔可夫链，随机游走的平稳分布就是权威分数（PageRank，幂迭代求解）；再按"枢纽-权威"二分细化（HITS）；最后与 BM25 内容分混合成 Web 排序。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **PageRank**：随机冲浪者模型的平稳分布——$PR(p)$ 是长期停留在页面 $p$ 的概率；递归定义"页面分数 = 入链来源分数之和/出链数"，用阻尼因子 $d$ 保证唯一性与收敛性。
- **幂迭代**：从均匀分布出发反复执行 $r^{(t+1)} = dMr^{(t)}+(1-d)/N$ 直到 $\|r^{(t+1)}-r^{(t)}\|$ 小于阈值；$d<1$ 时保证收敛到唯一解。
- **HITS**：两类分数——authority（被好 hub 指向）与 hub（指向好 authority），交替更新并归一化。
- **Web 排序混合**：$score(q,d)=\lambda\cdot\text{BM25}(q,d)+(1-\lambda)\cdot PR(d)$（各自归一化）。

### 2. 核心公式
**PageRank（递归式与矩阵式）**：
$$PR(p)=\frac{1-d}{N}+d\sum_{q\in B_p}\frac{PR(q)}{L(q)},\qquad r^{(t+1)}=d\,M\,r^{(t)}+\frac{1-d}{N}\,\mathbf{1}$$
**HITS（交替更新）**：
$$a_i=\sum_{j\to i}h_j,\qquad h_i=\sum_{i\to j}a_j,\qquad \text{每步归一化}$$
**混合排序**：
$$\mathrm{score}(q,d)=\lambda\,\mathrm{BM25}(q,d)+(1-\lambda)\,PR(d)$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $B_p$ | 链入 $p$ 的页面集合 | 集合 | 入链 |
| $L(q)$ | 页面 $q$ 的出链数 | $\ge1$ | 平分 $PR(q)$ |
| $d$ | 阻尼因子 | $[0,1)$，经典 0.85 | 防蛛网陷阱、保收敛 |
| $M$ | 归一化链接矩阵 | 随机矩阵 | $M_{ij}=1/L(j)$ |
| $N$ | 网页总数 | 正整数 | 均匀项 $(1-d)/N$ |
| $a_i, h_i$ | authority / hub 分 | $\ge0$ | HITS 两类分数 |
| $\lambda$ | 混合权重 | $[0,1]$ | 内容 vs 权威 |

### 4. 常见变体与适用条件
- **变体**：Personalized PageRank（偏好向量替代均匀项）、Topic-Sensitive PageRank、TrustRank（反垃圾）；HITS 收敛性不如 PageRank（无阻尼，可能不收敛）。**适用/限制**：PR 是查询无关的全局分（离线算、在线查表）；HITS 需在线对查询子图迭代（贵）；悬空节点会"吸走"分数需处理；混合权重 $\lambda$ 需验证集调。

## 6. 推导思路和思想来源

- **最初困难**：内容打分被关键词堆砌攻击；"权威性"是全局属性，单篇文档内部信号无法回答。**直接方法局限**：简单入链计数可被链接农场刷；人工白名单不可扩展。
- **关键"转念"**：① **递归投票**：票的权重由投票者自身的 PageRank 决定——"被重要者引用更重要"；② **随机游走视角**：把递归定义翻译成马尔可夫链的平稳分布，数学上就是主特征向量（Perron-Frobenius）；③ **阻尼因子** $d$：既模拟"随机跳转"的真实冲浪行为，又保证矩阵不可约非周期 → 唯一平稳分布、幂迭代收敛。
- **推导主线与动机**：链接图 → 归一化转移矩阵 $M$ → 加均匀跳转（$d$ 混合）→ 求平稳分布 $r$（特征值 1 的特征向量）→ 幂迭代（反复 $r\leftarrow dMr+(1-d)/N$）→ 收敛即 PageRank。HITS 走另一条路：hub-authority 二分 + 交替归一化。
- **为什么自然得到此结论**：因为"声望的递归定义"与"马尔可夫链平稳分布"是同一个数学对象；而幂迭代是求解主特征向量最朴素可靠的数值方法。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：3 页图：A→B、A→C、B→C、C→A（即 A 出链 2，B、C 各 1）。$d=0.85$，从均匀 $r^{(0)}=(1/3,1/3,1/3)$ 出发，求 $r^{(1)}$。
- **解题思路与关键步骤**：$L(A)=2,L(B)=1,L(C)=1$；$r^{(1)}_A=0.05+0.85\cdot r^{(0)}_C/1\approx0.333$，$r^{(1)}_B=0.05+0.85\cdot r^{(0)}_A/2\approx0.192$，$r^{(1)}_C=0.05+0.85\cdot(r^{(0)}_A/2+r^{(0)}_B)=0.475$。**最终答案**：$r^{(1)}=(0.333,0.192,0.475)$——C 被 A、B 共同指向得分最高。**易错点**：把"入链数"当得分（没除来源页出链数）；忘加均匀项 $(1-d)/N$。
- **🤔 追问**：若 $d=0$？——$r^{(1)}=(1/3,1/3,1/3)$，所有页面平分，链接信息完全丢失；$d$ 越大链接结构影响越大，但 $d=1$ 时图若不满足遍历条件可能不收敛。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：图 A→B、B→C、A→C。用 HITS 迭代一轮（初始 $h=(1,1,1)$），判断谁是 hub、谁是 authority；再对比 PageRank 会给出什么结论。
- **解题思路与完整解答**：authority 更新：$a_A=0,\ a_B=h_A=1,\ a_C=h_A+h_B=2$ → 归一化 $(0,1/3,2/3)$；hub 更新：$h_A=a_B+a_C=1,\ h_B=a_C=2/3,\ h_C=0$ → 归一化 $(3/5,2/5,0)$。**结论**：C 是 authority（被 A、B 指向），A 是 hub（指向两个权威）。**关键推理**：PageRank 视角 C 也最高（结论一致），但 HITS 额外给出"A 是好目录页"的结构信息，适合查询子图（主题内谁是权威站/导航站）。**易错点**：把 hub 与 authority 混为一谈；HITS 每步必须归一化否则发散。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW06 拓展 = 用 NetworkX 在小型 Web 图上实现 PageRank 与 HITS，与 BM25 混合后在 TREC Web 类数据集（如 gov2 子集）上报告 nDCG@10 对比纯 BM25。代码形态：
```python
import networkx as nx
G = nx.DiGraph()
G.add_edges_from([("A", "B"), ("A", "C"), ("B", "C"), ("C", "A")])
pr = nx.pagerank(G, alpha=0.85)          # 幂迭代封装
hubs, auths = nx.hits(G)                 # HITS 交替迭代
# 混合排序：score = lam * bm25_norm(q, d) + (1 - lam) * pr_norm(d)
# lam 在验证集扫描（如 0.5-0.9），评估用 trec_eval 的 ndcg_cut.10
```
- **实际价值与转化**：`nx.pagerank` 默认即幂迭代（`tol=1e-06` 停）；自实现版需自己处理悬空节点（无出链页面把分数均分或删去）；混合排序时 BM25 与 PR 量纲不同，必须先各自归一化再加权——HW06 报告中"λ 消融"是标准验收项。

## 8. 常见误区和易混概念

### 误区 1：PageRank 是查询相关的排序分
- **错误直觉**：PageRank 分高 = 搜什么都排前面。
- **为什么错**：PageRank 只依赖**链接结构**，与查询词完全无关——"权威"是全局属性；实际搜索排序是"查询相关（BM25）× 全局权威（PR）"的混合。**正确理解**：PR 是离线算好的先验，BM25 是查询相关的证据，两者互补；只有混合后才可作检索排序。

### 误区 2：入链越多 PageRank 越高
- **错误直觉**：数入链数就行，PageRank 就是入链计数。
- **为什么错**：PageRank 是**递归加权**——来自高 PR 页的票更值钱，且票被出链数均分；100 个低质链接农场的入链可能不如 1 个权威页的入链。**正确理解**：$\frac{PR(q)}{L(q)}$ 才是投票权重，这正是 PageRank 抗链接农场的原因。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| PageRank | 全局权威 | 随机游走平稳分布，查询无关 | 预计算 + 混合排序 |
| HITS | 枢纽/权威二分 | 查询子图在线迭代，可能不收敛 | 主题内导航/权威站识别 |
| BM25 | 内容相关 | 词项统计，无结构信息 | 内容打分（[[BM25与TF-IDF]]） |
| TrustRank | 反垃圾 | 从可信种子反向传播 | 垃圾站降权 |

### 题目与解析

#### 1. 一句话说清 PageRank 与 HITS 在"衡量什么"上的区别。
> [!question]- 答案解析
> - **答案**：PageRank 衡量**全局权威**（随机游走平稳分布，单一分数，查询无关）；HITS 衡量**查询子图内的枢纽-权威二分**（两类分数 $h_i, a_i$，互为递归定义）。
> - **解析**：PageRank 离线算一次全图复用；HITS 对每个查询在子图上在线迭代（成本高、无阻尼可能不收敛）。应用上 PageRank 适合"谁是权威站"，HITS 适合"这个主题下谁是导航站/内容站"。
> - **易错原因**：把 HITS 的 authority 当"查询无关"；两者不是同一分数的两种算法，而是两种建模。
> - **对应误区**：误区 1（PR 查询相关论）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 3 页图：A→B、A→C、B→C、C→A，$d=0.85$，$r^{(0)}=(1/3,1/3,1/3)$，求 $r^{(1)}$ 各分量并指出谁领先。
> [!question]- 答案解析
> - **答案**：$r^{(1)}_A=0.05+0.85\times(r^{(0)}_C/1)=0.333$；$r^{(1)}_B=0.05+0.85\times(r^{(0)}_A/2)=0.192$；$r^{(1)}_C=0.05+0.85\times(r^{(0)}_A/2+r^{(0)}_B/1)=0.475$。C 领先。
> - **解析**：C 被 A、B 同时指向且来源页出链少（B 只有 1 条出链，票全给 C）；注意 A 的 0.85/3 来自"被 C 指向"，A 自己的两条出链各贡献 0.1417 给 B 和 C。**易错原因**：入链计数替代加权；忘记除以来源页出链数 $L(q)$。

#### 3. 什么是蛛网陷阱与悬空节点？阻尼因子 $d$ 如何同时解决这两个问题？
> [!question]- 答案解析
> - **答案**：蛛网陷阱 = 一组页面只互相链接、无出链到外部，随机游走会被困住吸走全部分数；悬空节点 = 无出链页面，概率"漏掉"。$d<1$ 时每次跳转都有 $(1-d)$ 概率随机跳到任意页——陷阱组无法垄断（分数以 $1-d$ 比例漏出），悬空节点的概率也不至于归零；数学上 $d<1$ 保证转移矩阵不可约、非周期，幂迭代收敛到唯一解。
> - **解析**：经典 $d=0.85$ 意味着约每 6-7 步就随机跳一次；工程上悬空节点另做处理（删边或均分），但阻尼已从理论上保证唯一性。**易错原因**：以为 $d$ 只是"调权重的超参"——它是收敛性与抗陷阱的理论保证。

#### 4. 设计 BM25×PageRank 混合排序：写出公式、指出两个工程要点、说明 λ 怎么定。
> [!question]- 答案解析
> - **答案**：$\mathrm{score}(q,d)=\lambda\cdot\mathrm{BM25}_{norm}(q,d)+(1-\lambda)\cdot PR_{norm}(d)$。要点：① 两分量量纲不同，必须各自归一化（如 min-max 或除以最大值）再加权；② PR 是查询无关的，同一文档对每个查询的 PR 项相同——可离线预计算缓存。λ 在验证集（如 TREC 查询集）上扫描（常见 0.5-0.9），以 nDCG@10 选最优并做消融报告。
> - **解析**：λ=1 退化为纯 BM25（基线）；λ=0 退化为"权威排序"（查询无关，不可用）；混合的价值在于"相关性与权威性互补"——垃圾站 BM25 高但 PR 低。
> - **易错原因**：不归一化直接加权（BM25 数值量级远大于 PR，λ 形同虚设）；用训练集查询选 λ 造成过拟合。

#### 5. 论证幂迭代 $r^{(t+1)}=dMr^{(t)}+(1-d)/N$ 为什么收敛到唯一解；并设计一个验证 PageRank 正确性的小实验。
> [!question]- 答案解析
> - **答案**：$d<1$ 时映射 $f(r)=dMr+(1-d)/N$ 是**压缩映射**：$\|f(r)-f(r')\|=\|dM(r-r')\|\le d\|r-r'\|$（M 是随机矩阵，$\|M\|_\infty=1$），压缩系数 $d<1$，由 Banach 不动点定理存在唯一不动点且迭代指数收敛。实验：构造已知解的图（如 3 节点例），用 NetworkX `pagerank` 与自实现幂迭代对拍（误差 < 1e-6）；再注入"链接农场"（互链环）验证其 PR 不暴涨（对比入链计数法），并用 trec_eval 报告 BM25 与混合排序的 nDCG@10 差异。
> - **解析**：压缩映射论证同时解释"为什么 $d$ 必须 <1"与"为什么迭代必收敛"；对拍实验是 HW06 自实现验收的通用做法。**易错原因**：用"特征值论证"但说不出收敛速率（$d^t$ 指数衰减）；实验只跑一个图、不做对拍与消融。
