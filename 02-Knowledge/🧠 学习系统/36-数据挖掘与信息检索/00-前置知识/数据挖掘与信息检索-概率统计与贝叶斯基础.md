## 💡 直觉与动机

在数据挖掘与信息检索中，数据几乎总是充满不确定性与噪声（例如：用户搜索关键词时的歧义意图、文档主题分布、CTR 预估中的稀疏点击）。

**贝叶斯思想**的核心是：将不确定性用概率来量化，并随着新证据（观察到的特征/点击行为）的引入，利用**贝叶斯定理**不断更新对事物的信念（从先验概率到后验概率）。

---

## 📐 正式定义与数学表达

### 1. 条件概率与贝叶斯定理

对于事件 $A$ 与 $B$，在 $P(B) > 0$ 的条件下，贝叶斯定理表述为：

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)} = \frac{P(B|A) \cdot P(A)}{\sum_{i} P(B|A_i) \cdot P(A_i)}$$

其中：
- $P(A)$：**先验概率**（Prior Probability），在看到证据 $B$ 之前的信念
- $P(B|A)$：**似然度**（Likelihood），在 $A$ 成立的假设下看到证据 $B$ 的概率
- $P(A|B)$：**后验概率**（Posterior Probability），看到证据 $B$ 后更新的概率
- $P(B)$：**边缘似然**（Evidence/Marginal Likelihood），归一化因子

### 2. 极大似然估计（MLE）与最大后验估计（MAP）

参数估计的两大经典视角：

$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} P(D|\theta) = \arg\max_{\theta} \sum_{i=1}^{N} \log P(x_i|\theta)$$

$$\hat{\theta}_{\text{MAP}} = \arg\max_{\theta} P(\theta|D) = \arg\max_{\theta} [P(D|\theta) \cdot P(\theta)] = \arg\max_{\theta} [\log P(D|\theta) + \log P(\theta)]$$

> MAP 相当于在 MLE 的基础上增加了关于参数 $\theta$ 的先验正则化项（如 L2 正则化对应高斯先验）。

## 💻 最小 Python 实现 — 朴素贝叶斯分类器原理

```python
import numpy as np

class NaiveBayesClassifier:
    """朴素贝叶斯二分类器（高斯似然）"""
    def fit(self, X: np.ndarray, y: np.ndarray):
        self.classes = np.unique(y)
        self.priors = {c: np.mean(y == c) for c in self.classes}
        self.means = {c: X[y == c].mean(axis=0) for c in self.classes}
        self.stds = {c: X[y == c].std(axis=0) + 1e-9 for c in self.classes}

    def _gaussian_pdf(self, x, mean, std):
        return (1 / (np.sqrt(2 * np.pi) * std)) * np.exp(-((x - mean)**2) / (2 * std**2))

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        probas = []
        for x in X:
            posteriors = {}
            for c in self.classes:
                likelihood = np.prod(self._gaussian_pdf(x, self.means[c], self.stds[c]))
                posteriors[c] = likelihood * self.priors[c]
            total = sum(posteriors.values())
            probas.append([posteriors[c] / (total + 1e-12) for c in self.classes])
        return np.array(probas)

# 测试数据
X = np.array([[1.0, 2.1], [1.2, 1.8], [5.0, 6.1], [5.2, 5.9]])
y = np.array([0, 0, 1, 1])
clf = NaiveBayesClassifier()
clf.fit(X, y)
print("新样本 [1.1, 1.9] 的类别概率:", clf.predict_proba(np.array([[1.1, 1.9]])))
```

## ⚠️ 常见误区与避坑指南

1. **混淆 $P(A|B)$ 与 $P(B|A)$（检察官谬误）**：例如 $P(\text{文本含“免费”}|\text{垃圾邮件}) = 80\%$ 并不等于 $P(\text{垃圾邮件}|\text{文本含“免费”}) = 80\%$，忽略先验概率 $P(\text{垃圾邮件})$ 会导致严重误判。

2. **零概率问题（Zero Frequency Problem）**：在朴素贝叶斯中，若某个特征值在训练集中未出现，其似然度为 0 会导致整个后验概率乘积归零。必须使用**拉普拉斯平滑（Laplace Smoothing）**。

3. **假设特征独立性过度硬套**：朴素贝叶斯假设条件独立，但现实特征通常高度相关。理解其局限性是在复杂场景改用 Logistic 回归或树模型的关键。
