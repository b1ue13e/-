## 📐 正式定义与数学表达

### 1. 余弦相似度 (Cosine Similarity)
对于高维空间中的两个向量 $\mathbf{A}, \mathbf{B} \in \mathbb{R}^d$，其余弦相似度定义为：
$$\text{Sim}_{\cos}(\mathbf{A}, \mathbf{B}) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\|_2 \|\mathbf{B}\|_2} = \frac{\sum_{i=1}^d A_i B_i}{\sqrt{\sum_{i=1}^d A_i^2} \sqrt{\sum_{i=1}^d B_i^2}}$$

### 2. 奇异值分解 (Singular Value Decomposition, SVD)
任意矩阵 $\mathbf{X} \in \mathbb{R}^{m \times n}$ 均可分解为：
$$\mathbf{X} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$$
其中 $\mathbf{U} \in \mathbb{R}^{m \times m}$ 和 $\mathbf{V} \in \mathbb{R}^{n \times n}$ 为正交矩阵，$\mathbf{\Sigma} \in \mathbb{R}^{m \times n}$ 为对角矩阵，对角元素 $\sigma_i$ 即为奇异值。

## 💻 最小 Python 实现

```python
import numpy as np

def cosine_similarity(v1: np.ndarray, v2: np.ndarray) -> float:
    """计算两个向量的余弦相似度"""
    norm1 = np.linalg.norm(v1)
    norm2 = np.linalg.norm(v2)
    if norm1 == 0 or norm2 == 0:
        return 0.0
    return float(np.dot(v1, v2) / (norm1 * norm2))

# 示例
doc1 = np.array([1.0, 2.0, 0.0, 5.0])
doc2 = np.array([2.0, 1.0, 0.0, 3.0])
print(f"Cosine Similarity: {cosine_similarity(doc1, doc2):.4f}")
```

## ⚠️ 常见误区与避坑指南

- **误区 1**：混淆欧氏距离与余弦相似度。欧氏距离受向量模长影响极大，在长文档与短文档比较时表现较差；而余弦相似度仅关注方向，忽略长度差异。
- **误区 2**：在未归一化的向量上直接进行点积。未归一化的点积值会严重偏向高频词/长文本。
