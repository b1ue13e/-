## 💡 直觉与动机

真实数据集中缺失值（Missing Values）、噪声（Noise）和不一致性（Inconsistency）极为常见。业界经验：数据科学家 60-80% 的时间花在数据清洗上。

清洗的核心问题：
1. 缺失值是**随机缺失**还是**系统性缺失**？（决定填补策略）
2. 异常值是**噪声**还是**真实极端值**？（决定是删除还是保留）
3. 清洗操作是否会引入**信息泄露**？（填补必须在划分训练集之后进行）

## 📐 正式定义与关键框架

### 缺失值机制分类（Rubin 1976）

| 缺失机制 | 英文 | 定义 | 示例 | 处理策略 |
|:---|:---|:---|:---|:---|
| **完全随机缺失** | MCAR | 缺失与任何数据无关 | 传感器随机故障 | 均值/中位数/KNN填补均可 |
| **随机缺失** | MAR | 缺失与可观测数据有关，与缺失值本身无关 | 年龄缺失与性别有关 | 多重插补（MICE）较好 |
| **非随机缺失** | MNAR | 缺失与缺失值本身有关 | 高收入者不愿填收入 | 最难处理，需建模缺失机制 |

### 缺失值填补策略

**统计填补**：
- **均值填补**：$x_{\text{miss}} \leftarrow \bar{x}$（适合 MCAR + 正态分布，但会缩小方差）
- **中位数填补**：对偏态分布和含异常值的特征更鲁棒
- **众数填补**：适合类别特征

**模型填补**：
$$x_{\text{miss}} \leftarrow \hat{f}(x_{\text{observed}})$$

- **KNN 填补**：用 $k$ 个最相似样本的均值/众数
- **MICE**（Multiple Imputation by Chained Equations）：逐特征迭代，每个特征用其他特征回归预测

### 异常值检测（见 [[异常检测]] 卡）

- **Z-score**：$|z_i| = |(x_i - \mu) / \sigma| > 3$ 标记异常
- **IQR**：$x < Q_1 - 1.5\text{IQR}$ 或 $x > Q_3 + 1.5\text{IQR}$
- **处理选项**：删除 / 截断（Capping/Winsorizing）/ 替换为边界值

## 💻 最小 Python 实现

```python
import numpy as np
from collections import Counter

def impute_missing(X: np.ndarray, strategy: str = 'mean') -> np.ndarray:
    """
    按列填补缺失值（NaN）
    strategy: 'mean' | 'median' | 'mode' | 'knn'
    """
    X = X.copy().astype(float)
    for col in range(X.shape[1]):
        missing_mask = np.isnan(X[:, col])
        if not missing_mask.any():
            continue
        observed = X[~missing_mask, col]

        if strategy == 'mean':
            fill_val = observed.mean()
        elif strategy == 'median':
            fill_val = np.median(observed)
        elif strategy == 'mode':
            vals, counts = np.unique(observed, return_counts=True)
            fill_val = vals[np.argmax(counts)]
        else:
            fill_val = observed.mean()  # fallback

        X[missing_mask, col] = fill_val
    return X

def winsorize(x: np.ndarray, lower: float = 0.05, upper: float = 0.95) -> np.ndarray:
    """截断法处理异常值（保留 [lower, upper] 百分位范围）"""
    lo, hi = np.percentile(x, lower*100), np.percentile(x, upper*100)
    return np.clip(x, lo, hi)

def detect_outliers_iqr(x: np.ndarray, factor: float = 1.5) -> np.ndarray:
    """返回异常值的布尔掩码"""
    q1, q3 = np.percentile(x, 25), np.percentile(x, 75)
    iqr = q3 - q1
    return (x < q1 - factor*iqr) | (x > q3 + factor*iqr)

# 示例
np.random.seed(42)
data = np.array([[1, 2, np.nan], [4, np.nan, 6], [7, 8, 9],
                 [np.nan, 11, 12], [13, 14, 15]], dtype=float)
print("原始数据:\n", data)
print("均值填补后:\n", impute_missing(data, 'mean').round(2))

ages = np.array([25, 28, 30, 200, 27, 31, 29, 250, 26])  # 含异常值
print("IQR异常检测:", detect_outliers_iqr(ages))
print("截断后:", winsorize(ages).astype(int))
```

## ⚠️ 常见误区与避坑指南

1. **在划分训练/测试集之前做填补**：若用全体数据的均值填补，则测试集缺失值引用了测试集的信息，形成数据泄露。**正确做法**：先 train/test split，再在训练集拟合填补器，用相同参数变换测试集。

2. **删除含缺失值的行（Listwise Deletion）**：当缺失率 > 5% 且不是 MCAR 时，删除会引入样本偏差。例如收入高的人不愿填写收入，删除后训练数据偏向低收入群体。

3. **均值填补高缺失率特征（> 30%）**：缺失率太高时均值填补会严重扭曲该特征的分布（方差被大幅压缩）。应考虑添加一个"是否缺失"的二元指示特征，保留缺失信息。

4. **误认为缺失值填补后即可信任该数据**：MNAR 场景下，即使填补了，估计仍然有偏。应在建模报告中明确说明缺失机制假设和局限性。

5. **对类别特征用均值填补**：类别特征（如城市、颜色）没有均值，应用众数或专门的类别填补方法，或增加一个"Unknown"类别。
