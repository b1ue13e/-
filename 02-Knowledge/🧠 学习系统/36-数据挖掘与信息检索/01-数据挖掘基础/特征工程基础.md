## 💡 直觉与动机

特征工程（Feature Engineering）是将原始数据转化为机器学习模型可用的数值输入的过程。业界流传一句话："数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限。"

核心问题：原始数据（文本、类别、时间戳）无法直接输入大多数 ML 算法（需要数值矩阵），且数值范围差异巨大会导致梯度下降收敛缓慢、距离度量失效。特征工程解决的是"输入质量"问题。

---

## 📐 正式定义与关键公式

### 1. 数值特征归一化

**Min-Max 归一化**（将特征缩放到 $[0, 1]$）：
$$x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$

**Z-score 标准化**（均值为 0，标准差为 1）：
$$x' = \frac{x - \mu}{\sigma}$$

> 选择依据：树模型（决策树/随机森林）对归一化不敏感；线性模型、SVM、神经网络对量纲敏感，必须归一化。

**RobustScaler**（对异常值鲁棒）：
$$x' = \frac{x - \text{median}}{\text{IQR}}$$

### 2. 类别特征编码

| 编码方式 | 适用场景 | 示例 |
|:---|:---|:---|
| **One-Hot** | 无序类别，类别数 < 20 | 颜色: red→[1,0,0], blue→[0,1,0] |
| **Ordinal** | 有序类别（低/中/高） | 学历: 本科=2, 硕士=3, 博士=4 |
| **Target Encoding** | 高基数类别（城市/商品ID） | 用目标变量均值替换类别 |
| **Binary Encoding** | 高基数类别，压缩维度 | $k$ 个类别 → $\lceil\log_2 k\rceil$ 个二进制位 |

### 3. 特征选择三大流派

$$\text{特征选择} = \begin{cases} \text{过滤法（Filter）} & \text{方差、相关系数、互信息} \\ \text{包装法（Wrapper）} & \text{递归特征消除（RFE）} \\ \text{嵌入法（Embedded）} & \text{L1正则化、树模型特征重要性} \end{cases}$$

### 4. 主成分分析（PCA）降维

目标：找到方差最大的正交投影方向：
$$\mathbf{z} = W^T \mathbf{x}, \quad W \in \mathbb{R}^{d \times k}$$

解：对协方差矩阵 $\Sigma = \frac{1}{n}X^TX$ 做特征值分解，取前 $k$ 个特征向量。

**方差解释率**：
$$\text{Explained Variance Ratio} = \frac{\lambda_i}{\sum_j \lambda_j}$$

## 💻 最小 Python 实现

```python
import numpy as np
from collections import defaultdict

def minmax_normalize(X: np.ndarray) -> np.ndarray:
    xmin = X.min(axis=0)
    xmax = X.max(axis=0)
    return (X - xmin) / (xmax - xmin + 1e-8)

def zscore_standardize(X: np.ndarray) -> np.ndarray:
    return (X - X.mean(axis=0)) / (X.std(axis=0) + 1e-8)

def target_encode(categories: list, targets: list) -> dict:
    """Target Encoding：用类别的目标均值编码"""
    sums = defaultdict(float)
    counts = defaultdict(int)
    for cat, tgt in zip(categories, targets):
        sums[cat] += tgt
        counts[cat] += 1
    return {cat: sums[cat] / counts[cat] for cat in sums}

def pca_manual(X: np.ndarray, k: int) -> tuple:
    """手工实现 PCA（教学用）"""
    X_centered = X - X.mean(axis=0)
    cov = X_centered.T @ X_centered / len(X)
    eigenvalues, eigenvectors = np.linalg.eigh(cov)
    # 按特征值降序排列
    idx = np.argsort(eigenvalues)[::-1]
    W = eigenvectors[:, idx[:k]]
    explained = eigenvalues[idx[:k]] / eigenvalues.sum()
    return X_centered @ W, explained

# 示例
np.random.seed(0)
X = np.random.randn(100, 5) * np.array([10, 0.1, 100, 1, 50])
X_norm = minmax_normalize(X)
print(f"归一化后范围: [{X_norm.min():.2f}, {X_norm.max():.2f}]")

Z, expl = pca_manual(X, k=2)
print(f"PCA前2主成分解释方差: {expl.sum():.1%}")
```

## ⚠️ 常见误区与避坑指南

1. **用测试集统计量做归一化**：必须用**训练集**的 min/max/mean/std 拟合归一化参数，再用相同参数变换测试集。否则是数据泄露。

2. **One-Hot 高基数特征（如用户ID）**：10万个用户ID做 One-Hot 会产生10万维稀疏向量，内存爆炸且无法泛化。应改用 Embedding 或 Target Encoding。

3. **对树模型做 One-Hot 编码后性能反而下降**：树模型按特征值分裂，不需要 One-Hot。对于高基数类别，直接输入 Label Encoding 给树模型即可，One-Hot 会增加树的深度需求。

4. **PCA 之前忘记标准化**：PCA 对量纲敏感，若特征量纲差异很大（如收入 vs 年龄），量纲大的特征会主导前几个主成分，导致 PCA 方向失真。

5. **特征选择后没有重新做交叉验证**：应在交叉验证的每个 fold 内独立做特征选择（而非全局选），否则特征选择本身会引入对测试集的信息泄露。
