## 💡 直觉与动机

关联规则挖掘能产生大量规则，但大多数规则是**平凡的**（显而易见）或**误导性的**（统计假象）。仅靠 Support 和 Confidence 是不够的：

- **置信度悖论**：$P(\text{牛奶}|\text{尿布}) = 40\%$，但 $P(\text{牛奶}) = 50\%$，说明买尿布的人**反而更少**买牛奶（Lift < 1）。
- **支持度偏向热门物品**：低频但高价值的模式（如高端产品共同购买）会被 min\_sup 过滤掉。

需要更丰富的评估指标族，从多个角度衡量规则的"有趣性"。

## 📐 正式定义与指标公式对比

设规则 $A \Rightarrow B$，令：
- $P(A) = p_A$，$P(B) = p_B$，$P(A \cup B) = p_{AB}$，事务总数 $N$

| 指标 | 公式 | 取值范围 | 对称 | 最优值 |
|:---|:---|:---|:---:|:---:|
| **Support** | $p_{AB}$ | $[0,1]$ | ✅ | ↑ |
| **Confidence** | $p_{AB}/p_A$ | $[0,1]$ | ❌ | ↑ |
| **Lift** | $p_{AB}/(p_A \cdot p_B)$ | $[0,\infty)$ | ✅ | $>1$ |
| **Conviction** | $(1-p_B)/(1-p_{AB}/p_A)$ | $[0,\infty)$ | ❌ | $\infty$ |
| **Leverage** | $p_{AB} - p_A \cdot p_B$ | $[-0.25, 0.25]$ | ✅ | $>0$ |
| **Kulczynski** | $\frac{1}{2}(p_{AB}/p_A + p_{AB}/p_B)$ | $[0,1]$ | ✅ | $\to 1$ |
| **余弦相似度** | $p_{AB}/\sqrt{p_A \cdot p_B}$ | $[0,1]$ | ✅ | $\to 1$ |

### Lift 的几何意义

$$\text{Lift}(A \Rightarrow B) = \frac{P(A \cup B)}{P(A) \cdot P(B)} = \frac{\text{实际共现概率}}{\text{独立假设下的期望共现概率}}$$

- $\text{Lift} = 1$：$A$ 和 $B$ 统计独立
- $\text{Lift} > 1$：正向关联（共现多于期望）
- $\text{Lift} < 1$：负向关联（共现少于期望）

### 对称性与不平衡比率（IR）

当 $P(A) \gg P(B)$ 时，Confidence 严重偏向高频项目。Kulczynski 指标可与**不平衡比率（Imbalance Ratio）**联合使用：

$$\text{IR}(A, B) = \frac{|P(A) - P(B)|}{P(A) + P(B) - P(A \cup B)}$$

IR 接近 0 说明两者频率相近；IR 接近 1 说明频率严重不对称，需谨慎解读规则方向。

## 💻 最小 Python 实现

```python
import math
from dataclasses import dataclass

@dataclass
class RuleMetrics:
    support: float
    confidence: float
    lift: float
    leverage: float
    conviction: float
    kulczynski: float
    cosine: float

def compute_rule_metrics(p_A: float, p_B: float, p_AB: float) -> RuleMetrics:
    """计算关联规则 A => B 的全套评估指标"""
    if p_A == 0 or p_B == 0:
        raise ValueError("P(A) 和 P(B) 不能为 0")

    conf = p_AB / p_A
    lift = p_AB / (p_A * p_B)
    leverage = p_AB - p_A * p_B
    conviction = (1 - p_B) / (1 - conf) if conf < 1 else float('inf')
    kulc = 0.5 * (p_AB / p_A + p_AB / p_B)
    cosine = p_AB / math.sqrt(p_A * p_B)

    return RuleMetrics(
        support=round(p_AB, 4),
        confidence=round(conf, 4),
        lift=round(lift, 4),
        leverage=round(leverage, 4),
        conviction=round(conviction, 4),
        kulczynski=round(kulc, 4),
        cosine=round(cosine, 4)
    )

# 示例1：Lift < 1 的反直觉规则
print("规则：尿布 => 牛奶")
m = compute_rule_metrics(p_A=0.20, p_B=0.50, p_AB=0.08)
print(f"  Confidence={m.confidence}, Lift={m.lift} ({'正相关' if m.lift>1 else '负相关！'})")

# 示例2：高置信但低 Lift
print("\n规则：高频商品A => 高频商品B")
m2 = compute_rule_metrics(p_A=0.90, p_B=0.85, p_AB=0.78)
print(f"  Confidence={m2.confidence}, Lift={m2.lift:.3f}")
```

## ⚠️ 常见误区与避坑指南

1. **只看置信度报告规则**：必须同时报告 Lift，置信度高但 Lift ≤ 1 的规则没有价值，甚至有误导性。

2. **Lift 在稀疏数据中不稳定**：当 $P(A)$ 或 $P(B)$ 极小时，Lift 的估计方差很大，可能产生虚假高值。应设置最小支持度下限（min\_sup ≥ 统计显著性阈值）。

3. **对称指标掩盖方向性**：Lift 和 Kulczynski 是对称的（$A \Rightarrow B$ 和 $B \Rightarrow A$ 值相同），但实际应用中往往需要方向性（如"买A的人会买B"和"买B的人会买A"的业务价值完全不同）。用 Confidence 确认方向。

4. **Conviction 无穷大时的解读**：Conviction = $\infty$ 说明规则是完美决定关系（Confidence = 1），但不代表业务价值高——可能 $P(A)$ 极低。

5. **忽略多重检验校正**：挖掘数万条规则时，少量规则"偶然"满足所有指标阈值的概率不可忽视（类似多重检验的 p 值膨胀），应结合置换检验（Permutation Test）评估规则的统计显著性。
