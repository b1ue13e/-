## 💡 直觉与动机

异常检测（Anomaly Detection / Outlier Detection）的目标是找出那些与大多数数据**显著不同**的点。它本质上是无监督学习（没有"哪个是异常"的标签），依赖的假设是正常样本占绝大多数，异常样本稀少且偏离整体分布。

典型场景：金融欺诈检测（99.9% 正常交易，0.1% 欺诈）、网络入侵检测、工业设备故障预警、医疗诊断中的罕见病筛查。关键挑战是极端的类别不平衡——甚至没有标注的异常样本。

## 📐 正式定义与关键公式

### 统计方法：Z-score 与 IQR

**Z-score（适用于近似正态分布）**：

$$z_i = \frac{x_i - \mu}{\sigma}$$

通常 $|z_i| > 3$ 视为异常（覆盖 99.7% 的正态分布）。

**IQR 方法（鲁棒，对非正态分布友好）**：

$$\text{IQR} = Q_3 - Q_1$$
$$\text{异常范围：} x < Q_1 - 1.5 \cdot \text{IQR} \quad \text{或} \quad x > Q_3 + 1.5 \cdot \text{IQR}$$

### 局部离群因子 LOF（Local Outlier Factor）

LOF 衡量一个点相对于其邻域的**局部密度偏离程度**。

**可达距离（Reachability Distance）**：

$$\text{reach-dist}_k(p, o) = \max(\text{k-dist}(o),\ d(p, o))$$

**局部可达密度（LRD）**：

$$\text{lrd}_k(p) = \frac{1}{\frac{1}{|N_k(p)|}\sum_{o \in N_k(p)} \text{reach-dist}_k(p, o)}$$

**LOF 分数**：

$$\text{LOF}_k(p) = \frac{\sum_{o \in N_k(p)} \frac{\text{lrd}_k(o)}{\text{lrd}_k(p)}}{|N_k(p)|}$$

> $\text{LOF} \approx 1$：正常点（密度与邻居相似）；$\text{LOF} \gg 1$：异常点（密度远低于邻居）。

### 孤立森林（Isolation Forest）

核心思想：**异常点容易被隔离**（需要更少的随机分裂次数）。

**异常分数**：

$$s(x, n) = 2^{-\frac{E[h(x)]}{c(n)}}$$

其中 $h(x)$ 是数据点 $x$ 在孤立树中的路径长度，$c(n) = 2H(n-1) - \frac{2(n-1)}{n}$ 是 $n$ 个样本的二叉搜索树平均路径长度（归一化因子）。

$s \to 1$：高度异常；$s \to 0.5$：正常；$s \to 0$：绝对正常。

## 💻 最小 Python 实现

```python
import numpy as np

def isolation_score_simple(X: np.ndarray, n_trees: int = 100, subsample: int = 256) -> np.ndarray:
    """简化版孤立森林路径长度计算（教学用）"""
    n = len(X)
    scores = np.zeros(n)

    for _ in range(n_trees):
        # 随机子采样
        idx = np.random.choice(n, min(subsample, n), replace=False)
        sample = X[idx]

        # 对每个点，随机分裂直到孤立（简化：随机在[min,max]切分）
        for i in range(n):
            path_len = 0
            node = sample.copy()
            while len(node) > 1:
                feat = np.random.randint(X.shape[1])
                lo, hi = node[:, feat].min(), node[:, feat].max()
                if lo == hi:
                    break
                split = np.random.uniform(lo, hi)
                left = node[node[:, feat] < split]
                right = node[node[:, feat] >= split]
                # 判断 X[i] 走哪边
                node = left if X[i, feat] < split else right
                path_len += 1
            scores[i] += path_len

    scores /= n_trees
    # 归一化为异常分数 (越高越异常)
    c_n = 2 * (np.log(subsample - 1) + 0.5772) - 2*(subsample-1)/subsample
    return 2 ** (-scores / c_n)

# 示例
np.random.seed(42)
normal = np.random.randn(100, 2)
outliers = np.array([[5, 5], [-5, 5], [5, -5]])
X = np.vstack([normal, outliers])
scores = isolation_score_simple(X, n_trees=50, subsample=64)
print("异常分数最高的3个点：", np.argsort(scores)[-3:])  # 应为 100, 101, 102
```

## ⚠️ 常见误区与避坑指南

1. **用 Z-score 处理非正态分布**：厚尾分布（如收入数据）Z-score 会遗漏真实异常，应改用 IQR 或分布假设更少的方法（LOF、Isolation Forest）。

2. **LOF 的 $k$ 参数选择**：$k$ 太小（噪声敏感）；$k$ 太大（丢失局部信息）。通常 $k \in [10, 50]$，需结合领域知识调优。

3. **Isolation Forest 无法处理高维相关结构**：对高维数据，随机特征切分的效率退化。可先降维（PCA）后再用 Isolation Forest。

4. **将异常分数当作概率解释**：LOF 和 Isolation Forest 的输出是相对排序分数，不是概率，阈值需在验证集上调整。

5. **忽略时间序列中的季节性**：在交易数据中，节假日的"正常峰值"会被误判为异常。应先分解时间序列（STL分解），对残差做异常检测。
