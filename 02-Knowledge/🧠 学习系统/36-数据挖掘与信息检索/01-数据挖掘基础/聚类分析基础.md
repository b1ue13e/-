## 💡 直觉与动机

聚类（Clustering）是典型的**无监督学习**任务：在没有标签的情况下，根据数据点之间的相似性将其分组为若干簇（Cluster），使**簇内相似度高、簇间相似度低**。

与分类不同，聚类没有"正确答案"，结果的质量取决于应用场景。典型应用：用户分群（个性化运营）、文档主题聚类（搜索结果分组）、异常检测预处理（正常簇 vs 离群点）。

## 📐 正式定义与关键公式

### K-Means：目标函数

K-Means 最小化**簇内平方和（WCSS / Inertia）**：

$$J = \sum_{j=1}^{K} \sum_{\mathbf{x}_i \in C_j} \| \mathbf{x}_i - \boldsymbol{\mu}_j \|^2$$

其中 $\boldsymbol{\mu}_j = \frac{1}{|C_j|} \sum_{\mathbf{x}_i \in C_j} \mathbf{x}_i$ 是第 $j$ 个簇的质心。

**K-Means 算法（Lloyd's Algorithm）**：
1. 随机初始化 $K$ 个质心（K-Means++ 改进：按概率正比于距离最远点选取）
2. **分配步**：每个点分配到最近质心的簇
3. **更新步**：重新计算每个簇的质心
4. 重复步骤 2-3 直到质心不再变化

> K-Means 保证单调收敛到局部最优，时间复杂度 $O(nKTd)$（$n$=样本数，$K$=簇数，$T$=迭代数，$d$=维度）。

### DBSCAN：基于密度的聚类

核心概念：
- **核心点**：$\varepsilon$ 邻域内至少有 $\text{MinPts}$ 个点
- **边界点**：在某核心点的 $\varepsilon$ 邻域内，但自身不是核心点
- **噪声点**：既不是核心点，也不是边界点

$$\text{直接密度可达：} q \text{ 在 } p \text{ 的 } \varepsilon\text{-邻域内，且 } p \text{ 是核心点}$$

### 聚类质量评估——轮廓系数（Silhouette Score）

$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

- $a(i)$：点 $i$ 与**同簇**其他点的平均距离（簇内紧密度）
- $b(i)$：点 $i$ 到**最近异簇**所有点的平均距离（簇间分离度）
- $s(i) \in [-1, 1]$；越接近 1 越好，接近 0 说明在边界，负值说明被分到了错误的簇

## 💻 最小 Python 实现

```python
import numpy as np
from typing import Optional

def kmeans_simple(X: np.ndarray, K: int, max_iter: int = 100, seed: int = 42) -> tuple:
    """纯 NumPy 实现 K-Means（教学用，不含 K-Means++ 初始化）"""
    rng = np.random.default_rng(seed)
    # 随机选 K 个初始质心
    centers = X[rng.choice(len(X), K, replace=False)]

    for _ in range(max_iter):
        # 分配步：计算每个点到各质心的距离
        dists = np.linalg.norm(X[:, None, :] - centers[None, :, :], axis=2)  # (n, K)
        labels = np.argmin(dists, axis=1)  # (n,)

        # 更新步
        new_centers = np.array([X[labels == k].mean(axis=0) for k in range(K)])
        if np.allclose(centers, new_centers):
            break
        centers = new_centers

    inertia = sum(np.sum((X[labels == k] - centers[k])**2) for k in range(K))
    return labels, centers, inertia

# 示例
np.random.seed(0)
X = np.vstack([np.random.randn(50, 2) + [3, 3],
               np.random.randn(50, 2) + [-3, -3]])
labels, centers, inertia = kmeans_simple(X, K=2)
print(f"Inertia: {inertia:.2f}")
```

## ⚠️ 常见误区与避坑指南

1. **不选 K 值直接运行 K-Means**：必须用肘部法则（Elbow Method）或轮廓系数选 $K$。肘部法则看 Inertia 下降速度，找"肘点"。

2. **K-Means 对异常值极其敏感**：均值质心被离群点拉偏。可改用 K-Medoids（选实际样本点作质心），或先做异常检测再聚类。

3. **K-Means 假设球形分布**：对月牙形、环形等非凸结构聚类效果极差。此时应使用 DBSCAN 或谱聚类（Spectral Clustering）。

4. **轮廓系数高 ≠ 业务有意义**：轮廓系数是纯数学指标，必须结合业务逻辑解释各簇的实际含义。

5. **高维空间距离失效（维度灾难）**：在 $d > 50$ 时欧氏距离趋于等值，聚类效果退化。必须先降维（PCA/UMAP）再聚类。
