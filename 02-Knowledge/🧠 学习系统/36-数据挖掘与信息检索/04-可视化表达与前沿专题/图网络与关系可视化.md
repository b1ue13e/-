## 💡 直觉与动机

在 Web 信息检索（如 PageRank 网页链接图）、社交网络分析以及知识图谱中，数据天然呈现为**图（Graph）**结构。

图可视化的核心挑战在于**防杂乱（Anti-Clutter）**与**结构表达**：海量的节点（Nodes）和边（Edges）重叠在一起会形成“毛球（Hairball）”，必须依赖优秀的布局算法与聚合技术才能揭示社群与拓扑结构。

---

## 📐 正式定义与核心算法

### 1. 力导向布局算法（Force-Directed Layout / Fruchterman-Reingold）

将图模拟为物理弹簧系统：
- **节点之间**存在静电排斥力（Repulsive Force）：$F_r = \frac{k^2}{d}$
- **相连的边**存在弹簧吸引力（Attractive Force）：$F_a = \frac{d^2}{k}$

通过迭代计算合力并更新节点位置，直至系统能量达到局部极小值。

### 2. 节点-链接图 vs 邻接矩阵

| 模式 | 优点 | 缺点 | 适用场景 |
|:---|:---|:---|:---|
| **节点-链接图 (Node-Link)** | 直观、易于追踪路径 | 节点/边密集时产生毛球 | 稀疏图 ($|E| \ll |V|^2$) |
| **邻接矩阵 (Adjacency Matrix)** | 不存在边交叉，适合密集图 | 难以追踪路径/环路 | 稠密图、社群发现 |

## 💻 最小 Python 实现 — 模拟力导向布局单步迭代

```python
import numpy as np

def force_directed_step(nodes_pos: np.ndarray, edges: list, k: float = 1.0, c: float = 0.1) -> np.ndarray:
    """
    力导向布局单步物理迭代 (NumPy)
    nodes_pos: (N, 2) 节点二维坐标
    edges: [(i, j), ...] 边列表
    """
    n = len(nodes_pos)
    disp = np.zeros_like(nodes_pos)

    # 1. 计算排斥力 (两两节点)
    for i in range(n):
        for j in range(i + 1, n):
            delta = nodes_pos[i] - nodes_pos[j]
            dist = np.linalg.norm(delta) + 1e-6
            force = (k**2 / dist) * (delta / dist)
            disp[i] += force
            disp[j] -= force

    # 2. 计算吸引力 (相连边)
    for u, v in edges:
        delta = nodes_pos[u] - nodes_pos[v]
        dist = np.linalg.norm(delta) + 1e-6
        force = (dist**2 / k) * (delta / dist)
        disp[u] -= force
        disp[v] += force

    # 3. 更新位置
    return nodes_pos + c * disp

# 测试
pos = np.array([[0.0, 0.0], [1.0, 0.0], [0.5, 1.0]])
edges = [(0, 1), (1, 2), (2, 0)]
new_pos = force_directed_step(pos, edges)
print("更新后节点坐标:\n", np.round(new_pos, 3))
```

## ⚠️ 常见误区与避坑指南

1. **对稠密图直接绘制 Node-Link**：边重叠严重，视觉效果退化为“黑块”。应采用**边捆绑（Edge Bundling）**技术或切换为邻接矩阵。

2. **忽略随机初始化的影响**：力导向算法容易陷入局部最优，不同随机种子导出的布局形态可能大相径庭。生产环境通常使用 Spectral / PCA 初始化节点位置。
