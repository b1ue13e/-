## 💡 直觉与动机

搜索引擎正在经历自倒排索引诞生以来最深刻的范式变革：从**关键词精确匹配（TF-IDF/BM25）** 到 **语义向量检索（Dense Retrieval）**，再到最新的 **生成式检索与 Agent 搜索（DSI & RAG）**。

理解搜索前沿发展路线，不仅能站在技术潮头，还能为设计下一代智能检索系统提供架构视野。

---

## 📐 搜索技术演进三大范式

```
【第一代：倒排索引+统计评分】     【第二代：双塔神经网络稠密召回】     【第三代：生成式检索与 Agent 搜索】
 TF-IDF / BM25 / PageRank    ──▶   DPR / ColBERT / BGE     ──▶   DSI / RAG Agent / 搜索大模型
 (关键字硬匹配)                    (向量空间最近邻)                  (模型即索引 / 自动多轮推理)
```

### 关键范式对比

1. **Dense Passage Retrieval (DPR)**：使用双塔 BERT 分别编码 Query 和 Passage，用 Inner Product 计算相关性：
   $$\text{Score}(q, d) = E_Q(q)^T E_D(d)$$
2. **Differentiable Search Index (DSI)**：取消外部倒排/向量索引，将整个文档库参数化记入 LLM 中，模型直接根据 Query 输出 DocID。
3. **Search Agent (RAG Agent)**：搜索引擎变为 LLM Agent 的 Tool，Agent 根据中间推理自主发起多轮搜索、改写查询并总结答案。

## 💻 最小 Python 实现 — 模拟 Search Agent 多轮查询重写

```python
class MockSearchAgent:
    """模拟 Search Agent 的多轮查询分解与检索流水线"""
    def __init__(self, doc_db: dict):
        self.doc_db = doc_db

    def plan_queries(self, complex_query: str) -> list:
        """将复杂查询拆解为多个原子子查询"""
        if "比较" in complex_query:
            parts = complex_query.replace("比较", "").split("和")
            return [f"{p.strip()} 核心原理" for p in parts]
        return [complex_query]

    def search(self, sub_query: str) -> list:
        """模拟检索调用"""
        results = [doc for key, doc in self.doc_db.items() if any(w in doc for w in sub_query.split())]
        return results[:2]

    def run(self, query: str) -> dict:
        sub_queries = self.plan_queries(query)
        retrieved_docs = {}
        for sq in sub_queries:
            retrieved_docs[sq] = self.search(sq)
        return {
            "original_query": query,
            "sub_queries": sub_queries,
            "evidence": retrieved_docs
        }

# 测试
db = {
    "1": "BM25 是一种基于词频和倒排索引的稀疏概率检索模型。",
    "2": "DPR 是一种利用双塔 BERT 进行语义向量表达的稠密检索模型。"
}
agent = MockSearchAgent(db)
res = agent.run("比较 BM25 和 DPR")
print("Agent 执行轨迹:", res)
```

## ⚠️ 常见误区与避坑指南

1. **盲目认为生成式检索（DSI）完全替代倒排索引**：DSI 目前在动态文档增删（Update）和幻觉控制上存在天然缺陷。现代工业界普遍采用 RAG（检索增强生成）作为稳健过渡方案。
