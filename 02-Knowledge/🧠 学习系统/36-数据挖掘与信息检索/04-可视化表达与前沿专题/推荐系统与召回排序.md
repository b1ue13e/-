## 💡 直觉与动机

推荐系统解决的是**信息过载**问题：在海量物品（商品/视频/文章）中，为用户找到其可能感兴趣的一小部分。现代工业级推荐系统通常分为两个阶段：

1. **召回（Recall）**：从亿级候选中快速筛选出数千个候选（强调效率，可接受低精度）
2. **排序（Ranking）**：对数千个候选精细排序（复杂模型，追求高精度）

本卡重点覆盖召回阶段的核心方法：协同过滤、矩阵分解和双塔模型。

---

## 📐 正式定义与关键公式

### 协同过滤（Collaborative Filtering）

基于"相似用户喜欢相似物品"的假设：

**用户-物品评分矩阵**：$R \in \mathbb{R}^{m \times n}$（$m$ 用户，$n$ 物品，大量缺失值）

**基于物品的协同过滤（Item-CF）预测**：

$$\hat{r}_{ui} = \frac{\sum_{j \in N(u)} \text{Sim}(i, j) \cdot r_{uj}}{\sum_{j \in N(u)} |\text{Sim}(i, j)|}$$

其中 $N(u)$ 是用户 $u$ 历史交互物品集，$\text{Sim}(i, j)$ 通常用余弦相似度计算。

### 矩阵分解（Matrix Factorization / ALS）

将评分矩阵分解为用户矩阵和物品矩阵的乘积：

$$\hat{R} \approx P \cdot Q^T, \quad P \in \mathbb{R}^{m \times k},\ Q \in \mathbb{R}^{n \times k}$$

目标函数（带正则化）：

$$\mathcal{L} = \sum_{(u,i): r_{ui} \neq 0} (r_{ui} - \mathbf{p}_u^T \mathbf{q}_i)^2 + \lambda(\|\mathbf{p}_u\|^2 + \|\mathbf{q}_i\|^2)$$

**ALS（交替最小二乘）求解**：固定 $Q$ 优化 $P$，再固定 $P$ 优化 $Q$，交替迭代直至收敛。

### 双塔模型（Two-Tower / DSSM）

用于工业级百亿规模的向量召回：

$$\text{Score}(u, i) = \text{UserTower}(x_u)^T \cdot \text{ItemTower}(x_i)$$

训练：用 **In-Batch Negative Sampling**（batch 内其他物品作为负样本），用 BCE 或 Softmax 损失。
推理：离线计算所有物品向量建立 FAISS 索引，在线用用户向量做 ANN 查询。

## 💻 最小 Python 实现 — 矩阵分解（ALS）

```python
import numpy as np

def als_mf(R: np.ndarray, k: int = 10, lam: float = 0.1, n_iter: int = 20) -> tuple:
    """
    基于 ALS 的矩阵分解（仅对已观测评分优化）
    R: 用户-物品评分矩阵，0 表示未评分
    """
    m, n = R.shape
    mask = (R > 0).astype(float)  # 已观测位置
    rng = np.random.default_rng(42)

    P = rng.normal(0, 0.1, (m, k))  # 用户隐因子矩阵
    Q = rng.normal(0, 0.1, (n, k))  # 物品隐因子矩阵

    for iteration in range(n_iter):
        # 固定 Q，更新 P（逐用户求解）
        for u in range(m):
            observed = mask[u] > 0
            if observed.sum() == 0:
                continue
            Q_obs = Q[observed]    # (n_obs, k)
            R_obs = R[u, observed] # (n_obs,)
            A = Q_obs.T @ Q_obs + lam * np.eye(k)
            b = Q_obs.T @ R_obs
            P[u] = np.linalg.solve(A, b)

        # 固定 P，更新 Q（逐物品求解）
        for i in range(n):
            observed = mask[:, i] > 0
            if observed.sum() == 0:
                continue
            P_obs = P[observed]
            R_obs = R[observed, i]
            A = P_obs.T @ P_obs + lam * np.eye(k)
            b = P_obs.T @ R_obs
            Q[i] = np.linalg.solve(A, b)

        # 计算 RMSE
        pred = P @ Q.T
        rmse = np.sqrt(np.sum(mask * (R - pred)**2) / mask.sum())
        if (iteration + 1) % 5 == 0:
            print(f"Iter {iteration+1:3d} | RMSE: {rmse:.4f}")

    return P, Q

# 小规模示例（5用户 x 4物品）
R = np.array([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [1, 0, 0, 4],
    [0, 1, 5, 4],
], dtype=float)

P, Q = als_mf(R, k=3, n_iter=20)
R_hat = P @ Q.T
print("\n预测评分矩阵（保留2位小数）:")
print(np.round(R_hat, 2))
```

## ⚠️ 常见误区与避坑指南

1. **冷启动问题被忽视**：新用户/新物品没有历史数据，协同过滤和矩阵分解完全无效。工业界解决方案：新用户用内容特征（Content-Based）或热门推荐；新物品用物品侧特征初始化向量。

2. **负样本采样偏差（Sampling Bias）**：随机负样本大多是热门物品，模型学到的是区分热/冷物品，而非真实用户偏好。应使用频率矫正的采样（Popularity-Corrected Sampling），Yi et al. 2019 有详细讨论。

3. **训练集数据泄露**：推荐系统按时间切分训练/测试集，不能随机切分。若把未来的交互数据放入训练集，所有离线指标都会虚高。

4. **离线 AUC 高但在线 CTR 低**：离线测试集（历史数据）的分布与实时流量有偏差（曝光偏差 Exposure Bias）。必须同时设计在线 A/B 实验。

5. **双塔模型的 Item 端更新滞后**：物品向量是离线预计算的，如果物品属性频繁变化（如价格波动），需要增量更新物品索引，否则召回质量下降。
