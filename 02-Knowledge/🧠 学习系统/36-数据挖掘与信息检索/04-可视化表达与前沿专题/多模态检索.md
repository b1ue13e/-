## 💡 动机与直觉

传统的文本搜索引擎仅能处理文本-文本匹配，无法直接响应“用文本搜图片”、“用图片搜相似商品”或“音频-文本对齐”等跨模态需求。

**多模态检索（Multimodal Retrieval）** 的核心在于建立一个**统一的共享表示空间（Unified Shared Embedding Space）**。通过对比学习（Contrastive Learning），将文本、图像、语音等不同模态的特征映射到同等维度的特征空间中，使得语义相关的跨模态对（如“猫的照片”与文本 "a photo of a cat"）在该空间内的余弦相似度极高。

## 📐 算法原理与 CLIP 架构

```
图像 Encoder (Vision Transformer / ResNet) ──▶ Image Embedding I_i ──┐
                                                                       ├─▶ 矩阵点积与 Cosine 相似度
文本 Encoder (Transformer Text Encoder)   ──▶ Text Embedding T_j  ──┘
```

### 1. 对比学习损失函数 (InfoNCE Loss)

给定一个包含 $N$ 个 (图像, 文本) 对的 Batch，网络产生 $N$ 个图像特征 $I_1, \dots, I_N$ 和 $N$ 个文本特征 $T_1, \dots, T_N$。

相似度矩阵 $S_{i, j} = \text{sim}(I_i, T_j) = \frac{I_i \cdot T_j}{\|I_i\|_2 \|T_j\|_2} \cdot e^\tau$（其中 $\tau$ 为可学习的温度系数）。

包含两个维度的交叉熵损失：
- **图像到文本 loss**：$\mathcal{L}_{I \to T} = -\frac{1}{N} \sum_{i=1}^N \log \frac{\exp(S_{i, i})}{\sum_{j=1}^N \exp(S_{i, j})}$
- **文本到图像 loss**：$\mathcal{L}_{T \to I} = -\frac{1}{N} \sum_{j=1}^N \log \frac{\exp(S_{j, j})}{\sum_{i=1}^N \exp(S_{i, j})}$
- **总体 Loss**：$\mathcal{L} = \frac{\mathcal{L}_{I \to T} + \mathcal{L}_{T \to I}}{2}$

## 💻 最小 Python 实践 (OpenCLIP 仿真)

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleCLIP(nn.Module):
    def __init__(self, text_dim: int = 128, img_dim: int = 128, embed_dim: int = 64):
        super().__init__()
        self.img_proj = nn.Linear(img_dim, embed_dim)
        self.text_proj = nn.Linear(text_dim, embed_dim)
        self.logit_scale = nn.Parameter(torch.ones([]) * np.log(1 / 0.07))

    def forward(self, img_feats, text_feats):
        # 1. 映射到共享空间
        img_embeds = F.normalize(self.img_proj(img_feats), p=2, dim=-1)
        text_embeds = F.normalize(self.text_proj(text_feats), p=2, dim=-1)

        # 2. 余弦相似度矩阵
        logit_scale = self.logit_scale.exp()
        logits_per_image = logit_scale * img_embeds @ text_embeds.t()
        logits_per_text = logits_per_image.t()

        return logits_per_image, logits_per_text

# 单元测试
if __name__ == "__main__":
    import numpy as np
    model = SimpleCLIP()
    batch_size = 4
    dummy_img = torch.randn(batch_size, 128)
    dummy_text = torch.randn(batch_size, 128)

    l_img, l_text = model(dummy_img, dummy_text)
    print("相似度矩阵尺寸 (Images x Texts):", l_img.shape)
    assert l_img.shape == (batch_size, batch_size)
```

## ⚠️ 常见误区与避坑指南

1. **误区：多模态检索只需要简单拼特征**
   - 避坑：直接拼接不同模态特征（Concat）无法建立对齐语义，必须通过双塔对比学习（Two-Tower Contrastive Learning）显式对齐余弦空间。

**Q: CLIP 等多模态检索模型实现文本-图像对齐的核心 Loss 是什么？**
**A**:
- **InfoNCE 对比学习 Loss**。将正例 (图像_i, 文本_i) 的余弦相似度最大化，同时将同一 Batch 内的 $N-1$ 个负例相似度最小化。
