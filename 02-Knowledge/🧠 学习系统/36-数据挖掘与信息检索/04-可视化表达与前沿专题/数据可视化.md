## 💡 动机与直觉

“一图胜千言”。数据挖掘算法（如聚类、分类、离群点）输出的结果往往是高维复杂的数学矩阵，直接阅读文本数字极难洞察规律。

**数据可视化（Data Visualization）** 是将抽象数据映射为视觉特征（位置、形状、颜色、尺寸）的科学与艺术。其核心目标是协助人类大脑的视觉皮层高效进行模式识别、趋势推断与异常诊断。

---

## 📐 视觉编码与图形语法 (Grammar of Graphics)

### 1. 视觉通道 (Visual Channels) 识别有效性

根据 Tufte 与 Mackinlay 的研究，不同视觉通道对不同数据类型的表达精确度排序如下：

```
定量数据 (Quantitative): 位置 (Position) > 长度 (Length) > 角度 (Angle) > 面积 (Area) > 颜色饱和度 (Saturation)
定性数据 (Categorical):  位置 (Position) > 颜色色调 (Hue) > 形状 (Shape) > 填充纹理 (Texture)
```

### 2. Tufte 数据-墨水比 (Data-Ink Ratio)
数据墨水比定义为用于展示实际数据的墨水量占总墨水量的比例：

$$\text{Data-Ink Ratio} = \frac{\text{用于展现数据的墨水}}{\text{打印图表所用的总墨水}} \to 1.0$$

- **原则**：最大化数据墨水比，消除无意义的网格阴影、3D 立体装饰及冗余边框（Chartjunk）。

## 💻 最小 Python 实践：Seaborn / Matplotlib 散点图与决策边界可视化

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.cluster import DBSCAN

# 1. 生成双月数据集
X, y = make_moons(n_samples=200, noise=0.08, random_state=42)

# 2. 挖掘算法：DBSCAN 聚类
db = DBSCAN(eps=0.3, min_samples=5).fit(X)
labels = db.labels_

# 3. 视觉映射：颜色映射为簇标签，形状映射为噪声点
plt.figure(figsize=(8, 5))
unique_labels = set(labels)
colors = [plt.cm.Spectral(each) for each in np.linspace(0, 1, len(unique_labels))]

for k, col in zip(unique_labels, colors):
    if k == -1:
        col = [0, 0, 0, 1]  # 噪声点用黑色标记
    class_member_mask = (labels == k)
    xy = X[class_member_mask]
    plt.plot(xy[:, 0], xy[:, 1], 'o', markerfacecolor=tuple(col),
             markeredgecolor='k', markersize=6, label=f"Cluster {k}" if k != -1 else "Noise")

plt.title("DBSCAN Clustering Density Visualization (Data-Ink Optimized)")
plt.xlabel("Feature X1")
plt.ylabel("Feature X2")
plt.legend()
plt.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
# 保存而非阻塞阻塞显示
plt.savefig("dbscan_vis_demo.png", dpi=100)
print("可视化图像生成完毕: dbscan_vis_demo.png")
```

## ⚠️ 常见误区与避坑指南

1. **误区：滥用 3D 图表与炫彩颜色**
   - 避坑：3D 饼图或 3D 柱状图会导致严重的透视角度误导，改变图形实际投影面积；定性分类变量颜色尽量不要超过 7 种。
