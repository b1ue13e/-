## 💡 直觉与动机

数据可视化的目标是让人类视觉系统高效处理数据中的信息。但不同的视觉编码方式效率差异巨大——条形图和折线图对于同一组数据可以让用户得出完全不同的结论，饼图在超过 5 个类别时严重失效。

核心问题：**把什么数据映射到什么视觉属性（Visual Channel），能最快、最准确地传递信息？** 这不是审美问题，而是有实验基础的认知科学。

---

## 📐 正式定义与核心原则

### Bertin 的视觉变量（Visual Variables）

Jacques Bertin 在 1967 年提出 7 类基本视觉编码维度：

| 视觉变量 | 英文 | 适合数据类型 | 感知精度排名 |
|:---|:---|:---|:---:|
| **位置 X/Y** | Position | 定量、定序 | ⭐⭐⭐⭐⭐ 最高 |
| **长度** | Length | 定量 | ⭐⭐⭐⭐ |
| **角度** | Angle | 定量（谨慎） | ⭐⭐⭐ |
| **面积** | Area | 定量（有偏差） | ⭐⭐⭐ |
| **颜色（色调）** | Hue | 定性（分类） | ⭐⭐⭐ |
| **颜色（亮度/饱和度）** | Luminance | 定量（序列） | ⭐⭐ |
| **形状** | Shape | 定性（分类） | ⭐⭐ |

### Cleveland & McGill 感知精度实验结论

通过严格的人类感知实验，确定了以下排名（从最精确到最不精确）：

$$\text{位置} > \text{长度} > \text{角度} > \text{面积} > \text{颜色深浅} > \text{颜色色调}$$

**实践指导**：
- **定量比较**：优先用位置（柱状图）而非角度（饼图）或面积（气泡图）
- **类别区分**：用颜色色调（不超过 8-10 个类别，超过则难以区分）
- **连续变量**：用颜色渐变（Sequential Color Scale）

### Tufte 的数据墨水比（Data-Ink Ratio）

$$\text{Data-Ink Ratio} = \frac{\text{用于展示数据的墨水量}}{\text{图形中的总墨水量}}$$

目标：**最大化数据墨水比**，删除所有不传递信息的视觉元素（图表垃圾 Chartjunk）：多余的网格线、3D 效果、阴影、装饰性图片。

## 💻 最小 Python 实现 — Matplotlib 最佳实践

```python
import matplotlib.pyplot as plt
import matplotlib.ticker as mticker
import numpy as np

# 高数据墨水比柱状图示例
categories = ['检索召回率', 'Precision@10', 'NDCG@10', 'MRR', 'MAP']
values_a   = [0.82, 0.65, 0.71, 0.58, 0.63]
values_b   = [0.75, 0.72, 0.78, 0.68, 0.70]

fig, ax = plt.subplots(figsize=(8, 4))
x = np.arange(len(categories))
width = 0.35

bars_a = ax.bar(x - width/2, values_a, width, label='BM25', color='#2196F3', alpha=0.85)
bars_b = ax.bar(x + width/2, values_b, width, label='Hybrid(RRF)', color='#FF5722', alpha=0.85)

# 最大化数据墨水比：去除顶部和右侧框线
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.yaxis.set_major_formatter(mticker.PercentFormatter(xmax=1.0))
ax.set_xticks(x)
ax.set_xticklabels(categories, fontsize=9)
ax.set_ylim(0, 1.0)
ax.legend(frameon=False)
ax.set_title('BM25 vs Hybrid Retrieval 评测对比', fontsize=11, pad=10)

# 直接在柱子顶部标注数值（减少眼睛移动）
for bar in bars_a:
    ax.text(bar.get_x() + bar.get_width()/2., bar.get_height() + 0.01,
            f'{bar.get_height():.0%}', ha='center', va='bottom', fontsize=7)

plt.tight_layout()
plt.savefig('retrieval_comparison.png', dpi=150, bbox_inches='tight')
```

## ⚠️ 常见误区与避坑指南

1. **饼图超过 5 个类别**：人眼区分角度的精度极差，超过 5 类的饼图几乎无法准确读出比例。改用水平柱状图（按比例排序）。

2. **双 Y 轴图表（Dual-Axis Chart）**：两个不同量纲的趋势共享 Y 轴，读者容易得出错误的相关性结论。应分为两个独立子图。

3. **使用彩虹色（Rainbow Colormap）展示连续数据**：彩虹色（如 Jet）没有感知均匀性，某些颜色区间显示的数值差异大，实际数值差异小。应使用 Viridis、Plasma 或 Cividis 等感知均匀的色图。

4. **忽略色觉障碍人群**：约 8% 的男性存在红绿色盲。避免用红/绿区分类别；使用 colorbrewer.org 推荐的色觉友好配色。

5. **截断 Y 轴制造误导**：Y 轴不从 0 开始会夸大微小差异，形成"数据说谎"。学术图表中截断 Y 轴必须明确标注并说明原因。
