# 列空间与零空间

> **核心问题**：矩阵 $A$ "能到达哪里"（列空间）？"把什么压成了零"（零空间）？——这两问回答 $A\mathbf{x}=\mathbf{b}$ 的一切。

## 0. 学习边界

| 分类 | 评估 |
|:--|:--|
| 价值等级 | **A** — 四个基本子空间的一半，是"解的存在性与唯一性"的空间语言 |
| 理由 | $A\mathbf{x}=\mathbf{b}$ 有解 ⟺ $\mathbf{b}\in C(A)$；解唯一 ⟺ $N(A)=\{\mathbf{0}\}$ |
| 投入建议 | 必须能从 RREF 找出两空间的基并说出维度 |

## 1. 这个知识点解决什么问题？

[[线性方程组与高斯消元法|1.1]] 用算法判定解；本卡用**空间**回答同一问题：$\mathbf{b}$ 在 $A$ 的列张成的空间内就有解（存在性），零空间只含零向量则解唯一。列空间回答"$A$ 能到达哪里"，零空间回答"哪些方向被 $A$ 吞噬"。

## 2. 它为什么重要？它有什么用？

- **解的存在性**：$\mathbf{b}\in C(A)$ ⟺ 有解——把"秩比较"翻译成"空间包含"。
- **解的唯一性**：$N(A)=\{\mathbf{0}\}$ ⟺ 唯一解；$N(A)$ 的维数 = 自由变量个数 = 解的自由度。
- **秩-零化度**：$\dim C(A) + \dim N(A) = n$（阶段 II 的秩-零化度定理在这里已见雏形）。
- 后续：[[四个基本子空间|四个基本子空间]]（1.10）、最小二乘（阶段 IV：$\mathbf{b}$ 不在 $C(A)$ 时投影到 $C(A)$）。

## 4. 定义复述

### 4.1 列空间（Column Space）

$$C(A) = \{A\mathbf{x} : \mathbf{x}\in\mathbb{R}^n\} = \operatorname{span}\{\text{$A$ 的列向量}\}$$

- 是 $\mathbb{R}^m$ 的子空间（映射的**像**）。
- $A\mathbf{x}=\mathbf{b}$ 有解 ⟺ $\mathbf{b}\in C(A)$。

### 4.2 零空间（Null Space）

$$N(A) = \{\mathbf{x}\in\mathbb{R}^n : A\mathbf{x}=\mathbf{0}\}$$

- 是 $\mathbb{R}^n$ 的子空间（齐次解集）。
- $N(A)$ 的基 = **基础解系**，个数 = $n - \operatorname{rank}(A)$（自由变量个数）。

### 4.3 计算：从 RREF 读出两空间的基

对 $A=\begin{bmatrix}1&1&1\\2&2&2\end{bmatrix}$ 化 RREF 得 $\begin{bmatrix}1&1&1\\0&0&0\end{bmatrix}$（主元列 1）：

- **列空间的基**：原矩阵中**主元列**对应的列——$\{(1,2)^T\}$，$\dim C(A)=1$。
- **零空间的基**：令自由变量 $(x_2,x_3)$ 取 $(1,0),(0,1)$，解 $x_1+x_2+x_3=0$ 得 $\eta_1=(-1,1,0)^T,\ \eta_2=(-1,0,1)^T$——这就是基础解系，$\dim N(A)=2$。
- 验证：$1+2=3=n$ ✓（秩-零化度，阶段 II 严格证明）。

## 5. 直觉与图像

- **列空间**：$A$ 的"射程范围"。$\mathbb{R}^3\to\mathbb{R}^3$ 的矩阵若把空间压成平面，列空间就是那个平面。
- **零空间**：$A$ 的"黑洞"——被压到原点的方向。零空间越大，信息丢失越多，解越不唯一。
- 解 $A\mathbf{x}=\mathbf{b}$：在列空间里找一个组合方式（$\mathbf{x}$ 的选择自由 = 零空间的大小）。

> **一句话本质**：列空间 = 能到达的；零空间 = 被消灭的；两者维度之和 = 输入维度 $n$。

## 6. 定理陈述与证明重建

### 定理：$C(A)$ 与 $N(A)$ 都是子空间

**证明**：$C(A)$ 是 $\{A\mathbf{x}\}$ 的像（映射的像对线性组合封闭，直接验证）；$N(A)$ 是齐次解集（已在 [[向量空间与子空间|1.6]] 证明）。$\square$

### 定理：$A\mathbf{x}=\mathbf{b}$ 的所有解 = 特解 + 零空间（Hefferon §2.2 结构定理）

**前提**：$\mathbf{x}_p$ 是 $A\mathbf{x}=\mathbf{b}$ 的一个特解。

**结论**：$\{\mathbf{x} : A\mathbf{x}=\mathbf{b}\} = \mathbf{x}_p + N(A) = \{\mathbf{x}_p + \mathbf{x}_n : \mathbf{x}_n\in N(A)\}$。

**证明主线**：(⊆) 若 $A\mathbf{x}=\mathbf{b}$ 且 $A\mathbf{x}_p=\mathbf{b}$，则 $A(\mathbf{x}-\mathbf{x}_p)=\mathbf{0}$，故 $\mathbf{x}-\mathbf{x}_p\in N(A)$；(⊇) 若 $\mathbf{x}_n\in N(A)$，则 $A(\mathbf{x}_p+\mathbf{x}_n)=\mathbf{b}+\mathbf{0}=\mathbf{b}$。$\square$

**关键"转念"**：非齐次解集 = 零空间"平移"一个特解——它本身不是子空间（不过原点），但形状由零空间完全决定。

## 7. 经典反例库

### 反例 1：$\mathbf{b}$ 不在列空间 → 无解

$A=\begin{bmatrix}1&0\\0&1\\0&0\end{bmatrix}$，$\mathbf{b}=(1,1,1)^T$：$C(A)=xy$-平面，$\mathbf{b}$ 有 $z$ 分量，无解（$\operatorname{rank}(A)=2<3=\operatorname{rank}([A|\mathbf{b}])$）。

### 反例 2：零空间非零 → 解不唯一

$A=\begin{bmatrix}1&1\\1&1\end{bmatrix}$，$\mathbf{b}=(2,2)^T$：$\mathbf{x}_p=(2,0)^T$ 是特解，$N(A)=\operatorname{span}\{(1,-1)^T\}$，通解 $\mathbf{x}=(2,0)^T+c(1,-1)^T$。

### 反例 3：列空间 ≠ 行空间（维度相同但不同空间）

$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$：$C(A)=\operatorname{span}\{(1,3)^T,(2,4)^T\}=\mathbb{R}^2$，行空间 $=\operatorname{span}\{(1,2),(3,4)\}=\mathbb{R}^2$——作为 $\mathbb{R}^2$ 的子空间两者相等（方阵满秩的特例）；但一般 $m\times n$ 矩阵的列空间在 $\mathbb{R}^m$、行空间在 $\mathbb{R}^n$，**不同空间**。

## 8. 条件变式

| 变式方向 | 具体变化 | 影响 |
|:--|:--|:--|
| 弱化：$\mathbf{b}$ 不在列空间 | 无解 | 退化为最小二乘：投影到 $C(A)$（阶段 IV） |
| 加强：$A$ 满列秩（$n$ 个无关列） | $N(A)=\{\mathbf{0}\}$ | 解唯一（若有解） |
| 换空间：$A^T$ 的列空间 | $C(A^T)$ = 行空间 | 见 [[四个基本子空间\|1.10]] |
| 换对象：线性映射 $T$ | $C(A)\leftrightarrow \operatorname{im}T$，$N(A)\leftrightarrow\ker T$ | 阶段 II 核与像 |
