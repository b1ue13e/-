# 📐 第一阶段：线性方程组与矩阵

> **本阶段核心问题**：给定 $A\mathbf{x}=\mathbf{b}$，解是否存在？是否唯一？如何高效求解？

## 🎯 本阶段学习目标

完成本阶段后，你应该能：
1. 用高斯消元法将任意线性方程组化为行阶梯形（REF）和简化行阶梯形（RREF）
2. 从 RREF 判断解的存在性（无解 / 唯一解 / 无穷多解）并写出通解
3. 理解矩阵乘法的四种等价视角（行×列、列组合、行组合、外积和）
4. 计算逆矩阵（Gauss-Jordan 消元法）并理解可逆的等价条件
5. 将消元过程分解为 $A = LU$（LU 分解）
6. 理解列空间、零空间、行空间、左零空间的概念
7. 掌握线性无关、基、维数的定义并能判定
