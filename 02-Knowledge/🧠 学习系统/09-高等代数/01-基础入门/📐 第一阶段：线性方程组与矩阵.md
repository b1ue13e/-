# 📐 第一阶段：线性方程组与矩阵

> **本阶段核心问题**：给定 $A\mathbf{x}=\mathbf{b}$，解是否存在？是否唯一？如何高效求解？
> **入口**：先完成 [[🧭 高等代数-前置知识|前置诊断]]，再开始 1.1。

## 🎯 本阶段学习目标

完成本阶段后，你应该能：
1. 用高斯消元法将任意线性方程组化为行阶梯形（REF）和简化行阶梯形（RREF）
2. 从 RREF 判断解的存在性（无解 / 唯一解 / 无穷多解）并写出通解（特解 + 基础解系）
3. 理解矩阵运算（加法、乘法、转置、分块）的四种乘法视角并熟练手算
4. 用 Gauss-Jordan 与伴随公式求逆矩阵，默写可逆的 8 条等价条件
5. 把消元过程翻译为 $A = LU$（含 $PA=LU$）并用于多右端求解
6. 验证向量空间八条公理与子空间三条判定；理解张成、相关/无关、基、维数、坐标
7. 从 RREF 找出列空间、零空间、行空间、左零空间的基并写出维度公式
8. 用秩（Rouché–Capelli）对任意方程组做完整分类

## 🔀 易混概念交错辨析（交错练习）

> **交错练习（interleaving）**：把下面几组易混概念**混在同一轮闭卷**做——先写"该用哪个工具 / 查哪个子空间"的判别依据，再回看对应卡的「闭卷验收」核对。纳入各卡「间隔复习节奏」（当天 → 次日 → 第 7 天 → 第 30 天）重做。

1. 给 $A\in\mathbb{R}^{4\times3}$ 与 $\mathbf{b}$，问"$\mathbf{b}$ 能否写成 $A$ 的列组合"应查 **$C(A)$** 还是 **$N(A)$**？问"通解的自由部分由谁张成"又该查哪个？
2. 同一方程组，"仅判断解的存在/唯一性"与"写出通解"——前者可止于 REF 吗？写出必须用 RREF 的硬条件（主元变量 vs 自由变量）。
3. 同一 $A$ 要解 50 个不同 $\mathbf{b}$：用 $LU$（或 $PA=LU$）还是每次 Gauss-Jordan 求逆？依据是运算量还是"是否需要逆本身"？
4. "向量组能张成空间"与"向量组线性无关"是同一断言吗？各对应维数公式里的哪一项（张成 ↔ 维数，无关 ↔ 基的极小性）？

> 判别依据分散在 [[列空间与零空间|1.7]]、[[行阶梯形与简化行阶梯形|1.2]]、[[LU分解|1.5]]、[[线性无关与线性相关|1.8]]、[[基与维数|1.9]]；交错做的价值正是逼你在动手前先"选型"，而非按卡序机械回忆。
