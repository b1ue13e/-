# 四个基本子空间

> **核心问题**：矩阵 $A$（$m\times n$）像"四扇门"通向四个子空间——$A$ 与 $A^T$ 的列空间与零空间。它们如何两两正交互补，共同解释 $A\mathbf{x}=\mathbf{b}$？

## 0. 先判断它值不值得深挖

| 分类 | 评估 |
|:--|:--|
| 价值等级 | **A** — MIT 18.06 的"地图"：一张图看清矩阵的全部信息 |
| 理由 | 四个子空间的维度公式与正交关系是秩-零化度、最小二乘、SVD 的几何底座 |
| 投入建议 | 必须能画出四个子空间关系图并默写维度公式 |

## 1. 这个知识点解决什么问题？

[[列空间与零空间|1.7]] 介绍了 $C(A)$ 与 $N(A)$。但 $A$ 还有"另一半"：$A^T$ 的列空间（= $A$ 的**行空间**）与 $A^T$ 的零空间（**左零空间**）。四个子空间构成矩阵的完整画像：$A$ 把 $\mathbb{R}^n$ 的零空间压成 $\mathbf{0}$、把行空间一一映射到列空间；$\mathbb{R}^n = N(A)\oplus C(A^T)$（阶段 II 直和）。

## 2. 它为什么重要？它有什么用？

- **维度守恒**：$\dim C(A)=\dim C(A^T)=r$，$\dim N(A)=n-r$，$\dim N(A^T)=m-r$。
- **正交分解**：$C(A^T)\perp N(A)$（$\mathbb{R}^n$ 中），$C(A)\perp N(A^T)$（$\mathbb{R}^m$ 中）——阶段 IV 正交补。
- **最小二乘**：$\mathbf{b}$ 投影到 $C(A)$ 的残差落在 $N(A^T)$——正规方程 $A^TA\mathbf{x}=A^T\mathbf{b}$ 的几何解释。
- **SVD**：四个子空间就是 $U,\Sigma,V$ 的列空间分解（阶段 IV）。

## 4. 定义复述

### 4.1 四个基本子空间（MIT 18.06 术语）

| 子空间 | 记号 | 定义 | 所在空间 | 维数 |
|:--|:--|:--|:--|:--|
| 列空间 | $C(A)$ | $\{A\mathbf{x}\}$ = 列的张成 | $\mathbb{R}^m$ | $r$ |
| 零空间 | $N(A)$ | $\{\mathbf{x}: A\mathbf{x}=\mathbf{0}\}$ | $\mathbb{R}^n$ | $n-r$ |
| 行空间 | $C(A^T)$ | $A$ 的行的张成 = $A^T$ 的列空间 | $\mathbb{R}^n$ | $r$ |
| 左零空间 | $N(A^T)$ | $\{\mathbf{y}: A^T\mathbf{y}=\mathbf{0}\}$（即 $\mathbf{y}^TA=\mathbf{0}^T$） | $\mathbb{R}^m$ | $m-r$ |

**维度检验**：$r+(n-r)=n$（$\mathbb{R}^n$ 被 $C(A^T)$ 与 $N(A)$ 分割）；$r+(m-r)=m$（$\mathbb{R}^m$ 被 $C(A)$ 与 $N(A^T)$ 分割）。

### 4.2 基的计算（从 RREF 读出全部四个）

对 $A$ 做消元 $A\to R$（RREF）：

- **$C(A)$ 的基**：$A$ 中主元列对应的原列（$r$ 个）。
- **$N(A)$ 的基**：解 $A\mathbf{x}=\mathbf{0}$ 的基础解系（$n-r$ 个）。
- **$C(A^T)$ 的基**：$R$ 的**非零行**（$r$ 个）——行变换不改变行空间。
- **$N(A^T)$ 的基**：消元过程中的"零行组合"（$m-r$ 个）；或解 $A^T\mathbf{y}=\mathbf{0}$。

例：$A=\begin{bmatrix}1&1&1\\2&2&2\end{bmatrix}$，$R=\begin{bmatrix}1&1&1\\0&0&0\end{bmatrix}$，$r=1$：
- $C(A)=\operatorname{span}\{(1,2)^T\}$；$N(A)=\operatorname{span}\{(-1,1,0)^T,(-1,0,1)^T\}$；
- $C(A^T)=\operatorname{span}\{(1,1,1)\}$；$N(A^T)=\operatorname{span}\{(-2,1)^T\}$（因 $(-2,1)A=\mathbf{0}^T$）。

### 4.3 正交关系（前瞻：阶段 IV 严格定义正交补）

$$\mathbb{R}^n = C(A^T) \oplus N(A),\qquad \mathbb{R}^m = C(A) \oplus N(A^T)$$

且 $C(A^T)\perp N(A)$、$C(A)\perp N(A^T)$：行空间里的向量与零空间里的向量内积为零（因为 $A\mathbf{x}=\mathbf{0}$ 说明每行与 $\mathbf{x}$ 正交）。

## 5. 直觉与图像

经典示意图（MIT 18.06 Lec 10）：

```
   ℝⁿ                          ℝᵐ
┌────────────┐   A (1-1)    ┌────────────┐
│  C(Aᵀ)  r  │ ──────────▶ │  C(A)   r  │
│  行空间     │             │  列空间     │
│            │   A (0)     │            │
│  N(A)  n-r │ ──────────▶ │  0         │
│  零空间     │             │            │
└────────────┘             │  N(Aᵀ) m-r │
                           └────────────┘
```

$A$ 把行空间**一一映射**到列空间（可逆），把零空间全部压成 $\mathbf{0}$；左零空间是"$A$ 够不到的 $\mathbb{R}^m$ 部分"。

> **一句话本质**：四个子空间 = 矩阵的"收入和支出表"——$r$ 维信息无损传递（行空间→列空间），$n-r$ 维被吞噬（零空间），$m-r$ 维从未被触及（左零空间）。

## 6. 定理陈述与证明重建

### 定理：$A\mathbf{x}=\mathbf{b}$ 有解 ⟺ $\mathbf{b}\perp N(A^T)$（Fredholm 替代）

**证明主线**：有解 ⟺ $\mathbf{b}\in C(A)$。而 $C(A)=\{A\mathbf{x}\}$，$N(A^T)=\{\mathbf{y}: A^T\mathbf{y}=\mathbf{0}\}$。由 $\mathbb{R}^m = C(A)\oplus N(A^T)$ 与正交关系，$\mathbf{b}\in C(A)$ ⟺ $\mathbf{b}$ 与 $N(A^T)$ 中所有向量正交。$\square$

**关键"转念"**："无解的方向"恰是左零空间——最小二乘就是把这个方向的残差"豁免"。

### 定理：行秩 = 列秩（$\dim C(A^T)=\dim C(A)$）

**证明主线**：消元 $A\to R$（RREF）：行变换不改变行空间，故 $\dim C(A^T)=\dim C(R^T)=R$ 的非零行数 $=r$；主元列数 $=r$ 恰是列空间的维数。$\square$

## 7. 经典反例库

### 反例 1：行空间与列空间"维度相同但不同世界"

$A$ 为 $2\times 3$：$C(A)\subseteq\mathbb{R}^2$，$C(A^T)\subseteq\mathbb{R}^3$——不是同一个空间，只是维数同为 $r$。

### 反例 2：$N(A)$ 与 $N(A^T)$ 维度不同

$A=\begin{bmatrix}1&1&1\\2&2&2\end{bmatrix}$：$n-r=2$，$m-r=1$——零空间在 $\mathbb{R}^3$（平面），左零空间在 $\mathbb{R}^2$（直线）。

### 反例 3：$A^TA$ 与 $A$ 的四个子空间关系

$N(A^TA)=N(A)$（1.7 习题）：$A^TA$ 的零空间与 $A$ 相同，但 $A^TA$ 的行空间/列空间在 $\mathbb{R}^n$ 中——当 $m<n$ 时 $A^TA$ 奇异（最小二乘的隐患，阶段 IV 处理）。

## 8. 条件变式

| 变式方向 | 具体变化 | 影响 |
|:--|:--|:--|
| 弱化：$r=m$（行满秩） | $N(A^T)=\{\mathbf{0}\}$ | $A$ 有右逆；$AA^T$ 可逆 |
| 加强：$r=n$（列满秩） | $N(A)=\{\mathbf{0}\}$ | $A^TA$ 可逆；最小二乘唯一 |
| 换对象：$A^T$ | 四个子空间角色互换 | 行空间↔列空间，零空间↔左零空间 |
| 换域：复数 | 转置换共轭转置 $A^H$ | 四个子空间理论不变（阶段 IV 酉空间） |
