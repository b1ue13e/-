# 线性方程组解的结构

> **核心问题**：$A\mathbf{x}=\mathbf{b}$ 的全部解长什么样？——"特解 + 齐次通解"，自由度 $n-r$。

## 0. 学习边界

| 分类 | 评估 |
|:--|:--|
| 理由 | "通解 = 特解 + 基础解系"是微分方程、差分方程解结构理论的模板 |
| 投入建议 | 必须能对任意方程组完整写出通解并解释自由度 |

## 1. 这个知识点解决什么问题？

前面各卡分别给了工具：消元（1.1）、阶梯形（1.2）、秩（1.11）、零空间（1.7）。本卡**收官**：用秩三句话分类所有可能（无解/唯一/无穷），并给出无穷解时的完整表达式——**特解 + 齐次通解**，其中齐次通解由基础解系（$n-r$ 个无关向量）张成。

## 2. 它为什么重要？它有什么用？

- **解的分类学**：Rouché–Capelli 定理 $r(A)$ vs $r([A|\mathbf{b}])$。
- **自由度**：$n-r$ = 自由变量数 = 解空间的维数（统计中"自由度"的代数根源）。
- **模板迁移**：常微分方程 $y''+y=0$ 的通解 = 特解 + 齐次通解——同一结构（见常微分方程课程的线性方程组与矩阵方法章节）。
- **欠定系统**：压缩感知、正则化（解不唯一时如何选"好"解）。

## 4. 定义复述

### 4.1 齐次方程组 $A\mathbf{x}=\mathbf{0}$

- 恒有解（$\mathbf{0}$ 是平凡解）；
- 解集 $N(A)$ 是子空间（[[向量空间与子空间|1.6]]）；
- **基础解系**：$N(A)$ 的一组基，含 $n-r$ 个向量；齐次通解 $= c_1\boldsymbol{\eta}_1+\cdots+c_{n-r}\boldsymbol{\eta}_{n-r}$。

**计算流程**：化 RREF → 找出自由变量（非主元列）→ 令每个自由变量轮流取 1、其余取 0，解出主元变量 → 得到基础解系。

### 4.2 非齐次方程组 $A\mathbf{x}=\mathbf{b}$

**结构定理**：若 $\mathbf{x}_p$ 是一个特解，则通解

$$\mathbf{x} = \mathbf{x}_p + \mathbf{x}_h,\qquad \mathbf{x}_h\in N(A)$$

即 **通解 = 特解 + 齐次通解**。

### 4.3 解的分类（Rouché–Capelli）

| 条件 | 结论 |
|:--|:--|
| $r(A) < r([A\mid\mathbf{b}])$ | 无解 |
| $r(A) = r([A\mid\mathbf{b}]) = n$ | 唯一解 |
| $r(A) = r([A\mid\mathbf{b}]) < n$ | 无穷多解，自由度 $n-r$ |

## 5. 直觉与图像

- 齐次解 = 穿过原点的"根"（子空间）；非齐次解 = 这根"根"被特解平移到别处。
- 例（欠定系统 $x_1+x_2+x_3=3$，$2x_1+2x_2+2x_3=6$，实质 1 个方程）：

$$\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix} = \underbrace{\begin{pmatrix}3\\0\\0\end{pmatrix}}_{\text{特解}} + c_1\underbrace{\begin{pmatrix}-1\\1\\0\end{pmatrix}}_{\boldsymbol{\eta}_1} + c_2\underbrace{\begin{pmatrix}-1\\0\\1\end{pmatrix}}_{\boldsymbol{\eta}_2}$$

解是一个**二维平面**（自由度 2）。

> **一句话本质**：非齐次解集 = 零空间 + 一个平移；形状完全由 $A$ 决定，位置由 $\mathbf{b}$ 决定。

## 6. 定理陈述与证明重建

### 定理：通解 = 特解 + 齐次通解（Hefferon §1.5, Lemma 3.7/§1.6）

**前提**：$\mathbf{x}_p$ 是 $A\mathbf{x}=\mathbf{b}$ 的一个解。

**结论**：$\{\mathbf{x}: A\mathbf{x}=\mathbf{b}\} = \mathbf{x}_p + N(A)$。

**证明主线**：
- (⊆) 若 $A\mathbf{x}=\mathbf{b}$ 且 $A\mathbf{x}_p=\mathbf{b}$，则 $A(\mathbf{x}-\mathbf{x}_p)=\mathbf{0}$，即 $\mathbf{x}-\mathbf{x}_p\in N(A)$；
- (⊇) 若 $\mathbf{x}_h\in N(A)$，则 $A(\mathbf{x}_p+\mathbf{x}_h)=\mathbf{b}+\mathbf{0}=\mathbf{b}$。$\square$

**关键"转念"**：两个非齐次解的**差**是齐次解——"解集是一个仿射空间（子空间的平移）"。

### 推论：基础解系个数 = $n-r$

**证明主线**：$N(A)$ 的维数 $=n-\dim C(A)=n-r$（秩-零化度定理，阶段 II 严格证明；本阶段由"自由变量数 $=n-$ 主元列数"直接得到）。$\square$

## 7. 经典反例库

### 反例 1：$r(A)<r([A|\mathbf{b}])$ 无解

$\begin{cases}x+y=1\\x+y=2\end{cases}$：$r(A)=1$，$r([A|\mathbf{b}])=2$，无解（矛盾方程）。

### 反例 2：特解不唯一，但通解形式等价

$\begin{cases}x+y=3\\x-y=1\end{cases}$：$(2,1)$ 与 $(1,2)$？后者代入 $x-y=-1\neq1$ 不是解——注意特解必须真代入。若取 $\mathbf{x}_p=(2,1)$，零空间 $\{0\}$，通解唯一。

### 反例 3：$A\mathbf{x}=\mathbf{b}$ 的解集不是子空间

$A=[1]$，$\mathbf{b}=[1]$：解集 $\{1\}$ 不含 $\mathbf{0}$，不是子空间——它是零空间 $\{0\}$ 平移到 1。

## 8. 条件变式

| 变式方向 | 具体变化 | 影响 |
|:--|:--|:--|
| 弱化：$\mathbf{b}=\mathbf{0}$ | 齐次 | 解集是子空间，通解 = 基础解系组合 |
| 加强：$A$ 方阵可逆 | $r=n$ | 唯一解 $\mathbf{x}=A^{-1}\mathbf{b}$ |
| 换对象：$A$ 非方阵列满秩 | $r=n<m$ | 最多唯一解（超定系统，最小二乘见阶段 IV） |
| 推广：微分方程 | $Ly=0$ 与 $Ly=f$ | 同样的"特解+齐次通解"结构 |
