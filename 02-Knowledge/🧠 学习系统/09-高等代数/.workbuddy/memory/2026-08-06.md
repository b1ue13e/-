### ⚠️ 重要教训（本仓库必须遵守）
1. **禁止使用 `git rm` 批量或单文件删除含 emoji/全角字符路径下的文件**——Windows 上会随机误删同目录其他文件（本会话发生 2 次事故：01-基础入门 与 04-精通拓展 目录工作区文件被连带删除，均靠 git restore + 重写恢复）。正确做法：**cp 到 .recovery-hold → 物理移动/删除（mv 或 Python）→ git add -A 记录**。
2. **并行会话共享暂存区**：git add 后若其他会话提交，暂存内容会被并入其提交（本会话 B-S4 主体被并入运筹学提交 6a87d07）。提交后必须核对 commit 实际包含文件（`git show --stat`），发现异常立即查 `git log --graph`。
3. 删除文件还会被沙箱回收站保护拦截（回收站不可用）——mv 到 .recovery-hold 是可靠替代（源文件消失 = 等效删除且保留副本）。
4. 表格内 wikilink 用 `\|` 转义；跨目录链接用 vault 根相对路径（`02-Knowledge/...`）；脚本（preflight/verify_links）只匹配 `🧭*.md` 为 MOC——本课程 MOC 用 📐/🎨/🌟/🚀 前缀，STAGE_MOC_COUNT 报错为工具噪声。
