# 子空间的交与和

> **核心问题**：两个子空间如何"求交"、"合并"？合并后的集合还是子空间吗？维度怎么算？

## 0. 先判断它值不值得深挖

| 分类 | 评估 |
|:--|:--|
| 价值等级 | **A** — 维数公式 $\dim(U+W)=\dim U+\dim W-\dim(U\cap W)$ 是"用维度算信息"的样板 |
| 理由 | 交与和是子空间的两种合成方式；直和（2.2）与维数公式（2.3）都从这里长出来 |
| 投入建议 | 必须能证明"交是子空间、并不是"并熟练计算 $U+W$ 与 $U\cap W$ 的基 |

## 1. 这个知识点解决什么问题？

[[向量空间与子空间|1.6]] 的子空间判定只处理单个子集。现实中子空间经常"成对出现"（如 $C(A)$ 与 $N(A^T)$、$W$ 与补空间）。本卡定义两种合成：**交** $U\cap W$（两者共同部分）与**和** $U+W=\{u+w:u\in U,w\in W\}$（两者张成的最大空间），并回答：交总是子空间，**并不是**——"和"才是正确的合并操作。

## 2. 它为什么重要？它有什么用？

- **维数公式**：$\dim(U+W) = \dim U + \dim W - \dim(U\cap W)$——"并集信息 = 两边之和 - 重复部分"。
- **四个基本子空间**：$\mathbb{R}^n = C(A^T) + N(A)$（且是直和，2.2）。
- **解的结构**：特解 + 零空间本质是"子空间 + 平移"。
- **后续**：直和、补空间、商空间（高等代数第 5 版第 4 章）。

## 4. 定义复述

### 4.1 交与和（Hefferon §2.7）

设 $U,W$ 是 $V$ 的子空间：

- **交** $U\cap W = \{\mathbf{v} : \mathbf{v}\in U \text{ 且 } \mathbf{v}\in W\}$；
- **和** $U+W = \{\mathbf{u}+\mathbf{w} : \mathbf{u}\in U,\ \mathbf{w}\in W\}$。

**定理**：$U\cap W$ 与 $U+W$ 都是 $V$ 的子空间。

**并 $U\cup W$ 一般不是子空间**（反例见下）。

### 4.2 基的计算

- $U\cap W$：解 $\mathbf{v}\in U$ 且 $\mathbf{v}\in W$（联立两组约束）。
- $U+W$：取 $U$ 的基与 $W$ 的基之并，剔除相关冗余（极大无关组）。

例：$U=\operatorname{span}\{(1,1,0),(0,1,1)\}$（平面），$W=\operatorname{span}\{(1,0,1)\}$（直线）：
- $U+W$：三向量 $(1,1,0),(0,1,1),(1,0,1)$ 是否无关？$c_1(1,1,0)+c_2(0,1,1)+c_3(1,0,1)=0$ 得 $c_1=-c_3,\ c_1+c_2=0,\ c_2+c_3=0$ → 唯一零解，无关 → $\dim(U+W)=3=\dim\mathbb{R}^3$，$U+W=\mathbb{R}^3$。
- $U\cap W$：$\mathbf{v}=a(1,1,0)+b(0,1,1)=c(1,0,1)$。由 $a=c,\ a+b=0,\ b=c$ → $a=c,\ b=-a,\ -a=a$ → $a=0$ → $\mathbf{v}=\mathbf{0}$ → $U\cap W=\{\mathbf{0}\}$。
- 验证维数公式：$3 = 2+1-0$ ✓。

## 5. 直觉与图像

- **交** = 两个平面的"公共线/公共点"；**和** = 两个平面共同"撑起"的最大空间。
- 并集失败的原因：$(1,0)\in x$-轴、$(0,1)\in y$-轴，但 $(1,0)+(0,1)=(1,1)$ 不在任一轴上——**加法需要闭合空间**，并集不闭合。

> **一句话本质**：和 = 子空间的"正确合并"（加法闭包）；交 = 子空间的"公共部分"；两者通过维数公式勾连。

## 6. 定理陈述与证明重建

### 定理 1：$U\cap W$ 与 $U+W$ 是子空间（Hefferon Lemma 2.9）

**证明主线（交）**：$\mathbf{0}\in U\cap W$；若 $\mathbf{v}_1,\mathbf{v}_2\in U\cap W$，则其在 $U$ 中封闭、在 $W$ 中也封闭，故组合属于两者。**（和）**：$\mathbf{0}=\mathbf{0}+\mathbf{0}$；$(\mathbf{u}_1+\mathbf{w}_1)+(\mathbf{u}_2+\mathbf{w}_2)=(\mathbf{u}_1+\mathbf{u}_2)+(\mathbf{w}_1+\mathbf{w}_2)$，数乘同理。$\square$

### 定理 2：维数公式（Hefferon §2.7 / 高等代数第 4 章）

$$\dim(U+W) = \dim U + \dim W - \dim(U\cap W)$$

**证明主线**：取 $U\cap W$ 的基 $\{\boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_k\}$，扩充为 $U$ 的基 $\{\boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_k,\boldsymbol{\alpha}_{k+1},\dots,\boldsymbol{\alpha}_p\}$ 与 $W$ 的基 $\{\boldsymbol{\beta}_1,\dots,\boldsymbol{\beta}_k,\boldsymbol{\gamma}_{k+1},\dots,\boldsymbol{\gamma}_q\}$。证明 $S=\{\boldsymbol{\beta}_i\}\cup\{\boldsymbol{\alpha}_j\}\cup\{\boldsymbol{\gamma}_\ell\}$ 是 $U+W$ 的基：
1. **张成**：$U+W$ 中任意向量是 $U$ 元素与 $W$ 元素之和，各由对应基表示；
2. **无关**：设 $\sum b_i\boldsymbol{\beta}_i+\sum a_j\boldsymbol{\alpha}_j+\sum c_\ell\boldsymbol{\gamma}_\ell=\mathbf{0}$，移项得 $\sum a_j\boldsymbol{\alpha}_j = -\sum b_i\boldsymbol{\beta}_i - \sum c_\ell\boldsymbol{\gamma}_\ell \in U\cap W$，故可被 $\boldsymbol{\beta}$ 表示，由 $U$ 的基无关性得所有系数为零，逐项推出。$\square$

于是 $\dim(U+W)=k+(p-k)+(q-k)=p+q-k=\dim U+\dim W-\dim(U\cap W)$。$\square$

**关键"转念"**：维数公式是"包含-排除原理"的线性代数版本——重复部分（交）被减掉一次。

## 7. 经典反例库

### 反例 1：$U\cup W$ 不是子空间

$U=x$-轴，$W=y$-轴：$(1,0)+(0,1)=(1,1)\notin U\cup W$。**和** $U+W=\mathbb{R}^2$ 才是合并的正确方式。

### 反例 2：$\dim(U\cap W)$ 可能为零但 $U,W$ 都很大

$\mathbb{R}^3$ 中两个不同平面过原点：交是一条直线（$\dim=1$）；若两个平面相同则交是平面（$\dim=2$）。"$\dim U+\dim W>n$ 则交非零"——重要推论：$\dim U+\dim W > \dim V$ ⟹ $U\cap W\neq\{\mathbf{0}\}$。

### 反例 3：维数公式对"并"不成立

$\dim(U\cup W)$ 无定义（不是子空间）——不能把公式套到并集上。

## 8. 条件变式

| 变式方向 | 具体变化 | 影响 |
|:--|:--|:--|
| 弱化：$U\cap W=\{\mathbf{0}\}$ | 直和（2.2） | 维数公式退化：$\dim(U+W)=\dim U+\dim W$ |
| 加强：$U+W=V$ 且交为零 | $V=U\oplus W$ | 唯一分解（2.2） |
| 换对象：三个子空间 | 维数公式推广（含交叉项） | 需要容斥式的推广（高等代数习题） |
| 换视角：线性映射 | $\ker T$ 与 $\operatorname{im}T$ | 秩-零化度定理（2.6）是维数公式的映射版本 |
