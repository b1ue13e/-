# 特征值与特征向量 (Eigenvalues and Eigenvectors)

## 1. 特征值与特征向量的定义与几何映射

**特征值与特征向量 (Eigenvalues and Eigenvectors)** 的核心定义是：在 $n$ 维线性空间中，描述线性变换 $\mathbf{A}$ 在某个特定非零向量 $\mathbf{v}$ 作用下仅发生**模长伸缩变化**而**保持方向（或反向）不变**的代数与几何特征。由 Euler, Cauchy 和 Hilbert 等人建立理论体系。

**基本性质**：
1. **方向不变性**：线性变换 $A \mathbf{v}$ 对特征向量 $\mathbf{v}$ 的作用等价于纯标量乘法 $\lambda \mathbf{v}$；
2. **迹与行列式恒等式**：
   - 所有特征值之和等于矩阵的迹 (Trace)：$\sum_{i=1}^n \lambda_i = \text{tr}(A)$
   - 所有特征值之积等于矩阵的行列式 (Determinant)：$\prod_{i=1}^n \lambda_i = \det(A)$
3. **对称阵谱定理 (Spectral Theorem)**：若 $A$ 为实对称矩阵，则其所有特征值均为实数，且存在由正交特征向量组成的完备正交基。

---

## 2. 特征多项式与谱定理形式化推导

**线性变换方程假设**：
设 $A \in \mathbb{R}^{n \times n}$，非零向量 $\mathbf{v} 
e \mathbf{0}$，标量 $\lambda \in \mathbb{C}$。

$$A \mathbf{v} = \lambda \mathbf{v} \iff (A - \lambda I) \mathbf{v} = \mathbf{0}$$

**推导过程（特征多项式与重数）**：
1. 由于 $\mathbf{v} 
e \mathbf{0}$，齐次线性方程组 $(A - \lambda I) \mathbf{v} = \mathbf{0}$ 存在非零解的充要条件是系数矩阵非满秩：
$$P(\lambda) = \det(A - \lambda I) = 0$$
$P(\lambda)$ 称为矩阵 $A$ 的**特征多项式 (Characteristic Polynomial)**；
2. 代数基本定理保证 $P(\lambda) = 0$ 在复数域内恰有 $n$ 个根 $\lambda_1, \dots, \lambda_n$（按代数重数计）；
3. **实对称阵特征值必为实数证明**：设 $A = A^T$，$A \mathbf{v} = \lambda \mathbf{v}$。两边共轭转置乘 $\mathbf{v}$：
$$\mathbf{v}^H A \mathbf{v} = \lambda \mathbf{v}^H \mathbf{v}$$
由于 $\mathbf{v}^H A \mathbf{v} = (A \mathbf{v})^H \mathbf{v} = (\lambda \mathbf{v})^H \mathbf{v} = \bar{\lambda} \mathbf{v}^H \mathbf{v}$；
4. **因此**，$\lambda \mathbf{v}^H \mathbf{v} = \bar{\lambda} \mathbf{v}^H \mathbf{v}$，因为 $\mathbf{v}^H \mathbf{v} > 0$，推导出 $\lambda = \bar{\lambda}$，即实对称阵特征值均为实数。

## 3. 特征值分解 (EVD) 与 矩阵代数运算对比

| 矩阵性质 | 特征值 $\lambda_i$ 规律 | 特征向量正交性 | 可对角化充要条件 |
|:---|:---|:---|:---|
| **实对称阵 ($A=A^T$)** | **全为实数** | **必定正交** ($V^T V = I$) | 恒可对角化 ($A = V \Lambda V^T$) |
| **正定矩阵 ($A \succ 0$)** | **全部严格大于零 ($\lambda_i > 0$)** | 必定正交 | 恒可对角化 |
| **正交矩阵 ($Q^T Q = I$)** | **模长全为 1 ($|\lambda_i| = 1$)** | 对应复数域正交 | 在复数域可对角化 |
| **幂零矩阵 ($A^k = 0$)** | **全部为零 ($\lambda_i = 0$)** | 几何重数低于代数重数 | **不可对角化** (须化为 Jordan 块) |

**局限（误区与反例）**：当代数重数大于几何重数（特征空间维度）时，矩阵不可对角化（缺陷矩阵 Defective Matrix）；此外非对称矩阵的特征向量不具备正交性。

关联知识点推荐：[[奇异值分解SVD]]、[[主成分分析PCA]]、[[反向传播算法BP]]、[[群论基础与拉格朗日定理]]。

## 4. Python Numpy 特征值求解与迹/行列式自测断言

```python
import numpy as np

def verify_eigen_properties(A: np.ndarray) -> tuple:
    """验证矩阵特征值与迹、行列式的数学恒等式"""
    vals, vecs = np.linalg.eig(A)

    trace_sum = np.sum(vals)
    det_prod = np.prod(vals)

    actual_trace = np.trace(A)
    actual_det = np.linalg.det(A)

    return vals, vecs, trace_sum, det_prod, actual_trace, actual_det

if __name__ == "__main__":
    # 测试实对称矩阵 A
    A = np.array([
        [4.0, 2.0],
        [2.0, 3.0]
    ])

    vals, vecs, t_sum, d_prod, a_trace, a_det = verify_eigen_properties(A)

    # 自测验证 1: A v == \lambda v 方程断言
    for i in range(len(vals)):
        v = vecs[:, i]
        assert np.allclose(A @ v, vals[i] * v), f"第 {i} 个特征对不满足 A v = lambda v"

    # 自测验证 2: 迹恒等式 sum(\lambda_i) == trace(A)
    assert abs(t_sum - a_trace) < 1e-5, f"迹不等: {t_sum} vs {a_trace}"

    # 自测验证 3: 行列式恒等式 prod(\lambda_i) == det(A)
    assert abs(d_prod - a_det) < 1e-5, f"行列式不等: {d_prod} vs {a_det}"

    # 自测验证 4: 实对称阵特征向量正交性断言 V^T V == I
    assert np.allclose(vecs.T @ vecs, np.eye(2)), "对称阵特征向量必须正交"

    print(f"特征值与特征向量求解成功: \lambda = {vals.round(4)}")
    print(f"迹: {t_sum:.4f} (理论: {a_trace:.4f}), 行列式: {d_prod:.4f} (理论: {a_det:.4f})")
    print("特征值与特征向量单元测试与自查验证全部成功！")
```
