# 🧭 开源作业体系-高等代数

> **教材主线**：[Hefferon *Linear Algebra*](https://hefferon.net/linearalgebra/) (CC BY-SA) | **验收源**：[MIT 18.06SC](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/)

## 📚 资源角色

| 角色 | 来源 | 许可 | 用途 |
|:---|:---|:---|:---|

## 🎯 作业体系（按 MIT 18.06SC 三单元组织）

### Unit I: $A\mathbf{x}=\mathbf{b}$ and the Four Subspaces → 阶段 I-II

| Problem Set | 主题 | Hefferon | 核心知识点 |
|:---|:---|:---|:---|
| PS1 | 线性方程组几何与高斯消元 | §1.1-1.3 | 消元法、行阶梯形、回代 |
| PS2 | 矩阵乘法与逆矩阵 | §1.4 | 矩阵运算、Gauss-Jordan、可逆条件 |
| PS3 | LU 分解与向量空间 | §2.1-2.2 | LU分解、子空间、列空间、零空间 |
| PS4 | 线性无关、基、维数 | §2.3-2.6 | 相关性判定、基、维数、秩 |
| PS5 | 四个基本子空间 | §2.5 | 行空间、零空间转置关系 |

### Unit II: Least Squares, Determinants and Eigenvalues → 阶段 III-IV(前半)

| Problem Set | 主题 | Hefferon | 核心知识点 |
|:---|:---|:---|:---|
| PS6 | 正交性与投影 | §6.1-6.3 | 内积、Cauchy-Schwarz、正交投影 |
| PS7 | Gram-Schmidt 与最小二乘 | §6.4-6.6 | QR分解、正规方程、最小二乘解 |
| PS8 | 行列式 | §4.1-4.6 | 行列式性质、Laplace、Cramer法则 |
| PS9 | 特征值与特征向量 | §5.1-5.2 | 特征多项式、$\det(A-\lambda I)=0$ |
| PS10 | 对角化 | §5.3 | 可对角化条件、$A=PDP^{-1}$ |

### Unit III: Positive Definite Matrices and Applications → 阶段 IV(后半)

| Problem Set | 主题 | Hefferon | 核心知识点 |
|:---|:---|:---|:---|
| PS11 | 对称矩阵与正定性 | — | 实对称谱定理、正定判定、二次型 |
| PS12 | SVD 奇异值分解 | — | $A=U\Sigma V^T$、Eckart-Young、PCA |

## ✅ 验收方式

1. **每个 PS 三件套**：
   - ① 闭卷手算（从 MIT 18.06SC Problem Set 抽取 5-8 题）
   - ② NumPy/SymPy 数值验证
   - ③ 1 页「动机复盘」（这个 PS 解决了什么核心问题？）
2. **计算与证明并重**：每个 PS 至少 1 个证明题
3. **满分 Rubric**：PS1-12 各 ~8 分，共 100 分
