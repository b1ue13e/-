# 🧭 高等代数-前置知识

> **进入本课程的最低标准**：能独立完成下方「诊断入口」全部问题。未达标者按顺序补学前置卡后重测。

---

## 为什么需要前置层

高等代数（Hefferon *Linear Algebra* Ch.1-6 + MIT 18.06SC）从线性方程组起步，**不需要微积分、不需要任何大学数学背景**，但定理的证明与反例构造依赖三项"数学成熟度"：

1. **集合与函数的语言**——向量空间的定义是"集合 + 两种运算 + 八条公理"，不懂集合与映射就无法读定义；
2. **逻辑与量词**——"存在 $n$ 个线性无关向量"、"对任意 $v \in V$"这类命题必须能精确解析；
3. **证明方法**——秩-零化度定理、维数公式、谱定理的证明大量使用直接证明、反证法与数学归纳法。

这三项是公共数学基础，已由 `04-离散数学` 高质量完成，本课程直接复用，不重复建卡。

## 🔍 诊断入口

闭卷回答以下问题（每题 ≤ 5 分钟）。全部正确即可进入 [[🗺️ 高等代数学习路径|高等代数学习路径]] 阶段 I；否则按 P1-P5 顺序补学对应前置卡：

1. 设 $A = \{1,2,3\}$，$B = \{2,3,4\}$。写出 $A \cap B$、$A \cup B$、$A \setminus B$，并判断 $A \subseteq B$ 是否成立。
2. 判断以下命题真假，并说明理由："存在整数 $n$ 使得 $n^2 = 2$"（提示：反证）。
3. 用反证法证明：$\sqrt{2}$ 不是有理数。
4. 用数学归纳法证明：$1 + 2 + \cdots + n = \dfrac{n(n+1)}{2}$ 对所有正整数 $n$ 成立。
5. 解释 $p \to q$ 与 $\neg q \to \neg p$ 为什么逻辑等价（可画真值表）。

**通过标准**：5/5 正确。若 4/5 以下，重读对应前置卡 3 天后复测。
