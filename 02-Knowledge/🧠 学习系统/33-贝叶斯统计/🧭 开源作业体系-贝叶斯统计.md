# 🧭 开源作业体系-贝叶斯统计

> 本页是「贝叶斯统计」开源教材与作业的**唯一挂载点**：教材主线、作业链 HW01-HW06、知识点覆盖矩阵、验收方式全部在此对齐。作业体系来源：**PyMC 官方 Examples 与教程**（https://docs.pymc.io/en/stable/examples.html ，新址 https://www.pymc.io/projects/examples/en/latest/ ），手算与理论部分以《Statistical Rethinking》/《Bayesian Data Analysis》为参考，开源讲义 Bayes Rules! 负责主线教材（见 [[📚 教材挂载索引]]）。

## 📚 教材主线（Spine）

| 角色 | 来源 | 用途 |
|:---|:---|:---|
| 主线教材（开源讲义） | *Bayes Rules!*（https://www.bayesrulesbook.com/） | 先验/似然/后验、共轭家族、回归与层次模型的章节主线，HW 的理论落点 |
| 官方实践与验收源 | PyMC 官方 Examples（https://docs.pymc.io/en/stable/examples.html）与教程（Getting Started / API 文档） | 每个 HW 一个对应 example：复现官方 notebook → 换成自己的数据/先验 → 形成作业交付 |
| 理论参考 | *Statistical Rethinking*（McElreath）、*Bayesian Data Analysis* 3e（Gelman 等） | 采样直觉、模型比较、层次建模的深度参考；BDA 第 10-11 章（MCMC）与第 6-7 章（模型检查）为 HW02/HW05 的权威依据 |
| 配套工具 | PyMC + ArviZ（`az.summary` / `az.plot_trace` / `az.loo`） | 采样、诊断（R-hat/ESS/trace）、后验预测与模型比较的统一工具链 |

**Honor Code 说明**：PyMC Examples 与教程代码可阅读、可复现（记录来源 URL 与 commit），但作业交付必须**换数据或换先验、自己重写模型**并附完整推理；手算题（HW01/HW02）必须闭卷独立完成后再对照讲义复盘；不复制官方 notebook 直接提交。

| HW | 主题 | 官方来源（PyMC 对应 example） | 所需知识点（双链） | 验收方式 |
|:---|:---|:---|:---|:---|
| HW01 | 贝叶斯定理与共轭先验（手算） | PyMC 教程 Getting Started：Bayesian Inference（https://www.pymc.io/projects/docs/en/stable/learn.html ）概念对照，主体为手算 | [[贝叶斯定理与共轭先验]]、条件概率 | 闭卷手算 Beta-Binomial 与 Normal-Normal 后验（含归一化常数）；共轭更新结果与 PyMC 数值后验对比一致 |
| HW02 | MCMC 与 Metropolis-Hastings（手撕） | PyMC 文档 MCMC/HMC 章节 + Examples `samplers` 系列（对照官方采样器行为） | [[MCMC与MetropolisHastings]]、[[贝叶斯定理与共轭先验]] | 手写 MH 采样器复现单参数后验；对比 PyMC 采样结果；调参（步长/链数）并给出 burn-in 取舍与接受率报告 |
| HW03 | NUTS 与 PyMC 建模流程（线性回归后验） | Examples `generalized_linear_models/GLM_linear`（https://www.pymc.io/projects/examples/en/latest/generalized_linear_models/GLM_linear.html ） | [[NUTS与PyMC建模流程]]、[[MCMC与MetropolisHastings]]、[[贝叶斯定理与共轭先验]] | 五步建模跑通；R-hat<1.01、ESS>400（`az.summary` 存档）；trace/后验图入库；后验预测区间覆盖检验 |

| HW05 | 后验预测检查与模型比较 | Examples `case_studies/model_comparison`（https://www.pymc.io/projects/examples/en/latest/case_studies/model_comparison.html ）+ PyMC 文档 Posterior Predictive Checks | [[后验预测检查与模型比较]]、[[NUTS与PyMC建模流程]] | PPC 图 + 检验统计量 + 贝叶斯 p 值；WAIC/LOO 比较至少 3 个候选模型；敏感性分析（换先验/换数据子集）报告 |
| HW06 | A/B 测试或分层模型完整项目 | Examples `case_studies/radon`（https://www.pymc.io/projects/examples/en/latest/case_studies/radon.html ）分层案例；A/B 参照 PyMC 官方 A/B testing 教程 | 全部前置 + 决策解释（见 [[📋 知识点卡清单]]） | Capstone：先验预测 → 采样诊断（R-hat/ESS/trace）→ 后验预测检查 → 敏感性分析 → 决策解释，五段报告存档到 `03-Projects/` |

> 分层验收原则：HW01-02 是**手算/手撕链**（必须闭卷独立完成）；HW03-05 是**建模链**（每 HW 必须交收敛诊断 + 后验预测 + 敏感性分析三件套）；HW06 是 **Capstone 全流程**（五段报告为满分门槛）。

## ✅ 验收方式与评分

1. **建模复现**：每个 HW 用 PyMC 复现官方对应 example（记录来源 URL），再换数据/换先验重写模型，代码与运行结果存档。
2. **采样诊断**：`az.summary` 给出 R-hat、ESS，R-hat < 1.01 且 ESS > 400；trace 图无发散/无粘滞；HW02 手撕采样器附接受率与 burn-in 说明。
3. **后验预测检查报告**：PPC 图 + 1-2 个检验统计量（均值/极值/分组均值）+ 贝叶斯 p 值解读。
4. **敏感性分析**：至少一次"换先验 或 换数据子集"，结论稳健性讨论（HW03 起必交）。
5. **决策解释**：把后验/预测区间翻译成可执行结论（"该不该上线/该选哪个方案/不确定度有多大"），HW06 Capstone 必须五段齐全。
6. **满分 Rubric**：HW01-02 手算/手撕全对（20 分）+ HW03-05 三件套齐全且诊断通过（45 分）+ HW06 Capstone 五段报告（35 分），共 100 分。
