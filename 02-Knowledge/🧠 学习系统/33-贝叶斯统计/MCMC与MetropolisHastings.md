# MCMC与MetropolisHastings

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW02 是唯一要求"手撕采样器"的作业——不亲手写出接受-拒绝逻辑，就无法理解 NUTS 为何存在、R-hat 在诊断什么。MH 是现代 MCMC（HMC/NUTS）的祖辈，是 [[🧭 开源作业体系-贝叶斯统计]] 中 HW02-HW06 的共同底层。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：贝叶斯后验的归一化常数 $P(y)=\int P(y|\theta)P(\theta)d\theta$ 在高维几乎算不出来，于是后验"只有形状、没有刻度"；共轭只覆盖极少数模型，回归、层次模型全部中招。网格积分维数一高就爆炸，重要性采样权重退化。因此引入 **MCMC**：构造一条马尔可夫链，让它长期游走后访问每个位置的频率恰好等于后验密度——**Metropolis-Hastings 算法**给出通用构造法，只要求能算"未归一化的后验形状"，不要求积分。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：不学它，HW03 的 NUTS 无法解释（NUTS 只是 MH 的"聪明提议"版），HW05 的模型比较没有样本可用。它把贝叶斯推断从"少数可手算模型"推广到"任意模型"。
- **实际应用场景**：PyMC/Stan 的引擎底层；Ising 模型等物理模拟、计量经济学、贝叶斯神经网络的后验采样。**高频题型/任务**：写出 MH 更新步骤；计算接受率；分析步长对混合速度的影响；判断链是否收敛（burn-in、trace、R-hat）。

---

## 3. 学它之前需要哪些前置知识？

1. **[[贝叶斯定理与共轭先验]]**：MH 的目标分布就是后验（只需未归一化版本）。
2. **马尔可夫链与平稳分布**：转移矩阵、不可约/非周期、平稳分布唯一——MH 正确性的理论语言。
3. **大数定律与蒙特卡洛**：为什么"样本均值 → 期望"；MCMC 只是把 iid 换成相关的链。

---

## 4. 用直觉语言解释它

> «"MH 采样像雾天爬山：随机朝一个方向迈一步，前方更高（后验密度更大）就过去，更低就按比例赌一把——赌输就留在原地。走很久以后，你在每个高度停留的时间比例，正好等于这个高度的真实分布。"»

- **直觉类比/几何图像**：后验密度是"地形"，MH 是"带随机性的爬山者"；"赌一把"保证不会永远困在局部峰。
- **为什么很自然**：因为"访问频率 ∝ 密度"正是平稳分布的直觉定义；接受率让"向上走"与"向下走"的流量在任意两点间平衡（细致平衡）。**一句话直觉本质**：**设计"随机游走 + 接受/拒绝"规则，使链的平稳分布恰好等于目标后验，然后把链的样本当后验样本用。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **MCMC**：构造以目标分布 $\pi$ 为唯一平稳分布的马尔可夫链，丢弃预热期后，用链上样本的均值估计 $\mathbb{E}_\pi[f]$。**Metropolis-Hastings**：给定当前状态 $x$，从提议分布 $q(x'|x)$ 抽候选 $x'$，以接受率 $\alpha$ 接受，否则停留在 $x$。

### 2. 核心公式

**接受率**：$$\alpha(x,x')=\min\!\left(1,\ \frac{\pi(x')\,q(x\mid x')}{\pi(x)\,q(x'\mid x)}\right)$$

**对称提议（Metropolis 特例，如随机游走 $q(x'|x)=N(x,\sigma^2)$）**：$$\alpha=\min\!\left(1,\ \frac{\pi(x')}{\pi(x)}\right)$$

**细致平衡（平稳分布的充分条件）**：$$\pi(x)\,P(x\to x')=\pi(x')\,P(x'\to x),\qquad P(x\to x')=q(x'\mid x)\,\alpha(x,x')$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\pi(\theta)$ | 目标分布（未归一化后验） | $\propto P(y\mid\theta)P(\theta)$ | 只需算到比例常数 |
| $q(\theta'\mid\theta)$ | 提议分布 | 概率密度 | 随机游走常用 $N(\theta,\sigma^2)$ |
| $\alpha$ | 接受率 | $[0,1]$ | 接受候选的概率 |
| $\sigma$（步长） | 提议尺度 | $>0$ | 调参核心旋钮 |
| burn-in | 预热期样本 | 整数 | 丢弃，让链进入平稳 |

### 4. 常见变体与适用条件
- **变体**：随机游走 Metropolis（对称提议）、独立 MH、Gibbs 采样（逐分量条件采样，接受率恒 1）、自适应 MH。
- **适用/限制**：目标密度可逐点求值、低维或提议接近目标时效率可接受；高维强相关后验下随机游走效率指数级下降，应换 HMC/NUTS（见 [[NUTS与PyMC建模流程]]）。

---

## 6. 推导思路和思想来源

- **最初困难**：直接构造"访问频率 = 目标密度"的随机过程看似不可能。**直接方法局限**：重要性采样权重退化；拒绝采样高维几乎全拒绝。
- **关键"转念"**：不要求一步到位——**允许相关、允许拒绝**，只要链的"长期访问频率"等于 $\pi$；问题转化为设计转移核 $P$ 使 $\pi$ 是其平稳分布。
- **推导主线与动机**：任选对称提议 $q$ → 原始转移的平稳分布不是 $\pi$ → 引入接受率修正流量 → 令细致平衡成立解出 $\alpha=\min(1,\ \pi(x')q(x|x')/\pi(x)q(x'|x))$ → 得 MH 算法；收敛性由马尔可夫链理论（不可约+非周期+细致平衡 ⇒ 唯一平稳分布）保证。
- **为什么自然得到此结论**：细致平衡是"流量守恒"的直接翻译——两状态间正向流量等于反向流量，分布不再漂移；接受率正是让守恒成立的"阀门"。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：目标 $\pi(\theta)\propto \theta^8(1-\theta)^2$（$\mathrm{Beta}(9,3)$ 未归一化密度）。当前 $\theta=0.5$，对称提议 $\theta'=0.6$。求接受率。
- **解题思路与关键步骤**：对称提议下 $\alpha=\min(1,\ \pi(0.6)/\pi(0.5))$。$\pi(0.6)=0.6^8\cdot0.4^2\approx0.000269$；$\pi(0.5)=0.5^{10}\approx0.000977$；比值 $\approx0.275$。**最终答案**：$\alpha=0.275$——以 27.5% 概率接受 0.6，否则留在 0.5。
- **易错点**：忘记对称提议下 $q$ 之比为 1；把未归一化密度当真密度（比例常数不影响比值，但必须同一次求值）。🤔 若提议 $\theta'=0.55$？接受率约 17%，越远离众数 $9/12=0.75$ 接受率越低，链被"拉回"高处。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：手写 MH 采样 $\mathrm{Beta}(9,3)$，迭代 5000、burn-in 1000，报告后验均值并与理论值 0.75 比较。
- **解题思路与完整解答**：① 初始化 $\theta^{(0)}=0.5$；② 抽 $\varepsilon\sim N(0,0.1^2)$，$\theta'=\theta^{(t-1)}+\varepsilon$；③ 算 $\alpha=\min(1,\pi(\theta')/\pi(\theta^{(t-1)}))$；④ 抽 $u\sim U(0,1)$，$u<\alpha$ 接受否则原地；⑤ 丢弃前 1000 样本，$\hat{\mu}\approx0.75\pm0.01$。
- **易错点**：步长过大（接受率过低、链粘滞）或过小（接受率高但移动极慢）；burn-in 前算均值严重偏移；自相关使有效样本远小于 4000。🤔 若 $\sigma$ 从 0.1 改成 0.5？接受率大幅下降、轨迹呈"平台-跳跃"状；随机游走 MH 目标接受率约 20%-50%。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW02 验收 = "手写 MH 与 PyMC 结果一致"；PyMC 默认引擎是 NUTS，但 MH 仍是读懂 trace 平台与接受率诊断的"母语"。代码形态（手写 MH + PyMC 对照）：
```python
import numpy as np

def log_pi(t, a=9, b=3):
    return (a-1)*np.log(t) + (b-1)*np.log(1-t)

def mh(T=5000, burn=1000, sigma=0.1, seed=0):
    rng = np.random.default_rng(seed)
    th = 0.5; out = []
    for _ in range(T):
        p = th + rng.normal(0, sigma)
        if 0 < p < 1 and rng.random() < min(1, np.exp(log_pi(p)-log_pi(th))):
            th = p
        out.append(th)
    return np.array(out[burn:])

print(mh().mean())  # ≈ 0.75（Beta(9,3) 理论均值）

# PyMC 对照（HW02 验收口径）
import pymc as pm, arviz as az
with pm.Model() as m:
    th = pm.Beta("theta", alpha=9, beta=3)
    tr = pm.sample(2000, chains=4, step=pm.Metropolis(), random_seed=1)
az.summary(tr, var_names=["theta"], round_to=3)
```

## 8. 常见误区和易混概念

### 误区 1：burn-in 越长越好、样本越多越好
- **错误直觉**：多丢样本、多跑迭代总能提高精度。
- **为什么错**：MCMC 样本自相关，精度由**有效样本量 ESS** 决定；链不混合时跑百万步也只有一个有效样本。**正确理解**：先看 trace 是否平稳混合，再用 ESS/R-hat 判断（见 [[NUTS与PyMC建模流程]]）。

### 误区 2：接受率越高算法越好
- **错误直觉**：几乎每次都接受 = 采样效率高。
- **为什么错**：随机游走 MH 接受率接近 1 通常意味着步长太小，链局部缓慢爬行，自相关极强。**正确理解**：随机游走 MH 最优接受率约 23%（高维理论值）；过高过低都是病，要看 trace 与 ESS 综合判断。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| MCMC | 从无法直接采样的分布取样本 | 样本来自相关马尔可夫链 | 后验采样（HW02-HW06） |
| MH vs Gibbs | 提议如何产生 | MH 提议+接受率；Gibbs 逐分量条件采样 | MH 通用、Gibbs 需条件可采样 |
| MH vs NUTS | 提议是否用梯度 | MH 盲搜；NUTS 沿哈密顿轨迹大步采样 | 低维 MH、高维 [[NUTS与PyMC建模流程]] |

### 题目与解析

#### 1. MCMC 与普通蒙特卡洛采样的本质区别是什么？
> [!question]- 答案解析
> - **答案**：普通蒙特卡洛假设样本 iid 来自目标分布；MCMC 样本来自一条**自相关的马尔可夫链**，只是长期访问频率（平稳分布）等于目标分布，精度看 ESS 而非原始样本数。**解析**：相关性使 MCMC 样本"信息量"低于同数量 iid 样本，因此诊断（trace/ESS）是 MCMC 必备环节；把链上 5000 个样本当独立样本会高估精度。

#### 2. 目标 $\pi(\theta)\propto\theta^6(1-\theta)^4$，当前 $\theta=0.4$，对称提议 $\theta'=0.5$，求接受率。
> [!question]- 答案解析
> - **答案**：$\alpha=\min(1,\ \pi(0.5)/\pi(0.4))$。$\pi(0.5)=0.5^{10}\approx0.000977$；$\pi(0.4)=0.4^6\cdot0.6^4\approx0.000531$；比值 $\approx1.84$，故 $\alpha=1$。**解析**：0.5 比 0.4 更接近众数 0.6，"向上走"必然接受；拒绝机制保证向下移动仍存在（见第 5 题）；算反比值会得到错误接受率。

#### 3. 随机游走 MH 步长过大/过小各有什么症状？最优区间大致多少？
> [!question]- 答案解析
> - **答案**：过大：接受率过低（<5%）、trace 长平台、链长时间原地；过小：接受率过高（>70%）、trace 密集"毛虫"状、自相关极强、ESS 低。经验最优接受率约 20%-50%（高维理论约 23%）。**解析**：接受率是"信号"，调参目标是最大化 ESS/步数而非接受率；误以为接受率高就好是常见错误。

#### 4. 提议分布不对称时，接受率为何要乘 $q(\theta|\theta')/q(\theta'|\theta)$？
> [!question]- 答案解析
> - **答案**：细致平衡要求 $\pi(\theta)q(\theta'|\theta)\alpha(\theta,\theta')=\pi(\theta')q(\theta|\theta')\alpha(\theta',\theta)$；$q$ 不对称时往返流量本身不等，必须用比值修正，否则链的平稳分布是 $\pi$ 与提议偏置的混合。**解析**：对称提议下比值为 1，退化为 $\min(1,\pi(\theta')/\pi(\theta))$；把对称公式套到非对称提议上会导致系统性偏差。

#### 5. 简述"MH 构造的链以 $\pi$ 为唯一平稳分布"的证明思路。
> [!question]- 答案解析
> - **答案**：① 转移核 $P(x\to x')=q(x'|x)\alpha(x,x')$；② 代入 $\alpha$ 分两种情况验证细致平衡 $\pi(x)P(x\to x')=\pi(x')P(x'\to x)$ 成立；③ 细致平衡 ⇒ $\pi$ 是平稳分布（对 $x$ 求和得 $\pi P=\pi$）；④ 链不可约且非周期时平稳分布唯一，长期访问频率收敛到 $\pi$。**解析**：核心是"接受率恰好抵消提议的不平衡"——这就是 MH 唯一的魔法；只背结论、讲不出细致平衡是常见卡点。
