# 贝叶斯统计-前置-共轭概率分布族速查

> 所属阶段：[[🧭 贝叶斯统计-前置知识|前置知识]]

---

## 1. 为什么需要共轭先验？

在 MCMC 与数值积分算法普及之前，解析推断完全依赖于**共轭性 (Conjugacy)**。
即使在现代 MCMC/HMC 时代，理解共轭性也是理解参数收缩（Shrinkage）、吉布斯采样（Gibbs Sampling 全条件更新）以及先验强度（超参数等价样本量）的核心钥匙。

**核心定义**：若似然函数为 $p(y \mid \theta)$，当先验分布 $p(\theta)$ 与所得后验分布 $p(\theta \mid y)$ 属于**同一个概率分布族**时，称该先验分布为该似然的**共轭先验 (Conjugate Prior)**。

---

## 2. 指数族 (Exponential Family) 的通用共轭机制

若似然函数可写为自然指数族形式：
$$p(y \mid \theta) = h(y) \exp\left( \eta(\theta)^T T(y) - A(\theta) \right)$$
其中 $T(y)$ 为充分统计量，$\eta(\theta)$ 为自然参数，$A(\theta)$ 为对数配分函数。

则该似然必存在自然共轭先验：
$$p(\theta \mid \chi_0, \nu_0) = f(\chi_0, \nu_0) \exp\left( \eta(\theta)^T \chi_0 - \nu_0 A(\theta) \right)$$
观测到 $n$ 个独立样本 $y_1, \dots, y_n$ 后的后验分布仍为同族分布，超参数更新方程具有极简的代数可加性：
$$\chi_{\text{post}} = \chi_0 + \sum_{i=1}^n T(y_i), \quad \nu_{\text{post}} = \nu_0 + n$$
- $\nu_0$ 直观对应于**先验等效样本量 (Prior Effective Sample Size)**；
- $\chi_0$ 直观对应于**先验伪观测统计量之和 (Prior Pseudo-statistic Sum)**。

## 3. 核心共轭先验速查表

| 似然分布 $P(y \mid \theta)$ | 未知参数 $\theta$ | 共轭先验 $P(\theta)$ | 超参数先验含义 | 后验分布 $P(\theta \mid y)$ | 后验均值 (先验与数据权衡) |
| :--- | :---: | :--- | :--- | :--- | :--- |
| **二项分布** $\text{Binomial}(n, \theta)$ | 成功率 $\theta \in [0, 1]$ | $\text{Beta}(\alpha, \beta)$ | $\alpha$: 先验成功数<br>$\beta$: 先验失败数 | $\text{Beta}(\alpha + y, \beta + n - y)$ | $\frac{\alpha + y}{\alpha + \beta + n}$ |
| **伯努利分布** $\text{Bernoulli}(\theta)$ | 成功率 $\theta \in [0, 1]$ | $\text{Beta}(\alpha, \beta)$ | 同上 | $\text{Beta}(\alpha + \sum y_i, \beta + n - \sum y_i)$ | $\frac{\alpha + \sum y_i}{\alpha + \beta + n}$ |
| **泊松分布** $\text{Poisson}(\lambda)$ | 事件率 $\lambda > 0$ | $\text{Gamma}(\alpha, \beta)$ | $\alpha$: 先验总事件数<br>$\beta$: 先验总暴露时间 | $\text{Gamma}(\alpha + \sum y_i, \beta + n)$ | $\frac{\alpha + \sum y_i}{\beta + n}$ |
| **指数分布** $\text{Exp}(\lambda)$ | 故障率 $\lambda > 0$ | $\text{Gamma}(\alpha, \beta)$ | $\alpha$: 先验故障次数<br>$\beta$: 先验总存活时长 | $\text{Gamma}(\alpha + n, \beta + \sum y_i)$ | $\frac{\alpha + n}{\beta + \sum y_i}$ |
| **高斯分布** $\mathcal{N}(\mu, \sigma^2)$<br>($\sigma^2$ 已知) | 均值 $\mu \in \mathbb{R}$ | $\mathcal{N}(\mu_0, \sigma_0^2)$ | $\mu_0$: 先验均值<br>$\tau_0 = \frac{1}{\sigma_0^2}$: 先验精度 | $\mathcal{N}(\mu_n, \sigma_n^2)$<br>$\frac{1}{\sigma_n^2} = \frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}$ | $\mu_n = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{n \bar{y}}{\sigma^2}}{\frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}}$ |
| **高斯分布** $\mathcal{N}(\mu, \sigma^2)$<br>($\mu$ 已知) | 方差 $\sigma^2 > 0$ | $\text{Inv-Gamma}(\alpha, \beta)$ | $\alpha$: 先验半自由度<br>$\beta$: 先验半平方和 | $\text{Inv-Gamma}(\alpha + \frac{n}{2}, \beta + \frac{1}{2}\sum(y_i-\mu)^2)$ | $\frac{\beta + \frac{1}{2}\sum(y_i-\mu)^2}{\alpha + n/2 - 1}$ |
| **多项分布** $\text{Multinomial}(n, \boldsymbol{\theta})$ | 类别概率向量 $\boldsymbol{\theta}$ | $\text{Dirichlet}(\boldsymbol{\alpha})$ | $\alpha_k$: 类别 $k$ 的先验计数 | $\text{Dirichlet}(\boldsymbol{\alpha} + \boldsymbol{y})$ | $\mathbb{E}[\theta_k] = \frac{\alpha_k + y_k}{\sum \alpha_j + n}$ |

## 4. 关键代数性质与积分常数

### (1) Beta 函数性质
$$B(\alpha, \beta) = \int_0^1 \theta^{\alpha-1} (1-\theta)^{\beta-1} d\theta = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$$
递推关系：$\Gamma(\alpha+1) = \alpha \Gamma(\alpha)$，当 $\alpha \in \mathbb{N}^+$ 时 $\Gamma(\alpha) = (\alpha-1)!$。

### (2) 高斯精度加和原理
定义精度 (Precision) $\tau \triangleq \frac{1}{\sigma^2}$。
在 Normal-Normal 共轭模型中：
$$\text{Posterior Precision} = \text{Prior Precision} + \text{Data Precision}$$
$$\tau_n = \tau_0 + n \cdot \tau_{\text{data}}$$
这一加和性完美解释了**为什么信息只能增加而不能减少**。

## 5. 主动回忆自测

- [ ] 默写 Beta-Binomial 更新后参数表达式与后验均值公式；
- [ ] 解释当 $n \to \infty$ 时，后验均值 $\frac{\alpha + y}{\alpha + \beta + n}$ 如何退化为最大似然估计 $\frac{y}{n}$；
- [ ] 指出 Gamma-Poisson 模型中超参数 $\beta$ 的量纲（时间/空间单位）对更新公式的影响。

> [!tip]- 闭卷自测参考答案与思维误区
> 1. **Beta-Binomial 更新**：先验 $\text{Beta}(\alpha, \beta)$，似然 $\text{Binomial}(n, \theta)$，后验为 $\text{Beta}(\alpha + y, \beta + n - y)$。后验期望为 $\mathbb{E}[\theta \mid y] = \frac{\alpha + y}{\alpha + \beta + n}$。
> 2. **渐近退化为 MLE**：将后验均值重写为加权平均：$\mathbb{E}[\theta \mid y] = \frac{\alpha+\beta}{\alpha+\beta+n} \cdot \frac{\alpha}{\alpha+\beta} + \frac{n}{\alpha+\beta+n} \cdot \frac{y}{n}$。随着观测数据量 $n \to \infty$，先验权重 $\frac{\alpha+\beta}{\alpha+\beta+n} \to 0$，数据权重 $\to 1$，后验均值严格收敛于样本均值（即 MLE 点估计 $\hat{\theta}_{\text{MLE}} = \frac{y}{n}$）。
> 3. **Gamma-Poisson 超参数物理含义**：$\alpha$ 是先验伪事件总数，$\beta$ 是先验伪暴露时间/空间区间。更新后的总暴露量为 $\beta + n$（$n$ 个单位观测周期），因此更新公式在量纲上始终保持“事件数/总暴露时间”的物理一致性。
