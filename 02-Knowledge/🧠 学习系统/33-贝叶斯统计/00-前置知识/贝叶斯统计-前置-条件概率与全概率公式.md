# 贝叶斯统计-前置-条件概率与全概率公式

> 所属阶段：[[🧭 贝叶斯统计-前置知识|前置知识]]

---

## 1. 核心问题与动机

在经典概率论中，所有事件的发生概率都在一个预先给定的样本空间 $\Omega$ 上计算。然而在现实推断中，我们几乎总是**在获得某种不完全信息（事件 $B$ 发生）之后**，去重新评估目标事件 $A$ 的发生几率。

如果直接使用无条件概率 $P(A)$，就会完全无视新线索带来的信息增益；而条件概率与全概率公式正是将样本空间根据已知线索进行“投影与重加权”的数学工具。

---

## 2. 严格形式化定义

### (1) 条件概率 (Conditional Probability)
设 $(\Omega, \mathcal{F}, P)$ 为概率空间，事件 $A, B \in \mathcal{F}$，且 $P(B) > 0$。事件 $A$ 在事件 $B$ 发生条件下的条件概率定义为：
$$P(A \mid B) \triangleq \frac{P(A \cap B)}{P(B)}$$

连续随机变量情形下，设 $(X, Y)$ 联合密度为 $p(x, y)$，边际密度 $p_Y(y) > 0$，则给定 $Y=y$ 时 $X$ 的条件概率密度函数 (PDF) 为：
$$p_{X\mid Y}(x \mid y) \triangleq \frac{p(x, y)}{p_Y(y)} = \frac{p(x, y)}{\int_{\mathbb{R}} p(x', y) dx'}$$

### (2) 样本空间的分割与全概率公式 (Law of Total Probability)
设事件序列 $\{B_1, B_2, \dots, B_n\}$（或可数可加无穷序列）构成样本空间 $\Omega$ 的一个**划分 (Partition)**，即满足：
1. **互斥性**：$B_i \cap B_j = \emptyset, \quad \forall i \neq j$；
2. **完备性**：$\bigcup_{i=1}^n B_i = \Omega$；
3. **非零概率**：$P(B_i) > 0, \quad \forall i$。

则对任意事件 $A \in \mathcal{F}$，其边际概率由全概率公式给出：
$$P(A) = \sum_{i=1}^n P(A \cap B_i) = \sum_{i=1}^n P(A \mid B_i) P(B_i)$$

连续情形下，边际似然积分表达为：
$$p(y) = \int_{\Theta} p(y \mid \theta) p(\theta) d\theta$$

---

## 3. 深入理解：条件概率满足全部柯尔莫哥洛夫公理

固定条件事件 $B$（满足 $P(B) > 0$），测度 $P(\cdot \mid B)$ 在 $(\Omega, \mathcal{F})$ 上同样构成一个合法的概率测度：
1. **非负性**：对任意 $A \in \mathcal{F}$，$P(A \mid B) = \frac{P(A \cap B)}{P(B)} \ge 0$；
2. **规范性**：$P(\Omega \mid B) = \frac{P(\Omega \cap B)}{P(B)} = \frac{P(B)}{P(B)} = 1$；
3. **可数可加性**：若 $A_1, A_2, \dots$ 两两互斥，则：
   $$P\left(\bigcup_{i=1}^\infty A_i \mid B\right) = \frac{P\left((\bigcup A_i) \cap B\right)}{P(B)} = \frac{\sum_{i=1}^\infty P(A_i \cap B)}{P(B)} = \sum_{i=1}^\infty P(A_i \mid B)$$

**推论**：所有关于无条件概率的性质（如容斥原理、对偶律、单调性），在给定同一条件 $B$ 下均严格成立。

## 4. 经典实例分析：辛普森悖论与条件分解

假设某医学实验测试药物对病人的疗效（恢复率）：

| 人群分组 | 用药组 (Treatment) | 对照组 (Control) |
| :--- | :--- | :--- |
| **轻症组** ($C=0$) | $90/100 = 90\%$ | $80/100 = 80\%$ (用药更优) |
| **重症组** ($C=1$) | $30/100 = 30\%$ | $20/100 = 20\%$ (用药更优) |
| **总体合并** | 若重症分配更多用药 | 总体恢复率可能反转 |

根据全概率公式展开：
$$P(\text{Recovery} \mid \text{Drug}) = \sum_{c \in \{0, 1\}} P(\text{Recovery} \mid \text{Drug}, C=c) P(C=c \mid \text{Drug})$$
如果分配不是随机双盲（即 $C \not\perp \text{Drug}$），则先验权重 $P(C=c \mid \text{Drug})$ 的偏斜会导致总体与组内条件的结论背离。这正是贝叶斯层次建模中控制混杂变量（Confounding Variable）的出发点。

---

## 5. 易混淆概念与反例

1. **混淆 $P(A \mid B)$ 与 $P(B \mid A)$（检察官谬误 Prosecutor's Fallacy）**：
   - 设 $A$ 为“嫌疑人无辜”，$B$ 为“DNA 特征匹配”；
   - 实验室给出 $P(B \mid A) = 10^{-6}$（无辜者偶然匹配的极低假阳性率）；
   - 检察官误称嫌疑人无辜的概率 $P(A \mid B) = 10^{-6}$。实际上由贝叶斯定理：
     $$P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B \mid A)P(A) + P(B \mid A^c)P(A^c)}$$
     若人群基底庞大（$P(A) \approx 1$），则 $P(A \mid B)$ 可能仍然很高。
2. **条件独立性不等于独立性**：
   - 设两个灯泡由同一总电源供电（电源故障为 $Z$）。给定 $Z$，两灯泡寿命独立；但未观测 $Z$ 时，灯泡 1 熄灭会极大增加灯泡 2 熄灭的先验几率。

- [ ] 解释为什么条件概率测度满足规范性公理 $P(\Omega \mid B) = 1$；
- [ ] 举出一个 $X \perp Y \mid Z$ 但 $X \not\perp Y$ 的实际例子。

> [!tip]- 闭卷自测参考答案与思维误区
> 1. **全概率公式形式**：
>    - 离散：$P(A) = \sum_{i} P(A \mid B_i)P(B_i)$，要求 $\bigcup B_i = \Omega, B_i \cap B_j = \emptyset$；
>    - 连续：$p(y) = \int_\Theta p(y \mid \theta) p(\theta) d\theta$（边际似然/证据项）。
> 2. **规范性公理验证**：由定义 $P(\Omega \mid B) = \frac{P(\Omega \cap B)}{P(B)} = \frac{P(B)}{P(B)} = 1$。这证明给定条件事件 $B$ 后，所有概率质量被重新限制在子空间 $B$ 上并重新归一化。
> 3. **思维误区 (Prosecutor's Fallacy)**：混淆 $P(\text{DNA matches} \mid \text{Innocent}) = 10^{-6}$ 与 $P(\text{Innocent} \mid \text{DNA matches})$。在 1000 万人口的城市中，无辜者中可能自然出现 10 人匹配，如果无辜先验极高，匹配者是无辜者的概率依然可能高达 $10/11 \approx 91\%$。
