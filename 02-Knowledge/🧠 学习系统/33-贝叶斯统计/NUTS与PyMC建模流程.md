# NUTS与PyMC建模流程

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：HW03 起的每个作业都跑在 PyMC + NUTS 上，"五步建模 + R-hat/ESS 诊断"是 [[🧭 开源作业体系-贝叶斯统计]] 中 HW03-HW06 的通用验收模板。不懂 NUTS 就读不懂发散警告，不懂诊断就无法验收任何模型。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：随机游走 MH（[[MCMC与MetropolisHastings]]）在高维或强相关后验下几乎瘫痪：每步"碰运气"，接受率低、混合极慢、ESS 惨不忍睹——而真实模型（回归、层次模型）动辄几十个参数且高度相关。因此引入 **HMC/NUTS**：利用后验梯度信息让采样器"沿等高线滚动"而非"随机乱跳"；并用 **PyMC 五步建模流程**把"模型定义 → 采样 → 诊断 → 后验预测 → 报告"固化为可验收工程规范，**R-hat 与 ESS** 是判断"能否用这批样本"的量化闸门。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是 HW03-HW06 全部作业的执行引擎与验收语言；不懂它就等于不懂 PyMC 报错与 `az.summary` 输出。
- **实际应用场景**：PyMC/Stan 默认采样器（NUTS）；贝叶斯神经网络、大规模层次模型的可行采样方案；工业 A/B 与因果推断的标准工作流。**高频题型/任务**：读 `az.summary` 判断收敛；解释 divergent transition 警告；按五步流程完成回归模型并写诊断报告。

---

## 3. 学它之前需要哪些前置知识？

1. **[[MCMC与MetropolisHastings]]**：HMC 是 MH 的特例（提议来自哈密顿轨迹），接受率、burn-in、诊断概念全部复用。
2. **梯度与微分**：HMC 用 $\nabla_\theta \log\pi(\theta)$ 引导轨迹；至少理解"梯度指向密度上升最快方向"。
3. **[[贝叶斯定理与共轭先验]]**：模型 = 先验 × 似然，PyMC 的 `pm.Normal` 等即组件声明。

---

## 4. 用直觉语言解释它

> «"随机游走 MH 是雾天乱撞的醉汉；HMC 是把台球放在碗里松手——它沿碗壁滚，动能势能互相转换，走过一大段光滑弧线才停一次。NUTS 给台球装自动刹车：发现它在往回滚（走过头）就立刻停，不用人肉调'滚多远'。"»

- **直觉类比/几何图像**：把 $-\log\pi(\theta)$ 当"地形高度"，HMC 给参数附加"动量"$p$，轨迹保持总能量不变，因此几乎总被接受；NUTS 用"折返检测"自动决定轨迹长度。
- **为什么很自然**：梯度让提议"朝密度高的方向走"，比盲搜高效得多；能量守恒使接受率接近 1，一次跳跃抵随机游走几百步。**一句话直觉本质**：**用"带动量的物理滚动"替代"随机乱跳"，用"折返刹车"替代"人肉调步长"，再用 R-hat/ESS 量化判断链是否真的到达平稳。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **HMC**：在参数 $\theta$ 上引入辅助动量 $p\sim N(0,M)$，沿哈密顿方程 $\dot\theta=M^{-1}p,\ \dot p=\nabla_\theta\log\pi(\theta)$ 演化 $L$ 步蛙跳（leapfrog），把终点当 MH 候选；因能量近似守恒接受率极高，且轨迹远离起点（低自相关）。**NUTS**：自适应 HMC——自动调节步长 $\epsilon$ 与轨迹长度 $L$（"No-U-Turn"：轨迹开始折返即停），无需人工调参，是 PyMC `pm.sample()` 默认引擎。**R-hat / ESS**：多链收敛诊断——R-hat 比较链间与链内方差；ESS 是考虑自相关后的等效独立样本数。

### 2. 核心公式

**哈密顿系统**（$U(\theta)=-\log\pi(\theta)$ 为势能，$K(p)=\tfrac12 p^\top M^{-1}p$ 为动能）：$$\dot{\theta}=M^{-1}p,\qquad \dot{p}=-\nabla_\theta U(\theta)=\nabla_\theta\log\pi(\theta)$$

**R-hat（简化）**：$$\hat R=\sqrt{\frac{\widehat{\mathrm{var}}^{+}(\text{chain means})+\text{within-chain variance}}{\text{within-chain variance}}},\qquad \text{通过判据：}\hat R<1.01$$

**ESS（近似）**：$$\mathrm{ESS}=\frac{T}{1+2\sum_{k\ge1}\hat\rho_k},\qquad \text{常用闸门：}\mathrm{ESS}>400$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\theta$ | 模型参数向量 | $\mathbb{R}^p$ | 采样对象 |
| $p$ | 辅助动量 | $\mathbb{R}^p$ | 每次采样重抽，不进后验 |
| $M$ | 质量矩阵 | 正定 $p\times p$ | 常取对角阵（自适应） |
| $\epsilon$ | 蛙跳步长 | $>0$ | NUTS 自动调节（dual averaging） |
| $\hat R$ | 收敛统计量 | $\ge1$ | 越接近 1 越好；<1.01 通过 |
| ESS | 有效样本量 | 正整数 | bulk/tail 两个版本都要看 |

### 4. 常见变体与适用条件
- **变体**：NUTS（PyMC 默认）、固定 $\epsilon,L$ 的 HMC、Jitter+adapt（`pm.sample()` 默认含）；诊断工具 `az.summary` / `az.plot_trace` / `az.plot_energy`。
- **适用/限制**：目标密度对数可微、参数连续、中高维度优势明显；离散参数需边缘化，强多峰或刚性后验会出现发散（divergence）——需重新参数化（如非中心化）。

## 6. 推导思路和思想来源

- **最初困难**：随机游走 MH 高维效率灾难——提议不利用目标几何，相关参数方向寸步难行。**直接方法局限**：高斯近似提议（Langevin 类）只对近似高斯后验有效。
- **关键"转念"**：把"采样问题"翻译成"物理模拟问题"——目标密度对数是势能，引入动量后系统沿能量守恒轨迹演化；**轨迹终点分布恰好是 $\pi$ 的等温分布**，方向由梯度决定，天然沿"山谷"快速移动。
- **推导主线与动机**：联合分布 $\pi(\theta,p)=\pi(\theta)N(p|0,M)$（边际仍是 $\pi$）→ 哈密顿方程保持 $H=U+K$ → 蛙跳离散化引入小误差 → 用 MH 接受率修正 → 接受率 $\approx e^{-(H'-H)}$ 在 $\epsilon$ 小时接近 1 → 高效 HMC。NUTS 再解决"$L$ 怎么选"：递归加倍轨迹，检测"折返"（$(\theta_s-\theta_0)^\top p_s$ 变号）即停。
- **为什么自然得到此结论**：因为"梯度指向上升方向"与"能量守恒保证可逆性"两个物理事实，恰好对应 MCMC 需要的"高效提议"与"细致平衡可验证"。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：一维目标 $\pi(\theta)\propto e^{-\theta^2/2}$（标准正态）。位置 $\theta=1$，动量 $p=1$，$M=1$。求势能、动能与总能量 $H$。
- **解题思路与关键步骤**：$U=\theta^2/2=0.5$（取常数 0）；$K=p^2/2=0.5$；$H=1.0$，轨迹演化中 $H$ 近似守恒，终点接受率 $\approx e^{-(H'-H)}\approx1$。**最终答案**：$U=0.5,\ K=0.5,\ H=1.0$；蛙跳一步后 $H'$ 与 1.0 之差为 $O(\epsilon^3)$，接受率趋近 1。
- **易错点**：动能忘除 2；把 $U$ 当正对数似然而忽略符号。🤔 若 $\theta=3$（远离众数）？势能 $U=4.5$ 很大，系统获得高动能快速滚向众数附近，这正是 HMC 快速收敛的原因。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：`az.summary` 输出 `alpha` 的 `r_hat=1.03`、`ess_bulk=150`。能否进入后验预测阶段？补救步骤？
- **解题思路与完整解答**：不能。R-hat 超 1.01 闸门、ESS 低于 400，链未充分混合。补救：① 增加 `tune` 与 `draws`（如 2000→4000）；② 增加链数 `chains=4→8`；③ 若有 divergences，检查 `az.plot_trace` 能量尖峰，做非中心化重参数化；④ 重跑后复查 `az.summary` 全部 `r_hat<1.01` 且 `ess_bulk/ess_tail>400`。
- **易错点**：只看 `r_hat` 忽略 `ess_tail`（尾部 ESS 低则极端分位数不可靠）；对未收敛模型直接解释系数。🤔 为什么不能只加 `draws` 不加 `tune`？——`tune` 是自适应期（调 $\epsilon$ 与质量矩阵），样本未进入平稳；`tune` 不足时 `draws` 再多也带"预热污染"。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW03 验收 = 五步流程跑通线性回归：定义模型 → 采样 → 诊断 → 后验预测 → 报告。以下代码即交付模板。代码形态（PyMC 五步，对照 PyMC Examples `GLM_linear`）：
```python
import numpy as np, pymc as pm, arviz as az

rng = np.random.default_rng(42)
x = rng.uniform(0, 10, 50); y = 2.0 + 0.8*x + rng.normal(0, 1.0, 50)

# ① 定义模型：先验 + 似然
with pm.Model() as lin:
    alpha = pm.Normal("alpha", mu=0, sigma=10)
    beta  = pm.Normal("beta",  mu=0, sigma=5)
    sigma = pm.HalfNormal("sigma", sigma=3)
    mu = alpha + beta*x
    obs = pm.Normal("obs", mu=mu, sigma=sigma, observed=y)

# ② 采样（NUTS 默认）
with lin:
    trace = pm.sample(1000, chains=4, tune=1000, random_seed=42)

# ③ 诊断 + ④ 后验预测 + ⑤ 报告
print(az.summary(trace, var_names=["alpha", "beta", "sigma"], round_to=3))
az.plot_trace(trace)
with lin:
    ppc = pm.sample_posterior_predictive(trace, random_seed=42)
az.plot_ppc(ppc, num_pp_samples=100)
```

## 8. 常见误区和易混概念

### 误区 1：R-hat < 1.01 就万事大吉
- **错误直觉**：收敛诊断通过 = 采样一定正确。
- **为什么错**：R-hat 只检查"链间一致性"，测不出"共同卡在局部模式"或"发散未被报告"；多峰后验四条链可能都困在同一峰。**正确理解**：R-hat/ESS 是**必要不充分**条件：还要看 trace 形态、`az.plot_energy`、PPC 与领域知识（见 [[后验预测检查与模型比较]]）。

### 误区 2：把 ESS 当"总样本数"
- **错误直觉**：`draws=2000, chains=4` 就有 8000 个独立样本。
- **为什么错**：自相关使有效样本远小于原始样本；`ess_bulk` 常只有原始数的 20%-60%。**正确理解**：ESS 决定 MC 标准误（$\approx \sigma/\sqrt{\mathrm{ESS}}$）；ESS<400 时区间估计不可信。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| HMC vs 随机游走 MH | 提议是否用梯度 | 物理轨迹 vs 盲搜；接受率 ~1 vs 最优 ~0.23 | 高维连续后验 vs 低维/教学 |
| NUTS vs HMC | 步长/轨迹长度谁定 | NUTS 自适应（dual averaging + 折返检测） | PyMC/Stan 默认 |
| R-hat vs ESS | 收敛 vs 精度 | 链间一致性 vs 有效信息量 | 两者都要看（`az.summary`） |

### 题目与解析

#### 1. HMC 相比随机游走 Metropolis 效率高的根本原因是什么？
> [!question]- 答案解析
> - **答案**：HMC 的提议由哈密顿轨迹产生，方向由梯度 $\nabla_\theta\log\pi(\theta)$ 引导，且能量近似守恒使接受率接近 1；随机游走不利用目标信息，只能小步挪动、大量拒绝。**解析**：效率 = 有效跳跃距离 × 接受率；HMC 一次跳跃可跨越高度相关空间，自相关远低于随机游走，ESS/秒 高一个数量级以上；误以为 HMC 只是"步长更大"的 MH 是常见错误。

#### 2. `az.summary` 显示 `r_hat=1.005, ess_bulk=320, ess_tail=150`，能进入后验预测阶段吗？
> [!question]- 答案解析
> - **答案**：不能。R-hat 达标，但 ESS 未达标：bulk 320 < 400、tail 150 远低于 400——尾部（极端分位数）估计极不可靠。**解析**：`ess_tail` 低意味着 HDI 边界不稳定，此时解释区间或做 PPC 会传递噪声；补救：加 `draws`/`chains`，必要时重参数化；只检查 `r_hat` 或只检查 `ess_bulk` 是常见疏漏。

#### 3. 采样后出现 200 个 divergent transitions，正确的处理顺序是什么？
> [!question]- 答案解析
> - **答案**：① 加 `tune`（如 1000→2000）并提高 `target_accept`（如 0.8→0.95）重跑——多数发散是步长 $\epsilon$ 过大；② 仍发散则标准化连续变量；③ 层次模型改用非中心化参数化；④ 全部无效才换采样器或简化模型。**解析**：发散 = 蛙跳离散误差过大导致轨迹穿越"能量悬崖"，通常意味着数值问题而非模型错误；无视发散直接解释结果（发散样本不满足细致平衡，后验有偏）。

#### 4. 把五步流程与 HW03 验收项一一对应。
> [!question]- 答案解析
> - **答案**：① 定义模型 → "建模复现"；② 采样 → "可复现运行"（随机种子、版本）；③ 诊断（`az.summary`/`az.plot_trace`）→ "R-hat<1.01、ESS>400、trace 无异常"；④ 后验预测 → "后验预测区间覆盖检验"；⑤ 报告（系数 HDI + 解释）→ "决策解释"。**解析**：五步即验收清单，漏掉任何一步都无法按 [[🧭 开源作业体系-贝叶斯统计]] 的 Rubric 拿分；把"采样完成"当"作业完成"是常见错误。

#### 5. 为什么 NUTS 能自动选择轨迹长度？简述"No-U-Turn"判据。
> [!question]- 答案解析
> - **答案**：NUTS 用递归加倍构建轨迹树，每次检查"折返"信号：当 $(\theta_s-\theta_0)^\top p_s<0$（从起点看向当前点的速度投影变号）说明轨迹开始往回走，继续加长只增计算不增信息，于是停止；配合双平均（dual averaging）自适应步长 $\epsilon$，实现免调参。**解析**：$(\theta_s-\theta_0)^\top p_s$ 变号即折返，这正是轨迹长度 $L$ 不再是超参数的机制；把 NUTS 的自适应误当成"自动调先验"是常见误解。
