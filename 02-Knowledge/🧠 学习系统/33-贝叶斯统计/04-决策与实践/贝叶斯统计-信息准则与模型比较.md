# 贝叶斯统计-信息准则与模型比较

> 所属阶段：[[🧭 阶段4-决策与实践|阶段4：决策与实践]]

---

## 1. 评估标准：期望对数逐点预测密度 (elpd)

在面对多个竞争模型时，贝叶斯模型评价的现代黄金标准是**样本外预测精度 (Out-of-sample Predictive Accuracy)**。

定义**期望对数逐点预测密度 (elpd)**：
$$\text{elpd} \triangleq \sum_{i=1}^n \int \log P(\tilde{y}_i \mid y) f(\tilde{y}_i) d\tilde{y}_i$$
其中 $f(\tilde{y}_i)$ 为不可见真实世界的真实数据生成机制。

---

## 2. PSIS-LOO-CV：帕累托平滑重要性采样留一法

精确执行 $n$ 次留一交叉验证 (LOO-CV) 需要重新拟合模型 $n$ 次，对大型 MCMC 模型计算成本完全不可接受。

Vehtari et al. (2017) 提出的 **PSIS-LOO** 仅利用全量数据的单次 MCMC 后验样本，通过重要性采样反向逼近留一后验：

### (1) 原始重要性权重与方差爆炸
留一后验权重为：
$$r_i^{(s)} \triangleq \frac{P(\theta^{(s)} \mid y_{-i})}{P(\theta^{(s)} \mid y)} = \frac{1}{P(y_i \mid \theta^{(s)})}$$
对于离群样本点（$y_i$ 在该模型下似然极低），$r_i^{(s)}$ 会极端巨大，导致重要性权重方差无限发散。

### (2) 帕累托分布平滑与 $\hat{k}$ 诊断
PSIS 对最大的 $M = \min(0.2S, 3\sqrt{S})$ 个极端权重拟合**广义帕累托分布 (GPD)**，并用分布的理论期望顺序统计量替换极端值：

| 帕累托形态参数 $\hat{k}$ | 样本点诊断状态 | 算法可靠性与操作建议 |
| :--- | :--- | :--- |
| **$\hat{k} \le 0.5$** | **极佳 (Good)** | 权重方差有限，中心极限定理成立，PSIS-LOO 逼近精度极高。 |
| **$0.5 < \hat{k} \le 0.7$** | **良好 (OK)** | 权重具有轻微厚尾，但平滑后依然完全可用。 |
| **$\hat{k} > 0.7$** | **危险警告 (Warning)** | 权重方差无限发散，该观测点对模型具有过大的杠杆影响力。PSIS 逼近失效，**必须对该点执行真实重新拟合 (Exact Refit)**。 |

## 3. 广泛适用信息准则 (WAIC)

WAIC 是 AIC / BIC 在全后验分布下的严密推广：
$$\text{WAIC} \triangleq -2 \left( \text{lppd} - p_{\text{WAIC}} \right)$$
- **对数后验预测密度 (lppd)**：$\text{lppd} = \sum_{i=1}^n \log \left( \frac{1}{S} \sum_{s=1}^S P(y_i \mid \theta^{(s)}) \right)$；
- **有效参数惩罚项 $p_{\text{WAIC}}$**：由后验对数似然在各样本点上的后验方差求和得到：
  $$p_{\text{WAIC}} = \sum_{i=1}^n \text{Var}_{\theta \mid y}\left( \log P(y_i \mid \theta) \right)$$

## 4. 模型组合：为什么 Stacking 优于贝叶斯模型平均 (BMA)？

在真实世界中，“所有备选模型中存在一个绝对真理”的假设通常不成立（$\mathcal{M}$-open 视角）。
- **BMA 的缺陷 (Winner-takes-all)**：由于边际似然对样本量指数敏感，随着数据量增加，BMA 会将 100% 的后验权重武断地压在单一模型上；
- **模型堆叠 (Stacking, Yao et al., 2018)**：基于各模型的 LOO 留一预测密度，通过凸优化求解最优权重向量 $\boldsymbol{w}$：
  $$\max_{\boldsymbol{w}} \sum_{i=1}^n \log \left( \sum_{k=1}^K w_k P(y_i \mid y_{-i}, \mathcal{M}_k) \right), \quad \text{s.t. } w_k \ge 0, \sum w_k = 1$$
  Stacking 能够在保留各模型独特优势的同时，大幅提升样本外的泛化能力。

## 5. 主动回忆与闭卷自测

- [ ] 解释为什么留一交叉验证的重要性权重严格等于观测点似然的倒数 $\frac{1}{P(y_i \mid \theta)}$；
- [ ] 阐明 PSIS-LOO 中 $\hat{k} > 0.7$ 的物理诊断含义；
- [ ] 比较 WAIC 的有效参数惩罚项 $p_{\text{WAIC}}$ 与 AIC 中参数个数 $K$ 的本质区别。

> [!tip]- 闭卷自测参考答案与思维误区
> 1. **留一权重倒数证明**：
>    $r_i = \frac{P(\theta \mid y_{-i})}{P(\theta \mid y)} = \frac{\frac{P(y_{-i}\mid\theta)P(\theta)}{P(y_{-i})}}{\frac{P(y_i, y_{-i}\mid\theta)P(\theta)}{P(y)}} \propto \frac{P(y_{-i}\mid\theta)}{P(y_i\mid\theta)P(y_{-i}\mid\theta)} = \frac{1}{P(y_i\mid\theta)}$。
> 2. **$\hat{k} > 0.7$ 诊断机理**：
>    当广义帕累托形状参数 $\hat{k} > 0.7$ 时，重要性权重的理论方差无限发散，蒙特卡洛中心极限定理失效。这意味着样本点 $y_i$ 是对模型具有极大杠杆影响的高敏感离群点，PSIS 逼近已不可靠，必须从数据中剔除该点后对模型进行精确重拟合（Exact Refit）。
> 3. **$p_{\text{WAIC}}$ vs AIC 参数数 $K$**：
>    AIC 的 $K$ 是无先验约束下的朴素参数自由度。而在强先验正则化或层次收缩模型中，参数受到先验的强力约束（并非自由探索）。$p_{\text{WAIC}} = \sum \text{Var}_{\theta\mid y}(\log P(y_i\mid\theta))$ 真实衡量了后验对每个数据点的变异敏感度，在强先验下 $p_{\text{WAIC}} \ll K$，准确反映了有效自由度。
