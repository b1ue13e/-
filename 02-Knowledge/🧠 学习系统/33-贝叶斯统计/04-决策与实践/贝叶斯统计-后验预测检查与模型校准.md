# 贝叶斯统计-后验预测检查与模型校准

> 所属阶段：[[🧭 阶段4-决策与实践|阶段4：决策与实践]]

---

## 1. 核心理念：模型能否复现真实世界的关键特征？

贝叶斯模型即使 MCMC 采样 $\hat{R} < 1.01$ 完美收敛，也不代表模型是对的（它可能完美收敛到了一个完全错误的数据生成假设上）。

**后验预测检查 (Posterior Predictive Checks, PPC)** 的哲学源自统计证伪主义（Gelman & Shalizi, 2013）：
**如果模型是真实世界的一个可信简化，那么利用其后验参数生成的合成数据 $y^{\text{rep}}$，在统计特征上应当与真实观测数据 $y$ 无法区分**。

---

## 2. 合成数据生成与检验统计量 (Discrepancy Measure)

### (1) 仿真生成过程
设从后验中采集到了 $S$ 个参数样本 $\theta^{(1)}, \dots, \theta^{(S)} \sim P(\theta \mid y)$。
对每个参数样本，从似然函数中生成一套**全尺寸的合成数据集**：
$$y^{\text{rep}, (s)} \sim P(y \mid \theta^{(s)}), \quad s=1, \dots, S$$

### (2) 常见检验统计量 $T(y)$ 的选择
根据具体业务领域的潜在风险设计专门的检验函数 $T(y)$：
- **极值风险检验**：$T(y) = \max(y)$（如评估风控模型是否低估了黑天鹅损失）；
- **偏态与偏离度检验**：$T(y) = \frac{1}{n} \sum (y_i - \bar{y})^3$；
- **零膨胀检验**：$T(y) = \frac{1}{n} \sum_{i=1}^n I(y_i = 0)$（检查电商中不产生购买的用户比例）；
- **分位数间距**：$T(y) = Q_{0.95}(y) - Q_{0.05}(y)$。

---

## 3. 贝叶斯 $p$ 值 (Bayesian $p$-value) 的数学定义与计算

贝叶斯 $p$ 值定义为：**在后验分布下，合成数据检验统计量比真实数据更极端的概率**：

$$p_B \triangleq P(T(y^{\text{rep}}, \theta) \ge T(y, \theta) \mid y) = \int \int I\left(T(y^{\text{rep}}, \theta) \ge T(y, \theta)\right) P(y^{\text{rep}} \mid \theta) P(\theta \mid y) dy^{\text{rep}} d\theta$$

通过蒙特卡洛样本直接近似：
$$\hat{p}_B = \frac{1}{S} \sum_{s=1}^S I\left( T(y^{\text{rep}, (s)}, \theta^{(s)}) \ge T(y, \theta^{(s)}) \right)$$

### 判决标准
| 贝叶斯 $p$ 值范围 | 模型健康状态 | 统计学结论与改进方向 |
| :--- | :--- | :--- |
| **$0.10 \le p_B \le 0.90$** | **良态拟合 (Well-calibrated)** | 真实数据恰好落在合成数据分布的腹地，模型成功捕获该特征。 |
| **$p_B \approx 0.50$** | **对称理想状态** | 合成特征完全对称地包络真实特征。 |
| **$p_B < 0.01$ 或 $p_B > 0.99$** | **系统性病态 (Falsified)** | 真实数据在所有合成样本中都排在极端边缘，证明当前似然函数存在结构性硬伤（如用高斯似然拟合厚尾数据，或用泊松拟合零膨胀数据）。 |

---

## 4. LOO-PIT 校准检验 (Probability Integral Transform)

留一概率积分变换 (LOO-PIT) 检验整个后验累积分布函数在每个样本点上的校准均匀性：
$$u_i = P(y_i^{\text{rep}} \le y_i \mid y_{-i})$$
- **理想状态**：如果模型完全校准，序列 $\{u_1, u_2, \dots, u_n\}$ 应当在 $[0, 1]$ 上严格服从**均匀分布 $\text{Uniform}(0, 1)$**；
- **U 型直方图**：说明模型估计的后验方差过窄，实际数据频频击穿边界（过度自信）；
- **倒 U 型（拱形）直方图**：说明后验方差过宽，模型过度保守。

## 5. 主动回忆与闭卷自测

- [ ] 阐述传统频率学派 $p$ 值与贝叶斯 $p$ 值的本质区别（条件固定点 vs 全后验积分）；
- [ ] 写出用 NumPy 计算零膨胀检验统计量与 $\hat{p}_B$ 的核心代码逻辑；
- [ ] 解释 LOO-PIT 直方图呈现 U 型时代表模型的什么系统性缺陷。

> [!tip]- 闭卷自测参考答案与思维误区
> 1. **$p$ 值本质区别**：
>    - 频率学派 $p$ 值：假设原假设真值固定，计算重复抽样下比观测值更极端的概率 $P(T(y^{\text{rep}}) \ge T(y) \mid \theta_0)$，依赖点假设；
>    - 贝叶斯 $p$ 值：将参数 $\theta$ 的全后验不确定性全部积分掉 $\int P(T(y^{\text{rep}}) \ge T(y) \mid \theta) P(\theta \mid y) d\theta$，反映模型对当前数据的自洽度。
> 2. **零膨胀检验与 $\hat{p}_B$ 核心逻辑**：
>    `t_obs = np.mean(y_obs == 0)`；`t_rep = np.mean(y_rep == 0, axis=1)`；`p_val = np.mean(t_rep >= t_obs)`。若 $\hat{p}_B < 0.01$，说明真实零值数量远超模型预测能力，必须切换为零膨胀模型（如 Zero-Inflated Poisson）。
> 3. **LOO-PIT U 型直方图缺陷**：
>    LOO-PIT 聚集在两端（接近 0 和 1），说明真实观测值频频落在后验预测分布的极端尾部之外，这证明模型估计的预测方差严重偏窄（过度自信 / 欠拟合厚尾效应），必须引入更重尾的似然函数（如 Student-t 或负二项分布）。
