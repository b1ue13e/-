# 层次模型HierarchicalModel

---

## 0. 学习边界

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：[[🧭 开源作业体系-贝叶斯统计]] 中 HW04 整篇作业就是层次模型（对照 PyMC Examples `hierarchical_partial_pooling`），验收项明确写着"部分池化 vs 完全池化对比；解释收缩（shrinkage）现象；后验预测按组校验"；HW06 Capstone 的 radon 分层案例也依赖它。不懂收缩就读不懂为什么"小样本组的估计被拉向全局均值"。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：数据天然分组成簇——学生在校内、住户在县内、病人在医院内，每组样本量参差不齐。以前两种做法都卡壳：**无池化（no pooling）**把每组当独立参数估计，小样本组（如只测了 1 户的县）方差爆炸、估计被噪声主导；**完全池化（complete pooling）**把所有组合并成一个均值，小样本组是稳了，但把"县与县确实不同"这个结构信息全部抹掉。因此引入**部分池化（partial pooling）/ 层次模型**：每个组有自己的参数 $\theta_j$，但这些参数**共享一个组间分布** $\theta_j \sim N(\mu, \tau^2)$——大样本组主要信自己的数据，小样本组自动向全局均值"借力"，借多少由组内/组间方差之比决定。这正好是 HW04 的验收主题。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：HW04 的全部内容；HW06 radon 分层案例的骨架；是"混合效应/随机效应模型"的贝叶斯形态与多层贝叶斯起点。
- **实际应用场景**：教育（学校效果）、医学（医院/中心效应）、贝叶斯 A/B 分层（每组有自己的效果但共享整体先验）。**高频题型/任务**：三池化对比；手算收缩后的组估计；解释 $\tau$ 与 ICC；PyMC 层次模型 + 非中心化参数化 + 收敛诊断。

---

## 3. 学它之前需要哪些前置知识？

1. **[[NUTS与PyMC建模流程]]**：层次模型的采样、R-hat/ESS 诊断、发散处理（非中心化）全部复用五步流程。
2. **[[贝叶斯定理与共轭先验]]**：Normal-Normal 共轭——后验均值 = 样本均值与先验均值的**精度加权平均**，收缩公式就是它的直接产物。
3. **正态分布与精度**：$\sigma^2$ 与精度 $1/\sigma^2$ 的互换；方差分解 $Var(y)=\tau^2+\sigma^2$ 是组间/组内方差的语言。

---

## 4. 用直觉语言解释它

> «"部分池化就像全班合买参考书"：大组自己书多（数据足），不太需要借；小组只有半本（数据少），就从全班共用书里借——借多少不是拍脑袋，而是看"组内差异 vs 组间差异"的比值：组间差异越大（$\tau$ 大），小组越敢坚持自己的小样本；组间差异越小，小组越该跟大部队走。"»

- **直觉类比/几何图像**：组均值估计 = 组内样本均值 $\bar y_j$ 与全局均值 $\mu$ 之间的"拔河"，绳子两端的力分别是组内精度 $n_j/\sigma^2$ 与组间先验精度 $1/\tau^2$；$n_j$ 越大、$\tau$ 越大，越偏向 $\bar y_j$。
- **为什么很自然**：共享组间分布就是给"组间差异"本身建模——$\tau$ 是数据估计出来的，不是拍脑袋定的，因此折中比例自动最优。
- **一句话直觉本质**：**组参数不独立、也不相同，而是"同分布"——用组间方差 $\tau^2$ 控制每组在"自己的数据"和"全局信息"之间的收缩程度。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 最核心定义
- **无池化**：$\theta_j$ 相互独立估计，$\hat\theta_j=\bar y_j$（每组只用自己数据）。
- **完全池化**：$\hat\theta_j=\bar y$（所有组共用一个均值，忽略组间差异）。
- **部分池化（层次模型）**：$y_{ij}\sim N(\theta_j,\sigma^2)$，$\theta_j\sim N(\mu,\tau^2)$，超参数 $\mu,\tau$ 再给超先验；组参数通过共享先验"部分借用"全局信息。

### 2. 核心公式
$$y_{ij}\sim N(\theta_j,\ \sigma^2),\qquad \theta_j\sim N(\mu,\ \tau^2)$$
**收缩估计（精度加权平均）**：
$$\hat\theta_j^{\mathrm{PP}}=\frac{\frac{n_j}{\sigma^2}\,\bar y_j+\frac{1}{\tau^2}\,\mu}{\frac{n_j}{\sigma^2}+\frac{1}{\tau^2}}$$
**方差分解与 ICC**：
$$\mathrm{Var}(y_{ij})=\tau^2+\sigma^2,\qquad \rho=\frac{\tau^2}{\tau^2+\sigma^2}$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\theta_j$ | 第 $j$ 组的参数（组均值） | $\mathbb{R}$ | 采样对象 |
| $\mu$ | 组间分布均值（超参数） | $\mathbb{R}$ | 全局水平 |
| $\tau$ | 组间标准差（超参数） | $>0$ | 组间异质性大小 |
| $\sigma$ | 组内标准差 | $>0$ | 个体噪声 |
| $n_j$ | 第 $j$ 组样本量 | 正整数 | 收缩权重的关键 |
| $\rho$ | 组内相关系数 ICC | $[0,1]$ | $\tau=0$ 时 $\rho=0$ |

### 4. 常见变体与适用条件
- **变体**：非中心化参数化 $\theta_j=\mu+\tau z_j,\ z_j\sim N(0,1)$（数值稳定）；分层回归（$\theta_j$ 带组级协变量）；随机截距/斜率。**适用/限制**：有自然分组且组数 $J\ge5$；每组样本量严重不均时收益最大；$\tau$ 后验塌到 0 附近说明组间差异不显著，完全池化更简单。

---

## 6. 推导思路和思想来源

- **最初困难**：小样本组的无池化估计不可靠；完全池化又抹掉组间结构——两者是"方差"与"偏差"的两难；直接加权平均（如 James-Stein 式收缩）需要人肉定收缩量。
- **关键"转念"**：把"组间差异的大小"本身当作未知参数 $\tau$ 放进模型——先验 $\theta_j\sim N(\mu,\tau^2)$ 不是拍脑袋的，而是**数据驱动的先验（empirical 风格）**；Normal-Normal 共轭自动给出精度加权平均，收缩量由 $n_j,\sigma^2,\tau^2$ 内生决定。
- **推导主线与动机**：写出联合后验 $p(\theta,\mu,\tau,\sigma|y)\propto\prod_j\prod_i N(y_{ij}|\theta_j,\sigma^2)\cdot\prod_j N(\theta_j|\mu,\tau^2)\cdot p(\mu,\tau,\sigma)$；固定 $\mu,\tau,\sigma$ 时 $\theta_j$ 的条件后验是 $\bar y_j$ 与 $\mu$ 的精度加权——收缩公式由此而来。
- **为什么自然得到此结论**：因为"组间差异"本身携带信息（方差 $\tau^2$），把它建模出来，折中比例就自动最优；大样本组 $\frac{n_j}{\sigma^2}$ 远大于 $\frac{1}{\tau^2}$，几乎不收缩——无需人为规则。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（可手算）
- **题目**：两组学生成绩。组 1：$n_1=3,\ \bar y_1=10.3$；组 2：$n_2=1,\ \bar y_2=0$。已知 $\sigma=1,\ \tau=2,\ \mu=5$。求无池化与部分池化的组估计。
- **解题思路与关键步骤**：无池化 $\hat\theta_j=\bar y_j$。部分池化：精度 $n_j/\sigma^2$ 与 $1/\tau^2=0.25$ 加权，$\hat\theta_1=(3\times10.3+0.25\times5)/3.25\approx9.92$；$\hat\theta_2=(1\times0+0.25\times5)/1.25=1.0$。
- **最终答案**：无池化 $(10.3, 0)$；部分池化 $(9.92, 1.0)$——大组几乎不动，单样本组从 0 收缩到 1。**易错点**：忘把 $\sigma^2,\tau^2$ 取倒数（精度）；把 $\tau$ 当 $\sigma$ 用。
- **🤔 追问**：若 $\tau$ 降到 0.5？——$\frac{1}{\tau^2}=4$ 远大于组内精度，两组都强烈收缩向 $\mu$，说明"组间差异小"时全体向全局看齐，趋向完全池化。

### 例子 2：中等例子（条件判断与多步推理）
- **题目**：Gelman 8 schools 数据：8 所学校的 SAT 补习效果 $\bar y_j$（标准差 $\sigma_j$ 已知），$n_j$ 从 3 到 38 不等，$\bar y$ 整体约为 7.7。为什么个别学校原始估计为负（-1 左右）而层次模型给正值？判断该不该信原始负值。
- **解题思路与完整解答**：负值学校样本量极小（$n_j=3$），无池化估计被噪声主导；层次模型中 $\frac{1}{\tau^2}\mu$ 与组内精度同量级，$\hat\theta_j$ 被拉向 $\mu\approx7.7$，区间显著变窄。**关键推理**：数据不支持"效果为负"——区间几乎覆盖 0 且收缩后为正，小样本组的极端值多半是噪声。**易错点**：把点估计当全部信息忽略区间宽度；以为收缩是"向 0 收缩"——实际是"向信息量更大的全局均值收缩"。

### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：HW04 验收 = 复现 PyMC `hierarchical_partial_pooling`（radon 案例：各县的氡浓度，$n_j$ 从 1 到 100+），跑通三模型对比 + 收缩图 + 后验预测按组校验。代码形态（非中心化参数化，对照 PyMC Examples `case_studies/hierarchical_partial_pooling`）：
```python
import numpy as np, pymc as pm, arviz as az
J = len(counties); group_idx = county_index
with pm.Model() as hier:
    mu  = pm.Normal("mu", mu=0, sigma=10)        # 超先验：全局水平
    tau = pm.HalfCauchy("tau", beta=1)           # 组间标准差
    z   = pm.Normal("z", 0, 1, shape=J)          # 非中心化潜变量
    theta = pm.Deterministic("theta", mu + tau*z)
    sigma = pm.HalfNormal("sigma", sigma=5)      # 组内标准差
    obs = pm.Normal("obs", mu=theta[group_idx], sigma=sigma, observed=y)
with hier:
    trace = pm.sample(1000, chains=4, tune=1000, random_seed=42)
print(az.summary(trace, var_names=["mu", "tau", "theta"], round_to=3))
```
- **实际价值与转化**：`az.summary` 中对比"小样本县 $\theta_j$ 的 HDI 宽度"与"无池化模型的宽度"，直接产出 HW04 要求的收缩分析；`tau` 的后验 HDI 不包含 0 说明组间差异显著，收缩有据可依。

## 8. 常见误区和易混概念

### 误区 1：完全池化 = "用全部数据更稳，所以更好"
- **错误直觉**：样本量越大越可靠，合并所有组样本量最大。
- **为什么错**：完全池化假设组间无差异，组水平推断（如"这个县的风险"）系统性有偏；当 $\tau$ 大时偏差远大于方差收益。**正确理解**：池化方式的选择本质是"组间方差 $\tau^2$ 是否显著"的经验问题，不是样本量问题。

### 误区 2：收缩 = 人为篡改数据 / 把结果往 0 拉
- **错误直觉**：层次模型"不诚实"，把小样本组的结果改小了。
- **为什么错**：收缩是**精度加权**——向信息量更大的全局估计借力，最小化均方误差（方差-偏差权衡），James-Stein 效应有严格统计证明。**正确理解**：收缩方向是 $\mu$ 不是 0；收缩量由数据内生决定。

### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 无池化 | 组参数独立 | 小样本组方差爆炸 | 每组样本都很大 |
| 完全池化 | 忽略组间差异 | 组水平推断有偏 | 组间方差可忽略 |
| 部分池化 | 组间差异建模 | 数据驱动收缩 | 组数多、样本不均（HW04） |
| 固定效应 vs 随机效应 | 组参数是否共享分布 | 前者独立估计（无池化），后者来自超先验（部分池化） | 频率派术语对应 |

### 题目与解析

#### 1. 无池化、完全池化、部分池化对"组参数"分别做了什么假设？
> [!question]- 答案解析
> - **答案**：无池化假设组参数相互独立（各用各的数据）；完全池化假设所有组参数相等（共用一个均值）；部分池化假设组参数来自同一个分布 $\theta_j\sim N(\mu,\tau^2)$（共享组间方差结构，允许组间不同但相互借力）。
> - **解析**：三者是"独立性假设"的连续谱：完全独立 → 共享分布 → 完全相等；层次模型把"组间差异"当可估计的结构而非噪声。
> - **易错原因**：把"部分池化"误当成"无池化和完全池化的简单平均"；对应误区 1（完全池化更稳）。
> - **Obsidian 标签建议**：`#自测题/基础`

#### 2. 已知 $\sigma^2=1,\ \tau^2=4,\ \mu=10$，某组 $n_j=4,\ \bar y_j=22$，求部分池化估计 $\hat\theta_j^{\mathrm{PP}}$。
> [!question]- 答案解析
> - **答案**：$\hat\theta_j^{\mathrm{PP}}=\frac{4\times22+0.25\times10}{4+0.25}=\frac{90.5}{4.25}\approx21.3$。
> - **解析**：组内精度 4 与先验精度 0.25 加权，大样本组收缩幅度小（22→21.3）；若 $n_j=1$，则 $\hat\theta_j=\frac{22+2.5}{1.25}=19.6$，收缩更明显。**易错原因**：直接用方差加权而不用精度（倒数）；忘记 $\bar y_j$ 要乘 $n_j$。

#### 3. 什么条件下层次模型（部分池化）相比无池化收益最大？什么条件下收益趋近于零？
> [!question]- 答案解析
> - **答案**：收益最大 = 组数 $J$ 较多 + 组内样本量 $n_j$ 严重不均 + 组间差异真实存在（$\tau$ 后验明显大于 0）；收益趋近于零 = 所有 $n_j$ 都很大（各组证据充分，收缩量 $\approx0$）或 $\tau\approx0$（组间无差异，退化为完全池化）。
> - **解析**：收缩量由 $\frac{n_j/\sigma^2}{n_j/\sigma^2+1/\tau^2}$ 决定；$n_j$ 大或 $\tau$ 大时收缩趋近 0；两者都小才收缩。**易错原因**：以为"数据越多层次模型越好"——数据极充足时三模型等价，收益来自"数据不足的组"。

#### 4. 后验给出 $\tau=0.05$（HDI 含 0），$\sigma=2$。ICC 是多少？这说明什么？下一步建议？
> [!question]- 答案解析
> - **答案**：$\rho=\frac{0.05^2}{0.05^2+4}\approx0.0006$，组间方差可忽略——组与组几乎没有系统性差异。建议：换完全池化模型更简洁（或至少报告 $\rho$ 后再决定），此时按组解释"差异"没有证据。
> - **解析**：ICC 度量"总方差中组间占比"；$\rho$ 小时层次模型与完全池化结果几乎一致，但 $\tau$ 的不确定性本身有价值（敏感性分析素材）。**易错原因**：只看 $\tau$ 点估计不看 HDI；忘记 ICC 是 HW04 报告的标准统计量。

#### 5. 为什么层次模型容易出 divergent transitions？非中心化参数化为什么能缓解？
> [!question]- 答案解析
> - **答案**：中心化形式中 $\theta_j$ 与 $\mu,\tau$ 强相关（$\theta_j$ 的分布随 $\tau$ 缩放），后验呈"漏斗形"（funnel），NUTS 在窄口处步长失配产生发散；非中心化 $\theta_j=\mu+\tau z_j$ 把相关性转移到 $z_j\sim N(0,1)$（与 $\mu,\tau$ 近似独立），几何变"圆"，NUTS 高效混合。
> - **解析**：这是 [[NUTS与PyMC建模流程]] 中"发散→重参数化"在层次模型上的具体应用；HW04 验收要求最终 `r_hat<1.01`、`ess>400` 且无发散。**易错原因**：把发散当模型错误而放弃层次模型；或在中心化形式下盲目加大 `draws`（治标不治本）。
