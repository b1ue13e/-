# 贝叶斯统计-共轭先验与解析后验推导

> 所属阶段：[[🧭 阶段1-贝叶斯基础|阶段1：贝叶斯基础]]

## 1. 核心推导任务

当后验分布与先验分布处于同一参数形式的概率分布族时，我们可以直接通过代数恒等式写出后验超参数的解析闭式解，从而彻底免去高维数值采样的负担。

本卡给出贝叶斯推断中两个最经典的解析推导全过程：
1. **一维离散-连续共轭：Beta-Binomial 闭式解与边际分布**；
2. **一维连续-连续共轭：Normal-Normal 精度加和与配方法展开**。

---

## 2. 推导一：Beta-Binomial 模型的完整代数推导

### (1) 模型设定
- 观测数据：$n$ 次独立同分布伯努利试验中出现 $y$ 次成功，$y \sim \text{Binomial}(n, \theta)$；
- 似然函数：$P(y \mid \theta) = \binom{n}{y} \theta^y (1 - \theta)^{n - y}$；
- 先验分布：$\theta \sim \text{Beta}(\alpha, \beta)$，其先验密度为：
  $$P(\theta) = \frac{1}{B(\alpha, \beta)} \theta^{\alpha - 1} (1 - \theta)^{\beta - 1}, \quad \theta \in [0, 1]$$
  其中 $B(\alpha, \beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha + \beta)}$ 为 Beta 归一化常数。

### (2) 后验分布推导 (Kernel Method 核心法)
结合贝叶斯公式，后验概率密度为：
$$P(\theta \mid y) \propto P(y \mid \theta) P(\theta)$$
代入具体形式并提取关于未知参数 $\theta$ 的核心因式（将与 $\theta$ 无关的常数并入比例常数）：
$$P(\theta \mid y) \propto \left[ \theta^y (1 - \theta)^{n - y} \right] \cdot \left[ \theta^{\alpha - 1} (1 - \theta)^{\beta - 1} \right]$$
指数合并：
$$P(\theta \mid y) \propto \theta^{(\alpha + y) - 1} (1 - \theta)^{(\beta + n - y) - 1}$$

**结论识别**：上式与 $\text{Beta}(\alpha_{\text{post}}, \beta_{\text{post}})$ 的核函数完全一致！因此后验分布严格服从 Beta 分布：
$$\theta \mid y \sim \text{Beta}(\alpha + y, \beta + n - y)$$

### (3) 边际似然函数 (Beta-Binomial 分布)
积分求归一化分母：
$$P(y) = \int_0^1 P(y \mid \theta) P(\theta) d\theta = \binom{n}{y} \frac{1}{B(\alpha, \beta)} \int_0^1 \theta^{(\alpha + y) - 1} (1 - \theta)^{(\beta + n - y) - 1} d\theta$$
代入 Beta 积分定义：
$$P(y) = \binom{n}{y} \frac{B(\alpha + y, \beta + n - y)}{B(\alpha, \beta)}$$
此即著名的 **Beta-Binomial 边际复合分布**，在统计物理与客户购买频率建模中广泛用作处理过分散 (Overdispersion) 的基准分布。

## 3. 推导二：Normal-Normal 模型的配方法推导

### (1) 模型设定
- 观测数据：$y = (y_1, y_2, \dots, y_n)$，已知方差为 $\sigma^2$（即数据精度 $\tau = 1/\sigma^2$），样本均值为 $\bar{y} = \frac{1}{n} \sum y_i$；
- 联合似然函数：
  $$P(y \mid \theta) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi \sigma^2}} \exp\left( -\frac{(y_i - \theta)^2}{2\sigma^2} \right) \propto \exp\left( -\frac{n}{2\sigma^2} (\bar{y} - \theta)^2 \right)$$
- 先验分布：$\theta \sim \mathcal{N}(\mu_0, \sigma_0^2)$（先验精度 $\tau_0 = 1/\sigma_0^2$）：
  $$P(\theta) \propto \exp\left( -\frac{1}{2\sigma_0^2} (\theta - \mu_0)^2 \right)$$

### (2) 指数配方展开推导
写出未归一化后验密度的指数部分 $Q(\theta)$：
$$P(\theta \mid y) \propto \exp\left( -\frac{1}{2} Q(\theta) \right)$$
$$Q(\theta) = \frac{(\theta - \mu_0)^2}{\sigma_0^2} + \frac{n(\theta - \bar{y})^2}{\sigma^2} = \tau_0 (\theta - \mu_0)^2 + n\tau (\theta - \bar{y})^2$$

展开二次项与一次项：
$$Q(\theta) = \tau_0 (\theta^2 - 2\mu_0 \theta + \mu_0^2) + n\tau (\theta^2 - 2\bar{y}\theta + \bar{y}^2)$$
$$Q(\theta) = (\tau_0 + n\tau) \theta^2 - 2(\tau_0 \mu_0 + n\tau \bar{y}) \theta + \text{Const}$$

令后验精度 $\tau_n \triangleq \tau_0 + n\tau$（即 $\frac{1}{\sigma_n^2} = \frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}$），对 $\theta$ 重新配方：
$$Q(\theta) = \tau_n \left( \theta^2 - 2 \frac{\tau_0 \mu_0 + n\tau \bar{y}}{\tau_n} \theta \right) + \text{Const} = \tau_n (\theta - \mu_n)^2 + \text{Const}'$$
其中后验均值 $\mu_n$ 为：
$$\mu_n \triangleq \frac{\tau_0 \mu_0 + n\tau \bar{y}}{\tau_0 + n\tau} = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{n\bar{y}}{\sigma^2}}{\frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}}$$

### (3) 后验均值的凸组合物理意义
定义先验与样本的相对权重 $w = \frac{n/\sigma^2}{1/\sigma_0^2 + n/\sigma^2}$：
$$\mu_n = (1 - w) \mu_0 + w \bar{y}$$
- 当样本量 $n \to \infty$ 时，$w \to 1$，$\mu_n \to \bar{y}$，先验被海量数据完全淹没；
- 当先验极度确信（$\sigma_0^2 \to 0$）时，$w \to 0$，$\mu_n \to \mu_0$，数据无法动摇先验；
- 当先验无信息（$\sigma_0^2 \to \infty$）时，后验均值精确退化为 MLE 估计 $\bar{y}$，方差为 $\sigma^2/n$。

## 4. 主动回忆与闭卷自测

- [ ] 在纸上不查任何资料，独立写出 Normal-Normal 配方法推导中 $\theta^2$ 与 $\theta$ 项合并并重构平方的过程；
- [ ] 解释 Beta 分布中 $\alpha, \beta$ 超参数为何可解释为“先验虚拟成功与失败次数”；
- [ ] 若给定泊松似然 $y_i \sim \text{Poisson}(\lambda)$ 与先验 $\lambda \sim \text{Gamma}(\alpha, \beta)$，口算其后验参数。

> [!tip]- 闭卷自测参考答案与思维误区
> 1. **Normal-Normal 配方核心**：
>    二次项系数：$\tau_n = \tau_0 + n\tau = \frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}$；
>    一次项系数：$2(\tau_0 \mu_0 + n\tau \bar{y})$；
>    提取系数并重构平方：$\tau_n \left( \theta^2 - 2 \frac{\tau_0 \mu_0 + n\tau \bar{y}}{\tau_n} \theta \right) = \tau_n (\theta - \mu_n)^2$，其中 $\mu_n = \frac{\tau_0 \mu_0 + n\tau \bar{y}}{\tau_0 + n\tau}$。
> 2. **Beta 虚拟计数直觉**：
>    后验核形式为 $\theta^{(\alpha + y) - 1} (1-\theta)^{(\beta + n - y) - 1}$。数学上，$y$ 与 $n-y$ 是实际观测到的成功与失败次数，$\alpha$ 与 $\beta$ 与之处于完全对称的代数加和位置，因此 $\alpha-1$ 与 $\beta-1$ 直观对应于先验伪计数。
> 3. **Gamma-Poisson 闭算**：
>    似然核 $\propto \lambda^{\sum y_i} e^{-n\lambda}$，先验核 $\propto \lambda^{\alpha-1} e^{-\beta\lambda}$。指数与底数合并得到 $\lambda^{(\alpha + \sum y_i) - 1} e^{-(\beta + n)\lambda}$，因此后验严格为 $\text{Gamma}(\alpha + \sum y_i, \beta + n)$。
