# 贝叶斯统计-后验预测分布与贝叶斯点区间估计

> 所属阶段：[[🧭 阶段1-贝叶斯基础|阶段1：贝叶斯基础]]

---

## 1. 为什么不能直接将后验均值代入似然？

在得到参数的后验分布 $P(\theta \mid y)$ 之后，我们常常需要对**未来的全新未见观测 $\tilde{y}$** 做出概率预测。

一个常见的致命错误是所谓的**插入法 (Plug-in Approximation)**：
$$\text{Plug-in Prediction} = P(\tilde{y} \mid \hat{\theta}_{\text{mean}})$$
插入法完全**忽略了参数估计本身包含的认知不确定性**，导致对极端事件的概率严重低估、预测区间过窄（过度自信）。

贝叶斯推断的做法是**对参数空间求全期望**，将所有可能参数取值的预测按后验概率进行连续加权平均：
$$P(\tilde{y} \mid y) = \int_{\Theta} P(\tilde{y} \mid \theta) P(\theta \mid y) d\theta$$

---

## 2. 后验预测分布 (PPD) 的解析推导

### (1) Beta-Binomial 模型的下一件抽样预测
已知 $\theta \mid y \sim \text{Beta}(\alpha', \beta')$，其中 $\alpha' = \alpha + y, \beta' = \beta + n - y$。
预测下一个单次试验 $\tilde{y} \in \{0, 1\}$ 成功的概率：
$$P(\tilde{y} = 1 \mid y) = \int_0^1 P(\tilde{y} = 1 \mid \theta) P(\theta \mid y) d\theta = \int_0^1 \theta \cdot P(\theta \mid y) d\theta = \mathbb{E}[\theta \mid y]$$
代入 Beta 分布均值公式：
$$P(\tilde{y} = 1 \mid y) = \frac{\alpha'}{\alpha' + \beta'} = \frac{\alpha + y}{\alpha + \beta + n}$$

### (2) Normal-Normal 模型的方差膨胀定理 (全方差公式)
设数据生成模型为 $\tilde{y} \sim \mathcal{N}(\theta, \sigma^2)$，已知后验 $\theta \mid y \sim \mathcal{N}(\mu_n, \sigma_n^2)$。
利用全期望公式与全方差公式 (Law of Total Variance)：
$$\mathbb{E}[\tilde{y} \mid y] = \mathbb{E}_{\theta \mid y}[\mathbb{E}(\tilde{y} \mid \theta)] = \mathbb{E}[\theta \mid y] = \mu_n$$
$$\text{Var}(\tilde{y} \mid y) = \mathbb{E}_{\theta \mid y}[\text{Var}(\tilde{y} \mid \theta)] + \text{Var}_{\theta \mid y}(\mathbb{E}[\tilde{y} \mid \theta]) = \sigma^2 + \sigma_n^2$$

**结论**：
$$\tilde{y} \mid y \sim \mathcal{N}\left(\mu_n, \sigma^2 + \sigma_n^2\right)$$
后验预测方差严格等于**固有偶发不确定性 (Aleatoric, $\sigma^2$)** 与**参数认知不确定性 (Epistemic, $\sigma_n^2$)** 之和！随着样本量 $n \to \infty$，$\sigma_n^2 \to 0$，预测方差渐近收敛于固有下界 $\sigma^2$。

---

## 3. 决策论视角：损失函数驱动的最优贝叶斯点估计

后验分布是一个完整的概率密度曲面，但若现实任务强制要求输出单一数值决策点 $a \in \mathbb{R}$，则最优选择完全由**损失函数 $L(\theta, a)$** 决定：
$$a^* = \arg\min_a \mathbb{E}_{\theta \mid y}[L(\theta, a)] = \arg\min_a \int_\Theta L(\theta, a) P(\theta \mid y) d\theta$$

| 损失函数形态 $L(\theta, a)$ | 物理含义 | 最优贝叶斯点估计 $a^*$ | 数学证明依据 |
| :--- | :--- | :--- | :--- |
| **平方误差损失 (Quadratic Loss)**<br>$L(\theta, a) = (\theta - a)^2$ | 对大误差施加严厉惩罚 | **后验均值 (Posterior Mean)**<br>$\mathbb{E}[\theta \mid y]$ | $\frac{\partial}{\partial a} \mathbb{E}[(\theta-a)^2] = -2(\mathbb{E}[\theta \mid y] - a) = 0$ |
| **绝对误差损失 (Linear Loss)**<br>$L(\theta, a) = \lvert \theta - a \rvert$ | 对正负误差线性惩罚，对离群点稳健 | **后验中位数 (Posterior Median)**<br>$\text{Median}(\theta \mid y)$ | $\frac{\partial}{\partial a} \mathbb{E}[\lvert \theta-a \rvert] = P(\theta < a) - P(\theta > a) = 0$ |
| **0-1 损失 (0-1 Loss)**<br>$L(\theta, a) = I(\lvert \theta - a \rvert > \epsilon)$ | 只要不完全精确就遭受固定惩罚 | **最大后验估计 (MAP / Mode)**<br>$\arg\max_\theta P(\theta \mid y)$ | 取极限 $\epsilon \to 0$ 时积分退化为局部最高密度点 |

## 4. 贝叶斯区间估计：HPD 区间 vs 等尾可信区间 (ETI)

不同于频率学派的置信区间，贝叶斯**可信区间 (Credible Interval)** 具有直接的概率解释：$P(\theta \in [L, U] \mid y) = 1 - \alpha$。

```mermaid
graph TD
    A[贝叶斯可信区间 (1 - alpha)] --> B[等尾区间 ETI: Equal-Tailed Interval]
    A --> C[最高后验密度区间 HPD / HDI]
    B --> B1[两端各切除 alpha/2 分位数]
    B --> B2[优点: 单调变换不变性, 计算极快]
    C --> C1[满足区间内所有点密度均高于区间外]
    C --> C2[优点: 具有最短区间长度, 适合偏态/多峰分布]
```

### (1) 最高后验密度区间 (Highest Posterior Density, HPD)
定义集合 $C_{1-\alpha} = \{ \theta : P(\theta \mid y) \ge k_\alpha \}$，其中常数 $k_\alpha$ 满足 $\int_{C_{1-\alpha}} P(\theta \mid y) d\theta = 1 - \alpha$。
- **几何特征**：在所有覆盖 $1-\alpha$ 概率质量的区间中，**HPD 区间的总几何长度（勒贝格测度）严格最短**；
- **多峰处理**：若后验分布呈现双峰，HPD 会自动断裂为两个分离的区间并集，精准反映不确定性。

## 5. 主动回忆与闭卷自测

- [ ] 利用全方差公式证明后验预测方差严格大于已知参数时的观测方差；
- [ ] 解释为什么偏态分布下，后验均值、后验中位数与 MAP 点估计会发生分离；
- [ ] 比较 HPD 区间与 ETI 区间在指数分布后验下的几何差异。

> [!tip]- 闭卷自测参考答案与思维误区
> 1. **全方差证明**：由 $\text{Var}(\tilde{y} \mid y) = \mathbb{E}[\text{Var}(\tilde{y}\mid\theta)] + \text{Var}(\mathbb{E}[\tilde{y}\mid\theta]) = \sigma^2 + \sigma_n^2$。因为后验认知方差 $\sigma_n^2 > 0$，所以 $\text{Var}(\tilde{y} \mid y) > \sigma^2$。若直接使用插入法，相当于强行令 $\sigma_n^2 = 0$，必然低估预测风险。
> 2. **三点估计分离**：在右偏分布（如收入或故障时间）中，长尾极端值将均值向右拉动，而众数 (MAP) 位于峰值，中位数位于累积 50% 处，呈现 $\text{Mode} < \text{Median} < \text{Mean}$ 的严格偏斜序列。因此点估计必须与业务实际承担的损失函数（平方、绝对或 0-1）严格匹配。
> 3. **指数分布下 HPD vs ETI**：对于单调递减的指数分布 $\text{Exp}(\lambda)$，最高密度点始终在 $\theta = 0$ 处。因此 95% HPD 区间是从 $0$ 到 95% 分位数（单侧紧凑），长度最短；而 95% ETI 区间会在左侧强行切除 2.5% 的尾部，导致区间包含低密度区域且总长度更大。
