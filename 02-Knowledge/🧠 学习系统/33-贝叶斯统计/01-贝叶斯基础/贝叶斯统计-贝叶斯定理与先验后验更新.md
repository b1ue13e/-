# 贝叶斯统计-贝叶斯定理与先验后验更新

> 所属阶段：[[🧭 阶段1-贝叶斯基础|阶段1：贝叶斯基础]]

---

## 1. 核心问题与统计哲学转变

在频率学派框架下，参数 $\theta$ 被视为**客观存在但未知的固定常数**，所有不确定性仅来源于随机抽样的变异性。由此产生的 95% 置信区间并不表示“参数落在该区间的概率为 95%”，而是“重复抽样 100 次所构造的区间中，有 95 个会覆盖该固定真值”。

**贝叶斯学派的范式转换**：
1. **参数是随机变量**：由于观测者的知识不完全，参数 $\theta$ 本身用概率分布 $P(\theta)$ 描述其认知不确定性 (Epistemic Uncertainty)；
2. **推断即条件更新**：通过观测数据 $y$，利用条件概率公式将先验信念 $P(\theta)$ 剪裁为后验分布 $P(\theta \mid y)$；
3. **保留全分布**：推断的终局不是单个点，而是完整的后验几何曲面。

---

## 2. 贝叶斯定理的严格数学表达

设未知参数空间为 $\Theta$，观测数据空间为 $\mathcal{Y}$：

$$P(\theta \mid y) = \frac{P(y \mid \theta) P(\theta)}{P(y)} = \frac{P(y \mid \theta) P(\theta)}{\int_{\Theta} P(y \mid \theta') P(\theta') d\theta'}$$

各组成项的形式化定义与角色：
1. **先验分布 (Prior) $P(\theta)$**：在接触当前数据 $y$ 之前，基于物理定律、领域知识或历史实验对 $\theta$ 的概率度量；
2. **似然函数 (Likelihood) $P(y \mid \theta)$**：由数据生成机制决定的条件分布。注意：固定 $y$ 时，$P(y \mid \theta)$ 是关于 $\theta$ 的函数，通常不是概率密度（积分不必为 1）；
3. **边际似然 / 归一化常数 (Evidence / Marginal Likelihood) $P(y)$**：对所有可能参数状态积分得到的数据发生总概率。它是先验预测分布对实际观测点的评估值，确保 $\int_\Theta P(\theta \mid y) d\theta = 1$；
4. **后验分布 (Posterior) $P(\theta \mid y)$**：融合数据证据后的认知终态。

### 代数核心正比关系
由于分母 $P(y) = \int_\Theta P(y \mid \theta) P(\theta) d\theta$ 与特定 $\theta$ 无关（仅为定值标量常数），贝叶斯推断核心公式简化为：
$$\text{Posterior} \propto \text{Likelihood} \times \text{Prior}$$
$$P(\theta \mid y) \propto P(y \mid \theta) P(\theta)$$

## 3. 序贯更新性质 (Sequential Bayesian Updating)

贝叶斯推断具有天然的时序一致性。设我们先后独立观测到两批独立数据 $y_1$ 和 $y_2$。

**第一步**：基于第一批数据 $y_1$ 更新：
$$P(\theta \mid y_1) = \frac{P(y_1 \mid \theta) P(\theta)}{P(y_1)}$$

**第二步**：当第二批数据 $y_2$ 到达时，以当前后验 $P(\theta \mid y_1)$ 作为**新的先验**：
$$P(\theta \mid y_1, y_2) = \frac{P(y_2 \mid \theta, y_1) P(\theta \mid y_1)}{P(y_2 \mid y_1)}$$
由于给定参数 $\theta$ 时数据条件独立（$P(y_2 \mid \theta, y_1) = P(y_2 \mid \theta)$），代入第一步表达式：
$$P(\theta \mid y_1, y_2) = \frac{P(y_2 \mid \theta) \cdot \frac{P(y_1 \mid \theta) P(\theta)}{P(y_1)}}{P(y_2 \mid y_1)} = \frac{P(y_1, y_2 \mid \theta) P(\theta)}{P(y_1, y_2)}$$

**结论**：**分批流式逐步更新与一次性批处理全量数据，得到的最终后验分布完全恒等**。

## 4. 最小 Python 数值演示：先验与似然相乘

```python
import numpy as np

def bayesian_grid_update(theta_grid: np.ndarray, prior: np.ndarray, y: int, n: int) -> np.ndarray:
    """基于离散网格近似的连续贝叶斯更新演示."""
    # 似然函数: Binomial(n, theta)
    likelihood = (theta_grid ** y) * ((1.0 - theta_grid) ** (n - y))
    
    # 未归一化后验
    unnormalized_posterior = likelihood * prior
    
    # 数值积分 (梯形公式) 归一化
    evidence = np.trapz(unnormalized_posterior, theta_grid)
    posterior = unnormalized_posterior / evidence
    return posterior

# 演示: 10次试验7次成功
grid = np.linspace(0.0, 1.0, 1000)
flat_prior = np.ones_like(grid) / 1.0
post = bayesian_grid_update(grid, flat_prior, y=7, n=10)
print(f"后验众数 (MAP) 接近: {grid[np.argmax(post)]:.3f}")
```

## 5. 易混淆概念与反例库

### 误区 1：把最大似然估计 (MLE) 等同于贝叶斯后验
- **反例**：抛一枚硬币 3 次均出现正面（$y=3, n=3$）。
  - MLE 给出 $\hat{\theta}_{\text{MLE}} = 3/3 = 1.0$，荒谬地断言这枚硬币绝不可能出现反面；
  - 贝叶斯后验结合无偏先验 $\text{Beta}(2, 2)$ 后得到 $\text{Beta}(5, 2)$，后验均值为 $\frac{5}{7} \approx 0.714$，合理保留了反面出现的可能性。

### 误区 2：误以为先验是“无根据的主观臆断”
- 先验可以来源于：
  1. 物理约束（如质量、方差必须 $>0$）；
  2. 历史基线研究（如前期临床试验已有的几百例样本）；
  3. 最大熵原理（在给定均值方差约束下选择信息量最少的先验，如高斯分布）；
  4. 正则化弱先验（防止参数在高维空间由于噪声飞逸）。

### 误区 3：忽视先验-似然冲突 (Prior-Data Conflict) 导致的多峰破坏
- **现象**：当领域先验断言 $\theta \approx 0$（高精度小方差），而观测数据强力指向 $y \approx 10$ 时，如果后验模型使用重尾柯西分布似然，后验分布 $P(\theta \mid y)$ 会呈现**非凸的双峰结构 (Bimodal)**，导致后验均值失去代表性（落在概率极低的中间谷底 5）。
- **解法**：必须进行先验敏感性分析（Prior Sensitivity Analysis），并在模型比较中使用 PSIS-LOO 诊断极值尾部厚度。

- [ ] 解释为什么边际似然 $P(y) = \int P(y \mid \theta) P(\theta) d\theta$ 在高维参数空间下是难以直接计算的瓶颈；
- [ ] 用自己的话解释先验、似然、边际似然与后验的物理含义。

> [!tip]- 闭卷自测参考答案与思维误区
> 1. **序贯更新恒等式**：$P(\theta \mid y_1, y_2) = \frac{P(y_2 \mid \theta, y_1) P(\theta \mid y_1)}{P(y_2 \mid y_1)} = \frac{P(y_2 \mid \theta) \frac{P(y_1 \mid \theta) P(\theta)}{P(y_1)}}{\frac{P(y_1, y_2)}{P(y_1)}} = \frac{P(y_1, y_2 \mid \theta) P(\theta)}{P(y_1, y_2)}$。在展开分子时，条件独立性 $P(y_2 \mid \theta, y_1) = P(y_2 \mid \theta)$ 起到了核心作用。
> 2. **高维积分瓶颈（维数灾难）**：当 $\theta \in \mathbb{R}^D$ 且 $D \ge 20$ 时，若用网格数值积分，每个维度取 100 个点需要 $100^{20} = 10^{40}$ 次函数计算，即便使用超级计算机也无法在宇宙寿命内完成。因此必须依赖马尔可夫链蒙特卡洛 (MCMC) 采样直接绕过边际似然 $P(y)$ 的计算。
> 3. **核心物理含义**：
>    - **先验 $P(\theta)$**：观察数据前的初始置信空间（领域知识或正则化假设）；
>    - **似然 $P(y \mid \theta)$**：在给定参数假设下，观测到当前数据的生成概率相容度；
>    - **边际似然 $P(y)$**：所有可能参数对数据的加权平均预测总概率（归一化常数）；
>    - **后验 $P(\theta \mid y)$**：吸收观测证据后更新的信念终态。
