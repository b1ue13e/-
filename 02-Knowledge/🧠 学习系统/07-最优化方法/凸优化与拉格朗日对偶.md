# 凸优化与拉格朗日对偶 (Lagrangian Duality)

## 0. 先判断它值不值得深挖
- **类别**：A 类（优化理论的绝对核心、灵魂）
- **判断理由**：拉格朗日对偶是将带约束问题转化为无约束问题的根基。它不仅提供了原问题最优解的下界，更是推导 KKT 条件、理解支持向量机（SVM）、以及设计现代算法（如 ADMM、内点法）的基石。不懂对偶，就不懂现代优化。

---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
考虑标准优化问题：
$$\min f_0(x) \quad \text{s.t.} \quad f_i(x) \le 0, \quad h_i(x) = 0$$
这里的硬约束让我们很难受。我们希望：
1. 能不能把硬约束“软化”，变成目标函数里的惩罚项？
2. 即使问题是非凸的，很难求解，能不能找到它最优值的一个“下界”（Lower Bound）？

---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：对偶理论将原问题（Primal）和一个新的凹优化问题（Dual）联系起来。对于凸优化，两者通常等价；对于非凸优化，对偶提供下界。
- **实际应用场景**：SVM中的核技巧（只有在对偶问题中才能自然引入核函数）、资源分配问题中的定价（对偶变量就是“影子价格”）、整数规划的松弛。
- **高频题型/任务**：推导给定问题的拉格朗日对偶函数、写出 KKT 条件、证明某问题的强对偶性。

## 4. 用直觉语言解释它
> «"这东西其实就像……"»
- **直觉类比/几何图像**：
  想象你是一个包工头（原问题），要在满足各种工期、材料限制下（约束）让成本最低（目标）。
  此时来了一个监管部门（对偶变量 $\lambda, \nu$），如果你的工期超了、材料不符合，他就会对你罚款。罚款的严厉程度就是乘子。
  **拉格朗日函数**就是你面临的“总成本 = 原始成本 + 罚款”。
  监管部门非常聪明，他们要在所有可能的罚款标准中，选出一种最严厉的标准（$\max_{\lambda, \nu}$），最大化你的最低可能成本。
- **弱对偶性**：无论监管部门怎么罚款，你尽力调整后的最低总成本，永远**小于等于**你一开始老老实实满足硬约束时的最低成本（因为老老实实满足约束时，罚款必定 $\le 0$）。
- **强对偶性**：对于“好的”问题（凸优化+Slater条件），监管部门的最高罚款逼迫出的成本，**刚好等于**你原计划的完美成本。这就叫强对偶。

## 5. 正式定义、核心公式、符号解释
### 1. 拉格朗日函数 (Lagrangian)
将约束引入目标，定义 $\mathcal{L}: \mathbb{R}^n \times \mathbb{R}^m \times \mathbb{R}^p \to \mathbb{R}$：
$$\mathcal{L}(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{i=1}^p \nu_i h_i(x)$$
注意：必须有 $\lambda_i \ge 0$。

### 2. 拉格朗日对偶函数 (Lagrange Dual Function)
对偶函数是拉格朗日函数对 $x$ 取下确界：
$$g(\lambda, \nu) = \inf_x \mathcal{L}(x, \lambda, \nu)$$
**极重要性质**：无论原问题是否为凸，$g(\lambda, \nu)$ 总是关于 $\lambda, \nu$ 的**凹函数**。

### 3. 对偶问题 (Dual Problem)
寻找最严厉的罚款机制：
$$\max_{\lambda \ge 0, \nu} g(\lambda, \nu)$$

### 4. 强弱对偶性
设原问题最优值为 $p^*$，对偶问题最优值为 $d^*$。
- **弱对偶 (Weak Duality)**：$d^* \le p^*$。差值 $p^* - d^*$ 称为对偶间隙。
- **强对偶 (Strong Duality)**：$d^* = p^*$。通常在原问题是凸优化且满足 **Slater 条件**（存在严格可行点）时成立。

### 5. KKT 条件
若强对偶成立，且函数可微，那么任何一对原最优解 $x^*$ 和对偶最优解 $(\lambda^*, \nu^*)$ 必须满足：
1. **平稳性 (Stationarity)**: $\nabla f_0(x^*) + \sum \lambda_i^* \nabla f_i(x^*) + \sum \nu_i^* \nabla h_i(x^*) = 0$
2. **原可行性 (Primal Feasibility)**: $f_i(x^*) \le 0, h_i(x^*) = 0$
3. **对偶可行性 (Dual Feasibility)**: $\lambda_i^* \ge 0$
4. **互补松弛性 (Complementary Slackness)**: $\lambda_i^* f_i(x^*) = 0$

## 6. 推导思路和思想来源
### KKT 中的互补松弛性是怎么来的？
假设强对偶成立，即 $f_0(x^*) = g(\lambda^*, \nu^*)$。
根据定义：
$$g(\lambda^*, \nu^*) = \inf_x \left( f_0(x) + \sum \lambda_i^* f_i(x) + \sum \nu_i^* h_i(x) \right)$$
因为 $x^*$ 是可能取到的极小点之一：
$$\le f_0(x^*) + \sum \lambda_i^* f_i(x^*) + \sum \nu_i^* h_i(x^*)$$
又因为 $h_i(x^*)=0$，且 $\lambda_i^* \ge 0, f_i(x^*) \le 0$：
$$\le f_0(x^*) + 0 + 0 = f_0(x^*)$$
因为最左边和最右边相等，所以中间所有的不等号都必须取等号！
这直接导致：$\sum \lambda_i^* f_i(x^*) = 0$。由于每一项都非正，所以必须各项为零，即 $\lambda_i^* f_i(x^*) = 0$。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：注水算法 (Water-filling)
通信中分配功率以最大化信道容量：
$\min -\sum \log(\alpha_i + x_i)$ s.t. $x_i \ge 0$, $\sum x_i = 1$
构建拉格朗日函数后，利用KKT的平稳性和互补松弛，可解得 $x_i^* = \max(0, \frac{1}{\nu} - \alpha_i)$。由于像往高低不平的池子里注水，水平面为 $1/\nu$，故得名注水算法。

### 例子 2：线性规划的对偶
原问题：$\min c^T x$ s.t. $Ax = b, x \ge 0$
对偶问题推导：
$\mathcal{L}(x, \lambda, \nu) = c^Tx - \lambda^Tx + \nu^T(Ax-b) = -b^T\nu + (c - \lambda + A^T\nu)^T x$
对 $x$ 求下确界，要想不为 $-\infty$，必须要求括号内为 $0$。
因此对偶函数为 $-b^T\nu$，如果 $c - \lambda + A^T\nu = 0$ 且 $\lambda \ge 0$。
转化后就是标准形式的LP对偶。

### 例子 3：支持向量机 (SVM) 对偶推导
SVM原问题（Hard Margin）：
$\min \frac{1}{2}\|w\|^2$ s.t. $y_i(w^T x_i + b) \ge 1$
通过KKT条件，$w^* = \sum \alpha_i y_i x_i$，代回后得到对偶问题：只涉及样本之间的内积 $x_i^T x_j$。这为“核技巧”替代内积打开了大门，使得SVM可以高效处理非线性分类。

## 8. 常见误区和易混概念
### 误区 1：KKT条件对所有优化问题都是充要条件？
**纠正**：错！
- 对于**非凸**问题，KKT 是必要条件（前提是满足正则性条件 Constraint Qualification，如 Slater 或 LICQ）。
- 对于**凸优化**问题，KKT 是**充分条件**。
- 对于**凸优化且满足Slater条件**，KKT 才是**充要条件**。

### 概念对比表
| 变量/函数 | 经济学解释 (影子价格) |
|---|---|
| 原目标 $f_0(x)$ | 总成本 |
| 乘子 $\lambda_i$ | 放宽第 $i$ 个不等式约束带来的边际成本降低（价格）|
| 互补松弛 $\lambda_i f_i = 0$| 如果资源没用完（$f_i < 0$），那么它的边际价值（影子价格）必定为0 |

## 11. 自测题：5 道
> [!question]- 1. 对偶函数 $g(\lambda, \nu)$ 为什么一定是凹函数，无论原问题是否凸？
> 因为 $g(\lambda, \nu) = \inf_x \mathcal{L}(x, \lambda, \nu)$ 是一族关于 $(\lambda, \nu)$ 的仿射函数（即线性加常数）的逐点下确界。仿射函数既凸且凹，一组凹函数的逐点下确界必然是凹函数。这使得对偶问题 $\max g$ 必定是一个凸优化问题。

> [!question]- 2. 什么是 Slater 条件？它有什么作用？
> Slater 条件是指：对于凸优化问题，存在一个点 $x \in \text{relint}(\mathcal{D})$，使得所有的非线性不等式约束严格成立（$f_i(x) < 0$）。其作用是作为强对偶性成立的充分条件。只要满足 Slater 条件，凸优化问题就满足强对偶性。

> [!question]- 3. 在 KKT 条件中，“互补松弛性”具体指什么？它的物理意义是什么？
> 互补松弛性指 $\lambda_i^* f_i(x^*) = 0$。物理意义是：在最优点处，要么约束处于边界被激活（$f_i = 0$，此时惩罚 $\lambda_i$ 可以大于0）；要么约束在可行域内部未被激活（$f_i < 0$，此时这个约束不起作用，其对应的惩罚或“影子价格” $\lambda_i$ 必须严格等于0）。

> [!question]- 4. 如果原问题目标函数无下界（最优值为 $-\infty$），对偶问题的可行域会怎样？
> 根据弱对偶性 $d^* \le p^*$。如果 $p^* = -\infty$，那么必须有 $d^* = -\infty$。由于对偶问题是最大化问题，其结果为 $-\infty$ 的唯一可能就是对偶问题**不可行**（即其可行域为空集）。

> [!question]- 5. 举例说明何种情况下，一个可微非凸问题的最优点不满足 KKT 条件。
> KKT条件作为必要条件需要满足约束验证（CQ）。例如问题：$\min_x x$ s.t. $x^2 \le 0$。唯一可行解是 $x=0$，也是最优点。目标梯度为 1，约束梯度在 $x=0$ 处为 $2(0) = 0$。KKT平稳性要求 $1 + \lambda(0) = 0$，这不可能成立。这是因为在 $x=0$ 处，LICQ 和 Slater 条件均不满足。
