# 凸优化与拉格朗日对偶 (Convex Optimization and Lagrangian Duality)

## 1. 凸优化与拉格朗日对偶的定义与核心性质

**凸优化与拉格朗日对偶 (Convex Optimization and Lagrangian Duality)** 的核心定义是：研究目标函数为凸函数、约束集为凸集的极值问题，并通过构造拉格朗日对偶函数将带约束的原问题 (Primal Problem) 转化为下界无约束或简单约束的对偶问题 (Dual Problem) 的数学优化理论体系。由 Boyd, Vandenberghe 和 Rockafellar 等人建立完善。

**基本性质**：
1. **局部最优即全局最优**：在凸优化问题中，任何局部极小值点必然是全局最小值点；
2. **弱对偶性 (Weak Duality)**：对偶问题的最优值 $d^*$ 天然构成原问题最优值 $p^*$ 的下界，即 $d^* \le p^*$，恒成立；
3. **强对偶性 (Strong Duality)**：当满足 Slater 约束资格 (Slater's Condition) 时，$d^* = p^*$ 成立，此时可以通过求解简单的对偶问题直接得到原问题的全局最优解。

## 2. 拉格朗日对偶与 KKT 条件形式化推导

**原问题形式化表达**：
$$\min_{\mathbf{x}} f_0(\mathbf{x}) \quad \text{s.t.} \quad f_i(\mathbf{x}) \le 0 \; (i=1,\dots,m), \quad h_j(\mathbf{x}) = 0 \; (j=1,\dots,p)$$

**推导过程（拉格朗日函数与对偶问题）**：
1. 构造**拉格朗日函数 (Lagrangian)**，其中 $\boldsymbol{\lambda} \ge \mathbf{0}, \boldsymbol{
u}$ 为乘子向量：
$$L(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{
u}) = f_0(\mathbf{x}) + \sum_{i=1}^m \lambda_i f_i(\mathbf{x}) + \sum_{j=1}^p 
u_j h_j(\mathbf{x})$$
2. 定义**拉格朗日对偶函数 (Lagrangian Dual Function)** $g(\boldsymbol{\lambda}, \boldsymbol{
u}) = \inf_{\mathbf{x}} L(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{
u})$。易证 $g(\boldsymbol{\lambda}, \boldsymbol{
u})$ 总是凹函数；
3. **KKT (Karush-Kuhn-Tucker) 条件推导**（当强对偶成立时，最优解 $(\mathbf{x}^*, \boldsymbol{\lambda}^*, \boldsymbol{
u}^*)$ 必须满足）：
   - **平稳性 (Stationarity)**：$
abla_{\mathbf{x}} L(\mathbf{x}^*, \boldsymbol{\lambda}^*, \boldsymbol{
u}^*) = 
abla f_0(\mathbf{x}^*) + \sum \lambda_i^* 
abla f_i(\mathbf{x}^*) + \sum 
u_j^* 
abla h_j(\mathbf{x}^*) = \mathbf{0}$
   - **原问题可行性 (Primal Feasibility)**：$f_i(\mathbf{x}^*) \le 0, \; h_j(\mathbf{x}^*) = 0$
   - **对偶问题可行性 (Dual Feasibility)**：$\lambda_i^* \ge 0$
   - **互补松弛性 (Complementary Slackness)**：$\lambda_i^* f_i(\mathbf{x}^*) = 0 \; (\forall i)$
4. **因此**，若 $\lambda_i^* > 0$，则必有 $f_i(\mathbf{x}^*) = 0$（约束紧致/生效），这一推导直接决定了 SVM 支持向量的稀疏性质。

## 3. 原问题与拉格朗日对偶问题全方位对比

| 维度 | 原问题 (Primal Problem) | 拉格朗日对偶问题 (Dual Problem) |
|:---|:---|:---|
| **变量空间** | $\mathbf{x} \in \mathbb{R}^n$ (决策变量) | $\boldsymbol{\lambda} \in \mathbb{R}^m, \boldsymbol{
u} \in \mathbb{R}^p$ (拉格朗日乘子) |
| **优化目标** | $\min_{\mathbf{x}} f_0(\mathbf{x})$ | $\max_{\boldsymbol{\lambda} \ge \mathbf{0}, \boldsymbol{
u}} g(\boldsymbol{\lambda}, \boldsymbol{
u})$ |
| **凹凸性要求** | 要求 $f_0, f_i$ 为凸函数 | **对偶函数 $g$ 总是凹函数**（对偶问题总是凸优化） |
| **约束条件** | 含复杂的非线性不等式/等式 | 仅包含非负约束 $\boldsymbol{\lambda} \ge \mathbf{0}$ |
| **工程应用** | 机器特征参数直接求解 | **SVM 核技巧拓展**、资源分配 (Water-filling) |

**局限（误区与反例）**：若原问题非凸，强对偶性通常不成立（存在对偶间隙 Dual Gap $p^* - d^* > 0$）；非凸问题中不能凭空假设 $d^* = p^*$。

## 4. Python 拉格朗日对偶性与 KKT 条件自测断言

```python
import numpy as np

def primal_objective(x: float) -> float:
    """原问题: min x^2 + 1, s.t. x - 2 <= 0"""
    return x**2 + 1.0

def lagrangian_dual_function(lam: float) -> float:
    """
    L(x, lam) = x^2 + 1 + lam*(x - 2)
    dL/dx = 2x + lam = 0 => x* = -lam / 2
    g(lam) = inf_x L(x, lam) = (-lam/2)^2 + 1 + lam*(-lam/2 - 2) = -lam^2/4 - 2*lam + 1
    """
    return -0.25 * (lam**2) - 2.0 * lam + 1.0

if __name__ == "__main__":
    # 1. 验证原问题最优解 x* = 0 (约束 x <= 2 未紧致), p* = 1.0
    x_opt_primal = 0.0
    p_star = primal_objective(x_opt_primal)

    # 2. 求解对偶问题 max_{\lambda >= 0} g(\lambda)
    # dg/dlam = -lam/2 - 2 = 0 => lam* = -4 < 0 (不在可行域内)
    # 因为 g(\lambda) 单调递减, lam >= 0 下最优为 lam* = 0
    lam_opt_dual = 0.0
    d_star = lagrangian_dual_function(lam_opt_dual)

    # 自测验证 1: 强对偶性成立 p* == d*
    assert abs(p_star - d_star) < 1e-6, f"强对偶破坏: {p_star} vs {d_star}"

    # 自测验证 2: KKT 互补松弛性 lam* * f(x*) == 0
    f_val = x_opt_primal - 2.0  # -2.0 < 0
    assert lam_opt_dual * f_val == 0.0, "KKT 互补松弛条件必须满足"

    # 自测验证 3: 弱对偶下界断言 (任意 \lambda >= 0, g(\lambda) <= p*)
    for lam_test in [0.5, 1.0, 5.0]:
        assert lagrangian_dual_function(lam_test) <= p_star

    print(f"凸优化与拉格朗日对偶验证成功: p* = {p_star:.4f}, d* = {d_star:.4f}")
    print("凸优化与拉格朗日对偶单元测试与自查验证全部成功！")
```
