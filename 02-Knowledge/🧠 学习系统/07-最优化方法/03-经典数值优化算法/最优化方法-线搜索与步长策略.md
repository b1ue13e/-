## 0. 学习边界
- **类别**：A 类（工业界算法落地基石）
- **判断理由**：在实际工程中，极其昂贵的“精确线搜索”毫无用处。如何高效、动态、安全地决定“走多远”（步长 $\alpha$），是所有线搜索方法（梯度下降、拟牛顿法）落地的核心。Armijo 和 Wolfe 条件不仅是考试常客，更是你在实现优化器时必须理解的防御性编程逻辑。

---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
在给定了一个下降方向 $p_k$（如负梯度方向或牛顿方向）后，我们需要决定在这个方向上走多远：更新公式为 $x_{k+1} = x_k + \alpha_k p_k$。
如果 $\alpha_k$ 太小，算法会像蜗牛爬行，收敛极慢；
如果 $\alpha_k$ 太大，可能会跨过最优解，导致函数值不降反升，甚至发散（Ping-pong 震荡）。
因此，我们需要一种廉价、有效的规则来寻找一个“足够好但不必最优”的步长。

---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：它是《数值优化》中两大全局化框架之一（另一个是[[最优化方法-信赖域方法]]）。
- **实际应用场景**：SciPy、MATLAB 内部的 `fmin_unc`，深度学习框架的优化器内核，都会用到 Backtracking Line Search（回溯线搜索）或满足 Wolfe 条件的强线搜索。拟牛顿法（如 BFGS）的曲率条件 $s_k^T y_k > 0$ 强依赖于步长满足 Wolfe 条件，否则 Hessian 逼近可能不保正定。
- **高频题型/任务**：Zoutendijk 定理的证明；画图说明为什么只用 Armijo 条件不够，必须加上 Curvature 条件。

---
## 3. 学它之前需要哪些前置知识？
1. **[[最优化方法-最速下降与收敛分析]]**：理解下降方向 $p_k^T \nabla f(x_k) < 0$ 的概念。
2. **泰勒展开**：理解一阶近似 $f(x + \alpha p) \approx f(x) + \alpha p^T \nabla f(x)$。

## 4. 用直觉语言解释它
> «"你想在山上扔个球找谷底。你不仅要确保球往下滚了（Armijo），还要确保球别滚得太远直接飞到对面的半山腰（Wolfe）。"»
- **直觉类比/几何图像**：
  - **Armijo条件**：不仅要求函数值下降，还要求“充分下降”。函数图像必须位于初始切线的一部分比例（比如 10%）的下方。防止步长太小导致的假收敛。
  - **曲率条件（Curvature）**：要求这一步走完后，那个位置的坡度（方向导数）不能像出发点那么陡了。说明我们确实走到了一个比较平缓的地方，防止步长过短。
- **一句话直觉本质**：用两个不等式上下夹击，在“防小步距假死”和“防大步距震荡”之间划定一个安全区。

## 5. 正式定义、核心公式、符号解释
### 1. 核心定义
令 $\phi(\alpha) = f(x_k + \alpha p_k)$ 为沿着射线 $p_k$ 的一维函数。此时 $\phi'(0) = \nabla f(x_k)^T p_k < 0$。

### 2. Armijo 条件（充分下降条件 Sufficient Decrease）
$$f(x_k + \alpha_k p_k) \le f(x_k) + c_1 \alpha_k \nabla f(x_k)^T p_k$$
其中 $c_1 \in (0, 1)$。实际中 $c_1$ 取值极小，如 $10^{-4}$。这个条件要求函数值的下降量，至少是线性近似下降量的一个比例 $c_1$。

### 3. Curvature 条件（曲率条件）
$$\nabla f(x_k + \alpha_k p_k)^T p_k \ge c_2 \nabla f(x_k)^T p_k$$
其中 $c_2 \in (c_1, 1)$。由于 $\nabla f(x_k)^T p_k$ 是负数，这意味着新点的斜率要比初始点“负得没那么厉害”或“变成正数了”（即越过了谷底）。

### 4. Wolfe 条件与强 Wolfe 条件
上述两个条件合称 **Wolfe Conditions**。
**强 Wolfe 条件（Strong Wolfe Conditions）** 对曲率条件加了绝对值限制：
$$|\nabla f(x_k + \alpha_k p_k)^T p_k| \le c_2 |\nabla f(x_k)^T p_k|$$
这意味着我们希望新的方向导数不仅不能太负，也不能太正，最好趋近于0（接近局部极小值点）。对于共轭梯度法和 BFGS，必须使用强 Wolfe 条件。

### 5. 符号说明表
| 符号 | 含义 |
|---|---|
| $p_k$ | 第 $k$ 步的下降方向，满足 $p_k^T \nabla f_k < 0$ |
| $c_1$ | Armijo 容差参数，典型值 $10^{-4}$ |
| $c_2$ | Wolfe 容差参数，拟牛顿法一般取 $0.9$，非线性共轭梯度法取 $0.1$ |
| $\phi(\alpha)$ | 一维剖面函数 |

## 6. 推导思路和思想来源
### Backtracking Line Search（回溯法）的动机：
- **最初困难**：如何寻找同时满足两者的 $\alpha$？精确解根方程很难。
- **关键"转念"**：实际应用中，如果初始尝试的步长很大（比如牛顿法中初始设定 $\alpha=1$），只要满足了 Armijo 条件，基本上步长就不会太小，从而隐式地满足了某种曲率条件。
- **算法流程**：
  1. 初始化 $\alpha = \bar{\alpha}$（通常设为 1），选定收缩因子 $\rho \in (0,1)$（常取 0.5）。
  2. 只要 $f(x_k + \alpha p_k) > f(x_k) + c_1 \alpha \nabla f_k^T p_k$（即 Armijo 不满足）：
  3. 让 $\alpha = \rho \alpha$（步长减半）。
  4. 循环结束，返回当前 $\alpha$。
- **为什么自然得到此结论**：这个过程从大往小找，第一次满足 Armijo 条件时，立刻停下。这就保证了步长不仅满足充分下降，而且也是尽可能大（因为上一个更大的步长不满足），从而避免了步长过小的陷阱。

### Zoutendijk 定理（全局收敛保障）：
假设函数下界存在，且梯度满足 Lipschitz 连续。若迭代满足 Wolfe 条件，则必定有：
$$\sum_{k=0}^{\infty} \cos^2\theta_k \|\nabla f_k\|^2 < \infty$$
其中 $\cos\theta_k = \frac{-\nabla f_k^T p_k}{\|\nabla f_k\| \|p_k\|}$。
这说明，只要你选取的搜索方向 $p_k$ 不会渐进垂直于负梯度（即 $\cos\theta_k \ge \delta > 0$），那么必然有 $\|\nabla f_k\| \to 0$。这是所有基于 Wolfe 条件线搜索算法全局收敛的基石！

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算图解）
设 $\phi(\alpha) = 2 - 2\alpha + \alpha^2$。起点 $\alpha=0, \phi(0)=2, \phi'(0)=-2$。
我们要找 Armijo 条件 $\phi(\alpha) \le 2 + c_1 \alpha (-2)$，取 $c_1 = 0.1$。
条件化为 $2 - 2\alpha + \alpha^2 \le 2 - 0.2\alpha \Rightarrow \alpha^2 - 1.8\alpha \le 0 \Rightarrow \alpha \in [0, 1.8]$。
可见，只要 $\alpha$ 小于 $1.8$，就满足充分下降条件。

### 例子 2：中等例子（Backtracking 过程）
针对上例，假设我们实施 Backtracking，初始 $\bar{\alpha}=2$, $\rho=0.5$。
- 尝试 $\alpha=2$: $f(2) = 2 - 4 + 4 = 2$。目标界限是 $2 - 0.2\times 2 = 1.6$。因为 $2 \not\le 1.6$，拒绝。
- 更新 $\alpha = 0.5 \times 2 = 1$。
- 尝试 $\alpha=1$: $f(1) = 2 - 2 + 1 = 1$。目标界限 $2 - 0.2\times 1 = 1.8$。因为 $1 \le 1.8$，接受！
返回最终步长 $\alpha_k = 1$。

### 例子 3：实际应用例子（Python 代码）
```python
import numpy as np

def backtracking_line_search(f, grad_f, x, p, alpha_init=1.0, rho=0.5, c1=1e-4):
    """
    Backtracking Line Search using Armijo condition
    """
    alpha = alpha_init
    fx = f(x)
    grad_dot_p = np.dot(grad_f(x), p)
    
    # 必须是下降方向
    assert grad_dot_p < 0
    
    while f(x + alpha * p) > fx + c1 * alpha * grad_dot_p:
        alpha *= rho
        # 安全退出机制，防止死循环
        if alpha < 1e-10:
            break
            
    return alpha

# 测试用例：Rosenbrock 函数
def rosen(x):
    return 100 * (x[1] - x[0]**2)**2 + (1 - x[0])**2
def grad_rosen(x):
    dfdx0 = -400 * x[0] * (x[1] - x[0]**2) - 2 * (1 - x[0])
    dfdx1 = 200 * (x[1] - x[0]**2)
    return np.array([dfdx0, dfdx1])

x0 = np.array([-1.2, 1.0])
p = -grad_rosen(x0) # 最速下降方向
alpha = backtracking_line_search(rosen, grad_rosen, x0, p)
print(f"Accepted Step Size: {alpha}")
```

## 8. 常见误区和易混概念
### 误区 1：认为只要 $f(x_{k+1}) < f(x_k)$ 算法就一定收敛。
> **纠正**：严格下降是不够的。比如 $f(x_k) = 1 + \frac{1}{k}$。虽然每次都下降，但序列并没有收敛到函数的实际最小值（假如实际极小值是 -100）。必须要求**充分下降**（Armijo条件限制了下降量至少与步长成正比）。

### 概念对比表
| 条件 | 目的 | 主要限制项 | 在回溯法中的地位 |
|---|---|---|---|
| **Armijo** | 保证下降量充足，防止步长过大 | 限制上界 | 回溯法唯一的显式判断条件 |
| **Curvature** | 保证向前推进充足，防止步长过小 | 限制下界 | 靠回溯法的“初始步长设大”隐式满足 |
| **Strong Wolfe** | 防止步长越过极小点导致震荡 | 限制导数绝对值 | 必须用更复杂的插值算法（Zoom）实现 |

## 11. 自测题：5 道
> [!question]- 题目 1：在 Armijo 条件 $f(x_k + \alpha p_k) \le f(x_k) + c_1 \alpha \nabla f_k^T p_k$ 中，如果令 $c_1 = 1$，会出现什么问题？
> **解答**：由于对于非线性函数，在 $x_k$ 处的切线往往在函数图像下方（假设函数在局部具有某种凸性）。若 $c_1=1$，则要求实际下降必须等于或超过泰勒一阶展开的预测值。除了极其微小的邻域或特定的凹函数外，几乎没有任何非零的 $\alpha$ 能够满足这个条件，导致线搜索无法跳出第一步。实际中 $c_1$ 设置得很小（如 $10^{-4}$）来给高阶项留出容错空间。

> [!question]- 题目 2：Wolfe 条件中的曲率条件为什么要求 $c_2 > c_1$？
> **解答**：如果我们选 $c_2 \le c_1$，那么存在可能没有任何一个 $\alpha$ 能同时满足 Armijo 和曲率条件。理论可以证明，只要 $0 < c_1 < c_2 < 1$，在一维子函数 $\phi(\alpha)$ 有界下方的情况下，一定存在包含正区间的 $\alpha$ 同时满足这两个条件。

> [!question]- 题目 3：Zoutendijk 条件 $\sum \cos^2\theta_k \|\nabla f_k\|^2 < \infty$ 如何推导出了最速下降法的全局收敛性？
> **解答**：最速下降法选取 $p_k = -\nabla f_k$，此时 $\cos\theta_k = 1$。Zoutendijk 级数收敛必然要求其通项趋于 0，因此必定有 $\|\nabla f_k\|^2 \to 0$。即梯度范数必然收敛到 0，证明了全局收敛。

> [!question]- 题目 4：对于牛顿法，回溯法的初始步长 $\bar{\alpha}$ 必须设为多少？为什么？
> **解答**：必须设为 $\bar{\alpha} = 1$。因为牛顿方向 $p_k = -H_k^{-1}g_k$ 本身不仅包含了方向信息，其尺度（缩放比例）正好指向了二次模型的极小值点。如果不用 1，牛顿法将丧失其标志性的“二阶局部收敛率”（Quadratic Convergence Rate），退化为线性收敛。

> [!question]- 题目 5：共轭梯度法（CG）为何对线搜索精度要求极高（必须满足强 Wolfe 条件）？
> **解答**：CG 算法中，搜索方向的“共轭性”极大依赖于上一步线搜索是“精确”的。如果线搜索不精确（没有落在强 Wolfe 条件规定的导数极小区），后续生成的方向就不再相互共轭，导致整个 $Krylov$ 子空间的性质崩溃，算法陷入死循环或发散。

## ⚠️ 常见陷阱与避坑指南

> [!CAUTION]
> 1. **Armijo 条件与 Zoutendijk 锯齿现象**：单纯使用 Armijo 充分下降条件 $f(x_k + \alpha d_k) \le f(x_k) + c_1 \alpha 
abla f_k^T d_k$ 无法防止步长过于微小。必须配合曲率条件 (Curvature Condition) 或回溯线搜索 (Backtracking Line Search) 策略。
> 2. **Wolfe 条件参数设置规则**：Strong Wolfe 条件要求 $c_1 \in (0, 0.5)$ 且 $c_2 \in (c_1, 1)$。最速下降法推荐 $c_1=1e-4, c_2=0.9$；拟牛顿法 BFGS 推荐 $c_1=1e-4, c_2=0.9$；牛顿法推荐 $c_1=1e-4, c_2=0.1$。

Q: 强 Wolfe 条件 (Strong Wolfe Conditions) 的两条数学不等式分别是什么？
A: 1) 充分下降条件 (Armijo Condition): $f(x_k + \alpha_k d_k) \le f(x_k) + c_1 \alpha_k 
abla f(x_k)^T d_k$
2) 强曲率条件 (Strong Curvature Condition): $|
abla f(x_k + \alpha_k d_k)^T d_k| \le c_2 |
abla f(x_k)^T d_k|$，其中 $0 < c_1 < c_2 < 1$。
<!-- id: opt-linesearch-01 -->

Q: 回溯线搜索 (Backtracking Line Search) 的算法流程是什么？
A: 给定参数 $\alpha = 1, \rho \in (0, 1), c \in (0, 1)$。当 $f(x_k + \alpha d_k) > f(x_k) + c \alpha 
abla f_k^T d_k$ 时，反复更新步长 $\alpha \leftarrow \rho \alpha$；一旦满足 Armijo 条件则停止并返回步长 $\alpha$。

Q: Armijo 准则（充分下降条件）的数学公式是什么？
A: $f(x_k + \alpha p_k) \le f(x_k) + c_1 \alpha \nabla f(x_k)^\top p_k$ （其中 $c_1 \in (0, 1)$，常取 $10^{-4}$）。
