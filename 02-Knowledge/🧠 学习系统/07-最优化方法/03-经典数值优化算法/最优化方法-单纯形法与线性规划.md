## 0. 学习边界
- **类别**：A 类 (基础算法/必修)
- **判断理由**：单纯形法（Simplex Method）是运筹学和优化理论中最著名的算法之一，甚至曾被评为20世纪十大算法。它不仅是求解线性规划（LP）最实用的工具，也是理解对偶性（Duality）、灵敏度分析（Sensitivity Analysis）、以及凸多面体几何性质的关键基石。

---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
面临形式为：
$$ \min c^T x $$
$$ \text{s.t. } Ax = b $$
$$ x \ge 0 $$
的线性规划问题。虽然目标函数和约束都是线性的，看似简单，但变量有非负约束，导致解空间是一个多面体（Polyhedron）。寻找全局极小值实际上是在多面体的无数个点中寻找。我们不可能遍历多面体内的所有点。

---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：单纯形法架起了“代数方程组”（基与非基变量）与“几何直觉”（多面体顶点）之间的桥梁，是理解一切更高级运筹学算法的出发点。
- **实际应用场景**：
  - 资源分配、生产调度、物流运输规划。
  - 组合优化问题的松弛求解（例如整数规划的分支定界法中每次都要用单纯形法解LP）。
- **高频题型/任务**：
  - 将一般的LP转化为标准形式。
  - 列单纯形表（Simplex Tableau）并进行旋转（Pivoting）迭代。
  - 二阶段法（Phase I/Phase II）求解初始基可行解。
  - 计算检验数（Reduced Costs）并判断最优性。

## 4. 用直觉语言解释它
> «"这东西其实就像……在多面体形状的钻石表面寻找最低点。你不需要穿透钻石内部去乱找，只需要沿着钻石的棱，从一个顶点滑到相邻的另一个更低的顶点。一直滑，直到你发现周围所有相连的顶点都比你高，你就知道你到最底下了！"»
- **直觉类比/几何图像**：线性规划的可行域是一个凸多面体；其最优解一定可以在某个顶点（Vertex）取到。单纯形法就是从一个顶点出发，沿着多面体的边走到另一个目标函数值更优的相邻顶点，直到没有更优的邻居为止。
- **为什么很自然**：由于局部最优等于全局最优（凸性），这种类似于“贪心”的顶点漫游策略必定能找到全局最优解。
- **一句话直觉本质**：代数上，它就是在约束矩阵的“基可行解”之间不断切换非基变量进基、基变量出基，通过寻找负的检验数来降低目标函数值。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
- **线性规划标准型**：$\min c^T x$， s.t. $Ax=b, x \ge 0$。其中 $A$ 为 $m \times n$ 矩阵（$m < n$ 且行满秩）。
- **基（Basis, $B$）与非基（Non-basis, $N$）**：将矩阵 $A$ 分块为 $[B, N]$，其中 $B$ 是 $m \times m$ 可逆矩阵。对应地，$x$ 分解为基变量 $x_B$ 和非基变量 $x_N$。
- **基可行解（Basic Feasible Solution, BFS）**：令非基变量 $x_N = 0$，解得 $x_B = B^{-1}b$。如果此时 $x_B \ge 0$，则该解是一个基可行解。几何上对应多面体的一个顶点。

### 2. 核心公式
- **基本解的代数表达**：
  从 $Bx_B + Nx_N = b$，得 $x_B = B^{-1}b - B^{-1}Nx_N$。
- **目标函数的代数表达**：
  $z = c_B^T x_B + c_N^T x_N = c_B^T (B^{-1}b - B^{-1}Nx_N) + c_N^T x_N = c_B^T B^{-1}b + (c_N^T - c_B^T B^{-1}N)x_N$
- **检验数（Reduced Costs）**：
  向量 $\bar{c}_N^T = c_N^T - c_B^T B^{-1}N$。
  它表示如果将非基变量 $x_N$ 中的某一个变量增加 1 单位，目标函数将发生的变化量。
- **最优性条件**：
  对于最小化问题，如果所有检验数 $\bar{c}_j \ge 0$，则当前基可行解是最优解。

### 3. 符号说明表
| 符号 | 含义 |
| :--- | :--- |
| $c$ | 目标函数的代价系数向量 |
| $A, b$ | 约束矩阵和右侧常数向量 |
| $x_B, x_N$ | 基变量向量，非基变量向量 |
| $\bar{c}_j$ | 第 $j$ 个变量的检验数 |
| $B^{-1}N$ | 单纯形表的主体部分，用于决定出基变量 |

### 4. 常见变体与适用条件
- **大M法与两阶段法（Phase I/Phase II）**：当我们没有现成的初始可行基时，通过引入人工变量（Artificial Variables）构造辅助规划，从而在 Phase I 寻找一个合法的初始 BFS，然后在 Phase II 继续求解原问题。

## 6. 推导思路和思想来源
- **最初困难**：有无穷多个非负解 $x$ 满足 $Ax=b$。
- **关键"转念"**：微积分代数基本定理指出极值可以在顶点取得。顶点的代数特征就是 $n-m$ 个变量为 0。所以只要在有限个“基”里面搜就行了。 $\binom{n}{m}$ 虽然大，但多数问题不会走遍所有的基。
- **推导主线与动机**：
  1. 假设我现在在一个顶点 $x$。
  2. 我想换个顶点：选一个当前为 0 的非基变量 $x_j$（进基变量），让它大于 0。
  3. 这个动作对目标函数的影响是 $\bar{c}_j$。如果 $\bar{c}_j < 0$，说明增加 $x_j$ 能让 $z$ 减小，是个好方向。
  4. 能无限制增加 $x_j$ 吗？不能。因为要保证其他基变量不变为负（可行性）。所以通过最小比值准则（Minimum Ratio Test）决定 $x_j$ 增加的极限。
  5. 达到极限时，必定有某个原基变量变成了 0，它被“挤出”了基（出基变量）。
  6. 重复以上过程，直到找不到 $\bar{c}_j < 0$ 的变量。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算单纯形表）
**问题**：
$\max 3x_1 + 5x_2$
s.t.
$x_1 \le 4$
$2x_2 \le 12$
$3x_1 + 2x_2 \le 18$
$x_1, x_2 \ge 0$

**步骤**：
1. **标准化**：转为最小化问题并加松弛变量 $x_3, x_4, x_5$。
   $\min -3x_1 - 5x_2$
   $x_1 + x_3 = 4$
   $2x_2 + x_4 = 12$
   $3x_1 + 2x_2 + x_5 = 18$
2. **初始表**：基变量 $x_3, x_4, x_5$ (值为4, 12, 18)。检验数为 -3, -5。
3. **进基与出基**：选检验数最小的 $x_2$ 进基（因为 -5 < -3）。计算最小比值：$x_4$行 $12/2=6$，$x_5$行 $18/2=9$。选小的6，所以 $x_4$ 出基。
4. **高斯旋转操作（Pivot）**：把 $x_2$ 那一列通过行变换化为单位向量形式。
5. 继续迭代直至所有检验数 $\ge 0$。最优解 $x_1 = 2, x_2 = 6$，目标函数极大值为 $36$。

### 例子 2：实际应用代码 (Scipy)
```python
from scipy.optimize import linprog

# max 3x1 + 5x2 => min -3x1 - 5x2
c = [-3, -5]
# Inequality constraints Ax <= b
A = `[[1, 0], [0, 2], [3, 2]]`
b = [4, 12, 18]

# Default bounds for variables are x >= 0
res = linprog(c, A_ub=A, b_ub=b, method='simplex') # Note: highs is preferred now, simplex used for demo
print("Optimal value:", -res.fun)
print("Optimal solution x:", res.x)
```

## 8. 常见误区和易混概念
### 误区 1：认为单纯形法的复杂度是多项式时间
**澄清**：单纯形法在最坏情况下（Worst-case）是**指数级别**的复杂度（著名的 Klee-Minty 立方体例子可以逼迫单纯形法走遍所有顶点）。但它在实际应用中的平均表现出奇地好，近乎线性。若要严格的多项式时间算法，需要使用椭球法或内点法。
### 误区 2：进基变量的选择和出基变量可以随便挑
**澄清**：进基变量必须满足检验数为负（如果是最小化问题）；出基变量必须严格遵守**最小比值法则 (Minimum Ratio Test)**，否则一旦选错，会导致某些基变量变为负数，破坏基可行解（走出多面体外部）。

### 概念对比表
| 概念 | 几何意义 | 代数意义 |
| :--- | :--- | :--- |
| 基本可行解 (BFS) | 多面体顶点 | $n-m$ 个非基变量为 0 且基变量非负 |
| 检验数 (Reduced Cost) | 沿着某条边移动时的斜率 | 目标函数关于非基变量的偏导数 |
| 退化 (Degeneracy) | 多个超平面交于一点 | 有些基变量的值恰好为 0 |

## 11. 自测题：5 道
> [!question]- 题目 1：在单纯形法的某一步迭代中，发现所有 $\bar{c}_j < 0$ 的非基变量，其对应的系数列向量全为非正数（$\le 0$）。这意味着什么？
> **答案**：意味着**原问题无界 (Unbounded)**。因为当你试图增加这个进基变量时，最小比值测试的分母全为负或零，意味着该变量可以无限增大而不会违反任何可行性约束，同时目标函数无限下降。

> [!question]- 题目 2：什么是退化现象（Degeneracy），它会导致单纯形法出现什么问题？
> **答案**：退化是指存在至少一个**基变量的值等于 0** 的基可行解。在几何上，这意味着多于 $m$ 个约束超平面交于同一个顶点。它会导致单纯形法在旋转时目标函数值没有任何改善，可能在几个不同的基之间陷入无限死循环（Cycling）。引入 Bland 规则（总是选择下标最小的变量进出基）可以打破死循环。

> [!question]- 题目 3：对偶问题的解隐藏在单纯形表的哪里？
> **答案**：在最优单纯形表中，初始松弛变量对应的检验数 $\bar{c}$ 的值，正好等于原问题的最优对偶变量（即影子价格，Shadow Prices）。因为 $\bar{c}_N^T = c_N^T - c_B^T B^{-1}N = c_N^T - \lambda^T N$，对于松弛变量，$c_N=0, N=I$，所以检验数就是 $-\lambda$。

> [!question]- 题目 4：将下面问题化为标准型并指出初始基矩阵 B：
$\max x_1 - x_2$  s.t. $x_1 + x_2 \le 5$, $x_1, x_2 \ge 0$
> **答案**：化为 $\min -x_1 + x_2$，s.t. $x_1 + x_2 + x_3 = 5$, $x_1, x_2, x_3 \ge 0$。初始基变量为松弛变量 $x_3$，所以基矩阵 $B = [1]$，非基变量为 $x_1, x_2$。

> [!question]- 题目 5：解释检验数 $\bar{c}_j$ 的经济学含义？
> **答案**：检验数也叫**相对成本/机会成本**。它表示为了强制生产一单位的产品 $j$ (即让 $x_j=1$)，在保持资源总量不变的情况下，由于占用了稀缺资源而不得不牺牲的现有基变量带来的利润，减去直接从产品 $j$ 获得的利润。如果 $\bar{c}_j < 0$ (求极小)，说明生产它有利可图。

## ⚠️ 常见陷阱与避坑指南

> [!CAUTION]
> 1. **单纯形法退化与死循环 (Degeneracy & Cycling)**：当存在基可行解的某个基变量值为 0 时，入基变量无法使目标函数值进一步下降。若不采用 Bland 规则（最小下标优先规则），单纯形法则可能陷入无限死循环。
> 2. **大 M 法的数值溢出**：在大 M 法中设置过大的 $M$（如 $1e10$）会导致计算机浮点数加减法舍入误差丢失真实系数信息。推荐采用两阶段单纯形法 (Two-phase Simplex Method) 求解初始基可行解。

## 🃏 Anki 卡片

Q: 单纯形法 (Simplex Method) 中换基操作的 pivot 规则（进基与出基）是什么？
A: 进基变量：选择检验数（Reduced Cost）大于 0 且最大（或最负，取决于极大化/极小化约定）的非基变量；
出基变量：根据最小比值法则（Ratio Test $\theta = \min \{b_i / a_{ij} \mid a_{ij} > 0\}$）选择约束最紧的基变量出基。
<!-- id: opt-simplex-01 -->

Q: 什么是单纯形法的 Bland 规则？它解决了什么问题？
A: Bland 规则要求在有多个变量候选进基或出基时，总是选择下标最小的变量。该规则 mathematically 证明了能够彻底消除退化解引发的死循环 (Cycling)。
<!-- id: opt-simplex-02 -->


---

Q: 线性规划的极值一定在可行域的哪里取得？单纯形法的几何直觉是什么？
A: 必在多面体可行域的顶点（极点）取得。单纯形法沿着多面体的棱从一个顶点移动到相邻改善顶点。
<!-- id: opt-lp-03 -->


---

Q: 线性规划中入基变量与出基变量的选取规则是什么？
A: 入基变量（Pivot In）：选择检验数 $\sigma_j = c_j - z_j > 0$ 最大（求极大值）的非基变量；出基变量（Pivot Out）：根据最小比值规则 $\theta = \min_{a_{i,j} > 0} \frac{b_i}{a_{i,j}}$ 选择约束最紧的基变量出基。
