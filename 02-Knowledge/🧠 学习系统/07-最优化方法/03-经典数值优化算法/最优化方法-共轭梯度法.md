## 2. 为什么它重要？它有什么用？
- **连接大图景**：它是从简单一阶方法向复杂二阶方法过渡的桥梁。通过引入“A共轭”概念，它实现了历史搜索方向的相互正交，避免了重复探索；同时，非线性CG是众多无约束优化方法中的经典。
- **实际应用场景**：
  - 求解偏微分方程（PDEs）离散化后产生的大型稀疏线性系统。
  - 深度学习中某些近似二阶优化算法（如Hessian-free optimization）需要用到CG来求解牛顿步。
- **高频题型/任务**：
  - 证明 CG 在 $n$ 步内收敛。
  - 推导 CG 算法的迭代公式（特别是 $\alpha_k$ 和 $\beta_k$）。
  - 给定小规模矩阵手动执行一步 CG。

## 4. 用直觉语言解释它
> «"这东西其实就像……在一座椭球形的山谷里找谷底，最速下降法是个瞎子，每次只顾眼前最陡的路，结果左碰右撞；共轭梯度法是个聪明的瞎子，他记得之前走过的总体趋势，每次不仅往下走，还保证新走的方向和之前所有的方向在某种特殊的度量下‘不冲突’。"»
- **直觉类比/几何图像**：想象等高线是狭长的椭圆。最速下降法总是垂直于等高线走，导致不断折返。CG 则是通过拉伸空间（用 $A$ 进行变换），把椭圆变成圆，然后在圆里走，两个互相垂直的方向就能直接到圆心。映射回原来的空间，这两个方向就是“A共轭”的。
- **为什么很自然**：既然标准正交方向好，但我们无法轻易知道变换矩阵，那就构造一组相对于 $A$ 正交的方向，使得每次沿着一个方向走到极小值后，在后续方向上的移动不会破坏之前在旧方向上取得的极小值。
- **一句话直觉本质**：在一组 $A$ 共轭方向上逐个进行一维精确线搜索，每次搜索都在扩展的 Krylov 子空间中寻找最优解。

## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
**A-共轭（A-Conjugacy）**：给定对称正定矩阵 $A$，如果一组非零向量 $\{p_0, p_1, \dots, p_k\}$ 满足 $p_i^T A p_j = 0$ 对所有 $i \neq j$ 成立，则称这些向量是 $A$ 共轭的（或 $A$ 正交的）。

**Krylov 子空间**：由初始残差 $r_0$ 和矩阵 $A$ 生成的子空间，$\mathcal{K}_k(A, r_0) = \text{span}\{r_0, Ar_0, A^2r_0, \dots, A^{k-1}r_0\}$。CG 的第 $k$ 步解 $x_k$ 恰好是在 $x_0 + \mathcal{K}_k(A, r_0)$ 中使得 $f(x)$ 最小的解。

### 2. 核心公式
线性共轭梯度法（求解 $Ax = b$）的标准算法流程：
给定初始点 $x_0$，计算初始残差 $r_0 = b - Ax_0$，令初始搜索方向 $p_0 = r_0$。
For $k = 0, 1, 2, \dots$ until $r_k$ is sufficiently small:
1. 计算步长：$\alpha_k = \frac{r_k^T r_k}{p_k^T A p_k}$
2. 更新解：$x_{k+1} = x_k + \alpha_k p_k$
3. 更新残差：$r_{k+1} = r_k - \alpha_k A p_k$  *(注意 $r_{k+1} = b - Ax_{k+1}$)*
4. 计算共轭参数：$\beta_{k+1} = \frac{r_{k+1}^T r_{k+1}}{r_k^T r_k}$
5. 更新方向：$p_{k+1} = r_{k+1} + \beta_{k+1} p_k$

### 3. 符号说明表
| 符号 | 含义 |
| :--- | :--- |
| $A$ | 维度为 $n \times n$ 的对称正定矩阵 (SPD) |
| $x_k$ | 第 $k$ 次迭代的近似解 |
| $r_k$ | 第 $k$ 次迭代的残差，即负梯度 $r_k = b - Ax_k = -\nabla f(x_k)$ |
| $p_k$ | 第 $k$ 次迭代的搜索方向（相互 $A$ 共轭） |
| $\alpha_k$ | 沿方向 $p_k$ 的最优步长 |
| $\beta_k$ | 用于正交化新残差与旧方向的标量系数 |

### 4. 常见变体与适用条件
- **预条件共轭梯度法 (PCG)**：用于改善 $A$ 的条件数，引入预条件矩阵 $M \approx A$，求解 $M^{-1}Ax = M^{-1}b$。
- **非线性共轭梯度法 (Nonlinear CG)**：如 Fletcher-Reeves (FR), Polak-Ribière (PR)，用于一般的非线性优化 $f(x)$，此时没有矩阵 $A$，残差替换为负梯度，$\alpha_k$ 通过线搜索获得，$\beta_k$ 有不同公式。

## 6. 推导思路和思想来源
- **最初困难**：我们要解 $Ax = b$，可以看作最小化 $f(x) = \frac{1}{2} x^T A x - b^T x$。最速下降法选负梯度 $r_k = b - Ax_k$ 作为方向，但条件数差时，搜索路径严重震荡。
- **关键"转念"**：如果有一组向量 $\{p_0, p_1, \dots, p_{n-1}\}$，不仅线性无关，而且彼此不干扰——即顺着 $p_0$ 走到极小值后，顺着 $p_1$ 走的时候不会让 $p_0$ 方向上的导数偏离 0。这就要求 $\nabla f(x_2)^T p_0 = 0$。推导可知，这等价于 $p_1^T A p_0 = 0$。这就引出了 A-共轭。
- **推导主线与动机**：
  1. 假设解可以表示为 $x^* = \sum_{i=0}^{n-1} \alpha_i p_i$。
  2. 乘以 $p_k^T A$，得 $p_k^T A x^* = \alpha_k p_k^T A p_k$。因为 $Ax^* = b$，所以 $\alpha_k = \frac{p_k^T b}{p_k^T A p_k}$。这说明只要有了 A共轭方向，解可以在 $n$ 步内直接求出！
  3. 但是我们要边迭代边找方向。能不能通过正交化（Gram-Schmidt）从残差序列构造 $p_k$？可以，但普通全量正交化要存所有旧向量。
  4. **CG的神奇之处 (短递推关系)**：定理表明，当前的残差 $r_k$ 只需与前一个方向 $p_{k-1}$ 进行 A正交化，就自动与所有之前的 $p_0, \dots, p_{k-2}$ A正交！这就引出了 $p_k = r_k + \beta_k p_{k-1}$ 的简洁递推。
- **为什么自然得到此结论**：因为每次残差 $r_k$ 属于 $\mathcal{K}_{k+1}$，而 $r_k$ 且与之前的所有的子空间正交。由对称阵的性质，它其实等价于 Lanczos 迭代，只有三项递推，这是由 $A$ 是对称矩阵决定的。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
**问题**：用 CG 解 $Ax=b$，其中 $A = \begin{bmatrix} 4 & 1 \\ 1 & 3 \end{bmatrix}$, $b = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$, $x_0 = \begin{bmatrix} 2 \\ 1 \end{bmatrix}$。
**步骤**：
1. $r_0 = b - Ax_0 = \begin{bmatrix} 1 \\ 2 \end{bmatrix} - \begin{bmatrix} 4 & 1 \\ 1 & 3 \end{bmatrix}\begin{bmatrix} 2 \\ 1 \end{bmatrix} = \begin{bmatrix} 1 \\ 2 \end{bmatrix} - \begin{bmatrix} 9 \\ 5 \end{bmatrix} = \begin{bmatrix} -8 \\ -3 \end{bmatrix}$。$p_0 = r_0$。
2. $Ap_0 = \begin{bmatrix} 4 & 1 \\ 1 & 3 \end{bmatrix}\begin{bmatrix} -8 \\ -3 \end{bmatrix} = \begin{bmatrix} -35 \\ -17 \end{bmatrix}$。
3. $p_0^T A p_0 = [-8 \ -3] \begin{bmatrix} -35 \\ -17 \end{bmatrix} = 280 + 51 = 331$。$r_0^T r_0 = 64 + 9 = 73$。
   $\alpha_0 = 73 / 331 \approx 0.2205$。
4. $x_1 = x_0 + \alpha_0 p_0 = \begin{bmatrix} 2 \\ 1 \end{bmatrix} + \frac{73}{331}\begin{bmatrix} -8 \\ -3 \end{bmatrix} = \begin{bmatrix} 0.2356 \\ 0.3384 \end{bmatrix}$。
*(由于只是 $n=2$，再迭代一步必定到达精确解)*。

### 例子 2：实际应用例子（真实场景/代码）
**Python实现简单的线性 CG**
```python
import numpy as np

def conjugate_gradient(A, b, x0, tol=1e-5):
    x = x0
    r = b - A @ x
    p = r.copy()
    rsold = np.dot(r, r)
    
    for i in range(len(b)):
        Ap = A @ p
        alpha = rsold / np.dot(p, Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rsnew = np.dot(r, r)
        
        if np.sqrt(rsnew) < tol:
            print(f"Converged at step {i+1}")
            break
            
        beta = rsnew / rsold
        p = r + beta * p
        rsold = rsnew
    return x

# Test
A = np.array([[4, 1], [1, 3]])
b = np.array([1, 2])
x0 = np.array([2.0, 1.0])
print("CG Solution:", conjugate_gradient(A, b, x0))
print("Numpy Solution:", np.linalg.solve(A, b))
```

## 8. 常见误区和易混概念
### 误区 1：认为 CG 只能用于正定二次函数
**澄清**：标准线性 CG 确实只解决 $Ax=b$ (A为SPD)，但其变体如非线性 CG (Fletcher-Reeves等) 可以用于任意光滑极值问题，不过此时需要用精确线搜索代替解析的 $\alpha_k$ 并且更新公式略有不同。
### 误区 2：在非对称矩阵上直接用 CG
**澄清**：如果 A 不是对称正定的，$p_k^T A p_k$ 可能为 0 或负数，导致除零错误或发散。对于非对称系统，应使用 GMRES 或 BiCGSTAB。

### 概念对比表
| 方法 | 搜索方向 | 内存占用 | 计算复杂度/步 | 收敛性保证 |
| :--- | :--- | :--- | :--- | :--- |
| 最速下降法 | 负梯度方向 | 极小 ($O(n)$) | $O(\text{nnz}(A))$ | 极慢（条件数差时） |
| 共轭梯度法 | A-共轭方向 | 小 ($O(n)$) | $O(\text{nnz}(A))$ | 最多 $n$ 步精确收敛 |
| 牛顿法 | Hessian的逆乘负梯度 | 大 ($O(n^2)$) | $O(n^3)$ | 二次收敛，极快 |

## 11. 自测题：5 道
> [!question]- 题目 1：CG法每一步的残差 $r_k$ 的几何含义是什么？它和梯度有什么关系？
> **答案**：在极小化 $f(x) = \frac{1}{2}x^T A x - b^T x$ 时，梯度为 $\nabla f(x) = Ax - b$。残差定义为 $r_k = b - Ax_k$，所以残差就是**负梯度方向**。这就是为什么初始方向 $p_0$ 设为 $r_0$，即最速下降方向。

> [!question]- 题目 2：为什么共轭梯度法理论上可以在 $n$ 步内收敛？
> **答案**：在 $n$ 维空间中，最多存在 $n$ 个相互 A-共轭的非零向量。CG 每一步都在一个新的 A-共轭方向上找到最优值，并且保证后续搜索不破坏之前的最优性。因此，经过 $n$ 次独立方向上的探索，相当于在整个 $n$ 维空间上找到了极小值，所以理论上 $n$ 步收敛。

> [!question]- 题目 3：预条件（Preconditioning）的本质目的是什么？
> **答案**：CG 的收敛速度依赖于矩阵 $A$ 的条件数 $\kappa(A)$，迭代步数大约与 $\sqrt{\kappa(A)}$ 成正比。预条件就是找到一个好求逆的矩阵 $M \approx A$，将原问题变为 $M^{-1}Ax = M^{-1}b$（实际实现用对称化形式），使得预条件系统的条件数远小于 $A$，从而大幅加速收敛。

> [!question]- 题目 4：推导 $\alpha_k$ 的公式 $\alpha_k = \frac{r_k^T r_k}{p_k^T A p_k}$
> **答案**：因为 $x_{k+1} = x_k + \alpha_k p_k$，我们要最小化 $f(x_{k+1})$ 对 $\alpha_k$ 的依赖。即令 $\frac{d}{d\alpha_k} f(x_k + \alpha_k p_k) = 0$。
根据链式法则：$(\nabla f(x_{k+1}))^T p_k = 0$，即 $(Ax_{k+1} - b)^T p_k = 0$。
代入得 $(A(x_k + \alpha_k p_k) - b)^T p_k = 0$ $\Rightarrow (Ax_k - b + \alpha_k A p_k)^T p_k = 0$。
因为 $r_k = b - Ax_k$，所以 $-r_k^T p_k + \alpha_k p_k^T A p_k = 0 \Rightarrow \alpha_k = \frac{r_k^T p_k}{p_k^T A p_k}$。
又由 $p_k = r_k + \beta_k p_{k-1}$ 且 $r_k$ 与旧方向 $p_{k-1}$ 正交，可知 $r_k^T p_k = r_k^T r_k$。所以得证。

> [!question]- 题目 5：非线性CG中，Fletcher-Reeves 的 $\beta_{k+1}$ 是怎么计算的？
> **答案**：在非线性 CG 中，Fletcher-Reeves 公式的 $\beta_{k+1}$ 为 $\beta_{k+1}^{FR} = \frac{\nabla f(x_{k+1})^T \nabla f(x_{k+1})}{\nabla f(x_k)^T \nabla f(x_k)}$，或者写为 $\|g_{k+1}\|^2 / \|g_k\|^2$。这是线性 CG 中 $\beta$ 公式的直接推广。

## ⚠️ 常见陷阱与避坑指南

> [!CAUTION]
> 1. **非线性共轭梯度法中的重置策略 (Restart Rule)**：在非线性 CG（如 Fletcher-Reeves 或 Polak-Ribière）中，由于非二次项干扰，搜索方向会逐渐失去共轭性。建议每 $n$ 步或当 $|\nabla f_{k+1}^T \nabla f_k| / \|\nabla f_{k+1}\|^2 \ge 0.2$ 时重置方向为最速下降方向 $\beta_k = 0$。
> 2. **PRP+ 算法防止数值失真**：Polak-Ribière (PRP) 算法可能产生 $\beta_k < 0$，导致非下降方向。实践中统一采用 $\beta_k^{\text{PRP+}} = \max(0, \beta_k^{\text{PRP}})$ 保证方向有效性。

## 🃏 Anki 卡片

Q: 线性共轭梯度法求解 $A x = b$ ($A \succ 0$) 理论上在多少步内收敛到精确解？
A: 理论上至多 $n$ 步（$n$ 为矩阵 $A$ 的维数），因为算法在 $n$ 维空间中逐一消去 $A$-正交（共轭）方向上的误差成分。
<!-- id: opt-cg-01 -->

Q: Polak-Ribière (PRP) 与 Fletcher-Reeves (FR) 共轭系数 $\beta_k$ 的主要区别是什么？
A: $\beta_k^{\text{FR}} = \frac{g_{k+1}^T g_{k+1}}{g_k^T g_k}$，$\beta_k^{\text{PRP}} = \frac{g_{k+1}^T (g_{k+1} - g_k)}{g_k^T g_k}$。当算法卡顿、相邻梯度变化极小时，$g_{k+1} \approx g_k$，PRP 会自动使 $\beta_k \to 0$，实现自动重置（Auto-restart），因此实际性能优于 FR。
