# 最优化方法 - 罚函数法与障碍法

> **核心地位**：罚函数法（Penalty Method）与障碍法（Barrier Method）是将**约束优化问题**转换为序列无约束优化问题求解（Sequential Unconstrained Optimization Technique, SUOT）的两大基石理论。外罚函数法从可行域外部逐步逼近，内障碍法从可行域内部构建高能阻垒，为内点法（Interior-Point Methods）与增广拉格朗日法（ALM）奠定了关键数学基础。

---

## §01 问题动机与苏格拉底式引入

> **🤔 苏格拉底与学习者的对话**：
> - **学习者**：“我们手头已经掌握了极其高效的无约束优化算法（如牛顿法、拟牛顿法），但如何用它们求解带复杂几何边界的约束优化问题 \(\min f(x) \text{ s.t. } g(x) \le 0\)？”
> - **苏格拉底**：“如果你想让一个人绝不出界，有两种办法：第一种是等他越界后施加越来越重的物理惩罚；第二种是在边界内侧建立一道无限高能的电子围栏。这两者有何本质区别？”
> - **学习者**：“第一种是‘外罚函数法’，允许暂时越界但惩罚递增；第二种是‘内障碍法’，永远只能在可行域内部移动！”
> - **苏格拉底**：“当惩罚系数 \(\sigma \to \infty\) 时，在靠近边界处目标函数的 Hessian 矩阵会发生什么可怕现象？”
> - **学习者**：“沿着垂直边界方向的曲率无限大，而沿着切线方向的曲率有限，导致 Hessian 矩阵条件数发散，牛顿法直接崩塌！这也引出了后来的增广拉格朗日法与内点法修正。”

## §02 数学机制与 Hessian 病态性严谨分析

考虑一般约束优化问题：

\[
\min_{x} f(x) \quad \text{s.t.} \quad h_i(x) = 0 \; (i=1..m), \quad g_j(x) \le 0 \; (j=1..p)
\]

### 1. 外罚函数法 (Exterior Penalty Method) 与病态 Hessian 证明

对违反约束的点施加二次高额惩罚：

\[
\Phi(x; \sigma) = f(x) + \sigma \left[ \sum_{i=1}^m h_i^2(x) + \sum_{j=1}^p \max(0, g_j(x))^2 \right]
\]

其梯度与 Hessian 矩阵为：

\[
\nabla \Phi(x; \sigma) = \nabla f(x) + 2\sigma \sum_{i=1}^m h_i(x) \nabla h_i(x) + 2\sigma \sum_{j \in \mathcal{A}} g_j(x) \nabla g_j(x)
\]
\[
\nabla^2 \Phi(x; \sigma) = \nabla^2 f(x) + 2\sigma \sum_{i=1}^m \left( \nabla h_i(x) \nabla h_i(x)^T + h_i(x) \nabla^2 h_i(x) \right) + 2\sigma \sum_{j \in \mathcal{A}} \nabla g_j(x) \nabla g_j(x)^T + \dots
\]

**病态性代数证明**：
当 \(\sigma \to \infty\) 时，极小值点处 \(h_i(x) \to 0\)，Hessian 矩阵主导项为外积矩阵：

\[
\nabla^2 \Phi(x; \sigma) \approx \nabla^2 f(x) + 2\sigma \sum_{i=1}^m \nabla h_i(x) \nabla h_i(x)^T
\]

- **垂直约束法向方向**（由 \(\nabla h_i(x)\) 张成的子空间）：特征值呈 \(\mathcal{O}(\sigma)\) 线性爆炸；
- **约束切空间方向**（满足 \(\nabla h_i(x)^T v = 0\) 的方向）：特征值保持 \(\mathcal{O}(1)\)。

因而 Hessian 条件数发散：

\[
\kappa(\nabla^2 \Phi) = \frac{\lambda_{\max}}{\lambda_{\min}} \approx \mathcal{O}(\sigma) \to \infty \quad (\sigma \to \infty)
\]

这导致数值无约束求解器（如标准牛顿法）由于矩阵求逆极其病态而发散崩溃。

### 2. 内障碍法 (Interior Barrier Method / Logarithmic Barrier)

仅适用于纯不等式约束 \(g_j(x) < 0\)（具有非空可行域内部）：

\[
B(x; \mu) = f(x) - \mu \sum_{j=1}^p \ln(-g_j(x))
\]

- **特性**：迭代点 \(x^{(k)}\) 永远处于可行域严格内部（\(g_j(x) < 0\)）；当 \(x\) 靠近边界 \(g_j(x) \to 0^-\) 时，惩罚项 \(-\mu \ln(-g_j(x)) \to +\infty\)，产生无穷大屏障阻止出界。
- **参数控制**：障碍参数 \(\mu_k \to 0^+\)。

## §03 数值比较

| 维度 | 外罚函数法 (Exterior Penalty) | 内障碍法 (Interior Barrier) |
| :--- | :--- | :--- |
| **迭代点轨迹** | 可行域外部 \(\to\) 边界 | 可行域内部 \(\to\) 边界 |
| **适用约束类型** | 等式约束 \(h(x)=0\) 及不等式 \(g(x)\le 0\) | 仅限不等式约束 \(g(x) < 0\) |
| **初始点要求** | 任意初始点 \(x_0\) | 必须严格可行初始点 (\(g_j(x_0) < 0\)) |
| **极限数值性** | \(\sigma \to \infty\)，Hessian 剧烈病态 (\(\mathcal{O}(\sigma)\)) | \(\mu \to 0\)，Hessian 在边界病态，但配合内点法（原-对偶内点法）非常高效 |

## §04 Python 代码实现 (对数障碍法)

```python
import numpy as np
from scipy.optimize import minimize

def log_barrier_solver(f, grad_f, g_list, x0, mu0=1.0, factor=0.1, tol=1e-5):
    """
    对数障碍法求解纯不等式约束问题 min f(x) s.t. g_j(x) <= 0
    """
    x = np.array(x0, dtype=np.float64)
    mu = mu0
    
    for it in range(50):
        # 定义内障碍目标函数
        def barrier_obj(x_val):
            val = f(x_val)
            for g in g_list:
                g_val = g(x_val)
                if g_val >= 0: # 出界惩罚
                    return 1e10
                val -= mu * np.log(-g_val)
            return val
        
        # 求解无约束子问题
        res = minimize(barrier_obj, x, method='BFGS')
        x = res.x
        
        if mu < tol:
            break
        mu *= factor
        
    return x

# 验证例子: min x_1^2 + x_2^2 s.t. 1 - x_1 - x_2 <= 0 (即 x_1 + x_2 >= 1)
if __name__ == "__main__":
    f = lambda x: x[0]**2 + x[1]**2
    grad_f = lambda x: np.array([2*x[0], 2*x[1]])
    g1 = lambda x: 1.0 - x[0] - x[1] # g1(x) <= 0
    
    x_opt = log_barrier_solver(f, grad_f, [g1], x0=[1.0, 1.0], mu0=1.0)
    print("障碍法解 (理论解为 [0.5, 0.5]):", np.round(x_opt, 4))
```

## §05 常见误区与工程陷阱

- **误区**：对数障碍法可以直接处理等式约束 \(h(x) = 0\)。
- **事实**：等式约束可行域没有“严格内部”（测度为 0），不能对等式约束使用对数障碍法。等式约束必须使用外罚函数或增广拉格朗日法 (ALM)。

## 🎯 知识自测与主动回忆

> [!question]- 1. 外罚函数法 (Exterior Penalty) 与内障碍法 (Interior Barrier) 的核心差异是什么？
> **答案**：外罚函数法允许迭代点位于可行域外部，逐渐向边界收敛，支持等式与不等式约束，参数 $\sigma \to \infty$；内障碍法要求迭代点永远保持在严格可行域内部（$g_j(x) < 0$），仅支持不等式约束，参数 $\mu \to 0$。

> [!question]- 2. 为何外罚函数法在 $\sigma \to \infty$ 时会导致 Hessian 矩阵数值病态？
> **答案**：因为外罚函数的 Hessian 包含二次惩罚项展开的外积矩阵 $2\sigma \nabla h_i(x) \nabla h_i(x)^T$。法向量方向的特征值随 $\sigma$ 线性发散（$\mathcal{O}(\sigma)$），而切空间方向特征值为 $\mathcal{O}(1)$，导致条件数 $\kappa \approx \mathcal{O}(\sigma) \to \infty$。

> [!question]- 3. 对数障碍项 $-\mu \sum \ln(-g_j(x))$ 在边界 $g_j(x) \to 0^-$ 时的极限表现是什么？
> **答案**：当 $g_j(x) \to 0^-$ 时，$-g_j(x) \to 0^+$，$\ln(-g_j(x)) \to -\infty$，因此障碍项 $-\mu \ln(-g_j(x)) \to +\infty$，在边界形成极高屏障，防止迭代点出界。

> [!question]- 4. 为什么障碍法不能用于处理等式约束 $h_i(x) = 0$？
> **答案**：因为等式约束可行域的“严格内部”为空集（测度为 0）。若强制定义 $\ln(-h_i(x))$ 或 $\ln(h_i(x))$，迭代点永远无法在保持可行性的同时使 $\ln$ 项有意义。

> [!question]- 5. 增广拉格朗日法 (ALM) 是如何解决外罚函数法 Hessian 条件数发散这一痛点的？
> **答案**：ALM 在外罚函数的基础上显式引入了拉格朗日乘子估计项 $\lambda^T h(x)$。通过在每一步更新乘子 $\lambda^{(k+1)} = \lambda^{(k)} + 2\sigma h(x^{(k)})$，无需将惩罚因子 $\sigma$ 驱动至 $\infty$ 即可得到精确最优解，彻底克服了病态 Hessian 引起的收敛崩溃。

Q: 外罚函数法 (Exterior Penalty) 与内障碍法 (Interior Barrier) 的核心差异是什么？
A: 1. **外罚函数法**：迭代点从可行域**外部**向边界靠拢，支持等式与不等式约束，参数 $\sigma \to \infty$。
2. **内障碍法**：迭代点始终保持在可行域**内部**（$g_j(x) < 0$），仅支持不等式约束，参数 $\mu \to 0$。

Q: 外罚函数法在惩罚因子 $\sigma \to \infty$ 时导致 Hessian 条件数发散的代数推导原因是什么？
A: 外罚函数 Hessian 包含项 $2\sigma \nabla h_i(x) \nabla h_i(x)^T$。约束法空间方向特征值为 $\mathcal{O}(\sigma)$，而切空间方向特征值为 $\mathcal{O}(1)$，导致条件数 $\kappa \approx \mathcal{O}(\sigma) \to \infty$，使无约束求解器数值崩溃。

Q: 增广拉格朗日法 (ALM) 相比外罚函数法的最核心优势是什么？
A: 增广拉格朗日法引入了显式的拉格朗日乘子 $\lambda$。通过在迭代中更新乘子 $\lambda^{(k+1)} = \lambda^{(k)} + 2\sigma h(x^{(k)})$，**无需将 $\sigma \to \infty$** 即可精确收敛至最优解，避免了 Hessian 病态发散。
