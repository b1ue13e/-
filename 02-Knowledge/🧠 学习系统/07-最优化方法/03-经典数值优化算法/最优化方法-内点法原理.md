# 内点法原理

---
## 0. 学习边界
- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：内点法是**多项式时间 + 高精度**求解 LP/QP/SOCP/SDP 的唯一主流框架（CVXPY 的 ECOS/CLARABEL/MOSEK 全是内点法），也是 HW03 手撕作业的三大算法之一（与梯度下降、ADMM 并列，pytest 以 CVXPY 为标杆）。Boyd Ch.11 是它最系统的中文可读教材。

---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 求解带不等式约束的凸问题 $\min f_0(x)\ \text{s.t.}\ f_i(x) \le 0$ 时，KKT 条件虽然优美但无法直接"解方程"（不等式约束不参与等式系统）；投影梯度法每步要投影到可行域，而一般凸集的投影本身是个子优化问题；单纯形法（[[最优化方法-单纯形法与线性规划]]）只适用于 LP，且最坏情形迭代次数是指数的。以前的办法要么只适用特殊问题、要么没有最坏情形保证。因此需要一种**对任何凸问题都有多项式时间保证、又能在实践中达到工业精度**的通用算法——内点法就是这个答案。

---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：内点法是"理论最优（多项式时间）"与"工程最优（高精度）"的交点：它把 [[最优化方法-凸优化问题标准形式]] 的所有子类（LP/QP/SOCP/SDP）一网打尽，是 [[最优化方法-锥规划与半定规划SDP]] 的实际求解引擎；与 [[最优化方法-一阶方法收敛性分析]] 的线性收敛形成"精度 vs 规模"的经典权衡。
- **实际应用场景**：CVXPY 中 `solver=ECOS/CLARABEL/MOSEK` 全部是内点法；大规模 LP 中内点法已取代单纯形法成为默认（商用求解器 Gurobi/CPLEX 两者都提供）；SDP 松弛（MAX-CUT、SVM 核学习）几乎只能靠内点法。
- **高频题型/任务**：写出对数障碍函数；推导中心路径的 KKT 条件与对偶间隙 $m/t$；手撕 barrier method（HW03）；内点法 vs 单纯形法对比；复杂度 $O(\sqrt{n}\log(1/\varepsilon))$ 中各符号的含义。

---
## 3. 学它之前需要哪些前置知识？
1. **[[最优化方法-凸优化问题标准形式]]**：内点法处理的对象就是标准形式——凸 $f_0$、凸 $f_i \le 0$、仿射等式（等式约束可消去或并入障碍的二次罚）。
2. **[[最优化方法-凸优化与拉格朗日对偶]]**：中心路径的本质是"对偶间隙可控的近似 KKT 点"，$\lambda_i(t) = -1/(t f_i(x))$ 就是显式构造的对偶可行解。
3. **牛顿法（参考 [[最优化方法-拟牛顿法BFGS]]）**：内点法的内层迭代就是带回溯线搜索的阻尼牛顿法；牛顿减量 $\lambda(x)^2 = \nabla f^T (\nabla^2 f)^{-1} \nabla f$ 是终止判据。
4. **[[最优化方法-凸集与凸函数]]**：$\log$ 是凹函数，$-\log(-u)$ 在 $u<0$ 上凸——对数障碍的凸性来源。

---
## 4. 用直觉语言解释它
> «内点法就像"在隧道里开车去山谷底"：可行域是一间屋子，边界墙（$f_i(x) = 0$）被涂上了一层**对数罚**——越靠近墙，惩罚越大，到墙边直接是"∞ 高度"（所以车永远不撞墙，始终在屋内）。但罚太狠会离墙太远、到不了最优（最优往往在墙上）；于是我们**一边开车一边把罚的强度调低**（$t$ 增大），车就沿着一条"越来越贴近墙的路径"（中心路径）滑向最优解。每一步（牛顿步）都在当前罚下"大步走直线"，再用回溯线搜索保证不冲过头。"»
- **直觉类比/几何图像**：对数障碍 $\phi(x) = -\sum_i \log(-f_i(x))$ 是一圈"软墙"；$t f_0(x) + \phi(x)$ 的极小点 $x^*(t)$ 构成一条曲线——中心路径，像隧道的中线；$t \to \infty$ 时 $x^*(t) \to$ 最优解。
- **为什么很自然**：障碍函数把"约束"变成"目标的一部分"，把约束优化变成**一串无约束优化**——而无约束问题恰好能用（二次收敛的）牛顿法轻松解决。这是"把难题分解成一系列易题"的经典策略。
- **一句话直觉本质**：**内点法 = 对数障碍把不等式约束变成软墙 → 中心路径 $x^*(t)$ 沿墙内侧逼近最优 → 外层加大 $t$、内层牛顿步精修，对偶间隙 $m/t$ 可控地压到 $\varepsilon$。**

---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
- **对数障碍函数**：$\phi(x) = -\sum_{i=1}^{m} \log(-f_i(x))$，定义域 $\mathrm{dom}\,\phi = \{x : f_i(x) < 0,\ \forall i\}$（严格可行集内部），在边界上 $\phi \to +\infty$。
- **障碍问题**：$\min\ t f_0(x) + \phi(x)$，$t > 0$ 为权重参数。
- **中心路径**：$\{x^*(t) : t > 0\}$，其中 $x^*(t)$ 是障碍问题的唯一极小点（$f_0$ 凸 + $\phi$ 严格凸 ⟹ 唯一）。
- **内点法（barrier method）**：外层按 $t := \mu t$（$\mu \in [10, 20]$）增大 $t$，内层从 $x^*(t)$ 出发用阻尼牛顿法解下一个障碍问题。
### 2. 核心公式
中心路径的 KKT 条件（$\lambda_i(t)$ 为隐式对偶变量）：
$$\nabla f_0(x^*(t)) + \sum_{i=1}^{m} \lambda_i(t)\, \nabla f_i(x^*(t)) = 0, \qquad \lambda_i(t) = \frac{-1}{t\, f_i(x^*(t))} > 0$$
对偶间隙上界与收敛复杂度（$n$ 为不等式约束个数，记 $x^{(k)}$ 为第 $k$ 个障碍问题解）：
$$f_0(x^*(t)) - p^* \le \frac{m}{t}, \qquad N_{\text{outer}} = O\!\left(\log\frac{m}{t_0\, \varepsilon}\right),\quad N_{\text{total}} = O\!\left(\sqrt{n}\; \log\frac{m}{t_0\, \varepsilon}\right)$$
牛顿步与回溯线搜索（内层）：
$$\Delta x_{nt} = -\left(\nabla^2(t f_0 + \phi)\right)^{-1} \nabla (t f_0 + \phi), \qquad t_s := \max\{\beta^j : f(x + \beta^j \Delta x_{nt}) \le f(x) + \alpha \beta^j \nabla f(x)^T \Delta x_{nt}\}$$
### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $\phi(x)$ | 对数障碍函数 | $\mathbb{R}^n \to \mathbb{R}$ | 严格凸、定义域为严格可行集 |
| $t$ | 障碍权重 | $t > 0$ | 越大越"贴近边界" |
| $x^*(t)$ | 中心路径点 | $\mathbb{R}^n$ | 障碍问题的唯一极小点 |
| $\lambda_i(t)$ | 隐式对偶变量 | $\lambda_i > 0$ | 显式构造的对偶可行解 |
| $m$ | 不等式约束个数 | 正整数 | 对偶间隙 $= m/t$ |
| $\mu$ | 外层倍增因子 | 通常 $10 \sim 20$ | 太大内层迭代多，太小外层轮数多 |
| $\alpha, \beta$ | 回溯参数 | $\alpha \in (0, 0.5),\ \beta \in (0, 1)$ | 典型 $\alpha = 0.01 \sim 0.3,\ \beta = 0.5 \sim 0.8$ |

### 4. 常见变体与适用条件
- **变体**：原始内点法（barrier method，本文）；原始-对偶内点法（同时迭代 $x, \lambda, \nu$，实践中更快，MOSEK/ECOS 实现）；对 LP 的简化（障碍 + 仿射等式可直接消元）。
- **适用条件**：问题严格可行（存在严格内点）；$f_0, f_i$ 二阶可微（或可加光滑化）。
- **限制条件**：需要可行起点（不可行时先做 phase I 或两阶段法）；每次牛顿迭代解 $n \times n$ 线性系统 $O(n^3)$，变量数超过 $10^4 \sim 10^5$ 后让位于一阶法（[[最优化方法-一阶方法收敛性分析]]）；$t$ 增大后问题病态加剧（Hessian 条件数 $\sim t$）。

## 6. 推导思路和思想来源
- **最初困难**：不等式约束让 KKT 系统无法直接求解；可行域投影复杂；单纯形法无最坏情形多项式保证。
- **直接方法局限**：罚函数法（二次罚）需要罚参数 $\to \infty$ 才能精确满足约束，数值上必然病态。
- **关键"转念"**：不追求"一步到位"，而是构造一族**逼近问题** $\min t f_0 + \phi$，让 $t$ 从 $1$ 慢慢涨到 $10^6$。两个洞察撑起整个理论：① $\phi$ 是**自洽障碍**（self-concordant），使牛顿法在最坏情形也有受控的迭代次数（阻尼阶段每次常数因子收缩，之后二次收敛）；② $x^*(t)$ 附带一个**免费的对偶可行解** $\lambda_i(t) = -1/(t f_i(x^*(t)))$，于是 $m/t$ 就是可验证的对偶间隙——算法可以"边算边报误差"。
- **推导主线与动机**：KKT 条件（[[最优化方法-凸优化与拉格朗日对偶]]）→ 用 $\lambda_i = -1/(t f_i)$ 参数化得到中心路径条件 → 障碍问题的最优性条件自动满足该参数化 → barrier method 外层 $\mu$ 倍增、内层牛顿 → 自洽障碍性质给出牛顿迭代数 $O(\sqrt{m})$ → 总复杂度 $O(\sqrt{m}\log(m/(t_0\varepsilon)))$。
- **为什么自然得到此结论**：对数函数是唯一"把乘法变成加法"的凸函数（$\log(uv) = \log u + \log v$），这让约束的乘积结构（$\prod (-f_i)$）变成可分离的惩罚和——这是"对数"而非其他罚函数的内在原因。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：求 $\min x$ s.t. $x \ge 1$ 的中心路径 $x^*(t)$，并验证 $t \to \infty$ 收敛到最优解。
- **解题思路与关键步骤**：写成 $f_1(x) = 1 - x \le 0$。障碍 $\phi(x) = -\log(x - 1)$，障碍问题 $\min\ tx - \log(x-1)$。一阶条件：$t - \frac{1}{x-1} = 0$。
- **最终答案**：$x^*(t) = 1 + \frac{1}{t}$；对偶间隙 $= m/t = 1/t$；取 $t = 10^6$ 时 $x^* = 1.000001$，间隙 $10^{-6}$。检验 $\lambda_1(t) = -1/(t f_1(x^*)) = -1/(t(1 - x^*)) = 1$，与最优对偶变量一致。
- **易错点**：混淆 $f_1(x) \le 0$ 的符号（障碍是 $-\log(-f_1)$，不是 $-\log(f_1)$）。
- **🤔 追问**：若改成两个约束 $x \ge 1, x \le 3$？——中心路径 $x^*(t) = \frac{3 + 1 + \sqrt{(3-1)^2 + 4/t^2}}{2}$ 型表达式（解二次方程），$t \to \infty$ 时 $x^* \to 1$（活跃约束），间隙 $2/t$。
### 例子 2：中等例子（条件判断与多步推理）
- **题目**：写出 LP $\min c^T x$ s.t. $Ax \le b$ 的 barrier method 完整算法（伪代码），并说明每步在做什么。
- **解题思路与完整解答**：$\phi(x) = -\sum_{i=1}^m \log(b_i - a_i^T x)$，梯度 $\nabla\phi = \sum_i \frac{a_i}{b_i - a_i^T x}$，Hessian $\nabla^2\phi = \sum_i \frac{a_i a_i^T}{(b_i - a_i^T x)^2}$。算法：
```python
def barrier_lp(c, A, b, t0=1.0, mu=15.0, eps=1e-6, alpha=0.2, beta=0.5):
    x = find_strict_feasible(A, b)          # phase I：先找一个严格可行点
    t = t0
    while m / t > eps:                       # 外层：对偶间隙判据
        for _ in range(max_inner):           # 内层：阻尼牛顿法
            grad = t*c + grad_phi(x, A, b)
            H    = hess_phi(x, A, b)         # 只含障碍项（c^T x 二阶为零）
            dx   = -np.linalg.solve(H, grad) # 牛顿步
            lam2 = -grad @ dx                # 牛顿减量^2
            if lam2 / 2 <= 1e-8: break       # 牛顿收敛判据
            s = 1.0
            while not (Armijo(x + s*dx) and feasible(x + s*dx)):
                s *= beta                    # 回溯线搜索（还要保证不越墙）
            x = x + s*dx
        t *= mu                              # 外层：加大障碍权重
    return x, m/t                            # 解与最终对偶间隙
```
**关键推理**：① 回溯条件多一条"新点仍严格可行"（否则 $\phi = \infty$）；② Hessian 只来自 $\phi$（线性目标二阶为零），所以是 $A$ 的加权 Gram 矩阵，可预分解加速；③ 终止判据用对偶间隙 $m/t$ 而非残差——这正是内点法的"可验证最优性"。
- **易错点**：初始点不可行会直接 $\log$ 负值报错；`lam2` 判据应使用牛顿减量而非梯度范数。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：用内点法手撕 LP 并与 CVXPY 标杆对照（HW03 验收方式）：
```python
import numpy as np
# 问题：min c^T x  s.t. Ax <= b（手撕 barrier，见上）
x_ip, gap = barrier_lp(c, A, b, eps=1e-6)

import cvxpy as cp
x = cp.Variable(n)
prob = cp.Problem(cp.Minimize(c @ x), [A @ x <= b])
prob.solve(solver=cp.ECOS)          # ECOS = 原始-对偶内点法
x_cvx = x.value
assert np.allclose(x_ip, x_cvx, atol=1e-3)   # HW03 pytest 验收
print(f"间隙={gap:.2e}, 最大偏差={np.abs(x_ip-x_cvx).max():.2e}")
```
**与单纯形法的工程对比**：LP 规模 $10^5$ 约束时，单纯形法（[[最优化方法-单纯形法与线性规划]]）每步换基 $O(nm)$、迭代数实践中好但无界；内点法总迭代 $O(\sqrt{m}\log(1/\varepsilon))$（每次牛顿迭代 $O(mn^2)$ 或稀疏分解更快），最坏情形有保证；商业求解器对 LP 默认内点法、对需要热启动的场景（MILP 节点）用单纯形。

## 8. 常见误区和易混概念
### 误区 1：以为"中心路径的 $x^*(t)$ 就是近似最优解，直接输出"
- **错误直觉**：解完一个障碍问题就收工。
- **为什么错**：$x^*(t)$ 与最优解的距离 ≈ $m/t$；若 $t$ 小（如 $t=1$），误差可能很大；必须按 $\mu$ 倍增 $t$ 直到 $m/t < \varepsilon$。
- **正确理解**：$t$ 是"精度旋钮"，对偶间隙 $m/t$ 是**可验证的误差上界**——算法终止条件就是它。
### 误区 2：把复杂度 $O(\sqrt{n}\log(1/\varepsilon))$ 里的 $n$ 当成变量维数，或以为它是一次牛顿迭代的代价
- **错误直觉**：$n$ 是 $x$ 的维数，整个算法 $O(\sqrt n \log)$ 次浮点运算。
- **为什么错**：$n$（Boyd 记为 $m$）是**不等式约束个数**；这个数是**牛顿迭代总次数**，每次牛顿迭代还要解 $O(N^3)$ 的线性系统（$N$ 为变量数）。
- **正确理解**：复杂度分两层：外层 $O(\log(m/t_0\varepsilon))$ 轮 × 内层 $O(\sqrt m)$ 次牛顿步 = 总 $O(\sqrt m \log(1/\varepsilon))$ 次牛顿迭代，每次代价 $O(N^3)$（稠密）。
### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 内点法（本概念） | 约束如何进入算法 | 障碍/路径，最坏情形多项式，高精度 | LP/QP/SOCP/SDP 通用求解 |
| 单纯形法 | LP 的顶点搜索 | 组合方法，实践中快，无最坏保证，可热启动 | MILP 分支定界节点、小规模 LP |
| 罚函数法/ALM | 约束如何近似 | 罚参数 $\to \infty$ 病态；ALM 用乘子修正 | [[最优化方法-增广拉格朗日与ADMM]] 非光滑问题 |
| 一阶方法 | 大规模问题 | 每步 $O(N)$ 但线性/次线性收敛，精度低 | 深度学习中不可行域问题 |

### 题目与解析
#### 1. 为什么对数障碍 $\phi(x) = -\sum_i \log(-f_i(x))$ 是凸函数？它的定义域是什么？
> [!question]- 答案解析
> - **答案**：$u \mapsto -\log(-u)$ 在 $u < 0$ 上是凸函数（二阶导 $1/u^2 > 0$），与凸函数 $f_i$ 复合后仍凸（凸函数的凸递减复合在 $-f_i$ 凸的场合保持凸：$-\log(-f_i) = -\log \circ (-f_i)$，$-f_i$ 凹，$-\log$ 凸递减——复合仍凸）；定义域为严格可行集 $\{x : f_i(x) < 0,\ \forall i\}$。
> - **解析**：凸性保证障碍问题 $\min t f_0 + \phi$ 是凸问题，中心路径 $x^*(t)$ 唯一；定义域取开集是因为 $\log 0 = -\infty$，边界上 $\phi \to +\infty$ 形成"软墙"。
> - **易错原因**：记错复合方向（凸函数与凸函数的复合不一定凸，这里依赖 $-\log$ 的单调性）。
#### 2. 对 $\min\ x$ s.t. $x \ge 1$，求 $t = 100$ 时中心路径点、对偶变量与对偶间隙。
> [!question]- 答案解析
> - **答案**：$x^*(100) = 1 + 1/100 = 1.01$；$\lambda_1 = 1$；间隙 $= m/t = 1/100 = 0.01$。
> - **解析**：一阶条件 $t - 1/(x-1) = 0 \Rightarrow x = 1 + 1/t$；对偶间隙 $f_0(x^*) - p^* = 1.01 - 1 = 0.01 = m/t$，精确相等（单约束时间隙公式取等号）。$\lambda_1 = -1/(t f_1(x^*)) = -1/(100 \times (1 - 1.01)) = 1$。
> - **易错原因**：符号错误（$f_1 = 1 - x$ 而非 $x - 1$）。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 3. 为什么外层倍增因子 $\mu$ 通常取 $10 \sim 20$ 而不是 $\mu = 2$ 或 $\mu = 10^6$？终止判据为什么用 $m/t$ 而不是梯度范数？
> [!question]- 答案解析
> - **答案**：$\mu$ 太小则外层轮数 $\log_\mu(m/(t_0\varepsilon))$ 太多；$\mu$ 太大则每次 $t$ 跳变后牛顿法需很多步才收敛（且病态加剧）——$10 \sim 20$ 是"内外层总工作量"的平衡点。用 $m/t$ 是因为它是**可验证的对偶间隙**（$\lambda_i(t)$ 是对偶可行解），梯度范数小不代表接近最优（尺度问题）。
> - **解析**：总牛顿迭代数 $\approx \sqrt{m}\,\log_\mu(\mu m/(t_0\varepsilon))$，对 $\mu$ 求最优在 $\mu \approx e$ 附近；工程上 $10 \sim 20$ 接近最优且对偶间隙每轮降一个数量级，好记账。
> - **易错原因**：把 $\mu$ 当超参随意调；用原始残差当终止判据。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 4. 同一 LP 用内点法与单纯形法求解，各自的迭代特征与适用场景是什么？为什么 MILP 分支定界内部用单纯形而非内点法？
> [!question]- 答案解析
> - **答案**：内点法迭代数 $O(\sqrt{m}\log(1/\varepsilon))$ 有最坏情形保证、对大规模 LP 精度高；单纯形法迭代数实践中远小于理论指数上界、对病态数据更稳健。MILP 分支定界在每个节点求解 LP，且节点间解变化小——单纯形法可**热启动**（从父节点基出发），内点法每节点需从头迭代。
> - **解析**：内点法每次迭代解一个线性系统（可利用稀疏分解），单纯形法每步换基（稀疏单纯形对网络流等结构化问题极快）；现代商用求解器两者都内置，按问题特征自动选择。
> - **易错原因**：以为内点法"总是更好"——忽略了热启动与稀疏结构。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 5. 写出 LP $\min c^T x$ s.t. $Ax \le b$ 的牛顿步公式（用障碍的梯度/海森表示），并解释总复杂度 $O(\sqrt{m}\log(m/(t_0\varepsilon)))$ 每一项的含义。
> [!question]- 答案解析
> - **答案**：令 $s_i = b_i - a_i^T x$，$\nabla\phi = \sum_i a_i/s_i$，$H = \sum_i a_i a_i^T/s_i^2$；牛顿步 $\Delta x_{nt} = -H^{-1}(t c + \nabla\phi)$。复杂度：$\sqrt{m}$ = 每轮障碍问题牛顿迭代数上界（自洽障碍性质），$\log(m/(t_0\varepsilon))$ = 外层轮数（间隙 $m/t$ 从 $m/t_0$ 降到 $\varepsilon$，$t$ 乘 $\mu$ 增长），两者相乘为总牛顿迭代数；每次牛顿迭代另有 $O(N^3)$（或稀疏分解）代价。
> - **解析**：$H$ 恰是加权 Gram 矩阵 $\sum_i a_i a_i^T / s_i^2$，半正定（严格可行时正定），牛顿步良定义；线性目标使 Hessian 只来自障碍。把 $m$ 换记为 $n$ 即 $O(\sqrt{n}\log(1/\varepsilon))$ 的常见写法。
> - **易错原因**：把复杂度当总浮点运算量（漏掉每次迭代的线性系统代价）；混淆约束数 $m$ 与变量数 $N$。
> - **Obsidian 标签建议**：`#自测题/较难`

## ⚠️ 常见陷阱与避坑指南

> [!CAUTION]
> 1. **中心路径边界陡峭性引发的 Hessian 病态**：对数障壁函数 $-\mu \sum \ln(-f_i(x))$ 在接近可行域边界时梯度与 Hessian 极度陡峭。当障碍参数 $\mu \to 0$ 时，Newton 方程组的系数矩阵严重病态，必须使用原对偶内点法 (Primal-Dual Interior-Point Method)。
> 2. **原对偶内点法步长截断**：在更新原对偶变量 $(x, \lambda, 
u)$ 时，步长 $\glpha$ 必须经过截断，确保新迭代点严格保持对偶可行性 $\lambda + \glpha \Delta \lambda > 0$（通常乘以 $0.995$ 保护因子）。

## 🃏 Anki 卡片

Q: 障壁内点法 (Barrier Method) 中对数障壁函数的作用是什么？
A: 用 $-\mu \sum_{i=1}^m \ln(-f_i(x))$ 将不等式约束拼接到目标函数中，当 $x$ 接近可行域边界 $f_i(x) \to 0^-$ 时，对数项趋于 $+\infty$，形成高墙阻止迭代点穿出可行域，从而将约束优化转为无约束优化。
<!-- id: opt-ipm-01 -->

Q: 原对偶内点法 (Primal-Dual Interior Point Method) 相比对数障壁法有何核心优势？
A: 原对偶内点法同时迭代原变量与对偶变量，不需要在每个内层循环中精确求解 Newton 步，且收敛速度更快、数值稳定性更好，是现代凸优化求解器（如 ECOS, MOSEK）的主流内核。
