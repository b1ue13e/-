# 最优化方法-信赖域方法

## 0. 学习边界
- **类别**：A+ 类（大规模与非凸优化的利器）
- **判断理由**：信赖域（Trust Region）方法是与线搜索并列的两大全局优化策略。与线搜索“先定方向，再找步长”的逻辑完全相反，信赖域是“先定步长上限（信赖域半径），再在域内寻找最优方向”。它能够天然地处理非正定 Hessian 矩阵（自动包含负曲率方向），在高度非凸的问题上极其稳健，是深度学习、非线性最小二乘（Levenberg-Marquardt）背后的灵魂思想。

---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
在使用牛顿法求解非凸问题时，Hessian 矩阵 $\nabla^2 f(x_k)$ 可能有负特征值（不是正定的）。此时牛顿方向 $p_k = -(\nabla^2 f)^{-1}\nabla f$ 可能根本不是下降方向！
线搜索遇到这种情况非常头疼，需要对 Hessian 进行强制正定修正。而我们希望能有一种方法，无需修改模型，直接处理负曲率情况，并且在模型不准确的地方（比如距离当前点太远的地方）限制步子，不让它乱跑。

---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：信赖域的核心在于求解带范数约束的二次规划子问题（Trust Region Subproblem, TRS）。这个子问题的解析结构极为优美，引出了久明方程（Secular Equation）。
- **实际应用场景**：Levenberg-Marquardt (LM) 算法常用于计算机视觉中的 Bundle Adjustment 和 SLAM，它本质上就是一个带特殊 Hessian 近似的信赖域方法。
- **高频题型/任务**：推导和证明 TRS 的全局最优解所需的 KKT 条件（特别是乘子 $\lambda$ 使得 $B + \lambda I \succeq 0$ 的条件）；折线法（Dogleg Method）的路径描绘。

## 4. 用直觉语言解释它
> «"这就像一个被关在带链条的项圈里的狗。主人（当前点）画了一个圈（信赖域半径 $\Delta$），告诉狗：‘在这个圈里，你可以去你觉得骨头最香的地方（求二次模型的极小值）。如果你觉得最香的地方在圈外，你最多只能跑到链条崩直（落界在边界上）’。"»
- **直觉类比/几何图像**：
  我们用一个二次曲面 $m_k(p)$ 来拟合当前的复杂地形。但是泰勒展开只有在中心点附近才准确。我们不相信太远的地方，所以画了一个半径为 $\Delta_k$ 的球形信赖域。我们只在这个球里寻找 $m_k(p)$ 的最低点。
- **动态调整**：如果在这个球里找到的点，实际函数值下降得跟模型预测的一样好，说明模型很准，下一步可以把球画大点（放大信赖域）；如果实际非但不降反升，说明模型在这个范围内都极度失真，必须把球缩小（收缩信赖域）。

## 5. 正式定义、核心公式、符号解释
### 1. 二次模型与信赖域子问题 (TRS)
在点 $x_k$，构建二次模型：
$$m_k(p) = f(x_k) + g_k^T p + \frac{1}{2}p^T B_k p$$
其中 $g_k = \nabla f(x_k)$，$B_k$ 可以是真实的 Hessian 矩阵 $\nabla^2 f(x_k)$ 或其近似。
我们要解决的 **Trust Region Subproblem** 是一个带约束的优化问题：
$$\min_{p \in \mathbb{R}^n} m_k(p) \quad \text{s.t. } \|p\| \le \Delta_k$$

### 2. 评价比率 $\rho_k$ 与信赖域更新
定义实际下降量 (Actual Reduction) 和预测下降量 (Predicted Reduction) 的比值：
$$\rho_k = \frac{f(x_k) - f(x_k + p_k)}{m_k(0) - m_k(p_k)}$$
- 若 $\rho_k \approx 1$（如 $\rho_k > 0.75$）：模型极好，可以放大半径 $\Delta_{k+1} = 2\Delta_k$。
- 若 $\rho_k > 0$（如 $0.25 \le \rho_k \le 0.75$）：接受步子，半径不变。
- 若 $\rho_k < 0.25$（甚至为负数）：拒绝这一步（不更新位置），并且狠狠缩小半径 $\Delta_{k+1} = 0.25\Delta_k$。

### 3. 符号说明表
| 符号 | 含义 |
|---|---|
| $\Delta_k$ | 第 $k$ 步的信赖域半径 |
| $B_k$ | 目标函数的二阶信息，不要求正定 |
| $p$ | 相对于当前点的偏移向量（即步长与方向的组合） |
| $\rho_k$ | 保真度比率 (Ratio) |

## 6. 推导思路和思想来源
### 信赖域子问题的最优性条件（解析理论）：
- **最初困难**：如何求解 $\min p^T B p + g^T p$ s.t. $p^T p \le \Delta^2$？特别是当 $B$ 非正定时。
- **关键推导**：应用拉格朗日乘子法，设乘子为 $\lambda \ge 0$。拉格朗日函数为 $L(p, \lambda) = g^T p + \frac{1}{2}p^T B p + \frac{\lambda}{2}(p^T p - \Delta^2)$。
令 $\nabla_p L = 0$，得到：
$$(B + \lambda I) p = -g$$
为了让这个稳定点是全局极小值，二阶条件要求 Hessian $(B + \lambda I)$ 必须半正定！即 $(B + \lambda I) \succeq 0$。
而且互补松弛条件要求 $\lambda (\Delta - \|p\|) = 0$。
- **结论（极重要）**：$p^*$ 是 TRS 全局最优解的充要条件是存在标量 $\lambda \ge 0$，使得：
  1. $(B + \lambda I) p^* = -g$
  2. $\lambda (\Delta - \|p^*\|) = 0$
  3. $(B + \lambda I) \succeq 0$
- **为什么自然得到此结论**：这非常优雅，$\lambda$ 的作用就是给非正定的矩阵 $B$ 加上一个对角正则化项 $\lambda I$，直到它变得正定为止。这在数学上等价于 Levenberg-Marquardt (LM) 方法。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：柯西点 (Cauchy Point) 求解
柯西点是信赖域方法必须满足的最基本退化形态。它等同于“限制在负梯度方向上的带信赖域的最速下降”。
设 $p_k^s = -\tau \frac{\Delta_k}{\|g_k\|} g_k$ 或者只沿负梯度找极小。如果单纯为了满足全局收敛，不管用什么高级方法求 TRS，只要该方法求得的解在模型上的下降量，不差于柯西点的下降量，就能保证全局收敛。

### 例子 2：狗腿法 (Dogleg Method)
当 $B$ 是正定矩阵时，狗腿法提供了一种非常快速且近似的 TRS 求解路径：
- 路径起点：原点。
- 第一段：从原点走到非约束极小的最速下降点（柯西点附近的无约束点）。
- 第二段：从该点走向牛顿点 $p^N = -B^{-1}g$。
这条由两段折线构成的路径（形状像狗的后腿）随着到原点的距离单调递增。求解时，只需找到这条折线与半径为 $\Delta$ 的球面的交点即可。这是一个简单的一元二次方程求根，避免了复杂的矩阵分解！

### 例子 3：实际应用例子（Levenberg-Marquardt 算法联系）
LM 算法用于最小二乘问题 $\min \|F(x)\|^2$。其迭代为 $(J^T J + \mu I) p = -J^T F$。
这里的阻尼因子 $\mu$ 完全对应于 TRS 中的拉格朗日乘子 $\lambda$！
- $\mu$ 大（对应极小信赖域），算法倾向于梯度下降，鲁棒但慢。
- $\mu$ 小（对应极大信赖域），算法倾向于高斯-牛顿法，收敛极快但可能不稳定。

## 8. 常见误区和易混概念
### 误区 1：只要解决了 TRS，信赖域方法就一定能前进一步。
> **纠正**：不一定。即使算出了完美的 $p^*$，如果在原函数上测试发现 $\rho_k < 0.25$ 甚至为负，这一步也是要被 **拒绝 (Rejected)** 的。此时 $x_{k+1} = x_k$，必须缩小 $\Delta$ 重新求解 TRS。

### 概念对比表
| 对比维度 | 线搜索 (Line Search) | 信赖域 (Trust Region) |
|---|---|---|
| **决策顺序** | 先定方向 $p$，再找步长 $\alpha$ | 先定步长上限 $\Delta$，找最佳方向和实际步长 $p$ |
| **对非正定Hessian的处理** | 必须提前强行修改 Hessian 使其正定 | 天然支持，Hessian 有负曲率反而能提供绝佳的下降方向 |
| **子问题复杂度** | 简单（一维搜索） | 困难（求解带约束的二次规划，或使用 Dogleg 等近似） |

## 11. 自测题：5 道
> [!question]- 题目 1：在评估 $\rho_k$ 时，如果 $\rho_k$ 接近 0 或为负数，算法会如何调整？
> **解答**：这说明实际函数在这一步没有下降，或者下降远不如二次模型预测的那么多，暗示模型在距离中心 $\Delta_k$ 这么远的地方极其不准确。算法会拒绝当前的步幅（即保持 $x_{k+1} = x_k$），并将信赖域半径大幅缩小（例如 $\Delta_{k+1} = 0.25\Delta_k$），然后重新求解。

> [!question]- 题目 2：信赖域方法中，如果当前信赖域极大，而 Hessian 矩阵正定，求解 TRS 会得到什么解？
> **解答**：当 $\Delta$ 足够大以至于包含了无约束极小点时，约束不激活。根据互补松弛条件，乘子 $\lambda = 0$。此时方程 $(B + 0 I)p = -g$ 直接给出牛顿方向 $p = -B^{-1}g$。也就是说，在高度信任模型时，信赖域法完全等价于纯牛顿法。

> [!question]- 题目 3：信赖域子问题中的拉格朗日乘子 $\lambda$ 为什么要求 $(B + \lambda I)$ 必须半正定？
> **解答**：如果 $(B + \lambda I)$ 有负特征值，那么在拉格朗日函数的展开式中，沿着相应的负特征向量方向，目标函数可以无下界。这意味着求出的偏导为零的点只是一个鞍点或局部极大值，而不是全局极小值。半正定性是二阶充分条件的要求。

> [!question]- 题目 4：Dogleg（狗腿法）适用的前提条件是什么？
> **解答**：Dogleg 适用的前提是近似 Hessian 矩阵 $B$ 必须是严格正定的。如果不正定，无约束牛顿点可能不存在或不是极小点，折线路径的构造（从柯西点连向牛顿点）将失去几何基础与单调下降意义。

> [!question]- 题目 5：什么是“硬情况”（The Hard Case）？
> **解答**：在求解 TRS 的 $(B+\lambda I)p = -g$ 时，如果 $B$ 的最小特征值 $\lambda_1$ 为负，我们理应取 $\lambda = -\lambda_1$ 使得矩阵半正定。但是有可能正好此时梯度 $g$ 垂直于对应的特征向量，导致在此特征向量方向上缺乏一次项来“拉动”步长使得边界条件 $\|p\| = \Delta$ 满足。这是一个病态的极端数学边缘情况，需要特意在特征向量方向上添加一个任意大的分量来补足范数。

## ⚠️ 常见陷阱与避坑指南

> [!CAUTION]
> 1. **信赖域半径更新阈值的稳定性**：实际下降量与预测下降量之比 $\rho_k = \frac{f(x_k) - f(x_k + s_k)}{m_k(0) - m_k(s_k)}$。当 $\rho_k < 0.25$ 时必须缩减半径；当 $\rho_k > 0.75$ 且解紧贴信赖域边界时才放大半径。不要在 $\rho_k \gpprox 0$ 时盲目更新点 $x_{k+1}$。
> 2. **Cauchy 点解决全局收敛保障**：信赖域子问题的近似求解至少要达到 Cauchy 点的下降量，否则算法无法保障全局收敛性。

## 🃏 Anki 卡片

Q: 信赖域方法 (Trust Region Method) 与线搜索方法 (Line Search) 的根本哲学区别是什么？
A: 线搜索方法先确定下降方向 $d_k$，再搜索合适的步长 $\alpha_k$；信赖域方法先确定最大许可步长半径 $\Delta_k$（信赖域），再在该区域内求解二次子模型得到最佳位移向量 $s_k$。
<!-- id: opt-tr-01 -->

Q: 信赖域子问题中拟合优度指标 $\rho_k$ 的定义及其决策逻辑是什么？
A: $\rho_k = \frac{f(x_k) - f(x_k + s_k)}{m_k(0) - m_k(s_k)}$（实际下降 / 模型预测下降）。
若 $\rho_k \le 0$：拒绝步长，缩小半径 $\Delta_{k+1} = \Delta_k / 4$；
若 $\rho_k \in (0, 0.75)$：接受步长，保持半径；
若 $\rho_k \ge 0.75$ 且 $\|s_k\| = \Delta_k$：接受步长，扩大半径 $\Delta_{k+1} = \min(2\Delta_k, \Delta_{\max})$。

---

Q: 信赖域 Powell Dogleg 算法的折线轨迹连接了哪两个关键节点？
A: 轨迹连接了最速下降 Cauchy 点 $p_C = -\frac{g^\top g}{g^\top B g} g$ 与非受控牛顿点 $p_N = -B^{-1} g$，在信赖域边界上进行连续截断插值。
