# 最优化方法-牛顿法


## 2. 为什么它重要？它有什么用？
- **连接大图景**：它是从一阶方法迈向二阶方法的桥梁；用二阶收敛（迭代次数远少于梯度法）换取每步更高的计算成本。
- **实际应用场景**：
  - Logistic / 岭回归中的 Newton-CG、信赖域牛顿。
  - 凸优化内点法（每步解一个牛顿方程组追踪中心路径）。
  - 深度学习中的 Hessian-free 优化（用 CG 求解牛顿步而不显式存 Hessian）。
- **高频题型/任务**：推导牛顿步、证明二次收敛、写出阻尼牛顿迭代、处理 Hessian 非正定时的修正。

## 3. 学它之前需要哪些前置知识？
1. **[[最优化方法-多元梯度与海森矩阵]]**：牛顿步依赖梯度 $g_k=\nabla f(x_k)$ 与海森矩阵 $H_k=\nabla^2 f(x_k)$。
2. **[[最优化方法-最速下降与收敛分析]]**：用来对比收敛速度（线性 vs 二次）。
3. **[[最优化方法-线搜索与步长策略]]**：阻尼牛顿用线搜索确定步长 $\alpha_k$。

## 4. 用直觉语言解释它
> «"梯度下降像蒙眼下山，只凭脚感找最陡方向；牛顿法先用手摸清楚脚下地形的曲率（Hessian），在局部建一个抛物面模型，直接算出碗底在哪，一步跨过去。"»
- **直觉类比/几何图像**：在 $x_k$ 处用二阶泰勒展开把函数近似成一个碗状二次曲面 $m_k(d)=f_k+g_k^T d+\frac12 d^T H_k d$。这个碗的"形状"由 $H_k$ 决定，碗底位置就是令梯度为零的点：$H_k d = -g_k$，于是牛顿步 $d_k^N = -H_k^{-1} g_k$。若局部模型精确（函数本身就是二次型），这一步直接到达真极小点。
- **一句话直觉本质**：用海森矩阵把"峡谷"拉伸成"圆碗"，消除条件数带来的锯齿，从而快速逼近极小。

---
## 5. 正式定义、核心公式、符号解释

### 1. 核心定义
对无约束光滑极小化 $\min_x f(x)$，在当前点 $x_k$ 处构造局部二次模型：
$$ m_k(d) = f(x_k) + \nabla f(x_k)^T d + \frac12 d^T \nabla^2 f(x_k)\, d $$

### 2. 核心公式
- **牛顿步（Newton step）**：
  $$ d_k^{N} = -\bigl(\nabla^2 f(x_k)\bigr)^{-1} \nabla f(x_k) $$
- **纯牛顿迭代**：$x_{k+1} = x_k + d_k^{N}$（固定步长 1）。
- **阻尼牛顿（Damped Newton）**：$x_{k+1} = x_k + \alpha_k d_k^{N}$，其中 $\alpha_k$ 由线搜索（如 Armijo 回溯）确定，保证充分下降。

### 3. 符号说明表
| 符号 | 含义 |
| :--- | :--- |
| $g_k = \nabla f(x_k)$ | 当前梯度（一阶导数） |
| $H_k = \nabla^2 f(x_k)$ | 当前海森矩阵（二阶导数） |
| $d_k^N$ | 牛顿方向（下降方向，当 $H_k\succ 0$） |
| $\alpha_k$ | 阻尼步长（线搜索给出） |

### 4. 常见变体与适用条件
- **阻尼牛顿**：当 $H_k$ 非正定时用线搜索保证下降，是实际首选。
- **牛顿-CG（Truncated Newton）**：不显式求 $H_k^{-1}$，而用共轭梯度法迭代求解牛顿方程组 $H_k d = -g_k$，适合高维（避免 $O(n^3)$ 求逆）。
- **修正牛顿**：对 $H_k$ 做正定修正（如加 $\tau I$）后再求逆，应对非凸情形。

## 6. 推导思路和思想来源
- **最初困难**：最速下降只看一阶，峡谷里锯齿慢。
- **关键"转念"**：既然在 $x_k$ 附近用二阶泰勒近似，何不把近似函数当成真函数，直接求它的极小点？
- **推导主线**：
  对二次模型 $m_k(d)$ 关于 $d$ 求导并令为零：
  $$ \nabla_d m_k(d) = g_k + H_k d = 0 \quad\Rightarrow\quad d_k^N = -H_k^{-1} g_k $$
- **二次收敛来源**：若 $f$ 二阶连续可微，且在最优点 $x^*$ 处 $H^*=\nabla^2 f(x^*)\succ 0$ 且 Lipschitz 连续，则在 $x_k$ 充分接近 $x^*$ 时，用纯牛顿步有
  $$ \|x_{k+1}-x^*\| \le c\,\|x_k-x^*\|^2 $$
  即误差平方级收缩——这就是"二次收敛"。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：手算（二次函数一步收敛）
对 $f(x)=\frac12 x^T A x - b^T x$（$A\succ 0$），有 $g_k=Ax_k-b$，$H_k=A$。牛顿步：
$$ d_k^N = -A^{-1}(A x_k - b) = x^* - x_k \quad\Rightarrow\quad x_{k+1}=x_k+d_k^N = x^* $$
**一步到达精确解**（因为二次模型与函数完全一致）。

### 例子 2：Python 阻尼牛顿（Rosenbrock 函数）
```python
import numpy as np

def f(x):
    return 100*(x[1]-x[0]**2)**2 + (1-x[0])**2

def grad_f(x):
    g = np.zeros(2)
    g[0] = -400*x[0]*(x[1]-x[0]**2) - 2*(1-x[0])
    g[1] = 200*(x[1]-x[0]**2)
    return g

def hess_f(x):
    H = np.zeros((2,2))
    H[0,0] = 1200*x[0]**2 - 400*x[1] + 2
    H[0,1] = H[1,0] = -400*x[0]
    H[1,1] = 200
    return H

def backtracking(x, g, d):
    alpha = 1.0
    c = 1e-4
    while f(x + alpha*d) > f(x) + c*alpha*(g @ d):
        alpha *= 0.5
    return alpha

x = np.array([-1.0, 2.0])
for k in range(50):
    g = grad_f(x)
    if np.linalg.norm(g) < 1e-8:
        break
    H = hess_f(x)
    # 修正牛顿：保证 H 正定可用
    try:
        d = -np.linalg.solve(H, g)
    except np.linalg.LinAlgError:
        d = -g
    alpha = backtracking(x, g, d)
    x = x + alpha*d
print("牛顿法收敛点:", x, "迭代:", k+1)
```

## 8. 常见误区和易混概念
### 误区 1：认为牛顿法总比梯度法快
**澄清**：牛顿法仅在最优点附近（模型足够准且 $H_k\succ 0$）才二次收敛；在远离最优点或函数非凸时，牛顿步可能不是下降方向，甚至发散。实际必须用阻尼/修正。
### 误区 2：忽视求逆的 $O(n^3)$ 代价
**澄清**：显式求解 $H_k^{-1}$ 在高维（百万参数）不可行，这正是拟牛顿法（BFGS / L-BFGS，只近似 $H^{-1}$ 且只需 $O(n^2)$ 甚至 $O(n)$ 内存）和牛顿-CG 出现的原因。

### 概念对比表
| 方法 | 收敛阶（近最优） | 每步代价 | 内存 | 对 Hessian 要求 |
| :--- | :--- | :--- | :--- | :--- |
| 最速下降 | 线性（条件数差时极慢） | $O(n)$ | $O(n)$ | 仅梯度 |
| 牛顿法 | 二次 | $O(n^3)$（求逆） | $O(n^2)$ | 需 $H_k\succ0$ |
| 拟牛顿 BFGS | 超线性 | $O(n^2)$ | $O(n^2)$ | 近似，无需显式求逆 |
| L-BFGS | 超线性 | $O(n)$ 向量运算 | $O(n)$ | 仅需梯度历史 |

## 11. 自测题：5 道
> [!question]- 题目 1：牛顿步 $d_k^N=-H_k^{-1}g_k$ 为什么在 $H_k\succ 0$ 时是下降方向？
> **答案**：$g_k^T d_k^N = -g_k^T H_k^{-1} g_k < 0$（因 $H_k^{-1}\succ 0$ 且 $g_k\ne0$），方向导数<0 即下降方向。

> [!question]- 题目 2：纯牛顿法在二次函数上为何一步收敛？
> **答案**：二次模型的 Hessian 等于函数真实 Hessian 且恒定，模型与函数完全一致，牛顿步恰好是到真极小点的位移 $x^*-x_k$，故一步到达。

> [!question]- 题目 3：二次收敛的含义是什么？与最速下降的线性收敛有何区别？
> **答案**：二次收敛指误差平方级收缩 $\|e_{k+1}\|\le c\|e_k\|^2$，每迭代有效数字位数约翻倍；最速下降在强凸光滑下是线性（几何）收敛 $\|e_{k+1}\|\le \rho\|e_k\|$（$0<\rho<1$），速度由条件数决定，慢得多。

> [!question]- 题目 4：当 $H_k$ 非正定时，纯牛顿步可能做什么？
> **答案**：牛顿步可能不是下降方向，甚至指向极大/鞍点方向，导致目标函数上升或发散。需用阻尼线搜索、正定修正（加 $\tau I$）或转用拟牛顿/梯度方向。

> [!question]- 题目 5：为什么高维下不直接用牛顿法而用 L-BFGS 或牛顿-CG？
> **答案**：显式求 $H_k^{-1}$ 需 $O(n^3)$ 与 $O(n^2)$ 内存，百万维不可行。L-BFGS 用梯度历史低秩近似逆，只需 $O(n)$；牛顿-CG 用共轭梯度迭代解线性方程组，避免显式求逆。

## ⚠️ 常见陷阱与避坑指南

> [!CAUTION]
> 1. **非凸时直接套纯牛顿**：必须先做阻尼线搜索或正定修正，否则可能上升/发散。
> 2. **高维显式求逆**：百万维参数下勿用 `np.linalg.inv(H)`，改用求解器 `np.linalg.solve(H, g)`、L-BFGS 或牛顿-CG。
> 3. **Hessian 计算错误**：手推 Hessian 务必校验对称性（二阶偏导连续时 $H=H^T$）。

Q: 牛顿步的公式及其下降方向成立的矩阵条件？
A: $d_k^N=-H_k^{-1}g_k$；当 $H_k\succ 0$ 时 $g_k^T d_k^N=-g_k^T H_k^{-1}g_k<0$，为下降方向。

Q: 牛顿法"二次收敛"的含义与前提？
A: 近最优且 $H^*\succ0$ 且 Hessian Lipschitz 时，$\|x_{k+1}-x^*\|\le c\|x_k-x^*\|^2$，每步有效数字约翻倍；二次函数上纯牛顿一步收敛。

Q: 牛顿法比一阶梯度下降法最核心的优势与劣势分别是什么？
A: 优势：在极小点附近具有二次收敛速率（Quadratic Convergence）；劣势：每步需计算并求解 $d \times d$ 海森矩阵，单步开销高达 O(d^3)。
