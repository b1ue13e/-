# 最优化方法 - 坐标下降法

> **核心地位**：坐标下降法（Coordinate Descent, CD）及其块拓展（Block Coordinate Descent, BCD）是一类通过每次仅沿单一坐标方向（或单一子块）进行一维最优化来求解高维无约束/结构化约束优化问题的无梯度/一阶方法。在 Lasso 正则化、Liblinear（SVM）及高维稀疏特征学习中占据主导地位。

> **🤔 苏格拉底与学习者的对话**：
> - **学习者**：“在求解高维问题（如 \(d = 1,000,000\) 维）时，计算全梯度 \(\nabla f(x)\) 极其昂贵，有没有不必计算全梯度的优化策略？”
> - **苏格拉底**：“如果你在一间黑屋子里，每次只允许你朝着一个方向（比如只向前/向后，或只向左/向右）挪动直到最低点，然后再换下一个方向，你能走到地面最低处吗？”
> - **学习者**：“如果地面是光滑碗状（凸函数），我按顺次调整每个坐标轴，最终能走到谷底！这比一次性计算三维坡度容易得多。”
> - **苏格拉底**：“那么在包含 \(L_1\) 范数非光滑项的 Lasso 优化中，为什么这种一维调整能导出绝妙的‘闭门限解’？”
> - **学习者**：“因为固定其余变量后，关于单个变量 \(w_i\) 的子问题可以利用次微分导出极其简单的‘软门限算子’！”

## §02 Lasso 问题的坐标下降解法与次梯度推导

对于 Lasso 回归问题：

\[
\min_{w \in \mathbb{R}^d} \frac{1}{2n} \|y - X w\|_2^2 + \lambda \|w\|_1
\]

固定其余 \(w_{j \neq i}\)，针对 \(w_i\) 的子问题为一维优化：

\[
\min_{w_i} \frac{1}{2} z_i \left( w_i - \frac{\rho_i}{z_i} \right)^2 + \lambda |w_i|
\]

其中 \(z_i = X_i^T X_i\)，\(\rho_i = X_i^T (y - \sum_{j \neq i} X_j w_j)\)。

### 软门限算子 (Soft-Thresholding) 次微分严谨推导：

一维凸优化 \(f(w_i)\) 的最优性一阶条件为 **\(0 \in \partial f(w_i)\)**：

\[
0 \in z_i \left( w_i - \frac{\rho_i}{z_i} \right) + \lambda \partial |w_i|
\]

1. **若 \(w_i > 0\)**：\(\partial |w_i| = \{1\}\)，解得 \(w_i = \frac{\rho_i - \lambda}{z_i}\)。此解成立前提为 \(\rho_i > \lambda\)；
2. **若 \(w_i < 0\)**：\(\partial |w_i| = \{-1\}\)，解得 \(w_i = \frac{\rho_i + \lambda}{z_i}\)。此解成立前提为 \(\rho_i < -\lambda\)；
3. **若 \(w_i = 0\)**：\(\partial |w_i| = [-1, 1]\)，充要条件为 \(0 \in -\rho_i + \lambda [-1, 1]\)，即 \(|\rho_i| \le \lambda\)。

综合以上三种情况，一维一阶解可统一表示为**软门限算子**：

\[
w_i^* = \frac{1}{z_i} S_\lambda (\rho_i) = \frac{1}{z_i} \text{sign}(\rho_i) \max\left(|\rho_i| - \lambda, 0\right)
\]

## §03 收敛性与局限

1. **可微凸函数**：若 \(f(x)\) 连续可微且严格凸，坐标下降法收敛到全局最优解；
2. **复合非光滑函数**：若目标可拆分为 \(f(x) = g(x) + \sum_{i=1}^d h_i(x_i)\)，其中 \(g\) 可微凸，\(h_i\) 凸，CD 依然收敛；
3. **反例 Warning**：若非光滑项不可分离（如 \(h(x_1, x_2) = |x_1 - x_2|\)），CD 可能停滞在非平稳点（死锁）。

## §04 Python 代码实现 (Lasso CD)

```python
import numpy as np

def soft_thresholding(rho, lam):
    """软门限算子 S_lam(rho)"""
    if rho > lam:
        return rho - lam
    elif rho < -lam:
        return rho + lam
    else:
        return 0.0

def lasso_coordinate_descent(X, y, alpha, max_iter=1000, tol=1e-6):
    """基于坐标下降法求解 Lasso 回归"""
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    z = np.sum(X**2, axis=0) # 坐标轴模长平方
    
    for it in range(max_iter):
        w_old = w.copy()
        for j in range(n_features):
            # 计算不含第 j 个特征的残差
            r_j = y - (X @ w - X[:, j] * w[j])
            rho_j = np.dot(X[:, j], r_j)
            w[j] = soft_thresholding(rho_j, alpha * n_samples) / z[j]
            
        if np.max(np.abs(w - w_old)) < tol:
            break
    return w

# 验证测试
if __name__ == "__main__":
    np.random.seed(42)
    X = np.random.randn(100, 10)
    w_true = np.array([3.0, -2.0, 0, 0, 1.5, 0, 0, 0, 0, 0])
    y = X @ w_true + 0.1 * np.random.randn(100)
    
    w_est = lasso_coordinate_descent(X, y, alpha=0.1)
    print("估计系数:", np.round(w_est, 3))
```

## §05 常见误区与工程陷阱

- **误区**：认为坐标下降对所有凸函数都收敛。
- **事实**：若非光滑项不可分离（包含交叉项如 \(|x_1 - x_2|\)），坐标下降会陷入局部死锁而无法移动。

## 🎯 知识自测与主动回忆

> [!question]- 1. 请给出软门限算子 $S_\lambda(x)$ 的表达式与几何形状。
> **答案**：$S_\lambda(x) = \text{sign}(x) \max(|x| - \lambda, 0)$。几何上是一条在 $[-\lambda, \lambda]$ 区间内收拢至 $0$，在区间外平移 $\lambda$ 模长的软折线。

> [!question]- 2. 解释为何坐标下降法极其适合高维稀疏 Lasso 回归的求解。
> **答案**：因为 Lasso 目标中的 $L_1$ 范数项 $\sum |w_i|$ 关于坐标轴是**完全可分离**的。每个坐标轴子问题不仅具备显式解析解（软门限算子），且无需矩阵求逆，一维计算复杂度仅为 $\mathcal{O}(N)$。

> [!question]- 3. 写出包含不可分离非光滑项 $f(x_1, x_2) = x_1^2 + x_2^2 + |x_1 - x_2|$ 在初始点 $(1, 1)$ 处的坐标下降表现。
> **答案**：在 $(1, 1)$ 处固定 $x_2=1$，关于 $x_1$ 的函数为 $x_1^2 + 1 + |x_1 - 1|$，在 $x_1=1$ 处取得最小值；固定 $x_1=1$，关于 $x_2$ 的函数在 $x_2=1$ 处取得最小值。坐标下降法误以为已达到极小值停止移动，但原函数在 $(0,0)$ 处取到更小值 $0$。

> [!question]- 4. 块坐标下降（Block Coordinate Descent, BCD）与点坐标下降（CD）的区别是什么？
> **答案**：CD 每次更新单维变量 $w_i$；BCD 每次选择一组变量块 $w_{I_k}$（如多分类 SVM 中的矩阵一整列）同步求解一维/低维子问题，能大幅减少通信开销并处理块可分离正则项。

> [!question]- 5. 在实际工程实现中，如何利用残差向量更新进一步加速 Lasso 坐标下降法？
> **答案**：可以维护全局残差向量 $r = y - X w$。更新第 $j$ 维时，直接计算 $\rho_j = X_j^T r + z_j w_j^{\text{old}}$，更新 $w_j^{\text{new}}$ 后将残差更新为 $r \leftarrow r - X_j (w_j^{\text{new}} - w_j^{\text{old}})$，省去每次构建全矩阵乘积的开销。

## 🃏 Anki 卡片

Q: 坐标下降法在求解包含非光滑项 Optimization 时，对目标函数结构的收敛条件要求是什么？
A: 目标函数必须能写成 $f(x) = g(x) + \sum_{i=1}^d h_i(x_i)$ 的形式，即：
1. $g(x)$ 是连续可微的凸函数；
2. 非光滑正则项 $h_i(x_i)$ 在各个坐标轴间必须是**可分离**的（如 $L_1$ 范数 $\sum |x_i|$）。若非光滑项包含交叉项（如 $|x_1 - x_2|$），坐标下降法可能会卡死在非最优点。
<!-- id: opt-cd-01 -->

Q: Lasso 坐标下降法中软门限算子 (Soft-Thresholding Operator) 的数学表达式与推导依据是什么？
A: 一维子问题一阶次梯度条件 $0 \in z_i w_i - \rho_i + \lambda \partial |w_i|$ 的解为：$w_i^* = \frac{1}{z_i} S_\lambda (\rho_i) = \frac{1}{z_i} \text{sign}(\rho_i) \max(|\rho_i| - \lambda, 0)$。其依据是在 $|\rho_i| \le \lambda$ 时次微分包含零点，使最佳解被精确压缩归零（产生稀疏性）。
<!-- id: opt-cd-02 -->

Q: 如何通过维护残差向量 $r = y - X w$ 将 Lasso 坐标下降的单次迭代开销降低？
A: 每次计算 $\rho_j = X_j^T r + z_j w_j^{\text{old}}$，在更新 $w_j^{\text{new}}$ 后增量更新残差：$r \leftarrow r - X_j (w_j^{\text{new}} - w_j^{\text{old}})$，将单次更新从 $\mathcal{O}(N d)$ 降低至向量内积开销 $\mathcal{O}(N)$。
