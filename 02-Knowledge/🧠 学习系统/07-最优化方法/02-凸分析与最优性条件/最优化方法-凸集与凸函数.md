# 最优化方法-凸集与凸函数

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：现实优化问题大多"只能找到局部最优"，且判断"当前点是否全局最优"是 NP-hard 的。传统做法是随机多起点 + 启发式搜索，既慢又不保证质量。必须找出一类**结构上保证"局部最优 = 全局最优"**的问题——凸问题。而判定凸性，第一步就是检查**定义域（凸集）**与**目标/约束函数（凸函数）**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：没有凸性就没有强对偶（$d^* = p^*$）、没有 KKT 充分性、没有内点法的多项式复杂度保证；[[最优化方法-最速下降与收敛分析]]、[[最优化方法-拟牛顿法BFGS]] 的收敛定理都以凸性为前提。
- **实际应用场景**：最小二乘、Lasso、SVM、逻辑回归、投资组合——这些模型目标都是凸的，所以能可靠求解；CVXPY 建模时 `is_convex()` 检查的正是本卡的数学。
- **高频题型/任务**：判定集合/函数凸性；用保凸运算构造新凸函数；用一阶/二阶条件证明凸性；Jensen 不等式用于 KL 散度非负等证明。

## 4. 用直觉语言解释它

> «凸集是"没有坑、没有洞、没有凹陷"的橡皮泥：任意两点连成的线段整条都躺在里面。凸函数是"碗"：任意两点的连线（弦）悬在碗面之上，碗面上任一点的切线都在碗面之下。»

- **为什么很自然**："碗形"意味着没有局部凹陷——任何局部低点都是碗底，即全局最低点。
- **一句话直觉本质**：**凸性 = "连线不越界"（集合）+ "弦在弧上 / 切线在弧下"（函数）——它把"找全局最优"从难事变成可验证的平凡事。**

---

## 5. 正式定义、核心公式、符号解释

### 1. 核心定义

- **凸集**：$\forall x, y \in C,\ \forall \theta \in [0,1]$：$\theta x + (1-\theta) y \in C$。
- **凸函数**：$\mathrm{dom}\, f$ 是凸集，且 $f(\theta x + (1-\theta) y) \le \theta f(x) + (1-\theta) f(y)$。
- **严格凸**：不等号对 $\theta \in (0,1)$、$x \ne y$ 严格成立；**强凸**：存在 $m > 0$ 使 $f(y) \ge f(x) + \nabla f(x)^T(y-x) + \frac{m}{2}\|y-x\|_2^2$。

### 2. 核心公式

- **一阶条件**（$f$ 可微、dom 凸）：$f$ 凸 $\iff f(y) \ge f(x) + \nabla f(x)^T(y-x),\ \forall x, y \in \mathrm{dom}\, f$。
- **二阶条件**（$f$ 二阶可微）：$f$ 凸 $\iff \nabla^2 f(x) \succeq 0,\ \forall x \in \mathrm{dom}\, f$。
- **上境图**：$f$ 凸 $\iff \mathrm{epi}\, f = \{(x,t) : f(x) \le t\}$ 是凸集。
- **Jensen 不等式**：$f(\mathbb{E}[x]) \le \mathbb{E}[f(x)]$。

### 3. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $C$ | 集合（定义域） | 凸集判定对象 |
| $\theta$ | 凸组合权重 | $[0,1]$ |
| $\nabla f(x)$ | 梯度 | 一阶信息 |
| $\nabla^2 f(x)$ | Hessian | $\succeq 0$ 表半正定 |
| $m$ | 强凸参数 | $> 0$ |

## 6. 推导思路和思想来源

- **最初困难**：怎么保证"局部最优就是全局最优"？怎么验证函数处处没有"凹陷"？
- **直接方法局限**：逐点扫描不可行（无穷多个点）。
- **关键"转念"**：把"处处成立"的不等式交给**结构**去保证——一阶条件 $f(y) \ge f(x) + \nabla f(x)^T(y-x)$ 在 $x$ 为驻点时直接推出 $f(y) \ge f(x)$，即驻点就是全局最小。**凸性不是被"证明"的，而是被"设计"出来的**：用保凸运算拼装已知凸函数，天然继承凸性。
- **推导主线**：定义（弦在弧上）→ 令 $y \to x$ 取极限得一阶条件 → 再求导得二阶条件 → 三者互相蕴含（可微前提下），形成"判定工具箱"。
- **为什么自然**：凸组合是"线段"与"期望"的代数化身，Jensen 不等式不过是定义在概率测度下的极限形式。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：可手算（凸性判定）

$f(x) = x^4$：$f'' = 12x^2 \ge 0$ 恒成立 → 凸（严格凸、不强凸——没有二次下界）。$f(x) = x^3$：$f'' = 6x$，$x < 0$ 时 $< 0$ → 在 $\mathbb{R}$ 上非凸（正半轴局部凸）。$f(x) = e^x$：$f'' = e^x > 0$ → 凸且严格凸，但**不强凸**（无二次下界）——"凸"与"强凸"有本质差距。

### 例子 2：中等（log-sum-exp 的凸性证明）

$\mathrm{logsumexp}(x) = \log\left(\sum_i e^{x_i}\right)$ 是凸函数。设 $z_i = e^{x_i}$：

$$ v^T \nabla^2 f\, v = \frac{1}{\mathbf{1}^T z}\sum_i z_i v_i^2 - \frac{1}{(\mathbf{1}^T z)^2}\left(\sum_i z_i v_i\right)^2 \ge 0 $$

最后一步由 Cauchy-Schwarz：$(\sum z_i v_i)^2 \le (\sum z_i)(\sum z_i v_i^2)$。**意义**：softmax 的"对数配分函数"凸 ⇒ 逻辑回归/最大熵模型损失凸。

### 例子 3：实际应用（CVXPY 凸性检查）

```python
import cvxpy as cp
x = cp.Variable(3)
f1 = cp.sum_squares(x) + cp.norm1(x)   # 凸 + 凸 = 凸
f2 = cp.square(x[0]) * x[1]            # 二次 × 线性：非凸
print(f1.is_convex())   # True
print(f2.is_convex())   # False
```

## 8. 常见误区和易混概念

- **误区 1：以为"凹函数 = 凸函数的反面，两者之外没有第三种"。** $x^3$ 既非凸也非凹；凹函数只是 $-f$ 凸。**既不凸也不凹**的函数大量存在（也是 DCP 拒绝的对象）。
- **误区 2：把"凸集的性质"套到"凸函数"上。** 凸集的**并集一般不保凸**（$[-1,0] \cup [1,2]$ 断开），**交集保凸**；函数用非负加权和与逐点最大，集合用交集与仿射逆像。口诀：**"集合用交集，函数用加权和与逐点最大"**。
- **误区 3：用二阶条件验证半正定只看顺序主子式。** 半正定需检查**全部**主子式（或直接算最小特征值 $\lambda_{\min} \ge 0$）；顺序主子式 $\ge 0$ 对半正定不充分。

| 概念 | 核心问题 | 关键区别 | 典型场景 |
| :--- | :--- | :--- | :--- |
| 凸函数 | 弦在弧上 | 全局最小 = 局部最小 | 优化目标/约束 |
| 强凸函数 | 有二次下界 | 额外保证线性收敛率 | GD/牛顿收敛分析 |
| 凹函数 | $-f$ 凸 | 最大化问题的目标 | 对偶函数、效用函数 |
| 凸集 vs 仿射集 | 线段 vs 整条直线 | 仿射集是凸集特例 | 可行域判定 |

## 11. 自测题

> [!question]- 1.（定义复述）凸函数定义中为什么是 $\le$ 而不是 $\ge$？
> **答案**：$\le$ 表示"弦在弧上"，即碗形；若为 $\ge$ 则是凹函数。取 $f(x)=x^2$、$x=-1, y=1, \theta=0.5$：左边 0、右边 1，$0 \le 1$ 成立而 $0 \ge 1$ 不成立。

> [!question]- 2.（公式运用）用二阶条件判定 $f(x,y) = x^2 + y^2 - xy$ 的凸性。
> **答案**：$\nabla^2 f = \begin{bmatrix} 2 & -1 \\ -1 & 2 \end{bmatrix}$，$D_1=2>0$、$\det=3>0$，正定 ⟹ 凸（严格凸）。易错：只查对角线而忽略交叉项。

> [!question]- 3.（反例/条件变式）$C = [-2,-1] \cup [1,2]$ 是凸集吗？$D = [-2,-1] \cap [1,2]$ 呢？
> **答案**：$C$ 非凸（取 $x=-1.5, y=1.5$，中点 0 不在 $C$）；$D$ 凸（交集保凸，空集平凡凸）。

> [!question]- 4.（保凸构造）已知 $g$ 凸，证明 $h(x) = \max\{g(x), 0\}$ 凸。
> **答案**：逐点最大保凸：$\max\{f_i(\theta x + (1-\theta)y)\} \le \max\{\theta f_i(x) + (1-\theta)f_i(y)\} \le \theta \max f_i(x) + (1-\theta)\max f_i(y)$。这是 SVM hinge 损失凸性的来源。

> [!question]- 5.（核心证明）设 $f$ 可微凸，若 $\nabla f(x^*) = 0$，证明 $x^*$ 是全局最小点。
> **答案**：由一阶条件，$\forall y$：$f(y) \ge f(x^*) + \nabla f(x^*)^T(y - x^*) = f(x^*)$。这是"凸优化可判定"的理论核心；非凸情形（如 $x^3$ 在 0）不成立。

> [!question]- 6.（辨析）"强凸"与"凸"的区别是什么？
> **答案**：强凸额外要求 $f(y) \ge f(x) + \nabla f(x)^T(y-x) + \frac{m}{2}\|y-x\|^2$（$m>0$），即存在二次下界。$e^x$ 凸但不强凸；强凸是线性收敛率的保证。
