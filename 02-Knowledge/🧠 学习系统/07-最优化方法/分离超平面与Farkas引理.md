## 0. 先判断它值不值得深挖
- **类别**：A 类（底层基础数学工具）
- **判断理由**：分离超平面定理是支撑几乎所有凸优化对偶理论的几何基石（包括强对偶证明、次梯度存在性）。而 Farkas 引理（择一定理的代表）则是线性规划强对偶性以及 KKT 条件必要性证明的核心代数工具。不从几何角度理解它们，对偶理论只是一堆枯燥的公式代数，无法建立直觉。

---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
在多维空间中，我们经常需要判断两个几何集合（尤其是凸集）是否有交集；或者在代数上，我们要判断一组线性不等式是否存在解。如果不存在解，我们能否找到一个明确的“证据”（certificate）来证明它们确实无解？这就是所谓的“择一定理”（Theorem of Alternatives）所要解决的问题：要么系统有解，要么存在一个无可辩驳的证据证明它无解，二者必居其一。

---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：
  - 分离超平面定理是几何层面；Farkas 引理是其在线性多面体锥上的代数特例表现。
  - 它们是证明凸优化问题强对偶性（Slater条件的作用）和 KKT 条件中乘子存在性的直接底层支撑。
- **实际应用场景**：
  - **金融数学**：Farkas 引理被用来证明资产定价中的“无套利基本定理”（Fundamental Theorem of Asset Pricing）。无套利条件相当于系统无解，其“证据”即为风险中性测度。
  - **支持向量机（SVM）**：硬间隔 SVM 的本质就是在寻找能分离正负两个凸集（数据点凸包）的最优分离超平面。
- **高频题型/任务**：证明两组线性条件只有一个成立；根据凸集性质构造分离函数。

## 4. 用直觉语言解释它
> «"这东西其实就像……刀切蛋糕"»
- **直觉类比/几何图像**：
  - **分离超平面**：如果你桌上有两块没有粘在一起的面团（不相交的凸集），你肯定能拿一把刀，一刀切下去，把它们分开，左边一块，右边一块。如果面团不是凸的（比如像个马蹄形包裹着另一个），你一刀下去可能就切到另一个了。
  - **支撑超平面**：一个光滑的球面，你拿一块平坦的木板去贴它，木板只能在表面切合（相切），不会刺入球体。这个木板就是支撑超平面。
  - **Farkas 引理**：一束光只能照亮一个锥形区域。如果你要找的点在这个光锥里，那就是系统1有解；如果点在光锥外，那一定能找到一个遮光板（超平面）把点和光锥完美隔开，这就是系统2有解（证据）。
- **一句话直觉本质**：对于任何凸的形状，外面的点一定能被一条直线/平面隔开；要么你能达成目标，要么能找到无法达成目标的绝对证据。

## 5. 正式定义、核心公式、符号解释
### 1. 分离超平面定理 (Separating Hyperplane Theorem)
**定理**：设 $C$ 和 $D$ 是 $\mathbb{R}^n$ 中两个**不相交的非空凸集**（即 $C \cap D = \emptyset$）。则必定存在一个非零向量 $a \in \mathbb{R}^n$ 和实数 $b \in \mathbb{R}$，使得：
$$ a^T x \le b, \quad \forall x \in C $$
$$ a^T x \ge b, \quad \forall x \in D $$
这个超平面 $\{x \mid a^T x = b\}$ 就将 $C$ 和 $D$ 分离了。
**严格分离**：如果 $C$ 是闭凸集，$D$ 是紧凸集（有界闭凸集），则存在严格分离超平面：$a^T x < b$ 且 $a^T y > b$。

### 2. 支撑超平面定理 (Supporting Hyperplane Theorem)
**定义**：设 $C \subseteq \mathbb{R}^n$ 是个集合，$x_0$ 是其边界上的点。如果存在 $a \neq 0$ 使得 $\forall x \in C, a^T x \le a^T x_0$，则称超平面 $\{x \mid a^T (x - x_0) = 0\}$ 在 $x_0$ 处支撑集合 $C$。
**定理**：对于任意非空凸集 $C$，其边界上的任意一点 $x_0$，都存在至少一个穿过 $x_0$ 的支撑超平面。

### 3. Farkas引理 (Farkas' Lemma)
给定矩阵 $A \in \mathbb{R}^{m \times n}$ 和向量 $b \in \mathbb{R}^m$。以下两个断言（系统）**有且仅有一个**成立：
- **系统 1**：存在 $x \in \mathbb{R}^n$ 使得 $Ax = b$ 且 $x \succeq 0$。
- **系统 2**：存在 $y \in \mathbb{R}^m$ 使得 $A^T y \succeq 0$ 且 $b^T y < 0$。

*(注：系统1表示 $b$ 在 $A$ 的列向量生成的凸锥内；系统2表示可以找到一个分离超平面法向量 $y$，使得 $A$ 的列都在它的一侧，而 $b$ 在另一侧。)*

### 3. 符号说明表
| 符号 | 含义 |
| :--- | :--- |
| $C, D$ | 通常表示欧氏空间中的凸集 |
| $a, y$ | 超平面的法向量（对偶变量的几何对应） |
| $x \succeq 0$ | 向量的每个分量都不小于0 |

## 6. 推导思路和思想来源
- **分离超平面定理的证明（闭凸集情况）**：
  1. 假设 $C$ 是闭凸集，$x_0 \notin C$。我们需要找点和集的投影。
  2. 由于 $C$ 是闭的，必定在 $C$ 中存在一点 $y_0$ 离 $x_0$ 最近（投影定理，可通过连续函数极值证明）。
  3. 考虑法向量 $a = y_0 - x_0$。通过凸集的性质可以证明，对于 $C$ 中的任意 $x$，与 $a$ 的内积都不会往 $x_0$ 的方向倾斜（即角度大于等于90度）。
  4. 由此得出 $a^T x \ge a^T y_0 > a^T x_0$，这就构造出了严格分离超平面！
- **Farkas 引理的思想来源**：
  本质上是上述分离超平面的特例。令 $C = \{ Ax \mid x \succeq 0 \}$，这是一个闭凸锥。
  如果系统1不成立，说明 $b \notin C$。
  那么必然存在一个严格分离超平面将 $b$ 和 $C$ 隔开：存在 $y$ 使得对所有 $z \in C$，有 $y^T z \ge 0 > y^T b$。
  因为 $C$ 中元素是 $Ax$，所以 $y^T (Ax) \ge 0 \implies (A^T y)^T x \ge 0$。要对所有 $x \ge 0$ 成立，必须要求 $A^T y \ge 0$。同时 $y^T b < 0$。这就是系统2！

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础 Farkas 引理手工验证
**问题**：考虑 $A = \begin{bmatrix} 1 \\ 1 \end{bmatrix}$，检查 $b = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$ 是否在 $A$ 的锥中。
**分析**：
系统 1：是否存在 $x \ge 0$ 使得 $\begin{bmatrix} 1 \\ 1 \end{bmatrix} x = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$？显然无解，因为 $x=1$ 和 $x=2$ 矛盾。
既然系统 1 无解，Farkas 引理说系统 2 必有解。
系统 2：是否存在 $y = \begin{bmatrix} y_1 \\ y_2 \end{bmatrix}$，使得 $y_1 + y_2 \ge 0$ 且 $y_1 + 2y_2 < 0$？
我们试着找找看。比如令 $y_1 = 1, y_2 = -0.8$。
则 $1 - 0.8 = 0.2 \ge 0$，而 $1 - 1.6 = -0.6 < 0$。完全成立！
$y = [1, -0.8]^T$ 就是“证据”，证明系统 1 无解。

### 例子 2：从 Farkas 引理看 LP 对偶性
**原问题**： $\min c^T x$ s.t. $Ax=b, x \ge 0$
**对偶问题**： $\max b^T y$ s.t. $A^T y \le c$
弱对偶性说 $b^T y \le c^T x$。
如果原问题最优值有限（假设为 $p^\star$），我们要找 KKT 点。事实上， Farkas 引理可以直接被用来推导出如果原问题有最优解，对偶问题必有相同的最优解（强对偶）。这是因为“不存在一个能比 $p^\star$ 更小且满足约束的 $x$” 这个陈述，本身就是一个无解的线性系统。对其应用 Farkas 引理，产生的证据 $y$ 恰好就构造了对偶问题的最优解！

### 例子 3：代码演示分离超平面（软/硬间隔 SVM 雏形）
```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import linprog

# 用 Farkas 的另一种变形（严格分离）来找两个不相交凸包的分离平面
# 设有两个点集，我们希望通过线性规划找到分离它们的超平面 w^Tx + b = 0
np.random.seed(0)
X1 = np.random.randn(20, 2) + np.array([2, 2])
X2 = np.random.randn(20, 2) + np.array([-2, -2])

# 我们要找 w=[w1, w2], b 使得:
# w^T x_i + b >= 1 对 X1
# w^T x_i + b <= -1 对 X2
# 我们尝试用线性规划找到可行解，不考虑最大化间隔（只看是否能分离）
# 变量顺序 [w1, w2, b]
# 不等式转换为 <= 0 形式:
# -x_i1 w1 - x_i2 w2 - b <= -1  (for X1)
# x_i1 w1 + x_i2 w2 + b <= -1   (for X2)

m1 = X1.shape[0]
m2 = X2.shape[0]
A_ineq = np.vstack([-np.hstack([X1, np.ones((m1, 1))]),
                    np.hstack([X2, np.ones((m2, 1))])])
b_ineq = -np.ones(m1 + m2)

# 目标函数没所谓，设为 0
c = np.zeros(3)

# 求解（变量无界限制）
res = linprog(c, A_ub=A_ineq, b_ub=b_ineq, bounds=(None, None))

print("是否成功找到分离超平面:", res.success)
if res.success:
    w1, w2, b_val = res.x
    print(f"超平面方程: {w1:.2f}*x + {w2:.2f}*y + {b_val:.2f} = 0")
```

## 8. 常见误区和易混概念
### 误区 1：只要是不相交的两个集合就能严格分离
**纠正**：必须要求是**凸集**，并且至少一个是闭集且另一个是紧集（有界闭集），才能保证**严格**分离。如果两个集合是不相交的闭凸集，但不紧致（比如两条平行的抛物线向同一个方向无穷延伸且无限逼近），它们可能只能弱分离而不能严格分离！
### 误区 2：Farkas 引理只适用于非负约束
**纠正**：Farkas 引理有许多不同的变体定理（如 Gordan 定理, Stiemke 定理等），分别对应于严格不等号、无非负约束的情况等。它们统称为择一定理（Theorems of Alternatives）。
### 概念对比表

| 定理 | 几何图像 | 代数对应 | 应用 |
| :--- | :--- | :--- | :--- |
| 分离超平面定理 | 两个不相交凸集被平面切开 | 一般凸优化中的 Hahn-Banach 形式 | 证明强对偶性（Slater） |
| Farkas 引理 | 向量不在闭凸锥中则被超平面隔开 | 矩阵与不等式系统的择一定理 | LP 强对偶、KKT乘子存在 |

## 11. 自测题：5 道

> [!question]- 题目 1：概念辨析
> 以下关于分离超平面的说法正确的是：
> A. 任何两个不相交的集合都可以被一个超平面分离。
> B. 任何两个不相交的凸集都可以被一个超平面严格分离。
> C. 两个不相交的非空凸集必然存在一个超平面将它们分离（可以是弱分离）。
> **解答**：
> 选 C。A错误，非凸集（例如环形和环形中心的球）无法分离。B错误，要求闭和紧才能确保“严格”分离，例如 $\{(x,y) \mid x>0, y \ge 1/x\}$ 和 $x$轴，它们不相交但只能弱分离（超平面为 $y=0$）。

> [!question]- 题目 2：Farkas引理系统配对
> 给定 Farkas 引理的变体：证明不可能同时存在 $x$ 使得 $Ax < 0$ 且存在非零 $y \ge 0$ 使得 $A^T y = 0$。这个定理通常叫什么？它说明了什么几何事实？
> **解答**：
> 这是 **Gordan 定理**（也是择一定理的一种）。
> 几何事实：如果在行向量构成的一组法向量方向上能找到一个完全指向内部的严格方向（$Ax<0$），那么原点就不能被这些行向量的非负非零组合表示出来。这意味着行向量们并没有把所有方向都“封死”。

> [!question]- 题目 3：支撑超平面的性质
> 对于函数 $f(x)=|x|$ 在 $x=0$ 处对应的图像（一个上方的锥体），其下方的支撑超平面的斜率范围是多少？这和什么概念有关？
> **解答**：
> 函数图像是 $y = |x|$。在 $(0,0)$ 点支撑它的直线 $y = kx$ 必须满足 $kx \le |x|$ 对所有 $x$ 成立。
> 因此 $-1 \le k \le 1$。
> 这里的集合 $[-1, 1]$ 恰恰就是绝对值函数在 $x=0$ 处的**次梯度（Subgradient）**集合！这揭示了次梯度的几何本质就是支撑超平面的斜率。

> [!question]- 题目 4：Farkas引理的代数验证
> 对于 $A = [1, -1]$，$b = 2$。应用 Farkas 引理。哪个系统有解？请给出解。
> **解答**：
> 系统 1：$x_1 - x_2 = 2, x_1, x_2 \ge 0$。显然有解，如 $x = [2, 0]^T$。
> 系统 2：要求 $y$ 使得 $A^Ty \ge 0 \implies y \ge 0$ 且 $-y \ge 0 \implies y=0$。同时要求 $b^Ty = 2y < 0$。由于 $y=0$ 无法满足 $2y < 0$，系统 2 无解。
> 验证了有且仅有一个系统有解。

> [!question]- 题目 5：投影定理的要点
> 在推导点与闭凸集的严格分离时，第一步是找到集合中距离点最近的投影。如果集合不是闭的（比如开圆盘），这一步会出什么问题？
> **解答**：
> 如果集合不是闭的（例如内部不包含边界），当给定的点在边界上或者非常靠近边界时，可能不存在“距离最小”的那一个极限点，即下确界无法取到。这就无法构造出那个确定的法向量（$y_0 - x_0$），导致传统几何证明手段失效。这也是为什么严格分离强烈依赖闭集（和紧集）性质。
