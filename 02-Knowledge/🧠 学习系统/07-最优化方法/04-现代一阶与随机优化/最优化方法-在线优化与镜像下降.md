# 最优化方法-在线优化与镜像下降


## §02 镜像下降 (Mirror Descent) 与 Bregman 散度

欧氏梯度的局限在于隐式假定了参数空间使用 $L_2$ 范数。当可行域为概率单纯形 $\Delta_d = \{x \ge 0 \mid \sum x_i = 1\}$ 时，$L_2$ 范数的直径是 $\mathcal{O}(1)$，但梯度在 $L_\infty$ 范数下可能高达 $\mathcal{O}(d)$。

### 1. 镜像映射与 Bregman 散度定义：
设 $\psi(x)$ 为强凸镜面函数（Mirror Map），其定义的 Bregman 散度为：
\[
D_\psi(x, y) = \psi(x) - \psi(y) - \langle \nabla \psi(y), x - y \rangle
\]

### 2. 镜像下降迭代法则：
1. **对偶空间梯度映射**：$\nabla \psi(y_{t+1}) = \nabla \psi(x_t) - \eta g_t$；
2. **原空间 Bregman 投影**：$x_{t+1} = \arg\min_{x \in \mathcal{K}} D_\psi(x, y_{t+1})$。

当取负熵函数 $\psi(x) = \sum x_i \log x_i$ 时，镜像下降退化为著名的**熵镜像下降 / 指数梯度算法（Exponentiated Gradient Algorithm）**，其显式更新为：
\[
x_{t+1, i} \propto x_{t, i} \exp(-\eta g_{t, i})
\]
其 Regret 依赖仅为 $\mathcal{O}(\sqrt{T \log d})$，对维度 $d$ 是**对数级依附**！

## §03 Python 代码实现 (Entropic Mirror Descent)

```python
import numpy as np

def entropic_mirror_descent_simplex(loss_grads_func, dim, T=500, eta=None):
    """在单纯形上运行熵镜像下降 (Exponentiated Gradient)"""
    if eta is None:
        eta = np.sqrt(2 * np.log(dim) / T)
        
    x = np.ones(dim) / dim # 初始为均匀分布
    x_hist = [x.copy()]
    
    for t in range(T):
        g_t = loss_grads_func(x, t) # 获得在线梯度
        # 熵镜像更新：乘性权重更新
        x_next = x * np.exp(-eta * g_t)
        x = x_next / np.sum(x_next) # 归一化投影到单纯形
        x_hist.append(x.copy())
        
    return np.array(x_hist)
```

## 🎯 知识自测与主动回忆

> [!question]- 1. 为什么在概率单纯形上，熵镜像下降（Entropic Mirror Descent）显著优于标准投影梯度下降（PGD）？
> **答案**：标准 PGD 依赖欧几里得几何，Regret 维度依附度为 $\mathcal{O}(\sqrt{d T})$；而熵镜像下降利用负熵镜面函数，将投影转化为乘性更新，Regret 对维度的依附降至 $\mathcal{O}(\sqrt{T \log d})$，在极高维稀疏特征/博弈求解中极具优势。

> [!question]- 2. 在线凸优化 (OCO) 中 Regret 的严格数学定义是什么？
> **答案**：$\text{Regret}_T = \sum_{t=1}^T f_t(x_t) - \min_{x^* \in \mathcal{K}} \sum_{t=1}^T f_t(x^*)$。它衡量在线算法的历史累计损失与全局最佳固定策略 $x^*$ 的累计损失之间的差值。

> [!question]- 3. Bregman 散度 $D_\psi(x, y)$ 的几何物理意义是什么？
> **答案**：$D_\psi(x, y)$ 表示凸函数 $\psi$ 在 $x$ 点的值与在 $y$ 点处一阶泰勒展开近似值之间的残差。它推广了欧氏距离（当 $\psi(x) = \frac{1}{2}\|x\|^2$ 时 $D_\psi(x,y) = \frac{1}{2}\|x-y\|^2$）和 KL 散度（当 $\psi(x)$ 为负熵时）。

> [!question]- 4. 镜像下降如何利用对偶空间（Dual Space）避开复杂的空间几何束缚？
> **答案**：镜像下降首先通过梯度 $\nabla \psi$ 将原空间决策点映射到对偶空间 $\nabla \psi(x_t)$，在对偶空间中简单执行无约束梯度步更新 $\nabla \psi(y_{t+1}) = \nabla \psi(x_t) - \eta g_t$，最后通过 Bregman 投影将拉回原空间可行域 $\mathcal{K}$。

> [!question]- 5. 什么时候选择使用在线凸优化框架而非离线最优化框架？
> **答案**：当数据流连续到达、数据量巨大无法存入内存、环境随时间非平稳变化（如股票交易、广告推荐点击率预测），或面对对抗性博弈场景时，必须使用 OCO 框架。
