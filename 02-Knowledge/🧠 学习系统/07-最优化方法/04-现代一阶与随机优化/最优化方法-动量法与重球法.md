# 最优化方法 - 动量法与重球法

> **核心地位**：动量法（Momentum）是解决标准梯度下降在病态条件（Ill-conditioned）曲面上振荡剧烈、收敛极慢问题的物理启发式方法。Polyak 重球法与 Nesterov 加速梯度（NAG）构建了现代深度学习自适应优化算法（如 Adam）的动量基石。

---

## §01 问题动机与苏格拉底式引入

> **🤔 苏格拉底与学习者的对话**：
> - **学习者**：“梯度下降方向永远是局部最陡下降方向，为什么在病态曲面（如狭长山谷）上会表现得极差？”
> - **苏格拉底**：“设山谷方程为 \(f(x_1, x_2) = \frac{1}{2} x_1^2 + 50 x_2^2\)。当你在陡峭的山壁 \(x_2 = 10\) 处，梯度 \(\nabla f = [x_1, 100 x_2]^T\) 的主要分量指向哪里？”
> - **学习者**：“指向垂直于山谷底部的纵向方向（跨度方向），而沿着山谷底部 \(x_1\) 方向的分量非常小！”
> - **苏格拉底**：“如果你每次更新都顺着梯度走，会发生什么？如何利用‘历史更新方向’来抵消山壁间的无意义震荡？”
> - **学习者**：“山壁两边的纵向梯度正负交替，如果把历史梯度累加起来，纵向正负抵消，横向同向累积，就能顺着山谷快速滚下去！这就是动量物理直觉。”

**物理直觉（重球滚落）**：
想象一个重球沿山谷滚下。由于重力势能转化为动能，球不仅受到当前位置斜率（当前梯度）的推力，还保留了之前滚动的惯性（历史速度）。
- **峡谷跨度方向**：正负交替的梯度通过历史累加互相抵消，抑制振荡；
- **峡谷底部方向**：方向一致的梯度不断累积，加速沿极小值方向前进。

## §02 正式定义与数学表达

### 1. Polyak 重球法 (Polyak Heavy-Ball Method)

对于无约束优化问题 \(\min_{x \in \mathbb{R}^d} f(x)\)，Polyak (1964) 提出的重球法迭代格式为：

\[
v_{t+1} = \beta v_t + \alpha \nabla f(x_t)
\]
\[
x_{t+1} = x_t - v_{t+1} = x_t - \alpha \nabla f(x_t) + \beta (x_t - x_{t-1})
\]

其中：
- \(\alpha > 0\) 为学习率（Step size）；
- \(\beta \in [0, 1)\) 为动量系数（Momentum coefficient）；
- \(v_t\) 为第 \(t\) 步的速度向量（惯性项）。

### 2. Nesterov 加速梯度 (NAG)

Nesterov (1983) 改进了重球法，提出了“先展望后修正”的前瞻（Look-ahead）机制：

\[
v_{t+1} = \beta v_t + \alpha \nabla f(x_t - \beta v_t)
\]
\[
x_{t+1} = x_t - v_{t+1}
\]

NAG 的核心突破在于：计算梯度的位置不是当前点 \(x_t\)，而是**根据上一时刻速度预估的前瞻点** \(x_t - \beta v_t\)。若前瞻点方向偏差，当前梯度能快速修正速度，防止重球冲过极小点（Overshooting）。

## §03 收敛性推导与谱半径分析 (二次型硬核推导)

考虑二次型 \(f(x) = \frac{1}{2} x^T A x\)，其中 \(\mu I \preceq A \preceq L I\)，条件数 \(\kappa = L/\mu\)。重球法更新方程为：

\[
x_{t+1} - (1+\beta) x_t + \beta x_{t-1} + \alpha A x_t = 0
\]

写成状态转移矩阵形式 \(\begin{bmatrix} x_{t+1} \\ x_t \end{bmatrix} = T \begin{bmatrix} x_t \\ x_{t-1} \end{bmatrix}\)，其中：

\[
T = \begin{bmatrix} (1+\beta)I - \alpha A & -\beta I \\ I & 0 \end{bmatrix}
\]

对矩阵 \(A\) 的任意特征值 \(a \in [\mu, L]\)，标量特征方程为：

\[
\lambda^2 - (1 + \beta - \alpha a) \lambda + \beta = 0
\]

当根为共轭复根时（判别式 \(\Delta < 0\)），根的模长为 \(|\lambda| = \sqrt{\beta}\)。
通过选择最佳参数：
\[
\alpha^* = \frac{4}{(\sqrt{L} + \sqrt{\mu})^2}, \quad \beta^* = \left( \frac{\sqrt{L} - \sqrt{\mu}}{\sqrt{L} + \sqrt{\mu}} \right)^2 = \left( \frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1} \right)^2
\]

所有特征值的最大模长（谱半径）为：

\[
\rho(T) = \sqrt{\beta^*} = \frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}
\]

| 算法 | 收敛速率 (Condition Number \(\kappa = L/\mu\)) | 达到 \(\epsilon\)-精度所需迭代次数 |
| :--- | :--- | :--- |
| **标准梯度下降 (GD)** | \(\mathcal{O}\left(\left(\frac{\kappa-1}{\kappa+1}\right)^k\right)\) | \(\mathcal{O}\left(\kappa \log \frac{1}{\epsilon}\right)\) |
| **Polyak 重球法 (Heavy-Ball)** | \(\mathcal{O}\left(\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k\right)\) | \(\mathcal{O}\left(\sqrt{\kappa} \log \frac{1}{\epsilon}\right)\) |
| **Nesterov 加速梯度 (NAG)** | \(\mathcal{O}\left(\left(1 - \frac{1}{\sqrt{\kappa}}\right)^k\right)\) (最优一阶下界) | \(\mathcal{O}\left(\sqrt{\kappa} \log \frac{1}{\epsilon}\right)\) |

## §04 NumPy 算法实现与 Python 代码

```python
import numpy as np

def heavy_ball_momentum(grad_fn, x0, alpha=0.01, beta=0.9, num_iters=100):
    """Polyak 重球法实现"""
    x = np.array(x0, dtype=np.float64)
    v = np.zeros_like(x)
    history = [x.copy()]
    
    for _ in range(num_iters):
        g = grad_fn(x)
        v = beta * v + alpha * g
        x = x - v
        history.append(x.copy())
    return x, np.array(history)

def nesterov_momentum(grad_fn, x0, alpha=0.01, beta=0.9, num_iters=100):
    """Nesterov 加速梯度 (NAG) 实现"""
    x = np.array(x0, dtype=np.float64)
    v = np.zeros_like(x)
    history = [x.copy()]
    
    for _ in range(num_iters):
        # 在前瞻点计算梯度
        x_ahead = x - beta * v
        g = grad_fn(x_ahead)
        v = beta * v + alpha * g
        x = x - v
        history.append(x.copy())
    return x, np.array(history)

# 二维病态二次型测试 f(x_1, x_2) = 0.5 * x_1^2 + 10 * x_2^2
if __name__ == "__main__":
    grad_f = lambda x: np.array([x[0], 20.0 * x[1]])
    x0 = [10.0, 10.0]
    
    x_hb, _ = heavy_ball_momentum(grad_f, x0, alpha=0.08, beta=0.8, num_iters=50)
    x_nag, _ = nesterov_momentum(grad_f, x0, alpha=0.08, beta=0.8, num_iters=50)
    
    print(f"Heavy-Ball 50步结果: {x_hb}")
    print(f"NAG 50步结果: {x_nag}")
```

## §05 常见误区与工程陷阱

1. **混淆重球法与 NAG 的梯度计算点**：重球法梯度计算在现存点 \(\nabla f(x_t)\)，而 NAG 计算在预测未来点 \(\nabla f(x_t - \beta v_t)\)。
2. **动量系数 \(\beta\) 设置过高**：若 \(\beta \to 1.0\)，阻尼过小导致算法在极小值周围剧烈震荡甚至发散。

## 🎯 知识自测与主动回忆

> [!question]- 1. 请写出 Polyak 重球法与 Nesterov 加速梯度的更新公式，并说明前瞻点 $\nabla f(x_t - \beta v_t)$ 的物理含义。
> **答案**：重球法 $v_{t+1} = \beta v_t + \alpha \nabla f(x_t)$，$x_{t+1} = x_t - v_{t+1}$。NAG 为 $v_{t+1} = \beta v_t + \alpha \nabla f(x_t - \beta v_t)$。前瞻点利用先前的动量估算“下一步可能落到的位置”，并在此提前计算梯度；若前瞻位置斜率变陡，梯度能提前制动，防止冲过极小值。

> [!question]- 2. 对于条件数 $\kappa = 100$ 的强凸二次问题，GD 与 NAG 达到相同精度所需迭代步数比例约为多少？
> **答案**：GD 所需步数为 $\mathcal{O}(\kappa) = 100$ 阶；NAG 所需步数为 $\mathcal{O}(\sqrt{\kappa}) = 10$ 阶。比例约为 10:1，NAG 速度提升约一个数量级。

> [!question]- 3. 在二次型求解中，为什么重球法的收敛速率能够从 $\frac{\kappa-1}{\kappa+1}$ 提升到 $\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}$？
> **答案**：因为重球法引入二阶递推，形成了 $2 \times 2$ 分块转移矩阵。在最佳参数下，转移矩阵的特征根对变为复共轭对，其模长（谱半径）等于 $\sqrt{\beta^*}$，从而将对 $\kappa$ 的线性依赖降低为平方根依赖。

> [!question]- 4. 动量参数 $\beta=0$ 时，重球法退化为什么算法？
> **答案**：当 $\beta=0$ 时，惯性项消失，$v_{t+1} = \alpha \nabla f(x_t)$，算法退化为标准固定步长梯度下降法 (Gradient Descent)。

> [!question]- 5. 深度学习中 PyTorch 实现的 SGD with Momentum 与经典 Polyak 重球法公式有何细微语法差异？
> **答案**：PyTorch 中的动量公式通常为 $v_{t+1} = \beta v_t + \nabla f(x_t)$，$x_{t+1} = x_t - \alpha v_{t+1}$，学习率 $\alpha$ 被乘在整个动量更新量 $v_{t+1}$ 外侧，本质上等价于对步长做了常数缩放。

Q: Polyak 重球法 (Heavy-Ball) 与 Nesterov 加速梯度 (NAG) 的核心区别是什么？
A: 1. **重球法**：在当前位置 $x_t$ 计算梯度，$v_{t+1} = \beta v_t + \alpha \nabla f(x_t)$。
2. **NAG**：在速度估计的前瞻点 $x_t - \beta v_t$ 计算梯度，$v_{t+1} = \beta v_t + \alpha \nabla f(x_t - \beta v_t)$。前瞻机制能有效抑制冲过极小点的现象。
