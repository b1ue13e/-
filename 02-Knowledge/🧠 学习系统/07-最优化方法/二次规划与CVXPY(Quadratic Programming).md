# 二次规划与CVXPY(Quadratic Programming)

---

## 0. 先判断它值不值得深挖

- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：二次规划（QP）是最简单但极其强大的非线性优化问题。在量化金融（投资组合优化）和机器学习（支持向量机）中，它是最核心的数学模型。而 CVXPY 则是用 Python 求解此类问题的标准工业界工具。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 线性规划（LP）很好解，但它的目标函数只能是直线的。现实中很多成本或风险是二次的（比如方差、平方误差）。如果在约束是线性的前提下，目标函数变成了一个开口向上的“碗”（二次凸函数），这就是二次规划。我们需要一种标准语言把它写出来，并扔给求解器。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是从线性优化跨越到非线性凸优化的第一步。
- **实际应用场景**：
  1. **金融**：马科维茨模型，目标是最小化组合方差 $w^T \Sigma w$（二次项），约束是预期收益达标和权重和为1（线性约束）。
  2. **机器学习**：硬间隔 SVM，目标是最小化 $\|w\|^2$（二次项），约束是所有样本分类正确（线性约束）。
- **高频题型/任务**：将实际业务问题抽象成标准的矩阵形式 $\frac{1}{2}x^T P x + q^T x$，然后用 CVXPY 编写 5 行代码求解。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **正定矩阵（Positive Definite Matrix）**：矩阵 $P$ 必须是半正定的（$x^T P x \ge 0$），这就保证了那个“二次曲面”是开口向上的（即凸函数），保证了局部最优就是全局最优。

---

## 4. 用直觉语言解释它

> «“这东西其实就像在一个由几面平直的墙围起来的院子里，找那个最低的坑。”»

- **直觉类比/几何图像**：线性约束就像是在地上画了几条直线，围成一个多边形的院子（可行域）。目标函数是一个抛物面（像个大碗）。你要找的，就是这个院子内部（或者院子的边界上），高度最低的那个点。
- **一句话直觉本质**：在多面体（线性约束）上寻找二次型（凸二次函数）的极小值。

---

## 5. 正式定义、核心公式、符号解释

### 1. 标准数学定义
$$
\begin{aligned}
\min_x \quad & \frac{1}{2} x^T P x + q^T x \\
\text{s.t.} \quad & G x \le h \\
& A x = b
\end{aligned}
$$

### 2. 符号说明表

| 符号 | 含义 | 备注 |
| :--- | :--- | :--- |
| $x$ | 决策变量 | 大小为 $n \times 1$ 的向量 |
| $P$ | 二次项系数矩阵 | 必须是对称半正定矩阵 ($P \succeq 0$) |
| $q$ | 一次项系数 | 大小为 $n \times 1$ |
| $G, h$ | 不等式约束 | 线性约束 |
| $A, b$ | 等式约束 | 线性约束 |

---

## 6. 推导思路和思想来源(CVXPY的DCP规则)

- **最初困难**：哪怕你不小心写成 $x^3$ 或者 $P$ 不是正定的，求解器就没法保证能找到全局最优解了。
- **关键“转念”**：CVXPY 引入了 **DCP (Disciplined Convex Programming，规范凸编程)** 规则。它强制要求你按照一套严格的加法、乘法和函数组合规则来写代码。只要你的代码通过了 DCP 检查，CVXPY 就100%保证它能转成标准 QP 并求出全局最优。

---

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：基础例子（CVXPY 实现马科维茨组合优化）
- **题目**：假设有 3 个资产，预期收益向量为 $\mu$，协方差矩阵为 $\Sigma$。求在无卖空限制（$w \ge 0$）、全额投资（$\sum w_i = 1$）且要求预期收益至少为 $R$ 的情况下，方差最小的权重 $w$。
- **解题思路与关键步骤**：
  ```python
  import cvxpy as cp
  import numpy as np

  # 定义变量
  w = cp.Variable(3)
  
  # 定义目标函数 (最小化方差 w^T Sigma w)
  risk = cp.quad_form(w, Sigma)
  objective = cp.Minimize(risk)
  
  # 定义约束
  constraints = [
      w >= 0,               # 无卖空
      cp.sum(w) == 1,       # 权重和为1
      mu.T @ w >= R         # 收益达标
  ]
  
  # 求解
  prob = cp.Problem(objective, constraints)
  prob.solve()
  print("最优权重:", w.value)
  ```

## 8. 常见误区和易混概念

### 误区 1：在 CVXPY 里直接写 `w.T @ Sigma @ w`
- **为什么错**：虽然数学上是对的，但在 CVXPY 中，直接矩阵乘法可能无法通过 DCP 规则检查（它无法确认这是个凸函数）。
- **正确理解**：必须使用 CVXPY 提供的原子函数 `cp.quad_form(w, Sigma)`，这样 CVXPY 内部能直接识别这是一个二次型，并在确认 `Sigma` 为半正定后，判定为合法的凸函数。
