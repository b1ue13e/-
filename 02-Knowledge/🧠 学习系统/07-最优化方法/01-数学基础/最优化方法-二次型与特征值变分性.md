# 最优化方法-二次型与特征值变分性

## 0. 学习边界
- **类别**：A 类（二次目标与局部分析的线性代数底座）
- **判断理由**：在最优化中，无论是简单的局部泰勒展开，还是最速下降法、牛顿法、凸分析中的强凸性与 Lipschitz 梯度，其代数本质都是在研究对称二次型 $x^T A x$。特征值最大最小值决定了函数碗状形态的陡缓与极小值的唯一性。

---

## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
当把目标函数局部二次逼近为 $f(x) \approx \frac{1}{2} x^T A x + b^T x + c$ 时：
1. **怎么判断这个二次函数有没有唯一的全局极小点？**（正定矩阵 $A \succ 0$）
2. **它的等高线形状是圆、扁平的椭球，还是下鞍点（双曲抛物面）？**（特征值分布）
3. **函数的二次变化率上下界怎么确定？**（瑞利商 Rayleigh Quotient 与最大最小特征值）

---

## 2. 为什么它重要？它有什么用？
- **连接大图景**：正定矩阵（Positive Definite Matrix）是凸二次规划存在唯一解的充要条件。海森矩阵的最大与最小特征值 $\lambda_{\max}, \lambda_{\min}$ 的比值，就是优化理论中最核心的指标——**条件数 $\kappa = \lambda_{\max}/\lambda_{\min}$**，直接决定了梯度下降法的收敛速度！
- **实际应用场景**：
  - **二阶极小值条件**：$\nabla f(x^*) = 0$ 且 $\nabla^2 f(x^*) \succ 0$ 保证局部严格极小点。
  - **PCA 与奇异值分解**：利用瑞利商的最大化获取第一主成分。
  - **强凸性与光滑性**：$m I \preceq \nabla^2 f(x) \preceq L I$ 的代数表达。

## 4. 用直觉语言解释它
> «"二次型是函数的几何地形，特征值是地形主轴的陡峭程度"»
- **直觉类比/几何图像**：
  - 考虑二次函数 $f(x_1, x_2) = a x_1^2 + b x_2^2$：
    - 若 $a > 0, b > 0$，这是一个朝上开口的“标准碗”，底端是唯一的极小值。（正定 $A \succ 0$）
    - 若 $a > 0, b < 0$，沿 $x_1$ 轴向上弯，沿 $x_2$ 轴向下弯，形成马鞍面。（不定 $A$）
    - 若 $a = 100, b = 1$，这是一个极度扁平狭长的“陡峭峡谷”。沿着 $x_2$ 方向极其平缓，沿着 $x_1$ 方向极其陡峭。（条件数 $\kappa = 100$ 大）
- **一句话直觉本质**：特征值就是二次型在正交主轴方向上的二阶曲率大小。

## 5. 正式定义、核心公式、符号解释

### 1. 正定性与半正定性 (PSD) 定义
设 $A \in \mathbf{R}^{n \times n}$ 为实对称矩阵（$A = A^T$）。二次型为 $g(x) = x^T A x$。

- **正定 (Positive Definite, $A \succ 0$)**：
  对所有非零向量 $x \ne 0$，均有 $x^T A x > 0$。等价于 $A$ 的所有特征值 $\lambda_i > 0$。
- **半正定 (Positive Semi-Definite, $A \succeq 0$)**：
  对所有向量 $x$，均有 $x^T A x \ge 0$。等价于 $A$ 的所有特征值 $\lambda_i \ge 0$。

### 2. 瑞利商 (Rayleigh Quotient) 与变分刻画
对非零向量 $x \in \mathbf{R}^n$，瑞利商定义为：
$$ R(A, x) = \frac{x^T A x}{x^T x} $$
根据 Rayleigh-Ritz 定理，对称矩阵 $A$ 的最大与最小特征值满足如下**变分极值**：
$$ \lambda_{\min}(A) = \min_{x \ne 0} \frac{x^T A x}{x^T x} \le \frac{x^T A x}{x^T x} \le \max_{x \ne 0} \frac{x^T A x}{x^T x} = \lambda_{\max}(A) $$
因此对任意 $x$，有不等式包络：
$$ \lambda_{\min}(A) \|x\|_2^2 \le x^T A x \le \lambda_{\max}(A) \|x\|_2^2 $$

### 3. 谱分解 (Spectral Decomposition)
对称矩阵 $A$ 可正交对角化为：
$$ A = Q \Lambda Q^T = \sum_{i=1}^n \lambda_i q_i q_i^T $$
其中 $Q = [q_1, \dots, q_n]$ 为标准正交特征向量矩阵，$\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_n)$。

## 6. 例子：Python 二次型地形与等高线绘制

通过可视化深刻感悟特征值比例与条件数对等高线椭球形态的影响。

```python
import numpy as np
import matplotlib.pyplot as plt

# 构造两种不同条件数的正定矩阵
A_good = np.array(`[[2.0, 0.0], [0.0, 2.0]]`) # 良好的圆碗 (kappa = 1)
A_ill  = np.array(`[[10.0, 0.0], [0.0, 1.0]]`) # 病态狭长峡谷 (kappa = 10)

# 网格采样
x1 = np.linspace(-3, 3, 100)
x2 = np.linspace(-3, 3, 100)
X1, X2 = np.meshgrid(x1, x2)

Z_good = 0.5 * (A_good[0,0]*X1**2 + A_good[1,1]*X2**2)
Z_ill  = 0.5 * (A_ill[0,0]*X1**2 + A_ill[1,1]*X2**2)

fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 好条件的圆碗等高线
axes[0].contour(X1, X2, Z_good, levels=15, cmap='viridis')
axes[0].set_title("W-Well Contour (kappa = 1.0)")
axes[0].set_aspect('equal')
axes[0].grid(True)

# 病态峡谷等高线
axes[1].contour(X1, X2, Z_ill, levels=15, cmap='viridis')
axes[1].set_title("Ill-conditioned Valley (kappa = 10.0)")
axes[1].set_aspect('equal')
axes[1].grid(True)

plt.show()
```

## 7. 常见踩坑与误区
- **误区 1**：认为矩阵所有元素非负就叫正定矩阵。这是完全错误的！正定是指二次型 $x^T A x > 0$（例如 $\begin{bmatrix} 1 & 3 \\ 3 & 1 \end{bmatrix}$ 所有元素都正，但特征值是 $4$ 和 $-2$，属于不定矩阵）。
- **误区 2**：忽视对称性前提。瑞利商与特征值变分界限成立的前提是矩阵 $A$ **必须为对称矩阵**。

## 10. 自测题：5 道
> [!question]- 题目 1：正定矩阵 $A \succ 0$ 的所有特征值满足什么？
> **答案**：全部严格大于 0。等价地，对任意非零 $x$ 有 $x^T A x > 0$。

> [!question]- 题目 2：瑞利商的极值与特征值有何关系？
> **答案**：$\min_{x\ne0}\frac{x^T A x}{x^T x} = \lambda_{\min}(A)$，$\max_{x\ne0}\frac{x^T A x}{x^T x} = \lambda_{\max}(A)$。瑞利商的值域是 $[\lambda_{\min}, \lambda_{\max}]$。

> [!question]- 题目 3：为什么条件数 $\kappa = \lambda_{\max}/\lambda_{\min}$ 决定梯度下降收敛速度？
> **答案**：条件数越大，等高线越狭长（峡谷），最速下降法锯齿越严重，收敛越慢；$\kappa=1$ 时圆碗可一步到中心方向。

> [!question]- 题目 4：矩阵所有元素都为正，是否一定正定？
> **答案**：不一定。正定看的是二次型 $x^T A x > 0$ 而非元素符号。例如 $\begin{bmatrix}1&3\\3&1\end{bmatrix}$ 元素皆正，但特征值为 $4$ 与 $-2$，是不定矩阵。

> [!question]- 题目 5：强凸性与 Hessian 的特征值界限如何对应？
> **答案**：若对所有 $x$ 有 $mI \preceq \nabla^2 f(x) \preceq LI$，则 $f$ 是 $m$-强凸且 $L$-光滑，对应 Hessian 特征值被夹在 $[m, L]$ 之间。

## ⚠️ 常见陷阱与避坑指南

> [!CAUTION]
> 1. **元素非负 ≠ 正定**：务必用二次型或特征值判定，不要看矩阵元素。

Q: 对称矩阵 $A$ 的正定性与其特征值的关系？
A: $A \succ 0 \iff$ 所有特征值 $>0$；$A \succeq 0 \iff$ 所有特征值 $\ge 0$。

Q: 瑞利商 $\frac{x^T A x}{x^T x}$ 的取值范围？
A: 恰好是 $[\lambda_{\min}(A), \lambda_{\max}(A)]$；最小/最大值分别在最小/最大特征向量处取到。
