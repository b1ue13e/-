# 最优化方法-二次型与特征值变分性

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：梯度下降在有些问题上收敛极快、在另一些问题上却锯齿爬行慢如蜗牛。同样的算法，差别只在于**目标函数的二阶地形**。要量化"地形有多狭长"，就需要把二次型 $x^T A x$ 与特征值（曲率主轴）联系起来——这正是本卡的核心：**用特征值的变分刻画（瑞利商）理解矩阵正定性、条件数与收敛速度的代数根源**。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：正定矩阵是凸二次规划唯一解的充要条件；海森矩阵最大/最小特征值之比就是**条件数** $\kappa = \lambda_{\max}/\lambda_{\min}$，它直接决定梯度下降的收敛速度与牛顿法的稳定性。
- **实际应用场景**：
  - 二阶极小值条件：$\nabla f(x^*) = 0$ 且 $\nabla^2 f(x^*) \succ 0$ 保证严格局部极小。
  - 强凸性与光滑性：$m I \preceq \nabla^2 f(x) \preceq L I$ 的代数表达，是凸优化收敛定理的标准假设。
  - PCA：瑞利商最大化给出第一主成分。
- **高频题型/任务**：正定性判定（特征值/主子式/Cholesky）、瑞利商极值证明、条件数计算、用 $\lambda_{\min}\|x\|^2 \le x^T A x \le \lambda_{\max}\|x\|^2$ 做收敛估计。

## 4. 用直觉语言解释它

> «二次型是函数的地形图，特征值是地形主轴的陡峭程度»

- **直觉类比/几何图像**：二次函数 $f(x_1, x_2) = a x_1^2 + b x_2^2$：
  - $a, b > 0$：朝上开口的圆/椭圆碗，底部是唯一极小点（$A \succ 0$）。
  - $a > 0, b < 0$：马鞍面，$x_1$ 方向凹上、$x_2$ 方向凹下（$A$ 不定）。
  - $a = 100, b = 1$：极度狭长的陡峭峡谷（$\kappa = 100$），沿 $x_2$ 平缓、沿 $x_1$ 陡峭。
- **一句话直觉本质**：特征值是二次型在正交主轴方向上的二阶曲率；瑞利商 $\frac{x^T A x}{x^T x}$ 给出"沿任意方向 $x$ 的平均曲率"，其极值恰好是最大/最小特征值。

---

## 5. 正式定义、核心公式、符号解释

### 1. 正定性与半正定性

设 $A \in \mathbb{R}^{n \times n}$ 实对称（$A = A^T$），二次型 $g(x) = x^T A x$：

- **正定**（$A \succ 0$）：$\forall x \ne 0,\ x^T A x > 0$，等价于所有特征值 $\lambda_i > 0$。
- **半正定**（$A \succeq 0$）：$\forall x,\ x^T A x \ge 0$，等价于所有特征值 $\lambda_i \ge 0$。
- **不定**：特征值有正有负，存在鞍点方向的二次型。

### 2. 瑞利商与变分刻画

对 $x \ne 0$，瑞利商 $R(A, x) = \frac{x^T A x}{x^T x}$。由 Rayleigh-Ritz 定理（对称矩阵的变分特征）：

$$ \lambda_{\min}(A) = \min_{x \ne 0} \frac{x^T A x}{x^T x}, \qquad \lambda_{\max}(A) = \max_{x \ne 0} \frac{x^T A x}{x^T x} $$

推论（包络不等式）：

$$ \lambda_{\min}(A)\,\|x\|_2^2 \le x^T A x \le \lambda_{\max}(A)\,\|x\|_2^2, \quad \forall x \in \mathbb{R}^n. $$

### 3. 谱分解

对称矩阵 $A$ 可正交对角化：$A = Q \Lambda Q^T = \sum_{i=1}^n \lambda_i q_i q_i^T$，$Q = [q_1, \dots, q_n]$ 正交、$\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_n)$。

### 4. 条件数

$\kappa(A) = \lambda_{\max}(A)/\lambda_{\min}(A)$（正定矩阵）。$\kappa = 1$ 是圆球，$\kappa$ 越大等高线越狭长。

---

## 6. 推导思路和思想来源

### 为什么瑞利商的极值是特征值？（关键转念）

把约束 $\|x\| = 1$ 下的最优化 $\max_{x} x^T A x$ 写成 Lagrange 乘子形式：

$$ \mathcal{L}(x, \lambda) = x^T A x - \lambda (x^T x - 1), \quad \nabla_x \mathcal{L} = 2Ax - 2\lambda x = 0 \Rightarrow A x = \lambda x. $$

于是极值点必须是 $A$ 的特征向量，Lagrange 乘子 $\lambda$ 就是对应特征值，目标值 $x^T A x = \lambda x^T x = \lambda$。**"最大化二次型"问题自动导出特征值问题**——这就是瑞利商与特征值同构的根源，也是 PCA、谱方法、SDP 松弛共享的代数内核。

### 为什么 $A \succ 0$ 保证唯一极小？

$f(x) = \frac12 x^T A x$（$A \succ 0$）梯度 $\nabla f = Ax$，驻点 $x^* = 0$；$f(x) - f(0) = \frac12 x^T A x \ge \frac12 \lambda_{\min}\|x\|^2 > 0$（$x \ne 0$），故 $0$ 是唯一全局极小点。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：手算瑞利商极值与条件数

$A = \begin{bmatrix} 3 & 1 \\ 1 & 3 \end{bmatrix}$：特征值 $\lambda = 4, 2$，$\kappa = 2$。验证包络：取 $x = (1, 0)^T$，$x^T A x = 3$ 落在 $[2, 4] \cdot \|x\|^2$ 内。最小/最大瑞利商在 $(1,-1)^T$（对应 $\lambda=2$）与 $(1,1)^T$（对应 $\lambda=4$）取到。

### 例子 2：Python 地形可视化

```python
import numpy as np
import matplotlib.pyplot as plt

A_good = np.array([[2.0, 0.0], [0.0, 2.0]])    # kappa = 1, 圆碗
A_ill  = np.array([[10.0, 0.0], [0.0, 1.0]])   # kappa = 10, 狭长峡谷

x1 = np.linspace(-3, 3, 100); x2 = np.linspace(-3, 3, 100)
X1, X2 = np.meshgrid(x1, x2)
Z_good = 0.5 * (A_good[0,0]*X1**2 + A_good[1,1]*X2**2)
Z_ill  = 0.5 * (A_ill[0,0]*X1**2 + A_ill[1,1]*X2**2)

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].contour(X1, X2, Z_good, levels=15, cmap='viridis'); axes[0].set_title("Well-conditioned (kappa=1)")
axes[1].contour(X1, X2, Z_ill, levels=15, cmap='viridis');  axes[1].set_title("Ill-conditioned (kappa=10)")
for ax in axes: ax.set_aspect('equal'); ax.grid(True)
plt.show()
```

### 例子 3：条件数决定梯度下降收敛速率

对 $f(x) = \frac12 x^T A x$（$A \succ 0$）做最速下降，误差按 $\rho = \frac{\kappa - 1}{\kappa + 1}$ 线性收缩。$\kappa = 1$ 时 $\rho = 0$（一步收敛）；$\kappa = 10^6$ 时 $\rho \approx 1 - 2\times10^{-6}$，需要约 $10^6$ 次迭代量级——这解释了为什么病态问题必须用牛顿/预条件。

## 8. 常见误区与相近概念对比

- **误区 1：矩阵所有元素非负 ⇒ 正定。** 错。正定看二次型 $x^T A x > 0$。例：$\begin{bmatrix}1&3\\3&1\end{bmatrix}$ 元素皆正，但特征值为 $4$ 与 $-2$，是不定矩阵。
- **误区 2：忽略对称性前提。** 瑞利商与特征值变分界限只对**对称矩阵**成立；非对称矩阵先取对称部分 $(A+A^T)/2$ 再讨论。
- **误区 3：把顺序主子式 $\ge 0$ 当半正定判据。** 半正定需要**全部**主子式 $\ge 0$；顺序主子式 $\ge 0$ 只是正定的充分判据（Sylvester），对半正定不充分。

| 概念 | 定义 | 判定工具 | 优化中的角色 |
| :--- | :--- | :--- | :--- |
| 正定 $A \succ 0$ | $x^T A x > 0$ | 特征值 >0 / 顺序主子式 >0 / Cholesky | 严格凸、唯一极小 |
| 半正定 $A \succeq 0$ | $x^T A x \ge 0$ | 特征值 ≥0 / 全部主子式 ≥0 | 凸性 |
| 条件数 $\kappa$ | $\lambda_{\max}/\lambda_{\min}$ | 特征值比 | 收敛速率、数值稳定性 |

## 11. 自测题

> [!question]- 1.（定义复述）正定/半正定的定义与等价特征值条件？
> **答案**：$A \succ 0 \iff \forall x \ne 0,\ x^T A x > 0 \iff$ 所有特征值 $> 0$；$A \succeq 0$ 同理放宽为 $\ge 0$。

> [!question]- 2.（推导）证明瑞利商的最大值等于最大特征值。
> **答案**：令 $\|x\|=1$，Lagrange 函数 $\mathcal{L} = x^T A x - \lambda(x^T x - 1)$，驻点满足 $Ax = \lambda x$，故极值点为特征向量、极值为特征值；取最大者即 $\lambda_{\max}$。

> [!question]- 3.（反例）元素全为正但不定矩阵的例子？
> **答案**：$\begin{bmatrix}1&3\\3&1\end{bmatrix}$，特征值 $4$ 与 $-2$，$x=(1,-1)^T$ 时 $x^T A x = -2 < 0$，故不定。

> [!question]- 4.（条件变式）$\kappa = 1$ 与 $\kappa \to \infty$ 时最速下降的收敛性如何变化？
> **答案**：$\kappa=1$ 等高线为圆，一步收敛（$\rho=0$）；$\kappa$ 越大 $\rho = (\kappa-1)/(\kappa+1)$ 越接近 1，收敛越慢（线性但速率因子趋近 1）。

> [!question]- 5.（应用）给定 $A = \mathrm{diag}(10, 1)$，估计最速下降达到 $10^{-6}$ 精度需要的迭代次数量级。
> **答案**：$\kappa = 10$，$\rho = 9/11 \approx 0.818$；需 $k$ 满足 $\rho^k \lesssim 10^{-6}$，即 $k \approx 6/\ln(1/0.818) \approx 30$ 次量级。

Q: 瑞利商 $\frac{x^T A x}{x^T x}$ 的取值范围？极值在哪取到？
A: 恰好是 $[\lambda_{\min}(A), \lambda_{\max}(A)]$；最小值/最大值分别在最小/最大特征向量处取到。证明用 Lagrange 乘子，驻点 $Ax = \lambda x$ 即特征值问题。

---
Q: 条件数 $\kappa$ 如何定义？它如何影响最速下降的收敛速率？
A: $\kappa = \lambda_{\max}/\lambda_{\min}$（正定对称矩阵）。收敛速率因子 $\rho = (\kappa-1)/(\kappa+1)$；$\kappa$ 越大锯齿越严重、收敛越慢，$\kappa=1$ 时一步收敛。
