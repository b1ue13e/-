# 最优化方法-多元梯度与海森矩阵

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：一元函数用 $f'(x)=0$ 找极值很直观，但优化问题中参数是高维向量 $x \in \mathbb{R}^n$（神经网络百万参数、矩阵变量、函数空间），我们面对的是多元标量函数 $f: \mathbb{R}^n \to \mathbb{R}$。这时三个问题必须回答：

1. **朝哪个方向走函数下降最快？**（负梯度方向）
2. **函数在局部是"碗"还是"马鞍"？**（海森矩阵的曲率信息）
3. **怎么用多项式在局部近似复杂多元函数？**（多元二阶泰勒展开）

没有这套工具，梯度下降、牛顿法、凸性判定全都无从谈起。

---

## 2. 为什么它重要？它有什么用？

- **连接大图景**：它是"一维微积分 → 高维优化算法"的桥梁。一阶梯度 $\nabla f(x)$ 决定算法步进**方向**，二阶海森矩阵 $\nabla^2 f(x)$ 刻画**曲率**，决定牛顿类方法的步幅与稳定性。
- **实际应用场景**：
  - 一阶优化：SGD、Adam 用 $\nabla f(x)$ 修正方向（见 [[最优化方法-SGD与随机优化]]）。
  - 二阶优化：牛顿法 $d = -(\nabla^2 f(x))^{-1}\nabla f(x)$ 用海森矩阵一步逼近极小点（见 [[最优化方法-牛顿法]]）。
  - 凸性检验：$\nabla^2 f(x) \succeq 0$ 判定凸函数（见 [[最优化方法-凸集与凸函数]]）。
  - 收敛分析：条件数 $\kappa = \lambda_{\max}/\lambda_{\min}$ 决定梯度下降锯齿程度（见 [[最优化方法-最速下降与收敛分析]]）。

## 4. 用直觉语言解释它

> «梯度是探路的手杖，海森矩阵是脚下地形的弯曲度»

- **直觉类比/几何图像**：蒙眼下山时，梯度像用脚向四周试探后指出的**最陡上坡**方向，其反方向就是下山最快的路；海森矩阵则告诉你山坡是**碗状凹陷**（正定）、**马鞍形**（不定）还是**山脊**（负定）。
- **一句话直觉本质**：梯度是一阶变化率向量，海森矩阵是二阶变化率组成的对称矩阵；一阶决定方向，二阶决定曲率与凸性。

---

## 5. 正式定义、核心公式、符号解释

### 1. 核心定义

设 $f: \mathbb{R}^n \to \mathbb{R}$ 二阶连续可微。

- **梯度向量**：
  $$ \nabla f(x) = \left[ \frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_n} \right]^T \in \mathbb{R}^n $$
- **海森矩阵**：
  $$ \nabla^2 f(x) = \left[ \frac{\partial^2 f}{\partial x_i \partial x_j} \right]_{i,j=1}^n \in \mathbb{R}^{n \times n} $$
  二阶偏导连续时（Clairaut 定理）混合偏导相等，海森矩阵**对称**：$(\nabla^2 f)^T = \nabla^2 f$。

### 2. 核心公式

- **方向导数**：沿单位方向 $v$（$\|v\|_2 = 1$）：$D_v f(x) = \nabla f(x)^T v$。
- **多元二阶泰勒展开**（$x_0$ 附近沿 $d$）：
  $$ f(x_0 + d) = f(x_0) + \nabla f(x_0)^T d + \frac{1}{2} d^T \nabla^2 f(x_0) d + o(\|d\|^2) $$
- **下降方向判据**：$d$ 是下降方向 $\iff \nabla f(x)^T d < 0$（方向导数为负）。

### 3. 常用向量求导表

| 函数 $f(x)$ | 梯度 $\nabla_x f(x)$ | 海森矩阵 $\nabla_x^2 f(x)$ |
| :--- | :--- | :--- |
| $a^T x$ | $a$ | $0$ |
| $x^T A x$（$A$ 对称） | $2Ax$ | $2A$ |
| $x^T A x$（$A$ 一般） | $(A + A^T)x$ | $A + A^T$ |
| $\|x\|_2^2 = x^T x$ | $2x$ | $2I$ |

## 6. 推导思路和思想来源

### 为什么沿负梯度方向下降最快？

沿单位方向 $v$ 的瞬时变化率是方向导数 $D_v f(x) = \nabla f(x)^T v$。由 Cauchy-Schwarz 不等式：

$$ |\nabla f(x)^T v| \le \|\nabla f(x)\|_2 \,\|v\|_2 = \|\nabla f(x)\|_2, $$

等号当且仅当 $v$ 与 $\nabla f(x)$ **平行**时成立。因此：

- $v = \nabla f(x)/\|\nabla f(x)\|$ 时 $D_v f = +\|\nabla f\|$（增长最快）；
- $v = -\nabla f(x)/\|\nabla f(x)\|$ 时 $D_v f = -\|\nabla f\|$（下降最快）。

**关键"转念"**：把"找下降最快的方向"翻译成"最小化方向导数这个线性函数"，线性函数在单位球上的极值由 Cauchy-Schwarz 直接给出，不需要任何梯度以外的信息——这是最速下降法的全部数学依据。

## 7. 例子：基础 → 中等 → 实际应用

### 例子 1：手算梯度与海森矩阵

**题目**：$f(x_1, x_2) = x_1^2 + 3x_1 x_2 + 2x_2^2$，求在 $x = (1, 2)^T$ 的梯度与海森矩阵。

**解答**：$\nabla f = \begin{bmatrix} 2x_1 + 3x_2 \\ 3x_1 + 4x_2 \end{bmatrix}$，在 $(1,2)$ 处 $\nabla f = \begin{bmatrix} 8 \\ 11 \end{bmatrix}$。二阶偏导：$f_{x_1x_1}=2,\ f_{x_1x_2}=3,\ f_{x_2x_2}=4$，故 $\nabla^2 f = \begin{bmatrix} 2 & 3 \\ 3 & 4 \end{bmatrix}$（常数对称阵，$D_1=2>0,\ D_2=8-9=-1<0$，**不定** ⇒ $f$ 非凸，$(1,2)$ 不是极小点）。

### 例子 2：Python 数值梯度校验

解析梯度易手推错，工程上常用双边有限差分校验：

```python
import numpy as np

def f(x):
    return x[0]**2 + 3 * x[0] * x[1] + 2 * x[1]**2

def grad_analytic(x):
    return np.array([2 * x[0] + 3 * x[1], 3 * x[0] + 4 * x[1]])

def grad_numerical(f, x, eps=1e-5):
    grad = np.zeros_like(x)
    for i in range(len(x)):
        xp, xm = x.copy(), x.copy()
        xp[i] += eps
        xm[i] -= eps
        grad[i] = (f(xp) - f(xm)) / (2 * eps)
    return grad

x0 = np.array([1.0, 2.0])
g_ana, g_num = grad_analytic(x0), grad_numerical(f, x0)
rel = np.linalg.norm(g_ana - g_num) / (np.linalg.norm(g_ana) + np.linalg.norm(g_num))
print(f"相对误差: {rel:.2e}")
assert rel < 1e-7, "梯度校验失败"
```

## 8. 常见误区与相近概念对比

### 误区

- **误区 1：混淆求导结果的维度**。标量对向量求导得**向量**（与自变量同维）；向量对向量求导得**雅可比矩阵**。梯度是前者。
- **误区 2：非对称 $A$ 上直接套 $2Ax$**。$\nabla_x(x^T A x)$ 一般结果是 $(A + A^T)x$；只有 $A$ 对称才等于 $2Ax$。二次型只依赖对称部分 $(A+A^T)/2$。
- **误区 3：把"驻点"当"极小点"**。$\nabla f(x^*) = 0$ 只是必要条件；需二阶条件 $\nabla^2 f(x^*) \succeq 0$（凸时充分）或 $\succ 0$（严格局部极小）判定类型。

### 相近概念对比

| 概念 | 一阶信息 | 二阶信息 | 用途 |
| :--- | :--- | :--- | :--- |
| 梯度 $\nabla f$ | 方向导数的梯度 | — | 最速下降方向、KKT 一阶条件 |
| 海森矩阵 $\nabla^2 f$ | — | 曲率张量 | 凸性判定、牛顿步、鞍点识别 |
| 雅可比矩阵 $J$ | 向量值函数的导数 | — | 约束优化、最小二乘线性化 |

## 11. 自测题

> [!question]- 1.（定义复述）梯度向量与海森矩阵的精确定义？海森矩阵何时必对称？
> **答案**：梯度是各偏导组成的列向量；海森矩阵是二阶偏导矩阵。二阶偏导连续时（Clairaut 定理）混合偏导相等，海森矩阵对称。

> [!question]- 2.（推导）用 Cauchy-Schwarz 证明负梯度是最速下降方向，并指出等号条件。
> **答案**：$D_v f = \nabla f^T v \ge -\|\nabla f\|\|v\| = -\|\nabla f\|$，等号当且仅当 $v \propto -\nabla f$；故 $- \nabla f$ 方向下降最快，最大下降速率为 $\|\nabla f\|$。

> [!question]- 3.（反例）$\nabla f(x^*) = 0$ 但 $x^*$ 不是极小点的例子？
> **答案**：$f(x_1, x_2) = x_1^2 - x_2^2$，在 $(0,0)$ 处梯度为零但海森矩阵 $\mathrm{diag}(2, -2)$ 不定，$(0,0)$ 是鞍点。

> [!question]- 4.（条件变式）$x^T A x$ 在 $A$ 非对称时的梯度是什么？为什么二次型只依赖对称部分？
> **答案**：$(A + A^T)x$。因 $x^T A x = x^T \frac{A+A^T}{2} x$（标量与其转置相等），非对称部分在二次型中抵消。

> [!question]- 5.（应用）数值梯度校验用哪种差分？误差量级如何控制？
> **答案**：双边中心差分 $(f(x+\varepsilon e_i) - f(x-\varepsilon e_i))/(2\varepsilon)$，误差 $O(\varepsilon^2)$；$\varepsilon$ 取 $10^{-5}$ 左右可在截断误差与舍入误差间平衡，解析/数值相对误差应 < $10^{-6}$。
