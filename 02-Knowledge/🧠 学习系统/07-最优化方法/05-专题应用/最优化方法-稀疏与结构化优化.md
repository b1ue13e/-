# 最优化方法-稀疏与结构化优化

## §01 为什么学？它解决什么问题？

**动机**：高维统计、压缩感知、特征选择、深度网络剪枝等场景的核心诉求是**从 $n \ll p$ 的高维数据中找到少数真正重要的变量**。直接做"选择 $k$ 个变量"是组合爆炸的 NP-hard 问题；L1 范数（Lasso）作为它的凸松弛，把 NP-hard 问题变成可高效求解的凸优化，并天然产生稀疏解。

**结构化扩展**：单纯 L1 把每个变量**独立**地压向零，忽略了变量之间的**组结构/顺序结构**（如：一组基因同时表达、相邻像素平滑、树形特征层级）。**结构化稀疏（Structured Sparsity）** 通过组 L1（Group Lasso）、融合 Lasso（Fused Lasso）、稀疏组 Lasso（Sparse Group Lasso）等正则项编码先验结构，得到比 L1 更合理的解。

**本卡回答**：L1 为什么产生稀疏解（几何解释）？近端算子如何高效求解 Lasso？Group Lasso 与 Fused Lasso 的模型与求解？稀疏优化在压缩感知/特征选择中的标准设置（RIP、受限特征值条件）？

**学完能做什么**：能画出 L1 与 L2 约束下稀疏性的几何直觉；能用近端梯度/FISTA/ADMM 求解 Lasso 与 Group Lasso；能说明 Fused Lasso 的 TV 正则如何编码顺序结构；能描述压缩感知中 RIP 条件的作用。

## §02 L1 稀疏性的几何直觉

考虑 $\min_x \frac{1}{2}\|Ax - b\|_2^2 + \lambda \|x\|_1$，等价的约束视角：$\min \frac{1}{2}\|Ax-b\|_2^2$ s.t. $\|x\|_1 \le t$。

**为什么 L1 产生稀疏解？** 等高线（数据拟合项）第一次触到 $\|x\|_1 \le t$ 的**菱形边界**时，接触点几乎总是落在**坐标轴上**（因为菱形在轴向上有尖角）。而 L2 约束是圆球，接触点一般在球面光滑处，坐标多为非零。维数越高，L1 触碰坐标轴的概率越大。

> 严格说：只要数据拟合项在最优点处的负梯度方向不与菱形的某个面完全正交，最优解就落在顶点（坐标轴交点）上——这就是稀疏性的来源。正则化参数 $\lambda$ 越大，菱形越小，稀疏度越高。

## §03 近端算子：Lasso 的高效求解核心

Lasso 目标 $F(x) = g(x) + \lambda\|x\|_1$（$g$ 光滑、$\nabla g$ 为 $L$-Lipschitz）是典型的**复合优化**问题，近端梯度法（详见 [[最优化方法-近端梯度与FISTA]]）每步迭代：

$$ x_{k+1} = \text{prox}_{\frac{\lambda}{L}\|\cdot\|_1} \left( x_k - \frac{1}{L} \nabla g(x_k) \right) $$

L1 的近端算子是**软阈值（Soft-thresholding）**，闭式可解：

$$ [\text{prox}_{t\|\cdot\|_1}(z)]_i = \text{sign}(z_i) \cdot \max(0, |z_i| - t) = \begin{cases} z_i - t, & z_i > t \\ 0, & |z_i| \le t \\ z_i + t, & z_i < -t \end{cases} $$

**几何直觉**：软阈值把 $z_i$ 向零压缩 $t$，并把绝对值小于 $t$ 的坐标**直接置零**——这正是稀疏性产生的机制。FISTA 加速后收敛率 $\mathcal{O}(1/k^2)$。

---

## §04 Group Lasso：组结构稀疏

当变量天然分组（如基因通路、多通道信号、词嵌入维度），我们希望**整组选入或整组丢弃**，而不是组内零星保留。Group Lasso：

$$ \min_x \; \frac{1}{2}\|Ax - b\|_2^2 + \lambda \sum_{g \in \mathcal{G}} \|x_g\|_2 $$

其中 $x_g$ 是第 $g$ 组变量，$\|x_g\|_2$ 是组的欧氏范数。近端算子按组处理：

$$ [\text{prox}_{t\|\cdot\|_{2,1}}(z)]_g = \begin{cases} \left(1 - \frac{t}{\|z_g\|_2}\right) z_g, & \|z_g\|_2 > t \\ 0, & \|z_g\|_2 \le t \end{cases} $$

即**组级软阈值**：整组范数小于阈值则整组置零，否则整组按比例收缩。对比 L1（坐标级置零）与 Group Lasso（组级置零）正是"稀疏与结构化"的分界线。

**Sparse Group Lasso**：$\lambda_1 \|x\|_1 + \lambda_2 \sum_g \|x_g\|_2$，同时允许组内稀疏与组间稀疏，近端算子为"先组阈值、再坐标阈值"两步组合。

---

## §05 Fused Lasso 与 TV 正则：顺序结构

当特征有顺序（时间序列、基因组位置、图像像素），我们希望相邻系数接近，Fused Lasso：

$$ \min_x \; \frac{1}{2}\|Ax - b\|_2^2 + \lambda_1 \|x\|_1 + \lambda_2 \sum_{i=2}^{p} |x_i - x_{i-1}| $$

第二项是 **TV（Total Variation）惩罚**，编码"相邻平滑"。1D 信号去噪（1D Fused Lasso / TV denoising）可用**近端算子 + 池化（taut string）算法**或 ADMM 高效求解；图像去噪对应 2D TV，常用 ADMM 分离 $x$ 与差分项 $Dx$。

**直觉**：TV 正则产生**分段常数**解（阶梯状），既保留突变（边缘/断层）又平滑噪声——这是与 L1（点稀疏）和 Group Lasso（组稀疏）都不同的第三类结构先验。

## §06 Python 实现：FISTA 求解 Lasso

```python
import numpy as np

def soft_threshold(z, t):
    return np.sign(z) * np.maximum(np.abs(z) - t, 0)

def fista_lasso(A, b, lam, L=None, max_iter=2000, tol=1e-8):
    """FISTA 求解 min 0.5||Ax-b||² + λ||x||₁"""
    m, n = A.shape
    if L is None:
        L = np.linalg.norm(A, 2) ** 2  # 利普希茨常数上界
    x = np.zeros(n)
    y = x.copy()
    t_old = 1.0
    for k in range(max_iter):
        grad = A.T @ (A @ y - b)
        x_new = soft_threshold(y - grad / L, lam / L)
        t_new = (1 + np.sqrt(1 + 4 * t_old ** 2)) / 2
        y = x_new + ((t_old - 1) / t_new) * (x_new - x)
        if np.linalg.norm(x_new - x) < tol:
            break
        x, t_old = x_new, t_new
    return x

# 测试：稀疏信号恢复
rng = np.random.default_rng(0)
n, m = 200, 60
x_true = np.zeros(n)
x_true[rng.choice(n, 8, replace=False)] = rng.standard_normal(8)
A = rng.standard_normal((m, n))
b = A @ x_true + 0.01 * rng.standard_normal(m)
x_hat = fista_lasso(A, b, lam=0.01)
print("恢复非零位置匹配:", np.sum(np.abs(x_hat) > 1e-3) == 8)
print("稀疏度:", np.sum(np.abs(x_hat) > 1e-3), "/ 8")
```

## §07 例子：手算软阈值

设 $z = (1.5, -0.3, 0.8, -2.0)$，阈值 $t = 0.5$：

- $z_1 = 1.5 > 0.5$：$1.5 - 0.5 = 1.0$
- $z_2 = -0.3$，$|z_2| = 0.3 < 0.5$：置零 $0$
- $z_3 = 0.8 > 0.5$：$0.8 - 0.5 = 0.3$
- $z_4 = -2.0 < -0.5$：$-2.0 + 0.5 = -1.5$

结果：$\text{prox}_{0.5\|\cdot\|_1}(z) = (1.0, 0, 0.3, -1.5)$。可见阈值 $t$ 直接决定了哪些坐标被清零。

## §08 压缩感知与理论保证

压缩感知（Compressed Sensing）的经典设置：$y = A x^*$，$x^*$ 是 $k$-稀疏（$k \ll p$），$A$ 是 $m \times p$ 随机测量矩阵（$m \approx k \log(p/k)$）。理论保证依赖：

- **RIP（Restricted Isometry Property）**：$A$ 对任意 $k$-稀疏向量近似等距：$(1-\delta_k)\|x\|_2^2 \le \|Ax\|_2^2 \le (1+\delta_k)\|x\|_2^2$。RIP 保证 L1 最小化能**精确恢复** $x^*$（稀疏信号唯一辨识）。
- **受限特征值条件（RE）**：统计中保证 Lasso 估计误差 $\|x̂ - x^*\|_2 = \mathcal{O}(\sqrt{k \log p / n})$ 的充分条件。

**直觉**：RIP 说测量矩阵 $A$ 对"稀疏信号"不塌缩距离——任何两个不同的稀疏信号经 $A$ 测量后仍然可区分。这是"少量随机测量能完美重建稀疏信号"的理论根基。

## §09 常见误区与易混概念

- **误区 1：L1 正则 = 贝叶斯 MAP = L2 正则加绝对值**
  对，但重要的是**稀疏性**：L1 的尖角几何使解落在坐标轴（稀疏），L2 无尖角（非稀疏）。两者都是 MAP 估计，但先验不同（Laplace vs Gaussian）。

- **误区 2：Group Lasso 只是"把 L1 换成组范数"这么简单**
  不。Group Lasso 的稀疏单位是**整组**而非坐标；当组大小为 1 时退化为 L1。理解组级软阈值（整组置零 vs 整组收缩）是关键。

- **误区 3：Fused Lasso 的 TV 项产生"稀疏"解**
  TV 项产生的是**分段常数**（差分稀疏），不是系数稀疏。它让相邻系数相等（差分=0），在图像/信号去噪中保留边缘。

### 概念对比表

| 正则项 | 稀疏单位 | 编码结构 | 典型近端算子 | 应用 |
| :--- | :--- | :--- | :--- | :--- |
| L1 (Lasso) | 单个坐标 | 点稀疏 | 软阈值 | 特征选择、压缩感知 |
| Group L1 | 整组 | 组稀疏 | 组软阈值 | 基因通路、多通道 |
| Sparse Group | 组+坐标 | 组内+组间 | 两步阈值 | 层级特征 |
| TV (Fused) | 差分 | 分段常数 | TV 去噪/ADMM | 图像、时序 |

## 🎯 知识自测与主动回忆

> [!question]- 1. 从几何上看，为什么 L1 正则的解会落在坐标轴上（产生稀疏）而 L2 不会？
> **答案**：L1 约束 $\|x\|_1 \le t$ 是菱形（有坐标轴尖角），等高线首次触及边界时接触点大概率落在尖角（坐标轴）上；L2 约束是圆球（边界光滑），接触点一般在球面光滑处、坐标几乎全非零。

> [!question]- 2. 软阈值算子对 $z=(1.5,-0.3,0.8,-2.0)$、$t=0.5$ 的输出是什么？
> **答案**：$(1.0, 0, 0.3, -1.5)$。规则：$|z_i|>t$ 则 $\text{sign}(z_i)(|z_i|-t)$，$|z_i|\le t$ 则置零。故 $1.5\to1.0$、$-0.3\to0$、$0.8\to0.3$、$-2.0\to-1.5$。

> [!question]- 3. Group Lasso 的近端算子与坐标软阈值有何本质区别？
> **答案**：坐标软阈值按单个坐标置零/收缩；组级软阈值按整组范数判断——$\|z_g\|_2 \le t$ 时整组置零，否则整组按 $1 - t/\|z_g\|_2$ 比例收缩。稀疏单位从"坐标"变成"整组"。

> [!question]- 4. Fused Lasso 的 TV 项编码什么结构？为什么解是分段常数？
> **答案**：TV 项 $\sum_i |x_{i+1}-x_i|$ 惩罚相邻系数之差，鼓励相邻相等（差分为零），因此产生分段常数（阶梯状）解，在保留突变的同时平滑噪声。

> [!question]- 5. 压缩感知中 RIP 条件保证什么？直观含义是什么？
> **答案**：RIP 保证 $A$ 对任意 $k$-稀疏向量近似等距：$(1-\delta_k)\|x\|_2^2 \le \|Ax\|_2^2 \le (1+\delta_k)\|x\|_2^2$。直观含义是 $A$ 不塌缩稀疏信号间的距离——任意两个不同的稀疏信号经 $A$ 测量后仍可区分，这是 L1 精确恢复的理论基础。
