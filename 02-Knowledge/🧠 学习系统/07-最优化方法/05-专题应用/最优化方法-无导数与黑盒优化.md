# 最优化方法-无导数与黑盒优化

## §01 学习引导：当梯度不可得时怎么办？

**解决什么问题**：前面所有方法（梯度下降、牛顿、近端等）都假设我们能计算 $\nabla f(x)$ 或近端算子。但在超参数调优、实验设计、仿真优化等场景中，目标函数是**黑盒**：只有输入输出，没有解析形式，求导不可能或代价极高（例如训练一次深度学习模型数小时）。此时需要**无导数优化（Derivative-Free Optimization）**。

**两条主流路线**：
1. **直接搜索法**：如 Nelder-Mead 单纯形法，只用函数值比较，无需梯度、不建模型——适用于低维、噪声小的黑盒问题；
2. **代理模型法**：如贝叶斯优化（Bayesian Optimization），用高斯过程（GP）拟合黑盒函数，再通过采集函数（EI/UCB）智能选择下一个采样点——适用于评估昂贵、低维（$d \le 20$）的问题。

**学完能做什么**：能说清何时该用无导数优化而非梯度方法；能描述 Nelder-Mead 的单纯形几何操作（反射/扩张/收缩/压缩）；能写出 EI/UCB 采集函数并解释"探索—利用"权衡；能实现 Nelder-Mead 并在 Rosenbrock 等测试函数上运行。

## §02 贝叶斯优化 (Bayesian Optimization) 框架

针对高昂评估成本（Expensive Black-box Function，如训练大模型 10 小时评估一次 Validation Loss）的黑盒问题，贝叶斯优化建立**高斯过程（Gaussian Process, GP）代理模型**：

1. **高斯过程先验**：建立 $f(x) \sim \mathcal{GP}(m(x), k(x, x'))$；
2. **采集函数 (Acquisition Function)**：平衡“探索（Exploration）”与“利用（Exploitation）”：
   - **期望改进 (Expected Improvement, EI)**：$\text{EI}(x) = \mathbb{E}[\max(0, f(x) - f(x^+))]$
   - **Upper Confidence Bound (UCB)**：$\text{UCB}(x) = \mu(x) + \kappa \sigma(x)$
3. **采样与更新**：通过极小化轻量级的采集函数选择下一个采样点 $x_{t+1}$，更新 GP 后验。

## §03 Python 代码实现 (Nelder-Mead 算法)

```python
import numpy as np

def nelder_mead(f, x0, step=0.1, alpha=1.0, gamma=2.0, rho=0.5, sigma=0.5, max_iters=200, tol=1e-4):
    """Nelder-Mead 单纯形黑盒求解器"""
    d = len(x0)
    # 初始化 d+1 个顶点
    simplex = [np.array(x0, dtype=float)]
    for i in range(d):
        x = np.array(x0, dtype=float)
        x[i] += step
        simplex.append(x)
        
    for k in range(max_iters):
        # 1. 排序
        simplex.sort(key=lambda x: f(x))
        best, worst = simplex[0], simplex[-1]
        
        if np.std([f(x) for x in simplex]) < tol:
            break
            
        # 2. 质心
        centroid = np.mean(simplex[:-1], axis=0)
        
        # 3. 反射
        xr = centroid + alpha * (centroid - worst)
        fxr = f(xr)
        
        if f(best) <= fxr < f(simplex[-2]):
            simplex[-1] = xr
        elif fxr < f(best):
            # 扩展
            xe = centroid + gamma * (xr - centroid)
            if f(xe) < fxr:
                simplex[-1] = xe
            else:
                simplex[-1] = xr
        else:
            # 收缩
            xc = centroid + rho * (worst - centroid)
            if f(xc) < f(worst):
                simplex[-1] = xc
            else:
                # 缩减
                for i in range(1, len(simplex)):
                    simplex[i] = best + sigma * (simplex[i] - best)
                    
    return simplex[0]
```

## 🎯 知识自测与主动回忆

> [!question]- 1. 什么场景下必须采用无导数最优化（DFO）而非梯度下降法？
> **答案**：当目标函数为黑盒代码（如商业仿真器、黑盒 API）、解析梯度不存在、目标函数不可导、由于测量误差导致梯度被严重噪声淹没，或者单次评估成本极其昂贵时，必须使用 DFO 算法。

> [!question]- 2. Nelder-Mead 单纯形法中的单纯形（Simplex）定义是什么？在 $d$ 维空间中包含多少个顶点？
> **答案**：单纯形是 $d$ 维空间中包含 $d+1$ 个顶点的凸包（如 2 维中的三角形、3 维中的四面体）。Nelder-Mead 算法通过对这 $d+1$ 个顶点的几何反射、扩展、收缩与缩减，实现沿最陡下降方向的自适应多面体变形。

> [!question]- 3. 贝叶斯优化（Bayesian Optimization）的核心两大部分是什么？各自起什么作用？
> **答案**：1) **代理模型（Surrogate Model，如高斯过程 GP）**：拟合已知采样点，给出未知点的均值预测 $\mu(x)$ 和不确定度 $\sigma(x)$；2) **采集函数（Acquisition Function，如 EI、UCB）**：利用均值与不确定度计算下一个最具探索价值的采样点。

> [!question]- 4. CMA-ES 算法（协方差矩阵自适应进化策略）的基本思想是什么？适合什么维度？
> **答案**：CMA-ES 利用多元正态分布采样群体点，根据适应度排序更新分布的均值向量与协方差矩阵，自适应学出最优解领域的椭球几何。它非常适合 10-100 维的中等维度非凸黑盒优化。

> [!question]- 5. Nelder-Mead 算法是否有收敛到全局极小点的理论保证？
> **答案**：没有。Nelder-Mead 属于启发式局部搜索算法，对于高维问题（$d > 10$）单纯形可能发生退化（Degeneracy）而陷入局部极小点或驻点。因此高维黑盒优化通常改用 CMA-ES 或随机搜索。

## §04 手算例子：一维 Nelder-Mead 的一步操作

考虑 $d=1$ 时的退化情形（一般 $d=1$ 单纯形为 2 个点）。设 $f(x) = (x-1)^2$，初始两个顶点 $x_0 = 0, x_1 = 2$，函数值 $f(0) = 1, f(2) = 1$（并列）。取反射系数 $\alpha = 1$。

1. **排序**：$f(0) = f(2)$ 并列，任取 $x_{\text{best}} = 0$，$x_{\text{worst}} = 2$；
2. **质心**（排除最差点）：$c = x_{\text{best}} = 0$；
3. **反射**：$x_r = c + \alpha(c - x_{\text{worst}}) = 0 + 1 \times (0 - 2) = -2$，$f(-2) = 9$；
4. **比较**：$f(x_r) = 9 > f(x_{\text{worst}}) = 1$，反射失败 → 执行**收缩**：$x_c = c + \rho(x_{\text{worst}} - c) = 0 + 0.5 \times 2 = 1$（$\rho = 0.5$），$f(1) = 0$；
5. **接受收缩**：$f(x_c) = 0 < f(x_{\text{worst}}) = 1$，用 $x_c = 1$ 替换最差点。

一步之后单纯形顶点变为 $\{0, 1\}$，而 $x = 1$ 恰好是最优点。这个例子说明：当反射方向变差时，收缩操作能把搜索拉回可行区域，且 $d=1$ 时收缩点往往直接命中低值区。

## §05 常见误区与易混概念

- **误区 1：无导数优化 = 随机搜索**
  随机搜索是均匀采样（无记忆）；Nelder-Mead 维护单纯形几何（有结构记忆），贝叶斯优化维护 GP 代理模型（利用历史采样点）。无导数优化包含"直接搜索"与"代理模型"两大路线，随机搜索只是最朴素的基线。

- **误区 2：黑盒问题就一定要用无导数方法**
  如果黑盒函数**代价中等**且**噪声低**，有限差分梯度 + 梯度下降可能更快；只有当评估昂贵（训练模型数小时）、导数不可得或噪声淹没梯度时才值得用 DFO。判断标准是"一次评估的成本 vs 迭代步数的收益"。

- **误区 3：贝叶斯优化的 GP 代理可以无限采样**
  GP 后验更新是 $\mathcal{O}(n^3)$（$n$ 为采样点数量），采样几百点后每轮更新变慢；此时可改用稀疏 GP、局部重训练或切换 CMA-ES。

### 概念对比表

| 方法 | 维度适用 | 代理模型 | 收敛保证 | 每轮成本 |
| :--- | :--- | :--- | :--- | :--- |
| 随机搜索 | 任意 | 无 | 无（概率性） | 极低 |
| Nelder-Mead | $d \le 10$ | 无（单纯形几何） | 无（启发式） | 低 |
| 贝叶斯优化 | $d \le 20$ | GP | 渐进一致 | 中（GP 更新） |
| CMA-ES | $10 \le d \le 100$ | 协方差矩阵 | 无严格保证 | 中 |

Q: 贝叶斯优化（Bayesian Optimization）解决什么核心问题？
A: 解决单次评估成本极其昂贵的黑盒无导数优化问题。利用高斯过程 (GP) 建立代理模型，通过采集函数 (如 EI、UCB) 平衡探索 (Exploration) 与利用 (Exploitation)。

Q: 为什么基于有限差分（Finite Difference）估计黑盒梯度在存在高频噪声时会失效？
A: 有限差分数值梯度 $\frac{f(x+\epsilon) - f(x)}{\epsilon}$ 当 $\epsilon$ 极小时，测量噪声会被放大 $1/\epsilon$ 倍，导致估算出的梯度完全被噪声主导而失去真实方向。
