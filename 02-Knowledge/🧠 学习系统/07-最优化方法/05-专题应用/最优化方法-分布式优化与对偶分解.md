# 最优化方法-分布式优化与对偶分解

## §01 为什么学？它解决什么问题？

**动机**：前三阶段的算法（牛顿法、BFGS、内点法）都隐含假设"整个问题可以放进一台机器的内存，并且可以集中式地计算全局梯度或 Hessian"。但真实的大规模问题（推荐系统参数 $10^{10}$、联邦学习、传感器网络、数据中心资源调度）往往：

1. **数据分散**：样本分布在多个节点（联邦学习），不允许汇总到中心；
2. **单机内存不足**：完整 Hessian 或甚至完整梯度都无法装入内存；
3. **隐私/通信约束**：节点间只能交换低维消息，不能共享原始数据。

**本卡回答**：如何把一个大规模集中式问题**拆成多个可并行求解的子问题**，让各节点只依赖局部数据 + 少量通信就能收敛到全局最优。核心思想是**对偶分解（Dual Decomposition）** 与它的增强版本 **ADMM**（本卡铺垫 ADMM 的分布式视角，ADMM 细节见 [[最优化方法-增广拉格朗日与ADMM]]）。

**学完能做什么**：能把一个可分离结构的凸问题写成对偶分解形式；能解释为什么原始分解（Primal Decomposition）与对偶分解（Dual Decomposition）的适用场景不同；能说明 ADMM 相比朴素对偶分解在收敛性上的改进（可证明收敛、无需严格凸）。

---

## §02 可分离结构：分解的前提

一个优化问题"可分解"当且仅当目标函数与约束具有**块可分离（Block Separable）** 结构：

$$ \min_{x_1, \dots, x_N} \sum_{i=1}^{N} f_i(x_i) \quad \text{s.t.} \quad \sum_{i=1}^{N} A_i x_i = b $$

其中 $x_i$ 是第 $i$ 个节点的局部变量，$f_i$ 只依赖 $x_i$，耦合只发生在**一致性约束** $\sum_i A_i x_i = b$ 中。如果连约束都可分离（每块独立约束 $A_i x_i = b_i$），问题退化为 $N$ 个无关子问题，无需通信；**耦合约束正是需要分布式算法的原因**。

**直觉**：想象 $N$ 个供应商共同满足一个总需求 $b$。每个供应商有自己的成本函数 $f_i$，他们不能直接看到彼此的成本，只能通过"价格信号"（对偶变量）协商各自生产多少，直到供需平衡。

## §03 对偶分解（Dual Decomposition）

### 1. 写出拉格朗日函数

对耦合约束 $\sum_i A_i x_i = b$ 引入对偶变量 $\lambda$：

$$ L(x, \lambda) = \sum_{i=1}^{N} f_i(x_i) + \lambda^T \left( \sum_{i=1}^{N} A_i x_i - b \right) = \sum_{i=1}^{N} \left[ f_i(x_i) + \lambda^T A_i x_i \right] - \lambda^T b $$

**关键观察**：拉格朗日函数关于 $(x_1, \dots, x_N)$ 是**可分离的**！每一项 $f_i(x_i) + \lambda^T A_i x_i$ 只涉及 $x_i$。因此给定 $\lambda$，最小化 $L$ 可以并行地拆成 $N$ 个独立子问题：

$$ x_i^*(\lambda) = \arg\min_{x_i} \; f_i(x_i) + \lambda^T A_i x_i, \quad i = 1, \dots, N $$

### 2. 对偶问题与梯度上升

对偶函数 $g(\lambda) = \min_x L(x, \lambda) = \sum_i g_i(\lambda) - \lambda^T b$。对偶问题 $\max_\lambda g(\lambda)$ 可用**梯度上升**求解。关键性质：

$$ \nabla g(\lambda) = \sum_{i=1}^{N} A_i x_i^*(\lambda) - b $$

即对偶梯度 = **耦合约束的残差**。这给出优雅的分布式迭代：

```
循环直到收敛:
  1. 广播 λ 给所有节点
  2. 每个节点并行求解 x_i*(λ) = argmin f_i(x_i) + λᵀAᵢxᵢ
  3. 中心收集所有 Aᵢxᵢ*(λ)，计算残差 r = ΣᵢAᵢxᵢ*(λ) - b
  4. 更新 λ ← λ + αᵏ·r   (梯度上升，步长 αᵏ 满足递减条件)
```

### 3. 收敛性与限制

- **优点**：每轮迭代只通信 $N$ 个局部解（或聚合残差），不暴露原始数据，天然适合联邦/分布式架构。
- **致命限制**：梯度上升要求 $g(\lambda)$ 可微，即对偶函数严格凹。若原始问题**非严格凸**（如 $f_i$ 是分段线性、有平底），对偶函数可能不可微甚至 $+\infty$，梯度上升在最优解附近**震荡不收敛**。
- **经典失败例**：$f_i(x_i) = |x_i|$（L1 范数）时对偶不可微，朴素对偶分解无法收敛到精确解——这正是需要近端/增广拉格朗日（ADMM）的原因。

## §04 原始分解 vs 对偶分解（决策表）

| 维度 | 原始分解 (Primal Decomposition) | 对偶分解 (Dual Decomposition) |
| :--- | :--- | :--- |
| 分割对象 | 约束中的共享资源 $b$ | 目标函数中的对偶变量 $\lambda$ |
| 主问题变量 | 资源分配量（主层调参） | 价格/对偶变量 $\lambda$ |
| 子问题 | 固定资源后各块独立求解 | 固定价格后各块独立求解 |
| 适用结构 | 约束耦合、目标可分离 | 目标可分离、耦合约束少 |
| 收敛保证 | 依赖子问题良定性 | 需强对偶 + 对偶可微（严格凸） |
| 工程难点 | 主层步长难调 | 对偶不可微时震荡 |

## §05 分布式梯度下降与一致性约束视角

除了对偶分解，另一种常见框架是把问题写成**一致性（Consensus）形式**：

$$ \min_{x} \sum_{i=1}^{N} f_i(x) \quad \text{等价于} \quad \min_{x_1,\dots,x_N} \sum_{i=1}^{N} f_i(x_i) \quad \text{s.t.} \quad x_1 = x_2 = \dots = x_N $$

即每个节点有自己的变量副本 $x_i$，约束强制所有副本一致。**分布式梯度下降（DGD）** 的迭代为：

$$ x_i^{k+1} = \sum_{j \in \mathcal{N}(i)} W_{ij} x_j^k - \alpha^k \nabla f_i(x_i^k) $$

其中第一步是**加权平均**（通过图邻域 $\mathcal{N}(i)$ 与双随机矩阵 $W$ 实现），第二步是局部梯度步。该方法的收敛率依赖图连通性（拉普拉斯第二小特征值 $\lambda_2$ 决定混合速度），且固定步长只能收敛到最优解的一个邻域。

**ADMM 的一致性形式**（详见 [[最优化方法-增广拉格朗日与ADMM]]）通过引入辅助变量 $z$ 把一致性约束变成 $x_i - z = 0$，并用增广拉格朗日 + 对偶上升获得**可证明收敛**且步长无需衰减的迭代。

## §06 例子：两步手算对偶分解

**问题**：两个节点，$f_1(x_1) = \frac{1}{2}x_1^2$，$f_2(x_2) = \frac{1}{2}x_2^2$，耦合约束 $x_1 + x_2 = 1$（即 $A_1 = A_2 = 1, b = 1$）。

**拉格朗日**：$L = \frac{1}{2}x_1^2 + \frac{1}{2}x_2^2 + \lambda(x_1 + x_2 - 1)$。

**第 1 步（给定 $\lambda = 0$）**：
- 节点 1：$\min \frac{1}{2}x_1^2 \Rightarrow x_1^* = 0$；
- 节点 2：$x_2^* = 0$；
- 残差 $r = 0 + 0 - 1 = -1$；
- 更新 $\lambda \leftarrow \lambda + \alpha r = 0 + 0.5 \times (-1) = -0.5$（步长 $\alpha = 0.5$）。

**第 2 步（$\lambda = -0.5$）**：
- 节点 1：$\min \frac{1}{2}x_1^2 - 0.5 x_1 \Rightarrow x_1^* = 0.5$；
- 节点 2：$x_2^* = 0.5$；
- 残差 $r = 0.5 + 0.5 - 1 = 0$，收敛。

**最优解**：$x_1^* = x_2^* = 0.5$（由对称性也可直接验证）。可见对偶分解通过价格信号 $\lambda$ 协调两个节点达到全局最优，且每步只需交换标量 $\lambda$ 与残差。

## §07 Python 实现：对偶分解求解可分离 QP

```python
import numpy as np

def dual_decomposition(fi_grads, Ai, b, dims, alpha=0.1, max_iter=500, tol=1e-6):
    """对偶分解：可分离凸问题 min Σfi(xi) s.t. ΣAi·xi = b
    fi_grads: [grad_f1, grad_f2, ...]，每项接受局部变量 xi 返回梯度
    Ai: [A1, A2, ...]，dims: [d1, d2, ...]
    """
    N = len(fi_grads)
    lam = np.zeros(b.shape)          # 对偶变量
    xs = [np.zeros(d) for d in dims] # 各节点局部解
    for k in range(max_iter):
        # 并行子问题：x_i* = argmin fi(xi) + λᵀAi·xi，用一步梯度法内解
        for i in range(N):
            xi = xs[i]
            grad = fi_grads[i](xi) + Ai[i].T @ lam
            xs[i] = xi - 0.5 * grad   # 内层一步梯度（假设 fi 二次）
        # 聚合残差并更新对偶变量
        r = sum(Ai[i] @ xs[i] for i in range(N)) - b
        lam = lam + alpha * r
        if np.linalg.norm(r) < tol:
            break
    return xs, lam

# 测试：两节点 min 0.5x1² + 0.5x2²  s.t. x1 + x2 = 1
g1 = lambda x: x        # ∇(0.5x²) = x
g2 = lambda x: x
xs, lam = dual_decomposition([g1, g2], [np.ones((1,1))]*2, np.array([1.0]), [1, 1])
print("x1 =", xs[0][0], " x2 =", xs[1][0], " (最优: 0.5, 0.5)")
# 输出: x1 ≈ 0.5, x2 ≈ 0.5
```

## §08 常见误区与易混概念

- **误区 1：分布式优化 = 并行计算**
  并行计算（多核/GPU 并行梯度）共享同一份全局状态，属于"加速单机算法"；分布式优化中每个节点有**独立的局部变量副本**，通过通信达成一致，解决的是"数据/资源物理分散"或"隐私限制"问题。

- **误区 2：对偶分解总能收敛**
  仅当对偶函数可微（原始问题严格凸 + 强对偶）时才收敛；L1、SVM 等非严格凸问题用朴素对偶分解会震荡，需增广拉格朗日（ADMM）或平滑化。

- **误区 3：ADMM = 对偶分解 + 惩罚项这么简单**
  惩罚项 $\frac{\rho}{2}\|Ax + Bz - c\|^2$ 不是锦上添花，它把对偶函数变成**强凹**的（$\rho$ 相当于强凸系数），这正是 ADMM 能在温和假设下线性收敛的根本原因。

### 概念对比表

| 方法 | 通信量/轮 | 收敛保证 | 步长要求 | 适用规模 |
| :--- | :--- | :--- | :--- | :--- |
| 对偶分解 | 低（标量 λ） | 弱（需严格凸） | 递减 | 小-中 |
| 分布式梯度下降 | 中（图邻域平均） | 线性（固定步长邻域） | 需调 | 中 |
| ADMM | 中（x,z 向量） | 线性/超线性（温和假设） | 无需衰减 | 大 |
| 内点法（集中式） | 无 | 二次 | 无 | 受限于单机内存 |

Q: 为什么朴素对偶分解在 L1 正则问题上不收敛？ADMM 如何解决？
A: L1 目标非严格凸导致对偶函数不可微，梯度上升在最优解附近震荡。ADMM 的增广拉格朗日惩罚项 $\frac{\rho}{2}\|Ax+Bz-c\|^2$ 使对偶函数强凹，恢复可证明收敛。

Q: 分布式梯度下降（DGD）与对偶分解在"一致性"上的处理有何不同？
A: DGD 通过图邻域加权平均 $x_i^{k+1} = \sum_j W_{ij} x_j^k - \alpha^k \nabla f_i$ 隐式达成一致；对偶分解通过价格信号 λ 显式协调，一致性由约束残差驱动。

## 🎯 知识自测与主动回忆

> [!question]- 1. 对偶分解中，为什么给定对偶变量 λ 后各子问题可以并行求解？
> **答案**：拉格朗日函数 $L(x,\lambda) = \sum_i [f_i(x_i) + \lambda^T A_i x_i] - \lambda^T b$ 关于 $x_1,\dots,x_N$ 完全可分离——每一项只依赖自己的 $x_i$，没有交叉项，因此最小化 $L$ 等价于 $N$ 个独立子问题，天然可并行。

> [!question]- 2. 对偶梯度上升中的"梯度"具体是什么？为什么说它是约束残差？
> **答案**：$\nabla g(\lambda) = \sum_i A_i x_i^*(\lambda) - b$，其中 $x_i^*(\lambda)$ 是当前价格下的子问题最优解。它衡量耦合约束 $\sum_i A_i x_i = b$ 的违背程度（残差）：残差为正说明供过于求，价格应上升。

> [!question]- 3. 朴素对偶分解收敛需要什么条件？为什么 L1 问题会失败？
> **答案**：需要对偶函数可微（原问题严格凸 + 强对偶）。L1 目标非严格凸导致对偶函数有不可微点，梯度上升在最优解附近震荡；增广拉格朗日（ADMM）通过惩罚项让对偶函数强凹来修复。

> [!question]- 4. 原始分解与对偶分解各分割什么对象？分别适合什么结构？
> **答案**：原始分解分割约束中的共享资源 b（主层调资源分配，子问题固定资源求解）；对偶分解分割目标中的价格 λ（主层调价格，子问题固定价格求解）。前者适合约束耦合，后者适合目标可分离且耦合约束少。

> [!question]- 5. 分布式梯度下降中加权平均矩阵 W 需要满足什么条件？收敛速度由什么决定？
> **答案**：W 应为双随机矩阵（行和、列和均为 1）且图连通，保证各副本最终一致；收敛速度由图拉普拉斯第二小特征值 $\lambda_2$ 决定（$\lambda_2$ 越大混合越快，通常与网络直径相关）。
