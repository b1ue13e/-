# 凸优化问题标准形式

---
## 0. 先判断它值不值得深挖
- **类别**：**A 类（核心概念，必须深挖）**
- **判断理由**：标准形式是 Boyd Ch.4 的**总纲**——它把 LP/QP/QCQP/SOCP/SDP 全部统一为"凸目标 + 凸不等式 + 仿射等式"一个框架，也是 CVXPY 把用户问题编译成锥标准形（求解器内部语言）的依据。HW02 的验收（"能判定任意问题是否凸、能写出等价标准形式"）直接考它。

---
## 1. 这个知识点解决什么问题？
> **我们遇到了什么麻烦**：
> 现实中优化问题千奇百怪：有的目标是线性的、有的是二次的，约束有不等式也有等式，还有矩阵变量（$X \succeq 0$）。以前的办法是"每个问题各写各的求解器"，但这样无法回答三个根本问题：**这个问题到底是不是凸的？有没有多项式时间算法？换一种等价写法会不会更好解？** 因此需要一种**统一标准形式**：把所有"好解的问题"放进同一个表格（凸 $f_0$、凸 $g_i \le 0$、仿射 $h_i = 0$），并给出层层嵌套的子类（LP ⊂ QP ⊂ QCQP ⊂ SOCP ⊂ SDP），每层对应一类专用算法与一个求解器。

---
## 2. 为什么它重要？它有什么用？
- **连接大图景**：标准形式是整条上升链的中枢——上游 [[凸集与凸函数]] 保证 $f_0, g_i$ 的凸性，下游 [[内点法原理]] 与 [[一阶方法收敛性分析]] 都假定问题"已写成标准形式"；CVXPY 的 `is_dcp()` 检查的就是"能否翻译成标准形式/锥标准形"。
- **实际应用场景**：判断论文/作业中的模型是否凸；把非标准问题（$\max$、$\ge$、绝对值、$\ell_1$ 范数）改写为标准形式；选择求解器——LP 用 GLPK/HiGHS，QP 用 OSQP，SOCP/SDP 用 ECOS/CLARABEL/MOSEK。
- **高频题型/任务**：问题分类（"这是 LP 还是 QP？"）；等价变换（epigraph、松弛、变量替换）；把模型写成矩阵形式交给 CVXPY。

---
## 3. 学它之前需要哪些前置知识？
1. **[[凸集与凸函数]]**：凸函数、仿射函数的定义与保凸运算——标准形式的合法性全部建立在这之上（$f_0, g_i$ 凸、$h_i$ 仿射）。
2. **[[CVXPY建模与求解器]]**：DCP 规则 = 标准形式的机器实现；`cp.Problem` 的构造方式与标准形式一一对应。
3. **线性代数**：半正定矩阵（$P \succeq 0$ 与 $x^T P x \ge 0$）、Cholesky 分解 $P = P^{1/2}P^{1/2}$——QP 转 SOCP、SDP 定义都要用它。

---
## 4. 用直觉语言解释它
> «标准形式就像一张"入学报名表"：不管你是什么问题（线性、二次、带矩阵约束），只要你能把目标填进"凸函数"那一栏、把不等式填进"凸函数 ≤ 0"那一栏、把等式填进"仿射 = 0"那一栏，你就获得了"全球最优 + 多项式时间算法"的入学资格。表格还分班级：LP 班、QP 班、SOCP 班、SDP 班——班级越靠后，能收的学生越多，但老师（算法）越贵。"»
- **直觉类比/几何图像**：$g_i(x) \le 0$ 是"一堵凸的墙"，$h_i(x) = 0$ 是"一块平的板"；可行域 = 墙内与板上的交集。只有"墙是凸的、板是平的"才能保证任何局部最优 = 全局最优。
- **为什么很自然**：凸函数的水平集是凸集、仿射函数的水平集是仿射集（平的），所以标准形式自动保证可行域凸——而"凸集上极小化凸函数"是唯一有全局最优保证的设定。
- **一句话直觉本质**：**标准形式 = "凸目标 + 凸不等式 + 仿射等式"的统一表格，LP/QP/QCQP/SOCP/SDP 是表格里层层放宽的五个班级。**

---
## 5. 正式定义、核心公式、符号解释
### 1. 最核心定义
凸优化问题（标准形式）：
$$\min_x\ f_0(x) \quad \text{s.t.} \quad f_i(x) \le 0,\ i = 1,\dots,m;\quad h_j(x) = 0,\ j = 1,\dots,p$$
其中 $f_0, f_1, \dots, f_m$ 是**凸函数**，$h_1, \dots, h_p$ 是**仿射函数**。可行域 $\mathcal{D} = \bigcap \mathrm{dom}\, f_i \cap \{x : h_j(x)=0\}$ 必为凸集。

### 2. 核心公式：五大子类
$$\text{LP: } \min c^T x \ \text{s.t.}\ Gx \le h,\ Ax = b \qquad \text{QP: } \min \tfrac{1}{2}x^T P x + q^T x \ \text{s.t.}\ Gx \le h,\ Ax = b,\ P \succeq 0$$
$$\text{QCQP: } \min \tfrac{1}{2}x^T P_0 x + q_0^T x + r_0 \ \text{s.t.}\ \tfrac{1}{2}x^T P_i x + q_i^T x + r_i \le 0,\ P_i \succeq 0$$
$$\text{SOCP: } \min c^T x \ \text{s.t.}\ \|A_i x + b_i\|_2 \le c_i^T x + d_i,\ Fx = g \qquad \text{SDP: } \min \mathrm{tr}(CX) \ \text{s.t.}\ \mathrm{tr}(A_i X) = b_i,\ X \succeq 0$$

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $f_0(x)$ | 目标函数 | 凸函数 → $\mathbb{R}$ | 最小化；$\max$ 需取负号 |
| $g_i(x) \le 0$ | 不等式约束 | $g_i$ 凸 | 方向必须是 $\le$；$\ge$ 需取负 |
| $h_j(x) = 0$ | 等式约束 | $h_j$ 仿射 | 非线性等式 = 非凸！ |
| $P \succeq 0$ | 半正定矩阵 | 对称阵 | QP 目标凸性的充要条件 |
| $\|A_i x + b_i\|_2 \le c_i^T x + d_i$ | 二阶锥约束 | $d_i \ge 0$ 时锥 | $\|z\|_2 \le t$ 即 $(z,t) \in \mathcal{K}_{soc}$ |
| $X \succeq 0$ | 半正定矩阵变量 | $\mathbb{S}^n_+$ | SDP 的"广义不等式" |

### 4. 常见变体与适用条件
- **锥标准形（统一语言）**：$\min c^T x \ \text{s.t.}\ Fx + g \preceq_\mathcal{K} 0$，$\mathcal{K}$ 为非负象限（LP）/二阶锥乘积（SOCP）/半定锥（SDP）——这是求解器真正处理的格式。
- **适用条件**：目标与不等式约束必须凸；等式约束必须仿射；变量可扩展（引入 epigraph 变量 $t$ 吸收目标）。
- **限制条件**：QCQP 一般不是 SOCP（凹二次约束不可锥化，除非约束是凸的）；DCP 可表达 ⊂ 锥可表达（含指数锥的 DCP 问题超出 SOCP/SDP 范围，需 EXP 锥求解器）。

## 6. 推导思路和思想来源
- **最初困难**：优化问题种类繁多，无法统一分析（局部最优 ≠ 全局最优、无多项式算法保证）。
- **直接方法局限**：对一般非线性问题，KKT 只是必要条件；只有凸性才能把它变成充分条件。
- **关键"转念"**：把"问题长什么样"换成"问题属于哪个类"——按**目标与约束的代数结构**分层：线性 → 二次 → 二次约束二次 → 二阶锥 → 半定锥。每一层都是上一层的**严格推广**（LP ⊂ QP ⊂ SOCP ⊂ SDP 有包含链），且每一层都有专属多项式时间算法。
- **推导主线与动机**：凸集/凸函数（Ch.2-3）→ 用 $f_i \le 0$ 描述凸水平集、用 $h_j = 0$ 描述仿射集 → 可行域凸 ⟹ 局部 = 全局（Ch.4.2）→ 引入广义不等式 $g_i(x) \preceq_\mathcal{K} 0$ 得到锥规划（Ch.4.6）→ 五大子类统一进锥标准形。
- **为什么自然得到此结论**：因为"保证全局最优"这一要求本身就把问题类锁定在凸结构上；锥规划之所以是终点，是因为半定锥 $\mathbb{S}^n_+$ 是能承载"矩阵变量"的最小自然结构（[[锥规划与半定规划SDP]] 详述）。

## 7. 例子：基础 → 中等 → 实际应用
### 例子 1：基础例子（可手算）
- **题目**：把 $\max\ 3x_1 + 2x_2$ s.t. $x_1 + x_2 \le 4,\ x_1 - x_2 \le 1,\ x_1 \ge 0,\ x_2 \ge 0$ 写成标准形式并求解。
- **解题思路与关键步骤**：① $\max$ 转 $\min$：目标取 $-3x_1 - 2x_2$；② $\ge$ 约束取负：$-x_1 \le 0,\ -x_2 \le 0$；③ 合并矩阵：$G = \begin{pmatrix}1&1\\1&-1\\-1&0\\0&-1\end{pmatrix},\ h = (4,1,0,0)^T$，$c = (-3,-2)^T$。
- **最终答案**：最优解在顶点 $(2.5, 1.5)$ 处（两条边界 $x_1+x_2=4,\ x_1-x_2=1$ 相交），最优值 $f^* = -10.5$，原问题最大值 $10.5$。
- **易错点**：忘记 $\max$ 取负后最优值也要取负；把非负约束 $x \ge 0$ 漏进标准形式。
- **🤔 追问**：若目标改成 $\min\ x_1^2 + x_2^2$ 呢？——它仍是凸问题，但属于 **QP**（有二次目标），顶点最优解不再成立，最优解 $(2, 1.5)$ 不唯一在顶点。
### 例子 2：中等例子（条件判断与多步推理）
- **题目**：证明无约束 QP $\min\ \tfrac{1}{2}x^T P x + q^T x$（$P \succeq 0$）等价于一个 SOCP，并写出其锥形式。
- **解题思路与完整解答**：$x^T P x = \|P^{1/2}x\|_2^2$（Cholesky）。由于 $t \mapsto t^2$ 在 $[0,\infty)$ 单调递增，最小化 $\|P^{1/2}x\|_2^2$ 与最小化 $\|P^{1/2}x\|_2$ 同解。引入 $t \ge 0$：
$$\min_{x,t}\ t + q^T x \quad \text{s.t.} \quad \|P^{1/2}x\|_2 \le t$$
这是标准 SOCP（线性目标 + 一个二阶锥约束）。**关键推理**：$\|P^{1/2}x\|_2 \le t$ 等价于 $(P^{1/2}x, t) \in \mathcal{K}_{soc}$，故锥标准形中 $\mathcal{K}$ 含一个二阶锥因子。
- **易错点**：直接把 $\|P^{1/2}x\|_2^2 \le t$ 当 SOC 约束——二次约束是 QCQP 而非 SOCP；必须利用单调性去掉平方。
### 例子 3：实际应用例子（真实场景/代码）
- **实际价值与转化**：Lasso 在 CVXPY 中的表达 $\min\ \tfrac12\|X\beta - y\|_2^2 + \gamma\|\beta\|_1$ 可展开为标准形式：令 $r = X\beta - y$，$\min\ \tfrac12\|r\|_2^2 + \gamma\sum_j u_j$ s.t. $r = X\beta - y,\ -u_j \le \beta_j \le u_j$——这是带仿射等式与线性不等式的 QP。CVXPY 内部自动做这层"从 DCP 到锥标准形"的编译：
```python
import cvxpy as cp
beta = cp.Variable(p)
r = cp.Variable(n)                       # 显式残差变量（epigraph 展开）
obj = cp.Minimize(0.5 * cp.sum_squares(r) + gamma * cp.norm1(beta))
cons = [r == X @ beta - y]               # 仿射等式：标准形式 h=0
prob = cp.Problem(obj, cons)
prob.solve(solver=cp.CLARABEL)           # 内点法：内部求解锥标准形
print(prob.status, beta.value[:3])
```
**与求解器的对应**：CVXPY 的 `is_dcp()` 检查的是"能否编译成锥标准形"；`solver=cp.CLARABEL`（内点法）内部求解的正是 $K = \mathbb{R}^n_+ \times \mathcal{K}_{soc}$ 的锥规划——这解释了为什么 SOCP 问题不能交给纯 LP 求解器 GLPK。

## 8. 常见误区和易混概念
### 误区 1：以为"等式约束可以是非线性函数"
- **错误直觉**：$h(x) = 0$ 只要"看起来简单"就行，比如 $x_1^2 + x_2 = 1$。
- **为什么错**：$x_1^2 + x_2 = 1$ 是抛物线（非仿射），可行集非凸，问题立刻失去"局部 = 全局"保证。
- **正确理解**：标准形式中 $h$ 必须是**仿射**（$h(x) = Ax - b$）；非线性等式只能用两个不等式 $g \le 0$ 近似或直接判为不可用标准形式。
### 误区 2：把 QCQP 与 SOCP 混为一谈
- **错误直觉**：都有"二次"，所以可以互相转换。
- **为什么错**：SOCP 的锥约束 $\|A x + b\|_2 \le c^T x + d$ 的平方展开是 $x^T A^T A x + \dots \le (c^Tx+d)^2$——只有当 $c^T x + d \ge 0$ 恒成立且 $c = 0$ 时才退化为凸二次约束；一般 QCQP 不能写成 SOCP。
- **正确理解**：SOCP ⊂ QCQP 的补集非空；判断归属要看**约束是"范数 ≤ 线性"还是"二次型 ≤ 0"**。
### 概念对比表

| 概念 | 核心问题 | 关键区别 | 典型使用场景 |
| :--- | :--- | :--- | :--- |
| 标准形式（本概念） | 什么是"好解"的问题 | 凸目标 + 凸不等式 + 仿射等式 | 问题分类、求解器选择 |
| DCP 可表达性 | 能否被 CVXPY 编译 | 语法层面；DCP ⊂ 数学凸 | CVXPY 建模排错 |
| 锥标准形 | 求解器内部语言 | 用广义不等式统一五类问题 | 内点法后端 |
| 松弛 | 把难问题变易 | 放宽约束/目标，解不同 | NP-hard 问题近似 |

### 题目与解析
#### 1. 标准形式要求目标与不等式约束是凸函数、等式约束是仿射函数。为什么等式约束必须是仿射的？
> [!question]- 答案解析
> - **答案**：等式约束 $h(x) = 0$ 的可行集 $\{x : h(x) = 0\}$ 必须是凸集；只有仿射函数的水平集是仿射集（凸），非线性函数的水平集一般非凸（如 $x_1^2 + x_2 = 1$ 是抛物线）。
> - **解析**：可行域 = 凸不等式水平集 ∩ 仿射等式水平集，两者都是凸集 ⟹ 可行域凸 ⟹ 局部最优 = 全局最优。若 $h$ 非线性，全局最优性保证立即失效。
> - **易错原因**：凭"直觉上简单"判断，忽视水平集的几何形状。
> - **对应误区**：误区 1（非线性等式）。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 2. 判断下列问题各属于哪一类（LP/QP/QCQP/SOCP/SDP）：① $\min \|x\|_1$ s.t. $Ax = b$；② $\min x^T P x + q^T x$（$P \succeq 0$）s.t. $x \ge 0$；③ $\min c^T x$ s.t. $\|Ax + b\|_2 \le 1$；④ $\min \mathrm{tr}(CX)$ s.t. $X \succeq 0$。
> [!question]- 答案解析
> - **答案**：① LP（$\|x\|_1$ 用 epigraph 变量展开后是线性目标 + 线性约束）；② QP；③ SOCP；④ SDP。
> - **解析**：分类看**目标与约束的代数结构**而非表面符号：$\|x\|_1 = \max_{s \in \{\pm1\}^n} s^T x$ 是分段线性凸函数，可线性化；$\|Ax+b\|_2 \le 1$ 正是二阶锥约束的原始形态；$X \succeq 0$ 是半定锥广义不等式。
> - **易错原因**：把范数目标误判为 SOCP（范数在**目标**里且可线性化时是 LP；在**约束**里才是 SOCP）。
> - **对应误区**：误区 2（QCQP/SOCP 混淆的镜像）。
> - **Obsidian 标签建议**：`#自测题/基础`
#### 3. 判断正误并说明理由：$\min\ x_1^2 + x_2$ s.t. $x_1 + x_2^2 \le 1,\ x_1 - x_2 = 0$ 是凸优化问题。
> [!question]- 答案解析
> - **答案**：不是。$x_1 + x_2^2 \le 1$ 中 $g(x) = x_1 + x_2^2 - 1$ 的 Hessian 为 $\mathrm{diag}(0, 2) \succeq 0$ 其实是凸的；但等式约束 $x_1 - x_2 = 0$ 是仿射的，也没问题——**真正的问题**：目标 $x_1^2 + x_2$ 中 $-x_2$ 前的符号。等等，$f_0 = x_1^2 + x_2$ 的 Hessian $\mathrm{diag}(2,0) \succeq 0$ 是凸的。重新检查：$g$ 凸、$h$ 仿射、$f_0$ 凸，**它是凸问题**（QCQP）。
> - **解析**：逐项核对三个条件即可：$f_0$ 凸（$\succeq 0$ 的 Hessian）、$g$ 凸、$h$ 仿射——全部满足。这类题的关键是**不要被"看起来怪"骗到，逐项验证**；若把约束改成 $x_1 + x_2^2 = 1$（非线性等式）则立即非凸。
> - **易错原因**：凭直觉跳过 Hessian 检查；混淆"非线性等式"与"凸不等式"。
> - **对应误区**：误区 1。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 4. 已知 $P \succeq 0$，把 $\min\ x^T P x$ s.t. $Ax = b$ 改写为 SOCP 标准形式，并解释为什么可以去掉平方。
> [!question]- 答案解析
> - **答案**：$\min\ t$ s.t. $\|P^{1/2}x\|_2 \le t,\ Ax = b$。
> - **解析**：$x^T P x = \|P^{1/2}x\|_2^2$；因 $u \mapsto u^2$ 在 $[0, \infty)$ 单调递增，最小化 $\|P^{1/2}x\|_2^2$ 与最小化 $\|P^{1/2}x\|_2$ 同解（取同一点 $x^*$）；引入 epigraph 变量 $t$ 吸收目标后得到线性目标 + 二阶锥约束。若 $P$ 奇异则 $P^{1/2}$ 用特征值分解 $\Lambda^{1/2}V^T$ 定义。
> - **易错点**：若把约束写成 $\|P^{1/2}x\|_2^2 \le t$ 则是 QCQP 而非 SOCP——平方必须通过单调性消掉。
> - **对应误区**：误区 2。
> - **Obsidian 标签建议**：`#自测题/中等`
#### 5. 把 Lasso $\min_\beta\ \tfrac12\|X\beta - y\|_2^2 + \gamma\|\beta\|_1$ 展开成带显式变量与仿射等式/线性不等式的 QP 标准形式，并说明 CVXPY 中如何表达。
> [!question]- 答案解析
> - **答案**：$\min_{\beta, r, u}\ \tfrac12\|r\|_2^2 + \gamma\sum_j u_j$ s.t. $r = X\beta - y,\ -u \le \beta \le u$。
> - **解析**：引入残差 $r$ 吸收二次项（仿射等式 $r - X\beta + y = 0$），引入 $u$ 把 $\ell_1$ 展开为线性约束 $-u_j \le \beta_j \le u_j$（因为 $\|\beta\|_1 = \min_u\{\sum u_j : -u \le \beta \le u\}$，等式在最优时成立）。CVXPY 中写 `r == X @ beta - y` 与 `cp.norm1(beta)` 即可，编译器自动完成同一展开并翻译成锥标准形（$\mathcal{K} = \mathbb{R}^{2p}_+ \times \mathcal{K}_{soc}$）。
> - **解析（续）**：这解释了为什么 CVXPY 报错 DCP 时先问"能否 epigraph 展开"——大多数"看似非 DCP"的写法都有等价标准形式。
> - **易错原因**：忘记 $u$ 的非负性（$u \ge 0$ 由 $-u \le \beta \le u$ 在最优时自动满足，但显式写出更稳）。
> - **Obsidian 标签建议**：`#自测题/较难`
