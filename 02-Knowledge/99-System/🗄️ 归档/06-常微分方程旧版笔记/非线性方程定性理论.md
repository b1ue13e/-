# 非线性方程定性理论

> 所属模块：[[🗺️ 常微分方程学习路径|常微分方程学习路径]] · 返回阶段：[[📙 第三阶段：进阶|📙 第三阶段：进阶 (Advanced)]]

---

## 0. 学习边界

- **类别**：**A 类（核心定理，必须深挖）**。非线性定性理论回答了线性理论留下的全部"之后呢"：线性化什么时候可信、什么时候失效、非线性世界里有哪些新现象（极限环、分岔、混沌）。
- **判断理由**：现实中几乎没有真线性系统；几乎所有建模都要用这套工具判断"平衡点稳不稳、会不会震荡、会不会振荡持续"。它同时是 [[项目-Lorenz|Lorenz]]、[[神经ODE|Neural ODE]] 等专题的入口。
- **验收模式说明**：本卡不设置指标/冲榜类任务；验收只看「定义复述、证明重建、反例、条件变式、闭卷验收」五项是否通过。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：[[相平面与轨线分析]] 给了线性系统 $\mathbf{x}'=A\mathbf{x}$ 完整的相图分类。但真实系统是
> $$\mathbf{x}' = f(\mathbf{x}),$$
> $f$ 是非线性的，比如摆 $\theta''+\frac{g}{L}\sin\theta=0$、捕食系统 $x'=(a-by)x$。我们不能把非线性系统"当线性系统算"——可是在**平衡点附近**，$f(\mathbf{x}) \approx Df(\mathbf{x}_0)(\mathbf{x}-\mathbf{x}_0)$，系统"几乎"是线性的。
>
> **本卡回答三个问题**：
> 1. 平衡点附近的非线性系统，什么时候可以放心用线性化结论？（Hartman–Grobman 的适用边界）
> 2. 没有平衡点吸引力、但系统也不爆炸时，会发生什么？（极限环，Poincaré–Bendixson）
> 3. 参数连续变化时，相图怎么突变？（分岔）

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：它是进阶阶段的枢纽——上承 [[相平面与轨线分析]]，下接 [[稳定性理论基础]]（Lyapunov 直接法处理线性化判不了的场合）、[[📙 第三阶段：进阶|极限环/分岔/混沌]]、[[Lorenz系统|Lorenz 系统]] 与 [[混沌定义|混沌]]。
- **实际应用场景**：振铃电路（van der Pol 振荡）、[[电路建模|电路]]、[[种群建模|种群]]、神经动力学、心脏搏动模型；工程上所有"会不会自激振荡"的问题都落在极限环范畴。
- **高频考点**：Jacobian 线性化判别、Hartman–Grobman 适用条件（双曲）、"线性化为中心"的陷阱、用 Bendixson–Dulac 判据排除闭轨、三种基本分岔范式。

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[相平面与轨线分析]]**：2×2 线性系统奇点分类、$\tau$-$\Delta$ 判别。本卡一切"线性化结论"都以它作为参照系。
2. **[[平衡点]]** 与 [[平衡点稳定性初识]]：什么是平衡点、稳定/不稳定的初步直觉。
3. **[[解的存在唯一性定理]]**（[[Picard迭代]]）：局部存在性保证"在平衡点附近看一小段轨道"是有意义的；唯一性保证轨线不交（见相平面卡定理 B）。
4. **[[特征值定义]] / [[线性方程组与矩阵方法]]**：Jacobian 的特征值计算是全部判别的发动机。

## 4. 定义复述

### 1. 精确定义

设 $\mathbf{x}'=f(\mathbf{x})$，$f:D\subseteq\mathbb{R}^n\to\mathbb{R}^n$ 为 $C^1$（以下以 $n=2$ 为主）。

- **平衡点 / 临界点（equilibrium / critical point）**：$f(\mathbf{x}_0)=0$ 的点。
- **线性化（linearization）**：在平衡点 $\mathbf{x}_0$ 处令 $\mathbf{u}=\mathbf{x}-\mathbf{x}_0$，Taylor 展开
  $$\mathbf{u}' = A\mathbf{u} + o(\|\mathbf{u}\|),\qquad A = Df(\mathbf{x}_0)=\begin{pmatrix}\partial f_i/\partial x_j(\mathbf{x}_0)\end{pmatrix},$$
  忽略高阶项得到的线性系统 $\mathbf{u}'=A\mathbf{u}$ 称为线性化系统。
- **双曲平衡点（hyperbolic equilibrium）**：$A=Df(\mathbf{x}_0)$ 的**所有特征值实部非零**。这是"线性化可信"的精确边界。
- **（几乎线性 / almost linear）**：Diffy Qs §8.2.1 的等价说法——平衡点孤立且 Jacobian 可逆；此时非线性项在平衡点附近"很小"，系统行为近似线性化（主教材的非形式化表述，见 §6 定理 1 诚实标注）。
- **极限环（limit cycle）**（Diffy Qs §8.4）：**一条闭轨，且至少有一条其他轨线螺旋式地趋近它（或从它螺旋离开）**。若所有邻近轨线都螺旋进入它，称为（渐近）稳定极限环。与中心闭轨的区别：极限环是"孤立"的闭轨（附近没有别的闭轨），中心是"成族"的闭轨。
- **稳定 / 渐近稳定 / 不稳定**（Diffy Qs §8.2）：平衡点 $\mathbf{x}_0$ 稳定，若 $\forall\varepsilon>0,\ \exists\delta>0$，$\|\mathbf{x}(0)-\mathbf{x}_0\|<\delta \Rightarrow \|\varphi(t;\mathbf{x}(0))-\mathbf{x}_0\|<\varepsilon,\ \forall t\ge0$；若还满足 $\lim_{t\to\infty}\varphi(t;\mathbf{x}(0))=\mathbf{x}_0$（对所有足够近初值），则渐近稳定；否则不稳定。注：主教材未用"Lyapunov 稳定"一词，直接定义"stable"；本库细卡 [[Lyapunov稳定]] 用更标准术语。

## 5. 直觉与图像

- **直觉类比/几何图像**：线性化是"用放大镜看平衡点"。把非线性系统在平衡点附近放大，高阶项缩成"几乎看不见的灰尘"，主项就是线性系统。**问题在于：灰尘偶尔会吹翻船**——当线性化的特征值实部恰好等于 0（中心），线性系统自己都拿不定主意（闭轨 vs 螺线），灰尘（非线性项）就决定了方向。
- **极限环直觉**：一个钟摆装上"负阻尼"：小振幅时系统自己加油（越晃越大），大振幅时系统又刹车（越晃越小），最后停在某个"自持振荡"的环上——这就是 van der Pol 振荡器。极限环是**动力学自己画出来的孤立圆圈**，不是线性系统那种"成族"的椭圆。
- **分岔直觉**：一个参数（比如弹簧刚度、种群增长率）连续拧动，相图在某个临界值"啪"地变了形状——平衡点消失、分裂、或交换稳定性。**分岔 = 相图的定性突变点。**
- **一句话直觉本质**：**线性化可信 ⇔ 平衡点是"双曲"的（特征值实部全非零）；可信时，非线性系统在平衡点附近和它的线性近似长得一模一样。**

> ⚠️ 直觉只是导航，不是证明。任何直觉表述都要能回到第 4 节的精确定义。

## 6. 定理陈述与证明重建

### 定理 1：Hartman–Grobman 定理（双曲情形）与适用边界

**前提**：$\mathbf{x}'=f(\mathbf{x})$，$f$ 为 $C^1$；$\mathbf{x}_0$ 为**双曲**平衡点（$A=Df(\mathbf{x}_0)$ 特征值实部全非零）。
**结论**：存在 $\mathbf{x}_0$ 的邻域 $U$、原点邻域 $V$ 及同胚 $h:U\to V$，把非线性流的轨线（带时间参数地）映成线性流 $e^{At}$ 的轨线：
$$h\circ \varphi_t = e^{At}\circ h\qquad(\text{在定义域内}).$$
特别地：双曲平衡点的**局部相图拓扑**与**稳定性**完全由线性化决定——按 [[相平面与轨线分析]] 定理 A 分类即可。

**出处**：严谨陈述为 Hartman (1960)/Grobman (1959) 定理，标准教材如 Perko《Differential Equations and Dynamical Systems》（本库 [[📚 教材挂载索引|已挂载]]）或 Hirsch–Smale；**具体章节页码 [待验证]**。

> **诚实标注（重要）**：主教材 Notes on Diffy Qs **不命名、不陈述** Hartman–Grobman 定理。它只给出非形式化版本：§8.2.1 定义"几乎线性"（孤立 + Jacobian 可逆），并断言"非线性项很小，系统行为与线性化一致"；§8.2.2 的 Table 8.1 据此直接给出非线性平衡点分类表（实根同负→渐近稳定汇、异号→不稳定鞍、复根实部正/负→不稳定/渐近稳定螺旋源/汇）。本卡呈现的完整定理是标准课程内容（MIT 18.03SC Unit IV 亦在"Linearization"单元讲授），但主教材本身只到非形式化层面——考试/验收时以"双曲平衡点可按线性化分类"为准。

### 2. 证明主线（骨架）

- **第 1 步（改写）**：平移后 $\mathbf{u}'=A\mathbf{u}+N(\mathbf{u})$，$N(0)=0,\ DN(0)=0$（非线性项二阶小）。
- **第 2 步（共轭方程）**：要找同胚 $h=\mathrm{id}+p$ 满足 $h\circ\varphi_t=e^{At}\circ h$。把 $p$ 满足的方程整理为不动点方程 $p = \mathcal{T}(p)$，其中 $\mathcal{T}$ 由线性化流与非线性流的作用定义。
- **第 3 步（压缩映射）**：双曲性 $\Rightarrow$ 线性算子 $e^{At}$ 在适当 Banach 空间（$e^{\alpha t}$ 权重的连续有界函数空间，$0<\alpha<\min|\mathrm{Re}\,\lambda_i|$）上有谱隙、$I-e^{At}\circ(\cdots)$ 可逆；$\mathcal{T}$ 为压缩 ⇒ 不动点 $p$ 存在；再证 $h$ 是同胚（逆向用 $\varphi_t$ 的逆流构造）。
- **关键"转念"**：双曲性的作用是把"线性流在时间上拉开"（一个方向压缩、另一个方向拉伸），从而把共轭问题变成可解的压缩不动点问题——**正是"实部非零"让缩放有了确定方向**。

> 完整证明依赖 Banach 空间不动点与谱隙估计，超出 Diffy Qs 与本课程范围，本卡只给骨架。**适用边界（同样重要）**：特征值有**零实部**时定理不适用——此时必须靠更高阶项、[[Lyapunov直接法]]、中心流形或能量函数进一步判定（见 §7 反例 1）。

### 定理 2：非线性平衡点分类流程（Jacobian → 特征值 → 何时可信）

**流程**：
1. 解 $f(\mathbf{x})=0$ 求出**所有**平衡点。
2. 对每个平衡点算 Jacobian $A=Df(\mathbf{x}_0)$ 及其特征值。
3. **判据**（$n=2$，依据 Diffy Qs §8.2.2 Table 8.1 + 定理 1）：

| Jacobian 特征值 | 平衡点类型 | 稳定性 |
| :--- | :--- | :--- |
| 实根，同负 | 结点（sink） | 渐近稳定 |
| 实根，同正 | 结点（source） | 不稳定 |
| 实根，异号 | 鞍点 | 不稳定 |
| 复根，实部 $<0$ | 焦点（spiral sink） | 渐近稳定 |
| 复根，实部 $>0$ | 焦点（spiral source） | 不稳定 |
| 复根，实部 $=0$ | **线性化为中心——不可下结论** | 待定，见反例 1 |

4. **何时可信**：特征值实部**全非零**（双曲）时，上述分类对非线性系统**严格成立**（定理 1），稳定性也一致。只要出现**零实部特征值**（中心、$\det A=0$ 退化、高阶零点），线性化结论**不可信**，必须改用其他工具。

**出处**：Diffy Qs §8.2.2 Table 8.1；流程为 §8.1.2 + §8.2.2 综合。

### 定理 3：极限环与 Poincaré–Bendixson 定理

**定义**（Diffy Qs §8.4）：极限环是闭轨，且存在其他轨线螺旋趋近/离开它。

**定理 3.1（Poincaré–Bendixson，Diffy Qs Theorem 8.4.1）**：
**前提**：$R\subset\mathbb{R}^2$ 有界闭区域，$R$ 内部**不含**临界点；系统 $\mathbf{x}'=f(\mathbf{x})$（二维自治）的解在 $R$ 内对一切 $t\ge t_0$ 存在且有界。
**结论**：该解要么本身是周期解，要么**趋于 $R$ 内的一条周期解**（即 $R$ 内含极限环或闭轨）。

**证明骨架（完整证明超出本课程，注明）**：
- **第 1 步**：有界轨线 ⇒ $\omega$-极限集 $\Omega$（见 [[动力系统与遍历理论]]）非空、紧、连通、不变。
- **第 2 步**：$R$ 内无临界点 ⇒ $\Omega$ 上向量场处处非零 ⇒ 过 $\Omega$ 中每点的轨线可以一直延拓，且 $\Omega$ 由整条轨线组成。
- **第 3 步（关键转念）**：在二维平面取一条过 $p\in\Omega$ 的**横截线段**（与方向场横截的短线段）。$\Omega$ 中的轨线只能按固定方向穿过横截线；若 $\Omega$ 不是单条闭轨，则在横截线上会累积出无穷多个交点，这些交点依时间收敛，推出 $\Omega$ 上存在"非周期但返回横截线"的点，与横截线的局部唯一性（轨线不交，见相平面卡定理 B）矛盾。
- **第 4 步（收尾）**：故 $\Omega$ 必为一条周期轨线——该轨线即所求闭轨，解趋于它。∎（骨架）

**适用边界与诚实标注**：该定理**只在二维**成立（Diffy Qs §8.4 明确提示三维以上"空间太多"，轨线可以绕开）；且 $R$ 内**不能有临界点**，否则解可能趋于临界点或"由临界点及连接轨线组成的闭链"。完整证明（Bendixson 截面技巧）本课程不要求。

**定理 3.2（Bendixson–Dulac 否定判据，Diffy Qs Theorem 8.4.2）**：
**前提**：$R$ 为**单连通**区域，$\operatorname{div} f = \partial_x f + \partial_y g$ 在 $R$ 上恒正或恒负（至多在孤立点/曲线上为零）。
**结论**：$R$ 内不存在**非平凡（非常数）闭轨**。

**证明（完整，可手写）**：反设 $C\subset R$ 是一条闭轨（周期解）。由格林公式
$$\oint_C \big(f\,dy - g\,dx\big) = \iint_R \left(\frac{\partial f}{\partial x}+\frac{\partial g}{\partial y}\right)\,dx\,dy .$$
（若 $C$ 内部不是全部含于 $R$，在 $C$ 包围的子区域内应用；$R$ 单连通保证 $C$ 内部⊂$R$。）另一方面，在闭轨上 $dx=f\,dt,\ dy=g\,dt$，故被积表达式 $f\cdot g\,dt - g\cdot f\,dt \equiv 0$，左边 $=0$。而右边被积函数恒正或恒负，面积分 $\neq0$。矛盾。故 $R$ 内无闭轨。∎

**证明技巧迁移**：Bendixson–Dulac 的"格林公式把线积分变面积分"技巧 → 可迁移到 [[自伴算子|边值问题/自伴算子]] 的特征值积分恒等式；"横截线累积交点"技巧 → 可迁移到 [[动力系统与遍历理论]] 的 Poincaré 截面与 [[Poincaré映射|Poincaré 映射]]。

### 定理 4：分岔初步——三个基本范式

**诚实标注**：主教材 Diffy Qs **不包含分岔内容**（已核实：§8.3 只讲摆与捕食系统，通篇无"bifurcation"）。三个范式方程是动力系统标准教材内容（Perko《Differential Equations and Dynamical Systems》／Strogatz《Nonlinear Dynamics and Chaos》，**页码 [待验证]**）；本库细卡 [[鞍结分岔]]、[[跨临界分岔]]、[[叉式分岔]] 已挂载，可作本地来源。

| 范式方程 | 平衡点（随 $\mu$） | 临界行为 |
| :--- | :--- | :--- |
| **鞍结**：$x' = \mu - x^2$ | $\mu<0$：无平衡点；$\mu=0$：$x^*=0$ 退化；$\mu>0$：$x^*=\pm\sqrt\mu$（一稳定一不稳定） | 一对平衡点从临界点"生"出（或消失） |
| **跨临界**：$x' = \mu x - x^2$ | $x^*=0$（特征值 $\mu$）与 $x^*=\mu$（特征值 $-\mu$） | $\mu$ 过 $0$ 时两个平衡点**交换稳定性** |
| **超临界叉形**：$x' = \mu x - x^3$ | $\mu<0$：唯一稳定平衡点 $x^*=0$；$\mu>0$：$x^*=0$ 失稳，分叉出 $x^*=\pm\sqrt\mu$（均稳定） | 一个稳定平衡点退化为"一碗"变"双坑" |

手算验证（叉形）：$x^*=0$ 的线性化系数 $f'(0)=\mu$，故 $\mu<0$ 稳定、$\mu>0$ 不稳定；$x^*=\pm\sqrt\mu$ 处 $f'(\pm\sqrt\mu)=\mu-3\mu=-2\mu<0$，稳定。整个过程用一阶导（线性化！）就能算——分岔临界点本身是非双曲点（特征值过零），但**分支上的点**是双曲的，线性化照常适用。

## 7. 经典反例库

> 数学的边界由反例划定。每个反例回答一个问题：「这个条件能省吗？」

### 反例 1：线性化失效——中心变焦点（任务指定例子）

- **问题**：线性化特征值为纯虚（中心）时，非线性系统一定也是中心吗？
- **反例构造**：
  $$x' = -y + x(x^2+y^2),\qquad y' = x + y(x^2+y^2).$$
  原点处 Jacobian $A=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$，特征值 $\pm i$——线性化是**中心**（成族闭轨）。
  用极坐标 $x=r\cos\theta,\ y=r\sin\theta$：
  $$r' = \frac{xx'+yy'}{r} = \frac{-xy+yx + (x^2+y^2)^2}{r} = r^3, \qquad \theta' = \frac{xy'-yx'}{r^2} = 1.$$
  故 $r(t)=\dfrac{r_0}{\sqrt{1-2r_0^2 t}}$（有限时间爆掉）——**半径单调增大**，原点实际是**不稳定焦点（螺旋源）**，不是中心！
- **结论崩塌点**：定理 1 的前提"特征值实部全非零"被破坏（实部 $=0$）。$\tau$-$\Delta$ 平面上 $\tau=0$ 落在零测度边界，非线性项 $r^3$ 把它"推"向不稳定一侧。**中心稳定性由非线性项决定，线性化完全失明。**
- **教训**：见到"线性化是中心"，必须警惕；改用极坐标/能量/更高阶项判定。主教材 Diffy Qs §8.2.3 给出同族例子 $x'=y,\ y'=-x+y^3$（原点 Jacobian 亦为 $\pm i$，但 $\lambda=(3/2)y^2\pm\cdots$ 在 $y\neq0$ 处实部为正，轨线螺旋向外）——即"**The trouble with centers**"小节的核心内容。

### 反例 2：非双曲点——线性化连"稳定与否"都给不出

- **问题**：特征值为零实部之外，还有其他非双曲情形吗？线性化能给出方向吗？
- **反例构造**：标量方程 $x'=x^2$。原点 $x^*=0$ 处 $f'(0)=0$——非双曲。线性化 $\mathbf{u}'=0$ 预测"每个点都是平衡点"，毫无区分力。真实行为：$x(t)=\frac{1}{1/x_0 - t}$，$x_0>0$ 时有限时间爆炸，$x_0<0$ 时衰减到 $0$——原点**半稳定**（一侧吸引一侧排斥）。线性化完全无法预测。
- **教训**：$\det A=0$（含零特征值）同样是线性化失效区。双曲性 = 实部非零，是定理 1 不可省的承重墙。

### 反例 3：Poincaré–Bendixson 的适用边界——$R$ 内不能有临界点 / 只限二维

- **问题**：P–B 定理的"$R$ 内无临界点"与"二维"两个条件能省吗？
- **反例构造（二维含临界点）**：$x'=x,\ y'=-y$（线性鞍点），$R=\{x^2+y^2\le1\}$ 内含临界点 $(0,0)$。过 $(x_0,0)$ 的轨线沿稳定流形趋于原点——**没有闭轨**，解趋于临界点而非周期解。P–B 结论"趋于周期解"不再成立。
- **反例构造（三维）**：Lorenz 系统 $\sigma=10,\rho=28,\beta=8/3$（见 [[Lorenz系统]] / Diffy Qs §8.5.2）在三维中轨线被吸引到**奇异吸引子**——不趋于任何周期轨、也不趋于平衡点。P–B 定理在 $\mathbb{R}^3$ 失效，因为轨线可以"绕开"，横截线论证不再成立。
- **教训**：边界条件不是可省的形式条款。两个条件正是证明中"横截线"技巧的命根子。

## 8. 条件变式

> 把条件改一改，结论还成立吗？这是数学学习最有效的自检方式。

| 变式 | 条件改动 | 结论变化 | 成立/不成立 | 依据（证明或反例） |
| :--- | :--- | :--- | :---: | :--- |
| Jacobian 特征值纯虚 | 双曲→非双曲 | 线性化分类失效，稳定性由非线性项定 | 不成立 | 反例 1（$x'=-y+x r^2$ 中心变焦点） |
| $f'(0)=0$ 的标量退化 | 双曲→$\det A=0$ | 线性化零矩阵，预测无力 | 不成立 | 反例 2（$x'=x^2$ 半稳定） |
| P–B 中 $R$ 含临界点 | 无临界点→含临界点 | 结论从"趋于周期解"改为"趋于临界点/闭链" | 不成立 | 反例 3（鞍点 + $R$ 内含原点） |
| 二维 → 三维 | $\mathbb{R}^2\to\mathbb{R}^3$ | P–B 失效，出现奇异吸引子 | 不成立 | Lorenz（Diffy Qs §8.5.2） |
| 平衡点渐近稳定（双曲） | 加小参数扰动 | 稳定性保持（结构稳定） | 成立 | Hartman–Grobman 同胚，拓扑结构不变 |
| 分岔参数过临界 | $\mu$ 从两侧逼近 $\mu_c$ | 平衡点个数/稳定性突变 | 成立（按范式） | 定理 4 三个范式 |

### 题目与解析

#### 1. 判断题：线性化何时可信
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：判断："非线性系统在平衡点附近的相图，永远等于其线性化相图。" 并对"永远"给出修正。
> - **答案/证明**：错。仅当平衡点**双曲**（Jacobian 特征值实部全非零）时成立（Hartman–Grobman）；出现零实部特征值时失效（反例 1）。
> - **解析**：修正为"双曲平衡点附近，非线性系统与其线性化局部拓扑同胚"。
> - **易错原因**：把"局部近似"偷换成"永远相等"。
> - **对应反例/变式**：反例 1、2。

#### 2. 平衡点分类计算（本卡主例题）
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：系统 $x'=y,\ y'=-x+x^2$（Diffy Qs §8.1 例题）。求全部平衡点并分类。
> - **答案/证明**：平衡点解 $y=0,\ -x+x^2=0$ ⇒ $(0,0)$ 与 $(1,0)$。Jacobian $J=\begin{pmatrix}0&1\\-1+2x&0\end{pmatrix}$。
>   - $(0,0)$：$J=\begin{pmatrix}0&1\\-1&0\end{pmatrix}$，特征值 $\pm i$——**线性化为中心，非双曲，待定**（本例题用相图/能量可判为稳定中心，但线性化本身不下结论）。
>   - $(1,0)$：$J=\begin{pmatrix}0&1\\1&0\end{pmatrix}$，特征值 $\pm1$——**双曲鞍点**（稳定流形方向 $\propto(1,-1)$，不稳定 $\propto(1,1)$）。
> - **解析**：同一系统里同时出现"可信"（鞍点）与"不可信"（中心）两类平衡点，是流程第 4 步的最佳演示。
> - **易错原因**：见到 $\pm i$ 直接写"中心稳定"，忘了非线性系统的中心要另行判定。
> - **对应反例/变式**：反例 1。

#### 3. 极坐标判定中心陷阱
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：判定 $x'=-y+\varepsilon x(x^2+y^2),\ y'=x+\varepsilon y(x^2+y^2)$ 在原点的类型，$\varepsilon=+1$ 与 $\varepsilon=-1$ 分别讨论。
> - **答案/证明**：极坐标 $r'=\varepsilon r^3,\ \theta'=1$。$\varepsilon=+1$：$r$ 单调增 → 不稳定焦点；$\varepsilon=-1$：$r$ 单调减 → 稳定焦点。线性化（$A=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$）两者都是中心。
> - **解析**：这是反例 1 的参数族版本，说明非线性项"决定方向"且方向可正可负。
> - **易错原因**：忘记把系统写成极坐标。
> - **对应反例/变式**：反例 1。

#### 4. 用 Bendixson–Dulac 排除闭轨
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：证明系统 $x'=x^2+y^2,\ y'=2xy$ 在整个平面内不存在非平凡闭轨。
> - **答案/证明**：$\operatorname{div} f = 2x + 2x = 4x$，并非恒正/恒负——直接套用失败。修改：乘 Dulac 因子 $\phi=1$ 不行；换思路，任取单连通子区域 $R$ 其中 $x$ 保持符号，则 $\iint_R \operatorname{div}f =4\iint_R x$ 在该子区域内恒正或恒负，该子区域内无闭轨。由于闭轨必含在某半平面（$x>0$ 或 $x<0$ 的某个单连通开集）内，全平面无闭轨。∎
> - **解析**：本题演示"散度符号随位置变化时，用分区/单连通子区域逐一排除"；Dulac 因子（乘 $h(x,y)$ 使 $\operatorname{div}(h f)$ 定号）可进一步推广。对应 Diffy Qs Thm 8.4.2 及其后习题。
> - **易错原因**：忽略"单连通"与"区域内恒号"两个前提。
> - **对应反例/变式**：Diffy Qs §8.4 Example 8.4.5（散度恒正却有闭轨——因为区域带洞，非单连通）。

#### 5. 全局 vs 局部
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：van der Pol 方程 $x''-\mu(1-x^2)x'+x=0$（$\mu=1$）写成系统。用线性化说明原点类型，再用数值说明存在极限环。全局行为与局部行为如何关联？
> - **答案/证明**：令 $x'=y$，则 $y'=\mu(1-x^2)y-x$。原点 Jacobian $J=\begin{pmatrix}0&1\\-1&\mu\end{pmatrix}$，$\tau=\mu>0,\Delta=1>0$，判别式 $\mu^2-4<0$ → 不稳定焦点。局部失稳 + 全局有界（耗散使轨线被拉回）→ P–B 保证某闭区域内有极限环。数值见下方程序（van der Pol）。
> - **解析**：这是"线性化告诉你小尺度，P–B 告诉你大尺度，拼起来是极限环"的标准叙事。MIT 18.03SC Unit IV 的 Limit Cycles 与 Chaos 单元有同类问题（编号 [待验证]）。
> - **易错原因**：只做局部分析就断言全局行为。
> - **对应反例/变式**：定理 3、反例 3。

## 附：可运行 Python——中心变焦点 + 极限环

```python
import matplotlib
matplotlib.use('Agg')          # 无显示器环境用 Agg；交互环境可删此行
import numpy as np
import matplotlib.pyplot as plt

# 任务指定反例：x' = -y + x*(x^2+y^2),  y' = x + y*(x^2+y^2)
# 极坐标: r' = r^3, theta' = 1  ->  线性化(中心) vs 真实(不稳定焦点)
def f_polar(state):
    x, y = state
    r2 = x*x + y*y
    return np.array([-y + x*r2, x + y*r2])

def rk4(f, s0, T, dt):
    N = len(T); sol = np.zeros((N,2)); sol[0] = s0
    for i in range(1, N):
        h = T[1]-T[0]
        k1 = f(sol[i-1]); k2 = f(sol[i-1]+h/2*k1)
        k3 = f(sol[i-1]+h/2*k2); k4 = f(sol[i-1]+h*k3)
        sol[i] = sol[i-1] + h/6*(k1+2*k2+2*k3+k4)
    return sol

T = np.linspace(0, 6, 2000)
s0 = np.array([0.2, 0.0])

# 非线性系统：预期半径从 0.2 增大到 ~0.277 (r^2 = r0^2/(1-2 r0^2 t))
nl = rk4(f_polar, s0, T, 0.003)
# 线性化系统 u' = A u (中心)：半径保持 0.2
A = np.array([[0., -1.],[1., 0.]])
lin = rk4(lambda s: A@s, s0, T, 0.003)

fig, (a1, a2) = plt.subplots(1, 2, figsize=(9,4))
a1.plot(nl[:,0], nl[:,1], 'r-');  a1.set_title("nonlinear: outward spiral  r(6)=%.3f"%np.hypot(*nl[-1]))
a2.plot(lin[:,0], lin[:,1], 'b-'); a2.set_title("linearization: center  r(6)=%.3f"%np.hypot(*lin[-1]))
for ax in (a1, a2): ax.set_xlabel('x'); ax.set_ylabel('y'); ax.axis('equal'); ax.grid(alpha=.3)
# 预期输出：左图半径 0.2 -> 0.277 的向外螺线；右图半径恒为 0.2 的圆。
plt.tight_layout(); plt.savefig('center_vs_spiral.png', dpi=150)

# --- 极限环：极坐标 r' = 1 - r^2, theta' = 1  (r=1 为渐近稳定极限环) ---
def f_lc(state):
    x, y = state
    r = np.hypot(x, y)
    return np.array([(1-r*r)*x/r - y, (1-r*r)*y/r + x])   # r 大时吸回, r 小时推出

T2 = np.linspace(0, 20, 4000)
for r0 in (0.3, 1.6):
    traj = rk4(f_lc, np.array([r0, 0.0]), T2, 0.005)
    plt.figure(); plt.plot(traj[:,0], traj[:,1]); plt.axis('equal'); plt.grid(alpha=.3)
    plt.title("limit cycle r=1  (start r0=%.1f -> spirals to unit circle)" % r0)
# 预期输出：从 r0=0.3 与 r0=1.6 出发的两条轨线都螺旋收敛到单位圆 r=1。
```
