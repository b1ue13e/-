# 恰当方程与积分因子

---

## 0. 学习边界

- **类别**：**A 类（核心定理，必须深挖）**
- **判断理由**：恰当方程把"解 ODE"翻译成"求一个函数的全微分"，背后是多元微积分最深刻的朴素事实——**混合偏导可交换（Clairaut 定理）**。它同时给出了"什么时候一个微分形式是别人的全微分"的干净判据（$M_y = N_x$），以及"不是全微分时怎么补一个因子凑成全微分"（积分因子）的机制。后者正好把上一张卡的线性方程积分因子 $e^{\int p}$ 收编为特例。这是从"单变量微积分视角"升级到"多变量微分形式视角"的关隘。
- **验收模式说明**：本卡不设置指标/冲榜类任务；验收只看「定义复述、证明重建、反例、条件变式、闭卷验收」五项是否通过。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 我们已经会解 $y' = f(x)g(y)$（可分离）和 $y' + py = f$（线性）。但大量方程两种都不像，比如
> $$
> (3x^2 + 2y)\,dx + (2x - 3y^2)\,dy = 0.
> $$
> 它不可分离，也不是 $y' + py = f$ 的样子。
> 关键观察：左端很像**某个二元函数 $\phi(x,y)$ 的全微分** $d\phi = \phi_x dx + \phi_y dy$——如果我们能反推出 $\phi$，那么"解方程"就退化成"找 $\phi$ 的等高线"（$\phi_x dx + \phi_y dy = 0$ ⇔ $\phi(x,y) = C$）。

恰当方程理论回答三个递进的问题：
1. **什么时候** $M\,dx + N\,dy$ 真的是某个 $\phi$ 的全微分？（判别定理：$M_y = N_x$）
2. **怎么**把这个 $\phi$ 反求出来？（求势函数的两步积分法）
3. 若**不是**全微分，能否乘一个因子 $\mu$ 把 $M\,dx + N\,dy$ 变成全微分？（积分因子：把不恰当方程变成恰当方程）

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：恰当方程是初等积分法的"总后台"。
  - **可分离方程是特例**：$g(y)\,dy = f(x)\,dx$ 写成 $M dx + N dy = 0$（$M = -f$，$N = 1/g$），势函数 $\phi = F(x) + G(y)$ 是"分块"的；
  - **线性方程是积分因子理论的特例**：$y' + py = f$ 写成 $(py - f)dx + dy = 0$，其积分因子 $e^{\int p\,dx}$ 正是"只含 $x$ 的积分因子"构造的产物（§6 定理 3.3 的收尾点）；
  - **更远处**：高维的恰当性就是 $\nabla \times F = 0$ 与保守场/Green 定理/Stokes 定理；物理上的"力场有势函数 ⟺ 做功与路径无关"就是本题的物理面孔。
- **实际应用场景**：保守力场（重力、静电场）势能的存在性；热力学状态函数；流体的速度势；任何"物理量是某个函数的全微分"的建模场景。
- **高频考点**：判别恰当性；两步法求势函数（先积 $M$ 再对齐 $N$）；初值问题 + 隐式解；积分因子的"只含 $x$ / 只含 $y$"判据；"强行凑势函数"失败的识别。

最小必要背景：

3. **[[一阶线性方程]]**：$e^{\int p}$ 积分因子的来历；本卡最后会证明它只是"只含 $x$ 积分因子"的特例。
4. **[[隐函数求导]]**：对 $\phi(x,y) = C$ 求导得到 $M + N y' = 0$，反向验证解。

6. **多元微积分基础（全微分、混合偏导）**：`[[待创建:多元微分基础]]`——Clairaut 定理 $\phi_{xy} = \phi_{yx}$ 是本卡判别定理的数学根基，当前路径内尚无此卡。

## 4. 定义复述

### 1. 精确定义

**恰当方程（exact equation）**：形如
$$
M(x,y)\,dx + N(x,y)\,dy = 0
$$
的一阶方程称为恰当方程，若存在一个 $C^2$ 函数 $\phi = \phi(x,y)$ 使得
$$
d\phi = \phi_x\,dx + \phi_y\,dy = M\,dx + N\,dy,
$$
即 $\phi_x = M$ 且 $\phi_y = N$（在区域 $R$ 上逐点成立）。此时 $\phi$ 称为**势函数（potential function）**。

**积分因子（integrating factor）**：对（未必恰当的）方程 $M dx + N dy = 0$，一个不恒为零的函数 $\mu(x,y)$ 称为积分因子，若
$$
\mu M\,dx + \mu N\,dy
$$
是恰当的。乘 $\mu$ 不改变方程的解集（在 $\mu \neq 0$ 处），但把"解曲线"从非等高线族变成势函数等高线族。

**注意边界情形**：判别定理要求 $M, N$ 一阶偏导连续；积分因子要求 $\mu \neq 0$；隐式解 $\phi(x,y) = C$ 要局部解出 $y$ 需 $N = \phi_y \neq 0$（隐函数定理）。

### 2. 等价形式

| 形式 | 表述 | 适用场景 |
| :--- | :--- | :--- |
| 微分形式 | $M\,dx + N\,dy = 0$，$M_y = N_x$ | 判别与求解的标准入口 |
| 全微分形式 | $d\phi = 0$（$\phi$ 为势函数） | 理解"为什么解是等高线" |
| 向量场形式 | $F = (M, N)$ 为保守场，$\nabla \phi = F$ | 与多元微积分/物理对接 |
| 导数形式 | $y' = -M/N$（$N \neq 0$） | 与 $y' = f(x,y)$ 视角互转 |

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $M(x,y)$ | $dx$ 的系数 | $C^1$ 函数 | 势函数要求 $\phi_x = M$ |
| $N(x,y)$ | $dy$ 的系数 | $C^1$ 函数 | 势函数要求 $\phi_y = N$ |
| $\phi(x,y)$ | 势函数（$C^2$） | $R$ 上的光滑函数 | 通解为 $\phi = C$ |
| $\mu(x,y)$ | 积分因子 | 不恒为零 | 把不恰当变恰当 |
| $R$ | 讨论区域（矩形/单连通） | 开集 | $M_y = N_x$ 全局化需单连通 |

## 5. 直觉与图像

- **直觉类比/几何图像**：把 $M\,dx + N\,dy$ 想成"地形图上的一小步位移 $\mathrm{d}($高度$)$"。全微分 $d\phi$ 是真实地形（山体 $\phi$）的局部变化量；$\phi$ 的等高线是"水平路线"（$d\phi = 0$）。判别 $M_y = N_x$ 好比问："这些局部小步能否拼成一张连贯的地形图？"——如果沿任意闭合路径绕一圈回来高度不还原（$\oint M dx + N dy \neq 0$），就没有这样的地形（无势函数）。$M_y = N_x$ 保证"绕一小圈"的高度增量是 0，即局部无矛盾。
- **为什么很自然**：从微积分已知 $\phi_{xy} = \phi_{yx}$（Clairaut，混合偏导可交换）。若 $M dx + N dy = d\phi$，则 $\partial_y M = \partial_y\phi_x = \phi_{xy}$，$\partial_x N = \partial_x\phi_y = \phi_{yx}$，故 $M_y = N_x$ **自动**成立。反过来，若 $M_y = N_x$，我们用"先横后竖"的折线积分把 $\phi$ 构造出来——这是"旋度为零的场有势"在二维的最朴素证明。
- **一句话直觉本质**：**方程 $M dx + N dy = 0$ 能不能等于"某函数 $\phi$ 的等高线" $d\phi = 0$，判据就是交叉偏导 $M_y$ 与 $N_x$ 相等**；不等时，就乘个因子 $\mu$ 把这对交叉偏导"校准"到相等。

> ⚠️ 直觉只是导航，不是证明。$M_y = N_x$ 保证的是**局部**存在势函数；区域非单连通时全局可能失败（§7 反例 2）。"乘 $\mu$"也不是万能的——只有特定形状的 $\mu$ 能显式求出（§6 定理 3.3）。

## 6. 定理陈述与证明重建

### 1. 定理陈述

**定理 3.1（恰当性判别定理）**

**前提**：$M, N$ 在矩形区域 $R = I \times J$ 上 $C^1$（一阶偏导连续）。

**结论**：$M\,dx + N\,dy$ 在 $R$ 上是某个 $C^2$ 函数 $\phi$ 的全微分（即方程 $M dx + N dy = 0$ 恰当）**当且仅当**
$$
\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \quad \text{在 } R \text{ 上处处成立}.
$$

**出处**：Notes on Diffy Qs §1.8 *Exact equations*（书中把"$M_y = N_x$ ⇒ 存在势函数"的方向归功于庞加莱引理 Poincaré Lemma）。验收源说明：MIT 18.03SC Fall 2011 的 Unit I 并无恰当方程章节（已核实其课程菜单），故本节以 Diffy Qs 为主教材。

**定理 3.2（恰当方程的通解 = 势函数水平集）**

**前提**：$M dx + N dy = 0$ 恰当，$\phi$ 为其势函数。

**结论**：方程的全部解由隐式方程 $\phi(x, y) = C$ 给出；若在某点 $(x_0, y_0)$ 处 $N(x_0, y_0) = \phi_y(x_0,y_0) \neq 0$，则在 $(x_0, y_0)$ 附近可唯一解出 $y = y(x)$，且经过该点的解满足 $\phi(x_0, y_0) = C$。

**定理 3.3（只含 $x$ 的积分因子的存在性——充要条件）**

**前提**：$M, N$ 在矩形区域 $R$ 上 $C^1$，$N \neq 0$；设
$$
R_0(x) := \frac{M_y - N_x}{N}
$$
与 $y$ 无关（只含 $x$）。

**结论**：$\mu(x) = e^{\int R_0(x)\,dx}$ 是积分因子，即 $\mu M\,dx + \mu N\,dy$ 恰当。且"存在只含 $x$ 的积分因子" **当且仅当** $R_0$ 只含 $x$。

**推论（只含 $y$ 的情形）**：若 $\displaystyle S_0(y) := -\frac{M_y - N_x}{M} = \frac{N_x - M_y}{M}$ 只含 $y$，则 $\mu(y) = e^{\int S_0(y)\,dy}$ 是积分因子。

**出处**：Notes on Diffy Qs §1.8（小节 1.8.2 讨论积分因子，含"只含 $x$ 或只含 $y$"的特例）。

### 2. 证明主线（骨架）

**定理 3.1 的证明**

- **第 1 步（⇒ 方向：恰当 ⇒ $M_y = N_x$）**：设 $d\phi = M dx + N dy$，即 $\phi_x = M$，$\phi_y = N$。因 $M, N$ 是 $C^1$，$\phi$ 是 $C^2$，混合偏导连续；由 Clairaut 定理（混合偏导与求导次序无关）：
  $$
  M_y = (\phi_x)_y = \phi_{xy} = \phi_{yx} = (\phi_y)_x = N_x. \qquad \blacksquare
  $$
- **第 2 步（⇐ 方向：$M_y = N_x$ ⇒ 构造 $\phi$）**：固定 $(x_0, y_0) \in R$，用"先横后竖"的折线路径定义
  $$
  \phi(x, y) := \int_{x_0}^{x} M(t, y)\,dt + \int_{y_0}^{y} N(x_0, s)\,ds.
  $$
  直观：先从 $(x_0, y_0)$ 水平走到 $(x_0 \to x, y)$（沿当前高度 $y$ 积 $M$），再竖直从 $y_0$ 走到 $y$（沿固定 $x_0$ 积 $N$）。
- **第 3 步（验证 $\phi_x = M$）**：第一项对 $x$ 用微积分基本定理：$\dfrac{\partial}{\partial x}\int_{x_0}^x M(t,y)\,dt = M(x,y)$；第二项不含 $x$，偏导为 0。故 $\phi_x = M$。$\blacksquare$
- **第 4 步（验证 $\phi_y = N$，用上 $M_y = N_x$）**：对 $y$ 求偏导：
  $$
  \phi_y = \int_{x_0}^{x} \frac{\partial M}{\partial y}(t, y)\,dt + N(x_0, y)
  $$
  （第一项在积分号下求导，因 $M_y$ 连续故合法；第二项由微积分基本定理）。代入 $M_y = N_x$：
  $$
  \phi_y = \int_{x_0}^{x} N_x(t, y)\,dt + N(x_0, y) = \big[N(t,y)\big]_{t=x_0}^{t=x} + N(x_0, y) = N(x, y) - N(x_0,y) + N(x_0,y) = N(x,y). \qquad \blacksquare
  $$
- **关键"转念"**：(⇐) 方向的构造看起来像"背下来的公式"，实质是**用折线积分定义 $\phi$**：先把 $M$ 沿水平段积出来（把 $y$ 当参数），再用 $N$ 沿竖直段补上随 $y$ 的变化。$M_y = N_x$ 保证这两段的"衔接处"不会出矛盾——它正是"绕小矩形一圈净增量为 0"的积分版本。这个"沿路径积分定义函数 + 用可积条件保证路径无关"的模式，就是庞加莱引理/保守场定理的二维雏形。

**定理 3.2 的证明**

- **第 1 步（解必落在等高线上）**：设 $y = y(x)$ 是 $M + N y' = 0$ 的解。沿解曲线求 $\phi$ 的变化：
  $$
  \frac{d}{dx}\phi(x, y(x)) = \phi_x + \phi_y\,y' = M + N\,y' = 0,
  $$
  故 $\phi(x, y(x)) \equiv$ 常数，解躺在某条等高线 $\phi = C$ 上。$\blacksquare$
- **第 2 步（等高线就是解，收尾）**：反之，若 $\phi(x,y) = C$ 且 $\phi_y = N \neq 0$，由隐函数定理在每点邻域解出 $y = y(x)$，对等式 $\phi(x, y(x)) = C$ 求导：
  $$
  \phi_x + \phi_y\,y' = 0 \;\Longrightarrow\; M + N\,y' = 0,
  $$
  即 $y(x)$ 是原方程的解。$\blacksquare$
- **关键"转念"**：求解恰当方程 = **找等高线**。解微分方程被翻译成"画 $\phi$ 的地形图的等高线"，这是本卡最漂亮的观念跃迁。

**定理 3.3 的证明**

- **第 1 步（必要性：有只含 $x$ 的积分因子 ⇒ $R_0$ 只含 $x$）**：设 $\mu = \mu(x)$ 是积分因子，则 $\mu M\,dx + \mu N\,dy$ 恰当，由定理 3.1：
  $$
  \frac{\partial}{\partial y}(\mu M) = \frac{\partial}{\partial x}(\mu N) \;\Longrightarrow\; \mu M_y = \mu' N + \mu N_x.
  $$
  整理（$\mu \neq 0$）：
  $$
  \frac{\mu'}{\mu} = \frac{M_y - N_x}{N} = R_0.
  $$
  左边 $\mu'/\mu = (\ln\mu)'$ 只含 $x$，故右边 $R_0$ 也必须与 $y$ 无关。$\blacksquare$
- **第 2 步（充分性：构造）**：设 $R_0$ 只含 $x$，定义 $\mu(x) = e^{\int R_0\,dx}$，则
  $$
  \mu' = \mu R_0 = \mu\,\frac{M_y - N_x}{N} \;\Longrightarrow\; \mu' N = \mu M_y - \mu N_x \;\Longrightarrow\; \mu' N + \mu N_x - \mu M_y = 0.
  $$
- **第 3 步（验证乘积后恰当，收尾）**：计算
  $$
  \frac{\partial}{\partial y}(\mu M) - \frac{\partial}{\partial x}(\mu N) = \mu M_y - \big(\mu' N + \mu N_x\big) = -\big(\mu' N + \mu N_x - \mu M_y\big) = 0.
  $$
  由定理 3.1，$\mu M\,dx + \mu N\,dy$ 恰当。$\blacksquare$
- **推论（只含 $y$ 的情形）**：把 $x, y$ 角色互换：若 $\mu = \mu(y)$，则恰当条件 $\partial_y(\mu M) = \partial_x(\mu N)$ 给出 $\mu' M + \mu M_y = \mu N_x$，即
  $$
  \frac{\mu'}{\mu} = \frac{N_x - M_y}{M} = S_0(y),
  $$
  故 $\mu(y) = e^{\int S_0(y)\,dy}$。证明同构。$\blacksquare$
- **关键"转念"**：找积分因子 = 解一个一阶 ODE $\mu' = \mu R_0$。当 $R_0$ 只含 $x$ 时这正是"增长率正比于自身"，解就是 $e^{\int}$——**对数导数 $(\ln\mu)' = \mu'/\mu$ 是触发指数构造的直觉信号**。一般情形 $\mu$ 依赖 $x, y$，则需要解一个一阶偏微分方程 $\mu_y M + \mu M_y = \mu_x N + \mu N_x$，一般没有闭式解（见 §7 反例 3）。

**统一视角（线性方程 = 只含 $x$ 的积分因子）**：把 $y' + p(x)y = f(x)$ 写成微分形式 $(py - f)\,dx + dy = 0$，则 $M = py - f$，$N = 1$：
$$
R_0 = \frac{M_y - N_x}{N} = \frac{p - 0}{1} = p(x),
$$
故 $\mu = e^{\int p\,dx}$——与 [[一阶线性方程]] 的积分因子完全一致。**线性方程是"存在只含 $x$ 积分因子"的最重要特例**，两个看似独立的工具在这里统一。

### 4. 证明技巧迁移

- **"沿路径积分定义对象 + 可积条件保证一致"**：这正是保守场/路径无关线积分/庞加莱引理的核心模板，往高维（$\nabla \times F = 0$）和复分析（Cauchy-Riemann）都通用。
- **"找乘子补全导数"**：积分因子 $\mu$ 的本质是找一个乘子让表达式成为全导数——与一阶线性方程、二阶降阶法、Wronskian 一脉相承。
- **"充要条件分两半证"**：必要性靠代数整理（把恰当条件展开解出 $\mu'/\mu$），充分性靠构造 + 直接验证——这种"拆条件→构造→验算"的格式在存在性定理里是标准动作。

## 7. 经典反例库

> 数学的边界由反例划定。每个反例回答一个问题：「这个条件能省吗？」

### 反例 1：不恰当方程强行凑势函数会怎样（"$M_y = N_x$"不能省）

- **问题**：$M_y \neq N_x$ 时，硬按"积 $M$ 得 $\phi$、再对齐 $N$"的两步法会怎样？
- **反例构造**：$y\,dx + 2x\,dy = 0$。$M = y$，$N = 2x$，$M_y = 1 \neq 2 = N_x$，**不恰当**。
  - 强行凑：设 $\phi_x = M = y$，对 $x$ 积分得 $\phi = xy + g(y)$。
  - 再要求 $\phi_y = N$：$\phi_y = x + g'(y) \overset{?}{=} 2x$，即 $g'(y) = x$。
  - **矛盾**：$g$ 只允许是 $y$ 的函数，而右边 $x$ 依赖 $x$——凑不出 $g$。
  - 若硬假装 $\phi = xy$（忽略 $g$），则 $d\phi = y\,dx + x\,dy \neq y\,dx + 2x\,dy$，得到的"通解" $xy = C$ 根本不满足原方程（代回：$y + x y' = 0$ 即 $y' = -y/x$，而原方程 $y + 2xy' = 0$ 给 $y' = -y/(2x)$，不同！）。
- **结论崩塌点**：两步法第 2 步"$g'(y) = $ 某含 $x$ 的量"无法成立，根因是 $M_y \neq N_x$ 使"先积 $M$ 得到的 $\phi$ 的对 $y$ 偏导"与 $N$ 之间隔着 $\int (M_y - N_x)dx \neq 0$ 的残留。**教训**：判别恰当性是两步法的**第一动作**，不是可选项。
- **修正路径**：该方程其实是可分离的（$dx/x = -2\,dy/y$，通解 $xy^2 = C$），也可用积分因子 $\mu = x^{-1/2}$（见习题 4）——两种路线的结果应该一致，互相验证。

### 反例 2：区域非单连通时 $M_y = N_x$ 不足以给出全局势函数（"区域"条件不能省）

- **问题**：$M_y = N_x$ 逐点成立，就一定有**全局单值**势函数吗？
- **反例构造**：在 $\mathbb{R}^2 \setminus \{(0,0)\}$（挖去原点的平面）上取
  $$
  M = \frac{-y}{x^2 + y^2}, \qquad N = \frac{x}{x^2 + y^2}.
  $$
  - 计算：$M_y = \dfrac{y^2 - x^2}{(x^2+y^2)^2} = N_x$，在挖去原点的**整个区域上处处成立**。
  - 但沿单位圆正向绕一圈：$\oint_C M\,dx + N\,dy = \oint_C \dfrac{x\,dy - y\,dx}{x^2 + y^2} = \int_0^{2\pi} d\theta = 2\pi \neq 0$。
  - 绕一圈净增量非零 ⇒ 不存在**单值**势函数。局部势函数是极角 $\theta = \arctan(y/x)$，它是多值的（绕一圈 $\theta$ 增加 $2\pi$，需要砍出一条分支）。
  - 对应的 ODE：$-\frac{y}{x^2+y^2}dx + \frac{x}{x^2+y^2}dy = 0$ ⇔ $y' = y/x$，解是射线 $y = Cx$；"隐式解 $\theta = C$"在全局只能写成多值/分支形式。
- **结论崩塌点**：定理 3.1 的 (⇐) 构造沿特定折线积分定义 $\phi$；当折线绕洞一周回到原点时，积分值变了 $2\pi$——"路径无关"在非单连通区域失败。**教训**：$M_y = N_x$ 保证的是**局部**有势（庞加莱引理是局部的）；全局单值需要区域**单连通**。这是"条件依赖区域拓扑"的经典例子。

### 反例 3：既无"只含 $x$"也无"只含 $y$"的积分因子的方程（积分因子两招的边界）

- **问题**：定理 3.3 的两个特例都不适用时，方程就无解了吗？
- **反例构造**：$x^2 y\,dx + x y^2\,dy = 0$。
  - $M = x^2 y$，$N = xy^2$：$M_y = x^2$，$N_x = y^2$，$M_y - N_x = x^2 - y^2$。
  - $R_0 = \dfrac{x^2 - y^2}{xy^2} = \dfrac{x}{y^2} - \dfrac{1}{y}$：依赖 $x, y$ 两者 ⇒ 无"只含 $x$"积分因子。
  - $S_0 = \dfrac{y^2 - x^2}{x^2 y} = \dfrac{y}{x^2} - \dfrac{1}{x}$：依赖两者 ⇒ 无"只含 $y$"积分因子。
  - **但方程仍可解**：$y' = -\dfrac{x^2 y}{x y^2} = -\dfrac{x}{y}$，即 $y\,dy = -x\,dx$（可分离！），通解 $x^2 + y^2 = C$。
- **结论崩塌点**：定理 3.3 的两招只覆盖"积分因子只含单个变量"的情形；一般积分因子 $\mu(x,y)$ 存在性等价于解 PDE $\mu_y M + \mu M_y = \mu_x N + \mu N_x$，没有通用闭式算法。**教训**：判据不适用 ≠ 方程不可解——可分离性、代换等其他机制仍可能奏效。**换一个方向**：反过来，也存在真不可显式求的方程（如 $\mu$ 必须同时依赖 $x,y$ 且无初等形式的例子），这解释了为什么"找积分因子"是艺术而非算法。

## 8. 条件变式

> 把条件改一改，结论还成立吗？这是数学学习最有效的自检方式。

| 变式 | 条件改动 | 结论变化 | 成立/不成立 | 依据（证明或反例） |
| :--- | :--- | :--- | :---: | :--- |
| 弱化 1 | $M, N$ 只有 $C^0$（无偏导） | 判别定理无法陈述；需用弱解/分布框架 | 需换框架 | — |
| 换条件 1 | 区域非单连通（如挖去原点） | $M_y = N_x$ 逐点成立但无全局单值势函数 | 不成立（全局） | 反例 2：绕洞一圈增量 $2\pi$ |
| 加强 1 | $M, N$ 为 $C^\infty$ | 势函数也 $C^\infty$（正则性传递） | 成立 | 折线积分构造保留光滑性 |
| 换条件 2 | 加初值且 $N(x_0,y_0) \neq 0$ | 隐式解 $\phi = C$ 在初值附近可唯一显式化 | 成立 | 隐函数定理（定理 3.2） |
| 换条件 3 | 积分因子只含 $x$ | 需 $R_0 = (M_y-N_x)/N$ 只含 $x$，得 $\mu = e^{\int R_0 dx}$ | 成立（充要） | 定理 3.3 |
| 换条件 4 | 积分因子只含 $y$ | 需 $S_0 = (N_x-M_y)/M$ 只含 $y$，得 $\mu = e^{\int S_0 dy}$ | 成立（充要） | 推论 3.3 |
| 换条件 5 | 一般 $\mu(x,y)$ | 需解一阶偏微分方程，无通用公式 | 不一定可求 | 反例 3 |
| 换空间 | 三维 $P dx + Q dy + R dz$ | 恰当 ⟺ 旋度为零 $\nabla\times F = 0$ 且区域单连通；判据变成 3 个混合偏导条件 | 成立（需单连通） | 向量分析 / Stokes 定理 |

## 11. 分级习题

题目来源标注教材章节或 OCW 作业编号；解答独立完成，复盘阶段才对照。

### 例题（先看解答，掌握流程）

#### 例 1（基础，完整"验证→求势→通解"流程）：解 $(3x^2 + 2y)\,dx + (2x - 3y^2)\,dy = 0$。

> [!question]- 答案与解析
> - **第 1 步 验证恰当性**：$M = 3x^2 + 2y$，$N = 2x - 3y^2$。$M_y = 2$，$N_x = 2$。$M_y = N_x$ ✓ **恰当**。
> - **第 2 步 求势函数**：由 $\phi_x = M$，对 $x$ 积分（把 $y$ 当常数）：
>   $\phi = \int (3x^2 + 2y)\,dx = x^3 + 2xy + g(y)$。
>   再要求 $\phi_y = N$：$\phi_y = 2x + g'(y) = 2x - 3y^2$ ⇒ $g'(y) = -3y^2$ ⇒ $g(y) = -y^3$。
>   故 $\boxed{\phi = x^3 + 2xy - y^3}$。
> - **第 3 步 写通解**：$\phi = C$，即 $\boxed{x^3 + 2xy - y^3 = C}$。
> - **第 4 步 验证（反向）**：对 $\phi = C$ 隐式求导：$3x^2 + 2y + (2x - 3y^2)\,y' = 0$，正是原方程 ✓。

#### 例 2（中等，积分因子完整流程）：解 $y\,dx + 2x\,dy = 0$。

> [!question]- 答案与解析
> - **第 1 步 验证不恰当**：$M = y$，$N = 2x$。$M_y = 1 \neq 2 = N_x$。**不恰当**（强行凑势函数必失败，见 §7 反例 1）。
> - **第 2 步 求积分因子**：$R_0 = \dfrac{M_y - N_x}{N} = \dfrac{1 - 2}{2x} = -\dfrac{1}{2x}$，只含 $x$ ✓。故
>   $\mu = e^{\int -\frac{dx}{2x}} = e^{-\frac{1}{2}\ln x} = x^{-1/2}$。
> - **第 3 步 验证乘积后恰当**：$\mu M = x^{-1/2} y$，$\mu N = 2\sqrt{x}$。
>   $\partial_y(x^{-1/2}y) = x^{-1/2}$；$\partial_x(2\sqrt{x}) = x^{-1/2}$。相等 ✓ **恰当**。
> - **第 4 步 求势**：$\phi_x = x^{-1/2}y$ ⇒ $\phi = \int x^{-1/2} y\,dx = 2\sqrt{x}\,y + g(y)$。$\phi_y = 2\sqrt{x} + g'(y) = 2\sqrt{x}$ ⇒ $g' = 0$。故 $\phi = 2\sqrt{x}\,y$。
> - **第 5 步 通解**：$2\sqrt{x}\,y = C$ ⇒ $\boxed{y = \dfrac{C}{\sqrt{x}}}$。
> - **互验（用可分离法）**：$y\,dx + 2x\,dy = 0$ ⇒ $\dfrac{dx}{x} = -2\,\dfrac{dy}{y}$ ⇒ $\ln x = -2\ln y + C'$ ⇒ $xy^2 = C'$，即 $y = \dfrac{\widetilde C}{\sqrt{x}}$。两条路线结果一致 ✓。

### 题目与解析

#### 1. 判断下列方程哪些恰当，并说明理由；对不恰当的，演示"强行凑势函数"在哪一步失败：① $(2xy)\,dx + (x^2 + 1)\,dy = 0$；② $(y)\,dx + (2x)\,dy = 0$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案**：① $M_y = 2x$，$N_x = 2x$，**恰当**。② $M_y = 1 \neq 2 = N_x$，不恰当。
> - **解析**：②强行凑：$\phi_x = y$ ⇒ $\phi = xy + g(y)$；$\phi_y = x + g'(y) = 2x$ ⇒ $g'(y) = x$，右边含 $x$，矛盾（§7 反例 1）。
> - **易错原因**：跳过"验证恰当"直接积分；$g'(y)$ 那一步残留 $x$ 时不知为何失败。
> - **对应反例/变式**：§7 反例 1。

#### 2. 解 $2xy\,dx + (x^2 + 1)\,dy = 0$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$M_y = 2x = N_x$ ✓ 恰当。$\phi_x = 2xy$ ⇒ $\phi = x^2 y + g(y)$；$\phi_y = x^2 + g'(y) = x^2 + 1$ ⇒ $g'(y) = 1$ ⇒ $g = y$。故 $\phi = y(x^2 + 1)$，通解 $y(x^2 + 1) = C$，即 $y = \dfrac{C}{x^2 + 1}$。
> - **解析**：验证：$y' = -\dfrac{2Cx}{(x^2+1)^2}$；$2xy + (x^2+1)y' = \dfrac{2Cx}{x^2+1} - 2Cx \cdot \dfrac{1}{x^2+1} = 0$ ✓。
> - **易错原因**：$\phi_y$ 求偏导时把 $x^2 y$ 的 $y$ 偏导 $x^2$ 算漏。
> - **对应反例/变式**：例题 1 同型。

#### 3. 解 $(3x^2 + 2y)\,dx + (2x - 3y^2)\,dy = 0$ 并给出经过 $(1, 1)$ 的解。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：由例题 1，势函数 $\phi = x^3 + 2xy - y^3$。代入 $(1,1)$：$\phi(1,1) = 1 + 2 - 1 = 2$。故过 $(1,1)$ 的解为 $x^3 + 2xy - y^3 = 2$。
> - **解析**：这是定理 3.2 的"定 $C$"操作：解族是等高线，初值点定出所在等高线的高度。
> - **易错原因**：忘记把初值代入 $\phi$ 定 $C$，而非代入 $y$。
> - **对应反例/变式**：§8 换条件 2（$N(x_0,y_0) \neq 0$ 才保证可显式化）。

#### 4. 用积分因子解 $y\,dx + 2x\,dy = 0$（与例题 2 一致，独立重做一遍）。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$R_0 = (M_y - N_x)/N = (1-2)/(2x) = -1/(2x)$，只含 $x$。$\mu = x^{-1/2}$。乘积后 $\mu M = x^{-1/2}y$，$\mu N = 2\sqrt{x}$，$M_y' = x^{-1/2} = N_x'$ ✓。$\phi = 2\sqrt{x}\,y$，通解 $2\sqrt{x}y = C$，即 $y = C/\sqrt{x}$。
> - **解析**：本例题同时也是可分离的，两条路线交叉验证（§7 反例 1 的修正路径）。
> - **易错原因**：$R_0$ 的分子是 $M_y - N_x$（不是 $N_x - M_y$），符号别搞反。
> - **对应反例/变式**：定理 3.3 直接应用。

#### 5. 求积分因子并解 $2y\,dx + (x + y)\,dy = 0$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$M = 2y$，$N = x + y$。$M_y = 2$，$N_x = 1$。
>   $R_0 = \dfrac{2 - 1}{x + y} = \dfrac{1}{x+y}$：依赖 $x, y$，**无** x-型。
>   $S_0 = \dfrac{N_x - M_y}{M} = \dfrac{1 - 2}{2y} = -\dfrac{1}{2y}$：只含 $y$ ✓。$\mu(y) = e^{\int -\frac{dy}{2y}} = e^{-\frac12\ln y} = y^{-1/2}$。
>   乘积后：$\mu M = 2\sqrt{y}$，$\mu N = xy^{-1/2} + \sqrt{y}$。验证：$\partial_y(2\sqrt{y}) = y^{-1/2}$；$\partial_x(xy^{-1/2} + \sqrt{y}) = y^{-1/2}$ ✓ 恰当。
>   求势：$\phi_x = 2\sqrt{y}$ ⇒ $\phi = 2x\sqrt{y} + h(y)$；$\phi_y = xy^{-1/2} + h'(y) = xy^{-1/2} + \sqrt{y}$ ⇒ $h'(y) = \sqrt{y}$ ⇒ $h = \dfrac{2}{3}y^{3/2}$。
>   通解：$\boxed{2x\sqrt{y} + \dfrac{2}{3}y^{3/2} = C}$。
> - **解析**：这是"只含 $y$ 积分因子"的完整演示；方程本身不可分离，积分因子是必要工具。
> - **易错原因**：$S_0$ 的分子符号（$N_x - M_y$）；$e^{-\frac12\ln y} = y^{-1/2}$ 而不是 $\sqrt{y}$。
> - **对应反例/变式**：推论 3.3 直接应用。

#### 6. 把 $y' + p(x)y = f(x)$ 写成 $M dx + N dy = 0$，用定理 3.3 重现其积分因子 $e^{\int p\,dx}$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：写成 $(py - f)dx + dy = 0$，$M = py - f$，$N = 1$。$M_y = p$，$N_x = 0$。$R_0 = \dfrac{p - 0}{1} = p(x)$，只含 $x$。故 $\mu = e^{\int p\,dx}$。与 §1.4 完全一致。
> - **解析**：一阶线性方程是"存在只含 $x$ 积分因子"的最重要特例——这是两张主题卡的统一点（§6 统一视角）。
> - **易错原因**：忘记 $y' + py = f$ 对应的微分形式是 $(py - f)dx + dy = 0$（$N = 1$ 而不是 $N = dy$ 的系数之外的东西）。
> - **对应反例/变式**：定理 3.3 应用。

#### 7. （研究型）对反例 2 的 $M = \dfrac{-y}{x^2+y^2}$，$N = \dfrac{x}{x^2+y^2}$，解释为什么 $M_y = N_x$ 处处成立却没有全局势函数；能否通过"砍一刀"（选分支）得到局部势函数？
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：绕单位圆 $\oint = 2\pi \neq 0$，路径相关 ⇒ 无单值势函数（§7 反例 2）。局部取 $\theta = \arctan(y/x)$ 是一个势函数，但沿任一从 $x$-正半轴出发穿过负半轴的闭合路线 $\theta$ 跳变 $2\pi$——"砍掉一条射线"（选 $\theta \in (-\pi, \pi)$ 分支）后在单连通开区域上 $\theta$ 是单值 $C^1$ 势函数，跨过切口不连续。
> - **解析**：这是"局部有势、全局拓扑受阻"的标准样板，也是庞加莱引理为什么要求单连通的动机。
> - **易错原因**：把"处处 $M_y = N_x$"当成"全局恰当"。
> - **对应反例/变式**：§8 换条件 1。
