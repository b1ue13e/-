# 数值解法基础

---

## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具）**——数值解法是现代工程里真正"上机算"的那一套，但作为知识卡我们只深挖前两阶方法（Euler、RK4）的原理、误差与收敛性，不铺开高阶花样。
- **判断理由**：大多数初值问题根本写不出解析解（如 $y' = e^{-y^2}$ 无初等通解），数值法是人类"看得见解"的唯一途径。它同时是后面刚性方程、SDE、Neural ODE 三张卡的地基。值得深挖到"误差从哪来、为什么步长减半误差就变小"这一层。
- **验收模式说明**：本卡不设置指标/冲榜类任务；验收只看「定义复述、证明重建、反例、条件变式、闭卷验收」五项是否通过。

---

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：
> 学了分离变量、积分因子、常数变易……但打开任何一本工程书都会遇到 $y' = \sin(t y)$、$y' = \mathbf{A} y + g(y)$ 这种根本凑不出通解的方程。解析课教的所有技巧在这里全部失灵——**我们在"解写不出来"这一步卡住了**。
>
> 数值法的回答是：不求精确公式，只求"在若干个离散时间点上逼近真实解"。把时间切成一串小步 $t_0, t_0+h, t_0+2h,\dots$，每步只做一次加减乘除，就能得到一张数值解表。代价是引入**误差**，于是必须问：误差多大？步长越小误差越小吗？会累积爆炸吗？

---

## 2. 它为什么重要？它有什么用？

- **连接大图景**：不学它，后续的[[刚性方程与多步法]]、[[随机微分方程基础]]、[[神经微分方程]]全部看不懂——它们讨论的就是"在数值解里发生的现象"。scipy 的 `solve_ivp` 背后就是本节思想的工程化。
- **实际应用场景**：任何需要"解出来跑仿真"的场合——轨道计算、电路瞬态、化学反应动力学、深度学习里的 Neural ODE 前向传播（见[[项目-ODE求解器]]）。实测误差与解析解对比、判断步长是否足够细，都是本节技能。
- **高频考点**：Euler 公式的 Taylor 一阶推导；局部截断误差与全局误差的阶数区分（局部 $O(h)$、全局 $O(h)$——Euler）；RK4 局部误差 $O(h^5)$、全局 $O(h^4)$ 的陈述；收敛性定理（一致性 + 稳定性 ⇒ 收敛）。

---

## 3. 学它之前需要哪些前置知识？

最小必要背景（各 200 字以内）：

1. **[[Taylor展开一元]]**：$y(t+h) = y(t) + h y'(t) + \frac{h^2}{2} y''(t) + \cdots$。Euler 法就是从截断到一阶开始的，余项用 Lagrange 型 $O(h^2)$ 控制。这是整个误差分析的语言。
2. **[[初值问题]]**：$y' = f(t, y),\ y(t_0) = y_0$ 的表述、解的存在唯一性直觉（见 [[Picard条件]]：$f$ 对 $y$ 满足 Lipschitz 条件时解唯一）。
3. **[[微积分基础]]**：导数的几何意义（切线）、积分即面积。Euler 法的几何直觉就是"沿着切线滑一小步"。

## 4. 定义复述

### 1. 精确定义

**初值问题**：$y' = f(t, y),\quad y(t_0) = y_0,\quad t \in [t_0, T]$。记步长 $h > 0$，节点 $t_n = t_0 + n h$，精确解记为 $y(t)$，数值解记为 $y_n \approx y(t_n)$。

**一步法（单步法）**：形如
$$
y_{n+1} = y_n + h\, \Phi(t_n, y_n, h)
$$
的递推格式（$y_0 = y(t_0)$）。$\Phi$ 称为增量函数。Euler 法取 $\Phi = f(t_n, y_n)$。

**局部截断误差（local truncation error）**：把精确解代进一步法公式，每步与精确解一步演化的差距除以 $h$：
$$
\tau_n \;=\; \frac{y(t_n + h) - y(t_n)}{h} \;-\; \Phi\big(t_n, y(t_n), h\big).
$$
量词说明：$\tau_n$ 测的是"一步"的误差（已除以 $h$），假设前一步是精确的。

**全局误差（global error）**：
$$
e_n \;=\; y(t_n) - y_n, \qquad n = 0,1,\dots,N,\quad N = \lfloor (T-t_0)/h \rfloor.
$$
量词说明：$e_n$ 是所有前序误差累积后的总误差。

**方法的阶数**：若局部截断误差 $\tau_n = O(h^p)$，称方法为 $p$ 阶方法（**注意**：这指局部；全局误差通常为 $O(h^p)$，见第 6 节）。

### 2. 等价形式

| 形式 | 表述 | 适用场景 |
| :--- | :--- | :--- |
| 原始定义 | $\tau_n = \dfrac{y(t_n+h)-y(t_n)}{h} - \Phi(t_n,y(t_n),h)$ | 逐方法验证阶数 |
| 等价形式 1 | 每步"注入"的误差 $\approx h\,\tau_n = O(h^{p+1})$ | 推导全局误差的递推式 |
| 等价形式 2 | 阶数 = $\tau_n$ 展开式中 $h$ 的最低次幂 | 快速判阶（Taylor 展开） |

### 3. 符号说明表

| 符号 | 含义 | 取值范围 / 量纲 | 备注 |
| :--- | :--- | :--- | :--- |
| $y(t)$ | 精确解 | 实值/向量值函数 | 未知、待逼近 |
| $y_n$ | 数值解（第 $n$ 步） | $\approx y(t_n)$ | 可计算 |
| $h$ | 步长 | $h > 0$ | 越小越准但越贵 |
| $N$ | 总步数 | $N = (T-t_0)/h$ | 与 $h$ 反比 |
| $\Phi$ | 增量函数 | 一步法的核心 | Euler: $\Phi=f$ |
| $\tau_n$ | 局部截断误差 | $O(h^p)$ | 单步、按 $h$ 归一 |
| $e_n$ | 全局误差 | 通常 $O(h^p)$ | 累积结果 |
| $L$ | Lipschitz 常数 | $|f(t,y_1)-f(t,y_2)|\le L|y_1-y_2|$ | 收敛性证明的关键 |

## 5. 直觉与图像

- **直觉类比/几何图像**：开车导航。你只看得到当前位置 $(t_n, y_n)$ 和仪表上的瞬时速度 $f(t_n, y_n)$。下一小段怎么走？"按当前速度匀速开一小会儿"——这就是 Euler：$y_{n+1} = y_n + h\cdot f(t_n,y_n)$（**沿切线滑一小步**）。你每隔 $h$ 秒修正一次方向，步长越小，路线越贴合真实车道。
- **改进（Heun / 改进 Euler）**：先按起点切线滑到"试探点"，再看试探点的速度，**用两个速度的平均**再正式走。相当于"先探头，再平均"。
- **RK4**：滑一小段时用**四个加权探测点**（起点、中点两次、终点）的速度做加权平均：$\dfrac{k_1+2k_2+2k_3+k_4}{6}$。代价是每步 4 次函数求值，换来局部误差从 $O(h)$ 降到 $O(h^5)$。
- **为什么很自然**：Taylor 展开说 $y(t+h) = y(t) + h y'(t) + O(h^2)$，而 $y'(t)=f$，所以"保留一阶项"就是 Euler；多算几个中间点的斜率就是模仿更高阶的 Taylor 项。误差分析的本质就是**把每一步的 $\tau_n$ 乘上 $h$ 当作"新注入的误差"，看它如何在 Lipschitz 条件下被放大与累积**。
- **一句话直觉本质**：数值解 = "解写不出来时的逐步逼近"：每步截断一点、累积成总误差，步长是唯一的旋钮。

> ⚠️ 直觉只是导航，不是证明。任何直觉表述都要能回到第 4 节的精确定义（$\tau_n$ 与 $e_n$）。

## 6. 定理陈述与证明重建

### 1. 定理陈述

**Euler 法的收敛性定理（核心性质定理）**
- **前提**：$f$ 在带形区域 $[t_0,T]\times\mathbb{R}$ 上连续，且对 $y$ 满足 Lipschitz 条件（常数 $L$）：$|f(t,y_1)-f(t,y_2)|\le L|y_1-y_2|$；精确解 $y\in C^2[t_0,T]$（保证二阶导数有界，记 $M = \max |y''|$）。注：Lipschitz 条件是[[Picard条件]]里已经见过的，保证解唯一、也保证数值误差被"压缩"。
- **结论**：全局误差满足
$$
|e_n| \le \frac{e^{L(T-t_0)} - 1}{L}\, M\, h \;=\; O(h), \qquad \forall n\le N.
$$
  即 Euler 法一阶收敛，全局误差与步长成正比；步长减半，误差约减半。
- **出处**：Diffy Qs v6.11 §1.7（Euler 方法本节已核实）；收敛性精细证明为数值分析标准结果，超出主教材，见 Wikipedia: Numerical methods for ordinary differential equations [待验证]。

**RK4 的误差陈述（性质定理）**
- **前提**：$f$ 足够光滑（$C^5$ 量级）。
- **结论**：局部截断误差 $\tau_n = O(h^4)$（即每步误差 $h\,\tau_n = O(h^5)$），全局误差 $O(h^4)$。
- **出处**：超出 Diffy Qs 主教材范围，标准结果见 Wikipedia 同上条目 [待验证]。

**一致性 + 稳定性 ⇒ 收敛（理论框架）**
- **前提**：方法一致（$\tau_n \to 0$ 当 $h\to0$）且零稳定（误差递推的齐次部分不放大）。
- **结论**：方法收敛（$e_n \to 0$）。Euler 与 RK4 都满足这两条。

### 2. 证明主线（骨架）——Euler 全局误差 $O(h)$

- **第 1 步（构造递推）**：记精确解满足的步进为
  $$
  y(t_{n+1}) = y(t_n) + h\, f(t_n, y(t_n)) + h\,\tau_n,
  $$
  数值步进为 $y_{n+1} = y_n + h f(t_n, y_n)$。两式相减：
  $$
  e_{n+1} = y(t_{n+1}) - y_{n+1} = e_n + h\big[f(t_n, y(t_n)) - f(t_n, y_n)\big] - h\,\tau_n.
  $$
- **第 2 步（Lipschitz + 局部误差界）**：用 Lipschitz 条件与 Taylor 余项（$\tau_n = \frac{h}{2}y''(\xi_n)$，故 $|\tau_n|\le \frac{M}{2}h$）：
  $$
  |e_{n+1}| \le (1 + hL)\,|e_n| + h\,|\tau_n| \le (1 + hL)\,|e_n| + \frac{M}{2} h^2.
  $$
- **第 3 步（Gronwall 收口）**：反复迭代 $n$ 次并利用 $(1+hL)^n \le e^{nhL} \le e^{L(T-t_0)}$：
  $$
  |e_n| \le \frac{M}{2L} h\,\Big[(1+hL)^n - 1\Big] \le \frac{M\,(e^{L(T-t_0)}-1)}{2L}\,h = O(h).
  $$
- **关键"转念"**：**把"每一步注入的 $h\,\tau_n$"而不是 $\tau_n$ 当成误差源**——这样每步新误差是 $O(h^2)$，但被 $n = T/h$ 次累积，$h^2 \times 1/h = h$，正好掉一阶。这正是"为什么局部误差比全局误差高一阶"的核心直觉。

### 5. 数值实验（可运行 Python）

```python
# 误差对比：Euler vs RK4 vs scipy.solve_ivp
# 测试方程 y' = y, y(0)=1, 精确解 y(t)=e^t。运行：python 文件名.py
import numpy as np
from scipy.integrate import solve_ivp

def f(t, y):
    return y

T, y0 = 1.0, 1.0
exact = np.exp(T)          # y(1) = e

def euler(f, y0, h):
    t, y = 0.0, y0
    while t < T - 1e-12:
        y = y + h * f(t, y)
        t = t + h
    return y

def rk4(f, y0, h):
    t, y = 0.0, y0
    while t < T - 1e-12:
        k1 = f(t, y)
        k2 = f(t + h/2, y + h/2 * k1)
        k3 = f(t + h/2, y + h/2 * k2)
        k4 = f(t + h, y + h * k3)
        y = y + h/6 * (k1 + 2*k2 + 2*k3 + k4)
        t = t + h
    return y

print("精确解 y(1) = e ≈ %.10f" % exact)
for N in (10, 100, 1000):
    h = T / N
    e_err = abs(euler(f, y0, h) - exact)
    r_err = abs(rk4(f, y0, h) - exact)
    print(f"N={N:5d}  欧拉误差={e_err:.3e}  RK4误差={r_err:.3e}")
# 预期：N 每增大 10 倍，欧拉误差约缩小 10 倍，RK4 误差约缩小 10^4 倍

sol = solve_ivp(f, (0, T), [y0], method='RK45', rtol=1e-10, atol=1e-12)
print("scipy.solve_ivp 误差 =", abs(sol.y[0, -1] - exact))

assert abs(euler(f, y0, 1e-3) - exact) < 1e-2   # 欧拉一阶：O(h)=1e-3 量级
assert abs(rk4(f, y0, 1e-3) - exact) < 1e-8     # RK4 四阶：O(h^4)=1e-12 量级
assert abs(sol.y[0, -1] - exact) < 1e-8
print("断言全部通过：欧拉 O(h)、RK4 O(h^4)、scipy 高精度")

# --- 反例：欧拉大步长在 y'=-10y 上发散 ---
def f2(t, y):
    return -10.0 * y

def euler_steps(f, y0, h, steps):
    t, y = 0.0, y0
    for _ in range(steps):
        y = y + h * f(t, y)
        t = t + h
    return t, y

h_bad, steps = 0.3, 5                     # h*λ = 3 > 2 → |1+hλ|=2 每一步翻倍
t_end, y_end = euler_steps(f2, 1.0, h_bad, steps)
exact_end = np.exp(-10.0 * t_end)
print(f"反例：y'=-10y, h=0.3, 5 步后 t={t_end:.1f}")
print("  欧拉数值解 = %.4f（解析解 ≈ %.2e）" % (y_end, exact_end))
assert abs(y_end) > 10 and abs(exact_end) < 1e-3   # 数值爆炸，真解趋零
print("断言通过：|1+hλ|>1 时显式欧拉发散，与理论一致")
```

## 7. 经典反例库

> 数学的边界由反例划定。每个反例回答一个问题：「这个条件能省吗？」

### 反例 1：Lipschitz 条件不能省（或步长上界不能超）

- **问题**：去掉 $f$ 的 Lipschitz 连续，Euler 收敛性定理还成立吗？不成立。
- **反例构造**：$y' = y^2,\ y(0)=1$（无界右端，$\partial_y f = 2y$ 无界）。精确解 $y(t) = 1/(1-t)$ 在 $t\to 1^-$ 爆炸（有限时间爆破）。任意固定步长的 Euler 在 $t$ 接近 $1$ 时误差不可控。
- **结论崩塌点**：证明第 2 步用了 Lipschitz 常数 $L$ 把 $|f(t,y(t))-f(t,y_n)|$ 压成 $L|e_n|$；$f=y^2$ 没有全局 Lipschitz 常数，这一步失效。

### 反例 2：步长条件不能随便省——Euler 在 $y'=-\lambda y$ 大步长下发散

- **问题**：对线性衰减方程 $y' = -\lambda y\ (\lambda>0)$，$h$ 取多大都行吗？不行。
- **反例构造**：$\lambda=10,\ h=0.3$，则 $|1 + h\lambda| = |1-3| = 2 > 1$。Euler 递推
  $$
  y_{n+1} = y_n(1 - h\lambda) = -2\,y_n
  $$
  每一步幅值翻倍：$y_5 = (-2)^5 = -32$，而真解 $y(1.5) = e^{-15}\approx 3.1\times10^{-7}$。**解明明在衰减，数值却振荡放大**。这就是第 5 节 Python 里的反例。
- **结论崩塌点**：全局误差界 $O(h)$ 里的常数 $e^{L(T-t_0)}$ 只保证"不动点意义"的收敛，但步进放大因子 $|1+h\lambda|>1$ 会让误差几何级数增长——收敛性定理的界要求 $h$ 足够小（$h<2/\lambda$）。这直接通向[[刚性方程与多步法]]。

## 8. 条件变式

> 把条件改一改，结论还成立吗？这是数学学习最有效的自检方式。

| 变式 | 条件改动 | 结论变化 | 成立/不成立 | 依据（证明或反例） |
| :--- | :--- | :--- | :---: | :--- |
| 弱化 1 | 去掉 $f$ 的 Lipschitz 连续 | Euler 收敛性定理不再成立 | 不成立 | 反例 $y'=y^2$（有限时间爆破） |
| 加强 1 | $f$ 更光滑（$C^2,C^3,\dots$） | Euler 全局误差仍是 $O(h)$，不会自动升阶 | 成立（结论不变） | Taylor 余项只留到一阶 |
| 换条件 1 | $h \to h/10$ | Euler 误差约降为 $1/10$；RK4 约降为 $1/10^4$ | 成立 | 本卡第 6.5 节 Python 实测 |
| 换空间 | 向量方程组 $y\in\mathbb{R}^m$ | 结论不变，绝对值换为范数 | 成立 | 分量逐项做，Lipschitz 用范数 |
| 有限→无限 | $T \to \infty$（长期积分） | 误差按 $e^{L T}$ 增长，长时间后可能失控 | 有条件成立 | Gronwall 界的指数因子 |
| 换方法 | Euler → RK4（同 $h$） | 阶数从 $1$ 升到 $4$ | 成立 | Butcher 表消去到 $h^4$ 阶 |

### 题目与解析

#### 1. [题目 1] 判断题：局部截断误差 $O(h^2)$ 的方法，全局误差一定 $O(h^2)$。对吗？
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：不一定——取决于"局部误差"如何定义。若 $\tau_n = O(h^p)$（除以 $h$ 后的单步误差），则 $p$ 阶方法全局误差通常 $O(h^p)$；但若把单步误差写成 $O(h^{p+1})$（不除以 $h$），说法会绕晕。关键在于量词与归一化（见本卡 4.1）。
> - **解析**：欧拉 $\tau_n=O(h)$、全局 $O(h)$；RK4 $\tau_n=O(h^4)$、全局 $O(h^4)$。误差源 $h\tau_n$ 累积 $N=1/h$ 次。
> - **易错原因**：混淆"每步误差 $h\tau_n$"与"局部截断误差 $\tau_n$"。
> - **对应反例/变式**：8 节"加强 1"——$f$ 更光滑也不会让欧拉自动升阶。

#### 2. [题目 2] 用 Euler 法手算 $y' = 2xy,\ y(0)=1$ 在 $x=0.2$ 处的近似值，步长 $h=0.1$。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$y_0=1$；$y_1 = 1 + 0.1\cdot 2\cdot 0\cdot 1 = 1$；$y_2 = 1 + 0.1\cdot 2\cdot 0.1\cdot 1 = 1.02$。精确解 $y=e^{x^2}$，$y(0.2)=e^{0.04}\approx1.0408$，Euler 给 $1.02$。
> - **解析**：误差 $0.02$，量级 $O(h)$ 吻合。
> - **易错原因**：$f$ 在右端点取值时 $t$ 要取 $t_n$ 而不是 $t_{n+1}$。
> - **对应反例/变式**：改 $h=0.05$ 再算，误差约减半。

#### 3. [题目 3] 对 $y'=-10y,\ y(0)=1$，求显式 Euler 不发散的最大步长；用 $h=0.3$ 写出前两步数值解。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：稳定条件 $|1+h\lambda|<1 \Rightarrow h<2/\lambda=0.2$。$h=0.3$ 时 $y_1=-2$、$y_2=4$。
> - **解析**：真解单调衰减，数值振荡且幅值翻倍，是刚性现象的雏形。
> - **易错原因**：只记得"步长越小越准"，忘了"稳定性"这个硬约束。
> - **对应反例/变式**：见本卡 7 节反例 2。

#### 4. [题目 4] 独立重写 Euler 全局误差 $O(h)$ 的证明主线。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：$e_{n+1}=e_n+h[f(t_n,y(t_n))-f(t_n,y_n)]-h\tau_n$ → $|e_{n+1}|\le(1+hL)|e_n|+\tfrac{M}{2}h^2$ → Gronwall：$|e_n|\le \tfrac{M(e^{LT}-1)}{2L}h$。
> - **解析**：关键转念是"注入误差是 $h\tau_n$"。
> - **易错原因**：把 $h^2$ 累积写成 $N h^2 = h$（对），但忘了 Lipschitz 项 $(1+hL)^n\le e^{LT}$ 的指数放大。
> - **对应反例/变式**：换空间（向量方程）时绝对值换范数。

#### 5. [题目 5]（开放）把 Euler 换成 Heun（改进 Euler），重走证明主线，判断全局误差阶数；并用第 6.5 节脚本验证。
> [!question]- 答案与解析（复盘阶段查看）
> - **答案/证明**：Heun 局部 $\tau_n=O(h^2)$，代入递推得 $|e_{n+1}|\le(1+hL)|e_n|+Ch^3$，累积得 $O(h^2)$。
> - **解析**：证明结构完全一样，只换了局部误差阶数。这解释了"方法阶数 = 局部误差阶数 = 全局误差阶数"。
> - **易错原因**：没有先证 Heun 的局部误差，直接套结论。
> - **对应反例/变式**：自拟改造第 6.5 节脚本对比 Heun 与 Euler 的实测阶数。
