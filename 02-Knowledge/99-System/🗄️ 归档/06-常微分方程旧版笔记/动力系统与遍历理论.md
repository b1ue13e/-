## 0. 先判断它值不值得深挖

- **类别**：**B 类（常用工具）+ 延伸视野**。ODE 课程本身不需要遍历理论；但它是理解"混沌的统计行为""Lorenz 吸引子上轨道为何长期统计稳定"的唯一入口。
- **判断理由**：如果只学到 [[非线性方程定性理论]] 的平衡点/极限环，会留下错觉——"长期行为要么收敛要么振荡"。混沌系统既不收敛也不周期，却仍有**确定的统计规律**（时间平均收敛）。遍历理论解释这个"无序中的有序"。**轻量化方案**：本卡只要求定义复述 + Birkhoff 定理陈述层 + 流的群性质验证；不要求遍历证明。
- **验收模式说明**：本卡不设置指标/冲榜类任务；验收只看「定义复述、证明重建、反例、条件变式、闭卷验收」五项是否通过。

## 1. 这个知识点解决什么问题？

> **我们遇到了什么麻烦**：前面所有卡片都在问"轨线去哪"。但 Lorenz 系统（见 [[04-精通与专题/Lorenz系统]]、[[项目-Lorenz]]）的轨线**既不去平衡点、也不去周期轨**——它在一个"奇异吸引子"上永远游荡，对初值极其敏感。问题是：
> 1. 轨线永远游荡时，"状态落在某个区域的**长期比例**"还有没有规律？
> 2. 能不能用"空间平均"（对整个相空间积分）代替"时间平均"（沿一条轨线取时间平均）？
>
> **遍历理论回答**：在一定条件下，**时间平均 = 空间平均**（Birkhoff 遍历定理）。这给混沌系统一个坚实的统计基础，也是 [[Lyapunov指数]]、[[04-精通与专题/Logistic映射|Logistic 映射]] 等统计工具的理论根源。

## 2. 它为什么重要？它有什么用？

- **连接大图景**：把"一条轨线"升级为"一族轨线的长期统计"，是理解 [[04-精通与专题/混沌定义|混沌]]、[[Lyapunov指数|Lyapunov 指数]]、物理中的遍历假设（统计力学）的桥。
- **实际应用场景**：统计力学（分子在相空间中的时间平均=系综平均）、[[04-精通与专题/Logistic映射|生态/迭代系统]]、Lorenz 吸引子的数值统计、马尔可夫链的长期行为。
- **高频考点**：流的群性质验证、$\omega$/$\alpha$-极限集的定义与计算、遍历性的判定直觉（有理 vs 无理旋转）、Birkhoff 定理陈述。

## 4. 定义复述

### 1. 精确定义

设自治系统 $\mathbf{x}'=f(\mathbf{x})$，$f:D\subseteq\mathbb{R}^n\to\mathbb{R}^n$ 为 $C^1$，初值问题解存在唯一。

- **流（flow）**：映射 $\varphi:\mathbb{R}\times D\to D$，$\varphi_t(\mathbf{x}_0):=\varphi(t;\mathbf{x}_0)$。对每个固定 $t$，$\varphi_t:D\to D$ 是把初始状态推到时刻 $t$ 的映射。
- **流的群性质（semigroup/group property）**：
  $$\varphi_0=\mathrm{id},\qquad \varphi_{t+s}=\varphi_t\circ\varphi_s\quad(\forall t,s),\qquad \varphi_{-t}=\varphi_t^{-1}.$$
  即 $\{\varphi_t\}_{t\in\mathbb{R}}$ 构成一个单参数**群**（可逆同胚，若有界时刻连续依赖则 $\varphi_t$ 为同胚）。
- **轨道 / 轨线（orbit）**：$O(\mathbf{x}_0)=\{\varphi_t(\mathbf{x}_0):t\in\mathbb{R}\}$。
- **$\omega$-极限集（omega-limit set）**：
  $$\omega(\mathbf{x}_0)=\Big\{p:\ \exists\, t_n\to+\infty,\ \varphi_{t_n}(\mathbf{x}_0)\to p\Big\}.$$
  轨线"最后"的所有聚点。
- **$\alpha$-极限集（alpha-limit set）**：同上，但取 $t_n\to-\infty$。
- **不变集（invariant set）**：$S$ 满足 $\varphi_t(S)=S$ 对一切 $t$。平衡点、周期轨、$\omega$-极限集都是不变集。
- **保测变换（measure-preserving map）**：$(X,\mathcal{B},\mu)$ 为概率空间，$T:X\to X$ 可测且 $\mu(T^{-1}E)=\mu(E)$ 对所有可测集 $E$。
- **遍历变换（ergodic map）**：保测 $T$ 若所有 $T$-不变可测集满足 $\mu(E)=0$ 或 $\mu(E)=1$，则称 $T$ 遍历。**直觉**：系统"不可分解"——没有两块互不往来的子集；轨线最终逛遍"所有该逛的地方"。
- **（ODEs 版直觉）**：自治流在紧不变集上的长期行为若是"统计均匀地游走"，即遍历。

### 2. 等价形式

| 形式 | 表述 | 适用场景 |
| :--- | :--- | :--- |
| 群性质（逐点） | $\varphi_{t+s}(\mathbf{x})=\varphi_t(\varphi_s(\mathbf{x}))$ | 验证流为群 |
| $\omega$-极限集（集列） | $\omega(\mathbf{x}_0)=\bigcap_{t\ge0}\overline{\{\varphi_s(\mathbf{x}_0):s\ge t\}}$ | 证明非空/闭 |
| 遍历性（算子版） | $T$ 遍历 $\iff$ $T$-不变 $\mathcal{L}^2$ 函数几乎处处常数 | Birkhoff 的平方平均版本 |
| 时间平均 = 空间平均 | $\dfrac{1}{T}\int_0^T f(\varphi_t x)\,dt \longrightarrow \int_X f\,d\mu$（a.e.） | Birkhoff 定理结论 |

## 5. 直觉与图像

- **直觉类比/几何图像**：把相平面想成一张"地图"，流就是"跟随箭头的地图动画"。**群性质**说：先放动画 $s$ 秒、再放 $t$ 秒 = 一口气放 $t+s$ 秒；倒放 $t$ 秒能回到原点。$\omega$-极限集是"把动画无限放下去，画面最终在哪些点反复出现"（终点站集合）。**遍历性**像"在迷宫里随机漫游，长期来看每个房间被访问的比例等于房间面积占比"——时间平均=空间平均。
- **为什么很自然**：ODE 的解唯一性自动保证"从同一点出发只有一条路"（群性质里 $\varphi_s(\mathbf{x})$ 是确定状态，再从这里出发还是那条路）。而"长期比例有极限"在混沌系统里**数值上真的出现**（Lorenz 吸引子的 x-z 投影密度图），Birkhoff 定理就是它的严格化。
- **一句话直觉本质**：**流 = 状态演化的确定性动画；$\omega$-极限集 = 动画的终点站；遍历 = 终点的分布把空间"逛遍"。**

> ⚠️ 直觉只是导航，不是证明。任何直觉表述都要能回到第 4 节的精确定义。

## 6. 定理陈述与证明重建

### 定理 1：流 $\varphi_t$ 的群性质

**前提**：$\mathbf{x}'=f(\mathbf{x})$，$f$ 为 $C^1$（初值问题解存在唯一，Picard–Lindelöf，Diffy Qs §1.2.2/§3.1.5）；$f$ 在有界集上满足一致 Lipschitz 使解整体存在（或至少在公共定义域上）。
**结论**：$\varphi_0=\mathrm{id}$；$\varphi_{t+s}=\varphi_t\circ\varphi_s$；$\varphi_{-t}=\varphi_t^{-1}$；且 $(t,\mathbf{x})\mapsto\varphi_t(\mathbf{x})$ 连续（$f$ 为 $C^1$ 时对 $\mathbf{x}$ 光滑，见 [[04-精通与专题/参数连续性|参数连续性]]）。

**证明**（群性质主线）：
- **$\varphi_0=\mathrm{id}$**：初值 $\mathbf{x}$ 在时刻 $0$ 当然还是 $\mathbf{x}$。
- **$\varphi_{t+s}=\varphi_t\circ\varphi_s$（关键"转念"：重新定时 + 唯一性）**：固定 $\mathbf{x}$，定义 $u(\tau)=\varphi_{\tau}(\varphi_s(\mathbf{x}))$。则 $u(0)=\varphi_s(\mathbf{x})$，且 $u$ 满足
  $$u'(\tau)=f(u(\tau)).$$
  另一方面，$v(\tau)=\varphi_{s+\tau}(\mathbf{x})$ 也满足 $v'=f(v)$ 且 $v(0)=\varphi_s(\mathbf{x})$。**由解的唯一性** $u\equiv v$。取 $\tau=t$：$\varphi_t(\varphi_s(\mathbf{x}))=\varphi_{t+s}(\mathbf{x})$。∎
- **$\varphi_{-t}=\varphi_t^{-1}$**：由 $\varphi_{t+(-t)}=\varphi_0=\mathrm{id}$ 及 $\varphi_{(-t)+t}=\mathrm{id}$ 直接得到。
- **第 1 步的前提检查**：上面的论证只用了"唯一性"，因此若唯一性失效（$f$ 仅连续非 Lipschitz），群性质也失效——见 §7 反例 3。

### 定理 2：$\omega$-极限集的基本性质

**前提**：轨线 $O(\mathbf{x}_0)$ 有界（即 $\{\varphi_t(\mathbf{x}_0):t\ge0\}$ 相对紧）。
**结论**：$\omega(\mathbf{x}_0)$ **非空、紧、连通、不变**。
**证明骨架**：
- **非空**：$\{\varphi_{t_n}(\mathbf{x}_0)\}$ 为有界序列，取 $t_n\to+\infty$ 的子列由 Bolzano–Weierstrass 收敛。
- **紧**：$\omega(\mathbf{x}_0)=\bigcap_{t\ge0}\overline{\{\varphi_s(\mathbf{x}_0):s\ge t\}}$ 是一族递缩紧集的交，非空紧。
- **不变**：若 $p\in\omega$，取 $t_n\to\infty$ 使 $\varphi_{t_n}(\mathbf{x})\to p$；对固定 $s$，由连续依赖 $\varphi_{t_n+s}(\mathbf{x})\to\varphi_s(p)$，故 $\varphi_s(p)\in\omega$。反向（$\varphi_{-s}(p)$）由轨线有界与子列技巧同理。∎
**出处**：标准动力系统内容（Arnold《Ordinary Differential Equations》与公开讲义 [待验证]）；二维特例即 [[非线性方程定性理论]] 定理 3.1（Poincaré–Bendixson）的前提结构。

### 定理 3：Birkhoff 点态遍历定理（陈述层）

**前提**：$(X,\mathcal{B},\mu)$ 概率空间，$T:X\to X$ 保测；$f\in L^1(X,\mu)$。
**结论**：对几乎每个 $x\in X$，
$$\lim_{N\to\infty}\frac{1}{N}\sum_{k=0}^{N-1} f\big(T^k x\big) = \bar f(x)\ \text{存在},$$
且 $\bar f$ 是 $T$-不变的；若 $T$ **遍历**，则 $\bar f(x)=\displaystyle\int_X f\,d\mu$ **几乎处处等于空间平均**。连续时间版：$\dfrac{1}{T}\int_0^T f(\varphi_t x)\,dt \to \int_X f\,d\mu$（a.e.）。

**证明**：超出本课程（依赖极大遍历不等式/Maximal Ergodic Theorem，先证几乎处处存在再证常数），**本卡只陈述、不证明**。这是任务指定的诚实边界：遍历理论证明需要测度论工具（马尔可夫不等式、$L^1$ 收敛定理），不是 ODE 课程内容。

**出处**：Birkhoff (1931)。开放教材/讲义均有陈述；**本库无法逐页核实页码，引用标 `[待验证]`**。建议后续用 Arnold《Ordinary Differential Equations》或公开讲义（如 MIT、Cambridge 的 Ergodic Theory 讲义）核对后再补。

### 手算例题（本卡主例题）

**例 A（流与极限集）**：调和振子 $\mathbf{x}'=\begin{pmatrix}0&1\\-1&0\end{pmatrix}\mathbf{x}$，即 $x'=y,\ y'=-x$。
- 流：$\varphi_t(x_0,y_0)=\big(x_0\cos t+y_0\sin t,\ -x_0\sin t+y_0\cos t\big)$（旋转矩阵 $R(t)$）。
- 验证群性质：$R(t+s)=R(t)R(s)$（三角加法定理），$R(0)=I$，$R(-t)=R(t)^{-1}=R(t)^{\top}$——逐条代入即验。
- 轨道：$O(\mathbf{x}_0)=\{(x,y):x^2+y^2=x_0^2+y_0^2\}$（圆周）。因轨道周期且紧，
  $$\omega(\mathbf{x}_0)=\alpha(\mathbf{x}_0)=\text{整条圆周}.$$
  圆心 $0$ 是平衡点：$\omega(0)=\alpha(0)=\{0\}$。

**例 B（$\omega$-极限集为平衡点）**：标量 $x'=-x$。$\varphi_t(x)=xe^{-t}$。$\omega(x)=\{0\}$（$x\neq0$），$\alpha(x)=\varnothing$（$t\to-\infty$ 时 $|x|\to\infty$ 无界）。说明：$\omega$-极限集非空需要轨线有界（定理 2 前提）。

**例 C（遍历直觉的最小模型）**：圆周旋转 $T_\alpha:\theta\mapsto\theta+\alpha\pmod{2\pi}$，保 Lebesgue 测度。
- $\alpha/2\pi$ 有理（如 $\pi/2$）：每点周期为 4，轨道是 4 个点——不遍历（不变集由单条轨道组成，测度 $\ne0,1$）。
- $\alpha/2\pi$ 无理：每条轨道在圆周上**稠密**，系统遍历（Weyl 等分布定理：$\frac1N\sum f(\theta+k\alpha)\to\frac{1}{2\pi}\int f$）。
这是"时间平均 = 空间平均"最直观的成立与不成立对照。（出处：公开讲义标准内容，页码 [待验证]。）

## 7. 经典反例库

> 数学的边界由反例划定。每个反例回答一个问题：「这个条件能省吗？」

### 反例 1：不遍历的保测变换——有理旋转

- **问题**：所有保测变换都遍历吗？
- **反例构造**：$X=S^1$（圆周，Lebesgue 测度），$T:\theta\mapsto\theta+\pi/2$。则 $T^4=\mathrm{id}$，每条轨道恰好 4 个点。取 $E=\{$某个 4 点轨道$\}$，$E$ 是 $T$-不变集，但 $\mu(E)=0$ 且 $E\neq\varnothing$——不满足"不变集测度只取 $0$ 或 $1$"，故 $T$ **不遍历**。
- **结论崩塌点**：遍历定义要求"不可分解"（无非平凡不变集）；周期运动把相空间切成互不往来的有限块，时间平均只看到本块，看不到全局。
- **教训**：周期轨道 ≠ 遍历；遍历需要"轨道密度足够高"（对无理旋转成立）。

### 反例 2：$\omega$-极限集为空——轨线无界时定理 2 前提失效

- **问题**：$\omega(\mathbf{x}_0)$ 一定非空吗？
- **反例构造**：标量 $x'=x$（$x\neq0$）。$\varphi_t(x)=xe^t\to+\infty$，无有界轨道；对任何 $p$，$\varphi_{t_n}(x)\to p$ 不成立，$\omega(x)=\varnothing$。
- **教训**：定理 2 的"轨线有界"前提不可省；有界性是 $\omega$-极限集存在的命根子。

### 反例 3：唯一性失效 → 流无法良好定义

- **问题**：$\varphi_t$ 一定是个（确定的）映射族吗？
- **反例构造**：$x'=3x^{2/3}$（$f$ 连续但不 Lipschitz，见 [[相平面与轨线分析]] 反例 1）。过 $x=0$ 的解不止一条（$x\equiv0$ 与 $x(t)=t^3$），$\varphi_t(0)$ 的值不唯一，$\varphi_t$ 不是良定义的函数，群性质无从谈起。
- **教训**：群性质的成立依赖 Picard 唯一性；"流"是唯一性定理的产物。这就是为什么本卡把 [[解的存在唯一性定理]] 列为首要前置。

## 8. 条件变式

> 把条件改一改，结论还成立吗？这是数学学习最有效的自检方式。

| 变式 | 条件改动 | 结论变化 | 成立/不成立 | 依据（证明或反例） |
| :--- | :--- | :--- | :---: | :--- |
| $f$ 仅连续（去 Lipschitz） | 唯一性失效 | 流 $\varphi_t$ 无良定义 | 不成立 | 反例 3（$x'=3x^{2/3}$） |
| 轨线无界 | 去掉有界性 | $\omega$-极限集可空 | 不成立 | 反例 2（$x'=x$） |
| 旋转角有理 | 无理 → 有理 | 遍历 → 不遍历 | 不成立 | 反例 1 |
| 相空间紧 + 保测 | 非紧/无不变概率测度 | Birkhoff 前提（$\mu(X)<\infty$）破坏 | 不成立 | 定理 3 前提，Lorenz 需构造吸引子上测度 |
| 二维 → 三维 | 极限集结构升级 | $\omega$-极限集可非周期（混沌吸引子） | 不成立（结构变复杂） | Lorenz，Diffy Qs §8.5.2 |
| 周期轨上的遍历性 | 周期轨 → 取一条闭轨 | 沿闭轨取时间平均 = 沿闭轨空间平均（退化成立） | 成立 | 周期轨上的 $T$ 是圆旋转的特例 |

### 题目与解析

#### 1. 验证流的群性质
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：对 $x'=x,\ y'=2y$ 写出流 $\varphi_t$ 并验证群性质。
> - **答案/证明**：$\varphi_t(x_0,y_0)=(x_0e^t,\ y_0e^{2t})$。$\varphi_0(x_0,y_0)=(x_0,y_0)$；$\varphi_t(\varphi_s(x_0,y_0))=\varphi_t(x_0e^s,\ y_0e^{2s})=(x_0e^{s+t},\ y_0e^{2(s+t)})=\varphi_{s+t}(x_0,y_0)$。∎
> - **解析**：指数族 $\varphi_t=e^{tA}$，$A=\mathrm{diag}(1,2)$，$e^{(s+t)A}=e^{sA}e^{tA}$ 就是群性质。
> - **易错原因**：把 $\varphi_t$ 当普通函数复合，忘记它是对"状态"作用。
> - **对应反例/变式**：定理 1。

#### 2. 计算 $\omega$ 与 $\alpha$-极限集
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：对 $x'=-y,\ y'=x$（中心）与 $x'=-x,\ y'=-2y$（稳定结点），分别求 $\omega(\mathbf{x}_0)$ 与 $\alpha(\mathbf{x}_0)$。
> - **答案/证明**：中心：$\omega(\mathbf{x}_0)=\alpha(\mathbf{x}_0)=\{(x,y):x^2+y^2=x_0^2+y_0^2\}$（整条圆周，见例 A）。稳定结点：$\omega(\mathbf{x}_0)=\{(0,0)\}$（一切轨线收敛原点），$\alpha(\mathbf{x}_0)=\varnothing$（$t\to-\infty$ 无界）。
> - **解析**：$\omega$ = "终点站"，$\alpha$ = "出发站"；周期轨两者相同。
> - **易错原因**：忘记 $\alpha$ 用 $t\to-\infty$。
> - **对应反例/变式**：例 A、B。

#### 3. 遍历 vs 不遍历
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：说明 $T_\alpha:\theta\mapsto\theta+\alpha$ 在 $S^1$（Lebesgue）上，$\alpha=2\pi/3$ 时不遍历。
> - **答案/证明**：$\alpha/2\pi=1/3$ 有理，$T^3=\mathrm{id}$；任取单点轨道 $E=\{\theta_0\}$，$E$ 不变但 $\mu(E)=0$、$E\neq\varnothing$，不满足遍历定义。
> - **解析**：周期运动把 $S^1$ 切成 3 块互不往来；时间平均只看到自己那 3 个点。
> - **易错原因**：混淆"每条轨道密否"与"遍历"（有理旋转轨道既不稠密也不遍历）。
> - **对应反例/变式**：反例 1。

#### 4. $\omega$-极限集与 P–B
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：把 [[非线性方程定性理论]] 定理 3.1（Poincaré–Bendixson）用 $\omega$-极限集语言重述。
> - **答案/证明**：二维自治系统若有界闭区域内无临界点，则轨线的 $\omega$-极限集是一条周期轨（闭轨）。即：**二维有界无临界点时，$\omega$-极限集只能是闭轨。**
> - **解析**：本卡定理 2 保证 $\omega$ 非空紧不变，P–B 进一步压缩它的形态。
> - **易错原因**：高维误用（$\omega$ 可以是奇异吸引子）。
> - **对应反例/变式**：反例 3（三维）。

#### 5. Lorenz 吸引子的统计行为（开放）
> [!question]- 答案与解析（复盘阶段查看）
> **题干**：对 Lorenz 系统做数值实验：从随机初值出发积分 $t\in[0,1000]$，统计 $x(t)$ 落在 $[-20,20]$ 网格直方图；换初值再统计，比较两直方图是否"长得像"。说明这在直觉上对应遍历理论的什么内容。
> - **答案/证明**：两直方图随 $t$ 增大趋于同一密度（吸引子上有唯一"物理"不变测度——SRB 测度，[待验证]）；这正是"时间平均 ≈ 空间平均"在耗散系统上的体现（须在吸引子上取不变测度，而非整个 $\mathbb{R}^3$）。
> - **解析**：数值上可直接观察；严格理论（SRB 测度存在性）属高级动力系统，超出本卡。
> - **易错原因**：直接对整个相空间用 Birkhoff（$\mu(X)<\infty$ 前提不满足）。
> - **对应反例/变式**：下方 Python 程序。

## 附：可运行 Python——Lorenz 奇异吸引子与初值敏感

```python
import matplotlib
matplotlib.use('Agg')          # 无显示器环境用 Agg；交互环境可删此行
import numpy as np
import matplotlib.pyplot as plt

# Lorenz 系统 (sigma=10, rho=28, beta=8/3)：混沌/奇异吸引子
def lorenz(s, sigma=10.0, rho=28.0, beta=8.0/3.0):
    x, y, z = s
    return np.array([sigma*(y-x), x*(rho-z)-y, x*y - beta*z])

def rk4(s, dt, N):
    sol = np.zeros((N, 3)); sol[0] = s
    for i in range(1, N):
        k1 = lorenz(sol[i-1]); k2 = lorenz(sol[i-1]+dt/2*k1)
        k3 = lorenz(sol[i-1]+dt/2*k2); k4 = lorenz(sol[i-1]+dt*k3)
        sol[i] = sol[i-1] + dt/6*(k1 + 2*k2 + 2*k3 + k4)
    return sol

dt, N = 0.005, 20000
sol = rk4(np.array([1.0, 1.0, 1.0]), dt, N)
x, y, z = sol[:,0], sol[:,1], sol[:,2]

# --- x-z 平面投影的"蝴蝶"吸引子 ---
plt.figure(figsize=(6,5))
plt.plot(x, z, lw=0.4, color='C0')
plt.xlabel('x'); plt.ylabel('z')
plt.title('Lorenz attractor, x-z projection  (t in [0,100])')
# 预期输出：x 在 [-18.7, 19.6]、z 在 [1.0, 47.8] 的蝴蝶形吸引子。

# --- 初值敏感：x0 相差 1e-9，t=100 时轨道已几乎不相关 ---
s2 = np.array([1.0 + 1e-9, 1.0, 1.0])
sol2 = rk4(s2, dt, N)
d = np.hypot(sol[:,0]-sol2[:,0], sol[:,1]-sol2[:,1])
print("t=0 separation: 1e-9   |   t=100 separation: %.2f" % d[-1])
# 预期输出：t=100 separation 约为 20 量级（混沌：微小初值差指数放大，Lyapunov 指数为正）
plt.figure(figsize=(6,4))
plt.semilogy(np.arange(N)*dt, d + 1e-300)
plt.xlabel('t'); plt.ylabel('distance'); plt.ylim(1e-12, 1e3)
plt.title('Sensitive dependence on initial conditions')
plt.tight_layout(); plt.savefig('lorenz.png', dpi=150)
```
