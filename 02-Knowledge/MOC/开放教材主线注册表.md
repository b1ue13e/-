# 开放教材主线注册表

> 本表是 33 门课程的**知识主线真值源**。阅读与笔记以开放教材/官方免费教材为主，课程作业只负责验收，软件仓库只负责实验。

## 硬规则

1. 优先级：`明确开放许可教材 > 作者/机构官方免费教材 > 官方课程讲义 > 软件文档 > 其他材料`。
2. `official-free` 只代表可从官方页面免费阅读，**不代表允许再分发或改编**。
3. 本库默认只保存链接、章节定位和自己的笔记；只有明确许可时才镜像原文/源码。
4. 知识卡不能只写课程首页；必须写 `locator` 到 Chapter / Section / Assignment。
5. 若主教材覆盖不完整，在课程页标注缺口，不用无来源生成内容填补。

## 笔记写入要求

```yaml
sources:
  - title: "Open textbook title"
    url: "https://official-source/..."
    locator: "Chapter 3 / Section 3.2"
    source_type: open-textbook
    license: "CC BY-SA 4.0 | official-free | page-specific"
    verified_at: 2026-08-02
```

- 定义、定理、公式和算法边界必须能回到主教材的具体位置。
- 作业页支持“完成什么”，不自动支持“某条事实正确”。
- 代码库支持 API 和可运行实现，不单独替代理论来源。
