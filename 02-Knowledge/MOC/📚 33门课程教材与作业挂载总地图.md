## 🛠️ 阶梯作业 4-Tier Baseline 规范

每一门课程的作业均在 `03-Projects/` 建立相应的 4-Tier 阶段：

```
🟢 L1 - Simple Baseline   │ 调包/跑通官方 API / 基础公式手算
🟡 L2 - Medium Baseline   │ 模块推导 / 特征工程 / 调参优化
🔴 L3 - Strong Baseline   │ [核心] 从零手撕核心底层算法（不调库，PyTest 自测校验）
👑 L4 - Boss Baseline     │ Kaggle / Top 竞赛冲榜 / 形式化证明 (Lean 4/Coq)
```
