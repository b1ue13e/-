# 权威课程与作业来源白名单

> 本页记录已经核验的**来源入口、可承担的角色和复用边界**。白名单不等于可以复制：课程题目、Starter、数据、第三方素材和答案分别受许可证、课程政策与 Honor Code 约束。

## 来源优先级

`明确开放许可教材 > 作者/机构官方免费教材 > 官方课程讲义 > 官方作业 > 软件文档 > 其他材料`。知识主线统一从 [[02-Knowledge/MOC/开放教材主线注册表|开放教材主线注册表]] 进入；作业白名单不再兼任教材清单。

## 使用规则

1. **知识卡来源**：优先引用教材章节、原始论文、官方文档或课程讲义，并写明章节/作业编号；只有课程主页链接不算完成事实核验。
2. **作业来源**：默认 `link-only`。本地只保存自己的题目拆解、实验日志和答案，不复制或公开官方解答。
3. **代码复用**：只有仓库或具体文件存在明确许可证时才可复制；课程网页公开访问不等于代码获准再分发。
4. **版本冻结**：激活课程时记录 `source_url`、学期/commit、许可证核验日期、数据条款和解答可见性。
5. **时间敏感页面**：Stanford、Berkeley 等课程页可能每学期更新；执行前重新核验，不把当前作业数量永久写死到模板逻辑。

## 来源等级

- **S 级**：原始论文、标准、官方文档、作者/机构官方教材；可直接支持定义、公式、算法和边界。
- **A 级**：大学官方课程讲义与作业；适合课程结构、例题和验收设计，事实性结论仍尽量定位到具体讲义页。
- **B 级**：官方软件仓库与示例；适合 API、工程流程和可运行验证，不单独替代理论来源。
- **禁用作唯一来源**：搜索摘要、聚合转载、无作者博客、答案仓库、AI 生成文本。

## 写入知识卡的最小来源记录

```yaml
sources:
  - title: "来源标题"
    url: "https://..."
    locator: "Chapter / Section / Assignment"
    source_type: paper | textbook | official-doc | course
    verified_at: 2026-08-02
```

正文至少说明“该来源支持哪一条定义、公式、实现或边界”，避免只堆链接。
