# Mathematics for Machine Learning

> 本课程（17-机器学习）的**数学底座 Spine**。本页为来源注册与获取入口，非教学内容；用于补线性代数、概率与连续优化的形式化语言。

## 教材定位

- 作者：Marc Peter Deisenroth, A. Aldo Faisal, Cheng Soon Ong
- 角色：为线性模型、正则化、泛化理论与表示学习提供数学背景（线性代数、概率、连续优化）。
- 与主线映射：Chapter 2（线性代数）、Chapter 3（解析几何）、Chapter 6（概率）、Chapter 7（优化）对应各阶段数学前置。
