# 属性数据分析-大作业-真实离散数据端到端建模与诊断报告

## 🎯 学习目标
1. 综合运用属性数据分析全课程数理推导与建模方法，独立完成从探索性列联分析、GLM 建模到严苛诊断的端到端项目；
2. 掌握二项分类、事件计数与有序等级多模态离散数据的建模选型逻辑；
3. 熟练掌握 Hosmer-Lemeshow 检验、过度离散检验（Poisson vs NB2）、完全分离诊断及比例优势检验等工业与学术级诊断；
4. 产出具备严谨统计学推断依据与业务/科研决策指导价值的综合数据分析报告。

## 📝 详细任务指引与步骤

### 实战项目架构
学习者需选择一个核心场景（推荐以 173 条马蹄蟹伴侣研究或 84 例关节炎临床试验为主线），完成四大标准阶段：

### 阶段一：探索性数据分析 (EDA) 与列联推断
1. 绘制核心分类变量的双向/分层列联表；
2. 计算 Pearson $X^2$、似然比 $G^2$ 统计量及标准化 Pearson 残差 $r_{ij}$；
3. 计算未调整优势比（OR）及其 Woolf 95% 置信区间；
4. 检查是否存在稀疏单元格（$\hat{\mu}_{ij} < 5$）或零频数情况。

### 阶段二：GLM 统计建模与假设检验
1. 根据响应变量特征（二元/计数/有序）选取合适的 GLM 理论分布族与链接函数；
2. 引入连续自变量、哑变量及必要交互项；
3. 使用似然比检验（Deviance drop）与 Wald 检验进行变量筛选与效应评估。

### 阶段三：严苛模型诊断与模型扩展
1. **二分类模型**：计算 Hosmer-Lemeshow 拟合优度检验统计量，检查是否存在完全分离（Separation），绘制 ROC 曲线与校准曲线；
2. **计数模型**：计算 Pearson 分散参数 $\hat{\phi} = X^2/\text{df}$，检验过度离散，若存在则升级为负二项回归（NB2）；
3. **有序模型**：执行比例优势假设检验（Brant 检验 / LRT）。

### 阶段四：消融实验与最终决策报告
1. 构建基线模型与最终优化模型的对比表格（Log-Likelihood, AIC, BIC, Deviance）；
2. 撰写结构化分析报告：包括问题背景、方法论、模型参数几率比/IRR 解释、局限性与风险边界。
