# 属性数据分析-课后作业-01-列联表手算与卡方独立性检验

## 🎯 学习目标
1. 熟练掌握 $2 \times 2$ 与 $I \times J$ 列联表在独立性原假设下的期望频数 $\hat{\mu}_{ij} = \frac{n_{i+}n_{+j}}{n}$ 闭卷手算；
2. 独立推导并计算 Pearson 卡方统计量 $X^2$ 与似然比卡方统计量 $G^2$（Deviance）；
3. 计算每个单元格的标准化 Pearson 残差 $r_{ij}$，定位偏离独立性的具体组别；
4. 使用 Python / R 编写自动化复核脚本，验证手算结果的数值精确度。

## 📝 详细题目与任务指引

### 题目背景
某临床试验评估一种新型降压药对高血压患者的达标效果，收集到 120 例患者数据如下：

| 组别 | 血压达标 ($Y=1$) | 血压未达标 ($Y=0$) | 行合计 ($n_{i+}$) |
| :--- | :---: | :---: | :---: |
| **新药组 ($X=1$)** | 42 | 18 | 60 |
| **对照组 ($X=2$)** | 24 | 36 | 60 |
| **列合计 ($n_{+j}$)** | 66 | 54 | 120 |

### 任务步骤
1. **计算期望频数矩阵**：
   - 写出独立性原假设 $H_0: \pi_{ij} = \pi_{i+}\pi_{+j}$；
   - 手工计算 4 个单元格的期望频数 $\hat{\mu}_{11}, \hat{\mu}_{12}, \hat{\mu}_{21}, \hat{\mu}_{22}$；
2. **计算假设检验统计量**：
   - 计算 Pearson 卡方统计量 $X^2 = \sum \frac{(n_{ij}-\hat{\mu}_{ij})^2}{\hat{\mu}_{ij}}$；
   - 计算似然比检验统计量 $G^2 = 2 \sum n_{ij} \ln(n_{ij} / \hat{\mu}_{ij})$；
   - 确定自由度 $\text{df} = (I-1)(J-1) = 1$，查表在 $\alpha = 0.05$（临界值 $\chi^2_1(0.05) = 3.841$）下给出统计推断结论；
3. **计算关联效应量与标准化残差**：
   - 计算新药组相对对照组的优势比 $\hat{\theta} = \frac{n_{11}n_{22}}{n_{12}n_{21}}$；
   - 计算对数标准误 $\text{SE}(\ln\hat{\theta}) = \sqrt{\frac{1}{n_{11}} + \frac{1}{n_{12}} + \frac{1}{n_{21}} + \frac{1}{n_{22}}}$ 并给出 95% 置信区间；
   - 计算新药达标单元格的标准化残差 $r_{11} = \frac{n_{11}-\hat{\mu}_{11}}{\sqrt{\hat{\mu}_{11}(1-p_{1+})(1-p_{+1})}}$ 并进行医学解释；
4. **代码复核**：
   - 编写 Python 脚本运行 `scipy.stats.chi2_contingency` 输出检验结果，核对手算数值。
