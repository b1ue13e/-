# 评测数据

`eval_cases.jsonl` 是课程原创的确定性离线验收集，共 40 条：

- 20 条正常样本：验证状态机完成、评分和工具轨迹。
- 10 条异常样本：验证空输入、缺证据、非法分数和重复故障失败关闭。
- 10 条对抗样本：验证恶意证据不会获得动作权限。

每行一个 UTF-8 JSON 对象，`id` 唯一；`expected_status` 和可选的 `expected_score` 是逐样本事实源。`scripts/run_eval.py` 会校验 20/10/10 分片、执行全部样本并把实际结果写入 `artifacts/eval/latest.json`。

该数据只验证课程本地标准库控制面，不代表真实模型、在线协议或生产攻击覆盖。
