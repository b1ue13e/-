# 测度论-大作业-测度到概率的定理依赖档案

## 学习目标

- 建立从可测结构到概率测度的可审阅定理依赖图。
- 独立重建四条代表性证明，并为关键假设配对反例。
- 把推前测度、期望、弱收敛与前面三阶段的结果连接起来。
- 通过书面档案、错误分析和口头验收展示跨阶段迁移能力。

## 任务边界

项目只要求测度论主线和一个最小概率迁移，不要求实现 Lean、数值模拟、完整概率论或 Fourier 分析。所有证明必须独立书写；公开教材只用于定位和复盘，不提交答案转录。

## 环境与允许资源

- 预计用时：12–16 小时，建议按结构图、证明、反例、概率迁移、口试五个检查点提交草稿。
- 工具：Markdown/LaTeX 与任意画图工具；不要求代码。最终 PDF 必须可搜索文本。
- 允许引用：课程来源索引中的章节与讲次；禁止复制教材或网络解答，所有外部提示写入 `reflection.md`。

## 必做模块

1. **结构图**：σ-代数 → 外测度/可测集 → 可测函数 → 积分 → 收敛定理 → `L^p` → RN/条件期望 → 概率测度。
2. **四个完整证明**：生成 σ-代数最小性、MCT 或 Fatou、`L^p` 完备性核心步骤、RN 唯一性。
3. **四个反例**：Vitali 或不可测边界、DCT 缺控制、`p<1` 非范数、非绝对连续无密度。
4. **概率迁移**：把一个离散随机变量写成推前测度，计算期望，并用有界连续测试函数解释一个弱收敛例子。
5. **口头验收**：8 分钟内不看稿解释主依赖图和两个失败条件。

## 必要提示、常见失败与可选进阶

- 必要提示：每个证明先写“输入假设—关键接口—输出结论”；每个反例写“删除的条件—仍满足的条件—失败结论”。
- 常见失败：依赖图只有名词没有箭头理由；RN 与 `L^p` 证明只写骨架；弱收敛直接推出期望收敛；把本地项目说成官方作业。
- 可选进阶：增加一个自选定理的第二证明，或制作 5 分钟公开讲解视频。进阶不替代任何必做模块。

## 完成后的复盘入口

## 评分细则
