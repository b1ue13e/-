# 测度论-阶段作业-03-Lp与Radon-Nikodym

## 学习目标

- 用 Hölder/Minkowski 建立 `L^p` 范数结构，并区分 `p<1`。
- 分别重建 `1≤p<∞` 与 `p=∞` 的完备性证明接口。
- 准确陈述有限符号测度版 RN 定理并证明 a.e. 唯一性。
- 把 RN 表示迁移到条件期望存在性，同时保留 `L^1`/`L^2` 边界。

## 任务边界

本作业不要求完整证明 Hahn 分解、谱定理或一般 Banach 空间理论；只使用 Axler Ch.7 和 Ch.9 已列出的 Lp、实/复测度与 RN 结果。若采用正交投影解释，必须另写 X 属于 L2 的附加假设。

## 环境与允许资源

- 预计用时：4–5 小时；完备性与 RN 两部分分开完成。
- 工具：纸笔或 Markdown；不需要代码或数值实验。
- 允许引用：Hölder、Minkowski、Riesz 表示和 Jordan 分解的准确陈述；被要求的证明步骤必须展开。

## 任务

1. 陈述 Hölder 与 Minkowski 不等式，说明各自如何支撑 `L^p` 范数。
2. 写出 `L^p` 完备性证明骨架：快速收敛子列、绝对可和控制、a.e. 极限、范数收敛。
3. 构造 `p<1` 时三角不等式失败的例子。
4. 陈述 RN 定理的假设、结论和 a.e. 唯一性，证明唯一性。
5. 用 `δ_0` 与 Lebesgue 测度说明绝对连续条件不能删除。
6. 从 RN 定理推出 `E[X|G]` 的存在性；若使用正交投影视角，明确附加 `X∈L²`。

## 提交产物

- 六题证明稿。
- 一页“测度、密度、条件期望”概念对照。

## 自检

- RN 链式法则方向必须与绝对连续关系一致。
- “唯一”必须写成“模 μ-a.e. 唯一”。
- 总分 ≥75 方可进入第四阶段。

## 必要提示、常见失败与可选进阶

- 必要提示：完备性证明先抽快速子列；RN 先处理有限正测度，再拼接 σ-有限分块，最后处理符号测度。
- 常见失败：把 `p=∞` 塞进有限 `p` 的 MCT/DCT 证明；把绝对连续写成双向；对一般 `L^1` 条件期望直接使用正交投影。
- 可选进阶：证明 RN 链式法则，或在有限分割生成的子 `σ` 代数上显式计算条件期望。进阶不计入阶段门槛。

## 完成后的复盘入口

提交后记录一项最难复现的定义、一处证明断点和一个条件反例。若同一错误出现两次，将对应知识卡标记为薄弱点并进入复习系统；通过后再进入课程路径中的下一阶段。

## 评分细则

Lp 完备性部分按“快速子列、绝对可和控制、a.e. 极限、范数收敛”四步计分；RN 部分按假设、表示、a.e. 唯一性计分；条件期望部分必须写出子 σ-代数和可积性。把 L2 投影条件套到一般 L1 情形会扣除条件分。

## 引导检查点

先列出每个结论的最小假设，再尝试删掉一个假设并寻找反例。RN 链式法则先画绝对连续关系箭头，再决定导数相乘顺序。
