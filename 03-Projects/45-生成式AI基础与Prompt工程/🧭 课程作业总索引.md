# 生成式 AI 基础与 Prompt 工程作业总索引

本页只按 `assignment_level`、`stage_id` 与 `requires` 派生入口。作业题面、知识依赖和完成状态以各作业文件 frontmatter 为唯一事实源。

## 使用顺序

1. 前置诊断不通过时，只做 `stage_id: "00"` 的课后作业。
2. Prompt 主线依次完成阶段 1、3、4；阶段 2 的模型实现作业按目标选做。
3. 每项提交先跑离线协议 Gate，再接真实模型或新数据；离线 fixture 分数不得写成模型能力结论。
4. 完成至少一项阶段 4 作业后再进入大作业。

## 阶段通过规则

| 阶段 | 最小作业证据 | 通过标准 |
| :---: | :--- | :--- |
| 00 | Python/JSON/Softmax 诊断 | 命令可复现、断言通过、错误输入失败关闭 |
| 01 | 生成循环与 Transformer 最小实验 | 能解释 shape、mask、解码并保留测试证据 |
| 03 | Prompt 基线、受控实验、分解 | 冻结数据与配置，只改一个变量，提交逐样本错误分析 |
| 04 | RAG、Judge、事实核验、安全 | 引用/拒答、人工校准、注入回归和人工接管策略齐全 |
| 结课 | 新数据上的可追溯 Prompt 系统 | 复现、有效性、可靠性和安全四类证据同时通过 |
