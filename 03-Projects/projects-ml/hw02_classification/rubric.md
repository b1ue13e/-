# HW02 Classification Rubric

## 一票否决项

- 测试集参与标准化、模型选择或调参；
- 提交第三方答案、权重或无法解释的代码；
- 伪造分数、日志或实验次数；
- `prediction.csv` 的 `Id,Class` 契约不合法；
- 无法从 README 命令复现最终结果。

## 100 分评分表

| 维度 | 分值 | 通过标准 |
|:---|---:|:---|
| 数据契约与泄漏控制 | 15 | 文件、形状、39 类、分层划分和训练集标准化说明清楚 |
| 可运行性与正确性 | 25 | 训练、checkpoint、推理和提交全链路通过测试 |
| Baseline 与实验设计 | 20 | 至少有 Simple/Medium 对照，固定种子和主要变量 |
| 评价与错误分析 | 20 | 同时报 Accuracy、macro-F1、混淆矩阵和主要错分类别 |
| 复现与工程质量 | 10 | 命令、环境、输出路径、随机种子和失败日志齐全 |
| 解释与知识反哺 | 10 | 能解释交叉熵、类别边界和最有效改动，并回链知识卡 |
| **总计** | **100** | **75 分通过；不得触发一票否决项** |
