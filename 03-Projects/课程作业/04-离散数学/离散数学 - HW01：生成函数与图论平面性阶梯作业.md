# 离散数学 - HW01：生成函数与图论平面性阶梯作业

> 🎯 **作业目标**：手写真值表推导、求解生成函数递推关系，证明 Kuratowski 平面图定理推论。

---

## 1. ⚙️ 环境与 Starter Code 准备
- **求解工具**：`SymPy` / `Lean 4`
- **开源标杆仓库**：[MIT 6.042J Mathematics for Computer Science](https://ocw.mit.edu/courses/6.042j-mathematics-for-computer-science-fall-2010/)
- **核心依赖**：`sympy`, `pytest`

## 2. 🎯 阶梯式 Baseline / 难度设计 (4-Tier Difficulty)

| 梯度级别 | 目标 / 验收标准 | 关键实现细节与要求 |
| :--- | :--- | :--- |
| 🟢 **L1 - Simple Baseline** | 真值表验证等价性 | 编写 Python 脚本验证主范式与逻辑蕴含关系。 |
| 🟡 **L2 - Medium Baseline** | 求解封闭解 $a_n$ | 用生成函数 (Ordinary Generating Functions) 求解二阶线性递推方程 $a_n = 5a_{n-1} - 6a_{n-2}$。 |

| 👑 **L4+ - 极客拓展** | **Lean 4 形式化证明** | 在 Lean 4 交互式证明器中完成 De Morgan 律与群论基本定理的形式化证明。 |

## 3. 🧪 自动化测试 Harness (SymPy Validation)

```python
import sympy as sp

def test_generating_function_coefficients():
    x = sp.Symbol('x')
    n = sp.Symbol('n', integer=True, positive=True)
    
    # G(x) = 1 / (1 - 5*x + 6*x**2)
    G = 1 / (1 - 5*x + 6*x**2)
    series_coeffs = sp.fps(G, x, 0).truncate(6)
    
    # 闭式解: a_n = 3^n - 2^n
    # n=3: 27 - 8 = 19
    a3 = 3**3 - 2**3
    assert a3 == 19
```

## 🃏 Anki 卡片

- Q: 为什么完备图 $K_5$ 是非平面图 (Non-planar Graph)？请用欧拉公式给予简要证明。
- A: 若 $K_5$ 为平面图，由欧拉公式 $V-E+F=2$，已知 $V=5, E=10$，得 $F=7$。但每个面至少由 3 条边围成，故 $2E \ge 3F \implies 20 \ge 21$，产生矛盾。
