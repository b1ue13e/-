# 离散数学-课后作业-01：生成函数与递推关系

> **范围**：课后作业（lesson）· 问题集（problem-set）· 阶段3（生成函数模块）。

## 1. 学习目标

完成本作业后，你应该能够：

1. 对一个给定递推关系写出其普通生成函数（OGF）并推导封闭解；
2. 使用生成函数乘积（卷积）处理组合计数恒等式；
3. 用 SymPy 形式幂级数接口验证系数并解释其结果；
4. 说明 OGF 与 EGF 的适用对象差异，并选择正确工具。

## 4. 详细题目

### 题 1：构造 OGF 并求解封闭解（基础）

对递推关系

$$
a_n = 5a_{n-1} - 6a_{n-2}, \quad a_0 = 1,\ a_1 = 5
$$

1. 写出生成函数 $A(x) = \sum_{n\ge0} a_n x^n$，并推导 $A(x) = \dfrac{1}{1-5x+6x^2}$。
2. 用部分分式分解恢复 $a_n$ 的封闭解，验证 $a_n = 3^n - 2^n$。
3. 用特征根法交叉验证同一封闭解。
4. 用下面的 SymPy 骨架验证前 6 项系数：

```python
import sympy as sp
x = sp.Symbol('x')
G = 1 / (1 - 5*x + 6*x**2)
print(sp.fps(G, x, 0).truncate(6))   # 期望: 1 + 5*x + 19*x^2 + 65*x^3 + 211*x^4 + 665*x^5 + O(x^6)
```

### 题 2：生成函数求计数序列（基础）

求序列 $(a_n)$，其中 $a_n$ = "用面值 1、2、3 的邮票凑出总面值 $n$ 的方案数（顺序无关）"。

1. 写出组合对象的生成函数 $G(x) = \dfrac{1}{(1-x)(1-x^2)(1-x^3)}$ 并解释每个因子的含义。
2. 展开前 6 项，给出 $a_0,\dots,a_5$。
3. 说明这个模型与"顺序有关"的版本（$(\frac{x}{1-x})^3$ 类）在语义上的差别。

### 题 3：卷积与恒等式（中等）

使用生成函数证明下列恒等式，并各给出一个组合论证：

1. $\displaystyle\sum_{k=0}^{n} \binom{n}{k}\binom{n}{n-k} = \binom{2n}{n}$。
2. $\displaystyle\sum_{k=0}^{n} \binom{n}{k}^2 = \binom{2n}{n}$（说明与上一题的关联）。

### 题 4：OGF 与 EGF 辨析（中等）

1. 序列 $(1,1,1,\ldots)$ 的 OGF 是 $\frac{1}{1-x}$，EGF 是 $e^x$。分别说明两个对象适用的组合场景。
2. 对"从 $n$ 个不同对象中选出 $k$ 个做排列"这一有标号对象，指出应使用 OGF 还是 EGF，并写出其生成函数形式。

### 题 5：综合（较难）

用生成函数求解非齐次递推 $a_n = 2a_{n-1} + 1$，$a_0 = 0$，并把 $a_n$ 的显式公式与"每次翻倍再 +1"的直观过程核对。
