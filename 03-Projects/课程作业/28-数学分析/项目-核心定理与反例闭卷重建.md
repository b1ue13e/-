# 核心定理与反例闭卷重建

> 这是为 `数学分析` 编写的**本地原创正式作业**。外部课程只决定知识顺序和参考边界；本页不复制外部题目、Starter 或答案。课程未成为 Active Sprint 前，状态保持 `planned`。

## 1. 任务与学习结果

完成后需要证明：你不仅能复述知识，还能在固定输入、明确协议和失败条件下独立得到可复核结果。

- **输入/数据**：本地原创的实数、序列、级数、连续与微分命题组。
- **朴素基线**：重建上确界性质、单调收敛和介值定理中的两条。
- **独立实现**：完成紧致性、Riemann 可积性或一致连续性的证明组合。
- **强验证**：削弱条件并构造反例，制作定义—引理—定理依赖图和闭卷抽测。

## 2. 来源与使用边界

- **Spine**：[MIT 18.100A](https://ocw.mit.edu/courses/18-100a-real-analysis-fall-2020/)，仅作为学习顺序与公开入口。
- **本地内容**：任务改写、评价协议、Rubric 和提交结构均为原创。
- **镜像策略**：`link-only`；激活课程时再记录精确版本、许可证、数据条款和环境锁文件。
- **答案策略**：只保存自己的实现与摘要；完整解答保持私有，不挂他人答案仓库。

## 3. 执行阶段

| 阶段 | 工作 | 必交证据 |
|:---|:---|:---|
| T1 规格与最小例 | 冻结输入、环境、随机种子和评价口径 | manifest、最小手算/已知答案例 |
| T2 Baseline | 完成朴素方法并逐项解释 | 基线输出、测试与误差记录 |
| T3 独立实现 | 完成紧致性、Riemann 可积性或一致连续性的证明组合 | 实现、日志、同口径比较 |
| T4 强验证 | 削弱条件并构造反例，制作定义—引理—定理依赖图和闭卷抽测 | 敏感性、失败案例与结论边界 |

## 6. 验收测试

以下是硬验收，任一项失败都不能依靠总分抵消：

- [ ] `01` 定义无循环依赖
- [ ] `02` 每个存在性结论给出依据
- [ ] `03` 反例满足保留条件
- [ ] `04` 随机抽题可在限定时间重建
- [ ] 所有产出可从 `README.md` 按顺序复核。
- [ ] 报告包含至少一个失败案例和适用边界。

## 8. 失败条件

- 使用测试数据、参考答案或未来信息参与方法选择；
- 来源、数据、环境或随机性无法追溯；
- Baseline 与改进方法使用不同评价口径；
- 只展示成功结果，不报告反例、诊断或失败模式；
- 复制外部课程答案，或把公开可见误认为允许再分发；
- 无法从提交物独立复核关键结论。

## 9. 提交物

- [ ] `README.md`：一条从环境到结果的复核路径；
- [ ] `manifest.yml`：版本、数据、条款、环境与种子；
- [ ] 实现、证明或分析计划；
- [ ] 硬验收测试及真实输出；
- [ ] Baseline 与强验证对比；
- [ ] `report.md`：结论、失败案例、限制与知识反哺。

## 10. 知识反哺

- 概念误解 → `kind: concept`；

- 失败与漏洞 → `kind: mistake`，必要时设置 `flow: review`。
