# HW01 FAQ

## 1. 这份作业最容易做错什么？

- 把 smoke 数据当成正式实验结果
- 只报最好数字，不解释协议和失败案例
- 忽略公平对照与可复现性

## 2. 什么时候说明我还没准备好开始？

- 如果对 `NumPy 向量化` 还不稳，建议先回补再做。
- 如果对 `训练/验证/测试切分` 还不稳，建议先回补再做。
- 如果对 `距离度量与线性分类` 还不稳，建议先回补再做。

## 3. 老师最在意什么？

- 你是否真正理解 `CIFAR-10 kNN 与 Softmax 基线` 的任务边界
- 你是否按数据契约和作业协议做事
- 你是否给出最小 baseline 和失败案例

## 4. 老师不希望看到什么？

- 没有数据来源和切分说明
- 只有结果，没有方法边界
- 直接照搬外部实现充当自己的作业
