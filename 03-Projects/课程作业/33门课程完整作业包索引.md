## 边界

- MIT OCW 等页面按其 Creative Commons/课程条款逐项使用；
- Stanford、Penn State、李宏毅课程等未明确允许整库再分发的材料保持 `link-only`；
- GitHub 仓库许可证只覆盖仓库内声明的内容，不自动覆盖数据、模型和第三方素材；
- 完整答案不进入公共知识卡，自己的提交默认 `private`。
