# 社交网络传播与影响力分析

## 项目目标

在一个公开的小型网络数据集上，比较中心性排序、社区结构和独立级联传播下的种子选择效果，明确拓扑指标与真实传播结果之间的差异。

## 实验协议

- 记录节点、边、方向性、权重和时间字段；先说明数据缺失与去重规则。
- 使用 degree、PageRank、betweenness 和 community-aware baseline 选择种子。
- 在独立级联模型中固定传播概率、预算和随机种子，至少运行 100 次蒙特卡洛重复。
- 留出时间片或边集做验证，避免用全图信息评估未来链接/传播。

## 任务清单

- [ ] 用 NetworkX 完成数据导入、统计摘要和可视化抽样。
- [ ] 计算中心性、社区模块度和节点覆盖率，并解释指标冲突。
- [ ] 实现贪心、degree 和 PageRank 三种种子策略。
- [ ] 比较不同传播概率与预算下的平均覆盖、标准差和置信区间。
- [ ] 写出网络干预的伦理边界，禁止把影响力分数直接当作个体价值判断。

## 完成标准

- [ ] 代码固定随机种子可重复，结果表包含均值、标准差和运行次数。
- [ ] 报告包含至少一个失败案例：中心性最高的节点并非最优种子。
- [ ] 输出图、实验配置和结论可以被另一台机器复现。
