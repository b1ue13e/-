# 数学分析-阶段作业-03-微分积分定理链

## 学习目标

闭卷重建“极值定理 → Rolle → MVT → Taylor”和“统一连续 → Riemann 可积 → FTC”两条定理链，并用它们解决不等式和积分问题。

## 任务边界

微分部分限于一元实函数，积分部分限于有界 Riemann 积分。反常积分、Lebesgue 判据和多元微分不属于本任务。FTC2 的必修证明采用连续函数版本，若陈述更一般版本必须额外说明证明接口，不能偷换条件。

## 提交产物

- `theorem-chain.md`：两条依赖图及完整证明。
- `applications.md`：四道应用题。
- `error-log.md`：条件遗漏与修订记录。

## 执行流程

先只画两条依赖图并接受一次自检，确认每条箭头都标明调用条件后再展开证明。每个证明完成后反向检查：删掉一个条件，结论是否仍成立；若不知道，记录为待核对而不是编造反例。应用题最后完成，用来测试能否在没有定理标签时选择正确工具。

## 任务

### A. 微分定理链（30 分）

1. 从极值定理证明 Rolle 定理。
2. 构造辅助函数从 Rolle 推出 MVT。
3. 使用 MVT 证明：若 $f'=0$ 于区间，则 f 为常数。
4. 写出二阶 Taylor 公式的精确条件与 Lagrange 余项。

### B. Riemann 积分链（30 分）

1. 写出 Darboux 可积判据。
2. 用一致连续证明闭区间连续函数可积。
3. 证明 FTC 第一部分在连续点成立。
4. 在连续函数版本下，从 FTC1 或 MVT 推出 FTC2。

### C. 应用与反例（25 分）

1. 用 MVT 证明 $|\sin x-\sin y|\le|x-y|$。
2. 估计 $e^{0.1}$ 的二阶 Taylor 误差。
3. 用上下和证明 Dirichlet 函数不可积。
4. 给出连续不可导函数，并指出 MVT 为什么不能套用。

### D. 口头验收提纲（15 分）

准备 6 分钟说明：MVT 与 FTC 分别如何把局部信息变成整体信息。提纲必须提到每条定理的定义域和正则性条件。

## 分层提示与自检

- MVT：减去端点割线，而不是直接对 f 用 Rolle。
- 连续函数可积：把每段振荡控制为 $\varepsilon/(b-a)$。
- FTC1：先把差商写成平均值，再处理 h 的正负。
- 提交前逐条圈出“连续于闭区间”“可导于开区间”等条件。
