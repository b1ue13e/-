# 08-NLP全栈-阶段作业-03-大模型微调对齐与推理评估

> ⏱ **预计完成耗时**：5 小时  
> 🎯 **对应阶段**：阶段 5 - 大语言模型与前沿技术 / 阶段 6 - 专业方向深入

---

## 🎯 学习目标

1. 手写实现 DPO (Direct Preference Optimization) 损失函数算子，并在偏好数据对上完成策略模型 Logits 梯度更新。
2. 掌握自回归生成中的 KV Cache 显存管理与提速，对比单 Token 步增前向与全量前向的延迟差异。
3. 实现带 Temperature, Top-K 和 Top-P (Nucleus) 的解码采样器，并在纯 PyTorch 中模拟 INT4 非对称量化与误差分析。

---

## 🚧 任务边界

- **包含**：DPO 损失算法与隐式奖励提取、KV Cache 拼接循环、Top-K/Top-P 动态截断采样器与 W4A16 模拟量化重建误差。
- **不包含**：全量 70B 大模型多卡 PPO 强化学习训练与 C++ CUDA 算子编译。

---

## 📋 详细题目与实施步骤

### 任务 1：DPO Loss 算子实现与对齐训练
根据 DPO 隐式 Reward 表达式手写 DPO Loss：

$$\mathcal{L}_{\text{DPO}}(\theta) = -\log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right)$$

验证当策略模型提高 $y_w$ 概率、压低 $y_l$ 概率时 Loss 的单调递减特性。

### 任务 2：KV Cache 提速与解码采样器
手写 `sample_top_k_top_p` 函数，包含 Top-K 截断、Top-P 动态累积概率截断与带有 KV Cache 的生成循环。

### 任务 3：W4A16 模拟量化误差审计
实现非对称 INT4 量化与反量化函数 `quantize_asymmetric_int4()`，对比线性层权重在 FP16 与 INT4 状态下的均方误差 (MSE) 变化。
