## 习题题面 (Open-Source Problem Set)

### 题目 1：分离变量法与 Torricelli 漏水定律（物理建模）
> **对应知识卡**：[[常微分方程-一阶方程的分离变量法]] | **来源**：MIT 18.03 PSet 1 Part I

考虑一个顶半径为 $R$、高度为 $H$ 的倒立圆锥形水槽。水槽底端有一个面积为 $a$ 的圆形排水孔。根据托里拆利定律，水流出孔的速度为 $v = \sqrt{2gh}$（$h$ 为水深）。

1. 导出水深 $h(t)$ 随时间变化的一阶微分方程：$\frac{dh}{dt} = - \frac{a \sqrt{2g}}{\pi R^2 / H^2} h^{-3/2}$。
2. 若初始水深 $h(0) = H$，求解水深 $h(t)$ 的解析表达式。
3. 求出将水槽完全排空所需的总时间 $T_{\text{empty}}$。

### 题目 2：逻辑斯蒂人口模型与离域分化（非线性分离变量）
> **对应知识卡**：[[常微分方程-一阶方程的分离变量法]] | **来源**：Notes on Diffy Qs §1.3 Ex 1.3.9

某种种群的增长满足带环境承载力 $K$ 和猎杀率 $h$ 的逻辑斯蒂模型：
$$\frac{dP}{dt} = r P \left(1 - \frac{P}{K}\right) - h$$

1. 取 $r=1, K=4, h=3/4$，写出对应的微分方程并求其平衡点（Equilibrium Points）。
2. 通过分离变量法求出满足初始条件 $P(0) = P_0$ 的解 $P(t)$。
3. 判定临界初始值：当 $P_0$ 小于多少时，种群将在有限时间内走向灭绝（$P(t) \to 0$）？

---

### 题目 3：积分因子法与 RC 交流电路响应（电路建模）
> **对应知识卡**：[[常微分方程-一阶线性方程与积分因子]] | **来源**：MIT 18.03 PSet 1 Part II

在包含电阻 $R$ 和电容 $C$ 的一阶串联 RC 电路中，输入交流电压 $V(t) = V_0 \cos(\omega t)$。电荷量 $q(t)$ 满足：
$$R \frac{dq}{dt} + \frac{1}{C} q = V_0 \cos(\omega t), \quad q(0) = 0$$

1. 求出该方程的积分因子 $\mu(t)$。
2. 求解电荷量 $q(t)$ 的特解。
3. 将解分解为**瞬态响应** $q_{\text{trans}}(t)$ 与**稳态响应** $q_{\text{ss}}(t)$，求稳态响应的振幅和相位差。

### 题目 4：伯努利方程（非线性可转化一阶方程）
> **对应知识卡**：[[常微分方程-一阶线性方程与积分因子]] | **来源**：Notes on Diffy Qs §1.4 Ex 1.4.6

求解以下伯努利微分方程：
$$\frac{dy}{dx} + \frac{1}{x} y = x y^2, \quad x > 0$$

1. 引入变量代换 $v = y^{1-2} = y^{-1}$，导出关于 $v(x)$ 的一阶线性微分方程。
2. 求解 $v(x)$ 并还原求出 $y(x)$ 的通解。
3. 给出满足初始条件 $y(1) = 2$ 的特解，并确定该特解的最大最大定义域。

---

### 题目 5：全微分与恰当方程（势函数存在性）
> **对应知识卡**：[[常微分方程-恰当方程]] | **来源**：Notes on Diffy Qs §1.6

给定微分方程：
$$(3x^2 y + 2xy) dx + (x^3 + x^2 + 1) dy = 0$$

1. 验证该方程是否满足恰当性条件 $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$。
2. 求解其对应的势函数 $F(x, y)$，使得 $dF(x, y) = M dx + N dy$。
3. 求满足初始条件 $y(1) = 2$ 的显式解析解 $y(x)$。

---

### 题目 6：Picard 迭代与解的存在唯一性验证
> **对应知识卡**：[[常微分方程-一阶方程的存在唯一性定理]] | **来源**：MIT 18.03 PSet 2 Part I

考虑初值问题：
$$\frac{dy}{dx} = 2x(1 + y), \quad y(0) = 0$$

1. 证明函数 $f(x, y) = 2x(1 + y)$ 在全平面矩形区域满足 Lipschitz 条件。
2. 计算 Picard 逼近序列的前 4 项迭代解 $y_0(x), y_1(x), y_2(x), y_3(x)$。
3. 写出 Picard 序列极限 $y(x) = \lim_{n\to\infty} y_n(x)$ 的级数闭形式，并验证它正是该初值问题的精确解析解。

### 题目 7：方向场与斜率场几何感知（定性分析）
> **对应知识卡**：[[常微分方程-相平面与方向场基础]] | **来源**：MIT 18.03 Technical Note

对于一阶微分方程：
$$y' = y^2 - x$$

1. 求出对应斜率 $k = 0, 1, -1$ 的等斜线（Isoclines）代数方程。
2. 分析解在第一象限抛物线 $y = \sqrt{x}$ 上方的斜率正负，说明解的渐近单调性。
3. 编写一段 Python 代码（使用 `matplotlib` 和 `numpy`），绘制区域 $x \in [-2, 4], y \in [-2, 3]$ 内的方向场及过 $(0,0)$ 的数值轨线。

### 题目 8：Euler 法数值近似与局部/全局截断误差（数值初步）
> **对应知识卡**：[[常微分方程-数值解法基础与仿真]] | **来源**：Notes on Diffy Qs §1.7

对于已知解析解的初值问题 $y' = y, y(0) = 1$（精确解为 $y(t) = e^t$）：

1. 使用步长 $h = 0.1$，手算用显式 Euler 法求 $y(0.2)$ 的近似值 $y_2$。
2. 计算 $t = 1$ 时，步长分别为 $h = 0.1, 0.05, 0.025, 0.0125$ 时 Euler 法的绝对误差 $|y_N - e^1|$。
3. 写一段 Python 实验代码验证：将步长 $h$ 减半时，全局误差是否呈现 $\mathcal{O}(h)$ 的一阶收敛下降规律。

## 参考解答与 Python 代码验证

<details>
<summary><b>点击展开【题目 1 参考解答与 Python 验算】</b></summary>

#### 解析推导：
1. 几何微元关系：水深 $h$ 时，截面半径 $r = \frac{R}{H} h$，截面积 $A(h) = \pi r^2 = \pi \frac{R^2}{H^2} h^2$。
2. 体积变化率等于流出速率：$A(h) \frac{dh}{dt} = -a v = -a \sqrt{2gh}$。
   $$\pi \frac{R^2}{H^2} h^2 \frac{dh}{dt} = -a \sqrt{2g} h^{1/2} \implies \frac{dh}{dt} = -\frac{a H^2 \sqrt{2g}}{\pi R^2} h^{-3/2}$$
3. 分离变量积分得特解：
   $$h(t) = \left( H^{5/2} - \frac{5 a H^2 \sqrt{2g}}{2 \pi R^2} t \right)^{2/5}$$
4. 完全排空时间 $T_{\text{empty}}$（$h(T) = 0$）：
   $$T_{\text{empty}} = \frac{2 \pi R^2 \sqrt{H}}{5 a \sqrt{2g}}$$

#### Python SymPy 验证代码：
```python
import sympy as sp

t = sp.Symbol('t', positive=True)
h = sp.Function('h')
a, g, R, H = sp.symbols('a g R H', positive=True)

eq = sp.Eq(h(t).diff(t), - (a * H**2 * sp.sqrt(2*g) / (sp.pi * R**2)) * h(t)**(-3/2))
sol = sp.dsolve(eq, h(t), ics={h(0): H})
print("解表达式 h(t):", sol)
```
</details>

#### 解析推导：
1. 带入参数得 $\frac{dP}{dt} = P(1 - P/4) - 3/4 = - \frac{1}{4} (P^2 - 4P + 3) = - \frac{1}{4} (P - 1)(P - 3)$。
   平衡点为 $P = 1$（不稳定）与 $P = 3$（稳定）。
2. 分离变量积分：
   $$\int \frac{dP}{(P - 1)(P - 3)} = - \frac{1}{4} \int dt \implies \frac{1}{2} \ln \left| \frac{P - 3}{P - 1} \right| = - \frac{1}{4} t + C$$
3. 解得：若 $P_0 < 1$，解在有限时间内降至 0，灭绝临界初始值为 $P_0 = 1$。
</details>

<details>
<summary><b>点击展开【题目 4 参考解答】</b></summary>

#### 解析推导：
1. 令 $v = y^{-1}$，则 $\frac{dv}{dx} = -y^{-2} \frac{dy}{dx}$。
   原方程同除以 $y^2$ 得 $y^{-2} \frac{dy}{dx} + \frac{1}{x} y^{-1} = x \implies - \frac{dv}{dx} + \frac{1}{x} v = x \implies \frac{dv}{dx} - \frac{1}{x} v = -x$。
2. 积分因子 $\mu(x) = e^{-\int \frac{1}{x} dx} = \frac{1}{x}$。
   $\frac{d}{dx} (\frac{v}{x}) = -1 \implies \frac{v}{x} = -x + C \implies v(x) = C x - x^2$。
3. 还原 $y(x) = \frac{1}{C x - x^2}$。初值 $y(1) = 2 \implies \frac{1}{C - 1} = 2 \implies C = 3/2$。
   特解为 $y(x) = \frac{1}{\frac{3}{2}x - x^2} = \frac{2}{3x - 2x^2}$，在 $x \in (0, 3/2)$ 内成立。
</details>

<details>
<summary><b>点击展开【题目 6 参考解答】</b></summary>

#### 解析推导：
1. Picard 迭代积分公式：$y_{n+1}(x) = \int_0^x 2t (1 + y_n(t)) dt$。
2. 初始项 $y_0(x) = 0$。
   - $y_1(x) = \int_0^x 2t(1 + 0) dt = x^2$。
   - $y_2(x) = \int_0^x 2t(1 + t^2) dt = x^2 + \frac{x^4}{2}$。
   - $y_3(x) = \int_0^x 2t(1 + t^2 + \frac{t^4}{2}) dt = x^2 + \frac{x^4}{2} + \frac{x^6}{6}$。
3. 第 $n$ 项为 $y_n(x) = \sum_{k=1}^n \frac{(x^2)^k}{k!}$，极限 $y(x) = e^{x^2} - 1$。
</details>

<details>
<summary><b>点击展开【题目 8 参考解答与 Python 实验代码】</b></summary>

#### Python 验证收敛阶代码：
```python
import numpy as np

def euler_solve(f, y0, t0, t_end, h):
    N = int((t_end - t0) / h)
    t = t0
    y = y0
    for _ in range(N):
        y += h * f(t, y)
        t += h
    return y

exact = np.exp(1.0)
print(f"Exact e^1 = {exact:.6f}")

for h in [0.1, 0.05, 0.025, 0.0125]:
    approx = euler_solve(lambda t, y: y, 1.0, 0.0, 1.0, h)
    err = abs(approx - exact)
    print(f"h = {h:<6} | Euler = {approx:.6f} | Error = {err:.6f}")
```
</details>
