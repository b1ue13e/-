## 1. 群体心理与阈值（10 分，Yokila）

早在 20 世纪初，社会学家和经济学家就在研究创新，例如思想、产品、技术和行为，如何在社会中扩散。该领域的重要研究者之一是 Mark Granovetter 教授；他与 Thomas Schelling 一起把阈值模型引入社会学。

Granovetter 模型包含一个个体群体，以及为简化而设定的两种行为：参与骚乱或不参与骚乱。

### 阈值模型

每个个体 $i$ 有一个阈值 $t_i$，其行为按以下规则决定：如果正在参与骚乱的人数至少为 $t_i$，那么个体 $i$ 也会加入；否则保持不活跃。

这里隐含假设每个人都完全了解群体中其他所有人的行为。阈值小的节点称为创新者或早期采用者，阈值大的节点称为落后者或晚期采用者。Granovetter 阈值模型通过底层人群的阈值解释了经典的实证采用曲线，也解释了少数个体如何触发大规模行为。

本题研究阈值对最终参与骚乱人数的影响。

对包含 $n$ 个个体的群体，定义阈值直方图

$$

其中 $N_\ell$ 表示阈值为 $\ell\in[n]$ 的个体数量。例如，$N_0$ 是无论如何都会参与骚乱的人数，$N_1$ 是只要有另一个人参与就会加入的人数，依此类推。

2005 年 Graph Drawing 会议提供了 IMDB 电影数据库的数据集。本题使用其缩减版本，其中保留 1995-2004 年间至少共同出演过两部电影的演员之间的合作边。下载：

- [SIR Erdos-Renyi 图](http://cs224w.stanford.edu/homeworks/hw3/data_sets/SIR_erdos_renyi.txt)
- [SIR 优先连接图](http://cs224w.stanford.edu/homeworks/hw3/data_sets/SIR_preferential_attachment.txt)

回顾 SIR 模型：每个节点处于易感（susceptible）、感染（infected）或康复（recovered）之一；初始时每个节点要么易感，要么感染。易感节点的每个感染邻居都以概率 $\beta$ 尝试感染它；感染节点以概率 $\delta$ 康复。康复节点不再易感，不能再次被感染。

### 算法 1：在图 $G=(V,E)$ 上模拟 SIR

**输入**：初始感染节点集合 $I$

```text
S <- V \ I                 # 易感节点
R <- empty set             # 康复节点

while I is not empty:
    S_new <- empty set     # 本轮后不再易感的节点
    I_new <- empty set     # 本轮新感染节点
    J_new <- empty set     # 本轮后不再感染的节点
    R_new <- empty set     # 本轮新康复节点

    for each node u in V:
        if u is in S:
            for each edge (u, v) in E with v in I:
                with probability beta:
                    add u to S_new
                    add u to I_new
                    break
        else if u is in I:
            with probability delta:
                add u to J_new
                add u to R_new

    S <- S \ S_new
    I <- (I union I_new) \ J_new
    R <- R union R_new
```

## 4. 影响力最大化（25 分，Anunay、Silviana）

课堂上讨论了影响力最大化问题及其贪心爬山算法。算法每次向当前种子集合加入一个节点：

$$
S_0=\varnothing,
$$

对 $i>0$，

$$
S_i=S_{i-1}\cup
\left\{
\arg\max_u\bigl[f(S_{i-1}\cup\{u\})-f(S_{i-1})\bigr]
\right\},
$$

其中 $f(S)$ 表示由初始活跃集合 $S$ 影响的节点数，并包括 $S$ 自身。

课堂上已证明，爬山算法不能保证得到最优解。也就是说，可能存在 $|T|=i$ 的集合 $T$，使

$$
f(S_i)<f(T).
$$

第 4.1、4.2 要求构造这种例子。答案必须包含：

1. 每个节点 $u$ 的影响集合 $X_u$。可以直接描述集合，也可以画有向图，其中从 A 到 B 的边表示 A 以概率 1 影响 B。
2. 贪心爬山运行 $i$ 次后选择的集合 $S_i$。
3. 含 $i$ 个节点的最优集合 $T$。

所有问题都可以假设：

1. $S$ 中的节点影响自身，因此 $f(S)$ 包括 $S$ 中的节点。
2. $X_u$ 包含被 $u$ 直接或最终间接影响的所有节点。
3. 若多个节点边际增益相同，从中随机选择一个。

### 4.1 非最优爬山（8 分）

对 $i=2$ 构造一个满足

$$
f(S_i)<f(T)
$$

的例子，即爬山算法只能找到非最优解。

提示：给定前 $i-1$ 步后，贪心算法的最后一步是最优的。

### 4.2 有界非最优爬山（8 分）

对 $i=3$ 构造一个满足

$$
f(S_i)\le0.8f(T)
$$

的例子，即爬山算法只能找到不超过最优值 80% 的解。

### 4.3 爬山算法的最优性（4 分）

给出影响集合 $X_u$ 的一种性质，使

$$
f(S_i)=f(T).
$$

也就是说，给出一个关于节点影响集合的充分条件，使贪心爬山总能输出最优解。该性质不必是必要条件，但必须是 $X_u$ 的性质；“网络只有 $i$ 个节点”之类的性质不能作为正确答案。

存在多个正确答案，课程接受所有合理答案。

### 4.4 更多爬山分析（5 分）

假设爬山算法运行 $k$ 步后停止，且

$$
|S_k|=|T|=k.
$$

课堂上证明过如下形式的界：

$$
f(T)\le f(S_k)+\sum_{i=1}^{k}\delta_i,
\tag{2}
$$

其中 $\delta_1,\ldots,\delta_k$ 是集合

$$
\{f(S_k\cup\{u\})-f(S_k)\mid u\}
$$

中最大的 $k$ 个值。

构造一个例子族，使

$$
f(S_k)+\sum_{i=1}^{k}\delta_i-f(T)
$$

可以任意大。

更具体地，对任意数 $b$，给出一张网络，使

$$
f(S_k)+\sum_{i=1}^{k}\delta_i-f(T)>b.
$$

“例子族”是例子集合 $\mathcal F$，满足对任意 $b$，都存在与 $b$ 对应的网络 $E(b)\in\mathcal F$，使上述差值大于 $b$。
