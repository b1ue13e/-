# 社交网络挖掘-课后作业-00-前置诊断与环境自检

## 学习目标

证明自己能够读取边表、解释随机性、完成矩阵传播，并区分训练/验证/测试，而不是只在诊断答案展开后产生熟悉感。

## 任务边界

- 在项目根目录执行，Python 要求 3.11 及以上。
- 基础依赖仅为 `numpy`、`networkx`、`pytest`；不要求 GPU。
- 诊断允许跳过已通过模块的补学，但复测必须换数字或换小图。
- 不提交诊断答案截图，提交自己的推导、命令和输出摘要。

## 详细任务

### L00-1 诊断与补学决策

闭卷完成前置诊断，记录三个模块得分、关键题结果、信心和补学决定。24 小时后只重测失败模块，并说明结果是否改变了最初判断。

### L00-2 环境 smoke test

运行：

```powershell
python scripts/course_smoke.py --output artifacts/preflight
python -m pytest -q
```

解释 Python、NumPy、NetworkX 版本，以及 smoke test 检查的图不变量。仅写“测试通过”不得分。

### L00-3 最小变式

在不修改 starter 的前提下，新建自己的 `submission/l00_check.py`：构造一个含互惠边、重复事件和自环的有向边表；选择简单图或多重图口径；写至少四个断言。

## 提交产物

- `submission/l00_diagnostic.md`：首测、复测、信心和补学决策。
- `submission/l00_check.py`：最小变式与断言。
- `submission/l00_environment.txt`：命令、版本和测试摘要。

## 验收标准与 Rubric

| 维度 | 分值 | 通过证据 |
| :--- | ---: | :--- |
| 诊断诚实性 | 20 | 首测与复测分开记录，不把看过答案后的结果当首测 |
| 数据语义 | 25 | 有向、重复、自环口径明确且断言一致 |
| 数学与评估 | 20 | 能解释随机性、矩阵方向和数据切分职责 |
| 可运行性 | 25 | 两条命令从项目根目录成功执行 |
| 复盘 | 10 | 指出一个真实错误及其补救入口 |

总分至少 80，且 smoke test 与自定义断言全部通过，才能进入阶段 1。

## 引导与自检

- 若导入失败，先确认使用的是 `python -m pip` 对应的解释器。
- 若边数不符合预期，先比较事件数、唯一边数和图对象边数。
- 若矩阵结果转置，先写清 $A_{ij}$ 的方向定义。
- [ ] 提交中没有复制展开答案。
- [ ] 所有输出都能由记录的命令重建。
