# 社交网络挖掘-大作业-开放网络分析与链路预测

## 学习目标

在一个真实、匿名、带时间戳的社会接触网络上，完成数据契约、结构解释、社区分析、无泄漏链接预测、表示学习比较和可复现报告。最终结论必须说明证据、失败案例和外推边界，不能只展示最高分模型。

## 任务边界

- 合成 fixture 只验证协议和代码，不得作为最终结论的数据来源。
- 真实数据必须从官方源下载并保留许可、引用、哈希与匿名化说明。
- 最终预测对象是“后续首次观测到的接触边”，不是友谊、影响或疾病传播。
- 所有模型必须复用同一时间切分、候选空间、负样本和指标。
- 课程 starter 是最低可运行基线，不替代学习者的模型扩展、误差分析和复现报告。

## 两条数据轨道

### 轨道 A：合成协议预检

`scripts/generate_course_data.py` 生成 24 节点 fixture，用于验证 schema、切分、指标和算法 oracle。它不能作为最终项目数据，也不能支持真实社会行为结论。

### 轨道 B：必做真实数据

使用 [SocioPatterns High School 2013](https://sociopatterns.org/datasets) 高中面对面接触网络：匿名学生节点、20 秒接触窗口、五天时间跨度，并带班级元数据。

- 下载与归一化：`scripts/fetch_public_network.py`。
- 固定上游压缩包 SHA-256：`ecf4a90312c8d72057f72e936c366b470e63876da7db846300044795f045e2ea`。
- 许可证：`CC BY-NC-SA 3.0`；报告必须署名 SocioPatterns、引用 Mastrandrea et al. (2015)，并保留非商业与相同方式共享限制。
- 语义边界：边表示近距离接触，不等于友谊、影响或疾病传播。

没有轨道 B 的真实数据结果，Capstone 不得通过。可再增加 SNAP、引文或 Wikipedia 网络做外部比较，但不能替代轨道 B。

## 冻结协议

建模前创建 `project_manifest.yml`，至少包含：

1. 预测对象、观察截止时点、验证窗口、测试窗口和候选边空间；
2. 数据 URL、访问日期、许可证、下载哈希、图方向、重复事件和冷启动策略；
3. 训练/验证/测试正边、负样本定义、比例和随机种子；
4. 指标、`K` 值、模型选择规则、硬件和计时范围；
5. 允许进入模型的字段，以及每个字段在预测时点是否可见。

协议修改必须新增 manifest 版本并说明原因，不能覆盖旧版本。

## 可运行起点

课程 starter 已实现数据契约、首次连边时间切分、合法负采样、随机/PA/CN/Jaccard/AA 基线和 AP/AUC/Precision@K：

```powershell
python -m pip install -r requirements.txt
python scripts/generate_course_data.py --output data/generated --seed 42
python starter/run_baseline.py --events data/generated/temporal_edges.csv --output artifacts/starter-synthetic
python scripts/fetch_public_network.py --output data/external/high-school-2013
python starter/run_baseline.py --events data/external/high-school-2013/temporal_edges.csv --undirected --output artifacts/starter-real
python -m pytest -q
```

Starter 输出 `split_manifest.json`、`predictions.csv` 和 `metrics.json`。学习者必须审查并扩展这些产物，不能把 starter 输出直接当作项目结论。

## 里程碑

### M1 数据契约与结构基线

- 对合成与真实数据分别运行契约检查，报告事件、唯一边、节点、自环、重复接触和时间范围。
- 在训练截止时点构图，报告度、互惠、WCC/SCC、聚类和距离口径。
- 用 ER 或配置模型作零模型；至少解释一个观测结构为何不能仅由规模、密度或度序列说明。

### M2 社区与排名解释

- 比较模块度方法和谱二分，报告目标函数、随机种子、组规模和不稳定案例。
- 班级元数据只能在社区完成后用于置换不变评价，不能进入无监督社区算法。
- 为直接触达、桥接控制和递归声望分别选择中心性，不把排名写成因果影响。

### M3 无泄漏链接预测

- 复核 starter 的首次连边定义、时间切分、闭世界节点和负样本规则。
- 复用随机、PA、CN、Jaccard、AA 五个基线，保留逐边预测。
- 报告 AP、ROC-AUC、Precision@K；故意构造一次完整图泄漏作为失败回归，但不得进入正式结果。

### M4 表示学习比较

- 在同一 split 上增加共现加 SVD、Node2Vec 或最小消息传递模型。
- 消息传递模型必须包含参数、损失、优化、验证早停和至少 5 个训练种子。
- 比较指标、运行时间和参数量；至少做两项消融，并保留复杂模型不提升的结果。

### M5 传播或社区稳健性

二选一：

- **传播轨道**：在训练图上比较随机、中心性和贪心种子的 SIR/IC 结果；明确接触边不等于真实传播概率。
- **社区轨道**：分析跨班级边、冷启动节点和高度节点上的链接预测误差。

必须报告不确定性、一个失败案例和不能外推的边界。

### M6 从干净输出目录复现

删除可重建输出后重新运行数据获取、schema 检查、切分、基线、改进模型、主表和主图。记录命令、耗时、版本与哈希；不得依赖 notebook 隐藏状态或本机绝对路径。
