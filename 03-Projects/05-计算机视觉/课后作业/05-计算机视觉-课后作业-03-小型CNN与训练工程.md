## 📝 详细题目（稳定题号，按序完成）

### Q1 工程骨架与数据管线（15 分）

- 组织最小工程：`data → model → train loop → eval`，训练/验证/测试三分离；
- `load_images(csv)`：读 smoke CSV → `(N,1,4,4)` float32 归一化到 `[0,1]`；真实数据适配 `npz`（(N,3,32,32) uint8 → float32 / 255）；
- 固定随机种子（`np.random.seed` + `torch.manual_seed`）并记录版本。

**验收**：`X.shape == (N, 1, 4, 4)`；空文件抛 `ValueError`。

### Q2 TinyCNN 结构（15 分）

实现 `TinyCNN`：`Conv2d(1→8, 3×3, pad=1) + BatchNorm2d(8) + ReLU + FC(8·4·4 → 2)`：

- 输入通道/图像尺寸/类别数参数化（smoke 1×4×4、真实 3×32×32 通用）；
- 记录参数量：`sum(p.numel() for p in model.parameters())`，报告数量级。

**验收**：smoke 上 `run_smoke` 的 `final_train_loss` 可降到 < 0.01（过拟合信号）。

### Q3 训练循环与单 batch 过拟合（15 分）

实现 `train_epoch(model, optimizer, X, y, batch_size)` 与 `evaluate(model, X, y)`：

- **先验证"单 batch 可过拟合"**：在 4 样本 smoke 上训练 60 epoch，loss 应单调下降；
- 训练/评估模式切换正确（`model.train()` / `model.eval()`，评估结束后恢复）。

**验收**：`run_smoke` 输出 `train_accuracy` 与 `val_accuracy` 均 ≥ 0.5 且 `final_train_loss` < 0.01。

### Q4 BatchNorm train/eval 模式验证（20 分）

实现 `check_batchnorm_train_eval(model, X)`：

- 同一输入分别经 `model.train()` 与 `model.eval()` 前向，计算输出最大差分；
- 训练若干步后差分应显著 > 0（train 用 batch 统计、eval 用 running stats）；
- 解释：为什么训练阶段用 batch 统计、推理阶段用 running stats？（提示：推理时 batch 大小变化与统计稳定性）

**验收**：smoke 上 `batchnorm_train_eval_diff` > 0.01；报告写入解释。

### Q5 单因素对照实验（25 分）

在 smoke（或真实子集）上做**单因素对照**，每轮只改一个因素、其余固定，报告验证集准确率表：

| 实验 | 对照 A | 对照 B | 观察什么 |
|:---|:---|:---|:---|
| 优化器 | SGD+momentum | Adam | 收敛速度与最终指标 |
| 学习率调度 | 固定 LR | CosineAnnealing | 后期收敛是否更稳 |
| 数据增强 | 无 | 随机翻转/裁剪 | 训练/验证 gap 变化 |
| 正则化 | 无 | Dropout(0.5) | 过拟合缓解程度 |

- 每个实验至少跑 2 个配置，报告准确率与训练/验证 gap；
- 进阶：用**类别级准确率**评估，说明某类物体是否系统性更差。

**验收**：≥2 组对照完成且结论明确（"Adam 比 SGD 快 / 增强缩小 gap"等，用数据说话）。

### Q6 失败分析与复盘（10 分）

- 可视化至少 3 个验证失败样本（真实数据时），分析失败模式（模糊/遮挡/类别混淆）；
- 解释"单 batch 过拟合通过 ≠ 泛化好"；
- 提交前确认 `rubric.md` 自评与 `submission_checklist.md`。

**验收**：报告 Q6 小节完整。

## 🔍 引导与自检

**递进提示（不泄露答案）**：
1. 先用 4 样本 smoke 把"单 batch 过拟合"跑通（loss 降到 < 0.01），再谈泛化——代码正确性优先；
2. BatchNorm 验证前至少训练几十步（running stats 未更新时 diff ≈ 0 是正常的）；
3. 对照实验用固定种子和相同初始化，只改目标因素；
4. 曲线图比数字更能暴露不收敛/过拟合，务必画图。

**常见失败与调试方向**：

| 现象 | 可能原因 | 调试方向 |
|:---|:---|:---|
| 训练 loss 不降 | lr 过高/过低 | 扫 `lr ∈ {0.01, 0.05, 0.1}` |
| BatchNorm diff = 0 | 未训练就验证 / BN 未生效 | 先跑几十步再 `check_batchnorm_train_eval` |
| 验证准确率异常高 | 增强/预处理泄漏到验证集 | 检查数据管线是否三分离 |
| train 好 val 差（gap 大） | 过拟合 / 增强不足 | 加 Dropout 或增强做对照 |
| eval 模式结果跳动 | 忘记 `model.eval()` | 评估前显式切换，结束恢复 train |

**提交前清单**：smoke 通过、曲线齐全、≥2 组对照表、BatchNorm 差分记录、README 记录种子与版本、失败样本分析存在。
