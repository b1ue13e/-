# 05-计算机视觉-课后作业-03-小型CNN与训练工程

## 📋 任务描述与学习目标

搭建并训练一个小型 CNN（卷积 + BatchNorm + 全连接），围绕训练工程要素（初始化、优化器、学习率调度、数据增强、正则）做单因素对照，产出可复现的训练报告。

学完本课后你应该能：

- 用 PyTorch 组织训练/验证/测试三分离的最小工程；
- 解释并验证 BatchNorm 的 train/eval 模式差异；
- 通过单因素实验说明至少两个训练技巧的实际效果（而非只复述直觉）。

## 🎯 任务分层要求（基础 / 进阶 / 综合）

### 基础要求
- [ ] 用 `starter/` 跑通小型 CNN 训练闭环（固定种子、固定切分）
- [ ] 实现并验证 BatchNorm train/eval 行为
- [ ] 记录损失/准确率曲线

### 进阶要求
- [ ] 对照实验：SGD vs Adam；固定 LR vs Cosine 调度
- [ ] 引入一种数据增强（翻转/裁剪/Mixup 之一）并报告效果

### 综合要求
- [ ] 单因素敏感性报告：只改变一个因素，报告类别级指标与失败案例
- [ ] 完成 `rubric.md` 自评与提交清单
