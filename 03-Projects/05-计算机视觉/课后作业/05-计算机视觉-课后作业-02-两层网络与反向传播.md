## 📝 详细题目（稳定题号，按序完成）

### Q1 网络结构与前向传播（15 分）

实现两层网络 `affine(线性) - ReLU - affine - softmax`：

- 输入 `X: (N, D)`，隐藏层 `H: (N, H)`（ReLU），输出 `scores: (N, C)`（softmax 交叉熵）；
- 前向必须**缓存中间量**（`z1/h1/z2` 或等价），反向传播需要；
- 手算样例（用 `_init_params()` 的固定参数）：`tiny_batch`（4 样本，2 特征，3 隐藏单元，2 类）上 `initial_loss ≈ 0.6939`。

**验收**：`run_smoke` 输出的 `initial_loss` 与样例一致（±1e-4）。

### Q2 反向传播：输出层与隐藏层梯度（20 分）

实现 `loss_and_grads(params, batch) -> (loss, grads)`：

- 输出层：`dlogits = p − y_onehot`；`dW2 = h^T dlogits / N`，`db2 = mean(dlogits)`；
- 隐藏层：`dh = dlogits · W2^T`，经 ReLU 掩码 `dh1 = dh * (z1 > 0)`，`dW1 = x^T dh1 / N`，`db1 = mean(dh1)`；
- 损失为平均交叉熵：`L = (1/N) Σ -log p_i[y_i]`。

**验收**：梯度形状与参数一致；`gradient_diff = |num(W2[0][0]) − an(W2[0][0])| < 1e-4`（smoke 断言）。

### Q3 参数更新（10 分）

实现 `_apply_step(params, grads, learning_rate)`：

- `W -= lr * grad`（按元素）；偏置同理；
- 单步更新后 loss 必须下降（smoke 断言 `after_one_step_loss < initial_loss`）。

**验收**：smoke 断言通过。

### Q4 全参数数值梯度验证（25 分）

实现通用中心差分 `numeric_gradient(params, param_name, index, batch, eps=1e-5)` 与 `gradient_check_table(params, batch)`：

- 对 `W1(2×3) / b1(3) / W2(3×2) / b2(2)` 共 **17 个标量**逐一做 `(f(W+eps) − f(W−eps)) / (2·eps)`；
- 相对误差 `|num−an| / max(1, |num|, |an|)`，全部 < 1e-4（eps=1e-5 时）；
- 输出梯度检查表（参数、索引、解析值、数值值、相对误差）写入报告。

**验收**：`max_gradient_error()` < 1e-4；表格入报告。

### Q5 训练与过拟合信号（20 分）

用固定初始参数或 He 初始化，在 `overfit_batch.smoke.csv` 上训练 40 步：

- 记录 loss 历史，证明 loss 单调下降并可过拟合（`overfit_final_loss` 远低于初始）；
- 进阶：He 初始化（`W ~ N(0, √(2/fan_in))`）对比原始初始化，说明收敛差异；
- 进阶：L2 正则 `reg` 并入梯度（`grad += reg*W`），观察对训练/验证曲线的影响。

**验收**：smoke `overfit_final_loss < initial_loss`；训练曲线图入报告（进阶）。

### Q6 反思与复盘（10 分）

- 解释"为什么 ReLU 反向传播要乘掩码 `z1 > 0`"与"0 点处如何处理"；
- 解释"为什么梯度检查能抓实现 bug，但训练不收敛可能是别的问题"；
- 对比手写反向传播与 PyTorch autograd 的梯度（可选进阶）。

**验收**：报告 Q6 小节回答上述问题。

## 🔍 引导与自检

**递进提示（不泄露答案）**：
1. 反向传播从输出层往输入层写：`dlogits → dW2/db2 → dh → dh1(掩码) → dW1/db1`，每一步用形状推断自检；
2. ReLU 掩码用 `z1 > 0` 的布尔矩阵乘上 `dh`，0 点处导数取 0（约定即可，与 PyTorch 一致）；
3. 数值梯度若与解析梯度在某个元素上差一个量级，先检查该元素是否除以 N、是否乘了错误的转置；
4. 训练不收敛 ≠ 梯度错：先跑梯度检查表，再调学习率。

**常见失败与调试方向**：

| 现象 | 可能原因 | 调试方向 |
|:---|:---|:---|
| `gradient_diff` 大 | 未除 N / 转置方向错 | 检查 `X.T @ dhidden` 与 `hidden.T @ dlogits` |
| ReLU 层梯度全 0 | 掩码方向写反 | `dh1 = dh * (z1 > 0)`，不是 `*(z1 < 0)` |
| 单步 loss 上升 | 学习率过大或梯度符号错 | 先 `lr=0.01` 试单步；检查 `W - lr*grad` 符号 |
| 训练 loss 卡住 | 初始化过大导致饱和 | 用 He 初始化 `√(2/fan_in)` |
| 数值梯度耗时长 | 逐参数 2 次前向 | smoke 规模（17 参数）应 < 1 分钟，真实数据用子集 |
