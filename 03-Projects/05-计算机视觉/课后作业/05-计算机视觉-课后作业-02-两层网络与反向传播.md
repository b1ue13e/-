# 05-计算机视觉-课后作业-02-两层网络与反向传播

## 📋 任务描述与学习目标

实现两层全连接网络的前向传播与反向传播（仅 NumPy），用数值梯度验证反向传播正确性，并在 CIFAR-10 子集上训练到可复现的验证指标。

学完本课后你应该能：

- 手写两层 MLP 前向传播与链式法则反向传播梯度；
- 用中心差分数值梯度验证每一层梯度（相对误差阈值）；
- 解释初始化、学习率与正则强度对训练曲线的影响。

## 🎯 任务分层要求（基础 / 进阶 / 综合）

### 基础要求
- [ ] 用 `starter/` 实现两层网络：`affine - ReLU - affine - softmax`
- [ ] 完成反向传播各层梯度（`dW1/db1/dW2/db2`）
- [ ] 数值梯度验证通过（相对误差 < 1e-6 量级）

### 进阶要求
- [ ] 引入 He/Kaiming 初始化与 L2 权重衰减
- [ ] 记录训练/验证损失曲线并解释过拟合现象

### 综合要求
- [ ] 对比不同隐藏层宽度/学习率下的最终指标与失败样本
- [ ] 完成 `rubric.md` 自评与对照报告
