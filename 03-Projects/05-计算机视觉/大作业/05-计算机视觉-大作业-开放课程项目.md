# 05-计算机视觉-大作业-开放课程项目

## 📋 任务描述与学习目标

自选一个计算机视觉问题（分类/检测/分割/生成/自监督之一），按 `proposal → milestone → final report` 三段式推进，给出 baseline、改进与失败分析，形成完整的项目交付。

学完本大作业后你应该能：

- 定义一个有边界的视觉问题，并给出可复核的 baseline；
- 按 proposal/milestone/final report 结构推进并管理风险；
- 说明项目结论、失败模式与下一步，而不是只展示成功结果。

## 📐 任务边界与假设

- **任务边界**：选题限定在课程已教授的五类视觉问题（分类/检测/分割/生成/自监督）之一；项目必须给出可复核的 baseline，不要求 SOTA 或部署上线。
- **允许使用**：课程阶段已覆盖的模型与公开数据集（记录来源与许可证）；预训练权重保持 `link-only` 使用。
- **禁止事项**：不得复制他人项目成果或提交非本人实现；不得在 proposal 未批准前投入大规模训练。
- **假设**：单机单卡可完成；选题过大（数据不可获取/训练不可行）属于需要提前识别的风险，应在 proposal 阶段暴露。

## 🎯 任务分层要求（基础 / 进阶 / 综合）

### 基础要求
- [ ] 提交 proposal（问题、数据、baseline 计划、风险），使用包内 `proposal_template.md`
- [ ] 跑通 baseline 并记录可复核结果

### 进阶要求
- [ ] 完成 milestone 报告（中途结果 + 风险更新）

### 综合要求
- [ ] 完成 final report：结论、失败案例、边界与下一步
- [ ] 用 `ta_grading_template.md` 与 `rubric.md` 完成自评
