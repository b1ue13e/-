# HW06 Milestones

## M0 - 开题前检查

- 跑通 starter 和 smoke test
- 确认前置知识是否具备
- 明确真实数据目录和协议

## M1 - 数据与协议冻结

- 真实数据到位
- 切分和预处理写入 README
- 输出目录和命令固定

## M2 - Baseline 完成

- 完成 `课程项目 baseline + 一项清楚的改进尝试` 的最小实现
- 记录关键指标
- 记录失败案例和异常现象

## M3 - 正式交付

- 完成报告
- 完成提交清单
- 确认结果可复现

## 这份作业真正希望你增长的能力

- 会定义一个合适的视觉问题并给出 baseline
- 会按 proposal -> milestone -> final report 推进项目
- 会说明项目结论、失败与下一步
