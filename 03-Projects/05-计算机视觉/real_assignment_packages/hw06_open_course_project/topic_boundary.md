# HW06 允许选题 / 不建议选题

## 允许选题

- 小型图像分类改进：有清楚 baseline、数据切分和类别级分析
- 迁移学习对比：冻结 vs 微调，且有成本记录
- 最小检测子集实验：有固定 VOC 子集、固定评测协议和失败案例
- 误差分析型项目：核心目标是解释失败模式，而不是只追最高分

## 不建议选题

- 题目过大：例如“做一个通用自动驾驶系统”
- 数据和评价协议不清：只有想法，没有可复核指标
- 没有 baseline：一上来就堆复杂模型
- 完全依赖外部成品仓库：自己无法解释训练、评测和失败
- 需要超出当前课程算力预算的大规模实验

## 老师批准时重点问什么

- baseline 是什么？
- 成功标准是什么？
- 失败了以后还能交什么证据？
