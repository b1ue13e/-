# HW02 Milestones

## M0 - 开题前检查

- 跑通 starter 和 smoke test
- 确认前置知识是否具备
- 明确真实数据目录和协议

## M1 - 数据与协议冻结

- 真实数据到位
- 切分和预处理写入 README
- 输出目录和命令固定

## M2 - Baseline 完成

- 完成 `两层全连接网络 + 梯度检查` 的最小实现
- 记录关键指标
- 记录失败案例和异常现象

## M3 - 正式交付

- 完成报告
- 完成提交清单
- 确认结果可复现

## 这份作业真正希望你增长的能力

- 会独立实现两层网络前向和反向传播
- 会做梯度检查和过拟合烟雾测试
- 能区分实现错误、协议错误和调参问题
