# HW01 Rubric

| 维度 | 分值 | 评分关注点 |
|:---|---:|:---|
| 数据与协议 | 20 | 数据来源、切分、版本与运行协议是否清楚 |
| baseline 与 starter 完整性 | 20 | 是否基于 `kNN + 线性 Softmax` 跑通最小闭环 |
| 结果与失败分析 | 20 | 是否解释失败案例，而不是只报最好结果 |
| 工程组织 | 20 | README、目录、命令、输出是否可复核 |
| 报告质量 | 20 | 是否回答核心问题并写清限制与下一步 |

**通过线建议：**

- `75/100` 及以上；
- 且硬验收项全部通过。
