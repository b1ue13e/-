# 🧭 15-控制与机器人学 课程作业总索引

> 本页是「控制与机器人学」课程作业体系的**唯一挂载点**：作业分层、官方作业链、验收口径与来源全部在此对齐。

## ✅ 验收方式与评分（通用口径）

1. **官方 demo 复现**：每个作业先跑通 PythonRobotics 对应官方 demo（保持原始参数），输出截图与数据存档到本目录。
2. **自写实现**：作业实现不得直接 import 官方函数；自写代码须在**同一随机种子、同一固定场景**下与官方输出对齐（轨迹、误差指标可比）。
3. **轨迹跟踪误差报告**：每个作业交付一份报告：固定场景描述（地图 / 路径 / 速度配置）+ 指标（横向误差 RMS 与 Max、纵向误差、到达时间、成功率）+ 与官方 demo / 基线的误差对比表。
4. **参数敏感性分析**：至少一个关键参数做网格扫描——HW01: Q/R 权重、MPC 预测时域；HW02: 栅格分辨率、采样数；HW03: 前视距离、Stanley 增益 $k$；HW04: 噪声协方差 Q/R——输出"参数 → 误差"曲线并给出结论。
5. **满分 Rubric**：官方复现通过（40 分）+ 自写实现对齐（30 分）+ 误差报告完整（20 分）+ 敏感性分析（10 分）。

## ⚖️ Honor Code

- PythonRobotics 的 demo 代码（MIT License）可阅读、可运行、可对照，但**作业实现必须自己写**；提交时注明"参考了哪些官方文件、改了什么、为什么改"。
- 官方仓库与教材中的公式、伪代码可以引用，但必须在报告中标注出处。
- 已有知识卡可双向引用，但不得复制其内容充当作业产出。
- 完成后再对照官方 solution 复盘；复盘结论写入对应知识点笔记的主动回忆区。
