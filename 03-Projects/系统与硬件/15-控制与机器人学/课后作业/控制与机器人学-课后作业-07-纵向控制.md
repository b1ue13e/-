# 控制与机器人学-课后作业-07-纵向控制

> 本作业为阶段 7（纵向控制）的**课后作业**，验收纵向动力学、PI 速度控制、安全距离/可变时距与 ACC 切换逻辑的基本功。

- 给出跟车/自由巡航的切换条件与状态机。

## 4. 任务背景与边界

- **场景**：单车纵向速度/间距控制，含定速巡航与自适应巡航（ACC）。
- **输入**：车辆参数、期望速度/时距、前车状态。
- **输出**：加速度指令、控制量、间距误差曲线。
- **禁止事项**：不得直接 import 官方控制器充当自写实现；符号须自洽。

## 5. 详细题目

**题目 1（基础）：纵向方程（25 分）**
1a. 写出 $m\dot v = F_{trac}-F_{res}$，列出阻力分项（滚阻/空阻/坡阻/惯量）；
1b. 取 $m=1500\ \text{kg},\ F_{trac}=3000\ \text{N}$，平路无风 $F_{res}=200\ \text{N}$，手算 $\dot v$；
1c. 说明空气阻力随 $v^2$ 变化对高速控制的影响。

**题目 2（基础）：PI 速度控制（25 分）**
2a. 设计 PI 控制器 $a = K_p e_v + K_i \int e_v$，给出离散递推式；
2b. 取 $v_{ref}=20\ \text{m/s},\ v=18\ \text{m/s},\ K_p=0.5,\ K_i=0.1,\ dt=0.1\ \text{s}$，手算一步控制量（设上一步积分项为 0）；
2c. 解释积分项消除稳态误差的机理与抗饱和必要性。

**题目 3（进阶）：安全距离与可变时距（25 分）**
3a. 由恒定车头时距 $T$ 与最小静止间距 $d_0$ 写出期望间距 $d_{des}=d_0+T v$；
3b. 取 $T=1.5\ \text{s},\ d_0=2\ \text{m},\ v=30\ \text{m/s}$ 计算 $d_{des}$；
3c. 说明上坡（坡阻为正）对跟随间距与驱动力的扰动方向。

**题目 4（综合）：ACC 切换逻辑（25 分）**
4a. 给出"跟车模式 ↔ 自由巡航模式"的切换条件（基于前车是否存在/间距阈值）；
4b. 画出模式状态机并标注触发量与迟滞；
4c. 用一段最小 Python 或状态表验证：前车消失时平滑切回定速巡航。

## 9. 引导与自检（不泄露答案）

**检查点**：
- [ ] 题 1b 加速度单位 m/s²；
- [ ] PI 递推中积分项累积的是速度误差而非加速度；
- [ ] 期望间距随时距与速度单调递增；
- [ ] ACC 切换含迟滞以避免模式抖动。

**常见失败模式**：
- 阻力单位错（N vs kg·m/s²）→ 统一量纲；
- 积分饱和导致超调 → 加抗饱和/clamp；
- 切换无迟滞 → 在阈值附近振荡。

**提交前自检**：推导完整、手算有步骤、代码可运行、未复制官方数值。
