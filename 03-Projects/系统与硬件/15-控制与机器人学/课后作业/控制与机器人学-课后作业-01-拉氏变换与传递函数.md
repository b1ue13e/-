# 控制与机器人学-课后作业-01-拉氏变换与传递函数

> 课后作业（lesson · problem-set）：验证阶段 1「控制地基」的拉氏变换与传递函数理解，为后续时域/频域分析打基础。

## 2. 学习目标

完成后能够：
- 熟练完成常用函数（阶跃/冲激/指数/正弦）的拉氏变换与逆变换；
- 由微分方程写出传递函数，并识别零极点；
- 用终值定理/初值定理分析稳态与初值；
- 独立完成一次闭环手算，不查表也能复现核心变换对。

## 3. 所需知识

## 4. 任务背景与边界

- **场景**：一阶/二阶系统的建模与变换分析（RLC 电路、弹簧阻尼、电机一阶模型）。
- **输入**：各题给出的微分方程/电路图。
- **输出**：变换结果、传递函数、零极点与响应表达式（手写推导，可附 Python `sympy` 校验）。
- **禁止**：直接抄写教材答案；每题必须给出推导步骤。

## 5. 详细题目

**题目 1（基础，15 分）**：求下列函数的拉氏变换：
1a. $f(t) = 3e^{-2t}$；
1b. $f(t) = t \cdot u(t)$；
1c. $f(t) = \sin(3t)$；
1d. $f(t) = e^{-t}\cos(2t)$。

**题目 2（基础，20 分）**：求下列象函数的逆拉氏变换（部分分式展开）：
2a. $F(s) = \dfrac{5}{s(s+2)}$；
2b. $F(s) = \dfrac{3s+4}{s^2+4s+13}$（提示：配方法）。

**题目 3（核心，25 分）**：系统微分方程 $\ddot{y} + 5\dot{y} + 6y = 4\dot{u} + 2u$：
3a. 写出传递函数 $G(s) = Y(s)/U(s)$；
3b. 求零极点，判断稳定性；
3c. 求单位阶跃响应的完整时域表达式 $y(t)$。

**题目 4（应用，25 分）**：一阶电机模型 $G(s) = \dfrac{K}{\tau s + 1}$（$K=2$，$\tau=0.5$）：
4a. 求单位阶跃响应 $y(t)$ 并手绘草图；
4b. 用终值定理求稳态值并验证；
4c. 求 $y(t)$ 达到 63.2% 稳态值的时间。

**题目 5（综合，15 分）**：用终值定理判断 $G(s) = \dfrac{1}{s^2+s+1}$ 的单位阶跃稳态值；解释为何该定理在 $s=0$ 有极点时不可用。

## 9. 引导与自检

- 常见错误：变换性质漏项（如 $e^{-at}$ 的平移）、部分分式重复根处理、终值定理用在不满足条件处；
- 自查清单：
  - [ ] 每个变换对都检查了收敛域条件；
  - [ ] 部分分式展开后用初值定理验证（$f(0^+)=\lim sF(s)$）；
  - [ ] 传递函数化简后零极点重新核对；
  - [ ] 阶跃响应终值与稳态值一致。
