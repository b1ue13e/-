# 控制与机器人学-课后作业-04-PID整定与二阶系统

> 课后作业（lesson · problem-set）：验证阶段 4「经典控制入门」的 PID 与二阶系统设计能力，为阶段 6 横向控制调参打基础。

| 课程 | 控制与机器人学（15-控制与机器人学） |

## 2. 学习目标

完成后能够：
- 由二阶系统参数（$\zeta, \omega_n$）计算时域指标（超调/调节时间/峰值时间）；
- 设计 P/PI/PD/PID 控制器并分析闭环响应变化；
- 用 Ziegler-Nichols 或 Lambda 法给出初始参数并验证；
- 手算一次完整整定闭环，理解三环（电流/速度/位置）的基本分工。

## 3. 所需知识

- `requires`（frontmatter）：二阶系统、PID公式、三环控制；
- 建议先完成 [[CC调参|CC调参]]、[[频率响应|频率响应]] 的检索练习。

## 4. 任务背景与边界

- **场景**：位置伺服系统（电机 + 减速器），典型二阶对象 $G_p(s) = \dfrac{K}{s(\tau s + 1)}$。
- **输入**：各题给定的对象参数与性能指标。
- **输出**：控制器参数、闭环传递函数、性能指标计算与整定结论。
- **禁止**：只给最终参数不写依据；调参必须有指标对照。

## 5. 详细题目

**题目 1（基础，20 分）**：二阶系统 $G(s) = \dfrac{100}{s^2 + 10s + 100}$：
1a. 求 $\zeta, \omega_n$；
1b. 求超调量、峰值时间、2% 调节时间；
1c. 若要求超调 < 5%，$\zeta$ 至少取多少？

**题目 2（核心，25 分）**：对象 $G_p(s) = \dfrac{5}{s(s+2)}$ 串入比例控制器 $K_p$：
2a. 求闭环传递函数，画出 $K_p$ 增大时极点轨迹（定性）；
2b. 求使系统临界稳定的 $K_p$ 值；
2c. 选定 $K_p$ 使阻尼比 $\zeta = 0.5$，求对应超调。

**题目 3（进阶，30 分）**：对题目 2 对象设计 PID 控制器 $K_p + K_d s + K_i/s$：
3a. 用 Ziegler-Nichols（临界增益法）给出初始 $K_p, K_i, K_d$；
3b. 仿真/手算闭环阶跃响应，报告超调与调节时间；
3c. 若超调过大，说明应调整哪个参数、为什么。

**题目 4（应用，25 分）**：位置伺服三环结构（电流内环 → 速度环 → 位置环）：
4a. 说明三环的分工与带宽关系（内快外慢）；
4b. 给出一组符合"内环比外环快 5-10 倍"的示例带宽；
4c. 为什么内环需要先整定？

## 6. 环境与复现

- 手算为主；可选 Python 验证：`control` 库（`tf`、`step_response`、`margin`）或手写仿真；
- 题目 3b 建议用 Python 仿真验证（提交响应曲线截图）。

## 7. 提交产物

- 解答文档（推导 + 参数 + 指标）；
- 题目 3b 的仿真响应曲线（如用 Python）；
- 一份"整定心得"（参数如何影响指标，≤ 200 字）。

## 8. 验收标准与 Rubric

## 9. 引导与自检

- 常见错误：$\omega_d$ 与 $\omega_n$ 混淆、调节时间用错准则（2% vs 5%）、ZN 参数直接用不验证；
- 自查清单：
  - [ ] 每个指标都标了适用条件（欠阻尼）；
  - [ ] 闭环极点与 $\zeta, \omega_n$ 换算正确；
  - [ ] 仿真结果与手算一致；
  - [ ] 调参结论能解释"为什么这么调"。
