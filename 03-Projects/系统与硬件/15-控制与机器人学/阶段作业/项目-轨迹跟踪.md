# 项目-轨迹跟踪

> 阶段作业（stage · lab）：在 Frenet 框架下实现"参考轨迹 → 误差 → 横向控制"完整跟踪链，验证误差收敛与跟踪精度。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 8：轨迹与路径跟踪 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 实现参考轨迹的 Frenet 投影（最近点 + 误差提取）；
- 基于横向误差设计跟踪控制（PP/Stanley/LQR）；
- 验证误差收敛与速度适应性；
- 报告"路径曲率 → 跟踪误差"的关系。

## 3. 所需知识

- `requires`：Frenet误差、横向多项式、横向动力学；
- 前置支撑：Frenet转换、预瞄距离、算法选型。

## 4. 任务背景与边界

- **场景**：参考轨迹（含直线+弯道+正弦），车辆跟踪；
- **输入**：参考轨迹点、车速、控制器参数；
- **输出**：Frenet 误差曲线、跟踪轨迹、指标；
- **禁止**：直接用全局坐标误差代替 Frenet 误差交差。

## 5. 详细题目

**题目 1（基础，25 分）：Frenet 投影**
1a. 实现最近路径点搜索（或精确投影）求 $(s, d)$；
1b. 提取横向偏差 $d$ 与航向偏差 $\Delta\psi$；
1c. 对比"全局 xy 误差"与"Frenet 误差"在弯道处的差异。

**题目 2（核心，30 分）：跟踪控制**
2a. 用 PP（Frenet 版）或 Stanley 跟踪参考轨迹；
2b. 直线+弯道轨迹仿真，报告 Frenet 误差 RMS/Max；
2c. 验证误差在初始偏差 1 m 下收敛。

**题目 3（进阶，25 分）：速度-曲率关系**
3a. 扫车速 $v \in \{5, 10, 15\}$ m/s，报告误差变化；
3b. 在弯道段单独统计误差，解释"高速弯道误差增大"；
3c. 实现弯道自动降速（按曲率），对比改进。

**题目 4（应用，20 分）：跟踪链完整性**
4a. 串联"规划（换道作业）→ 插值（轨迹插值作业）→ 跟踪"；
4b. 端到端误差报告；
4c. 结论：跟踪链各环节误差的贡献与瓶颈。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定参考轨迹、种子、控制频率；
- 报告注明控制器参数与轨迹参数。

## 7. 提交产物

- 代码 + README；
- 指标表（车速 × 误差）。
