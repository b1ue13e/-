# 项目-换道规划

> 阶段作业（stage · lab）：用五次多项式在 Frenet 系生成换道轨迹，验证可行性（曲率/速度约束）并评估舒适性。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 8：轨迹与路径跟踪 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 用五次多项式生成横向换道轨迹（边界条件：位移/速度/加速度）；
- 检验轨迹可行性（曲率上限、加加速度、无碰撞）；
- 扫换道时长评估舒适性指标；
- 输出可跟踪的换道轨迹（供跟踪控制器使用）。

## 3. 所需知识

- `requires`：横向多项式、轨迹定义、轨迹可行性；
- 前置支撑：Frenet转换、S曲线规划（模块 A/B）。

## 4. 任务背景与边界

- **场景**：高速公路双车道，自车 30 m/s 换道至相邻车道（横向偏移 3.5 m）；
- **输入**：换道时长 $T$、横向偏移、边界条件；
- **输出**：横向/纵向轨迹、曲率曲线、可行性判定；
- **禁止**：直接用正弦函数近似交差；必须用多项式边界条件求解。

## 5. 详细题目

**题目 1（基础，25 分）：五次多项式**
1a. 推导五次多项式 $d(t) = a_0 + a_1 t + \cdots + a_5 t^5$ 的系数（给定 $d(0), \dot d(0), \ddot d(0), d(T), \dot d(T), \ddot d(T)$）；
1b. 换道场景：$T = 6$ s，$d$ 从 0 → 3.5 m，两端速度/加速度为 0；
1c. 手算/代码解出系数并画 $d(t), \dot d(t), \ddot d(t)$。

**题目 2（核心，30 分）：轨迹合成**
2a. 纵向保持匀速（$s(t) = vt$），合成 Frenet 轨迹 $(s, d)$；
2b. 转回笛卡尔坐标并采样路径点；
2c. 计算曲率 $\kappa(t)$，验证 ≤ 车辆最大转向曲率。

**题目 3（进阶，25 分）：可行性检验**
3a. 检查加加速度 $jerk = d^{(3)}(t)$ 峰值（舒适性）；
3b. 检查与相邻车道车辆的碰撞窗口（时间-空间）；
3c. 扫 $T \in \{4, 6, 8, 10\}$ s，报告 jerk/曲率峰值变化。

**题目 4（应用，20 分）：可跟踪性**
4a. 把换道轨迹输出给 PP/Stanley 跟踪器（复用阶段 6 实现），测跟踪误差；
4b. 报告"规划曲率约束 → 跟踪可行性"的一致性；
4c. 结论：换道轨迹设计的工程参数选择。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定车速、车道宽、换道时长表；
- 报告注明多项式系数与约束值。

## 7. 提交产物

- 报告：多项式推导、轨迹图、可行性表、跟踪验证、结论；
- 代码 + README；
- 数据表（T vs jerk vs 曲率）。

## 9. 引导与自检

- 常见失败：边界条件符号错、曲率公式用错（二阶/一阶比）、jerk 未检查；
- 调试路径：多项式系数验证（端点）→ 轨迹合成 → 约束 → 跟踪；
- 自查清单：
  - [ ] $d(0), d(T)$ 及导数满足边界；
  - [ ] 曲率全程 ≤ 上限；
  - [ ] T 扫描有 jerk 曲线；
  - [ ] 跟踪误差 RMS 有记录。
