# 项目-机械臂抓取

> 阶段作业（stage · lab）：在 PyBullet 中实现"目标位姿 → IK → 关节轨迹 → 抓取"的完整机械臂抓取闭环。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 2（运动学）+ 阶段 11（工程实现） |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 在 PyBullet 中加载机械臂 URDF 并驱动关节；
- 用 IK 求取目标抓取位姿的关节角；
- 生成关节轨迹（PTP）并跟踪（关节 PID）；
- 完成"接近-抓取-提升"任务并评估成功率。

## 3. 所需知识

- `requires`：机械臂DH参数与逆运动学、几何Jacobian、关节空间控制实现、笛卡尔与力控实现；
- 前置支撑：变换链、齐次变换矩阵、几何法IK/数值IK。

## 4. 任务背景与边界

- **场景**：PyBullet 仿真，6DOF 机械臂抓取固定物体；
- **输入**：物体位姿、夹爪目标位姿；
- **输出**：抓取轨迹、成功率、失败分析；
- **禁止**：手动拖拽关节交差；必须 IK + 轨迹 + 控制闭环。

## 5. 详细题目

**题目 1（基础，25 分）：环境搭建**
1a. 在 PyBullet 加载机械臂 URDF（如 KUKA iiwa 或自建二连杆+夹爪）；
1b. 实现关节读取/设置、重力、碰撞检测；
1c. 放置目标物体（方块/球），打印末端与物体位姿。

**题目 2（核心，30 分）：IK 与轨迹**
2a. 给定物体位姿 + 预抓取偏移（沿接近方向退 0.1 m），用 PyBullet IK 或自写数值 IK 求关节角；
2b. 生成 PTP 轨迹（三次/五次多项式）；
2c. 关节 PID 跟踪，报告末端轨迹误差。

**题目 3（进阶，25 分）：抓取闭环**
3a. 实现"接近 → 闭合夹爪 → 提升"状态机；
3b. 抓取后提升 0.2 m，检测物体是否随动（成功判据）；
3c. 3 种物体位姿各跑 5 次，报告成功率。

**题目 4（应用，20 分）：失败分析**
4a. 分析失败案例（碰撞、IK 无解、滑脱）；
4b. 尝试改进（调整预抓取偏移/速度）并重测；
4c. 结论：抓取任务的运动学/控制瓶颈。

## 6. 环境与复现

- Python 3.10+，`pybullet`（4.x）、`numpy`、`matplotlib`；
- 固定随机种子、物体位姿集合、控制频率（240 Hz 仿真 / 100 Hz 控制）；
- 报告注明 URDF 来源与 PyBullet 版本。

## 9. 引导与自检

- 常见失败：夹爪闭合时序错（未到位就闭合）、IK 多解选了不可达解、提升速度过快滑脱；
- 调试路径：先单次抓取跑通 → 成功率统计 → 失败分析；
- 自查清单：
  - [ ] 预抓取位姿有接近方向偏移；
  - [ ] 夹爪闭合前末端到位（误差阈值）；
  - [ ] 成功判据明确（提升后物体位移 < 阈值）；
  - [ ] 失败案例逐个有根因。
