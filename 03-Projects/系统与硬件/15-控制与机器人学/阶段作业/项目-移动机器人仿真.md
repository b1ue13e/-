# 项目-移动机器人仿真

> 阶段作业（stage · lab）：仿真差分驱动机器人的运动学与里程计，验证积分精度与漂移特性。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 3：移动机器人与车辆模型 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 实现差速驱动运动学（轮速 → $v, \omega$ → 位姿积分）；
- 实现里程计模型并分析积分漂移；
- 与 PythonRobotics `diff_drive.py` 逐拍对比（$10^{-6}$ 精度）；
- 理解"精确圆弧积分 vs 欧拉积分"的差异。

## 3. 所需知识

- `requires`：移动机器人运动学与差分驱动、里程计、差分驱动；
- 前置支撑：ICR（瞬心）、坐标系变换。

## 4. 任务背景与边界

- **场景**：差分驱动机器人（轮距 $b$、轮径 $r$），轮速指令序列；
- **输入**：左右轮速时间序列（含变向/曲线）；
- **输出**：位姿轨迹、积分误差、与官方 demo 的逐拍对比；
- **禁止**：直接用官方 `State.update` 交差；须自写积分。

## 5. 详细题目

**题目 1（基础，25 分）：运动学实现**
1a. 实现 $v = r(\omega_L + \omega_R)/2$、$\omega = r(\omega_L - \omega_R)/b$；
1b. 欧拉积分位姿（$x, y, \theta$）；
1c. 直线/原地转/弧线三场景仿真并画轨迹。

**题目 2（核心，30 分）：与官方对齐**
2a. 同一轮速序列（PythonRobotics demo 场景），逐拍对比位姿；
2b. 报告最大误差（应 < $10^{-6}$，纯数值差异）；
2c. 实现**精确圆弧积分**版本，对比欧拉的轨迹终点差异。

**题目 3（进阶，25 分）：里程计漂移**
3a. 加入轮径误差（±1%），长时间仿真报告位置漂移；
3b. 加轮速噪声（高斯），统计终点分布（多次 MC）；
3c. 解释"为何里程计只能短时可靠、需要绝对修正"。

**题目 4（应用，20 分）：步长敏感性**
4a. 扫 $dt \in \{0.1, 0.05, 0.01\}$ s，报告终点误差收敛；
4b. 给出工程推荐控制/仿真步长；
4c. 结论：运动学模型在 EKF 预测步中的角色（阶段 10 衔接）。

## 9. 引导与自检

- 常见失败：$\omega$ 符号（左右反）、欧拉步长过大、圆弧积分公式用错；
- 调试路径：直线 → 原地转 → 弧线 → 对齐 → 漂移；
- 自查清单：
  - [ ] 直线无横向漂移；
  - [ ] 与官方逐拍误差 < $10^{-6}$；
  - [ ] 漂移统计用多次 MC 而非单次；
  - [ ] $dt$ 扫描有收敛趋势。
