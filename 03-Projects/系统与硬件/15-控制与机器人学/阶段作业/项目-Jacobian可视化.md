# 项目-Jacobian可视化

> 阶段作业（stage · lab）：可视化机械臂 Jacobian 矩阵与可操作性椭球，识别奇异位形并分析速度传递特性。

## 2. 学习目标

完成后能够：
- 计算二连杆/三连杆机械臂的几何 Jacobian；
- 绘制可操作性椭球（末端速度可达方向）；
- 通过条件数/行列式定位奇异位形；
- 解释奇异附近速度放大与数值问题。

## 3. 所需知识

- `requires`：几何Jacobian、解析Jacobian、奇异位形、可操作性；
- 前置支撑：DH 参数、变换链、正运动学。

## 4. 任务背景与边界

- **场景**：平面二连杆/三连杆机械臂；
- **输入**：连杆长度、关节角序列；
- **输出**：$J(q)$、可操作性椭球图、奇异位形列表；
- **禁止**：直接调库不展示原理；椭球必须从 $J$ 奇异值构造。

## 5. 详细题目

**题目 1（基础，25 分）：Jacobian 计算**
1a. 推导二连杆平面臂的几何 Jacobian $J(q)$（2×2 位置 Jacobian）；
1b. 给定 $q = (\pi/4, \pi/4)$、$l_1 = l_2 = 1$，数值计算 $J$；
1c. 用 `numpy.linalg.svd` 分解，报告奇异值。

**题目 2（核心，30 分）：可操作性椭球**
2a. 由 $J J^\top$ 的特征值/特征向量绘制末端速度椭球；
2b. 扫 $\theta_2 \in [0, \pi]$，观察椭球形状变化；
2c. 报告"椭球越扁 → 该方向速度能力越弱"的实例。

**题目 3（进阶，25 分）：奇异位形**
3a. 用 $\det(J)$ 或最小奇异值定位奇异位形（如 $\theta_2 = 0, \pi$）；
3b. 在奇异附近给定末端速度，计算关节速度 $\dot q = J^{-1} \dot x$，报告数值放大；
3c. 演示阻尼最小二乘（$J^\top(JJ^\top + \lambda I)^{-1}$）对奇异附近速度的处理。

**题目 4（应用，20 分）：三连杆扩展**
4a. 扩展到三连杆（带姿态），计算 3×3 Jacobian；
4b. 重绘椭球并定位新奇异位形；
4c. 结论：Jacobian 可视化在机械臂运动规划/力控中的角色。

## 9. 引导与自检

- 常见失败：几何 Jacobian 的旋转项漏掉、奇异值分解方向混、阻尼 $\lambda$ 过大失真；
- 调试路径：二连杆解析验证 → 椭球 → 奇异 → 三连杆；
- 自查清单：
  - [ ] $J$ 数值与手算一致；
  - [ ] 椭球轴方向 = 特征向量、长度 = 奇异值；
  - [ ] 奇异处最小奇异值 → 0；
  - [ ] 阻尼最小二乘的 $\lambda$ 扫描有对比。
