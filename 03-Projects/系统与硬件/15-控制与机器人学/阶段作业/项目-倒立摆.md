# 项目-倒立摆

> 阶段作业（stage · lab）：为倒立摆建立状态空间模型，用状态反馈与 LQR 设计摆起与平衡控制，验证能控性与极点配置。

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 5：状态空间与现代控制 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 从物理方程推导倒立摆非线性模型并线性化到状态空间；
- 验证系统能控性；
- 用极点配置与 LQR 设计平衡控制器；
- 仿真摆起（能量法或 LQR 分段）与平衡切换。

## 3. 所需知识

- `requires`：状态空间表示、能控性、LQR代价函数、状态反馈；
- 前置支撑：拉格朗日方程（阶段 3）、二阶系统（阶段 1）；
- 可选扩展：状态估计（观测器，见 [[05-状态空间与现代控制/观测器结构|观测器结构]]）。

## 4. 任务背景与边界

- **场景**：小车-倒立摆（cart-pole），状态 $[x, \dot x, \theta, \dot\theta]$，控制力 $F$；
- **输入**：物理参数（$m=0.1$ kg、$M=1$ kg、$l=0.5$ m、$g=9.81$）；
- **输出**：模型、能控性分析、LQR 参数、平衡/摆起仿真；
- **禁止**：直接用 gym 环境交差（可用作对照）；控制器必须自设计。

## 5. 详细题目

**题目 1（基础，25 分）：建模与线性化**
1a. 用拉格朗日方程推导 cart-pole 非线性方程；
1b. 在平衡点（$\theta = 0$）线性化，写出 $A, B$ 矩阵；
1c. 验证能控性矩阵满秩。

**题目 2（核心，30 分）：平衡控制设计**
2a. 用极点配置（如 $[-2\pm j2, -5, -5]$）设计 $K$；
2b. 用 LQR（$Q = \text{diag}(10, 1, 100, 1)$，$R = 0.1$）设计 $K_{lqr}$；
2c. 仿真两控制器在 $\theta_0 = 0.1$ rad 下的平衡恢复，对比指标。

**题目 3（进阶，25 分）：摆起控制**
3a. 设计能量法摆起（摆动直到接近竖直）；
3b. 实现摆起 → 平衡的切换逻辑（角度阈值 + 状态重置）；
3c. 从 $\theta_0 = \pi$（倒挂）完整仿真到稳定平衡。

**题目 4（应用，20 分）：鲁棒性**
4a. 参数扰动（$m$ ±20%）下重测 LQR 平衡；
4b. 输入饱和（$|F| \le 10$ N）下的表现；
4c. 报告"为何 LQR 权重 $q_\theta$ 大 = 摆更硬"的直观解释。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`、`scipy`（`solve_continuous_are`）；
- 固定仿真步长（1 ms）与初始条件；
- 报告注明 $A, B$、$K$、$Q, R$ 数值。

## 9. 引导与自检

- 常见失败：$\theta$ 符号错导致不稳定、线性化点误用（非平衡点）、摆起切换抖动（增益突变）；
- 调试路径：先固定摆（只控 $x$）→ 平衡 → 摆起；
- 自查清单：
  - [ ] $A$ 矩阵特征值含正实部（开环不稳定，符合预期）；
  - [ ] 闭环特征值 = 配置值；
  - [ ] LQR 解出 $P \succ 0$；
  - [ ] 摆起切换阈值有记录。
