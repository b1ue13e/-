# 项目-电机三环

> 阶段作业（stage · lab）：为直流电机搭建电流-速度-位置三环串级控制，验证"内快外慢"带宽设计与整定顺序。

| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |

## 2. 学习目标

完成后能够：
- 建立电流环/速度环/位置环的被控对象模型；
- 按"内环先整定、带宽 5-10 倍递增"设计串级参数；
- 仿真三环阶跃响应（位置指令跟踪）；
- 分析内环带宽对整体性能的影响。

## 3. 所需知识

- `requires`：三环控制、串级控制、串级设计、PID公式；
- 前置支撑：一阶系统（阶段 1）、二阶系统、电机模型。

## 4. 任务背景与边界

- **场景**：直流电机位置伺服，三环结构：电流环（内）→ 速度环（中）→ 位置环（外）；
- **输入**：电机参数、各环 PI/P 参数；
- **输出**：三环阶跃响应、带宽对比、整定顺序记录；
- **禁止**：一次全开三环一起调；必须按内到外逐环整定。

## 5. 详细题目

**题目 1（基础，25 分）：对象建模**
1a. 电流环对象：电枢回路 $G_i(s) = \dfrac{1}{L_a s + R_a}$；
1b. 速度环对象：$G_v(s) = \dfrac{K_t}{(Js + B)(L_a s + R_a) + K_t K_e}$（化简）；
1c. 位置环对象：$G_p(s) = G_v(s)/s$；
1d. 给定参数（$R_a=1, L_a=0.01, K_t=K_e=0.1, J=0.01, B=0.001$）写出三环传递函数。

**题目 2（核心，30 分）：内到外整定**
2a. 电流环：PI 整定使带宽 $\omega_{ci} \approx 500$ rad/s；
2b. 速度环：在内环闭合基础上整定，$\omega_{cv} \approx 80$ rad/s；
2c. 位置环：比例控制，$\omega_{cp} \approx 10$ rad/s；
2d. 记录"内快外慢 5-10 倍"的带宽比例。

**题目 3（进阶，25 分）：闭环验证**
3a. 位置阶跃（1 rad）仿真三环响应，报告超调/调节时间/稳态误差；
3b. 加载力矩扰动，测位置跌落；
3c. 故意把内环带宽设慢（与外环同量级），复现性能劣化。

**题目 4（应用，20 分）：参数分析**
4a. 扫位置环 $K_{pp}$（×0.1/×1/×10），报告超调与响应速度权衡；
4b. 说明为什么内环必须先整定（外环控制器看到的是内环闭环后的对象）；
4c. 报告"三环整定顺序"的经验总结。

## 9. 引导与自检

- 常见失败：内环未闭合就调外环、带宽比例不够（外环比内环快）、速度环忘记内环闭合后的等效对象；
- 调试路径：电流环单闭环 → 速度环（闭合电流环）→ 位置环（闭合速度环）；
- 自查清单：
  - [ ] 三环带宽比值 5-10 倍；
  - [ ] 每环整定时前序环已闭合；
  - [ ] 位置阶跃无稳态误差（外环含积分或前馈）；
  - [ ] 内环变慢的劣化实验有量化对比。
