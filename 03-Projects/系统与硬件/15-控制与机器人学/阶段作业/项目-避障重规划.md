# 项目-避障重规划

> 阶段作业（stage · lab）：实现"感知障碍 → 碰撞检测 → 局部重规划"的动态避障闭环，验证成功率与重规划延迟。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 8：轨迹与路径跟踪 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 实现障碍物检测与碰撞检测（线段-圆/栅格）；
- 实现全局路径 + 局部重规划（检测到新障碍时重算）；
- 验证动态障碍场景下的成功率；
- 分析重规划延迟对安全性的影响。

## 3. 所需知识

- `requires`：碰撞检测、路径规划Astar与RRT、栅格地图与占据栅格；
- 前置支撑：轨迹跟踪（上一作业）、路径插值。

## 4. 任务背景与边界

- **场景**：动态障碍（移动行人/车辆）在路径上出现；
- **输入**：地图、起点终点、障碍轨迹（时变）；
- **输出**：避障轨迹、碰撞事件、成功率；
- **禁止**：静止障碍一遍过交差；必须有动态障碍场景。

## 5. 详细题目

**题目 1（基础，25 分）：碰撞检测**
1a. 实现线段-圆碰撞检测（车辆简化成圆/线段）；
1b. 实现栅格占用检查（路径点 vs 占据格）；
1c. 静态障碍场景验证检测正确性。

**题目 2（核心，30 分）：重规划闭环**
2a. 全局 A* 规划初始路径；
2b. 每步检查碰撞：检测到新障碍 → 以当前位置为起点重规划（A*/RRT*）；
2c. 静态+移动障碍混合场景仿真，报告是否成功到达。

**题目 3（进阶，25 分）：动态场景**
3a. 移动障碍（横向穿越/迎面）场景各 10 次 MC 运行；
3b. 报告成功率、最小净距、重规划次数；
3c. 分析失败案例（重规划太慢/路径被占）。

**题目 4（应用，20 分）：延迟影响**
4a. 人为加重规划延迟（0.1/0.3/0.5 s），报告成功率下降；
4b. 比较"每步检查重规划" vs "定时重规划"；
4c. 结论：避障重规划的关键设计参数。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定地图、障碍轨迹、种子、MC 次数；
- 报告注明检测半径/重规划策略。

## 7. 提交产物

- 报告：检测实现、重规划闭环、MC 统计、延迟分析、结论；
- 代码 + README；
- 成功率与失败案例表。

## 9. 引导与自检

- 常见失败：碰撞检测漏检（步长过大）、重规划起点未贴当前位姿、动态障碍用静止近似；
- 调试路径：静态 → 单个移动障碍 → MC 统计 → 延迟；
- 自查清单：
  - [ ] 碰撞事件计数准确；
  - [ ] 重规划起点 = 当前位姿；
  - [ ] MC 次数 ≥ 10、种子固定；
  - [ ] 延迟曲线有下降趋势。
