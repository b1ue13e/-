# 项目-ACC仿真

> 阶段作业（stage · lab）：实现自适应巡航（ACC）——定速/跟车双模式与切换逻辑，验证安全距离保持与时延影响。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 7：纵向控制 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 实现固定时距/可变时距安全距离模型；
- 设计"定速 ↔ 跟车"切换逻辑（前车检测 + 速度选择）；
- 仿真典型场景（前车减速、切入、驶离）验证 ACC 行为；
- 分析感知时延对安全性与舒适性的影响。

## 3. 所需知识

- `requires`：安全距离、可变时距、ACC切换逻辑、时延补偿；
- 前置支撑：PI速度控制、纵向方程（定速巡航作业）。

## 4. 任务背景与边界

- **场景**：单车道跟车，主车 ACC，前车速度序列给定；
- **输入**：前车轨迹（含减速/加速/切入）、ACC 参数（$h$ 时距、$a_{max}$）；
- **输出**：主车速度/距离曲线、模式切换标记；
- **禁止**：固定时距一条道走到黑；必须实现切换逻辑与时距模型。

## 5. 详细题目

**题目 1（基础，25 分）：安全距离模型**
1a. 实现固定时距 $d = v\tau + d_0$ 与可变时距（$h$ 随速度/前车状态）；
1b. 对比两种模型在高速/低速的最小安全距离；
1c. 实现纵向速度控制（复用定速巡航的 PI）。

**题目 2（核心，30 分）：ACC 切换逻辑**
2a. 实现模式状态机：定速（无前车/前车远）↔ 跟车（前车在安全距离内）；
2b. 切换条件明确（距离/速度阈值 + 滞回避免抖动）；
2c. 仿真"前车从 30 减速到 15 m/s"场景，验证切换与无碰撞。

**题目 3（进阶，25 分）：场景测试**
3a. 场景 A：前车急刹（-4 m/s²），测最小距离；
3b. 场景 B：旁车切入（距离突变），测切换响应；
3c. 场景 C：前车驶离（恢复定速），测模式退出。

**题目 4（应用，20 分）：时延与舒适性**
4a. 感知时延 0.1/0.3/0.5 s 下重测场景 A，报告最小距离与碰撞风险；
4b. 加速度平滑（$jerk$ 限制）前后对比舒适性；
4c. 结论：ACC 的安全-舒适权衡与时延对策。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定前车轨迹（含时间戳）、ACC 参数表、仿真步长；
- 报告注明时延与平滑参数。

## 9. 引导与自检

- 常见失败：切换滞回不足导致模式抖动、安全距离模型用错单位、时延只加在测量不加在控制；
- 调试路径：单跟车 → 减速场景 → 切入 → 时延；
- 自查清单：
  - [ ] 三场景均无碰撞；
  - [ ] 模式切换时间轴标注清晰；
  - [ ] 时延扫描有最小距离曲线；
  - [ ] 舒适性对比用 jerk 指标。
