# 控制与机器人学-阶段作业-08-路径规划与轨迹生成

> 阶段作业（stage · lab）：验收阶段 8「轨迹与路径跟踪」的路径规划（A*/RRT）与 Frenet 轨迹生成闭环。非官方中文版：基于 PythonRobotics 开放材料本地化改编。

## 2. 学习目标

完成后能够：
- 在栅格地图上实现 A*，理解启发式与最优性；
- 实现 RRT/RRT* 并在同一地图比较收敛与路径质量；
- 用 Frenet 采样生成平滑轨迹并做碰撞检测；
- 输出"规划 → 轨迹 → 可跟踪性"的完整证据链。

## 3. 所需知识

- `requires`：路径规划Astar与RRT、栅格地图与占据栅格、Frenet转换、S曲线规划；
- 前置支撑：路径定义/路径表示/轨迹可行性/速度分配（模块 A）；
- 可选扩展：避障重规划（不设隐性前置）。

## 4. 任务背景与边界

- **场景**：固定迷宫地图（如 100×100 栅格），起点/终点给定；
- **输入**：栅格地图、起点终点、车辆运动学约束（最大转向角）；
- **输出**：规划路径、Frenet 轨迹、碰撞检查结果、对比表；
- **禁止**：直接 import 官方求解函数作为自写实现；官方代码仅对照基线。

## 5. 详细题目

**题目 1（基础，25 分）：A\* 实现**
1a. 实现 A*（8 邻域或 4 邻域，欧氏/曼哈顿启发式）；
1b. 在同一迷宫上运行，报告路径长度、扩展节点数；
1c. 对比两种启发式的最优性与扩展效率。

**题目 2（基础，25 分）：RRT 与 RRT\***
2a. 实现基本 RRT（采样、最近邻、扩展）；
2b. 实现 RRT*（重连线），固定随机种子；
2c. 同一地图比较：收敛时间、路径长度、路径平滑度。

**题目 3（核心，35 分）：Frenet 轨迹生成**
3a. 把规划路径转为 Frenet 坐标（s/d）；
3b. 用五次多项式生成横向轨迹采样 + 纵向速度规划；
3c. 对候选轨迹做碰撞检测与代价评估，选出最优；
3d. 输出可跟踪轨迹（时间参数化位置序列）并验证曲率约束。

**题目 4（进阶，15 分）：对比与敏感性**
4a. A* vs RRT 的适用场景结论（确定性最优 vs 随机采样）；
4b. 扫栅格分辨率（0.5/1.0/2.0 m）与采样数，画"参数 → 路径质量"曲线。

## 9. 引导与自检

- 常见失败：A* 用对角穿越障碍、RRT 步长过大穿墙、Frenet 横向采样未限幅、碰撞检测用点而非线段；
- 调试路径：先单跑 A*（有答案）→ 再 RRT（比较）→ 最后 Frenet 接规划路径；
- 自查清单：
  - [ ] A* 结果用 `networkx` 或暴力 BFS 交叉验证最优性；
  - [ ] RRT 随机种子固定，多次运行取统计；
  - [ ] Frenet 轨迹逐点检查曲率 ≤ 车辆最大转向曲率；
  - [ ] 碰撞检测覆盖线段与障碍格交点。
