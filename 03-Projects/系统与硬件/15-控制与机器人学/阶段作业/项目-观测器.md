# 项目-观测器

> 阶段作业（stage · lab）：为状态不可全测的系统设计 Luenberger 观测器，验证能观性、观测器极点与分离原理。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 5：状态空间与现代控制 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 判断系统的能观性并设计观测器增益 $L$；
- 仿真观测器估计收敛（对比真实状态）；
- 用分离原理组合"状态反馈 + 观测器"闭环；
- 分析观测器极点位置对估计速度与噪声放大 trade-off。

## 3. 所需知识

- `requires`：观测器结构、观测器增益、能观性、分离原理；
- 前置支撑：状态空间表示、状态反馈（阶段 5 模块 A/B）；
- 可选扩展：卡尔曼滤波（阶段 10，不设隐性前置）。

## 4. 任务背景与边界

- **场景**：二阶系统（如电机）$\dot x = Ax + Bu$，$y = Cx$，$C$ 只测一个状态；
- **输入**：$A, B, C$、期望观测器极点；
- **输出**：观测器设计、估计收敛图、组合闭环仿真；
- **禁止**：直接假设全状态已知；观测器必须显式建模。

## 5. 详细题目

**题目 1（基础，25 分）：能观性与观测器设计**
1a. 给定 $A = \begin{pmatrix}0 & 1\\-2 & -3\end{pmatrix}$，$C = \begin{pmatrix}1 & 0\end{pmatrix}$，验证能观；
1b. 设计 $L = [l_1, l_2]^\top$ 使观测器极点 $\lambda_{obs} = -6 \pm j6$；
1c. 写出观测器方程 $\dot{\hat x} = A\hat x + Bu + L(y - C\hat x)$。

**题目 2（核心，30 分）：估计收敛仿真**
2a. 初值 $x_0 = [1, 0]^\top$、$\hat x_0 = [0, 0]^\top$，仿真观测器，报告收敛时间（误差 < 1%）；
2b. 改变观测器极点（快 2× / 慢 0.5×），对比收敛速度与对测量噪声的放大；
2c. 加 5% 测量噪声，评估估计精度。

**题目 3（进阶，25 分）：分离原理验证**
3a. 设计状态反馈 $K$ 使控制器极点 $\lambda_{ctrl} = -2 \pm j2$；
3b. 组合"$u = -K\hat x$ + 观测器"闭环仿真；
3c. 验证闭环特征值 = $\sigma(A - BK) \cup \sigma(A - LC)$（分离原理）。

**题目 4（应用，20 分）：工程权衡**
4a. 观测器过快（$\lambda = -60$）→ 噪声放大；过慢（$\lambda = -1.5$）→ 暂态差；各给一组仿真证据；
4b. 报告"观测器极点 2-5 倍于控制器"的经验验证；
4c. 说明观测器与卡尔曼滤波的关系（阶段 10 衔接）。

## 9. 引导与自检

- 常见失败：$L$ 解算用转置混淆（对偶系统）、观测器初值未设、分离原理验证时用了理想状态；
- 调试路径：先纯观测器（无反馈）→ 纯状态反馈 → 组合；
- 自查清单：
  - [ ] 能观性矩阵满秩；
  - [ ] $\lambda(A-LC)$ = 配置极点；
  - [ ] 组合闭环用 $\hat x$ 而非 $x$；
  - [ ] 噪声放大实验有定量对比。
