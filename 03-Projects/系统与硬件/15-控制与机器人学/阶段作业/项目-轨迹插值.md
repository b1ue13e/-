# 项目-轨迹插值

> 阶段作业（stage · lab）：实现路径点插值（线性/三次样条/五次多项式）与时间参数化，生成平滑可跟踪轨迹。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 8：轨迹与路径跟踪 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 对比线性/三次样条/五次插值的平滑度与连续性；
- 实现时间参数化（等距采样 → 速度/加速度分配）；
- 验证插值轨迹的曲率连续性与可跟踪性；
- 处理路径点噪声与稀疏采样。

## 3. 所需知识

- `requires`：轨迹定义、轨迹状态、S曲线规划；
- 前置支撑：速度分配、梯形速度（模块 A）。

## 4. 任务背景与边界

- **场景**：给定稀疏路径点（含弯道），生成平滑插值轨迹；
- **输入**：路径点序列（xy）、目标速度；
- **输出**：插值轨迹（位置/速度/加速度时间序列）、曲率曲线；
- **禁止**：`scipy.interpolate.splrep` 不说明参数直接交差；须对比方法。

## 5. 详细题目

**题目 1（基础，25 分）：空间插值对比**
1a. 对同一组路径点（含 90° 弯），实现线性/三次样条/五次插值；
1b. 报告各方法的 $C^0/C^1/C^2$ 连续性与曲率突变；
1c. 画插值结果对比图。

**题目 2（核心，30 分）：时间参数化**
2a. 按弧长重采样（等弧长）路径；
2b. 用梯形/S 曲线分配速度（起点终点静止，巡航 $v = 5$ m/s）；
2c. 生成位置/速度/加速度时间序列并验证边界。

**题目 3（进阶，25 分）：曲率与可行性**
3a. 计算插值轨迹曲率，检查弯道处的曲率峰值；
3b. 验证加速度限制（向心加速度 $v^2\kappa \le a_{max}$）；
3c. 在超限弯道处自动降速（重新参数化），报告改进。

**题目 4（应用，20 分）：鲁棒性**
4a. 给路径点加噪声（±0.1 m），对比三种插值的曲率稳定性；
4b. 稀疏/密集采样对比轨迹质量；
4c. 结论：插值方法选择与工程注意事项。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`、`scipy`；
- 固定路径点集、采样密度、目标速度；
- 报告注明插值参数（平滑度 s、点数）。

## 7. 提交产物

## 9. 引导与自检

- 常见失败：三次样条过冲、弧长重采样不均匀、曲率公式用错；
- 调试路径：线性 → 样条 → 参数化 → 曲率 → 鲁棒性；
- 自查清单：
  - [ ] 端点插值误差为 0；
  - [ ] 速度端点为零、巡航值正确；
  - [ ] 弯道降速前后曲率对比；
  - [ ] 噪声实验同种子。
