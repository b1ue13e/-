# 项目-MCL

> 阶段作业（stage · lab）：实现蒙特卡洛定位（粒子滤波）的全局定位，验证"绑架机器人"恢复与粒子数权衡。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 10：状态估计 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 实现 SIR 粒子滤波定位（运动更新 + 测量更新 + 重采样）；
- 在未知初始位姿（全局定位）下收敛到真实位姿；
- 复现"绑架机器人"问题并验证恢复；
- 分析粒子数对精度/计算的影响。

## 3. 所需知识

- `requires`：SIR滤波、重采样、蒙特卡洛；
- 前置支撑：噪声模型、协方差矩阵（模块 A）。

## 4. 任务背景与边界

- **场景**：二维环境（landmark 测量），机器人初始位姿未知（均匀采样）；
- **输入**：地图（地标位置）、运动/测量模型参数、粒子数 $N$；
- **输出**：位姿收敛轨迹、粒子分布、定位误差；
- **禁止**：直接用官方 particle filter 类交差；须自写 SIR 循环。

## 5. 详细题目

**题目 1（基础，25 分）：SIR 实现**
1a. 实现粒子初始化（均匀分布）、运动更新（加噪声）、测量更新（似然加权）、重采样；
1b. 已知初始位姿（$\pm 0.5$ m）场景，验证收敛；
1c. 报告定位 RMSE 与粒子分布可视化。

**题目 2（核心，30 分）：全局定位**
2a. 初始位姿完全未知（全地图均匀采样），仿真收敛；
2b. 报告收敛时间（粒子聚拢时刻）与最终误差；
2c. 不同地标数量（2/3/4 个）下的收敛性对比。

**题目 3（进阶，25 分）：绑架机器人**
3a. 定位收敛后瞬间把真位姿搬到远处（模拟绑架）；
3b. 观察粒子分布（旧位置聚拢 → 分散 → 新位置聚拢）；
3c. 报告恢复时间与机制（多样性来自哪里）。

**题目 4（应用，20 分）：粒子数权衡**
4a. 扫 $N \in \{100, 1000, 5000\}$，报告 RMSE 与耗时；
4b. 报告"粒子数 → 精度收益递减"曲线；
4c. 结论：MCL 的参数选择与适用边界。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定地图、种子、测量频率、粒子数；
- 报告注明模型参数与 MC 次数。

## 7. 提交产物

- 报告：SIR 实现、收敛/绑架实验、粒子数分析、结论；
- 代码 + README；
- 数据表（N × RMSE × 耗时）。

## 9. 引导与自检

- 常见失败：权重未归一化、重采样后多样性耗尽（无恢复能力）、测量似然用错；
- 调试路径：已知初值 → 全局 → 绑架 → 粒子数；
- 自查清单：
  - [ ] 收敛前后粒子分布对比图；
  - [ ] 绑架恢复时间有记录；
  - [ ] $N$ 扫描同种子；
  - [ ] 权重归一化检查。
