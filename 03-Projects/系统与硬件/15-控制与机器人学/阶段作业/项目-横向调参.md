# 项目-横向调参

> 阶段作业（stage · lab）：系统化调参实验——前视距离/增益/自适应策略对横向跟踪性能的影响，沉淀可复用的调参流程。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 6：横向控制 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 建立"参数 → 指标"的自动化扫描流程（网格/随机）；
- 理解前视距离 $L_d$ 与增益 $k$ 的失效模式（振荡/切弯/抖动）；
- 实现并验证自适应 $L_d = kv$ 的效果；
- 输出一份可复用的横向调参 SOP。

## 3. 所需知识

- `requires`：预瞄距离、横向偏差、自适应预瞄、CC调参；
- 前置支撑：PP算法、Stanley公式、横向控制对比。

## 4. 任务背景与边界

- **场景**：正弦/八字路径，PP 与 Stanley 各一；
- **输入**：参数空间（$L_d$、$k$、$v$）与扫网格；
- **输出**：热力图/曲线、最优参数、调参 SOP；
- **禁止**：凭感觉手动调 3 次就交差；必须网格扫描 + 统计。

## 5. 详细题目

**题目 1（基础，25 分）：扫描框架**
1a. 搭建"参数 → 仿真 → 指标（RMS/Max）"批处理框架；
1b. 对 PP 扫 $L_d \in [0.5, 10]$（20 档），Stanley 扫 $k \in [0.1, 10]$（20 档）；
1c. 输出 RMS 热力图。

**题目 2（核心，30 分）：失效模式分析**
2a. 从扫描结果提取 3 个典型参数（最优/振荡/切弯），逐一个案分析轨迹图；
2b. 解释各失效模式的机理（预瞄过小 → 高频振荡；过大 → 弯道内切）；
2c. 对比 PP 与 Stanley 的失效边界。

**题目 3（进阶，25 分）：自适应策略**
3a. 实现 $L_d = k_v v + L_0$ 自适应（扫 $k_v$）；
3b. 与固定 $L_d$ 对比多车速下的 RMS；
3c. 报告自适应带来的增益（尤其高速段）。

**题目 4（应用，20 分）：调参 SOP**
4a. 把实验结论整理成"横向调参 SOP"（初值 → 扫描 → 个案 → 自适应）；
4b. SOP 应含判定规则（何时算振荡/切弯，指标阈值）；
4c. 用另一个场景验证 SOP 可迁移。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定路径、种子、仿真时长；扫描网格记录在案；
- 报告注明参数范围与档数。

## 7. 提交产物

- 报告：热力图、失效个案、自适应对比、SOP、结论；
- 扫描框架代码 + README；
- 数据表（参数 × 指标）。

## 9. 引导与自检

- 常见失败：网格过疏漏最优、RMS 口径漂移、个案图未标注参数；
- 调试路径：单参数扫描 → 双参数热力图 → 个案 → 自适应；
- 自查清单：
  - [ ] 热力图坐标与颜色标尺清晰；
  - [ ] 振荡/切弯个案各有轨迹证据；
  - [ ] 自适应对比同车速同路径；
  - [ ] SOP 步骤可被第三人执行。
