# 项目-八字绕环

> 阶段作业（stage · lab）：在八字绕环（lemniscate）路径上实现并验证 Pure Pursuit 跟踪，产出横向误差指标与参数敏感性结论。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 6：横向控制 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 生成八字绕环参考路径并离散化采样；
- 实现 Pure Pursuit 预瞄点搜索与转向角计算；
- 在固定车速下测量横向误差（RMS/Max）；
- 扫前视距离并解释"U 形"参数-误差曲线。

## 3. 所需知识

- `requires`：PP算法、预瞄距离、横向偏差、自行车模型；
- 前置支撑：阶段 6 模块 A（横向误差模型）与课后作业-06（手算铺垫）。

## 4. 任务背景与边界

- **场景**：PythonRobotics `pure_pursuit.py` 的八字绕环场景（$l_d = 0.1v + 2.0$），$v = 10$ m/s 固定；
- **输入**：路径点序列、车辆初始位姿、前视距离 $L_d$；
- **输出**：跟踪轨迹、横向误差曲线、指标表；
- **禁止**：直接 import 官方 `PurePursuit` 类；官方实现仅对照基线。

## 5. 详细题目

**题目 1（基础，25 分）：路径与车辆模型**
1a. 用参数方程生成八字绕环（$x = a\cos t/(1+\sin^2 t)$、$y = a\sin t\cos t/(1+\sin^2 t)$）；
1b. 实现自行车模型离散积分；
1c. 复现官方 demo（保持参数），记录官方误差基线。

**题目 2（核心，30 分）：PP 实现**
2a. 实现预瞄点搜索（最近于 $L_d$ 的路径点 + 线性插值）；
2b. 实现 $\delta = \arctan(2L\sin\alpha/L_d)$；
2c. 自写与官方 demo 同场景对比，报告横向误差 RMS/Max。

**题目 3（进阶，25 分）：参数敏感性**
3a. 扫 $L_d \in \{1, 2, 4, 8\}$ m，画"$L_d$ → RMS"曲线；
3b. 解释 U 形：过小振荡、过大切弯；
3c. 给出本场景的最优 $L_d$ 与理由。

**题目 4（应用，20 分）：速度影响**
4a. 扫 $v \in \{2, 5, 10, 15\}$ m/s（$L_d$ 固定），报告误差变化；
4b. 实现 $L_d = kv$ 自适应，对比固定 $L_d$；
4c. 结论：PP 的适用速度区间与调参原则。

## 6. 环境与复现
