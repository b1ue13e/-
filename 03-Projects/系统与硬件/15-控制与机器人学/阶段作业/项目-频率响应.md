# 项目-频率响应

> 阶段作业（stage · lab）：实现频率响应分析工具（正弦扫频 + Bode 图 + 裕度测量），用频域指标评估系统鲁棒性。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 4：经典控制入门 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 用正弦扫频法实测系统的幅值/相位响应；
- 绘制 Bode 图并解读增益裕度/相位裕度/穿越频率；
- 用频域指标评估闭环稳定性与鲁棒性；
- 对比理论 Bode 与实测 Bode 的差异。

## 3. 所需知识

- `requires`：频率响应、Bode图、稳定裕度；
- 前置支撑：传递函数、时域指标（阶段 1）。

## 4. 任务背景与边界

- **场景**：二阶系统 $G(s) = \dfrac{100}{s^2 + 10s + 100}$ 与一阶延迟系统；
- **输入**：正弦输入（幅值/频率序列）；
- **输出**：实测 Bode、裕度测量、稳定性结论；
- **禁止**：只用 `control.bode()` 交差；裕度须从实测响应提取。

## 5. 详细题目

**题目 1（基础，25 分）：扫频实现**
1a. 实现正弦扫频：对频率序列 $f \in [0.1, 0.2, \dots, 10]$ Hz，逐频点激励系统并测稳态幅值比与相位差；
1b. 处理暂态（丢弃前 N 个周期）与噪声（整周期平均）；
1c. 输出实测 Bode 数据表。

**题目 2（核心，30 分）：Bode 与裕度**
2a. 对 $G(s)$ 绘制实测 Bode，并与理论 Bode（`control.bode`）叠加；
2b. 提取增益穿越频率 $\omega_{gc}$、相位裕度 $\phi_m$；
2c. 对含延迟版本 $G e^{-0.2s}$ 重测，报告裕度下降。

**题目 3（进阶，25 分）：时域-频域一致性**
3a. 用实测相位裕度预测闭环阶跃超调（$OS \approx \exp(-\pi\zeta/\sqrt{1-\zeta^2})$，$\zeta$ 由 $\phi_m$ 近似）；
3b. 仿真闭环阶跃，对比预测超调与实际；
3c. 解释偏差来源（近似公式假设）。

**题目 4（应用，20 分）：频域设计入口**
4a. 对相位裕度不足的系统（延迟版），说明超前补偿的方向（提高 $\omega_{gc}$ 处的相位）；
4b. 用 Bode 定性验证补偿前后裕度变化；
4c. 报告"频域方法 vs 根轨迹方法"的适用对比。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`、`scipy`、`control`（对照）；
- 固定扫频频率表、暂态丢弃周期数、噪声种子；
- 报告注明采样率与仿真时长。

## 7. 提交产物

- 报告：方法、实测/理论 Bode 叠加图、裕度表、结论；
- 扫频代码 + README；
- 数据表（频率 vs 幅值比/相位差）。

## 9. 引导与自检

- 常见失败：暂态未丢弃导致幅值偏、相位缠绕未展开、$\phi_m$ 定义混淆（开环 vs 闭环）；
- 调试路径：先无噪声理想仿真 → 加噪声 → 加延迟；
- 自查清单：
  - [ ] 幅值比用稳态段计算（丢弃暂态）；
  - [ ] 相位差展开到连续曲线；
  - [ ] $\omega_{gc}$ 与理论值一致；
  - [ ] 超调预测误差有定量解释。
