# 控制与机器人学-阶段作业-02-机械臂运动学与动力学控制

> 阶段作业（stage · lab）：验收阶段 2「机器人学基础模型」的机械臂建模与控制闭环。非官方中文版：基于 Modern Robotics / PythonRobotics 开放材料本地化改编。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 2：机器人学基础模型 |

| 来源 | Modern Robotics 官方代码（NxRLab，MIT）；PythonRobotics `arm_navigation_joint_control.py` |

## 2. 学习目标

完成后能够：
- 为 6 自由度机械臂（如 PUMA 类）建立 DH 参数表；
- 实现正运动学（FK）与解析/数值逆运动学（IK）；
- 计算几何 Jacobian 并分析奇异位形；
- 在 PyBullet 中实现关节空间轨迹跟踪（含计算力矩或重力补偿）。

## 3. 所需知识

- `requires`：机械臂DH参数与逆运动学、几何Jacobian、正运动学、机器人动力学；
- 前置支撑：旋转矩阵/齐次变换/变换链（模块 A）、DH参数/正运动学；
- 可选扩展：力控/阻抗（阶段 11，不设隐性前置）。

## 4. 任务背景与边界

- **场景**：PUMA 560 或自选 6DOF 机械臂，PyBullet 仿真；
- **输入**：DH 参数、目标末端位姿/关节轨迹；
- **输出**：FK/IK 验证、Jacobian、仿真跟踪轨迹；
- **禁止**：直接 import 官方 FK/IK 求解函数；官方代码仅对照基线。

## 5. 详细题目

**题目 1（基础，25 分）：DH 参数与正运动学**
1a. 建 PUMA 类机械臂 DH 参数表（含每个关节的 $a, \alpha, d, \theta$）；
1b. 实现 FK：给定关节角 → 末端位姿矩阵 $T$；
1c. 用官方 `ModernRobotics` 代码或手算一个构型交叉验证。

**题目 2（基础，25 分）：逆运动学**
2a. 实现解析 IK（PUMA 有闭合解）或数值 IK（Jacobian 迭代）；
2b. 测试 3 个目标位姿，报告收敛性与精度（位置误差 < 1 mm）；
2c. 讨论 IK 多解与奇异位形。

**题目 3（核心，30 分）：Jacobian 与奇异分析**
3a. 实现几何 Jacobian $J(q)$；
3b. 计算 $J$ 的行列式/条件数，找出奇异构型；
3c. 在奇异附近执行任务，说明数值问题与处理（阻尼最小二乘）。

**题目 4（进阶，20 分）：PyBullet 轨迹跟踪**
4a. 在 PyBullet 加载机械臂 URDF；
4b. 实现关节空间 PTP 轨迹 + 关节 PID（或计算力矩）；
4c. 报告末端轨迹误差与跟随性能。

## 6. 环境与复现

- Python 3.10+，依赖 `numpy`、`pybullet`（4.x）、`matplotlib`；
- 固定 DH 参数表与目标位姿（写入报告）；
- 报告注明 ModernRobotics commit hash 与 PyBullet 版本。

## 7. 提交产物

- 报告：DH 表、FK/IK 验证、Jacobian 与奇异分析、仿真图、结论；
- 自写代码 + README；
- 验证数据表（目标位姿 vs 求解结果）。

## 9. 引导与自检

- 常见失败：DH 约定（标准 vs 修正）混用、IK 迭代发散（初值差）、奇异处 Jacobian 奇异、URDF 关节序号错位；
- 调试路径：FK 先验证（手算一构型）→ IK（三个目标）→ Jacobian → 仿真；
- 自查清单：
  - [ ] DH 表所有 $a/\alpha$ 符号核对；
  - [ ] FK 末端位姿与 `ModernRobotics` 对照一致；
  - [ ] IK 收敛判据明确（位置 + 姿态误差）；
  - [ ] 奇异构型有数值处理（阻尼最小二乘）。
