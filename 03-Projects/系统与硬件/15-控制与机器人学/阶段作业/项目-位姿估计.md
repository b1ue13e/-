# 项目-位姿估计

> 阶段作业（stage · lab）：扩展 EKF 定位——多传感器融合（GPS + 里程计 + 地标）与零偏估计，验证精度提升与一致性。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 10：状态估计 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 扩展 EKF 状态（位姿 + 零偏）与多传感器测量模型；
- 实现"高频里程计预测 + 低频 GPS/地标更新"异步融合；
- 验证融合后的精度提升与一致性（NEES）；
- 分析零偏估计对长期漂移的抑制。

## 3. 所需知识

- `requires`：EKF非线性状态估计、导航定位、一致性；
- 前置支撑：卡尔曼滤波KalmanFilter、噪声模型、采样率差异。

## 4. 任务背景与边界

- **场景**：车辆定位，传感器：里程计（高频，含零偏）、GPS（低频）、地标（可选）；
- **输入**：参考轨迹、传感器噪声参数、零偏真值；
- **输出**：估计轨迹、误差、NEES、零偏估计曲线；
- **禁止**：只跑官方 demo 不加扩展；必须有"多传感器 vs 单传感器"对比。

## 5. 详细题目

**题目 1（基础，25 分）：EKF 扩展**
1a. 状态扩展为 $[x, y, \psi, v, b_v]$（含里程计零偏）；
1b. 建立 GPS（xy）与地标（距离/方位）测量模型及雅可比；
1c. 跑通官方 `ekf_localization.py` 基线。

**题目 2（核心，30 分）：异步融合**
2a. 里程计 100 Hz 预测 + GPS 1 Hz 更新；
2b. 对比"仅里程计 / 仅 GPS / 融合"三种方案的 RMSE；
2c. 报告融合精度提升（相对纯里程计漂移）。

**题目 3（进阶，25 分）：零偏估计**
3a. 注入里程计零偏（$b_v = 0.5$ m/s），不估计 vs 估计对比；
3b. 报告零偏收敛时间与残差；
3c. 分析"零偏不可观时"的表现（能观性讨论）。

**题目 4（应用，20 分）：一致性**
4a. 10 次 MC 计算 NEES，检验一致性；
4b. 扫 $Q$ 过小/过大，报告过度自信/悲观；
4c. 结论：位姿估计融合架构的设计要点。

## 9. 引导与自检

- 常见失败：预测/更新频率配比错、零偏与状态耦合误差、NEES 未用 MC；
- 调试路径：官方基线 → 加地标 → 加零偏 → NEES；
- 自查清单：
  - [ ] 融合 RMSE < 纯里程计；
  - [ ] 零偏估计收敛到真值附近；
  - [ ] NEES 用 10 次 MC；
  - [ ] Q 扫描有过度自信证据。
