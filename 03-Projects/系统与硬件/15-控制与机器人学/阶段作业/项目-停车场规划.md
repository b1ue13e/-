# 项目-停车场规划

> 阶段作业（stage · lab）：在停车场栅格地图上用 A*/RRT 规划泊车路径，验证最优性与障碍约束下的路径质量。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 8：轨迹与路径跟踪 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 建立停车场栅格地图（障碍 + 车位 + 通道）；
- 用 A* 规划最短路径并验证最优性；
- 用 RRT/RRT* 规划并比较路径质量；
- 分析"路径长度 vs 计算时间"的工程权衡。

## 3. 所需知识

- `requires`：栅格地图与占据栅格、路径规划Astar与RRT、轨迹定义；
- 前置支撑：碰撞检测、路径表示（模块 A）。

## 4. 任务背景与边界

- **场景**：停车场栅格地图（30×20），车位/通道/立柱障碍；
- **输入**：地图数组、起点终点（入库位姿）；
- **输出**：规划路径、扩展可视化、最优性验证；
- **禁止**：直接调 `networkx` 找最短路径交差；A* 必须自写。

## 5. 详细题目

**题目 1（基础，25 分）：地图与 A\***
1a. 设计停车场地图（含 3 个车位、通道、2 根立柱）；
1b. 自写 A*（8 邻域 + 欧氏启发）规划"入口 → 指定车位"；
1c. 用 BFS/Dijkstra 对照验证 A* 路径最优性。

**题目 2（核心，30 分）：RRT 对比**
2a. 实现 RRT 与 RRT*（固定种子），同地图规划；
2b. 对比 A*/RRT/RRT* 的路径长度与计算时间（10 次统计）；
2c. 报告路径平滑度（转折点/曲率）差异。

**题目 3（进阶，25 分）：多车位与场景**
3a. 三个不同车位各规划一次，报告路径特征；
3b. 增加障碍（临时车辆占道），重规划并对比路径变化；
3c. 分析"通道宽度 vs 路径可行性"（扫通道宽度）。

**题目 4（应用，20 分）：工程权衡**
4a. 扫栅格分辨率（0.5/1.0/2.0），报告路径长度与耗时；
4b. 给出泊车规划的场景选型建议（A* vs RRT*）；
4c. 结论：规划输出如何衔接跟踪控制（阶段 6/9）。

## 9. 引导与自检

- 常见失败：A* 对角穿障碍、启发式非一致导致次优、RRT 步长穿墙；
- 调试路径：A* 先验证最优 → RRT → 多场景 → 分辨率；
- 自查清单：
  - [ ] A* 与 Dijkstra 等长；
  - [ ] RRT* 多次运行路径方差小；
  - [ ] 三车位路径均无碰撞；
  - [ ] 分辨率扫描有趋势。
