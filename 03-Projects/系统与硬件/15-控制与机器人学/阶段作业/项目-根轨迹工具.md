# 项目-根轨迹工具

> 阶段作业（stage · lab）：编写根轨迹绘制工具，验证增益变化对闭环极点的影响，并用劳斯判据交叉验证稳定性边界。

| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 1：控制地基 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 用数值方法绘制给定开环传递函数的根轨迹（实轴段、渐近线、分离点）；
- 解释增益 $K$ 增大时闭环极点的迁移与稳定性变化；
- 用劳斯判据求出临界稳定增益并交叉验证；
- 判断根轨迹设计在补偿器设计中的角色。

## 3. 所需知识

- `requires`：根轨迹、零极点、劳斯判据；
- 前置支撑：传递函数、稳定性（阶段 1 模块 B）。

## 4. 任务背景与边界

- **场景**：单位反馈系统 $G(s) = \dfrac{K}{(s+1)(s+3)}$ 与 $G(s) = \dfrac{K(s+2)}{s(s+1)(s+4)}$；
- **输入**：开环传递函数参数；
- **输出**：根轨迹图、$K$ 扫描下极点轨迹、临界增益；
- **禁止**：直接调用 `control.root_locus()` 作为自写实现（可作对照）。

## 5. 详细题目

**题目 1（基础，25 分）：数值根轨迹**
1a. 对 $G(s) = \dfrac{K}{(s+1)(s+3)}$，用"相角条件 + 网格搜索"绘制根轨迹（自写）；
1b. 标出分离点（$s = -2$）与实轴段；
1c. 与 `control.root_locus()` 结果叠加对比。

**题目 2（核心，30 分）：稳定性边界**
2a. 对 $G(s) = \dfrac{K}{s(s+1)(s+4)}$，扫描 $K \in [0, 300]$，记录闭环极点的实部符号；
2b. 用劳斯判据求临界增益 $K_c$（手算），与数值扫描结果对比；
2c. 解释"$K$ 超过 $K_c$ 时闭环失稳"的根轨迹机理（极点越过虚轴）。

**题目 3（进阶，25 分）：零点的影响**
3a. 加入开环零点 $z = -2$：$G(s) = \dfrac{K(s+2)}{s(s+1)(s+4)}$，重绘根轨迹；
3b. 对比有无零点的根轨迹形状与临界增益变化；
3c. 说明零点如何"拉"根轨迹（改善阻尼/稳定性）。

**题目 4（应用，20 分）：设计应用**
4a. 为二阶系统 $G(s) = \dfrac{K}{s(s+10)}$ 用根轨迹法选择 $K$ 使阻尼比 $\zeta = 0.5$；
4b. 仿真闭环阶跃响应，验证超调与 $\zeta$ 的一致性；
4c. 报告"根轨迹法 vs 劳斯判据"的互补使用场景。

## 6. 环境与复现

- 固定网格密度与 $K$ 扫描范围（写入报告）。

## 9. 引导与自检

- 常见失败：网格过粗漏分离点、相角条件用错（应为 $180^\circ + 360^\circ k$）、劳斯表符号错；
- 调试路径：先二阶（解析可验证）→ 三阶（劳斯交叉验证）→ 加零点；
- 自查清单：
  - [ ] 分离点与解析值一致；
  - [ ] $K_c$ 两种方法误差 < 5%；
  - [ ] 有无零点两图同坐标对比；
  - [ ] 设计结果用阶跃响应验证。
