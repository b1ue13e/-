# 项目-电机仿真

> 阶段作业（stage · lab）：为直流电机速度建立一阶模型，仿真开环/闭环响应，验证时域指标与稳态误差。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 1：控制地基 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 由电机电气-机械参数推导一阶速度模型 $G(s) = \dfrac{K}{\tau s + 1}$；
- 仿真开环阶跃响应并提取时间常数/稳态值；
- 加入比例反馈，分析稳态误差与时域指标变化；
- 用 Python 建立可复现的仿真脚手架。

## 3. 所需知识

- `requires`：一阶系统、时域指标、传递函数；
- 前置支撑：拉氏变换（阶段 1 模块 A）。

## 4. 任务背景与边界

- **场景**：直流电机速度控制（电枢控制，忽略电感 $L_a$）；
- **输入**：电机参数（$R_a, K_t, K_e, J, B$）与电压指令；
- **输出**：模型、开环/闭环响应、指标表；
- **禁止**：不建模直接画图；指标必须从响应中实测提取。

## 5. 详细题目

**题目 1（基础，25 分）：建模**
1a. 由 $J\dot\omega + B\omega = K_t i$、$v = R_a i + K_e \omega$ 推导 $\dfrac{\Omega(s)}{V(s)}$；
1b. 给定 $R_a = 1\ \Omega$、$K_t = K_e = 0.1$、$J = 0.01\ \text{kg·m}^2$、$B = 0.001$，求 $K$ 与 $\tau$；
1c. 用 `scipy.signal` 或手写欧拉积分建立仿真。

**题目 2（核心，30 分）：开环响应**
2a. 阶跃电压 10 V，仿真开环响应并提取稳态速度与 $63.2\%$ 时间；
2b. 对比理论值（$K \cdot V$、$\tau$）与仿真值，报告误差；
2c. 改变 $J$（×10），重测并解释时间常数变化。

**题目 3（进阶，25 分）：比例闭环**
3a. 加比例反馈 $v = K_p(\omega_d - \omega)$，仿真闭环阶跃；
3b. 扫 $K_p \in \{1, 10, 100\}$，报告稳态误差与超调（如有）；
3c. 解释为何一阶闭环无超调、稳态误差随 $K_p$ 减小。

**题目 4（应用，20 分）：扰动**
4a. 加负载力矩 $T_L$（阶跃），观察开环/闭环的速度跌落；
4b. 对比闭环的扰动抑制效果并量化（跌落比例）；
4c. 说明"为何闭环能抑制扰动"（灵敏度传递函数）。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`、`scipy`；
- 固定仿真时长与步长（如 10 s / 1 ms）；
- 报告注明电机参数表。

## 7. 提交产物

- 报告：建模推导、仿真图（开环/闭环/扰动）、指标表、结论；
- 仿真代码 + README；
- 参数敏感性表（$J$、$K_p$ 变化）。

## 8. 验收标准与 Rubric

| 维度 | 分值 | 通过要求 |

| 建模正确 | 25 | $K, \tau$ 推导与数值正确 |

| 比例闭环 | 25 | 稳态误差分析正确 |

## 9. 引导与自检

- 常见失败：忽略反电动势耦合、欧拉步长过大导致误差、稳态误差用错定义；
- 调试路径：先无反馈跑通 → 理论对照 → 加反馈 → 加扰动；
- 自查清单：
  - [ ] 模型推导从电机方程出发；
  - [ ] 仿真稳态值与 $K \cdot V$ 一致；
  - [ ] 闭环稳态误差随 $K_p$ 单调减小；
  - [ ] 扰动跌落百分比有数值。
