# 项目-车辆模型验证

> 阶段作业（stage · lab）：实现并验证自行车模型与线性车辆动力学模型，交叉检验运动学/动力学口径与离散化精度。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 3：移动机器人与车辆模型 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 实现自行车运动学模型（unicycle/bicycle）与线性单轨动力学模型；
- 对比运动学与动力学模型在低速/高速的差异；
- 验证模型离散化精度（步长收敛）；
- 建立误差模型（横向/航向偏差）供后续控制使用。

## 3. 所需知识

- `requires`：自行车模型、车辆动力学、车辆线性化、车辆误差模型；
- 前置支撑：侧偏角、状态空间表示（阶段 5 衔接）。

## 4. 任务背景与边界

- **场景**：车辆直线/匀速圆周/变道轨迹仿真；
- **输入**：车速、转向角序列、模型参数（$l_f, l_r, C_f, C_r, m, I_z$）；
- **输出**：轨迹对比、离散化误差曲线、误差模型验证；
- **禁止**：直接用 `Vehicle` 库不写实现；模型必须自己离散化。

## 5. 详细题目

**题目 1（基础，25 分）：运动学模型**
1a. 实现 bicycle 运动学（$\dot x = v\cos(\psi+\beta)$ 或简化）；
1b. 匀速圆周（$v=10$ m/s、$\delta=0.1$ rad）仿真 20 s，验证曲率半径 $R = L/\delta$；
1c. 与 PythonRobotics 官方 bicycle 模型对比（同输入）。

**题目 2（核心，30 分）：动力学模型**
2a. 实现线性单轨模型（侧偏力线性化，$C_f, C_r$）；
2b. 高速（30 m/s）阶跃转向下对比运动学/动力学轨迹差异；
2c. 报告"何时必须用动力学模型"（速度阈值）。

**题目 3（进阶，25 分）：离散化精度**
3a. 用欧拉/龙格-库塔离散化，扫步长 $dt \in \{0.01, 0.05, 0.1\}$ s；
3b. 报告终点误差随步长的收敛阶（理论上 RK4 = $O(dt^4)$）；
3c. 给出工程推荐步长。

**题目 4（应用，20 分）：误差模型**
4a. 建立 Frenet 误差模型（横向偏差 $e_y$、航向偏差 $e_\psi$）；
4b. 在变道轨迹上验证误差动力学与状态空间形式；
4c. 说明误差模型对 LQR/MPC 横向控制的作用。

## 6. 环境与复现

- 报告注明参数与离散化方法。

## 9. 引导与自检

- 常见失败：bicycle 的 $\beta$ 符号错、动力学模型 $C_f$ 单位混淆、RK4 步长过大；
- 调试路径：运动学单跑 → 动力学对比 → 步长扫描 → 误差模型；
- 自查清单：
  - [ ] 圆周半径与 $L/\delta$ 一致；
  - [ ] 高速下动力学与运动学轨迹分离；
  - [ ] 收敛阶有数值验证（误差比）；
  - [ ] 误差模型与状态空间式一致。
