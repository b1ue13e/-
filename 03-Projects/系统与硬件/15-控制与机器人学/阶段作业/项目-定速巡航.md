# 项目-定速巡航

> 阶段作业（stage · lab）：建立车辆纵向动力学模型，设计 PI 速度控制器实现定速巡航，验证坡度/阻力扰动下的鲁棒性。

## 2. 学习目标

完成后能够：
- 建立纵向动力学模型（驱动力 - 阻力 - 坡度）；
- 设计 PI 速度控制器并整定；
- 验证定速保持精度与坡度/风阻扰动的抑制；
- 分析积分项对稳态误差的作用。

## 3. 所需知识

- `requires`：纵向方程、行驶阻力、PI速度控制；
- 前置支撑：一阶系统、PID公式（阶段 4）。

## 4. 任务背景与边界

- **场景**：车辆定速巡航（目标 30 m/s），含坡度与风阻；
- **输入**：车辆参数（$m, C_d, A, f_r$）、坡度序列、目标速度；
- **输出**：速度跟踪曲线、油门指令、扰动响应；
- **禁止**：不建模直接调库；控制器参数必须有整定依据。

## 5. 详细题目

**题目 1（基础，25 分）：纵向建模**
1a. 建立 $m\dot v = F_{trac} - F_{aero} - F_{roll} - F_{grade}$；
1b. 给定 $m = 1500$ kg、$C_d = 0.3$、$A = 2.2$ m²、$f_r = 0.015$，写出阻力表达式；
1c. 实现纵向动力学仿真（油门 → 驱动力 → 速度）。

**题目 2（核心，30 分）：PI 速度控制**
2a. 设计 PI：$F_{trac} = K_p(v_d - v) + K_i\int(v_d - v)dt$；
2b. 整定（Lambda 法/试凑），目标：阶跃无稳态误差、超调 < 5%；
2c. 平路定速 30 m/s 仿真，报告稳定时间与稳态误差。

**题目 3（进阶，25 分）：扰动鲁棒性**
3a. 坡度序列（2% 上坡 20 s → 平路 → 2% 下坡），测速度跌落/超调；
3b. 加阵风（风阻 ×1.5 持续 5 s），测扰动抑制；
3c. 比较纯 P 与 PI 的扰动恢复差异（积分项的作用）。

**题目 4（应用，20 分）：油门限制**
4a. 油门限幅 0-100%，大坡度下观察饱和；
4b. 加抗饱和（back-calculation），对比恢复；
4c. 结论：定速巡航的性能边界与改进方向。

## 9. 引导与自检

- 常见失败：阻力项符号错、$K_i$ 过大振荡、坡度用正弦代替阶跃；
- 调试路径：无扰动平路 → 坡度 → 风阻 → 饱和；
- 自查清单：
  - [ ] 平路稳态误差 ≈ 0；
  - [ ] 坡度扰动恢复时间有记录；
  - [ ] P vs PI 对比同场景；
  - [ ] 饱和前后对比同图。
