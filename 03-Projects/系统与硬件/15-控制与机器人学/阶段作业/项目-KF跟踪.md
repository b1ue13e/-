# 项目-KF跟踪

> 阶段作业（stage · lab）：用 KF 跟踪匀速运动目标（位置 + 速度状态），处理测量噪声与测量缺失。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 10：状态估计 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 为匀速运动目标建立 KF 问题设定（CV 模型 + 位置测量）；
- 实现 KF 预测-更新循环并验证收敛；
- 处理测量缺失（纯预测外推）与野值（新息门限）；
- 评估跟踪精度（RMSE vs Cramér-Rao 下界）。

## 3. 所需知识

- `requires`：卡尔曼滤波KalmanFilter、问题设定、数据关联；
- 前置支撑：协方差矩阵、噪声模型（模块 A）。

## 4. 任务背景与边界

- **场景**：二维平面匀速目标（CV 模型），位置测量带噪；
- **输入**：真实轨迹、测量（噪声 + 缺失 + 野值）、$Q/R$；
- **输出**：跟踪轨迹、误差、新息序列；
- **禁止**：直接用 `filterpy` 的 KF 类交差（可对照）；须自写。

## 5. 详细题目

**题目 1（基础，25 分）：问题设定与实现**
1a. CV 模型：状态 $[x, v_x, y, v_y]$，$A, B, Q$ 离散化；
1b. 自写 KF（预测 + 更新）；
1c. 匀速直线仿真，报告 RMSE。

**题目 2（核心，30 分）：噪声与一致性**
2a. 扫 $R \in \{0.1, 1, 10\}$，报告 RMSE 与增益变化；
2b. 计算 NEES（10 次 MC），一致性检验；
2c. 验证 KF 精度与 CRB 的关系（可达下界）。

**题目 3（进阶，25 分）：测量缺失与野值**
3a. 30% 测量缺失（随机），报告纯预测外推段误差增长；
3b. 注入 3 个野值（±20σ），用新息门限（$|r| \le 3\sigma$）剔除，报告恢复；
3c. 对比有/无野值处理的轨迹。

**题目 4（应用，20 分）：转弯目标**
4a. 目标中途转弯（恒定转弯率），CV 模型跟踪误差分析；
4b. 增大 $Q$ 补偿模型失配，报告误差改善；
4c. 结论：KF 的模型假设边界与对策。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定真实轨迹、种子、测量缺失模式；
- 报告注明 $Q, R$ 与 MC 次数。

## 7. 提交产物

- 报告：模型、实现、误差/NEES、缺失野值处理、结论；
- 代码 + README；
- 数据表（R 扫描 × RMSE）。

| 缺失/野值 | 25 | 门限剔除有效 |

## 9. 引导与自检

- 常见失败：$Q$ 过小致"过度自信"、野值门限未用新息协方差 $S$、NEES 单次当结论；
- 调试路径：直线跟踪 → 一致性 → 缺失/野值 → 转弯；
- 自查清单：
  - [ ] 野值剔除用 $r^\top S^{-1} r$ 而非绝对差；
  - [ ] NEES 用 10 次 MC；
  - [ ] 缺失段误差增长有解释；
  - [ ] 转弯场景 Q 调大有对比。
