# 项目-PUMA仿真

> 阶段作业（stage · lab）：为 PUMA 560 建立 DH 参数与正逆运动学，仿真末端位姿与工作空间。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 2：机器人学基础模型 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 建立 PUMA 560 的 DH 参数表（标准 DH 约定）；
- 实现正运动学（FK）并验证末端位姿；
- 实现解析逆运动学（PUMA 有闭合解）或数值 IK；
- 采样关节空间生成末端可达点云（工作空间可视化）。

## 3. 所需知识

- `requires`：PUMA560、机械臂DH参数与逆运动学、齐次变换矩阵；
- 前置支撑：旋转矩阵、变换链、欧拉角。

## 4. 任务背景与边界

- **场景**：PUMA 560 六自由度机械臂；
- **输入**：DH 参数表、关节角/目标末端位姿；
- **输出**：FK/IK 验证、工作空间点云；
- **禁止**：直接调 `ModernRobotics` 库的 FKinSpace 交差（可对照）。

## 5. 详细题目

**题目 1（基础，25 分）：DH 建模与 FK**
1a. 建立 PUMA 560 的 DH 参数表（$a_i, \alpha_i, d_i, \theta_i$）；
1b. 实现 FK：给定关节角 → 末端位姿矩阵 $T$；
1c. 用官方 `ModernRobotics` 或教材示例数值交叉验证。

**题目 2（核心，30 分）：逆运动学**
2a. 实现解析 IK（PUMA 闭式解，分 $\theta_1, \theta_3$ 几何解 + 腕部欧拉角）；
2b. 测试 5 个目标位姿，报告解数（多解）与精度（位置 < 1 mm）；
2c. 实现数值 IK（Jacobian 迭代）作对照，比较收敛性。

**题目 3（进阶，25 分）：工作空间**
3a. 随机采样关节角（$N = 5000$），计算末端位置点云；
3b. 绘制工作空间（XY/XZ 投影）并标注奇异边界；
3c. 分析"腕部奇异"（$\theta_5 = 0$）时的末端行为。

**题目 4（应用，20 分）：路径验证**
4a. 生成一条末端直线路径，用 IK 逆解出关节轨迹；
4b. 检查路径是否穿越奇异/工作空间边界，报告处理；
4c. 结论：PUMA 构型的运动学特点（奇异性、多解选择）。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；
- 固定 DH 表、采样种子、目标位姿集合；
- 报告注明 DH 表与验证数据。

## 7. 提交产物

- 报告：DH 表、FK/IK 验证、工作空间图、路径分析、结论；
- 代码 + README；
- 验证表（目标位姿 vs 逆解 vs 误差）。

## 8. 验收标准与 Rubric

| 维度 | 分值 | 通过要求 |
|:---|:---:|:---|
| DH + FK | 25 | 参数正确、FK 有交叉验证 |
| 逆运动学 | 30 | 5 目标位姿精度达标、多解分析 |
| 工作空间 | 25 | 点云与奇异边界正确 |
| 路径验证 | 20 | 路径-奇异处理有记录 |

## 9. 引导与自检

- 常见失败：DH 约定（标准 vs 修正）混用、腕部奇异未处理、IK 多解选择无准则；
- 调试路径：FK 先验证 → 解析 IK → 数值 IK 对照 → 采样工作空间；
- 自查清单：
  - [ ] FK 末端位姿与参考一致；
  - [ ] 解析 IK 的解回代 FK 误差 < 1 mm；
  - [ ] 工作空间点云密度合理；
  - [ ] 奇异处有显式处理（如 $\theta_5$ 退化）。
