# 项目-MPC倒立摆

> 阶段作业（stage · lab）：用 MPC 控制倒立摆（线性 MPC 平衡 + 非线性 MPC 摆起），对比 LQR 的约束处理能力。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 9：MPC 深入 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 建立倒立摆线性/非线性预测模型；
- 实现线性 MPC 平衡控制（QP 形式）；
- 实现非线性 MPC 摆起（CasADi/数值优化）；
- 对比 MPC 与 LQR 在输入约束下的差异。

## 3. 所需知识

- `requires`：模型预测控制(MPC)、非线性车辆MPC、滚动优化；
- 前置支撑：倒立摆模型（阶段 5 作业）、LQR（阶段 5）。

## 4. 任务背景与边界

- **场景**：cart-pole 倒立摆，输入力 $F$（限幅 ±10 N）；
- **输入**：物理参数、预测时域、约束、初始条件；
- **输出**：平衡/摆起轨迹、输入曲线、约束检查；
- **禁止**：无约束 MPC 当"约束 MPC"交差；约束必须显式进 QP。

## 5. 详细题目

**题目 1（基础，25 分）：模型与离散化**
1a. 建立 cart-pole 线性模型（平衡点）与非线性模型；
1b. 离散化（$dt = 0.02$ s）；
1c. 验证开环预测。

**题目 2（核心，30 分）：线性 MPC 平衡**
2a. 装配 QP：代价（$\theta, x$ 误差 + 输入）+ 约束 $|F| \le 10$；
2b. $N = 20$ 滚动求解，$\theta_0 = 0.1$ rad 平衡仿真；
2c. 验证约束满足与收敛。

**题目 3（进阶，25 分）：非线性 MPC 摆起**
3a. 用 CasADi（或逐次线性化）实现非线性 MPC；
3b. 从 $\theta = \pi$ 摆起 + 平衡完整仿真；
3c. 报告摆起时间与输入峰值。

**题目 4（应用，20 分）：LQR vs MPC**
4a. LQR（无约束）在 $|F| \le 10$ 下的表现（输入饱和）；
4b. MPC（约束感知）同场景对比；
4c. 结论：约束场景下 MPC 的收益与计算代价。

## 6. 环境与复现

- 报告注明模型与求解器。

## 9. 引导与自检

- 常见失败：QP 不可行（预测时域内状态发散）、非线性 MPC 初值差、约束未进代价；
- 调试路径：LQR 平衡基线 → 线性 MPC → 非线性 MPC 摆起；
- 自查清单：
  - [ ] 平衡段 $|F| \le 10$ 全程；
  - [ ] 摆起时间可复现；
