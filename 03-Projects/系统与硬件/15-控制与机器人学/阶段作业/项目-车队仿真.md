# 项目-车队仿真

> 阶段作业（stage · lab）：仿真 N 车编队纵向跟随，验证串稳定性（扰动沿车队的衰减/放大）与间距保持。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `stage`（阶段作业） |
| 任务形态 | `lab`（编程实验 + 报告） |
| 所属阶段 | 阶段 7：纵向控制 |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 建立 N 车纵向跟随链（前车感知 + ACC 控制）；
- 定义并测量串稳定性（扰动沿车队传播）；
- 比较前车跟随/恒时距策略的串稳定性差异；
- 给出防"幽灵堵车"（扰动放大）的控制器设计原则。

## 3. 所需知识

- `requires`：串稳定性、安全距离、ACC切换逻辑；
- 前置支撑：纵向方程、PI速度控制（定速巡航）。

## 4. 任务背景与边界

- **场景**：5 车同车道编队，头车速度扰动（正弦/阶跃）；
- **输入**：车队参数、间距策略（固定时距/恒时距）、控制器增益；
- **输出**：间距误差传播曲线、串稳定性判定；
- **禁止**：只测首车响应；必须观察误差沿车队传播。

## 5. 详细题目

**题目 1（基础，25 分）：车队建模**
1a. 建立 5 车纵向动力学链（每车感知前车 + 自身速度）；
1b. 间距定义：$d_i = x_{i-1} - x_i$，误差 $e_i = d_i - d_{des}$；
1c. 实现头车速度指令序列（含正弦扰动）。

**题目 2（核心，30 分）：串稳定性测量**
2a. 定义串稳定性：$\|e_i(t)\|_\infty$ 随 $i$ 不增大（扰动不放大）；
2b. 恒时距策略下测量误差沿车队传播；
2c. 判定并报告：该策略是否串稳定？给出证据。

**题目 3（进阶，25 分）：策略对比**
3a. 固定时距（$d = v\tau + d_0$）vs 恒时距（$d = d_0$）对比；
3b. 扫控制器增益 $K_p, K_i$，报告串稳定性边界；
3c. 解释"为何某些参数组合导致误差沿车队放大"。

**题目 4（应用，20 分）：设计原则**
4a. 综合实验提出"串稳定 ACC"设计原则（间距策略 + 增益约束）；
4b. 用 5 车 + 8 车验证原则可扩展；
4c. 结论：与"幽灵堵车"现象的关系。

## 9. 引导与自检

- 常见失败：只报告头车/第二车响应、时距模型单位错、串稳定性判定无 $\infty$ 范数依据；
- 调试路径：2 车先跑通 → 5 车 → 参数扫描；
- 自查清单：
  - [ ] 误差传播曲线含全部 5 车；
  - [ ] 串稳定判定用 $\|e\|_\infty$；
  - [ ] 增益扫描有放大/衰减边界；
  - [ ] 8 车扩展验证记录。
