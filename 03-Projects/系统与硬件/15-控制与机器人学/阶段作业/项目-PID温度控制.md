# 项目-PID温度控制

> 阶段作业（stage · lab）：为加热炉建立一阶+延迟模型，设计并整定 PID 温度控制器，验证抗饱和与扰动抑制。本卡由原「项目-温度控制」与「项目-PID温度控制」合并转正（§5.5 不形式化拆分紧密知识点）。

## 2. 学习目标

完成后能够：
- 为一阶 + 纯延迟（FOPDT）温度过程建立模型并辨识参数；
- 用 Lambda 法/Ziegler-Nichols 设计 PID 并仿真验证；
- 实现抗饱和（anti-windup）并观察积分饱和现象；
- 评估稳态误差与扰动抑制，输出调参结论。

## 3. 所需知识

- `requires`：PID公式、抗饱和、稳态误差详细、CC调参；
- 前置支撑：二阶系统（阶段 1）、频率响应（阶段 4）；
- 可选扩展：与 PID 温度控制对比的模型预测控制（不设隐性前置）。

## 4. 任务背景与边界

- **场景**：电加热炉温度控制。被控对象近似 FOPDT：$G(s) = \dfrac{K e^{-\theta s}}{\tau s + 1}$；
- **输入**：加热功率指令（0-100%）、温度测量（含噪声）；
- **输出**：PID 参数、阶跃响应、抗饱和对比曲线、扰动响应；
- **禁止**：直接调库 `pid` 一跑了之；参数必须有设计依据。

## 5. 详细题目

**题目 1（基础，20 分）：对象辨识**
1a. 用阶跃响应实验数据（给定）辨识 $K, \tau, \theta$（两点法/切线法）；
1b. 写出 FOPDT 模型并画出拟合对比。

**题目 2（核心，30 分）：PID 设计与整定**
2a. 用 Lambda 法（$\lambda = 2\tau$ 起）给出 $K_p, T_i, T_d$；
2b. 用 Ziegler-Nichols 给出另一组参数；
2c. 仿真对比两组参数的阶跃响应（超调/调节时间/稳态误差）。

**题目 3（进阶，25 分）：抗饱和**
3a. 加入执行器限幅（0-100%），重现积分饱和（大超调 + 回落慢）；
3b. 实现 back-calculation 抗饱和，对比有/无抗饱和的响应；
3c. 解释饱和期间积分项的行为。

**题目 4（应用，25 分）：扰动与鲁棒性**
4a. 加入 20% 负载扰动（如开门散热），测扰动抑制；
4b. 模型参数 ±20% 偏差下重测，报告鲁棒性；
4c. 稳态误差分析：为何 PI 控制可消除阶跃扰动下的稳态误差（见 稳态误差详细）。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`；可选 `control` 库（`tf`、`step_response`）；
- 固定仿真步长（如 0.01 s）与随机种子；
- 报告注明对象参数、整定公式、限幅值。

## 7. 提交产物

## 9. 引导与自检

- 常见失败：$\theta$ 辨识偏小（把一阶滞后当纯延迟）、$K_i$ 过大振荡、限幅后积分持续累积（饱和）不处理；
- 调试路径：先无延迟模型跑通 PID → 加延迟 → 加限幅 → 加抗饱和 → 加扰动；
- 自查清单：
  - [ ] 辨识曲线与模型拟合图对比；
  - [ ] 两组整定参数都仿真验证；
  - [ ] 抗饱和前后对比同图；
  - [ ] 稳态误差结论引用「稳态误差详细」卡。
