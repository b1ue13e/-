# 项目-计算力矩

> 阶段作业（stage · lab）：为二连杆机械臂实现计算力矩（反馈线性化）控制，对比关节 PID，验证动力学前馈的价值。

## 2. 学习目标

完成后能够：
- 用拉格朗日方法推导二连杆机械臂动力学 $M(q)\ddot q + C(q,\dot q)\dot q + G(q) = \tau$；
- 实现计算力矩控制律并推导闭环误差方程；
- 在 PyBullet 中对比关节 PID 与计算力矩的高速跟踪；
- 分析模型参数误差对计算力矩性能的影响。

## 3. 所需知识

- `requires`：拉格朗日方程、几何Jacobian、速度传递、计算力矩控制；
- 前置支撑：DH 参数、变换链（阶段 2 模块 A）；
- 可选扩展：关节空间控制实现（阶段 11）。

## 4. 任务背景与边界

- **场景**：二连杆平面机械臂（无重力简化或含重力），目标关节轨迹跟踪；
- **输入**：连杆参数（$m_1, m_2, l_1, l_2$）、参考轨迹；
- **输出**：动力学模型、计算力矩控制、跟踪误差对比；
- **禁止**：直接用 PyBullet 内置逆动力学不说明；必须自写动力学。

## 5. 详细题目

**题目 1（基础，25 分）：动力学建模**
1a. 用拉格朗日法推导二连杆 $M(q), C(q,\dot q), G(q)$（含科氏项）；
1b. 数值验证：$M(q)$ 对称正定，$\dot M - 2C$ 反对称；
1c. 给定参数（$m_1 = m_2 = 1$ kg、$l_1 = l_2 = 1$ m、$g = 9.81$）写出显式矩阵。

**题目 2（核心，30 分）：计算力矩控制**
2a. 实现 $\tau = M(q)(\ddot q_d + K_d \dot e + K_p e) + C\dot q + G$；
2b. 取 $K_p = 100, K_d = 20$（闭环 $\omega_n = 10$、$\zeta = 1$），仿真正弦轨迹跟踪；
2c. 报告跟踪误差（位置 RMS）。

**题目 3（进阶，25 分）：对比关节 PID**
3a. 实现每关节独立 PD/PID（无动力学前馈）；
3b. 同一轨迹对比：低速（$\omega = 1$ rad/s）与高速（$\omega = 5$ rad/s）下误差；
3c. 解释"高速时 PID 误差为何显著增大（耦合+科氏）"。

**题目 4（应用，20 分）：参数鲁棒性**
4a. 计算力矩用的 $M, C, G$ 与真实参数偏差 ±20%，重测；
4b. 报告参数失配下的误差劣化曲线；
4c. 结论：模型精度与性能的权衡（何时 PID 够用、何时必须计算力矩）。

## 9. 引导与自检

- 常见失败：$C$ 矩阵符号错（科氏项）、$M$ 非正定、PyBullet 关节序号错位、增益过大激励未建模动态；
- 调试路径：先无重力（纯惯性）→ 加重力 → 加科氏 → 高速对比；
- 自查清单：
  - [ ] $\dot M - 2C$ 反对称数值验证；
  - [ ] 计算力矩闭环误差 < PID 一个量级（高速）；
  - [ ] 参数失配实验保留原始参数对照；
  - [ ] PyBullet（如用）与自写动力学结果一致。
