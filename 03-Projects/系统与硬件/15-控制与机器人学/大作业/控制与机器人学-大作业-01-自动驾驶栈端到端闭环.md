# 控制与机器人学-大作业-01-自动驾驶栈端到端闭环

> 大作业（capstone · project）：跨阶段串联**定位 → 规划 → 跟踪 → 控制**的完整闭环。本地融合任务（非冒充官方作业）：以 PythonRobotics 四模块为基线，集成 MIT 6.832 方法。

## 2. 学习目标

完成后能够：
- 搭建一个可复现的自动驾驶仿真栈（GPS+里程计 → A*/RRT → PP/MPC → 执行器）；
- 统一评估定位、规划、跟踪各环节的误差与失败模式；
- 比较至少两种规划或控制方法（A* vs RRT；PP vs MPC）；
- 输出包含基线、消融、失败案例与限制说明的完整报告。

## 3. 所需知识

- `requires`：导航定位、路径规划Astar与RRT、纯跟踪与Stanley控制器、模型预测控制(MPC)、ROS2工程基础；
- 前置支撑：阶段 8/9/10/11 全部核心卡；
- 机械臂方向可选（替代车辆栈，需说明选择理由）。

## 4. 任务背景与边界

- **场景**：统一仿真环境（PythonRobotics 自建或 CARLA）中完成"从起点到终点"的自动驾驶闭环；
- **输入**：地图、起点终点、传感器噪声模型（GPS/IMU）；
- **输出**：端到端轨迹、各环节误差、成功率、失败案例；
- **禁止**：直接调用官方整栈 demo 作为交付；各环节必须自写核心逻辑并注明参考。

## 5. 详细题目

**题目 1（基础，20 分）：系统集成与基线**
1a. 搭建"定位（EKF）→ 规划（A*）→ 跟踪（PP）→ 控制（执行器模型）"流水线；
1b. 跑通"朴素基线"：A* + PP，报告端到端成功率（≥ 10 次随机起点）。

**题目 2（核心，30 分）：方法比较**
2a. 规划侧：A* vs RRT*（同地图），比较路径质量与成功率；
2b. 跟踪侧：PP vs MPC（同路径），比较横向误差 RMS 与约束满足。

**题目 3（进阶，30 分）：消融与失败分析**
3a. 消融：去掉 EKF 定位（用理想位姿）vs 用估计位姿，量化定位误差对端到端的影响；
3b. 失败案例：挑 3 个失败场景（如窄道、传感器丢失、MPC 不可行），分析根因；
3c. 限制说明：算法/模型/仿真的边界。

**题目 4（综合，20 分）：评估与报告**
4a. 统一指标：成功率、平均到达时间、横向误差 RMS、碰撞率；
4b. 报告含复现步骤（种子、参数、环境）、结果表、结论；
4c. 可选：ROS2 节点化集成（加分项，不设隐性前置）。

## 6. 环境与复现

- Python 3.10+，依赖 `numpy`、`matplotlib`、`scipy`、`cvxpy`（MPC）；

- 记录官方 commit hash（PythonRobotics）与运行环境；
- 预计运行时间：单次端到端 < 5 分钟（CPU）。

## 9. 引导与自检

- 常见失败：定位误差累积导致规划失败（先查 EKF）、MPC 不可行（软约束）、PP 在窄道振荡（$L_d$ 自适应）；
- 里程碑拆解（每步可验收）：
  1. EKF 定位单跑（复用阶段作业-10）→ 2. A* 单跑 → 3. PP 跟踪（复用阶段作业-06）→ 4. 串起来 → 5. MPC 替换 → 6. 消融与失败分析；
- 自查清单：
  - [ ] 端到端 10 次成功率 ≥ 70%（朴素基线）；
  - [ ] 比较在同地图/同种子下进行；
  - [ ] 每个失败案例有根因分析（非"运气不好"）；
  - [ ] 报告不含夸大结论（边界写清楚）。
