# 项目-自动驾驶仿真

> 大作业（capstone · project）：在统一仿真中实现自动驾驶栈闭环——定位 → 规划 → 跟踪 → 控制，聚焦多算法比较与端到端评估。与大作业-01 互补（本作业侧重在固定场景下做消融与方法对比）。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `capstone`（大作业） |
| 任务形态 | `project`（综合项目 + 报告） |
| 所属阶段 | 跨阶段（阶段 8-11） |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 组装"EKF 定位 → A*/RRT 规划 → PP/MPC 跟踪"完整栈；
- 在固定场景做规划/控制方法的公平比较（消融）；
- 量化定位误差对端到端性能的影响；
- 输出包含基线、消融、失败案例的完整报告。

## 3. 所需知识

- `requires`：状态空间与LQR控制、路径规划Astar与RRT、模型预测控制(MPC)、导航定位；
- 前置支撑：横向控制工程实现、MPC车辆工程实现（阶段 11）；
- 先决条件：完成阶段作业-08/06/10（各模块单测）。

## 4. 任务背景与边界

- **场景**：固定地图（含障碍）与随机起点终点（≥ 10 次）；
- **输入**：地图、传感器噪声模型、方法配置；
- **输出**：端到端成功率、误差、失败案例；
- **禁止**：各环节直接调用官方整栈；核心模块必须自写并注明对照。

## 5. 详细题目

**题目 1（基础，20 分）：栈组装与基线**
1a. 组装定位（EKF）→ 规划（A*）→ 跟踪（PP）→ 执行；
1b. 跑通朴素基线（A* + PP），报告成功率（≥ 10 次随机起点）；
1c. 记录各环节耗时与误差分配。

**题目 2（核心，30 分）：方法比较**
2a. 规划：A* vs RRT*（同地图），比较路径质量与成功率；
2b. 跟踪：PP vs MPC（同路径），比较横向误差 RMS 与约束满足；
2c. 报告公平比较的方法（同种子、同场景）。

**题目 3（进阶，30 分）：消融与失败分析**
3a. 消融：理想位姿 vs EKF 位姿，量化定位误差影响；
3b. 失败案例 3 个（窄道、传感器丢失、MPC 不可行）逐个根因；
3c. 限制说明（模型/仿真边界）。

**题目 4（综合，20 分）：评估报告**
4a. 统一指标：成功率、平均到达时间、RMS、碰撞率；
4b. 报告复现步骤（种子、参数、环境）与结论；
4c. 可选：与 CARLA 高保真环境对照（加分项）。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`、`cvxpy`/`osqp`；
- 固定种子、地图、传感器参数；单次端到端 < 5 分钟；
- 报告注明官方 commit hash 与运行环境。

## 7. 提交产物

- 报告：问题定义、基线、方法、消融、失败案例、限制、复现；
- 代码仓库 + README；
- 结果数据（成功率表、误差表、轨迹图）。

## 9. 引导与自检

- 里程碑拆解：EKF 单跑 → A* 单跑 → PP 跟踪 → 串联 → MPC 替换 → 消融；
- 常见失败：定位误差累积致规划失败、MPC 不可行（软约束）、PP 窄道振荡；
- 自查清单：
  - [ ] 端到端 10 次成功率 ≥ 70%；
  - [ ] 比较同地图同种子；
  - [ ] 每个失败案例有根因；
  - [ ] 报告不含夸大结论。
