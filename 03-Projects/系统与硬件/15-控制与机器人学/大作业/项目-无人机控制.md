# 项目-无人机控制

> 大作业（capstone · project）：为四旋翼建立动力学模型，设计姿态-位置级联控制与 LQR 姿态控制，在仿真中验证悬停与轨迹跟踪。

## 1. 作业身份

| 项 | 值 |
|:---|:---|
| 课程 | 控制与机器人学（15-控制与机器人学） |
| 规模层级 | `capstone`（大作业） |
| 任务形态 | `project`（综合项目 + 报告） |
| 所属阶段 | 跨阶段（阶段 5/10/11） |
| 来源类型 | `local_integration_task`（本地化改编） |

## 2. 学习目标

完成后能够：
- 建立四旋翼动力学模型（刚体 + 螺旋桨力/力矩）；
- 设计级联控制器（外环位置/速度 → 内环姿态 → 电机分配）；
- 用 LQR 设计姿态控制器并对比 PD；
- 仿真悬停、轨迹跟踪与抗风扰动。

## 3. 所需知识

- `requires`：状态空间与LQR控制、LQR代价函数、EKF非线性状态估计；
- 前置支撑：旋转矩阵、角速度、欧拉角（阶段 2）；
- 先决条件：完成阶段 5 检查点与状态估计基础。

## 4. 任务背景与边界

- **场景**：四旋翼（X 构型），悬停 → 轨迹跟踪（直线/圆形）；
- **输入**：机体参数（$m, I, k_f, k_m$）、参考轨迹、风扰；
- **输出**：控制律、姿态/位置响应、电机指令；
- **禁止**：直接用 gym-pybullet-drones 的整机控制器交差；核心控制律须自设计。

## 5. 详细题目

**题目 1（基础，25 分）：动力学建模**
1a. 建立四旋翼刚体动力学（位置、姿态运动学 + 欧拉方程）；
1b. 建立电机模型（转速 → 力/力矩分配矩阵）；
1c. 在 PyBullet 中加载四旋翼并验证模型参数。

**题目 2（核心，30 分）：级联控制器**
2a. 外环：位置误差 → 期望加速度 → 期望姿态（倾斜角）；
2b. 内环：姿态 LQR（状态 $[\phi, \theta, \psi, p, q, r]$）；
2c. 悬停仿真，报告位置漂移与姿态收敛。

**题目 3（进阶，25 分）：轨迹跟踪**
3a. 圆形轨迹（半径 2 m、周期 20 s）跟踪；
3b. 报告位置误差 RMS 与姿态响应；
3c. 加风扰（阵风模型），测扰动抑制。

**题目 4（应用，20 分）：方法对比**
4a. 姿态环 LQR vs 调优 PD 对比（跟踪误差/鲁棒性）；
4b. 扫 LQR 权重（$Q$ 姿态 vs 角速度），报告响应差异；
4c. 结论：级联结构的带宽设计与局限。

## 6. 环境与复现

- Python 3.10+，`numpy`、`matplotlib`、`scipy`、`pybullet`（可选）；
- 固定机体参数、参考轨迹、种子、风扰参数；
- 报告注明控制器参数与控制频率。

## 7. 提交产物

- 报告：建模、控制器设计、仿真图、对比、结论；
- 代码 + README；
- 数据表（控制器 × 误差 × 电机峰值）。

## 9. 引导与自检

- 常见失败：欧拉角奇异、分配矩阵符号错、内环带宽不足致振荡、风扰模型过强；
- 里程碑：悬停 → 直线 → 圆形 → 风扰 → 对比；
- 自查清单：
  - [ ] 悬停位置漂移 < 0.2 m；
  - [ ] 圆形 RMS < 0.5 m；
  - [ ] 电机指令在限幅内；
  - [ ] LQR vs PD 同场景同种子。
