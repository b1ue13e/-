# 计算机组成原理-阶段作业-06-汇编器

> 非官方中文版：题目结构保留 Nand2Tetris Project 6 官方任务编号（P6a-P6e），语义本地化。

## 1. 作业身份

- 课程：计算机组成原理（阶段1：CPU架构 → 工具链起点）
- 规模：`stage`（阶段作业）｜形态：`lab`（编译工具实现）
- 来源：Nand2Tetris Project 6（The Assembler），`adapted_from`
- 官方页：[nand2tetris.org/project06](https://www.nand2tetris.org/project06)
- 前置知识：[[01-CPU架构/汇编器与符号表]]（两遍扫描、符号表）、[[01-CPU架构/ISA-指令系统详解]]（指令编码）、[[01-CPU架构/指令集架构]]

## 2. 学习目标

完成后你应该能够：

1. 把汇编器拆成四个正交模块：Parser（词法/语法）、Code（编码表）、SymbolTable（符号解析）、Driver（两遍扫描）；
2. 实现符号解析的两遍扫描算法，说明"为什么一遍扫描无法处理前向标签引用"；
3. 正确区分标签（`(LOOP)`，不占指令地址）与变量（`@i`，从 RAM[16] 起分配）；
4. 让你的输出与官方 Assembler **逐字节一致**，并能解释任一差异位来自哪个字段；
5. 认识到本作业的模块划分会在 HW10/HW11 编译器中原样复用（Parser + SymbolTable + CodeGen）。

## 3. 任务背景与边界

- 语言：不限（Python / Java / C++ / Rust 均可），仅用标准库。
- 输入输出：`Prog.asm` → `Prog.hack`，每行 16 个 `0/1` 字符 + 换行；不得输出多余空行或 BOM。
- 与既有作业的关系：[[阶段作业/计算机组成原理-阶段作业-01-机器语言与汇编器]] 是 **P4+P6 合并版**；本作业是 P6 的独立细化版本（新增模块化拆分要求 P6a、错误处理 P6d）。二者择一提交；若已完成阶段作业-01 的 P6 部分，本作业只需补 P6a 的模块文档与 P6d 的错误处理即可记为完成。
- 禁止事项：不得复制官方 Assembler 源码或他人提交；不得调用外部汇编器生成结果再包装。

## 4. 详细题目

### P6a 模块设计（先设计后编码）

在 `设计.md` 中给出四个模块的接口签名（伪代码即可）：

| 模块 | 职责 | 关键接口 |
|:---|:---|:---|
| `Parser` | 逐行读取、去注释/空白、判定指令类型、切出字段 | `hasMoreLines()` / `advance()` / `instructionType()` / `symbol()` / `dest()` / `comp()` / `jump()` |
| `Code` | 助记符 → 二进制字段 | `dest(str)->3bit` / `comp(str)->7bit` / `jump(str)->3bit` |
| `SymbolTable` | 符号 → 地址 | `addEntry()` / `contains()` / `getAddress()` |
| `Driver` | 两遍扫描编排 | `firstPass()` / `secondPass()` |

**要求**：写清"为什么 Code 模块必须是纯函数、无状态"。

### P6b 无符号汇编器

先实现只处理**无符号**程序的版本（输入中不含 `(LABEL)` 与变量 `@name`，只有 `@123` 数字常量）。

通过官方 `add/Add.asm`、`max/MaxL.asm`、`rect/RectL.asm`、`pong/PongL.asm` 四份无符号输入。

### P6c 完整汇编器（含符号表）

扩展支持：

1. **预定义符号**：`R0–R15`、`SP`、`LCL`、`ARG`、`THIS`、`THAT`、`SCREEN`(16384)、`KBD`(24576)；
2. **标签**：第一遍扫描收集 `(XXX)` → 下一条指令的 ROM 地址（标签本身不占地址）；
3. **变量**：第二遍遇到未知符号时，从 RAM[16] 起递增分配。

通过官方 `max/Max.asm`、`rect/Rect.asm`、`pong/Pong.asm`。

### P6d 错误处理与鲁棒性（本作业新增题）

你的汇编器遇到下列输入时必须**报错并给出行号**，而不是静默产出错误的 `.hack`：

| 非法输入 | 期望行为 |
|:---|:---|
| `@70000`（超出 15 位地址范围） | 报错：常量越界 |
| `D=X+1`（未知 comp 助记符） | 报错：非法计算字段 |
| `(LOOP)` 重复定义 | 报错：符号重复 |
| `D=M;JXX`（未知 jump） | 报错：非法跳转字段 |

自建 `tests/bad/` 放 4 个非法样例，在 `报告.md` 贴出报错输出。

### P6e 自举验证（进阶，可选）

用你的汇编器汇编 [[阶段作业/计算机组成原理-阶段作业-04-机器语言]] 的 `Mult.asm` / `Fill.asm`，把产出的 `.hack` 载入 [[阶段作业/计算机组成原理-阶段作业-05-计算机体系结构]] 的 `Computer.hdl` 运行成功——这意味着"你写的工具链 + 你造的硬件"闭环打通。

## 8. 引导与自检（不泄露答案）

- 检查点 1：`(LOOP)` 出现在第 10 行代码之后，它的地址是 10 还是 11？——想清楚"标签不占 ROM 地址"这句话的确切含义。
- 检查点 2：`@R5` 和 `@5` 生成的机器码一样吗？——一样。那为什么还需要预定义符号？（可读性 + 与 VM 阶段的约定）
- 检查点 3：变量分配从 16 开始，如果一个程序用了 300 个变量会怎样？——想想 RAM 布局与栈区冲突。
- 常见失败：注释 `//` 出现在行尾未剥离；行内 Windows 换行 `\r` 混入导致助记符匹配失败；第一遍扫描把 `(LABEL)` 也计入指令计数；`comp` 表漏了 `a=1` 那一半（`M` 系列）；输出末尾多一个空行导致 diff 报错。
- 提交前清单：□ 7 份官方输入全部 diff 无差异；□ 4 类错误均报行号；□ 无 `\r` 污染；□ 设计文档先于代码；□ 报告含符号表快照。
