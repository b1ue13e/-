## 2. 学习目标

完成后你应该能够：

1. 用 Jack（类 Java 的极简面向对象语言）写出一个可运行的交互式程序；
2. 说清 Jack 的三类变量作用域（`static` / `field` / `var` 与 `argument`）各自的生命周期；
3. 使用 Jack 标准库（`Screen`/`Output`/`Keyboard`/`Array`/`String`/`Math`/`Memory`/`Sys`）完成 I/O 与内存操作；
4. 手工完成对象的构造与销毁（`Memory.alloc` / `dispose`），体会"无 GC 语言"的资源纪律；
5. 从"程序员视角"预判编译器需要做什么——本作业是 HW10/HW11 的**需求说明书**。

## 3. 任务背景与边界

- 环境：Nand2Tetris 软件套件的 **JackCompiler**（官方编译器）+ **VM Emulator**。本作业**使用官方编译器**，不要求自写（自写在 HW10/HW11）。
- 输入输出：一个目录内的多个 `.jack` 文件 → 官方编译器产出 `.vm` → VM Emulator 运行。
- 范围边界：本作业**不评价编译器实现**，只评价你的 Jack 程序设计与运行正确性。
- 禁止事项：不得直接提交官方示例程序（Pong/Square 原样）；可参考其结构但功能须自选或显著改造。

## 4. 详细题目

### P9a 语言规格摘要（先做）

在 `设计.md` 中用你自己的话填完：

| 概念 | Jack 的写法 | 与 Java/C 的差异 |
|:---|:---|:---|
| 类与构造函数 | `constructor Foo new(...)` | ? |
| 方法 / 函数 / 构造 | `method` / `function` / `constructor` | ? |
| 变量作用域 | `static` / `field` / `var` / 参数 | ? |
| 基本类型 | `int` / `char` / `boolean` + 类类型 | ? |

并回答：Jack 没有运算符优先级，`1 + 2 * 3` 的求值结果是多少？这对你写表达式有什么约束？

### P9b 最小可运行程序（热身）

写一个 `Main.jack`，在屏幕上打印你的名字并等待按键退出。目的：跑通"编辑 → 编译 → VM Emulator 运行"的完整回路。

### P9c 交互式应用（主任务，二选一）

自选其一实现，**必须**包含至少 3 个类、至少 1 个自定义类的构造与 `dispose`：

**方案 A：图形交互程序**
例如可移动方块 / 简易贪吃蛇 / 打砖块。要求：键盘控制、边界碰撞检测、屏幕重绘不留残影。

**方案 B：数据结构演示程序**
例如可视化的排序过程 / 链表或栈的图形化演示 / 简易计算器。要求：用 `Array` 实现底层存储，用 `Output`/`Screen` 展示状态变化。

**通用要求**：

1. 至少 3 个类，职责分离（如 `Main` / 领域类 / 渲染或工具类）；
2. 每个自定义对象都有配对的 `dispose`，程序退出前全部释放；
3. 处理至少 2 个边界条件（如越界、空输入、数组满）；
4. 代码有注释，说明每个类的职责。

### P9d 资源与内存纪律（本作业新增题）

在 `报告.md` 中说明：

- 你的程序共分配了几类对象？各在何时释放？
- 若忘记 `dispose`，在 Hack 这样的 32K RAM 机器上会发生什么？（结合堆区被耗尽的后果描述）
- 用 `Memory.peek` 观察堆指针（或用 VM Emulator 观察 RAM 变化）给出一次分配前后的对照数据。

### P9e 编译器需求预判（进阶，可选）

挑出你程序中的 3 个语法结构（如 `let a[i] = b;`、`if/else`、`do obj.method(x)`），预测官方编译器会生成怎样的 VM 代码；再用官方编译器实际编译，对照你的预测。差异写进 `报告.md`——这份对照将直接成为 [[阶段作业/计算机组成原理-阶段作业-11-编译器后端]] 的自测基线。

## 8. 引导与自检（不泄露答案）

- 检查点 1：`method` 与 `function` 的区别是什么？——一个隐含 `this`，一个没有；调用方式也不同（`do obj.m()` vs `do Class.f()`）。
- 检查点 2：`Array` 是对象还是原生类型？它的元素有类型检查吗？——想清楚这会带来什么风险。
- 检查点 3：屏幕重绘留残影通常是因为什么？——先擦后画的顺序问题。
- 检查点 4：Jack 的 `while` 没有 `break`，你打算怎么提前退出循环？
- 常见失败：构造函数忘写 `return this;`；`do` 与 `let` 用混（有返回值的调用必须用 `let`，无返回值必须用 `do`）；表达式依赖了运算符优先级（Jack 从左到右求值，必须显式加括号）；对象释放后仍被引用导致行为不可预测。
- 提交前清单：□ 官方编译器零错误；□ ≥3 类；□ 全部对象配对 dispose；□ 3 张截图；□ 边界条件已测。
