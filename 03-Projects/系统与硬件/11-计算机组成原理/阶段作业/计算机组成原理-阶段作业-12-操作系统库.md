5. **回答一个边界问题**：这些能力中，哪些属于计算机组成原理，哪些其实属于操作系统课程。

## 4. 详细题目

### P12a Memory（核心，与计组关联最紧）

实现 `Memory.peek/poke/alloc/deAlloc`。

- 堆区起于 2048、止于 16383；用**空闲链表**管理（每块含 `size` 与 `next` 两个头字段）；
- `alloc(size)`：首次适配（first-fit）或最佳适配（best-fit），二选一并在文档中说明理由；
- `deAlloc(o)`：归还到空闲链表；**进阶**：实现相邻空闲块合并（coalescing）；
- 用 `MemoryTest` 验证。

**必答**：在 `设计.md` 中对照 [[02-内存管理/内存分配器]]，说明你的策略会产生哪一类碎片（内部/外部），并给出一个能触发该碎片的分配序列。

### P12b Math

实现 `multiply` / `divide` / `sqrt` / `abs` / `min` / `max`。

- `multiply`：移位加法（Hack 无乘法指令），需 O(n) 次迭代（n=16）；
- `divide`：递归倍增减法，O(log n) 深度；
- `sqrt`：二分法，从最高位向下试探；
- 用 `MathTest` 验证。

**必答**：给出 `multiply` 与 `divide` 的时间复杂度推导（以位宽 n 为参数）。

### P12c String

实现 `new/dispose/length/charAt/setCharAt/appendChar/eraseLastChar/intValue/setInt/backSpace/doubleQuote/newLine`。

- 用 `Array` 作底层存储，`maxLength` 固定；
- `setInt` 需处理负数与 0；
- 用 `StringTest` 验证。

### P12d Array

实现 `Array.new` / `dispose`（本质是 `Memory.alloc/deAlloc` 的薄封装）。用 `ArrayTest` 验证。

### P12e Screen

实现 `init/clearScreen/setColor/drawPixel/drawLine/drawRectangle/drawCircle`。

- `drawPixel` 需按位读改写（一个字 16 像素）；
- `drawLine` 用整数增量算法（避免除法）；
- 用 `ScreenTest` 验证。

### P12f Output

实现 `init/moveCursor/printChar/printString/printInt/println/backSpace`。使用官方字符位图表。用 `OutputTest` 验证。

### P12g Keyboard 与 Sys

- `Keyboard`：`keyPressed/readChar/readLine/readInt`（需与 `Output` 配合回显）；
- `Sys`：`init/halt/error/wait`（`wait` 用忙等循环，需标定循环次数）；
- 用 `KeyboardTest`、`SysTest` 验证。

### P12h 全 OS 收官（本作业新增题）

把你实现的 8 个类**全部替换**官方版本，编译 [[阶段作业/计算机组成原理-阶段作业-09-高级语言Jack]] 的自写程序（或官方 Pong）并在 VM Emulator 运行成功。

在 `报告.md` 记录：

- 哪一个类的替换最先暴露问题？为什么？
- 你的 OS 与官方 OS 在同一程序上的运行速度差异（用 VM Emulator 的指令计数粗估）。

## 8. 引导与自检（不泄露答案）

- 检查点 1：`Memory.alloc` 返回的地址是块头还是数据区首地址？——差 2 个字，接错会踩坏链表。
- 检查点 2：为什么 `Memory` 类可以用 `Array` 的技巧直接访问任意地址？——想想 Jack 里 `let a = 0; a[i]` 意味着什么（这是官方允许的"后门"）。
- 检查点 3：`Math.divide` 递归深度最大是多少？会不会爆栈？——用 16 位边界值试一次。
- 检查点 4：`drawLine` 为什么不能用 `dy/dx` 浮点斜率？——Hack 无浮点，且除法昂贵。
- 常见失败：空闲链表初始化时未设 `next=null` 导致遍历越界；`String.setInt` 未处理最小负数；`Screen.drawPixel` 用了赋值而非按位或/与，抹掉同一字内其他像素；`Sys.wait` 循环次数未标定导致过快或卡死；测试时目录里混了官方与自写同名类。
- 提交前清单：□ 8 组测试逐个隔离验证；□ 空闲链表结构图完成；□ 复杂度推导完成；□ P12h 全替换跑通；□ 边界反思已写。
