## 2. 学习目标

完成后你应该能够：

1. 实现两级作用域符号表：类级（`static` / `field`）与子程序级（`argument` / `var`），并说明查找顺序；
2. 把 Jack 的四类变量映射到 VM 的四个内存段：`static` / `this` / `argument` / `local`；
3. 生成表达式的**后序遍历**代码，说明"为什么栈机天然适合后序求值"；
4. 正确生成三类子程序的序言（prologue）：`function`（无 this）、`method`（`argument 0` 是 this）、`constructor`（调用 `Memory.alloc` 并 `return this`）；
5. 让你的编译器编译官方 Pong 并在 VM Emulator 上真正玩起来。

## 4. 详细题目

### P11a 符号表设计（先做）

在 `设计.md` 中填完这张映射表并说明查找顺序（先子程序级后类级）：

| Jack 声明 | 作用域 | VM 段 | index 从几开始 | 生命周期 |
|:---|:---|:---|:---:|:---|
| `static int x;` | 类级 | `static` | ? | ? |
| `field int y;` | 类级 | `this` | ? | ? |
| `method f(int a)` 的 `a` | 子程序级 | `argument` | ? | ? |
| `function f(int a)` 的 `a` | 子程序级 | `argument` | ? | ? |
| `var int t;` | 子程序级 | `local` | ? | ? |

并回答：为什么 `method` 的第一个显式参数 index 是 1 而不是 0？

### P11b 表达式代码生成

实现 `expression` / `term` / `expressionList` 的代码生成：

- 二元运算：先生成左操作数、再生成右操作数、最后发出运算命令（后序）；
- Jack 无运算符优先级，严格从左到右；
- `*` 与 `/` 必须翻译为 `call Math.multiply 2` / `call Math.divide 2`；
- 一元 `-` → `neg`，`~` → `not`；
- 常量：`true` → `push constant 0; not`，`false`/`null` → `push constant 0`，`this` → `push pointer 0`。

**里程碑验证**：先用官方 `Seven`（常量表达式）与 `ConvertToBin`（位运算与循环）跑通。

### P11c 语句代码生成

| 语句 | 关键点 |
|:---|:---|
| `let x = e;` | 变量 → 对应段 pop |
| `let a[i] = e;` | 数组赋值需借 `pointer 1`/`that 0`，**注意求值顺序**避免 `pointer 1` 被内层表达式覆盖 |
| `if (c) {..} else {..}` | 生成 `IF_TRUE_n` / `IF_FALSE_n` / `IF_END_n` 唯一标签 |
| `while (c) {..}` | 生成 `WHILE_EXP_n` / `WHILE_END_n` |
| `do f(...);` | 调用后必须 `pop temp 0` 丢弃返回值 |
| `return;` | 无返回值时必须 `push constant 0` 再 `return` |

**里程碑验证**：官方 `Square`（完整语句集）、`Average`（数组 + String）。

### P11d 对象与数组（面向对象支持）

- `constructor`：`push constant <字段数>` → `call Memory.alloc 1` → `pop pointer 0`，末尾 `return this`；
- `method`：序言 `push argument 0; pop pointer 0`；调用 `obj.f(x)` 时把 obj 作为第 0 个实参压入；
- `function`：无 this 序言；
- 数组访问 `a[i]`：`push a; push i; add; pop pointer 1; push that 0`。

**里程碑验证**：官方 `ComplexArrays`（多维/嵌套数组表达式）、`Pong`（完整 OO 程序）。

### P11e 全链路整合（本作业新增题）

用**你自己写的整条工具链**跑通一个程序：

```
你的 Jack 程序 (HW09)
  → 你的编译器 (HW11)         → .vm
  → 你的 VM 翻译器 (HW07/08)  → .asm
  → 你的汇编器 (HW06)         → .hack
  → 你的 CPU (HW05, Computer.hdl)  → 运行
```

在 `报告.md` 记录：每一级产物的行数/大小、整条链路上遇到的第一个不兼容点及其修复。**这是本课程"从与非门到高级语言"的收口证据。**

### P11f 生成质量对比（进阶，可选）

对同一 `.jack` 输入，对比你的编译器与官方编译器生成的 VM 指令条数，找出你多生成的部分（常见于表达式临时值与冗余 push/pop），提出 2 条优化并实测效果。

## 8. 引导与自检（不泄露答案）

- 检查点 1：`let a[i] = b[j];` 中有两次数组访问，`pointer 1` 只有一个——你打算怎么排序求值？（提示：把某一侧的结果先存进 `temp`）
- 检查点 2：`do Screen.drawRectangle(...)` 之后不 `pop temp 0` 会怎样？——栈会缓慢泄漏，几十次调用后行为异常。
- 检查点 3：`constructor` 若忘记 `pop pointer 0`，后续 `field` 访问会落到哪里？
- 检查点 4：`true` 为什么是 `push constant 0; not` 而不是 `push constant 1`？——想想 Hack VM 的 true 表示。
- 常见失败：`method` 的 argument index 未整体后移 1；`if/while` 标签计数器在类之间未隔离导致重名；字符串常量未生成 `String.new` + 逐字符 `String.appendChar`；`return;`（void）漏 `push constant 0` 导致栈失衡；符号表在进入新子程序时未清空子程序级条目。
- 提交前清单：□ 六组官方输入行为正确；□ Pong 可玩且无栈泄漏；□ 符号表两级隔离；□ 全链路整合已跑通；□ 报告含 bug 记录。
