# 计算机组成原理-阶段作业-01-机器语言与汇编器

> 非官方中文版：题目结构保留 Nand2Tetris Project 4 / Project 6 官方任务编号（P4、P6），语义本地化。

## 1. 作业身份

- 课程：计算机组成原理（阶段1：CPU架构）
- 规模：`stage`（阶段作业）｜形态：`lab`（汇编编程 + 汇编器实现）
- 来源：Nand2Tetris Project 4（Machine Language Programming）+ Project 6（The Assembler），`adapted_from`
- 官方页：[nand2tetris.org/project04](https://www.nand2tetris.org/project04)、[nand2tetris.org/project06](https://www.nand2tetris.org/project06)
- 前置知识：[[01-CPU架构/ISA-指令系统详解]]（指令格式/寻址）、[[01-CPU架构/汇编器与符号表]]（符号表/两遍扫描）

## 2. 学习目标

完成后你应该能够：

1. 读懂 Hack 机器语言（A 指令 `@value` / C 指令 `dest=comp;jump`），并手写汇编程序控制 CPU；
2. 用寄存器/内存寻址实现算术循环（乘法、I/O 交互）；
3. 实现一个汇编器：两遍扫描、符号表、指令编码，输出与官方 Assembler 逐字节一致的 `.hack` 文件；
4. 解释"为什么符号表机制是编译器的基础"（符号→地址映射在 HW06→HW10 编译器中原样复用）。

## 3. 任务背景与边界

- 环境：Nand2Tetris 软件套件（CPU Emulator / Assembler），汇编器实现语言不限（Python/Java/C++ 均可）；
- 输入输出：`Prog.asm` → 汇编器 → `Prog.hack`（每行 16 位 0/1），与官方 Assembler 输出逐字节一致；
- 禁止事项：不得复制官方 Assembler 源码或他人提交；不得直接调用外部汇编器生成结果。

## 4. 详细题目

### P4a 乘法（Multiply）

用 Hack 汇编实现 `R2 = R0 * R1`（R0、R1 为非负整数，结果可溢出 16-bit）。要求使用循环累加，**注释说明每段作用**。

### P4b I/O 交互（Fill）

实现"键盘输入非零时屏幕全亮，为零时屏幕全黑"的循环程序（对应屏幕内存映射 `SCREEN` 与键盘 `KBD`）。**至少给出一次状态转移说明**。

### P4c 自写分支循环（进阶，可选）

实现一个求 `n!`（n<8）或冒泡排序（固定数组）的汇编程序，验证你对 C 指令 jump 语义（JGT/JEQ/JLT/JMP）的掌握。

### P6a 基础汇编器（无符号）

实现汇编器第一阶段：只翻译**无符号**程序（`ProgL.asm` 类输入），支持 A 指令与 C 指令的二进制编码。

### P6b 完整汇编器（含符号）

扩展支持符号表：预定义符号（`SP/LCL/ARG/THIS/THAT/SCREEN/KBD`）、标签 `(LOOP)`、变量 `@x`。两遍扫描：

1. 第一遍：收集标签 → 地址；
2. 第二遍：翻译，变量从地址 16 起分配。

**验证**：你的输出与官方 Assembler 在官方测试程序上逐字节一致。

## 5. 环境与复现

- 依赖：Nand2Tetris 软件套件（CPU Emulator 用于测试 `.hack`，Assembler 用于对照）；Python 3 或 Java 实现汇编器。
- 目录：`03-Projects/系统与硬件/11-计算机组成原理/阶段作业/阶段1-汇编器/` 下建 `asm/`（源程序）、`assembler/`（实现）、`tests/`（官方测试副本）。

## 8. 引导与自检（不泄露答案）

- 检查点 1：`@R0` 在 Hack 中表示什么？（地址 0，即 D 寄存器映射的 RAM 单元）
- 检查点 2：C 指令 `D=M` 的 comp 编码是多少位？（6 位，`M` 表示访存）
- 常见失败：标签与变量同名冲突；第二遍扫描遗漏符号；C 指令 dest 位序写反（A/D/M 顺序）；
- 提交前清单：□ 官方测试全过；□ diff 无差异；□ 报告含状态转移图与 bug 记录。
