# 计算机组成原理-课后作业-01-逻辑门与布尔算术

> 非官方中文版：题目结构保留 Nand2Tetris Project 1-2 官方任务编号（P1a-P1f、P2a-P2e），语义本地化。

## 1. 作业身份

- 课程：计算机组成原理（阶段0：总图景）
- 规模：`lesson`（课后作业）｜形态：`problem-set`（题集+HDL 实现）
- 来源：Nand2Tetris Project 1-2（`adapted_from`），官方项目页 [nand2tetris.org/project01](https://www.nand2tetris.org/project01)
- 前置知识：[[00-总图景/布尔逻辑门与HDL]]（真值表、德摩根定律、组合逻辑）

## 2. 学习目标

完成后你应该能够：

1. 用真值表和布尔表达式描述任一基础逻辑门的行为；
2. 从 Nand 门出发，用 HDL 逐级构建 Not/And/Or/Xor/Mux/DMux；
3. 用 2 的补码解释 16-bit 加法的进位传播，并在 HDL 中实现 HalfAdder/FullAdder/Add16；
4. 说出"为什么所有组合逻辑都可以只靠 Nand 实现"。

## 3. 任务背景与边界

- 环境：Nand2Tetris 官方 `HardwareSimulator`（[下载](https://www.nand2tetris.org/software)）；仅使用 Nand 门作为原语，禁止在本题直接调用其他芯片。
- 输入输出：每份 `.hdl` 文件必须通过官方 `.tst` 测试脚本，无警告、无时序错误。
- 禁止事项：不允许复制官方参考实现或他人提交。

## 4. 详细题目

### P1a 基础门（Nand → Not / And / Or / Xor）

用 HDL 实现 `Not.hdl`、`And.hdl`、`Or.hdl`、`Xor.hdl`，每个芯片只用 Nand 门。

### P1b 多路选择（Mux / DMux）

实现 `Mux.hdl`（2 选 1）与 `DMux.hdl`（1 分 2）。Mux 的布尔表达式：`out = (a AND NOT sel) OR (b AND sel)`。

### P1c 多路总线（Mux8Way16 / DMux4Way）

实现 16-bit 宽、8 路输入的 `Mux8Way16.hdl` 与 4 路分发的 `DMux4Way.hdl`。

### P1d 16-bit 门（Not16 / And16 / Or16 / Mux16）

把 P1a 的门逐位扩展到 16-bit 总线版本。

### P2a 半加器 HalfAdder

`sum = a XOR b`，`carry = a AND b`。给出真值表后再写 HDL。

### P2b 全加器 FullAdder

三输入（a, b, c）→（sum, carry）。要求用两个 HalfAdder 组合。

### P2c 16-bit 加法器 Add16

用 FullAdder 级联实现 16-bit 无符号加法，解释最低位进位如何传播到最高位。

### P2d 增量器 Inc16

用 Add16 实现 `out = in + 1`。

### P2e ALU（进阶，可选）

实现 Nand2Tetris `ALU.hdl` 的 6 控制位（zx/nx/zy/ny/f/no）行为。完成本题可衔接阶段1的 [[01-CPU架构/ALU算术逻辑单元]]。

## 8. 引导与自检（不泄露答案）

- 检查点 1：`Not.hdl` 是否只用了一个 Nand？——是。
- 检查点 2：`Add16` 的最低位进位是否真的"走到"了最高位？——手动跑 `1111...1 + 0000...1` 应得 `0000...0` 且最终进位丢弃（无符号 16-bit 溢出）。
- 常见失败：Mux 的 sel 位序写反（bit 0 是最高位还是最低位）；DMux 的 in 未连接到所有输出。
- 提交前清单：□ 每个 .hdl 单独通过官方 .tst；□ 无时序芯片混入（本题全组合逻辑）；□ 报告含推导。
