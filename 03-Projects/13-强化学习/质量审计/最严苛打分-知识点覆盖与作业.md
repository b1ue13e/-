## 1. 知识点覆盖全面吗？

### 1.1 内部质量（卡片本身）：A−（优秀）
- 243 张卡 100% 含教学闭环（动机→定义→手算→对比误区→闭卷自测→派生视图）。
- 无 stub、无死链、无孤儿卡（B11 已验证，本轮复核 `requires` 死链=0）。
- 每一概念细分到公式/例子/对比，最丰富卡达 3075 字。

### 1.2 广度（相对"全面"RL 大纲）：B（良好但不全面）
**主干极深**（与声明 Spine 一致）：Bandits / MDP / DP / 值函数 / Bellman / TD-SARSA-Q / DQN 全家桶(Double·Dueling·PER·Noisy·C51·Rainbow) / 策略梯度 / REINFORCE / Actor-Critic(A2C·A3C·TRPO) / PPO(GAE·IS·PPOClip·PPOvsTRPO) / RLHF / 分布式(ApeX·IMPALA·R2D2·SEED) / DDPG·SAC。

**显著缺失（综合 RL 课程通常应包含）**：

| 缺失主题 | 重要性 | 说明 |
|:---|:---:|:---|
| 基于模型的 RL / Dyna / MuZero / World Model | ★★★ | 完全缺，是现代 RL 主干之一 |
| 离线 / Batch RL（CQL·BCQ·TD3+BC） | ★★★ | 完全缺，工业落地核心 |
| 模仿学习（BC·DAgger·GAIL） | ★★ | 完全缺 |
| TD3（双延迟 DDPG） | ★★ | DDPG、SAC 都有，唯独缺 TD3，谱系断裂 |
| 深度探索 / 好奇心 / 内在奖励 / RND | ★★ | 仅 bandit 级探索，深度探索缺 |
| 多智能体 RL 算法（IQL·MADDPG·self-play·PSRO） | ★★ | 仅「多智能体MDP」概念卡 + CS188 搜索，无算法 |
| AlphaGo / MCTS + RL | ★★ | 完全缺 |
| 分层 RL（options·Feudal） | ★★ | 完全缺 |
| 元 RL / 少样本 / 持续学习 | ★ | 缺 |
| 安全 / 约束 MDP / reward hacking 深讲 | ★★ | 仅 RLHF-KL 触及，无 CMDP/约束优化 |
| DPO（直接偏好优化） | ★★ | RLHF 止于 PPO，现代偏好优化缺 |
| 分布式 RL 框架（QR-DQN·IQN） | ★ | 仅 C51 |
| 函数逼近理论（tile coding·线性 FA·deadly triad 系统讲） | ★ | 仅「局限-*」卡点到即止 |

> 严苛结论：**本课程是「 Sutton&Barto + SpinningUp + CS188 + CS285 」主干的纵深的优秀课程，但不是一份"全面"的 RL  surveying 课程。** 若以"覆盖全面"为标尺，广度给 B。

### 1.3 逐卡→作业衔接：D（严重不足）
- 仅 21/243（8.6%）卡被作业直接 requires；91.4% 卡的派生作业块为空。
- 作业采用 **hub 锚定** 设计：每份作业挂在 7 个 hub 卡（如「PPO目标裁剪与最小实现」requires 7 个 hub），微卡（PPOClip-Epsilon、GAE-Lambda95、IS-KL、超参-*、工程-* 等）不被单独点名。

## 2. 课后作业打分（按用户两个维度）

### 2.1 "学完这张卡，有没有作业能练"：C−
- **逐卡层面：否。** 91.4% 的卡没有作业可挂。即便放宽到"所在阶段有作业"，也只在 hub 卡上成立。
- **阶段层面：是。** 7 个阶段 + 前置均有 ≥1 份作业（lesson×11 基本每阶段 1–2 份，stage×2，capstone×1），阶段级练习闭环成立。
- 即：作业**测的是概念簇（hub）**，不是**每张微卡**。对"逐卡可练"的严苛标准，这是不达标。

### 2.2 "是否是名校开源作业"：B−（严重高估需纠偏）
14 份作业 `source_type` 分布：

| 来源类型 | 数量 | 清单 |
|:---|:---:|:---|
| `official_assignment`（名校血统） | 4 | CS188-P1、CS188-P2、CS188-P3、HW02 |
| `local_integration_task`（本地自编） | 10 | 其余 11 份 lesson(除 CS188-P1/P2) + capstone |

**逐份解剖"名校开源"成色**：
- **CS188-P1（Pacman搜索）/ CS188-P2（多智能体搜索）**：属 Berkeley CS188 **Project 2（对抗/期望极大搜索）**，**不是 RL 作业**，是搜索项目。名校血统为真，但**非 RL**。
- **CS188-P3（Q学习与近似Q学习）**：Berkeley CS188 **Project 3（RL）**，**真正意义上是唯一一份 1:1 名校原生 RL 开源作业**。✅
- **HW02（DQN与PPO连续动作控制）**：**改编自** Berkeley CS285 HW1/HW2（Deep RL），非原题直译，属"名校衍生改编"。
- **其余 10 份**：本地自编（题面自包含、含可运行 Starter、Rubric 齐全，质量高，但**非名校开源**）。

> 严苛结论：若严格按"名校开源 RL 作业"标准，**真正达标的仅 CS188-P3 一份**；HW02 算名校衍生改编；CS188-P1/P2 是名校但非 RL；10/14 为本地自编。B11 称"作业 91 分 / 名校开源"过于乐观。

### 2.3 作业本身质量：A（单份优秀）
- 11 份 lesson 100% 含 ≤40–50 行可运行 Starter，且多数已实跑对齐手算值。
- 9 必填段（身份与边界 / 环境与 Starter / 题目 / 提交 / Rubric / 常见错误 / 进阶 / 自检 / 来源）基本齐备。
- 0 营销标签、围栏平衡、无死链。

### 2.4 作业综合评分（最严苛，满分 20）
| 维度 | 分 | 依据 |
|:---|:---:|:---|
| 单份作业质量 | 18 | Starter/Rubric/自检齐全，可运行 |

## 3. 总评与最该动手的两项

- **知识点综合 ≈ 14/20（B+）**；**作业综合 ≈ 13/20（B）**。
- 相对 B11 自评（卡 87 / 作业 91）：B11 把"阶段有 lesson"误当"逐卡可练"，且把"带名校血统 4 份"误当"名校开源作业"，两项在严苛口径下均需下调。
- **无阻断项、无死链**，发布门槛（结构层）仍可达；但"覆盖全面"与"逐卡可练"是真实短板。

### 建议（按性价比排序）
1. **补"逐卡可练"视图（低成本高收益）**：对 222 张未挂作业的卡，在「学完后可以完成」之外增加「相关下游知识/练习」聚合，或在阶段 MOC 维护"卡→作业"映射表，让微卡学习者至少能看到同簇作业。
2. **诚实标注来源（非阻断）**：B11 清单已提"开源许可待补"；另需区分 CS188-P1/P2 是搜索非 RL、HW02 是 CS285 改编、10 份为本地自编——避免"名校开源"被误读。
3. **补广度缺口（中等投入）**：优先补 TD3（谱系断裂）、离线 RL、模仿学习、model-based/Dyna、深度探索——这 5 类最能拉升"覆盖全面"评分。
4. **核心锚点卡补白话导语**：152 张 CJK 稀薄微卡中挑 ~10 张核心卡补 1–2 句直觉铺垫（B11 D3）。
