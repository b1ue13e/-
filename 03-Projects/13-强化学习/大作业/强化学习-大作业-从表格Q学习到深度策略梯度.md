# 强化学习-大作业：从表格 Q-Learning 到深度策略梯度

> **目标**：用同一个任务（推荐 `CartPole` 入门、`LunarLander` 进阶、`MuJoCo/HalfCheetah` 挑战）贯穿四种范式，亲手验证「表征能力↑ → 样本效率↑但实现复杂度↑」的权衡，并产出一份可复现的实验报告。本大作业整合阶段 2–7 的全部核心概念。

## 1. ⚙️ 环境与交付形态

- 语言：Python + `gymnasium`（或 `stable-baselines3` 仅用于对照基线）。
- 交付物：一个可运行仓库 + 一份 Markdown 实验报告（含曲线、表格、关停分析）。
- 禁止直接调用 `sb3.PPO` 等黑盒完成核心算法——DQN 与 PPO 需自行实现核心循环（允许用 `torch` 搭网络）。

## 2. 🎯 四阶段阶梯任务（必须全部完成）

| 阶段 | 范式 | 必做 | 验收点 |
| :--- | :--- | :--- | :--- |
| A | 表格 Q-Learning | 离散 CartPole；ε-greedy；学习率/折扣可调 | 能在 500 步内稳定到 200 步满分；画出回报曲线 |
| B | DQN | 卷积/MLP 近似 Q；经验回放；目标网络 | 在 LunarLander 上稳定收敛；对比"有无回放/目标网络"消融 |
| C | REINFORCE / 策略梯度 | 连续或离散；baseline 减方差 | 复现"加 baseline 后方差下降"现象 |
| D | PPO | 自实现裁剪目标 + GAE；多 epoch 更新 | 在连续任务上超越阶段 C；报告 KL/裁剪命中率 |

## 3. 🧪 自动化验证（自测 + 对照）

- 每个阶段提交前跑 3 个随机种子，报告 mean±std（呼应 `RL 评估协议：种子方差与样本效率`）。
- 选一阶段与 `sb3` 官方实现做对照，差距 > 对齐预期时写"差异归因"。
- 必含消融：DQN 去掉经验回放、PPO 去掉 GAE，量化性能衰减。

## 4. 📊 实验报告结构（占分 40%）

1. 问题建模：把任务写成 MDP 五元组（状态/动作/转移/奖励/折扣）。
2. 方法对照：四种范式的贝尔曼/策略梯度公式摘录与你的实现映射。
3. 结果：样本效率、最终回报、训练稳定性的横向对比表。
4. 失败案例分析：至少一个训崩的实验 + 归因（学习率/奖励塑形/探索不足）。
5. 结论：何时用表格、何时用 DQN、何时用 PPO。

## 5. 🃏 Anki 卡片（占分 10%）

至少 8 张卡，覆盖：Q-Learning 更新 vs 策略梯度更新、经验回放为何降相关、目标网络为何稳、GAE 偏差—方差、PPO 裁剪直觉、KL/信任区域。

- **实验严谨性**（25）：多种子、消融、对照齐全。

## 7. 边界与来源

- **边界**：DQN 与 PPO 必须自行实现核心训练循环（网络可用 `torch` 搭）；仅允许用 `stable_baselines3` 提供对照基线，不得用其黑盒完成核心算法。四种范式须在同一任务上横向对比，不得各自换不同环境凑数。

## 9. 常见错误与提示

- **表格 Q-Learning 阶段**：离散 CartPole 的状态必须离散化（分箱），否则 `Q` 表无法索引；ε 过大会导致一直探索不收敛。
- **DQN 阶段**：经验回放容量过小退化为在线学习；目标网络更新过频会让 TD 目标抖动；连续奖励未做缩放会梯度爆炸。
- **REINFORCE 阶段**：未减 baseline 时回报方差大、学习慢；回报未做折扣会导致长轨迹权重失衡。
- **PPO 阶段**：`log_prob_old` 用新策略重算会让 ratio 恒为 1、失去近端约束；GAE 的 `γ` 与更新用的 `γ` 必须一致；连续动作若直接 `argmax` 会失去随机性。
