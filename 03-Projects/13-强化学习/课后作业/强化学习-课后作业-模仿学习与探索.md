## 2. 题目详述（自包含）

### Q1 — BC 损失形式
写出行为克隆的负对数似然损失；它本质是哪类学习问题？

### Q2 — DAgger 滚动聚合
第1轮 BC 在 100 状态上训；第2轮 π_1 跑出 100 新状态（含 40 个 BC 会错的状态），专家标注后 D 变 200；解释错误状态占比如何随轮次下降并收敛。

### Q3 — GAIL 判别器当奖励
GAIL 中判别器 D 如何充当奖励（r = −log D）？与 BC 的根本差异？

### Q4 — RND 内在奖励
新状态 x_new：f=[0.3,0.7], f^=[0.1,0.9] → 误差²=0.08（高奖励）；老状态 x_old：f^≈f=[0.5,0.5] → 误差≈0。说明为何已访问状态的内在奖励会自然衰减。

### Q5 — 最小实现（BC）
用 ≤40 行 numpy 在小型 (s,a) 数据集上用线性模型拟合专家动作（多类/回归），报告训练集精度。

## 5. 环境与 Starter（可直接运行）

> 纯标准库实现。存为 `starter_hw12.py` 后 `python starter_hw12.py`，观察 DAgger 如何把学生策略逐步拉向专家。

```python
import random
random.seed(0)
def expert(state): return 0.6*state[0]+0.4*state[1]
def student(state, theta): return theta*sum(state)/len(state)
theta=0.1; dataset=[]
for rnd in range(5):
    batch=[[random.random(), random.random()] for _ in range(8)]
    for s in batch: dataset.append((s, expert(s)))
    theta=sum(d[1] for d in dataset)/len(dataset)  # 朴素聚合
    print(f"round {rnd}: dataset size={len(dataset)} theta={round(theta,3)}")
```
