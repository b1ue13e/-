## 2. 题目详述（自包含）

### Q1 — 样本效率对比
解释模型基 RL 相比无模型的核心优势；给出一个示意性的样本效率倍数（并说明其依赖的假设）。

### Q2 — Dyna 的 k 步仿真
真实每步后做 k 次模型仿真：共多少次 Q 更新？k=10 时是多少？k 过大为何可能有害（compounding error）？

### Q3 — MuZero vs AlphaZero
二者关键区别是什么？为何 MuZero 不需要已知环境规则？

### Q4 — RSSM 先验与后验
World Model / Dreamer 中先验 p(s_t|·) 与后验 q(s_t|·,o_t) 各自作用？为何要在潜空间做想象？

### Q5 — 最小实现（Dyna 循环）
用 ≤40 行 numpy 实现 Dyna 的"真实更新 + 模型训练 + k 次仿真更新"循环（用随机转移表作为学到的模型）。

## 5. 环境与 Starter（可直接运行）

> 纯标准库实现。存为 `starter_hw11.py` 后 `python starter_hw11.py`，观察学到的 (s,a)->s' 模型误差与模型基想象 rollout。

```python
import random
random.seed(0); dim=2
W=[[0.0]*(dim+1) for _ in range(dim)]  # 含动作偏置项
def model_predict(s,a):
    x=s+[a]; return [sum(W[i][j]*x[j] for j in range(dim+1)) for i in range(dim)]
def train_model(s,a,sp):
    lr=0.1; x=s+[a]; pred=model_predict(s,a)
    for i in range(dim):
        for j in range(dim+1):
            W[i][j]+=lr*(sp[i]-pred[i])*x[j]
def env_step(s,a): return [0.8*s[0]+0.1*a, 0.2*s[1]-0.3*a]
for _ in range(300):
    s=[random.random(), random.random()]; a=random.random(); train_model(s,a,env_step(s,a))
err=0.0; n=50
for _ in range(n):
    s=[random.random(), random.random()]; a=random.random(); sp=env_step(s,a)
    pred=model_predict(s,a); err+=sum((pred[i]-sp[i])**2 for i in range(dim))
print("model (s,a)->s' MSE on test: %.5f"%(err/n))
s0=[0.5,0.5]; traj=[s0]; a=0.1
for _ in range(5): traj.append(model_predict(traj[-1], a))
print("imagined model-based rollout length:", len(traj))
```
