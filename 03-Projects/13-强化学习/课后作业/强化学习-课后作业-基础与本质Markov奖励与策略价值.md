## 2. 环境与最小依赖

- **环境**：纯 Python + `numpy`。无需 gym。
- **策略 → 价值 骨架（题目内给出）**：

```python
import numpy as np

gamma = 0.9
# 2 状态 MDP: s0(起点) 下 a0"前进"->s1(终止,r=+1); a1"停留"->s0(r=0)
# 策略 pi(a0|s0)=0.7, pi(a1|s0)=0.3
pi = np.array([0.7, 0.3])          # [a0, a1] 在 s0
r_go, r_stay = 1.0, 0.0

# 1) Bellman 期望方程求精确 V(s0)
#    V = pi0*(r_go + g*V(s1)) + pi1*(r_stay + g*V(s0)),  V(s1)=0
#    => V = 0.7*1 + 0.3*0.9*V  =>  V = 0.7 / (1 - 0.27)
V_exact = (pi[0] * r_go + pi[1] * r_stay) / (1 - pi[1] * gamma)
print("精确 V(s0) =", round(float(V_exact), 4))

# 2) 蒙特卡洛估计（对照 RL-HW06）：按策略 rollout 取回报均值
rng = np.random.default_rng(0)
returns = []
for _ in range(20000):
    ret, t, s = 0.0, 1.0, 0
    while s == 0:                    # s0: 采动作
        a = 0 if rng.random() < pi[0] else 1
        if a == 0:                   # 前进 -> 终止, r=1
            ret += t * r_go; break
        else:                        # 停留 -> 回 s0, r=0
            ret += t * r_stay; t *= gamma
    returns.append(ret)
print("MC 估计 V(s0) =", round(float(np.mean(returns)), 4))
```

## 3. 题目详述（自包含）

### Q1 — 马尔可夫性质判断
网格世界：agent 需先「按下开关」才能打开通往目标的门。给出两种状态表示：
- (a) `s = (x, y)`（当前格子坐标）
- (b) `s = (x, y, 开关是否已按)`
- 判断 (a) 是否满足马尔可夫性质；给出反例说明 `P(s'|s, a)` 依赖历史；说明 (b) 为何是（近似）Markov。
- 推广：一个「最小充分状态」必须包含哪些信息？

### Q2 — 奖励设计
任务：训练 agent 在网格中**尽快到达目标且不撞墙**。
- 设计奖励：给出 `r_goal`、`r_step`、`r_wall` 的具体数值与符号；说明「稀疏奖励（仅到目标 +1）」与「塑形奖励（每步 −0.1 + 到目标 +10）」的取舍，以及信用分配含义。
- 手算：一条 5 步到达目标的轨迹，在 `γ=1` 下，稀疏回报 = 1；塑形回报 = `4×(−0.1) + 10 = 9.6`。讨论为何塑形奖励能加速学习但可能引入次优偏向。

### Q3 — 策略 → 价值（手算 + 最小实现）
给定 2 状态 MDP（`s0` 起点，`s1` 终止）：`s0` 下 `a0`「前进」到 `s1` 得 `r=+1`；`a1`「停留」回到 `s0` 得 `r=0`。策略 `π(a0|s0)=0.7, π(a1|s0)=0.3`，`γ=0.9`。
- (a) 由 Bellman 期望方程 `V(s0) = 0.7·(1 + 0.9·V(s1)) + 0.3·(0.9·V(s0))`，`V(s1)=0`，手算 `V(s0) = 0.7 / 0.73 ≈ 0.959`。
- (b) 用 Starter 复算精确值并跑 MC 估计对照，二者应都在 ≈0.959 附近。

## 6. 基础要求、必要提示与常见错误

- **必要提示**：Markov 看 `P(s'|s, a)` 是否只依赖 `(s, a)`；奖励设计须考虑信用分配；`V(s)` 是「**策略下**」的期望回报，换策略 `V` 变。
- **常见错误**：① 把需要历史才能决定的状态当 Markov；② 奖励只给终局导致稀疏难学却不提塑形；③ Bellman 期望方程漏掉自环项 `0.3·0.9·V(s0)`；④ 把 `V(s)` 当成与策略无关的量；⑤ MC 估计与精确解量级差很大却不检查（样本不够 / 代码错）。
- **本地断言（Q3 速验）**：

```python
gamma, pi0, pi1, r_go = 0.9, 0.7, 0.3, 1.0
V = (pi0 * r_go) / (1 - pi1 * gamma)
assert abs(V - 0.9589) < 1e-3
```

## 🃏 知识内化卡片

- Q：怎么判断一个状态表示是不是 Markov？
- A：看「下一步只由当前状态 + 动作决定，与更早历史无关」是否成立，即 `P(s'|s, a)` 是否就够了。若某些转移依赖「之前按过开关没」，单看坐标就不够，必须把开关状态并进状态。
- Q：稀疏奖励和塑形奖励怎么选？
- A：稀疏奖励（只在目标给 +1）最贴近真目标、不引入次优偏向，但信用分配难、学得慢；塑形奖励（每步小惩罚 + 到达大奖励）加速学习，但要小心塑形项本身改变最优策略（潜在奖励需满足策略不变性）。
