## 2. 环境与最小依赖

- **环境**：纯 Python，无需 `numpy` / `gym`。
- **交互循环 + 回报 骨架（题目内给出）**：

```python
# 迷你环境：从 s=0 每步 +1，到 s=3 终止；第 k 步奖励 = k
# 一次交互循环：agent 取动作 -> 环境返回 (s', r, done)
class MiniEnv:
    def __init__(self):
        self.s = 0
    def reset(self):
        self.s = 0
        return self.s
    def step(self, a):
        self.s += 1
        r = self.s                      # 第 k 步奖励 = k
        done = (self.s >= 3)
        return self.s, r, done

def rollout(env, policy, max_steps=10):
    s = env.reset(); traj = []; done = False; k = 0
    while not done and k < max_steps:
        a = policy(s)                   # agent 决策
        s2, r, done = env.step(a)       # 环境反馈
        traj.append((s, a, r)); s = s2; k += 1
    return traj

def returns(traj, g):
    G = 0.0; disc = 1.0
    for (_, _, r) in traj:
        G += disc * r; disc *= g
    return G

gamma = 0.9
# 1) Agent-环境交互循环 + 轨迹回报
env = MiniEnv()
traj = rollout(env, lambda s: 0)        # 恒"右"
print("轨迹步数 =", len(traj), " 轨迹 =", traj)
print("无折扣回报 G =", returns(traj, 1.0))
print("折扣回报 G(γ=0.9) =", round(returns(traj, gamma), 4))

# 2) 回合(episode) vs 步(step)
n_eps = 5
tot = sum(len(rollout(MiniEnv(), lambda s: 0)) for _ in range(n_eps))
print(f"{n_eps} 个回合, 总步数 = {tot}  (每回合 {tot // n_eps} 步)")
```

## 3. 题目详述（自包含）

### Q1 — 轨迹回报计算
给定一条轨迹的逐步奖励 `[1, 2, 3]`（共 3 步到终止）。
- (a) 无折扣回报 `G = 1 + 2 + 3 = 6`。
- (b) 折扣回报（`γ=0.9`）`G = 1 + 0.9·2 + 0.9²·3 = 5.23`。
- 用 Starter 复算，二者应分别得到 `6.0` 与 `5.23`。

### Q2 — 回合 vs 步
一个迷宫每回合长度 `3~7` 步随机。跑 `4` 回合：
- 总步数区间是多少？（最小 `12`，最大 `28`）
- 说明「回合（episode）」与「步（step / transition）」的区别：回合是一局从 `reset` 到 `done` 的完整序列；步是**单次** agent 决策 + 环境反馈的交互。

### Q3 — Agent—环境交互循环
写出每一步 `t` 的循环：agent 观察 `s_t` → 按 `π` 选 `a_t` → 环境按动态 `p(s',r|s,a)` 返回 `r_{t+1}, s_{t+1}`。
- 标出：① `π` 在哪一步被使用；② 环境的「动态」`p(s',r|s,a)` 与「奖励函数」`r(s,a)` 分别体现在循环的哪个返回量；③ 轨迹 `τ` 由哪些量组成。

## 6. 基础要求、必要提示与常见错误

- **必要提示**：`G_t = Σ γ^k r_{t+k+1}`；折扣从 `t+1` 步起乘（首步 `γ^0=1`）；回合以 `done=True` 结束。
- **常见错误**：① `G` 漏乘折扣（把折扣回报算成无折扣）；② 折扣幂次错（首步应为 `γ^0=1`）；③ 混淆回合与步（把「4 回合」当「4 步」）；④ 把环境动态 `p` 当成 agent 的 `π`；⑤ 轨迹只写状态、漏掉动作 / 奖励。
- **本地断言（Q1 速验）**：

```python
gamma = 0.9
rewards = [1, 2, 3]
G = sum(gamma ** k * r for k, r in enumerate(rewards))
assert abs(G - 5.23) < 1e-2
```

## 🃏 知识内化卡片

- Q：回合（episode）和步（step）到底差在哪？
- A：步是**一次**交互（agent 出一个动作、环境回一个 `(s', r)`）；回合是从 `reset` 到 `done` 的**整条轨迹**，由若干步组成。统计样本量、设定最大长度时这两个单位极易混。
- Q：折扣回报 `G` 为什么从 `t+1` 步开始乘 `γ`？
- A：`G_t = r_{t+1} + γ r_{t+2} + …`，首步奖励 `r_{t+1}` 是即时回报（`γ^0=1`），之后每推远一步多乘一个 `γ`。`γ` 越小越「近视」，越大越「长远」。
