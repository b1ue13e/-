## 2. 环境与最小依赖

- **环境**：纯 Python（列表/字典即可），或 numpy。无需外部库。
- **自包含小 MDP**（题目内给出，直接可算）：

```
四状态链 A→B→C→D（终止），动作 Right/Left。
P(s'|s,Right): A→B, B→C, C→D 各 1.0；Left 反之（D 终止不再动）。
奖励：每步 −1；到达 D 额外 +10（即 R(C,Right,D)=+10，其余步 −1）。
折扣 γ = 0.9。
```

**价值迭代 Starter（可直接运行，存为 `rl_hw02_mdp.py`）**：

```python
import numpy as np
S = 4  # A=0, B=1, C=2, D=3(终止)
gamma = 0.9

def reward(s, a):
    # 每步 -1；从 C 经 Right 到达 D 额外 +10
    return 10.0 if (a == 0 and s == 2) else -1.0

def nxt(s, a):
    # Right: s->s+1（到 D 停）；Left: s->s-1（到 A 停）
    return min(s + 1, 3) if a == 0 else max(s - 1, 0)

V = np.zeros(S)
for _ in range(300):                      # 同步备份至收敛
    Vn = np.array([
        max(reward(s, 0) + gamma * V[nxt(s, 0)],
            reward(s, 1) + gamma * V[nxt(s, 1)]) for s in range(3)
    ] + [0.0])                            # 终止态 D 的 V 恒为 0
    if np.max(np.abs(Vn - V)) < 1e-9:
        V = Vn; break
    V = Vn
print("v* =", np.round(V, 3))            # 应得 [6.2, 8.0, 10.0, 0.0]
```

## 6. 基础要求、必要提示与常见错误

- **必要提示**：折扣 `γ` 乘在**未来值** `V(s')` 上，当前步奖励 `R` 不打折（除非你的惯例把 R 也写进折扣和，需全文一致）；回报 `G` 与值函数 `V` 不同：`G` 是单条轨迹的，`V(s)` 是期望。
- **常见错误**：① 把 Bellman **最优**备份（max）误用到**策略评估**（应取对 π 的期望 `Σ_a π(a|s) Σ P...`）；② `γ` 错误地套到当前步奖励；③ 价值迭代每轮没**同步**更新（用上一轮 V 全量算新 V，而非边算边用新值）；④ 把终止态 D 的 `V(D)` 当成 0 之外的值（终止态无后续，通常 `V(D)=0` 或含到达奖励）。

## 🃏 知识内化卡片

- Q：策略评估 vs 最优 Bellman 备份，核心区别？
- A：策略评估对给定 π 取**期望** `Σ_a π(a|s) Σ_{s'} P(s'|s,a)[R+γv(s')]`；最优备份取**最大** `max_a Σ_{s'} P(...)`。前者给 `v^π`，后者给 `v*`。
- Q：折扣 γ 作用在哪？
- A：乘在**未来**值 `V(s')` 上，表示越远奖励越不重要；当前步奖励 R 不打折（或按统一约定处理，但需全文一致）。
- Q：为什么说最优值函数唯一？
- A：Bellman 最优算子 `T` 是压缩映射：`‖Tv − Tv'‖∞ ≤ γ‖v − v'‖∞`（γ<1）。压缩映射不动点唯一 ⇒ `v*` 存在且唯一。
