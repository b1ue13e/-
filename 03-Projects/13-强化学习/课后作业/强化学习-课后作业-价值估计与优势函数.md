## 2. 环境与最小依赖

- **环境**：纯 Python + `numpy`。无需 gym。
- **价值估计骨架（题目内给出）**：

```python
import numpy as np

gamma = 0.9
# 给定：从 s=0 出发的两条回合回报（蒙特卡洛样本）
G_samples = [12.0, 4.0]
V = np.array([8.0, 3.0])                 # 当前 V 表：V[0] 初值, V[1] 是 s'

# 1) 蒙特卡洛估计 V(s=0) = 样本平均回报
V_mc = np.mean(G_samples)
print("MC 估计 V(0) =", V_mc)            # 8.0

# 2) 单步 TD(0) 更新：s=0 -> s'=1, r=5
s, r, sp = 0, 5.0, 1
td_target = r + gamma * V[sp]            # 5 + 0.9*3 = 7.7
delta = td_target - V[s]                 # 7.7 - 8 = -0.3
V_new = V.copy(); V_new[s] += 0.1 * delta
print("TD 目标 =", td_target, " δ =", round(delta, 3), " V(0)→", round(float(V_new[0]), 3))

# 3) 优势 A = Q - V（同一 (s,a)），用独立示意的 V(s)=2
V_s = 2.0
Q = np.array([[5.0, 1.0]])               # Q(s=0, a0)=5, a1=1
A = Q - V_s                              # [3, -1]
print("优势 A(0) =", A, "  (0 中心)")
```

## 3. 题目详述（自包含）

### Q1 — 蒙特卡洛估计 V(s)
从 `s` 出发的两条回合回报 `G1=12, G2=4`（γ=1，单步即终止示例）。
- `V_MC(s) = (12+4)/2 = 8`。说明 MC 用「完整回报均值」，无偏但高方差、需走到终止。

### Q2 — TD(0) 估计 V(s)
给定当前 `V` 表 `V(s)=8, V(s')=3`，单步转移 `r=5, γ=0.9`。
- TD 目标 `= r + γV(s') = 5 + 0.9·3 = 7.7`；TD 误差 `δ = 7.7 − 8 = −0.3`；一步更新 `V(s) ← V(s) + αδ`。
- 说明 TD 用「bootstrapping（借 `V(s')`）」可在线单步更新、低方差但略有偏差。

### Q3 — 优势函数 A=Q−V
给定 `V(s)=2, Q(s,a1)=5, Q(s,a2)=1`。
- `A(a1)=5−2=3`，`A(a2)=1−2=−1`。优势以 0 为中心，只表达「相对平均的好坏」。

### Q4 — 最小实现
用 ≤40 行实现：给定回报样本做 MC 估计、给定 `(s, r, s')` 做 TD(0) 更新、给定 `Q` 表算 `A=Q−V`，打印结果对照 Q1–Q3。

## 6. 基础要求、必要提示与常见错误

- **必要提示**：MC 目标 = 完整回报 `G_t`；TD(0) 目标 = `r + γV(s')`；二者都估计 `V(s)` 但偏差—方差不同；`A(s,a)=Q(s,a)−V(s)` 须同一 `(s,a)`。
- **常见错误**：① 把 MC 的 `G` 直接当 TD 目标（TD 用一步 bootstrap 非整条）；② 优势写成 `A=Q+V`；③ TD 误差忘记减 `V(s)`（写成 `r+γV(s')` 漏减）；④ 混淆 `V(s)` 与 `Q(s,a)` 维度；⑤ `γ` 在 MC / TD 中不一致。
- **本地断言（Q2 速验）**：

```python
gamma, r, Vs, Vsp = 0.9, 5.0, 8.0, 3.0
td = r + gamma * Vsp
delta = td - Vs
assert abs(td - 7.7) < 1e-9 and abs(delta + 0.3) < 1e-9
```

## 🃏 知识内化卡片

- Q：蒙特卡洛与 TD(0) 估计 `V(s)` 的根本区别？
- A：MC 用「整条轨迹回报 `G` 的样本均值」——无偏但高方差、必须等到回合结束；TD(0) 用「`r + γV(s')`」做一步 bootstrap——可在线单步更新、低方差但有少许偏差（因为借用了可能不准确的 `V(s')`）。
- Q：为何优势 `A=Q−V` 比直接用 `Q` 好？
- A：`A` 以 0 为中心，只表达「该动作相对状态平均水平的好坏」，消除状态绝对价值的尺度影响，梯度更稳定，且 `E_a[A]=0` 自带基线效果。
