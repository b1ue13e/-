# 🧭 强化学习课程作业总索引

> 本文件是「强化学习」全部作业的**唯一入口**。作业规模只有三层：`lesson`(课后作业) / `stage`(阶段作业) / `capstone`(大作业)。
> 作业—知识关系的事实源是每份作业 frontmatter 的 `requires` 字段；知识卡通过反向查询看到「学完后可以完成」。

## 作业编写标准（2026-08-06 优化后）

- **题面自包含**：每份作业在正文中完整列出各题要求、关键数据与评分点（保留官方题号/公式/数据），无需离开 Obsidian 即可动手；官方 Starter Code 提供获取方式（git/压缩包）。
- **无营销式标签**：已移除历史「4-Tier / Boss / L1–L4 / Simple·Medium·Strong Baseline」等营销命名，改为「基础要求 / 必要提示 / 常见错误 / 可选进阶」的任务结构。
- **统一必填段**：身份与边界 → 环境与 Starter → 题目详述 → 提交产物 → 评分 Rubric → 常见错误与提示 → 可选进阶 → 自检清单 → 来源与后续入口。
- **来源诚实标注**：CS188 P1/P2/P3 为 `official_assignment`（题面翻译自伯克利，CC-BY 课程材料）；HW02 改编自 CS285 HW1/HW2；大作业为 `local_integration_task`（本地融合，独立制定验收）。

## 课程主干与验收源

- 主教材（Spine）：Sutton & Barto, *Reinforcement Learning: An Introduction* (2e, MIT Press) — 覆盖基础、MDP、值函数、TD、策略梯度、Actor-Critic。
- 实践主线（Co-Spine）：OpenAI *Spinning Up* (MIT) — 深度 RL 算法实现（VPG/TRPO/PPO/DDPG/TD3/SAC）。
- 名校作业源：UC Berkeley CS188 (Intro to AI) Projects 2/3（Q-Learning、近似 Q、多智能体搜索）；HW02（DQN+PPO 连续控制）。
- 来源与许可证详见 `02-Knowledge/🧠 学习系统/13-强化学习/📚 教材挂载索引.md`。
