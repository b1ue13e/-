## 详细题目清单

### 题目 1（调和函数平均值公式、Harnack 估计与 Liouville 定理，30分）
设 $\Omega = B_1(0) \subset \mathbb{R}^3$ 为三维单位球，$u \in C^2(B_1(0)) \cap C(\bar{B}_1(0))$ 为非负调和函数，且球心处温度 $u(0) = 1$。
1. **Harnack 不等式与内部界**：应用三维调和函数 Harnack 不等式，对任意 $|x| = r < 1$，成立：
   $$\frac{1 - r}{(1 + r)^2} u(0) \le u(x) \le \frac{1 + r}{(1 - r)^2} u(0)$$
   计算在内球 $B_{1/2}(0)$ 上 $u(x)$ 的严格最大值上界与最小值下界。
2. **Liouville 定理推广证明**：若 $u$ 在全空间 $\mathbb{R}^3$ 上调和，且满足亚线性增长条件：存在常数 $C > 0$ 使得对所有 $x \in \mathbb{R}^3$ 都有 $|u(x)| \le C(1 + |x|^{1/2})$。利用调和函数内部一阶导数先验估计 $|\nabla u(x)| \le \frac{3}{R}\max_{y \in \partial B_R(x)} |u(y)|$，令 $R \to \infty$，证明 $u(x)$ 在全空间必为常数函数。

### 题目 2（三维上半空间镜像法 Green 函数与 Poisson 核推导，35分）
考虑三维上半空间 $\mathbb{R}_+^3 = \{ (x_1, x_2, x_3) \in \mathbb{R}^3 : x_3 > 0 \}$ 上的 Laplace 方程 Dirichlet 边值问题：
$$\begin{cases} \Delta u = 0, & x \in \mathbb{R}_+^3 \\ u(x_1, x_2, 0) = g(x_1, x_2), & (x_1, x_2) \in \mathbb{R}^2 \end{cases}$$
1. **构造镜像点与 Green 函数**：三维基本解为 $\Phi(x) = \frac{1}{4\pi |x|}$。对于源点 $x = (x_1, x_2, x_3)$，其关于底面边界 $y_3 = 0$ 的镜像点为 $\tilde{x} = (x_1, x_2, -x_3)$。写出 Green 函数 $G(x, y) = \Phi(y - x) - \Phi(y - \tilde{x})$ 并验证边界条件 $G(x, y)|_{y_3=0} \equiv 0$。
2. **计算边界外法向导数核（Poisson 核）**：底面边界的外法向量为 $\mathbf{n} = (0, 0, -1)$。计算泊松核：
   $$K(x, y) = -\left.\frac{\partial G}{\partial y_3}\right|_{y_3=0} = \frac{x_3}{2\pi \left[ (x_1 - y_1)^2 + (x_2 - y_2)^2 + x_3^2 \right]^{3/2}}$$
3. **写出半空间泊松积分显式解**：给出解 $u(x_1, x_2, x_3)$ 关于边界数据 $g$ 的二维重积分表示式。

### 题目 3（二维单位圆盘调和函数 Poisson 积分与极大值验证，35分）
在极坐标二维单位圆盘 $D = \{ (r, \theta) : r < 1 \}$ 内求解 $\Delta u = 0$，给定边界条件：
$$u(1, \theta) = \cos^2(\theta) = \frac{1 + \cos(2\theta)}{2}$$
1. **平均值定理求圆心温度**：利用第一平均值定理，直接计算圆心处温度 $u(0, 0) = \fint_{\partial D} u(1, \theta) d\theta$。
2. **分离变量法求全局解析解**：利用极坐标下通解公式 $u(r, \theta) = \frac{a_0}{2} + \sum_{n=1}^\infty r^n (a_n \cos(n\theta) + b_n \sin(n\theta))$，求出各阶系数并写出圆内显式解析解。
3. **极值原理检验**：求出 $u(r, \theta)$ 在闭圆盘 $\bar{D}$ 上的最大值与最小值及其发生点，验证极大值原理。
