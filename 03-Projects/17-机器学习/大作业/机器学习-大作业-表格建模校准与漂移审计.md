# 机器学习 - Capstone：表格建模、校准与漂移审计

> 本大作业是整门课的**综合结课项目**：把前面各阶段学到的回归 / 分类 / 评估 / 异常检测串成一条完整、可复现、可解释的表格数据流水线。它不是某一份官方 HW 的放大版，而是本地融合任务（`local_integration_task`）。

## 1. 布置时机

- 建议在所有阶段作业（阶段作业 01–05）完成后再布置；
- 是 `assignment_level: capstone`，归入 `大作业/`；
- 目标不是“刷最高分”，而是证明你能独立交付一条生产可用的表格建模流水线。

## 2. 任务背景与边界

给定一份真实或接近真实的表格数据集（分类或回归），完成：

```
数据清洗 → 特征工程 → 模型选择与调参 → 校准 → 可解释性 → 数据漂移检查
```

- **输入**：结构化表格（数值 + 类别特征），允许含缺失值、异常值与分布偏移；
- **输出**：可部署的模型 + 校准曲线 + 解释报告 + 漂移审计报告；
- **禁止**：使用测试集统计量做训练期标准化；直接提交未校准的概率当作置信度；
- **不要求**：必须冲 SOTA；应优先保证流程完整、可复现、可解释。

## 3. 学习目标

完成本作业后，应该能做到：

1. 建立可复现的朴素基线，并说明为何先有基线；
2. 完成特征工程、验证切分与调参，且有对照实验；
3. 对模型输出做概率校准（如 Platt / Isotonic）；
4. 用 SHAP / 置换重要性给出可解释性说明；
5. 检测训练—服务之间的数据漂移，并给出处置建议。

## 5. 详细任务与里程碑

| 里程碑 | 任务 | 必交证据 |
| :---: | :--- | :--- |
| M1 基线 | 数据探查、清洗、朴素基线（线性/树） | 探查报告、基线分数 |
| M2 特征与调参 | 编码、标准化、特征选择、调参对照 | 实验表、最佳配置 |

## 9. 引导与自检

- 不做基线直接上复杂模型 → 先补 M1；
- 只看准确率不看校准 → 检查 Reliability Curve；
- 解释图与业务无关 → 回到 M4 定位关键特征；
- 漂移报告只剩“有偏移”无建议 → 补处置方案。
