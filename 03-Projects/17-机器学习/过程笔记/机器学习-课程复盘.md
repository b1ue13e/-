# 课程复盘

## 用途

在走完全部五个阶段（基础概念 → 线性模型 → 正则优化 → 树与集成 → 其他方法）之后，做一次横向串联与自查。本卡不教新算法，而是把你学过的模型放进「问题—方法—评估—局限」的统一框架里，找出薄弱阶段并决定下一步补强。它和「[[机器学习-代码实践]]」「[[机器学习-项目实践]]」互补：代码练单点能力，项目练综合串联，复盘负责「把地图拼完整」。

## 五阶段主线串联

- **阶段1 基础概念**：用「假设空间 + 归纳偏好 + 泛化」这套语言贯穿全课；任何模型都能回到「它在哪个假设空间里、偏好什么、怎么评估泛化」。
- **阶段2 线性模型**：回归与分类的统一视角（最小二乘 / 对数几率 / 判别函数）；为后续所有带参数的模型奠定「经验风险最小化」直觉。
- **阶段3 正则优化**：把「训练」本身变成研究对象——梯度、BP、L1/L2、稀疏与泛化理论（VC 维 / PAC）。这是「会用模型」升级为「理解训练」的关键。
- **阶段4 树与集成**：非参数 / 分段常数假设空间，以及 Bagging/Boosting 的组合策略；工程上最常用的一族。
- **阶段5 其他方法**：SVM/核、贝叶斯、聚类、降维，以及半监督/概率图/强化等扩展入口；按问题类型灵活取用。

## 复盘自检（通过标准）

完成复盘意味着你能做到：

- [ ] 对任意一个学过的模型，说出它的假设空间、损失函数、优化方式与典型失败模式。
- [ ] 给一个新问题，能列出 2–3 个候选模型并说明为什么选 / 不选。
- [ ] 解释过拟合与欠拟合在五个阶段里分别以什么形式出现、各自怎么治。
- [ ] 把课程作业（课后 / 阶段 / 大作业）对应回它考察的阶段与知识点。
- [ ] 指出自己最弱的阶段，并给出补强计划（重读哪些卡、补做哪份作业）。

## 常见误区

- 只记公式不回假设空间：遇到新模型就不会归类。
- 把阶段割裂：线性模型与树模型其实是同一「假设空间—损失—优化」框架下的不同选择。
- 复盘变成抄目录：没有「我最弱在哪、下一步做什么」的产出，等于没复盘。
