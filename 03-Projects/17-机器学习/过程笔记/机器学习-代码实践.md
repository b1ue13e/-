# 代码实践

## 用途

沉淀机器学习「动手写代码」的学习方法。代码是把抽象算法落地的唯一途径：能跑通、能复现、能改对，才算真懂。本卡不教具体算法，而是教如何用代码把算法吃透——它和「[[机器学习-项目实践]]」互补，前者练单点能力，后者练综合串联。

## 核心原则

- **先跑通，再改写**：拿到参考实现先原样跑通，确认环境与数据无误，再尝试改动，避免「改着改着不知道哪错了」。
- **最小可复现**：用 10～100 条样本的小数据集验证主流程，比直接上全量更快定位 bug。
- **对照权威来源复现**：以周志华《机器学习》、Hands-on ML、MML 的代码 / 公式为准，复现后和原结果对拍误差。
- **为关键函数写最小测试**：对损失计算、梯度等核心函数写几个断言，防止数值错误静默通过。
- **读懂胜于抄**：理解每一行为什么这么写，比复制粘贴收获大一个量级。

## 推荐工作流

1. 明确目标：要复现哪个算法、解决哪类问题。
2. 准备玩具数据：造或截取极小数据集。
3. 实现核心：先写前向 / 损失 / 单步更新，再逐步加训练循环。
4. 对拍验证：与 sklearn / 教材结果对比，误差是否可接受。
5. 改写与调参：换数据、改超参、加正则，观察现象变化。
6. 沉淀笔记：把踩过的坑与「为什么」写进对应知识卡，而不是只留在 notebook 里。

## 常见误区

- 只跑 notebook 不写函数，导致无法复用与测试。
- 直接上全量数据，报错后难以定位根因。
- 过度依赖框架却不理解底层，遇到诡异 bug 时无能为力。
