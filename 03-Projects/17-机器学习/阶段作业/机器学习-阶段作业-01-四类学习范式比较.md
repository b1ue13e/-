# 阶段作业 01 · 四类学习范式比较（主观题）

## 1. 作业身份

- 课程：机器学习（周志华主线）
- 规模 / 形态：`stage` / `quiz`（主观简述题）
- 所属阶段：第一阶段 基础概念
- 来源：本地融合任务（对齐教材第 1 章「学习任务的分类」），非名校官方作业
- 许可证：`[待验证]`（教材为商业出版物，仅内部练习）

## 2. 学习目标

完成后能用自己的话区分**监督 / 无监督 / 半监督 / 强化**四类学习范式，并针对一个具体场景判断其所属范式与关键差异。

## 3. 所需知识（`requires`）

- [[机器学习-监督学习]]：带标签数据、从经验到模型
- [[机器学习-无监督学习]]：无标签、发现内在结构
- [[机器学习-半监督与强化学习]]：少量标签 + 环境交互回报

## 4. 任务背景与边界

给定下面 4 个应用片段，请逐条判断其学习范式，并写出「数据是否有标签 / 目标是什么 / 典型算法」三要素：

1. 用 1 万张已标注「猫 / 狗」的图片训练分类器。
2. 对 10 万条无标签用户行为做分群，发现 5 类人群。
3. 仅有 100 张标注样本 + 9000 张无标注样本，训练一个可用模型。
4. _agent_ 在迷宫中每走一步获得「+1 / -1」奖励，逐步学会最短路径策略。

## 5. 详细题目（稳定题号）

- **Q1**：为上述 4 个片段分别标注范式（监督 / 无监督 / 半监督 / 强化）。
- **Q2**：用一页以内说明「监督 vs 无监督」在「数据、目标、评估方式」三处最根本的区别。
- **Q3**：举一个你身边的例子，它同时属于「半监督」与「强化学习」的混合设定，并解释为什么两类信号都存在。

## 6. 环境与复现

- 无需代码；纯文字作答。建议在 [[机器学习-机器学习概述]] 与三类范式卡片通读后独立完成。

## 7. 提交产物

- 一份 Markdown / 文档，包含 4 个片段的范式判定表 + Q2 对比 + Q3 举例。

## 8. 验收标准与 Rubric

| 维度 | 合格（≥60%） | 优秀（≥85%） |
| :--- | :--- | :--- |
| 范式判定 | 4/4 判定正确 | 判定正确且能指出易混边界（如半监督与监督） |
| 对比深度 | 列出三要素 | 能说明「无标签时如何定义目标函数」 |
| 举例 | 有一个合理例子 | 例子真实、能区分两类信号来源 |

## 9. 引导与自检（不泄露答案）

- 检查点：先问自己「有没有 y？」再问「y 从哪来？」。
- 常见失败：把「强化学习」误判为「无监督」（关键区别在是否有环境回报信号）。
- 提交前：确认每段都写了「数据 / 目标 / 算法」三要素。
