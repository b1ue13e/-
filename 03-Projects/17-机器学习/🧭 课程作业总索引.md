# 🧭 机器学习 · 课程作业总索引

> 本页是 `03-Projects/17-机器学习` 下全部**正课程验收作业**的单一入口。作业按规模层级分三类（目录即层级，不新增第四种）。每份作业以文件 frontmatter 的 `assignment_level`、`stage_id`、`requires` 为准；本页只提供派生视图，不复制静态映射。

## 使用顺序

1. 从 [[🗺️ 机器学习学习路径|课程学习路径]] 进入当前阶段。
2. 阶段 MOC 给出有序知识卡；完成对应课后/阶段作业并通过 Rubric 后再前进。
3. 答案不进入活动目录；保存自己的作答、运行证据、失败记录与订正。
4. `planned / ongoing` 只表示规格可用，不表示任务已执行或得到分数。

## 统一通过口径

- 课后/阶段作业：总分至少 80/100，且没有来源、泄漏、复现或依赖硬失败。
- 大作业：总分至少 85/100，最终测试段只在协议冻结后使用一次。
- 任一代码结果必须附环境、命令、随机种子与真实输出；未运行不得标记 `completed`。

## 与知识卡的关系（单一事实源）

- 作业依赖：**只**在作业 frontmatter 维护 `requires`；知识卡**不**手工反向维护作业列表（由 Dataview 反向查询生成「学完后可以完成」）。
- 验收闭环：学完某阶段知识卡 → 完成对应 `阶段作业` → 通过 Rubric → 进入下一阶段。
- 所有作业禁止出现 `李宏毅式 / 4-Tier / Boss Baseline / 阶梯作业` 等历史改编标签；难度递进写作「基础 / 进阶 / 综合」。
