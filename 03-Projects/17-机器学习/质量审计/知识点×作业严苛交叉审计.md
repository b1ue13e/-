## 1. 审计口径与评分框架

### 1.1 卡级「作业可练度」（回答 Q1）
以作业 `requires` 是否直接点名该卡为唯一判据：
- **A（有精准练习）**：≥1 份主线作业 `requires` 直接点名 → 学完该卡即有对应作业可练。
- **B（间接/阶段）**：仅所在阶段 `stage` 作业整体覆盖（本次为 0，因 stage 作业也已显式枚举卡）。
- **C（无任何练习）**：无任何作业引用 → 学完无练。

### 1.2 作业级「名校开源度」（回答 Q2）
- **S**：逐题转载/对齐某名校公开课程作业（Stanford CS229/231n、MIT 6.036、Berkeley CS189、CMU 10-701、NTU 李宏毅等），有清晰 license 与来源页。
- **A**：名校教材/MOOC 官方配套练习（清晰 license）。
- **B**：本地融合任务（`local_integration_task`，参考教材自编，**非名校 HW**）。
- **C**：占位/无真实数据 Starter。

### 1.3 覆盖性（回答 Q3）
对照周志华《机器学习》经典 ML 五阶段 + 前置，评估广度与闭环完整性。

### 2.3 Q3：知识点覆盖全面吗？

**广度：对经典 ML 五阶段基本全面。**
- 72 张卡映射周志华《机器学习》主线章节：基础概念(13)、线性模型(7)、正则优化(12)、树与集成(13)、其他方法(25)、前置(2)。
- 五阶段核心算法（线性回归/逻辑回归/SVM/决策树/随机森林/XGBoost/聚类/PCA/贝叶斯/EM）均有卡 + 对应作业，闭环完整。

**结构性缺口（严苛视角）：**

1. **深度学习无正式阶段**：`神经网络`/`反向传播算法`/`深度学习入门` 挂在"正则优化"下，但**无 DL 阶段、无主线 DL 作业**。它们只能靠降级的 DL 参考分支练习 → 主线闭环断裂。
2. **概率图模型 / 半监督 / 强化学习薄且无正式练习**：`概率图模型入门`(45行)、`半监督与强化学习`(79行) 是 C 级零练习卡；RL 部分仅有 `DQN`/`策略梯度`/`Q-Learning`(重定向页)，无阶段作业。
3. **数学前置无练习**：`线性代数基础`(208行)/`概率统计基础`(125行) 是 C 级零练习卡——作为前置应至少配计算/证明练习。
4. **背景卡缺检索练习**：`机器学习概述`(371行)/`监督学习`(480行)/`无监督学习` 等大卡无作业，仅靠卡片内"检索练习"小节支撑（此前审计已指出形成性练习体系未系统化）。

> **答 Q3：经典 ML 五阶段覆盖"基本全面"；现代 ML（DL/RL/PGM）与工程闭环"不全面"。** 若目标是"吃透周志华经典 ML"，达标；若目标是"对标名校 ML 课程（含 DL 与公开课作业）"，远未达标。
