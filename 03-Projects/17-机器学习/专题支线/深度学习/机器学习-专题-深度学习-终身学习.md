# 机器学习 · 深度学习专题（可选参考）：Life-Long Learning 终身学习

> 这份作业的重点不是在单个任务上做到最好，而是观察模型在连续任务中为什么会忘、能不能少忘、什么方法更稳。

## 1. 布置时机

- 建议在学完以下内容后布置：
  - 多任务学习或连续任务设定
  - 基本深度学习训练
  - 泛化与过拟合概念
- 最好在学生已经有多次模型训练经验之后布置。

## 2. 前置知识

开始前，学生应该已经会：

1. 理解任务序列和单任务训练的区别。
2. 知道 catastrophic forgetting 是什么。
3. 会记录 task-by-task 结果。
4. 理解 replay 和 regularization 的大致思路。

## 3. 任务背景

你需要让模型连续学习多个任务，并尽量减少旧任务性能下降。

这份作业训练的是：

- 顺序任务训练
- 遗忘量化
- replay 与正则化比较
- 多任务表现记录

## 4. 学习目标

完成后，应该能做到：

1. 观察并量化遗忘现象。
2. 跑通一种缓解遗忘的方法。
3. 比较 replay 和 regularization。
4. 用 task-by-task 表说明问题。

## 9. 分阶段完成要求

### 第一阶段：先跑通

- 跑顺序训练 baseline
- 记录每个任务后的历史任务表现
- 看清遗忘现象

### 第二阶段：再改进

- 加 replay
- 加 EWC / LwF / SI
- 比较不同方法

### 第三阶段：最后解释

- 比较不同任务顺序
- 解释哪些任务最容易被忘
- 总结最稳方法

## 10. 建议实施步骤

1. 先建立无防遗忘 baseline。
2. 记录 task-by-task 表。
3. 再加入 replay。
4. 然后尝试正则化方法。
5. 最后比较顺序和 buffer 大小。

## 11. 引导与自检

- 没记录 task-by-task 表。
- 任务顺序变了却没写清楚。
- replay buffer 太小没效果。
- 正则化方法实现错却没排查。
- 只看最终任务，不看历史任务回落。
