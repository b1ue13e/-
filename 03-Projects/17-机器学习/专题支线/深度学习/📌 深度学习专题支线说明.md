## 命名约定（供审计登记）

- `assignment_id` 采用 `机器学习-DL-01 .. 机器学习-DL-14`，独立于主线程的 `机器学习-01..09`（课后）、`机器学习-阶段作业-01..05`、`机器学习-capstone`，避免编号冲突。
- `stage_id` 统一为 `专题`，明确标识这些作业位于五阶段主线之外（非 01–05 任一阶段）。
- `assignment_level` 按规模二分：`lesson` 为单一模型聚焦型（CNN / 自注意力 / Transformer / GAN / BERT / 自编码器 / 图神经网络，共 7 份）；`stage` 为系统级或多组件综合型（强化学习 / 元学习 / 模型压缩 / 终身学习 / 对抗攻击 / 可解释性 XAI / 领域自适应，共 7 份）——后者涉及训练循环、流水线或评测协议等多模块整合，故归为 stage 规模。
- 二者均为本支线内部登记约定：主线程 Dataview 按 `课后作业/阶段作业/大作业` 三固定目录查询，不会纳入；知识卡反向查询已加 `type = "project"` 过滤，亦不会混入主线「学完后可以完成」。
