# 机器学习 · 深度学习专题（可选参考）：Autoencoder 自编码器

> 这份作业会把“会做监督学习”往前推一步，进入表示学习和异常检测。重点不是把重建损失降到最低，而是理解 latent 表示到底学到了什么。

## 1. 布置时机

- 建议在学完以下内容后布置：
  - 表示学习基本概念
  - 降维与重建
  - PCA 直觉
  - 异常检测基本思路
- 最好在学生已经做过至少一个图像或特征任务之后布置。

## 2. 前置知识

开始前，学生应该已经会：

1. 理解输入和重建目标的关系。
2. 理解 latent representation 的基本直觉。
3. 知道 reconstruction error 可以用来做什么。
4. 会看输入 / 重建对照图。

## 3. 任务背景

你需要通过压缩再重建来学习表示，并把重建误差用于异常检测或表示分析。

这份作业训练的是：

- 无监督表示学习
- latent 维度设计
- 重建质量判断
- 阈值选择与异常检测

## 4. 学习目标

完成后，应该能做到：

1. 跑通基础 autoencoder。
2. 解释 latent dim 改变的影响。
3. 比较普通 AE 和变体 AE。
4. 用 reconstruction error 做基本异常检测。

## 9. 分阶段完成要求

### 第一阶段：先跑通

- 跑通基础 AE
- 保存输入 / 重建图
- 生成初始异常分数

### 第二阶段：再改进

- 调 latent dim
- 比较 AE 变体
- 改善重建效果

### 第三阶段：最后解释

- 看 error distribution
- 分析异常样本
- 解释 latent 学到的结构

## 10. 建议实施步骤

1. 先固定输入预处理方式。
2. 跑通一个最小 AE。
3. 保存重建样本，不只看 loss。
4. 调 latent dim 和模型深度。
5. 最后再尝试 VAE、denoising AE 或 sparse AE。

## 11. 引导与自检

- 输入没归一化。
- 只看 loss，不看重建图。
- latent dim 过大导致模型只是记忆。
- 阈值凭感觉设定。
- 不同变体损失定义混用。
