# 机器学习 · 深度学习专题（可选参考）：Meta Learning 元学习

> 这份作业是整门课的高阶收束。它不再要求模型在一个固定任务上越训越强，而是要求模型学会“更快适应新任务”，这和前面所有作业都不完全一样。

## 1. 布置时机

- 建议在学完以下内容后布置：
  - few-shot 学习基本概念
  - episodic training
  - 表征学习与泛化
  - 基本优化直觉
- 最好放在整门课最后。

## 2. 前置知识

开始前，学生应该已经会：

1. 理解 support / query 的区别。
2. 知道 few-shot baseline 是什么。
3. 了解 ProtoNet 或 MAML 的基本思路。
4. 会比较不同 `N-way K-shot` 设定。

## 3. 任务背景

你需要让模型在很少样本的新任务上快速适应。

这份作业训练的是：

- few-shot 任务组织
- episodic training
- baseline 与 meta 方法比较
- 不同 way / shot 下的泛化分析

## 4. 学习目标

完成后，应该能做到：

1. 跑通一个 few-shot baseline。
2. 跑通一种 meta learning 方法。
3. 比较不同 way / shot 设定。
4. 解释 meta 方法为什么更快适应。

## 6. 数据说明

### 数据类型

- 输入：episode 形式的任务样本
- 输出：few-shot 分类结果
- 任务类型：元学习 / few-shot 泛化

### 你至少要先弄清楚

1. `N-way K-shot` 是如何定义的。
2. support / query 如何划分。
3. 训练和验证 episode 是否同口径。
4. baseline 和 meta 方法是否公平比较。
5. unseen classes 是否单独测试。

## 8. 验收标准与 Rubric
> **最低通过门槛**：满足 Rubric「基础完成度」全部要求且结果可复现（附环境 / 命令 / 随机种子），即视为通过；总分 ≥ 80/100 为良好。

## 9. 分阶段完成要求

### 第一阶段：先跑通

- 跑一个 few-shot baseline
- 固定 episode 采样规则
- 生成首个结果表

### 第二阶段：再改进

- 跑 ProtoNet 或 MAML
- 比较不同 way / shot
- 比较 unseen classes 表现

### 第三阶段：最后解释

- 分析失败 episode
- 总结 meta 增益来自哪里
- 解释哪个设定最难

## 10. 建议实施步骤

1. 先写清 support / query 采样逻辑。
2. 先跑一个简单 baseline。
3. 再跑一种 meta 方法。
4. 对比多个 `way-shot` 设定。
5. 挑失败 episode 做分析。

## 11. 引导与自检

- 训练和验证 episode 口径不一致。
- support / query 划分写错。
- few-shot baseline 太弱，比较不公平。
- 只记一个 `way-shot` 设定。
- 中间最好模型没保存。
