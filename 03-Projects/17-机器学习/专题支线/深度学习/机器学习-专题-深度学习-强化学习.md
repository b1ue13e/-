# 机器学习 · 深度学习专题（可选参考）：Reinforcement Learning 强化学习

> 这份作业第一次把“看静态数据训练模型”切换成“和环境交互学习”。真正的难点不是把代码写出来，而是学会判断一个策略到底是真的变强了，还是只是单次 lucky run。

## 1. 布置时机

- 建议在学完以下内容后布置：
  - MDP 基本概念
  - policy gradient 或 DQN
  - exploration 和 reward
  - 训练方差问题
- 不建议在学生还没有基本实验记录习惯前布置。

## 2. 前置知识

开始前，学生应该已经会：

1. 理解状态、动作、回报、策略。
2. 知道单次 reward 曲线不能直接说明问题。
3. 会记录随机种子和环境版本。
4. 理解评估和训练不是一回事。

## 3. 任务背景

你需要训练 agent 与环境交互，并让总回报提升。

这份作业训练的是：

- 环境交互闭环
- reward 曲线分析
- 训练稳定性
- 多 seed 评估意识

## 4. 学习目标

完成后，应该能做到：

1. 跑通一个基础 RL agent。
2. 判断训练震荡和收敛情况。
3. 比较不同算法或稳定化技巧。
4. 用多次实验而不是单次结果下结论。

## 9. 分阶段完成要求

### 第一阶段：先跑通

- 跑通一个基础 agent
- 记录第一条 reward 曲线
- 完成单次评估

### 第二阶段：再改进

- replay / target network / advantage
- 比较另一种算法
- 做多 seed

### 第三阶段：最后解释

- 解释震荡或 collapse
- 比较不同 seed
- 总结最有效技巧

## 10. 建议实施步骤

1. 先固定环境版本。
2. 跑一个最小 agent。
3. 记录 reward 曲线。
4. 再加稳定化技巧。
5. 至少做 3 个 seed 对照。

## 11. 引导与自检

- 环境版本不一致。
- 只看单次最优结果。
- 训练回报和评估回报混在一起。
- replay 或 target update 写错。
- 没保存中间最优 checkpoint。
