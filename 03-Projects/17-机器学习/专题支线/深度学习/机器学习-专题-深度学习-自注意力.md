# 机器学习 · 深度学习专题（可选参考）：Self-Attention 自注意力

> 这份作业不是让你记住 attention 公式，而是让你第一次真正感受到“序列中的每个位置都可以和别的位置交互”会带来什么表达能力。

## 1. 布置时机

- 建议在学完以下内容后布置：
  - RNN 的局限
  - Q / K / V 的基本含义
  - multi-head attention
  - 残差与 layer norm
- 最好在 CNN 作业之后、Transformer 作业之前布置。

## 2. 前置知识

开始前，学生应该已经会：

1. 理解序列数据和图像数据的区别。
2. 知道 mask 在序列任务中的作用。
3. 会用 batch 组织不等长序列。
4. 会看训练和验证曲线。

## 3. 任务背景

你需要对序列进行分类或表征。  
官方常见题型可以类比为：`Speaker Classification`。

这份作业训练的是：

- 序列输入组织
- attention block 的搭建
- pooling / 长度策略选择
- attention 模型与传统结构的比较

## 4. 学习目标

完成后，应该能做到：

1. 跑通基本 attention encoder。
2. 理解 sequence length、head 数、hidden size 会如何影响训练。
3. 看懂 padding mask 为什么必要。
4. 用简单消融说明模型结构选择。

## 9. 分阶段完成要求

### 第一阶段：先跑通

- 正确读取变长序列
- 跑通最小 attention 模型
- 生成首个验证结果

### 第二阶段：再改进

- 比较 pooling
- 调整 head / hidden size
- 稳定训练

### 第三阶段：最后解释

- 做简单消融
- 记录 hardest sequences
- 写出结构选择理由

## 10. 建议实施步骤

1. 先确保 padding 和 mask 正确。
2. 先用单层模型跑通。
3. 再增加 heads、残差、layer norm。
4. 控制变量做 pooling 对照。
5. 保存最佳结果和配置。

## 11. 引导与自检

- 忘记处理 padding mask。
- 训练和推理切块方式不一致。
- 标签映射没固定。
- hidden size 一味增大导致显存爆掉。
- 只会调分，不做结构对照。
