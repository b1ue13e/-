# 机器学习 · 深度学习专题（可选参考）：GCN 与 GraphSAGE 节点分类

> 🎯 **作业目标**：手写 Node2Vec 生成节点嵌入、手写 Message Passing 消息传递机制、在 PyG 中实现 GCN 与 GraphSAGE 完成 Cora 数据集分类。

## 1. 布置时机

- 建议在学完 **神经网络** 与 **概率图模型入门** 后布置。
- 本作业属于图数据专题，不在前五阶段主线上，作为深度学习扩展专题，可放在阶段作业之后选做。

## 2. 前置知识

开始前，学生应该已经会：

1. 理解神经网络的前向传播与反向传播，能手写单层矩阵乘法。
2. 了解概率图模型的基本概念（节点、边、条件独立性、消息传递直觉）。
3. 会用 PyTorch 基础张量操作（`torch.randn`、`matmul`、`@`）。
4. 知道训练 / 验证 / 测试划分与随机种子的基本作用。

## 3. 任务背景

给定一张带节点属性与边的图（如引文网络、社交网络、分子图），目标是为其中未标注类别的节点预测离散标签（节点分类）。

- **输入**：节点特征矩阵 $X\in\mathbb{R}^{N\times d}$、邻接 / 边索引、部分节点的训练标签、可选的节点划分掩码。
- **输出**：所有（或测试集）节点的类别预测，以及对应的评估指标。
- **假设**：图中相连节点倾向具有相似标签（同质性 homophily）；特征已归一化、边已去重、标签无系统性错标。
- **限制与禁止事项**：禁止在训练 / 验证时偷看测试节点标签（标签泄露）；禁止用未来信息或全局标签构造边；提交须包含可复现的随机种子与划分脚本，且测试指标只能由预留测试掩码计算。

## 4. 学习目标

完成本作业后，应该能做到：

1. 解释图卷积的对称归一化矩阵为何是 $\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$；
2. 手写 Node2Vec 与单层 GCN 的前向传播；
3. 在 PyG 中实现 GraphSAGE / GAT 并完成节点分类；
4. 用自动化测试验证层形状与消息传递正确性。

| 难度级别 | 目标 Cora Acc | 关键实现细节与要求 |

## 11. 引导与自检

- 邻接矩阵未加自环，导致节点看不到自身特征；
- 对称归一化写错为 $\tilde{D}^{-1}\tilde{A}$，多层堆叠后特征数值爆炸；
- 度为零节点出现除零，需对 $\tilde{D}$ 做伪逆或加平滑；
- PyG 的 `Data` 对象与手写 NumPy 邻接矩阵混用导致维度对不齐。

```python
import pytest
import torch

def test_gcn_layer_forward_shape():
    from gnn_layers import GCNConvManual
    conv = GCNConvManual(in_channels=16, out_channels=32)

    x = torch.randn(100, 16)
    adj = torch.eye(100)  # 恒等邻接矩阵
    out = conv(x, adj)

    assert out.shape == (100, 32), "GCN 输出 Shape 必须为 (num_nodes, out_channels)"
```
