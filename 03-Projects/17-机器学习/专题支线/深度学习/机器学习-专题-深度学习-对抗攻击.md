# 机器学习 · 深度学习专题（可选参考）：Adversarial Attack 对抗攻击

> 这份作业真正要训练的不是“把模型搞坏”，而是让你第一次系统地意识到：一个看起来分数不错的模型，可能在非常小的扰动下就失效。

## 1. 布置时机

- 建议在学完以下内容后布置：
  - 成熟图像分类模型
  - 梯度反向传播
  - 模型泛化与鲁棒性基本概念
- 最好在 `HW09 Explainable AI` 前后衔接布置。

## 2. 前置知识

开始前，学生应该已经会：

1. 固定一个可复现的分类模型。
2. 理解输入梯度的含义。
3. 知道 epsilon 不是随便拍脑袋选的。
4. 会对比干净样本和攻击样本。

## 3. 任务背景

你需要通过小扰动让模型犯错，并比较不同攻击和防御方案。

这份作业训练的是：

- 构造对抗样本
- 比较攻击强度
- 理解鲁棒性与精度的取舍
- 用曲线和样例而不是口头判断鲁棒性

## 4. 学习目标

完成后，应该能做到：

1. 跑通基础攻击方法。
2. 比较 FGSM 和更强攻击。
3. 画 epsilon 曲线。
4. 判断简单防御是否值得。

## 6. 数据说明

### 数据类型

- 输入：干净样本与扰动样本
- 输出：攻击前后预测结果
- 任务类型：鲁棒性分析任务

### 你至少要先弄清楚

1. epsilon 的尺度对应哪个输入空间。
2. 归一化是在攻击前还是攻击后。
3. 攻击是否限制在感知上微小扰动。
4. 成功率如何计算。
5. 防御后干净样本精度掉了多少。

## 9. 分阶段完成要求

### 第一阶段：先跑通

- 跑通 FGSM
- 保存攻击成功样本
- 记录首个成功率

### 第二阶段：再改进

- 比较更强攻击
- 画 epsilon 曲线
- 尝试简单防御

### 第三阶段：最后解释

- 比较干净精度和鲁棒精度
- 分析最脆弱样本
- 说明哪种防御值得保留

## 10. 建议实施步骤

1. 先固定目标模型和样本子集。
2. 跑通 FGSM。
3. 逐步扩大 epsilon。
4. 再加 PGD 或 iterative 攻击。
5. 最后做一个简单防御对照。

## 11. 引导与自检

- epsilon 和归一化空间不一致。
- 攻击前没有打开梯度。
- 只看成功率，不看图像是否已经肉眼失真。
- 防御后忘了看干净样本精度。
- 不固定模型版本和数据子集。
