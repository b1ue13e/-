# 应用回归分析课后作业 01：OLS 估计与推断

## 学习目标

- 从设计矩阵推导 OLS 解并检查维度。
- 区分系数、标准误、置信区间和预测区间。
- 用手算和软件结果互相校验，而不是只粘贴 summary。

## 任务边界

使用前置卡中的三点小样本，或自行给出一个 $n\ge 5$、含截距和两个解释变量的小数据。不得直接调用库函数替代第 1 题推导。

若使用自拟数据，必须让设计矩阵满列秩，并在提交中写出完整数值。主任务只处理经典同方差 OLS；HC3、WLS 和变量选择留到阶段 2，不得用后续方法绕开当前推导。

## 题目

### 1. 矩阵推导

1. 写出 $X^TX$、$X^Ty$ 与 $\hat\beta$。
2. 计算拟合值和残差，验证 $X^Te=0$。
3. 说明满列秩失败时哪个步骤失效。
4. 给出函数接口 `ols_closed_form(X, y) -> beta, fitted, residual`，并用手算数据做断言。

### 2. 推断

1. 写出 $\hat\sigma^2$ 和 $\operatorname{Var}(\hat\beta\mid X)$。
2. 对一个预先指定系数构造 95% 置信区间。
3. 写出一个联合零假设，并说明为什么使用 F 检验。
4. 分别写出 t 统计量和 F 统计量的自由度；指出何时二者检验同一单参数限制。

### 3. 软件复核

用 statsmodels 复核系数、标准误和 F 检验。再选择一个新 $x_0$，同时报告均值响应置信区间和新观测预测区间，并解释宽度差异。

### 4. 反例与边界

构造一个完全共线的小数据，使闭式逆矩阵失败。说明软件可能采取报错、广义逆或自动删列中的哪种行为；不能只粘贴错误信息。再构造一个残差明显非正态但样本量较大的例子，解释正态性与 OLS 无偏性的关系。

## 环境

- Python 3.11
- numpy、pandas、statsmodels
- 固定随机种子 42；若使用自拟确定性数据则说明无需随机种子。
- 运行命令：`python solution.py`；退出码必须为 0。
- 最小测试：系数与手算容差 `1e-8`，残差正交性容差 `1e-10`。

## 提交产物

- derivation.md：完整手算与条件说明。
- solution.py 或 solution.ipynb：可重复运行。
- result.md：不超过 800 字，解释推断结果和一个限制。

## 渐进提示

1. 先检查每个矩阵乘法的维度。
2. 若结果与软件不同，检查截距列和自由度。
3. 预测区间应额外包含未来误差方差。
4. 完全共线时先检查秩，不要用增加正则化冒充 OLS 闭式解。

## 常见失败

- 把 $X^TX$ 可逆写成数据服从正态分布。
- 忘记截距列，导致残差和不为零。
- 使用总体方差分母而不是残差自由度。
- 只比较系数，不核对标准误和区间。
- 把显著系数描述为高预测贡献或因果效应。
