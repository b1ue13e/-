# 应用回归分析阶段作业 02：诊断与补救审计

## 学习目标

- 把阶段 1 的 OLS 基线与阶段 2 的诊断方法整合成可复核决策链。
- 比较补救方案对推断和预测的不同影响。
- 保留失败方案并解释失败机制。

## 任务边界

不得通过更换目标变量、删除不利样本或改写主指标制造改善。补救只能针对已经用证据识别的机制；超出已学内容的方法可列为后续工作，但不参与主评分。

## 任务

在课后作业 02 的模拟数据或一个许可清晰的公开数据上，完成“基线 → 诊断 → 两种补救 → 复检”的闭环。补救方案必须针对已识别机制，至少包含以下两类中的两种：

- OLS + HC3 与可行 WLS 的推断比较。
- Box-Cox 或预先声明的响应变换。
- 对影响点进行保留/剔除敏感性分析。
- 对共线性进行变量重定义、联合检验或正则化预案。

## 必做问题

1. 冻结基线公式和主结论，不得补救后重新定义问题。
2. 对每个诊断结论给出证据和不确定性。
3. 比较补救前后系数、标准误、残差结构与原量纲样本外误差。
4. 保留至少一个无效或副作用明显的补救方案。
5. 给出最终建议，并说明它适用于推断还是预测。

## 环境与数据

- Python 3.11；numpy、pandas、statsmodels、scikit-learn、matplotlib。
- 若使用外部数据，记录 URL、版本、许可证、访问日期和本地校验值。
- 所有方差模型、变换参数和特征选择只使用训练数据。

## 提交产物

- src/：从原始输入到结果的脚本。
- figures/：诊断和复检图。
- report.md：问题、证据、决策、失败方案、限制。
- environment.txt：版本与运行命令。
