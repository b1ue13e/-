# 应用回归分析大作业：端到端回归研究

## 学习目标

完成一份别人能运行、能质疑、能复核的回归研究。默认使用 scikit-learn 内置 diabetes 数据，避免网络和许可阻塞；也可更换为许可明确、任务更真实的数据。

## 任务边界

默认问题是预测一年后疾病进展指标，而不是估计某特征的因果效应。若自行改成推断或因果问题，必须另行说明设计、目标总体和识别假设，预测分数不能替代识别证据。

## 必做流程

1. **问题与协议**：冻结分析单位、目标、主指标、候选模型、测试集和选择规则。
2. **数据审计**：字段语义、缺失、重复、范围、抽样偏差和泄漏风险。
3. **基线**：均值预测、OLS、Ridge、Lasso；至少一个非线性候选。
4. **诊断**：OLS 残差、影响点、共线性和可能的函数形式错设。
5. **模型选择**：训练集内部交叉验证；全部预处理进入 Pipeline。
6. **最终测试**：只运行一次，报告 RMSE、MAE、$R^2$ 与误差分层。
7. **错误分析**：保留一个失败模型、一个高误差子群和一个敏感性结果。
8. **解释**：区分统计关联、预测贡献和因果效应；禁止越界措辞。
9. **复现**：一条命令生成 JSON 指标与 CSV 预测，测试通过。

## 本地 Starter

- scripts/capstone_baseline.py：可运行基线与无泄漏搜索示范。
- tests/test_capstone_baseline.py：结果 schema、确定性、测试集边界和 Pipeline 检查。

Starter 只提供最小基线，不包括完整诊断、误差分层、非线性候选或最终报告。

## 环境与命令

- Python 3.11
- numpy 2.4.6、pandas 3.0.3、scikit-learn 1.8.0、statsmodels 0.14.6
- 运行：python 03-Projects/30-应用回归分析/scripts/capstone_baseline.py --output 03-Projects/30-应用回归分析/artifacts
- 测试：python -m pytest 03-Projects/30-应用回归分析/tests -q

## 提交产物

- README.md：问题、环境、运行与目录。
- protocol.md：运行前冻结的实验协议。
- src/：数据审计、训练、评价和绘图。
- artifacts/metrics.json、predictions.csv 和必要图表。
- report.md：结论、诊断、错误分析、限制与复现说明。
- tests/：覆盖关键数据边界和结果。

## 100 分 Rubric

| 维度 | 分值 | 通过要求 |
| :--- | ---: | :--- |
| 问题定义与数据 | 15 | 目标、单位、数据来源和泄漏风险清楚 |
| 基线与诊断 | 20 | 有朴素基线、OLS 和完整诊断 |
| 无泄漏建模 | 25 | Pipeline、CV、测试集边界正确 |
| 评价与错误分析 | 20 | 主指标、分层、失败模型和敏感性完整 |
| 解释与边界 | 10 | 不作无依据因果声明 |
| 复现与工程 | 10 | 命令、版本、测试和产物完整 |

总分至少 85；无泄漏建模至少 20；任何测试集污染直接不通过。

## 分阶段检查点

1. 只提交 protocol.md，确认问题和协议。
2. 提交数据审计与朴素基线。
3. 提交训练集内部比较，不得查看测试结果。
4. 冻结方案后运行一次最终测试。
5. 完成错误分析、报告和复现验证。

- [ ] 报告了失败和不确定性。
- [ ] 预测结论没有冒充因果结论。
