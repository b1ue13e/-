# 🧭 时间序列分析课程作业总索引

> 本页是作业唯一入口。题目、规模、阶段与知识依赖分别以作业文件的 `assignment_level`、`stage_id` 和 `requires` 为准；本页只提供派生视图，不复制静态映射。

## 使用顺序

1. 先从[[🗺️ 时间序列分析学习路径|课程学习路径]]进入当前阶段。
2. 阶段 MOC 给出有序知识卡；完成对应课后/阶段作业并通过硬验收后再前进。
3. 答案不进入活动目录；保存自己的作答、运行证据、失败记录与订正。
4. `planned` 只表示规格可用，不表示任务已执行或得到分数。

## 课后作业固定输入

作业 00、01、05、06 使用同一个只生成输入、不生成答案的脚本：

```powershell
python scripts/build_lesson_homework_fixtures.py
```

生成文件位于 `artifacts/homework-fixtures/`，`manifest.json` 记录种子、行数、列名和命令。学习者提交物必须放在自己的 `submission/` 中，不得覆盖课程 fixture；作业 02–04 按题面固定种子自行模拟。

## 统一通过口径

- 课后/阶段作业：总分至少 80/100，且没有来源、泄漏、复现或依赖硬失败。
- 大作业：总分至少 85/100，最终测试段只在协议冻结后使用一次。
- 任一代码结果必须附环境、命令、随机种子与真实输出；未运行不得标记 `completed`。

## 已验证运行证据

课程大作业的最小真实运行样例位于 `artifacts/capstone-co2/`，由 `scripts/run_capstone_co2.py` 生成：包含 manifest、环境、逐预测结果、逐 horizon 指标、区间覆盖、候选资格、警告、失败拟合和运行日志。模型选择先于最终测试；缺失窗口或拟合失败会使候选失去选择资格。

阶段 5 的同协议参考证据位于 `artifacts/stage5-extensions/`，由下面的命令生成：

```powershell
python scripts/run_stage5_extensions.py
```

它使用公共领域 macrodata 的 GDP 增长，在 16 个 validation 原点比较 naïve、AR、ARIMAX、VAR、状态空间和滞后特征 ML；只有验证胜者与 naïve 进入 16 个最终 test 原点。参考证据不替代学习者以通胀率为目标完成[[时间序列分析-阶段作业-05-动态回归与信息边界]]。
