# 时间序列分析｜阶段作业 01：结构探索与数据契约

## 学习目标

把一张真实规则时间表转化为可审计的数据字典、结构假设和变换/分解决策，为平稳性分析冻结输入对象。

## 任务边界与环境

选择一个公开、规则频率、至少 120 个观测的单变量序列；记录来源、访问日期、许可、字段、频率和公布延迟。所有清洗、变换和分解必须在训练窗口内拟合，最终测试段在协议冻结前封存。使用 Python 3、`pandas`、`matplotlib`、`statsmodels`，保存版本和运行命令。

## 任务

1. **数据字典与信息边界（20 分）**：写出观测单位、时间键、目标、频率、缺失机制、预测原点、horizon、可得信息和失败成本。
2. **结构证据（25 分）**：提交原序列时间图、季节图或周期摘要、异常/断点清单，并区分趋势、季节、周期、噪声和真实零值。
3. **变换与分解（25 分）**：比较至少一个方差变换、移动平均/经典分解和 STL；说明每个操作改变的对象、窗口和边界。
4. **可执行审计（20 分）**：写出缺期、重复日期、排序、插值和切分断言，生成 `data-contract.json` 或等价表格。
5. **阶段报告（10 分）**：用 300–500 字说明哪些结构进入阶段 2，哪些判断仍保持不确定。

## 提交产物

提交 `README.md`、`manifest.yml`、数据字典、可运行脚本、原始/变换/分解图、审计清单、结构报告和环境文件。不得提交许可不允许再分发的数据快照。

## 验收标准与 Rubric

| 维度 | 分值 | 通过证据 |
| :--- | ---: | :--- |
| 数据契约 | 20 | 频率、边界、horizon 和信息时钟可复核 |
| 结构诊断 | 25 | 图形和机制证据区分趋势/季节/异常 |
| 变换分解 | 25 | 变换在窗口内拟合，能解释副作用 |
| 可复现审计 | 20 | 从空目录可重建主要表图 |
| 阶段沟通 | 10 | 结论不把探索证据夸大为因果 |

通过线 80/100；硬失败包括全样本预处理、随机切分、无数据来源、无朴素基线或删除异常/失败证据。

## 引导与自检

先冻结数据契约，再画原图，最后决定变换和分解；提交前从空目录运行 README 命令，抽查三条观测的时间可得性，并确认所有图表能回链到输入表。通过后进入[[02-平稳性与相关结构/🧭 阶段2-平稳性与相关结构]]。
