# 时间序列分析阶段作业 05｜动态回归与信息边界

## 作业定位

- **版本**：2026-08-07。
- **规模**：阶段作业，预计 6–8 小时。
- **任务目标**：在同一季度通胀预测协议下，公平比较朴素基线、AR、动态回归与滞后特征 ML。
- **数据**：statsmodels macrodata，1959Q1–2009Q3，共 203 个季度观测，官方页面标记为 public domain。
- **参考证据边界**：artifacts/stage5-extensions/ 使用 GDP 增长和不同模型集合，只演示输出契约，不提供本作业的通胀预测结果。
- **禁止事项**：随机切分、使用预测季度同期或未来宏观变量、查看 test 后改特征/超参数、静默删除失败窗口、用最终测试决定模型。

## 学习目标

完成后应能：

1. 画出预测原点与宏观变量公布时钟，区分“数据表中存在”和“预测时可得”。
2. 使用至少一季滞后的外生变量建立动态回归，而不是把同期变量当作已知未来。
3. 为普通 ML 构造严格滞后的目标、外生和日历特征。
4. 让四类模型共享预测原点、真实值、指标、失败规则和计算预算。
5. 只用 validation 决定模型，冻结后在 test 运行朴素基线与胜者。
6. 保留负结果，并给出降级到简单基线的可执行条件。

## 任务边界与冻结协议

使用：

~~~python
import statsmodels.api as sm

raw = sm.datasets.macrodata.load_pandas().data.copy()
~~~

数据来源：[statsmodels macrodata](https://www.statsmodels.org/stable/datasets/generated/macrodata.html)。预测目标为数据列 infl，表示年化季度通胀率。

必须按以下协议执行：

- 时间索引由 year 与 quarter 显式构造为季度 PeriodIndex。
- 目标滞后：infl_lag1、infl_lag2、infl_lag4。
- 外生变量：tbilrate_lag1、unemp_lag1、realint_lag1，全部至少滞后一季。
- 日历变量：季度正弦和余弦，在预测原点可知。
- 删除因滞后产生的开头缺失后，最后 32 个季度固定为评估区间。
- 前 16 个评估原点为 validation，后 16 个为最终 test。
- horizon 固定为 1；每个原点使用扩展窗口重新拟合。
- validation 比较全部候选；test 只运行 naïve 与验证期冻结胜者。
- 候选若缺少任一 validation 原点或出现拟合失败，则失去选择资格。

固定候选：

| 模型 | 最小规格 | 可用信息 |
| :--- | :--- | :--- |
| naïve | $\hat y_t=y_{t-1}$ | infl_lag1 |
| AR | AutoReg，lags [1, 2, 4]，含截距 | 历史通胀 |
| 动态回归 | ARIMA$(1,0,0)$ 误差，含三个滞后外生变量 | 预测原点前一季宏观变量 |
| ML lag | HistGradientBoostingRegressor，固定题面参数 | 目标滞后、外生滞后、季度日历 |

ML 参数固定为：max_iter=100、max_depth=3、learning_rate=0.05、l2_regularization=0.1、random_state=20260807。不得在 test 上搜索参数。

## 详细任务

### Q1 数据契约与时间索引（15 分）

1. 构造 YYYYQn 季度 PeriodIndex，断言严格递增且无重复。
2. 提交数据字典：目标、外生变量、单位、频率、来源与许可。
3. 记录原始 203 行、滞后处理后的有效行数和删除原因。
4. 明确 validation/test 的起止季度和预测原点数量。

### Q2 特征可得性与泄漏测试（20 分）

提交 feature-availability.csv，至少包含：

| 字段 | 含义 |
| :--- | :--- |
| feature | 特征名 |
| source_period | 特征来自哪个季度 |
| forecast_period | 要预测的季度 |
| available_at_origin | 在预测原点是否已知 |
| used_by | 哪些模型使用 |

自动测试必须证明：

- infl_lag1[t] 等于 infl[t-1]，其他滞后同理；
- 外生变量在时点 $t$ 的特征来自 $t-1$；
- 每条预测的 timestamp 晚于 train_end；
- test 数据没有进入 validation 的拟合、选模或参数搜索。

### Q3 朴素与 AR 基线（15 分）

1. 在全部 validation 原点运行 naïve 和固定 AR。
2. 输出逐预测记录，不得只输出平均分。
3. 记录拟合失败、非有限预测和窗口缺失。
4. 报告 MAE、RMSE、MASE，并解释 MASE 分母如何只由当前训练窗口计算。

### Q4 动态回归（20 分）

1. 使用固定的 ARIMA$(1,0,0)$ 误差与三个滞后外生变量。
2. 对每个原点重新拟合，并提供下一季度外生行。
3. 保存收敛状态、警告和失败；未收敛窗口不得静默纳入指标。
4. 解释系数是条件预测关联，不是政策因果效应。
5. 与 naïve/AR 比较 validation 结果并记录一个最差窗口。

### Q5 滞后特征 ML（15 分）

1. 只使用题面冻结的七个特征和固定超参数。
2. 证明训练样本每一行的特征都早于其目标。
3. 使用与统计模型完全相同的 validation 原点。
4. 记录固定随机种子、训练样本数和预测数。
5. 若 ML 未优于基线，保留结果，不扩大搜索空间。

### Q6 冻结选择与最终测试（15 分）

1. 候选必须完成 16 个 validation 原点且无失败才有资格。
2. 按 validation RMSE 排序，冻结唯一胜者。
3. test 只运行 naïve 与冻结胜者，共 16 个原点。
4. 提交 test 指标，但不得据此返回修改模型。
5. 若胜者 test RMSE 不优于 naïve，写出降级决策和下一轮只允许在新验证段尝试的改进。
