# 时间序列分析｜课后作业 06：模型识别与残差诊断

## 作业定位

本作业只训练“预注册三个候选并用估计与残差证据筛选”。优化器敏感性、GARCH 修复、滚动预测和最终部署决策已移出 lesson 规模，分别留给后续知识卡和阶段作业。

## 学习目标

- 手算 AICc 并理解小样本惩罚。
- 在拟合前注册候选和否决条件。
- 正确使用 Ljung–Box 的 `model_df` 与预注册滞后。
- 区分收敛、根、残差相关和分布形态四类证据。

## 任务边界

只拟合题面给定的 M0–M2，并在同一 240 行样本上完成估计与残差审计；不做自动搜索、GARCH、滚动预测或最终部署判断。

## 起始材料与固定协议

运行：

```powershell
python scripts/build_lesson_homework_fixtures.py
```

输入为 `artifacts/homework-fixtures/hw06_diagnostic_series.csv`，共 240 个连续月度观测。只拟合以下候选，均使用 `trend="c"`：

- M0：ARIMA$(0,0,0)$；
- M1：ARIMA$(1,0,0)$；
- M2：ARIMA$(2,0,0)$。

Python 3，依赖 `pandas`、`numpy`、`statsmodels`、`matplotlib`、`scipy`；普通 CPU 预计少于 5 分钟。不得增加候选来追求更小 AICc。

## 渐隐任务

### Q1｜AICc 手算（15 分）

给定 $T=80$：模型 A 的 $\ell=-100,k=3$，模型 B 的 $\ell=-98,k=6$。按

$$
\mathrm{AIC}=2k-2\ell,
\qquad
\mathrm{AICc}=\mathrm{AIC}+\frac{2k(k+1)}{T-k-1}
$$

手算并解释小样本修正如何改变两者差距。参数计数口径必须写明是否含方差参数。

### Q2｜候选预注册（10 分）

拟合前创建 `artifacts/candidate_registry.csv`：

```text
model,order,expected_acf,expected_failure,keep_if,reject_if
```

原文件不得在拟合后覆盖；如需修正，另写 `candidate_registry_revision.csv` 并解释新证据。

### Q3｜估计台账（25 分）

拟合 M0–M2，提交：

```text
model,nobs,log_likelihood,k,aic,aicc,converged,min_ar_root_modulus,warning
```

三者必须使用完全相同的 240 个观测。警告和失败原样保留；不能把 `enforce_stationarity=True` 当成已经完成根审计。

### Q4｜残差诊断（30 分）

对每个候选：

1. 绘制残差时序图和 lag 1–24 ACF；
2. 在预注册 lag 6、12 执行 Ljung–Box，设置 `model_df=p+q`；
3. 报告残差均值、标准差和最大绝对残差时间；
4. 用 Q–Q 图描述分布形态，但不把非正态自动等同于有自相关。

提交 `artifacts/residual_diagnostics.csv`：

```text
model,lag,model_df,lb_stat,lb_pvalue,residual_mean,residual_std,worst_timestamp,worst_abs_residual
```

当 `lag <= model_df` 时，说明自由度为何无效，而不是用 `NaN` 冒充通过。

### Q5｜最小修复说明（10 分）

从 M0 或 M1 中选择一个明确欠拟合候选，只允许把它替换为预注册的下一个候选。比较修复前后的 AICc、根和 lag 12 Ljung–Box；若新候选仍失败，保留失败结论。

### Q6｜评审结论（10 分）

用 250 字以内说明哪些候选可进入[[时间序列分析-阶段作业-04-滚动预测与区间评估]]。必须区分“允许进入样本外评估”与“已经证明最终胜出”。

## 必要提示

1. AICc 只在响应变换、差分和有效样本一致时可直接比较。
2. Ljung–Box 大 p 值表示未拒绝所检查滞后范围内的无自相关，不证明残差独立正态。
3. `model_df` 扣除已估计的 AR/MA 自由度；滞后必须大于该数值。

## 常见错误

- 拟合后才编写候选台账。
- 三个候选因缺失处理或截断使用不同样本。
- 只看 AICc，不检查收敛、根和残差。
- 用 Q–Q 图替代白噪声检验。
- 把 Ljung–Box 大 p 值写成“接受独立正态”。
