# 时间序列分析｜课后作业 01：平稳性与差分

## 作业定位

本作业只训练“识别结构并选择最少处理”。ADF/KPSS 尚不是必需前置，因此基础分不能依赖单位根检验；检验只放在不计分扩展中。

## 学习目标

- 手算普通差分并解释差分后的研究对象。
- 区分短期相关、确定性趋势、随机趋势和随水平变化的尺度。
- 用图形、分段统计和 ACF 支持处理选择。
- 识别过度差分和“为追结果不断变换”的风险。

## 任务边界

基础分只使用已教授的图形、分段统计、ACF 和一次首选变换；不以 ADF/KPSS 或多轮调参作为必要证据。每个匿名序列最多执行一种首选处理。

## 起始材料与环境

先运行：

```powershell
python scripts/build_lesson_homework_fixtures.py
```

使用 `artifacts/homework-fixtures/hw01_structure_series.csv`。输入包含四个匿名月度序列 `series_a` 至 `series_d`，每列 160 个观测。Python 3，依赖 `pandas`、`numpy`、`matplotlib`、`statsmodels`；普通 CPU 少于 3 分钟。

## 渐隐任务

### Q1｜示范后的手算迁移（15 分）

已知一阶差分定义 $\Delta y_t=y_t-y_{t-1}$。对 `20, 23, 27, 32, 38, 45` 计算一阶、二阶差分；逐项写出时间含义，并说明二阶差分为什么不再是“本期比上期增加多少”。

### Q2｜运行前预注册（15 分）

在画图和计算 ACF 前提交 `artifacts/structure_predictions.csv`：

```text
series_id,expected_mean_structure,expected_scale_structure,proposed_action,reason
```

`proposed_action` 只能从 `none`、`detrend`、`difference`、`log` 中先选一个；允许运行后否决自己的预判，但不得覆盖原文件。

### Q3｜独立证据表（35 分）

为四个序列分别输出：

1. 原序列图；
2. 前半段与后半段的均值、标准差；
3. lag 1–12 的 ACF；
4. 一项你认为最有判别力的反例或边界。

提交 `artifacts/structure_evidence.csv`，字段固定为：

```text
series_id,first_half_mean,second_half_mean,first_half_std,second_half_std,acf1,acf12,evidence_summary
```

### Q4｜最少处理与复查（25 分）

根据 Q3，为每列选择一个首选处理。处理后重新计算同一组统计量，并回答：

- 哪个结构被削弱？
- 新序列的含义是什么？
- 是否出现强负 lag-1 ACF、异常放大或其他过度处理信号？
- 还有哪种替代处理值得保留？

禁止连续差分直到图形“看起来满意”；基础要求中每列最多执行一种首选处理。

### Q5｜非技术沟通（10 分）

不用“平稳”“单位根”“协方差”三个词，在 150 字内解释为什么价格水平与价格变化不能直接共用同一模型。

## 必要提示

1. 趋势主要改变局部均值，尺度效应主要改变局部波动；二者可以同时存在。
2. 随机趋势与确定性趋势都可能产生缓慢衰减的 ACF，需结合机制和处理后含义。
3. 对数主要改变尺度，差分主要改变水平变化；不要把两者写成同一种操作。

## 常见错误

- 用一个 ACF 数字替代所有图形和机制证据。
- 对匿名序列运行多种处理后只保留最好看的结果。
- 差分后仍用原序列的业务含义解释数值。
- 把“后半段标准差更大”直接等同于异方差，而不检查水平变化。
