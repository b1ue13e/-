# 时间序列分析｜课后作业 00：前置诊断与数据契约

## 学习目标

验证进入主线所需的 Python、表格、描述统计和矩阵能力，并把一次预测任务写成无泄漏的数据契约。

## 任务边界与环境

使用 Python 3、`pandas`、`numpy`；所有输入在脚本中内嵌生成，禁止下载外部数据、随机打乱时间或把异常行静默删除。固定随机种子 `20260806`，运行时间目标少于 2 分钟。

## 题目

1. **表格诊断（25 分）**：构造含乱序日期、重复日期、缺失值和一个真实零值的表，输出排序前后摘要、重复键、缺失计数和待人工确认清单。
2. **统计与矩阵（25 分）**：手算一组五个观测的样本均值、样本方差、协方差和相关系数；检查一个 `X @ beta` 的维度并解释错误输入为何不能相乘。
3. **数据契约（30 分）**：为“预测下月观测值”写出目标、频率、预测原点、horizon、公布延迟、训练/验证/测试边界、主指标和失败成本。
4. **泄漏口述（20 分）**：用 150 字解释一个全样本插值或中心滚动均值如何泄漏，并给出窗口内修复方案。

## 输入输出约定

脚本必须从下面的固定字段开始：`date`、`value`、`published_at`。`date` 表示观测所属时间，`published_at` 表示学习者真正能看到该值的时间；二者不能混用。输出 `diagnostics.json`，至少包含 `is_sorted`、`duplicate_dates`、`missing_values`、`zero_values`、`latest_available_at_origin` 和 `matrix_shapes`。若发现重复日期或公布延迟跨过预测原点，脚本必须返回非零退出码或明确的失败状态，不得继续生成“干净数据”。

`manifest.yml` 至少填写：任务名称、预测目标、频率、预测原点、horizon、训练/验证/测试边界、输入字段、时间可得性规则、主指标、随机种子、运行命令和输出清单。统计手算需同时保留公式、代入值和最终结果，不能只粘贴 `numpy` 输出。

## 失败分支

- 同一天有两条记录：先报告冲突，不自行求平均；只有任务契约明确聚合规则后才能处理。
- 数值为 `0`：先判断它是业务真实零值还是缺失编码，不以 `0 → NaN` 作为默认清洗。
- `published_at` 晚于预测原点：该观测不进入训练特征，即使其 `date` 属于历史月份。
- 矩阵维度不匹配：输出形状和预期形状，解释是哪一个特征或参数定义错误。

## 提交产物

提交 `answer.md`、`prerequisite_diagnostic.py`、`manifest.yml`、运行输出和 `environment.txt`。输出必须包含数据质量清单、手算中间步骤和完整数据契约。

## 验收标准与 Rubric

| 维度 | 分值 | 通过证据 |
| :--- | ---: | :--- |
| 表格诊断 | 25 | 乱序、重复、缺失和真实零值均被区分 |
| 统计矩阵 | 25 | 分母、维度和中间步骤正确 |
| 数据契约 | 30 | 时间边界和信息可得性可执行 |
| 泄漏解释 | 20 | 能指出未来信息及窗口内修复 |

通过线 80/100；硬失败包括没有脚本、随机打乱、静默删除问题行或把预测原点之后的信息写入特征。

先手工写预期异常，再运行脚本；提交前逐项核对输入排序、重复键、缺失处理、矩阵形状和预测原点。通过后进入[[01-时序结构与数据契约/🧭 阶段1-时序结构与数据契约]]。
