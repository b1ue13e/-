# 时间序列分析｜课后作业 00：前置诊断与数据契约

## 作业定位

这是进入主线前的启动门。你要证明自己能够读懂一张有问题的时间表、保留异常证据，并把“预测什么、何时预测、当时能看到什么”写成机器可检查的契约。不要在本作业中拟合预测模型。

## 学习目标

- 区分乱序、重复时间键、缺失观测、缺失数值、真实零值和公布延迟。
- 手算最小统计量并检查矩阵维度，而不是只复制库输出。
- 冻结预测原点、horizon、信息可得性和数据切分。
- 让错误显式失败，不把清洗步骤变成静默改写。

## 任务边界

只审计固定输入、完成最小手算并编写数据契约；不要求清洗后的数据集或预测模型。异常必须保留，任何自动修复都超出本作业范围。

## 起始材料与环境

在项目目录运行：

```powershell
python scripts/build_lesson_homework_fixtures.py
```

输入文件为 `artifacts/homework-fixtures/hw00_observations.csv`。固定预测原点为 `2025-08-15`，目标是预测下一个月度观测。使用 Python 3、`pandas`、`numpy`；普通 CPU 预计少于 2 分钟。

禁止随机打乱、静默删除重复行、默认把零值改成缺失值，或使用 `published_at` 晚于预测原点的观测。

## 基础要求

### Q1｜运行前预判（10 分）

不运行代码，先在 `answer.md` 写出你预计会发现的异常类型，并区分：

1. 时间键重复与数值重复；
2. 日期序列缺期与某行 `value` 为空；
3. 真实零值与缺失编码；
4. `date` 属于过去但 `published_at` 尚不可得。

评分只看分类理由，不要求预判具体数量全部正确。

### Q2｜数据质量审计器（30 分）

编写 `src/audit_observations.py`，读取固定输入并生成：

- `artifacts/issues.csv`：字段固定为 `issue_type, record_id, period, severity, details`；
- `artifacts/diagnostics.json`：至少包含 `rows`、`is_sorted`、`duplicate_periods`、`missing_periods`、`missing_values`、`zero_values`、`unavailable_at_origin`；
- 控制台退出码：存在重复时间键或预测原点后才可得的数据时，`--strict` 模式退出码必须非零。

审计器只能报告问题，不能在本题中自动求均值、插值或删除记录。

### Q3｜统计量与矩阵检查（20 分）

对向量 `4, 7, 7, 10, 12` 手算样本均值和样本方差，保留公式、代入值和分母。随后判断下面矩阵乘法是否可行，并说明输出形状：

$$
X\in\mathbb{R}^{4\times 3},\qquad
\beta\in\mathbb{R}^{3\times 1}.
$$

再构造一个不可相乘的 `beta_bad`，让程序打印实际形状和期望形状后明确失败。

### Q4｜预测任务契约（25 分）

提交 `manifest.yml`，至少包含：

```yaml
target:
frequency:
origin:
horizon:
available_when:
train_end:
validation_range:
test_range:
primary_metric:
failure_cost:
seed:
command:
outputs:
```

`available_when` 必须同时引用 `date` 与 `published_at`，并说明哪个字段决定能否进入训练。

### Q5｜泄漏辨析与修复（15 分）

分别用不超过 120 字解释以下两种错误，并给出窗口内修复方法：

1. 先在全表插值，再切训练/验证；
2. 用 `center=True` 的滚动均值作为预测特征。

## 必要提示

1. **第一层**：先按 `date` 检查键完整性，再按 `published_at <= origin` 检查信息可得性。
2. **第二层**：缺期需要从期望的月度索引与实际索引做集合差；它不等于 `value.isna()`。
3. **第三层**：错误清单与清洗结果是不同产物。本作业只要求错误清单。

## 常见失败与调试

- `0` 被计入缺失：检查是否使用了 `replace(0, NaN)`。
- 重复记录被 `drop_duplicates()` 吞掉：在任何清洗前先输出冲突行。
- `date` 早于原点就直接可用：还要检查 `published_at`。
- 矩阵异常只有报错堆栈：在触发乘法前输出两侧形状。
