# 时间序列分析｜课后作业 03：AR 模型与均值回归

## 作业定位

本作业只验证 AR(1) 的均值、冲击传播、边界和有限样本波动。模型选择、残差诊断和滚动赛马留给后续作业，不作为本节隐藏要求。

## 学习目标

- 区分截距 $c$ 与长期均值 $\mu$。
- 递推多步预测和冲击响应。
- 解释正负 $\phi$、近单位根和爆炸过程的路径差异。
- 用重复模拟而非单条好看路径检验理论性质。

## 任务边界

只研究 AR(1) 的理论与模拟；不要求 AR($p$) 选阶、AICc、残差检验或滚动预测。非平稳参数只做手算辨析，不参与重复模拟。

## 环境与协议

Python 3，依赖 `numpy`、`pandas`、`statsmodels`、`matplotlib`。固定总种子 `20260807`；每次模拟保留 240 个观测、burn-in 100，重复 50 次。普通 CPU 少于 3 分钟。

## 渐隐任务

### Q1｜完整手算（25 分）

对

$$
y_t=4+0.6y_{t-1}+\varepsilon_t
$$

完成：

1. 推导长期均值；
2. 当前 $y_t=15$ 时递推未来 1、2、3 步条件均值；
3. 写出“到长期均值的距离”如何变化；
4. 计算大小为 10 的新冲击在三期后的剩余影响。

每一步必须显示代入过程，不能只给小数答案。

### Q2｜边界完成题（20 分）

填写下表但不要运行代码：

| $\phi$ | 是否满足 AR(1) 平稳条件 | 预期路径 | ACF 符号/衰减 | 冲击 5 在第 4 期的影响 |
| :---: | :---: | :--- | :--- | :---: |
| 0.2 |  |  |  |  |
| 0.8 |  |  |  |  |
| -0.8 |  |  |  |  |
| 1.0 |  |  |  |  |
| 1.1 |  |  |  |  |

说明 $\phi=1$ 与 $\phi=1.1$ 为什么是两种不同的非平稳边界。

### Q3｜重复模拟（35 分）

只对 $\phi=0.2,0.8,-0.8$ 做 50 次模拟。每次计算样本均值、样本方差和 lag 1–5 ACF，提交：

```text
phi,replications,theoretical_mean,mean_of_sample_means,sd_of_sample_means,acf1_mean,acf5_mean
```

生成 `artifacts/ar_repetition_summary.csv`，并用一张图展示 $\phi=0.8$ 与 $-0.8$ 的 50 条路径中各自固定选取的前 5 条。不得挑选最符合理论的路径。

### Q4｜代码审查（10 分）

审查以下两类错误并给出最小修复：

1. 每次重复都执行 `np.random.default_rng(20260807)`；
2. 生成 AR(1) 后不做 burn-in 就直接计算均值。

解释错误会怎样改变重复结果，而不只写“随机种子不对”。

### Q5｜费曼解释（10 分）

面向中学生，用“带阻尼的记忆”解释 $\phi=0.8$，再用“交替过冲”解释 $\phi=-0.8$。限 160 字。

## 必要提示

1. 当 $\lvert\phi\rvert<1$ 时，可先对期望取极限求长期均值。
2. 多步预测的噪声条件期望为零，但不等于未来真实误差为零。
3. 50 次重复应由同一个随机数生成器连续派生，或使用明确的子种子序列。

## 常见错误

- 把截距 4 写成长期均值。
- 冲击三期后的指数多乘或少乘一次。
- 负 $\phi$ 被写成“无均值回归”。
- 用单条路径的样本 ACF 要求精确等于 $\phi^k$。
