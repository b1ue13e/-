# 时间序列分析｜大作业：预测漂移监控扩展

> [!info] 课程关系
> 先完成[[时间序列分析-大作业-滚动预测与完整建模报告]]。本任务只增加非线性对照、误差漂移监控和降级决策，不替代经典基线、残差与区间审计。

## 学习目标

完成后应能在不泄漏未来信息的前提下：

1. 把滞后、滚动统计和外生变量重建为预测原点可用的特征表。
2. 让经典模型、XGBoost 类模型和朴素基线共享同一滚动协议。
3. 用验证期误差分布预注册漂移阈值，并在测试期逐窗口触发告警。
4. 把告警转化为继续服务、重训、降级到基线或暂停预测的可审计决策。

## 任务边界与固定协议

- 使用一个公开的规则时间序列，至少 240 个观测；必须记录来源、访问日期、许可、频率、修订和公布延迟。
- 至少包含目标序列和两个预测时真实可得的外生或日历特征；无法证明可得性的变量不得进入模型。
- 按时间划分 train / validation / test。特征生成、缺失处理、缩放和阈值校准都只能在当时可用的窗口内完成。
- 固定比较 last-value naive、适用时的 seasonal naive、经典大作业选中的模型，以及一个 XGBoost/梯度提升对照。
- 基础漂移告警只使用课程已经教授的误差指标：在 validation 上计算窗口长度 `w` 的滚动 MASE，并冻结其 90% 分位数 `q90`；test 中连续两个窗口的滚动 MASE 高于 `q90` 才触发告警。
- PSI、KS 检验或特征分布监控只作为可选扩展，不计入基础通过条件，也不得成为隐藏前置。
- 普通 CPU 预计 8–12 小时；若单次运行超过 30 分钟，必须记录数据规模、搜索空间和停止条件。

## 环境与运行入口

使用 Python 3.11，至少需要 `numpy`、`pandas`、`scikit-learn`、`statsmodels` 和 `matplotlib`。提交时保存实际解析出的精确版本，不把下面的包名当成版本锁定：

## 详细任务

### Q1 数据契约与信息边界（15 分）

提交数据字典、预测对象、频率、horizon、预测原点、外生变量公布时钟和最终测试边界。用断言证明时间键有序、无重复，且每个特征在预测原点已经可得。

### Q2 经典基线复现（15 分）

在新数据上复现 naive、seasonal naive 和经典大作业选中的模型。所有模型使用相同预测原点、真实值和指标；经典基线无法复现时不得继续训练 ML。

### Q3 非线性特征与模型（20 分）

只使用滞后、训练窗口内滚动统计、日历和当时可得的外生变量。提交特征清单、时间对齐测试、固定随机种子和有限超参数空间；不得使用 test 调参。

### Q4 滚动样本外比较（20 分）

在 validation 和 test 上分别输出逐预测记录，至少报告 MAE、RMSE、MASE 和逐 horizon 结果。保留拟合失败和最大误差窗口；模型失败的窗口不得从平均值中静默删除。

### Q5 误差漂移与告警（20 分）

只在 validation 上确定 `w` 和 `q90`，然后冻结。test 中逐窗口计算滚动 MASE、告警状态和连续超阈值次数；提交至少一个真实或可控注入的漂移案例，并解释告警是否及时、是否误报。

### Q6 决策与复现（10 分）

为“无告警、单次超阈值、连续超阈值、数据契约失败”分别给出继续、观察、重训、降级或暂停规则。从空目录按 README 重跑，确认指标和告警表可由逐预测文件复算。

## 必要提示与常见错误

- 先画预测原点和数据公布时间，再写特征代码；“训练表里存在”不等于预测时可得。
- 漂移告警监控的是模型误差是否偏离验证期基准，不自动证明数据分布或因果机制发生变化。
- 单个窗口超阈值可能是偶然波动；基础协议要求连续两个窗口超阈值，避免看到 test 后临时改阈值。
- ML 输给基线时保留负结果并降级，不增加搜索预算直到它偶然获胜。
