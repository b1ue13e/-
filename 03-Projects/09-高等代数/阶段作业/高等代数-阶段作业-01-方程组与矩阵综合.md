# 高等代数-阶段作业-01-方程组与矩阵综合

> **课程**：高等代数 ｜ **规模**：stage ｜ **形态**：problem-set ｜ **阶段**：I（01-基础入门）

## 🎯 学习目标

验证阶段 I 的**多模块整合**：给定任意矩阵，能完成消元 → 分解 → 子空间 → 秩 → 解结构的全流程分析，并解释各环节联系。

## 📖 所需知识

阶段 I 全部知识卡（见 `requires`）。本作业默认已通过课后作业 01。

## ✍️ 综合题目（限时 120 分钟，闭卷）

给定 $A=\begin{bmatrix}1&2&1&0\\2&4&2&1\\1&1&0&1\\0&1&1&1\end{bmatrix}$，$\mathbf{b}=(1,2,1,0)^T$：

1. **消元**：化 RREF，记录换行次数；写出 $PA=LU$ 分解（$P$ 为置换矩阵）。
2. **解结构**：解 $A\mathbf{x}=\mathbf{b}$；写出通解（特解 + 基础解系），说明自由度。
3. **四个子空间**：给出 $C(A)$、$N(A)$、$C(A^T)$、$N(A^T)$ 的基与维数；验证 $\mathbb{R}^4=C(A^T)\oplus N(A)$ 与 $\dim$ 公式。
4. **秩分析**：用 Rouché–Capelli 判定 $A\mathbf{x}=\mathbf{b}$ 与 $A\mathbf{x}=\mathbf{b}'$（$\mathbf{b}'=(1,1,1,1)^T$）的解情况。
5. **综合问答**：① 为什么 $N(A)$ 的维数等于自由变量数？② 若把第 3 列去掉，各子空间如何变化？

**复盘要求**：完成后写 0.5 页「阶段复盘」：本阶段三个最易错点 + 每个的修复方法。
