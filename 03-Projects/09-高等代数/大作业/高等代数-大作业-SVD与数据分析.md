# 高等代数-大作业-SVD与数据分析

> **课程**：高等代数 ｜ **规模**：capstone ｜ **形态**：project ｜ **阶段**：跨阶段（I-IV 综合）
> **性质**：本地融合任务——用线性代数完整解决一个真实数据分析问题（非官方作业）

## 🎯 学习目标

本大作业验证你能否**端到端**运用高等代数：问题定义 → 数据建模 → 谱分析（SVD/PCA）→ 低秩逼近 → 误差评估 → 解释与展示。它不是课后题的放大版，而是一个完整的数据科学小项目。

## 📖 所需知识

跨阶段知识（见 `requires`）：矩阵分解（阶段 I）、特征值理论（阶段 III）、正交与投影（阶段 IV 前半）、SVD/PCA（阶段 IV 后半）。

## 📋 任务（二选一）

**方案 A：图像压缩**
1. 加载一张灰度图像（≥256×256，可自拍或从公开数据集取，记录来源）；
2. 转为 $m\times n$ 矩阵，做 SVD；
3. 用 $k\in\{5,20,50,100\}$ 截断重建，计算 PSNR/相对 F-范数误差；
4. 展示 4 张重建图 + 误差曲线；解释"奇异值衰减"与压缩比的权衡。

**方案 B：鸢尾花数据集 PCA**
1. 加载 Iris 数据集（sklearn，记录版本）；
2. 中心化 → 协方差 → SVD/PCA；
3. 报告主成分、解释方差比、前两主成分散点图；
4. 用 PCA 特征做分类（kNN，5 折交叉验证）并与原始特征对比；讨论降维的代价。

**报告结构（必含）**：问题定义与数据描述 → 方法（数学公式：SVD、Eckart-Young、误差定义）→ 实现（代码片段）→ 结果（图/表）→ **错误分析**（奇异值截断丢了什么？）→ 改进方向 → 结论。

## ⚙️ 环境与复现

- Python 3.11+；NumPy、Matplotlib；方案 B 加 scikit-learn（`sklearn.datasets.load_iris`、`decomposition.PCA`）。
- 固定随机种子；记录依赖版本；代码可一键复现（`python main.py`）。

## 🔍 引导与自检

- 检查点：① 中心化/数据预处理是否完成？② $\lVert A-A_k\rVert_F$ 是否与 $\sqrt{\sum_{i>k}\sigma_i^2}$ 一致？③ 图是否有轴标签与图例？
- 常见失败：数据泄漏（标准化用全样本统计量）；奇异值排序假设错误；报告无错误分析。
- 提交前清单：代码可复现、图清晰、数学符号正确、结论与数据匹配。
