# 37-复变函数-阶段作业-02-奇点留数与保角映射应用

## 学习目标

1. 深入理解分式线性变换（Möbius 变换 \(w = \frac{az+b}{cz+d}\)）的几何性质：保圆性、交比不变性、保角性与对称点映射。
2. 掌握利用保角映射将复杂的二维平面区域（如上半平面、带状域、楔形域）变易为标准单连通域（单位圆盘）。
3. 掌握将保角映射应用于二维物理场（静电场、二维流体力学、热传导）中 Dirichlet 边值问题求解的完整方法。

## 任务边界

本作业为第三、四阶段的综合实验任务：
- 根据给定的几何映射条件（三点对应关系或导数约束），求解唯一的 Möbius 变换代数系数。
- 利用保角映射解二维 Laplace 方程 \(\Delta \phi = 0\)，给出势函数 \(\phi(x,y)\) 的解析表达及等势线方程。

## 详细题目

### 题目 1 (Möbius 变换代数构造 [MIT 18.04 Spring 2018 Lecture Notes Section 9])
试求一个分式线性变换 \( w = f(z) \)，满足以下映射约束条件：
1. 将上半平面 \(\text{Im}(z) > 0\) 一一保角映射为单位圆盘 \( |w| < 1 \)；
2. 映射满足点对应 \( w(i) = 0 \)；
3. 映射满足导数幅角约束 \(\text{arg } w'(i) = 0\)。
（提示：利用上半平面到单位圆盘的一般映射公式 \( w = e^{i\alpha} \frac{z - z_0}{z - \bar{z}_0} \)，代入 \(z_0 = i\) 并通过 \(w'(i)\) 确定相位角 \(\alpha\)）。

### 题目 2 (调和场与 Dirichlet 边值问题 [MIT 18.04 Spring 2018 Lecture Notes Section 10])
考虑上半平面 \(\text{Im}(z) > 0\) 上的二维电势场 \(\phi(x,y)\)，满足 \(\Delta \phi = 0\)，且其实轴边界条件为：
\( y=0 \) 时，对 \( x > 0 \) 有 \(\phi(x, 0) = V_1\)；对 \( x < 0 \) 有 \(\phi(x, 0) = V_0\)。
1. 利用解析主值对数函数 \( w = \text{Ln } z = \ln|z| + i \text{Arg}(z) \) 将上半平面映射为带状区域；
2. 确定虚部 \(\text{Arg}(z) = \arctan\left(\frac{y}{x}\right)\) 满足的边界对应关系；
3. 构造满足条件的闭式电势函数 \(\phi(x,y)\)；
4. 给出电场线与等势线（即 \(\phi(x,y) = C\)）在复平面上的几何形状。
