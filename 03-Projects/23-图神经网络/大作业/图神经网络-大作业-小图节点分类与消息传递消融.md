# 图神经网络-大作业-小图节点分类与消息传递消融

## 学习目标与任务边界

从问题定义到复现报告完成一个小图节点分类项目：同一数据、split 和预算下比较 MLP、浅层结构基线、GCN、GraphSAGE、GAT；用深度、采样和特征消融解释增益或无增益，并给出不能外推到大规模/线上场景的边界。

## 任务背景与选择

默认使用课程 12 节点 toy 图，便于 CPU 快速验收；也可使用一个明确许可的公开小图，但必须单独记录 URL、版本、许可证、哈希和官方 split。不得使用需要私有凭据或无法复现的数据。

## 里程碑

### C1 问题与协议

写任务契约、目标用户、图/特征/标签、transductive/inductive 边界、指标、资源上限和 kill 标准。冻结 manifest 后不得为提高 test 分数重切。

### C2 数据与基线

完成数据验证、split 不交、类别/度数/组件统计；实现随机/多数类、MLP、一个浅层结构基线。基线不通过泄漏测试前不运行 GNN。

### C3 模型实现

实现并测试 GCN、GraphSAGE、GAT；对归一化、fanout、局部 softmax、输出形状和 permutation equivariance 建立自动测试。每个模型至少 3 个 seed。

### C4 消融

至少完成：深度 1/2/4、特征去除/扰动、GraphSAGE 分层 batch fanout 或 GAT 固定权重中的三项。每项只改变一个主要因素，报告时间、参数、输出方差、采样节点/边数和指标。

### C5 错误与限制

按节点度、社区、特征缺失或错误类型分析至少 3 个失败样本。保留复杂模型不优于 MLP/GCN 的运行，给出一个 kill/pivot 决策。

### C6 从空目录复现

在新的输出目录按 README 执行测试和训练；保存命令、耗时、环境、生成文件、哈希和失败日志。Notebook 仅可作为探索，最终不得依赖隐藏状态。

## 环境与命令

```powershell
python -m pip install -r requirements.txt
python -m pytest -q
python starter/run_baseline.py --output artifacts/starter-smoke --epochs 120
python reference/capstone/run.py --config reference/capstone/config.json --output artifacts/capstone-reference
python -m pytest -q reference/capstone/tests
```

课程提供的 `reference/capstone/` 是 reference submission，用于验证任务接口和验收路径；学习者必须在 `submission/capstone/` 创建自己的提交目录，不能复制 reference 结果作为个人完成证据。

CPU toy 图预计主线 smoke 在数分钟内完成；外部数据超出预算时必须缩小范围或说明未完成，不伪造运行记录。

## 提交产物

- `submission/capstone/README.md`、`requirements-lock.txt`、配置和数据 manifest；
- 数据检查、模型、训练、指标、绘图和测试代码；
- `artifacts/capstone/runs.csv`、主表、消融表、错误样本、日志和哈希；
- `report.md`：问题、方法、结果、失败、限制、kill/pivot 和复现说明；
- 5 分钟演示或等价书面 walkthrough。

Reference 证据位于 `artifacts/capstone-reference/`，包括 `manifest.json`、`runs.csv`、`summary.json` 和 `error_nodes.json`。它只证明本地合成 transductive 协议可执行，不替代学习者的独立提交，也不支持 OGB、inductive 或线上结论。
