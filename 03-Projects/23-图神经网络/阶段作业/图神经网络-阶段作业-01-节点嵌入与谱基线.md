# 图神经网络-阶段作业-01-节点嵌入与谱基线

## 学习目标

在同一张小图、同一节点分类 split 下比较：特征 MLP、随机游走共现 SVD、拉普拉斯谱 embedding。证明你理解表示目标和协议，而不是只会画二维图。

## 任务边界

本题只允许使用课程提供的 toy 图或一份有明确许可的小图；不得把测试标签、未来边或下游分类器的测试结果用于 embedding 维度/窗口选择。SVD 和谱分解属于结构 baseline，不得在报告中包装成训练过的 Node2Vec 或 GNN。

## 任务与里程碑

1. 冻结图、特征、标签、train/val/test mask 和 3 个 seed，生成带 SHA256 的 manifest。
2. 实现均匀随机游走，共现矩阵和截断 SVD；记录窗口、维度和奇异值。
3. 用拉普拉斯非平凡特征向量构造谱 embedding；处理零特征值和符号等价性。
4. 用同一个线性分类器比较原始特征、随机游走 SVD、谱 embedding；只用 val 选维度。
5. 报告均值/标准差、训练时间、失败节点和一个结构反例。

## 提交产物

`submission/s01/` 至少包含数据读取、游走采样、共现构造、SVD/谱 embedding、统一分类器和测试；`artifacts/s01/` 至少包含图哈希、split manifest、每个 seed 的指标、奇异值表和一份错误节点清单。报告必须让另一个人只按 README 命令重跑，而不是依赖本机绝对路径。

## 常见失败

- 只生成 embedding 而没有固定下游分类协议；
- 对特征矩阵和邻接矩阵使用不同节点顺序；
- 把 t-SNE 相邻解释成标签可分；
- 只保留平均最好的 seed，删除其它运行。

## Rubric（100 分）

- 协议与 split 20；随机游走/SVD 20；谱 embedding 20；公平比较 20；测试、错误和报告 20。
- 通过线 80；测试标签调参、不同 split 或只报最佳 seed 为硬失败。

## 引导与自检

- 先对 4 节点图做手算 oracle；

- [ ] 三个方法使用相同分类器和 split；
- [ ] t-SNE 不进入主指标；
- [ ] 无增益结果保留。
