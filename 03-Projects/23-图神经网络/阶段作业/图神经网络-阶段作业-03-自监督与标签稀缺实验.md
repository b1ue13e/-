# 图神经网络-阶段作业-03-自监督与标签稀缺实验

## 学习目标

检验图自监督在少标签场景是否真正改善下游，而不是只让预训练 loss 下降。

## 任务边界

自监督目标、增强、下游 split 和标签比例必须在 manifest 中冻结；不能用测试指标决定增强强度、温度、遮罩率或微调策略。若 toy 图规模不足以展示稳定差异，应报告“不足以判断”，不得补写未运行结果。

## 任务

1. 把训练标签比例降到 50% 和 25%，保持 val/test 不变并记录新 manifest。
2. 选择一种自编对比目标或节点特征掩码目标；写清正负样本、增强和温度/遮罩率。
3. 比较从头训练、冻结 encoder + 线性头、全量微调三种协议；每种至少 3 个 seed。
4. 做增强强度和标签比例两项消融；记录假负例/语义破坏的失败案例。
5. 报告预训练指标与下游指标，禁止用前者替代后者。

## 检查里程碑

1. `augmentations.py` 为每种增强返回原节点/边到新视图的映射，并测试不会读取标签；
2. `objective.py` 用两样本 toy batch 检查正对角、负样本分母和 temperature；
3. `protocol.json` 冻结标签比例、seed、增强、预训练 epochs、下游头和微调策略；
4. 先完成从头训练基线，再运行冻结 encoder 和全量微调；
5. 每个失败运行仍写入 `runs.csv`，用 `status/error` 字段标记，而不是删除。

输入是课程 toy 图或有明确许可的小图；输出是预训练表示、下游 logits、完整运行表和错误样本。主结论只回答“在当前标签比例与增强假设下是否有稳定增益”，不得外推到其它数据域。

## 提交产物

`submission/s03/` 包含增强函数、目标函数、encoder/任务头、冻结/微调三种入口和正负样本测试；`artifacts/s03/` 包含每种标签比例、协议和 seed 的完整运行表。报告必须同时给出预训练 loss、下游 val/test、假负例检查和增强破坏语义的失败案例。

## 常见失败

- 正样本索引错位，模型在训练自己与别人的 embedding；
- 只报告预训练 loss 下降；
- 用相同图的测试节点生成负例却不说明协议；
- 把增强破坏标签后产生的性能下降归因于模型结构。

## Rubric（100 分）

- 标签稀缺协议 20；自监督目标正确 25；下游公平比较 25；增强/失败分析 20；复现 10。
- 通过线 80；测试集选择增强或只报告预训练 loss 为硬失败。

## 引导与自检

- 先证明增强不会直接暴露标签；
- [ ] 对比 batch 内正负索引正确；
- [ ] 与从头训练共享下游 split/头预算；
- [ ] 没有隐藏自监督无增益结果。

## 调试顺序

- loss 为 NaN：先检查向量归一化、temperature 和空负样本；
- loss 下降但下游不变：检查增强是否保留任务语义、任务头是否训练、表示是否坍塌；
- 冻结优于微调：检查微调学习率和少标签过拟合，不自动解释为预训练更强；
- 单个 seed 提升：增加 seed 并报告波动，不立即修改结论。
