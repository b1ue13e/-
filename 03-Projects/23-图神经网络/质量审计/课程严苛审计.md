## 2. 本轮关键整改

### 2.1 作业从“规格存在”升级为可执行支架

- 新增 `starter/run_assignment.py` 统一入口。
- S01：随机游走共现、截断 SVD、拉普拉斯 embedding 和统一线性探针。
- S02：MLP/GCN/GraphSAGE/GAT 同 split、多 seed 对照。
- S03：最小图对比预训练、冻结探针与从头监督基线，明确不声称稳定增益。
- S04：dense/sparse attention 主项、score 内存和零边界估算，明确不是实测延迟。
- 四份阶段作业记录 `starter_entrypoint` 与 `starter_status: verified_worked_example`，并保留学习者独立提交要求。

### 2.2 修正 GraphSAGE 采样证据

- `sample_batch_subgraph` 现在从目标 batch 出发逐层展开，每个节点只展开一次，每行消息边不超过 fanout。
- fanout 训练只在 batch 目标节点计算 loss，记录 `sampled_nodes_mean`、`sampled_edges_mean`、`batch_size` 和 `training_mode`。
- reference 中 GraphSAGE full-neighborhood 与 `fanout=3` 的比较现在使用真实 batch 子图路径，不再把整张 `N×N` 邻接矩阵删边冒充小批训练。

### 2.3 修正指标与消融口径

- macro-F1 自动读取全部类别；三分类回归测试已覆盖原先二分类硬编码缺陷。
- `final_train_loss` 在恢复 validation 最优状态后重新计算，不再对应未选中的最后训练状态。
- 不再比较不同维度的 `embedding_variance`；统一记录最终 logits 的 `output_variance`。
- capstone 增加 GCN depth 4，与 depth 1/2、特征消融和 GraphSAGE fanout 形成一致的三类消融。

### 2.4 分离 reference 与学习者提交

- reference 移至 `reference/capstone/`。
- `submission/` 只保存学习者提交，并有独立 README 说明。
- capstone 作业、项目 README、测试和课程阶段 MOC 已同步新路径。

### 2.5 复现与来源

- 新增 `requirements-lock.txt`，记录本机实际验证的精确版本；范围型 `requirements.txt` 继续用于兼容安装。
- 来源索引补充 DGI/GraphCL 与 Graphormer，只填补自监督和结构编码两个明确缺口，不形成第二套 Spine。
- DGI、GraphCL、Graphormer、GRL 与 CS224W 链接已联网核验可达；许可继续采用论文链接或 `link-only` 边界。
