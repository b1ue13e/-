# 图神经网络-课后作业-01-图表示与随机游走

## 学习目标与任务边界

本作业验证图任务契约、邻接/拉普拉斯计算、随机游走统计和浅层 embedding 目标。不得直接调用 Node2Vec 黑盒得到最终报告；允许使用 NetworkX 检查边和路径。

## 任务

### L01-1 任务契约

为一个引用图分别写节点分类、链路预测、图分类的输入、输出、split 和指标；指出其中一个不适合 accuracy 的场景。

### L01-2 矩阵与谱

对 4 节点路径写 `A,D,L`，计算 `x=[0,1,1,3]` 的 `x^TLx`。说明零特征值与连通分量的关系，并写出一个高频方向不一定是噪声的反例。

### L01-3 随机游走

固定 seed=42、每节点 5 条游走、长度 8、窗口 2，输出转移计数和 manifest。说明行随机矩阵与列随机矩阵的约定，不能混用。

### L01-4 结构基线

用共现矩阵加 SVD 生成一个可复现的浅层 baseline；报告 embedding 维度、奇异值截断、下游分类器、固定 split 和 3 个 seed。不要把 SVD 结果称为 Node2Vec。

## 环境与运行

```powershell
python -m pytest -q
python your_solution.py --seed 42 --walk-length 8 --window 2 --output artifacts/l01
```

- 再写代码并断言每行转移计数等于游走步数；
- embedding 训练不得读取测试标签；
- [ ] 记录 `p/q` 或明确本题使用均匀游走；
