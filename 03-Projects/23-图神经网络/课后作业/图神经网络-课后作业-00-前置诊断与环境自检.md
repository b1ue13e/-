# 图神经网络-课后作业-00-前置诊断与环境自检

## 学习目标与任务边界

完成后应能独立运行 Python/NumPy/PyTorch，手算一个三节点图的 `A/D/L`，完成一次分类更新，并写出无泄漏 split。此任务不训练 GNN，不使用外部数据，不要求 GPU。

## 环境与复现

在项目根目录执行：

```powershell
python --version
python -c "import torch, networkx, numpy; print(torch.__version__, networkx.__version__, numpy.__version__)"
python -m pytest -q
```

记录 Python、Torch、NetworkX、NumPy、操作系统和 `pytest` 输出；若版本不同，说明差异而不是删掉失败日志。

## 题目

### L00-1 图矩阵

对路径 `0—1—2` 写出 `A`、`D`、`L=D-A`、加自环后的 `\tilde A`。用 `x=[0,1,3]^T` 验证 `x^TLx=5`，并解释每个矩阵的语义。

### L00-2 张量训练

运行 `图神经网络-PyTorch张量与分类训练最小桥接` 中的代码；把 `logits/y` 的形状写入报告，解释 `CrossEntropyLoss` 输入为什么不是概率。

### L00-3 split 审计

为 6 个节点设计不交的 train/val/test mask，写出 transductive 与 inductive 的结构可见边界。给出一个会泄漏测试边的链路预测流程，并修正它。

### L00-4 进入主线判断

闭卷回答：为什么 `A`、`X`、标签和指标不能只用一句“图数据”概括？未通过哪一项时，你会回到哪张前置卡？

## 提交产物

- `report.md`：L00-1 至 L00-4 的推导、形状和 split 说明；
- `environment.txt`：版本与测试输出；
- `diagnostic.py`：矩阵、mask 不交和 `x^TLx` 断言；
- 不提交课程卡的完整答案副本。

## Rubric（100 分）

- 图矩阵与二次型 30 分：矩阵正确、假设写清；
- 张量与训练 25 分：形状、loss 和更新职责正确；
- split 与泄漏 30 分：协议可执行、修正合理；
- 复现记录 15 分：命令、版本、失败和限制完整。

通过线：75 分，且 split 与泄漏部分不得低于 18 分。

## 引导与自检

- 先手算再运行，不要用代码输出反推公式；
- `diagnostic.py` 先断言 mask 交集为空，再打印结果；
- 测试失败时检查 dtype、节点编号和路径是否闭合；
- [ ] 没有把验证/测试标签送入 loss；
- [ ] 没有把 `D^{-1}A` 写成对称归一化；
- [ ] 没有把 toy smoke 分数写成 benchmark 结果。
