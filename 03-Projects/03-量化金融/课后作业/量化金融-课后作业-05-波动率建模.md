# 量化金融-课后作业-05-波动率建模

## 作业定位

本作业从“收益近似不相关但平方收益相关”进入 GARCH(1,1)，再在固定候选参数中按 Gaussian QML 选模并做一次冻结预测。它不要求扩散过程 MLE、自动优化器调参或滚动重估。

## 学习目标

识别波动聚集，正确实现条件方差递推，理解正性与弱平稳条件，并严格隔离训练段和预测段。

## 任务边界

- 只使用零均值 Gaussian QML 比较 fixture 提供的有限候选参数。
- 初始方差和候选集合均由 fixture 冻结，不得按测试结果增加候选。
- 不要求 EGARCH/GJR、GBM 扩散估计、滚动窗口搜索或真实行情。

## 题目细化

### Q1 波动聚集诊断（20 分）

1. 在训练段计算收益与平方收益前 20 阶 ACF。
2. 画两张同尺度图并报告前三个非零滞后的值。
3. 解释“线性相关弱”为什么不排除“条件方差可预测”。

### Q2 GARCH(1,1) 递推（25 分）

实现 `variance = omega + alpha * lagged_return**2 + beta * lagged_variance`。

1. 用每组候选参数从同一初始方差递推训练段。
2. 在运行前拒绝 `omega <= 0`、`alpha < 0`、`beta < 0` 或 `alpha + beta >= 1`。
3. 保留一个非法候选的失败测试。

### Q3 固定候选 Gaussian QML（25 分）

1. 对每组候选计算训练段负对数似然；所有候选必须出现在结果表。
2. 选择训练损失最小者，不允许查看预测段后重选。
3. 报告所选参数的长期方差、持久性 `alpha + beta` 和半衰期解释。

### Q4 冻结一步预测（30 分）

1. 从训练段最后状态开始，逐日做一步方差预测；预测长度由 fixture 指定。
2. 在每次预测后才吸收该日已实现收益，禁止提前读取未来收益。
3. 与“训练段方差常数”基线比较预测段 Gaussian QML，不以真实生成方差作为评分输入。
4. 说明本结论只适用于合成过程和固定候选集合。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| 方差出现负数 | 检查参数约束、初值和是否误用收益而非收益平方 |
| 所有候选损失相同 | 检查是否在循环中真正使用各自参数 |
| 预测异常好 | 搜索是否读取预测期未来收益或在测试段后重选候选 |

## 验收标准

训练段诊断、三类参数约束、全部候选损失和冻结预测均可复现；非法参数测试会失败；预测选择不接触预测段或生成真值。

## 失败条件

- 假定或反推生成真参数作为选模规则；
- 预测时使用未来收益；
- 只保留最优候选、删除失败候选；
- 引入未教授的扩散 MLE 或后看式超参数搜索。
