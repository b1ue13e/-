# 量化金融-课后作业-08-随机微积分与期权

## 作业定位

这份 lesson 题集把同一组 GBM/期权参数串成四个短任务：伊藤变换、解析定价、Greeks 数值核对、反变量 Monte Carlo。适应过程证明、控制变量和复杂对冲留给官方加练或 L09。

## 学习目标

能在声明条件下应用伊藤引理，检查 Black-Scholes 价格边界与 put-call parity，用有限差分核对 delta/gamma，并报告 Monte Carlo 置信区间。

## 任务边界

- 使用 fixture 的现货、行权价、利率、股息、波动率、到期日、路径数和置信度。
- 只实现欧式 vanilla 合约；不处理美式行权、随机波动率或跳跃过程。
- 反变量是必做方差缩减；控制变量是可选加分，不得成为隐性前置。

## 题目细化

### Q1 两个伊藤变换（20 分）

对 `dS = mu*S*dt + sigma*S*dW`：

1. 推导 `d log(S)`，指出二阶项的来源。
2. 推导 `d(S^2)`，说明与直接平方微分相比多出的项。
3. 用 Euler 小步模拟检查两条变换后的期望方向，明确这是数值 sanity check 而不是证明。

### Q2 Black-Scholes 与套利边界（25 分）

1. 计算欧式 call 与 put 解析价格。
2. 用 put-call parity 反推另一价格并比较误差。
3. 检查价格上下界，并解释股息率、利率和到期日的输入条件。

### Q3 Greeks 有限差分（25 分）

用 fixture 的 `epsilon` 对 spot 做中心差分。

1. 估计 delta 和 gamma，与解析 Greeks 对照。
2. 再用两个更小步长做敏感性表，说明截断误差与舍入误差的折中。
3. 不用差分结果宣称真实市场对冲效果。

### Q4 反变量 Monte Carlo（30 分）

1. 用风险中性 GBM 生成路径并定价 call；保存样本均值、标准误和 95% 置信区间。
2. 将 `Z` 与 `-Z` 配对，报告 plain 与 antithetic 两种估计的样本方差。
3. 与解析价格比较，说明置信区间是否覆盖解析值。
4. 控制变量作为可选项；若完成，单独报告它不是通过条件。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| parity 误差很大 | 检查 call/put 的贴现项和股息率符号 |
| gamma 对步长极敏感 | 检查中心差分、价格精度和 epsilon 记录 |
| 反变量方差更大 | 检查是否把 `-Z` 配错路径或把配对样本当两次独立均值 |

## 验收标准

两条伊藤变换写出二阶项；解析价格满足 parity 与边界；Greeks 误差在预先记录的容忍度内；antithetic 估计可复现且置信区间可解释。

## 失败条件

- 把 Itô 公式写成普通链式法则；
- 用解析价格调回 Monte Carlo 结果却不报告原始估计；
- 把可选控制变量当必做；
- 把合成 GBM 结果外推到真实波动率。
