# 量化金融课程作业总索引

> 作业题面、`requires`、Rubric 和状态只在三类规范作业文件维护。本页只提供顺序和 Dataview 入口；支持代码、合成数据和测试不维护第二份题面。

## 统一运行协议

1. 先完成作业 frontmatter 中 `requires` 指向的知识卡，再阅读整份题面。
2. 课后作业输入来自 `scripts/assignments/lesson_fixtures.py`；阶段作业 smoke 输入由 `scripts/assignments/generate_smoke_data.py` 写入 `data/smoke/`。
3. 每份作业按题面指定的 `submissions/<assignment_id>/` 结构提交；命令、Python 版本、退出码和失败配置必须保留。
4. starter 是公开参考实现和协议验证器，不是评分答案；学生实现必须通过相同不变量和自己的边界测试。
5. Qlib contract preflight 不等于 `qrun` 已执行；只有 `qrun.evidence.json` 的返回码为 0 才能记录执行通过。

```powershell
Set-Location "F:\-\03-Projects\金融与时序\03-量化金融"
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python scripts\assignments\generate_smoke_data.py
.\.venv\Scripts\python -c "from scripts.assignments.lesson_fixtures import qf_l01_fixture; print(qf_l01_fixture()['payoffs'].shape)"
.\.venv\Scripts\python -m pytest tests\assignments -q
```

每份课后作业的 `## 官方原题加练` 链接指向对应 MIT 18.S096 Problem Set。官方题与本地必做题独立计数；本地完成状态不代表已经完成 MIT 原题。
