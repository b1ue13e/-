# 量化金融-阶段作业-02-定价、时序与风险综合实验

## 学习目标

在固定样本边界下串联回归、波动率、VaR/ES、POT/GPD 和期权定价，并区分模型假设、估计误差与样本外证据。

## 任务边界

- CAPM、GARCH 和期权输入使用 `lesson_fixtures.py` 的固定 fixture；POT 使用项目内 60 条合成收益。
- GARCH 只比较预注册候选参数，不搜索测试集；POT 阈值固定为训练损失的 80% 分位。
- Black-Scholes 与 Monte Carlo 只处理欧式期权和常数参数。

## 题目细化

### S1 回归与残差（20 分）

用 `qf_l03_fixture()` 估计 CAPM alpha/beta，报告标准误、残差均值、残差与市场因子的内积，并保留影响点前后对照。

### S2 波动率与基础风险（25 分）

用 `qf_l05_fixture()` 的训练段比较三个 GARCH 候选，只按验证损失选定；在冻结预测段报告方差预测、Gaussian VaR 和历史 VaR/ES。

### S3 POT/GPD 尾部外推（25 分）

运行 canonical EVT 包，报告阈值、超阈值数、shape、scale、95% VaR 与 ES。若超阈值少于 8 或 shape 不支持有限均值，必须停止。

### S4 期权定价对照（30 分）

用 `qf_l08_fixture()` 对同一欧式 call 计算 Black-Scholes 与 Monte Carlo 价格；报告标准误、95% 置信区间、put-call parity 和无套利边界。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| ES 小于 VaR | 损失符号和尾部切片 |
| POT 参数无效 | 阈值、超阈值数和 `floc=0` |
| MC 偏离理论价 | 折现、风险中性漂移、标准误和种子 |

## 验收标准

四个模块使用一致时间边界；方法级不变量全部通过；至少保留一个模型失败或参数失效案例；结论明确区分合成数据、理论基准和样本外证据。

## 失败条件

- 使用测试集选择 GARCH 参数或 POT 阈值；
- 把收益左尾和损失右尾混用；
- 超阈值不足仍输出 GPD 结论；
- 把 Monte Carlo 一次运行误差解释成模型失效。
