# 量化金融-阶段作业-01-数据协议与无泄漏基线

## 学习目标

把字段、复权、信息时间、信号时间、执行延迟和成本写成可运行协议，并完成一个使用前一日信号的 MA5/MA20 基线。

## 任务边界

- 使用项目内合成 OHLCV 完成 smoke；真实数据只在来源、可得时间和许可齐全后替换。
- 策略只验证时间协议、成本恒等式和路径风险，不以收益高低评分。
- 不做参数搜索；窗口固定为 5/20，成本率固定为 5 bps。

## 题目细化

### S1 数据协议与字段审计（25 分）

为 `ohlcv.csv` 记录字段、单位、时区、频率、复权因子、交易日历和可得时间；验证日期唯一递增，OHLCV 与成交量为正。

### S2 无泄漏信号与执行（30 分）

计算调整收盘价、MA5、MA20 和信号；第 $t$ 日收益只能使用 $t-1$ 日及以前形成的仓位。输出 `signal`、`position`、`gross`、`turnover`、`cost`、`net`。

### S3 路径风险与恢复（20 分）

从 net 序列计算净值、running peak、drawdown、最大回撤起止点和恢复日期；样本结束仍未恢复时写 `unknown`。

### S4 泄漏负例（25 分）

故意令 `position_t = signal_t`，证明测试能识别未滞后版本。比较负例与规范实现，但不得把收益差异当成泄漏判据，判据必须来自信息时间。

## 引导自检

- [ ] `position[t]` 是否只由 `signal[t-1]` 决定？
- [ ] 成本是否只在仓位变化时产生且始终非负？
- [ ] 最大回撤是否从净收益路径而非 gross 路径计算？
- [ ] 负例失败原因是否落在信息时间而不是收益数字？

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| 信号未滞后 | `shift(1)` 的位置和缺失值处理 |
| net 不等于 gross-cost | turnover、成本单位和索引对齐 |
| 回撤为正 | running peak 或收益/净值口径写反 |

## 验收标准

三个公开不变量全部通过；数据协议能逐列复核；泄漏负例必须失败；提交包含命令、Python 版本、退出码和一次失败复盘。

## 失败条件

- 当日收盘特征用于当日收益；
- 为提高结果修改窗口、成本或测试区间；
- 只有最终收益，没有逐期时间与成本台账；
- 未知数据许可被写成已确认。
