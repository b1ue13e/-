# 量化金融-阶段作业-04-市场冲击与最优执行

## 学习目标

在库存守恒和固定窗口下比较 TWAP、VWAP 与连续 Almgren-Chriss 闭式轨迹的离散网格采样，并用事件台账估计队列消耗与条件成交概率。

## 任务边界

- smoke 只验证数学与台账；不声称复现真实交易所延迟、排队或冲击。
- Almgren-Chriss 使用常数波动率、临时冲击和风险厌恶参数；当前 runner 是连续闭式解的网格采样，不冒充离散差分模型的精确解，也不做参数校准。
- 队列模型采用单位消耗泊松假设，事件回放要求时间戳从 $t=0$ 开始；概率基线不把 `add_ahead` 当作泊松消耗，必须报告它对批量事件、前方新增和非平稳强度的失效边界。

## 题目细化

### S1 订单与事件台账（20 分）

定义新增、成交、前方撤单和后方撤单对队列位置的影响；逐事件输出初始队列、变化量和剩余队列，禁止用 L2 快照伪装精确 L3 队列。

### S2 三条执行轨迹（30 分）

对 120,000 股母单计算 TWAP、冻结成交量曲线下的 VWAP 和连续 Almgren-Chriss 闭式轨迹的离散采样；输出每期交易量、剩余库存和临时冲击成本估计。

### S3 队列成交概率（20 分）

运行单位消耗泊松近似，分别报告到达队首概率与自有订单成交概率；事件回放同时分别记录“到达队首”和“实际成交”，两者不一致时解释模型误差。

### S4 参数与失效边界（30 分）

分别扰动风险厌恶、波动率、临时冲击和前方撤单比例；报告轨迹或成交概率如何变化，并说明哪些参数必须由目标市场数据估计。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| 库存未归零 | 交易量与库存差分的索引 |
| AC 退化为随意缩放 | 双曲正弦库存路径和参数单位 |
| 成交概率越界 | 泊松 survival function 与队列单位 |

## 验收标准

两个 canonical runner 均退出 0；库存、成本和概率不变量通过；参数敏感性有方向解释；报告明确列出单位事件和合成数据边界。

## 失败条件

- 用任意比例缩放冒充 Almgren-Chriss；
- 用买卖方向占比冒充成交概率；
- 声称存在跨市场通用延迟、成交率或收益阈值；
- 库存或现金台账无法逐期复算。
