# 量化金融-课后作业-01-线性代数与概率基础

## 学习目标

用向量、矩阵和条件概率表达资产收益、协方差与线性组合，为 CAPM 和组合优化建立可计算的符号基础。

## 任务边界

1. 对给定收益向量计算均值、协方差、相关系数，并验证协方差矩阵半正定。
2. 推导线性组合的期望与方差，解释相关性变化对风险的影响。
3. 用蒙特卡洛模拟检查正态假设下的均值/方差收敛和尾部误差。

## 环境与执行

使用 Python 3.11、NumPy、SciPy；提交推导、可运行 notebook、图表和误差说明。评分：推导 30，计算 30，模拟 20，解释 10，可复现性 10。不得提交完整答案复制品。

## 提交产物

- 推导稿、可运行 notebook、协方差矩阵诊断、蒙特卡洛收敛图和误差说明。
- notebook 必须从干净内核运行，并记录 Python 与依赖版本；不得只提交截图。

## 验收标准

- 均值、协方差和线性组合方差与手算结果一致，协方差矩阵半正定检查通过。
- 模拟结果随样本量增加收敛，且报告说明正态假设在尾部的局限。

## 引导自检

- [ ] 先用二维小样本手算，再扩展到 NumPy 实现。
- [ ] 检查协方差矩阵对称性、特征值和维度。
- [ ] 改变随机种子后重新运行，确认结论不是单次模拟偶然结果。

## 运行证据与失败判定

- 提交二维手算表、NumPy 输出、特征值检查和随机种子；矩阵维度与对称性断言必须留在日志中。
- 协方差矩阵出现负特征值、概率和不为 1 或结果依赖单一随机种子时，判定为失败并说明原因。
- 至少保存一次边界输入（空样本、单观测或完全相关变量）的处理结果。

## 最小执行协议

1. 输入使用自行生成的二维与五维收益样本；记录分布参数、样本量和随机种子，不从真实市场表现倒推参数。
2. 先手算二维样本的均值、协方差、组合方差和条件概率，再用 NumPy 复算；手算与代码不一致时先定位口径，不继续扩展维度。
3. 对概率和、矩阵维度、对称性和半正定性写断言；完全相关、常数列、单观测与空样本必须给出明确错误或降级策略。
4. 改变样本量和种子至少三次，提交统计量分布而非单次输出；报告说明有限样本误差如何传递到组合风险。
5. 提交 `notebook/script`、命令日志、手算页、断言输出和一页解释。无法复跑或只贴截图均不通过。
