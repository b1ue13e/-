# 量化金融-课后作业-04-组合与因子模型

## 学习目标与任务

构造均值-方差组合与因子暴露；解释约束、估计误差、换手和风险预算；以等权和单因子组合为基线，完成样本外及参数扰动对照。

## 环境与执行

使用 Python 3.11、NumPy、pandas、SciPy；提交权重、暴露、成本与风险归因表。评分：模型 30，约束 20，样本外 25，解释 15，可复现性 10。

## 任务边界

- 在已教授的组合和因子模型范围内比较基线、约束组合与因子暴露；不要求实盘订单撮合。
- 所有标准化、去极值和中性化参数只能由训练区间估计。

## 提交产物

- 权重与因子暴露表、风险归因、成本/换手表、样本外对照和运行日志。
- 报告说明约束、估计误差、基准选择和结论失效条件。

## 验收标准

- 组合约束、暴露计算和收益归因通过测试；基线与策略使用同一日历和成本协议。
- 样本外结果至少包含收益、波动、回撤、换手和成本，而非单一 Sharpe。

## 引导自检

- [ ] 先确认因子和收益的日期对齐。
- [ ] 再检查权重和约束残差。
- [ ] 最后冻结参数后运行样本外与成本敏感性实验。

## 运行证据与失败判定

- 保存因子构造、日期对齐、标准化/中性化、权重约束残差、组合收益与成本分解。
- 因子暴露计算使用未来数据、权重未归一化或只展示毛收益时，判定为失败。
- 固定一套参数后分别运行样本外、换手成本加倍和去除单一因子实验，保留失败结果。

## 最小执行协议

1. 冻结资产池、因子定义、再平衡频率、中性化变量、训练/测试边界和交易成本；退市与缺失样本处理写入数据卡。
2. 先运行等权与单因子排序基线，再完成多因子组合；每个信号只使用调仓日前已公开的数据，公告滞后必须显式处理。
3. 保存原始暴露、去极值、标准化、中性化与组合权重的逐步结果，并对权重和、杠杆、行业暴露写断言。
4. 在冻结参数后运行样本外、成本加倍、单因子剔除和子区间实验；不得只保留改善结果。
5. 提交数据卡、配置、脚本、因子覆盖表、成本分解、失败案例和命令日志；无法区分毛收益与净收益不通过。

**最低通过判据**：日期可得性、权重约束和交易成本三类检查全部通过；样本外同时报告收益、回撤、换手、暴露与容量限制。因子在成本后失效时必须保留并解释。
