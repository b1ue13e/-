# 量化金融-大作业-策略回测与风险控制

## 学习目标

以单一流动性较好的资产或资产组合为对象，比较一个简单基线和一个可解释因子策略，建立不会把未来信息泄漏进回测的研究流程。

## 任务边界

- 价格使用复权口径，并保留原始 OHLCV 与数据版本。
- 信号在收盘后生成，最早下一根 K 线成交；显式扣除手续费、滑点和换手成本。
- 使用 walk-forward 或 purged CV；测试集只允许在最后一次评估使用。
- 不以单一 Sharpe 排名，必须同时报告最大回撤、Calmar、换手、尾部损失和分年度表现。

## 提交产物

- [ ] 实现 naive buy-and-hold 与等权再平衡基线。
- [ ] 实现一个动量或价值因子，并完成去极值、标准化和行业/规模中性化说明。
- [ ] 加入交易成本、滑点、持仓上限和最大回撤熔断规则。
- [ ] 做参数扰动、子区间、替代数据源和安慰剂检验。
- [ ] 用历史模拟 VaR 与 CVaR 做组合层风险报告，并解释超限原因。

## 验收标准

- [ ] 任意结果都能追溯到数据版本、信号日期和成交日期。
- [ ] 报告同时给出毛收益、净收益、成本占比和风险归因。
- [ ] 明确策略失效、停止交易和重新研究的触发条件；不输出投资建议。

## 引导自检

- [ ] 先冻结数据、基线、时间切分和成本假设。
- [ ] 再实现信号、风险约束和样本外回测。
- [ ] 最后完成压力、安慰剂和失败案例分析。

## 运行证据与失败判定

- 固化数据版本、研究协议、参数配置、交易成本、日志和报告；同一命令可重建全部表图。
- 信号与成交时间倒置、样本外窗口参与调参、成本后收益未披露或风险熔断不可复现时，判定为失败。
- 结果必须包含等权/买入持有基线、失败策略、压力情景和停止交易条件，不以单一 Sharpe 宣称成功。

## 研究阶段门禁

1. 数据门禁要求原始数据摘要、复权/退市处理和信号可得时间全部可追溯；任一日期泄漏即回到数据阶段。
2. 基线门禁要求买入持有与等权再平衡均可复跑，收益、换手和成本口径与主策略完全相同。
3. 模型门禁要求参数只由训练/验证集确定，仓位、杠杆、流动性和最大回撤约束均有自动断言。
4. 稳健性门禁要求至少完成参数扰动、子区间、成本加倍、安慰剂和极端行情实验，并保留失败结果。
5. 发布门禁要求测试集只使用一次，报告含风险归因、失败条件、停止交易与重新研究规则；任何门禁未通过均不得标记完成。

最终提交包含协议、数据卡、配置、源码、测试、日志、逐笔或逐日持仓、机器可读指标和研究报告。所有结论都必须能反向定位到输入版本、信号日期、成交日期和成本假设。
