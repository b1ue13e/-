## 题目

### Q1｜信息与条件期望（20 分）

独立抛两次公平硬币，$H_i\in\{0,1\}$，$X=2H_1+H_2$，$\mathcal G=\sigma(H_1)$。

1. 写出 $E[X\mid\mathcal G]$ 的两个可能取值。
2. 用定义中的积分一致性验证结果。
3. 令 $\mathcal F_0\subset\mathcal F_1\subset\mathcal F_2$ 为自然滤过，判断 $X_t=H_{t+1}$（$t=0,1$）是否适应，并解释。

### Q2｜收敛模式（20 分）

对 $Z\sim N(0,1)$ 和 $X_n=Z/n$：

1. 证明 $X_n\to0$ 于 $L^2$ 与几乎处处意义。
2. 画出 a.s./概率/$L^1$/$L^2$ 的有效蕴含图。
3. 用独立事件 $P(A_n)=1/n$、$Y_n=\mathbf1_{A_n}$ 解释为什么 $L^2$ 不一般推出 a.s.。

### Q3｜随机矩阵与 PGF（30 分）

给定

$$
P=\begin{pmatrix}0.8&0.2\\0.3&0.7\end{pmatrix}.
$$

1. 检查 $P$ 的合法性并求平稳分布。
2. 手算 $P^2$，从状态 0 出发求两步后位于状态 1 的概率。
3. 对 $N\sim\operatorname{Poisson}(4)$，从 PGF 推导均值与方差。
4. 解释周期链为什么可能有平稳分布但 $P^n$ 不收敛。

### Q4｜环境自检（30 分）

1. 运行全部测试并保存真实终端输出。
2. 运行：

```powershell
python scripts/stochastic_process_lab.py all --seed 20260808 --output submission/SP-L00/reference-check.json
```

3. 核对 JSON 至少包含 `markov/poisson/brownian/mm1/ou`。
4. 任选一项说明理论值、经验值、偏差和有限样本解释。
