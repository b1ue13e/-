# 🧭 随机过程课程作业总索引

> 本页是作业唯一入口。当前交付为 7 份 lesson、4 份 stage 和 1 份 capstone；实际状态由作业文件的 `assignment_level`、`stage_id`、`assignment_format` 和 `requires` 派生，本页不复制静态映射。

## 使用顺序

1. 从[[🗺️ 随机过程学习路径]]进入当前阶段，按阶段 MOC 的有序清单学习。
2. 完成紧密知识点对应的课后作业，再完成阶段整合作业。
3. 代码、推导、图表、失败记录和环境信息进入个人 `submission/`；不要覆盖参考脚本或测试。阶段作业必须先完成对应 lesson；capstone 必须在四个阶段出口均通过后开始。
4. `planned` 表示任务规格可用，不表示已经执行、通过或得到分数。

## 参考运行入口

课程提供不含答案的最小实验工具：

```powershell
python scripts/stochastic_process_lab.py all --output artifacts/reference-run.json
python -m unittest discover -s tests -v
```

参考输出用于验证工具链，不替代学习者的推导、实验设计、敏感性分析和报告。

## 统一通过口径

- 课后/阶段作业：至少 80/100，且无条件遗漏、来源不可追溯、伪随机复现或结论越界。
- 大作业：至少 85/100，必须包含理论基线、模拟验证、失败案例、限制与复现命令。
- 任一数值结论必须记录随机种子、样本量、步长和环境；未运行不得标记 `completed`。
- 参考运行包含 Markov、Poisson、Brownian、反射原理、赌徒破产、M/M/1、OU 和 GBM 误差研究；它只证明工具链可用，不替代个人提交。
