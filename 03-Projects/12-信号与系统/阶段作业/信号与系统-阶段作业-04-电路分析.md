## 2. 学习目标

完成本作业后，你应当能够：

- 用阻抗法由电路直接写出 [[系统函数]] `H(s)=Vout/Vin`；
- 用 [[拉普拉斯变换]] 求阶跃响应的时域表达式并解释暂态/稳态；
- 把电路仿真与解析解对照，验证模型正确；
- 分析 RLC 的谐振峰与 `Q` 值关系。

## 3. 所需知识（requires）

- [[拉普拉斯变换]]:把微分方程变成代数、求逆变换得时域。

## 4. 任务背景与边界

**背景**：滤波器、均衡器最终都落在电路上。能用拉普拉斯从电路得到 `H(s)` 并预测响应，是“信号与系统”与“电路”的桥梁。

**输入**：RC 低通 / RLC 带通电路参数。

**输出**：`H(s)`、阶跃响应解析与仿真、谐振分析。

**边界**：

- `H(s)` 必须来自阻抗法（`Z_C=1/(sC)`、`Z_L=sL`），不凭记忆抄公式；
- 逆拉普拉斯可用部分分式 + 查表，须写出过程；
- 允许用电路仿真库，但解析对照由你完成。

## 5. 详细题目

### P1 手算 / 推导（基础，必做）

RC 低通：`R=1 kΩ`、`C=1 µF`，`H(s)=1/(1+sRC)`。

1. 求 `-3 dB` 截止角频率 `ωc=1/(RC)`，给出数值（Hz）；
2. 对单位阶跃输入，用逆拉普拉斯求 `vout(t)=1-e^{-t/RC}`，写出时间常数 `τ=RC`；
3. 说明稳态增益为 1、暂态以 `τ` 衰减。

### P2 实现（编程，必做）

编写 `circuit_analysis.py`：

- 用 `scipy.signal` 或自写差分，对 RC 低通做阶跃仿真，对照 P1 解析 `1-e^{-t/τ}`（容差 1e-3）；
- 画出阶跃响应曲线与误差；
- 用 `freqs` 画幅度响应，标出 `-3 dB` 点验证 `ωc`。

### P3 应用 / 分析（综合，必做）

RLC 串联带通（`R=10 Ω`、`L=1 mH`、`C=1 µF`）。求谐振频率 `f0=1/(2π√LC)` 与品质因数 `Q=(1/R)√(L/C)`，说明 `Q` 越大谐振峰越尖锐；仿真其阶跃/冲激响应，观察过冲与振荡随 `Q` 增大的变化。

## 9. 引导与自检

- **检查点**：RC 阶跃应单调升至 1，时间常数 `τ=RC`；若仿真过冲，检查是否误用 RLC 参数。
- **常见失败**：阻抗法写错（电容写成 `sC` 而非 `1/(sC)`）；`Q` 公式分母分子颠倒。
- **调试方向**：先用直流（s=0）验证 `H(0)` 是否符合电路直觉（RC 低通通直流）。
- **提交前清单**：① P1 给出 `ωc` 与 `vout(t)`；② P2 对照误差数值；③ P3 给出 `f0`、`Q`。
