## 作业定位
- 作业模块：卷积图解法与 LTI 系统互联
- 覆盖范围：连续/离散卷积的**图解法四步**（反转—平移—相乘—积分/求和）、卷积**代数性质**（交换/结合/分配/时移/恒等）的证明与手算、LTI 系统的**互联结构**（级联/并联/反馈）如何化简为单个冲激响应或系统函数。
- 本 HW 的位置：[[信号与系统-课后作业-HW07-卷积与LTI系统响应|HW07]] 已把卷积"算对 + 用代码画出来"。本 HW 进一步把卷积从"能算"升到"能几何地看见每一步、能证明它的代数性质、能把多个系统互联化简"——这是读图（看波形推结果）、做证明题、以及后续分析滤波链/反馈控制的理论地基。
- 验收方式（三轨）：手绘图解（闭卷）+ 代数证明（推导）+ 互联化简（系统函数），对接 100 分 Rubric（图解 35 + 性质证明 35 + 互联化简 30）。

## 所需知识（requires）
- [[冲激响应重要性]]：为何 LTI 系统完全由 `h(t)`/`h[n]` 表征（叠加+时不变 ⇒ 任意输入=冲激叠加）。
- [[图解法反转]]/[[图解法平移]]/[[图解法换元]]/[[图解法滑动]]/[[图解法相乘]]/[[图解法积分]]：图解法的六步分解，每一步对应一个可独立验证的几何操作。
- [[卷积交换律]]/[[卷积结合律]]/[[卷积分配律]]/[[卷积时移性质]]/[[卷积恒等]]：五个核心代数性质，本 HW 要求能证明其中三个。
- [[卷积变量]]：卷积中"哑变量"的本质（积分/求和变量与输出变量分离），避免变量混淆。
- [[级联系统]]/[[并联系统]]/[[反馈系统]]：系统互联的冲激响应/系统函数化简规则。
- [[系统表征]]：时域（h）/频域（H）/系统函数（传递）三种等价表征及其换算。
- [[因果性判断]]：从 `h(t)=0 (t<0)` / `h[n]=0 (n<0)` 判定因果性，互联后因果性如何保持。

## 引导自检
提交前自检清单：
- [ ] 图解法的"反转"作用在**哪个变量**？是 `h(t)` 关于 `τ=0` 反转为 `h(-τ)`，再平移为 `h(t-τ)`？
- [ ] 离散卷积长度是否仍为 `L+M-1`？逐 `n` 列出时有没有漏掉 `h[n-k]` 中 `k` 的合法范围？
- [ ] 证明交换律时，换元 `λ=t-τ`（或 `m=n-k`）后积分/求和限是否同步变换正确？
- [ ] 级联 `h = h1*h2` 与并联 `h = h1+h2` 有没有写反？反馈回路是否化简成了 `H/(1+GH)`？
常见失败点：把 `h(t-τ)` 误写成 `h(τ-t)`（反转方向反）；证明中换元后忘记同步改变积分限；级联与并联规则混淆。调试策略：先固定一个 `t`/`n` 在纸上画出 `x(τ)` 与 `h(t-τ)` 的重叠条带，肉眼核对乘积区间，再动笔写解析式。

## 子题

### P1 · 图解法手算（闭卷）
- [ ] 设 `x(t)=u(t)-u(t-1)`（单位高度、宽度 1 的矩形脉冲），`h(t)=e^{-t}u(t)`。用图解法求 `y(t)=x*h`，分 `t<0`、`0≤t<1`、`t≥1` 三段写出解析式，并说明每段"重叠区间"如何随 `t` 变化。
- [ ] 离散序列 `x[n]=[1,2,2,1]`（三角窗），`h[n]=[1,-1]`。按"反转—平移—相乘—求和"逐步列出 `n=-1,0,1,2,3,4` 时 `h[n-k]` 与乘积累加，给出 `y` 的六点值，并用 `len(x)+len(h)-1=6` 验算长度。
- [ ] 用图解法解释"为何 `x*h` 的支撑区间 = 两者支撑区间之和"（给一个具体例子，画出边界平移）。

### P2 · 代数性质证明（推导）
- [ ] **交换律**：由定义 `y(t)=∫x(τ)h(t-τ)dτ`，令 `λ=t-τ`，证 `x*h = h*x`，并给出"输入与系统可互换"的物理直觉。
- [ ] **结合律**：证 `(x*h1)*h2 = x*(h1*h2)`，用哑变量换元说明"先卷积哪个"不影响总冲激响应——这正是级联系统可交换顺序的依据（接 [[卷积结合律]]）。
- [ ] **分配律**：证 `x*(h1+h2) = x*h1 + x*h2`，说明并联系统的总响应等于各支路响应之和（接 [[卷积分配律]]）。
- [ ] **时移性质**：若 `y=x*h`，证 `x(t-t0)*h = y(t-t0)`，并解释"时不变"在卷积中的体现（接 [[卷积时移性质]]）。
- [ ] **恒等**：证 `x*δ = x`（冲激是卷积单位元，接 [[卷积恒等]]），并说明为何系统接一个 `h=δ` 的"系统"等于原样通过。

### P3 · LTI 系统互联化简
- [ ] **级联**：系统 A 冲激响应 `h1[n]=0.5^n u[n]`，系统 B 冲激响应 `h2[n]=δ[n]-δ[n-1]`。求级联总冲激响应 `h[n]=h1*h2`，写成闭式并判因果性。
- [ ] **并联**：两系统 `h_a(t)=e^{-t}u(t)`、`h_b(t)=e^{-2t}u(t)` 并联，求总 `h(t)` 与对应系统函数 `H(s)=H_a(s)+H_b(s)`，并判稳定性（极点位置）。
- [ ] **反馈**：单位负反馈，前向 `G(s)=1/(s+1)`，反馈 `H(s)=1`。用化简公式 `T=G/(1+GH)` 求闭环传递函数，给出极点并判稳定性；若 `H(s)=s` 会怎样（振荡/不稳定）？

### 衔接预习（不计入 Rubric，指向 HW04/HW05）
- 多系统级联在频域变成相乘：`Y=X·H1·H2`，这正是滤波链分析的入口（见 [[信号与系统-课后作业-HW03-连续傅里叶变换|HW03]]/[[信号与系统-课后作业-HW05-拉普拉斯变换|HW05]]）。
- 反馈系统的稳定性判据在 `s`/`z` 域更直观（极点全在 LHP / 单位圆内），见 [[信号与系统-课后作业-HW05-拉普拉斯变换|HW05]] 与 [[信号与系统-课后作业-HW06-Z变换与数字滤波器|HW06]]。

## 参考实现思路
- 图解法自检：`import numpy as np, matplotlib.pyplot as plt`；对离散情形画 `x[k]`（固定）与随 `n` 平移的 `h[n-k]`，用 `axvspan` 标出重叠区。
- 结合律几何直觉：把 `(x*h1)*h2` 想象成"先把 x 过 h1 再过 h2"，与"先把 h1、h2 合成为一个总核再过 x"等价。
- 反馈化简：`T = G/(1+G*H)`，注意 `GH` 是环路增益乘积，极性（正负反馈）决定分母符号。

## 检索练习与常见误区（闭卷，不翻书）
**检索练习**
- 闭卷画出离散图解法"反转—平移—相乘—求和"四步中 `h[n-k]` 随 `n` 变化的形状。
- 写出卷积结合律并用一句话解释其物理含义。
- 负反馈闭环传递函数 `T` 的分母是什么？

**常见误区 / 反例**
- 误区：`h(t-τ)` 与 `h(τ-t)` 等价。**反例**：前者是"先反转再右移 t"，后者是"先反转再左移 t"，卷积结果完全错。
- 误区：并联总响应是各 `h` 卷积。**反例**：并联是**相加** `h1+h2`，只有级联才是卷积 `h1*h2`。
- 误区：交换律意味着"先过哪个系统无所谓，响应波形也无关"。**反例**：总响应 `y` 确实相同（结合律/交换律保证），但**中间信号**不同；两个系统若非线性则交换律不成立。
