## 引导自检
提交前自检清单：
- [ ] 手算结果与自写代码数值一致（误差 < 1e-10）？
- [ ] 频谱是否做了 `fftshift`、频率轴单位是否正确？

常见失败点：卷积下标 `n-m` 越界；窗函数旁瓣被误判为噪声；高于奈奎斯特的频率「伪装」成低频（混叠）未识别。调试策略：先在小 N、合成信号上验证核心算法，再上真实数据；对照 numpy/scipy 逐项排查。

## 子题

### P1 · 手算（闭卷）

- [ ] 求周期方波（占空比 50%）的指数 FS 系数 c_k，说明为何只有奇次谐波、幅度 ∝ 1/k。
- [ ] 求周期三角波（Λ 形）的 FS 系数（应为 1/k² 衰减），对比方波说明「更平滑⇒高频衰减更快」。

### P2 · 实现（numpy）

- [ ] 自写函数 fs_coeff(x, T, N) 用数值积分（梯形法）估计前 N 个复系数 c_k，并与解析结果对照。
- [ ] 用前 N=5/15/50 项重建方波，画出重建波形，定量展示吉布斯过冲（约 9%）。

### P3 · 应用（谐波分析）

- [ ] 对一段周期音频（或合成多频信号）做谐波分析，画出前 20 根谐波的幅度谱，指出基频与主要谐波。

## 参考实现思路
系数估计：`ck = (1/T)*trapz(x*exp(-1j*k*w0*t), t)`；重建：`xr=sum_k ck*exp(1j*k*w0*t)`；吉布斯过冲在跳变处约 8.95%。

## 验收标准与 Rubric
- 正确性（40%）：方波/三角波 FS 系数推导正确；数值系数与解析一致（误差 < 1e-3）。
- 完整性（25%）：完成 P1 两问 + P2 重建 + P3 谐波谱。
- 可复现性（20%）：固定信号参数，他人可复现。
- 解释质量（15%）：能解释 1/k 与 1/k² 衰减差异及吉布斯现象成因。
