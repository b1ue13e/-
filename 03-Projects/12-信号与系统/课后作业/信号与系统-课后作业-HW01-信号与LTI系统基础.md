- 把方法用到真实信号/音频上，解释结果中关键现象（收敛、泄漏、混叠、边界效应等）的成因与工程取舍（P3）。

## 引导自检
提交前自检清单：
- [ ] 手算结果与自写代码数值一致（误差 < 1e-10）？
- [ ] 频谱是否做了 `fftshift`、频率轴单位是否正确？
- [ ] 长度与零填充是否满足避免循环卷积混叠的条件（≥ L+M-1）？
- [ ] 固定 `seed=42`，他人能否独立复现？
常见失败点：卷积下标 `n-m` 越界；窗函数旁瓣被误判为噪声；高于奈奎斯特的频率「伪装」成低频（混叠）未识别。调试策略：先在小 N、合成信号上验证核心算法，再上真实数据；对照 numpy/scipy 逐项排查。

## 子题

### P1 · 手算（闭卷）

- [ ] 给定 x(t)=u(t)-u(t-2) 与 h(t)=e^{-t}u(t)，手算连续卷积 y(t)=x*h，分段写出结果并画图草图。
- [ ] 判断下列系统是否线性 / 时不变 / 因果：(a) y(t)=x(t)+1；(b) y(t)=x(2t)；(c) y(t)=x(t-1)。给出理由。
- [ ] 证明特征函数性质：对 LTI 系统，输入 e^{st} 时输出 = H(s)e^{st}，写出 H(s) 的卷积表达式。

### P2 · 实现（numpy）

- [ ] 不调用 numpy.convolve，自写离散卷积和函数 my_conv(x,h)（双重循环），并与 numpy.convolve 对照，误差 < 1e-10。
- [ ] 用 my_conv 对一段合成信号做 3 点、5 点滑动平均（MA 滤波器），画出原信号与平滑后信号。

### P3 · 应用（真实音频）

- [ ] 用 soundfile 读取一段示例音频，构造一阶差分 h[n]=δ[n]-δ[n-1] 与一阶累加（积分）滤波器，分别作用后对比波形与频谱（用 numpy.fft）。
- [ ] 解释为何差分近似微分、累加近似积分，并讨论边界效应。

## 参考实现思路
实现题骨架：my_conv 用 `for n in range(L+M-1): y[n]=sum(x[m]*h[n-m] for m in range(M))`；音频用 `soundfile.read` 得 (data, sr)，单声道处理；频谱 `np.abs(np.fft.rfft(x))`。
