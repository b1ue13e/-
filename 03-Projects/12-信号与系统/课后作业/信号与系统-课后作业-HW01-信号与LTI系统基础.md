## 三、知识速查（你需要知道）

> 只列本题直接用到的最小集合；完整推导看对应知识卡。

- **卷积（连续）**：`y(t)=x*h = ∫_{−∞}^{∞} x(τ)h(t−τ)dτ`；支撑区间 = 两信号支撑区间之和。
- **卷积（离散）**：`y[n]=Σ_k x[k]h[n−k]`，结果长度 `L+M−1`。
- **LTI 判定三性质**：
  - 线性：输入 `a·x₁+b·x₂` ⇒ 输出 `a·y₁+b·y₂`；
  - 时不变：`x(t−t₀)` ⇒ `y(t−t₀)`；
  - 因果：输出只依赖 `t≤t₀` 的输入。
- **特征函数**：对 LTI 系统，输入 `e^{st}` ⇒ 输出 `H(s)e^{st}`，其中 `H(s)=∫h(t)e^{−st}dt`（系统的特征函数性质）。

### 卷积几何（翻转—平移—相乘—求和）

```
  h[k]  ──翻转──▶  h[-k]  ──平移 n──▶  h[n-k]
       对每一个 n：x[k] · h[n-k] 相乘后求和  =  y[n]

  几何直觉：随 n 增大，h[n-k] 像一扇窗在 x 上向右平移，
  窗内逐点相乘再累加，就得到该 n 处的输出 y[n]。
```

## 六、子题

### P1 · 手算（闭卷，35 分）

> 先看作例，再独立做其余。

**【示范例题】** 已知 `x=[1,2]`、`h=[1,1,1]`，求 `y=x*h`。
按定义 `y[n]=Σ_k x[k]h[n−k]`：
- `n=0`: `x[0]h[0]=1·1=1`
- `n=1`: `x[0]h[1]+x[1]h[0]=1·1+2·1=3`
- `n=2`: `x[1]h[1]=2·1=2` ⇒ `y=[1,3,2]`（长度 `2+3−1=4`? 注意此处 `x` 长 2、`h` 长 3 ⇒ `2+3−1=4`，实际 `y` 应 4 点，补 `n=3: 0`）。✎ 自检见下文「引导自检」。

**【完成题（渐隐支架）】** 已知 `x=[1,2,1]`、`h=[1,1]`，按「翻转—平移—相乘—求和」列出 `n=0,1` 时 `h[n−k]` 与乘积累加（已给出），**请补全 `n=2,3`** 并写出 `y` 的四点值。
- `n=0`: `h[0−k]` 仅 `k=0` 非零 ⇒ `y[0]=1`
- `n=1`: `k=0,1` ⇒ `1·1+1·1=2`

**【独立题】**
1. 给定 `x(t)=u(t)−u(t−2)` 与 `h(t)=e^{−t}u(t)`，手算连续卷积 `y(t)=x*h`，分段写出结果并画草图。
2. 判断下列系统是否线性 / 时不变 / 因果，给出理由：(a) `y(t)=x(t)+1`；(b) `y(t)=x(2t)`；(c) `y(t)=x(t−1)`。
3. 证明特征函数性质：对 LTI 系统，输入 `e^{st}` 时输出 `=H(s)e^{st}`，写出 `H(s)` 的卷积表达式。

### P2 · 实现（numpy，35 分）

1. 不调用 `numpy.convolve`，自写离散卷积 `my_conv(x,h)`（双重循环），与 `numpy.convolve` 对照，误差 `<1e-10`。
2. 用 `my_conv` 对一段合成信号做 3 点、5 点滑动平均（MA 滤波器），画出原信号与平滑后信号。
3. 把任意实序列分解为偶部 `x_e=(x+x[−n])/2` 与奇部 `x_o=(x−x[−n])/2`，验证 `x_e+x_o=x` 且 `x_o[0]=0`；再分解为直流 `DC=mean(x)` 与交变 `AC=x−DC`，验证 `mean(AC)=0`。（训练「信号表示与对称性化简」，是后续卷积与傅里叶展开的前置手感。）

### P3 · 应用（真实音频，30 分）

1. 用 `soundfile` 读取一段示例音频，构造一阶差分 `h[n]=δ[n]−δ[n−1]` 与一阶累加（积分）滤波器，分别作用后对比波形与频谱（`numpy.fft`）。
2. 解释为何差分近似微分、累加近似积分，并讨论边界效应（序列两端的不对称处理）。

**常见误区 / 反例**
- 误区：卷积 `x*h` 结果长度等于 `max(L,M)`。**反例**：`[1,2]*[1,1,1]` 得 4 点（=`L+M−1`）。
- 误区：`y(t)=x(2t)` 是时不变。**反例**：输入延时 ⇒ 输出被压缩而非延时 ⇒ 时变。
- 误区：因果系统必稳定。**反例**：`h(t)=e^{t}u(t)` 因果但发散，不稳定。
