## 2. 学习目标

完成本作业后，你应当能够：

- 由给定通带/阻带指标计算 [[巴特沃斯]] 滤波器所需阶数；
- 写出或导出数字滤波器的 [[系统函数]] `H(z)`（分子/分母系数）；
- 用 `freqz` 绘制并验证频率响应；
- 把滤波器应用于含噪信号完成去噪并评估效果。

## 3. 所需知识（requires）

- [[巴特沃斯]]：最大平坦低通原型与阶数公式。
- [[系统函数]]：`H(z)=B(z)/A(z)` 的系数表示与频率响应。

## 4. 任务背景与边界

**背景**：滤波器是“按频率挑选成分”的工具。给定“保留 <100 Hz、抑制 >200 Hz”的指标，需要量化阶数并验证。

**输入**：含噪信号（有用低频 + 高频噪声）。

**输出**：阶数、系数、频响图、去噪结果。

**边界**：

- 阶数计算须给出公式与代入过程，不能直接调库取 `N` 后当手算；
- 验证必须用 `freqz` 检查通/阻带衰减是否达标；
- 允许用 `scipy.signal.butter` 出系数，但阶数由你先算。

## 5. 详细题目

### P1 手算 / 推导（基础，必做）

指标：采样 `fs=1000 Hz`，通带边 `fp=100 Hz`、通带波纹 `Rp=1 dB`，阻带边 `fsb=200 Hz`、阻带衰减 `Rs=30 dB`。给出巴特沃斯阶数公式 `N ≥ log10((10^{Rp/10}-1)/(10^{Rs/10}-1)) / (2·log10(Ωp/Ωs))`（预扭曲后），代入计算最小整数 `N`，并说明模拟归一化截止 `Ωc`。

### P2 实现（编程，必做）

编写 `filter_design.py`：

- 用 P1 的 `N` 与 `butter` 设计数字低通，打印 `b, a`（即 [[系统函数]] 系数）；
- 用 `scipy.signal.freqz` 画幅度响应（dB），标出通带/阻带边，验证 `Rp`、`Rs` 满足；
- 把该滤波器作用于 `useful=sin(2π·50t) + 0.5·sin(2π·300t)`（噪声为 300 Hz），输出去噪后信号。

### P3 应用 / 分析（综合，必做）

对比 `N`（P1 值）与 `N+2` 两版滤波器的阻带衰减与过渡带宽，画出两者频响叠图，说明“更高阶 = 更陡但可能数值更敏感”，并在去噪 MSE 上量化差异。

## 6. 环境与复现

## 9. 引导与自检

- **检查点**：设计的滤波器在 100 Hz 处衰减应 ≤1 dB、在 200 Hz 处 ≥30 dB；若不满足，先查 `N` 是否取小了。
- **常见失败**：通/阻带边与 `Wn` 归一化混淆（应除以 `fs/2`）；阶数公式分子分母写反。
- **调试方向**：先用 `freqz` 画一条裸频响，肉眼核对两个边频的 dB 值。
- **提交前清单**：① P1 给出整数 `N`；② P2 有系数与频响图；③ P3 两版对比图。
