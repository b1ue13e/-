## 2. 学习目标

完成本作业后，你应当能够：

- 用一阶差分（高通）在 1D/2D 信号上定位突变（边缘）；
- 解释直接用差分会被噪声放大的原因，并用 [[窗函数]]（高斯）平滑后的导数（LoG 思路）抑制噪声；
- 用 [[巴特沃斯]] 高通作为另一种边缘增强方式并比较；
- 在含噪阶跃/方块图像上定量比较“裸差分”与“平滑后差分”的定位误差。

## 3. 所需知识（requires）

- [[窗函数]]：用窗（如高斯）平滑以抑制噪声。
- [[巴特沃斯]]：高通滤波器强调高频（边缘）。

## 4. 任务背景与边界

**背景**：边缘即“变化剧烈处”。差分能找边缘，但噪声也是高频，会被一并放大。工程上用“先平滑再微分”或高通滤波权衡。

**输入**：含噪阶跃 1D 信号或含方块边界的小图像。

**输出**：边缘图/边缘位置、两种方法的对比。

**边界**：

- 1D 与 2D 任选其一深入，另一可简述；推荐 1D 为主、2D 用 `scipy.ndimage` 简单演示；
- 高斯标准差 `σ` 须作为可调参数并讨论；
- 允许用 `scipy` 工具，但差分/滤波组合由你实现。

## 5. 详细题目

### P1 手算 / 推导（基础，必做）

对离散阶跃 `x = [0,0,0,1,1,1]`（在 `n=3` 处跳变），写出前向差分 `d[n]=x[n]-x[n-1]` 的六点值，指出边缘位置对应 `d` 的非零点。说明若 `x` 叠加 ±0.3 噪声，差分会如何被“污染”（给出含噪差分的示例两点值）。

### P2 实现（编程，必做）

编写 `edge_detect.py`：

- 对含噪阶跃信号（`seed=0`，噪声 `0.3·randn`）分别做：① 裸差分；② 先高斯窗平滑（`σ=1`）再差分（近似 LoG）；
- 用 [[巴特沃斯]] 高通滤波作为第三种，画出三者边缘响应；
- 比较边缘峰值位置与真实跳变点 `n=3` 的偏差。

### P3 应用 / 分析（综合，必做）

对 2D 小图像（如 `64×64` 含一个亮方块）用 `scipy.ndimage.gaussian_filter` + 梯度求边缘，再用 `sobel`/高通对照，说明“先平滑后微分”为何比裸差分更干净，并讨论 `σ` 越大边缘越粗的权衡。

## 9. 引导与自检

- **检查点**：边缘峰值应出现在真实跳变点附近；若裸差分峰被噪声淹没，先确认噪声幅度并减小或直接对比平滑法。
- **常见失败**：把 `σ` 当“越大越好”（边缘变粗、位移）；2D 梯度未取 `sqrt(gx²+gy²)`。
- **调试方向**：先用无噪阶跃验证差分峰值位置，再加噪对比两种方法。
- **提交前清单**：① P1 给出差分六值；② P2 三种响应对比图；③ P3 有 2D 边缘图。
