## 2. 学习目标

完成本作业后，你应当能够：

- 由可闻频带（20 Hz–20 kHz）由 [[采样定理与混叠]] 推出 CD 级 44.1 kHz 采样率的由来；
- 用合成“音频”信号演示欠采样导致的频谱混叠；
- 在降采样前加入抗混叠低通并验证混叠被抑制；
- 比较“直接降采样”与“先抗混叠再降采样”的频谱差异。

## 3. 所需知识（requires）

## 4. 任务背景与边界

**背景**：CD 用 44.1 kHz 而非刚好 40 kHz，正是为抗混叠滤波器留出过渡带。本作业用合成音频复现这一工程权衡。

**输入**：合成多音“音频”（若干 0–20 kHz 正弦叠加）。

**输出**：降采样后的频谱、混叠证据、抗混叠后改善。

**边界**：

- 不依赖外部音频文件，用合成信号模拟；
- 抗混叠滤波器截止须随目标 `fs` 的 `fs/2` 设置；
- 禁止把混叠峰当成新增乐器。

## 5. 详细题目

### P1 手算 / 推导（基础，必做）

可闻上限 `fmax = 20 kHz`。由奈奎斯特求理论最小采样率。解释 44.1 kHz 比最小值高约 2.1 kHz 的原因（给抗混叠滤波器过渡带）。若将一段含 19 kHz 的音以 `fs=24 kHz` 采样，求其混叠频率（应落在可闻带内）。

### P2 实现（编程，必做）

编写 `audio_sampling.py`：

- 合成 `x(t)`：含 1 kHz、5 kHz、19 kHz 三音等幅，`fs0 = 48 kHz`；
- 直接降采样到 `fs1 = 24 kHz`（取每 2 点），做 FFT 看 19 kHz 是否折叠到 `24/2 - |19 - 24| = 5 kHz` 附近造成与真实 5 kHz 混淆；
- 画出降采样前后幅度谱。

### P3 应用 / 分析（综合，必做）

在降采样前先加抗混叠低通（截止 `fs1/2 = 12 kHz`，`butter` 设计），再降采样并做 FFT，说明 19 kHz 已被滤除、不再混叠；对比“直接降采样”与“抗混叠+降采样”的频谱，给出工程结论。

## 9. 引导与自检

- **检查点**：19 kHz 在 `fs=24 kHz` 下混叠到 5 kHz（24-19=5），会与真实 5 kHz 叠加；若你看到别的值，检查 `fs/2` 与折叠公式。
- **常见失败**：降采样时取点错误（步长应为 `fs0/fs1`）；抗混叠截止设成 `fs0/2` 而非目标 `fs1/2`。
- **调试方向**：先对单音验证降采样后频率符合 `|f - k·fs1|`。
- **提交前清单**：① P1 给出 44.1k 解释与混叠值；② P2 频谱图有；③ P3 对比图有。
