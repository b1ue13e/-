# Z变换与差分方程求解（Z变换与差分方程求解）

> 所属路径：[[🗺️ 信号与系统学习路径|信号与系统学习路径]]

## 作业定位
- 作业模块：Z 变换与差分方程求解
- 覆盖范围：单边/双边 Z 变换公式、典型序列（`δ`/`u`/`aⁿu`）的 Z 变换与 ROC、用 Z 变换**解线性常系数差分方程**（零输入+零状态分解）、逆 Z 变换（部分分式 + 幂级数/长除）、ROC 与因果性/稳定性的判定、以及 Z 变换与 DTFT 的关系（`z=e^{jΩ}` 在单位圆上）。
- 本 HW 的位置：[[信号与系统-课后作业-HW06-Z变换与数字滤波器|HW06]] 用 Z 变换做"滤波器设计"。本 HW 退一层，专注"Z 变换作为解差分方程的工具"——这是离散系统分析的一般方法，也是读懂 HW06 滤波器背后代数推导的前提。两者互补，不重叠。
- 验收方式（三轨）：公式/ROC 计算（闭卷）+ 差分方程求解（推导）+ 逆变换与零极点解读（代码辅助），对接 100 分 Rubric（变换与 ROC 35 + 差分方程求解 35 + 逆变换/零极点 30）。

## 学习目标
完成本作业后，你应当能够：
- 对任意有限长/右边/左边/双边序列正确写出 Z 变换式并画出 ROC；
- 用 Z 变换把线性常系数差分方程转化为代数方程，分离零输入响应与零状态响应，并叠加得全响应；
- 用部分分式展开 + 基本对做逆 Z 变换，由 ROC 决定每一项取因果或反因果反演；
- 由 `H(z)` 的极点位置判定系统因果性与 BIBO 稳定性（极点全在单位圆内 ⇔ 稳定因果）。

## 引导自检
提交前自检清单：
- [ ] 每个 `X(z)` 后面是否都带了 ROC？ROC 边界是否恰好由极点模值决定？
- [ ] 解差分方程时，`Z{x[n-k]}=z^{-k}X(z)` 的位移性质用对了吗？初值条件是否进了零输入项？
- [ ] 逆变换时，同一个极点产生的项，因果/反因果是**由 ROC 选的**而非随便选的——ROC 含 `∞` 取右边序列，含 `0` 取左边序列。
- [ ] 稳定性判定：`|极点|<1`（单位圆内）⇔ 因果稳定；只要有一个极点在单位圆外就不稳定。
常见失败点：写变换式忘写 ROC；把 `a^n u[n]` 的 ROC 写成 `|z|<|a|`（应为 `|z|>|a|`）；逆变换不分 ROC 直接套"右边"公式导致双边序列错半边。调试策略：先用"序列是右边/左边"反推 ROC 形态，再让部分分式每一项的 ROC 都能并成总 ROC。

## 子题

### P1 · 变换式与 ROC（闭卷）
- [ ] 求以下序列的单边 Z 变换与 ROC：`x1[n]=δ[n-2]`、`x2[n]=u[n]`、`x3[n]=a^n u[n]`（`a` 实数）、`x4[n]=n a^n u[n]`（提示：对 `a^n u[n]` 的变换式对 `a` 求导）。
- [ ] 求 `x[n]=a^n u[-n-1]`（左边序列）的 Z 变换与 ROC，并与 `a^n u[n]` 对比，说明"同极点、不同 ROC"的现象（接 [[左边Z变换]] / [[双边Z变换]]）。
- [ ] 给定 `X(z)=1/((1-0.5z^{-1})(1-2z^{-1}))`，列出它可能的全部 ROC 及其对应的时间序列类型（右边/左边/双边），各对应怎样的因果/反因果选择？

### P2 · 用 Z 变换解差分方程
- [ ] 系统差分方程 `y[n]-0.5 y[n-1]=x[n]`，`x[n]=δ[n]`，初始松弛（`y[-1]=0`）。求 `Y(z)`、`H(z)`，并用逆变换求 `h[n]` 与 `y[n]`，验证它是 `0.5^n u[n]`。
- [ ] 同上系统，输入 `x[n]=u[n]`，求零状态响应 `y_zs[n]`（用 `X(z)=1/(1-z^{-1})` 与部分分式）；再设非零初值 `y[-1]=1`，求零输入响应 `y_zi[n]` 并叠加得全响应。
- [ ] 二阶系统 `y[n]-y[n-1]+0.25 y[n-2]=x[n]`。求 `H(z)` 与极点；若 `x[n]=δ[n]`，求 `h[n]`（注意重根 `r=0.5` 的反演形式）。

### P3 · 逆变换、零极点与稳定性
- [ ] 对 `H(z)=(1-z^{-1})/(1-0.5z^{-1})`：(a) 画零极点图（接 [[Z域零点]]/[[Z域极点]]/[[Z域零极点图]]）；(b) 由 ROC `|z|>0.5` 判定因果性；(c) 极点是否在单位圆内 ⇒ 稳定性结论。
- [ ] 给定 `H(z)=z/(z^2-1.5z+0.5)`，求极点，判断因果稳定；若改为反因果 ROC（`|z|<0.5`），系统还稳定吗？解释"因果"与"稳定"在此如何解耦。
- [ ] 验证 DTFT 关系：对某 `H(z)`，令 `z=e^{jΩ}` 得到 `H(e^{jΩ})`；用 [[DTFT周期性]] 说明频谱以 `2π` 为周期；用 [[DTFT存在条件]] 说明为何 `|z|>1` 的 ROC（极点在单位圆外）会导致 DTFT 不存在（接 [[Z与DTFT关系推导]]）。

## 参考实现思路
- 部分分式：`X(z)=A/(1-p z^{-1}) + B/(1-q z^{-1})`，对 `z^{-1}` 展开后逐项反演。
- ROC 决定反演方向：`|z|>|p|` ⇒ 右边序列 `p^n u[n]`；`|z|<|p|` ⇒ 左边序列 `-p^n u[-n-1]`。
- SymPy 校核：`from sympy import apart, expand; apart(X_subs)` 看部分分式；逆变换仍须手算并说明 ROC。

## 检索练习与常见误区（闭卷，不翻书）
**检索练习**
- 闭卷写出 `Z{a^n u[n]}` 及其 ROC；再写 `Z{a^n u[-n-1]}` 与 ROC，点明差异。
- 一句话：因果 LTI 离散系统 BIBO 稳定的极点条件是什么？
- DTFT 与 Z 变换的关系用一句话概括（`z` 取何值）。

**常见误区 / 反例**
- 误区：`a^n u[n]` 的 ROC 是 `|z|<|a|`。**反例**：右边序列 ROC 在极点圆**外** `|z|>|a|`；写成内部会得到反因果序列，完全错。
- 误区：逆 Z 变换只看极点、不看 ROC。**反例**：同一 `X(z)` 不同 ROC 对应完全不同的时间序列（右边 vs 左边 vs 双边）。
- 误区："稳定"⇔"因果"。**反例**：反因果系统极点全在原点左侧也可稳定；因果系统若有极点在单位圆外则不稳定。两者独立。
