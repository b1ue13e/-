## 2. 学习目标

完成本作业后，你应当能够：

- 用“翻转—平移—相乘—积分”四步几何地解释卷积的每一步；
- 对短序列手算卷积并画出翻转平移过程；
- 用动画/多帧图展示卷积滑动窗口，建立 `y[n] = Σ x[k]h[n-k]` 的直观；
- 用一个小尺寸平滑核演示卷积的“局部平均/去噪”作用。

## 4. 任务背景与边界

**背景**：卷积是 LTI 系统的核心运算。只背公式容易“算得出、想不明”；可视化能把抽象的求和变成可看见的滑动过程。

**输入**：两个有限长序列或一个矩形脉冲与一个指数。

**输出**：逐步过程图、最终卷积结果图。

**边界**：

- 离散卷积用手算验证，禁止只调用库函数交差；
- 连续情形用数值积分近似并说明近似步长；
- 动画可用多帧静态图代替（不强制生成 gif）。

## 5. 详细题目

### P1 手算 / 推导（基础，必做）

设 `x = [1, 2, 1]`、`h = [1, 1]`。按翻转—平移—相乘—求和逐步计算 `y = x * h`，列出 `n = 0,1,2,3` 时 `h[n-k]` 与乘积累加过程，给出 `y` 的四点值，并验证长度 `len(y) = 3+2-1 = 4`。

### P2 实现（编程，必做）

编写 `conv_visual.py`：

- `conv_steps(x, h)` 返回每一步的 `(shift, h_flipped_shifted, product, cumsum)`；
- 用子图画出：原始 `x`、原始 `h`、`h` 翻转后随 `n` 平移的形状、对应 `product`、以及累计 `y[n]`；
- 另对连续情形 `x(t)=rect(t/2)`、`h(t)=e^{-t}u(t)`，用步长 `dt=0.01` 数值卷积并画图。

### P3 应用 / 分析（综合，必做）

取含噪信号 `noisy = clean + 0.3*randn`（固定 `seed=0`），用长度为 5 的矩形核 `h = ones(5)/5` 做卷积平滑，画出 `noisy`、`clean`、平滑后三者的对比，计算平滑后与 `clean` 的 MSE，并讨论核越宽去噪越强但细节越模糊的权衡。

## 9. 引导与自检

- **检查点**：`y` 的长度应为 `len(x)+len(h)-1`；若你得到的长度不对，先检查翻转后的对齐（`h[-k]` 而非 `h[k]`）。
- **常见失败**：把 `h[n-k]` 写成 `h[k-n]`（平移方向反了）；连续卷积积分上下限取错导致支撑区间偏差。
- **调试方向**：先对一个 `n` 单独画出 `x[k]` 与 `h[n-k]` 重叠区域，确认相乘区间。
- **提交前清单**：① P1 表格完整；② P2 至少 3 张过程图；③ P3 MSE 为具体数值。
