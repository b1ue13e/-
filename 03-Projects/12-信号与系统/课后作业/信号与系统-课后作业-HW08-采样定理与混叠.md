## 所需知识（requires）
- [[采样定理与混叠]]：采样后频谱周期延拓、欠采样时高频折叠成低频（混叠）。
- [[奈奎斯特定理]]：无失真采样要求 `fs > 2·fmax`，奈奎斯特频率 = `fs/2`。
- [[理想重建]]：理想低通增益 `Ts`、sinc 插值 `x(t)=Σx[n]sinc((t-nTs)/Ts)`、频域零填充重建。

### 采样—重建信号链

```
连续信号 x(t)
   │
   ├─[抗混叠低通 LP，截止 = fs/2]           ← 必须在采样「之前」
   ▼
采样  x[n] = x(n·Ts),   Ts = 1/fs
   │
   ▼  FFT → 频谱（周期延拓；欠采样时高频折叠成低频 = 混叠）
   │
   ├─[理想重建：频域零填充 + IFFT，或截断 sinc 插值] → x̂(t)
   ▼
重建误差：fs < 2·fmax 时不可恢复；MSE 在 fs/fmax 越过 2 后急剧下降
```

## 学习目标
完成本作业后，你应当能够：
- 由 [[奈奎斯特定理]] 计算最小采样率与混叠频率（公式 `f_alias=|f - k·fs|` 取最小非负整数 `k`）；
- 用代码演示"真实高频"在欠采样下"伪装"成低频，并用频谱（FFT）显示能量搬移；
- 用理想低通（频域零填充 + IFFT，或截断 sinc）做重建，量化 `fs<2·fmax` 时的失真；
- 说明抗混叠滤波为何必须在采样之前，并解释 CD 44.1 kHz 比理论最小值高的工程原因（保护带宽）。

## 子题

### P1 · 手算（闭卷）

- [ ] 设 `fs=100 Hz`，真实频率 `f=90 Hz`。计算其混叠频率 `f_alias`（取 `k` 使 `|90-k·100|` 最小）。再对 `f=130 Hz`、`f=210 Hz` 各算一次，总结"频率轴以 `fs/2` 为轴折叠"的规律；说明为何 `fs=100` 时无法区分 90 Hz 与 10 Hz。
- [ ] 设信号最高频率 `fmax=1 kHz`，由奈奎斯特求最小采样率 `fs_min`；若 `fs=1.5 kHz`（低于 `fs_min`），指出频谱周期延拓后在 `[0, fs/2]` 内重叠区域中心频率。
- [ ] 可闻上限 `fmax=20 kHz`，求理论最小采样率，解释 44.1 kHz 比最小值高约 2.1 kHz 的原因（给抗混叠滤波器过渡带）。

### P2 · 实现（numpy/scipy）

- [ ] 编写 `aliasing_demo.py`：生成 `x(t)=cos(2π·90·t)` 以 `fs=100 Hz` 采样得离散点；用"理想低通重建"（或直接按 10 Hz 余弦）画出采样点"看起来像"的曲线，与真实 90 Hz 连续曲线叠画；用 FFT 显示能量在 10 Hz 而非 90 Hz。
- [ ] 编写 `sampling_sim.py`：生成带限信号 `x(t)=sinc(2·fmax·t)·cos(2π·fm·t)`（`fm<fmax`），以 `fs∈{2.2, 1.5, 4}·fmax` 采样；用频域零填充做理想重建，画原始与重建对比，列出三种 `fs` 的重建 MSE。
- [ ] 编写 `audio_sampling.py`：合成含 1/5/19 kHz 三音等幅信号 `fs0=48 kHz`；直接降采样到 `fs1=24 kHz`（取每 2 点），做 FFT 看 19 kHz 是否折叠到 5 kHz 附近造成与真实 5 kHz 混淆；画降采样前后幅度谱。

### P3 · 应用（抗混叠与保护带宽）

- [ ] 在采样/降采样前先加抗混叠低通（截止 `fs/2`，用 `butter` 设计），再采样并做 FFT，说明高频被滤除、不再混叠；对比"直接降采样"与"抗混叠+降采样"的频谱，给出工程结论（为何滤波必须在采样之前）。
- [ ] 绘制"重建 MSE 随 `fs/fmax` 比值"的曲线（`fs/fmax` 从 1.1 到 5），指出 MSE 在比值越过 2 后急剧下降的区间，解释其工程含义（留出保护带宽）。

## 参考实现思路
- 混叠：`f_alias = min(abs(f - k*fs) for k in range(-10,11))`。
- 重建：`Xf = fftshift(fft(x));  # 在频域保留 |f|<fs/2，其余置零;  ifft(ifftshift(Xf))`，零填充提高密度。
- 抗混叠：`b,a=signal.butter(4, fs1/2, fs=fs0); x_aa=signal.lfilter(b,a,x)` 后再降采样。

## 检索练习与常见误区（闭卷，不翻书）

**检索练习**
- 闭卷写出奈奎斯特率与混叠频率公式 `f_alias=|f−k·fs|` 的取 `k` 规则。
- 为何抗混叠滤波必须在采样「之前」？
- 44.1 kHz 为何高于理论最小采样率？

**常见误区 / 反例**
- 误区：`f_alias=fs−f`（直接相减）。**反例**：应取 `|f−k·fs|` 的最小非负整数 `k`（频率轴以 `fs/2` 折叠）。
- 误区：奈奎斯特频率 = `fs`。**反例**：奈奎斯特频率 = `fs/2`。
- 误区：高采样率总能提高重建质量。**反例**：超过 `2·fmax` 后收益递减，只是浪费存储。
