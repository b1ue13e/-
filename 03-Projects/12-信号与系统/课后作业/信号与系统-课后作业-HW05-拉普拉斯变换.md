## 引导自检
提交前自检清单：
- [ ] 手算结果与自写代码数值一致（误差 < 1e-10）？
- [ ] 频谱是否做了 `fftshift`、频率轴单位是否正确？
- [ ] 长度与零填充是否满足避免循环卷积混叠的条件（≥ L+M-1）？
- [ ] 固定 `seed=42`，他人能否独立复现？
常见失败点：卷积下标 `n-m` 越界；窗函数旁瓣被误判为噪声；高于奈奎斯特的频率「伪装」成低频（混叠）未识别。调试策略：先在小 N、合成信号上验证核心算法，再上真实数据；对照 numpy/scipy 逐项排查。

## 子题

### P1 · 手算（闭卷）

- [ ] 求 x(t)=e^{-2t}u(t) 与 x(t)=e^{3t}u(-t) 的 LT 与各自 ROC，说明右/左边信号 ROC 形状。
- [ ] 给定 H(s)=(s+1)/((s+2)(s+3))，求零极点，画零极点图，判断系统是否因果稳定。

### P2 · 理论

- [ ] 由 H(s) 极点位置说明响应模态（如 s=-2±j3 ⇒ 衰减振荡），并解释稳定条件 Re(p)<0。
- [ ] 求系统对指数输入 e^{st} 的稳态响应，联系 [[特征函数]]。

### P3 · 应用（scipy）

- [ ] 用 scipy.signal 定义连续系统（num/den），绘制阶跃响应与零极点图，验证 P1 的因果/稳定判断。

## 参考实现思路
scipy：`b,a=signal.tf2*(...)`；`t,y=signal.step((b,a))`；`signal.tf2zpk(b,a)` 得零极点；画图用 matplotlib。
