## 2. 学习目标

完成本作业后，你应当能够：

- 将任意实信号分解为偶部与奇部，并验证 `x(t)=x_e(t)+x_o(t)`；
- 将信号分解为直流分量（均值）与交变分量，理解基线漂移的物理含义；
- 用基本信号（单位阶跃、单位冲激、矩形脉冲）拼出分段定义信号；
- 判断一个信号的奇偶对称性，并用对称性化简后续积分与变换。

## 4. 任务背景与边界

**背景**：现实中的观测信号往往是多个成分叠加的结果（例如 ECG 同时包含心电波形、呼吸引起的基线漂移、工频干扰）。把信号拆成可解释的成分是分析、滤波与特征提取的第一步。

**输入**：一组离散采样或分段函数表达式。

**输出**：分解后的各分量序列/函数，以及可视化图。

**假设与边界**：

- 处理有限长离散序列（长度 `N` 给定），连续情形只在给定分段表达式上做解析分解；
- 偶/奇分解对实信号定义；复信号本题不涉及；
- 禁止直接调用现成“去趋势”库函数完成核心分解（允许用 `numpy.mean` 求均值，但 DC/AC 拆分须自行相减实现）。

## 5. 详细题目

### P1 手算 / 推导（基础，必做）

给定离散序列 `x[n] = [1, 3, 2, 4]`（`n = 0,1,2,3`）：

1. 计算偶部 `x_e[n] = (x[n] + x[-n]) / 2` 与奇部 `x_o[n] = (x[n] - x[-n]) / 2`，先定义 `x[-n]`（`x[-0]=x[0]`，`x[-1]=x[1]`，`x[-2]=x[2]`，`x[-3]=x[3]`），写出 `x_e`、`x_o` 的四点值并验证 `x_e + x_o = x`。
2. 求该序列的直流分量 `DC = mean(x)` 与交变分量 `AC[n] = x[n] - DC`，验证 `mean(AC) = 0`。
3. 判断序列整体是否偶/奇/无对称性，说明理由。

### P2 实现（编程，必做）

编写 `signal_decompose.py`：

- 函数 `even_odd(x)` 返回 `(xe, xo)`；
- 函数 `dc_ac(x)` 返回 `(dc, ac)`；
- 函数 `from_primitives(spec)`，输入为“基本信号拼接规格”（如 `[(’step‘, t0), (’rect‘, t1, t2)]`），返回分段信号数组；
- 用 `matplotlib` 画出 `x`、`x_e`、`x_o` 与 `DC/AC` 的对比图。

提供样例 `x = np.array([1,3,2,4,2,3,1])`，输出各分量数值与图像。

### P3 应用 / 分析（综合，必做）

取一个长度 64 的含基线漂移示例信号 `s[n] = clean[n] + 0.05*n`（线性漂移）+ 小噪声。用 DC/AC 与“去趋势”（减去最小二乘拟合直线）两种方法去除漂移，对比去漂移前后 `clean` 与恢复信号的均方误差，说明哪种对线性漂移更有效并解释原因。

## 9. 引导与自检

- **检查点（不泄露答案）**：偶部应关于 `n=0` 对称，奇部应满足 `x_o[0]=0`；若你算出的 `x_e+x_o≠x`，先检查 `x[-n]` 的定义。
- **常见失败**：把有限长序列的“偶对称”误判为整体偶信号；去漂移时把噪声也当成漂移拟合掉。
- **调试方向**：先用 `x_e[n]-x_o[n]` 应得 0 来验证符号；画 `x` 与 `x_e+x_o` 重叠曲线确认重构。
- **提交前清单**：① P1 数值已填；② 三张图生成；③ P3 给出 MSE 数值而非只给文字。
