# 数值分析-课后作业-03-QR分解与最小二乘

> 对齐官方源：**MIT 18.335J Problem Set 3 (Householder QR & Least Squares)** 与 **Trefethen NLA Lecture 10-12**

---

## 1. 学习目标与动机
- 掌握 Householder 镜面反射正交变换的数值稳定构造；
- 独立编写矩阵 $A \in \mathbb{R}^{m \times n}$（$m \ge n$）的完整 Householder QR 分解与正交求解器；
- 在病态多项式拟合任务中，实测正交法相比正规方程法（Normal Equations）在保持条件数方面的绝对优势。

---

## 2. 任务边界与输入输出
- **输入**：$m \times n$ 超定矩阵 $A$ 及观测向量 $b$。
- **输出**：正交矩阵 $Q$、上三角矩阵 $R$ 及最小二乘解 $\hat{x} = \arg\min_x \|Ax - b\|_2$。

---

## 3. 详细实验任务与算法规范

### 任务 1：Householder 向量生成与反射
实现函数 `householder_vector(x)`，严格按照避免相消的符号选择规则 $v = x + \operatorname{sgn}(x_1) \|x\|_2 e_1$ 计算反射向量 $v$。

### 任务 2：QR 分解与隐式正交变换
实现函数 `qr_factor_householder(A)`，生成紧凑存储的反射向量集与上三角矩阵 $R$。

### 任务 3：病态 Vandermonde 最小二乘拟合实验
构造 50 个等距采样点拟合 10 阶多项式。
- 对比方法：正规方程法 $A^T A x = A^T b$（Cholesky / LU 求解） vs Householder QR 法；
- 记录两者在不同多项式阶数下的解残差范数。

## 7. Starter Code 与可执行基线

```python
import numpy as np

def householder_qr(A_in):
    A = A_in.copy().astype(np.float64)
    m, n = A.shape
    Q = np.eye(m)
    for k in range(n):
        x = A[k:, k]
        norm_x = np.linalg.norm(x)
        if norm_x > 1e-15:
            alpha = -np.sign(x[0]) * norm_x if x[0] != 0 else -norm_x
            v = x.copy()
            v[0] -= alpha
            v = v / np.linalg.norm(v)
            A[k:, k:] -= 2.0 * np.outer(v, np.dot(v, A[k:, k:]))
            Q[:, k:] -= 2.0 * (Q[:, k:] @ v[:, None]) @ v[None, :]
    R = np.triu(A[:n, :])
    return Q[:, :n], R
```
