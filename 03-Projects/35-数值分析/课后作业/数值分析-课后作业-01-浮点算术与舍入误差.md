# 数值分析-课后作业-01-浮点算术与舍入误差

> 对齐官方源：**MIT 18.335J Problem Set 1 (Floating Point & Conditioning)** 与 **FNC Chapter 1**

---

## 1. 学习目标与动机
- 建立对 IEEE 754 双精度浮点物理限制的直观认知；
- 独立编写算法循环逼近实测硬件的机器精度 $\epsilon_{\text{mach}}$ 与下溢边界；
- 深入剖析浮点相消灾难（Catastrophic Cancellation）的机理，并实现 Kahan 补偿求和算法。

---

## 2. 任务边界与输入输出
- **输入**：无外部数据输入，使用纯算法生成测试向量 $x \in \mathbb{R}^N$（$N = 10^7$）。
- **输出**：
  1. 实测机器精度 $\epsilon_{\text{mach}}$；
  2. 灾难相消与稳定重写法的误差对比曲线数据；
  3. 朴素累加与 Kahan 补偿求和的前向误差对比报告。

---

## 3. 详细实验任务与算法规范

### 任务 1：机器精度循环逼近
不得调用 `np.finfo`。初始化 $e = 1.0$，在循环中令 $e \leftarrow e / 2.0$，直到满足 $1.0 + e == 1.0$。记录最终的 $2 \times e$ 并与理论值 $2^{-52} \approx 2.2204 \times 10^{-16}$ 对比。

### 任务 2：灾难相消与代数稳定重写
计算函数 $f(x) = \frac{1 - \cos x}{x^2}$ 当 $x \to 0$ 时的数值行为。
- **直接计算法**：直接执行分子减法与分母除法，在 $x \in [10^{-16}, 10^{-1}]$ 密集取样；
- **稳定重写法**：利用半角公式 $1 - \cos x = 2 \sin^2(x/2)$，重写为 $f_{\text{stable}}(x) = \frac{2 \sin^2(x/2)}{x^2}$；
- 记录相对误差曲线，分析截断精度崩溃区间。

### 任务 3：Kahan 补偿求和算法（Compensated Summation）
构造长度为 $N = 10^7$ 的单精度（`float32`）数组，元素为 $x_i = 10^{-5}$，理论精确和为 $100.0$。
- **朴素累加**：直接循环 `sum += x[i]`；
- **Kahan 累加**：维护低位舍入误差补偿变量 $c$。

## 7. Starter Code 与可执行基线

```python
import numpy as np

def measure_machine_eps():
    e = 1.0
    while (1.0 + e / 2.0) != 1.0:
        e = e / 2.0
    return e

def kahan_sum(arr):
    s = np.float32(0.0)
    c = np.float32(0.0) # 补偿变量
    for x in arr:
        y = x - c
        t = s + y
        c = (t - s) - y
        s = t
    return s
```
