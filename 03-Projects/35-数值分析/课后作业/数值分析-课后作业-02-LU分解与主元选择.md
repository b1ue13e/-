# 数值分析-课后作业-02-LU分解与主元选择

> 对齐官方源：**MIT 18.335J Problem Set 2 (LU Decomposition & Stability)** 与 **Trefethen NLA Lecture 20-22**

---

## 1. 学习目标与动机
- 深入掌握高斯消元法（Gaussian Elimination）的矩阵分解本质 $PA = LU$；
- 独立编写带列选主元（Partial Pivoting）的 LU 原地分解与前向/后向回代求解器；
- 构造典型病态矩阵，实测增长因子 $\rho$ 与后向误差界。

---

## 2. 任务边界与输入输出
- **输入**：$n \times n$ 非奇异系数矩阵 $A$ 及右端常数向量 $b$。
- **输出**：置换向量 $P$、下三角矩阵 $L$、上三角矩阵 $U$ 以及方程解向量 $\hat{x}$。

---

## 3. 详细实验任务与算法规范

### 任务 1：带列选主元的 LU 原地分解
实现函数 `lu_factor_pivot(A)`：
1. 每一步寻找当前列绝对值最大元素所在的行 $p$；
2. 执行行交换置换并记录置换矩阵；
3. 执行列消元，将倍加因子存储于下三角区，将消元后主元存储于上三角区。

### 任务 2：前向回代与后向回代求解
实现函数 `lu_solve_pivot(P, L, U, b)`：
1. 首先计算置换后的右端项 $b^* = P b$；
2. 前向回代求解下三角方程组 $L y = b^*$；
3. 后向回代求解上三角方程组 $U x = y$。

### 任务 3：数值稳定性与增长因子监测
构造 Wilkinson 矩阵 $W_n$：对角线为 1，下三角元全为 -1，最后一列全为 1。
实测其理论增长因子 $\rho = 2^{n-1}$，验证选主元在最坏情况下的病态极限。

## 6. 引导自检与易错陷阱
- **陷阱**：在行交换时只交换了右侧未消元子矩阵，而漏掉了左侧已经计算好的下三角 $L$ 矩阵元素。

## 7. Starter Code 与可执行基线

```python
import numpy as np

def lu_factor_pivot(A_in):
    A = A_in.copy().astype(np.float64)
    n = A.shape[0]
    piv = np.arange(n)
    for k in range(n - 1):
        p = np.argmax(np.abs(A[k:, k])) + k
        if p != k:
            A[[k, p], :] = A[[p, k], :]
            piv[[k, p]] = piv[[p, k]]
        if abs(A[k, k]) < 1e-15:
            raise ValueError("矩阵奇异")
        A[k+1:, k] /= A[k, k]
        A[k+1:, k+1:] -= np.outer(A[k+1:, k], A[k, k+1:])
    L = np.tril(A, -1) + np.eye(n)
    U = np.triu(A)
    return piv, L, U
```
