# 数值分析-阶段作业-01-数值线性代数稳定性与特征值

> 本阶段作业是「阶段1：误差分析与数值线性代数」的综合大作业。它要求将浮点舍入模型、选主元 LU 分解、Householder 正交化以及对称 QR 特征值算法熔铸为一体，完成一个包含理论推导、基准实验与稳定性审计的综合报告。

---

## 1. 学习目标与动机
- 掌握直接法后向稳定性分析的全套实验测量技术；
- 实现带 Wilkinson 位移的对称三对角 QR 谱分解算法；
- 针对病态 Hilbert 矩阵与随机密集矩阵，全方位对比 LU、Householder QR 与 SVD 的后向残差与正交性保持能力。

---

## 2. 任务边界与输入输出
- **输入**：不同条件数 $\kappa(A) \in [10^1, 10^{16}]$ 的综合测试矩阵集。
- **输出**：
  1. 增长因子 $\rho$ 与后向残差统计表；
  2. 对称矩阵全部特征值计算结果与残差 $\|A v_i - \lambda_i v_i\|_2$；
  3. 阶段综合稳定性分析与审计报告。

---

## 3. 详细实验任务与算法规范

### 模块 A：直接法后向稳定性严苛审计
1. 自动生成随机正态矩阵 $A_{\text{rand}} \in \mathbb{R}^{100 \times 100}$、病态 Kahan 矩阵以及 Hilbert 矩阵；
2. 分别使用未选主元高斯消元、列选主元 LU（PLU）与 Householder QR 解线性方程组 $Ax = b$；
3. 计算并输出规范化后向误差：
   $$\text{Backward Error} = \frac{\|b - A\hat{x}\|_2}{\|A\|_F \|\hat{x}\|_2 + \|b\|_2}$$

### 模块 B：带 Wilkinson 位移的三对角对称 QR 算法
1. 实现 Householder 对称三对角化 $A = Q T Q^T$；
2. 在三对角矩阵 $T$ 上实现隐式 Wilkinson 位移 QR 迭代：
   - 提取底部 $2 \times 2$ 子矩阵，选取最接近 $t_{m,m}$ 的特征值作为位移 $\mu$；
   - 迭代直到次对角线元素 $|t_{m, m-1}| \le \epsilon_{\text{mach}} (|t_{m-1,m-1}| + |t_{m,m}|)$ 并降阶。
3. 验证计算所得特征值与 `scipy.linalg.eigh` 的绝对一致性。

## 7. Starter Code 与可执行基线

```python
import numpy as np

def tridiagonal_qr_step(T_in, shift):
    # 单步带位移三对角 QR 迭代
    T = T_in.copy()
    n = T.shape[0]
    # T - mu*I = QR, T_new = RQ + mu*I
    Q, R = np.linalg.qr(T - shift * np.eye(n))
    return R @ Q + shift * np.eye(n)
```
