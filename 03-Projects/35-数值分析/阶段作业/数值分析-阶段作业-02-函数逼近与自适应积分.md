# 数值分析-阶段作业-02-函数逼近与自适应积分

> 本阶段作业是「阶段2：函数逼近、插值与数值求积」的综合大作业。要求综合运用 Chebyshev 谱逼近、三次自然样条插值与自适应复合求积器，完成一个工业级函数逼近与积分算法套件。

---

## 1. 学习目标与动机
- 建立对多项式全局逼近（Chebyshev）与分段光滑逼近（三次样条）在不同连续度函数上的优劣对比；
- 独立编写基于误差估计自适应二分网格的自适应 Simpson / Gauss-Kronrod 积分器；
- 解决奇异性与高频震荡函数的积分逼近挑战。

---

## 2. 任务边界与输入输出
- **输入**：多类测试函数集（包含平滑解析函数、带尖点不可导函数 $f(x) = |x|$、高频震荡函数 $f(x) = \sin(100x)$）。
- **输出**：逼近拟合误差比较表、自适应细化网格树分布图与求积收敛报告。

---

## 3. 详细实验任务与算法规范

### 模块 A：Chebyshev 重心插值 vs 三次自然样条对比
1. 实现三对角追赶法（Thomas 算法）求解三次自然样条边界方程组；
2. 在平滑 Runge 函数与尖点不可导函数上，对比 Chebyshev 插值与三次样条插值的最大模误差 $\|f - P_N\|_\infty$；
3. 证明并验证：三次样条在非光滑函数上具有稳定的 $O(h^4)$ 收敛，而多项式全局插值会退化。

### 模块 B：自适应 Simpson 复合求积器
1. 实现自适应二分递归积分器：对区间 $[a, b]$，计算单步 Simpson 近似 $S_1$ 与左右两半步近似 $S_2$；
2. 利用局部误差估计 $|S_2 - S_1| / 15 < \tau$ 作为停机准则，不达标时递归二分；
3. 统计函数评估总次数，输出自适应采样点分布直方图。

```python
import numpy as np

def adaptive_simpson(f, a, b, tol=1e-8, max_depth=20):
    c = 0.5 * (a + b)
    h = b - a
    fa, fb, fc = f(a), f(b), f(c)
    s = (h / 6.0) * (fa + 4.0 * fc + fb)
    
    def _recurse(a, b, fa, fb, fc, s, depth):
        c = 0.5 * (a + b)
        d = 0.5 * (a + c)
        e = 0.5 * (c + b)
        fd, fe = f(d), f(e)
        h = b - a
        s_left = (h / 12.0) * (fa + 4.0 * fd + fc)
        s_right = (h / 12.0) * (fc + 4.0 * fe + fb)
        s2 = s_left + s_right
        if depth >= max_depth or abs(s2 - s) <= 15.0 * tol:
            return s2 + (s2 - s) / 15.0
        return (_recurse(a, c, fa, fc, fd, s_left, depth + 1) +
                _recurse(c, b, fc, fb, fe, s_right, depth + 1))
                
    return _recurse(a, b, fa, fb, fc, s, 0)
```
