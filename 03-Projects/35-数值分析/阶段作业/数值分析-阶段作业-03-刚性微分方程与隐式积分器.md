# 数值分析-阶段作业-03-刚性微分方程与隐式积分器

> 本阶段作业是「阶段3：非线性方程与ODE数值解」的综合大作业。要求结合多维 Newton-Raphson 求解器与隐式积分格式（Backward Euler / Crank-Nicolson），完成跨越快慢多时间尺度的多维非线性刚性微分系统高保真仿真。

---

## 1. 学习目标与动机
- 攻克多时间尺度非线性动力系统数值积分稳定性难题；
- 实现每时间步内嵌多维 Newton-Raphson 迭代的隐式求解器；
- 针对经典 Van der Pol 极度刚性极限环振荡系统与化学反应动力学，对比显式发散与隐式稳定的算力开销与精度。

---

## 2. 任务边界与输入输出
- **输入**：刚性系统常微分方程 $y' = f(t, y)$、刚性参数 $\mu \in [10^2, 10^4]$、初值 $y_0$ 与仿真总时间 $T$。
- **输出**：多维状态轨迹时间曲线、每时间步 Newton 迭代收敛历程以及显式/隐式步数对比报告。

---

## 3. 详细实验任务与算法规范

### 模块 A：多维隐式后向 Euler 与 Crank-Nicolson 积分器
1. 对一般非线性系统 $y' = f(t, y)$，构造后向 Euler 隐式残差方程：
   $$G(y_{n+1}) = y_{n+1} - y_n - h f(t_{n+1}, y_{n+1}) = 0$$
2. 在每时间步调用多维 Newton 求解器，解析推导雅可比矩阵 $J_G = I - h \frac{\partial f}{\partial y}(t_{n+1}, y_{n+1})$；
3. 扩展实现二阶 A-稳定 Crank-Nicolson 积分器。

### 模块 B：Van der Pol 极度刚性极限环基准实验
考虑二阶非线性刚性方程：
$$x'' - \mu (1 - x^2) x' + x = 0, \quad \mu = 1000$$
1. 转化为一阶系统 $y_1' = y_2, \; y_2' = \mu (1 - y_1^2) y_2 - y_1$；
2. 实测显式 RK4 在该系统上的步长上限（$h < 10^{-6}$ 否则溢出）；
3. 演示隐式后向 Euler 在步长 $h = 0.01$ 下依然能极其光滑稳定地捕捉到弛豫振荡极限环。

## 6. 引导自检与易错陷阱
- **陷阱**：在刚性跳跃区域，Newton 初始猜测直接取上一步值 $y_n$ 可能导致初值过远；可以结合前向预测子（Predictor-Corrector）提供更佳初值。

## 7. Starter Code 与可执行基线

```python
import numpy as np

def backward_euler_step(f, J_f, t_next, y_n, h, tol=1e-10, max_iter=20):
    y_next = y_n.copy() # 初值猜测
    for _ in range(max_iter):
        G = y_next - y_n - h * f(t_next, y_next)
        if np.linalg.norm(G) < tol:
            return y_next, True
        J_G = np.eye(len(y_n)) - h * J_f(t_next, y_next)
        delta_y = np.linalg.solve(J_G, -G)
        y_next += delta_y
    return y_next, False
```
