## 1. 学习目标

1. 理解 SVRG（随机梯度方差缩减）如何通过快照点全梯度控制变量，实现从次线性 $\mathcal{O}(1/\sqrt{k})$ 到线性收敛 $\mathcal{O}(\rho^k)$ 的跃升；
2. 掌握概率单纯形上的熵镜像下降（Entropic Mirror Descent / Exponentiated Gradient）更新法则，验证其对维度的对数依附界 $\mathcal{O}(\sqrt{\log d})$；
3. 使用 Nelder-Mead 单纯形法与进化策略解决无法获取梯度的黑盒函数极值搜索。

## 4. Starter Code 与实现框架

```python
import numpy as np

def svrg_logistic_regression(X, y, lmbda=0.01, m=100, eta=0.05, max_epochs=20):
    """SVRG 逻辑回归求解器"""
    N, d = X.shape
    w = np.zeros(d)
    w_hist = [w.copy()]
    
    for epoch in range(max_epochs):
        # 1. 计算快照点全梯度
        w_snapshot = w.copy()
        # sigmoid 梯度
        z = X @ w_snapshot
        p = 1.0 / (1.0 + np.exp(-z))
        full_grad = (1.0 / N) * X.T @ (p - y) + lmbda * w_snapshot
        
        # 2. 内循环随机更新
        for t in range(m):
            i = np.random.randint(0, N)
            xi, yi = X[i], y[i]
            
            # 单样本梯度
            p_t = 1.0 / (1.0 + np.exp(xi @ w))
            grad_t = (p_t - yi) * xi + lmbda * w
            
            p_snap = 1.0 / (1.0 + np.exp(xi @ w_snapshot))
            grad_snap = (p_snap - yi) * xi + lmbda * w_snapshot
            
            # SVRG 方差缩减梯度估计量
            v_t = grad_t - grad_snap + full_grad
            w = w - eta * v_t
            
        w_hist.append(w.copy())
    return np.array(w_hist)
```
