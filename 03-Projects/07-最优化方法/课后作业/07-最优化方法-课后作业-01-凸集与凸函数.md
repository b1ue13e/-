### 关联知识点与前置定理

做题前，请确保已复习以下知识卡：
1. **[[最优化方法-凸集与凸函数]]**：
   - **凸集定义**：对任意 $x, y \in C$ 及 $\theta \in [0, 1]$，有 $\theta x + (1-\theta)y \in C$。
   - **凸函数二阶条件**：$f$ 二阶可微且 Dom $f$ 为凸集，则 $f$ 凸等价于 $\nabla^2 f(x) \succeq 0$（Hessian 矩阵半正定）。
   - **保凸运算**：非负加权求和、与仿射函数复合、逐点求最大值（Pointwise maximum）。
2. **[[最优化方法-分离超平面与Farkas引理]]**：
   - **超平面与半空间**：$\{x \mid a^T x = b\}$ 与 $\{x \mid a^T x \le b\}$ 均为凸集。

## 3. 详细题目与要求

### 题目 1：半正定锥 $S_+^n$ 的凸性证明（手推题）

**背景**：在半定规划 (SDP) 中，决策变量常限定在半正定矩阵集合 $S_+^n = \{X \in \mathbf{R}^{n \times n} \mid X = X^T, X \succeq 0\}$ 中。

**任务**：严格利用凸集的第一性原理（定义），证明 $S_+^n$ 是一个凸锥（Convex Cone）。

#### 💡 小白解题提示 (Hints)：

1. **提示 1 (根据定义)**：设任意 $A, B \in S_+^n$，以及任意 $\theta_1, \theta_2 \ge 0$。你需要证明矩阵 $C = \theta_1 A + \theta_2 B$ 依然满足对称性 $C = C^T$ 和半正定性 $C \succeq 0$。
2. **提示 2 (半正定性的二次型判定)**：矩阵 $M \succeq 0$ 等价于对任意非零向量 $z \in \mathbf{R}^n$，都有 $z^T M z \ge 0$。
3. **提示 3 (展开展开)**：展开 $z^T (\theta_1 A + \theta_2 B) z = \theta_1 (z^T A z) + \theta_2 (z^T B z)$，观察两项的符号。

### 题目 2：Log-Sum-Exp 函数的凸性证明（手推题）

**背景**：Log-Sum-Exp 函数 $f(x) = \mathbf{lse}(x) = \log\left( \sum_{i=1}^n e^{x_i} \right)$ 在机器学习中极其重要（例如 Softmax 交叉熵损失的配分函数，以及 Max 函数的平滑光滑逼近）。

**任务**：计算 $f(x)$ 的 Hessian 矩阵 $\nabla^2 f(x)$，并证明其半正定性 $\nabla^2 f(x) \succeq 0$。

#### 💡 小白解题提示 (Hints)：

1. **提示 1 (求一阶偏导)**：令 $u_i = e^{x_i}$，$S = \sum_{j=1}^n e^{x_j}$。求 $\frac{\partial f}{\partial x_i} = \frac{e^{x_i}}{S} = p_i$，注意向量 $p = (p_1, \dots, p_n)^T$ 构成一个概率分布（满足 $p_i > 0, \sum p_i = 1$）。
2. **提示 2 (求二阶偏导)**：求 $\frac{\partial^2 f}{\partial x_i \partial x_j}$。当 $i=j$ 时和当 $i \neq j$ 时形式不同。最后将 Hessian 矩阵写为矩阵形式：$\nabla^2 f(x) = \mathrm{diag}(p) - p p^T$。
3. **提示 3 (证明 $v^T \nabla^2 f v \ge 0$)**：对任意向量 $v \in \mathbf{R}^n$，计算 $v^T (\mathrm{diag}(p) - p p^T) v = \sum_{i=1}^n p_i v_i^2 - (p^T v)^2$。结合 **Cauchy-Schwarz 不等式** $\left(\sum a_i b_i\right)^2 \le \left(\sum a_i^2\right) \left(\sum b_i^2\right)$（取 $a_i = \sqrt{p_i} v_i, b_i = \sqrt{p_i}$）即可得证！

def is_convex_combination_inside(set_func, point1, point2, num_samples=100):
    """
    通过随机抽样测试连线上的点是否都在集合内
    """
    alphas = np.linspace(0, 1, num_samples)
    segment = np.array([alpha * point1 + (1 - alpha) * point2 for alpha in alphas])

    return np.all(inside_mask)
