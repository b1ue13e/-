# 07-最优化方法-课后作业-06-经典数值算法实现

> **本作业来源与出处**：Nocedal & Wright《Numerical Optimization》Chapter 3 & 6 经典算法实现化改编。

## 1. 学习目标

掌握手撕 Armijo 回溯线搜索与 BFGS 拟牛顿法算法实现。

## 2. 任务边界与知识依赖

求解无约束优化问题 $\min_{x} f(x)$，核心是确定**下降方向 $d_k$** 和**合适步长 $\alpha_k$**。从最速下降法（最便宜的方向，但有震荡）到阻尼牛顿法（精准的方向，但 Hessian 计算太贵），再到 BFGS 拟牛顿法（利用梯度差近似 Hessian 逆），展示了数值优化的演进脉络。本作业要求你手撕核心算法，直观体会收敛速度差异。

---

### 关联知识点与前置定理

做题前，请确保已复习以下知识卡：
1. **[[最优化方法-线搜索与步长策略]]**：
   - **Armijo 充分下降条件**：$f(x_k + \alpha d_k) \le f(x_k) + c_1 \alpha \nabla f(x_k)^T d_k \ (c_1 \in (0, 1))$。
   - **回溯步长算法**：从 $\alpha = 1.0$ 开始，若不满足 Armijo 条件则 $\alpha \leftarrow \rho \alpha \ (\rho \in (0, 1))$。
2. **[[最优化方法-拟牛顿法BFGS]]**：
   - **BFGS 逆矩阵 $H_k$ 更新**：利用 $s_k = x_{k+1} - x_k, y_k = g_{k+1} - g_k, \rho_k = \frac{1}{y_k^T s_k}$，公式为 $H_{k+1} = (I - \rho_k s_k y_k^T) H_k (I - \rho_k y_k s_k^T) + \rho_k s_k s_k^T$。

**任务**：实现通用的 Backtracking Line Search 函数，满足 Armijo 条件。

#### 💡 小白解题提示 (Hints)：

1. **输入参数**：目标函数 `f`、梯度函数 `grad_f`、当前点 `x`、下降方向 `d`、初始步长 `alpha=1.0`、参数 `c1=1e-4`、衰减率 `rho=0.5`。
2. **迭代终止条件**：在 `f(x + alpha * d) <= f(x) + c1 * alpha * np.dot(grad_f(x), d)` 成立时停止循环并返回当前 `alpha`。

#### Python Starter Code 框架：

```python
import numpy as np

def armijo_line_search(f, grad_f, x, d, c1=1e-4, rho=0.5):
    """Armijo 回溯线搜索"""
    alpha = 1.0
    fx = f(x)
    gx = grad_f(x)
    
    while f(x + alpha * d) > fx + c1 * alpha * np.dot(gx, d):
        alpha *= rho
        if alpha < 1e-12:
            break
    return alpha

def bfgs_optimizer(f, grad_f, x0, max_iters=200, tol=1e-6):
    """手撕 BFGS 拟牛顿法"""
    x = np.array(x0, dtype=float)
    n = len(x)
    H = np.eye(n) # 初始 Hessian 逆近似为单位阵
    
    history = [x.copy()]
    
    for k in range(max_iters):
        g = grad_f(x)
        if np.linalg.norm(g) < tol:
            print(f"BFGS 在第 {k} 次迭代成功收敛！")
            break
            
        # 1. 下降方向 d = -H * g
        d = - H @ g
        
        # 2. 线搜索求步长
        alpha = armijo_line_search(f, grad_f, x, d)
        
        # 3. 更新位置
        x_next = x + alpha * d
        g_next = grad_f(x_next)
        
        # 4. 位移与梯度差
        s = x_next - x
        y = g_next - g
        
        # 5. BFGS 矩阵更新
        ys = np.dot(y, s)
        if ys > 1e-10: # 保证曲率条件
            rho = 1.0 / ys
            I = np.eye(n)
            H = (I - rho * np.outer(s, y)) @ H @ (I - rho * np.outer(y, s)) + rho * np.outer(s, s)
            
        x = x_next
        history.append(x.copy())
        
    return x, history

# 测试 Rosenbrock 函数
def rosenbrock(x):
    return 100.0 * (x[1] - x[0]**2)**2 + (1.0 - x[0])**2

def grad_rosenbrock(x):
    g1 = -400.0 * x[0] * (x[1] - x[0]**2) - 2.0 * (1.0 - x[0])
    g2 = 200.0 * (x[1] - x[0]**2)
    return np.array([g1, g2])

# 运行求解
x_opt, hist = bfgs_optimizer(rosenbrock, grad_rosenbrock, x0=[-1.2, 1.0])

# 断言检验
print("优化结果:", x_opt)
assert np.allclose(x_opt, [1.0, 1.0], atol=1e-3), "BFGS 算法未收敛到正确极小值！"
```
