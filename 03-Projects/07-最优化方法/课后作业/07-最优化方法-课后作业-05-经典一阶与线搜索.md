## 题目列表

### Problem 1: Backtracking Armijo 线搜索算法实现 (25分)

实现回溯 Armijo 线搜索算法，满足 Armijo 条件：
\[
f(x_k + \alpha p_k) \le f(x_k) + c_1 \alpha \nabla f(x_k)^T p_k \quad (c_1 \in (0, 1))
\]

```python
def backtracking_armijo(f, grad_f, x, p, alpha0=1.0, c1=1e-4, rho=0.5):
    """
    Inputs:
        f: 目标函数句柄
        grad_f: 梯度函数句柄
        x: 当前迭代点 (d,)
        p: 搜索方向 (d,)
        alpha0: 初始步长
        c1: Armijo 参数 (默认 1e-4)
        rho: 步长缩减因子 (0 < rho < 1)
    Outputs:
        alpha: 满足 Armijo 条件的步长
    """
    alpha = alpha0
    while f(x + alpha * p) > f(x) + c1 * alpha * np.dot(grad_f(x), p):
        alpha *= rho
        if alpha < 1e-12:
            break
    return alpha
```

### Problem 2: 最速下降法 vs 标准牛顿法对比 (35分)

对于病态二次型函数 \(f(x_1, x_2) = \frac{1}{2} x_1^2 + \frac{\gamma}{2} x_2^2\) (\(\gamma = 100\))，初始点 \(x_0 = [10.0, 1.0]\)：
1. 使用 Armijo 回溯步长实现最速下降法（Gradient Descent）；
2. 实现标准牛顿法 \(p_k = - \nabla^2 f(x_k)^{-1} \nabla f(x_k)\)；
3. 比较两者达到 $\|\nabla f(x_k)\| < 10^{-6}\) 所需的迭代步数，并画出二维平面上的收敛轨迹。

### Problem 3: 线性共轭梯度法 (Linear Conjugate Gradient) (40分)

实现 Hestenes-Stiefel / Fletcher-Reeves 线性共轭梯度法，求解对称正定系统 \(A x = b\)（其中 \(A \in \mathbb{R}^{d \times d}\)）：

\[
r_0 = b - A x_0, \quad p_0 = r_0
\]
\[
\alpha_k = \frac{r_k^T r_k}{p_k^T A p_k}, \quad x_{k+1} = x_k + \alpha_k p_k
\]
\[
r_{k+1} = r_k - \alpha_k A p_k, \quad \beta_{k+1} = \frac{r_{k+1}^T r_{k+1}}{r_k^T r_k}, \quad p_{k+1} = r_{k+1} + \beta_{k+1} p_k
\]

在 \(d=500\) 维随机对称正定矩阵 \(A\) 上测试，验证 CG 是否在不超过 \(d\) 步内理论精确收敛。
