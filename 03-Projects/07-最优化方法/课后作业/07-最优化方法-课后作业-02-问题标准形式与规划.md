## 1. 学习目标

学会将一般优化问题转化为 LP, QP, SOCP, SDP 标准规划形式，并使用 CVXPY 进行求解验证。

## 2. 任务边界与知识依赖

求解求解器（求解库如 CVXPY, Gurobi, SciPy）通常只“认识”标准的优化范式，例如线性规划 (LP)、二次规划 (QP)、二次约束二次规划 (QCQP)、二阶锥规划 (SOCP) 和半定规划 (SDP)。能够将复杂的实际工程约束转化成标准范式，是每一个算法工程师与求解器使用者的基本功。

---

### 关联知识点与前置定理

做题前，请确保已复习以下知识卡：
1. **[[最优化方法-凸优化问题标准形式]]**：
   - **LP 标准形**：$\min c^T x \ \mathrm{s.t.}\ Ax = b, x \ge 0$。
   - **QP 标准形**：目标含正定二次型 $\frac{1}{2} x^T P x + q^T x$。
2. **[[最优化方法-锥规划与半定规划SDP]]**：
   - **Schur 补引理 (Schur Complement)**：设对称分块矩阵 $X = \begin{bmatrix} A & B \\ B^T & C \end{bmatrix}$，若 $A \succ 0$，则 $X \succeq 0 \iff C - B^T A^{-1} B \succeq 0$。

## 3. 详细题目与要求

### 题目 1：绝对值范数最小化问题的 LP 转化（手推题）

**问题背景**：稀疏信号恢复与鲁棒回归中，常出现包含绝对值的最小化问题：
$$\min_{x \in \mathbf{R}^n} \|Ax - b\|_1 + \gamma \|x\|_1$$
其中 $A \in \mathbf{R}^{m \times n}, b \in \mathbf{R}^m, \gamma > 0$。

**任务**：引入辅助变量（Slack Variables），将其严格转化为标准线性规划 (LP) 形式：
$$\min_{y} c^T y \quad \text{s.t.} \quad G y \le h$$

#### 💡 小白解题提示 (Hints)：

1. **提示 1 (拆解绝对值)**：对于标量 $z$，条件 $|z| \le u$ 等价于一对线性不等式 $-u \le z \le u$（即 $z \le u$ 且 $-z \le u$）。
2. **提示 2 (引入辅助变量)**：引入辅助向量 $u \in \mathbf{R}^m$ 来界定 $|Ax - b|_1 = \sum_{i=1}^m |a_i^T x - b_i| \le \sum u_i$，以及引入 $v \in \mathbf{R}^n$ 来界定 $|x|_1 = \sum_{j=1}^n |x_j| \le \sum v_j$。
3. **提示 3 (构造决策变量)**：定义总决策变量 $y = [x^T, u^T, v^T]^T \in \mathbf{R}^{n+m+n}$。目标函数变成线性的 $c^T y = 0^T x + \mathbf{1}^T u + \gamma \mathbf{1}^T v$。写出对应矩阵 $G$ 与 $h$。

---

### 题目 2：QCQP 转化为半定规划 SDP（手推与建模题）

**问题背景**：约束优化中常遇到二次约束二次规划 (QCQP)：
$$\min_{x} x^T P_0 x + q_0^T x + r_0 \quad \text{s.t.} \quad x^T P_i x + q_i^T x + r_i \le 0, \ i=1,\dots,K$$
其中 $P_0, P_i \succ 0$。

**任务**：利用 **Schur 补引理**，将单约束 QCQP：
$$\min_{x} \frac{1}{2} x^T P_0 x + q_0^T x \quad \text{s.t.} \quad x^T P_1 x \le 1$$
转化为标准半定规划 (SDP) 的线性矩阵不等式 (LMI) 形式。

#### 💡 小白解题提示 (Hints)：

1. **提示 1 (二次项转化为矩阵)**：由于 $P_1 \succ 0$，可分解 $P_1 = R^T R$（如 Cholesky 分解）。约束变成 $\|R x\|_2^2 \le 1$。
2. **提示 2 (Schur 补化简)**：不等式 $1 - (Rx)^T (1)^{-1} (Rx) \ge 0$ 根据 Schur 补，等价于如下 $2 \times 2$ 分块矩阵：
   $$\begin{bmatrix} I & R x \\ (R x)^T & 1 \end{bmatrix} \succeq 0$$
3. **提示 3 (目标函数的辅助变量表述)**：引入标量 $t$，令目标函数小于等于 $t$：$\frac{1}{2} x^T P_0 x + q_0^T x \le t$，再次对二次项运用 Schur 补转换！

### 题目 3：基于 CVXPY 的模版转化验证（编程题）

**任务**：使用 Python 中的 `cvxpy` 库，分别用直接调用和化为 LP 后调用求解器求解小规模 $\|Ax - b\|_1$ 问题，验证两极解的一致性。

## 运行环境与依赖

- **Python 环境**：Python 3.10+，包含 `cvxpy`, `numpy`
- **运行命令**：`python hw02_lp_sdp.py`

#### Python Starter Code 框架：

```python
import cvxpy as cp
import numpy as np

# 随机生成测试数据
np.random.seed(42)
m, n = 10, 5
A = np.random.randn(m, n)
b = np.random.randn(m)
gamma = 0.5

# 1. 方式一：CVXPY 原生表达式
x_direct = cp.Variable(n)
cost_direct = cp.norm1(A @ x_direct - b) + gamma * cp.norm1(x_direct)
prob_direct = cp.Problem(cp.Minimize(cost_direct))
prob_direct.solve()

# 2. 方式二：手动转为 LP
x_lp = cp.Variable(n)
u = cp.Variable(m)
v = cp.Variable(n)

constraints = [
    A @ x_lp - b <= u,
    -(A @ x_lp - b) <= u,
    x_lp <= v,
    -x_lp <= v
]
cost_lp = cp.sum(u) + gamma * cp.sum(v)
prob_lp = cp.Problem(cp.Minimize(cost_lp), constraints)
prob_lp.solve()

# 测试校验断言
print(f"原生求解最小值: {prob_direct.value:.6f}")
print(f"手动 LP 求解最小值: {prob_lp.value:.6f}")
assert np.isclose(prob_direct.value, prob_lp.value, atol=1e-5), "求解结果不一致！"
```
