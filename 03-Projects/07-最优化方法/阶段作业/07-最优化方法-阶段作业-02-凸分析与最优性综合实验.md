## 3. 详细题目与要求

### 任务 1：软间隔 SVM 的对偶问题推导（手推部分）

考虑软间隔 SVM 原问题 (Primal Problem)：
$$\min_{w, b, \xi} \frac{1}{2} \|w\|_2^2 + C \sum_{i=1}^N \xi_i$$
$$\text{s.t.} \quad y_i (w^T x_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0, \quad i=1,\dots,N$$
其中 $C > 0$ 为惩罚常数，$\xi_i$ 为松弛变量。

#### 💡 推导步骤引导：
1. **写出拉格朗日函数**：引入乘子 $\alpha_i \ge 0$ 和 $\mu_i \ge 0$：
   $$L(w, b, \xi, \alpha, \mu) = \frac{1}{2} \|w\|_2^2 + C \sum_{i=1}^N \xi_i - \sum_{i=1}^N \alpha_i [y_i(w^T x_i + b) - 1 + \xi_i] - \sum_{i=1}^N \mu_i \xi_i$$
2. **求关于原变量的极小化**：
   - $\frac{\partial L}{\partial w} = 0 \implies w = \sum_{i=1}^N \alpha_i y_i x_i$
   - $\frac{\partial L}{\partial b} = 0 \implies \sum_{i=1}^N \alpha_i y_i = 0$
   - $\frac{\partial L}{\partial \xi_i} = 0 \implies C - \alpha_i - \mu_i = 0 \implies \alpha_i \le C$
3. **推导出对偶问题 (Dual Problem)**：
   $$\max_{\alpha} \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j (x_i^T x_j)$$
   $$\text{s.t.} \quad \sum_{i=1}^N \alpha_i y_i = 0, \quad 0 \le \alpha_i \le C, \ i=1,\dots,N$$

### 任务 2：使用 CVXPY 求解对偶问题与决策边界可视化（编程部分）

#### Python Starter Code 框架：

```python
import numpy as np
import cvxpy as cp
import matplotlib.pyplot as plt

# 1. 生成合成数据集
np.random.seed(42)
N = 40
X_pos = np.random.randn(N//2, 2) + np.array([1.5, 1.5])
y_pos = np.ones(N//2)
X_neg = np.random.randn(N//2, 2) + np.array([-1.5, -1.5])
y_neg = -np.ones(N//2)

X = np.vstack([X_pos, X_neg])
y = np.hstack([y_pos, y_neg])
C = 1.0

# 2. 构建 CVXPY 对偶问题
alpha = cp.Variable(N)
# 构造 Gram 矩阵与其二次型
K = (X @ X.T) * np.outer(y, y)

objective = cp.Maximize(cp.sum(alpha) - 0.5 * cp.quad_form(alpha, K))
constraints = [cp.sum(cp.multiply(alpha, y)) == 0, alpha >= 0, alpha <= C]

prob = cp.Problem(objective, constraints)
prob.solve()

alpha_val = alpha.value

# 3. 根据 KKT 条件重建 w 和 b
w_val = np.sum((alpha_val * y)[:, None] * X, axis=0)

# 支持向量落在 0 < alpha < C 上的点用于解出 b
sv_mask = (alpha_val > 1e-4) & (alpha_val < C - 1e-4)
if np.any(sv_mask):
    b_val = np.mean(y[sv_mask] - X[sv_mask] @ w_val)
else:
    b_val = 0.0

print(f"求解成功！w = {w_val}, b = {b_val:.4f}")
print("支持向量数量:", np.sum(alpha_val > 1e-4))

# 4. 可视化决策边界
plt.figure(figsize=(8, 6))
plt.scatter(X[y==1][:,0], X[y==1][:,1], color='blue', label='Class +1')
plt.scatter(X[y==-1][:,0], X[y==-1][:,1], color='red', label='Class -1')

# 画支持向量
sv_all = alpha_val > 1e-4
plt.scatter(X[sv_all][:,0], X[sv_all][:,1], s=150, facecolors='none', edgecolors='k', linewidths=1.5, label='Support Vectors')

# 决策面 w1*x1 + w2*x2 + b = 0
x1_grid = np.linspace(-4, 4, 100)
x2_grid = -(w_val[0] * x1_grid + b_val) / w_val[1]
plt.plot(x1_grid, x2_grid, 'k-', label='Decision Boundary')

plt.xlim(-4, 4)
plt.ylim(-4, 4)
plt.legend()
plt.title('Soft-Margin SVM via Convex Dual Formulation')
plt.grid(True)
plt.show()

# 测试校验断言
assert np.sum(sv_all) > 0, "必须成功检测到支持向量！"
```
