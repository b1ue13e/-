## 3. 详细题目与要求

### Task 1: 逻辑回归与自适应学习率对比 ($L_2$ 正则)

在凸光滑损失函数 $f(w) = rac{1}{N} \sum_{i=1}^N \ln(1 + e^{-y_i w^T x_i}) + rac{\lambda}{2} \|w\|_2^2$ 上：
- 实现 Mini-batch SGD、Momentum SGD、Adam 以及 AdamW。
- 观察不同 Mini-batch 大小 ($B \in \{16, 64, 256\}$) 下梯度的方差与震荡情况。

### Task 2: Lasso 稀疏解求解 ($L_1$ 正则与 FISTA)

在非光滑复合目标 $F(w) = rac{1}{2N} \|X w - y\|_2^2 + \lambda \|w\|_1$ 上：
- 实现 ISTA（近端梯度法）与 FISTA（Nesterov 加速近端梯度法）。
- 验证软阈值算子 $\mathbf{prox}_{\gamma \lambda \|\cdot\|_1}$ 生成的稀疏性。
- 对比 ISTA 与 FISTA 在高维稀疏特征选择下的收敛步骤数。

```python
import numpy as np
import matplotlib.pyplot as plt

def soft_thresholding(x, tau):
    """软阈值算子"""
    return np.sign(x) * np.maximum(np.abs(x) - tau, 0.0)

def fista_lasso(X, y, lmbda, max_iters=500, L=None):
    """FISTA 求解 Lasso"""
    N, d = X.shape
    if L is None:
        L = np.linalg.norm(X, ord=2)**2 / N  # Lipschitz 常数
    
    w = np.zeros(d)
    y_k = w.copy()
    t = 1.0
    history = []
    
    for k in range(max_iters):
        # 梯度步
        grad = (1.0 / N) * X.T @ (X @ y_k - y)
        # 近端步
        w_next = soft_thresholding(y_k - (1.0 / L) * grad, lmbda / L)
        # 动量步
        t_next = (1.0 + np.sqrt(1.0 + 4.0 * t**2)) / 2.0
        y_k = w_next + ((t - 1.0) / t_next) * (w_next - w)
        
        w = w_next
        t = t_next
        
        loss = 0.5 / N * np.sum((X @ w - y)**2) + lmbda * np.sum(np.abs(w))
        history.append(loss)
        
    return w, history
```
