# 🧭 07-最优化方法 课程作业总索引

本索引统一追踪本课程下所有形态的验收任务。根据 `AGENTS.md` 规范，所有作业都分布在以下三个规模层级目录中，使用 `assignment_level` 和 `requires` 与知识卡片自动关联。

## 📊 总体进度与统计

```dataviewjs
const hw_pages = dv.pages('"03-Projects/07-最优化方法" and -#索引')
                   .where(p => p.type === "project" && ["homework", "lab", "exam", "reading"].includes(p.project_type || "homework"));

const levels = ["lesson", "stage", "capstone"];
const level_names = { "lesson": "课后作业 (Lesson)", "stage": "阶段作业 (Stage)", "capstone": "大作业 (Capstone)" };

let total = 0;
let done = 0;
const rows = levels.map(level => {
    const pages = hw_pages.where(p => p.assignment_level === level);
    const completed = pages.where(p => p.status === "completed").length;
    total += pages.length;
    done += completed;
    return [
        level_names[level],
        pages.length,
        completed,
        pages.length ? `${Math.round(completed * 100 / pages.length)}%` : "—"
    ];
});

dv.table(["作业规模", "总数", "已完成", "完成率"], rows);
dv.paragraph(`**总览：进度 ${total ? Math.round(done * 100 / total) : 0}%** | ${done} / ${total}`);
```
