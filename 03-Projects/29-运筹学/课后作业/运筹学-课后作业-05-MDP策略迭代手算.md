# 运筹学-课后作业-05-MDP策略迭代手算

> 所属阶段：[[🧭 阶段3-随机与动态决策|阶段 3]] ｜ 形态：题集（problem-set）

## 学习目标

建立 DP 递推；手算策略评估与策略迭代；验证贝尔曼方程。

## 所需知识

- [[运筹学-动态规划]]（四要素、最优性原理、贝尔曼方程）
- [[运筹学-Markov决策过程]]（五元组、策略评估/迭代、值迭代）
- [[运筹学-前置-概率与期望]]

## 任务边界

策略评估必须写出完整的贝尔曼方程组并求解；值迭代阈值 1e-4；禁止复制他人代码或答案。

## 题目

### 1. DP 递推（资源分配）

把 4 单位资源分给 3 个项目，各项目收益函数 $r_k(d)$（自定凸/线性/阶梯各一个），写出 DP 递推并手算最优分配与总收益（倒推表）。

### 2. 最短路径 DP

用 DP 倒推求解课上 4 层最短路径例（A→D），写出每层价值函数 $V_k$ 与最优路径，验证与枚举一致。

### 3. MDP 策略评估（手算）

两状态维修问题（状态好 G/坏 B；修成本 5、好状态收益 10、坏状态收益 2；不修时 G→G 0.8、B→B 0.9；$\gamma=0.9$）：

1. 对"永远不修"策略写贝尔曼方程组并求解 $V(G),V(B)$；
2. 做策略改进，给出新策略；对"B 时修、G 时不修"再评估一轮；
3. 说明策略迭代为何有限步收敛。

### 4. 值迭代（代码）

用 Python 对第 3 题实现值迭代（收敛阈值 1e-4），输出收敛过程（价值随迭代变化）与最优策略，与手算对照。可用 `numpy`，无需 ortools。

## 环境与复现

- `pip install numpy`；值迭代代码需输出收敛曲线数据。

## 提交产物

- `hw05_dp.md`（第 1-3 题手算，含倒推表与方程组）；`hw05_value_iter.py`（第 4 题）。

## 引导与自检

- 常见失败：$\gamma$ 忘乘；状态转移概率弄反；值迭代阈值太松导致不收敛到手算值。
- 提交前检查：方程组两个未知数两个方程、改进后策略明确写出、值迭代输出有中间轮次。
