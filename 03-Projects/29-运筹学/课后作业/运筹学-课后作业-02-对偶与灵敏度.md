# 运筹学-课后作业-02-对偶与灵敏度

> 所属阶段：[[🧭 阶段1-线性规划基础|阶段 1]] ｜ 形态：题集（problem-set）

## 学习目标

写出对偶并验证强对偶；读影子价格；判断参数变化是否改变最优基。

## 所需知识

- [[运筹学-对偶理论与影子价格]]（对偶构造、互补松弛、影子价格）
- [[运筹学-灵敏度分析]]（目标系数/右端项区间、100% 规则）
- [[运筹学-单纯形法]]（最终表检验数、最优基、灵敏度推导基础）

## 任务边界

对偶变量符号必须正确（$\ge$ 约束对应 $y\le0$）；灵敏度区间必须由检验数不等式推导，禁止直接调用求解器灵敏度 API 代替推导。

## 题目

### 1. 对偶构造与强对偶

对 $\min\ 3x_1+4x_2$ s.t. $x_1+x_2\ge2,\ x_1+2x_2\ge3,\ x\ge0$：

1. 写出对偶问题并注明各对偶变量符号；
2. 解原问题与对偶，验证 $p^*=d^*$；
3. 用互补松弛检查你在本题第 2 步求得的原问题最优解的对偶约束状态。

### 2. 影子价格解读

对 $\max\ 3x_1+2x_2$ s.t. $x_1+x_2\le4,\ x_1\le2,\ x_2\le3,\ x\ge0$：

1. 写出对偶并求对偶最优解；
2. 说明三个资源的影子价格，哪个资源最稀缺？为什么 $x_2\le3$ 的影子价格为 0？
3. 若 $b_1$ 从 4 增到 5，最优值变化多少？验证。

### 3. 灵敏度区间

对第 2 题模型：

1. 求 $c_1$（目标系数）保持最优基不变的区间（由最终表检验数不等式推导，写出区间与边界值处最优基的变化）；
2. 求 $b_1$（右端项）的保持区间（由检验数不等式推导，写出区间与边界值处最优基的变化）；
3. 用 OR-Tools 对边界值验证：$c_1=2$ 时最优解是否不唯一（整条边最优）？$b_1=5$ 时最优基是否仍为 $\{x_1,x_2\}$？

### 4. 100% 规则（可选进阶）

$b_1$ 从 4 变化 +20%、$b_3$ 从 3 变化 -20%，用 100% 规则判断最优基是否保证保持（先算各自占允许变化量的百分比，再求和判断结论）；用求解器验证实际是否换基。本题可选，不阻塞主任务。

## 环境与复现

- 用 GLOP 或 `scipy.optimize.linprog` 验证；手算与代码结果需一致。
- 记录灵敏度区间时给出推导过程（检验数不等式），不只写结论。
- **规格验证（2026-08-09，Python 3.13 + scipy）**：`scripts/hw02_verify.py` 已实跑，确认题面模型可解且靶值自洽——Q1 原最优 $(1,1)\ z=7$（强对偶 $p^*=d^*=7$）、Q2 原最优 $(2,2)\ z=10$、Q3 区间 $c_1\ge2$ 与 $b_1\in[2,5]$、Q4 比值和 $0.8+0.6=1.4>1$ 故最优基不保证保持。该脚本仅供你自检靶值，**推导必须在作业中自己完成**（不泄露结论，符合 AGENTS.md §5.5.7）。
