# 运筹学-课后作业-02-对偶与灵敏度

> 所属阶段：[[🧭 阶段1-线性规划基础|阶段 1]] ｜ 形态：题集（problem-set）

## 学习目标

写出对偶并验证强对偶；读影子价格；判断参数变化是否改变最优基。

## 所需知识

- [[运筹学-对偶理论与影子价格]]（对偶构造、互补松弛、影子价格）
- [[运筹学-灵敏度分析]]（目标系数/右端项区间、100% 规则）

## 任务边界

对偶变量符号必须正确（$\ge$ 约束对应 $y\le0$）；灵敏度区间必须由检验数不等式推导，禁止直接调用求解器灵敏度 API 代替推导。

## 题目

### 1. 对偶构造与强对偶

对 $\min\ 3x_1+4x_2$ s.t. $x_1+x_2\ge2,\ x_1+2x_2\ge3,\ x\ge0$：

1. 写出对偶问题并注明各对偶变量符号；
2. 解原问题与对偶，验证 $p^*=d^*$；
3. 用互补松弛检查原最优解 $(1,1)$ 的对偶约束状态。

### 2. 影子价格解读

对 $\max\ 3x_1+2x_2$ s.t. $x_1+x_2\le4,\ x_1\le2,\ x_2\le3,\ x\ge0$（最优 $(2,2)$，$z=10$）：

1. 写出对偶并求对偶最优解；
2. 说明三个资源的影子价格，哪个资源最稀缺？为什么 $x_2\le3$ 的影子价格为 0？
3. 若 $b_1$ 从 4 增到 5，最优值变化多少？验证。

### 3. 灵敏度区间

对第 2 题模型：

1. 求 $c_1$（目标系数）保持最优基不变的区间；
2. 求 $b_1$（右端项）的保持区间；
3. 用 OR-Tools 对边界值验证（如 $c_1=4$ 时是否仍有多个最优解）。

### 4. 100% 规则（可选进阶）

$b_1$ 变化 +20%（允许 +50%）、$b_2$ 变化 -30%（允许 -60%），用 100% 规则判断最优基是否保持；用求解器验证。本题可选，不阻塞主任务。

## 环境与复现

- 用 GLOP 或 `scipy.optimize.linprog` 验证；手算与代码结果需一致。
- 记录灵敏度区间时给出推导过程（检验数不等式），不只写结论。

## 提交产物

- `hw02_duality.md`（手算推导 + 区间推导）；`hw02_verify.py`（数值验证）。
