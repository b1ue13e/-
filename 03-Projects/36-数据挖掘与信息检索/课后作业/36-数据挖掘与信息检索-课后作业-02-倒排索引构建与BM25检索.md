## 📝 题目详细内容

### 任务 1：倒排索引构建与差分编码
1. 建立倒排链表：每个 Term 映射到按 DocID 升序排列的列表；
2. 计算相邻文档 ID 的差分（d-gaps）：$\Delta_i = \text{DocID}_i - \text{DocID}_{i-1}$（其中 $\text{DocID}_0 = \text{DocID}_0$）；
3. 实现 Variable Byte 编码：对每个数值将其 7 位有效位填入字节，最高位（MSB）作为延续位（Continuation Bit，末字节置 1）。

### 任务 2：BM25 排序评分计算
对查询 $Q = (q_1, q_2, \dots, q_m)$，计算文档 $D$ 的相关度得分：
$$\text{Score}_{\text{BM25}}(D, Q) = \sum_{i=1}^m \text{IDF}(q_i) \cdot \frac{\text{TF}(q_i, D) \cdot (k_1 + 1)}{\text{TF}(q_i, D) + k_1 \cdot \left(1 - b + b \cdot \frac{|D|}{\text{avgdl}}\right)}$$
其中 $\text{IDF}(q_i) = \ln \left(\frac{N - \text{DF}(q_i) + 0.5}{\text{DF}(q_i) + 0.5} + 1\right)$。

### 任务 3：Query Likelihood 语言模型与 Dirichlet 平滑
计算查询生成概率：
$$P(Q|D) = \prod_{q \in Q} \frac{\text{TF}(q, D) + \mu \cdot P(q|C)}{|D| + \mu}$$
其中 $\mu$ 为狄利克雷先验超参数，$P(q|C)$ 为全库背景词频概率。

## 💻 Starter Code 骨架

```python
import math
from typing import List, Dict, Tuple
from collections import Counter, defaultdict

class InvertedIndexEngine:
    def __init__(self, k1: float = 1.5, b: float = 0.75, mu: float = 2000.0):
        self.k1 = k1
        self.b = b
        self.mu = mu
        self.postings: Dict[str, List[int]] = defaultdict(list)
        self.doc_lens: Dict[int, int] = {}
        self.collection_freqs: Dict[str, int] = defaultdict(int)
        self.total_tokens = 0
        self.num_docs = 0

    def index_document(self, doc_id: int, text: str):
        tokens = text.lower().split()
        self.doc_lens[doc_id] = len(tokens)
        self.num_docs += 1
        self.total_tokens += len(tokens)
        for t in set(tokens):
            self.postings[t].append(doc_id)
        for t in tokens:
            self.collection_freqs[t] += 1

    @staticmethod
    def vb_encode(numbers: List[int]) -> bytes:
        stream = bytearray()
        for num in numbers:
            bytes_list = []
            while True:
                bytes_list.insert(0, num % 128)
                if num < 128:
                    break
                num //= 128
            bytes_list[-1] += 128
            stream.extend(bytes_list)
        return bytes(stream)
```
