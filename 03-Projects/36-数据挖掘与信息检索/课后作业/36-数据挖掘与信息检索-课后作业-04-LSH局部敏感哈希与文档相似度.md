## 📝 题目详细内容

### 任务 1：$k$-Shingle 与 Jaccard 相似度基准
将长文本转化为 $k$-Shingles 集合，计算真实 Jaccard 相似度：
$$\text{Sim}_{\text{Jaccard}}(S_1, S_2) = \frac{|S_1 \cap S_2|}{|S_1 \cup S_2|}$$

### 任务 2：MinHash 签名矩阵（Signature Matrix）
构建 $n \times m$ 的签名矩阵（$n$ 个哈希函数，$m$ 篇文档）：
$$h_i(x) = (a_i \cdot x + b_i) \pmod p$$
利用随机排列或单次遍历行算法更新每列的最小哈希值 $\text{SIG}(i, c)$，验证定理：
$$P(\text{SIG}(i, c_1) == \text{SIG}(i, c_2)) = \text{Sim}_{\text{Jaccard}}(c_1, c_2)$$

### 任务 3：LSH 分桶与 S 曲线调优
将签名矩阵划分为 $b$ 个 Band，每个 Band 包含 $r$ 行（使得 $n = b \times r$）：
- 只有当两篇文档在至少一个 Band 内的所有 $r$ 个签名完全相同时，才被判定为候选近邻对；
- 候选命中概率为 $1 - (1 - s^r)^b$；根据相似度阈值 $s = 0.8$ 计算最佳 $b$ 与 $r$。

## 💻 Starter Code 骨架

```python
import numpy as np
from typing import List, Set, Tuple, Dict
from collections import defaultdict

class MinHashLSH:
    def __init__(self, num_hashes: int = 100, bands: int = 20, prime: int = 2147483647):
        self.n = num_hashes
        self.b = bands
        self.r = num_hashes // bands
        self.p = prime
        np.random.seed(42)
        self.a = np.random.randint(1, self.p, size=self.n)
        self.b_param = np.random.randint(0, self.p, size=self.n)

    def compute_signature(self, shingle_indices: Set[int]) -> np.ndarray:
        sig = np.full(self.n, np.inf)
        for row in shingle_indices:
            hashes = (self.a * row + self.b_param) % self.p
            sig = np.minimum(sig, hashes)
        return sig.astype(np.int64)

    def get_candidate_pairs(self, signatures: List[np.ndarray]) -> Set[Tuple[int, int]]:
        candidates = set()
        for band_idx in range(self.b):
            start = band_idx * self.r
            end = start + self.r
            bucket: Dict[Tuple[int, ...], List[int]] = defaultdict(list)
            for doc_id, sig in enumerate(signatures):
                sub_sig = tuple(sig[start:end])
                bucket[sub_sig].append(doc_id)
            for doc_list in bucket.values():
                if len(doc_list) > 1:
                    for i in range(len(doc_list)):
                        for j in range(i + 1, len(doc_list)):
                            candidates.add((min(doc_list[i], doc_list[j]), max(doc_list[i], doc_list[j])))
        return candidates
```
