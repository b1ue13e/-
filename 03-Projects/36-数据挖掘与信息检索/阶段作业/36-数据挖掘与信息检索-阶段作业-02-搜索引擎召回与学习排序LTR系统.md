## 📝 题目详细内容

### 任务 1：多路召回与融合检索
1. 稀疏通道：利用 BM25 算法计算关键词与文档的词项匹配得分；
2. 稠密通道：计算 Query Embedding 与 Document Embedding 的余弦相似度；
3. 融合阶段：利用 Reciprocal Rank Fusion（RRF）合并两路召回的前 50 篇候选文档。

### 任务 2：PageRank 链接图拓扑计算
在给定的万维网网页有向图中，构造转移矩阵 $\mathbf{M}$，引入阻尼系数 $d=0.85$ 进行幂迭代计算：
$$\mathbf{r}^{(t+1)} = d \mathbf{M} \mathbf{r}^{(t)} + \frac{1 - d}{N} \mathbf{e}$$
迭代至向量 $\mathbf{r}$ 的 $L_1$ 范数变化小于 $10^{-6}$。

### 任务 3：Pairwise RankNet 神经网络重排序
对文档对 $(D_i, D_j)$ 提取特征向量 $\mathbf{x}_i, \mathbf{x}_j$，计算得分差异 $s_i - s_j$，并通过交叉熵损失函数更新权重参数：
$$C_{ij} = -\bar{P}_{ij} \log P_{ij} - (1 - \bar{P}_{ij}) \log(1 - P_{ij})$$
计算最终的 NDCG@10 指标，验证重排后相对于单路 BM25 的提升幅度。

## 💻 Starter Code 骨架

```python
import numpy as np
from typing import List, Tuple, Dict

class PairwiseRankNet:
    def __init__(self, input_dim: int = 6, hidden_dim: int = 16, lr: float = 0.01):
        self.lr = lr
        np.random.seed(42)
        self.w1 = np.random.randn(input_dim, hidden_dim) * 0.1
        self.b1 = np.zeros(hidden_dim)
        self.w2 = np.random.randn(hidden_dim, 1) * 0.1
        self.b2 = np.zeros(1)

    def forward(self, x: np.ndarray) -> np.ndarray:
        h = np.maximum(0, np.dot(x, self.w1) + self.b1)
        score = np.dot(h, self.w2) + self.b2
        return score.flatten()

    def train_pair(self, x_i: np.ndarray, x_j: np.ndarray, target: float = 1.0):
        """Pairwise 交叉熵损失梯度更新：s_ij = s_i - s_j"""
        h_i = np.maximum(0, np.dot(x_i, self.w1) + self.b1)
        s_i = np.dot(h_i, self.w2) + self.b2
        h_j = np.maximum(0, np.dot(x_j, self.w1) + self.b1)
        s_j = np.dot(h_j, self.w2) + self.b2

        diff = float(s_i - s_j)
        prob = 1.0 / (1.0 + np.exp(-diff))
        grad = prob - target

        self.w2 -= self.lr * grad * (h_i - h_j).reshape(-1, 1)
```
