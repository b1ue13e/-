## 📝 题目详细内容

### 任务 1：GraphSAGE 邻居聚合与归一化
1. 邻居采样：对每个目标节点采样固定数量 $S_k$ 的一阶邻居节点；
2. 聚合函数：计算邻居特征向量的均值（Mean Aggregator）；
3. 特征投影：将自身特征与邻居聚合特征拼接后经过权重矩阵 $\mathbf{W}$ 映射并执行 $L_2$ 归一化。

### 任务 2：跨模态向量检索与双塔推荐
1. 分别提取查询文本与目标图像的特征向量；
2. 计算点积相似度矩阵，优化对称 InfoNCE 对比损失；
3. 构建用户交互历史向量与物品候选向量的点积召回通道。

### 任务 3：可视化图表编码与仪表板
设计包含力导向图（Force-Directed Graph）与损失收敛曲线的可视化配置，严格遵守颜色感知与通道编码原则。

## 💻 Starter Code 骨架

```python
import numpy as np
from typing import List, Dict

class GraphSAGENodeAggregator:
    def __init__(self, in_dim: int = 8, out_dim: int = 4):
        np.random.seed(42)
        self.w = np.random.randn(in_dim * 2, out_dim) * 0.1

    def aggregate_neighbors(self, node_feats: np.ndarray, adj_list: Dict[int, List[int]], target_node: int) -> np.ndarray:
        """邻居采样与均值聚合：h_N(v) = Mean({h_u, u in N(v)})"""
        neighbors = adj_list.get(target_node, [])
        if not neighbors:
            neigh_feat = np.zeros_like(node_feats[target_node])
        else:
            neigh_feat = np.mean(node_feats[neighbors], axis=0)
            
        concatenated = np.concatenate([node_feats[target_node], neigh_feat])
        out_feat = np.maximum(0, np.dot(concatenated, self.w))
        return out_feat / (np.linalg.norm(out_feat) + 1e-9)
```
