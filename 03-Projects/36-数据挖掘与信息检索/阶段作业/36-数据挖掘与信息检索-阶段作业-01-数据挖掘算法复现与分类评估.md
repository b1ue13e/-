## 📝 题目详细内容

### 任务 1：K-Means++ 距离权重概率采样与收敛判定
1. 首个质心随机选取；后续每个质心以与当前已有质心最短距离平方 $D(x)^2$ 成正比的概率 $P(x) = \frac{D(x)^2}{\sum D(x)^2}$ 进行采样；
2. 迭代直至质心漂移距离小于 $\epsilon = 10^{-4}$，计算轮廓系数（Silhouette Coefficient）评估聚类紧凑度。

### 任务 2：高斯朴素贝叶斯分类与平滑
基于贝叶斯公式与条件独立性假设计算连续特征的后验概率：
$$P(Y=c | X) \propto P(Y=c) \prod_{j=1}^d \frac{1}{\sqrt{2\pi \sigma_{cj}^2}} \exp\left(-\frac{(x_j - \mu_{cj})^2}{2\sigma_{cj}^2}\right)$$
对离散特征采用 Laplace 平滑以防止零概率传播。

### 任务 3：ROC-AUC 曲线面积梯形积分实现
按预测正例概率降序排列所有样本，通过累加各阈值下的 True Positive Rate (TPR) 与 False Positive Rate (FPR) 计算积分面积。

## 💻 Starter Code 骨架

```python
import numpy as np
from typing import List, Tuple, Dict

class NaiveBayesClassifier:
    def __init__(self):
        self.class_priors: Dict[int, float] = {}
        self.means: Dict[int, np.ndarray] = {}
        self.vars: Dict[int, np.ndarray] = {}

    def fit(self, X: np.ndarray, y: np.ndarray):
        n_samples, n_features = X.shape
        classes = np.unique(y)
        for c in classes:
            X_c = X[y == c]
            self.class_priors[c] = len(X_c) / n_samples
            self.means[c] = np.mean(X_c, axis=0)
            self.vars[c] = np.var(X_c, axis=0) + 1e-9

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        probas = []
        for x in X:
            posteriors = []
            for c, prior in self.class_priors.items():
                mean = self.means[c]
                var = self.vars[c]
                likelihood = -0.5 * np.sum(np.log(2 * np.pi * var) + ((x - mean) ** 2) / var)
                posteriors.append(np.log(prior) + likelihood)
            exp_p = np.exp(posteriors - np.max(posteriors))
            probas.append(exp_p / np.sum(exp_p))
        return np.array(probas)
```
