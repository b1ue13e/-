# A02 E0 等权与指数基线

> 目标：在没有预测模型时，建立可复核的组合收益、风险、换手和成本基准。

## 解锁条件

- [ ] A01 passed
- [ ] K07–K10 passed

## 必交物

- [ ] E0 等权组合或明确指数基准
- [ ] gross/net 日收益序列
- [ ] 年化收益、波动、最大回撤
- [ ] 换手率和买卖成本明细
- [ ] 零成本控制与三档成本敏感性
- [ ] 与基准共享同一交易日历的断言

## 硬验收

- E0 不计算或伪造 IC；它没有预测分数。
- `net = gross - cost` 可逐期复核。
- 成本非负，买卖费率路径分开。
- 结果同时报告 gross、net、benchmark、gross excess、net excess。
