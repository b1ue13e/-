## 课后作业使用协议

1. 先完成作业 frontmatter 中 `requires` 指向的知识卡，再阅读整份题面；不要边做边更改固定输入。
2. 在仓库根目录创建隔离环境并安装 `03-Projects/金融与时序/03-量化金融/requirements-dev.txt`。
3. 固定输入统一由 `scripts/assignments/lesson_fixtures.py` 生成；fixture 只提供输入，不提供解题实现。
4. 每份作业按题面指定的 `submissions/<assignment_id>/` 结构提交，运行日志必须包含命令、Python 版本和退出码。
5. 先通过公开断言和自己的测试，再写结论；不得修改 fixture、种子或容差来迁就结果。

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r "03-Projects\金融与时序\03-量化金融\requirements-dev.txt"
.\.venv\Scripts\python -m pytest "03-Projects\金融与时序\03-量化金融\tests\assignments" -q
```
