# 量化金融-课后作业-03-时间序列与波动率

## 学习目标与任务

检验平稳性、ACF/PACF 与波动率聚集；实现滚动波动率和 GARCH 基线；比较预测损失、VaR 覆盖率和不同窗口的稳定性，并说明何时模型不适用。

## 环境与执行

使用 Python 3.11、pandas、statsmodels；提交检验表、预测图、回测结果和可复现命令。评分：检验 25，预测 30，风险回测 25，解释 10，可复现性 10。

## 任务边界

- 以收益率序列为对象，覆盖平稳性、ACF/PACF、滚动波动率和 GARCH 基线；不把相关性直接解释为交易因果。
- 预测和 VaR 回测必须按时间顺序进行，测试区间不用于选择模型阶数。

## 提交产物

- 平稳性与相关性检验表、波动率预测图、VaR 覆盖结果、模型对照和命令日志。
- 报告列出频率、窗口、分布假设和模型失败条件。

## 验收标准

- 检验结论与图形一致，预测区间无未来数据；VaR 违约统计和基线对照可复算。
- 至少指出一个 GARCH 不适用或诊断失败的情形。

## 引导自检

- [ ] 先确认价格已转换为收益率并处理缺失值。
- [ ] 再运行常数波动率基线，最后拟合 GARCH。
- [ ] 用时间外窗口检查预测和 VaR，而不是只看样本内拟合。

## 运行证据与失败判定

- 提交收益率转换、缺失处理、平稳性/残差诊断、常数波动率基线和 GARCH 预测表。
- 把价格直接拟合、忽略厚尾、样本外窗口为空或只用 AIC 选模型时，判定为失败。
- 报告预测误差、VaR 违约次数和按日期可追溯的预测值；不得只截图最终指标。

## 最小执行协议

1. 冻结价格字段、复权口径、收益频率、训练/验证/测试日期和缺失处理；价格与收益序列分别保存，防止误把价格拟合为平稳过程。
2. 先运行历史标准差或 EWMA 基线，再估计 GARCH；任何预测在日期 `t` 只能使用 `t` 及之前信息，并保存滚动窗口边界。
3. 对模型收敛、参数约束、标准化残差和 ARCH 剩余效应逐项检查；失败窗口显式标记，不用未来估计值填补。
4. 在固定测试区间比较波动率损失、VaR 违约与连续违约；测试结果不得用于重新选择阶数或分布。
5. 提交数据卡、配置、脚本、逐日预测、诊断图和命令日志；只提交样本内拟合图不通过。

**最低通过判据**：逐日预测可复算，测试区间未参与调参，至少一种样本外损失和 VaR 覆盖诊断完整报告；模型未优于基线时应明确判为负结果。
