# HW10 Grader Notes

这份说明是老师视角的批改口径，不是学生答案。

## 重点看什么

- 是否真正理解 `HRP 分层风险平价` 的任务边界
- 是否按数据契约和协议完成作业
- 是否完成 `HRP vs MPT vs 1/N` 并做公平对照
- 是否能解释结果而不是只堆数字

## 明确不看什么

- 不以最复杂模型为优先
- 不以最好看结果为唯一评价标准
- 不要求学生复现外部论文的全部细节

## 批改时建议追问的问题

- 为什么 HRP 不需要直接求逆？
- 样本外稳健比样本内最优更重要吗？
- 哪些市场环境下 HRP 也会失败？

## 一票否决项

- 数据来源不清楚
- 存在明显未来信息但未说明
- 没有 baseline
- 没有失败案例或边界说明
