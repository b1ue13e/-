# HW15 Milestones

- 明确作业题目：`挂单成交概率与队列位置`
- 确认前置知识是否具备
- 跑通 starter 和 smoke test

## M1 - 数据与协议冻结

- 真实数据到位
- 口径说明写入 README
- 训练 / 验证 / 测试或样本内 / 样本外切分固定

## M2 - Baseline 完成

- 完成最小 baseline：`基础队列模型 + 成交概率估计`
- 记录关键指标
- 记录失败案例和异常现象

## M3 - 正式交付

- 完成报告
- 完成提交清单
- 确认能复现
