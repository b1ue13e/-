# HW14 Grader Notes

这份说明是老师视角的批改口径，不是学生答案。

## 重点看什么

- 是否真正理解 `暗池与智能订单路由` 的任务边界
- 是否按数据契约和协议完成作业
- 是否完成 `单市场执行 vs 多市场 SOR` 并做公平对照
- 是否能解释结果而不是只堆数字

## 明确不看什么

- 不以最复杂模型为优先
- 不以最好看结果为唯一评价标准
- 不要求学生复现外部论文的全部细节

## 批改时建议追问的问题

- 为什么路由不是简单选最优价？
- 延迟对齐如何改变结果？
- 暗池节省点差是否伴随其他代价？

## 一票否决项

- 数据来源不清楚
- 存在明显未来信息但未说明
- 没有 baseline
- 没有失败案例或边界说明
