# HW01 Grader Notes

这份说明是老师视角的批改口径，不是学生答案。

## 重点看什么

- 是否真正理解 `CAPM 资产定价与单股 Alpha/Beta 归因` 的任务边界
- 是否按数据契约和协议完成作业
- 是否完成 `单资产 CAPM + 滚动 Beta` 并做公平对照
- 是否能解释结果而不是只堆数字

## 明确不看什么

- 不以最复杂模型为优先
- 不以最好看结果为唯一评价标准
- 不要求学生复现外部论文的全部细节

## 批改时建议追问的问题

- 你的 alpha 与 beta 分别在说什么？
- 滚动 Beta 为什么会变化？
- 如果 benchmark 换掉，结论会变化吗？

## 一票否决项

- 数据来源不清楚
- 存在明显未来信息但未说明
- 没有 baseline
- 没有失败案例或边界说明
