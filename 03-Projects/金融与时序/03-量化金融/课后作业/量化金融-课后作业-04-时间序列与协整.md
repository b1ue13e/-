# 量化金融-课后作业-04-时间序列与协整

## 作业定位

本作业要求先用 AR(2) 的根和 Yule-Walker 方程建立“平稳性可推导”的基准，再进入 ADF 与 Engle-Granger。这样可以避免把软件返回的单个 p 值误当成时间序列结论。

## 学习目标

- 从 AR 特征根、均值和自协方差判断协方差平稳性。
- 明确 ADF 的原假设、确定性项、滞后数和样本长度。
- 区分相关、共同趋势、协整残差平稳与可交易策略。

## 任务边界

- 全部实验使用合成数据，固定 `seed=404`、`n=1200`、`burn_in=200`。
- ADF 固定为 `regression="c"`、`maxlag=1`、`autolag=None`，不得根据 p 值反复换设定。
- 主任务不构造交易信号，不估计收益、成本或 Sharpe ratio。
- 协整部分是本地课程扩展；MIT Problem Set 4 只作为 AR/MA/平稳性主题来源。

## 固定输入

### 过程 A：平稳 AR(2)

$$
z_t=0.2+0.6z_{t-1}-0.2z_{t-2}+\epsilon_t,qquad
\epsilon_t\sim N(0,1).
$$

### 过程 B：随机游走

$$
x_t=x_{t-1}+\eta_t,qquad \eta_t\sim N(0,1),\qquad x_0=0.
$$

### 过程 C：协整对

$$
u_t=0.65u_{t-1}+\nu_t,\quad \nu_t\sim N(0,0.5^2),\qquad
y_t=2+1.5x_t+u_t.
$$

### 过程 D：伪回归负例

$$
a_t=a_{t-1}+e_t,\qquad b_t=b_{t-1}+v_t,
$$

其中 $e_t,v_t$ 相互独立且均为 $N(0,1)$。

## 题目细化

### Q1 AR(2) 理论基准（25 分）

1. 推导过程 A 的无条件均值。
2. 写出特征多项式并计算根；说明根位于单位圆外时为何平稳。
3. 用 Yule-Walker 方程求 $\rho_1$ 与 $\rho_2$，再递推到 $\rho_{10}$。
4. 模拟过程 A，比较理论 ACF 与样本 ACF 的前 10 阶；报告最大绝对差，但不要求逐阶单调接近。

### Q2 ADF 协议（20 分）

1. 分别对过程 A 和 B 运行固定规格 ADF。
2. 输出 `series/nobs/regression/maxlag/test_stat/pvalue/critical_5pct/decision`。
3. 用一句完整陈述解释拒绝或不拒绝原假设，禁止写“接受平稳/接受单位根”。
4. 再取前 80 个观测运行相同检验，说明检验功效与样本长度的关系；不得用短样本结果替换主结果。

### Q3 Engle-Granger 两步法（35 分）

1. 分别对 `x_t` 和 `y_t` 运行 ADF，确认二者的积分阶判断使用同一规格。
2. 在全样本上回归 $y_t=\alpha+\beta x_t+\hat u_t$，报告 alpha、beta 与残差。
3. 对 $\hat u_t$ 运行残差单位根检验，并明确这不是普通 ADF 临界值可无条件替代的场景；同时调用 `statsmodels.tsa.stattools.coint` 作为 Engle-Granger 主判据。
4. 验证生成机制下 `y - 2 - 1.5*x` 与保存的 `u` 在数值容差内一致；这项是数据生成审计，不是估计答案。
5. 对过程 D 重复两步法，保留任何偶然显著结果，并解释多次试验会放大假发现概率。

### Q4 研究结论边界（20 分）

提交一页“允许说 / 不允许说”清单，至少覆盖：

- ADF 不拒绝单位根；
- 两条序列高度相关；
- Engle-Granger 拒绝无协整；
- 残差均值回复；
- 是否可以宣称存在稳定套利。

每条必须指出还缺哪项证据。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| AR(2) 模拟发散 | 系数符号、特征根判据或 burn-in |
| ADF 结果每次变化 | 随机数生成器是否在函数内部无控制地重建 |
| `y-2-1.5*x` 不等于 `u` | 序列对齐、burn-in 切片是否一致 |
| 协整回归残差均值不近 0 | 回归是否遗漏截距 |
| 两独立随机游走“显著” | 保留结果，检查是否进行了多次挑选 |
