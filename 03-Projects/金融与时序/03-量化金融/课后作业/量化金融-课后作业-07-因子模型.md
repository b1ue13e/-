# 量化金融-课后作业-07-因子模型

## 作业定位

本作业先用 PCA 建立“统计因子”的可验证基准，再区分时间序列回归中的暴露与 Fama-MacBeth 横截面回归中的风险溢价。三种量不能混用：主成分载荷、资产 beta、横截面 lambda 各有不同含义。

## 学习目标

- 解释 PCA 载荷的符号不唯一与协方差重构不变量。
- 在冻结训练期估计资产因子暴露，并保留 alpha 与残差诊断。
- 用固定 beta 做逐期横截面回归，汇总风险溢价和不确定性。

## 任务边界

- 主任务仅使用固定合成面板，不下载 Fama-French 数据。
- 数据形状固定为 `T=240` 月、`N=40` 资产、`K=3` 因子；`seed=707`。
- 前 `180` 月只估计 beta，后 `60` 月只做横截面风险溢价评价。
- 因子集合在生成数据前固定，不添加结果驱动的新因子。

## 固定输入

因子均值与协方差：

$$
\lambda=\begin{bmatrix}0.005\\0.002\\0.003\end{bmatrix},\qquad
\Omega=\begin{bmatrix}
0.0016&0.0002&0.0001\\
0.0002&0.0009&0.00015\\
0.0001&0.00015&0.0012
\end{bmatrix}.
$$

使用单一 `numpy.random.default_rng(707)`，按以下顺序生成：

```python
factors = rng.multivariate_normal(lambda_, Omega, size=240)
betas[:, 0] = rng.normal(1.0, 0.20, size=40)
betas[:, 1] = rng.normal(0.0, 0.50, size=40)
betas[:, 2] = rng.normal(0.0, 0.50, size=40)
idiosyncratic = rng.normal(0.0, 0.03, size=(240, 40))
returns = factors @ betas.T + idiosyncratic
decoy = rng.normal(0.0, factors[:, 0].std(ddof=0), size=240)
```

列名固定为 `MKT/SMB/HML`；这些名称只表示合成因子的角色，不代表真实 Fama-French 数据。

## 题目细化

### Q1 PCA 因子基准（20 分）

1. 对固定矩阵 $\Omega$ 求特征值与标准化特征向量，并按特征值降序排列。
2. 验证 $\Omega=V\Lambda V^T$、$V^TV=I$，报告前三个解释方差比例。
3. 将第一特征向量乘以 `-1`，证明协方差重构不变；解释为什么载荷符号本身不能单独解释为正负经济效应。
4. 比较对协方差矩阵和相关矩阵做 PCA 的载荷差异，说明标准化改变了什么。

### Q2 时间序列因子暴露（30 分）

1. 仅使用前 180 月，对每个资产估计
   $$
   r_{i,t}=\alpha_i+\beta_{i,M}MKT_t+\beta_{i,S}SMB_t+\beta_{i,H}HML_t+\epsilon_{i,t}.
   $$
2. 输出每个资产的 alpha、三项 beta、标准误、残差波动率和训练期 $R^2$。
3. 将估计 beta 与生成真值比较，报告 MAE 与按因子分组的误差；不得删除误差大的资产。
4. 对一个资产验证正规方程 $X^T\hat\epsilon\approx0$，并说明 beta 是条件相关暴露而非因果效应。

### Q3 Fama-MacBeth 横截面回归（30 分）

1. 固定 Q2 的训练期 beta；对测试期每个月执行
   $$
   r_{i,t}=\gamma_{0,t}+\gamma_{M,t}\hat\beta_{i,M}+\gamma_{S,t}\hat\beta_{i,S}+\gamma_{H,t}\hat\beta_{i,H}+e_{i,t}.
   $$
2. 输出 60 行逐月 gamma、截面样本数和截面 $R^2$。
3. 汇总每个 gamma 的时间均值、朴素标准误 `std(gamma_t)/sqrt(60)` 和 95% 区间。
4. 将平均 gamma 与生成因子均值 `lambda` 比较，但不得要求每项在有限样本中精确相等。
5. 说明为什么这里的标准误没有处理自相关、第一阶段 beta 估计误差和 Shanken 修正。

### Q4 负控与时间协议（20 分）

1. 将独立 `decoy` 加入时间序列回归，报告其 beta 分布和对训练 $R^2$ 的增量。
2. 构造错位负例：用 `factors[t+1]` 解释 `returns[t]`；保留结果并标记为 `invalid_alignment`。
3. 写出因子时间戳、资产收益区间和可用时间；解释真实数据中公告滞后为何会改变协议。
4. 用不超过 200 字区分：PCA 载荷、时间序列 beta、横截面 lambda、因果效应。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| PCA 重构失败 | 特征值排序后是否同步重排特征向量 |
| beta 形状为 `(3,40)` | 资产/因子轴是否转置 |
| Fama-MacBeth 只有一行 | 是否错误地做了一次 pooled regression |
| gamma 极不稳定 | 截面是否含截距、beta 是否共线、资产数是否正确 |
| decoy 显著 | 保留有限样本结果，检查是否事后筛选或数据错位 |
