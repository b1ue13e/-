# 量化金融-课后作业-05-波动率建模

## 作业定位

本作业从“固定时间跨度内加密采样”开始，先看清漂移和波动率估计的差异，再实现 GARCH 过滤、约束估计和单步递推预测。重点是条件方差的时间信息协议，不是比较一批模型后挑最优结果。

## 学习目标

- 推导 GBM 对数增量的漂移与波动率估计量，并解释一致性差异。
- 实现 GARCH(1,1) 方差递推和高斯准似然，验证参数约束。
- 以冻结训练/测试切分比较 GARCH 与常方差基线，保留失败拟合。

## 任务边界

- 全部数据由固定生成机制产生，不使用外部行情。
- 主模型仅为 Gaussian GARCH(1,1)；GJR-GARCH 是可选扩展，不影响通过。
- 模型参数只在训练集估计一次；测试期逐点预测时只能使用上一期已观察收益。
- 不允许用测试集选择初值、约束、优化器或模型。

## 固定输入

### 实验 A：GBM 对数增量

$$
dS_t=\mu_*S_tdt+\sigma S_tdW_t,qquad
\mu_*=0.06,\quad \sigma=0.20,\quad T=4.
$$

对 `n in {64, 256, 1024, 4096}`，令 $h=T/n$，生成

$$
Y_i=\log(S_{t_i}/S_{t_{i-1}})\sim N((\mu_*-\sigma^2/2)h,\sigma^2h).
$$

每种 `n` 做 `replications=500`，随机种子固定为 `505`。

### 实验 B：GARCH(1,1)

$$
r_t=\sqrt{h_t}z_t,\quad z_t\sim N(0,1),\qquad
h_t=\omega+\alpha r_{t-1}^2+\beta h_{t-1},
$$

固定真值：

```text
omega = 0.000002
alpha = 0.07
beta  = 0.90
n = 3000
burn_in = 500
seed = 505
```

丢弃 burn-in 后，前 `1800` 个观测为训练集，后 `700` 个为测试集。

## 题目细化

### Q1 高频采样下的漂移与波动率（25 分）

1. 推导每个 `n` 下对数漂移 $\mu=\mu_*-\sigma^2/2$ 与 $\sigma^2$ 的极大似然估计量。
2. 对 500 次重复实验报告两类估计量的均值、偏差和 RMSE。
3. 画出 RMSE 随 `n` 的变化，并解释为什么固定 $T$ 时加密采样对波动率和漂移提供的信息不同。
4. 报告使用 `ddof=0` 还是 `ddof=1`，并解释它与 MLE/无偏估计的区别。

### Q2 GARCH 递推与理论条件（20 分）

1. 推导 $E[h_t]=\omega/(1-\alpha-\beta)$ 的条件。
2. 用无条件方差初始化 `h0`，实现 `filter_variance(returns, omega, alpha, beta)`。
3. 验证所有 $h_t>0$、$\omega>0$、$\alpha,\beta\ge0$、$\alpha+\beta<1$。
4. 分别用 `beta=0.95` 和 `alpha=-0.01` 构造失败配置；函数必须拒绝并说明原因。

### Q3 受约束准似然估计（30 分）

1. 实现高斯负对数准似然：
   $$
   \ell_t=\frac12\left(\log h_t+\frac{r_t^2}{h_t}\right).
   $$
2. 只用训练集估计 $(\omega,\alpha,\beta)$。推荐对参数做变换后调用 `scipy.optimize.minimize`，或显式约束。
3. 保存优化器 `success/message/nit/fun`、初值、最终参数和约束余量 `1-alpha-beta`。
4. 至少运行一个故意不合格的初值或过小迭代上限，保留失败日志；不得只报告成功运行。
5. 解释“估计参数接近生成真值”与“模型适用于真实市场”之间的差别。

### Q4 冻结测试集预测（25 分）

1. 用训练集末期条件方差初始化测试递推；时点 `t` 的预测只能使用 `r_{t-1}`。
2. 比较 GARCH 与训练集常方差基线，指标固定为 MSE 与 QLIKE：
   $$
   QLIKE_t=\log \hat h_t+\frac{r_t^2}{\hat h_t}.
   $$
3. 输出每个测试时点的 `return/realized_proxy/garch_forecast/constant_forecast`。
4. 无论哪一模型胜出都保留结果；不得在测试集上改初值或模型。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| 方差出现负数 | 参数约束、初始方差和递推索引 |
| 似然为 `nan/inf` | `h_t<=0`、对数零值或输入非有限 |
| 测试表现异常好 | 是否在测试期重新拟合或用了 `r_t` 预测 `h_t` |
| 参数贴近边界 | 初值、缩放、约束变换与识别性 |
| 漂移 RMSE 不随 `n` 明显下降 | 先回到固定时间跨度的信息量推导 |
