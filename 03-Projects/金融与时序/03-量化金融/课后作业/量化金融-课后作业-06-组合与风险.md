# 量化金融-课后作业-06-组合与风险

## 作业定位

本作业把组合优化与尾部风险放在同一个冻结协议里：先用训练样本确定组合，再只在测试样本衡量 VaR/ES。不能根据测试期尾部结果回头更换权重。

## 学习目标

- 推导并实现全局最小方差组合，验证预算、正定性和 KKT 条件。
- 构造无卖空有效前沿，并处理不可行目标收益。
- 在统一损失符号下比较 Gaussian、历史和 POT-EVT VaR/ES。

## 任务边界

- 使用固定合成数据，不下载行情。
- 所有组合权重只用训练集 `0:3000` 估计；测试集 `3000:5000` 只评价风险。
- 损失固定定义为 $L_t=-w^Tr_t$；所有 VaR/ES 均以正损失数报告。
- 置信度固定为 `0.95` 与 `0.99`；不得挑选使模型表现最好看的置信度。

## 固定输入

年化期望收益、波动率和相关矩阵为：

$$
\mu=\begin{bmatrix}0.04\\0.06\\0.09\\0.05\end{bmatrix},\qquad
\sigma=\begin{bmatrix}0.10\\0.15\\0.20\\0.12\end{bmatrix},
$$

$$
C=\begin{bmatrix}
1&0.30&0.10&0.20\\
0.30&1&0.40&0.25\\
0.10&0.40&1&0.15\\
0.20&0.25&0.15&1
\end{bmatrix},\qquad
\Sigma=diag(\sigma)Cdiag(\sigma).
$$

收益生成器固定为：

```python
seed = 606
n = 5000
df = 5
daily_cov = Sigma / 252
z = rng.standard_t(df=df, size=(n, 4)) / sqrt(df / (df - 2))
returns = z @ cholesky(daily_cov).T
train, test = returns[:3000], returns[3000:]
```

## 题目细化

### Q1 协方差与全局最小方差（25 分）

1. 验证 `C` 与 `Sigma` 对称、对角线含义正确且最小特征值非负。
2. 推导允许卖空时的全局最小方差权重：
   $$
   w_{gmv}=\frac{\Sigma^{-1}\mathbf1}{\mathbf1^T\Sigma^{-1}\mathbf1}.
   $$
3. 不显式求逆，使用线性方程求权重；验证 `sum(w)=1` 和一阶条件。
4. 用训练样本协方差分别计算解析 GMV 与无卖空 GMV，报告权重和训练方差。
5. 将第 4 项资产复制为第 5 项，构造奇异协方差负例；实现必须给出明确失败或声明采用的正则化，不能静默求伪逆。

### Q2 无卖空有效前沿（25 分）

1. 对目标年化收益 `0.04, 0.05, 0.06, 0.07, 0.08, 0.09` 求解最小方差组合，约束为 `sum(w)=1`、`w>=0`、`mu.T@w=target`。
2. 输出 `target/feasible/weights/variance/solver_status/constraint_residual`。
3. 增加目标 `0.11` 作为不可行负例；不得返回“最接近”权重冒充可行解。
4. 与等权组合比较训练期收益和方差，但不按训练结果宣布测试期赢家。

### Q3 冻结权重下的 VaR/ES（30 分）

固定使用 Q1 的无卖空 GMV 权重。所有分布参数和分位数只用训练损失估计，测试损失只用于超限评价：

1. Gaussian VaR 与 ES；写出正态分布公式和年化/单日单位。
2. 历史 VaR 与历史 ES；明确训练分位数的插值方法。
3. POT-EVT：以训练损失的 95% 经验分位数为阈值，只对训练超额损失拟合 GPD，报告 `threshold/exceedances/shape/scale`，再估计 99% VaR；只有 `shape<1` 时报告有限 ES。
4. 对每种方法验证同一置信度下 `ES >= VaR`；若不满足，先检查符号与尾部方向。
5. 在测试期逐日使用此前 250 个已观察损失重估历史 99% VaR，并做超限计数；只报告超限率，不要求执行复杂回测检验。

### Q4 压力与结论边界（20 分）

1. 将所有非对角相关系数提高 `0.20` 并截断到 `0.95`，重新检查相关矩阵是否正半定；若不是，停止而不是直接优化。
2. 在合法压力矩阵下计算固定权重的组合方差变化。
3. 回答：为什么训练期最小方差不等于测试期最低损失？为什么 Gaussian VaR 与 EVT 可能给出不同尾部判断？
4. 写出本题未覆盖的至少三项真实部署风险。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| 前沿出现负方差 | 协方差矩阵、目标函数或矩阵乘法 |
| 目标 0.11 被标为可行 | 收益约束残差或优化器状态是否被忽略 |
| ES 小于 VaR | 损失符号、尾部方向、分位数索引 |
| GPD 拟合不稳定 | 超额损失是否为正、样本数和 `floc=0` |
| 压力矩阵非 PSD | 相关系数逐项修改不保证整体合法 |

## 验收标准

- 组合权重满足预算和约束，奇异/不可行负例被明确处理。
- 有效前沿输出全部目标而非只保留成功点。
- 三种 VaR/ES 使用冻结权重、统一损失口径和完整参数记录。
- 压力分析先验证矩阵合法性，再讨论风险变化。

## 失败条件

- 使用测试集重新估计权重或选择组合。
- 对不可行优化、奇异矩阵或 GPD 失败静默回退。
- 混用收益与损失符号，或混用日/年化单位。
- 只报告风险最低的模型，不保留其他方法与超限结果。
