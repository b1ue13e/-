# 量化金融-课后作业-01-线性代数与一周期模型

## 作业定位

这不是一次 NumPy API 练习。目标是把矩阵的秩、线性方程和正半定性放进一周期定价语境，并能在代码给出结果前判断结果是否可能成立。

## 学习目标

- 用矩阵的形状、秩和列空间解释“能否复制一项支付”。
- 从资产价格和状态支付求状态价格，并用正性判断无套利。
- 用协方差矩阵验证组合方差，识别非对称或非正半定输入。

## 任务边界

- 只使用题面给定的小矩阵；不得调用优化器替代推导。
- Python 只负责复核手算和执行断言；手算过程是必交证据。
- 本地题面受 MIT 18.S096 Problem Set 1 的线性代数主题启发，并连接 MIT 18.642 一周期模型；不是 MIT 官方题目的翻译或答案。

## 固定输入

### 输入 A：支付与价格

两种未来状态为 `up/down`，两项可交易资产为债券 `B` 与股票 `S`。状态在行、资产在列：

$$
X=\begin{bmatrix}1.02&132\\1.02&88\end{bmatrix},\qquad
p=\begin{bmatrix}1\\100\end{bmatrix}.
$$

待定价或复制的支付为：

$$
c=\begin{bmatrix}15\\0\end{bmatrix},\qquad
d=\begin{bmatrix}6\\4\end{bmatrix}.
$$

### 输入 B：组合矩

三项资产的期望简单收益与协方差矩阵为：

$$
\mu=\begin{bmatrix}0.04\\0.07\\0.10\end{bmatrix},\qquad
\Sigma=\begin{bmatrix}
0.0100&0.0018&0.0012\\
0.0018&0.0225&0.0045\\
0.0012&0.0045&0.0400
\end{bmatrix},\qquad
w=\begin{bmatrix}0.50\\0.30\\0.20\end{bmatrix}.
$$

## 题目细化

### Q1 线性代数诊断（20 分）

1. 写出 `X`、`p`、`c`、`Sigma` 和 `w` 的形状，并说明 `X.T @ q = p` 中每个量的经济含义。
2. 判断以下说法的真假；错误时给出一个最小反例：
   - 方阵满秩等价于可逆；
   - 对称矩阵必为正半定；
   - `rank(AB) <= rank(A)`；
   - 协方差矩阵允许存在负特征值。
3. 不调用 `inv`，分别用消元和 `solve` 复核一个线性方程组；解释为什么显式求逆不是默认实现。

### Q2 状态价格、复制与无套利（35 分）

1. 手算状态价格向量 `q`，使 `X.T @ q = p`。报告重定价残差 `X.T @ q - p`。
2. 检查 `q` 是否逐项为正，并说明该检查与无套利的关系。
3. 分别求支付 `c` 与 `d` 的无套利价格。
4. 对 `c` 求复制组合 `h`，使 `X @ h = c`；验证 `p.T @ h` 与状态价格定价一致。
5. 将股票现价从 `100` 改为 `140`，重新计算状态价格。若出现非正状态价格，说明哪个无套利条件失败；不要求构造交易所级可执行策略。

### Q3 组合矩与输入防线（30 分）

1. 手算 `w.T @ mu` 与 `w.T @ Sigma @ w`，并用 Python 复核。
2. 检查 `sum(w)=1`、`Sigma=Sigma.T` 和 `lambda_min(Sigma) >= -1e-12`。
3. 构造两个失败输入：一个权重维度错误；一个对角线为正但存在负特征值的对称矩阵。
4. 实现 `validate_covariance(matrix, tol=1e-12)`；失败时必须抛出含原因的异常，不能静默截断负特征值。

### Q4 一页决策说明（15 分）

用不超过 300 字回答：

- “线性方程有解”和“存在唯一无套利价格”之间还缺哪些条件？
- 数值残差很小为什么不自动证明金融假设正确？
- 哪一个失败输入最可能在真实研究代码中悄悄传播，为什么？

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| `solve` 报 singular matrix | `X.T` 的秩、资产支付是否线性相关 |
| 价格复核正确但复制失败 | 状态/资产轴是否转置错误 |
