# 量化金融-课后作业-08-随机微积分与期权

## 作业定位

本作业要求先判断适应性与鞅，再应用伊藤引理，最后才进入 Black-Scholes 和蒙特卡洛。数值价格必须由无套利边界、put-call parity 和解析解共同约束。

## 学习目标

- 在给定滤过下判断适应性和鞅，正确计算 Brownian 条件矩。
- 对 GBM 的函数应用伊藤引理，不遗漏二次变差项。
- 实现 Black-Scholes 价格和 Greeks，并用方差缩减蒙特卡洛复核。

## 任务边界

- 只处理无分红连续复利模型扩展到常数股息率 `q` 的欧式期权。
- 参数固定，不做隐含波动率校准、美式提前行权或随机波动率。
- 蒙特卡洛使用风险中性精确终值分布；Euler 离散留给 QF-L09。
- 不把 Black-Scholes 假设描述为真实市场事实。

## 固定输入

```text
S0 = 100.0
K = 105.0
r = 0.03
q = 0.01
sigma = 0.20
T = 0.75
seed = 808
n_paths = 200000
confidence = 0.95
```

风险中性终值固定为：

$$
S_T=S_0\exp\left((r-q-\tfrac12\sigma^2)T+\sigma\sqrt{T}Z\right),
\qquad Z\sim N(0,1).
$$

## 题目细化

### Q1 适应性、条件矩与鞅（20 分）

设 $\mathcal F_t=\sigma(W_s:0\le s\le t)$，对每个结论给出理由：

1. $W_t$、$W_T$（当 $t<T$）、$\max_{0\le s\le t}W_s$ 是否对 $\mathcal F_t$ 适应。
2. 计算 $E[W_t\mid\mathcal F_s]$ 与 $Var(W_t\mid\mathcal F_s)$，其中 $0\le s<t$。
3. 证明 $W_t^2-t$ 是鞅，并说明 $W_t^2$ 为什么不是。
4. 证明指数过程 $\exp(\sigma W_t-\frac12\sigma^2t)$ 的期望为 1；写出所需可积性条件。

### Q2 伊藤引理（25 分）

设真实测度下

$$
dS_t=\mu S_tdt+\sigma S_tdW_t.
$$

1. 对 $f(S)=\log S$ 推导 $df(S_t)$，明确 $-\frac12\sigma^2$ 的来源。
2. 对 $f(S)=S^2$ 推导 $df(S_t)$，并与普通链式法则的错误结果比较。
3. 对一般 $V(t,S_t)$ 写出二维伊藤公式，再在 Delta 对冲组合中消去 $dW_t$，并计入连续股息率 `q` 的持有收益，得到 $V_t+\frac12\sigma^2S^2V_{SS}+(r-q)SV_S-rV=0$。
4. 写明上述推导需要的光滑性、连续交易、无摩擦和可复制条件；条件缺失时不要继续声称唯一价格。

### Q3 Black-Scholes 解析契约（30 分）

1. 实现带常数股息率 `q` 的欧式看涨、看跌价格。
2. 实现 call delta、gamma 与 vega；用中心差分分别复核 delta 与 gamma。
3. 验证 put-call parity：
   $$
   C-P=S_0e^{-qT}-Ke^{-rT}.
   $$
4. 验证价格边界、call 对 $S_0$ 单调不减、gamma 非负、vega 非负。
5. 对非法输入 `S0<=0`、`K<=0`、`sigma<0`、`T<0` 给出明确异常。`T=0` 必须返回到期支付而不是除零。

### Q4 蒙特卡洛与方差缩减（25 分）

1. 用精确终值分布估计 call 价格、样本标准误和 95% 置信区间。
2. 使用对偶变量 `Z/-Z`，报告与普通估计的方差比。
3. 使用折现股票 $e^{-rT}S_T$ 作为控制变量，其风险中性期望为 $S_0e^{-qT}$；估计最优控制系数，并报告方差比。
4. 将两种方差缩减结果与解析价同表比较；不得只保留方差最小的方法。
5. 解释解析价未落入某次有限样本区间时应如何诊断，而不是修改种子。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| put-call parity 失败 | 股息折现项、利率符号或 `d1/d2` |
| gamma 为负 | 正态密度、分母或差分公式 |
| MC 价格系统性偏高 | 是否遗漏折现，或用了真实漂移 `mu` |
| 对偶变量无降方差 | 是否将 `Z` 与 `-Z` 成对平均 |
| 控制变量偏移均值 | 控制变量期望是否使用 $S_0e^{-qT}$ |

## 验收标准

- Q1-Q2 的推导条件完整，不用代码替代理论。
