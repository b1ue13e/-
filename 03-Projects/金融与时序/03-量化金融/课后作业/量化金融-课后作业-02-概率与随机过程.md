# 量化金融-课后作业-02-概率与随机过程

## 作业定位

本作业把条件分布、全方差、马尔可夫链和鞅放在同一条推理链上：先写概率空间中的结论，再用固定随机种子的模拟检查有限样本会如何偏离理论。

## 学习目标

- 正确使用全期望与全方差，不漏掉状态均值差异带来的方差。
- 判断一个过程是否具有 Markov 或 martingale 性质，并明确所用信息集。
- 区分理论等式、蒙特卡洛估计与“看起来接近”的经验现象。

## 任务边界

- 主任务使用题面给定的离散分布与合成过程，不需要行情数据。
- 模拟不能替代理论证明；理论值与模拟值必须分列报告。
- 只使用固定输入和种子 `17`；改变配置只能放在可选扩展。

## 固定输入

### 市场状态混合模型

令状态 $Z\in\{C,S\}$ 分别表示 calm 与 stress：

$$
P(Z=C)=0.8,\qquad P(Z=S)=0.2.
$$

给定状态后，日收益 $R$ 的条件矩为：

| 状态 | $E[R\mid Z]$ | $Var(R\mid Z)$ |
| :--- | ---: | ---: |
| calm | 0.001 | 0.0001 |
| stress | -0.004 | 0.0009 |

### 三状态 Markov 链

状态顺序固定为 `calm/normal/stress`，转移矩阵为：

$$
P=\begin{bmatrix}
0.85&0.10&0.05\\
0.15&0.70&0.15\\
0.10&0.25&0.65
\end{bmatrix}.
$$

### 简单随机游走

$$
S_0=0,\qquad S_t=S_{t-1}+\epsilon_t,\qquad
P(\epsilon_t=1)=P(\epsilon_t=-1)=0.5.
$$

模拟配置固定为 `steps=252`、`paths in {100, 1000, 10000}`、`seed=17`。

## 题目细化

### Q1 条件矩与尾部事件（25 分）

1. 用全期望公式求 $E[R]$。
2. 用全方差公式将 $Var(R)$ 拆成“状态内方差”和“状态均值差异”两部分。
3. 计算若错误地只加权条件方差，会低估多少方差；解释该遗漏在风险建模中的含义。
4. 设等待时间 $T\sim Exp(\lambda=2)$，证明 $P(T>s+t\mid T>s)=P(T>t)$，并计算 $P(T>1)$ 的表达式。该小题只交推导，不做模拟。

### Q2 Markov 链与稳态（25 分）

1. 验证 `P` 每行和为 1 且元素非负。
2. 从初始分布 `pi0=(1,0,0)` 递推 `pi_t=pi_0 P^t`，报告 `t=1,5,20,100`。
3. 解 $\pi=\pi P$、$\sum_i\pi_i=1$，并与 `pi_100` 比较。
4. 将 `stress -> calm` 的转移概率改为 `-0.02`，测试必须拒绝该矩阵，而不是归一化掩盖错误。

### Q3 鞅判断与反例（25 分）

对自然滤过 $\mathcal F_t=\sigma(\epsilon_1,\ldots,\epsilon_t)$：

1. 证明公平随机游走 $S_t$ 是鞅。
2. 判断 $S_t^2$ 是否为鞅；若不是，构造一个由 $S_t^2$ 修正得到的鞅。
3. 将步进概率改为 `P(epsilon=1)=0.55`，说明哪一条鞅条件失效。
4. 指出“样本均值接近 0”为什么不能单独证明鞅性质。

### Q4 蒙特卡洛与有限样本（25 分）

1. 对三种路径数模拟 $S_{252}$，报告样本均值、总体方差估计和理论值。
2. 对每个规模记录绝对误差，但不得要求误差随样本量单调下降。
3. 用同一种子重复运行，验证结果摘要完全一致；换种子后只要求统计口径一致。
4. 生成一个失败报告：故意用 `ddof=1` 与理论总体方差直接比较，解释口径差异而不是删掉结果。

## 失败诊断

| 现象 | 优先检查 |
| :--- | :--- |
| `pi_t` 和不为 1 | 行/列随机矩阵约定是否混用 |
| 稳态向量出现负数 | 线性方程或归一化约束是否写错 |
| 随机游走方差接近 1 | 是否对终值按步数错误标准化 |
| 同种子仍不复现 | 是否创建了多个未受控随机数生成器 |
| 样本均值偏离 0 | 先检查有限样本误差，不立即修改过程定义 |
