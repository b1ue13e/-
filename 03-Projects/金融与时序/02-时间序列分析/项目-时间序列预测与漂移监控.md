## 项目目标

使用一个公开的日频数据集，完成从清洗、基线预测、滚动验证到分布漂移监控的完整链路。重点是验证预测是否在样本外成立，而不是追求单次最优分数。

## 数据与约束

- 输入：日期、目标值和可用的外生变量；禁止使用未来窗口统计量。
- 切分：按时间顺序划分 train / validation / test，禁止随机打乱。
- 基线：naive-last、季节性 naive、ARIMA；可选 XGBoost/LSTM 只能作为对照。
- 指标：MAE、RMSE、MASE，并报告预测区间覆盖率（若提供区间）。

## 漂移监控最小实现

固定的 `PSI > 0.1` 或 `p < 0.05` 不是跨场景通用阈值。下面先从无漂移参考分布重采样，得到同样本量下统计量的经验 95% 阈值，再检测一个人为均值漂移窗口。

```python
import numpy as np
from scipy.stats import ks_2samp

def psi(reference, current, bins=10, eps=1e-6):
    edges = np.unique(np.quantile(reference, np.linspace(0, 1, bins + 1)))
    edges[0], edges[-1] = -np.inf, np.inf
    ref_p = np.histogram(reference, bins=edges)[0] / len(reference)
    cur_p = np.histogram(current, bins=edges)[0] / len(current)
    ref_p = np.clip(ref_p, eps, None)
    cur_p = np.clip(cur_p, eps, None)
    return float(np.sum((cur_p - ref_p) * np.log(cur_p / ref_p)))

rng = np.random.default_rng(20260805)
reference = rng.normal(0, 1, 1000)
current = rng.normal(0.6, 1, 300)

null_psi, null_ks = [], []
for _ in range(200):
    a = rng.choice(reference, size=300, replace=True)
    b = rng.choice(reference, size=300, replace=True)
    null_psi.append(psi(a, b))
    null_ks.append(ks_2samp(a, b).statistic)

psi_threshold = np.quantile(null_psi, 0.95)
ks_threshold = np.quantile(null_ks, 0.95)
psi_value = psi(reference, current)
ks = ks_2samp(reference, current)

print(f"PSI={psi_value:.3f}, calibrated_95={psi_threshold:.3f}, alert={psi_value > psi_threshold}")
print(f"KS={ks.statistic:.3f}, calibrated_95={ks_threshold:.3f}, p={ks.pvalue:.3g}, alert={ks.statistic > ks_threshold}")
# 固定输出：PSI=0.331 > 0.110；KS=0.243 > 0.107，两者都告警
```

### 阈值与动作契约

| 项目 | 必须冻结的内容 |
|---|---|
| 参考窗 | 哪段稳定时期、样本量、特征版本 |
| 当前窗 | 窗口长度、更新频率、是否重叠 |
| 阈值 | 无漂移重采样分位数，或由历史误报/漏报成本校准 |
| 多重监控 | 同时监控多特征时的误报控制与告警合并规则 |
| 告警动作 | 先查数据质量，再评估误差；满足升级条件才重训、降级或暂停 |

PSI/KS 只说明输入分布发生变化，不自动证明预测性能下降。最终告警必须与窗口级预测误差、区间覆盖率和业务损失联动。
