# HW09｜滚动预测与完整建模报告

> **目标**：把 HW01–HW08 的判断串成一份可复现报告。允许最终结论是“保留 naïve/seasonal naïve”，但不允许没有证据地宣布复杂模型胜出。

## A｜预测任务契约（10 分）

建模前冻结：

| 字段 | 你的定义 |
|---|---|
| 预测对象与单位 |  |
| 使用者和决策 |  |
| 预测频率 |  |
| 关键 horizon |  |
| 数据公布延迟 |  |
| 主要点指标 |  |
| 区间水平 |  |
| 必须比较的基线 |  |
| 失败成本 |  |

没有任务契约，不得根据结果事后挑选最有利指标。

## B｜时间切分与信息边界（15 分）

1. 画出训练、滚动验证和最终测试段；
2. 说明 expanding 还是 rolling window，以及原因；
3. 列出每个起点需要重新拟合的预处理和模型步骤；
4. 最终测试段在模型选择结束前保持封存；
5. 季节任务确保评估覆盖完整季节位置。

## C｜指标手算校验（10 分）

从滚动结果随机抽取至少 5 个预测：

1. 手算 MAE 和 RMSE；
2. 用训练集分母手算 MASE；
3. 与代码结果核对；
4. 若不一致，先修复计算口径再继续。

## D｜逐 horizon 模型赛马（20 分）

至少比较：

- naïve；
- 季节任务中的 seasonal naïve；
- HW08 通过残差诊断的 1–3 个候选。

报告每个 horizon 的 MAE、RMSE、MASE、有效预测次数，以及相对主要基线的百分比变化。不得只报告所有 horizon 的混合平均值。

## E｜区间与失败窗口（15 分）

1. 按 horizon 报告 80%/95% 区间覆盖率与平均宽度；
2. 找出误差最大的三个预测起点；
3. 回到原始时间线调查异常、制度变化或数据问题；
4. 说明这些失败是否可在预测发生前识别；
5. 不得删除失败窗口后重新报平均分。

## F｜最终一次测试（10 分）

模型与评估协议冻结后，才打开最终测试段：

1. 只运行一次主要比较；
2. 报告与滚动验证结论是否一致；
3. 若不一致，不回头调参，而是分析漂移、方差和选择不确定性；
4. 保存运行时间、数据版本和代码版本。

## G｜完整建模报告（20 分）

报告必须按教学逻辑组织：

1. **问题**：预测服务什么决策？
2. **数据**：来源、时间范围、频率、缺失和异常；
3. **平稳化**：变换、普通/季节差分及证据；
4. **候选**：ACF/PACF 只如何生成候选；
5. **估计**：AICc、收敛、标准误和根；
6. **诊断**：残差时间图、ACF、Ljung–Box、平方残差；
7. **评估**：滚动起点、逐 horizon 指标、基线和区间；
8. **结论**：最终采用什么、为何采用、何时失效；
9. **复现**：数据、环境、随机种子和运行命令。

结论限制在 300 字内，必须包含至少一条负面发现或适用边界。

## 验收标准

- [ ] 任务、horizon 和指标在评估前冻结
- [ ] 所有学习步骤尊重每个预测起点的信息边界
- [ ] 指标通过手算样例复核
- [ ] 逐 horizon 比较适当基线
- [ ] 同时报告区间覆盖率与宽度
- [ ] 不删除失败窗口，不反复查看最终测试集
- [ ] 允许朴素模型胜出或所有复杂模型失败
- [ ] 报告可以由别人按版本信息复现
