# HW07｜模型识别与参数估计阶梯作业

> **规则**：沿用 HW05 或 HW06 的训练数据。测试段继续封存，本作业不得根据测试误差反复修改候选。

## A｜AICc 手算（15 分）

给定有效样本量 $T=80$：

| 候选 | 对数似然 $\ell$ | 参数数 $k$ |
|---|---:|---:|
| A | -100 | 3 |
| B | -98 | 6 |
| C | -101 | 2 |

1. 计算三者的 AIC 和 AICc；
2. 按 AICc 排序；
3. 解释为什么“B 的似然最高”不足以选择 B；
4. 写出这次比较成立所依赖的两个口径条件。

## B｜盲看相关图提出候选（15 分）

只查看训练集差分后的 ACF/PACF，不先运行自动选模：

1. 写下 3–5 个候选；
2. 每个候选用一句话说明图形或机制依据；
3. 写出一个你主动排除的高阶候选及排除理由；
4. 保存候选清单后再开始拟合，不允许看到结果后改写原判断。

## C｜参数可信度审计（25 分）

为每个候选记录：

| 字段 | 必填内容 |
|---|---|
| 结构 | order、seasonal_order、trend |
| 拟合 | log-likelihood、AICc、有效样本量 |
| 数值状态 | 是否收敛、警告、迭代次数 |
| 参数 | 估计值、标准误、置信区间 |
| 约束 | 最小 AR 根模、最小 MA 根模 |
| 初步结论 | 保留/淘汰及一句证据 |

遇到未收敛时先记录失败，不要静默丢弃。只有在说明原因后，才允许调整初值、优化器或候选结构。

## D｜边界敏感性实验（15 分）

对当前 AICc 最优模型完成至少两项：

- 将训练起点前后移动一个合理窗口；
- 删除一个有明确理由的异常点后重估，同时保留原结果；
- 更换合理初值或优化器；
- 比较是否强制平稳/可逆约束。

报告参数、最小根模和模型排名是否稳定。若结果敏感，不得只挑最好看的一次。

## E｜人工与自动搜索对照（15 分）

运行一种自动选模方法，并记录：

1. 搜索范围与 stepwise/exhaustive 设置；
2. 差分阶数与趋势项处理；
3. 自动结果是否出现在人工候选中；
4. 若没有，新增结构带来了什么收益和风险；
5. 把自动结果加入同一台账，而不是单独宣布胜者。

## F｜候选评审会（15 分）

写一份不超过 300 字的评审结论：

- 哪些候选进入下一课残差诊断？
- 哪些候选被淘汰，决定性证据是什么？
- 当前结论对训练窗口或估计设置是否敏感？
- 还没有使用测试集时，你明确不能得出什么结论？

## 验收标准

- [ ] 能手算并解释 AICc，而不是只抄软件输出
- [ ] 候选在拟合前已经冻结
- [ ] 同时报告估计值与不确定性
- [ ] 检查收敛、警告和特征根
- [ ] 未跨不同差分口径机械比较 AICc
- [ ] 自动选模与人工候选接受相同审计
- [ ] 淘汰理由具体且可复核
