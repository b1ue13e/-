# 🧭 常微分方程 课程作业总索引

> 本文档为常微分方程课程的作业事实源总索引。作业按规模层级分为 **课后作业 (lesson)**、**阶段作业 (stage)**、**大作业 (capstone)**，任务形态用 `assignment_format` 表达。作业清单由 Dataview 从作业 Frontmatter 自动派生，不手工维护第二份列表。

---

## 📊 作业总览

```dataviewjs
// 作业规模与状态统计（只读统计，不产生知识正文）
const files = dv.pages('"03-Projects/06-常微分方程"')
  .where(p => p.type === "project" && p.assignment_level != null);

const levels = { lesson: "课后作业", stage: "阶段作业", capstone: "大作业" };
let total = 0;
let line = "";

for (const [key, name] of Object.entries(levels)) {
  const arr = files.where(p => p.assignment_level === key);
  const done = arr.where(p => p.status === "completed").length;
  const planned = arr.where(p => p.status === "planned").length;
  const active = arr.where(p => p.status === "active").length;
  total += arr.length;
  line += `- **${name}**：${arr.length} 份（完成 ${done} / 规划 ${planned} / 进行中 ${active}）\n`;
}

dv.paragraph(`**共 ${total} 份作业**\n${line}`);
```

## 🗺️ 按阶段浏览作业

作业—阶段归属由各作业 Frontmatter 的 `stage_id` 唯一维护；下表按阶段自动汇总，点击作业名进入题面。

```dataview
TABLE assignment_level AS "规模层级", assignment_format AS "任务形态", status AS "状态", progress AS "进度"
FROM "03-Projects/06-常微分方程"
WHERE type = "project" AND assignment_level != null AND stage_id != null
SORT stage_id ASC, assignment_level ASC, file.name ASC
```
