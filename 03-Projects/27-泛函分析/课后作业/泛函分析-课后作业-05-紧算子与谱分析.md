# 泛函分析-课后作业-05-紧算子与谱分析

> 对应知识点：[[泛函分析-紧算子与有限维逼近]]、[[泛函分析-自伴算子与正算子]]、[[泛函分析-谱理论与紧自伴算子谱定理]]、[[泛函分析-Fredholm二歧定理]]

## 🎯 学习目标与任务背景

### 1. 学习目标
1. 熟练计算典型算子（积分算子、微分逆算子、序列移位算子、乘法算子）的点谱 $\sigma_p$、连续谱 $\sigma_c$ 与剩余谱 $\sigma_r$。
2. 掌握紧自伴算子的特征值与正交特征函数系的显式求解方法。
3. 掌握 Weyl 近似特征序列判据，严格证明乘法位置算子的纯连续谱性质。
4. 熟练应用 Fredholm 二歧定理求解第二类 Fredholm 积分方程并判定解的唯一性与存在条件。

### 2. 任务背景与边界
本作业涵盖紧算子判据、自伴算子谱分解、Weyl 判据以及第二类 Fredholm 积分方程求解。题目假定在标准 Hilbert 空间 $L^2$ 与 $l^2$ 上进行，要求将特征方程与正交相容性条件推导完整。

## 📝 作业题目清单 (满分 100 分)

### 题 1：Hilbert-Schmidt 积分算子的谱全景分析 (25 分)
在实 Hilbert 空间 $H = L^2[0, 1]$ 上考虑积分算子：
$$(K f)(t) = \int_0^1 \min(t, s) f(s) ds, \quad t \in [0, 1]$$
1. 证明 $K$ 是**紧算子**且是**自伴正算子**（$K = K^* \ge 0$）。(8 分)
2. 求出算子 $K$ 的**所有特征值 $\lambda_n$ 与对应的标准正交特征函数系 $e_n(t)$**（提示：令 $g = Kf$，利用常微分方程边值问题 $g^{\prime\prime}(t) = -f(t), \ g(0)=0, g^\prime(1)=0$ 求解）。(12 分)
3. 计算算子范数 $\|K\|_{\mathcal{B}(L^2)}$ 与谱半径 $r(K)$。(5 分)

---

### 题 2：序列空间移位算子双向谱分类 (25 分)
在复 Hilbert 空间 $l^2$ 上考虑单向右移算子 $R(x_1, x_2, \dots) = (0, x_1, x_2, \dots)$ 与左移算子 $L(x_1, x_2, \dots) = (x_2, x_3, \dots)$。
1. 证明 $R^* = L$。(5 分)
2. 求出 $L$ 的点谱 $\sigma_p(L) = \{|\lambda| < 1\}$，并证明其剩余谱为空 $\sigma_r(L) = \emptyset$。(10 分)
3. 证明 $R$ 没有特征值（$\sigma_p(R) = \emptyset$），且开单位圆盘 $\{|\lambda| < 1\}$ 全部属于剩余谱 $\sigma_r(R)$。(10 分)

---

### 题 3：乘法算子的连续谱与 Weyl 奇异序列 (25 分)
在 Hilbert 空间 $H = L^2[0, 1]$ 上考虑乘法算子 $(M_x f)(t) = t f(t)$。
1. 证明 $M_x$ 是有界自伴算子，且点谱为空 $\sigma_p(M_x) = \emptyset$。(10 分)
2. 对任意固定的 $\lambda \in (0, 1)$，构造归一化方波序列 $v_n(t) = \sqrt{n} \cdot \mathbf{1}_{[\lambda - \frac{1}{2n}, \lambda + \frac{1}{2n}]}(t)$，严格计算 $\|v_n\|_{L^2}$ 与 $\|(M_x - \lambda I)v_n\|_{L^2}$。(10 分)
3. 说明为何上述计算利用 Weyl 判据证明了 $\lambda \in \sigma_c(M_x)$，并给出全谱 $\sigma(M_x) = [0, 1]$。(5 分)

---

### 题 4：退化核 Fredholm 积分方程求解与二歧性验证 (20 分)
求解第二类 Fredholm 积分方程：
$$u(t) - \lambda \int_0^\pi \cos(t + s) u(s) ds = \sin(t), \quad t \in [0, \pi]$$
1. 利用三角和差公式展开核函数，将积分方程转化为二维代数方程组。(8 分)
2. 计算特征值 $\lambda$，指出当 $\lambda$ 为何值时方程对右端项 $\sin(t)$ 存在唯一解，并求出该解的显式表达式。(8 分)
3. 当 $\lambda$ 等于特征值时，验证 Fredholm 正交相容性条件，并说明此时方程解的情况。(4 分)

---

### 题 5：【计算实验】Python 泛函数值显微镜——Nyström 离散谱与 Weyl 奇异序列实测 (20 分)
在项目根目录运行 Python 仿真套件：`python 03-Projects/27-泛函分析/scripts/spectral_integral_operator.py`。
1. **Nyström 积分算子特征值衰减验证**：
   - 提取前 5 个数值特征值 $\lambda_k^{(h)}$，与理论特征值 $\lambda_k = \frac{1}{(k-0.5)^2 \pi^2}$ 进行绝对误差对比；
   - 说明为何特征值以 $O(1/k^2)$ 迅速衰减到 0，解释这与算子紧性（Hilbert-Schmidt）的理论内在对应。(10 分)
2. **乘法算子连续谱 Weyl 奇异序列残差验证**：
   - 取目标谱点 $\lambda = 0.5$，记录波包尺度 $n \in [5, 10, 20, 50, 100]$ 下残差 $\|(M_x - 0.5 I)v_n\|_{L^2}$；

## 🔍 引导自检与检查点

- 💡 **自检 1**：在题 1(2) 中，$g(t) = \int_0^t s f(s)ds + t \int_t^1 f(s)ds$。求导得 $g^\prime(t) = \int_t^1 f(s)ds$，再求导得 $g^{\prime\prime}(t) = -f(t)$。边界条件为 $g(0) = 0, g^\prime(1) = 0$。特征方程为 $-\lambda g^{\prime\prime} = g$，解得正交基 $e_n(t) = \sqrt{2}\sin((n-1/2)\pi t)$，特征值 $\lambda_n = \frac{1}{(n-1/2)^2 \pi^2}$！
- 💡 **自检 2**：在题 3(2) 与题 5 中，$\|(M_x - \lambda I)v_n\|_{L^2} = \frac{1}{\sqrt{12} n} \to 0$，残差与 $n$ 成反比严格衰减。
- 💡 **自检 3**：运行 `pytest` 应全部通过，无任何断言失败。
