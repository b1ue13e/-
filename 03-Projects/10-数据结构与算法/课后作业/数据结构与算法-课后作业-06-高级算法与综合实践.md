# 数据结构与算法 - 课后作业 06：高级算法与综合实践

> **所属课程**：数据结构与算法  
> **所属阶段**：Stage 06 高级与综合训练  
> **学术来源**：MIT 6.006 Problem Set 6 改编与本地化  

---

## 🎯 学习目标

1. 深入掌握字符串高效匹配算法，手写 KMP 前缀函数 (`next` 数组) 与 Rabin-Karp 滚动哈希算法。
2. 理解图论高级连通性算法，熟练运用 Tarjan 算法求解强连通分量 (SCC)、割点与桥 (割边)。
3. 掌握网络流模型，手写 Edmonds-Karp 或 Dinic 最大流算法，理解“最大流最小割定理 (Max-Flow Min-Cut Theorem)”。

---

## 🚧 任务边界与假设

- **编程语言**：标准 C++17 或 Python 3.10+。
- **数据规模**：文本串长 $N \le 10^6$，图节点数 $V \le 10^4$，网络流增广路效率优化达标。
- **禁止事项**：禁止直接使用暴力 $O(N \times M)$ 字符串匹配替代 KMP / Rabin-Karp。

---

## ⚙️ 核心题目集

### 1. 理论推导题 (Theoretical Problems)

📌 **直通知识点**：[[数据结构与算法-KMP算法]] | [[数据结构与算法-Rabin-Karp算法]] | [[数据结构与算法-AC自动机]]
1. **KMP 时间复杂度证明**：通过双指针势能分析 (Amortized Analysis)，证明 KMP 构建 `next` 数组与主串匹配的总时间复杂度为 $O(N + M)$。
2. **最大流最小割定理证明**：证明残余网络中不存在从源点 $S$ 到汇点 $T$ 的增广路时，最大流的值等于某个割的容量。

### 2. 代码实现题 (Programming Problems)

📌 **直通知识点**：[[数据结构与算法-Dinic算法与网络流实现]] | [[数据结构与算法-二分图匹配与匈牙利算法]]
1. **KMP 模式匹配与周期推导**：实现 KMP 算法，并根据 `next` 数组推导字符串的最短循环节。
2. **Dinic 网络最大流算法**：基于 BFS 构建分层图与 DFS 多路增广实现 Dinic 算法，求解最大流与二分图最大匹配。

## 🃏 Anki 卡片

- Q: Dinic 算法中“当前弧优化”的作用是什么？
- A: 在同一个分层图的 DFS 多路增广过程中，跳过已经遍历完且无法再增广的边，从而降低重复搜索开销。
