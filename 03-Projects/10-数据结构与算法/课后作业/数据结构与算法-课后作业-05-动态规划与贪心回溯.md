# 数据结构与算法 - 课后作业 05：动态规划与贪心回溯

> **所属课程**：数据结构与算法  
> **所属阶段**：Stage 05 算法思想进阶  
> **学术来源**：MIT 6.006 Problem Set 5 改编与本地化  

---

## 🎯 学习目标

1. 理解动态规划的“最优子结构”与“重叠子问题”性质，熟练定义 DP 状态与推导状态转移方程。
2. 掌握背包问题（0-1 背包、完全背包）的空间复杂度压缩优化（二维表格压缩为一维滚动数组）。
3. 深刻理解贪心选择性质与回溯算法的剪枝策略（可行性剪枝与最优性剪枝）。

---

## 🚧 任务边界与假设

- **编程语言**：标准 C++17 或 Python 3.10+。
- **空间优化考核**：背包问题与 LCS/编辑距离题目的空间优化版本需达成 $O(W)$ 或 $O(N)$ 空间复杂度。
- **禁止事项**：递归记忆化搜索未加记忆化数组（导致指数级暴搜退化）视为不合格。

---

## ⚙️ 核心题目集

### 1. 理论推导题 (Theoretical Problems)

📌 **直通知识点**：[[数据结构与算法-DP状态定义]] | [[数据结构与算法-DP初始化]] | [[数据结构与算法-动态规划入门]]
1. **贪心选择性质证明**：对区间调度问题 (Interval Scheduling Problem)，严谨证明“按结束时间最早排序”的贪心策略能获得最大不相交区间数量。
2. **DP 空间压缩证明**：证明在 0-1 背包一维空间优化中，容量循环必须采用“逆序遍历”以防止同一物品被重复选择。

### 2. 代码实现题 (Programming Problems)

📌 **直通知识点**：[[数据结构与算法-N皇后问题]] | [[数据结构与算法-背包DP]] | [[数据结构与算法-最长公共子序列LCS]]
1. **最长公共子序列 (LCS) 与具体解构造**：求解两字符串的 LCS 长度，并利用 traceback 还原具体子序列字符串。
2. **N 皇后问题与剪枝**：基于回溯法实现 N 皇后问题的全解搜索，使用位运算加速列与正反斜线的占位检查。

## 🃏 Anki 卡片

- Q: 动态规划与贪心算法的核心区别是什么？
- A: 动态规划基于最优子结构做出依赖于所有子问题结果的全局决策；而贪心算法在每一步做出局部最优选择，不依赖后续子问题的解。
