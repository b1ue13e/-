# 数据结构与算法 - 课后作业 03：树、堆与优先队列

> **所属课程**：数据结构与算法  
> **所属阶段**：Stage 03 树与堆  
> **学术来源**：MIT 6.006 Problem Set 3 改编与本地化  

---

## 🎯 学习目标

1. 深入掌握二叉搜索树 (BST) 的性质，手写 AVL 树的左旋、右旋与四种失衡恢复机制 (LL, RR, LR, RL)。
2. 理解二叉堆 (Max/Min Heap) 的自下而上建堆算法 $O(N)$ 推导与 `sift_up` / `sift_down` 调整维护过程。
3. 掌握带有路径压缩和按秩合并的并查集 (Disjoint Set Union) 及单点修改区间查询的树状数组 (BIT)。

---

## 🚧 任务边界与假设

- **编程语言**：标准 C++17 或 Python 3.10+。
- **性能考核**：建堆算法必须达成 $O(N)$ 时间复杂度，单点建堆 $O(N \log N)$ 视为不达标。
- **禁止事项**：禁止直接使用标准库 `std::priority_queue` 伪造堆逻辑。

---

## ⚙️ 核心题目集

### 1. 理论推导题 (Theoretical Problems)

📌 **直通知识点**：[[数据结构与算法-二叉搜索树基础]] | [[数据结构与算法-AVL树]] | [[数据结构与算法-BST删除]]
1. **建堆复杂度证明**：使用级数求和证明对包含 $N$ 个元素的任意数组执行自下而上建堆 (Build-Heap) 的总时间复杂度为 $O(N)$。
2. **AVL 树旋转不变性**：证明对 AVL 树执行单旋（左旋/右旋）后，树的中序遍历序列保持严格递增不变。

### 2. 代码实现题 (Programming Problems)

📌 **直通知识点**：[[数据结构与算法-TopK问题]] | [[数据结构与算法-Trie基础]] | [[数据结构与算法-Trie单词搜索]]
1. **手写 AVL 树**：实现带有平衡因子计算与自动旋转调节的 AVL 树插入与删除接口。
2. **并查集与连通块**：实现支持路径压缩与按秩合并的并查集，解决连通分量计数与动态连通性判定问题。

## 📏 验收标准

- **平衡树功能正确性** (40%)：AVL 树在大量随机插入与删除后，任意节点的平衡因子绝对值 $\le 1$。
- **并查集均摊复杂度** (40%)：并查集操作达成 $O(\alpha(N))$ 均摊时间复杂度。
- **测试覆盖率** (20%)：包含随机数据对拍 (Stress Testing) 和边界测试。

## 💡 引导与自检

- [ ] AVL 树删除节点后，是否沿父节点一路向上更新高度并检查旋转调节？
- [ ] 并查集的 `find` 函数是否实现了递归或迭代式的路径压缩？
- [ ] 二叉堆数组表示中，索引从 0 开始时，节点 $i$ 的左右子节点索引公式是否正确？

---

## 🃏 Anki 卡片

- Q: 为什么自下而上建堆的时间复杂度是 $O(N)$ 而不是 $O(N \log N)$？
- A: 因为树中绝大多数节点集中在底部，底层的节点下沉高度极小，级数和 $\sum_{h=0}^{\log N} \frac{N}{2^{h+1}} O(h) = O(N)$。
