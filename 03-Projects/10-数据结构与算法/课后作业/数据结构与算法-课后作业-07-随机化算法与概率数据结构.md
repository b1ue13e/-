# 数据结构与算法 - 课后作业 07：随机化算法与概率数据结构

> **所属课程**：数据结构与算法  
> **所属阶段**：Stage 06 高级与综合训练  
> **学术来源**：MIT 6.046J Problem Set 3 / Stanford CS161 改编与本地化  

---

## 🎯 学习目标

1. 深入理解概率数据结构（SkipList、Bloom Filter）的设计思想与期望复杂度分析。
2. 掌握 Rabin-Karp 滚动哈希 (Rolling Hash) 在多模式与长文本匹配中的数学原理与碰撞防护。
3. 熟练实现基于随机化概率翻硬币 (Coin Tossing) 的跳表层级分配机制与高并发淘汰算法。

---

## 🚧 任务边界与假设

- **编程语言**：标准 C++17 或 Python 3.10+。
- **环境假设**：仅使用标准库随机数生成器（如 C++ `<random>` 或 Python `random`）。
- **禁止事项**：禁止直接使用三方跳表库或哈希碰撞过滤库，核心随机化索引分配与 Hash 函数映射需自主编写。

## ⚙️ 核心题目集

### 1. 理论推导题 (Theoretical Problems)

📌 **直通知识点**：[[数据结构与算法-快速傅里叶变换FFT]] | [[数据结构与算法-区间合并]]
1. **跳表期望高度与查找复杂度证明**：在晋升概率 $p = 0.5$ 的跳表中，证明元素总数为 $n$ 时跳表的期望最大高度为 $O(\log n)$，且任意元素的搜索路径期望长度为 $O(\log n)$。
2. **布隆过滤器 False Positive 假阳性率推导**：设布隆过滤器位数组长度为 $m$，插入元素个数为 $n$，哈希函数个数为 $k$。推导假阳性率 $P_{fp} \approx (1 - e^{-kn/m})^k$，并证明当 $k = \frac{m}{n} \ln 2$ 时假阳性率达到最小。

### 2. 代码实现题 (Programming Problems)

📌 **直通知识点**：[[数据结构与算法-差分约束]] | [[数据结构与算法-跳表]]
1. **跳表 (SkipList) 核心接口实现**：实现具备 $O(\log n)$ 期望时间复杂度的 `search`, `add`, `erase` 接口，支持可配概率晋升策略。
2. **Rabin-Karp 多模式滚动哈希匹配器**：实现 Rabin-Karp 算法，使用双哈希 (Double Hashing) 机制有效防护哈希碰撞攻击，求解长文本中的模式串定位。

## 🃏 Anki 卡片

- Q: 为什么跳表 (SkipList) 在实际工程（如 Redis Sorted Set）中常被用来替代平衡二叉树（AVL/红黑树）？
- A: 跳表实现更简单直观；范围查询性能优异且节点调整无需复杂的旋转操作；通过概率并发锁机制更易做到高并发读写。
