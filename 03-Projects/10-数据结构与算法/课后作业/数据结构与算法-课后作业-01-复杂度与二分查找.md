# 数据结构与算法 - 课后作业 01：复杂度与二分查找

> **所属课程**：数据结构与算法  
> **所属阶段**：Stage 01 算法入门与基本分析  
> **学术来源**：MIT 6.006 Problem Set 1 改编与本地化  

---

## 🎯 学习目标

1. 熟练运用 $\mathcal{O}, \Omega, \Theta$ 渐近记号进行算法时间与空间复杂度的严谨数学推导。
2. 掌握主定理 (Master Theorem) 和递归树方法在递推关系式分析中的应用。
3. 熟练编写无 Bug 的整数二分与浮点二分模板，理解闭区间与左闭右开区间的边界处理原则。

---

## 🚧 任务边界与假设

- **编程语言**：标准 C++17 或 Python 3.10+。
- **环境假设**：无第三方扩展依赖，仅使用标准库。
- **禁止事项**：禁止直接调用标准库二分查找函数（如 `std::lower_bound` 或 Python `bisect`），须手写二分查找逻辑。

---

## ⚙️ 核心题目集

### 1. 理论推导题 (Theoretical Problems)

1. **渐近记号证明**：证明 $3n^2 + 7n + 10 = \Theta(n^2)$，求出对应的常数 $c_1, c_2, n_0$。
2. **递推关系求解**：使用主定理分析递推关系 $T(n) = 4T(n/2) + \mathcal{O}(n \sqrt{n})$ 的渐近时间复杂度。

### 2. 代码实现题 (Programming Problems)

1. **旋转排序数组中的最小值**：在无重复元素的旋转排序数组中，用 $\mathcal{O}(\log n)$ 时间复杂度寻找最小值。
2. **浮点数三次方根**：实现浮点数二分查找，求实数 $x$ 的三次方根，精度要求达到 $10^{-6}$。

- `ps01_binary_search.cpp` 或 `ps01_binary_search.py`：二分查找核心算法实现及单元测试用例。

## 📏 验收标准

- **渐近分析正确性** (40%)：推导步骤严谨，边界与常数限定无误。
- **二分查找正确性** (40%)：通过所有边界测试（空数组、单元素、重复元素、边界越界防护）。
- **代码规范性** (20%)：无语法错误，有清晰注释和单元测试覆盖。
