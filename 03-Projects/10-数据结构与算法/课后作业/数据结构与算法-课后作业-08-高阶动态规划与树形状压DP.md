# 数据结构与算法 - 课后作业 08：高阶动态规划与树形/状压 DP

> **所属课程**：数据结构与算法  
> **所属阶段**：Stage 06 高级与综合训练  
> **学术来源**：MIT 6.006 / OpenDSA / Competitive Programming 题库改编  

---

## 🎯 学习目标

1. 深入掌握树形动态规划 (Tree DP) 的状态转移定义、换根 DP (Rerooting DP) 的二次 DFS 思想。
2. 熟练运用位运算表达复杂二值集合状态，掌握状态压缩 DP (Bitmask DP) 的复杂度边界与空间压缩。
3. 理解数位 DP (Digit DP) 的记忆化搜索框架与区间约束条件处理技巧。

---

## 🚧 任务边界与假设

- **编程语言**：标准 C++17 或 Python 3.10+。
- **状态上限**：状态压缩求解中的集合大小 $N \le 20$（状态数控制在 $2^{20} \approx 10^6$ 以内），防止内存或超时溢出。
- **禁止事项**：禁止直接使用全局大数组忽略维度压缩，必须进行严谨的状态转移方程空间优化。

## ⚙️ 核心题目集

### 1. 理论推导题 (Theoretical Problems)

📌 **直通知识点**：[[数据结构与算法-树形DP]] | [[数据结构与算法-数位DP]]
1. **换根 DP 正确性与复杂度分析**：证明在无向树上通过两次 DFS 求解所有节点到其他所有节点距离之和的换根 DP 方法，能在 $O(N)$ 时间复杂度内求解，推导向下子树贡献与向上父亲贡献的拆分方程。
2. **状态压缩 DP 的状态空间与位运算转移**：在 TSP (旅行商问题) 中，分析 $dp[mask][u]$ 状态表示的含义，证明总时间复杂度为 $O(n^2 \cdot 2^n)$，并说明位操作 `mask & (1 << v)` 与 `mask ^ (1 << v)` 的推导合理性。

### 2. 代码实现题 (Programming Problems)

📌 **直通知识点**：[[数据结构与算法-状压DP]] | [[数据结构与算法-概率DP]]
1. **树的最佳选择 (树上最大独立集)**：实现树形 DP 算法，求解在树形结构中节点选与不选互斥约束下的最大权值独立集。
2. **旅行商问题 (TSP) 状态压缩 DP**：实现 TSP 算法，计算从起点出发遍历所有 $N$ 个城市且每个城市仅访问一次的最短回路路径。

## 🃏 Anki 卡片

- Q: 换根 DP (Rerooting DP) 的核心解题范式是什么？
- A: 第一遍 DFS 自底向上统计子树内部的贡献（如子树大小、子树距离和）；第二遍 DFS 自顶向下将父节点及兄弟节点的贡献累加回当前节点，从而在 $O(N)$ 内求出每个节点作为根时的全局解。
