# F:-\ Obsidian 知识库 MEMORY

## PKM 铁律（永久生效，跨所有学习路径）

### 🚨 核心禁忌
1. **不批量生成卡片正文**——AI 只生成空壳模板和审稿意见
2. **不替代手算**——手算 = 痛苦编码 = 神经元内化
3. **不复制黄金样例到自己路径**——样例是参考高级
4. **概念卡 ≤ 2-3KB**——超过就要拆段、拆文件
5. **L1-L4 永远外挂**——题目在阶梯作业文件，概念卡只链接

### AI 角色边界

| ✅ AI 做的 | ❌ AI 不做的 |
|:---|:---|
| 建框架（模板、SOP、索引、作业入口）| 批量生成卡片正文 |
| 当考官（审稿、找漏洞、反例、Bug）| 批量重写空壳卡 |
| 当资料员（挂章节定位、找开源作业）| 替用户写手算例子 |
| 写 pytest Harness 模板 | 替用户跑实验 |
| | 替用户提交作业 |

### 单向工作流

```
用户读教材/视频
   ↓
用户写空壳卡（痛苦编码）
   ↓
用户写完整卡片（200-400 字关键判断 + 反例）
   ↓
AI 审稿（用 01-教师式课程卡填法 的自检清单）
   ↓
用户修改（补漏洞、补反例、改代码）
   ↓
通过后才标 status: completed
```

## 反思与教训（PKM 关键）

- **能力 ≠ 任务**：AI 有能力批量写卡，但 PKM 场景下不能做
- **"看似更高效" ≠ "真正有效"**：丰满卡片产生"已经学会"的幻觉
- **费曼技巧的本质**：你必须是那个写板书的教师
- **黄金样例 vs 填空答案**：样例是高级参考，不是复制对象
- **字数是物理约束**：3KB 以上的卡片复习时认知负担过重
