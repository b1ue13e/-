# 归纳偏好

> 📘 填写法参考：[[01-教师式课程卡填法]]
> 🪜 对应作业：[[🪜 阶梯作业-基础概念#L2 - 归纳偏好实证|L2 - 归纳偏好实证]]

## 0. 这节课解决什么问题

如果版本空间里**有多个假设**都能完美拟合训练样本（如 [[假设空间]] 中直线 vs 二次曲线），我们**凭什么选**其中一个？凭"奥卡姆剃刀"——选**最简单的**。这就是**归纳偏好**（inductive bias）。没有它，机器学习就**没有泛化能力**；有了它，就要为"为什么选这个而不是那个"负责。

## 1. 学习目标

学完后，不看笔记能够：

- **能说**：用一段话讲清"为什么学习必须引入归纳偏好"和"NFL 定理的真正含义"
- **能算**：在 3 候选假设上用奥卡姆剃刀打分
- **能做**：用 sklearn 显式加 L1/L2 正则化，验证稀疏偏好 vs 权重衰减偏好
- **能判断边界**：知道"奥卡姆剃刀 ≠ 真理"——只在特定先验下成立

## 2. 课前诊断

> [!question] 诊断题
> 两个假设：(A) y = 2x (参数 2 个)，(B) y = x² + x + 1 (参数 3 个)。两者在训练集上 SSE 都是 0。**只看奥卡姆剃刀，你选哪个？真实数据是 y = x² 时，会后悔吗？**

> [!answer]- 诊断答案
> 选 (A)，因为参数更少（更"简单"）。**会后悔**——因为真实关系是二次的。这是奥卡姆剃刀的局限：**"简单"不等于"对"**。归纳偏好是**对问题先验**的声明，**没有"普适最好"**的偏好。

## 3. 直觉模型

```mermaid
graph LR
A[版本空间 V: 多个候选] -->|应用偏好: 简单/平滑/稀疏| B[唯一假设 g]
A -->|不同偏好| C[不同假设 g']
B --> D[泛化效果]
C --> D
D -->|NFL 定理| E[总误差守恒: 没有免费午餐]
```

**关键点**：
- 归纳偏好 = **学习算法的"先验"**——算法对"什么样的假设更好"的内置判断
- **奥卡姆剃刀**：在其他条件相同时选最简单的假设
- **NFL 定理**（没有免费午餐）：**所有算法的平均性能相同**——脱离问题谈"哪个算法最好"无意义

## 4. 从具体数字到一般公式

### 4.1 手算例子

3 个候选假设在 4 样本上都完美拟合：

| 假设 | 形式 | 参数数 | 复杂度分（奥卡姆）|
|:---|:---|:---:|:---:|
| $h_1$ | y = 2x | 1 | 1 |
| $h_2$ | y = 2x + 1 | 2 | 2 |
| $h_3$ | y = 0.5x² + 1.5x | 3 | 3 |

**应用奥卡姆剃刀**：选 $h_1$。

**改条件追问**：如果真实函数是 y = 0.5x² + 1.5x，$h_1$ 误差大，**奥卡姆选错了**。这说明：归纳偏好是**有风险的赌注**——赌"真实函数是简单的"。

### 4.2 一般形式：归纳偏好的形式化

设假设空间 $\mathcal{H}$，**偏好**定义为一个排序函数：

$$
P: \mathcal{H} \to \mathbb{R}, \quad h_1 \succ h_2 \iff P(h_1) < P(h_2)
$$

不同算法对应不同 $P$：

| 算法 | 偏好 $P$ |
|:---|:---|
| 线性回归（无正则） | 残差平方和最小 |
| Lasso | 残差平方和 + $\lambda \|w\|_1$（偏好**稀疏**） |
| Ridge | 残差平方和 + $\lambda \|w\|_2^2$（偏好**权重小**） |
| 决策树 | 树深度小、叶子数少（偏好**简单结构**） |
| 朴素贝叶斯 | 条件独立假设（偏好**特征解耦**） |
| SVM | 最大间隔（偏好**低密度边界**） |

**NFL 定理的数学表述**：

设 $f: X \to Y$ 是真实函数，$a$ 是学习算法，$E_{out}(a, f)$ 是算法 $a$ 在 $f$ 上的期望泛化误差。NFL 定理说：

$$
\sum_{f} E_{out}(a_1, f) = \sum_{f} E_{out}(a_2, f)
$$

**含义**：对所有问题**均匀平均**，每个算法表现一样。"算法 A 比 B 好"只能在**特定问题分布**下成立。

## 5. 教师示范例题

**题目**：在 sin(2πx) + 噪声 的数据上，训练误差相同的 4 个模型：
- A: 1 阶多项式
- B: 5 阶多项式
- C: 9 阶多项式
- D: 1 阶多项式 + L2 正则化

**判断**：按奥卡姆剃刀 + NFL 定理，应该选哪个？

**思路**：
- 奥卡姆剃刀偏好**结构简单**（A 优于 B 优于 C）
- L2 正则化等价于"偏好**权重小**"，让 A 更稳
- 真实函数是 sin 周期函数 → 实际上 B 可能更好

**逐步解答**：
- 选 A+D：赌"真实函数是简单光滑的"
- 选 B：赌"真实函数有 5 阶多项式的复杂度"
- **如果不知道真实函数**（我们通常不知道），**优先选 A+D**——更稳、更可解释

**结果检查**：5-fold 交叉验证，**A+D 通常优于 B 优于 C**（A 略欠拟合但稳定；C 严重过拟合）。

**改一个条件追问**：如果数据是 **Kaggle 房价**（特征多、关系复杂），B 可能优于 A。这就是**问题分布决定偏好**——NFL 定理的实用版。

## 6. 最小代码实验

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import Ridge, LinearRegression, Lasso
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score

np.random.seed(42)
X = np.linspace(0, 1, 30).reshape(-1, 1)
y = np.sin(2 * np.pi * X).ravel() + 0.1 * np.random.randn(30)

# 4 个不同偏好的模型
models = {
    "A: 1阶（奥卡姆极简）": make_pipeline(PolynomialFeatures(1), LinearRegression()),
    "B: 5阶（高容量）": make_pipeline(PolynomialFeatures(5), LinearRegression()),
    "C: 9阶（极高容量）": make_pipeline(PolynomialFeatures(9), LinearRegression()),
    "D: 1阶 + L2正则（Ridge）": make_pipeline(PolynomialFeatures(1), Ridge(alpha=0.1)),
}

for name, model in models.items():
    scores = cross_val_score(model, X, y, cv=5, scoring='neg_mean_squared_error')
    model.fit(X, y)
    train_mse = np.mean((model.predict(X) - y) ** 2)
    print(f"{name:30s} | train MSE={train_mse:.4f} | CV MSE={-scores.mean():.4f}")

# 预期输出:
# A: 1阶（奥卡姆极简） | train MSE=0.13 | CV MSE=0.16  ← 偏差大但稳定
# B: 5阶（高容量）      | train MSE=0.01 | CV MSE=0.05  ← 居中
# C: 9阶（极高容量）    | train MSE=0.00 | CV MSE=0.20  ← 训练完美但测试差
# D: 1阶 + L2正则       | train MSE=0.13 | CV MSE=0.16  ← 类似 A
```

**解释输出**：B 在 CV 上最好——这违反了"奥卡姆最简单"直觉！原因是真实函数 sin 不是简单直线。**NFL 定理的工程启示**：**没有普适最好，只有"对这个分布最好"**。

## 7. 常见错误与反例

### ❌ 反例 1：把"奥卡姆剃刀"当作真理

> "选最简单的模型一定好"

**问题**：如果真实关系很复杂，简单模型必然欠拟合。奥卡姆剃刀是**启发式**（在先验下成立），不是定理。

### ❌ 反例 2：把 NFL 定理读成"算法都一样"

> "既然 NFL，那随便选个算法"

**问题**：NFL 定理说"在**所有问题**上平均一样"，但**现实中只关心一个特定问题**。在特定分布下，选对归纳偏好的算法**显著优于其他**。

### ❌ 反例 3：把正则化当作"万能提升"

> "加 L2 一定比不加好"

**问题**：正则化强度 $\lambda$ 太大 → 欠拟合；太小 → 等于无正则。需要 CV 调 $\lambda$。

### 反直觉练习

> [!question] 反直觉
> 在 CIFAR-10 上 ResNet-50 比线性回归**强得多**。这违反 NFL 定理吗？

> [!answer]- 答案
> **不违反**。NFL 定理是说"在**所有**问题（含白噪声随机标签）上平均"。CIFAR-10 是有结构的真实图像数据，**卷积 + 残差的归纳偏好**正好匹配图像先验（平移不变性、局部性）。在**这个特定问题**上 ResNet-50 极强。在**所有问题**上它和线性回归平均一样。

### 🟡 L2 - 手算/推导

- 3 假设 H1（直线 2 参数，SSE=0.1）、H2（5 阶多项式 6 参数，SSE=0.01）、H3（10 阶 11 参数，SSE=0.001）。按奥卡姆剃刀 + CV 经验，你选哪个？**写出 1 段说明**。

  > [!answer]- 答案
  > CV 上通常选 H1 或 H2。H3 训练误差最小但极可能过拟合，**奥卡姆 + CV 都会弃用 H3**。在样本量小时 H1 更稳，样本量大时 H2 可能更准。

### 🔴 L3 - 代码实验

- 在 5 个不同数据分布（线性、二次、正弦、阶梯、随机）上跑 4 个模型，画出"模型 × 分布"的热力图。**观察 NFL 定理在数据上的体现**。

```python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import Ridge, LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score

def make_data(kind, n=50, seed=0):
    np.random.seed(seed)
    X = np.linspace(0, 1, n).reshape(-1, 1)
    if kind == "linear": y = 2*X.ravel() + 0.1*np.random.randn(n)
    elif kind == "quad": y = 0.5*(10*X.ravel())**2 + 0.1*np.random.randn(n)
    elif kind == "sin": y = np.sin(2*np.pi*X.ravel()) + 0.1*np.random.randn(n)
    elif kind == "step": y = (X.ravel() > 0.5).astype(float) + 0.1*np.random.randn(n)
    else: y = np.random.randn(n)
    return X, y

models = {
    "linear": make_pipeline(PolynomialFeatures(1), LinearRegression()),
    "deg5":   make_pipeline(PolynomialFeatures(5), LinearRegression()),
    "ridge5": make_pipeline(PolynomialFeatures(5), Ridge(alpha=0.1)),
}

for kind in ["linear", "quad", "sin", "step", "random"]:
    X, y = make_data(kind)
    row = [kind]
    for name, m in models.items():
        s = cross_val_score(m, X, y, cv=5, scoring='neg_mse').mean()
        row.append(f"{-s:.2f}")
    print(" | ".join(row))
```
