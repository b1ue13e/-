# 01 · 教师式课程卡填法

> 8 段结构把"模板骨架"变成"可闭卷回答的笔记"。
> 模板位置：`99-System/📇 模板/🧑‍🏫 教师式课程卡模板.md`

## 🚨 三大硬规则（必须先看）

### 规则 1：用户写，AI 审

**这张卡的正文必须由你自己写。**AI 只在以下场景介入：
- ✅ 生成**空壳模板**（8 段标题 + 引导提示）
- ✅ **审稿**：用本文末尾的自检清单评判你的草稿
- ✅ **找反例候选**：列"哪些是看起来对其实错"，但**写不写**由你决定

**AI 绝不**：
- ❌ 批量生成 8 段正文
- ❌ 替你写手算例子（手算 = 痛苦编码 = 神经元内化）
- ❌ 替你"完善"已写的内容

> 这不是工具能力问题，是 PKM 自杀问题。详见 [[📘 笔记生产方法论#🚨 核心原则：用户写，AI 审|核心原则]]。

### 规则 2：字数硬上限 2-3KB

| 类型 | 字数上限 | 超过怎么办 |
|:---|:---|:---|
| **概念卡** | 2-3KB（800-1200 字） | 拆段、拆文件 |
| **推导链** | 3-4KB（1200-1600 字） | 拆出 `xxx-推导.md` |
| **黄金样例** | 4-6KB 允许 | 仅限 `99-System/📇 方法论/样例/` 下 |

**为什么**：原子化是 Obsidian 的核心。3KB 以上的卡片复习时认知负担过重。

### 规则 3：L1-L4 题目**永远外挂**

L1-L4 当堂练习**不写在概念卡里**，统一挂在 `🪜 阶梯作业-{{阶段名}}.md`：

```markdown
## 8. 当堂练习

见 [[🪜 阶梯作业-基础概念#🟢 L1 - 概念回忆|L1]] / [[🪜 阶梯作业-基础概念#🟡 L2 - 手算|L2]]
```

这样：
- 概念卡保持纯粹（学习内容）
- 阶梯作业聚合（验收内容）
- L1-L4 题目可单独修改、迭代、增加

## 🎯 适用场景

- 一个核心概念需要真正掌握（能说、能算、能做、能判断边界）
- 教材章节定位清晰（D2L / ISLR / Murphy / Bishop / Sutton 都能找到对应章节）
- 至少能挂 1 个开源作业（CMU 11-785 / Stanford CS229 / Lee Hung-yi 等）
- 至少有 1 个最小代码实验（sklearn / d2l / 任何仓库）

**不适用**：纯概念速览（用 `📓 概念笔记模板`）；公式推导链（用 `📐 推导笔记模板`）；错题回顾（用 `🧯 错题漏洞笔记模板`）。

## 📐 8 段结构详解

### 0. 这节课解决什么问题

**1 段话，不超过 80 字**。三要素：
- 一个具体场景（旧方法为什么不够）
- 这个问题在主线哪一步发生
- 本课工具为什么必须出现

**反例**："本文介绍 XGBoost 算法的原理和应用" ← 这种是错的，没说"为什么必须 XGBoost"。

**正例**：
> 当决策树单独使用无法压缩高维稀疏表格数据的误差时，需要一种"加法 + 二阶优化"的范式把树串成强学习器——这就是 XGBoost 解决的**「梯度 + 正则 + 工程」三位一体**问题。

### 1. 学习目标

**4 条**："学完后，不看笔记能够……"。分四档：
- **能说**：用自己的话讲清
- **能算**：手算一个最小例子
- **能做**：写出最小可运行代码
- **能判断边界**：知道什么时候不能用

### 2. 课前诊断

**1 道折叠题**（用 `> [!question]` 和 `> [!answer]-`）。题目要能暴露**典型误区**而不是简单回忆。

**反例**："XGBoost 是什么？" ← 回忆题，无诊断价值。
**正例**：
> [!question] 诊断题
> 假设你用 100 棵树做 GBDT，每棵树的 max_depth=6，训练集 RMSE=0.01，测试集 RMSE=0.5。**最可能的修复方向是？**（不要选"加更多树"）

> [!answer]- 诊断答案
> 第一反应往往是想"加树"，但测试 RMSE 比训练高 50 倍是典型的**过拟合 + 树过深**信号。优先：① max_depth 降到 3-4；② min_child_weight 调大；③ 加 λ/α 正则；④ 用 early stopping。"加树"只会加深过拟合。

### 3. 直觉模型

**1 张图（强制）或 1 个类比**。用 Excalidraw 画，或插入 Mermaid：

```mermaid
graph LR
A[旧方法: 单树投票] -->|瓶颈| B[无法压缩误差]
B -->|破局| C[加法 + 梯度 + 正则]
C --> D[XGBoost]
```

不要先堆公式。直觉不到位，公式就是空中楼阁。

### 4. 从具体数字到一般公式

**4.1 手算例子**：给完整数据，逐步计算。

例（XGBoost）：
- 初始预测 ŷ⁰⁾ = 0（常数）
- 真实 y = [0, 1, 1]
- L2 损失下，g = (ŷ - y), h = 1
- 第 1 棵树对每个样本：g₁ = -0, g₂ = 1, g₃ = 1
- 单叶节点的 G=-2, H=3，最优 w = -G/(H+λ) = 2/(3+1) = 0.5
- 新预测 ŷ¹⁾ = 0.5
- 再算 g²⁾...

**4.2 一般形式**：从手算抽象出公式，每个符号注明**意义 + 成立条件**。

### 5. 教师示范例题

**"题目 → 思路 → 逐步解答 → 结果检查 → 改条件追问"** 5 步。
最后一步尤其重要：**改一个条件**（如把 L2 换成交叉熵），让学生自己推。

### 6. 最小代码实验

```python
# 最小可运行片段，5-15 行
import xgboost as xgb
X, y = [[1],[2],[3],[4]], [1, 2, 3, 4]
model = xgb.XGBRegressor(max_depth=2, n_estimators=2)
model.fit(X, y)
print(model.predict([[5]]))  # 预期: ~5
```

**先写预期，再写代码，最后解释输出**。三段式：预期 → 代码 → 解释。

### 7. 常见错误与反例

**至少 1 个"看起来对其实错"**。格式：
- ❌ 错误直觉："XGBoost = 很多树投票"
- ✅ 实际是：XGBoost 是**加法 + 二阶 + 正则**的统一目标
- 复现错误的最小反例（可手算或代码）

### 8. 当堂练习（L1-L4）

| 级别 | 类型 | 例 |
|:---|:---|:---|
| 🟢 L1 概念回忆 | 一句话 | "XGBoost 目标函数由哪两部分组成？" |
| 🟡 L2 手算/推导 | 数字+步骤 | 给 3 样本、2 棵深度 1 树，手算 G/H |
| 🔴 L3 代码实验 | 5-20 行 | 在 toy 数据上跑 XGBoost，对比 GBDT |
| 👑 L4 开放应用 | 真实数据 | Kaggle tabular 任务调参 |

答案默认折叠（`> [!answer]-`），先独立完成。

### 9. 过关标准

- [ ] 能说（不看书讲清楚）
- [ ] 能算（手算一个最小例子）
- [ ] 能做（5-20 行代码验证）
- [ ] 能判断边界（什么场景不能用）
- [ ] 至少 1 个反例能复现

## 🃏 Anki 卡片（每张卡 ≥3 张）

只考**关键判断**和**反直觉**，不复制整段文字：
- "XGBoost 与随机森林的根本区别是什么？" :: 答案（不超过 3 句）
