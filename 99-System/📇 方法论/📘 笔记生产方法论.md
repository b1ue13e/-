## 🚨 核心原则：用户写，AI 审

> **这是 PKM 中最容易触犯的核心禁忌**——让 AI 写正文会变成"AI 的维基百科"，引发**收藏家谬误**（看着排版精美就以为自己学会了）。

### ❌ AI 不做的事
- **不批量生成卡片正文**——AI 不能替你做"假设空间"的理解
- **不批量重写空壳卡**——这是 PKM 自杀行为，破坏费曼技巧
- **不替你写手算例子**——手算 = 痛苦编码，是神经元层面的内化

### ✅ AI 做的事
- **建框架**：模板、SOP、索引、作业入口
- **当考官**：审你的草稿，找漏洞、反例、Bug
- **当刻薄审稿人**：用自检清单逐条评判你的卡
- **当资料员**：挂章节定位、找开源作业、列优秀代码库

### 工作流（单向，不可逆）

```
你读教材/视频
    ↓
你写空壳卡（这是你的痛苦编码）
    ↓
你写完整卡片（200-400 字关键判断 + 反例）
    ↓
AI 审稿：用 01-教师式课程卡填法 的自检清单
    ↓
你修改：补漏洞、补反例、改代码
    ↓
通过后才标 status: completed
```

### 字数硬规则

| 卡片类型 | 字数上限 | 为什么 |
|:---|:---|:---|
| **概念卡** | 2-3KB（中文 800-1200 字） | 原子化；超过就要拆 |
| **推导卡** | 3-4KB（中文 1200-1600 字） | 公式链必须紧凑 |
| **L1-L4 题目** | **不写在概念卡里** | 外挂到阶梯作业文件 |
| **样例（参考用）** | 4-6KB 允许 | 黄金样例可丰满，但仍要拆段 |

### 拆分原则

- 公式推导 ≥ 30 行 → 拆出 `xxx-推导.md`
- 反例 ≥ 3 个 → 拆出 `xxx-反例集.md`
- 代码实验 ≥ 30 行 → 拆出 `xxx-实验.ipynb`
- L1-L4 题目 → 永远挂在阶梯作业文件，概念卡只链接

## 🧭 总体方法论

### 一条笔记应该长什么样

```
一页笔记 = 一个"主问题" + 8 段结构 + 3 个反例 + 1 个最小实验 + ≥3 个反向链接
```

- **主问题**：一句话说清"这页解决什么问题"，先于一切
- **8 段结构**：见 `01-教师式课程卡填法`
- **3 个反例**：至少 1 个"看起来对其实错"
- **1 个最小实验**：可复现的代码或手算
- **≥3 个反向链接**：前置、相关、跨路径

### 一组笔记应该怎么连

```
概念卡 → 推导卡 → 题型卡 → 错题卡 → 阶梯作业 → 项目验证
 ↑______________|  (Sprint 1 主线循环)
```

- **概念卡** = 是什么、解决什么问题
- **推导卡** = 公式怎么来、每一步为什么
- **题型卡** = 这类题怎么识别、怎么做
- **错题卡** = 我在哪儿错、错因、修复动作
- **阶梯作业** = 4 级难度实战
- **项目验证** = 端到端可复现

### 一门课程应该怎么学

```
开放教材主线 → 教师式课程卡 → 阶梯作业 L1-L2 → 错题回流 → L3-L4 项目
     ↑                                                ↓
     ←──────────── 薄弱点 Anki Again 回流 ─────────────┘
```

## 🛠️ 工具协同

| 工具 | 角色 | 边界 |
|:---|:---|:---|
| **Obsidian** | 知识主仓库、双链、可视化 | **不接管制卡**（不双调度） |
| **Anki 26.05 FSRS** | Spaced Repetition 调度 | **唯一调度方** |
| **Dataview** | 自动索引、统计、面板 | 只读 frontmatter |
| **Templater** | 模板插值 | 生成新卡时用 |
| **QuickAdd** | 快速创建 + 命令面板 | 新卡流程编排 |
| **Excalidraw** | 直觉模型图、思维导图 | `## 直觉模型` 段强制 |
| **Canvas** | 多卡串联、知识图谱 | 复杂概念组用 |

## 📐 一致性规则

1. **frontmatter 字段**：`type / status / flow / kind / concept / prerequisites / related` 是核心 7 字段，所有卡必须填。
2. **段落编号**：学习卡用中文数字（一、二、三），索引页用英文（1. 2. 3.），作业卡用 Tier（L1-L4）。
3. **文件名**：概念卡用主题名（`假设空间.md`），推导卡用主题+推导（`XGBoost目标函数推导.md`），作业卡用编号（`HW01-线性回归.md`）。
4. **链接语法**：内部用 `[[]]`，外部用 `[title](url)`，嵌入用 `![[]]`。
5. **来源标注**：每个事实性陈述必须挂 `sources` 字段，写到 `locator` 级章节。
