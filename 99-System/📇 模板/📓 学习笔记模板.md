# 📓 学习笔记模板入口

> 新建学习笔记时，先判断它属于哪一种沉淀，再套对应模板。

## 五类模板

| 类别 | 负责什么 | 模板 |
|:---|:---|:---|
| MOC 地图笔记 | 只放结构和链接，不写正文 | [[🧭 MOC地图笔记模板]] |
| 概念笔记 | 理解一个知识点 | [[📓 概念笔记模板]] |
| 推导笔记 | 展开公式、证明和每一步理由 | [[📐 推导笔记模板]] |
| 题型笔记 | 总结解题套路和常见变式 | [[📝 题型笔记模板]] |
| 错题/漏洞笔记 | 记录真实错误、错因和修复动作 | [[🧯 错题漏洞笔记模板]] |

## 选择规则

- 如果页面主要是“目录、路径、链接”，用 MOC。
- 如果页面主要回答“这是什么、解决什么问题”，用概念笔记。
- 如果页面主要回答“公式为什么成立、每一步怎么来”，用推导笔记。
- 如果页面主要回答“这类题怎么识别、怎么做”，用题型笔记。
- 如果页面来自一次真实错误、卡点或误解，用错题/漏洞笔记。

## 推荐流程

教材目录 -> MOC -> 预问题 -> AI 讲解 -> 闭卷复现 -> 题目训练 -> 错误回填 -> 间隔复习 -> 应用输出
