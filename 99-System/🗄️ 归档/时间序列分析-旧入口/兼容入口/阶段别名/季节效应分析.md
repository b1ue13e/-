# 季节效应分析｜导航别名

> 权威主题卡是[[季节性与STL分解]]；季节预测模型进入[[L06-SARIMA与季节预测]]。本页不复制季节定义、代码和练习。

## 最小判断框架

1. **频率不是周期**：月度数据只有在业务机制与重复图形支持时才候选 $m=12$。
2. **季节不等于周期**：固定日历位置重复属于季节性；不固定周期的商业循环不能机械做季节差分。
3. **季节强度会变**：经典分解假设较强；STL 可允许季节形态缓慢变化。
4. **预测必须有 seasonal naïve**：复杂季节模型若无法稳定胜过同季节朴素值，就没有证明额外复杂度。

**学习顺序**：[[季节性与STL分解]] → [[L06-SARIMA与季节预测]] → [[滚动回测与预测区间]]。
