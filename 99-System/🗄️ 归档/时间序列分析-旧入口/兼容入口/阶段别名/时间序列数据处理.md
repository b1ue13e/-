# 时间序列数据处理｜导航别名

> 唯一教学正文为[[L00-环境与时间索引]]；金融字段专题见[[OHLCV字段清洗与复权]]。

处理顺序：解析日期 → 排序与去重 → 声明频率 → 显式补齐时间轴 → 区分缺失机制 → 冻结预测原点 → 在训练窗口内执行填补/缩放。任何使用未来观测的插值、复权或修订数据都必须按历史可得版本重建。
