# 时序特征工程｜导航别名

> 权威主题卡统一为[[时序特征工程与ML预测]]。本页不复制特征公式、泄漏边界、代码和练习。

## 最小检查

- 每个特征必须属于真实预测原点的信息集 $\mathcal F_t$。
- 滞后与滚动统计必须先 `shift` 再聚合，防止当前目标混入。
- 缩放、填补、编码和特征选择都只在每个训练窗口拟合。
- 多步预测要声明 direct、recursive 或 multi-output 策略。
- 树模型至少比较 naïve、seasonal naïve 与经典统计模型。
