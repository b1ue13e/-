# 33 门课程开源自学项目调研

> [!success] 落地状态（2026-07-28）
> 33 门课程的 Spine、阶段 Lab、Capstone、Rubric、许可证边界和学习路径入口已全部落地，见 [[33门课程开源自学与验收总索引]]。本报告保留为调研证据；“完整设计”不代表同时开课，当前唯一 Sprint 仍是量化金融。

> [!summary]
> 结论：33 门课程都能找到可用的开源主线、实验仓库或项目载体。  
> 其中 **27 门可以直接挂载成熟课程/Notebook/作业体系**，**5 门需要在开源材料上补自定义验收作业**，**1 门（测度论）应坚持证明优先，编程或 Lean 只作可选验证**。

## 1. 本地现状

- 33 条主路径均已有学习路径文件和阶段结构。
- 当前 33 个学习路径文件中没有外部 `http/https` 链接。
- 现有设计的优势是知识框架清楚；主要缺口是：
  1. 可直接跟学的公开课程与作业；
  2. 可复现的代码、数据和实验环境；
  3. 阶段性验收项目与统一 Rubric；
  4. 资源许可证与本地镜像策略。

## 2. 筛选原则

每门课最多只选一个主线，其他资源降级为实验或参考，避免资源囤积。

| 层级 | 作用 | 最低要求 |
|---|---|---|
| 主线 Spine | 决定学习顺序 | 有完整目录、章节或周计划 |
| 实验 Lab | 把概念变成可观察结果 | 有 Notebook、代码、作业或数据 |
| 验收 Capstone | 判断是否真正掌握 | 有 baseline、改进、对比、报告 |
| 参考 Reference | 卡住时查阅 | 不进入默认任务队列 |

成熟度标记：

- **A：可直接挂载**——主线、实验或作业已经比较完整；
- **B：需补作业**——资源成熟，但需要自己设计阶段验收；
- **C：证明优先**——不应为了项目制强行编程。

### 这一组的注意事项

1. 不要使用公开的课程答案仓库作为主线；只使用官方题目、starter code 和公开教材。
2. 深度学习项目必须先有朴素 baseline，不能一开始就上大模型。
3. 量化项目必须检查前视偏差、幸存者偏差、交易成本和时间切分。
4. 信息检索项目先做 BM25，再做稠密检索；否则无法判断复杂模型是否真的改进。

### 证明型课程的统一验收

不要用“写了多少笔记”作为完成标准。建议采用：

1. **定义复述**：不看资料写出定义，并给出正例与反例；
2. **定理依赖图**：标明每个关键结论依赖哪些定义、引理；
3. **证明重建**：只给提示，独立完成证明；
4. **变式题**：改变一个条件，判断结论是否仍成立；
5. **口头费曼**：5–10 分钟说明定理解决了什么问题；
6. **闭卷抽测**：阶段结束后随机抽 3 个定义、2 个证明、1 个反例。

## 8. 与现有 Obsidian 系统的接入方式

### 8.1 不建议直接改主线索引为“链接仓库列表”

主线索引仍只放粗粒度主题卡。外部资源统一进入每门课现有的 `📚 教材挂载索引.md`，再从学习路径链接过去。

每个资源条目建议使用：

```yaml
resource_role: spine | lab | capstone | reference
resource_type: course | open-textbook | notebook | project | library
source_url: ""
license: ""
mirror_policy: link-only | fork | local-clone
stages: []
start_here: ""
expected_output: ""
acceptance_test: ""
compute: low | medium | high
```

### 8.2 推荐的课程页结构

```markdown
## 开源主线
- 主资源：
- 只学哪些章节：
- 明确跳过哪些章节：

## 阶段实验
| 阶段 | 实验 | 产出 | 验收 |

## 结课项目
说明书 → baseline → 改进对比 → Rubric 报告 → 知识反哺

## 许可证与镜像
- 可否复制到本地：
- 是否只能保留链接：
- 最后核验日期：
```

### 8.3 许可证规则

1. 默认只保存链接与自己的学习说明。
2. 有明确 MIT、Apache、BSD、GPL 或 CC 许可证时，再按条款决定是否镜像。
3. GitHub 上“公开可见”不等于允许复制或再分发。
4. 没有明确许可证的仓库采用 `link-only`。
5. 课程作业遵守 Honor Code：使用题目和 starter code，不挂载他人答案。

## 10. 最终判断

可以找到，而且资源质量足以把现有 33 条“知识路线”升级为“可执行自学课程”。

真正应该做的不是继续收集更多链接，而是：

1. 每门课只确定一个主线；
2. 每阶段只挂一个实验；
3. 每门课只设一个结课项目；
4. 用统一 Rubric 验收；
5. 只启动当前 Sprint 所需的 6 门，其他保持 `planned`。
