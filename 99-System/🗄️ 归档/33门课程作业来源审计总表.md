# 33 门课程作业来源审计总表

> 本表已按用户提供的详细课程映射完成 attachment-v2 对齐，只审计每门课的唯一 Spine。`可访问` 不等于允许复制：没有机器可读许可证或官方复用声明时，一律 `link-only`。课程题目和 Starter Code 即使公开，也必须遵守原课程 Honor Code。

## 审计口径

- GitHub 主线：2026-07-28 使用 GitHub 仓库元数据核验仓库存在、未归档及机器可读 SPDX。
- 官方网页：只确认页面可访问；许可证和作业复用范围未明确时保持 `link-only`。
- `NOASSERTION` 或未返回许可证：视为**未核验**，不能从“公开仓库”推导出复制权。
- MIT、Apache、BSD、GPL 只描述仓库内容的许可证，不自动覆盖数据集、第三方素材、课程题目或底层行情。
- 本地镜像只在课程真正激活后进行；未激活课程不预先克隆。
