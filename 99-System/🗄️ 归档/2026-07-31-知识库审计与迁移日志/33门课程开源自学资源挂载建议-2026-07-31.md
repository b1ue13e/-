# 33门课程开源自学资源挂载建议

> 本页不是再列一遍资源清单，而是回答一个更实际的问题：每门课应该优先挂什么类型的外部资源，作业应该像什么，哪些课适合 GitHub，哪些课更适合 OCW、教材和题集。

> 现实落地状态请同时参照：[[33门课程资源与实施现状审计-2026-07-31]]。本页解决“应该怎么挂”，审计页解决“现在做到哪一步”。

## 挂载规则

1. 代码课优先挂 `官方课程 / 官方作业 / 开源课程仓库`，GitHub 解答仓库只做 `link-only` 参考。
2. 工程课优先挂 `Starter Code + Lab + Capstone`，避免只挂讲义不挂验收。
3. 证明型数学课优先挂 `教材 + OCW + 习题集 + 证明验收模板`，不强行套成代码作业。
4. 每门课只保留一个主 Spine；补充资源最多 1-2 条，防止学习入口失控。
5. 涉及公开课程作业时，遵守 Honor Code：保留题目与 starter code，外部答案仓库只做思路对照，不直接纳入本地答案包。

## 优先级建议

### 第一批：最适合先挂真实作业的课程

- `17-机器学习`：现成公开作业最多，最容易做成范例页。
- `05-计算机视觉`：CS231n 作业结构成熟，容易拆成阶梯作业。
- `08-NLP 全栈`：CS224N + Hugging Face 资源完整，适合阶段化。
- `13-强化学习`：CS188 Projects 的题型天然适合验收。
- `10-数据结构与算法`：官方题单 + 本地测试 harness 容易落地。
- `11-计算机组成原理`：Nand to Tetris 有天然分层 project。

### 第二批：适合“课程 + notebook + 小项目”混合挂载

- `02-时间序列分析`
- `03-量化金融`
- `07-最优化方法`
- `23-图神经网络`
- `29-运筹学`
- `33-贝叶斯统计`

### 第三批：不要硬做成 GitHub 作业仓库

- `04-离散数学`
- `25-测度论`
- `26-实变函数`
- `27-泛函分析`
- `28-数学分析`

这类课程更适合采用：

- `Spine`: OCW / 教材 / 习题课
- `Lab`: 少量可视化或验证 notebook
- `Capstone`: 证明重建、反例卡、闭卷概念图
