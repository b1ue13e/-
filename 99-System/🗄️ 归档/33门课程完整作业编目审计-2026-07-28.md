# 33 门课程完整作业编目审计（2026-07-28）

## 结论

- 33/33 门正式课程均有 `课程作业总表.md`；
- 共编目 **273 个课程内官方公开作业/实验入口条目**；
- 共建立 **132 个本地原创扩展单元**；
- 作业单元合计 **405 个**；
- 33 个课程教材索引均能进入完整作业包；
- 每个作业单元都有来源、类型、最低提交、硬验收、答案策略和执行状态；
- 33 门课原有的期末综合正式作业继续作为 Capstone；
- 当前作业状态均为 `planned`，没有伪造执行结果。

> 273 是“课程内入口条目数”，同一公开资源被不同课程使用时会按课程分别计数，不表示 273 个互不重复的第三方文件。

## 编目口径

### `official-link`

- 对官方页面实际公开列出的 Homework、Problem Set、Project、Colab 或 Programming Assignment 逐项编号；
- 本库保存题号、主题、官方 URL 和自己的执行要求；
- 不复制第三方题干、Starter 压缩包或参考答案；
- 存在官方解答时先独立完成，再按原课程政策核对。

### `local-original`

- 对没有完整公开作业序列的课程，按课程知识主线建立本地原创作业；
- 对官方作业未覆盖但本地课程需要的主题补充扩展作业；
- 不把本地扩展冒充官方课程作业。

## 许可与答案边界

1. “公开可访问”不自动等于“开放许可证”；
2. MIT OCW 材料按 MIT OCW/Creative Commons 条款逐项使用；
3. Stanford、Penn State、李宏毅等课程作业默认 `link-only`；
4. GitHub 仓库许可证只覆盖仓库明确声明的内容，不自动覆盖数据、模型和第三方素材；
5. 不挂学生答案仓库，不把官方解答复制进知识卡；
6. 未激活课程不整仓克隆，避免版本漂移、重复资产和无效囤积。
