# 📜 修炼规则

> 完成任务即得修为；拖延主线即生心魔。修炼系统只结算已有日计划和知识库状态，不额外增加新任务。

## 每日修为

| 日计划章节 | 修炼名 | 每项修为 |
|:--|:--|:--|
| 今日学习 | 主线天命 | +30 |
| ChatGPT 出题复盘 | 试剑台 | +10 |
| 雅思词汇 | 外门功课 | +10 |
| 训练计划 | 炼体 | +30 |
| 饮食与身体打卡 | 辟谷 | +5 |
| 当日收束 | 夜观命盘 | +5 |

## 长期功德

| 页面类型 | 状态 | 修为 |
|:--|:--|:--|
| `study` | `completed / ongoing / planned` | `+10 / +3 / +0` |
| `stage` | `completed / active或ongoing / 其他` | `+80 / +20 / +0` |
| `paper` | `finished / reading / unread` | `+120 / +40 / +0` |
| `book` | `finished / reading / 其他` | `+200 / +60 / +0` |
| `project` | `completed` | `+300` |
| `project` | 未完成但有 `progress` | 按百分比折算 |

## 境界

境界共 9 重，每重 9 层：炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫。

当前修为按“已得修为 / 全库最大可得修为”映射到 81 小层。全库学完且心魔值为 0 时，证得最终称号：**万法归一·诸天道祖**。

## 心魔与跌落

- 只结算 `start < today` 的日计划；今天未完成不提前惩罚。
- 过去某日 `今日学习` 完成 `2/3`：心魔 `+1`。
- 过去某日 `今日学习` 完成 `0/3` 或 `1/3`：心魔 `+2`。
- 完美日：`今日学习`、`ChatGPT 出题复盘`、`当日收束`全部完成，心魔 `-1`。
- 每 `2` 点心魔压低 `1` 小层境界；只掉小层，不跌破当前大境界第一层。
- 历史最高境界按已获修为单独保留，不被心魔抹掉。

## 使用纪律

1. 每天只打开当天日计划和修炼总枢。
2. 完成就勾选，不补写经验。
3. 周/月/季度复盘只用于观察趋势，不新增支线任务。
4. 心魔不是羞辱，是警报；补回连续完美日即可退散。
