# 🔗 日计划课程索引挂载规则

> 每个日计划必须挂载课程入口、阶段/教材目录主题、雅思入口、体能项目入口，并保留饮食 kcal 打卡。

## 每日固定结构

| 模块 | 内容 |
|:--|:--|
| 学习 | 三门深学，每门课程入口 + 阶段入口/教材目录主题卡 |
| 复盘 | ChatGPT 出题复盘，记录错题原因 |
| 雅思 | 每天新背 40 词，标记不熟词 |
| 训练 | 跑步/篮球/力量/跳绳/恢复，按周模板执行 |
| 饮食 | kcal、蛋白质、饮水、体重、饥饿感、疲劳感打卡 |
| 导航 | 前后日、本周、本月、本季度、总索引 |

## 主题来源纪律

1. 日计划中的“主题”必须来自对应学习路径总览、阶段入口、教材目录或正式主题卡。
2. 取材顺序固定为：学习路径总览 -> 阶段入口清单 -> 对应教材/书籍目录 -> 已存在正式主题卡。
3. 不得把 `理解\d+`、`推导\d+`、`证明\d+`、`公式理解\d+`、`未命名`、`Pasted image` 放入每日学习主线。
4. 临时理解卡只能作为正式主题卡内部的补充链接，不进入日计划、周计划、月计划的主线主题列表。
5. 如果某天主题不够 3 个，从同阶段学习清单或对应书籍目录补正式主题；宁可保留 2 个正式主题，也不要用临时卡凑数。
6. 每次生成或修改计划后，必须运行临时卡扫描，确保计划系统中没有上述临时命名。

## 执行纪律

1. 当天只执行当天日计划。
2. 学习输出不追求长笔记，必须保留可测试输出。
3. 饮食只看连续趋势，不因单日波动崩盘。
4. 周计划只做统计和调整，不增加新任务。
